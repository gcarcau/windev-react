# ParentObjet (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Identifie le "parent" d'un objet graphique : champ, colonne, fenêtre, page, ...

## Exemple

> _(WINDEV, Etats et Requêtes, Java, Code Utilisateur (MCU))_ // COL_Colonne1 est dans TABLE_Table1, qui est dans la fenêtre FEN_Fenêtre2,
// qui est fille de FEN_Fenêtre1
ParentObjet(COL_Colonne1) // Renvoie "TABLE_Table1"
ParentObjet(TABLE_Table1) // Renvoie "FEN_Fenêtre2"
ParentObjet(FEN_Fenêtre2) // Renvoie "FEN_Fenêtre1"
ParentObjet(FEN_Fenêtre1) // Renvoie ""

> _(WEBDEV - Code Serveur, Ajax)_ // COL_Colonne1 est dans TABLE_Table1, qui est dans la page PAGE_Page1
ParentObjet(COL_Colonne1) // Renvoie "TABLE_Table1"
ParentObjet(TABLE_Table1) // Renvoie "PAGE_Page1"

## Syntaxe

```wlangage
<Résultat> = ParentObjet(<Nom de l'objet>)
```

`<Résultat>` *Chaîne de caractères*
> - Si <Nom de l'objet> est un champ, <Résultat> correspond au nom de la fenêtre (ou de la page) à laquelle appartient le champ (même si le champ est dans un onglet).
> - Si <Nom de l'objet> est une colonne, <Résultat> correspond au nom du champ Table.
> - Si <Nom de l'objet> est une fenêtre, <Résultat> correspond au nom de la fenêtre mère (ou à une chaîne vide ("") si le paramètre <Nom de l'objet> n'a pas de fenêtre mère).
> - Si <Nom de l'objet> est une page, <Résultat> correspond au nom du frameset (ou à une chaîne vide ("") si le paramètre <Nom de l'objet> n'a pas de frameset).
`<Nom de l'objet>` *Chaîne de caractères*
> Nom de l'objet (champ, fenêtre, page, colonne) dont le parent est recherché. Si l'objet est inconnu, une erreur WLangage est affichée.

## Remarques

> _(WINDEV, Code Utilisateur (MCU))_ ParentObjet et les fenêtres MDILa fonction ParentObjet utilisée sur une fenêtre ouverte depuis une fenêtre fille MDI renvoie l'alias de la fenêtre fille MDI.
