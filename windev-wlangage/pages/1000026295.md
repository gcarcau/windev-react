# Fonctions de gestion du champ Editeur HTML

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion du champ Editeur HTML (syntaxe préfixée)](1000026310.md)).
Les fonctions WLangage permettant de gérer les champs Editeur HTML sont les suivantes :

| [EditeurHTMLDepuisEmail](1000026172.md) | Importe le contenu HTML d'un email et ses images dans un champ Editeur HTML. Les images contenues dans l'email sont également affichées dans le champ. |
| --- | --- |
| [EditeurHTMLExécuteJS](1000026260.md) | Exécute du code Javascript dans un champ Editeur HTML. |
| [EditeurHTMLFormateSélection](1000025996.md) | Modifie le style de la sélection dans un champ Editeur HTML. |
| [EditeurHTMLInsère](1000025994.md) | Insère du texte ou du code HTML à la position du curseur dans un champ Editeur HTML. |
| [EditeurHTMLInsèreTableau](1000025917.md) | Insère un tableau à la position du curseur dans un champ Editeur HTML. |
| [EditeurHTMLRecherche](1000025918.md) | Recherche une chaîne de caractères dans un champ Editeur HTML. |
| [EditeurHTMLRécupère](1000025981.md) | Récupère en mode asynchrone la valeur d'une des propriétés d'un champ Editeur HTML. |
| [EditeurHTMLRécupèreDocument](1000025993.md) | Récupère en mode asynchrone le document HTML en cours dans un champ Editeur HTML. |
| [EditeurHTMLRécupèreSélection](1000025992.md) | Récupère en mode asynchrone la sélection effectuée dans un champ Editeur HTML. |
| [EditeurHTMLRemplace](1000025995.md) | Remplace une chaîne de caractères par une autre dans un champ Editeur HTML. |
| [EditeurHTMLSélectionne](1000025926.md) | Sélectionne une portion de texte dans un champ Editeur HTML. |
| [EditeurHTMLVersEmail](1000026171.md) | Exporte le contenu d'un champ Editeur HTML vers une variable de type Email (pour envoyer l'email). |
| [EditeurHTMLVersPDF](1000025927.md) | Exporte le contenu d'un champ Editeur HTML vers un fichier PDF. |
