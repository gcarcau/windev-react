# Beep (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Permet d'émettre un bip sonore sur le haut parleur de la machine.

## Exemple

```wlangage
// En CAPPELWD("Beep");
```

```wlangage
// En PascalAPPELWD('Beep');
```

```wlangage
// En VBCall APPELWD("Beep")
```

## Syntaxe

