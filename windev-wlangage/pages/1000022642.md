# <Variable Connexion>.AjoutePlanification (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Ajoute un nouvel élément planifié sur un serveur HFSQL : tâche planifiée (procédure stockée), sauvegarde, optimisation ou rafraîchissement d'une vue matérialisée.

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion
...
// Recalculer les statistiques des fichiers de données de la base de données "MaBase",
// tous les samedis à 23H00
Optim est une hOptimisationPlanifiée
Optim.Description = "Recalcul des statistiques des fichiers de données" + ...
	" de la base de données MaBase"

Optim.Planification.Mois = "*"
Optim.Planification.JourDeLaSemaine = "samedi"
Optim.Planification.Heure = "23"
Optim.Planification.Minute = "0"

Optim.Fichier[1].Nom = "MaBase"
Optim.Fichier[1].Option = hOptStat

MaConnexion.AjoutePlanification(Optim)
```

## Syntaxe

#### Ajouter une tâche planifiée

```wlangage
<Résultat> = <Connexion>.AjoutePlanification(<Tâche planifiée>)
```

`<Résultat>` *Booléen*
> - Vrai si la tâche planifiée a été ajoutée,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle une tâche planifiée doit être ajoutée.
`<Tâche planifiée>` *Variable de type hTâchePlanifiée*
> Nom de la variable de type [hTâchePlanifiée](1000017448.md), décrivant la tâche déclenchant une procédure stockée.

#### Ajouter une tâche d'optimisation planifiée

```wlangage
<Résultat> = <Connexion>.AjoutePlanification(<Tâche d'optimisation planifiée>)
```

`<Résultat>` *Booléen*
> - Vrai si la tâche d'optimisation planifiée a été ajoutée,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle une tâche d'optimisation planifiée doit être ajoutée.
`<Tâche d'optimisation planifiée>` *Variable de type hOptimisationPlanifiée*
> Nom de la variable de type [hOptimisationPlanifiée](1000018854.md) manipulée.

#### Ajouter une planification de sauvegarde

```wlangage
<Résultat> = <Connexion>.AjoutePlanification(<Sauvegarde planifiée>)
```

`<Résultat>` *Booléen*
> - Vrai si la sauvegarde planifiée a été ajoutée,
> - Faux dans le cas contraire.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle une sauvegarde planifiée doit être ajoutée.
`<Sauvegarde planifiée>` *Variable de type hDescriptionSauvegarde*
> Nom de la variable de type [hDescriptionSauvegarde](1000017455.md) manipulée.

#### Ajouter une planification de rafraîchissement d'une vue matérialisée

```wlangage
<Résultat> = <Connexion>.AjoutePlanification(<Vue matérialisée>)
```

`<Résultat>` *Booléen*
> - Vrai si la planification a été ajoutée,
> - Faux dans le cas contraire.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle une planification de rafraîchissement de vue matérialisée doit être ajoutée.
`<Vue matérialisée>` *Variable de type hPlanificationVueMatérialisée*
> Nom de la variable de type [hPlanificationVueMatérialisée](1000021444.md) contenant la description de la vue matérialisée à rafraîchir.
