# Interligne (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **Interligne** permet de gérer l'interligne d'un élément. Cette propriété est utilisable sur :

- une variable de type [docParagraphe](1000022483.md) (caractéristiques de mise en page).
- une variable de type [docNiveauNumérotation](1000022799.md).
