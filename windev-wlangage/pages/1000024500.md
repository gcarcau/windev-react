# <Variable picCalque>.DessinePoint (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Dessine un point dans une variable de type [picCalque](1000024604.md).

## Exemple

```wlangage
MonImageWDPic est un WDPic = "Test.bmp"
MonCalque est un picCalque
// Dessin d'un point jaune clair dans un calque
MonCalque.DessinePoint(10, 50, JauneClair)
IMG_MonDessin = MonImageWDPic
```

## Syntaxe

#### Dessiner un point en donnant ses coordonnées

```wlangage
<Image picCalque>.DessinePoint(<Abscisse> , <Ordonnée> [, <Couleur du point> [, <Opacité>]])
```

`<Image picCalque>` *Variable de type picCalque*
> Nom de la variable de type [picCalque](1000024604.md) à manipuler.
`<Abscisse>` *Entier*
> Position horizontale (en pixels) du point à dessiner.
`<Ordonnée>` *Entier*
> Position verticale (en pixels) du point à dessiner.
`<Couleur du point>` *Entier ou constante (optionnel)*
> Couleur à affecter au point. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md).
>
>
> Si ce paramètre n'est pas précisé, la couleur du point :
>
>
> - est *Transparent* si la fonction [<Image>.Stylo](1000024016.md) n'a pas été utilisée auparavant,
> - correspond à la couleur précisée dans le dernier appel à la fonction [<Image>.Stylo](1000024016.md).
`<Opacité>` *Entier optionnel*
> Opacité de la couleur, comprise entre 0 (transparent) et 255 (opacité complète). Une opacité de 128 indique que le pixel concerné aura une transparence de 50% lorsqu'il sera dessiné à l'écran ou sauvé dans une image au format PNG.
> **Remarque** : Cette opacité sera prise en compte si le dessin dans l'image a été initialisé avec la constante *dAvecOpacité* (fonction [<Variable picCalque>.DébutDessin](1000024470.md)).

#### Dessiner un point via une variable de type Point

```wlangage
<Image picCalque>.DessinePoint(<Point> [, <Couleur du point> [, <Opacité>]])
```

`<Image picCalque>` *Variable de type picCalque*
> Nom de la variable de type [picCalque](1000024604.md) à manipuler.
`<Point>` *Variable de type Point*
> Nom de la variable de type [Point](1000018908.md) contenant les coordonnées du point à dessiner.
`<Couleur du point>` *Entier ou constante (optionnel)*
> Couleur à affecter au point. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md).
>
>
> Si ce paramètre n'est pas précisé, la couleur du point :
>
>
> - est *Transparent* si la fonction [<Image>.Stylo](1000024016.md) n'a pas été utilisée auparavant,
> - correspond à la couleur précisée dans le dernier appel à la fonction [<Image>.Stylo](1000024016.md).
`<Opacité>` *Entier optionnel*
> Opacité de la couleur, comprise entre 0 (transparent) et 255 (opacité complète). Une opacité de 128 indique que le pixel concerné aura une transparence de 50% lorsqu'il sera dessiné à l'écran ou sauvé dans une image au format PNG.
> **Remarque** : Cette opacité sera prise en compte si le dessin dans l'image a été initialisé avec la constante *dAvecOpacité* (fonction [<Variable picCalque>.DébutDessin](1000024470.md)).

## Remarques

### Coordonnées
Les coordonnées sont indiquées par rapport au coin haut gauche de l'image (coordonnées (0,0)).
