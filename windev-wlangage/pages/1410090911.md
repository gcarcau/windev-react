# Paramètres de la procédure utilisée par la fonction ListeProcédureChargeImage

> **Disponible :** **WINDEV** (Windows)

Procédure WLangage (également nommée "callback") exécutée pour afficher les images d'un champ Liste Image.

## Exemple

```wlangage
PROCÉDURE INTERNE ChargeImagePerso(numLigne est un entier, largeur est entier, hauteur est entier)
	ImageACharger est une Image
	ImageACharger.Largeur = largeur
	ImageACharger.Hauteur = hauteur
	dDébutDessin(ImageACharger, dAvecOpacité)
	dPolice("Arial", 12, iNormal, 0)
	dTexte(4, 0, "Ligne " + numLigne)
	RENVOYER ImageACharger
FIN

ListeProcédureChargeImage(LSI_MaListeImage, ChargeImagePerso)
```

## Syntaxe

```wlangage
<Résultat> = ListeProcédureChargeImage_Callback(<Ligne> , <Largeur> , <Hauteur>)
```

`<Résultat>` *Variable de type Image*
> Variable de type [Image](1000019650.md) correspondant à l'image à ajouter dans la liste.
`<Ligne>` *Entier*
> Numéro de la ligne manipulée.
`<Largeur>` *Entier*
> Largeur attendue pour l'image.
`<Hauteur>` *Entier*
> Hauteur attendue pour l'image.

**Composante : wd300.dll**
