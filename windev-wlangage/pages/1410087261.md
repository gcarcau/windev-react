# <Page>.FermePopup (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur)

Masque une page affichée en popup via la fonction [<Page>.AffichePopup](1410087260.md).

## Exemple

```wlangage
// Ferme la page affichée en popup
PAGE_DétailsProduit.FermePopup()
```

## Syntaxe

```wlangage
<Page>.FermePopup()
```

`<Page>` *Nom de page*
> Nom de la page affichée en popup qui sera masquée. Cette page doit avoir été affichée par la fonction [<Page>.AffichePopup](1410087260.md). Si ce n'est pas le cas, la fonction **<Page>.FermePopup** n'a aucune action.

## Remarques

Les navigateurs ne rafraîchissent pas l'affichage au milieu d'un code Javascript : les fonctions [<Page>.AffichePopup](1410087260.md) et **<Page>.FermePopup** doivent être utilisées dans des traitements/événements différents. Si ces fonctions sont utilisées dans le même traitement/événement, la page Popup n'est pas affichée.

**Composante : wd300page.dll**
