# Logiciel Etats & Requêtes : Fonctions WLangage non supportées

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

## Présentation

Certaines fonctions WLangage ne sont pas disponibles sous le logiciel Etats & Requêtes. Ces fonctions sont les suivantes :

| [HAjoute](3044147.md) | Ajoute l'enregistrement présent en mémoire dans le fichier de données (la requête ou la vue). |
| --- | --- |
| [HAjouteGroupe](3044280.md) | Ajoute un groupe d'utilisateurs (connexion HFSQL Client/Serveur) |
| [HAjouteLiaison](3044312.md) | Ajoute une règle d'intégrité entre deux fichiers sur le serveur. |
| [HAjouteUtilisateur](3044281.md) | Ajoute un utilisateur (connexion HFSQL Client/Serveur) |
| [HArrêteServeur](3044317.md) | Arrête un serveur HFSQL. Pour réaliser cette action, l'utilisateur doit posséder les droits d'actions sur le serveur. |
| [HChangeRepJNL](3044164.md) | Modifie l'emplacement des fichiers du journal correspondant à un fichier de données HFSQL. (fichier *JNL et fichiers JournalOperation et JournalIdentification s'ils existent). |
| [HCopieFichier](3044282.md) | Effectue une copie d'un fichier de données HFSQL du Client vers le serveur et inversement |
| [HCréation](3044255.md) | Crée à vide un fichier de données (fichier d'extension ".FIC") avec le fichier d'index et le fichier mémo si nécessaire. |
| [HCréationSiInexistant](3044254.md) | La fonction **HCréationSiInexistant** effectue les opérations suivantes :  - Si le fichier n'existe pas, crée à vide un fichier de données (fichier d'extension ".FIC") avec le fichier d'index et le fichier mémo si nécessaire.   La fonction est équivalente à [HCréation](3044255.md). - Si le fichier existe, ouvre le fichier.   La fonction est alors équivalente à [HOuvre](3044120.md).   Pour optimiser l'appel à la fonction **HCréationSiInexistant**, l'ouverture du fichier peut être également réalisée uniquement au premier accès réalisé sur le fichier. |
| [HDBCréation](3044171.md) | Termine la description dynamique de la structure du fichier. Le fichier qui vient d'être décrit est créé sur le disque dans le chemin indiqué dans [HDBDécritFichier](3044172.md). Les fichiers de données, mémos et d'index sont créés sur le disque. |
| [HEcrit](3044092.md) | Écrit un enregistrement dans le fichier de données sans mettre à jour les index correspondants à toutes les clés utilisées dans le fichier. |
| [HImporteHF55](3044055.md) | Importe un fichier Hyper File 5.5 dans un fichier au format HFSQL Classic. |
| [HImporteTexte](3044011.md) | Importe un fichier Texte dans un fichier au format HFSQL Classic. |
| [HImporteXML](3044007.md) | Importe un fichier XML dans un fichier au format HFSQL Classic. |
| [HLibère](3044064.md) | Transforme les enregistrements rayés (HRaye) d'un fichier en enregistrements supprimés. La place occupée par les enregistrements rayés est ainsi libérée, et pourra être réutilisée lors des prochains ajout (HAjoute). |
| [HMigreCléComposéeReliée](3044038.md) | Migre les valeurs des clés composées reliées provenant d'un fichier au format Hyper File 5.5 vers le format HFSQL Classic. |
| [HModifie](3044042.md) | Modifie l'enregistrement spécifié ou l'enregistrement présent en mémoire dans le fichier de données (la requête ou la vue). |
| [HModifieDroitBaseDeDonnées](3044326.md) | Modifie les droits donnés à un utilisateur ou à un groupe pour une base de données HFSQL Client/Serveur. |
| [HModifieDroitFichier](3044327.md) | Modifie les droits accordés sur un fichier de données HFSQL Client/Serveur pour un utilisateur ou un groupe. |
| [HModifieDroitServeur](3044328.md) | Modifie les droits accordés sur un serveur HFSQL pour un utilisateur ou un groupe. |
| [HModifieGroupe](3044308.md) | Modifie les informations du groupe spécifié en fonction des informations de la structure. |
| [HModifiePropriétéBaseDeDonnées](3044329.md) | Modifie les propriétés d'une base de données située sur un serveur HFSQL. |
| [HModifiePropriétéFichier](3044330.md) | Modifie les propriétés d'un fichier de données HFSQL situé sur un serveur. |
| [HModifiePropriétéServeur](3044331.md) | Modifie les propriétés d'un serveur HFSQL. |
| [HModifieUtilisateur](3044309.md) | Modifie les informations de l'utilisateur spécifié en fonction des informations de la structure. |
| [HRaye](3044121.md) | Raye un enregistrement d'un fichier. L'enregistrement est supprimé logiquement et pourra éventuellement être récupéré. |
| [HRegénèreFichier](3044122.md) | Régénère un fichier à partir de son journal. |
| [HSupprime](3044018.md) | Supprime un enregistrement d'un fichier (d'une requête ou d'une vue). |
| [HSupprimeBaseDeDonnées](3044332.md) | Supprime une base de données présente sur un serveur HFSQL. Toutes les connexions utilisant la base de données supprimée sont fermées. |
| [HSupprimeFichier](3044294.md) | Supprime les fichiers de données HFSQL (fichier .fic, .ndx et .mmo s'ils existent) sur le serveur. |
| [HSupprimeGroupe](3044295.md) | Supprime un groupe d'utilisateurs associé à une connexion, sur le serveur. |
| [HSupprimeLiaison](3044314.md) | Supprime une règle d'intégrité entre deux fichiers sur le serveur. |
| [HSupprimeUtilisateur](3044296.md) | Supprime un utilisateur associé à une connexion sur le serveur. |
| [HVueVersFichier](3044021.md) | Enregistre les modifications réalisées dans une vue (grâce aux fonctions [HModifie](3044042.md), [HSupprime](3044018.md) ou [HRaye](3044121.md)) dans le fichier correspondant. |
