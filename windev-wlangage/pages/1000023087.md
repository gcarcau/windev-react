# Société (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **Société** permet de connaître et de modifier la société associée à un élément. Cette propriété est disponible sur :

- les variables de type [gglContact](1000017434.md).
- les variables de type [docPropriété](1000022945.md).
- les variables de type [adminWBCompte](1410089382.md).
