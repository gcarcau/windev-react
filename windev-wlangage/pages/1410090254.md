# EditeurCodeInsère (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur)

Insère une chaîne de caractères dans le champ Editeur de code.
Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.

## Exemple

```wlangage
// Insère un commentaire avec la date du jour au début du code
sCommentaire est chaîne = "// le " + DateSys() + RC
EditeurCodeInsère(EDCODE_Exemple, 1, sCommentaire)
```

## Syntaxe

```wlangage
EditeurCodeInsère(<Champ Editeur de code> , <Position> , <Texte>)
```

`<Champ Editeur de code>` *Nom de champ*
> Nom du champ Editeur de code à manipuler.
`<Position>` *Entier*
> Positon d'insertion par rapport au début du code.
`<Texte>` *Chaîne de caractères*
> Texte à insérer.

**Classification Métier / UI : Code UI**

**Composante : wd300obj.dll**
