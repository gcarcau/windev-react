# <Variable mongoCollection>.Cherche (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Cherche des documents dans une collection MongoDB.

## Exemple

```wlangage
CollecMDB est un mongoCollection
sFiltre est une chaîne
sFiltre = "{ ""name"": ""France"" }"
soit MaRecherche = CollecMDB.Cherche(sFiltre)
// Lecture du résultat
POUR TOUT item DE MaRecherche
	Trace(VariantVersJSON(item))
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Collection>.Cherche(<Filtre> [, <Option>])
```

`<Résultat>` *Variable de type mongoRésultat*
> Variable de type [mongoRésultat](1000022415.md) correspondant au résultat de la recherche. En cas de problème, la fonction [ErreurInfo](3013008.md) permet d'identifier l'erreur.
`<Collection>` *Variable de type mongoCollection*
> Nom de la variable de type [mongoCollection](1000022411.md) correspondant à la collection MongoDB dans laquelle la recherche doit être effectuée.
`<Filtre>` *Type correspondant au filtre utilisé*
> Description du/des filtres au format MongoDB à appliquer pour effectuer la recherche. Ce filtre correspond à :
>
> - un document au format JSON, sous forme de chaîne de caractères.
> - un document au format BSON, sous forme de buffer.
> - un variant.
`<Option>` *Variable optionnelle de type mongoChercheOption*
> Nom de la variable de type [mongoChercheOption](1000022414.md) correspondant aux options de recherche.
