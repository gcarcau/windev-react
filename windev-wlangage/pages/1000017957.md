# Libellé (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **Libellé** permet de connaître et de modifier le libellé d'un élément. Cette propriété est utilisable sur :

- les champs, les fenêtres, les pages et les états. Pour plus de détails, consultez [Libellé](2510053.md).
- une variable de type [gglAdressePostale](1000017575.md).
- une variable de type [gglContact](1000017434.md).
- une variable de type [gglEmail](1000017571.md).
- une variable de type [gglEvénement](1000017440.md).
- une variable de type [gglLieu](1000017441.md).
- une variable de type [gglMessagerieInstantanée](1000017569.md).
- une variable de type [gglPersonne](1000017446.md).
- une variable de type [gglSociété](1000017756.md).
- une variable de type [gglTéléphone](1000017573.md).
- une variable de type [inAppProduit](1000020868.md).
- une variable de type [pdfSignature](1000022255.md).
- une variable de type [Jeton](1000023942.md).
- une variable de type [MarqueurImage](1000025796.md).
- une variable de type [diagTexte](1410088393.md).
- une variable de type [sysNotificationBouton](1410087947.md).
- une variable de type [sysNotificationEntrée](1410088024.md).
- une variable de type [SaisieAssistée](1410088983.md).
- une variable de type [ActionRapide](1410090054.md).
- Nouveauté 2025
   une variable de type [pdfOptionChamp](1410090533.md).
