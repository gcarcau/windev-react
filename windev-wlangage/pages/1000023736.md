# <Tableur>.SelectFeuille (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Sélectionne une feuille de calcul (identifiée par son nom) dans un champ Tableur.

## Exemple

```wlangage
// Bouton [Aller sur Feuille]
TBLR_MonTableur.SelectFeuille(SAI_NomFeuille_A_Sélectionner)
SI ErreurDétectée = Vrai ALORS
	Erreur(ErreurInfo())
SINON
	LIB_MaFeuille = TBLR_MonTableur.FeuilleEnCours
FIN
```

## Syntaxe

```wlangage
<Champ Tableur>.SelectFeuille(<Feuille>)
```

`<Champ Tableur>` *Nom de champ*
> Nom du champ Tableur à manipuler.
`<Feuille>` *Chaîne de caractères*
> Nom de la feuille de calcul à sélectionner.

## Remarques

- L'indice de la feuille en cours est disponible via la propriété [FeuilleEncours](1000021640.md).
- Le nom de la feuille en cours est connu via la propriété [NomFeuille](1000021646.md).
- Si la feuille n'existe pas, la fonction lève une erreur non fatale : la variable [ErreurDétectée](3087001.md) est à Vrai et la fonction [ErreurInfo](3013008.md) permet de connaître la cause de l'erreur.
- Cette fonction est utilisable uniquement sur un champ Tableur présent dans une fenêtre.
