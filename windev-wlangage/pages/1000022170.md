# RTFAvecImagesEtTableaux (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes) · **WEBDEV** (Windows)

La propriété **RTFAvecImagesEtTableaux** permet de gérer la prise en charge des images et tableaux dans un champ Libellé de type RTF présent dans un état.

## Exemple

```wlangage
// Activer la prise en charge des images et tableaux
// dans le RTF du champ LIB_Descriptif
LIB_Descriptif.RTFAvecImagesEtTableaux = Vrai
```

## Syntaxe

#### Connaître le mode de gestion des images et tableaux en RTF

```wlangage
<Résultat> = <Champ Libellé>.RTFAvecImagesEtTableaux
```

`<Résultat>` *Booléen*
> - Vrai si les images et tableaux sont gérées dans le champ Libellé de type RTF,
> - Faux dans le cas contraire.
`<Champ Libellé>` *Nom de champ*
> Nom du champ Libellé à manipuler. Ce champ est présent dans un état.

#### Modifier le mode de gestion des images et tableaux en RTF

```wlangage
<Champ Libellé>.RTFAvecImagesEtTableaux = <Nouveau mode>
```

`<Champ Libellé>` *Nom de champ*
> Nom du champ Libellé à manipuler. Ce champ est présent dans un état.
`<Nouveau mode>` *Booléen*
> - Vrai pour gérer les images et tableaux dans le champ Libellé de type RTF,
> - Faux dans le cas contraire.

## Remarques

- Cette propriété permet de changer le mode de gestion des images et des tableaux pour un champ. Il est également possible de modifier globalement ce mode de gestion (c'est-à-dire pour tous les champs) en utilisant la fonction [iParamètre](3046008.md) avec la constante *iRTFAvecImagesEtTableaux*.
- La fonction [iParamètre](3046008.md) utilisée avec la constante *iRTFAvecImagesEtTableaux* est prioritaire sur la propriété **RTFAvecImagesEtTableaux**. La propriété **RTFAvecImagesEtTableaux** est donc ignorée si la fonction [iParamètre](3046008.md) est appelée avec la constante *iRTFAvecImagesEtTableaux*.
