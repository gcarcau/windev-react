# <Variable Connexion>.ListeTâche (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Liste les tâches planifiées d'un serveur HFSQL Client/Serveur pour une connexion donnée.

## Syntaxe

```wlangage
<Résultat> = <Connexion>.ListeTâche()
```

`<Résultat>` *Chaîne de caractères*
> Liste des tâches planifiées disponibles sur le serveur sous la forme :
>
>
> ```wlangage
> <Identifiant de la tâche 1> + TAB + <Description de la tâche 1> + TAB + ...<Tâche 1 active ou non> + TAB + <Utilisateur> + TAB + <Mois> + TAB + ...<Jour du mois> + TAB + <Jour de la semaine> + TAB + <Heure> + TAB + ...<Minute> + TAB + <Jour du mois ou jour de la semaine> + TAB + ...<Nombre exécution> + TAB + <Nom de la procédure> + EOT + ...
> ```
>
>
>
> **Remarque** : Pour obtenir les caractéristiques d'une tâche, utilisez la fonction [<Variable Connexion>.InfoTâche](1000022686.md).
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle les tâches planifiées doivent être listées.

## Remarques

- Pour lister les tâches des autres utilisateurs, il est nécessaire de posséder le droit de visualisation des utilisateurs (constante *hDroitVisualisationUtilisateur* dans les fonctions [<Variable Connexion>.InfoDroitServeur](1000022668.md) et [<Variable Connexion>.ModifieDroitServeur](1000022710.md)).
- Pour lister les tâches planifiées, il est nécessaire de posséder le droit de connexion (constante *hDroitConnexion* ou *hDroitConnexionCryptée*) sur la base contenant la procédure stockée.
- Il est possible d'utiliser la fonction **<Variable Connexion>.ListeTâche** pour vérifier l'existence d'une tâche. Il suffit de vérifier si l'identifiant de la tâche est présent parmi les tâches renvoyées par la fonction.
