# <Source>.JournalRedémarre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Redémarre la journalisation du fichier de données. Cette journalisation a été arrêtée grâce à la fonction [<Source>.JournalStop](1000025008.md).

## Exemple

```wlangage
Client.JournalInfo("début impression de " + Critère)
Client.JournalStop() // Stopper le journal
Client.LitPremier(Critère)
TANTQUE Client.Trouve()
	// Traitement
	Client.LitSuivant()
FIN
Client.JournalRedémarre() // Redémarrer le journal
Client.JournalInfo("fin impression de" + Critère) // Ecrire
```

## Syntaxe

```wlangage
<Résultat> = <Source>.JournalRedémarre()
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Source>` *Type correspondant à la source spécifiée*
> Nom du fichier de données journalé dont la journalisation doit redémarrer.

## Remarques

- Lors du redémarrage du journal, le fichier de données doit être dans son état initial, c'est-à-dire l'état dans lequel il était avant l'utilisation de la fonction [<Source>.JournalStop](1000025008.md).
- Entre les fonctions [<Source>.JournalStop](1000025008.md) et **<Source>.JournalRedémarre**, les informations ne seront pas sauvegardées dans le journal.
- La fonction **<Source>.JournalRedémarre** est équivalente à l'utilisation de la fonction [<Source>.GèreJournal](1000024986.md) avec le paramètre Vrai.
