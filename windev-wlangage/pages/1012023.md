# Propriétés associées à une page

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

## Présentation

Une page peut être manipulée par les propriétés WLangage en code serveur, navigateur ou en PHP.

## Les propriétés disponibles

| [Alias](2510004.md) | La propriété **Alias** permet de :   - connaître ou de modifier l'alias d'une fenêtre (WINDEV et WINDEV Mobile). - connaître ou de modifier l'alias d'un volet d'onglet dynamique (WINDEV). - connaître le nom interne HTML / Javascript d'un champ (WEBDEV). |
| --- | --- |
| [CouleurFond](2510022.md) | La propriété **CouleurFond** permet de gérer la couleur de fond d'un champ, d'une fenêtre, d'une page ou d'un bloc d'un état. |
| [CurseurSouris](2510026.md) | La propriété **CurseurSouris** permet de connaître et de modifier le curseur de survol défini pour un champ, une fenêtre ou une page. |
| [Description](1000017164.md) | La propriété **Description** permet de connaître et modifier la description associée à la page. |
| [Extra](1410089327.md) | La propriété **Extra** permet de :  - Connaître les informations supplémentaires associées à un champ, à une fenêtre, ou à une page. - Modifier les informations supplémentaires associées à un champ, à une fenêtre ou à une page. _(WEBDEV - Code Navigateur)_ En code navigateur, il est uniquement possible de connaître les informations supplémentaires associées à un champ ou une page. |
| [FichierParcouru](2510040.md) | La propriété **FichierParcouru** permet de connaître et de modifier la source de données utilisée pour l'affichage des enregistrements dans les champs basés sur un fichier de données. |
| [HTMLEntête](1000020178.md) | La propriété **HTMLEntête** permet de connaître et de modifier le code HTML ajouté dans l'entête de la page. |
| [HTMLFinPage](1000020177.md) | La propriété **HTMLFinPage** permet de connaître et de modifier le code HTML ajouté à la fin de la page. |
| [ImageFond](2510056.md) | La propriété **ImageFond** permet de connaître et de modifier l'image de fond d'un élément : fenêtre, page, champ ou état. |
| [Libellé](2510053.md) | **Dans une base de données**, la propriété **Libellé** permet de :  - Connaître le libellé associé à une rubrique d'un fichier de données. - Connaître le libellé associé à un fichier de données. - Connaître et modifier le libellé d'une connexion.   **Dans un état**, la propriété **Libellé** permet de :   - Connaître le texte d'un champ Libellé ou Lien. - Modifier le texte d'un champ Libellé ou Lien.   **Dans une fenêtre ou une page**, la propriété **Libellé** permet également de :   - Connaître et modifier le libellé d'un champ présent dans une fenêtre ou une page. - Connaître et modifier le libellé d'une option de menu. - Connaître et modifier le titre d'une fenêtre ou d'une page. - Connaître le contenu d'un champ chemin de navigation. |
| [LibelléHTML](1000020922.md) | La propriété **LibelléHTML** permet de manipuler le libellé d'un champ sous forme de code HTML. |
| [MenuContextuel](2510077.md) | La propriété **MenuContextuel** permet de :  - Connaître le menu contextuel personnalisé associé à un champ, à une fenêtre ou une page. - Modifier le menu contextuel personnalisé associé à un champ, une fenêtre ou une page (associer un autre menu contextuel au champ, à la fenêtre ou à la page). - Personnaliser les menus système des champs en ajoutant des options. |
| [MotsClés](1000017163.md) | La propriété **MotsClés** permet de connaître et modifier les mots-clés associés à une page. |
| [Nom](2510082.md) | La propriété **Nom** permet de connaître :  - le nom de la police associée à une variable de type Police. - le nom d'un champ, d'un état ou d'un bloc d'un état. - le nom d'un champ, d'un groupe de champs ou d'une fenêtre. - le nom d'un champ, d'un groupe de champs ou d'une page. |
| [NomComplet](2514005.md) | La propriété **NomComplet** permet de connaître le nom complet :  - d'un champ. - d'une fenêtre. - d'une option de menu. - d'une colonne de table. |
| [Note](2510085.md) | La propriété **Note** permet de :  - Connaître les notes associées à un champ, à une fenêtre, à une page ou un état. - Modifier les notes associées à un champ, à une fenêtre, à une page ou un état. |
| [Plan](2510094.md) | La propriété **Plan** permet de :  - Connaître :   - le plan actif d'une fenêtre (ou d'un état) ou le plan auquel appartient un champ.  - le plan actif d'un élément WEBDEV. - Modifier :   - le plan actif d'une fenêtre (ou d'un état) ou associer un champ à un autre plan.  - le plan actif d'un élément WEBDEV. |
| [RubriqueParcourue](2510111.md) | La propriété **RubriqueParcourue** permet de :  - Connaître la rubrique utilisée pour le parcours automatique des champs Table, Zone répétée, Liste (y compris Liste image), Combo, état sur fichier ou des superchamps. - Modifier la rubrique utilisée pour le parcours automatique des champs Table, Zone répétée, Liste (y compris Liste image), Combo, état sur fichier ou des superchamps. Le parcours est alors réinitialisé. |
| [Titre](2510090.md) | La propriété **Titre** permet de :  - Connaître le titre d'une colonne d'un champ Table, d'un champ Graphe, d'une fenêtre ou d'une page - Modifier le titre d'une colonne d'un champ Table, d'un champ Graphe, d'une fenêtre ou d'une page. |
| [TitreNote](2510121.md) | La propriété **TitreNote** permet de :  - Connaître le titre des notes utilisé pour la documentation technique d'un champ, d'une fenêtre, d'une page ou d'un état. - Modifier le titre des notes utilisé pour la documentation technique d'un champ, d'une fenêtre, d'une page ou d'un état. |
| [Traitement](1000020878.md) | La propriété **Traitement** permet de modifier les traitements à exécuter par les événements disponibles sur un champ, une fenêtre, une page, un état, ... |
| [Type](2510131.md) | La propriété **Type** permet de connaître :  - le type d'un élément décrit par programmation (description de rubrique ou de fichier) ou non (fichier ou rubrique défini sous l'éditeur d'analyses, vue ou requête). - le type d'un objet. - le type de la valeur stockée dans un variant. |
| [Valeur](2510130.md) | La propriété **Valeur** permet de :  - Connaître et modifier la valeur d'un champ d'un état. - Connaître et modifier la valeur d'un champ ou le titre d'une fenêtre. - Connaître l'identifiant d'un flux. - Connaître et modifier la valeur d'un champ ou le titre d'une page. |
| [ValeurInitiale](2510128.md) | La propriété **ValeurInitiale** permet de connaître la valeur initiale d'un champ d'une fenêtre ou d'une page. |
| [ValeurRenvoyée](2510134.md) | La propriété **ValeurRenvoyée** permet de :  - Connaître et modifier la valeur renvoyée par une fenêtre, une page ou un état. - Connaître et modifier la valeur renvoyée par une option d'un champ Sélecteur. |
