# Structure HClient

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

## Présentation

La structure **HClient** permet de gérer :

- la déconnexion d'un ou de plusieurs postes Client (fonction [HDéconnecteClient](3044339.md))
- l'envoi d'un message à un ou plusieurs postes Client (fonction [HEnvoieMessageVersClient](3044346.md))

## Détail de la structure HClient

### Variables de la structure
Les variables suivantes permettent de gérer les postes Client :

| HClient.Application | Chaîne de caractères. Nom de l'application.  Ce nom est renvoyé par la fonction [HListeUtilisateurConnecté](3044291.md). |
| --- | --- |
| HClient.Base | Chaîne de caractères. Base de données HFSQL Client/Serveur. |
| HClient.Fichier | Chaîne de caractères. Fichier de données. |
| HClient.Login | Chaîne de caractères Login de l'utilisateur. |
| HClient.Machine | Chaîne de caractères. Machine de l'utilisateur : Nom de la machine ou adresse IP de la machine. |

Les fonctions utilisant cette structure agiront sur les connexions dont l'utilisateur a le login **HClient.Login** et qui sont effectuées par une application **HClient.Application**. Cette application est lancée sur la machine **HClient.Machine** et utilise le fichier de données **HClient.Fichier** de la base de données **HClient.Base**.

Chaque variable de la structure peut prendre pour valeur "" (chaîne vide) qui signifie "n'importe quelle valeur".

## Fonctions utilisant la structure HClient

Les fonctions utilisant la structure **HClient** sont les suivantes :

| [HDéconnecteClient](3044339.md) | Affiche un message sur le(s) poste(s) Client et déconnecte l'application. |
| --- | --- |
| [HEnvoieMessageVersClient](3044346.md) | Affiche un message sur le(s) poste(s) Client. |
| [HRAZClient](3044341.md) | Initialise la structure de gestion des postes Client (structure [HClient](3044340.md)). |
