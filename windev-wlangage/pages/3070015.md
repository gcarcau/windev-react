# SocketFerme (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Ferme un socket ou une connexion à un socket d'un serveur.
**Attention** : Il est nécessaire de fermer la connexion pour que le socket serveur prenne connaissance d'un message en mode de lecture bloquant.

**Rappel** : Un socket est une ressource de communication utilisée par les applications pour communiquer d'une machine à une autre sans se soucier du type de réseau.

## Exemple

```wlangage
SI SocketCrée("Serveur", 8000) = Faux ALORS
	Erreur("Erreur création " + ErreurInfo(errMessage))
SINON
	...
	SocketFerme("Serveur")
FIN
```

## Syntaxe

```wlangage
SocketFerme(<Nom du socket>)
```

`<Nom du socket>` *Chaîne de caractères*
> Nom du socket qui a reçu le message.
> **Dans des applications WINDEV, ce nom a été défini sur le serveur** :
>
>
> - soit par la fonction [SocketCrée](3070011.md), [SocketCréeSSL](1000017041.md) ou [SocketCréeInfraRouge](3070012.md) (cas d'un serveur simplifié),
> - soit par la fonction [SocketAccepte](3070004.md) (cas d'un serveur standard).
>
>
> **Dans des applications WINDEV, ce nom a été défini sur le client** par la fonction [SocketConnecte](3070016.md), [SocketConnecteSSL](1000017042.md) ou [SocketConnecteInfraRouge](3070018.md).

## Remarques

> _(Android, Widget Android)_ Permissions requisesL'utilisation de cette fonction entraîne la modification des permissions requises par l'application. Permission requise : INTERNET Cette permission autorise l'application à ouvrir des sockets réseau.
