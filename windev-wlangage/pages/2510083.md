# NombreColonne (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

La propriété **NombreColonne** permet de :

- Connaître le nombre de colonnes présentes dans :
  - un champ Liste multicolonne.
  - un champ Table ou Table hiérarchique.
  - un champ Zone répétée.
  - un champ Sélecteur.
  - un champ Interrupteur.
  - un champ Tableau croisé dynamique.
  - un champ Combo Table.
  - un champ Tableau de Bord.
  - un champ Tableur.
- Modifier le nombre de colonnes présentes :
  - dans un champ Liste multicolonne. Le nombre de colonnes d'un champ Liste multicolonne ne peut pas être inférieur à 2.
  - dans un champ Zone répétée.

> _(WINDEV)_ Rappel : Pour rendre un champ Liste multicolonne (champ Liste ou champ Liste image affiché en mode classique) :Affichez la fenêtre de description du champ (option "Description" du menu contextuel du champ).Dans l'onglet "Détail", saisissez le nombre de colonnes voulu dans l'option "Nombre de colonnes".

## Exemple

```wlangage
// --Traitement de modification de taille de la fenêtre
// Si la largeur de la fenêtre est modifiée :
// - la largeur du champ Liste est modifiée
LISTE_MaListe.Largeur = MaFenêtre.Largeur - 30
// - le nombre de colonnes présentes dans le champ Liste est modifié
// selon la nouvelle largeur de la fenêtre
LISTE_MaListe.NombreColonne = LISTE_MaListe.Largeur/50
```

## Syntaxe

#### Connaître le nombre de colonnes d'un champ

```wlangage
<Nombre de colonnes> = <Champ manipulé>.NombreColonne
```

`<Nombre de colonnes>` *Entier*
> - Nombre de colonnes présentes dans le champ Liste multicolonne spécifié.
> - Nombre de colonnes présentes dans le champ Table spécifié.
> - Nombre de colonnes présentes dans le champ Interrupteur ou Sélecteur spécifié.
> - Nombre de colonnes présentes dans le champ Tableau croisé dynamique spécifié.
> - Nombre de colonnes présentes dans le champ Combo Table spécifié.
> - Nombre de cellules en largeur présentes dans le champ Tableau de bord spécifié.
> - Nombre maximum de colonnes ayant des données (valeur ou formule) dans un champ Tableur.
> - Nombre de colonnes présentes dans le champ Zone répétée spécifié.
> - 1 si l'élément spécifié ne correspond pas à un champ pouvant être traité.
`<Champ manipulé>` *Nom de champ*
> Nom du champ dont on veut connaître le nombre de colonnes.

> _(WINDEV, WINDEV)_ Modifier le nombre de colonnes présentes dans un champ Masquer les détails
<Champ manipulé>.NombreColonne = <Nombre de colonnes>

 <Champ manipulé> : Nom de champNom du champ à manipuler : Champ Liste multicolonne Champ Zone répétée. <Nombre de colonnes> : EntierNouveau nombre de colonnes. Pour les listes, ce nombre doit être supérieur à 1 (il n'est pas possible de transformer un champ Liste multicolonne en liste standard ou inversement).

## Remarques

### Limites
La propriété **NombreColonne** s'applique uniquement aux :

- Champs Liste multicolonne (champs Liste image affichés en mode classique).
- Champs Table ou Table hiérarchique.
- Champs Sélecteur.
- Champs Interrupteur.
- Champs Tableau croisé dynamique.
- Champs Combo Table.
- Champs Tableau de bord.
- Champs Tableur.
- Champs Zone répétée.

> _(Java)_ La propriété NombreColonne s'applique uniquement aux éléments suivants :Champs Interrupteur.Champs Sélecteur.Champs Table.

> _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur, PHP)_ La propriété NombreColonne s'applique uniquement aux : Champs Interrupteur.Champs Sélecteur.Champs Table.Champs Table hiérarchique.Champs Zone répétée.Champs Tableau de bord.Remarque : Dans une page en mode Responsive Web Design, la propriété NombreColonne ne tient pas compte de la surcharge du nombre de colonnes par tranche.
