# DécomplèteRep (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Enlève le caractère '/' ou '\' à la fin d'une chaîne si ce caractère est présent.
Cette fonction est utile pour la manipulation de noms de fichiers complets en cas d'incertitude sur le format du chemin (par exemple si l'utilisateur saisit un chemin de fichier).

Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Android, Widget Android, Java, Code Utilisateur (MCU), PHP, Ajax)_ Res = DécomplèteRep("c:\temp\") // Renvoie "c:\temp"
Res = DécomplèteRep("c:\temp") // Renvoie "c:\temp"
Res = DécomplèteRep("\\CCS\Rep2\User\") // Renvoie "\\CCS\Rep2\User"
Res = DécomplèteRep("/root/file/") // Renvoie "/root/file"
Res = DécomplèteRep("") // Renvoie ""

## Syntaxe

```wlangage
<Résultat> = DécomplèteRep(<Chaîne à vérifier>)
```

`<Résultat>` *Chaîne de caractères*
> - Chaîne de caractères <Chaîne à vérifier> non terminée par le caractère '\' ou '/',
> - Chaîne vide ("") si le paramètre <Chaîne à vérifier> correspond à une chaîne vide ("").
`<Chaîne à vérifier>` *Chaîne de caractères*
> Chaîne de caractères à vérifier.

## Remarques

### Espaces
**Attention** : Les espaces avant et après <Chaîne à vérifier> sont supprimés (identique à la fonction [SansEspace](3024034.md)).

### Fonction DécomplèteRep et Unicode
Si la chaîne passée en paramètre est au format ANSI, le résultat sera au format ANSI.
Si la chaîne passée en paramètre est au format Unicode, le résultat sera au format Unicode.

**Remarque** : Si le résultat de la fonction **DécomplèteRep** utilisée sur une chaîne ANSI est affecté à une chaîne Unicode (et inversement), la conversion ANSI/Unicode sera implicitement réalisée.

Pour plus de détails, consultez [Gestion de l'Unicode](3024038.md).
