# TypeMIME (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **TypeMIME** permet de connaître et de modifier le type MIME d'un élément. Cette propriété est utilisable sur :

- une variable de type [nfcDonnée](1000020406.md).
- une variable de type [upnpImage](1000020905.md).
- une variable de type [gglDocument](1000018001.md).
- une variable de type [gglPièceJointe](1000026182.md).
- une variable de type [FichierGgl](1410089586.md).
