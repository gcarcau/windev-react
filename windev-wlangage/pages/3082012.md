# zipTaille (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie la taille de l'archive (au format ZIP, RAR, CAB, WDZ, 7z, gzip, TAR ou TGZ (TAR.GZ)) :

- soit la taille de l'ensemble des fichiers compressés présents dans l'archive.
- soit la taille de l'ensemble des fichiers avant compression présents dans l'archive.

Lors de l'extraction des fichiers, il est conseillé de calculer la taille de l'ensemble des fichiers avant compression (présents dans l'archive) pour vérifier si l'espace disque disponible est suffisant.

Rappel :

- Seules les archives au format ZIP, gzip, TAR et TGZ (TAR.GZ) sont disponibles.
- Seules les archives au format ZIP sont disponibles.

Nouveauté 2025

> _(WINDEV, WEBDEV - Code Serveur, Windows, Linux, iPhone/iPad)_ Le format gzip (extension .gz) est désormais géré.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ MonArchive est une zipArchive

// Ouverture d'une archive
ResOuvreArchive = zipOuvre(MonArchive, "C:\MesArchives\Archive.zip")

// Taille de l'archive ouverte
SI ResOuvreArchive = 0 ALORS
 ResTailleArchive = zipTaille(MonArchive)
 ...
FIN

## Syntaxe

```wlangage
<Résultat> = zipTaille(<Archive> [, <Type de taille>])
```

`<Résultat>` *Entier*
> Taille de l'archive.
`<Archive>` *Chaîne de caractères ou variable de type zipArchive*
> Nom de l'archive à manipuler.
> Ce nom peut correspondre :
>
> - soit au nom d'une archive défini avec la fonction [zipOuvre](3082044.md) ou [zipCrée](3082003.md).
> - soit au nom d'une variable de type [zipArchive](1000018679.md).
>    Les variables de type [zipArchive](1000018679.md) ne sont pas disponibles en JAVA.
`<Type de taille>` *Booléen optionnel*
> Type de calcul de la taille de l'archive :
>
> - Vrai : Taille de l'ensemble des fichiers compressés présents dans l'archive.
> - Faux (valeur par défaut) : Taille de l'ensemble des fichiers avant compression présents dans l'archive.
