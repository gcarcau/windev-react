# diagActionAutorisée (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Le type **diagActionAutorisée** permet de définir tous les droits de l'utilisateur final sur une forme d'un diagramme présent dans le champ Editeur de diagrammes. Les caractéristiques de ces droits peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
Attention : Ce type de variable peut être utilisé uniquement sur les variables dérivant du type [diagForme](1410088082.md) :

- Variable de type [diagChemin](1410088384.md),
- Variable de type [diagGroupe](1410088127.md),
- Variable de type [diagImage](1410088414.md),
- Variable de type [diagLien](1410088454.md),
- Variable de type [diagOvale](1410088135.md),
- Variable de type [diagPolygone](1410088137.md),
- Variable de type [diagRectangle](1410088083.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Définition des droits sur une forme de type Image
fond est un diagImage
fond.Image = "fond.png"
fond.ActionAutorisée.Déplacer = Faux
fond.ActionAutorisée.Redimensionner = Faux
fond.ActionAutorisée.Rotation = Faux
x est un Diagramme <- EDIAG_SansNom1
x.Forme.Ajoute(fond)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type diagActionAutorisée
Les propriétés suivantes peuvent être utilisées pour manipuler une action autorisée sur une forme :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Altitude | Booléen | - Vrai pour autoriser le changement d'altitude de la forme, - Faux pour l'interdire. |
| ChangerProportion | Booléen | Si la propriété **Redimensionner** vaut Vrai :   - Vrai pour autoriser le changement de la hauteur et de la largeur de la forme indépendamment, - Faux pour l'interdire. |
| Copier | Booléen | - Vrai pour autoriser la copie et la duplication d'une forme, - Faux pour l'interdire. |
| Déplacer | Booléen | - Vrai pour autoriser le déplacement d'une forme, - Faux pour l'interdire. |
| EditerLibellé | Booléen | - Vrai pour autoriser l'édition du libellé d'une forme, - Faux pour l'interdire. |
| EditerStyle | Booléen | - Vrai pour autoriser le changement de style d'une forme (couleur, cadre, police, ...), - Faux pour l'interdire. |
| PointDAttache | Booléen | - Vrai pour autoriser le changement des points d'attache d'une forme (liens uniquement), - Faux pour l'interdire. |
| PointDePassage | Booléen | - Vrai pour autoriser le changement, l'ajoute et la suppression de points d'attache d'une forme (liens uniquement), - Faux pour l'interdire. |
| Redimensionner | Booléen | - Vrai pour autoriser le changement de taille d'une forme, - Faux pour l'interdire. |
| Rotation | Booléen | - Vrai pour autoriser de faire tourner une forme, - Faux pour l'interdire. |
| Sélectionner | Booléen | - Vrai pour autoriser la sélection d'une forme, - Faux pour l'interdire. |
| Supprimer | Booléen | - Vrai pour autoriser la suppression d'une forme, - Faux pour l'interdire. |
