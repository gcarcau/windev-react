# NomComplet (Propriété)

> **Disponible :** **WINDEV** (Windows, Java) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **NomComplet** permet de connaître le nom complet :

- d'un champ.
- d'une fenêtre.
- d'une option de menu.
- d'une colonne de table.

## Exemple

> _(WINDEV, iPhone/iPad, Widget IOS, Java)_ Info("Le nom complet du champ est " + SAI_Saisie1.NomComplet)
// Affiche "Le nom complet du champ est FEN_Fenêtre1.SAI_Saisie1"

> _(WEBDEV - Code Serveur)_ Trace("Le nom complet du champ est " + SAI_Saisie1.NomComplet)
// Affiche "Le nom complet du champ est PAGE_Page1.SAI_Saisie1"

> _(WINDEV, Android, iPhone/iPad, Widget IOS, Java)_ Info("Le nom complet du champ est " + COL_Colonne1.NomComplet)
// Affiche "Le nom complet du champ est FEN_Fenêtre1.TABLE_Table1.COL_Colonne1"

## Syntaxe

#### Connaître le nom complet de l'élément spécifié

```wlangage
<Résultat> = <Elément manipulé>.NomComplet
```

`<Résultat>` *Chaîne de caractères*
> - Nom complet de l'élément spécifié.
> - Chaîne vide ("") pour :
>   - les lignes des champs Table, Liste, Liste image ou Combo,
>   - les cellules des champs Table.
`<Elément manipulé>` *Chaîne de caractères*
> Nom de l'élément à manipuler.

## Remarques

> _(Widget Android)_ La propriété NomComplet s'applique uniquement aux éléments suivants :Champ Bouton.Champ Libellé.Champ Image.Fenêtre.
