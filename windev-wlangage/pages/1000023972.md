# SectionCritique (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

Les variables de type **SectionCritique** permettent de définir des sections critiques afin de limiter l'exécution simultanée d'un code (procédure, ligne de code, ...) **à un thread** à un instant donné dans une seule application.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Déclaration
//----------------
S est un SectionCritique

// Utilisation pour un bloc de code
//---------------------------
using S DANS
	// code protégé par la section critique
	// un seul thread pourra exécuter ce code à un moment donné
FIN
```

## Remarques

- Le type **SectionCritique** permet de simplifier la déclaration des sections critiques.
- Les variables de type **SectionCritique** respectent les règles de portée de variables.
- La protection d'un bloc de code par une section critique est réalisable grâce à la syntaxe [UTILISER ... DANS](1510025.md).
