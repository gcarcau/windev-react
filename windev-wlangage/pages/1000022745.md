# <Variable Connexion>.OpérationEncours (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Renvoie la liste des opérations automatiques en cours sur un serveur HFSQL.

## Exemple

```wlangage
// Description de la connexionMaConnexion est une Connexion // Liste de toutes les opérations en courstabOp est un tableau dynamique de hOpérationServeur tabOp = MaConnexion.OpérationEncours()
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.OpérationEncours()
```

`<Résultat>` *Tableau de hOpérationServeur*
> Tableau de variables de type [hOpérationServeur](1000022471.md) contenant la description de toutes les opérations en cours sur le serveur HFSQL.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion à une base de données.

**Composante : wd300hf.dll**
