# 64 bits natif et 32 bits natif : un code source unique

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows)

## Présentation

Les ordinateurs récents sont désormais équipés par défaut de systèmes d'exploitation "64 bits", que ce soient des machines de type serveur ou des machines de bureau.
La principale différence entre un système "32 bits" et un système "64 bits" est la suivante : en "64 bits", les applications et le système ne sont plus limités au niveau de l'allocation mémoire.

En effet, en "32 bits", le système d'exploitation est limité à 4 Go de mémoire, et en "64 bits", il n'y a quasiment plus de limite (la limite théorique est à 18 milliards de Gigas).

Pour vous aider à développer des sites et des applications 64 bits, WINDEV et WEBDEV proposent :

- Un framework disponible en 32 et 64 bits
- Le serveur d'application WEBDEV disponible en 32 et 64 bits
- Le serveur HFSQL Client/Serveur disponible en 32 et 64 bits. Pour plus de détails, consultez [HFSQL Client/Serveur](3044306.md).

## Comment le faire ?

> _(WINDEV, Windows)_ Pour créer une application 64 bitsDéveloppez votre application 64 bits. Il est possible de transformer une application 32 bits en application 64 bits.Déployez votre application.

> _(WEBDEV - Code Serveur)_ Pour installer un site WEBDEV sur un serveur 64 bitsInstallez un serveur d'application WEBDEV 64 bits sur un serveur Web 64 bits.Développez et déployez votre site WEBDEV sur le serveur Web. Remarque : Un site compilé en 64 bits peut être utilisé avec un serveur 32 bits ou 64 bits. Un serveur 64 bits ne peut afficher que des sites 64 bits. Si le site n'a pas été compilé avec l'option "64 bits", une erreur s'affichera au lancement du site.
