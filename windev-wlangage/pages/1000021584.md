# géoSuiviDésactive (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Désactive le suivi des positions utilisateur pour une application WINDEV Mobile.

## Exemple

```wlangage
géoSuiviDésactive()
```

## Syntaxe

```wlangage
géoSuiviDésactive()
```
