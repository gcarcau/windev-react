# <Carte>.ModifieImage (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Modifie une image dessinée sur la carte affichée dans un champ Carte.

## Exemple

```wlangage
// Modifie la largeur d'une image affiché dans le champ Carte
MonImage est un CarteImage

MonImage.Largeur = 100
CARTE_MaCarte.ModifieImage(MonImage)
```

## Syntaxe

```wlangage
<Résultat> = <Champ Carte>.ModifieImage(<Image>)
```

`<Résultat>` *Booléen*
> - Vrai si l'image a pu être modifiée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler.
`<Image>` *Variable de type CarteImage*
> Nom de la variable de type [CarteImage](1000025523.md) correspondant à l'image à modifier.

## Remarques

- L'image doit avoir été ajoutée dans le champ Carte pour pouvoir être modifiée.
- Pour ajouter une nouvelle image à dessiner dans le champ Carte, utilisez la fonction [<Carte>.AjouteImage](1000025802.md).
- Pour supprimer une image dessinée dans le champ Carte, utilisez la fonction [<Carte>.SupprimeImage](1000025829.md).
