# Fonctions de dessin et de traitement des images

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de dessin et de traitement des images (syntaxe préfixée)](1000024243.md)).
Attention : Pour connaître les pré-requis nécessaires pour dessiner selon les différentes plateformes utilisées, consultez [Dessiner en WINDEV, WEBDEV et WINDEV Mobile](3029035.md).

Les différentes fonctions de dessin sont les suivantes :
