# <Arbre>.SelectMoins (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Dé-sélectionne un élément dans un champ Arbre.
Exemple de champ Arbre :
[image: Vocabulaire lié à un champ Arbre]

## Exemple

```wlangage
// Désélectionne le noeud "Desserts" dans le champ Arbre "ARBRE_RecetteTV"
Res = ARBRE_RecetteTV.SelectMoins("Recettes" + TAB + "Desserts")
```

## Syntaxe

```wlangage
<Résultat> = <Champ Arbre>.SelectMoins(<Chemin de l'élément>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément a été désélectionné,
> - Faux si l'élément spécifié n'existe pas.
`<Champ Arbre>` *Nom de champ*
> Nom du champ Arbre à manipuler.
`<Chemin de l'élément>` *Chaîne de caractères optionnelle*
> Chemin complet de l'élément à manipuler. Ce paramètre est de la forme :
>
>
> ```wlangage
> "<Nom de la racine>" + TAB + ["<Nom du 1er noeud>" + TAB + ...["<Nom du 2ème noeud>" + TAB + [...]]]"<Nom de la feuille>"
> ```
>
>
> En cas de doublons sur un élément du chemin, ce chemin peut contenir l'identifiant de l'élément (indiqué à la suite du nom grâce à la fonction [ArbreID](3018027.md)).
> Si ce paramètre est spécifié, l'élément spécifié est désélectionné.
>
> Si ce paramètre n'est pas spécifié, l'élément en cours est désélectionné.

## Remarques

### Arbre multisélection
Dans le cas d'un champ multisélection :

- si le paramètre <Chemin de l'élément> est spécifié, seul l'élément spécifié est désélectionné.
- si le paramètre <Chemin de l'élément> n'est pas spécifié, tous les éléments sélectionnés sont désélectionnés.
