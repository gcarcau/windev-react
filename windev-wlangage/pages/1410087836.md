# ScanRécupère (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Récupère les caractéristiques d'un scanneur dans une variable de type [Scanneur](1410087808.md). Cette variable pourra ensuite être utilisée pour effectuer des opérations de scan.
Remarque : Pour connaître l'ensemble des scanneurs connectés au poste en cours, utilisez la fonction [ScanListe](1410087807.md).

## Exemple

```wlangage
// Récupérer les caractéristiques d'un scanneur
MonScanneur est un Scanneur
MonScanneur = ScanRécupère("hp scanjet 5590")
```

## Syntaxe

```wlangage
<Résultat> = ScanRécupère(<Nom du scanneur>)
```

`<Résultat>` *Variable de type Scanneur*
> Variable de type [Scanneur](1410087808.md) initialisée avec les informations du scanneur <Nom du scanneur>.
> En cas d'erreur, la variable [ErreurDétectée](3087001.md) vaut Vrai et le message d'erreur correspondant peut être connu avec la fonction [ErreurInfo](3013008.md).
`<Nom du scanneur>` *Chaîne de caractères*
> Nom du scanneur dont les caractéristiques doivent être récupérées. Ce nom doit correspondre à un des noms renvoyés par la fonction [ScanListe](1410087807.md).

**Classification Métier / UI : Code UI**

**Composante : wd300std.dll**
