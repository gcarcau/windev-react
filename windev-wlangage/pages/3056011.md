# NetDéconnecte (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **Autres** (Procédures stockées)

Déconnecte d'un serveur FTP (File Transfer Protocol) ou RPC (Remote Procedure Call) réalisé avec WINDEV.

## Exemple

```wlangage
ConnectRPC est un entier
ConnectRPC = NetConnecte("148.61.125.245", ServeurRPC, "GUEST", "")
...
NetDéconnecte(ConnectRPC)
```

## Syntaxe

```wlangage
NetDéconnecte(<Identifiant de la connexion>)
```

`<Identifiant de la connexion>` *Entier*
> Identifiant de la connexion à déconnecter (obtenu par la fonction [NetConnecte](3056004.md)).

**Classification Métier / UI : Code métier**

**Composante : wd300com.dll**
