# JetonActif (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

La propriété **JetonActif** permet de savoir si un champ de saisie est un champ de saisie de type "Jetons de texte".

## Exemple

```wlangage
SI SAI_Email.JetonActif = Vrai ALORS
	SAI_Email.JetonListeSéparateur = ";.:" + TAB
FIN
```

## Syntaxe

#### Savoir si le champ de saisie est de type "Jetons de texte"

```wlangage
<Résultat> = <Champ de saisie>.JetonActif
```

`<Résultat>` *Booléen*
> - Vrai si le champ de saisie est de type "Jetons de texte",
> - Faux dans le cas contraire.
`<Champ de saisie>` *Nom de champ*
> Nom du champ de saisie manipulé.

## Remarques

Si la propriété **JetonActif** est à Vrai, lorsque l'utilisateur frappe un caractère séparateur ou un retour chariot (RC), un jeton est automatiquement ajouté et la saisie continue dans le champ.
Un jeton est une zone de texte encadrée qui permet à l'utilisateur d'identifier les différents éléments d'un saisie multiple. Par exemple, les jetons permettent d'identifier facilement les différents destinataires d'un email.

La valeur renvoyée ou mémorisée par un champ de saisie de type "Jetons de texte" est une chaîne séparée par RC.
Par exemple : paul@mail1.com<RC>mar@mail2.fr

Les séparateurs qui déclenchent la création de nouveaux jetons durant la saisie sont définis par la propriété [JetonListeSéparateur](1000023783.md).

La gestion des doublons est paramétrée par la propriété [JetonAutoriseDoublon](1000023784.md).

Il est possible d'obtenir une saisie assistée sur les jetons valides avec la fonction [SaisieAssistéeAjoute](1000020043.md).
