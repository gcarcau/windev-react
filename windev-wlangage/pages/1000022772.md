# <Variable Connexion>.VérifieMiseAJourServeur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Vérifie s'il existe une version plus récente du serveur HFSQL pouvant être mise à jour automatiquement.

## Exemple

```wlangage
MaConnexion est une Connexion

soit sNouvelleVersion = MaConnexion.VérifieMiseAJourServeur()
SI  sNouvelleVersion<>"" ALORS Info(sNouvelleVersion)
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.VérifieMiseAJourServeur()
```

`<Résultat>` *Chaîne de caractères*
> Version de la mise à jour disponible sur le serveur HFSQL.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion au serveur HFSQL.

## Remarques

Le serveur de mise à jour (contenant le pack de mise à jour du serveur HFSQL) peut être défini par la fonction [<Variable Connexion>.GèreMiseAJourServeur](1000022662.md).

**Composante : wd300hf.dll**
