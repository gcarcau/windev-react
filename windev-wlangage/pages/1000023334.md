# TableurRestaurePositionEtSélection (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Restaure :

- la position de l'ascenseur d'un champ Tableur,
- la feuille en cours,
- le ou les éléments sélectionnés dans la feuille en cours du champ Tableur.

Ces éléments ont été précédemment sauvegardés par la fonction [TableurSauvePositionEtSélection](1000023333.md).

## Exemple

```wlangage
soit MaSauvegarde = TableurSauvePositionEtSélection(TBLR_Tableur1)

// Met en gras la cellule B1
TableurSelectPlus(TBLR_Tableur, "B1")
TableurStyleSélection(TBLR_Tableur, tblrGras, Vrai)

// Restaure la position/sélection
TableurRestaurePositionEtSélection(TBLR_Tableur1, MaSauvegarde)
```

## Syntaxe

```wlangage
TableurRestaurePositionEtSélection(<Champ Tableur> [, <Sauvegarde>])
```

`<Champ Tableur>` *Nom de champ*
> Nom du champ Tableur à manipuler.
`<Sauvegarde>` *Chaîne de caractères optionnelle*
> Caractéristiques de la sauvegarde renvoyées par la fonction [TableurSauvePositionEtSélection](1000023333.md).
>
> - Si ce paramètre n'est pas précisé, la dernière sauvegarde réalisée par [TableurSauvePositionEtSélection](1000023333.md) sur le champ est utilisée (si elle existe).
> - Si aucune sauvegarde n'a été réalisée précédemment ou si la chaîne spécifiée est invalide, une erreur est affichée.

## Remarques

### Cas particuliers

- Le nom du champ utilisé pour la sauvegarde (fonction [TableurSauvePositionEtSélection](1000023333.md)) peut être différent de celui utilisé pour la restauration. Cette fonctionnalité peut être utile pour dupliquer la position et la sélection sur deux champs Tableur affichés alternativement par exemple.
- Si le champ est vide, la fonction **TableurRestaurePositionEtSélection** n'a aucun effet.
