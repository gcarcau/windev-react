# JourDuMois (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (iPhone/iPad)

La propriété **JourDuMois** permet de connaître et de modifier le numéro du jour du mois pour lequel la tâche planifiée doit être exécutée.
Cette propriété est utilisable sur :

- une variable de type [hTâchePlanifiée](1000017448.md).
- une variable de type [hPlanification](1000018853.md).
- une variable de type [Répétition](1000019262.md).
- une variable de type [serveurAppliTâchePlanifiée](1000022367.md).
