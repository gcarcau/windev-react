# Environnement général de WINDEV

> **Disponible :** **WINDEV** (Windows, Linux, Java)

Les éléments importants de l'environnement général de WINDEV sont les suivants :

|  | **Ruban** Permet un accès rapide aux principales fonctionnalités de WINDEV. Ce ruban est composé de volets, de groupes et d'options. Pour plus de détails, consultez [Un menu sous forme de ruban](9000149.md). |
| --- | --- |
|  | **Tableau de bord du projet** Regroupe les principaux accès aux différents éléments du projet. |
|  | **Espace de travail** Affiche les fenêtres des différents éditeurs (fenêtre de code, fenêtres ou états en création, analyse, etc.) |
|  | [**Volets ancrables**](2027001.md) Affiche par exemple les éléments (fenêtres, états, champs, etc.) disponibles dans le projet en cours ([volet "Explorateur de projet"](2027029.md)). |
|  | **[Documents ouverts](2029012.md)** Affiche un bouton pour chaque document ouvert sous l'éditeur. Pour afficher l'élément voulu au premier plan, il suffit de cliquer sur le "bouton" correspondant. |
|  | **[Volets ancrables](2027001.md)** Volets permettant de :   - afficher les erreurs de compilation (erreurs présentes dans le code WLangage, [volet "Erreurs de compilation"](2027031.md)). - effectuer des recherches ([volet "Rechercher - Remplacer"](2027013.md)). - afficher le débogueur lors du test d'un élément ([volet "Débogueur"](2027030.md)). - ... |
