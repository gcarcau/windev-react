# URLRedirection (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **URLRedirection** permet de connaître l'URL utilisée pour la redirection du résultat. Cette propriété est utilisée par :

- une variable de type [OAuth2Paramètres](1000022212.md).
- une variable de type [OpenIDParamètres](1000023561.md).
