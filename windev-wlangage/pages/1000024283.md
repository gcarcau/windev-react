# <Table>.SauvePositionEtSélection (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Sauve :

- la position de l'ascenseur d'un champ Table ou d'un champ Table hiérarchique,
- le ou les éléments sélectionnés dans le champ.

Ces éléments peuvent être restaurés par la fonction [<Table>.RestaurePositionEtSélection](1000024280.md).

## Exemple

```wlangage
SauveTable est une chaîne
SauveTable = TABLE_Table1.SauvePositionEtSélection()
TABLE_Table1.Affiche(taInit)
TABLE_Table1.RestaurePositionEtSélection(SauveTable)
```

## Syntaxe

```wlangage
<Résultat> = <Champ Table>.SauvePositionEtSélection()
```

`<Résultat>` *Chaîne de caractères*
> - Informations qui seront transmises à la fonction [<Table>.RestaurePositionEtSélection](1000024280.md).
> - Chaîne vide ("") si le champ Table est vide.
`<Champ Table>` *Nom de champ*
> Nom du champ Table ou Table hiérarchique à manipuler.

## Remarques

### Conditions d'utilisation
La fonction **<Table>.SauvePositionEtSélection** peut être utilisée indifféremment sur :

- un champ Table ou Table hiérarchique fichier.
- un champ Table ou Table hiérarchique par programmation.
- un champ monosélection ou multisélection.

### Equivalence
Les fonctions **<Table>.SauvePositionEtSélection** et [<Table>.RestaurePositionEtSélection](1000024280.md) sont équivalentes à l'option "Mémoriser la position et la sélection" disponible dans l'onglet "Détail" de la description du champ Table.

### Limitation
La fonction **<Table>.SauvePositionEtSélection** ne fonctionne pas sur les champs Table fichier à rebond (c'est-à-dire sans ascenseur proportionnel).
