# TypeContenu (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **TypeContenu** permet de connaître et définir le contenu d'un élément. Cette propriété peut être utilisée :

- sur une variable de type [CodeBarres](1000019451.md).
- sur une variable de type [mongoGridFSInfoFichier](1000022417.md).
