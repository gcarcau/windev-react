# HMigreCléComposéeReliée (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Migre les valeurs des clés composées reliées provenant d'un fichier de données au format Hyper File 5.5 vers le format HFSQL Classic.

| **Quand utiliser cette fonction ?** Le format des clés composées a changé entre Hyper File 5.5 et HFSQL Classic (monoposte ou réseau).  Conséquence : la valeur des clés reliées correspondant à une clé composée n'est plus correcte après migration des fichiers de données du format Hyper File 5.5 au format HFSQL Classic. La fonction **HMigreCléComposéeReliée** permet de modifier la valeur des clés reliées et de retrouver la valeur de la clé composée dans la clé reliée.  **Conditions d'utilisation**  Cette fonction doit être utilisée :   - uniquement avec des fichiers de données au format HFSQL Classic (fichier de données au format 5.5 migré au format Classic), - une seule fois par clé à migrer, - juste après la migration de Hyper File 5.5 vers HFSQL Classic. En effet, si des enregistrements sont ajoutés entre la migration et l'utilisation de la fonction **HMigreCléComposéeReliée**, les valeurs des nouveaux enregistrements pourront être corrompues. |
| --- |

## Exemple

```wlangage
// Modifier les valeurs de la clé COMMANDE.CLECOMPCLIENT
HMigreCléComposéeReliée(CLIENT, CLECOMP, COMMANDE, CLECOMPCLIENT)
```

## Syntaxe

```wlangage
<Résultat> = HMigreCléComposéeReliée(<Fichier de données source de la liaison> , <Clé composée source> , <Fichier de données relié> , <Clé reliée> [, <Jauge>])
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été effectuée,
> - Faux en cas de problème. La fonction [HErreur](3044088.md) permet d'obtenir plus de détails sur le problème rencontré.
`<Fichier de données source de la liaison>` *Chaîne de caractères*
> Nom du fichier de données source de la liaison, contenant la description de la clé composée.
`<Clé composée source>` *Chaîne de caractères*
> Nom de la rubrique de type "Clé composée" dans le fichier de données source de la liaison.
`<Fichier de données relié>` *Chaîne de caractères*
> Nom du fichier de données relié contenant la valeur de la clé composée à migrer.
`<Clé reliée>` *Chaîne de caractères*
> Nom de la rubrique de clé dans le fichier de données relié. La valeur de cette rubrique doit être migrée.
`<Jauge>` *Nom de fenêtre ou nom de champ optionnel*
> Nom du champ de type Jauge ou nom de la fenêtre permettant de visualiser la progression de la migration.
