# dEfface (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Efface le contenu d'une variable de type [Image](1000019650.md) ou d'un champ Image avec la couleur spécifiée.

## Exemple

```wlangage
dDébutDessin(IMG_Dessin)
// Dessin d'un rectangle dont le fond est jaune clair et le bord bleu clair
dRectangle(10, 10, 50, 50, JauneClair, BleuClair)
// Efface le dessin avec la couleur bleue
dEfface(BleuClair)
```

## Syntaxe

#### Effacer avec la couleur spécifiée dans l'image en cours

```wlangage
dEfface([<Couleur>])
```

`<Couleur>` *Constante ou Variable de type Couleur optionnelle*
> Couleur utilisée pour effacer. Cette couleur peut correspondre à :
>
> - une des constantes WLangage de couleur,
> - une variable de type [Couleur](1000019661.md).
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - une couleur prédéfinie (voir [les couleurs prédéfinies du WLangage](3010002.md)).
>
> Si ce paramètre n'est pas précisé, l'état initial de l'image sera appliqué :
>
> - transparent pour une variable de type [Image](1000019650.md),
> - couleur du fond de la fenêtre pour un champ Image.

#### Effacer avec la couleur spécifiée dans le champ Image ou dans la variable de type Image

```wlangage
dEfface(<Image> [, <Couleur>])
```

`<Image>` *Nom de champ ou variable de type Image*
> Nom du champ Image ou de la variable de type [Image](1000019650.md) à manipuler.
`<Couleur>` *Constante ou Variable de type Couleur optionnelle*
> Couleur utilisée pour effacer. Cette couleur peut correspondre à :
>
> - une des constantes WLangage de couleur,
> - une variable de type [Couleur](1000019661.md).
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - une couleur prédéfinie (voir [les couleurs prédéfinies du WLangage](3010002.md)).
>
> Si ce paramètre n'est pas précisé, l'état initial de l'image sera appliqué :
>
> - transparent pour une variable de type [Image](1000019650.md),
> - couleur du fond de la fenêtre pour un champ Image.

## Remarques

### Gestion de l'opacité

- Si le dessin a été activé dans le champ sans l'option d'opacité (fonction [dDébutDessin](3029009.md) sans la constante *dAvecOpacité*) :
  - Sous Windows, la fonction **dEfface** utilisée avec une couleur ne prendra pas en compte l'opacité.
  - Sous Linux, seules les couleurs dont l'opacité est maximum seront utilisables.
- Si le dessin a été activé dans le champ avec l'option d'opacité (fonction [dDébutDessin](3029009.md) avec la constante *dAvecOpacité*), la fonction **dEfface** utilisée avec une couleur prendra en compte l'opacité.
