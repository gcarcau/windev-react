# CarteSupprimeForme (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Supprime une forme dessinée sur la carte affichée dans un champ Carte.

## Exemple

```wlangage
// Suppression d'une forme
CarteSupprimeForme(CARTE_MaCarte, MaForme)
```

## Syntaxe

#### Supprimer une forme via la variable associée

```wlangage
<Résultat> = CarteSupprimeForme(<Champ Carte> [, <Forme>])
```

`<Résultat>` *Booléen*
> - Vrai si la forme a pu être supprimée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler. Si ce paramètre correspond à une chaîne vide (""), le champ Carte auquel appartient l'événement en cours sera utilisé.
`<Forme>` *Variable de type CarteCercle, CartePolygone ou CartePolyligne*
> Forme à supprimer sur la carte affichée dans le champ Carte. Cette forme est décrite à l'aide d'un des types de variables suivants :
>
> - une variable de type [CartePolygone](1000025476.md),
> - une variable de type [CartePolyligne](1000025489.md),
> - une variable de type [CarteCercle](1000025504.md).
>
> Si ce paramètre n'est pas spécifié, toutes les formes présentes sur la carte seront supprimées.

#### Supprimer une forme à partir de son nom

```wlangage
<Résultat> = CarteSupprimeForme(<Champ Carte> , <Identifiant de la forme>)
```

`<Résultat>` *Booléen*
> - Vrai si la forme a pu être supprimée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Carte>` *Chaîne de caractères*
> Nom du champ Carte à manipuler. Si ce paramètre correspond à une chaîne vide (""), le champ Carte auquel appartient l'événement en cours sera utilisé.
`<Identifiant de la forme>` *Chaîne de caractères*
> Identifiant de la forme à supprimer. Cet identifiant correspond à la propriété **Nom** de la variable associée à la forme. Si ce paramètre n'est pas spécifié, toutes les formes présentes sur la carte seront supprimées.

## Remarques

- Pour ajouter une nouvelle forme à dessiner dans un champ Carte, utilisez la fonction [CarteAjouteForme](1000025509.md).
- Pour modifier une forme dessinée dans un champ Carte, utilisez la fonction [CarteModifieForme](1000025511.md).
