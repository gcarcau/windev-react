# Menu contextuel système

> **Disponible :** **WINDEV** (Windows, Java) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Les menus contextuels système sont gérés par le système (Android, Windows, ...). Ces menus contextuels s'affichent sur certains types de champs (ActiveX, ...).

## Les menus contextuels système par défaut

Certains types de champs peuvent avoir un menu contextuel système. Ce menu contextuel peut correspondre :

- ***soit au menu contextuel affiché par Windows***. C'est le cas par exemple pour les menus contextuels des champs ActiveX, multimédia ou HTML :
  - un champ HTML : Remarque : Le menu contextuel système affiché est celui d'Internet Explorer. Il dépend de l'objet sélectionné dans la page (image, texte, lien, ...).
  - un champ ActiveX : Remarque : Le menu contextuel système affiché dépend de l'ActiveX associé au champ.
- ***soit au menu contextuel des FAA géré par WINDEV***.
  - un champ de saisie :
  - un champ Table : Pour plus de détails, consultez [Menu contextuel d'un champ Table](1013207.md).

Le menu contextuel des FAA peut être configuré (par exemple pour afficher uniquement certaines options) et traduit. Pour plus de détails, consultez [Configurer le menu contextuel des FAA](2010040.md).
