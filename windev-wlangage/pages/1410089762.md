# docElémentInterrupteur (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux)

Le type **docElémentInterrupteur** permet de définir toutes les caractéristiques avancées d'un interrupteur utilisable pour la création d'un formulaire. Les caractéristiques de cet interrupteur peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
Pour manipuler les interrupteurs, la variable de type **docElémentInterrupteur** doit être instanciée via l'opérateur **<-** avec la propriété **Champ** de la variable de type [docElément](1000022484.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Insertion d'une case à cocher cochée
o est un docElément
o.Type = typeDocElémentChampInterrupteur
CheckBox est un docElémentInterrupteur <- o..Champ
CheckBox.Coché = Vrai
DocInsère(MonDoc, 2, o)

// Insertion d'une case à cocher décochée
o2 est un docElément
o2.Type = typeDocElémentChampInterrupteur
CheckBox2 est un docElémentInterrupteur <- o2..Champ
CheckBox2.Coché = Faux
DocInsère(MonDoc, 23, o2)
```

```wlangage
// Ouvre un fichier docx dans le champ Traitement de texte
TT_MonDoc = DocOuvre(fRepExe() + fSep() + "MonDoc.docx")
MonDoc est un Document = TT_MonDoc
// Parcours les paragraphes pour trouver les interrupteurs
sElement est une chaîne
sParagraphe est une chaîne
sValeur,sDebut,sFin,sType sont des chaînes
POUR TOUT MonPara DE MonDoc.Paragraphe
	sParagraphe = sParagraphe + [RC] + sElement
	sElement = ""
	POUR TOUT MonElement DE MonPara.Elément
		sDebut = MonElement.PositionDébut
		sFin = MonElement.PositionFin
		SELON MonElement.Type
			CAS typeDocElémentChampInterrupteur
			sType = "Case à cocher"
			CheckBox est un docElémentInterrupteur <- MonElement..Champ
			sValeur = CheckBox.Coché
		FIN
		sElement = sElement + [RC] + sValeur + TAB + sDebut + TAB + sFin + TAB + sType
	FIN
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type docElémentInterrupteur
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **docElémentInterrupteur** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| CaractCoché | Chaîne de caractères | Caractère Unicode utilisé pour afficher la représentation d'un interrupteur coché. |
| CaractDécoché | Chaîne de caractères | Caractère Unicode utilisé pour afficher la représentation d'un interrupteur décoché. |
| Coché | Booléen | Etat de l'interrupteur :   - Vrai si l'interrupteur est coché, - Faux dans le cas contraire. |
| FontCaractCoché | Chaîne de caractères | Nom de la police (font) utilisée pour représenter le caractère coché. |
| FontCaractDécoché | Chaîne de caractères | Nom de la police (font) utilisée pour représenter le caractère décoché. |

Attention : seules les cases à cocher les plus récentes sont gérées (les cases à cocher "legacy" ne sont pas supportées).
