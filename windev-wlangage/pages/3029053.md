# dModifieSaturation (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Modifie la saturation d'une image contenue :

- dans un champ Image,
- dans une variable de type [Image](1000019650.md).
   Ce type de variable n'est pas disponible.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Dessiner en WINDEV, WEBDEV et WINDEV Mobile.

## Exemple

```wlangage
// Change la saturation de l'image contenue dans le champ IMG_Image1
dModifieSaturation(IMG_Image1, 50)
```

## Syntaxe

```wlangage
<Résultat> = dModifieSaturation(<Image d'origine> , <Variation de saturation> [, <Image destination>])
```

`<Résultat>` *Booléen*
> - Vrai si le changement a été effectué,
> - Faux dans le cas contraire.
`<Image d'origine>` *Chaîne de caractères ou variable de type Image*
> Image à manipuler. Cette image peut correspondre :
>
> - au nom d'un champ Image.
> - au nom d'une variable de type [Image](1000019650.md).
>    Ce type de variable n'est pas disponible.
`<Variation de saturation>` *Entier*
> Valeur comprise entre -100 et +100. Cette valeur sera ajoutée à la saturation actuelle de chaque pixel pour obtenir une nouvelle saturation.
`<Image destination>` *Chaîne de caractères optionnelle ou variable de type Image*
> Image dans laquelle l'image transformée sera dessinée. Cette image peut correspondre :
>
> - au nom d'un champ Image.
> - au nom d'une variable de type [Image](1000019650.md).
>    Ce type de variable n'est pas disponible.
>
>
> Si ce paramètre n'est pas spécifié, la transformation s'effectuera sur l'<Image d'origine>.
