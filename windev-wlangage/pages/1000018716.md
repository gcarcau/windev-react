# Confidentialité (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Confidentialité** permet de connaître et de modifier le niveau de confidentialité d'un email.
Cette propriété est utilisable sur :

- la structure [Email](3032029.md).
- une variable de type [Email](1000018713.md).
