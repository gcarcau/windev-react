# RendezVousModifie (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Modifie le rendez-vous en cours :

- dans l'agenda d'une messagerie Lotus Notes ou Outlook.
  Lors de la lecture d'un rendez-vous, les données de ce rendez-vous sont mis à jour dans la [structure RendezVous](1000011010.md). Pour modifier le rendez-vous en cours, il suffit de modifier les valeurs de la [structure RendezVous](1000011010.md) et de valider les modifications avec la fonction **RendezVousModifie**.
  **Rappel** : Cette fonction ne permet pas de modifier le rendez-vous en cours dans l'agenda d'une messagerie Outlook Express.
- dans un calendrier (ou agenda) d'un appareil Android.
- dans un calendrier (ou agenda) d'un appareil iOS.

## Exemple

```wlangage
// Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", ...
	"mail/julie.nsf", "C:\Lotus Notes\julie.id")
// Lecture du dernier rendez-vous
RendezVousDernier(IDSession)
// Modification du lieu
mRendezVous.Lieu = "Salle 5H"
RendezVousModifie(IDSession)
```

> _(Android, Widget Android, iPhone/iPad)_ // Rendez-vous à modifier
gRDV est un RendezVous
// ...

// Modification du rendez-vous
gRDV.Titre = SAI_Titre
gRDV.DateDébut = SAI_DateDeb + SAI_HeureDeb
gRDV.DateFin = SAI_DateFin + SAI_HeureFin
gRDV.Lieu = SAI_Lieu
gRDV.Contenu = SAI_Desc
SI SAI_Fuseau <> "" ALORS
 gRDV.FuseauHoraire = SAI_Fuseau
FIN
gRDV.Auteur = SAI_Auteur
gRDV.Invité = SAI_Invités
gRDV.JournéeEntière = INT_Jentière[1]

SI RendezVousModifie(gRDV) ALORS
 ToastAffiche("RDV modifié")
SINON
 Erreur(ErreurInfo())
FIN

## Syntaxe

#### Modifier un rendez-vous dans l'agenda d'une messagerie Lotus Notes ou Outlook

```wlangage
<Résultat> = RendezVousModifie(<Identifiant de la session> [, <Identifiant du rendez-vous>])
```

`<Résultat>` *Booléen*
> - Vrai si la modification a été effectuée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Identifiant de la session>` *Entier*
> Identifiant de la session à utiliser. Cet identifiant est renvoyé par une des fonctions suivantes : [EmailOuvreSessionNotes](3032121.md), [EmailOuvreSessionOutlook](3032128.md), [NotesOuvreBase](1000005101.md) ou [OutlookOuvreSession](3032123.md).
`<Identifiant du rendez-vous>` *Chaîne de caractères optionnelle*
> Identifiant du rendez-vous à modifier. Cet identifiant est contenu dans la variable mRendezVous.ID.

> _(Android, Widget Android, iPhone/iPad)_ Modifier un rendez-vous dans un calendrier (ou agenda) d'un appareil mobile (Android/iOS) Masquer les détails
<Résultat> = RendezVousModifie(<Rendez-vous>)

 <Résultat> : BooléenVrai si la modification a été effectuée, Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction ErreurInfo. <Rendez-vous> : Variable de type RendezVousNom de la variable de type RendezVous correspondant au rendez-vous à modifier dans le calendrier de l'appareil Android/iOS.

## Remarques

> _(WINDEV, WEBDEV - Code Serveur)_ Outlook : Mode de gestion des contacts/participantsSous Outlook, il est possible de spécifier le mode de gestion des contacts/participants lors de l'ouverture de la session (fonction EmailOuvreSessionOutlook ou fonction OutlookOuvreSession).

> _(Android, Widget Android)_ Agenda Android : RemarquesLa fonction RendezVousModifie peut être utilisée dans l'émulateur mais pas dans le simulateur.
