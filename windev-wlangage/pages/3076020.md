# telErreur (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Indique si la dernière fonction telxxx ([fonctions de gestion des appels téléphoniques](3076005.md)) a renvoyé une erreur dans le module TAPI. Cette fonction est particulièrement utile dans le cas des fonctions ne renvoyant pas Vrai ou Faux comme résultat.

## Exemple

```wlangage
SI telNuméroAppelé() = "" ALORS
	SI telErreur() = Vrai ALORS
		Erreur(ErreurInfo(errMessage))
	FIN
FIN
```

## Syntaxe

```wlangage
<Résultat> = telErreur()
```

`<Résultat>` *Booléen*
> - Faux si aucune erreur n'est survenue lors de l'utilisation d'une fonction de téléphonie,
> - Vrai en cas d'erreur. Le libellé ou le code de l'erreur TAPI peut être connu avec la fonction [ErreurInfo](3013008.md).

**Composante : wd300com.dll**
