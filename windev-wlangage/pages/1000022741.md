# grCouleurBarre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Initialise la couleur d'une barre spécifique sur un graphe de type Histogramme ou Histogramme empilé.

## Exemple

```wlangage
// Change la barre 2 de la série 1grCouleurBarre(GRF_MonHisto, 1, 2, RVB(200,150,45))
```

## Syntaxe

```wlangage
grCouleurBarre(<Nom du graphe> , <Numéro de la série> , <Numéro de la catégorie> , <Couleur>)
```

`<Nom du graphe>` *Nom de champ ou chaîne de caractères*
> Nom du graphe à manipuler. Ce nom peut correspondre :
>
> - au nom du graphe défini par programmation avec la fonction [grCrée](3042005.md).
> - au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.
>
>
> > _(Android)_ Seuls les champs Graphe sont disponibles.
>
> > _(WEBDEV - Code Navigateur, PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Numéro de la série>` *Entier*
> Numéro de la série à manipuler.
`<Numéro de la catégorie>` *Entier*
> Numéro de la catégorie à manipuler.
`<Couleur>` *Entier ou constante de type Entier*
> Couleur de la barre. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie](3010002.md).

## Remarques

- Pour modifier la couleur de toutes les barres d'une catégorie, utilisez la fonction [grCouleurCatégorie](1000020928.md).
- La modification du graphe est automatique. La fonction [grDessine](3042026.md) est inutile.

**Classification Métier / UI : Code neutre**

**Composante : wd300grf.dll**
