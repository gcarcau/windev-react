# Le volet "Messagerie"

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Le volet "Messagerie" permet d'échanger des messages entre les différents collaborateurs de l'entreprise.
Pour plus de détails, consultez [Messagerie](2027023.md).
**Remarque** : Les différents collaborateurs pris en compte pour la messagerie sont les collaborateurs enregistrés dans le groupware développeur et / ou dans les différents Centres de Contrôle. Pour plus de détails, consultez [Base de données des Centres de Contrôle](3540720.md).

## Afficher le volet "Messagerie"

**Pour afficher le volet "Messagerie"**, sous le volet sous le volet "Accueil", dans le groupe "Environnement", déroulez "Volets" et sélectionnez "Volets" puis "Messagerie".
Pour plus de détails sur les manipulations des volets, consultez [Manipuler les volets ancrables](2027001.md).
