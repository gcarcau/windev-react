# Constantes de gestion de la réplication

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

| Constante | Détail | Utilisée par les fonctions |
| --- | --- | --- |
| **rplAbonnéEstAJour** | Information à connaître : Le réplica abonné est à jour ou non | [HInfoRéplica](3044015.md) |
| **rplAbonnéPrioritaire** | Les données présentes dans la base de données abonnée (ou le fichier abonné) sont prioritaires lors de la réplication. | [HSynchroniseRéplica](3044014.md), [HRplGestionFichier](1000017215.md) |
| **rplBidirectionnel** | - Mise à jour de la base de données maître ET de la base de données abonnée. - Mise à jour du fichier maître ET du fichier abonné. | [HSynchroniseRéplica](3044014.md), [HRplGestionFichier](1000017215.md) |
| **rplConflitModification** | Enregistrement a été modifié à la fois sur le réplica source et sur le réplica destination | [HSynchroniseRéplica](3044014.md) |
| **rplConflitSuppression** | Enregistrement supprimé sur le réplica destination et modifié ou supprimé sur le réplica source. | [HSynchroniseRéplica](3044014.md) |
| **rplDateSynchroDepuisAbonné** | Information à connaître : Date de la dernière synchronisation | [HInfoRéplica](3044015.md) |
| **rplDateSynchroDepuisMaître** | Information à connaître : Date de la dernière synchronisation depuis la base maître. | [HInfoRéplica](3044015.md) |
| **rplDateSynchroVersAbonné** | Information à connaître : Date de la dernière synchronisation vers la base abonnée. | [HInfoRéplica](3044015.md) |
| **rplDateSynchroVersMaître** | Information à connaître : Date de la dernière synchronisation vers la base maître. | [HInfoRéplica](3044015.md) |
| **rplGestionConflitRéplication** | Le fichier utilisera le mode de gestion des conflits spécifié avec la fonction HSynchroniseRéplica. | [HRplGestionFichier](1000017215.md) |
| **rplHAjoute** | Réplication d'un ajout | [HSynchroniseRéplica](3044014.md) |
| **rplHModifie** | Réplication d'une modification | [HSynchroniseRéplica](3044014.md) |
| **rplHSupprime** | Réplication d'une suppression | [HSynchroniseRéplica](3044014.md) |
| **rplMaîtreEstAJour** | Information à connaître : Le réplica maître est à jour ou non. | [HInfoRéplica](3044015.md) |
| **rplMaîtrePrioritaire** | Les données présentes dans la base de données maître sont prioritaires lors de la réplication. | [HSynchroniseRéplica](3044014.md) |
| **rplNumRéplicaTransportable** | Information à connaître : Numéro de génération du dernier réplica transportable généré. | [HInfoRéplica](3044015.md) |
| **rplPasDeConflit** | Aucun conflit détecté | [HSynchroniseRéplica](3044014.md) |
| **rplPlusRécentPrioritaire** | Les données les plus récentes sont prioritaires. Attention, les données les plus récentes sont évaluées par rapport à l'heure sur le poste abonné. | [HSynchroniseRéplica](3044014.md) |
| **rplRéplicationDésactivé** | Permet de désactiver temporairement la gestion de la réplication. | [HGèreRéplication](3044067.md) |
| **rplRéplicationHétérogène** | Constante gardée par compatibilité. Cette constante est identique à *rplRéplicationUniverselle*. | [HGèreRéplication](3044067.md) |
| **rplRéplicationJournalisé** | Permet de réaliser une réplication entre des fichiers de données HFSQL (utilise les fichiers de données HFSQL journalés). | [HGèreRéplication](3044067.md) |
| **rplRéplicationUniverselle** | Permet de réaliser une réplication universelle (par exemple entre une base de données HFSQL et une base de données Oracle). | [HGèreRéplication](3044067.md) |
| **rplRubriqueNonRépliquée** | Rubrique non répliquée. | [HRplGestionRubrique](1000017216.md) |
| **rplRubriqueRépliquée** | Rubrique répliquée. | [HRplGestionRubrique](1000017216.md) |
| **rplVersAbonné** | - Mise à jour de la base de données abonnée en fonction de la base de données maître. - Mise à jour du fichier abonné en fonction de la base de données maître. | [HSynchroniseRéplica](3044014.md), [HRplGestionFichier](1000017215.md) |
| **rplVersMaître** | - Mise à jour de la base de données maître en fonction de la base de données abonnée. - Mise à jour du fichier maître en fonction de la base de données abonnée. | [HSynchroniseRéplica](3044014.md), [HRplGestionFichier](1000017215.md) |
