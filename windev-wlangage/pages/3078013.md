# TwainSelectSource (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Affiche une boîte de dialogue standard listant les différents périphériques Twain disponibles sur le poste en cours. L'utilisateur pourra choisir le périphérique Twain à utiliser par défaut. Ce périphérique sera pris en compte pour toutes les fonctions Twain suivantes.
**Remarques** :

- La fonction [TwainSourceEnCours](3078015.md) permet de connaître le périphérique Twain utilisé par défaut par les fonctions Twain.
- En 64 bits, seuls les périphériques ayant un driver 64 bits sont listés.

## Exemple

```wlangage
// Affiche la boîte de dialogue standard listant les différents
// périphériques Twain disponibles sur le poste en cours
SI TwainSelectSource() = Faux ALORS
	Erreur("L'utilisateur n'a pas choisi de périphérique Twain")
FIN
```

## Syntaxe

```wlangage
<Résultat> = TwainSelectSource()
```

`<Résultat>` *Booléen*
> - Vrai si un périphérique Twain a été sélectionné par l'utilisateur,
> - Faux dans le cas contraire. Le message d'erreur correspondant peut être connu avec la fonction [ErreurInfo](3013008.md).

## Remarques

### Changer le périphérique Twain par défaut :
Pour changer le périphérique Twain utilisé par défaut, il est possible :

- soit d'utiliser la fonction [TwainSourceEnCours](3078015.md).
- soit d'afficher la liste des périphériques Twain installés grâce à la fonction **TwainSelectSource**. L'utilisateur pourra alors choisir le périphérique Twain à utiliser par défaut.

### Fonctionnement dans des applications 64 bits
Dans une application 64 bits, cette fonction utilisera automatiquement le driver Twain 64 bits. Si ce driver n'est pas installé, le périphérique TWAIN ne pourra pas être manipulé.

**Composante : wd300std.dll**
