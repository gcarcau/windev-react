# gglMessagerieInstantanée (Type de variable)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Le type **gglMessagerieInstantanée** permet de décrire et de modifier les caractéristiques d'une messagerie instantanée utilisée par un contact.
Ce type de variable est utilisé par le type [gglContact](1000017434.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Connexion à Google
Cnx est une gglConnexion
Cnx.Email = "balthazar@gmail.com"
Cnx.MotDePasse = "azerty"
Cnx.NomApplication = "MonAppli-01"
SI GglConnecte(Cnx) = Faux ALORS
	Erreur(ErreurInfo())
FIN

...

// Récupération du tableau des contacts
tabContacts est un tableau de gglContact
tabContacts = GglListeContact(Cnx)

// Affichage des données de messagerie instantanée du premier contact
MonContact est un gglContact = tabContacts[1]
Mess est une gglMessagerieInstantanée dynamique
POUR TOUT Mess DE MonContact.MessagerieInstantanée
	Trace(Mess.Libellé + " : " + Mess.Adresse)
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type gglMessagerieInstantanée
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **gglMessagerieInstantanée** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Adresse | Chaîne de caractères | Adresse du contact sur le système de messagerie instantanée. |
| Libellé | Chaîne de caractères | Libellé de description de l'adresse. |
| Messagerie | Constante de type Entier | Type de messagerie instantanée concernée. Peut correspondre à une des constantes suivantes :  - *gglMessagerieAIM* : Messagerie AIM - *gglMessagerieGoogleTalk* : Messagerie Google - *gglMessagerieICQ* : Messagerie ICQ - *gglMessagerieJabber* : Messagerie Jabber - *gglMessagerieMSN* : Messagerie MSN - *gglMessagerieQQ* : Messagerie QQ - *gglMessagerieSkype* : Messagerie Skype - *gglMessagerieYahoo* : Messagerie Yahoo |
| Principal | Booléen | - Vrai si l'adresse correspond à l'adresse principale du contact, - Faux dans le cas contraire. |
| Type | Constante de type Entier | Type de l'adresse correspondant à une des variables suivantes :  - *gglAutre* : Adresse ni du domicile ni du travail. - *gglBureau* : Adresse professionnelle. - *gglDomicile* : Adresse du domicile. |
