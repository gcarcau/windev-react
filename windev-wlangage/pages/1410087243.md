# Manipuler un champ Menu contextuel par programmation

> **Disponible :** **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur)

## Présentation

Pour manipuler un champ Menu contextuel par programmation, WEBDEV propose différentes fonctions et propriétés WLangage.
Il est également possible de manipuler le menu ou ses options directement par programmation : il suffit d'utiliser la notation "<Nom de l'option>" si l'option de menu est manipulée depuis la page.

## Manipuler le champ Menu contextuel par programmation

### Associer un menu contextuel à un champ ou une page
L'association d'un menu contextuel à un champ ou une page peut être effectué :

- Sous l'éditeur de pages (via l'option "Menu contextuel" de l'onglet "UI" de la fenêtre de description de l'élément).
- Par programmation :
  - Grâce à la propriété [MenuContextuel](2510077.md).
  - Grâce à la fonction [OuvreMenuContextuel](3025029.md) (code navigateur uniquement).

Remarque : la fonction [ChampContextuel](3025012.md) permet de connaître le nom du champ qui a ouvert le menu contextuel en cours.

### Fonctions WLangage de manipulation des menus et de leurs options
Les fonctions permettant de manipuler un champ Menu contextuel sont les suivantes :

| [MenuAjouteMenu](1000017266.md) | Ajoute un nouveau menu dans un menu existant (déroulant ou contextuel) d'une fenêtre ou d'une page. |
| --- | --- |
| [MenuAjouteOption](1000017262.md) | Ajoute une nouvelle option de menu à la suite de la dernière option d'un menu (déroulant ou contextuel). |
| [MenuAjouteOptionURL](1000018529.md) | Ajoute une nouvelle option de menu à la suite de la dernière option d'un menu (déroulant ou contextuel). Cette option de menu permet d'afficher la page correspondant à l'URL indiquée. |
| [MenuAjoutePopup](1000020583.md) | Transforme une option de menu d'une page pour que cette option ouvre une popup. |
| [MenuAjouteSéparateur](1000017270.md) | Ajoute un nouveau séparateur dans un menu (menu déroulant ou contextuel). |
| [MenuSupprime](3038058.md) | Supprime un menu ou une option de menu. |

### Propriétés WLangage
Les propriétés disponibles sur les options de menu (menus déroulants ou contextuels) sont les suivantes :

| [Cochée](2510019.md) | Permet de gérer une marquedevant l'option de menu. |
| --- | --- |
| [Libellé](2510053.md) | Permet de connaître et de modifier le libellé d'une option de menu. |
| [Nom](2510082.md) | Permet de connaître le nom d'une option de menu. |
| [Sélectionnée](2510112.md) | Permet de savoir si l'option de menu est sélectionnée. |
| [Type](2510131.md) | Permet de savoir si l'élément manipulé est une option de menu. |
| [Visible](2510138.md) | Permet de savoir si une option de menu est visible et de rendre visible / invisible une option de menu. |

Pour connaître la liste complète des propriétés du WLangage pouvant être utilisées avec un champ de type Menu contextuel, consultez [Propriétés associées au champ Menu contextuel](1410087223.md).
