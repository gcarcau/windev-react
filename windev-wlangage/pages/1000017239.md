# ExeDonnePID (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie des informations sur le processus courant.
> _(WEBDEV - Code Serveur)_ Dans le code serveur d'un site dynamique, la fonction ExeDonnePID retourne l'identifiant de la connexion visible dans l'administrateur de WEBDEV (pour plus de détails, consultez Administrateur WEBDEV). Cet identifiant est unique au moment de l'appel et tant que dure la connexion. Il n'est pas unique dans le temps.

> _(iPhone/iPad)_ Cette fonction est désormais disponible pour les applications iPhone/iPad.

## Exemple

```wlangage
// PID de l'application
MonPID est un entier
MonPID = ExeDonnePID()
```

## Syntaxe

```wlangage
<Résultat> = ExeDonnePID([<Information recherchée>])
```

`<Résultat>` *Entier système*
> Information demandée.
`<Information recherchée>` *Constante de type Entier optionnelle*
> Information demandée sur le processus courant :
>
> | *exePID* (valeur par défaut) | PID (Processus Identifier) du processus courant. |
> | --- | --- |
> | *exePIDParent* | PID du parent (c'est-à-dire le processus qui a lancé le processus en cours). _(Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst, Java, PHP)_ Cette constante n'est pas disponible. |
> | *exeTID* | Identificateur du thread courant. _(Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst, Java, PHP)_ Cette constante n'est pas disponible. |
