# StockageLocalDisponible (Fonction)

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur)

Indique si le stockage local est disponible ou non pour le navigateur en cours.

## Exemple

```wlangage
SI StockageLocalDisponible() = Faux ALORS
	Info("Votre navigateur ne permet pas de gérer les contextes navigateur")
FIN
```

## Syntaxe

```wlangage
<Résultat> = StockageLocalDisponible()
```

`<Résultat>` *Booléen*
> - Vrai si le stockage local est disponible,
> - Faux dans le cas contraire.

**Composante : WDJS.DLL**
