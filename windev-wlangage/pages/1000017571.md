# gglEmail (Type de variable)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Le type **gglEmail** permet de décrire et de modifier une adresse email d'un contact.
Ce type de variable est utilisé par le type [gglContact](1000017434.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Connexion à Google
Cnx est une gglConnexion
Cnx.Email = "balthazar@gmail.com"
Cnx.MotDePasse = "azerty"
Cnx.NomApplication = "MonAppli-01"
SI GglConnecte(Cnx) = Faux ALORS
	Erreur(ErreurInfo())
FIN
...
// Récupération du tableau des contacts
tabContacts est un tableau de gglContact
tabContacts = GglListeContact(Cnx)

// Affichage des emails du premier contact
UnContact est un gglContact = tabContacts[1]
UnEmail est un gglEmail dynamique
POUR TOUT UnEmail DE UnContact.Email
	Trace(UnEmail.Libellé + " : " + UnEmail.Adresse)
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type gglEmail
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **gglEmail** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Adresse | Chaîne de caractères Unicode | Adresse email du contact. |
| Libellé | Chaîne de caractères Unicode | Libellé de description de l'adresse.  Equivalent d'un type personnalisé. Il faut renseigner obligatoirement une seule des deux propriétés **Libellé** ou **Type**. |
| Principal | Booléen | - Vrai si l'email correspond à l'adresse email principale du contact, - Faux dans le cas contraire. |
| Type | Constante de type entier | Type de l'adresse email correspondant à une des variables suivantes :  - *gglAutre* : Autre type d'adresse. - *gglBureau* : Adresse professionnelle. - *gglDomicile* : Adresse du domicile.  Il faut renseigner obligatoirement une seule des deux propriétés **Libellé** ou **Type**. |
