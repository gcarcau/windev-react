# Police (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **Police** permet de :

- Connaître l'identifiant de la police utilisée dans un champ d'un état, d'une page ou d'une fenêtre.
- Modifier la police utilisée dans un champ d'un état, d'une page ou d'une fenêtre.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, iPhone/iPad, Widget IOS)_ MaPolice est une Police
MaPolice = PoliceCrée("Arial", 12, iGras)
SAI_Adresse.Police = MaPolice

```wlangage
// Définir les caractéristiques d'une variable de type Police
Police1 est une Police
Police1.Nom = "Arial"
Police1.Couleur = JauneClair
Police1.Taille = 14
Police1.UnitéTaille = unitéPoint
Police1.Angle = 45
// Appliquer la police au champ "MonChamp"
MonChamp.Police = Police1
```

## Syntaxe

#### Connaître la police utilisée dans un champ

```wlangage
<Résultat> = <Champ manipulé>.Police
```

`<Résultat>` *Police*
> Variable de type [Police](1514045.md) contenant les caractéristiques de la police utilisée dans le champ spécifié.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.

#### Modifier la police utilisée dans un champ

```wlangage
<Champ manipulé>.Police = <Nouvelle police>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.
`<Nouvelle police>` *Police*
> Variable de type [Police](1514045.md) contenant les caractéristiques de la nouvelle police à utiliser dans le champ spécifié. Les caractéristiques de la police ont été définies grâce à la fonction [PoliceCrée](3060002.md) ou grâce aux [propriétés de gestion des polices](2515045.md).

## Remarques

### Police des champs d'un état
Pour manipuler les polices des champs d'un état, utilisez les propriétés :

- [Police](1514045.md),
- [PoliceNom](2510100.md),
- [PoliceBarrée](2510091.md),
- [PoliceGras](2510103.md),
- [PoliceItalique](2510102.md),
- [PoliceSoulignée](2510099.md),
- [PoliceTaille](2510072.md).

> _(Android, Widget Android)_ Ces propriétés ne sont pas disponibles.

> _(WEBDEV - Code Serveur)_ Police des champs d'une pageIl est conseillé d'utiliser comme nom de police une série de polices séparée par des virgules. Par exemple : "Arial, Helvetica, Sans-serif", "Time New Roman, Times, Serif", ...La propriété Police ne permet pas de récupérer ou de modifier les tailles CSS en plus des tailles absolues. Pour plus de détails, consultez la page d'aide de la propriété PoliceTaille.

### Limites

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad)_ Pour un état, la propriété Police peut être utilisée sur :un champ Libellé.un champ Calculé.un champ Lien.un champ Prédéfini.un champ de saisie.
Pour une fenêtre et une page, la propriété **Police** peut être utilisée sur :

- un champ Libellé,
- un champ de saisie,
- un champ Bouton,
- un champ Interrupteur,
- un champ Sélecteur,
- un champ Liste,
- une ligne de liste (y compris liste image) ou de combo,
- un champ Table,
- un champ Table hiérarchique,
- une cellule de table,
   La propriété est disponible en lecture uniquement.
- une colonne de table,
- un champ d'affichage formaté,
- un champ HTML,
- un champ Combo,
- un champ Lien,
- un champ Libellé HTML,
- un champ Réglette,
- un champ Chemin de navigation,
- un champ Arbre,
- un Champ Menu,
- une case de barre de message.

> _(Android, Widget Android)_ La propriété Police peut être utilisée sur :un champ Bouton, un champ Libellé,un champ de saisie,une colonne d'un champ Table,une ligne d'un champ Liste, Table ou Combo, une ressource d'un champ Planning. Cette propriété n'est pas disponible sur les champs d'un état.
