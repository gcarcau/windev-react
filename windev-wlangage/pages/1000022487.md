# Style (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **Style** permet de :

- récupérer ou d'affecter le style complet d'un champ (y compris les surcharges). Pour plus de détails, consultez l'aide de la propriété [Style](1000021472.md).
- connaître les styles associés à un document de type Traitement de texte. Cette propriété est utilisable sur les variables de type [Document](1000022461.md).
- Nouveauté 2025
   définir les styles des boutons d'une notification Windows. Cette propriété est utilisable sur les variables de type [sysNotificationBouton](1410087947.md).
