# apiRéponse (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Le type **apiRéponse** permet d'obtenir le résultat d'une requête envoyée sur une API REST précédemment importée. Les caractéristiques de ce résultat peuvent être connues à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

Nouveauté 2025
**Attention** : Ce type de variable est disponible uniquement à partir de la version 2025 Update 2.

## Exemple

```wlangage
Réponse est une apiRéponse
// Appel de la fonction de l'API
Réponse = MonApi.RécupèreClient(1)
// Lecture d'un élément de l'entête
nb_requetes_restantes est un entier = Réponse.Entête["Rate-Limit"]
// Lecture de la réponse de la fonction
client est un MonApi.Client = Réponse.Valeur
```

## Propriétés

### Propriétés spécifiques à la description des variables de type apiRéponse
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **apiRéponse** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Entête | Tableau associatif de chaînes de caractères | Ensemble clé/valeur des entêtes reçues. |
| RéponseHTTP | Variable de type [httpRéponse](1000021165.md) | Réponse HTTP brute du Webservice REST.  **Cette propriété est disponible en lecture seulement.** |
| TypeValeurRetour | Variable de type [Définition](1000019540.md) | Type de la valeur.  **Cette propriété est disponible en lecture seulement.** |
| Valeur |  | Valeur de la réponse.  Cette valeur est déduite :    - de la documentation du Webservice REST. - du contenu de la réponse HTTP. - des entêtes.   Cette valeur peut correspondre à :    - un type simple : entier, chaîne de caractères, numérique, booléen, etc. Le type mime correspondant est "octet-stream". - un tableau de types simples. - un contenu JSON. Le type mime correspondant est "application/json".   Si cette valeur est vide, un problème est survenu. Dans ce cas, il est conseillé d'analyser le contenu des propriétés **TypeValeurRetour** et **RéponseHTTP**.   **Cette propriété est disponible en lecture seulement.** |
