# ExceptionAffiche (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Affiche la fenêtre standard des exceptions avec le contenu de l'exception courante.
> _(WEBDEV - Code Serveur)_ La fenêtre standard des exceptions est affichée uniquement en mode test. Lors de l'exécution du site, la fenêtre n'est pas affichée.

## Exemple

```wlangage
QUAND EXCEPTION DANS
	Proc()
FAIRE
	// Affichage de l'exception
	ExceptionAffiche()
	// Code spécifique après l'affichage
	...
	// Fin de l'application
	FinProgramme()
FIN
```

## Syntaxe

```wlangage
<Résultat> = ExceptionAffiche()
```

`<Résultat>` *Constante de type Entier*
> Manipulation effectuée par l'utilisateur sur la fenêtre :
>
> | *eaFinProgramme* | L'utilisateur n'a pas coché l'option "Relancer l'application". |
> | --- | --- |
> | *eaRelanceProgramme* | L'utilisateur a coché l'option "Relancer l'application". |
>
>
>
> > _(WEBDEV - Code Serveur, Android, Widget Android, Java)_ La fenêtre standard des exceptions est affichée uniquement en mode test. Lors de l'exécution du site, la fenêtre n'est pas affichée. Dans ce cas, <Résultat> vaut eaFinProgramme.

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
