# URI

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le mot-clé URI peur correspondre à :

- une variable de type [URI](1000024027.md).
- la propriété URI permettant gérer un emplacement dans un fichier XML. Cette propriété est utilisable sur :
  - une variable de type [xmlNamespace](1000018803.md).
  - une variable de type [xmlSignatureRéférence](1000020746.md).
