# Taille (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Renvoie :

- la taille d'une chaîne de caractères, c'est-à-dire le nombre de caractères composant la chaîne de caractères (y compris les caractères espace et 0 binaire).
- la taille d'un buffer, c'est-à-dire le nombre d'octets composant le buffer.

> _(WEBDEV - Code Navigateur, PHP)_ Dans cette version, il n'est pas possible de connaître la taille d'un buffer.

## Exemple

```wlangage
Taille("Quasimodo")      // Renvoie 9
Taille(" Quasimodo ")    // Renvoie 11
Taille("A" + Caract(0))  // Renvoie 2
Taille("")               // Renvoie 0
Taille(" ")              // Renvoie 1
```

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Android, Widget Android, Java, Code Utilisateur (MCU), Ajax)_ MonBuffer est un Buffer = "Le développement facile"
Taille(MonBuffer) // Renvoie 23

## Syntaxe

#### Connaître la taille d'une chaîne de caractères

```wlangage
<Résultat> = Taille(<Chaîne initiale>)
```

`<Résultat>` *Entier*
> Nombre **de caractères** composant la chaîne.
`<Chaîne initiale>` *Chaîne de caractères*
> Chaîne de caractères dont la taille doit être calculée.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst, Java, Code Utilisateur (MCU), Ajax, Linux, iPhone/iPad, Widget IOS, Apple Watch)_ Connaître la taille d'un buffer Masquer les détails
<Résultat> = Taille(<Buffer initial>)

 <Résultat> : EntierNombre d' octets composant le buffer. <Buffer initial> : BufferBuffer dont la taille doit être calculée. En UNICODE, chaque caractère occupe quatre octets de mémoire. La taille d'un buffer contenant une chaîne UNICODE correspond à quatre fois le nombre de caractères réellement contenu dans la chaîne sous Windows.

**Composante : wd300vm.dll**
