# Description de Paramètre (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

Une variable de type **Description de Paramètre** permet de décrire un paramètre d'une syntaxe par programmation.
Les caractéristiques de ce type peuvent être connues à l'aide de différentes propriétés WLangage. Ce type de variable est utilisé par les variables de type [Description de Syntaxe](1410089154.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
Description_état est une Définition = RécupèreDéfinitionType(ETAT_CommandesClients)Description_syntaxe est une Description de Syntaxe = Description_état.SyntaxeDéclaration// Parcourt les paramètres de l'étatPOUR TOUT x DE Description_syntaxe.Paramètre Trace(x.Nom)FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type Description de Paramètre
Les propriétés suivantes peuvent être utilisées pour manipuler une Description de Paramètre :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Nom | Chaîne de caractères | Nom du paramètre.  **Cette propriété est disponible en lecture seulement**. |
| Type | [Définition](1000019540.md) | Type du paramètre.  **Cette propriété est disponible en lecture seulement**. |
