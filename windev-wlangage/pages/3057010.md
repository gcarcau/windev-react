# OLEServeur (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Liste les serveurs OLE enregistrés auprès du système en cours.

## Exemple

```wlangage
// Initialiser le champ Liste avec les serveurs OLE disponibles
ListeAjoute(LISTE_SERVOLE, OLEServeur())
// Récupérer le serveur à lancer
Choix est une chaîne
Ind est un entier = ListeSelect(LISTE_SERVOLE)
Choix = LISTE_SERVOLE[Ind] + TAB
Choix = ExtraitChaîne(Choix, 2)
OLECréeVide(OLE_OLE1, Choix)
```

## Syntaxe

```wlangage
<Résultat> = OLEServeur()
```

`<Résultat>` *Chaîne de caractères*
> - Liste des serveurs OLE au format :
>   ```wlangage
>   <Description 1> + TAB + <Nom du Serveur 1> + RC + ... + RC + <Description N> + TAB + <Nom du Serveur N>
>   ```
>   Le nom du serveur pourra ensuite être utilisé dans la fonction [OLECréeVide](3057001.md).
>   Remarque : la liste des serveurs peut contenir des chaînes vides (à supprimer si nécessaire).
> - Chaîne vide ("") en cas d'erreur.

## Remarques

### Initialiser un champ Liste avec les serveurs OLE
Il est possible de remplir un champ Liste (ou un champ Combo) avec la liste des serveurs OLE en utilisant directement la fonction [ListeAjoute](3049004.md). La syntaxe à utiliser est la suivante :

```wlangage
ListeAjoute(<Nom du champ Liste>, OLEServeur())
```

### Divers
Seul OLE version 1 est géré.

**Composante : wd300ole.dll**
