# FinEtendueVisible (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android)

La propriété **FinEtendueVisible** permet de :

- connaître la dernière date ou heure visible :
  - dans un champ Planning.
  - dans un champ TimeLine.
- modifier la dernière heure visible dans un champ TimeLine.

## Exemple

> _(WINDEV)_ // Champ TimeLine sur 2 minutes au total
TimelineChangeMode(TL_TimeLine, plnModeSeconde, 120)

// équivalent à :
TL_TimeLine.DébutEtendueTotale = 0 // commence à 0 sec
TL_TimeLine.FinEtendueTotale = 120 // fin à 120 sec

// Rendre visible les 30 premières secondes
TL_TimeLine.DébutEtendueVisible = 0 // commence à 0 sec
TL_TimeLine.FinEtendueVisible = 30 // taille à 30 sec

## Syntaxe

#### Connaître la dernière date ou heure visible

```wlangage
<Résultat> = <Champ manipulé>.FinEtendueVisible
```

`<Résultat>` *Entier ou chaîne de caractères au format Date/Heure*
> Dernière valeur visible dans le champ. Cette valeur correspond :
>
> - à un entier pour :
>   - un champ TimeLine,
>   - un champ Planning en mode seconde, milliseconde ou microseconde.
> - à une date au format AAAAMMJJHHSSCC pour un champ Planning en mode jour, semaine, mois.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler. Ce champ peut correspondre à :
>
> - un champ Planning.
> - un champ TimeLine.

> _(WINDEV)_ Modifier la valeur de la dernière heure visible dans un champ TimeLine Masquer les détails
<Champ TimeLine>.FinEtendueVisible = <Nouvelle valeur>

 <Champ TimeLine> : Nom de champNom du champ TimeLine à manipuler. <Nouvelle valeur> : EntierDernière valeur visible dans le champ.

## Remarques

- L'ensemble des événements représentés par le champ est compris entre [DébutEtendueTotale](1000020392.md) et [FinEtendueTotale](1000020393.md). Cela correspond à l'étendue totale de l'ascenseur ou du range slider associé au champ.
- L'ensemble des événements visibles dans le champ est compris entre [DébutEtendueVisible](1000020394.md) et **FinEtendueVisible**. Cela correspond à la taille de la cage de l'ascenseur ou du range slider associé au champ.
- Cette propriété permet de modifier la valeur de la dernière heure visible uniquement dans un champ TimeLine.
- La propriété [FinEtendueTotale](1000020393.md) et **FinEtendueVisible** sont équivalentes. Elles permettent de connaître la dernière valeur visible dans le champ.
