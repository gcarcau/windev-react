# KiosqueDésactive (Fonction)

> **Disponible :** **WINDEV Mobile** (Android)

Désactive le mode kiosque pour l'application en cours. Les boutons système sont de nouveau affichés dans l'interface.

## Exemple

```wlangage
// Arrête le mode kiosque pour l'application en cours
KiosqueDésactive()
```

## Syntaxe

```wlangage
KiosqueDésactive()
```

## Remarques

### Cas particuliers
La fonction [EnModeKiosque](1000024427.md) permet de savoir si l'application est actuellement en mode kiosque.

> _(Android)_ Application en arrière-plan : Spécificité à partir de Android 10A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. La fonction KiosqueDésactive peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. Conseils : Il est possible de savoir si l'application est en arrière-plan grâce à la fonction EnModeArrièrePlan. Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type Notification). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété ActiveApplication est à Vrai. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété ActionClic.Pour plus de détails, consultez Android 10 : Comportement des applications en arrière-plan.
