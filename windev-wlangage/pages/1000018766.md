# <Variable sfConnexion>.ExécuteTraitement (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Demande l'exécution d'un traitement spécifique. Il est possible de :

- Soumettre des enregistrements au processus d'approbation.
- Effectuer une action d'approbation.

## Syntaxe

```wlangage
<Résultat> = <Connexion Salesforce>.ExécuteTraitement(<Traitement à effectuer>)
```

`<Résultat>` *Variable de type Tableau*
> Tableau de variables de type [sfRésultatExécuteTraitement](1000018559.md) contenant les données résultat.
`<Connexion Salesforce>` *Variable de type sfConnexion*
> Nom de la variable de type [sfConnexion](1000017579.md) à utiliser
`<Traitement à effectuer>` *Tableau de variants*
> Tableau de variants contenant les traitements à exécuter. Ce tableau peut contenir des objets de type :
>
> - [sfRequêteTraitementTâche](1000018520.md).
> - [sfRequêteTraitementSoumission](1000018516.md).

## Remarques

### Cas d'erreurs possibles :

- La connexion Internet n'est pas valide.
- L'authentification n'a pas pu être réalisée correctement.
- La réponse XML du serveur n'est pas lisible.

Pour savoir si une erreur est survenue, utilisez la variable [ErreurDétectée](3087001.md).
