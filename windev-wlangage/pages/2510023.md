# CadrageHorizontal (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le cadrage horizontal d'un champ consiste à définir la position du texte dans le champ par rapport aux bords du champ. Ainsi, il est possible de cadrer le contenu d'un champ Libellé par rapport aux bords de la zone du libellé.
Plusieurs cadrages sont à votre disposition :

- cadrage à gauche [image: Texte cadré à gauche]
- cadrage à droite [image: Texte cadré à droite]
- centré [image: Texte centré]
- justifié

La propriété **CadrageHorizontal** permet de connaître et de modifier le cadrage horizontal d'un champ.
Le cadrage initial du champ est défini sous l'éditeur lors de la description du champ.

## Exemple

```wlangage
// Si le champ est cadré à gauche, on le cadre à droite
SI LIB_libellé1.CadrageHorizontal = chGauche ALORS
	LIB_libellé1.CadrageHorizontal = chDroite
FIN
```

## Syntaxe

#### Connaître le cadrage horizontal d'un champ

```wlangage
<Cadrage actuel>.CadrageHorizontal = <Champ manipulé>
```

`<Cadrage actuel>` *Constante de type entier*
> Cadrage horizontal actuel du champ. Les valeurs possibles sont les suivantes :
>
>
> | *chCentre* | Le texte est centré. |
> | --- | --- |
> | *chDroite* | Le texte est aligné à droite. |
> | *chGauche* | Le texte est aligné à gauche. |
> | *chJustifié* | Le texte est justifié. |
> | *chNonDéfini* | Cadrage défini par l'héritage du CSS. Cette constante est disponible uniquement en WEBDEV. |
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.

#### Modifier le cadrage horizontal d'un champ

```wlangage
<Champ manipulé>.CadrageHorizontal = <Nouveau cadrage>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.
`<Nouveau cadrage>` *Constante de type entier*
> Nouveau cadrage horizontal du champ. Les valeurs possibles sont les suivantes :
>
>
> | *chCentre* | Le texte est centré. |
> | --- | --- |
> | *chDroite* | Le texte est aligné à droite. |
> | *chGauche* | Le texte est aligné à gauche. |
> | *chJustifié* | Le texte est justifié. |
> | *chNonDéfini* | Cadrage défini par l'héritage du CSS. Cette constante est disponible uniquement en WEBDEV. |

## Remarques

> _(WINDEV, Etats et Requêtes, Android, iPhone/iPad, Mac Catalyst, Java, Code Utilisateur (MCU))_ Cadrage horizontal et texte de taille supérieure au champSi le texte ne rentre pas complètement dans le champ, les informations suivantes sont affichées :Sous l'éditeur d'états, la partie gauche du texte est affichée.Sous l'éditeur de fenêtres :dans un libellé, la partie droite du texte est affichée.dans un champ de saisie, la partie gauche du texte est affichée.

### Cadrage vertical
Pour définir le cadrage vertical du champ, utilisez la propriété [CadrageVertical](2510054.md).

### Limitation

> _(WINDEV)_ Dans une fenêtre, la propriété CadrageHorizontal permet de connaître et de modifier le cadrage horizontal des champs de type :Champ LibelléChamp de saisieChamp Combo (avec ou sans saisie)Champ Interrupteur / champ SélecteurChamp ListeChamp Liste imageChamp ImageColonne de table et colonne de table hiérarchiqueCase de barre de messageChamp Code-barresChamp GrapheChamp Jauge. La propriété permet de connaître et modifier le cadrage horizontal du pourcentage de progression affiché dans la jauge.Champ NotationChamp Organigramme

> _(WEBDEV - Code Serveur)_ Dans une page, la propriété CadrageHorizontal permet de connaître et de modifier le cadrage horizontal des champs de type :Champ Libellé, champ Libellé HTMLChamp de saisieChamp BoutonChamp Interrupteur / champ SélecteurChamp Table, colonne de tableChamp Table hiérarchique, colonne de table hiérarchiqueChamp Cellule de table (en lecture uniquement)Champ d'affichage formatéChamp Liste, champ ComboChamp Zone répétéeChamp HTMLChamp LienChamp RégletteChamp Chemin de navigationChamp Arbre

> _(PHP)_ Dans une page PHP, la propriété CadrageHorizontal permet de connaître et de modifier le cadrage horizontal des champs de type :Champ Libellé, libellé HTMLChamp de saisieChamp BoutonChamp Interrupteur / champ SélecteurChamp Table, colonne de tableChamp Table hiérarchique, colonne de table hiérarchiqueChamp d'affichage formatéChamp Liste, champ ComboChamp Zone répétéeChamp HTMLChamp LienChamp RégletteChamp Arbre

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Android, iPhone/iPad)_ Dans un état, la propriété CadrageHorizontal permet de connaître et de modifier le cadrage horizontal des champs de type :Champ Libellé.Champ Calculé.Champ Prédéfini.Champ Graphe.Groupes de champs. Cette propriété s'appliquera uniquement aux champs du groupe gérant le cadrage horizontal.

> _(Java)_ La propriété CadrageHorizontal s'applique uniquement aux champs suivants :Champ Libellé.Champ de saisie.Champ Image.Champ Interrupteur.Champ Sélecteur.Champ Liste.Champ Combo.Colonne de table (de type texte, combo ou interrupteur).

> _(Android, iPhone/iPad, Mac Catalyst)_ La propriété CadrageHorizontal s'applique aux colonnes de table.

> _(Widget IOS)_ La propriété CadrageHorizontal s'applique aux champs Libellé.
