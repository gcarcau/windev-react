# zipNbPartie (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie le nombre de sous-archives (parties) d'une archive au format CAB, RAR, ZIP, WDZ, 7z, gzip, TAR ou TGZ (TAR.GZ).
Nouveauté 2025

> _(WINDEV, WEBDEV - Code Serveur, Windows, Linux, iPhone/iPad)_ Le format gzip (extension .gz) est désormais géré.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ MonArchive est une zipArchive
// Ouverture d'une archive
ResOuvreArchive = zipOuvre(MonArchive, "C:\MesArchives\Archive.zip")
SI ResOuvreArchive = 0 ALORS
 ...
 // Nombre de parties présentes dans l'archive
 ResNbPartie = zipNbPartie(MonArchive)
 Info("Cette archive est composée de " + ResNbPartie + " partie(s)")
 ...
FIN

## Syntaxe

```wlangage
<Résultat> = zipNbPartie(<Archive>)
```

`<Résultat>` *Entier*
> Nombre de parties présentes dans l'archive spécifiée :
>
> - 1 : si l'archive est mono-partie ou si l'archive multi-parties contient une seule sous-archive.
> - n : si l'archive est multi-parties.
`<Archive>` *Chaîne de caractères ou variable de type zipArchive*
> Nom de l'archive à manipuler.
> Ce nom peut correspondre :
>
> - soit au nom d'une archive défini avec la fonction [zipOuvre](3082044.md) ou la fonction [zipCrée](3082003.md).
> - soit au nom d'une variable de type [zipArchive](1000018679.md).

## Remarques

### Une archive multi-parties peut être constituée d'une seule partie
Une archive multi-parties peut être composée d'une seule sous-archive (partie). En effet, lors du découpage d'une archive, la taille spécifiée pour les sous-archives peut être supérieure à la taille de l'archive.

### Rappel

> _(Linux, iPhone/iPad, Widget IOS, Mac Catalyst)_ Seules les archives au format ZIP, gzip, TAR et TGZ (TAR.GZ) sont disponibles.

**Classification Métier / UI : Code métier**

**Composante : wd300zip.dll**
