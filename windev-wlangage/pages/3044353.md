# HPrioritéClient (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Modifie la priorité d'une application cliente. Les applications dont la priorité doit être modifiée sont les applications clientes décrites dans la structure [HClient](3044340.md).
**Remarque** : Plus la priorité de l'application cliente est haute, plus le serveur traitera les demandes de cette application en premier.

## Exemple

```wlangage
// Définition de la structure HClient
HClient.Application = "MonApplicationCliente"

// Changement de priorité de l'application
HPrioritéClient("MaConnexion", 5)
```

## Syntaxe

```wlangage
<Résultat> = HPrioritéClient(<Connexion> , <Priorité>)
```

`<Résultat>` *Booléen*
> - Vrai si le changement de priorité a eu lieu,
> - Faux dans le cas contraire. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion vers le serveur HFSQL. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Priorité>` *Entier*
> Nouvelle valeur de la priorité à affecter à l'application cliente. Cette valeur est comprise entre -10 (basse priorité) et 10 (haute priorité).
> Par défaut, au lancement de l'application, la priorité est de 0 (priorité normale).

## Remarques

Pour modifier la priorité de l'application cliente spécifiée, le droit de modifier la priorité est nécessaire. Ce droit correspond à la constante *hDroitPriorité* (utilisée dans les fonctions [HInfoDroitServeur](3044322.md) et [HModifieDroitServeur](3044328.md)).
