# PicSauve (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Sauve l'image présente :

- dans un champ Editeur d'images.
- dans une variable de type [WDPic](1000023503.md).

## Exemple

> _(WINDEV)_ // Demande de sauvegarde de l'image présente dans un champ Editeur d'images
SI PicSauve(EI_MonEditeur) = Faux ALORS
 Erreur(ErreurInfo())
FIN

```wlangage
MonImageWDPic est un WDPic
...
// Demande de sauvegarde de l'image
SI PicSauve(MonImageWDPic, "C:\temp\test.png") = Faux ALORS
	Erreur(ErreurInfo())
FIN
```

## Syntaxe

```wlangage
<Résultat> = PicSauve(<Image> [, <Fichier>])
```

`<Résultat>` *Booléen*
> - Vrai si l'image a été créée,
> - Faux dans le cas contraire (erreur, annulation du sélecteur de fichier, ...). En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai et la fonction [ErreurInfo](3013008.md) permet de connaître le détail de l'erreur.
`<Image>` *Nom de champ ou variable de type WDPic*
> Image à sauver. Cette image peut correspondre :
>
> - au nom du champ Editeur d'images à manipuler.
> - au nom d'une variable de type [WDPic](1000023503.md) à manipuler.
`<Fichier>` *Chaîne de caractères optionnelle*
> Nom et chemin du fichier image à sauver. L'extension du fichier détermine le type de l'image à sauver.
> Si ce paramètre n'est pas précisé :
>
> - Dans le cas d'un champ Editeur d'images : l'action effectuée correspond à la fonctionnalité d'enregistrement de l'éditeur d'images (clic sur la disquette dans le ruban).
>   Si l'image n'a jamais été enregistrée, le sélecteur de fichier s'affiche.
> - Dans le cas d'une variable de type [WDPic](1000023503.md), une erreur fatale est affichée.
