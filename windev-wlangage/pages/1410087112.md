# 1. Projet et analyse

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

| [Page précédente](1410087111.md) | [Sommaire](1410087102.md) | [Page suivante](1410087113.md) |
| --- | --- | --- |

Le développement d'un **site Web** en utilisant WEBDEV repose sur deux éléments principaux : le Projet et l'Analyse.
Un **Projet WEBDEV** est un ensemble d'éléments (pages, états, champs, classes, composants, etc.) dont l'assemblage permet de réaliser un site Web.

Une **Analyse WEBDEV** correspond au schéma des données utilisé par l'application. L'analyse regroupe les différentes tables (aussi appelées fichiers de données) utilisées par le site.

Un site est construit à partir d'un projet.

Lorsqu'un projet WEBDEV utilise des fichiers de données, une analyse doit être associé à ce projet. Généralement, un projet est associé à une analyse, mais il peut également être associé à plusieurs analyses.

Une analyse peut être associée à un ou plusieurs projets.
