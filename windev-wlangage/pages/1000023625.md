# SectionCritique

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Le mot-clé **SectionCritique** peut correspondre :

- à la fonction [SectionCritique](1000024373.md) qui permet d'activer une section critique nommée ou sur une variable dans une instruction de type [UTILISER ... DANS](1510025.md).
- au type de variable [SectionCritique](1000023972.md) qui permet de définir des sections critiques afin de limiter l'exécution simultanée d'un code (procédure, ligne de code, ...) **à un thread** à un instant donné dans une seule application.
