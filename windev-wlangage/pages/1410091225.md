# <Connexion HFSQL>.ListeHistoriqueReindexation (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Liste les différentes opérations effectuées sur les fichiers de données en cours ou celles qui ont eu lieu pendant les dernières 24 heures et sur les 1000 derniers fichiers : réindexations, recalcul des statistiques, vérification des mémo, vérification des index, etc.
Nouveauté Abonnement
Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
CnxBaseDeDonnées est une Connexion
tabHistoriques est un tableau de hHistoriqueRéindexation
// Liste des réindexations / vérifications en cours
tabHistoriques = CnxBaseDeDonnées.ListeHistoriqueRéindexation()
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.ListeHistoriqueReindexation()
```

`<Résultat>` *Tableau de variables de type hHistoriqueRéindexation*
> Tableau de variables de type [hHistoriqueRéindexation](1410091059.md), contenant les caractéristiques des différentes réindexations effectuées.
`<Connexion>` *Variable de type Connexion*
> Connexion vers le serveur contenant les données à manipuler. Cette connexion correspond au nom d'une variable de type [Connexion](1514073.md).

## Remarques

Les opérations listées par la fonction **<Connexion HFSQL>.ListeHistoriqueReindexation** sont les suivantes :

- réindexations lancées par la fonction [<Connexion HFSQL>.RéindexeAsynchrone](1410091221.md).
- calculs de statistiques exécutés par la fonction [HStatCalculAsynchrone](1410091224.md).
- vérification des index exécutée par la fonction [<Connexion HFSQL>.VérifieIndexAsynchrone](1410091223.md).
- vérification des mémos exécutée par la fonction [<Connexion HFSQL>.VérifieMémoAsynchrone](1410091222.md).
