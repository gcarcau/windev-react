# Les champs conteneurs

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

WINDEV, WEBDEV et WINDEV Mobile proposent différents champs qui peuvent contenir d'autres champs : ce sont des champs "conteneur".
Ainsi, de nombreux types de champs correspondent à des champs conteneur :

- les champs Cellule,
- les champs Flexbox,
- les champs Disposition,
- les champs Onglet
- etc.

Les éléments présents dans le champ conteneur sont des "fils" du champ conteneur.

Ces champs conteneurs possèdent propriétés spécifiques sous l'éditeur de fenêtres et de pages.

## Refuser les fils

Par défaut, les éléments déplacés (par la souris ou par le clavier) dans un champ conteneur deviennent les fils de ce champ conteneur : ils sont inclus dans le champ conteneur (et non superposés au champ conteneur).
Par exemple, un champ Bouton placé dans une cellule devient un fils du champ Cellule. Si la cellule est déplacée dans la fenêtre ou dans la page, le champ fils sera également déplacé. La position du champ fils est relative à celle du conteneur associé.

Lors du déplacement d'un champ, il est possible d'interdire d'associer ce champ à un champ conteneur :

1. Sélectionnez le champ conteneur sous l'éditeur.
2. Sous le volet "Modification", dans le groupe "Aide à l'édition", cochez l'option "Refuse les fils".

Les champs déplacés à la souris ou au clavier sur le champ conteneur ne seront plus "inclus" dans le champ conteneur mais seront "superposés" à ce champ.
Nouveauté 2025

## Supprimer un champ conteneur sans supprimer ses fils

Par défaut, l'utilisation de la touche Suppr sur un champ conteneur supprime le champ conteneur et tous les champs associés au champ conteneur (les champs fils).
Pour les superchamps, les champs Cellule et les champs Flexbox, il est possible de supprimer le champ conteneur sans supprimer ses champs fils.

Pour supprimer un champ conteneur sans supprimer ses éléments fils :

1. Sélectionnez le champ conteneur sous l'éditeur (champ Onglet, champ Disposition, champ Cellule, etc.).
2. Sous le volet "Modification", dans le groupe "Transformations", déroulez "Refactoring et permutations" et sélectionnez l'option "Supprimer en conservant les fils".

Nouveauté 2025

## Coloriser les conteneurs

La colorisation des conteneurs en édition vous aide à concevoir vos UI, surtout dans le cas de conteneurs imbriqués.
Lorsque vous utilisez des conteneurs de type Cellule, Flexbox ou Disposition, n'hésitez pas à utiliser la colorisation de conteneurs. Cette option permet d'utiliser des dégradés de couleurs afin de visualiser les surfaces de chaque zone.

Pour utiliser cette fonctionnalité :

1. Sous le volet "Affichage", dans le groupe "Voir (tous les champs)", cochez l'option "Coloriser les conteneurs".
2. Sélectionnez si nécessaire la palette de couleurs à utiliser.

**Remarque** : Vous pouvez utiliser le raccourci F7 pour alterner entre les différentes options d'affichage : marges, surface des champs, encadrement et colorisation des conteneurs.
