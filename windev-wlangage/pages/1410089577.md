# Cryptage (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Cryptage** permet de connaître et de modifier le type de cryptage utilisé. Cette propriété est utilisable sur :

- une connexion HFSQL Client/Serveur. Pour plus de détails, consultez [Cryptage](2512102.md).
- une variable de type [JWTParamètres](1410089572.md).
