# SSLActive (Fonction)

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur)

Permet d'activer ou de désactiver le mode sécurisé SSL.
**Attention** : l'utilisation de cette fonction suppose qu'un certificat SSL est actif. Pour plus de détails, consultez [Transactions sécurisées](3012011.md) et [Obtention d'un certificat SSL (IIS version 2 à 5)](3012012.md).

## Exemple

```wlangage
// -- code de clic navigateur du bouton
SSLActive(Vrai)

// -- code de clic serveur du bouton
PageAffiche(PAGE_Page1_Sécu)
// la page "PAGE_Page1_Sécu" est ouverte en mode sécurisé.
// Toutes les actions faites à partir de cette page
// seront sécurisées
```

```wlangage
// -- code de clic navigateur du bouton
SSLActive(Faux)
// -- code de clic serveur du bouton
PageAffiche(PAGE_Page1)
// la page "PAGE_Page1" est ouverte en mode normal.
// Toutes les actions faites à partir de cette page
// seront en mode non sécurisé
```

## Syntaxe

```wlangage
SSLActive(<Mode>)
```

`<Mode>` *Booléen*
> - Vrai si le mode SSL doit être activé,
> - Faux dans le cas contraire.

## Remarques

### Conditions d'utilisation
Cette fonction peut être utilisée uniquement :

- dans le code de clic des boutons réalisant une opération de type "Envoyer la valeur des champs au serveur (submit)" (onglet "Général" de la fenêtre de description du champ).
- dans le code de sélection d'une option de menu de type "Envoyer la valeur des champs au serveur (submit)" (onglet "Général" de la fenêtre de description de l'option de menu).

**Composante : WDJS.DLL**
