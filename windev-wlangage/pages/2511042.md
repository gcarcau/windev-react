# NbCopie (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

La propriété **NbCopie** permet de connaître et de modifier le nombre d'exemplaires à imprimer d'un état.
> _(WINDEV, WINDEV Mobile)_ Remarques :Le visualisateur de rapports permet aussi à l'utilisateur final de paramétrer directement le nombre de copies à imprimer.Cette propriété fonctionne uniquement lors d'une impression sur une imprimante.Si un nombre de copies est spécifié par l'utilisateur (fonction iParamètre ou fonction iParamètreEtat) avant de lancer l'impression de l'état, ce nombre de copies sera prioritaire sur celui spécifié avec la propriété NbCopie.

## Exemple

```wlangage
// Imprimer l'état "ETAT_Client" 10 fois
ETAT_Client.NbCopie = 10
```

## Syntaxe

#### Connaître le nombre d'exemplaires d'un état

```wlangage
<Résultat> = <Etat manipulé>.NbCopie
```

`<Résultat>` *Entier*
> Nombre d'exemplaires à imprimer.
`<Etat manipulé>` *Nom d'état*
> Nom de l'état à manipuler.

#### Modifier le nombre d'exemplaires d'un état

```wlangage
<Etat manipulé>.NbCopie = <Nombre de copies>
```

`<Etat manipulé>` *Nom d'état*
> Nom de l'état à manipuler.
`<Nombre de copies>` *Entier*
> Nombre de copies à imprimer.

## Remarques

### Donner la possibilité à l'utilisateur de déterminer le nombre de copies d'un état
La propriété **NbCopie** ne pouvant être utilisée que dans le code de l'état, il est nécessaire de passer le nombre de copies en paramètre à l'état lors de l'impression.
Par exemple :

1. Code permettant d'imprimer l'état.
  ```wlangage
  iImprimeEtat(ETAT_MonEtat, 3)
  ```
2. Code d'ouverture de l'état.
  ```wlangage
  PROCÉDURE ETAT_MonEtat(nNbCopie)
  ETAT_MonEtat.NbCopie = nNbCopie
  ```

### Limites

- La propriété **NbCopie** s'applique uniquement aux états (et non aux champs ou blocs d'un état).
- Cette propriété est prise en compte uniquement lors d'une impression réalisée sur une imprimante.
