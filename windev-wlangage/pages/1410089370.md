# Fonctions de gestion des répertoires et des fichiers externes (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions de gestion des fichiers externes via une syntaxe préfixée sont les suivantes :

| [<Variable FichierDisque>.Bloque](1410089037.md) | Bloque entièrement ou partiellement un fichier externe. |
| --- | --- |
| [<Variable FichierDisque>.ChangeTaille](1410089038.md) | Change la taille d'un fichier externe. |
| [<Variable FichierDisque>.Cherche](1410089039.md) | Cherche une chaîne de caractères ou un buffer dans un fichier ouvert avec la fonction [<Variable FichierDisque>.Ouvre](1410090197.md). |
| [<Variable FichierDisque>.Crée](1410090211.md) | Crée un fichier externe. |
| [<Variable FichierDisque>.Débloque](1410089040.md) | Débloque entièrement ou partiellement un fichier externe. |
| [<Variable FichierDisque>.Ecrit](1410089041.md) | Écrit :  - une chaîne de caractères dans un fichier externe. - une portion de mémoire. |
| [<Variable FichierDisque>.EcritLigne](1410089042.md) | Écrit une ligne dans un fichier texte (au format ANSI ou Unicode). |
| [<Variable FichierDisque>.Ferme](1410089043.md) | Ferme un fichier externe. |
| [<Variable FichierDisque>.Lit](1410089044.md) | Lit :  - un bloc d'octets (bloc de caractères) dans un fichier externe (ANSI ou Unicode), - le contenu d'un fichier externe (ANSI ou Unicode) pour l'affecter dans une portion de mémoire. |
| [<Variable FichierDisque>.LitLigne](1410089045.md) | Lit une ligne dans un fichier externe (au format ANSI ou Unicode). |
| [<Variable FichierDisque>.LitLigneExpressionRégulière](1410089046.md) | Lit une ligne d'un fichier externe et récupère dans des variables les morceaux de cette ligne en fonction d'une expression régulière. |
| [<Variable FichierDisque>.NomFichier](1410089047.md) | Renvoie le nom d'un fichier externe actuellement ouvert. |
| [<Variable FichierDisque>.Ouvre](1410090197.md) | Ouvre un fichier externe (ANSI ou Unicode) pour le manipuler par programmation. |
| [<Variable FichierDisque>.OuvreFichierTemp](1410090203.md) | Crée et ouvre un fichier temporaire. |
| [<Variable FichierDisque>.Positionne](1410089048.md) | Renvoie et modifie la position en cours dans un fichier externe. |
| [<Variable FichierDisque>.Taille](1410089049.md) | Renvoie la taille d'un fichier en octets. |
