# RVBVersHTML (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Renvoie la couleur HTML correspondant à la couleur RVB.

## Exemple

```wlangage
RVBVersHTML(255) // Renvoie "#0000FF"
```

## Syntaxe

```wlangage
<Résultat> = RVBVersHTML(<Couleur RVB>)
```

`<Résultat>` *Chaîne de caractères*
> Couleur HTML exprimée en hexadécimal.
> > _(WEBDEV - Code Navigateur)_ <Résultat> correspond à une variable de type Couleur.
`<Couleur RVB>` *Entier*
> Couleur RVB à convertir en couleur HTML. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - [une couleur prédéfinie du WLangage](3010002.md).

## Remarques

> _(WEBDEV - Code Navigateur)_ AstuceSi le résultat est affiché dans une trace à l'écran (fonction Trace), la variable de type Couleur est convertie en chaîne correspondant à la couleur au format RVB.

**Classification Métier / UI : Code neutre**

**Composante : wd300std.dll**
