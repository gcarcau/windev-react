# Fonctions de gestion du planificateur Windows

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Les fonctions permettant de gérer le planificateur Windows sont les suivantes :

| [PlanificateurAjouteHoraire](3089001.md) | Crée un horaire pour une tâche planifiée. |
| --- | --- |
| [PlanificateurAjouteTâche](3089003.md) | Crée une tâche dans le planificateur de tâches Windows (si cette tâche n'existe pas déjà). |
| [PlanificateurEtatTâche](3089005.md) | Récupère ou modifie l'état d'une tâche créée dans le planificateur de tâches Windows. |
| [PlanificateurListeTâche](3089006.md) | Récupère la liste des tâches planifiées. |
| [PlanificateurModifieHoraire](3089007.md) | Modifie les paramètres d'un horaire de tâche planifiée, c'est-à-dire les paramètres qui vont définir l'exécution d'une tâche. |
| [PlanificateurModifieTâche](3089008.md) | Modifie les paramètres d'une tâche planifiée. |
| [PlanificateurOuvrePropriétésTâche](3089009.md) | Ouvre la page de propriétés d'une tâche planifiée. |
| [PlanificateurPropriétésHoraire](3089010.md) | Lit les propriétés d'un horaire de tâche planifiée et met à jour la [structure HoraireTâchePlanifiée](3089002.md). |
| [PlanificateurPropriétésTâche](3089011.md) | Lit les propriétés d'une tâche planifiée et met à jour la [structure TâchePlanifiée](3089004.md). |
| [PlanificateurRAZ](3089012.md) | Remplit les structures [TâchePlanifiée](3089004.md) et/ou [HoraireTâchePlanifiée](3089002.md) avec les valeurs par défaut. |
| [PlanificateurSupprimeHoraire](3089013.md) | Supprime un horaire d'une tâche planifiée. |
| [PlanificateurSupprimeTâche](3089014.md) | Supprime une tâche planifiée. |
