# Fonctions de gestion des données spatiales

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Les fonctions de gestion des données spatiales sont les suivantes :

| [GéométrieAire](1410090167.md) | Calcule l'aire d'une géométrie donnée. |
| --- | --- |
| [GéométrieChevauche](1410090308.md) | Permet de savoir si deux géométries se chevauchent. |
| [GéométrieContient](1410090138.md) | Permet de savoir si une géométrie A contient une géométrie B. |
| [GéométrieCorrige](1410090157.md) | Permet d'obtenir une version corrigée de la géométrie spécifiée. |
| [GéométrieCouvre](1410090140.md) | Permet de savoir si une géométrie A couvre une géométrie B. |
| [GéométrieCroise](1410090341.md) | Permet de savoir si deux géométries se croisent. |
| [GéométrieDésérialiseWKT2D](1410090336.md) | Construit une géométrie en 2 dimensions à partir d'une représentation textuelle au format WKT. |
| [GéométrieDésérialiseWKTGéo](1410090335.md) | Construit une géométrie en coordonnées géographiques à partir d'une représentation textuelle au format WKT. |
| [GéométrieDifférence](1410090156.md) | Renvoie la géométrie correspondant à la différence entre deux géométries. |
| [GéométrieDifférenceSymétrique](1410090164.md) | Calcule la différence symétrique entre deux géométries. |
| [GéométrieDisjoint](1410090307.md) | Permet de savoir si deux géométries sont disjointes, c'est-à-dire si leur intersection est vide. |
| [GéométrieDistance](1410090297.md) | Calcule la distance entre deux géométries. |
| [GéométrieEgale](1410090295.md) | Permet de savoir si deux géométries sont spatialement égales, c'est-à-dire si la première géométrie est incluse dans la seconde, et si la seconde est incluse dans la première. |
| [GéométrieEnveloppeConvexe](1410090169.md) | Calcule l'enveloppe convexe de la géométrie spécifiée. |
| [GéométrieEstContenu](1410090139.md) | Permet de savoir si la géométrie A est complètement contenue dans la géométrie B (c'est-à-dire que la géométrie B contient complètement la géométrie A). |
| [GéométrieEstCouvert](1410090141.md) | Permet de savoir si tout point de la géométrie A se trouve à l'intérieur ou dans le contour de la géométrie B. |
| [GéométrieEstValide](1410090158.md) | Vérifie si la géométrie spécifiée est valide au sens de la norme OGC. |
| [GéométrieIntersecte](1410090115.md) | Vérifie si deux géométries ont une intersection non vide. |
| [GéométrieIntersection](1410090153.md) | Renvoie la géométrie correspondant à l'intersection entre deux géométries. |
| [GéométrieLongueur](1410090296.md) | Calcule la longueur d'une géométrie donnée. |
| [GéométriePérimètre](1410090168.md) | Calcule le périmètre d'une géométrie donnée (polygone ou multipolygone). |
| [GéométrieSérialiseDSV](1410090121.md) | Sérialise une géométrie en utilisant le format DSV spécifié. |
| [GéométrieSérialiseWKT](1410090108.md) | Sérialise une géométrie au format Well Known Text (WKT). |
| [GéométrieTouche](1410090114.md) | Permet de savoir si deux géométries se touchent. |
| [GéométrieUnion](1410090155.md) | Renvoie la géométrie correspondant à l'union entre deux géométries. |
| [Polyligne2DAjoutePoint](1410090159.md) | Ajoute un nouveau point dans une polyligne en 2 dimensions (polyligne géométrique). |
| [PolyligneGéoAjoutePoint](1410090160.md) | Ajoute un nouveau point dans une polyligne géographique. |


Les types de variables manipulés par les fonctions de gestion des données spatiales sont les suivants :

- Variables correspondant à des géométries en 2 dimensions :
  | [MultiPoint2D](1410090129.md) | Le type **MultiPoint2D** permet de stocker un ensemble de points en 2 dimensions. Il s'agit d'une collection de points : les points ne sont pas connectés entre eux (contrairement à une polyligne). |
  | --- | --- |
  | [MultiPolygone2D](1410090135.md) | Le type **MultiPolygone2D** permet de stocker un ensemble de polygones en 2 dimensions sans intersections entre eux. |
  | [MultiPolyligne2D](1410090131.md) | Le type **MultiPolyligne2D** permet de stocker un ensemble de polylignes en 2 dimensions non connectées entre elles. |
  | [Point2D](1410090100.md) | Le type **Point2D** permet de définir les caractéristiques d'une position dans le plan en 2 dimensions. |
  | [Polygone2D](1410090122.md) | Le type **Polygone2D** permet de définir toutes les caractéristiques avancées d'un polygone dans un plan. |
  | [Polyligne2D](1410090109.md) | Le type **Polyligne2D** permet de définir toutes les caractéristiques avancées d'une polyligne en 2 dimensions. |
- Variables correspondant à des géométries en coordonnées géographiques :
  | [MultiPointGéo](1410090130.md) | Le type **MultiPointGéo** permet de stocker un ensemble de points géographiques. Il s'agit d'une collection de points : les points ici ne sont pas connectés entre eux. |
  | --- | --- |
  | [MultiPolygoneGéo](1410090136.md) | Le type **MultiPolygoneGéo** permet de stocker un ensemble de polygones géographiques sans intersections entre eux. |
  | [MultiPolyligneGéo](1410090133.md) | Le type **MultiPolyligneGéo** permet de stocker un ensemble de polylignes géographiques non connectées entre elles. |
  | [PointGéo](1410090102.md) | Le type **PointGéo** permet de définir toutes les caractéristiques avancées d'une position sur la sphère terrestre (point géographique). |
  | [PolygoneGéo](1410090127.md) | Le type **PolygoneGéo** permet de définir toutes les caractéristiques avancées d'un polygone géographique. |
  | [PolyligneGéo](1410090128.md) | Le type **PolyligneGéo** permet de définir toutes les caractéristiques avancées d'une polyligne géographique. |
