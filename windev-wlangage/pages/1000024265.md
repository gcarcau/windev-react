# <Traitement de texte>.FinModification (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

Signale la fin du regroupement d'un ensemble d'opérations sur un champ Traitement de texte en un seul événement (gestion du "undo/redo").

## Exemple

```wlangage
TT_MonDocument.DébutModification()
TT_MonDocument.Remplace("%NomClient%", Client.Nom)
TT_MonDocument.Remplace("%PrénomClient%", Client.Prénom)
TT_MonDocument.FinModification()
```

## Syntaxe

```wlangage
<Champ Traitement de texte>.FinModification()
```

`<Champ Traitement de texte>` *Nom de champ*
> Nom du champ Traitement de texte à manipuler.

## Remarques

Les modifications effectuées sur le document sont regroupées à partir de l'appel de la fonction [<Traitement de texte>.DébutModification](1000023405.md). Si plusieurs modifications annulables sont effectuées, il suffit d'un seul "Ctrl + Z" pour annuler toutes les opérations effectuées.

**Composante : wd300obj.dll**
