# <Traitement de texte>.Redo (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

Rétablit la dernière action annulée sur un champ Traitement de texte.

## Exemple

```wlangage
// Refait la dernière action annulée sur le champ
TT_MonDocument.Redo()
```

## Syntaxe

```wlangage
<Résultat> = <Champ Traitement de texte>.Redo()
```

`<Résultat>` *Booléen*
> - Vrai si la dernière action annulée a été rétablie,
> - Faux dans le cas contraire.
`<Champ Traitement de texte>` *Nom de champ*
> Nom du champ Traitement de texte à manipuler.

**Composante : wd300mdl.dll**
