# Description du projet : Onglet Ambiance

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

## Présentation

La fenêtre de description du projet permet de configurer de nombreux éléments de votre projet. Cette fenêtre est constituée des onglets suivants :

- L'onglet ["Projet"](2030046.md) qui permet de saisir les informations générales du projet.
- L'onglet "Analyse" qui permet d'associer une ou plusieurs analyses au projet et / ou un modèle UML.
- L'onglet ["Fichiers de données"](2030052.md) qui permet de saisir différentes informations sur les fichiers de données gérés par l'application (uniquement disponible si le projet est lié au moins à une analyse).
- L'onglet "Live data" qui permet de configurer l'affichage des données (provenant des fichiers de données) sous les différents éditeurs.
- L'onglet ["Langues"](9500219.md) qui permet de paramétrer les différentes langues manipulées par le projet ainsi que les options linguistiques à utiliser pour chaque langue.
- L'onglet ["Style"](9500234.md) qui permet de choisir le thème de gabarit, la feuille de styles personnalisée et de personnaliser l'aperçu avant impression. Il est également possible de paramétrer la taille des écrans.
- L'onglet **"Ambiance"** qui permet de choisir l'ambiance du projet, la palette associée , la feuille de styles et les ressources externes.
- L'onglet ["GDS"](9500239.md) qui permet de gérer le travail en groupe (GDS ou GIT).
- L'onglet ["Options"](9500227.md) qui permet de configurer les options de création, de mise à jour, et de sauvegarde des éléments. Cet onglet permet également de gérer la synchronisation des modèles, d'activer le mode strict et de définir la charte de programmation.
- L'onglet ["Avancé"](9500236.md) qui permet de gérer l'utilisation de "Etats & Requêtes", les FAA et le verrouillage de l'application.
- L'onglet ["Compilation"](9500218.md) qui permet de configurer les options de compilation.
- L'onglet ["Télémétrie"](9500223.md) qui permet de configurer les options de télémétrie pour le projet.
   Cette option n'est pas disponible.

## Onglet Ambiance

### Ambiance du projet
L'onglet "Ambiance" de la fenêtre de description du projet permet de connaître et de définir l'ambiance utilisée par le projet. Un aperçu permet de voir l'ambiance en situation.
**Remarque** : Si l'ambiance est modifiée via la fenêtre de description du projet, cette modification est prise en compte uniquement pour les nouvelles pages créées. L'application de l'ambiance sur les pages existantes est réalisée page par page :

1. Ouvrez la page voulue sous l'éditeur.
2. Sous le volet "Page", dans le groupe "Ambiance et styles", cliquez sur "Ambiance".
3. Dans la fenêtre qui s'affiche, sélectionnez l'ambiance voulue et la palette associée.
4. Validez.

### Palette du projet
Les palettes de couleurs définissent un jeu de couleurs qui sont proposées dans tous les sélecteurs de couleurs du projet.
Ces couleurs sont également appliquées sur les styles définis dans l'ambiance du projet afin de permettre de changer rapidement et facilement l'aspect visuel d'un projet.

L'onglet "Ambiance" permet de connaître et de modifier la palette de couleurs associée à l'ambiance.

**Remarque** : Si la palette est modifiée via la fenêtre de description du projet, cette modification est prise en compte uniquement pour les nouvelles pages créées. Le changement de palette sur les pages existantes est réalisée page par page :

1. Ouvrez la page voulue sous l'éditeur.
2. Sous le volet "Page", dans le groupe "Ambiance et styles", déroulez "Palette" et choisissez une des palettes associées à l'ambiance en cours.

La fenêtre de description du projet permet également d'afficher toutes les palettes et de créer une palette de couleurs. Pour plus de détails, consultez [Palettes de couleurs](2016021.md).

### Options de l'ambiance
Il est également possible de :

- Choisir **la langue de l'ambiance**. Les ambiances sont disponibles en Français et en Anglais.
- Appliquer l'ambiance sur les boîtes de dialogue (OuiNon et OKAnnuler) : Si cette option est sélectionnée, les boîtes de dialogue affichées par le site utiliseront les caractéristiques de l'ambiance.

### Feuilles de styles
Il est possible de :

- Sélectionner la ou les feuilles de styles associées au projet.
- Ajouter des ressources externes (fichiers javascript ou feuilles de styles CSS externes). Les feuilles de styles CSS seront automatiquement chargées à l'ouverture du projet.

Pour plus de détails, consultez [Inclure des fichiers Javascript ou une ressource Web](1012027.md).
