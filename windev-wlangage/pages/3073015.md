# SysNomExe (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **Autres** (Procédures stockées)

Renvoie le nom et le chemin complet d'une application.
**Remarque** : Pour récupérer le nom de l'exécutable courant, utilisez la fonction [ExeInfo](3035001.md).

## Exemple

```wlangage
// Récupérer le nom et le chemin complet de l'application en cours
ResNomExe = SysNomExe(SysInstance())
```

## Syntaxe

```wlangage
<Résultat> = SysNomExe(<Instance de l'exécutable>)
```

`<Résultat>` *Chaîne de caractères*
> Nom et chemin complet de l'application spécifiée.
`<Instance de l'exécutable>` *Entier*
> Instance de l'exécutable de l'application à manipuler. L'instance d'une application peut être obtenue avec la fonction [SysInstance](3073018.md).

**Composante : wd300std.dll**
