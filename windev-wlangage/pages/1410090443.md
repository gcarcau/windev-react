# DocEffaceMiseEnForme (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Remplace la mise en forme actuelle de la sélection par la mise en forme par défaut. Ce remplacement est effectuée :

- sur la sélection en cours dans un champ Traitement de texte.
- sur un fragment.

## Exemple

> _(WINDEV)_ // Efface la mise en forme du fragment sélectionné dans le champ Traitement de texte
DocEffaceMiseEnForme(TT_Lettre.Sélection.Fragment)

## Syntaxe

```wlangage
DocEffaceMiseEnForme(<Elément manipulé>)
```

`<Elément manipulé>` *Variable de type docFragment ou nom de champ*
> Elément manipulé. Cet élément peut correspondre :
>
> - au nom du champ Traitement de texte. Dans ce cas, seule la sélection en cours sera manipulée.
> - à une variable de type [docFragment](1000022482.md).

**Classification Métier / UI : Code neutre**

**Composante : wd300mdl.dll**
