# ChaîneSecrète (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Le type **ChaîneSecrète** permet de manipuler des chaînes de caractères contenues dans le coffre-fort à mots de passe.
Le contenu de cette chaîne secrète ne sera jamais visible, notamment dans les cas suivants :

- Utilisation des fonctions permettant d'afficher des boîtes de dialogue (fonction Info par exemple),
- Affichage de la trace.
- Utilisation du débogueur.

De même, il est impossible de transférer le contenu d'une variable de type **ChaîneSecrète** dans un autre type de variable.

## Exemple

```wlangage
s est une ChaîneSecrète
SI EnModeTest ALORS
	s = BaseHFSQL_Tests
SINON
	s = BaseHFSQL_Production
FIN

HPasse("*", s)
```

## Syntaxe

#### Déclarer et initialiser une variable de type "ChaîneSecrète"

```wlangage
<Nom de la variable> est une ChaîneSecrète = <Valeur>OU <Nom de la variable> est une ChaîneSecrète<Nom de la variable> = <Valeur>
```

`<Nom de la variable>` **
> Nom de la variable à déclarer.
`<Valeur>` **
> Valeur donnée à la variable. Cette valeur correspond à l'identifiant d'une chaîne secrète défini dans le coffre-fort à mots de passe du projet (ou de la collection de procédures).

## Remarques

### Valeur par défaut
Une variable de type "ChaîneSecrète" déclarée et non initialisée correspond à une chaîne vide ("").
