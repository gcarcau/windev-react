# Fonctions de gestion des champs TimeLine

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU))

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des champs TimeLine (syntaxe préfixée)](1000020783.md)).
Les fonctions de gestion des champs TimeLine sont les suivantes :

| [TimelineAffiche](1000020683.md) | Réinitialise le contenu d'un champ TimeLine à partir de sa source de données (fichier de données HFSQL par exemple). |
| --- | --- |
| [TimelineAjouteEvénement](1000020400.md) | Ajoute un événement dans un champ TimeLine. |
| [TimelineAjoutePiste](1000020405.md) | Ajoute une nouvelle piste dans un champ TimeLine. |
| [TimelineChangeMode](1000020397.md) | Modifie la période (c'est-à-dire le nombre de secondes, millisecondes, microsecondes, ...) affichée par un champ TimeLine. |
| [TimelineListeEvénement](1000020401.md) | Renvoie :   - la liste des événements compris entre deux moments donnés dans un champ TimeLine, - tous les événements d'un champ TimeLine, - un événement particulier (sélectionné ou survolé). |
| [TimelineSupprimeEvénement](1000020403.md) | Supprime un événement dans un champ TimeLine. |
| [TimelineSupprimePiste](1000020760.md) | Supprime une piste dans un champ TimeLine. |
| [TimelineSupprimeTout](1000020404.md) | Supprime tous les événements et toutes les pistes d'un champ TimeLine. |
