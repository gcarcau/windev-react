# Fonctions Calendrier

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions Calendrier (syntaxe préfixée)](1000017392.md)).
Ces fonctions permettent de manipuler les champs Calendrier ainsi que les champs de saisie de type Date :

| [CalendrierOuvre](1000017291.md) | Dans un champ de saisie de type Date, ouvre une fenêtre popup affichant un calendrier. |
| --- | --- |
| [CalendrierPosition](1000017281.md) | Renvoie le mois affiché dans un champ Calendrier. |
| [CalendrierSelect](1000017283.md) | Renvoie la date sélectionnée dans un champ Calendrier. |
| [CalendrierSélecteur](1000017300.md) | Ouvre un dialogue modal avec un calendrier pour saisir une date. |
| [CalendrierSelectMoins](1000017340.md) | Désélectionne une date dans un champ Calendrier multisélection. |
| [CalendrierSelectOccurrence](1000017282.md) | Renvoie le nombre de jours sélectionnés dans un champ Calendrier. |
| [CalendrierSelectPlus](1000017339.md) | Sélectionne une date dans un champ Calendrier. |
