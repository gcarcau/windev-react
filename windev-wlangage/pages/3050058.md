# MatCrée (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Crée une matrice de 0 ligne et 0 colonne.

## Exemple

```wlangage
// Création d'une matrice
ResCréation = MatCrée("MaMatrice")
```

## Syntaxe

```wlangage
<Résultat> = MatCrée(<Matrice>)
```

`<Résultat>` *Booléen*
> - Vrai si la matrice a été créée,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Matrice>` *Chaîne de caractères*
> Nom de la matrice à créer. Ce nom sera utilisé dans toutes les fonctions de gestion des matrices.

## Remarques

### Existence de la matrice
L'existence de la matrice n'est pas vérifiée. Si la matrice existait auparavant, cette matrice est écrasée. Pour vérifier l'existence d'une matrice, utilisez la fonction [MatExiste](3050076.md).
