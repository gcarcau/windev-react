# iStatusImpressionEtat (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Renvoie l'état de l'impression en cours.
Cette fonction doit être utilisée dans le code de fermeture de l'état.

**Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Imprimer sous Linux](9000078.md).

## Exemple

```wlangage
// Fin de l'impression
SELON iStatusImpressionEtat()
	CAS -2 : Trace("Impression abandonnée")
	CAS 0 : Trace("Impression en cours")
	CAS 1 : Trace("Etat vide : aucune données à imprimer")
FIN
```

## Syntaxe

```wlangage
<Résultat> = iStatusImpressionEtat()
```

`<Résultat>` *Entier*
> Etat de l'impression en cours :
>
> - 1 : Il n'y a pas de données à imprimer
> - 0 : Impression en cours
> - -1 : Aucune impression en cours
> - -2 : Abandon

**Classification Métier / UI : Code neutre**

**Composante : wd300etat.dll**
