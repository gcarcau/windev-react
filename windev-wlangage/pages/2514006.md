# Opacité (Propriété)

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Opacité** permet de connaître et définir le pourcentage d'opacité d'une fenêtre ou des champs présents dans une fenêtre ou une page. Il est ainsi possible de rendre transparente une fenêtre (ou un champ présent dans une fenêtre ou une page).
**Remarques** :

- Cette propriété peut également être appliquée à un champ d'une page.
- Cette propriété peut ne pas être supportée par les anciens navigateurs (Internet Explorer 5.5 et antérieurs, ...).
- Dans le cas d'une variable de type [Couleur](1000019661.md), la valeur de l'opacité n'est pas comprise entre 0 et 100 mais entre 0 et 255.

Nouveauté 2025

> _(WINDEV, Android, iPhone/iPad)_ Cette propriété est désormais disponible sur le champ Cellule à partir de la version 2025 Update 1.

## Exemple

> _(WINDEV)_ // Rendre la fenêtre invisible petit à petit (fade out)
i est un entier
POUR i = 1 À 100
 FEN_FenêtreSaisie.Opacité = 100 - i
FIN
Ferme()

## Syntaxe

#### Connaître le pourcentage d'opacité d'une fenêtre ou d'un champ (d'une fenêtre ou d'une page)

```wlangage
<Pourcentage d'opacité> = <Elément manipulé>.Opacité
```

`<Pourcentage d'opacité>` *Entier*
> Pourcentage d'opacité de l'élément spécifié (fenêtre ou champ). Ce pourcentage est compris entre 0 (fenêtre complètement invisible) et 100 (fenêtre complètement opaque).
`<Elément manipulé>` *Nom de fenêtre, nom de champ ou nom de groupe de champs*
> Nom de l'élément à manipuler :
>
> - Nom de la fenêtre,
>    Non géré.
> - Nom du champ,
> - Nom du groupe de champs.

#### Modifier le pourcentage d'opacité d'une fenêtre ou d'un champ (d'une fenêtre ou d'une page)

```wlangage
<Elément manipulé>.Opacité = <Pourcentage d'opacité>
```

`<Elément manipulé>` *Nom de fenêtre, nom de champ ou nom de groupe de champs*
> Nom de l'élément à manipuler :
>
> - Nom de la fenêtre,
>    Non géré.
> - Nom du champ,
> - Nom du groupe de champs.
`<Pourcentage d'opacité>` *Entier*
> Nouveau pourcentage d'opacité à appliquer à l'élément spécifié (fenêtre ou champ). Ce pourcentage est compris entre 0 (fenêtre complètement invisible) et 100 (fenêtre complètement opaque).

## Remarques

> _(WINDEV)_ Limite : système d'exploitation et carte graphiqueLa propriété Opacité peut être utilisée uniquement sur les systèmes supérieurs à Windows 7.Si la carte graphique ne gère pas l'effet de transparence, la propriété Opacité n'aura aucun effet.

> _(WINDEV)_ Limite : types de fenêtresLe système Windows ne permet pas de gérer l'opacité des fenêtres de type Fille MDI.

> _(Android, iPhone/iPad)_ Opacité de l'Action BarPour gérer l'opacité de l'Action Bar : Affichez la fenêtre de description du champ Action Bar. Dans l'onglet "Détail" : Cochez l'option "Rendre le fond des barres transparent". Spécifiez les barres prises en compte : "Action Bar" ou "Action Bar et barre système". Validez. L'Action Bar est transparente. Il est possible de modifier l'opacité de l'Action Bar avec la propriété Opacité. Pour plus de détails, consultez Description du champ Action Bar.
