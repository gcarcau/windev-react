# PiloteErreur (Fonction)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU))

Pilote le prochain appel de la fonction [Erreur](3021013.md), puis clique automatiquement sur le bouton "OK".

## Exemple

```wlangage
// Fermeture automatique de la prochaine boîte de dialogue Erreur
PiloteErreur()

// Traitement
// ...

Erreur("Une erreur est survenue pendant le traitement.")
// Le message est fermé automatiquement
```

## Syntaxe

```wlangage
PiloteErreur()
```

## Remarques

### Vérification de la fonction
L'existence d'une fonction de pilotage ([PiloteAvertissement](1000009001.md), **PiloteErreur**, [PiloteInfo](1000009006.md), ...) est vérifiée lors de l'appel de la fonction de dialogue associée ([Avertissement](3021009.md), [Erreur](3021013.md), [Info](3021011.md), ...).

### Différence de type de message
L'ordre des fonctions [PiloteXXX](1000009002.md) doit respecter l'ordre d'affichage des fonctions [Erreur](3021013.md), [Info](3021011.md), ... Dans le cas contraire, une erreur fatale sera déclenchée.

**Composante : wd300testexe.dll**
