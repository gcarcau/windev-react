# TélémétrieActive (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Active manuellement la télémétrie. Cette fonction doit être utilisée si l'activation manuelle de la télémétrie a été spécifiée dans les options de télémétrie.
**Remarque** : Les caractéristiques de la télémétrie sont configurées dans la description de la configuration. La description de la configuration est accessible :

- Depuis la fenêtre de description du projet : dans l'onglet "Projet", sélectionnez l'option "Description de la configuration courante".
- Depuis le volet "Explorateur de projet" : affichez le menu contextuel de l'option "Configurations" et sélectionnez "Description".

Pour plus de détails, consultez [Télémétrie : Configuration des applications WINDEV et WINDEV Mobile](1410086582.md).

## Exemple

```wlangage
TélémétrieActive()
```

## Syntaxe

#### Activation manuelle de la télémétrie

```wlangage
TélémétrieActive()
```

#### Activation manuelle de la télémétrie en modifiant le nom du serveur

```wlangage
TélémétrieActive(<Serveur>)
```

`<Serveur>` *Chaîne de caractères*
> Serveur de télémétrie à utiliser. Ce paramètre peut correspondre :
>
> - au nom du serveur de télémétrie,
> - à l'adresse IP du serveur de télémétrie (par exemple "192.54.12.8").

## Remarques

Attention : La télémétrie n'est jamais activée en mode test afin d'éviter de remplir la base de données avec des données partielles. La télémétrie est activée et activable uniquement dans l'application générée.

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
