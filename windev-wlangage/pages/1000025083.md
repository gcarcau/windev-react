# <Source>.VersRubrique (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Affecte la valeur indiquée à une rubrique de l'enregistrement en cours.
**Remarque** : L'utilisation de cette fonction est très rare. Il est conseillé d'utiliser l'affectation directe des rubriques par la syntaxe <NomFichier>.<NomRubrique> = <Valeur>.
Par exemple : Client.Nom = "Dupont".

## Exemple

```wlangage
// Affecte à la seconde rubrique du fichier de données client la valeur Dupont
Client.VersRubrique(2, "Dupont")
```

## Syntaxe

#### Affectation d'une valeur à une rubrique (une valeur pour chaque rubrique d'une rubrique tableau)

```wlangage
<Source>.VersRubrique(<Ordre de la rubrique> [, <Indice>] , <Valeur>)
```

`<Source>` *Type correspondant à la source spécifiée*
> Nom du fichier de données manipulé.
`<Ordre de la rubrique>` *Entier*
> Numéro d'ordre physique de la rubrique dans le fichier de données.
`<Indice>` *Entier optionnel*
> Indice de la rubrique tableau à affecter. Si une rubrique non tableau est affectée, <Indice> doit valoir 1.
`<Valeur>` *Chaîne de caractères ou autre*
> Valeur à affecter à la rubrique. Si la valeur doit être affectée à une rubrique tableau :
>
> - si le paramètre <Indice> a été utilisé, la valeur sera affectée à la rubrique indicée spécifiée.
> - si aucun des paramètres précédent n'a été utilisé, <Valeur> doit contenir toutes les valeurs de la rubrique tableau, séparées par TAB.
>
>
> > _(Hyper File 5.5)_ Il est impossible d'affecter des rubriques tableau.

#### Affectation d'une valeur à une rubrique (une valeur pour une rubrique tableau)

```wlangage
<Source>.VersRubrique(<Ordre de la rubrique> [, <Séparateur Tableau>] , <Valeur>)
```

`<Source>` *Type correspondant à la source spécifiée*
> Nom du fichier de données manipulé.
`<Ordre de la rubrique>` *Entier*
> Numéro d'ordre physique de la rubrique dans le fichier de données.
`<Séparateur Tableau>` *Chaîne de caractères optionnelle*
> Chaîne utilisée pour séparer les valeurs de chaque rubrique tableau. Par défaut, TAB est utilisée.
>
> > _(Hyper File 5.5)_ Il est impossible d'affecter des rubriques tableau.
`<Valeur>` *Chaîne de caractères ou autre*
> Valeur à affecter à la rubrique. Si la valeur doit être affectée à une rubrique tableau :
>
> - si le paramètre <Séparateur Tableau> a été utilisé, <Valeur> doit contenir toutes les valeurs de la rubrique tableau, séparées par le séparateur indiqué
> - si aucun des paramètres précédent n'a été utilisé, <Valeur> doit contenir toutes les valeurs de la rubrique tableau, séparées par TAB.
>
>
> > _(Hyper File 5.5)_ Il est impossible d'affecter des rubriques tableau.

## Remarques

### Ordre des rubriques dans le fichier de données
L'ordre des rubriques dans le fichier de données commence à 1. L'ordre d'une rubrique peut être obtenu via la propriété [Indice](2512040.md).

> _(WINDEV, Windows, Langage Externe, HFSQL Classic, HFSQL Client/Serveur, Procédures stockées, Hyper File 5.5)_ Langage externeLa <Valeur> doit être passée sous forme de chaîne.Il n'est pas possible d'affecter un mémo binaire avec la fonction <Source>.VersRubrique.
