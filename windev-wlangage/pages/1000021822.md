# Zoomer une fenêtre (FAA)

> **Disponible :** **WINDEV** (Windows)

## Présentation

Pour faciliter la lecture des fenêtres, l'utilisateur final peut zoomer le contenu d'une fenêtre à l'aide de la souris.
[image: Zoom d'une fenêtre]**Pour zoomer une fenêtre**, l'utilisateur doit utiliser la touche Ctrl et la roulette de la souris.
**Pour revenir à l'affichage initial**, il suffit d'utiliser l'option "Annuler le zoom" du menu contextuel de la fenêtre (ou la combinaison de touches Ctrl + 0).

Remarque : Si nécessaire, des ascenseurs peuvent apparaître lors du zoom.

## Programmation

### Programmer le zoom
Il est possible de programmer le zoom à appliquer à la fenêtre en utilisant la propriété [Zoom](1000017201.md) sur la fenêtre.
Par exemple :

```wlangage
// Agrandissement à 150%
FEN_Client..Zoom = 150
```

Si le zoom est réalisé par programmation, le menu contextuel de la fenêtre permet d'annuler le zoom.

### Désactiver le zoom
Pour interdire le zoom sur une fenêtre, il suffit d'utiliser la fonction [FAADésactive](1000022018.md) avec la constante *faaZoom*.

### Annuler le zoom
Pour annuler le zoom sur une fenêtre (et revenir à l'état initial), il suffit d'utiliser la fonction [FAAExécute](1000022099.md) avec la constante *faaZoom*.

### Modifier le libellé de l'option permettant d'annuler le zoom (par programmation)
Pour annuler le zoom, l'utilisateur final peut afficher le menu contextuel de la fenêtre (clic droit) et sélectionner l'option "Annuler le zoom".
Pour modifier le libellé de cette option, il suffit d'utiliser la fonction [FAAChangeLibellé](1000022100.md) avec la constante *faaZoom*.
