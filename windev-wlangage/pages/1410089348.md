# Belgique.VérifieBCE (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un numéro BCE (numéro Banque-Carrefour des Entreprises de Belgique servant à identifier une entreprise).

## Exemple

```wlangage
// Test d'une variableMonNuméroBCE est une chaîne = "0436649062"Belgique.VérifieBCE(MonNuméroBCE) // renvoie Vrai // Test d'un champSAI_NuméroBCE = "ABC"Belgique.VérifieBCE(SAI_NuméroBCE) // renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = Belgique.VérifieBCE(<Numéro à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un numéro BCE valide.
> - Faux dans le cas contraire.
`<Numéro à vérifier>` *Nom de champ ou variable de type chaîne*
> Numéro BCE à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.
