# NbEnrLu (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

La propriété **NbEnrLu** permet de connaître le nombre d'enregistrements lus : sélectionnés à la fois par la source de l'état ET par le code de filtre (s'il existe).

## Exemple

```wlangage
// Si plus de 100 enregistrements ont été lus
SI ETAT_EtatClient.NbEnrLu > 100 ALORS
	// L'impression de l'état "ETAT_EtatClient" est arrêtée
	iFinEtat()
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Etat manipulé>.NbEnrLu
```

`<Résultat>` *Entier*
> Nombre d'enregistrements lus.
`<Etat manipulé>` *Nom d'état*
> Nom de l'état à manipuler.

## Remarques

### Nombre d'enregistrements

- La propriété **NbEnrLu** renvoie le nombre d'enregistrements sélectionnés par la source de l'état (requête, vue, zone mémoire ou champ Table).
- La propriété [NbEnrImprimé](2511058.md) renvoie le nombre d'enregistrements sélectionnés à la fois par la source de l'état ET par le code de filtre (s'il existe).
- Dans le cas d'un état sur fichier, les propriétés **NbEnrLu** et [NbEnrImprimé](2511058.md) retournent la même valeur : le nombre d'enregistrements du fichier ET sélectionnés par le code de filtre (s'il existe).
- La propriété [NbEnrTotal](2511047.md) permet de connaître et de modifier le nombre d'enregistrements à imprimer. Le nombre d'enregistrements à imprimer sera compris entre 1 et [NbEnrImprimé](2511058.md).

### Limite
La propriété **NbEnrLu** ne peut pas être utilisée sur un état sans source de données.
