# <Type Buffer>.Décode (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Décode une chaîne de caractères précédemment encodée avec la fonction [<Type Buffer>.Encode](1410087345.md).

## Exemple

```wlangage
// Encodage d'une image en base64
Res est un Buffer = Encode(fChargeBuffer("MonImage.jpg"), encodeBASE64)
// ...
// Décodage de l'image
ImageDécodée est une Image = Res.Décode(encodeBASE64)
```

## Syntaxe

```wlangage
<Résultat> = <Elément à décoder>.Décode([<Format d'encodage/décodage>])
```

`<Résultat>` *Chaîne de caractères ou Buffer*
> Résultat du décodage.
`<Elément à décoder>` *Nom de champ*
> Données à décoder. Ces données ont été encodées avec la fonction [<Type Buffer>.Encode](1410087345.md).
> Attention : La chaîne à décoder doit être du même format que les chaînes par défaut du projet : ANSI ou Unicode.
`<Format d'encodage/décodage>` *Constante de type Entier*
> Indique le type d'encodage effectué. Ce paramètre doit être identique à celui choisi lors du codage.
>
> | *encodeBASE64* (Valeur par défaut) | Format BASE 64 (respecte la norme RFC 4648). Le texte encodé comporte uniquement des caractères imprimables et les RC (Retour Chariot). _(PHP)_ Les RC (Retour Chariot) sont supprimés. |
> | --- | --- |
> | *encodeBASE64SansRC* | Format BASE 64 (respecte la norme RFC 4648) sans les RC (Retour Chariot). Le texte encodé comporte uniquement des caractères imprimables. _(PHP)_ Cette constante n'est pas disponible. |
> | *encodeBASE64URL* | Format BASE 64 URL (respecte la norme RFC 4648). Le texte encodé comporte uniquement des caractères imprimables. _(PHP)_ Cette constante n'est pas disponible. |
> | *encodeBASE85* | Format BASE 85. Le texte encodé comporte uniquement des caractères imprimables. _(Android, Widget Android)_ Format non supporté. _(PHP)_ Cette constante n'est pas disponible. |
> | *encodePCS* | Format ASCII. Le texte encodé comporte uniquement des caractères imprimables. _(Android, Widget Android)_ Format non supporté. _(PHP)_ Cette constante n'est pas disponible. |
> | *encodeURLVersAnsi* | Format URL. Le texte encodé comporte uniquement des caractères autorisés dans une URL. Le texte décodé est une chaîne ANSI. Cette constante correspond à la constante *encodeURLDepuisAnsi* utilisée dans la fonction [<Type Buffer>.Encode](1410087345.md). _(PHP)_ Cette constante n'est pas disponible. |
> | *encodeURLVersUnicode* | Format URL. Le texte encodé comporte uniquement des caractères autorisés dans une URL. Le texte décodé est une chaîne Unicode. Cette constante correspond à la constante *encodeURLDepuisUnicode* utilisée dans la fonction [<Type Buffer>.Encode](1410087345.md). _(PHP)_ Cette constante n'est pas disponible. |
> | *encodeURLVersUTF8* | Format URL. Le texte encodé comporte uniquement des caractères autorisés dans une URL. Le texte décodé est une chaîne UTF-8. Cette constante correspond à la constante *encodeURLDepuisUTF8* utilisée dans la fonction [<Type Buffer>.Encode](1410087345.md). _(PHP)_ Cette constante n'est pas disponible. |
> | *encodeUUEncode* | Format UUEncode. Le texte encodé comporte uniquement des caractères imprimables. _(Android, Widget Android)_ Format non supporté. |

## Remarques

### Format des chaînes de caractères à décoder
La chaîne à décoder doit être du même format que les chaînes par défaut de la configuration de projet en cours : ANSI ou Unicode.
Pour connaître ou modifier le format des chaînes par défaut :

1. Affichez la fenêtre de description de la configuration en cours : dans le volet "Explorateur de projet", affichez le menu contextuel de "Configurations" et sélectionnez "Description".
2. L'onglet "Unicode" permet de connaître le type de chaînes de caractères géré par défaut.
