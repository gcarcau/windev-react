# Forme (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Forme** permet de gérer les différentes formes d'un élément. Cette propriété est disponible sur :

- une variable de type [MarqueurImage](1000025796.md).
- une variable de type [Diagramme](1410088055.md).
- une variable de type [VisiteGuidée](1410090170.md).
- une variable de type [VisiteGuidéeEtape](1410090178.md).
