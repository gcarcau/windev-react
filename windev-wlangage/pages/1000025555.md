# CartePopupAffichée (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Permet de savoir si la popup d'un marqueur du champ Carte est affichée.

## Exemple

```wlangage
MonMarqueur est un Marqueur
SI CartePopupAffichée(CARTE_MaCarte, MonMarqueur) ALORS
	...
FIN
```

## Syntaxe

```wlangage
<Résultat> = CartePopupAffichée(<Champ Carte> , <Marqueur>)
```

`<Résultat>` *Booléen*
> - Vrai si la popup du marqueur est affichée,
> - Faux dans le cas contraire.
`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler. Si ce paramètre correspond à une chaîne vide (""), le champ Carte auquel appartient l'événement en cours sera utilisé.
`<Marqueur>` *Variable de type Marqueur*
> Nom de la variable de type [Marqueur](1000019940.md) dont on veut savoir si une popup est affichée.

## Remarques

- Pour afficher la popup, utilisez la fonction [CarteAffichePopup](1000025553.md).
- Pour fermer la popup, utilisez la fonction [CarteFermePopup](1000025554.md).
