# La structure Groupe

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

## Présentation

La structure Groupe est une structure prédéfinie du WLangage (aucune déclaration n'est nécessaire). Cette structure permet de :

- créer ou modifier un groupe de contacts.
- récupérer le contenu d'un groupe de contacts.

## Les différentes variables de la structure Groupe

La structure est composée des membres suivants :

| **mGroupe.Contact** | Tableau de chaîne de caractères.  Nom des contacts présents dans le groupe.   Pour accéder au nom des différents contacts du groupe, utilisez le format suivant :  mGroupe.Contact[<Num contact>] Où <Num contact correspond au numéro du contact voulu. Le nombre de contacts présents dans le groupe peut être connu grâce à la variable mGroupe.NbContact. |
| --- | --- |
| **mGroupe.Description** | Chaîne de caractères.  Description du groupe de contacts. |
| **mGroupe.EnDehors** | Booléen.  Indique s'il y a un groupe de contacts courant. |
| **mGroupe.ID** | Chaîne de caractères. Identifiant unique du groupe de contacts |
| **mGroupe.NbContact** | Entier.  Nombre de contacts présents dans le groupe. |
| **mGroupe.Nom** | Chaîne de caractères. Nom du groupe de contacts. |
