# <Variable mongoBase>.SupprimeBase (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Supprime une base MongoDB et toutes ses collections.

## Exemple

```wlangage
CnxBaseMDB est un mongoConnexion
MaBaseMongo est un mongoBase
MaBaseMongo = CnxBaseMDB.BaseDeDonnées["CRM"]
MaBaseMongo.SupprimeBase()
```

## Syntaxe

```wlangage
<Résultat> = <Base>.SupprimeBase()
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème. La fonction [ErreurInfo](3013008.md) permet d'identifier l'erreur.
`<Base>` *Variable de type mongoBase*
> Nom de la variable de type [mongoBase](1000022410.md) correspondant à la base MongoDB à supprimer.
