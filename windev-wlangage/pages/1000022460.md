# BalayageVertical (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **BalayageVertical** permet de connaître et de modifier le sens du balayage dans une fenêtre interne avec balayage.
Remarque : Cette propriété correspond à l'option "Orientation du balayage" présente dans l'onglet "UI" de la description du champ Fenêtre Interne.

## Exemple

```wlangage
// Evénement : Changement d'orientation de la fenêtre
// Le code suivant permet de toujours balayer sur le même axe
FI_MaFenInterne1.BalayageVertical = PAS FI_MaFenInterne1.BalayageVertical
```

## Syntaxe

#### Connaître le sens du balayage

```wlangage
<Résultat> = <Champ Fenêtre interne>.BalayageVertical
```

`<Résultat>` *booléen*
> - Vrai si le balayage s'effectue verticalement,
> - Faux dans le cas contraire : le balayage s'effectue horizontalement.
`<Champ Fenêtre interne>` *Nom de champ*
> Nom du champ Fenêtre interne manipulé.

> Non disponible pour une application Android

Modifier le sens du balayage Masquer les détails
<Champ Fenêtre interne>.BalayageVertical = <Sens>

 <Champ Fenêtre interne> : Nom de champNom du champ Fenêtre interne manipulé. <Sens> : booléenVrai si le balayage doit s'effectuer verticalement, Faux si le balayage doit s'effectuer horizontalement.

## Remarques

Cette propriété est sans effet si la fonctionnalité de balayage n'est pas activée sur le champ Fenêtre interne. Pour plus de détails, consultez [Changement du contenu d'une fenêtre par balayage](1013277.md).
> _(Android)_ Cette propriété est disponible en lecture seulement.
