# Fonctions de gestion des champs Interrupteur (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions permettant de gérer les champs Interrupteur via une syntaxe préfixée sont les suivantes :

| [<Interrupteur>.Ajoute](1000021291.md) | Ajoute une nouvelle option dans un champ Interrupteur. |
| --- | --- |
| [<Interrupteur>.Insère](1000021307.md) | Insère une nouvelle option dans un champ Interrupteur. |
| [<Interrupteur>.Occurrence](1000021308.md) | Renvoie le nombre d'options présentes dans un champ Interrupteur. |
| [<Interrupteur>.Supprime](1000021309.md) | Supprime une option d'un champ Interrupteur. |
