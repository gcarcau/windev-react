# Alias (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Alias** permet de connaître l'alias d'un élément. Cette propriété est utilisable sur :

- un élément WINDEV/WEBDEV/WINDEV Mobile :
  - pour connaître ou de modifier l'alias d'une fenêtre (WINDEV).
  - pour connaître ou de modifier l'alias d'un volet d'onglet dynamique (WINDEV).
  - pour connaître le nom interne HTML / Javascript d'un champ (WEBDEV).
   Pour plus de détails, consultez l'aide de la propriété [Alias](2510004.md).
- une variable de type [mongoGridFSInfoFichier](1000022417.md).
- une variable de type [docStyle](1000022486.md).
- une variable de type [Description d'Option](1000023072.md).
- une variable de type [Description de valeur](1000023061.md).
- une variable de type [YAML](1000024438.md).
- Nouveauté Abonnement
  une propriété [OptionsOuverture](1410091299.md) d'une variable de type [Fenêtre](1410091366.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
- Nouveauté Abonnement
  une variable de type [OptionsOuvertureFenêtre](1410091298.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
