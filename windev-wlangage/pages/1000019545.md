# AgendaMode (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Mac Catalyst)

Renvoie le mode d'affichage d'un champ Agenda : jour, semaine, mois, ...
Remarque : La fonction [AgendaChangeMode](1000019497.md) permet de modifier le mode d'affichage du champ Agenda.

## Exemple

```wlangage
// Alterne entre l'affichage par jour et par mois
SI AgendaMode(AGD_MonAgenda) = agzJour ALORS
	AgendaChangeMode(AGD_MonAgenda, agzMois)
SINON
	AgendaChangeMode(AGD_MonAgenda, agzJour)
FIN
```

## Syntaxe

```wlangage
<Résultat> = AgendaMode(<Champ Agenda>)
```

`<Résultat>` *Constante de type Entier*
> Plage de temps affichée par le champ Agenda :
>
> | *agzJour* | Le champ Agenda affiche une journée. |
> | --- | --- |
> | *agzMois* | Le champ Agenda affiche un mois complet. |
> | *agzNbJourPersonnalisé* | Affiche le champ Agenda sur le nombre de jours précisé grâce à la fonction [AgendaChangeMode](1000019497.md). _(WEBDEV - Code Serveur, PHP)_ Cette constante n'est pas disponible. |
> | *agzSemaine* | Le champ Agenda affiche une semaine complète (ou partielle si un nombre de jours a été précisé grâce à la fonction [AgendaChangeMode](1000019497.md)). |
> | *agzSemaineSur5* | Le champ Agenda affiche une semaine sur 5 jours (sans le week-end). |
`<Champ Agenda>` *Nom de champ*
> Nom du champ Agenda à manipuler. Ce champ peut correspondre :
>
> - au champ Agenda d'une fenêtre.
> - au champ Agenda d'un état.
> - au champ Agenda d'une page.

## Remarques

### Compatibilité
La fonction **AgendaMode** remplace la fonction [AgendaZoom](1000018884.md) (conservée par compatibilité).

### Equivalences
Les lignes de code suivantes sont équivalentes :

```wlangage
AgendaChangeMode(AGD_Agenda, agzSemaine, 5)
```

et

```wlangage
AgendaChangeMode(AGD_Agenda, agzSemaineSur5)
```

Dans les 2 cas, la fonction **AgendaMode** renvoie la constante *agzSemaineSur5*.
