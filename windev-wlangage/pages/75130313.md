# Table,Insere (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Insère un élément dans une table à une position donnée.

## Exemple

```wlangage
// En CAPPELWD("Table,Insere,TableProd,10=%s",Ligne);
```

```wlangage
// En PascalAPPELWD('Table,Insere,TableProd,10='+Ligne);
```

```wlangage
// En VBcall APPELWD("Table,Insere,TableProd,10="+Ligne)
```

## Syntaxe

```wlangage
Table,Insere(<Nom de la table> , <Indice> , <Valeur de la ligne>)
```

`<Nom de la table>` *Chaîne de caractères*
> Nom de la table à manipuler.
`<Indice>` *Chaîne de caractères*
> Indice de l'élément dans la table.
`<Valeur de la ligne>` *Chaîne de caractères*
> Valeur de la ligne à insérer.

## Remarques

### Notes

- Après la fonction **Table,Insere**, la table n'est pas en saisie. Pour pouvoir saisir dans la table, il faut appeler [Ecran,Saisie](75130265.md).
- Si la table comporte plusieurs colonnes, il faut séparer chaque colonne par la valeur numérique de [TAB] (code binaire 9) :
  - Exemple en C :
    ```wlangage
    APPELWD("Table,Insere,TabCli,14=DUPOND\tJean");
    ```
  - Exemple en Pascal :
    ```wlangage
    APPELWD('Table,Insere,TabCli,14=DUPOND'+#9+'Jean');
    ```
  - Exemple en VB :
    ```wlangage
    call APPELWD("Table,Insere,TabCli,14=DUPOND"+CHR$(9)+"Jean")
    ```

### Table fichier

- Dans le cas d'une table fichier, l'enregistrement n'est pas inséré dans le fichier, il faut appeler la fonction [Table,Enregistre](75130312.md).
- Pour modifier le fichier associé à une table, il ne faut par utiliser la fonction HAjoute : il faut utiliser les fonctions **Table,Insere** et [Table,Enregistre](75130312.md).
