# MultiPointGéo (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Le type **MultiPointGéo** permet de stocker un ensemble de points géographiques. Il s'agit d'une collection de points : les points ici ne sont pas connectés entre eux.
Une variable de type **MultiPointGéo** peut servir à stocker un ensemble de points dans un seul et même enregistrement HFSQL, sans avoir à utiliser un enregistrement par point. Ce type de variable est nécessaire par exemple si l'ensemble de points correspond à l'entité manipulée par un programme (dans ce cas, chaque point n'est pas manipulé indépendamment).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
monPoint est un PointGéo
mltp est un MultiPointGéo
monPoint.Latitude = 26.152
monPoint.Longitude = 63.2101221
mltp.Point.Ajoute(monPoint)
monPoint.Latitude = 27.152
monPoint.Longitude = 64.2101221
mltp.Point.Ajoute(monPoint)
monPoint.Latitude = 27.162
monPoint.Longitude = 63.2102221
mltp.Point.Ajoute(monPoint)
monPoint.Latitude = 26.252
monPoint.Longitude = 63.2121221
mltp.Point.Ajoute(monPoint)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type MultiPointGéo
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **MultiPointGéo** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Point | Tableau de [PointGéo](1410090102.md) | Points de la variable. |
| Type | Constante de type Entier | Type de la géométrie en cours. Dans le cas d'un ensemble de points géographiques, correspond à la constante *tgMultiPointGéo*. Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfMultiPointGéo*. **Cette propriété est disponible en lecture uniquement.** |
