# Evénement (Type de variable)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le type **Evénement** permet de définir toutes les caractéristiques avancées d'un événement : anniversaire, fête, ...
Les caractéristiques de cet événement peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.

Ce type de variable est utilisé par les variables de type [Contact](1000020254.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Récupère la date d'anniversaire d'un contact
sDate est une chaîne
POUR TOUT evt DE MonContact.Evénement
	SI evt.Type = evtAnniversaire ALORS
		sDate = evt.DateBrute
		RETOUR
	FIN
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type Evénement
Les propriétés suivantes peuvent être utilisées pour manipuler un événement :

| **Nom de la propriété** | **Type manipulé** | **Effet** |
| --- | --- | --- |
| DateBrute | Chaîne de caractères | Date de début de l'événement. La chaîne de caractères est non formatée. |
| Etiquette | Chaîne de caractères | Etiquette pour les types d'événement personnalisé (Optionnel). Si la propriété **Type** ne correspond pas à la constante *evtPersonnalisé*, la valeur de cette propriété sera ignorée. |
| Type | Constante de type Entier | _(Android)_ Type d'événement : evtAnniversaire : Anniversaire / date de naissance. evtAutre : autres types.evtFête : Fête.evtPersonnalisé : type personnalisé correspondant à la valeur de la propriété Etiquette. _(iPhone/iPad, Widget IOS, Mac Catalyst)_ Type d'événement : evtFête : Fête.evtPersonnalisé : type personnalisé correspondant à la valeur de la propriété Etiquette. |

## Remarques

### Réinitialisation
Pour réinitialiser le contenu d'une variable de type **Evénement**, il est possible d'utiliser la fonction [VariableRAZ](3013069.md).
