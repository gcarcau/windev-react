# WebserviceLitTokenUtilisateur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Récupère le token d'autorisation ("access token") reçu par le webservice qui est en cours d'exécution.

## Exemple

```wlangage
soit sToken = WebserviceLitTokenUtilisateur()
soit sTokenDécodé = AuthIntrospecteToken(sToken, oauth2AccessToken, sURL)
// Inspecte le contenu de sTokenDécodé
```

## Syntaxe

```wlangage
<Résultat> = WebserviceLitTokenUtilisateur()
```

`<Résultat>` *Chaîne de caractères*
> Token d'autorisation reçu par le webservice (au format JSON).

**Classification Métier / UI : Code métier**
