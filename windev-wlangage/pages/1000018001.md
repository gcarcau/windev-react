# gglDocument (Type de variable)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Le type **gglDocument** permet de manipuler un document Google. Ce document a été créé par la fonction [GglEnvoieDocument](1000017368.md). Les caractéristiques de ce document peuvent être connues à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Connexion
Cnx est une gglConnexion
Cnx.Email = "balthazar@gmail.com"
Cnx.MotDePasse = "azerty"
Cnx.NomApplication = "MonAppli-03"
SI GglConnecte(Cnx) = Faux ALORS
	Erreur(ErreurInfo())
SINON
	// Récupération du tableau des documents
	tabDocs est un tableau de gglDocument = GglListeDocument(Cnx)
	// Parcours des documents
	Doc est un gglDocument
	POUR TOUT Doc DE tabDocs
		Trace(Doc.Titre)
	FIN
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type gglDocument
Les propriétés suivantes peuvent être utilisées pour manipuler un document Google (ces propriétés sont disponibles en lecture uniquement) :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| DateMiseAJour | DateHeure | Date de la dernière mise à jour du document. **Remarque** : La date est une date UTC (en temps universel). |
| Identifiant | Chaîne de caractères | Identifiant du document. |
| Suivi | Booléen | - Vrai si le document est marqué comme "Suivi", - Faux dans le cas contraire. |
| Titre | Chaîne de caractères | Titre du document. |
| TypeMIME | Chaîne de caractères | Type MIME du document.  Remarque : Pour plus de détails sur les types MIME autorisés, consultez    - Types standards : [http://fr.wikipedia.org/wiki/Type_MIME](http://fr.wikipedia.org/wiki/Type_MIME) - Types spécifiques Google Drive : [https://developers.google.com/drive/web/mime-types](https://developers.google.com/drive/web/mime-types) |
