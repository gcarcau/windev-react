# Information 2105 : Cette fonction a été renommée

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Cause

Vous tentez d'utiliser une fonction du WLangage existante dans une version précédente de WINDEV. Cette fonction a été renommée. Vous devez utiliser la nouvelle fonction.
