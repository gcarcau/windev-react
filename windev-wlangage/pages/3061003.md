# GraveurAnnuleGravure (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Annule la gravure en cours de réalisation. Cette gravure a été lancée grâce à la fonction [GraveurEnregistre](3061006.md).
**Remarque** : Lors de l'annulation de la gravure, la compilation en cours est automatiquement supprimée.

## Exemple

```wlangage
// Gravure du CD
GraveurEnregistre()
...
// Annuler la gravure en cours
ResAnnulation est un booléen
ResAnnulation = GraveurAnnuleGravure()
// Demande d'annulation prise en compte ?
SI ResAnnulation = Vrai ALORS
	// Etat du graveur
	SI GraveurEtat() = graveurInactif ALORS
		Info("La gravure a été annulée")
	SINON
		Info("La demande d'annulation a été prise en compte mais n'a pas encore été réalisée")
	FIN
SINON
	// Détail de l'erreur
	Erreur(ErreurInfo(errMessage))
FIN
```

## Syntaxe

```wlangage
<Résultat> = GraveurAnnuleGravure()
```

`<Résultat>` *Booléen*
> - Vrai si la demande d'annulation de la gravure a été prise en compte. Pour savoir si l'annulation est effectivement réalisée, utilisez la fonction [GraveurEtat](3061007.md).
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md).

## Remarques

### Compilation
Une compilation correspond à l'ensemble des fichiers à graver sur un CD ou DVD. Cette compilation sera prise en compte lors du prochain appel de la fonction [GraveurEnregistre](3061006.md).
Une compilation est automatiquement créée lors du premier appel de la fonction [GraveurAjouteFichier](3061001.md) ou de la fonction [GraveurAjouteRépertoire](3061002.md). Une seule compilation à la fois peut être créée.

Une compilation est automatiquement supprimée :

- soit lors du changement du type du CD/DVD à graver (fonction [GraveurTypeMédia](3061013.md)).
- soit lors de la sélection du graveur utilisé par défaut (fonction [GraveurSélectionne](3061012.md)).
- soit après l'appel de la fonction [GraveurEnregistre](3061006.md) (uniquement si la gravure a été lancée, <Résultat> à Vrai).
- soit lors de l'annulation de la gravure (fonction **GraveurAnnuleGravure**).
- soit lors de la fermeture de l'application WINDEV ou du site WEBDEV en cours.

### Configuration nécessaire

> _(WINDEV)_ La gravure de CD est disponible uniquement sous Windows XP et supérieur. La gravure de DVD est disponible sous Windows Vista, et sous Windows XP en utilisant la mise à jour KB932716 pour Windows XP (cette mise à jour doit être téléchargée depuis le site de Microsoft et installée car elle n'est pas prise en compte par le mécanisme de Live Update).

> _(WEBDEV - Code Serveur)_ La gravure de CD et DVD sera réalisée sur le serveur Web. Pour graver des CD ou des DVD, le serveur doit être sous Windows XP ou supérieur. Pour graver des CD sous Windows 2003 Serveur, il est nécessaire d'activer le service de gravure IMAPI (nommée "Service COM de gravage de CD IMAPI"). Pour graver des DVD sous Windows 2003 Serveur, il est nécessaire d'installer en plus la mise à jour KB932716.

**Composante : wd300grv.dll**
