# PartieEntière (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Renvoie la partie entière d'un nombre. La partie entière d'un nombre est le plus grand entier relatif inférieur ou égal au nombre. Par exemple :

- la partie entière de 3,5 est 3.
- la partie entière de -3,5 est -4.

## Exemple

```wlangage
// Partie entière de 16.999
ResPartieEntière = PartieEntière(16.999)
// Renvoie 16
// Pour obtenir 17, utiliser la fonction Arrondi
```

## Syntaxe

```wlangage
<Résultat> = PartieEntière(<Nombre>)
```

`<Résultat>` *Réel*
> Partie entière recherchée. Correspond au plus grand entier inférieur ou égal à <Nombre>.
`<Nombre>` *Réel*
> Nombre à manipuler.
