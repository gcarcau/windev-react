# Chemin (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Chemin** permet de connaître et de modifier un chemin. Cette propriété est utilisable sur :

- une variable de type [gglParamètreCarte](1000017505.md).
- une variable de type [rssFlux](1000017795.md).
- une variable de type [rssCloud](1000017785.md).
- une variable de type [Cookie](1000019222.md).
- une variable de type [hdfsInformation](1000021973.md).
- une variable de type [URI](1000024027.md).
- une variable de type [FichierGgl](1410089586.md).
