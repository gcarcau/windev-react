# dSauveImageTIFF (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Sauve une image au format TIFF soit dans un fichier, soit en mémoire.

## Exemple

```wlangage
// Création d'un fichier TIFF de deux pages
tabImage est un tableau de 2 Image
tabImage[1].Image = "C:\MesImages\Image1.bmp"
tabImage[2].Image = "C:\MesImages\Image2.bmp"
dSauveImageTIFF(tabImage, "MonFichier.TIFF")
```

## Syntaxe

#### Sauvegarder une image TIFF dans un fichier

```wlangage
<Résultat> = dSauveImageTIFF(<Images> , <Nom du fichier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'image a été sauvegardée,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Images>` *Tableau d'images ou variable de type Tiff*
> - Tableau contenant les images pour chaque page du fichier TIFF.
> - Nom de la variable de type [Tiff](1000021025.md) à manipuler.
`<Nom du fichier>` *Chaîne de caractères*
> Nom et chemin complet (ou relatif) du fichier TIFF à créer. Un chemin de type UNC peut être utilisé. L'extension du fichier n'est pas obligatoire.
> **Attention** :
>
>
> - Pour que l'image soit sauvée, le répertoire de destination doit exister.
> - L'existence du fichier TIFF n'est pas vérifiée. Si ce fichier existe, il est automatiquement écrasé.

#### Sauvegarder une image TIFF en mémoire

```wlangage
<Résultat> = dSauveImageTIFF(<Images> , <enMémoire>)
```

`<Résultat>` *Buffer*
> Chaîne d'octets contenant l'image au format TIFF. Cette chaîne d'octets peut être par la suite affectée à un champ Image, enregistrée dans un fichier (fonction [fSauveTexte](3036046.md)), ...
`<Images>` *Tableau d'images ou variable de type Tiff*
> - Tableau contenant les images pour chaque page du fichier TIFF.
> - Nom de la variable de type [Tiff](1000021025.md) à manipuler.
`<enMémoire>` *Constante*
> *enMémoire* : Constante permettant de sauvegarder une image en mémoire.

**Composante : wd300pnt.dll**
