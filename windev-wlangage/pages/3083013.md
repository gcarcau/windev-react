# ZoneRépétéeModifie (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Modifie les valeurs des attributs dans une répétition d'un champ Zone répétée.
**Remarque** : Il est conseillé d'utiliser la fonction [ZoneRépétéeModifieLigne](3083015.md). En effet, la fonction [ZoneRépétéeModifieLigne](3083015.md) permet d'insérer :

- des caractères TAB dans les attributs/champs.
- des valeurs de n'importe quel type dans les attributs/champs.

> _(WINDEV, Etats et Requêtes, Android, iPhone/iPad, Java, Code Utilisateur (MCU))_ Pour les champs Zone répétée sans attributs, il est conseillé de modifier directement la valeur des champs concernés. Pour plus de détails, consultez le paragraphe "Modifier un champ Zone répétée sans attributs".

## Exemple

```wlangage
// Modification d'une répétition dans un champ Zone répétée
ZoneRépétéeModifie(ZR_Zone1, NomProduit + TAB + CodeProduit, Indice)
```

```wlangage
// Modifie une valeur dans le champ Zone répétée en 12ème position
ZoneRépétéeModifie(ZR_Zone1, Nom + TAB + Prenom + TAB + ...
	NumTel + TAB + NumFax, 12)
```

## Syntaxe

```wlangage
ZoneRépétéeModifie(<Champ Zone répétée> , <Valeur> [, <Indice>])
```

`<Champ Zone répétée>` *Nom de champ*
> Nom du champ Zone répétée à manipuler.
> Si ce paramètre est égal à chaîne vide (""), la modification sera effectuée sur le champ Zone répétée en cours.
`<Valeur>` *Chaîne de caractères*
> Liste des valeurs modifiées. Ce paramètre doit être de la forme :
>
>
> ```wlangage
> <Valeur 1> + TAB + ... + <Valeur N>
> ```
>
>
>
> Les différentes valeurs doivent être indiquées dans l'ordre des attributs (fenêtre de description du champ Zone répétée).
> Pour ne pas spécifier de valeur pour un attribut, utilisez une chaîne vide ("") ou 0 (selon le type de l'attribut).
`<Indice>` *Entier optionnel*
> Indice de la répétition à modifier.
>
> - Si ce paramètre n'est pas précisé, la modification sera effectuée sur l'élément en cours.
> - Si <Indice> est supérieur au nombre de répétitions, la fonction **ZoneRépétéeModifie** est équivalente à la fonction [ZoneRépétéeAjoute](3083006.md).

## Remarques

### Conditions d'utilisation
La fonction **ZoneRépétéeModifie** peut être utilisée indifféremment sur :

- un champ Zone répétée fichier,
- un champ Zone répétée par programmation.

> _(WEBDEV - Code Navigateur)_ Cette fonction n'est pas disponible sur les champs Zone répétée linéaire. Cette fonction est disponible uniquement sur les champs Zone répétée en mode navigateur.

> _(WEBDEV - Code Serveur, PHP)_ Cette fonction est disponible pour les champs Zone répétée en mode Ajax, les champs Zone répétée en mode classique et les champs Zone répétée linéaire.

> _(PHP)_ La fonction ZoneRépétéeModifie peut être utilisée uniquement sur un champ Zone répétée par programmation.

### Tri
Si la fonction **ZoneRépétéeModifie** modifie un attribut de tri du champ Zone répétée en cours, le tri sur cet attribut sera annulé.

### Manipulation d'un mémo binaire
Pour modifier un mémo binaire dans un champ Zone répétée, utilisez la fonction [ZoneRépétéeModifieLigne](3083015.md).

> _(WINDEV, Etats et Requêtes, Android, iPhone/iPad, Java, Code Utilisateur (MCU))_ Modifier un champ Zone répétée sans attributsPour modifier un champ Zone répétée sans attributs, il est conseillé de modifier directement la valeur des champs concernés.Par exemple :

// Modification de la valeur des champs
// du champ Zone répétée "ZR_Zone1" pour la répétition 23
ZR_Zone1[23].ChampNom = "Hobbes"
ZR_Zone1[23].ChampPrénom = "Samantha"
