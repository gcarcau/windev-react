# FormatCouleur (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **FormatCouleur** permet de gérer le format de la couleur (couleur ou niveau de gris). Cette propriété est disponible sur :

- une variable de type [Scanneur](1410087808.md),
- une variable de type [pdfParamètre](1410087857.md).
