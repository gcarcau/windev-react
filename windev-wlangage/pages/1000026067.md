# <Variable websocketClient>.Déconnecte (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Déconnecte un client actuellement connecté sur un serveur de WebSocket.

## Exemple

```wlangage
// Récupère la liste des clients
tabClients est un tableau de websocketClient = WebSocketListeClientConnecté()
// Déconnecte certains clients
POUR TOUT oClient DE tabClients
	SI oClient.Déconnecte() ALORS
		oClient.Déconnecte()
	FIN
FIN
```

## Syntaxe

```wlangage
<Client>.Déconnecte()
```

`<Client>` *Variable de type websocketClient*
> Nom de la variable de type [websocketClient](1000025952.md) correspondant au client à déconnecter.

## Remarques

- Lors de la déconnexion du client, le traitement de déconnexion du client est appelé.
- **Cette fonction est asynchrone**: la fonction ne fait que demander la déconnexion du client. La déconnexion effective du client peut intervenir ultérieurement (et en particulier après l'exécution de la fonction **<Variable websocketClient>.Déconnecte**). La fonction **<Variable websocketClient>.Déconnecte** ne renvoie jamais d'erreur (par exemple si le client s'est/a été déconnecté entre temps).
