# MemPositionne (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Positionne la zone mémoire sur un élément.

## Exemple

```wlangage
// Positionne sur l'élément 7 dans la zone mémoire "MaZoneMémoire"
ResPosition = MemPositionne("MaZoneMémoire", 7)
```

## Syntaxe

```wlangage
<Résultat> = MemPositionne(<Zone mémoire> , <Indice>)
```

`<Résultat>` *Chaîne de caractères*
> Valeur de retour de l'élément spécifié, définie par les fonctions [MemAjoute](3053002.md) ou [MemModifie](3053007.md).
`<Zone mémoire>` *Chaîne de caractères*
> Nom de la zone mémoire, défini par la fonction [MemCrée](3053005.md).
`<Indice>` *Entier*
> Indice de l'élément sur lequel la zone mémoire doit être positionnée. L'indice d'un élément peut être obtenu grâce aux fonctions [MemEnCours](3053008.md) ou [MemRecherche](3053015.md).

## Remarques

### Existence de la zone mémoire
L'existence de la zone mémoire n'est pas vérifiée.
Si la zone mémoire spécifiée n'existe pas, une erreur du WLangage est générée lors de l'exécution de la fonction **MemPositionne**.

Pour vérifier l'existence d'une zone mémoire, utilisez la fonction [MemExiste](3053006.md).

**Classification Métier / UI : Code neutre**

**Composante : wd300std.dll**
