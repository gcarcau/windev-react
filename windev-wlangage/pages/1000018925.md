# JSFinEvénement (Fonction)

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur)

Supprime l'association d'une fonction WLangage navigateur à événement (mis en place grâce à la fonction [JSEvénement](1000018924.md)). La procédure associée à l'événement ne sera plus appelée.
**Remarque** : L'interception des événements est automatiquement arrêtée lorsque la page associée est fermée.

## Exemple

```wlangage
// Annule l'interception de tous les clics sur la page
// gnClic est un entier renvoyé par la fonction JSEvénement
JSFinEvénement(gnClicPage)
```

## Syntaxe

```wlangage
<Résultat> = JSFinEvénement(<Numéro de l'événement>)
```

`<Résultat>` *Booléen*
> - Vrai si l'interception de l'événement a été annulée,
> - Faux en cas d'erreur (numéro d'événement incorrect par exemple).
`<Numéro de l'événement>` *Entier*
> Numéro de l'événement à annuler. Cet entier a été renvoyé par la fonction [JSEvénement](1000018924.md).

**Composante : WDJS.DLL**
