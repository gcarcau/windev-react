# SaaSEstConnecté (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Détermine si la connexion au webservice SaaS est toujours en cours.
**Rappel** : La connexion au webservice SaaS a été effectuée avec la fonction [SaasConnecte](1000018959.md). Lorsque la connexion a été effectuée, le webservice SaaS teste périodiquement la validité de la connexion toutes les 4 minutes par un appel automatique de la fonction **SaaSEstConnecté**.

## Exemple

```wlangage
SI SaaSEstConnecté() = Faux ALORS
	SI SaaSConnecte("login", "motdepasse") = Vrai ALORS
		Info("Connexion rétablie")
	FIN
FIN
```

## Syntaxe

```wlangage
<Résultat> = SaaSEstConnecté()
```

`<Résultat>` *Booléen*
> - Vrai si la connexion est toujours en cours,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).

**Composante : wd300com.dll**
