# SQLDéconnecte (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Ferme la connexion en cours et libère l'espace mémoire utilisé par la connexion. La fonction **SQLDéconnecte** doit être appelée systématiquement pour fermer la connexion, même si cette connexion a échoué.
> _(PHP)_ Il n'est pas nécessaire d'utiliser la fonction SQLDéconnecte dans les cas suivants :si aucune session n'est utilisée.si la connexion a échoué.

> _(WEBDEV - Code Navigateur)_ Les fonctions SQL permettent de manipuler des bases de données locales (de type Web SQL database). Pour plus de détails, consultez Accès en mode local à une base de données (SQLite).

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax, HFSQL Classic, HFSQL Client/Serveur, Hyper File 5.5)_ // Exemple attaché à l'analyse GESCOM
// TABLE_TableReq est un champ Table par programmation
ResConnect est un entier
ResExec est un booléen
MaBase est une chaîne = "C:\GESCOM.WDD"
ResConnect = SQLConnecte(MaBase, "", "")
SI ResConnect <> 0 ALORS
 ResExec = SQLExec("SELECT NOM, VILLE FROM POP", "REQ1")
 SI ResExec = Vrai ALORS
 // Récupérer les données dans la table
 SQLTable("REQ1", TABLE_TableReq)
 SINON
 // Erreur d'exécution de la requête
 // Récupérer les informations relatives à la requête exécutée
 SQLInfoGene("REQ1")
 Erreur(SQL.MesErreur)
 FIN
 // Libérer la requête dans tous les cas
 SQLFerme("REQ1")
SINON
 // Erreur de connexion
 Erreur("La connexion à la base" + MaBase + "a échoué")
FIN
// Libérer la requête dans tous les cas
SQLDéconnecte()

## Syntaxe

```wlangage
SQLDéconnecte()
```

## Remarques

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax, HFSQL Classic, HFSQL Client/Serveur, Hyper File 5.5)_ Connexion avec une analyse HFSQLDans le cas d'une connexion avec une analyse HFSQL, la fonction SQLDéconnecte ferme l'analyse (équivalent à la fonction HFermeAnalyse). Ainsi, pour continuer à manipuler les fichiers de l'analyse, il faut ouvrir l'analyse avec la fonction HOuvreAnalyse.

### Divers

- Une seule connexion peut être en cours à un moment donné.
- La libération de mémoire allouée lors de la connexion (exécution de "SQLFreeConnect") est automatiquement gérée.
