# <Variable Image>.SauveGIF (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Sauve une image présente dans une variable de type [Image](1000019650.md) :

- soit dans un fichier au format GIF.
- soit en mémoire.

**Remarque** : Cette fonction permet uniquement de sauvegarder des images pour des résolutions d'écran allant jusqu'à 32 bits.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les dessins.

## Exemple

```wlangage
MonImage est une Image = "Test.bmp"
// Sauve en mémoire l'image présente dans MonImage
ResSauvegarde = MonImage.SauveGIF(enMémoire)
```

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ MonImage est une Image = "Test.bmp"
// Sauve l'image présente dans MonImage sur "C:\Documents\Image.GIF"
ResSauvegarde = MonImage.SauveGIF("C:\Documents\Image.GIF")

## Syntaxe

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ Sauvegarder une image dans un fichier au format GIF Masquer les détails
<Résultat> = <Variable Image>.SauveGIF(<Nom du fichier> [, <Nombre de couleurs>])

 <Résultat> : BooléenVrai si l'image a été sauvegardée, Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction ErreurInfo avec la constante errMessage. <Variable Image> : Variable de type ImageNom de la variable de type Image à manipuler. <Nom du fichier> : Chaîne de caractèresNom et chemin complet (ou relatif) du fichier GIF. Un chemin de type UNC peut être utilisé. L'extension du fichier n'est pas obligatoire.Attention : Pour que l'image soit sauvée, le répertoire de destination doit exister.L'existence du fichier GIF n'est pas vérifiée. Si ce fichier existe, il est automatiquement écrasé. <Nombre de couleurs> : Entier optionnelNombre de couleurs de l'image sauvegardée. Valeur comprise entre 16 et 256 (256 par défaut). Ce paramètre correspond au nombre de couleurs proposées dans la palette de couleurs lors de l'utilisation du fichier GIF.

#### Sauvegarder une image en mémoire

```wlangage
<Résultat> = <Variable Image>.SauveGIF(<enMémoire> [, <Nombre de couleurs>])
```

`<Résultat>` *Buffer*
> Chaîne d'octets contenant l'image au format GIF.
> Cette chaîne d'octets peut être par la suite affectée à un champ Image, enregistrée dans un fichier (fonction [fSauveTexte](3036046.md)), envoyée à travers un réseau (grâce aux [fonctions Socket](3070007.md)), ...
`<Variable Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) à manipuler.
`<enMémoire>` *Constante*
> *enMémoire* : Constante permettant de sauvegarder une image en mémoire.
`<Nombre de couleurs>` *Entier optionnel*
> Nombre de couleurs de l'image sauvegardée. Valeur comprise entre 16 et 256 (256 par défaut). Ce paramètre correspond au nombre de couleurs proposées dans la palette de couleurs lors de l'utilisation du fichier GIF.

**Composante : wd300pnt.dll**
