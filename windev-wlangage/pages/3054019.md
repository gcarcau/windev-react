# LangueVersNation (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Renvoie la nation correspondant à une langue.

## Exemple

```wlangage
// Connaître la nation correspondant
// à la langue arménienne
ResNation est un entier
ResNation = LangueVersNation(langueArménien)
SELON ResNation
	CAS nationAllemand :
	 ...
	CAS nationAustralien :
	 ...
	CAS 0 :
	 ...
FIN
```

```wlangage
// Connaître la nation correspondant
// à la langue anglaise en Australie
ResNation est un entier
ResNation = LangueVersNation(langueAnglais, 3)
SELON ResNation
	CAS nationAnglais :
	 ...
	CAS nationAustralien :
	 ...
	CAS 0 :
	 ...
FIN
```

## Syntaxe

```wlangage
<Résultat> = LangueVersNation(<Langue> [, <Sous-langue>])
```

`<Résultat>` *Constante de type Entier*
> - Nation correspondant de la langue spécifiée,
> - 0 si la langue spécifiée ne correspond à aucune nation.
>
> Pour plus de détails sur ces constantes, consultez [Correspondance entre les langues, les sous-langues, les alphabets et les nations](3054022.md).
`<Langue>` *Constante de type Entier*
> Langue dont on veut connaître la nation. Pour plus de détails sur ces constantes, consultez [Correspondance entre les langues, les sous-langues, les alphabets et les nations](3054022.md).
`<Sous-langue>` *Entier optionnel*
> Sous-langue dont on veut connaître la nation. Pour plus de détails sur ces sous-langues, consultez [Correspondance entre les langues, les sous-langues, les alphabets et les nations](3054022.md).
> Si ce paramètre n'est pas spécifié, la nation standard de la <Langue> spécifiée est donnée.
