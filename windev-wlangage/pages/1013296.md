# Animation d'un champ Graphe

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

L'animation du champ Graphe permet de proposer un affichage dynamique dans vos applications.
Par exemple, au premier affichage d'un graphe de type Histogramme, chaque barre semble jaillir de l'axe des abscisses. L'animation est également effectuée lorsqu'une valeur est modifiée.

L'animation du champ Graphe est définie sous l'éditeur dans l'onglet ["Détail"](3042080.md) de la fenêtre de description du champ.

## Mise en place

### Animer un champ Graphe
Pour animer un champ Graphe :

1. Affichez la fenêtre de description du champ Graphe.
2. Dans l'onglet "Détail" :
  - Dans la zone "Animations des graphes 2D", cochez l'option "Activer les animations".
  - Dans la zone "Animations", cochez l'option "Activer les animations".
  - Dans la zone "Interactivité", cochez l'option "Graphe interactif" si nécessaire puis l'option "Activer les animations".**Remarque** : L'option "Graphe interactif" permet d'obtenir des graphes réagissant aux actions de l'internaute. Par exemple, dans un graphe de type Secteur, la part survolée est automatiquement excentrée, la part cliquée est positionnée en bas du graphe, la valeur sélectionnée dans la légende est rendue invisible, ...
     Seuls les graphes interactifs sont disponibles.
3. Validez la fenêtre de description du champ.

Remarques :

- Cette option est disponible pour les types de graphes suivants :
  - Aire, Bulle, Courbe, Donut, Histogramme, MinMax, Radar, Secteur, Waterfall.
  - Aire, Bulle, Courbe, Donut, Histogramme, Secteur.
  - Aire, Courbe, Histogramme, Histogramme empilé, Secteur, Donut, Hémicycle.
- L'animation effectuée sur les champs Graphe dépend du type de graphe affiché. Cette animation ne peut pas être paramétrée.
- Par défaut, l'animation d'un champ Graphe dure 30 millisecondes.
- Si un champ Graphe est animé, l'animation sera également effectuée lors du dessin du graphe en cas de changement d'une valeur (fonction [grDessine](3042026.md)).
- La fonction [grDessine](3042026.md) n'est pas bloquante. Si le graphe est dessiné avec une animation, la fonction rendra la main dès le début de l'animation. Ainsi, si plusieurs graphes sont affichés dans la même fenêtre, il est possible d'animer ces champs simultanément.
- Par défaut, les champs Graphe créés à partir de la version 19 sont animés.

### Modifier ou supprimer l'animation par programmation
La propriété [DuréeAnimation](1000021069.md) permet de :

- Connaître et modifier la durée de l'animation effectuée dans un champ Graphe.
  ```wlangage
  // Augmentation du délai
  GRF_MonGraphe.DuréeAnimation = 2000
  ```
- Annuler l'animation d'un champ Graphe. Il suffit pour cela de changer la durée de l'animation en lui donnant une valeur nulle.
  ```wlangage
  // Arrête l'animation temporairement
  GRF_MonGraphe.DuréeAnimation = 0
  ```
