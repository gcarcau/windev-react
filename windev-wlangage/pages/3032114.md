# LDAPSupprime (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **Autres** (Procédures stockées)

Supprime un objet du serveur LDAP. Pour des raisons de sécurité, l'objet est supprimé uniquement si cet objet n'a pas de fils.

## Exemple

```wlangage
// Suppression de l'utilisateur Bob
SI LDAPSupprime("MaSession", "CN=Bob, CN=Users, DC=pcsoft, DC=local") = Faux ALORS
	Erreur("Erreur en suppression de Bob")
FIN
```

## Syntaxe

```wlangage
<Résultat> = LDAPSupprime(<Session LDAP> , <DN de l'objet de base>)
```

`<Résultat>` *Booléen*
> - Vrai si la suppression a été effectuée,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de détails sur l'erreur.
`<Session LDAP>` *Chaîne de caractères*
> Nom de la session LDAP manipulée.
`<DN de l'objet de base>` *Chaîne de caractères*
> Nom absolu de l'objet (Distinguished Name) à supprimer

**Composante : wd300com.dll**
