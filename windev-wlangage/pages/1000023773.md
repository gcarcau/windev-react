# <Arbre>.SupprimeTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Supprime l'ensemble des éléments d'un champ Arbre.
Exemple de champ Arbre :
[image: Vocabulaire lié à un champ Arbre]

## Exemple

```wlangage
// Suppression du contenu du champ Arbre "ARBRE_RecetteTV"
ResSuppression = ARBRE_RecetteTV.SupprimeTout()
```

## Syntaxe

```wlangage
<Résultat> = <Champ Arbre>.SupprimeTout()
```

`<Résultat>` *Booléen*
> - Vrai si la suppression a été effectuée,
> - Faux dans le cas contraire.
`<Champ Arbre>` *Nom de champ*
> Nom du champ Arbre à manipuler.

**Composante : wd300obj.dll**
