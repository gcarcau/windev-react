# Liste des mots réservés

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

Les mots réservés du WLangage sont les suivants :

| [Allouer](1511011.md) | Permet de réserver de la place en mémoire pour contenir un tableau dynamique, un objet de classe dynamique, une structure dynamique. |
| --- | --- |
| [BLOC](1511026.md) | Permet de définir un bloc de code sous l'éditeur de code. |
| [EXTERNE](1511013.md) | Permet soit d'intégrer un fichier texte contenant du WLangage dans une application, soit de déclarer un objet externe |
| [Libérer](1511012.md) | Permet de libérer explicitement la mémoire occupée par un tableau dynamique, un objet de classe dynamique, une structure dynamique. |
| [MaFenêtre](1511004.md) | Permet de manipuler la fenêtre courante. |
| [MaFenêtreCoulissanteBasse](1511030.md) | Permet de manipuler la fenêtre coulissante basse associée à la fenêtre courante. |
| [MaFenêtreCoulissanteDroite](1511023.md) | Permet de manipuler la fenêtre coulissante droite associée à la fenêtre courante. |
| [MaFenêtreCoulissanteGauche](1511022.md) | Permet de manipuler la fenêtre coulissante gauche associée à la fenêtre courante. |
| [MaFenêtreFille](1511021.md) | Permet de manipuler la fenêtre fille de la fenêtre courante. |
| [MaFenêtreInterne](1511024.md) | Permet de manipuler la fenêtre interne courante. |
| [MaPage](1511017.md) | Permet de manipuler la page courante. |
| [MaSource](1511001.md) | Permet de manipuler la source de données (fichier, vue ou requête) courante. |
| [MesParamètres](1511018.md) | Permet de manipuler les paramètres d'une procédure WLangage (procédure classique ou procédure à nombre de paramètres variable) |
| [Modulo](1511002.md) | Retourne le reste d'une division entière. |
| [MoiMême](1511007.md) | Permet de manipuler le champ en cours. |
| [MonEtat](2510086.md) | Permet de manipuler l'état courant |
| [MonParent](1511016.md) | Permet de manipuler le superchamp en cours à partir d'un de ses champs |
| [Null](2512064.md) | Permet de :  - indiquer qu'un paramètre ne doit pas être pris en compte dans une requête : Null et les requêtes - spécifier qu'une variable de type variant ne contient pas de valeur : Null et les variants - comparer une valeur à 0 : Null et les numériques - dans certaines fonctions du WLangage, indiquer que le paramètre ne doit pas être pris en compte : Null et les fonctions du WLangage |
| [STOP](1511014.md) | Permet d'appeler le débogueur du WLangage lors d'un test sous l'éditeur. Après exécution de ce mot-clé, le test en cours s'effectuera dans le débogueur. |

A cette liste doivent être ajoutés :

- les différents types de variables disponibles,
- les différentes fonctions WLangage,
- les différentes propriétés WLangage.
