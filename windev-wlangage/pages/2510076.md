# Mémoire (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

La propriété **Mémoire** permet de savoir si le champ spécifié est un champ "par programmation" (également appelé "mémoire") ou un champ fichier.
Les champs sur lesquels s'applique la propriété **Mémoire** sont les champs Liste, Liste image, Combo, Table, Table hiérarchique ou Zone répétée (suivant le produit utilisé : WINDEV, WINDEV Mobile ou WEBDEV).

**Rappel** :

- Les champs Liste, Liste image, Combo, Table, Table hiérarchique et Zone répétée **par programmation** manipulent des données stockées en mémoire (définies par programmation).
- Les champs Liste, Liste image, Combo, Table, Table hiérarchique et Zone répétée **fichier** manipulent des données provenant de fichiers de données ou de requêtes.

**Important : Cette propriété est conservée par compatibilité**. Il est conseillé d'utiliser la propriété [TypeRemplissage](1000017723.md).

## Exemple

```wlangage
SI LISTE_Liste1.Mémoire = Vrai ALORS
	ListeAjoute(LISTE_Liste1, "Paris")
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Champ manipulé>.Mémoire
```

`<Résultat>` *Booléen*
> - Vrai si le contenu du champ provient d'ajouts effectués par programmation.
> - Faux si le contenu du champ provient d'un fichier de données.
`<Champ manipulé>` *Nom de champ*
> Nom du champ (Liste, Liste image, Combo, Zone répétée, Table ou Table hiérarchique) à manipuler.

## Remarques

### Champs Liste, Liste image, Combo et Table fichier
Les propriétés suivantes définissent les enregistrements qui sont affichés.

- [FichierParcouru](2510040.md) : Nom du fichier de données de base.
- [RubriqueParcourue](2510111.md) : Nom de la rubrique utilisée pour le parcours (le tri est effectué sur cette rubrique).
- [Filtre](2510042.md) : Si ce filtre n'est pas vide, seuls les enregistrements correspondant au filtre sont affichés.
- [ParcoursAuto](2510093.md) : Indique si les événements de parcours associés à l'élément sont utilisés.

### Limite

> _(Java)_ En Java, la propriété Mémoire s'applique uniquement sur les champs Liste.
