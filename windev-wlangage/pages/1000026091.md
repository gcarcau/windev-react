# Fonctions Modbus (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Les fonctions Modbus en syntaxe préfixée sont les suivantes :

| [<modbusSession>.Déconnecte](1000025954.md) | Ferme la session Modbus. |
| --- | --- |
| [<modbusSession>.EcritBit](1000025967.md) | Écrit un ou plusieurs bits à une adresse précise dans un esclave Modbus. |
| [<modbusSession>.EcritFlottant](1000026035.md) | Ecrit une ou plusieurs flottants simple précision à partir d'une adresse précise dans un esclave Modbus. |
| [<modbusSession>.EcritRegistre](1000026036.md) | Ecrit un ou plusieurs registres (valeur 16 bits) à partir d'une adresse précise dans un esclave Modbus. |
| [<modbusSession>.EnvoieTrameBrute](1410090468.md) | Envoie une trame brute à un esclave Modbus. Il est ainsi possible de communiquer avec des automates qui disposent de fonctionnalités non-standards. |
| [<modbusSession>.LitBit](1000026065.md) | Lit un ou plusieurs bits à partir d’une adresse précise sur un esclave Modbus. |
| [<modbusSession>.LitFlottant](1000026079.md) | Lit un ou plusieurs flottants "simple précision" à partir d'une adresse précise dans un esclave Modbus. |
| [<modbusSession>.LitRegistre](1000026080.md) | Lit un ou plusieurs registres à partir d'une adresse précise dans un esclave Modbus. |
