# Paragraphe (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **Paragraphe** permet de manipuler les paragraphes d'un document Traitement de texte. Cette propriété est utilisable sur :

- les variables de type [docElément](1000022484.md).
- les variables de type [Document](1000022461.md).
- les variables de type [docFragment](1000022482.md).
