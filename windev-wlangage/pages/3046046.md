# iForceComplément (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Force l'impression d'un bloc de complément de corps. Le complément de corps s'imprime sur la hauteur de la page restante, c'est-à-dire jusqu'au bas de page.
Cette fonction permet par exemple de forcer l'impression d'un complément de corps :

- soit après une fin de rupture.
- soit sur la dernière page d'un état.

**Remarque** : Si cette fonction n'est pas utilisée, le complément de corps s'imprime après le dernier bloc de corps de chaque page. Le complément de corps ne s'imprime que si un bloc corps est imprimé dans la page.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Imprimer sous Linux.

## Exemple

```wlangage
iForceComplément()
```

## Syntaxe

```wlangage
iForceComplément()
```

## Remarques

La fonction **iForceComplément** pourrait être remplacée par l'impression d'un bloc (fonction [iImprimeBloc](3046030.md)) redimensionné avec la propriété [Hauteur](2510050.md).

**Classification Métier / UI : Code neutre**

**Composante : wd300etat.dll**
