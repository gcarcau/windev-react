# diagBordure (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Le type **diagBordure** permet de définir toutes les caractéristiques avancées d'une bordure (ou d'un cadre) d'une forme utilisée dans un diagramme. Les caractéristiques de cette bordure peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

**ATTENTION : Ce type ne doit pas être utilisé directement. Il doit être utilisé uniquement via le type [diagForme](1410088082.md) (ou un de ses types dérivés).**

## Exemple

```wlangage
// Crée une forme rectangle
MaForme est un diagRectangle

// Définit les dimensions, la position et la couleur de fond
MaForme.X = 100
MaForme.Y = 100
MaForme.Largeur = 350
MaForme.Hauteur = 150
MaForme.Fond.Couleur = RougePastel
MaForme.Bordure.Couleur = Noir
MaForme.Bordure.Epaisseur = 2
MaForme.Bordure.Type = TraitTiret

// Obtient une référence sur le diagramme affiché
MonDiagramme est un Diagramme <- EDIAG_MonDiagramme

// Ajoute la forme rectangle dans le diagramme
Ajoute(MonDiagramme.Forme, MaForme)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type diagBordure
Les propriétés suivantes peuvent être utilisées pour manipuler la bordure d'une forme :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Couleur | Entier | Couleur de la bordure.  Cette propriété peut correspondre à :   - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)), - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)), - [une couleur prédéfinie du WLangage](3010002.md). - une variable de type [Couleur](1000019661.md). Dans ce cas, l'opacité spécifiée dans la variable est prise en compte. |
| Epaisseur | Réel | Epaisseur du trait de la bordure. |
| Type | Entier | Type du trait de la bordure :   - *TraitContinu* : - *TraitPointillé* : - *TraitTiret* : |
