# Constantes HTML

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Les constantes de gestion des fichiers HTML sont les suivantes :

| Constante | Détail | Fonction / Type de variable |
| --- | --- | --- |
| **htmlNoeudCData** | Type du noeud dans le document HTML : Noeud CDATA (compatibilité XHTML). | Type [htmlNoeud](1000026081.md) |
| **htmlNoeudCommentaire** | Type du noeud dans le document HTML : Noeud de type commentaire. | Type [htmlNoeud](1000026081.md) |
| **htmlNoeudElément** | Type du noeud dans le document HTML : Noeud de type élément, une balise du HTML. | Type [htmlNoeud](1000026081.md) |
| **htmlNoeudTexte** | Type du noeud dans le document HTML : Noeud de type texte. | Type [htmlNoeud](1000026081.md) |
