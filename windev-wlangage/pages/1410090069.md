# ActionRapideEpingle (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android)

Demande à épingler une action rapide.
Lorsqu'une action est épinglée, l'icône correspondante est créée sur l'écran d'accueil de l'appareil, et il est possible d'y accéder en un seul toucher. Ce fonctionnement peut être pratique pour les actions ou les fonctionnalités utilisées fréquemment pour lesquelles un accès direct est nécessaire.

Remarque : Cette fonctionnalité est disponible uniquement à partir de Android 8.

## Exemple

```wlangage
tabAction est un tableau de ActionRapide = ActionRapideListe()
POUR TOUTE action DE tabAction
	SI action.Identifiant = "ID_ACTION_ENVOI_MESSAGE" ALORS
		ActionRapideEpingle(action)
	FIN
FIN
```

## Syntaxe

#### Epingler une action rapide identifiée par son identifiant

```wlangage
<Résultat> = ActionRapideEpingle(<Identifiant>)
```

`<Résultat>` *Booléen*
> - Vrai si la demande a été effectuée,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet de connaître le détail de l'erreur.
>
> Attention : La fonction retournera Vrai même si l'utilisateur a refusé l'opération.
`<Identifiant>` *Chaîne de caractères*
> Identifiant de l'action rapide à épingler. L'action rapide doit déjà avoir été ajoutée à l'application pour être épinglée.

#### Epingler une action rapide identifiée par une variable de type ActionRapide

```wlangage
<Résultat> = ActionRapideEpingle(<Action>)
```

`<Résultat>` *Booléen*
> - Vrai si l'action a été ajoutée,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet de connaître le détail de l'erreur.
>
> Attention : La fonction retournera Vrai même si l'utilisateur a refusé l'opération.
`<Action>` *Variable de type ActionRapide*
> Nom de la variable de type [ActionRapide](1410090054.md) décrivant l'action à épingler. L'action rapide doit déjà avoir été ajoutée à l'application pour être épinglée.

## Remarques

- La fonction affiche une fenêtre à l'utilisateur pour demander l'autorisation à l'utilisateur d'ajouter un raccourci sur l'écran d'accueil.
- L'action rapide doit déjà avoir été ajoutée à l'application pour être épinglée.
- Cette fonction doit être exécutée lorsque l'application est au premier plan. Il est déconseillé de l'exécuter dans les événements d'initialisation de l'application.
