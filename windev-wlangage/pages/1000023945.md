# Fonctions de gestion des champs Zone répétée (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions permettant de gérer les champs Zone répétée (syntaxe préfixée) sont les suivantes :

| [<Zone répétée>.Affiche](1000023451.md) | Réactualise l'affichage d'une zone répétée fichier à partir d'une position donnée : les modifications effectuées sur le fichier lié sont répercutées dans la zone répétée. |
| --- | --- |
| [<Zone répétée>.AffichePopup](1000023481.md) | Affiche la popup automatique de zoom du champ Galerie d'images. |
| [<Zone répétée>.Ajoute](1000023469.md) | Ajoute une répétition à la fin d'un champ Zone répétée. |
| Nouveauté 2025 [<Zone répétée>.AjouteDébut](1410090639.md) | Ajoute une répétition (ou ligne) au début d'un champ Zone répétée infinie. La répétition est insérée avant la première répétition du champ Zone répétée. La position de défilement du champ Zone répétée n'est pas modifiée. |
| [<Zone répétée>.AjouteFI](1000023474.md) | Ajoute une répétition sous forme d'une fenêtre interne à la fin d'un champ Zone répétée par programmation. |
| Nouveauté 2025 [<Zone répétée>.AjouteFIDébut](1410090640.md) | Ajoute une répétition (ou une ligne) constituée par une fenêtre interne en première répétition d'un champ Zone Répétée infinie. La répétition est insérée avant la première répétition du champ Zone répétée. La position de défilement du champ Zone répétée n'est pas modifiée. |
| [<Zone répétée>.AjouteLigne](1000023475.md) | Ajoute une répétition à la fin d'un champ Zone répétée. |
| [<Zone répétée>.AjoutEnCours](1000023482.md) | Modifie ou renvoie l'état de visibilité de la fenêtre interne de patience lors de l'ajout d'éléments supplémentaires dans un champ Zone répétée infinie. |
| [<Zone répétée>.AjoutePI](1410089490.md) | Ajoute une répétition sous forme d'une page interne à la fin d'un champ Zone répétée par programmation. |
| [<Zone répétée>.AnnuleBalayage](1000023483.md) | Annule l'affichage de la fenêtre interne affichée dans un champ Zone répétée suite au balayage d'une répétition (ou ligne). |
| [<Zone répétée>.CherchePartout](1000023485.md) | Recherche une valeur dans tous les attributs d'un champ Zone répétée. |
| [<Zone répétée>.DébutRemplissage](1000023487.md) | Indique le début du remplissage d'un champ Zone répétée par programmation. |
| [<Zone répétée>.DéplaceLigne](1000023488.md) | Déplace une répétition ou échange deux répétitions d'un champ Zone répétée. |
| [<Zone répétée>.Déroule](1000023489.md) | Déroule une rupture du champ Zone répétée sur une ligne donnée. |
| [<Zone répétée>.DérouleTout](1000023490.md) | Déroule toutes les ruptures d'un champ Zone répétée avec rupture. |
| [<Zone répétée>.Enregistre](1000023496.md) | Valide la modification ou l'ajout de l'enregistrement associé à la répétition en cours dans le champ Zone répétée fichier. |
| [<Zone répétée>.Enroule](1000023497.md) | Enroule une rupture précédemment déroulée d'un champ Zone répétée. |
| [<Zone répétée>.EnrouleDéroule](1000023499.md) | Sur une répétition/ligne donnée d'un champ Zone répétée :   - replie une rupture (si elle est déroulée), - déplie une rupture (si elle est enroulée). |
| [<Zone répétée>.EnrouleTout](1000023500.md) | Enroule toutes les ruptures déroulées d'un champ Zone répétée. |
| [<Zone répétée>.FinRemplissage](1000023501.md) | Indique la fin du remplissage d'un champ Zone répétée par programmation. |
| [<Zone répétée>.IndiceRupture](1000023502.md) | Renvoie l'indice du haut et du bas de rupture d'une rupture donnée dans un champ Zone répétée. |
| [<Zone répétée>.InfoXY](1000023508.md) | Permet de connaître la répétition ou le champ se trouvant à une position donnée du champ Zone répétée (X, Y). |
| [<Zone répétée>.Insère](1000023509.md) | Insère une répétition dans un champ Zone répétée. |
| [<Zone répétée>.InsèreFI](1000023510.md) | Insère une répétition sous forme d'une fenêtre interne dans un champ Zone répétée par programmation. |
| [<Zone répétée>.InsèreLigne](1000023511.md) | Insère une répétition dans un champ Zone répétée. |
| [<Zone répétée>.InsèrePI](1410089491.md) | Insère une répétition sous forme d'une page interne dans un champ Zone répétée par programmation. |
| [<Zone répétée>.Modifie](1000023512.md) | Modifie les valeurs des attributs dans une répétition d'un champ Zone répétée. |
| [<Zone répétée>.ModifieFI](1000023519.md) | Modifie une répétition correspondant à une fenêtre interne dans un champ Zone répétée par programmation. |
| [<Zone répétée>.ModifieLigne](1000023520.md) | Modifie les valeurs des attributs dans une répétition d'un champ Zone répétée. |
| [<Zone répétée>.ModifiePI](1410089492.md) | Modifie une répétition correspondant à une page interne dans un champ Zone répétée par programmation. |
| [<Zone répétée>.NumEnr](1000023521.md) | Renvoie le numéro de l'enregistrement en cours dans un champ Zone répétée fichier. |
| [<Zone répétée>.Occurrence](1000023522.md) | Renvoie le nombre de répétitions d'un champ Zone répétée. |
| [<Zone répétée>.Position](1000023523.md) | Déplace l'ascenseur d'un champ Zone répétée par programmation pour afficher une répétition spécifique ou renvoie l'indice de la première répétition affichée dans un champ Zone répétée par programmation. |
| [<Zone répétée>.RafraîchissementVisible](1000023524.md) | Modifie ou renvoie l'état de visibilité du bandeau de rafraîchissement d'un champ Zone répétée. |
| [<Zone répétée>.RestaurePositionEtSélection](1000023525.md) | Restaure la position de l'ascenseur d'un champ Zone répétée ainsi que le ou les éléments sélectionnés. |
| [<Zone répétée>.SauvePositionEtSélection](1000023696.md) | Sauve :  - la position de l'ascenseur dans un champ Zone répétée, - le ou les éléments sélectionnés.  Ces éléments peuvent être restaurés grâce à la fonction [<Zone répétée>.RestaurePositionEtSélection](1000023525.md). |
| [<Zone répétée>.Select](1000023697.md) | Renvoie l'indice de l'élément sélectionné dans un champ Zone répétée. |
| [<Zone répétée>.SelectMoins](1000023698.md) | Dé-sélectionne une répétition dans un champ Zone répétée. |
| [<Zone répétée>.SelectOccurrence](1000023699.md) | Renvoie le nombre de répétitions sélectionnées dans un champ Zone répétée. |
| [<Zone répétée>.SelectPlus](1000023700.md) | Sélectionne une répétition dans un champ Zone répétée. |
| [<Zone répétée>.Supprime](1000023701.md) | Supprime une répétition dans un champ Zone répétée. |
| [<Zone répétée>.SupprimeSelect](1000023702.md) | Supprime la ou les lignes sélectionnées dans un champ Zone répétée. |
| [<Zone répétée>.SupprimeTout](1000023703.md) | Supprime toutes les répétitions du champ Zone répétée par programmation. |
| [<Zone répétée>.Trie](1000023704.md) | Permet de :  - Trier un champ Zone répétée selon un ou plusieurs de ses attributs. - Trier un champ Zone répétée sur tous ses attributs. - Annuler un tri précédemment effectué (c'est-à-dire ne plus tenir compte du tri). |
| [<Zone répétée>.VersExcel](1000023705.md) | Crée un fichier Excel avec les données d'un champ Zone répétée (champ Zone répétée fichier ou champ Zone répétée mémoire). |
| [<Zone répétée>.VersWord](1000023706.md) | Crée un fichier Word (.RTF) avec les données d'un champ Zone répétée. |
| [<Zone répétée>.VersXML](1000023707.md) | Crée un fichier XML avec les données d'un champ Zone répétée (champ Zone répétée fichier ou champ Zone répétée par programmation). |
