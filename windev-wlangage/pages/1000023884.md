# <Fenêtre>.Iconise (Fonction)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU))

Iconise une fenêtre WINDEV.
**Remarque** : La fonction **<Fenêtre>.Iconise** réalise la même action que le bouton de réduction présent dans le coin haut droit des fenêtres.

## Exemple

```wlangage
// Iconise la fenêtre "FEN_SaisieClient"
FEN_SaisieClient.Iconise()
```

## Syntaxe

```wlangage
<Fenêtre>.Iconise()
```

`<Fenêtre>` *Nom de fenêtre*
> Nom de la fenêtre à icôniser.
> Remarque : Si la fenêtre spécifiée correspond à une fenêtre fille, la fenêtre mère est également icônisée.

## Remarques

Pour savoir si une fenêtre est icônisée, utilisez la fonction [FenTaille](3038020.md).

**Composante : wd300obj.dll**
