# Variable SAP

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

## Présentation

La variable SAP permet de configurer les paramètres de la connexion au serveur SAP. Ces paramètres seront utilisés par la fonction [SAPConnecte](1000017120.md).

## Variable SAP

La variable SAP est composée des éléments suivants :

| SAP.Adresse | Chaîne de caractères Adresse du système SAP. |
| --- | --- |
| SAP.Connexion | Chaîne de caractères Description de la connexion SAP. Pour plus de détails sur le contenu de cette description, consultez la documentation spécifique SAP. Exemple :   ```wlangage SAP.Connexion = "TYPE=3 ASHOST=MINISAP.test.com SYSNR=00 CLIENT=000 USER=BCUSER PASSWD=minisap" ```   Remarque : si ce paramètre est précisé, les autres variables SAP sont ignorées. |
| SAP.Langue | Chaîne de caractères Définit la langue utilisée pour la connexion (par exemple "en" pour l'anglais) |
| SAP.MotDePasse | Mot de passe de l'utilisateur qui se connecte. |
| SAP.NuméroClient | Chaîne de caractères Numéro du client qui se connecte. |
| SAP.NuméroSystème | Entier Numéro du système SAP. |
| SAP.Utilisateur | Chaîne de caractères Nom de l'utilisateur qui se connecte. |

## Exemple

### Connexion à un serveur SAP

```wlangage
SAP.Adresse = "MINISAP.test.com"
SAP.NuméroSystème = "0"
SAP.NuméroClient = "000"
SAP.Utilisateur = "BCUSER"
SAP.MotDePasse = "MINISAP"
SAP.Langue = ""
IDSAP est un entier = SAPConnecte()
```
