# Fonctions diverses WEBDEV

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

Les fonctions diverses WEBDEV sont les suivantes :

| [ASPAffiche](3012003.md) | Appelle un script ASP externe et renvoie la page résultat dans la fenêtre en cours du navigateur. |
| --- | --- |
| [ASPExécute](3012007.md) | Appelle un script externe .asp et renvoie le résultat dans une chaîne. |
| [CapsLockVérifie](1000020557.md) | Vérifie si la touche CapsLock est enfoncée. |
| [CertificatClientInfo](1000019393.md) | Renvoie des informations sur le certificat utilisé par le poste client. |
| [ChaîneAffiche](3012001.md) | Renvoie une chaîne spécifique (ou un buffer) sur le navigateur du client en réponse à la requête reçue. |
| [ConnexionOccurrence](3012004.md) | Renvoie le nombre d'instances du site WEBDEV en cours d'exécution sur le serveur. |
| [CouleurPalette](1000019905.md) | Renvoie une couleur de la palette courante. |
| [DynamicServingConfigure](1000021994.md) | Indique l'environnement à utiliser par le "Dynamic Serving" pour choisir le jeu de pages à afficher. |
| [ExécuteProcédureDifférée](1000020682.md) | Exécute une procédure différée (dans le serveur d'application WEBDEV). |
| [FichierAffiche](3012005.md) | Affiche un fichier sur le navigateur de l'internaute. |
| Nouveauté 2025 [FichierTélécharge](1410090792.md) | Lance le téléchargement d'un fichier par le navigateur. |
| Nouveauté 2025 [FichierVisualise](1410090793.md) | Lance la visualisation d'un fichier dans le navigateur. |
| [HTMLClasseAjoute](1000021550.md) | Ajoute une classe dans les classes HTML d'un champ. |
| [HTMLClasseBascule](1000021551.md) | Bascule une classe dans les classes HTML d'un champ : si la classe n'existe pas, elle est ajoutée, si la classe existe déjà, elle est supprimée. |
| [HTMLClasseSupprime](1000021552.md) | Supprime une classe des classes HTML d'un champ. |
| [jQuery](1000021070.md) | Exécute une méthode Javascript (ou plusieurs méthodes chaînées) de la librairie jQuery sur un élément de la page. |
| [jQueryExécute](1000021008.md) | Exécute une méthode Javascript de la librairie jQuery sur un élément de la page. |
| [JSEvénement](1000018924.md) | Associe une procédure navigateur à un événement sur un objet en code navigateur. |
| [JSFinEvénement](1000018925.md) | Supprime l'association d'une fonction WLangage navigateur à événement (mis en place grâce à la fonction [JSEvénement](1000018924.md)). |
| [JSInfoEvénement](3036067.md) | Permet de manipuler les propriétés JavaScript de l'événement navigateur qui a déclenché l'exécution du code. |
| [JSInterruptionEvénement](1000019185.md) | Interrompt le traitement de l'événement en cours. |
| [JSMéthode](3012002.md) | Permet d'exécuter une méthode Javascript sur un élément de la page en cours. |
| [JSONExécute](1000017284.md) | Appelle une URL serveur qui retourne des données au format JSON (JavaScript Object Notation). |
| [JSONExécuteExterne](1000017286.md) | Appelle une URL serveur externe qui retourne des données au format JSON (JavaScript Object Notation). |
| [JSPropriété](3012019.md) | Permet de manipuler des fonctionnalités spécifiques sur des objets de la page en cours. |
| [PHPAffiche](3012021.md) | Appelle un script PHP externe et renvoie la page résultat dans la fenêtre en cours du navigateur. |
| [PHPExécute](3012013.md) | Appelle un script externe .php et renvoie le résultat dans une chaîne. |
| [RépertoireDonnées](3036007.md) | La fonction RépertoireDonnées est conservée uniquement pour compatibilité. |
| [RépertoireWeb](3012015.md) | Renvoie le chemin du répertoire contenant :  - les images, - les fichiers Javascript, - les fichiers applet Java, - les autres fichiers accessibles depuis le navigateur. |
| [RépertoireWeb_15](3012018.md) | Attention : lors de la migration d'un projet WEBDEV 1.5 vers WEBDEV 17 :   - la fonction RépertoireWeb a été remplacée par la fonction RépertoireWeb_15. - un warning est automatiquement généré dans votre projet. |
| [ScriptAffiche](3012017.md) | Appelle un script ou une page externe (par exemple .php, .asp, .mhtml ou .mht) et renvoie la page résultat dans la fenêtre en cours du navigateur. |
| [ScriptExécute](3012016.md) | Appelle un script externe (par exemple .php ou .asp) et renvoie le résultat dans une chaîne. |
| [SessionHeartBeatActive](1000026248.md) | Active ou désactive le "heartbeat" de la session courante. |
| [SessionPageDemandée](1410089106.md) | Renvoie le nom de la page explicitement demandée au lancement de la session. |
| [SessionPrologue](1000026262.md) | Active ou désactive une procédure WLangage appelée sur chaque requête dans une session. |
| [SSLActive](3012014.md) | Permet d'activer ou de désactiver le mode sécurisé SSL. |
