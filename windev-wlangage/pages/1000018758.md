# TableIndiceRupture (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Renvoie l'indice du haut et du bas de rupture d'une rupture donnée dans un champ Table.
L'indice du haut de rupture d'une rupture donnée correspond également à l'indice de la première ligne dans cette rupture.

L'indice du bas de rupture d'une rupture donnée correspond également à l'indice de la dernière ligne dans cette rupture.

## Exemple

```wlangage
IndiceHaut est un entier
// Récupère l'indice du haut de rupture de la ligne sélectionnée
IndiceHaut = TableIndiceRupture(RUPT_HautDeRupture)
```

```wlangage
// Ajoute une ligne dans le champ Table
IndiceLigne est un entier
IndiceLigne = TableAjouteLigne(TABLE_Articles, NomProduit, NomFournisseur, PrixUnitaire)
// Récupère l'indice du haut de rupture de la ligne ajoutée
IndiceHaut = TableIndiceRupture(RUPT_HautDeRupture, IndiceLigne)
// Fixe la valeur du libellé contenu dans la rupture
TABLE_Articles[IndiceHaut].LIB_Fournisseur = NomFournisseur
```

## Syntaxe

```wlangage
<Résultat> = TableIndiceRupture(<Haut / Bas de rupture> [, <Indice>])
```

`<Résultat>` *Entier*
> - Indice du haut / bas de rupture spécifié dans la rupture contenant la ligne <Indice>,
> - 0 en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Haut / Bas de rupture>` *Nom champ*
> Nom du haut ou du bas de rupture à manipuler.
> Ce paramètre peut correspondre :
>
> - soit au <Nom du haut / bas de rupture>.
> - soit au <Champ Table>.<Nom du haut / bas de rupture>.
`<Indice>` *Entier optionnel*
> Indice d'une des lignes contenues dans la rupture voulue.
> Si ce paramètre n'est pas spécifié, l'indice du haut / bas de rupture spécifié dans la rupture contenant la ligne en cours est retourné.

## Remarques

### Conditions d'utilisation
La fonction **TableIndiceRupture** peut être utilisée indifféremment sur un champ Table fichier ou Table par programmation.
> _(WEBDEV - Code Serveur, PHP)_ Cette fonction est disponible pour les champs Table en mode Ajax et les champs Table en mode classique.

> _(WEBDEV - Code Navigateur)_ Cette fonction est disponible uniquement pour les champs Table en mode navigateur.

Il est conseillé d'appeler la fonction **TableIndiceRupture** après l'affichage complet du contenu du champ Table. Dans le cas contraire, les indices renvoyés par la fonction **TableIndiceRupture** peuvent ne pas correspondre aux indices réellement affichés dans le champ.
