# Position

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Le mot-clé **Position** peut correspondre :

- à la fonction **[Position](3024027.md)** qui permet de rechercher la position d'une chaîne de caractères dans une autre chaîne de caractères.
- à la propriété **Position** disponible sur :
  - une variable de type [Adresse](1000019944.md).
  - une variable de type [Marqueur](1000019940.md).
  - une variable de type [Filigrane](1000019922.md).
  - une variable de type [docTabulation](1000022573.md).
  - une variable de type [CarteImage](1000025523.md).
  - une variable de type [xlsCommentaire](1000024870.md).
- Nouveauté Abonnement
  une variable de type [OptionsOuvertureFenêtre](1410091298.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
