# ArbreModifie (Fonction)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Modifie un élément (noeud ou feuille) dans un champ Arbre.
Exemple de champ Arbre : [image: Vocabulaire lié à un champ Arbre]

## Exemple

```wlangage
// Modification du libellé du noeud "Desserts" dans le champ Arbre "ARBRE_RecetteTV"
Res = ArbreModifie(ARBRE_RecetteTV, "Recettes" + TAB + "Desserts", "Desserts glacés")
```

```wlangage
// Modification de l'image de la racine de champ Arbre "ARBRE_RecetteTV"
Res = ArbreModifie(ARBRE_RecetteTV, "Recettes", Null, ...
		"C:\MesImages\Img1.GIF", "C:\MesImages\Img2.GIF")
```

## Syntaxe

```wlangage
<Résultat> = ArbreModifie(<Champ Arbre> , <Chemin de l'élément à modifier> , <Nouveau libellé> [, <Nouvelle image enroulée> [, <Nouvelle image déroulée> [, <Nouvel identifiant de l'élément> [, <Texte de la bulle d'aide>]]]])
```

`<Résultat>` *Booléen*
> - Vrai si l'élément a été modifié dans le champ Arbre,
> - Faux dans le cas contraire.
`<Champ Arbre>` *Nom de champ*
> Nom du champ Arbre à manipuler.
`<Chemin de l'élément à modifier>` *Chaîne de caractères*
> Chemin complet de l'élément à modifier. Ce paramètre est de la forme :
>
>
> ```wlangage
> "<Nom de la racine>" + TAB + ["<Nom du 1er noeud>" + TAB + ...["<Nom du 2ème noeud>" + TAB + [...]]]"<Nom de la feuille>"
> ```
`<Nouveau libellé>` *Chaîne de caractères*
> - Nouveau libellé de l'élément spécifié,
> - Constante *NULL* pour conserver le libellé existant.
`<Nouvelle image enroulée>` *Chaîne de caractères ou constante optionnelle*
> Nouvelle image associée à l'élément spécifié. Cette image est affichée lorsque cet élément est enroulé (voir Remarques). Ce paramètre correspond :
>
> - soit au nom et au chemin complet (ou relatif) de l'image. Un chemin de type UNC peut être utilisé.
> - soit à la constante :
>   | *aDéfaut* (Valeur par défaut) | Image par défaut (dossier fermé) : [image: Dossier fermé] |
>   | --- | --- |
>   | *Null* | Conserve l'image de l'élément spécifié |
`<Nouvelle image déroulée>` *Chaîne de caractères ou constante optionnelle*
> Nouvelle image associée à l'élément spécifié. Cette image est affichée lorsque cet élément est déroulé (voir Remarques). Ce paramètre correspond :
>
> - soit au nom et au chemin complet (ou relatif) de l'image. Un chemin de type UNC peut être utilisé.
> - soit à la constante :
>   | *aDéfaut* (Valeur par défaut) | Image par défaut (dossier ouvert) : [image: Dossier ouvert] |
>   | --- | --- |
>   | *Null* | Conserve l'image de l'élément spécifié |
`<Nouvel identifiant de l'élément>` *Chaîne de caractères ou entier (optionnel)*
> Nouvel identifiant de l'élément ou la constante *NULL* pour conserver l'identifiant de l'élément spécifié.
> **Attention** : Le caractère Tabulation (TAB) est interdit dans les identifiants des éléments.
`<Texte de la bulle d'aide>` *Chaîne de caractères optionnelle*
> Si ce paramètre est précisé, son contenu sera affiché lors du survol de l'élément dans une bulle d'aide. Par défaut, ce paramètre correspond à une chaîne vide. Si aucune bulle d'aide n'est associée à l'élément, la bulle d'aide associée au champ Arbre sera automatiquement affichée.

## Remarques

### Format des images enroulées/déroulées

> _(WINDEV)_ Les formats d'images supportés sous Windows sont :Bitmap (*.BMP)Graphics Interchange Format (*.gif)Joint Picture Experts Group (*.jpg ; *.jpeg)Kodak Photo CD (*.pcd)PaintBrush (*.pcx)Adobe Photoshop Format (*.psd)TrueVision TARGA (*.tga)Tagged Image File Format (*.tif ; *.tiff)Remarque : l'option "tiff mosaïque" de la norme tiff 6.0 n'est pas supportée. Dans ce cas, il est conseillé d'enregistrer l'image à la norme tiff 5.0. Portable Network Graphics (*.png)Windows MetaFiles (*.emf ; *.wmf)Icônes (*.ico ; *.icw)Remarques : Affichage HQ (Haute Qualité) disponible.Gestion des planches au format BMP transparent (32 bits).Curseurs (*.cur)Portable Document Format (*.pdf)Scalable Vector Graphics (*.svg)Images WINDEV (générées par l'éditeur d'images, *.WDPIC).Nouveauté 2025Images au format WebP (*.webp).

> _(WEBDEV - Code Serveur)_ Les formats d'images reconnus sont les suivants : GIF, JPEG, PNG ou SVG (selon le support des navigateurs).

### Type des images enroulées/déroulées
Les images utilisées peuvent être :

- des fichiers image,
- des rubriques d'un fichier de données HFSQL de type "Mémo Binaire" contenant une image.
- des dessins réalisés à l'aide des [fonctions de dessin dans les listes et dans les combos](3029028.md).

L'image spécifiée est réduite proportionnellement à la taille 16 x 16 pixels : dans la majorité des cas, la hauteur de l'image correspond à la hauteur de la ligne du champ Arbre.

> _(WEBDEV - Code Serveur)_ Les images utilisées peuvent uniquement être des fichiers image. Ces fichiers doivent être présents dans le répertoire "<NomProjet>_WEB". Ces images ne sont pas transformées lors de l'enregistrement de la page. Il n'est pas nécessaire d'utiliser la fonction fRepWeb pour indiquer le chemin de l'image. Ce chemin est relatif au répertoire "<NomProjet>_WEB".

**Remarque** : Il est conseillé d'utiliser des images 16 x 16 pixels (taille des petites icônes).
