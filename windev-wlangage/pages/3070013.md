# SocketExiste (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Teste l'existence d'un socket.
**Remarques** :

- Pour tester la validité de la connexion, il faut utiliser la fonction [SocketClientInfo](3070009.md) pour vérifier l'adresse IP du socket client et le numéro de port.
- Tant que le socket créé n'a pas été fermé par la fonction [SocketFerme](3070015.md), le socket existe.
- En cas d'interruption de la communication, la fonction **SocketExiste** peut retourner un résultat positif alors que le dialogue est arrêté.

## Exemple

```wlangage
// Vérification de l'existence avant la création
SI SocketExiste("MaSocket") = Faux ALORS
	SI SocketCrée("MaSocket", 8000) = Faux ALORS
		 Erreur("Erreur création " + ErreurInfo(errMessage))
	 FIN
SINON
	 SocketLit("MaSocket", Faux)
FIN
```

## Syntaxe

```wlangage
<Résultat> = SocketExiste(<Nom du socket>)
```

`<Résultat>` *Booléen*
> - Vrai si le socket existe,
> - Faux dans le cas contraire.
`<Nom du socket>` *Chaîne de caractères*
> Nom du socket à vérifier.
> Dans le cas d'une application WINDEV, ce nom a été défini :
>
>
> - soit par la fonction [SocketCrée](3070011.md), [SocketCréeSSL](1000017041.md) ou [SocketCréeInfraRouge](3070012.md) (cas d'un serveur simplifié).
> - soit par la fonction [SocketAccepte](3070004.md) (cas d'un serveur standard).
> - soit par la fonction [SocketConnecte](3070016.md) (cas d'un site WEBDEV).
>
>
> > _(WINDEV)_ Attention : le nom du socket est "case-sensitive".

## Remarques

> _(Android, Widget Android)_ Permissions requisesL'utilisation de cette fonction entraîne la modification des permissions requises par l'application. Permission requise : INTERNET Cette permission autorise l'application à ouvrir des sockets réseau.
