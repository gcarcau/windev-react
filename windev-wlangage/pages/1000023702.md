# <Zone répétée>.SupprimeSelect (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Supprime la ou les lignes sélectionnées dans un champ Zone répétée.

## Exemple

```wlangage
// Supprime toutes les répétitions sélectionnées
SI OuiNon("Voulez-vous vraiment supprimer les clients sélectionnés ?") ALORS
	ZR_Affichage_Client.SupprimeSelect()
FIN
```

## Syntaxe

```wlangage
<Champ Zone répétée>.SupprimeSelect()
```

`<Champ Zone répétée>` *Nom de champ*
> Nom du champ Zone répétée à manipuler.

## Remarques

### Conditions d'utilisation
La fonction **<Zone répétée>.SupprimeSelect** peut être utilisée indifféremment sur :

- un champ Zone répétée fichier,
- un champ Zone répétée par programmation.

### Suppression dans un champ Zone répétée fichier
La fonction **<Zone répétée>.SupprimeSelect** supprime les enregistrements correspondants dans le fichier de données associé au champ. Si des rubriques sont reliées à d'autres fichiers de données, aucune modification n'est effectuée automatiquement sur ces fichiers de données liés.

### Intégrité référentielle et champ Zone répétée fichier
Si la gestion de l'intégrité référentielle est active (fonction [<Variable Connexion>.GèreIntégrité](1000023960.md)), testez la fonction [HErreurIntégrité](3044086.md) après l'appel de la fonction **<Zone répétée>.SupprimeSelect** pour vérifier l'intégrité. Si une erreur d'intégrité est détectée, la répétition n'est pas supprimée et reste visible dans le champ.

### Suppression dans un champ Zone répétée fichier et Trigger
Il est possible de déclencher un trigger lors de la suppression d'un enregistrement dans un champ Zone répétée fichier. Pour plus de détails, consultez la documentation de la fonction [<Source>.DécritTrigger](1000024216.md).

### Gestion des erreurs
En cas d'échec de la suppression, la variable [ErreurDétectée](3087001.md) est à Vrai. Pour plus de détails sur l'erreur, il est possible d'utiliser la fonction [ErreurInfo](3013008.md).

### Blocage du fichier de données lié
Si le fichier de données est bloqué dans le traitement en cours, la fonction **<Zone répétée>.SupprimeSelect** supprime la ligne spécifiée et débloque le fichier de données.
