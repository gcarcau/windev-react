# Fonctions de gestion des champs Chemin de navigation

> **Disponible :** **WEBDEV** (Windows, Linux, PHP)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des chemins de navigation (syntaxe préfixée)](3083039.md)).
Les fonctions permettant de gérer les champs Chemin de navigation sont les suivantes :

| [CheminNavigationAjouteLien](3083016.md) | Ajoute un lien dans un champ Chemin de navigation. |
| --- | --- |
| [CheminNavigationInsèreLien](3083017.md) | Insère un lien dans un champ Chemin de navigation. |
| [CheminNavigationModifieLien](3083018.md) | Modifie un lien dans un champ Chemin de navigation. |
| [CheminNavigationSupprimeLien](3083019.md) | Supprime un lien dans un champ Chemin de navigation. |
| [CheminNavigationSupprimeTout](3083020.md) | Supprime tous les liens dans un champ Chemin de navigation. |
