# Valeur (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

La propriété **Valeur** permet de connaître et de modifier la valeur d'un élément. Cette propriété est utilisable sur :

- un champ d'une fenêtre, d'un état ou d'une page. Pour plus de détails, consulter [Propriété Valeur sur les champs](2510130.md).
- une variable de type [gglLieu](1000017441.md).
- une variable de type [rssFlux](1000017795.md).
- une variable de type [rssSource](1000017803.md).
- une variable de type [rssIdentifiant](1000017797.md).
- une variable de type [rssCatégorie](1000017782.md).
- une variable de type [xlsCellule](1000017472.md).
- une variable de type [xlsDocument](1000017464.md).
- une variable de type [xmlLecteur](1000023392.md).
- une variable de type [Cookie](1000019222.md).
- une variable de type [xmlAttribut](1000018799.md).
- une variable générée automatiquement lors de l'[import d'un Webservice](3086001.md).

- une variable de type [Icône](1000020811.md).
- une variable de type [Tiff](1000021025.md).

- une variable de type [emailEntête](1000020774.md).
- une variable de type [hbCellule](1000021707.md).
- une variable de type [xpathRésultat](1000021967.md).
- une variable de type [AuthToken](1000022220.md).
- une variable de type [docElémentTexte](1000022493.md).
- une variable de type [docNiveauNumérotation](1000022799.md).
- une variable de type [memcachedRésultat](1000023359.md).
- une variable de type [Description d'Option](1000023072.md).
- une variable de type [Description de valeur](1000023061.md).
- une variable de type [Jeton](1000023942.md).
- une variable de type [Chrono](1000023560.md).
- une variable de type [URI](1000024027.md).
- une variable de type [pdfDocument](1000024909.md).
- une variable de type [YAML](1000024438.md).
- une variable de type [htmlAttribut](1000025912.md).
- une variable de type [Diagramme](1410088055.md).
- Nouveauté 2025
   une variable de type [pdfChamp](1410090536.md).
- Nouveauté 2025
  une variable de type [jsonLecteur](1410090783.md).
  **Attention** : Cette fonctionnalité est disponible uniquement à partir de la version 2025 Update 3.
