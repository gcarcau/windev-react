# DonneCouleur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Permet d'obtenir une suite de couleurs harmonieuses sans avoir à utiliser une table de couleurs.

## Exemple

```wlangage
// Remplit les données du champ Graphe
POUR I = 1 À 12
	// Ajoute le chiffre d'affaires du mois numéro I
	grAjouteDonnée(GRF_MonGraphe, I, tabValeurs[I])

	// Affecte une couleur à la série du mois numéro I
	grCouleurSérie(GRF_MonGraphe, I, DonneCouleur())
FIN
```

## Syntaxe

```wlangage
<Résultat> = DonneCouleur([<Indice> [, <Série>]])
```

`<Résultat>` *Entier*
> Couleur au format RVB.
> > _(WEBDEV - Code Navigateur)_ <Résultat> correspond à une variable de type Couleur.
`<Indice>` *Entier optionnel*
> Numéro de la couleur à récupérer.
> Si ce paramètre n'est pas spécifié, la couleur renvoyée est une couleur qui n'a jamais été utilisée.
> Si ce paramètre est spécifié, pour un indice donné, la même couleur sera toujours renvoyée.
>
> > _(PHP)_ Ce paramètre n'est pas disponible.
`<Série>` *Constante optionnelle de type Entier*
> Constante indiquant le style de série de couleur à récupérer :
>
> | *coulSérieDéfaut* (Valeur par défaut) | La couleur renvoyée est choisie parmi une série de couleurs standard. |
> | --- | --- |
> | *coulSérieFoncée* | La couleur renvoyée est choisie parmi une série de couleurs plus foncées (adaptée au champ TreeMap par exemple). |
> | *coulSérieGabarit* | La couleur renvoyée est choisie parmi la série de couleurs définie pour le gabarit en cours. _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur, PHP)_ Cette constante n'est pas disponible. |
> | *coulSériePalette* | La couleur renvoyée est choisie parmi la série de couleurs définie pour la palette en cours. _(WINDEV, Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst, Java)_ Cette constante n'est pas disponible. |
> | *coulSériePastel* | La couleur renvoyée est choisie parmi une série de couleurs plus claires. |

## Remarques

> _(WEBDEV - Code Navigateur)_ AstuceSi le résultat est affiché dans une trace à l'écran (fonction Trace), la variable de type Couleurest convertie en chaîne correspondant à la couleur au format RVB.
