# sfRequêteTraitementTâche (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Le type **sfRequêteTraitementTâche** permet de décrire la requête de traitement d'une tâche à soumettre à la fonction [SFExécuteTraitement](1000018523.md). Les caractéristiques de ce type peuvent être modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Propriétés

### Propriétés spécifiques à la description des variables de type sfRequêteTraitementTâche
Les propriétés suivantes peuvent être utilisées pour manipuler la requête de traitement d'une tâche à soumettre à la fonction [SFExécuteTraitement](1000018523.md) :

| Nom | Type manipulé | Effet |
| --- | --- | --- |
| Action | Chaîne de caractères | Action à réaliser sur la tâche Salesforce. Cette action peut correspondre à une des chaînes de caractères suivantes :  - Approve - Reject - Remove |
| Commentaire | Chaîne de caractères | Commentaire à ajouter à l'historique du traitement de la tâche. |
| IDApprobateurSuivant | Chaîne de caractères | Identifiants des utilisateurs qui devront effectuer la prochaine opération. |
| IDTâche | Chaîne de caractères | Identifiant de la tâche à traiter. |

## Remarques

### Fonctions manipulant le type sfRequêteTraitementTâche

| [SFExécuteTraitement](1000018523.md) | Demande l'exécution d'un traitement spécifique. |
