# MatRéelAdditionne (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Additionne une valeur à chaque élément d'une matrice. Cette addition est réalisée directement dans la matrice spécifiée.

## Exemple

```wlangage
// Addition de la valeur 3 à une matrice
MatRéelAdditionne("MaMatrice", 3)
```

## Syntaxe

```wlangage
MatRéelAdditionne(<Matrice> , <Valeur>)
```

`<Matrice>` *Chaîne de caractères*
> Nom de la matrice à manipuler, défini avec la fonction [MatCrée](3050058.md).
`<Valeur>` *Réel*
> Valeur à ajouter à la matrice.

## Remarques

### Existence de la matrice
L'existence de la matrice n'est pas vérifiée. Pour vérifier l'existence d'une matrice, utilisez la fonction [MatExiste](3050076.md).

### Gestion des erreurs
**Attention** : La fonction **MatRéelAdditionne** ne retourne pas de code d'erreur. Pour savoir si des erreurs ont été générées, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
