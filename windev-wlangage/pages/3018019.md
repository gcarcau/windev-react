# Constantes Arbre

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Afficher uniquement les constantes utilisées par les syntaxes préfixées
Afficher uniquement les constantes utilisées par les syntaxes non préfixées

Les constantes de gestion des champs Arbre sont les suivantes :

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |
| **aAccepteDoublon** | Position de la feuille par rapport aux éléments du même niveau : les doublons sont acceptés. | [ArbreAjoute](3018012.md), [ArbreDéplaceElément](3018024.md) |
| **aAprès** | Position de la feuille insérée : feuille insérée après l'élément "frère" spécifié. | [ArbreInsère](3018023.md) |
| **aAscendant** | Type de tri : tri par ordre alphabétique. | [ArbreTrie](3018020.md) |
| **aAvant** | Position de la feuille insérée : feuille insérée avant l'élément "frère" spécifié. | [ArbreInsère](3018023.md) |
| **aDéfaut** | Type d'image associée à la feuille : image par défaut. | [ArbreAjoute](3018012.md), [ArbreInsère](3018023.md), [ArbreModifie](3018013.md) |
| **aDernier** | Position de la feuille par rapport aux éléments du même niveau : feuille insérée ou déplacée à la dernière place du niveau. | [ArbreAjoute](3018012.md), [ArbreDéplaceElément](3018024.md) |
| **aDéroule** | État d'un noeud : noeud déroulé | [ArbreEtat](3018015.md) |
| **aDescendant** | Type de tri : tri à l'inverse de l'ordre alphabétique. | [ArbreTrie](3018020.md) |
| **aEnroule** | État d'un noeud : noeud enroulé | [ArbreEtat](3018015.md) |
| **aErreur** | État d'un noeud / Type d'un élément : noeud ou élément inexistant. | [ArbreEtat](3018015.md), [ArbreTypeElément](3018014.md) |
| **aFeuille** | Type d'un élément : élément feuille. | [ArbreTypeElément](3018014.md), [ArbreCherche](3018030.md) |
| **aiArbreID** | Type d'information demandée : Identifiant de l'élément au point (X,Y). | [ArbreInfoXY](3018026.md) |
| **aiNomBranche** | Type d'information demandée : Nom de l'élément au point (X, Y). | [ArbreInfoXY](3018026.md) |
| **aiNumLigne** | Type d'information demandée : Numéro de la ligne au point (X, Y). | [ArbreInfoXY](3018026.md) |
| **aiOrigineEcran** | Si cette option est précisée, l'origine des coordonnées spécifiées correspond à l'écran et non au champ Arbre. | [ArbreInfoXY](3018026.md) |
| **aizBouton** | Type de la zone survolée : Bouton "+ / -" situé devant le libellé de l'élément de l'arbre. | [ArbreInfoXY](3018026.md) |
| **aizCoche** | Type de la zone survolée : Coche de l'élément. | [ArbreInfoXY](3018026.md) |
| **aizDroite** | Type de la zone survolée : Espace à droite du libellé de l'élément. | [ArbreInfoXY](3018026.md) |
| **aizEnDehors** | Type de la zone survolée : Espace situé sous les éléments de l'arbre. | [ArbreInfoXY](3018026.md) |
| **aizGauche** | Type de la zone survolée : Espace situé à gauche du libellé de l'élément. | [ArbreInfoXY](3018026.md) |
| **aizImage** | Type de la zone survolée : Image située devant le libellé de l'élément. | [ArbreInfoXY](3018026.md) |
| **aizLibellé** | Type de la zone survolée : Libellé de l'élément. | [ArbreInfoXY](3018026.md) |
| **aiZone** | Type d'information demandée : Type de la zone survolée. | [ArbreInfoXY](3018026.md) |
| **aNoeud** | Type d'un élément : élément noeud. | [ArbreTypeElément](3018014.md), [ArbreCherche](3018030.md) |
| **aPremier** | Position de la feuille par rapport aux éléments du même niveau / Indique le "fils" voulu : feuille insérée ou déplacée à la première place du niveau / Premier élément fils. | [ArbreAjoute](3018012.md), [ArbreDéplaceElément](3018024.md) [ArbreRécupèreFils](3018010.md) |
| **aSuivant** | Indique le "fils" voulu : fils suivant. | [ArbreRécupèreFils](3018010.md) |
| **aTout** | Niveau des éléments à prendre en compte : tous les "fils" sont pris en compte. | [ArbreOccurrence](3018009.md) |
| **aTriAlpha** | Position de la feuille par rapport aux éléments du même niveau : feuille insérée ou déplacée suivant l'ordre alphabétique. | [ArbreAjoute](3018012.md), [ArbreDéplaceElément](3018024.md) |
| **aUnNiveau** | Niveau des éléments à prendre en compte : seuls les "fils" immédiats sont pris en compte. | [ArbreOccurrence](3018009.md), [ArbreCherche](3018030.md) |
