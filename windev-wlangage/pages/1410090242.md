# HRequêteExécutée (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Permet de savoir si une requête a été exécutée. Cette fonction peut être notamment utilisée avant de parcourir les résultats de la requête. En effet, si le parcours est effectué sur le résultat d'une requête non exécutée, une erreur WLangage sera affichée.
**Différence avec la fonction [HSourceDeDonnéesConnue](1410090243.md)** : La fonction [HSourceDeDonnéesConnue](1410090243.md) permet de savoir si la source de données est connue du moteur HFSQL, quelque soit son contenu. La fonction **HRequêteExécutée** est utilisable uniquement sur les requêtes.

## Exemple

```wlangage
reqStatVols est une Requête SQL =
[
	SELECT * FROM  Vols
	WHERE Vols.IDAéroportDépart = {ParamIDAéroportDépart}
	AND Vols.IDAéroportArrivée = {ParamIDAéroportArrivée}
]
reqStatVols.ParamIDAéroportDépart = 12
reqStatVols.ParamIDAéroportArrivée = 2

SI PAS HRequêteExécutée(reqStatVols) ALORS
	HExécuteRequêteSQL(reqStatVols)
FIN
```

## Syntaxe

```wlangage
<Résultat> = HRequêteExécutée(<Requête à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si la requête a déjà été exécutée,
> - Faux dans le cas contraire ou si le paramètre <Requête à vérifier> ne correspond pas à une requête. La fonction [HErreurInfo](3044071.md) permet d'obtenir plus d'informations sur le problème rencontré.
`<Requête à vérifier>` *Chaîne de caractères*
> Nom de la requête à vérifier. Ce paramètre peut correspondre à :
>
> - Nom et chemin complet de la requête (fichier ".WDR").
> - Nom logique de la requête.
> - Nom d'une variable de type [Requête SQL](1514082.md).
>
> Si ce paramètre ne correspond pas au nom d'une requête, <Résultat> correspondra à Faux.

## Remarques

Les requêtes de type "INSERT", "DELETE" et "CREATE" ne sont parcourables que si elles contiennent l'ordre SQL "RETURNING".
