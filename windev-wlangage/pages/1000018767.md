# emailSessionOutlook (Type de variable)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Le type **emailSessionOutlook** permet de manipuler le logiciel de messagerie Outlook (emails, contacts, groupes de contacts, tâches, rendez-vous et dossiers). Les caractéristiques de la connexion peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Attention** : Cette fonction ne permet pas d'accéder aux différentes données manipulées par le logiciel de messagerie Outlook Express.

**Remarques** :

- Lors de l'utilisation de la fonction [EmailOuvreSessionOutlook](3032128.md), le répertoire en cours est automatiquement modifié par Outlook.
- Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Ouverture de la session
MaSession est une emailSessionOutlook
MaSession..Nom = "ProfilOutlook"
EmailOuvreSession(MaSession)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type emailSessionOutlook
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **emailSessionOutlook** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Nom | Chaîne de caractères | Identifie le profil de la connexion. Si ce paramètre correspond à une chaîne vide ("") :   - si plusieurs profils sont définis sur le poste en cours, la fonction [EmailOuvreSession](3032028.md) affiche une fenêtre contenant tous les profils dans laquelle l'utilisateur peut choisir son profil. - si un seul profil est défini sur le poste en cours, la fonction [EmailOuvreSession](3032028.md) sélectionne automatiquement ce profil. |
