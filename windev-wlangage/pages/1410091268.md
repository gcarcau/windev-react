# JSON : Manipulations de fichiers de plusieurs gigaoctets

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

## Présentation

Depuis la version 2025, un parseur JSON est intégré dans WINDEV, WEBDEV et WINDEV Mobile afin de manipuler les fichiers JSON de plusieurs Gigas : par exemple, données de Open Street Map ou de Open Data France.
La vitesse de lecture et la consommation mémoire sont nettement améliorées sur les fichiers JSON de taille importante. En effet, le fichier n'est pas chargé en mémoire : il est simplement parcouru.

**Attention** : Cette fonctionnalité est disponible uniquement à partir de la version 2025 Update 3.

## Comment le faire ?

### Méthode
Pour lire un fichier JSON de taille importante :

1. Ouvrez le fichier JSON à lire avec la fonction [JSONOuvreLecteur](1410090784.md). Cette fonction permet d'initialiser une variable de type [jsonLecteur](1410090783.md).
  Par exemple :
  ```wlangage
  Lecteur est un jsonLecteur = JSONOuvreLecteur("MonFichier.json")
  ```
2. Parcourez le JSON en utilisant une des syntaxes de [POUR TOUT](1510029.md).
3. Les propriétés de la variable [jsonLecteur](1410090783.md) permettent de connaître les caractéristiques de l'élément lu.

### Exemples
L'exemple ci-dessous présente un fichier json didactique et différents modes de parcours avec la liste des éléments parcourus.
Fichier JSON traité :

```wlangage
// Parcours sur un niveau
// Lecteur est la variable correspondant au fichier JSON
Lecteur est un jsonLecteur = JSONOuvreLecteur("fichier.json")
POUR CHAQUE Lecteur
	// Lecture du tableau racine ligne 1
	POUR CHAQUE Lecteur
		// Lecture des objets lignes 2 et 21
		POUR CHAQUE Lecteur
			// Lecture des membres lignes 3 à 5, 22 à 24
			POUR CHAQUE Lecteur
				// Lecture des objets lignes 7, 13, 26 et 32
				POUR CHAQUE Lecteur
					// Lecture des membres lignes 8 à 11, 14 à 17, 27 à 30 et 33 à 36
				FIN
			FIN
		FIN
	FIN
FIN
```

```wlangage
// Parcours sur un niveau avec copie
// Lecteur est la variable correspondant au fichier JSON
Lecteur est un jsonLecteur = JSONOuvreLecteur("fichier.json")
POUR CHAQUE tableau_clients DE Lecteur
	// Lecture du tableau racine ligne 1
	POUR CHAQUE client DE tableau_clients
		// Lecture des objets lignes 2 et 21
		POUR CHAQUE propriété_client DE client
			// Lecture des membres lignes 3, 4, 5, 22, 23 et 24
			SI propriété_client.Nom = "addresses" ALORS
				POUR CHAQUE adresse DE propriété_client
					// Lecture des objets lignes 7, 13, 26 et 32
					POUR CHAQUE propriété_adresse DE adresse
						// Lecture des membres lignes 8 à 11, 14 à 17, 27 à 30 et 33 à 36
					FIN
				FIN
			FIN
		FIN
	FIN
FIN
```

```wlangage
// Parcours en profondeur
// Lecteur est la variable correspondant au fichier JSON
Lecteur est un jsonLecteur = JSONOuvreLecteur("fichier.json")
POUR CHAQUE Lecteur EN PROFONDEUR
	// Lecture de tous les éléments ligne 1, 2, 3 à 5, 7, 8 à 11, 13, 14 à 17,
	// 21, 22 à 24, 26, 27 à 30, 32 et 33 à 36
FIN
```
