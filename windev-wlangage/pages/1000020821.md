# gpwOuvreSite (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux)

Permet de lancer le site lors de l'utilisation du groupware utilisateur.

## Exemple

```wlangage
// Ouverture du sitegpwOuvreSite()
```

## Syntaxe

```wlangage
<Résultat> = gpwOuvreSite()
```

`<Résultat>` *Booléen*
> - Vrai si le site a été lancé,
> - Faux dans le cas contraire.

**Composante : wd300gpu.dll**
