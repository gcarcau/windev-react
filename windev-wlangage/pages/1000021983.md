# <Variable hdfsConnexion>.FermeConnexion (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Ferme une connexion à un serveur Hadoop.

## Exemple

```wlangage
// Connexion
MaConnexion est une hdfsConnexion
MaConnexion.namenode = "MonServeur"
MaConnexion.Utilisateur = "Admin"
SI MaConnexion.OuvreConnexion() ALORS
	// Fermeture de la connexion
	MaConnexion.FermeConnexion()
SINON
	Erreur()
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.FermeConnexion()
```

`<Résultat>` *Booléen*
> - Vrai si la déconnexion a été réalisée,
> - Faux en cas de problème. La fonction [ErreurInfo](3013008.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type hdfsConnexion*
> Nom de la variable de type [hdfsConnexion](1000021650.md) correspondant à la connexion au serveur Hadoop à fermer.

**Composante : wd300big.dll**
