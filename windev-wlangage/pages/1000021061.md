# Constantes InApp

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |
| **inAppAbonnement** | Type de produit manipulé : Abonnement | Type [inAppProduit](1000020868.md) |
| **inAppAnnulation** | Erreur renvoyée par la fonction ErreurInfo(ErrCode)  Achat annulé par l'utilisateur. | [inAppAchèteProduit](1000020873.md) |
| **inAppDateAchat** | Date d'achat au format AAAAMMJJ. | [inAppListeAchat](1000020888.md) |
| **inAppDateFinAbonnement** | Date de fin d'abonnement au format AAAAMMJJ. | [inAppListeAchat](1000020888.md) |
| **inAppErreurInconnue** | Erreur renvoyée par la fonction ErreurInfo(ErrCode)  Erreur inconnue. | [inAppAchèteProduit](1000020873.md) |
| **inAppErreurSignature** | Erreur renvoyée par la fonction ErreurInfo(ErrCode)  Erreur lors de la vérification de la signature des données reçue pour la validation de l'achat (problème de sécurité). | [inAppAchèteProduit](1000020873.md) |
| **inAppIdentifiantAchat** | Identifiant de l'achat. | [inAppListeAchat](1000020888.md) |
| **inAppNuméroCommande** | Numéro de la commande correspondant à l'achat. | [inAppListeAchat](1000020888.md) |
| **inAppProduit** | Type de produit manipulé : Produit consommable et non consommable. | Type [inAppProduit](1000020868.md) |
| **inAppRenouvellementAuto** | Paramétrage du renouvellement automatique. | [inAppListeAchat](1000020888.md) |
| **inAppRéponseInvalide** | Erreur renvoyée par la fonction ErreurInfo(ErrCode)  Réponse invalide. | [inAppAchèteProduit](1000020873.md) |
