# PartageProximitéRechercheAppareil (Fonction)

> **Disponible :** **WINDEV Mobile** (Android)

Recherche les appareils à proximité qui ont annoncé leur présence et qui sont en attente de connexion.

## Exemple

```wlangage
// Code de l'interrupteur permettant d'activer ou non la recherche des appareils
INT_Recherche.Etat = Grisé
SI INT_Recherche ALORS
	PartageProximitéRechercheAppareil(CallbackRésultat, CallbackDécouverte, gnTopologieDeRéseau)
SINON
	PartageProximitéArrêteRecherche()
	INT_Recherche.Etat = Actif
FIN
		PROCÉDURE INTERNE CallbackRésultat(bRésultat est un booléen)
			SI bRésultat ALORS
				INT_Recherche.Etat = Actif
			SINON
				Info("Échec de la recherche d'appareils ou de l'attente de connexion :" + RC + ErreurInfo())
			FIN
		FIN
```

```wlangage
PROCÉDURE CallbackDécouverte(bDecouverte est un booléen, sIdAppareil est une chaîne, sNomAppareil est une chaîne)
SI bDecouverte ALORS
	ToastAffiche("Appareil découvert : " + sNomAppareil)
SINON
	ToastAffiche("Appareil indisponible : " + sNomAppareil)
FIN
```

## Syntaxe

```wlangage
PartageProximitéRechercheAppareil(<Procédure de résultat> , <Procédure de recherche> [, <Topologie>])
```

`<Procédure de résultat>` *Nom de procédure*
> Nom de la procédure WLangage (également nommée "callback") exécutée pour notifier la réussite ou l'échec du démarrage de la recherche.
> Pour plus de détails sur cette procédure, consultez [Paramètres de la procédure utilisée par la fonction PartageProximitéRechercheAppareil (Résultat)](1410090663.md).
`<Procédure de recherche>` *Nom de procédure*
> Nom de la procédure WLangage (également nommée "callback") exécutée lorsqu'un nouvel appareil distant a été trouvé ou lorsqu'un appareil précédemment trouvé n'est plus accessible.
> Il est d'usage d'effectuer la demande de connexion à l'appareil dans le code de cette procédure (fonction [PartageProximitéDemandeConnexion](1410090650.md)).
> Pour plus de détails sur cette procédure, consultez [Paramètres de la procédure utilisée par la fonction PartageProximitéRechercheAppareil (Recherche)](1410090664.md).
`<Topologie>` *Constante de type Entier optionnelle*
> Topologie de réseau à utiliser pour la connexion aux autres appareils.
> Le choix de la topologie définit les contraintes de connexion entre appareils et les technologies mises en oeuvre pour le partage (WiFi Direct, Bluetooth, BTLE).
> Ce paramètre peut correspondre à une des constantes suivantes :
>
>
> | *ppCluster* | Topologie de cluster entre les appareils à proximité.  Dans cette topologie, chaque appareil peut se connecter à plusieurs appareils et/ou accepter les connexions de plusieurs appareils. Chaque appareil peut être à la fois "annonceur" (qui peut accepter des connexions entrantes de N autres appareils) ou "découvreur" (qui peut établir une connexion sortante à un seul appareil).   Cette topologie est adaptée dans les situations d'échanges multidirectionnels qui ne nécessitent pas le transfert de volumes importants de données.   Cette topologie utilise la technologie Bluetooth 5.0. |
> | --- | --- |
> | *ppEtoile* | Topologie pour les applications qui distribuent des informations à partir d'un point centralisé. Chaque appareil peut, à tout moment, jouer le rôle d'un "annonceur" (qui peut accepter des connexions entrantes de N autres appareils) ou d'un "découvreur" (qui peut établir une connexion sortante à un seul appareil), mais pas les deux en même temps. Une fois le lien établi, les appareils conservent leur rôle jusqu'à la fin de la connexion.   Cette topologie est adaptée aux situations dans lesquelles un seul appareil diffuse du contenu en continu nécessitant beaucoup de bande passante à plusieurs appareils (exemple : streaming vidéos).   Cette topologie utilise les technologies Bluetooth 5.0 et Wi-Fi Direct. |
> | *ppPointAPoint* (Valeur par défaut) | Topologie pour les connexions de type "un à un" où chaque appareil peut se connecter uniquement à un seul autre appareil à la fois. Il est ainsi possible de maximiser la bande passante du lien. Cette topologie est destinée aux applications qui nécessitent l'échange de données volumineuses, comme le transfert de fichiers.  Cette topologie utilise les technologies Bluetooth 5.0 et Wi-Fi Direct. |

## Remarques

- Pour demander la connexion à l'appareil découvert, utilisez la fonction [PartageProximitéDemandeConnexion](1410090650.md).
- Le processus de recherche peut entraîner une consommation de ressources réseau importante, il est donc conseillé d'arrêter la recherche dès que tous les appareils avec lesquels le partage doit être effectué sont trouvés.
- Il est toujours possible d'envoyer des données aux appareils connectés après l'arrêt de la recherche.
- Pour arrêter la recherche, utilisez la fonction [PartageProximitéArrêteRecherche](1410090649.md).
