# DéchargeDLL

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Le mot-clé **DéchargeDLL** peut correspondre :

- à la fonction **DéchargeDLL** qui permet de décharger une librairie 32 bits (DLL) qui a été précédemment chargée en mémoire. Pour plus de détails, consultez [DéchargeDLL](3014009.md).
- à la propriété **DéchargeDLL** disponible sur une variable de type [Description d'API](1000019149.md).
