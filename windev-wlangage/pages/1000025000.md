# <Source>.JournalInfo (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **Autres** (Procédures stockées)

Ajoute des commentaires dans le journal lors de l'enregistrement de l'opération journalée. Ces commentaires seront utilisés pour toutes les opérations effectuées dans le contexte HFSQL en cours, jusqu'au prochain appel de la fonction **<Source>.JournalInfo**.

## Exemple

```wlangage
Client.JournalInfo("Ajout de " + Client.NomClient)
Client.Ajoute()
```

#### Définir un commentaire spécifique par fichier de données journalé

```wlangage
<Résultat> = <Source>.JournalInfo(<Message>)
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Source>` *Type correspondant à la source spécifiée*
> Nom du fichier de données journalé auquel le message se rapporte.
`<Message>` *Chaîne de caractères*
> Message à insérer dans les informations de journalisation (16 caractères maximum, si la chaîne est plus longue, les informations seront tronquées). Ces informations pourront être récupérées grâce à l'outil [WDLog](3516012.md).
> Si ce paramètre n'est pas spécifié, aucun message n'est inséré.

## Remarques

Pour insérer des informations différentes lors de chaque opération, il est nécessaire d'appeler la fonction **<Source>.JournalInfo** avant chaque opération.

**Composante : wd300hf.dll**
