# FTPDéconnecte (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Ferme la connexion entre le poste en cours et le serveur FTP (File Transfer Protocol). Cette connexion a été établie avec la fonction [FTPConnecte](3040016.md).
Nouveauté Abonnement
Une nouvelle syntaxe manipulant une variable de type [ftpConnexion](1410090869.md) est disponible.

**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst, Java, Code Utilisateur (MCU), Ajax, WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Android, Widget Android, Java, Code Utilisateur (MCU), Ajax)_ // Connexion à un serveur FTP
nConnexion est un entier
nConnexion = FTPConnecte("192.108.10.2")
...
// Déconnexion
FTPDéconnecte(nConnexion)

Nouveauté Abonnement

// Syntaxe non disponible en PHP
// Connexion du poste en cours au serveur FTP
MaConnexionFTP est une ftpConnexion
MaConnexionFTP.Serveur = "192.54.12.8"
FTPConnecte(MaConnexionFTP)
...
// Déconnexion
FTPDéconnecte(MaConnexionFTP)

## Syntaxe

```wlangage
<Résultat> = FTPDéconnecte(<Connexion FTP>)
```

`<Résultat>` *Booléen*
> - Vrai si la déconnexion a été effectuée,
> - Faux en cas d'erreur. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de détails.
`<Connexion FTP>` *Entier ou variable de type ftpConnexion*
> - Identifiant de la connexion, obtenu avec la fonction [FTPConnecte](3040016.md).
>    Ce paramètre est de type Variant.
> - Nouveauté Abonnement
>   Nom de la variable de type [ftpConnexion](1410090869.md) correspondant à la connexion FTP utilisée.
>   **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
>   Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
>    Non disponible.

## Remarques

### Délai
Par défaut, toutes les fonctions FTP échouent si aucune réponse du serveur FTP n'est reçue après 20 secondes. Ce délai peut être modifié :

- lors de la connexion au serveur FTP avec la fonction [FTPConnecte](3040016.md) (paramètre <Durée de non réponse>).
- Nouveauté Abonnement
  lors de la définition des paramètres de la variable [ftpConnexion](1410090869.md) (propriété **DuréeNonRéponse**).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

> _(Android, Widget Android)_ Permissions requisesL'utilisation de cette fonction entraîne la modification des permissions requises par l'application. Permission requise : INTERNET Cette permission autorise l'application à ouvrir des sockets réseau.
