# CipherChoisi

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **CipherChoisi** permet de connaître le nom du cipher choisi. Cette propriété est utilisable sur :

- une variable de type [httpRequête](1000021158.md).
- une variable de type [restRequête](1000021481.md).
