# grMenu (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Permet de choisir le type du menu contextuel affiché par un graphe.

## Exemple

```wlangage
// Affiche le menu contextuel sous forme de popup du graphe "MonGraphe", créé par programmation
grMenu("MonGraphe", grMenuPourCompatibilité)
```

```wlangage
// Active le menu contextuel sous forme de fenêtre pour le champ GRF_MonGraphe
grMenu(GRF_MonGraphe, grMenuFenêtre)
```

## Syntaxe

```wlangage
grMenu(<Nom du graphe> , <Type de menu>)
```

`<Nom du graphe>` *Nom de champ ou chaîne de caractères*
> Nom du graphe à manipuler. Ce nom correspond :
>
> - soit au nom du graphe défini par programmation avec la fonction [grCrée](3042005.md).
> - soit au nom du champ Graphe présent dans l'éditeur de fenêtres.
`<Type de menu>` *Constante de type Entier*
> Type de menu à afficher :
>
> | *grMenuAucun* | Aucun menu contextuel n'est affiché.  Remarque : Cette constante correspond à la valeur Faux utilisée dans les versions précédentes. |
> | --- | --- |
> | *grMenuFenêtre* | Un menu contextuel sous forme de fenêtre est affiché. |
> | *grMenuPourCompatibilité* | Un menu contextuel déroulant est affiché. Cette option permet d'afficher le menu des graphes présent dans les versions antérieures à la version 23.  Remarque : Cette constante correspond à la valeur Vrai utilisée dans les versions précédentes. |

## Remarques

- Pour modifier le texte des options du menu contextuel conservé par compatibilité, utilisez la fonction [grOptionMenu](3042042.md).
- Les données définies avec la fonction **grMenu** seront prises en compte lors du prochain appel à la fonction [grDessine](3042026.md).
