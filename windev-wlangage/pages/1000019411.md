# fEstUneImage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Permet de savoir si un fichier présent sur disque ou un fichier contenu dans un buffer correspond à un format d'image reconnu par WINDEV ou WEBDEV.

## Exemple

```wlangage
SI fEstUneImage(MonBuffer) = Vrai ALORS
	Info("La variable correspond à une image.")
FIN
```

## Syntaxe

#### Analyser un fichier externe

```wlangage
<Résultat> = fEstUneImage(<Nom et chemin du fichier>)
```

`<Résultat>` *Booléen*
> - Vrai si le fichier est une image pouvant être chargée par WINDEV, WEBDEV ou WINDEV Mobile,
> - Faux dans le cas contraire.
`<Nom et chemin du fichier>` *Chaîne de caractères Ansi ou Unicode*
> Nom et chemin complet (ou relatif) du fichier à identifier. Il est possible d'utiliser un chemin UNC.

#### Analyser une variable de type Buffer

```wlangage
<Résultat> = fEstUneImage(<Nom de la variable>)
```

`<Résultat>` *Booléen*
> - Vrai si le buffer correspond à une image,
> - Faux dans le cas contraire.
`<Nom de la variable>` *Variable de type Buffer ou mémo binaire*
> Nom de la variable (de type buffer ou mémo binaire) contenant l'image à analyser.

## Remarques

### Astuce
La fonction **fEstUneImage** peut être relativement lente car elle tente de charger l'image. Pour vérifier rapidement si un fichier est une image, il est également possible de vérifier directement l'extension du fichier.

**Composante : wd300std.dll**
