# Fonctions de gestion des tableaux

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des tableaux (syntaxe préfixée)](1000024323.md)).
Ces fonctions permettent de manipuler facilement les variables de type Tableau, Tableau associatif et Tableau dynamique :

| [Agrège](1000024744.md) | Exécute une opération d'agrégation sur chaque élément d'un tableau WLangage. |
| --- | --- |
| [Ajoute](1000017348.md) | Ajoute un élément en dernière position :   - d'un tableau WLangage à une dimension. - d'une propriété tableau d'un type avancé (tableau des événements de gglAgenda, ...). - d'une liste WLangage. |
| [AjouteColonne](1000017350.md) | Ajoute une colonne à la fin d'une propriété de type tableau à deux dimensions (par exemple variable de type [xlsDocument](1000017464.md)). |
| [AjouteLigne](1000017349.md) | Ajoute une ligne à la fin :   - d'un tableau WLangage à une ou deux dimensions. - d'une propriété tableau d'un type de variable à deux dimensions (par exemple variable de type [xlsDocument](1000017464.md)). |
| [AjouteRéférence](1000023933.md) | Ajoute la référence d'un objet en dernière position dans un tableau à une dimension. |
| [Applique](1000024856.md) | Exécute une procédure pour chaque élément d'un tableau WLangage. |
| [ChaîneVersTableau](1000017008.md) | Remplit un tableau à 1 ou 2 dimensions du type spécifié avec la chaîne de caractères passée en paramètre. |
| [Cherche](1000017365.md) | Cherche l'indice d'un élément dans un tableau WLangage. |
| [ChercheParProcédure](1000020102.md) | Recherche un élément dans un tableau à une dimension en utilisant une procédure de comparaison. |
| [CSVVersTableau](1000017097.md) | Remplit un tableau à 1 ou 2 dimensions du type spécifié avec la chaîne de caractères au format CSV passée en paramètre. |
| [Déplace](1000017358.md) | Permet :  - de déplacer un élément dans un tableau WLangage à une dimension ou dans une propriété tableau d'un type avancé (tableau des événements de gglAgenda, ...). Les autres éléments du tableau sont décalés. - d'échanger deux éléments dans un tableau WLangage à une dimension ou dans une propriété tableau d'un type avancé (tableau des événements de gglAgenda, ...). |
| [DéplaceColonne](1000017360.md) | Déplace ou échange une colonne dans une propriété de type tableau à deux dimensions présente dans un type avancé (xlsDocument, ...). |
| [DéplaceLigne](1000017359.md) | Permet :  - de déplacer une ligne dans un tableau WLangage à deux dimensions ou dans une propriété tableau d'un type avancé. | [FichierVersTableau](1000018833.md) | Remplit un tableau de classes ou de structures avec le contenu d'un fichier de données ou d'une requête HFSQL. |

| [Insère](1000017351.md) | Insère un élément à une position donnée :   - dans un tableau WLangage à une dimension. - dans un tableau associatif. - dans une propriété tableau d'un type avancé (tableau des événements de gglAgenda, ...). - dans une liste WLangage. |
| [InsèreColonne](1000017353.md) | Insère une colonne à une position donnée dans une propriété tableau d'un type avancé à deux dimensions (xlsDocument, ...). |
| [InsèreLigne](1000017352.md) | Insère une ligne à une position donnée :   - dans un tableau WLangage à deux dimensions. - dans une propriété tableau d'un type avancé à deux dimensions (xlsDocument, ...). |
| [InsèreRéférence](1000023937.md) | Ajoute la référence d'un objet à la position donnée dans un tableau à une dimension. |
| [Max](3050005.md) | Renvoie la plus grande des valeurs passées en paramètre. |
| [Min](3050004.md) | Renvoie la plus petite des valeurs. |

**Enchaînement de fonctions**
Il est possible d'enchaîner les différentes fonctions de manipulation d'un tableau.
Les fonctions suivantes peuvent être utilisées dans un enchaînement :

- [Filtre](1000024845.md)
- [Transforme](1000024734.md)
- [Union](1000025408.md)
- [Intersection](1000025407.md)
- [Distinct](1000025406.md).

Cet enchaînement pourra être utilisé comme source d'une instruction POUR TOUT ou se terminer par une des fonctions suivantes :

- [Applique](1000024856.md)
- [Agrège](1000024744.md)
- [Min](3050004.md)
- [Max](3050005.md)
- [Somme](1000019892.md)
- [Moyenne](1000019891.md)
- [VérifieTousFaux](1000024858.md), [VérifieTousVrai](1000024857.md), [VérifieUnFaux](1000024860.md), [VérifieUnVrai](1000024859.md).

Exemple :

```wlangage
gnMoyenne = gtabUser.Filtre(cbFiltre).Transforme(cbTransforme).Moyenne()
```

**Remarque** : Pour remettre tous les éléments d'un tableau à leurs valeurs initiales, utilisez la fonction [VariableRAZ](3013069.md).
