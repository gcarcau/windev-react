# EnModeSessionPrélancée (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Permet de savoir si le site est lancé en mode "session prélancée" de WEBDEV.

## Exemple

```wlangage
SI EnModeSessionPrélancée() = Vrai ALORS
	Info("Site en mode session prélancée")
FIN
```

## Syntaxe

```wlangage
<Résultat> = EnModeSessionPrélancée()
```

`<Résultat>` *Booléen*
> - Vrai si le site est exécuté en mode session prélancée.
> - Faux dans le cas contraire.
>
>
> > _(WEBDEV - Code Navigateur)_ Ce paramètre correspond toujours à Faux.

## Remarques

### Disponibilité de la fonction
La fonction **EnModeSessionPrélancée** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **EnModeSessionPrélancée** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
