# PDFFerme (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Ferme le fichier PDF chargé en mémoire dans une variable de type [pdfDocument](1000024909.md).

## Exemple

```wlangage
MonPDF est un pdfDocument = "test.pdf"
POUR TOUTE PageDocument DE MonPDF.Page
	Trace(PageDocument.Hauteur)
FIN
PDFFerme(MonPDF)
```

## Syntaxe

```wlangage
PDFFerme(<PDF à fermer>)
```

`<PDF à fermer>` *Variable de type pdfDocument*
> Nom de la variable de type [pdfDocument](1000024909.md) correspondant au fichier PDF à fermer.

## Remarques

> _(Android, Widget Android)_ A partir de la version 28, cette fonction n'est pas supportée par les processeurs ARM 32 bits. En effet, les nouveautés en matière de gestion des PDF imposent une exécution en 64 bits. Si une application doit être exécutée sur une flotte existante d'appareils ARM 32 bits, la génération de cette application doit être effectuée avec la version 27 de WINDEV Mobile.
