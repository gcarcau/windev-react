# MiseEnPage (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

La propriété **MiseEnPage** permet de connaître et de modifier la mise en page :

- du diagramme en cours dans le champ Editeur de diagrammes. La mise en page est décrite dans une variable de type [diagMiseEnPage](1410088610.md).
- de la feuille en cours d'un champ Tableur. La mise en page est décrite dans une variable de type [xlsMiseEnPage](1000023139.md).

## Exemple

```wlangage
// Feuille en cours [SansMarges]
xMiseEnPage est un xlsMiseEnPage  = TBLR_ChampTableur.MiseEnPage
xMiseEnPage.MargeGauche = 0
xMiseEnPage.MargeDroite = 0
TBLR_ChampTableur.MiseEnPage = xMiseEnPage
```

## Syntaxe

#### Connaître la mise en page d'un diagramme

```wlangage
<Résultat> = <Champ Editeur de diagrammes>.MiseEnPage
```

`<Résultat>` *Variable de type diagMiseEnPage*
> Variable de type [diagMiseEnPage](1410088610.md) correspondant à la mise en page actuelle du diagramme.
`<Champ Editeur de diagrammes>` *Nom de champ*
> Nom du champ Editeur de diagrammes manipulé.

#### Modifier la mise en page d'un diagramme

```wlangage
<Champ Editeur de diagrammes>.MiseEnPage = <Nouvelle mise en page>
```

`<Champ Editeur de diagrammes>` *Nom de champ*
> Nom du champ Editeur de diagrammes manipulé.
`<Nouvelle mise en page>` *Variable de type diagMiseEnPage*
> Nom de la variable de type [diagMiseEnPage](1410088610.md) correspondant à la nouvelle mise en page du diagramme.

## Remarques

Cette mise en page est utilisée lors de l'impression du diagramme via le champ Editeur de diagrammes ou via la fonction [iImprimeDiagramme](1410088189.md).
