# <Variable mqttSession>.Déconnecte (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Permet de se déconnecter d'un serveur MQTT (également appelé "Broker").

## Exemple

```wlangage
MaSessionMQTT est un mqttSession
...
MaSessionMQTT.Déconnecte()
```

## Syntaxe

```wlangage
<Session MQTT>.Déconnecte()
```

`<Session MQTT>` *Variable de type mqttSession*
> Nom de la variable [mqttSession](1000023023.md) correspondant aux paramètres de la connexion à terminer.

## Remarques

### Déconnexion
Lors d'une déconnexion ou d'une perte de connexion, la propriété **EstConnectée** de la variable [mqttSession](1000023023.md) passe à Faux.

**Classification Métier / UI : Code métier**

**Composante : wd300com.dll**
