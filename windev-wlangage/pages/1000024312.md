# <Tableau>.Mélange (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Mélange les éléments d'un tableau WLangage.

## Exemple

```wlangage
// Initialisation du mélange aléatoire
InitHasard()

// Remplissage du tableau
PlayList est un tableau de chaînes
...

// Mélange des éléments du tableau
PlayList.Mélange()
```

## Syntaxe

```wlangage
<Tableau WLangage>.Mélange()
```

`<Tableau WLangage>` *Variable de type Tableau*
> Tableau WLangage à manipuler. Ce tableau peut avoir de 1 à N dimensions.

## Remarques

- Le mélange des éléments du tableau est basé sur la génération de nombres aléatoires. Il faut utiliser la fonction [InitHasard](3013030.md) pour réinitialiser le mélange.
- Cette fonction ne peut pas être utilisée sur les tableaux associatifs.
- Si le tableau possède plusieurs dimensions, le mélange est réalisé à travers les différentes dimensions.

**Composante : wd300vm.dll**
