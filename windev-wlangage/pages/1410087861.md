# Unicode (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Unicode** permet de connaître et de modifier le format Unicode d'un élément. Cette propriété est utilisable sur :

- un champ. Pour plus de détails, consultez [Unicode](1000017001.md).
- une variable de type [pdfParamètre](1410087857.md).
