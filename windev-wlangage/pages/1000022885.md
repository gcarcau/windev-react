# <Agenda>.Mode (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Mac Catalyst)

Renvoie le mode d'affichage d'un champ Agenda : jour, semaine, mois, ...
Remarque : La fonction [<Agenda>.ChangeMode](1000022879.md) permet de modifier le mode d'affichage du champ Agenda.

## Exemple

```wlangage
// Alterne entre l'affichage par jour et par mois
SI AGD_MonAgenda.Mode() = agzJour ALORS
	AGD_MonAgenda.ChangeMode(agzMois)
SINON
	AGD_MonAgenda.ChangeMode(agzJour)
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Champ Agenda>.Mode()
```

`<Résultat>` *Constante de type Entier*
> Plage de temps affichée par le champ Agenda :
>
> | *agzJour* | Le champ Agenda affiche une journée. |
> | --- | --- |
> | *agzMois* | Le champ Agenda affiche un mois complet. |
> | *agzNbJourPersonnalisé* | Affiche le champ Agenda sur le nombre de jours précisé grâce à la fonction [<Agenda>.ChangeMode](1000022879.md). _(WEBDEV - Code Serveur, PHP)_ Cette constante n'est pas disponible. |
> | *agzSemaine* | Le champ Agenda affiche une semaine complète (ou partielle si un nombre de jours a été précisé grâce à la fonction [<Agenda>.ChangeMode](1000022879.md)). |
> | *agzSemaineSur5* | Le champ Agenda affiche une semaine sur 5 jours (sans le week-end). |
`<Champ Agenda>` *Nom de champ*
> Nom du champ Agenda à manipuler. Ce champ peut correspondre :
>
> - au champ Agenda d'une fenêtre.
> - au champ Agenda d'un état.
> - au champ Agenda d'une page.

## Remarques

### Equivalences
Les lignes de code suivantes sont équivalentes :

```wlangage
AGD_Agenda.ChangeMode(agzSemaine, 5)
```

et

```wlangage
AGD_Agenda.ChangeMode(agzSemaineSur5)
```

Dans les 2 cas, la fonction **<Agenda>.Mode** renvoie la constante *agzSemaineSur5*.
