# Le champ Forme

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes) · **WEBDEV** (Windows) · **WINDEV Mobile** (iPhone/iPad, Mac Catalyst)

## Présentation du champ Forme

### Champ d'un état ou d'une fenêtre
Le champ Forme permet de créer dans vos fenêtres et dans vos états des formes géométriques :

- Rectangle.
- Ellipse (ce type de forme n'est pas disponible dans les états).
- Losange (ce type de forme n'est pas disponible dans les états).
- Flèche (ce type de forme n'est pas disponible dans les états).
- Trait.

> _(WEBDEV - Code Serveur, iPhone/iPad)_ Le champ Forme est disponible uniquement dans l'éditeur d'états.

## Créer un champ forme

> _(WINDEV, Java, WINDEV)_ Créer un champ de type Forme sous l'éditeur de fenêtresPour créer un champ de type Forme sous l'éditeur de fenêtres : Sous le volet "Création", dans le groupe "Autres champs", cliquez sur "Forme".Cliquez dans la fenêtre à la position où le champ doit être créé. L'assistant de création de forme se lance. Choisissez la forme à créer et ses caractéristiques (épaisseur de trait, ...).Validez la création de la forme.Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ.Remarques : Pour créer directement une forme spécifique, sous le volet "Création", dans le groupe "Autres champs", déroulez "Forme" et choisissez la forme voulue.A partir de la version 12, les formes de type Flèche, Ellipse et Trait utilisent le framework GDI+ : les effets de "crénelage" sont ainsi diminués. Si votre fenêtre possède des champs Forme créés avec une version précédente, ce nouveau mode de dessin est automatiquement appliqué.Sous l'éditeur de fenêtres, il est possible de définir une image de fond pour les formes de type Rectangle, Ellipse et Losange (option "Image de fond" dans l'onglet "Détail" de la fenêtre de description du champ). Sous l'éditeur de fenêtres, la fonction FormePolygone permet de créer une forme libre.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad)_ Créer un champ de type Forme sous l'éditeur d'étatsPour créer un champ de type Forme sous l'éditeur d'états : Sous le volet "Création", dans le groupe "Visuel", déroulez "Forme" et sélectionnez la forme voulue.Cliquez dans l'état à la position où le champ doit être créé.Pour modifier la forme, affichez la fenêtre de description du champ (option "Description" dans le menu contextuel du champ) et choisissez la forme voulue dans l'onglet "Général".

## Astuces

> _(WINDEV)_ Comment modifier l'angle d'une flèche sous l'éditeur de fenêtresPour modifier l'angle d'une flèche sous l'éditeur, il suffit de :Sélectionner l'extrémité de la flèche avec la souris.Maintenir le bouton gauche de la souris enfoncé.Déplacer la souris jusqu'à obtenir l'angle voulu.

> _(WINDEV)_ Déplacer les extrémités d'une flèche par programmationPour déplacer les extrémités d'une flèche, vous pouvez utiliser les fonctions FlècheXXX : La fonction FlècheDébut permet de positionner l'extrémité d'origine de la flèche.La fonction FlècheFin permet de positionner l'extrémité de fin de la flèche.
