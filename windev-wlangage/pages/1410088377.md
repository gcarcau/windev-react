# <Table>.VersWord (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Crée un fichier Word (.RTF) avec les données d'un champ Table ou Table hiérarchique.
**Remarque** : Ce fichier pourra être ouvert sous Word ou sous OpenOffice Writer (selon le logiciel installé sur le poste en cours).

## Exemple

> _(WINDEV, Etats et Requêtes, Code Utilisateur (MCU))_ sFic est une chaîne
// Demande le nom du fichier
sFic = fSélecteur("", "", "Choisissez le fichier d'exportation", ...
 "Fichiers Word (*.rtf) *.rtf", "rtf", fselCrée + fselExiste)
// Si le nom n'a pas été fourni, abandonne l'export
// Sinon, exporte le contenu du champ Table TABLE_TABLE1
SI sFic <> "" ALORS TableVersWord(TABLE_TABLE1, sFic, taSansTitre)

> _(WEBDEV - Code Serveur, Ajax)_ sFic est une chaîne
// Demande le nom du fichier
sFic = ComplèteRep(fRepExe()) + "MonDOCS" + ConnexionOccurrence() + ".doc"
// Si le nom n'a pas été fourni, abandonne l'export
// Sinon, exporte le contenu du champ Table TABLE_TABLE1
SI sFic <> "" ALORS TableVersWord(TABLE_TABLE1, sFic, taSansTitre)

## Syntaxe

```wlangage
<Résultat> = <Champ Table>.VersWord(<Nom du fichier Doc> [, <Options> [, <Ligne début> [, <Ligne fin>]]])
```

`<Résultat>` *Booléen*
> - Vrai si le fichier a été créé,
> - Faux dans le cas contraire.
`<Champ Table>` *Nom de champ*
> Nom du champ à manipuler. Ce champ peut correspondre :
>
> - à un champ Table.
> - à un champ Table hiérarchique.
`<Nom du fichier Doc>` *Chaîne de caractères*
> Nom et chemin complet du fichier Word à créer. Si le fichier existe déjà, il est remplacé par le nouveau fichier.
`<Options>` *Constante optionnelle de type Entier*
> Paramètre le fichier Word à créer.
>
> | *taAvecColonnesInvisibles* | Exporte aussi les colonnes invisibles du champ. _(WINDEV)_ Les colonnes définies comme non imprimables et non exportables sont exportées. Ces colonnes sont définies : soit par programmation : propriété VisibleEnExportEtImpression à Faux. soit dans l'onglet "Général" de la fenêtre de description des colonnes : option "Export et impression" à "Jamais". |
> | --- | --- |
> | *taColonneOrdreAffiché* | Exporte les colonnes selon l'ordre des colonnes actuellement affiché dans le champ (et non selon l'ordre des colonnes défini sous l'éditeur). _(WEBDEV - Code Serveur)_ Cette constante n'est pas disponible. |
> | *taLigneSélectionnées* | Exporte uniquement les lignes sélectionnées (par défaut, toutes les lignes sont exportées). _(WEBDEV - Code Serveur)_ Cette constante n'est pas disponible. |
> | *taSansTitre* | Seules les données sont copiées dans le fichier. |
> | *taSansTotaux* | N'exporte pas :   - les lignes de totaux, moyenne et comptage automatique (par défaut, ces lignes sont exportées). - les lignes de calculs personnalisés (par défaut, ces lignes sont exportées). _(WEBDEV - Code Serveur)_ Cette constante n'est pas disponible. |
> | *taTitreColonnes* (Valeur par défaut) | Le titre des colonnes est inséré dans le fichier. |
`<Ligne début>` *Entier optionnel*
> Numéro de la ligne de début de l'exportation. Si ce paramètre n'est pas précisé, la ligne de début est la première ligne du champ.
`<Ligne fin>` *Entier optionnel*
> Numéro de la ligne de fin de l'exportation. Si ce paramètre n'est pas précisé, la ligne de fin est la dernière ligne du champ.

## Remarques

### Conditions d'utilisation
La fonction **<Table>.VersWord** peut être utilisée indifféremment sur :

- un champ Table ou Table hiérarchique fichier.
- un champ Table ou Table hiérarchique par programmation.
- un champ monosélection ou multisélection.

- Le fichier créé pourra être ouvert avec Word version 95 ou supérieure ou avec OpenOffice Writer version 2 ou supérieure.
- Les colonnes fusionnées sont ignorées.
