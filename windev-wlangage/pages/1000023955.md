# SaisieOccurrenceJeton (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Renvoie le nombre de jetons présents dans un champ de saisie de type "Jetons de texte".

## Exemple

```wlangage
// Mise à jour du libellé
LIB_Info = "Nb de destinataire : " + SaisieOccurrenceJeton(SAI_Destinataire)
```

## Syntaxe

```wlangage
<Résultat> = SaisieOccurrenceJeton(<Champ de saisie>)
```

`<Résultat>` *Entier*
> Nombre de jetons associé au champ de saisie.
`<Champ de saisie>` *Nom de champ*
> Nom du champ de saisie de type "Jetons de texte".

## Remarques

- Si les doublons sont autorisés dans le champ de saisie de type "Jetons de texte", le nombre de jetons renvoyé prend en compte les doublons.
- Une erreur est affichée si le champ de saisie n'est pas un champ de type "Jetons de texte" (propriété [JetonActif](1000023782.md) vaut Faux).
- La propriété [ValeurMémorisée](2510127.md) du champ de saisie renvoie les valeurs mémorisées des jetons du champ séparées par le caractère <RC> (Retour Chariot).
