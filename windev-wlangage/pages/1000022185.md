# <Tableau croisé dynamique>.EnrouleTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Enroule tous les entêtes de lignes et/ou de colonnes d'un champ Tableau croisé dynamique.
Nouveauté Abonnement

> _(WEBDEV - Code Serveur, Linux)_ Cette fonction est désormais disponible pour les sites WEBDEV sous Windows et sous Linux.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
// Charge le fichier des données
TCD_Statistiques.Charge(sFichier)
// Enroule tous les entêtes du champ Tableau croisé dynamique
TCD_Statistiques.EnrouleTout()
```

## Syntaxe

```wlangage
<Champ Tableau croisé dynamique>.EnrouleTout([<Type de l'entête>])
```

`<Champ Tableau croisé dynamique>` *Nom de champ*
> Nom du champ Tableau croisé dynamique à manipuler. Ce champ Tableau croisé dynamique doit avoir été rempli soit avec la fonction [<Tableau croisé dynamique>.CalculeTout](1000022180.md), soit avec la fonction [<Tableau croisé dynamique>.Charge](1000022181.md).
`<Type de l'entête>` *Constante ou combinaison de constantes optionnelle de type Entier*
> Type de l'entête à enrouler :
>
> | *tcdEntêteColonne* | Enroule les entêtes de colonnes. |
> | --- | --- |
> | *tcdEntêteLigne* | Enroule les entêtes de lignes. |
>
>
> Par défaut, si ce paramètre n'est pas spécifié, les entêtes de lignes **ET** de colonnes sont enroulés.

**Composante : wd300obj.dll**
