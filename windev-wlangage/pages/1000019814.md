# Propriétés associées au champ Carte

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Un champ Carte peut être utilisé :

- dans une fenêtre,
- dans une page.

Les propriétés associées au champ varient en fonction du lieu d'utilisation.
