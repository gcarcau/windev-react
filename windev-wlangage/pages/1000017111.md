# ServiceArrête (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Arrête un service. Ce service peut être un service présent sur le poste local ou sur un poste distant.

## Exemple

```wlangage
// Arrête le service présent dans la table TABLE_Service
SI ServiceArrête(COL_Nom[TABLE_Service]) = Vrai ALORS
	SI ServiceAttendEtat(COL_Nom[TABLE_Service], serviceEtatArrêté, 10) = -1 ALORS
		 Erreur(ErreurInfo())
	FIN
SINON
	Erreur(ErreurInfo())
FIN
```

## Syntaxe

```wlangage
<Résultat> = ServiceArrête(<Nom du service> [, <Poste distant>])
```

`<Résultat>` *Booléen*
> - Vrai si la demande d'arrêt du service a été transmise au gestionnaire de services,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Nom du service>` *Chaîne de caractères*
> Nom du service à arrêter.
`<Poste distant>` *Chaîne de caractères optionnelle*
> Adresse IP du poste distant au format xxx.xxx.xxx.xxx (obtenu par la fonction [NetAdresseIP](3056023.md)) ou nom du poste distant (obtenu par la fonction [NetNomMachine](3056014.md)). Ce paramètre permet d'arrêter un service sur un autre poste. Pour utiliser cette option, l'utilisateur doit être administrateur de la machine distante.
> Si ce paramètre n'est pas précisé ou correspond à une chaîne vide, le service est manipulé en local.

## Remarques

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Windows, Code Utilisateur (MCU), Ajax)_ Mode de fonctionnementLa fonction ServiceArrête demande au gestionnaire de services d'arrêter le service. Cette opération peut ne pas être effectuée immédiatement. Pour connaître l'état du service, utilisez la fonction ServiceAttendEtat.
