# Fonctions de gestion des fenêtres (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Mac Catalyst)

| [<Elément>.DemandeMiseAJourUI](1410088728.md) | Demande l'exécution de l'événement "Demande de mise à jour de l'affichage" de l'élément spécifié (et rend la main **sans attendre l'exécution de l'événement**). |
| --- | --- |
| [<Elément>.ExécuteMiseAJourUI](1410088729.md) | Exécute immédiatement l'événement "Demande de mise à jour de l'affichage" de l'élément spécifié. |
| [<Fenêtre>.ActiveGFI](1410088766.md) | Active ou désactive le GFI (Grisage des Fenêtres Inaccessibles) d'une fenêtre spécifique. |
| [<Fenêtre>.AgencementEnCours](1410088841.md) | Renvoie l'indice de l'agencement en cours dans la fenêtre ou dans la fenêtre interne spécifiée. |
| [<Fenêtre>.ChangeAgencement](1410088842.md) | Applique un agencement spécifique sur :   - une fenêtre. - une fenêtre interne. |
| Nouveauté 2025 [<Fenêtre>.ExtHaut](1410088867.md) | Renvoie la hauteur totale d'une fenêtre. |
| Nouveauté 2025 [<Fenêtre>.ExtLarg](1410090624.md) | Renvoie la largeur totale d'une fenêtre. |
| Nouveauté 2025 [<Fenêtre>.ExtPosX](1410090628.md) | Renvoie la position horizontale du coin haut gauche d'une fenêtre par rapport au coin haut gauche de l'écran. |
| Nouveauté 2025 [<Fenêtre>.ExtPosY](1410090625.md) | Renvoie la position verticale du coin haut gauche d'une fenêtre par rapport au coin haut gauche de l'écran. |
| [<Fenêtre>.Iconise](1000023884.md) | Iconise une fenêtre WINDEV. |
| [<Fenêtre>.ImageFenêtre](1000023885.md) | Crée l'image de la fenêtre spécifiée dans un fichier BMP. |
| Nouveauté 2025 [<Fenêtre>.IntHaut](1410090629.md) | Renvoie la hauteur interne d'une fenêtre (sans la barre de titre ni le cadre). |
| Nouveauté 2025 [<Fenêtre>.IntLarg](1410090626.md) | Renvoie la largeur interne d'une fenêtre (sans le cadre). |
| Nouveauté 2025 [<Fenêtre>.IntPosX](1410088866.md) | Renvoie la position horizontale du coin haut gauche de la zone interne (sans le cadre ni la barre de titre) d'une fenêtre par rapport au coin haut gauche de l'écran. |
| Nouveauté 2025 [<Fenêtre>.IntPosY](1410090627.md) | Renvoie la position verticale du coin haut gauche de la zone interne (sans le cadre ni la barre de titre) d'une fenêtre par rapport au coin haut gauche de l'écran. |
| [<Fenêtre>.Maximise](1000023886.md) | Affiche une fenêtre WINDEV dans sa taille maximale. |
| [<Fenêtre>.Ouvre](1000023903.md) | Ouvre une fenêtre modale WINDEV ou WINDEV Mobile. |
| [<Fenêtre>.OuvreAsynchrone](1410087862.md) | Ouvre une fenêtre dont le résultat sera récupéré via une procédure WLangage (appelée "callback"). |
| [<Fenêtre>.OuvreFenêtreMobile](1000023887.md) | Ouvre une fenêtre dans une application mobile. |
| [<Fenêtre>.OuvreFille](1000023904.md) | Ouvre une fenêtre fille non modale. |
| [<Fenêtre>.OuvrePopupAsynchrone](1410087873.md) | Ouvre une fenêtre de type popup dont le résultat sera récupéré par une procédure WLangage (également appelée "Callback"). |
| [<Fenêtre>.OuvrePopupPosition](1410087874.md) | Ouvre une fenêtre de type popup en précisant sa position d'ouverture et attend sa fermeture. |
| [<Fenêtre>.OuvreSoeur](1410086669.md) | Ouvre une fenêtre soeur non modale. |
| [<Fenêtre>.Repeint](1000023634.md) | Redessine immédiatement les champs de la fenêtre nécessitant une mise à jour graphique. |
| [<Fenêtre>.Restaure](1000023888.md) | Affiche une fenêtre WINDEV dans sa taille initiale. |
