# Fonctions de gestion des tâches parallèles

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des tâches parallèles (syntaxe préfixée)](1000021606.md)).
Les fonctions de gestion des tâches parallèles sont les suivantes :

| [TâcheParallèleAnnule](1000021278.md) | Termine immédiatement l'exécution de la tâche courante : la tâche passe dans l'état *tpeAnnulée*. |
| --- | --- |
| [TâcheParallèleAttend](1000021212.md) | Attend la fin de l'exécution d'une tâche parallèle. |
| [TâcheParallèleAttendToutes](1000021297.md) | Attend la fin de l'exécution de toutes les tâches parallèles présentes dans un tableau. |
| [TâcheParallèleDemandeAnnulation](1000021213.md) | Demande l'annulation d'une tâche parallèle. |
| [TâcheParallèleExécute](1000021211.md) | Déclenche l'exécution d'une tâche parallèle. |
| [TâcheParallèleExécuteAprès](1000021214.md) | Indique une tâche parallèle de continuation qui sera exécutée lorsque la tâche parallèle spécifiée sera terminée. |
| [TâcheParallèleExécuteAprèsToutes](1000021217.md) | Indique une tâche parallèle de continuation qui sera exécutée lorsque toutes les tâches d'un tableau de tâches parallèles seront terminées. |
| [TâcheParallèleExécuteAprèsUne](1000021216.md) | Indique une tâche parallèle de continuation qui sera exécutée après la première tâche terminée d'un tableau de tâches parallèles. |
| [TâcheParallèleParamètre](1000021284.md) | Modifie les paramètres des tâches parallèles. |
