# Fonctions Bouton segmenté

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions permettant de gérer les champs Bouton segmenté sont les suivantes :

| Nouveauté 2025 [BoutonSegmentéAjoute](1410090834.md) | Ajoute une nouvelle option (c'est-à-dire un nouveau bouton) dans un champ Bouton segmenté. |
| --- | --- |
| Nouveauté 2025 [BoutonSegmentéInsère](1410090835.md) | Insère une nouvelle option dans un champ Bouton segmenté. |
| Nouveauté 2025 [BoutonSegmentéSupprime](1410090836.md) | Supprime une option dans un champ Bouton segmenté. |
| Nouveauté 2025 [BoutonSegmentéSupprimeTout](1410090837.md) | Supprime toutes les options d'un champ Bouton segmenté. |
