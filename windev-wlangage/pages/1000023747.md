# <Image>.CalqueVisible (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Permet de rendre visible ou invisible un calque d'une image de type WDPIC.

## Exemple

```wlangage
// Affiche l'image d'un produit dans un champ Image
PROCÉDURE AfficheProduit(sChampImage est un Champ, sNomWDPic est une chaîne, ...
			bPromo est un booléen)

MonImage est un WDPic
MonImage.NomFichier = sNomWDPic

sChampImage.Valeur = MonImage
sChampImage.CalqueVisible("Calque Promo", bPromo)
```

## Syntaxe

```wlangage
<Résultat> = <Image WDPic>.CalqueVisible(<Nom du calque> , <Visible>)
```

`<Résultat>` *Booléen*
> - Vrai si le calque existe,
> - Faux si le calque n'existe pas. En cas d'échec, la variable [ErreurDétectée](3087001.md) vaut Vrai et la fonction [ErreurInfo](3013008.md) permet de connaître le détail de l'erreur.
`<Image WDPic>` *Variable de type WDPic*
> Nom de la variable de type [WDPic](1000023503.md) correspondant à l'image manipulée.
`<Nom du calque>` *Chaîne de caractères*
> Nom du calque à manipuler. Ce nom doit être identique au nom défini sous l'éditeur d'images.
`<Visible>` *Booléen*
> - Vrai si le calque doit être visible,
> - Faux si le calque doit être invisible.

## Remarques

Un calque peut être rendu visible ou invisible par programmation uniquement si le calque possède l'option "Visible/Invisible par programmation". Cette option est disponible dans le menu contextuel du calque. Cette option peut être activée :

- sous l'éditeur d'images,
- dans le champ Editeur d'images.

Pour plus de détails, consultez [Gestion des calques](1410086606.md).
