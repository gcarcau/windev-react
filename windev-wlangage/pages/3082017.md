# zipTailleFichier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie la taille d'un des fichiers de l'archive (au format CAB, RAR, WDZ, ZIP, 7z, gzip, TAR ou TGZ (TAR.GZ)) :

- soit la taille du fichier compressé.
- soit la taille du fichier avant compression.

Lors de l'extraction d'un fichier d'une archive, il est conseillé de comparer la taille non compressée du fichier et l'espace disque disponible.

Rappel :

- Seules les archives au format ZIP, gzip, TAR et TGZ (TAR.GZ) sont disponibles.
- Seules les archives au format ZIP sont disponibles.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ MonArchive est une zipArchive
// Ouverture d'une archive
ResOuvreArchive = zipOuvre(MonArchive, "C:\MesArchives\Archive.zip")

// Taille de "Fichier.txt"
SI ResOuvreArchive = 0 ALORS
 ResTailleFichier = zipTailleFichier(MonArchive, "Fichier.txt")
 ...
FIN

## Syntaxe

#### Connaître la taille d'un fichier identifié par son indice

```wlangage
<Résultat> = zipTailleFichier(<Archive> , <Indice du fichier> [, <Type de taille>])
```

`<Résultat>` *Entier*
> Taille du fichier spécifié.
`<Archive>` *Chaîne de caractères ou variable de type zipArchive*
> Nom de l'archive à manipuler.
> Ce nom peut correspondre :
>
> - soit au nom d'une archive défini avec la fonction [zipOuvre](3082044.md) ou [zipCrée](3082003.md).
> - soit au nom d'une variable de type [zipArchive](1000018679.md).
>    Les variables de type [zipArchive](1000018679.md) ne sont pas disponibles en Java.
`<Indice du fichier>` *Entier*
> Indice du fichier dont la taille doit être calculée. Cet indice peut être connu grâce à la fonction [zipChercheFichier](3082002.md).
`<Type de taille>` *Booléen optionnel*
> Type de calcul de la taille du fichier :
>
> - Vrai : Taille du fichier compressé.
> - Faux (valeur par défaut) : Taille du fichier avant compression.

#### Connaître la taille d'un fichier identifié par son chemin

```wlangage
<Résultat> = zipTailleFichier(<Archive> , <Chemin du fichier> [, <Type de taille>])
```

`<Résultat>` *Entier*
> Taille du fichier spécifié.
`<Archive>` *Chaîne de caractères ou variable de type zipArchive*
> Nom de l'archive à manipuler.
> Ce nom peut correspondre :
>
> - soit au nom d'une archive défini avec la fonction [zipOuvre](3082044.md) ou [zipCrée](3082003.md).
> - soit au nom d'une variable de type [zipArchive](1000018679.md).
>    Les variables de type [zipArchive](1000018679.md) ne sont pas disponibles en Java.
`<Chemin du fichier>` *Entier*
> Chemin mémorisé du fichier dont la taille doit être calculée.
`<Type de taille>` *Booléen optionnel*
> Type de calcul de la taille du fichier :
>
> - Vrai : Taille du fichier compressé.
> - Faux (valeur par défaut) : Taille du fichier avant compression.
