# gglChemin (Type de variable)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Le type **gglChemin** permet de définir les caractéristiques du chemin à dessiner sur une carte. Les caractéristiques de ce chemin peuvent être définies et modifiées à l'aide de différentes propriétés WLangage. Le tracé du chemin utilise les points indiqués (et non pas les rues présentes sur la carte).
Ce type de variable est utilisé par le type [gglParamètreCarte](1000017505.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Propriétés

### Propriétés spécifiques à la description des variables de type gglChemin
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **gglChemin** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Couleur | Entier | Couleur du tracé. Cette couleur peut correspondre à :  - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)), - [une couleur prédéfinie](3010002.md). |
| Epaisseur | Entier | Epaisseur du trait (en pixels). |
| Opacité | Entier | Opacité du trait (en pourcentage). |
| Point[n] | Tableau de [gglCoordonnée](1000017489.md) | Points du chemin. Le nombre de points maximum pouvant être utilisés est 100. |
| Point[n].Latitude | Réel | Latitude du point. |
| Point[n].Longitude | Réel | Longitude du point. |
