# <Table>.VersJSON (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Convertit le contenu d'un champ Table ou Table hiérarchique en une chaîne au format JSON.

## Exemple

```wlangage
s est une chaîne
s = TABLEH_Commandes.VersJSON()
fSauveTexte("export_commandes.json", s)
```

## Syntaxe

```wlangage
<Résultat> = <Champ Table>.VersJSON([<Option>])
```

`<Résultat>` *Chaîne de caractères*
> Chaîne de caractères au format JSON correspondant au contenu du champ Table hiérarchique.
`<Champ Table>` *Nom de champ*
> Nom du champ Table ou Table hiérarchique manipulé.
`<Option>` *Constante optionnelle de type Entier*
> Option de configuration du JSON généré :
>
> - Si ce paramètre n'est pas précisé, le JSON généré ne sera pas mis en forme.
> - Si ce paramètre correspond à la constante *jsonMiseEnForme*, le JSON généré sera mis en forme.

**Classification Métier / UI : Code UI**

**Composante : wd300obj.dll**
