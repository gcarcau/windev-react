# TélémétrieDésactive (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Désactive la télémétrie. Les données de télémétrie ne sont plus envoyées au serveur.

## Exemple

```wlangage
TélémétrieDésactive()
```

## Syntaxe

```wlangage
TélémétrieDésactive()
```

## Remarques

Pour désactiver la télémétrie dans une application, il est possible de :

- utiliser la fonction **TélémétrieDésactive**.
- réinstaller l'application en décochant l'option "Participer à l'amélioration ...".
- modifier le fichier <Nom exécutable>.WX. Ce fichier doit contenir les lignes suivantes :
  ```wlangage
  [WDANALYTICS]COLLECTE=0
  ```
  Remarque : Cette entrée n'est pas du tout présente dans le fichier <Nom exécutable>.WX si la télémétrie est active.

**Composante : wd300vm.dll**
