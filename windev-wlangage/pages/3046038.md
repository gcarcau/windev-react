# iTerminePage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Force le passage à la page suivante au cours de l'impression d'un état.
**Remarques** :

- Pour forcer le saut de page, il est aussi possible de sélectionner l'option "Saut de page après le bloc" dans la description d'un bloc (onglet "UI").
- Cette fonction peut être utilisée uniquement avec des états créés avec l'éditeur d'états.

**Attention** : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez [Imprimer sous Linux](9000078.md).

## Exemple

```wlangage
// Saut de page
iTerminePage()
```

## Syntaxe

```wlangage
iTerminePage()
```

**Classification Métier / UI : Code neutre**

**Composante : wd300etat.dll**
