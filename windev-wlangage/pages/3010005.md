# Constantes de visibilité d'un objet

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

| Constante | Description | Utilisée par les fonctions/propriétés |
| --- | --- | --- |
| **Actif** | État de l'objet : objet actif | Propriété [Etat](2510039.md), propriété [EtatInitial](2510063.md), [FenEtat](3038030.md), [MenuEtat](3038003.md) |
| **ActifDevant** | État de la fenêtre : La fenêtre devient active (fenêtre en saisie) et mise en avant plan. Cette constante correspond au résultat d'un clic sur la barre de titre de la fenêtre. | [FenEtat](3038030.md) |
| **AffichageSeulement** | État d'un objet : saisie impossible dans l'objet | Propriété [Etat](2510039.md), propriété [EtatInitial](2510063.md), [FenEtat](3038030.md) |
| **Dessus** | État de la fenêtre : fenêtre au premier plan par rapport aux autres fenêtres de l'application | [FenEtat](3038030.md), [OuvreFille](3038021.md), [OuvreSoeur](3038045.md) |
| **DessusTout** | État de la fenêtre : fenêtre au premier plan par rapport à toutes les fenêtres (y compris celles des autres applications) | [FenEtat](3038030.md), [OuvreFille](3038021.md), [OuvreSoeur](3038045.md) |
| **Grisé** | État de l'objet : objet grisé | Propriété [Etat](2510039.md), propriété [EtatInitial](2510063.md), [MenuEtat](3038003.md) |
| **HorsEcran** | État de la fenêtre : fenêtre active en dehors de la zone visible de l'écran | Propriété [Etat](2510039.md), propriété [EtatInitial](2510063.md), [FenEtat](3038030.md) |
| **Inactif** | État d'un objet : saisie impossible dans l'objet | Propriété [Etat](2510039.md), propriété [EtatInitial](2510063.md) |
| **Inexistant** | État de la fenêtre : fenêtre non ouverte ou non existante | Propriété [Etat](2510039.md), propriété [EtatInitial](2510063.md), [FenEtat](3038030.md) |
| **Invisible** | État de la fenêtre ou de l'option de menu : fenêtre ou option invisible | Propriété [Etat](2510039.md), propriété [EtatInitial](2510063.md), [FenEtat](3038030.md), [MenuEtat](3038003.md) |
| **Normal** | État de la fenêtre : fenêtre affichée en mode normal (les fenêtres des autres applications peuvent passer devant) | [FenEtat](3038030.md) |
