# GraveurAjouteFichier (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Ajoute un fichier à la compilation. Lorsque tous les fichiers voulus seront ajoutés à la compilation, la gravure du CD/DVD pourra être réalisée (fonction [GraveurEnregistre](3061006.md)).
**Remarque** : Pour ajouter l'ensemble des fichiers d'un répertoire à la compilation, utilisez la fonction [GraveurAjouteRépertoire](3061002.md).

## Exemple

```wlangage
// Gravure d'un CD de type données
GraveurTypeMédia(médiaType_CD_ROM_XA)
// Ajout de fichiers
ResAjout est un booléen
ResAjout = GraveurAjouteFichier("C:\MonRépertoire\MonFichierA.TXT", "\MesFichiers\FicA.TXT")
ResAjout = GraveurAjouteFichier("C:\MonRépertoire\MonFichierB.TXT", "\MesFichiers\FicB.TXT")
// Pour visualiser cet exemple en totalité, cliquez sur le lien "Exemple"
```

```wlangage
// Gravure d'un CD de type audio
GraveurTypeMédia(médiaType_CDDA_CDROM)
// Ajout de fichiers
ResAjout est un booléen
ResAjout = GraveurAjouteFichier("C:\MesMusiques\MaChansonA.WAV")
ResAjout = GraveurAjouteFichier("C:\MesMusiques\MaChansonB.WAV")
// Pour visualiser cet exemple en totalité, cliquez sur le lien "Exemple"
```

## Syntaxe

```wlangage
<Résultat> = GraveurAjouteFichier(<Fichier à ajouter> [, <Fichier sur le CD ou DVD>])
```

`<Résultat>` *Booléen*
> - Vrai si le fichier a été ajouté à la compilation,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
>
>
> **Remarque** : Il est nécessaire qu'un CD ou DVD soit présent dans le graveur. Ce CD ou DVD doit contenir assez d'espace pour graver une nouvelle session.
`<Fichier à ajouter>` *Chaîne de caractères*
> Nom et chemin du fichier à ajouter dans la compilation (260 caractères maximum). Ce chemin peut être un chemin complet, relatif ou de type UNC.
> Dans le cas d'une compilation de type audio, ce fichier doit correspondre à un fichier ".WAV" (44100 Hz, 16 bits).
> > _(WEBDEV - Code Serveur)_ Le chemin du fichier est relatif au serveur Web.
`<Fichier sur le CD ou DVD>` *Chaîne de caractères optionnelle*
> Nom et chemin du fichier sur le CD ou sur le DVD. Ce chemin doit commencer par le caractère "antislash" ("\").
> Par défaut, le fichier sera ajouté à la racine du CD/DVD.
> Dans le cas d'une compilation de type audio, ce paramètre n'est pas pris en compte. En effet, le fichier sera automatiquement ajouté à la racine du CD/DVD.

## Remarques

### Compilation
Une compilation correspond à l'ensemble des fichiers à graver sur un CD ou un DVD. Cette compilation sera prise en compte lors du prochain appel de la fonction [GraveurEnregistre](3061006.md).
Une compilation est automatiquement créée lors du premier appel de la fonction **GraveurAjouteFichier** ou de la fonction [GraveurAjouteRépertoire](3061002.md). Une seule compilation à la fois peut être créée.

Une compilation est automatiquement supprimée :

- soit lors du changement du type du CD/DVD à graver (fonction [GraveurTypeMédia](3061013.md)).
- soit lors de la sélection du graveur utilisé par défaut (fonction [GraveurSélectionne](3061012.md)).
- soit après l'appel de la fonction [GraveurEnregistre](3061006.md) (uniquement si la gravure a été lancée, <Résultat> à Vrai).
- soit lors de l'annulation de la gravure (fonction [GraveurAnnuleGravure](3061003.md)).
- soit lors de la fermeture de l'application WINDEV ou du site WEBDEV en cours.

### Ajout de plusieurs fichiers identiques
Si le même fichier est ajouté plusieurs fois à la compilation :

- dans le cas d'un CD/DVD de type audio : ce fichier sera présent sur le CD/DVD autant de fois qu'il a été ajouté.
- dans le cas d'un CD/DVD de type données : seul le dernier fichier ajouté (même nom, même répertoire sur le CD/DVD) sera présent sur le CD/DVD.

### Configuration nécessaire

> _(WINDEV)_ La gravure de CD est disponible uniquement sous Windows XP et supérieur. La gravure de DVD est disponible sous Windows Vista, et sous Windows XP en utilisant la mise à jour KB932716 pour Windows XP (cette mise à jour doit être téléchargée depuis le site de Microsoft et installée car elle n'est pas prise en compte par le mécanisme de Live Update).

> _(WEBDEV - Code Serveur)_ La gravure de CD et DVD sera réalisée sur le serveur Web. Pour graver des CD ou des DVD, le serveur doit être sous Windows XP ou supérieur. Pour graver des CD sous Windows 2003 Serveur, il est nécessaire d'activer le service de gravure IMAPI (nommée "Service COM de gravage de CD IMAPI"). Pour graver des DVD sous Windows 2003 Serveur, il est nécessaire d'installer en plus la mise à jour KB932716.
