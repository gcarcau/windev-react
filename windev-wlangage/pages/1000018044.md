# CouleurFond (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

La propriété **CouleurFond** permet de connaître et de modifier la couleur de fond d'un élément. Cette propriété est utilisable sur :

- les champs d'une fenêtre ou d'une page. Pour plus de détails, consultez l'aide de la propriété [CouleurFond](2510022.md).
- une variable de type [EvénementTimeline](1000020612.md).
- une variable de type [RendezVous](1000019244.md).
- une variable de type [xlsCellule](1000017472.md).
- une variable de type [OrgaElément](1000019713.md).
- une variable de type [TâcheGantt](1000020881.md).
- une variable de type [pdfSignature](1000022255.md).
- une variable de type [docCellule](1000022927.md).
- une variable de type [docFragment](1000022482.md).
- une variable de type [docNiveauNumérotation](1000022799.md).
- une variable de type [docParagraphe](1000022483.md) (caractéristiques de mise en page).
- une variable de type [Jeton](1000023942.md).
- une variable de type [Toast](1000024638.md).
- une variable de type [MarqueurImage](1000025796.md).
- une variable de type [CarteCercle](1000025504.md).
- une variable de type [CartePolygone](1000025476.md).
- une variable de type [Diagramme](1410088055.md).
- une variable de type [diagTexte](1410088393.md).
- une variable de type [VisiteGuidée](1410090170.md).
