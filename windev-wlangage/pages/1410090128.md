# PolyligneGéo (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Le type **PolyligneGéo** permet de définir toutes les caractéristiques avancées d'une polyligne géographique. Les caractéristiques de cette polyligne peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Caractéristiques d'une polyligne géographique** :

Une polyligne géographique est une suite segments dans le repère géographique (latitude - longitude) qui se suivent. Elle est définie par une suite de points.

**Remarque** : Une polyligne géographique n'est pas composée de segments droits comme une polyligne en 2 dimensions. Une polyligne géographique décrit une position sur la surface courbe de la Terre : il s'agit d'une suite d'arcs ayant la courbure de la Terre, comparable à des trajectoires d'avions (géodésiques).

Si le dernier point d'une polyligne est identique au premier point, la polyligne est dite "fermée".
Si les différents segments de la polyligne ne se coupent pas les uns les autres, la polyligne est dite "simple".
Une polyligne simple **et** fermée s'appelle un "anneau" (ou "LinearRing" en anglais).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
monPoint est un PointGéo
maLigne est une PolyligneGéo

monPoint.Latitude = 12.127542
monPoint.Longitude = 35.4245
maLigne.Point.Ajoute(monPoint)

monPoint.Latitude = 12.24147
monPoint.Longitude = 35.2147
maLigne.Point.Ajoute(monPoint)

monPoint.Latitude = 13.2411
monPoint.Longitude = 33.2141
maLigne.Point.Ajoute(monPoint)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type **PolyligneGéo**
Les propriétés suivantes peuvent être utilisées pour manipuler une polyligne géographique :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Point | Tableau de [PointGéo](1410090102.md) | Points de la polyligne. |
| Type | Constante de type Entier | Type de la géométrie en cours. Dans le cas d'une polyligne géographique, correspond à la constante *tgPolyligneGéo*. Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfPolyligneGéo*. **Cette propriété est disponible en lecture uniquement.** |
