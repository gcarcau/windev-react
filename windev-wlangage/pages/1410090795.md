# HauteurAdaptée (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Renvoie la hauteur adaptée d'un champ pour que tout le texte contenu dans le champ ou toutes les lignes soient visibles.

## Exemple

```wlangage
Hauteur_adaptée est un entier = HauteurAdaptée(LISTE_Recettes)
SI Hauteur_adaptée < 100 ALORS
	// Afficher directement le détail sous le champ Liste
	LISTE_Recettes.Hauteur = Hauteur_adaptée
	BTN_Affiche_Détail.Visible = Faux
	FI_Détail.Visible = Vrai
FIN
```

## Syntaxe

```wlangage
<Hauteur> = HauteurAdaptée(<Champ>)
```

`<Hauteur>` *Entier*
> Hauteur adaptée du champ pour que la totalité du texte ou des lignes soit affichée.
`<Champ>` *Nom de champ*
> Nom du champ manipulé. Ce champ peut être par exemple un champ de saisie, un champ Table, un champ Disposition, etc.

**Classification Métier / UI : Code UI**
