# HInfoLog (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Renvoie des informations sur les logs du serveur.
**Rappel** : Les logs du serveur permettent de visualiser les appels au serveur effectués par les clients.

## Exemple

```wlangage
Informations est une chaîne
// Récupération de la correspondance entre les numéros de fonctions
// et le nom des fonctions WLangage
Informations = HInfoLog("MaConnexion", hCorrespondance)
```

## Syntaxe

```wlangage
<Résultat> = HInfoLog(<Nom de la connexion> , <Type d'information>)
```

`<Résultat>` *Chaîne de caractères*
> Résultat détaillé du type d'information demandé.
> Si le type d'information demandé correspond à la constante *hCorrespondance,* <Résultat> est de la forme :
>
>
> ```wlangage
> <Numéro 1> + TAB + <Paramètre 1> + TAB + <Valeur 1> + TAB + <Nom Français 1> + TAB + <Nom Anglais 1> + RC + ... + <Numéro N> + TAB + <Paramètre N> + TAB + <Valeur N> + TAB + <Nom Français N> + TAB + <Nom Anglais N>
> ```
>
>
>
> Où :
>
>
> - <Numéro> correspond au numéro identifiant la fonction dans les logs.
> - <Paramètre> correspond au paramètre dans le log qui permet de différencier des fonctions semblables (par exemple [HLitPremier](3044051.md)/[HLitSuivant](3044037.md)).
> - <Valeur> correspond à la valeur du paramètre.
> - <Nom Français> correspond au nom en français de la fonction WLangage.
> - <Nom Anglais> correspond au nom en anglais de la fonction WLangage.
`<Nom de la connexion>` *Chaîne de caractères*
> Nom de la connexion vers le serveur pour lequel des informations sur les logs sont demandées.
`<Type d'information>` *Constante de type entier*
> Indique le type d'information demandée :
>
> | *hCorrespondance* | Fournit la correspondance entre les numéros de fonctions du log et le nom des fonctions WLangage |
> | --- | --- |

## Remarques

### Récupération des logs

- La fonction [HGèreServeur](3044359.md) permet d'obtenir et de modifier des informations sur les logs (taille maximale, chemin, ...).
- La fonction [HRécupèreLog](3044357.md) permet de récupérer les logs du serveur (entre deux dates) dans un fichier au format texte.

**Composante : wd300hf.dll**
