# EnModeSysNotification (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Permet de savoir si l'application est lancée depuis une notification interactive "Windows 10".

## Exemple

```wlangage
SI EnModeSysNotification() = Vrai ALORS
	Trace("Application lancée depuis une notification Windows 10")
FIN
```

## Syntaxe

```wlangage
<Résultat> = EnModeSysNotification()
```

`<Résultat>` *Booléen*
> - Vrai si l'application est lancée depuis une notification "Windows 10",
> - Faux dans le cas contraire.

**Classification Métier / UI : Code métier**

**Composante : wd300std.dll**
