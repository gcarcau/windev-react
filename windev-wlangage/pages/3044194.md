# HDébloqueNumEnr (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Débloque un enregistrement précédemment bloqué avec :

- soit la fonction [HBloqueNumEnr](3044152.md),
- soit une fonction de lecture utilisée avec un paramètre bloquant (par exemple fonction [HLit](3044047.md) utilisé avec la constante *hBlocageEcriture* ou la constante *hBlocageLectureEcriture*).

**Remarque** : La fonction **HDébloqueNumEnr** ne permet pas de débloquer un enregistrement bloqué par une autre application.
> _(Java)_ Cette fonction est disponible uniquement pour les fichiers de données HFSQL. Elle n'est pas disponible pour les fichiers de données accédés par JDBC.

## Exemple

```wlangage
// Blocage
HBloqueNumEnr(CLIENT, hNumEnrEnCours, hBlocageLectureEcriture)
// Modification de l'enregistrement
...
// Déblocage
HDébloqueNumEnr(CLIENT, hNumEnrEnCours)
```

## Syntaxe

```wlangage
<Résultat> = HDébloqueNumEnr([<Fichier de données> [, <Numéro d'enregistrement>]])
```

`<Résultat>` *Booléen*
> - Vrai si l'enregistrement a été débloqué,
> - Faux en cas de problème. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Fichier de données>` *Chaîne de caractères optionnelle*
> Nom du fichier de données manipulé.
> Si ce nom n'est pas spécifié, la fonction **HDébloqueNumEnr** va manipuler le dernier fichier de données utilisé par la dernière fonction de gestion HFSQL (fonction commençant par la lettre H).
`<Numéro d'enregistrement>` *Entier optionnel*
> Numéro de l'enregistrement à débloquer.
> Si ce numéro n'est pas spécifié (égal à 0 ou à la constante *hNumEnrEnCours*), la fonction **HDébloqueNumEnr** va manipuler l'enregistrement en cours.
>
> > _(Connecteurs Natifs (Accès Natifs))_ La fonction HDébloqueNumEnr débloque uniquement l'enregistrement en cours. Il est impossible de spécifier un numéro d'enregistrement différent de celui en cours (pour désigner l'enregistrement en cours, utilisez la constante hNumEnrEnCours).

## Remarques

La fonction **HDébloqueNumEnr** est sans effet si :

- Le fichier de données est en mode Mono (voir la fonction [HMode](3044039.md)).
- L'enregistrement n'est pas bloqué.

**Composante : wd300hf.dll**
