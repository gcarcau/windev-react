# MultiGéométrie (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Le type **MultiGéométrie** permet de stocker un ensemble de géométries de types différents. Il s'agit donc d'une collection hétérogène : il est possible de stocker un ensemble de points, de polygones, etc.
Il est également possible de stocker des géométries définies avec des systèmes de coordonnées différentes, telles que des points avec des coordonnées géométriques et des points avec des coordonnées géographiques, dans une même variable de type **MultiGéométrie**. Toutefois, cette opération doit être réalisée avec prudence car cela risque de causer des erreurs lors d'opérations essayant de mixer les deux types de points : la distance entre un point en coordonnées géométriques et un point en coordonnées géographiques n'est pas définie.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
MultiG est un MultiGéométrie
g est une Géométrie

// Ajoute un point en coordonnées géométriques (2D)
p est un Point2D
g = p
MultiG.Géométrie.Ajoute(g)

// Ajoute un polygone en coordonnées géographiques
polyGéo est un PolygoneGéo
polyGéo.Contour.AjoutePoint(0, 1)
polyGéo.Contour.AjoutePoint(1, 1)
polyGéo.Contour.AjoutePoint(1, 0)
polyGéo = GéométrieCorrige(polyGéo)
g = polyGéo
MultiG.Géométrie.Ajoute(g)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type MultiGéométrie
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **MultiGéométrie** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Géométrie | Tableau de [Géométrie](1410090098.md) | Géométries composant la variable de type **MultiGéométrie**. |
| Type | Constante de type Entier | Type de la géométrie en cours. Dans le cas d'un ensemble de géométries, correspond à la constante *tgMultiGéométrie*. Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfMultiForme*. **Cette propriété est disponible en lecture uniquement.** |
