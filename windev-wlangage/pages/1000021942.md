# <Variable fbSession>.Etat (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Vérifie l'état d'une session Facebook.
> _(Android)_ Attention : Cette fonctionnalité est disponible jusqu'à Android 11. A partir d'Android 12, cette fonction provoque une erreur fatale. Il est conseillé de : tester la version d'Android utilisée via la fonction SysVersionAndroid.utiliser la fonction AuthIdentifie pour gérer l'authentification Facebook.

## Exemple

```wlangage
MaSession est un fbSession

SI MaSession.Etat() <> fbSessionOuverte ALORS
	Info("Pas de session ouverte")
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Session>.Etat()
```

`<Résultat>` *Constante de type Entier*
> Etat de la session :
>
>
> | *fbSessionFermée* | Session Facebook fermée. |
> | --- | --- |
> | *fbSessionOuverte* | Session Facebook ouverte. |
> | *fbSessionPermissionIncorrecte* | Session Facebook ouverte avec des droits différents de ceux de la session passée en paramètre. |
`<Session>` *Variable de type fbSession*
> Nom de la variable de type [fbSession](1000021851.md) correspondant à la connexion à manipuler.

**Composante : wd300ggl.dll**
