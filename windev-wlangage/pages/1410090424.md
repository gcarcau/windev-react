# Fonctions de gestion du champ Editeur de code (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur)

Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ La plupart de ces fonctions sont désormais disponibles en code navigateur.

Les fonctions permettant de gérer les champs Editeur de code (via une syntaxe préfixée) sont les suivantes :

| [<Editeur de code>.Charge](1410090411.md) | Charge un fichier de code WLangage dans un champ Editeur de code. |
| --- | --- |
| [<Editeur de code>.Commente](1410090412.md) | Commente la sélection en cours dans le champ Editeur de code. Les caractères "//" sont ajoutés devant la ligne en cours. |
| [<Editeur de code>.Compile](1410090413.md) | Compile le code WLangage affiché dans le champ Editeur de code et affiche les potentielles erreurs. |
| [<Editeur de code>.Décommente](1410090414.md) | Décommente la sélection en cours dans le champ Editeur de code. Les caractères "//" présents devant la ligne en cours sont supprimés. |
| [<Editeur de code>.DupliqueLigne](1410090415.md) | Duplique la ligne courante dans le champ Editeur de code. |
| [<Editeur de code>.Exécute](1410090416.md) | Exécute le code WLangage affiché dans le champ Editeur de code. |
| [<Editeur de code>.Insère](1410090417.md) | Insère une chaîne de caractères dans le champ Editeur de code. |
| [<Editeur de code>.Recherche](1410090418.md) | Recherche une chaîne de caractères ou une expression régulière dans le champ Editeur de code. |
| [<Editeur de code>.RécupèreErreur](1410090419.md) | Permet de récupérer l'erreur de compilation du code présent dans le champ Editeur de code. |
| [<Editeur de code>.Remplace](1410090420.md) | Recherche et remplace une chaîne de caractères dans le champ Editeur de code. |
| [<Editeur de code>.Sauve](1410090421.md) | Sauve le contenu d'un champ Editeur de code dans un fichier. |
| [<Editeur de code>.SupprimeTout](1410090422.md) | Supprime le contenu du champ Editeur de code. |
