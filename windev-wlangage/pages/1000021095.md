# gpwModifieUtilisateur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

Modifie un utilisateur dans la base de données du groupware utilisateur.

## Exemple

```wlangage
// Valeurs du nouvel utilisateur
clUtilisateur est un gpwUtilisateur
clUtilisateur.Email = SAI_Email
clUtilisateur.Login = SAI_Login
clUtilisateur.MotDePasse = SAI_MotPasse
clUtilisateur.Nom = SAI_Nom
clUtilisateur.Prénom = SAI_Prenom
clUtilisateur.Téléphone = SAI_Telephone

// Modification de l'utilisateur
SI gpwModifieUtilisateur(clUtilisateur) = Faux
	Info("Impossible de modifier l'utilisateur." + RC + HErreurInfo())
	RETOUR
FIN
```

## Syntaxe

```wlangage
<Résultat> = gpwModifieUtilisateur(<Utilisateur>)
```

`<Résultat>` *Booléen*
> - Vrai si l'utilisateur est modifié,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Utilisateur>` *Variable de type gpwUtilisateur*
> Nom de la variable de type [gpwUtilisateur](1000021088.md) contenant les informations à modifier.

**Composante : wd300gpu.dll**
