# <Variable Connexion>.RSListeConfig (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Liste les réplications disponibles sur un serveur HFSQL maître ou abonné.

## Exemple

```wlangage
// Déclaration des variables
Cnx est une Connexion
listeRS est un tableau de hRSConfig

// Configuration de la connexion
...

// Liste des réplications
listeRS = Cnx.RSListeConfig()
POUR TOUT ConfigRéplication DE listeRS
	Trace(ConfigRéplication.Serveur)
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.RSListeConfig([<Option>])
```

`<Résultat>` *Tableau de hRSConfig*
> Tableau de variables de type [hRSConfig](1000020484.md) décrivant les différentes réplications définies sur le serveur HFSQL.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion vers le serveur HFSQL maître (sur lequel sont définies les réplications).
`<Option>` *Constante de type Entier*
> Permet de lister les réplications pour lesquelles le serveur en cours est maître ou abonné :
>
> | *hrsAbonné* | Liste les réplications pour lesquelles le serveur en cours est abonné. Remarque : Dans ce cas, la variable de type [hRSConfig](1000020484.md) correspondant à la réplication a les caractéristiques suivantes :   - Réplication bidirectionnelle : l'identifiant correspond à l'identifiant de la réplication sur le serveur abonné. - Réplication monodirectionnelle : l'identifiant vaut 0. - La propriété **Serveur** correspond au nom du serveur maître. - Les propriétés **Description** et **Planification** ne sont pas disponibles. |
> | --- | --- |
> | *hrsMaître* (Valeur par défaut) | Liste les réplications pour lesquelles le serveur en cours est maître. |
