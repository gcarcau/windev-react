# Entier (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Le type **Entier** permet de réaliser simplement des calculs sur des valeurs entières. Une variable de type entier peut avoir une valeur comprise entre -2 x 109 et 2 x 109 (environ).
Remarque : Pour des calculs avancés, le WLangage propose différents types d'entiers.
Le type Entier est un type nullable. Pour plus de détails, consultez [Activation des types nullables](1511031.md).

## Exemple

```wlangage
i est un entier
i = 5
```

## Syntaxe

```wlangage
<Nom de la variable> est un entier<Nom de la variable 1>, <Nom de la variable 2> sont des entiers
```

`<Nom de la variable>` **
> Nom de la variable à déclarer.

## Remarques

### Déclaration et initialisation
Une variable de type "Entier" déclarée et non initialisée est égale à 0.

### Valeur Hexadécimale
Pour saisir une valeur hexadécimale dans le code, il suffit de préfixer la valeur hexadécimale par "0x".

```wlangage
MaVariable est un entier
MaVariable = 0x4D5
```

Remarque : Il est possible d'utiliser le caractère '_' comme séparateur de blocs dans les nombres hexadécimaux. Les blocs peuvent avoir une taille de 2, 4 ou 8 caractères de long.
Exemple :

```wlangage
Nb1 est un entier = 0x_12_15_A4_BC
Nb2 est un entier = 0x_CD4A_DE58
```

### Séparateur des milliers
Il est possible d'utiliser le caractère 'Espace' ou le caractère '_' comme séparateur de milliers dans les nombres. Par exemple :

```wlangage
num1 est un entier
num1 = 123 456
soit num2 = 246_789
```

> _(PHP)_ Spécificités PHPLes nombres (réels, entiers, monétaires, numériques) ne peuvent pas dépasser 14 chiffres significatifs en PHP. S'ils dépassent cette limite, ils sont arrondis à 14 chiffres.Les entiers en 32 bits ont pour valeur maximum : 2147483647 pour 32 bits <=> 0x7FFFFFFFLes entiers en 64 bits ont pour valeur maximum : 9223372036854775807<=>0x7FFFFFFFFFFFFFFF

### Les différents types d'entiers

Pour des opérations spécifiques, le WLangage propose différents types d'entiers. Ces types sont conseillés notamment pour l'utilisation des API Windows.

|  | Valeur comprise entre |
| --- | --- |
| - ***Entier sur 1 octet*** | -128 et 127 (incluses) Exemple :    ```wlangage i est un entier sur 1 octet ``` |
| - ***Entier sur 2 octets*** | -32.768 et 32.767 (incluses) Exemple :    ```wlangage i est un entier sur 2 octets ``` |
| - ***Entier sur 4 octets*** | -2 x 109 et 2 x 109(environ) Exemple :    ```wlangage i est un entier sur 4 octets ``` |
| - ***Entier sur 8 octets*** | -9 x 1018 et 9 x 1018(environ) Exemple :    ```wlangage i est un entier sur 8 octets ``` |
| - ***Entier sans signe*** | 0 et 4 x 109 Exemple :    ```wlangage i est un entier sans signe ``` _(Android, Widget Android)_ Une variable de ce type sera automatiquement convertie en Entier. |
| - ***Octet*** | 0 et 255 (incluses) Ce type est équivalent au type Entier sans signe sur 1 octet. Exemple :    ```wlangage i est un octet ``` _(Android, Widget Android)_ Une variable de ce type sera automatiquement convertie en Entier. |
| - ***Entier sans signe sur 1 octet*** | 0 et 255 (incluses) Exemple :    ```wlangage i est un entier sans signe sur 1 octet ``` _(Android, Widget Android)_ Une variable de ce type sera automatiquement convertie en Entier. |
| - ***Entier sans signe sur 2 octets*** | 0 et 65.535 (incluses) Exemple :    ```wlangage i est un entier sans signe sur 2 octets ``` _(Android, Widget Android)_ Une variable de ce type sera automatiquement convertie en Entier. |
| - ***Entier sans signe sur 4 octets*** | 0 et 4 x 109 (environ) Exemple :    ```wlangage i est un entier sans signe sur 4 octets ``` _(Android, Widget Android)_ Une variable de ce type sera automatiquement convertie en Entier. |
| - ***Entier sans signe sur 8 octets*** | 0 et 18 x 1018 Exemple :    ```wlangage i est un entier sans signe sur 8 octets ``` _(Android, Widget Android)_ Une variable de ce type sera automatiquement convertie en Entier. |
| - ***Entier système*** | s'adapte automatiquement à la taille gérée par le mode de compilation (4 octets pour un programme compilé en 32 bits, 8 octets pour un programme compilé en 64 bits).  Exemple :    ```wlangage i est un entier système ``` _(WINDEV, WEBDEV - Code Serveur, iPhone/iPad, Apple Watch)_ Remarque : La fonction EntierSystèmeVersEntier permet de convertir un entier système en un entier sur 4 octets. |

Vous trouverez les valeurs exactes de ces différents types d'entiers dans le fichier Limites.wl présent dans le sous-répertoire Personal\External du répertoire d'installation de WINDEV, WEBDEV, WINDEV Mobile.
**Remarque** : Tous les types avancés (différents du type "Entier") sont conseillés pour l'utilisation des API Windows.

Par défaut, depuis les versions 7.x, les entiers sont des entiers sur 4 octets.
