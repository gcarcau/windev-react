# PoliceEtendue (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android)

La propriété **PoliceEtendue** permet de gérer l'espacement des caractères de la police. Il est possible de :

- Savoir si les caractères du texte affiché sont étendus ou non.
- Étendre ou non les caractères du texte affiché.

Les différents types d'espacement entre les caractères gérés en WLangage sont :

- Normal : l'espacement entre les caractères est normal.
- Condensé : l'espacement entre les caractères est diminué (propriété [PoliceCondensée](2510096.md)).
- Étendu : l'espacement entre les caractères est augmenté (propriété **PoliceEtendue**).
- Large : l'espacement entre les caractères est augmenté au maximum (propriété [PoliceLarge](2510101.md)).

## Exemple

```wlangage
// Étendre les caractères du texte affiché dans le champ "LIB_ChampLibellé"
LIB_ChampLibellé.PoliceEtendue = Vrai
```

## Syntaxe

#### Savoir si les caractères du texte affiché dans un champ sont étendus

```wlangage
<Résultat> = <Champ manipulé>.PoliceEtendue
```

`<Résultat>` *Booléen*
> - Vrai si les caractères du texte affiché sont étendus,
> - Faux dans le cas contraire.
`<Champ manipulé>` *Nom de champ*
> Nom du champ (champ Libellé ou champ Calculé) à manipuler.

#### Étendre les caractères du texte affiché dans un champ

```wlangage
<Champ manipulé>.PoliceEtendue = <Étendus/Non étendus>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ (champ Libellé ou champ Calculé) à manipuler.
`<Étendus/Non étendus>` *Booléen*
> - Vrai si les caractères du texte affiché doivent être étendus,
> - Faux dans le cas contraire.

## Remarques

### Variable de type Police
Si des polices identiques (même taille, même attribut, ...) doivent être appliquées sur plusieurs champs, il est conseillé d'utiliser une variable de type Police.
Une police peut être créée à partir d'une variable de type [Police](1514045.md).

Pour définir les caractéristiques de la police, utilisez :

- soit la fonction [PoliceCrée](3060002.md),
- soit les propriétés [Angle](1410086632.md), [Barré](2513005.md), [Couleur](2510071.md), [Etendu](2513002.md), [Gras](2513001.md), [Italique](2513007.md), [Large](2513012.md), [Nom](2510082.md), [Souligné](2513013.md) et [Taille](2510125.md).

Cette police pourra être utilisée :

- Pour écrire du texte dans des dessins (fonction [dPolice](3029020.md)).
- Pour écrire dans les graphes (fonctions [grPoliceEtiquette](3042012.md), [grPoliceLégende](3042037.md), [grPoliceTitre](3042048.md) et [grPoliceTitreAxe](3042059.md)).
- Pour imprimer (fonction [iPolice](3046014.md)).
- Dans les champs d'une fenêtre (propriété [Police](1514045.md) des champs d'une fenêtre).
- Dans les champs d'un état (propriété [Police](1514045.md) des champs d'un état).

### Police utilisée par les fonctions d'impression
Pour créer une police utilisable par les [fonctions d'impression](3046065.md) ([iImprimeBloc](3046030.md), [iImprimeMot](3046034.md), ...), utilisez :

- soit la fonction [iCréePolice](3046045.md).
- soit une variable de type [Police](1514045.md).

### Limites
Dans un état, la propriété **PoliceEtendue** peut être utilisée uniquement sur :

- un champ Libellé.
- un champ Lien URL.
- un champ Calculé.
- un champ Prédéfini.

> _(WINDEV)_ Dans une fenêtre, la propriété PoliceEtendue ne peut pas être utilisée sur :un champ Spin,un champ Web Camera,un champ Conférence.Remarque : Cette propriété s'applique sur les champs "Liste image" en mode d'affichage "Liste classique" uniquement.
