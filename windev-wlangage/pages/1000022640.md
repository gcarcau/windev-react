# DocImprime (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Imprime un document au format "docx".
Remarque : Cette fonction est équivalente à la fonction [iImprimeDoc](1000022390.md).

## Exemple

```wlangage
MonDocument est un Document = "c:\temp\propale.docx"
iDestination(iVisualisateur)
DocImprime(MonDocument)
```

## Syntaxe

```wlangage
DocImprime(<Document>)
```

`<Document>` *Variable de type Document ou nom de champ*
> Document à imprimer. Ce document correspond :
>
> - au nom d'un champ Traitement de texte.
> - à une variable de type [Document](1000022461.md).
