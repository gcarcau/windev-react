# SysVersion (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux, PHP)

Renvoie des renseignements sur la version de PHP utilisée sur le poste serveur en cours.

## Exemple

```wlangage
// Affichage de la version PHP
 Info("Version PHP " + SysVersion())
```

## Syntaxe

```wlangage
<Résultat> = SysVersion()
```

`<Résultat>` *Chaîne de caractères*
> - Information demandée sur la version PHP,
> - Chaîne vide ("") en cas d'erreur.
>
>
> > _(WEBDEV - Code Serveur)_ Cette fonction est également disponible en WEBDEV Serveur uniquement pour pouvoir être utilisée lors du débogage d'un site PHP. La fonction retourne alors "Mode simulation PHP". Si cette fonction est utilisée en dehors du mode de débogage d'un site PHP, une erreur fatale est affichée.

**Composante : wd300page.dll**
