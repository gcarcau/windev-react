# Email (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Email** permet de connaître et de modifier une adresse email. Cette propriété est utilisable sur :

- une variable de type [gglAuteur](1000017746.md).
- une variable de type [gglConnexion](1000018009.md).
- une variable de type [gglPersonne](1000017446.md).
- une variable de type [sfInfoUtilisateur](1000018423.md).
- une variable de type [Contact](1000020254.md).
- une variable de type [gpwUtilisateur](1000021088.md).
- une variable de type [saasUtilisateur](1000019083.md).
- une variable de type [OpenIDIdentité](1000023567.md).
- une variable de type [AppleID](1000025405.md).
- une variable de type [adminWBCompte](1410089382.md).
- une variable de type [gglCompte](1410089816.md).
