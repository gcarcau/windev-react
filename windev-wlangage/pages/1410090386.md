# <Variable ActionRapide>.Supprime (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

Supprime une action rapide de l'application.

## Exemple

```wlangage
action est une ActionRapide
action.Identifiant = "ID_ACTION_ENVOI_MESSAGE"
action.Libellé = "Envoyer un message"
action.Procédure = "ProcEnvoiMessage" // ProcEnvoiMessage est une procédure globale
action.Ajoute()
// ...
action.Supprime()
```

## Syntaxe

```wlangage
<Résultat> = <Action>.Supprime()
```

`<Résultat>` *Booléen*
> - Vrai si l'action rapide a été supprimée,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet de connaître le détail de l'erreur.
`<Action>` *Variable de type ActionRapide*
> Variable de type [ActionRapide](1410090054.md) décrivant l'action à supprimer
