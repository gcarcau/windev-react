# <Champ d'afichage HTML>.SurErreurJS (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Indique la procédure à appeler en cas d'erreur dans l'exécution du Javascript dans un champ d'affichage HTML.

## Exemple

```wlangage
HTM_Affichage.SurErreurJS(HTMLSurErreurJS_Callback)
	PROCÉDURE INTERNE HTMLSurErreurJS_Callback()
		Erreur(ErreurInfo())
	FIN
```

## Syntaxe

```wlangage
<Champ d'affichage HTML>.SurErreurJS(<Procédure WLangage>)
```

`<Champ d'affichage HTML>` *Nom de champ*
> Nom du champ d'affichage HTML à manipuler.
`<Procédure WLangage>` *Nom de procédure*
> Procédure WLangage (également nommée "callback") appelée lorsqu'une erreur est rencontrée dans le code Javascript de la page. Cette procédure est de la forme :
>
>
> ```wlangage
> PROCEDURE <Nom de la procédure>(sErreur est une chaîne)
> ```
>
>
> où <sErreur> est une chaîne de caractères correspondant à l'erreur Javascript rencontrée.
> Dans le code de cette procédure, la fonction [ErreurInfo](3013008.md) permet de connaître l'erreur rencontrée.

**Classification Métier / UI : Code UI**

**Composante : wd300obj.dll**
