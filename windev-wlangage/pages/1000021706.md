# hbLit (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Lit des cellules (valeurs de rubriques) d'une ligne (enregistrement) dans une table HBase.

## Exemple

```wlangage
// Connexion
Connexion est un hbConnexion
Connexion.Serveur = "MonServeur"
// Description des données à lire
Lecture est un hbLecture
Lecture.Ligne = "post1"
Lecture.Version = 2
// Description colonne
Col est un hbColonne
Col.Famille = "Post"
Ajoute(Lecture.Colonne, Col)
// Lecture des données
MonRésultat est un tableau de hbCellule = hbLit(connexion, "blog", Lecture)
// Affichage des données lues
POUR TOUT Cellule DE MonRésultat FAIRE
	Trace("Colonne : " + Cellule.Colonne.Qualificatif + "; Valeur : " + ...
	Cellule.Valeur + "; timestamp : " + Cellule.Timestamp)
FIN
```

## Syntaxe

```wlangage
<Résultat> = hbLit(<Connexion> , <Table> , <Lecture>)
```

`<Résultat>` *Tableau de hbCellule*
> Tableau de variables de type [hbCellule](1000021707.md) correspondant aux valeurs des cellules lues.
`<Connexion>` *Variable de type hbConnexion*
> Nom de la variable de type [hbConnexion](1000021685.md) correspondant à la connexion au serveur HBase.
`<Table>` *Chaîne de caractères*
> Nom de la table HBase à manipuler.
`<Lecture>` *Variable de type hbLecture*
> Nom de la variable de type [hbLecture](1000021701.md) contenant les caractéristiques de la lecture à effectuer.
