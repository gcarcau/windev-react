# SAPDéconnecte (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Déconnecte un système SAP R/3.

## Exemple

```wlangage
SAP.Adresse = "MINISAP.test.com"
SAP.NuméroSystème = "0"
SAP.NuméroClient = "000"
SAP.Utilisateur = "BCUSER"
SAP.MotDePasse = "MINISAP"
SAP.Langue = ""
IDSAP est un entier = SAPConnecte()
...
SAPDéconnecte(IDSAP)
```

## Syntaxe

```wlangage
SAPDéconnecte(<Identifiant de la connexion>)
```

`<Identifiant de la connexion>` *Entier*
> Identifiant de la connexion renvoyé par la fonction [SAPConnecte](1000017120.md).

**Composante : wd300mess.dll**
