# pdfProtection (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Le type **pdfProtection** permet de connaître les différentes protections appliquées à un document PDF présent dans une variable de type [pdfDocument](1000024909.md).
Nouveauté Abonnement
**Attention** : Ce type de variable est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3. Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
mon_doc est un pdfDocument = "monpdf.pdf"

SI mon_doc.Protection.Modification = Vrai ALORS
	Info("Modification autorisée")
FIN

SI mon_doc.Protection.Assemblage = Vrai ALORS
	Info("Ajout, suppression et rotation de page autorisés")
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type pdfProtection
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **pdfProtection** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Assemblage | Booléen | - Vrai si l'assemblage de documents est autorisé, - Faux dans le cas contraire.  Cette propriété est disponible en lecture seulement. |
| Commentaire | Booléen | - Vrai si l'insertion de commentaires dans le document est autorisée, - Faux dans le cas contraire.  Cette propriété est disponible en lecture seulement. |
| CopieAccessibilité | Booléen | - Vrai si la copie du contenu pour accessibilité est autorisée, - Faux dans le cas contraire.  Cette propriété est disponible en lecture seulement. |
| Impression | Booléen | - Vrai si l'impression du document est autorisée, - Faux dans le cas contraire.  Cette propriété est disponible en lecture seulement. |
| Modification | Booléen | - Vrai si la modification du document est autorisée, - Faux dans le cas contraire.  Cette propriété est disponible en lecture seulement. |
| RemplissageFormulaire | Booléen | - Vrai si le remplissage des champs de type formulaire est autorisé, - Faux dans le cas contraire.  Cette propriété est disponible en lecture seulement. |
| Sélection | Booléen | - Vrai si le contenu du fichier PDF peut être copié ou extrait, - Faux dans le cas contraire.  Cette propriété est disponible en lecture seulement. |
