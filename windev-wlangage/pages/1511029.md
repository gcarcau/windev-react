# MaVisiteGuidée

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

La variable **MaVisiteGuidée** permet de manipuler la visite guidée en cours. La variable **MaVisiteGuidée** permet de connaître les caractéristiques de la variable de type [VisiteGuidée](1410090170.md) utilisée.
Si aucune visite guidée n'est en cours, **MaVisiteGuidée** renvoie une erreur.

## Exemple

```wlangage
SI EnModeVisiteGuidée() = Vrai ALORS
	Trace("Version de la visite guidée en cours : " + MaVisiteGuidée.Version)
FIN
```

## Syntaxe

```wlangage
MaVisiteGuidée
```

## Remarques

### Fonctions du WLangage et Visite guidée en cours
Les fonctions WLangage manipulant une visite guidée peuvent utiliser la variable **MaVisiteGuidée**.
