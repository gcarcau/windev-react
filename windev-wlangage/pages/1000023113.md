# BeaconListeDétectionEnArrièrePlan (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Retourne la liste des détections actives de balises Beacon lancées en arrière-plan avec la fonction [BeaconDétecteEnArrièrePlan](1000023112.md).

## Exemple

```wlangage
// Parcours les détections en cours
tabGroupeBalises est un tableau de beaconGroupe = BeaconListeDétectionEnArrièrePlan()
POUR TOUT groupe DE tabGroupeBalises
	// Arrête la détection en arrière-plan d'un groupe de balises
	SI groupe.UUID = " 12345678-1234-1234-1234-123456789012 " _ET_ groupe.Major = 5 ALORS
		BeaconArrêteDétectionEnArrièrePlan(groupe)
	FIN
FIN
```

## Syntaxe

```wlangage
<Résultat> = BeaconListeDétectionEnArrièrePlan()
```

`<Résultat>` *Tableau de beaconGroupe*
> Tableau de variables de type [beaconGroupe](1000023105.md) correspondant à la liste des groupes de balises Beacon en cours de détection. Si aucune détection n'est en cours, ce tableau est vide.

## Remarques

### Version nécessaire

> _(Android, Widget Android)_ Les fonctions de gestion des balises Beacon sont disponibles uniquement sur les appareils disposant d'une version d'Android supérieure ou égale à la version 4.3 (api level 18).
Si la fonction est utilisée avec une version antérieure du système, une erreur fatale sera déclenchée. Pour connaître la version du système Android sur laquelle s'exécute l'application, utilisez la fonction SysVersionAndroid.

> _(iPhone/iPad, Widget IOS)_ Les fonctions de gestion des balises Beacon sont disponibles uniquement sur les appareils disposant d'une version d'iOS supérieure ou égale à iOS 11.
