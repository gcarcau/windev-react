# SysCouleur (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **Autres** (Procédures stockées)

Identifie ou modifie la couleur d'un élément Windows.

## Exemple

```wlangage
// Identifier la couleur de la barre de titre active
ResCouleur = SysCouleur(scBrTitreActif)
```

## Syntaxe

#### Identifier la couleur d'un élément Windows

```wlangage
<Résultat> = SysCouleur(<Élément Windows>)
```

`<Résultat>` *Entier*
> Couleur de l'élément spécifié sous la forme RVB. Pour récupérer les composantes de la couleur, utilisez les fonctions [RVBBleu](3029049.md), [RVBRouge](3029050.md) et [RVBVert](3029051.md).

## Remarques

### Couleur
La couleur dépend du nombre de couleurs utilisées par le système et de la résolution de l'écran. Ce nombre de couleurs peut être connu grâce à la fonction [SysCouleurRes](3073012.md).
