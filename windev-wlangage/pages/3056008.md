# Constantes Net

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |
| **INTERNET** | Temps d'attente de réponse (TimeOut) utilisé pour la connexion : Valeur adaptée à l'utilisation d'Internet (temps d'attente de réponse important). | [NetConnecte](3056004.md) |
| **INTRANET** | Temps d'attente de réponse (TimeOut) utilisé pour la connexion : Valeur adaptée à l'utilisation d'Intranet (temps d'attente de réponse faible). | [NetConnecte](3056004.md) |
| **IPv4** | Liste les adresses IPv4 d'un poste. | [NetListeAdresseIP](1000019683.md) |
| **IPv6** | Liste les adresses IPv6 d'un poste. | [NetListeAdresseIP](1000019683.md) |
| **netConfirmer** | Type de la boîte de dialogue à afficher : Boîte de message avec les boutons "Oui", "Non" et "Annuler". | [NetMessageBoxClient](3056017.md), [NetMessageBoxDistant](3056020.md) |
| **netInfo** | Type de la boîte de dialogue à afficher : Boîte de message de type Information (bouton "OK" uniquement). | [NetMessageBoxClient](3056017.md), [NetMessageBoxDistant](3056020.md) |
| **netOkAnnuler** | Type de la boîte de dialogue à afficher : Boîte de message avec les boutons "OK" et "Annuler". | [NetMessageBoxClient](3056017.md), [NetMessageBoxDistant](3056020.md) |
| **netOptionEnvoieBuffer** | Gère les droits des clients sur le poste serveur : Autoriser ou non l'utilisation de la fonction [NetEnvoieBuffer](3056001.md). | [NetOptionServeur](3056022.md) |
| **netOptionEnvoieFichier** | Gère les droits des clients sur le poste serveur : Autoriser ou non l'utilisation de la fonction [NetEnvoieFichier](3056005.md). | [NetOptionServeur](3056022.md) |
| **netOptionEnvoieMessage** | Gère les droits des clients sur le poste serveur : Autoriser ou non l'utilisation de la fonction [NetEnvoieMessage](3056003.md). | [NetOptionServeur](3056022.md) |
| **netOptionExécute** | Gère les droits des clients sur le poste serveur : Autoriser ou non l'utilisation de la fonction [NetExécute](3056002.md). | [NetOptionServeur](3056022.md) |
| **netOptionListeDisque** | Gère les droits des clients sur le poste serveur : Autoriser ou non l'utilisation de la fonction [NetListeDisque](3056015.md). | [NetOptionServeur](3056022.md) |
| **netOptionListeRep** | Gère les droits des clients sur le poste serveur : Autoriser ou non l'utilisation de la fonction [NetListeRep](3056016.md). | [NetOptionServeur](3056022.md) |
| **netOptionMessageBoxDistant** | Gère les droits des clients sur le poste serveur : Autoriser ou non l'utilisation de la fonction [NetMessageBoxDistant](3056020.md). | [NetOptionServeur](3056022.md) |
| **netOptionRécupèreFichier** | Gère les droits des clients sur le poste serveur : Autoriser ou non l'utilisation de la fonction [NetRécupèreFichier](3056025.md). | [NetOptionServeur](3056022.md) |
| **netOptionRenommeFichier** | Gère les droits des clients sur le poste serveur : Autoriser ou non l'utilisation de la fonction [NetRenommeFichier](3056006.md). | [NetOptionServeur](3056022.md) |
| **netOptionSupprimeFichier** | Gère les droits des clients sur le poste serveur : Autoriser ou non l'utilisation de la fonction [NetSupprimeFichier](3056018.md). | [NetOptionServeur](3056022.md) |
| **netOuiNon** | Type de la boîte de dialogue à afficher : Boite de message avec les boutons "Oui" et "Non". | [NetMessageBoxClient](3056017.md), [NetMessageBoxDistant](3056020.md) |
| **netRéessayerAnnuler** | Type de la boîte de dialogue à afficher : Boîte de message avec les boutons "Réessayer" et "Annuler". | [NetMessageBoxClient](3056017.md), [NetMessageBoxDistant](3056020.md) |
| **netRéessayerIgnorer** | Type de la boîte de dialogue à afficher : Boîte de message avec les boutons "Abandon", "Réessayer" et "Ignorer". | [NetMessageBoxClient](3056017.md), [NetMessageBoxDistant](3056020.md) |
| **niConnecté** | Type d'information souhaitée sur la connexion : permet de savoir si la connexion est active. | [NetInfoAccèsDistant](3056028.md) |
| **niDuréeConnexion** | Type d'information souhaitée sur la connexion : durée depuis l'ouverture de la connexion. | [NetInfoAccèsDistant](3056028.md) |
| **niNbOctetReçu** | Type d'information souhaitée sur la connexion : nombre d'octets reçus depuis l'ouverture de la connexion. | [NetInfoAccèsDistant](3056028.md) |
| **niNbOctetTransmis** | Type d'information souhaitée sur la connexion : nombre d'octets transmis depuis l'ouverture de la connexion. | [NetInfoAccèsDistant](3056028.md) |
| **ServeurFTP** | Type de serveur utilisé : Utilisation d'un serveur WINDEV FTP. | [NetConnecte](3056004.md)[NetDémarreServeur](3056013.md) |
| **ServeurRPC** | Type de serveur utilisé : Utilisation d'un serveur WINDEV RPC. | [NetConnecte](3056004.md), [NetDémarreServeur](3056013.md) |
