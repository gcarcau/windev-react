# Trou (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

La propriété **Trou** permet de définir les trous d'un polygone. Ce trou correspond à une polyligne simple et fermée présente à l'intérieur d'un polygone. Cette propriété est disponible sur :

- une variable de type [Polygone2D](1410090122.md).
- une variable de type [PolygoneGéo](1410090127.md).
