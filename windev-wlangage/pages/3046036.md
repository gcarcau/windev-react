# iLargeurPage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Calcule la largeur de la page imprimable (en millimètres) en tenant compte des marges (gauches ou droites) définies.

## Exemple

```wlangage
// Imprime les dimensions de la feuille (en mm)
iImprime("Largeur de la page : " + iLargeurPage() + "mm")
iImprime("Hauteur de la page : " + iHauteurPage() + "mm")
iFinImprime()
```

## Syntaxe

```wlangage
<Résultat> = iLargeurPage(<Identifiant de la police>)
```

`<Résultat>` *Réel*
> Largeur de la page :
>
> - en millimètres si le paramètre <Identifiant de la police> n'est pas précisé.
> - en nombre de caractères imprimables avec la police <Identifiant de la police>. Si la police <Identifiant de la police> est une police proportionnelle, le nombre retourné correspond au nombre moyen de caractères imprimables.
>
>
> > _(Android, Widget Android, Java)_ Largeur de la page en millimètres.
`<Identifiant de la police>` *Chaîne de caractères*
> Identifiant de la police utilisée, renvoyé par la fonction [iPolice](3046014.md) ou précisé lors de la création de la police avec la fonction [iCréePolice](3046045.md). Si ce paramètre n'est pas spécifié, la largeur de la page sera renvoyée en millimètres.
> > _(Android, Widget Android, Java)_ Ce paramètre n'est pas disponible.

## Remarques

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Code Utilisateur (MCU), Ajax)_ Utilisation dans le code d'un étatSi la fonction iLargeurPage est utilisée :après le code d'ouverture de l'état, le résultat correspond à la largeur imprimable dans l'état (largeur de la page - les marges de gauche et droite).dans le code d'ouverture de l'état, le résultat correspond à la largeur imprimable physiquement (largeur de la page - les marges physiques de gauche et droite définies pour l'imprimante).

### Divers
La fonction [iHauteurPage](3046052.md) permet de connaître la hauteur imprimable d'une page.
