# telDialerAffiche (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android)

Ouvre l'application de téléphonie (dialer) par défaut et affiche le numéro spécifié. Aucun appel n'est déclenché.

## Exemple

```wlangage
telDialerAffiche("0612345678")
```

## Syntaxe

```wlangage
<Résultat> = telDialerAffiche(<Numéro de téléphone>)
```

`<Résultat>` *Booléen*
> - Vrai si l'application de téléphonie (dialer) a pu être ouverte,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Numéro de téléphone>` *Chaîne de caractères*
> Numéro de téléphone à afficher dans l'écran de numérotation.
> Si ce paramètre est une chaîne vide (""), l'application de téléphonie sera ouverte sur l'écran de numérotation.

## Remarques

### Appel automatique
Pour déclencher automatiquement l'appel du numéro spécifié, utilisez la fonction [telDialerCompose](1000019235.md).

> _(Android, Widget Android)_ Application en arrière-plan : Spécificité à partir de Android 10A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. La fonction telDialerAffiche peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. Conseils : Il est possible de savoir si l'application est en arrière-plan grâce à la fonction EnModeArrièrePlan. Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type Notification). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété ActiveApplication est à Vrai. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété ActionClic.Pour plus de détails, consultez Android 10 : Comportement des applications en arrière-plan.
