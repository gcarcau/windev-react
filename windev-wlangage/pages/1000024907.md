# Orientation (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **Orientation** permet de connaître et de modifier l'orientation d'un élément. Cette propriété est utilisable sur :

- une variable de type [docSection](1000022685.md).
- une variable de type [pdfPage](1000024904.md).
- une variable de type [iInfoSortie](1410088954.md).
