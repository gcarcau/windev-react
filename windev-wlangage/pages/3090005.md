# Fonctions USB

> **Disponible :** **WINDEV** (Windows)

Les fonctions permettant de gérer les périphériques USB sont les suivantes :

| [USBDéconnecte](3090001.md) | Déconnecte ou éjecte un périphérique USB. |
| --- | --- |
| [USBDétecteStockageAmovible](3090007.md) | Détecte si une unité de stockage amovible (par exemple CD, clé USB, appareil photo USB, ...) a été ajoutée ou enlevée. |
| [USBListePériphérique](3090002.md) | Liste les périphériques USB actuellement branchés sur le poste en cours. |
| [USBPropriété](3090003.md) | Récupère la valeur d'une propriété d'un périphérique USB. |
| [USBRecherche](3090004.md) | Recherche un périphérique USB d'après certains mots-clés. |
