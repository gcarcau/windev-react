# SaaSAdminListeLicence (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Liste les licences d'abonnement SaaS associées à un utilisateur.
**Attention** : Cette fonction est disponible uniquement à partir de la version 2025 Update 1.

## Exemple

```wlangage
SI PAS SaaSAdminConnecte(login, password, serveur) ALORS
	RETOUR
FIN
// Liste les utilisateurs
tabUtilisateur est tableau de saasUtilisateur = SaaSAdminListeUtilisateur()
SI tabUtilisateur.Occurrence = 0 ALORS
	RETOUR
FIN
// Liste les sites
tabSite est tableau de saasSite = SaaSAdminListeSite()
SI tabSite.Occurrence = 0 ALORS
	RETOUR
FIN
// Liste les abonnements disponibles
tabAbonnement est un tableau de saasAbonnement = SaaSAdminListeAbonnement(tabSite[1])
SI tabAbonnement.Occurrence = 0 ALORS
	RETOUR
FIN
// Liste les licences de l'utilisateur
Abonnements_utilisateur_avant est un tableau de saasAbonnement = SaaSAdminListeLicence(tabUtilisateur[1])
// Active une licence
SI PAS SaaSAdminActiveLicence(tabAbonnement[1], tabUtilisateur[1]) ALORS
	RETOUR
FIN
// Liste les licences
Abonnements_utilisateur_ est un tableau de saasAbonnement = SaaSAdminListeLicence(tabUtilisateur[1])
// Désactive la licence
SaaSAdminDésactiveLicence(tabAbonnement[1], tabUtilisateur[1])
// Liste les licences après désactivation
Abonnements_utilisateur_Apres est un tableau de saasAbonnement = SaaSAdminListeLicence(tabUtilisateur[1])
Info("Avant " + Abonnements_utilisateur_avant.Occurrence, "Pendant " + Abonnements_utilisateur_.Occurrence,
	"Après " + Abonnements_utilisateur_Apres.Occurrence)
```

## Syntaxe

```wlangage
<Résultat> = SaaSAdminListeLicence(<Utilisateur>)
```

`<Résultat>` *Tableau de variables de type saasAbonnement*
> Variable de type [saasAbonnement](1000019088.md) contenant la liste des licences d'abonnement de l'utilisateur spécifié.
`<Utilisateur>` *Variable de type saasUtilisateur*
> Nom de la variable de type saasUtilisateur correspondant à l'utilisateur pour lequel les licences d'abonnement sont recherchées.
