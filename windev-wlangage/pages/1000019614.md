# EnModeWindows (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Identifie si le code est exécuté en mode Windows ou non.
**Rappel** : Pour connaître le système d'exécution, utilisez la fonction [SysVersionWindows](3073025.md).

## Exemple

```wlangage
// Code exécuté en Windows ?
SI EnModeWindows() = Vrai ALORS
	// Code spécifique à la plateforme Windows
FIN
```

## Syntaxe

```wlangage
<Résultat> = EnModeWindows()
```

`<Résultat>` *Booléen*
> - Vrai si le code est exécuté en mode Windows,
> - Faux dans le cas contraire (Faux en Windows CE par exemple).
>
>
> > _(WEBDEV - Code Navigateur)_ Ce paramètre correspond toujours à Faux.

## Remarques

### Disponibilité de la fonction
La fonction **EnModeWindows** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **EnModeWindows** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.

### Exécution des traitements contenant des erreurs de compilation
Par défaut, le mécanisme de sécurité du WLangage se déclenche uniquement si la ligne contenant l'erreur de compilation est exécutée.
Par exemple, si une fonction interdite dans le produit en cours est présente dans une boucle SI, le mécanisme de sécurité du WLangage se déclenchera uniquement si la ligne contenant cette fonction s'exécute.

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
