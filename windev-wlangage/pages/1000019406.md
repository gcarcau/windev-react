# Fonctions DNS

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

## Présentation

Le DNS (Domain Name System) est un service permettant d'établir une correspondance entre une adresse IP et un nom de domaine.
Le WLangage propose plusieurs fonctions permettant de manipuler simplement les adresses IP et les domaines sur un serveur DNS.

## Fonctions WLangage

Les fonctions de gestion des serveurs DNS sont les suivantes :

| [DNSAjouteAdresse](1000019400.md) | Ajoute une association "Adresse IP/Nom de domaine" dans le serveur DNS. |
| --- | --- |
| [DNSInterroge](1410089873.md) | Envoie une requête à un serveur DNS. |
| [DNSListeAdresse](1000019401.md) | Liste les adresses IP associées à un nom de domaine dans le serveur DNS. |
| [DNSSupprimeAdresse](1000019402.md) | Supprime une association "Adresse IP/Nom de domaine" dans un serveur DNS. |
