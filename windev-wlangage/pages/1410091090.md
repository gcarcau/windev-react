# SysCrypte (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **Autres** (Procédures stockées)

Crypte des données en utilisant les informations d'identification de l'utilisateur Windows.
Les données peuvent être décryptées (fonction [SysDécrypte](1410091091.md)) uniquement par l'utilisateur ayant crypté les données et sur la machine où elles ont été cryptées.
Les données cryptées peuvent par exemple être sauvegardées dans un fichier afin d'être décryptées ensuite par le même utilisateur de la même machine que l'application ayant crypté les données.

Nouveauté Abonnement
Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
// Cryptage du buffer
MonBuffer est un Buffer
MonBufferCrypté est un Buffer = SysCrypte(MonBuffer)
```

## Syntaxe

```wlangage
<Résultat> = SysCrypte(<Buffer> [, <Mot de passe application>])
```

`<Résultat>` *Buffer*
> - Buffer contenant les données cryptées.
> - Buffer vide en cas d'erreur. Le compte-rendu détaillé de l'erreur est connu grâce à la fonction [ErreurInfo](3013008.md).
`<Buffer>` *Chaîne de caractères ou Buffer*
> Buffer à crypter.
`<Mot de passe application>` *Buffer optionnel*
> Mot de passe permettant d'appliquer une clé supplémentaire au cryptage des données (clé de salage).
>
> - Si ce paramètre n'est pas précisé, les données seront cryptées sans clé de salage.
> - Si ce paramètre est précisé, il devra également être utilisé pour le décryptage des données.
>
> Ce mot de passe évite qu'une autre application lancée par le même utilisateur sur la même machine puisse décrypter les données si elle n'a pas le mot de passe.
> Remarque : Si vous souhaitez utiliser une chaîne pour initialiser ce buffer, il est conseillé d'utiliser une chaîne au format UTF8 pour un usage dans des applications utilisant des chaînes ANSI ou UNICODE.
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre peut être "Buffer ASCII" ou "Buffer UTF 8".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).

## Remarques

- Si l'utilisateur change le mot de passe de connexion à la machine entre le cryptage et le décryptage, il pourra toujours décrypter les données.
- Les informations d'identification utilisées sont celles du compte Windows utilisé pour l'exécution des sites et Webservices (paramétrées pour le compte de l'administrateur du site dans le gestionnaire de comptes du serveur WEBDEV).
  Tous les internautes des sites administrés par le même compte du serveur WEBDEV partagent le même utilisateur Windows.
  Par conséquent, si un internaute d'un site crypte des données, ces données pourront être décryptées par un internaute de ce site ou d'un autre site administré par le même compte (à condition que l'internaute ait accès à ces données).
