# MargeDroite (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **MargeDroite** permet de définir la marge droite d'un élément. Cette propriété est utilisable :

- sur les états. Pour plus de détails, consultez [MargeDroite](2511053.md).
- sur les variables de type [docSection](1000022685.md).
- sur les variables de type [xlsMiseEnPage](1000023139.md).
