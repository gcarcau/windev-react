# HTTPRAZFormulaire (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Vide un formulaire HTTP en cours d'édition.

## Exemple

```wlangage
HTTPCréeFormulaire("FORM")
...
HTTPRAZFormulaire("FORM")
```

## Syntaxe

```wlangage
HTTPRAZFormulaire(<Nom du formulaire>)
```

`<Nom du formulaire>` *Chaîne de caractères*
> Nom du formulaire HTTP à vider. Ce nom a été donné lors de la création du formulaire HTTP (fonction [HTTPCréeFormulaire](1000017119.md)). Si le formulaire n'existe pas, une erreur est affichée.

**Composante : wd300com.dll**
