# PointDePassage (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **PointDePassage** permet de gérer les points de passage d'un lien. Cette propriété est utilisable sur :

- un champ Fil. Pour plus de détails, consultez l'aide de la propriété [PointDePassage](1000021957.md).
- une variable de type [diagLien](1410088454.md).
- une variable de type [diagActionAutorisée](1410088840.md).
