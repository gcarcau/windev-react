# saasService (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

Le type **saasService** permet de définir toutes les caractéristiques avancées d'un service SaaS.
Les caractéristiques de ce Service peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
MonService est un saasService
MonService.Nom = "Accès"

SiteActuel est un saasSite

SaaSAdminAjouteService(MonService, SiteActuel)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type saasService
Les propriétés suivantes peuvent être utilisées pour manipuler un service SaaS :

| **Nom de la propriété** | **Type manipulé** | **Effet** |
| --- | --- | --- |
| Nom | Chaîne de caractères | Nom du service. Ce nom sera utilisé pour vérifier l'autorisation d'accès grâce à la fonction [SaaSVérifieService](1000018961.md). |
| Site | Variable de type [saasSite](1000019068.md) | Site SaaS auquel le service appartient.  Cette propriété est accessible en lecture seulement. |

## Remarques

### Fonctions utilisant le type SaaService
Les fonctions suivantes peuvent être utilisées pour manipuler une variable de type **saasService** :

| [SaaSAdminActiveService](1000019132.md) | Active un service dans une tarification SaaS. |
| --- | --- |
| [SaaSAdminAjouteService](1000019107.md) | Ajoute un service SaaS dans la description d'un site. |
| [SaaSAdminChercheService](1000019110.md) | Recherche de la description d'un service SaaS. |
| [SaaSAdminDésactiveService](1000019133.md) | Désactive un service dans une tarification SaaS. |
| [SaaSAdminModifieService](1000019108.md) | Modifie un service SaaS. |
| [SaaSAdminSupprimeService](1000019109.md) | Supprime un service SaaS. |
