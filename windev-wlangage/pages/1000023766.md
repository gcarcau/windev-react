# <Arbre>.RécupèreIdentifiant (Fonction)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Renvoie l'identifiant associé à un élément (noeud ou feuille) dans un champ Arbre.
Exemple de champ Arbre :
[image: Vocabulaire lié à un champ Arbre]

## Exemple

```wlangage
// Renvoie l'identifiant du noeud "Desserts" dans le champ Arbre "ARBRE_RecetteTV"
Res = ARBRE_RecetteTV.RécupèreIdentifiant("Recettes" + TAB + "Desserts")
```

## Syntaxe

```wlangage
<Résultat> = <Champ Arbre>.RécupèreIdentifiant(<Chemin de l'élément>)
```

`<Résultat>` *Chaîne de caractères*
> - Identifiant de l'élément spécifié,
> - Chaîne vide ("") si aucun identifiant n'est associé à l'élément ou si l'élément spécifié n'existe pas.
>
>
> Si l'identifiant (défini avec la fonction [<Arbre>.Ajoute](1000023422.md) ou [<Arbre>.Modifie](1000023763.md)) n'est pas une chaîne de caractères mais un entier, il peut être nécessaire de convertir le résultat en entier pour manipuler cet identifiant (fonction [Val](3024037.md)).
`<Champ Arbre>` *Nom de champ*
> Nom du champ Arbre à manipuler.
`<Chemin de l'élément>` *Chaîne de caractères*
> Chemin complet de l'élément à manipuler. Ce paramètre est de la forme :
>
>
> ```wlangage
> "<Nom de la racine>" + TAB + ["<Nom du 1er noeud>" + TAB + ...["<Nom du 2ème noeud>" + TAB + [...]]]"<Nom de la feuille>"
> ```

## Remarques

### Récupérer l'identifiant d'un élément avec gestion des doublons
Pour récupérer l'identifiant de l'élément sélectionné en prenant en compte la gestion des doublons, le paramètre <Chemin de l'élément> doit correspondre au code suivant :

```wlangage
<Champ Arbre>.Select(Vrai)
```

Par exemple :

```wlangage
Trace(ARBRE_Arbre1.Select() + "/" + ...
	ARBRE_Arbre1.RécupèreIdentifiant(ARBRE_Arbre1.Select(Vrai)))
```
