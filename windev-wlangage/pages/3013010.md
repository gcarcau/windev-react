# VersionWINDEV (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Renvoie le numéro de version de la DLL wdxxxvm.
> _(Android, Widget Android, Java)_ Renvoie le numéro de version de l'archive wdxxxjava.jar.

**Remarque** : Cette fonction est équivalente à la fonction [ExeInfo](3035001.md) avec la constante *exeVersion*.

## Exemple

> _(WINDEV, Etats et Requêtes, Code Utilisateur (MCU))_ Info("Version WINDEV : " + VersionWINDEV())

> _(WEBDEV - Code Serveur, Ajax)_ Info("Version WEBDEV : " + VersionWINDEV())

> _(WINDEV, Android, Widget Android, Java)_ Info("Version Java : " + VersionWINDEV())

## Syntaxe

```wlangage
<Résultat> = VersionWINDEV([<Version>])
```

`<Résultat>` *Chaîne de caractères ou constante*
> - Numéro de version de l'élément demandé.
> - Constante correspondant à la langue du framework utilisé.
`<Version>` *Constante optionnelle de type Entier*
> Version recherchée :
>
> | *versionFramework* | Renvoie le numéro de version du framework PC SOFT (par exemple, "01F300039g"). _(Android, Widget Android)_ Non disponible. |
> | --- | --- |
> | *versionLangue* | Renvoie une constante correspondant à la langue du framework :   - *langueAnglais* : Framework en anglais. - *langueChinois* : Framework en chinois. - *langueFrançais* : Framework en français. _(Android, Widget Android, Java, PHP)_ Non disponible. |
> | *versionVM* (valeur par défaut) | Renvoie le numéro de version de la DLL wdxxxvm (par exemple, "30.01Dn"). _(Android, Widget Android, Java)_ Renvoie le numéro de version de l'archive wdxxxjava.aar.Pour connaître la version de cette archive, il suffit de :Ouvrir l'archive ".jar" ou ".aar" (il s'agit d'une archive au format zip),Accéder au dossier "\res\raw\",Ouvrir le fichier "build_info.properties". Ce fichier texte contient (par exemple) :   major.number=25minor.number=0build.number=341revision.number=8   Si une application Android APK / AAB est générée avec cette version du framework, la fonction WLangage VersionWINDEV retourne "25.0.341.8". |

**Composante : wd300vm.dll**
