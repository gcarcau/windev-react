# Sélectionnée (Propriété)

> **Disponible :** **WINDEV** (Windows, Java) · **WEBDEV** (Windows, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Sélectionnée** permet de :

- Savoir si une ligne est sélectionnée (dans un champ Liste, Liste image ou Table) et sélectionner une ligne (dans un champ Liste, Liste image ou Table).
  **Remarque** : A la différence de la fonction [ListeSelect](3049011.md), cette propriété permet de savoir directement si la ligne à l'indice spécifié est sélectionnée ou non.
- Savoir si une colonne ou une cellule d'un champ Table est sélectionnée et sélectionner une colonne ou une cellule d'un champ Table (cas des champs Table avec sélection de la ligne ou de la colonne).
- Savoir si une option d'un menu de type onglet est sélectionnée et sélectionner une option d'un menu de type onglet.

## Exemple

> _(WINDEV, Android, iPhone/iPad, Java)_ // Sélectionne la ligne 5 du champ Liste VILLE
LISTE_Ville[5].Sélectionnée = Vrai

> _(WEBDEV - Code Serveur, PHP)_ // Modifie l'option de menu sélectionnée
OPT_OptionMobile.Sélectionnée = Vrai

## Syntaxe

> _(WINDEV, Android, iPhone/iPad, Java, WINDEV)_ Savoir si un élément est sélectionné Masquer les détails
<Résultat> = <Champ manipulé>[<Indice de la ligne>].Sélectionnée

 <Résultat> : BooléenVrai si l'élément est sélectionné, Faux dans le cas contraire. <Champ manipulé> : Nom de champNom du champ à manipuler : Nom du champ Liste, Liste image ou Table : permet de savoir si la ligne est sélectionnée. Nom de la colonne : permet de savoir si la cellule est sélectionnée. Si l'indice de la ligne n'est pas spécifié, permet de savoir si la colonne est sélectionnée. <Indice de la ligne> : EntierIndice de la ligne à manipuler.

> _(WINDEV, Android, iPhone/iPad, Java, WINDEV)_ Sélectionner un élément Masquer les détails
<Champ manipulé>[<Indice de la ligne>].Sélectionnée = <Sélection>

 <Champ manipulé> : Nom de champNom du champ à manipuler : Nom du champ Liste, Liste image ou Table : permet de sélectionner ou non une ligne. Nom de la colonne : permet de sélectionner ou non une cellule. Si L'indice de la ligne n'est pas spécifié, permet de sélectionner ou non la colonne de la table. <Indice de la ligne> : EntierIndice de la ligne à manipuler. <Sélection> : BooléenVrai si l'élément doit être sélectionné, Faux dans le cas contraire.

> _(WEBDEV - Code Serveur, PHP, Ajax)_ Savoir si une option de menu WEBDEV est sélectionnée Masquer les détails
<Résultat> = <Option manipulée>.Sélectionnée

 <Résultat> : BooléenVrai si l'option est sélectionnée, Faux dans le cas contraire. <Option manipulée> : Nom d'optionNom de l'option de menu à manipuler.

> _(WEBDEV - Code Serveur, PHP, Ajax)_ Sélectionner une option de menu WEBDEV Masquer les détails
<Option manipulée>.Sélectionnée = <Sélection>

 <Option manipulée> : Nom d'optionNom de l'option à sélectionner. <Sélection> : BooléenVrai si l'option doit être sélectionnée, Faux dans le cas contraire.

## Remarques

> _(WINDEV, Android, iPhone/iPad, Java, iPhone/iPad)_ Champ Liste monosélection et multisélectionDans le cas d'un champ Liste multisélection, la propriété Sélectionnée permet de :connaître les lignes sélectionnées.sélectionner plusieurs lignes.Dans le cas d'un champ Liste monosélection, lorsque une ligne est sélectionnée avec la propriété Sélectionnée, la ligne précédemment sélectionnée est automatiquement dé-sélectionnée. Les champs Liste multisélection ne sont pas disponibles.

> _(WINDEV, Android, iPhone/iPad, Java)_ LimitesLa propriété Sélectionnée s'applique uniquement aux :Champs Table.Champs Liste.Champs Liste image.Colonnes de table.Cellules de table.

> _(Android, iPhone/iPad, Java)_ La propriété Sélectionnée s'applique uniquement aux champs Liste.
