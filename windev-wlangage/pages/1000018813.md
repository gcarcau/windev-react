# FormatHtml (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

La propriété **FormatHtml** permet de :

- savoir si un champ de saisie accepte la saisie au format HTML.
- modifier le format de saisie d'un champ de saisie.

Cette propriété est utilisable sur les champs de saisie d'une fenêtre.

## Exemple

```wlangage
// Si le champ est au format HTML
SI SAI_MonChamp.FormatHtml = Vrai ALORS
	// Récupération du texte brut
	sValeur = HTMLVersTexte(SAI_MonChamp)
FIN
```

## Syntaxe

#### Savoir si un champ de saisie est au format HTML

```wlangage
<Résultat> = <Champ de saisie>.FormatHtml
```

`<Résultat>` *Booléen*
> - Vrai si la saisie dans le champ se fait au format HTML,
> - Faux dans le cas contraire.
`<Champ de saisie>` *Nom de champ*
> Nom du champ de saisie à manipuler.

#### Activer/désactiver la saisie au format HTML dans un champ de saisie

```wlangage
<Champ de saisie>.FormatHtml = <Valeur>
```

`<Champ de saisie>` *Nom de champ*
> Nom du champ de saisie à manipuler.
`<Valeur>` *Booléen*
> - Vrai si la saisie dans le champ doit se faire au format HTML,
> - Faux dans le cas contraire.
