# <Type DateHeure>.VersEpoch (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Convertit une date-heure locale vers le format Epoch (nombre d'unités de temps depuis le 01/01/1970 à 00h00 UTC).

## Exemple

```wlangage
MonJour est un DateHeureMonJour = "20170726100941"// Affiche "1501056581" (en France)Info(MonJour.VersEpoch())
```

## Syntaxe

```wlangage
<Résultat> = <Donnée à convertir>.VersEpoch([<Options de conversion>])
```

`<Résultat>` *Entier sur 8 octets*
> - Date et heure au format Epoch (nombre d'unités de temps depuis le 01/01/1970 à 00h00 UTC).
> - -1 en cas d'erreur (date et heure invalides).
`<Donnée à convertir>` *Variable de type DateHeure*
> Variable de type DateHeure correspondant à la date et heure locale à convertir. Ce paramètre sera considéré invalide dans les cas suivants :
>
> - si la date est invalide ou antérieure au 01/01/1970. La validité de la date peut être vérifiée avec la fonction [DateValide](3027003.md).
> - si l'heure est invalide. La validité de l'heure peut être vérifiée avec la fonction [HeureValide](3027021.md).
>
> Remarque : Il est possible d'utiliser des dates au-delà de l'année 2038.
`<Options de conversion>` *Constante optionnelle de type Entier*
> Options de conversion de la date et de l'heure au format Epoch :
>
>
> | *epochUnixMilliseconde* | Le résultat sera exprimé en nombre de millisecondes depuis le 01/01/1970 à 00h00 UTC (temps 0 sous Unix). |
> | --- | --- |
> | *epochUnixSeconde* (valeur par défaut) | Le résultat sera exprimé en nombre de secondes depuis le 01/01/1970 à 00h00 UTC (temps 0 sous Unix). |

**Classification Métier / UI : Code neutre**

**Composante : wd300std.dll**
