# <Variable EmailSessionOutlook>.MiseAJour (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **Autres** (Procédures stockées)

Met à jour les messages de MS Exchange par rapport au serveur d'emails. Les opérations suivantes sont réalisées :

- Les messages présents dans la boîte d'envoi de MS Exchange sont envoyés vers le serveur d'email Internet.
- Les messages en attente sur le serveur Internet sont transférés dans la boîte de réception du client MS Exchange.

La fonction **<Variable EmailSessionOutlook>.MiseAJour** est utilisable uniquement avec le client MS Exchange.

**Rappel** : Pour manipuler des emails, il est nécessaire d'ouvrir une session d'email grâce à la fonction [<Variable EmailSessionOutlook>.OuvreSession](1000022302.md).

## Exemple

```wlangage
// Ouverture de la session
IDSession est une emailSessionOutlook
...
// Récupération des messages dans la boîte de réception de MS Exchange
SI IDSession.MiseAJour() = Vrai ALORS
	Info("Messages récupérés")
SINON
	Erreur()
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Session>.MiseAJour()
```

`<Résultat>` *Booléen*
> - Vrai si la mise à jour a été effectuée,
> - Faux dans le cas contraire. En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Session>` *Variable de type emailSessionOutlook*
> Nom de la variable de type [emailSessionOutlook](1000018767.md) permettant d'identifier la session.

## Remarques

### Erreur lors de la transmission de l'email
Si un message n'a pas pu être transmis à cause d'une mauvaise connexion Internet ou d'une adresse incorrecte, le message est retourné au client MS Exchange : le message apparaît donc dans les messages non lus.
