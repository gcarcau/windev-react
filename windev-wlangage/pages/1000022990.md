# MotDePasseCléPrivée (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **MotDePasseCléPrivée** permet de gérer le mot de passe du fichier de clés (dans le cas d'une connexion par clé privée). Cette propriété est utilisée :

- par les variables de type [sshSession](1000021157.md).
- par les variables de type [mqttSession](1000023023.md).
- Nouveauté 2025
   une variable de type [ftpConnexion](1410090869.md).
