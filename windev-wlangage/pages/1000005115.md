# NotesRAZ (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Crée un document vide dans Lotus Notes.
**Remarques** :

- Pour modifier les champs Lotus Notes de ce document, utilisez la fonction [NotesModifieChamp](1000005113.md).
- Pour enregistrer ce document, utilisez la fonction [NotesEnregistre](1000005110.md).

## Exemple

```wlangage
// Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", ...
		"mail\julie.nsf", "C:\Users\Julie\AppData\Local\Lotus\Notes\Data\user.id")
...
// Création d'un document
NotesRAZ(IDSession)
// Modification des champs Lotus Notes de ce document
NotesModifieChamp(IDSession, "Subject", "Mon sujet")
NotesModifieChamp(IDSession, "Name", "Mon nom")
NotesModifieChamp(IDSession, "Body", "Mon texte")
// Enregistrement de ce document
NotesEnregistre(IDSession)
```

```wlangage
// Ouverture d'une connexion Lotus Notes
IDConnexion est un entier
IDConnexion = NotesOuvreConnexion("MotDePasse", "ServeurMars", ...
		"C:\Users\Julie\AppData\Local\Lotus\Notes\Data\user.id")
// Spécification de la base Lotus Notes à utiliser
IDBase est un entier
IDBase = NotesOuvreBase(IDConnexion, "MaBase.nsf")
...
// Création d'un document
NotesRAZ(IDBase)
// Modification de ce document
NotesModifieChamp(IDBase, "Subject", "Mon sujet")
// Enregistrement de ce document
NotesEnregistre(IDBase)
```

## Syntaxe

```wlangage
<Résultat> = NotesRAZ(<Identifiant de la session>)
```

`<Résultat>` *Booléen*
> - Vrai si le document vide a bien été créé,
> - Faux dans le cas contraire. En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai.
>    Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Identifiant de la session>` *Entier*
> Identifiant de la session à utiliser. Cet identifiant est renvoyé par la fonction [EmailOuvreSessionNotes](3032121.md) ou la fonction [NotesOuvreBase](1000005101.md).
