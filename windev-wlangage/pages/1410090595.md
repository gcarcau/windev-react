# Fonctions de gestion des données spatiales (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Les fonctions permettant de manipuler des données spatiales via une syntaxe préfixée sont les suivantes :

| [<Variable Polygone2D>.Aire](1410090517.md) | Calcule l'aire d'un polygone en 2 dimensions. |
| --- | --- |
| [<Variable Polygone2D>.Chevauche](1410090519.md) | Permet de savoir si un polygone en 2 dimensions chevauche une autre géométrie. |
| [<Variable Polygone2D>.Contient](1410090522.md) | Permet de savoir si une géométrie A de type polygone en 2 dimensions contient une géométrie B. |
| [<Variable Polygone2D>.Corrige](1410090523.md) | Permet d'obtenir une version corrigée du polygone en 2 dimensions spécifié. |
| [<Variable Polygone2D>.Couvre](1410090526.md) | Permet de savoir si une géométrie A de type polygone en 2 dimensions couvre une géométrie B. |
| [<Variable Polygone2D>.Croise](1410090527.md) | Permet de savoir si un polygone en 2 dimensions croise une autre géométrie. |
| [<Variable Polygone2D>.Différence](1410090530.md) | Renvoie la géométrie correspondant à la différence entre un polygone en 2 dimensions et une autre géométrie. |
| [<Variable Polygone2D>.DifférenceSymétrique](1410090531.md) | Calcule la différence symétrique entre un polygone en 2 dimensions et une autre géométrie. |
| [<Variable Polygone2D>.Disjoint](1410090563.md) | Permet de savoir si deux géométries sont disjointes, c'est-à-dire si leur intersection est vide. |
| [<Variable Polygone2D>.Distance](1410090566.md) | Calcule la distance entre un polygone en 2 dimensions et une autre géométrie. |
| [<Variable Polygone2D>.Egale](1410090567.md) | Permet de savoir si deux géométries sont spatialement égales, c'est-à-dire si la première géométrie est incluse dans la seconde, et si la seconde est incluse dans la première. |
| [<Variable Polygone2D>.EnveloppeConvexe](1410090588.md) | Calcule l'enveloppe convexe du polygone en 2 dimensions spécifié. |
| [<Variable Polygone2D>.EstContenu](1410090571.md) | Permet de savoir si la géométrie A (de type polygone en 2 dimensions) est complètement contenue dans la géométrie B (c'est-à-dire que la géométrie B contient complètement la géométrie A). |
| [<Variable Polygone2D>.EstCouvert](1410090572.md) | Permet de savoir si tout point de la géométrie A (de type polygone en 2 dimensions) se trouve à l'intérieur ou dans le contour de la géométrie B. |
| [<Variable Polygone2D>.EstValide](1410090575.md) | Vérifie si le polygone en 2 dimensions spécifié est valide au sens de la norme OGC. |
| [<Variable Polygone2D>.Intersecte](1410090576.md) | Vérifie si une géométrie de type polygone en 2 dimensions et une géométrie quelconque ont une intersection non vide. |
| [<Variable Polygone2D>.Intersection](1410090579.md) | Renvoie la géométrie correspondant à l'intersection d'un polygone en 2 dimensions avec une autre géométrie. |
| [<Variable Polygone2D>.Périmètre](1410090580.md) | Calcule le périmètre d'un polygone en 2 dimensions. |
| [<Variable Polygone2D>.SérialiseWKT](1410090583.md) | Sérialise un polygone en 2 dimensions au format Well Known Text (WKT). |
| [<Variable Polygone2D>.Touche](1410090584.md) | Permet de savoir si un polygone en 2 dimensions touche une autre géométrie. |
| [<Variable Polygone2D>.Union](1410090587.md) | Renvoie la géométrie correspondant à l'union entre un polygone en 2 dimensions et une autre géométrie. |
| [<Variable PolygoneGéo>.Aire](1410090518.md) | Calcule l'aire d'un polygone en coordonnées géographiques. |
| [<Variable PolygoneGéo>.Chevauche](1410090520.md) | Permet de savoir si un polygone en coordonnées géographiques chevauche une autre géométrie. |
