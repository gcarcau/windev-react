# iListeImprimante (Fonction)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Renvoie la liste des imprimantes installées sur le poste en cours.
> _(WEBDEV - Code Serveur)_ La liste des imprimantes correspond aux imprimantes locales installées sur le serveur Web (et non sur le poste de l'internaute). Les imprimantes réseau ne sont pas listées.

## Exemple

```wlangage
sListeImprimante est une chaîne
sListeImprimante = iListeImprimante()
```

## Syntaxe

```wlangage
<Résultat> = iListeImprimante()
```

`<Résultat>` *Chaîne de caractères*
> Liste des imprimantes sous la forme :
>
>
> ```wlangage
> <Imprimante 1> + RC + ... + <Imprimante N>
> ```
>
>
>
> Où <Imprimante1> ... <Imprimante N> correspondent au nom des imprimantes.

## Remarques

Pour afficher la liste des imprimantes dans un champ Liste ou un champ Combo, utilisez la syntaxe :
```wlangage
ListeAjoute(<Nom Champ Liste ou Combo>, <Résultat>)
```
