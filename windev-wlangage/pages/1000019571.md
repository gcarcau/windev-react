# Déployer un plan d'action

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Une fois créés, les plans d'action doivent être déployés pour être exécutés.

## Comment le faire ?

### Déployer un plan d'action depuis WINDEV, WEBDEV ou WINDEV Mobile
Pour déployer un plan d'action :

1. Ouvrez le projet contenant le plan d'action à déployer.
2. Cliquez sur l'icône de génération des plans d'action parmi les boutons d'accès rapide :
3. Enregistrez le plan d'action si nécessaire.
4. L'assistant de génération et de déploiement des plans d'action se lance.
5. Dans l'assistant, indiquez les informations générales sur la bibliothèque contenant les plans d'action :
  - le nom de la bibliothèque des plans d'action. Ce nom correspond par défaut au nom du projet.
  - la société.
  - la description.
  - la version. Cette version peut être incrémentée automatiquement à chaque génération.
  - le copyright.
6. Sélectionnez les plans d'action publics, accessibles dans l'administrateur de la fabrique logicielle.
7. Indiquez l'option de déploiement voulue. Il est possible de déployer la bibliothèque des plans d'action immédiatement ou plus tard :
  - Si le déploiement est effectué immédiatement, indiquez le nom du poste correspondant au coordinateur de la fabrique logicielle.
  - Si le déploiement est effectué plus tard, le déploiement sera effectué depuis l'administrateur de la fabrique logicielle.
8. Validez l'assistant.
9. Il est possible de réaliser une sauvegarde du projet en cours.
10. Si vous avez choisi de déployer immédiatement, le coordinateur s'affiche et indique le résultat du déploiement.

### Déployer un plan d'action à partir de l'administrateur de la fabrique logicielle
Pour déployer un plan d'action à partir de l'administrateur de la fabrique logicielle :

1. Générez la bibliothèque du plan d'action sur le poste de développement, en demandant à effectuer le déploiement plus tard.
2. Lancez l'administrateur de la fabrique logicielle : sous le volet "Outils", dans le groupe "Utilitaires", cliquez sur "WDFAdmin".
3. Dans la fenêtre qui s'affiche, indiquez le nom du coordinateur auquel l'administrateur doit se connecter.
4. L'administrateur de la fabrique logicielle se lance.
5. Dans l'onglet "Entrepôt" :
  - Cliquez sur le bouton "Ajouter une bibliothèque".
  - Sélectionnez le fichier "wdfab" correspondant à la bibliothèque du plan d'action à déployer. Ce fichier a été généré dans le répertoire Exe du projet lié au plan d'action.
6. La bibliothèque contenant le plan d'action est déployée. Il apparaît dans l'entrepôt.
