# Fonctions de manipulation de l'UI par l'utilisateur final

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU))

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de manipulation de l'UI par l'utilisateur final (syntaxe préfixée)](1000022336.md)).
Les différentes fonctions permettant de gérer la manipulation de l'UI par l'utilisateur final sont les suivantes :

| [FenEdActive](1000021843.md) | Permet :   - de savoir si le mode "Modification de l'UI par l'utilisateur final" est activé dans une fenêtre (ou une fenêtre interne). - d'activer ou non le mode "Modification de l'UI par l'utilisateur final" dans une fenêtre (ou une fenêtre interne). |
| --- | --- |
| [FenEdCharge](1000021849.md) | Charge les modifications faites par l'utilisateur final dans une fenêtre. |
| [FenEdCréeNote](1000022270.md) | Crée un champ Note repositionnable. |
| [FenEdDéclareUndo](1000021898.md) | Déclare comment annuler une action ajoutée avec la fonction [FenEdDo](1000021897.md). |
| [FenEdDésélectionneTout](1000021873.md) | Désélectionne tous les champs lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [FenEdDo](1000021897.md) | Exécute une action (définie par programmation) avec support du Undo/Redo. |
| [FenEdRedo](1000021905.md) | Exécute la dernière action annulée lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [FenEdRestaure](1000021869.md) | Annule toutes les modifications effectuées par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [FenEdSauve](1000021848.md) | Sauve les modifications réalisées en mode "Modification de l'UI par l'utilisateur final". |
| [FenEdSauveNote](1000022120.md) | Exporte les notes repositionnables créées par l'utilisateur dans un fichier. |
| [FenEdSelect](1000021871.md) | Renvoie l'un des champs sélectionnés lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [FenEdSelectMoins](1000021874.md) | Dé-sélectionne un champ lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [FenEdSelectOccurrence](1000021870.md) | Indique le nombre de champs sélectionnés lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [FenEdSelectPlus](1000021872.md) | Sélectionne un champ lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [FenEdUndo](1000021904.md) | Annule la dernière action effectuée lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
