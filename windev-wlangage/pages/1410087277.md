# LuhnVérifie (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Vérifie que la suite donnée respecte bien la formule de Luhn.
Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.

## Exemple

```wlangage
sNuméroSiret est une chaîne = SAI_SaisieSIRET
SI LuhnVérifie(sNuméroSiret) ALORS
	Info("Numéro valide")
SINON
	Info("Numéro invalide")
FIN
```

## Syntaxe

```wlangage
<Résultat> = LuhnVérifie(<Identifiant>)
```

`<Résultat>` *Booléen*
> - Vrai si la suite respecte la formule de Luhn,
> - Faux dans le cas contraire.
`<Identifiant>` *Chaîne de caractères*
> Suite impérativement composée uniquement de chiffres et d'espaces (les espaces ne sont pas déterminants pour la formule).

**Classification Métier / UI : Code neutre**

**Composante : wd300std.dll**
