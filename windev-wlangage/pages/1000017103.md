# ServiceInfo (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Renvoie des informations concernant la configuration d'un service. La configuration du service est affectée à la [variable Service](1000017118.md).
Ce service peut être un service présent sur le poste local ou sur un poste distant.

## Exemple

```wlangage
// Obtenir les caractéristiques du service présent dans la table TABLE_Service
SI ServiceInfo(COL_Nom[TABLE_Service]) = Faux ALORS
	Erreur(ErreurInfo(errMessage))
SINON
	Info("Variable Service mise à jour")
FIN
```

## Syntaxe

```wlangage
<Résultat> = ServiceInfo(<Nom du service> [, <Poste distant>])
```

`<Résultat>` *Booléen*
> - Vrai si les informations ont été demandées,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md). La variable Service est alors remplie avec les informations concernant la configuration du service.
`<Nom du service>` *Chaîne de caractères*
> Nom du service à manipuler.
`<Poste distant>` *Chaîne de caractères optionnelle*
> Adresse IP du poste distant au format xxx.xxx.xxx.xxx (obtenu par la fonction [NetAdresseIP](3056023.md)) ou nom du poste distant (obtenu par la fonction [NetNomMachine](3056014.md)). Ce paramètre permet d'obtenir des informations sur un service sur un autre poste. Pour utiliser cette option, l'utilisateur doit être administrateur de la machine distante.
> Si ce paramètre n'est pas précisé ou correspond à une chaîne vide (""), le service est manipulé en local.

## Remarques

### Variable Service
La variable Service permet de connaître les éléments suivants. Pour plus de détails, consultez la page d'aide concernant la [variable Service](1000017118.md).

| Service.Démarrage | Mode de démarrage du service |
| --- | --- |
| Service.Description | Description du service |
| Service.ErreurDémarrage | Traitement par Windows des erreurs lors du démarrage d'un service (cas des services avec démarrage automatique). |
| Service.LigneCommande | Ligne de commande complète du service (chemin de l'exécutable et paramètres). |
| Service.Type | Type du service |
| Service.Utilisateur | Compte utilisateur qui exécutera le service. |

**Composante : wd300std.dll**
