# <Variable Connexion>.ListeFichiersSurveillés (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Renvoie la liste des fichiers de données surveillés par la fonction [<Source>.Surveille](1000025029.md).
Attention :

- Cette fonction est utilisable uniquement en mode Client/Serveur.
- La liste des fichiers de données surveillés correspond à la liste au moment de l'exécution de la fonction. Si des fichiers de données ne sont plus surveillés (fonction [<Source>.SurveilleStop](1000025030.md)), ils n'apparaîtront pas dans la liste.

## Exemple

```wlangage
MaConnexion est une Connexion
MesFichiersSurveillés est un tableau de chaînes
MesFichiersSurveillés = MaConnexion.ListeFichiersSurveillés()
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.ListeFichiersSurveillés()
```

`<Résultat>` *Tableau WLangage*
> Tableau de chaînes contenant les différents fichiers de données surveillés.
`<Connexion>` *Variable de type Connexion*
> Nom d'une variable de type [Connexion](1514073.md) correspondant à la connexion manipulée.
