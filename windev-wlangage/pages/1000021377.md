# AvecBoutonNouveau (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

La propriété **AvecBoutonNouveau** permet de :

- Savoir si un champ Onglet dynamique propose une croix d'ajout.
- Configurer un champ Onglet dynamique pour proposer ou non une croix d'ajout.

Rappel : La croix d'ajout permet à l'utilisateur final d'ouvrir un nouvel onglet.

## Exemple

```wlangage
ONG_OngletDyn.AvecBoutonNouveau = Vrai
ONG_OngletDyn.FenêtreSiNouveau = "FI_Document"
ONG_OngletDyn.LibelléSiNouveau = "Nouvel onglet"
```

## Syntaxe

#### Savoir si un champ Onglet dynamique propose une croix d'ajout

```wlangage
<Résultat> = <Champ Onglet>.AvecBoutonNouveau
```

`<Résultat>` *Booléen*
> - Vrai si tous les volets d'un champ Onglet dynamique possèdent une croix d'ajout,
> - Faux si les volets d'un champ Onglet dynamique ne possèdent pas une croix d'ajout.
`<Champ Onglet>` *Nom de champ*
> Nom du champ Onglet à manipuler.

#### Configurer un champ Onglet dynamique pour proposer ou non une croix d'ajout

```wlangage
<Champ Onglet>.AvecBoutonNouveau = <Croix d'ajout>
```

`<Champ Onglet>` *Nom de champ*
> Nom du champ Onglet à manipuler.
`<Croix d'ajout>` *Booléen*
> - Vrai si les volets d'un champ Onglet dynamique doivent afficher une croix d'ajout,
> - Faux si les volets d'un champ Onglet dynamique ne doivent pas afficher une croix d'ajout.

## Remarques

- Si les volets possèdent une croix d'ajout, lorsque l'utilisateur clique sur cette croix, l'événement "Création d'un volet" est exécuté. Par défaut, un nouveau volet est créé. Cependant, l'événement "Création d'un volet" peut empêcher la création du volet via l'instruction "RENVOYER Faux" ou la fonction [DonneFocusEtRetourUtilisateur](1410088107.md).
- Le libellé et la fenêtre interne utilisés par défaut pour le nouveau volet peuvent être définis :
  - dans la fenêtre de description du champ Onglet (onglet "Détail").
  - par programmation grâce aux propriétés [FenêtreSiNouveau](1000021381.md) et [LibelléSiNouveau](1000021380.md).
- Si les volets ne possèdent pas de croix d'ajout, la Fonctionnalité Automatique de vos Applications (FAA) "Nouveau" présente dans le menu contextuel du volet est désactivée.
