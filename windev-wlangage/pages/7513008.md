# wWDGetTypeValeurRetour

> **Disponible :** **WINDEV** (Windows)

## Utilisation

Type de la valeur de retour de la dernière instruction [nWDExecute](7513015.md), [nWDExecuteEx](7513020.md) ou [nWDEvalue](7513017.md).

## Syntaxe

```wlangage
Void      wWDGetTypeValeurRetour(void);
```

## Notes

### Valeur renvoyée

Cette fonction renvoie une des constantes suivantes :

| **Nom** | **Valeur** |
| --- | --- |
| WDTYPE_VOID | 0 |
| WDTYPE_BOOL | 1 |
| WDTYPE_INT | 2 |
| WDTYPE_INT64 | 3 |
| WDTYPE_DOUBLE | 4 |
| WDTYPE_TSTR | 5 |
| WDTYPE_BIN | 6 |
