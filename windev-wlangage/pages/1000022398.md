# Fonctions Notes repositionnables

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU))

Les fonctions permettant de manipuler le champ Note Repositionnable par programmation sont les suivantes :

| [NoteChargeTout](1000022397.md) | Importe et affiche les notes repositionnables de la fenêtre en cours précédemment sauvées par la fonction [NoteSauveTout](1000022396.md). |
| --- | --- |
| [NoteCrée](1000022395.md) | Crée un champ Note repositionnable dans la fenêtre en cours par programmation. |
| [NoteSauveTout](1000022396.md) | Sauvegarde les notes redimensionnables de la fenêtre en cours dans un fichier. |
| [NoteSupprime](1000022893.md) | Supprime une note repositionnable présente dans la fenêtre en cours. |
