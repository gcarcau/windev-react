# ChronoPause (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Interrompt un chronomètre afin de mesurer la durée d'un traitement. Le chronométrage pourra être relancé par la fonction [ChronoReprend](1000018830.md).
Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Les variables de type Chrono sont désormais disponibles en code navigateur. La syntaxe manipulant les variables de type Chrono devient également disponible.

## Exemple

```wlangage
DuréeTraitement est une Durée
ChronoDébut()
MaFonction1()
DuréeTraitement = ChronoPause()
Info("Le traitement MaFonction1 a duré " + DuréeTraitement)
ChronoReprend()
MaFonction2()
DuréeTraitement = ChronoFin()
Info("Les traitements MaFonction1 et MaFonction2 ont duré " + DuréeTraitement)
```

> _(WEBDEV - Code Navigateur, Etats et Requêtes, Windows, Linux, Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst, Java, Code Utilisateur (MCU))_ DuréeTraitement est une Durée
MonChrono est un Chrono
ChronoDébut(MonChrono)
MaFonction1()
DuréeTraitement = ChronoPause(MonChrono)
Info("Le traitement MaFonction1 a duré " + DuréeTraitement)
ChronoReprend(MonChrono)
MaFonction2()
DuréeTraitement = ChronoFin(MonChrono)
Info("Les traitements MaFonction1 et MaFonction2 ont duré " + DuréeTraitement)

## Syntaxe

#### Interrompre le chronométrage réalisé avec un numéro de chronomètre

```wlangage
<Résultat> = ChronoPause([<Numéro du chronomètre>])
```

`<Résultat>` *Durée*
> Temps passé (en millisecondes) depuis le dernier appel à la fonction [ChronoDébut](3027031.md) pour le numéro de chronomètre spécifié.
`<Numéro du chronomètre>` *Entier optionnel*
> Identifiant du chronomètre utilisé. Si ce paramètre n'est pas précisé, sa valeur par défaut est 1.

> Cette syntaxe n'est pas disponible en PHP

Interrompre le chronométrage réalisé avec une variable de type Chrono Masquer les détails
<Résultat> = ChronoPause(<Chronomètre>)

 <Résultat> : DuréeTemps passé (en millisecondes) depuis le dernier appel à la fonction ChronoDébut pour le chronomètre spécifié. <Chronomètre> : Variable de type ChronoNom de la variable de type Chrono correspondant au chronomètre à utiliser.

## Remarques

### Divers
Si la fonction **ChronoPause** est utilisée sur un chronomètre déjà interrompu, cette fonction n'a aucun effet.

### Erreur
Si la fonction [ChronoDébut](3027031.md) n'a pas été appelée avant la fonction **ChronoPause**, une erreur WLangage est affichée.

### Threads
Les fonctions de chronométrage (Chronoxxx) concernant un même chronomètre doivent être utilisées dans un même thread.
