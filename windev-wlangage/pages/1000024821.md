# Procédure WLangage appelée par la fonction SocketConnecte

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur)

Procédure WLangage écrite en code navigateur (également nommée "callback") appelée par la fonction [SocketConnecte](3070016.md). Cette procédure est appelée une fois que la connexion au serveur a été effectuée. Cette procédure permet d'envoyer un message au serveur à l'aide de la fonction [SocketEcrit](3070002.md).

## Exemple

```wlangage
SocketConnecte("client", "ws[s]://<AdresseDuServeurDeWebSocket>", SurEvenementSocket)

PROCÉDURE INTERNE SurEvenementSocket(nEvenement, sMessage)

	SELON nEvenement

		CAS SocketOuverture
			SocketEcrit("client", "Envoi message depuis le navigateur.")

		CAS SocketMessage
			Info("Réception d'un message serveur : " + sMessage)

		CAS SocketFermeture
			Info("Fermeture du socket", sMessage)

		CAS SocketErreur
			Erreur("Erreur du socket")
	FIN
FIN
```

## Syntaxe

```wlangage
SocketConnecte_Callback(<Evénement> , <Message>)
```

`<Evénement>` *Constante de type Entier*
> Correspond à une des constantes suivantes :
>
>
> | *SocketErreur* | Une erreur s'est produite durant la communication avec le serveur. Le paramètre <Message est toujours vide. |
> | --- | --- |
> | *SocketFermeture* | Le socket est fermé. Le paramètre <Message contient un code qui indique la raison de la fermeture. |
> | *SocketMessage* | Le socket a reçu un message. Le paramètre <Message contient les données relatives au message. |
> | *SocketOuverture* | Le socket est connecté au serveur. Il est possible d'envoyer des messages. |
`<Message>` *Chaîne de caractères*
> Message reçu en réponse du serveur en fonction de l'<Evénement>.

**Classification Métier / UI : Code neutre**

**Composante : WDJS.DLL**
