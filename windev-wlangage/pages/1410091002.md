# <Variable Palette>.Sauve (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Sauve une palette dans un fichier.

## Exemple

```wlangage
// Génération d'une palette
Palette1 est une Palette
Palette1.Génère(0x90CAF9)
// Modification d'un élément de la palette
Palette1["Logo"] = 0xA0305
// Enregistrement de la palette modifiée
Palette1.Sauve("AvecLogo.wdpalette")
```

## Syntaxe

```wlangage
<Palette>.Sauve(<Nom du fichier>)
```

`<Palette>` *Variable de type Palette*
> Nom de la variable de type [Palette](1000021347.md) à sauver dans un fichier.
`<Nom du fichier>` *Chaîne de caractères*
> Nom complet du fichier dans lequel la palette doit être sauvegardée. Par défaut, ce fichier est de type "wdpalette".

**Classification Métier / UI : Code UI**

**Composante : wd300pnt.dll**
