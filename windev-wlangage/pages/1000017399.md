# AnimationActive (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Active ou désactive les animations dans les champs.
**Remarque** : Seules les animations de champs sont concernées : animations automatiques (configurées dans le projet ou dans la fenêtre) ou animations programmées (avec les fonctions [AnimationPrépare](1000017386.md), [AnimationJoue](1000017387.md), ...). Les animations des champs Image et des champs Libellé ainsi que les animations de fenêtres ne sont pas concernées.

## Exemple

```wlangage
// Les animations ne seront jamais activées
AnimationActive(Faux)
```

## Syntaxe

```wlangage
<Résultat> = AnimationActive([<Mode d'activation>])
```

`<Résultat>` *Booléen*
> Correspond à l'ancien mode de gestion des animations de champs (avant l'utilisation de la fonction **AnimationActive**) :
>
> - Vrai si la gestion des animations était active,
> - Faux dans le cas contraire.
`<Mode d'activation>` *Booléen optionnel*
> Mode d'activation des animations :
>
>
> | *Faux* | Les animations ne sont jamais affichées. |
> | --- | --- |
> | *Vrai* | Les animations sont en mode automatique. L'animation est effectuée en fonction de la puissance de la machine utilisée. Si le poste ne dispose pas des API nécessaires aux animations, les animations ne seront pas affichées. |

**Composante : wd300obj.dll**
