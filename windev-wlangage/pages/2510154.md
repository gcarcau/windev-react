# Option (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Option** permet de paramétrer l'affichage d'un champ Code-barres.

## Exemple

```wlangage
// Conserver les options du champ et ne pas afficher le texte
CBA_CodeBarre1.Option = OUBinaire(CBA_CodeBarre1.Option, CB_SansTexte)
```

## Syntaxe

```wlangage
<Champ Code-barres>.Option = <Caractéristiques du champ>
```

`<Champ Code-barres>` *Nom de champ*
> Nom du champ Code-barres à manipuler.
`<Caractéristiques du champ>` *Constante (ou combinaison de constantes) de type Entier*
> Caractéristiques du champ :
>
> | *CB_Bas* | Code-barres positionné en bas du rectangle destination _(Android)_ Cette constante n'est pas disponible. |
> | --- | --- |
> | *CB_CaractèreControle* | Code-barres contenant des caractères de contrôle (valable uniquement pour les codes-barres de type *CB_CODE128*, *CB_DATAMATRIX*, *CB_EAN128*, *CB_GS1-128* et *CB_PDF417*).  Par défaut, les caractères de contrôle sont encadrés par les caractères "<" et ">". Pour ne pas interpréter ces caractères comme caractères de contrôle, il suffit de doubler le premier "<" :    - "<C40>" = caractère de contrôle - "<<AB>" = chaîne <AB à encoder dans le code-barres.   Pour plus de détails sur les caractères acceptés, consultez [Les différents types de code-barres](3046064.md). _(Android)_ Cette constante n'est pas disponible. |
> | *CB_CaractèreVérification* | Code-barres contenant des caractères de vérification (valable uniquement pour les codes-barres de type *CB_CODE128*, *CB_DATAMATRIX*, *CB_EAN128*, *CB_GS1-128* et *CB_PDF417*). Si cette option est sélectionnée, les constantes *CB_CaractèreControle* et *CB_JeuxCaractères* sont automatiquement prises en compte. _(Android)_ Cette constante n'est pas disponible. |
> | *CB_CentreH* | Centrage horizontal du code-barres dans le rectangle destination. _(Android)_ Cette constante n'est pas disponible. |
> | *CB_CentreV* | Centrage vertical du code-barres dans le rectangle destination. _(Android)_ Cette constante n'est pas disponible. |
> | *CB_Droite* | Code-barres aligné à droite dans le rectangle destination. _(Android)_ Cette constante n'est pas disponible. |
> | *CB_Etendu* | Code-barres étendu (valable uniquement pour les code-barres de type *CB_CODE39* et *CB_CODE93*). _(Android)_ Cette constante n'est pas disponible. |
> | *CB_FormateTexte* | Formate le texte affiché pour les codes-barres de type *EAN 128* ou *GS1-128* : des parenthèses sont ajoutées autour des AIs dans le texte imprimé. _(Android)_ Cette constante n'est pas disponible. |
> | *CB_Gauche* | Code-barres aligné à gauche dans le rectangle destination. _(Android)_ Cette constante n'est pas disponible. |
> | *CB_Haut* | Code-barres positionné en haut du rectangle destination. _(Android)_ Cette constante n'est pas disponible. |
> | *CB_IgnoreFormatage* | Ignore les parenthèses d'un code 128, EAN-128 ou GS1-128 (valable uniquement pour les codes-barres de type *CB_CODE128*, *CB_EAN128* et *CB_GS1_128*). Les parenthèses sont utilisées pour rendre le code-barres plus lisible par un humain mais ne sont pas dessinées dans le code. _(Android)_ Cette constante n'est pas disponible. |
> | *CB_JeuxCaractères* | Code-barres utilisant un ou plusieurs jeux de caractères utilisés pour la compression du code-barres. Ce jeu de caractères doit être défini dans la valeur du code-barres.  Pour plus de détails sur les jeux de caractères, consultez [Les différents types de code-barres](3046064.md). _(Android)_ Cette constante n'est pas disponible. |
> | *CB_NonProportionnel* | Ajuste le code-barres à la taille du rectangle destination. _(Android)_ Cette constante n'est pas disponible. |
> | *CB_SansTexte* | N'affiche pas le texte sous le code-barres (valable uniquement pour les codes-barres de type *CB_UPCA*, *CB_UPCB*, *CB_EAN13* et *CB_EAN8*). _(Android)_ Cette constante n'est pas disponible. |
> | *CB_Texte* | Affiche le texte sous le code-barres.  Le texte est normalisé pour les codes-barres de type *CB_UPCA*, *CB_UPCE*, *CB_EAN13* et *CB_EAN8*.   Pour les autres types de codes-barres, le texte peut dépasser du cadre d'affichage du code-barres. _(Android)_ Cette constante n'est pas disponible. |
> | *CB_TexteCentre* | Centre le texte sous le code-barres.  Cette constante est disponible pour les codes-barres de type *CB_CODE128*, *CB_CODE93*, *CB_CODE11*, *CB_EAN128*, *CB_CODE39*, *CB_INTER2OF5*, *CB_CODABAR*, *CB_MSI*. _(Android)_ Cette constante n'est pas disponible. |
> | *CB_TexteDroite* | Justifie le texte sous le code-barres à droite.  Cette constante est disponible pour les codes-barres de type *CB_CODE128*, *CB_CODE93*, *CB_CODE11*, *CB_EAN128*, *CB_CODE39*, *CB_INTER2OF5*, *CB_CODABAR*, *CB_MSI*. _(Android)_ Cette constante n'est pas disponible. |
> | *CB_TexteGauche* | Justifie le texte sous le code-barres à gauche.  Cette constante est disponible pour les codes-barres de type *CB_CODE128*, *CB_CODE93*, *CB_CODE11*, *CB_EAN128*, *CB_CODE39*, *CB_INTER2OF5*, *CB_CODABAR*, *CB_MSI*. _(Android)_ Cette constante n'est pas disponible. |
> | *CB_Vérification* | Code-barres avec caractères de vérification (valable uniquement pour les codes-barres de type *CB_CODE39*, *CB_CODE93*, *CB_INTER2OF5* et *CB_CODABAR*). _(Android)_ Cette constante n'est pas disponible. |
> | *CB_Vertical* | Affiche le code-barres verticalement. _(Android)_ Cette constante n'est pas disponible. |
> | *CB_90* | Affiche le code-barres verticalement. |
> | *CB_180* | Affiche le code-barres en faisant une rotation à 180 degrés. |
> | *CB_270* | Affiche le code-barres en faisant une rotation à 270 degrés. |
