# CapteurTermine (Fonction)

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Indique la fin de l'utilisation des fonctions capteurs. Toutes les détections en cours sont arrêtées :

- détection des secousses lancée par les fonctions [CapteurDétecteDébutSecousses](1000019363.md) et/ou [CapteurDétecteFinSecousses](1000019364.md),
- détection des changements d'accélération lancée par la fonction [CapteurDétecteChangementAccélération](1000019362.md),
- détection des changements d'orientation lancée par la fonction [CapteurDétecteChangementOrientation](1000019361.md).

## Exemple

```wlangage
CapteurTermine()
```

## Syntaxe

```wlangage
CapteurTermine()
```
