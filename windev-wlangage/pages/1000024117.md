# <Graphe>.PoliceEtiquette (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Modifie la police utilisée pour les étiquettes de catégorie d'un graphe. [image: Etiquette de catégorie]
> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
// Modification de la police des étiquettes des axes du champ Graphe : GRF_Graphe

// Création d'une police spécifique
polEtiquettes est une Police
polEtiquettes.Nom = "Verdana"
polEtiquettes.Taille = 10
polEtiquettes.Gras = Vrai

// Changement de police
GRF_Graphe.PoliceEtiquette(polEtiquettes)
GRF_Graphe.Dessine()
```

## Syntaxe

#### Définition de la police utilisée pour les étiquettes d'un graphe

```wlangage
<Champ Graphe>.PoliceEtiquette(<Police utilisée>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe présent dans l'éditeur d'états.
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Police utilisée>` *Police*
> Police à utiliser. Ce paramètre correspond à une variable de type [Police](1514045.md). Les caractéristiques de la police ont été définies grâce à la fonction [PoliceCrée](3060002.md) ou grâce aux [propriétés de gestion des polices](2515045.md).

#### Définition de la police utilisée pour les étiquettes d'un graphe (syntaxe conservée par compatibilité)

```wlangage
<Champ Graphe>.PoliceEtiquette(<Identifiant de la police>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe présent dans l'éditeur d'états.
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Identifiant de la police>` *Entier*
> Identifiant de la police, défini avec la fonction [grCréePolice](3042001.md). Si cette police n'existe pas, une erreur du WLangage est générée.

## Remarques

### Manipulation des étiquettes de catégories
Les étiquettes de catégories sont affichées :

- sous les graduations horizontales pour les graphes de type courbe ou les graphes boursiers de type chandelier japonais et BarCharts,
- sous l'axe des X pour les histogrammes ou les graphes de type boursier Minimum/Maximum.

[image: Etiquette de catégorie]Les étiquettes de catégories ne sont pas utilisables avec les graphes de type nuage de points.
La définition des étiquettes de catégories est réalisée avec la fonction [<Graphe>.EtiquetteCatégorie](1000024072.md).

Il est possible de modifier la police de l'étiquette grâce à la fonction **<Graphe>.PoliceEtiquette**.

Les étiquettes de catégories définies avec la fonction [<Graphe>.EtiquetteCatégorie](1000024072.md) peuvent être affichées dans le libellé du graphe de type Secteur (constante *grAfficheEtiquette* utilisée avec la fonction [<Graphe>.Libellé](1000024165.md)).

### Initialisation des polices
La police utilisée par défaut pour les étiquettes a les caractéristiques suivantes :

- Nom de la police : Arial
- Taille : 14
- Style : Normal
- Couleur : Noir

### Orientation de la police
Dans le cas des étiquettes d'un graphe, la propriété "orientation" de la police est ignorée.
Pour changer l'orientation de la police des étiquettes, il faut modifier directement la description du champ Graphe dans la fenêtre à 7 onglets.

Par défaut, l'orientation est choisie de manière automatique. Cette orientation tient compte de la taille et du nombre d'étiquettes à afficher.
