# sfRequêteFusionne (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Le type **sfRequêteFusionne** permet de décrire les éléments à fusionner lors de l'appel de la fonction [SFFusionne](1000018509.md). Les caractéristiques des éléments à fusionner peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Propriétés

### Propriétés spécifiques à la description des variables de type sfRequêteFusionne
Les propriétés suivantes peuvent être utilisées pour manipuler un élément à fusionner :

| Nom | Type manipulé | Effet |
| --- | --- | --- |
| EnregistrementMaître | [sfObjet](1000018439.md) | Enregistrement dans lequel vont être fusionnées les données. |
| IDEnregistrementAFusionner | Chaîne de caractères | Liste des identifiants Salesforce des enregistrements dont les données vont être fusionnées dans l'enregistrement maître. Les différents identifiants sont séparés par des RC (Retour-chariot). |

## Remarques

### Fonctions manipulant le type sfRequêteFusionne

| [SFFusionne](1000018509.md) | Fusionne des enregistrements Salesforce (appelés également objets Salesforce). |
| --- | --- |
