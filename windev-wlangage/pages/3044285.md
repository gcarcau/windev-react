# HInfoUtilisateur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Met à jour [les variables de gestion des utilisateurs](3044315.md) avec les informations concernant l'utilisateur spécifié. Pour des raisons de sécurité, le mot de passe de l'utilisateur n'est pas récupéré.

## Exemple

```wlangage
// Description de la connexion
HDécritConnexion("MaConnexion", "Julie", "MotDePasse", "MonServeurHF", "MaBaseDeDonnées", ...
	hAccèsHFClientServeur, hOLecture)
// Ouverture de la connexion
HOuvreConnexion("MaConnexion")
// Association du fichier de données à la connexion
HChangeConnexion(Client, "MaConnexion")
SI HInfoUtilisateur("MaConnexion", "Florence") = Vrai ALORS
	Info("Voici les caractéristiques de l'utilisateur" + RC + ...
		"Login : " + HUtilisateur.Login + ...
		"Nom Complet : " + HUtilisateur.NomComplet + ...
		"Email : " + HUtilisateur.Email)
FIN
```

## Syntaxe

```wlangage
<Résultat> = HInfoUtilisateur(<Connexion> , <Utilisateur>)
```

`<Résultat>` *Booléen*
> - Vrai si la structure de gestion des utilisateurs a été mise à jour,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
>
>
> Remarque : Une erreur "Utilisateur inconnu" sera renvoyée par la fonction [HErreurInfo](3044071.md) si l'utilisateur en cours n'a pas le droit de visualisation des utilisateurs (constante *hDroitVisualisationUtilisateur*). Ce droit peut être défini par la fonction [HModifieDroitServeur](3044328.md).
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion pour laquelle les renseignements concernant l'utilisateur doivent être récupérés. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Utilisateur>` *Chaîne de caractères*
> Nom de l'utilisateur pour lequel les informations doivent être récupérées. Ce nom doit correspondre à la variable **HUtilisateur.Login** de l'un des utilisateurs de la connexion spécifiée.

**Composante : wd300hf.dll**
