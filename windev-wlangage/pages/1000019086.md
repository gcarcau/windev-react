# <Variable zipArchive>.Ferme (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Ferme une archive.
Nouveauté 2025

> _(WINDEV, WEBDEV - Code Serveur, Windows, Linux, iPhone/iPad)_ Le format gzip (extension .gz) est désormais géré.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Code Utilisateur (MCU), Ajax)_ MonArchive est une zipArchive
// Ouverture d'une archive
ResOuvreArchive = MonArchive.Ouvre("C:\Archives\Archive.zip")

SI ResOuvreArchive = 0 ALORS
 // Traitements
 ...
 // Fermeture de l'archive
 MonArchive.Ferme()
FIN

## Syntaxe

```wlangage
<Archive>.Ferme()
```

`<Archive>` *Variable de type zipArchive*
> Nom d'une variable de type [zipArchive](1000018679.md) correspondant à l'archive à manipuler.

## Remarques

### Conditions d'utilisation

- La fermeture d'une archive ne peut être réalisée que si :
  - L'archive est ouverte. L'ouverture d'une archive s'effectue avec la fonction [<Variable zipArchive>.Ouvre](1000019097.md).
  - L'archive existe. La création d'une archive s'effectue avec la fonction [<Variable zipArchive>.Crée](1000019160.md).
- A l'arrêt de l'application, toutes les archives manipulées seront automatiquement fermées.
- Une erreur du WLangage est affichée si l'archive à fermer n'existe pas. Le programme est alors arrêté.

Rappel :

- Seules les archives au format ZIP, gzip, TAR et TGZ (TAR.GZ) sont disponibles.
- Seules les archives au format ZIP sont disponibles.

**Composante : wd300zip.dll**
