# CodeWLangageDonneDéclarationsCSS (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Renvoie la feuille de style CSS correspondant à un thème du code WLangage.

## Exemple

```wlangage
MiseEnFormeCode est un CodeWLangageMiseEnForme
MiseEnFormeCode.Format = codeWLangageFormatHTML
MiseEnFormeCode.Langue = langueAnglais
MiseEnFormeCode.InclureDéclarationsCSS = Faux

HTM_SansNom1 = "
<style>[%CodeWLangageDonneDéclarationsCSS(codeWLangageThèmeSombre)%]</style>
[%UTF8VersChaîne(CodeWLangageMetEnForme(MiseEnFormeCode, "s est une chaîne"))%]
"
```

## Syntaxe

```wlangage
<Résultat> = CodeWLangageDonneDéclarationsCSS(<Thème>)
```

`<Résultat>` *Chaîne de caractères*
> Code de la feuille de style CSS utilisée pour la coloration du code selon le thème spécifié.
`<Thème>` *Constante de type Entier*
> Thème utilisé pour la coloration :
>
> | *codeWLangageThèmeClair* | Utilisation du thème clair. |
> | --- | --- |
> | *codeWLangageThèmeGris* | Utilisation du thème gris. |
> | *codeWLangageThèmeSombre* | Utilisation du thème sombre. |

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
