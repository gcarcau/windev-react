# Comment ajouter une nouvelle ligne dans un champ Table ?

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

Un champ Table géré par programmation peut être soit :

- en affichage
- en saisie

Si le champ Table est en saisie, il est souvent nécessaire de gérer l'ajout d'une nouvelle ligne dans le champ Table. Pour cela, il faut utiliser les fonctions [TableAjouteLigne](3074006.md) et [DonneFocusEtRetourUtilisateur](1410088107.md).

## Principe

Pour gérer par programmation l'ajout d'une nouvelle ligne dans un champ Table :

1. Créez un bouton dans la fenêtre contenant le champ Table. Ce bouton va gérer l'ajout de la ligne dans le champ Table.
2. Dans le code de clic de ce bouton :
  - utilisez la fonction [TableAjouteLigne](3074006.md) pour ajouter une nouvelle ligne.
  - récupérez et mémorisez dans une variable le numéro de la ligne ajoutée (retournée par la fonction [TableAjouteLigne](3074006.md)).
  - positionnez-vous sur la nouvelle ligne ajoutée.
  - donnez le focus à la colonne dans laquelle la saisie doit être effectuée grâce à la fonction [DonneFocusEtRetourUtilisateur](1410088107.md).

**Note** : Si vous utilisez la fonction [TableAjoute](3074017.md) pour ajouter une nouvelle ligne dans le champ Table, il est nécessaire d'utiliser la fonction [TableOccurrence](3074021.md) pour récupérer le numéro de la nouvelle ligne ajoutée.

### Exemple de code

```wlangage
nNumLigne est un entier

// Ajout d'une ligne
nNumLigne = TableAjouteLigne(TABLE_LigneCde)
// La ligne ajoutée devient la ligne en cours
TABLE_LigneCde = nNumLigne
// Sélection de la colonne où la saisie doit être effectuée
DonneFocusEtRetourUtilisateur(TABLE_LigneCde.COL_RefProduit)
```
