# grLissage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Lisse un graphe de type Courbe ou Nuage de points par la méthode des "splines cubiques".
**Rappel** : Par défaut, un graphe est non lissé.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
// Lisse le graphe GRF_MonGraphe
grLissage(GRF_MonGraphe, Vrai)
```

## Syntaxe

#### Lisser un graphe

```wlangage
grLissage(<Nom du graphe> , <Lissage>)
```

`<Nom du graphe>` *Nom de champ ou chaîne de caractères*
> Nom du graphe à manipuler. Ce nom correspond :
>
> - soit au nom du graphe défini par programmation avec la fonction [grCrée](3042005.md).
> - soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.
>
>
> > _(Android)_ Seuls les champs Graphe sont disponibles.
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Lissage>` *Booléen*
> - Vrai si le lissage doit être activé,
> - Faux dans le cas contraire.

#### Lisser une série d'un graphe

```wlangage
grLissage(<Nom du graphe> , <Numéro de la série> , <Lissage>)
```

`<Nom du graphe>` *Nom de champ ou chaîne de caractères*
> Nom du graphe à manipuler. Ce nom correspond :
>
> - soit au nom du graphe défini par programmation avec la fonction [grCrée](3042005.md).
> - soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.
>
>
> > _(Android)_ Seuls les champs Graphe sont disponibles.
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Numéro de la série>` *Entier*
> Numéro de la série à lisser.
`<Lissage>` *Booléen*
> - Vrai si le lissage doit être activé,
> - Faux dans le cas contraire.

## Remarques

Le lissage est pris en compte :

- dans les graphes de type courbe (constante *grCourbe*),
- dans les graphes de type nuage de points (constante *grNuage*) dont les points sont reliés (fonction [grNuageReliePoint](3042040.md)).

**Attention** : Cette fonction n'a aucun effet sur un graphe 3D.

Les paramètres définis avec la fonction **grLissage** seront pris en compte lors du prochain appel à la fonction [grDessine](3042026.md).
