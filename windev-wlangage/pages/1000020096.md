# <Multimédia>.Volume (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android)

Renvoie ou modifie le volume sonore du fichier multimédia joué dans un champ Multimédia.
> _(WEBDEV - Code Navigateur)_ Remarque : Selon le type de vidéo et la configuration du navigateur, cette fonction peut ne pas être supportée. Dans ce cas son utilisation sera sans effet mais ne provoquera pas d'erreur.

## Exemple

> _(WINDEV, Etats et Requêtes, Code Utilisateur (MCU))_ MonFichier est une chaîne = "C:\Ma musique\mysong.mp3"
MM_Multimédia1.Joue(MonFichier)
// Fixe le son
MM_Multimédia1.Volume(50)

## Syntaxe

#### Connaître le volume sonore

```wlangage
<Résultat> = <Champ Multimédia>.Volume()
```

`<Résultat>` *Entier*
> Volume sonore actuel (compris entre 0 et 100, 0 pour muet).
`<Champ Multimédia>` *Nom de champ*
> Nom du champ Multimédia à manipuler.

#### Modifier le volume sonore

```wlangage
<Résultat> = <Champ Multimédia>.Volume(<Nouveau volume>)
```

`<Résultat>` *Entier*
> Volume sonore avant modification (compris entre 0 et 100, 0 pour muet).
`<Champ Multimédia>` *Nom de champ*
> Nom du champ Multimédia à manipuler.
`<Nouveau volume>` *Entier*
> Volume sonore souhaité (compris entre 0 et 100, 0 pour muet).

**Composante : wd300obj.dll**
