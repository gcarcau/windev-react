# TrameFond (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **TrameFond** permet de connaître et de modifier la couleur de la trame de fond d'un élément. Cette propriété est utilisable sur :

- les variables de type [docCellule](1000022927.md).
- les variables de type [docFragment](1000022482.md).
- les variables de type [docParagraphe](1000022483.md).
- les variables de type [docNiveauNumérotation](1000022799.md).
