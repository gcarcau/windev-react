# gpwDéfaut (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Renvoie la valeur correspondant à "DEFAUT" selon le framework utilisé ou la langue spécifiée.
Remarque : Le groupware et les fichiers du groupware étant multilingues, il est ainsi possible de récupérer la valeur de la constante représentant le mot "DEFAUT".

## Exemple

```wlangage
sCstDéfaut est une chaîne
sCstDéfaut = gpwDéfaut()
```

## Syntaxe

```wlangage
<Résultat> = gpwDéfaut([<Langue>])
```

`<Résultat>` *Chaîne de caractères*
> Valeur correspondant à "DEFAUT".
> Si le paramètre <Langue> n'est pas spécifié, la valeur renvoyée dépend du framework utilisé :
>
>
> - "DEFAUT" lorsque le framework est en français,
> - "DEFAULT" lorsque le framework est en anglais.
`<Langue>` *Constante optionnelle*
> Langue à utiliser pour obtenir la valeur correspondant à "DEFAUT" :
>
> | *langueAnglais* | Valeur correspondant à "DEFAUT" en anglais : "DEFAULT". |
> | --- | --- |
> | *langueEspagnol* | Valeur correspondant à "DEFAUT" en espagnol : "DEFAULT". |
> | *langueFrançais* | Valeur correspondant à "DEFAUT" en français : "DEFAUT". |

**Classification Métier / UI : Code neutre**

**Composante : wd300gpu.dll**
