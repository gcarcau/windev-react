# Fonctions MATLAB

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Les fonctions d'accès à MATLAB sont les suivantes :

| [mlChargeEspaceDeTravail](1000021358.md) | Charge l'ensemble des variables d'un fichier MATLAB dans la session. |
| --- | --- |
| [mlEcritVariable](1000021355.md) | Ecrit la valeur d'une variable de la session MATLAB. |
| [mlExécute](1000021353.md) | Evalue et exécute une commande sur une session MATLAB. |
| [mlInitialise](1000021351.md) | Initialise une nouvelle session MATLAB indépendante avec un espace de travail vide pour exécuter des fonctions. |
| [mlListeVariable](1000021357.md) | Liste les variables présentes dans la session MATLAB. |
| [mlRAZEspaceDeTravail](1000021360.md) | Supprime l'ensemble des variables de la session MATLAB. |
| [mlRécupèreVariable](1000021354.md) | Récupère une valeur d'une variable de la session MATLAB. |
| [mlSauveEspaceDeTravail](1000021359.md) | Sauve l'espace de travail de la session dans un fichier MATLAB. |
| [mlSupprimeVariable](1000021356.md) | Supprime une variable de la session MATLAB. |
| [mlTermine](1000021352.md) | Termine une session MATLAB. Cette session a été initialisée avec la fonction [mlInitialise](1000021351.md). |

> _(WEBDEV - Code Serveur)_ Attention : MatLab doit être installé sur le serveur Web et doit être configuré pour que les utilisateurs Internet aient le droit d'y accéder.
