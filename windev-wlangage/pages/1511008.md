# Désignation de l'élément en cours (Mot réservé)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

Les mots-clés permettant de désigner l'élément en cours sont :

| [MaFenêtre](1511004.md) | Permet de manipuler la fenêtre courante. |
| --- | --- |
| [MaFenêtreCoulissanteDroite](1511023.md) | Permet de manipuler la fenêtre coulissante droite associée à la fenêtre courante. |
| [MaFenêtreCoulissanteGauche](1511022.md) | Permet de manipuler la fenêtre coulissante gauche associée à la fenêtre courante. |
| [MaFenêtreInterne](1511024.md) | Permet de manipuler la fenêtre interne courante. |
| [MaPage](1511017.md) | Permet de manipuler la page courante |
| [MaSource](1511001.md) | Permet de manipuler la source de données courante |
| [MoiMême](1511007.md) | Permet de manipuler le champ courant |
| [MonChampPopup](1511005.md) | Permet de manipuler le champ qui a ouvert une fenêtre de type popup |
| [MonEtat](1511010.md) | Permet de manipuler l'état courant |
| [MonFichier](1511019.md) | Permet de manipuler le fichier qui a déclenché le trigger à partir du code du trigger. |
| [MonParent](1511016.md) | Permet de manipuler le superchamp en cours à partir d'un de ses champs |
| [Objet](6010002.md) / [This](6010002.md) | Permet de manipuler la classe en cours. |
| MonThread | Permet de manipuler l'objet Thread qui exécute le code courant. |
