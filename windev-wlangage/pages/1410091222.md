# <Connexion HFSQL>.VérifieMémoAsynchrone (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Vérifie l'intégrité structurelle des mémos d'un fichier de données HFSQL Client/Serveur.
Nouveauté Abonnement
Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
CnxBaseDeDonnées est une Connexion
TableauFichier est un tableau de hParamètreFichier

MonFichierParam est un hParamètreFichier
MonFichierParam.Nom = "ActionPossible"
// MonFichierParam.MotDePasse = ""
// La propriété Option n'est pas prise en compte
TableauFichier.Ajoute(MonFichierParam)

CnxBaseDeDonnées.VérifieMémoAsynchrone(TableauFichier, CB_HVérifieMémoAsynchrone)
	PROCÉDURE INTERNE CB_HVérifieMémoAsynchrone(MonFichier est une chaîne, MonRésultat est une chaîne)
		SI MonRésultat = "" ALORS
			Trace("Fichier traité et vérifié " + MonFichier)
		SINON
			Trace("Fichier traité avec problème " + MonFichier)
		FIN
	FIN
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.VérifieMémoAsynchrone(<Fichiers de données à vérifier> [, <Procédure WLangage>])
```

`<Résultat>` *Booléen*
> - Vrai si la vérification a été lancée,
> - Faux dans le cas contraire.
`<Connexion>` *Variable de type Connexion*
> Connexion vers le serveur contenant les fichiers de données à manipuler. Cette connexion correspond au nom d'une variable de type [Connexion](1514073.md).
`<Fichiers de données à vérifier>` *Tableau de variables de type hParamètreFichier*
> Nom du tableau de variables de type [hParamètreFichier](1000018900.md) correspondant à la liste des fichiers de données à traiter.
`<Procédure WLangage>` *Nom de procédure optionnel*
> Nom de la procédure WLangage (également nommée "callback") appelée pour chaque fichier de données traité. Cette procédure permet de manipuler le fichier de données en cours.
> Pour plus de détails sur cette procédure, consultez [Paramètres de la procédure utilisée par la fonction <Connexion HFSQL>.VérifieMémoAsynchrone](1410091106.md).

## Remarques

- La vérification de la liste des blocs libres est effectuée uniquement en HFSQL Client/Serveur.
- La fonction **<Connexion HFSQL>.VérifieMémoAsynchrone** est plus rapide que la fonction [<Connexion HFSQL>.RéindexeAsynchrone](1410091221.md) utilisée avec la constante *hVérifieMémo*.
- Si un problème est détecté, il est possible d'utiliser la fonction [<Connexion HFSQL>.RéindexeAsynchrone](1410091221.md) avec la constante *hVérifieMémo*.
