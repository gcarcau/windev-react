# Fonctions J2EE

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Les fonctions J2EE sont les suivantes :

| [J2EEAjouteEntête](3047001.md) | Ajoute un entête à la prochaine procédure à exécuter sur le serveur. |
| --- | --- |
| [J2EEDonneRésultat](3047003.md) | Renvoie le résultat de la dernière procédure J2EE exécutée avec succès. |
| [J2EEErreur](3047010.md) | Renvoie l'erreur de la dernière procédure J2EE ayant échoué. |
| [J2EEExécute](3047007.md) | Exécute une procédure sur un serveur de services Web XML J2EE. |
| [J2EEExécuteXML](3047008.md) | Exécute une procédure sur un serveur de services Web XML J2EE. |
