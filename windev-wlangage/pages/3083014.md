# ZoneRépétéeOccurrence (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Renvoie le nombre de répétitions d'un champ Zone répétée.

## Exemple

```wlangage
// Nombre de répétitions dans le champ Zone répétée "ZR_Zone1" ?
Résultat1 est un entier
Résultat1 = ZoneRépétéeOccurrence(ZR_Zone1)
```

```wlangage
// Affiche le nombre de réponses trouvées : (ex : "Il y a 31 réponses")
LIB_LIBELLE1 = "Il y a " + ZoneRépétéeOccurrence(ZR_ZoneResultat) + " réponses"
```

## Syntaxe

```wlangage
<Résultat> = ZoneRépétéeOccurrence(<Champ Zone répétée> [, <Répétition/Attribut>])
```

`<Résultat>` *Entier*
> - Nombre de répétitions du champ Zone répétée,
> - 0 si le champ Zone répétée est vide.
`<Champ Zone répétée>` *Nom de champ*
> Nom du champ Zone répétée à manipuler.
> Si ce paramètre est égal à chaîne vide (""), le comptage sera effectué sur le champ Zone répétée en cours.
`<Répétition/Attribut>` *Constante (optionnelle)*
> | *toAffichée* _(WEBDEV - Code Serveur)_ Constante par défaut sur un champ Zone répétée fichier. | Nombre de répétitions non vides visibles. _(WEBDEV - Code Serveur, PHP)_ Cette constante ne doit pas être utilisée :pour les champs Zone répétée en mode AJAX.pour les champs Zone répétée linéaire. _(WEBDEV - Code Navigateur)_ Cette constante n'est pas disponible. |
> | --- | --- |
> | *toColonne* | Nombre d'attributs présents dans le champ Zone répétée. |
> | *toTotal* (Valeur par défaut) _(WEBDEV - Code Serveur)_ Constante par défaut sur un champ Zone répétée par programmation. | **Champ Zone répétée fichier** :  - Nombre total d'enregistrements :  - du fichier de données lié (s'il n'y a pas de filtre).  - filtrés du fichier de données lié (s'il y a un filtre).  - de la requête (si le champ Zone répétée est liée à une requête). - Nombre d'enregistrements visibles.  **Attention** : l'événement "Fin d'initialisation" est exécuté uniquement lorsque le total est calculé. **Champ Zone répétée par programmation** : Nombre total de répétitions (répétitions ajoutées par les fonctions [ZoneRépétéeAjoute](3083006.md), [ZoneRépétéeAjouteLigne](3083004.md), [ZoneRépétéeInsère](3083003.md) et [ZoneRépétéeInsèreLigne](3083002.md)). |
> | *toVisible* | Nombre de répétitions visibles (y compris les répétitions vides ou affichées partiellement). Correspond au nombre maximum de répétitions que peut afficher le champ Zone répétée. _(WEBDEV - Code Serveur, PHP)_ Cette constante ne doit pas être utilisée :pour les champs Zone répétée en mode AJAX.pour les champs Zone répétée linéaire. _(WEBDEV - Code Navigateur)_ Cette constante n'est pas disponible. |

## Remarques

### Conditions d'utilisation
La fonction **ZoneRépétéeOccurrence** peut être utilisée indifféremment sur :

- un champ Zone répétée fichier,
- un champ Zone répétée par programmation.

> _(WEBDEV - Code Navigateur)_ Cette fonction n'est pas disponible sur les champs Zone répétée linéaire. Cette fonction est disponible uniquement sur les champs Zone répétée en mode navigateur.

> _(WEBDEV - Code Serveur, PHP)_ Cette fonction est disponible pour les champs Zone répétée en mode Ajax, les champs Zone répétée en mode classique et les champs Zone répétée linéaire.

> _(PHP)_ La fonction ZoneRépétéeOccurrence peut être utilisée uniquement sur un champ Zone répétée par programmation.
