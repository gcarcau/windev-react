# XMLModifie (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Modifie le contenu de l'élément courant dans un document XML.

## Exemple

```wlangage
// Positionnement sur la racine
XMLRacine("MonDocXML")
// Remplacement des liens
XMLRecherche("MonDocXML", "Lien", XMLBalise)
TANTQUE XMLTrouve("MonDocXML") = Vrai
	// Calcul de la nouvelle valeur du lien
	Nouveau_lien = Traitement_Lien(XMLDonnée("MonDocXML"))
	// Modification dans le document XML
	XMLModifie("MonDocXML", Nouveau_lien)
	XMLSuivant("MonDocXML")
FIN
```

## Syntaxe

```wlangage
<Résultat> = XMLModifie(<Document XML> , <Nouvelle valeur de l'élément>)
```

`<Résultat>` *Booléen*
> - Vrai si la modification est effectuée,
> - Faux dans le cas contraire (la variable [ErreurDétectée](3087001.md) est alors à Vrai).
>   Pour obtenir plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Document XML>` *Chaîne de caractères*
> Document XML dans lequel la modification doit être effectuée.
`<Nouvelle valeur de l'élément>` *Chaîne de caractères*
> Nouvelle valeur de l'élément en cours :
>
> - valeur de la balise si l'élément en cours est une balise.
> - valeur de l'attribut si l'élément en cours est un attribut.

## Remarques

### Lecture de la valeur de l'élément courant
Pour lire la valeur de l'élément courant, utilisez la fonction [XMLDonnée](3081004.md).

### Enregistrer les modifications dans le fichier XML
Pour enregistrer les modifications effectuées dans un fichier XML, vous devez :

1. Utiliser la fonction [XMLConstruitChaîne](3081016.md). Cette fonction récupère et met en forme le contenu d'un document XML.
2. Enregistrer la chaîne de caractères générée par la fonction [XMLConstruitChaîne](3081016.md) dans un fichier XML. Pour cela, il suffit d'utiliser la fonction [fSauveTexte](3036046.md).

Exemple :

```wlangage
// Après modification du document XML
SourceXML = XMLConstruitChaîne("DocXML")
// Enregistrement du fichier XML
fSauveTexte("ExampleModifié.xml", SourceXML)
```

> _(WEBDEV - Code Navigateur)_ Cette fonctionnalité n'est pas disponible.
