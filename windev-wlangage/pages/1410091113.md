# SSHDéconnecteCommande (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Permet d'arrêter la session SSH qui était active pour permettre l'envoi groupé de plusieurs commandes. Cette session SSH a été précédemment activée via la fonction [SSHConnecteCommande](1410091112.md).
Nouveauté Abonnement
Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
Session est une sshSession
// Propriétés de la session
// ...
// Initialise la session SSH à conserver
SSHConnecteCommande(Session)
SSHCommande(Session, "echo 'Hello world !'")
SSHCommande(Session, "echo 'Hello world !'")
SSHCommande(Session, "echo 'Hello world !'")
SSHCommande(Session, "echo 'Hello world !'")
// Ferme la session SSH pour retrouver un fonctionnement normal
SSHDéconnecteCommande(Session)
```

## Syntaxe

```wlangage
SSHDéconnecteCommande(<Session SSH>)
```

`<Session SSH>` *Variable de type sshSession*
> Nom d'une variable [sshSession](1000021157.md) contenant les paramètres de connexion de la session SSH à déconnecter.

**Classification Métier / UI : Code métier**

**Composante : wd300com.dll**
