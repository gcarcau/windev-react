# grHMSupprimeCouleur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Supprime les couleurs spécifiées par la fonction [grHMCouleur](1000021629.md) dans un graphe de type Heatmap.

## Exemple

```wlangage
// On fixe les couleursgrHMSupprimeCouleur(GRF_Graphe)grHMCouleur(GRF_Graphe, -65, RVB(0, 105, 255))grHMCouleur(GRF_Graphe, 0, RVB(240, 255, 0))grHMCouleur(GRF_Graphe, 35, RVB(255, 31, 0))
```

## Syntaxe

```wlangage
grHMSupprimeCouleur(<Nom du graphe> [, <Palier>])
```

`<Nom du graphe>` *Nom de champ ou chaîne de caractères*
> Nom du graphe à manipuler. Ce nom correspond :
>
> - soit au nom du graphe défini par programmation avec la fonction [grCrée](3042005.md).
> - soit au nom du champ Graphe présent dans l'éditeur de fenêtres ou d'états.
>
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Palier>` *Réel optionnel*
> Palier de la couleur qui doit être supprimée. Si ce paramètre n'est pas spécifié, toutes les couleurs de palier sont supprimées et la couleur de la première série est utilisée.

## Remarques

Les données modifiées avec la fonction **grHMSupprimeCouleur** seront prises en compte lors du prochain appel à la fonction [grDessine](3042026.md).
