# EmailSupprimeDossier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Supprime un dossier dans le logiciel de messagerie Outlook ou sur un serveur IMAP.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur)_ // Ouverture de la session
IDSession = EmailOuvreSessionOutlook("MonProfil")
...
// Suppression d'un dossier
EmailSupprimeDossier(IDSession, "Dossiers personnels\Boîte de réception\Travail")

// Suppression d'un dossier dans le dossier en cours
EmailSupprimeDossier(IDSession, EmailDossierCourant(IDSession) + "\Travail")

```wlangage
// Protocole IMAP
MaSession est une emailSessionIMAP
...
// Suppression d'un dossier dans le dossier en cours
EmailSupprimeDossier(MaSession, EmailDossierCourant(MaSession) + "\Travail")

// Suppression d'un dossier dans le dossier personnel
EmailSupprimeDossier(MaSession, "Dossiers personnels\Boîte de réception\TravailPerso")
```

## Syntaxe

```wlangage
<Résultat> = EmailSupprimeDossier(<Session> , <Chemin du dossier>)
```

`<Résultat>` *Booléen*
> - Vrai si la suppression a été effectuée,
> - Faux dans le cas contraire. En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Session>` *Chaîne de caractères, Entier ou Variable de type emailSessionOutlook ou emailSessionIMAP*
> Identifiant de la session email en cours. Cet identifiant peut être :
>
> - un entier renvoyé par la fonction [EmailOuvreSessionOutlook](3032128.md) ou [OutlookOuvreSession](3032123.md).
> - une variable de type [emailSessionOutlook](1000018767.md).
> - une variable de type [emailSessionIMAP](1000018957.md).
> - le nom d'utilisateur passé à la fonction [EmailOuvreSessionIMAP](1000019189.md).
`<Chemin du dossier>` *Chaîne de caractères Unicode*
> Chemin du dossier à supprimer.

## Remarques

> _(WINDEV, WEBDEV - Code Serveur)_ Cas d'un serveur OutlookLe dossier doit être présent dans la branche "Dossiers personnels".Lors de l'appel de la fonction EmailSupprimeDossier, les manipulations suivantes sont automatiquement effectuées :les messages contenus dans le dossier à supprimer sont déplacés dans la Corbeille (dossier "Eléments supprimés").les sous-dossiers du dossier à supprimer et leur contenu sont déplacés dans la Corbeille (dossier "Eléments supprimés").le dossier à supprimer est définitivement supprimé.Si le dossier à supprimer est déjà présent dans la Corbeille, le dossier et son contenu sont définitivement supprimés.Rappel : Cette fonction ne permet pas de supprimer un dossier du logiciel de messagerie Outlook Express.
