# sfRésultatRestaure (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Le type **sfRésultatRestaure** permet de connaître le résultat de la fonction [SFRestaure](1000018527.md). Les caractéristiques de ce résultat peuvent être connues à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Connexion à Salesforce
Cnx est une sfConnexion
Cnx.Login = "balthazar@gmail.com"
Cnx.MotDePasse = "azerty" + "XXB12VCZ54"
SI SFConnecte(Cnx) = Faux ALORS
	Erreur("La connexion a échoué")
	RETOUR
FIN

ResRecupSuppr est un sfRésultatRechercheSupprimé
ResRecupSuppr = SFRechercheSupprimé(Cnx, "Mileage__c", "20090101", "20090131")

tabRestaure est un tableau de chaînes
MonEnregistrement est un sfEnregistrementSupprimé
POUR TOUT MonEnregistrement DE ResRecupSuppr.EnregistrementSupprimé
	Ajoute(tabRestaure, MonEnregistrement.ID)
FIN

ResRestaure est un tableau de sfRésultatRestaure
ResRestaure = SFRestaure(Cnx, tabRestaure)
MonEnregRestauré est un sfRésultatRestaure
POUR TOUT MonEnregRestauré DE ResRestaure
	Trace("ID = " + MonEnregRestauré.ID)
	Trace("Succès = " + MonEnregRestauré.Succès)
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type sfRésultatRestaure
Les propriétés suivantes peuvent être utilisées pour manipuler le résultat de la fonction [SFRestaure](1000018527.md) :

| Nom | Type manipulé | Effet |
| --- | --- | --- |
| Erreur | Tableau de [sfErreur](1000018455.md) | Compte-rendu d'erreurs. |
| ID | Chaîne de caractères | Identifiant Salesforce de l'enregistrement restauré. **Cette propriété est disponible en lecture seulement**. |
| Succès | Booléen | - Vrai si la restauration a été effectuée, - Faux dans le cas contraire.   **Cette propriété est disponible en lecture seulement**. |
