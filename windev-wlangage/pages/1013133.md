# Image "cliquable" dans une fenêtre

> **Disponible :** **WINDEV** (Windows, Java) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Sous WINDEV et WINDEV Mobile, il est possible d'utiliser des images cliquables. Un image cliquable est une image (affichée dans un champ Image) sur laquelle l'utilisateur peut cliquer. Un traitement spécifique (code de clic sur l'image) est alors exécuté.
Contrairement à un bouton, aucun effet d'enfoncement n'est observé lors du clic sur une image cliquable.

## Utiliser une image cliquable

Pour utiliser une image cliquable dans une application :

1. Sous le volet "Création", dans le groupe "Champs usuels", cliquez sur "Image".
2. Affichez la description du champ (option "Description" du menu contextuel de l'image).
3. Dans l'onglet "Détail", utilisez les paramètres propres au cliquage :
  - L'option "Cette image est une zone de clic" permet de rendre l'image cliquable. L'événement "Clic sur l'image" est ajouté automatiquement aux événements WLangage associés au champ.
  - L'option "Prioritaire pour les clics" permet d'intercepter le clic de souris sur l'image, quelle que soit l'altitude du champ Image dans la fenêtre. Si cette option n'est pas cochée, le champ Image doit être au premier plan pour intercepter le clic de la souris.
  - Indiquez si l'image doit être manipulable par l'utilisateur. Pour plus de détails, consultez [Menu contextuel des champs Image](9500105.md).

> _(Android)_ Zones de cliquage et multi-touchSi l'image est considérée comme une zone de cliquage, il est possible : soit de gérer uniquement le premier appui d'un doigt sur l'image (fonctionnement par défaut dans les versions précédentes). Si plusieurs doigts sont utilisés sur l'image, les différents traitements correspondants (doigt enfoncé, clic, ...) sont appelés uniquement lorsque le premier doigt est utilisé. soit de gérer les différents appuis des doigts sur l'image (option "Rappeler les traitements à chaque doigt (multipoints)") : Si plusieurs doigts sont utilisés sur l'image, les différents traitements/événements correspondants (doigt enfoncé, clic, ...) sont appelés à chaque nouvel appui d'un doigt supplémentaire. Pour plus de détails, consultez Gestion du multi-touch.
