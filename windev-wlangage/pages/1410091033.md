# <Variable Commande>.ExécutionEstEnCours (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

Indique si l'exécutable lié à une commande exécutée en mode console est actuellement en cours d'exécution.
Nouveauté 2025
**Attention** : Cette fonction est disponible uniquement à partir de la version 2025 Update 1.

## Exemple

```wlangage
// Exécution de la commande 'C:\Chemin\MonProgramme.exe -opt1=val1'
// Définition de la commande
MaCommandeAExécuter est une Commande
// Exécutable à lancer
MaCommandeAExécuter.Exécutable = "C:\Chemin\MonProgramme.exe"
// Arguments à passer à l'exécutable
MaCommandeAExécuter.Arguments = "Argument1"
// Activation des flux
MaCommandeAExécuter.Flux = cmdEntréeStandard + cmdSortieStandard
// Ajout d'un argument à la ligne de commande
MaCommandeAExécuter.AjouteArgument("Argument2")
// Ajout d'une option à la ligne de commande
MaCommandeAExécuter.AjouteOption("opt1", "val1")

// Exécution de la commande
MaCommandeAExécuter.Exécute(Faux)

TANTQUE MaCommandeAExécuter.ExécutionEstEnCours() = Vrai
	// Mettre une jauge à jour
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Commande manipulée>.ExécutionEstEnCours()
```

`<Résultat>` *Booléen*
> - Vrai si l'exécutable de la commande est en cours d'exécution,
> - Faux dans le cas contraire.
`<Commande manipulée>` *Variable de type Commande*
> Nom de la variable de type [Commande](1410090491.md) à manipuler.

**Classification Métier / UI : Code métier**

**Composante : wd300std.dll**
