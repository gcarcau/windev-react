# SysRep (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, PHP) · **Autres** (Procédures stockées)

Renvoie le chemin d'un répertoire du système.
> _(WEBDEV - Code Serveur)_ Renvoie le chemin d'un répertoire du système du poste serveur.

> _(PHP)_ Dans cette version, cette fonction permet uniquement de renvoyer le répertoire système.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ // Récupérer le chemin du répertoire système
ResRep = SysRep(srSystème)

> _(PHP)_ // Récupérer le chemin du répertoire système
ResRep = SysRep()

## Syntaxe

<Résultat> = SysRep([<Répertoire du système>])

## Remarques

### Répertoire temporaire
Pour connaître le répertoire temporaire de l'utilisateur, utilisez la fonction [fRepertoireTemp](3036044.md).

### Corbeille
La "Corbeille" correspond à un répertoire virtuel géré par Windows. La fonction **SysRep** ne permet donc pas de connaître le chemin de la "Corbeille".

**Composante : wd300std.dll**
