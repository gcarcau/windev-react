# Procédure WLangage appelée par la fonction PopupAffichePage

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur)

Procédure WLangage (appelée "callback") appelée par la fonction [PopupAffichePage](1410087258.md) après la fermeture de la page affichée en mode popup. Cette procédure est une procédure navigateur et elle peut correspondre à une procédure locale, globale ou interne.

## Exemple

> _(WEBDEV - Code Navigateur)_ // Affiche la page PAGE_DétailsProduit en popup
// Attend la fermeture de la page et affiche la valeur renvoyée
PopupAffichePage(PAGE_Détail, (nIDProduit), PopupAffiche_Callback, BTN_CHAMP, popupPositionXY, 10, 10)

 PROCÉDURE INTERNE PopupAffiche_Callback(RetourPagePopup)
 Trace("La popup a renvoyé : [%RetourPagePopup%]")
 FIN

## Syntaxe

```wlangage
PopupAffichePage_Callback(<Valeur de retour>)
```

`<Valeur de retour>` *Type de la valeur de retour*
> Valeur qui sera renvoyée par la page via la fonction [PopupFermePage](1410087259.md).
