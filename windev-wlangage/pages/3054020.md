# LangueVersNom (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Renvoie le nom d'une langue.

## Exemple

```wlangage
// Connaître le nom de la langue arménienne
ResNom est une chaîne
ResNom = LangueVersNom(langueArménien)
```

```wlangage
// Connaître le nom de la langue anglaise en Australie
ResNom est une chaîne
ResNom = LangueVersNom(langueAnglais, 3)
// Renvoie "Australien"
```

## Syntaxe

```wlangage
<Résultat> = LangueVersNom(<Langue> [, <Sous-langue>])
```

`<Résultat>` *Chaîne de caractères*
> - Nom de la langue spécifiée,
> - Chaîne vide ("") si la langue spécifiée n'est pas connue.
`<Langue>` *Constante de type Entier*
> Langue dont on veut connaître le nom. Pour plus de détails sur ces constantes, consultez [Correspondance entre les langues, les sous-langues, les alphabets et les nations](3054022.md).
`<Sous-langue>` *Entier optionnel*
> Sous-langue dont on veut connaître le nom. Pour plus de détails sur ces sous-langues, consultez [Correspondance entre les langues, les sous-langues, les alphabets et les nations](3054022.md).
> Si ce paramètre n'est pas spécifié, le nom standard de la <Langue> spécifiée est donnée.
