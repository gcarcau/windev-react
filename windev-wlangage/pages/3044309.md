# HModifieUtilisateur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Modifie les informations d'un utilisateur en fonction des éléments présents dans les [variables de gestion des utilisateurs](3044315.md) correspondantes.

## Exemple

```wlangage
// Description de la connexion
HDécritConnexion("MaConnexion", "Julie", "MotDePasse", "MonServeurHF", "MaBaseDeDonnées", ...
	hAccèsHFClientServeur, hOLecture)
// Ouverture de la connexion
HOuvreConnexion("MaConnexion")
// Association du fichier de données à la connexion
HChangeConnexion(Client, "MaConnexion")
SI HInfoUtilisateur("MaConnexion", "Florence") = Vrai ALORS
	// Modification des caractéristiques
	HUtilisateur.Groupes = "ADMIN" + RC + "TEST" + RC + "DOC"
	SI HModifieUtilisateur("MaConnexion", "Florence") = Vrai ALORS
		Info("Utilisateur modifié")
	FIN
FIN
```

## Syntaxe

```wlangage
<Résultat> = HModifieUtilisateur(<Connexion> , <Utilisateur>)
```

`<Résultat>` *Booléen*
> - Vrai si l'utilisateur a été modifié,
> - Faux en cas d'erreur. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion pour laquelle un utilisateur doit être modifié. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Utilisateur>` *Chaîne de caractères*
> Nom de l'utilisateur dont on veut modifier les caractéristiques. Ce nom doit correspondre à la variable **HUtilisateur.Login** de l'un des utilisateurs de la connexion spécifiée.

## Remarques

### Droits nécessaires pour modifier un utilisateur
Pour modifier un utilisateur (différent de l'utilisateur en cours), il est nécessaire de posséder le droit de visualisation des utilisateurs (constante *hDroitVisualisationUtilisateur*). Dans le cas contraire, la fonction **HModifieUtilisateur** renverra Faux et le message d'erreur sera "Utilisateur inconnu".
Pour modifier le nom d'un utilisateur, il est nécessaire de posséder le droit de visualisation des utilisateurs (constante *hDroitVisualisationUtilisateur*) et le droit de gestion des utilisateurs (constante *hDroitGestionUtilisateur*).

Remarque : Ces constantes sont utilisées dans les fonctions [HInfoDroitServeur](3044322.md) et [HModifieDroitServeur](3044328.md).
