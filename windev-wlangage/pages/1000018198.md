# Lien (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **Lien** permet de connaître et de modifier le lien d'un élément. Cette propriété est utilisable sur :

- une variable de type [rssCanal](1000017769.md).
- une variable de type [rssEntrée](1000017792.md).
- une variable de type [rssImage](1000017799.md).
- une variable de type [rssSaisieTexte](1000017802.md).
- une variable de type [hdfsInformation](1000021973.md).
- une variable de type [docElément](1000022484.md).
- une variable de type [docElémentLien](1000022970.md).
- une variable de type [diagPointDePassage](1410088548.md).
- une variable de type [diagSélection](1410088172.md).
