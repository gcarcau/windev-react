# CelluleFermeDialogue (Fonction)

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur)

Masque un champ Cellule précédemment affiché dans la page via la fonction [CelluleAfficheDialogue](1000017139.md).

## Exemple

```wlangage
// Ferme le champ Cellule de question
CelluleFermeDialogue(CELL_Question)
```

## Syntaxe

```wlangage
CelluleFermeDialogue(<Champ Cellule>)
```

`<Champ Cellule>` *Nom de champ*
> Nom de la cellule qui sera masquée. Cette cellule est superposable et a été affichée par la fonction [CelluleAfficheDialogue](1000017139.md). Si ce n'est pas le cas, la fonction **CelluleFermeDialogue** ne fait rien.

## Remarques

Les navigateurs ne rafraîchissent pas l'affichage au milieu d'un code Javascript : les fonctions [CelluleAfficheDialogue](1000017139.md) et **CelluleFermeDialogue** doivent être utilisées dans des événements/traitements différents. Si ces fonctions sont utilisées dans le même événement/traitement, le champ Cellule n'est pas affiché.

**Composante : WDJS.DLL**
