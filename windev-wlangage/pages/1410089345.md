# Procédure WLangage appelée par la fonction iOSApplicationOpenURLProcédure

> **Disponible :** **WINDEV Mobile** (iPhone/iPad)

Procédure WLangage (également nommée "callback") appelée par la fonction [iOSApplicationOpenURLProcédure](1410089346.md) lorsque l'application doit ouvrir une ressource désignée par une URL.

## Exemple

```wlangage
iOSApplicationOpenURLProcédure(AffichageURL)

	PROCÉDURE INTERNE AffichageURL(uURL est une URI)
		SI FenEtat(FEN_SansNom1) <> Inexistant ALORS
			FEN_SansNom1.LIB_Result = uURL
		FIN
	FIN
```

## Syntaxe

```wlangage
iOSApplicationOpenURLProcédure_Callback(<URL>)
```

`<URL>` *Variable de type URI*
> Variable de type [URI](1000024027.md) correspondant à l'URL à lancer.
