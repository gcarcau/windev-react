# 1. Créer un projet WEBDEV et son analyse

## Leçon 1 - Créer un projet WEBDEV et son analyse

**Ce que vous allez apprendre** :

- Créer un projet.
- Créer une analyse.

[image: Durée de la leçon] 5 mn

## Analyse et projet : Définitions

La création d'un site avec WEBDEV se base sur la création d'un **projet**. Ce projet contient tous les éléments nécessaires au site.
Lors de la conception d'un site, vous pouvez être amené à manipuler des données. Pour les stocker, vous devez constituer ce que l'on nomme "une base de données".

Dans WEBDEV, lors de la création d'un projet manipulant des données, vous devez tout d'abord créer une **analyse**. Une "analyse" contient la description des fichiers de données (ou "tables"). Les données de l'application seront enregistrées dans les fichiers de données.
**Vocabulaire** :
Le terme "Fichier de données" correspond dans certaines bases de données à "une table".

C'est seulement lors de l'exécution du site que ces descriptions sont utilisées pour créer la base de données et/ou les fichiers de données. C'est dans cette base de données ou dans ces fichiers de données que seront stockées les informations.

## Un projet exemple associé à une analyse

Dans ce tutoriel, nous allons créer un projet associé à une base de données HFSQL.WEBDEV sait gérer de nombreux formats de bases de données. Il propose également HFSQL, système de base de données intégrée à WEBDEV et livrée en standard. La base de données HFSQL est disponible en version Locale, Réseau, Cluster, Client/Serveur (Windows et Linux), Cloud et Mobile.
Pour créer un site avec une base de données, il faut :

- Créer le projet lié au site. Ce projet regroupera tous les éléments du site (pages, codes, requêtes, états, etc.).
- Créer l'analyse liée au projet. L'analyse permet de décrire tous les fichiers de données manipulés par le site.

## Création du projet

Avant tout développement avec WEBDEV, il faut un projet ? Créons-le !
Pour créer le projet, il suffit de suivre les différentes étapes de l'assistant de création de projet :

1. Lancez WEBDEV et affichez la page d'accueil de WEBDEV si nécessaire (Ctrl + <).
2. Dans la page d'accueil, cliquez sur "Créer un projet", puis sur l'option "Site, Site SaaS". L'assistant de création du projet se lance. Les différentes étapes de l'assistant vont vous aider à créer votre projet.
  Tous les renseignements indiqués dans cet assistant pourront être modifiés par la suite.
3. L'assistant propose de définir la charte graphique (également appelée "Ambiance"). Sélectionnez "Phoenix".
  Les ambiances permettent d'harmoniser l'aspect visuel d'un site et rendent les changements de look plus simples et plus rapides.
  L'ambiance fournit les images, les polices, la texture, la forme des boutons et les styles disponibles pour le projet..
  [image: Assistant de création de projet - choix de l'ambiance]
4. Passez à l'étape suivante de l'assistant (bouton "Suivant").
5. L'assistant permet de saisir le nom du projet et son emplacement. Dans notre cas, ce projet va simplement s'appeler "Mon_Site_WEBDEV".
  [image: Assistant de création de projet - Informations générales]
  Par défaut, WEBDEV propose de créer ce projet dans le répertoire ".\Mes Projets\Mon_Site_WEBDEV". Vous pouvez conserver cet emplacement ou le modifier grâce au bouton [...].
  Lorsque vous développez pour le Web, il est préférable d'éviter les caractères accentués dans les noms des éléments (projets, pages, etc.).
6. Cliquez sur le bouton "Terminer" : le projet est créé. La fenêtre de création d'un nouvel élément s'affiche. Fermez cette fenêtre à l'aide de la croix en haut à droite.

## Création de l'analyse

Nous allons maintenant créer l'analyse liée au projet :

1. Cliquez sur  parmi les boutons d'accès rapide. L'assistant de création d'une analyse se lance.
2. Indiquez le nom et le répertoire de l'analyse. Par défaut, le nom de l'analyse correspond au nom du projet et le répertoire de l'analyse est un répertoire ".ana" dans le répertoire du projet. Nous allons conserver ces paramètres par défaut.
  [image: Assistant de création d'analyse - Nom de l'analyse]
  Passez à l'étape suivante de l'assistant.
3. Vous pouvez ensuite choisir le type de la base de données manipulée par le projet. Sélectionnez "HFSQL Classic".
  [image: Assistant de création d'analyse - Type de la base de données]
  Passez à l'étape suivante de l'assistant.
4. Validez. L'assistant de création d'un fichier de données se lance automatiquement.
5. Fermez cet assistant. Nous verrons dans la prochaine leçon les différentes manières disponibles pour créer la description d'un fichier de données.

## Conclusion

Dans cette leçon, nous avons découvert :

- l'importance du projet dans la création d'un site.
- les étapes de la création d'un projet.
- les étapes de la création d'une analyse.
- etc.

La prochaine leçon de ce tuto va vous permettre les différentes méthodes proposées pour décrire un fichier de données sous l'éditeur d'analyses. Vous apprendrez également à définir les liaisons entre les différents fichiers de données de l'analyse.
