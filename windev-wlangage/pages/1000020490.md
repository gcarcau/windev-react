# Serveur (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

La propriété **Serveur** permet de gérer les serveurs. Cette propriété est utilisable sur :

- une connexion HFSQL. Pour plus de détails, consultez [Serveur](2512105.md).
- une variable de type [hRSConfig](1000020484.md).
- une variable de type [hbConnexion](1000021685.md).
- une variable de type [memcachedConnexion](1000023339.md).
- une variable de type [redisConnexion](1000023527.md).
- Nouveauté 2025
  une variable de type [ftpConnexion](1410090869.md).
