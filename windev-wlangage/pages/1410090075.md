# Marge (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

La propriété **Marge** permet de définir la taille d'une marge, par exemple autour d'un texte. Cette propriété est utilisable sur :

- une variable de type [diagTexte](1410088393.md).
- une variable de type [VisiteGuidée](1410090170.md).
- une variable de type [VisiteGuidéeEtape](1410090178.md).
- la propriété [BoutonGauche](1410090001.md) d'un champ de saisie.
- la propriété [BoutonDroit](1410090002.md) d'un champ de saisie.
