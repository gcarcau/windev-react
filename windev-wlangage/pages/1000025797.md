# <Carte>.ChangeStyle (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android)

Modifie le style de la carte affichée dans le champ Carte.
Nouveauté Abonnement

> _(Android)_ Cette fonction est disponible uniquement si le style de la carte n'a pas été personnalisé. Dans le cas contraire, cette fonction est sans effet. Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3. Pour plus de détails, consultez Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement.

## Exemple

```wlangage
// Applique un style "Aubergine" à la carte
CARTE_MaCarte.ChangeStyle(ccsAubergine)
```

## Syntaxe

```wlangage
<Résultat> = <Champ Carte>.ChangeStyle(<Style> [, <Chemin du fichier de configuration>])
```

`<Résultat>` *Booléen*
> - Vrai si le nouveau style a pu être appliqué,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler.
`<Style>` *Entier*
> Modifie le style appliqué à la carte affichée par le champ Carte. Ce paramètre peut prendre l'une des valeurs suivantes :
>
> | *ccsArgenté* | Style "argenté". |
> | --- | --- |
> | *ccsAubergine* | Style "aubergine". |
> | *ccsAutomatique* | Le style sera appliqué en fonction du mode clair ou sombre de l'application :  - Thème clair : le style utilisé sera le style "standard", - Thème sombre : le style utilisé sera le style "nuit".  Si le thème de l'application change alors que le champ Carte est affiché, le style sera automatiquement modifié. |
> | *ccsNuit* | Style "nuit". |
> | *ccsPersonnalisé* | Style personnalisé. dans ce cas, le paramètre <Chemin du fichier de configuration doit être spécifié. |
> | *ccsRétro* | Style "retro". |
> | *ccsSombre* | Style "sombre". |
> | *ccsStandard* | Style "standard". |
`<Chemin du fichier de configuration>` *Chaîne de caractères optionnelle*
> Chemin du fichier JSON décrivant le style personnalisé qui doit être appliqué à la carte. Ce fichier doit être un fichier JSON valide encodé en UTF-8. Pour plus d'information sur la configuration personnalisé du style, consultez : [https://mapstyle.withgoogle.com/](https://mapstyle.withgoogle.com/)
> Ce paramètre sera pris en compte uniquement si le paramètre <Style> correspond à la constante *ccsPersonnalisé*.

## Remarques

- Par défaut le champ Carte utilise le style automatique.
- Pour récupérer le style utilisé par la carte affichée depuis le champ Carte, utilisez la fonction [<Carte>.RécupèreStyle](1000025798.md).
