# <Bouton segmenté>.Ajoute (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Ajoute une nouvelle option (c'est-à-dire un nouveau bouton) dans un champ Bouton segmenté. L'option est ajoutée à la suite des options existantes.

## Exemple

```wlangage
BS_Temps.Ajoute("J+1")
BS_Temps.Ajoute("J+7")
BS_Temps.Ajoute("J+30")
```

## Syntaxe

```wlangage
<Résultat> = <Champ Bouton segmenté>.Ajoute(<Libellé de l'option>)
```

`<Résultat>` *Entier*
> - Indice de l'option ajoutée.
> - -1 en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Bouton segmenté>` *Nom de champ*
> Nom du champ Bouton segmenté dans lequel l'option doit être ajoutée. L'option est ajoutée à la suite des options existantes.
`<Libellé de l'option>` *Chaîne de caractères*
> Libellé de l'option à ajouter.

**Classification Métier / UI : Code UI**

**Composante : wd300obj.dll**
