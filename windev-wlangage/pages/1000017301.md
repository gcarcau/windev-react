# JourFériéSupprimeTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Vide la liste de tous les jours fériés. Les jours fériés sont définis avec la fonction [JourFériéAjoute](1000017304.md).

## Exemple

```wlangage
// Vide la liste des jours fériés
JourFériéSupprimeTout()
```

## Syntaxe

```wlangage
JourFériéSupprimeTout()
```

## Remarques

Après l'appel de la fonction **JourFériéSupprimeTout**, la fonction [JourFérié](1000017303.md) renvoie toujours Faux.
