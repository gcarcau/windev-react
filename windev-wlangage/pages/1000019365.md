# MenuExiste (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

Indique si une option de menu existe dans un menu.

## Exemple

```wlangage
// Si l'option n'existe pas encore
SI MenuExiste(MonMenu, "OuvreClient" + ID) = Faux ALORS
	// Ajout de l'option
	MenuAjouteOption(MonMenu, "OuvreClient" + ID, "Ouvrir la fiche " + ID, OuvreFiche, ID)
FIN
```

## Syntaxe

```wlangage
<Résultat> = MenuExiste(<Menu> , <Option de menu>)
```

`<Résultat>` *Booléen*
> - Vrai si l'option de menu existe,
> - Faux dans le cas contraire.
>
>
> **Attention** : La recherche n'est pas récursive : si le menu contient un sous-menu qui contient l'option, <Résultat> vaut Faux.
`<Menu>` *Nom de menu*
> Nom du menu ou du menu contextuel dans lequel la recherche doit être effectuée.
`<Option de menu>` *Chaîne de caractères*
> Nom de l'option de menu à rechercher.

**Composante : wd300obj.dll**
