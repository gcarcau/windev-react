# Heure (Mot-clé)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le mot-clé **Heure** peut correspondre :

- à une variable de type [Heure](1514068.md).
- à la propriété **Heure**. Cette propriété permet de connaître et de modifier l'heure d'un élément. Cette propriété est utilisable sur :
  - une variable ou une rubrique de type Date, Heure et DateHeure. Pour plus de détails, consultez [Propriété Heure sur les rubriques et les types Date, Heure et DateHeure](2512038.md).
  - une variable de type [hTâchePlanifiée](1000017448.md).
  - une variable de type [hPlanification](1000018853.md).
  - une variable de type [Répétition](1000019262.md).
  - une variable de type [serveurAppliTâchePlanifiée](1000022367.md).
