# Erreur 1048 : L'héritage est interdit dans une variable composée

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

## Cause

Vous tentez de définir un héritage dans la définition d'une variable composée. L'héritage est interdit dans une variable composée.

## Correction

Supprimez la déclaration de l'héritage.

## Exemple

### Héritage dans une variable composée

**Code provoquant l'erreur**

```wlangage
Coordonnée est composé de x est un réel y est un réelFINCoordonnée1 est composé de  un objet Coordonnée x1 est un réel y1 est un réelFIN
```

**Correction proposée**

Supprimer l'héritage.

```wlangage
Coordonnée est composé de x est un réel y est un réelFINCoordonnée1 est composé de x1 est un réel y1 est un réelFIN
```
