# Permission (Propriété)

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, iPhone/iPad)

Le mot-clé **Permission** permet de connaître et de modifier les permissions.
Ce mot-clé peut correspondre :

- à la variable de type [Permission](1410087419.md).
- à la propriété **Permission** utilisable sur :
  - une variable de type [btleCaractéristique](1000022060.md).
  - une variable de type [btleDescripteur](1000022064.md).
  - une variable de type [fbSession](1000021851.md).
