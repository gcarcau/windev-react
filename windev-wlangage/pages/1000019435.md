# Fonctions de gestion des champs Planning

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des champs Planning (syntaxe préfixée)](1000022917.md)).
Les fonctions de gestion des champs Planning sont les suivantes :

| [iCalendarVersPlanning](1000021917.md) | Importe des données au format iCalendar dans un champ Planning. |
| --- | --- |
| [PlanningAffiche](1000019426.md) | Réinitialise le contenu d'un champ Planning à partir de sa source de données (fichier de données HFSQL par exemple). |
| [PlanningAffichePériodePrécédente](1000019495.md) | Déplace la zone temporelle affichée sur la zone précédente (par exemple, semaines précédentes) dans un champ Planning. |
| [PlanningAffichePériodeSuivante](1000019496.md) | Déplace la zone temporelle affichée sur la zone suivante (par exemple, semaines suivantes) dans un champ Planning. |
| [PlanningAjouteRendezVous](1000019273.md) | Ajoute un nouveau rendez-vous dans un champ Planning. |
| [PlanningAjouteRessource](1000019279.md) | Ajoute une nouvelle ressource dans un champ Planning. |
| [PlanningChangeMode](1000019440.md) | Modifie la période (c'est-à-dire le nombre de jours) affichée par un champ Planning. |
| [PlanningCouleurFond](1000019997.md) | Fixe une couleur de fond sur une plage horaire d'un champ Planning présent dans une fenêtre (par exemple, plage horaire correspondant au déjeuner, à un jour férié, ...). |
| [PlanningDateVisible](1000022876.md) | Rend visible ou invisible un jour dans un champ Planning. |
| [PlanningHeureAffichée](1000019373.md) | Définit la plage horaire affichée par le champ Planning en mode Jour ou Semaine. |
| [PlanningHeureOuvrable](1000022404.md) | Permet d'indiquer les heures ouvrables spécifiques par jour dans un champ Planning. |
| [PlanningHeureOuvrableRessource](1000022403.md) | Permet d'indiquer les heures ouvrables spécifiques par jour et par ressource dans un champ Planning. |
| [PlanningInfoXY](1000019553.md) | Renvoie le rendez-vous, la ressource ou la date se trouvant à une position donnée dans un champ Planning. |
| [PlanningListeRendezVous](1000019276.md) | Renvoie :   - la liste des rendez-vous compris entre deux dates données dans un champ Planning, - tous les rendez-vous d'un champ Planning, - un rendez-vous particulier (sélectionné ou survolé). |
| [PlanningMode](1000019992.md) | Renvoie le mode d'affichage d'un champ Planning : jour, semaine, mois, ... |
| [PlanningPlageSélectionnée](1000022550.md) | Retourne la date et l'heure de début ou de fin de la plage horaire sélectionnée dans un champ Planning. |
| [PlanningPosition](1000019372.md) | Affiche un champ Planning à partir d'une date spécifiée ou renvoie la date du premier jour (ou dernier jour) affiché dans un champ Planning. |
| [PlanningPositionDateHeure](1000019998.md) | Affiche un champ Planning à partir d'une date spécifiée ou renvoie la date du premier jour (ou dernier jour) affiché dans un champ Planning. |
| [PlanningPositionRessource](1000019969.md) | Affiche une ressource donnée dans un champ Planning ou renvoie la position la première ressource visible dans un champ Planning. |
| [PlanningSelectMoins](1000019286.md) | Désélectionne un rendez-vous dans un champ Planning. |
| [PlanningSelectPlus](1000019285.md) | Sélectionne un rendez-vous dans un champ Planning. |
| [PlanningSupprimeRendezVous](1000019274.md) | Supprime un rendez-vous dans un champ Planning. |
| [PlanningSupprimeRessource](1000019282.md) | Supprime une ressource dans un champ Planning. |
| [PlanningSupprimeTout](1000019275.md) | Supprime tous les rendez-vous et toutes les ressources d'un champ Planning. |
| [PlanningVersiCalendar](1000021920.md) | Exporte les rendez-vous d'un champ Planning au format iCalendar. |
