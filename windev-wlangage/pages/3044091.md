# HDétruitVue (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Détruit une vue précédemment créée. Cette destruction consiste à détruire tout ce qui concerne la vue, y compris sa description. Lors de cette destruction, les enregistrements bloqués par la vue (s'ils existent) sont débloqués.

## Exemple

```wlangage
// Destruction de la vue Client34
SI HDétruitVue(Client34) = Faux ALORS
	Erreur("Erreur lors de la destruction d'une vue : " + HErreur())
SINON
	Info("La vue a bien été détruite.")
FIN
```

## Syntaxe

```wlangage
<Résultat> = HDétruitVue([<Vue>])
```

`<Résultat>` *Booléen*
> - Vrai si la vue a été détruite,
> - Faux en cas de problème : la vue n'est pas détruite. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Vue>` *Chaîne de caractères optionnelle*
> Nom de la vue à détruire. Ce nom a été défini grâce à la fonction [HCréeVue](3044159.md). Si ce paramètre n'est pas spécifié, la fonction **HDétruitVue** se réfère à la dernière vue utilisée.

## Remarques

Par défaut, lors de la sortie de l'application, toutes les vues existantes sont détruites.

**Composante : wd300hf.dll**
