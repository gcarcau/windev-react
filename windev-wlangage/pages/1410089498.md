# TypeAutorisation (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **TypeAutorisation** permet de connaître le type d'autorisation disponible. Cette propriété est utilisée par :

- une variable de type [OAuth2Paramètres](1000022212.md).
- une variable de type [OpenIDParamètres](1000023561.md).
