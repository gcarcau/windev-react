# SaaSDéconnecte (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Déconnecte l'utilisateur d'un site SaaS auprès du webservice SaaS gestionnaire du site.

## Exemple

```wlangage
SI SaaSConnecte("login", "motdepasse") = Vrai ALORS
	SI SaaSDéconnecte() = Vrai ALORS
		Info("Déconnexion réussie")
	FIN
FIN
```

## Syntaxe

```wlangage
<Résultat> = SaaSDéconnecte()
```

`<Résultat>` *Booléen*
> - Vrai si la déconnexion a été effectuée,
> - Faux dans le cas contraire. Si la fonction **SaaSDéconnecte** est utilisée plusieurs fois (sans reconnexion par la fonction [SaasConnecte](1000018959.md)), <Résultat> est également à Faux.

**Composante : wd300com.dll**
