# Configuration du serveur HFSQL

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Le Centre de Contrôle HFSQL propose une gestion complète des serveurs HFSQL.

Pour afficher les caractéristiques d'un serveur HFSQL :

1. Connectez-vous si nécessaire à un serveur HFSQL. Pour plus de détails, consultez [Gestion des bases de données HFSQL Client/Serveur](35400013.md).
2. Double-cliquez sur le nom du serveur HFSQL dans l'arborescence.
3. La partie droite du Centre de Contrôle affiche un onglet au nom du serveur. Cet onglet est constitué de :
  - différents onglets permettant de gérer les caractéristiques du serveur HFSQL.
  - un ruban permettant de configurer le serveur HFSQL.

Dans le ruban, dans le groupe "Paramètres", l'option "Configuration du serveur" permet de gérer toutes les options de configuration du serveur HFSQL.

[image: Ruban pour un onglet de type 'Serveur']

## Général

Dans la fenêtre de configuration du serveur, cliquez sur "Général". Les options suivantes apparaissent :

[image: Configuration du serveur, option 'Général']

Vous pouvez configurer :

- **Emplacement des bases de données**, c'est-à-dire les fichiers de données des différentes applications HFSQL Client/Serveur. Des raccourcis peuvent être utilisés pour indiquer les répertoires spécifiques :
  - "%%EXE%%" : Répertoire du service Manta.
  - "%%COMMONAPPDATA%%" : Répertoire des données commun à toutes les applications.
- **Calcul des statistiques sur les clés** : L'activation de cette option permet d'optimiser automatiquement l'exécution des requêtes et des filtres.
- **Répertoire local de stockage** : Ce répertoire contient toutes les données récupérées (logs et statistiques) afin d'effectuer des consolidations sur de longues périodes.
- **Langue du serveur** : Langue des messages du serveur.
  Si l'application cliente a pu ouvrir la connexion sur le serveur HFSQL Client/Serveur alors une éventuelle erreur (un mot de passe incorrect par exemple) est renvoyée par le serveur HFSQL dans la langue de l'application cliente.
  Si l'application cliente n'a pas pu ouvrir la connexion (chiffrement incompatible par exemple) alors le message d'erreur est renvoyé dans la langue configurée dans le serveur HFSQL Client/Serveur.

## Journaux

Dans la fenêtre de configuration du serveur, cliquez sur "Journaux des fichiers". Les options suivantes apparaissent :

[image: Configuration du serveur, option 'Journaux des fichiers']

Vous pouvez définir le répertoire des journaux et de leur sauvegarde.

## Logs

Dans la fenêtre de configuration du serveur, cliquez sur "Logs du serveur". Les options suivantes apparaissent :

[image: Configuration du serveur, option 'Logs du serveur']

Il est possible :

- d'indiquer le répertoire des fichiers de log.
- d'activer l'enregistrement des appels au serveur dans le fichier de log.
- d'activer l'enregistrement des paramètres des appels dans le fichier de log.

Il est également possible d'indiquer la taille maximale du fichier de log.

## Statistiques d'activité

Dans la fenêtre de configuration du serveur, cliquez sur "Statistiques d'activité". Les options suivantes apparaissent :

[image: Configuration du serveur, option 'Statistiques d'activité']

Les statistiques d'activité permettent de mesurer la charge du serveur. Il est possible :

- d'activer les statistiques d'activité,
- de spécifier le répertoire d'enregistrement,
- de spécifier la taille maximale du fichier,
- de spécifier la période de calcul des performances (en secondes).

## Système

Dans la fenêtre de configuration du serveur, cliquez sur "Système". Les options suivantes apparaissent :

[image: Configuration du serveur, option 'Système']

- Port d'écoute du serveur,
- Compte utilisateur du serveur (uniquement pour Linux)
- Autoriser des tailles supérieures à 2 Go pour les fichiers système.
- Port de débogage à distance,
- Autoriser l'authentification par Active Directory.

Nouveauté 2025
Il est également possible de gérer l'historique des exécutions des planifications. Les différents éléments planifiés (tâches, optimisations, etc.) possèdent un historique d'exécution, permettant de connaître par exemple la date d'exécution ainsi que le compte-rendu, etc.
Il est possible de :

- définir la taille maximale de l'historique des exécutions, c'est-à-dire le nombre maximal d'exécutions mémorisées dans l'historique des planifications (100000 par défaut).
- purger l'historique. Dans ce cas, tous les historiques d'exécution des éléments planifiés seront supprimés.

## Caches

Dans la fenêtre de configuration du serveur, cliquez sur "Caches". Les options suivantes apparaissent :

[image: Configuration du serveur, option 'Caches']

- Taille du cache des index.
  **Remarque** : en 32 bits, la taille du cache des index est limitée à 1Go.
- Cache disque (serveur Windows uniquement) : La gestion standard des caches disques de Windows en mode 64 bits (indépendamment de HFSQL) peut amener à des saturations mémoire. Cette option permet de personnaliser la gestion des caches mémoire.

## Notifications

Dans la fenêtre de configuration du serveur, cliquez sur "Notifications".
Cette option permet de gérer les destinataires des notifications.

Attention : la configuration de l'envoi des notifications est nécessaire avant d'ajouter des destinataires.

Pour plus de détails, consultez [Notifications d'un serveur HFSQL](1000017311.md).

## Réplication

Dans la fenêtre de configuration du serveur, cliquez sur "Réplication".
Cette option permet de configurer la réplication de serveurs. Pour plus de détails, consultez [Réplication de serveurs HFSQL](1000020588.md).

## Version

Dans la fenêtre de configuration du serveur, cliquez sur "Version".
Cette option permet de :

- Connaître la version actuelle du serveur :
  - Version majeure : Version correspondant à la version du moteur HFSQL utilisé par le serveur.
  - Version mineure : Numéro de la mise à jour utilisée.
  - Langue : Langue utilisée pour le serveur.
  Le lien "Plus de détails" permet d'obtenir le détail des modules utilisés.
- Mettre en place la mise à jour automatique du serveur. Si cette option est activée, le serveur HFSQL peut être mis à jour automatiquement dès qu'une nouvelle version est disponible :
  - sur le serveur PC SOFT.
  - sur un serveur personnalisé.
  Pour plus de détails, consultez [Mise à jour du serveur](35400018.md).

## Sécurité des mots de passe

Dans la fenêtre de configuration du serveur, cliquez sur "Sécurité des mots de passe".
Cette option permet de définir une politique de sécurité des mots de passe sur un serveur HFSQL. Cette politique sera appliquée lors de la connexion d'un utilisateur au serveur HFSQL.

Pour manipuler les données d'une base HFSQL Client/Serveur, les utilisateurs s’identifient via un login et un mot de passe.
La politique de gestion des mots de passe permet de définir aussi bien la taille de ces mots de passe que leur complexité ou encore leur mode de renouvellement (changement de mot de passe obligatoire tous les mois par exemple).

Il est possible d'activer les options suivantes :

- **Durée de validité du mot de passe** : Permet d'activer le contrôle sur la durée de validité d'un mot de passe. Il est possible de modifier ce délai (60 jours par défaut) en cliquant sur le nombre de jours proposé par défaut. Lorsque ce délai est écoulé, le mot de passe de l'utilisateur doit être changé.
- **Délai avant changement** : Permet d'activer le contrôle sur le délai minimal entre deux changements de mots de passe. Il est possible de modifier ce délai (0 jours par défaut) en cliquant sur le nombre de jours proposé par défaut.
- **Délai avant réutilisation** : Permet d'activer le contrôle sur le délai entre deux réutilisations du même mot de passe. Il est possible de modifier ce délai (365 jours par défaut) en cliquant sur le nombre de jours proposé par défaut.
- **Changement avant réutilisation** : Permet d'activer le contrôle sur le nombre de changements de mots de passe avant la réutilisation d'un ancien un mot de passe. Il est possible de modifier ce nombre (3 changements par défaut) en cliquant sur le nombre proposé par défaut.
- **Blocage après saisie invalide** : Permet d'activer le contrôle sur le nombre d'échec de saisie de mots de passe avant le blocage de la connexion pendant une durée déterminée. Il est possible de modifier ce nombre (5 échecs par défaut) et la durée (5 minutes par défaut) en cliquant sur les différentes valeurs proposées par défaut.
- **Taille** : Permet d'activer le contrôle sur la taille minimale des mots de passe. Il est possible de modifier cette taille (12 caractères par défaut) en cliquant sur le nombre de caractères proposé par défaut.
- **Complexité** : Permet de définir le contrôle sur la complexité attendue pour le mot de passe. Par défaut, aucun contrôle n'est effectué (option "Faible").
  - L'option "Moyenne" permet de vérifier que les mots de passe contiennent au moins une majuscule, une minuscule et un numérique.
  - L'option "Elevée" permet de vérifier que les mots de passe contiennent au moins une majuscule, une minuscule, un numérique et un caractère spécial.

**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
