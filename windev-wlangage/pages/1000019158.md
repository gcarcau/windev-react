# Paramètre (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **Paramètre** permet de connaître et de modifier certains paramètres. Cette propriété est utilisable sur :

- une variable de type [hTâchePlanifiée](1000017448.md).
- une variable de type [Description d'API](1000019149.md).
- une variable de type [Description de TâcheParallèle](1000021586.md).
- une variable de type [serveurAppliTâchePlanifiée](1000022367.md).
- une variable de type [Description de Syntaxe](1410089154.md).
