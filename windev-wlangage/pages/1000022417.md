# mongoGridFSInfoFichier (Type de variable)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Le type **mongoGridFSInfoFichier** permet de connaître toutes les caractéristiques avancées d'un fichier contenu dans une base MongoDB. Les caractéristiques de ce fichier peuvent être connues à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
tabListeFichier est un tableau de mongoGridFSInfoFichier

tabListeFichier = MongoGridFSListeFichier(CnxMDB.BaseDeDonnées["CRM"])
POUR TOUT Fic DE tabListeFichier
	// Traite le fichier
	Trace(Fic.Nom)
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type mongoGridFSInfoFichier
Les propriétés suivantes peuvent être utilisées pour manipuler les informations d'un fichier :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Alias | Tableau de chaînes | Tableau des noms d'alias du fichier.  **Cette propriété est disponible en lecture seulement**. |
| Date | DateHeure | Date de création du fichier au format UTC.  **Cette propriété est disponible en lecture seulement**. |
| ID | Variant | Identifiant du fichier.  **Cette propriété est disponible en lecture seulement**. |
| Md5 | Chaîne de caractères | Clé de hachage (md5) pré-calculée sur le contenu du fichier.  **Cette propriété est disponible en lecture seulement**. |
| Métadonnées | Variant | Données additionnelles stockées avec le fichier.  **Cette propriété est disponible en lecture seulement**. |
| Nom | Chaîne de caractères | Nom du fichier.  **Cette propriété est disponible en lecture seulement**. |
| Taille | Entier | Taille du fichier en octets.  **Cette propriété est disponible en lecture seulement**. |
| TailleChunk | Entier | Taille des morceaux du fichier.  **Cette propriété est disponible en lecture seulement**. |
| TypeContenu | Chaîne de caractères | Type du contenu au format MIME.  **Cette propriété est disponible en lecture seulement**. |
