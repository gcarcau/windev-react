# Maintenance de l'analyse

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

L'éditeur d'analyses permet d'effectuer plusieurs opérations de maintenance sur l'analyse affichée sous l'éditeur.
Pour accéder aux opérations de maintenance, sous le volet "Analyse", dans le groupe "Analyse", déroulez "Maintenance".

## Liste des rubriques avec règle d'anonymisation

Pour lister les rubriques anonymisées depuis l'éditeur d'analyses :

1. Dans l'éditeur d'analyses, sous le volet "Analyse", dans le groupe "Analyse", déroulez "Maintenance" et sélectionnez "Liste des rubriques avec règle d'anonymisation".
2. La fenêtre qui s'affiche liste les différentes rubriques anonymisées par fichier, ainsi que la règle d'anonymisation utilisée.

Pour plus de détails sur l'anonymisation, consultez [Anonymisation automatique des données](9000215.md).

## Modifier la casse du nom des fichiers et des rubriques

Pour modifier la casse des noms de fichiers :

1. Dans l'éditeur d'analyses, sous le volet "Analyse", dans le groupe "Analyse", déroulez "Maintenance" et sélectionnez "Modifier la casse du nom des fichiers".
2. Dans la fenêtre qui s'affiche, sélectionnez :
  - le type de casse à appliquer : minuscule, majuscule ou première lettre en majuscule.
  - les noms de fichiers à modifier.
3. Validez : la modification est immédiatement réalisée pour les descriptions de fichiers sélectionnées.

Pour modifier la casse des noms de rubriques :

1. Dans l'éditeur d'analyses, sous le volet "Analyse", dans le groupe "Analyse", déroulez "Maintenance" et sélectionnez "Modifier la casse du nom des rubriques".
2. Dans la fenêtre qui s'affiche, sélectionnez :
  - le type de casse à appliquer : minuscule, majuscule ou première lettre en majuscule.
  - pour chaque fichier, les noms de rubriques à modifier.
3. Validez : la modification est immédiatement réalisée pour les descriptions de rubriques sélectionnées.
