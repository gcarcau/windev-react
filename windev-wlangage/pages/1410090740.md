# EnModeRecyclage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Identifie si le mode "Recyclage des sessions prélancées" est activé dans les options du projet.
Remarque : Le mode "Recyclage des sessions prélancées" est disponible uniquement pour les Webservices. Ce mode correspond à l'utilisation spécifique des sessions prélancées. Pour plus de détails, consultez [Les sessions prélancées](1000019485.md).

## Exemple

```wlangage
SI EnModeRecyclage() ALORS
	// Remise à zéro des variables.
	bAuthentifié = Faux
FIN
```

## Syntaxe

```wlangage
<Résultat> = EnModeRecyclage()
```

`<Résultat>` *Booléen*
> - Vrai si le mode "Recyclage des sessions prélancées" est activé dans les options du projet.
> - Faux dans le cas contraire.

## Remarques

### Disponibilité de la fonction
La fonction **EnModeRecyclage** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **EnModeRecyclage** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.

### Exécution des traitements contenant des erreurs de compilation
Par défaut, le mécanisme de sécurité du WLangage se déclenche uniquement si la ligne contenant l'erreur de compilation est exécutée.
Par exemple, si une fonction interdite dans le produit en cours est présente dans une boucle SI, le mécanisme de sécurité du WLangage se déclenchera uniquement si la ligne contenant cette fonction s'exécute.
