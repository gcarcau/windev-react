# Constantes OBEX

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

| Constante | Description | Utilisée par la fonction |
| --- | --- | --- |
| **obexBluetooth** | Transport des données effectué par Bluetooth | [OBEXConnecte](1000017153.md) |
| **obexInfraRouge** | Transport des données effectué par Infrarouge | [OBEXConnecte](1000017153.md) |
| **obexListeDétaillée** | Liste les fichiers OBEX sous forme détaillée :  <Nom du fichier 1 + TAB + <Type 1 + TAB + <Taille en octets 1 + TAB + <Permissions 1 + TAB + <Date de modification 1 + TAB + <Date de création 1 + TAB + <Date d'accès 1 + RC + ... | [OBEXListeFichier](1000017148.md) |
| **obexListeRépertoire** | Liste les fichiers et les répertoires OBEX. | [OBEXListeFichier](1000017148.md) |
| **obexListeSimple** | Liste les fichiers OBEX sous forme simple :  <Nom du fichier 1 + TAB + <Type 1 + RC + ... <Nom du fichier N + TAB + <Type N où <Type correspond à "F" si l'élément est un fichier, et "D" si l'élément est un répertoire. | [OBEXListeFichier](1000017148.md) |
