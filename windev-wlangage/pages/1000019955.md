# Fonctions de gestion du champ Carte

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion du champ Carte (syntaxe préfixée)](1000022419.md)).
Les fonctions de gestion des champs Carte sont les suivantes :

| [CarteAffichePopup](1000025553.md) | Ouvre la popup d'un marqueur affiché dans un champ Carte. |
| --- | --- |
| [CarteAffichePosition](1000019787.md) | Centre la carte affichée dans un champ Carte sur une position géographique ou un lieu donné. |
| [CarteAfficheZone](1000025535.md) | Déplace la carte affichée dans le champ Carte pour que la zone géographique spécifiée soit entièrement visible dans le champ. |
| [CarteAjouteForme](1000025509.md) | Ajoute une nouvelle forme (polygone, ligne, cercle) sur la carte affichée dans un champ Carte. |
| [CarteAjouteImage](1000025532.md) | Ajoute une nouvelle image sur la carte affichée dans un champ Carte. |
| [CarteAjouteItinéraire](1000020383.md) | Ajoute un itinéraire sur un champ Carte. |
| [CarteAjouteMarqueur](1000019794.md) | Ajoute un nouveau marqueur sur une carte affichée dans un champ Carte. |
| [CarteChangeStyle](1000025556.md) | Modifie le style de la carte affichée dans le champ Carte. A partir de la version 2025 Update 2, cette fonction n'est plus disponible. La gestion des styles de carte a été modifiée par Google. Désormais, il est nécessaire de définir les styles des cartes dans la plateforme Google puis d'utiliser la fonction [CarteIdentifiantGgl](1410091136.md) pour gérer les styles des cartes. |
| [CarteConfigureAPIGgl](1000021611.md) | Déclare des paramètres supplémentaires pour le champ Carte qui seront transmis à l'API Google. |
| [CarteDistanceItinéraire](1000021614.md) | Calcule la distance d'un itinéraire dans un champ Carte. |
| [CarteExécuteJS](1000021615.md) | Exécute du code natif de l'API Google Maps dans un champ Carte en Javascript. |
| [CarteFermePopup](1000025554.md) | Ferme la popup d'un marqueur affichée dans le champ Carte. |
| [CarteFinDéplacement](1000019949.md) | Arrête le suivi du déplacement de l'appareil dans un champ Carte. |
| Nouveauté 2025 [CarteIdentifiantGgl](1410091136.md) | Renvoie ou modifie le style de la carte affichée dans le champ Carte. Ce style correspond à un ID de carte défini dans la console Google Cloud. **Cette fonction est une nouveauté disponible à partir de la version 2025 Update 2.** _(Android)_ Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3. |
| [CarteInfoPosition](1000019951.md) | Renvoie les coordonnées en pixel du point d'un champ Carte correspondant à une position géographique (latitude et longitude). |
| [CarteInfoXY](1000019950.md) | Renvoie la position géographique (latitude et longitude) correspondant à un point d'un champ Carte. |
| [CarteLicenceGgl](1000021299.md) | Indique la clé de licence "Google Maps API" à utiliser dans les champs Carte (de WINDEV ou WEBDEV). |
| [CarteLimiteZone](1000025537.md) | Limite la zone géographique affichée dans le champ Carte. |
| [CarteModifieForme](1000025511.md) | Modifie une forme dessinée sur la carte affichée dans un champ Carte. |
| [CarteModifieImage](1000025533.md) | Modifie une image dessinée sur la carte affichée dans un champ Carte. |
| [CarteModifieMarqueur](1000019796.md) | Modifie un marqueur affiché dans un champ Carte. |
| [CartePopupAffichée](1000025555.md) | Permet de savoir si la popup d'un marqueur du champ Carte est affichée. |
| [CarteRécupèreImage](1000022376.md) | Récupère l'image d'une carte affichée dans un champ Carte. Les marqueurs et les itinéraires affichés sur cette carte seront également présents dans l'image. |
| [CarteRécupèreObjetJS](1000021474.md) | Retourne l'instance de l'API d'un champ Carte. |
| [CarteRécupèrePosition](1000019790.md) | Renvoie la position géographique du point situé au centre de la carte actuellement affiché dans un champ Carte. |
| [CarteRécupèreStyle](1000025557.md) | Renvoie le style utilisé par la carte affichée dans le champ Carte. A partir de la version 2025 Update 2, cette fonction n'est plus disponible. La gestion des styles de carte a été modifiée par Google. Désormais, il est nécessaire de définir les styles des cartes dans la plateforme Google puis d'utiliser la fonction [CarteIdentifiantGgl](1410091136.md) pour gérer les styles des cartes. |
| [CarteSuitDéplacement](1000019953.md) | Affiche la position courante de l'appareil dans un champ Carte et met à jour cette position durant son déplacement. |
| [CarteSupprimeForme](1000025510.md) | Supprime une forme dessinée sur la carte affichée dans un champ Carte. |
| [CarteSupprimeImage](1000025534.md) | Supprime une image dessinée sur la carte affichée dans un champ Carte. |
| [CarteSupprimeItinéraire](1000020384.md) | Supprime un itinéraire d'un champ Carte. |
| [CarteSupprimeMarqueur](1000019795.md) | Supprime un marqueur d'une carte affichée par un champ Carte. |
| [CarteSupprimeTout](1000019952.md) | Supprime dans un champ Carte :   - tous les marqueurs, - toutes les formes, - toutes les images. |

Les types de variables manipulés par le champ Carte ou ses fonctions sont les suivants :

| [CarteCercle](1000025504.md) | Le type **CarteCercle** permet de définir les caractéristiques d'une forme de type cercle à dessiner sur la carte affichée dans un champ Carte. |
| --- | --- |
| [CarteImage](1000025523.md) | Le type **CarteImage** permet de définir les caractéristiques d'une image à dessiner sur la carte affichée dans un champ Carte. |
| [CartePolygone](1000025476.md) | Le type **CartePolygone** permet de définir les caractéristiques d'une forme de type polygone à dessiner sur la carte affichée dans un champ Carte. |
| [CartePolyligne](1000025489.md) | Le type **CartePolyligne** permet de définir les caractéristiques d'une ligne composée de plusieurs segments à dessiner sur la carte affichée dans un champ Carte. |
| [Marqueur](1000019940.md) | Le type **Marqueur** permet de définir les caractéristiques d'un marqueur à placer sur une carte affichée dans un champ Carte. |
| [MarqueurImage](1000025796.md) | Le type **MarqueurImage** permet personnaliser l'image associée à un marqueur ou à un cluster de marqueurs affiché dans le champ Carte. |
