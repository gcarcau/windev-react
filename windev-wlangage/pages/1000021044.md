# Graphe de type "Pourcentage imagé"

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

## Présentation

Le graphe "Pourcentage imagé" est un graphe qui illustre visuellement des données sous forme de pourcentages, à l'aide d'une forme illustrative : bouteille, personne, etc.

## Caractéristiques d'un graphe Pourcentage imagé

Dans ce graphe :

**1.** **Titre du graphe.**
Les caractéristiques du titre du graphe sont saisies dans l'onglet "Détail" de la description du champ (bouton "Editer le titre du graphe").
Il est possible de définir le titre du graphe, sa position et son style.

**2.** **Image utilisée pour les valeurs**

- L'image est définie par programmation via la fonction [grPIImage](1410090782.md). Elle peut correspondre à une image d'un format quelconque. Une image vectorielle est conseillée.
- Une seule image peut être utilisée par graphe

**3.** **Portion du graphe**
A chaque niveau, les valeurs affichées représentent une portion, correspondant à la valeur de la donnée. Par défaut, la valeur maximale des données affichées dans le graphe est utilisée pour calculer le pourcentage correspondant à chaque portion. Il est possible de fixer une valeur maximale avec la fonction [grPIValeurMaximale](1410090786.md).

**4.** **Bulle d'aide**
La valeur des données survolées à la souris s'affiche dans une bulle.

**5.** **Légende du graphe.**
Les caractéristiques de la légende sont saisies dans l'onglet "Détail" de la description du champ (bouton "Editer la légende du graphe"). Il est possible de définir sa position et son style.

Autres caractéristiques :

- Les graphes de type "Pourcentage imagé" sont uniquement des graphes non interactifs.
- Les étiquettes et pourcentages des valeurs ne sont pas affichables.
