# <Variable Connexion>.ModifieGroupe (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Modifie les informations du groupe en fonction des éléments présents dans [les variables de gestion de groupe](3044315.md) correspondantes.

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion

// Ouverture de la connexion
MaConnexion.OuvreConnexion()
...
// Modification des membres du groupe
HGroupe.Utilisateurs = "Flo" + RC + "Julie" + RC + "Luc"
// Modification du groupe
SI MaConnexion.ModifieGroupe("TESTEURS") = Vrai ALORS
	Info("Groupe modifié")
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.ModifieGroupe(<Groupe>)
```

`<Résultat>` *Booléen*
> - Vrai si le groupe a été modifié,
> - Faux en cas d'erreur. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle un groupe doit être modifié.
`<Groupe>` *Chaîne de caractères*
> Nom du groupe dont on veut modifier les caractéristiques.

## Remarques

### Droits nécessaires pour modifier un groupe
Pour modifier un groupe (différent de celui de l'utilisateur en cours) , il est nécessaire de posséder le droit de visualisation des utilisateurs (constante *hDroitVisualisationUtilisateur*). Dans le cas contraire, la fonction **<Variable Connexion>.ModifieGroupe** renverra Faux et le message d'erreur sera "Groupe inconnu".
Pour modifier le nom d'un groupe, il est nécessaire de posséder le droit de visualisation des utilisateurs (constante *hDroitVisualisationUtilisateur*) et le droit de gestion des utilisateurs (constante *hDroitGestionUtilisateur*).

Remarque : Ces constantes sont utilisées dans les fonctions [<Variable Connexion>.InfoDroitServeur](1000022668.md) et [<Variable Connexion>.ModifieDroitServeur](1000022710.md).

### Gestion des droits
Il est possible de donner des droits à un groupe grâce aux fonctions :

- [<Variable Connexion>.ModifieDroitBaseDeDonnées](1000022707.md) : permet de donner des droits sur une base de données.
- [<Variable Connexion>.ModifieDroitFichier](1000022709.md) : permet de donner des droits sur un fichier de données.
- [<Variable Connexion>.ModifieDroitServeur](1000022710.md) : permet de donner des droits sur un serveur.

Pour plus de détails sur la gestion des droits, consultez [Gestion des droits en HFSQL Client/Serveur](3044333.md).
