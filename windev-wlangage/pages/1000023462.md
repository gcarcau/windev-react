# TableurRécupèreInfoTri (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Renvoie différentes informations sur le tri effectué dans un champ Tableur.

## Exemple

```wlangage
// Montre la zone qui va être triée
sSel est chaîne
sSel = TableurRécupèreInfoTri(TBLR_Tableur, tblrInfoTriSélection)
SI sSel = "" ALORS
	RETOUR // non triable
FIN
sMin est une chaîne = ExtraitChaîne(sSel, 1, ":")
sMax est une chaîne = ExtraitChaîne(sSel, 2, ":")

// Sélectionne la zone
TableurSelectPlus(TBLR_Tableur, sMin, sMax)
```

## Syntaxe

```wlangage
<Résultat> = TableurRécupèreInfoTri(<Champ Tableur> , <Type d'information>)
```

`<Résultat>` *Chaîne de caractères*
> Information demandée.
`<Champ Tableur>` *Nom de champ*
> Nom du champ Tableur à manipuler.
`<Type d'information>` *Constante de type Entier*
> Information recherchée :
>
> | *tblrInfoTriAvecTitre* | Permet de savoir si la sélection triée par la FAA (Fonctionnalité Automatique de vos Applications) de tri du champ Tableur contient un titre. <Résultat peut correspondre à :   - 1 si la sélection à trier comporte un titre, - 0 dans le cas contraire. |
> | --- | --- |
> | *tblrInfoTriCritères* | Permet de connaître les derniers critères de tri utilisés pour trier le champ Tableur. <Résultat est de la forme :    ```wlangage "<Nom de la colonne1>[;< Option>]" + TAB + "<Nom de la colonne2>" + TAB + ... ```   où :   - <Nom de la colonne est le nom de la colonne triée, - <Option correspond à une des constantes de tri de la fonction [TableurTrieSélection](1000023463.md).   Exemple : "A<Tab>B;3" |
> | *tblrInfoTriSélection* | Permet de connaître la sélection qui sera triée par la FAA (Fonctionnalité Automatique de vos Applications) de tri du champ Tableur. Exemple : "A2:B4".  Remarque : Si la sélection ne permet pas de tri, <Résultat correspond à une chaîne vide (""). |
