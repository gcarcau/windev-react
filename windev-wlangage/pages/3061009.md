# GraveurListe (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Liste les graveurs installés sur le poste en cours.
**Remarques** :

- La fonction [GraveurSélectionne](3061012.md) permet de sélectionner le graveur à utiliser.
- La fonction [GraveurChemin](3061004.md) permet de connaître le lecteur associé au graveur en cours.

## Exemple

```wlangage
// Connaître les graveurs installés
ListeGraveur est une chaîne
ListeGraveur = GraveurListe()
SI ListeGraveur ~= "" ALORS
	Erreur("Aucun graveur n'a été détecté sur ce poste")
	RETOUR
FIN
// Pour visualiser cet exemple en totalité, cliquez sur le lien "Exemples"
```

## Syntaxe

```wlangage
<Résultat> = GraveurListe([<Détail>])
```

`<Résultat>` *Chaîne de caractères*
> Liste des graveurs installés sur le poste en cours, sous la forme :
>
> - **liste détaillée (si le paramètre <Détail> correspond à Vrai)** :
>   ```wlangage
>   <Identifiant du graveur 1> + TAB + <Marque du graveur 1> + TAB + <Modèle du graveur 1> + TAB + <Logiciel intégré du graveur 1> + RC + ...<Identifiant du graveur N> + TAB + <Marque du graveur N> + TAB + <Modèle du graveur N> + TAB + <Logiciel intégré du graveur N>
>   ```
> - **liste non détaillée (si le paramètre <Détail> correspond à Faux**) :
>   ```wlangage
>   <Identifiant du graveur 1> + RC + ... + <Identifiant du graveur N>
>   ```
>
> Où :
>
> - <Identifiant du graveur 1> ... <Identifiant du graveur N> correspondent à l'identifiant des graveurs.
> - <Marque du graveur 1> ... <Marque du graveur N> correspondent à la marque des graveurs.
> - <Modèle du graveur 1> ... <Modèle du graveur N> correspondent au modèle des graveurs.
> - <Logiciel intégré du graveur 1> ... <Logiciel intégré du graveur N> correspondent à la version du logiciel intégré (appelé également "firmware") des graveurs.
>
>
> > _(WEBDEV - Code Serveur)_ Le poste en cours correspond au serveur Web.
`<Détail>` *Booléen optionnel*
> - Vrai pour lister les informations détaillées des graveurs,
> - Faux (par défaut) pour lister uniquement l'identifiant des graveurs.

## Remarques

### Configuration nécessaire

> _(WINDEV)_ La gravure de CD est disponible uniquement sous Windows XP et supérieur. La gravure de DVD est disponible sous Windows Vista, et sous Windows XP en utilisant la mise à jour KB932716 pour Windows XP (cette mise à jour doit être téléchargée depuis le site de Microsoft et installée car elle n'est pas prise en compte par le mécanisme de Live Update).

> _(WEBDEV - Code Serveur)_ La gravure de CD et DVD sera réalisée sur le serveur Web. Pour graver des CD ou des DVD, le serveur doit être sous Windows XP ou supérieur. Pour graver des CD sous Windows 2003 Serveur, il est nécessaire d'activer le service de gravure IMAPI (nommée "Service COM de gravage de CD IMAPI"). Pour graver des DVD sous Windows 2003 Serveur, il est nécessaire d'installer en plus la mise à jour KB932716.

**Composante : wd300grv.dll**
