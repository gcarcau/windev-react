# LibelléHTML (Propriété)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

La propriété **LibelléHTML** permet de manipuler un libellé sous forme de code HTML. Cette propriété est utilisable sur :

- les champs d'une page. Pour plus de détails, consultez l'aide de la propriété [LibelléHTML](1000020922.md).
- une variable de type [Jeton](1000023942.md).
- une variable de type [diagTexte](1410088393.md).
