# <Variable Connexion>.InfoTâche (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie les caractéristiques d'une tâche planifiée dans une variable de type [hTâchePlanifiée](1000017448.md). Il est par exemple possible de lire certaines caractéristiques de la tâche planifiée pour les modifier par la suite avec la fonction [<Variable Connexion>.ModifieTâche](1000022722.md).

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion

MaTâche est une hTâchePlanifiée
// Récupération des caractéristiques de la tâche planifiée
MaTâche = MaConnexion.InfoTâche(IDTâche)
// Modification de la tâche planifiée
MaTâche.Heure = SAI_Heure.Heure + 1
MaConnexion.ModifieTâche(IDTâche, MaTâche)
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.InfoTâche(<Tâche planifiée>)
```

`<Résultat>` *Variable de type hTâchePlanifiée*
> Variable de type [hTâchePlanifiée](1000017448.md) contenant les caractéristiques de la tâche planifiée spécifiée.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle une tâche doit être manipulée.
`<Tâche planifiée>` *Entier*
> Identifiant de la tâche planifiée renvoyé par les fonctions [<Variable Connexion>.AjouteTâche](1000022645.md) et [<Variable Connexion>.ListeTâche](1000022700.md).

## Remarques

- Pour vérifier l'existence d'une tâche, utilisez la fonction [<Variable Connexion>.ListeTâche](1000022700.md) : il suffit de vérifier si l'identifiant de la tâche est présent parmi les tâches renvoyées par la fonction [<Variable Connexion>.ListeTâche](1000022700.md).
- Pour récupérer les caractéristiques d'une tâche planifiée, il est nécessaire de posséder le droit de connexion (constante *hDroitConnexion* ou *hDroitConnexionCryptée*) sur la base de données contenant la procédure stockée.
