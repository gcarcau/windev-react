# Exécutable (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows)

La propriété **Exécutable** permet de connaître et de modifier l'exécutable à manipuler. Cette propriété est utilisée par :

- une variable de type [Processus](1000018696.md).
- Nouveauté 2025
   une variable de type [Commande](1410090491.md).
