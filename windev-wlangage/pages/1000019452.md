# Fonctions de gestion des images

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des images (syntaxe préfixée)](1000023882.md)).
Différentes fonctions de gestion des images sont disponibles :

- Les fonctions spécifiques au Web permettant de manipuler les images (notamment les fonctions de gestion de défilement d'images).
- Les fonctions de gestion des images dans les champs Image.

| [ImageArrêteDéfilement](1000019428.md) | Arrête le défilement automatique des images. |
| --- | --- |
| [ImageCalqueVisible](1000023504.md) | Permet de rendre visible ou invisible un calque d'une image de type WDPIC. |
| [ImageDernier](1000019432.md) | Affiche la dernière image du défilement. |
| [ImageLanceDéfilement](1000019427.md) | Lance le défilement automatique des images. |
| [ImageOccurrence](1000019434.md) | Renvoie le nombre total d'images prises en compte par le défilement. |
| [ImagePositionDéfilement](1000019433.md) | Retourne l'image affichée. |
| [ImagePosX](3045003.md) | Renvoie la position horizontale (X) du curseur de souris par rapport au champ Image considéré. |
| [ImagePosY](3045001.md) | Renvoie la position verticale (Y) du curseur de souris par rapport au champ Image cliquable considéré. |
| [ImagePrécédent](1000019430.md) | Affiche l'image précédente du défilement. |
| [ImagePremier](1000019429.md) | Affiche la première image du défilement. |
| [ImageSuivant](1000019431.md) | Affiche l'image suivante du défilement. |
| [ImageZone](3045002.md) | Renvoie le numéro de la zone de l'image cliquée par l'internaute. |
