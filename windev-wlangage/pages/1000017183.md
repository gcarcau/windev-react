# Fonctions SAP

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Ces fonctions permettent d'utiliser les fonctions / BAPI d'un serveur SAP :

| [SAPConnecte](1000017120.md) | Connecte un système SAP R/3 à partir des informations données dans la [structure SAP](1000017184.md). |
| --- | --- |
| [SAPDéconnecte](1000017121.md) | Déconnecte un système SAP R/3. |
| [SAPExécute](1000017122.md) | Appelle une fonction ou BAPI synchrone sur un système SAP. |

## Liste des exemples associés :

| [image: Les fonctions SAP] | Exemples unitaires (WINDEV) : Les fonctions SAP     [ + ] Utilisation des fonctions WLangage SAPXxx. Ces fonctions permettent d'utiliser les BAPI SAP nativement dans WINDEV et dans WEBDEV. Cela permet donc d'accéder à vos données SAP directement depuis vos applications WINDEV. |
