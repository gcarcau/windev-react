# Page (Propriété)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

La propriété **Page** permet de manipuler une page. Cette propriété est utilisable sur :

- une variable de type [pdfSignature](1000022255.md).
- une variable de type [pdfDocument](1000024909.md).
- le champ Page WEBDEV. Cette propriété permet de manipuler depuis la fenêtre, la page chargée dans le champ Page WEBDEV. Pour plus de détails, consultez [Page](1410089371.md).
