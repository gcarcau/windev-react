# <Variable FichierDisque>.Taille (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Renvoie la taille d'un fichier en octets.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Java, Code Utilisateur (MCU), Ajax)_ // Ouverture d'un fichier externe
MonFichierTxt est un FichierDisque
ResTaille est un entier
SI MonFichierTxt.Ouvre("C:\MesRépertoires\Fichier.txt", foLectureEcriture) ALORS
 // Taille d'un fichier
 ResTaille = MonFichier.Taille()
FIN

## Syntaxe

#### Connaître la taille d'un fichier en fonction de son chemin

```wlangage
<Résultat> = <Chemin du fichier>.Taille()
```

`<Résultat>` *Entier*
> - Taille du fichier en octets,
> - -1 en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
>
> Lors de la manipulation de fichiers de plus de 2 Go, <Résultat> doit correspondre à un entier sur 8 octets.
`<Chemin du fichier>` *Variable de type FichierDisque*
> Nom de la variable de type [FichierDisque](1410088883.md) initialisée avec la fonction [<Variable FichierDisque>.Ouvre](1410090197.md), [<Variable FichierDisque>.Crée](1410090211.md) ou [<Variable FichierDisque>.OuvreFichierTemp](1410090203.md).

## Remarques

### Gestion des erreurs
La fonction **<Variable FichierDisque>.Taille** génère une erreur dans les cas suivants :

- le fichier spécifié n'existe pas,
- le nom du fichier spécifié est invalide.

**Remarque** : la fonction **<Variable FichierDisque>.Taille** ne fonctionne pas sur les fichiers cachés.
