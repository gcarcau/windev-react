# Fonctions Java

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Ces fonctions permettent d'exécuter simplement du code Java :

| [JavaCharge](3048001.md) | Indique l'emplacement des classes de l'utilisateur nécessaires à l'exécution de l'application ou de l'applet Java. |
| --- | --- |
| [JavaExécute](3048003.md) | Lance une application ou une applet Java en appelant la méthode "Main" d'une classe Java donnée. |
| [JavaExécuteFonction](3048004.md) | Lance une fonction statique spécifique d'une classe Java donnée. |
