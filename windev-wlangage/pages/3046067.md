# iRAZ (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Ré-initialise les paramètres d'impression (marges, police, format du papier, orientation, ...) mémorisés dans la librairie d'impression.

## Exemple

```wlangage
iRAZ()
```

## Syntaxe

```wlangage
iRAZ()
```

## Remarques

La fonction **iRAZ** doit être utilisée pour modifier les paramètres d'impression en cours de programme lorsque les fonctions [iConfigure](3046072.md) et [iParamètre](3046008.md) ne peuvent pas être utilisées.

**Composante : wd300prn.dll**
