# Fonctions de gestion des ports série et parallèle

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android)

| [sDansFileEntrée](3062004.md) | Récupère le nombre d'octets en attente dans le buffer d'entrée du port série ou du port infrarouge spécifié. |
| --- | --- |
| [sDansFileSortie](3062005.md) | Récupère le nombre d'octets en attente de transfert dans le buffer de sortie du port série, du port parallèle ou du port infrarouge spécifié. |
| [sEchap](3062006.md) | Lance diverses fonctions agissant directement sur les bits du port série, du port parallèle ou du port infrarouge, indépendamment du protocole de communication. |
| [sEcrit](3062009.md) | Écrit une chaîne de caractères dans le buffer de sortie du port série, du port parallèle ou du port infrarouge spécifié. |
| [sEvénement](3062014.md) | Branche un événement sur un port série. |
| [sFerme](3062010.md) | Ferme le port série, le port parallèle ou le port infrarouge spécifié. |
| [sFinEvénement](3062008.md) | Débranche la détection d'un événement sur un port série. |
| [sFixeParamètre](3062011.md) | Fixe ou modifie les paramètres de configuration du port série, du port parallèle ou du port infrarouge spécifié. |
| [sListePort](1000025980.md) | Renvoie la liste des noms des ports séries et des ports parallèles présents sur la machine. |
| [sLit](3062012.md) | Lit une chaîne de caractères dans le buffer d'entrée du port série spécifié. |
| [sOuvre](3062013.md) | Ouvre et initialise :  - soit un port série. - soit un port parallèle. - soit un port infrarouge. |

Autres fonctions liées :
