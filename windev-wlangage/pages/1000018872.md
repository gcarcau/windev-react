# SysMiniatureSupprimeBouton (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Supprime un des boutons présents dans la miniature de l'application dans la barre des tâches.

## Exemple

```wlangage
// Supprime le bouton au rang 3
SysMiniatureSupprimeBouton(3)
```

## Syntaxe

```wlangage
<Résultat> = SysMiniatureSupprimeBouton(<Numéro du bouton>)
```

`<Résultat>` *Booléen*
> - Vrai si le bouton a été supprimé,
> - Faux dans le cas contraire.
`<Numéro du bouton>` *Entier*
> Rang du bouton à supprimer (compris entre 1 et 7). Lors de l'ajout d'un bouton, la fonction [SysMiniatureAjouteBouton](1000018871.md) renvoie le rang du bouton ajouté.

## Remarques

- Lorsqu'un bouton est supprimé, les rangs des boutons suivants sont modifiés. Par exemple, si le bouton de rang 4 est supprimé, le bouton de rang 5 devient après cette suppression le bouton de rang 4.
- Il est possible de supprimer tous les boutons liés à une miniature grâce à la fonction [SysMiniatureSupprimeTout](1000018873.md).
