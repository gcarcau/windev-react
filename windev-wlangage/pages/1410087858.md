# Qualité (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Qualité** permet de connaître et de définir le niveau de qualité d'un élément. Cette propriété est utilisable sur :

- une variable de type [VoixDeSynthèse](1000025986.md).
- une variable de type [pdfParamètre](1410087857.md).
