# zipListeFichier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie la liste des fichiers présents dans une archive.
Nouveauté 2025

> _(WINDEV, WEBDEV - Code Serveur, Windows, Linux, iPhone/iPad)_ Le format gzip (extension .gz) est désormais géré.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ MonArchive est une zipArchive
// Ouverture d'une archive
ResOuvreArchive = zipOuvre(MonArchive, "C:\Temp\MonArchive.ZIP")
SI ResOuvreArchive = 0 ALORS
 ...
 // Renvoie la liste des fichiers de l'archive
 UneListeDeFichiers = zipListeFichier(MonArchive)
 // Affichage des fichiers dans un champ Liste
 ListeAjoute(LISTE_FichierZip, UneListeDeFichiers)
 ...
FIN

## Syntaxe

```wlangage
<Résultat> = zipListeFichier(<Archive>)
```

`<Résultat>` *Chaîne de caractères*
> Liste des fichiers présents dans l'archive. Cette liste utilise le format suivant :
>
>
> ```wlangage
> <Chemin mémorisé> + RC + <Chemin mémorisée2> + RC + ...
> ```
>
>
>
> <Chemin mémorisé> correspond au nom et au chemin du fichier (si le chemin du fichier a été mémorisé lors de l'ajout du fichier dans l'archive).
`<Archive>` *Chaîne de caractères ou variable de type zipArchive*
> Nom de l'archive à manipuler.
> Ce nom peut correspondre :
>
> - soit au nom d'une archive défini avec la fonction [zipOuvre](3082044.md) ou [zipCrée](3082003.md).
> - soit au nom d'une variable de type [zipArchive](1000018679.md).
>    Les variables de type [zipArchive](1000018679.md) ne sont pas disponibles en JAVA.

## Remarques

### Rappel

- Seules les archives au format ZIP, gzip, TAR et TGZ (TAR.GZ) sont disponibles.
- Seules les archives au format ZIP sont disponibles.

### Nombre de fichiers dans une archive
Le nombre de fichiers présents dans une archive peut être obtenu avec la fonction [zipNbFichier](3082035.md).

### Chemin mémorisé
Le tableau ci-dessous présente les chemins mémorisés dans l'archive en fonction :

- du chemin d'accès du fichier,
- de la portion mémorisée du chemin.

Le répertoire en cours est : "C:\Temp".

| **Fonction zipAjouteFichier** | **Localisation du fichier** | *zipAucun* | *zipRépertoire* | *zipDisque* |
| --- | --- | --- | --- | --- |
| zipAjouteFichier("Archi", "Fichier.txt") | C:\Temp\Fichier.txt | Fichier.txt | Fichier.txt | Fichier.txt |
| zipAjouteFichier("Archi", "Donnée\Fichier.txt") | C:\Temp\Donnée\Fichier.txt | Fichier.txt | Donnée\Fichier.txt | Donnée\Fichier.txt |
| zipAjouteFichier("Archi", "D:\Donnée\Fichier.txt") | D:\Donnée\Fichier.txt | Fichier.txt | Donnée\Fichier.txt | D:\Donnée\Fichier.txt |

**Remarque** : Si la constante *zipDisque* est utilisée, le format WDZ mémorise le chemin complet du fichier (lettre du lecteur comprise) alors que le format ZIP ne mémorise pas la lettre du lecteur.
