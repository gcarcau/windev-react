# Propriétés associées aux options d'un champ Interrupteur à bascule

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Les deux options d'un champ Interrupteur à bascule peuvent être manipulées en WLangage dans une fenêtre ou une page avec les propriétés suivantes.

## Propriétés disponibles dans une fenêtre

**Propriétés disponibles dans une fenêtre**

Les différentes propriétés associées aux options des champs Interrupteur à bascule sont les suivantes :

| [Bulle](2510005.md) | La propriété **Bulle** permet de connaître et de modifier le texte affiché dans une bulle d'aide. Cette bulle d'aide peut être associée :   - à un champ d'une fenêtre ou d'une page, - Nouveauté Abonnement  à un champ d'un état. Dans ce cas, la bulle d'aide sera visible uniquement dans le visualisateur de rapports.  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3. |
| --- | --- |
| [Couleur](2510071.md) | La propriété **Couleur** permet de connaître ou modifier la couleur de la police de :  - une variable de type Police. - un texte d'un champ Libellé ou calculé d'un état. - un texte d'un champ d'une fenêtre. - un texte d'un champ d'une page. |
| [CouleurFond](2510022.md) | La propriété **CouleurFond** permet de gérer la couleur de fond d'un champ, d'une fenêtre, d'une page ou d'un bloc d'un état. |
| [Etat](2510039.md) | La propriété **Etat** permet de connaître et de modifier l'état d'affichage d'un élément. |
| [Grisé](1000019648.md) | La propriété **Grisé** permet de :   - Savoir si un champ, un groupe de champs ou une fenêtre est grisé ou non. - Griser ou dégriser un champ, un groupe de champs ou une fenêtre. |
| [Hauteur](2510050.md) | La propriété **Hauteur** permet de connaître et modifier la hauteur :  - d'un champ ou d'un bloc dans un état. - d'un champ (présent dans une fenêtre), d'une fenêtre, d'une ligne d'un champ Table ou Liste (y compris Liste image), d'une option d'un champ Sélecteur ou Interrupteur, d'un haut ou d'un bas de rupture d'un champ Table ou d'un champ Zone répétée. - d'un champ (présent dans une page), d'un haut ou bas de rupture d'un champ Table ou Zone répétée. Le champ peut être superposable ou non. - d'une cellule de rupture d'un champ Table ou d'un champ Zone répétée. |
| [Image](2510034.md) | La propriété **Image** permet de connaître et de modifier l'image de fond d'un champ ou d'un bloc. |
| [Libellé](2510053.md) | **Dans une base de données**, la propriété **Libellé** permet de :  - Connaître le libellé associé à une rubrique d'un fichier de données. - Connaître le libellé associé à un fichier de données. - Connaître et modifier le libellé d'une connexion.   **Dans un état**, la propriété **Libellé** permet de :   - Connaître le texte d'un champ Libellé ou Lien. - Modifier le texte d'un champ Libellé ou Lien.   **Dans une fenêtre ou une page**, la propriété **Libellé** permet également de :   - Connaître et modifier le libellé d'un champ présent dans une fenêtre ou une page. - Connaître et modifier le libellé d'une option de menu. - Connaître et modifier le titre d'une fenêtre ou d'une page. - Connaître le contenu d'un champ chemin de navigation. |
| [Markdown](1410089000.md) | La propriété **Markdown** permet de gérer le markdown dans les champs d'une fenêtre ou d'un état. |
| [Nom](2510082.md) | La propriété **Nom** permet de connaître :  - le nom de la police associée à une variable de type Police. - le nom d'un champ, d'un état ou d'un bloc d'un état. - le nom d'un champ, d'un groupe de champs ou d'une fenêtre. - le nom d'un champ, d'un groupe de champs ou d'une page. |
| [NomComplet](2514005.md) | La propriété **NomComplet** permet de connaître le nom complet :  - d'un champ. - d'une fenêtre. - d'une option de menu. - d'une colonne de table. |
| [NuméroAide](2510141.md) | La propriété **NuméroAide** permet de connaître et de modifier le numéro d'aide associé au champ. |
| [SousLibellé](1000017232.md) | La propriété **SousLibellé** permet de connaître et de modifier :   - le libellé secondaire d'une option d'un champ Sélecteur ou Interrupteur. - le libellé secondaire d'un élément d'un champ TreeMap. |
| [TauxParallaxeHauteur](1000021921.md) | La propriété **TauxParallaxeHauteur** permet de connaître et d'indiquer à quelle vitesse un champ est réduit lorsque l'ascenseur de la fenêtre, de la fenêtre interne ou de la page se déplace. |
| [TroisEtats](2510124.md) | La propriété **TroisEtats** permet de :  - Savoir si une option d'un interrupteur gère 3 états ou uniquement 2 états. - Savoir si un champ Arbre utilise des coches à 2 ou 3 états. - Modifier le type d'une option d'un interrupteur : options à 3 états ou à 2 états. |
| [ValeurRenvoyée](2510134.md) | La propriété **ValeurRenvoyée** permet de :  - Connaître et modifier la valeur renvoyée par une fenêtre, une page ou un état. - Connaître et modifier la valeur renvoyée par une option d'un champ Sélecteur. |
| [Visible](2510138.md) | La propriété **Visible** permet de :  - Savoir si un élément est visible. - Rendre un élément visible ou invisible. |

Remarque : Selon la plateforme utilisée, certaines propriétés peuvent ne pas être disponibles. Consultez la page d'aide de la propriété pour plus de détails.
