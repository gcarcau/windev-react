# SysThème (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Renvoie le thème visuel affiché actuellement sur le poste en cours.
Remarque : Ce thème est celui affiché automatiquement par le poste en cours (configuré dans les paramètres de l'appareil). Il ne correspond pas au thème choisi par programmation avec la fonction [ChangeThème](1000025266.md).

## Exemple

```wlangage
// Affichage d'une image claire si le thème sombre est affiché
SI SysThème() = stThèmeSombre ALORS
	IMG_Image = "image_claire.jpg"
FIN
```

## Syntaxe

```wlangage
<Résultat> = SysThème()
```

`<Résultat>` *Constante de type Entier*
> Thème visuel affiché sur le poste en cours :
>
> | *stThèmeClair* | Le thème clair du poste en cours est utilisé. |
> | --- | --- |
> | *stThèmeInconnu* | Le thème utilisé est inconnu. |
> | *stThèmeSombre* | Le thème sombre du poste en cours est utilisé. |

**Composante : wd300dotnet.dll**
