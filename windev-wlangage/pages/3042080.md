# Champ Graphe : Onglet "Détail"

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Quelque soit l'éditeur (fenêtres, pages ou états), l'onglet "Détail" de la fenêtre de description du champ Graphe permet de décrire :

- l'apparence du graphe,
- les caractéristiques du zoom et de la mire,
- l'interactivité du graphe (y compris la mire),
- le titre et la légende,
- les animations et l'image de fond.

## Apparence du graphe

Les caractéristiques d'apparence du graphe sont les suivantes :

- **Barre d'outils** : Cette option permet de paramétrer l'affichage de la barre d'outils associée au champ Graphe. Cette barre d'outils permet à l'utilisateur de définir les caractéristiques d'affichage du graphe. Le bouton "..." permet de définir les différentes options proposées dans la barre d'outils.
- **Adoucir les effets d'escalier (Antialiasing)** : permet d'utiliser l'antialiasing si le GDI+ est installé.
   Cette option n'est pas disponible.
- **Effet de lumière réaliste** : permet d'utiliser un effet de lumière sur le graphe. Si cette option est choisie, le pourcentage de biseau permet de paramétrer l'inclinaison de la lumière.
   Cette option n'est pas disponible.
- **Couleurs de bordure automatiques** : Si cette option est cochée, les couleurs de bordure des séries sont calculées automatiquement.
- **Couleurs dégradées** : Permet d'utiliser des couleurs dégradées dans l'affichage des séries. Le dégradé est par défaut vertical mais il est possible d'utiliser un dégradé horizontal.
- **Afficher aussi les étiquettes superposées** : Cette option permet d'autoriser le chevauchement des étiquettes dans les graphes de type Secteur, Hémicycle, Beignet, ...
   Cette option n'est pas disponible.
- **Afficher les étiquettes à l'extérieur des portions** : Cette option permet de placer les étiquettes en dehors des portions dans les graphes de type Secteur, Hémicycle, Beignet, ...
   Cette option n'est pas disponible.
- **Afficher les valeurs** : Permet d'afficher les valeurs en plus des pourcentages dans les étiquettes. Il est possible de définir le masque d'affichage à utiliser.
  L'option **Valeurs en vertical** permet d'afficher les valeurs verticalement.

## Zoom et mire (non disponible dans les états)

> _(WINDEV, iPhone/iPad)_ Gestion du ZoomL'activation du Zoom permet à l'utilisateur de pouvoir zoomer sur les données affichées dans le graphe.Autoriser le zoom horizontal : permet d'activer uniquement le zoom des valeurs selon l'axe horizontal. L'ascenseur de zoom est placé sous le champ. Autoriser le zoom vertical : permet d'activer uniquement le zoom des valeurs selon l'axe vertical. L'ascenseur de zoom est placé à droite du champ.

> _(WINDEV, iPhone/iPad)_ Gestion de la mireLa mire permet à l'utilisateur de connaître avec précision la valeur pointée. Pour plus de détails, consultez Mire dans un graphe. L'activation de la mire est réalisée via l'option "Activer la mire du graphe".L'option "Mire multiple (courbe et histo. empilés)" permet d'obtenir une mire multiple dans les graphes de type Courbe ou Histogramme.Remarque : La mire est disponible pour les types de graphes suivants : Aire, Bulle, Courbe, Histogramme, MinMax, Radar et Waterfall.

## Titre et légende

Le titre et la légende peuvent être paramétrés dans un champ Graphe.
Le bouton "Editer le titre du graphe" permet d'afficher la fenêtre de description du titre du graphe. Cette fenêtre permet de :

- Saisir si nécessaire le titre du graphe.
- Paramétrer son positionnement. Si un positionnement manuel est choisi, il est possible de déplacer la zone du titre sous l'éditeur.
- Paramétrer le style utilisé pour afficher le titre du graphe.

Le bouton "Editer la légende du graphe" permet d'afficher la fenêtre de description de la légende du graphe. Cette fenêtre permet de :

- Définir le positionnement de la légende.
  Ce positionnement peut être automatique ou manuel.
  Si un positionnement manuel est choisi, il est possible :
  - de déplacer la zone de la légende sous l'éditeur.
  - de choisir la position des libellés (en ligne ou en colonne)
  - d'adapter la taille de la légende au contenu
- Définir l'aspect de la légende : Il est possible d'utiliser un cadre arrondi pour la légende.
- Définir le style de la légende (police, ...).

## Animations et image de fond

> _(WINDEV, Android, iPhone/iPad, WINDEV, WINDEV, Android, iPhone/iPad)_ AnimationsCertains graphes peuvent être animés.
 Pour les graphes 2D, il est possible d'activer ou non les animations. Pour les graphes 3D, plusieurs options peuvent être paramétrées : Zoom avant, Construction progressive, Rotation, Couleurs progressives. L'option "Activer les animations" permet d'animer le graphe.Pour plus de détails sur la gestion des animations dans le champ graphe, consultez Animation d'un champ Graphe.

### Image de fond
L'image de fond sera affichée en fond du graphe.

> _(WINDEV, Android, iPhone/iPad)_ Il est possible d'utiliser le mode 9 images pour cette image.

> _(WEBDEV - Code Serveur, PHP)_ Il est possible de définir : la localisation de l'image. son mode d'affichage.

> _(WEBDEV - Code Serveur, PHP, PHP)_ InteractivitéL'interactivité du champ Graphe permet d'activer : les animationsla mire du graphe. Rappel : La mire permet à l'utilisateur de connaître avec précision la valeur pointée. Pour plus de détails, consultez Mire dans un graphe. Remarques : Pour que l'interactivité soit réelle, il est nécessaire que le navigateur utilisé supporte cette fonctionnalité. Seuls les champs Graphe interactif sont disponibles.
