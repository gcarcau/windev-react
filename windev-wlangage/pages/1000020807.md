# ActionClic (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **ActionClic** permet de définir la procédure exécutée lors du clic sur un élément. Cette propriété est utilisable sur :

- une variable de type [Marqueur](1000019940.md).
- une variable de type [Notification](1000019441.md).
- une variable de type [notificationAction](1000021304.md).
- une variable de type [Toast](1000024638.md).
- une variable de type [CarteCercle](1000025504.md).
- une variable de type [CarteImage](1000025523.md).
- une variable de type [CartePolygone](1000025476.md).
- une variable de type [CartePolyligne](1000025489.md).
