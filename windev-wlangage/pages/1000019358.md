# ToastAffiche (Fonction)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Affiche un message de type "Toast".
Le toast est un message furtif qui apparaît durant quelques secondes à l'écran avant de disparaître avec un effet de fondu sans intervention de l'utilisateur. Un toast ne prend pas le focus, il n'est pas modal et il n'interrompt pas l'exécution de l'application.

L'affichage de toasts est recommandé pour transmettre des informations à l'utilisateur sans bloquer l'exécution de l'application (exemple : affichage d'un message pour indiquer la fin d'un téléchargement).
[image: Message de type toast en Android]
> _(Linux)_ Cette fonction est disponible uniquement pour les sites WEBDEV Linux.

Nouveauté 2025

> _(WINDEV)_ L'affichage par défaut des toasts a été amélioré. Par défaut : un arrondi est automatiquement appliqué aux coins du toast. une marge externe est définie entre le bord du toast et le bord de don parent. l'animation d'ouverture et de fermeture du toast correspond à l'animation définie dans les options du projet (option "Animations des champs", dans l'onglet "Avancé" de la description du projet).

## Exemple

> _(WINDEV, Android, iPhone/iPad)_ MonToast est un Toast
MonToast.Titre = "Le saviez-vous ?"
MonToast.Texte = "Les FAA sont un truc génial."
MonToast.Bouton[1].Libellé = "En savoir plus..."
MonToast.Bouton[1].ActionClic = FoncAide
MonToast.ActionFermeture = clicFerme
ToastAffiche(MonToast)
PROCÉDURE INTERNE FoncAide
 Ouvre("FEN_Aide")
FIN
PROCÉDURE INTERNE clicFerme(nBouton)
 Trace("Clic fermeture, bouton " + nBouton)
FIN

```wlangage
ToastAffiche("Ceci est un message Toast.")
```

```wlangage
ToastAffiche("Ceci est un message Toast.", toastLong, cvMilieu, chCentre, VertClair)
```

ToastAffiche(gPoliceGras() + gPolice("Batang") + gPoliceTaille(18) + ...

## Syntaxe

> _(WINDEV, Android, iPhone/iPad)_ Afficher un toast basé sur une variable de type Toast Masquer les détails
ToastAffiche(<Toast>)

 <Toast> : Variable de type ToastNom de la variable de type Toast décrivant le toast à afficher. Remarque : La variable de type Toast permet de définir de nombreux paramètres.

#### Définir et afficher un toast

```wlangage
ToastAffiche(<Message> [, <Durée d'affichage> [, <Cadrage Vertical> [, <Cadrage Horizontal> [, <Couleur de fond>]]]])
```

`<Message>` *Chaîne de caractères*
> Message à afficher. Ce message peut être multiligne.
`<Durée d'affichage>` *Entier optionnel*
> Constante indiquant la durée d'affichage du message Toast :
>
> | *toastCourt* (Valeur par défaut) | Le message Toast sera affiché pendant une faible période de temps. |
> | --- | --- |
> | *toastLong* | Le message Toast sera affiché pendant une longue période de temps. |
>
>
> **Remarque** : La durée d'affichage exacte dépend de l'appareil utilisé.
`<Cadrage Vertical>` *Entier optionnel*
> Constante indiquant le cadrage vertical du message. Ce cadrage est relatif :
>
> - à l'écran.
> - à la fenêtre.
> - à la page.
>
>
>
> | *cvBas* (Valeur par défaut) | Affichage du message Toast en bas. |
> | --- | --- |
> | *cvHaut* | Affichage du message Toast en haut. |
> | *cvMilieu* | Affichage du message Toast au milieu. |
>
>
>
> > _(Android)_ A partir de Android 11, le positionnement des toasts ne peut plus être personnalisé. Ce paramètre est ignoré.
`<Cadrage Horizontal>` *Entier optionnel*
> Constante indiquant le cadrage horizontal du message. Ce cadrage est relatif :
>
> - à l'écran.
> - à la fenêtre.
> - à la page.
>
>
>
> | *chCentre* (Valeur par défaut) | Affichage du message Toast au centre. _(iPhone/iPad)_ Le toast s'affiche toujours centré horizontalement. |
> | --- | --- |
> | *chDroite* | Affichage du message Toast sur la droite. _(iPhone/iPad)_ Cette constante n'est pas disponible. |
> | *chGauche* | Affichage du message Toast sur la gauche. _(iPhone/iPad)_ Cette constante n'est pas disponible. |
>
>
>
> > _(Android)_ A partir de Android 11, le positionnement des toasts ne peut plus être personnalisé. Ce paramètre est ignoré.
`<Couleur de fond>` *Entier optionnel*
> Couleur de fond utilisée pour l'affichage du message. Ce paramètre peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md).
>
>
> > _(Android)_ Ce paramètre n'est pas disponible.

## Remarques

### Gestion des threads
La fonction **ToastAffiche** peut être appelée depuis un thread WLangage (par exemple pour notifier l'utilisateur d'événements survenus durant l'exécution du thread).

### Appels successifs
Si la fonction **ToastAffiche** est appelée plusieurs fois, chaque toast est affiché lorsque le toast précédent a disparu. Ce comportement peut être modifié en utilisant la propriété **Superposable** de la variable de type [Toast](1000024638.md). Cette propriété permet de retrouver le comportement de la version 24 : les toasts se superposent les uns au-dessus des autres.

> _(iPhone/iPad)_ Si la fonction ToastAffiche est appelée plusieurs fois, seul le dernier appel à la fonction sera pris en compte.
