# Fonctions Widget

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Les fonctions de gestion des Widgets sont les suivantes :

| [WidgetAffiche](1000020647.md) | Rafraîchit l'affichage d'une fenêtre de type Widget. |
| --- | --- |
| [WidgetLanceAppli](1000020648.md) | Lance l'application à laquelle appartient un Widget. |
| [WidgetProcédure](1410087599.md) | Permet de spécifier la procédure qui sera appelée lorsque l'utilisateur effectue un clic dans un Widget iOS 14. |
