# Constantes de gestion des champs Lecteur PDF et des fichiers PDF

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Les constantes utilisées par les fonctions de gestion des champs Lecteur PDF sont les suivantes :

| Constante | Détail | Fonction ou type de variable |
| --- | --- | --- |
| **affAvecCouverture** | Mode d'affichage de la page dans le lecteur PDF utilisé : Considère la première page du fichier PDF comme étant une couverture. La première page est affichée à droite lors d'un affichage en mode 2 pages. | Type [pdfParamètre](1410087857.md) |
| **affAvecDéfilement** | Mode d'affichage de la page dans le lecteur PDF utilisé : Affichage avec défilement : Affiche les pages selon une colonne verticale ininterrompue occupant la largeur d'une page. Le défilement peut être activé pour un affichage 1 page ou 2 pages. | Type [pdfParamètre](1410087857.md) |
| **affDéfaut** | Mode d'affichage de la page dans le lecteur PDF utilisé : Affichage par défaut. | Type [pdfParamètre](1410087857.md) |
| **affDeuxPages** | Mode d'affichage de la page dans le lecteur PDF utilisé : Affichage de deux pages à la fois, côte à côte du ficher PDF dans le lecteur PDF. | Type [pdfParamètre](1410087857.md) |
| **affUnePage** | Mode d'affichage de la page dans le lecteur PDF utilisé : Affichage d'une seule page à la fois du fichier PDF dans le lecteur PDF. Les parties adjacentes ne sont pas affichées. | Type [pdfParamètre](1410087857.md) |
| Nouveauté 2025 **pdfCertificatExpiré** | Le certificat de la signature est expiré.  **Attention** : Cette constante est disponible uniquement à partir de la version 2025 Update 1. | [Paramètres de la procédure utilisée par la fonction PDFVérifieSignatures](1410090989.md) |
| **pdfCoordonnéeX** | Abscisse de la position spécifiée sur la page (exprimée en millimètres). | [LecteurPDFInfoXY](1000025332.md) |
| **pdfCoordonnéeY** | Ordonnée de la position spécifiée sur la page (exprimée en millimètres). | [LecteurPDFInfoXY](1000025332.md) |
| **pdfCouleur** | Gestion de la couleur dans le fichier PDF : Création d'un fichier PDF en couleurs. | Type [pdfParamètre](1410087857.md) |
| Nouveauté 2025 **pdfModifiéAprèsSignature** | Le PDF a été modifié après sa signature.  **Attention** : Cette constante est disponible uniquement à partir de la version 2025 Update 1. | [Paramètres de la procédure utilisée par la fonction PDFVérifieSignatures](1410090989.md) |
| **pdfNiveauGris** | Gestion de la couleur dans le fichier PDF : Création d'un fichier PDF en noir et blanc. | Type [pdfParamètre](1410087857.md) |
| **pdfNuméroPage** | Numéro de la page contenant la position spécifiée. | [LecteurPDFInfoXY](1000025332.md) |
| **pdfOrigineEcran** | Permet de changer l'origine pour le calcul des informations correspondant à une position dans le champ Lecteur PDF. | [LecteurPDFInfoXY](1000025332.md) |
| Nouveauté 2025 **pdfSignatureInvalide** | La signature est invalide.  **Attention** : Cette constante est disponible uniquement à partir de la version 2025 Update 1. | [Paramètres de la procédure utilisée par la fonction PDFVérifieSignatures](1410090989.md) |
| **rotationAntihoraire** | Effectue une rotation à -90 degrés de la page. | [LecteurPDFTournePage](1000023940.md) |
| **rotationHoraire** | Effectue une rotation à 90 degrés de la page. | [LecteurPDFTournePage](1000023940.md) |
| **zoomContenu** | Zoom appliqué par défaut au fichier PDF à son ouverture : Zoom au contenu. | Type [pdfParamètre](1410087857.md) |
| **zoomDéfaut** | Zoom appliqué par défaut au fichier PDF à son ouverture : Zoom par défaut. | Type [pdfParamètre](1410087857.md) |
| **zoomPageEntière** | Zoom appliqué par défaut au fichier PDF à son ouverture : Zoom permettant d'afficher une page entière. | Type [pdfParamètre](1410087857.md) |
| **zoomPleineHauteur** | Zoom appliqué par défaut au fichier PDF à son ouverture : Zoom permettant d'afficher la page entière dans sa hauteur. | Type [pdfParamètre](1410087857.md) |
| **zoomPleineLargeur** | Zoom appliqué par défaut au fichier PDF à son ouverture : Zoom permettant d'afficher la page entière dans sa largeur. | Type [pdfParamètre](1410087857.md) |
| **zoomTailleRéelle** | Zoom appliqué par défaut au fichier PDF à son ouverture : Zoom à 100%/ | Type [pdfParamètre](1410087857.md) |
