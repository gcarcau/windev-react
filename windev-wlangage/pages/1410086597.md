# Fonctions Caméra

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Les fonctions de gestion du champ Caméra sont les suivantes :
| [CaméraAffiche](1410086595.md) | Affiche dans un champ "Caméra" la séquence vidéo actuellement retransmise par une "web caméra" ou par la caméra de l'appareil mobile. _(Android, iPhone/iPad)_ Fonction conservée pour les champs Caméra "Compatibles 26". |
| --- | --- |
| [CaméraArrête](1410086596.md) | Arrête l'affichage ou l'enregistrement d'une séquence vidéo affichée dans un champ Caméra. _(Android, iPhone/iPad)_ Fonction conservée pour les champs Caméra "Compatibles 26". |
| [CaméraArrêteDécodage](1000022449.md) | Arrête le décodage des codes-barres via un champ Caméra. |
| [CaméraCapture](1000022450.md) | Capture la séquence vidéo actuellement retransmise par une "caméra" :  - sous forme d'une image : prend une photo. - sous forme de vidéo : enregistre une vidéo. _(Android, iPhone/iPad)_ Fonction conservée pour les champs Caméra "Compatibles 26". |
| [CaméraChangeDriver](1000022451.md) | Connecte le champ "Caméra" à un driver de capture vidéo spécifique. |
| [CaméraConfigure](1000022452.md) | Permet de configurer le driver de capture vidéo. |
| [CaméraDemandePermission](1000022453.md) | Demande la permission d'utiliser la caméra de l'appareil. |
| [CaméraDémarreDécodage](1000022454.md) | Démarre le décodage des codes-barres dans un champ Caméra. |
| [CaméraEtat](1000022455.md) | Renvoie l'état d'un champ Caméra. _(Android, iPhone/iPad)_ Fonction conservée pour les champs Caméra "Compatibles 26". |
| [CaméraGénèreMiniature](1000022456.md) | Génère une miniature de la photo ou de la vidéo spécifiée. |
| [CaméraLanceAppli](1000022470.md) | Lance l'application caméra native de l'appareil afin d'enregistrer une vidéo ou de prendre une photo. |
| [CaméraListeDriver](1000022457.md) | Liste les drivers de capture vidéo installés sur le poste en cours. |
| [CaméraListeParamètre](1000022458.md) | Liste les valeurs supportées par la caméra de l'appareil pour un paramètre donné. _(Android, iPhone/iPad)_ Fonction conservée pour les champs Caméra "Compatibles 26". |
| [CaméraParamètre](1000022459.md) | Renvoie ou modifie la valeur d'un paramètre de la caméra de l'appareil. _(Android, iPhone/iPad)_ Fonction conservée pour les champs Caméra "Compatibles 26". |
| [CaméraPhoto](1410087225.md) | Prend une photo via un champ Caméra dans une application Android ou iOS. |
| [CaméraVidéoArrête](1410087229.md) | Arrête l'enregistrement d'une vidéo précédemment démarré par la fonction [CaméraVidéoDémarre](1410087227.md). |
| [CaméraVidéoDémarre](1410087227.md) | Démarre l'enregistrement d'une vidéo via un champ Caméra dans une application Android ou iOS. |
