# jsonLecteur (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Le type **jsonLecteur** permet le parcours linéaire d'un document JSON de taille importante avec des performances optimales et une occupation mémoire réduite. Les caractéristiques de ce document JSON peuvent être lues à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

**Attention** : Ce type de variable est disponible uniquement à partir de la version 2025 Update 3.

## Exemple

```wlangage
Lecteur_JSON est un jsonLecteur = JSONOuvreLecteur("fichier.json")
POUR TOUT Lecteur_JSON EN PROFONDEUR
	...
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type jsonLecteur
Les propriétés suivantes peuvent être utilisées pour manipuler un document JSON :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Nom | Chaîne de caractères | - Nom du membre, si l'élément courant est un membre d'un objet. - Chaîne vide ("") si l'élément courant correspond à la racine ou un élément de tableau.   **Cette propriété est disponible en lecture seulement.** |
| Parent | jsonLecteur | Élément parent dans un parcours en profondeur.  **Cette propriété est disponible en lecture seulement.** |
| Profondeur | Entier | Profondeur de l'élément courant. **Cette propriété est disponible en lecture seulement.** |
| SourceJSON | Chaîne de caractères | JSON source correspondant à l'élément courant.  **Cette propriété est disponible en lecture seulement.** |
| Type | Entier | Type de l'élément courant :  - *wlBooléen* : valeur JSON simple booléenne. - *wlChaîneUnicode* : valeur JSON simple chaîne. - *wlEntier* : valeur JSON simple entière. - *wlNull* : valeur JSON simple Null. - *wlNumérique* : valeur JSON simple décimale. - *wlVariantObjet* : objet JSON. - *wlVariantTableau* : tableau JSON. - *wlVide* : lecteur non initialisé.   **Cette propriété est disponible en lecture seulement.** |
| Valeur | Tous types | Valeur si l'élément courant est un type simple (autre que objet ou tableau).  **Cette propriété est disponible en lecture seulement.** |
