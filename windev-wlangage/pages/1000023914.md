# TraceSupprimeTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android) · **Autres** (Procédures stockées)

Vide le contenu de la fenêtre de trace ouverte en parallèle de la fenêtre en cours.

## Exemple

```wlangage
// Vide le contenu de la fenêtre de trace
TraceSupprimeTout()
```

## Syntaxe

```wlangage
TraceSupprimeTout()
```

## Remarques

### Fichier de trace
La trace peut être effectuée dans un fichier dans les cas suivants :

- sous Linux,
- via la fonction [TraceDébut](3013049.md) avec la constante *trFichier*.

Dans ce cas, la fonction **TraceSupprimeTout** supprime le fichier de trace.

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
