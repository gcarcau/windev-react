# Sélectionnée (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Sélectionnée** permet de savoir si un élément est sélectionné et de sélectionner un élément.
Cette propriété est utilisable sur :

- les champs. Pour plus de détails, consultez l'aide de la propriété [Sélectionnée](2510112.md).
- Nouveauté 2025
   une variable de type [pdfOptionChamp](1410090533.md).
