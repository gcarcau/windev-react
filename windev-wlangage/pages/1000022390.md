# iImprimeDoc (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Imprime un document au format "docx".

## Exemple

```wlangage
MonDocument est un Document = "c:\temp\propale.docx"
iDestination(iVisualisateur)
iImprimeDoc(MonDocument)
```

## Syntaxe

#### Imprimer le contenu d'un champ Traitement de texte ou d'une variable de type Document

```wlangage
<Résultat> = iImprimeDoc(<Document>)
```

`<Résultat>` *Booléen*
> - Vrai si le document est valide pour l'impression,
> - Faux dans le cas contraire.
`<Document>` *Variable de type Document ou nom de champ*
> Document à imprimer. Ce document correspond :
>
> - au nom d'un champ Traitement de texte.
> - à une variable de type [Document](1000022461.md).

> _(WINDEV)_ Imprimer le contenu d'un champ Traitement de texte avec redimensionnement Masquer les détails
<Résultat> = iImprimeDoc(<Champ Traitement de texte> [, <Dimensionnement>])

 <Résultat> : BooléenVrai si le document est valide pour l'impression, Faux dans le cas contraire. <Champ Traitement de texte> : Nom de champNom du champ Traitement de texte à manipuler affichant le document à imprimer. <Dimensionnement> : Constante de type EntierTaille d'impression : iHomothétiqueAgrandissement ou réduction homothétique des pages du document afin qu'elles s'adaptent au format de sortie en ignorant les marges physiques.iHomothétiqueSansAgrandissementRéduction homothétique des pages du document afin qu'elles s'adaptent au format de sortie en ignorant les marges physiques. Les pages utilisant un format inférieur conservent leur format et sont centrées. iHomothétiqueSansAgrandissementZoneImprimableRéduction homothétique des pages du document afin qu'elles s'adaptent au format de sortie en prenant en compte les marges physiques. Les pages utilisant un format inférieur conservent leur format et sont centrées. iTailleRéelleImpression à la taille réelle. Les pages utilisant un format : plus petit que le format de sortie sont centrées dans la page. plus grand que le format de sortie sont tronquées et sont centrées dans la page.

#### Imprimer le contenu d'un fichier de type "docx", d'une variable de type Buffer ou d'un mémo binaire

```wlangage
<Résultat> = iImprimeDoc(<Elément à imprimer> [, <Mot de passe>])
```

`<Résultat>` *Booléen*
> - Vrai si le document est valide pour l'impression,
> - Faux dans le cas contraire.
`<Elément à imprimer>` *Chaîne de caractères, Buffer ou mémo binaire*
> - Nom et chemin du fichier de type "docx" à imprimer.
> - Nom de la variable de type Buffer à imprimer.
> - Nom de la rubrique de type Mémo binaire à imprimer.
`<Mot de passe>` *Chaîne de caractères optionnelle ou Chaîne secrète*
> - Mot de passe d'ouverture de l'élément à imprimer (fichier de type "docx", contenu de la variable de type Buffer, contenu de la variable de type Mémo binaire).
> - Chaîne vide ("") si l'élément à imprimer n'a pas de mot de passe.
>
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).
