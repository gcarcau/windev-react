# XMLNoeudValide (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Valide un noeud XML, ses fils et ses attributs à partir de sa description dans le schéma XSD lié au document XML.

## Exemple

```wlangage
// Validation à partir du schéma défini lors de la déclaration
cMonNoeud est un xmlNoeud, description="schemaXSDDuProjet.NoeudRacine"
cMonNoeud..Texte = "21"
cMonNoeud..NoeudFils = "221"
SI XMLNoeudValide(cMonNoeud) = Faux ALORS
	Erreur(ErreurInfo())
SINON
	Info("Le noeud XML est valide")
FIN
```

## Syntaxe

```wlangage
<Résultat> = XMLNoeudValide(<Noeud XML>)
```

`<Résultat>` *Booléen*
> - Vrai si la validation réussie,
> - Faux dans le cas contraire. En cas d'erreur, il est possible de connaître le libellé de l'erreur avec la fonction [ErreurInfo](3013008.md).
`<Noeud XML>` *Variable de type xmlNoeud*
> Nom de la variable de type [xmlNoeud](1000018786.md) correspondant au noeud à valider en utilisant le schéma XSD. Le schéma XSD utilisé correspond :
>
> - soit à la description utilisée au moment de la déclaration du noeud (par exemple : cMonNoeud est un xmlNoeud, description="monXSD.MonNoeud")
> - soit à la description utilisée au moment de la déclaration du document XML auquel est associé le noeud.
