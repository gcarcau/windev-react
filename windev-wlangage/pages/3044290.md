# HListeUtilisateur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie la liste des utilisateurs définis pour une connexion.

## Exemple

```wlangage
// Description de la connexion
HDécritConnexion("MaConnexion", "Julie", "MotDePasse", "MonServeurHF", "MaBaseDeDonnées", ...
	hAccèsHFClientServeur, hOLecture)
// Ouverture de la connexion
HOuvreConnexion("MaConnexion")
Résultat1 est une chaîne
Résultat1 = HListeUtilisateur("MaConnexion")
// Ajout des utilisateurs dans un champ Liste
ListeAjoute(LISTE_Maliste, Résultat1)
```

## Syntaxe

```wlangage
<Résultat> = HListeUtilisateur(<Connexion>)
```

`<Résultat>` *Chaîne de caractères*
> Nom des différents utilisateurs existants pour la connexion spécifiée. Les noms des utilisateurs sont séparés par RC (Retour-Chariot).
> **Remarque** : Si l'utilisateur en cours ne possède pas le droit de visualisation des utilisateurs (constante *hDroitVisualisationUtilisateur*) sur le serveur (fonction [HModifieDroitServeur](3044328.md) ou [HInfoDroitServeur](3044322.md)), la fonction **HListeUtilisateur** renvoie uniquement l'utilisateur en cours.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion à manipuler. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
