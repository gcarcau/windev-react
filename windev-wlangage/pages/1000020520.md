# ChampTypeInfo (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Renvoie l'icône correspondant au type de champ spécifié.
> _(WEBDEV - Code Serveur)_ Remarque : Il est nécessaire de recompiler le projet pour que les images soient copiées dans le répertoire "_WEB/res" du projet.

## Exemple

> _(WINDEV, Code Utilisateur (MCU))_ nType est un entier = SAI_Nom.Type
ImgChamp est une Image = ChampTypeInfo(nType)
IMG_Champ = ImgChamp

> _(WINDEV, WEBDEV - Code Serveur, Code Utilisateur (MCU))_ ImgChamp est une chaîne = ChampTypeInfo(typCalendrier)
IMG_Champ = ImgChamp

## Syntaxe

```wlangage
<Résultat> = ChampTypeInfo(<Type>)
```

`<Résultat>` *Variable de type Image ou chaîne de caractères*
> - Variable de type [Image](1000019650.md) correspondant à l'icône du type de champ.
> - Chaîne de caractères correspondant au chemin et au nom du fichier image créé. Ce chemin est relatif au répertoire <Nom Projet>_WEB du projet.
