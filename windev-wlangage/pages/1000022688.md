# <Variable Connexion>.InfoVue (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Renvoie des informations sur une vue matérialisée.

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion

Info("Les données de la vue ont été produites le " + ...
	MaConnexion.InfoVue(MaVue, hDateDernierRafraîchissement)
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.InfoVue(<Vue> , <Information demandée>)
```

`<Résultat>` *Chaîne de caractères*
> Information demandée.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion vers le serveur HFSQL qui contient la vue matérialisée.
`<Vue>` *Chaîne de caractères*
> Nom de la vue matérialisée présente sur le serveur et pour laquelle les informations sont demandées.
`<Information demandée>` *Constante de type Entier*
> Information demandée sur la vue matérialisée spécifiée.
>
> | *hCodeSQL* | <Résultat contiendra le code SQL du contenu de la vue. |
> | --- | --- |
> | *hDateDernierRafraîchissement* | <Résultat contiendra la date (au format AAAAMMJJ) du dernier rafraîchissement réussi de la vue. |
> | *hErreurDernierRafraîchissement* | <Résultat correspondra à :   - l'erreur produite pendant le dernier rafraîchissement. - Chaîne vide ("") si le dernier rafraîchissement a réussi. |
> | *hRafraîchissementEnCours* | <Résultat correspondra à :   - 1 si la vue est en cours de rafraîchissement, - 0 sinon. |

**Composante : wd300hf.dll**
