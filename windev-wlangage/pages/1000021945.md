# <Variable fbSession>.RécupèreInformationUtilisateur (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Récupère les informations Facebook de l'utilisateur connecté.
> _(Android, iPhone/iPad, Widget IOS, Mac Catalyst)_ Cette fonction est disponible dans le simulateur.

> _(Android)_ Attention : Cette fonctionnalité est disponible jusqu'à Android 11. A partir d'Android 12, cette fonction provoque une erreur fatale. Il est conseillé de : tester la version d'Android utilisée via la fonction SysVersionAndroid.utiliser la fonction AuthIdentifie pour gérer l'authentification Facebook.

## Exemple

```wlangage
MaSession est un fbSession
...
sEmail est chaîne = MaSession.RécupèreInformationUtilisateur(fbEmail)
```

## Syntaxe

```wlangage
<Résultat> = <Session>.RécupèreInformationUtilisateur(<Information>)
```

`<Résultat>` *Chaîne de caractères ou Buffer*
> Information demandée.
`<Session>` *Variable de type fbSession*
> Nom de la variable de type [fbSession](1000021851.md) correspondant à la connexion Facebook à manipuler.
`<Information>` *Constante de type chaîne de caractères*
> Information demandée :
>
> | *fbEmail* | Email de l'utilisateur. |
> | --- | --- |
> | *fbIdentifiant* | Identifiant Facebook de l'utilisateur. |
> | *fbImage* | Image de l'utilisateur. |
> | *fbNom* | Nom de l'utilisateur. |

## Remarques

Lors de la connexion, les droits (permissions) correspondant à l'information demandée devront avoir été accordés. Dans le cas contraire, la fonction échouera.

**Composante : wd300ggl.dll**
