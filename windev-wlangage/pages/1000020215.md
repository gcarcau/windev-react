# Fonctions de gestion des champs Zone multiligne

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des champs Zone multiligne (syntaxe préfixée)](1000020220.md)).
Les fonctions de gestion des champs Zone multiligne sont les suivantes :

| [zmlAjouteLigne](1000020199.md) | Ajoute une nouvelle ligne dynamique dans un champ Zone multiligne. |
| --- | --- |
| [zmlInsèreLigne](1000020207.md) | Insère une nouvelle ligne dynamique dans un champ Zone multiligne. |
| [zmlSupprime](1000020208.md) | Supprime une ligne dynamique dans un champ Zone multiligne. |
| [zmlSupprimeTout](1000020209.md) | Supprime toutes les lignes dynamiques dans un champ Zone multiligne. |
