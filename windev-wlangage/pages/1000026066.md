# Fonctions WebSocket

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions WebSocket (syntaxe préfixée)](1000026141.md)).
Les fonctions utilisables dans un projet de type Serveur de WebSocket sont les suivantes :

| [WebSocketDéconnecte](1000025960.md) | Déconnecte un client actuellement connecté sur un serveur de WebSocket. |
| --- | --- |
| [WebSocketEnvoie](1000025957.md) | Envoie un message pour un client du serveur de WebSocket. |
| [WebSocketExécute](1000025961.md) | Exécute une procédure dans le contexte d'un client connecté au serveur de WebSocket. |
| [WebSocketExécuteServiceGlobal](1000026042.md) | Exécute une procédure globale dans le contexte du service global du serveur de WebSocket. |
| [WebSocketListeClientConnecté](1000025956.md) | Liste les clients connectés au serveur de WebSocket. |
