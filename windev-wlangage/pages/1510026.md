# UTILISER DANS (Chronomètre)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Apple Watch)

L'instruction **UTILISER ... DANS** permet d'effectuer automatiquement les opérations de déclenchement et d'arrêt d'un chrono.
Cette instruction permet principalement de simplifier le cumul de chronomètres sur plusieurs itérations.

Si le chronomètre est arrêté au début du bloc, il est automatiquement déclenché en sortie du bloc.

## Exemple

```wlangage
c est un Chrono

UTILISER c DANS
	ThreadPause(2 s)
	SI Vrai ALORS
		SORTIR
		// Le calcul du chronomètre s'arrête
	FIN
FIN

ThreadPause(2 s) // Ce code n'est pas pris en compte dans le calcul du chronomètre

UTILISER c DANS
	ThreadPause(2 s)
FIN

Info(c)
```

## Syntaxe

```wlangage
UTILISER <Chronomètre> DANS ...FIN
```

`<UTILISER DANS>` **
> Signale le début du bloc d'instructions.
`<Chronomètre>` *Variable de type Chrono*
> Nom de la variable de type [Chrono](1000023560.md) correspondant au chronométrage à réaliser.
