# Fonctions XML (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

## Principe de manipulation d'un document XML

Pour manipuler un document XML, il est conseillé d'[Utiliser une variable de type xmlDocument](3081018.md). Cette méthode permet d'utiliser un fichier de type XSD.
Plusieurs types de variables spécifiques sont disponibles :

| [xmlAttribut](1000018799.md) | Le type **xmlAttribut** permet de manipuler les attributs d'un noeud dans un document XML. |
| --- | --- |
| [xmlDocument](1000018782.md) | Le type **xmlDocument** permet de manipuler simplement un fichier XML. |
| [xmlNamespace](1000018803.md) | Le type **xmlNamespace** permet de manipuler l'espace de nommage XML d'un attribut de noeud dans un document XML. |
| [xmlNoeud](1000018786.md) | Le type **xmlNoeud** permet de manipuler un noeud d'un document XML. |

Plusieurs fonctions spécifiques permettent de manipuler les variables de type xmlDocument

| [<Variable JSON>.VersXML](1410087332.md) | Convertit une chaîne de caractères au format JSON en une chaîne de caractères au format XML. |
| --- | --- |
| [<Variable xmlDocument>.ConstruitChaîne](1000023891.md) | Récupère et met en forme le contenu d'un document XML. |
| [<Variable xmlDocument>.DocumentValide](1000023892.md) | Valide un document XML à partir d'un schéma XSD. |
| [<Variable xmlDocument>.ExécuteXPath](1000023893.md) | Exécute une requête XPATH dans une variable de type xmlDocument. |
| [<Variable xmlDocument>.Sauve](1000023895.md) | Sauvegarde un document XML dans un fichier. |
| [<Variable xmlNoeud>.ChercheNamespaceParNom](1000023889.md) | Recherche un namespace (espace de nommage) XML à partir de son nom dans un noeud XML et dans les parents de ce noeud. |
| [<Variable xmlNoeud>.ChercheNamespaceParURI](1000023890.md) | Recherche un namespace (espace de nommage) XML à partir de son URI (Universal Resource Identifier) dans un noeud et dans les parents de ce noeud. |
| [<Variable xmlNoeud>.NoeudValide](1000023894.md) | Valide un noeud XML, ses fils et ses attributs à partir de sa description dans le schéma XSD lié au document XML. |
| [<xmlDocument>.VersJSON](1410087334.md) | Convertit une chaîne de caractères au format XML en une chaîne de caractères au format JSON. |
| [<xmlNoeud>.VersJSON](1410087333.md) | Convertit une chaîne de caractères au format XML en une chaîne de caractères au format JSON. |

Certaines fonctions sont également liées à la gestion du XML :

| [<Source>.EnregistrementVersXML](1000024610.md) | Récupère la structure et la valeur de l'enregistrement en cours et les exporte dans une chaîne de caractères au format XML. |
| --- | --- |
| [<Source>.ExporteXML](1000024956.md) | Exporte les enregistrements d'un fichier de données (HFSQL ou OLE DB), d'une vue ou d'une requête dans un fichier XML. |
| [<Source>.ImporteXML](1000024994.md) | Importe un fichier XML dans un fichier de données au format HFSQL Classic ou Client/Serveur (fichier de données décrit sous l'éditeur d'analyses ou déclaré par les fonctions [<Source>.Déclare](1000024213.md), [<Source>.DéclareExterne](1000024214.md) ou [<Source>.DécritFichier](1000024215.md)). |
| [J2EEExécuteXML](3047008.md) | Exécute une procédure sur un serveur de services Web XML J2EE. |
| [SOAPExécuteXML](3069014.md) | Exécute une procédure sur un serveur SOAP. |
| [<Table>.VersXML](1410088378.md) | Crée un fichier XML avec les données d'un champ Table ou Table hiérarchique. |
| [<Zone répétée>.VersXML](1000023707.md) | Crée un fichier XML avec les données d'un champ Zone répétée (champ Zone répétée fichier ou champ Zone répétée par programmation). |
