# ValeurSupérieure (Propriété)

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

La propriété **ValeurSupérieure** permet de :

- Connaître la borne supérieure de l'intervalle actuellement sélectionné dans un champ Potentiomètre d'intervalle.
- Modifier la borne supérieure de l'intervalle actuellement sélectionné dans un champ Potentiomètre d'intervalle.

## Exemple

```wlangage
// Initialise l'intervalle de prix pour la recherche des produits
RGS_FiltrePrix.BorneMin = 0
RGS_FiltrePrix.BorneMax = 1000
RGS_FiltrePrix.ValeurInférieure = 10
RGS_FiltrePrix.ValeurSupérieure = 1000
```

## Syntaxe

#### Connaître la valeur supérieure de l'intervalle sélectionné

```wlangage
<Résultat> = <Champ Potentiomètre d'intervalle>.ValeurSupérieure
```

`<Résultat>` *Entier*
> Valeur supérieure de l'intervalle actuellement sélectionné dans le champ.
`<Champ Potentiomètre d'intervalle>` *Nom de champ*
> Nom du champ Potentiomètre d'intervalle manipulé.

#### Modifier la valeur supérieure de l'intervalle sélectionné

```wlangage
<Champ Potentiomètre d'intervalle>.ValeurSupérieure = <Nouvelle valeur>
```

`<Champ Potentiomètre d'intervalle>` *Nom de champ*
> Nom du champ Potentiomètre d'intervalle manipulé.
`<Nouvelle valeur>` *Entier*
> Nouvelle valeur supérieure de l'intervalle actuellement sélectionné dans le champ.

## Remarques

- Pour connaître et modifier la borne inférieure de l'intervalle, utilisez les propriétés [ValeurInférieure](1000020433.md) ou [Valeur](2510130.md).
- Les propriétés [ValeurInférieure](1000020433.md) et **ValeurSupérieure** respectent les conditions suivantes :
  - La propriété [BorneMin](2510008.md) est inférieure ou égale à la propriété [ValeurInférieure](1000020433.md).
  - La propriété [ValeurInférieure](1000020433.md) est inférieure ou égale à la propriété **ValeurSupérieure**.
  - La propriété **ValeurSupérieure** est inférieure ou égale à la propriété [BorneMax](2510009.md).
   Donc en affectation :
  - Si la nouvelle valeur est plus faible que la propriété [BorneMin](2510008.md), les propriétés [ValeurInférieure](1000020433.md) et **ValeurSupérieure** prennent la valeur de la propriété [BorneMin](2510008.md).
  - Si la nouvelle valeur est plus faible que la propriété [ValeurInférieure](1000020433.md), la propriété [ValeurInférieure](1000020433.md) est modifiée et prend la même valeur que la propriété **ValeurSupérieure**.
  - Si la nouvelle valeur est élevée que la propriété [BorneMax](2510009.md), la propriété **ValeurSupérieure** prend la valeur de la propriété [BorneMax](2510009.md).
