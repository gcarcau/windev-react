# Alignement

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Mac Catalyst)

La propriété **Alignement** permet de gérer l'alignement d'un élément. Cette propriété est utilisable sur :

- une variable de type [Marqueur](1000019940.md).
- une variable de type [docParagraphe](1000022483.md) (caractéristiques de mise en page).
- une variable de type [docNiveauNumérotation](1000022799.md).
- une variable de type [CarteImage](1000025523.md).
- une variable de type [FormatNumérique](1410089836.md).
