# Italie.VérifieCF (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un numéro CF (numéro d'identification personnel en Italie).

## Exemple

```wlangage
// Test d'une variableMonNuméroCF est une chaîne = "RSSMRA74D22A001Q"Italie.VérifieCF(MonNuméroCF) // renvoie Vrai // Test d'un champSAI_NuméroCF = "ABC"Italie.VérifieCF(SAI_NuméroCF) // renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = Italie.VérifieCF(<Numéro à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un numéro CF valide.
> - Faux dans le cas contraire.
`<Numéro à vérifier>` *Nom de champ ou variable de type chaîne*
> Numéro CF à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.

**Composante : wd300std.dll**
