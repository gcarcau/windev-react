# BTListeRadio (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Liste les radios Bluetooth connectées à la machine.

## Exemple

```wlangage
sChaîneTmp est une chaîne
sListePériphs est une chaîne
// Liste les radios
sListePériphs = BTListeRadio()
// Vide le champ Table affichant la liste des radios
TableSupprimeTout(TABLE_Radios)
// Remplit le champ Table
SI sListePériphs <> "" ALORS
	POUR TOUTE CHAÎNE sChaîneTmp DE sListePériphs SÉPARÉE PAR RC
		TableAjoute(TABLE_Radios, sChaîneTmp)
	FIN
SINON
	Info(ErreurInfo(errComplet))
FIN
```

## Syntaxe

```wlangage
<Résultat> = BTListeRadio([<Niveau de détail>])
```

`<Résultat>` *Chaîne de caractères*
> Liste des radios disponibles. Cette liste est de la forme :
>
> - en mode simple :
>   ```wlangage
>   <Identifiant Radio 1> + TAB + <Adresse MAC 1> + TAB + <Nom 1> + RC + ... + RC + <Identifiant Radio N> + TAB + <Adresse MAC N> + TAB + <Nom N>
>   ```
> - en mode détaillé :
>   ```wlangage
>   <Identifiant Radio 1> + TAB + <Adresse MAC 1> + TAB + <Nom 1> + TAB + <Identifiant Classe 1> + TAB + <Identifiant fabricant 1> + TAB + <Identifiant Version 1> + RC + ... + RC + <Identifiant Radio N> + TAB + <Adresse MAC N> + TAB + <Nom N> + TAB + <Identifiant Classe N> + TAB + <Identifiant fabricant N> + TAB + <Identifiant Version N>
>   ```
>
>
> Les différentes informations obtenues sont les suivantes :
>
>
> - <Identifiant Radio> : Identifiant de la radio, à utiliser dans les fonctions Bluetooth manipulant des radios.
> - <Adresse MAC> : Adresse physique de la radio
> - <Nom> : Nom retourné par la radio (peut être une chaîne vide
> - <Identifiant Classe> : Classe de radio (entier sur 32 permettant d'obtenir des informations sur le type de la radio)
> - <Identifiant fabricant> : Identifiant du fabricant de la radio
> - <Identifiant Version> : Identifiant propre à la radio (consulter sa documentation)
`<Niveau de détail>` *Constante optionnelle de type Entier*
> Niveau de détail du résultat :
>
>
> | *btListeDétaillée* | <Résultat contient la liste des radios en mode détaillé. |
> | --- | --- |
> | *btListeSimple* (Valeur par défaut) | <Résultat contient la liste des radios en mode simple. |

## Remarques

Seules les piles bluetooth Microsoft, Bluesoleil et Broadcom (Widcomm) sont supportées par cette fonction. Pour connaître la pile utilisée, utilisez la fonction [BTPile](1000017229.md).
Les piles Broadcom (Widcomm) ne sont pas disponibles en 64 bits.

Pour plus de détails sur les clés supportées, consultez [Quelles piles utiliser ?](1000017231.md)

**Composante : wd300com.dll**
