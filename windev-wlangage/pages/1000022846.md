# StyleID (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **StyleID** permet de connaître et de modifier l'identifiant du style associé à un élément.
Cette propriété est utilisée par les variables de type :

- [docFragment](1000022482.md).
- [docParagraphe](1000022483.md).
- [docStyle](1000022486.md).
