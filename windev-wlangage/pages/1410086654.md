# AgentUtilisateur

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **AgentUtilisateur** permet d'identifier le client d'une requête HTTP/HTTPS. Cette propriété est utilisable sur :

- une variable de type [httpRequête](1000021158.md).
- une variable de type [restRequête](1000021481.md).
