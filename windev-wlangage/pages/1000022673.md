# <Variable Connexion>.InfoPropriétéBaseDeDonnées (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Permet de connaître les propriétés d'une base de données située sur un serveur HFSQL.

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion

// Ouverture de la connexion
MaConnexion.OuvreConnexion()
...
NomPropriétaire est une chaîne
NomPropriétaire = MaConnexion.InfoPropriétéBaseDeDonnées(hPropriétaire, "MaBaseDeDonnées")
SI NomPropriétaire <> "" ALORS
	Trace("Propriétaire de la base de donnée : " + NomPropriétaire)
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.InfoPropriétéBaseDeDonnées(<Propriété> , <Base de données>)
```

`<Résultat>` *Chaîne de caractères*
> - Valeur de la propriété demandée,
> - Chaîne vide ("") en cas d'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle la valeur d'une propriété est recherchée.
`<Propriété>` *Constante de type Entier*
> Propriété de la base de données recherchée :
>
> | *hApplication* | Nom de l'application à partir de laquelle la base de données a été créée.  Si cette constante est utilisée, <Résultat est une chaîne de caractères de la forme <Nom de l'exécutable>(<Nom du projet>). |
> | --- | --- |
> | *hCréateur* | Nom du créateur de la base de données. Cette information est purement informative et n'a pas d'influence.  Si cette constante est utilisée, <Résultat est une chaîne de caractères. |
> | *hDate* | Date de la création de la base de données.  Si cette constante est utilisée, <Résultat est une chaîne de caractères de la forme AAAAMMJJHHmmSSCCC. |
> | *hMachine* | Nom du poste à partir duquel a été créé l'élément.  Si cette constante est utilisée, <Résultat est de la forme <Nom du poste client + TAB + <Adresse IP du poste Client>. |
> | *hNotes* | Description de la base de données ou toute autre information associée à la base de données grâce à la fonction [<Variable Connexion>.ModifiePropriétéBaseDeDonnées](1000022717.md).  Si cette constante est utilisée, <Résultat est une chaîne de caractères. |
> | *hPropriétaire* | Propriétaire de la base de données.  Le propriétaire est celui qui possède la base de données. Le propriétaire d'une base de données peut être modifié via la fonction [<Variable Connexion>.ModifiePropriétéBaseDeDonnées](1000022717.md).  Si cette constante est utilisée, <Résultat est une chaîne de caractères. |
`<Base de données>` *Chaîne de caractères*
> Nom de la base de données pour laquelle les propriétés sont recherchées.
> Si ce paramètre correspond à une chaîne vide (""), la base de données utilisée sera celle définie dans la connexion.
> Si aucune base de données n'est définie dans la connexion, une erreur WLangage sera générée.

## Remarques

Pour modifier les propriétés d'une base de données, utilisez la fonction [<Variable Connexion>.ModifiePropriétéBaseDeDonnées](1000022717.md).
