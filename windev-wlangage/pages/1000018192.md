# MotClé (Propriété)

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows)

La propriété **MotClé** permet de connaître et de modifier un mot-clé. Cette propriété est utilisable sur :

- une variable de type [docPropriété](1000022945.md).
- une variable de type [pdfDocument](1000024909.md).
