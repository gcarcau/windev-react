# HRAZClient (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Initialise la structure de gestion des postes Client (structure [HClient](3044340.md)).

## Exemple

```wlangage
// Description de la connexion
HDécritConnexion("MaConnexion", "Julie", "MotDePasse", "MonServeurHF", "MaBaseDeDonnées", ...
	hAccèsHFClientServeur, hOLecture)
// Ouverture de la connexion
HOuvreConnexion("MaConnexion")
...
HRAZClient()
// Caractéristiques des clients à déconnecter
HClient.Application = "Application.exe"
// Déconnexion des clients
HDéconnecteClient("MaConnexion", "Déconnexion imminente", 300)
```

## Syntaxe

```wlangage
<Résultat> = HRAZClient()
```

`<Résultat>` *Booléen*
> - Vrai si l'initialisation a été effectuée,
> - Faux en cas de problème. La fonction [HErreurInfo](3044071.md) permet d'obtenir plus de détails.
