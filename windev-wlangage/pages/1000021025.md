# Tiff (Type de variable)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Le type **Tiff** permet de définir toutes les caractéristiques avancées d'une image TIFF. Les caractéristiques de ce type peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Chargement du fichier
MonTiff est un Tiff = "MonFichier.tiff"
// Remplacement de la première page
MonTiff.Image[1] = "C:\MesImages\sigle48.bmp"
// Sauvegarde du fichier
dSauveImageTIFF(MonTiff, "MonFichierModifié.tiff")
```

## Propriétés

### Propriétés spécifiques à la description des variables de type Tiff
Les propriétés suivantes peuvent être utilisées pour manipuler une image au format Tiff :

| **Nom de la propriété** | **Type manipulé** | **Effet** |
| --- | --- | --- |
| Image | Tableau de [Image](1000019650.md) | Tableau contenant les images de chaque page du fichier TIFF. |
| Valeur | Image (mémo) | Valeur de l'image. Cette propriété permet de charger une image Tiff à partir d'un buffer, d'un fichier ou d'un mémo. |

## Remarques

### Fonctions WLangage manipulant les variables de type Tiff

| [dSauveImageTIFF](1000020852.md) | Sauve une image au format TIFF dans un fichier ou en mémoire. |
