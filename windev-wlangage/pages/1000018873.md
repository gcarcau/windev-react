# SysMiniatureSupprimeTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Supprime tous les boutons associés à la miniature de l'application dans la barre des tâches. Il est ensuite possible d'ajouter de nouveaux boutons avec la fonction [SysMiniatureAjouteBouton](1000018871.md).

## Exemple

```wlangage
// Suppression de tous les boutons liés à la miniature de l'application
SysMiniatureSupprimeTout()
```

## Syntaxe

```wlangage
<Résultat> = SysMiniatureSupprimeTout()
```

`<Résultat>` *Booléen*
> - Vrai si toutes les boutons associés à la miniature ont été supprimés,
> - Faux dans le cas contraire.
