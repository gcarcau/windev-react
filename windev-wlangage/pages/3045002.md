# ImageZone (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux, PHP)

Renvoie le numéro de la zone de l'image cliquée par l'internaute.
Cette fonction est utilisable uniquement dans le code de clic d'un champ Image cliquable (ce champ a pour action "Zones de clic définies en édition (Map Area)" dans l'onglet "Général" de la fenêtre de description du champ).

## Exemple

```wlangage
// Clic sur IMG_IMAGE1
n est un entier = ImageZone()
Trace(n)
SELON n
	CAS 0: LIB_Libellé1 = "Zone externe"
	CAS 1: LIB_Libellé1 = "Zone 1"
	CAS 2: LIB_Libellé1 = "Zone 2"
FIN
```

## Syntaxe

```wlangage
<Résultat> = ImageZone()
```

`<Résultat>` *Entier*
> Numéro de la zone cliquée. Ce numéro est indéfini si la fonction **ImageZone** est utilisée dans un événement différent de l'événement "Clic" d'un champ Image.
> Remarque : Dans l'onglet "Général" de la fenêtre de description du champ Image, l'option "Action lors du clic" correspond à "Zones de clic définies en édition (Map Area)".

## Remarques

### Sessions prélancées
Si votre projet utilise les sessions prélancées, cette fonction ne doit pas être utilisée dans l'événement "Initialisation" du projet. Cette fonction doit être utilisée dans l'événement "Initialisation lors d'une connexion à une session prélancée".
