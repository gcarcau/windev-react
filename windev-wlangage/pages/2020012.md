# Environnement de développement

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Au premier lancement de WINDEV, WEBDEV et WINDEV Mobile, un environnement de développement est automatiquement proposé. Cet environnement propose les options adaptées pour bénéficier des dernières technologies dans vos projets.
Remarque : Si vous possédez une version précédente, les options d'environnement personnalisées sont automatiquement récupérées.

**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Options de l'environnement

Par défaut, l'environnement de développement proposé par défaut propose les options suivantes :

- Thème sombre (pour l'environnement et le code).
  Pour plus de détails, consultez [Thèmes de l'éditeur](2036001.md).
- Syntaxe préfixée.
- Langage de l'interface en mode générique (Team Table).
  Pour plus de détails, consultez [Choix du vocabulaire](2036001.md).
- Utilisation de minuscules pour les mots-clés saisis dans l'éditeur de code.
  Pour plus de détails, consultez [Options de l'éditeur de code](9000218.md).
- Documentation automatique des procédures au format Doxygen.
  Pour plus de détails, consultez [Options de l'éditeur de code](9000218.md).
- Utilisation du format texte pour tous les éléments du projet.
- Charte de programmation désactivée au niveau du code.
  Pour plus de détails, consultez [Charte de programmation](9000074.md).
- Autorisation des types nullables.
  Pour plus de détails, consultez [Activation des types nullables](1511031.md).

Toutes ces options sont bien entendu modifiables.
