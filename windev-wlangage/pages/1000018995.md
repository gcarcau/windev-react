# Fonctions de gestion des champs TreeMap

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des champs TreeMap (syntaxe préfixée)](1000019801.md)).
Les fonctions de gestion des champs TreeMaps sont les suivantes :

| [TreeMapAjoute](1000018814.md) | Ajoute un élément dans un champ TreeMap. |
| --- | --- |
| [TreeMapCherche](1000019739.md) | Recherche l'indice d'un élément dans un champ TreeMap à partir du chemin de l'élément. |
| [TreeMapInfoXY](1000018899.md) | Renvoie l'indice de l'élément affiché à une position donnée dans un champ TreeMap. |
| [TreeMapOccurrence](1000018928.md) | Renvoie le nombre d'éléments présents dans un champ TreeMap. |
| [TreeMapRecherche](1000018901.md) | Recherche l'indice d'un élément dans un champ TreeMap à partir du chemin de l'élément. |
| [TreeMapSelectGroupe](1000018902.md) | Sélectionne visuellement un groupe d'éléments dans un champ TreeMap. |
| [TreeMapSupprime](1000018903.md) | Supprime un élément dans un champ TreeMap. |
| [TreeMapSupprimeTout](1000018914.md) | Supprime tous les éléments d'un champ TreeMap. |

## Liste des exemples associés :

| [image: Le champ Treemap] | Exemples unitaires (WINDEV) : Le champ Treemap     [ + ] Utilisation du champ Treemap. Le champ TreeMap permet de représenter dynamiquement des données, éventuellement arborescentes, de manière pondérée. Ce type de champ est très utile notamment pour permettre une visualisation intuitive de volumes de données.   Par exemple, dans l'exemple, il permet de visualiser le contenu d'un répertoire et d'analyser la taille des fichiers et sous-répertoires qu'il contient. |
