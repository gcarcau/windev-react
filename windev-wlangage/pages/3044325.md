# HInfoPropriétéServeur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Permet de connaître les propriétés d'un serveur HFSQL.

## Exemple

```wlangage
// Description de la connexion
HDécritConnexion("MaConnexion", "Julie", "MotDePasse", "MonServeurHF", "MaBaseDeDonnées", hAccèsHFClientServeur, hOLecture)
// Ouverture de la connexion
HOuvreConnexion("MaConnexion")
...
NotesServeur est une chaîne
NotesServeur = HInfoPropriétéServeur("MaConnexion", hNotes)
SI NotesServeur <> "" ALORS
	Trace("Description du serveur : " + NotesServeur)
FIN
```

## Syntaxe

```wlangage
<Résultat> = HInfoPropriétéServeur(<Connexion> , <Propriété>)
```

`<Résultat>` *Chaîne de caractères*
> - Valeur de la propriété demandée,
> - Chaîne vide ("") en cas d'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion pour laquelle la valeur d'une propriété est recherchée. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Propriété>` *Constante de type Entier*
> Propriété du serveur recherchée :
>
> | *hNotes* | Description du serveur ou toute autre information associée au serveur grâce à la fonction [HModifiePropriétéServeur](3044331.md).  Si cette constante est utilisée, <Résultat est une chaîne de caractères. |
> | --- | --- |

## Remarques

Pour modifier les propriétés d'un serveur, utilisez la fonction [HModifiePropriétéServeur](3044331.md).

**Composante : wd300hf.dll**
