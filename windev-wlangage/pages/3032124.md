# FermeSession (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **Autres** (Procédures stockées)

Ferme une session avec le logiciel de messagerie Lotus Notes ou Outlook.
**Rappel** : Une session est ouverte grâce à la fonction [EmailOuvreSessionNotes](3032121.md), [EmailOuvreSessionOutlook](3032128.md), [OutlookOuvreSession](3032123.md) ou [NotesOuvreConnexion](1000005102.md).

Une session non terminée sera automatiquement fermée à la fin du programme WINDEV ou de la session WEBDEV.

## Exemple

```wlangage
// Ouverture d'une session
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", ...
		"mail/julie.nsf", "C:\Lotus Notes\julie.id")
// Si une session est ouverte, fermeture de cette session
SI IDSession <> 0 ALORS
	FermeSession(IDSession)
FIN
```

## Syntaxe

```wlangage
FermeSession(<Identifiant session>)
```

`<Identifiant session>` *Entier*
> Identifiant de la session en cours. Cette valeur est renvoyée par la fonction [EmailOuvreSessionNotes](3032121.md), [EmailOuvreSessionOutlook](3032128.md), [OutlookOuvreSession](3032123.md) ou [NotesOuvreConnexion](1000005102.md).

**Composante : wd300com.dll**
