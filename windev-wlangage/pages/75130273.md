# Ferme (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Ferme la fenêtre en cours et restitue le contexte existant avant l'ouverture de la fenêtre.

## Exemple

```wlangage
// En CAPPELWD("Ferme");
```

```wlangage
// En PascalAPPELWD('Ferme');
```

```wlangage
// En VBcall APPELWD("Ferme")
```

## Syntaxe

```wlangage
Ferme()
```
