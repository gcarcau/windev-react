# Cadre (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Cadre** permet de connaître et de modifier le cadre d'un élément. Cette propriété est utilisable sur :

- le cadre du champ d'un état. Pour plus de détails, consultez [Cadre](1000018157.md).
- une variable de type [xlsCellule](1000017472.md).
- une variable de type [gglParamètreCarte](1000017505.md).
- une variable de type [OrgaElément](1000019713.md).
- une variable de type [pdfSignature](1000022255.md).
- une variable de type [docParagraphe](1000022483.md) (caractéristiques de mise en page).
- une variable de type [docNiveauNumérotation](1000022799.md).
