# Palette (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Le type **Palette** permet de définir toutes les caractéristiques avancées d'une palette de couleurs. Les caractéristiques de cette palette peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
Ce type de variable est utilisé :

- par le type [Icône](1000020811.md).
- Nouveauté 2025
   pour manipuler les palettes de couleurs utilisables dans les fenêtres et les projets.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

Nouveauté 2025

> _(Android)_ Ce type de variable est désormais disponible pour les applications Android.

## Exemple

```wlangage
// Récupération de la première couleur de la palette de la première image d'une icône
MonIcône est une Icône = "MonIcone.ico"
Palette1 est une Palette = MonIcône.Palette[1]
Couleur1 est une Couleur = Palette1[1]
```

## Propriétés

### Propriétés spécifiques à la description des variables de type Palette
Les propriétés suivantes peuvent être utilisées pour manipuler une palette de couleurs :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Couleur | Tableau de [Couleur](1000019661.md) | Tableau contenant les couleurs de la palette. |

### Fonctions manipulant des variables de type Palette

| Nouveauté 2025 [PaletteCharge](1410090780.md) | Charge une palette à partir d'un fichier de type ".wdpalette". |
| --- | --- |
| Nouveauté 2025 [PaletteGénère](1410090825.md) | Génère une palette à partir d'une couleur de base. |
| Nouveauté 2025 [PaletteRécupère](1410090898.md) | Récupère la palette courante du projet ou la palette de la fenêtre. |
| Nouveauté 2025 [PaletteSauve](1410090779.md) | Sauve une palette dans un fichier. |
