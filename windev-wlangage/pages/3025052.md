# ParamètreOrthographe (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Paramètre le correcteur orthographique pour les champs de saisie et les colonnes de champ Table de toute l'application. Il est possible de spécifier dans quelle langue la correction orthographique doit être effectuée.

## Exemple

```wlangage
// Active la vérification d'orthographe pour toute l'application
ParamètreOrthographe(orthographeActif, Vrai)
// Sélectionne le dictionnaire anglais
ParamètreOrthographe(orthographeNation, nationAnglais)
```

```wlangage
// Savoir si la vérification d'orthographe est activée pour toute l'application
SI ParamètreOrthographe(orthographeActif) = Vrai ALORS
	Info("Le correcteur est activé")
FIN
```

## Syntaxe

#### Paramétrer le correcteur orthographique

```wlangage
ParamètreOrthographe(<Option> , <Valeur>)
```

`<Option>` *Constante de type Entier*
> Option de paramétrage du correcteur orthographique de OpenOffice :
>
> | *orthographeActif* | Si <Valeur correspond à Vrai, le correcteur orthographique est activé pour tous les champs de saisie de l'application.  **Attention** : Il est nécessaire que l'option "Vérifier l'orthographe" ait été cochée sous l'éditeur. Si <Valeur correspond à Faux, le correcteur orthographique est désactivé pour tous les champs de saisie de l'application. |
> | --- | --- |
> | *orthographeNation* | Indique la langue du dictionnaire à utiliser. <Valeur peut correspondre à une des constantes permettant d'identifier les langues (voir paragraphe Remarques). Si le dictionnaire n'est pas installé, la correction automatique ne sera pas proposée. Remarque : Cette constante est prise en compte uniquement pour une vérification orthographique avec OpenOffice. |
> | *orthographeTypeCorrecteur* | Permet de sélectionner le type de correcteur utilisé.  Si <Valeur correspond à :   - *orthographeCorrecteurIntégré* : le correcteur orthographique intégré sera utilisé pour tous les champs de saisie de l'application. - *orthographeCorrecteurOpenOffice* : le correcteur orthographique de OpenOffice sera utilisé pour tous les champs de saisie de l'application. |
`<Valeur>` *Variant*
> Valeur de l'option paramétrée (voir le paramètre <Options>).

#### Connaître le paramétrage du correcteur orthographique

```wlangage
<Résultat> = ParamètreOrthographe(<Option>)
```

`<Résultat>` *Variant*
> Valeur de l'option demandée.
`<Option>` *Entier*
> Option de paramétrage du correcteur orthographique de OpenOffice :
>
> | *orthographeActif* | Si <Résultat correspond à Vrai, le correcteur orthographique de OpenOffice est activé pour tous les champs de saisie de l'application Si <Résultat correspond à Faux, le correcteur orthographique de OpenOffice est désactivé pour tous les champs de saisie de l'application. |
> | --- | --- |
> | *orthographeNation* | Indique la langue du dictionnaire à utiliser. <Résultat correspond à un identifiant de langue (voir paragraphe Notes). |
> | *orthographeTypeCorrecteur* | Si <Résultat correspond à :   - *orthographeCorrecteurIntégré* : le correcteur orthographique intégré est utilisé pour tous les champs de saisie de l'application. - *orthographeCorrecteurOpenOffice* : le correcteur orthographique de OpenOffice est utilisé pour tous les champs de saisie de l'application. |

## Remarques

### Notes

- Il est également possible d'activer le correcteur orthographique de Word avec la fonction [FAAExécute](1000022099.md) et de le désactiver avec la fonction [FAADésactive](1000022018.md).
- L'utilisation du correcteur orthographique de OpenOffice demande nécessite l'installation des dictionnaires de OpenOffice. Pour plus de détails, consultez [Vérifiez l'orthographe avec OpenOffice](1013146.md).
- L'utilisation du correcteur orthographique intégré nécessite l'utilisation des dictionnaires Hunspell. Pour plus de détails, consultez [Vérification d'orthographe basée sur les dictionnaires Hunspell](1410087030.md).
