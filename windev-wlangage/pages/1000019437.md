# Fonctions Wi-Fi

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions de gestion des réseaux Wi-Fi sont les suivantes :

| [WiFiActive](1000019350.md) | Active ou désactive le Wi-Fi sur l'appareil. |
| --- | --- |
| [WiFiAjouteRéseau](1000019351.md) | Ajoute un nouveau réseau à la liste des réseaux Wi-Fi configurés de l'appareil. |
| [WiFiConnecte](1000019352.md) | Connecte l'appareil au réseau Wi-Fi spécifié. |
| [WiFiDétectePointAccès](1000019353.md) | Lance la détection des points d'accès Wi-Fi actuellement accessibles depuis l'appareil. |
| [WiFiEtat](1000019354.md) | Renvoie l'état actuel d'activation du Wi-Fi sur l'appareil ou demande à être notifié des changements d'état d'activation du Wi-Fi. |
| [WiFiInfoConnexion](1000019355.md) | Renvoie l'information spécifiée à propos de la connexion Wi-Fi actuelle de l'appareil. |
| [WiFiListeCarteRéseau](1000020693.md) | Renvoie la liste des cartes réseaux Wi-Fi actuellement disponibles sur le poste en cours. |
| [WiFiListeRéseau](1000019356.md) | Renvoie la liste des réseaux Wi-Fi actuellement configurés sur l'appareil. |
| [WiFiSelectCarteRéseau](1000020694.md) | Sélectionne la carte réseau Wi-Fi qui sera utilisée pour les prochains appels des fonctions WiFi. |
| [WiFiSupprimeRéseau](1000019357.md) | Supprime un réseau de la liste des réseaux Wi-Fi configurés de l'appareil. |
