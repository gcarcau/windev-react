# <Liste de Kanban>.PositionListe (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Permet de faire défiler une liste d'un champ Kanban afin d'afficher une carte donnée.

## Exemple

```wlangage
PositionCarte est un entier
MaCarte est un kbCarte
MaCarte.Titre = "Anglais"
PositionCarte = KANBAN_Révision.InsèreCarte(LISTE_Matière_à_Revoir, 3, MaCarte)

// Sélectionne la carte insérée
MaCarteKanban est un kbCarte
MaCarteKanban <- LISTE_Matière_à_Revoir[PositionCarte]

// Affiche la carte insérée
LISTE_Matière_à_Revoir.PositionListe(MaCarteKanban)
```

## Syntaxe

```wlangage
<Liste de Kanban>.PositionListe(<Carte>)
```

`<Liste de Kanban>` *Nom de champ*
> Nom du champ Liste de Kanban à manipuler.
`<Carte>` *Variable de type kbCarte*
> Nom de la variable de type [kbCarte](1410089167.md) correspondant à la carte à afficher. Si la carte n'est pas présente dans la liste de Kanban, aucune action n'est réalisée.

**Classification Métier / UI : Code UI**

**Composante : wd300obj.dll**
