# VersionHTTP (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

## XXX

La propriété **VersionHTTP** permet de gérer la version du protocole HTTP utilisée par le serveur. Cette propriété est utilisable sur :

- une variable de type [httpRequête](1000021158.md).
- une variable générée automatiquement pour représenter [un Webservice importé](3086001.md).
- une variable générée automatiquement pour représenter [un Webservice REST importé](1410087809.md).
