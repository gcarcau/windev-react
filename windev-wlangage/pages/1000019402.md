# DNSSupprimeAdresse (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Supprime une association "Adresse IP/Nom de domaine" dans un serveur DNS.

## Exemple

```wlangage
ResultDNS est un booléen

// Supprime une adresse
ResultDNS = DNSSupprimeAdresse("testAp.towerqual.local.", "192.168.1.1", "Andromede_2")
SI ResultDNS = Faux ALORS
	Erreur(ErreurInfo(errComplet))
FIN

// Supprime toutes les adresses
ResultDNS = DNSSupprimeAdresse("testAp.towerqual.local.", "", "Andromede_2")
SI ResultDNS = Faux  ALORS
	Erreur(ErreurInfo(errComplet))
FIN
```

## Syntaxe

```wlangage
<Résultat> = DNSSupprimeAdresse(<Nom de domaine> [, <Adresse IP> [, <Serveur DNS> [, <Utilisateur> [, <Mot de passe>]]]])
```

`<Résultat>` *Booléen*
> - Vrai si la suppression a été effectuée,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de renseignements sur le problème rencontré.
`<Nom de domaine>` *Chaîne de caractères Unicode*
> Nom de domaine à supprimer du DNS. Ce paramètre est de la forme :
>
> ```wlangage
> <Nom> + "." + <Domaine>
> ```
>
>
> Exemple : "testdoc.pcsoft.com"
`<Adresse IP>` *Chaîne de caractères optionnelle*
> Adresse IP associée au nom de domaine à supprimer. Cette adresse IP peut être une adresse IP version 4 (au format xxx.xxx.xxx.xxx) ou version 6 (au format aaaa :bbbb :cccc :dddd :eeee :ffff :gggg :hhhh :iiii :jjjj).
> Si ce paramètre correspond à une chaîne vide (""), toutes les associations du nom de domaine avec une adresse IP seront supprimées.
`<Serveur DNS>` *Chaîne de caractères optionnelle*
> Adresse du serveur DNS à mettre à jour. L'association "Adresse IP/Nom de domaine" sera supprimée de ce serveur. Par défaut, le serveur DNS actuel est utilisé.
`<Utilisateur>` *Chaîne de caractères Unicode optionnelle*
> Nom de l'utilisateur utilisé pour signer la requête.
`<Mot de passe>` *Chaîne de caractères Unicode optionnelle ou Chaîne secrète*
> Mot de passe associé à l'utilisateur pour signer la requête.
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).

## Remarques

- Cette fonction gère les serveurs DNS Linux et Windows ne nécessitant pas de signature des requêtes.
- Cette fonction gère les serveurs DNS Windows nécessitant une signature des requêtes.

**Composante : wd300com.dll**
