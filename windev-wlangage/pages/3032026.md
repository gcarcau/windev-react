# EmailMsgErreur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Retourne le message correspondant à l'identifiant de l'erreur.
Pour connaître le libellé de l'erreur, nous vous conseillons d'utiliser directement la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.

> _(Linux)_ Il est conseillé d'utiliser la fonction ErreurInfo à la place de la fonction EmailMsgErreur.

Toutes les fonctions de gestion d'emails renvoient un résultat indiquant si la fonction a été effectuée ou non. En cas d'erreur, ces fonctions renvoient 0 ou Faux. La variable Email.Erreur contient alors l'identifiant de l'erreur survenue.

## Exemple

```wlangage
// Envoie le mail
SI EmailEnvoieMessage(NomUser) = Faux ALORS
	Erreur(EmailMsgErreur(Email.Erreur))
FIN
```

## Syntaxe

```wlangage
<Résultat> = EmailMsgErreur(<Numéro erreur>)
```

`<Résultat>` *Chaîne de caractères*
> Message complet de l'erreur.
`<Numéro erreur>` *Entier*
> Identifiant de l'erreur. La variable Email.Erreur contient l'identifiant de la dernière erreur survenue lors de l'utilisation des fonctions de gestion des emails.

## Remarques

### Codes d'erreur et messages associés
Les codes correspondants sont :

| 0 : Aucune erreur | 12 : Impossible d'ouvrir le fichier attaché |
| --- | --- |
| 1 : Abandon demandé par l'utilisateur | 13 : Impossible d'écrire le fichier attaché |
| 2 : Erreur inconnue | 14 : Destinataire inconnu |
| 3 : Impossible de se connecter | 15 : Mauvais format de l'adresse destinataire |
| 4 : Disque plein | 16 : Pas de message |
| 5 : Plus de mémoire disponible | 17 : Message invalide |
| 6 : Accès interdit | 18 : Texte du message trop long |
| 8 : Trop de sessions ouvertes | 19 : Session invalide |
| 9 : Trop de fichiers attachés (10 maximum) | 21 : Adresse du destinataire ambiguë |
| 10 : Trop de destinataires (20 destinataires) | 23 : Erreur réseau |
| 11 : Fichier attaché non trouvé | 26 : Le protocole n'est pas supporté par le serveur |
| 10004 : Interruption système | 10053 : Le logiciel a provoqué un arrêt de la connexion |
| 10009 : Mauvais numéro de fichier | 10054 : Connexion coupée par l'hôte |
| 10013 : Permission refusée | 10055 : Buffer trop petit |
| 10014 : Adresse non valide | 10056 : La connexion est déjà établie |
| 10022 : Argument non valide | 10057 : Le socket n'est pas connecté |
| 10035 : Opération non terminée | 10058 : L'implémentation socket a échoué |
| 10036, 10037 : Une opération est en cours | 10060 : Time out |
| 10038 : Socket non valide | 10061 : Connexion refusée |
| 10040 : Il faut spécifier une adresse destination | 10063 : Nom de fichier trop long |
| 10041, 10042, 10043 : Protocole TCP IP non supporté | 10064 : L'hôte a coupé la connexion |
| 10044 : Type de socket non supporté | 10065 : L'hôte est inaccessible |
| 10045 : Opération non supportée par la socket | 10091 : Réseau inaccessible |
| 10046, 10047 : Protocole TCP IP non supporté | 10092 : Mauvaise version de la DLL Winsock |
| 10048 : L'adresse est déjà utilisée | 10093 : Implémentation réseau non initialisée |
| 10049 : Adresse non trouvée | 10101 : Socket déconnecté |
| 10050 : Le réseau est coupé | 11001 - 11002 : Hôte non trouvé |
| 10051 : Réseau inaccessible | 11003 : Erreur inconnue |
| 10052 : Le réseau a coupé la connexion lors d'un reset | 11004 : Impossible de répondre à la demande, la donnée n'existe pas |
