# <Zone répétée>.DébutRemplissage (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Indique le début du remplissage d'un champ Zone répétée par programmation. L'avancement du remplissage est représenté :

- soit par une jauge infinie affichée au bas du champ.
- soit par une fenêtre interne.

**Attention** : Avant d'utiliser cette fonction, vous devez activer le mécanisme de gestion du remplissage dans la fenêtre de description du champ. Pour plus de détails, consultez [Caractéristiques d'un champ Zone répétée dans une fenêtre](1013294.md).

## Exemple

```wlangage
ZR_MaZone.DébutRemplissage()

POUR i = 1 À 10000
	ZR_MaZone.AjouteLigne()
	Multitâche(-1)
FIN

ZR_MaZone.FinRemplissage()
```

## Syntaxe

```wlangage
<Champ Zone répétée>.DébutRemplissage()
```

`<Champ Zone répétée>` *Nom de champ*
> Nom du champ Zone répétée à manipuler.

## Remarques

- A la fin du traitement de chargement du champ Zone répétée, il est nécessaire d'appeler la fonction [<Zone répétée>.FinRemplissage](1000023501.md) afin d'indiquer que le remplissage est terminé.
- Cette fonction est sans effet sur les champs Zone répétée reliés à une source de données de type fichier de données ou requête.

**Composante : wd300obj.dll**
