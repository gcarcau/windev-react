# Fonctions MQTT (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions permettant de gérer les clients MQTT (syntaxe préfixée) sont les suivantes :

| [<Variable mqttSession>.Abonne](1000023083.md) | Permet de s'abonner à une notification MQTT. |
| --- | --- |
| [<Variable mqttSession>.Connecte](1000023084.md) | Permet de se connecter à un serveur MQTT (également appelé "Broker"). |
| [<Variable mqttSession>.Déconnecte](1000023085.md) | Permet de se déconnecter d'un serveur MQTT (également appelé "Broker"). |
| [<Variable mqttSession>.Désabonne](1000023086.md) | Permet de se désabonner d'une notification MQTT. |
| [<Variable mqttSession>.DésabonneTout](1000023090.md) | Permet de se désabonner de tous les abonnements préalablement souscrits. |
| [<Variable mqttSession>.Publie](1000023091.md) | Publie un message sur le broker MQTT. |
