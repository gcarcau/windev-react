# <Variable Scanneur>.Capacité (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Permet de savoir si un scanneur possède une capacité donnée.

## Exemple

```wlangage
MonScanneur est un Scanneur

// Indique si le scanneur supporte le recto-verso
RectoVerso est un booléen = MonScanneur.Capacité(scanCapacitéRectoVerso)
```

## Syntaxe

```wlangage
<Résultat> = <Scanneur>.Capacité(<Capacité>)
```

`<Résultat>` *Booléen*
> - Vrai si le scanneur a la capacité <Capacité>,
> - Faux dans le cas contraire. En cas d'erreur, la variable [ErreurDétectée](3087001.md) vaut Vrai et le message d'erreur correspondant peut être connu avec la fonction [ErreurInfo](3013008.md).
`<Scanneur>` *Variable de type Scanneur*
> Nom de la variable de type [Scanneur](1410087808.md) initialisée avec les informations du scanneur dont on veut connaître la capacité.
`<Capacité>` *Constante de type Entier*
> Information recherchée concernant la capacité du scanneur :
>
>
> | *scanCapacitéChargeur* | Permet de savoir si le scanneur a un chargeur. |
> | --- | --- |
> | *scanCapacitéPlateau* | Permet de savoir si le scanneur a un plateau. |
> | *scanCapacitéRectoVerso* | Permet de savoir si le scanneur supporte le recto-verso. |

## Remarques

Il est également possible de connaître les capacités d'un scanneur avec la fonction [<Variable Scanneur>.Propriété](1410087863.md). Cette fonction renvoie une combinaison des constantes correspondant aux capacités supportées par le scanneur. La fonction **<Variable Scanneur>.Capacité** simplifie le code permettant de savoir si le scanneur a une capacité donnée.

**Composante : wd300std.dll**
