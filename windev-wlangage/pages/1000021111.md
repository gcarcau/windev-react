# BitParPixel (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **BitParPixel** permet de connaître et de modifier le nombre de bits par pixels d'une image. Cette propriété est utilisable sur :

- une variable de type [Image](1000019650.md).
- une variable de type [upnpImage](1000020905.md).
- une variable de type [Icône](1000020811.md).
- une variable de type [Scanneur](1410087808.md).
