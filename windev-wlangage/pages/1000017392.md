# Fonctions Calendrier (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android)

Ces fonctions permettent de manipuler les champs Calendrier ainsi que les champs de saisie de type Date via une syntaxe préfixée :

| [<Calendrier>.Position](1000017361.md) | Renvoie le mois affiché dans un champ Calendrier. |
| --- | --- |
| [<Calendrier>.Select](1000017385.md) | Renvoie la date sélectionnée dans un champ Calendrier. |
| [<Calendrier>.SelectMoins](1000017363.md) | Désélectionne une date dans un champ Calendrier multisélection. |
| [<Calendrier>.SelectOccurrence](1000017362.md) | Renvoie le nombre de jours sélectionnés dans un champ Calendrier. |
| [<Calendrier>.SelectPlus](1000017343.md) | Sélectionne une date dans un champ Calendrier. |
| [<Saisie>.CalendrierOuvre](1000017423.md) | Dans un champ de saisie de type Date, ouvre une fenêtre popup affichant un calendrier. |
