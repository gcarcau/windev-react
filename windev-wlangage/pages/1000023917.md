# Destination (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **Destination** permet de définir :

- la destination d'une sauvegarde. Cette propriété est utilisable sur une variable de type [hDescriptionSauvegarde](1000017455.md).
- le fichier résultat d'une requête. Cette propriété est utilisable sur :
  - une variable de type [httpRequête](1000021158.md).
  - une variable de type [restRequête](1000021481.md).
  - une variable de type [TéléchargementInfo](1410087306.md).
  - une variable de type [TéléchargementParamètre](1410087293.md).
  - une variable de type [iInfoSortie](1410088954.md).
