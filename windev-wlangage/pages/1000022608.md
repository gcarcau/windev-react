# ActionRedo (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Exécute la dernière action annulée. Cette fonction est équivalente à un "Redo" (Ctrl + Y) de l'utilisateur.

## Exemple

```wlangage
// Bouton [Rétablir]
ActionRedo()
```

## Syntaxe

```wlangage
ActionRedo([<Fenêtre à manipuler>])
```

`<Fenêtre à manipuler>` *Nom de fenêtre optionnel*
> Nom de la fenêtre ou de la fenêtre interne à manipuler.
>
> - Si ce paramètre n'est pas précisé, l'action est exécutée dans la fenêtre en cours.
> - Si ce paramètre est précisé, la fonction **ActionRedo** est équivalente à la fonction [FenEdRedo](1000021905.md).

## Remarques

### Conditions d'utilisation

- Si aucune action n'a été annulée, la fonction **ActionRedo** ne fait rien.
- Si la dernière action est une action personnalisée exécutée par la fonction [ActionDo](1000022676.md), la procédure déclarée dans cette fonction est exécutée.
- L'action rétablie peut être à nouveau annulée avec la combinaison de touches Ctrl + Z ou par programmation grâce à la fonction [ActionUnDo](1000022677.md).
