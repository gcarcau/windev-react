# Personnaliser l'apparence d'une carte Google Maps

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android)

## Présentation

Dans les applications WINDEV et Android, le champ Carte utilise les cartes Google Maps. Le fonctionnement des styles des cartes Google Maps a été modifié par Google, et propose une large palette de possibilités.
Avant cette modification, les styles de carte étaient prédéfinis, et ils pouvaient être manipulés grâce aux fonctions [CarteChangeStyle](1000025556.md) et [CarteRécupèreStyle](1000025557.md).

- Nouveauté Abonnement
   Ces fonctions sont toujours utilisables tant qu'aucune carte personnalisée n'est utilisée. Si une carte personnalisée est utilisée, ces fonctions sont sans effet.
- Ces fonctions ne sont plus disponibles.

Désormais, les étapes pour définir et utiliser un style de carte sont les suivantes :

1. Définition des styles des cartes dans la console Google.
2. Association d'un ID de carte au style de carte.
3. Association de l'ID au champ Carte :
  - Nouveauté Abonnement
     via la fenêtre de description du champ.
    **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
    Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
  - via la fonction [CarteIdentifiantGgl](1410091136.md).

Un ID de carte est un identifiant unique qui représente les styles et les paramètres de configuration de Google Maps stockés dans Google Cloud. Les identifiants de carte peuvent être utilisés pour activer des fonctionnalités, ou pour gérer ou styliser des cartes dans vos applications.

## Les étapes en détail

### Définition des styles de carte dans la console Google
Depuis la console Google Cloud Platform "https://console.cloud.google.com" :

1. Connectez-vous avec votre compte développeur.
2. Sélectionnez le projet "Google" (ou créez-en un nouveau si nécessaire).
3. Accédez à "Google Maps Platform" soit depuis le menu de gauche soit depuis la recherche en haut.
4. Cliquez sur "Styles de carte".
5. Cliquez sur "Créer un style".
6. Choisissez si vous souhaitez créer un style en thème clair ou sombre.

Les différents éléments cartographiques peuvent alors être personnalisés (couleurs de fond, couleurs de texte, visibilité des différents éléments).
Lorsque la personnalisation des différents éléments cartographiques est terminée, enregistrez le style.

### Association d'un ID de carte au style de carte
Pour créer un ID de carte, toujours dans votre projet Google :

1. Cliquez sur l'option "Gestion des plans" depuis le menu de gauche.
2. Cliquez sur "Créer un ID de carte".
3. Donnez un nom à cet ID.
4. Sélectionnez le type de carte : Javascript ou Android.
  Dans le cas d'une application WINDEV, sélectionnez "Javascript".
5. Cliquez sur "Enregistrer".
6. Dans la partie "Styles de carte", il est alors possible de modifier le style de carte pour le thème clair et pour le thème sombre.
7. Cliquez sur "Modifier le style" du thème voulu : un volet s'ouvre, sélectionnez le style personnalisé juste créé.
8. Enregistrez l'ID de carte : il est nécessaire dans le code WLangage de l'application.

### Association de l'ID de carte au champ Carte
Pour utiliser le style de carte personnalisé, l'ID de carte doit être utilisé dans votre application. Deux méthodes sont disponibles :

- Fonction [CarteIdentifiantGgl](1410091136.md) :
  ```wlangage
  CarteIdentifiantGgl(CARTE_EX, <ID Carte>)
  ```
- Nouveauté Abonnement
   Description du champ Carte : Il est possible de spécifier l'ID de carte dans la fenêtre de description du champ Carte (onglet "Détail").
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

Remarque : Si aucun style n'a été personnalisé, le style par défaut des cartes Google est utilisé.

> _(Android)_ Cas particulier : Passage du thème clair au thème sombreLe changement de thème est différent selon le style utilisé : Sans utilisation d'ID de carte : Si le style de la carte correspond à la constante ccsAutomatique, les thèmes clair et sombre associé au style courant sont utilisés. Nouveauté AbonnementAvec utilisation d'un ID de carte : Pour le thème clair, le style personnalisé est utilisé. Pour le thème sombre, la personnalisation du style est ignorée. Le thème sombre par défaut est utilisé.Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3. Pour plus de détails, consultez Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement.
