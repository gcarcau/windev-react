# HDésactiveFiltre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Désactive temporairement un filtre sur un fichier de données (une vue ou une requête). Ce filtre a été créé avec la fonction [HFiltre](3044100.md). Si aucun filtre n'a été déclaré, la fonction **HDésactiveFiltre** est sans effet.

## Exemple

```wlangage
// Déclaration du filtre : sélection des clients
// qui ont entre 20 et 60 ans
HFiltre(Client, Age_Client, 20, 60)
...
HDésactiveFiltre(Client) // Filtre désactivé
...
// Parcours du fichier de données avec filtre sur l'âge
// Traitement des clients qui ont entre 20 et 60 ans
// (procédure TraiteClient2060)
HActiveFiltre(Client)
HLitPremier(Client, Age_Client)
TANTQUE HTrouve(Client) = Vrai
	TraiteClient2060()
	HLitSuivant(Client, Age_Client)
FIN
```

## Syntaxe

```wlangage
<Résultat> = HDésactiveFiltre([<Fichier de données>])
```

`<Résultat>` *Booléen*
> - Vrai si le filtre est désactivé,
> - Faux en cas d'erreur (fichier de données ou rubrique inexistant).
`<Fichier de données>` *Chaîne de caractères optionnelle*
> Nom du fichier de données, de la vue ou de la requête manipulé.
> Si ce paramètre n'est pas spécifié, la fonction **HDésactiveFiltre** manipule le dernier fichier de données utilisé par la dernière fonction de gestion HFSQL (fonction commençant par la lettre H).

## Remarques

### Activation et désactivation d'un filtre
Après la déclaration d'un filtre (fonction [HFiltre](3044100.md)), le filtre est actif. Après désactivation d'un filtre avec la fonction **HDésactiveFiltre**, le filtre peut être réactivé grâce à la fonction [HActiveFiltre](3044158.md).
Remarque : Lors de l'appel de la fonction [HFerme](3044073.md), le filtre activé par la fonction **HFiltre** est automatiquement supprimé.

### Nombre de filtres actifs possibles
Pour un fichier de données spécifique, un seul filtre peut être actif à la fois.

### Parcours
Les modifications apportées par les fonctions [HFiltre](3044100.md) et **HDésactiveFiltre** sont prises en compte uniquement lors de l'utilisation des fonctions [HLitPremier](3044051.md)/[HPremier](3044113.md), [HLitDernier](3044140.md)/[HDernier](3044101.md) ou [HLitRecherchePremier](3044036.md)/[HLitRechercheDernier](3044034.md).
