# Les Centres de Contrôle

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Un Centre de Contrôle permet d'avoir une vision globale du domaine couvert, que ce soit en phase de développement, sur un site d'exploitation, ou encore pour les aspects de maintenance ou d'évolution des applications.

## Les Centres de Contrôle dédiés à la gestion de projet

### Présentation
WINDEV, WEBDEV et WINDEV Mobile permettent de suivre le développement de projets grâce au [Centre de Gestion de Projets](3540701.md).
Le Centre de Gestion de Projets permet de gérer les différents événements de la vie d'un projet : Exigences, Tâches, Planning personnel, Incidents, etc. A partir de ce centre, les intervenants peuvent indiquer les tâches réalisées ou à réaliser, les incidents corrigés, etc. Ce Centre permet également de récupérer les retours client sur les applications déployées.

### Utiliser les Centres de Contrôle de développement
Pour utiliser les Centres de Contrôle de développement, plusieurs cas peuvent se présenter selon vos besoins :

- [Je suis développeur : Comment récupérer les bugs et/ou les suggestions de mes clients ?](3540719.md)
- [Je suis développeur : Comment gérer mes tâches et mon planning ?](3540721.md)
- [Je suis chef de projet : Comment gérer un projet de développement ?](3540722.md)

## Les Centres de Contrôle redistribuables

### Plusieurs Centres de Contrôle redistribuables sont livrés avec WINDEV, WEBDEV et WINDEV Mobile :

- **[Centre de Contrôle des moteurs et bases de données HFSQL (réseau et Client/Serveur)](3540001.md)**
  Ce Centre de Contrôle (également nommé Centre de Contrôle HFSQL) permet de gérer les différentes bases de données HFSQL (Réseau, Mobile et essentiellement Client/Serveur) qui sont présentes dans l'entreprise. Ce Centre de Contrôle peut être utilisé lors du développement d'une application. Il est redistribuable avec les applications HFSQL Client/Serveur.
- **[Centre de Contrôle Utilisateur](3540201.md)**
  Ce Centre de Contrôle permet de gérer les applications déployées sur un réseau d'entreprise. A partir de ce Centre de Contrôle, les utilisateurs peuvent installer les applications qui leur sont dédiées. Le Centre de Contrôle utilisateur est redistribuable.
- Le **[Centre de Contrôle des applications réseau](2028052.md)** : Le Centre de Contrôle des applications WINDEV permet au responsable d'une application utilisée en réseau d'avoir une vision complète de l'application à distance : gestion des mises à jour, gestion des utilisateurs, mise à jour avec prise en charge du Push, ... Ce Centre de Contrôle est redistribuable. Il est automatiquement installé avec les applications avec "Live update".

## Les Centres de Contrôle spécifiques

Plusieurs Centres de Contrôle spécifiques sont également fournis avec WINDEV, WEBDEV ou WINDEV Mobile :

- Le **[Gestionnaire de comptes WEBDEV](3539029.md)** : Destiné principalement aux hébergeurs et aux Webmasters, le Gestionnaire de comptes WEBDEV permet d'aider à héberger plus facilement les sites WEBDEV.
- Le **[Centre de Contrôle Android](1410086630.md)** : Le Centre de Contrôle Android vous permet de gérer facilement vos matériels Android pour les phases de mise au point. Ce Centre de Contrôle est livré avec WINDEV Mobile et il n'est pas redistribuable.
