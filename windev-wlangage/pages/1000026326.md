# Fonctions de gestion de la double authentification

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Les fonctions de gestion de la double authentification (fonctions "DoubleAuth") sont les suivantes :

| [DoubleAuthGénèreCléTOTP](1000025974.md) | Génère une clé TOTP pour un utilisateur dans une application. |
| --- | --- |
| [DoubleAuthGénèreLien](1000025975.md) | Génère un lien pour enregistrer un compte dans une application d'authentification. Affecté à un champ Code-barres, ce lien permettra d'afficher un QRCode pouvant être scanné dans l'application d'authentification choisie sur le téléphone. |
| [DoubleAuthVérifieCode](1000025976.md) | Vérifie le code donné par une application d'authentification. |
