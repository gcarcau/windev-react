# CelluleDéfaut

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux)

La propriété **CelluleDéfaut** permet de gérer le style des cellules dans les documents XLS.
Cette propriété est utilisable sur :

- une variable de type [xlsColonne](1000017471.md).
- une variable de type [xlsLigne](1000017325.md).
