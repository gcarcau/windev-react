# NbLigneMaxParLigne (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

La propriété **NbLigneMaxParLigne** permet de connaître et de modifier la hauteur maximum des lignes d'un champ Table (exprimée en nombre de caractères).

## Exemple

```wlangage
// Autorise jusqu'à 5 lignes de texte dans une ligne d'un champ Table
TABLE_MaTable_Client.NbLigneMaxParLigne = 5
```

## Syntaxe

#### Connaître la hauteur maximum des lignes d'un champ Table

```wlangage
<Résultat> = <Champ Table>.NbLigneMaxParLigne
```

`<Résultat>` *Entier*
> Nombre de lignes pouvant être affichées.
`<Champ Table>` *Nom de champ*
> Nom du champ Table manipulé. Ce champ peut être un champ Table fichier, champ Table par programmation ou champ Table sur variable.

#### Définir la hauteur maximum des lignes d'un champ Table

```wlangage
<Champ Table>.NbLigneMaxParLigne = <Nouvelle hauteur>
```

`<Champ Table>` *Nom de champ*
> Nom du champ Table manipulé. Ce champ peut être un champ Table fichier, champ Table par programmation ou champ Table sur variable.
`<Nouvelle hauteur>` *Entier*
> Nombre de lignes pouvant être affichées.
