# MatCompresse (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Compresse la place mémoire occupée par une matrice.
**Remarque** : La compression est nécessaire si vous manipulez une matrice importante sur laquelle de nombreux calculs ont été effectués. Si cette matrice comporte plusieurs colonnes et/ou lignes nulles, la compression permet de réduire nettement la taille mémoire de la matrice.

## Exemple

```wlangage
// Compression d'une matrice
MatCompresse("MaMatrice")
```

## Syntaxe

```wlangage
MatCompresse(<Matrice>)
```

`<Matrice>` *Chaîne de caractères*
> Nom de la matrice à compresser, défini avec la fonction [MatCrée](3050058.md).

## Remarques

### Existence de la matrice à compresser
L'existence de la matrice n'est pas vérifiée. Pour vérifier l'existence d'une matrice, utilisez la fonction [MatExiste](3050076.md).

### Gestion des erreurs
**Attention** : La fonction **MatCompresse** ne retourne pas de résultat. Pour savoir si des erreurs ont été générées par la compression, utilisez la fonction [MatErreur](3050044.md) sur cette matrice. Le libellé de l'erreur peut être connu grâce à la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.

**Classification Métier / UI : Code neutre**
