# Fonctions de manipulation de l'UI par l'utilisateur final (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU))

| [<Fenêtre>.EdActive](1000022294.md) | Permet :   - de savoir si le mode "Modification de l'UI par l'utilisateur final" est activé dans une fenêtre (ou une fenêtre interne). - d'activer ou non le mode "Modification de l'UI par l'utilisateur final" dans une fenêtre (ou une fenêtre interne). |
| --- | --- |
| [<Fenêtre>.EdCharge](1000022292.md) | Charge les modifications faites par l'utilisateur final dans une fenêtre. |
| [<Fenêtre>.EdCréeNote](1000022301.md) | Crée un champ Note repositionnable. |
| [<Fenêtre>.EdDésélectionneTout](1000022317.md) | Désélectionne tous les champs lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [<Fenêtre>.EdDo](1000022327.md) | Exécute une action (définie par programmation) avec support du Undo/Redo. |
| [<Fenêtre>.EdRedo](1000022328.md) | Exécute la dernière action annulée lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [<Fenêtre>.EdRestaure](1000022329.md) | Annule toutes les modifications effectuées par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [<Fenêtre>.EdSauve](1000022330.md) | Sauve les modifications réalisées en mode "Modification de l'UI par l'utilisateur final". |
| [<Fenêtre>.EdSelect](1000022331.md) | Renvoie l'un des champs sélectionnés lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [<Fenêtre>.EdSelectMoins](1000022332.md) | Dé-sélectionne un champ lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [<Fenêtre>.EdSelectOccurrence](1000022333.md) | Indique le nombre de champs sélectionnés lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [<Fenêtre>.EdSelectPlus](1000022334.md) | Sélectionne un champ lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
| [<Fenêtre>.EdUndo](1000022335.md) | Annule la dernière action effectuée lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé). |
