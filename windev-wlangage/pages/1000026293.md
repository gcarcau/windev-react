# zipFiltre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie la liste des formats d'archives gérés par la plateforme en cours, au format attendu par le filtre de la fonction [fSélecteur](3036053.md).

## Exemple

```wlangage
// Récupération de la liste des formats d'archives
ResFormatArchive = zipFiltre()
```

## Syntaxe

```wlangage
<Résultat> = zipFiltre()
```

`<Résultat>` *Chaîne de caractères*
> Liste des formats d'archives gérés par la plateforme en cours sous la forme :
>
>
> ```wlangage
> <Description> + TAB + <*.Extension> + RC + <Description2> + TAB + <*.Extension2>
> ```
>
>
>
> où :
>
> - <Description> correspond au nom du format. Par exemple : "Archive Winzip (*.zip)".
> - <Extension> correspond aux différentes extensions de <Description>.

## Remarques

### Formats d'archives supportés
Les formats d'archives supportés sous Windows sont :

- Archive Winzip (*.zip)
- Archive WINDEV (*.wdz)
- Cabinet file (*.cab)
- Roshal ARchive (*.rar)
- Archive 7z (*.7z)
- Tape ARchive (*.tar)
- Tape ARchive compressée (*.tgz; *.tar.gz; *.gz)
- Archive WINDEV auto-extractible (*.exe)

**Composante : wd300zip.dll**
