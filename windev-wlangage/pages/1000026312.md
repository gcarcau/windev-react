# <Variable htmlDocument>.ChercheElémentParBalise (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Cherche les éléments d'un document HTML correspondant à une balise.

## Exemple

```wlangage
d est un htmlDocument = HTMLOuvre("https://www.pcsoft.fr", depuisURL)
// ...
t est un tableau de htmlNoeud <- d.ChercheElémentParBalise("form")
```

## Syntaxe

```wlangage
<Résultat> = <Elément à manipuler>.ChercheElémentParBalise([<Elément recherché>])
```

`<Résultat>` *Tableau*
> Tableau d'éléments de type [htmlNoeud](1000026081.md) correspondant à la recherche.
`<Elément à manipuler>` *Variable de type htmlDocument*
> Nom de la variable de type [htmlDocument](1000025910.md) dans laquelle la recherche doit être effectuée.
`<Elément recherché>` *Chaîne de caractères optionnelle*
> Nom de la balise à rechercher. Si ce paramètre n'est pas précisé ou correspond à une chaîne vide (""), <Résultat> contiendra tous les éléments.
