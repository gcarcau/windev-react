# BeaconArrêteDétectionEnArrièrePlan (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Arrête une ou plusieurs détections de balises Beacon en arrière-plan. Ces détections ont été lancées avec la fonction [BeaconDétecteEnArrièrePlan](1000023112.md).

## Exemple

```wlangage
// Suppression de toutes les détections en arrière-plan
BeaconArrêteDétectionEnArrièrePlan()
```

## Syntaxe

#### Supprimer toutes les détections en arrière-plan

```wlangage
<Résultat> = BeaconArrêteDétectionEnArrièrePlan()
```

`<Résultat>` *Booléen*
> - Vrai si toutes les détections ont été arrêtées,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).

#### Supprimer une détection en arrière-plan

```wlangage
<Résultat> = BeaconArrêteDétectionEnArrièrePlan(<Groupe de balises Beacon>)
```

`<Résultat>` *Booléen*
> - Vrai si la détection a bien été arrêtée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Groupe de balises Beacon>` *Variable de type beaconGroupe*
> Nom de la variable de type [beaconGroupe](1000023105.md) correspondant au groupe de balises Beacon dont la détection doit être arrêtée.

#### Supprimer plusieurs détections en arrière-plan

```wlangage
<Résultat> = BeaconArrêteDétectionEnArrièrePlan(<Tableau de groupes de balises>)
```

`<Résultat>` *Booléen*
> - Vrai si la détection a bien été arrêtée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Tableau de groupes de balises>` *Tableau de variables de type beaconGroupe*
> Nom du tableau de variables de type [beaconGroupe](1000023105.md) correspondant aux groupes de balises Beacon dont la détection doit être arrêtée.

## Remarques

### Version nécessaire

> _(Android, Widget Android)_ Les fonctions de gestion des balises Beacon sont disponibles uniquement sur les appareils disposant d'une version d'Android supérieure ou égale à la version 4.3 (api level 18).
Si la fonction est utilisée avec une version antérieure du système, une erreur fatale sera déclenchée. Pour connaître la version du système Android sur laquelle s'exécute l'application, utilisez la fonction SysVersionAndroid.

> _(iPhone/iPad, Widget IOS)_ Les fonctions de gestion des balises Beacon sont disponibles uniquement sur les appareils disposant d'une version d'iOS supérieure ou égale à iOS 11.
