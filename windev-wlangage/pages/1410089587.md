# VisualisationMarkdown (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **VisualisationMarkdown** permet d'indiquer ou non si un champ de saisie affiche son contenu au format Markdown.
Remarque : Cette propriété permet de changer le type du champ de saisie en le rendant de type "Visualisation Markdown".

## Exemple

```wlangage
// Clic sur [Prévisu en Markdown]
SAI_Promo.VisualisationMarkdown = Vrai

// Clic sur [Modification]
SAI_Promo.VisualisationMarkdown = Faux
DonneFocus(SAI_Promo)
```

## Syntaxe

#### Savoir si le champ de saisie affiche son contenu au format Markdown

```wlangage
<Résultat> = <Champ de saisie>.VisualisationMarkdown
```

`<Résultat>` *Booléen*
> - Vrai si le champ de saisie est en lecture seule avec le contenu affiché au format Markdown. Le défilement et la sélection sont possibles (sauf si la propriété [Etat](2510039.md) vaut *Grisé*). La propriété [Etat](2510039.md) du champ est inchangée. Le champ de saisie est de type "Visualisation Markdown".
> - Faux si le champ de saisie est en saisie.
`<Champ de saisie>` *Nom de champ*
> Nom du champ de saisie manipulé.

#### Indiquer si un champ de saisie affiche ou non son contenu au format Markdown

```wlangage
<Champ de saisie>.VisualisationMarkdown = <Mode de gestion>
```

`<Champ de saisie>` *Nom de champ*
> Nom du champ de saisie manipulé.
`<Mode de gestion>` *Booléen*
> - Vrai : le champ de saisie passe en lecture seule avec le contenu affiché au format Markdown. Le défilement et la sélection sont possibles (sauf si la propriété [Etat](2510039.md) vaut *Grisé*). La propriété [Etat](2510039.md) du champ est inchangée. Le champ de saisie passe en champ de saisie de type "Visualisation Markdown".
> - Faux : le champ de saisie repasse en saisie. Il est également nécessaire d'utiliser la propriété [Etat](2510039.md) pour le rendre actif.

## Remarques

- L'option "Gestion du Markdown" présente dans l'onglet "UI" de la fenêtre de description des champs de saisie s'applique uniquement au libellé, à la bulle et aux jetons associés au champ de saisie. Cette propriété ne s'applique pas au contenu du champ de saisie.
- Pour afficher des données au format Markdown, le champ de saisie doit :
  - soit être de type "Visualisation Markdown".
  - soit avoir la propriété **VisualisationMarkdown** à Vrai.
