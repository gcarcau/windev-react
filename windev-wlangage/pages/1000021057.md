# AscenseurPosition (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Permet de gérer la position des ascenseurs :

- Modifie ou récupère la position d'un des ascenseurs (horizontal ou vertical) d'un champ ou d'une fenêtre dans une application WINDEV ou WINDEV Mobile.
- Récupère la position d'un des ascenseurs (horizontal ou vertical) d'une page dans un site WEBDEV.

## Exemple

> _(WINDEV, Android, iPhone/iPad)_ // Synchronisation des ascenseurs de deux champs Table
nPos = AscenseurPosition(TABLE_MaTable, ascVert)
AscenseurPosition(TABLE_MaTable2, ascVert, nPos)

## Syntaxe

#### Connaître la position de l'ascenseur

```wlangage
<Résultat> = AscenseurPosition(<Elément manipulé> [, <Orientation>])
```

`<Résultat>` *Entier*
> - Position de la cage de l'ascenseur.
> - 0 si l'ascenseur n'existe pas ou si l'ascenseur est grisé.
`<Elément manipulé>` *Nom de champ, de fenêtre ou de page*
> - Nom du champ manipulé.
>    Cette fonction n'est pas disponible pour le champ Image.
> - Nom de la fenêtre manipulée.
> - Nom de la page manipulée.
`<Orientation>` *Constante optionnelle de type Entier*
> Orientation de l'ascenseur pour lequel la position doit être récupérée :
>
> | *ascHorz* | La position est calculée pour l'ascenseur horizontal du champ. |
> | --- | --- |
> | *ascVert* (Valeur par défaut) | La position est calculée pour l'ascenseur vertical du champ. |

> _(WINDEV, Android, iPhone/iPad, iPhone/iPad)_ Modifier la position de l'ascenseur Masquer les détails
<Résultat> = AscenseurPosition(<Champ manipulé> , <Orientation> , <Nouvelle position>)

 <Résultat> : EntierNouvelle position de la cage de l'ascenseur. <Champ manipulé> : Nom de champNom du champ manipulé.
 Cette fonction n'est pas disponible pour le champ Image. <Orientation> : Constante optionnelle de type EntierOrientation de l'ascenseur pour lequel la position doit être modifiée : ascHorzLa position est modifiée pour l'ascenseur horizontal du champ.ascVertLa position est modifiée pour l'ascenseur vertical du champ. <Nouvelle position> : Entier optionnelNouvelle position de l'ascenseur. La position de l'ascenseur commence à 1. Si la valeur spécifiée n'est pas dans les bornes spécifiées pour l'ascenseur du champ, une position correcte est forcée. Si l'ascenseur n'existe pas ou est grisé, la nouvelle position n'est pas prise en compte : la fonction ne fait rien.

## Remarques

> _(WINDEV)_ La fonction AscenseurPositionMax permet de connaître la position maximale d'un des ascenseurs (horizontal ou vertical) d'un champ dans une application WINDEV.
