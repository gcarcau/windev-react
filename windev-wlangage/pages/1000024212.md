# <Source>.DébloqueNumEnr (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Débloque un enregistrement précédemment bloqué avec :

- soit la fonction [<Source>.BloqueNumEnr](1000024197.md),
- soit une fonction de lecture utilisée avec un paramètre bloquant (par exemple fonction [<Source>.Lit](1000025019.md) utilisé avec la constante *hBlocageEcriture* ou la constante *hBlocageLectureEcriture*).

**Remarque** : La fonction **<Source>.DébloqueNumEnr** ne permet pas de débloquer un enregistrement bloqué par une autre application.
> _(Java)_ Cette fonction est disponible uniquement pour les fichiers de données HFSQL. Elle n'est pas disponible pour les fichiers de données accédés par JDBC.

## Exemple

```wlangage
// Blocage
Client.BloqueNumEnr(hNumEnrEnCours, hBlocageLectureEcriture)
// Modification de l'enregistrement
...
// Déblocage
Client.DébloqueNumEnr(hNumEnrEnCours)
```

## Syntaxe

```wlangage
<Résultat> = <Source>.DébloqueNumEnr([<Numéro d'enregistrement>])
```

`<Résultat>` *Booléen*
> - Vrai si l'enregistrement a été débloqué,
> - Faux en cas de problème. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Source>` *Type correspondant à la source spécifiée*
> Nom du fichier de données manipulé.
`<Numéro d'enregistrement>` *Entier optionnel*
> Numéro de l'enregistrement à débloquer.
> Si ce numéro n'est pas spécifié (égal à 0 ou à la constante *hNumEnrEnCours*), la fonction **<Source>.DébloqueNumEnr** va manipuler l'enregistrement en cours.
>
> > _(Connecteurs Natifs (Accès Natifs))_ La fonction <Source>.DébloqueNumEnr débloque uniquement l'enregistrement en cours. Il est impossible de spécifier un numéro d'enregistrement différent de celui en cours (pour désigner l'enregistrement en cours, utilisez la constante hNumEnrEnCours).

## Remarques

La fonction **<Source>.DébloqueNumEnr** est sans effet si :

- Le fichier de données est en mode Mono (voir la fonction [<Source>.Mode](1000025037.md)).
- L'enregistrement n'est pas bloqué.

**Composante : wd300hf.dll**
