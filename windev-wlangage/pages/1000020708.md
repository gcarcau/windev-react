# Gestion des agendas (Android/iOS)

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

WINDEV Mobile permet d'accéder simplement aux agendas et aux rendez-vous des téléphones et tablettes sous Android et iOS. Il est par exemple possible de :

- Lister les agendas existants.
- Lister les rendez-vous.
- Ajouter un nouveau rendez-vous à un agenda.
- Nouveauté 2025
  Ajouter un nouveau rendez-vous à l'agenda par défaut du téléphone.
- Modifier les données d'un rendez-vous.
- Supprimer un rendez-vous.
- Supprimer tous les rendez-vous d'un agenda.
- Définir la répétition d'un rendez-vous (tous les jours, tous les mois, etc.).
- Ajouter/Modifier/Supprimer les rappels pour un rendez-vous donné (exemple : envoi d'un SMS une heure avant le rendez-vous).
- Lancer l'application native de gestion des agendas pour créer, éditer ou visualiser un rendez-vous.

## Mise en place

Pour gérer les rendez-vous d'un agenda (calendrier), WINDEV Mobile propose :

- Plusieurs types de données :
  | [Calendrier](1000020663.md) | Le type **Calendrier** permet de manipuler un calendrier (ou agenda) associé à un compte utilisateur ou bien se trouvant sur l'appareil. |
  | --- | --- |
  | [RendezVous](1000019244.md) | Le type **RendezVous** permet de définir toutes les caractéristiques avancées d'un rendez-vous : horaires, lieu, ... |
- Diverses fonctions :
  - Fonctions pour gérer l'ajout, la suppression et la modification des rendez-vous :
    | [RendezVousAjoute](1000011001.md) | Ajoute un rendez-vous :   - dans l'agenda d'une messagerie Lotus Notes ou Outlook. - dans un calendrier (ou agenda) d'un appareil mobile (Android ou iOS). |
    | --- | --- |
    | [RendezVousModifie](1000011003.md) | Modifie le rendez-vous en cours :   - dans l'agenda d'une messagerie Lotus Notes ou Outlook. - dans un calendrier (ou agenda) d'un appareil mobile (Android/iOS). |
    | [RendezVousSupprime](1000011008.md) | Supprime :   - le rendez-vous en cours de l'agenda d'une messagerie Lotus Notes ou Outlook. - un rendez-vous dans un calendrier (ou agenda) d'un appareil mobile (Android/iOS). |
  - Fonctions pour lister les rendez-vous et faire des recherches :
    | [RendezVousListe](1000020690.md) | Liste les rendez-vous présents sur le mobile (Android/iOS) et correspondant aux critères spécifiés. |
    | --- | --- |
    | [RendezVousListeCalendrier](1000020661.md) | Liste les calendriers disponibles sur l'appareil mobile (Android/iOS). |
  - Fonctions utilisant l'application native de gestion des agendas (calendriers) :
    | [RendezVousAffiche](1000020692.md) | Affiche un rendez-vous dans l'application native de gestion des rendez-vous de l'appareil mobile (Android ou iOS). |
    | --- | --- |
    | [RendezVousCrée](1000020691.md) | Permet de créer un rendez-vous via la fenêtre de création de rendez-vous de l'application native de gestion des rendez-vous de l'appareil Android ou iOS. |

> _(Android)_ Remarque : Ces fonctions peuvent être utilisées dans l'émulateur mais pas dans le simulateur.
