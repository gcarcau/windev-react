# Espagne.VérifieDNI (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un numéro DNI (numéro d'identification personnel en Espagne).

## Exemple

```wlangage
// Test d'une variableMonNuméroDNI est une chaîne = "12345678Z"Espagne.VérifieDNI(MonNuméroDNI) // renvoie Vrai // Test d'un champSAI_NuméroDNI = "ABC"Espagne.VérifieDNI(SAI_NuméroDNI) // renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = Espagne.VérifieDNI(<Numéro à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un numéro DNI valide.
> - Faux dans le cas contraire.
`<Numéro à vérifier>` *Nom de champ ou variable de type chaîne*
> Numéro DNI à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.

**Composante : wd300std.dll**
