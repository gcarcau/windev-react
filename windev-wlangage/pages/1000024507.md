# <Variable Document>.DébutModification (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Signale le début du regroupement d'un ensemble d'opérations sur une variable de type [Document](1000022461.md) en un seul événement (gestion du "undo/redo").

## Exemple

```wlangage
MonDocument est un Document

MonDocument.DébutModification()
MonDocument.Remplace("%NomClient%", Client.Nom)
MonDocument.Remplace("%PrénomClient%", Client.Prénom)
MonDocument.FinModification()
```

## Syntaxe

```wlangage
<Document>.DébutModification()
```

`<Document>` *Variable de type Document*
> Nom de la variable de type [Document](1000022461.md) à manipuler.

## Remarques

Le regroupement est annulé par l'utilisation des fonctions [<Variable Document>.Undo](1000024538.md), [<Variable Document>.UndoRedoSupprimeTout](1000024540.md), [<Variable Document>.Ferme](1000024508.md) et [<Traitement de texte>.Ouvre](1000024269.md).

**Composante : wd300mdl.dll**
