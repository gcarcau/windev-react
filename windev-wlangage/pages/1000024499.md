# <Variable picCalque>.PixelOpacité (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Identifie l'opacité d'un pixel d'une image (présente dans une variable de type [picCalque](1000024604.md)) gérant la couche Alpha.

## Exemple

```wlangage
MonImageWDPic est un WDPic = "Test.bmp"
MonCalque est un picCalque
// Identification de l'opacité du pixel (15, 25)
// sur le calque
ResOpacité = MonCalque.PixelOpacité(15, 25)
IMG_MonDessin = MonImageWDPic
```

## Syntaxe

```wlangage
<Résultat> = <Image picCalque>.PixelOpacité(<Abscisse> , <Ordonnée>)
```

`<Résultat>` *Entier*
> Opacité du pixel spécifié (comprise entre 0 pour transparent, et 255 pour une opacité complète).
`<Image picCalque>` *Variable de type picCalque*
> Nom de la variable de type [picCalque](1000024604.md) à manipuler.
`<Abscisse>` *Entier*
> Position horizontale du pixel à manipuler.
`<Ordonnée>` *Entier*
> Position verticale du pixel à manipuler.

## Remarques

### Coordonnées
Les coordonnées sont indiquées en pixels par rapport au coin haut gauche de l'image (coordonnées (0,0)).

### Dessin dans une image avec opacité
Pour spécifier que le dessin dans l'image gère l'opacité (couche Alpha), utilisez la fonction [<Variable picCalque>.DébutDessin](1000024470.md) en spécifiant la constante ***dAvecOpacité***.
