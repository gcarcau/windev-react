# <Variable Connexion>.ListeBaseDeDonnées (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Liste les bases de données Client/Serveur associées à une connexion.

> _(PHP)_ Liste les bases de données associées à une connexion MySQL.

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion

// Ouverture de la connexion
MaConnexion.OuvreConnexion()
...
// Ajoute dans un champ de saisie les bases de données de MaConnexion
SAI_Saisie1 = MaConnexion.ListeBaseDeDonnées()
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.ListeBaseDeDonnées([<Options>])
```

`<Résultat>` *Chaîne de caractères*
> Liste des bases de données du serveur défini par la connexion. En fonction de la constante utilisée, le résultat est plus ou moins détaillé :
>
> | *hLstNormal* | Liste les bases de données du serveur défini par la connexion : <Nom de la base de données 1 + TAB + <Nom de la base de données 2 + TAB + ... |
> | --- | --- |
> | *hLstFichier* | Liste les bases de données et leurs fichiers pour le serveur défini par la connexion : <Nom de la base de données 1 + TAB + <Nom du fichier de données 1 dans la base de données 1 + TAB + ... + RC + <Nom de la base de données 2 + TAB + <Nom du fichier de données 1 dans la base de données 2 + TAB + ... + RC + ... |
> | *hLstTailleBaseDeDonnées* | Liste les bases de données et leur taille (en octets) pour le serveur défini par la connexion : <Nom de la base de données 1 + TAB + <Taille de la base de données 1 + RC + <Nom de la base de données 2 + TAB + <Taille de la base de données 2 + RC + ... _(PHP)_ Non disponible. |
>
>
> Où :
>
> - <Nom de la base de données X> : Nom de la base de données.
> - <Nom du fichier de données Y dans la base de données X> : Nom du fichier de données physique Y présent dans la base de données X.
> - <Taille de la base de données X> : Taille de l'ensemble des fichiers constituant la base de données en octets.
>
>
> En cas d'erreur, la liste des bases de données correspond à une chaîne vide ("") et la fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion à manipuler.
`<Options>` *Constante ou combinaison de constantes de type entier (optionnel)*
> Type de liste à effectuer :
>
> | *hLstFichier* | Liste détaillée, permettant de connaître les fichiers associés à chaque base de données. |
> | --- | --- |
> | *hLstNormal* (valeur par défaut) | Liste non détaillée, contenant uniquement le nom des bases de données associées à une connexion. |
> | *hLstTailleBaseDeDonnées* | Liste détaillée, permettant de connaître la taille de l'ensemble des fichiers associés à chaque base de données. _(Android, Widget Android, Java, PHP)_ Non disponible. |

## Remarques

> _(WINDEV, WEBDEV - Code Serveur, Connecteurs Natifs (Accès Natifs))_ Fonction <Variable Connexion>.ListeBaseDeDonnées et le Connecteur Natif MySQLLa fonction HListeFichier renvoie uniquement la liste des fichiers de la base de données en cours. La fonction <Variable Connexion>.ListeBaseDeDonnées liste les bases de données MySQL accessibles et leurs fichiers.
