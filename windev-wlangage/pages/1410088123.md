# DiagrammeCharge (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Charge un diagramme dans une variable de type Diagramme à partir d'un fichier ".wddiag", d'un mémo ou d'un buffer binaire.

## Exemple

```wlangage
MonDiagramme est un Diagramme
MonDiagramme <- EDIAG_MonDiagramme
DiagrammeCharge(MonDiagramme, "diagramme1.wddiag")
SI ErreurDétectée ALORS
	Erreur("Fichier non chargé : " + ErreurInfo())
FIN
```

## Syntaxe

```wlangage
<Résultat> = DiagrammeCharge(<Diagramme> , <Fichier à charger>)
```

`<Résultat>` *Booléen*
> - Vrai si le fichier a été chargé,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de détails sur l'erreur.
`<Diagramme>` *Variable de type Diagramme*
> Nom d'une variable de type [Diagramme](1410088055.md) dans laquelle le fichier doit être chargé.
`<Fichier à charger>` *Chaîne de caractères*
> Fichier diagramme à charger. Ce fichier peut correspondre :
>
> - au chemin complet d'un fichier ".wddiag",
> - au nom d'un fichier ".wddiag" (si le fichier est dans le répertoire de l'exécutable),
> - à un buffer binaire contenant les données complètes d'un fichier ".wddiag" (résultat de la fonction [DiagrammeSauve](1410088122.md)). Dans ce cas, il est possible d'utiliser une affectation directe :
>   ```wlangage
>   Nom_Champ_Diagramme = NomFichier.NomRubriqueBinaire
>   ```
