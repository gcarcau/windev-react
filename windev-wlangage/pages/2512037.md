# GrosFichier (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

La propriété **GrosFichier** permet de paramétrer la taille maximale possible d'un fichier de données. Il est ainsi possible de :

- Savoir si un fichier de données est configuré pour contenir plus de 2 Go de données (fichier de données défini sous l'éditeur d'analyses ou défini par programmation).
- Définir les caractéristiques de taille d'un fichier de données (lors de la description du fichier par programmation uniquement).

## Exemple

```wlangage
// Définir la taille maximale du fichier de données Client
Client.GrosFichier = Vrai
...
// Valide la description du fichier de données
HDécritFichier(Client)
```

## Syntaxe

#### Savoir si le fichier de données peut contenir plus de 2 Go de données

```wlangage
<Résultat> = <Fichier de données>.GrosFichier
```

`<Résultat>` *Booléen*
> - Vrai si le fichier de données est configuré pour contenir plus de 2 Go de données,
> - Faux dans le cas contraire.
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données manipulé. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Fichier](1514065.md).

#### Définir si le fichier de données peut contenir plus de 2 Go de données (fichier défini par programmation)

```wlangage
<Fichier de données>.GrosFichier = <Taille 2Go>
```

`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données manipulé. Ce nom vient d'être défini grâce au type [Description de Fichier](1514065.md).
`<Taille 2Go>` *Booléen*
> - Vrai si le fichier de données doit être configuré pour contenir plus de 2 Go de données,
> - Faux dans le cas contraire.

## Remarques

### Fichiers de données de plus de 2 Go
Les fichiers de données de plus de 2 Go ne peuvent être créés que sur des disques de type NTFS. De plus, le système d'exploitation doit lui aussi gérer et supporter les fichiers de plus de 2 Go.
