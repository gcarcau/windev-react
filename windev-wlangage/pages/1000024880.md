# <Variable Thread>.Attend (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Attend la fin de l'exécution du thread désigné. Un temps maximum d'attente peut être précisé.
**Rappel** : Un thread est un processus lancé en parallèle de l'application en cours ("thread" principal). Il est par exemple possible de lancer l'exécution d'une tâche en traitement de fond (sauvegarde, ...).

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, iPhone/iPad, Widget IOS, Apple Watch)_ // Construit un threadt est un Thread(Proc, ("Premier paramètre", 2))// Déclenche l'exécution du threadThreadExécute(t)...t.Attend(300)

## Syntaxe

> _(WINDEV, WEBDEV - Code Serveur, iPhone/iPad, Widget IOS, Apple Watch)_ Attendre la fin de l'exécution du thread (utilisation d'une variable de type Thread) Masquer les détails
<Résultat> = <Thread à attendre>.Attend([<Durée maximale>])

 <Résultat> : BooléenVrai si le thread s'est arrêté ou si le thread n'existe pas, Faux si le thread n'est pas arrêté (la durée maximale s'est écoulée). <Thread à attendre> : Variable de type ThreadNom de la variable de type Thread correspondant au thread dont il faut attendre la fin de l'exécution. <Durée maximale> : Entier optionnel, Durée optionnelle ou constante optionnelleNombre de centièmes de seconde d'attente maximale. Si à la fin de la durée spécifiée, le thread n'est pas arrêté, <Résultat> est égal à Faux. Si ce paramètre n'est pas spécifié ou correspond à la constante Infini, l'attente est infinie. Ce paramètre peut correspondre à : un entier correspondant au nombre de centièmes de seconde, une variable de type Durée, l'indication directe de la durée (par exemple 1 s ou 10 ms).

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
