# <Variable sfConnexion>.Connecte (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Permet de s'authentifier auprès de la plateforme Salesforce.

## Exemple

```wlangage
// Connexion à Salesforce
Cnx est une sfConnexion
Cnx.Login = "balthazar@gmail.com"
Cnx.MotDePasse = "azerty" + "XXB12VCZ54"
SI Cnx.Connecte() = Faux ALORS
	Erreur("La connexion a échoué." + RC + ErreurInfo())
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Connexion Salesforce>.Connecte()
```

`<Résultat>` *Booléen*
> - Vrai si l'authentification a été réalisée,
> - Faux en cas de problème. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Connexion Salesforce>` *Variable de type sfConnexion*
> Nom de la variable de type [sfConnexion](1000017579.md) à utiliser.

## Remarques

### Cas d'erreurs possibles :

- La connexion Internet n'est pas valide.
- L'authentification n'a pas pu être réalisée correctement.

**Composante : wd300ggl.dll**
