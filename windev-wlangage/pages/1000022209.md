# NationVersSousLangue (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Renvoie la sous-langue par défaut correspondant à une nation.

## Exemple

```wlangage
Res = NationVersSousLangue(nationAustralien)// Res = 3
```

## Syntaxe

```wlangage
<Résultat> = NationVersSousLangue(<Nation>)
```

`<Résultat>` *Entier*
> Sous-langue de la nation spécifiée.
