# dRectangleArrondi (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Dessine un rectangle arrondi :

- dans un champ Image,
- dans une variable de type [Image](1000019650.md).
   Ce type de variable n'est pas disponible.
- dans une variable de type [WDPic](1000023503.md) (sur le calque d'arrière-plan),
- dans une variable de type [picCalque](1000024604.md).

Remarque : Pour dessiner des rectangles personnalisés, il est conseillé d'utiliser la fonction [dCadre](1000021894.md).

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Dessiner en WINDEV, WEBDEV et WINDEV Mobile.

## Exemple

```wlangage
// Initialise le dessin dans un champ Image
dDébutDessin(IMG_Dessin)

// Dessin d'un rectangle arrondi dont le fond est jaune clair
// et le bord bleu clair
dRectangleArrondi(10, 10, 50, 50, 3, JauneClair, BleuClair)
```

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS, Mac Catalyst, Code Utilisateur (MCU), Ajax)_ // Dessin d'un rectangle arrondi dont le fond est jaune clair
// et le bord bleu clair
dRectangleArrondi(IMG_Dessin, 10, 10, 50, 50, 3, JauneClair, BleuClair)

## Syntaxe

#### Dessiner un rectangle arrondi en spécifiant les coordonnées du rectangle et le diamètre des coins

```wlangage
dRectangleArrondi([<Image>, ] <X1> , <Y1> , <X2> , <Y2> , <Diamètre du coin> [, <Fond> [, <Trait>]])
```

`<Image>` *Nom de champ optionnel ou variable de type Image, WDPic ou picCalque optionnelle*
> > _(Etats et Requêtes, Windows, Linux, iPhone/iPad, Widget IOS, Mac Catalyst, Code Utilisateur (MCU), WINDEV, WEBDEV - Code Serveur, WINDEV, WEBDEV - Code Serveur)_ Image à manipuler. Cette image peut correspondre : au nom d'un champ Image. au nom d'une variable de type Image. au nom d'une variable de type WDPic. Seul le calque d'arrière-plan sera manipulé. au nom d'une variable de type picCalque. Si ce paramètre n'est pas précisé, il est nécessaire de définir la destination du dessin avec la fonction dDébutDessin.
>
> > _(WEBDEV - Code Navigateur)_ Ce paramètre n'est pas disponible.
`<X1>` *Entier*
> Abscisse en pixels du coin haut gauche du rectangle.
`<Y1>` *Entier*
> Ordonnée en pixels du coin haut gauche du rectangle.
`<X2>` *Entier*
> Abscisse en pixels du coin bas droit du rectangle.
`<Y2>` *Entier*
> Ordonnée en pixels du coin bas droit du rectangle.
`<Diamètre du coin>` *Entier*
> Diamètre des coins du rectangle.
`<Fond>` *Entier ou constante de type Entier (optionnel)*
> - Couleur du fond du rectangle. Cette couleur peut être :
>   - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
>   - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
>   - [une couleur prédéfinie du WLangage](3010002.md),
>   - une variable de type [Couleur](1000019661.md),
>   - transparente si ce paramètre n'est pas précisé et si la fonction [dFond](3029002.md) n'a pas été utilisée auparavant.
> - Caractéristiques du fond :
>   - variable de type [Fond](1000022038.md). Dans ce cas, le dégradé défini dans la variable n'est pas pris en compte.
>   - caractéristiques spécifiées dans le dernier appel à la fonction [dFond](3029002.md) si ce paramètre n'est pas précisé.
>
>
> Pour utiliser une couleur de fond dégradée, utilisez la fonction [dRectangleDégradé](1000017059.md).
`<Trait>` *Entier, constante ou variable de type Cadre (optionnel)*
> Couleur du trait du rectangle. Cette couleur peut être :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md),
> - une variable de type [Couleur](1000019661.md).
>
> Si ce paramètre n'est pas spécifié :
>
> - couleur précisée dans le dernier appel à la fonction [dStylo](3029029.md).
> - couleur identique à la couleur utilisée pour le fond si la fonction [dStylo](3029029.md) n'a pas été utilisée.

dRectangleArrondi([<Image>, ] <X1> , <Y1> , <X2> , <Y2> , <Cadre> [, <Fond>])

`<Image>` *Nom de champ optionnel ou variable de type Image, WDPic ou picCalque optionnelle*
> > _(Etats et Requêtes, Windows, Linux, iPhone/iPad, Widget IOS, Mac Catalyst, Code Utilisateur (MCU), WINDEV, WEBDEV - Code Serveur, WINDEV, WEBDEV - Code Serveur)_ Image à manipuler. Cette image peut correspondre : au nom d'un champ Image. au nom d'une variable de type Image. au nom d'une variable de type WDPic. Si ce paramètre n'est pas précisé, il est nécessaire de définir la destination du dessin avec la fonction dDébutDessin.
>
> > _(WEBDEV - Code Navigateur)_ Ce paramètre n'est pas disponible.
`<X1>` *Entier*
> Abscisse en pixels du coin haut gauche du rectangle.
`<Y1>` *Entier*
> Ordonnée en pixels du coin haut gauche du rectangle.
`<X2>` *Entier*
> Abscisse en pixels du coin bas droit du rectangle.
`<Y2>` *Entier*
> Ordonnée en pixels du coin bas droit du rectangle.
`<Cadre>` *Variable de type Cadre*
> Nom de la variable de type [Cadre](15140100.md) définissant les caractéristiques du rectangle. Seules les propriétés suivantes sont prises en compte :
>
> - Arrondi : si la propriété correspond à la constante *ArrondiIndéfini*, aucun arrondi n'est réalisé.
> - Couleur : si la propriété correspond à la constante *CouleurIndéfinie*, la couleur définie lors dernier appel à la fonction [dStylo](3029029.md) est utilisée. Si cette fonction n'a pas été utilisée, la couleur de fond du rectangle est utilisée.
> - Epaisseur : si la propriété correspond à la constante *EpaisseurIndéfinie*, l'épaisseur définie lors du dernier appel à la fonction [dStylo](3029029.md) est utilisée. Si cette fonction n'a pas été utilisée, l'épaisseur vaut 1.
> - Trait : si la propriété correspond à *TraitIndéfini*, le type de trait défini lors du dernier appel à la fonction [dStylo](3029029.md) est utilisé. Si cette fonction n'a pas été utilisée, le trait est un trait continu.
`<Fond>` *Entier, constante ou variable de type Fond (optionnel)*
> - Couleur du fond du rectangle. Cette couleur peut être :
>   - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
>   - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),

>   - transparente si ce paramètre n'est pas précisé et si la fonction [dFond](3029002.md) n'a pas été utilisée auparavant.

>   - variable de type [Fond](1000022038.md). Dans ce cas, le dégradé défini dans la variable n'est pas pris en compte.
>   - caractéristiques spécifiées dans le dernier appel à la fonction [dFond](3029002.md) si ce paramètre n'est pas précisé.
>
>
> Pour utiliser une couleur de fond dégradée, utilisez la fonction [dRectangleDégradé](1000017059.md).

## Remarques

### Coordonnées

Les coordonnées sont indiquées par rapport au coin haut gauche du champ Image ou de l'image (coordonnées (0,0)).

### Utilisation des fonctions de dessin
Les fonctions de dessin peuvent être utilisées selon 2 méthodes :

- **Méthode 1 : Utilisation de la fonction dDébutDessin**
  - La fonction [dDébutDessin](3029009.md) doit être appelée avant toute autre fonction de dessin. La fonction [dDébutDessin](3029009.md) permet de définir l'élément (champ Image ou variable) sur lequel les fonctions de dessin vont intervenir.
  - Dans le cas du dessin sur un champ Image :
    - Les fonctions de dessin travaillent sur une copie ("bitmap") de l'image. Vous pouvez utiliser les fonctions de dessin de Windows (grâce à la fonction [API](3014005.md) ou [AppelDLL32](3014003.md)) mais ces fonctions doivent utiliser le DC (Device Context) renvoyé par la fonction [dDébutDessin](3029009.md).
    - La fonction [dFinDessin](3029019.md) ne doit pas être appelée dans le même traitement que la fonction [dDébutDessin](3029009.md).
      Si la fonction [dFinDessin](3029019.md) est appelée dans le même traitement que la fonction [dDébutDessin](3029009.md), le dessin n'apparaîtra pas : il sera automatiquement effacé.
- **Méthode 2 : indication de la destination du dessin directement dans la syntaxe (via un paramètre)**
  Le paramètre <Image> permet de spécifier directement la destination du dessin. La fonction [dDébutDessin](3029009.md) devient inutile. Cette fonction doit être supprimée.

> _(WEBDEV - Code Navigateur)_ Dessin en code NavigateurCertaines fonctions de dessin sont disponibles en code Navigateur. Les fonctions de dessin en code Navigateur sont basées sur la norme HTML 5. Pour les spécialistes, ces fonctions s'appuient sur la balise "canvas" de HTML 5. Les fonctionnalités de dessin en code navigateur sont disponibles uniquement sur les navigateurs récents (supportant la norme HTML 5). Pour savoir si le navigateur utilisé propose les fonctionnalités de dessin, utilisez la fonction DessinDisponible. Attention : Pour utiliser les fonctions de dessin avec Internet Explorer 9, le projet doit inclure la référence au fichier DTD. Pour cela, le mode HTML doit être "HTML 4.01 Transitional + DTD". Cette option est disponible dans l'onglet "Avancé" de la fenêtre de description du projet.Rappel : Pour afficher la fenêtre de description du projet, sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description".Cas particulier : Dessiner dans le navigateur d'un téléphone Android : Les fonctions de dessin navigateur sont disponibles uniquement à partir de la version 3 de Android.
