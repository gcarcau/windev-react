# <Variable Image>.CouleurDominanteImage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie la couleur dominante (c'est-à-dire la plus fréquente) d'une image présente dans une variable de type [Image](1000019650.md).

## Exemple

```wlangage
MonImage est une Image = "Test.bmp"
MaCouleur est une Couleur = MonImage.CouleurDominanteImage()
```

## Syntaxe

```wlangage
<Résultat> = <Variable Image>.CouleurDominanteImage()
```

`<Résultat>` *Entier*
> Couleur dominante de l'image.
`<Variable Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) à manipuler.

## Remarques

- Les pixels transparents ou semi-transparents de l'image sont ignorés.
- La fonction **<Variable Image>.CouleurDominanteImage** ne fonctionne pas sur des images vectorielles (SVG, PDF, ...).

**Composante : wd300pnt.dll**
