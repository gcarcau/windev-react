# <Variable pdfPage>.AjouteImage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Ajoute une image dans une page d'un fichier PDF existant.
Nouveauté 2025

> _(Android)_ Cette fonction est désormais disponible pour les applications Android.

> _(Widget Android)_ Cette fonction est désormais disponible en mode Widget Android.

> _(iPhone/iPad)_ Cette fonction est désormais disponible pour les applications iPhone/iPad.

## Exemple

```wlangage
MonPDF est un pdfDocument
...
MonImage est une Image = fRepExe() + [fSep()] + "Signature.pdf"
MonPDF.Page[1].AjouteImage(MonImage, 10, 10, 150, 50, drHomothétiqueCentré)
MonPDF.Sauve(fRepExe() + [fSep()] + "ETAT_SansNom1_Avec_Image.pdf")
```

## Syntaxe

```wlangage
<Page manipulée>.AjouteImage(<Image à ajouter> , <X> , <Y> , <Largeur> , <Hauteur> [, <Mode d'affichage> [, <Angle>]])
```

`<Page manipulée>` *Variable de type pdfPage*
> Nom de la variable de type [pdfPage](1000024904.md) correspondant à la page dans laquelle l'image doit être ajoutée.
`<Image à ajouter>` *Nom de champ, de variable ou chaîne de caractères*
> Image à ajouter dans la page du fichier PDF. Cette image peut correspondre à :
>
> - une variable de type [Image](1000019650.md),
> - le nom et chemin de l'image à ajouter dans la page,
> - une rubrique de type mémo Image,
> - un champ Image.
`<X>` *Réel*
> Coordonnée X (en millimètres) de l'image dans la page.
`<Y>` *Réel*
> Coordonnée Y (en millimètres) de l'image dans la page.
`<Largeur>` *Réel*
> Largeur de l'image (en millimètres).
`<Hauteur>` *Réel*
> Hauteur de l'image (en millimètres).
`<Mode d'affichage>` *Constante optionnelle de type Entier ou combinaison de constantes*
> Mode d'affichage de l'image :
>
> | *drEtiré* | L'image est étirée si nécessaire pour correspondre à la largeur et à la hauteur spécifiées. |
> | --- | --- |
> | *drHauteQualité* | Cette constante peut être combinée avec les options de redimensionnement de type homothétique. En mode homothétique, cette constante permet d'améliorer la qualité de l'image lorsque celle-ci est réduite par rapport à sa taille initiale. |
> | *drHomothétique* | L'image est étirée ou réduite pour occuper de manière optimale l'espace défini sans être déformée. Elle occupe :  - soit toute la hauteur spécifiée. - soit toute la largeur spécifiée. |
> | *drHomothétiqueCentré* (Valeur par défaut) | L'image est étirée ou réduite pour occuper de manière optimale l'espace défini sans être déformée et elle est centrée. Elle occupe :  - soit toute la hauteur spécifiée : l'image est centrée horizontalement. - soit toute la largeur spécifiée : l'image est centrée verticalement. |
> | *drHomothétiqueEtendu* | L'image est étirée ou réduite pour que le plus petit côté de l'image soit affiché entièrement. |
`<Angle>` *Réel*
> Orientation de l'image (exprimée en degrés).
