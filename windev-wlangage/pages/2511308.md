# Mois (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **Mois** permet de connaître et de modifier le mois d'un élément. Cette propriété est utilisable sur :

- une variable ou une rubrique de type Date, Heure et DateHeure. Pour plus de détails, consulter [Propriété Mois sur les types Date, Heure et DateHeure](2512052.md).
- une variable de type [hTâchePlanifiée](1000017448.md).
- une variable de type [hPlanification](1000018853.md).
- une variable de type [Répétition](1000019262.md).
- une variable de type [serveurAppliTâchePlanifiée](1000022367.md).
