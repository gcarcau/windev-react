# PoliceDécharge (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Décharge une police précédemment chargée avec la fonction [PoliceCharge](1410090994.md).
Nouveauté Abonnement
Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 1.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
PoliceDécharge("Roboto-Regular.ttf")
```

## Syntaxe

```wlangage
<Résultat> = PoliceDécharge(<Police>)
```

`<Résultat>` *Booléen*
> - Vrai si la police a été déchargée,
> - Faux dans le cas contraire.
`<Police>` *Chaîne de caractères ou Buffer*
> - Nom et chemin du fichier correspondant à la police à décharger. Ce chemin a été indiqué lors du chargement de la police.
> - Buffer contenant la police à décharger. Ce buffer a été utilisé lors du chargement de la police.

## Remarques

Si une même police est chargée plusieurs fois, il faut effectuer autant d'appels à la fonction **PoliceDécharge** que d'appels à la fonction [PoliceCharge](1410090994.md).

**Classification Métier / UI : Code UI**

**Composante : wd300pnt.dll**
