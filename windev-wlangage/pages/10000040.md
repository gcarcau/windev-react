# Erreur 40 : Il manque le FIN qui marque la fin de déclaration de la classe

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

## Cause

Vous déclarez une classe dans le code de déclaration de votre classe. La déclaration de la classe ne se termine pas par le mot-clé FIN.

## Correction

Utilisez le mot-clé FIN pour terminer la déclaration de votre classe.

## Exemple

### Déclaration d'une classe sans le mot-clé FIN

**Code provoquant l'erreur**

```wlangage
// -- Déclaration de la classe "Fichier"Fichier est une Classe  Nom est une chaîne  Extension est une chaîne Répertoire est une chaîne
```

**Correction proposée**

Utiliser le mot-clé FIN.

```wlangage
// -- Déclaration de la classe "Fichier"Fichier est une Classe  Nom est une chaîne  Extension est une chaîne Répertoire est une chaîneFIN
```
