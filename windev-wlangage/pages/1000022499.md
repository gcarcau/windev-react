# PoliceGras (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **PoliceGras** permet de gérer le gras dans un texte. Cette propriété est utilisable sur :

- les champs. Pour plus de détails, consultez [PoliceGras](2510103.md).
- une variable de type [docMiseEnForme](1000022817.md).
