# Fonctions SOAP

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions SOAP (syntaxe préfixée)](1000023951.md)).
Les fonctions permettant de manipuler le protocole SOAP sont les suivantes :

| [SOAPAjouteAssertionSAML](1000020762.md) | Ajoute une assertion SAML à une requête de Webservice. |
| --- | --- |
| [SOAPAjouteAttribut](1000019241.md) | Ajoute un attribut à une variable automatique générée par l'import d'un Webservice. |
| [SOAPAjouteEntête](3069001.md) | Ajoute un entête à la prochaine fonction SOAP d'un Webservice à exécuter. |
| [SOAPAjouteSignatureXML](1000020754.md) | Ajoute une signature XML à une requête de Webservice. |
| [SOAPDonneRésultat](3069002.md) | Renvoie le résultat de la dernière procédure SOAP exécutée avec succès. |
| [SOAPEncodeRésultat](3069003.md) | Permet de paramétrer le format de la valeur retournée par le serveur SOAP WINDEV au programme client SOAP. |
| [SOAPErreur](3069005.md) | Renvoie l'erreur de la dernière procédure SOAP ayant échoué. |
| [SOAPExécute](3069013.md) | Exécute une procédure sur un serveur SOAP. |
| [SOAPExécuteXML](3069014.md) | Exécute une procédure sur un serveur SOAP. |
| [SOAPPrépare](1000019238.md) | Construit la requête SOAP d'appel à une fonction d'un Webservice. |
| [SOAPRécupèreEntête](1000019237.md) | Récupère un entête dans le message SOAP reçu suite à l'appel d'un Webservice. |
| [SOAPVersHTTP](1000023920.md) | Construit la requête HTTP d'appel à une fonction d'un Webservice. Cette requête peut être modifiée pour l'adapter si nécessaire aux attentes du Webservice. Elle pourra ensuite être envoyée grâce à la fonction [HTTPEnvoie](1000021183.md). |
