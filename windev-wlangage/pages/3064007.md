# ComposantListe (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Retourne la liste des composants externes (fichiers ".WDK") utilisés par l'application WINDEV, WINDEV Mobile ou par le site WEBDEV en cours.
**Remarque** : Tous les composants externes sont listés, qu'ils soient chargés en mémoire ou non.

## Exemple

```wlangage
// Récupération des composants utilisés
MaListeComposant est une chaîne = ComposantListe()
// Parcours de cette liste
Composant est une chaîne
Composant = ExtraitChaîne(MaListeComposant, rangPremier, RC)
TANTQUE Composant <> EOT
	// Récupération du composant (noms logique et physique)
	Trace(ExtraitChaîne(Composant, 1, TAB) + " - " + ExtraitChaîne(Composant, 2, TAB))
	// Composant suivant
	Composant = ExtraitChaîne(MaListeComposant, rangSuivant, RC)
FIN
```

## Syntaxe

```wlangage
<Résultat> = ComposantListe()
```

`<Résultat>` *Chaîne de caractères*
> Liste des composants externes (fichiers ".DLL") utilisés par l'application en cours, sous la forme :
>
>
> ```wlangage
> <Nom 1° composant> + TAB + <Chemin 1° composant> + RC + <Nom 2° composant> + TAB + <Chemin 2° composant> + RC + ... + <Nom N° composant> + TAB + <Chemin N° composant>
> ```
>
>
>
> où :
>
>
> - <Nom X composant> correspond au nom logique du composant externe X.
> - <Chemin X composant> correspond au nom et chemin complet du composant externe X.

## Remarques

La fonction **ComposantListe** ne retourne pas de code d'erreur. Pour savoir si cette fonction a généré une erreur, utilisez la variable [ErreurDétectée](3087001.md). En cas d'erreur, il est possible de connaître le détail de l'erreur grâce à la fonction [ErreurInfo](3013008.md).

**Composante : wd300vm.dll**
