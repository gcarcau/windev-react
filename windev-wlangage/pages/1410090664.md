# Paramètres de la procédure utilisée par la fonction PartageProximitéRechercheAppareil (Recherche)

> **Disponible :** **WINDEV Mobile** (Android)

Procédure WLangage (également nommée "callback") appelée par la fonction [PartageProximitéRechercheAppareil](1410090648.md) lorsqu'un nouvel appareil distant a été trouvé ou lorsqu'un appareil précédemment découvert n'est plus accessible.
Il est d'usage d'effectuer la demande de connexion à l'appareil dans le code de cette procédure (fonction [PartageProximitéDemandeConnexion](1410090650.md)).

## Exemple

```wlangage
// Code de l'interrupteur permettant d'activer ou non la recherche des appareils
INT_Recherche.Etat = Grisé
SI INT_Recherche ALORS
	PartageProximitéRechercheAppareil(CallbackRésultat, CallbackDécouverte, gnTopologieDeRéseau)
SINON
	PartageProximitéArrêteRecherche()
	INT_Recherche.Etat = Actif
FIN
		PROCÉDURE INTERNE CallbackRésultat(bRésultat est un booléen)
			SI bRésultat ALORS
				INT_Recherche.Etat = Actif
			SINON
				Info("Échec de la recherche d'appareils ou de l'attente de connexion :" + RC + ErreurInfo())
			FIN
		FIN
```

```wlangage
PROCÉDURE CallbackDécouverte(bDecouverte est un booléen, sIdAppareil est une chaîne, sNomAppareil est une chaîne)
SI bDecouverte ALORS
	ToastAffiche("Appareil découvert : " + sNomAppareil)
SINON
	ToastAffiche("Appareil indisponible : " + sNomAppareil)
FIN
```

## Syntaxe

```wlangage
PartageProximitéRechercheAppareil_Callback_Decouverte(<Découverte> , <Identifiant de l'appareil> , <Nom de l'appareil>)
```

`<Découverte>` *Booléen*
> - Vrai si un nouvel appareil a été découvert,
> - Faux si un appareil précédemment découvert n'est plus accessible.
`<Identifiant de l'appareil>` *Chaîne de caractères*
> Identifiant de l'appareil distant.
`<Nom de l'appareil>` *Chaîne de caractères*
> Nom de l'appareil distant.
> Ce nom correspond au nom qui a été donné à la fonction [PartageProximitéAttendConnexion](1410090655.md) (appelée par l'appareil découvert).
