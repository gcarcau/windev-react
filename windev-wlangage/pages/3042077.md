# Types de graphes disponibles

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

WINDEV, WEBDEV et WINDEV Mobile proposent de nombreux types de graphes.
Les types de graphes disponibles sont les suivants :

- [Graphe de type Secteur (ou Camembert), Beignet ou Hémicycle](3042007.md).
- [Graphe de type Histogramme](3042011.md).
- [Graphe de type Courbe](3042002.md).
- [Graphe de type Nuage de points](3042008.md).
  Nouveauté Abonnement
   Ce type de graphe est désormais disponible pour les applications Android.
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
- [Graphe de type Boursier](3042004.md).
- [Graphe de type Radar](3042073.md).
- [Graphe de type Aire](3042074.md).
- [Graphe à bulles](1000019190.md)
  **Remarque** : Dans l'éditeur d'états, les graphes à bulles ne sont pas disponibles.
- [Graphe de type Entonnoir](1000019193.md).
- [Graphe de type Surface](1000020624.md).
- [Graphe de type Waterfall](1000021009.md).
- [Graphe de type Secteur multiniveau](1000021010.md).
- [Graphe de type Heatmap](1000021011.md).
- [Graphe composite, constitué de plusieurs graphes](1000021016.md).
- [Graphe de type Pyramide](1000021023.md).
- [Graphe en temps réel](1000021037.md).
- [Graphe d'intervalle](1000021038.md).
- [Graphe circulaire de progrès](1000021039.md).
- [Graphe Aire polaire](1000021040.md).
- [Graphe de type "Waffle"](1000021041.md).
- Nouveauté 2025
  [Graphe de type "Pourcentage imagé"](1000021044.md).
- Nouveauté Abonnement
  [Graphe de type "Zones proportionnelles imbriquées"](1000021045.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

Pour connaître les possibilités de chaque type de graphe, consultez la page d'aide correspondante.
