# GèreRTF (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **GèreRTF** permet de paramétrer le mode de gestion du RTF dans un index full-text. Il est ainsi possible de :

- Savoir si le texte des rubriques d'un index full-text peut contenir ou non du RTF. L'index full-text a été défini sous l'éditeur d'analyses par programmation.
- Définir si le texte des rubriques d'un index full-text peut contenir ou non du RTF. L'index full-text a été défini par programmation.

## Syntaxe

#### Connaître le mode de gestion du RTF

```wlangage
<Mode de gestion> = <Fichier de données>.<Index full-text>.GèreRTF
```

`<Mode de gestion>` *Booléen*
> - Vrai si le texte peut contenir du RTF,
> - Faux dans le cas contraire. Si le texte peut contenir du RTF, les balises RTF ne seront pas indexées.
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données manipulé. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Fichier](1514065.md).
`<Index full-text>` *Chaîne de caractères*
> Nom de l'index full-text manipulé. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description d'IndexFullText](1000017461.md).

#### Définir le mode de gestion du RTF

```wlangage
<Index full-text>.GèreRTF = <Nouveau mode de gestion>
```

`<Index full-text>` *Chaîne de caractères*
> Nom de l'index full-text manipulé. Ce nom vient d'être défini grâce au type [Description d'IndexFullText](1000017461.md).
`<Nouveau mode de gestion>` *Booléen*
> - Vrai si le texte peut contenir du RTF,
> - Faux dans le cas contraire. Si le texte peut contenir du RTF, les balises RTF ne seront pas indexées.
