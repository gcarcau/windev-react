# Propriétés associées aux séries d'un graphe

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

Les différentes propriétés utilisables avec les séries d'un "Graphe" sont les suivantes :

| [AxeSecondaire](1000019187.md) | La propriété **AxeSecondaire** permet de :   - savoir si une série d'un graphe est placée sur l'axe secondaire. - placer une série d'un graphe sur l'axe secondaire. |
| --- | --- |
| [BorneMax](2510009.md) | La propriété **BorneMax** permet de :  - connaître et de modifier la borne maximale d'un état basé sur un fichier de données. - connaître la borne maximale du filtre en cours. - connaître la valeur maximale d'une série d'un graphe. - connaître et modifier la valeur maximale de certains types de champs. |
| [BorneMin](2510008.md) | La propriété **BorneMin** permet de :  - connaître et de modifier la borne minimale d'un état basé sur un fichier de données. - connaître la borne minimale du filtre en cours. - connaître la valeur minimale d'une série d'un graphe. - connaître et modifier la valeur minimale de certains types de champs. |
| [CouleurSérie](2510145.md) | La propriété **CouleurSérie** permet de :  - Connaître la couleur d'une série d'un graphe. - Modifier la couleur d'une série d'un graphe. |
| [Epaisseur](2510144.md) | La propriété **Epaisseur** permet de :  - Connaître et modifier l'épaisseur du trait d'une série (uniquement pour les graphes de type Courbe). - Connaître et modifier l'épaisseur du trait d'un champ Fil. |
| [Légende](2510143.md) | La propriété **Légende** permet de :  - Connaître l'étiquette d'une série. - Modifier l'étiquette d'une série. |
| [MAJAutomatique](2510146.md) | La propriété **MAJAutomatique** permet de :  - Savoir si les données de la séries sont automatiquement recalculées à chaque appel de la fonction [grDessine](3042026.md) - Modifier le mode de recacul des données de la série. |
| [Source](2510147.md) | La propriété **Source** peut être utilisée sur :  - **un champ Graphe** : dans ce cas, la propriété **Source** permet de connaître la source de la série : Colonne de table, liste de valeurs, ... - **une connexion** : dans ce cas, la propriété **Source** permet de connaître ou définir la source d'une connexion (HFSQL Client/Serveur, OLE DB, ...). |
| [SourceDescription](2510148.md) | La propriété **SourceDescription** permet de connaître le nom de l'élément utilisé comme source de données d'une série. |
