# fSélecteurImage (Fonction)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU))

Ouvre le sélecteur d'images de Windows. Le sélecteur d'images est le suivant :
[image: Sélecteur d'images]

**Remarque** : **Sous Android et iOS**, la boîte de dialogue de sélection d'un fichier n'est pas disponible. Utilisez la fonction [AlbumSélecteur](1000020186.md) (pour sélectionner un fichier de type Image ou Vidéo) ou la fonction [URISélecteur](1000024026.md) pour tout type de fichier.

## Exemple

```wlangage
// Sélection d'un fichier image
Fichier = fSélecteurImage("C:\Répertoires", "Fichier.bmp", "Sélectionner une image", ...
	"JPEG (*.JPG)" + TAB + "*.jpg" + RC + "BMP (*.BMP)" + TAB + "*.bmp")
```

## Syntaxe

```wlangage
<Résultat> = fSélecteurImage(<Répertoire initial> , <Fichier sélectionné par défaut> , <Titre du sélecteur> [, <Types de fichiers> [, <Option>]])
```

`<Résultat>` *Chaîne de caractères*
> - Nom complet du fichier sélectionné. Si plusieurs fichiers sont sélectionnés, les noms complets des différents fichiers sélectionnés sont séparés par des RC (Retour Chariot).
> - Chaîne vide ("") si aucun fichier n'a été sélectionné.
`<Répertoire initial>` *Chaîne de caractères*
> Chemin complet ou relatif du répertoire initial (260 caractères maximum). Ce nom de répertoire peut être terminé indifféremment par "\" ou non. Les fichiers contenus dans ce répertoire s'affichent dans le sélecteur d'images.
> Si ce paramètre est une chaîne vide (""), le répertoire initial correspondra au répertoire en cours.
> > _(Windows)_ Ce paramètre peut être au format Ansi ou Unicode.A partir de Windows 7, le système d'exploitation peut ne pas respecter ce répertoire, notamment s'il a mémorisé un emplacement plus opportun en fonction des choix précédents de l'utilisateur.
`<Fichier sélectionné par défaut>` *Chaîne de caractères*
> Nom et extension du fichier sélectionné par défaut. Si ce paramètre est une chaîne vide (""), aucun fichier ne sera sélectionné par défaut.
> > _(Windows)_ Ce paramètre peut être au format Ansi ou Unicode.
`<Titre du sélecteur>` *Chaîne de caractères*
> Intitulé affiché dans la barre de titre du sélecteur d'images. Si ce paramètre est une chaîne vide (""), le titre de la fenêtre WINDEV en cours sera affiché.
> > _(Windows)_ Ce paramètre peut être au format Ansi ou Unicode.
`<Types de fichiers>` *Chaîne de caractères optionnelle*
> Description des types de fichiers pouvant être sélectionnés. Cette description est de la forme :
>
>
> ```wlangage
> <Types Fichiers> + TAB + <Liste Extensions>[ + RC + <Types Fichiers 2> + TAB + <Liste Extensions 2>]
> ```
>
>
>
>
>
> - <Types Fichiers> : chaîne de caractères décrivant le type de fichier ("BMP (*.BMP;*.RLE)" par exemple).
> - <Liste Extensions> : extensions correspondant au type décrit ("*.BMP;*.RLE" par exemple).
>
>
> Par exemple :
>
> ```wlangage
> "BMP (*.BMP;*.RLE)"+TAB+"*.BMP;*.RLE"+RC+"Icône (*.ICO)"+TAB+"*.ICO"+RC+"Autres"+TAB+"*.GIF;*.TIF;*.JPG"
> ```
>
> > _(Windows)_ Ce paramètre peut être au format Ansi ou Unicode.
`<Option>` *Constante ou combinaison de constante optionnelle de type Entier*
> Options à prendre en compte :
>
> | *fCheminUnicode* | <Résultat sera une chaîne de caractères au format Unicode (par défaut, la fonction **fSélecteurImage** renvoie une chaîne de caractères Ansi). |
> | --- | --- |
> | *fSelMulti* | Ouvre le sélecteur en mode multisélection. L'utilisateur peut ainsi sélectionner plusieurs fichiers image à l'aide des touches "Ctrl" et "Shift". |

## Remarques

### Sélection de répertoire
La fonction **fSélecteurImage** permet de sélectionner des fichiers image. Pour sélectionner un répertoire, utilisez la fonction [fRepSélecteur](3036050.md).

### Mode d'ouverture du sélecteur d'images
Seul le bouton "Ouvrir" peut apparaître dans le sélecteur d'images. Pour que le bouton "Enregistrer" apparaisse dans le sélecteur d'images, combinez les fonctions [fSélecteur](3036053.md) et [fFiltreImage](3036009.md) (voir l'exemple de la fonction fFiltreImage).
