# PressePapierUnicode (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **Autres** (Procédures stockées)

Retourne le texte contenu dans le presse-papiers au format Unicode.

## Exemple

```wlangage
MonTexte est une chaîne Unicode
SI PressePapierFormat(ppfTexteUnicode) = Vrai ALORS
	// Le contenu du presse-papiers est copié dans la variable MonTexte
	MonTexte = PressePapierUnicode()
FIN
```

## Syntaxe

```wlangage
<Résultat> = PressePapierUnicode()
```

`<Résultat>` *Chaîne de caractères Unicode*
> Texte contenu dans le presse-papiers.

**Composante : wd300std.dll**
