# DocFinModification (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Signale la fin du regroupement d'un ensemble d'opérations sur un document de type Traitement de texte en un seul événement (gestion du "undo/redo").

## Exemple

```wlangage
DocDébutModification(TT_MonDocument)
DocRemplace(TT_MonDocument, "%NomClient%", Client.Nom)
DocRemplace(TT_MonDocument, "%PrénomClient%", Client.Prénom)
DocFinModification(TT_MonDocument)
```

## Syntaxe

```wlangage
DocFinModification(<Document>)
```

`<Document>` *Variable de type Document ou chaîne de caractères*
> Document à manipuler. Ce document correspond :
>
> - au nom d'un champ Traitement de texte.
> - à une variable de type [Document](1000022461.md).

## Remarques

Les modifications effectuées sur le document sont regroupées à partir de l'appel de la fonction [DocDébutModification](1000022620.md). Si plusieurs modifications annulables sont effectuées, il suffit d'un seul "Ctrl + Z" pour annuler toutes les opérations effectuées.

**Composante : wd300obj.dll**
