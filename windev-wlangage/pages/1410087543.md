# 3. Préparer l'installation

## Leçon 3 - Préparer l'installation

**Ce que vous allez apprendre** :

- Comment installer une application Client/Serveur en clientèle ?

[image: Durée de la leçon] 5 mn

## Présentation

L'installation d'une application Client/Serveur nécessite plusieurs options spécifiques. Ces options sont prises en charge par l'assistant de création d'installation de WINDEV.
Nous allons créer la procédure d'installation de notre application "WD Application Complète".
Nous ne verrons dans cette leçon uniquement les points spécifiques à la création de l'installation d'une application utilisant une base de données HFSQL Client/Serveur. La création de l'exécutable et de la procédure d'installation sont effectuées dans le tuto [Déployer l'application](1410087528.md).
**Avertissement**

 Pour faire les manipulations de cette leçon sur le projet "WD Application Complète", il est nécessaire d'avoir effectué les manipulations des leçons précédentes de ce tuto sur ce projet.

## Lancement de l'assistant de création d'installation

Pour lancer la procédure d'installation d'une application HFSQL Client/Serveur :

1. Sous le volet "Projet", dans le groupe "Génération", cliquez sur "Procédure d'installation".
2. Créez l'exécutable et validez la création de l'aide.
3. Cliquez sur l'option "Données" dans la partie gauche de l'assistant : l'étape "Paramètres des bases de données" est affichée. Dans cette étape, plusieurs options sont spécifiques à une application en mode Client/Serveur. Par exemple, il est possible de :
  - Intégrer l'installation d'un serveur HFSQL : cette option permet de proposer l'installation du serveur HFSQL et du Centre de Contrôle HFSQL lors de l'installation de l'application. Cette option est par exemple nécessaire lors d'une première installation de l'application.
  - Configurer l'emplacement des fichiers de données de l'application : Cette option permet de spécifier l'emplacement des fichiers de données. Dans le cas d'une application Client/Serveur, les fichiers de données seront bien entendu présents sur le serveur.
  - Déployer des fichiers de données sur un serveur HFSQL : Cette option permet d'indiquer si les fichiers de données utilisés en développement doivent être déployés sur le serveur.
    [image: Création d'installation]
   Si ces options sont cochées, les étapes suivantes permettent de paramétrer les différents éléments à prendre en compte pour effectuer l'installation sur le poste des utilisateurs finaux.
