# SaaSAdminLitParamètreSite (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Lit un paramètre du site précédemment enregistré avec la fonction [SaaSAdminEcritParamètreSite](1000019769.md). Cette fonction peut être exécutée en dehors du site SaaS concerné.

## Exemple

```wlangage
s est une chaîne
s = SaaSAdminLitParamètreSite("Jet-Thames", "Dupont" ,"logo")
SI ErreurDétectée = Vrai ALORS IMG_ImageLogo = s
```

## Syntaxe

#### Lire une information

```wlangage
<Résultat> = SaaSAdminLitParamètreSite(<Site SaaS> , <Client SaaS> , <Nom du paramètre>)
```

`<Résultat>` *Variant*
> Valeur de la donnée recherchée.
`<Site SaaS>` *Chaîne de caractères*
> Nom du site SaaS à manipuler.
`<Client SaaS>` *Chaîne de caractères*
> Nom du compte client SaaS.
`<Nom du paramètre>` *Chaîne de caractères*
> Nom de la donnée à lire. Cette donnée est unique par client. Si cette donnée n'existe pas, la variable [ErreurDétectée](3087001.md) est à Vrai.

#### Lire une information (utilisation des variables de type saasxxx)

```wlangage
<Résultat> = SaaSAdminLitParamètreSite(<Site SaaS> , <Compte Client> , <Nom du paramètre>)
```

`<Résultat>` *Variant*
> Valeur de la donnée recherchée.
`<Site SaaS>` *Variable de type saasSite*
> Nom de la variable de type [saasSite](1000019068.md) correspondant au site SaaS à manipuler.
`<Compte Client>` *Variable de type saasClient*
> Nom de la variable de type [saasClient](1000019072.md) correspondant au compte client SaaS.
`<Nom du paramètre>` *Chaîne de caractères*
> Nom de la donnée à lire. Cette donnée est unique par client. Si cette donnée n'existe pas, la variable [ErreurDétectée](3087001.md) est à Vrai.
