# <Carte>.LimiteZone (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Limite la zone géographique affichée dans le champ Carte.

## Exemple

```wlangage
p1 est une géoPosition
p1.Latitude = 0
p1.Longitude = 0
p2 est une géoPosition
p2.Latitude = 3
p2.Longitude = 3
CARTE_MaCarte.LimiteZone(p1, p2)
```

## Syntaxe

#### Définir la zone géographique

```wlangage
<Résultat> = <Champ Carte>.LimiteZone(<Position Nord Ouest> , <Position Sud Est>)
```

`<Résultat>` *Booléen*
> - Vrai si la limitation de la zone affichable a été effectuée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler.
`<Position Nord Ouest>` *Variable de type géoPosition*
> Nom de la variable de type [géoPosition](1000019191.md) correspondant au point Nord Ouest de la zone affichée dans le champ Carte.
`<Position Sud Est>` *Variable de type géoPosition*
> Nom de la variable de type [géoPosition](1000019191.md) correspondant au point Sud Est de la zone affichée dans le champ Carte.

#### Supprimer la zone géographique

```wlangage
<Résultat> = <Champ Carte>.LimiteZone()
```

`<Résultat>` *Booléen*
> - Vrai si la limitation de la zone affichable a été supprimée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler.

## Remarques

- Selon le niveau de zoom, le champ Carte peut afficher une zone plus étendue que la zone spécifiée, mais le centre de la carte sera toujours situé à l'intérieur de la zone spécifiée en paramètre.
- Lors de l'appel de la fonction **<Carte>.LimiteZone**, la carte affichée dans le champ Carte sera automatiquement positionnée sur la zone spécifiée.
