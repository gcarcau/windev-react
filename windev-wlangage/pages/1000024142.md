# Fonctions de gestion d'une base Big Data Redis

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion d'une base Big Data Redis (syntaxe préfixée)](1410088287.md)).
Les fonctions de gestion d'une base de données Redis sont les suivantes :

| [RedisAbonne](1000023552.md) | Souscrit un abonnement à un canal de diffusion Redis. |
| --- | --- |
| [RedisAffecte](1410088170.md) | Modifie la valeur d'une clé sur un serveur Redis. |
| [RedisConnecte](1000023530.md) | Ouvre une connexion vers un serveur Redis (ou un cluster Redis). |
| [RedisDéconnecte](1410089738.md) | Force la fermeture de la connexion vers un serveur Redis (ou un cluster Redis). |
| [RedisDésabonne](1000023553.md) | Supprime un abonnement à un canal de diffusion Redis. |
| [RedisExécuteCommande](1000023541.md) | Exécute une commande sur un serveur Redis et récupère le résultat. |
| [RedisPipelineAjoute](1000023542.md) | Ajoute une commande Redis dans un pipeline. |
| [RedisPipelineRAZ](1000023549.md) | Ignore les résultats de l'exécution d'une commande Redis ayant été ajoutée par la fonction [RedisPipelineAjoute](1000023542.md). |
| [RedisPipelineRécupère](1000023543.md) | Récupère le résultat de l'exécution d'une commande Redis ayant été ajouté par [RedisPipelineAjoute](1000023542.md). |
| [RedisPublie](1000023551.md) | Publie un message sur un canal de diffusion Redis. |
| [RedisRécupère](1410088171.md) | Récupère la valeur d'une clé sur un serveur Redis sous forme de chaîne. |

Nouveauté 2025
Support de la base de données Big Data Valkey : Les fonctions Redisxxx permettent d'accéder et de manipuler des données présentes sur un serveur Valkey.
