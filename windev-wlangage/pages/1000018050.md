# Multiligne (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **Multiligne** permet de savoir si un élément est multiligne. Cette propriété est utilisable sur :

- les champs d'une fenêtre, d'une page ou d'un état. Pour plus de détails, consultez [Multiligne sur les champs](2510105.md).
- une variable de type [xlsCellule](1000017472.md).
