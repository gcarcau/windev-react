# RègleAnonymisation (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

La propriété **RègleAnonymisation** permet de connaître la règle d'anonymisation appliquée à une rubrique d'un fichier de données.

## Exemple

```wlangage
Trace(Client.Prénom.RègleAnonymisation) // Affiche "partial(2,"X",4)"
```

## Syntaxe

```wlangage
<Règle d'anonymisation> = <Fichier de données>.<Rubrique>.RègleAnonymisation
```

`<Règle d'anonymisation>` *Chaîne de caractères*
> Règle d'anonymisation utilisée, au format SQL.
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données manipulé. Ce nom a été défini sous l'éditeur d'analyses.
`<Rubrique>` *Chaîne de caractères*
> Nom de la rubrique manipulée. Ce nom a été défini sous l'éditeur d'analyses.
