# Visible (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

La propriété **Visible** permet de gérer la visibilité d'un élément. Cette propriété est utilisable sur :

- les champs d'une fenêtre, d'une page ou d'un état. Pour plus de détails, consultez [Visible](2510138.md).
- une variable de type [picCalque](1000024604.md).
- une variable de type [kbCarte](1410089167.md).
- la propriété [BoutonGauche](1410090001.md) d'un champ de saisie.
- la propriété [BoutonDroit](1410090002.md) d'un champ de saisie.
- une variable de type [xlsCommentaire](1000024870.md).
- Nouveauté Abonnement
  une variable de type [OptionsOuvertureFenêtre](1410091298.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
