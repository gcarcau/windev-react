# Fonctions Action

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU))

Les fonctions de gestion des actions avec Undo/Redo sont les suivantes :
| [ActionDéclareUndo](1000022678.md) | Déclare comment annuler une action ajoutée avec la fonction [ActionDo](1000022676.md). Cette fonction **DOIT** être appelée durant l'exécution de la procédure fournie à la fonction [ActionDo](1000022676.md). |
| --- | --- |
| [ActionDo](1000022676.md) | Crée et exécute une action personnalisée (définie par programmation) avec support du "Undo/Redo". |
| [ActionRedo](1000022608.md) | Exécute la dernière action annulée. |
| [ActionUndo](1000022677.md) | Annule la dernière action effectuée par l'utilisateur final. |
