# Fonctions de gestion des champs Tableau croisé dynamique

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des champs Tableau croisé dynamique (syntaxe préfixée)](1000022194.md)).
Nouveauté Abonnement

> _(WEBDEV - Code Serveur, Windows, Linux)_ La plupart de ces fonctions sont désormais disponibles pour les sites WEBDEV sous Windows et sous Linux.

> _(WEBDEV - Code Navigateur)_ Certaines fonctions sont désormais disponibles en code navigateur.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
Ces fonctions permettent de manipuler les champs de type Tableau croisé dynamique :

| [TCDAxeXY](1000021113.md) | Permet de :   - Spécifier les entêtes de lignes et de colonnes affichés dans un champ Tableau croisé dynamique. - Connaître les entêtes de lignes et de colonnes affichés dans un champ Tableau croisé dynamique. _(WEBDEV - Code Serveur, Linux)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. |
| --- | --- |
| [TCDCalculeMiseAJour](1000020534.md) | Met à jour une partie des données d'un champ Tableau croisé dynamique à partir d'une date. _(WEBDEV - Code Serveur, Linux)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. |
| [TCDCalculeMiseAJourAsynchrone](1410089990.md) | Met à jour (sans blocage) une partie des données d'un champ Tableau croisé dynamique à partir d'une date. _(WEBDEV - Code Serveur, Linux)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. |
| [TCDCalculeTout](1000020539.md) | Calcule ou recalcule entièrement un champ Tableau croisé dynamique. _(WEBDEV - Code Serveur, Linux)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. |
| [TCDCalculeToutAsynchrone](1410090244.md) | Calcule ou recalcule entièrement un champ Tableau croisé dynamique sans blocage. _(WEBDEV - Code Serveur, Linux)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. |
| [TCDCharge](1000020507.md) | Charge le résultat du calcul d'un champ Tableau croisé dynamique depuis une sauvegarde (fichier présent sur le disque ou sauvegarde dans un buffer). _(WEBDEV - Code Serveur, Linux)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. |
| [TCDComparePériode](1000024869.md) | Calcule et affiche une comparaison de périodes dans un champ Tableau croisé dynamique. _(WEBDEV - Code Serveur, Linux)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. |
| [TCDDéroule](1000020699.md) | Déroule toutes les données d'un champ Tableau croisé dynamique selon un entête de ligne ou de colonne. _(WEBDEV - Code Serveur, Linux)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. |
| [TCDDérouleTout](1000020623.md) | Déroule tous les entêtes de lignes et/ou de colonnes d'un champ Tableau croisé dynamique. _(WEBDEV - Code Serveur, Linux)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. |
| [TCDEnroule](1000020698.md) | Enroule toutes données d'un champ Tableau croisé dynamique selon un entête de ligne ou de colonne. _(WEBDEV - Code Serveur, Linux)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. |
| [TCDEnrouleTout](1000020622.md) | Enroule tous les entêtes de lignes et/ou de colonnes d'un champ Tableau croisé dynamique. _(WEBDEV - Code Serveur, Linux)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. |
| [TCDFiltre](1000020531.md) | Active ou désactive un filtre sur un champ Tableau croisé dynamique. _(WEBDEV - Code Serveur, Linux)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. |
| [TCDInfoXY](1000020735.md) | Renvoie les valeurs d'entêtes correspondant à une position en pixels dans un champ Tableau croisé dynamique. _(WEBDEV - Code Navigateur)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. |
| [TCDListePositionEntête](1000020975.md) | Renvoie toutes les valeurs associées à un entête de ligne ou de colonne d'un champ Tableau croisé dynamique. _(WEBDEV - Code Serveur, Linux)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. |
| [TCDSauve](1000020471.md) | Sauve le résultat du calcul d'un champ Tableau croisé dynamique (dans un fichier ou en mémoire). _(WEBDEV - Code Serveur, Linux)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. |
| [TCDSelect](1000021024.md) | Permet de connaître la position des cellules sélectionnées et de sélectionner des cellules dans un champ Tableau croisé dynamique. _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur, Linux)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. |
| [TCDSelectOccurrence](1000022175.md) | Renvoie le nombre de cellules sélectionnées dans un champ Tableau croisé dynamique. _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur, Linux)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. |
| [TCDValeurEntête](1000021135.md) | Renvoie la valeur affichée dans un entête du champ Tableau croisé dynamique. _(WEBDEV - Code Serveur, Linux)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. |
| [TCDVersExcel](1000020703.md) | Crée un fichier Excel avec les données d'un champ Tableau croisé dynamique. _(WEBDEV - Code Serveur, Linux)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. |
