# btleDescripteur (Type de variable)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le type **btleDescripteur** permet de manipuler le descripteur d'une caractéristique Bluetooth Low Energy.
Ce descripteur décrit les données échangées entre deux appareils compatibles Bluetooth LE : unité de la valeur, plage de valeurs, ... Il est identifié par une chaîne de caractère unique (UUID).

Les caractéristiques de ce descripteur peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
cMonService est un btleService
...
cMaCaractéristique est un btleCaractéristique <- cMonService[1]
cMonDesc est un btleDescripteur <- cMaCaractéristique.Descripteur[1]
```

## Propriétés

### Propriétés spécifiques à la description des variables de type btleDescripteur
Les propriétés suivantes peuvent être utilisées pour manipuler un descripteur :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Permission | Entier | Permissions associées au descripteur. Cette propriété est disponible en lecture seulement. |
| UUID | Chaîne de caractères | Identifiant du descripteur.  Cette propriété est disponible en lecture seulement. |
