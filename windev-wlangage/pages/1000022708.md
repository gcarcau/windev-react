# TailleMax (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android)

La propriété **TailleMax** permet de connaître et de définir une taille maximale. Cette propriété est disponible sur :

- une variable de type [nfcTag](1000020411.md).
- une variable de type [mongoCollectionOption](1000022413.md).
