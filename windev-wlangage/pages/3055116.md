# Fonctions de gestion AJAX

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur)

Les fonctions AJAX sont les suivantes :

| [AJAXAnnuleAppelAsynchrone](3055110.md) | Annule l'exécution automatique de la procédure navigateur appelée par la fonction [AJAXExécuteAsynchrone](3055115.md). |
| --- | --- |
| [AJAXAppelAsynchroneEnCours](3055111.md) | Permet de savoir si une procédure serveur appelée par la fonction [AJAXExécuteAsynchrone](3055115.md) est en cours d'exécution. |
| [AJAXDisponible](3055112.md) | Permet de savoir si la technologie AJAX est utilisable dans le navigateur en cours. |
| [AJAXExécute](3055114.md) | Exécute une procédure serveur sans rafraîchir la page. |
| [AJAXExécuteAsynchrone](3055115.md) | Exécute une procédure serveur sans rafraîchir la page. |
