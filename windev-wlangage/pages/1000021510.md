# <Variable xlsDocument>.Ferme (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Ferme un fichier XLS.
Nouveauté 2025

> _(Android)_ Cette fonction est désormais disponible pour les applications Android.

> _(Widget Android)_ Cette fonction est désormais disponible en mode Widget Android.

> _(iPhone/iPad)_ Cette fonction est désormais disponible pour les applications iPhone/iPad.

## Exemple

```wlangage
MonFichierXLS est un xlsDocument

// Ouverture d'un fichier XLS
MonFichierXLS = xlsOuvre("C:\MesRépertoires\Fichier.XLS")
...
// Fermeture du fichier XLS
MonFichierXLS.Ferme()
```

## Syntaxe

```wlangage
<Document XLS>.Ferme()
```

`<Document XLS>` *Variable de type xlsDocument*
> Nom de la variable de type [xlsDocument](1000017464.md) correspondant au fichier XLS à fermer. Le fichier physique associé à cette variable (s'il existe) est fermé. Les modifications réalisées dans le fichier ne sont pas sauvées avant sa fermeture (utilisez la fonction [<Variable xlsDocument>.Sauve](1000021511.md) si nécessaire).

**Composante : wd300xls.dll**
