# Fonctions de gestion du champ Editeur d'images et des variables WDPic (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU))

Les fonctions de gestion du champ Editeur d'images et des variables WDPic (via une syntaxe préfixée) sont les suivantes :

| [<Éditeur d'images>.Crée](1000023430.md) | Crée une image dans le champ Editeur d'images. |
| --- | --- |
| [<Éditeur d'images>.Ferme](1000023431.md) | Ferme l'image se trouvant dans un champ Editeur d'images. |
| [<Éditeur d'images>.Ouvre](1000023432.md) | Ouvre une image dans un champ Editeur d'images. |
| [<Éditeur d'images>.Sauve](1000023433.md) | Sauvegarde l'image affichée dans le champ Editeur d'images. |
| [<Variable WDPic>.FusionneCalque](1000024866.md) | Fusionne les calques d'une image au format WDPic. |
| [<Variable WDPic>.Redimensionne](1000024920.md) | Redimensionne une image au format WDPic. |
| [<Variable WDPic>.Rotation](1000024922.md) | Effectue une rotation d'une image au format WDPic. |
| [<Variable WDPic>.Sauve](1000024923.md) | Sauve l'image présente dans une variable de type WDPic. |
