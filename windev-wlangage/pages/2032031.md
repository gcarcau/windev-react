# Fenêtre de description d'une requête composée

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

La fenêtre de description d'une requête composée est constituée de plusieurs parties. Cette fenêtre de description permet de :

- changer les requêtes utilisées dans la requête.
- modifier l'ordre d'exécution des requêtes.
  Rappel : Les rubriques apparaissant dans le résultat de la requête composée correspondent aux rubriques de la première requête exécutée.
- visualiser la requête en code SQL ou en langage naturel.
- gérer les enregistrements "doublons".
- trier les enregistrements.

Cette fenêtre de description s'affiche :

- lors de la création d'une requête de sélection.
  Rappel : Pour créer une requête :
  - Cliquez sur  parmi les boutons d'accès rapide.
  - La fenêtre de création d'un nouvel élément s'affiche : cliquez sur "Requêtes".
- depuis une requête composée affichée sous l'éditeur de requêtes (option "Description de la requête" du menu contextuel de la requête).

## Fenêtre de description d'une requête composée

Cette partie de la fenêtre de description d'une requête liste principalement les différentes rubriques pouvant être utilisées dans la requête.

|  | Liste des différentes requêtes de sélection pouvant être utilisées dans la requête composée. **Remarque** : Pour sélectionner plusieurs requêtes, maintenez la touche Ctrl enfoncée. |
| --- | --- |
|  | Permet d'ajouter ou de supprimer la ou les requêtes sélectionnées dans la requête composée. |
|  | Liste des différentes requêtes utilisées dans la requête composée. Ces requêtes sont affichées dans leur ordre d'exécution. |
|  | Modifie l'ordre d'exécution des requêtes. |
|  | Permet de conserver ou de supprimer les enregistrements dupliqués (doublons) du résultat de la requête composée. |
|  | Liste des rubriques résultat de la requête composée. **Rappel** : Ces rubriques correspondent aux rubriques de la première requête exécutée. |
|  | Permet de trier ou d'annuler le tri sur une rubrique de la requête. |
|  | Affiche :  - soit la requête composée en langage naturel. - soit le code SQL correspondant à la requête composée. |
