# Fonctions HDFS (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

Les fonctions de gestion des fichiers sur un système HDFS (syntaxe préfixée) sont les suivantes :

| [<Variable hdfsConnexion>.CopieDepuis](1000021980.md) | Copie un fichier situé sur un serveur Hadoop vers la machine locale. |
| --- | --- |
| [<Variable hdfsConnexion>.CopieVers](1000021981.md) | Copie un fichier situé sur la machine locale vers un serveur Hadoop. |
| [<Variable hdfsConnexion>.CréeRépertoire](1000021982.md) | Crée un répertoire sur un serveur Hadoop. |
| [<Variable hdfsConnexion>.FermeConnexion](1000021983.md) | Ferme une connexion à un serveur Hadoop. |
| [<Variable hdfsConnexion>.Liste](1000021984.md) | Liste le contenu d'un répertoire sur un serveur Hadoop. |
| [<Variable hdfsConnexion>.OuvreConnexion](1000021985.md) | Ouvre une connexion vers un serveur Hadoop. |
| [<Variable hdfsConnexion>.Renomme](1000021986.md) | Modifie le nom d'un fichier ou d'un répertoire sur un serveur Hadoop. |
| [<Variable hdfsConnexion>.Supprime](1000021987.md) | Supprime un fichier ou un répertoire sur un serveur Hadoop. |

Les types manipulés par les fonctions HDFS sont les suivants :

| [hdfsConnexion](1000021650.md) | Le type **hdfsConnexion** permet de définir toutes les caractéristiques avancées d'une connexion au système de fichiers Hadoop (HDFS). |
| --- | --- |
| [hdfsDroit](1000021662.md) | Le type **hdfsDroit** permet de définir toutes les caractéristiques avancées des droits d'accès à un élément (fichier, lien, répertoire) du système de fichiers Hadoop. |
| [hdfsInformation](1000021973.md) | Le type **hdfsInformation** permet de définir toutes les caractéristiques avancées de l'état d'un élément (fichier, répertoire, lien) du système de fichiers Hadoop. |

Attention : Les fonctions HBase sont disponibles en édition et en exécution uniquement à partir de Windows Vista ou Windows Server 2008.
