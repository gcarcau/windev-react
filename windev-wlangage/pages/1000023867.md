# NoeudRacine (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **NoeudRacine** permet de connaître les noeuds racine d'un document HTML ou XML. Cette propriété est utilisable sur :

- une variable de type [xmlDocument](1000018782.md).
- une variable de type [htmlDocument](1000025910.md).
