# Tests automatiques : Fonctions spécifiques aux tests

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Dans le code d'un test automatique, il est possible d'utiliser les fonctions suivantes :

| [TestAjouteItération](1000017015.md) | Ajoute une itération dans le test en cours et donne les valeurs des paramètres du test pour cette itération. |
| --- | --- |
| [TestEcritRésultat](1000013001.md) | Écrit une information ou une erreur dans le compte-rendu d'un test unitaire, sous l'éditeur de tests. |
| [TestErreur](1000023506.md) | Provoque :   - une assertion lors du test de l'élément ou du projet (mode Go). - une erreur en mode test automatique. |
| [TestSurErreur](1000023507.md) | Provoque :   - une assertion lors du test de l'élément ou du projet (mode Go). - une erreur en mode test automatique. |
| [TestVérifie](1000017023.md) | Écrit un résultat dans le compte-rendu de test en fonction du résultat d'une expression booléenne. |
| [TestVérifieDifférence](1000023397.md) | Vérifie si les expressions spécifiées sont différentes en programmation défensive et en mode test automatique. |
| [TestVérifieEgalité](1000023398.md) | Vérifie si les expressions sont égales en programmation défensive et en mode test automatique. |
| [TestVérifieFaux](1000023399.md) | Vérifie si une expression est fausse en programmation défensive et en mode test automatique. |
| [TestVérifieNonNull](1000023400.md) | Vérifie si l'expression n'est pas Null en programmation défensive et en mode test automatique. |
| [TestVérifieNull](1000023401.md) | Vérifie si l'expression est Null en programmation défensive et en mode test automatique. |
| [TestVérifieVrai](1000023402.md) | Vérifie si une expression vaut Vrai en programmation défensive et en mode test automatique. |

Remarque : Dans le code d'un test automatique, il est également possible d'utiliser l'instruction [SUR](1511020.md).
