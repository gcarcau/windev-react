# <Graphe>.HMSupprimeCouleur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Supprime les couleurs spécifiées par la fonction [<Graphe>.HMCouleur](1000024080.md) dans un graphe de type Heatmap.

## Exemple

```wlangage
// On fixe les couleurs
GRF_Graphe.HMSupprimeCouleur()
GRF_Graphe.HMCouleur(-65, RVB(0, 105, 255))
GRF_Graphe.HMCouleur(0, RVB(240, 255, 0))
GRF_Graphe.HMCouleur(35, RVB(255, 31, 0))
```

## Syntaxe

```wlangage
<Champ Graphe>.HMSupprimeCouleur([<Palier>])
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres ou d'états).
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Palier>` *Réel optionnel*
> Palier de la couleur qui doit être supprimée. Si ce paramètre n'est pas spécifié, toutes les couleurs de palier sont supprimées et la couleur de la première série est utilisée.

## Remarques

Les données modifiées avec la fonction **<Graphe>.HMSupprimeCouleur** seront prises en compte lors du prochain appel à la fonction [<Graphe>.Dessine](1000024062.md).
