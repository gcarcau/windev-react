# PoliceSoulignée (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

La propriété **PoliceSoulignée** permet de :

- Savoir si le texte affiché est souligné ou non.
- Souligner ou non le texte.

## Exemple

```wlangage
// Souligner le texte affiché dans le champ "LIB_ChampLibellé"
LIB_ChampLibellé.PoliceSoulignée = Vrai
```

## Syntaxe

#### Savoir si le texte affiché dans un champ est souligné

```wlangage
<Résultat> = <Champ manipulé>.PoliceSoulignée
```

`<Résultat>` *Booléen*
> - Vrai si le texte est souligné,
> - Faux dans le cas contraire.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.

#### Modifier la mise en forme souligné du texte affiché dans un champ

```wlangage
<Champ manipulé>.PoliceSoulignée = <Souligné/Non souligné>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.
`<Souligné/Non souligné>` *Booléen*
> - Vrai si le texte affiché doit être souligné,
> - Faux dans le cas contraire.

## Remarques

> _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur, PHP)_ Cas particulier : champ LienLe résultat de la propriété PoliceSoulignée ne tient pas compte du fait que les navigateurs soulignent par défaut les liens.La valeur renvoyée par la propriété PoliceSoulignée en code navigateur et en code serveur pour un même champ Lien peut donc être différente.

### Limites

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS)_ Dans un état, la propriété PoliceSoulignée peut être utilisée uniquement sur :un champ Libellé.un champ Calculé.un champ Lien URL.un champ Prédéfini.

> _(WINDEV, WINDEV Mobile, iPhone/iPad)_ Dans une fenêtre, la propriété PoliceSoulignée ne peut pas être utilisée sur :un champ Spin,un champ Web Camera,un champ Conférence.Remarque : Cette propriété s'applique sur les champs "Liste image" en mode d'affichage "Liste classique" uniquement.
 La propriété PoliceSoulignée ne peut pas être utilisée sur les colonnes de table.

> _(WEBDEV - Code Serveur, PHP, Ajax)_ Dans une page, la propriété PoliceSoulignée peut être utilisée sur :un champ Libellé,un champ de saisie,un champ Bouton,un champ Interrupteur,un champ Sélecteur,un champ Liste,une colonne d'un champ Table,une cellule d'un champ Table (en lecture uniquement),un champ d'affichage formaté,un champ HTML,un champ Combo,un champ Lien,un champ Libellé HTML,un champ Réglette,un champ Chemin de navigation (sauf en PHP),un champ Arbre,un menu.
