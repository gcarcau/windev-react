# HPolitiqueSécuritéRécupère (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Récupère la politique de sécurité d'un serveur HFSQL.
Selon le type de l'utilisateur, les informations récupérées varient :

- Si l'utilisateur est un "super utilisateur", toutes les informations concernant la politique de sécurité sont récupérées.
- Pour les autres types d'utilisateurs, seules les informations concernant la complexité du mot de passe et sa taille minimale sont récupérées. Il est par exemple possible avec ces informations de créer un mot de passe qui répond à ces critères.

Nouveauté Abonnement
Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
soit maPolitique = HPolitiqueSécuritéRécupère(maConnexion)
```

## Syntaxe

```wlangage
<Résultat> = HPolitiqueSécuritéRécupère(<Connexion>)
```

`<Résultat>` *Variable de type hPolitiqueSécurité*
> Variable de type [hPolitiqueSécurité](1410091181.md) correspondant à la politique de sécurité des mots de passe actuellement présente sur le serveur HFSQL.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion au serveur HFSQL à manipuler. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
