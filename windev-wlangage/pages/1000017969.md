# Etat (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

La propriété **Etat** permet de connaître et de modifier l'état d'un élément. Cette propriété est utilisable sur :

- **les champs, les fenêtres, les pages, les états**. Pour plus de détails, consultez [Propriété Etat sur les champs](2510039.md).
- une variable de type [TâcheParallèle](1000021220.md).
- une variable de type [Thread](1000024879.md).
- une variable de type [TéléchargementInfo](1410087306.md).
- Nouveauté 2025
  une variable de type [hHistoriquePlanification](1410090764.md).
- Nouveauté SaaS
  une variable de type [hHistoriqueRéindexation](1410091059.md).
