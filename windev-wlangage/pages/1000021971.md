# EnModeSimulateurUniversalWindowsPlatform (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Identifie si le code est exécuté dans le simulateur pour les applications en mode Universal Windows Platform (Universal Windows 10 App) ou non.

## Exemple

```wlangage
// Code exécuté dans le simulateur Universal Windows 10 App ?
SI EnModeSimulateurUniversalWindowsPlatform() = Vrai ALORS
	// Code spécifique pour le simulateur
FIN
```

## Syntaxe

```wlangage
<Résultat> = EnModeSimulateurUniversalWindowsPlatform()
```

`<Résultat>` *Booléen*
> - Vrai si le code est exécuté dans le simulateur pour les applications en mode Universal Windows Platform (Universal Windows 10 App),
> - Faux dans le cas contraire.

## Remarques

### Disponibilité de la fonction
La fonction **EnModeSimulateurUniversalWindowsPlatform** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **EnModeSimulateurUniversalWindowsPlatform** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.

### Exécution des traitements contenant des erreurs de compilation
Par défaut, le mécanisme de sécurité du WLangage se déclenche uniquement si la ligne contenant l'erreur de compilation est exécutée.
Par exemple, si une fonction interdite dans le produit en cours est présente dans une boucle SI, le mécanisme de sécurité du WLangage se déclenchera uniquement si la ligne contenant cette fonction s'exécute.

**Composante : wd300vm.dll**
