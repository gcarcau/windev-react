# Fonctions de gestion des champs Kanban

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des champs Kanban (syntaxe préfixée)](1410089740.md)).
Les fonctions permettant de gérer les champs Kanban sont les suivantes :

| [KanbanAffiche](1410089522.md) | Rafraîchit l'affichage d'un champ Kanban ou d'une carte d'un champ Kanban. |
| --- | --- |
| [KanbanAjouteCarte](1410089140.md) | Ajoute une carte dans une liste d'un champ Kanban. |
| [KanbanAjouteListe](1410089137.md) | Ajoute une nouvelle liste dans un champ Kanban. |
| [KanbanDéplaceCarte](1410089144.md) | Déplace une carte dans un champ Kanban. |
| [KanbanDéplaceListe](1410089540.md) | Déplace une liste de Kanban dans un champ Kanban. |
| [KanbanEnregistre](1410089562.md) | Modifie l'enregistrement associé à la carte en cours dans le champ Kanban fichier. |
| [KanbanFiltre](1410089534.md) | Affiche uniquement les cartes correspondant au filtre spécifié. |
| [KanbanIndiceListe](1410089317.md) | Renvoie l'indice d'une liste présente dans un champ Kanban. |
| [KanbanInfoXY](1410089224.md) | Renvoie pour une position donnée dans un champ Kanban (coordonnées d'un point du champ) :  - soit le numéro de la carte pour la position indiquée, - soit le numéro de la liste pour la position indiquée. |
| [KanbanInsèreCarte](1410089316.md) | Insère une carte dans une liste de Kanban. |
| [KanbanInsèreListe](1410089539.md) | Insère une liste de Kanban dans un champ Kanban. |
| [KanbanOccurrence](1410089240.md) | Renvoie le nombre de cartes ou de listes dans un champ Kanban. |
| [KanbanPositionListe](1410089241.md) | Permet de faire défiler une liste d'un champ Kanban afin d'afficher une carte donnée. |
| [KanbanSupprimeCarte](1410089141.md) | Supprime une carte d'un champ Kanban ou d'un champ Liste de Kanban. |
| [KanbanSupprimeListe](1410089239.md) | Supprime une liste de Kanban d'un champ Kanban. |
| [KanbanSupprimeToutCarte](1410089143.md) | Supprime toutes les cartes d'un champ Kanban ou d'un champ Liste de Kanban. |
