# DriveSupprimeFichier (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Supprime un fichier dans un drive (disque distant).

## Exemple

```wlangage
oOAuth2Param est un OAuth2Paramètres
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.URLRedirection = "http://localhost:9000/"

oDrive est un Drive
oDrive = oDriveConnecte(oOAuth2Param)

SI DriveSupprimeFichier(oDrive, "/MesRépertoires/Fichier.txt") = Faux ALORS
	Erreur("Impossible de supprimer le fichier demandé", ErreurInfo())
	RETOUR
FIN
```

## Syntaxe

#### Supprimer un fichier à l'intérieur d'un drive

```wlangage
<Résultat> = DriveSupprimeFichier(<Drive> , <Fichier à supprimer>)
```

`<Résultat>` *Booléen*
> - Vrai si le fichier a été supprimé,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Drive>` *Variable de type Drive ou gglDrive*
> Nom de la variable de type [Drive](1410089369.md) ou [gglDrive](1410089374.md) correspondant au drive à manipuler. La connexion au drive voulu doit avoir été effectuée. Dans le cas contraire, la suppression n'est pas réalisée.
`<Fichier à supprimer>` *Chaîne de caractères*
> Chemin absolu du fichier à supprimer. Si ce paramètre ne correspond pas à un chemin de fichier valide, le fichier ne sera pas supprimé.

#### Supprimer un fichier de la suite Google à l'intérieur d'un drive Google

```wlangage
<Résultat> = DriveSupprimeFichier(<Drive Google> , <Fichier à supprimer>)
```

`<Résultat>` *Booléen*
> - Vrai si le fichier a été supprimé,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Drive Google>` *Variable de type gglDrive*
> Nom de la variable de type [gglDrive](1410089374.md) correspondant au drive Google à manipuler. La connexion au drive voulu doit avoir été effectuée. Dans le cas contraire, la suppression n'est pas réalisée.
`<Fichier à supprimer>` *Variable de type FichierGgl*
> Nom de la variable de type [FichierGgl](1410089586.md) correspondant au fichier à manipuler.

## Remarques

Un fichier supprimé via la fonction **DriveSupprimeFichier** ne peut pas être recréé directement. L'utilisateur doit se connecter à nouveau au drive pour que la recréation du fichier soit possible.
