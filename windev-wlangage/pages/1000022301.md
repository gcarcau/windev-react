# <Fenêtre>.EdCréeNote (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Crée un champ Note repositionnable par programmation.

## Exemple

```wlangage
NOTE_Manote est un Champ
NOTE_Manote <- MaFenêtre.EdCréeNote("Nouvelle note")
NOTE_Manote.CouleurFond = BleuClair
```

## Syntaxe

```wlangage
[<Résultat> <- ] <Fenêtre>.EdCréeNote(<Texte initial> [, <X> [, <Y>]])
```

`<Résultat>` *Variable de type Champ*
> Le champ Note créé peut être manipulé via une variable de type [Champ](1000020967.md). Dans ce cas, l'affectation doit être réalisée avec l'opérateur **'<-'**.
> Si la fonction **<Fenêtre>.EdCréeNote** est utilisée directement, le champ Note est créé dans la fenêtre et il est visible par défaut.
`<Fenêtre>` *Nom de fenêtre*
> Nom ou alias de la fenêtre dans laquelle le champ Note sera créé.
> Si ce paramètre n'est pas précisé ou correspond à une chaîne vide (""), le champ Note sera créé dans la fenêtre en cours.
`<Texte initial>` *Chaîne de caractères*
> Texte affiché dans le champ Note.
`<X>` *Entier optionnel*
> Abscisse du champ Note à créer (position sur l'axe des X) en pixels. Position horizontale du coin haut gauche du champ par rapport au coin haut gauche de la zone client de la fenêtre (c'est-à-dire la fenêtre sans les barres de titre et de menu ni le cadre). Ce paramètre correspond à la propriété [XInitial](2510140.md).
> Si ce paramètre n'est pas précisé, l'abscisse du champ Note correspond à la position X de la souris.
>
> Il est ensuite possible de modifier cette valeur avec la propriété [X](2510135.md).
`<Y>` *Entier optionnel*
> Ordonnée du champ Note à créer (position sur l'axe des Y) en pixels. Position verticale du coin haut gauche du champ par rapport au coin haut gauche de la zone client de la fenêtre (c'est-à-dire la fenêtre sans les barres de titre et de menu ni le cadre). Ce paramètre correspond à la propriété [YInitial](2510087.md).
> Si ce paramètre n'est pas précisé, l'ordonnée du champ Note correspond à la position Y de la souris.
>
> Il est ensuite possible de modifier cette valeur avec la propriété [Y](2510137.md).

## Remarques

### Caractéristiques du champ Note repositionnable

- La création peut être annulée par Ctrl + Z.
- Le champ Note repositionnable créé est une note persistante : si la fenêtre est fermée puis ré-ouverte, la note sera restaurée.
  Pour créer un champ Note non persistant, utilisez la fonction [ChampCrée](1000020876.md) avec la constante *typNoteRepositionnable*.
- Le champ Note repositionnable créé sera sauvé lors de l'appel aux fonctions :
  - [<Fenêtre>.EdSauve](1000022330.md),
  - [FenEdSauveNote](1000022120.md),
  - [NoteSauveTout](1000022396.md).

### Equivalences

- Cette fonction est équivalente à la création d'une note dans la fenêtre par l'utilisateur final via la FAA (Fonctionnalité Automatique de votre Application). Pour plus de détails, consultez [Note repositionnable (FAA)](1000021820.md).
- Utilisée pour créer un champ Note repositionnable dans la fenêtre en cours, cette fonction est équivalente à la fonction [NoteCrée](1000022395.md).
