# EmailAbonneAuDossier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Ajoute un dossier existant à la liste des dossiers abonnés.
Nouveauté Abonnement
Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
session est une emailSessionIMAP
session.AdresseServeur = "imap.gmail.com"
session.Port = 993
session.Option = optionTLS
session.Nom = "XXXXX"
session.MotDePasse = "XXXXXXX"
EmailOuvreSession(session)

// Liste des dossiers de gestion des mails et des dossiers abonnés
res est chaîne
res = EmailListeDossier(session, LstDossierNormal)
Trace(res)
Trace("---------------------------------------------------")
// Abonne le dossier "Test"
Trace("Abonnement : " + (EmailAbonneAuDossier(session, "Test") ? "OK" SINON "KO"))
Trace("---------------------------------------------------")
// Liste des dossiers de gestion des mails et des dossiers abonnés
// Le dossier Test est désormais listé
res = EmailListeDossier(session, LstDossierNormal)
Trace(res)
Trace("---------------------------------------------------")
```

## Syntaxe

```wlangage
<Résultat> = EmailAbonneAuDossier(<Session IMAP> , <Dossier>)
```

`<Résultat>` *Booléen*
> - Vrai si le dossier spécifié a été abonné,
> - Faux dans le cas contraire. Le compte-rendu détaillé de l'erreur est connu grâce à la fonction [ErreurInfo](3013008.md).
`<Session IMAP>` *Variable de type emailSessionIMAP*
> Nom de la variable de type [emailSessionIMAP](1000018957.md) correspondant à la session IMAP connectée au serveur de mails.
`<Dossier>` *Chaîne de caractères*
> Nom et chemin du dossier à ajouter dans la liste des dossiers abonnés.

## Remarques

- Les dossiers créés avec la fonction [EmailAjouteDossier](3032129.md) sont automatiquement abonnés.
- La fonction [EmailListeDossier](3032133.md) utilisée avec la constante *LstDossierNormal* liste les dossiers contenant les emails et les dossiers abonnés. Si un dossier abonné contient des sous dossiers, ces sous dossiers seront également listés.
- La fonction [EmailListeDossier](3032133.md) utilisée avec la constante *LstDossierTous* liste tous les dossiers (dossiers contenant les emails et dossiers abonnés ou non abonnés).
