# CaméraListeDriver (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Liste les drivers de capture vidéo installés sur le poste en cours.
Remarque : Cette fonction est équivalente à la fonction [VidéoListeDriver](3079008.md).

## Exemple

```wlangage
// Connaître les drivers Vidéo installés
// Affichage dans la liste LISTE_ListeDriver
ListeAjoute(LISTE_ListeDriver, CaméraListeDriver(viDirectShow))
```

## Syntaxe

```wlangage
<Résultat> = CaméraListeDriver([<Technologie utilisée>])
```

`<Résultat>` *Chaîne de caractères*
> Liste des drivers vidéo installés sur le poste, sous la forme :
>
>
> ```wlangage
> <Nom du driver 1> + TAB + <Version du driver 1> + RC + ... <Nom du driver N> + TAB + <Version du driver N>
> ```
>
>
>
> Où :
>
>
> - <Nom du driver 1> ... <Nom du driver N> correspondent au nom des drivers vidéos,
> - <Version du driver 1> ... <Version du driver N> correspondent à la version du driver.
`<Technologie utilisée>` *Constante de type Entier*
> Type de technologie utilisée pour lister les drivers :
>
> | *vidDirectShow* | Technologie utilisée : Direct Show.  Cette constante doit être utilisée pour sélectionner un driver utilisé dans un champ Conférence (fonction [FluxChangeDriver](1000021613.md)). |
> | --- | --- |
> | *vidVideoForWindows* (Valeur par défaut) | Technologie utilisée : Video for Windows |

**Composante : wd300obj.dll**
