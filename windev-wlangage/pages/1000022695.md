# <Variable Connexion>.ListeOptimisationPlanifiée (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Liste les tâches d'optimisation planifiées des fichiers de données HFSQL Client/Serveur pour une connexion.

## Exemple

```wlangage
MaConnexion est une Connexion
...
tabOptim est un tableau de hOptimisationPlanifiée
tabOptim = MaConnexion.ListeOptimisationPlanifiée()
POUR TOUT Optim DE tabOptim
	AfficheInfo(Optim)
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.ListeOptimisationPlanifiée()
```

`<Résultat>` *Tableau de variables de type hOptimisationPlanifiée*
> Variable de type tableau de [hOptimisationPlanifiée](1000018854.md). Chaque élément de ce tableau contient les caractéristiques d'une tâche d'optimisation planifiée. Le nombre d'éléments de ce tableau correspond au nombre de tâches d'optimisation planifiée disponibles.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle les tâches d'optimisation planifiées doivent être listées.

## Remarques

### Droits nécessaires
Pour lister les tâches d'optimisation planifiées, il est nécessaire de posséder pour chaque base concernée, le droit de connexion (constante *hDroitConnexion* ou *hDroitConnexionCryptée*),
Pour une optimisation du serveur complet, l'utilisateur doit être super-utilisateur.

Pour savoir si un utilisateur ou un groupe possède ces droits, utilisez la fonction [<Variable Connexion>.InfoDroitServeur](1000022668.md) ou [HInfoDroitDaseDeDonnées](1000022666.md).

Pour modifier les droits d'un utilisateur ou d'un groupe d'utilisateurs, utilisez la fonction [<Variable Connexion>.ModifieDroitServeur](1000022710.md) ou [<Variable Connexion>.ModifieDroitBaseDeDonnées](1000022707.md).
