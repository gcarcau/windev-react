# <Tableur>.FinModification (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Signale la fin du regroupement d'un ensemble d'opérations sur un champ Tableur en un seul événement (gestion du "undo/redo").

## Exemple

```wlangage
// Met en gras et italique la sélection. Un seul Ctrl + Z annule les 2 opérations
TBLR_MonTableur.DébutModification()
TBLR_MonTableur.StyleSélection(tblrGras, Vrai)
TBLR_MonTableur.StyleSélection(tblrItalique, Vrai)
TBLR_MonTableur.FinModification()
```

## Syntaxe

```wlangage
<Champ Tableur>.FinModification()
```

`<Champ Tableur>` *Nom de champ*
> Nom du champ Tableur à manipuler.

## Remarques

Les modifications effectuées sur le champ Tableur sont regroupées à partir de l'appel de la fonction [<Tableur>.DébutModification](1000023721.md). Si plusieurs modifications annulables sont effectuées dans le champ Tableur, il suffit d'un seul Ctrl + Z pour annuler toutes les opérations effectuées.

**Composante : wd300obj.dll**
