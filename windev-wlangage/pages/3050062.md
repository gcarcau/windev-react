# Cosinus (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Calcule le cosinus d'un angle.

## Exemple

```wlangage
// Calcul du cosinus de 60
ResCosinus = Cosinus(60)
// Renvoie 0.5
```

## Syntaxe

```wlangage
<Résultat> = Cosinus(<Angle>)
```

`<Résultat>` *Réel*
> Cosinus de l'angle spécifié.
`<Angle>` *Entier ou réel*
> Angle (en degrés) à manipuler. Ce paramètre peut avoir une valeur quelconque : le calcul du cosinus est effectué "modulo 360".
