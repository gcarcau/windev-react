# NbReçus (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Apple Watch)

La propriété **NbReçus** permet de connaître le nombre de paramètres réellement reçus par une procédure.
**Remarque** : La propriété [Occurrence](2510097.md) permet de connaître le nombre de paramètres utilisables dans la procédure.

## Exemple

```wlangage
// Appel de la procédure
MaProc("A")
```

```wlangage
// Déclaration de la procédure
PROCÉDURE MaProc(p1, po2 = "Y", po3 = "Z")
Info(MesParamètres.NbReçus) // Renvoie 1
Info(MesParamètres.Occurrence) // Renvoie 3
```

## Syntaxe

```wlangage
<Résultat> = <MesParamètres>.NbReçus
```

`<Résultat>` *Entier*
> Nombre de paramètres réellement reçus par la procédure. Ce nombre ne prend pas en compte les paramètres optionnels pour lesquels aucune valeur n'a été spécifiée lors de l'appel.
`<MesParamètres>` *Mot-clé*
> Mot-clé du WLangage permettant de désigner l'ensemble des paramètres d'une procédure.
