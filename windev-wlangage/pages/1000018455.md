# sfErreur (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Le type **sfErreur** permet de connaître les caractéristiques d'une erreur renvoyée par Salesforce. Les caractéristiques de ces erreurs peuvent être connues à l'aide de différentes propriétés WLangage.
Ce type de variable est utilisé par les types de variables suivants :

- [sfRésultatConvertitPiste](1000018739.md).
- [sfRésultatDéconnecte](1000018560.md).
- [sfRésultatExécuteTraitement](1000018559.md).
- [sfRésultatFusionne](1000018499.md).
- [sfRésultatRestaure](1000018526.md).
- [sfRésultatSauvegarde](1000018460.md).
- [sfRésultatSupprime](1000018546.md).
- [sfRésultatVideCorbeille](1000018467.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Propriétés

### Propriétés spécifiques à la description des variables de type sfErreur
Les propriétés suivantes peuvent être utilisées pour manipuler une erreur Salesforce :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| CodeErreur | Chaîne de caractères | Code de l'erreur. Ce code permet de connaître l'erreur rencontrée. Pour plus de détails, consultez directement la documentation de l'API Salesforce (mot-clé StatusCode). **Cette propriété est disponible en lecture seulement**. |
| Message | Chaîne de caractères | Texte du message d'erreur. **Cette propriété est disponible en lecture seulement**. |
| Rubrique | Chaîne de caractères | Liste des rubriques concernées par l'erreur. Les noms des rubriques sont séparés par des RC (retour-chariot). **Cette propriété est disponible en lecture seulement**. |
