# <Carte>.SupprimeTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Supprime dans un champ Carte :

- tous les marqueurs,
- toutes les formes,
- toutes les images.

> _(Android)_ Si des itinéraires ont été ajoutés à la carte (fonction <Carte>.AjouteItinéraire), ils sont également supprimés.

## Exemple

```wlangage
// Suppression de tous les marqueurs du champ Carte
CARTE_MaCarte.SupprimeTout()
```

## Syntaxe

```wlangage
<Champ Carte>.SupprimeTout()
```

`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler.

## Remarques

- Gestion des marqueurs :
  - Pour supprimer un marqueur en particulier affiché dans un champ Carte, utilisez la fonction [<Carte>.SupprimeMarqueur](1000022466.md).
  - Pour ajouter un nouveau marqueur sur un champ Carte, utilisez la fonction [<Carte>.AjouteMarqueur](1000022422.md).
  - Pour modifier un marqueur affiché dans un champ Carte, utilisez la fonction [<Carte>.ModifieMarqueur](1000022383.md).
- Gestion des itinéraires : Pour supprimer un itinéraire particulier, utilisez la fonction [<Carte>.SupprimeItinéraire](1000022465.md).
- Gestion des images :
  - Pour supprimer une image spécifique affichée dans un champ Carte, utilisez la fonction [<Carte>.SupprimeImage](1000025829.md).
  - Pour ajouter une nouvelle image dans un champ Carte, utilisez la fonction [<Carte>.AjouteImage](1000025802.md).
  - Pour modifier une image dans un champ Carte, utilisez la fonction [<Carte>.ModifieImage](1000025818.md).
- Gestion des formes :
  - Pour supprimer une forme spécifique affichée dans un champ Carte, utilisez la fonction [<Carte>.SupprimeForme](1000025820.md).
  - Pour ajouter une nouvelle forme dans un champ Carte, utilisez la fonction [<Carte>.AjouteForme](1000025801.md).
  - Pour modifier une forme dans un champ Carte, utilisez la fonction [<Carte>.ModifieForme](1000025805.md).
