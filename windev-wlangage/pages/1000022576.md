# RetraitGauche (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **RetraitGauche** permet de connaître et de modifier le retrait à gauche d'un élément. Cette propriété est utilisable sur :

- les champs de saisie et les champs Libellé. Pour plus de détails, consultez [RetraitGauche](2513018.md).
- les variables de type [docParagraphe](1000022483.md).
- les variables de type [docNiveauNumérotation](1000022799.md).
