# HsMenu,Etat (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Renvoie l'état d'une option de menu (actif, invisible, grisé).

## Exemple

```wlangage
// En C// Etat de l'option correspondant au chemin LCAPPELWD("HsMenu,Etat,LC");if WDEntier==1 APPELWD("INFO, L'option n'est pas active");// Etat de l'option numéro 15APPELWD("HsMenu,Etat,15");if WDEntier==2 APPELWD("INFO, L'option n'apparaît pas");
```

```wlangage
// En Pascal(* Etat de l'option correspondant au chemin LC *)APPELWD('HsMenu,Etat,LC');if WDEntier=1 then  APPELWD('INFO, L'option n'est pas active');(* Etat de l'option numéro 15 *)APPELWD('HsMenu,Etat,15');if WDEntier=2 then  APPELWD('INFO, L'option n'apparaît pas');
```

```wlangage
// En VB' Etat de l'option correspondant au chemin LCcall APPELWD("HsMenu,Etat,LC")if WDEntier=1 then  call APPELWD('INFO, L'option n'est pas active')end if' Etat de l'option numéro 15call APPELWD("HsMenu,Etat,15")if WDEntier=2 then   call APPELWD("INFO, L'option n'apparaît pas")end if
```

## Syntaxe

```wlangage
HsMenu,Etat([<Option>])
```

`<Option>` *Chaîne de caractères (optionnelle)*
> Numéro qui correspond :
>
> - soit à l'indice de l'option
> - soit à une chaîne de caractères correspondant au chemin d'accès à l'option (lettres d'appels).

## Remarques

**HsMenu,Etat** retourne dans WdEntier l'état de l'option du menu. Cet état peut correspondre à :

- -1 si l'option n'existe pas
- 0 si l'option est active
- 1 si l'option est grisée
- 2 si l'option est invisible
