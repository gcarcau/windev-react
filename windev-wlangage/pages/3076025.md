# telNuméroAppelé (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Permet de connaître le numéro de téléphone appelé.

## Exemple

```wlangage
NumTel est une chaîne
NumTel = telNuméroAppelé(IDAppel)
Message("Appel en cours : " + NumTel + "...")
```

## Syntaxe

```wlangage
<Résultat> = telNuméroAppelé([<Identifiant de l'appel>])
```

`<Résultat>` *Chaîne de caractères*
> Numéro de téléphone appelé.
`<Identifiant de l'appel>` *Entier optionnel*
> Identifiant de l'appel à manipuler. Cet identifiant est connu dans la procédure WLangage appelée par la fonction [telDémarreDétectionAppel](3076029.md).
> Si ce paramètre n'est pas spécifié, l'appel en cours est manipulé. Dans le cas d'un appel sortant (fonction [telCompose](3076013.md)), l'appel en cours correspond à l'appel sortant.

## Remarques

### Configuration nécessaire
Les fonctions de téléphonie utilisent la technologie TAPI 2.0 et/ou la technologie TAPI 3.1. Ces technologies sont utilisables sur tous les systèmes.

**Composante : wd300com.dll**
