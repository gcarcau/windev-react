# Navigation facilitée dans les éditeurs

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

La navigation dans les éditeurs est facilitée par la présence d'une nouvelle barre de navigation dynamique, activée par la combinaison de touches Ctrl + Tab.
L'historique de la navigation est mémorisé et il est facile de revenir en arrière.

L'utilisation de la barre de navigation permet de parcourir les différents éléments ouverts. Lors du passage sur le nom d'un élément, cet élément est visualisé dans l'environnement.
