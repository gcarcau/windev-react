# Numérotation

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

La propriété **Numérotation** permet de décrire la numérotation d'un élément. Cette propriété est utilisable :

- sur une variable de type [docParagraphe](1000022483.md).
- sur une variable de type [Document](1000022461.md).
