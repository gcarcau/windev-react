# Aérer une sélection de champs

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Pour créer des UI actuelles, il est nécessaire d'espacer les champs de vos fenêtres ou vos pages. Avec WINDEV, WEBDEV et WINDEV Mobile, il suffit d'indiquer l'espacement voulu et les champs sont automatiquement déplacés.
Nouveauté 2025

> _(WEBDEV - Code Serveur)_ Cette fonctionnalité est désormais disponible pour les sites WEBDEV.

## Comment le faire ?

Pour augmenter l'espacement entre les champs :

1. Sélectionnez les champs concernés.
2. Sous le volet "Alignement", dans le groupe "Autres alignements", déroulez "Agrandir
  Aérer" et sélectionnez "Aérer la sélection".
3. Dans la fenêtre qui s'affiche, indiquez les paramètres permettant d'aérer l'espace entre les champs sélectionnés :  Il est possible de :
  - Indiquer le pas d'aération en largeur et/ou en hauteur. L'icône  permet de lier les deux valeurs.
  - Indiquer si nécessaire la tolérance voulue. Cette tolérance permet d'affiner la détection des champs à aérer lorsque ceux-ci ne sont pas correctement alignés ou s'ils se chevauchent.
   L'icône  permet d'obtenir un aperçu de la modification en temps réel dans votre fenêtre.
4. Validez. Les paramètres indiqués sont appliqués aux champs sélectionnés.

**Remarques** :

- L'espacement se fait vers la droite et vers le bas.
- Attention : La taille de la fenêtre n'est pas modifiée.
