# Précision (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **Précision** permet de manipuler la précision d'un élément. Cette propriété est utilisable sur :

- une variable de type [géoPosition](1000019191.md).
- une variable de type [ocrOption](1000025768.md).
