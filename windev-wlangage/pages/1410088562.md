# Fonctions de gestion des diagrammes

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des diagrammes (syntaxe préfixée)](1410089917.md)).
Les fonctions de gestion des diagrammes et du champ Editeur de diagrammes sont les suivantes :

| [DiagrammeCharge](1410088123.md) | Charge un diagramme dans une variable de type Diagramme à partir d'un fichier ".wddiag", d'un mémo ou d'un buffer binaire. |
| --- | --- |
| [DiagrammeChargeBibliothèque](1410088356.md) | Charge un fichier diagramme pour en faire une bibliothèque de formes prédéfinies. |
| [DiagrammeDébutModification](1410088735.md) | Signale le début du regroupement d'un ensemble d'opérations sur un document de type Diagramme en un seul événement (gestion du "undo/redo"). |
| [DiagrammeDégroupe](1410088422.md) | Dissocie les différentes formes d'un groupe dans un champ Editeur de diagrammes. |
| [DiagrammeFinModification](1410088736.md) | Signale la fin du regroupement d'un ensemble d'opérations sur un document de type Diagramme en un seul événement (gestion du "undo/redo"). |
| [DiagrammeFormeVersImage](1410088373.md) | Crée une image à partir d'une forme d'un diagramme (la forme peut être affichée ou non dans le diagramme). |
| [DiagrammeGroupe](1410088421.md) | Crée un groupe à partir des éléments sélectionnés dans le champ Editeur de diagrammes. |
| [DiagrammeInfoXY](1410088464.md) | Indique la présence d'une forme à une position donnée dans le champ Editeur de diagrammes. |
| [DiagrammeRecherche](1410088695.md) | Recherche les formes contenant un texte spécifique dans un diagramme. |
| [DiagrammeSauve](1410088122.md) | Sauve un diagramme dans un fichier "diag". |
| [DiagrammeSelectMoins](1410088168.md) | Désélectionne une forme dans un champ Editeur de diagrammes. |
| [DiagrammeSelectPlus](1410088167.md) | Sélectionne une forme dans un champ Editeur de diagrammes. |
| [DiagrammeVersImage](1410088144.md) | Exporte un diagramme vers une une variable de type [Image](1000019650.md). |
| [DiagrammeVersSVG](1410088873.md) | Exporte un diagramme vers une image vectorielle au format SVG. |

Plusieurs types de variables spécifiques permettent également de manipuler les diagrammes :

| [diagBibliothèque](1410088354.md) | Le type **diagBibliothèque** permet de définir toutes les caractéristiques avancées d'une bibliothèque de formes prédéfinies utilisée par un champ Editeur de diagrammes. |
| --- | --- |
| [diagBordure](1410088179.md) | Le type **diagBordure** permet de définir toutes les caractéristiques avancées d'une bordure (ou d'un cadre) d'une forme utilisée dans un diagramme. |
| [diagChemin](1410088384.md) | Le type **diagChemin** permet de définir toutes les caractéristiques avancées d'une forme de type Chemin (équivalent à une forme polygone pouvant comporter des lignes arrondies). |
| [diagExtrémité](1410088470.md) | Le type **diagExtrémité** permet de définir toutes les caractéristiques avancées d'une extrémité d'un lien entre 2 formes d'un diagramme. |
| [diagForme](1410088082.md) | Le type **diagForme** permet de définir toutes les caractéristiques avancées de la forme de base utilisée par un diagramme. |
| [diagGroupe](1410088127.md) | Le type **diagGroupe** permet de définir toutes les caractéristiques avancées d'un groupe de formes dans un champ Editeur de Diagrammes. |
| [diagImage](1410088414.md) | Le type **diagImage** permet de définir toutes les caractéristiques avancées d'une forme de diagramme réalisée à partir d'une image. |
| [diagLien](1410088454.md) | Le type **diagLien** permet de définir toutes les caractéristiques avancées d'un lien entre 2 formes d'un diagramme. |
| [diagMiseEnPage](1410088610.md) | Le type **diagMiseEnPage** permet de définir toutes les caractéristiques de mise en page d'un diagramme. |
| [diagOvale](1410088135.md) | Le type **diagOvale** permet de définir toutes les caractéristiques avancées d'une forme de type Ovale. |
| [diagPoint](1410088140.md) | Le type **diagPoint** permet de définir toutes les caractéristiques avancées d'un point dans un diagramme. |
| [diagPointDAttache](1410088457.md) | Le type **diagPointDAttache** permet de définir toutes les caractéristiques avancées d'un point permettant d'attacher un lien sur une forme présente dans un champ Editeur de diagrammes. |
| [diagPointDePassage](1410088548.md) | Le type **diagPointDePassage** permet de définir toutes les caractéristiques avancées d'un point de passage pour un lien. |
| [diagPolygone](1410088137.md) | Le type **diagPolygone** permet de définir toutes les caractéristiques avancées d'une forme de type Polygone. |
| [Diagramme](1410088055.md) | Le type **Diagramme** permet de définir toutes les caractéristiques avancées d'un diagramme éditable via le champ Editeur de diagrammes. |
| [diagRectangle](1410088083.md) | Le type **diagRectangle** permet de définir toutes les caractéristiques avancées d'une forme de type Rectangle. |
| [diagSélection](1410088172.md) | Le type **diagSélection** permet de définir toutes les caractéristiques avancées d'une sélection réalisée dans un diagramme. |
| [diagTexte](1410088393.md) | Le type **diagTexte** permet de définir toutes les caractéristiques avancées d'un texte associé à une forme dans un diagramme. |
