# <Variable httpRéponse>.RécupèreCookie (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Récupère les cookies lus dans la variable [httpRéponse](1000021165.md) (contenant le résultat de la fonction [<Variable httpRequête>.Envoie](1000021624.md)).

## Syntaxe

#### Récupérer les cookies lus via une variable de type httpRéponse

```wlangage
<Résultat> = <Réponse HTTP>.RécupèreCookie()
```

`<Résultat>` *Tableau de variables de type Cookie*
> Liste des cookies stockés en mémoire pour le domaine spécifié.
`<Réponse HTTP>` *Variable de type httpRéponse*
> Nom de la variable [httpRéponse](1000021165.md) pour laquelle les cookies doivent être listés.

**Composante : wd300com.dll**
