# <Variable mongoGridFS>.SupprimeFichierParID (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Supprime un fichier identifié par son identifiant dans un système de fichiers MongoDB.
**Remarque** : Pour supprimer un fichier identifié à partir de son nom, utilisez la fonction [<Variable mongoGridFS>.SupprimeFichier](1000025394.md).

## Exemple

```wlangage
gCnxMONGO est un mongoConnexion

fsVV est un mongoGridFS
fsVV.Préfixe = "fs"
fsVV.BaseDeDonnées = gCnxMONGO.BaseDeDonnées[SAI_BASE]

tabFichier = fsVV.ListeFichier()
fic est un mongoGridFSInfoFichier
i est entier
POUR TOUT fic DE tabFichier
	i++
	Trace("-------------------------------------------------------------")
	Trace("n°: " + i)
	Trace("ID : " + VariantVersJSON(fic.ID))
	Trace("Nom : " + fic.Nom)
	fsVV.SupprimeFichierParID(fic.ID)
	SI ErreurDétectée ALORS
		Info("Pb dans SupprimeFichierParID : ", ErreurInfo(errComplet))
	FIN
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Système de fichiers>.SupprimeFichierParID(<Identifiant du fichier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème. La fonction [ErreurInfo](3013008.md) permet d'identifier l'erreur.
`<Système de fichiers>` *Variable de type mongoGridFS*
> Nom de la variable de type [mongoGridFS](1000022416.md) correspondant au système de fichiers Mongo à manipuler.
`<Identifiant du fichier>` *Variant*
> Identifiant du fichier à supprimer.

**Composante : wd300big.dll**
