# Figma : comment trouver la clé Figma

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Pour utiliser l'import Figma dans votre produit, il est nécessaire de spécifier la clé Figma dans les options générales de WINDEV, WEBDEV ou WINDEV Mobile.
Cette clé correspond à un token qui doit être généré depuis Figma.

Attention : ce token est généré pour une période spécifique. A l'issue de cette période, l'import Figma ne fonctionnera plus et il sera nécessaire de regénérer un token. Il est conseillé de choisir un token à durée illimitée (voir ci-dessous).

## Génération du token Figma

Pour générer le token Figma :

1. Lancez Figma (en mode Application ou en mode Web).
2. Connectez-vous à votre compte ou créez un nouveau compte.
3. Affichez les paramètres du compte (option "Settings" du compte).
4. Dans la zone "Personal access tokens", cliquez sur "Generate new token".
5. Dans la fenêtre qui s'affiche, spécifiez :
  - Le nom du token.
  - La période d'utilisation. Attention : par défaut, la période de validité du token est de 30 jours. Il est possible de choisir une période de 90 jours ou un token infini.
    Remarque : Lorsque le token sera arrivé à expiration, il ne sera plus possible d'utiliser l'import Figma dans WINDEV, WEBDEV ou WINDEV Mobile. Il sera nécessaire de re-générer un token.
6. Conservez les options par défaut.
7. Cliquez sur "Generate token".
8. Le token est affiché. Copiez ce token et conservez-le.
  Attention : Il n'y aura aucun autre moyen de retrouver ce token. Si vous ne le copiez pas, il sera nécessaire de générer un nouveau token.
9. Fermez la fenêtre de paramétrage de Figma.

### Saisir la clé dans WINDEV, WEBDEV ou WINDEV Mobile
Dans WINDEV, WEBDEV ou WINDEV Mobile, renseignez le token Figma dans les options générales du produit :

1. Sous le volet "Accueil", dans le groupe "Environnement", déroulez "Options" et sélectionnez "Options générales de xxx".
2. Affichez l'onglet "API tierces".
3. Dans l'option "Clé Figma", indiquez la clé Figma générée précédemment.
  Remarque : Le bouton "Tester" permet de tester la validité de la clé Figma.
