# HTTPEnvoieAsynchrone (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Envoie une requête HTTP en mode asynchrone : le programme continue de s'exécuter et la réponse est traitée par une procédure spécifique.
Nouveauté Abonnement
Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
cMaRequête est un httpRequête
cMaRequête.URL = "http://www.monsite.fr/api/streamdata"
cMaRequête.ProcédureEntête = procédure(cMonEntête est un httpRéponse) {
	SI cMonEntête.CodeEtat = 200 ALORS Trace("Requête envoyée.")
}
cMaRequête.ProcédureDonnées = procédure(bufMorceau est un Buffer) {
	Trace("Je traite [%Taille(bufMorceau)%] octets de données")
}
PROCÉDURE INTERNE procFin(cMaRéponse est un httpRéponse)
	Trace("requête http terminée")
FIN
HTTPEnvoieAsynchrone(cMaRequête, procFin)
```

## Syntaxe

#### Envoyer une requête HTTP (variable de type httpRequête)

```wlangage
HTTPEnvoieAsynchrone(<Requête HTTP> , <Procédure WLangage>)
```

`<Requête HTTP>` *Variable de type httpRequête*
> Nom de la variable de type [httpRequête](1000021158.md) contenant les caractéristiques de la requête HTTP à envoyer au serveur.
`<Procédure WLangage>` *Nom de procédure*
> Nom de la procédure WLangage appelée lors de la réponse du serveur HTTP. Pour plus de détails, consultez [Paramètres de la procédure utilisée par la fonction HTTPEnvoieAsynchrone](1000025791.md).

#### Envoyer une requête HTTP en précisant l'URL à interroger

```wlangage
HTTPEnvoieAsynchrone(<URL> , <Procédure WLangage>)
```

`<URL>` *Chaîne de caractères*
> URL à interroger.
`<Procédure WLangage>` *Nom de procédure*
> Nom de la procédure WLangage appelée lors de la réponse du serveur HTTP. Pour plus de détails, consultez [Paramètres de la procédure utilisée par la fonction HTTPEnvoieAsynchrone](1000025791.md).

## Remarques

Si la gestion des cookies est mise en place pour la requête spécifiée (fonction [HTTPCookieGère](1000019218.md)), après l'appel de la fonction **HTTPEnvoieAsynchrone** les cookies reçus sont mis à jour dans la variable [httpRequête](1000021158.md). Ainsi, lors du prochain appel de la fonction **HTTPEnvoieAsynchrone** avec cette requête, les cookies seront pris en compte.
