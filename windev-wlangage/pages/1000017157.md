# CorbeilleVide (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **Autres** (Procédures stockées)

Vide la corbeille du système.

## Exemple

```wlangage
CorbeilleVide()
```

## Syntaxe

```wlangage
<Résultat> = CorbeilleVide()
```

`<Résultat>` *Booléen*
> - Vrai si la corbeille a été vidée,
> - Faux dans le cas contraire.

**Composante : wd300std.dll**
