# HDésactiveTriggerServeur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Désactive un trigger Serveur HFSQL Client/Serveur sur un serveur. Ce trigger est désactivé pour tous les clients de ce serveur. Ce trigger pourra ensuite être réactivé simplement grâce à la fonction [HActiveTriggerServeur](1000017034.md).
**Remarque** : Les fonctions de manipulation des triggers serveur sont des fonctions avancées. Les triggers serveur peuvent être créés directement dans l'éditeur d'analyses. Pour plus de détails, consultez [Triggers serveur](3044369.md).

## Syntaxe

#### Désactiver un trigger serveur sur les fichiers de données HFSQL logiques

```wlangage
HDésactiveTriggerServeur(<Trigger> , <Fichiers de données logiques HFSQL Client/Serveur>)
```

`<Trigger>` *Chaîne de caractères*
> Nom du trigger à désactiver. Ce nom a été donné grâce à la fonction [HDécritTriggerServeur](1000017033.md).
`<Fichiers de données logiques HFSQL Client/Serveur>` *Chaîne de caractères*
> Nom logique de un ou plusieurs fichiers de données HFSQL Client/Serveur.
> Pour indiquer plusieurs noms, séparez les noms de fichiers de données par une virgule (",").

#### Désactiver un trigger serveur sur des fichiers de données HFSQL physiques d'un serveur

```wlangage
<Résultat> = HDésactiveTriggerServeur(<Connexion> , <Trigger> [, <Fichiers de données physiques HFSQL Client/Serveur>])
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion au serveur HFSQL. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Trigger>` *Chaîne de caractères*
> Nom du trigger à désactiver. Ce nom a été donné grâce à la fonction [HDécritTriggerServeur](1000017033.md).
`<Fichiers de données physiques HFSQL Client/Serveur>` *Chaîne de caractères optionnelle*
> Nom physique de un ou plusieurs fichiers de données HFSQL Client/Serveur associés à la connexion (par exemple "CLIENT.FIC").
> Pour indiquer plusieurs noms, séparez les noms de fichiers de données par une virgule (",").
> Si ce paramètre n'est pas précisé ou est égal à une chaîne vide (""), le trigger sera désactivé sur tous les fichiers de données de la base.
