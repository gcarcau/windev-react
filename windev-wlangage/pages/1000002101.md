# Information 2101 : 'Entier court' n'existe plus : utilisez 'entier sans signe sur 1 octet'

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

## Cause

Vous utilisez un ***entier court***. Ce type de données n'existe plus dans WINDEV.

## Correction

Remplacez le type Entier Court par le type ***Entier sans signe sur 1 octet***.

## Exemple

### Utilisation d'un entier court

**Code provoquant l'erreur**

```wlangage
MaDonnée est un entier court
```

**Correction proposée**

Utilisez le type Entier non signé sur un octet.

```wlangage
MaDonnée est un entier sans signe sur 1 octet
```
