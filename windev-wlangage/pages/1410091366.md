# Manipulation d'une fenêtre par son type

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Un fenêtre WINDEV ou WINDEV Mobile est un type de variable, manipulable par programmation.

## Syntaxe de déclaration

Pour manipuler une variable associée à une fenêtre, il est nécessaire de réaliser la déclaration suivante :

```wlangage
<Nom_variable_Fenêtre> est une Fenêtre <Nom de la fenêtre>
```

Exemple :

```wlangage
Ma_fen_exe est une Fenêtre FEN_Principale
```

**Avant l'ouverture de la fenêtre**, il est possible de définir :

- les options d'ouverture de la fenêtre (via la propriété [OptionsOuverture](1410091299.md)),
- les paramètres de la fenêtre (via la propriété **ParamètresOuverture**).

Tout accès à un autre élément de la fenêtre provoque une exception "La fenêtre n'a pas été ouverte".
La comparaison de la variable de la fenêtre à Null renvoie Vrai.
**Après l'ouverture de la fenêtre** (via les fonctions [Ouvre](3038035.md), [OuvreFille](3038021.md), [OuvreSoeur](3038045.md), etc), il devient possible de manipuler la fenêtre, mais également ses éléments (champs, procédures, variables, etc.).
La propriété **ParamètresOuverture** est vidée.
La comparaison de la variable de la fenêtre à Null renvoie Faux.

**A partir de la fermeture de la fenêtre** :

- les propriétés [OptionsOuverture](1410091299.md) et **ParamètresOuverture** permettent de préparer une nouvelle ouverture de la fenêtre.
- la propriété **ValeurRenvoyée** permet de récupérer la valeur renvoyée par la fenêtre

Tout accès à un autre élément de la fenêtre provoque une exception "La fenêtre n'a pas été ouverte".
La comparaison de la variable de la fenêtre à Null renvoie Vrai.
Remarque : A tout moment, la fonction [FenEtat](3038030.md) permet de connaître l'état de la fenêtre.

### Portée des variables
Les règles de portée des variables s'appliquent.
La fin de la portée de la variable ne provoque pas la fermeture de la fenêtre : la fenêtre est toujours utilisable par l'utilisateur ou par programmation, par son nom ou son alias.

### Syntaxe de déclaration simplifiée
Pour déclarer une variable de type fenêtre, il est également possible d'utiliser une syntaxe de déclaration simplifiée :

```wlangage
<Nom_variable_fenêtre> est une <Nom de la fenêtre>
```

Pour utiliser cette déclaration simplifiée :

1. Activez l'utilisation de la syntaxe simplifiée : sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description".
2. Dans l'onglet "Compilation", sélectionnez l'option "Autoriser la déclaration simplifiée des types Fenêtre".
3. Validez.

**Attention** : l'utilisation de la déclaration simplifiée peut avoir plusieurs conséquences. En effet, il existe un risque de conflit entre les variables correspondant aux fenêtres et les types WLangage.
Dans ce cas, si une variable de type Fenêtre a le même nom qu'un type de variable WLangage, le type WLangage doit être préfixé par "WL.".

## Propriétés OptionsOuverture et ParamètresOuverture

### Options d'ouverture de la fenêtre
En manipulant la variable associée à la fenêtre, il est possible de définir les options d'ouverture de la fenêtre grâce à la propriété [OptionsOuverture](1410091299.md). Cette propriété correspond à une variable de type [OptionsOuvertureFenêtre](1410091298.md).
Il est ainsi possible de définir les coordonnées de la fenêtre, sa taille, etc.

La syntaxe à utiliser est la suivante :

```wlangage
<Variable_Fenêtre>.OptionsOuverture.<Propriété> = <Valeur>
```

Exemple :

```wlangage
// Définition des options de la fenêtre pour son ouverture
Ma_fen_exe est une Fenêtre FEN_Principale
Ma_fen_exe.OptionsOuverture.X = 50
Ma_fen_exe.OptionsOuverture.Y = 100
Ma_fen_exe.OptionsOuverture.Animation = afRotationX + afMorphCylindre
// Ouverture de la fenêtre
Ma_fen_exe.Ouvre()
```

### Passage de paramètres à une fenêtre
En manipulant la variable associée à la fenêtre, il est possible d'indiquer la valeur des différents paramètres passés à la fenêtre grâce à la propriété [ParamètresOuverture](1410091044.md).
La syntaxe à utiliser est la suivante :

```wlangage
<Nom_variable_Fenêtre>.ParamètresOuverture.<Nom du paramètre> = <Valeur du paramètre>
```

Exemple :

1. Code de déclaration de la fenêtre à ouvrir :
  ```wlangage
  // -- Déclarations globales de FEN_Calendrier
  PROCÉDURE FEN_Calendrier(sDateSel)
  //  sDateSel : date à sélectionner
  ```
2. Code permettant d'ouvrir la fenêtre :
  ```wlangage
  Ma_fen_Calendrier est une Fenêtre FEN_Calendrier
  // Passage de paramètres
  Ma_fen_Calendrier.ParamètresOuverture.sDateSel = DateDuJour()
  // Ouverture de la fenêtre
  Ma_fen_Calendrier.Ouvre()
  ```

## Fonctions WLangage utilisables

Les variables de type Fenêtre peuvent être utilisées :

- par les fonctions permettant d'ouvrir une fenêtre :
  | [MDIOuvre](3052005.md) | Ouvre et active une fenêtre fille MDI. |
  | --- | --- |
  | [Ouvre](3038035.md) | Ouvre une fenêtre modale WINDEV. |
  | [OuvreAsynchrone](1410087804.md) | Ouvre une fenêtre dont le résultat sera récupéré via une procédure WLangage (appelée "callback"). |
  | [OuvreFenêtreMobile](1000021018.md) | Ouvre une fenêtre dans une application mobile. |
  | [OuvreFille](3038021.md) | Ouvre une fenêtre fille non modale. |
  | [OuvreSoeur](3038045.md) | Ouvre une fenêtre soeur non modale. |
- par la fonction [FenEtat](3038030.md).
- par les fonctions permettant de fermer une fenêtre :
  | [Ferme](3038018.md) | Ferme une fenêtre WINDEV (en renvoyant si nécessaire une valeur). |
  | --- | --- |
