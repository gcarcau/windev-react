# xmlSignatureInformationCléX509 (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Le type **xmlSignatureInformationCléX509** permet de définir les informations à mettre dans la partie **KeyInfo** de la signature XML. Il est ainsi possible d'ajouter les informations sur un certificat X509. Les caractéristiques de ce type de variable peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
MaSignature est un xmlSignature
Info est un xmlSignatureInformationCléX509
Info.AvecCertificat = Vrai
Ajoute(MaSignature.InformationClé, Info)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type xmlSignatureInformationCléX509
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **xmlSignatureInformationCléX509** :

| **Nom de la propriété** | **Type manipulé** | **Effet** |
| --- | --- | --- |
| AvecCertificat | Booléen | - Vrai : le certificat est ajouté dans la description de la signature, - Faux : le certificat n'est pas ajouté dans la description de la signature. |
| AvecEmetteur | Booléen | - Vrai : le nom de l'émetteur du certificat est ajouté dans la description de la signature, - Faux : le nom de l'émetteur du certificat n'est pas ajouté dans la description de la signature. |
| AvecNomSujet | Booléen | - Vrai : le nom du sujet du certificat est ajouté dans la description de la signature, - Faux : le nom du sujet du certificat n'est pas ajouté dans la description de la signature. |
