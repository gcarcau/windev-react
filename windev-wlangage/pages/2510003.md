# GDS : Historiser localement

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

L'historisation locale d'un élément permet de poser localement un point de sauvegarde de l'élément. Il sera ensuite possible de :

- revenir à ce point de sauvegarde.
- intégrer ou pas ce point de sauvegarde à la base de sources.

Lors d'une historisation locale, aucune donnée n'est réintégrée dans le GDS.

**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

**Remarque** : Si une politique de réintégration a été définie, l'historisation locale sera possible uniquement si l'élément historisé respecte cette politique. Pour plus de détails, consultez [Politique de réintégration](2038024.md).

## Historisation d'un élément

### Mise en place
Pour historiser localement un élément, sous le volet "GDS", dans le groupe "Elément en cours", déroulez "Réintégrer" puis cliquez sur "Historiser localement".
Lors de l'historisation locale, la fenêtre suivante est affichée :

Cette fenêtre propose différents onglets pour préciser des informations sur la réintégration :

- L'onglet "Tâches" permet d'indiquer que l'élément historisé correspond à l'exécution ou à la réalisation d'une tâche.
- L'onglet "Incidents" permet d'indiquer que l'élément réintégré corrige un incident.
- L'onglet "Commentaire" permet de saisir un commentaire sur la réintégration. Par exemple, vous pouvez indiquer que la fenêtre propose désormais une nouvelle option de menu.
  Le bouton "IA : Générer le commentaire" permet de générer automatiquement un commentaire à partir des modifications effectuées dans le code. Pour plus de détails, consultez [IA dans l'éditeur de code](9000219.md).

Cette fenêtre permet également de :

- Connaître les modifications effectuées sur l'élément (bouton "Mes Modifs").
- Visualiser les propriétés de l'élément (bouton "Propriétés").

### Récupérer une version historisée
Lorsqu'une historisation locale a été faite, il est possible de récupérer une version historisée localement de l'élément, via l'historique de l'élément.

1. Sous le volet "GDS", dans le groupe "Elément en cours", cliquez sur "Historique".
2. Dans la fenêtre qui s'affiche, il est possible de récupérer un des historiques de l'élément.

### Réintégrer un élément historisé localement dans le GDS
Un élément historisé localement peut ensuite être réintégré dans le GDS via le ruban : sous le volet "GDS", dans le groupe "Elément en cours", cliquez sur "Réintégrer".
Dans ce cas, la fenêtre de réintégration indique le nombre de versions locales et propose l'option "Aplatir les versions locales". Si cette option est cochée, le détail des versions locales ne sera pas affiché et sauvegardé dans l'historique de l'élément réintégré dans le GDS.
