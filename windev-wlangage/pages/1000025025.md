# <Source>.MiseAJourLiaison (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Met à jour sur le serveur l'ensemble des liaisons impliquant un fichier de données HFSQL Client/Serveur.
Remarque : L'ensemble des fichiers de données impliqués dans les liaisons doit avoir été configuré par la fonction [<Source>.ChangeRep](1000024202.md) si besoin.

Nouveauté Abonnement

> _(Android)_ Cette fonction est désormais disponible pour les applications Android.

> _(Widget Android)_ Cette fonction est désormais disponible en mode Widget Android.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
// Met à jour les liaisons du fichier de données Client
Client.MiseAJourLiaison()
```

## Syntaxe

```wlangage
<Résultat> = <Source>.MiseAJourLiaison([<Option>])
```

`<Résultat>` *Booléen*
> - Vrai si la mise à jour a été effectuée,
> - Faux en cas d'erreur.
`<Source>` *Type correspondant à la source spécifiée*
> Nom du fichier de données permettant de connaître la liste des liaisons considérées.
`<Option>` *Constante ou combinaison de constantes optionnelle*
> Options de la modification automatique des données :
>
> | *hmsNormal*  (Valeur par défaut) | Fonctionnement par défaut de la modification automatique des données. |
> | --- | --- |
> | *hmsSansContrôle* | La modification automatique des données est effectuée même si :  - la description du fichier de données est plus récente que celle de l'analyse, - le GUID de l'analyse et le GUID du fichier de données sont différents. |
>
>
> **Remarque** : Les fichiers de données manipulés ne doivent pas être ouverts (par l'application ou par une autre application).

## Remarques

- Les rubriques utilisées par les liaisons doivent exister.
- Tous les fichiers de l'analyse doivent exister si vous utilisez le paraméttre "*"
- Lors de la mise à jour, les liaisons supprimées dans l'analyse sont supprimées sur le serveur HFSQL.
- Il est possible d'utiliser la fonction [<Source>.ModifieStructure](1000025039.md) avant d'utiliser la fonction **<Source>.MiseAJourLiaison**.
