# Constantes de gestion des rendez-vous

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

| Constante | Description | Utilisée par la fonction |
| --- | --- | --- |
| **rappelDéfaut** | Méthode à utiliser pour effectuer le rappel : méthode par défaut. Cette méthode varie en fonction du paramétrage de l'appareil. | Type [Rappel](1000020688.md) |
| **rappelEmail** | Méthode à utiliser pour effectuer le rappel : envoi d'un email. Ce type de rappel est disponible uniquement si le compte associé au calendrier du rendez-vous supporte ce type de rappel et si ce compte est configuré. | Type [Rappel](1000020688.md) |
| **rappelNotification** | Méthode à utiliser pour effectuer le rappel : envoi d'une notification. | Type [Rappel](1000020688.md) |
| **rappelSMS** | Méthode à utiliser pour effectuer le rappel : envoi d'un SMS. Ce type de rappel est disponible uniquement si le compte associé au calendrier du rendez-vous supporte ce type de rappel et si ce compte est configuré. | Type [Rappel](1000020688.md) |
| Nouveauté 2025 **rdvAnnulation** | Etat du rendez-vous créé : La création du rendez-vous a été annulée. Utilisé dans la syntaxe de création d'un rendez-vous asynchrone. | [RendezVousCrée](1000020691.md) |
| **rdvContenu** | Filtre sur les rendez-vous : Filtre sur la description du rendez-vous (recherche de type contient). | [RendezvousListe](1000020690.md) |
| Nouveauté 2025 **rdvÉchec** | Etat du rendez-vous créé : La création du rendez-vous est en échec.  Utilisé dans la syntaxe de création d'un rendez-vous asynchrone. | [RendezVousCrée](1000020691.md) |
| **rdvIdentifiant** | Filtre sur les rendez-vous : Filtre sur les identifiants de rendez-vous (recherche à l'identique). | [RendezvousListe](1000020690.md) |
| **rdvLieu** | Filtre sur les rendez-vous : Filtre sur le lieu du rendez-vous (recherche de type contient). | [RendezvousListe](1000020690.md) |
| Nouveauté 2025 **rdvSuccès** | Etat du rendez-vous créé : Le rendez-vous a bien été créé. Utilisé dans la syntaxe de création d'un rendez-vous asynchrone. | [RendezVousCrée](1000020691.md) |
| **rdvTitre** | Filtre sur les rendez-vous : Filtre sur le titre du rendez-vous (recherche de type contient). | [RendezvousListe](1000020690.md) |
