# <Variable EmailSessionNotes>.OuvreSession (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **Autres** (Procédures stockées)

Ouvre une session d'emails vers un serveur Lotus Domino afin de manipuler les messages.
**Remarque** :

> _(WINDEV, WEBDEV - Code Serveur)_ Pour ouvrir une session avec le logiciel de messagerie Lotus Notes, utilisez la fonction EmailOuvreSessionNotes.

## Exemple

```wlangage
// Ouvre une session d'emails
MaSessionNotes est une emailSessionNotes
SI MaSessionNotes.OuvreSession() = Vrai ALORS
	// Connecté
SINON
	NomUser = ""
	Erreur("Impossible d'établir la connexion")
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Session>.OuvreSession()
```

`<Résultat>` *Booléen*
> - Vrai si la session a été ouverte,
> - Faux dans le cas contraire. En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai.
>   Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Session>` *Variable de type emailSessionNotes*
> Nom de la variable de type [emailSessionNotes](1000018768.md) correspondant à la session d'emails à manipuler.
