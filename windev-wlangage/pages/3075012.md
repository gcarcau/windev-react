# TableauOccurrence (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Renvoie :

- soit le nombre d'éléments présents dans un tableau à une dimension.
- soit le nombre de lignes présentes dans un tableau à deux dimensions.
- soit le nombre d'éléments présents dans la première dimension d'un tableau à trois dimensions ou plus.

**Remarque** : Cette fonction est utilisable uniquement sur les [tableaux WLangage](1514030.md).

## Exemple

```wlangage
MonTableau est un tableau de 2 chaînes
TableauInsère(MonTableau, 1, "WINDEV")
TableauInsère(MonTableau, 2, "WEBDEV")
TableauInsère(MonTableau, 3, "WINDEV et WEBDEV")
// Nombre d'éléments ?
Trace(TableauOccurrence(MonTableau)) // Affiche 5
```

```wlangage
MonTableau est un tableau de 2 par 3 chaînes
TableauInsèreLigne(MonTableau, 1, "A", "B", "C")
TableauInsèreLigne(MonTableau, 2, "D", "E", "F")
// Nombre de lignes ?
Trace(TableauOccurrence(MonTableau)) // Affiche 4
```

## Syntaxe

```wlangage
<Résultat> = TableauOccurrence(<Tableau WLangage>)
```

`<Résultat>` *Entier*
> - Nombre d'éléments présents dans le tableau si <Tableau WLangage> est un tableau à une dimension.
> - Nombre de lignes présentes dans le tableau si <Tableau WLangage> est un tableau à deux dimensions.
> - Nombre d'éléments présents dans la première dimension du tableau si <Tableau WLangage> est un tableau à trois dimensions ou plus.
`<Tableau WLangage>` *Tableau*
> Nom de la variable de type Tableau à manipuler.
