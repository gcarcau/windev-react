# <Kanban>.DéplaceListe (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Déplace une liste de Kanban dans un champ Kanban.

## Exemple

```wlangage
// Déplace la liste LISTE_A_VOIR vers la position 2
KANBAN_Planning.DéplaceListe(LISTE_A_VOIR.IndiceListe(), 2)
```

## Syntaxe

```wlangage
<Champ Kanban>.DéplaceListe(<Position avant déplacement> , <Position après déplacement>)
```

`<Champ Kanban>` *Nom de champ*
> Nom du champ Kanban manipulé.
`<Position avant déplacement>` *Entier*
> Position de la liste de Kanban avant déplacement. Cette position peut être connue avec la fonction [<Liste de Kanban>.IndiceListe](1410089485.md).
`<Position après déplacement>` *Entier*
> Nouvelle position de la liste de Kanban.
>
> - Si cette position est inférieure ou égale à 1, la liste de Kanban est déplacée en première position.
> - Si cette position est supérieure ou égale au nombre de listes de Kanban dans le champ, la liste de Kanban est déplacée en dernière position.
> - Si <Position avant déplacement> = <Position après déplacement>, aucun déplacement n'est effectué.
