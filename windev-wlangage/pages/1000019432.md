# ImageDernier (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

Affiche la dernière image du défilement.

## Exemple

```wlangage
// Affiche la dernière bannièreImageDernier(IMG_Bannière)
```

## Syntaxe

```wlangage
ImageDernier(<Champ Image>)
```

`<Champ Image>` *Nom de champ*
> Nom du champ à manipuler :
>
> - Champ Image.
> - Champ Image cliquable.
> - Champ Vignette.

## Remarques

### Gestion des effets de transition
Si des effets de transition ont été spécifiés lors de la description du champ :

- Ces effets de transition sont pris en compte lors de l'utilisation de la fonction **ImageDernier**.
- Ces effets de transition ne sont pas pris en compte lors de l'utilisation de la fonction **ImageDernier**. En effet, la page est totalement rafraîchie. Pour prendre en compte ces effets, il suffit d'utiliser un code en mode Ajax.

**Composante : wd300page.dll**
