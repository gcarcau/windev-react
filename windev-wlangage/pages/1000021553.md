# EmailDétruit (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Détruit tous les emails marqués comme supprimés (état "Deleted") du dossier courant d'une session IMAP.

## Exemple

```wlangage
cMaSession est une emailSessionIMAP
...
SI EmailOuvreSession(cMaSession) ALORS
	cMonEmail est un Email
	EmailLitPremier(cMaSession, cMonEmail)
	TANTQUE PAS cMonEmail..EnDehors
		EmailSupprimeMessage(cMaSession, cMonEmail)
		EmailLitSuivant(cMaSession, cMonEmail)
	FIN
	// Détruit les emails supprimés
	EmailDétruit(cMaSession)
	EmailFermeSession(cMaSession)
FIN
```

## Syntaxe

```wlangage
<Résultat> = EmailDétruit(<Session>)
```

`<Résultat>` *Booléen*
> - Vrai si la destruction a été effectuée,
> - Faux dans le cas contraire.
`<Session>` *Variable de type emailSessionIMAP*
> Nom de la variable de type [emailSessionIMAP](1000018957.md) correspondant à la session sur laquelle les messages doivent être détruits.

**Composante : wd300com.dll**
