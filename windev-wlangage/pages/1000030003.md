# Propriétés associées au champ Diagramme de Gantt

> **Disponible :** **WINDEV** (Windows)

## Présentation

Dans un champ Table ou Table hiérarchique, une colonne de type "Diagramme de Gantt" peut être manipulée en WLangage dans une fenêtre avec les propriétés suivantes.
Remarque : Ces propriétés sont identiques à celles utilisées sur une colonne d'un champ Table ou une colonne d'un champ Table hiérarchique.

Il est également possible d'utiliser des propriétés WLangage sur les Diagrammes de Gantt présents dans un état.
