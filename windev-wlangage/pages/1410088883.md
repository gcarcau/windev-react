# FichierDisque (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Le type **FichierDisque** permet de manipuler un fichier texte présent sur disque. Les caractéristiques de ce fichier peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage

// Ecriture dans un fichier texte
MonFichier est un FichierDisque = fOuvre("Fichier.txt")
MonFichier.Ecrit("Compte-rendu")
```

## Propriétés

### Propriétés spécifiques à la description des variables de type **FichierDisque**
Les propriétés suivantes peuvent être utilisées pour manipuler un fichier texte :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| DateCréation | DateHeure | Date et heure de création du fichier. _(Linux, iPhone/iPad, Widget IOS, Mac Catalyst)_ Cette propriété est disponible en lecture seulement. _(Android, Widget Android, Java)_ Cette propriété est disponible à partir de Android 8 uniquement. Dans les versions précédentes, la lecture de cette propriété renverra une chaîne vide. |
| DateDernierAccès | DateHeure | Date et heure du dernier accès au fichier. _(Android, Widget Android, Java)_ Cette propriété est disponible à partir de Android 8 uniquement. Dans les versions précédentes, la lecture de cette propriété renverra une chaîne vide et son écriture sera sans effet. |
| DateModification | DateHeure | Date et heure de dernière modification du fichier. _(Android, Widget Android, Java)_ Cette propriété est disponible à partir de Android 8 uniquement. Dans les versions précédentes, la lecture de cette propriété renverra une chaîne vide et son écriture sera sans effet. |
| Handle | Entier système | - Handle système du fichier, - -1 si pas de fichier associé.  **Cette propriété est disponible en lecture seulement**. _(Android, Widget Android, Java)_ Cette propriété n'est pas disponible. |

Remarque : Le fichier associé à une variable de type **FichierDisque** est automatiquement fermé à la fin de la portée de la dernière variable associée au fichier.

> _(Android, Widget Android, Java)_ Le fichier associé à une variable de type FichierDisque est automatiquement fermé lorsque la dernière variable pointant sur le fichier sera éligible à la libération par le système Android.
