# <Variable btlePériphérique>.RécupèreTousServices (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Récupère tous les services d'un périphérique Bluetooth Low Energy correspondant à un identifiant (UUID).

## Exemple

```wlangage
MonPériph est un btlePériphérique
...
tabService est un tableau de btleService
tabService = MonPériph.RécupèreTousServices("ACC54-DAD4D5-DADD")
POUR TOUT ÉLÉMENT service DE tabService
	...
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Périphérique>.RécupèreTousServices(<Identifiant>)
```

`<Résultat>` *Tableau de variables de type btleService*
> Tableau de variables de type [btleService](1000022057.md) correspondant aux services trouvés. Si aucun service ne correspond à l'identifiant spécifié, le tableau retourné sera vide.
`<Périphérique>` *Variable de type btlePériphérique*
> Nom de la variable de type [btlePériphérique](1000022054.md) correspondant au périphérique Bluetooth manipulé.
`<Identifiant>` *Chaîne de caractères*
> Identifiant (UUID) des services à récupérer.

## Remarques

Plusieurs services d'un même périphérique Bluetooth peuvent correspondre au même identifiant (UUID). Pour récupérer uniquement le premier service correspondant à un identifiant, utilisez la fonction [<Variable btlePériphérique>.RécupèreUnService](1000022222.md).
