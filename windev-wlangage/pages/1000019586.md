# <Variable File>.Enfile (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Enfile un élément dans une file. L'élément est ajouté à la fin de la file.
Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.

## Exemple

```wlangage
MaFile est une File d'entiers

// On enfile les valeurs 1, 2 et 3
MaFile.Enfile(1)
MaFile.Enfile(2)
MaFile.Enfile(3)

// Affichage de la trace : 1, 2, 3
x est un entier
TANTQUE MaFile.Défile(x)
	Trace(x)
FIN
```

## Syntaxe

```wlangage
<File>.Enfile(<Valeur>)
```

`<File>` *Variable de type File*
> Nom de la variable de type [File](1514021.md) à manipuler.
`<Valeur>` *Type d'éléments manipulés par la file*
> Valeur à ajouter à la fin de la file. Tous les types de variables peuvent être utilisés SAUF les tableaux, les tableaux associatifs, les files, les piles et les listes.

## Remarques

### Gestion du multithread
Si la propriété [AjoutTerminé](1000018388.md) vaut Vrai, la fonction **<Variable File>.Enfile** échoue et provoque une erreur WLangage.
> _(WEBDEV - Code Navigateur)_ La gestion du multithread n'est pas disponible.

**Composante : wd300vm.dll**
