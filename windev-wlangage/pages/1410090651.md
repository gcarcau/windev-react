# PartageProximitéRefuseConnexion (Fonction)

> **Disponible :** **WINDEV Mobile** (Android)

Refuse la demande de connexion d'un appareil distant.

## Exemple

```wlangage
// Bouton permettant de refuser la connexion
PartageProximitéRefuseConnexion(gsIdAppareil)
Ferme()
```

## Syntaxe

```wlangage
PartageProximitéRefuseConnexion(<Identifiant de l'appareil>)
```

`<Identifiant de l'appareil>` *Chaîne de caractères*
> Identifiant de l'appareil distant pour lequel la connexion doit être refusée.
