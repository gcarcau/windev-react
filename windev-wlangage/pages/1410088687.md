# <Éditeur de diagrammes>.Sauve (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Sauve un diagramme dans un fichier "diag".

## Exemple

```wlangage
EDIAG_MonDiagramme.Sauve("diagramme1.wddiag")
SI ErreurDétectée ALORS
	Erreur("Fichier non sauvegardé : " + ErreurInfo())
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Editeur de diagrammes>.Sauve(<Fichier>)
```

`<Résultat>` *Booléen*
> - Vrai si la sauvegarde a été effectuée,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de détails sur l'erreur.
`<Editeur de diagrammes>` *Nom de champ*
> Nom du champ Editeur de diagrammes à manipuler.
`<Fichier>` *Chaîne de caractères*
> Chemin complet du fichier "diag".

**Composante : wd300mdl.dll**
