# PoliceCrée (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Crée une définition de police. Cette police pourra être utilisée :

- pour écrire du texte dans des dessins (fonction [dPolice](3029020.md)).
- pour sélectionner la police utilisée dans les graphes (fonctions [grPoliceEtiquette](3042012.md), [grPoliceLégende](3042037.md), [grPoliceTitre](3042048.md), [grPoliceTitreAxe](3042059.md)).
- pour sélectionner une police d'impression (fonction [iPolice](3046014.md)).
- pour définir la police utilisée dans les champs d'une fenêtre, d'une page ou d'un état (propriété [Police](2515045.md)).

## Exemple

```wlangage
// Création d'une police
MaPolice est une Police
MaPolice = PoliceCrée("Arial", 12, iGras, JauneClair)
// Utilisation de cette police dans le champ "NomClient"
NomClient.Police = MaPolice
```

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Windows, Code Utilisateur (MCU), Ajax)_ // Création d'une police normale
PNormal est une Police = PoliceCrée("Arial", 12)
// Création d'une police en gras
PGras est une Police = PoliceCrée("Arial", 12, iGras)
// Préparation de l'impression
iDestination(iPDF)
// Parcours d'un tableau
i est un entier
POUR i = 1 À 100
 // Utilisation de la police normale pour les 50 premiers éléments du tableau
 SI i<=50 ALORS
 iPolice(PNormal)
 SINON
 // Utilisation de la police en gras pour les 50 derniers éléments du tableau
 iPolice(PGras)
 FIN
FIN
// Lancement de l'impression
iFinImprime()

## Syntaxe

```wlangage
<Résultat> = PoliceCrée(<Nom de la police> [, <Taille> [, <Style> [, <Couleur> [, <Angle>]]]])
```

`<Résultat>` *Variable de type Police*
> Variable de type [Police](1514045.md) pouvant être utilisée dans les différentes fonctions de dessin, de graphe ou d'impression utilisant une police.
`<Nom de la police>` *Chaîne de caractères*
> Nom de la police utilisée. Ce nom doit correspondre à une des polices installées sur le poste en cours.
`<Taille>` *Entier optionnel*
> Taille de la police exprimée en points pica (1 point Pica = 0,353 mm). Par défaut, la taille de la police est 12.
`<Style>` *Constante ou combinaison de constantes optionnelle de type entier*
> Attributs de la police :
>
> | *iBarre* | Police barrée |
> | --- | --- |
> | *iCondense* | Caractères condensés |
> | *iEtendu* | Caractères étendus |
> | *iGras* | Police en gras |
> | *iItalique* | Police italique |
> | *iLarge* | Caractères larges |
> | *iNormal* (valeur par défaut) | Police normale, sans attributs |
> | *iSouligné* | Police soulignée |
`<Couleur>` *Entier optionnel*
> Couleur utilisée pour la police. Si ce paramètre n'est pas précisé, la couleur utilisée est le noir.
> Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)).
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - une [couleur prédéfinie dans le WLangage](3010002.md).
`<Angle>` *Entier optionnel*
> Angle (en degrés) selon lequel le texte sera imprimé. L'angle est calculé à partir d'une ligne horizontale, dans le sens inverse des aiguilles d'une montre (sens trigonométrique).

## Remarques

### Différences entre la fonction PoliceCrée et la fonction iCréePolice
La fonction **PoliceCrée** permet de créer une définition de police utilisable dans tous les éléments d'une application WINDEV ou WEBDEV. Cette police est mémorisée grâce au type de [variable Police](1514045.md) et pourra être utilisée :

- pour écrire du texte dans des dessins (fonction [dPolice](3029020.md)).
- pour sélectionner la police utilisée dans les graphes (fonctions [grPoliceEtiquette](3042012.md), [grPoliceLégende](3042037.md), [grPoliceTitre](3042048.md), [grPoliceTitreAxe](3042059.md)).
- pour sélectionner une police d'impression (fonction [iPolice](3046014.md)).
- pour définir la police utilisée dans les champs d'une fenêtre (propriété [Police](2515045.md) des champs d'une fenêtre).
- pour définir la police utilisée dans les champs d'une page (propriété [Police](2515045.md) des champs d'une page).
- pour définir la police utilisée dans les champs d'un état (propriété [Police](2515045.md) des champs d'un état).

La fonction [iCréePolice](3046045.md) permet uniquement de créer une police utilisable par les fonctions d'impression.
