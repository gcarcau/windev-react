# <Tableau croisé dynamique>.ValeurEntête (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Renvoie la valeur affichée dans un entête du champ Tableau croisé dynamique.
Nouveauté Abonnement

> _(WEBDEV - Code Serveur, Linux)_ Cette fonction est désormais disponible pour les sites WEBDEV sous Windows et sous Linux.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
i est entier = 1
s est chaîne = TCD_Stat.ValeurEntête("DTCD_Famille", i)
TANTQUE s <> ""
	Trace(s)
	s = TCD_Stat.ValeurEntête("DTCD_Famille", i)
	i++
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Champ Tableau croisé dynamique>.ValeurEntête(<Entête> , <Indice>)
```

`<Résultat>` *Chaîne de caractères*
> - Valeur de l'entête spécifié.
> - Chaîne vide ("") si l'indice spécifié est invalide.
`<Champ Tableau croisé dynamique>` *Nom de champ*
> Nom du champ Tableau croisé dynamique à manipuler
`<Entête>` *Chaîne de caractères*
> Nom d'un entête du champ Tableau croisé dynamique.
`<Indice>` *Entier*
> Indice de la valeur à récupérer.
