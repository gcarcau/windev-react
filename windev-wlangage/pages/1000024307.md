# <Tableau>.EchangeLigne (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Permet d'échanger deux lignes dans un tableau à deux dimensions ou dans une propriété tableau d'un type avancé.

## Exemple

```wlangage
MonTableau est un tableau de 5 par 2 chaînes
MonTableau[1,1] =  "A"
MonTableau[1,2] =  "a"
MonTableau[2,1] =  "B"
MonTableau[2,2] =  "b"
MonTableau[3,1] =  "C"
MonTableau[3,2] =  "c"
MonTableau[4,1] =  "D"
MonTableau[4,2] =  "d"
MonTableau[5,1] =  "E"
MonTableau[5,2] =  "e"
// Échanger la ligne 2 avec la ligne 4
MonTableau.EchangeLigne(2, 4)
// Le tableau contient les éléments :
// "A", "a"
// "D", "d"
// "C", "c"
// "B", "b"
// "E", "e"
```

## Syntaxe

```wlangage
<Tableau WLangage>.EchangeLigne(<Indice de la 1ère ligne> , <Indice de la 2ème ligne>)
```

`<Tableau WLangage>` *Tableau*
> Nom de la variable de type Tableau à manipuler. Ce tableau doit être un tableau à deux dimensions.
`<Indice de la 1ère ligne>` *Entier*
> Indice de la première ligne à échanger.
`<Indice de la 2ème ligne>` *Entier*
> Indice de la seconde ligne à échanger.
