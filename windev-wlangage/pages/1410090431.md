# <Variable Notification>.Ajoute (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Ajoute une notification dans la barre système de l'appareil (Android) ou dans le centre de notification (iOS).
> _(Android)_ La notification est affichée dans la barre système et peut ensuite être déroulée pour voir son détail. La notification peut contenir des actions spécifiques, affichées sous forme de texte cliquable en dessous du message de la notification.La mise en place des notifications supplémentaires est réalisée via la propriété ActionSupplémentaire de la variable de type Notification. A partir d'Android 8.0 (Oreo, API level 26), toutes les notifications créées par une application Android doivent être associées à une catégorie de notification (connue également sous le nom de "channel"). Les catégories de notification sont définies par la propriété Catégorie des variables de type Notification.

> _(iPhone/iPad)_ La notification sera visible dans le centre de notification uniquement si l'application est en arrière-plan (par exemple, utilisation du suivi de position en arrière-plan avec la fonction géoSuiviActive).

## Exemple

```wlangage
notif est une Notification
notif.Titre = "Nouveau message reçu"
notif.Message = "Cliquez pour afficher le message"
notif.Ajoute()
```

## Syntaxe

```wlangage
<Résultat> = <Notification>.Ajoute()
```

`<Résultat>` *Booléen*
> - Vrai si la notification a été ajoutée,
> - Faux dans le cas contraire.
>
>
> **Remarque** : Dans le simulateur, cette fonction est sans effet et renvoie toujours Faux.
`<Notification>` *Variable de type Notification*
> Nom de la variable de type [Notification](1000019441.md) contenant la description de la notification à afficher.
> Si ce paramètre correspond à une notification déjà ajoutée, cette notification sera mise à jour. La fonction **<Variable Notification>.Ajoute** aura alors le même effet que la fonction [<Variable Notification>.Modifie](1410090432.md).
