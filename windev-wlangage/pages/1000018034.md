# Modifié (Propriété)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (iPhone/iPad)

La propriété **Modifié** permet de savoir si un élément a été modifié. Cette propriété est utilisable sur :

- les champs d'une fenêtre. Pour plus de détails, consultez [Modifié sur les champs d'une fenêtre](2510080.md).
- une variable de type [xlsDocument](1000017464.md).
- une variable de type [Document](1000022461.md).
