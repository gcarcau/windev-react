# awProcédureRéceptionInfo (Fonction)

> **Disponible :** **WINDEV Mobile** (iPhone/iPad, Apple Watch)

Précise la procédure WLangage appelée lors de la réception des informations provenant de la fonction [awEnvoieInfo](1000022117.md).

## Exemple

```wlangage
PROCÉDURE INTERNE RecoitDonnées(b est Buffer)
	Info(b)
FIN

awProcédureRéceptionInfo(RecoitDonnées)
```

## Syntaxe

```wlangage
awProcédureRéceptionInfo(<Procédure WLangage>)
```

`<Procédure WLangage>` *Nom de procédure*
> Nom de procédure WLangage (également nommée "callback") appelée lors de la réception des informations provenant de la fonction [awEnvoieInfo](1000022117.md).
> Cette procédure est de la forme :
>
>
> ```wlangage
> PROCEDURE <Nom de la procédure>(<Réponse>)
> ```
>
>
>
> où <Réponse> est une variable de type Buffer.

## Remarques

**Conseil** : Appelez cette fonction dans le code d'initialisation du projet pour que la procédure soit accessible dès le démarrage de l'application.
