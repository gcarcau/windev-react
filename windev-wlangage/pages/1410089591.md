# Emetteur (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Emetteur** permet de connaître et de modifier l'émetteur d'un certificat ou d'une authentification. Cette propriété est utilisable sur :

- une variable de type [Certificat](1000019287.md).
- une variable de type [JWTParamètres](1410089572.md).
