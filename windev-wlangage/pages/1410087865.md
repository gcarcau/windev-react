# Zoom (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Zoom** permet de connaître et de modifier le zoom appliqué à un élément. Cette propriété est utilisable sur :

- un champ ou une fenêtre. Pour plus de détails, consultez [Zoom](1000017201.md).
- une variable de type [pdfParamètre](1410087857.md).
