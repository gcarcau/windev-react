# Liste,Occurrence (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Renvoie le nombre d'éléments d'une liste.

## Exemple

```wlangage
// En CAPPELWD("Liste,Occurrence,ListeProd");NbElem=WDEntier;
```

```wlangage
// En PascalAPPELWD('Liste,Occurrence,ListeProd');NbElem:=WdEntier;
```

```wlangage
// En VBcall APPELWD("Liste,Occurrence,ListeProd")NbElem=WdEntier
```

## Syntaxe

```wlangage
Liste,Occurrence(<Nom de la liste>)
```

`<Nom de la liste>` *Chaîne de caractères*
> Nom du champ Liste à manipuler.

## Remarques

WdEntier contient le nombre d'éléments de la liste.
