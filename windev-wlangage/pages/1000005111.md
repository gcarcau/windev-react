# NotesFermeBase (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **Autres** (Procédures stockées)

Ferme la base locale ou distante Lotus Notes ou Domino utilisée. Cette base a été préalablement ouverte à l'aide de la fonction [NotesOuvreBase](1000005101.md).
**Remarque** : Cette base sera automatiquement fermée à la fin du programme WINDEV ou de la session WEBDEV.

## Exemple

```wlangage
// Ouverture de la session
IDSession est un entier
IDSession = NotesOuvreConnexion("MotDePasse", "ServeurMars", ...
		"C:\Users\Julie\AppData\Local\Lotus\Notes\Data\user.id")
// Ouverture de la base
SI NotesOuvreBase(IDSession, "mail/julie.nsf") <> 0 ALORS
	Info("Session ouverte et base spécifiée")
SINON
	Erreur(ErreurInfo())
FIN
...
// Fermeture de la base
NotesFermeBase(IDSession)
```

## Syntaxe

```wlangage
<Résultat> = NotesFermeBase(<Identifiant de la session>)
```

`<Résultat>` *Booléen*
> - Vrai si la base Lotus Notes a été fermée,
> - Faux en cas d'erreur. Pour obtenir le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Identifiant de la session>` *Chaîne de caractères*
> Identifiant de la session à manipuler. Cet identifiant est retourné par la fonction [NotesOuvreConnexion](1000005102.md).

**Composante : wd300com.dll**
