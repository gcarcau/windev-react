# <Carte>.AjouteImage (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Ajoute une nouvelle image sur la carte affichée dans un champ Carte.

## Exemple

```wlangage
// Ajout d'une image dans le champ Carte
ImageSurCarte est un CarteImage
ImageSurCarte.Position = MaPosition
ImageSurCarte.Image = "image.png"
ImageSurCarte.ActionClic = ProcClic
CARTE_MaCarte.AjouteImage(ImageSurCarte)
```

## Syntaxe

```wlangage
<Résultat> = <Champ Carte>.AjouteImage(<Image>)
```

`<Résultat>` *Booléen*
> - Vrai si l'image a pu être ajoutée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler.
`<Image>` *Variable de type CarteImage*
> Nom de la variable de type [CarteImage](1000025523.md) correspondant à l'image à ajouter.

## Remarques

- Si l'image a été déjà été ajoutée dans le champ Carte ou si l'image est invalide (ex : largeur non spécifiée), une erreur fatale sera affichée.
- Pour supprimer une image dessinée dans un champ Carte, utilisez la fonction [<Carte>.SupprimeImage](1000025829.md).
- Pour modifier une image dessinée dans un champ Carte, utilisez la fonction [<Carte>.ModifieImage](1000025818.md).
