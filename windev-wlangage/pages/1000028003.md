# Propriétés associées au champ Réseau social

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

## Présentation

Un champ Réseau social peut être manipulé en WLangage dans une page avec les propriétés suivantes.

## Propriétés disponibles dans une page

> _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur)_ Propriétés disponibles dans une page (code serveur)Les différentes propriétés associées aux champs Réseau social sont les suivantes :
AliasLa propriété Alias permet de : connaître ou de modifier l'alias d'une fenêtre (WINDEV et WINDEV Mobile).connaître ou de modifier l'alias d'un volet d'onglet dynamique (WINDEV).connaître le nom interne HTML / Javascript d'un champ (WEBDEV).ExtraLa propriété Extra permet de :Connaître les informations supplémentaires associées à un champ, à une fenêtre, ou à une page.Modifier les informations supplémentaires associées à un champ, à une fenêtre ou à une page. En code navigateur, il est uniquement possible de connaître les informations supplémentaires associées à un champ ou une page.GroupeLa propriété Groupe permet de : savoir si le champ appartient ou non à un groupe de champs. Si le champ appartient à un ou plusieurs groupes, la propriété Groupe permet d'identifier ces groupes de champs.associer un champ à un groupe de champs. HTMLAprèsLa propriété HTMLAprès permet de connaître et de modifier le code HTML ajouté après le champ.HTMLAvantLa propriété HTMLAvant permet de connaître et de modifier le code HTML ajouté avant le champ.ImageLa propriété Image permet de connaître et de modifier l'image de fond d'un champ ou d'un bloc.NomLa propriété Nom permet de connaître :le nom de la police associée à une variable de type Police.le nom d'un champ, d'un état ou d'un bloc d'un état.le nom d'un champ, d'un groupe de champs ou d'une fenêtre.le nom d'un champ, d'un groupe de champs ou d'une page.NomCompletLa propriété NomComplet permet de connaître le nom complet :d'un champ.d'une fenêtre.d'une option de menu.d'une colonne de table.NoteLa propriété Note permet de :Connaître les notes associées à un champ, à une fenêtre, à une page ou un état.Modifier les notes associées à un champ, à une fenêtre, à une page ou un état.TitreNoteLa propriété TitreNote permet de :Connaître le titre des notes utilisé pour la documentation technique d'un champ, d'une fenêtre, d'une page ou d'un état. Modifier le titre des notes utilisé pour la documentation technique d'un champ, d'une fenêtre, d'une page ou d'un état.TraitementLa propriété Traitement permet de modifier les traitements à exécuter par les événements disponibles sur un champ, une fenêtre, une page, un état, ...TypeLa propriété Type permet de connaître :le type d'un élément décrit par programmation (description de rubrique ou de fichier) ou non (fichier ou rubrique défini sous l'éditeur d'analyses, vue ou requête).le type d'un objet.le type de la valeur stockée dans un variant.ValeurLa propriété Valeur permet de :Connaître et modifier la valeur d'un champ d'un état.Connaître et modifier la valeur d'un champ ou le titre d'une fenêtre.Connaître l'identifiant d'un flux. Connaître et modifier la valeur d'un champ ou le titre d'une page.ValeurInitialeLa propriété ValeurInitiale permet de connaître la valeur initiale d'un champ d'une fenêtre ou d'une page.VisibleLa propriété Visible permet de :Savoir si un élément est visible.Rendre un élément visible ou invisible.VisibleInitialLa propriété VisibleInitial permet de savoir si :un champ était visible lors du premier affichage de la fenêtre ou la page associée.une fenêtre était visible lors de son premier affichage.XLa propriété X permet de :Connaître l'abscisse d'un champ, d'une colonne d'un champ Table ou d'une fenêtre (position sur l'axe des X).Modifier l'abscisse d'un champ ou d'une fenêtre (position sur l'axe des X).XInitialLa propriété XInitial permet de :Connaître l'abscisse : d'un champ (position sur l'axe des X) lors de l'ouverture de la fenêtre ou de la page.d'une fenêtre (position sur l'axe des X) lors de l'ouverture de la fenêtre. Modifier l'abscisse d'un champ ancré "à droite" (position sur l'axe des X) lors de l'ouverture de la fenêtre.Connaître l'abscisse d'un champ par rapport à son bloc (position en millimètres sur l'axe des X) lors de l'ouverture de l'état.YLa propriété Y permet de :Connaître l'ordonnée d'un champ ou d'une fenêtre (position sur l'axe des Y).Modifier l'ordonnée d'un champ ou d'une fenêtre (position sur l'axe des Y).YInitialLa propriété YInitial permet de :Connaître l'ordonnée : d'un champ (position sur l'axe des Y) lors de l'ouverture de la fenêtre ou de la page.d'une fenêtre (position sur l'axe des Y) lors de l'ouverture de la fenêtre.Modifier l'ordonnée d'un champ ancré "en bas" (position sur l'axe des Y) lors de l'ouverture de la fenêtre.Connaître l'ordonnée d'un champ par rapport à son bloc (position en millimètres sur l'axe des Y) lors de l'ouverture de l'état.
