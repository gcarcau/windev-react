# JournéeEntière

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **JournéeEntière** permet de configurer un événement pour une durée d'une journée entière. Cette propriété est utilisable sur :

- une variable de type [gglEvénement](1000017440.md).
- une variable de type [RendezVous](1000019244.md).
