# AlgorithmeNormalisation (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **AlgorithmeNormalisation** permet de définir la méthode de standardisation du XML (C14N). Cette propriété est utilisable sur :

- une variable de type [xmlSignature](1000020736.md).
- Nouveauté Abonnement
  une variable de type [xmlSignatureXAdES](1410091158.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
