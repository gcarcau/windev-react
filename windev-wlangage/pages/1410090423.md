# Constantes de gestion des serveurs Bitcoin Core

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Les constantes de gestion des serveurs Bitcoin Core sont les suivantes :

| Constante | Détail | Fonction |
| --- | --- | --- |
| **btcRpcAdresseServeur** | Adresse du serveur Bitcoin Core. | [BitcoinCoreParamètre](1410090320.md) |
| **btcRpcLogin** | Login utilisateur de connexion au serveur Bitcoin Core. | [BitcoinCoreParamètre](1410090320.md) |
| **btcRpcMotDePasse** | Mot de passe utilisateur de connexion au serveur Bitcoin Core. | [BitcoinCoreParamètre](1410090320.md) |
| **btcRpcNuméroDePort** | Numéro de port de connexion au serveur Bitcoin Core. | [BitcoinCoreParamètre](1410090320.md) |
| **btcTimeout** | Timeout de connexion au serveur Bitcoin Core. | [BitcoinCoreParamètre](1410090320.md) |
