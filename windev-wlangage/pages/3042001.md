# grCréePolice (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

|  | **But** Créer une police pour les graphes.  **Syntaxe**  grCréePolice(<NumPolice>, <NbPixelsHauteur>, <Style>, <NomPoliceWindows [,<Couleur>])  <NumPolice est le numéro (entier) identifiant la police créée  <NbPixelsHauteur est un entier correspondant à la hauteur de la police en pixels.  <Style est l'attribut (ou style) de la police   - iNormal police normale (sans attribut) - iGras police en gras (attribut gras) - iSouligne police soulignée (attribut souligné) - iItalique police italique (attribut italique) - iBarre police barrée   <NomPoliceWindows est le nom de la police choisie (parmi celles installées sur le poste)  <Couleur est la couleur dans laquelle est affiché le texte. Cette couleur correspond à une [constante prédéfinie](3010002.md) (Noir par défaut)  **Détail**  Les polices créées avec **grCréePolice** sont automatiquement détruites à la fermeture de l'application.  La création d'une police avec un numéro de police existante écrase automatiquement l'ancienne police.  La couleur utilisée par défaut pour les polices est le noir (Noir).  **Notes**   - La fonction [grSupprimeTout](3042055.md) ne détruit pas les polices créées avec **grCréePolice**. - Une série ne doit pas être composée de plus de 8000 éléments. |
