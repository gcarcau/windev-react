# EnModeWebservice (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Permet de savoir si l'exécution est en cours dans le moteur AWWS.

## Exemple

```wlangage
// Code exécuté depuis un Webservice ?
SI EnModeWebservice() = Vrai ALORS
	// Traitements à effectuer
	...
SINON
	// Traitements à effectuer
	...
FIN
```

## Syntaxe

```wlangage
<Résultat> = EnModeWebservice()
```

`<Résultat>` *Booléen*
> - Vrai si le code est exécuté dans le moteur AWWS,
> - Faux dans tous les autres cas.
>
>
> > _(WEBDEV - Code Navigateur)_ Ce paramètre correspond toujours à Faux.

## Remarques

### Disponibilité de la fonction
La fonction **EnModeWebservice** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **EnModeWebservice** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
