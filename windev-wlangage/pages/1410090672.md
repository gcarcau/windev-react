# <AuthToken>.Révoque (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Révoque un token JWT.
Remarques :

- La révocation consiste à exécuter une requête afin d'invalider le token spécifié. A la prochaine connexion, le processus de connexion devra être entièrement refait.
- Lors de l'utilisation d'une variable de type [OAuth2Paramètres](1000022212.md), il est nécessaire de spécifier l'URL de révocation avec la propriété **URLRévocation**.

## Exemple

```wlangage
stOpenIdParam est un OpenIDParamètres
stOpenIdParam.URLConfiguration = "https://accounts.google.com/.well-known/openid-configuration"
stOpenIdParam.ClientID = "686331726510-0ojt7fqbkmtns8qjne242v5fuqb8v3tr.apps.googleusercontent.com"
stOpenIdParam.ClientSecret = "vEhFxP8I5AjppVFJsLYi0uKt"
stOpenIdParam.Scope = "email openid"
stOpenIdParam.URLRedirection = "http://localhost:9874"
stToken est un AuthToken = AuthIdentifie(stOpenIdParam)
SI ErreurDétectée ALORS
	Erreur(ErreurInfo(errComplet))
	RETOUR
FIN
identite est une OpenIDIdentité = stToken.OpenIDLitIdentité()
 SI ErreurDétectée ALORS
	Erreur(ErreurInfo(errComplet))
	RETOUR
FIN
Trace(identite.Email)
stToken.Révoque()
```

## Syntaxe

```wlangage
<Résultat> = <Token de connexion>.Révoque()
```

`<Résultat>` *Booléen*
> - Vrai si la déconnexion a été réalisée,
> - Faux dans le cas contraire.
`<Token de connexion>` *Variable de type AuthToken*
> Nom de la variable de type [AuthToken](1000022220.md) correspondant au token de la connexion.
