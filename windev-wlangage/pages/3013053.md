# WHelp (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Affiche un fichier ou une page d'aide au format CHM.

## Exemple

```wlangage
// Ouverture du "NotePad.hlp" sur la page de Couper/Coller
WHelp("C:\Windows\NotePad.hlp", "COLLAGE DE TEXTE")
```

## Syntaxe

#### Ouvrir un fichier d'aide

```wlangage
WHelp(<Nom du fichier d'aide> [, <Mot-clé>])
```

`<Nom du fichier d'aide>` *Chaîne de caractères*
> Nom et chemin du fichier d'aide (.HLP ou .CHM). Si le fichier d'aide n'est pas trouvé, la fonction ne fait rien.
`<Mot-clé>` *Chaîne de caractères optionnelle*
> Mot-clé permettant de rechercher la page d'aide.
> Si ce paramètre correspond à une chaîne vide ("") ou n'est pas spécifié, l'index du fichier d'aide est ouvert et l'utilisateur pourra sélectionner le mot-clé voulu. Si le fichier d'aide n'a pas d'index, le fichier est ouvert sur la première page de l'aide.

#### Afficher une page d'aide spécifique

```wlangage
WHelp(<Nom du fichier d'aide> , <Numéro de contexte>)
```

`<Nom du fichier d'aide>` *Chaîne de caractères*
> Nom et chemin du fichier d'aide (aide au format CHM). Si le fichier d'aide n'est pas trouvé, la fonction ne fait rien.
`<Numéro de contexte>` *Entier*
> Numéro de contexte associé à la page d'aide et au champ pour lequel la page doit s'afficher. Le numéro d'aide associé à un champ peut être connu avec la fonction [NumHelp](3013027.md).

#### Ouvrir l'aide sur l'aide au format HLP (WinHelp.hlp)- Syntaxe conservée par compatibilité

```wlangage
WHelp()
```

## Remarques

### Changement de langue et fichier d'aide
Sous l'éditeur d'aide de WINDEV, il est possible de construire le nom du fichier d'aide à partir d'un identifiant numérique correspondant à la fonction [Nation](3054014.md).
Dans ce cas, pour lancer le fichier d'aide correspondant à la langue en cours, il suffit d'utiliser le code suivant :

```wlangage
// Lancement de l'aide au format CHM
WHelp("MonFichier" + NumériqueVersChaîne(Nation(), "03d") + ".chm")
```

### Divers

- Le format Winhelp n'est plus supporté par les versions récentes de Windows (supérieures à Windows Vista). Pour plus d'informations sur WinHelp, consultez la documentation de Windows.
- Pour associer une bulle d'aide contextuelle aux champs d'une fenêtre, utilisez la fonction [FichierAide](3013029.md).
