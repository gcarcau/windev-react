# <Variable WDPic>.InverseCouleur (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Inverse les couleurs dans une variable de type [WDPic](1000023503.md).

## Exemple

```wlangage
MonImageWDPic est un WDPic = "Test.bmp"
// Inverse les couleurs de la variable MonImageWDPic
Résultat1 est un booléen
Résultat1 = MonImageWDPic.InverseCouleur()
SI Résultat1 = Faux ALORS Erreur("L'opération a échoué")
IMG_MonDessin = MonImageWDPic
```

## Syntaxe

```wlangage
<Résultat> = <Image WDPic>.InverseCouleur()
```

`<Résultat>` *Booléen*
> - Vrai si l'inversion des couleurs a été effectuée,
> - Faux dans le cas contraire.
`<Image WDPic>` *Variable de type WDPic*
> Nom de la variable de type [WDPic](1000023503.md) à manipuler. Seul le calque d'arrière-plan sera manipulé.
> Chaque pixel de l'image prend la couleur opposée (négation bit à bit) de la couleur d'origine. L'image manipulée est directement modifiée.

## Remarques

### Fin du dessin
Si la fonction [<Variable WDPic>.FinDessin](1000024472.md) est appelée dans le même traitement que la fonction **<Variable WDPic>.InverseCouleur**, la transformation de l'image ne sera pas affichée.

**Composante : wd300pnt.dll**
