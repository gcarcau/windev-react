# Fonctions DDE

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Les fonctions permettant de gérer le DDE sont les suivantes :

| [DDEChaîne](3028002.md) | Retourne les informations récupérées par la fonction [DDERécupère](3028017.md). |
| --- | --- |
| [DDEConnecte](3028015.md) | Ouvre une connexion DDE entre le programme en cours et le destinataire selon un sujet donné. |
| [DDEDéconnecte](3028003.md) | Supprime une connexion entre le programme en cours et un destinataire. |
| [DDEDestinataire](3028001.md) | Identifie le destinataire d'une connexion DDE. |
| [DDEEnvoie](3028004.md) | Envoie une donnée au programme connecté via DDE. |
| [DDEErreur](3028006.md) | Retourne le compte-rendu d'exécution d'une fonction de gestion du dialogue DDE. |
| [DDEEvénement](3028009.md) | Associe une procédure WLangage à un événement DDE : lorsque l'événement DDE se produit, la procédure WLangage associée est automatiquement lancée. |
| [DDEExécute](3028008.md) | Envoie un ordre à exécuter sur le serveur. |
| [DDEFinLien](3028005.md) | Interrompt un lien entre un item et une donnée. |
| [DDEItem](3028007.md) | Identifie l'item concerné par un événement DDE. |
| [DDELance](3028013.md) | Lance l'exécution d'un programme (exécutable par exemple) depuis l'application en cours. |
| [DDELien](3028010.md) | Crée un lien chaud avec une donnée. |
| [DDELienTiède](3028014.md) | Crée un lien tiède avec une donnée. |
| [DDEModifie](3028011.md) | Modifie une donnée liée. |
| [DDERécupère](3028017.md) | Récupère une donnée envoyée par un programme (le destinataire de la connexion pour l'objet spécifié). |
| [DDESujet](3028019.md) | Identifie le sujet de la conversation associée à une connexion DDE. |
