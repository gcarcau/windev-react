# ClientID (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **ClientID** permet de connaître l'identifiant du client défini lors de la déclaration (ou de l'enregistrement) de l'application. Cette propriété est utilisée par :

- une variable de type [gglConnexion](1000018009.md).
- une variable de type [OAuth2Paramètres](1000022212.md).
- une variable de type [OpenIDParamètres](1000023561.md).
- une variable de type [gpwOAuthParamètres](1000024751.md).
