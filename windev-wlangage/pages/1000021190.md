# Fonctions de gestion des champs Sélecteur (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions permettant de gérer les champs Sélecteur via une syntaxe préfixée sont les suivantes :

| [<Sélecteur>.Ajoute](1000021186.md) | Ajoute une nouvelle option dans un champ Sélecteur. |
| --- | --- |
| [<Sélecteur>.Insère](1000021187.md) | Insère une nouvelle option dans un champ Sélecteur. |
| [<Sélecteur>.Occurrence](1000021188.md) | Renvoie le nombre d'options présentes dans un champ Sélecteur. |
| [<Sélecteur>.Supprime](1000021189.md) | Supprime une option d'un champ Sélecteur. |
