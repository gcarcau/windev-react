# dbgOptionAudit (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Récupère ou modifie les options de l'audit dynamique.

## Exemple

```wlangage
// Connaître les options de l'audit dynamique
SI ETBinaire(dbgOptionAudit(), AuditWarningUtilisateur) = AuditWarningUtilisateur ALORS
	Trace("Audit dynamique avec Warning utilisateur")
FIN
SI ETBinaire(dbgOptionAudit(), AuditErreur) = AuditErreur ALORS
	Trace("Audit dynamique avec erreur")
FIN
```

## Syntaxe

#### Obtenir les options de l'audit dynamique

```wlangage
<Résultat> = dbgOptionAudit()
```

`<Résultat>` *Constante de type Entier*
> Options de l'audit dynamique :
>
> | *AuditAssertion* | Les assertions sont inscrites dans l'audit dynamique. |
> | --- | --- |
> | *AuditCommentaire* | Les commentaires d'audit sont inscrits dans l'audit dynamique. Un commentaire d'audit est écrit grâce à la fonction [dbgEcritCommentaireAudit](1000018839.md). |
> | *AuditErreur* | Les erreurs non fatales non traitées sont inscrites dans l'audit dynamique. |
> | *AuditException* | Les erreurs fatales, traitées par QUAND EXCEPTION ou non traitées, sont inscrites dans l'audit dynamique. |
> | *AuditWarningAnomalie* | Les warnings d'exécution concernant les anomalies détectées sont inscrits dans l'audit dynamique. |
> | *AuditWarningPerformance* | Les warnings d'exécution concernant les performances sont inscrits dans l'audit dynamique. |
> | *AuditWarningUtilisateur* | Les warnings d'exécution personnalisés sont inscrits dans l'audit dynamique. Un warning personnalisé est déclenché grâce à la fonction [dbgEcritWarningAudit](1000018838.md). |

#### Modifier les options de l'audit dynamique

```wlangage
dbgOptionAudit([<Nouvelles options>])
```

`<Nouvelles options>` *Entier optionnel*
> Options de l'audit dynamique :
>
> | *AuditAssertion* | Les assertions sont inscrites dans l'audit dynamique. |
> | --- | --- |
> | *AuditCommentaire* | Les commentaires d'audit sont inscrits dans l'audit dynamique. Un commentaire d'audit est écrit grâce à la fonction [dbgEcritCommentaireAudit](1000018839.md). |
> | *AuditErreur* | Les erreurs non fatales non traitées sont inscrites dans l'audit dynamique. |
> | *AuditException* | Les erreurs fatales, traitées par QUAND EXCEPTION ou non traitées, sont inscrites dans l'audit dynamique. |
> | *AuditTout* | Tous les événements d'audit sont inscrits dans l'audit dynamique. |
> | *AuditWarningAnomalie* | Les warnings d'exécution concernant les anomalies détectées sont inscrits dans l'audit dynamique. |
> | *AuditWarningPerformance* | Les warnings d'exécution concernant les performances sont inscrits dans l'audit dynamique. |
> | *AuditWarningUtilisateur* | Les warnings d'exécution personnalisés sont inscrits dans l'audit dynamique. Un warning personnalisé est déclenché grâce à la fonction [dbgEcritWarningAudit](1000018838.md). |
