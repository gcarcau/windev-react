# grDestinationImage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Définit une variable de type Image comme destination d'un graphe.

## Exemple

```wlangage
MonImage est une Image
MonImage.Largeur = 100
MonImage.Hauteur = 100
grCrée("MonGraphe", grSecteur)

// Définit la destination du dessin du graphe
grDestinationImage("MonGraphe", MonImage)
// Ajoute les données
grAjouteDonnée("MonGraphe", 1, 10)
...
// Dessine le graphe
grDessine("MonGraphe")
```

## Syntaxe

```wlangage
grDestinationImage(<Nom du graphe> , <Nom de la variable Image>)
```

`<Nom du graphe>` *Chaîne de caractères*
> Nom du graphe à manipuler, défini avec la fonction [grCrée](3042005.md).
`<Nom de la variable Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) dans laquelle le graphe sera dessiné.

## Remarques

### Conditions d'utilisation et limites

- Le graphe sera dessiné dans la variable de type [Image](1000019650.md) spécifiée. Le graphe sera dessiné sur un fond blanc. Le précédent dessin contenu dans la variable [Image](1000019650.md) sera effacé.
- Cette fonction ne peut pas être utilisée avec les champs Graphe.
- Cette fonction ne permet pas d'obtenir l'image d'un graphe en 3D. Le graphe sera automatiquement converti en 2D.

### Créer et dessiner un graphe par programmation
Pour dessiner un graphe :

- créez le graphe (fonction [grCrée](3042005.md)),
- ajoutez les données (fonctions [grAjouteDonnée](3042023.md), [grBourseAjouteDonnée](3042009.md) et [grNuageAjouteDonnéeXY](3042032.md)),
- définissez la destination du graphe à l'aide des fonctions suivantes :
  - [grDestinationBMP](3042018.md),
  - [grDestinationChamp](3042020.md),
  - [grDestinationEMF](3042017.md),
  - [grDestinationFen](3042031.md),
  - **grDestinationImage**,
  - [grDestinationWMF](3042019.md).
- dessinez le graphe (fonction [grDessine](3042026.md)).
