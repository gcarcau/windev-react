# Membre (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **Membre** permet de connaître et de modifier un membre d'une variable de type Variant, JSON ou YAML. Cette propriété est utilisable sur :

- une variable de type [JSON](1000023611.md).
- une variable de type [Variant](1514019.md).
- une variable de type [YAML](1000024438.md).
