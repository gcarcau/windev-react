# Constantes URI

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Les constantes utilisées par les fonctions URIxxx sont les suivantes :

| Constante | Détail | Fonction |
| --- | --- | --- |
| **uriAjout** | Le contenu du fichier ou du buffer est ajouté à la fin du contenu initial de la ressource. | [FichierVersURI](1410087413.md) [BufferVersURI](1410087415.md) |
| **uriAudio** | Types MIME gérés : Autorise tous les types de fichier audio. | [URISélecteur](1000024026.md) |
| **uriCréation** | - Ouvre le sélecteur en mode "Création" pour créer un nouveau document. - Le contenu initial de la ressource est remplacé par celui du fichier ou du buffer. | - [URISélecteur](1000024026.md) - [FichierVersURI](1410087413.md)  [BufferVersURI](1410087415.md) |
| **uriImage** | Types MIME gérés : Autorise tous les types de fichier image. | [URISélecteur](1000024026.md) |
| **uriInfoNom** | Information demandée : Nom de la ressource (sans extension). | [URIRécupèreInfo](1000024037.md) |
| **uriInfoTaille** | Information demandée : Taille de la ressource (en octets). | [URIRécupèreInfo](1000024037.md) |
| **uriInfoTypeConversion** | Information demandée : Types MIME (et extensions de fichier correspondantes) dans lesquels la ressource peut être convertie lors de l'export de la ressource. | [URIRécupèreInfo](1000024037.md) |
| **uriInfoTypeOrigine** | Information demandée : Type MIME d'origine de la ressource et extension de fichier correspondante. | [URIRécupèreInfo](1000024037.md) |
| **uriOuverture** | Ouvre le sélecteur en mode "Ouverture" pour ouvrir un document existant. | [URISélecteur](1000024026.md) |
| **uriVidéo** | Types MIME gérés : Autorise tous les types de fichier image. | [URISélecteur](1000024026.md) |
