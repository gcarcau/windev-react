# JSONOuvreLecteur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Crée un lecteur permettant de lire un document JSON sans le charger en mémoire.
**Attention** : Cette fonction est disponible uniquement à partir de la version 2025 Update 3.

## Exemple

```wlangage
lecteur_JSON est un jsonLecteur = JSONOuvreLecteur(nom_du_fichier)
```

## Syntaxe

```wlangage
<Résultat> = JSONOuvreLecteur(<Document> [, <Origine>])
```

`<Résultat>` *Variable de type jsonLecteur*
> Variable de type [jsonLecteur](1410090783.md) permettant de lire un document JSON sans le charger en mémoire.
`<Document>` *Chaîne de caractères*
> - Chemin du fichier contenant le document JSON à lire.
> - Contenu JSON à manipuler.
`<Origine>` *Constante optionnelle de type Entier*
> Contenu du paramètre <Document> :
>
> | *depuisFichier* | Le paramètre <Document correspond au nom d'un fichier. |
> | --- | --- |
> | *depuisChaîne* | Le paramètre <Document est une chaîne UTF8 contenant le JSON à manipuler. |
