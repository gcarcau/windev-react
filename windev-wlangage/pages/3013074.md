# EnModeAJAX (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Identifie si le code est exécuté depuis :

- un traitement en mode AJAX.
- une procédure appelée grâce aux fonctions [AJAXExécute](3055114.md) ou [AJAXExécuteAsynchrone](3055115.md).

Pour plus de détails sur AJAX, consultez [Présentation de AJAX](3055101.md).

## Exemple

```wlangage
// Code exécuté depuis un traitement AJAX ?
SI EnModeAJAX() = Vrai ALORS
	// Mode AJAX
	// Traitements à effectuer
	...
SINON
	// Mode non AJAX
	// Traitements à effectuer
	...
FIN
```

## Syntaxe

```wlangage
<Résultat> = EnModeAJAX()
```

`<Résultat>` *Booléen*
> - Vrai si le code est exécuté depuis un traitement en mode AJAX ou depuis une procédure appelée grâce aux fonctions [AJAXExécute](3055114.md) ou [AJAXExécuteAsynchrone](3055115.md),
> - Faux dans le cas contraire.
>
>
> Si le traitement en cours n'est pas en mode AJAX mais s'il a été appelé à partir d'un traitement en mode AJAX (grâce à la fonction [ExécuteTraitement](3013031.md) par exemple), la fonction **EnModeAJAX** retourne Vrai.
>
> > _(WEBDEV - Code Navigateur)_ Ce paramètre correspond toujours à Faux.

## Remarques

> _(WEBDEV - Code Serveur, PHP, Ajax)_ Traitements en mode AJAXLes traitements suivants peuvent passer en mode AJAX automatique :traitement serveur "Clic" d'un champ Bouton, d'un champ Lien ou d'un champ Image cliquable.traitement serveur "A chaque modification" d'un champ Liste, d'un champ Combo, d'un champ Interrupteur ou d'un champ Sélecteur.Pour passer un traitement en mode AJAX automatique, cliquez simplement sur le terme "AJAX" présent dans le bandeau du traitement :
Traitement n'utilisant pas la technologie AJAXTraitement utilisant la technologie AJAX

> _(WEBDEV - Code Serveur, PHP, Ajax)_ Procédures en mode AJAXPour permettre l'appel d'une procédure serveur par AJAX, cliquez simplement sur le terme "AJAX" présent dans le bandeau de la procédure :
Procédure ne pouvant pas être appelée par AJAXProcédure pouvant être appelée par AJAX

### Disponibilité de la fonction
La fonction **EnModeAJAX** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **EnModeAJAX** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.
