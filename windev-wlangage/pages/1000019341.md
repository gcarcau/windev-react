# Global (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **Global** permet de savoir si un élément est global ou non. Cette propriété est utilisée par :

- une variable de type [Description de procédure](1000019317.md).
- une variable de type [Description de Propriété](1000019324.md).
- une variable de type [Description de Variable](1000019560.md).
