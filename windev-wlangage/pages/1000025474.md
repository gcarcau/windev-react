# RGPD (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **RGPD** permet de :

- savoir si une rubrique d'un fichier de données est concernée par la RGPD.
- définir si une rubrique doit être concernée par la RGPD (lors de la description de la rubrique par programmation uniquement).

Rappel : La définition des rubriques concernées par la RGPD est réalisée sous l'éditeur d'analyses.

## Exemple

```wlangage
// Description du fichier de données UnFichier
...
// Description de la rubrique "NOM"
MaRubrique est une Description de Rubrique
MaRubrique.Nom = "NOM"
MaRubrique.Type = hRubTexte
MaRubrique.Taille = 40
MaRubrique.TypeClé = hCléUnique
MaRubrique.RGPD = Vrai
// Validation de la description de la rubrique "NOM"
HDécritRubrique(UnFichier, MaRubrique)
// Validation de la description du fichier de données UnFichier
...
```

## Syntaxe

#### Savoir si la rubrique est concernée par la RGDP

```wlangage
<Résultat> = <Fichier de données>.<Rubrique>.RGPD
```

`<Résultat>` *Booléen*
> - Vrai si la rubrique associée à l'enregistrement est concernée par la RGPD,
> - Faux dans le cas contraire.
>
> Nom logique du fichier de données manipulé. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Fichier](1514065.md).
`<Rubrique>` *Chaîne de caractères*
> Nom de la rubrique manipulée. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Rubrique](1514071.md).

#### Définir si une rubrique est concernée par la RGPD

```wlangage
<Rubrique>.RGPD = <Mode de gestion>
```

`<Rubrique>` *Chaîne de caractères*
> Nom de la rubrique manipulée. Ce nom vient d'être défini grâce au type [Description de Rubrique](1514071.md).
`<Mode de gestion>` *Booléen*
> - Vrai si la rubrique est concernée par la RGPD,
> - Faux dans le cas contraire.
