# Contact (Type de variable)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le type **Contact** permet de définir toutes les caractéristiques avancées d'un contact du répertoire téléphonique.
Les caractéristiques de ce contact peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Ajoute un numéro de téléphone au contact "John Doe"
tabContact est un tableau de Contact = ContactListe()
SI PAS ErreurDétectée ALORS
	c est un Contact
	POUR TOUT c DE tabContact
		SI c.Nom ~= " Doe " _ET_ c.Prénom ~= " John "
			tel est un Téléphone
			tel.Numéro = " 0467010203 "
			tel.Type = telDomicile
			Ajoute(c.Téléphone, tel)
			ContactModifie(c)
			RETOUR
		FIN
	FIN
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type Contact
Les propriétés suivantes peuvent être utilisées pour manipuler un contact téléphonique :

| **Nom de la propriété** | **Type manipulé** | **Effet** |
| --- | --- | --- |
| Adresse | Tableau de [Adresse](1000019944.md) | Liste des adresses postales du contact. |
| Email | Tableau de [AdresseEmail](1000020244.md) | Liste des adresses email du contact. |
| Evénement | Tableau de [Evénement](1000020248.md) | Liste des événements associés au contact. |
| Favori | Booléen | - Vrai si le contact est dans la liste des favoris, - Faux dans le cas contraire. |
| ID | Entier | Identifiant du contact.  **Cette propriété est disponible en lecture seulement**. |
| MessagerieInstantanée | Tableau de [MessagerieInstantanée](1000020247.md) | Liste des adresses de messageries instantanées du contact. |
| Nom | Chaîne de caractères | Nom de famille du contact. |
| NomAffiché | Chaîne de caractères | Nom du contact tel qu'il doit être affiché sur le téléphone (dans la liste des contacts ou lors de la réception d'un appel par exemple). Ce nom est construit automatiquement à partir des informations fournies sur le contact, il n'est pas possible de le modifier. Typiquement, le nom affiché correspond à la concaténation du prénom et du nom de famille. Si ces informations n'ont pas été renseignées pour le contact, le nom affiché peut correspondre à l'adresse email ou au numéro de téléphone du contact.  **Cette propriété est disponible en lecture seulement**. |
| Note | Tableau de chaînes de caractères | Liste des notes associées au contact. _(iPhone/iPad, Widget IOS, Mac Catalyst)_ Une seule note peut être associée au contact. |
| Prénom | Chaîne de caractères | Prénom du contact. |
| SIP | Tableau de [AdresseSIP](1000020245.md) | Liste des adresses SIP du contact. _(iPhone/iPad, Widget IOS, Mac Catalyst)_ Cette propriété n'est pas disponible. |
| SiteWeb | Tableau de [AdresseWeb](1000020246.md) | Liste des adresses Web du contact. |
| Source | Tableau de [ContactSource](1000020211.md) | Liste des sources de contacts (comptes Google, Exchange, Facebook, etc.) auxquelles appartient le contact. _(iPhone/iPad, Widget IOS, Mac Catalyst)_ La source n'est pas modifiable. Le contact ne peut appartenir qu'à une seule source. |
| Téléphone | Tableau de [Téléphone](1000020241.md) | Liste des numéros de téléphone du contact. |

## Remarques

### Réinitialisation
Pour réinitialiser le contenu d'une variable de type Contact, il est possible d'utiliser la fonction [VariableRAZ](3013069.md) ou [ContactRAZ](1000006107.md).
