# GéométrieDésérialiseWKTGéo (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Construit une géométrie en coordonnées géographiques à partir d'une représentation textuelle au format WKT.
Remarques :

- Les points présents dans le WKT représente un couple "latitude-longitude".
- Attention : dans le format WKT, la longitude vient avant la latitude. Un point (latitude, longitude) est représenté par "POINT(longitude latitude)".

## Exemple

```wlangage
TexteWKT est une chaîne ANSI
TexteWKT = "
	POLYGON( (4.9746785 47.13040029, 4.97344728 47.13107359, 4.97345634 47.13108307,
	4.97388735 47.13087471, 4.9746785 47.13040029) )
	"
monPolygone est un PolygoneGéo = GéométrieDésérialiseWKTGéo(TexteWKT)
```

## Syntaxe

```wlangage
<Résultat> = GéométrieDésérialiseWKTGéo(<Représentation WKT>)
```

`<Résultat>` *Variable correspondant à des données spatiales*
> Variable de géométrie en coordonnées géographiques correspondant à la représentation WKT. Cette géométrie peut correspondre à un des types de variables suivants :
>
> - [PointGéo](1410090102.md).
> - [PolyligneGéo](1410090128.md).
> - [PolygoneGéo](1410090127.md).
> - [MultiPointGéo](1410090130.md).
> - [MultiPolyligneGéo](1410090133.md).
> - [MultiPolygoneGéo](1410090136.md).
`<Représentation WKT>` *Chaîne de caractères ANSI*
> Chaîne de caractères correspondant à la représentation WKT de la géométrie en coordonnées géographiques à construire.
