# MatErreur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Identifie le type de la dernière erreur due à une fonction Matxxx ([fonctions de gestion des matrices](3050051.md)).

## Exemple

```wlangage
// Identification du type d'erreur
ResErreur = MatErreur("MaMatrice")
```

## Syntaxe

```wlangage
<Résultat> = MatErreur(<Matrice>)
```

`<Résultat>` *Entier*
> - 0 si aucune erreur n'est survenue sur la matrice,
> - un code d'erreur (valeur supérieure à 0) dans le cas contraire.
`<Matrice>` *Chaîne de caractères*
> Nom de la matrice manipulée, défini avec la fonction [MatCrée](3050058.md).

## Remarques

### Code d'erreur
Les codes d'erreur pouvant survenir sur une matrice sont :

- 8 : Pas assez de mémoire disponible.
- 9 : La position demandée est en dehors de la matrice.
- 10 : Le nom de la matrice est invalide.
- 11 : Les matrices ont des dimensions différentes.
- 12 : Le déterminant est nul. Impossible de calculer l'inverse de la matrice.

**Attention** : Les erreurs 9, 10 et 11 génèrent une erreur du WLangage. L'application est alors arrêtée.

> _(WEBDEV - Code Navigateur)_ En code navigateur, les codes d'erreur pouvant survenir sur une matrice sont :1202 : La position demandée est en dehors de la matrice. 1200 : Le nom de la matrice est invalide. 1203 : Les matrices ont des dimensions différentes. 1206 : Le déterminant est nul. Impossible de calculer l'inverse de la matrice.Attention : Les erreurs 1202, 1200 et 1203 génèrent une erreur du WLangage. L'application est alors arrêtée.

### Existence de la matrice
L'existence de la matrice n'est pas vérifiée. Pour vérifier l'existence d'une matrice, utilisez la fonction [MatExiste](3050076.md).
