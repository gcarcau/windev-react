# Affiche (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Affiche une valeur dans un champ ou affecte une valeur dans une variable.
**Remarque** : En WLangage, pour affecter une valeur à un champ, une simple affectation suffit.

## Syntaxe

```wlangage
Affiche([<Nom de la fenêtre>, ] <Nom> [, <Indice 1> [, <Indice 2>]] , <Valeur>)
```

`<Nom de la fenêtre>` *Chaîne de caractères (optionnelle)*
> Nom de la fenêtre où l'élément doit être affiché. Ce paramètre doit être spécifié uniquement si cette fenêtre est différente de celle en cours. Par exemple, le champ "Nom" appartient à la fenêtre FEN_Fiche qui n'est pas la fenêtre en cours.
`<Nom>` *Chaîne de caractères*
> Nom du champ à afficher ou le nom de la variable à affecter dans la fenêtre.
`<Indice 1>` *Chaîne de caractères (optionnelle)*
> Indice dans le cas d'un champ indicé ou d'une variable indicée.
`<Indice 2>` *Chaîne de caractères (optionnelle)*
> Indice dans le cas d'une variable indicée à deux dimensions.
`<Valeur>` *Chaîne de caractères*
> Valeur du champ à afficher ou de la variable à affecter.

## Remarques

### Affectation de variable
Lors d'une affectation de variable, le paramètre <Valeur> doit être passé à APPELWD sous forme texte, même si la variable est de type numérique :
AFFICHE,<Nom de variable>[,Indice>]=<Texte>

Le séparateur décimal est le point.

Exemple en C :

```wlangage
// Affectation de 100.12 dans la variable PrixHT de type réelAPPELWD("AFFICHE,PRIXHT=100.12");// Affichage de Vendredi dans la variable NomJour de type ChaineAPPELWD("AFFICHE,NOMJOUR=Vendredi");// Passage de la valeur à afficher par variableAPPELWD("AFFICHE,PRIXHT=%d",Prix);APPELWD("AFFICHE,NOMJOUR=%s",Jour);
```

Exemple en Pascal :

```wlangage
(*Affectation de 100.12 dans la variable PrixHT de type réel *)APPELWD('AFFICHE,PRIXHT=100.12');(*affichage de Vendredi dans la variable NomJour de type Chaine *)APPELWD('AFFICHE,NOMJOUR=Vendredi');(*passage de la valeur à afficher par variable *)APPELWD('AFFICHE,PRIXHT='+Prix);APPELWD('AFFICHE,NOM='+NomCli);
```

Exemple en VB :

```wlangage
'Affectation de 100.12 dans la variable PrixHT de type réelcall APPELWD("AFFICHE,PRIXHT=100.12")'affichage de Vendredi dans la variable NomJour de type Chainecall APPELWD("AFFICHE,NOMJOUR=Vendredi")'passage de la valeur à afficher par variablecall APPELWD("AFFICHE,PRIXHT="+Prix)call APPELWD("AFFICHE,NOMJOUR="+Jour)
```

### Champ de saisie
<Valeur> doit être passée à APPELWD sous forme texte, même si le champ est de type numérique :
AFFICHE,<Nom du champ>[,<Indice>]=<Texte>

Le séparateur décimal est le point.

Exemple en C :

```wlangage
// Affichage de la valeur 100,12 dans le champ numérique PRIXAPPELWD("AFFICHE,PRIX=100.12");// Affichage de Vendredi dans le champ indicé JOUR à l'indice 31APPELWD("AFFICHE,JOUR,31=Vendredi");//Passage de la valeur à afficher par variableAPPELWD("AFFICHE,NOM=%s",NomCli);
```

Exemple en Pascal :

```wlangage
(*Affectation de 100.12 dans la variable PrixHT de type réel *)APPELWD('AFFICHE,PRIXHT=100.12');(*affichage de Vendredi dans la variable NomJour de type Chaine *)APPELWD('AFFICHE,NOMJOUR=Vendredi');(*passage de la valeur à afficher par variable *)APPELWD('AFFICHE,PRIXHT='+Prix);APPELWD('AFFICHE,NOM='+NomCli);
```

Exemple en VB :

```wlangage
'Affichage de la valeur 100,12 dans le champ numérique PRIXcall APPELWD("AFFICHE,COMPTEUR=100.12")'Affichage de Vendredi dans champ indicé JOUR à l'indice 31call APPELWD("AFFICHE,JOUR,31=Vendredi")'Passage de la valeur à afficher par variablecall APPELWD("AFFICHE,NOM="+NomCli)
```

Note: Pour les textes longs (supérieurs à 200 caractères), utilisez la fonction AfficheTexteLong.

### Champ Libellé
<Valeur> est le nouveau libellé à afficher :

```wlangage
AFFICHE,<Nom du champ>=<Texte>
```

Le séparateur décimal est le point.

Exemple en C :

```wlangage
APPELWD("AFFICHE,LibTexte=Nom du client");
```

Exemple en Pascal :

```wlangage
APPELWD('AFFICHE,LibTexte=Nom du client');
```

Exemple en VB :

```wlangage
Call APPELWD("AFFICHE,LibTexte=Nom du client")
```

### Interrupteur ou case à cocher
Pour cocher l'interrupteur, <Valeur> peut être égale à la chaîne "O" ou "1" :

```wlangage
AFFICHE,<Nom du champ>[,<Indice>]="O"AFFICHE,<Nom du champ>[,<Indice>]="1"
```

Pour décocher l'interrupteur, <Valeur> peut être égale à la chaîne "N" ou "0" :

```wlangage
AFFICHE,<Nom du champ>[,<Indice>]="N"AFFICHE,<Nom du champ>[,<Indice>]="0"
```

Exemple en C :

```wlangage
APPELWD("AFFICHE,INTERR=O");  // MarqueAPPELWD("AFFICHE,TABINTERR,2=N"); // Démarque
```

Exemple en Pascal :

```wlangage
APPELWD('AFFICHE,INTERR=O');(* Marque   *)APPELWD('AFFICHE,TABINTERR,2=N'); (* Démarque *)
```

Exemple en VB :

```wlangage
Call APPELWD("AFFICHE,INTERR,2=O") 'MarqueCall APPELWD("AFFICHE,TABINTERR,2=N") 'Démarque
```

### Sélecteur ou case d'options
<Valeur> est le numéro de l'option à sélectionner :

```wlangage
AFFICHE,<Nom du champ>=<Numéro de l'option>
```

Exemple en C :

```wlangage
APPELWD("AFFICHE,SELECT=1");   // option 1 en coursAPPELWD("AFFICHE,TYPECLI=3");  // option 3 en cours
```

Exemple en Pascal :

```wlangage
APPELWD('AFFICHE,SELECT=1');  (*option 1 en cours*)APPELWD('AFFICHE,TYPECLI=3');  (*option 3 en cours*)
```

Exemple en VB :

```wlangage
Call APPELWD("AFFICHE,SELECT=1") 'option 1 en coursCall APPELWD("AFFICHE,TYPECLI=3") 'option 3 en cours
```

### Bouton texte et bouton graphique
<Valeur> peut être le nouveau libellé du bouton :

```wlangage
AFFICHE,<Nom du champ>=<Libellé du bouton>
```

<Valeur> peut être la nouvelle image du bouton :

```wlangage
AFFICHE,<Nom du champ>=<Image du bouton>
```

Exemple en C :

```wlangage
APPELWD("AFFICHE,BTOK=Valider");APPELWD("AFFICHE,BTOK=IMGOK.BMP");
```

Exemple en Pascal :

```wlangage
APPELWD('AFFICHE,BTOK=VALIDER');APPELWD('AFFICHE,BTOK=IMGOK.BMP');
```

Exemple en VB :

```wlangage
call APPELWD("AFFICHE,BTOK=VALIDER")call APPELWD("AFFICHE,BTOK=IMGOK.BMP")
```

### Image
<Valeur> peut être le nom du fichier image à afficher.

```wlangage
AFFICHE,<Nom du champ>=<Nom du fichier image>
```

Exemple en C :

```wlangage
APPELWD("AFFICHE,Photo=VIDAL.BMP");
```

Exemple en Pascal :

```wlangage
APPELWD('AFFICHE,PHOTO=VIDAL.BMP');
```

Exemple en VB :

```wlangage
Call APPELWD("AFFICHE,PHOTO=VIDAL.BMP")
```

### Ascenseur ou barre de défilement
<Valeur> correspond à la position de l'ascenseur :

```wlangage
AFFICHE,<Nom du champ>=<Position>
```

Exemple en C :

```wlangage
APPELWD("AFFICHE,ASCENS=35");  // position 35
```

Exemple en Pascal :

```wlangage
APPELWD('AFFICHE,ASCENS=35');  (*position 35*)
```

Exemple en VB :

```wlangage
Call APPELWD("AFFICHE,ASCENS=35")  'position 35
```

### Liste déroulante ou liste déroulée
Si <Indice> est précisé :

```wlangage
AFFICHE,<Nom du champ>,<Indice>=<Valeur>
```

- si <Indice> est supérieur au nombre d'éléments de la liste, la valeur est ajoutée dans la liste
- si <Indice> est inférieur ou égal au nombre d'éléments de la liste, la valeur est modifiée à l'indice précisé.

Si l'indice n'est pas précisé :

```wlangage
AFFICHE,<Nom du champ> = <Valeur>
```

L'élément en cours devient l'élément dont l'indice correspond à la valeur passée en paramètre.

Pour les combos avec saisie, la valeur sera affichée dans le champ de saisie.

Exemple en C :

```wlangage
APPELWD("AFFICHE,COMBO1,5=DUPOND");  // DUPOND inséré à l'indice 5
```

Exemple en Pascal :

```wlangage
APPELWD('AFFICHE,COMBO1,5=DUPOND');(* DUPOND inséré à l'indice 5 *)
```

Exemple en VB :

```wlangage
Call APPELWD("AFFICHE,COMBO1,5=DUPOND")' DUPOND inséré à l'indice 5
```
