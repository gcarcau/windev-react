# QuadrillageVisible (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **QuadrillageVisible** permet d'afficher ou non un quadrillage. Cette propriété est utilisable sur :

- un champ Tableur ou Editeur de diagrammes. Pour plus de détails, consultez l'aide de la propriété [QuadrillageVisible](1000023117.md).
- une variable de type [xlsMiseEnPage](1000023139.md).
