# Connexion

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Le mot-clé **Connexion** peut correspondre :

- au type de variable [Connexion](1514073.md).
- à la propriété **Connexion** qui permet de connaître et de modifier la connexion actuellement associée à un fichier de données.
  Pour plus de détails, consultez [Connexion](2512019.md).
- à la propriété **Connexion** d'une variable de type [hbParamètreScan](1000021715.md).
