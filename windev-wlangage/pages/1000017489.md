# gglCoordonnée (Type de variable)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Le type **gglCoordonnée** permet de décrire et de manipuler un point géographique d'une carte. Les caractéristiques de ce type de variable peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
Ce type de variable est utilisé par :

- le type [gglParamètreCarte](1000017505.md).
- le type [gglChemin](1000017433.md).

**Remarques** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Propriétés

### Propriétés de gestion
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **gglCoordonnée** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Latitude | Réel | Latitude du point. |
| Longitude | Réel | Longitude du point. |
