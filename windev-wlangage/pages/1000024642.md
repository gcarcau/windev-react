# <Variable picCalque>.SymétrieVerticale (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Retourne l'image contenue dans une variable de type [picCalque](1000024604.md) par rapport à un axe vertical (symétrie par rapport à un axe vertical).

## Exemple

```wlangage
MonImageWDPic est un WDPic = "Test.bmp"
MonCalque est un picCalque

// Symétrie verticale de l'image contenue dans le calque
MonRésultat est un booléen
MonRésultat = MonCalque.SymétrieVerticale()
SI MonRésultat = Faux ALORS Erreur("L'opération a échoué")
IMG_MonDessin = MonImageWDPic
```

## Syntaxe

```wlangage
<Résultat> = <Image picCalque>.SymétrieVerticale()
```

`<Résultat>` *Booléen*
> - Vrai si la symétrie a été effectuée,
> - Faux dans le cas contraire.
`<Image picCalque>` *Variable de type picCalque*
> Nom de la variable de type [picCalque](1000024604.md) à manipuler.
> La symétrie est réalisée par rapport à l'axe vertical médian de l'image. L'image est directement modifiée.

## Remarques

### Fin du dessin
Si la fonction [<Variable picCalque>.FinDessin](1000024473.md) est appelée dans le même traitement que la fonction **<Variable picCalque>.SymétrieVerticale**, la transformation de l'image ne sera pas affichée.

**Composante : wd300pnt.dll**
