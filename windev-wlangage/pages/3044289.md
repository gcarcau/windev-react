# HListeGroupe (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Renvoie la liste des groupes d'utilisateurs définis pour une connexion.

## Exemple

```wlangage
// Description de la connexion
HDécritConnexion("MaConnexion", "Julie", "MotDePasse", ...
	"MonServeurHF", "MaBaseDeDonnées", hAccèsHFClientServeur, hOLecture)
// Ouverture de la connexion
HOuvreConnexion("MaConnexion")
Res est une chaîne
Res = HListeGroupe("MaConnexion")
// Ajout des groupes dans un champ Liste
LISTE_Maliste.Ajoute(Res)
```

## Syntaxe

```wlangage
<Résultat> = HListeGroupe(<Connexion>)
```

`<Résultat>` *Chaîne de caractères*
> Nom des différents groupes existants pour la connexion spécifiée. Les noms des différents groupes sont séparés par RC (Retour-Chariot).
> **Remarque** : Si l'utilisateur en cours ne possède pas le droit de visualisation des utilisateurs (constante *hDroitVisualisationUtilisateur*) sur le serveur (fonction [HModifieDroitServeur](3044328.md) ou [HInfoDroitServeur](3044322.md)), la fonction **HListeGroupe** renvoie uniquement le groupe en cours.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion manipulée. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
