# ModeBacASable (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **ModeBacASable** permet de savoir si le mode bac à sable est utilisé. Cette propriété est utilisable sur :

- une variable de type [sfInfoSession](1000018416.md).
- une variable de type [sfConnexion](1000017579.md).
