# gpwInitAnalyse (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

Initialisation de l'analyse du groupware utilisateur.
**Remarque** : Cette fonction concerne le groupware utilisateur utilisé en mode compatible (conservé par compatibilité à partir de la version 18).

## Exemple

```wlangage
// Initialisation de l'analyse du groupware utilisateur
SI gpwInitAnalyse() = Faux ALORS
	Erreur(ErreurInfo())
FIN
```

## Syntaxe

```wlangage
<Résultat> = gpwInitAnalyse()
```

`<Résultat>` *Booléen*
> - Vrai si l'initialisation s'est bien passée,
> - Faux en cas d'erreur. La fonction [ErreurInfo](3013008.md) permet d'identifier l'erreur.

**Composante : wd300gpu.dll**
