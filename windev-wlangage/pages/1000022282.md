# <Variable emailSessionIMAP>.FermeSession (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Ferme la session IMAP.

## Exemple

```wlangage
// Ouverture de la session
MaSession est une emailSessionIMAP

MaSession.AdresseServeur = "imap.masociete.fr"
MaSession.Nom = "utilisateur"
MaSession.MotDePasse = SAI_Mot_de_passe

MaSession.OuvreSession()
...
MaSession.FermeSession()
```

## Syntaxe

```wlangage
<Session IMAP>.FermeSession()
```

`<Session IMAP>` *Variable de type emailSessionIMAP*
> Nom de la variable de type [emailSessionIMAP](1000018957.md) correspondant à la session d'email à manipuler.
