# <Table>.NumEnr (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Renvoie le numéro de l'enregistrement en cours dans un champ Table fichier.
**Remarque** : La fonction **<Table>.NumEnr** peut être utilisée indifféremment sur un champ Table monosélection ou multisélection.

## Exemple

```wlangage
// Numéro d'enregistrement en cours dans le champ Table "TABLE_TableProduit"
ResNumEnr = TABLE_TableProduit.NumEnr()
```

## Syntaxe

```wlangage
<Résultat> = <Champ Table>.NumEnr()
```

`<Résultat>` *Entier*
> - Numéro de l'enregistrement en cours dans le fichier de données lié au champ Table,
> - 0 s'il n'y a pas de ligne en cours ou si la ligne en cours n'est pas encore enregistrée dans le fichier de données lié au champ Table.
`<Champ Table>` *Nom de champ*
> Nom du champ Table à manipuler.

## Remarques

- Si la requête a été exécutée avec la constante *hAvecFiltre* (option cochée dans l'éditeur de requêtes), la fonction **<Table>.NumEnr** renvoie le numéro de l'enregistrement en cours dans la requête.
- Si la requête a été exécutée sans la constante *hAvecFiltre*, la fonction **<Table>.NumEnr** renvoie un résultat indéterminé.
