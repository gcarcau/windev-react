# Fonctions du WLangage utilisables dans un état

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

La plupart des fonctions du WLangage peuvent être utilisées dans les événements d'un état (créé avec l'éditeur d'états).
Cependant, certaines fonctions sont déconseillées telles que les fonctions d'impression spécifiques à l'impression en WLangage ou les fonctions d'accès aux enregistrements manipulés par l'état.

## Fonctions du WLangage déconseillées dans un état

Il est déconseillé d'utiliser les fonctions suivantes dans les événements de l'état, des blocs ou des champs. Si ces fonctions sont utilisées, l'exécution de l'état pourra être incorrecte.
**Fonctions d'impression** : [iEllipse](3046009.md), [iFinImprime](3046053.md), [iHauteurImage](3046057.md), [iImprime](3046031.md), [iImprimeCodeBarre](3046020.md), [iImprimeImage](3046017.md), [iImprimeMot](3046034.md), [iImprimeZone](3046027.md), [iImprimeZoneRTF](3046023.md), [iLargeurImage](3046061.md), [iLien](3046018.md), [iLigne](3046035.md), [iPosX](3046015.md), [iPosY](3046075.md), [iSauteLigne](3046071.md), [iTrait](3046050.md), [iTraitH](3046051.md) et [iTraitV](3046066.md).

**Fonctions d'accès à un enregistrement** : Toutes les fonctions HFSQL du WLangage entraînant la modification de l'enregistrement en mémoire ou de l'enregistrement en cours dans le fichier de base de l'état sont déconseillées dans les événements de l'état, du bloc ou des champs. En effet, ces fonctions risquent de modifier le parcours du fichier de base de l'état.

Ces fonctions sont principalement : [HAjoute](3044147.md), [HCréation](3044255.md), [HCréationSiInexistant](3044254.md), [HDernier](3044101.md), [HEcrit](3044092.md), HLitxxxx, [HModifie](3044042.md), [HPrécédent](3044112.md), [HPositionne](3044110.md), [HPremier](3044113.md), [HRecherche](3044130.md), [HRecule](3044126.md), [HRaye](3044121.md), [HSuivant](3044027.md), [HSupprime](3044018.md), ...
Sous [le logiciel Etats & Requêtes](3088004.md), les fonctions suivantes sont interdites :

## Fonctions d'impression du WLangage utilisables dans un état

Les fonctions d'impression suivantes peuvent être utilisées dans un état :

| [iAperçu](3046069.md) | Paramètre la destination de l'impression. |
| --- | --- |
| [iCadre](3046044.md) | Imprime un cadre aux coordonnées spécifiées. |
| [iCadreArrondi](3046024.md) | Imprime un cadre avec des bords arrondis aux coordonnées spécifiées. |
| [iConfigure](3046072.md) | Configure l'imprimante pour une impression réalisée en WLangage :  - soit en ouvrant directement la fenêtre de configuration. - soit en modifiant directement l'imprimante utilisée pour l'impression en cours. |
| [iCréePolice](3046045.md) | Crée une nouvelle police d'impression. |
| [iDernierFichier](3046068.md) | Renvoie :   - le nom complet du dernier fichier généré lors de l'impression (PDF, RTF, Texte, ...). - la liste des fichiers duplicata créés. |
| [iEscape](3046054.md) | Envoie une commande ESCAPE ou une commande de données à une imprimante. |
| [iFenêtreAbandon](3046042.md) | Paramètre l'affichage de la fenêtre permettant l'abandon de l'impression en cours... |
| [iFermeEtat](3046041.md) | Arrête immédiatement l'impression de l'état en cours. |
| [iFinEtat](3046040.md) | Force l'arrêt de l'impression d'un état. |
| [iForceComplément](3046046.md) | Force l'impression d'un bloc de complément de corps. |
| [iHautBasPageImbriqué](3046047.md) | Imprime ou non les hauts et bas de page de l'état imbriqué. |

| [iHauteurTexte](3046070.md) | Calcule la hauteur de la police du texte à imprimer (en millimètres). |

| [iImpressionAbandonnée](3046006.md) | Permet de savoir si l'utilisateur a demandé l'abandon de l'impression du document en cours. |
| [iImpressionDemandée](3046029.md) | Permet de savoir si l'utilisateur a demandé l'impression du document depuis le visualisateur de rapports. |
| [iImprimeBloc](3046030.md) | Force l'impression d'un bloc de l'état en cours d'impression. |
| [iImprimeComplémentCorps](3046019.md) | Force l'impression d'un bloc de complément de corps en spécifiant la hauteur du bloc de complément. |
| [iImprimeEtat](3046032.md) | Imprime un état réalisé avec l'éditeur d'états. |

| [iInitRequêteEtatConnexion](3046028.md) | Initialise la requête liée à l'état. |
| [iLargeurPage](3046036.md) | Calcule la largeur de la page imprimable (en millimètres) en tenant compte des marges (gauches ou droites) définies. |

| [iListeImprimante](3046063.md) | Renvoie la liste des imprimantes installées sur le poste en cours. |

| [iSelectPolice](3046055.md) | Crée une nouvelle police d'impression depuis la fenêtre standard de sélection des polices de Windows... |
