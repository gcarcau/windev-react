# gImageExiste (Fonction)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU))

Vérifie si une image a bien été chargée en mémoire.
**Rappel** : Les fonctions [ChargeImage](3029022.md) ou [ChargePlancheImage](1000018826.md) permettent de charger des images en mémoire. Ces images peuvent être numérotées de 1 à 9. La fonction **gImageExiste** permet de savoir si l'image N a bien été chargée en mémoire. Cette image pourra être ensuite utilisée par la fonction [gImage](3029042.md).

## Exemple

```wlangage
// Charge l'image 3 si elle n'a pas encore été chargée
SI PAS gImageExiste(3) ALORS
	ChargeImage(3, "Logo.png")
FIN
LIB_TITRE = "Notre logo : " = gImage(3)
```

## Syntaxe

```wlangage
<Résultat> = gImageExiste(<Identifiant de l'image>)
```

`<Résultat>` *Booléen*
> - Vrai si l'image a été chargée en mémoire.
> - Faux dans le cas contraire.
`<Identifiant de l'image>` *Entier*
> Identifiant de l'image (compris entre 1 et 9) recherchée en mémoire. Cet identifiant est donné par les fonctions [ChargeImage](3029022.md) ou [ChargePlancheImage](1000018826.md).

**Composante : wd300obj.dll**
