# Prix (Propriété)

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Prix** permet de gérer le prix d'un élément.
Cette propriété est utilisable sur :

- une variable de type [saasTarification](1000019091.md).
- une variable de type [inAppProduit](1000020868.md).
