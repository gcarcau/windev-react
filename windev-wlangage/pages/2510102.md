# PoliceItalique (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

La propriété **PoliceItalique** permet de :

- Savoir si le texte affiché est en italique ou non.
- Modifier la mise en forme italique du texte.

## Exemple

```wlangage
// Mettre le texte affiché dans le champ "LIB_ChampLibellé" en italique
LIB_ChampLibellé.PoliceItalique = Vrai
```

## Syntaxe

#### Savoir si le texte affiché dans un champ est en italique

```wlangage
<Résultat> = <Champ manipulé>.PoliceItalique
```

`<Résultat>` *Booléen*
> - Vrai si le texte affiché est en italique,
> - Faux dans le cas contraire.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.

> _(WINDEV, Android, Java, Code Utilisateur (MCU), PHP)_ Modifier la mise en forme italique du texte affiché dans un champ Masquer les détails
<Champ manipulé>.PoliceItalique = <Italique/Non italique>

 <Champ manipulé> : Nom de champNom du champ à manipuler. <Italique/Non italique> : BooléenVrai si le texte affiché doit être en italique, Faux dans le cas contraire.

## Remarques

### Limites
Dans un état, la propriété **PoliceItalique** peut être utilisée uniquement sur :

- un champ Libellé.
- un champ Lien URL.
- un champ Calculé.
- un champ Prédéfini.

> _(WINDEV)_ Dans une fenêtre, la propriété PoliceItalique ne peut pas être utilisée sur :un champ Spin,un champ Web Camera,un champ Conférence.Remarque : Cette propriété s'applique sur les champs "Liste image" en mode d'affichage "Liste classique" uniquement.

> _(WEBDEV - Code Serveur)_ Dans une page, la propriété PoliceItalique peut être utilisée sur :un champ Libellé,un champ de saisie,un champ Bouton,un champ Interrupteur,un champ Sélecteur,un champ Liste,une colonne d'un champ Table,une cellule d'un champ Table (en lecture uniquement),un champ d'affichage formaté,un champ HTML,un champ Combo,un champ Lien,un champ Libellé HTML,un champ Réglette,un champ Chemin de navigation (sauf en PHP),un champ Arbre,un menu.

> _(Java)_ La propriété PoliceItalique s'applique uniquement aux éléments suivants :Champ Bouton.Champ Libellé.Champ Combo.Champ Arbre.Colonne d'un champ Table.
