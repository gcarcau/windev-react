# RetraitDroit (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **RetraitDroit** permet de connaître et de modifier le retrait à droite d'un élément. Cette propriété est utilisable sur :

- les champs de saisie et les champs Libellé. Pour plus de détails, consultez [RetraitDroit](1000021110.md).
- les variables de type [docParagraphe](1000022483.md).
- les variables de type [docNiveauNumérotation](1000022799.md).
