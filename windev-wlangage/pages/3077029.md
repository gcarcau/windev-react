# ThreadPause (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Temporise le thread en cours pour la durée indiquée.
Attention : Si une demande d'arrêt du thread est faite par un autre thread (fonction [ThreadDemandeArrêt](1000021218.md)), la pause cesse immédiatement sans attendre la durée indiquée.

## Exemple

```wlangage
ThreadPause(100)
```

## Syntaxe

```wlangage
ThreadPause(<Temporisation>)
```

`<Temporisation>` *Entier*
> Temporisation du thread (en centièmes de seconde). Ce paramètre peut correspondre à :
>
> - un entier correspondant au nombre de centièmes de seconde,
> - une variable de type Durée,
> - l'indication de la durée en clair (par exemple '1s' ou '10cs').

## Remarques

- Il est conseillé d'utiliser la fonction **ThreadPause** à la place des fonctions [Multitâche](3015004.md) ou [Temporisation](3015012.md) lorsque plusieurs threads sont utilisés (y compris pour le thread principal de l'application) si la temporisation n'a pas besoin de traiter les actions de l'utilisateur.
- Dans une application de type Service, la fonction **ThreadPause** doit être remplacée par la fonction [ServiceTemporise](1000018712.md).

**Composante : wd300vm.dll**
