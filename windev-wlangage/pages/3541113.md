# Contrôle : Connectivité machine (requête PING)

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows)

## Présentation

Le robot de surveillance va effectuer un ping sur l'adresse IP spécifiée.
Le contrôle sera :

- réussi si l'adresse répond au ping,
- en échec dans le cas contraire.

## Paramètres spécifiques au contrôle de la connectivité machine

### Informations sur la machine
Il suffit de préciser le nom ou l'adresse IP de la machine à tester.
