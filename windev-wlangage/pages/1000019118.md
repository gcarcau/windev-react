# TexteSansFormat (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

La propriété **TexteSansFormat** permet de récupérer :

- le texte contenu dans un champ de saisie riche (au format RTF ou HTML) sans les balises de formatage HTML ou RTF.
- le texte contenu dans un champ d'affichage HTML ou dans un champ Editeur HTML sans les balises de formatage HTML.
- le texte contenu dans un champ de saisie riche (au format HTML) sans les balises de formatage HTML.

## Exemple

```wlangage
// Copie du texte brut dans un second champ de saisie
SAI_TexteBrut = SAI_TexteHTML.TexteSansFormat
```

## Syntaxe

```wlangage
<Résultat> = <Champ manipulé>.TexteSansFormat
```

`<Résultat>` *Chaîne de caractères*
> Texte contenu dans le champ sans les balises de formatage.
> **Attention** : Si le champ est un champ Unicode, la chaîne de caractères renvoyée est une chaîne de caractères Unicode.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler :
>
> - Nom du champ de saisie riche à manipuler.
> - Champ d'affichage HTML.
> - Champ Editeur HTML.
