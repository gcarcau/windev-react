# Espagne.VérifieNIF (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un numéro NIF (numéro d'identification d'entreprise en Espagne).

## Exemple

```wlangage
// Test d'une variableMonNuméroNIF est une chaîne = "B82661935"Espagne.VérifieNIF(MonNuméroNIF) // renvoie Vrai // Test d'un champSAI_NuméroNIF = "ABC"Espagne.VérifieNIF(SAI_NuméroNIF) // renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = Espagne.VérifieNIF(<Numéro à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un numéro NIF valide.
> - Faux dans le cas contraire.
`<Numéro à vérifier>` *Nom de champ ou variable de type chaîne*
> Numéro NIF à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.

**Composante : wd300std.dll**
