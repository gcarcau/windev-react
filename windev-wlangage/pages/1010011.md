# Gestion des menus contextuels dans une application WINDEV ou WINDEV Mobile

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Un menu contextuel présent dans une fenêtre peut être ouvert par l'utilisateur :

- grâce à un clic droit de la souris.
- par un appui long sur le champ.

Ce menu permet aux utilisateurs d'accéder plus facilement aux fonctionnalités spécifiques d'une fenêtre ou d'un champ d'une fenêtre.
WINDEV et WINDEV Mobile permettent de gérer plusieurs types de menus contextuels :

- **Les menus contextuels personnalisés**. Ces menus sont créés sous l'éditeur de fenêtres et peuvent être manipulés par programmation.
  Pour plus de détails, consultez [Menu contextuel personnalisé](1010017.md).
- **Les menus contextuels des FAA** (Fonctionnalités Automatiques de vos Applications) gérés par WINDEV. Ces menus contextuels s'affichent lors d'un clic droit sur certains types de champs (Champ de saisie, Graphe, Table, ...). Ces menus contextuels permettent à l'utilisateur final d'utiliser des fonctionnalités disponibles automatiquement dans l'application.
  Pour plus de détails sur les FAA, consultez [Fonctionnalités Automatiques de vos Applications](9000022.md).
   Les menus contextuels des FAA sont disponibles uniquement sur les champs Table.
- **Les menus contextuels système** gérés par le système (Android, Windows, ...). Ces menus contextuels s'affichent sur certains types de champs (ActiveX, ...).
  Pour plus de détails, consultez [Menu contextuel système](1010023.md).
   Les menus contextuels système ne sont pas disponibles.

Remarque : Dans une page WEBDEV, il est également possible de gérer des menus contextuels grâce au champ [Menu contextuel](1410087217.md).

## Menu contextuel des champs Monétaire + Euro

> _(WINDEV)_ Dans les champs de type "Monétaire WINDEV + Euro" (champ de saisie, colonne d'un champ Table, ...), il est possible de proposer à l'utilisateur un menu contextuel permettant de choisir la devise d'affichage. Ce menu contextuel présente le résultat de la conversion de la valeur saisie dans les différentes devises gérées.
Si ce menu contextuel est proposé aux utilisateurs, le menu contextuel associé au champ ne sera pas pris en compte.Pour activer ce menu contextuel système : Affichez la fenêtre de description du champ de saisie de type "Monétaire + Euro". Dans l'onglet "Détail", dans la zone "Gestion de l'Euro", cliquez sur le bouton "Options". Dans la fenêtre qui s'affiche, cochez l'option "Devise modifiable par menu contextuel". Validez la fenêtre. Validez la fenêtre de description du champ.
