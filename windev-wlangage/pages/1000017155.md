# OBEXEnvoieVCard (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Envoie un fichier VCard (carte de visite virtuelle) à un périphérique gérant le protocole OBEX.

## Syntaxe

```wlangage
<Résultat> = OBEXEnvoieVCard(<Identifiant de la connexion OBEX> , <Fichier VCard>)
```

`<Résultat>` *Booléen*
> - Vrai si le transfert a réussi,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de renseignements sur le problème rencontré.
`<Identifiant de la connexion OBEX>` *Entier*
> Identifiant de la connexion OBEX à utiliser. Cet identifiant est retourné par la fonction [OBEXConnecte](1000017153.md).
`<Fichier VCard>` *Chaîne de caractères*
> Nom de la carte de visite à envoyer.

## Remarques

### Fichier VCard
VCard est un format standard ouvert d'échange de données personnelles (Visit Card) décrit par les documents RFC2425 et RFC2426.
Exemple de VCard :

```wlangage
BEGIN:VCARDVERSION:2.1FN:Marcel DupondN:Dupond;MarcelADR;WORK;PREF;QUOTED-PRINTABLE:;Paris 75015=France;16 rue des lavandiersTEL;CELL:+36452655MAIL;INTERNET:mdupond@dupond.comUID:END:VCARD
```

### Limitation
Seules les piles bluetooth Microsoft sont supportées par cette fonction. Pour connaître la pile utilisée, utilisez la fonction [BTPile](1000017229.md).
Pour plus de détails sur les clés supportées, consultez [Quelles piles utiliser ?](1000017231.md)
