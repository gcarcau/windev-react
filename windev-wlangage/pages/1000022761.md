# <Variable Connexion>.SupprimeParamètre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Supprime un paramètre précédemment sauvé avec la fonction [<Variable Connexion>.SauveParamètre](1000022753.md).

## Exemple

```wlangage
MaConnexion est une Connexion

MaConnexion.SupprimeParamètre("MonParamètre")
```

#### Supprime un paramètre sur le serveur (depuis le poste Client)

```wlangage
<Résultat> = <Connexion>.SupprimeParamètre(<Paramètre>)
```

`<Résultat>` *Booléen*
> - Vrai si la suppression a été réalisée,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion à utiliser.
`<Paramètre>` *Chaîne de caractères*
> Nom du paramètre à supprimer. Ce paramètre ne doit pas correspondre à une chaîne vide et ne doit pas contenir le caractère "RC" (Retour Chariot).

**Composante : wd300hf.dll**
