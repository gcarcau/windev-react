# Fragment (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Fragment** permet de manipuler un fragment. Cette propriété est utilisable sur :

- une variable de type [URI](1000024027.md).
- une variable de type [edtHTMLSélection](1000026093.md).
