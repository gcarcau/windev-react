# FAA : Déplier ou replier une arborescence (champ Arbre ou Table hiérarchique)

> **Disponible :** **WINDEV** (Windows)

## Présentation

Le champ Arbre et le champ Table hiérarchique proposent à l'utilisateur final de nombreuses options via le menu contextuel.
Une des options de ce menu contextuel est la possibilité de déplier ou de replier toute l'arborescence du champ.

L'option "Déplier tout" ou "Replier tout" permet de :

- déplier toutes les branches de l'arbre ou de la hiérarchie sélectionnée.
- replier toutes les branches de l'arbre ou de la hiérarchie sélectionnée.

## Paramétrage

### Paramétrage du menu automatique
Le menu contextuel du champ Arbre ou Table hiérarchique peut bien évidemment être désactivé. Pour paramétrer l'affichage du menu contextuel du champ, vous devez :

1. Afficher la fenêtre de description du champ.
2. Sélectionner l'onglet "UI".
3. Choisir le menu désiré dans la combo "Menu contextuel". Il est possible de :
  - "Afficher le menu des FAA (Système)" : Dans ce cas, le menu contextuel affiché sera le menu automatique du champ. Pour plus de détails sur la configuration de ce menu, consultez [Configurer le menu des FAA](2010040.md).
  - "Ajouter un menu contextuel" : Si cette option est cochée, vous pouvez sélectionner le menu contextuel personnalisé à afficher.

Remarques :

- Si les deux options sont cochées, le menu contextuel personnalisé peut être ajouté avant ou après le menu des FAA.
- Si aucune option n'est sélectionnée, aucun menu contextuel ne sera sélectionné. L'option <Désactivé> sera affichée dans la fenêtre de description.
- La propriété [MenuContextuel](2510077.md) permet également de supprimer le menu contextuel spécifique aux FAA et de retrouver le menu Windows classique pour un champ spécifique.

### Désactiver l'option "Déplier tout"/"Replier tout"
Par programmation, la fonction [FAADésactive](1000022018.md) permet de supprimer certaines options du menu contextuel des FAA.
Pour ne pas proposer l'option "Déplier tout"/"Replier tout", utilisez la fonction [FAADésactive](1000022018.md) avec la constante *faaDéplierReplierTout*.
