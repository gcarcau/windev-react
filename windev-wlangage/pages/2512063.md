# NomPhysiqueDécrit (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **NomPhysiqueDécrit** permet de gérer le nom physique des fichiers de données HFSQL.
Cette propriété ne tient pas compte des éventuels changements de noms réalisés grâce à la fonction [HChangeNom](3044141.md). Il est ainsi possible de :

- Connaître le nom physique d'un fichier de données défini sous l'éditeur d'analyses ou défini par programmation.
- Définir un nom physique pour un fichier de données (lors de la description du fichier de données par programmation uniquement).

## Exemple

```wlangage
// Connaître le nom physique du fichier de données Client
ResNomPhys = Client.NomPhysiqueDécrit
```

## Syntaxe

#### Connaître le nom physique d'un fichier de données

```wlangage
<Nom physique actuel> = <Fichier de données>.NomPhysiqueDécrit
```

`<Nom physique actuel>` *Chaîne de caractères*
> Nom physique du fichier de données (sans extension). Ce nom ne tient pas compte des éventuels changements de noms (fonction [HChangeNom](3044141.md)).
`<Fichier de données>` *Chaîne de caractères*
> Nom logique du fichier de données manipulé. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Fichier](1514065.md).

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS, Code Utilisateur (MCU), Ajax, HFSQL Classic, HFSQL Client/Serveur, Hyper File 5.5)_ Définir un nom physique pour un fichier de données créé par programmation Masquer les détails
<Fichier de données>.NomPhysiqueDécrit = <Nouveau nom physique>

 <Fichier de données> : Chaîne de caractèresNom logique du fichier de données manipulé. Ce nom vient d'être défini grâce au type Description de Fichier. <Nouveau nom physique> : Chaîne de caractèresNom physique du fichier de données (sans extension).
