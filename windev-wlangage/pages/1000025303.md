# fInsèreTexteAuDébut (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Insère un texte au début d'un fichier sans écraser le texte déjà présent dans le fichier.

## Exemple

```wlangage
// Chemin du fichiersoit sCheminDuFichier = "C:\MesRépertoires\Fichier.txt"// Chaîne à insérersChaîneAEcrire est une chaînesChaîneAEcrire = "Voici le texte à insérer en début de fichier"// Insertion au débutsoit bInsertion_réussie = fInsèreTexteAuDébut(sCheminDuFichier, sChaîneAEcrire)
```

## Syntaxe

```wlangage
<Résultat> = fInsèreTexteAuDébut(<Chemin du fichier> , <Texte>)
```

`<Résultat>` *Booléen*
> - Vrai si l'insertion a été effectuée,
> - Faux dans le cas contraire.
`<Chemin du fichier>` *Chaîne de caractères*
> Nom et chemin complet (ou relatif) du fichier (260 caractères maximum). Un chemin de type UNC peut être utilisé.
> Si le fichier n'existe pas, il est automatiquement créé.
>
> > _(iPhone/iPad, Widget IOS, Mac Catalyst)_ Ce paramètre peut correspondre à un chemin complet ou relatif par rapport au répertoire en cours (connu avec la fonction fRepEnCours). Ce paramètre est sensible à la casse. Rappel : Sous les iPhone/iPad, une application a uniquement le droit d'écrire dans son répertoire d'installation ou dans un de ses sous-répertoires.
`<Texte>` *Chaîne de caractères*
> Texte à insérer au début du fichier.
