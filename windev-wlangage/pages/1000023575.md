# Fonctions de gestion des protocoles OAuth et OpenID

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des protocoles OAuth et OpenID (syntaxe préfixée)](1000023630.md)).
Les fonctions de gestion des protocoles OAuth et OpenID sont les suivantes :

| Nouveauté 2025 [AuthDéconnecte](1410090538.md) | Déconnecte un utilisateur précédemment authentifié via :  - le protocole OAuth 2.0 sur un service Web quelconque. - le protocole OpenID sur un service Web quelconque. - un token JWT. |
| --- | --- |
| [AuthIdentifie](1000022219.md) | Effectue une authentification utilisant le protocole OAuth 2.0 sur un webservice quelconque. |
| [AuthImporteToken](1410089557.md) | Crée un token d'accès à un webservice à partir d'une description de token au format JSON. |
| Nouveauté 2025 [AuthIntrospecteToken](1410090841.md) | Introspecte un token OAuth. |
| Nouveauté 2025 [AuthRécupèreInfoUtilisateur](1410090919.md) | Récupère les informations concernant un utilisateur à partir d'un jeton d'accès (access token). |
| [AuthRenouvelleToken](1000026168.md) | Renouvelle un token OAuth2 d'un utilisateur si ce token est expiré. |
| Nouveauté 2025 [AuthRévoqueToken](1410090634.md) | Révoque un token JWT. |
| Nouveauté 2025 [AuthVérifieAuthentification](1410090756.md) | Vérifie la validité du token de l'utilisateur courant dans le cas d'une authentification SSO. |
| Nouveauté Abonnement [JWTCréeAssertion](1410091014.md) | Crée une assertion JWT. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 1.** |
| [OpenIDLitIdentité](1000023573.md) | Récupère l'identité d'un utilisateur contenue dans une variable de type [AuthToken](1000022220.md). |

Les types de variables spécifiques aux protocoles OAuth et OpenID sont les suivants :

| [AuthToken](1000022220.md) | Le type **AuthToken** contient les caractéristiques d'un token d'accès à un service Web. |
| --- | --- |
| [JWTParamètres](1410089572.md) | Le type **JWTParamètres** permet de définir toutes les informations nécessaires pour effectuer une authentification JWT. |
| [OAuth2Paramètres](1000022212.md) | Le type **OAuth2Paramètres** permet de définir toutes les informations nécessaires pour s'authentifier sur un service Web implémentant le standard OAuth 2.0. |
| [OpenIDIdentité](1000023567.md) | Le type **OpenIDIdentité** permet de définir toutes les caractéristiques avancées d'un utilisateur connecté à un service Web via le protocole OAuth 2.0. |
| [OpenIDParamètres](1000023561.md) | Le type **OpenIDParamètres** permet de définir toutes les caractéristiques avancées d'une authentification pour OpenID. |
