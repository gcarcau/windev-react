# Handle_R (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Le mot-clé **Handle** permet de connaître et de modifier le handle d'un élément. Ce mot-clé peut correspondre :

- à la fonction [Handle](3015005.md). Pour plus de détails, consultez [Handle](3015005.md).
- à la propriété **Handle** d'une variable de type [FichierDisque](1410088883.md).
