# Racine (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Renvoie la racine d'un nombre.

## Exemple

```wlangage
// Racine carré de 25
ResRacine = Racine(25)
// Renvoie 5
```

## Syntaxe

```wlangage
<Résultat> = Racine(<Nombre> , <Ordre de la racine>)
```

`<Résultat>` *Réel*
> Racine du nombre.
`<Nombre>` *Entier ou réel*
> Nombre à manipuler.
`<Ordre de la racine>` *Entier ou réel*
> Ordre de la racine (par exemple 2 pour une racine carrée, 3 pour une racine cubique, ...).
> Si ce paramètre n'est pas spécifié, la racine carrée du <Nombre> est extraite.

**Composante : wd300mat.dll**
