# Evénements associés aux champs HTML

> **Disponible :** **WEBDEV** (Windows, Linux, PHP)

## Présentation

WEBDEV propose différents événements associés au champ HTML.

## Evénements gérés par défaut

> _(WEBDEV - Code Serveur, PHP)_ Evénements gérés par WEBDEVWEBDEV gère par défaut les événements suivants (ordre d'apparition sous l'éditeur de code) :EvénementCondition d'exécutionInitialisation (Code serveur)Exécuté à l'ouverture de la pageRemarque : Dans une page statique, aucun événement n'est disponible.
