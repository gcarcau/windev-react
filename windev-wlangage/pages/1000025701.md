# OCRParamètre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Initialise les options générales de l'OCR (Optical Character Recognition) natif.

## Exemple

```wlangage
// Création des options
MesOCROptions est un ocrOption

// Ne souhaite que les nombres lors de la lecture d'une image
MesOCROptions.NombreUniquement = Vrai

OCRParamètre(MesOCROptions)
```

## Syntaxe

```wlangage
OCRParamètre(<Options avancées>)
```

`<Options avancées>` *Variable de type ocrOption*
> Nom de la variable de type [ocrOption](1000025768.md) contenant les paramètres avancés pour la gestion de l'OCR.

**Classification Métier / UI : Code métier**

**Composante : wd300ocr.dll**
