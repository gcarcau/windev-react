# Fonctions multimédia

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions multimédia (syntaxe préfixée)](1000020097.md)).
Les fonctions Multimédia permettent de manipuler les fichiers multimédia associés aux champs Multimédia.

| [MultimédiaArrêt](1000017203.md) | Arrête la lecture en cours d'un fichier multimédia dans un champ Multimédia. |
| --- | --- |
| [MultimédiaContrôleVisible](1000019973.md) | Gère la visibilité des boutons de contrôle (Lecture, Pause, avance rapide, ...) du champ Multimédia. |
| [MultimédiaDébut](1000017204.md) | Place au début du fichier multimédia joué dans le champ Multimédia. |
| [MultimédiaDurée](1000017211.md) | Renvoie la taille du fichier multimédia en cours de lecture (en millisecondes) dans le champ Multimédia. |
| [MultimédiaEtat](1000017214.md) | Indique l'état du fichier multimédia joué dans le champ Multimédia. |
| [MultimédiaFerme](1000017205.md) | Ferme le fichier multimédia en cours dans le champ Multimédia. |
| [MultimédiaFin](1000017209.md) | Place à la fin du fichier multimédia joué dans le champ Multimédia. |
| [MultimédiaHauteur](1000017212.md) | Renvoie la hauteur en pixels de l'image source du fichier multimédia joué dans le champ Multimédia. |
| [MultimédiaJoue](1000017202.md) | Joue un fichier multimédia dans un champ Multimédia. |
| [MultimédiaLargeur](1000017213.md) | Renvoie la largeur en pixels de l'image source du fichier multimédia joué dans le champ Multimédia. |
| [MultimédiaOuvre](1000017206.md) | Ouvre un fichier multimédia dans un champ Multimédia. |
| [MultimédiaPause](1000017207.md) | Met en pause la lecture d'un fichier multimédia dans un champ Multimédia. |
| [MultimédiaPosition](1000017210.md) | Renvoie ou modifie la position en cours du fichier multimédia en cours dans le champ Multimédia. |
| [MultimédiaVolume](1000017208.md) | Renvoie ou modifie le volume sonore du fichier multimédia joué dans un champ Multimédia. |
