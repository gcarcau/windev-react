# Propriétés associées au champ Lecteur PDF

> **Disponible :** **WINDEV** (Windows) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Un champ Lecteur PDF peut être manipulé en WLangage dans une fenêtre avec les propriétés suivantes.

## Propriétés disponibles dans une fenêtre

Les différentes propriétés associées aux champs Lecteur PDF sont les suivantes :

| [Accessibilité](1410090235.md) | La propriété **Accessibilité** permet de définir et de connaître les propriétés d'accessibilité définies sur un champ. |
| --- | --- |
| [AffichageActif](2510015.md) | La propriété **AffichageActif** permet de :  - savoir si l'affichage d'un champ ou d'une fenêtre est activé ou non. Si l'affichage est activé, le contenu du champ est rafraîchi régulièrement. - activer ou non l'affichage d'un champ ou d'une fenêtre. |
| [Altitude](2510002.md) | La propriété **Altitude** permet de gérer l'altitude d'un champ. |
| [Ancrage](2510001.md) | La propriété **Ancrage** permet de gérer l'ancrage d'un champ dans une fenêtre, une page ou un état. |
| [BarreOutilsVisible](1000021333.md) | La propriété **BarreOutilsVisible** permet :   - de savoir si la barre d'outils ou le ruban est affichée dans un champ. - d'afficher ou non la barre d'outils ou le ruban dans un champ. |
| [CheminFichier](1000023104.md) | La propriété **CheminFichier** permet de connaître :   - le nom du fichier xlsx associé à un champ Tableur. - le nom du fichier associé à un champ Editeur d'images. - le nom du fichier PDF associée à un champ Lecteur PDF. - le nom du fichier DOCX associé à un champ Traitement de texte. - le nom du fichier wddiag associé à un champ Editeur de diagrammes. |
| Nouveauté Abonnement [CouleurChamp](1410091164.md) | La propriété **CouleurChamp** permet de connaître et modifier la couleur de fond utilisée pour les différents champs modifiables d'un formulaire PDF lors de l'affichage de ce formulaire dans un champ Lecteur PDF. **Cette propriété est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.** |
| Nouveauté Abonnement [CouleurFocus](1410091165.md) | La propriété **CouleurFocus** permet de connaître et de modifier la couleur utilisée pour mettre en évidence les champs de saisie ayant le focus dans un formulaire PDF (affiché dans un champ Lecteur PDF).  **Cette propriété est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.** |
| [Epinglé](1410087943.md) | La propriété **Epinglé** permet de :   - Epingler ou non un champ : le champ épinglé sera positionné par rapport à la zone visible de son conteneur au lieu de la zone du contenu. - Savoir si un champ est épinglé. |
| [Etat](2510039.md) | La propriété **Etat** permet de connaître et de modifier l'état d'affichage d'un élément. |
| [EtatInitial](2510063.md) | La propriété **EtatInitial** permet de connaître l'état initial d'un champ. |
| [Extra](1410089327.md) | La propriété **Extra** permet de :  - Connaître les informations supplémentaires associées à un champ, à une fenêtre, ou à une page. - Modifier les informations supplémentaires associées à un champ, à une fenêtre ou à une page. |

| [FlexGrow](1410089748.md) | La propriété **FlexGrow** permet de connaître et de modifier le facteur d'agrandissement d'un champ présent dans une ligne d'un champ Flexbox. |
| [FlexShrink](1410089749.md) | La propriété **FlexShrink** permet de connaître et de modifier le facteur de réduction d'un champ présent dans une ligne d'un champ Flexbox. |
| [Grisé](1000019648.md) | La propriété **Grisé** permet de :   - Savoir si un champ, un groupe de champs ou une fenêtre est grisé ou non. - Griser ou dégriser un champ, un groupe de champs ou une fenêtre. |
| [Groupe](2510049.md) | La propriété **Groupe** permet de :   - savoir si le champ appartient ou non à un groupe de champs. Si le champ appartient à un ou plusieurs groupes, la propriété **Groupe** permet d'identifier ces groupes de champs. - associer un champ à un groupe de champs. |
| [Hauteur](2510050.md) | La propriété **Hauteur** permet de connaître et modifier la hauteur :  - d'un champ ou d'un bloc dans un état. - d'un champ (présent dans une fenêtre), d'une fenêtre, d'une ligne d'un champ Table ou Liste (y compris Liste image), d'une option d'un champ Sélecteur ou Interrupteur, d'un haut ou d'un bas de rupture d'un champ Table ou d'un champ Zone répétée. - d'un champ (présent dans une page), d'un haut ou bas de rupture d'un champ Table ou Zone répétée. | [HauteurInitiale](2510043.md) | La propriété **HauteurInitiale** permet de :  - Connaître la hauteur de création d'un champ ou d'une fenêtre. - Modifier la hauteur de base utilisée pour l'ancrage des champs "en hauteur". - Connaître la hauteur de création d'un champ ou d'un bloc d'un état. |

| [HauteurMin](2510035.md) | La propriété **HauteurMin** permet de connaître et de modifier la hauteur minimale d'un champ ou d'une fenêtre. |

Le champ peut être superposable ou non. |
| [LargeurInitiale](2510067.md) | La propriété **LargeurInitiale** permet de :  - Connaître la largeur de création d'un champ ou d'une fenêtre. - Modifier la largeur de base utilisée pour l'ancrage des champs "en largeur". - Connaître la largeur de création d'un champ d'un état. |
| [LargeurMax](2510068.md) | La propriété **LargeurMax** permet de connaître et de modifier la largeur maximale d'un champ ou d'une fenêtre. |
| [LargeurMin](2510062.md) | La propriété **LargeurMin** permet de connaître et de modifier la largeur minimale d'un champ ou d'une fenêtre. |
