# FluxJoue (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Reprend la réception ou l'émission d'un type de données dans un flux. Ce type de données a été arrêté avec la fonction [FluxStop](3039002.md).

## Exemple

```wlangage
// Reprend la réception du son dans le flux
FluxJoue(FLUX_MonFlux.Valeur, FluxSonRéception)
```

## Syntaxe

```wlangage
FluxJoue(<Identifiant du flux> [, <Type de flux>])
```

`<Identifiant du flux>` *Entier*
> Identifiant du flux à manipuler. Cet identifiant est connu dans l'événement "Demande de connexion d'un nouveau flux" associé au flux. Il peut également être connu grâce à la propriété [Valeur](2510130.md) utilisée sur le flux ou en utilisant directement le nom du flux.
`<Type de flux>` *Constante ou combinaison de constantes optionnelle de type Entier*
> Type de flux à reprendre :
>
> - Constantes simples :
>   | *FluxSonEmission* | Flux de type son émis. |
>   | --- | --- |
>   | *FluxSonRéception* | Flux de type son reçu. |
>   | *FluxVidéoEmission* | Flux de type Vidéo émis. |
>   | *FluxVidéoRéception* | Flux de type Vidéo reçu. |
> - Constantes correspondant à une combinaison de constantes :
>   | *FluxSonDuplex* | Flux de type son reçu et émis (correspond à *FluxSonEmission*+ *FluxSonRéception*). |
>   | --- | --- |
>   | *FluxTout* (valeur par défaut) | Flux de type vidéo + son (*FluxSonDuplex*+ *FluxVidéoDuplex*). |
>   | *FluxVidéoDuplex* | Flux de type vidéo reçu et émis (correspond à *FluxVidéoEmission*+ *FluxVidéoRéception*). |

## Remarques

### Procédure de détection de flux
Un flux est associé à l'événement "Demande de connexion d'un nouveau flux". Cet événement est exécuté lorsqu'une demande de connexion d'un flux entrant est détectée.
Cet événement est exécuté dans un des deux cas suivants :

- si la propriété [Détection](2510031.md) utilisée sur le flux est à Vrai.
- si l'option "Détection des flux entrants actifs" a été cochée dans la fenêtre de description des flux.

**Remarque** : Cet événement est exécuté dans un thread spécifique du WLangage. Il est donc soumis aux limitations sur les threads. Pour plus de détails sur la gestion des threads, consultez [Gestion des threads avec WINDEV](3077026.md).
