# BoutonSegmentéSupprimeTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Supprime toutes les options d'un champ Bouton segmenté.

## Exemple

```wlangage
BoutonSegmentéSupprimeTout(BS_Réponses)
POUR I = 1 À nbRéponse
	BoutonSegmentéAjoute(BS_Réponses, "Réponse " + I)
FIN
```

## Syntaxe

```wlangage
BoutonSegmentéSupprimeTout(<Champ Bouton segmenté>)
```

`<Champ Bouton segmenté>` *Nom de champ*
> Nom du champ Bouton segmenté manipulé.

## Remarques

Lors de la suppression d'options dans un champ Bouton segmenté, la taille du champ n'est pas modifiée. Il est possible de modifier la taille du champ avec les propriétés [Largeur](2510059.md) et [Hauteur](2510050.md).

**Classification Métier / UI : Code UI**
