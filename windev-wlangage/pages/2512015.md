# CxAccès (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **CxAccès** permet de gérer le type d'accès au fichier lors de la connexion OLE DB à une table spécifique. Il est possible de :

- Connaître le type d'accès au fichier de données utilisé pour la connexion à une table par OLE DB.
  Le type d'accès peut correspondre :
  - soit au type d'accès défini sous l'éditeur d'analyses,
  - soit au type d'accès spécifié via les fonctions [HConnecte](3044263.md), [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
    Cette propriété peut être utilisée pour un fichier de données ou une connexion défini sous l'éditeur d'analyses ou défini par programmation.
- Définir le type d'accès au fichier de données utilisé pour la connexion à une table par OLE DB (lors de la description par programmation du fichier de données uniquement).
  Dans ce cas, cette propriété est équivalente à la propriété [CxAccèsDécrit](2512048.md).

**Rappel** : La fonction [HConnecte](3044263.md) permet de redéfinir un ou plusieurs paramètres de la connexion OLE DB sur une table. Par défaut, les caractéristiques de la connexion OLE DB sont définies :

- soit sous l'éditeur d'analyses lors de la description du fichier de données,
- soit en programmation lors de la description du fichier de données.

## Exemple

```wlangage
// Connaître le type d'accès du fichier de données Client
ResTypeAccès = Client.CxAccès
```

## Syntaxe

#### Connaître le type d'accès au fichier de données par une connexion

```wlangage
<Type d'accès> = <Fichier de données ou Connexion>.CxAccès
```

`<Type d'accès>` *Constante*
> Renvoie le type d'accès au fichier de données.
>
>
> | *hOLecture* | Le fichier de données est accessible uniquement en lecture. Seule la lecture des enregistrements est possible. Il n'est pas possible d'en ajouter ou d'en supprimer. |
> | --- | --- |
> | *hOLectureEcriture* | Le fichier de données est accessible en lecture et en écriture. Il est possible aussi bien de lire des enregistrements que d'écrire de nouveaux enregistrements. |
`<Fichier de données ou Connexion>` *Chaîne de caractères*
> - Nom du fichier de données manipulé. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Fichier](1514065.md).
> - Nom de la connexion manipulée. Ce nom a été défini sous l'éditeur d'analyses ou avec les fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).

#### Définir le type d'accès au fichier par une connexion

```wlangage
<Fichier de données ou Connexion>.CxAccès = <Type d'accès>
```

`<Fichier de données ou Connexion>` *Chaîne de caractères*
> - Nom du fichier de données manipulé. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Fichier](1514065.md).
> - Nom de la connexion manipulée. Ce nom a été défini sous l'éditeur d'analyses ou avec les fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
`<Type d'accès>` *Constante*
> Définit le type d'accès au fichier de données.
>
>
> | *hOLecture* | Le fichier de données est accessible uniquement en lecture. Seule la lecture des enregistrements est possible. Il n'est pas possible d'en ajouter ou d'en supprimer. |
> | --- | --- |
> | *hOLectureEcriture* | Le fichier de données est accessible en lecture et en écriture. Il est possible aussi bien de lire des enregistrements que d'écrire de nouveaux enregistrements. |

## Remarques

### Divers
La propriété [CxAccèsDécrit](2512048.md) permet de connaître et de modifier le type d'accès spécifié pour la connexion OLE DB lors de la description du fichier de données.

### Equivalence
La propriété **CxAccès** permet de définir le type d'accès sur un fichier de données manipulé par une connexion. Cette propriété est conservée par compatibilité. Il est conseillé d'utiliser la propriété [Accès](2512100.md). La propriété [Accès](2512100.md) permet de définir le type d'accès sur les fichiers de données manipulés par une connexion.
