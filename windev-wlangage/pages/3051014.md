# MCINombrePiste (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Renvoie le nombre de pistes d'un fichier multimédia, précédemment ouvert (fonction [MCIOuvre](3051017.md)).

## Exemple

```wlangage
MCIOuvre("cdaudio", "cd")
...
Info("Nombre de pistes : " + MCINombrePiste("cd"))
...
MCIFerme("cd")
```

## Syntaxe

```wlangage
<Résultat> = MCINombrePiste(<Fichier multimédia ou alias> [, <Paramètres> [, <Nom de la fenêtre de messages>]])
```

`<Résultat>` *Chaîne de caractères*
> - Nombre de pistes,
> - -1 en cas d'erreur. Pour connaître le numéro de l'erreur, utilisez la fonction [MCIErr](3051011.md). Pour connaître le libellé de l'erreur, utilisez la fonction [MCIMsgErr](3051021.md) ou la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
>   Le compte-rendu de la commande peut être connu avec la fonction [MCIRécupère](3051022.md).
`<Fichier multimédia ou alias>` *Chaîne de caractères*
> - Nom du fichier multimédia à manipuler (AVI, MP3, ...).
> - Alias défini lors de l'ouverture du fichier (fonction [mciOuvre](3051017.md)).
`<Paramètres>` *Chaîne de caractères optionnelle*
> Paramètres complémentaires si nécessaire. Ces paramètres peuvent être connus en consultant la documentation de la fonction MCI Windows "status".
> Il est possible d'ajouter la constante *MciAttente* à cette chaîne. Cette constante permet d'indiquer que le programme doit attendre la fin de la commande MCI pour exécuter la suite de l'application.
`<Nom de la fenêtre de messages>` *Chaîne de caractères optionnelle*
> Nom de la fenêtre permettant d'intercepter et de gérer les différents messages envoyés par MMSYSTEM.DLL. Ces messages sont du type MM_xxxxxx et sont récupérables grâce à la fonction [Evénement](3015011.md). Il est par exemple possible d'obtenir des messages concernant la gestion du lecteur de CD ROM ou du Joystick.

**Composante : wd300std.dll**
