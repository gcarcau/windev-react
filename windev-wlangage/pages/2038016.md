# GDS : Gestion des branches

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

La gestion des branches permet de gérer en parallèle plusieurs versions (exploitées ou pas) d'une même application.
**Le cas habituel est celui-ci** : Vous avez diffusé une version de votre application et vous travaillez sur la future version applicative de cette application. Mais vous souhaitez dans le même temps, reporter dans la version en clientèle les corrections de bug que vous effectuez dans la nouvelle version, et ainsi créer et diffuser des versions correctives intermédiaires.

**Autre exemple** : Les branches peuvent également servir à gérer des versions spécifiques par client. Chaque branche correspond à une version client. Dès que le projet de base (tronc commun) est modifié, il suffit de reporter ces modifications dans chacune des branches.

Les branches permettent ainsi de diffuser des versions correctives de l'application en clientèle sans effort : vous ne coderez pas deux fois les mêmes choses.

Le risque d'erreurs dû au "report manuel" disparaît également.

Le confort augmente, la sécurité augmente, le frein à la mise à disposition de correctifs disparaît...

**Remarques** :

- Les reports de branches sont bidirectionnels. Il est possible de reporter des modifications du projet principal vers la branche ou de la branche vers le projet principal. Le projet modifié est toujours celui qui est ouvert.
- A partir de la version 2024, il devient possible de créer des branches sur des répertoires ne contenant pas de projet depuis l'administrateur du GDS. Pour plus de détail, consultez [Administrateur du GDS : Gestion des branches](2038022.md).
- Nouveauté 2025
  A partir de la version 2025, la suppression de branches et de répertoires a été optimisée. Pour profiter de cette optimisation, utilisez la dernière version de la base de sources du GDS. Pour plus de détails, consultez [GDS : Versions de la base de sources](2038018.md).
  **Attention** : Cette fonctionnalité est disponible uniquement à partir de la version 2025 Update 1.

## Comment gérer les branches

Pour gérer les branches, le GDS propose :

- [La création de branches](2038029.md),
- [La gestion visuelle des branches](2038031.md),
- [La récupération des modifications effectuées dans une branche](2038030.md) (report de branches).

Remarque : Grâce au portefeuille de projets, il est possible de créer une branche sur un ensemble de projets en une seule opération. Pour plus de détails, consultez [Portefeuille de projets](9500231.md).
