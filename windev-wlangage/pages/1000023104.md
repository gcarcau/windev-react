# CheminFichier (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, iPhone/iPad, Mac Catalyst)

La propriété **CheminFichier** permet de connaître :

- le nom du fichier xlsx associé à un champ Tableur. Ce nom est initialisé par les fonctions [TableurCharge](1000021340.md) et [TableurSauve](1000021341.md).
- le nom du fichier associé à un champ Editeur d'images. Ce nom est initialisé par les fonctions [PicOuvre](1000023379.md) et [PicSauve](1000023381.md).
- le nom du fichier PDF associée à un champ Lecteur PDF. Ce nom est initialisé par la fonction [LecteurPDFOuvre](1000023452.md).
- le nom du fichier DOCX associé à un champ Traitement de texte. Ce nom est initialisé par les fonctions [DocOuvre](1000022622.md) et [DocSauve](1000022387.md).
- le nom du fichier wddiag associé à un champ Editeur de diagrammes. Ce nom est initialisé par les fonctions [DiagrammeCharge](1410088123.md) et [DiagrammeSauve](1410088122.md).

## Exemple

> _(WINDEV)_ SI TBLR_MonTableur.CheminFichier <> "" ALORS
 LIB_TitreTableur = TBLR_MonTableur.CheminFichier
FIN

## Syntaxe

#### Connaître le nom du fichier associé au champ

```wlangage
<Résultat> = <Champ à manipuler>.CheminFichier
```

`<Résultat>` *Chaîne de caractères*
> Nom du fichier associé au champ.
`<Champ à manipuler>` *Nom du champ*
> Nom du champ à manipuler :
>
> - Champ Tableur,
> - Champ Editeur d'images,
> - Champ Traitement de texte,
> - Champ Lecteur PDF.
> - Champ Editeur de diagrammes.

## Remarques

- Par défaut, la propriété **CheminFichier** correspond à une chaîne vide.
- Cette propriété est disponible uniquement sur :
  - les champs Tableur présents dans une fenêtre.
  - les champs Editeur d'images.
  - les champs Traitement de texte.
  - les champs Lecteur PDF.
  - les champs Editeur de diagrammes.
