# Environnement de l'éditeur d'états

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

[image: Editeur d'états]

Les éléments importants de l'éditeur d'états sont les suivants :

| [image: 1] | **Ruban** Permet un accès rapide aux principales fonctionnalités de l'éditeur d'états. Ce ruban est composé de volets, de groupes et d'options. Pour plus de détails, consultez [Un menu sous forme de ruban](9000149.md). |
| --- | --- |
| [image: 2] | [**Règles d'alignement**](2022001.md) Permettent d'aligner les champs dans l'état. Pour afficher les règles, utilisez le raccourci Ctrl + R. |
| [image: 3] | **Etat en cours d'édition** Des ascenseurs permettent de faire défiler les états volumineux. Il est également possible de zoomer sur l'état pour visualiser plus précisément les éléments de l'état (Ctrl + roulette de souris). |
| [image: 4] | [**Volets verticaux**](2027001.md) Affiche :  - les éléments (fichiers, variables, états, champs, ...) disponibles dans le projet en cours ([volet "Explorateur de projet"](2027029.md)). - la description des éléments de l'état via le [modifieur](2027006.md).  Dans le logiciel Etats & Requêtes, seuls les volets ["Explorateur de projet"](2027029.md) et ["Modifieur"](2027006.md) sont disponibles. |
| [image: 5] | **Fenêtre de description** Permet de visualiser et/ou de modifier :  - les caractéristiques du ou des champs sélectionnés. - les caractéristiques de l'état en cours. |
| [image: 6] | **Fenêtre de code** Affiche les différents traitements associés à l'état, à ses blocs et à ses champs. |
| [image: 7] | [**Documents ouverts**](2029012.md) Affiche un bouton pour chaque document ouvert sous l'éditeur. Pour afficher l'élément voulu au premier plan, il suffit de cliquer sur le "bouton" correspondant. |
| [image: 8] | [**Volets horizontaux**](2027001.md) Affiche :  - les erreurs de compilation (erreurs présentes dans le code WLangage) ou erreurs d'IHM ([volet "Erreurs de compilation"](2027031.md)), - l'outil de recherche ([volet "Rechercher-Remplacer"](2027013.md)), - le débogueur lors du test d'un élément ([volet "Débogueur"](2027030.md)), - ... |
