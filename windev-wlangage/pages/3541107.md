# Robot de surveillance : Créer un contrôle

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows)

## Présentation

Le moniteur du robot de surveillance permet de créer les différents contrôles à effectuer par le robot de surveillance.

## Comment le faire ?

Les catégories permettent de regrouper les contrôles par thèmes. Chaque contrôle est associé à une catégorie.
Par défaut, si un contre-robot a été installé, une catégorie "Contre-robot" est créée. Cette catégorie contient un test de surveillance du contre-robot.

### Créer une catégorie
Pour créer une catégorie :

1. Dans le menu, dans le groupe "Catégories et contrôles", cliquez sur "Ajouter" et sélectionnez l'option "Ajouter une catégorie" (ou utilisez l'option "Créer une catégorie" du menu contextuel de la table des contrôles).[image: Ajouter une catégorie]
2. Dans la fenêtre qui s'affiche, indiquez le nom de la catégorie.
3. Validez. La nouvelle catégorie apparaît dans le moniteur.

### Créer un contrôle
Pour créer un contrôle :

1. Dans le menu, dans le groupe "Catégories et contrôles", cliquez sur "Ajouter" et sélectionnez l'option "Ajouter un contrôle" (ou utilisez l'option "Créer un contrôle" du menu contextuel de la table des contrôles). [image: Ajouter un contrôle]
2. La fenêtre de configuration du contrôle s'affiche.
  [image: Configuration d'un contrôle]
3. Indiquez :
  - le nom du contrôle.
  - la catégorie du contrôle.
  - le type de contrôle à effectuer.
  - Si le contrôle dépend ou non d'un autre contrôle.
    Remarque : Si le contrôle dépend d'un autre contrôle, il sera exécuté uniquement si le contrôle dont il dépend s'est exécuté sans erreur.
4. Indiquez les [paramètres généraux](3541108.md) du contrôle.
5. Indiquez les paramètres spécifiques du contrôle. Ces paramètres dépendent du type de contrôle sélectionné.
  - [Connectivité machine (ping)](3541113.md).
  - [Connectivité FTP](3541111.md).
  - [Connectivité HTTP](3541112.md).
  - [Connectivité Serveur HFSQL Client/Serveur](3541115.md).
  - [Connectivité bases tierces (par ODBC)](3541110.md).
  - [Connectivité NNTP](3541114.md).
  - [Activité d'une application WINDEV](3541109.md).
  - [Envoi d'un email](3541117.md).
  - [Log d'un site WEBDEV](3541119.md).
  - [SNMP](3541121.md).
  - [Espace disque (par SNMP)](3541118.md).
  - [WLangage (code)](3541122.md).
  - [Serveur WEBDEV](3541120.md).
  - [Connectivité SMTP](3541116.md).
  - Etat d'un cluster.
  - Activité d'un serveur de Télémétrie.
  - Sonde température.
  - Sonde température (par fichier).
  - [Etat SMART d'un disque](3541125.md).
  - [Validité d'un certificat SSL](3541127.md).
6. A tout moment, le bouton "Tester" permet d'exécuter le test en cours d'édition. Le test est exécuté depuis le moniteur.
7. Validez. Le test apparaît dans le moniteur du robot de surveillance.
