# PoliceBarrée (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

La propriété **PoliceBarrée** permet de :

- Savoir si le texte affiché est barré ou non.
- Barrer ou non le texte affiché dans un champ.

> _(WEBDEV - Code Serveur, iPhone/iPad)_ Cette propriété est disponible uniquement pour les champs des états.

## Exemple

```wlangage
// Barrer le texte affiché dans le champ "LIB_ChampLibellé"
LIB_ChampLibellé.PoliceBarrée = Vrai
```

## Syntaxe

#### Savoir si le texte affiché dans un champ est barré

```wlangage
<Résultat> = <Champ manipulé>.PoliceBarrée
```

`<Résultat>` *Booléen*
> - Vrai si le texte affiché est barré,
> - Faux dans le cas contraire.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.

#### Barrer ou non le texte affiché dans un champ

```wlangage
<Champ manipulé>.PoliceBarrée = <Barré/Non barré>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.
`<Barré/Non barré>` *Booléen*
> - Vrai si le texte affiché doit être barré,
> - Faux dans le cas contraire.

## Remarques

### Limites

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad)_ Dans un état, la propriété PoliceBarrée peut être utilisée uniquement sur :un champ Libellé.un champ Calculé.un champ Lien URL.un champ Prédéfini.
Dans une fenêtre, la propriété **PoliceBarrée** ne peut pas être utilisée sur :

- un champ Spin,
- un champ Web Camera,
- un champ Conférence.

Remarque : Cette propriété s'applique sur les champs "Liste image" en mode d'affichage "Liste classique" uniquement.
