# TCDCharge (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Charge le résultat du calcul d'un champ Tableau croisé dynamique depuis une sauvegarde (fichier présent sur le disque ou sauvegarde dans un buffer). Ce calcul a été précédemment sauvé grâce à la fonction [TCDSauve](1000020471.md).
Nouveauté Abonnement

> _(WEBDEV - Code Serveur, Linux)_ Cette fonction est désormais disponible pour les sites WEBDEV sous Windows et sous Linux.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
sFichier est une chaîne
// Construit le nom du fichier
sFichier = SysRep(srAppData) + ["\"] + "StatsParPays.tcd"

// Le fichier existe ?
SI fFichierExiste(sFichier) ALORS
	// Oui, on le charge
	TCDCharge(TCD_Statistiques, sFichier)
	SI OuiNon("Voulez-vous tout recalculer ?") ALORS TCDCalculeTout(TCD_Statistiques)
SINON
	// Le fichier n'existe pas, on le calcule
	TCDCalculeTout(TCD_Statistiques)
FIN
TCDSauve(TCD_Statistiques, sFichier)
```

## Syntaxe

```wlangage
<Résultat> = TCDCharge(<Champ Tableau croisé dynamique> , <Support de sauvegarde> [, <Mot de passe>])
```

`<Résultat>` *Booléen*
> - Vrai si le contenu du champ Tableau croisé dynamique a été chargé.
> - Faux dans le cas contraire
`<Champ Tableau croisé dynamique>` *Nom de champ*
> Nom du champ Tableau croisé dynamique à manipuler.
`<Support de sauvegarde>` *Chaîne de caractères ou Buffer*
> - Sauvegarde dans un fichier : Nom et chemin complet du fichier à charger. Ce fichier correspond à un fichier précédemment sauvé avec la fonction [TCDSauve](1000020471.md).
> - Sauvegarde en mémoire : Buffer de sauvegarde renvoyé par la fonction [TCDSauve](1000020471.md).
`<Mot de passe>` *Chaîne de caractères optionnelle ou Chaîne secrète*
> Mot de passe associé à la sauvegarde du champ Tableau croisé dynamique. Ce mot de passe a été spécifié lors de la sauvegarde du champ Tableau croisé dynamique avec la fonction [TCDSauve](1000020471.md).
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).

## Remarques

### Sauvegarde et chargement du contenu d'un champ Tableau croisé dynamique
Lorsque le champ Tableau croisé dynamique est calculé avec la fonction [TCDCalculeTout](1000020539.md), le résultat peut être sauvé avec la fonction [TCDSauve](1000020471.md). Il est ensuite possible de le recharger avec la fonction **TCDCharge** : dans ce cas, le contenu du champ Tableau croisé dynamique n'est pas recalculé.
