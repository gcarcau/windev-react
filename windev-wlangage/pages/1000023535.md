# Habillage (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **Habillage** permet de connaître et de modifier les caractéristiques d'habillage d'un élément. Cette propriété est utilisable sur :

- une variable de type [docElémentImage](1000022696.md).
- une variable de type [docElémentZoneDeTexte](1000023420.md).
