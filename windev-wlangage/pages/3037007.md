# FaxDéconnecte (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Ferme une connexion à un serveur de fax (précédemment ouverte avec la fonction [FaxConnecte](3037005.md)).
**Remarque** : Cette fonction ne peut être utilisée que sous Windows 2000, XP ou version supérieure. Sous Windows Vista (et supérieur), la gestion des fax est disponible uniquement avec Windows Professionnel et Windows Edition Intégrale.

## Exemple

```wlangage
IDConnect est un entier
IDConnect = FaxConnecte()
...
SI FaxDéconnecte(IDConnect) = Faux ALORS
	Erreur("La déconnexion a échoué.", ErreurInfo(errMessageSystème))
FIN
```

## Syntaxe

```wlangage
<Résultat> = FaxDéconnecte(<Identifiant connexion>)
```

`<Résultat>` *Booléen*
> - Vrai si la déconnexion a été effectuée,
> - Faux en cas d'erreur. Le message d'erreur correspondant peut être obtenu avec la fonction [ErreurInfo](3013008.md).
`<Identifiant connexion>` *Entier*
> Identifiant de la connexion obtenu avec la fonction [FaxConnecte](3037005.md).

**Composante : wd300com.dll**
