# IDToken (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (iPhone/iPad)

La propriété **IDToken** permet de connaître le token associé à une authentification. Cette propriété est disponible sur :

- une variable de type [OpenIDIdentité](1000023567.md),
- une variable de type [AppleID](1000025405.md).
