# Option,Version (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Connaît le numéro de version de wdxxxwm.dll de WINDEV.

## Exemple

```wlangage
// En CAPPELWD("Option,Version");strcpy(Version,WDChaine);
```

```wlangage
// En PascalAPPELWD('Option,Version');Version:=WdChaine;
```

```wlangage
// En VBcall APPELWD("Option,Version")Version=WdChaine
```

## Syntaxe

```wlangage
Option,Version()
```

## Remarques

Le numéro de version est contenu dans WdChaine sous la forme 9.99X (par exemple 1.05A).
