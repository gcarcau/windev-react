# Action (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

La propriété **Action** permet de spécifier l'action à réaliser. Cette propriété est utilisable sur :

- une variable de type [sfRequêteTraitementTâche](1000018520.md).
- une variable de type [sysNotification](1410087893.md).
- une variable de type [sysNotificationBouton](1410087947.md).
