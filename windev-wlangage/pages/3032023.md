# EmailRAZ (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Ré-initialise toutes les variables de la structure [email](3032029.md) ou d'une variable de type [Email](1000018713.md).

## Exemple

```wlangage
// Ré-initialiser toutes les variables de la structure email
EmailRAZ()
```

## Syntaxe

```wlangage
EmailRAZ([<Email>])
```

`<Email>` *Variable optionnelle de type Email*
> Nom de la variable [Email](1000018713.md) à réinitialiser. Si ce paramètre n'est pas spécifiée, la structure [Email](3032029.md) sera utilisée.
>
> > _(PHP)_ Ce paramètre n'est pas disponible.
