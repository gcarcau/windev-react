# SocketCréeInfraRouge (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Créé un socket utilisant le port infrarouge. Un socket est une ressource de communication utilisée par les applications pour communiquer d'une machine à une autre sans se soucier du type de réseau.
**Remarque** : Cette fonction doit être appelée sur le poste serveur utilisé pour la communication. Si le poste client utilise une application WINDEV pour se connecter à ce socket, cette application devra utiliser la fonction [SocketConnecteInfraRouge](3070018.md).

## Exemple

```wlangage
SI SocketCréeInfraRouge("Serveur", "Service") = Faux ALORS
	Erreur("Erreur création " + ErreurInfo(errMessage))
FIN
```

## Syntaxe

```wlangage
<Résultat> = SocketCréeInfraRouge(<Nom du socket> , <Nom du service>)
```

`<Résultat>` *Booléen*
> - Vrai si la fonction a réussi,
> - Faux dans le cas contraire. En cas d'erreur, il est possible de connaître le détail de l'erreur grâce à la fonction [ErreurInfo](3013008.md).
`<Nom du socket>` *Chaîne de caractères*
> Nom à donner au socket. Ce nom sera utilisé dans toutes les fonctions socket.
`<Nom du service>` *Chaîne de caractères*
> Nom à donner au service. Ce nom sera utilisé dans la fonction [SocketConnecteInfraRouge](3070018.md).

## Remarques

### Re-création de socket
Si un socket n'est pas fermé correctement par la fonction [SocketFerme](3070015.md) (redémarrage du poste par exemple), la recréation du socket peut être relativement longue. Il est en effet nécessaire d'attendre que le système libère le socket.

### Création de socket
Pour créer un socket sur un poste serveur, utilisez la fonction [SocketCrée](3070011.md).

### Protocole IRDA
La fonction **SocketCréeInfraRouge** utilise le protocole IRDA (Infrared Data Association).

### Limite Windows
Le nombre maximum de sockets infrarouge utilisés simultanément est 80.
