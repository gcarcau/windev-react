# LargeurPage (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **LargeurPage** permet de connaître et de modifier la largeur d'une page. Cette propriété est utilisable sur :

- une variable de type [docSection](1000022685.md).
- une variable de type [xlsMiseEnPage](1000023139.md).
