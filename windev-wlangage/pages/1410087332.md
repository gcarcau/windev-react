# <Variable JSON>.VersXML (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **Autres** (Procédures stockées)

Convertit une chaîne de caractères au format JSON en une chaîne de caractères au format XML.

## Exemple

```wlangage
soit json = ChaîneVersJSON("
{ "nom" : "TestName"
 ,"id" : 2
 ,"vrai" : "True"
 ,"liste" : [5,5,6,2,47]
}
")

soit xml = json.VersXML()
Trace(xml..SourceXML)

// Le résultat affiché sera
// <document>
//   <nom>TestName</nom>
//   <id>2</id>
//   <vrai>true</vrai>
//   <liste>
//     <item>5</item>
//     <item>5</item>
//     <item>6</item>
//     <item>2</item>
//     <item>47</item>
//   </liste>
// </document>
```

## Syntaxe

```wlangage
<Résultat> = <JSON à convertir>.VersXML([<Convertisseur>])
```

`<Résultat>` *Variable de type xmlNoeud*
> Variable de type xmlNoeud correspondant à la conversion de la chaîne de caractères au format JSON.
`<JSON à convertir>` *Variable de type JSON*
> Nom de la variable de type [JSON](1000023611.md) à convertir.
`<Convertisseur>` *Variable de type JSONXMLConvertisseur optionnelle*
> Nom de la variable de type [JSONXMLConvertisseur](1410087323.md) correspondant à la norme de conversion personnalisée à appliquer.
> Attention : Cette personnalisation nécessite une bonne connaissance du langage XML.
> Si ce paramètre n'est pas spécifié, une norme définie par défaut sera imposée lors de la conversion : les valeurs par défaut de la variable de type [JSONXMLConvertisseur](1410087323.md) sont utilisées.
