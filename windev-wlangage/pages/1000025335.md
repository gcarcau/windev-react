# TableauIntersection (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Renvoie un tableau correspondant à l'intersection de deux tableaux.
Les tableaux suivants peuvent être manipulés :

- Tableau d'éléments simples (entier, réel, chaîne de caractères) à une dimension.
- Tableau de structures à une dimension.

Nouveauté Abonnement

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
// Premier tableau d'entiers
tabMonTableau1 est un tableau d'entiers
TableauAjoute(tabMonTableau1, 1)
TableauAjoute(tabMonTableau1, 2)
TableauAjoute(tabMonTableau1, 1)
TableauAjoute(tabMonTableau1, 3)
// Second tableau d'entiers
tabMonTableau2 est un tableau d'entiers
TableauAjoute(tabMonTableau2, 3)
TableauAjoute(tabMonTableau2, 5)
TableauAjoute(tabMonTableau2, 8)
TableauAjoute(tabMonTableau2, 1)
// Tableau de l'intersection
tabMonIntersection est un tableau d'entiers
tabMonIntersection = TableauIntersection(tabMonTableau1, tabMonTableau2)
// le résultat est 3;1
```

## Syntaxe

```wlangage
<Résultat> = TableauIntersection(<Premier tableau WLangage> , <Second tableau WLangage>)
```

`<Résultat>` *Tableau*
> Variable de type Tableau contenant le résultat de l'intersection.
`<Premier tableau WLangage>` *Tableau*
> Nom de la variable de type Tableau correspondant au premier tableau à manipuler. Ce tableau doit être un tableau à une dimension. Ce tableau ne sera pas modifié.
`<Second tableau WLangage>` *Tableau*
> Nom de la variable de type Tableau correspondant au second tableau à manipuler. Ce tableau doit être un tableau à une dimension. Ce tableau doit être du même type que le tableau spécifié avec le paramètre <Premier tableau WLangage>. Ce tableau ne sera pas modifié.

## Remarques

- Si un tableau contient plusieurs doublons, ces doublons ne sont pas conservés.
- Si les tableaux sont triés, le tableau résultat n'est pas trié.
