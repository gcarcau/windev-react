# AuthDéconnecte (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android)

Déconnecte un utilisateur précédemment authentifié via :

- le protocole OAuth 2.0 sur un service Web quelconque.
- le protocole OpenID sur un service Web quelconque.
  Nouveauté 2025
   Cette syntaxe est désormais disponible en Android et Widget Android.
- un token JWT.

Remarques :

- La déconnexion ouvre un navigateur (comme pour la connexion). L'URL de redirection est appelée lorsque la déconnexion est effectuée. A la prochaine connexion, le processus de connexion devra être entièrement refait.
- Lors de l'utilisation d'une variable de type [OAuth2Paramètres](1000022212.md), il est nécessaire de spécifier l'URL de déconnexion avec la propriété **URLDéconnexion**.
- **Pour une configuration IOS**, cette fonction n'est pas disponible. Il est conseillé d'utiliser la fonction [AuthRévoqueToken](1410090634.md).

## Exemple

```wlangage
stOpenIdParam est un OpenIDParamètres
stOpenIdParam.URLConfiguration = "https://login.microsoftonline.com/99f49690-a048-4e6e-a51e-9e6e96b4981d/v2.0/.well-known/openid-configuration"
stOpenIdParam.ClientID = "99f10db4-c3b1-437f-8362-8070750f0190"
stOpenIdParam.Scope = "email openid"
stOpenIdParam.URLRedirection = "http://localhost:9874"
stToken est un AuthToken = AuthIdentifie(stOpenIdParam)
SI ErreurDétectée ALORS
	Erreur(ErreurInfo(errComplet))
	RETOUR
FIN
identite est une OpenIDIdentité = OpenIDLitIdentité(stToken)
SI ErreurDétectée ALORS
	Erreur(ErreurInfo(errComplet))
	RETOUR
FIN
Trace(identite.Email)
AuthDéconnecte(stToken)
```

## Syntaxe

#### Déconnexion d'un utilisateur authentifié par le protocole OAuth 2.0

```wlangage
<Résultat> = AuthDéconnecte(<Authentification OAuth>)
```

`<Résultat>` *Booléen*
> - Vrai si la déconnexion a été réalisée,
> - Faux dans le cas contraire.
`<Authentification OAuth>` *Variable de type OAuth2Paramètres*
> Nom de la variable de type [OAuth2Paramètres](1000022212.md) correspondant à la connexion à fermer. La propriété **URLDéconnexion** permet d'indiquer la page à afficher lors de la déconnexion.

#### Déconnexion d'un utilisateur authentifié par le protocole OAuth 2.0 (syntaxe asynchrone)

```wlangage
AuthDéconnecte(<Authentification OAuth> , <Procédure WLangage>)
```

`<Authentification OAuth>` *Variable de type OAuth2Paramètres*
> Nom de la variable de type [OAuth2Paramètres](1000022212.md) correspondant à la connexion à fermer. La propriété **URLDéconnexion** permet d'indiquer la page à afficher lors de la déconnexion.
`<Procédure WLangage>` *Nom de procédure*
> Procédure WLangage optionnelle qui sera appelée lors de la déconnexion. Cette procédure est de la forme :
>
>
> ```wlangage
> <Nom de la procédure>(<Déconnexion>)
> ```
>
>
>  où <Déconnexion> est un booléen permettant de savoir si la déconnexion a été effectuée (Vrai) ou non (Faux).

#### Déconnexion d'un utilisateur authentifié par le protocole OpenID

```wlangage
<Résultat> = AuthDéconnecte(<Authentification OpenID>)
```

`<Résultat>` *Booléen*
> - Vrai si la déconnexion a été réalisée,
> - Faux dans le cas contraire.
`<Authentification OpenID>` *Variable de type OpenIDParamètres*
> Nom de la variable de type [OpenIDParamètres](1000023561.md) correspondant à la connexion à fermer.

#### Déconnexion d'un utilisateur authentifié par le protocole OpenID (syntaxe asynchrone)

```wlangage
AuthDéconnecte(<Authentification OpenID> , <Procédure WLangage>)
```

`<Authentification OpenID>` *Variable de type OpenIDParamètres*
> Nom de la variable de type [OpenIDParamètres](1000023561.md) correspondant à la connexion à fermer.
`<Procédure WLangage>` *Nom de procédure*
> Procédure WLangage optionnelle qui sera appelée lors de la déconnexion. Cette procédure est de la forme :
>
>
> ```wlangage
> <Nom de la procédure>(<Déconnexion>)
> ```
>
>
>  où <Déconnexion> est un booléen permettant de savoir si la déconnexion a été effectuée (Vrai) ou non (Faux).

> _(Windows, Linux)_ Déconnexion d'un utilisateur authentifié via JWT Masquer les détails
<Résultat> = AuthDéconnecte(<Token de la connexion>)

 <Résultat> : BooléenVrai si la déconnexion a été réalisée, Faux dans le cas contraire. <Token de la connexion> : Variable de type AuthTokenNom de la variable de type AuthToken correspondant au token de la connexion.

> _(Windows, Linux)_ Déconnexion d'un utilisateur authentifié via JWT (syntaxe asynchrone) Masquer les détails
AuthDéconnecte(<Token de la connexion> , <Procédure WLangage>)

 <Token de la connexion> : Variable de type AuthTokenNom de la variable de type AuthToken correspondant au token de la connexion. <Procédure WLangage> : Nom de procédureProcédure WLangage optionnelle qui sera appelée lors de la déconnexion. Cette procédure est de la forme :

<NomProcédure>(<Déconnexion>)

 où <Déconnexion> est un booléen permettant de savoir si la déconnexion a été effectuée (Vrai) ou non (Faux).
