# <Variable Connexion>.MiseAJourVue (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Crée ou met à jour la description d'une vue SQL ou d'une vue matérialisée depuis l'analyse vers un serveur HFSQL.
Remarque : La mise à jour des données de la vue est réalisée grâce à la fonction [<Variable Connexion>.RafraîchitVue](1000023963.md).

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion

// Met à jour la description de la vue sur le serveur HFSQL
MaConnexion.MiseAJourVue(MaVue)
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.MiseAJourVue(<Vue> [, <Forcer>])
```

`<Résultat>` *Booléen*
> - Vrai si la vue (SQL ou matérialisée) a été créée ou mise à jour.
> - Faux en cas de problème. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion vers le serveur sur lequel la vue (SQL ou matérialisée) doit être créée ou mise à jour.
`<Vue>` *Chaîne de caractères*
> Nom de la vue (SQL ou matérialisée) à manipuler. Cette vue doit être créée ou mise à jour sur le serveur HFSQL.
`<Forcer>` *Booléen optionnel*
> - Faux (par défaut) : la vue sera créée ou mise à jour :
>   - si le serveur ne possède pas la vue.
>   - si le serveur possède une version plus ancienne de la vue.
> - Vrai : la vue sera mise à jour dans tous les cas.
