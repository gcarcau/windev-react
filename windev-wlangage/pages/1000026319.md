# <Variable htmlNoeud>.ChercheElémentParNom (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Cherche les éléments d'un noeud HTML dont l'attribut "name" correspond à une valeur spécifique.

## Exemple

```wlangage
d est un htmlNoeud
e est un tableau de htmlNoeud <- d.ChercheElémentParNom("Couleur1")
```

## Syntaxe

```wlangage
<Résultat> = <Elément à manipuler>.ChercheElémentParNom(<Nom>)
```

`<Résultat>` *Tableau*
> Tableau d'éléments de type [htmlNoeud](1000026081.md) correspondant à la recherche.
`<Elément à manipuler>` *Variable de type htmlNoeud*
> Nom de la variable de type [htmlNoeud](1000026081.md) dans laquelle la recherche doit être effectuée.
`<Nom>` *Chaîne de caractères*
> Valeur de l'attribut "name" recherché.
