# LargeurEtiquette (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

La propriété **LargeurEtiquette** permet de :

- Connaître la largeur des étiquettes d'un état de type "Étiquette".
- Modifier la largeur des étiquettes d'un état de type "Étiquette".

**Remarque** : La largeur des étiquettes a été définie lors de la création de l'état au format étiquette. Cette option peut être connue et/ou modifiée sous l'éditeur d'états dans l'option "Format des étiquettes" dans le menu contextuel de l'état.

## Exemple

```wlangage
// Augmente la largeur des étiquettes de l'état "ETAT_EtiqClient"
ETAT_EtiqClient.LargeurEtiquette = ETAT_EtiqClient.LargeurEtiquette + 35
// Est équivalent à : ETAT_EtiqClient.LargeurEtiquette += 35
```

## Syntaxe

#### Connaître la largeur des étiquettes

```wlangage
<Résultat> = <Etat manipulé>.LargeurEtiquette
```

`<Résultat>` *Réel*
> Largeur (en millimètres) des étiquettes de l'état spécifié.
`<Etat manipulé>` *Nom d'état*
> Nom de l'état de type "Étiquette" à manipuler.

#### Modifier la largeur des étiquettes

```wlangage
<Etat manipulé>.LargeurEtiquette = <Nouvelle largeur>
```

`<Etat manipulé>` *Nom d'état*
> Nom de l'état de type "Étiquette" à manipuler.
`<Nouvelle largeur>` *Réel*
> Nouvelle largeur (en millimètres) des étiquettes de l'état spécifié.

## Remarques

### Etat de type "Étiquette"

- Pour connaître ou modifier la hauteur des étiquettes d'un état de type "Étiquette", utilisez la propriété [HauteurEtiquette](2511069.md).
- Pour connaître ou modifier l'espacement horizontal entre les étiquettes d'un état de type "Étiquette", utilisez la propriété [EspaceH](2511067.md).
- Pour connaître ou modifier l'espacement vertical entre les étiquettes d'un état de type "Étiquette", utilisez la propriété [EspaceV](2511065.md).
- Pour connaître ou modifier le nombre d'étiquettes imprimées sur la largeur d'une page, utilisez la propriété [NbEtiquette](2511050.md).

### Limite
La propriété **LargeurEtiquette** s'applique uniquement aux états de type "Étiquette".
