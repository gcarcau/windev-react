# Manipulations d'un champ Graphe dans un site WEBDEV

> **Disponible :** **WEBDEV** (Windows, Linux, PHP)

## Présentation

Lors de l'exécution d'un champ Graphe dans une page d'un site WEBDEV, l'internaute dispose d'un menu contextuel permettant de modifier la présentation du graphe affiché.
[image: Barre d'outils des graphes en Web]

## Fonctionnalités du menu contextuel

Le menu contextuel d'un champ Graphe permet de choisir le type de graphe à afficher. Il est possible de :

- afficher le graphe sous forme d'un graphe en secteur :
  - Secteur,
  - Hémicycle,
  - Donut,
  - Entonnoir.
- afficher le graphe sous forme d'histogramme :
  - Histogramme groupé, empilé, horizontal groupé, horizontal empilé,
  - Waterfall.
- afficher le graphe sous forme de :
  - courbe,
  - nuage de points,
  - aire,
  - radar,
  - bulles.
- afficher le graphe sous forme de graphe boursier :
  - chandelier japonais,
  - BarCharts,
  - Minimum Maximum.

Ce menu contextuel permet également :

- d'afficher ou non le quadrillage horizontal ou vertical.
- d'afficher ou non la légende et de gérer sa position.
- de gérer les effets de lissage, dégradé, relief, crénelage et transparence.
- d'afficher au choix une bulle en survol des valeurs, une mire ou une mire multiple.
- d'afficher ou non les animations.
- d'activer ou non l'interactivité du graphe.
- d'enregistrer ou d'imprimer le graphe.

## Mettre en place le menu contextuel

Par défaut, lors de la création d'un champ Graphe, le menu contextuel est affiché en mode automatique.
Pour configurer l'affichage du menu contextuel :

1. Affichez la fenêtre de description du champ Graphe.
2. Dans l'onglet "Détail", dans la zone "Interactivité", il est possible de sélectionner dans le champ "Menu contextuel" :
  - le mode d'affichage : jamais, automatique ou toujours visible.
  - les options affichées par la barre d'outils (bouton "...").
3. Validez la fenêtre de description du champ.
