# L'éditeur de requêtes Utilisateur : Spécificités

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes)

## Présentation

Cette page d'aide présente les spécificités de l'éditeur de requêtes Utilisateur :

- Type de requêtes
- Source de données de l'état.
- Volets verticaux.

**Remarque** : L'icône suivante  (présent dans l'aide en ligne) permet d'indiquer les différences entre l'éditeur de requêtes Utilisateur et l'éditeur de requêtes intégré.

## Spécificités

### Type de requêtes
Sous l'éditeur de requêtes Utilisateur, il n'est pas possible de créer :

- des requêtes d'insertion.
- des requêtes de modification.
- des requêtes de suppression.
- des requêtes en code SQL utilisant les ordres suivants : [INSERT](2034001.md), [UPDATE](2034001.md), [DELETE](2034001.md)

**Rappel** : L'éditeur de requêtes Utilisateur ne permet pas de modifier la base de données du projet en cours.

### Source de données d'une requête
Les fichiers et les rubriques pouvant être utilisés dans une requête sont définis sous l'éditeur d'analyses de WINDEV. Pour plus de détails sur la préparation nécessaire à l'utilisation d'une application WINDEV avec le logiciel Etats & Requêtes, consultez [Diffuser le logiciel Etats & Requêtes](3088002.md).

### Volets ancrables
Sous l'éditeur de requêtes Utilisateur, les volets ancrables permettent d'accéder uniquement :

- aux principales fonctionnalités de l'éditeur de requêtes Utilisateur.
- aux éléments accessibles (états, requêtes, ...) de votre projet.

Pour plus de détails sur les volets ancrables, consultez [Volets ancrables](2027001.md).
