# Déplacer

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Déplacer** permet d'autoriser ou non le déplacement d'un élément. Cette propriété est disponible sur :

- une variable de type [diagActionAutorisée](1410088840.md).
- une variable de type [kbActionAutorisée](1410089541.md).
