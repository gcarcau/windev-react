# Avancement (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android)

La propriété **Avancement** permet de connaître l'état d'avancement d'une tâche. Cette propriété est utilisable sur :

- une variable de type [TâcheGantt](1000020881.md).
- une variable de type [TéléchargementInfo](1410087306.md).
- Nouveauté SaaS
   une variable de type [sysNotificationJauge](1410090964.md).
- Nouveauté SaaS
  une variable de type [hHistoriqueRéindexation](1410091059.md).
