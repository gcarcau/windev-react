# SysListeCarteGraphique (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Renvoie le nom des cartes graphiques connectées au poste en cours.

## Exemple

```wlangage
// Récupération des différentes cartes graphiques du PC en cours
ListeAjoute(LISTE_Ecran, SysListeCarteGraphique())
```

## Syntaxe

```wlangage
<Résultat> = SysListeCarteGraphique()
```

`<Résultat>` *Chaîne de caractères*
> Liste des cartes graphiques du poste en cours, chaîne vide ("") en cas d'erreur. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de renseignements sur le problème rencontré.
> Cette liste est du type :
>
>
> ```wlangage
> <Nom de l'écran 1> + TAB + <Nom de la carte graphique 1> + RC + <Nom de l'écran 2> + TAB + <Nom de la carte graphique 2> + RC + ... + RC + <Nom de l'écran N>+ TAB + <Nom de la carte graphique N>
> ```
>
> Par exemple :
>
>
> ```wlangage
> \\.\DISPLAY1<TAB>NVIDIA GeForce 210 <\r><\n>\\.\DISPLAY2<TAB>NVIDIA GeForce 210
> ```

## Remarques

### Connaître les écrans liés à une carte graphique
Pour connaître les écrans associés à une carte graphique, utilisez la fonction [SysListeEcran](1000017014.md).
