# Vertical (Propriété)

> **Disponible :** **WINDEV** (Windows, Java) · **WEBDEV** (Windows, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

La propriété **Vertical** permet de :

- Savoir si un champ est horizontal ou vertical.
- Modifier le sens d'affichage des champs Table. Un champ Table peut être affiché verticalement (mode classique) ou horizontalement. Dans ce cas, les colonnes du mode classique deviennent les lignes du champ Table.
- Modifier le sens d'affichage des champs Zone répétée. Un champ Zone répétée peut être affiché verticalement (mode classique) ou horizontalement.

**Remarques** :

- Le sens d'orientation d'un champ est défini dans l'onglet "Général" de la description du champ.
- La propriété **Vertical** est utilisable uniquement sur les champs de type Jauge.
- La propriété **Vertical** est disponible uniquement pour les champs Planning.
- Dans un état, la propriété **Vertical** permet de connaître l'orientation du champ Jauge.

## Exemple

> _(WINDEV)_ // Connaître le sens d'orientation du champ "ASC_Ascenseur"
ResSens = ASC_Ascenseur.Vertical

> _(WINDEV)_ // Passer le champ Table TABLE_Client en affichage horizontal
TABLE_Client.Vertical = Faux

## Syntaxe

#### Connaître le sens d'orientation des champs

```wlangage
<Résultat> = <Champ manipulé>.Vertical
```

`<Résultat>` *Booléen*
> - Vrai si le champ spécifié est vertical,
> - Faux si le champ spécifié est horizontal.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.

> _(WINDEV)_ Modifier le sens d'orientation des champs Table Masquer les détails
<Champ Table>.Vertical = <Nouveau sens>

 <Champ Table> : Nom de champNom du champ Table à manipuler. <Nouveau sens> : BooléenVrai si le champ Table doit être affichée verticalement (mode d'affichage classique des champs Table), Faux si le champ Table doit être affichée horizontalement.

> _(WINDEV)_ Modifier le sens d'orientation des champs Zone répétée Masquer les détails
<Champ Zone répétée>.Vertical = <Nouveau sens>

 <Champ Zone répétée> : Nom de champNom du champ Zone répétée à manipuler. <Nouveau sens> : BooléenVrai si le champ Zone répétée doit être affiché verticalement (mode d'affichage classique des champs Zone répétée), Faux si le champ Zone répétée doit être affichée horizontalement.

## Remarques

### Limites

> _(WINDEV, WINDEV, WINDEV, WINDEV)_ La propriété Vertical s'applique uniquement aux :champs Jauge.champs Spin.champs Potentiomètre.champs Ascenseur.champs Séparateur.champs Carrousel.champs Table. champs Range slider. champs Planning. champs Zone répétée.

> _(Java)_ La propriété Vertical s'applique uniquement aux champs Jauge.

> _(WEBDEV - Code Serveur, PHP)_ La propriété Vertical s'applique uniquement aux champs Planning.
