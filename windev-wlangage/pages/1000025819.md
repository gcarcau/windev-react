# <Carte>.PopupAffichée (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Permet de savoir si la popup d'un marqueur du champ Carte est affichée.

## Exemple

```wlangage
MonMarqueur est un Marqueur SI CARTE_MaCarte.popupAffichée(MonMarqueur) ALORS  ...FIN
```

## Syntaxe

```wlangage
<Résultat> = <Champ Carte>.PopupAffichée(<Marqueur>)
```

`<Résultat>` *Booléen*
> - Vrai si la popup du marqueur est affichée,
> - Faux dans le cas contraire.
`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler.
`<Marqueur>` *Variable de type Marqueur*
> Nom de la variable de type [Marqueur](1000019940.md) dont on veut savoir si une popup est affichée.

## Remarques

- Pour afficher la popup, utilisez la fonction [<Carte>.AffichePopup](1000025799.md).
- Pour fermer la popup, utilisez la fonction [<Carte>.FermePopup](1000025803.md).
