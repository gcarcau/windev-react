# <VisiteGuidée>.Info (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Renvoie des informations sur une visite guidée.

## Exemple

```wlangage
VisiteDécouverte est un VisiteGuidée
// Affiche la visite guidée uniquement au premier lancement
SI VisiteDécouverte.Info(vgInfoOccurrence) = 0 ALORS
	VisiteDécouverte.Démarre()
FIN
```

```wlangage
VisiteDécouverte est un VisiteGuidée
// Affiche la visite guidée 1 fois par jour max et 5x max
SI VisiteDécouverte.Info(vgInfoDate) < DateSys() _ET_ VisiteDécouverte.Info(vgInfoOccurrence) < 5 ALORS
	VisiteDécouverte.Démarre()
FIN
```

```wlangage
// Affiche les nouveautés d'une version
VisiteNouveauté est un VisiteGuidée
VisiteNouveauté.Identifiant = "Nouveauté de la version"
VisiteNouveauté.Version = 29
SI VisiteNouveauté.Info(vgInfoVersion) < 29 ALORS
	VisiteNouveauté.Étape[1].Cible = SAI_Prénom
	VisiteNouveauté.Étape[1].Titre = "Nouveau !"
	VisiteNouveauté.Étape[1].Description = "Vous pouvez maintenant saisir votre prénom"
	VisiteNouveauté.Démarre()
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Visite guidée>.Info(<Information>)
```

`<Résultat>` *Type de l'information*
> Information demandée.
`<Visite guidée>` *Variable de type VisiteGuidée*
> Nom de la variable de type [VisiteGuidée](1410090170.md) correspondant à la visite guidée manipulée.
`<Information>` *Constante de type Entier*
> Information recherchée :
>
> | *vgInfoDate* | Date à laquelle la visite guidée a été vue pour la dernière fois sur le poste en cours. |
> | --- | --- |
> | *vgInfoOccurrence* | Nombre de fois où l'utilisateur a vu la visite guidée. |
> | *vgInfoVersion* | Numéro de version de la dernière visite guidée vue par l'utilisateur. |

**Classification Métier / UI : Code UI**

**Composante : wd300mdl.dll**
