# <Source>.SourceDeDonnéesConnue (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Permet de savoir si une source de données est initialisée. Cette fonction permet d'éviter une erreur du type "Vous avez appelé la fonction XXX. La source de données YYY n'est pas initialisée".
**Différence avec la fonction [<Source>.RequêteExécutée](1410090480.md)** : La fonction **<Source>.SourceDeDonnéesConnue** permet de savoir si la source de données est connue du moteur HFSQL, quelque soit son contenu. La fonction [<Source>.RequêteExécutée](1410090480.md) est utilisable uniquement sur les requêtes.

## Exemple

```wlangage
MaVue est une Source de Données
// MaVue est associée à une vue

SI MaVue.SourceDeDonnéesConnue() = Faux ALORS
	// Initialisation de la variable MaVue
	MaVue.CréeVue(CLIENT, "*", "NOM,VILLE", "NOM]='A'", hVueDéfaut)
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Source de données à vérifier>.SourceDeDonnéesConnue()
```

`<Résultat>` *Booléen*
> - Vrai si la source de données a été initialisée,
> - Faux dans le cas contraire. La fonction [HErreurInfo](3044071.md) permet d'obtenir plus d'informations sur le problème rencontré.
`<Source de données à vérifier>` *Variable de type Source de Données*
> Variable de type [Source de Données](1514053.md) à vérifier. Cette source de données peut correspondre à :
>
> - un fichier de données externe,
> - une requête SQL,
> - une vue.

## Remarques

### Comment initialiser une variable de type Source de Données
L'initialisation d'une variable de type Source de Données dépend de son contenu :

- Fichier de données externe : il est nécessaire d'utiliser la fonction [<Source>.DéclareExterne](1000024214.md).
- Requête et requête SQL : il est nécessaire d'utiliser les fonctions [<Source>.ExécuteRequête](1000024944.md), [<Source>.ExécuteRequêteSQL](1000024948.md), etc.
- Vue HFSQL : Il est nécessaire d'utiliser la fonction [<Source>.CréeVue](1000024209.md).

Pour plus de détails, consultez l'aide du type [Source de Données](1514053.md).
