# Activation des types Nullables

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

L'activation des types nullables entraîne de nombreuses modifications dans la gestion du Null effectuée par votre projet.
L'activation sur un projet existant n'est pas recommandée. De nombreuses modifications sont à effectuer aussi bien au niveau de l'analyse qu'au niveau du code de votre application.

Cette page liste les principales différences entre la nouvelle et l'ancienne gestion du Null.

## Différences de comportements dues à l'activation des valeurs nullables

En cochant l'option "Autoriser les types nullables", différentes fonctionnalités sont activées. Ces fonctionnalités changent la programmation de la gestion du Null :

- [Stockage de la valeur Null dans une variable : définition d'un type nullable](1511031.md).
- [Savoir si un élément est null](1511031.md).
- [Récupérer la valeur d'un élément qui autorise le Null](1511031.md).
- [Utilisation du Null dans les fonctions WLangage](1511031.md).
- [Utilisation du Null dans les procédures](1511031.md).
- [Opérations réalisables sur des variables autorisant le Null](1511031.md).
- [Gestion du Null dans les rubriques HFSQL](3044187.md).
