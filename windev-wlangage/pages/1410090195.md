# PageEcritCodeHTTPPersonnalisé (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux)

Renseigne le code HTTP personnalisé qui sera retourné au client à la fin de l'exécution du code serveur de la page. Cette fonction permet de spécifier n'importe quel code entre 100 et 599, y compris les codes de retour suivants :

- Codes 2xx pour gérer le **Succès** d'exécution d'une fonction.
- Codes 3xx pour gérer la **Redirection** d'une fonction.
- Codes 4xx pour gérer une **Erreur du client**.
- Codes 5xx pour gérer une **Erreur du serveur**.

## Exemple

```wlangage
// Indique une erreur de token
PageEcritCodeHTTPPersonnalisé("498 Invalid Token")
```

## Syntaxe

```wlangage
PageEcritCodeHTTPPersonnalisé(<Code HTTP et libellé>)
```

`<Code HTTP et libellé>` *Chaîne de caractères*
> Code HTTP suivi de son libellé retourné par l'appel courant. Le format attendu est le suivant :
>
>
> ```wlangage
> <code HTTP> <Libellé>
> ```
>
>
> Par exemple "498 Invalid Token". Les codes acceptés sont compris entre 100 et 599.

## Remarques

Le code transmis par la fonction **PageEcritCodeHTTPPersonnalisé** est ignoré :

- En cas d'erreur (code 4xx et 5xx) ou de redirection (code 3xx).
- Dans un appel AJAX.
