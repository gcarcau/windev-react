# Constantes des fonctions de géolocalisation

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Les constantes utilisées par les fonctions de géolocalisation sont les suivantes :

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |
| **géoCarte2D** | La position est affichée sur une carte en deux dimensions dans l'application de cartographie native de l'appareil. | [géoLanceAppli](1000019954.md) |
| **géoKilomètre** | Renvoie la distance en kilomètres. | [géoDistance](1000019211.md) |
| **géoMètre** | Renvoie la distance en mètres. | [géoDistance](1000019211.md) |
| **géoMile** | Renvoie la distance en miles. | [géoDistance](1000019211.md) |
| **géoSuiviActivé** | Etat du système de suivi : Le système de suivi de position est activé. | [géoSuiviEtat](1000021592.md) |
| **géoSuiviDésactivé** | Etat du système de suivi : Le système de suivi de position est désactivé. | [géoSuiviEtat](1000021592.md) |
| **géoSuiviErreur** | Etat du système de suivi : Erreur pendant la récupération de l'état d'activation du système. Utilisez la fonction [ErreurInfo](3013008.md) pour obtenir le détail de l'erreur. | [géoSuiviEtat](1000021592.md) |
| **géoVue360** | La position est affichée sous forme d'image avec une vue à 360° dans l'application de cartographie native de l'appareil. | [géoLanceAppli](1000019954.md) |
| **gpsActivé** | Le fournisseur de localisation est activé. | [GPSEtat](1000019207.md) |
| **gpsAltitude** | Le fournisseur de localisation fournit des informations d'altitude. | [GPSInitParamètre](1000019204.md), [GPSInfo](1000019208.md) |
| **gpsAuto** | Détermination automatique du fournisseur de localisation. | [GPSInitParamètre](1000019204.md) |
| **gpsDésactivé** | Le fournisseur de localisation est désactivé. | [GPSEtat](1000019207.md) |
| **gpsDirection** | Le fournisseur de localisation fournit des informations de direction. | [GPSInitParamètre](1000019204.md), [GPSInfo](1000019208.md) |
| **gpsDisponible** | Le fournisseur de localisation est devenu disponible. | [GPSEtat](1000019207.md) |
| **gpsEnergie** | Demande des informations sur la consommation énergétique du fournisseur de localisation. | [GPSInfo](1000019208.md) |
| **gpsEnergieElevée** | Le fournisseur de localisation peut requérir une quantité d'énergie élevée de la part de l'appareil. | [GPSInitParamètre](1000019204.md), [GPSInfo](1000019208.md) |
| **gpsEnergieFaible** | Le fournisseur de localisation doit requérir une quantité d'énergie faible de la part de l'appareil. | [GPSInitParamètre](1000019204.md), [GPSInfo](1000019208.md) |
| **gpsEnergieMoyenne** | Le fournisseur de localisation peut requérir une quantité d'énergie moyenne de la part de l'appareil. | [GPSInitParamètre](1000019204.md), [GPSInfo](1000019208.md) |
| **gpsErreur** | Une erreur s'est produite lors de la récupérationde l'état du fournisseur de localisation. | [GPSEtat](1000019207.md) |
| **gpsErreurDroit** | Le navigateur n'a pas les droits pour utiliser la géolocalisation. | [GPSRécupèrePosition](1000019205.md), [GPSSuitDéplacement](1000019206.md) |
| **gpsErreurOK** | Aucune erreur n'a été détectée. | [GPSRécupèrePosition](1000019205.md), [GPSSuitDéplacement](1000019206.md) |
| **gpsErreurPosition** | Impossible de déterminer la position (erreur interne du fournisseur d'accès par exemple). | [GPSRécupèrePosition](1000019205.md), [GPSSuitDéplacement](1000019206.md) |
| **gpsErreurTimeout** | La position n'a pas pu être récupérée dans le temps imparti. | [GPSRécupèrePosition](1000019205.md), [GPSSuitDéplacement](1000019206.md) |
| **gpsHorsService** | Le fournisseur de localisation est hors service. | [GPSEtat](1000019207.md) |
| **gpsIndisponible** | Le fournisseur de localisation est devenu temporairement indisponible. | [GPSEtat](1000019207.md) |
| **gpsPrécision** | Demande des informations sur la précision de mesure du fournisseur de localisation. | [GPSInfo](1000019208.md) |
| **gpsPrécisionElevée** | Calcul de position avec une précision élevée. | [GPSInitParamètre](1000019204.md), [GPSInfo](1000019208.md) |
| **gpsPrécisionFaible** | Calcul de position avec une précision faible. | [GPSInitParamètre](1000019204.md), [GPSInfo](1000019208.md) |
| **gpsRéseau** | Calcul de la position en utilisant le réseau d'antenne mobile ou Wi-Fi. | [GPSInitParamètre](1000019204.md), [GPSInfo](1000019208.md) |
| **gpsSatellite** | Calcul de la position en utilisant le système GPS. | [GPSInitParamètre](1000019204.md), [GPSInfo](1000019208.md) |
| **gpsType** | Demande des informations sur le type de fournisseur de localisation. | [GPSInfo](1000019208.md) |
| **gpsVitesse** | Le fournisseur de localisation fournit des informations de vitesse. | [GPSInitParamètre](1000019204.md), [GPSInfo](1000019208.md) |
