# fCréeLien (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **Autres** (Procédures stockées)

Crée un lien sur un fichier à l'emplacement spécifié. Ce lien peut être :

- un lien symbolique (fichier lnk).
- un lien physique. Ce lien peut avoir ou non le même nom que le fichier d'origine. Le lien physique permet de faire apparaître un même fichier à plusieurs emplacements.

**Remarques** :

- Pour supprimer un lien (symbolique ou physique), utilisez la fonction [fSupprime](3036029.md).
- Pour créer un raccourci sur le bureau de Windows, dans le menu "Démarrer" de Windows ou dans un répertoire spécifique, utilisez la fonction [CréeRaccourci](3014008.md).

## Exemple

```wlangage
// Création d'un lien symbolique (fichier lnk)
fCréeLien("C:\temp\lisezmoi.txt", "C:\lisezmoi.lnk", fLienSymbolique)

// Création d'un lien physique
fCréeLien("C:\temp\lisezmoi.txt", "C:\lisezmoi.doc", fLienPhysique)
```

## Syntaxe

```wlangage
<Résultat> = fCréeLien(<Fichier pointé> , <Destination du lien> , <Type de lien> [, <Ligne de commande> [, <Répertoire de travail>]])
```

`<Résultat>` *Booléen*
> - Vrai si le lien a été créé,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Fichier pointé>` *Chaîne de caractères*
> Chemin complet du fichier vers lequel le lien doit pointer.
`<Destination du lien>` *Chaîne de caractères*
> Chemin et nom du fichier correspondant au lien à créer. L'extension du lien doit être précisée.
`<Type de lien>` *Constante de type Entier*
> Type de lien à créer :
>
> | *fLienPhysique* | Création d'un lien physique.  Un lien physique est un fichier accessible par plusieurs chemins. La suppression du fichier est possible uniquement lorsque tous les liens physiques ont été supprimés. **Attention** : Le <Fichier pointé et la <Destination du lien doivent être sur le même disque. |
> | --- | --- |
> | *fLienSymbolique* | Création d'un lien symbolique.  Un lien symbolique est un "pointeur" vers un fichier. La suppression du lien symbolique n'affecte pas le fichier pointé. La suppression du fichier pointé rend le lien symbolique invalide. _(Linux)_ Seul le propriétaire du fichier peut créer un lien symbolique. _(PHP)_ Pour créer un lien symbolique, le système utilisé doit être Windows Vista ou supérieur. _(Windows)_ Sous Windows 10, pour créer un lien symbolique, l'utilisateur doit être administrateur du poste. |
`<Ligne de commande>` *Chaîne de caractères optionnelle*
> Ligne de commande du lien. Ce paramètre est pris en compte uniquement lors de la création d'un lien symbolique.
>
> > _(Linux, PHP)_ Ce paramètre n'est pas disponible.
`<Répertoire de travail>` *Chaîne de caractères optionnelle*
> Répertoire de travail du lien. Ce paramètre est pris en compte uniquement lors de la création d'un lien symbolique.
>
> > _(Linux, PHP)_ Ce paramètre n'est pas disponible.

## Remarques

- Sous Windows, les liens peuvent être créés uniquement sur des disques formatés en NTFS.
- Pour que la fonction **fCréeLien** fonctionne, il est nécessaire d'exécuter le site PHP dans IIS avec une élévation de droits
- Si le système utilisé correspond à Windows Vista ou supérieur, il est nécessaire d'utiliser un serveur PHP supérieur à la version 5.3.

**Composante : wd300std.dll**
