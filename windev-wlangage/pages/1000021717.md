# Filtre

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Apple Watch)

Le mot-clé **Filtre** peut correspondre à :

- la fonction [Filtre](1000024845.md) qui renvoie un tableau contenant les éléments d'un tableau source pour lesquels une procédure renvoie Vrai.
- la propriété **Filtre** permet de connaître et de modifier les caractéristiques d'un filtre.
  Cette propriété est utilisable sur :
  - les champs Liste, Combo, Table fichier. Pour plus de détails, consultez l'aide de la propriété [Filtre](2510042.md).
  - une variable de type [hbParamètreScan](1000021715.md).
  - une variable de type [mongoOpérationModificationUn](1410089164.md).
  - une variable de type [mongoOpérationModificationTout](1410089165.md).
  - une variable de type [mongoOpérationRemplacementUn](1410089166.md).
  - une variable de type [mongoOpérationSuppressionTout](1410089162.md).
  - une variable de type [mongoOpérationSuppressionUn](1410089161.md).
