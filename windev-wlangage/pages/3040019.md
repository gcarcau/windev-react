# FTPNom (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie le nom du dernier fichier accédé par une fonction FTP (File Transfer Protocol).
**Remarque** : La fonction **FTPNom** est utile notamment lors d'un parcours de fichiers sur un serveur FTP au moyen de la fonction [FTPListeFichier](3040018.md).

Nouveauté Abonnement
Une nouvelle syntaxe manipulant une variable de type [ftpConnexion](1410090869.md) est disponible.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
// Nom du dernier fichier accédé par une fonction FTP
ResNom = FTPNom()
```

Nouveauté Abonnement

```wlangage
// Syntaxe non disponible en PHP
// Connexion du poste en cours au serveur FTP
MaConnexionFTP est une ftpConnexion
MaConnexionFTP.Serveur = "192.54.12.8"
FTPConnecte(MaConnexionFTP)

// Nom du dernier fichier accédé par une fonction FTP
ResNom = FTPNom(MaConnexionFTP)
```

## Syntaxe
Nouveauté Abonnement

> Syntaxe non disponible en PHP

Connaître le nom du dernier fichier accédé (connexion via un variable ftpConnexion) Masquer les détails
<Résultat> = FTPNom(<Connexion FTP>)

 <Résultat> : Chaîne de caractèresNom du dernier fichier accédé par une fonction FTP. Ce fichier a été modifié par une des fonctions FTP suivantes : FTPAttribut, FTPDate, FTPHeure, FTPTaille, FTPListeFichier. Chaîne vide ("") en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction ErreurInfo avec la constante errMessage. <Connexion FTP> : Variable de type ftpConnexionNom de la variable de type ftpConnexion décrivant les caractéristiques de la connexion au serveur FTP. Attention : Ce type de variable est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2. Pour plus de détails, consultez Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement.

#### Connaître le nom du dernier fichier accédé (connexion via l'identifiant de la connexion au serveur FTP)

```wlangage
<Résultat> = FTPNom()
```

`<Résultat>` *Chaîne de caractères*
> - Nom du dernier fichier accédé par une fonction FTP. Ce fichier a été modifié par une des fonctions FTP suivantes : [FTPAttribut](3040006.md), [FTPDate](3040015.md), [FTPHeure](3040013.md), [FTPTaille](3040007.md), [FTPListeFichier](3040018.md).
> - Chaîne vide ("") en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.

## Remarques

### Requête au serveur FTP
La fonction **FTPNom** ne provoque pas l'envoi d'une requête au serveur FTP.

### Délai
Par défaut, toutes les fonctions FTP échouent si aucune réponse du serveur FTP n'est reçue après 20 secondes. Ce délai peut être modifié :

- lors de la connexion au serveur FTP avec la fonction [FTPConnecte](3040016.md) (paramètre <Durée de non réponse>).
- Nouveauté Abonnement
  lors de la définition des paramètres de la variable [ftpConnexion](1410090869.md) (propriété **DuréeNonRéponse**).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

### Droits des utilisateurs
La demande d'informations sur des fichiers ou répertoires présents sur un serveur FTP n'est possible que pour un utilisateur ayant les droits en lecture sur le serveur FTP. En règle générale, les utilisateurs "anonymes" ont les droits en lecture.

> _(Android, Widget Android)_ Permissions requisesL'utilisation de cette fonction entraîne la modification des permissions requises par l'application. Permission requise : INTERNET Cette permission autorise l'application à ouvrir des sockets réseau.
