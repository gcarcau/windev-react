# telOrigine (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Permet de connaître l'origine d'un appel (appel entrant, appel sortant, etc.).

## Syntaxe

```wlangage
<Résultat> = telOrigine([<Identifiant de l'appel>])
```

`<Résultat>` *Constante de type Entier*
> Origine de l'appel.
>
> | *telOrigineAppelConférence* | Appel en mode conférence (à plusieurs). |
> | --- | --- |
> | *telOrigineAppelEntrant* | Appel entrant : communication provenant de l'extérieur.  L'utilisation de cette variable dépend du type de matériel utilisé, du driver, ... |
> | *telOrigineAppelExterne* | Appel provenant de l'extérieur.  L'utilisation de cette variable dépend du type de matériel utilisé, du driver, ... |
> | *telOrigineAppelInconnue* | Appel d'origine indéterminée.  L'utilisation de cette variable dépend du type de matériel utilisé, du driver, ... |
> | *telOrigineAppelIndisponible* | Appel d'origine indéterminée.  L'utilisation de cette variable dépend du type de matériel utilisé, du driver, ... |
> | *telOrigineAppelInterne* | Appel interne au PABX |
> | *telOrigineAppelSortant* | Appel sortant : communication effectuée vers l'extérieur. |
`<Identifiant de l'appel>` *Entier optionnel*
> Identifiant de l'appel à manipuler. Cet identifiant est connu dans la procédure WLangage appelée par la fonction [telDémarreDétectionAppel](3076029.md).

## Remarques

### Configuration nécessaire
Les fonctions de téléphonie utilisent la technologie TAPI 2.0 et/ou la technologie TAPI 3.1. Ces technologies sont utilisables sur tous les systèmes.

**Composante : wd300com.dll**
