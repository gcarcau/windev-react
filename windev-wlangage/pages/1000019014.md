# Note (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Note** permet de connaître et de modifier un texte libre associé à un élément. Cette propriété est utilisable sur :

- Les fenêtres, les pages ou les champs. Pour plus de détails, consultez [Note](2510085.md).
- une variable de type [EvénementTimeline](1000020612.md).
- une variable de type [RendezVous](1000019244.md).
- une variable de type [OrgaElément](1000019713.md).
- une variable de type [Contact](1000020254.md).
- une variable de type [Marqueur](1000019940.md).
- une variable de type [websocketClient](1000025952.md).
- une variable de type [diagForme](1410088082.md).
- une variable de type [sysNotification](1410087893.md).
- une variable de type [sysNotificationBouton](1410087947.md).
- une variable de type [ActionRapide](1410090054.md).
