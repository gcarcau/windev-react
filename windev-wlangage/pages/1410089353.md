# Canada.VérifieNE9 (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un numéro NE9 (numéro d'entreprise à 9 chiffres servant à identifier une entreprise au Canada).

## Exemple

```wlangage
// Test d'une variableMonNuméroNE9 est une chaîne = "887471886"Canada.VérifieNE9(MonNuméroNE9)  // renvoie Vrai // Test d'un champSAI_NuméroNE9 = "ABC"Canada.VérifieNE9(SAI_NuméroNE9) // renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = Canada.VérifieNE9(<Numéro à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un numéro NE9 valide.
> - Faux dans le cas contraire.
`<Numéro à vérifier>` *Nom de champ ou variable de type chaîne*
> Numéro NE9 à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.

**Composante : wd300std.dll**
