# Fonctionnalités Automatiques de vos Applications (FAA)

> **Disponible :** **WINDEV** (Windows)

## Présentation

Les Fonctionnalités Automatiques de vos Applications (FAA) permettent d'ajouter des fonctionnalités à votre application sans aucune ligne de code. Il suffit de cocher les options appropriées afin de bénéficier de ces fonctionnalités.
Voici quelques exemples de FAA disponibles :

- [Générer une aide pour votre application](2010030.md).
- [Utiliser des boutons minuterie](9500100.md).
- [Faire des recherches multichamps](9500101.md).
- [Proposer le correcteur orthographique (OpenOffice) dans les champs de saisie et les colonnes de table](1013146.md).
- [Créer des raccourcis clavier personnalisés](9500108.md).
- [Trier les listes et les combos](9500115.md).
- [Atteindre un numéro de ligne dans un champ de saisie](9500120.md).
- [Copier et coller le contenu des champs d'une fenêtre](9500116.md).

**Aidez vos utilisateurs**
Vous voulez donner une documentation à vos utilisateurs concernant les fonctionnalités automatiques de votre application (tri et recherche dans les tables, manipulation des graphes, ...) ? Utilisez la fonction [FAALanceAide](1410089447.md) dans vos applications. Le site [https://faa.pcsoft.fr/](https://faa.pcsoft.fr/) présente à vos utilisateurs les fonctionnalités automatiques de WINDEV incorporées dans vos applications : redimensionnement de la fenêtre, manipulation des tables, manipulation des graphes, etc.

## Configuration du menu des FAA

WINDEV propose de nombreuses FAA (Fonctionnalités Automatiques de vos Applications). Ces FAA permettent par exemple à l'utilisateur final d'imprimer le contenu d'un champ Table directement, d'exporter le contenu d'un champ Table vers Excel, d'afficher un champ Calendrier lors de la saisie d'une date, etc.
Bien souvent, des menus contextuels spécifiques sont liés aux FAA. Ces menus contextuels sont par exemple affichés sur les fenêtres, les champs de saisie, les champs Image, etc.

Il est possible de configurer simplement depuis l'éditeur, les différentes options affichées dans ce menu contextuel.

Il est également possible d'ajouter au menu contextuel des FAA un menu contextuel personnalisé. Ce menu contextuel peut être placé **avant** ou **après** le menu contextuel des FAA.

Pour plus de détails, consultez [Configurer les menus FAA (Fonctionnalités Automatiques de vos Applications)](2010040.md).

## Programmation

### Fonctions de gestion des Fonctionnalités Automatiques
Plusieurs fonctions WLangage permettent de gérer les fonctionnalités automatiques :
| [FAAActive](1000024767.md) | Réactive une Fonctionnalité Automatique de vos Applications (FAA) précédemment désactivée par la fonction [FAADésactive](1000022018.md). |
| --- | --- |
| [FAAChangeLibellé](1000022100.md) | Personnalise un libellé d'une option de menu pour les menus contextuels correspondant à une FAA (Fonctionnalité Automatique de vos Applications). |
| [FAADésactive](1000022018.md) | Désactive une Fonctionnalité Automatique d'une Application (FAA) sur un champ, sur une fenêtre ou sur l'application en cours. |
| [FAAExécute](1000022099.md) | Exécute une Fonctionnalité Automatique d'une Application (FAA) sur un champ ou une fenêtre. Par exemple, il est possible de lancer la correction orthographique sur un champ de saisie. |
| [FAAExporteParamètre](1000024375.md) | Sauve toutes les personnalisations réalisées via les FAA (Fonctionnalités Automatiques de vos Applications) dans un fichier. |
| [FAAImporteParamètre](1000024377.md) | Charge toutes les personnalisations réalisées via les FAA (Fonctionnalités Automatiques de vos Applications) ayant été précédemment sauvegardées dans un fichier. |
| [FAALanceAide](1410089447.md) | Ouvre le site d'aide des FAA (Fonctionnalités Automatiques de vos Applications). |
| [FAAMenuContextuelVersChaîne](1000022467.md) | Renvoie la liste des options du menu contextuel effectivement affiché par le champ. |
| [FAAParamètre](1000022108.md) | Permet de spécifier le comportement de certaines fonctionnalités automatiques de l'application (FAA). Il est par exemple possible de paramétrer l'option d'export vers Excel utilisée par [le menu automatique des tables](9500102.md). |
| [FAAPossible](1000022791.md) | Indique si une FAA (Fonctionnalité Automatique de l'Application) peut être exécutée sur un champ spécifique. |
| [FAASécuritéExport](1000022481.md) | Sécurise l'export de données confidentielles dans les FAA (Fonctionnalités Automatiques de vos Applications) qui permettent l'export, l'impression ou l'enregistrement de données. |
