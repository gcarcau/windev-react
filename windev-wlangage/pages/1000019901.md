# ChaîneInverse (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Inverse les caractères d'une chaîne.

## Exemple

```wlangage
Trace(ChaîneInverse("ABC"))
// La fenêtre de trace affiche "CBA"
```

## Syntaxe

```wlangage
<Résultat> = ChaîneInverse(<Chaîne>)
```

`<Résultat>` *Chaîne de caractères Ansi, Unicode ou Binaire*
> Chaîne de caractère inversée.
`<Chaîne>` *Chaîne de caractères Ansi, Unicode ou Binaire*
> Chaîne de caractères à inverser.

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
