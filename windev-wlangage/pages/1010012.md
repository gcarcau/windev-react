# Look des fenêtres : image et couleur de fond

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Pour optimiser le look de vos écrans, WINDEV et WINDEV Mobile permettent d'utiliser :

- des images dans vos fenêtres. Ces images sont utilisées en image de fond de la fenêtre. Vos champs sont superposés sur cette image.
- des couleurs de fond. De nombreuses couleurs standard peuvent être utilisées.

> _(WINDEV)_ Il est également possible de construire des couleurs de fond dégradées. Ces couleurs dégradées peuvent être utilisées : en fond de fenêtre, en couleur de fond des différents champs d'une fenêtre.

**Remarque** : sur les fenêtres avec un gabarit détouré, il n'est pas possible d'utiliser la fonctionnalité Aéro Snap de Windows. Aéro Snap impose une fenêtre standard redimensionnable.

## Images de fond des fenêtres

### Image de fond
Les formats d'images supportés sous Windows sont :

- Bitmap (*.BMP)
- Graphics Interchange Format (*.gif)
- Joint Picture Experts Group (*.jpg ; *.jpeg)
- Kodak Photo CD (*.pcd)
- PaintBrush (*.pcx)
- Adobe Photoshop Format (*.psd)
- TrueVision TARGA (*.tga)
- Tagged Image File Format (*.tif ; *.tiff)
  Remarque : l'option "tiff mosaïque" de la norme tiff 6.0 n'est pas supportée. Dans ce cas, il est conseillé d'enregistrer l'image à la norme tiff 5.0.
- Portable Network Graphics (*.png)
- Windows MetaFiles (*.emf ; *.wmf)
- Icônes (*.ico ; *.icw)
  Remarques :
  - Affichage HQ (Haute Qualité) disponible.
  - Gestion des planches au format BMP transparent (32 bits).
- Curseurs (*.cur)
- Portable Document Format (*.pdf)
- Scalable Vector Graphics (*.svg)
- Images WINDEV (générées par l'éditeur d'images, *.WDPIC).
- Nouveauté 2025
  Images au format WebP (*.webp).

> _(Android)_ Les formats disponibles sont les suivants : Bitmap (*.gif)Graphics Interchange Format (*.gif)Joint Picture Experts Group (*.jpg ; *.jpeg)Portable Network Graphics (*.png)Icônes (*.ico)Images WINDEV (générées par l'éditeur d'images, *.WDPIC).

### Configuration des images de fond
La configuration est effectuée dans l'onglet "Image" de la description de la fenêtre.
Pour sélectionner l'image de fond, cliquez sur le bouton [image: Bouton déroulant] du champ "Image de fond" :

- L'option "Parcourir" permet de sélectionner un fichier image accessible depuis votre poste.
- L'option "Catalogue" permet de sélectionner une image du catalogue d'images.

**Remarque** : Il est également possible de réaliser directement un Drag and Drop du fichier image présent dans l'explorateur vers la fenêtre WINDEV ou WINDEV Mobile.

## Couleur de fond

### Sélection de la couleur de fond
Pour sélectionner la couleur de fond d'une fenêtre :

1. Affichez la fenêtre de description.
2. Dans l'onglet "Style", ouvrez la liste "Couleur de fond". Une liste des différentes couleurs disponibles apparaît :
  - Couleurs disponibles : [image: Couleurs de fond disponibles sous WINDEV ]
  - Couleurs disponibles : [image: Couleurs de fond disponibles sous WINDEV Mobile ]
3. Sélectionnez la couleur de fond voulue.
4. Validez la fenêtre de description.

> _(WINDEV)_ Couleur de fond dégradéeDans la fenêtre de sélection des couleurs de fond, plusieurs couleurs de fond dégradées sont proposées par défaut. L'option "Autres dégradés" permet d'afficher la fenêtre de paramétrage du dégradé.Dans cette fenêtre, il est possible de :Sélectionner une couleur dégradée proposée par défaut.Modifier une des couleurs dégradées proposée par défaut : il est possible de paramétrer les couleurs, le nombre de couleurs pris en compte par le dégradé et l'angle du dégradé. Il suffit de laisser libre cours à votre esprit créatif.Remarque : Les couleurs dégradées peuvent également être utilisées en couleur de fond des champs : il suffit de modifier la couleur de fond du cadre extérieur du champ dans l'onglet "Style" de la fenêtre de description.
