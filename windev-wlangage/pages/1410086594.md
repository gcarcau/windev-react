# Ouverture

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Le mot-clé Ouverture peut correspondre à une variable mise à jour par les fonctions [PageInitialisation](3058025.md) et [InitFenêtre](3038019.md).
