# <Graphe>.HMLibelléX (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Modifie le libellé d'une catégorie sur l'axe des abscisses d'un graphe de type Heatmap.
Note : Par défaut, le libellé d'une catégorie correspond à la valeur numérique de la catégorie.

## Exemple

```wlangage
GRF_HMap.HMLibelléX(1, "X1")
GRF_HMap.HMLibelléX(2, "X2")
```

```wlangage
// Libellé des axes
POUR TOUT ÉLÉMENT nIndice, nTempérature DE gtaTempérature
 GRF_Graphe.HMLibelléX(nIndice, "" + nTempérature)
FIN
POUR TOUT ÉLÉMENT nIndice, nVent DE gtaVent
 GRF_Graphe.HMLibelléY(nIndice, "" + nVent)
FIN
```

## Syntaxe

```wlangage
<Champ Graphe>.HMLibelléX(<X> , <Libellé>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres ou d'états).
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<X>` *Entier*
> Position de la catégorie sur l'axe des abscisses.
`<Libellé>` *Chaîne de caractères*
> Nouveau libellé de la catégorie. Si ce paramètre correspond à une chaîne vide (""), la valeur numérique de la catégorie est affichée.

## Remarques

Le libellé défini avec la fonction **<Graphe>.HMLibelléX** sera pris en compte lors du prochain appel à la fonction [<Graphe>.Dessine](1000024062.md).
