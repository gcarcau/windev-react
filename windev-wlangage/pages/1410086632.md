# Angle (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Angle** permet de :

- Connaître l'angle (en degrés) d'une variable de type Police.
- Modifier l'angle (en degrés) d'une variable de type Police.

**Remarque** : L'angle est calculé à partir d'une ligne horizontale dans le sens inverse des aiguilles d'une montre (sens trigonométrique).

## Exemple

```wlangage
// Définir les caractéristiques d'une variable de type Police
Police1 est une Police
Police1.Nom = "Arial"
Police1.Couleur = JauneClair
Police1.Taille = 14
Police1.UnitéTaille = unitéPoint
Police1.Angle = 45
// Appliquer la police au champ "MonChamp"
MonChamp.Police = Police1
```

## Syntaxe

#### Connaître l'angle d'une variable de type Police

```wlangage
<Résultat> = <Nom de la police>.Angle
```

`<Résultat>` *Entier*
> Angle (en degrés) de la variable de type Police spécifiée.
`<Nom de la police>` *Police*
> Nom de la variable de type [Police](1514045.md) à manipuler.

#### Modifier l'angle d'une variable de type Police

```wlangage
<Nom de la police>.Angle = <Nouvel angle>
```

`<Nom de la police>` *Police*
> Nom de la variable de type [Police](1514045.md) à manipuler.
`<Nouvel angle>` *Entier*
> Nouvel angle (en degrés) de la variable de type Police spécifiée.

## Remarques

### Variable de type Police
Une police peut être créée à partir d'une variable de type [Police](1514045.md).
Pour définir les caractéristiques de la police, utilisez :

- soit la fonction [PoliceCrée](3060002.md).
- soit les propriétés [Alphabet](2512008.md), [Angle](1410086632.md), [Barré](2513005.md), [Couleur](2510071.md), [Gras](2513001.md), [Italique](2513007.md), [Interlettre](1410088367.md), [Interligne](1410088366.md), [Nom](2510082.md), [Souligné](2513013.md), [Taille](2510125.md) et [UnitéTaille](1410088365.md).

Cette police pourra être utilisée :

- Pour écrire du texte dans des dessins (fonction [dPolice](3029020.md)).
- Pour écrire dans les graphes (fonctions [grPoliceEtiquette](3042012.md), [grPoliceLégende](3042037.md), [grPoliceTitre](3042048.md) et [grPoliceTitreAxe](3042059.md)).
- Pour imprimer (fonction [iPolice](3046014.md)).
- Dans les champs d'une fenêtre (propriété [Police](1514045.md) des champs d'une fenêtre).
- Dans les champs d'un état (propriété [Police](1514045.md) des champs d'un état).

### Limites
Lors de l'affectation d'une police à un champ d'une fenêtre, la propriété **Angle** n'est pas prise en compte.
Par exemple, si la variable de type Police ***MaPolice*** a les caractéristiques suivantes : Taille 12, Arial, Angle 45, seules les deux premières caractéristiques seront prises en compte lors de l'affectation réalisée de la façon suivante :

```wlangage
MonChamp.Police = MaPolice
```
