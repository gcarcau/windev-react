# <redisConnexion>.Désabonne (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Supprime un abonnement à un canal de diffusion Redis.
Nouveauté 2025
Cette fonction peut également être utilisée pour manipuler des données sur un serveur Valkey.

## Exemple

```wlangage
gRedis.Désabonne("MonCanal")
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.Désabonne(<Canal>)
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été effectuée,
> - Faux dans le cas contraire.
`<Connexion>` *Variable de type redisConnexion*
> Nom de la variable de type [redisConnexion](1000023527.md) correspondant à la connexion au serveur Redis.
`<Canal>` *Chaîne de caractères*
> Nom du canal de diffusion pour lequel le désabonnement doit être effectué.

## Remarques

### Opérations effectuées lors du désabonnement
Lors du désabonnement, la procédure spécifiée dans la fonction [<redisConnexion>.Abonne](1410088279.md) sera exécutée.
