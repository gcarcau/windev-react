# TailleFichier (Propriété)

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android)

La propriété **TailleFichier** permet de connaître la taille des fichiers. Cette propriété est disponible sur :

- une variable de type [mongoBaseInfo](1000022412.md).
- une variable de type [TéléchargementInfo](1410087306.md).
