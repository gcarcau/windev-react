# telAppelEstTerminé (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Permet de savoir si l'appel (sortant ou entrant) est terminé.

## Exemple

```wlangage
// L'appel en cours est-il terminé ?
SI telAppelEstTerminé() = Vrai ALORS
	// Raccrochage de la ligne
	telRaccroche()
FIN
```

## Syntaxe

```wlangage
<Résultat> = telAppelEstTerminé([<Identifiant de l'appel>])
```

`<Résultat>` *Booléen*
> - Vrai si l'appel est terminé,
> - Faux dans le cas contraire.
`<Identifiant de l'appel>` *Entier optionnel*
> Identifiant de l'appel à manipuler. Cet identifiant est connu dans la procédure WLangage appelée par la fonction [telDémarreDétectionAppel](3076029.md). Si ce paramètre n'est pas spécifié, l'appel en cours (sortant ou entrant) est manipulé.

## Remarques

### Configuration nécessaire
Les fonctions de téléphonie utilisent la technologie TAPI 2.0 et/ou la technologie TAPI 3.1. Ces technologies sont utilisables sur tous les systèmes.

**Composante : wd300com.dll**
