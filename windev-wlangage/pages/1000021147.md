# SSHConnecteShell (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Ouvre une nouvelle session SSH de type "Shell". Cette session pourra être fermée à l'aide de la fonction [SSHDéconnecteShell](1000021148.md).
**Remarque** : Pour envoyer une commande directement au serveur SSH, utilisez la fonction [SSHCommande](1000021143.md).

## Exemple

```wlangage
cMaSession est une sshSession
cMaSession.Adresse = "127.0.0.1"
cMaSession.Port = 22
cMaSession.Utilisateur = "login"
cMaSession.MotDePasseUtilisateur = "pass"
SI SSHConnecteShell(cMaSession) ALORS
	Info("Session ouverte")
FIN
```

## Syntaxe

```wlangage
<Résultat> = SSHConnecteShell(<Session SSH>)
```

`<Résultat>` *Booléen*
> - Vrai si la session a été ouverte correctement,
> - Faux dans le cas contraire.
`<Session SSH>` *Variable de type sshSession*
> Nom d'une variable [sshSession](1000021157.md) contenant les paramètres de connexion de la session SSH à ouvrir.
