# HStatDate (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Renvoie la date de la dernière mise à jour des statistiques d'index. Ces statistiques ont été réalisées grâce aux fonctions [HStatCalcule](3044134.md) ou [HRéindexe](3044133.md).

## Exemple

```wlangage
// Réalisation de statistiques sur la clé NomCli du fichier de données Client
HStatCalcule(Client, NomCli)

// Connaître la date de réalisation de ces statistiques
ResDate = HStatDate()
Info("Les statistiques effectuées sur la rubrique NomCli ont été réalisées le : " + ...
			DateVersChaîne(ResDate, maskDateSystème))
```

## Syntaxe

```wlangage
<Résultat> = HStatDate([<Fichier de données> [, <Rubrique clé>]])
```

`<Résultat>` *Chaîne de caractères*
> - Date de la dernière mise à jour des statistiques au format AAAAMMJJ (AAAA correspond à l'année, MM au mois et JJ au jour). La date renvoyée est au format UTC (Universal Time Coordinated).
> - Chaîne vide ("") si aucun calcul de statistiques n'a été effectué.
`<Fichier de données>` *Chaîne de caractères optionnelle*
> Nom du fichier de données manipulé. Si ce nom n'est pas spécifié, la fonction **HStatDate** manipule le dernier fichier de données utilisé par la dernière fonction de gestion HFSQL (fonction commençant par la lettre H).
`<Rubrique clé>` *Chaîne de caractères optionnelle*
> Nom de la rubrique clé sur laquelle les statistiques ont été effectuées. Si ce nom n'est pas spécifié, la fonction **HStatDate** manipule la dernière rubrique clé utilisée par la dernière fonction de gestion HFSQL (fonction commençant par la lettre H).

## Remarques

Dans les fichiers de données HFSQL, seules les rubriques clés peuvent faire l'objet d'un calcul de statistiques.
