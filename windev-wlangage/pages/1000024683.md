# Procédure WLangage appelée par la fonction GPSDétectePosition

> **Disponible :** **WINDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Procédure WLangage (également nommée "callback") appelée par la fonction [GPSDétectePosition](1000019209.md) lorsque le périphérique entre ou sort de la région délimitée par les paramètres spécifiés. Cette procédure peut être une procédure locale, globale ou interne.

## Exemple

```wlangage
// Active la demande de notification
GPSDétectePosition(ProcDétection, 1.145258, 30.968745)
```

```wlangage
// Procédure appelée lors de la notification
PROCÉDURE ProcDétection(Entrée est un booléen)
SI Entrée = Vrai ALORS
	Info("Vous êtes arrivé à destination.")
FIN
```

## Syntaxe

```wlangage
<Résultat> = GPSDétectePosition_Callback(<Entrée> , <Identifiant de détection>)
```

`<Résultat>` *Booléen*
> - Vrai pour continuer la détection de la position spécifiée par la fonction [GPSDétectePosition](1000019209.md),
> - Faux pour arrêter la détection de la position spécifiée par la fonction [GPSDétectePosition](1000019209.md).
`<Entrée>` *Booléen*
> - Vrai si le périphérique entre dans la région délimitée par les paramètres spécifiés par la fonction [GPSDétectePosition](1000019209.md),
> - Faux s'il en sort.
`<Identifiant de détection>` *Entier*
> Valeur renvoyée par la fonction [GPSDétectePosition](1000019209.md). Cet identifiant permet de différencier les positions détectées lorsqu'une même procédure est utilisée pour la détection de plusieurs positions.
