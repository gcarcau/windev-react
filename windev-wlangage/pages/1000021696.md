# hbCréeTable (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Crée une table HBase ou modifie la description d'une table HBase.

## Exemple

```wlangage
// Connexion
Connexion est un hbConnexion
Connexion.Serveur = "MonServeur"
// Description de la table
DescTable est un hbDescriptionTable
DescTable.Nom = "blog"
// Description de la colonne "Post"
DescCol est un hbDescriptionColonne
DescCol.Nom = "Post"
Ajoute(DescTable.Colonne, DescCol)
// Création de la table
hbCréeTable(Connexion, DescTable)
```

## Syntaxe

```wlangage
<Résultat> = hbCréeTable(<Connexion> , <Description>)
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème. La fonction [ErreurInfo](3013008.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type hbConnexion*
> Nom de la variable de type [hbConnexion](1000021685.md) correspondant à la connexion au serveur HBase.
`<Description>` *Variable de type hbDescriptionTable*
> Nom de la variable de type [hbDescriptionTable](1000021688.md) correspondant à la description de la table.
