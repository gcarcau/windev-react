# SQLLitMémoTexte (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Récupère le contenu d'une colonne de type Mémo texte présente dans le résultat de la requête, pour la ligne en cours. Tout le contenu du mémo texte est récupéré, quelle que soit sa taille (Rappel : La fonction [SQLLitCol](3072019.md) récupère uniquement 32 Ko de la chaîne de caractères)
**Attention** : Cette fonction doit être utilisée lors d'un parcours du résultat de la requête de type "SQLAvance/SQLLitCol". Pour plus de détails sur les différents types de parcours du résultat d'une requête SQL, consultez [Types de parcours SQL](3072025.md).

> _(PHP)_ Cette fonction est inutile en PHP. Elle est équivalente à la fonction SQLLitCol.

## Exemple

```wlangage
SQLExec("SELECT NOM, PRENOM, POSTE, NOTES FROM CLIENT", "REQ1")
SQLAvance("REQ1") // Ou SQLFetch("REQ1")
// Récupérer les données
SAI_NOM = SQLLitCol("REQ1", 1)
SAI_PRENOM = SQLLitCol("REQ1", 2)
SAI_POSTE = SQLLitCol("REQ1", 3)
// Lire le mémo texte
SAI_NOTE = SQLLitMémoTexte("REQ1", 4)
SQLFerme("REQ1")
```

## Syntaxe

```wlangage
<Résultat> = SQLLitMémoTexte(<Nom de la requête> , <Numéro de la colonne>)
```

`<Résultat>` *Chaîne de caractères*
> Mémo texte.
`<Nom de la requête>` *Chaîne de caractères*
> Nom de la requête créée et exécutée avec la fonction [SQLExec](3072007.md) (avec guillemets), ou exécutée avec la fonction [SQLExecWDR](3072010.md) (avec ou sans guillemets).
> > _(Java)_ Les requêtes créées avec l'éditeur de requête doivent être spécifiées sous forme d'une chaîne de caractères avec guillemets.
`<Numéro de la colonne>` *Entier*
> Numéro de la colonne de type mémo texte à récupérer. Cette colonne correspond à une colonne de la requête (et non pas à une colonne de la table).

## Remarques

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Java, Code Utilisateur (MCU), PHP, Ajax)_ Ligne en cours de la requêteLa ligne en cours est positionnée par la fonction SQLAvance (également nommée SQLFetch).

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Java, Code Utilisateur (MCU), PHP, Ajax)_ Colonnes de la requêtePour lire les colonnes autres que les colonnes de type Mémo, utilisez la fonction SQLLitCol.Pour lire les autres types de colonnes mémo, utilisez la fonction SQLLitMémo.
