# Téléphone (Type de variable)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le type **Téléphone** permet de manipuler un numéro de téléphone ainsi que son type (domicile, bureau, ...).
Les caractéristiques de cette variable peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.

Ce type de variable est utilisé par les variables de type [Contact](1000020254.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Compose le premier numéro de téléphone professionnel d'un contact
tel est un Téléphone
POUR TOUT tel DE contact.Téléphone
	SI tel.Type = telMobileBureau OU tel.Type = telBureau ALORS
		telDialerCompose(tel.Numéro)
		RETOUR
	FIN
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type Téléphone
Les propriétés suivantes peuvent être utilisées pour manipuler un numéro de téléphone :

| **Nom de la propriété** | **Type manipulé** | **Effet** |
| --- | --- | --- |
| Etiquette | Chaîne de caractères | Etiquette pour les types de numéro de téléphone personnalisé (Optionnel). Si la propriété **Type** ne correspond pas à la constante *telPersonnalisé*, la valeur de cette propriété sera ignorée. |
| Numéro | Chaîne de caractères | Numéro de téléphone. Aucun formatage n'est effectué. |
| Type | Constante de type Entier | _(Android)_ Type du numéro : telAutre : autres typestelBureau : téléphone fixe du bureautelDomicile : téléphone fixe du domiciletelFaxBureau : fax du bureautelFaxDomicile : fax du domiciletelMobileBureau : téléphone mobile du bureautelMobileDomicile : téléphone mobile du domiciletelPersonnalisé : type personnalisé correspondant à la valeur de la propriété Etiquette.telVoiture : téléphone de la voiture _(iPhone/iPad, Widget IOS, Mac Catalyst)_ Type du numéro : telDomicile : téléphone fixe du domiciletelFaxBureau : fax du bureautelFaxDomicile : fax du domiciletelMobileDomicile : téléphone mobile du domiciletelPersonnalisé : type personnalisé correspondant à la valeur de la propriété Etiquette. |

## Remarques

### Réinitialisation
Pour réinitialiser le contenu d'une variable de type **Téléphone**, il est possible d'utiliser la fonction [VariableRAZ](3013069.md).
