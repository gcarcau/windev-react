# Constantes Navigateur

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |
| **cookieHTTPOnly** | Type du cookie : Cookie récupérable uniquement en code serveur. Ce cookie ne pourra pas être lu en code navigateur. | [CookieEcrit](3012008.md) |
| **cookieNormal** | Type du cookie : Cookie sans options spécifiques. | [CookieEcrit](3012008.md) |
| *cookieSameSiteLax* | Type du cookie : Cookie de type "SameSite=Lax". Ce type de cookie permet de se prémunir des vulnérabilités de type CSRF (Cross Site Request Forgery).  Le cookie concerné par cette instruction ne sera envoyé que si la requête provient du même site web ou d'un autre site via un lien externe. | [CookieEcrit](3012008.md) |
| **cookieSameSiteNone** | Cookie de type "Same Site=None". Ce type de cookie permet de se prémunir des vulnérabilités de type CSRF (Cross Site Request Forgery).  Les cookies seront envoyés quel que soit le contexte de l’appel. | [CookieEcrit](3012008.md) |
| **cookieSameSiteStrict** | Type du cookie : Cookie de type "SameSite=Strict". Ce type de cookie permet de se prémunir des vulnérabilités de type CSRF (Cross Site Request Forgery).  Le cookie concerné par cette instruction ne sera envoyé que si la requête provient du même site web. Il ne sera donc pas envoyé lors d’une première visite sur une page du site, mais uniquement lors des actions qui suivent. | [CookieEcrit](3012008.md) |
| **cookieSecure** | Type du cookie : Cookie transmis uniquement dans une requête HTTPS. | [CookieEcrit](3012008.md) |
| **navigateurOSAndroid** | Navigateur lancé à partir d'un système Android. | [NavigateurOS](1000021857.md) |
| **navigateurOSAutre** | Navigateur lancé à partir d'un système non répertorié. | [NavigateurOS](1000021857.md) |
| **navigateurOSiOS** | Navigateur lancé à partir d'un système iOS. | [NavigateurOS](1000021857.md) |
| **navigateurOSLinux** | Navigateur lancé à partir d'un système Linux. | [NavigateurOS](1000021857.md) |
| **navigateurOSMacOS** | Navigateur lancé à partir d'un système MacOS. | [NavigateurOS](1000021857.md) |
| **navigateurOSWindows** | Navigateur lancé à partir d'un système Windows. | [NavigateurOS](1000021857.md) |
| **navigateurOSWindowsMobile** | Navigateur lancé à partir d'un système Windows pour mobile. | [NavigateurOS](1000021857.md) |
| **NavigateurPlateformeAndroid** | L'utilisateur affiche le site sur un smartphone sous Android. | [NavigateurPlateforme](1000019486.md) |
| **NavigateurPlateformeBlackBerry** | L'utilisateur affiche le site sur un BlackBerry. | [NavigateurPlateforme](1000019486.md) |
| **NavigateurPlateformeiPad** | L'utilisateur affiche le site sur un iPad. | [NavigateurPlateforme](1000019486.md) |
| **NavigateurPlateformeiPhone** | L'utilisateur affiche le site sur un iPhone. | [NavigateurPlateforme](1000019486.md) |
| **NavigateurPlateformeMobile** | L'utilisateur affiche le site sur un smartphone (autres que ceux cités). | [NavigateurPlateforme](1000019486.md) |
| **NavigateurPlateformeRobot** | L'utilisateur est un robot de moteur de recherche (et qui indexe donc le site). | [NavigateurPlateforme](1000019486.md) |
| **NavigateurPlateformeStandard** | L'utilisateur n'utilise pas une plateforme particulière (c'est le cas pour les PC de bureau, les PC portables, les Mac, ...). | [NavigateurPlateforme](1000019486.md) |
| **NavigateurPlateformeWindowsMobile** | L'utilisateur affiche le site sur un smartphone sous Windows Mobile. | [NavigateurPlateforme](1000019486.md) |
| **NavigateurPlateformeWindowsPhone** | L'utilisateur affiche le site sur un smartphone sous Windows Phone. | [NavigateurPlateforme](1000019486.md) |
| **NavigateurTypeChrome** | Type du navigateur utilisé par l'internaute pour afficher le site : Chrome | [NavigateurType](1000019487.md) |
| **NavigateurTypeEdge** | Type du navigateur utilisé par l'internaute pour afficher le site : Microsoft Edge | [NavigateurType](1000019487.md) |
| **NavigateurTypeFirefox** | Type du navigateur utilisé par l'internaute pour afficher le site : Firefox | [NavigateurType](1000019487.md) |
| **NavigateurTypeGecko** | Type du navigateur utilisé par l'internaute pour afficher le site : Navigateur utilisant le moteur de rendu Gecko (autre que Firefox). | [NavigateurType](1000019487.md) |
| **NavigateurTypeInconnu** | Type du navigateur utilisé par l'internaute pour afficher le site : Le navigateur utilisé est inconnu ou les informations sont manquantes | [NavigateurType](1000019487.md) |
| **NavigateurTypeInternetExplorer** | Type du navigateur utilisé par l'internaute pour afficher le site : Internet Explorer. | [NavigateurType](1000019487.md) |
| **NavigateurTypeOpera** | Type du navigateur utilisé par l'internaute pour afficher le site : Opera | [NavigateurType](1000019487.md) |
| **NavigateurTypeRobot** | Type du navigateur utilisé par l'internaute pour afficher le site : Robot de moteur de recherche. | [NavigateurType](1000019487.md) |
| **NavigateurTypeSafari** | Type du navigateur utilisé par l'internaute pour afficher le site : Safari | [NavigateurType](1000019487.md) |
| **NavigateurTypeWebKit** | Type du navigateur utilisé par l'internaute pour afficher le site : Navigateur utilisant le moteur de rendu WebKit (autre que Chrome et Safari). | [NavigateurType](1000019487.md) |
| **NavigateurVersionComplète** | Numéro de version complet du navigateur utilisé par l'internaute. | [NavigateurVersion](1000019488.md) |
| **NavigateurVersionMajeure** | Numéro de version majeure du navigateur utilisé par l'internaute. | [NavigateurVersion](1000019488.md) |
