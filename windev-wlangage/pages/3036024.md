# fDisqueInfo (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, PHP) · **Autres** (Procédures stockées)

Renvoie des informations sur un disque.

## Exemple

```wlangage
// Taille totale du disque ?
ResTailleDisque est un numérique  = fDisqueInfo("C:", fdEspaceTotal)
```

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ // Nom du volume
RésultatNom est une chaîne
RésultatNom = fDisqueInfo("C:", fdNomVolume)
Info(RésultatNom)

## Syntaxe

```wlangage
<Résultat> = fDisqueInfo(<Chemin du disque> , <Information>)
```

`<Résultat>` *Tous types*
> - Information demandée.
> - 0 en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Chemin du disque>` *Chaîne de caractères*
> Chemin du disque à manipuler de la forme :
>
> - <lettre du lecteur>**:**. Par exemple : "**A:**". La lettre du lecteur est en majuscule.
> - chemin UNC. Par exemple : "\\<NomServeur>\<NomPartage>".
`<Information>` *Constante*
> Indique le type d'information à rechercher :
>
> | *fdEspaceLibre* | Espace disque sur le disque (en octets) |
> | --- | --- |
> | *fdEspaceTotal* | Taille totale du disque (en octets) |
> | *fdNbCluster* | Nombre de clusters du disque _(PHP)_ Cette constante n'est pas disponible. |
> | *fdNbSecteurParCluster* | Nombre de secteurs par cluster _(PHP)_ Cette constante n'est pas disponible. |
> | *fdNomVolume* | Nom du volume _(PHP)_ Cette constante n'est pas disponible. |
> | *fdNuméroDeSérie* | Numéro de série du disque, mis en place lorsque le disque est formaté (et non le numéro de série donné par le constructeur). _(PHP)_ Cette constante n'est pas disponible. |
> | *fdTailleNomFichier* | Taille maximale d'un nom de fichier sur le disque (en caractères) _(PHP)_ Cette constante n'est pas disponible. |
> | *fdTailleSecteur* | Taille d'un secteur (en octets) _(PHP)_ Cette constante n'est pas disponible. |
> | *fdTypeDisque* | Type de disque (voir tableau ci-dessous) _(PHP)_ Cette constante n'est pas disponible. |
