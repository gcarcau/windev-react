# SFFusionne (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Fusionne des enregistrements Salesforce (appelés également objets Salesforce).

## Syntaxe

```wlangage
<Résultat> = SFFusionne(<Connexion Salesforce> , <Type de fusion>)
```

`<Résultat>` *Variable de type Tableau*
> Tableau de variables de type [sfRésultatFusionne](1000018499.md) contenant les données résultat, notamment les identifiants des enregistrements fusionnés.
`<Connexion Salesforce>` *Variable de type sfConnexion*
> Nom de la variable de type [sfConnexion](1000017579.md) à utiliser
`<Type de fusion>` *Variable de type Tableau*
> Tableau de variables de type [sfRequêteFusionne](1000018506.md) correspondant aux enregistrements (objets Salesforce) à fusionner.

## Remarques

### Cas d'erreurs possibles :

- La connexion Internet n'est pas valide.
- L'authentification n'a pas pu être réalisée correctement.
- La réponse XML du serveur n'est pas lisible.

Pour savoir si une erreur est survenue, utilisez la variable [ErreurDétectée](3087001.md).
