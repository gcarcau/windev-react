# HFichierExiste (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Permet de savoir :

- si un fichier de données existe, c'est-à-dire s'il a été créé physiquement (fonctions [HCréation](3044255.md) ou [HCréationSiInexistant](3044254.md)).
  Remarque : Les substitutions en cours sur le fichier de données (effectuées avec les fonctions [HSubstRep](3044028.md), [HChangeRep](3044168.md) et [HChangeNom](3044141.md)) sont prises en compte.
- si une vue ou une requête a été définie.

## Exemple

```wlangage
// Test de l'existence du fichier de données "Client"
SI HFichierExiste(Client) = Vrai ALORS
	// Traitements
	...
FIN
```

```wlangage
// Test de l'existence d'un fichier de données Client/Serveur
SI HFichierExiste(MaConnexion, "MonFichier.FIC") = Vrai ALORS
	// Traitements
	...
FIN
```

## Syntaxe

#### Tester l'existence d'un fichier de données, d'une requête ou d'une vue

```wlangage
<Résultat> = HFichierExiste([<Elément>])
```

`<Résultat>` *Booléen*
> - Vrai si le fichier physique existe,
> - Faux dans le cas contraire.
`<Elément>` *Chaîne de caractères optionnelle*
> Nom de l'élément à manipuler :
>
> - Nom du fichier de données.
> - Nom de la vue ou de la requête.
>
>
> Si ce nom n'est pas spécifié, la fonction **HFichierExiste** va manipuler le dernier fichier de données, la dernière requête ou vue manipulé par la dernière fonction de gestion HFSQL (fonction commençant par la lettre H).

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Android, Widget Android, iPhone/iPad, Java, Code Utilisateur (MCU), Ajax, HFSQL Client/Serveur)_ Tester l'existence d'un fichier de données en HFSQL Client/Serveur Masquer les détails
<Résultat> = HFichierExiste(<Connexion> , <Fichier physique>)

 <Résultat> : BooléenVrai si le fichier de données physique existe sur le serveur, Faux dans le cas contraire. <Connexion> : Chaîne de caractères ou variable de type ConnexionConnexion associée au fichier de données. Cette connexion correspond : soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions HDécritConnexion ou HOuvreConnexion.soit au nom d'une variable de type Connexion. <Fichier physique> : Chaîne de caractèresNom physique du fichier de données recherché. L'extension du fichier doit être précisée (par exemple "Client.fic").

## Remarques

- La fonction **HFichierExiste** est utilisable que le fichier de données soit ouvert ou non.
- La fonction **HFichierExiste** n'ouvre pas le fichier de données si celui-ci est fermé.

**Composante : wd300hf.dll**
