# CoTang (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Calcule la co-tangente d'un angle.

## Exemple

```wlangage
// Calcul de la co-tangente de 20
ResCoTangente = CoTang(20)
// Renvoie 2.74747741945
```

## Syntaxe

```wlangage
<Résultat> = CoTang(<Angle>)
```

`<Résultat>` *Réel*
> Co-tangente de l'angle spécifié.
`<Angle>` *Entier ou réel*
> Angle (en degrés) à manipuler. Si ce paramètre est égal à 0°, 180° ou -180°, une erreur du WLangage est générée.

**Composante : wd300mat.dll**
