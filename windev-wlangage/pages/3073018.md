# SysInstance (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **Autres** (Procédures stockées)

Renvoie l'instance d'un module.

## Exemple

```wlangage
// Instance de l'application en cours
ResInstance = SysInstance()
```

## Syntaxe

```wlangage
<Résultat> = SysInstance([<Nom du module>])
```

`<Résultat>` *Entier*
> Instance du module spécifié.
`<Nom du module>` *Chaîne de caractères optionnelle*
> Correspond :
>
> - soit au nom et au chemin complet (ou relatif) du fichier exécutable (extension ".EXE") de l'application en cours. Un chemin de type UNC est autorisé.
> - soit au nom et au chemin complet (ou relatif) d'une librairie WINDEV (fichier ".DLL") actuellement chargée en mémoire (fonction [ChargeDLL](3014006.md)). Un chemin de type UNC est autorisé.
>
>
> Si ce paramètre n'est pas spécifié, l'instance de l'application en cours est retournée.

## Remarques

### Paramètre "Nom du module"
Le paramètre <Nom du module> ne doit pas contenir le nom et le chemin d'un fichier exécutable différent de celui de l'application en cours.
Pour savoir si un exécutable est actuellement lancé, utilisez la fonction [ExeLancé](3035003.md).

### Équivalence

```wlangage
ResInstance = SysInstance()
```

est équivalent à

```wlangage
ResInstance = Instance()
```

**Composante : wd300std.dll**
