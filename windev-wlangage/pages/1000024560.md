# saasVisite (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Le type **saasVisite** permet de connaître toutes les caractéristiques d'une visite d'un utilisateur SaaS. Les caractéristiques de ce type de variable peuvent être connues via différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
T est un tableau de saasVisite
T = SaaSAdminListeVisite("MonSiteSaaS", "Client1")
```

## Propriétés

### Propriétés spécifiques à la description des variables de type saasVisite
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **saasVisite** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Date | DateHeure | Date et heure à laquelle l'utilisateur s'est connecté.  **Cette propriété est disponible en lecture seulement**. |
| Durée | Durée | Durée de la connexion.  **Cette propriété est disponible en lecture seulement**. |
| Site | [saasSite](1000019068.md) | Site pour lequel l'utilisateur s'est connecté.  **Cette propriété est disponible en lecture seulement**. |
| Utilisateur | [saasUtilisateur](1000019083.md) | Utilisateur qui a effectué la visite.  **Cette propriété est disponible en lecture seulement**. |
