# ListeDLL (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Retourne :

- **en exécution** : la liste des librairies (fichiers ".DLL") utilisées par l'application WINDEV, WINDEV Mobile ou par le site WEBDEV en cours. Seules les librairies en mémoire sont listées.
- **en mode test** : toutes les librairies installées sur le poste en cours.

## Exemple

```wlangage
// Récupération des librairies utilisées
ListeLibrairie est une chaîne = ListeDLL()
// Parcours de cette liste
Librairie est une chaîne
Librairie = ExtraitChaîne(ListeLibrairie, rangPremier, RC)
TANTQUE Librairie <> EOT
	// Récupération de la librairie
	Trace(ExtraitChaîne(Librairie, 1, TAB))
	// Librairie suivante
	Librairie = ExtraitChaîne(ListeLibrairie, rangSuivant, RC)
FIN
```

```wlangage
// Récupération des librairies utilisées
ListeLibrairie est une chaîne = ListeDLL()
// Parcours de cette liste
POUR TOUTE CHAÎNE CheminLibrairie DE ListeLibrairie SÉPARÉE PAR TAB + RC
	// Récupération de la librairie
	Trace(CheminLibrairie)
FIN
```

## Syntaxe

```wlangage
<Résultat> = ListeDLL()
```

`<Résultat>` *Chaîne de caractères*
> Liste des librairies (fichiers ".DLL") utilisées par l'application en cours ou installées sur le poste en cours, sous la forme :
>
>
> ```wlangage
> <1° librairie> + TAB + RC + <2° librairie> + TAB + RC + ...+ <X librairie>
> ```
>
>
> Où <X librairie> correspond au nom et chemin complet de la librairie X.

## Remarques

### Gestion des erreurs
La fonction **ListeDLL** ne retourne pas de code d'erreur. Pour savoir si cette fonction a généré une erreur, utilisez la variable [ErreurDétectée](3087001.md). En cas d'erreur, il est possible de connaître le détail de l'erreur grâce à la fonction [ErreurInfo](3013008.md).
