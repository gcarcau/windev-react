# hParamètreFichier (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

Le type **hParamètreFichier** permet de définir les fichiers de données pris en compte par une tâche d'optimisation planifiée. Les caractéristiques de ces fichiers de données peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
Ce type de variable est utilisé par le type [hOptimisationPlanifiée](1000018854.md) et par différentes fonctions WLangage.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Recalculer les statistiques des fichier de la base "MaBase",
// tous les samedis à 23H00
Optim est une hOptimisationPlanifiée
Optim.Description = "Recalcul des statistiques des fichiers de la base de données MaBase"

Optim.Planification.Mois = "*"
Optim.Planification.JourDeLaSemaine = "samedi"
Optim.Planification.Heure = "23"
Optim.Planification.Minute = "0"

Optim.Fichier[1].Nom = "MaBase"
Optim.Fichier[1].Option = hOptStat

HAjouteOptimisationPlanifiée(MaConnexion, Optim)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type hParamètreFichier
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **hParamètreFichier** :

| **Nom de la propriété** | **Type manipulé** | **Effet** |
| --- | --- | --- |
| MotDePasse | Chaîne de caractères ou Chaîne secrète | Mot de passe des fichiers de données cryptés. Nouveauté 2025 **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode". Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).  Cette propriété est disponible en écriture uniquement. |
| Nom | Chaîne de caractères | Nom du fichier de données à traiter. Ce nom peut correspondre à une chaîne de type :   - <Nom de la base>/<Nom du fichier de données : Optimisation du fichier "Nom du fichier de données" dans la base "Nom de la base". - <Nom de la base : Optimisation de tous les fichiers de données contenus la base "Nom de la base". - "*" : Optimisation de tous les fichiers de données de toutes les bases de données du serveur. |
| Option | Constante de type Entier | Option d'optimisation :   - *hOptIndex* : Provoque la réindexation des fichiers de données. Cette réindexation est effectuée à chaud sur les index et les index full-text. - *hOptStat* : Provoque le recalcul des statistiques sur les fichiers de données. Le résultat est similaire à l'utilisation de la fonction [HStatCalcule](3044134.md). Ce traitement est effectué à chaud.   Attention : Cette propriété est prise en compte uniquement lors de l'utilisation d'une variable de type [hOptimisationPlanifiée](1000018854.md). |

## Remarques

### Fonctions utilisant les variables de type hParamètreFichier

| Nouveauté Abonnement [HRéindexeAsynchrone](1410091053.md) | Reconstruit l'index d'un fichier de données HFSQL Client/Serveur (fichier d'extension ".NDX"). Cette réindexation est asynchrone : elle est effectuée sur le serveur et ne bloque pas le poste Client.  **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| --- | --- |
| Nouveauté Abonnement [HStatCalculeAsynchrone](1410091108.md) | Réalise diverses statistiques sur les clés d'un fichier de données HFSQL Client/Serveur. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| Nouveauté Abonnement [HVérifieIndexAsynchrone](1410091105.md) | Vérifie que les données contenues dans le fichier d'index (fichier .NDX) référencent correctement les données contenues dans le fichier de données HFSQL Client/Serveur (fichier .FIC). **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| Nouveauté Abonnement [HVérifieMémoAsynchrone](1410091107.md) | Vérifie l'intégrité structurelle des mémos d'un fichier de données HFSQL Client/Serveur. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
