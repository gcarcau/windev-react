# ImageEnroulée (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **ImageEnroulée** permet de :

- connaître et/ou de modifier l'image par défaut d'une ligne enroulée dans un champ Table hiérarchique.
- connaître et/ou de modifier l'image par défaut d'une ligne enroulée dans un champ Arbre.
- connaître et/ou de modifier l'image d'une ligne spécifique enroulée dans un champ Table hiérarchique.
- connaître et/ou modifier l'image d'une ligne enroulée dans une rubrique hiérarchique d'un état de type "Tableau hiérarchique".

Cette propriété permet par exemple de définir :

- l'image qui sera utilisée par défaut lors des prochains ajouts dans le champ Table hiérarchique. Cette image sera prise en compte par les fonctions [TableAjoute](3074017.md), [TableAjouteLigne](3074006.md), [TableAjouteFils](1000010004.md), [TableInsère](3074025.md), [TableInsèreLigne](3074026.md), [TableInsèreFils](1000010005.md), ...
- l'image enroulée d'une des lignes du champ Table hiérarchique.
- l'image qui sera utilisée par défaut lors des prochains ajouts dans le champ Arbre. Cette image sera prise en compte par les fonctions [ArbreAjoute](3018012.md) et [ArbreInsère](3018023.md).
- l'image enroulée des lignes d'un état de type "Tableau hiérarchique".

## Exemple

```wlangage
// Définit l'image utilisée pour une ligne enroulée
TABLEH_Recette.ImageEnroulée = "C:\MesImages\Image.BMP"
```

```wlangage
// Change l'image enroulée de la ligne 4
TABLEH_Recette[4].ImageEnroulée = "C:\MesImages\Image.BMP"
```

> _(WINDEV, Etats et Requêtes, iPhone/iPad)_ // Change l'image enroulée dans l'état
// -- Avant impression de RUB_Hiérarchie
SI MoiMême.ProfondeurHiérarchique = 1 ALORS MoiMême.ImageEnroulée = "C:\Images\outil.png"

> _(WEBDEV - Code Serveur)_ // Change l'image enroulée de la ligne 4 d'un champ Table hiérarchique d'un site WEBDEV
// depuis un code serveur
// Le chemin relatif se base sur le répertoire WEB du site
// (connu par la fonction fRepWeb)
TABLEH_Recette[4].ImageEnroulée = ".\Image.png"

## Syntaxe

#### Connaître l'image par défaut d'une ligne enroulée ou l'image associée à une ligne spécifique

```wlangage
<Résultat> = <Champ manipulé>.ImageEnroulée
```

`<Résultat>` *Chaîne de caractères*
> - Nom et chemin complet de l'image associée par défaut aux lignes enroulées du champ.
> - Chaîne vide ("") si l'image utilisée par défaut n'a pas été modifiée.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler :
>
> - Champ Table hiérarchique.
> - Champ Arbre.
>
>
> Pour connaître l'image enroulée associée à une ligne spécifique d'un champ Table hiérarchique, il suffit d'utiliser la notation suivante :
>
>
> ```wlangage
> <Table hiérarchique>[<Numéro de la ligne>]
> ```

#### Modifier l'image par défaut d'une ligne enroulée ou l'image associée à une ligne spécifique

```wlangage
<Champ manipulé>.ImageEnroulée = <Nouvelle image>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler :
>
> - Champ Table hiérarchique.
> - Champ Arbre.
>
>
> Pour modifier l'image enroulée associée à une ligne spécifique d'un champ Table hiérarchique, il suffit d'utiliser la notation suivante :
>
>
> ```wlangage
> <Table hiérarchique>[<Numéro de la ligne>]
> ```
`<Nouvelle image>` *Chaîne de caractères*
> Nom et chemin complet de la nouvelle image associée par défaut à une ligne enroulée.
> > _(WEBDEV - Code Serveur)_ Le chemin d'accès des images doit être relatif au répertoire "<NomProjet>_WEB". Par exemple, dans ce cas, l'image est dans un sous-répertoire "Images" du répertoire "_WEB" du site :
>
> MoiMême.ImageDéroulée = "\Images\Job_16.gif"
> MoiMême.ImageEnroulée = "\Images\Job_16.gif"

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad)_ Connaître l'image d'une rubrique hiérarchique enroulée dans un état "Tableau hiérarchique" Masquer les détails
<Résultat> = <Rubrique hiérarchique>.ImageDéroulée

 <Résultat> : Chaîne de caractèresNom et chemin complet de l'image associée à une ligne enroulée de la rubrique hiérarchique. Chaîne vide ("") si aucune image n'est utilisée. <Rubrique hiérarchique> : Chaîne de caractèresNom de la rubrique hiérarchique à manipuler.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad)_ Modifier l'image d'une rubrique hiérarchique enroulée dans un état "Tableau hiérarchique" Masquer les détails
<Rubrique hiérarchique>.ImageDéroulée = <Nouvelle image>

 <Rubrique hiérarchique> : Chaîne de caractèresNom de la rubrique hiérarchique à manipuler. <Nouvelle image> : Chaîne de caractèresNom et chemin complet de la nouvelle image associée à une ligne enroulée de la rubrique hiérarchique.
