# XMLVérifieSignature (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Vérifie la signature d'un noeud XML.

## Exemple

```wlangage
maVérif est un xmlVérificationSignature
maVérif.Clé = "maclépublique.pem"

monDocXML est un xmlDocument = XMLOuvre("fichieraverifier.xml", XMLConserveNoeudTexteVide)

SI PAS XMLVérifieSignature(maVérif, monDocXML.Racine.NoeudSigne) ALORS
	Erreur("Signature invalide")
SINON
	Info("Ok")
FIN
```

## Syntaxe

```wlangage
<Résultat> = XMLVérifieSignature(<Vérification de signature> , <Noeud XML à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si la signature est correcte,
> - Faux dans le cas contraire.
`<Vérification de signature>` *Variable de type xmlVérificationSignature*
> Nom de la variable de type [xmlVérificationSignature](1410090389.md) contenant les informations nécessaires pour la vérification d'une signature XML.
`<Noeud XML à vérifier>` *Variable de type xmlNoeud*
> Noeud XML dont la signature doit être vérifiée.

## Remarques

Lors de l'ouverture du document XML via la fonction [XMLOuvre](1000018792.md), utilisez la constante *XMLConserveNoeudTexteVide*. En effet, le document ne doit subir aucune modification avant la vérification de la signature.
