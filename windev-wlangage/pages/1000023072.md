# Description d'Option (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Une variable de type **Description d'Option** permet de manipuler par programmation les caractéristiques d'une option de combinaison.
Les caractéristiques de ce type peuvent être connues à l'aide de différentes propriétés WLangage.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Récupère la définition du type de dd est une Définitiond = RécupèreDéfinition(ActionFichier)// Affiche le nom du type de dTrace(d.Nom) // Solution 1 : lister les options de la combinaisonSI d.Type = wlCombinaison ALORS  POUR TOUT MonElément DE d.Option  Trace(MonElément.Nom)  FINFIN// Solution 2 : lister les options de la combinaison // (en utilisant le type Description d'Option)SI d.Type = wlCombinaison ALORS D1 est une Description d'Option  POUR TOUT D1 DE d.Option  Trace(D1.Nom)  FINFIN
```

## Remarques

### Propriétés spécifiques à la description des variables du type Description d'Option
Les propriétés suivantes peuvent être utilisées pour manipuler une option de combinaison :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Alias | Booléen | - Vrai si l'option est un alias d'une option ou d'une combinaison d'options existante, - Faux dans le cas contraire.  **Cette propriété est disponible en lecture seulement**. |
| Déclaration | Variable de type [Définition](1000019540.md) | Déclaration de l'option.  **Cette propriété est disponible en lecture seulement**. |
| Hérité | Booléen | - Vrai si la combinaison est héritée d'une combinaison étendue, - Faux dans le cas contraire.  **Cette propriété est disponible en lecture seulement**. |
| Nom | Chaîne de caractères | Nom de l'option.  **Cette propriété est disponible en lecture seulement**. |
| Valeur | Tous types | Valeur de l'option.  **Cette propriété est disponible en lecture seulement**. |
| ValeurAssociée | Tous types | Valeur associée de l'option.  **Cette propriété est disponible en lecture seulement**. |
