# Centre de Gestion de Projets : Présentation

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Le Centre de Gestion de Projets permet de gérer le planning de réalisation d'un projet, de sa création à sa livraison finale. Il est ainsi possible de connaître l'ensemble des tâches à réaliser sur un projet, les développeurs concernés, les durées nécessaires, l'état d'avancement du projet, etc.
Après avoir listé l'ensemble des tâches d'un projet, le Centre de Gestion de Projets s'occupe de tout. La saisie du temps passé est quasi automatique, ne demande aucune action spécifique et ne génère aucune contrainte particulière. Pour plus de détails, consultez [Gestion du temps](3540713.md).

Lors de l'ouverture du projet concerné, le Centre de Gestion de Projets demande ou indique la tâche en cours. Dès qu'une tâche est réalisée, il suffit d'indiquer que cette tâche est terminée et de spécifier la nouvelle tâche.

Une tâche peut être reliée à un élément du projet (fenêtre, état, etc.). Chaque fois que l'élément concerné est ouvert, le temps passé sur cet élément est décompté et mémorisé dans le Centre de Gestion de Projets. Inversement, depuis la liste des tâches, il est possible d'ouvrir automatiquement l'élément correspondant à la tâche que vous voulez réaliser.

Chaque développeur peut également visualiser directement sa liste de tâches dans le volet "Centre de Gestion de Projets".

**Avertissement**

 En version 28, cet outil avait pour nom "Centre de Suivi de Projets".

## Lancement

Le Centre de Gestion de Projets peut être lancé :

- depuis WINDEV, WINDEV Mobile ou WEBDEV : sous le volet "Outils", dans le groupe "Centres de Contrôle", cliquez sur "Gestion de Projets".
- en exécutant directement le programme "CCSuivi.exe" présent dans le sous-répertoire "Programs" du répertoire d'installation de WINDEV, WINDEV Mobile ou WEBDEV.

Le Centre de Gestion de Projets permet à l'utilisateur d'afficher les données qui le concernent via plusieurs types de vues :

- Tableau de bord.
- [Tâches](3540704.md).
- [Incidents](3540723.md).
- [Exigences](3540716.md).
- [Planning](3540705.md).
- [Diagramme de Gantt](3540724.md).
- [Demandes](3540719.md).
- [Statistiques](3540714.md).
- [Messages](3540726.md).
- [Sprints](3540730.md).
- [Kanban](3540731.md).

Pour créer une nouvelle vue, vous pouvez :

- méthode 1 : cliquer sur le bouton "+" à droite des vues existantes.
- méthode 2 : dans le menu contextuel d'un onglet d'une vue, sélectionner l'option "Nouvelle vue".

Il est possible de créer plusieurs vues du même type mais affichant des données différentes.
**Astuce** : Par défaut, le libellé affiché dans l'onglet de la vue correspond au type du contenu (Tâches, Incidents, Planning, etc.) suivi du filtre discriminant utilisé dans le volet (nom de l'exigence, responsable de la tâche, développeur de l'incident, etc.).
Si vous affichez un grand nombre de vues et/ou que certaines vues ont un nom par défaut "identiques" (par exemple, 2 vues "Incidents" affichant 2 lots différents auront le même libellé), il peut être intéressant de renommer les volets des vues pour les rendre plus explicites et gagner de la place. Pour renommer un volet d'une vue :

1. Sélectionnez la vue voulue.
2. Affichez le menu contextuel de l'onglet de la vue (clic droit).
3. Dans le menu contextuel qui apparaît, sélectionnez l'option "Personnaliser le titre de la vue active".
4. Dans la fenêtre qui s'affiche, modifiez le titre de la vue et validez.

**Faire une recherche globale dans toutes les données du Centre de Gestion de Projets** :
Pour faire une recherche globale parmi les tâches, incidents, exigences :

1. Lancez la recherche par une des méthodes suivantes :
  - Déroulez  et sélectionnez l'option "Rechercher des items (Ctrl + Maj + F)".
  - Utilisez directement le raccourci clavier Ctrl + Maj + F.
  - Utilisez la loupe présente dans la barre de titre de Centre de Gestion de Projets.
2. Dans la fenêtre qui s'affiche, indiquez l'élément recherché :
  - Un mot tout seul : Le texte doit contenir un mot commençant par le mot indiqué.
  - Un mot entouré de guillemets : Le texte doit contenir le mot exact.
  - Plusieurs mots séparés par un espace : Le texte doit contenir tous les mots indiqués.
  - Un mot précédé du signe "-" : Le mot indiqué ne doit pas être présent dans le texte.
  - Un mot suivi de "int:<Intervenant>" : Le mot est recherché parmi les résultats de l'intervenant. Exemple : "aide int:doc"

### Conditions d'utilisation
Le Centre de Gestion de Projets n'est pas un outil redistribuable. Le Centre de Gestion de Projets ne peut pas être installé avec les applications développées avec WINDEV, WEBDEV ou WINDEV Mobile.
Pour utiliser le Centre de Gestion de Projets, WINDEV, WEBDEV ou WINDEV Mobile doivent obligatoirement être installés sur le poste en cours.

## Fonctionnalités

### Deux niveaux d'utilisation
Le Centre de Gestion de Projets permet de suivre la réalisation d'un projet.
Le Centre de Gestion de Projets propose deux niveaux d'utilisation :

- **Utilisation par un administrateur** (par défaut, le login et le mot de passe correspondent à "ADMIN").
  L'administrateur définit les projets, les intervenants, les tâches à réaliser. Seul l'administrateur peut donner les droits d'administrateur ou supprimer une tâche, etc.
  Remarque : Si vous utilisez une version précédente du Centre de Gestion de Projets, le login de l'administrateur peut correspondre à "SUPERVISEUR" (sans mot de passe).
- **Utilisation par un intervenant** :
  L'intervenant peut voir son planning, ajouter des tâches, les déplacer, configurer ses horaires de travail, modifier l'état d'une tâche, etc.

**Remarque** : Un intervenant peut créer un projet et être ***responsable de ce projet***. Dans ce cas, sur ce projet, le responsable de projet peut définir les tâches à réaliser, les intervenants, etc.

### Tâches réalisables par l'administrateur
Pour suivre la réalisation d'un projet, l'administrateur doit définir :

- le [projet](3540702.md).
- les [intervenants du projet](3540703.md).
- les [différentes tâches à réaliser par chacun des intervenants](3540704.md).
- les [spools de demandes](3540707.md).

Lorsque tous ces paramètres ont été définis, il est possible d'afficher les statistiques sur le suivi du projet (éléments réalisés et éléments à faire).

Cette configuration des projets se fait la plupart du temps par l'administrateur (par défaut, le login et le mot de passe correspondent à "ADMIN") ou par le responsable de projet.

### Utilisation
Le Centre de Gestion de Projets peut être utilisé par chaque intervenant d'un projet. Il permet à l'intervenant de :

- [Voir son planning et l'imprimer](3540705.md).
- [Voir sa liste des tâches pour un ou plusieurs projets](3540705.md).
- [Définir la tâche en cours](3540705.md).
- [Définir ses options de travail (jours, horaires de travail, etc.)](3540706.md).

Pour plus de détails sur l'utilisation du Centre de Gestion de Projets pour la gestion d'un planning et de ses tâches, consultez [Gestion du planning et des tâches](3540713.md).

### Liaison avec le volet "Centre de Gestion de Projets" de WINDEV, WEBDEV et WINDEV Mobile
Pour l'intervenant identifié par son login et son mot de passe sous WINDEV, WEBDEV ou WINDEV Mobile, le [volet "Centre de Gestion de Projets"](2027017.md) permet de :

- Visualiser les différentes tâches de l'intervenant,
- Démarrer ou arrêter une tâche
- Modifier l'ordre des tâches, etc.

### Mode "Invité"
Le Centre de Gestion de Projets propose un mode "Invité". Ce mode permet à un utilisateur non identifié de visualiser l'ensemble des informations contenues dans le Centre de Gestion de Projets (liste des tâches, plannings, liste des projets, etc.).
Pour lancer le Centre de Gestion de Projets en mode "Invité", il suffit de cliquer sur le bouton "Invité" dans la fenêtre de login.

**Pour autoriser le mode "Invité"** :

1. Déroulez [image: Menu du Centre de Gestion de Projets] puis sélectionnez "Options".
2. Sélectionnez "Options réservées aux administrateurs" puis sélectionnez l'option "Autoriser le mode invité".

**Remarque** : Seul un administrateur peut autoriser le mode "Invité". Le mode "Invité" n'est pas disponible si les fichiers de données des Centres de Contrôle sont au format HFSQL Client/Serveur.

### Accéder aux données du Centre de Gestion de Projets
Pour accéder aux données du Centre de Gestion de Projets, il est possible d'intégrer le composant **AccesExterne** dans votre projet.
Ce composant permet de consulter les données des Centres de Contrôle. Vous pouvez vous connecter à la base de données des Centres de Contrôle (HFSQL Classic, HFSQL Client/Serveur, PCSCloud ou GDSDrive) pour exporter au format JSON les données concernant les projets, les intervenants, les tâches, les incidents, les exigences.

Pour importer le composant **CCAccesExterne** dans le projet en cours :

1. Sous le volet "Projet", dans le groupe "Projet", déroulez "Importer" et sélectionnez "Un composant Externe .. Composant utilitaire ou exemple".
2. La liste des composants utilitaires et exemples est affichée.
3. Sélectionnez le composant **CCAccesExterne** et validez la fenêtre.
  Remarque : Vous pouvez également double-cliquer sur le composant pour l'importer dans votre projet.
4. La documentation associée à ce composant permet de connaître tous les détails de son mode de fonctionnement et de ses possibilités.
