# Fonctions de gestion des champs Agenda (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Les fonctions permettant de manipuler le champ Agenda via une syntaxe préfixée sont :

| [<Agenda>.Affiche](1000022880.md) | Réinitialise le contenu d'un champ Agenda à partir de sa source de données (fichier de données HFSQL par exemple). |
| --- | --- |
| [<Agenda>.AffichePériodePrécédente](1000022878.md) | Déplace la zone temporelle affichée sur la zone précédente (par exemple, semaines précédentes) dans un champ Agenda. |
| [<Agenda>.AffichePériodeSuivante](1000022896.md) | Déplace la zone temporelle affichée sur la zone suivante (par exemple, semaines suivantes) dans un champ Agenda. |
| [<Agenda>.AjouteRendezVous](1000022894.md) | Ajoute un nouveau rendez-vous dans un champ Agenda. |
| [<Agenda>.ChangeMode](1000022879.md) | Modifie la plage temporelle affichée par un champ Agenda (Jour/Semaine/Mois). |
| [<Agenda>.CouleurFond](1000022895.md) | Fixe une couleur de fond sur une plage horaire d'un champ Agenda. |
| [<Agenda>.DateVisible](1000022915.md) | Rend visible ou invisible un jour dans un champ Agenda. |
| [<Agenda>.HeureAffichée](1000022892.md) | Définit la plage horaire affichée par le champ Agenda en mode Jour ou Semaine. |
| [<Agenda>.HeureOuvrable](1000022916.md) | Permet d'indiquer les heures ouvrables spécifiques par jour dans un champ Agenda. |
| [<Agenda>.InfoXY](1000022889.md) | Renvoie pour une position donnée dans le champ Agenda (coordonnées d'un point de l'agenda) :   - soit l'indice du rendez vous pour la position indiquée. - soit la date correspondant à la position indiquée. |
| [<Agenda>.ListeRendezVous](1000022886.md) | Renvoie :   - la liste des rendez-vous compris entre deux dates données dans un champ Agenda, - tous les rendez-vous d'un champ Agenda, - un rendez-vous particulier (sélectionné ou survolé). |
| [<Agenda>.Mode](1000022885.md) | Renvoie le mode d'affichage par un champ Agenda : jour, semaine, mois, ... |
| [<Agenda>.PlageSélectionnée](1000022883.md) | Renvoie la date et l'heure de début ou de fin de la plage horaire sélectionnée dans un champ Agenda. |
| [<Agenda>.Position](1000022897.md) | Affiche un champ Agenda à partir d'une date spécifiée ou renvoie la date du premier jour (ou dernier jour) affiché dans un champ Agenda. |
| [<Agenda>.SelectMoins](1000022882.md) | Désélectionne un rendez-vous dans un champ Agenda. |
| [<Agenda>.SelectPlus](1000022881.md) | Sélectionne un rendez-vous dans un champ Agenda. |
| [<Agenda>.SupprimeRendezVous](1000022877.md) | Supprime un rendez-vous dans un champ Agenda. |
| [<Agenda>.SupprimeTout](1000022898.md) | Supprime tous les rendez-vous d'un champ Agenda. |
| [<Agenda>.VersiCalendar](1000022899.md) | Exporte les rendez-vous d'un champ Agenda au format iCalendar. |
