# Propriétés associées au champ Vignette

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

## Présentation

Les champs Vignette peuvent être manipulés avec les propriétés WLangage dans une page en code Serveur, Navigateur ou PHP.
