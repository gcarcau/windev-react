# Unicode (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **Unicode** permet de :

- Savoir si la valeur d'un champ est une chaîne Unicode.
- Indiquer si la valeur d'un champ est une chaîne Unicode.

**Remarque** : Cette propriété est particulièrement utile pour gérer les champs reliés à une rubrique HFSQL en Unicode.

## Exemple

```wlangage
// Teste si la valeur du champ SAI_MessageEmail est en Unicode
SI SAI_MessageEmail.Unicode = Faux ALORS
	SAI_MessageEmail.Unicode = Vrai
FIN
```

## Syntaxe

#### Savoir si la valeur du champ est en Unicode

```wlangage
<Résultat> = <Champ manipulé>.Unicode
```

`<Résultat>` *Booléen*
> - Vrai si la valeur du champ est en Unicode,
> - Faux dans le cas contraire.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.

#### Indiquer si la valeur d'un champ est en Unicode

```wlangage
<Champ manipulé>.Unicode = <Unicode/Ansi>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.
`<Unicode/Ansi>` *Booléen*
> - Vrai si la valeur du champ doit être en Unicode,
> - Faux dans le cas contraire.

## Remarques

### Gestion des alphabets non latins
Pour gérer les langues utilisant un alphabet non latin, il n'est pas nécessaire d'utiliser des champs Unicode. Il suffit d'utiliser la fonction [ChangeAlphabet](3054001.md).

### Limites
La propriété **Unicode** est disponible pour les champs suivants :

- Champ de saisie,
- Champ Combo,
- Champ Libellé,
- Champ Liste,
- Colonne de champ Table,
- Champ Liste image.
- Champ Tableau de bord (propriété disponible en lecture uniquement).
