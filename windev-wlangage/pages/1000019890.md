# FenForceGFI (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Force le GFI (Grisage des Fenêtres Inaccessibles) sur une fenêtre même si cette fenêtre n'est pas inaccessible.

## Exemple

```wlangage
Sablier(Vrai)
// Force le GFI sur la fenêtre principale
FenForceGFI(FEN_Principale, Vrai)
// Lance un calcul important
CalculImportant()
// Arrête le GFI sur la fenêtre principale
FenForceGFI(FEN_Principale, Faux)
Sablier(Faux)
```

## Syntaxe

```wlangage
FenForceGFI(<Fenêtre> , <Activation du GFI>)
```

`<Fenêtre>` *Nom de fenêtre*
> Nom de la fenêtre à manipuler.
`<Activation du GFI>` *Booléen*
> Nouvel état du GFI :
>
> - Vrai : le GFI est activé immédiatement sur la fenêtre spécifiée. La fenêtre s'affiche en grisé.
> - Faux : le GFI est désactivé immédiatement sur la fenêtre spécifiée. La fenêtre se réaffiche normalement (sauf si elle est inactive : elle reste alors grisée).

**Composante : wd300obj.dll**
