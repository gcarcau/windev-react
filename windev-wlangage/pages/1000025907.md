# HTMLOuvre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Charge un document HTML dans une variable de type [htmlDocument](1000025910.md).

## Exemple

```wlangage
d est un htmlDocument = HTMLOuvre("https://www.pcsoft.fr", depuisURL)
```

## Syntaxe

```wlangage
<Résultat> = HTMLOuvre(<Source HTML> [, <Type de source>])
```

`<Résultat>` *Variable de type htmlDocument*
> Variable de type [htmlDocument](1000025910.md) contenant la source spécifiée.
`<Source HTML>` *Chaîne de caractères*
> Document HTML à charger. Le contenu de ce document dépend du paramètre <Type de source>.
`<Type de source>` *Constante optionnelle de type Entier*
> Mode d'interprétation de la source. Les constantes disponibles sont les suivantes :
>
> | *depuisChaîne* | Le paramètre <Source HTML contient directement le contenu HTML. |
> | --- | --- |
> | *depuisFichier* | Le paramètre <Source HTML est un chemin de fichier. Le contenu HTML est chargé depuis ce fichier. |
> | *depuisURL* | Le paramètre <Source HTML est une URL. Le contenu HTML est récupéré depuis cette URL. |
>
>
> Si ce paramètre n'est pas spécifié, le type de la source est automatiquement déduit selon le contenu du paramètre <Source HTML> :
>
> - Si le paramètre <Source HTML> commence par "http://", la constante utilisée est *depuisURL*.
> - Si le paramètre <Source HTML> commence par une lettre de lecteur ou un chemin UNC, la constante utilisée est *depuisFichier*.
> - Dans tous les autres cas, la constante utilisée est *depuisChaîne*.
