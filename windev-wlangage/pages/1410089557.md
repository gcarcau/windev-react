# AuthImporteToken (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Crée un token d'accès à un webservice à partir d'une description de token au format JSON.

## Exemple

```wlangage
// Description JSON du token
jsToken est un JSON
jsToken.access_token = "iskrfbj65zKJHSFD"
jsToken.refresh_token = "LAJ5Vkjjnl54KJHK56354"
jsToken.token_type = "bearer"
jsToken.expires = 3600

// Date et heure de récupération du token
dhRecuperation est une DateHeure = "20230103101933000"

// Importation du token
MonToken est un AuthToken = AuthImporteToken(jsToken, dhRecuperation)
```

## Syntaxe

```wlangage
<Résultat> = AuthImporteToken(<Description JSON> [, <Date et heure récupération JSON>])
```

`<Résultat>` *Variable de type AuthToken*
> Variable de type [AuthToken](1000022220.md) correspondant à la description au format JSON.
> En cas d'erreur, la variable [ErreurDétectée](3087001.md) vaut Vrai et le message d'erreur correspondant peut être connu avec la fonction [ErreurInfo](3013008.md).
`<Description JSON>` *Chaîne de caractères*
> Description JSON du token d'accès au service Web (généralement renvoyée par une requête HTTP effectuée au service Web).
`<Date et heure récupération JSON>` *DateHeure optionnelle*
> Date et heure de récupération de la description du token au format JSON auprès du service Web concerné.
> Remarque : la description JSON d'un token renvoyée par un service Web contient une durée de validité du token. Il faut donc préciser la date et l'heure de récupération de la description du token auprès du service Web pour déterminer la date et heure d'expiration du token.
> Si ce paramètre n'est pas précisé, ce paramètre correspond à la date et heure en cours (résultat de la fonction [DateHeureSys](1000019398.md)).
