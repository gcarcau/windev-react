# <Variable Document>.VersTexte (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Crée une chaîne de caractères avec les données d'une variable de type [Document](1000022461.md).
Cette chaîne pourra ensuite par exemple être sauvegardée dans un format spécifique.

## Exemple

```wlangage
MonDocument est un Document

MaChaîne est une chaîne
MaChaîne = MonDocument.VersTexte()
// Sauvegarde dans un fichier texte
fSauveTexte("C:\temp\Contenu.txt", MaChaîne)
```

## Syntaxe

```wlangage
<Résultat> = <Document>.VersTexte()
```

`<Résultat>` *Chaîne de caractères*
> - Chaîne de caractères contenant les données.
> - Chaîne vide ("") en cas d'erreur ou s'il n'y a pas de données à extraire.
`<Document>` *Variable de type Document ou Chaîne de caractères*
> Nom de la variable de type [Document](1000022461.md) à manipuler.
