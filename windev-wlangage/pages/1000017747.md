# <Variable gglConnexion>.ListeAgenda (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Récupère la liste des agendas Google associés au compte Google spécifié. Cette fonction utilise le service Agenda Google Calendar.

## Exemple

```wlangage
// Connexion
Cnx est une gglConnexion
...
SI Cnx.Connecte() = Faux ALORS
	Erreur(ErreurInfo())
	RETOUR
FIN
tabAgendas est un tableau de gglAgenda
tabAgendas = Cnx.ListeAgenda(gglTous)
// Affichage du titre de chaque agenda
Agenda est un gglAgenda
POUR TOUT Agenda DE tabAgendas
	Trace(Agenda.Titre)
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Connexion Google>.ListeAgenda([<Filtre>])
```

`<Résultat>` *Tableau de variables de type gglAgenda*
> Liste des agendas Google du compte spécifié.
`<Connexion Google>` *Variable de type gglConnexion*
> Nom de la variable de type [gglConnexion](1000018009.md) à utiliser. Cette connexion a été validée avec la fonction [<Variable gglConnexion>.Connecte](1000021455.md).
`<Filtre>` *Constante de type Entier optionnelle*
> Indique le type d'agenda à lister :
>
> | *gglTous* (Valeur par défaut) | Liste tous les agendas souscrits (partagés) et créés par l'utilisateur en cours. |
> | --- | --- |
> | *gglUtilisateur* | Liste uniquement les agendas créés par l'utilisateur en cours. |

## Remarques

### Cas particuliers
Les agendas renvoyés ne contiennent pas leurs événements. Pour obtenir les événements des agendas, utilisez les fonctions [<Variable gglConnexion>.RemplitAgenda](1000017749.md) ou [<Variable gglConnexion>.RemplitAgendaParRequête](1000017750.md).
Pour obtenir l'agenda avec les événements associés, utilisez la fonction [<Variable gglConnexion>.RécupèreAgenda](1000017748.md).

### Cas d'erreurs possibles :

- La connexion Internet n'est pas valide.
- L'authentification n'a pas pu être réalisée correctement.
- La réponse XML du serveur n'est pas lisible.

Pour savoir si une erreur est survenue, utilisez la variable [ErreurDétectée](3087001.md).

### Limite
Seuls les 100 premiers agendas sont renvoyés.
