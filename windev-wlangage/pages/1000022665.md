# <Variable Connexion>.GèreTâche (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Active ou désactive une tâche planifiée d'un serveur HFSQL Client/Serveur. Cette fonction permet également de connaître l'état d'une tâche planifiée.
Il est ainsi possible par exemple de désactiver une tâche (pendant les vacances) puis de la réactiver.

## Syntaxe

#### Activer/Désactiver une tâche planifiée

```wlangage
<Résultat> = <Connexion>.GèreTâche(<Tâche planifiée> [, <Activer/Désactiver>])
```

`<Résultat>` *Booléen*
> Ancien mode de gestion de la tâche (avant utilisation de la fonction **<Variable Connexion>.GèreTâche**) :
>
> - Vrai si la tâche était active,
> - Faux si la tâche n'était pas active.
`<Connexion>` *Variable de type Connexion*
> Nom d'une variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle la tâche doit être gérée.
`<Tâche planifiée>` *Entier*
> Identifiant de la tâche planifiée à manipuler. Cet identifiant est fourni par les fonctions [<Variable Connexion>.AjouteTâche](1000022645.md) et [<Variable Connexion>.ListeTâche](1000022700.md).
`<Activer/Désactiver>` *Booléen optionnel*
> - Vrai pour activer la tâche,
> - Faux pour désactiver la tâche.

#### Connaître l'état d'une tâche planifiée

```wlangage
<Résultat> = <Connexion>.GèreTâche(<Tâche planifiée>)
```

`<Résultat>` *Booléen*
> - Vrai si la tâche est active,
> - Faux si la tâche n'est pas active.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle la tâche doit être gérée.
`<Tâche planifiée>` *Entier*
> Identifiant de la tâche planifiée à manipuler. Cet identifiant est fourni par les fonctions [<Variable Connexion>.AjouteTâche](1000022645.md) et [<Variable Connexion>.ListeTâche](1000022700.md).
