# gpwAucun (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Renvoie la valeur du mot "AUCUN" selon le framework utilisé ou la langue spécifiée. Le mot "AUCUN" est utilisé lorsqu'un utilisateur n'appartient pas à un groupe.
Remarque : Le groupware et les fichiers du groupware étant multilingues, il est ainsi possible de récupérer la valeur de la constante représentant le mot "AUCUN".

## Exemple

```wlangage
sCstAucun est une chaîne
sCstAucun = gpwAucun()
```

## Syntaxe

```wlangage
<Résultat> = gpwAucun([<Langue>])
```

`<Résultat>` *Chaîne de caractères*
> Valeur du mot "AUCUN".
> Si le paramètre <Langue> n'est pas spécifié, la valeur renvoyée dépend du framework utilisé :
>
>
> - "<AUCUN>" lorsque le framework est en français
> - "<NONE>" lorsque le framework est en anglais.
`<Langue>` *Constante optionnelle*
> Langue à utiliser pour obtenir la valeur correspondant à "AUCUN" :
>
> | *langueAnglais* | Valeur correspondant à "AUCUN" en Anglais : "NONE". |
> | --- | --- |
> | *langueEspagnol* | Valeur correspondant à "AUCUN" en espagnol : "NONE". |
> | *langueFrançais* | Valeur correspondant à "AUCUN" en français : "AUCUN". |

**Classification Métier / UI : Code neutre**

**Composante : wd300gpu.dll**
