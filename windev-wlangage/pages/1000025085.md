# Fonctions de gestion HFSQL (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Les fonctions de gestion des fichiers de données HFSQL (Syntaxe préfixée) sont :

| [<Destination>.CopieEnreg](1000024206.md) | Copie :   - le contenu de l'enregistrement en cours (chargé en mémoire) dans l'enregistrement en cours d'un fichier de données. - le contenu d'une variable de type [Enregistrement](1000020962.md) dans l'enregistrement en cours d'un fichier de données. |
