# <Image>.PositionDéfilement (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

Affiche le défilement à partir d'image spécifiée ou renvoie le nom de l'image affichée dans le défilement.

## Exemple

```wlangage
// Affiche l'image suivante (équivalent à NomImage.Suivante())
IMG_Bannière.PositionDéfilement(IMG_Bannière.PositionDéfilement() + 1)
```

## Syntaxe

#### Afficher un défilement à partir d'une image spécifiée

```wlangage
<Champ Image>.PositionDéfilement(<Indice>)
```

`<Champ Image>` *Nom de champ*
> Nom du champ à manipuler :
>
> - Champ Image.
> - Champ Image cliquable.
> - Champ Vignette.
`<Indice>` *Entier*
> Indice de l'image à afficher. Si ce paramètre est supérieur au nombre d'images à faire défiler (connu avec la fonction [<Image>.Occurrence](1000023750.md)), la première image est affichée par défaut.

#### Connaître l'indice de l'image affichée dans un défilement

```wlangage
<Résultat> = <Champ Image>.PositionDéfilement()
```

`<Résultat>` *Entier*
> Indice de l'image actuellement affichée.
`<Champ Image>` *Nom de champ*
> Nom du champ à manipuler :
>
> - Champ Image.
> - Champ Image cliquable.
> - Champ Vignette.

## Remarques

Utilisée dans un code serveur, la fonction **<Image>.PositionDéfilement** retourne l'indice de l'image en cours uniquement si le code serveur a été exécuté par un champ de type "Envoyer les valeurs au serveur (submit)".

**Composante : wd300page.dll**
