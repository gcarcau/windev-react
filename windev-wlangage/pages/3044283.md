# HInfoGroupe (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Renvoie des informations sur le groupe d'utilisateurs spécifié. Ces informations sont automatiquement affectées [aux variables de gestion des groupes d'utilisateurs](3044315.md).

## Exemple

```wlangage
// Description de la connexion
HDécritConnexion("MaConnexion", "Julie", "MotDePasse", "MonServeurHF", "MaBaseDeDonnées", ...
	hAccèsHFClientServeur, hOLecture)
// Ouverture de la connexion
HOuvreConnexion("MaConnexion")
// Association du fichier de données à la connexion
HChangeConnexion(Client, "MaConnexion")
...
// Recherche des caractéristiques d'un groupe
Res est un booléen
Res = HInfoGroupe("MaConnexion", "Groupe_Test")
SI Res = Vrai ALORS
	Trace("Structure du groupe mise à jour")
	Trace("Nom du groupe : " + HGroupe.Nom)
	Trace("Description du groupe : " + HGroupe.Description)
	Trace("Utilisateurs du groupe : " + HGroupe.Utilisateurs)
FIN
```

## Syntaxe

```wlangage
<Résultat> = HInfoGroupe(<Connexion> , <Groupe>)
```

`<Résultat>` *Booléen*
> - Vrai si les informations concernant le groupe ont été lues,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
>
>
> Remarque : Une erreur "Groupe inconnu" sera renvoyée par la fonction [HErreurInfo](3044071.md) si l'utilisateur en cours n'a pas le droit de visualisation des utilisateurs (constante *hDroitVisualisationUtilisateur*). Ce droit peut être défini par la fonction [HModifieDroitServeur](3044328.md).
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion à utiliser. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Groupe>` *Chaîne de caractères*
> Nom du groupe d'utilisateurs à manipuler.
