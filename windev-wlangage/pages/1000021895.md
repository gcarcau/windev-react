# Constantes Facebook

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, iPhone/iPad)

Les constantes utilisées par les fonctions de gestion des connexions Facebook sont les suivantes :

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |
| **fbEmail** | - Information à récupérer : Email de l'utilisateur. - Droits demandés à la connexion Facebook : permission "email" : Permet d'accéder à la première adresse email d'une personne. | - [FBRécupèreInformationUtilisateur](1000021837.md) - [Type fbSession](1000021851.md) |
| **fbIdentifiant** | Information à récupérer : Identifiant Facebook de l'utilisateur. | [FBRécupèreInformationUtilisateur](1000021837.md) |
| **fbImage** | Information à récupérer : Image de l'utilisateur. | [FBRécupèreInformationUtilisateur](1000021837.md) |
| **fbInfoAmis** | Droits demandés à la connexion Facebook : permission "user_friends" : Permet d'accéder à la liste des amis de votre application. | [Type fbSession](1000021851.md) |
| **fbInfoProfil** | Droits demandés à la connexion Facebook : permission "public_profile" : Permet d'accéder au profil public d'une personne. | [Type fbSession](1000021851.md) |
| **fbNom** | Information à récupérer : Nom de l'utilisateur. | [FBRécupèreInformationUtilisateur](1000021837.md) |
| **fbSessionFermée** | Etat de la session : Session Facebook fermée. | [FBEtatSession](1000021852.md) |
| **fbSessionOuverte** | Etat de la session : Session Facebook ouverte. | [FBEtatSession](1000021852.md) |
| **fbSessionPermissionIncorrecte** | Etat de la session : Session Facebook ouverte avec des droits différents de ceux de la session passée en paramètre. | [FBEtatSession](1000021852.md) |
