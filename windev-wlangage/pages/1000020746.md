# xmlSignatureRéférence (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le type **xmlSignatureRéférence** permet d'ajouter une partie référence dans la signature XML. Les caractéristiques de ce type de variable peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
Ce type de variable est utilisé par le type [xmlSignature](1000020736.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
ref est un xmlSignatureRéférence
ref.URI = "#id"
ref.AlgorithmeHash = HA_SHA_160
ref.Transformation[1] = atEnveloppée
ref.Transformation[2] = atC14NExclu
```

## Propriétés

### Propriétés spécifiques à la description des variables de type xmlSignatureRéférence
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **xmlSignatureRéférence** :

| **Nom de la propriété** | **Type manipulé** | **Effet** |
| --- | --- | --- |
| AlgorithmeHash | Constante de type Entier | Méthode utilisée pour le hachage de la référence :   - *HA_MD5_128* : Fonctions de hachage cryptographique classiques de type MD5. - *HA_RIPEMD_160* : Fonctions de hachage cryptographique classiques de type RIPEMD. - *HA_SHA_160* : Fonctions de hachage cryptographique classiques de type SHA. - *HA_SHA_256* : Fonctions de hachage cryptographique classiques de type SHA. - *HA_SHA_384* : Fonctions de hachage cryptographique classiques de type SHA. - *HA_SHA_512* : Fonctions de hachage cryptographique classiques de type SHA. |
| Transformation | Tableau de constantes de type Entier | Liste des transformations à appliquer aux données avant de passer l'algorithme de hachage. Les transformations possibles sont :   - *atAucune* : aucune transformation. - *atC14N11Inclus* : Transformation C14N11 inclusive. - *atC14N11InclusAvecCommentaire* : Transformation C14N11 inclusive avec commentaires. - *atC14NExclu* : Transformation C14N exclusive. - *atC14NExcluAvecCommentaire* : Transformation C14N exclusive avec commentaires. - *atC14NInclus* : Transformation C14N inclusive. - *atC14NInclusAvecCommentaire* : Transformation C14N inclusive avec commentaires. - *atEnveloppée* : Transformation par méthode enveloppée. |
| URI | Chaîne de caractères | Emplacement à signer. |
