# Belgique.VérifieUE (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un numéro UE (numéro d'unité d'établissement identifiant un établissement d'une entreprise en Belgique).

## Exemple

```wlangage
// Test d'une variableMonNuméroUE est une chaîne = "7123654957"Belgique.VérifieUE(MonNuméroUE) // renvoie Vrai // Test d'un champSAI_NuméroUE = "ABC"Belgique.VérifieUE(SAI_NuméroUE) // renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = Belgique.VérifieUE(<Numéro à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un numéro UE valide,
> - Faux dans le cas contraire.
`<Numéro à vérifier>` *Nom de champ ou variable de type chaîne*
> Numéro UE à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.

**Composante : wd300std.dll**
