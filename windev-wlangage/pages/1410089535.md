# Procédure WLangage appelée par la fonction KanbanFiltre

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Procédure WLangage (également nommée "callback") appelée par la fonction [KanbanFiltre](1410089534.md) pour effectuer un filtre avancé.

## Exemple

## Syntaxe

```wlangage
<Résultat> = KanbanFiltre_Callback(<Carte>)
```

`<Résultat>` *Booléen*
> - Vrai si la carte manipulée respecte la procédure de filtre et doit apparaître dans le résultat du filtre,
> - Faux dans le cas contraire.
`<Carte>` *Variable de type kbCarte*
> Variable de type [kbCarte](1410089167.md) manipulée par la procédure de filtre.

**Composante : wd300obj.dll**
