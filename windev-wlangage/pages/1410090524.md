# <Variable PolygoneGéo>.Corrige (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Permet d'obtenir une version corrigée du polygone géographique spécifié.
**Remarque** : Dans certains cas, il est possible de corriger automatiquement un certain nombre de problèmes dans une géométrie, tels que, par exemple, une mauvaise orientation des points dans un polygone.

## Exemple

```wlangage
// Correction d'un polygone géographique pour lequel il manque le dernier point
monPolygoneGéo est un PolygoneGéo
monPolygoneGéo.Contour.AjoutePoint(2.681548, 43.802043)
monPolygoneGéo.Contour.AjoutePoint(2.816297, 43.725179)
monPolygoneGéo.Contour.AjoutePoint(2.842733, 43.817899)
monPolygoneGéo.Contour.AjoutePoint(2.644979, 43.837466)
Trace("monPolygoneGéo.EstValide() = " + monPolygoneGéo.EstValide()) // Affiche "Faux"

// Correction
monPolygoneGéo_corrigé est un PolygoneGéo
monPolygoneGéo_corrigé = monPolygoneGéo.Corrige()
Trace("monPolygoneGéo_corrigé.EstValide() = " + monPolygoneGéo_corrigé.EstValide()) // Affiche "Vrai"
Trace("monPolygoneGéo.EstValide() = " + monPolygoneGéo.EstValide())
// Affiche toujours "Faux" : la géométrie donnée en paramètre n'est pas modifiée
```

## Syntaxe

```wlangage
<Résultat> = <Géométrie>.GéométrieCorrige()
```

`<Résultat>` *Variable correspondant à la géométrie manipulée*
> Géométrie corrigée.
`<Géométrie>` *Variable de type PolygoneGéo*
> Nom de la variable de type [PolygoneGéo](1410090127.md) à manipuler.
