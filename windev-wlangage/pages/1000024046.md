# <Saisie>.SupprimeJeton (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Supprime un jeton dans un champ de saisie de type "Jetons de texte".

## Exemple

```wlangage
// Clic sur [Supprimer le robot de test]
SAI_Destinataire.SupprimeJeton("robotmail@adresse.test.fr")
```

## Syntaxe

#### Supprimer un jeton identifié par sa valeur

```wlangage
<Résultat> = <Champ de saisie>.SupprimeJeton(<Valeur>)
```

`<Résultat>` *Booléen*
> - Vrai si le jeton a pu être supprimé,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ de saisie>` *Nom de champ*
> Nom du champ de saisie de type "Jetons de texte".
`<Valeur>` *Chaîne de caractères*
> Valeur mémorisée du jeton à supprimer. Si plusieurs jetons ont la même valeur, seul le premier jeton sera supprimé.

#### Supprimer un jeton identifié par son indice

```wlangage
<Résultat> = <Champ de saisie>.SupprimeJeton(<Indice>)
```

`<Résultat>` *Booléen*
> - Vrai si le jeton a pu être supprimé,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ de saisie>` *Nom de champ*
> Nom du champ de saisie de type "Jetons de texte".
`<Indice>` *Entier*
> Indice du jeton à supprimer.
