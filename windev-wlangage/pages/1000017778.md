# Catégorie (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

La propriété **Catégorie** permet de connaître et de modifier la catégorie d'un élément. Cette propriété est utilisable sur :

- une variable de type [Email](1000018713.md).
- une variable de type [EvénementTimeline](1000020612.md).
- une variable de type [RendezVous](1000019244.md).
- une variable de type [rssCanal](1000017769.md).
- une variable de type [rssEntrée](1000017792.md).
- la structure [Email](3032029.md).
- une variable de type [docPropriété](1000022945.md).
- une variable de type [Notification](1000019441.md).
