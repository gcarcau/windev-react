# SaaSAdminDéconnecte (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Termine la session d'administration d'une base SaaS.

## Exemple

```wlangage
// Connexion d'administration à la base SaaS
SI SaaSAdminConnecte("admin", "secret") = Faux ALORS
	Erreur("Vous n'êtes pas autorisé à vous connecter en tant qu'administrateur")
	RETOUR
FIN

...

// Fin de la session d'administration
SaaSAdminDéconnecte()
```

## Syntaxe

```wlangage
<Résultat> = SaaSAdminDéconnecte()
```

`<Résultat>` *Booléen*
> - Vrai si la déconnexion a été effectuée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).

**Composante : wd300com.dll**
