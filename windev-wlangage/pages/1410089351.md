# Canada.VérifieNAS (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un numéro NAS (numéro d'assurance sociale du Canada).

## Exemple

```wlangage
// Test d'une variableMonNuméroNAS est une chaîne = "046454286"Canada.VérifieNAS(MonNuméroNAS)  // renvoie Vrai // Test d'un champSAI_NuméroNAS = "ABC"Canada.VérifieNAS(SAI_NuméroNAS) // renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = Canada.VérifieNAS(<Numéro à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un numéro NAS valide.
> - Faux dans le cas contraire.
`<Numéro à vérifier>` *Nom de champ ou variable de type chaîne*
> Numéro NAS à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.

**Composante : wd300std.dll**
