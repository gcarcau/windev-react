# Configuration du serveur Apache 2.4

> **Disponible :** **WEBDEV** (Windows)

## Configuration du serveur pour le protocole CGI

Pour configurer le serveur Web :

1. Editez le fichier "httpd.conf" sous un éditeur de texte.
  Ce fichier est présent dans le sous-répertoire "/Conf" du répertoire d'installation du serveur Apache.
2. Ajoutez dans le fichier "httpd.conf" la définition de l'alias du protocole CGI (WD300AWP.EXE) par la ligne suivante :
  ```wlangage
  ScriptAlias /<Alias>/ "Répertoire du moteur"<Directory "Répertoire du moteur">Require all granted</Directory>
  ```
  - **Exemple : Poste de développement** : le moteur est situé dans le répertoire "C:\WEBDEV\Programs\Engine\WINDOWS\AWP" et le nom de l'alias est WD300AWP :
    ```wlangage
    ScriptAlias /WD300AWP/ "C:/WEBDEV/PROGRAMS/ENGINE/WINDOWS/AWP/"<Directory "C:/WEBDEV/PROGRAMS/ENGINE/WINDOWS/AWP/">Require all granted</Directory>
    ```
  - **Exemple : Poste de déploiement** : le moteur est situé dans le répertoire "C:\WEBDEV\Engine\WINDOWS\AWP" et le nom de l'alias est WD300AWP :
    ```wlangage
    ScriptAlias /WD300AWP/ "C:/WEBDEV/ENGINE/WINDOWS/AWP/"<Directory "C:/WEBDEV/ENGINE/WINDOWS/AWP/">Require all granted</Directory>
    ```
3. Redémarrez le serveur Apache.

**Remarques** :

- les caractères \ deviennent des /
- ne pas oublier le / final dans le chemin.
- respecter les différences entre majuscules / minuscules.

## Configuration du serveur pour les sites WEBDEV

Pour configurer le serveur Web :

1. Editez le fichier "httpd.conf" sous un éditeur de texte. Ce fichier est présent dans le sous-répertoire "/Conf" du répertoire d'installation du serveur Apache.
2. Ajoutez dans le fichier "httpd.conf" la définition de l'alias des images de chaque site WEBDEV :
  ```wlangage
  ;alias pour les images, les js, fichiers statiques, css...Alias /<Nom alias Image>/ "Répertoire des images de l'application"<Directory "Répertoire des images de l'application">Require all granted</Directory>
  ```
3. Ajoutez si nécessaire les informations permettant de gérer les URLs courtes dans le fichier "httpd.conf" :
  ```wlangage
  ;pour la gestion des URLs courtes<Files NomDuProjet> Require all granted ForceType application/WEBDEV30-awp </Files>
  ```
4. Par exemple pour le site WEBDEMO.
  ```wlangage
  ;alias pour les images, les js, fichiers statiques, css...Alias /WEBDEMO_WEB/ "C:/WEBDEMO/WEBDEMO_WEB/"<Directory "C:/WEBDEMO/WEBDEMO_WEB/">Order allow,denyAllow from all</Directory>;pour la gestion des URLS courtes<Files WEBDEMO> Require all granted ForceType application/WEBDEV30-awp </Files>
  ```
5. Redémarrez le serveur Apache.

### Attention

- Avec le serveur Web Apache, le nom de l'alias est "case sensitive". Il est nécessaire de respecter la casse définie pour l'alias dans les pages HTML faisant référence au répertoire des images.
- Il est nécessaire de définir un alias d'images pour chaque site WEBDEV.

## Configuration du serveur pour les sites utilisant des pages AWP (Active Web Pages)

Pour configurer le serveur Web :

1. Editez le fichier "httpd.conf" sous un éditeur de texte. Ce fichier est présent dans le sous-répertoire "/Conf" du répertoire d'installation du serveur Apache.
2. Dans la partie "AddType", ajoutez la ligne suivante :
  ```wlangage
  AddType application/WEBDEV30-awp .awpAddType application/WEBDEV30-awws .awws
  ```
3. Dans la partie "Action", ajoutez la ligne suivante :
  - Sous Windows :
    ```wlangage
    Action application/WEBDEV30-awp /WD300AWP/WD300AWP.exe virtualAction application/WEBDEV30-awws /WD300AWP/WD300AWP.exe virtual
    ```
  - Sous Linux :
    ```wlangage
    Action application/WEBDEV30-awp /WD300AWP/WD300AWP virtualAction application/WEBDEV30-awws /WD300AWP/WD300AWP virtual
    ```

Remarque : dans cette ligne, WD300AWP correspond à l'alias du moteur.
