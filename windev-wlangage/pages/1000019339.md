# Définition (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Apple Watch, Mac Catalyst)

La propriété **Définition** permet de gérer la définition d'un type. Cette propriété est utilisée par :

- une variable de type [Description de Propriété](1000019324.md).
- une variable de type [Description de Variable](1000019560.md).
