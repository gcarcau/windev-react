# xlsNbLignes (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

|  | **But** Obtenir le nombre de lignes d'un fichier XLS.  **Syntaxe (utilisant le type xlsDocument)**  <Résultat = xlsNbLignes(<Document XLS>)   - <Résultat est un entier. - <Document XLS est le nom de la variable de type [xlsDocument](1000017464.md) correspondant au fichier XLS à manipuler.   **Syntaxe (compatibilité version 12)**  <Résultat = xlsNbLignes(<NumFichier>)   - <Résultat est un entier. - <NumFichier est un entier contenant l'identifiant du fichier fourni par xlsOuvre.   **Détail**  **xlsNbLignes** retourne :   - le nombre de lignes du fichier XLS : Les lignes vides ne sont pas prises en compte. - -1 en cas d'erreur : la fonction xlsErreur permet de connaître le libellé de l'erreur |
