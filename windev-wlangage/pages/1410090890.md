# <Variable Connexion>.ListeHistoriquePlanification (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Liste l'historique d'exécution d'une opération planifiée sur un serveur HFSQL : tâche planifiée (procédure stockée), sauvegarde, optimisation, rafraîchissement d'une vue matérialisée.

## Exemple

```wlangage
MaConnexionBase est une Connexion
MonTableau est un tableau de hHistoriquePlanification

MonTableau = MaConnexionBase.ListeHistoriquePlanification(MaTachePlanifiée)
SI ErreurDétectée = Vrai ALORS
	Trace(HErreurInfo())
FIN
```

## Syntaxe

#### Lister l'historique d'exécution d'une planification de sauvegarde

```wlangage
<Résultat> = <Connexion>.ListeHistoriquePlanification([<Planification de sauvegarde> [, <Nombre d'élément>]])
```

`<Résultat>` *Tableau de variables de type hHistoriquePlanification*
> Tableau de variables de type [hHistoriquePlanification](1410090764.md), correspondant aux différentes exécutions de la sauvegarde planifiée.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion à manipuler.
`<Planification de sauvegarde>` *Variable de type hDescriptionSauvegarde optionnelle*
> Nom de la variable de type [hDescriptionSauvegarde](1000017455.md) pour laquelle l'historique doit être listé. Si ce paramètre n'est pas précisé, le résultat correspondra à l'historique d'exécution de toutes les planifications de sauvegarde définies pour la connexion.
`<Nombre d'élément>` *Entier optionnel*
> Nombre maximum d'éléments de l'historique à lister.
> Remarque : Par défaut, 100000 éléments sont stockés dans l'historique. Il est possible de modifier cette limite soit avec la fonction [<Variable Connexion>.GèreServeur](1000022664.md), soit via le fichier [HFCONF.INI](3044345.md).
