# <Variable Connexion>.RSAjouteConfig (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Ajoute une réplication entre deux serveurs HFSQL sur le poste serveur maître.

## Exemple

```wlangage
MaConnexion est une Connexion

ConfigRéplication1 est un hRSConfig
ConfigRéplication1.Serveur = "atlas.masociete.com:4996"
Ajoute(ConfigRéplication1.Fichier, "Mabase")
Ajoute(ConfigRéplication1.Fichier, "-Mabase\Monfichier.fic")
MaConnexion.RSAjouteConfig(ConfigRéplication1, hrsSansCopie)
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.RSAjouteConfig(<Réplication à effectuer> , <Option> [, <Jauge>])
```

`<Résultat>` *Booléen*
> - Vrai si la réplication a été ajoutée,
> - Faux dans le cas contraire. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion vers le serveur HFSQL maître.
`<Réplication à effectuer>` *Variable de type hRSConfig*
> Nom de la variable de type [hRSConfig](1000020484.md) décrivant la réplication à effectuer.
`<Option>` *Constante de type Entier*
> Action à réaliser :
>
> | *hrsCopie* | Active la copie initiale des éléments répliqués du serveur de la connexion (serveur maître) vers l'autre serveur (serveur abonné, défini dans la variable de type [hRSConfig](1000020484.md)). Cette copie est bloquante.  Compatibilité avec les versions précédentes : Correspond à Vrai dans les versions précédentes. |
> | --- | --- |
> | *hrsCopieTâcheDeFond* | Active la copie initiale des éléments répliqués du serveur de la connexion (serveur maître) vers l'autre serveur (serveur abonné, défini dans la variable de type [hRSConfig](1000020484.md)). Cette copie est réalisée en tâche de fond et n'est pas bloquante.  Pour savoir si la copie a été réalisée :    1. Listez les réplications disponibles avec la fonction [<Variable Connexion>.RSListeConfig](1000023554.md). 2. Si la réplication voulue n'est pas listée, elle n'a pas été ajoutée. 3. Si la réplication voulue est présente, consultez la valeur de la propriété **Initialisation** de la variable [hRSConfig](1000020484.md). Si cette propriété :   - est comprise entre 0 et 1000, la réplication est en cours d'ajout.  - vaut 1000, la réplication a été ajoutée.  - n'est pas renseignée, l'ajout de la réplication est en échec. |
> | *hrsSansCopie* | Aucune copie n'est réalisée.  Compatibilité avec les versions précédentes : Correspond à Faux dans les versions précédentes. |
`<Jauge>` *Nom de champ optionnel*
> Nom du champ Jauge permettant de visualiser l'avancement de la copie initiale.
