# Continent (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le type **Continent** permet de connaître les caractéristiques d'un continent. Les caractéristiques de ce continent peuvent être :

- récupérées avec les fonctions [ContinentRécupère](1000024933.md) et [ContinentListe](1000024932.md).
- connues à l'aide de différentes propriétés WLangage.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Récupération des informations sur l'Europe
oContinent est un Continent = ContinentRécupère(continentEurope)
// Affichage du libellé
LIB_Continent = oContinent.Nom
```

## Propriétés

### Propriétés spécifiques à la description des variables de type Continent
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **Continent** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Code | Constante de type Chaîne de caractères | Constante identifiant le continent :  - *continentAfrique* : Afrique (la constante vaut "AF") - *continentAmériqueNord* : Amérique du Nord (la constante vaut "NA") - *continentAmériqueSud* : Amérique du Sud (la constante vaut "SA") - *continentAntarctique* : Antarctique (la constante vaut "AN") - *continentAsie* : Asie (la constante vaut "AS") - *continentEurope* : Europe (la constante vaut "EU") - *continentIndéfini* : Le continent n'a pas pu être identifié. - *continentOcéanie* : Océanie (la constante vaut "OC")   **Cette propriété est disponible en lecture seulement**. |
| Nom | Chaîne de caractères | Nom du continent (dans la langue du framework).  **Cette propriété est disponible en lecture seulement**. |

## Remarques

### Fonctions WLangage utilisant les variables de type Continent

| [ContinentListe](1000024932.md) | Renvoie la liste des continents. |
| --- | --- |
| [ContinentRécupère](1000024933.md) | Renvoie la variable de type [Continent](1000024919.md) correspondant à une des valeurs suivantes :   - une constante continent (code continent sur 2 caractères), - un libellé de continent. |
| [PaysListe](1000024930.md) | Renvoie la liste de tous les pays ou des pays d'un continent donné selon la norme ISO 3166-1. |
