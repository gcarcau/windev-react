# URL (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

La propriété **URL** permet de :

- Connaître l'adresse associée à un champ.
- Modifier l'adresse associée à un champ.

Ce champ peut correspondre :

- sous l'éditeur de fenêtres à un Champ d'affichage HTML.
- sous l'éditeur de pages, à un lien, un bouton, une image cliquable, un champ iFrame, un champ Page cornée, un champ Code-barres ou une option de menu (définie sous l'éditeur ou par programmation).
- sous l'éditeur d'états, à un lien.

## Exemple

```wlangage
LIEN_LIEN1.URL = "http://www.pcsoft.fr"
```

## Syntaxe

#### Connaître l'adresse associée à un champ

```wlangage
<Résultat> = <Champ manipulé>.URL
```

`<Résultat>` *Chaîne de caractères*
> Adresse associée au champ.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler :
>
> - Champ d'une fenêtre : champ d'affichage HTML.
> - Champ d'une page : Lien, Bouton, Image, iFrame, Page cornée, Code-barres ou option de menu.
> - Champ d'un état : Lien.

#### Modifier l'adresse associée à un lien

```wlangage
<Champ manipulé>.URL = <Nouvelle adresse>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler :
>
> - Champ d'une fenêtre : champ d'affichage HTML.
> - Champ d'une page : Lien, Bouton, Image, iFrame, Page cornée, Code-barres ou option de menu.
> - Champ d'un état : Lien.
`<Nouvelle adresse>` *Tout type*
> Nouvelle adresse associée au lien. Cette adresse doit contenir "http://".

## Remarques

> _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur, PHP, Ajax)_ Propriété URL et propriété ValeurLa propriété URL a le même effet que la propriété Valeur sur les champs Bouton, Lien et iFrame.

### Limites

> _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur, WEBDEV - Code Serveur)_ La propriété URL est disponible uniquement sur :les champs Lien d'une page.les champs Bouton d'une page.les champs Image cliquable d'une page.les champs iFrame d'une page.les options de menu d'une page.les champs Page cornée d'une page.les champs Code-barres d'une page. les champs Lien d'un état.

> _(PHP)_ La propriété URL peut être utilisée uniquement sur :les champs Lien d'une page.les champs Image d'une page.les champs Image cliquable d'une page.les liens d'un champ Chemin de navigation.les champs Page cornée d'une page.les champs Captcha d'une page.les options de menu d'une page.
