# TypeTri (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **TypeTri** permet de :

- Connaître le sens de parcours défini pour une rubrique ou pour une composante d'une clé composée. Cette rubrique a été définie sous l'éditeur d'analyses ou par programmation.
- Définir le sens de parcours d'une rubrique ou d'une composante de clé composée (lors de la description de la rubrique par programmation uniquement).

## Exemple

```wlangage
// Connaître le sens de tri de la composante Nom de la clé composée NomPrénom
Res est un entier
Res = Client.NomPrénom[1].TypeTri
SELON Res
	CAS hCroissant : Info("Tri croissant sur Nom")
	CAS hDécroissant : Info("Tri décroissant sur Nom")
	CAS hNonTrié : Info("Pas de tri sur Nom")
FIN
```

## Syntaxe

#### Connaître le sens de parcours d'une rubrique

```wlangage
<Résultat> = <Fichier de données>.<Rubrique>.TypeTri
```

`<Résultat>` *Constante de type entier*
> Tupe de tri :
>
>
> | *hCroissant* | Ordre croissant (ascendant) |
> | --- | --- |
> | *hDécroissant* | Ordre décroissant (descendant) |
> | *hNonTrié* | Rubrique non triée |
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données manipulé.
`<Rubrique>` *Chaîne de caractères*
> Nom de la rubrique manipulée.
> Si la rubrique correspond à une composante de clé composée, le paramètre <Nom de la rubrique> correspond à :**<Nom de la clé composée>[<Indice de la composante>]**.
> Exemple : NomPrénom[1].

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS, Code Utilisateur (MCU), Ajax)_ Définir le sens de parcours d'une rubrique décrite par programmation Masquer les détails
<Rubrique>.TypeTri = <Sens du tri>

 <Rubrique> : Chaîne de caractèresNom de la rubrique manipulée. Ce nom vient d'être défini grâce au type Description de Rubrique. Si la rubrique correspond à une composante de clé composée, le paramètre <Nom de la rubrique> correspond à : <Nom de la clé composée>[<Indice de la composante>].Exemple : NomPrénom[1]. <Sens du tri> : Constante de type EntierType de tri : hCroissantOrdre croissant (ascendant)hDécroissantOrdre décroissant (descendant)hNonTriéRubrique non triée
