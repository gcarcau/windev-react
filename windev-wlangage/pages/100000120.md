# Erreur 120 : Redéfinition de la structure

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Cause

Vous tentez de déclarer deux structures du même nom dans le même traitement.

## Correction

Renommez une des structures ou supprimez la déclaration inutile.

## Exemples

### Deux structures du même nom sont déclarées dans le même traitement
**Code provoquant l'erreur**
```wlangage
Coord_Point est une Structure x,y sont des entiersFIN ... Coord_Point est une Structure x,y sont des entiersFIN
```

**Correction proposée**

Supprimez la seconde structure (déclaration inutile).

```wlangage
Coord_Point est une Structure x,y sont des entiersFIN
```

### Deux structures de même nom mais utilisant des membres différents sont présentes dans le même traitement
**Code provoquant l'erreur**
```wlangage
Coord_Point est une Structure x,y sont des entiersFIN ... Coord_Point est une Structure Coord_x,Coord_y sont des réelsFIN
```

**Correction proposée**

Supprimez la seconde déclaration (déclaration inutile).

```wlangage
Coord_Point est une Structure x,y sont des entiersFIN ... Coord_Point_Image est une Structure Coord_x,Coord_y sont des réelsFIN
```
