# PageExiste (Fonction)

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur)

Vérifie si la page spécifiée est actuellement affichée dans le navigateur de l'internaute.
Permet de savoir par exemple si une page est affichée dans un cadre différent de celui en cours.

## Exemple

```wlangage
// Vérifie si la page "PAGE_Inscription" est affichée
PageExiste(PAGE_Inscription)
```

## Syntaxe

```wlangage
<Résultat> = PageExiste(<Page>)
```

`<Résultat>` *Booléen*
> - Vrai si la page est actuellement affichée,
> - Faux dans le cas contraire.
`<Page>` *Nom de page*
> Nom de la page dont l'existence doit être vérifiée.

## Remarques

Pour vérifier si un contexte de page est ouvert sur le serveur, utilisez la fonction serveur [ContexteExiste](3058002.md).

**Classification Métier / UI : Code UI**

**Composante : WDJS.DLL**
