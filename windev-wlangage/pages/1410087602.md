# Fonctions de gestion des permissions Android

> **Disponible :** **WINDEV Mobile** (Android, Widget Android)

Les fonctions permettant de gérer les permissions des applications Android sont les suivantes :

| [PermissionDemande](1410087423.md) | Demande à l'utilisateur d'accorder une permission à l'application. |
| --- | --- |
| [PermissionListe](1410087429.md) | Renvoie une ou toutes les permissions déclarées par l'application. |
