# Barre des documents ouverts

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

La barre des documents de l'environnement permet de naviguer entre les différents éléments ouverts sous les différents éditeurs.
Si l'éditeur de code affiche un événement WLangage d'un élément d'une fenêtre, les onglets de l'UI et du code sont regroupés dans la barre.
Nouveauté 2025
Dans l'onglet correspondant au code, le nom de l'événement WLangage est affiché.

[image: Barre des documents]

Le survol d'un bouton affiche une vignette de l'aperçu : fenêtre, état, requête, code, etc.

[image: Visualisation du document dans la barre]

Chaque document peut être fermé par une croix dans le bouton ou dans la vignette d'aperçu, ce qui est plus rapide. Il est également possible de cliquer sur la roulette de la souris : l'élément survolé est alors fermé.

**Si le nombre de choix est supérieur à l'espace disponible pour son affichage**, la barre devient scrollable : il suffit d'utiliser la roulette de la souris pour faire défiler les différents éléments.
Il est également possible de déplacer un bouton de la barre par un simple "Drag and Drop".

Un menu permet d'afficher la liste de tous les éléments ouverts.

Remarques :

- Le menu contextuel de la barre des documents (et non pas d'un document) permet de rouvrir le ou les éléments qui ont été précédemment ouverts puis fermés (option "Récemment fermés").
- En fonction des ressources Windows disponibles, les éléments du projet les plus anciens ouverts sous l'éditeur seront fermés si nécessaire.

### Menu contextuel des boutons
Le menu contextuel de chacun des boutons de cette barre propose de nombreuses options. L'option "Fermer tout sauf moi-même" est vraiment incontournable.
**Utilisation du GDS** :
Si le projet est présent dans le GDS, le menu contextuel s'adapte. Plusieurs options permettent de manipuler l'élément en cours. Nouveauté 2025
L'option "Fermer les documents non extraits" permet de conserver uniquement les documents en cours de modification.
