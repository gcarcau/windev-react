# NuméroPage (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **NuméroPage** permet de connaître et de modifier le numéro d'une page. Cette propriété est utilisable sur :

- un champ Image ou un état. Pour plus de détails, consultez [NuméroPage](2510106.md).
- une variable de type [pdfSignet](1410089195.md).
