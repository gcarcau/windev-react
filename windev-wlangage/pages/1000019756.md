# Fonctions de gestion du multi-touch

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions de gestion des gestes sur un téléphone (iOS/Android) ou dans un site (multi-touch) sont les suivantes :

| [GesteNbPointeur](1000019750.md) | Retourne le nombre de pointeurs en contact avec l'écran. |
| --- | --- |
| [GestePointeurEncours](1000019751.md) | Retourne l'indice du pointeur (doigt ou stylet) ayant déclenché l'appel d'un traitement spécifique au multi-touch dans un champ Image. |
| [GestePosX](1000019741.md) | Retourne la position horizontale du pointeur (doigt ou stylet). |
| [GestePosY](1000019745.md) | Retourne la position verticale du pointeur (doigt ou stylet). |
| [GesteTypePointeur](1000023785.md) | Renvoie le type de pointeur utilisé sur l'appareil : doigt, souris ou stylet. |
