# Applique (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Exécute une procédure pour chaque élément d'un tableau WLangage.
Cette fonction est utilisable :

- sur les tableaux à une dimension,
- sur les tableaux associatifs.
   Non disponible.

## Exemple

```wlangage
// Remplit un champ Liste avec les noms des clients
tabClient est un tableau de Client
Applique(tabClient, UnClient=>{ListeAjoute(LISTE_Client, UnClient.Nom)})
```

> _(Windows, Linux, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)_ tabValeurs est un tableau d'entiers = [1,2]
Applique(tabValeurs,(valeur,clé) => {Trace(valeur * 2, clé)})

> _(Windows, Linux, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)_ dictValeurs est tableau associatif d'entiers
dictValeurs["A"] = 1
dictValeurs["B"] = 2
dictValeurs["C"] = 3
dictValeurs["D"] = 4
Applique(dictValeurs,valeur => {Trace(valeur * 2)})
Applique(dictValeurs,(valeur,clé) => {Trace(valeur * 2, clé)})

## Syntaxe

```wlangage
Applique(<Tableau source> , <Opération à effectuer>)
```

`<Tableau source>` *Tableau WLangage*
> Nom de la variable de type Tableau à manipuler. Ce tableau peut être :
>
> - un tableau à une dimension.
> - un tableau associatif.
>    Non disponible.
`<Opération à effectuer>` *Procédure WLangage*
> Nom de la procédure WLangage à exécuter pour chaque élément du <Tableau source>. Cette procédure peut être :
>
> - une procédure globale ou locale,
> - une procédure interne.
>
> Il est également possible d'utiliser directement une procédure lambda.

## Remarques

### Fonctionnement
La procédure <Opération à effectuer> est appelée pour chaque élément du tableau. La procédure reçoit en paramètre :

- l'élément manipulé.
- la clé de l'élément.
  Dans le cas d'un tableau simple, la clé correspond à l'indice de l'élément. Ce paramètre est optionnel.
  Dans le cas d'un tableau associatif, la clé correspond à la clé d'indexation des éléments.
   Non disponible.

Les résultats de tous les appels ne sont pas stockés.
