# Propriétés associées au champ Graphe

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Un champ Graphe peut être utilisé :

- dans une fenêtre,
- dans une page,
- dans un état.

Les propriétés associées au champ varient en fonction du lieu d'utilisation.
