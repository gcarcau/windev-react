# <Variable Connexion>.SupprimeTâche (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Supprime une tâche planifiée d'un serveur HFSQL Client/Serveur.

## Syntaxe

```wlangage
<Résultat> = <Connexion>.SupprimeTâche(<Tâche à supprimer>)
```

`<Résultat>` *Booléen*
> - Vrai si la tâche a été supprimée,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle la tâche doit être supprimée.
`<Tâche à supprimer>` *Entier*
> Identifiant de la tâche à supprimer. Cet identifiant est fourni par les fonctions [<Variable Connexion>.AjouteTâche](1000022645.md) et [<Variable Connexion>.ListeTâche](1000022700.md).

## Remarques

### Droits nécessaires
Pour avoir le droit de supprimer une tâche, il est nécessaire :

- soit d'être le propriétaire de la tâche.
- soit d'être super-utilisateur.

**Composante : wd300hf.dll**
