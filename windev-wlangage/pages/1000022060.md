# btleCaractéristique (Type de variable)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le type **btleCaractéristique** permet de manipuler une caractéristique d'un service Bluetooth Low Energy.
Une caractéristique permet d'échanger des données entre deux appareils compatibles Bluetooth LE. Elle est identifiée par une chaîne de caractères unique (UUID) et peut contenir un ensemble de descripteurs. Une liste des différents services et caractéristiques existants peut être trouvée sur le site [https://www.bluetooth.com/specifications/protocol-specifications](https://www.bluetooth.com/specifications/protocol-specifications).

Le type **btleCaractéristique** est utilisé par les variables de type [btleService](1000022057.md).

Les détails de cette caractéristique peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
cMonService est un btleService
...
cMaCaractéristique est un btleCaractéristique <- cMonService[1]
```

## Propriétés

### Propriétés spécifiques à la description des variables de type btleCaractéristique
Les propriétés suivantes peuvent être utilisées pour manipuler une caractéristique :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Descripteur | Tableau de [btleDescripteur](1000022064.md) | Liste des descripteurs associées à la caractéristique. |
| Permission | Entier | Permissions de la caractéristique. _(Windows)_ Cette propriété est inutile et vaut toujours 0.  Cette propriété est disponible en lecture seulement. |
| Propriété | Entier | Propriétés de la caractéristique. Cette propriété est disponible en lecture seulement. |
| UUID | Chaîne de caractères | Identifiant de la caractéristique. Cette propriété est disponible en lecture seulement. |
