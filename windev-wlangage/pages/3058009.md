# PageCourante (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

Renvoie le nom de la page contenant le code WLangage en cours d'exécution.

## Exemple

```wlangage
Ch est une chaîne
Ch = PageCourante()
```

## Syntaxe

```wlangage
<Résultat> = PageCourante()
```

`<Résultat>` *Chaîne de caractères*
> | Nom en majuscules de la page en cours | Si le code WLangage en cours d'exécution est :  - un événement associé à la page :   - événement "Déclarations globales",  - événement "Initialisation" de la page,  - événement "Chargement" de la page,  - événement "Fermeture" ou "Déchargement" de la page,  - événement "Synchronisation". - un événement associé à un champ (initialisation, clic). - une procédure locale de la page. |
> | --- | --- |
> | Chaîne vide ("") | Si le code en cours d'exécution est :  - un événement associé au projet - un code constructeur ou destructeur de classe - une méthode d'une classe - une procédure globale au projet. |
>
>
> > _(Linux)_ La casse du nom de la page correspond à la casse réelle du nom de la page. Par exemple, si la page courante correspond à la page "Accueil.WWH", le nom retourné sera "Accueil".

**Composante : wd300page.dll**
