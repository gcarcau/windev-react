# Interligne (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Interligne** permet de connaître et de modifier l'interligne défini pour une variable de type [Police](1514045.md). La valeur de l'interligne correspond au facteur multiplicatif de l'interligne simple.
Rappel : L'interligne correspond à l'espace entre les lignes d'un texte.

## Exemple

```wlangage
MaPolice est une Police
MaPolice.Nom = "arial"
MaPolice.UnitéTaille = unitéPoint
MaPolice.Taille = 12
MaPolice.Interligne = 1.5
MaPolice.Interlettre = 5
```

## Syntaxe

#### Connaître l'interligne défini pour une variable de type Police

```wlangage
<Résultat> = <Police>.Interligne
```

`<Résultat>` *Réel*
> Facteur multiplicatif de l'interligne simple.
`<Police>` *Variable de type Police*
> Nom de la variable de type [Police](1514045.md) à manipuler.

#### Modifier l'interligne défini pour une variable de type Police

```wlangage
<Police>.Interligne = <Interligne>
```

`<Police>` *Variable de type Police*
> Nom de la variable de type [Police](1514045.md) à manipuler.
`<Interligne>` *Réel*
> Facteur multiplicatif de l'interligne simple.

## Remarques

### Style d'un champ : Sélection de l'interligne sous l'éditeur
Le style d'un champ permet de définir la police utilisée pour les différents éléments du champ (Onglet "Style" de la fenêtre de description du champ). Lors de la saisie des informations de taille de la police sous l'éditeur, il est possible de choisir l'interligne et l'interlettrage pour la police en cours.
[image: Définition de l'interligne]

### Variable de type Police
Une police peut être créée à partir d'une variable de type [Police](1514045.md).
Pour définir les caractéristiques de la police, utilisez :

- soit la fonction [PoliceCrée](3060002.md).
- soit les propriétés [Alphabet](2512008.md), [Angle](1410086632.md), [Barré](2513005.md), [Couleur](2510071.md), [Gras](2513001.md), [Italique](2513007.md), [Interlettre](1410088367.md), [Interligne](1410088366.md), [Nom](2510082.md), [Souligné](2513013.md), [Taille](2510125.md) et [UnitéTaille](1410088365.md).

Cette police pourra être utilisée :

- Pour écrire du texte dans des dessins (fonction [dPolice](3029020.md)).
- Pour écrire dans les graphes (fonctions [grPoliceEtiquette](3042012.md), [grPoliceLégende](3042037.md), [grPoliceTitre](3042048.md) et [grPoliceTitreAxe](3042059.md)).
- Pour imprimer (fonction [iPolice](3046014.md)).
- Dans les champs d'une fenêtre (propriété [Police](1514045.md) des champs d'une fenêtre).
- Dans les champs d'un état (propriété [Police](1514045.md) des champs d'un état).
