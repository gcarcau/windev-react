# <Variable emailSessionOutlook>.SupprimeDossier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Supprime un dossier dans le logiciel de messagerie Outlook.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur)_ // Ouverture de la session Outlook
IDSession est une emailSessionOutlook
...
// Suppression d'un dossier
IDSession.SupprimeDossier("Dossiers personnels\Boîte de réception\Travail")
// Suppression d'un dossier dans le dossier en cours
IDSession.SupprimeDossier(IDSession.DossierCourant() + "\Travail")

## Syntaxe

```wlangage
<Résultat> = <Session>.SupprimeDossier(<Chemin du dossier>)
```

`<Résultat>` *Booléen*
> - Vrai si la suppression a été effectuée,
> - Faux dans le cas contraire. En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Session>` *Variable de type emailSessionOutlook*
> Nom de la variable de type [emailSessionOutlook](1000018767.md) correspondant à la session d'email à manipuler.
`<Chemin du dossier>` *Chaîne de caractères Unicode*
> Chemin du dossier à supprimer.

## Remarques

> _(WINDEV, WEBDEV - Code Serveur)_ Cas d'un serveur OutlookLe dossier doit être présent dans la branche "Dossiers personnels".Lors de l'appel de la fonction <Variable emailSessionOutlook>.SupprimeDossier, les manipulations suivantes sont automatiquement effectuées :les messages contenus dans le dossier à supprimer sont déplacés dans la Corbeille (dossier "Eléments supprimés").les sous-dossiers du dossier à supprimer et leur contenu sont déplacés dans la Corbeille (dossier "Eléments supprimés").le dossier à supprimer est définitivement supprimé.Si le dossier à supprimer est déjà présent dans la Corbeille, le dossier et son contenu sont définitivement supprimés.Rappel : Cette fonction ne permet pas de supprimer un dossier du logiciel de messagerie Outlook Express.

**Composante : wd300com.dll**
