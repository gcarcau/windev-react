# Fenetre (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Renvoie le nombre de fenêtres ouvertes à un instant donné.

## Exemple

```wlangage
// En CAPPELWD("Fenetre");strcpy(FenActive,WDChaine);
```

```wlangage
// En PascalAPPELWD('Fenetre');FenActive:=WdChaine;
```

```wlangage
// En VBcall APPELWD("Fenetre")FenActive=WdChaine
```

## Syntaxe

```wlangage
Fenetre()
```

## Remarques

- Le nombre de fenêtres est retourné dans WdEntier.
- Le nom de la fenêtre active est retourné dans WdChaine.
