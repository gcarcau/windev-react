# <Lecteur PDF>.RechercheSuivant (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Positionne sur le résultat suivant d'une recherche initiée par la fonction [<Lecteur PDF>.RecherchePremier](1000023778.md) dans le contenu d'un champ Lecteur PDF (si le contenu du champ Lecteur PDF contient plusieurs occurrences du texte recherché).

## Exemple

```wlangage
// Recherche un texte dans un champ Lecteur PDF et affiche le texte
PDF_MonLecteurPDF.RecherchePremier("société")
// Recherche l'élément suivant
SI PDF_MonLecteurPDF.RechercheSuivant() = Faux ALORS
	Info("Recherche terminée")
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Champ Lecteur PDF>.RechercheSuivant()
```

`<Résultat>` *Booléen*
> - Vrai si le texte spécifié dans la fonction [<Lecteur PDF>.RecherchePremier](1000023778.md) a été trouvé dans le document en cours dans le champ Lecteur PDF,
> - Faux si le texte n'a pas été trouvé.
`<Champ Lecteur PDF>` *Nom de champ*
> Nom du champ Lecteur PDF à manipuler.

## Remarques

- Le texte et les options de recherche ont été spécifiés dans la fonction [<Lecteur PDF>.RecherchePremier](1000023778.md).
- A partir de la version 28, cette fonction n'est pas supportée par les processeurs ARM 32 bits. En effet, les nouveautés en matière de gestion des PDF imposent une exécution en 64 bits.
  Si une application doit être exécutée sur une flotte existante d'appareils ARM 32 bits, la génération de cette application doit être effectuée avec la version 27 de WINDEV Mobile.

**Composante : wd300obj.dll**
