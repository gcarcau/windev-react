# kbCarte (Type de variable)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Le type **kbCarte** permet de définir toutes les caractéristiques avancées d'une carte utilisée dans un champ Kanban. Les caractéristiques de cette carte peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
Les cartes correspondent aux éléments affichés dans les listes d'un champ Kanban. Ces cartes peuvent :

- être ajoutées dans une liste d'un champ Kanban (fonction [KanbanAjouteCarte](1410089140.md)).
- être passées en paramètre d'événements WLangage (par exemple, événement "Déplacement d'une carte" du champ Kanban).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
MaCarte est un kbCarte
MaCarte.Titre = "Dossier"
MaCarte.Texte = "Gestion des dossiers clients"
MaCarte.Extra.ID = DonneIdentifiant()
KanbanAjouteCarte(KANBAN_Planning.LISTE_AFaire, MaCarte)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type kbCarte
Les propriétés suivantes peuvent être utilisées pour manipuler une carte d'un champ Kanban :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| ActionAutorisée | [kbActionAutorisée](1410089541.md) | Action autorisée sur la carte. |
| Date | DateHeure | Date et heure de la carte. Par défaut, cette propriété est initialisée avec les date et heure de création. |
| Nouveauté 2025 Extra | Variant | Permet de stocker une information avancée sans avoir d'influence sur l'exécution de l'application. Il est possible de stocker une valeur de n'importe quel type, un tableau, etc. Il est également possible d'ajouter des membres à la propriété **Extra**.  Exemple :    ```wlangage MaVariable.Extra.Info1 = ValeurMaVariable.Extra[Info2] = Valeur2MaVariable.Extra.Date = DateSys() ``` |
| FenêtreInterne | Chaîne de caractères | Nom de la fenêtre interne à utiliser pour afficher la carte. Si ce paramètre correspond à chaîne vide (""), la carte utilisée sera la carte par défaut du champ Kanban. |
| Indice | Entier | Priorité de la carte. Correspond à l'ordre dans la liste.  Pour modifier la priorité d'une carte, utilisez la fonction [KanbanDéplaceCarte](1410089144.md).  **Cette propriété est disponible en lecture seulement.** |
| Intervenant | Chaîne de caractères | Nom de l'intervenant associé à la carte. |
| NomListe | Chaîne de caractères | Nom de la liste qui contient la carte.  Pour modifier la liste associée à une carte, utilisez la fonction [KanbanDéplaceCarte](1410089144.md).  **Cette propriété est disponible en lecture seulement.** |
| PageInterne | Chaîne de caractères | Nom de la page interne à utiliser pour afficher la carte. Si ce paramètre correspond à chaîne vide (""), la carte utilisée sera la carte par défaut du champ Kanban. |
| Texte | Chaîne de caractères | Texte de la carte. Par défaut, ce texte est au format Markdown. |
| Titre | Chaîne de caractères | Titre de la carte. |
| Visible | Booléen | - Vrai si la carte doit être visible, - Faux dans le cas contraire. |

Les fonctions manipulant les variables de type **kbCarte** sont les suivantes :

| --- | --- |

| [KanbanInsèreCarte](1410089316.md) | Insère une carte dans une liste de Kanban. |
