# Couleur (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le type **Couleur** permet de définir toutes les caractéristiques avancées d'une couleur WLangage. Les caractéristiques de cette couleur peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
MaCouleur est une Couleur = JauneClair
MaCouleur.Luminosité += 10
```

```wlangage
MaCouleur est une Couleur(RVB(255,210,200))
LIB_Annonce.CouleurFond = MaCouleur
```

## Déclaration

#### Déclarer une variable de type Couleur

```wlangage
MaVariable est une Couleur
```

Dans ce cas, la couleur n'est pas définie.

#### Déclarer et décrire une couleur

```wlangage
MaVariable est une Couleur(<Couleur à utiliser>)
```

`<Couleur à utiliser>` *Entier ou constante*
> Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md),

## Propriétés

### Propriétés spécifiques à la description des variables de type Couleur
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **Couleur** :

| **Nom de la propriété** | **Type manipulé** | **Effet** |
| --- | --- | --- |
| Bleu | Entier | Valeur de la composante bleue de la couleur. |
| Couleur | Entier | Valeur de la couleur. Cette valeur est compatible avec :   - les fonctions [RVB](3029012.md), [RVBBleu](3029049.md), [RVBRouge](3029050.md), [RVBVert](3029051.md), ... - les constantes WLangage de couleurs.  Cette propriété correspond à la propriété par défaut utilisée par le type **Couleur**. |
| Luminosité | Entier | Luminosité de la couleur (comprise entre 0 et 255). |
| Opacité | Entier | Opacité par rapport à la couche alpha associée à la couleur.  Cette propriété doit être comprise entre 0 et 255. |
| Rouge | Entier | Valeur de la composante rouge de la couleur. |
| Saturation | Entier | Saturation de la couleur (comprise entre 0 et 255). |
| Teinte | Entier | Teinte de la couleur (comprise entre 0 et 255). |
| Vert | Entier | Valeur de la composante verte de la couleur. |
