# ScanListe (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Liste les scanneurs connectés au poste en cours.

## Exemple

```wlangage
// Affiche la liste des scanneurs du poste en cours dans le champ LISTE_Scanneur
ListeAjoute(LISTE_Scanneur, ScanListe())
```

## Syntaxe

```wlangage
<Résultat> = ScanListe()
```

`<Résultat>` *Chaîne de caractères*
> Liste des scanneurs connectés au poste en cours, sous la forme :
>
>
> ```wlangage
> <Nom du scanneur 1> + RC + ... <Nom du scanneur N>
> ```
>
>
>
> où : <Nom du scanneur 1> ... <Nom du scanneur N> correspondent au nom des scanneurs connectés.

## Remarques

Deux scanneurs ne peuvent pas avoir le même nom : le système ajoute automatiquement "#<numéro>" si un scanneur de même nom existe déjà.

**Classification Métier / UI : Code UI**

**Composante : wd300std.dll**
