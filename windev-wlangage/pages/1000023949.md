# <Variable xsdEntité>.AjouteAttribut (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Ajoute un attribut à une variable automatique générée par l'import d'un Webservice.

## Exemple

```wlangage
xsdJob est un DefinedReportJob
xsdJob.AjouteAttribut("xsi:type", xsdJob..Type)
```

## Syntaxe

```wlangage
<Variable>.AjouteAttribut(<Nom> , <Valeur>)
```

`<Variable>` *Variable générée par l'import d'un Webservice*
> Variable automatique du Webservice à modifier.
`<Nom>` *Chaîne de caractères Unicode*
> Nom de l'attribut à ajouter.
`<Valeur>` *Chaîne de caractères Unicode*
> Valeur de l'attribut à ajouter.

## Remarques

### Fonctionnement
Lorsqu'un Webservice est importé dans un projet, WINDEV, WEBDEV et WINDEV Mobile génèrent automatiquement les types de variables permettant de manipuler le flux XML utilisé par le protocole du Webservice.
La fonction **<Variable xsdEntité>.AjouteAttribut** permet d'ajouter un attribut qui ne serait pas déclaré dans le WSDL (et donc non généré automatiquement) à une variable de l'un des types importés.

**Remarque** : La fonction **<Variable xsdEntité>.AjouteAttribut** est une fonction avancée. Dans la plupart des cas, le WSDL déclare tous les éléments nécessaires à l'utilisation des Webservices.
