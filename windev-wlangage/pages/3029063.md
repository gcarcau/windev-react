# gPoliceSoulignée (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Construit une séquence de caractères permettant d'indiquer si le texte suivant l'appel de cette fonction est souligné ou non.
**Remarque** : Tout le texte écrit **à la suite** de la fonction est affecté.

> _(WINDEV, Android, iPhone/iPad, Widget IOS, Mac Catalyst)_ Dans une fenêtre, cette séquence de caractères permet d'utiliser un texte souligné (ou non) : dans un élément d'un champ Liste ou Combo.dans la barre de titre et/ou de message d'une fenêtre. dans un champ Libellé.

## Exemple

> _(WINDEV)_ // Affichage du titre "WINDEV, AGL n°1 en France." de la prochaine fenêtre
TitreSuivant(gPoliceSoulignée() + "WINDEV" + gPoliceSoulignée(Faux) + ", AGL n°1 en France.")

## Syntaxe

```wlangage
<Résultat> = gPoliceSoulignée([<Soulignée>])
```

`<Résultat>` *Chaîne de caractères*
> Séquence de caractères définissant si la suite du texte doit être soulignée ou non.
> > _(WINDEV, Android, iPhone/iPad, Widget IOS, Mac Catalyst)_ Cette séquence de caractères peut être : utilisée dans les fonctions ListeAjoute, ListeInsère ou ListeModifie.affectée à un champ Libellé. utilisée dans la barre de titre ou de message d'une fenêtre.
>
> > _(WEBDEV - Code Serveur)_ Cette séquence de caractères n'est pas interprétée par les champs en WEBDEV. Cette fonction peut être utilisée pour formater la chaîne renvoyée par un Webservice WEBDEV consommé par une application WINDEV ou WINDEV Mobile.
`<Soulignée>` *Booléen optionnel*
> - Vrai (par défaut) si le texte suivant la fonction **gPoliceSoulignée** doit être souligné,
> - Faux dans le cas contraire.

## Remarques

- La police par défaut est rétablie à la fin de l'appel des fonctions [gPoliceXXX](3029028.md).
- Toutes les autres caractéristiques de la police sont conservées (Italique, ...).
- Si l'attribut de police "souligné" est activé dans le style de l'élément auquel est affecté la chaîne graphique, un appel à la fonction **gPoliceSoulignée** avec le paramètre <Soulignée> à Faux ne permettra pas de désactiver cet attribut.
