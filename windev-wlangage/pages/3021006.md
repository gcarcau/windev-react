# Message (Fonction)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur)

Affiche (ou efface) un message dans la barre de message de la fenêtre ou du navigateur en cours.
**Remarque** : La fenêtre ou la fenêtre du navigateur doit posséder une barre de message.

> _(WINDEV)_ Si la barre de message est divisée en différentes cases, il est possible de spécifier la case dans laquelle le message est affiché.

> _(WEBDEV - Code Serveur)_ Pour simplifier le partage de code entre les applications WINDEV et WEBDEV, cette fonction n'a aucun effet en code serveur.

## Exemple

```wlangage
Message("Traitement en cours...")
MonTraitement() // Procédure permettant de réaliser le traitement voulu
Message("Prêt")
```

> _(WINDEV, Code Utilisateur (MCU))_ // Message dans la case "CBM_InfoUtil"
Message(CBM_InfoUtil, "Saisissez votre nom")

> _(WEBDEV - Code Navigateur)_ // Message avec défilement
Message("Bienvenue!", Défilant, 5)

## Syntaxe

#### Afficher ou effacer un message dans la barre de message simple

```wlangage
Message([<Texte>])
```

`<Texte>` *Chaîne de caractères optionnelle*
> Texte à afficher (127 caractères maximum).
> Si ce paramètre n'est pas précisé, le message précédemment affiché dans la barre de message est effacé.
>
> > _(WINDEV)_ Si la barre de message est divisée en différentes cases, ce texte sera affiché dans la première case.
>
>
> > _(WEBDEV - Code Navigateur)_ Si ce paramètre contient la chaîne "HH:MM", cette dernière est automatiquement remplacée par l'heure système du poste en cours.Pour afficher le caractère "&", il est nécessaire de le doubler, sinon la lettre suivant ce caractère sera soulignée.

> _(WINDEV, Code Utilisateur (MCU))_ Afficher ou effacer un message dans une case de la barre de message Masquer les détails
Message(<Nom de la case> , <Texte>)

 <Nom de la case> : Chaîne de caractèresNom de la case à manipuler. Si la case a été créée :sous l'éditeur de fenêtres, le nom de la case peut être indiqué sans guillemets.avec la fonction MessageAjouteCase, le nom de la case doit être indiqué entre guillemets (il est également possible d'utiliser le mot-clé Externe). <Texte> : Chaîne de caractèresTexte à afficher (127 caractères maximum).Si ce paramètre n'est pas précisé, le message précédemment affiché dans la barre de message est effacé.

> _(WEBDEV - Code Navigateur)_ Afficher un message défilant Masquer les détails
Message([<Texte> [, <Option> [, <Espacement>]]])

 <Texte> : Chaîne de caractères optionnelleTexte à afficher (127 caractères maximum).Si ce paramètre n'est pas précisé, le message précédemment affiché dans la barre de message est effacé.Si ce paramètre contient la chaîne "HH:MM", cette dernière est automatiquement remplacée par l'heure système du poste en cours.Pour afficher le caractère "&", il est nécessaire de le doubler, sinon la lettre suivant ce caractère sera soulignée. <Option> : Constante optionnelleIndique si le message est défilant :DéfilantLe message sera défilant <Espacement> : Entier optionnelTaille en nombre de caractères entre la fin du message et le début du message suivant. Si ce paramètre n'est pas précisé, égal à 0 ou est un chiffre négatif, cet espacement correspond au nombre de caractères du message.

## Remarques

### Caractéristiques du message
Le message est cadré à gauche.
Le texte affiché dans la barre de message simple ou dans la première case d'une barre de message multi-cases est automatiquement effacé lorsque l'utilisateur sélectionne un champ associé à un message d'aide : le message d'aide de ce champ s'affichera dans la barre de message.

### Erreur générée
Une erreur WLangage est générée si la fonction **Message** est appelée depuis un traitement du "Code du projet" (initialisation du projet, fermeture du projet ou fermeture de session).

> _(WINDEV, Code Utilisateur (MCU))_ Message et fenêtre Fille MDILa fonction Message utilisée depuis une fenêtre fille MDI sans barre de message utilise la barre de message de la fenêtre mère.
