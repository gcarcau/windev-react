# Instructions composées

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Instructions conditionnelles

Les instructions conditionnelles du WLangage sont les suivantes :

| [SELON](1510008.md) | Exécution d'une action ou d'une autre en fonction d'une expression |
| --- | --- |
| [SI](1510011.md) | Exécution d'une action ou d'une autre en fonction d'une condition. |

## Instructions répétitives

Les instructions répétitives du WLangage sont les suivantes :

| [BOUCLE](1510004.md) | Bloc d'instructions répété à l'infini |
| --- | --- |
| [POUR](1510001.md) | Bloc d'instructions répété jusqu'à une valeur limite |
| POUR TOUT | Parcours d'éléments :   - [POUR TOUT](1510013.md) : Parcours HFSQL (parcours complet, parcours avec recherche, parcours avec filtre). - [POUR TOUT](1510016.md) : Parcours de tableaux. - [POUR TOUT](1510019.md) : Parcours de tableaux associatifs. - [POUR TOUT](1510018.md) : Parcours de chaînes. - [POUR TOUT](1510017.md) : Parcours de champs. - [POUR TOUT](1510024.md) : Parcours des options disponibles dans les combinaisons. - [POUR TOUT](1510023.md) : Parcours des valeurs disponibles dans les énumérations. - [POUR TOUT](1510022.md) : Parcours sur une variable de type [xmlLecteur](1000023392.md). - Nouveauté 2025  [POUR TOUT](1510029.md) : Parcours sur une variable de type [jsonLecteur](1410090783.md).  **Attention** : Cette fonctionnalité est disponible uniquement à partir de la version 2025 Update 3. |
| [TANTQUE](1510010.md) | Bloc d'instructions répété en fonction d'une condition |

L'instruction POUR TOUT peut également être utilisée pour parcourir les objets DotNet qui implémentent l'interface IEnumerable.
