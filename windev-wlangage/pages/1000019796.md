# CarteModifieMarqueur (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Modifie un marqueur affiché dans un champ Carte.
> _(Android)_ Remarque : Cette fonction est disponible dans l'émulateur Android et dans le simulateur Android.

## Exemple

```wlangage
// Ajout d'un marqueur : l'icône change lorsque l'utilisateur clique dessus
MaPosition est une géoPosition
MaPosition.Latitude = 43.613708
MaPosition.Longitude = 3.876972
MonMarqueur est un Marqueur
MonMarqueur.Position = MaPosition
MonMarqueur.ActionClic = "ProcClicMarqueur"

CarteAjouteMarqueur(CARTE_Position, MonMarqueur)
```

```wlangage
PROCÉDURE ProcClicMarqueur(UnMarqueur est un Marqueur)

UnMarqueur.Image = "marqueur_clic.png"
CarteModifieMarqueur(CARTE_Position, UnMarqueur)
```

## Syntaxe

```wlangage
<Résultat> = CarteModifieMarqueur(<Champ Carte> , <Marqueur>)
```

`<Résultat>` *Booléen*
> - Vrai si le marqueur a pu être modifié,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler. Si ce paramètre correspond à une chaîne vide (""), le champ Carte auquel appartient l'événement en cours sera utilisé.
`<Marqueur>` *Variable de type Marqueur*
> Nom de la variable de type [Marqueur](1000019940.md) correspondant au marqueur à modifier.

## Remarques

- Pour ajouter un nouveau marqueur dans un champ Carte, utilisez la fonction [CarteAjouteMarqueur](1000019794.md).
- Pour supprimer un marqueur affiché dans un champ Carte, utilisez la fonction [CarteSupprimeMarqueur](1000019795.md).
