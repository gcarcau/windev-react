# RelanceProgramme (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

Termine l'application et la relance.

## Exemple

```wlangage
// Relance l'application
RelanceProgramme()
```

## Syntaxe

```wlangage
RelanceProgramme([<Exécution du code>])
```

`<Exécution du code>` *Booléen*
> - Vrai pour exécuter le code de terminaison du projet.
> - Faux (valeur par défaut) pour ne pas exécuter le code de fermeture du projet.

## Remarques

L'application est relancée dans les conditions les plus proches possibles de son lancement initial, en particulier avec la même ligne de commande et les mêmes variables d'environnement.

**Composante : wd300vm.dll**
