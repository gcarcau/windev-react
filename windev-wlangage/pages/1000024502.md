# <Variable WDPic>.Police (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Déclare la police de caractères qui sera utilisée par la fonction [<Variable WDPic>.DessineTexte](1000024676.md) dans une variable de type [WDPic](1000023503.md).

## Exemple

```wlangage
MonImageWDPic est un WDPic = "Test.bmp"
// Déclaration de la police de caractères :
// Arial, taille 12, gras
MonImageWDPic.Police("Arial", 12, iGras)

IMG_MonDessin = MonImageWDPic
```

## Syntaxe

#### Utiliser une police spécifique pour les dessins

```wlangage
<Image WDPic>.Police(<Police> [, <Taille de la police> [, <Attributs de la police> [, <Inclinaison du texte>]]])
```

`<Image WDPic>` *Variable de type WDPic*
> Nom de la variable de type [WDPic](1000023503.md) à manipuler. Seul le calque d'arrière-plan sera manipulé.
`<Police>` *Chaîne de caractères*
> Nom de la police utilisée lors du dessin du texte par [<Variable WDPic>.DessineTexte](1000024676.md). Ce paramètre ne doit pas correspondre à une famille de polices. La liste des polices installées sur le poste en cours peut être connue avec la fonction [PoliceListe](3060003.md).
`<Taille de la police>` *Entier optionnel*
> Taille de la police (en points). La valeur par défaut est 12.
`<Attributs de la police>` *Constante (ou combinaison de constantes) optionnelle*
> Attributs de police à utiliser :
>
> | *iBarre* | Barre le texte dessiné. |
> | --- | --- |
> | *iGras* | Met le texte dessiné en gras. |
> | *iItalique* | Met le texte dessiné en italique. |
> | *iNormal* (Valeur par défaut) | Normalise le texte dessiné |
> | *iSouligne* | Souligne le texte dessiné. |
`<Inclinaison du texte>` *Entier optionnel*
> Indique l'inclinaison (en degrés) du texte. La valeur par défaut est 0.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ Utiliser une police créée par programmation Masquer les détails
<Image WDPic>.Police(<Police utilisée>)

 <Image WDPic> : Variable de type WDPicNom de la variable de type WDPic à manipuler. Seul le calque d'arrière-plan sera manipulé. <Police utilisée> : PolicePolice à utiliser pour les dessins. Ce paramètre correspond à une variable de type Police. Les caractéristiques de la police ont été définies grâce à la fonction PoliceCrée ou grâce aux propriétés de gestion des polices.

## Remarques

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Windows, Code Utilisateur (MCU), Ajax)_ PolicesLa fonction PoliceListe permet de récupérer la liste des polices valides (TrueType, PostScript) installées sur la machine en cours.Pour obtenir un résultat satisfaisant lors de l'inclinaison du texte dessiné, la <Police> utilisée doit être de type "TrueType".
