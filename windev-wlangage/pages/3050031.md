# MatSupprime (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Supprime une matrice existante. La suppression d'une matrice inutilisée (ou nulle) dans une application permet de libérer la place mémoire utilisée par cette matrice.
**Remarque** : Toutes les matrices utilisées dans une application sont systématiquement supprimées à la fermeture de l'application.

## Exemple

```wlangage
// Suppression d'une matrice
MatSupprime("MaMatrice")
```

## Syntaxe

```wlangage
MatSupprime(<Matrice>)
```

`<Matrice>` *Chaîne de caractères*
> Nom de la matrice à supprimer, défini avec la fonction [MatCrée](3050058.md).

## Remarques

### Existence de la matrice à supprimer
L'existence de la matrice n'est pas vérifiée. Pour vérifier l'existence d'une matrice, utilisez la fonction [MatExiste](3050076.md). Si la matrice n'existe pas, la fonction **MatSupprime** n'a aucune action.
