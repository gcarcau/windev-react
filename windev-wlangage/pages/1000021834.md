# <Table>.DérouleTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Déroule :

- toute la hiérarchie (tous les noeuds) d'un champ Table hiérarchique.
- toutes les ruptures d'un champ Table.

> _(Java)_ Les ruptures ne sont pas disponibles sur les champs Table dans cette version.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, PHP)_ // Déroule tous les noeuds du champ Table hiérarchique "TABLEH_Planning"
TABLEH_Planning.DérouleTout()

## Syntaxe

```wlangage
<Champ Table>.DérouleTout()
```

`<Champ Table>` *Nom de champ*
> Nom du champ à manipuler. Ce nom peut correspondre :
>
> - au nom du champ Table hiérarchique pour lequel tous les noeuds doivent être déroulés.
> - au nom du champ Table pour lequel toutes les ruptures doivent être déroulées.

## Remarques

### Conditions d'utilisation
La fonction **<Table>.DérouleTout** peut être utilisée sur :

- un champ Table hiérarchique.
- un champ Table par programmation.
- un champ Table fichier chargé en mémoire.
- un champ Table en mode "Serveur + AJAX" ou un champ Table en mode "Serveur".
- un champ Table en mode "Navigateur".

Cette fonction ne peut pas être utilisée sur les champs Table fichier (accès direct).

### Champ Table hiérarchique
Lors de l'appel à la fonction **<Table>.DérouleTout**, si la branche spécifiée et/ou ses fils possèdent une procédure associée par la propriété [AjouteFilsDifféré](1000020927.md), cette procédure sera exécutée.
