# <Variable Connexion>.ListeUtilisateur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie la liste des utilisateurs définis pour une connexion.

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion

// Ouverture de la connexion
MaConnexion.OuvreConnexion()
Résultat1 est une chaîne
Résultat1 = MaConnexion.ListeUtilisateur()
// Ajout des utilisateurs dans un champ Liste
LISTE_Maliste.Ajoute(Résultat1)
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.ListeUtilisateur()
```

`<Résultat>` *Chaîne de caractères*
> Nom des différents utilisateurs existants pour la connexion spécifiée. Les noms des utilisateurs sont séparés par RC (Retour-Chariot).
> **Remarque** : Si l'utilisateur en cours ne possède pas le droit de visualisation des utilisateurs (constante *hDroitVisualisationUtilisateur*) sur le serveur (fonction [<Variable Connexion>.ModifieDroitServeur](1000022710.md) ou [<Variable Connexion>.InfoDroitServeur](1000022668.md)), la fonction **<Variable Connexion>.ListeUtilisateur** renvoie uniquement l'utilisateur en cours.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion à manipuler.
