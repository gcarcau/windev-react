# <Variable Connexion>.ListeSauvegardePlanifiée (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Liste les sauvegardes complètes et différentielles qui ont été planifiées sur un serveur HFSQL Client/Serveur. La liste des sauvegardes planifiées est renvoyée sous forme d'un tableau de variables avancées de type [hDescriptionSauvegarde](1000017455.md).

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion

tabSvg est un tableau dynamique de hDescriptionSauvegarde
tabSvg = MaConnexion.ListeSauvegardePlanifiée()
hSvg est une hDescriptionSauvegarde

POUR TOUT hSvg DE tabSvg
	Trace("_______________________________________________________")
	Trace("hSvg.Identifiant = " + hSvg.Identifiant)
	Trace("hSvg.Description = " + hSvg.Description)
	Trace("hSvg.Destination = " + hSvg.Destination)
	Trace("hSvg.LimiteNombreSauvegarde = " + hSvg.LimiteNombreSauvegarde)
	Trace("hSvg.Source = " + hSvg.Source)
	Trace("hSvg.Utilisateur = " + hSvg.Utilisateur)

	Trace("hSvg.PlanificationComplète.Mois = " + hSvg.PlanificationComplète.Mois)
	Trace("hSvg.PlanificationComplète.JourDuMois = " + hSvg.PlanificationComplète.JourDuMois)
	Trace("hSvg.PlanificationComplète.Heure = "  + hSvg.PlanificationComplète.Heure)
	Trace("hSvg.PlanificationComplète.Minute = " + hSvg.PlanificationComplète.Minute)
	Trace("hSvg.PlanificationComplète.JourDeLaSemaine = " + hSvg.PlanificationComplète.JourDeLaSemaine)
	Trace("hSvg.PlanificationComplète.JourDuMoisOuDeLaSemaine = " + ...
			hSvg.PlanificationComplète.JourDuMoisOuDeLaSemaine)

	Trace("hSvg.PlanificationDifférentielle.Mois = " + hSvg.PlanificationDifférentielle.Mois)
	Trace("hSvg.PlanificationDifférentielle.JourDuMois = " + hSvg.PlanificationDifférentielle.JourDuMois)
	Trace("hSvg.PlanificationDifférentielle.Heure = " + hSvg.PlanificationDifférentielle.Heure)
	Trace("hSvg.PlanificationDifférentielle.Minute = " + hSvg.PlanificationDifférentielle.Minute)
	Trace("hSvg.PlanificationDifférentielle.JourDeLaSemaine = " + hSvg.PlanificationDifférentielle.JourDeLaSemaine)
	Trace("hSvg.PlanificationDifférentielle.JourDuMoisOuDeLaSemaine = " + ...
			hSvg.PlanificationDifférentielle.JourDuMoisOuDeLaSemaine)

FIN
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.ListeSauvegardePlanifiée()
```

`<Résultat>` *Tableau de variables de type hDescriptionSauvegarde*
> Tableau contenant les variables de type [hDescriptionSauvegarde](1000017455.md).
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle les sauvegardes planifiées doivent être listées.

## Remarques

### Droits nécessaires
Pour lister les sauvegardes planifiées, l'utilisateur ou le groupe doit posséder :

- pour chaque base concernée par la sauvegarde, le droit de faire des sauvegardes (constante *hDroitSauvegarde*) ou le droit de se connecter (constante *hDroitConnexion* ou *hDroitConnexionCryptée*).
- pour une sauvegarde du serveur complet, le droit de faire des sauvegardes (constante *hDroitSauvegarde*) au niveau du serveur.

Pour savoir si un utilisateur ou un groupe possède ces droits, utilisez la fonction [<Variable Connexion>.InfoDroitServeur](1000022668.md) ou [HInfoDroitDaseDeDonnées](1000022666.md).

Pour modifier les droits d'un utilisateur ou d'un groupe d'utilisateurs, utilisez la fonction [<Variable Connexion>.ModifieDroitServeur](1000022710.md) ou [<Variable Connexion>.ModifieDroitBaseDeDonnées](1000022707.md).
