# iHauteurImage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Calcule la hauteur de l'image à imprimer (en millimètres). Ce calcul est réalisé par rapport à la résolution de l'imprimante sélectionnée (et non par rapport à la résolution de l'écran). Aucun facteur d'agrandissement n'est appliqué.
> _(Linux)_ Seules les images au format JPEG peuvent être manipulées.

## Exemple

```wlangage
// Imprime les dimensions de l'image (en mm)
iImprime("Largeur de l'image : " + iLargeurImage("WINDEV.JPG") + "mm")
iImprime("Hauteur de l'image : " + iHauteurImage("WINDEV.JPG") + "mm")
iFinImprime()
```

## Syntaxe

#### Calculer la hauteur d'une image présente dans un fichier

```wlangage
<Résultat> = iHauteurImage(<Nom de l'image>)
```

`<Résultat>` *Réel*
> Hauteur de l'image (en millimètres).
`<Nom de l'image>` *Chaîne de caractères*
> Nom et chemin (relatif ou complet) du fichier image.
> > _(Linux)_ Seules des images au format JPEG peuvent être manipulées.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Code Utilisateur (MCU), Ajax, Linux)_ Calculer la hauteur d'une image présente dans une variable de type Image Masquer les détails
<Résultat> = iHauteurImage(<Image>)

 <Résultat> : RéelHauteur de l'image (en millimètres). <Image> : Variable de type ImageNom d'une variable de type Image.
 Seules des images au format JPEG peuvent être manipulées.

## Remarques

- La fonction [iLargeurImage](3046061.md) permet de connaître la largeur d'une image à imprimer.
- La fonction **iHauteurImage** ne permet pas de connaître la hauteur d'une image au format WMF.
- Les dimensions d'une image peuvent être connues grâce à la fonction [InfoImage](1410091104.md).
