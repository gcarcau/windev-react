# SaisieAjouteJeton (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Ajoute un jeton dans un champ de saisie de type "Jetons de texte".

## Exemple

```wlangage
// Clic sur [Tous les destinataires]
SaisieSupprimeToutJeton(SAI_Destinataire)
POUR TOUT mail DE tabMail
	SaisieAjouteJeton(SAI_Destinataire, mail.Nom, mail.Adresse)
FIN
```

```wlangage
// Syntaxe avec le type Jeton
SaisieSupprimeToutJeton(SAI_Destinataire)
POUR TOUT mail DE tabMail
	MonJeton est un Jeton
	MonJeton.Libellé = mail.Adresse
	MonJeton.Valeur = mail.Nom
	SaisieAjouteJeton(SAI_Destinataire, MonJeton)
FIN
```

## Syntaxe

#### Ajouter un jeton directement

```wlangage
<Résultat> = SaisieAjouteJeton(<Champ de saisie> , <Valeur> [, <Libellé>])
```

`<Résultat>` *Entier*
> - Indice du jeton ajouté,
> - 0 en cas d'erreur :
>   - Si le champ de saisie n'est pas un champ de type "Jetons de texte" (propriété [JetonActif](1000023782.md) vaut Faux).
>   - Si un doublon a été détecté et si la propriété [JetonAutoriseDoublon](1000023784.md) vaut Faux.
`<Champ de saisie>` *Nom de champ*
> Nom du champ de saisie de type "Jetons de texte".
`<Valeur>` *Chaîne de caractères*
> Valeur du jeton.
`<Libellé>` *Chaîne de caractères optionnelle*
> Libellé du jeton. Si cette valeur n'est pas précisée, elle correspondra à la valeur du jeton.

#### Ajouter un jeton via le type Jeton

```wlangage
<Résultat> = SaisieAjouteJeton(<Champ de saisie> , <Jeton>)
```

`<Résultat>` *Entier*
> - Indice du jeton ajouté,
> - 0 en cas d'erreur :
>   - Si le champ de saisie n'est pas un champ de type "Jetons de texte" (propriété [JetonActif](1000023782.md) vaut Faux).
>   - Si un doublon a été détecté et si la propriété [JetonAutoriseDoublon](1000023784.md) vaut Faux.
`<Champ de saisie>` *Nom de champ*
> Nom du champ de saisie de type "Jetons de texte".
`<Jeton>` *Variable de type Jeton*
> Nom de la variable WLangage de type [Jeton](1000023942.md) décrivant le jeton à ajouter.

## Remarques

- Le jeton est ajouté à la position du curseur de saisie. Si le curseur de saisie est situé entre des jetons, le jeton est inséré entre les jetons.
- Pour ajouter un jeton à la fin de tous les jetons, utilisez la fonction [SaisieInsèreJeton](1000023954.md).
- La propriété [ValeurMémorisée](2510127.md) du champ de saisie renvoie les valeurs mémorisées des jetons du champ séparées par le caractère <RC> (Retour Chariot).
