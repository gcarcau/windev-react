# Les graphes

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

## Présentation

Pour intégrer des graphes dans vos applications ou sites, WINDEV, WEBDEV et WINDEV Mobile mettent à votre disposition :

- un [champ Graphe](1013006.md) (utilisable dans l'éditeur de fenêtres, de pages et d'états).
- des [fonctions WLangage](3042003.md) qui permettent de créer et de manipuler des graphes.

Les graphes permettent une visualisation rapide et concrète des données numériques.

> _(WINDEV, WEBDEV - Code Serveur, Linux)_ Utilisation des graphes en WEBDEV Linux et en WINDEV LinuxPour utiliser les graphes sous Linux, il est nécessaire d'installer la librairie QT (Core et GUI), version 5 minimale. Sous Ubuntu, cette librairie peut être installée avec les commandes suivantes :

sudo apt-get install libqtcore5sudo apt-get install libqtgui5

## Comment créer des graphes ?

### Créer des graphes dans les éditeurs
Les éditeurs de fenêtres, de pages et d'états disposent d'un champ Graphe. Lors de la création de ce champ, les assistants vous posent différentes questions afin de décrire le graphe qui va être créé. La fenêtre de description du champ permet de modifier à tout moment ces options.
Les fonctions WLangage permettent également de modifier les graphes affichés dans les champs Graphe. Il suffit d'indiquer le nom du champ Graphe dans les différentes fonctions.

> _(Widget IOS)_ Il n'est pas possible d'utiliser un champ Graphe. Seuls les graphes réalisés par programmation et affichés dans un champ Image sont disponibles.

Pour plus de détails sur ce type de champ, consultez [Le champ Graphe](1013006.md).

### Créer des graphes par programmation
Pour manipuler des graphes, WINDEV, WEBDEV et WINDEV Mobile disposent d'une cinquantaine de fonctions. Ces fonctions permettent de créer les graphes, de les modifier, de changer des options d'affichage ...
Pour plus de détails, consultez :

- [Programmation des graphes](1000021344.md).
- [Fonctions de gestion des graphes](3042003.md).

> _(Android)_ Il n'est pas possible de créer des graphes par programmation. Seuls les champs Graphe sont disponibles.

> _(PHP)_ Il n'est pas possible de créer des graphes par programmation. Seuls les champs Graphe interactif sont disponibles.

> _(Widget IOS)_ Seuls les graphes réalisés par programmation et affichés dans un champ Image sont disponibles.
