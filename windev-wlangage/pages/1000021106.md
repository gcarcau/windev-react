# MémoriserLaValeur (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes)

La propriété **MémoriserLaValeur** permet de :

- Savoir si un champ conserve sa valeur entre deux lancements de l'application via la persistance.
- Modifier un champ pour qu'il conserve ou non sa valeur entre deux lancements de l'application via la persistance.

Cette propriété correspond à l'option "Mémoriser la valeur" disponible dans l'onglet "Détail" de la fenêtre de description des champs :

- Interrupteur / Sélecteur,
- Combo / Liste,
- Champ de saisie,
- Onglet statique / Onglet dynamique.

## Exemple

```wlangage
c est un Champ
c <- ChampCrée("SAI_Date_1", typDate, 0, 0, 100, 20)
c.Libellé = "Date du jour"
c.MémoriserLaValeur = Vrai
```

## Syntaxe

#### Savoir si un champ conserve sa valeur entre deux lancements de l'application

```wlangage
<Résultat> = <Champ manipulé>.MémoriserLaValeur
```

`<Résultat>` *Booléen*
> - Vrai si le champ conserve sa valeur entre deux lancements de l'application,
> - Faux dans le cas contraire.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler. Ce champ peut être :
>
> - un champ Interrupteur ou Sélecteur,
> - un champ Combo ou Liste,
> - un champ de saisie,
> - un champ Onglet statique ou Onglet dynamique.

#### Modifier un champ pour qu'il conserve ou non sa valeur entre deux lancements de l'application

```wlangage
<Champ manipulé>.MémoriserLaValeur = <Nouvelle gestion>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler. Ce champ peut être :
>
> - un champ Interrupteur ou Sélecteur,
> - un champ Combo ou Liste,
> - un champ de saisie,
> - un champ Onglet statique ou Onglet dynamique.
`<Nouvelle gestion>` *Booléen*
> - Vrai si le champ doit conserver sa valeur entre deux lancements de l'application,
> - Faux dans le cas contraire.

## Remarques

- Si cette propriété est mise à Vrai après la phase d'initialisation, le champ ne reprendra pas la valeur précédente.
- Cette propriété est surtout utile pour paramétrer les champs créés via les fonctions [ChampCrée](1000020876.md) et [ChampClone](3025017.md).
- Cette propriété correspond à l'utilisation de l'option "Mémoriser la valeur" du menu contextuel des FAA (Fonctionnalités Automatiques de vos Applications). Lorsqu'un champ est créé avec la fonction [ChampCrée](1000020876.md), l'utilisateur final dispose du menu des FAA : il peut ajouter a posteriori la gestion de la persistance (sauf si l'option est désactivée avec la fonction [FAADésactive](1000022018.md).
