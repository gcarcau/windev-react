# EstImpair (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Identifie un nombre impair.

## Exemple

```wlangage
// Nombre impair ?
ResImpair = EstImpair(65)      // Renvoie Vrai
ResImpair = EstImpair(5 + 11)  // Renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = EstImpair(<Nombre>)
```

`<Résultat>` *Booléen*
> - Vrai si le nombre spécifié est impair,
> - Faux dans le cas contraire.
`<Nombre>` *Expression numérique entière ou entier*
> Expression numérique entière ou entier à identifier.

**Classification Métier / UI : Code neutre**

**Composante : wd300std.dll**
