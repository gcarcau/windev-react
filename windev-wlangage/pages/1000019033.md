# Fonctions de gestion de HFSQL Cluster

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

## Fonctions d'administration d'un cluster HFSQL

Les fonctions ci-dessous permettent d'administrer un cluster HFSQL :

| [HClusterAjouteNoeud](1000019061.md) | Active un noeud dans un cluster HFSQL. |
| --- | --- |
| [HClusterArrête](1000019058.md) | Suspend le fonctionnement d'un cluster HFSQL. Les noeuds du cluster n'accepteront plus de connexions de la part des applications clientes. |
| [HClusterDémarre](1000019057.md) | Démarre un cluster HFSQL. Ce cluster a été arrêté précédemment (par exemple avec la fonction [HClusterArrête](1000019058.md)). |
| [HClusterEtat](1000019059.md) | Renvoie l'état d'un cluster HFSQL en interrogeant son coordinateur. |
| [HClusterIgnoreSynchro](1000019243.md) | Désigne un noeud du cluster HFSQL comme source de données pour réaliser la synchronisation du cluster. |
| [HClusterInfoErreurSynchronisation](1000021975.md) | Renvoie l'erreur survenue lors de la précédente phase de synchronisation du cluster HFSQL. |
| [HClusterInfoNoeud](1000019060.md) | Renvoie l'état de chaque noeud du cluster en interrogeant le coordinateur. |
| [HClusterInfoSynchronisation](1000021974.md) | Renvoie l'état d'avancement de la synchronisation d'un noeud d'un cluster HFSQL. |
| [HClusterNoeudMaître](1410087885.md) | Renvoie le nom du noeud maître dans un cluster HFSQL. |
| [HClusterParamètre](1000019305.md) | Lit et modifie les paramètres d'un cluster HFSQL. |
| [HClusterSupprimeNoeud](1000019062.md) | Désactive un noeud dans un cluster HFSQL. |

Il est également possible d'utiliser les fonctions suivantes :

| [HChargeParamètre](1000017314.md) | Lit un paramètre précédemment sauvegardé à partir d'une procédure stockée grâce à la fonction [HSauveParamètre](1000017313.md). |
| --- | --- |
| [HSauveParamètre](1000017313.md) | Sauve une valeur persistante sur le serveur HFSQL. |
| [HSupprimeParamètre](1000017315.md) | Supprime un paramètre précédemment sauvé avec la fonction [HSauveParamètre](1000017313.md). |

| **Attention** :  L'utilisation de HFSQL Cluster nécessite l'usage d'un pack d'installation spécifique.  Ce pack est disponible gratuitement en téléchargement sur le site de PC SOFT, dans l'espace de téléchargement des modules communs à la version 2025. |
