# DébutEtendueVisible (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android)

La propriété **DébutEtendueVisible** permet de :

- connaître la première date ou heure visible :
  - dans un champ Planning.
  - dans un champ TimeLine.
- modifier la première heure visible dans un champ TimeLine.

Remarque : La première date ou heure visible correspond à la position de l'ascenseur dans le champ.

## Exemple

> _(WINDEV)_ // Champ TimeLine sur 2 minutes au total
TimelineChangeMode(TL_TimeLine, plnModeSeconde, 120)

// équivalent à :
TL_TimeLine.DébutEtendueTotale = 0 // commence à 0 sec
TL_TimeLine.FinEtendueTotale = 120 // fin à 120 sec

// Rendre visible les 30 premières secondes
TL_TimeLine.DébutEtendueVisible = 0 // commence à 0 sec
TL_TimeLine.FinEtendueVisible = 30 // taille à 30 sec

## Syntaxe

#### Connaître la première date ou heure visible

```wlangage
<Résultat> = <Champ manipulé>.DébutEtendueVisible
```

`<Résultat>` *Entier ou chaîne de caractères au format Date/Heure*
> Première valeur visible dans le champ. Cette valeur correspond :
>
> - à un entier pour :
>   - un champ TimeLine,
>   - un champ Planning en mode seconde, milliseconde ou microseconde.
> - à une date au format AAAAMMJJHHSSCC pour un champ Planning en mode jour, semaine, mois.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler. Ce champ peut correspondre à :
>
> - un champ Planning.
> - un champ TimeLine.

> _(WINDEV)_ Modifier la valeur de la première heure visible Masquer les détails
<Champ TimeLine>.DébutEtendueVisible = <Nouvelle valeur>

 <Champ TimeLine> : Nom de champNom du champ TimeLine à manipuler. <Nouvelle valeur> : EntierPremière valeur à rendre visible dans le champ TimeLine

## Remarques

- L'ensemble des événements représentés par le champ est compris entre [DébutEtendueTotale](1000020392.md) et [FinEtendueTotale](1000020393.md). Cela correspond à l'étendue totale de l'ascenseur ou du range slider associé au champ.
- L'ensemble des événements visibles dans le champ est compris entre **DébutEtendueVisible** et [FinEtendueVisible](1000020395.md). Cela correspond à la taille de la cage de l'ascenseur ou du range slider associé au champ.
- Les propriétés [DébutEtendueTotale](1000020392.md) et **DébutEtendueVisible** sont équivalentes. Elles permettent de connaître la première valeur visible dans le champ.
