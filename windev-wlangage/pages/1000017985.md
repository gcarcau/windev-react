# Titre (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **Titre** permet de connaître et de modifier le titre d'un élément. Cette propriété est utilisable sur :

- les fenêtres, les pages ou les champs Graphe. Pour plus de détails, consultez [Propriété Titre](2510090.md).
- une variable de type [EvénementTimeline](1000020612.md).
- une variable de type [gglAgenda](1000017418.md).
- une variable de type [gglDocument](1000018001.md).
- une variable de type [gglEvénement](1000017440.md).
- une variable de type [gglSociété](1000017756.md).
- une variable de type [Notification](1000019441.md).
- une variable de type [notificationFormat](1000021301.md).
- une variable de type [RendezVous](1000019244.md).
- une variable de type [rssCanal](1000017769.md)
- une variable de type [rssEntrée](1000017792.md)
- une variable de type [rssImage](1000017799.md)
- une variable de type [rssSaisieTexte](1000017802.md)
- une variable de type [OrgaElément](1000019713.md).
- une variable de type [TâcheGantt](1000020881.md).
- une variable de type [docPropriété](1000022945.md).
- une variable de type [Toast](1000024638.md).
- une variable de type [pdfDocument](1000024909.md).
- une variable de type [gglPièceJointe](1000026182.md).
- une variable de type [TéléchargementInfo](1410087306.md).
- une variable de type [TéléchargementParamètre](1410087293.md).
- une variable de type [sysNotification](1410087893.md).
- une variable de type [kbCarte](1410089167.md).
- une variable de type [pdfSignet](1410089195.md).
- une variable de type [VisiteGuidéeEtape](1410090178.md).
- Nouveauté Abonnement
   une variable de type [sysNotificationJauge](1410090964.md).
- Nouveauté Abonnement
  une variable de type [OptionsOuvertureFenêtre](1410091298.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
