# HClusterEtat (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Renvoie l'état d'un cluster HFSQL en interrogeant son coordinateur.
**Note** : Cette fonction est réservée à un usage avancé. L'administration d'un cluster HFSQL doit être faite de préférence à l'aide du Centre de Contrôle HFSQL.

## Exemple

```wlangage
SI HClusterEtat("clustermanager.mondomaine.com", "secret") = 5 ALORS
	LIB_Alerte = "ATTENTION : le cluster est en attente de synchronisation !"
FIN
```

## Syntaxe

```wlangage
<Résultat> = HClusterEtat(<Coordinateur> , <Mot de passe>)
```

`<Résultat>` *Entier*
> Etat du cluster. Les valeurs possibles sont les suivantes :
>
> | Valeur | Etat |
> | --- | --- |
> | 0 | Une erreur est survenue lors de l'appel au coordinateur. La fonction [ErreurInfo](3013008.md) peut être utilisée pour connaître le détail de l'erreur. |
> | 1 | Le cluster est arrêté. Il peut être relancé par la fonction [HClusterDémarre](1000019057.md). |
> | 2 | Le cluster est démarré. Il peut être suspendu par la fonction [HClusterArrête](1000019058.md). |
> | 3 | Le cluster est en cours d'arrêt. |
> | 4 | Le cluster est en cours de démarrage. |
> | 5 | Tous les noeuds du cluster actuellement connectés au coordinateur sont en attente de synchronisation. |
`<Coordinateur>` *Chaîne de caractères*
> Nom DNS de la machine où se trouve le coordinateur du cluster.
`<Mot de passe>` *Chaîne de caractères ou Chaîne secrète*
> Mot de passe utilisé pour se connecter au coordinateur. Ce mot de passe a été fourni lors de [l'installation du cluster](1000019031.md).
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).
