# EnMode64bits (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Identifie si le code est exécuté en mode 64 bits ou non.
Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.

## Exemple

```wlangage
// Code exécuté en 64 bits ?
SI EnMode64bits() = Vrai ALORS
	// Code spécifique pour une exécution 64 bits
FIN
```

## Syntaxe

```wlangage
<Résultat> = EnMode64Bits()
```

`<Résultat>` *Booléen*
> - Vrai si le code est exécuté depuis un traitement exécuté en mode 64 bits,
> - Faux dans le cas contraire.
>
>
> Nouveauté 2025
>
> > _(WEBDEV - Code Navigateur)_ Le résultat correspond toujours à Vrai.

## Remarques

### Disponibilité de la fonction
La fonction **EnMode64bits** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **EnMode64bits** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.

### Exécution des traitements contenant des erreurs de compilation
Par défaut, le mécanisme de sécurité du WLangage se déclenche uniquement si la ligne contenant l'erreur de compilation est exécutée.
Par exemple, si une fonction interdite dans le produit en cours est présente dans une boucle SI, le mécanisme de sécurité du WLangage se déclenchera uniquement si la ligne contenant cette fonction s'exécute.

**Classification Métier / UI : Code neutre**
