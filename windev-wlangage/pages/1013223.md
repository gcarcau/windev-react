# Propriétés associées au champ Onglet

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Un champ Onglet peut être manipulé en WLangage aussi bien dans une fenêtre ou dans une page avec les propriétés suivantes.
