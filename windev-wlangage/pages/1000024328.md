# <Image>.Fusionne (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Fusionne une image dans une autre image. Il est ainsi possible de créer des effets de fondu entre 2 images.
> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les dessins.

## Exemple

```wlangage
// Déclaration de l'image de promo
MonImagePromo est une Image = "ImagePromo.png"

// Fusion de l'image de promo dans l'image du produit avec une opacité à 80 %
IMG_PRODUIT.Fusionne(MonImagePromo, 80)
```

## Syntaxe

```wlangage
<Champ Image>.Fusionne(<Image Source> [, <Opacité>])
```

`<Champ Image>` *Nom de champ*
> Nom du champ Image correspondant à l'image dans laquelle la fusion doit être effectuée. Lors de la fusion, cette image sera considérée comme l'image d'arrière-plan.
`<Image Source>` *Champ Image ou variable de type Image, WDPic ou picCalque*
> Image à fusionner. Cette image peut correspondre :
>
> - au nom d'un champ Image.
> - au nom d'une variable de type [Image](1000019650.md).
> - au nom d'une variable de type [WDPic](1000023503.md). Seul le calque d'arrière-plan sera manipulé.
> - au nom d'une variable de type [picCalque](1000024604.md).
`<Opacité>` *Réel optionnel*
> Pourcentage d'opacité à appliquer sur <Image Source> avant d'effectuer la fusion (100% par défaut, aucune opacité n'est appliquée).

## Remarques

- La taille de l'image destination correspond à la taille de référence.
- La fonction **<Image>.Fusionne** effectue la fusion en conservant la couche alpha de l'image destination. La couche alpha de l'image source n'est donc pas utilisée.

**Composante : wd300pnt.dll**
