# <Liste>.Position (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Affiche un champ Liste (y compris champ Liste image) à partir d'un élément spécifié ou renvoie l'indice du premier élément affiché dans un champ Liste (lorsque l'ascenseur du champ a été utilisé).
**Remarque** : La fonction **<Liste>.Position** peut être utilisée indifféremment sur :

- les champs Liste fichier ou les champs Liste par programmation,
- les champs Liste monosélection ou multisélection.

> _(WEBDEV - Code Serveur)_ Cette fonction n'a aucun effet.

## Exemple

```wlangage
// Indice du premier élément affiché dans le champ Liste "LISTE_ListeClient"
ResPosition = LISTE_ListeClient.Position()
```

## Syntaxe

#### Afficher un champ Liste à partir d'un élément spécifié

```wlangage
<Champ Liste>.Position(<Indice de l'élément>)
```

`<Champ Liste>` *Nom de champ*
> Nom du champ Liste à manipuler.
`<Indice de l'élément>` *Entier*
> Indice de l'élément à afficher au début du champ Liste.
> Si ce paramètre est supérieur au nombre d'éléments présents dans le champ Liste (connu avec la fonction [<Liste>.Occurrence](1000017334.md)), une erreur WLangage est affichée.
> Si ce paramètre est égal à -1, le champ Liste est repositionnée au début.

#### Connaître l'indice du premier élément affiché dans un champ Liste ou Combo

```wlangage
<Résultat> = <Champ Liste>.Position()
```

`<Résultat>` *Entier*
> Indice du premier élément affiché dans le champ Liste spécifié.
`<Champ Liste>` *Nom de champ*
> Nom du champ Liste à manipuler.

## Remarques

### Afficher un élément au début d'un champ Liste (syntaxe 1)
L'élément affiché au début d'un champ Liste peut être différent de l'élément demandé. En effet, la fonction **<Liste>.Position** place au début du champ l'élément permettant de visualiser un maximum de lignes dans le champ. S'il n'y a pas assez d'éléments affichés en-dessous de l'élément spécifié, cet élément ne pourra pas être affiché au début du champ.
Par exemple, l'élément "Durand Jacques" ne peut pas être affiché au début du champ Liste : il n'y a pas assez d'éléments affichés en-dessous de cet élément.

### Limitations
La fonction **<Liste>.Position** ne fonctionne pas pour les champs Liste fichier en mode "manuel" qui utilisent un ascenseur à rebond.
Rappel :

- Un champ Liste fichier en mode "manuel" est un champ Liste relié par programmation à un fichier de données.
- Avec un ascenseur à rebond, il est possible de faire défiler l'ascenseur en gardant le bouton de la souris enfoncé sur le bouton de l'ascenseur ou en gardant la touche flèche haut ou flèche bas enfoncée.

### Divers

- Pour afficher un élément au début d'un champ Table ou pour connaître l'indice du premier élément affiché dans un champ Table, utilisez la fonction [<Table>.Position](1000024278.md).
- La fonction **<Liste>.Position** peut être utilisée sur une colonne d'un champ Table de type "Combo".
