# <Variable Image>.ModifieLuminosité (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Modifie la luminosité d'une image contenue dans une variable de type [Image](1000019650.md).
> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Dessiner en WINDEV, WEBDEV et WINDEV Mobile.

## Exemple

```wlangage
MonImage est une Image = "Test.bmp"
// Change la luminosité de l'image contenue dans la variable de type Image
MonImage.ModifieLuminosité(50)
```

## Syntaxe

```wlangage
<Résultat> = <Variable Image>.ModifieLuminosité(<Variation de Luminosité> [, <Image destination>])
```

`<Résultat>` *Booléen*
> - Vrai si le changement a été effectué,
> - Faux dans le cas contraire.
`<Variable Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) à manipuler.
`<Variation de Luminosité>` *Entier*
> Valeur comprise entre -100 et +100. Cette valeur sera ajoutée à la luminosité actuelle de chaque pixel pour obtenir une nouvelle luminosité.
`<Image destination>` *Nom de champ ou variable de type Image*
> Image dans laquelle l'image transformée sera dessinée. Cette image peut correspondre :
>
> - au nom d'un champ Image.
> - au nom d'une variable de type [Image](1000019650.md).
>
>
> Si ce paramètre n'est pas spécifié, la transformation s'effectuera sur <Variable Image>.

**Composante : wd300pnt.dll**
