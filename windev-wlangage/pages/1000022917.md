# Fonctions de gestion des champs Planning (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions de gestion des champs Planning (syntaxe préfixée) sont les suivantes :

| [<Planning>.Affiche](1000022900.md) | Réinitialise le contenu d'un champ Planning à partir de sa source de données (fichier HFSQL par exemple). |
| --- | --- |
| [<Planning>.AffichePériodePrécédente](1000022901.md) | Déplace la zone temporelle affichée sur la zone précédente (par exemple, semaines précédentes) dans un champ Planning. |
| [<Planning>.AffichePériodeSuivante](1000022902.md) | Déplace la zone temporelle affichée sur la zone suivante (par exemple, semaines suivantes) dans un champ Planning. |
| [<Planning>.AjouteRendezVous](1000022904.md) | Ajoute un nouveau rendez-vous dans un champ Planning. |
| [<Planning>.AjouteRessource](1000022905.md) | Ajoute une nouvelle ressource dans un champ Planning. |
| [<Planning>.ChangeMode](1000022906.md) | Modifie la période (c'est-à-dire le nombre de jours) affichée par un champ Planning. |
| Nouveauté 2025 [<Planning>.CouleurFond](1000022922.md) | Fixe une couleur de fond sur une plage horaire d'un champ Planning présent dans une fenêtre (par exemple, plage horaire correspondant au déjeuner, à un jour férié, ...). |
| [<Planning>.DateVisible](1000022918.md) | Rend visible ou invisible un jour dans un champ Planning. |
| [<Planning>.HeureAffichée](1000022907.md) | Définit la plage horaire affichée par le champ Planning en mode Jour ou Semaine. |
| [<Planning>.InfoXY](1000022908.md) | Renvoie le rendez-vous, la ressource ou la date se trouvant à une position donnée dans un champ Planning. |
| [<Planning>.ListeRendezVous](1000022909.md) | Renvoie :   - la liste des rendez-vous compris entre deux dates données dans un champ Planning, - tous les rendez-vous d'un champ Planning, - un rendez-vous particulier (sélectionné ou survolé). |
| [<Planning>.PositionDateHeure](1000022920.md) | Affiche un champ Planning à partir d'une date spécifiée ou renvoie la date du premier jour (ou dernier jour) affiché dans un champ Planning. |
| [<Planning>.PositionRessource](1000022921.md) | Affiche une ressource donnée dans un champ Planning ou renvoie la position la première ressource visible dans un champ Planning. |
| [<Planning>.SelectMoins](1000022910.md) | Désélectionne un rendez-vous dans un champ Planning. |
| [<Planning>.SelectPlus](1000022911.md) | Sélectionne un rendez-vous dans un champ Planning. |
| [<Planning>.SupprimeRendezVous](1000022912.md) | Supprime un rendez-vous dans un champ Planning. |
| [<Planning>.SupprimeRessource](1000022913.md) | Supprime une ressource dans un champ Planning. |
| [<Planning>.SupprimeTout](1000022914.md) | Supprime tous les rendez-vous et toutes les ressources d'un champ Planning. |
