# Constantes de gestion des erreurs et des exceptions

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |
| **eaFinProgramme** | Manipulation effectuée par l'utilisateur sur la fenêtre standard des exceptions : L'utilisateur n'a pas coché l'option "Relancer l'application". | [ExceptionAffiche](1000019408.md) |
| **eaRelanceProgramme** | Manipulation effectuée par l'utilisateur sur la fenêtre standard des exceptions : L'utilisateur a coché l'option "Relancer l'application". | [ExceptionAffiche](1000019408.md) |
| **epAfficheMessage** | Affiche le message d'erreur dans une fenêtre en proposant à l'utilisateur les choix suivants "Réessayer", "Annuler" et "Arrêter". | [ErreurChangeParamètre](3034009.md) |
| **epAfficheMessageFinProgramme** | Affiche le message d'erreur dans une fenêtre en proposant à l'utilisateur les choix "Arrêter" et "Relancer l'application" (Arrêter par défaut). | [ErreurChangeParamètre](3034009.md) |
| **epAfficheMessageFinTraitement** | Affiche le message d'erreur dans une fenêtre en proposant à l'utilisateur les choix "Annuler" et "Arrêter". | [ErreurChangeParamètre](3034009.md) |
| **epAfficheMessageRelanceProgramme** | Affiche le message d'erreur dans une fenêtre en proposant à l'utilisateur les choix "Arrêter" et "Relancer l'application" (Relancer par défaut). | [ErreurChangeParamètre](3034009.md) |
| **epCode** | Mode actuel : l'erreur est traitée par programmation (test de la valeur de retour des fonctions, utilisation de [ErreurDétectée](3087001.md), ...) Fonctionnement classique des exceptions. | [ErreurChangeParamètre](3034009.md), [ExceptionChangeParamètre](3034007.md) |
| **epExécuteProcédure** | Exécute la procédure indiquée en paramètre. | [ErreurChangeParamètre](3034009.md), [ExceptionChangeParamètre](3034007.md) |
| **epExécuteProcédureGénérale** | Exécute la procédure indiquée en paramètre. La procédure est appelée si aucun traitement d'exception local n'est actif. La procédure est active au niveau du contexte d'exécution (projet, composant externe autonome, composant interne autonome). S'il n'y a pas de procédure dans le contexte courant, la procédure est recherchée dans le contexte parent et ceci récursivement jusqu'au niveau de l'application. | [ExceptionChangeParamètre](3034007.md) |
| **epGotoCasErreur** | Exécute le code défini par l'étiquette : CAS ERREUR: | [ErreurChangeParamètre](3034009.md) |
| **epGotoCasException** | Exécute le code défini par l'étiquette : CAS EXCEPTION: | [ExceptionChangeParamètre](3034007.md) |
| **epRenvoyer** | Valide les erreurs. Sort du traitement en cours en renvoyant la valeur indiquée. Sort du traitement en cours en renvoyant la valeur spécifiée en paramètre. L'exception n'est pas propagée. | [ErreurChangeParamètre](3034009.md), [ExceptionChangeParamètre](3034007.md) |
| **epRenvoyerErreur** | Valide les erreurs. Sort du traitement en cours en renvoyant la valeur indiquée et en propageant l'erreur. L'erreur est alors traitée par le niveau supérieur de manière automatique (si le traitement d'erreur est activé) ou grâce à un SI PAS xxx ou un SI [ErreurDétectée](3087001.md). | [ErreurChangeParamètre](3034009.md) |
| **epRetour** | Valide les erreurs. Sort du traitement en cours. Si la gestion automatique des erreurs est activée dans le code appelant, l'erreur n'est pas remontée. Termine le traitement en cours sans propager l'exception. | [ErreurChangeParamètre](3034009.md), [ExceptionChangeParamètre](3034007.md) |
| **epRetourErreur** | Valide les erreurs. Sort du traitement en cours en propageant l'erreur. L'erreur est alors traitée par le niveau supérieur de manière automatique (si le traitement d'erreur est activé) ou grâce à un SI PAS xxx ou un SI [ErreurDétectée](3087001.md). Si la gestion automatique des erreurs est activée dans le code appelant, l'erreur est remontée. | [ErreurChangeParamètre](3034009.md) |
| **errCode** | Code de l'erreur | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errCodeSystème** | Numéro de l'erreur système (si elle existe) | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errComplet** | Toutes les informations de l'erreur (ligne de l'erreur, traitement en cours, ...) | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errDateHeure** | Date et heure de l'erreur | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errElément** | Nom de l'élément associé au traitement en cours lors de l'erreur | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errExceptionDotNet** | Objet de l'exception DotNet | [ExceptionInfo](3034006.md) |
| **errFIC** | Nom complet du fichier de données (.FIC) associé à l'erreur | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errFichier** | Nom logique du fichier associé à l'erreur | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errInfo** | Informations complémentaires | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errInfoDébug** | Informations spécifiques au débogage du problème rencontré. Ces informations ne doivent être affichées et communiquées qu'en cas de demande expresse de PC SOFT. | [ErreurInfo](3013008.md) |
| **errLiaison** | Nom de la liaison associée à l'erreur | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errLigne** | Numéro de la ligne de l'erreur | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errMessage** | Message complet de l'erreur | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errMessageSystème** | Message d'erreur système (si elle existe) | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errMMO** | Nom complet du fichier mémo (.MMO) associé à l'erreur | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errNDX** | Nom complet du fichier d'index (.NDX) associé à l'erreur | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errNombreSousErreur** | Nombre de sous-erreurs de l'erreur | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errNomCompletComposant** | Nom du composant en cours d'exécution :  - "" aucun composant. - "Composant1" : Composant "Composant1" utilisé directement dans le projet. - "Composant1.Composant2" : Composant "Composant2" utilisé depuis le "Composant1". | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errNumEnr** | Numéro de l'enregistrement associé à l'erreur | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errOrigine** | HFSQL Client/Serveur : permet d'accéder directement à la première erreur qui s'est déclenchée sur le serveur HFSQL. | [ExceptionInfo](3034006.md) |
| **errPendant** | Nom de la fonction WLangage qui a provoqué l'erreur | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errPile** | Pile des appels WLangage | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errRésumé** | Résumé de l'erreur | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errRubrique** | Nom de la rubrique associée à l'erreur | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errTraitement** | Nom du traitement en cours lors de l'erreur | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **errWDD** | Nom complet du WDD associé à l'erreur | [ErreurInfo](3013008.md), [ExceptionInfo](3034006.md) |
| **exceptionAvertissement** | Niveau de l'erreur à déclencher : exception d'avertissement | [ExceptionDéclenche](3034005.md) |
| **exceptionErreur** | Niveau de l'erreur à déclencher : exception d'erreur | [ExceptionDéclenche](3034005.md) |
| **exceptionInformation** | Niveau de l'erreur à déclencher : exception d'information | [ExceptionDéclenche](3034005.md) |
| **pubErrAucunePublicité** | Aucune publicité n'a été trouvée. | [Gestion des erreurs des champs Publicité](1000023002.md) |
| **pubErrInterne** | Erreur interne | [Gestion des erreurs des champs Publicité](1000023002.md) |
| **pubErrRequêteInvalide** | Requête AdMob invalide | [Gestion des erreurs des champs Publicité](1000023002.md) |
| **pubErrRéseau** | Erreur de connectivité réseau (pas d'accès internet par exemple) | [Gestion des erreurs des champs Publicité](1000023002.md) |
