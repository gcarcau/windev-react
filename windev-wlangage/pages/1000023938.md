# DonneNomPays (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad) · **Autres** (Procédures stockées)

Renvoie le libellé d'un pays correspondant au code ISO du pays à la norme ISO 3166-1.

## Exemple

```wlangage
// Libellé FrancesLibelléFrance est une chaîne = DonneNomPays("FRA")
```

## Syntaxe

```wlangage
<Résultat> = DonneNomPays(<Code ISO>)
```

`<Résultat>` *Chaîne de caractères*
> Nom du pays.
`<Code ISO>` *Chaîne de caractères*
> Code ISO du pays. Ce code ISO peut être le code ISO alphabétique (sur 2 ou 3 caractères) ou le code ISO numérique du pays.

**Composante : wd300std.dll**
