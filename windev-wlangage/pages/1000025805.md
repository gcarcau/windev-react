# <Carte>.ModifieForme (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Modifie une forme dessinée sur la carte affichée dans un champ Carte.

## Exemple

```wlangage
// Modifie le rayon d'un cercle affiché dans le champ Carte
Cercle est un CarteCercle
Cercle.Rayon = 50
CARTE_MaCarte.ModifieForme(Cercle)
```

## Syntaxe

```wlangage
<Résultat> = <Champ Carte>.ModifieForme(<Forme>)
```

`<Résultat>` *Booléen*
> - Vrai si la forme a pu être modifiée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler.
`<Forme>` *Variable de type CarteCercle, CartePolygone ou CartePolyligne*
> Forme à manipuler correspondant au nom d'une variable de type [CartePolygone](1000025476.md), [CartePolyligne](1000025489.md) ou [CarteCercle](1000025504.md).

## Remarques

- La forme doit avoir été ajoutée dans le champ Carte pour pouvoir être modifiée.
- Pour ajouter une nouvelle forme à dessiner sur une carte, utilisez la fonction [<Carte>.AjouteForme](1000025801.md).
- Pour supprimer une forme dessinée dans un champ Carte, utilisez la fonction [<Carte>.SupprimeForme](1000025820.md).
