# Cc (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Cc** permet de connaître et de modifier la liste des adresses en copie d'un email.
Cette propriété est utilisable sur :

- la structure [Email](3032029.md)
- une variable de type [Email](1000018713.md).
