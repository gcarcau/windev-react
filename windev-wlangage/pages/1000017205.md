# MultimédiaFerme (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Ferme le fichier multimédia en cours dans le champ Multimédia. La mémoire allouée au fichier multimédia est libérée.

## Exemple

> _(WINDEV, Etats et Requêtes, Windows, Code Utilisateur (MCU))_ MonFichier est une chaîne = "C:\Ma musique\mysong.mp3"

MultimédiaJoue(MM_Multimédia1, MonFichier)
...
MultimédiaFerme(MM_Multimédia1)

## Syntaxe

```wlangage
<Résultat> = MultimédiaFerme(<Nom du champ Multimédia>)
```

`<Résultat>` *Booléen*
> - Vrai si le fichier joué dans le champ Multimédia est correctement fermé,
> - Faux en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Nom du champ Multimédia>` *Chaîne de caractères*
> Nom du champ Multimédia à manipuler.

## Remarques

> _(iPhone/iPad)_ Specificités pour iPhone/iPadLa fonction MultimédiaFerme est équivalente à la fonction MultimédiaArrêt : la lecture en cours d'un fichier multimédia dans un champ Multimédia est arrêtée mais le fichier multimédia reste chargé en mémoire.

**Composante : wd300obj.dll**
