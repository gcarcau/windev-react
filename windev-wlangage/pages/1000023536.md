# <Variable Connexion>.RSInfo (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Permet de lire la configuration de la réplication pour un serveur HFSQL participant à une ou plusieurs réplication(s).
Cette fonction peut être exécutée aussi bien sur un serveur maître que sur un serveur abonné.

## Exemple

```wlangage
MaConnexion est une Connexion

Trace(MaConnexion.RSInfo())
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.RSInfo()
```

`<Résultat>` *Chaîne de caractères*
> Informations concernant les différentes réplications effectuées sur ce serveur. Ces informations sont de la forme :
>
>
> ```wlangage
> <Rôle du serveur> + TAB + <Identifiant serveur> + TAB + <Port> + TAB + <Priorité>
> ```
>
>
> où :
>
> - <Rôle du serveur> correspond à une constante de type entier permettant de connaître le rôle du serveur dans la réplication :
>   | *hrsAbonné* | Poste abonné dans la réplication entre serveurs HFSQL. |
>   | --- | --- |
>   | *hrsInactif* | Poste inactif dans la réplication entre serveurs HFSQL. |
>   | *hrsMaître* | Poste maître dans la réplication entre serveurs HFSQL. |
>   | *hrsMaître* + *hrsAbonné* | Postes maître et abonné dans la réplication entre serveurs HFSQL (cas d'une réplication bi-directionnelle). |
> - <Identifiant serveur> correspond au numéro identifiant le serveur HFSQL en cours parmi tous les serveurs participant à une réplication.
> - <Port> correspond au port TCP/IP utilisé pour la communication entre les serveurs.
> - <Priorité> correspond au numéro de priorité du serveur utilisé dans le cas d'une résolution par priorité lors d'un conflit de modification.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion vers le serveur HFSQL.
