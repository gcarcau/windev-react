# HRSModifieConfig (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Modifie certains paramètres d'une réplication existante entre deux serveurs HFSQL. Cette fonction doit être exécutée sur un serveur HFSQL maître d'une réplication.

## Exemple

```wlangage
Cnx est une Connexion
ConfigRéplication1 est un hRSConfig
...
ConfigRéplication1.Planification..Heure = "*/2"
HRSModifieConfig(Cnx, ConfigRéplication1)
```

## Syntaxe

```wlangage
<Résultat> = HRSModifieConfig(<Connexion> , <Réplication>)
```

`<Résultat>` *Booléen*
> - Vrai si la réplication a été modifiée,
> - Faux dans le cas contraire. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion vers le serveur HFSQL maître sur lequel la configuration de réplication doit être modifiée. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Réplication>` *Variable de type hRSConfig*
> Nom de la variable de type [hRSConfig](1000020484.md) décrivant la réplication modifiée à mettre à jour.

**Composante : wd300hf.dll**
