# iConfigureEtat (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Configure l'imprimante en ouvrant directement la fenêtre de configuration (WINDEV et WINDEV Mobile). La fenêtre de configuration est initialisée avec les paramètres choisis lors du développement (orientation de l'état, marges, ...) de l'état spécifié.
> _(WEBDEV - Code Serveur)_ Configure directement l'imprimante utilisée pour l'impression en cours en prenant en compte les paramètres choisis lors du développement (orientation de l'état, marges, ...) de l'état spécifié.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Imprimer sous Linux.

## Exemple

```wlangage
SI iConfigureEtat(ETAT_MonEtat) = Vrai ALORS
	iImprimeEtat(ETAT_MonEtat)
SINON
	Info("Configuration de l'état abandonnée")
FIN
```

## Syntaxe

```wlangage
<Résultat> = iConfigureEtat(<Nom de l'état>)
```

`<Résultat>` *Booléen*
> - Vrai si l'utilisateur a validé les informations saisies dans la boîte de dialogue,
> - Faux si l'utilisateur a abandonné.
`<Nom de l'état>` *Chaîne de caractères*
> Les caractéristiques de cet état (choisies lors du développement de l'état) seront utilisées pour initialiser la fenêtre de configuration (orientation, ...).

## Remarques

### Configuration prise en compte lors de l'impression d'un état
Seule la dernière configuration est prise en compte lors de l'impression d'un état.
Il est déconseillé d'utiliser plusieurs fois les fonctions **iConfigureEtat** et [iParamètreEtat](3046077.md) sans imprimer d'état.

### Ré-initialisation de la configuration
Après l'appel à la fonction **iConfigureEtat** (ou [iParamètreEtat](3046077.md)), tout nouvel appel à cette fonction ré-initialisera la fenêtre de configuration avec les paramètres utilisés lors du premier appel à la fonction.

**Composante : wd300etat.dll**
