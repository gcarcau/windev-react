# Utiliser les patterns RAD

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

## Les étapes de la création de pattern RAD

Les différentes étapes permettant de créer un Pattern RAD sont les suivantes :

1. [Création du projet de type "Pattern RAD"](2031021.md).
2. [Création des différentes fenêtres et pages du pattern](2031022.md).
3. [Génération du Pattern RAD](2031023.md).
4. **Utilisation du Pattern RAD**.

## Utilisation des patterns RAD

### Les fichiers patterns
Lors de la génération du pattern RAD, un fichier <Nom Pattern>.Pattern est généré dans le sous-répertoire EXE du projet. Pour être utilisé dans les différents produits, ce fichier doit être copié :

- dans le sous-répertoire "\Programs\Data\Models\RAD\FR ou EN\WD\Patterns" pour un pattern WINDEV.
- dans le sous-répertoire "\Programs\Data\Models\RAD\FR ou EN\Patterns" pour un pattern WEBDEV.

Note : Répertoire FR pour un pattern généré depuis un produit en langue française, EN pour un pattern généré depuis un produit en langue anglaise.
Après copie, le nouveau pattern RAD est disponible dans le produit considéré (WINDEV ou WEBDEV) pour générer un RAD Application Complète (et si nécessaire un RAD fenêtre ou page).

### Génération d'un RAD Application complète
Pour générer un RAD Application Complète :

1. Sous le volet "Projet", dans le groupe "Génération", cliquez sur "RAD Application complète".
2. Sélectionnez le pattern à utiliser et si nécessaire le gabarit à appliquer.
3. Suivez les différentes étapes de l'assistant.

**Remarque** : Si vous utilisez plusieurs fois sur le même projet l'assistant de création d'application complète du RAD, il est possible de générer uniquement les éléments correspondants aux fichiers ajoutés dans l'analyse. A chaque modification de l'analyse, une mise à jour du RAD est automatiquement proposée : les éléments nécessaires sont ajoutés à l'application générée par le RAD.

### Génération d'un RAD fenêtre ou d'un RAD page
Pour générer un RAD fenêtre ou page :

1. Cliquez sur  parmi les boutons d'accès rapide. La fenêtre de création d'un nouvel élément s'affiche : cliquez sur "Fenêtre" puis sur "Fenêtre" ou cliquez sur "Page" puis sur "Page".
2. Pour générer une fenêtre ou une page RAD, dans l'onglet "RAD", sélectionnez le pattern à utiliser (et si nécessaire le gabarit à utiliser).
3. Suivez les différentes étapes de l'assistant.

**Remarque** : En WEBDEV, seules les pages dynamiques utilisent les patterns RAD.
