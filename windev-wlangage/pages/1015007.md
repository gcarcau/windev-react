# Propriétés associées aux lignes d'un champ Table hiérarchique

> **Disponible :** **WINDEV** (Windows, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Les lignes des champs Table hiérarchique peuvent être manipulées avec les propriétés WLangage aussi bien dans une fenêtre que dans une page.
**Remarque** : Pour manipuler une ligne d'un champ Table hiérarchique avec les propriétés WLangage, utilisez la notation : <Champ Table hiérarchique>[<Indice de l'élément>]..<Propriété>.
