# iTermineColonne (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Force un saut de colonne dans un état multicolonne.

## Exemple

```wlangage
// Code après impression d'un bas de rupture
iTermineColonne()
```

## Syntaxe

```wlangage
iTermineColonne()
```

## Remarques

- Dans le cas d'un état avec une seule colonne, cette fonction se comporte comme la fonction [iTerminePage](3046038.md).
- Si cette fonction est appelée sur la dernière colonne de l'état, un saut de page est effectué.

**Classification Métier / UI : Code neutre**

**Composante : wd300etat.dll**
