# EnModeSimulateurUniversalWindowsApp (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Identifie si le code est exécuté dans le simulateur pour les applications en mode Universal Windows 10 App ou non.

## Exemple

```wlangage
// Code exécuté dans le simulateur Universal Windows 10 App ?
SI EnModeSimulateurUniversalWindowsApp() = Vrai ALORS
	// Code spécifique pour le simulateur
FIN
```

## Syntaxe

```wlangage
<Résultat> = EnModeSimulateurUniversalWindowsApp()
```

`<Résultat>` *Booléen*
> - Vrai si le code est exécuté dans le simulateur pour les applications en mode Universal Windows 10 App,
> - Faux dans le cas contraire.
>
>
> > _(WEBDEV - Code Navigateur)_ Ce paramètre correspond toujours à Faux.

## Remarques

### Disponibilité de la fonction
La fonction **EnModeSimulateurUniversalWindowsApp** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **EnModeSimulateurUniversalWindowsApp** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.

### Exécution des traitements contenant des erreurs de compilation
Par défaut, le mécanisme de sécurité du WLangage se déclenche uniquement si la ligne contenant l'erreur de compilation est exécutée.
Par exemple, si une fonction interdite dans le produit en cours est présente dans une boucle SI, le mécanisme de sécurité du WLangage se déclenchera uniquement si la ligne contenant cette fonction s'exécute.

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
