# ServiceRedémarre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Redémarre un service (déjà démarré). Ce service peut être un service présent sur le poste local ou sur un poste distant. Les options spécifiées lors du précédent démarrage du service sont automatiquement prises en compte (par exemple la ligne de commande).

## Exemple

```wlangage
// Redémarre le service présent dans le champ TABLE_Service
SI ServiceRedémarre(COL_Nom[TABLE_Service]) = Faux ALORS
	Erreur(ErreurInfo(errMessage))
FIN
```

## Syntaxe

```wlangage
<Résultat> = ServiceRedémarre(<Nom du service> [, <Poste distant>])
```

`<Résultat>` *Booléen*
> - Vrai si le redémarrage a été demandé,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Nom du service>` *Chaîne de caractères*
> Nom du service à redémarrer.
`<Poste distant>` *Chaîne de caractères optionnelle*
> Adresse IP du poste distant au format xxx.xxx.xxx.xxx (obtenu par la fonction [NetAdresseIP](3056023.md)) ou nom du poste distant (obtenu par la fonction [NetNomMachine](3056014.md)). Ce paramètre permet de redémarrer un service sur un autre poste. Pour utiliser cette option, l'utilisateur doit être administrateur de la machine distante.
> Si ce paramètre n'est pas précisé ou correspond à une chaîne vide (""), le service est manipulé en local.

## Remarques

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Windows, Code Utilisateur (MCU), Ajax)_ Mode de fonctionnementLa fonction ServiceRedémarre envoie au gestionnaire de services une demande de redémarrage d'un service. Cette opération peut ne pas être effectuée immédiatement. Pour connaître l'état du service, utilisez la fonction ServiceAttendEtat.

**Composante : wd300std.dll**
