# <Graphe>.WaffleTaille (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Permet de définir le nombre de lignes et de colonnes d'un graphe de type Waffle.

## Exemple

```wlangage
// Configure le graphe
GRF_Graphe.WaffleTaille(nbColonnes, nbLignes)
// Redessine le graphe
GRF_Graphe.Dessine()
```

## Syntaxe

```wlangage
<Champ graphe>.WaffleTaille(<Nombre de colonnes> , <Nombre de lignes>)
```

`<Champ graphe>` *Nom de champ*
> Nom du graphe à manipuler. Ce nom correspond :
>
> - soit au nom du graphe défini par programmation avec la fonction [grCrée](3042005.md).
> - soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.
`<Nombre de colonnes>` *Entier*
> Nombre de colonnes dans le graphe de type Waffle.
`<Nombre de lignes>` *Entier*
> Nombre de colonnes dans le graphe de type Waffle.
