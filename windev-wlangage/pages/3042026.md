# grDessine (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Dessine un graphe selon les paramètres spécifiés.
**Remarques** :

- La fonction **grDessine** prend en compte les nouveaux paramètres spécifiés depuis le dernier appel à cette même fonction.
- Cette fonction ne doit pas être utilisée pour les champs Graphe présents dans l'éditeur d'états.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
// Dessin d'un graphe créé par programmation
grDessine("MonGraphe")
```

```wlangage
// Dessin d'un graphe dans un champ Graphe
grDessine(GRF_MonGraphe)
```

## Syntaxe

```wlangage
grDessine(<Nom du graphe>)
```

`<Nom du graphe>` *Nom de champ ou chaîne de caractères*
> Ce nom peut correspondre :
>
> - au nom du graphe à dessiner, défini avec la fonction [grCrée](3042005.md).
> - au nom du champ Graphe (présent dans une fenêtre ou une page).
>
>
> > _(Android)_ Seuls les champs Graphe sont disponibles.
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.

## Remarques

### Créer et dessiner un graphe par programmation
Pour créer et dessiner un graphe :

- créez le graphe (fonction [grCrée](3042005.md)),
- ajoutez les données (fonctions [grAjouteDonnée](3042023.md), [grBourseAjouteDonnée](3042009.md) et [grNuageAjouteDonnéeXY](3042032.md)),
- définissez la destination du graphe à l'aide des fonctions suivantes :
  - [grDestinationBMP](3042018.md),
  - [grDestinationChamp](3042020.md),
  - [grDestinationEMF](3042017.md),
  - [grDestinationFen](3042031.md),
  - [grDestinationImage](1000020952.md),
  - [grDestinationWMF](3042019.md).
- dessinez le graphe (fonction **grDessine**).

### Graphes et threads
Un seul graphe peut être manipulé dans un thread.
Conséquences :

- Deux threads ne peuvent pas manipuler le même graphe.
- Un graphe créé dans un thread est automatiquement détruit à la fin de ce thread. Le graphe existe dans le thread qui contient l'appel à la fonction [grCrée](3042005.md).

**Remarque** : Il est déconseillé d'appeler la fonction **grDessine** dans un thread. L'appel de cette fonction hors du thread principal peut provoquer des deadlocks et/ou engendrer des comportements aléatoires.

> _(Android)_ Dessins simultanésLa fonction grDessine n'est pas bloquante. Si le graphe est dessiné avec une animation, la fonction rendra la main dès le début de l'animation. Ainsi, si plusieurs graphes sont affichés dans la même fenêtre, il est possible d'animer ces champs simultanément.
