# Fonctions de gestion des navigateurs

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

Les fonctions de gestion des navigateurs sont les suivantes :

| [AjouteFavori](3055004.md) | Ajoute une adresse Internet dans la liste des favoris de l'internaute. |
| --- | --- |
| [CookieEcrit](3012008.md) | Ecrit un cookie sur le poste de l'internaute. |
| [CookieLit](3012009.md) | Récupère la valeur d'un cookie enregistré sur le poste de l'internaute. |
| [CookieSupprime](1000025874.md) | Supprime un cookie sur le poste de l'internaute. |
| [EmailOuvreMessagerie](3032021.md) | Ouvre le logiciel de messagerie par défaut :   - de l'internaute sur le poste navigateur. - de l'utilisateur sur le poste Windows en cours. - sur le téléphone. |
| [NavigateurAdresseIP](3055003.md) | Renvoie l'adresse IP du poste de l'Internaute connecté au site WEBDEV. |
| [NavigateurEstConnecté](1000019392.md) | Indique si le navigateur est connecté au réseau. |
| [NavigateurFerme](3055007.md) | Ferme la fenêtre en cours du navigateur et stoppe l'exécution du code en cours. |
| [NavigateurHauteur](1000022548.md) | Renvoie la hauteur en pixels de la zone cliente dans laquelle la page est affichée. |
| [NavigateurHistoriqueAjoute](1000023458.md) | Ajoute une entrée dans l'historique de navigation en lui associant des données. Ces données seront transmises lors du retour sur cette entrée. |
| [NavigateurHistoriqueModifie](1000023459.md) | Modifie les données de l'entrée courante dans l'historique de navigation. Ces données seront transmises lors d'un retour sur l'entrée courante. |
| [NavigateurImprime](1000024545.md) | Imprime la page courante actuellement affichée dans le navigateur. |
| [NavigateurLanceAppli](1000019424.md) | Ouvre le navigateur Web par défaut de l'appareil en cours. |
| [NavigateurLargeur](1000022547.md) | Renvoie la largeur en pixels de la zone cliente dans laquelle la page est affichée. |
| [NavigateurMobile](1000021856.md) | Permet de savoir si le navigateur utilisé par l'internaute est lancé sur un mobile. |
| [NavigateurNom](3055005.md) | Renvoie le nom du navigateur de l'internaute ("user agent"). |
| [NavigateurOS](1000021857.md) | Indique le système d'exploitation annoncé par le navigateur de l'internaute. |
| [NavigateurOuvre](3055006.md) | Ouvre une nouvelle fenêtre du navigateur sur une page identifiée par son URL. |
| [NavigateurPartage](1410089642.md) | Lance le partage natif de l'appareil. |
| [NavigateurPlateforme](1000019486.md) | Retourne la plateforme du navigateur utilisée par l'internaute. |
| [NavigateurTranche](1000022546.md) | Renvoie le numéro de la tranche affichée dans une page en mode Responsive Web Design. |
| [NavigateurType](1000019487.md) | Retourne le type du navigateur utilisé par l'internaute. |
| [NavigateurVersion](1000019488.md) | Retourne la version du navigateur utilisé par l'internaute. |
| [NotificationAffiche](1000021021.md) | Affiche un message hors navigateur. |
| [PleinEcranActive](1000021012.md) | Passe le navigateur en mode "Plein écran". Le navigateur occupe ainsi tout l'espace de l'écran. |
| [PleinEcranDésactive](1000021013.md) | Désactive le mode "Plein écran" du navigateur. |
