# Fonctions statistiques

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Les fonctions statistiques sont les suivantes :

| [StatCorrélation](3050022.md) | Calcule le coefficient de corrélation entre deux séries de valeurs. |
| --- | --- |
| [StatCovariance](3050020.md) | Calcule la covariance entre deux séries de valeurs. |
| [StatEcartMoyen](3050024.md) | Calcule la moyenne des écarts absolus des valeurs par rapport à leur moyenne arithmétique. |
| [StatEcartType](3050025.md) | Calcule l'écart type d'une série de valeurs. |
| [StatEcartTypeP](3050026.md) | Calcule l'écart type d'une série complète de valeurs. |
| [StatErreur](3050019.md) | Calcule le numéro de la dernière erreur due à une fonction Statxx ([fonctions statistiques](3050027.md)). |
| [StatMax](3050034.md) | Calcule la valeur maximale d'une série de valeurs. |
| [StatMin](3050037.md) | Calcule la valeur minimale d'une série de valeurs. |
| [StatMoyenne](3050036.md) | Calcule la moyenne arithmétique, géométrique ou harmonique d'une série de valeurs. |
| [StatSomme](3050035.md) | Calcule le cumul d'une série de valeurs. |
| [StatVariance](3050033.md) | Calcule la variance d'une série de valeurs. |
| [StatVarianceP](3050030.md) | Calcule la variance d'une série complète de valeurs. |
