# Constantes de gestion des flux (son et vidéo)

> **Disponible :** **WINDEV** (Windows)

| Constante | Description | Utilisée par les fonctions ou propriétés |
| --- | --- | --- |
| **FluxAffichageAucun** | Vidéo affichée dans le champ Conférence : Aucune vidéo n'est affichée. | Propriété [Affichage](2510010.md) |
| **FluxAffichageEmission** | Vidéo affichée dans le champ Conférence : La vidéo affichée correspond à la vidéo émise par le poste en cours. | Propriété [Affichage](2510010.md) |
| **FluxAffichageRéception** | Vidéo affichée dans le champ Conférence : La vidéo affichée correspond à la vidéo reçue sur le poste en cours. | Propriété [Affichage](2510010.md) |
| **FluxNomAppelant** | Nom de l'émetteur du flux. | [FluxInfo](3039009.md), [FluxStop](3039002.md) |
| **FluxNuméroAppelant** | Numéro de l'émetteur de flux (par exemple son adresse IP). | [FluxInfo](3039009.md), [FluxStop](3039002.md) |
| **FluxSon** | Type de données émise par le flux : Les données de type son sont émises. | Propriété [Emission](2510037.md) |
| **FluxSonDuplex** | Flux de type son reçu et émis (correspond à FluxSonEmission + FluxSonRéception). | [FluxJoue](3039010.md), [FluxStop](3039002.md) |
| **FluxSonEmission** | Flux de type son émis. | [FluxJoue](3039010.md), [FluxStop](3039002.md) |
| **FluxSonRéception** | Flux de type son reçu. | [FluxJoue](3039010.md), [FluxStop](3039002.md) |
| **FluxTout** | Flux de type vidéo + son (FluxSonDuplex + FluxVidéoDuplex). | [FluxJoue](3039010.md), [FluxStop](3039002.md) |
| **FluxVidéo** | Type de données émise par le flux : Les données de type Vidéo sont émises. | Propriété [Emission](2510037.md) |
| **FluxVidéoDuplex** | Flux de type vidéo reçu et émis (correspond à FluxVidéoEmission + FluxVidéoRéception). | [FluxJoue](3039010.md), [FluxStop](3039002.md) |
| **FluxVidéoEmission** | Flux de type Vidéo émis. | [FluxJoue](3039010.md), [FluxStop](3039002.md) |
| **FluxVidéoRéception** | Flux de type Vidéo reçu. | [FluxJoue](3039010.md), [FluxStop](3039002.md) |
