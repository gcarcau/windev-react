# Constantes de gestion de la téléphonie

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows)

| Constante | Détail | Utilisée par la fonction |
| --- | --- | --- |
| **telInformationAppel** | Les informations supplémentaires (présentation du numéro) sont disponibles. Ces informations ne sont généralement disponibles qu'après la première sonnerie. | [telDémarreDétectionAppel](3076029.md) |
| **telJoueBloque** | La fonction **telJoue** est bloquante : le code continue de s'exécuter uniquement lorsque le son a été joué. Si ce paramètre n'est pas spécifié, la fonction renvoie un résultat dès que le son commence à être joué. | [telJoue](3076023.md) |
| **telJoueBoucle** | Le son est joué en boucle. Si ce paramètre n'est pas spécifié, le son est joué une seule fois. | [telJoue](3076023.md) |
| **telLigneAttendRéponse** | Etat de la ligne : L'appel est composé : recherche du correspondant | [telCompose](3076013.md), [telComposeLigne](3076012.md),  [telDémarreDétectionAppel](3076029.md) |
| **telLigneDecrochée** | Etat de la ligne : La ligne est connectée | [telCompose](3076013.md), [telComposeLigne](3076012.md),  [telDémarreDétectionAppel](3076029.md) |
| **telLigneNumérote** | Etat de la ligne : Numérotation en cours | [telCompose](3076013.md), [telComposeLigne](3076012.md),  [telDémarreDétectionAppel](3076029.md) |
| **telLigneOccupée** | Etat de la ligne : La ligne est actuellement occupée | [telCompose](3076013.md), [telComposeLigne](3076012.md),  [telDémarreDétectionAppel](3076029.md) |
| **telLigneRaccrochée** | Etat de la ligne : Le correspondant a raccroché | [telCompose](3076013.md), [telComposeLigne](3076012.md),  [telDémarreDétectionAppel](3076029.md) |
| **telLigneSonnerie** | Etat de la ligne : Sonnerie en cours chez le correspondant | [telCompose](3076013.md), [telComposeLigne](3076012.md),  [telDémarreDétectionAppel](3076029.md) |
| **telLigneTonalité** | Etat de la ligne : La ligne reçoit la tonalité | [telCompose](3076013.md), [telComposeLigne](3076012.md),  [telDémarreDétectionAppel](3076029.md) |
| **telNouvelAppel** | Nouvel appel détecté en attente de réponse ou de rejet. | [telDémarreDétectionAppel](3076029.md) |
| **telOptionDéfaut** | Détection d'appels sur un modem fax. Les fonctions de manipulation d'appel ne sont généralement pas supportées par les modems. | [telDémarreDétectionAppel](3076029.md) |
| **telOptionMoniteur** | Détecte les appels (par exemple pour réaliser des statistiques), même s'ils sont gérés par une autre application. Aucune manipulation de l'appel ne sera possible. | [telDémarreDétectionAppel](3076029.md) |
| **telOptionTypeFax** | Utilisation d'un périphérique acceptant les appels entrant de type Fax | [telCapacité](3076014.md) [telDémarreDétectionAppel](3076029.md) |
| **telOptionTypeInconnu** | Utilisation d'un périphérique acceptant les appels entrant de type inconnu | [telCapacité](3076014.md) [telDémarreDétectionAppel](3076029.md) |
| **telOptionTypeVoix** | Utilisation d'un périphérique acceptant les appels entrant de type Voix | [telCapacité](3076014.md) [telDémarreDétectionAppel](3076029.md) |
| **telOrigineAppelConférence** | Appel en mode conférence (à plusieurs) | [telOrigine](3076028.md) |
| **telOrigineAppelEntrant** | Appel entrant : communication provenant de l'extérieur. L'utilisation de cette variable dépend du type de matériel utilisé, du driver, ... | [telOrigine](3076028.md) |
| **telOrigineAppelExterne** | Appel d'origine indéterminée. L'utilisation de cette variable dépend du type de matériel utilisé, du driver, ... | [telOrigine](3076028.md) |
| **telOrigineAppelIndisponible** | Appel d'origine indéterminée. L'utilisation de cette variable dépend du type de matériel utilisé, du driver, ... | [telOrigine](3076028.md) |
| **telOrigineAppelInterne** | Appel interne au PABX | [telOrigine](3076028.md) |
| **telOrigineAppelSortant** | Appel sortant : communication effectuée vers l'extérieur. | [telOrigine](3076028.md) |
| **telToucheDétectée** | Une touche du clavier téléphonique a été utilisée. | [telDémarreDétectionAppel](3076029.md) |
