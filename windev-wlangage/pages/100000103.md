# Erreur 103 : Le type est inconnu

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Cause

Ce type est inconnu. Vous avez sans doute fait une faute de frappe dans le nom d'un type simple, d'une classe ou d'une structure.

## Correction

Vérifiez le type utilisé. Si vous utilisez une classe, vérifiez par exemple que cette classe est intégrée au projet.

**Remarque** : Grâce à la coloration syntaxique, les types reconnus sont colorés en NOIR par défaut.

## Exemples

### Utilisation d'un type simple inconnu

**Code provoquant l'erreur**

```wlangage

Chiffre_affaire est un enter
```

**Correction proposée**

Corrigez le type.

```wlangage

Chiffre_affaire est un entier
```

### Déclaration de structure

**Code provoquant l'erreur**

```wlangage

STPoint est une Structure
 x, y sont des entiers
FIN

UnPoint est STPont
```

**Correction proposée**

Corrigez le nom de la structure.

```wlangage

STPoint est une Structure
 x, y sont des entiers
FIN

UnPoint est STPoint
```
