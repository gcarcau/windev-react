# Fonctions de gestion du MCU

> **Disponible :** **WINDEV** (Windows)

Les fonctions de gestion du MCU sont les suivantes :

| [EnModeMCU](1000017027.md) | Identifie si le code est exécuté depuis un code écrit dans une macro utilisateur. |
| --- | --- |
| [MCUActif](3030020.md) | Permet de connaître et de modifier l'activation de la gestion du MCU (Macro Code Utilisateur). |
| [MCUOuvre](3030021.md) | Ouvre la fenêtre d'édition du Macro Code Utilisateur pour la fenêtre en cours. |
