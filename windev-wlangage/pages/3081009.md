# XMLEnDehors (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Permet de savoir si l'élément (balise ou attribut) sur lequel on veut se positionner est en dehors du document XML.
L'utilisation de la fonction **XMLEnDehors** n'est pas obligatoire. En effet, les fonctions de parcours XML renvoient un résultat qui permet de savoir si elles ont réussi ou échoué. L'utilisation de la fonction **XMLEnDehors** est conseillée pour plus de clarté dans votre code.

## Exemple

```wlangage
// Lecture du premier élément
XMLPremier("DocXML")

// Balise trouvée ?
SI XMLEnDehors("DocXML") = Faux ALORS
	Info("Balise courante : " + XMLNomElément("DocXML"))
FIN
```

## Syntaxe

```wlangage
<Résultat> = XMLEnDehors(<Document XML>)
```

`<Résultat>` *Booléen*
> - Vrai si une fonction de parcours n'a pas pu se positionner sur un élément,
> - Faux dans le cas contraire (la position en cours dans le document XML n'est alors pas modifiée).
>   La fonction **XMLEnDehors** renvoie toujours le résultat opposé de la fonction [XMLTrouve](3081020.md).
`<Document XML>` *Chaîne de caractères*
> Nom du document XML manipulé. Ce document contient le code XML à analyser et a été créé avec la fonction [XMLDocument](3081008.md).

## Remarques

### Fonctions modifiant XMLEnDehors
Les fonctions suivantes modifient la valeur retournée par la fonction **XMLEnDehors** :

- [XMLPremier](3081024.md), [XMLDernier](3081013.md),
- [XMLSuivant](3081030.md), [XMLPrécédent](3081023.md),
- [XMLFils](3081012.md), [XMLParent](3081022.md), [XMLRacine](3081019.md),
- [XMLRecherche](3081025.md).

### Fonctions XML et threads
Si votre application utilise des threads, le document XML est partagé entre tous ces threads. Pour plus de détails sur la gestion des threads, consultez [Gestion des threads](3077026.md).Si la position courante dans un document XML est modifiée dans un thread, la position courante dans ce document XML est modifiée pour tous les threads.

**Composante : wd300xml.dll**
