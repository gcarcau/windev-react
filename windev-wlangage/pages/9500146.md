# Champ Image : les formats supportés

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

## Présentation

> _(Windows)_ Les formats d'images supportés sous Windows sont :Bitmap (*.BMP)Graphics Interchange Format (*.gif)Joint Picture Experts Group (*.jpg ; *.jpeg)Kodak Photo CD (*.pcd)PaintBrush (*.pcx)Adobe Photoshop Format (*.psd)TrueVision TARGA (*.tga)Tagged Image File Format (*.tif ; *.tiff)Remarque : l'option "tiff mosaïque" de la norme tiff 6.0 n'est pas supportée. Dans ce cas, il est conseillé d'enregistrer l'image à la norme tiff 5.0. Portable Network Graphics (*.png)Windows MetaFiles (*.emf ; *.wmf)Icônes (*.ico ; *.icw)Remarques : Affichage HQ (Haute Qualité) disponible.Gestion des planches au format BMP transparent (32 bits).Curseurs (*.cur)Portable Document Format (*.pdf)Scalable Vector Graphics (*.svg)Images WINDEV (générées par l'éditeur d'images, *.WDPIC).Nouveauté 2025Images au format WebP (*.webp).

> _(Linux)_ Les formats d'images supportés sous Linux sont : Bitmap (*.BMP)Graphics Interchange Format (*.gif)Joint Picture Experts Group (*.jpg ; *.jpeg)Portable Network Graphics (*.png)Portable Bitmap (*.pbm)Portable Graymap (*.pgm)Portable Pixmap (*.ppm)Tagged Image File Format (*.tiff)Remarque : l'option "tiff mosaïque" de la norme tiff 6.0 n'est pas supportée. Dans ce cas, il est conseillé d'enregistrer l'image à la norme tiff 5.0. X11 Bitmap (*.xbm)X11 Pixmap (*.xpm)Scalable Vector Graphics (*.svg)Remarque : Pour gérer ce format, il faut installer une librairie QT supportant le format SVG.Images WINDEV (générées par l'éditeur d'images, *.WDPIC).

> _(Android, Widget Android)_ Les formats d'images supportés sont : Bitmap (*.BMP)Joint Picture Experts Group (*.jpeg)Portable Network Graphics (*.png)Scalable Vector Graphics (*.svg)Attention : les styles CSS et les éléments de type <filter> dans les images au format SVG ne sont pas supportés. Images WINDEV (générées par l'éditeur d'images, *.WDPIC).Attention : Si un fichier de type ".WDPIC" doit être affecté par programmation à un champ, il est nécessaire que ce fichier ait préalablement été ajouté dans la liste des éléments du projet.

> _(iPhone/iPad)_ Les formats d'images supportés sont : Portable Network Graphics (*.png)Joint Picture Experts Group (*.jpg ; *.jpeg)Tagged Image File Format (*.tiff ou *.tif)Remarque : L'option "tiff mosaïque" de la norme tiff 6.0 n'est pas supportée. Dans ce cas, il est conseillé d'enregistrer l'image à la norme tiff 5.0. Graphics Interchange Format (*.gif)Attention : Les Gif animés ne sont pas supportés. Bitmap (*.BMP)X11 Bitmap (*.xbm)Scalable Vector Graphics (*.svg)Images WINDEV (générées par l'éditeur d'images, *.WDPIC).

> _(Java)_ Les formats d'images supportés sont : Bitmap (*.BMP)Graphics Interchange Format (*.gif)Attention : Les Gif animés ne sont pas supportés.Joint Picture Experts Group (*.jpeg)Portable Network Graphics (*.png)Images WINDEV (générées par l'éditeur d'images, *.WDPIC).Attention : Si un fichier de type ".WDPIC" doit être affecté par programmation à un champ, il est nécessaire que ce fichier ait préalablement été ajouté dans la liste des éléments du projet.
