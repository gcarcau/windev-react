# Fonctions de gestion des champs Tableau de bord

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des champs Tableau de bord (syntaxe préfixée)](1000022537.md)).
Les fonctions de gestion des champs Tableau de bord sont les suivantes :

| [TDBAffiche](1000020970.md) | Rafraîchit l'affichage des éléments d'un champ Tableau de bord. |
| --- | --- |
| [TDBAjouteWidget](1000020953.md) | Ajoute et affiche un Widget (fenêtre interne) dans un champ Tableau de bord. |
| [TDBChangeTailleWidget](1000021286.md) | Change les dimensions d'un Widget présent dans un champ Tableau de bord. |
| [TDBChargeConfiguration](1000020961.md) | Restaure la configuration d'un champ Tableau de bord. |
| [TDBConfigurationInitiale](1000021043.md) | Modifie la configuration d'un champ Tableau de bord (définie sous l'éditeur) avant son premier affichage. |
| [TDBDéplaceWidget](1000021289.md) | Change la position d'un widget présent dans un champ Tableau de bord. |
| [TDBInfoXY](1000020974.md) | Permet de savoir :  - si un Widget est présent dans un champ Tableau de bord à une position donnée. - quel est le Widget présent dans un champ Tableau de bord à une position donnée. |
| [TDBMode](1000020956.md) | Ouvre ou ferme le mode "Edition" d'un champ Tableau de bord. |
| [TDBOccurrence](1000021042.md) | Renvoie le nombre de Widgets présents dans un champ Tableau de bord. |
| [TDBRécupèreWidgetPosition](1000022498.md) | Renvoie la position d'un Widget présent dans un champ Tableau de bord. |
| [TDBSauveConfiguration](1000020960.md) | Sauvegarde la configuration d'un champ Tableau de bord sous forme d'une chaîne. |
| [TDBSupprime](1000020955.md) | Supprime un Widget affiché dans un champ Tableau de bord. Le champ Tableau de bord est mis à jour et un emplacement vide remplace le Widget supprimé. |
| [TDBSupprimeTout](1000020954.md) | Supprime tous les Widgets affichés dans un champ Tableau de bord. |

Autres fonctions disponibles :

| [DnDDonneElémentTDB](1000020971.md) | Ajoute un Widget dans un champ Tableau de bord lors d'un "Drag and Drop". |
