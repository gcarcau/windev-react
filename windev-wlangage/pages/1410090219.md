# VisiteGuidéeInfo (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Renvoie des informations sur une visite guidée.

## Exemple

```wlangage
// Affiche la visite guidée uniquement au premier lancement
SI VisiteGuidéeInfo(VisiteDécouverte, vgInfoOccurrence) = 0 ALORS
	VisiteGuidéeDémarre(VisiteDécouverte)
FIN
```

```wlangage
// Affiche la visite guidée 1 fois par jour max et 5x max
SI VisiteGuidéeInfo(VisiteDécouverte, vgInfoDate) < DateSys()
		_ET_ VisiteGuidéeInfo(VisiteDécouverte, vgInfoOccurrence) < 5 ALORS
	VisiteGuidéeDémarre(VisiteDécouverte)
FIN
```

```wlangage
// Affiche les nouveautés d'une version
VisiteNouveauté est un VisiteGuidée
VisiteNouveauté.Identifiant = "Nouveauté de la version"
VisiteNouveauté.Version = 29
SI VisiteGuidéeInfo(VisiteNouveauté, vgInfoVersion) < 29 ALORS
	VisiteNouveauté.Étape[1].Cible = SAI_Prénom
	VisiteNouveauté.Étape[1].Titre = "Nouveau !"
	VisiteNouveauté.Étape[1].Description = "Vous pouvez maintenant saisir votre prénom"
	VisiteGuidéeDémarre(VisiteNouveauté)
FIN
```

## Syntaxe

```wlangage
<Résultat> = VisiteGuidéeInfo(<Visite guidée> , <Information>)
```

`<Résultat>` *Type de l'information*
> Information demandée.
`<Visite guidée>` *Chaîne de caractères ou variable de type VisiteGuidée*
> Visite guidée manipulée. Ce paramètre peut correspondre :
>
> - à l'identifiant de la visite guidée.
> - au nom de la variable [VisiteGuidée](1410090170.md).
`<Information>` *Constante de type Entier*
> Information recherchée :
>
> | *vgInfoDate* | Date à laquelle la visite guidée a été vue pour la dernière fois sur le poste en cours. |
> | --- | --- |
> | *vgInfoOccurrence* | Nombre de fois où l'utilisateur a vu la visite guidée. |
> | *vgInfoVersion* | Numéro de version de la dernière visite guidée vue par l'utilisateur. |

## Remarques

> _(WINDEV)_ Remettre à 0 le compteur de visites guidées (information donnée par la constante vgInfoOccurrence)Dans les applications WINDEV, il est possible de remettre le compteur de visites guidées à zéro via le code suivant :

SauveParamètre("VisiteGuidee\<identifiant_visite>\occurrence",0)

où <identifiant_visite> correspond à l'identifiant de la visite guidée. Par exemple :

Visite est un VisiteGuidée
Visite.Identifiant = "Visite_20240503_1119"
SauveParamètre("VisiteGuidee\Visite_20240503_1119\occurrence",0)
