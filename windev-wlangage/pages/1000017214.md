# MultimédiaEtat (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Indique l'état du fichier multimédia joué dans le champ Multimédia.
> _(WEBDEV - Code Navigateur)_ Remarque : Selon le type de vidéo et la configuration du navigateur, cette fonction peut ne pas être supportée. Dans ce cas, l'appel à cette fonction sera sans effet et ne provoquera pas d'erreur.

## Exemple

> _(WINDEV, Etats et Requêtes, Code Utilisateur (MCU))_ MonFichier est une chaîne = "C:\Ma musique\mysong.mp3"

MultimédiaOuvre(MM_Multimédia1, MonFichier)
...
SI MultimédiaEtat(MM_Multimédia1) = MultimédiaEtatPause ALORS
 MultimédiaDébut(MM_Multimédia1)
 MultimédiaJoue(MM_Multimédia1)
FIN
...
MultimédiaFerme(MM_Multimédia1)

## Syntaxe

```wlangage
<Résultat> = MultimédiaEtat(<Champ Multimédia>)
```

`<Résultat>` *Constante de type entier*
> Etat du fichier multimédia en cours dans le champ Multimédia.
>
> | *MultimédiaEtatArrêt* | Fichier arrêté. _(WEBDEV - Code Navigateur)_ Selon le type de vidéo et la configuration du navigateur, cette constante peut ne jamais être retournée : un fichier multimédia chargé peut être uniquement en lecture ou en pause. |
> | --- | --- |
> | *MultimédiaEtatJoue* | Fichier ouvert et en cours de lecture. |
> | *MultimédiaEtatPause* | Fichier en pause. |
`<Champ Multimédia>` *Nom de champ*
> Nom du champ Multimédia à manipuler.

**Composante : wd300obj.dll**
