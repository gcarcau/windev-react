# PoliceNom (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

La propriété **PoliceNom** permet de gérer le nom de la police utilisée. Cette propriété est utilisable sur :

- les champs. Pour plus de détails, consultez [PoliceNom](2510100.md).
- une variable de type [docMiseEnForme](1000022817.md).
- une variable de type [pdfElémentTexte](1000024556.md).
