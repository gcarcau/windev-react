# <Editeur de code>.Sauve (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Sauve le contenu d'un champ Editeur de code dans un fichier.

## Exemple

```wlangage
sFichier est une chaîne
// Ouvre le sélecteur de fichiers
sFichier = fSélecteur("", "", "Sélectionnez un fichier...", "Code WLangage (*.WL)" + TAB + "*.WL", "*.WL")

SI sFichier <> "" ALORS
	// Sauve le code WLangage présent dans le champ Editeur de code dans le fichier passé en paramètre
	EDCODE_Exemple.Sauve(sFichier)
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Champ Editeur de code>.Sauve(<Fichier à sauver>)
```

`<Résultat>` *Booléen*
> - Vrai si le code présent dans le champ Editeur de code a été sauvé dans le fichier,
> - Faux dans le cas contraire.
`<Champ Editeur de code>` *Nom de champ*
> Nom du champ Editeur de code à manipuler.
`<Fichier à sauver>` *Chaîne de caractères*
> Nom et chemin complet du fichier dans lequel le contenu du champ Editeur de code doit être sauvé.

**Classification Métier / UI : Code métier**

**Composante : wd300obj.dll**
