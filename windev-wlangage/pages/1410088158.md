# <Lecteur PDF>.RécupèreSignature (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Récupère la signature d'un document PDF sous forme d'un buffer. Le certificat correspondant pourra être extrait via la fonction [CertificatExtrait](1000019300.md).

## Exemple

```wlangage
PDF_LecteurPDF = PDFOuvre("test.pdf")

// Nombre de signatures dans le fichier PDF
nNbSignature est un entier = PDF_LecteurPDF.NbSignature()

// Récupération des informations sur les signatures
POUR i = 1 _À_ nNbSignature
	// Récupération de la signature
	bufSignature est un Buffer = PDF_LecteurPDF.RécupèreSignature(i)

	// Récupération de la date de la signature
	dhDateSignature est une DateHeure = PDF_LecteurPDF.RécupèreDateSignature(i)

	// Récupération du certificat
	Certif est un Certificat = CertificatExtrait(bufSignature)
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Champ Lecteur PDF>.RécupèreSignature(<Indice>)
```

`<Résultat>` *Buffer*
> Signature du document.
`<Champ Lecteur PDF>` *Nom de champ*
> Champ Lecteur PDF contenant le document à analyser.
`<Indice>` *Entier*
> Indice de la signature dans le document (le nombre de signatures est connu par la fonction [<Lecteur PDF>.NbSignature](1410088155.md)).

**Composante : wd300wdpdf.dll**
