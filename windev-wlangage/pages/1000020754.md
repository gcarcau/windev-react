# SOAPAjouteSignatureXML (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Ajoute une signature XML à une requête de Webservice.
Remarque : Cette fonction est une fonction avancée. Elle est notamment utilisée lors de la gestion du Webservice Sesam Vitale.

## Exemple

```wlangage
Param est un ParamRequest
MaProcRequête est un wsRequête
SOAPAjouteSignatureXML(MaProcRequête, Param.Assertion.Signature, MaSignature)
MaProc(MaProcRequête, Param, "Hello ")
```

## Syntaxe

```wlangage
<Résultat> = SOAPAjouteSignatureXML(<Requête> , <Emplacement de la signature> , <Signature>)
```

`<Résultat>` *Entier*
> - Indice de la signature ajoutée,
> - -1 en cas d'erreur.
`<Requête>` *Variable de type wsRequête*
> Nom de la variable de type [wsRequête](1000020577.md) correspondant à la requête dans laquelle il faut ajouter une signature.
`<Emplacement de la signature>` *Variable générée par l'import d'un Webservice*
> Entité XSD où la signature "ds :Signature" doit être ajoutée.
`<Signature>` *Variable de type xmlSignature*
> Nom de la variable de type [xmlSignature](1000020736.md) correspondant à la signature à ajouter.
