# NoteSupprime (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Supprime une note repositionnable présente dans la fenêtre en cours. Cette note repositionnable peut être un champ ou une note créée par programmation avec les fonctions [FenEdCréeNote](1000022270.md), [NoteCrée](1000022395.md) ou [ChampCrée](1000020876.md)).

## Exemple

```wlangage
// Clic sur [Nouvelle note]
gMaNote <- NoteCrée()

// Clic sur [Supprimer]
SI gMaNote <> Null ALORS
	NoteSupprime(gMaNote)
FIN
```

## Syntaxe

```wlangage
NoteSupprime(<Note à manipuler>)
```

`<Note à manipuler>` *Chaîne de caractères*
> Nom de la note repositionnable à supprimer. Ce nom peut correspondre :
>
> - au nom d'un champ Note repositionnable présent dans la fenêtre.
> - à une variable de type Champ associée à une note repositionnable créée avec une des fonctions suivantes : [FenEdCréeNote](1000022270.md), [NoteCrée](1000022395.md) ou [ChampCrée](1000020876.md).

**Composante : wd300obj.dll**
