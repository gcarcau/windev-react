# DateDuJour (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Renvoie ou modifie la date système (date du jour définie pour le poste en cours).
**Remarques** :

- Cette fonction est identique à la fonction [DateSys](3027026.md).
- La date système correspond à la date du jour définie pour le poste serveur.

## Exemple

```wlangage
Res = DateDuJour()   // Res = "20011225"
Res = DateVersChaîne(DateDuJour()) // Res = "25/12/2001"
Année = Gauche(DateDuJour(), 4)
// Année retourne l'année en cours (par exemple 2001)
```

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Windows, Code Utilisateur (MCU), Ajax, Procédures stockées)_ // Change la date système et affiche la nouvelle date
DateDuJour("20020101")
Info(DateDuJour())

## Syntaxe

#### Connaître la date système

```wlangage
<Résultat> = DateDuJour()
```

`<Résultat>` *Chaîne de caractères ou variable de type Date*
> Date système au format AAAAMMJJ (AAAA correspond à l'année, MM au mois et JJ au jour).

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Windows, Code Utilisateur (MCU), Ajax, Procédures stockées)_ Modifier la date système Masquer les détails
DateDuJour(<Nouvelle date>)

 <Nouvelle date> : Chaîne de caractères ou variable de type DateNouvelle date système au format AAAAMMJJ (AAAA correspond à l'année, MM au mois et JJ au jour).

## Remarques

- Pour obtenir la date sous un autre format que AAAAMMJJ, il faut formater la chaîne avec les fonctions [DateVersChaîne](3027025.md), [Droite](3024016.md), [Gauche](3024001.md), etc. Le format AAAAMMJJ a été choisi car il permet de tester la chronologie de deux dates selon ce même format, alors que cela ne serait pas possible avec une date au format AAAAJJMM ou AAMMJJ par exemple.
- Sur tous les systèmes actuels, l'année de la date système peut être comprise entre 1920 et 2120.
- **Attention** : Pour modifier la date système, il est nécessaire de posséder les droits administrateur sur le poste en cours.
- Dans cette version, la fonction **DateDuJour** permet uniquement de renvoyer la date système (date du jour définie pour le poste en cours ou le poste navigateur).
- En mode simulation, la date du PC est manipulée. En exécution réelle, la date du mobile est manipulée.
