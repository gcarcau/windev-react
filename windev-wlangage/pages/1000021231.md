# AnimationAllerRetour (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

La propriété **AnimationAllerRetour** permet de :

- Savoir si l'animation dans un champ Jauge infinie personnalisé fait un aller-retour.
- Configurer l'animation dans un champ Jauge infinie personnalisé pour faire un aller-retour.

## Exemple

```wlangage
JAUGE_Infinie1.Image = "Roue.png"
JAUGE_Infinie1.NbEtapeAnimation = 36
JAUGE_Infinie1.AnimationAllerRetour = Vrai
```

## Syntaxe

#### Savoir si l'animation fait un aller-retour

```wlangage
<Résultat> = <Champ Jauge>.AnimationAllerRetour
```

`<Résultat>` *Booléen*
> - Vrai si le champ Jauge fait un aller-retour,
> - Faux si le champ Jauge fait un simple aller.
`<Champ Jauge>` *Nom de champ*
> Nom du champ Jauge infinie à manipuler.

#### Configurer l'animation pour faire ou non un aller-retour

```wlangage
<Champ Jauge>.AnimationAllerRetour = <Nouvelle valeur>
```

`<Champ Jauge>` *Nom de champ*
> Nom du champ Jauge infinie à manipuler.
`<Nouvelle valeur>` *Booléen*
> - Vrai pour faire un aller/retour.
> - Faux pour faire un aller simple.
