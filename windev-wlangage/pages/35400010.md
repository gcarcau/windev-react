# Gestion des fichiers de données HFSQL Classic

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch)

## Présentation

Le Centre de Contrôle HFSQL propose une gestion complète des fichiers de données HFSQL Classic.
**Pour afficher les caractéristiques d'un fichier de données HFSQL Classic** :

1. Affichez si nécessaire la fenêtre de bienvenue du Centre de Contrôle HFSQL. Cette fenêtre apparaît :
  - au lancement du Centre de Contrôle HFSQL.
  - en déroulant [image: Option de menu] puis en sélectionnant "Ouvrir un fichier de données HFSQL Classic".
2. La fenêtre de bienvenue du Centre de Contrôle s'affiche.
  [image: Fichiers HFSQL Classic]
3. Indiquez :
  - le chemin du fichier de données HFSQL Classic à ouvrir,
  - son mot de passe (si nécessaire). Il est possible de mémoriser le mot de passe.
4. Validez.
5. Le Centre de Contrôle HFSQL affiche le contenu du fichier de données sélectionné.
  - Les différents onglets permettent de gérer les caractéristiques du fichier de données HFSQL Classic.
  - Le ruban propose les différentes actions possibles sur le fichier. Selon l'onglet sélectionné, les actions proposées peuvent varier.

## Détail des caractéristiques d'un fichier de données HFSQL Classic

### Onglet "Description"
Cet onglet présente toutes les informations concernant les rubriques du fichier de données.
[image: HFSQL Classic - onglet Description]

Les informations affichées sont les suivantes :

- Le nom de la rubrique,
- Le type de la rubrique,
- La taille de la rubrique,
- Le type de clé,
- Les statistiques,
- Si la rubrique est visible sous le logiciel "Etats & Requêtes".

Si nécessaire, des informations complémentaires sont affichées.

Remarque : Par défaut, les rubriques sont affichées dans l'ordre logique. il est possible d'utiliser l'ordre alphabétique si nécessaire via les options du Centre de Contrôle HFSQL :

1. Déroulez le menu du Centre de Contrôle HFSQL ().
2. Sélectionnez "Options".
3. Dans la fenêtre qui s'affiche, indiquez "alphabétique" pour l'option "Ordre d'affichage des rubriques".

### Onglet "Propriétés"
L'onglet "Propriétés" affiche les propriétés du fichier de données (nom physique, format, protection, etc.).

[image: HFSQL Classic - onglet Propriétés]

### Onglet "Contenu"
Cet onglet permet de visualiser les différents enregistrements du fichier de données.

[image: HFSQL Classic - onglet Contenu]

Il est également possible de filtrer les enregistrements affichés via la barre présente au-dessus des données.

Le menu contextuel du filtre () propose plusieurs options :

- Application automatique : le filtre est automatiquement exécuté lors de sa validation avec la touche Entrée du clavier. Si cette option n'est pas sélectionnée, la validation doit être effectuée en cliquant sur la coche verte en fin de ligne.
- Supprimer le filtre en cours : Permet de vider le champ du filtre.
- Copier le code SQL : Permet de copier dans le presse-papiers le code SQL correspondant au filtre saisi.
- Créer une requête : Permet d'afficher le volet "Requête" avec le code SQL de la requête saisie (équivalent à l'option "Nouvelle requête" du ruban). Pour plus de détails, consultez [Créer et exécuter une requête](35400019.md).
- Vider l'historique des filtres : Les filtres créés sont automatiquement mémorisés pour pouvoir être rapidement ré-appliqués. Il est possible de supprimer tous les filtres mémorisés.

Le menu contextuel des enregistrements permet de manipuler l'enregistrement sélectionné : suppression, ajout, mode d'affichage des mémos texte, etc.

Il est également possible de :

- Supprimer un enregistrement : sélectionnez l'enregistrement et cliquez sur le bouton "Supprimer" (ou appuyez sur la touche Suppr).
- Modifier ou ajouter un enregistrement : la saisie se fait directement dans la liste des enregistrements. Il suffit de se positionner sur la première ligne vide et de saisir les informations de l'enregistrement. La modification du fichier de données est faite automatiquement.

### Onglet "Journaux"
Cet onglet permet de visualiser le contenu des journaux, d'effectuer une recherche dans les journaux.
Il est nécessaire que le fichier de données soit journalé.

### Onglet "Transactions"
Cet onglet permet de libérer un enregistrement ou toutes les transactions.
[image: HFSQL Classic - Onglet Transactions]

## Options proposées par le ruban

Pour le fichier de données HFSQL Classic sélectionné, le ruban propose les actions suivantes :
[image: HFSQL Classic - Options du ruban]

- Dans le groupe "Requête SQL" :
  - Nouvelle requête : Cette option permet d'ouvrir un onglet spécifique permettant de réaliser une requête sur le fichier de données en cours.
  - Ouvrir une requête : Cette option permet d'ouvrir un onglet spécifique correspondant à une requête précédemment réalisée.
   Pour plus de détails, consultez [Créer et exécuter une requête](35400019.md).
- Dans le groupe "Fichier de données" :
  - Optimiser et réparer : Cette option permet d'afficher la fenêtre de configuration de l'optimisation et de la réparation des fichiers de données HFSQL. Pour plus de détails, consultez [Optimiser et réparer des fichiers de données](3540007.md).
  - Fermer le fichier de données : Cette option permet de fermer le fichier de données et l'onglet associé.
