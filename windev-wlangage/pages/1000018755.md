# ContentType (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **ContentType** permet de connaître et de modifier le type d'un message. Cette propriété est utilisable sur :

- une variable de type [emailAttache](1000018752.md).
- une variable de type [httpRequête](1000021158.md).
- une variable de type [httpRéponse](1000021165.md).
- une variable de type [restRequête](1000021481.md).
- une variable de type [restRéponse](1000021477.md).
