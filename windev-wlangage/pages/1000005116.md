# NotesSupprimeChamp (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Supprime le champ spécifié du document en cours dans Lotus Notes.
Pour prendre en compte cette suppression, il est nécessaire d'enregistrer le document à l'aide de la fonction [NotesEnregistre](1000005110.md).

## Exemple

```wlangage
// Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", ...
		"mail\julie.nsf", "C:\Users\Julie\AppData\Local\Lotus\Notes\Data\user.id")
...
// Lecture du premier document
NotesDocumentPremier(IDSession)
// Suppression du sujet du document
NotesSupprimeChamp(IDSession, "Subject")
// Enregistrement de la suppression
NotesEnregistre(IDSession)
```

## Syntaxe

```wlangage
<Résultat> = NotesSupprimeChamp(<Identifiant de la session> , <Champ Lotus Notes>)
```

`<Résultat>` *Booléen*
> - Vrai si le champ Lotus Notes a bien été supprimé,
> - Faux dans le cas contraire. En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Identifiant de la session>` *Entier*
> Identifiant de la session à utiliser. Cet identifiant est renvoyé par la fonction [EmailOuvreSessionNotes](3032121.md) ou [NotesOuvreBase](1000005101.md).
`<Champ Lotus Notes>` *Chaîne de caractères*
> Nom du champ Lotus Notes à supprimer. Si ce champ Lotus Notes n'existe pas, une erreur WLangage est générée.
> Pour connaître le nom et le type des champs du document Notes en cours, utilisez la fonction [NotesListeChamp](1000005112.md).
