# HTMLSupprimeFils (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Mac Catalyst)

Supprime un noeud donné dans le noeud courant d'un document HTML.

## Exemple

```wlangage
hDoc est un htmlDocument = "
<html>
	<head/>
	<body>
			<h1/>
			<h2>
			<span>
			<p>Texte</p>
			</span>
			</h2>
	</body>
</html>
"

hNoeud est un htmlNoeud
hNoeudRecherche est un tableau de htmlNoeud

hNoeudRecherche <- HTMLChercheElémentParBalise(hDoc, "body")
hNoeud <- hNoeudRecherche[1]
hNoeudRecherche <- HTMLChercheElémentParBalise(hNoeud, "h1")
hNoeudFils est un htmlNoeud <- hNoeudRecherche[1]
HTMLSupprimeFils(hNoeud, hNoeudFils)
// body : <h2><span><p>Texte</p></span></h2>
```

## Syntaxe

```wlangage
HTMLSupprimeFils(<Noeud source> , <Fils à supprimer>)
```

`<Noeud source>` *Variable de type htmlNoeud*
> Nom de la variable de type [htmlNoeud](1000026081.md) correspondant au noeud de référence pour la suppression du fils.
`<Fils à supprimer>` *Variable de type htmlNoeud*
> Nom de la variable de type [htmlNoeud](1000026081.md) correspondant au noeud fils à supprimer.
