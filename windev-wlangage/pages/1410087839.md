# ScanVersPDF (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Enregistre un document provenant d'un scanneur dans un fichier PDF.

## Exemple

```wlangage
MonScanneur est un Scanneur

// Scanne toutes les pages du chargeur dans un fichier PDF
ScanVersPDF(MonScanneur, "Fichier.PDF")
```

## Syntaxe

```wlangage
<Résultat> = ScanVersPDF(<Scanneur> [, <Nombre pages>] [, <Paramètres PDF>] , <Fichier PDF>)
```

`<Résultat>` *Booléen*
> - Vrai si le document a été enregistré,
> - Faux si le document n'a pas été enregistré. Le message d'erreur correspondant peut être connu avec la fonction [ErreurInfo](3013008.md).
`<Scanneur>` *Variable de type Scanneur*
> Nom de la variable de type [Scanneur](1410087808.md) correspondant au scanneur à utiliser.
`<Nombre pages>` *Entier optionnel*
> - Nombre de pages à scanner,
> - Constante *scanNombrePageToutes* pour scanner toutes les pages du chargeur (valeur par défaut).
`<Paramètres PDF>` *Variable de type pdfParamètre*
> Nom de la variable de type [pdfParamètre](1410087857.md) décrivant les caractéristiques du fichier PDF à créer.
`<Fichier PDF>` *Chaîne de caractères*
> Nom et chemin complet (ou relatif) du fichier (260 caractères maximum). L'extension du fichier n'est pas obligatoire. Un chemin de type UNC peut être utilisé.

## Remarques

Sans chargeur, pour scanner plusieurs pages dans un unique fichier PDF, il faut scanner chaque page dans un fichier PDF puis utiliser la fonction [PDFFusionne](1000019712.md).
