# saasSite (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

Le type **saasSite** permet de définir toutes les caractéristiques avancées d'un site WEBDEV SaaS.
Les caractéristiques de ce site peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
MonSite est un saasSite
MonSite.Nom = "SiteSAV"

SaaSAdminAjouteSite(S)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type saasSite
Les propriétés suivantes peuvent être utilisées pour manipuler un site SaaS :

| **Nom de la propriété** | **Type manipulé** | **Effet** |
| --- | --- | --- |
| Nom | Chaîne de caractères | Nom du site. Ce nom sera utilisé dans l'[Administrateur SaaS](1600000.md) et en programmation pour identifier le site. Il correspond généralement au nom du projet ou au nom de déploiement du site WEBDEV. |
