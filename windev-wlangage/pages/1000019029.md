# NombreExécution (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **NombreExécution** permet de connaître et de modifier le nombre d'exécutions d'une tâche. Cette propriété est utilisable sur :

- une variable de type [hOptimisationPlanifiée](1000018854.md).
- une variable de type [hTâchePlanifiée](1000017448.md).
