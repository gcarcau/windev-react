# <Chrono>.Début (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Démarre un chronomètre afin de mesurer la durée d'un traitement (en millisecondes) et permet de remettre à zéro un chronomètre existant. L'arrêt du chronométrage est effectué :

- soit avec la fonction [<Chrono>.Fin](1000023789.md).
- soit avec la fonction [<Chrono>.Pause](1000023790.md).

Si le chronométrage est arrêté, il pourra être relancé par la fonction [<Chrono>.Reprend](1000023792.md).
La valeur du chronomètre peut être lue à tout moment :

- avec la fonction [ChronoValeur](3027033.md).
- via la propriété **Valeur** de la variable de type [Chrono](1000023560.md).

Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Les variables de type Chrono sont désormais disponibles en code navigateur. La syntaxe manipulant les variables de type Chrono devient également disponible.

## Exemple

```wlangage
MonChrono1 est un Chrono
MonChrono2 est un Chrono
// Démarrage du premier chronomètre
MonChrono1.Début()
// Démarrage du second chronomètre
MonChrono2.Début()
// Arrêt premier chronomètre
DuréeChronoDébut est une Durée = MonChrono1.Fin()
MaFonction()
// Arrêt du second chronomètre
DuréeMaFonction est une Durée = MonChrono2.Fin()
Info("Le traitement MaFonction() a duré " + DuréeMaFonction, ...
	"Le traitement complet a duré " + DuréeChronoDébut)
```

## Syntaxe

#### Chronométrer avec une variable de type Chrono

```wlangage
<Chronomètre>.Début()
```

`<Chronomètre>` *Variable de type Chrono*
> Nom de la variable de type [Chrono](1000023560.md) correspondant au chronomètre à utiliser.

## Remarques

### Erreur
Si la fonction **<Chrono>.Début** n'a pas été appelée avant les fonctions [ChronoValeur](3027033.md) et [<Chrono>.Fin](1000023789.md), une erreur WLangage est affichée (erreur de type "le chronomètre n'est pas démarré").

### Threads et tâches parallèles
Chaque thread (et chaque tâche parallèle) possède ses propres chronomètres.
Deux threads distincts (ou deux tâches parallèles distinctes) peuvent réaliser des chronométrages séparés en utilisant un même numéro de chronomètre.

L'erreur WLangage "le chronomètre n'est pas démarré" sera affichée uniquement si la fonction **<Chrono>.Début** n'est pas appelée dans le même thread (ou la même tâche parallèle) que les fonctions [ChronoValeur](3027033.md) et [<Chrono>.Fin](1000023789.md).
