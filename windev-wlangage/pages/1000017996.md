# DateDébut (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Mac Catalyst)

La propriété **DateDébut** permet de connaître et de modifier la date de début d'une période. Cette propriété est utilisable sur :

- les champs Calendrier, Agenda et Planning. Pour plus de détails, consultez [Propriété DateDébut](1000017426.md).
- une variable de type [saasAbonnement](1000019088.md).
- une variable de type [gglEvénement](1000017440.md).
- une variable de type [RendezVous](1000019244.md).
- une variable de type [TâcheGantt](1000020881.md).
- une variable de type [hOpérationServeur](1000022471.md).
- Nouveauté 2025
  une variable de type [hHistoriquePlanification](1410090764.md).
- Nouveauté SaaS
  une variable de type [hHistoriqueRéindexation](1410091059.md).
