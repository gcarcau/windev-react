# Fonctions de gestion des matrices

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Les fonctions de gestion des matrices sont les suivantes :

| [MatAdditionne](3050049.md) | Additionne deux matrices de mêmes dimensions (même nombre de lignes et même nombre de colonnes). |
| --- | --- |
| [MatCompresse](3050043.md) | Compresse la place mémoire occupée par une matrice. |
| [MatCopie](3050048.md) | Crée la copie d'une matrice. |
| [MatCrée](3050058.md) | Crée une matrice de 0 ligne et 0 colonne. |
| [MatDéterminant](3050045.md) | Calcule le déterminant d'une matrice carrée (nombre de lignes égal au nombre de colonnes). |
| [MatEcrit](3050077.md) | Écrit un élément dans une matrice. |
| [MatErreur](3050044.md) | Identifie le type de la dernière erreur due à une fonction Matxxx ([fonctions de gestion des matrices](3050051.md)). |
| [MatExiste](3050076.md) | Teste l'existence d'une matrice en mémoire. |
| [MatInverse](3050075.md) | Inverse une matrice carrée. |
| [MatLit](3050074.md) | Lit la valeur d'un élément d'une matrice. |
| [MatLitColonne](3050070.md) | Lit la valeur de tous les éléments d'une colonne d'une matrice. |
| [MatLitLigne](3050032.md) | Lit la valeur de tous les éléments d'une ligne d'une matrice. |
| [MatMultiplie](3050072.md) | Multiplie deux matrices. |
| [MatNbColonne](3050073.md) | Renvoie le nombre de colonnes d'une matrice. |
| [MatNbLigne](3050060.md) | Renvoie le nombre de lignes d'une matrice. |
| [MatRéelAdditionne](3050059.md) | Additionne une valeur à chaque élément d'une matrice. |
| [MatRéelMultiplie](3050040.md) | Multiplie chaque élément d'une matrice par une valeur. |
| [MatRemplit](3050057.md) | Initialise tous les éléments d'une matrice d'une taille donnée. |
| [MatSupprime](3050031.md) | Supprime une matrice existante. |
| [MatTranspose](3050001.md) | Calcule la transposée d'une matrice. |
