# JSONVersChaîne (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Convertit le contenu d'une variable de type JSON en une chaîne au format JSON.

## Exemple

```wlangage
Personne est un JSON
Personne.Nom = "DUPONT"
Personne.Prenom = "Michel"
// Affiche : { "Nom":"DUPONT", "Prenom":"Michel" }
Trace(JSONVersChaîne(Personne))
```

## Syntaxe

```wlangage
<Résultat> = JSONVersChaîne(<Variable JSON> [, <Options>])
```

`<Résultat>` *Chaîne de caractères*
> Chaîne JSON résultant de la conversion de la variable de type JSON. Cette chaîne est au format UTF8.
> En cas d'échec, la variable [ErreurDétectée](3087001.md) vaut Vrai et la fonction [ErreurInfo](3013008.md) permet de connaître le détail de l'erreur.
`<Variable JSON>` *Variable de type JSON*
> Nom de la variable de type [JSON](1000023611.md) à convertir en chaîne au format JSON.
`<Options>` *Entier optionnel*
> Option de mise en forme de la chaîne au format JSON :
>
> | *psdMinifié* | Génère une chaîne au format JSON minifiée, sans aucun retour à la ligne ou caractère d'espacement. |
> | --- | --- |
> | *psdMiseEnForme* | Génère une chaîne au format JSON avec des retours à la ligne et une indentation. |
>
>
>
> > _(WEBDEV - Code Navigateur)_ Ce paramètre n'est pas disponible.

**Composante : wd300vm.dll**
