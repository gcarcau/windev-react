# Fonctions de gestion de l'album de photos

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions de gestion de l'album de photos sont les suivantes :

| [AlbumSauve](1000020191.md) | Sauve une image, une photo ou une vidéo dans l'album de photos de l'appareil mobile. |
| --- | --- |
| [AlbumSélecteur](1000020186.md) | Récupère une photo, une image ou une vidéo stockée dans l'album de photos de l'appareil mobile. |
| [PhotoLanceAppli](1000021601.md) | Lance l'application caméra native de l'appareil afin de prendre une photo. |
