# grPIImage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Définit l'image utilisée pour illustrer les données d'un graphe de type "Pourcentage imagé".
**Remarque** : Tous les formats d'image sont supportés, mais il est conseillé d'utiliser un format vectoriel.

## Exemple

```wlangage
ImageGraphe est une Image = "rocket.png"
grSupprimeSérie(GRF_Pourcentage, 1)
nSomme est un entier
POUR TOUTE LIGNE DE TABLE_Série
	nValeur est un entier = COL_Données
	nSomme += nValeur
	grAjouteDonnée(GRF_Pourcentage, 1, nValeur)
FIN
grPIValeurMaximale(GRF_Pourcentage, nSomme)
grPIImage(GRF_Pourcentage, ImageGraphe)
grDessine(GRF_Pourcentage)
```

## Syntaxe

```wlangage
grPIImage(<Graphe> , <Image> [, <Opacité>])
```

`<Graphe>` *Nom de champ ou chaîne de caractères*
> Nom du graphe à manipuler. Ce nom correspond :
>
> - soit au nom du graphe défini par programmation avec la fonction [grCrée](3042005.md).
> - soit au nom du champ Graphe présent dans l'éditeur de fenêtres ou de pages.
>
>
> > _(Android)_ Seuls les champs Graphe sont disponibles.
`<Image>` *Chaîne de caractères ou variable de type Image*
> Image de la catégorie. Cette image peut correspondre à :
>
> - une rubrique mémo,
> - le chemin d'un fichier image (ou juste son nom si l'image est présente dans le répertoire de l'exécutable),
> - un nom du champ Image contenant une image.
> - une variable de type [Image](1000019650.md).
`<Opacité>` *Entier optionnel*
> Opacité de l'image qui n'est pas comprise dans les pourcentages. Ce paramètre est compris entre 0 (image transparente, par défaut) et 100 (image visible). Ce paramètre est pris en compte uniquement pour la dernière partie du graphe, si la somme des valeurs utilisées dans le graphe ne correspond pas à 100%.

**Classification Métier / UI : Code UI**

**Composante : wd300grf.dll**
