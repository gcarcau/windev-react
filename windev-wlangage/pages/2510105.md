# Multiligne (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Dans une fenêtre ou une page, la propriété **Multiligne** permet :

- de savoir si un champ de saisie est multiligne ou de rendre un champ de saisie multiligne.
- de savoir si une colonne de table est multiligne ou de rendre ou non une colonne de table multiligne. Pour que le changement soit pris en compte, il est nécessaire de ré-afficher le champ Table (fonction [TableAffiche](3074003.md) par exemple) ou de remplir à nouveau le champ Table.

Dans un état, la propriété **Multiligne** permet de :

- savoir si un champ est multiligne
- modifier l'option "Multi-ligne" d'un champ.

**Remarques** :

- L'option "Multi-ligne" permet d'afficher le contenu d'un champ sur plusieurs lignes et de ne pas tronquer le contenu d'un champ.
- Dans les états, le multiligne est une option des champs Libellé, Rubrique, Calculé et Lien. Cette option est située dans l'onglet "Détail" de la description du champ.

## Exemple

```wlangage
// Le champ "SAI_Adresse" est-il multiligne ?
ResMultiligne = SAI_Adresse.Multiligne
```

## Syntaxe

#### Savoir si un champ est multiligne

```wlangage
<Résultat> = <Champ manipulé>.Multiligne
```

`<Résultat>` *Booléen*
> - Vrai si le champ spécifié est multiligne,
> - Faux dans le cas contraire.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.

#### Modifier l'option "Multiligne" d'un champ

```wlangage
<Champ manipulé>.Multiligne = <Est multiligne ?>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.
`<Est multiligne ?>` *Booléen*
> - Vrai si le champ spécifié doit être multiligne,
> - Faux si le champ spécifié ne doit pas être multiligne.

## Remarques

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS)_ Champs multilignes dans un étatSi un angle d'orientation est appliqué à un champ multiligne dans un état, les retours chariot automatiques ne sont pas pris en compte. Seuls les retours manuels à la ligne sont pris en compte.

### Limites

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS)_ Dans un état, la propriété Multiligne s'applique uniquement aux :champs Libellé,champs Rubrique,champs Calculé,champs Lien.

> _(WINDEV, WINDEV Mobile, Java)_ Dans une fenêtre, la propriété Multiligne s'applique uniquement aux :champs de saisie.colonnes dans les champs Table. La propriété Multiligne s'applique uniquement aux champs de saisie.
