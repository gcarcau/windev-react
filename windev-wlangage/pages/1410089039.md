# <Variable FichierDisque>.Cherche (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Cherche une chaîne de caractères ou un buffer dans un fichier ouvert avec la fonction [<Variable FichierDisque>.Ouvre](1410090197.md).

## Exemple

```wlangage
MonBuffer est un Buffer
MonFichierHtml est un FichierDisque
nPosition est un entier

MonBuffer = fChargeBuffer("C:\tmp\Page1.html")
MonFichierHtml.Ouvre("C:\test\MonFichier.html")
nPosition = MonFichierHtml.Cherche(MonBuffer)

SI nPosition <> -1 ALORS
	Info("Le contenu de Page1 a été trouvé dans MonFichierHtml à la position " + nPosition)
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Fichier manipulé>.Cherche(<Elément recherché> [, <Position de départ>])
```

`<Résultat>` *Entier*
> - Position de l'élément recherché dans le fichier.
> - -1 si aucun élément ne correspond à la recherche.
`<Fichier manipulé>` *Variable de type FichierDisque*
> Nom de la variable de type [FichierDisque](1410088883.md) initialisée avec la fonction [<Variable FichierDisque>.Ouvre](1410090197.md) ou [<Variable FichierDisque>.Crée](1410090211.md).
`<Elément recherché>` *Buffer ou chaîne de caractères*
> Buffer ou chaîne de caractères dont le contenu doit être recherché dans le fichier texte.
`<Position de départ>` *Entier optionnel*
> Position de départ de la recherche. Par défaut, la recherche est effectuée à partir du début du fichier.
