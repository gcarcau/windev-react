# Procédure WLangage appelée par la fonction CapteurDétecteChangementAccélération

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Procédure (également appelée "Callback") appelée par la fonction [CapteurDétecteChangementAccélération](1000019362.md) lors de la détection de l'accélération de l'appareil sur l'un de ses axes. Cette procédure peut être une procédure locale, globale ou interne.

## Exemple

```wlangage
// Détection des changements d'accélération
CapteurDétecteChangementAccélération("ProcDétectionAccélération", cptVertical)
```

```wlangage
// Procédure appelée par la fonction CapteurDétecteChangementAccélération
PROCÉDURE ProcDétectionAccélération(AccélérationVerticale est un réel, ...
	AccélérationHorizontale est un réel, AccélérationLatérale est un réel)
ToastAffiche(ChaîneConstruit("Accélération verticale détectée (%1 m/s²)", AccélérationVerticale))

// Arrêt de la détection des changements d'accélération
CapteurDétecteChangementAccélération("", cptVertical)
```

## Syntaxe

```wlangage
CapteurDétecteChangementAccélération_Callback(<Vertical> , <Longitudinal> , <Latéral>)
```

`<Vertical>` *Réel*
> Mesure de l'accélération de l'appareil sur l'axe vertical (Z) en m/s².
`<Longitudinal>` *Réel*
> Mesure de l'accélération de l'appareil sur l'axe longitudinal (Y) en m/s².
`<Latéral>` *Réel*
> Mesure de l'accélération de l'appareil sur l'axe horizontal (X) en m/s².
