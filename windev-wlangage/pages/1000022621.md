# DocFerme (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Ferme le fichier docx et libère le document de type Traitement de texte.

## Exemple

```wlangage
DocFerme(TT_MonDocument)
```

## Syntaxe

```wlangage
DocFerme(<Document>)
```

`<Document>` *Variable de type Document ou nom de champ*
> Document à manipuler. Ce document correspond :
>
> - au nom d'un champ Traitement de texte.
> - à une variable de type [Document](1000022461.md).
>
> Le fichier physique associé au champ ou à la variable (s'il existe) est fermé. Les modifications réalisées dans le fichier ne sont pas sauvées avant sa fermeture (utilisez la fonction [DocSauve](1000022387.md) si nécessaire).

**Composante : wd300mdl.dll**
