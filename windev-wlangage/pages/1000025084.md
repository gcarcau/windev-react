# <Source>.VueVersFichier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Enregistre les modifications réalisées dans une vue HFSQL (grâce aux fonctions [<Source>.Modifie](1000025038.md), [<Source>.Supprime](1000025071.md) ou [<Source>.Raye](1000025051.md)) dans le fichier de données correspondant.
**Remarque** : Cette opération ne peut être effectuée que si la vue a été créée avec la constante *hVueBlocage* (c'est-à-dire que les enregistrements importés dans la vue ont été bloqués dans le fichier de données). Après l'exécution de la fonction **<Source>.VueVersFichier**, les enregistrements sont débloqués dans le fichier source de la vue.

## Exemple

```wlangage
// Enregistre les modification de la vue Client34
// dans le fichier Client
Client34.VueVersFichier()
```

> _(WINDEV, WEBDEV - Code Serveur, Windows, HFSQL Classic)_ // Test du compte-rendu de la fonction HVueVersFichier
SI Client13.VueVersFichier() <> Vrai ALORS
 Erreur("Impossible d'enregistrer les modifications effectuées sur la vue")
FIN

## Syntaxe

```wlangage
<Résultat> = <Source>.VueVersFichier()
```

`<Résultat>` *Booléen*
> - Vrai si la vue a été transférée dans le fichier de données,
> - Faux dans le cas contraire. La fonction [HErreur](3044088.md) permet d'obtenir plus d'informations sur le problème rencontré.
`<Source>` *Type de la Source*
> Nom de la vue manipulée.

## Remarques

En cas d'erreur pendant la mise à jour du fichier de données, pour connaître les enregistrements qui ont posé problème et les problèmes associés, utilisez la fonction [HErreur](3044088.md). Il suffit de parcourir la vue à nouveau et de tester la fonction [HErreur](3044088.md) sur chaque enregistrement de la vue.
