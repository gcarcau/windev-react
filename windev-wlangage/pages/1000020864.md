# SMSLanceAppli (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Lance l'application native d'envoi de SMS de l'appareil (Android ou iPhone/iPad). Le contenu et les destinataires du SMS sont initialisés à partir des informations renseignées dans la [structure SMS](3068003.md) du WLangage.
Attention : Le SMS n'est pas envoyé. Seuls les champs de l'application d'envoi de SMS sont initialisés.

## Exemple

```wlangage
SMS.Numéro = "0610203040"
SMS.Message = "J'envoie des SMS avec WINDEV Mobile !"
SMSLanceAppli()
```

## Syntaxe

```wlangage
SMSLanceAppli()
```

## Remarques

### Eléments de la structure SMS pris en compte

- Seules les variables SMS.Numéro et SMS.Message sont prises en compte.
- Seules les variables suivantes sont prises en compte :
  - SMS.Numéro,
  - SMS.Message,
  - SMS.PièceJointe.
  - SMS.TypeNuméro et SMS.PréfixeNational sont prises en compte.

Pour plus de détails, consultez la [structure SMS](3068003.md) du WLangage.

### Cas d'erreurs
Si aucune application native d'envoi de SMS n'a été trouvée sur l'appareil, la variable [ErreurDétectée](3087001.md) vaudra Vrai après l'appel de la fonction. Pour connaître le détail de l'erreur, utilisez la fonction [ErreurInfo](3013008.md).

> _(Android, Widget Android)_ Application en arrière-plan : Spécificité à partir de Android 10A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. La fonction SMSLanceAppli peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. Conseils : Il est possible de savoir si l'application est en arrière-plan grâce à la fonction EnModeArrièrePlan. Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type Notification). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété ActiveApplication est à Vrai. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété ActionClic.Pour plus de détails, consultez Android 10 : Comportement des applications en arrière-plan.
