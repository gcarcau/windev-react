# mongoRésultat (Type de variable)

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows, Linux)

Le type **mongoRésultat** permet de connaître le résultat lors d'une recherche dans une base de type MongoDB.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
sFiltre est une chaîne
sFiltre = "{ ""name"": ""France"" }"
soit MaRecherche = MongoCherche(CollecMDB, sFiltre)
// Lecture du résultat
POUR TOUT item DE MaRecherche
	Trace(VariantVersJSON(item))
FIN
```

## Remarques

### Fonctionnement

- Le type de variable **mongoRésultat** peut être parcouru grâce à l'instruction POUR TOUT.
- Chaque élément parcouru est de type **Variant**.
- Chaque élément représente un document MongoDB.

### Fonctions manipulant le type mongoRésultat
Les fonctions manipulant une variable de type mongoRésultat sont les suivantes :

| [MongoCherche](1000022433.md) | Cherche des documents dans une collection MongoDB. |
| --- | --- |
| [MongoExécuteCommande](1000022435.md) | Exécute une commande générique sur une base MongoDB ou sur une collection MongoDB. |
| [MongoPipelineAgrégation](1000025267.md) | Permet de récupérer des documents issus de la transformation et de l'agrégation en plusieurs étapes. |
