# <Source>.ListeClésSpatiales (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Renvoie la liste des clés spatiales d'un fichier de données (d'une requête ou d'une vue) reconnues par le moteur HFSQL.

## Exemple

```wlangage
// Récupérer les clés spatiales d'un fichier de données présent dans l'analyse en cours
ListeClésSpatiales est une chaîne
ListeCléSpatiales = Communes.ListeClésSpatiales()
// Ajoute la liste des clés spatiales dans COMBO_Combo1
COMBO_Combo1.Ajoute(ListeClésSpatiales)
```

## Syntaxe

```wlangage
<Résultat> = <Source>.ListeClésSpatiales([<Chemin du WDD> [, <Mot de passe du WDD>]])
```

`<Résultat>` *Chaîne de caractères*
> Liste des clés spatiales présentes dans le fichier de données spécifié. Les noms des rubriques correspondant à des rubriques spatiales sont séparés par RC (Retour chariot).
`<Source>` *Type correspondant à la source spécifiée*
> Nom du fichier de données (de la requête ou de la vue) dont les clés spatiales doivent être listées.
> Si un nom de requête est spécifié, cette requête doit être en cours d'exécution (fonctions [<Source>.ExécuteRequête](1000024944.md) ou [<Source>.ExécuteRequêteSQL](1000024948.md)) pour que la fonction **<Source>.ListeClésSpatiales** fonctionne. Dans le cas contraire, une erreur du WLangage est générée.
`<Chemin du WDD>` *Chaîne de caractères optionnelle*
> Chemin complet de l'analyse (c'est-à-dire du fichier .WDD) dans laquelle le fichier de données est décrit.
> Si ce paramètre n'est pas précisé ou est égal à une chaîne vide (""), le fichier de données est recherché dans l'analyse en cours.
`<Mot de passe du WDD>` *Chaîne de caractères optionnelle ou Chaîne secrète*
> Mot de passe défini pour l'analyse.
> Si aucun mot de passe n'est défini, ce paramètre doit être égal à une chaîne vide ("").
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).
