# ErreurRestaureParamètre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Rétablit le traitement d'erreur d'un traitement. Ce traitement d'erreur a été modifié dans le traitement en cours par un appel à la fonction [ErreurChangeParamètre](3034009.md).

## Syntaxe

```wlangage
ErreurRestaureParamètre()
```

## Remarques

Si le nombre d'appels à la fonction **ErreurRestaureParamètre** est supérieur au nombre d'appels à la fonction [ErreurChangeParamètre](3034009.md), les appels en trop ne seront pas pris en compte.

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
