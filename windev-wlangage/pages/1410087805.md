# Procédure WLangage appelée par la fonction OuvreAsynchrone

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Procédure WLangage (appelée "callback") appelée par la fonction [OuvreAsynchrone](1410087804.md) après la fermeture de la fenêtre. Cette procédure peut être une procédure locale, globale ou interne.

## Exemple

```wlangage
// Ouverture asynchrone sans passage de paramètres
OuvreAsynchrone(FEN_FenChoixDate, (), onFermeChoixDate)
PROCÉDURE INTERNE onFermeChoixDate(DateChoisie)
	SAI_DATE = DateChoisie
FIN
```

```wlangage
// Ouverture asynchrone sans passage de paramètres et lambda
OuvreAsynchrone(FEN_FenChoixDate, (), (DateChoisie) => {SAI_DATE = DateChoisie})
```

```wlangage
// Ouverture asynchrone avec 2 paramètres
OuvreAsynchrone(FEN_FenChoixDate, (DateSys(), "Sélectionner une date"), onFermeChoixDate)
PROCÉDURE INTERNE onFermeChoixDate(DateChoisie)
	SAI_DATE = DateChoisie
FIN
```

Nouveauté Abonnement

```wlangage
// Définition des options de la fenêtre pour son ouverture
Ma_fen_Date est une Fenêtre FEN_FenChoixDate
Ma_fen_Date.OptionsOuverture.X = 50
Ma_fen_Date.OptionsOuverture.Y = 100
// Ouverture de la fenêtre
OuvreAsynchrone(Ma_fen_Date, onFermeChoixDate)
PROCÉDURE INTERNE onFermeChoixDate(DateChoisie)
	SAI_DATE = DateChoisie
FIN
```

## Syntaxe

```wlangage
OuvreAsynchrone_Callback(<Valeur de retour>)
```

`<Valeur de retour>` *Type de la valeur de retour*
> Correspond à la valeur qui sera renvoyée par la fenêtre. Cette valeur peut être renvoyée par exemple :
>
> - via l'instruction [RENVOYER](1510007.md) dans le code de fermeture de la fenêtre,
> - via la fonction [Ferme](3038018.md) (syntaxe Ferme("", Valeur)),
> - via la propriété [ValeurRenvoyée](2510134.md) de la fenêtre.
