# Constantes de gestion des champs Agenda

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Afficher uniquement les constantes utilisées par les syntaxes préfixées

Afficher uniquement les constantes utilisées par les syntaxes non préfixées

Les constantes de gestion des champs Agenda sont les suivantes :

| Constante | Description | Utilisée par les fonctions ou les types de variables |
| --- | --- | --- |
| **agDateDébut** | Type de date recherchée :   - Première date affichée dans le champ Agenda. - Première date de la plage sélectionnée dans le champ Agenda. | - [AgendaPosition](1000018889.md) - [AgendaPlageSélectionnée](1000022399.md) |
| **agDateFin** | - Type de date recherchée : Dernière date affichée dans le champ Agenda. - Dernière date de la plage sélectionnée dans le champ Agenda. | - [AgendaPosition](1000018889.md) - [AgendaPlageSélectionnée](1000022399.md) |
| **agDateHeure1erVisible** | Type de date recherchée : Première date et heure affichée dans le champ Agenda ou dans le champ Planning. | - [AgendaPosition](1000018889.md) - [PlanningPositionDateHeure](1000019998.md) |
| **agiDateHeure** | Type d'information demandée : Date et heure de du rendez-vous correspondant aux coordonnées fournies. | [AgendaInfoXY](1000018887.md) |
| **agiOrigineEcran** | Utiliser des coordonnées relatives à l'écran. | [AgendaInfoXY](1000018887.md) |
| **agiRendezVous** | Type d'information demandée : Indice du rendez-vous correspondant aux coordonnées fournies. | [AgendaInfoXY](1000018887.md) |
| **agMoisEnCours** | Type de date recherchée : Premier jour du mois affiché dans le champ Agenda. | [AgendaPosition](1000018889.md) |
| **agRdvSélectionné** | Type de rendez-vous recherché : Rendez-vous actuellement sélectionné dans le champ Agenda. | [AgendaListeRendezVous](1000018880.md) |
| **agRdvSurvolé** | Type de rendez-vous recherché : Rendez-vous survolé par la souris dans le champ Agenda. | [AgendaListeRendezVous](1000018880.md) |
| **agzJour** | Mode d'affichage de l'agenda : Agenda affiché sur une journée. | [AgendaChangeMode](1000019497.md), [AgendaMode](1000019545.md) |
| **agzMois** | Mode d'affichage de l'agenda : Agenda affiché sur un mois. | [AgendaChangeMode](1000019497.md), [AgendaMode](1000019545.md) |
| **agzNbJourPersonnalisé** | Mode d'affichage de l'agenda : Agenda affiché sur un nombre de jours personnalisé. | [AgendaChangeMode](1000019497.md), [AgendaMode](1000019545.md) |
| **agzSemaine** | Mode d'affichage de l'agenda : L'agenda affiche une semaine complète (ou partielle). | [AgendaChangeMode](1000019497.md), [AgendaMode](1000019545.md) |
| **agzSemaineSur5** | Mode d'affichage de l'agenda : L'agenda affiche les cinq premiers jours de la semaine. | [AgendaChangeMode](1000019497.md), [AgendaMode](1000019545.md) |
