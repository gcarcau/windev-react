# <Variable zipArchive>.FinAjoutFichier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Termine une série d'ajouts optimisés de fichiers dans une archive.
Nouveauté Abonnement
Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
// Début des ajouts optimisés de fichiers
MonArchive.DébutAjoutFichier()
// Ajout des fichiers dans l'archive
POUR TOUT CheminFichier DE tabListeFichier
	MonArchive.AjouteFichier(CheminFichier)
FIN
// Fin ajouts optimisés de fichiers
MonArchive.FinAjoutFichier()
```

## Syntaxe

```wlangage
<Résultat> = <Archive>.FinAjoutFichier()
```

`<Résultat>` *Entier*
> - 0 si la déclaration de la fin d'ajout de fichiers a été effectuée,
> - un code d'erreur (valeur supérieure à 0) dans le cas contraire. Pour plus de détails sur ces codes d'erreur, consultez les remarques.
`<Archive>` *Variable de type zipArchive*
> Nom de la variable de type [zipArchive](1000018679.md) à manipuler.

## Remarques

### Dans quels cas utiliser l'ajout optimisé de fichiers dans une archive
Pour les archives de type ZIP, WDZ et 7Z, certaines opérations permettant d'obtenir une archive valide sont effectuées lors de chaque ajout. Ces opérations peuvent influer sur le temps de création d'une archive.
Ainsi, une succession d'ajouts de fichiers via la fonction [<Variable zipArchive>.AjouteFichier](1000019050.md) est plus chronophage que l'ajout de ces mêmes fichiers via la fonction [<Variable zipArchive>.AjouteListeFichier](1000019159.md). En effet, avec la fonction [<Variable zipArchive>.AjouteListeFichier](1000019159.md), les opérations de vérification ne sont effectuées qu'une seule fois.

Pour obtenir un comportement similaire en utilisant la fonction [<Variable zipArchive>.AjouteFichier](1000019050.md), il est nécessaire de réaliser les ajouts entre les fonctions [<Variable zipArchive>.DébutAjoutFichier](1410091280.md) et **<Variable zipArchive>.FinAjoutFichier**.

Remarque : Cette fonction n'est pas utilisable sur les archives de type RAR et n'est utile que pour les archives de type ZIP, WDZ et 7Z.

### Comment utiliser les ajouts optimisés ?
Pour réaliser des ajouts optimisés :

1. Appelez la fonction [<Variable zipArchive>.DébutAjoutFichier](1410091280.md). L'archive est en attente de l'ajout des fichiers.
2. Utilisez la fonction [<Variable zipArchive>.AjouteFichier](1000019050.md) pour ajouter les différents fichiers voulus. Toutes les caractéristiques de cette fonction restent valables.
3. Terminez l'ajout des fichiers avec la fonction **<Variable zipArchive>.FinAjoutFichier**.

Remarques :

- Tout appel à une fonction autre que [<Variable zipArchive>.AjouteFichier](1000019050.md) sur l'archive entre un appel aux fonctions [<Variable zipArchive>.DébutAjoutFichier](1410091280.md) et **<Variable zipArchive>.FinAjoutFichier** provoquera une erreur fatale.
- Il est obligatoire d'utiliser la fonction **<Variable zipArchive>.FinAjoutFichier** après la fonction [<Variable zipArchive>.AjouteFichier](1000019050.md) pour obtenir une archive valide.

### Codes d'erreur
Les codes d'erreur retournés sont les suivants :

- 1 : Le chemin passé en paramètre n'existe pas.
- 3 : L'archive est corrompue.
