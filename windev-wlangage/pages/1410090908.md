# Fonctions Bouton segmenté (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions permettant de gérer les champs Bouton segmenté (syntaxe préfixée) sont les suivantes :

| Nouveauté 2025 [<Bouton segmenté>.Ajoute](1410090903.md) | Ajoute une nouvelle option (c'est-à-dire un nouveau bouton) dans un champ Bouton segmenté. |
| --- | --- |
| Nouveauté 2025 [<Bouton segmenté>.Insère](1410090904.md) | Insère une nouvelle option dans un champ Bouton segmenté. |
| Nouveauté 2025 [<Bouton segmenté>.Supprime](1410090905.md) | Supprime une option dans un champ Bouton segmenté. |
| Nouveauté 2025 [<Bouton segmenté>.SupprimeTout](1410090906.md) | Supprime toutes les options d'un champ Bouton segmenté. |
