# ZoomAuDoigt (Propriété)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **ZoomAuDoigt** permet de :

- savoir si un champ Image ou Caméra autorise le zoom au doigt.
- autoriser ou non le zoom au doigt dans un champ Image ou Caméra.

> _(Android, iPhone/iPad)_ Pour utiliser cette propriété sur un champ Caméra, le champ doit avoir été créé avec la version 27 ou avoir l'option suivante décochée : Mode compatible 26 Utiliser VidéoParamètre( ) pour configurer le champ (onglet "Général" du champ Caméra).

## Exemple

```wlangage
// En mode dessin, pas de zoom au doigt
SI bDessin = Vrai ALORS
	IMG_Image1.ZoomAuDoigt = Faux
SINON
	IMG_Image1.ZoomAuDoigt = Vrai
FIN
```

## Syntaxe

#### Savoir si un champ Image ou le champ Caméra autorise le zoom au doigt

```wlangage
<Résultat> = <Champ manipulé>.ZoomAuDoigt
```

`<Résultat>` *Booléen*
> - Vrai si le zoom au doigt est actif,
> - Faux dans le cas contraire.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler :
>
> - Champ Image,
> - Champ Caméra.

#### Autoriser ou non le zoom au doigt dans un champ Image ou le champ Caméra

```wlangage
<Champ manipulé>.ZoomAuDoigt = <Autorisation>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler :
>
> - Champ Image,
> - Champ Caméra.
`<Autorisation>` *Booléen*
> - Vrai pour activer le zoom au doigt,
> - Faux dans le cas contraire.

## Remarques

### Utilisation dans un champ Image

- Cette propriété permet notamment d'interrompre temporairement le zoom au doigt pour pouvoir dessiner dans un champ Image. De la même façon, il est possible d'interrompre le scroll au doigt avec la propriété [ScrollAuDoigt](1000019284.md).
- Attention : Pour un champ Image, la fonctionnalité de Scroll et zoom doit avoir été activée dans la fenêtre de description du champ Image (option "Scroll et zoom automatiques" dans l'onglet "Détail" de la fenêtre de description du champ). [image: Option ]
- L'appel à la fonction [dDébutDessin](3029009.md) désactive automatiquement les fonctionnalités de zoom et scroll au doigt.

> _(Android, iPhone/iPad)_ Utilisation dans un champ CaméraLorsque le zoom au doigt est activé, l'utilisateur peut zoomer/dézoomer en pinçant dans le champ Caméra. Cette propriété correspond à l'option "Autoriser le zoom aux doigts" disponible dans l'onglet "Général" de la fenêtre de description du champ. L'action de zoom par l'utilisateur entraine l'exécution de l'événement "Changement de zoom". Cet événement permet d'obtenir la valeur du nouveau zoom. Pour gérer ce paramètre, il est nécessaire de déclarer une procédure directement dans l'événement "Changement de zoom".Cette procédure doit être déclarée avec la syntaxe suivante :

PROCEDURE <Nom de la procédure>(<Zoom>)

où <Zoom> correspond à la nouvelle valeur du zoom en pourcentage.
