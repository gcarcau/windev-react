# <Variable WDPic>.DessineRectangle (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Dessine un rectangle dans une variable de type [WDPic](1000023503.md) (sur le calque d'arrière-plan).

## Exemple

```wlangage
MonImageWDPic est un WDPic = "Test.bmp"

// Dessin d'un rectangle dont le fond est jaune clair
// et le bord bleu clair
MonImageWDPic.DessineRectangle(10, 10, 50, 50, JauneClair, BleuClair)

IMG_MonDessin = MonImageWDPic
```

## Syntaxe

#### Dessiner un rectangle en spécifiant les coordonnées du rectangle

```wlangage
<Image WDPic>.DessineRectangle(<X1> , <Y1> , <X2> , <Y2> [, <Fond> [, <Trait>]])
```

`<Image WDPic>` *Variable de type WDPic*
> Nom de la variable de type [WDPic](1000023503.md) à manipuler. Seul le calque d'arrière-plan sera manipulé.
`<X1>` *Entier*
> Abscisse en pixels du coin haut gauche du rectangle.
`<Y1>` *Entier*
> Ordonnée en pixels du coin haut gauche du rectangle.
`<X2>` *Entier*
> Abscisse en pixels du coin bas droit du rectangle.
`<Y2>` *Entier*
> Ordonnée en pixels du coin bas droit du rectangle.
`<Fond>` *Entier, constante ou variable de type Fond (optionnel)*
> - Couleur du fond du rectangle. Cette couleur peut être :
>   - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
>   - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
>   - [une couleur prédéfinie du WLangage](3010002.md),
>   - une variable de type [Couleur](1000019661.md),
>   - transparente si ce paramètre n'est pas précisé et si la fonction [<Variable WDPic>.Fond](1000024481.md) n'a pas été utilisée auparavant.
> - Caractéristiques du fond :
>   - variable de type [Fond](1000022038.md). Dans ce cas, le dégradé défini dans la variable n'est pas pris en compte.
>   - caractéristiques spécifiées dans le dernier appel à la fonction [<Variable WDPic>.Fond](1000024481.md) si ce paramètre n'est pas précisé.
>
>
> Pour utiliser une couleur de fond dégradée, utilisez la fonction [<Variable WDPic>.DessineRectangleDégradé](1000024567.md).
`<Trait>` *Entier, constante ou variable de type Cadre (optionnel)*
> - Couleur du trait du rectangle. Cette couleur peut être :
>   - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
>   - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
>   - [une couleur prédéfinie du WLangage](3010002.md),
>   - une variable de type [Couleur](1000019661.md),
>   - identique à la couleur utilisée pour le fond si ce paramètre n'est pas précisé et si la fonction [<Variable WDPic>.Stylo](1000024636.md) n'a pas été utilisée.
> - Caractéristiques du trait :
>   - variable de type [Cadre](15140100.md). Dans ce cas, seules les propriétés suivantes sont prises en compte :
>     - Couleur : si la propriété correspond à la constante *CouleurIndéfinie*, la couleur définie lors du dernier appel à la fonction [<Variable WDPic>.Stylo](1000024636.md) est utilisée. Si cette fonction n'a pas été utilisée, la couleur de fond du rectangle est utilisée.
>     - Epaisseur : si la propriété correspond à la constante *EpaisseurIndéfinie*, l'épaisseur définie lors du dernier appel à la fonction [<Variable WDPic>.Stylo](1000024636.md) est utilisée. Si cette fonction n'a pas été utilisée, l'épaisseur vaut 1.
>     - Trait : si la propriété correspond à *TraitIndéfini*, le type de trait défini lors du dernier appel à la fonction [<Variable WDPic>.Stylo](1000024636.md) est utilisé. Si cette fonction n'a pas été utilisée, le trait est un trait continu.
>   - caractéristiques précisées dans le dernier appel à la fonction [<Variable WDPic>.Stylo](1000024636.md) si ce paramètre n'est pas précisé.
