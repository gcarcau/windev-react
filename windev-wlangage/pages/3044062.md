# HLibèrePosition (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Supprime une position sauvegardée par la fonction [HSauvePosition](3044136.md). Permet de libérer la mémoire allouée à la gestion des positions.

## Exemple

```wlangage
// Sauvegarde de la position
nPos est un entier = HSauvePosition(Client, Nom)
...
// Traitements
...
// Suppression de la position devenue inutile
HLibèrePosition(nPos)
```

## Syntaxe

```wlangage
<Résultat> = HLibèrePosition(<Position>)
```

`<Résultat>` *Booléen*
> - Vrai si la position spécifiée a été libérée,
> - Faux dans le cas contraire. La fonction [HErreur](3044088.md) permet d'obtenir plus d'informations sur le problème rencontré.
`<Position>` *Entier*
> Numéro d'une position précédemment sauvegardée, renvoyé par la fonction [HSauvePosition](3044136.md).

## Remarques

Les positions non libérées par programmation seront automatiquement libérées lors de la fermeture de l'application.
