# CouleurFocus (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

La propriété **CouleurFocus** permet de connaître et de spécifier la couleur utilisée pour mettre en évidence les champs de saisie ayant le focus dans un formulaire PDF (affiché dans un champ Lecteur PDF).
Nouveauté Abonnement
**Attention** : Cette propriété est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3. Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
// Couleur de fond définie pour les champs des formulaires PDF affichés via le champ Lecteur PDF
PDF_Lecteur_pdf.CouleurChamp = VertFoncé
// Couleur du champ qui a le focus dans les formulaires PDF affichés dans le champ Lecteur PDF
PDF_Lecteur_pdf.CouleurFocus = BleuClair
```

## Syntaxe

#### Connaître la couleur de fond des champs de saisie ayant le focus

```wlangage
<Résultat> = <Champ manipulé>.CouleurFocus
```

`<Résultat>` *Constante ou chaîne de caractères*
> Couleur de fond des champs de saisie ayant le focus. Correspond à l'une des options suivantes :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - [une couleur prédéfinie](3010002.md).
`<Champ manipulé>` *Nom de champ*
> Nom du champ Lecteur PDF.

#### Modifier la couleur de fond des champs de saisie ayant le focus

```wlangage
<Champ manipulé>.CouleurFocus = <Nouvelle couleur>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ Lecteur PDF.
`<Nouvelle couleur>` *Constante ou chaîne de caractères*
> Nouvelle couleur de fond des champs de saisie ayant le focus. Correspond à l'une des options suivantes :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie](3010002.md).
