# Constantes de gestion du groupware utilisateur

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |
| **gpwActivationImmédiate** | L'utilisateur est immédiatement activé. | [gpwActiveUtilisateur](1000021096.md), [gpwMotPasseOublié](1000021097.md) |
| **gpwActivationParEmail** | L'utilisateur est activé par email. Un email lui est automatiquement envoyé (les caractéristiques de l'email ont été définies dans la page d'administration). | [gpwActiveUtilisateur](1000021096.md), [gpwMotPasseOublié](1000021097.md) |
| **gpwAdministration** | Permet de passer en mode administration. |  |
| **gpwAnnulation** | L'utilisateur a cliqué sur le bouton d'annulation. | [gpwLogin](3041001.md) |
| **gpwAucun** | Nom du groupe d'utilisateurs par défaut : groupe Aucun. A partir de la version 24, cette constante n'est plus disponible. Elle a été remplacée par la fonction [gpwAucun](1000023557.md). |  |
| **gpwComplet** | Informations complètes sur l'utilisateur en cours. | [gpwRecupInfoUtilisateur](3041004.md) |
| **gpwConnexion** | Connexion utilisant un utilisateur créé et enregistré. | [gpwAuthLogin](1000023597.md) |
| **gpwDéfaut** | Nom du groupe d'utilisateurs par défaut : groupe Défaut. A partir de la version 24, cette constante n'est plus disponible. Elle a été remplacée par la fonction [gpwDéfaut](1000023556.md). |  |
| **gpwDroitAjoutApplication** | Droits d'accès : Droit d'ajouter une application dans le Store Privé. | Variable de type [gpwUtilisateur](1000021088.md) |
| **gpwDroitAucun** | Droits d'accès : Aucun droit d'ajout dans le Store Privé. | Variable de type [gpwUtilisateur](1000021088.md) |
| **gpwErreur** | Une erreur est survenue lors de la connexion de l'utilisateur. Pour obtenir plus d'informations sur cette erreur, utilisez la fonction [ErreurInfo](3013008.md) | [gpwLogin](3041001.md), [gpwOuvre](3041002.md), [gpwActiveUtilisateur](1000021096.md), [gpwMotPasseOublié](1000021097.md), [gpwVérifieUtilisateur](1000021104.md) |
| **gpwEtatAutorisé** | Etat de l'élément : L'élément est dans l'état autorisé. |  |
| **gpwEtatDéfaut** | Etat de l'élément : L'élément est dans l'état par défaut. | [gpwRecupDroits](1000020728.md) |
| **gpwEtatGrisé** | Etat de l'élément : Le champ est grisé. | [gpwRecupDroits](1000020728.md) |
| **gpwEtatInactif** | Etat de l'élément : Le champ est inactif. | [gpwRecupDroits](1000020728.md) |
| **gpwEtatInterdit** | Etat de l'élément : L'élément est interdit. |  |
| **gpwEtatInvisible** | Etat de l'élément : Le champ est invisible. | [gpwRecupDroits](1000020728.md) |
| **gpwFacebook** | Connexion utilisant un compte Facebook. | [gpwAjouteAuthLogin](1000023576.md), [gpwAuthLogin](1000023597.md) |
| **gpwGoogle** | Connexion utilisant un compte Google. | [gpwAjouteAuthLogin](1000023576.md), [gpwAuthLogin](1000023597.md) |
| **gpwInfoDoubleAuthentification** | Permet de savoir si la double authentification est activée. | [gpwRecupInfoUtilisateur](3041004.md) |
| **gpwInfoGroupe** | Nom du groupe de l'utilisateur. | [gpwRecupInfoUtilisateur](3041004.md) |
| **gpwInfoLogin** | Login de l'utilisateur. | [gpwRecupInfoUtilisateur](3041004.md) |
| **gpwInfoNom** | Nom de l'utilisateur. | [gpwRecupInfoUtilisateur](3041004.md) |
| **gpwInfoPrénom** | Prénom de l'utilisateur. | [gpwRecupInfoUtilisateur](3041004.md) |
| **gpwInfoRepDroit** | Répertoire du fichier des droits. | [gpwRecupInfoFichier](3041008.md) |
| **gpwInfoRepUtilisateur** | Répertoire du fichier des utilisateurs. | [gpwRecupInfoFichier](3041008.md) |
| **gpwInfoSuperviseur** | Permet de savoir si l'utilisateur connecté est un administrateur. | [gpwRecupInfoUtilisateur](3041004.md) |
| **gpwLDAPDNBase** | DN de base (chaîne de caractères au format "DC=xxx,DC=zzz,..."). | [gpwRecupInfoLDAP](1000017063.md) |
| **gpwLDAPPort** | Port du serveur LDAP. | [gpwRecupInfoLDAP](1000017063.md) |
| **gpwLDAPSansFichier** | Mode d'utilisation de l'annuaire LDAP. Vrai si le groupware utilisateur est lancé "sans fichiers de données", en mode authentification uniquement. | [gpwRecupInfoLDAP](1000017063.md) |
| **gpwLDAPServeur** | Nom du serveur LDAP. | [gpwRecupInfoLDAP](1000017063.md) |
| **gpwLDAPVersion** | Numéro de version LDAP. | [gpwRecupInfoLDAP](1000017063.md) |
| **gpwMicrosoft** | Connexion utilisant un compte Facebook. | [gpwAjouteAuthLogin](1000023576.md), [gpwAuthLogin](1000023597.md) |
| **gpwModeGroupware** | L'authentification est entièrement réalisée par le groupware utilisateur. | [gpwMode](1000020566.md) |
| **gpwModeLDAP** | L'authentification est réalisée par un annuaire LDAP. | [gpwMode](1000020566.md) |
| **gpwModeWindows** | L'authentification est réalisée par Windows. | [gpwMode](1000020566.md) |
| **gpwMotPasseInvalide** | Le mot de passe n'est pas valide. Il ne correspond pas au mot de passe de l'utilisateur décrit dans la base de données du groupware. | [gpwLogin](3041001.md), [gpwOuvre](3041002.md), [gpwVérifieUtilisateur](1000021104.md) |
| **gpwOK** | L'utilisateur est connecté | [gpwLogin](3041001.md), [gpwOuvre](3041002.md), [gpwVérifieUtilisateur](1000021104.md) |
| **gpwSalesforce** | Connexion utilisant un compte Salesforce. | [gpwAjouteAuthLogin](1000023576.md), [gpwAuthLogin](1000023597.md) |
| **gpwSuperviseur** | Nom du groupe d'utilisateurs par défaut : groupe Superviseur. A partir de la version 24, cette constante n'est plus disponible. Elle a été remplacée par la fonction [gpwSuperviseur](1000023555.md). |  |
| **gpwUtilisateurInconnu** | L'utilisateur n'est pas référencé dans la base de données du groupware utilisateur. | [gpwLogin](3041001.md), [gpwOuvre](3041002.md), [gpwVérifieUtilisateur](1000021104.md) |
| **gpwUtilisateursEnregistrés** | Groupe des utilisateurs enregistrés. A partir de la version 24, cette constante n'est plus disponible. Elle a été remplacée par la fonction [gpwUtilisateursEnregistrés](1000023559.md). |  |
| **gpwVisiteur** | Utilisateur de type Visiteur. A partir de la version 24, cette constante n'est plus disponible. Elle a été remplacée par la fonction [gpwVisiteur](1000023558.md). |  |
| **gpwYahoo** | Connexion utilisant un compte Yahoo. | [gpwAjouteAuthLogin](1000023576.md), [gpwAuthLogin](1000023597.md) |
