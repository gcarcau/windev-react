# Fonctions BitcoinCore

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Les fonctions Bitcoin permettant notamment de manipuler un serveur Bitcoin Core sont les suivantes :

| [BitcoinAdresseValide](1410088858.md) | Vérifie si une adresse d'un portefeuille Bitcoin est valide. |
| --- | --- |
| Nouveauté 2025 [BitcoinCoreConnexionOccurrence](1410090772.md) | Renvoie le nombre de pairs connectés. **Attention** : Cette fonction est disponible uniquement à partir de la version 2025 Update 2. |
| [BitcoinCoreDateHeureDernierBloc](1410090322.md) | Renvoie la date et l'heure de création du dernier bloc. |
| Nouveauté 2025 [BitcoinCoreDateHeureDernierLancement](1410090771.md) | Renvoie la date et l'heure du dernier lancement du logiciel Bitcoin Core. **Attention** : Cette fonction est disponible uniquement à partir de la version 2025 Update 2. |
| Nouveauté 2025 [BitcoinCoreEspaceDisqueUtilisé](1410090773.md) | Indique la taille sur disque de la blockchain. **Attention** : Cette fonction est disponible uniquement à partir de la version 2025 Update 2. |
| Nouveauté 2025 [BitcoinCoreHashBloc](1410090774.md) | Renvoie le hash d’un bloc identifié par son indice. **Attention** : Cette fonction est disponible uniquement à partir de la version 2025 Update 2. |
| [BitcoinCoreNombreBloc](1410090321.md) | Renvoie la taille de la chaîne de blocs connue par le noeud Bitcoin (c'est-à-dire le nombre de blocs créés depuis le 3 janvier 2009). Il est ainsi possible de calculer par exemple la date approximative du prochain "halving". |
| [BitcoinCoreNombreHashParSeconde](1410090319.md) | Renvoie le nombre de fois où la fonction sha256 a du être calculée par secondes pour calculer le dernier bloc. Ce nombre correspond à une preuve de travail. |
| [BitcoinCoreParamètre](1410090320.md) | Indique les paramètres de connexion au serveur Bitcoin Core, afin d'utiliser les fonctions [BitcoinCoreXXXX](1410090347.md). |

Remarque : L'utilisation des fonctions BitcoinCorexxx nécessite la mise en place d'un serveur Bitcoin et d'un serveur RPC. Pour plus de détails, consultez [Installation et utilisation d'un serveur Bitcoin Core](1410090348.md).
