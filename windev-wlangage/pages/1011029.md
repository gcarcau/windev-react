# Propriétés associées à un état

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Les différentes propriétés utilisables sur les états sont les suivantes :

| [BasPageCollé](2511074.md) | La propriété **BasPageCollé** permet de :  - Savoir si le bas de page doit être collé au dernier bloc avant le bas de page. - Modifier la gestion du bloc de bas de page. |
| --- | --- |
| [BorneMax](2510009.md) | La propriété **BorneMax** permet de :  - connaître et de modifier la borne maximale d'un état basé sur un fichier de données. - connaître la borne maximale du filtre en cours. - connaître la valeur maximale d'une série d'un graphe. - connaître et modifier la valeur maximale de certains types de champs. |
| [BorneMin](2510008.md) | La propriété **BorneMin** permet de :  - connaître et de modifier la borne minimale d'un état basé sur un fichier de données. - connaître la borne minimale du filtre en cours. - connaître la valeur minimale d'une série d'un graphe. - connaître et modifier la valeur minimale de certains types de champs. |
| [ConserverHiérarchieVisible](1000021055.md) | La propriété **ConserverHiérarchieVisible** permet de :  - Savoir quels éléments de la table hiérarchique sont imprimés : impression de la hiérarchie complète ou impression de la hiérarchie visible dans le champ. - Modifier le mode d'impression de la hiérarchie : impression de la hiérarchie complète ou impression de la hiérarchie visible dans le champ. |
| [DroiteAGauche](1000017228.md) | La propriété **DroiteAGauche** permet de connaître le sens d'écriture réel, effectif sur un champ, une colonne, une fenêtre ou un état. |
| [EspaceH](2511067.md) | La propriété **EspaceH** permet de connaître et de modifier l'espacement horizontal entre les étiquettes d'un état. Cet espace a été défini lors de la création de l'état au format étiquette. |
| [EspaceV](2511065.md) | La propriété **EspaceV** permet de connaître et de modifier l'espacement vertical entre les étiquettes d'un état. Cet espace a été défini lors de la création de l'état au format étiquette. |
| [HauteurEtiquette](2511069.md) | La propriété **HauteurEtiquette** permet de :  - Connaître la hauteur des étiquettes d'un état de type Étiquette. - Modifier la hauteur des étiquettes d'un état de type Étiquette. |
| [HTML](2511040.md) | La propriété **HTML** permet de :   - savoir si l'état en cours d'impression s'imprime en mode HTML. - gérer le type HTML d'un champ Libellé présent dans un état. |
| [ImageFond](2510056.md) | La propriété **ImageFond** permet de connaître et de modifier l'image de fond d'un élément : fenêtre, page, champ ou état. |
| [ImageFondImprimée](1000021350.md) | La propriété **ImageFondImprimée** permet de :   - Savoir si l'image de fond d'un état (formulaire ou non) doit être imprimée. - Imprimer ou non l'image de fond d'un état. |
| [ImpressionAChaquePage](2511057.md) | La propriété **ImpressionAChaquePage** permet de :  - Demander l'impression d'un état page par page. Chaque page de l'état sera envoyée séparément au spooler de l'imprimante. - Connaître le mode d'impression de l'état (page par page ou en totalité). |
| [InterfaceModifiableAvecEtatsEtRequêtes](2511075.md) | La propriété **InterfaceModifiableAvecEtatsEtRequêtes** permet de savoir si l' **interface** d'un état est modifiable sous le logiciel Etats & Requêtes. |
| [LargeurEtiquette](2511055.md) | La propriété **LargeurEtiquette** permet de :  - Connaître la largeur des étiquettes d'un état de type "Étiquette". - Modifier la largeur des étiquettes d'un état de type "Étiquette". |
| [MargeBasse](2511051.md) | La propriété **MargeBasse** permet de :  - Connaître la marge basse d'un état. - Modifier la marge basse d'un état. |
| [MargeDroite](2511053.md) | La propriété **MargeDroite** permet de :  - Connaître la marge de droite d'un état. - Modifier la marge de droite d'un état. |
| [MargeGauche](2511048.md) | La propriété **MargeGauche** permet de :  - Connaître la marge de gauche d'un état. - Modifier la marge de gauche d'un état. |
| [MargeHaute](2511043.md) | La propriété **MargeHaute** permet de :  - Connaître la marge haute d'un état. - Modifier la marge haute d'un état. |
| [MsgTriSel](2511045.md) | La propriété **MsgTriSel** permet de :  - Connaître le message d'attente affiché lors du tri et de la sélection des enregistrements de l'état. - Modifier le message d'attente affiché lors du tri et de la sélection des enregistrements de l'état. |
| [NbColonne](1000018810.md) | La propriété **NbColonne** permet de connaître le nombre de colonnes d'un état. |
| [NbCopie](2511042.md) | La propriété **NbCopie** permet de connaître et de modifier le nombre d'exemplaires à imprimer d'un état. |
| [NbEnrImprimé](2511058.md) | La propriété **NbEnrImprimé** permet de connaître le nombre d'enregistrements déjà imprimés. |
| [NbEnrLu](2511041.md) | La propriété **NbEnrLu** permet de connaître le nombre d'enregistrements lus : sélectionnés à la fois par la source de l'état ET par le code de filtre (s'il existe). |
| [NbEnrTotal](2511047.md) | La propriété **NbEnrTotal** permet de :  - Connaître le nombre d'enregistrements à imprimer. - Modifier le nombre d'enregistrements à imprimer. |
| [NbEtiquette](2511050.md) | La propriété **NbEtiquette** permet de :  - Connaître le nombre d'étiquettes imprimées sur la largeur d'une page. - Modifier le nombre d'étiquettes imprimées sur la largeur d'une page. |
| [NbExemplaireEtiquette](2511059.md) | La propriété **NbExemplaireEtiquette** permet de :  - Connaître le nombre d'exemplaires d'étiquettes identiques imprimés. - Modifier le nombre d'exemplaires d'étiquettes identiques à imprimer. |
| [Nom](2510082.md) | La propriété **Nom** permet de connaître :  - le nom de la police associée à une variable de type Police. - le nom d'un champ, d'un état ou d'un bloc d'un état. - le nom d'un champ, d'un groupe de champs ou d'une fenêtre. - le nom d'un champ, d'un groupe de champs ou d'une page. |
| [NomSource](2511035.md) | La propriété **NomSource** permet de :  - Connaître le nom de la source de données de l'état. - Changer la source de données de l'état. |
| [NomVue](2511030.md) | La propriété **NomVue** permet de :  - connaître le nom de la vue HFSQL, source de données d'un état - modifier le nom de la vue HFSQL, source de données d'un état. |
| [NomZoneMem](2511029.md) | La propriété **NomZoneMem** permet de :  - connaître le nom de la zone mémoire utilisée comme source de données d'un état. - modifier le nom de la zone mémoire utilisée comme source de données d'un état. |
| [NuméroPage](2510106.md) | La propriété **NuméroPage** permet de :   - connaître et de modifier le numéro de la page affichée dans un champ Image (fichiers image de type "multi-pages") - connaître et de modifier le numéro de la page d'un fichier PDF affiché dans un champ image d'une fenêtre - connaître et de modifier le numéro de la page d'un fichier PDF affiché en fond d'un état. |
| [NumEtiquetteDeDépart](2511032.md) | La propriété **NumEtiquetteDeDépart** permet de :  - Connaître le numéro de l'étiquette sur la planche d'étiquettes à partir de laquelle l'impression est effectuée. - Modifier le numéro de l'étiquette à partir de laquelle l'impression est effectuée sur la planche d'étiquettes. |
| [ODBCCodeSQL](2511028.md) | La propriété **ODBCCodeSQL** permet de :  - Connaître le code SQL de la "requête réalisée sur une connexion" source de l'état. - Modifier le code SQL de la "requête réalisée sur une connexion" source de l'état. |
| [ODBCMotDePasse](2511031.md) | La propriété **ODBCMotDePasse** permet de :  - Connaître le mot de passe utilisé pour se connecter à une base de données via un driver ODBC ou via un Connecteur Natif. - Préciser le mot de passe utilisé pour se connecter à une base de données via un driver ODBC ou via un Connecteur Natif. |
| [ODBCNomBase](2511034.md) | La propriété **ODBCNomBase** permet de :  - Connaître le nom de la base utilisée lors de l'impression d'un état basé sur une "requête réalisée sur une connexion". - Préciser le nom de la base sur laquelle porte l'impression d'un état basé sur une "requête réalisée sur une connexion". |
| [ODBCNomConnexion](2511033.md) | La propriété **ODBCNomConnexion** permet de :  - Connaître le nom de la connexion ODBC utilisée lors de l'impression d'un état basé sur une "requête réalisée sur une connexion". - Préciser le nom de la connexion ODBC sur laquelle porte l'impression d'un état basé sur une "requête réalisée sur une connexion". |
| [ODBCNomUtilisateur](2511019.md) | La propriété **ODBCNomUtilisateur** permet de :  - Connaître le nom de l'utilisateur utilisé pour se connecter à une base de données via un driver ODBC ou via un Connecteur Natif. - Préciser le nom d'utilisateur utilisé pour se connecter à une base de données via un driver ODBC ou via un Connecteur Natif. |
| [Plan](2510094.md) | La propriété **Plan** permet de :  - Connaître :   - le plan actif d'une fenêtre (ou d'un état) ou le plan auquel appartient un champ.  - le plan actif d'un élément WEBDEV. - Modifier :   - le plan actif d'une fenêtre (ou d'un état) ou associer un champ à un autre plan.  - le plan actif d'un élément WEBDEV. |
| [RubriqueParcourue](2510111.md) | La propriété **RubriqueParcourue** permet de :  - Connaître la rubrique utilisée pour le parcours automatique des champs Table, Zone répétée, Liste (y compris Liste image), Combo, état sur fichier ou des superchamps. - Modifier la rubrique utilisée pour le parcours automatique des champs Table, Zone répétée, Liste (y compris Liste image), Combo, état sur fichier ou des superchamps. Le parcours est alors réinitialisé. |
| [SélectionSeule](2511017.md) | La propriété **SélectionSeule** permet de :  - Savoir quels enregistrements du champ Table ou Table hiérarchique sont imprimés : impression de tous les enregistrements ou uniquement des enregistrements sélectionnés. - Modifier le mode d'impression des lignes du champ Table ou Table hiérarchique : impression de tous les enregistrements ou uniquement des enregistrements sélectionnés. |
| [SensEcriture](2513020.md) | La propriété **SensEcriture** permet de connaître et de modifier le sens d'écriture utilisé dans une fenêtre, un état ou dans un champ (utile pour la gestion des langues de type arabe ou hébreux). |
| [ToutModifiableAvecEtatsEtRequêtes](2511076.md) | La propriété **ToutModifiableAvecEtatsEtRequêtes** permet de savoir si un état est modifiable sous le logiciel Etats & Requêtes. |
| [Traitement](1000020878.md) | La propriété **Traitement** permet de modifier les traitements à exécuter par les événements disponibles sur un champ, une fenêtre, une page, un état, ... |
| [ValeurRenvoyée](2510134.md) | La propriété **ValeurRenvoyée** permet de :  - Connaître et modifier la valeur renvoyée par une fenêtre, une page ou un état. - Connaître et modifier la valeur renvoyée par une option d'un champ Sélecteur. |
