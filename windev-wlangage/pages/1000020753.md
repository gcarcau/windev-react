# XMLSigne (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Signe un document XML.

## Exemple

```wlangage
MonDoc est un xmlDocument
NoeudASigner est un xmlNoeud, description="schemaXSDDuProjet.NoeudRacine"
MonCertificat est un Certificat

MaSignature est un xmlSignature
MaSignature.AlgorithmeNormalisation = atC14NExcluAvecCommentaire
MaSignature.AlgorithmeSignature = asRSA_SHA_160
MaSignature.Clé = MonCertificat

SI XMLSigne(MaSignature, MonDoc.NoeudASigner) = Vrai ALORS
	Trace("Document signé")
FIN
```

## Syntaxe

```wlangage
<Résultat> = XMLSigne(<Signature> , <Noeud d'insertion>)
```

`<Résultat>` *Booléen*
> - Vrai si le document XML a été signé,
> - Faux dans le cas contraire.
`<Signature>` *Variable de type xmlSignature ou de type xmlSignatureXAdES*
> Signature à utiliser. Ce paramètre peut correspondre au choix :
>
> - Nom de la variable de type [xmlSignature](1000020736.md).
> - Nouveauté Abonnement
>   Nom de la variable de type [xmlSignatureXAdES](1410091158.md).
>    Ce type de variable n'est pas disponible.
>   **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
>   Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
`<Noeud d'insertion>` *Variable de type xmlNoeud*
> Nom de la variable de type [xmlNoeud](1000018786.md) correspondant à l'emplacement où la signature doit être insérée.

## Remarques

- Nouveauté Abonnement
  Il est possible d'utiliser un certificat présent sur une carte à puce pour signer le XML. Dans ce cas, la signature est automatiquement de type RSA SHA 256.
  **Attention** : Cette fonctionnalité est disponible dans la version Abonnement, uniquement à partir de WINDEV Suite 2025 Update 1.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
