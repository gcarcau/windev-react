# Existe (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Existe** permet de savoir si un élément existe.
Cette propriété est utilisable sur :

- les tableaux associatifs ou leurs éléments. Pour plus de détails, consultez [Existe](1000022167.md).
- une variable de type [Variant](1514019.md).
- une variable de type [XMLNoeud](1000018786.md).
- une variable de type [JSON](1000023611.md).
- une variable de type [YAML](1000024438.md).
- une variable de type [htmlAttribut](1000025912.md).
- l'instruction de compilation [COMPILE SI](1510021.md).
