# <Variable ftpConnexion>.Connecte (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Connecte le poste en cours à un serveur FTP (File Transfer Protocol).
> _(WINDEV, WEBDEV - Code Serveur, Windows, Android, Widget Android)_ Les modes de connexion sécurisés disponibles sont les suivants : FTPS : FTP sécurisé selon le protocole SSL avec chiffrement implicite. FTPES : FTP sécurisé selon le protocole SSL avec chiffrement explicite. SFTP : FTP sécurisé par un tunnel SSH.

Nouveauté Abonnement
Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
// Syntaxe non disponible en PHP
// Connexion du poste en cours au serveur FTP
MaConnexionFTP est une ftpConnexion
MaConnexionFTP.Serveur = "192.54.12.8"
MaConnexionFTP.Connecte()
```

## Syntaxe

```wlangage
<Résultat> = FTPConnecte(<Connexion FTP>)
```

`<Résultat>` *Entier*
> - Vrai si la connexion a été effectuée,
> - Faux dans le cas contraire. Le compte-rendu détaillé de l'erreur est connu grâce à la fonction [ErreurInfo](3013008.md) utilisée avec la constante *errCode* ou *errMessage*.
>   En cas d'erreur d'identification, la fonction [ErreurInfo](3013008.md) utilisée avec la constante *errCode* renvoie la constante *ftpErreurIdentification*.
`<Connexion FTP>` *Variable de type ftpConnexion*
> Nom de la variable de type [ftpConnexion](1410090869.md) décrivant les caractéristiques de la connexion au serveur FTP.

## Remarques

> _(Android, Widget Android)_ Permissions requisesL'utilisation de cette fonction entraîne la modification des permissions requises par l'application. Permission requise : INTERNET Cette permission autorise l'application à ouvrir des sockets réseau.
