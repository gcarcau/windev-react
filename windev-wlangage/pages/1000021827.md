# iCalendarVersRendezVous (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Liste les rendez-vous décrits dans une chaîne de caractères au format iCalendar.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Android, iPhone/iPad)_ // Charge les rendez-vous décrits dans un fichier iCalendar dans un champ Planning
// sChaîne est ici une chaîne ANSI
sChaîne est une chaîne = fChargeTexte("agenda.ics")
tabRDV est un tableau de RendezVous = iCalendarVersRendezVous(sChaîne)
SI PAS ErreurDétectée ALORS
 POUR TOUT ÉLÉMENT rdv DE tabRDV
 PlanningAjouteRendezVous(PLN_MonPlanning, rdv)
 FIN
FIN

## Syntaxe

```wlangage
<Résultat> = iCalendarVersRendezVous(<iCalendar>)
```

`<Résultat>` *Tableau de RendezVous*
> Tableau de variables de type [RendezVous](1000019244.md) contenant la liste des rendez-vous décrits dans la chaîne de caractères.
`<iCalendar>` *Chaîne de caractères ANSI au format UTF-8 ou Buffer*
> Données au format iCalendar.
> > _(Android, Widget Android)_ Ce paramètre doit être un buffer.

## Remarques

Pour construire une chaîne de caractères au format iCalendar à partir d'une liste de rendez-vous, utilisez la fonction [RendezVousVersiCalendar](1000021828.md).

**Composante : wd300mdl.dll**
