# hbConnexion (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

Le type **hbConnexion** permet de définir les caractéristiques d'une connexion à un serveur HBase. Les caractéristiques de cette connexion peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Connexion
Connexion est un hbConnexion
Connexion.Serveur = "MonServeur"
// Affichage de la liste des tables
Trace(hbListeTable(Connexion))
```

## Propriétés

### Propriétés spécifiques à la description des variables de type hbConnexion
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **hbConnexion** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Serveur | Chaîne de caractères | Nom DNS ou adresse IP du proxy HBase Thrift. Il est possible de spécifier une liste d'adresses en les séparant par un point-virgule. |

## Remarques

### Fonctions WLangage manipulant le type hbConnexion

| [hbCréeTable](1000021696.md) | Crée une table HBase ou modifie la description d'une table HBase. |
| --- | --- |
| [hbEcrit](1000021712.md) | Ecrit des cellules (valeurs de rubriques) dans une ou plusieurs lignes (enregistrements) d'une table HBase. |
| [hbListeTable](1000021687.md) | Récupère la liste des tables présentes sur un serveur HBase. |
| [hbLit](1000021706.md) | Lit des cellules (valeurs de rubriques) d'une ligne (enregistrement) dans une table HBase. |
| [hbRécupèreDescriptionTable](1000021695.md) | Récupère la description d'une table HBase. |
| [hbSupprime](1000021714.md) | Supprime :  - une ou plusieurs cellules d'une table HBase pour une ou plusieurs colonnes. - une ligne d'une table HBase. |
| [hbSupprimeTable](1000021713.md) | Supprime une table HBase. |
