# <Editeur HTML>.Récupère (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Récupère en mode asynchrone la valeur d'une des propriétés d'un champ Editeur HTML.
**Remarque** : Cette fonction est notamment utile pour les applications Android et iOS pour lesquelles les propriétés WLangage [Body](1000025914.md), [Valeur](2510130.md) et [TexteSansFormat](1000019118.md) ne sont pas disponibles (car utilisables uniquement en mode synchrone).

## Exemple

```wlangage
// Sauvegarde la saisie dans un fichier
EDHTML_MonEditeur.Récupère(ehrValeur, EditeurHTMLRécupère_Callback)
PROCÉDURE INTERNE EditeurHTMLRécupère_Callback(valeur)
	fSauveTexte("sauvegarde.html", valeur)
FIN
```

## Syntaxe

```wlangage
<Champ Editeur HTML>.Récupère(<Propriété> , <Procédure WLangage>)
```

`<Champ Editeur HTML>` *Nom de champ*
> Nom du champ Editeur HTML manipulé.
`<Propriété>` *Constante de type Entier*
> Propriété pour laquelle la valeur doit être récupérée ;
>
>
> | *ehrBody* | Permet d'obtenir le code HTML du body. Cette constante est équivalente à la propriété [Body](1000025914.md). |
> | --- | --- |
> | *ehrTexteSansFormat* | Permet d'obtenir le texte contenu dans le champ sans les balises HTML.  Cette constante est équivalente à la propriété [TexteSansFormat](1000019118.md). |
> | *ehrValeur* | Permet d'obtenir la valeur du champ.  Cette constante est équivalente à la propriété [Valeur](2510130.md). |
`<Procédure WLangage>` *Nom de procédure*
> Procédure WLangage (également nommée "callback") exécutée pour obtenir la valeur recherchée. Cette procédure est de la forme :
>
>
> ```wlangage
> PROCEDURE <Nom de la procédure>(Valeur)
> ```
>
>
> où <Valeur> est la valeur recherchée. Dans ce paramètre, les caractères sont encodés en UTF8.
