# PlanificateurRAZ (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Remplit les structures [TâchePlanifiée](3089004.md) et/ou [HoraireTâchePlanifiée](3089002.md) avec les valeurs par défaut.

## Exemple

```wlangage
// Initialisation des structures TâchePlanifiée et HoraireTâchePlanifiée
PlanificateurRAZ()
```

## Syntaxe

```wlangage
PlanificateurRAZ([<Structure à ré-initialiser>])
```

`<Structure à ré-initialiser>` *Constante ou combinaison de constantes optionnelle*
> Type de la structure à ré-initialiser.
>
> | *planificateurRAZHoraire* | Ré-initialise la structure HoraireTâchePlanifiée. |
> | --- | --- |
> | *planificateurRAZTâche* | Ré-initialise la structure TâchePlanifiée. |
> | *planificateurRAZTâche* + *planificateurRAZHoraire* (par défaut) | Ré-initialise les deux structures. |

## Remarques

### Ré-initialisation des structures
Les structures sont ré-initialisées de manière à créer une tâche par défaut (identique à celle crée par la commande "Nouvelle tâche" du planificateur Windows) : une tâche exécutée tous les jours à 9h à partir du jour de sa création, ne pouvant pas s'exécuter lorsque l'ordinateur fonctionne sur batteries, et limitée à 72 heures d'exécution.

**Classification Métier / UI : Code métier**

**Composante : wd300std.dll**
