# URLToken (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

La propriété **URLToken** permet de connaître et de modifier l'URL de récupération du token d'accès. Cette propriété est utilisable sur :

- une variable de type [OAuth2Paramètres](1000022212.md),
- une variable de type [JWTParamètres](1410089572.md).
