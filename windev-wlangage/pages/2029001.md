# Environnement de l'éditeur de projet

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Les éléments importants de l'éditeur de projet sont les suivants :

|  | **Ruban** Permet un accès rapide aux principales fonctionnalités de l'éditeur de projet. |
| --- | --- |
|  | **Tableau de bord du projet en cours** Tableau de bord permettant de voir l'état du projet et d'accéder à tous les éléments du projet. |
|  | **[Volets ancrables verticaux](2027001.md)** Affiche :  - les raccourcis vers les principales fonctionnalités disponibles sous l'éditeur en cours, - les fonctionnalités les plus utilisées, - les éléments (fenêtres, états, champs, ...) disponibles dans le projet en cours. |
|  | **Fenêtre de description** Permet de visualiser et/ou de modifier les caractéristiques du projet. |
|  | **[Documents ouverts](2029012.md)** Affiche un bouton pour chaque document ouvert sous l'éditeur. Pour afficher l'élément voulu au premier plan, il suffit de cliquer sur le "bouton" correspondant. |
|  | **[Volets ancrables horizontaux](2027001.md)** Volets permettant de :  - afficher les différents éléments du code (liste des classes, des procédures locales ou globales, [volet "Code"](2027009.md)), - afficher les erreurs de compilation (erreurs présentes dans le code WLangage, [volet "Erreurs de compilation"](2027031.md)), - effectuer des recherches ([volet "Rechercher - Remplacer"](2027013.md)), - afficher le débogueur lors du test d'un élément ([volet "Débogueur"](2027030.md)), - ... |
