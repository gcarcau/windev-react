# MemTrie (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Trie les éléments présents dans une zone mémoire. Ce tri est effectué sur l'argument de tri spécifié avec les fonctions [MemAjoute](3053002.md) ou [MemModifie](3053007.md).

## Exemple

```wlangage
// Tri croissant des éléments dans la zone mémoire "ZoneMémoire"
MemTrie("ZoneMémoire", Vrai)
```

## Syntaxe

```wlangage
MemTrie(<Zone mémoire> [, <Sens>])
```

`<Zone mémoire>` *Chaîne de caractères*
> Nom de la zone mémoire, défini par la fonction [MemCrée](3053005.md).
`<Sens>` *Booléen optionnel*
> - Vrai (valeur par défaut) si le tri doit être croissant,
> - Faux si le tri doit être décroissant.

## Remarques

### Existence de la zone mémoire
L'existence de la zone mémoire n'est pas vérifiée.
Si la zone mémoire spécifiée n'existe pas, une erreur du WLangage est générée lors de l'exécution de la fonction **MemTrie**.

Pour vérifier l'existence d'une zone mémoire, utilisez la fonction [MemExiste](3053006.md).

### Tri des éléments
Le tri est utilisé par les fonctions de parcours [MemPremier](3053014.md), [MemDernier](3053004.md), [MemSuivant](3053017.md) et [MemPrécédent](3053011.md), ainsi que par la fonction [MemRecherche](3053015.md).

**Classification Métier / UI : Code neutre**
