# Propriétés associées au champ Lien

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

## Présentation

Le champ Lien est aussi bien disponible dans une page ou un état. Certaines propriétés sont disponibles uniquement pour les champs liens présents dans une page ou dans un état.
