# ValeurInférieure (Propriété)

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

La propriété **ValeurInférieure** permet de :

- Connaître la borne inférieure de l'intervalle actuellement sélectionné dans un champ Potentiomètre d'intervalle.
- Modifier la borne inférieure de l'intervalle actuellement sélectionné dans un champ Potentiomètre d'intervalle.

Remarque : La propriété [Valeur](2510130.md) est identique à la propriété **ValeurInférieure**.

## Exemple

```wlangage
// Initialise l'intervalle de prix pour la recherche des produits
RGS_FiltrePrix.BorneMin = 0
RGS_FiltrePrix.BorneMax = 1000
RGS_FiltrePrix.ValeurInférieure = 10
RGS_FiltrePrix.ValeurSupérieure = 1000
```

## Syntaxe

#### Connaître la valeur inférieure de l'intervalle sélectionné

```wlangage
<Résultat> = <Champ Potentiomètre d'intervalle>.ValeurInférieure
```

`<Résultat>` *Entier*
> Valeur inférieure de l'intervalle actuellement sélectionné dans le champ.
`<Champ Potentiomètre d'intervalle>` *Nom de champ*
> Nom du champ Potentiomètre d'intervalle manipulé.

#### Modifier la valeur inférieure de l'intervalle sélectionné

```wlangage
<Champ Potentiomètre d'intervalle>.ValeurInférieure = <Nouvelle valeur>
```

`<Champ Potentiomètre d'intervalle>` *Nom de champ*
> Nom du champ Potentiomètre d'intervalle manipulé.
`<Nouvelle valeur>` *Entier*
> Nouvelle valeur inférieure de l'intervalle actuellement sélectionné dans le champ.

## Remarques

- Pour connaître et modifier la borne supérieure de l'intervalle, utilisez la propriété [ValeurSupérieure](1000020434.md).
- Les propriétés **ValeurInférieure** et [ValeurSupérieure](1000020434.md) respectent les conditions suivantes :
  - La propriété [BorneMin](2510008.md) est inférieure ou égale à la propriété **ValeurInférieure**.
  - La propriété **ValeurInférieure** est inférieure ou égale à la propriété [ValeurSupérieure](1000020434.md).
  - La propriété [ValeurSupérieure](1000020434.md) est inférieure ou égale à la propriété [BorneMax](2510009.md).
   Donc en affectation :
  - Si la nouvelle valeur est plus faible que la propriété [BorneMin](2510008.md), la propriété **ValeurInférieure** prend la valeur de la propriété [BorneMin](2510008.md).
  - Si la nouvelle valeur est plus élevée que la propriété [ValeurSupérieure](1000020434.md), la propriété [ValeurSupérieure](1000020434.md) est modifiée et prend la même valeur que la propriété **ValeurInférieure**.
  - Si la nouvelle valeur est plus élevée que la propriété [BorneMax](2510009.md), les propriétés **ValeurInférieure** et [ValeurSupérieure](1000020434.md) prennent la valeur de la propriété [BorneMax](2510009.md).
