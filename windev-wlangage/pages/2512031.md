# FichierRelié (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

La propriété **FichierRelié** permet de paramétrer les caractéristiques d'une liaison. Il est ainsi possible de :

- Connaître le nom du fichier de données relié utilisé dans la liaison.
- Changer le fichier de données relié utilisé dans la liaison.

## Exemple

```wlangage
// Modifier le fichier de données relié
GestionProjet.FichierRelié = Projet
```

## Syntaxe

#### Connaître le fichier de données relié de la liaison

```wlangage
<Fichier de données> = <Liaison>.FichierRelié
```

`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données relié de la liaison.
`<Liaison>` *Chaîne de caractères*
> Nom de la liaison définie sous l'éditeur d'analyses ou définie grâce au type [Description de Liaison](1514039.md).

#### Changer le fichier de données relié de la liaison

```wlangage
<Liaison>.FichierRelié = <Fichier de données>
```

`<Liaison>` *Chaîne de caractères*
> Nom de la liaison définie sous l'éditeur d'analyses ou définie grâce au type [Description de Liaison](1514039.md).
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données relié utilisé par la liaison. Ce fichier de données a été défini sous l'éditeur d'analyses ou par programmation grâce au type [Description de Fichier](1514065.md).

## Remarques

La propriété [FichierSource](2512034.md) permet de connaître et de modifier le fichier de données source de la liaison.
