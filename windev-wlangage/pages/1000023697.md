# <Zone répétée>.Select (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Renvoie l'indice de l'élément sélectionné dans un champ Zone répétée. L'élément sélectionné correspond à la répétition en cours sur laquelle le bandeau de sélection est affiché.
**Remarque** : La fonction **<Zone répétée>.Select** peut être utilisée indifféremment sur :

- un champ Zone répétée fichier ou Zone répétée par programmation.
- un champ Zone répétée monosélection ou multisélection. Dans le cas des champs Zone répétée multisélection, il est nécessaire d'utiliser la fonction **<Zone répétée>.Select** dans une boucle pour connaître toutes les répétitions sélectionnées.

## Exemple

```wlangage
// Indice de la répétition sélectionnée dans le champ Zone répétée "ZR_Produit"
ResSelect = ZR_Produit.Select()
```

```wlangage
// Répétitions sélectionnées dans un champ Zone répétée par programmation multisélection
i est un entier
NbSélectionné est un entier = ZR_Zone1.SelectOccurrence()
POUR i = 1 À NbSélectionné
	Trace("Elément sélectionné : " + ZR_Zone1.Select(i))
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Champ Zone répétée>.Select([<Rang>])
```

`<Résultat>` *Entier*
> - Indice de la répétition sélectionnée dans le champ Zone répétée spécifié,
> - -1 si aucune répétition n'est sélectionnée.
`<Champ Zone répétée>` *Nom de champ*
> Nom du champ Zone répétée à manipuler.
`<Rang>` *Entier optionnel*
> Rang de la sélection dans le cas d'un champ Zone répétée multisélection.
> Si ce paramètre n'est pas spécifié, l'indice de la première répétition sélectionnée est renvoyé.
> Par exemple, pour récupérer le premier élément sélectionné, <Rang> = 1.
> Pour récupérer le deuxième élément sélectionné, <Rang> = 2, ...
