# Compile

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Le mot-clé **Compile** peut correspondre :

- à la fonction **[Compile](3013015.md)** qui permet de compiler dynamiquement une procédure dont le code source est fourni..
- à l'instruction de compilation **<COMPILE SI>** qui permet de compiler ou non un code WLangage selon une condition (notamment utilisé pour compiler un code selon une plateforme ou un type de configuration).
