# Connecteur Natif Informix : Programmation à l'aide des fonctions HFSQL

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows)

## Présentation

Pour utiliser une base de données Informix avec le Connecteur Natif, il est nécessaire **d'importer la structure des tables Informix dans l'analyse WINDEV ou WEBDEV**.
**Différences par rapport à la programmation SQL** : Pour manipuler les données Informix, les requêtes ne sont pas obligatoires. En effet, vous pouvez directement utiliser les fonctions HFSQL pour lire vos données, effectuer des recherches, des filtres, ... Cependant, il est nécessaire d'importer la structure des fichiers Informix dans l'analyse WINDEV ou WEBDEV.

## Importation de la structure des fichiers

### Les étapes de l'importation
Pour réaliser cette importation :

1. Lancez l'éditeur d'analyses : cliquez sur [image: Charger l'analyse du projet] parmi les boutons d'accès rapide.
2. Sous le volet "Analyse", dans le groupe "Création", déroulez "Importer" et sélectionnez "Importer des descriptions de fichiers/tables".
3. L'assistant se lance. Une connexion à la base de données Informix est automatiquement créée et associée aux fichiers importés dans l'analyse. Cette connexion devra être utilisée pour manipuler le fichier de données Informix par programmation.

Dans les différents écrans de l'assistant, choisissez les options suivantes :

- Type de base de données : Informix.
- Caractéristiques de la connexion : Serveur de données, Utilisateur et mot de passe, base de données.
- L'application accédera aux données dans le format actuel.
- Lorsque la connexion est établie, il suffit de sélectionner les tables à importer dans l'analyse WINDEV ou WEBDEV. Ces tables pourront être manipulées par programmation grâce aux fonctions HFSQL du WLangage. Ces tables apparaîtront en bleu sous l'éditeur d'analyses.

### Prendre en compte les évolutions de la base de données Informix
Pour prendre en compte les évolutions des tables importées sous l'éditeur d'analyses, sous le volet "Analyse", dans le groupe "Analyse", déroulez "Synchronisation" et sélectionnez "Mettre à jour l'analyse depuis les bases de données externes".
Un assistant se lance et permet au choix :

- soit d'analyser les différences pour les tables importées
- soit d'analyser les différences pour toutes les tables Informix.

## Programmation

### 1. Ouverture de la connexion
Pour ouvrir la connexion à la base de données Informix, utilisez la fonction [HOuvreConnexion](3044107.md), en précisant le nom de la connexion à ouvrir. Ce nom de connexion a été défini lors de l'importation de la structure des fichiers dans l'analyse.
Pour modifier certains paramètres de cette connexion (par exemple le nom d'utilisateur ou le mot de passe), utilisez la fonction [HConnecte](3044263.md).

**Remarque** : Si vous tentez de lire directement le fichier de données (fonction [HLitPremier](3044051.md), ...), la connexion associée à la description du fichier de données dans l'analyse sera automatiquement ouverte.

### 2. Exécution de requêtes
Les fonctions [HExécuteRequête](3044080.md) et [HExécuteRequêteSQL](3044084.md) permettent d'exécuter des requêtes sur la base de données en cours.

- [HExécuteRequête](3044080.md) : permet d'exécuter une requête prédéfinie avec l'éditeur de requêtes.
- [HExécuteRequêteSQL](3044084.md) : permet d'exécuter une requête en précisant directement le code SQL de la requête et le nom qui sera attribué à ce code SQL.

```wlangage
// Initialisation de la requête "Client_84"
HExécuteRequête(CLIENT_84, "BaseInformix", hRequêteSansCorrection)
HExécuteRequêteSQL(ReqClient, hRequêteSansCorrection, ...
	"SELECT NOM FROM CLIENT", "BaseInformix")
```

### 3. Récupération du résultat
Le parcours du résultat est réalisé avec toutes les fonctions de lecture classiques : [HLitPremier](3044051.md), [HLitSuivant](3044037.md), [HLitRecherche](3044050.md), ...
**Remarque** : Les constantes *hBlocageEcriture* et *hBlocageLectureEcriture* sont ignorées. En effet, les blocages en lecture et/ou en écriture ne sont pas supportés par le Connecteur Natif.

### 4. Fermeture de la connexion
La fonction [HFermeConnexion](3044095.md) permet de fermer la connexion à la base de données lorsque toutes les requêtes nécessaires ont été réalisées.
