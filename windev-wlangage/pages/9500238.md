# Gestion des polices personnalisées dans un projet WINDEV ou WINDEV Mobile

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

## Présentation

Un projet WINDEV comme un projet WINDEV Mobile peut incorporer des polices de caractères personnalisées, notamment des Google fonts. Ces polices ne sont pas présentes par défaut sur le poste ou le périphérique mobile de l'utilisateur final.
Il est donc nécessaire d'incorporer ces polices avant de générer l'application et de la déployer.

Nouveauté 2025

> _(WINDEV)_ Il est désormais possible d'utiliser des polices de caractères personnalisées (notamment des Google Fonts) dans un projet WINDEV.

> _(Android, iPhone/iPad)_ Dans un projet WINDEV Mobile (iOS ou Android), les Google Fonts sont désormais disponibles.

**Attention** : Cette fonctionnalité est disponible uniquement à partir de la version 2025 Update 1.

**Remarque** : Les polices personnalisées ne sont pas prises en compte dans une application WINDEV pour Linux.

## Utiliser des polices personnalisées

### Ajouter des polices personnalisées dans un projet
Pour utiliser des polices spécifiques (en édition comme en exécution) :

1. Affichez la fenêtre de description du projet : sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description".
2. Dans l'onglet "Avancé", cliquez sur le bouton "Polices du projet".
3. La fenêtre qui s'affiche indique les polices spécifiques utilisées par le projet :
  Vous pouvez :
  - Nouveauté 2025
    Ajouter une "Google Font" : Le bouton "Ajouter une Google Font" permet d'afficher la liste des Google Fonts utilisables. Sélectionnez la police voulue et validez.
    **Attention** : Cette option est disponible uniquement à partir de la version 2025 Update 1.
  - Ajouter une police grâce à son fichier : Le bouton "Ajouter depuis le disque" permet d'ajouter des fichiers au format "TTF" ou "OTF".
   Les fichiers correspondant à la police seront copiés dans le sous-répertoire "Fonts" du projet.
  **ATTENTION** : Vous devez disposer des droits nécessaires pour la diffusion des polices sélectionnées.
4. Validez les différentes fenêtres.

Les polices sélectionnées seront :

- disponibles sous l'éditeur de fenêtres et l'éditeur d'états. Vérifiez que les polices ajoutées gèrent l'alphabet de votre application et qu'elles sont redistribuables.
- intégrées dans l'application (WINDEV, Android ou iOS) puis déployées sur le poste de l'utilisateur.

### Utiliser une police personnalisée dans une fenêtre ou un état
Pour utiliser une police personnalisée dans une fenêtre ou un état :

1. Affichez la fenêtre de description du champ.
2. Dans l'onglet "Style" :
  - Sélectionnez l'élément voulu.
  - Déroulez la liste des polices et sélectionnez la police voulue.
    Dans cette liste :
    - Les polices personnalisées sont affichées en premier.
    - Les polices sont regroupées par thème.
    - Nouveauté 2025
      Les polices "Google fonts" les plus courantes sont listées par défaut (mais ne sont pas installées). Si vous sélectionnez une de ces polices, elle sera automatiquement téléchargée et sauvegardée dans le répertoire "Fonts" du projet.
      **Attention** : Cette option est disponible uniquement à partir de la version 2025 Update 1.
    - Il est possible de sélectionner la plateforme de disponibilité des polices.
