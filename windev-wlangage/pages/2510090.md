# Titre (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Titre** permet de :

- Connaître le titre d'une colonne d'un champ Table, d'un champ Graphe, d'une fenêtre ou d'une page.
- Modifier le titre d'une colonne d'un champ Table, d'un champ Graphe, d'une fenêtre ou d'une page.

Dans les états, cette propriété permet de connaître et modifier le titre d'un champ Graphe.

## Exemple

> _(WINDEV)_ // Connaître le titre de la fenêtre "FEN_FormulaireSaisie"
ResTitre = FEN_FormulaireSaisie.Titre

> _(WINDEV, Java)_ // Ajout d'une image dans le titre d'une colonne d'un champ Table
TABLE_MaTable.COL_MaColonne.Titre = gImage("MonImage.BMP") + "Mon titre"

> _(WINDEV)_ // Placer la date à droite du titre de la fenêtre
MaFenêtre.Titre = EOT + gCadrage("D", DateVersChaîne(DateDuJour(), ...
 "JJJJ JJ MMMM AAAA"))

## Syntaxe

#### Connaître le titre d'un élément

```wlangage
<Résultat> = <Nom de l'élément>.Titre
```

`<Résultat>` *Chaîne de caractères*
> - Titre de la fenêtre ou de la page spécifiée.
> - Titre de la colonne spécifiée.
> - Titre de la colonne à laquelle appartient la cellule de table spécifiée.
> - Titre du champ Graphe spécifié.
`<Nom de l'élément>` *Chaîne de caractères*
> Nom de l'élément (colonne, graphe, cellule de table, fenêtre ou page) à manipuler.
> Une cellule de table n'a pas de nom. Pour récupérer le titre de la colonne à laquelle appartient une cellule de table, utilisez la syntaxe :
>
>
> ```wlangage
> <Nom de la table>[Numéro de ligne][Numéro de colonne]
> ```
>
>
>
> Par exemple :
>
>
> ```wlangage
> TABLE_Table1[1][2]
> ```

#### Modifier le titre d'un élément

```wlangage
<Nom de l'élément>.Titre = <Nouveau titre>
```

`<Nom de l'élément>` *Chaîne de caractères*
> Nom de l'élément (colonne, graphe, cellule de table, fenêtre ou page) à manipuler.
> Une cellule de table n'a pas de nom. Pour récupérer le titre de la colonne à laquelle appartient une cellule de table, utilisez la syntaxe :
>
>
> ```wlangage
> <Nom de la table>[Numéro de ligne][Numéro de colonne]
> ```
>
>
>
> Par exemple :
>
>
> ```wlangage
> TABLE_Table1[1][2]
> ```
`<Nouveau titre>` *Tout type*
> - Nouveau titre de la fenêtre ou de la page spécifiée. Les fonctions graphiques peuvent être utilisées dans ce paramètre.
>   **Cas particulier sous Windows Vista (et supérieur)** : Les fenêtres utilisant le look "Aero system" ne peuvent pas avoir de titre graphique : la partie graphique est ignorée. Si "Aero" n'est pas actif, le titre graphique sera affiché normalement.
> - Nouveau titre de la colonne.
> - Nouveau titre du champ Graphe.

## Remarques

> _(WINDEV)_ Cas des fenêtres détouréesSur les fenêtres détourées, la propriété Titre permet également de connaître et de modifier le titre de la fenêtre. Cependant, ce titre n'est pas affiché dans la fenêtre. Si vous avez utilisé un gabarit détouré, le titre de la fenêtre est affiché dans un champ de type Libellé. Le contenu de ce champ n'est pas pris en compte par la propriété Titre.

### Équivalence
La propriété **Titre** est équivalente aux propriétés [Valeur](2510130.md) et [Libellé](2510053.md).
Pour connaître le titre d'une fenêtre, les syntaxes suivantes sont équivalentes :

```wlangage
ResTitre = <Nom de la fenêtre>.TitreResTitre = <Nom de la fenêtre>.ValeurResTitre = <Nom de la fenêtre>.LibelléResTitre = <Nom de la fenêtre>
```

Pour connaître le titre d'une colonne, les syntaxes suivantes sont équivalentes :

```wlangage
ResTitre = <Nom de la colonne>.TitreResTitre = <Nom de la colonne>.Libellé
```

> _(WINDEV, WINDEV Mobile)_ Pour connaître le titre de la colonne à laquelle appartient une cellule d'un champ Table, les deux syntaxes suivantes sont équivalentes :

ResTitre = <Nom du champ Table>[<Numéro de ligne>][<Numéro de colonne>].TitreResTitre = <Nom du champ Table>[<Numéro de ligne>][<Numéro de colonne>].Libellé

### Limites
La propriété **Titre** s'applique uniquement aux :

- fenêtres et pages,
- colonnes d'un champ Table (et d'un champ Table hiérarchique),
- cellules d'un champ Table (et d'un champ Table hiérarchique),
- champs Graphe,
- menu d'une page.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad)_ Dans un état, la propriété Titre s'applique uniquement sur les champs Graphe.

> _(Java)_ En Java, la propriété Titre s'applique uniquement aux éléments suivants :Fenêtre.Colonne d'un champ Table.

> _(Widget Android)_ La propriété Titre s'applique uniquement aux fenêtres.

> _(PHP)_ En PHP, la propriété Titre s'applique uniquement sur les pages.
