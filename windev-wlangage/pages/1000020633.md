# Fonctions de gestion des toasts

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Les fonctions de gestion des toasts sont les suivantes :
| [ToastAffiche](1000019358.md) | Affiche un message de type "Toast". |
| --- | --- |
| [ToastAfficheFI](1000024643.md) | Ouvre un toast dont le contenu est basé sur une fenêtre interne. |
| [ToastAffichePopup](1000020625.md) | Affiche une page de type popup pendant une durée donnée pour afficher un message de type "Toast". |
| [ToastSupprimeTout](1000020336.md) | Supprime tous les toasts affichés par la fonction [ToastAffiche](1000019358.md). |
