# Auteur (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Auteur** permet de connaître et de modifier l'auteur d'un élément. Cette propriété est utilisable sur :

- une variable de type [EvénementTimeline](1000020612.md).
- une variable de type [gglEvénement](1000017440.md).
- une variable de type [RendezVous](1000019244.md).
- une variable de type [rssEntrée](1000017792.md).
- une variable de type [docPropriété](1000022945.md).
- une variable de type [pdfDocument](1000024909.md).
