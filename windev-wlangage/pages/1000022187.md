# <Tableau croisé dynamique>.InfoXY (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur)

Renvoie les valeurs d'entêtes correspondant à une position en pixels dans un champ Tableau croisé dynamique.
Nouveauté Abonnement

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
pos est une tcdPosition de TCD_Statistiques
pos = TCD_Statistiques.InfoXY(SourisPosX(), SourisPosY())
SI pos.EnDehors = Vrai ALORS
	LIB_Libellé  = ""
SINON
	LIB_Libellé = "Année =" + pos.Année + ...
		"Produit = " + pos.Produit + ...
		"Ventes  = " + TCD_Statistiques.VAL_Ventes[pos]
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Champ Tableau croisé dynamique>.InfoXY(<X> , <Y>)
```

`<Résultat>` *Variable de type tcdPosition*
> Variable de type [tcdPosition](1000020726.md) contenant les caractéristiques de la cellule sélectionnée.
> Remarques :
>
>
> - Si la position ne correspond à aucune cellule du tableau croisé dynamique (-1,-1), la propriété **EnDehors** de la variable [tcdPosition](1000020726.md) vaut Vrai.
> - La position (0,0) correspond à la 1ère cellule en haut à gauche.
`<Champ Tableau croisé dynamique>` *Nom de champ*
> Nom du champ Tableau croisé dynamique à manipuler.
`<X>` *Entier*
> Coordonnée X (en pixels) à analyser. Cette coordonnée est relative à la zone cliente du champ.
`<Y>` *Entier*
> Coordonnée Y (en pixels) à analyser. Cette coordonnée est relative à la zone cliente du champ.

**Composante : wd300obj.dll**
