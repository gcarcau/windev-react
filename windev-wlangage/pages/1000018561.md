# sfRésultatRechercheModifié (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Le type **sfRésultatRechercheModifié** permet de connaître le résultat de la fonction [SFRechercheModifié](1000018554.md). Les caractéristiques de ce résultat peuvent être connues à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Connexion à Salesforce
Cnx est une sfConnexion
Cnx.Login = "balthazar@gmail.com"
Cnx.MotDePasse = "azerty" + "XXB12VCZ54"
SI SFConnecte(Cnx) = Faux ALORS
	Erreur("La connexion a échoué")
	RETOUR
FIN

ResRecupModif est un sfRésultatRechercheModifié
ResRecupModif = SFRechercheModifié(Cnx, "Mileage__c", "20090101", "20090131")

Identifiant est une chaîne
POUR TOUTE CHAÎNE Identifiant DE ResRecupModif.ID SÉPARÉE PAR RC
		Trace("--- ID : " + Identifiant)
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type sfRésultatRechercheModifié
Les propriétés suivantes peuvent être utilisées pour manipuler le résultat de la fonction [SFRechercheModifié](1000018554.md) :

| Nom | Type manipulé | Effet |
| --- | --- | --- |
| DernièreDateCouverte | DateHeure | Date de l'enregistrement le plus récent qui est retourné par la fonction [SFRechercheModifié](1000018554.md). Cette date est au format UTC.  **Cette propriété est disponible en lecture seulement**. |
| ID | Chaîne de caractères | Liste des identifiants Salesforce des enregistrements (objets Salesforce) modifiés. Les identifiants sont séparés par des RC (Retour-Chariot). |

## Remarques

### Fonctions utilisant le type sfRésultatRechercheModifié

| [SFRechercheModifié](1000018554.md) | Recherche et récupère les enregistrements (objets Salesforce) modifiés pendant la période spécifiée. |
| --- | --- |
