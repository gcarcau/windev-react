# Erreur 1046 : Mauvais paramètre pour le constructeur de la classe

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

## Cause

Vous tentez de définir un objet d'une classe. Le nombre de paramètres spécifiés ne correspond pas au nombre de paramètres attendus par la classe.

## Correction

Vérifiez les paramètres attendus par le constructeur de la classe et modifiez votre code.

## Exemple

### Passage de paramètres à un constructeur

**Code provoquant l'erreur**

```wlangage
// -- Code de clic sur le bouton BTN_CréerRondpDessin est un Rond dynamique = allouer un Rond(gpDessin, x, y, larg)
```

```wlangage
// -- Constructeur de la classe "Rond"PROCÉDURE Rond::Constructeur(pt, aa, bb, cc, dd)
```

**Correction proposée**

Passer le nombre de paramètres attendu.

```wlangage
// -- Code de clic sur le bouton BTN_CréerRondpDessin est un Rond dynamique = allouer un Rond(gpDessin, x, y, larg, haut) // -- Constructeur de la classe "Rond"PROCÉDURE Rond::Constructeur(pt, aa, bb, cc, dd)
```
