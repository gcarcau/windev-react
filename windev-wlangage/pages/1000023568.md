# <Graphe>.ChargeParamètre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Restaure les paramètres de dessin d'un graphe. Ces paramètres ont été sauvegardés par la fonction [<Graphe>.SauveParamètre](1000024127.md).
**Rappel** : Par défaut, les paramètres d'un graphe modifiés par l'utilisateur sont sauvegardés lors de l'arrêt de l'application. Ces paramètres sont automatiquement restaurés au prochain lancement de l'application.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
// Sauvegarde des paramètres d'un champ Graphe
INIEcrit("Parametres", "GRF_Graphe", "Param", GRF_Graphe.SauveParamètre())

// Restauration des paramètres d'un champ Graphe
GRF_Graphe.ChargeParamètre(INILit("Parametres", "GRF_Graphe", "Param"))
```

## Syntaxe

```wlangage
<Résultat> = <Champ Graphe>.ChargeParamètre(<Paramètres>)
```

`<Résultat>` *Booléen*
> - Vrai si le chargement des paramètres a été effectué,
> - Faux dans le cas contraire.
`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres, de pages ou d'états).
`<Paramètres>` *Chaîne de caractères Ansi*
> Paramètre à restaurer. Ce paramètre est dans un format compressé. Il peut uniquement être obtenu par la fonction [<Graphe>.SauveParamètre](1000024127.md). La valeur de ce paramètre peut être sauvegardée dans un fichier, un mémo ou dans la base de registre.
> Si ce paramètre correspond à une chaîne vide (""), la fonction n'a aucun effet et renvoie Faux.
