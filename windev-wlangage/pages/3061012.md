# GraveurSélectionne (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Permet de sélectionner le graveur utilisé par défaut. Ce graveur sera utilisé par défaut pour toutes les [fonctions de gravure](3061015.md) suivantes.
**Remarque** :

- Par défaut, le graveur utilisé correspond au premier graveur retourné par la fonction [GraveurListe](3061009.md).
- Lors de la sélection du graveur à utiliser par défaut, la compilation en cours est automatiquement supprimée.

> _(WEBDEV - Code Serveur)_ Le graveur en cours est accessible depuis le serveur Web.

## Exemple

```wlangage
// Connaître les graveurs installés
Liste_Graveur est une chaîne
Liste_Graveur = GraveurListe()
SI Liste_Graveur ~= "" ALORS
	Erreur("Aucun graveur n'a été détecté sur ce poste")
	RETOUR
FIN
// Remplissage de la table TABLE_Graveur avec la liste des graveurs
UnGraveur, CheminGraveur sont des chaînes

POUR CHAQUE CHAÎNE UnGraveur DE Liste_Graveur SÉPARÉE PAR RC
	// Sélection du graveur
	SI GraveurSélectionne(ExtraitChaîne(UnGraveur, 1)) = Faux ALORS
		Erreur("Echec de la sélection de graveur", ErreurInfo())
		RETOUR
	FIN
	// Chemin du graveur en cours
	CheminGraveur = GraveurChemin()
	// Ajout dans la table
	TableAjouteLigne(TABLE_Graveur, CheminGraveur, UnGraveur)
FIN
```

## Syntaxe

```wlangage
<Résultat> = GraveurSélectionne(<Graveur>)
```

`<Résultat>` *Booléen*
> - Vrai si le graveur a été sélectionné,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Graveur>` *Entier ou chaîne de caractères*
> Indice ou identifiant du graveur renvoyé par la fonction [GraveurListe](3061009.md).

## Remarques

### Compilation
Les [fonctions de gravure](3061015.md) sont disponibles uniquement sous Windows XP et supérieur.
Une compilation correspond à l'ensemble des fichiers à graver sur un CD ou DVD. Cette compilation sera prise en compte lors du prochain appel de la fonction [GraveurEnregistre](3061006.md).

Une compilation est automatiquement créée lors du premier appel de la fonction [GraveurAjouteFichier](3061001.md) ou de la fonction [GraveurAjouteRépertoire](3061002.md). Une seule compilation à la fois peut être créée.

Une compilation est automatiquement supprimée :

- soit lors du changement du type du CD/DVD à graver (fonction [GraveurTypeMédia](3061013.md)).
- soit lors de la sélection du graveur utilisé par défaut (fonction **GraveurSélectionne**).
- soit après l'appel de la fonction [GraveurEnregistre](3061006.md) (uniquement si la gravure a été lancée, <Résultat> à Vrai).
- soit lors de l'annulation de la gravure (fonction [GraveurAnnuleGravure](3061003.md)).
- soit lors de la fermeture de l'application WINDEV ou du site WEBDEV en cours.

### Configuration nécessaire

> _(WINDEV, WEBDEV - Code Serveur)_ La gravure de CD est disponible uniquement sous Windows XP et supérieur. La gravure de DVD est disponible sous Windows Vista, et sous Windows XP en utilisant la mise à jour KB932716 pour Windows XP (cette mise à jour doit être téléchargée depuis le site de Microsoft et installée car elle n'est pas prise en compte par le mécanisme de Live Update). La gravure de CD et DVD sera réalisée sur le serveur Web. Pour graver des CD ou des DVD, le serveur doit être sous Windows XP ou supérieur. Pour graver des CD sous Windows 2003 Serveur, il est nécessaire d'activer le service de gravure IMAPI (nommée "Service COM de gravage de CD IMAPI"). Pour graver des DVD sous Windows 2003 Serveur, il est nécessaire d'installer en plus la mise à jour KB932716.
