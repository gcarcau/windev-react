# <Agenda>.SupprimeRendezVous (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Mac Catalyst)

Supprime un rendez-vous dans un champ Agenda. Si le champ Agenda est lié à une source de données, le rendez-vous est également supprimé dans la source de données.

## Exemple

```wlangage
// Supprime le rendez-vous sélectionné dans le champ Agenda AGD_Agenda1.SupprimeRendezVous()
```

```wlangage
// Supprime le premier rendez-vous ajoutéAGD_Agenda1.SupprimeRendezVous(1)
```

## Syntaxe

```wlangage
<Champ Agenda>.SupprimeRendezVous([<Indice du rendez-vous>])
```

`<Champ Agenda>` *Nom de champ*
> Nom du champ Agenda à manipuler. Ce champ peut correspondre :
>
> - au champ Agenda d'une fenêtre.
> - au champ Agenda d'un état.
> - au champ Agenda d'une page.
`<Indice du rendez-vous>` *Entier optionnel*
> Indice du rendez-vous à supprimer. Le premier rendez-vous a pour indice 1. Si ce paramètre n'est pas précisé, le rendez-vous sélectionné sera supprimé.

> _(WINDEV, WEBDEV - Code Serveur, iPhone/iPad, WINDEV, iPhone/iPad, Mac Catalyst, WEBDEV - Code Serveur)_ Supprimer un rendez-vous identifié par une variable de type RendezVous Masquer les détails
<Champ Agenda>.SupprimeRendezVous([<Rendez-vous à supprimer>])

 <Champ Agenda> : Nom de champNom du champ Agenda à manipuler. Ce champ peut correspondre : au champ Agenda d'une fenêtre. au champ Agenda d'un état. au champ Agenda d'une page. <Rendez-vous à supprimer> : Variable de type RendezVousNom de la variable de type RendezVous correspondant au rendez-vous à supprimer. Si ce paramètre n'est pas précisé, le rendez-vous sélectionné sera supprimé.

> _(WINDEV, WEBDEV - Code Serveur, iPhone/iPad, WINDEV, iPhone/iPad, Mac Catalyst, WEBDEV - Code Serveur)_ Supprimer plusieurs rendez-vous Masquer les détails
<Champ Agenda>.SupprimeRendezVous([<Rendez-vous à supprimer>])

 <Champ Agenda> : Nom de champNom du champ Agenda à manipuler. Ce champ peut correspondre : au champ Agenda d'une fenêtre. au champ Agenda d'un état. au champ Agenda d'une page. <Rendez-vous à supprimer> : Tableau de variables de type RendezVousNom de la variable de type Tableau de RendezVous correspondant aux rendez-vous à supprimer. Si ce paramètre n'est pas précisé, le rendez-vous sélectionné sera supprimé.
