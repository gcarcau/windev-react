# ClavierVisible (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Permet de rendre le clavier visible.
> _(iPhone/iPad)_ Sous iOS, il est uniquement possible de rendre un clavier invisible.

## Syntaxe

```wlangage
<Résultat> = ClavierVisible(<Visible/Invisible>)
```

`<Résultat>` *Booléen*
> - Vrai si le clavier en cours était visible avant l'appel de cette fonction,
> - Faux dans le cas contraire.
>
>
> > _(Android, Widget Android)_ <Résultat> est toujours à Vrai.
`<Visible/Invisible>` *Booléen*
> - Vrai pour rendre le clavier en cours visible,
> - Faux pour rendre le clavier en cours invisible.
>
>
> > _(iPhone/iPad)_ Il est uniquement possible de rendre le clavier invisible. Seule la valeur Faux peut être utilisée pour ce paramètre.

## Remarques

### Option "Activer le clavier en saisie"
L'option "Activer le clavier en saisie" (onglet "Détail" de la fenêtre de description d'un champ de saisie) permet de rendre visible automatiquement le clavier en cours lorsque le champ est en saisie.

### Gestion des erreurs
**Attention** : La fonction **ClavierVisible** ne retourne pas de code d'erreur. Pour savoir si cette fonction a généré une erreur, utilisez la variable [ErreurDétectée](3087001.md). En cas d'erreur, il est possible de connaître le détail de l'erreur grâce à la fonction [ErreurInfo](3013008.md).
