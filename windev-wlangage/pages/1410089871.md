# NotifPushDésabonne (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android)

Désabonne l'application Android des notifications push envoyées pour le sujet spécifié. L'application ne recevra plus les notifications push envoyées avec la fonction [NotifPushEnvoieAbonné](1410089872.md) pour le sujet spécifié.

## Exemple

```wlangage
// L'application ne recevra plus les notifications push relatives au thème "score"
NotifPushDésabonne("score")
```

## Syntaxe

```wlangage
<Résultat> = NotifPushDésabonne(<Sujet>)
```

`<Résultat>` *Booléen*
> - Vrai si le désabonnement a été effectué,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet de connaître l'erreur renvoyée par le service de notification.
`<Sujet>` *Chaîne de caractères*
> Sujet (ou topic) associé aux notifications push auxquelles l'application veut se désabonner.

**Composante : wd300android.jar**
