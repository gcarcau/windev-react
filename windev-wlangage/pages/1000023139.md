# xlsMiseEnPage (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

Le type **xlsMiseEnPage** permet de définir toutes les caractéristiques de mise en page pour l'impression d'une feuille d'un document XLSX présente dans un champ Tableur. Les caractéristiques de cette mise en page peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

Nouveauté 2025

> _(iPhone/iPad)_ Ce type de variable est désormais disponible pour les applications iPhone/iPad.

## Exemple

```wlangage
// Feuille en cours [SansMarges]
xMiseEnPage est un xlsMiseEnPage  = TBLR_ChampTableur.MiseEnPage
xMiseEnPage.MargeGauche = 0
xMiseEnPage.MargeDroite = 0
TBLR_ChampTableur.MiseEnPage = xMiseEnPage
```

## Propriétés

### Propriétés spécifiques à la description des variables de type xlsMiseEnPage
Les propriétés suivantes peuvent être utilisées pour manipuler une mise en page d'un document XLSX :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| EntêteImprimé | Booléen | - Vrai (valeur par défaut) pour imprimer l’entête de la feuille. - Faux dans le cas contraire. |
| EntêteVisible | Booléen | - Vrai (valeur par défaut) pour visualiser l'entête de la feuille dans le champ Tableur. - Faux dans le cas contraire. |
| HautDePage | Réel | Hauteur du haut de page dans la feuille imprimée, exprimée en millimètres. |
| HauteurPage | Réel | Hauteur de la page imprimée, exprimée en millimètres. |
| LargeurPage | Réel | Largeur de la page imprimée, exprimée en millimètres. |
| MargeBasse | Réel double | Marge basse de la page imprimée, exprimée en millimètres. |
| MargeDroite | Réel | Marge droite de la page imprimée, exprimée en millimètres. |
| MargeGauche | Réel | Marge gauche de la page imprimée, exprimée en millimètres. |
| MargeHaute | Réel | Marge haute de la page imprimée, exprimée en millimètres. |
| ModeAjustement | Constante de type entier | - *modeAjustementAucun* : Aucune mise à l'échelle n'est effectuée. - *modeAjustementColonnes* : Toutes les colonnes sont ajustées à la largeur du champ. - *modeAjustementLignes* : Toutes les lignes sont ajustées à la hauteur du champ. - *modeAjustementLignesEtColonnes* : La feuille de calcul est ajustée aux dimensions du champ Tableur. |
| OrientationPaysage | Booléen | - Vrai (valeur par défaut) pour une orientation en mode paysage, - Faux pour une orientation en mode portrait. |
| PiedDePage | Réel | Hauteur du pied de page dans la page imprimée, exprimée en millimètres. |
| QuadrillageImprimé | Booléen | - Vrai (valeur par défaut) pour imprimer le quadrillage autour des cellules, - Faux pour imprimer sans quadrillage. |
| QuadrillageVisible | Booléen | - Vrai (valeur par défaut) pour visualiser dans le champ Tableur le quadrillage autour des cellules, - Faux dans le cas contraire. |
