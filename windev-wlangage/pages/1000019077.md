# Fonctions Upload (syntaxe préfixée)

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

Les fonctions (syntaxe préfixée) de gestion de l'upload de fichiers sont les suivantes :

| [<Upload>.CopieFichier](1000019046.md) | Enregistre sur le serveur un fichier "uploadé" par l'internaute. |
| --- | --- |
| [<Upload>.FichierEnCours](1000019047.md) | Indique le fichier en cours d'upload via le champ Upload. |
| [<Upload>.Lance](1000019063.md) | Lance l'envoi des fichiers sélectionnés dans un champ Upload. |
| [<Upload>.NomFichier](1000019064.md) | Renvoie le nom d'un fichier "uploadé" par l'internaute. Cet upload a pu être effectué :   - via un champ de saisie de type "Upload". - via un champ Upload monofichier ou multifichier. |
| [<Upload>.Supprime](1000019065.md) | Supprime un fichier de la liste des fichiers à uploader : le fichier ne sera pas uploadé sur le serveur. |
| [<Upload>.SupprimeTout](1000019069.md) | Vide la liste des fichiers à uploader : aucun fichier ne sera uploadé sur le serveur. |
| [<Upload>.Taille](1000019070.md) | Renvoie la taille totale (en octets) des fichiers de l'upload en cours via un champ Upload. |
| [<Upload>.TailleEnvoyée](1000019071.md) | Renvoie la taille totale (en octets) des fichiers déjà envoyés par l'upload en cours via un champ Upload. |
| [<Upload>.TailleEnvoyéeFichierEnCours](1000019074.md) | Renvoie la taille (en octets) déjà envoyée du fichier en cours d'upload via un champ Upload. |
| [<Upload>.TailleFichier](1000019075.md) | Renvoie la taille totale (en octets) d'un fichier présent dans un champ Upload. |
| [<Upload>.TailleFichierEnCours](1000019076.md) | Renvoie la taille totale (en octets) du fichier en cours d'upload via un champ Upload. |
