# NomFeuille (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **NomFeuille** permet de connaître et de modifier le nom d'une feuille dans un document XLS. Cette propriété est utilisable sur :

- Un champ Tableur. Pour plus de détails, consultez l'aide de la propriété [NomFeuille](1000021646.md).
- Une variable de type [xlsDocument](1000017464.md).
