# Fonctions FTP WINDEV

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

**Avertissement**

 Les fonctions permettant de gérer le FTP/RPC WINDEV sont conservées par compatibilité. Il est conseillé d'utiliser un serveur FTP, SSH ou SCP standard. Pour plus de détails, consultez [Manipuler des fichiers sur un serveur FTP](3040009.md).

| [NetAdresseIP](3056023.md) | Renvoie l'adresse IP (Internet Protocol) d'un poste. |
| --- | --- |
| [NetAdresseMAC](1000016006.md) | Renvoie l'adresse MAC (adresse physique) de l'une des cartes réseau de la machine. |
| [NetConnecte](3056004.md) | Connecte à un serveur FTP (File Transfer Protocol) ou RPC (Remote Procedure Call) réalisé avec WINDEV. **Cette fonction est conservée par compatibilité**. |
| [NetDéconnecte](3056011.md) | Déconnecte d'un serveur FTP (File Transfer Protocol) ou RPC (Remote Procedure Call) réalisé avec WINDEV. **Cette fonction est conservée par compatibilité**. |
| [NetDémarreServeur](3056013.md) | Lance un serveur FTP (File Transfer Protocol) ou RPC (Remote Procedure Call) réalisé avec WINDEV. **Cette fonction est conservée par compatibilité**. |
| [NetEnvoieBuffer](3056001.md) | Transmet une chaîne de caractères à un serveur FTP (File Transfer Protocol) ou RPC (Remote Procedure Call) réalisé avec WINDEV. **Cette fonction est conservée par compatibilité**. |
| [NetEnvoieFichier](3056005.md) | Transmet un fichier à un serveur FTP (File Transfer Protocol) réalisé avec WINDEV. **Cette fonction est conservée par compatibilité**. |
| [NetEnvoieMessage](3056003.md) | Déclenche un événement Windows sur le système d'un poste serveur FTP (File Transfer Protocol) ou RPC (Remote Procedure Call) réalisé avec WINDEV. **Cette fonction est conservée par compatibilité**. |
| [NetEnvoieMessageClient](3056007.md) | Envoie un message du poste serveur vers tous les postes clients connectés. **Cette fonction est conservée par compatibilité**. |
| [NetExécute](3056002.md) | Exécute un programme spécifique sur un serveur FTP (File Transfer Protocol) ou RPC (Remote Procedure Call) réalisé avec WINDEV. **Cette fonction est conservée par compatibilité**. |
| [NetFermeAccèsDistant](3056021.md) | Ferme la ligne précédemment ouverte par la fonction [NetOuvreAccèsDistant](3056026.md). |
| [NetFinServeur](3056024.md) | Arrête un serveur FTP (File Transfer Protocol) ou RPC (Remote Procedure Call) réalisé avec WINDEV et précédemment lancé avec la fonction [NetDémarreServeur](3056013.md). **Cette fonction est conservée par compatibilité**. |

| [NetListeAdresseIP](1000019683.md) | Renvoie la liste des adresses IP (Internet Protocol) d'une machine. |

| [NetListeRep](3056016.md) | Liste les répertoires et les fichiers présents :   - sur le poste serveur FTP (File Transfer Protocol) ou RPC (Remote Procedure Call) réalisé avec WINDEV, - sur le poste client.   **Cette fonction est conservée par compatibilité**. |
| [NetMACVersIP](1000016004.md) | Renvoie l'adresse IP correspondant à une adresse MAC donnée. |

| [NetMsgErreur](3056019.md) | Renvoie le message d'erreur correspondant au numéro d'erreur retourné par les fonctions [NetOuvreAccèsDistant](3056026.md) et [NetFermeAccèsDistant](3056021.md). |
