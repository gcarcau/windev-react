# Clé (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **Clé** permet de gérer les clés :

- dans une variable de type [xmlSignature](1000020736.md).
- dans une variable de type [memcachedRésultat](1000023359.md).
- dans une variable de type [xmlVérificationSignature](1410090389.md).
- Nouveauté Abonnement
   dans une variable de type [xmlSignatureXAdES](1410091158.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
