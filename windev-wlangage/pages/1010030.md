# Plateforme d'exécution

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

WINDEV Mobile vous permet de développer des applications pour différentes familles de produits :

- Android,
- iPhone et/ou iPad,

Voyons en détail chaque plateforme :

- **Android** : WINDEV Mobile affiche la liste des plateformes créées pour Android. Il est possible d'éditer la description de la plateforme ou d'en ajouter une supplémentaire.
  Lors de l'ajout d'une plateforme, sélectionnez la plateforme et la résolution voulue.
   Lors de la modification d'une plateforme, il est alors possible de définir :
  - le type d'écran utilisé. Les caractéristiques de taille, de DPI, peuvent être directement modifiées (dans ce cas, la taille devient une taille personnalisée).
  - l'image utilisée en mode test. Cette image permet de tester votre application dans un environnement correspondant à l'environnement de vos utilisateurs.
  - le chemin du SDK Android utilisé. Pour plus de détails, consultez [Installation du SDK Android](9000042.md).

- **iOS** : Pour les plateformes iOS (iPhone, iPad), sélectionnez l'appareil à utiliser pour l'édition de l'application (iPhone ou iPad).

L'ensemble de ces caractéristiques constituent la plateforme d'exécution.

## Quand est-ce que la plateforme d'exécution est prise en compte ?

La plateforme d'exécution sélectionnée est prise en compte :

- **pour la création des fenêtres** : les dimensions sélectionnées seront automatiquement proposées pour les nouvelles fenêtres.
- **pour la génération de l'application**. En effet, l'application générée correspond à une plateforme spécifique.
- **lors du lancement de l'application en mode test**. La plateforme sélectionnée permet d'utiliser le simulateur correspondant.

## Comment modifier la plateforme d'exécution ?

La plateforme d'exécution peut être modifiée dans la description du projet :

1. Sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description".
2. Dans l'onglet "Projet", cliquez sur le bouton "Description de la plateforme courante".

La plateforme sélectionnée est valide pour tout le projet en cours.

> _(Android)_ Détection automatiqueWINDEV Mobile propose de détecter automatiquement les caractéristiques de la plateforme connectée au poste en cours (bouton "Détecter les caractéristiques automatiquement"). Si les caractéristiques de la plateforme connectée sont différentes de la plateforme sélectionnée, WINDEV Mobile affiche les éléments différents et modifie ces éléments si nécessaire.Lors de la création d'un nouveau projet, si un mobile sous Android est connecté au poste en cours, WINDEV Mobile détecte automatiquement les caractéristiques de la plateforme connectée.
