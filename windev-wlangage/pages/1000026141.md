# Fonctions WebSocket (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

Les fonctions utilisables dans un projet de type Serveur de WebSocket (syntaxe préfixée) sont les suivantes :

| [<Variable websocketClient>.Déconnecte](1000026067.md) | Déconnecte un client actuellement connecté sur un serveur de WebSocket. |
| --- | --- |
| [<Variable websocketClient>.Envoie](1000026068.md) | Envoie un message pour un client du serveur de WebSocket. |
| [<Variable websocketClient>.Exécute](1000026113.md) | Exécute une procédure globale dans le contexte d'un client connecté au serveur de WebSocket. |
