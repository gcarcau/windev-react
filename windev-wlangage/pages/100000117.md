# Erreur 117 : Le tableau possède X dimensions et vous y accédez avec Y dimensions

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

## Cause

Vous manipulez un tableau en prenant en compte plus de dimensions qu'il n'en a été défini.

## Correction

Modifiez la déclaration de votre tableau ou la syntaxe permettant de manipuler un élément du tableau.

## Exemple

### Manipulation d'un tableau déclaré avec une seule dimension

**Code provoquant l'erreur**

```wlangage
// Déclaration du tableauVenteMin est un tableau de 12 entiersi est un entier = 1// Affectation d'un élément de VenteMinVenteMin[15,2]=15
```

**Correction proposée**

Modification de la déclaration du tableau.

```wlangage
// Déclaration du tableauVenteMin est un tableau de 12 par 15 entiersi est un entier = 1// Affectation d'un élément de VenteMinVenteMin[15,2]=15
```

**Correction proposée**

Modification de l'affectation.

```wlangage
// Déclaration du tableauVenteMin est un tableau de 12 entiersi est un entier = 1// Affectation d'un élément de VenteMinVenteMin[2]=15
```
