# XMLAnnuleRecherche (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Annule la recherche effectuée par la fonction [XMLRecherche](3081025.md).

## Exemple

```wlangage
// Recherche de la balise "<prix>"
XMLRecherche("DocXML", "prix", XMLBalise)
TANTQUE XMLTrouve("DocXML") = Vrai
	Info("Balise trouvée " + XMLNomElément("DocXML"))
	XMLSuivant("DocXML")
FIN

// Annule la recherche en cours
XMLAnnuleRecherche("DocXML")

// Reprise d'un parcours standard
XMLPremier("DocXML")
TANTQUE XMLEnDehors("DocXML") = Faux
	// Opérations
	XMLSuivant("DocXML")
FIN
```

## Syntaxe

```wlangage
XMLAnnuleRecherche(<Document XML>)
```

`<Document XML>` *Chaîne de caractères*
> Nom du document XML dans lequel la recherche doit être annulée. Ce document contient le code XML et a été créé avec la fonction [XMLDocument](3081008.md).

**Composante : wd300xml.dll**
