# Fonctions de gestion des champs Table (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions (syntaxe préfixée) de gestion des champs Table sont les suivantes :

| [<Table>.Affiche](1000023505.md) | Rafraîchit l'affichage d'un champ Table ou Table hiérarchique à partir d'une position donnée :  - pour un champ lié à un fichier : les modifications effectuées sur le fichier de données lié sont répercutées dans le champ. - pour un champ manipulé par programmation : les colonnes calculées sont re-calculées. |
| --- | --- |
| [<Table>.Ajoute](1000023600.md) | Ajoute une ligne dans :   - un champ Table, - un champ Table hiérarchique, - un champ "Combo avec table" (champ Table affiché dans un champ Combo). |
| [<Table>.AjouteColonne](1000023607.md) | Ajoute des éléments à droite d'un champ Table horizontale. |
| Nouveauté 2025 [<Table>.AjouteDébut](1410090638.md) | Ajoute une ligne au début d'un champ Table infinie. La ligne est insérée avant la première ligne du champ Table. La position de défilement du champ Table n'est pas modifiée. |
| [<Table>.AjouteLigne](1000023404.md) | Ajoute une ligne dans :   - un champ Table, - un champ Table hiérarchique. |
| [<Table>.AjouteLigneAvecAnimation](1000023678.md) | Ajoute une ligne dans un champ Table ou un champ Table hiérarchique avec une animation. |
| [<Table>.AjoutEnCours](1000023838.md) | Modifie ou renvoie l'état de visibilité de la fenêtre interne de patience lors de l'ajout d'éléments supplémentaires dans un champ Table infinie. |
| [<Table>.AjouteSurEntête](1000023839.md) | Ajoute un sur-entête de colonnes dans un champ Table ou dans un champ Table hiérarchique d'une fenêtre. |
| [<Table>.Ajuste](1000023840.md) | Ajuste le titre et la taille des colonnes d'un champ Table ou Table hiérarchique. |
| [<Table>.CelluleSelect](1000023841.md) | Renvoie les coordonnées (numéro de ligne et numéro de colonne) d'une cellule sélectionnée. Cette fonction est conservée par compatibilité. Il est conseillé d'utiliser la fonction TableSelect. |
| [<Table>.CelluleSelectOccurrence](1000023842.md) | Renvoie le nombre de cellules sélectionnées dans un champ Table. Cette fonction est conservée par compatibilité. Il est conseillé d'utiliser la fonction TableSelectOccurrence. |
| [<Table>.CherchePartout](1410088374.md) | Recherche une valeur dans toutes les colonnes des champs suivants :   - champ Table, - champ Table hiérarchique, - champ Table affiché dans un champ Combo. |
| [<Table>.ColonnesFiltrées](1000024053.md) | Renvoie la liste des colonnes filtrées par l'utilisateur dans un champ Table ou Table hiérarchique. |
| [<Table>.ColonnesTriées](1000024054.md) | Renvoie la liste des colonnes triées d'une table. |
| [<Table>.DébutRemplissage](1000024055.md) | Indique le début du remplissage d'un champ Table (ou Table hiérarchique) par programmation. |
| [<Table>.DéplaceColonne](1000024244.md) | Déplace une colonne d'un champ Table ou Table hiérarchique. |
| [<Table>.DéplaceLigne](1000024245.md) | Déplace une ligne ou échange deux lignes dans un champ Table. |
| [<Table>.DepuisJSON](1410090403.md) | Initialise le contenu d'un champ Table ou Table hiérarchique à partir d'une chaîne JSON ou d'une variable JSON. |
| [<Table>.DésactiveFiltre](1000024246.md) | Annule un filtre utilisateur sur une colonne ou toutes les colonnes d'un champ Table ou Table hiérarchique. |
| [<Table>.DonneFocus](1000024247.md) | Donne le focus à une ligne d'un champ Table ou Table hiérarchique : le champ passe en saisie pour la ligne et la colonne spécifiée. |
| [<Table>.EchangeLigne](1000024248.md) | Echange :   - deux lignes dans un champ Table par programmation. - deux branches dans un champ Table hiérarchique par programmation. |
| [<Table>.Enregistre](1000024249.md) | Modifie ou ajoute l'enregistrement associé à la ligne en cours dans le champ Table fichier ou Table hiérarchique fichier. |
| [<Table>.EnrouleDéroule](1000024802.md) | Enroule ou déroule un élément d'un champ Table ou Table hiérarchique. |
| [<Table>.EnumèreColonne](1000024250.md) | Renvoie le nom d'une colonne d'un champ Table ou Table hiérarchique. |
| [<Table>.EnumèreRupture](1000024251.md) | Enumère les ruptures d'un champ Table. |
| [<Table>.Fin](1000024294.md) | Arrête le parcours manuel du fichier de données lié à un champ Table fichier. |
| [<Table>.FinRemplissage](1000024252.md) | Indique la fin du remplissage d'un champ Table ou Table hiérarchique par programmation. |
| [<Table>.FixeColonne](1000024253.md) | Fixe une colonne à gauche ou libère une colonne fixée à gauche. |
| [<Table>.FormuleAjoute](1000024254.md) | Ajoute une ligne calculée dans un champ Table en fournissant des procédures de calculs personnalisées. |
| [<Table>.FormuleSupprimeTout](1000024255.md) | Supprime toutes les lignes ajoutées avec la fonction <Table>.FormuleAjoute. |
| [<Table>.Imprime](1000024256.md) | Imprime directement le contenu du champ Table spécifié sans avoir réalisé au préalable un état sur le champ Table. |
| [<Table>.IndiceColonne](1000024257.md) | Renvoie l'indice d'une colonne dans un champ Table ou Table hiérarchique. |
| [<Table>.IndiceRupture](1000024258.md) | Renvoie l'indice du haut et du bas de rupture d'une rupture donnée dans un champ Table. |
| [<Table>.InfoXY](1000024259.md) | Renvoie pour une position donnée dans un champ Table ou Table hiérarchique (coordonnées d'un point du champ) :  - soit le nom de la colonne affichée pour la position indiquée. - soit l'indice de la ligne ou de la colonne pour la position indiquée. |
| [<Table>.Insère](1000024260.md) | Insère une ligne dans :   - un champ Table, - un champ Table hiérarchique, - une table affichée dans un champ Combo. |
| [<Table>.InsèreColonne](1000024261.md) | Insère des éléments sous forme de colonne dans ***un champ Table horizontale***. |
| [<Table>.InsèreLigne](1000023407.md) | Insère une ligne dans :   - un champ Table, - un champ Table hiérarchique. |
| [<Table>.InsèreLigneAvecAnimation](1000024272.md) | Insère une ligne dans un champ Table ou un champ Table hiérarchique avec une animation. |
| [<Table>.Modifie](1000024273.md) | Modifie une ligne dans :   - un champ Table, - un champ Table hiérarchique, - une table affichée dans un champ Combo. |
| [<Table>.ModifieColonne](1000024274.md) | Modifie une colonne dans un champ Table horizontale. |
| [<Table>.ModifieLigne](1000024275.md) | Modifie une ligne dans :   - un champ Table, - un champ Table hiérarchique. |
| [<Table>.NumEnr](1000024276.md) | Renvoie le numéro de l'enregistrement en cours dans un champ Table fichier. |
| [<Table>.Occurrence](1000024277.md) | Renvoie :   - soit le nombre de colonnes présentes dans un champ Table ou Table hiérarchique. - soit le nombre de lignes présentes dans un champ Table ou Table hiérarchique. |
| [<Table>.Position](1000024278.md) | Affiche un champ Table ou Table hiérarchique à partir d'une ligne spécifiée ou renvoie l'indice de la première ligne affichée dans un champ Table ou Table hiérarchique. |
| [<Table>.RafraîchissementVisible](1000024279.md) | Modifie ou renvoie l'état de visibilité du bandeau de rafraîchissement d'un champ Table ou Table hiérarchique. |

| [<Table>.SaisieEnCours](1000024281.md) | Indique si un champ Table ou Table hiérarchique est en cours de saisie. |
| [<Table>.SaisieLoupe](1000024282.md) | Passe en saisie la zone de recherche présente dans le titre de colonne du champ Table ou Table hiérarchique. |
| [<Table>.SauvePositionEtSélection](1000024283.md) | Sauve :   - la position de l'ascenseur d'un champ Table ou d'un champ Table hiérarchique, - le ou les éléments sélectionnés dans le champ. |
| [<Table>.Select](1000024284.md) | Renvoie l'indice de l'élément sélectionné dans le champ Table ou Table hiérarchique. |
| [<Table>.SelectMoins](1000024285.md) | Dé-sélectionne une ligne dans un champ Table ou Table hiérarchique. |
| [<Table>.SelectOccurrence](1000024286.md) | Renvoie le nombre d'éléments sélectionnés dans un champ Table ou Table hiérarchique (notamment dans le cas d'un champ multi-sélections). |
| [<Table>.SelectPlus](1000024287.md) | Sélectionne une ligne dans un champ Table ou Table hiérarchique. |
| [<Table>.SelectVersFichier](1000024288.md) | Positionne sur l'enregistrement du fichier de données correspondant à une ligne sélectionnée dans le champ Table fichier multisélection. |
| [<Table>.Supprime](1000024289.md) | Supprime une ligne dans :   - un champ Table, - un champ Table hiérarchique, - une table affichée dans un champ Combo. |

| [<Table>.SupprimeTout](1000024292.md) | Supprime toutes les lignes dans :   - un champ Table par programmation, - un champ Table hiérarchique par programmation, - une table affichée dans un champ Combo. |
