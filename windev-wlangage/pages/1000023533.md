# <Graphe>.AjouteDonnée (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Ajoute une donnée dans un graphe.
**Attention** : Pour les types de graphes "avancés", il existe une fonction WLangage spécifique pour ajouter les données (voir paragraphe "Remarques").

> _(WEBDEV - Code Serveur, Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
// Ajout d'une donnée dans le champ "GRF_MonGraphe".
// Cette donnée de valeur 10, est ajoutée à la fin de la première série.
GRF_MonGraphe.AjouteDonnée(1, 10)
```

```wlangage
// Courbe de 9 valeurs : si l'option "Dessin des valeurs manquantes" correspond à "Non dessinées",
// seul le point 3 n'est pas dessiné, les points 8 et 9 sont dessinés (à zéro)
GRF_MonGraphe.AjouteDonnée(1, 1, 50)
GRF_MonGraphe.AjouteDonnée(1, 2, 30)
GRF_MonGraphe.AjouteDonnée(1, 3, 30) // pas dessiné
GRF_MonGraphe.AjouteDonnée(1, 4, 30)
GRF_MonGraphe.AjouteDonnée(1, 5, 60)
GRF_MonGraphe.AjouteDonnée(1, 6, 60)
GRF_MonGraphe.AjouteDonnée(1, 7, 0) // dessiné dans tous les cas,
GRF_MonGraphe.AjouteDonnée(1, 8, Null) // dessiné dans tous les cas,
GRF_MonGraphe.AjouteDonnée(1, 9, 60)
GRF_MonGraphe.Dessine()
```

## Syntaxe

```wlangage
<Champ Graphe>.AjouteDonnée(<Numéro de la série> [, <Indice>] , <Valeur>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres, de pages ou d'états).
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Numéro de la série>` *Entier*
> Numéro de la série dans laquelle une valeur doit être ajoutée.
> Par exemple, si le champ Graphe affiche 2 courbes, ce paramètre permet d'identifier la courbe pour laquelle la donnée doit être ajoutée.
> Si le numéro spécifié n'existe pas, les séries comprises entre la dernière série existante et le numéro spécifié sont automatiquement créées et initialisées à 0.
`<Indice>` *Entier optionnel*
> Indice de la donnée dans la série où une valeur doit être ajoutée.
> Par exemple, pour un graphe de type Courbe, ce paramètre correspond à l'abscisse de la valeur à ajouter.
> Si ce paramètre :
>
>
> - n'est pas spécifié, la valeur est ajoutée à la fin de la série.
> - est spécifié, l'ancienne valeur est remplacée.
>
>
> > _(Android)_ L'indice de la donnée dans la série doit être un entier strictement positif.
`<Valeur>` *Entier ou réel*
> Valeur à ajouter.
> Par exemple, pour un graphe de type Courbe, ce paramètre correspond à l'ordonnée de la valeur à ajouter.

## Remarques

### Ajout de données

- Les données ajoutées avec la fonction **<Graphe>.AjouteDonnée** seront prises en compte lors du prochain appel à la fonction [<Graphe>.Dessine](1000024062.md).
- Pour un graphe de type Secteur (constante *grSecteur*), seules les données de la première série sont utilisées. Il est impossible de dessiner un graphe de type Secteur si toutes les données de la première série sont nulles.
- Pour les graphes de type "Histogramme empilé", si la valeur de la première série est négative, la barre correspondante est orientée vers le bas.

### Ajout de données dans les différents types de graphes

- Pour les graphes de type Nuage de points, il est conseillé d'utiliser la fonction [<Graphe>.NuageAjouteDonnéeXY](1000024105.md).
- Pour les graphes boursiers, il est conseillé d'utiliser la fonction [<Graphe>.BourseAjouteDonnée](1000023565.md).
- Pour les graphes Heatmap, il est conseillé d'utiliser la fonction [<Graphe>.HMAjouteDonnée](1000024079.md).
- Pour les graphes Secteur Multiniveau, il est conseillé d'utiliser la fonction [<Graphe>.SMNAjouteDonnée](1000024132.md).
- Pour les graphes de type Surface, il est conseillé d'utiliser la fonction [<Graphe>.SurfaceAjouteDonnée](1000024143.md).
- Pour les graphes circulaires de progrès, il est conseillé d'utiliser la fonction [<Graphe>.CPAjouteDonnée](1410088092.md).
- Pour ajouter une valeur à une donnée d'un graphe, utilisez la fonction [<Graphe>.IncrémenteDonnée](1000024086.md).
