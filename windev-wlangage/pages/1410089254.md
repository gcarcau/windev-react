# <Variable Image>.DessineTexteMarkdown (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Dessine un texte au format Markdown dans une variable de type [Image](1000019650.md).

## Exemple

```wlangage
MonImage est une Image
// Dessin d'un texte au format Markdown en 8,10 dans la variable MonImage
s est chaîne = [
# Titre
Ligne 2 avec du **gras**
*Italique* sur la ligne 3
]
MonImage.Police("Arial", 16)
MonImage.Stylo(VertClair) // texte en vert clair
MonImage.DessineTexteMarkdown(8, 10, s, MonImage.Largeur-16)
```

## Syntaxe

```wlangage
<Variable Image>.DessineTexteMarkdown(<Abscisse> , <Ordonnée> , <Texte Markdown> [, <Couleur du texte>])
```

`<Variable Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) à manipuler.
`<Abscisse>` *Entier*
> Coordonnées (abscisse) du texte à dessiner (en pixels).
`<Ordonnée>` *Entier*
> Coordonnées (ordonnée) du texte à dessiner (en pixels).
`<Texte Markdown>` *Type correspondant au texte à dessiner*
> Texte Markdown à dessiner.
`<Couleur du texte>` *Entier ou constante (optionnel)*
> Couleur du texte Markdown à utiliser. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md).
>
>
> Si ce paramètre n'est pas précisé, la couleur du texte :
>
>
> - est Noire si la fonction [<Image>.Stylo](1000024016.md) n'a pas été utilisée auparavant,
> - correspond à la couleur précisée dans le dernier appel à la fonction [<Image>.Stylo](1000024016.md).

## Remarques

### Police
Par défaut :

- La police utilisée est la police "MS Sans Serif" (taille 13).
- Le sens d'écriture est horizontal (de gauche à droite).
- L'angle haut gauche de l'image a les coordonnées (0,0).
- Le caractère "&" n'est pas interprété.

Pour modifier ces paramètres, utilisez la fonction [<Variable Image>.Police](1000024232.md).

### Couleur de fond
Par défaut, la couleur de fond d'un champ Image est transparente. Pour modifier la couleur de fond d'un champ Image, utilisez la propriété [CouleurFond](2510022.md).

### Coordonnées
Les coordonnées sont indiquées par rapport au coin haut gauche du champ Image ou de l'image (coordonnées (0,0)).
Les coordonnées correspondent au point haut gauche du rectangle dans lequel le texte sera dessiné. L'emplacement précis du texte dans ce rectangle dépend de la taille, de la forme et des attributs de la police.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS, Code Utilisateur (MCU))_ LimitationsEn mode anti-aliasing (fonction <Variable Image>.ChangeMode) ou en mode opacité (fonction <Variable picCalque>.DébutDessin), la fonction <Variable Image>.DessineTexteMarkdown est disponible uniquement pour les polices TrueType.
