# Constantes Bluetooth

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android)

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |
| **btActif** | Bluetooth activé sur l'appareil. | - [BTActive](1000019359.md), [BTEtat](1000019360.md) - [BTLEInitialise](1000022110.md), [BTLEEtat](1000021885.md) |
| **btActivationEnCours** | Bluetooth en cours d'activation sur l'appareil. | - [BTActive](1000019359.md), [BTEtat](1000019360.md) - [BTLEInitialise](1000022110.md), [BTLEEtat](1000021885.md) |
| **btAdresseMAC** | Adresse MAC du périphérique | [BTInfoPériphérique](1000017133.md),  [BTInfoRadio](1000017126.md),  [BTListePériphérique](1000017132.md) |
| **btClasseDePériphérique** | Classe du périphérique | [BTInfoPériphérique](1000017133.md),   [BTInfoRadio](1000017126.md) |
| **btClasseDeService** | Classe de service de la radio | [BTInfoRadio](1000017126.md) |
| **btCoD_AccèsRéseau** | Classe du périphérique : accès réseau | [BTInfoPériphérique](1000017133.md),  [BTInfoRadio](1000017126.md),  [BTListePériphérique](1000017132.md) |
| **btCoD_AudioVidéo** | Classe du périphérique : périphérique audio et vidéo | [BTInfoPériphérique](1000017133.md),  [BTInfoRadio](1000017126.md),  [BTListePériphérique](1000017132.md) |
| **btCoD_Divers** | Classe du périphérique : périphérique divers | [BTInfoPériphérique](1000017133.md),  [BTInfoRadio](1000017126.md),  [BTListePériphérique](1000017132.md) |
| **btCoD_Image** | Classe du périphérique : gestion d'image | [BTInfoPériphérique](1000017133.md),  [BTInfoRadio](1000017126.md),  [BTListePériphérique](1000017132.md) |
| **btCoD_Inconnu** | Classe du périphérique : inconnu | [BTInfoPériphérique](1000017133.md),  [BTInfoRadio](1000017126.md),  [BTListePériphérique](1000017132.md) |
| **btCoD_Jouet** | Classe du périphérique : jouet | [BTInfoPériphérique](1000017133.md),  [BTInfoRadio](1000017126.md),  [BTListePériphérique](1000017132.md) |
| **btCoD_Ordinateur** | Classe du périphérique : ordinateur | [BTInfoPériphérique](1000017133.md),  [BTInfoRadio](1000017126.md),  [BTListePériphérique](1000017132.md) |
| **btCoD_Périphérique** | Classe du périphérique : autre périphérique | [BTInfoPériphérique](1000017133.md),  [BTInfoRadio](1000017126.md),  [BTListePériphérique](1000017132.md) |
| **btCoD_Téléphone** | Classe du périphérique : téléphone | [BTInfoPériphérique](1000017133.md),  [BTInfoRadio](1000017126.md),  [BTListePériphérique](1000017132.md) |
| **btCoD_Vêtement** | Classe du périphérique : vêtement | [BTInfoPériphérique](1000017133.md),  [BTInfoRadio](1000017126.md),  [BTListePériphérique](1000017132.md) |
| **btCoS_Acquisition** | Classe de service : Périphérique d'acquisition de données (scanner, micro, ...). | [BTInfoRadio](1000017126.md) |
| **btCoS_Audio** | Classe de service : Périphérique audio (micro, haut-parleur, ...). | [BTInfoRadio](1000017126.md) |
| **btCoS_Information** | Classe de service : Service d'information (Serveur Web ou WAP, ...). | [BTInfoRadio](1000017126.md) |
| **btCoS_Positionnement** | Classe de service : Périphérique de positionnement (GPS, ...). | [BTInfoRadio](1000017126.md) |
| **btCoS_Réseau** | Classe de service : Périphérique réseau (point d'accès, ...). | [BTInfoRadio](1000017126.md) |
| **btCoS_Restitution** | Classe de service : Imprimante, haut-parleur | [BTInfoRadio](1000017126.md) |
| **btCoS_Téléphonie** | Classe de service : Appareil de téléphonie (téléphone, modem, ...). | [BTInfoRadio](1000017126.md) |
| **btCoS_Transfert** | Classe de service : Support de transfert (carte mémoire, ...). | [BTInfoRadio](1000017126.md) |
| **btDernièreFoisUtilisé** | Date et heure à laquelle le périphérique a été utilisé pour la dernière fois par le poste en cours. Cette date est au format JJMMAAAAHHMMSS. | [BTInfoPériphérique](1000017133.md) |
| **btDernièreFoisVu** | Date et heure à laquelle le périphérique a été vu pour la dernière fois par le poste en cours. Cette date est au format JJMMAAAAHHMMSS. | [BTInfoPériphérique](1000017133.md) |
| **btDésactivationEnCours** | Bluetooth en cours de désactivation sur l'appareil. | - [BTActive](1000019359.md), [BTEtat](1000019360.md) - [BTLEInitialise](1000022110.md), [BTLEEtat](1000021885.md) |
| **btDésactivé** | Bluetooth désactivé sur l'appareil. | - [BTActive](1000019359.md), [BTEtat](1000019360.md) - [BTLEInitialise](1000022110.md), [BTLEEtat](1000021885.md) |
| **btErreur** | L'état d'activation du Bluetooth n'a pas pu être récupéré. | - [BTActive](1000019359.md), [BTEtat](1000019360.md) - [BTLEEtat](1000021885.md) |
| **btEtatAuthentifié** | - 1 si le périphérique est actuellement authentifié auprès du poste en cours, 0 dans le cas contraire. - Permet de lister les périphériques authentifiés | [BTInfoPériphérique](1000017133.md),  [BTListePériphérique](1000017132.md),  [BTSélecteurPériphérique](1000017135.md) |
| **btEtatConnecté** | - 1 si le périphérique est actuellement "connecté" au poste en cours, 0 dans le cas contraire. - Permet de lister les périphériques connectés | [BTInfoPériphérique](1000017133.md), [BTListePériphérique](1000017132.md) |
| **btEtatInconnu** | Permet de lister les périphériques inconnus | [BTListePériphérique](1000017132.md),  [BTSélecteurPériphérique](1000017135.md) |
| **btEtatMémorisé** | 1 si le périphérique est actuellement "mémorisé" par le gestionnaire Bluetooth du poste en cours, 0 dans le cas contraire. | [BTInfoPériphérique](1000017133.md), [BTListePériphérique](1000017132.md),  [BTSélecteurPériphérique](1000017135.md) |
| **btEtatTous** | Permet de lister tous les périphériques | [BTListePériphérique](1000017132.md),  [BTSélecteurPériphérique](1000017135.md) |
| **btFabricant** | Nom du fabricant. | [BTInfoRadio](1000017126.md) |
| **btIDClasseDeService** | Valeur numérique (entier sur 11 bits) correspondant à la classe de service. | [BTInfoRadio](1000017126.md) |
| **btIDFabricant** | Identifiant du fabricant. | [BTInfoRadio](1000017126.md) |
| **btIDMajeurClasseDePériphérique** | Valeur numérique (entier sur 5 bits) correspondant au numéro majeur de la classe de périphérique. | [BTInfoRadio](1000017126.md) |
| **btIDMineurClasseDePériphérique** | Valeur numérique (entier sur 6 bits) correspondant au numéro mineur de la classe de périphérique. | [BTInfoRadio](1000017126.md) |
| **btIDVersion** | Numéro de version fixé par le fabricant. | [BTInfoRadio](1000017126.md) |
| **btleEtatConnecté** | L'appareil est connecté au périphérique Bluetooth spécifié. | [BTLEEtatConnexion](1000022068.md) |
| **btleEtatDéconnecté** | L'appareil n'est pas connecté au périphérique Bluetooth spécifié. | [BTLEEtatConnexion](1000022068.md) |
| **btListeDétaillée** | Le résultat est une liste détaillée | [BTListePériphérique](1000017132.md),  [BTListeRadio](1000017125.md),  [BTListeService](1000017141.md) |
| **btListeSimple** | Le résultat est une liste simple | [BTListePériphérique](1000017132.md),  [BTListeRadio](1000017125.md),  [BTListeService](1000017141.md) |
| **btNom** | Nom du périphérique ou de la radio | [BTInfoPériphérique](1000017133.md),  [BTInfoRadio](1000017126.md),  [BTListeService](1000017141.md) |
| **btNonInitialisé** | L'initialisation du Bluetooth Low Energy n'a pas été réalisée. | [BTLEEtat](1000021885.md) |
| **btPileAucune** | La clé locale utilise une pile non supportée ou aucune clé Bluetooth n'est installée. | [BTPile](1000017229.md) |
| **btPileBlueSoleil** | La clé locale utilise une pile BlueSoleil. | [BTPile](1000017229.md) |
| **btPileBroadcom** | La clé locale utilise une pile Broadcom (anciennement nommée Widcomm). | [BTPile](1000017229.md) |
| **btPileMicrosoft** | La clé locale utilise une pile Microsoft. | [BTPile](1000017229.md) |
