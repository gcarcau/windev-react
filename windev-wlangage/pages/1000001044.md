# Erreur 1044 : La classe dérive déjà de cette classe

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

## Cause

Vous tentez de rédéfinir un héritage. Le même héritage est défini deux fois dans le même code.

## Correction

Supprimez la syntaxe supplémentaire.

## Exemple

### Déclaration d'une classe dérivée

**Code provoquant l'erreur**

```wlangage

Rond est une Classe
 un objet Dessin
 un objet Dessin
FIN
```

**Correction proposée**

Supprimer la déclaration supplémentaire.

```wlangage

Rond est une Classe
 un objet Dessin
FIN
```
