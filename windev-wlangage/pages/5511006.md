# Connecteur Natif Informix : Programmation à l'aide des fonctions SQL

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows)

## Présentation

L'utilisation des fonctions SQL pour manipuler des données Informix n'implique pas une importation de la structure des fichiers dans l'analyse. Cependant, les données doivent être manipulées uniquement par requêtes. Il n'est pas possible de lire directement le contenu des fichiers Informix.

## Programmation

### 1. Ouverture de la connexion
La fonction [SQLConnecte](3072005.md) permet d'ouvrir une connexion à une base de données Informix par le Connecteur Natif. Il est nécessaire de passer en paramètre à la fonction [SQLConnecte](3072005.md) le type de la base utilisée, ici INFORMIX.
Le nom de la base correspond au nom du serveur Informix (ou à son alias).

```wlangage
NumConnexion = SQLConnecte("BaseInformix", "sa", "", "", "INFORMIX")
```

### 2. Exécution de requêtes
L'exécution de requêtes est réalisée grâce à la fonction [SQLExec](3072007.md). La fonction [SQLExec](3072007.md) attend en paramètres le texte de la requête SQL et le nom qui sera donné à cette requête.
```wlangage
SQLExec("SELECT NOM, PRENOM, POSTE, PHOTO FROM CLIENT", "REQ1")
```

### 3. Récupération du résultat
Plusieurs modes de récupération du résultat sont disponibles :

- [SQLPremier](3072017.md) : Permet de récupérer le résultat et initialise un parcours du résultat de type [SQLPremier/SQLCol](3072025.md).
- [SQLTable](3072031.md) : Permet de récupérer le résultat de la requête dans un champ Table par programmation de l'application WINDEV ou WEBDEV. Il est possible de récupérer le résultat de la requête par Fetch partiel.
- [SQLFetch (SQLAvance)](3072011.md) : Permet de parcourir les différentes lignes résultat de la requête. Le parcours du résultat de la requête est du type [SQLAvance/SQLLitCol](3072025.md).

La fonction [SQLBloque](3072003.md) permet de bloquer soit les enregistrements de la table, soit les enregistrements sélectionnés par la requête.

### 4. Fermeture de la connexion
La fonction [SQLFerme](3072015.md) permet de fermer la connexion à la base de données lorsque toutes les requêtes nécessaires ont été réalisées.
