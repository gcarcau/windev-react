# FenAdapteLargeur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

Adapte la largeur de la fenêtre au contenu des champs. Les champs sont affichés de manière optimale dans la fenêtre (les ascenseurs inutiles sont supprimés si possible).

## Exemple

```wlangage
FenAdapteLargeur(FEN_FicheDetail)
```

## Syntaxe

```wlangage
FenAdapteLargeur([<Fenêtre>])
```

`<Fenêtre>` *Nom de fenêtre optionnel*
> Nom de la fenêtre à redimensionner. Si ce paramètre n'est pas précisé, la fenêtre en cours sera manipulée.

## Remarques

Le redimensionnement en largeur d'une fenêtre est possible uniquement si la fenêtre contient un des champs suivants ancré en largeur :

- Champ Liste,
- Champ Table,
- Champ Zone répétée,
- Champ Arbre,
- Champ Liste image,
- Champ de saisie multiligne.

**Composante : wd300obj.dll**
