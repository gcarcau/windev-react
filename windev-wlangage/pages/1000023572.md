# Valide (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **Valide** permet de savoir si un élément est valide. Cette propriété est utilisable sur :

- une variable de type [Image](1000019650.md).
- une variable de type [AuthToken](1000022220.md).
- une variable de type [OpenIDIdentité](1000023567.md).
- une variable de type [AppleID](1000025405.md).
