# <Variable sfConnexion>.AvanceRequête (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Continue d'exécuter une requête SOQL (Salesforce Object Query Language) sur les enregistrements d'une base de données Salesforce. La requête a été exécutée avec la fonction [<Variable sfConnexion>.ExécuteRequête](1000018762.md).

## Exemple

```wlangage
// Connexion à Salesforce
Cnx est une sfConnexion
Cnx.Login = "balthazar@gmail.com"
Cnx.MotDePasse = "azerty" + "XXB12VCZ54"
SI Cnx.Connecte() = Faux ALORS
	Erreur("La connexion a échoué")
	RETOUR
FIN

ResRequête est un sfRésultatExécuteRequête
ResRequête = Cnx.ExécuteRequête("SELECT Date__c,Miles__c,Contact__c FROM Mileage__c")

BOUCLE
	MonEnregistrement est un sfObjet
	POUR TOUT MonEnregistrement DE ResRequête..Objet
		Trace("---- Type : " + MonEnregistrement..TypeObjet + " | ID : " + MonEnregistrement..ID)
		Trace(MonEnregistrement..Date__c + " / " + ...
		MonEnregistrement..Miles__c + " / " + MonEnregistrement..Contact__c)
	FIN

	SI ResRequête..Fini = Faux ALORS // Vérifie s'il reste des enregistrements "on fetch"
		ResRequête = Cnx.AvanceRequête(ResRequête..LocalisationRequête)
	SINON
		SORTIR // Fin de la lecture
	FIN
FIN

POUR TOUT MonEnregistrement DE ResRequête..Objet
	Trace("---- Type : " + MonEnregistrement..TypeObjet + ...
		" | ID : " + MonEnregistrement..ID)
	Trace(MonEnregistrement..Date__c + " / " + ...
		MonEnregistrement..Miles__c + " / " + MonEnregistrement..Contact__c)
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Connexion Salesforce>.AvanceRequête(<Localisation de la requête>)
```

`<Résultat>` *Variable de type sfRésultatExécuteRequête*
> Variable de type [sfRésultatExécuteRequête](1000018558.md) contenant les données résultat, notamment les enregistrements Salesforce correspondant au résultat de la requête.
`<Connexion Salesforce>` *Variable de type sfConnexion*
> Nom de la variable de type [sfConnexion](1000017579.md) à utiliser.
`<Localisation de la requête>` *Chaîne de caractères Unicode*
> Chaîne permettant d'identifiant la requête. Cette chaîne est obtenue grâce à la propriété **LocalisationRequête** de la dernière variable [sfRésultatExécuteRequête](1000018558.md) reçue.

## Remarques

### Cas d'erreurs possibles :

- La connexion Internet n'est pas valide.
- L'authentification n'a pas pu être réalisée correctement.
- La réponse XML du serveur n'est pas lisible.

Pour savoir si une erreur est survenue, utilisez la variable [ErreurDétectée](3087001.md).
