# xlsCoordonnéesVersNom (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Récupère le nom d'une cellule d'une feuille XLS ou d'un champ Tableur en fonction de ses coordonnées.
Nouveauté 2025

> _(Android)_ Cette fonction est désormais disponible pour les applications Android.

> _(Widget Android)_ Cette fonction est désormais disponible en mode Widget Android.

> _(iPhone/iPad)_ Cette fonction est désormais disponible pour les applications iPhone/iPad.

## Exemple

```wlangage
NomCellule est une chaîne = xlsCoordonnéesVersNom(1,1)
```

## Syntaxe

```wlangage
<Résultat> = xlsCoordonnéesVersNom(<Colonne> , <Ligne>)
```

`<Résultat>` *Chaîne de caractères*
> Nom de la cellule. Ce nom est du type "A1".
`<Colonne>` *Entier*
> Numéro de la colonne identifiant la cellule.
`<Ligne>` *Entier*
> Numéro de la ligne identifiant la cellule.
