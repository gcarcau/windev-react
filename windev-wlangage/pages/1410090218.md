# EnModeVisiteGuidée (Fonction)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Indique si une visite guidée est en cours d'exécution.

## Exemple

```wlangage
SI EnModeVisiteGuidée() ALORS
    Info("C'est bien ici qu'il fallait cliquer".)
    RETOUR
FIN
```

```wlangage
// Clic sur le bouton [Paramètres]
// Passage à l'étape suivante
SI EnModeVisiteGuidée() ALORS
	VisiteGuidéeChangeEtape(vgaEtapeSuivante)
	RETOUR
FIN
```

## Syntaxe

```wlangage
<Résultat> = EnModeVisiteGuidée()
```

`<Résultat>` *Booléen*
> - Vrai si une visite guidée est en cours d'exécution,
> - Faux dans le cas contraire.

## Remarques

### Disponibilité de la fonction
La fonction **EnModeVisiteGuidée** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **EnModeVisiteGuidée** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.

### Exécution des traitements contenant des erreurs de compilation
Par défaut, le mécanisme de sécurité du WLangage se déclenche uniquement si la ligne contenant l'erreur de compilation est exécutée.
Par exemple, si une fonction interdite dans le produit en cours est présente dans une boucle SI, le mécanisme de sécurité du WLangage se déclenchera uniquement si la ligne contenant cette fonction s'exécute.
