# Instruction POUR TOUT / POUR TOUS (parcours de combinaisons)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (iPhone/iPad, Apple Watch)

L'instruction **POUR TOUT** permet de parcourir les options disponibles dans les combinaisons.
**Remarque** : Les instructions **POUR TOUT, POUR TOUS, POUR CHAQUE** sont acceptées. Dans cette documentation, seule l'instruction **POUR TOUT** est utilisée et peut être remplacée par **POUR TOUS** ou **POUR CHAQUE**.

## Exemple

```wlangage
// Code de déclaration
// Déclarer une combinaison
TypeCombinaison est une Combinaison
	CréationFic
	LectureFic
	EcritureFic
	SuppressionFic
FIN
```

```wlangage
// Syntaxe 1 : Parcours des options de la combinaison
POUR TOUT eOption DE TypeCombinaison
	Trace(eOption..Nom)
FIN
```

```wlangage
// Affectation de la variable
ActionFichier = LectureFic + EcritureFic

// Syntaxe 2 : Parcours des options actives
POUR TOUT eOption DE ActionFichier
	Trace(eOption..Nom)
FIN
```

## Syntaxe

#### Syntaxe simplifiée

```wlangage
POUR TOUT <MonOption> DE <Combinaison> ...FIN
```

`<POUR TOUT>` **
> Signale le début du bloc d'instructions.
`<MonOption>` **
> Variable de type [Description d'Option](1000023072.md) correspondant à l'option de la combinaison. Il n'est pas nécessaire de déclarer cette variable.
`<Combinaison>` **
> - [Combinaison](1514074.md) contenant les valeurs à parcourir.
> - Variable de type [Combinaison](1514074.md) contenant les options à parcourir. Toutes les options (actives ou inactives) sont parcourues.

#### Parcours des options actives d'une variable de type Combinaison

```wlangage
POUR TOUT <MonOption> DE <Combinaison> ...FIN
```

`<POUR TOUT>` **
> Signale le début du bloc d'instructions.
`<MonOption>` **
> Variable de type [Description d'Option](1000023072.md) correspondant à l'option de la combinaison. Il n'est pas nécessaire de déclarer cette variable.
`<Combinaison>` **
> Variable de type [Combinaison](1514074.md) contenant les options à parcourir. Seules les options actives sont parcourues.
