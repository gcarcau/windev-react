# WDXView : Présentation

> **Disponible :** **WINDEV** (Windows)

## Présentation

### L'utilitaire WDXView
WDXView est un visualiseur d'ActiveX. Cet outil permet de connaître, de visualiser et de tester les différents ActiveX installés sur votre poste.
WDXView permet de :

- Connaître les propriétés, les méthodes, les événements et les constantes associés à un ActiveX. Les informations obtenues peuvent ensuite être utilisées pour piloter entièrement un ActiveX par programmation.
- Tester un ActiveX et ses fonctionnalités.

## Lancement de WDXView

WDXView peut être lancé :

- depuis l'éditeur : sous le volet "Outils", dans le groupe "Utilitaires", cliquez sur "WDXView",
- en exécutant le fichier "WDXVIEW.EXE" présent dans le sous-répertoire "Programs" du répertoire d'installation de WINDEV ou WINDEV Mobile.

### Conditions d'utilisation
WDXView n'est pas redistribuable avec vos applications. WDXView ne peut pas être installé avec les applications développées avec WINDEV et/ou WINDEV Mobile.
La licence d'utilisation de WINDEV et/ou WINDEV Mobile s'applique intégralement.
