# <Variable Image>.Fond (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Déclare la couleur de fond par défaut des rectangles, des cercles (et autres) utilisés dans une variable de type [Image](1000019650.md).
> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les dessins.

## Exemple

```wlangage
MonImage est une Image = "Test.bmp" // Déclaration de la couleur de fond des différents dessins réalisés dans la variable MonImageMonImage.Fond(VertClair) IMG_MonDessin = MonImage
```

## Syntaxe

```wlangage
<Variable Image>.Fond(<Couleur> [, <Style de remplissage> [, <Type de hachures> [, <Opacité>]]])
```

`<Variable Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) à manipuler.
`<Couleur>` *Entier ou constante*
> Couleur du fond par défaut des différents dessins. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md).
> - une variable de type [Couleur](1000019661.md). Dans ce cas, l'opacité spécifiée dans la variable est prise en compte.
`<Style de remplissage>` *Entier ou constante de type Entier optionnel*
> Style de remplissage du fond par défaut des différents dessins :
>
> | *FondHachuré* | Remplissage du fond par des hachures.  Correspond à la valeur 2 pour compatibilité. |
> | --- | --- |
> | *FondPlein* (Valeur par défaut) | Fond plein.  Correspond à la valeur 0 pour compatibilité. |
> | *FondTransparent* | Fond transparent (le paramètre <Couleur est alors ignoré). Correspond à la valeur 1 pour compatibilité. |
>
>
>
> > _(iPhone/iPad, Widget IOS, Mac Catalyst)_ Le dessin des hachures n'est pas supporté.
`<Type de hachures>` *Entier optionnel*
> Type de hachures du fond utilisé par défaut dans les différents dessins. Pour utiliser ce paramètre, la valeur du paramètre <Style de remplissage> doit être égale à 2. Si la valeur du paramètre <Style de remplissage> est différente de 2, le paramètre <Type de hachures> est ignoré. Les différents types de hachures sont :
>
> - 0 : Hachures horizontales
> - 1 : Hachures verticales
> - 2 : Hachures diagonales à 60%
> - 3 : Hachures diagonales à 120%
> - 4 (par défaut) : Hachures croisées
> - 5 : Hachures diagonales croisées
`<Opacité>` *Entier optionnel*
> Opacité de la couleur, comprise entre 0 (transparent) et 255 (opacité complète). Une opacité de 128 permet de mélanger 50% de la couleur avec la couleur existante dans le champ.
> **Remarques** :
>
>
> - Cette opacité sera prise en compte si le dessin a été initialisé avec la constante *dAvecOpacité* (fonction [<Variable Image>.DébutDessin](1000024349.md)).
> - Si le paramètre <Couleur> correspond à une variable de type [Couleur](1000019661.md), ce paramètre ne doit pas être spécifié : l'opacité spécifiée dans la variable sera prise en compte.
