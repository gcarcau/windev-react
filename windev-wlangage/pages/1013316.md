# Propriétés associées au champ SilverLight

> **Disponible :** **WEBDEV** (Windows, PHP, WEBDEV - Code Navigateur)

> _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur)_ Propriétés disponibles dans une page (code serveur)Les différentes propriétés associées aux champs SilverLight sont les suivantes :
AliasLa propriété Alias permet de : connaître ou de modifier l'alias d'une fenêtre (WINDEV et WINDEV Mobile).connaître ou de modifier l'alias d'un volet d'onglet dynamique (WINDEV).connaître le nom interne HTML / Javascript d'un champ (WEBDEV).AttributHTMLLa propriété AttributHTML permet de lire et de modifier les attributs HTML du champ.ClasseHTMLLa propriété ClasseHTML permet de lire et de modifier la valeur de l'attribut HTML "class" du champ.CouleurFondLa propriété CouleurFond permet de gérer la couleur de fond d'un champ, d'une fenêtre, d'une page ou d'un bloc d'un état.ExtraLa propriété Extra permet de :Connaître les informations supplémentaires associées à un champ, à une fenêtre, ou à une page.Modifier les informations supplémentaires associées à un champ, à une fenêtre ou à une page. En code navigateur, il est uniquement possible de connaître les informations supplémentaires associées à un champ ou une page.GroupeLa propriété Groupe permet de : savoir si le champ appartient ou non à un groupe de champs. Si le champ appartient à un ou plusieurs groupes, la propriété Groupe permet d'identifier ces groupes de champs.associer un champ à un groupe de champs. HauteurLa propriété Hauteur permet de connaître et modifier la hauteur :d'un champ ou d'un bloc dans un état.d'un champ (présent dans une fenêtre), d'une fenêtre, d'une ligne d'un champ Table ou Liste (y compris Liste image), d'une option d'un champ Sélecteur ou Interrupteur, d'un haut ou d'un bas de rupture d'un champ Table ou d'un champ Zone répétée.d'un champ (présent dans une page), d'un haut ou bas de rupture d'un champ Table ou Zone répétée. Le champ peut être superposable ou non.d'une cellule de rupture d'un champ Table ou d'un champ Zone répétée.HTMLAprèsLa propriété HTMLAprès permet de connaître et de modifier le code HTML ajouté après le champ.HTMLAvantLa propriété HTMLAvant permet de connaître et de modifier le code HTML ajouté avant le champ.LargeurLa propriété Largeur permet de connaître et modifier la largeur :d'un champ ou d'un bloc dans un état.d'un champ (présent dans une fenêtre), d'une fenêtre, d'une colonne de table ou d'une colonne de liste (y compris liste image).d'un champ (présent dans une page), d'une colonne de table ou d'une liste. Le champ peut être superposable ou non.LibelléDans une base de données, la propriété Libellé permet de :Connaître le libellé associé à une rubrique d'un fichier de données. Connaître le libellé associé à un fichier de données. Connaître et modifier le libellé d'une connexion. Dans un état, la propriété Libellé permet de :Connaître le texte d'un champ Libellé ou Lien.Modifier le texte d'un champ Libellé ou Lien.Dans une fenêtre ou une page, la propriété Libellé permet également de :Connaître et modifier le libellé d'un champ présent dans une fenêtre ou une page.Connaître et modifier le libellé d'une option de menu.Connaître et modifier le titre d'une fenêtre ou d'une page.Connaître le contenu d'un champ chemin de navigation.NomLa propriété Nom permet de connaître :le nom de la police associée à une variable de type Police.le nom d'un champ, d'un état ou d'un bloc d'un état.le nom d'un champ, d'un groupe de champs ou d'une fenêtre.le nom d'un champ, d'un groupe de champs ou d'une page.NomCompletLa propriété NomComplet permet de connaître le nom complet :d'un champ.d'une fenêtre.d'une option de menu.d'une colonne de table.NoteLa propriété Note permet de :Connaître les notes associées à un champ, à une fenêtre, à une page ou un état.Modifier les notes associées à un champ, à une fenêtre, à une page ou un état.TitreNoteLa propriété TitreNote permet de :Connaître le titre des notes utilisé pour la documentation technique d'un champ, d'une fenêtre, d'une page ou d'un état. Modifier le titre des notes utilisé pour la documentation technique d'un champ, d'une fenêtre, d'une page ou d'un état.TraitementLa propriété Traitement permet de modifier les traitements à exécuter par les événements disponibles sur un champ, une fenêtre, une page, un état, ...TypeLa propriété Type permet de connaître :le type d'un élément décrit par programmation (description de rubrique ou de fichier) ou non (fichier ou rubrique défini sous l'éditeur d'analyses, vue ou requête).le type d'un objet.le type de la valeur stockée dans un variant.ValeurLa propriété Valeur permet de :Connaître et modifier la valeur d'un champ d'un état.Connaître et modifier la valeur d'un champ ou le titre d'une fenêtre.Connaître l'identifiant d'un flux. Connaître et modifier la valeur d'un champ ou le titre d'une page.ValeurInitialeLa propriété ValeurInitiale permet de connaître la valeur initiale d'un champ d'une fenêtre ou d'une page.VisibleLa propriété Visible permet de :Savoir si un élément est visible.Rendre un élément visible ou invisible.VisibleInitialLa propriété VisibleInitial permet de savoir si :un champ était visible lors du premier affichage de la fenêtre ou la page associée.une fenêtre était visible lors de son premier affichage.XLa propriété X permet de :Connaître l'abscisse d'un champ, d'une colonne d'un champ Table ou d'une fenêtre (position sur l'axe des X).Modifier l'abscisse d'un champ ou d'une fenêtre (position sur l'axe des X).XInitialLa propriété XInitial permet de :Connaître l'abscisse : d'un champ (position sur l'axe des X) lors de l'ouverture de la fenêtre ou de la page.d'une fenêtre (position sur l'axe des X) lors de l'ouverture de la fenêtre. Modifier l'abscisse d'un champ ancré "à droite" (position sur l'axe des X) lors de l'ouverture de la fenêtre.Connaître l'abscisse d'un champ par rapport à son bloc (position en millimètres sur l'axe des X) lors de l'ouverture de l'état.YLa propriété Y permet de :Connaître l'ordonnée d'un champ ou d'une fenêtre (position sur l'axe des Y).Modifier l'ordonnée d'un champ ou d'une fenêtre (position sur l'axe des Y).YInitialLa propriété YInitial permet de :Connaître l'ordonnée : d'un champ (position sur l'axe des Y) lors de l'ouverture de la fenêtre ou de la page.d'une fenêtre (position sur l'axe des Y) lors de l'ouverture de la fenêtre.Modifier l'ordonnée d'un champ ancré "en bas" (position sur l'axe des Y) lors de l'ouverture de la fenêtre.Connaître l'ordonnée d'un champ par rapport à son bloc (position en millimètres sur l'axe des Y) lors de l'ouverture de l'état.
