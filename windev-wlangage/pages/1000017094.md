# HTTPDestination (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Indique le fichier de sauvegarde du résultat de la prochaine requête HTTP, exécutée dans le même thread.

## Exemple

```wlangage
// Récupération du code HTML de la page Web www.pcsoft.com
HTTPDestination("C:\Temp\pcsoft.htm")
HTTPRequête("http://www.pcsoft.fr")
```

## Syntaxe

```wlangage
<Résultat> = HTTPDestination(<Nom du fichier>)
```

`<Résultat>` *Booléen*
> - Vrai si le fichier a pu être créé,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Nom du fichier>` *Chaîne de caractères*
> Chemin complet du fichier à créer. Le fichier est créé, ouvert et bloqué lors de l'exécution de la fonction **HTTPDestination**. Il sera débloqué à la fin de la requête HTTP.

## Remarques

### Fonctionnement de HTTPRequête / HTTPDonneRésultat avec une destination
Si un fichier de sauvegarde du résultat de la requête HTTP est précisé avec la fonction **HTTPDestination** :

- la fonction [HTTPDonneRésultat](3043001.md) utilisée avec la constante *httpRésultat* renvoie toujours une chaîne vide ("").
- la fonction [HTTPDonneRésultat](3043001.md) utilisée avec la constante *httpEntête* renvoie toujours l'entête de la réponse HTTP. Cet entête n'est pas enregistré dans le fichier destination : seules les données sont enregistrées.

Lorsque la requête est terminée, la destination est annulée et la fonction [HTTPRequête](3043007.md) fonctionne normalement.
