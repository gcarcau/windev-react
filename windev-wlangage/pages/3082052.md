# zipNbPartieNécessaire (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie le nombre de parties d'une taille donnée nécessaires pour découper une archive mono-partie.
**Remarque** : Cette fonction est disponible uniquement pour les archives au format ZIP et WDZ.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ MonArchive est une zipArchive
// Ouverture d'une archive
ResOuvreArchive = zipOuvre(MonArchive, "C:\MesArchives\Archive.zip")

SI ResOuvreArchive = 0 ALORS
 ...
 // Nombre de parties de 1,4 Mo nécessaires pour contenir l'archive
 ResNbPartieNécessaire = zipNbPartieNécessaire(MonArchive, 1400*1024)
 Info("Pour découper cette archive, " + ResNbPartieNécessaire + ...
 " partie(s) de 1,4 Mo sont nécessaires")
 ...
FIN

## Syntaxe

```wlangage
<Résultat> = zipNbPartieNécessaire(<Archive> , <Taille des parties>)
```

`<Résultat>` *Entier*
> Nombre de parties d'une taille donnée nécessaires pour contenir une archive.
`<Archive>` *Chaîne de caractères ou variable de type zipArchive*
> Nom de l'archive à manipuler.
> Ce nom peut correspondre :
>
> - soit au nom d'une archive défini avec la fonction [zipOuvre](3082044.md) ou la fonction [zipCrée](3082003.md).
> - soit au nom d'une variable de type [zipArchive](1000018679.md).
`<Taille des parties>` *Entier*
> Taille des parties en octets. La taille par défaut est égale à 1,4 Mo (1400*1024 octets). La taille minimale est égale à 300 Ko par partie (300*1024 octets).

## Remarques

### Découpage d'une archive
La création d'une archive multi-parties est réalisable grâce à la fonction [zipDécoupe](3082020.md). La fonction **zipNbPartieNécessaire** permet de connaître le nombre de parties nécessaires au découpage de l'archive.

### Archive multi-parties
L'utilisation de la fonction **zipNbPartieNécessaire** sur une archive multi-parties permet de calculer le nombre de parties nécessaires en vue d'un nouveau découpage.
