# inAppProduit (Type de variable)

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

Le type **inAppProduit** permet de définir toutes les caractéristiques avancées d'un produit ou d'un abonnement dans le cadre d'un achat In-App. Les caractéristiques de ce produit peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
MesProduits est un tableau de inAppProduit
// Récupération à l'aide de inAppInfoProduit
// ...
POUR i = 1 _À_ MesProduits.Occurrence
	ZoneRépétéeAjouteLigne(ZR_Produits, MesProduits[i].Libellé, MesProduits[i].Description)
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type inAppProduit
Les propriétés suivantes peuvent être utilisées pour manipuler un produit In-App ou un abonnement In-App :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Description | Chaîne de caractères | Description du produit.  **Cette propriété est disponible en lecture seulement**. |
| Identifiant | Chaîne de caractères | Identifiant du produit ou de l'abonnement dans le store (iTunes Connect ou Google Play Store). **Cette propriété est disponible en lecture seulement**. |
| Libellé | Chaîne de caractères | Libellé ou titre du produit ou de l'abonnement. **Cette propriété est disponible en lecture seulement**. |
| Prix | Chaîne de caractères | - Prix du produit dans la monnaie courante, formaté en utilisant le masque du téléphone. - Tarif de l'abonnement dans la monnaie courante, formaté en utilisant le masque du téléphone.   **Cette propriété est disponible en lecture seulement**. |
| _(Android)_ Type | Constante de type Entier | Type de produit :   - *inAppAbonnement* : Abonnement. - *inAppProduit* : Produit consommable et non consommable.   **Cette propriété est disponible en lecture seulement**. |

## Remarques

### Fonctions utilisant le type inAppProduit
Les fonctions manipulant des variables de type **inAppProduit** sont les suivantes :

| [inAppAchèteProduit](1000020873.md) | Envoie une demande d'achat d'un produit "In-App" associé à l'application. |
| --- | --- |
| [inAppConsommeProduit](1000020880.md) | Permet de consommer dans une application un produit précédemment acheté par l'utilisateur. |
| [inAppListeInfoProduit](1000020872.md) | Récupère à partir du store les informations sur les produits "In-App" associés à l'application. |
