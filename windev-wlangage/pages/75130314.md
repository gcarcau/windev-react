# Table,Modifie (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Modifie un élément dans un champ Table.

## Exemple

```wlangage
// En CAPPELWD("Table,Modifie,TableProd,%s=%s",indice,valeur);
```

```wlangage
// En PascalAPPELWD('Table,Modifie,TableProd,'+indice+'='+valeur);
```

```wlangage
// En VBcall APPELWD("Table,Modifie,TableProd,"+indice+"="+valeur)
```

## Syntaxe

```wlangage
Table,Modifie(<Champ Table> [, <Indice>] , <Valeur>)
```

`<Champ Table>` *Nom de champ*
> Nom du champ Table à manipuler.
`<Indice>` *Chaîne de caractères (optionnelle)*
> Indice de l'élément dans le champ Table. Si l'indice n'est pas précisé, il s'agit de l'élément en cours.
>
> - Dans le cas d'un champ Table par programmation, l'indice est relatif à la totalité du champ Table.
> - Dans le cas d'un champ Table fichier, l'indice est relatif aux seuls éléments visualisés.
`<Valeur>` *Chaîne de caractères*
> Nouvelle valeur.

## Remarques

### Note
Si le champ Table comporte plusieurs colonnes, il faut séparer chaque colonne par la valeur numérique de [TAB] (code binaire 9).
Exemple en C :

```wlangage
APPELWD("Table,Modifie,TabCli,14=DUPOND\tJean");
```

Exemple en Pascal :

```wlangage
APPELWD('Table,Ajoute,TabCli,14=DUPOND'+#9+'Jean');
```

Exemple en VB :

```wlangage
call APPELWD("Table,Modifie,TabCli,14=DUPOND"+CHR$(9)+"Jean")
```

### Champ Table fichier
Dans le cas d'un champ Table fichier, l'enregistrement n'est pas modifié dans le fichier de données, il faut appeler la fonction [Table,Enregistre](75130312.md).
Pour modifier le fichier de données associé à un champ Table, il ne faut pas utiliser la fonction **HModifie**, mais utiliser les fonctions **Table,Modifie** et [Table,Enregistre](75130312.md).
