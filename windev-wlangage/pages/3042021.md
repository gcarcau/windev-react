# grEffaceDessin (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Efface le dessin d'un graphe (dans un champ Image ou dans une fenêtre).
**Remarque** : Le graphe n'est pas détruit. Les données et les paramètres du graphe sont conservés en mémoire. Il suffit d'appeler la fonction [grDessine](3042026.md) pour ré-afficher le graphe.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
// Effacement du graphe "MonGraphe"
grEffaceDessin("MonGraphe")
```

## Syntaxe

```wlangage
grEffaceDessin(<Nom du graphe>)
```

`<Nom du graphe>` *Nom de champ ou chaîne de caractères*
> Nom du graphe à effacer. Ce nom correspond :
>
> - soit au nom du graphe défini par programmation avec la fonction [grCrée](3042005.md).
> - soit au nom du champ Graphe (présent dans l'éditeur de fenêtres ou de pages).

## Remarques

- Si le graphe est dessiné dans une fenêtre indépendante, la fenêtre est fermée.
- La fonction **grEffaceDessin** n'a aucun effet si le graphe n'est pas dessiné.
- La fonction **grEffaceDessin** n'a aucun effet dans les états.
- Pour supprimer les données d'un graphe, utilisez la fonction [grSupprimeSérie](3042054.md) ou [grSupprimeTout](3042055.md).
