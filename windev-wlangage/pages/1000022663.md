# ChampExécuteModification (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Considère que le champ a été modifié par l'utilisateur (la propriété [Modifié](2510080.md) passe à Vrai pour le champ et si nécessaire pour la fenêtre) et exécute l'événement WLangage "A chaque modification" associé au champ.

## Exemple

```wlangage

ChampExécuteModification(SAI_Saisie)
```

## Syntaxe

```wlangage
ChampExécuteModification(<Champ manipulé>)
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.

**Composante : wd300obj.dll**
