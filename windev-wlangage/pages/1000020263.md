# Protocole (Propriété)

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android)

La propriété **Protocole** permet de connaître et de modifier le protocole utilisé. Cette propriété est utilisable sur :

- une variable de type [rssCloud](1000017785.md).
- une variable de type [MessagerieInstantanée](1000020247.md).
