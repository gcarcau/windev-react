# Description de Syntaxe (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

Une variable de type **Description de Syntaxe** permet de décrire par programmation la syntaxe d'un état, d'une fenêtre ou d'une page. Les caractéristiques de ce type de variable peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
Remarque : La description de la syntaxe est disponible dans la définition de l'état, de la fenêtre ou de la page. Cette définition peut être récupérée grâce à la fonction [RécupèreDéfinitionType](1000019559.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
Description_état est un Définition = RécupèreDéfinitionType(ETAT_CommandesClients)
Description_syntaxe est une Description de Syntaxe = Description_état.SyntaxeDéclaration
```

## Propriétés

### Propriétés spécifiques à la description des variables de type Description de Syntaxe

Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **Description de Syntaxe** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| NombreParamètresVariable | Booléen | - Vrai si le nombre de paramètres de la syntaxe est variable, - Faux dans le cas contraire.   **Cette propriété est disponible en lecture seulement**. |
| Paramètre | Tableau de [Description de Paramètre](1410089122.md) | Détail de chaque paramètre de la syntaxe. |
| Nouveauté Abonnement TypeRetour | Tableau de [Description de Paramètre](1410089122.md) | Détail de chaque valeur de retour renvoyée par la syntaxe.  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md). |
