# Zoom (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **Zoom** permet de connaître ou de modifier la valeur du zoom utilisée :

- dans un champ Image. Ce champ Image doit avoir la gestion des ascenseurs automatiques et du zoom activée (option "Ascenseurs et zoom automatiques" dans l'onglet "Détail" de la fenêtre de description du champ).
- dans un champ Carte.
- dans un champ Organigramme.
- dans un champ Table, Table hiérarchique, Tableau croisé dynamique, Tableur ou Liste.
- dans une fenêtre.
- dans un champ Traitement de texte.
- dans un champ Lecteur PDF.
- dans un champ Caméra.
  Remarque : Cette propriété est utilisable uniquement pour les champs Caméra qui ne sont pas en "Mode compatible 26".
- dans un champ Editeur de diagrammes.

## Exemple

> _(WINDEV, Android, Widget Android, iPhone/iPad, Widget IOS)_ // Effectue un zoom à 40% du fichier PDF affiché dans le champ Image
IMG_Image_PDF.Zoom = 40

## Syntaxe

#### Connaître le zoom effectué

```wlangage
<Résultat> = <Elément manipulé>.Zoom
```

`<Résultat>` *Entier*
> Valeur du zoom actuellement réalisé dans l'élément. Cette valeur correspond :
>
> - Dans un champ Image : au pourcentage de zoom.
> - Dans un champ Organigramme : au pourcentage de zoom.
> - Dans un champ Table, Table hiérarchique, Tableau croisé dynamique ou Tableur : au pourcentage de zoom.
> - Dans un champ Carte : à une valeur comprise entre 1 (affichage de la terre entière) et 21.
> - Dans une fenêtre : au pourcentage de zoom.
> - Dans un champ Traitement de texte : au pourcentage de zoom.
> - Dans un champ Lecteur PDF : au pourcentage de zoom.
> - **Dans un champ Caméra** : à une valeur comprise entre les valeurs des propriétés [ZoomMin](1410088098.md) et [ZoomMax](1410088099.md).
> - Dans un champ Editeur de diagrammes : au pourcentage de zoom.
`<Elément manipulé>` *Nom de champ ou nom de fenêtre*
> Nom de l'élément à manipuler :
>
> - Nom du champ Image.
> - Nom du champ Organigramme.
> - Nom du champ Carte.
> - Nom du champ Table, Table hiérarchique, Tableau croisé dynamique, Tableur ou Liste.
> - Nom de la fenêtre.
> - Nom du champ Traitement de texte.
> - Nom du champ Lecteur PDF.
> - Nom du champ Caméra.
> - Nom du champ Editeur de diagrammes.

#### Modifier le zoom effectué

```wlangage
<Elément manipulé>.Zoom = <Nouveau zoom>
```

`<Elément manipulé>` *Nom de champ ou nom de fenêtre*
> Nom de l'élément à manipuler :
>
> - Nom du champ Image.
> - Nom du champ Organigramme.
> - Nom du champ Carte.
> - Nom du champ Table, Table hiérarchique, Tableau croisé dynamique, Tableur ou Liste.
> - Nom de la fenêtre.
> - Nom du champ Traitement de texte.
> - Nom du champ Lecteur PDF.
> - Nom du champ Caméra.
> - Nom du champ Editeur de diagrammes.
`<Nouveau zoom>` *Entier ou constante de type Entier*
> Nouvelle valeur du zoom à appliquer à l'élément.
> > _(WINDEV, Android, iPhone/iPad, Widget IOS)_ Pour un champ Lecteur PDF, cette valeur peut correspondre :à un pourcentage.à une des constantes suivantes :zoomAdapteHauteurAffiche le fichier PDF en pleine hauteur dans le champ Lecteur PDF.zoomAdapteLargeurAffiche le fichier PDF en pleine largeur dans le champ Lecteur PDF.zoomAdapteTailleAffiche le fichier PDF en entier dans le champ Lecteur PDF.Remarque : quand un nouveau fichier PDF est chargé dans le champ, la valeur du zoom n'est pas conservée.
>
> > _(WINDEV, Android, iPhone/iPad, Widget IOS)_ Pour un champ Image, cette valeur peut correspondre :à un pourcentage.à une des constantes suivantes :zoomAdapteHauteurAffiche l'image en pleine hauteur dans le champ Image.zoomAdapteLargeurAffiche l'image en pleine largeur dans le champ Image.zoomAdapteTailleAffiche l'image en entier dans le champ Image.Remarque : quand une nouvelle image est chargée dans le champ, la valeur du zoom n'est pas conservée.
>
> > _(WINDEV, WEBDEV - Code Serveur, WEBDEV - Code Navigateur, Android, iPhone/iPad, Widget IOS, PHP, WINDEV, WINDEV, WINDEV, WINDEV, Android, iPhone/iPad, WINDEV, WEBDEV - Code Serveur)_ Pour un champ Carte : cette valeur est comprise entre 1 (affichage de la terre entière) et 21. cette valeur peut correspondre à la constante suivante : zoomAdapteTailleAdapte le zoom du champ Carte pour que tous les marqueurs soient visibles en même temps. Pour un champ Organigramme, cette valeur correspond à un pourcentage.
>  Pour un champ Table, Table hiérarchique, Tableau croisé dynamique, Tableur ou Liste : cette valeur correspond à un pourcentage. Pour une fenêtre, cette valeur correspond à un pourcentage. Pour un champ Traitement de texte, cette valeur correspond à un pourcentage. Pour un champ Caméra, cette valeur est comprise entre les valeurs des propriétés ZoomMin et ZoomMax. Pour un champ Editeur de diagrammes, cette valeur correspond au pourcentage de zoom.

## Remarques

> _(WINDEV, Etats et Requêtes, Windows, Code Utilisateur (MCU))_ Fonctions de dessin, zoom et ascenseurs automatiquesL'option "Ascenseurs et zoom automatiques" disponible sur un champ Image est incompatible avec la fonction dDébutDessin. Si cette option est utilisée sur le champ Image, la fonction dDébutDessin entraîne un affichage figé dans le champ. Le zoom est également figé. Le comportement redevient normal lors de l'appel de la fonction dFinDessin.Le même effet peut être constaté avec les fonctions dPixelCouleur et dRotation.

> _(Android, iPhone/iPad)_ Fonctionnement du zoomLa propriété Zoom correspond à une valeur entre les valeurs des propriétés ZoomMin et ZoomMax. Cette valeur correspond au facteur de grossissement. Par exemple, si la propriété Zoom vaut 2, cela signifie qu'un zoom 'x2' est appliqué. Si la valeur de la propriété Zoom est supérieure à celle de la propriété ZoomMax, le zoom prend la valeur de ZoomMax. Si la valeur de la propriété Zoom est inférieure à celle de la propriété ZoomMin, le zoom prend la valeur de ZoomMin.

### Limite
Cette propriété s'applique uniquement :

- aux champs Image ayant l'option "Ascenseurs et zoom automatiques".
- aux champs Carte.
- aux champs Organigramme.
- aux champs Table, Table hiérarchique, Tableau croisé dynamique, Tableur ou Liste.
- aux fenêtres.
- aux champs Traitement de texte.
- aux champs Lecteur PDF.
- aux champs Caméra.
