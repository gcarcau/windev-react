# DDEItem (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Identifie l'item concerné par un événement DDE.

## Exemple

```wlangage
// Équivalent à : Item = _DDE.Item
Item = DDEItem()
```

## Syntaxe

```wlangage
<Résultat> = DDEItem([<Identifiant connexion>])
```

`<Résultat>` *Chaîne de caractères*
> Item concerné par l'événement DDE.
`<Identifiant connexion>` *Entier optionnel*
> Identifiant de la connexion renvoyé par la fonction [DDEConnecte](3028015.md). Si ce paramètre n'est pas précisé, **DDEItem** utilise la dernière connexion manipulée.

**Composante : wd300std.dll**
