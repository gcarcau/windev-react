# <Source>.RéindexationEnCours (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Avertit si une ré-indexation est en cours sur un fichier de données HFSQL et renvoie le pourcentage de ré-indexation effectué.

## Exemple

```wlangage
SI Client.RéindexationEnCours() <> 0 ALORS
	Trace("Opération impossible, réindexation en cours")
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Source>.RéindexationEnCours([<Jauge>])
```

`<Résultat>` *Entier*
> - 0 si aucune ré-indexation n'est en cours sur le fichier de données,
> - un entier compris entre 1 et 100 indiquant le pourcentage de ré-indexation déjà effectué
`<Source>` *Type correspondant à la source spécifiée*
> Nom du fichier de données manipulé.
`<Jauge>` *Nom de fenêtre, nom de champ ou entier optionnel*
> - Nom de la fenêtre dans laquelle la jauge doit être affichée, ou nom du champ de type Jauge.
> - Identifiant (Handle) de la fenêtre qui affiche la jauge.
>
>
> > _(WEBDEV - Code Serveur)_ Ce paramètre n'est pas pris en compte.

## Remarques

### Ré-indexation
La réindexation ré-organise les index. Pendant la ré-indexation, tout accès aux données est impossible.

> _(WINDEV)_ Par défaut, lors d'un accès à un fichier de données en cours de ré-indexation, le moteur HFSQL affiche une fenêtre indiquant qu'une ré-indexation est en cours. Cette fenêtre sera automatiquement fermée à la fin de la ré-indexation.
Pour plus de détails sur cette fenêtre et sa personnalisation, consultez Gestion assistée des erreurs HFSQL.
