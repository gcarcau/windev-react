# Manipuler un champ Potentiomètre WEBDEV par programmation

> **Disponible :** **WEBDEV** (Windows, Linux, PHP)

## Présentation

WEBDEV permet de manipuler un champ Potentiomètre directement par programmation. Il suffit d'utiliser directement la variable du champ Potentiomètre dans le code.
La variable du champ Potentiomètre :

- correspond au nom du potentiomètre.
- est initialisé avec la position du curseur du potentiomètre.

## Récupérer la position du curseur

**Pour récupérer la position d'un potentiomètre linéaire**, utilisez la syntaxe suivante :
```wlangage
<Position> = <Nom Potentiomètre>
```

<Position> est une variable de type entier qui correspond à la position du curseur.

Remarques :

- Dans le cas d'un potentiomètre d'intervalle, <Position> correspond à la position du curseur principal (curseur de la valeur inférieure).
- Il est également possible d'utiliser la propriété [Valeur](2510130.md).

**Pour récupérer les positions d'un potentiomètre d'intervalle**, il est nécessaire d'utiliser les propriétés [ValeurInférieure](1000020433.md) et [ValeurSupérieure](1000020434.md) :

```wlangage
<Position Inférieure> = <Nom Potentiomètre>.ValeurInférieure<Position Supérieure> = <Nom Potentiomètre>.ValeurSupérieure
```

<Position Inférieure> et <Position Supérieure> sont des variables de type entier.

## Modifier la position du curseur

**Pour modifier la position d'un potentiomètre linéaire**, utilisez la syntaxe suivante :
```wlangage
<Nom Potentiomètre> = <Valeur>
```

<Valeur> est une valeur comprise entre la valeur minimale et la valeur maximale du potentiomètre. Ces valeurs ont été décrites dans la fenêtre de description du champ, ou par programmation, grâce aux propriétés [BorneMin](2510008.md) et [BorneMax](2510009.md).

**Remarque** : Il est également possible d'utiliser la propriété [Valeur](2510130.md).

**Pour modifier la position d'un potentiomètre d'intervalle**, utilisez la syntaxe suivante :

```wlangage
<Nom Potentiomètre>..ValeurInférieure = <Position du curseur principal><Nom Potentiomètre>..ValeurSupérieure = <Position du curseur secondaire>
```

<Position du curseur principal> et <Position du curseur secondaire> sont des valeurs comprises entre la valeur minimale et la valeur maximale du potentiomètre. Ces valeurs ont été décrites dans la fenêtre de description du champ, ou par programmation, grâce aux propriétés [BorneMin](2510008.md) et [BorneMax](2510009.md).

## Propriétés spécifiques à la gestion d'un potentiomètre WEBDEV

Les propriétés suivantes sont spécifiques à la gestion des caractéristiques d'un potentiomètre par programmation.

| [BorneMax](2510009.md) | Permet de connaître et de modifier la borne maximale d'un potentiomètre |
| --- | --- |
| [BorneMin](2510008.md) | Permet de connaître et de modifier la borne minimale d'un potentiomètre |
| [ValeurInférieure](1000020433.md) | Permet de connaître et de modifier la valeur inférieure d'un potentiomètre d'intervalle. |
| [ValeurSupérieure](1000020434.md) | Permet de connaître et de modifier la valeur supérieure d'un potentiomètre d'intervalle. |
| [Vertical](2510133.md) | Permet de savoir si le potentiomètre standard est horizontal ou vertical. |

Pour connaître la liste complète des propriétés du WLangage pouvant être utilisées avec un champ de type Potentiomètre, consultez [Propriétés associées au champ Potentiomètre](1013233.md).
