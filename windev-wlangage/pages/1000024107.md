# <Graphe>.NuageEtiquetteSérie (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Initialise l'étiquette d'une série de données dans un graphe de type "Nuage de points".
Exemple d'étiquette de série : [image: Etiquette de série]

**Rappel** : Par défaut, un graphe n'a aucune étiquette.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

Nouveauté Abonnement

> _(Android)_ Cette fonction est désormais disponible pour les applications Android.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
// Initialise l'étiquette "Achat" de la série de données 3 dans le champ GRF_MonGraphe
GRF_MonGraphe.NuageEtiquetteSérie(3, "Achat")
```

## Syntaxe

```wlangage
<Champ Graphe>.NuageEtiquetteSérie(<Numéro de la série> , <Étiquette>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres, de pages ou d'états).
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Numéro de la série>` *Entier*
> Numéro de la série pour laquelle une étiquette doit être initialisée.
`<Étiquette>` *Chaîne de caractères*
> Libellé de l'étiquette à initialiser.

## Remarques

- Il est possible de modifier la police de l'étiquette grâce à la fonction [<Graphe>.PoliceEtiquette](1000024117.md).
- Les données définies avec la fonction **<Graphe>.NuageEtiquetteSérie** seront prises en compte lors du prochain appel à la fonction [<Graphe>.Dessine](1000024062.md).
- La fonction **<Graphe>.NuageEtiquetteSérie** est équivalente à la fonction [<Graphe>.EtiquetteSérie](1000024073.md).
  La syntaxe de [<Graphe>.EtiquetteSérie](1000024073.md) utilisée avec des graphes de type "Nuage de points" est la suivante :
  ```wlangage
  <Champ Graphe>.EtiquetteSérie(2*<Indice>-1, <Étiquette>)
  ```
  **Rappel** : Un graphe de type "Nuage de points" utilise les données par groupe de deux séries (pour plus de détails, consultez la fonction [<Graphe>.NuageAjouteDonnéeXY](1000024105.md)).
