# <Carte>.FinDéplacement (Fonction)

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Arrête le suivi du déplacement de l'appareil dans un champ Carte. Ce suivi de déplacement a été précédemment lancé avec la fonction [<Carte>.SuitDéplacement](1000022464.md).

## Exemple

```wlangage
// Démarre le suivi du déplacement dans le champ Carte
CARTE_Position.SuitDéplacement()
...
// Stoppe le suivi du déplacement dans le champ Carte
CARTE_Position.FinDéplacement()
```

## Syntaxe

```wlangage
<Champ Carte>.FinDéplacement()
```

`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler.
