# AngleTitre (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

La propriété **AngleTitre** permet de :

- Savoir si le titre d'une colonne d'un champ Table (ou de toutes les colonnes du champ Table) est incliné.
- Incliner ou non le titre d'une colonne d'un champ Table (ou de toutes les colonnes du champ Table).

**Remarque** : Si le titre est incliné, la hauteur du titre est adaptée en conséquence pour laisser voir les titres des colonnes.

[image: Propriété AngleTitre sur un champ Table]

Cette propriété peut également être utilisée sur une colonne. Il est possible d'incliner une seule colonne d'un champ Table.

## Exemple

```wlangage
TABLE_TABLE1.COL_Colonne1.Titre = "Titre vraiment long"
TABLE_TABLE1.AngleTitre = 50
```

```wlangage
// Inclinaison uniquement du titre de la colonne 1
TABLE_TABLE1.COL_Colonne1.AngleTitre = 50
```

## Syntaxe

#### Savoir si le titre d'une colonne est incliné

```wlangage
<Inclinaison> = <Champ manipulé>.AngleTitre
```

`<Inclinaison>` *Entier*
> Degré d'inclinaison du titre de la colonne. Ce degré d'inclinaison peut être compris entre 0 (titre horizontal) et 90 (titre vertical). Par défaut, l'inclinaison est de 0 (titre horizontal)
`<Champ manipulé>` *Nom de champ*
> Nom du champ manipulé :
>
> - Nom du champ Table ou Table hiérarchique.
> - Nom de la colonne du champ Table ou Table hiérarchique.

#### Incliner ou non les titres des colonnes

```wlangage
<Champ manipulé>.AngleTitre = <Inclinaison>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ manipulé :
>
> - Nom du champ Table ou Table hiérarchique.
> - Nom de la colonne du champ Table ou Table hiérarchique.
`<Inclinaison>` *Entier*
> Degré d'inclinaison du titre de la colonne. Ce degré d'inclinaison peut être compris entre 0 (titre horizontal) et 90 (titre vertical).

## Remarques

### Cas particuliers

- Si un angle est précisé, la position des différentes icônes des colonnes (colonne triée, colonne triable, recherche et filtre) devient fixe.
- Les angles inférieurs à 10 degrés sont représentés par des angles de 10 degrés au moins.
- La propriété est sans effet sur les champs Table orientés à 90 degrés (c'est-à-dire avec les titres situés à gauche et non en haut).
- Si les fonctions de gestion des graphiques ([gImage](3029042.md), [gPoliceGras](3029061.md), etc.) sont utilisées dans les titres des colonnes, lorsque le titre est incliné avec la propriété **AngleTitre**, ces fonctions n'ont plus d'effet.

### Limite
La propriété **AngleTitre** s'applique uniquement aux champs Table et Table hiérarchique d'une fenêtre.
