# <Variable Connexion>.RSDéclenche (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Exécute immédiatement une réplication périodique entre serveurs HFSQL : la réplication se déclenche avant la planification prévue.

## Exemple

```wlangage
MaConnexion est une Connexion

ConfigRéplication1 est un hRSConfig
...
MaConnexion.RSDéclenche(ConfigRéplication1.Identifiant)
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.RSDéclenche(<Réplication à déclencher>)
```

`<Résultat>` *Booléen*
> - Vrai si la réplication a été déclenchée,
> - Faux dans le cas contraire. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion vers le serveur HFSQL maître de la réplication.
`<Réplication à déclencher>` *Entier*
> Identifiant la réplication à déclencher. Cet identifiant correspond à la propriété **Identifiant** de la variable de type [hRSConfig](1000020484.md) décrivant la réplication.

**Composante : wd300hf.dll**
