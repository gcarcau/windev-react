# AutoLanceSupprime (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Permet d'arrêter le lancement automatiquement d'une application WINDEV. Ce lancement automatique a été préalablement défini avec la fonction [AutoLanceAjoute](3019002.md).

## Exemple

```wlangage
// -- A partir d'une application WINDEV standard
// Lancement automatique de l'application "MonAppli" au démarrage
AutoLanceAjoute(alDémarrage, "MonAppli", fRepExe() + "\GestionClients.exe")
...
// Arrêt du lancement automatique de l'application "MonAppli"
AutoLanceSupprime(alDémarrage, "MonAppli")
```

## Syntaxe

```wlangage
AutoLanceSupprime(<Événement du lancement> , <Application>)
```

`<Événement du lancement>` *Constante de type entier*
> Événement qui provoquait le lancement de l'application :
>
> | *alDémarrage* | Lancement de l'application lors du démarrage du poste PC en cours. |
> | --- | --- |
`<Application>` *Chaîne de caractères*
> Nom de l'application défini avec la fonction [AutoLanceAjoute](3019002.md).

## Remarques

### Gestion des erreurs
**Attention** : La fonction **AutoLanceSupprime** ne retourne pas de code d'erreur. Pour savoir si cette fonction a généré une erreur, utilisez la variable [ErreurDétectée](3087001.md). En cas d'erreur, il est possible de connaître le détail de l'erreur grâce à la fonction [ErreurInfo](3013008.md).
