# Fonctions de gestion des champs Jauge

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur)

Les fonctions permettant de gérer les champs Jauge dans un site WEBDEV sont les suivantes :

| [JaugeActive](1000019477.md) | Active le rafraîchissement d'une jauge via Ajax. |
| --- | --- |
| [JaugeDésactive](1000019478.md) | Stoppe le rafraîchissement périodique d'une jauge via Ajax. |
| [JaugeExécute](1000019481.md) | Lance un traitement navigateur relativement long et fait avancer une jauge via Ajax selon l'avancement de ce traitement. |
