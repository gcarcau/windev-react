# Procédure WLangage appelée par la fonction inAppRestaureAchats

> **Disponible :** **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Procédure (également appelée "Callback") appelée par la fonction [inAppRestaureAchats](1000020879.md) lorsqu'un achat est restauré par le store. Cette procédure peut être une procédure locale, globale ou interne.

## Exemple

```wlangage
TableauSupprimeTout(gtabRecu_iOS)
SablierRéseau(Vrai)
inAppRestaureAchats(ProcRestauration)
```

```wlangage
// -----------------------------------------
PROCÉDURE ProcRestauration(bSuccès est un booléen, ...
		ProduitAcheté est un inAppProduit, nQuantité est un entier)
SI bSuccès ALORS
	stRecu est un ST_Recu_iOS
	stRecu.nQuantité = nQuantité
	stRecu.prodProduit = ProduitAcheté
	TableauAjoute(gtabRecu_iOS, stRecu)
	// Rafraîchissement du champ Zone répétée
	ZRAfficheRecu_iOS()
	SablierRéseau(Faux)
SINON
	Erreur("Erreur lors de la restauration des achats : " + ErreurInfo())
FIN
```

## Syntaxe

```wlangage
inAppRestaureAchats_Callback(<Succès> , <Produit> , <Quantité>)
```

`<Succès>` *Booléen*
> - Vrai si le produit a été restauré,
> - Faux dans le cas contraire. Pour récupérer le détail de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avant tout autre appel à une fonction WLangage (ce qui réinitialiserait l'erreur).
`<Produit>` *Variable de type inAppProduit*
> Variable de type [inAppProduit](1000020868.md) correspondant au produit à restaurer.
`<Quantité>` *Entier*
> Quantité du produit à restaurer.
