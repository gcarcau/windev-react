# Vide (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux)

La propriété **Vide** permet de savoir si un élément est vide. Cette propriété est utilisable sur :

- les éléments suivants :
  - les champs Zone répétée, Graphe, ...
  - les tableaux, les files, les piles.
   Pour plus de détails, consultez [Vide](2510126.md).
- une variable de type [xmlAttribut](1000018799.md).
