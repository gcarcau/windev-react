# Altitude (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Altitude** permet de connaître et de modifier l'altitude d'un élément. Cette propriété est utilisable sur :

- les champs d'une fenêtre ou d'un état. Pour plus de détails, consultez l'aide de la propriété [Altitude](2510002.md).
   Cette propriété permet uniquement de connaître l'altitude d'un champ.
- une variable de type [géoPosition](1000019191.md).
- une variable de type [docElémentImage](1000022696.md).
- une variable de type [docElémentZoneDeTexte](1000023420.md).
- une variable de type [Marqueur](1000019940.md).
- une variable de type [CarteCercle](1000025504.md).
- une variable de type [CarteImage](1000025523.md).
- une variable de type [CartePolygone](1000025476.md).
- une variable de type [CartePolyligne](1000025489.md).
- une variable de type [diagSélection](1410088172.md).
- une variable de type [diagActionAutorisée](1410088840.md).
