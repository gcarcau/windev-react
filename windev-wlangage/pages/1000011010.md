# La structure RendezVous

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

## Présentation

La structure RendezVous est une structure prédéfinie du WLangage (aucune déclaration n'est nécessaire). Cette structure permet de :

- créer ou modifier un rendez-vous.
- récupérer le contenu d'un rendez-vous.

Elle est utilisée pour manipuler les agendas de Outlook et Lotus Notes.

## Les différentes variables de la structure RendezVous

La structure est composée des membres suivants :

| **mRendezVous.AvecRépétition** | Booléen. Indique si le rendez-vous est périodique. Cette variable est disponible uniquement en lecture. |
| --- | --- |
| **mRendezVous.Catégorie** | Chaîne de caractères. Catégorie du rendez-vous |
| **mRendezVous.DateCréation** | Date.  Date de création du rendez-vous. |
| **mRendezVous.DateDébut** | Date. Date de début du rendez-vous. |
| **mRendezVous.DateDernièreModification** | Date. Date de dernière modification du rendez-vous. |
| **mRendezVous.DateFin** | Date. Date de fin du rendez-vous Lors de l'ajout d'un rendez-vous (fonction [RendezVousAjoute](1000011001.md)), si la date de fin de rendez-vous n'est pas spécifiée, la date de fin correspond automatiquement à la date de début. Lors de la modification d'un rendez-vous (fonction [RendezVousModifie](1000011003.md)), si la date de fin du rendez-vous en cours n'est pas valide, la date de fin correspond automatiquement à la date de début. |
| **mRendezVous.Disponibilité** | Entier. Indique la disponibilité de la personne :  - 0 : Disponible - 1 : Provisoire - 2 : Occupé - 3 : Absent du bureau  Ces informations sont disponibles sous Outlook uniquement. |
| **mRendezVous.EnDehors** | Booléen. Indique s'il y a un rendez-vous courant (Vrai) ou non (Faux). Cette variable permet par exemple de déterminer si la boucle de lecture des rendez-vous est terminée ou non. |
| **mRendezVous.Enligne** | Booléen. Indique si le rendez-vous est en ligne. |
| **mRendezVous.ID** | Chaîne de caractères. Identifiant unique du rendez-vous. Cette variable est disponible en lecture uniquement. |
| **mRendezVous.JournéeEntière** | Booléen. Indique si le rendez-vous est défini pour la journée entière. |
| **mRendezVous.Lieu** | Chaîne de caractères. Lieu du rendez-vous. |
| **mRendezVous.NbParticipant** | Entier. Nombre de participants au rendez-vous. |
| **mRendezVous.NbParticipantCc** | Entier. Nombre de participants cachés au rendez-vous. |
| **mRendezVous.NbParticipantCci** | Entier. Nombre de participants cachés et invisibles au rendez-vous. |
| **mRendezVous.Notes** | Chaîne de caractères. Notes sur le rendez-vous. |
| **mRendezVous.Objet** | Chaîne de caractères.  Objet du rendez-vous. |
| **mRendezVous.Participant** | Tableau de chaîne de caractères. Nom des participants du rendez-vous (Outlook uniquement, jusqu'à Outlook version 2003).  Pour accéder aux différents participants du rendez-vous, utilisez le format suivant :    ```wlangage mRendezVous.Participant[<Num participant>] ```   Où <Num participant correspond au numéro du participant voulu. Le nombre de participants du rendez-vous peut être connu grâce à la variable mRendezVous.NbParticipant. Remarque : Sous Outlook :   - Par défaut, sous Outlook, les participants correspondent aux contacts du rendez-vous. - Pour gérer les versions récentes de Outlook, il est possible d'indiquer le mode de gestion des contacts dans les fonctions [EmailOuvreSessionOutlook](3032128.md) et [OutlookOuvreSession](3032123.md). La variable mRendezVous.Participant contiendra alors soit les contacts des rendez-vous, soit les participants du rendez-vous. |
| **mRendezVous.ParticipantCc** | Tableau de chaîne de caractères. Nom des participants cachés du rendez-vous.   Pour accéder aux différents participants cachés du rendez-vous, utilisez le format suivant :    ```wlangage mRendezVous.ParticipantCc[<Num participant>] ```   Où <Num participant correspond au numéro du participant caché voulu. Le nombre de participants cachés du rendez-vous peut être connu grâce à la variable mRendezVous.NbParticipantCc. **Remarques** :   - Cette variable est utilisée pour les agendas Lotus Notes. - Pour gérer les versions récentes de Outlook, il est possible d'indiquer le mode de gestion des contacts dans les fonctions [EmailOuvreSessionOutlook](3032128.md) et [OutlookOuvreSession](3032123.md). Si le mode de gestion correspond à la constante *outlookRDVAvecParticipant*, la variable mRendezVous.ParticipantCc contiendra alors les participants cachés du rendez-vous. |
| **mRendezVous.ParticipantCci** | Tableau de chaîne de caractères. Nom des participants cachés et invisibles du rendez-vous.   Pour accéder aux différents participants cachés et invisibles du rendez-vous, utilisez le format suivant :   ```wlangage mRendezVous.ParticipantCci[<Num participant>] ```   Où <Num participant correspond au numéro du participant caché et invisible voulu. Le nombre de participants cachés et invisibles du rendez-vous peut être connu grâce à la variable mRendezVous.NbParticipantCci. **Remarques** :   - Cette variable est utilisée pour les agendas Lotus Notes. - Pour gérer les versions récentes de Outlook, il est possible d'indiquer le mode de gestion des contacts dans les fonctions [EmailOuvreSessionOutlook](3032128.md) et [OutlookOuvreSession](3032123.md). Si le mode de gestion correspond à la constante *outlookRDVAvecParticipant*, la variable mRendezVous.ParticipantCci contiendra alors les participants cachés et invisibles du rendez-vous. |
| **mRendezVous.Privé** | Booléen. Indique si le rendez-vous est privé. |
| **mRendezVous.RappelAuto** | Booléen. Indique si un rappel automatique doit être effectué pour le rendez-vous. Ce rappel sera réalisé <mRendezVous.RappelAvant minutes avant l'heure du rendez-vous. |
| **mRendezVous.RappelAvant** | Entier. Si un rappel automatique est demandé, ce rappel sera réalisé <mRendezVous.RappelAvant minutes avant l'heure du rendez-vous. Cette variable est prise en compte uniquement si un rappel automatique doit être effectué (mRendezVous.RappelAuto). |
