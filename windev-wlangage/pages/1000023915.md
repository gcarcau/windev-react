# DonneUUID (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Calcule un identifiant unique Universel (nommé "UUID") ayant pour taille 128 bits.
Cet identifiant est unique dans le monde quelle que soit la machine sur laquelle il a été produit.

## Exemple

```wlangage
MonUUID est un UUIDMonUUID = DonneUUID()// Exemple du UUID calculé : 95431e57-7d18-4fef-9d9d-96b231969149
```

## Syntaxe

```wlangage
<Résultat> = DonneUUID()
```

`<Résultat>` *UUID*
> Identifiant généré.
> Le UUID renvoyé est formaté pour un affichage avec des séparateurs. Par exemple : "95431e57-7d18-4fef-9d9d-96b231969149".

**Classification Métier / UI : Code neutre**

**Composante : wd300std.dll**
