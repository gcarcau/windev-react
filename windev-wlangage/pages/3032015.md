# EmailLitEntêteDernier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Lit l'entête du dernier email reçu :

- soit par le protocole POP3 ou IMAP : l'email est présent dans la boîte aux lettres sur le serveur de messagerie.
- soit par l'intermédiaire du logiciel de messagerie Lotus Notes ou Outlook : l'email reçu est présent sur le poste local dans la boîte de réception de Lotus Notes ou Outlook.

Les différentes variables de la structure [Email](3032029.md) (ou les propriétés d'une variable de type [Email](1000018713.md)) correspondant à l'entête du message sont remplies.

Cette fonction est utile lorsque la lecture de l'email est par exemple liée à la taille du message.

Si aucun email n'est trouvé, la variable Email.EnDehors est positionnée à Vrai.

**Rappel** : Avant de lire un email, il est nécessaire d'ouvrir une session avec la fonction [EmailOuvreSession](3032028.md), [EmailOuvreSessionNotes](3032121.md) ou [EmailOuvreSessionOutlook](3032128.md).

> _(Java)_ Seule la lecture par le protocole POP3 est disponible.

## Exemple
**Exemple utilisant la structure Email**

```wlangage
// Supprime les emails envoyés par des expéditeurs "black-listés"

EmailOuvreSessionPOP3("utilisateur", "secret", "pop.masociete.fr")

// Parcours des emails
// Lecture de l'entête uniquement
SI EmailLitEntêteDernier("utilisateur") ALORS
	BOUCLE
		// Est-ce-que l'expéditeur fait partie d'une
		// liste de gens "interdit" ?
		SI ExpediteurInterdit(Email.AdresseExpéditeur) OU ...
			ExpediteurInterdit(Email.Expéditeur) ALORS
			// Si l'email est "interdit", on le supprime
			// Les emails "autorisés" pourront alors être
			// lus complètement dans un deuxième temps
			EmailSupprimeMessage("utilisateur")
		FIN
	À FAIRE TANTQUE EmailLitEntêtePrécédent("utilisateur")
FIN
```

**Exemple utilisant une variable de type Email**

```wlangage
// Supprime les emails envoyés par des expéditeurs "black-listés"

MaSession est une emailSessionPOP3
MaSession.AdresseServeur = "pop.masociete.fr"
MaSession.Nom = "utilisateur"
MaSession.MotDePasse = "secret"
EmailOuvreSession(MaSession)

// Parcours des emails
POUR TOUT MessageEmail DE MaSession
	// Est-ce-que l'expéditeur fait partie d'une
	// liste de gens "interdit" ?
	SI ExpéditeurInterdit(MessageEmail..AdresseExpéditeur) OU ...
			ExpediteurInterdit(MessageEmail..Expediteur) ALORS
		// Si l'email est "interdit", on le supprime
		// Les emails "autorisés" pourront alors être
		// lus complètement dans un deuxième temps
		EmailSupprimeMessage(MaSession, MessageEmail)
	FIN
FIN
```

## Syntaxe

#### Lire l'entête du dernier email géré par le protocole POP3 ou IMAP

```wlangage
<Résultat> = EmailLitEntêteDernier(<Session> [, <Email>])
```

`<Résultat>` *Booléen*
> - Vrai si l'entête du message a été lu. Dans ce cas, la structure email est automatiquement mise à jour.
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
>
>
> La variable Email.EnDehors est positionnée à Vrai si aucun message n'a été trouvé (pas de mail).
`<Session>` *Chaîne de caractères ou variable de type emailSessionPOP3 ou emailSessionIMAP*
> Identifie la session d'un utilisateur. Correspond :
>
> - au nom d'utilisateur utilisé pour ouvrir la session email (fonction [EmailOuvreSession](3032028.md)).
> - à une variable de type [emailSessionPOP3](1000018759.md).
> - à une variable de type [emailSessionIMAP](1000018957.md).
>
>
> > _(Java)_ Les variables de type emailSessionPOP3 et emailSessionIMAP ne sont pas supportées.
`<Email>` *Variable de type Email optionnelle*
> Nom de la variable de type [Email](1000018713.md) correspondant à l'email à initialiser avec le contenu du message.
> Si ce paramètre n'est pas spécifié, la structure [Email](3032029.md) est utilisée.
>
> > _(Java)_ Ce paramètre n'est pas disponible

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ Lire l'entête du dernier email géré par l'intermédiaire de Lotus Notes ou Outlook Masquer les détails
<Résultat> = EmailLitEntêteDernier(<Session> [, <Email> [, <Mode de lecture>]])

 <Résultat> : BooléenVrai si l'entête du message a été lu. Dans ce cas, la structure email est automatiquement mise à jour.Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction ErreurInfo avec la constante errMessage.La variable Email.EnDehors est positionnée à Vrai si aucun message n'a été trouvé (pas de mail). <Session> : EntierIdentifiant de la session email en cours. Cet identifiant peut être :un entier renvoyé par la fonction EmailOuvreSessionOutlook ou OutlookOuvreSession.une variable de type emailSessionOutlook.une variable de type emailSessionNotes.une variable de type emailSessionIMAP. <Email> : Variable de type Email optionnelleNom de la variable de type Email correspondant à l'email à initialiser avec le contenu du message.Si ce paramètre n'est pas spécifié, la structure Email est utilisée. <Mode de lecture> : Constante ou chaîne de caractères optionnellePrécise les messages qui doivent être lus :emailNonLus ou "NON LUS"Seuls les messages qui n'ont pas été consultés seront lus.emailTous ou "TOUS"(Valeur par défaut)Tous les messages seront lus.

## Remarques

### La structure email et les variables de type Email
Deux méthodes de manipulation des emails sont disponibles :

- [La structure Email](3032029.md) est une structure globale permettant de manipuler simplement un message.
- [Les variables de type Email](1000018713.md) offrent des fonctionnalités plus avancées (data binding, sérialisation, instances multiples).

> _(WINDEV, WEBDEV - Code Serveur)_ Messagerie OutlookLes fonctions WLangage EmailLitxxx fonctionnent uniquement avec le fichier de données Outlook (.pst) par défaut. Les autres fichiers de données ne sont pas gérés.

**Composante : wd300com.dll**
