# Fonctions multimédia (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions Multimédia (syntaxe préfixée) permettent de manipuler les fichiers multimédia associés aux champs Multimédia.

| [<Multimédia>.Arrêt](1000019987.md) | Arrête la lecture en cours d'un fichier multimédia dans un champ Multimédia. |
| --- | --- |
| [<Multimédia>.Début](1000019988.md) | Place au début du fichier multimédia joué dans le champ Multimédia. |
| [<Multimédia>.Durée](1000019989.md) | Renvoie la taille du fichier multimédia en cours de lecture (en millisecondes) dans le champ Multimédia. |
| [<Multimédia>.Etat](1000019990.md) | Indique l'état du fichier multimédia joué dans le champ Multimédia. |
| [<Multimédia>.Fin](1000019991.md) | Place à la fin du fichier multimédia joué dans le champ Multimédia. |
| [<Multimédia>.Hauteur](1000019999.md) | Renvoie la hauteur en pixels de l'image source du fichier multimédia joué dans le champ Multimédia. |
| [<Multimédia>.Joue](1000020089.md) | Joue un fichier multimédia dans un champ Multimédia. |
| [<Multimédia>.Largeur](1000020093.md) | Renvoie la largeur en pixels de l'image source du fichier multimédia joué dans le champ Multimédia. |
| [<Multimédia>.Pause](1000020094.md) | Met en pause la lecture d'un fichier multimédia dans un champ Multimédia. |
| [<Multimédia>.Position](1000020095.md) | Renvoie ou modifie la position en cours du fichier multimédia en cours dans le champ Multimédia. |
| [<Multimédia>.Volume](1000020096.md) | Renvoie ou modifie le volume sonore du fichier multimédia joué dans un champ Multimédia. |
