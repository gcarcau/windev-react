# HTTPCookieLit (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Retourne la valeur d'un cookie reçu suite à une requête HTTP.
**Remarque** : Les cookies lus et envoyés par la fonction [HTTPRequête](3043007.md) sont uniquement conservés en mémoire dans l'application. Ils n'ont pas de rapport avec les cookies des navigateurs Web installés sur le poste.

## Exemple

```wlangage
// Effectue une requête HTTP
HTTPRequête("www.monsite.fr")
// Affiche le cookie d'identification renvoyé par le serveur
sID est une chaîne = HTTPCookieLit(".monsite.fr", "ID")
Info("Cookie d'identification = " + sID)
```

## Syntaxe

#### Syntaxe utilisable avec la fonction HTTPRequête

```wlangage
<Résultat> = HTTPCookieLit(<Domaine> , <Nom>)
```

`<Résultat>` *Chaîne de caractères*
> - Valeur du cookie.
> - Chaîne vide ("") si le cookie n'existe pas. La variable [ErreurDétectée](3087001.md) est alors à Vrai.
`<Domaine>` *Chaîne de caractères*
> Nom du domaine pour lequel le cookie a été reçu.
`<Nom>` *Chaîne de caractères*
> Nom du cookie.

> _(WINDEV, WEBDEV - Code Serveur, Android, Widget Android, iPhone/iPad, Ajax)_ Syntaxe utilisable avec la fonction HTTPEnvoie Masquer les détails
<Résultat> = HTTPCookieLit(<Requête HTTP> , <Domaine> , <Nom>)

 <Résultat> : Chaîne de caractèresValeur du cookie.Chaîne vide ("") si le cookie n'existe pas. La variable ErreurDétectée est alors à Vrai. <Requête HTTP> : Variable de type httpRequêteNom de la variable httpRequête pour laquelle le cookie doit être lu. <Domaine> : Chaîne de caractèresNom du domaine pour lequel le cookie a été reçu. <Nom> : Chaîne de caractèresNom du cookie.

## Remarques

Pour utiliser la fonction **HTTPCookieLit**, la gestion des cookies doit avoir été activée par la fonction [HTTPCookieGère](1000019218.md).
