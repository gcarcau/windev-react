# OKAnnuler (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Affiche un message dans une boîte de dialogue standard proposant les réponses "OK" et "Annuler" et renvoie la réponse de l'utilisateur.
[image: Dialogue OK / Annuler]
Remarques :

- **Cette boîte de dialogue est bloquante**. Pour continuer l'exécution de l'application, l'utilisateur doit valider un des boutons.
   Pour ne pas bloquer l'application, utilisez la fonction [OKAnnulerAsynchrone](1000025308.md).
- WINDEV permet d'appliquer le gabarit de votre projet à cette boîte de dialogue. Pour plus de détails, consultez [Personnaliser les boîtes de dialogue](3021003.md).

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Android, iPhone/iPad, Java, Code Utilisateur (MCU))_ // Suppression d'une ligne avec confirmation (oui par défaut)
SI OKAnnuler("Supprimer cet enregistrement ?") ALORS
 HSupprime(CLIENT)
FIN

> _(WINDEV, Etats et Requêtes, Android, iPhone/iPad, Java, Code Utilisateur (MCU))_ // Choix pour la sortie du programme
SI OKAnnuler("Voulez-vous quitter le programme?") = Oui ALORS
 Ferme()
FIN

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Android, iPhone/iPad, Java, Code Utilisateur (MCU))_ // Demande de confirmation de la suppression du fichier dont
// le nom est contenu dans la variable NOM_FIC, avec
// positionnement sur le bouton "Non" de la fenêtre OKAnnuler
SI OKAnnuler(Non, "Supprimer le fichier ?") ALORS
 fSupprime(NOM_FIC)
FIN

## Remarques

### Caractéristiques de la boîte de dialogue

- Le titre de la boîte de dialogue correspond au titre de la fenêtre (ou page) en cours.
   Pour respecter les spécifications du système, le titre de la boîte de dialogue est vide par défaut. Pour définir ce titre, utilisez la fonction [TitreSuivant](3038043.md).
- Pour modifier ou définir le titre de la boîte de dialogue, utilisez la fonction [TitreSuivant](3038043.md).

- Le message est cadré à gauche.
- Les libellés des boutons dépendent de la langue d'exécution de Windows.
- Le nombre maximum de caractères affichés est limité à 4096. Si une chaîne plus grande est passée en paramètre, elle sera tronquée.
- L'icône affichée (point d'exclamation) ne peut pas être modifiée.

> _(WINDEV)_ Pour personnaliser cette boîte de dialogue (ainsi que toutes les boîtes de dialogue système de votre application), cochez l'option "Personnaliser les fenêtres système (Info, OuiNon, Confirmer, Dialogue)" dans l'onglet "Style" de la description du projet. Pour plus de détails, consultez Personnaliser les boîtes de dialogue.

> _(WEBDEV - Code Serveur)_ Pour personnaliser cette boîte de dialogue (ainsi que toutes les boîtes de dialogue système de votre site), cochez l'option "Appliquer l'ambiance sur les boîtes de dialogue (OuiNon et OKAnnuler)" dans l'onglet "Ambiance" de la fenêtre de description du projet.

> _(WEBDEV - Code Navigateur)_ Affichage de la boîte de dialogueL'affichage de la boîte de dialogue n'est pas bloquant. La boîte de dialogue est affichée au centre de la page, avec un effet de GFI (Grisage des Fenêtres Inaccessibles).La fonction OKAnnuler utilise la page interne nommée "WEBDEVOKAnnuler". Pour intégrer cette page dans votre projet :Cliquez sur parmi les boutons d'accès rapide. La fenêtre de création d'un nouvel élément s'affiche : cliquez sur "Page" puis sur "Page".Cliquez sur "Page interne" dans l'assistant et sélectionnez la page interne "OK / Annuler".Validez. La page "WEBDEVOKAnnuler" est affichée sous l'éditeur.Enregistrez la page en conservant son nom par défaut.

### Saut de ligne dans la boîte de dialogue
La chaîne prédéfinie RC (Retour Chariot) peut être utilisée pour forcer le passage à la ligne suivante. Par exemple :

```wlangage
SI OKAnnuler("Attention : vous allez supprimer cet enregistrement" + RC + ...
	"Voulez-vous continuer ?") ALORS
	HSupprime(CLIENT)
FIN
```

est équivalent à :

```wlangage
SI OKAnnuler("Attention : vous allez supprimer cet enregistrement", ...
	"Voulez-vous continuer ?") ALORS
	HSupprime(CLIENT)
FIN
```

Il est également possible d'utiliser la syntaxe des chaînes multilignes. Par exemple :

```wlangage
OKAnnuler(
[
Attention : vous allez supprimer cet enregistrement.

Voulez-vous continuer ?
])
```

> _(Android)_ Application en arrière-plan : Spécificité à partir de Android 10A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. Conseils : Il est possible de savoir si l'application est en arrière-plan grâce à la fonction EnModeArrièrePlan. Lors du clic sur la notification, l'application sera remise au premier plan si la propriété ActiveApplication est à Vrai. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété ActionClic.Pour plus de détails, consultez Android 10 : Comportement des applications en arrière-plan.
