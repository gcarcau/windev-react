# OrthoVérifie (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Indique si un mot est correctement orthographié (c'est-à-dire s'il est connu du dictionnaire OpenOffice installé sur le poste).

## Exemple

```wlangage
SI OrthoDisponible() = Vrai ET OrthoVérifie(Mot) = Faux ALORS
	Erreur("Mot Incorrect")
FIN
```

## Syntaxe

```wlangage
<Résultat> = OrthoVérifie(<Mot à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai dans les cas suivants :
>   - le mot à vérifier est trouvé dans le dictionnaire OpenOffice,
>   - le mot à vérifier a été ajouté avec la fonction [OrthoAjouteDictionnaire](1000018921.md),
>   - le dictionnaire OpenOffice n'est pas installé. Il est possible de savoir si le correcteur orthographique est installé grâce à la fonction [OrthoDisponible](1000019019.md).
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet de connaître le détail de l'erreur.
`<Mot à vérifier>` *Chaîne de caractères*
> Mot à rechercher dans le dictionnaire de OpenOffice.

**Composante : wd300obj.dll**
