# gglLieu (Type de variable)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Le type **gglLieu** permet de décrire et de modifier le lieu d'un événement d'un agenda Google.
Ce type de variable est utilisé par les variables de type [gglEvénement](1000017440.md).

**Remarques** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Connexion à Google
Cnx est une gglConnexion
...
// Récupération du tableau des agendas disponibles
tabAgendas est un tableau de gglAgenda
tabAgendas = GglRécupèreAgenda(Cnx)
// Récupération des événements du premier agenda
GglRemplitAgenda(Cnx, tabAgendas[1])
// Affichage des lieux du premier événement
MonAgenda est un gglAgenda = tabAgendas[1]
Lieu est un gglLieu
POUR TOUT Lieu DE MonAgenda
	Trace(Lieu.Valeur)
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type gglLieu
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **gglLieu** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Valeur | Chaîne de caractères | Nom et description du lieu. |
