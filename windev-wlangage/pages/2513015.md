# ImageDéroulée (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Mac Catalyst)

La propriété **ImageDéroulée** permet de :

- connaître et/ou de modifier l'image par défaut d'une ligne déroulée dans un champ Table hiérarchique.
- connaître et/ou de modifier l'image par défaut d'une ligne déroulée dans un champ Arbre.
- connaître et/ou de modifier l'image d'une ligne spécifique déroulée dans un champ Table hiérarchique.
- connaître et/ou modifier l'image d'une ligne déroulée dans une rubrique hiérarchique d'un état de type "Tableau hiérarchique".

Cette propriété permet par exemple de définir :

- l'image qui sera utilisée par défaut lors des prochains ajouts dans le champ Table hiérarchique. Cette image sera prise en compte par les fonctions [TableAjoute](3074017.md), [TableAjouteLigne](3074006.md), [TableAjouteFils](1000010004.md), [TableInsère](3074025.md), [TableInsèreLigne](3074026.md), [TableInsèreFils](1000010005.md), ...
- l'image déroulée d'une des lignes du champ Table hiérarchique.
- l'image qui sera utilisée par défaut lors des prochains ajouts dans le champ Arbre. Cette image sera prise en compte par les fonctions [ArbreAjoute](3018012.md) et [ArbreInsère](3018023.md).
- l'image déroulée des lignes d'un état de type "Tableau hiérarchique".

## Exemple

```wlangage
// Définit l'image utilisée pour une ligne déroulée
TABLEH_Recette.ImageDéroulée = "C:\MesImages\Image.BMP"
```

```wlangage
// Change l'image déroulée de la ligne 4
TABLEH_Recette[4].ImageDéroulée = "C:\MesImages\Image.BMP"
```

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad)_ // Change l'image déroulée dans l'état
// -- AvantImpression de RUB_Hiérarchie
SI MoiMême.ProfondeurHiérarchique = 1 ALORS MoiMême.ImageDéroulée = "C:\Images\outil.png"

## Syntaxe

#### Connaître l'image par défaut d'une ligne déroulée ou l'image associée à une ligne spécifique

```wlangage
<Résultat> = <Champ manipulé>.ImageDéroulée
```

`<Résultat>` *Chaîne de caractères*
> - Nom et chemin complet de l'image associée par défaut aux lignes déroulées du champ.
> - Chaîne vide ("") si l'image utilisée par défaut n'a pas été modifiée.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler :
>
> - Champ Table hiérarchique.
> - Champ Arbre.
>
>
> Pour connaître l'image déroulée associée à une ligne spécifique d'un champ Table hiérarchique, il suffit d'utiliser la notation suivante :
>
>
> ```wlangage
> <Champ Table hiérarchique>[<Numéro de la ligne>]
> ```

#### Modifier l'image par défaut d'une ligne déroulée ou l'image associée à une ligne spécifique

```wlangage
<Champ manipulé>.ImageDéroulée = <Nouvelle image>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler :
>
> - Champ Table hiérarchique.
> - Champ Arbre.
>
>
> Pour modifier l'image déroulée associée à une ligne spécifique d'un champ Table hiérarchique, il suffit d'utiliser la notation suivante :
>
>
> ```wlangage
> <Champ Table hiérarchique>[<Numéro de la ligne>]
> ```
`<Nouvelle image>` *Chaîne de caractères*
> Nom et chemin complet de la nouvelle image associée par défaut à une ligne déroulée du champ Table hiérarchique.
> > _(WEBDEV - Code Serveur)_ Le chemin d'accès des images doit être relatif au répertoire "<NomProjet>_WEB". Par exemple, dans ce cas, l'image est dans un sous-répertoire "Images" du répertoire "_WEB" du site :
>
>
> MoiMême.ImageDéroulée = "\Images\Job_16.gif"
> MoiMême.ImageEnroulée = "\Images\Job_16.gif"

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad)_ Connaître l'image d'une rubrique hiérarchique déroulée dans un état "Tableau hiérarchique" Masquer les détails
<Résultat> = <Rubrique hiérarchique>.ImageDéroulée

 <Résultat> : Chaîne de caractèresNom et chemin complet de l'image associée à une ligne déroulée de la rubrique hiérarchique. Chaîne vide ("") si aucune image n'est utilisée. <Rubrique hiérarchique> : Chaîne de caractèresNom de la rubrique hiérarchique à manipuler.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad)_ Modifier l'image d'une rubrique hiérarchique déroulée dans un état "Tableau hiérarchique" Masquer les détails
<Rubrique hiérarchique>.ImageDéroulée = <Nouvelle image>

 <Rubrique hiérarchique> : Chaîne de caractèresNom de la rubrique hiérarchique à manipuler. <Nouvelle image> : Chaîne de caractèresNom et chemin complet de la nouvelle image associée à une ligne déroulée de la rubrique hiérarchique.
