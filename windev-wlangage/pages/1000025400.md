# <Variable mongoCollection>.SupprimeCollection (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Supprime une collection d'une base MongoDB.

## Exemple

```wlangage
cnxMDB est un mongoConnexion
MaCollection est un mongoCollection
MaCollection = cnxMDB.BaseDeDonnées["CRM"].Collection["produit"]
MaCollection.SupprimeCollection()
```

```wlangage
gclCollection est un mongoCollection
gclCollection.SupprimeCollection()
```

## Syntaxe

```wlangage
<Résultat> = <Collection>.SupprimeCollection()
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème. La fonction [ErreurInfo](3013008.md) permet d'identifier l'erreur.
`<Collection>` *Variable de type mongoCollection*
> Nom de la variable de type [mongoCollection](1000022411.md) à supprimer de la base MongoDB.
