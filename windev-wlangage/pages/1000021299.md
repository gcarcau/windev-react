# CarteLicenceGgl (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Indique la clé de licence "Google Maps API" à utiliser dans les champs Carte (de WINDEV ou WEBDEV). Cette clé peut être nécessaire pour utiliser les fonctionnalités "Google Maps API for work". Pour plus de détails, consultez la licence de "Google Maps API".
> _(WEBDEV - Code Serveur, PHP)_ Il est également possible de saisir la licence "Google Maps API" dans la fenêtre de description du projet (onglet "Projet").

> _(WINDEV, iPhone/iPad)_ Important : L'appel de la fonction CarteLicenceGgl doit être réalisé avant l'ouverture de la fenêtre contenant le champ Carte. Si le champ Carte se trouve dans la première fenêtre du projet, l'appel de la fonction CarteLicenceGgl doit être réalisé dans le code d'initialisation du projet.

> _(iPhone/iPad)_ En mode test, le champ Carte utilise le champ Carte de WINDEV. Cette fonction permet de spécifier si nécessaire la clé de licence "Google Maps API" afin que le champ Carte s'affiche correctement lors du GO sur le poste de développement.

## Exemple

```wlangage
// Initialisation de la clé Google
CarteLicenceGgl("ABCDEF12345789abcdef")
```

## Syntaxe

```wlangage
CarteLicenceGgl(<Clé Google>)
```

`<Clé Google>` *Chaîne de caractères ou Chaîne secrète*
> Clé fournie par Google.
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md). Nouveauté 2025
>
> > _(Android, Widget Android)_ Les chaînes secrètes ne sont pas disponibles pour ce paramètre en Android/Android Widget.

## Remarques

- L'utilisation d'un champ Carte est soumise à des conditions d'utilisations spécifiques. Consultez la licence Google sur l'utilisation des services de cartographie.
  | **Attention : A partir du 22 Juin 2016, les conditions d'utilisation des services de cartographie de Google ont évolué**. Il est désormais **obligatoire** de spécifier une clé de licence pour utiliser ce service. Vous devez :   1. Générer la clé dans la console développeur de Google ([https://console.developers.google.com](https://console.developers.google.com)). Les manipulations à réaliser sont les suivantes (à la date d'écriture de cette page) :   - Utilisez un compte Google pour se connecter à la console développeur.  - Créez un projet Google si nécessaire.  - Accédez au "Gestionnaire d'API" du projet.  - Dans la rubrique "API Google Maps", cliquez sur le lien "Google Maps JavaScript API".  - Cliquez sur "Activer" afin d'activer l'API Google Maps Javascript API.  - Dans la rubrique "Identifiants", déroulez le bouton "Créer des identifiants".  - Sélectionnez "Clé d'API".  - Sélectionnez "Clé d'API".   - Dans le cas d'un site WEBDEV, sélectionnez "Clé navigateur". Il est recommandé de préciser le domaine qui utilisera la clé pour le suivi des requêtes et pour éviter toute usurpation.  - Dans le cas d'une application WINDEV, sélectionnez "Clé serveur". Il est recommandé de préciser l'adresse qui utilisera la clé pour le suivi des requêtes et pour éviter toute usurpation.  - Validez la création de la clé, puis copiez la clé créée par Google. 2. Indiquez la clé utilisée dans l'application ou le site grâce à la fonction **CarteLicenceGgl**. |
  | --- |
- Cette fonction permet de spécifier la licence à utiliser pour que le fournisseur de carte Google Maps donne à l'application :
  - **à partir du 22 juin 2016**, accès aux fonctionnalités "Google Maps JavaScript API".
  - accès aux fonctionnalités étendues de "Maps API for work" (nombre de requêtes plus important, suivi, quotas, ...).
- La licence est appliquée à toutes les cartes de l'application et sera utilisée pour tous les nouveaux champs Carte créés après cet appel. Il est recommandé d'appeler cette fonction dans le code d'initialisation du projet.
