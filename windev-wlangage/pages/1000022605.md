# BaseDeDonnées (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **BaseDeDonnées** permet de connaître et de modifier la base de données associée à une connexion. Cette propriété est utilisable sur :

- une connexion. Pour plus de détails, consultez l'aide de la propriété [BaseDeDonnées](2512101.md).
- une variable de type [mongoConnexion](1000022409.md).
- une variable de type [mongoGridFS](1000022416.md).
