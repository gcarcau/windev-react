# SysIconeSupprime (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Supprime une icône de la barre des tâches (à côté de l'horloge). Cette icône a été ajoutée dans la barre des tâches avec la fonction [SysIconeAjoute](3073001.md).
 ou

**Remarque** : L'icône est automatiquement supprimée lors de la fermeture de l'application.

## Exemple

```wlangage
// Suppression de l'icône préalablement ajoutée dans la barre des tâches
ResSuppIcone = SysIconeSupprime()
```

## Syntaxe

```wlangage
<Résultat> = SysIconeSupprime()
```

`<Résultat>` *Booléen*
> - Vrai si l'icône a été supprimée de la barre des tâches,
> - Faux dans le cas contraire.

**Composante : wd300std.dll**
