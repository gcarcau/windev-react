# CadrageVertical (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

La propriété **CadrageVertical** permet de connaître et de modifier le cadrage vertical d'un champ ou d'un texte. Cette propriété est utilisable sur :

- les champs d'une fenêtre ou d'une page. Pour plus de détails, consultez [CadrageVertical](2510054.md).
- une variable de type [pdfSignature](1000022255.md).
- une variable de type [Toast](1000024638.md).
- une variable de type [picTexte](1000025178.md).
- une variable de type [diagTexte](1410088393.md).
