# OBEXEnvoieFichier (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Envoie un fichier sur un périphérique gérant le protocole OBEX.

## Exemple

```wlangage
// Connexion Bluetooth
SI BTConnectePériphérique(COL_ID, "123") = Vrai ALORS
	// Connexion OBEX
	nIDCnxOBEX = OBEXConnecte(obexBluetooth, COL_MAC)
	// Transfert du fichier
	TABLE_PERIPHERIQUES[TABLE_PERIPHERIQUES].CouleurFond = ...
				  SELON (OBEXEnvoieFichier(nIDCnxOBEX, sFichier), ...
						Blanc, RougePastel)
	// Fin du transfert
	OBEXDéconnecte(nIDCnxOBEX)
SINON
	 Erreur("Impossible de se connecter à " + COL_PERIPHERIQUE, ErreurInfo())
FIN
```

## Syntaxe

```wlangage
<Résultat> = OBEXEnvoieFichier(<Identifiant de la connexion OBEX> , <Chemin fichier local> [, <Chemin fichier distant>])
```

`<Résultat>` *Booléen*
> - Vrai si le transfert a réussi,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de renseignements sur le problème rencontré.
>
>
> **Attention** : Si le fichier est refusé par la machine distante, l'émetteur n'est pas informé : la fonction [ErreurInfo](3013008.md) ne contient pas d'erreur spécifique. La fonction [ErreurInfo](3013008.md) contient uniquement les messages d'erreur concernant la transmission.
`<Identifiant de la connexion OBEX>` *Entier*
> Identifiant de la connexion OBEX à utiliser. Cet identifiant est retourné par la fonction [OBEXConnecte](1000017153.md).
`<Chemin fichier local>` *Chaîne de caractères*
> Nom et chemin complet du fichier à envoyer.
`<Chemin fichier distant>` *Chaîne de caractères optionnelle*
> Nom et chemin du fichier sur le périphérique distant. Si ce paramètre n'est pas précisé, le fichier garde le même nom, et est copié dans le répertoire de transfert paramétré sur le périphérique OBEX.

## Remarques

### Localisation du fichier copié
Le fichier est copié dans le répertoire de transfert paramétré sur le périphérique OBEX utilisé. Si le paramètre <Chemin fichier distant> est spécifié, le chemin spécifié sera relatif au répertoire de transfert.

### Transfert de fichiers par infra-rouge
Lors du transfert de fichiers par infra-rouge, le transfert est terminé après l'exécution de **OBEXEnvoieFichier**. Cependant, Windows laisse la fenêtre de transfert ouverte (pour gérer un nouveau transfert potentiel de fichier). Cette fenêtre est fermée uniquement à la déconnexion ([OBEXDéconnecte](1000017154.md)).

### Limitation
Seules les piles bluetooth Microsoft sont supportées par cette fonction. Pour connaître la pile utilisée, utilisez la fonction [BTPile](1000017229.md).
Pour plus de détails sur les clés supportées, consultez [Quelles piles utiliser ?](1000017231.md)
