# Brésil.VérifieCNPJ (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un numéro CNPJ (numéro d'identification d'entreprise au Brésil).

## Exemple

```wlangage
// Test d'une variableMonNuméroCNPJ est une chaîne = "43337004000172"Brésil.VérifieCNPJ(MonNuméroCNPJ) // renvoie Vrai // Test d'un champSAI_NuméroCNPJ = "ABC"Brésil.VérifieCNPJ(SAI_NuméroCNPJ) // renvoie Faux
```

```wlangage
// Test d'une variableMonNuméroCNPJ est une chaîneMonRésultat est un booléenMonRésultat = Saisie("Entrez le numéro CNPJ : ", MonNuméroCNPJ)SI Brésil.VérifieCNPJ(MonNuméroCNPJ) = Faux ALORS Info("Numéro CNPJ invalide")FIN
```

## Syntaxe

```wlangage
<Résultat> = Brésil.VérifieCNPJ(<Numéro à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un numéro CNPJ valide.
> - Faux dans le cas contraire.
`<Numéro à vérifier>` *Nom de champ ou variable de type chaîne*
> Numéro CNPJ à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.

**Composante : wd300std.dll**
