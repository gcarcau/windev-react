# Fonctions de cryptage / compression

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de cryptage / compression (syntaxe préfixée)](1410087290.md)).
Les fonctions de gestion du cryptage et de la compression sont les suivantes :

| [Compresse](3024012.md) | Compresse une chaîne de caractères ou un bloc mémoire (buffer) sous forme binaire. |
| --- | --- |
| [Crypte](3024014.md) | Crypte une chaîne de caractères sous forme binaire ou sous forme ASCII. |
| [CrypteAsymétrique](1000024049.md) | Crypte un buffer en utilisant un algorithme de chiffrement asymétrique (RSA) nécessitant une clé publique et une clé privée. |
| [CrypteAsymétriqueEnveloppé](1000024057.md) | Réalise un cryptage asymétrique d'une enveloppe. |
| [CrypteGénèreCléRSA](1000024052.md) | Génère un couple clé privée/clé publique au format RSA. |
| [CrypteStandard](1000021293.md) | Crypte une chaîne de caractères ou un buffer binaire en utilisant un algorithme de chiffrement symétrique (AES, DES, etc.). |
| [Décode](1000022259.md) | Décode une chaîne de caractères précédemment encodée avec la fonction [Encode](1000022258.md). |
| [Décompresse](3024009.md) | Décompresse un bloc mémoire (buffer) préalablement compressé par la fonction [Compresse](3024012.md). |
| [Décrypte](3024035.md) | Décrypte une chaîne de caractères préalablement cryptée par la fonction [Crypte](3024014.md). |
| [DécrypteAsymétrique](1000024050.md) | Décrypte un buffer avec un algorithme clé privée/publique selon le cryptage RSA. |
| [DécrypteAsymétriqueEnveloppé](1000024058.md) | Réalise le décryptage asymétrique d'une enveloppe encryptée avec la fonction [CrypteAsymétriqueEnveloppé](1000024057.md). |
| [DécrypteStandard](1000021294.md) | Décrypte un message préalablement crypté avec un algorithme de chiffrement symétrique (AES, DES, etc.). |
| [Encode](1000022258.md) | Encode une chaîne de caractères ou un buffer. Pour décoder le résultat, il suffit d'utiliser la fonction [Décode](1000022259.md). |
| [LuhnCalcule](1410087276.md) | Calcule le prochain chiffre de contrôle de Luhn pour une suite donnée. |
| [LuhnVérifie](1410087277.md) | Vérifie que la suite donnée respecte bien la formule de Luhn. |
| Nouveauté Abonnement [ShamirCréeClésPartagées](1410091293.md) | Crée un ensemble de clés pour un même secret selon l'algorithme de Shamir. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.** |
| Nouveauté Abonnement [ShamirGénèreNombrePremier](1410091295.md) | Génère un nombre premier aléatoire utilisable pour la création de clés via l'algorithme de Shamir. Ce nombre est généré en fonction du secret.  **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.** |
| Nouveauté Abonnement [ShamirReconstruitSecret](1410091294.md) | Reconstruit un secret à partir d'un ensemble de clés. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.** |
| [UUDécode](1000018864.md) | Décode une chaîne de caractères au format UUEncode. |
| [UUEncode](1000018862.md) | Encode une chaîne de caractères selon l'algorithme UUEncode. |
