# <Image>.AnimationLitParamètre (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Mac Catalyst)

Lit la valeur d'un des paramètres d'animation défini pour un champ Image.

## Exemple

> _(Etats et Requêtes, Windows, Android, iPhone/iPad, Mac Catalyst, Code Utilisateur (MCU))_ SI IMG_Image1.AnimationLitParamètre(acpBoucle) = Vrai ALORS
 IMG_Image1.AnimationChangeParamètre(acpBoucle, Faux)
FIN
