# Fonctions SOAP (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

Les fonctions permettant de manipuler le protocole SOAP sont les suivantes :

| [<Variable wsRequête>.AjouteAssertionSAML](1000023948.md) | Ajoute une assertion SAML à une requête de Webservice. |
| --- | --- |
| [<Variable wsRequête>.AjouteSignatureXML](1000023950.md) | Ajoute une signature XML à une requête de Webservice. |
| [<Variable xsdEntité>.AjouteAttribut](1000023949.md) | Ajoute un attribut à une variable automatique générée par l'import d'un Webservice. |
