# SupprimeParamètre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Supprime un paramètre ou une série de paramètres sauvés :

- soit avec la fonction [SauveParamètre](3025046.md),
- soit automatiquement grâce à la [persistance des données](9000019.md) dans les champs.

**Attention** : Cette opération est irréversible et ne peut pas être annulée.

## Exemple

```wlangage
// Suppression d'un paramètre (syntaxe 1)
SupprimeParamètre("MonParamètre")
```

> _(WINDEV, Android, Widget Android, iPhone/iPad, Java)_ // Suppression d'un paramètre (syntaxe 1)
SupprimeParamètre("FEN_Fenêtre1\SAI_Saisie1")

> _(WINDEV, Android, Widget Android, iPhone/iPad, Java)_ // Suppression des paramètres de la fenêtre "FEN_Fen1" (syntaxe 2)
SupprimeParamètre(FEN_Fen1)
// équivalent à : SupprimeParamètre(FEN_Fen1..CheminComplet)

## Syntaxe

#### Supprimer un paramètre sauvé

```wlangage
<Résultat> = SupprimeParamètre(<Nom du paramètre>)
```

`<Résultat>` *Booléen*
> - Vrai si la fonction a réussi,
> - Faux dans le cas contraire. En cas d'erreur, il est possible de connaître le détail de l'erreur grâce à la fonction [ErreurInfo](3013008.md).
`<Nom du paramètre>` *Chaîne de caractères*
> Nom du paramètre à supprimer. Ce paramètre est recherché :
>
> - soit dans la base de registre (ou le fichier équivalent sur la plateforme d'exécution),
> - soit dans le fichier de paramètre spécifié avec la fonction [InitParamètre](3025044.md).
>
> Ce nom peut être une valeur ou un chemin complet (les séparateurs acceptés sont le point (.) et le slash (\)). Dans le cas d'un chemin complet, toutes les valeurs situées "en dessous" de ce chemin seront supprimées (voir exemple dans les notes).
> > _(Java)_ Si le mode d'initialisation choisi est la base de registre, la fonction SupprimeParamètre n'est sensible ni à la casse, ni à l'accentuation du nom du paramètre (Paramètre et parametre sont équivalents).

> _(WINDEV, Etats et Requêtes, Code Utilisateur (MCU))_ Supprimer tous les paramètres sauvés pour l'élément spécifié Masquer les détails
<Résultat> = SupprimeParamètre(<Nom de l'élément>)

 <Résultat> : BooléenVrai si la fonction a réussi, Faux dans le cas contraire. En cas d'erreur, il est possible de connaître le détail de l'erreur grâce à la fonction ErreurInfo. <Nom de l'élément> : Chaîne de caractèresNom du champ ou de la fenêtre dont les paramètres sauvegardés doivent être supprimés. Cet élément est recherché dans le fichier de paramètre spécifié avec la fonction InitParamètre (par défaut, dans la base de registre).

> _(WINDEV, Etats et Requêtes, Android, Widget Android, iPhone/iPad, Java, Code Utilisateur (MCU), WINDEV, Etats et Requêtes, iPhone/iPad, Java, Code Utilisateur (MCU))_ Supprimer tous les paramètres sauvegardés Masquer les détails
<Résultat> = SupprimeParamètre()

 <Résultat> : BooléenVrai si la fonction a réussi, Faux dans le cas contraire. En cas d'erreur, il est possible de connaître le détail de l'erreur grâce à la fonction ErreurInfo. Tous les paramètres sauvegardés pour l'application sont effacés. Au prochain lancement, l'application se comportera comme à son premier lancement.
 Le fichier de paramètre de l'application spécifié avec la fonction InitParamètre est entièrement vidé. Si les paramètres ont été sauvegardés dans un fichier INI ou XML, ce fichier est supprimé.

## Remarques

### Exemple détaillé de suppression d'un paramètre (syntaxe 1)

| Code utilisé | Fichier de sauvegarde : Base de registre | Fichier de sauvegarde : XML |
| --- | --- | --- |
| SupprimeParamètre ("Param1") | ```wlangage HKEY_CURRENT_USER \Software \<Société \<Application Param1 Param2 ``` | **<Param1 Valeur </Param1>** |
| SupprimeParamètre ("Fenetre1\Saisie2\X") | ```wlangage HKEY_CURRENT_USER \Software \<Société \<Application \Fenetre1\ Saisie2 X Y ``` | <Fenetre1 <Saisie2 **<X>Valeur </X>**  <Y>Valeur </Y </Saisie2 </Fenetre1> |
| SupprimeParamètre ("Fenetre1\Saisie2") | ```wlangage HKEY_CURRENT_USER \Software \<Société \<Application \Fenetre1 \Saisie2 X Y ``` | <Fenetre1 **<Saisie2>**  **<X>Valeur </X>**  **<Y>Valeur </Y>**  **</Saisie2>** </Fenetre1> |

<Société> correspond à la société indiquée lors de la création de l'exécutable. Si ce nom n'est pas renseigné, <Société> correspond à "Applications WinDev".

### Cas particuliers

- Sous Android, les valeurs persistantes sont sauvegardées dans les préférences partagées ("Shared Preferences") de l'application.
- Sous iOS, les valeurs persistantes sont sauvegardées dans les paramètres de l'application ("NSUserDefault").
- Dans un site WEBDEV, les valeurs persistantes sont enregistrées dans un cookie navigateur.
