# mlChargeEspaceDeTravail (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Charge l'ensemble des variables d'un fichier MATLAB dans la session. L'espace de travail (workspace) de la session MatLab est initialisé en chargeant l'ensemble des variables d'un fichier (fichier au format Mat-File d'extension .MAT).

## Exemple

```wlangage
nIdSession est un entier = mlInitialise()
SI ErreurDétectée ALORS
	ErreurInfo(errComplet)
	RETOUR
FIN
mlChargeEspaceDeTravail(nIdSession, "C:\temp\workspace.mat")
sListeVar est une chaîne = mlListeVariable(nIdSession)
mlTermine(nIdSession)
```

## Syntaxe

```wlangage
<Résultat> = mlChargeEspaceDeTravail(<Identifiant de la session> , <Nom du fichier> , <Variables conservées>)
```

`<Résultat>` *Booléen*
> - Vrai si le chargement a réussi.
> - Faux dans le cas contraire. En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Identifiant de la session>` *Entier*
> Identifiant de la session MATLAB. Cet identifiant est renvoyé par la fonction [mlInitialise](1000021351.md).
`<Nom du fichier>` *Chaîne de caractères*
> Chemin et le nom du fichier Mat-File à manipuler.
`<Variables conservées>` *Booléen*
> - Vrai pour conserver les variables existantes. La variable existante est conservée sauf si elle est redéfinie dans le fichier. Dans ce cas, la variable de la session est écrasée.
> - Faux pour ne pas les conserver (valeur par défaut). Les variables présentes dans la session sont supprimées avant le chargement.
