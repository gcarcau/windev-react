# <Graphe>.DonutPourcentageTrou (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

Modifie le pourcentage correspondant au rayon du trou d'un graphe de type Beignet (ou "Donut").
> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
// Le trou représentera 50% du rayon total du donut/beignet
GRF_MonGraphe.DonutPourcentageTrou(50)
```

## Syntaxe

```wlangage
<Champ Graphe>.DonutPourcentageTrou(<Pourcentage>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres, de pages ou d'états).
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Pourcentage>` *Entier*
> Pourcentage représenté par le trou du donut/beignet (compris entre 0 et 70).

## Remarques

- Le paramétrage réalisé avec la fonction **<Graphe>.DonutPourcentageTrou** sera pris en compte lors du prochain appel à la fonction [<Graphe>.Dessine](1000024062.md).
- Cette fonction peut être utilisée uniquement avec les graphes de type Beignet.
