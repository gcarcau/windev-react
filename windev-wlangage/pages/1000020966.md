# Fonctions DLNA / UPnP

> **Disponible :** **WINDEV** (Windows) · **WINDEV Mobile** (iPhone/iPad)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions DLNA / UPnP (syntaxe préfixée)](1000021000.md)).
Les fonctions WLangage permettant de manipuler des périphériques UPnP sont les suivantes :
| [UPNPCherchePériphérique](1000020912.md) | Recherche un périphérique à partir de son nom unique (UDN). |
| --- | --- |
| [UPNPExécuteAction](1000020918.md) | Exécute une action sur le service UPnP. |
| [UPNPListePériphérique](1000020901.md) | Liste les périphériques UPnP disponibles sur le réseau. |
| [UPNPMédiaArrêt](1000020944.md) | Arrête la lecture du média en cours sur le périphérique UPnP. |
| [UPNPMédiaJoue](1000020941.md) | Lance la lecture du média en cours sur le périphérique UPnP. |
| [UPNPMédiaOuvre](1000020942.md) | Ouvre un média sur le périphérique UPnP. |
| [UPNPMédiaPause](1000020943.md) | Met en pause la lecture du média en cours sur le périphérique UPnP. |
| [UPNPModifieContraste](1000020938.md) | Modifie le contraste d'un périphérique UPnP. |
| [UPNPModifieLuminosité](1000020939.md) | Modifie la luminosité d'un périphérique UPnP. |
| [UPNPModifieMuet](1000020931.md) | Modifier l'état 'Muet' d'un périphérique UPnP. |
| [UPNPModifieNetteté](1000020936.md) | Modifie la netteté d’un périphérique UPnP. |
| [UPNPModifieVolume](1000020937.md) | Modifie le volume d’un périphérique UPnP. |
| [UPNPRécupèreContraste](1000020933.md) | Récupère le contraste d’un périphérique UPnP. |
| [UPNPRécupèreLuminosité](1000020932.md) | Récupère la luminosité d'un périphérique UPnP. |
| [UPNPRécupèreMuet](1000020929.md) | Récupère l'état 'Muet' d'un périphérique UPnP. |
| [UPNPRécupèreNetteté](1000020935.md) | Récupère la netteté d’un périphérique UPnP. |
| [UPNPRécupèreVolume](1000020934.md) | Récupère le volume d’un périphérique UPnP. |
