# Géodésique (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Géodésique** permet d'indiquer si le dessin doit suivre la courbure de la Terre. Cette propriété est utilisable sur :

- une variable de type [CartePolygone](1000025476.md).
- une variable de type [CartePolyligne](1000025489.md).
