# Réduit (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

La propriété **Réduit** permet de :

- savoir si une note repositionnable est réduite,
- réduire ou restaurer une note repositionnable.

## Exemple

```wlangage
// Déplier un champ Note repositionnable et laisser le champ déplié
NOTE_MaNote.Réduit = Faux
NOTE_MaNote.RéduitAutomatique = 0
```

```wlangage
// Replier le champ Note repositionnable au bout d'une minute
NOTE_MaNote.Réduit = Vrai
NOTE_MaNote.RéduitAutomatique = 60
```

## Syntaxe

#### Savoir si une note repositionnable est réduite

```wlangage
<Résultat> = <Champ Note>.Réduit
```

`<Résultat>` *Booléen*
> - Vrai si le champ Note repositionnable est réduit. La note est affichée en haut à droite de la fenêtre,
> - Faux si le champ Note repositionnable est affiché entièrement.
`<Champ Note>` *Nom de champ*
> Nom du champ Note à manipuler.

#### Réduire ou restaurer une note repositionnable

```wlangage
<Champ Note>.Réduit = <Réduction>
```

`<Champ Note>` *Nom de champ*
> Nom du champ Note à manipuler.
`<Réduction>` *Booléen*
> - Vrai si le champ Note repositionnable doit être réduit,
> - Faux si le champ Note repositionnable doit être affiché entièrement.

## Remarques

- Lorsque la note repositionnable est réduite (propriété **Réduit** à Vrai), la note réduite est positionnée en haut à droite de la fenêtre.
- La propriété [RéduitAutomatique](1000021963.md) permet de connaître et définir le délai avant la réduction automatique de la note repositionnable.
