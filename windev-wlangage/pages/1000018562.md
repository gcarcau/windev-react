# sfRésultatRechercheSupprimé (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Le type **sfRésultatRechercheSupprimé** permet de connaître le résultat de la fonction [SFRechercheSupprimé](1000018475.md). Les caractéristiques de ce résultat peuvent être connues à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Connexion à Salesforce
Cnx est une sfConnexion
Cnx.Login = "balthazar@gmail.com"
Cnx.MotDePasse = "azerty" + "XXB12VCZ54"
SI SFConnecte(Cnx) = Faux ALORS
	Erreur("La connexion a échoué")
	RETOUR
FIN

ResRecupSuppr est un sfRésultatRechercheSupprimé
ResRecupSuppr = SFRechercheSupprimé(Cnx, "Mileage__c", "20090101", "20090131")

MonEnregistrement est un sfEnregistrementSupprimé
POUR TOUT MonEnregistrement DE ResRecupSuppr.EnregistrementSupprimé
	Trace("--- ID : " + MonEnregistrement.ID)
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type sfRésultatRechercheSupprimé
Les propriétés suivantes peuvent être utilisées pour manipuler le résultat de la fonction [SFRechercheSupprimé](1000018475.md) :

| Nom | Type manipulé | Effet |
| --- | --- | --- |
| DernièreDateCouverte | DateHeure | Date de l'enregistrement le plus récent qui est retourné par la fonction [SFRechercheSupprimé](1000018475.md). **Cette propriété est disponible en lecture seulement**. |
| EnregistrementSupprimé | Tableau de [sfEnregistrementSupprimé](1000018751.md) | Données des enregistrements supprimés. |
| PremièreDateDisponible | DateHeure | Date de l'enregistrement le plus ancien qui est retourné par la fonction [SFRechercheSupprimé](1000018475.md) |

## Remarques

### Fonctions manipulant le type sfRésultatRechercheSupprimé

| [SFRechercheSupprimé](1000018475.md) | Recherche et récupère les enregistrements (objets Salesforce) supprimés pendant la période spécifiée. |
| --- | --- |
