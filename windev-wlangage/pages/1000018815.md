# Fonctions Upload

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions Upload (syntaxe préfixée)](1000019077.md)).
Les fonctions de gestion de l'upload de fichiers sont les suivantes :

| [UploadCopieFichier](3012023.md) | Enregistre sur le serveur un fichier "uploadé" par l'internaute. |
| --- | --- |
| [UploadFichierEnCours](1000018798.md) | Indique le fichier en cours d'upload via le champ Upload. |
| [UploadLance](1000018793.md) | Lance l'envoi des fichiers sélectionnés dans un champ Upload. |
| [UploadNomFichier](3012022.md) | Renvoie le nom d'un fichier "uploadé" par l'internaute. Cet upload a pu être effectué :   - via un champ de saisie de type "Upload". - via un champ Upload monofichier ou multifichier. |
| [UploadSupprime](1000018808.md) | Supprime un fichier de la liste des fichiers à uploader : le fichier ne sera pas uploadé sur le serveur. |
| [UploadSupprimeTout](1000018809.md) | Vide la liste des fichiers à uploader : aucun fichier ne sera uploadé sur le serveur. |
| [UploadTaille](1000018795.md) | Renvoie la taille totale (en octets) des fichiers de l'upload en cours via un champ Upload. |
| [UploadTailleEnvoyée](1000018794.md) | Renvoie la taille totale (en octets) des fichiers déjà envoyés par l'upload en cours via un champ Upload. |
| [UploadTailleEnvoyéeFichierEnCours](1000018796.md) | Renvoie la taille (en octets) déjà envoyée du fichier en cours d'upload via un champ Upload. |
| [UploadTailleFichier](1000019035.md) | Renvoie la taille totale (en octets) d'un fichier présent dans un champ Upload. |
| [UploadTailleFichierEnCours](1000018797.md) | Renvoie la taille totale (en octets) du fichier en cours d'upload via un champ Upload. |
