# HTMLChercheElémentParBalise (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Cherche les éléments d'un document HTML (ou d'un noeud HTML) correspondant à une balise.

## Exemple

```wlangage
d est un htmlDocument = HTMLOuvre("https://www.pcsoft.fr", depuisURL)
// ...
t est un tableau de htmlNoeud <- HTMLChercheElémentParBalise(d, "form")
```

## Syntaxe

```wlangage
<Résultat> = HTMLChercheElémentParBalise(<Elément à manipuler> [, <Elément recherché>])
```

`<Résultat>` *Tableau*
> Tableau d'éléments de type [htmlNoeud](1000026081.md) correspondant à la recherche.
`<Elément à manipuler>` *Variable de type htmlDocument ou de type htmlNoeud*
> Elément dans lequel la recherche doit être effectuée :
>
> - Nom de la variable de type [htmlDocument](1000025910.md).
> - Nom de la variable de type [htmlNoeud](1000026081.md).
`<Elément recherché>` *Chaîne de caractères optionnelle*
> Nom de la balise à rechercher. Si ce paramètre n'est pas précisé ou correspond à une chaîne vide (""), <Résultat> contiendra tous les éléments.
