# <Graphe>.NuageTaillePoint (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Définit la taille des points dans un graphe de type "Nuage de points".
**Rappel** : Par défaut, la taille d'un point dans un graphe de type "Nuage de points" est égale à 1 pixel.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

Nouveauté Abonnement

> _(Android)_ Cette fonction est désormais disponible pour les applications Android.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
// Augmentation de la taille des points dans le champ "GRF_MonGraphe".
// Ce graphe est de type "Nuage de points".
GRF_MonGraphe.NuageTaillePoint(3)
```

## Syntaxe

```wlangage
<Champ Graphe>.NuageTaillePoint(<Taille>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe manipulé (présent dans l'éditeur de fenêtres, de pages ou d'états).
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Taille>` *Entier*
> Taille d'un point (en pixels).

## Remarques

### Taille d'un point
Le point affiché est un carré dont la taille du côté est calculée grâce à la formule suivante : (<Taille>*2)-1 pixels.
[image: Taille du point]

### Points dans les graphes de type "Nuage de points"

- Dans les graphes de type "Nuage de points", un point est défini par ses coordonnées (abscisse et ordonnée).
- Les données définies avec la fonction **<Graphe>.NuageTaillePoint** seront prises en compte lors du prochain appel à la fonction [<Graphe>.Dessine](1000024062.md).
- La fonction **<Graphe>.NuageTaillePoint** est utilisée uniquement pour les graphes de type "Nuage de points". Cette fonction est sans effet pour tous les autres types de graphes.
