# DocOuvre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Ouvre un fichier Traitement de texte (format docx) en mode Lecture/Ecriture. Le fichier docx est ouvert et bloqué jusqu'à sa fermeture.
**Remarque** : Pour créer un fichier docx sans utiliser un fichier initial, il suffit de créer une variable de type [Document](1000022461.md) (la fonction **DocOuvre** est alors inutile).

## Exemple

```wlangage
// Utilisation d'une variable Document
d est un Document
d = DocOuvre("C:\Users\test\Documents\fichier.docx")

SI ErreurDétectée() ALORS
	Erreur(ErreurInfo())
	RETOUR
FIN
```

```wlangage
// Utilisation d'un champ Traitement de texte
DocOuvre(TT_MonTT, "C:\Users\test\Documents\fichier.docx")

SI ErreurDétectée() ALORS
	Erreur(ErreurInfo())
	RETOUR
FIN
```

## Syntaxe

#### Associer un fichier docx à une variable Document

```wlangage
<Résultat> = DocOuvre(<Source du document> [, <Mot de passe>])
```

`<Résultat>` *Variable de type Document*
> Nom de la variable de type [Document](1000022461.md) correspondant au fichier docx. Cette variable peut être utilisée dans toutes les fonctions [DocXXX](1000022618.md).
> En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai et la fonction [ErreurInfo](3013008.md) permet de connaître la cause de l'erreur.
`<Source du document>` *Type correspondant à la source*
> Correspond à un des éléments suivants :
>
> - Chemin complet ou relatif du fichier docx à ouvrir (260 caractères maximum).
> - Nom de la variable de type Buffer contenant le document docx à afficher dans le champ Traitement de texte.
> - Nom de la rubrique mémo contenant le document docx à afficher dans le champ Traitement de texte. Ce paramètre est de la forme : <Fichier de données>.<Rubrique>.
`<Mot de passe>` *Chaîne de caractères optionnelle ou Chaîne secrète*
> Mot de passe d'ouverture du fichier docx à manipuler (si le fichier est protégé par un mot de passe d'ouverture).
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).
