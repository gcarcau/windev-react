# <Graphe>.SupprimeTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (iPhone/iPad)

Efface un graphe dessiné et créé avec la fonction [grCrée](3042005.md) et détruit ce graphe. La destruction d'un graphe permet de libérer la place mémoire occupée par la matrice utilisée par ce graphe.
**Remarque** : Tous les graphes utilisés dans une application sont systématiquement détruits à la fermeture de la fenêtre ou de l'application.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
// Destruction du graphe "MonGraphe"
GRF_MonGraphe.SupprimeTout()
```

## Syntaxe

```wlangage
<Champ Graphe>.SupprimeTout()
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler présent dans l'éditeur de fenêtres, de pages ou d'états.
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
