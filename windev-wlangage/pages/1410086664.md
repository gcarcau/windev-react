# Sélection (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **Sélection** permet de gérer la sélection. Cette propriété est disponibles sur :

- les champs Traitement de texte, Tableur, Editeur HTML et Editeur de diagrammes.
- Nouveauté Abonnement
  une variable de type [pdfProtection](1410091145.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
