# Constantes de gestion des applications et des executables

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Les différentes constantes de gestion des exécutables sont les suivantes :

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |
| **alDémarrage** | Lancement de l'application lors du démarrage du poste PC en cours | [AutoLanceAjoute](3019002.md), [AutoLanceSupprime](3019001.md) |
| **exeActif** | Mode de lancement du programme : programme lancé actif | [LanceAppli](3035006.md) |
| **exeActionRapide** | _(Android, iPhone/iPad)_ Mode de démarrage de l'application : l'application est lancée automatiquement via une action rapide. | [ExeInfo](3035001.md) |
| **exeBloquant** | Délai de reprise du programme en cours : le programme en cours reprend son exécution lorsque le programme lancé est terminé. | [LanceAppli](3035006.md) |
| **exeCopyright** | Information à récupérer : copyright du programme | [ExeInfo](3035001.md) |
| **exeDeepLink** | _(Android, iPhone/iPad)_ Mode de démarrage de l'application : l'application est lancée automatiquement par un lien "deep link". | [ExeInfo](3035001.md) |
| **exeDémarrage** | _(Android)_ Mode de démarrage de l'application : l'application est lancée automatiquement par le système, au démarrage de l'appareil. | [ExeInfo](3035001.md) |
| **exeDescription** | Information à récupérer : description du programme | [ExeInfo](3035001.md) |
| **exeEnArrièrePlan** | _(Android, iPhone/iPad)_ Mode de démarrage de l'application : l'application est lancée en arrière-plan lors de la gestion de suivi de géolocalisation ou lors de la détection d'un groupe de beacons. | [ExeInfo](3035001.md) |
| **exeGéoSuivi** | _(Android, iPhone/iPad)_ Mode de démarrage de l'application : l'application est lancée en arrière-plan lors de la gestion de suivi de géolocalisation.  Remarque : Cette constante est conservée par compatibilité à partir de la version 230050. Elle est identique à la constante *exeEnArrièrePlan*. | [ExeInfo](3035001.md) |
| **exeIconise** | Mode de lancement du programme : programme lancé inactif et réduit en icône | [LanceAppli](3035006.md) |
| **exeInactif** | Mode de lancement du programme : programme lancé inactif | [LanceAppli](3035006.md) |
| **exeLancement** | _(Android, iPhone/iPad)_ Information à récupérer : mode de démarrage de l'application. | [ExeInfo](3035001.md) |
| **exeLigneCommande** | Ligne de commande de l'exécutable. | [ExeListeProcessus](3035008.md) |
| **exeMaximise** | Mode de lancement du programme : programme lancé actif, "prenant la main" sur le programme en cours (la fenêtre d'exécution a la taille maximale autorisée) | [LanceAppli](3035006.md) |
| **exeMémoire** | Consommation actuelle de l'application | [ExeListeProcessus](3035008.md) |
| **exeMémoireMax** | Consommation maximale atteinte par l'application | [ExeListeProcessus](3035008.md) |
| **exeMode** | Information à récupérer : mode de compilation de l'exécutable (16, 32 ou 64 bits ou DOS) | [ExeInfo](3035001.md) |
| **exeNom** | Information à récupérer : nom complet de l'exécutable | [ExeInfo](3035001.md) |
| **exeNomCourt** | Nom et extension de l'exécutable de l'application | [ExeListeProcessus](3035008.md) |
| **exeNomLong** | Nom et chemin complet de l'exécutable de l'application | [ExeListeProcessus](3035008.md) |
| **exeNonBloquant** | Délai de reprise du programme en cours : le programme en cours et le programme lancé s'exécutent en parallèle | [LanceAppli](3035006.md) |
| **exeNotificationPush** | Mode de démarrage de l'application : l'application est lancée automatiquement par le système suite à la réception d'une notification push. | [ExeInfo](3035001.md) |
| **exePID** | Identifiant du processus de l'application. Cet identificateur peut être utilisé par exemple dans certaines API. | [ExeDonnePID](1000017239.md), [LanceAppli](3035006.md), [ExeListeProcessus](3035008.md) |
| **exePIDParent** | PID du parent (c'est-à-dire le processus qui a lancé le processus en cours). | [ExeDonnePID](1000017239.md), [ExeListeProcessus](3035008.md) |
| **exePrioritéBasse** | Priorité de l'application : Basse | [ExePriorité](3035010.md) |
| **exePrioritéHaute** | Priorité de l'application : Priorité haute | [ExePriorité](3035010.md) |
| **exePrioritéInférieureNormale** | Priorité de l'application : Priorité supérieure à *exePrioritéBasse* et inférieure à *exePrioritéNormale*. | [ExePriorité](3035010.md) |
| **exePrioritéNormale** | Priorité de l'application : Priorité supérieure à *exePrioritéInférieureNormale*et inférieure à *exePrioritéSupérieureNormale*. | [ExePriorité](3035010.md) |
| **exePrioritéSupérieureNormale** | Priorité de l'application : Priorité supérieure à *exePrioritéNormale*et inférieure à *exePrioritéTempsRéel*. | [ExePriorité](3035010.md) |
| **exePrioritéTempsRéel** | Priorité de l'application : Priorité temps réel. | [ExePriorité](3035010.md) |
| **exeRépertoire** | Information à récupérer : répertoire de l'exécutable (sans le \ final, mais avec les ":"). | [ExeInfo](3035001.md) |
| **exeSansHéritageHandle** | Permet d'indiquer que l'exécutable ne doit pas hériter des "Handles" du parent (attention, s'applique à TOUS les handles, fichiers compris). L'exécutable est indépendant de l'application qui le lance. | [DDELance](3028013.md) [LanceAppli](3035006.md) |
| **exeSociété** | Information à récupérer : nom saisi pour la société lors de la création de l'exécutable. | [ExeInfo](3035001.md) |
| **exeTéléchargementFin** | _(Android, Widget Android)_ Mode de démarrage de l'application : l'application est lancée automatiquement par le système lors de la fin d'un téléchargement précédemment demandé par l'application (par exemple, si l'application a été fermée pendant le téléchargement). | [ExeInfo](3035001.md) |
| **exeTID** | Identificateur du thread courant. | [ExeDonnePID](1000017239.md) |
| **exeValeurRetour** | Le programme en cours reprend son exécution lorsque le programme lancé est terminé. <Résultat correspond à la valeur de retour de l'exécutable. | [LanceAppli](3035006.md) |
| **exeVersion** | Information à récupérer : version du programme | [ExeInfo](3035001.md) |
| **exeVersionFormatWindows** | Information à récupérer : version du programme au format Windows standard. | [ExeInfo](3035001.md) |
| **ficheAchatInApp** | Type de fiche à ouvrir : Ouvre la fenêtre de paramétrage des achats In-App de l'application. | [AppliOuvreFiche](1000020980.md) |
| **ficheApplication** | Type de fiche à ouvrir : Ouvre la fiche de l'application. | [AppliOuvreFiche](1000020980.md) |
| **partageDocument** | Partage d'un ou de plusieurs documents (image, vidéo, pdf, ...). Ces documents sont identifiés par leur chemin complet, précisé en paramètre. | [LancePartage](1000020620.md) |
| **partageTexte** | Partage de texte. | [LancePartage](1000020620.md) |
