# VisibleInitial (Propriété)

> **Disponible :** **WINDEV** (Windows, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **VisibleInitial** permet de savoir si :

- un champ était visible lors du premier affichage de la fenêtre ou la page associée.
- une fenêtre était visible lors de son premier affichage.

**Remarques** :

- La visibilité initiale d'un champ ou d'une fenêtre correspond à celle fixée sous l'éditeur (onglet "Détail" de la description de l'objet). Cette option sera utilisée lors de l'initialisation du champ ou de la fenêtre.
- La visibilité d'un champ ou d'une fenêtre peut être modifiée grâce aux propriétés [Visible](2510138.md) et [Etat](2510039.md).

## Exemple

```wlangage
// Remettre le champ "SAI_Société" dans son état de visibilité initiale
SAI_Société.Visible = SAI_Société.VisibleInitial
```

## Syntaxe

```wlangage
<Résultat> = <Elément manipulé>.VisibleInitial
```

`<Résultat>` *Booléen*
> - Vrai si l'objet spécifié était visible lors de son premier affichage,
> - Faux dans le cas contraire.
`<Elément manipulé>` *Nom de champ ou nom de fenêtre*
> Nom de l'objet (champ ou fenêtre) à manipuler.
> Pour un champ associé à un onglet, utilisez la notation suivante :
>
>
> ```wlangage
> <Nom de l'onglet>.<Nom du champ>
> ```

## Remarques

### Attribut d'un champ
La propriété **VisibleInitial** ne modifie pas les autres attributs d'état du champ (sélection sans saisie, actif ou grisé).

### Limites
La propriété **VisibleInitial** ne peut pas être utilisée sur :

- une option d'interrupteur ou de sélecteur,
- une ligne de table, de liste ou de combo,
- une cellule de table,
- un menu de fenêtre,
- un groupe de champs,
- un élément d'un champ Arbre.

> _(Java)_ La propriété VisibleInitial s'applique uniquement aux éléments suivants :Champ Bouton.Champ Libellé.Champ de saisie.Champ Image.Champ Interrupteur.Champ Sélecteur.Champ Liste.Champ Combo.Champ Arbre.Champ Onglet.Fenêtre.Champ Table.Colonne de table.Superchamp.

> _(Widget Android)_ La propriété VisibleInitial s'applique uniquement aux éléments suivants :Champ Bouton.Champ Libellé.Champ Image.Fenêtre.
