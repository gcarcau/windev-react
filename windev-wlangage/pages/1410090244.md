# TCDCalculeToutAsynchrone (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Calcule ou recalcule entièrement un champ Tableau croisé dynamique sans blocage.
Nouveauté Abonnement

> _(WEBDEV - Code Serveur, Linux)_ Cette fonction est désormais disponible pour les sites WEBDEV sous Windows et sous Linux.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
TCDCalculeToutAsynchrone(TCD_Statistiques, Calcul_terminé)
	PROCÉDURE INTERNE Calcul_terminé(bOK est booléen)
		SI PAS bOK ALORS
			Erreur(ErreurInfo())
			RETOUR
		FIN
	FIN
```

## Syntaxe

```wlangage
TCDCalculeToutAsynchrone(<Champ Tableau croisé dynamique> [, <Procédure WLangage>])
```

`<Champ Tableau croisé dynamique>` *Nom de champ*
> Nom du champ Tableau croisé dynamique à calculer ou recalculer.
`<Procédure WLangage>` *Nom de procédure optionnel*
> Nom de la procédure WLangage ("callback") appelée à la fin du calcul.
> Pour plus de détails sur cette procédure, consultez [Paramètres de la procédure utilisée par la fonction TCDCalculeToutAsynchrone](1410090051.md).

## Remarques

### Comment le calcul est-il effectué ?
Le calcul est effectué en parcourant tous les enregistrements nécessaires. Ce calcul peut être relativement long selon la taille de la base de données. Par exemple, un calcul sur une base d'un million d'enregistrements peut prendre quelques minutes. La fonction **TCDCalculeToutAsynchrone** ne bloque pas l'application et exécute la procédure WLangage spécifiée lorsque le calcul est terminé.
Le contenu du champ Tableau croisé dynamique doit être recalculé entièrement :

- Lors de l'ajout de nouvelles rubriques à afficher.
- Lors de la modification des fonctions de filtrage.
- Lors de la modification des données source du calcul.

Le contenu du champ Tableau croisé dynamique n'a pas besoin d'être recalculé entièrement :

- Lors de l'utilisation d'un filtre sur une dimension déjà calculée.
- Lors du changement de dimension.
- Lors du déroulement ou de l'enroulement d'une dimension (par exemple, visualiser les trimestres au lieu des années).
