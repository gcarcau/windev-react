# HConstruitValCléANSI (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **Autres** (Procédures stockées)

**Quelle que soit la plateforme utilisée, les données enregistrées dans les fichiers de données HFSQL sont au format ANSI.**
Sous une plateforme Unicode, la fonction **HConstruitValCléANSI** permet de construire la valeur d'une clé composée pour enregistrer cette clé composée dans un fichier de données HFSQL.

Sous une plateforme ANSI, cette fonction est équivalente à [HConstruitValClé](3044258.md).

**La fonction HConstruitValCléANSI ne doit pas être utilisée** pour :

- réaliser un filtre (fonction [HFiltre](3044100.md)) sur une clé composée.
- effectuer une recherche (fonctions [HLitRecherchePremier](3044036.md), [HLitRechercheDernier](3044034.md), etc.) sur une clé composée.

Pour les filtres ou les recherches, utilisez la fonction [HConstruitValClé](3044258.md).

**Rappel** : Les clés composées sont des chaînes binaires dont le contenu ne peut pas être affiché directement. Pour plus de détails sur la gestion des clés composées, consultez [Clés composées](3044178.md).

## Exemple

```wlangage
// Affectation d'une rubrique dans un fichier de données lié
Facture.NomClientPrénom = HConstruitValCléANSI(Client, ...
	NomClientPrénom, Client.Nom, Client.Prénom)
```

## Syntaxe

```wlangage
<Résultat> = HConstruitValCléANSI(<Fichier de données> , <Clé composée> , <Valeur des composantes>)
```

`<Résultat>` *Chaîne de caractères*
> Valeur de la clé composée à enregistrer dans le fichier de données.
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données HFSQL utilisé.
`<Clé composée>` *Chaîne de caractères*
> Nom de la rubrique correspondant à la clé composée.
`<Valeur des composantes>` *Chaîne de caractères*
> Valeur à affecter à chaque composante de la clé composée.
> Ce paramètre est de la forme <Composante 1> , <Composante 2>, ...,<Composante N>.
> Par exemple : "MOULIN", "Françoise".

## Remarques

> _(HFSQL Classic)_ Quand utiliser la fonction HConstruitValCléANSI ? La fonction HConstruitValCléANSI peut et doit être utilisée pour enregistrer la valeur d'une clé composée utilisée comme clé de liaison dans un fichier de données.Exemple :
Pour enregistrer une nouvelle facture sur une plateforme Unicode, utilisez le code suivant :

Facture.NumFacture = ...
...

 NomClientPrénom, Client.Nom, Client.Prénom)
...
