# MessageSupprimeCase (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Supprime une case de la barre de message de la fenêtre en cours.
**Remarque** : La fenêtre doit posséder une barre de message.

## Exemple

```wlangage
// Ajoute la case "MaCase" dans la barre de message de la fenêtre en cours
MessageAjouteCase("MaCase", 100, RougeClair)
...
MessageSupprimeCase("MaCase")
```

## Syntaxe

```wlangage
MessageSupprimeCase(<Nom de la case>)
```

`<Nom de la case>` *Chaîne de caractères*
> Nom de la case à supprimer. Ce nom peut correspondre à une case de la barre de message créée sous l'éditeur ou par programmation (fonction [MessageAjouteCase](3021001.md)). Si la case n'existe pas, une erreur WLangage est affichée.

## Remarques

### Supprimer une case d'une barre de message
Il est conseillé de rendre la case invisible plutôt que de la supprimer.

### Utiliser les propriétés WLangage avec les cases des barres de message
De nombreuses propriétés WLangage peuvent être utilisées sur les cases des barres de message.
**Attention** : Pour utiliser une propriété sur une case d'une barre de message, la syntaxe à utiliser est la suivante :

```wlangage
{"Nom de la case"}..<Nom de la propriété>
```

Pour plus de détails, consultez [Liste des propriétés utilisables sur les cases de barre de message](1010035.md).
