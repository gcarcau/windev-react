# NombreColonne (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android)

La propriété **NombreColonne** permet de connaître et de modifier le nombre de colonnes d'un élément. Cette propriété est utilisable sur :

- les champs d'une fenêtre. Pour plus de détails, consultez [NombreColonne sur les champs d'une fenêtre](2510083.md).
- une variable de type [xlsDocument](1000017464.md).
- une variable de type [docFormatMulticolonne](1000023580.md).
