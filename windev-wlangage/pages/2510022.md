# CouleurFond (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

La propriété **CouleurFond** permet de connaître ou de modifier la couleur de fond de :

- un champ.
- une fenêtre.
- une page.
- un bloc d'un état.
- un libellé d'une option de menu.

**Remarque** : Selon le type de champ, les effets de la propriété **CouleurFond** peuvent varier (consultez le paragraphe "Remarques" pour plus de détails).

Nouveauté 2025

> _(WINDEV)_ La propriété CouleurFond est désormais disponible sur le champ Editeur d'images présent dans une fenêtre.

## Exemple

```wlangage
// Selon la valeur affichée, la couleur de fond est modifiée
SI SAI_Total > 15000 ALORS
	SAI_Total.CouleurFond = RougeClair
FIN
```

## Syntaxe

#### Connaître la couleur de fond

```wlangage
<Couleur de fond> = <Elément manipulé>.CouleurFond
```

`<Couleur de fond>` *Entier ou constante*
> Couleur de l'élément spécifié. Correspond à l'une des options suivantes :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - [une couleur prédéfinie](3010002.md).
>
>
> > _(WEBDEV - Code Navigateur)_ La couleur est renvoyée sous forme de chaîne de caractères par le navigateur.
`<Elément manipulé>` *Type de l'élément*
> Nom de l'élément à manipuler : champ, fenêtre, page ou bloc de l'état.

#### Modifier la couleur de fond

```wlangage
<Elément manipulé>.CouleurFond = <Nouvelle couleur>
```

`<Elément manipulé>` *Type de l'élément*
> Nom de l'élément à manipuler : champ, fenêtre, page ou bloc de l'état.
`<Nouvelle couleur>` *Entier ou constante*
> Nouvelle couleur de l'élément spécifié. Correspond à l'une des options suivantes :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie](3010002.md).

### Limites

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS, Mac Catalyst)_ Limites sur les champs d'un étatLa propriété CouleurFond n'a aucun effet sur :les états (dans leur totalité).les champs Etat Interne.les champs Signature.

> _(WINDEV)_ Limites sur les champs des fenêtres WINDEVLa propriété CouleurFond n'a aucun effet sur les champs suivants :les champs HTML,les champs Web caméra,les champs Potentiomètre.

> _(WEBDEV - Code Serveur)_ Limites sur les champs des pagesLa propriété CouleurFond n'a aucun effet sur les éléments d'un champ Liste ou Combo.

> _(WEBDEV - Code Navigateur)_ En code navigateur, la propriété CouleurFond fonctionne uniquement sur les champs suivants :les champs de saisie,les champs Liste et les éléments d'un champ Liste,les champs Combo et les éléments d'un champ Combo,les lignes d'un champ Table,les champs Libellé et Libellé HTML.les champs Bouton à 3 états. les champs Interrupteur et Sélecteur. les champs Image.les champs de type "Affichage formaté".les champs Lien.les champs HTML.les cellules.les champs Vignette.les champs iFrame.les lignes de champ Table en mode "Navigateur".les colonnes de champ Table en mode "Navigateur".les cellules de champ Table en mode "Navigateur".La propriété CouleurFond fonctionne également sur les pages.

> _(Java)_ La propriété CouleurFond s'applique uniquement aux éléments suivants :Champ Bouton.Champ Libellé.Champ de saisie.Champ Image.Champ Interrupteur.Champ Sélecteur.Champ Liste.Champ Combo.Champ Arbre.Champ Onglet.Fenêtre.Champ Table.Colonne de champ Table.

> _(Widget Android)_ La propriété CouleurFond s'applique uniquement aux éléments suivants :Champ Bouton.Champ Libellé.Champ Image.Fenêtre.

> _(Widget IOS)_ La propriété CouleurFond s'applique uniquement aux éléments suivants :Champ Libellé.Champ Image.Fenêtre.
