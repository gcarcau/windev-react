# <Variable sshSession>.Ecrit (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Ecrit des données dans la session SSH spécifiée.

## Exemple

```wlangage
cMaSession est une sshSession
// La session aura été ouverte avec la fonction <sshSession>.ConnecteShell.
// Caract(10) permet de terminer la ligne de commande à envoyer.

// Positionne dans le dossier /var/log
cMaSession.Ecrit("cd /var/log" + Caract(10))

// Demande à lire les lignes contenant "error"
cMaSession.Ecrit("grep -i error /var/log/messages" + Caract(10))
```

## Syntaxe

```wlangage
<Résultat> = <Session SSH>.Ecrit(<Données>)
```

`<Résultat>` *Booléen*
> - Vrai si les données ont été envoyées correctement,
> - Faux en cas d'erreur. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de renseignements sur le problème rencontré.
`<Session SSH>` *Variable de type sshSession*
> Nom de la variable [sshSession](1000021157.md) correspondant à la session SSH à manipuler.
`<Données>` *Buffer*
> Données à écrire dans la session SSH.

**Composante : wd300com.dll**
