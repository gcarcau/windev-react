# AppliOuvreFiche (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Ouvre :

- la fiche d'une application sur le market Android (Play Store) ou iOS (App Store) pour que l'utilisateur puisse la noter et/ou la commenter.
- la fiche de paramétrage des achats In-App d'une application.

## Exemple

> _(Android, Widget Android)_ // Ouverture de la fiche d'une application
AppliOuvreFiche("com.pcsoft.wm_note_de_frais")

// Ouverture de la fiche de l'application courante
AppliOuvreFiche()

> _(iPhone/iPad, Widget IOS, Mac Catalyst)_ // Ouverture de la fiche d'une application
AppliOuvreFiche("47232570")

## Syntaxe

```wlangage
AppliOuvreFiche([<Application> [, <Type de fiche>]])
```

`<Application>` *Chaîne de caractères optionnelle*
> > _(Android, Widget Android)_ Nom complet de l'application pour laquelle la fiche doit être ouverte. Ce nom est de forme <package>.<nom de l'application> (exemple : com.pcsoft.wm_note_de_frais). Si ce paramètre n'est pas spécifié, la fiche de l'application courante sera ouverte.
>
> > _(iPhone/iPad, Widget IOS, Mac Catalyst)_ Identifiant iTunes de l'application. Pour obtenir cet identifiant : 1. Rendez vous sur http://linkmaker.itunes.apple.com/us/. 2. Saisissez le nom de l'application. Le numéro se trouve alors dans l'URL fournie. Par exemple, pour l'application WB Quizz de PC Soft, l'adresse est "https://itunes.apple.com/us/app/wb-quizz/id473232570?mt=8&uo=4" target="itunes_store"" et l'identifiant est 473232570.
`<Type de fiche>` *Constante optionnelle de type Entier*
> > _(Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst, Android, Widget Android)_ Indique le type de fiche à ouvrir : ficheAchatInAppOuvre la fenêtre de paramétrage des achats In-App de l'application. Ouvre la même fiche qu'en utilisant la constante ficheApplication.ficheApplication(Valeur par défaut)Ouvre la fiche de l'application.

## Remarques

### Conditions nécessaires
L'application pour laquelle la fiche doit être ouverte doit préalablement avoir été publiée sur le store.

> _(Android, Widget Android)_ Application en arrière-plan : Spécificité à partir de Android 10A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. La fonction AppliOuvreFiche peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. Conseils : Il est possible de savoir si l'application est en arrière-plan grâce à la fonction EnModeArrièrePlan. Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type Notification). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété ActiveApplication est à Vrai. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété ActionClic.Pour plus de détails, consultez Android 10 : Comportement des applications en arrière-plan.
