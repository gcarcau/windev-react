# MatAdditionne (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Additionne deux matrices de mêmes dimensions (même nombre de lignes et même nombre de colonnes).

## Exemple

```wlangage
// Addition de deux matrices
ResAddition = MatAdditionne("MaMatrice1", "MaMatrice2", "MaMatriceRésultat")
```

## Syntaxe

```wlangage
<Résultat> = MatAdditionne(<1ère matrice> , <2ème matrice> , <Matrice résultat>)
```

`<Résultat>` *Booléen*
> - Vrai si l'addition a été effectuée,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<1ère matrice>` *Chaîne de caractères*
> Nom de la première matrice à additionner, défini avec la fonction [MatCrée](3050058.md).
`<2ème matrice>` *Chaîne de caractères*
> Nom de la seconde matrice à additionner, défini avec la fonction [MatCrée](3050058.md).
`<Matrice résultat>` *Chaîne de caractères*
> Nom de la matrice contenant le résultat de l'addition. Cette matrice est automatiquement créée lors de l'addition des deux matrices.

## Remarques

### Existence de la matrice Résultat
L'existence de la matrice n'est pas vérifiée. Si la matrice existait auparavant, cette matrice est écrasée. Pour vérifier l'existence d'une matrice, utilisez la fonction [MatExiste](3050076.md).

### Matrices identiques
Si le paramètre <1ère matrice> est identique au paramètre <2ème matrice>, la matrice résultat contient le double de la matrice d'origine.

### Soustraction de matrices
Pour soustraire une matrice à une autre matrice, il suffit de :

- multiplier la matrice à soustraire par -1 avec la fonction [MatRéelMultiplie](3050040.md),
- additionner la matrice obtenue à la première matrice.
