# <Variable emailSessionIMAP>.DésabonneDuDossier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Supprime un dossier existant de la liste des dossiers abonnés.
Nouveauté Abonnement
Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
session est une emailSessionIMAP
session.AdresseServeur = "imap.gmail.com"
session.Port = 993
session.Option = optionTLS
session.Nom = "XXXXX"
session.MotDePasse = "XXXXXXX"
session.OuvreSession()

// Liste des dossiers de gestion des mails et des dossiers abonnés
res est chaîne
res = EmailListeDossier(session, LstDossierNormal)
Trace(res)
Trace("---------------------------------------------------")
// Désabonne le dossier Test
Trace("Désabonnement : " + (session.DésabonneDuDossier("Test") ? "OK" SINON "KO"))
Trace("---------------------------------------------------")
// Liste des dossiers de gestion des mails et des dossiers abonnés
// Le dossier Test n'est plus listé
res = session.ListeDossier(LstDossierNormal)
Trace(res)
Trace("---------------------------------------------------")
```

## Syntaxe

```wlangage
<Résultat> = <Session IMAP>.DésabonneDuDossier(<Dossier>)
```

`<Résultat>` *Booléen*
> - Vrai si le dossier spécifié a été désabonné,
> - Faux dans le cas contraire. Le compte-rendu détaillé de l'erreur est connu grâce à la fonction [ErreurInfo](3013008.md).
`<Session IMAP>` *Variable de type emailSessionIMAP*
> Nom de la variable de type [emailSessionIMAP](1000018957.md) correspondant à la session IMAP connectée au serveur de mails.
`<Dossier>` *Chaîne de caractères*
> Nom et chemin du dossier à supprimer de la liste des dossiers abonnés.

## Remarques

- Les dossiers supprimés avec la fonction [<Variable emailSessionIMAP>.SupprimeDossier](1000022299.md) sont automatiquement désabonnés.
- Un dossier supprimé est automatiquement supprimé de la liste des dossiers abonnés.
- La fonction [<Variable emailSessionIMAP>.ListeDossier](1000022290.md) utilisée avec la constante *LstDossierNormal* liste les dossiers contenant les emails et les dossiers abonnés.
- La fonction [<Variable emailSessionIMAP>.ListeDossier](1000022290.md) utilisée avec la constante *LstDossierTous* liste tous les dossiers (dossiers contenant les emails et dossiers abonnés ou non abonnés).
