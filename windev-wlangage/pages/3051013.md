# MCIPosition (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Renvoie ou modifie la position en cours dans un fichier multimédia, précédemment ouvert (fonction [MCIOuvre](3051017.md)).

## Exemple

```wlangage
MCIOuvre("Son.wav", "MonSon")
...
MCIJoue("MonSon")
...
MCIPosition("MonSon", 10)
...
MCIFerme("MonSon")
```

## Syntaxe

#### Modifier la position dans le fichier

```wlangage
<Résultat> = MCIPosition(<Fichier multimédia ou alias> , <Position> [, <Paramètres> [, <Nom de la fenêtre de messages>]])
```

`<Résultat>` *Booléen*
> - Vrai si le positionnement a été réalisé,
> - Faux dans le cas contraire. Pour connaître le numéro de l'erreur, utilisez la fonction [MCIErr](3051011.md).
>   Pour connaître le libellé de l'erreur, utilisez la fonction [MCIMsgErr](3051021.md) ou la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
>   Le compte-rendu de la commande peut être connu avec la fonction [MCIRécupère](3051022.md).
`<Fichier multimédia ou alias>` *Chaîne de caractères*
> Nom du fichier multimédia à manipuler (AVI, MP3, ...) ou alias défini lors de l'ouverture du fichier (fonction [MCIOuvre](3051017.md)).
`<Position>` *Chaîne de caractères*
> Nouvelle position dans le fichier. Cette position est au format précisé par [MCIFormatPosition](3051004.md).
`<Paramètres>` *Chaîne de caractères optionnelle*
> Paramètres complémentaires si nécessaire. Ces paramètres peuvent être connus en consultant la documentation de la fonction MCI Windows "seek".
> Il est possible d'ajouter la constante *MciAttente* à cette chaîne. Cette constante permet d'indiquer que le programme doit attendre la fin de la commande MCI pour exécuter la suite de l'application.
`<Nom de la fenêtre de messages>` *Chaîne de caractères optionnelle*
> Nom de la fenêtre permettant d'intercepter et de gérer les différents messages envoyés par MMSYSTEM.DLL. Ces messages sont du type MM_xxxxxx et sont récupérables grâce à la fonction [Evénement](3015011.md). Il est par exemple possible d'obtenir des messages concernant la gestion du lecteur de CD ROM ou du Joystick.

#### Connaître la position dans le fichier

```wlangage
<Résultat> = MCIPosition(<Fichier multimédia ou alias> [, <Nom de la fenêtre de messages>])
```

`<Résultat>` *Chaîne de caractères*
> Position dans le fichier. Cette position est au format précisé par la fonction [MCIFormatPosition](3051004.md).
`<Fichier multimédia ou alias>` *Chaîne de caractères*
> Nom du fichier multimédia à fermer (AVI, MP3, ...) ou alias défini lors de l'ouverture du fichier (fonction [MCIOuvre](3051017.md)).
`<Nom de la fenêtre de messages>` *Chaîne de caractères optionnelle*
> Nom de la fenêtre permettant d'intercepter et de gérer les différents messages envoyés par MMSYSTEM.DLL. Ces messages sont du type MM_xxxxxx et sont récupérables grâce à la fonction [Evénement](3015011.md). Il est par exemple possible d'obtenir des messages concernant la gestion du lecteur de CD ROM ou du Joystick.

## Remarques

Après l'utilisation de la fonction **MCIPosition**, pour être sûr que le positionnement a bien été effectué, il est conseillé d'utiliser la ligne de code suivante :
```wlangage
TANTQUE MCIEtat(<Fichier ou alias>) <> MCIEtatArrêtFIN
```
