# IDCompte (Propriété)

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows)

La propriété **IDCompte** permet de gérer les identifiants de comptes. Cette propriété est utilisable sur :

- une variable de type [sfRésultatConvertitPiste](1000018739.md).
- une variable de type [sfConversionPiste](1000018742.md).
