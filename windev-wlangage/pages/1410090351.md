# <Variable Drive>.CopieRépertoire (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Copie un répertoire du drive (et son contenu) vers un autre répertoire de ce drive (disque distant).

## Exemple

```wlangage
oOAuth2Param est un OAuth2Paramètres
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.URLRedirection = "http://localhost:9000/"

oDrive est un Drive
oDrive = oDriveConnecte(oOAuth2Param)

SI oDrive.CopieRépertoire("/MesPhotos/2000/", "/Sauvegardes/") = Faux ALORS
	Erreur("Impossible de copier le répertoire demandé", ErreurInfo())
	RETOUR
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Drive>.CopieRépertoire(<Répertoire à copier> , <Répertoire destination>)
```

`<Résultat>` *Booléen*
> - Vrai si la copie a été réalisée,
> - Faux en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Drive>` *Variable de type Drive ou gglDrive*
> Nom de la variable de type [Drive](1410089369.md) ou [gglDrive](1410089374.md) correspondant au drive à manipuler. La connexion au drive voulu doit avoir été effectuée. Dans le cas contraire, la copie n'est pas réalisée.
`<Répertoire à copier>` *Chaîne de caractères*
> Chemin absolu du répertoire à copier. Si ce paramètre ne correspond pas à un chemin de répertoire valide, le répertoire ne sera pas copié. Le contenu de ce répertoire sera entièrement copié (sous-répertoires et fichiers).
`<Répertoire destination>` *Chaîne de caractères*
> Chemin du répertoire destination dans lequel le répertoire source sera copié. Si ce chemin n'est pas valide, le répertoire ne sera pas copié. Les répertoires manquants dans le chemin ne sont pas créés.

## Remarques

### Paramètres <Répertoire à copier> et <Répertoire destination>
Exemples de chemins valides :

```wlangage
"/mon répertoire de vacances/2021/""\photos"
```

Exemples de chemins invalides :

```wlangage
"répertoireA/RépertoireB""Ce/Chemin/Est/invalide""c:\Users\"
```
