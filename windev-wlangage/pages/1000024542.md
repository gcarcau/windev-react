# <Variable Document>.VersImage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Exporte une page contenue dans une variable de type [Document](1000022461.md) sous forme d'une image.

## Exemple

```wlangage
Mondoc est un Document <- TT_MonDocument
d est une Image = Mondoc.VersImage(1)
dSauveImageJPEG(d, "test")
LanceAppliAssociée("test.jpg")
```

## Syntaxe

```wlangage
<Résultat> = <Document>.VersImage(<Page>)
```

`<Résultat>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) correspondant à la page du document Traitement de texte.
`<Document>` *Variable de type Document*
> Nom de la variable de type [Document](1000022461.md) à manipuler.
`<Page>` *Entier*
> Numéro de la page à exporter sous forme d'une image.

**Composante : wd300mdl.dll**
