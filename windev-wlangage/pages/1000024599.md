# PageAgencementEnCours (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

Renvoie l'indice de l'agencement en cours :

- dans la page en cours.
- dans la page spécifiée.

Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.

> _(WEBDEV - Code Navigateur)_ En code navigateur, il est uniquement possible de connaître l'agencement de la page en cours.

## Exemple

```wlangage
SI PageAgencementEnCours() = 2 ALORS
	LIB_Détail = Client.Détail
FIN
```

## Syntaxe

#### Connaître l'agencement de la page en cours

```wlangage
<Résultat> = PageAgencementEnCours()
```

`<Résultat>` *Entier*
> - Indice de l'agencement en cours.
> - 0 si la page ne possède aucun agencement.
> - une des constantes suivantes :
>   | *agencementImpression* | L'agencement spécifique pour l'impression est en cours. |
>   | --- | --- |
>   | *agencementWINDEV* | L'agencement spécifique pour WINDEV est en cours. |
>   | *agencementWINDEVMobile* | L'agencement spécifique pour WINDEV Mobile est en cours. |
>   | *agencementWINDEVMobileTablette* | L'agencement spécifique pour WINDEV Mobile (tablette) est en cours. |

> Non disponible en code navigateur

Connaître l'agencement d'une page spécifique Masquer les détails
<Résultat> = PageAgencementEnCours(<Page>)

 <Résultat> : EntierIndice de l'agencement en cours.0 si la page interne ne possède aucun agencement. une des constantes suivantes : agencementImpressionL'agencement spécifique pour l'impression est en cours. agencementWINDEVL'agencement spécifique pour WINDEV est en cours.agencementWINDEVMobileL'agencement spécifique pour WINDEV Mobile est en cours.agencementWINDEVMobileTabletteL'agencement spécifique pour WINDEV Mobile (tablette) est en cours. <Page> : Nom de pageNom de la page manipulée.

## Remarques

- Les agencements sont numérotés dans leur ordre de création en édition.
- Si le terminal change d'orientation ou si la fonction [PageChangeAgencement](1000024598.md) est exécutée, l'agencement change.
