# NavigateurLanceAppli (Fonction)

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Ouvre le navigateur Web par défaut de l'appareil en cours.

## Exemple

```wlangage
NavigateurLanceAppli("http://www.pcsoft.fr")
```

## Syntaxe

```wlangage
NavigateurLanceAppli(<URL>)
```

`<URL>` *Chaîne de caractères*
> URL de la page à afficher à l'ouverture du navigateur.
