# GéométrieDésérialiseWKT2D (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Construit une géométrie en 2 dimensions à partir d'une représentation textuelle au format WKT.
**Remarque** : Les points présents dans le WKT représentent une coordonnée X/Y.

## Exemple

```wlangage
TexteWKT est une chaîne ANSI
TexteWKT = "
	POLYGON((4.9746785 47.13040029, 4.97344728 47.13107359, 4.97345634 47.13108307,
	4.97388735 47.13087471, 4.9746785 47.13040029) )
	"
monPolygone est une Géométrie = GéométrieDésérialiseWKT2D(TexteWKT)
```

## Syntaxe

```wlangage
<Résultat> = GéométrieDésérialiseWKT2D(<Représentation WKT>)
```

`<Résultat>` *Variable correspondant à des données spatiales*
> Variable de type [Géométrie](1410090098.md) correspondant à la représentation WKT. Les géométries manipulées peuvent correspondre à des variables de type :
>
> - [Point2D](1410090100.md).
> - [Polyligne2D](1410090109.md).
> - [Polygone2D](1410090122.md).
> - [MultiPoint2D](1410090129.md).
> - [MultiPolyligne2D](1410090131.md).
> - [MultiPolygone2D](1410090135.md).
`<Représentation WKT>` *Chaîne de caractères ANSI*
> Chaîne de caractères correspondant à la représentation WKT de la géométrie en 2 dimensions à construire.
