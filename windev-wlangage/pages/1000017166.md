# PageFermeDialogue (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux)

Ferme la page courante. Cette page a été ouverte avec la fonction [PageAfficheDialogue](1000017124.md). Une valeur de retour peut être renvoyée à la page appelante.

## Exemple

```wlangage
// Ferme la page utilisée pour le dialogue en renvoyant la valeur Vrai
PageFermeDialogue(Vrai)
```

## Syntaxe

```wlangage
PageFermeDialogue([<Valeur renvoyée>])
```

`<Valeur renvoyée>` *Type correspondant à la valeur renvoyée (optionnel)*
> Valeur renvoyée par la page lors de sa fermeture. Cette valeur est récupérée uniquement si la page a été ouverte avec la fonction [PageAfficheDialogue](1000017124.md). Si la page n'a pas été ouverte avec la fonction [PageAfficheDialogue](1000017124.md), une erreur est retournée.

## Remarques

- **PageFermeDialogue**() est équivalent à [ContexteFerme](3058003.md)("").
- **PageFermeDialogue**(Valeur) est équivalent à [ContexteFerme](3058003.md)("", Valeur).
- Si votre projet utilise les sessions prélancées, cette fonction ne doit pas être utilisée dans l'événement "Initialisation" du projet. Cette fonction doit être utilisée dans l'événement "Initialisation lors d'une connexion à une session prélancée".
