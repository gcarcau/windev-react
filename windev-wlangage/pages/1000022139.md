# TimeoutConnexion (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **TimeoutConnexion** permet de gérer le temps d'attente de connexion. Cette propriété est disponible sur :

- une variable de type [sshSession](1000021157.md).
- une variable de type [httpRequête](1000021158.md).
- une variable de type [restRequête](1000021481.md).
- une variable de type [mqttSession](1000023023.md).
- une variable de type [apiRequête](1410088935.md).
- une variable de type [memcachedConnexion](1000023339.md).
- une variable de type [redisConnexion](1000023527.md).
