# TestVérifieDifférence (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch)

Vérifie si les expressions spécifiées sont différentes en programmation défensive et en mode test automatique.
Remarque : Cette fonction est équivalente à la fonction [dbgVérifieDifférence](1000019777.md).

## Exemple

```wlangage
// La fonction ne devrait pas renvoyer 0TestVérifieDifférence(FonctionCalcul(), 0)
```

## Syntaxe

```wlangage
TestVérifieDifférence(<Expression 1> , <Expression 2> [, <Commentaires> [, <Paramètre 1> [... [, <Paramètre N>]]]])
```

`<Expression 1>` *Chaîne de caractères*
> Expression quelconque.
`<Expression 2>` *Chaîne de caractères*
> Expression quelconque.
`<Commentaires>` *Chaîne de caractères*
> Chaîne de caractères au format défini par la fonction [ChaîneConstruit](3024006.md).
`<Paramètre 1>` *Tout type*
> Premier paramètre attendu par le paramètre <Commentaires>.
`<Paramètre N>` *Tout type*
> Nième paramètre attendu par le paramètre <Commentaires>.

## Remarques

### Fonctionnement
Lorsque les expressions sont égales :

- **en mode test automatique**, une erreur est ajoutée dans le compte-rendu du test (équivalent de la fonction [TestEcritRésultat](1000013001.md)).
- **en mode test manuel**, une assertion est affichée (équivalent de la fonction [dbgAssertion](3014022.md)).
- **en mode exécution**, une assertion est affichée si les assertions ont été activées (équivalent de la fonction [dbgAssertion](3014022.md)).

En exécution d'une application, si les assertions ne sont pas activées, l'expression n'est pas évaluée.

La fonction [dbgSurErreur](1000020722.md) permet de lancer automatiquement une procédure WLangage permettant de récupérer le commentaire lié à l'erreur.

> _(Android, Widget Android)_ Gestion des assertionsLes messages de la fonction TestVérifieDifférence seront écrits dans le log ADB (au niveau "Assert"). Pour plus de détails, consultez Gestion des logs ADB.

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
