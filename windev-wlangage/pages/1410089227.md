# fChangeExtension (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad) · **Autres** (Procédures stockées)

Change l'extension d'un fichier présent sur un disque.

## Exemple

```wlangage
SI fChangeExtension("C:\Répertoire\Sauvegarde.txt", ".old") = Vrai ALORS
	fSauveTexte("C:\Répertoire\Sauvegarde.txt", MaChaîneTexte)
SINON
	ErreurInfo()
FIN
```

## Syntaxe

```wlangage
<Résultat> = fChangeExtension(<Chemin du fichier> , <Nouvelle extension>)
```

`<Résultat>` *Booléen*
> - Vrai si le changement de taille a été effectué,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Chemin du fichier>` *Chaîne de caractères*
> Fichier à manipuler (260 caractères maximum). Ce paramètre peut correspondre à :
>
> - un nom de fichier. Ce fichier sera automatiquement recherché dans le répertoire en cours (connu avec la fonction [fRepEnCours](3036022.md)).
> - un nom de fichier avec son chemin (complet ou relatif). Un chemin de type UNC peut être utilisé.
`<Nouvelle extension>` *Chaîne de caractères*
> Nouvelle extension souhaitée. Si la nouvelle extension ne commence pas par un point ".", celui-ci sera ajouté automatiquement.

## Remarques

Si la fonction **fChangeExtension** manipule un fichier ayant une extension composée, seule la dernière extension sera modifiée. Par exemple, la modification de "MonFichier.log.doc" correspondra à "MonFichier.log.docx".
