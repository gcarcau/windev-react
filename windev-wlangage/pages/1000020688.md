# Rappel (Type de variable)

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

Le type **Rappel** permet de décrire et manipuler un rappel pour notifier l'utilisateur qu'un rendez-vous est en approche.
Ce type de variable est utilisé par les variables de type [RendezVous](1000019244.md).

Les caractéristiques de ce rappel peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Ajoute un nouveau rappel par notification une heure avant le début du rendez-vous
rappelRDV est un Rappel
rappelRDV.Type = rappelNotification
rappelRDV.Délai = 60
Ajoute(rdv.Rappel, rappelRDV)
RendezVousModifie(rdv)

// Ajoute un nouveau rappel par email une semaine avant le début du rendez-vous
rappelRDV est un Rappel
rappelRDV.Type = rappelEmail
rappelRDV.Délai = 7 * 24 * 60
Ajoute(rdv.Rappel, rappelRDV)
RendezVousModifie(rdv)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type Rappel
Les propriétés suivantes peuvent être utilisées pour manipuler un rappel :

| **Nom de la propriété** | **Type manipulé** | **Effet** |
| --- | --- | --- |
| Délai | Entier ou Durée | Délai en minutes avant le début du rendez-vous pour lequel le rappel doit être effectué. Cette propriété peut correspondre à :   - un entier correspondant au nombre de minutes, - une variable de type Durée, - l'indication directe de la durée (par exemple 1 min). |
| Type | Constante de type Entier | Méthode à utiliser pour effectuer le rappel :   - *rappelDéfaut* : méthode par défaut. Cette méthode varie en fonction du paramétrage de l'appareil. - *rappelEmail* : envoi d'un email. Ce type de rappel est disponible uniquement si le compte associé au calendrier du rendez-vous supporte ce type de rappel et si ce compte est configuré. - *rappelNotification* : envoi d'une notification. - *rappelSMS* : envoi d'un SMS. Ce type de rappel est disponible uniquement si le compte associé au calendrier du rendez-vous supporte ce type de rappel et si ce compte est configuré. _(iPhone/iPad)_ Seule la constante rappelDéfaut est disponible. |

## Remarques

### Note
Pour réinitialiser le contenu d'une variable de type Rappel, il est possible d'utiliser la fonction [VariableRAZ](3013069.md).
