# <Variable Image>.Police (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Déclare la police de caractères qui sera utilisée par la fonction [<Variable Image>.DessineTexte](1000024242.md) dans une variable de type [Image](1000019650.md).
> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Dessiner en WINDEV, WEBDEV et WINDEV Mobile.

## Exemple

```wlangage
MonImage est une Image = "Test.bmp"
// Déclaration de la police de caractères :
// Arial, taille 12, gras
MonImage.Police("Arial", 12, iGras)

IMG_MonDessin = MonImage
```

## Syntaxe

#### Utiliser une police spécifique pour les dessins

```wlangage
<Variable Image>.Police(<Police> [, <Taille de la police> [, <Attributs de la police> [, <Inclinaison du texte>]]])
```

`<Variable Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) à manipuler.
`<Police>` *Chaîne de caractères*
> Nom de la police utilisée lors du dessin du texte par [<Variable Image>.DessineTexte](1000024242.md). Ce paramètre ne doit pas correspondre à une famille de polices. La liste des polices installées sur le poste en cours peut être connue avec la fonction [PoliceListe](3060003.md).
> > _(Java)_ Si le nom de la police n'est pas trouvé, Windows recherche une police dont le nom est le plus proche. Pour cela, la fonction <Variable Image>.DébutDessin doit avoir été utilisée.
`<Taille de la police>` *Entier optionnel*
> Taille de la police (en points). La valeur par défaut est 12.
`<Attributs de la police>` *Constante (ou combinaison de constantes) optionnelle*
> Attributs de police à utiliser :
>
> | *iBarre* | Barre le texte dessiné. |
> | --- | --- |
> | *iGras* | Met le texte dessiné en gras. |
> | *iItalique* | Met le texte dessiné en italique. |
> | *iNormal* (Valeur par défaut) | Normalise le texte dessiné |
> | *iSouligne* | Souligne le texte dessiné. |
`<Inclinaison du texte>` *Entier optionnel*
> Indique l'inclinaison (en degrés) du texte. La valeur par défaut est 0.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ Utiliser une police créée par programmation Masquer les détails
<Variable Image>.Police(<Police utilisée>)

 <Variable Image> : Variable de type ImageNom de la variable de type Image à manipuler. <Police utilisée> : PolicePolice à utiliser pour les dessins. Ce paramètre correspond à une variable de type Police. Les caractéristiques de la police ont été définies grâce à la fonction PoliceCrée ou grâce aux propriétés de gestion des polices.

## Remarques

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Windows, Java, Code Utilisateur (MCU), Ajax)_ PolicesLa fonction PoliceListe permet de récupérer la liste des polices valides (TrueType, PostScript) installées sur la machine en cours.Pour obtenir un résultat satisfaisant lors de l'inclinaison du texte dessiné, la <Police> utilisée doit être de type "TrueType".

**Classification Métier / UI : Code neutre**

**Composante : wd300pnt.dll**
