# DocAjoute (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Ajoute :

- à la fin d'un document de type Traitement de texte : un élément, un document, un paragraphe, un texte, une image ou un fragment.
- à la fin d'un fragment : un élément, un texte ou une image.

## Exemple

```wlangage
// Ajoute une image
// Sélection du fichier image
sFichier est chaîne
sFichier = fSélecteurImage(fRepEnCours(), "", "Ajouter une image",
	"JPEG (*.JPG)" + TAB + "*.jpg" + RC + "PNG (*.PNG)" + TAB + "*.png" + RC +
	"Tous les fichiers (*.*)" + TAB + "*.*")
SI sFichier = "" ALORS
	RETOUR
FIN
// Le fichier image est transféré dans une variable de type Image
img est une Image = sFichier
// Ajout de l'image en fin de document
DocAjoute(TT_SansNom1, img)
```

```wlangage
// Ajoute un saut de page
DocAjoute(TT_SansNom1, Caract(12))
```

## Syntaxe

#### Ajouter à la fin d'un document de type Traitement de texte

```wlangage
<Résultat> = DocAjoute(<Document> , <Objet à ajouter>)
```

`<Résultat>` *Variable de type docFragment*
> Variable de type [docFragment](1000022482.md) contenant le fragment ajouté.
`<Document>` *Nom de champ ou variable de type Document*
> Document à manipuler. Ce document correspond :
>
> - au nom d'un champ Traitement de texte.
> - à une variable de type [Document](1000022461.md).
`<Objet à ajouter>` *Type de l'objet ajouté*
> Objet à ajouter :
>
> - Elément : Nom de la variable de type [docElément](1000022484.md) correspondant à l'élément à ajouter.
> - Document : Nom de la variable de type [Document](1000022461.md) correspondant au document à ajouter.
>   **Attention** : Les éléments suivants du document ajouté ne sont pas conservés :
>   - La mise en page par défaut du document ajouté (par exemple les marges).
>   - Les paramètres de la section principale du document ajouté (par exemple les entêtes et les pieds de page).
> - Paragraphe : Nom de la variable de type [docParagraphe](1000022483.md) correspondant au paragraphe à ajouter. Ce paragraphe doit avoir été récupéré depuis un document, il ne peut être créé en partant de rien car le tableau des éléments d'un paragraphe est en lecture seule.
> - Texte sous forme de chaîne de caractères : Texte à ajouter.
>   Il est possible d'utiliser les constantes suivantes dans le texte à ajouter pour gérer les différents sauts possibles :
>   | *docSautDeColonne* | Ajoute un saut de colonne dans une section multicolonne. Si la section n'est pas multicolonne, un saut de page est ajouté. |
>   | --- | --- |
>   | *docSautDeLigne* | Ajoute un saut de ligne. |
>   | *docSautDePage* | Ajoute un saut de page. |
>   | *docSautDeParagraphe* | Ajoute un saut de paragraphe. |
> - Image : Nom de la variable de type [Image](1000019650.md) à ajouter.
> - Fragment : Nom de la variable de type [docFragment](1000022482.md) à ajouter.

#### Ajouter à la fin d'un fragment

```wlangage
<Résultat> = DocAjoute(<Fragment> , <Objet à ajouter>)
```

`<Résultat>` *Variable de type docFragment*
> Variable de type [docFragment](1000022482.md) contenant le fragment ajouté.
`<Fragment>` *Variable de type docFragment*
> Nom de la variable de type [docFragment](1000022482.md) à manipuler.
`<Objet à ajouter>` *Type de l'objet ajouté*
> Objet à ajouter :
>
> - Elément : Nom de la variable de type [docElément](1000022484.md) correspondant à l'élément à ajouter.
> - Texte sous forme de chaîne de caractères : Texte à ajouter.
>   Il est possible d'utiliser les constantes suivantes dans le texte à ajouter pour gérer les différents sauts possibles :
>   | *docSautDeColonne* | Ajoute un saut de colonne dans une section multicolonne. Si la section n'est pas multicolonne, un saut de page est ajouté. |
>   | --- | --- |
>   | *docSautDeLigne* | Ajoute un saut de ligne. |
>   | *docSautDePage* | Ajoute un saut de page. |
>   | *docSautDeParagraphe* | Ajoute un saut de paragraphe. |
> - Image : Nom de la variable de type [Image](1000019650.md) à ajouter.
