# hHistoriquePlanification (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Apple Watch)

Le type **hHistoriquePlanification** permet de connaître toutes les caractéristiques de l'historique de l'exécution d'une opération planifiée : optimisation, sauvegarde, etc. Ces caractéristiques peuvent être connues à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
monHistorique est un hHistoriquePlanification
```

## Propriétés

### Propriétés WLangage utilisables avec le type hHistoriquePlanification
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **hHistoriquePlanification** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| DateDébut | DateHeure | Date et Heure de début de l'exécution de l'opération planifiée. **Cette propriété est disponible en lecture seulement**. |
| DateFin | DateHeure | Date et Heure de fin de de l'exécution de l'opération planifiée. **Cette propriété est disponible en lecture seulement**. |
| Erreur | Chaîne de caractères | Erreur rencontrée (si la propriété **Etat** correspond à la constante *hExecPlanificationErreur*). |
| Etat | Entier | Etat de l'exécution de l'opération planifiée :   - *hExecPlanificationAnnulée* : L'exécution de l'opération planifiée a été annulée. - *hExecPlanificationEnCours* : L'exécution de l'opération planifiée est en cours. - *hExecPlanificationErreur* : L'exécution de l'opération planifiée est en erreur. - *hExecPlanificationTerminée* : L'exécution de l'opération planifiée est terminée.   **Cette propriété est disponible en lecture seulement**. |
| Identifiant | Entier | Identifiant de l'exécution de l'opération planifiée.  **Cette propriété est disponible en lecture seulement**. |
| LancementManuel | Booléen | - Vrai si l'exécution de l'opération planifiée a été lancée manuellement (c'est-à-dire via une fonction WLangage ou via le Centre de Contrôle HFSQL), - Faux dans la cas contraire.  **Cette propriété est disponible en lecture seulement**. |
| Type | Entier | Opération planifiée exécutée :   - *hlpOptimisation* : Optimisation des fichiers de données. - *hlpSauvegardeComplète* : Sauvegarde complète. - *hlpSauvegardeDifférentielle* : Sauvegarde différentielle. - *hlpTâche* : Tâche planifiée. - *hlpVueMatérialisée* : Rafraîchissement d'une vue matérialisée.   **Cette propriété est disponible en lecture seulement**. |
| Utilisateur | Chaîne de caractères | - Si l'exécution a été réalisée automatiquement, utilisateur ayant créé l'opération planifiée. - Si l'exécution a été réalisée manuellement, utilisateur ayant exécuté l'opération planifiée.  **Cette propriété est disponible en lecture seulement**. |
