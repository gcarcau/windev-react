# CadrageVertical (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le cadrage vertical d'un champ consiste à définir la position du texte dans le champ par rapport aux bords du champ. Ainsi, il est possible de cadrer le contenu d'un champ de saisie par rapport aux bords de la zone de saisie.
Trois cadrages différents sont à votre disposition :

- Cadrage en haut[image: Image d'un texte cadré en haut]
- Cadrage au milieu[image: Image d'un texte cadré au milieu]
- Cadrage en bas[image: Image d'un texte cadré en bas]

La propriété **CadrageVertical** permet de connaître et de modifier le cadrage vertical d'un champ.
Le cadrage initial du champ est défini lors de la description du champ.

## Exemple

```wlangage
// Si le champ est cadré en haut, on le cadre en bas
SI LIB_Libellé.CadrageVertical = cvHaut ALORS
	LIB_Libellé.CadrageVertical = cvBas
FIN
```

## Syntaxe

#### Connaître le cadrage vertical d'un champ

```wlangage
<Cadrage actuel> = <Champ manipulé>.CadrageVertical
```

`<Cadrage actuel>` *Constante de type entier*
> Cadrage vertical actuel du champ. Les valeurs possibles sont les suivantes :
>
>
> | *cvBas* | le texte est placé en bas du champ |
> | --- | --- |
> | *cvHaut* | le texte est placé en haut du champ |
> | *cvMilieu* | le texte est placé au milieu du champ |
>
>
>
> > _(WEBDEV - Code Serveur, PHP)_ Des options de cadrage vertical supplémentaires sont disponibles :cvAutoAlignement vertical automatique (correspond à la valeur CSS "auto")cvBaseLineAlignement vertical sur la ligne de base (correspond à la valeur CSS "baseline")cvDessousAlignement vertical en dessous de la ligne, en indice (correspond à la valeur CSS "sub")cvDessusAlignement vertical en dessus de la ligne, en exposant (correspond à la valeur CSS "super")cvNonDéfiniAlignement vertical hérité du parentcvTexteBasAlignement vertical du texte en décalage bas (correspond à la valeur CSS "text-bottom")cvTexteHautAlignement vertical du texte en décalage haut (correspond à la valeur CSS "text-top")
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.

#### Modifier le cadrage vertical d'un champ

```wlangage
<Champ manipulé>.CadrageVertical = <Nouveau cadrage>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.
`<Nouveau cadrage>` *Constante de type entier*
> Nouveau cadrage du champ. Les valeurs possibles sont les suivantes :
>
>
> | *cvBas* | le texte est placé en bas du champ |
> | --- | --- |
> | *cvHaut* | le texte est placé en haut du champ |
> | *cvMilieu* | le texte est placé au milieu du champ |
>
>
>
> > _(WEBDEV - Code Serveur, PHP)_ Il est possible de préciser les options de cadrage vertical supplémentaires grâce aux constantes suivantes :cvAutoAlignement vertical automatique (correspond à la valeur CSS "auto")cvBaseLineAlignement vertical sur la ligne de base (correspond à la valeur CSS "baseline")cvDessousAlignement vertical en dessous de la ligne, en indice (correspond à la valeur CSS "sub")cvDessusAlignement vertical en dessus de la ligne, en exposant (correspond à la valeur CSS "super")cvNonDéfiniAlignement vertical hérité du parentcvTexteBasAlignement vertical du texte en décalage bas (correspond à la valeur CSS "text-bottom")cvTexteHautAlignement vertical du texte en décalage haut (correspond à la valeur CSS "text-top")

## Remarques

### Cadrage horizontal
Pour définir le cadrage horizontal du champ, utilisez la propriété [CadrageHorizontal](2510023.md).

### Limitations

> _(WINDEV)_ Dans une fenêtre, la propriété CadrageVertical permet de connaître et de modifier le cadrage vertical des champs de type :Champ LibelléChamp Interrupteur ou sélecteurChamp ImageColonne de table ou de table hiérarchiqueChamp ListeChamp ComboChamp Code-barresChamp GrapheChamp NotationChamp Organigramme

> _(WEBDEV - Code Serveur)_ Dans une page, la propriété CadrageVertical permet de connaître et de modifier le cadrage vertical des champs de type :Champ de saisieChamp LibelléChamp BoutonChamp Interrupteur / champ SélecteurChamp Liste, ComboChamp TableChamp Cellule de table (en lecture uniquement)Champ Table hiérarchique, cellule de table hiérarchique (en lecture uniquement) Champ d'affichage formatéChamp HTMLChamp LienChamp Libellé HTMLChamp RégletteChamp Chemin de navigationChamp ArbreChamp JaugeChamp PlanningChamp Notation

> _(PHP)_ Dans une page, la propriété CadrageVertical permet de connaître et de modifier le cadrage vertical des champs de type :Champ de saisieChamp LibelléChamp BoutonChamp Interrupteur / Champ SélecteurChamp Liste ou ComboChamp TableChamp Table hiérarchique, cellule de champ Table hiérarchiqueChamp d'affichage formatéChamp HTMLChamp LienChamp Libellé HTMLChamp RégletteChamp Arbre

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad)_ Dans un état, la propriété CadrageVertical permet de connaître et de modifier le cadrage vertical des champs de type :Champ Libellé.Champ Calculé.Champ prédéfini.Champ Graphe.Groupe de champs : Cette propriété s'appliquera uniquement aux champs du groupe gérant le cadrage vertical.

> _(Android, Java)_ La propriété CadrageVertical s'applique uniquement aux champs suivants :Champ Libellé.Champ Image.Champ Interrupteur.Champ Sélecteur.Champ Combo.

> _(Android)_ La propriété CadrageVertical s'applique aux colonnes de table.

> _(iPhone/iPad)_ La propriété CadrageVertical s'applique à tous les types de champs (colonnes de table, libellé, ...).

> _(Widget IOS)_ La propriété CadrageVertical s'applique aux champs Libellé.
