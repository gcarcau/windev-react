# Fonctions de gestion du champ Traitement de texte (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Les fonctions de gestion des champs Traitement de texte (via une syntaxe préfixée) sont les suivantes :

| [<Document>.RechercheElémentParNom](1410088861.md) | Recherche un élément par son nom dans l'ensemble d'un document de type Traitement de texte. |
| --- | --- |
| [<Traitement de texte>.Ajoute](1000024032.md) | Ajoute à la fin d'un champ Traitement de texte : un élément, un document, un paragraphe, un texte, une image ou un fragment. |
| [<Traitement de texte>.DébutModification](1000023405.md) | Signale le début du regroupement d'un ensemble d'opérations sur un champ Traitement de texte en un seul événement (gestion du "undo/redo"). |
| Nouveauté 2025 [<Traitement de texte>.EffaceMiseEnForme](1410090632.md) | Remplace la mise en forme de la sélection en cours dans un champ Traitement de texte par la mise en forme par défaut. |
| [<Traitement de texte>.EntreEdition](1000024263.md) | Entre en édition dans le champ Traitement de texte dans une partie spécifique du document : corps, en-tête ou pied de page. |
| [<Traitement de texte>.Ferme](1000024264.md) | Ferme le fichier docx associé au champ Traitement de texte et libère le document. |
| [<Traitement de texte>.FinModification](1000024265.md) | Signale la fin du regroupement d'un ensemble d'opérations sur un champ Traitement de texte en un seul événement (gestion du "undo/redo"). |

| [<Traitement de texte>.InfoXY](1000025346.md) | Renvoie pour une position donnée dans un champ Traitement de texte (coordonnées d'un point du champ) :  - soit le numéro de la page correspondante, - soit la position X (en mm) correspondante, - soit la position Y (en mm) correspondante. |
| [<Traitement de texte>.Insère](1000024267.md) | Insère un objet dans un champ Traitement de texte. Les objets manipulables sont :   - un élément, - un document, - un paragraphe, - un texte, - une image, - un fragment. |

| [<Traitement de texte>.Ouvre](1000024269.md) | Ouvre un fichier Traitement de texte (format docx) en mode Lecture/Ecriture. Le fichier docx est ouvert et bloqué jusqu'à sa fermeture. |
