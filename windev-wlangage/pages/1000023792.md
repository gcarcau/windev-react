# <Chrono>.Reprend (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Redémarre un chronomètre précédemment arrêté par les fonctions [<Chrono>.Fin](1000023789.md) ou [<Chrono>.Pause](1000023790.md). La durée chronométrée à partir de la fonction **<Chrono>.Reprend** sera cumulée à la durée précédemment calculée.
Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Les variables de type Chrono sont désormais disponibles en code navigateur. La syntaxe manipulant les variables de type Chrono devient également disponible.

## Exemple

```wlangage

DuréeTraitement est une Durée
MonChrono est un Chrono
MonChrono.Début()
MaFonction1()
DuréeTraitement = MonChrono.Pause()
Info("Le traitement MaFonction1 a duré " + DuréeTraitement)
MonChrono.Reprend()
MaFonction2()
DuréeTraitement = MonChrono.Fin()
Info("Les traitements MaFonction1 et MaFonction2 ont duré " + DuréeTraitement)
```

## Syntaxe

```wlangage
<Chronomètre>.Reprend()
```

`<Chronomètre>` *Variable de type Chrono*
> Nom de la variable de type [Chrono](1000023560.md) correspondant au chronomètre à utiliser.

## Remarques

### Divers
Si la fonction **<Chrono>.Reprend** est utilisée sur un chronomètre déjà activé, cette fonction n'a aucun effet.

### Erreur
Si la fonction [<Chrono>.Début](1000023788.md) n'a pas été appelée avant la fonction **<Chrono>.Reprend**, une erreur WLangage est affichée.

### Threads
Les fonctions de chronométrage (Chronoxxx) concernant un même chronomètre doivent être utilisées dans un même thread.

**Composante : wd300vm.dll**
