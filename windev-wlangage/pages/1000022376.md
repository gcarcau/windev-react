# CarteRécupèreImage (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Récupère l'image d'une carte affichée dans un champ Carte. Les marqueurs et les itinéraires affichés sur cette carte seront également présents dans l'image.

## Exemple

```wlangage
// Récupération de l'image affichée dans le champ Carte et affectation à un champ Image
CarteRécupèreImage(CARTE_MonChampCarte, CallbackCarteRécupèreImage)

	PROCÉDURE INTERNE CallbackCarteRécupèreImage(ImageCarte est une Image)
		IMG_Image = ImageCarte
	FIN
```

## Syntaxe

```wlangage
CarteRécupèreImage(<Champ Carte> , <Procédure WLangage>)
```

`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler. Si ce paramètre correspond à une chaîne vide (""), le champ Carte auquel appartient l'événement en cours sera utilisé.
`<Procédure WLangage>` *Nom de procédure*
> Nom de la procédure WLangage (également nommée "callback") appelée lorsque l'image du champ Carte sera disponible.
> Cette procédure est de la forme :
>
>
> ```wlangage
> PROCEDURE <Nom de la procédure>(<Image>)
> ```
>
>
> où <Image> est une variable de type [Image](1000019650.md) contenant la carte affichée dans le champ.

## Remarques

> _(iPhone/iPad)_ Si le champ Carte contient des dessins de type CartePolyligne utilisant la propriété Géodésique, la propriété Géodésique ne sera pas prise en compte dans l'image récupérée.

**Composante : wd300obj.dll**
