# telMetAppelEnAttente (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Met un appel en attente. Cet appel sera en attente jusqu'à l'utilisation de la fonction [telReprendAppelEnAttente](3076035.md).

## Syntaxe

```wlangage
<Résultat> = telMetAppelEnAttente(<Identifiant de l'appel>)
```

`<Résultat>` *Booléen*
> - Vrai si l'appel a été mis en attente,
> - Faux dans le cas contraire.
`<Identifiant de l'appel>` *Entier*
> Identifiant de l'appel à mettre en attente. Cet identifiant est connu dans la procédure WLangage appelée par la fonction [telDémarreDétectionAppel](3076029.md).

## Remarques

### Limitation
Il n'est pas possible d'appeler la fonction **telMetAppelEnAttente** dans la procédure de détection d'appels (définie grâce à la fonction [telDémarreDétectionAppel](3076029.md)).

### Configuration nécessaire
Les fonctions de téléphonie utilisent la technologie TAPI 2.0 et/ou la technologie TAPI 3.1. Ces technologies sont utilisables sur tous les systèmes.
Attention : cette fonctionnalité n'est pas disponible pour tous les matériels.

**Composante : wd300com.dll**
