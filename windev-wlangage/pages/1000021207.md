# ValeurRenvoyée (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **ValeurRenvoyée** permet de gérer la valeur renvoyée. Cette propriété est utilisable sur :

- les fenêtres, les pages et les champs. Pour plus de détails, consultez [ValeurRenvoyée](2510134.md).
- une variable de type [TâcheParallèle](1000021220.md).
- une variable de type [Thread](1000024879.md).
