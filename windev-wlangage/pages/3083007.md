# Fonctions de gestion des champs Zone répétée

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des champs Zone répétée (syntaxe préfixée)](1000023945.md)).
Les fonctions permettant de gérer les champs Zone répétée sont les suivantes :

| [GalerieAffichePopup](1000023476.md) | Affiche la popup automatique de zoom du champ Galerie d'images. |
| --- | --- |
| [GalerieFermePopup](1000023478.md) | Ferme la popup automatique de zoom de la galerie d'images. |
| [GaleriePopupAffichée](1000024975.md) | Indique si la popup automatique de zoom du champ Galerie d'images est affichée. |
| [ZoneRépétéeAffiche](3083001.md) | Réactualise l'affichage d'une zone répétée fichier à partir d'une position donnée : les modifications effectuées sur le fichier lié sont répercutées dans la zone répétée. |
| [ZoneRépétéeAjoute](3083006.md) | Ajoute une répétition à la fin d'un champ Zone répétée. |
| Nouveauté 2025 [ZoneRépétéeAjouteDébut](1410090428.md) | Ajoute une répétition (ou ligne) au début d'un champ Zone répétée infinie. La répétition est insérée avant la première répétition du champ Zone répétée. La position de défilement du champ Zone répétée n'est pas modifiée. |
| [ZoneRépétéeAjouteFI](1000023439.md) | Ajoute une répétition sous forme d'une fenêtre interne à la fin d'un champ Zone répétée par programmation. |
| Nouveauté 2025 [ZoneRépétéeAjouteFIDébut](1410090427.md) | Ajoute une répétition (ou une ligne) constituée par une fenêtre interne en première répétition d'un champ Zone Répétée infinie. La répétition est insérée avant la première répétition du champ Zone répétée. La position de défilement du champ Zone répétée n'est pas modifiée. |
| [ZoneRépétéeAjouteLigne](3083004.md) | Ajoute une répétition à la fin d'un champ Zone répétée. |
| [ZoneRépétéeAjoutEnCours](1000021638.md) | Modifie ou renvoie l'état de visibilité de la fenêtre interne de patience lors de l'ajout d'éléments supplémentaires dans un champ Zone répétée infinie. |
| [ZoneRépétéeAjoutePI](1410089366.md) | Ajoute une répétition sous forme d'une page interne à la fin d'un champ Zone répétée par programmation. |
| [ZoneRépétéeAnnuleBalayage](1000021988.md) | Annule l'affichage de la fenêtre interne affichée dans un champ Zone répétée suite au balayage d'une répétition (ou ligne). |
| [ZoneRépétéeCherche](3083005.md) | Recherche une valeur dans un attribut d'un champ Zone répétée. |
| [ZoneRépétéeCherchePartout](1000021997.md) | Recherche une valeur dans tous les attributs d'un champ Zone répétée. |
| [ZoneRépétéeDébutRemplissage](1000022370.md) | Indique le début du remplissage d'un champ Zone répétée par programmation. |
| [ZoneRépétéeDéplaceLigne](1000017248.md) | Déplace une répétition ou échange deux répétitions d'un champ Zone répétée. |
| [ZoneRépétéeDéroule](1000019771.md) | Déroule une rupture du champ Zone répétée sur une ligne donnée. |
| [ZoneRépétéeDérouleTout](1000019774.md) | Déroule toutes les ruptures d'un champ Zone répétée avec rupture. |
| [ZoneRépétéeEnregistre](3083028.md) | Valide la modification ou l'ajout de l'enregistrement associé à la répétition en cours dans le champ Zone répétée fichier. |
| [ZoneRépétéeEnroule](1000019770.md) | Enroule une rupture précédemment déroulée d'un champ Zone répétée. |
| [ZoneRépétéeEnrouleDéroule](1000019970.md) | Sur une répétition/ligne donnée d'un champ Zone répétée :   - replie une rupture (si elle est déroulée), - déplie une rupture (si elle est enroulée). |
| [ZoneRépétéeEnrouleTout](1000019772.md) | Enroule toutes les ruptures déroulées d'un champ Zone répétée. |
| [ZoneRépétéeFinRemplissage](1000022371.md) | Indique la fin du remplissage d'un champ Zone répétée par programmation. |
| [ZoneRépétéeIndiceRupture](3083029.md) | Renvoie l'indice du haut et du bas de rupture d'une rupture donnée dans un champ Zone répétée. |
| [ZoneRépétéeInfoXY](3083022.md) | Permet de connaître la répétition ou le champ se trouvant à une position donnée du champ Zone répétée (X, Y). |
| [ZoneRépétéeInsère](3083003.md) | Insère une répétition dans un champ Zone répétée. |
| [ZoneRépétéeInsèreFI](1000023440.md) | Insère une répétition sous forme d'une fenêtre interne dans un champ Zone répétée par programmation. |
| [ZoneRépétéeInsèreLigne](3083002.md) | Insère une répétition dans un champ Zone répétée. |
| [ZoneRépétéeInsèrePI](1410089367.md) | Insère une répétition sous forme d'une page interne dans un champ Zone répétée par programmation. |
| [ZoneRépétéeModifie](3083013.md) | Modifie les valeurs des attributs dans une répétition d'un champ Zone répétée. |
| [ZoneRépétéeModifieFI](1000023441.md) | Modifie une répétition correspondant à une fenêtre interne dans un champ Zone répétée par programmation. |
| [ZoneRépétéeModifieLigne](3083015.md) | Modifie les valeurs des attributs dans une répétition d'un champ Zone répétée (fichier ou mémoire). |
| [ZoneRépétéeModifiePI](1410089368.md) | Modifie une répétition correspondant à une page interne dans un champ Zone répétée par programmation. |
| [ZoneRépétéeNumEnr](3083010.md) | Renvoie le numéro de l'enregistrement en cours dans un champ Zone répétée fichier. |
| [ZoneRépétéeOccurrence](3083014.md) | Renvoie le nombre de répétitions d'un champ Zone répétée. |
| [ZoneRépétéePosition](3083023.md) | Déplace l'ascenseur d'un champ Zone répétée par programmation pour afficher une répétition spécifique ou renvoie l'indice de la première répétition affichée dans un champ Zone répétée par programmation. |
| [ZoneRépétéeRafraîchissementVisible](1000021195.md) | Modifie ou renvoie l'état de visibilité du bandeau de rafraîchissement d'un champ Zone répétée. |
| [ZoneRépétéeRestaurePositionEtSélection](1000021789.md) | Restaure la position de l'ascenseur d'un champ Zone répétée ainsi que le ou les éléments sélectionnés. |
| [ZoneRépétéeSauvePositionEtSélection](1000021788.md) | Sauve :  - la position de l'ascenseur dans un champ Zone répétée, - le ou les éléments sélectionnés.  Ces éléments peuvent être restaurés grâce à la fonction [ZoneRépétéeRestaurePositionEtSélection](1000021789.md). |
| [ZoneRépétéeSelect](3083024.md) | Renvoie l'indice de l'élément sélectionné dans un champ Zone répétée. |
| [ZoneRépétéeSelectMoins](3083026.md) | Dé-sélectionne une répétition dans un champ Zone répétée. |
| [ZoneRépétéeSelectOccurrence](3083027.md) | Renvoie le nombre de répétitions sélectionnées dans un champ Zone répétée. |
| [ZoneRépétéeSelectPlus](3083025.md) | Sélectionne une répétition dans un champ Zone répétée. |
| [ZoneRépétéeSupprime](3083008.md) | Supprime une répétition dans un champ Zone répétée. |
| [ZoneRépétéeSupprimeSelect](1000023336.md) | Supprime la ou les lignes sélectionnées dans un champ Zone répétée. |
| [ZoneRépétéeSupprimeTout](3083012.md) | Supprime toutes les répétitions du champ Zone répétée par programmation. |
| [ZoneRépétéeTrie](3083009.md) | Permet de :  - Trier un champ Zone répétée selon un ou plusieurs de ses attributs. - Trier un champ Zone répétée sur tous ses attributs. - Annuler un tri précédemment effectué (c'est-à-dire ne plus tenir compte du tri). |
| [ZoneRépétéeVersExcel](3083030.md) | Crée un fichier Excel avec les données d'un champ Zone répétée (champ Zone répétée fichier ou champ Zone répétée mémoire). |
| [ZoneRépétéeVersWord](3083031.md) | Crée un fichier Word (.RTF) avec les données d'un champ Zone répétée. |
| [ZoneRépétéeVersXML](3083032.md) | Crée un fichier XML avec les données d'un champ Zone répétée (champ Zone répétée fichier ou champ Zone répétée par programmation). |
