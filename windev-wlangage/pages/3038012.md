# Fonctions de gestion des fenêtres

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Mac Catalyst)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des fenêtres (syntaxe préfixée)](1410088865.md)).
Voici la liste des principales fonctions permettant de gérer les fenêtres WINDEV et WINDEV Mobile par programmation.
Pour plus de détails :

- Sur la programmation des menus, consultez [Fonctions de gestion des menus](3038016.md)
- Sur la programmation des fenêtres MDI, consultez [Fonctions de programmation des fenêtres MDI](3052003.md)

| [Abandonne](1000017024.md) | Ferme la fenêtre en cours en exécutant l'événement "Clic" du champ Bouton de type ABANDON. |
| --- | --- |
| [ChangeGabarit](3013026.md) | Change dynamiquement le gabarit :   - de toutes les fenêtres de l'application en cours, - des fenêtres présentes dans les composants WINDEV utilisés par l'application, - d'une fenêtre spécifique du projet. |
| [DélaiAvantFermeture](3038040.md) | Limite le temps d'affichage d'une fenêtre ou d'une boîte de dialogue.  Si aucune action de l'utilisateur n'est effectuée, lorsque le temps spécifié est écoulé :   - dans le cas d'une fenêtre, le code d'un bouton de la fenêtre sera exécuté. - dans le cas d'une boîte de dialogue, la boîte de dialogue est automatiquement fermée. |
| [DemandeMiseAJourIHM](1000021378.md) | Demande l'exécution de l'événement "Demande de mise à jour de l'affichage" (et rend la main **sans attendre l'exécution de l'événement**). Cette fonction est conservée par compatibilité. |
| [DemandeMiseAJourIHMParent](1000022961.md) | Demande l'exécution du traitement "Demande de mise à jour de l'affichage" du parent. **Cette fonction est conservée par compatibilité.** |
| [DemandeMiseAJourUI](1000023899.md) | Demande l'exécution de l'événement "Demande de mise à jour de l'affichage" (et rend la main **sans attendre l'exécution de l'événement**). |
| [DemandeMiseAJourUIÉlément](1410088703.md) | Demande l'exécution de l'événement "Demande de mise à jour de l'affichage" de l'élément spécifié (et rend la main **sans attendre l'exécution de l'événement**). |
| [DemandeMiseAJourUIParent](1000023900.md) | Demande l'exécution du traitement "Demande de mise à jour de l'affichage" du parent. |
| [EnumèreMenu](3038039.md) | Renvoie :  - le nom de la nième option ou sous-option du menu principal de la fenêtre. - le nom de la nième option ou sous-option d'un menu contextuel personnalisé (créé avec WINDEV ou WINDEV Mobile). |
| [ExécuteMiseAJourIHM](1000021379.md) | Exécute immédiatement le traitement "Demande de mise à jour de l'affichage" de la fenêtre, de la page, de la fenêtre interne, de la page interne, du modèle de champs ou du superchamp. **Cette fonction est conservée par compatibilité.** |
| [ExécuteMiseAJourIHMParent](1000022962.md) | Exécute immédiatement l'événement "Demande de mise à jour de l'affichage" du parent. **Cette fonction est conservée par compatibilité.** |
| [ExécuteMiseAJourUI](1000023901.md) | Exécute immédiatement l'événement "Demande de mise à jour de l'affichage" de la fenêtre, de la page, de la fenêtre interne, de la page interne, du modèle de champs ou du superchamp. |
| [ExécuteMiseAJourUIÉlément](1410088704.md) | Exécute immédiatement l'événement "Demande de mise à jour de l'affichage" de l'élément spécifié. |
| [ExécuteMiseAJourUIParent](1000023902.md) | Exécute immédiatement l'événement "Demande de mise à jour de l'affichage" du parent. |
| [FenActiveGFI](3038056.md) | Active ou désactive le GFI (Grisage des Fenêtres Inaccessibles) :  - soit d'une fenêtre spécifique. - soit de toutes les fenêtres de l'application. |
| [FenAdapteHauteur](1000019886.md) | Adapte la hauteur de la fenêtre au contenu des champs. |
| [FenAdapteLargeur](1000019920.md) | Adapte la largeur de la fenêtre au contenu des champs. |
| [FenAdapteTaille](3038049.md) | Adapte la taille de la fenêtre au contenu des champs. |
| [FenAgencementEnCours](1000021133.md) | Renvoie l'indice de l'agencement en cours :   - dans la fenêtre en cours. - dans la fenêtre ou dans la fenêtre interne spécifiée. |
| [FenAttenteDébut](1000023416.md) | Ouvre la fenêtre d'attente de l'application. |
| [FenAttenteFin](1000023417.md) | Ferme la fenêtre d'attente de l'application ouverte avec la fonction [FenAttenteDébut](1000023416.md). |
| [FenChangeAgencement](1000021056.md) | Applique un agencement spécifique sur :   - une fenêtre. - une fenêtre interne. |
| [FenChangeAlias](3038028.md) | Modifie l'alias d'une fenêtre. |
| [FenColleFormulaire](1000018993.md) | Colle le contenu d'un formulaire stocké dans le presse-papiers. |
| [FenCopieFormulaire](1000018992.md) | Copie le contenu d'un formulaire dans le presse-papiers. |
| [FenCoulissanteVisible](1000020978.md) | Affiche ou masque une fenêtre coulissante (sliding menu). |
| [FenDésactiveEffet](1000017172.md) | Désactive des effets visuels du moteur graphique de WINDEV (pour une utilisation sous TSE par exemple). |
| [FenDonneHauteurAdaptée](1000019888.md) | Renvoie la hauteur d'une fenêtre, adaptée au contenu des champs. |
| [FenDonneLargeurAdaptée](1000019889.md) | Renvoie la largeur d'une fenêtre, adaptée au contenu des champs. |
| [FenEffetInactif](3038055.md) | Active ou désactive le GFI (Grisage des Fenêtres Inaccessibles) :  - soit d'une fenêtre spécifique. - soit de toutes les fenêtres de l'application. |
| [FenEnCours](3038033.md) | Identifie la fenêtre en cours de saisie. |
| [FenEnExécution](3038034.md) | Identifie la fenêtre contenant le code du WLangage en cours d'exécution. |
| [FenEtat](3038030.md) | Identifie ou modifie l'état d'une fenêtre. |
| [FenExtHaut](3038032.md) | Renvoie la hauteur totale d'une fenêtre. |
| [FenExtLarg](3038029.md) | Renvoie la largeur totale d'une fenêtre. |
| [FenExtPosX](3038027.md) | Renvoie la position horizontale du coin haut gauche d'une fenêtre par rapport au coin haut gauche de l'écran. |
| [FenExtPosY](3038026.md) | Renvoie la position verticale du coin haut gauche d'une fenêtre par rapport au coin haut gauche de l'écran. |
| [FenForceGFI](1000019890.md) | Force le GFI (Grisage des Fenêtres Inaccessibles) sur une fenêtre même si cette fenêtre n'est pas inaccessible. |
| [FenHauteurBarreIcone](3038025.md) | Renvoie ou modifie la hauteur actuelle de la zone "Barre d'icônes" de la fenêtre mère MDI en cours. |
| [FenImageFond](3038038.md) | Modifie l'image de fond d'une fenêtre en précisant le mode d'affichage de cette image. |
| [FenInitialisée](1000018919.md) | Permet de savoir si le code de fin d'initialisation d'une fenêtre a été exécuté. |
| [FenIntHaut](3038037.md) | Renvoie la hauteur interne d'une fenêtre (sans la barre de titre ni le cadre). |
| [FenIntLarg](3038031.md) | Renvoie la largeur interne d'une fenêtre (sans le cadre). |
| [FenIntPosX](3038017.md) | Renvoie la position horizontale du coin haut gauche de la zone interne (sans le cadre ni la barre de titre) d'une fenêtre par rapport au coin haut gauche de l'écran. |
| [FenIntPosY](3038011.md) | Renvoie la position verticale du coin haut gauche de la zone interne (sans le cadre ni la barre de titre) d'une fenêtre par rapport au coin haut gauche de l'écran. |
| Nouveauté 2025 [FenOptimise](1410090613.md) | Permet de changer le mode de création et de dessin des fenêtres. Ce mode sera utilisé par toutes les fenêtres ouvertes après cette fonction. |
| [FenOrientation](1000020075.md) | Modifie ou récupère l'orientation d'affichage de la fenêtre courante. |
| [FenPrécédente](3038014.md) | Identifie la fenêtre qui était en cours de saisie avant la fenêtre actuellement en cours de saisie (pour le même projet). |
| [FenRafraîchissementVisible](1000023419.md) | Modifie ou retourne l'état de visibilité du bandeau de rafraîchissement d'une fenêtre. |
| [FenRectangleEcran](1000017198.md) | Renvoie les coordonnées de l'écran qui contient une fenêtre. |
| [FenRepeint](3038006.md) | Redessine immédiatement les champs de la fenêtre nécessitant une mise à jour graphique. |
| [FenTaille](3038020.md) | La fonction FenTaille :  - renvoie ou modifie le mode d'affichage (maximisé, iconisé ou normal) d'une fenêtre, - modifie la hauteur et/ou la largeur d'une fenêtre, - déplace la fenêtre et modifie la hauteur et/ou la largeur d'une fenêtre. |
| [FenTauxGFI](3038057.md) | Permet de connaître ou de modifier le taux de grisage des fenêtres utilisant le GFI (Grisage des Fenêtres Inaccessibles). |
| [Ferme](3038018.md) | Ferme une fenêtre WINDEV (en renvoyant si nécessaire une valeur). |
| [Iconise](3038015.md) | Iconise une fenêtre WINDEV. |
| [ImageFenêtre](3038013.md) | Crée l'image de la fenêtre spécifiée dans un fichier BMP. |
| [InitFenêtre](3038019.md) | Initialise les champs à zéro (ou non) et lance les traitements d'initialisation des champs et de la fenêtre. |
| [Maximise](3038001.md) | Affiche une fenêtre WINDEV dans sa taille maximale. |
| [MultitâcheRepeint](3038004.md) | Re-dessine immédiatement les champs de la fenêtre nécessitant une mise à jour graphique. |
| [Ouvre](3038035.md) | Ouvre une fenêtre modale WINDEV. |
| [OuvreAsynchrone](1410087804.md) | Ouvre une fenêtre dont le résultat sera récupéré via une procédure WLangage (appelée "callback"). |
| [OuvreFenêtreMobile](1000021018.md) | Ouvre une fenêtre dans une application mobile. |
| [OuvreFille](3038021.md) | Ouvre une fenêtre fille non modale. |
| [OuvreMenuPrincipal](1000020347.md) | Ouvre le menu principal de la fenêtre en cours. |
| [OuvrePopup](3038046.md) | Ouvre une fenêtre de type popup et attend sa fermeture. |
| [OuvrePopupAsynchrone](1410087806.md) | Ouvre une fenêtre de type popup dont le résultat sera récupéré par une procédure WLangage (également appelée "Callback"). |
| [OuvrePopupPosition](3038047.md) | Ouvre une fenêtre de type popup en précisant sa position d'ouverture et attend sa fermeture. |
| [OuvreSoeur](3038045.md) | Ouvre une fenêtre soeur non modale. |
| [Restaure](3038042.md) | Affiche une fenêtre WINDEV dans sa taille initiale. |
| [TitreEnCours](3038023.md) | Modifie le titre de la fenêtre en cours (connu par la fonction [FenEnCours](3038033.md)) et la barre de titre. |
| [TitreSuivant](3038043.md) | Modifie le titre de la prochaine fenêtre à ouvrir. |
| [Utilise](3038044.md) | Ouvre une fenêtre WINDEV et ferme toutes les autres fenêtres précédemment ouvertes. |
Les fonctions suivantes peuvent également être utilisées pour manipuler les fenêtres :

| [EnumèreElément](3064001.md) | Permet d'énumérer les éléments du projet : fenêtres, pages, états, requêtes, ... |
