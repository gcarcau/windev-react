# Activé (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Activé** permet d'activer ou non la gestion d'un élément. Cette propriété est utilisable sur :

- une variable de type [hDescriptionSauvegarde](1000017455.md).
- une variable de type [hOptimisationPlanifiée](1000018854.md).
- une variable de type [InfoVersion](1000018905.md).
- une variable de type [gpwUtilisateur](1000021088.md).
- une variable de type [hTâchePlanifiée](1000017448.md).
- une variable de type [hPlanificationVueMatérialisée](1000021444.md).
- une variable de type [serveurAppliTâchePlanifiée](1000022367.md).
