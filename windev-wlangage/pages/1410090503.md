# CmdEcritEntréeStandard (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU))

Ecrit les données sur l'entrée standard de la commande exécutée en mode console.

## Exemple

```wlangage
// Exécution de la commande 'C:\Chemin\MonProgramme.exe -opt1=val1'

// Définition de la commande
MaCommandeAExécuter est une Commande
// Exécutable à lancer
MaCommandeAExécuter = "C:\Chemin\MonProgramme.exe"
// Arguments à passer à l'exécutable
MaCommandeAExécuter.Arguments = "Argument1"
// Activation des flux
MaCommandeAExécuter.Flux = cmdEntréeStandard + cmdSortieStandard
// Ajout d'un argument à la ligne de commande
CmdAjouteArgument(MaCommandeAExécuter, "Argument2")
// Ajout d'une option à la ligne de commande
CmdAjouteOption(MaCommandeAExécuter, "opt1", "val1")

// Exécution de la commande
CmdExécute(MaCommandeAExécuter, Faux)
// Écriture dans l'entrée standard (possible car le flux est actif)
CmdEcritEntréeStandard(MaCommandeAExécuter, "Test Ecriture" + RC)
```

## Syntaxe

```wlangage
CmdEcritEntréeStandard(<Commande manipulée> , <Données>)
```

`<Commande manipulée>` *Variable de type Commande*
> Nom de la variable de type [Commande](1410090491.md) correspondant à la commande à manipuler.
`<Données>` *Chaîne de caractères*
> Données à envoyer à la commande.
> Attention : Le flux d'entrée de commande doit être activé dans la variable de type [Commande](1410090491.md) (propriété **Flux**).
