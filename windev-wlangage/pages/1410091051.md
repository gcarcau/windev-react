# SysEstAdministrateur (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **Autres** (Procédures stockées)

Indique si l'utilisateur courant possède les droits d'administrateur de la machine.
Nouveauté Abonnement
Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
SI SysEstAdministrateur() = Vrai ALORS
	Info("Vous êtes administrateur de la machine.")
FIN
```

## Syntaxe

```wlangage
<Résultat> = SysEstAdministrateur()
```

`<Résultat>` *Booléen*
> - Vrai si l'utilisateur courant possède les droits d'administrateur de la machine,
> - Faux dans le cas contraire.

**Classification Métier / UI : Code métier**

**Composante : wd300std.dll**
