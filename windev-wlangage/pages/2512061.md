# NullSupporté (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **NullSupporté** permet de gérer la valeur NULL dans des fichiers de données HFSQL.
Cette propriété permet de :

- Connaître le mode de gestion de la valeur NULL pour un fichier de données décrit sous l'éditeur d'analyses.
- Définir que la valeur NULL va être gérée lors de la description d'un fichier de données par programmation.

**Remarque** : Si un fichier de données supporte la valeur NULL et si la rubrique autorise le NULL (propriété [NullAutorisé](1000019492.md)), il sera possible d'utiliser la propriété [Null](2512064.md) pour par exemple affecter NULL à la rubrique pour l'enregistrement en cours.

## Exemple

```wlangage
// Définir la gestion de la valeur NULL dans le fichier de données Client
Client.NullSupporté = Vrai
```

## Syntaxe

#### Savoir si le fichier de données permet la gestion de la valeur NULL

```wlangage
<Résultat> = <Fichier de données>.NullSupporté
```

`<Résultat>` *Booléen*
> - Vrai si le fichier permet la gestion de la valeur NULL,
> - Faux dans le cas contraire.
`<Fichier de données>` *Chaîne de caractères*
> Nom logique du fichier de données manipulé. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Fichier](1514065.md).

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS, Code Utilisateur (MCU), Ajax)_ Définir la gestion de la valeur NULL Masquer les détails
<Fichier de données>.NullSupporté = <Mode de gestion>

 <Fichier de données> : Chaîne de caractèresNom logique du fichier de données manipulé. Ce nom vient d'être défini grâce au type Description de Fichier. <Mode de gestion> : BooléenVrai pour gérer la valeur NULL, Faux dans le cas contraire.

## Remarques

### Cas particulier : Vue et requête
La propriété **NullSupporté** utilisée sur une vue ou une requête renvoie Vrai si et seulement si au moins un des fichiers source supporte la gestion du NULL.

### Cas d'erreurs
L'accès en écriture sur la propriété [Null](2512064.md) échoue si la propriété **NullSupporté** a pour valeur Faux.
L'erreur 70409 ("Vous avez appelé la fonction [HModifie](3044042.md). Le fichier <XXXX> ne supporte pas l'accès à la propriété Null. Veuillez activer la gestion du Null dans la description du fichier.") apparaît si les conditions suivantes sont réunies :

- une rubrique d'une requête ou d'une vue est mise à NULL,
- cette rubrique provient d'un fichier qui ne gère pas la valeur NULL
- la fonction [HModifie](3044042.md) est utilisée sur la requête ou la vue.
