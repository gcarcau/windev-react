# <Graphe>.NuageReliePoint (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Relie ou non les points dans un graphe de type "Nuage de points".
Exemple de graphe avec les points reliés : [image: Graphe avec points reliés]

**Rappel** : Par défaut, les points d'un graphe de type "Nuage de points" sont reliés.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

Nouveauté Abonnement

> _(Android)_ Cette fonction est désormais disponible pour les applications Android.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
// Délier les points du graphe GRF_MonGraphe de type "Nuage de points"
GRF_MonGraphe.NuageReliePoint(Faux)
```

## Syntaxe

#### Relier ou délier les points d'un graphe de type Nuage de points

```wlangage
<Champ Graphe>.NuageReliePoint(<Relier>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres, de pages ou d'états).
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Relier>` *Booléen*
> - Vrai si les points doivent être reliés entre eux,
> - Faux dans le cas contraire.

#### Relier ou délier les points d'une série d'un graphe de type Nuage de points

```wlangage
<Champ Graphe>.grNuageReliePoint(<Numéro de la série> , <Relier>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres, de pages ou d'états).
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Numéro de la série>` *Entier*
> Numéro de la série à manipuler.
`<Relier>` *Booléen*
> - Vrai si les points doivent être reliés entre eux,
> - Faux dans le cas contraire.

## Remarques

- Dans les graphes de type "Nuage de points", un point est défini par ses coordonnées (abscisse et ordonnée).
- Les données définies avec la fonction **<Graphe>.NuageReliePoint** seront prises en compte lors du prochain appel à la fonction [<Graphe>.Dessine](1000024062.md).
- La fonction **<Graphe>.NuageReliePoint** est utilisée uniquement pour les graphes de type "Nuage de points". Cette fonction est sans effet pour tous les autres types de graphes.
- Les points sont reliés dans l'ordre dans lequel ils ont été ajoutés.
