# PiloteSimulateur (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

Pilote la fenêtre du simulateur mobile (Android ou iOS).
> _(WINDEV)_ Cette fonction est disponible sous WINDEV uniquement pour pouvoir être utilisée en mode simulateur. Utilisée dans une application WINDEV, cette fonction n'a aucun effet.

## Exemple

```wlangage
// Change l'orientation du simulateur
PiloteSimulateur(psTourneEcran)
```

## Syntaxe

```wlangage
PiloteSimulateur(<Action>)
```

`<Action>` *Constante de type entier*
> Action à réaliser :
>
> | *psFerme* | Ferme le simulateur. |
> | --- | --- |
> | *psMenu* | Simule un appui sur le bouton Menu. _(iPhone/iPad)_ Cette constante n'est pas disponible. |
> | *psRetour* | Simule un appui sur le bouton Retour. _(iPhone/iPad)_ Cette constante n'est pas disponible. |
> | *psTourneEcran* | Tourne l'écran : passe du mode paysage au mode portrait ou inversement. |

## Remarques

Cette fonction doit être utilisée uniquement dans le code de tests automatiques effectués sur le simulateur Android ou iOS.
