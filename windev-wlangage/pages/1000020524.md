# gVersTexte (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Supprime les éléments graphiques d'une chaîne de caractères utilisant les fonctions [gValeurMémorisée](1410088363.md), [gImage](3029042.md), ...

## Exemple

```wlangage
s est une chaîne = gImage("Blog.bmp") + "Test" + gValeurMémorisée("3")
ListeAjoute(LISTE_Liste1, s)

SI gVersTexte(s) = "Test" ALORS
	Info("Test")
FIN
```

## Syntaxe

```wlangage
<Résultat> = gVersTexte(<Chaîne à traiter>)
```

`<Résultat>` *Chaîne de caractères*
> Chaîne de caractères sans les éléments graphiques.
`<Chaîne à traiter>` *Chaîne de caractères*
> Chaîne de caractères contenant ou pas des éléments graphiques (fonctions [gValeurMémorisée](1410088363.md), [gImage](3029042.md), [gRectangle](3029045.md), ...).
> Si la chaîne ne contient pas d'éléments graphiques, <Résultat> correspondra à la chaîne à traiter.

**Composante : wd300obj.dll**
