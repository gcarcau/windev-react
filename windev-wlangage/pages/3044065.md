# HGèreTrigger (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Active ou désactive la gestion des triggers. Pour plus de détails, consultez [Gestion des triggers](3044271.md).
**Remarque** : Par défaut, la gestion des triggers est active. **Pour accélérer votre application**, la désactivation des triggers est conseillée si ces derniers ne sont pas utilisés.

## Exemple

```wlangage
// Désactive la gestion des triggers
HGèreTrigger(Faux)
```

## Syntaxe

```wlangage
<Résultat> = HGèreTrigger(<Gestion>)
```

`<Résultat>` *Booléen*
> Ancien mode de gestion des triggers (avant l'utilisation de la fonction **HGèreTrigger**) :
>
> - Vrai si la gestion des triggers était active,
> - Faux si la gestion des triggers n'était pas active.
`<Gestion>` *Booléen*
> - Vrai si la gestion des triggers est activée,
> - Faux si cette gestion doit être désactivée.
