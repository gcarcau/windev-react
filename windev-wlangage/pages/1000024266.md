# <Traitement de texte>.Imprime (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Imprime le contenu d'un champ Traitement de texte au format "docx".
Remarque : Cette fonction est équivalente à la fonction [iImprimeDoc](1000022390.md).

## Exemple

```wlangage
iDestination(iVisualisateur)
TT_MonChampTT.Imprime()
```

## Syntaxe

```wlangage
<Champ Traitement de texte>.Imprime()
```

`<Champ Traitement de texte>` *Nom de champ*
> Nom du champ Traitement de texte dont le contenu doit être imprimé.
