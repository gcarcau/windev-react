# Le champ Editeur de code

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows, WEBDEV - Code Navigateur)

## Présentation du champ Editeur de code

Le champ Editeur de code permet à un utilisateur de l'application ou du site de saisir du code WLangage.
> _(WINDEV)_ Il est ainsi possible d'utiliser ce type de champ dans une application : pour que le développeur puisse faire des tests, pour qu'un utilisateur final averti saisisse par exemple des formules, lance des scripts, etc. pour effectuer une personnalisation spécifique à un client.
Nouveauté 2025

> _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur)_ Ce champ est désormais disponible pour les sites WEBDEV sous Windows.
Nouveauté 2025

> _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur)_ Dans un site WEBDEV, il est possible de saisir du code WLangage pour le colorer. Le code saisi n'est pas exécutable nativement. En effet, exécuter un code WLangage saisi par l'internaute entraîne nécessairement une faille de sécurité.

ATTENTION : Ce champ Editeur de code est indépendant : il ne connaît ni l'analyse liée au projet, ni les fichiers de données associés. Pour accéder aux données, il est nécessaire d'utiliser par exemple la fonction [HDéclareExterne](3044204.md). Exemple :

```wlangage
SI PAS HDéclareExterne(fRepDonnées() + fSep() + "CLIENTS.FIC", "CLIENTS") ALORS
	Erreur(HErreurInfo())
	RETOUR
FIN
HLitRecherchePremier(CLIENTS,"CODECLI","0018300")
Info(CLIENTS.NOM1)
```

## Créer un champ Editeur de code

> _(WINDEV)_ Pour créer un champ de type Editeur de code :Sous le volet "Création", dans le groupe "Champs graphiques", déroulez "Bureautique" puis cliquez sur "Editeur de code". Cliquez dans la fenêtre à la position où le champ doit être créé.
Nouveauté 2025

> _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur)_ Pour créer un champ de type Editeur de code :Sous le volet "Création", dans le groupe "Champs graphiques", déroulez "Avancé" puis cliquez sur "Editeur de code". Cliquez dans la page à la position où le champ doit être créé.

Remarque : Les dimensions du champ créé sont optimisées pour occuper l'espace disponible à la position indiquée. Si la taille du champ ne vous convient pas, utilisez la combinaison de touches Ctrl + Z : le champ retrouvera sa taille par défaut.

Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ.
