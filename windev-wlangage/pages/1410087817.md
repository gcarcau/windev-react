# Zone (Propriété)

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **Zone** permet de définir une zone. Cette propriété est utilisable sur :

- une variable de type [gglParamètreCarte](1000017505.md).
- une variable de type [Scanneur](1410087808.md).
