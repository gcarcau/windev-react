# VérifieOrthographe (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

La propriété **VérifieOrthographe** permet d'activer ou non la vérification automatique des fautes d'orthographe.
Les mots n'existant pas dans le dictionnaire sont automatiquement soulignés d'un trait rouge :

- dans les champs de saisie.
- dans les colonnes des champs Table.
- dans les champs Traitement de texte.

**Remarque** : Cette propriété est identique à l'option "Vérifier l'orthographe" présente :

- dans l'onglet "Détail" de la fenêtre de description des champs de saisie,
- dans l'onglet "Détail" de la fenêtre de description des colonnes des champs Table.

## Exemple

```wlangage
// Active la vérification orthographique dans un champ de saisie
SAI_Texte.VérifieOrthographe = Vrai
```

## Syntaxe

#### Savoir si la correction orthographique est activée

```wlangage
<Résultat> = <Champ manipulé>.VérifieOrthographe
```

`<Résultat>` *Booléen*
> - Vrai si la correction orthographique est activée,
> - Faux dans le cas contraire.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler :
>
> - champ de saisie,
> - colonne d'un champ Table,
> - champ Traitement de texte.

#### Activer ou non la correction orthographique

```wlangage
<Champ manipulé>.VérifieOrthographe = <Activer / Désactiver>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler :
>
> - champ de saisie,
> - colonne d'un champ Table,
> - champ Traitement de texte.
`<Activer / Désactiver>` *Booléen*
> - Vrai si la correction orthographique doit être activée,
> - Faux dans le cas contraire.
>
>
> > _(iPhone/iPad, Widget IOS)_ Attention : l'activation ou non de la correction orthographique n'est pas directement appliquée. En effet, il est nécessaire que le champ perde puis reprenne le focus (nécessaire pour que le système puisse adapter le clavier du champ).

## Remarques

> _(WINDEV, Etats et Requêtes, Windows, Code Utilisateur (MCU))_ Correcteur orthographique utilisé dans les champs de saisie et les colonnes d'un champ TableDans les champs de saisie et les colonnes d'un champ Table d'une application WINDEV, la propriété VérifieOrthographe utilise : soit le dictionnaire de OpenOffice 2.0. Pour plus de détails sur l'installation de ce logiciel et de ses dictionnaires, consultez Vérification d'orthographe avec OpenOffice.soit le correcteur intégré.Dans ce cas : les dictionnaires français et anglais sont automatiquement copiés (avec leur licence respectives) dans le répertoire de l'exécutable (option paramétrable dans la fenêtre de description du projet, onglet "Options"). les dictionnaires français et anglais sont chargés par défaut. pour utiliser d'autres dictionnaires, il est nécessaire de les associer à une langue et de les charger en mémoire avec la fonction DictionnaireCharge. Pour plus de détails, consultez Vérification d'orthographe basée sur les dictionnaires Hunspell.La fonction ParamètreOrthographe permet de : choisir le correcteur orthographique utilisé. activer le correcteur orthographique pour tous les champs de saisie de l'application. paramétrer la langue utilisée (dans le cas d'une correction orthographique via OpenOffice). Sur les mots non reconnus, le menu contextuel par défaut de WINDEV propose les options suivantes :Remplacement du mot par un mot valide (les 8 premières propositions de OpenOffice ou du correcteur intégré sont proposées).Ajout du mot dans le dictionnaire.

> _(WINDEV, Etats et Requêtes, Windows, Code Utilisateur (MCU))_ Correcteur orthographique utilisé dans les champs Traitement de texteDans les champs Traitement de texte, la propriété VérifieOrthographe utilise une vérification orthographique basée sur les dictionnaires au format Hunspell.Par défaut, si votre projet contient un champ Traitement de texte : les dictionnaires français et anglais sont automatiquement copiés (avec leur licence respectives) dans le répertoire de l'exécutable (option paramétrable dans la fenêtre de description du projet, onglet "Options"). les dictionnaires français et anglais sont chargés par défaut. Pour utiliser d'autres dictionnaires, il est nécessaire de les associer à une langue et de les charger en mémoire avec la fonction DictionnaireCharge. Pour plus de détails, consultez Vérification d'orthographe basée sur les dictionnaires Hunspell.

> _(Android, iPhone/iPad, Widget IOS)_ Correcteur orthographique utiliséLa propriété VérifieOrthographe utilise correcteur orthographique du système.Sur les mots non reconnus, le menu contextuel propose les options suivantes :Remplacement du mot par un mot valide.Ajout du mot dans le dictionnaire.Remarque : Le correcteur orthographique du système doit être activé.
