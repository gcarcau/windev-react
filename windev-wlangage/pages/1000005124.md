# NotesModifieFichierAttaché (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Modifie un fichier attaché à un champ du document en cours dans Lotus Notes.
Pour prendre en compte la modification de ce fichier, il est nécessaire d'enregistrer le document à l'aide de la fonction [NotesEnregistre](1000005110.md).

## Exemple

```wlangage
// Ouverture de la connexion
IDConnexion est un entier
IDConnexion = NotesOuvreConnexion("MotDePasse", "ServeurMars", ...
		"C:\Users\Julie\AppData\Local\Lotus\Notes\Data\user.id")
// Spécification de la base Lotus Notes à utiliser
IDBase est un entier
IDBase = NotesOuvreBase(IDConnexion, "julie.nsf")
...
// Lecture du premier document
NotesDocumentPremier(IDBase)
...
// Attachement d'un fichier au document en cours
NumFic est un entier
NumFic = NotesAjouteFichierAttaché(IDBase, "MonChampLotusNotes", "C:\MesDocuments\MonFichier.TXT")
...
// Modification de ce fichier
NotesModifieFichierAttaché(IDBase, "MonChampLotusNotes", NumFic, "D:\MesFichiers\FichierA.TXT")
```

## Syntaxe

```wlangage
<Résultat> = NotesModifieFichierAttaché(<Identifiant de la session> , <Champ Lotus Notes> , <Indice du fichier> , <Nouveau fichier>)
```

`<Résultat>` *Booléen*
> - Vrai si le fichier a été modifié,
> - Faux dans le cas contraire. En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Identifiant de la session>` *Entier*
> Identifiant de la session à utiliser. Cet identifiant est renvoyé par la fonction [EmailOuvreSessionNotes](3032121.md) ou [NotesOuvreBase](1000005101.md).
`<Champ Lotus Notes>` *Chaîne de caractères*
> Nom du champ Lotus Notes de type Texte Riche auquel le fichier à modifier est attaché.
> Pour connaître le nom et le type des champs du document Notes en cours, utilisez la fonction [NotesListeChamp](1000005112.md).
`<Indice du fichier>` *Entier*
> Indice du fichier à modifier. Cet indice correspond au rang du fichier dans la liste des fichiers du champ Lotus Notes (par exemple, le 3° fichier attaché aura l'indice 3).
> **Attention** : Les indices des fichiers sont modifiés lors de la suppression d'un fichier.
`<Nouveau fichier>` *Chaîne de caractères*
> Nom et chemin complet ou relatif du nouveau fichier à attacher au champ spécifié dans le document Notes en cours. Ce fichier sera automatiquement copié dans la base Lotus Notes en cours.

## Remarques

### Champ d'un document Notes
Chaque champ d'un document Notes peut avoir jusqu'à 256 fichiers attachés.

**Composante : wd300mess.dll**
