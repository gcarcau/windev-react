# HModifieOptimisationPlanifiée (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Modifie une tâche d'optimisation planifiée sur le serveur HFSQL défini par la connexion. Cette tâche est présente dans une variable avancée de type [hOptimisationPlanifiée](1000018854.md).

## Syntaxe

```wlangage
<Résultat> = HModifieOptimisationPlanifiée(<Connexion> , <Tâche d'optimisation planifiée>)
```

`<Résultat>` *Booléen*
> - Vrai si la tâche d'optimisation planifiée a été modifiée,
> - Faux en cas d'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion pour laquelle une tâche d'optimisation planifiée doit être modifiée. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Tâche d'optimisation planifiée>` *Variable de type hOptimisationPlanifiée*
> Nom de la variable de type [hOptimisationPlanifiée](1000018854.md) manipulée.

## Remarques

### Droits nécessaires
Pour modifier une tâche, il est nécessaire de posséder :

- le droit correspondant (constante *hDroitGèreTâche*) sur le serveur,
- le droit d'exécuter la commande liée à la tâche planifiée.

La tâche sera exécutée avec le compte de l'utilisateur qui a créé la tâche.
Remarque : Si le serveur est éteint, la tâche planifiée ne sera pas réalisée. La tâche planifiée sera réalisée à la prochaine date disponible lorsque le serveur sera allumé.
