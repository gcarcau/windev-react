# Propriétés associées aux Action Bar

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Une "Action Bar" peut être manipulée en WLangage dans une fenêtre avec les propriétés suivantes.

## Propriétés disponibles dans une fenêtre

### Action Bar : Propriétés disponibles dans une fenêtre
Les différentes propriétés associées aux "Action Bar" sont les suivantes :

| [Accessibilité](1410090235.md) | La propriété **Accessibilité** permet de définir et de connaître les propriétés d'accessibilité définies sur un champ. |
| --- | --- |
| [Couleur](2510071.md) | La propriété **Couleur** permet de connaître ou modifier la couleur de la police de :  - une variable de type Police. - un texte d'un champ Libellé ou calculé d'un état. - un texte d'un champ d'une fenêtre. - un texte d'un champ d'une page. |
| [CouleurFond](2510022.md) | La propriété **CouleurFond** permet de gérer la couleur de fond d'un champ, d'une fenêtre, d'une page ou d'un bloc d'un état. |
| [Extra](1410089327.md) | La propriété **Extra** permet de :  - Connaître les informations supplémentaires associées à un champ, à une fenêtre, ou à une page. - Modifier les informations supplémentaires associées à un champ, à une fenêtre ou à une page. |
| [Image](2510034.md) | La propriété **Image** permet de connaître et de modifier l'image de fond d'un champ ou d'un bloc. |
| [ImageFond](2510056.md) | La propriété **ImageFond** permet de connaître et de modifier l'image de fond d'un élément : fenêtre, page, champ ou état. |
| [Note](2510085.md) | La propriété **Note** permet de :  - Connaître les notes associées à un champ, à une fenêtre, à une page ou un état. - Modifier les notes associées à un champ, à une fenêtre, à une page ou un état. |
| [Opacité](2514006.md) | La propriété **Opacité** permet de connaître et définir le pourcentage d'opacité d'une fenêtre ou des champs présents dans une fenêtre ou une page. |
| [Style](1000021472.md) | La propriété **Style** permet de récupérer ou d'affecter le style complet d'un champ (y compris les surcharges). |
| [TitreNote](2510121.md) | La propriété **TitreNote** permet de :  - Connaître le titre des notes utilisé pour la documentation technique d'un champ, d'une fenêtre, d'une page ou d'un état. - Modifier le titre des notes utilisé pour la documentation technique d'un champ, d'une fenêtre, d'une page ou d'un état. |
| [Traitement](1000020878.md) | La propriété **Traitement** permet de modifier les traitements à exécuter par les événements disponibles sur un champ, une fenêtre, une page, un état, ... |
| [Valeur](2510130.md) | La propriété **Valeur** permet de :  - Connaître et modifier la valeur d'un champ d'un état. - Connaître et modifier la valeur d'un champ ou le titre d'une fenêtre. - Connaître l'identifiant d'un flux. - Connaître et modifier la valeur d'un champ ou le titre d'une page. |
| [ValeurRecherche](1000021602.md) | La propriété **ValeurRecherche** permet de connaître et modifier la valeur du champ de recherche dans une Action Bar. |
| [Visible](2510138.md) | La propriété **Visible** permet de :  - Savoir si un élément est visible. - Rendre un élément visible ou invisible. |
| [VisibleAvecAnimation](1410087232.md) | La propriété **VisibleAvecAnimation** permet de rendre un champ visible ou invisible en jouant l'animation "Apparition/Disparition". |
| [Volet](1000021098.md) | La propriété **Volet** permet de :   - Connaître les volets d'onglet associés à un champ. - Définir les volets d'onglet associés à un champ. |

> _(iPhone/iPad)_ Les propriétés d'un champ Action Bar ne sont pas modifiables par programmation.
