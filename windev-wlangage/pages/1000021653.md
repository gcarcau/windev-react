# <Cellule>.FermeDialogue (Fonction)

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur)

Masque un champ Cellule précédemment affiché dans la page via la fonction [<Cellule>.AfficheDialogue](1000021652.md).

## Exemple

```wlangage
// Ferme le champ Cellule de question
CELL_Question.FermeDialogue()
```

## Syntaxe

```wlangage
<Champ Cellule>.FermeDialogue()
```

`<Champ Cellule>` *Nom de champ*
> Nom de la cellule qui sera masquée. Cette cellule est superposable et a été affichée par la fonction [<Cellule>.AfficheDialogue](1000021652.md). Si ce n'est pas le cas, la fonction **<Cellule>.FermeDialogue** ne fait rien.

## Remarques

Les navigateurs ne rafraîchissent pas l'affichage au milieu d'un code Javascript : les fonctions [<Cellule>.AfficheDialogue](1000021652.md) et **<Cellule>.FermeDialogue** doivent être utilisées dans des événements/traitements différents. Si ces fonctions sont utilisées dans le même événement/traitement, le champ Cellule n'est pas affiché.

**Composante : WDJS.DLL**
