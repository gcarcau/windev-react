# <Caméra>.Arrête (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Mac Catalyst)

Arrête l'affichage ou la sauvegarde d'une séquence vidéo dans un champ Caméra.
> _(Android, iPhone/iPad)_ Avertissement
A partir de la version 27, cette fonction est obsolète pour les applications Android et iOS. Cette fonction est conservée uniquement pour les champs Caméra créés dans les versions précédentes et ayant l'option "Mode compatible 26" cochée (onglet "Général" de la fenêtre de description du champ).

## Exemple

```wlangage
// Arrête l'affichage de la séquence vidéo actuellement retransmise
// dans le champ Caméra "CAM_Cuisine"
ResArrêt = CAM_Cuisine.Arrête(viArrêteAffichage)
```

## Syntaxe

```wlangage
<Résultat> = <Champ Caméra>.Arrête([<Action à arrêter>])
```

`<Résultat>` *Booléen*
> - Vrai si l'affichage et/ou la sauvegarde dans le champ Caméra est correctement arrêtée,
> - Faux en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Caméra>` *Nom de champ*
> Nom du champ Caméra à manipuler.
`<Action à arrêter>` *Constante optionnelle de type entier*
> Type d'action à arrêter :
>
> | *viArrêteAffichage* | Arrête l'affichage de la vidéo. Le champ Caméra spécifié devient vide. |
> | --- | --- |
> | *viArrêteCapture* | Arrête l'enregistrement de la séquence vidéo. Le fichier généré est disponible. |
> | *viArrêteTout* (Valeur par défaut) | Arrête l'affichage et l'enregistrement de la séquence vidéo. Le fichier généré est disponible. Le champ Caméra spécifié devient vide. |

## Remarques

### Conditions d'utilisation

- Pour utiliser cette fonction, une "caméra" doit être connectée au poste en cours.
- Cette fonction nécessite un matériel équipé d'une caméra. Elle peut également être utilisée lors d'une exécution dans l'émulateur Android.
- Cette fonction nécessite un matériel équipé d'une caméra.

### Cas particuliers

- Pour sauvegarder la vidéo actuellement retransmise par une "web caméra", utilisez la fonction [<Caméra>.Capture](1000022382.md).
- Pour afficher dans un champ Caméra la séquence vidéo actuellement retransmise par une "web caméra", utilisez la fonction [<Caméra>.Affiche](1000022380.md).

> _(Android)_ Permissions requisesL'utilisation de cette fonction entraîne la modification des permissions requises par l'application.Permission requise : CAMERA.Cette permission permet aux applications d'accéder à la caméra.
