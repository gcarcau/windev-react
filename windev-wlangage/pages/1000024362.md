# <Variable Image>.PixelCouleur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Identifie la couleur d'un pixel contenu dans une variable de type [Image](1000019650.md).
> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Dessiner en WINDEV, WEBDEV et WINDEV Mobile.

## Exemple

```wlangage
MonImage est une Image = "Test.bmp"
// Identification de la couleur du pixel (15, 25)
// sur la variable MonImage
ResCouleur = MonImage.PixelCouleur(15, 25)
IMG_MonDessin = MonImage
```

## Syntaxe

```wlangage
<Résultat> = <Variable Image>.PixelCouleur(<Abscisse> , <Ordonnée>)
```

`<Résultat>` *Entier*
> Couleur du pixel spécifié sous la forme [RVB](3029012.md).
> Attention : la valeur retournée peut être différente suivant la configuration de l'affichage (résolution, ...).
`<Variable Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) à manipuler.
`<Abscisse>` *Entier*
> Position horizontale du pixel à manipuler.
`<Ordonnée>` *Entier*
> Position verticale du pixel à manipuler.

## Remarques

### Coordonnées
Les coordonnées sont indiquées en pixels par rapport au coin haut gauche de l'image (coordonnées (0,0)).

### Comment récupérer les composantes de la couleur ?
Pour récupérer les composantes de la couleur renvoyée par la fonction **<Variable Image>.PixelCouleur** :

- Pour obtenir la composante rouge, utilisez la fonction [RVBRouge](3029050.md) (ou effectuez une division modulo 256 de <Résultat>),
- Pour obtenir la composante verte, utilisez la fonction [RVBVert](3029051.md) (ou effectuez une division modulo 256 de <Résultat>/256),
- Pour récupérer la composante bleue, utilisez la fonction [RVBBleu](3029049.md) (ou effectuez une division modulo 256 de <Résultat>/256/256).
