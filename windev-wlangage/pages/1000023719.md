# <Tableur>.Charge (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Charge un fichier dans un champ Tableur présent dans une fenêtre. Les formats supportés sont :

- XLSX (classeur Excel),
- XLSM (classeur Excel prenant en charge les macros),
- XLTX (modèle Excel),
- XLTM (modèle Excel prenant en charge les macros),
- Nouveauté 2025
  CSV (fichier csv).

## Exemple

```wlangage
// Charge la seconde feuille du fichier XLSX
TBLR_Tableur.Charge("Classeur1.XLSX", 2)
```

## Syntaxe

```wlangage
<Résultat> = <Champ Tableur>.Charge(<Fichier à charger> [, <Numéro de feuille> [, <Option> [, <Mot de passe>]]])
```

`<Résultat>` *Booléen*
> - Vrai si le fichier a été chargé dans le champ Tableur,
> - Faux dans le cas contraire.
`<Champ Tableur>` *Nom de champ*
> Nom du champ Tableur manipulé.
`<Fichier à charger>` *Chaîne de caractères*
> Nom et chemin complet du fichier à charger. Les formats supportés sont :
>
> - XLSX (classeur Excel),
> - XLSM (classeur Excel prenant en charge les macros),
> - XLTX (modèle Excel),
> - XLTM (modèle Excel prenant en charge les macros),
> - Nouveauté 2025
>   CSV (fichier csv).
>
> Attention : Il n'est pas possible de charger un fichier XLSX contenant plus de 2 millions de cellules.
`<Numéro de feuille>` *Entier optionnel*
> - Numéro de la feuille à charger.
> - -1 pour utiliser le comportement par défaut :
>   - Si le champ Tableur est en mode multifeuille, toutes les feuilles de calcul seront chargées.
>   - Si le champ Tableur n'est pas en mode multifeuille, seule la première feuille de calcul sera chargée.
`<Option>` *Constante de type Entier*
> Mode d'ouverture du fichier au format XLSX à charger :
>
> | *tblrChargeDéfaut* (Valeur par défaut) | Le fichier XLSX chargé dans le champ Tableur est ouvert en écriture.  Dans ce mode, pour ouvrir le fichier ".xlxs" avec une autre application, il est nécessaire de le fermer avec la fonction [<Tableur>.Ferme](1000023722.md). |
> | --- | --- |
> | *tblrChargeDétaché* | Le fichier XLSX chargé dans le champ Tableur est chargé en mémoire uniquement. Le fichier ".xlxs" peut être ouvert avec une autre application.  Pour sauvegarder les données modifiées, il est nécessaire d'utiliser la fonction [<Tableur>.Sauve](1000023734.md) avec la constante *tblrEcrasementAutorisé*. Dans ce cas, les données modifiées par une autre application seront écrasées. |
> | *tblrChargeGardeMdp* | Le mot de passe du fichier XLSX chargé dans le champ Tableur est conservé en mémoire.  Lors de la sauvegarde du fichier ("Enregistrer sous" ou [<Tableur>.Sauve](1000023734.md)), il ne sera pas nécessaire de préciser à nouveau le mot de passe du fichier. Le mot de passe mémorisé sera conservé. |
`<Mot de passe>` *Chaîne de caractères optionnelle ou Chaîne secrète*
> Mot de passe d'ouverture du fichier XLSX à manipuler (si le fichier est protégé par un mot de passe d'ouverture).
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).

## Remarques

- Le contenu du fichier est chargé dans le champ Tableur.
- L'ancien contenu est supprimé.
- Les formules sont calculées.
- Certaines fonctionnalités d'Excel ne sont pas supportées.
- La taille des fichiers XLSX pouvant être chargés est limitée à 2 millions de cellules.
- Cette fonction est utilisable uniquement sur un champ Tableur présent dans une fenêtre.
- La fonction **<Tableur>.Charge** met à jour la propriété [CheminFichier](1000023104.md) du champ Tableur en associant le nom du fichier chargé au champ Tableur.
