# DDESujet (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Identifie le sujet de la conversation associée à une connexion DDE.

## Exemple

```wlangage
// Ouverture d'une connexion DDE
NumConnexion = DDEConnecte(NomServeur, "MonSujet")

...

// Sujet de la conversation ?
Sujet = DDESujet(NumConnexion)
```

## Syntaxe

```wlangage
<Résultat> = DDESujet([<Identifiant connexion>])
```

`<Résultat>` *Chaîne de caractères*
> Sujet de la conversation.
`<Identifiant connexion>` *Entier optionnel*
> Identifiant de la connexion renvoyé par la fonction [DDEConnecte](3028015.md). Si ce paramètre n'est pas précisé, **DDESujet** utilise la dernière connexion manipulée.

**Composante : wd300std.dll**
