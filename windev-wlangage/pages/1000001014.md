# Erreur 1030 : L'accès à la classe de base est restreint par un héritage privé

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

## Cause

Vous tentez d'accéder à une classe de base d'un héritage. Cette classe a été dérivée par un héritage privé : il n'est pas possible d'accéder à cette classe depuis un code extérieur à la classe ou depuis un code d'une de ses classes dérivées.

## Correction

Deux possibilités :

- Accédez à la classe de base par une méthode de la classe dérivée.
- Utilisez un héritage public : la classe sera accessible aussi bien par un code extérieur à la classe que par un code de ses classes dérivées.
