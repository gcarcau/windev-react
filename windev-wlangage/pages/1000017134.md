# BTOuvrePropriétésPériphérique (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Ouvre la fenêtre des propriétés d'un périphérique Bluetooth.

## Exemple

```wlangage
nNuméroPériph est un entier
// Les périphériques sont stockés dans un champ Table
nNuméroPériph = TABLE_Périph.COL_ID[TABLE_Périph]
// Ouvre la fenêtre des propriétés du périphérique sélectionné
BTOuvrePropriétésPériphérique(nNuméroPériph)
```

## Syntaxe

```wlangage
<Résultat> = BTOuvrePropriétésPériphérique(<Identifiant du périphérique>)
```

`<Résultat>` *Booléen*
> - Vrai si la fenêtre des propriétés du périphérique a été affichée,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de renseignements sur le problème rencontré.
`<Identifiant du périphérique>` *Entier*
> Identifiant du périphérique Bluetooth à manipuler. Cet identifiant est retourné par la fonction [BTListePériphérique](1000017132.md) ou par la fonction [BTSélecteurPériphérique](1000017135.md).

## Remarques

Seule la pile bluetooth Microsoft est supportée par cette fonction. Pour connaître la pile utilisée, utilisez la fonction [BTPile](1000017229.md).
Pour plus de détails sur les clés supportées, consultez [Quelles piles utiliser ?](1000017231.md)
