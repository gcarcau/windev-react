# PageAdresse (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

Permet d'obtenir l'adresse Internet d'une page.

- Renvoie l'adresse d'une page WEBDEV.
- Renvoie l'adresse de la page en cours.

## Exemple

> _(WEBDEV - Code Serveur, Ajax)_ Trace(PageAdresse(PAGE_COORDONNEE))
// Affiche par exemple :
// /WD300AWP/WD300AWP.EXE/CTX_2420-0-FCFOVjoyom/COORDONNEES/SYNC_12564

> _(WEBDEV - Code Serveur, Ajax)_ Trace(PageAdresse(PAGE_COORDONNEE, paComplète))
// Affiche par exemple :
// http://www.pcsoft.fr/WD300AWP/WD300AWP.EXE/CTX_2420-0-FCFOVjoyom/COORDONNEES/SYNC_12564

> _(WEBDEV - Code Navigateur)_ Trace(PageAdresse())
// Affiche par exemple :
// /WD300AWP/WD300AWP.EXE/CTX_358-0-NhDrnmZtoc/Page1/SYNC_16069977

> _(WEBDEV - Code Serveur, Ajax)_ // Génération d'un lien qui exécute le code de
// clic d'un bouton dont le nom est une variable
NomBouton est une chaîne = "BTN_BOUTON1"
HTM_ChampHTML.Valeur = "<A HREF=" + PageAdresse() + ...
 "?" + NomBouton + ">Cliquez-moi</A>"

> _(WEBDEV - Code Serveur, Ajax)_ // Code d'initialisation d'un lien permettant
// d'ouvrir une page en liaison sécurisée
ContexteOuvre(PAGE_PageSecu)
MoiMême.Valeur = PageAdresse(PAGE_PageSecu, paSécurisée) + "?WD_ACTION_=REFRESH")

## Syntaxe

> _(WEBDEV - Code Serveur, PHP, Ajax)_ Récupérer l'adresse d'une page Masquer les détails
<Résultat> = PageAdresse([<Page> [, <Option>]])

 <Résultat> : Chaîne de caractères AnsiAdresse de la page spécifiée ou chaîne vide ("") si :la page n'existe pas dans le projetle contexte de la page n'est pas ouvert (fonction ContexteOuvre). <Page> : Nom de pageNom de la page dont l'adresse doit être renvoyée.Si ce paramètre n'est pas précisé ou correspond à une chaîne vide (""), le nom de la page correspond au nom de la page en cours. <Option> : Constante optionnelleType d'adresse à renvoyer :paComplèteAdresse complète de la page (adresse en HTTP). paComplèteAutoAdresse complète de la page avec le protocole utilisé pour son affichage (HTTP ou HTTPS). paRelative(Valeur par défaut)Adresse relative au domaine en cours.paSécuriséeAdresse complète de la page, sécurisée par SSL (adresse en HTTPS).

> _(WEBDEV - Code Navigateur)_ Récupérer l'adresse de la page en cours Masquer les détails
<Résultat> = PageAdresse()

 <Résultat> : Chaîne de caractères UnicodeAdresse complète de la page en cours.
