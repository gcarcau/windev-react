# <Graphe>.CPAjouteDonnée (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

Ajoute une donnée à un graphe circulaire de progrès.

## Exemple

```wlangage
GRF_Graphe1.CPAjouteDonnée("Montpellier", 10)
GRF_Graphe1.CPAjouteDonnée("France", 50)
GRF_Graphe1.CPAjouteDonnée("Europe", 80)
```

## Syntaxe

```wlangage
<Champ Graphe>.CPAjouteDonnée(<Catégorie> , <Valeur>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe manipulé (présent dans l'éditeur de fenêtres ou d'états).
`<Catégorie>` *Chaîne de caractères*
> Nom de la catégorie associée à la donnée.
`<Valeur>` *Entier ou réel*
> Valeur à ajouter.
> Par défaut, la valeur est considérée en pourcentage. Si ce n'est pas le cas, il est possible de donner la valeur "maximale" avec la fonction [<Graphe>.CPValeurMaximale](1410088094.md) (le pourcentage sera automatiquement calculé à partir de cette valeur).

## Remarques

### Ajout de données dans un graphe
La fonction [<Graphe>.AjouteDonnée](1000023533.md) permet d'ajouter des données dans un graphe (secteur, histogramme, ...).
Selon le type de graphe, des fonctions spécifiques permettent également d'ajouter des données :

- Pour les graphes boursiers, il est conseillé d'utiliser la fonction [<Graphe>.BourseAjouteDonnée](1000023565.md).
- Pour les graphes Heatmap, il est conseillé d'utiliser la fonction [<Graphe>.HMAjouteDonnée](1000024079.md).
- Pour les graphes de type Nuage de points, il est conseillé d'utiliser la fonction [<Graphe>.NuageAjouteDonnéeXY](1000024105.md).
- Pour les graphes Secteur Multiniveau, il est conseillé d'utiliser la fonction [<Graphe>.SMNAjouteDonnée](1000024132.md).
- Pour les graphes de type Surface, il est conseillé d'utiliser la fonction [<Graphe>.SurfaceAjouteDonnée](1000024143.md).

Rappel : Pour ajouter une valeur à une donnée d'un graphe, utilisez la fonction [<Graphe>.IncrémenteDonnée](1000024086.md).
