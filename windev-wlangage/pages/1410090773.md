# BitcoinCoreEspaceDisqueUtilisé (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Indique la taille de la blockchain sur disque.
Nouveauté 2025
**Attention** : Cette fonction est disponible uniquement à partir de la version 2025 Update 2.

## Exemple

```wlangage
// Récupération de l'espace disque utilisé par la blockchain
n est un entier
n = BitcoinCoreEspaceDisqueUtilisé()
SI ErreurDétectée ALORS
	Erreur()
	RETOUR
FIN
Trace("Espace disque utilisé par la blockchain : " + n
```

## Syntaxe

```wlangage
<Résultat> = BitcoinCoreEspaceDisqueUtilisé()
```

`<Résultat>` *Entier*
> Taille de la blockchain sur disque (exprimée en octets).
