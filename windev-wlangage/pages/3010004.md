# Constantes de cryptage/compression

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad) · **Autres** (Procédures stockées)

| Constante | Détail | Utilisée dans les fonctions |
| --- | --- | --- |
| **compresseAucun** | Aucune compression n'est effectuée. | [Compresse](3024012.md),  [Crypte](3024014.md),  [Décrypte](3024035.md) |
| **compresseChaîneCourte** | La chaîne sera compressée à l'aide d'un algorithme optimisé pour les chaînes de caractères de petite taille. | [Compresse](3024012.md),  [Crypte](3024014.md),  [Décrypte](3024035.md) |
| **compresseGZIP** | La chaîne sera compressée avec l'algorithme GZIP. | [Compresse](3024012.md) |
| **compresseLZW** | La chaîne sera compressée avant d'être cryptée. | [Compresse](3024012.md),  [Crypte](3024014.md),  [Décrypte](3024035.md) |
| **crypte3DES** | Algorithme de cryptage utilisé : Triple Data Encryption Standard.  - Taille de la clé : 192 bits. - Taille des blocs : 64 bits. - Taille du vecteur d'initialisation (IV) : 64 bits. | [CrypteStandard](1000021293.md), [DécrypteStandard](1000021294.md) |
| **crypteAES128** | Algorithme de cryptage utilisé : Advanced Encryption Standard.  - Taille de la clé : 128 bits. - Taille des blocs : 128 bits. - Taille du vecteur d'initialisation (IV) : 128 bits. | [CrypteStandard](1000021293.md), [DécrypteStandard](1000021294.md) |
| Nouveauté 2025 **crypteAES192** | Algorithme de cryptage utilisé : Advanced Encryption Standard.  - Taille de la clé : 192 bits. - Taille des blocs : 128 bits. - Taille du vecteur d'initialisation (IV) : 128 bits. | [CrypteStandard](1000021293.md), [DécrypteStandard](1000021294.md) |
| **crypteAES256** | Algorithme de cryptage utilisé : Advanced Encryption Standard.   - Taille de la clé : 256 bits. - Taille des blocs : 128 bits. - Taille du vecteur d'initialisation (IV) : 128 bits. | [CrypteStandard](1000021293.md), [DécrypteStandard](1000021294.md) |
| **crypteAnsi** | Le cryptage réalisé est identique à celui réalisé dans une application WINDEV ou WEBDEV. Utile pour les applications cryptant en WINDEV Mobile et décryptant en WINDEV par exemple. | [Crypte](3024014.md), [Décrypte](3024035.md) |
| **crypteAucun** | Aucun cryptage effectué | [Crypte](3024014.md), [Décrypte](3024035.md), [fCrypte](3036013.md), [fDécrypte](3036018.md) |
| **crypteCBC** | Mode de traitement des blocs par l'algorithme de cryptage : Cipher Block Chaining - Enchaînement des blocs | [CrypteStandard](1000021293.md), [DécrypteStandard](1000021294.md) |
| **crypteCFB** | Mode de traitement des blocs par l'algorithme de cryptage : Cipher Feedback - Chiffrement à rétroaction. | [CrypteStandard](1000021293.md), [DécrypteStandard](1000021294.md) |
| **crypteCTR** | Mode de traitement des blocs par l'algorithme de cryptage : Cipher Counter - Chiffrement basé sur un compteur. | [CrypteStandard](1000021293.md), [DécrypteStandard](1000021294.md) |
| **crypteDES** | Algorithme de cryptage utilisé : Data Encryption Standard.  - Taille de la clé : 64 bits. - Taille des blocs : 64 bits. - Taille du vecteur d'initialisation (IV) : 64 bits.   Attention : cet algorithme est actuellement déprécié. | [CrypteStandard](1000021293.md), [DécrypteStandard](1000021294.md) |
| **crypteECB** | Mode de traitement des blocs par l'algorithme de cryptage : Electronic Code Book - Dictionnaire de codes. Ce mode d'opération est déconseillé et ne devrait être utilisé que pour des raisons de compatibilité. | [CrypteStandard](1000021293.md), [DécrypteStandard](1000021294.md) |
| **cryptePaddingOAEP** | Mode de remplissage des données cryptées pour être compatibles avec la taille requise par les algorithmes de cryptage par bloc : Les données sont complétées par des octets dont la valeur correspond au nombre total d'octets ajoutés pour atteindre la taille requise. | [CrypteAsymétrique](1000024049.md), [DécrypteAsymétrique](1000024050.md) |
| **cryptePaddingPKCS1** | Mode de remplissage des données cryptées pour être compatibles avec la taille requise par les algorithmes de cryptage par bloc : Les données sont complétées par des octets dont la valeur correspond au nombre total d'octets ajoutés pour atteindre la taille requise. | [CrypteAsymétrique](1000024049.md), [DécrypteAsymétrique](1000024050.md) |
| **cryptePaddingPKCS** | Mode de remplissage des données cryptées pour être compatibles avec la taille requise par les algorithmes de cryptage par bloc : Les données sont complétées par des octets dont la valeur correspond au nombre total d'octets ajoutés pour atteindre la taille requise. | [CrypteStandard](1000021293.md), [DécrypteStandard](1000021294.md) |
| **cryptePaddingZéro** | Mode de remplissage des données cryptées pour être compatibles avec la taille requise par les algorithmes de cryptage par bloc : Les données sont complétées par des zéros binaires jusqu'à obtenir la taille requise. | [CrypteStandard](1000021293.md), [DécrypteStandard](1000021294.md) |
| **crypteRapide** | Cryptage rapide (algorithme sur 128 bits) | [Crypte](3024014.md), [Décrypte](3024035.md), [fCrypte](3036013.md), [fDécrypte](3036018.md) |
| **crypteRC516** | Priorité donnée à la sécurité du cryptage (algorithme RC5 sur 16 rondes). | [Crypte](3024014.md), [Décrypte](3024035.md), [fCrypte](3036013.md), [fDécrypte](3036018.md) |
| **crypteSécurisé** | Cryptage sécurisé (algorithme RC5 sur 128 bits). | [Crypte](3024014.md), [Décrypte](3024035.md), [fCrypte](3036013.md), [fDécrypte](3036018.md) |
| **encodeAucun** | Format de la chaîne ou du fichier crypté : Binaire. | [Crypte](3024014.md), [Décrypte](3024035.md), [fCrypte](3036013.md), [fDécrypte](3036018.md) |
| **encodeBASE64** | Format de la chaîne ou du fichier crypté : BASE 64. Le texte encodé comporte uniquement des caractères imprimables. | [Crypte](3024014.md), [Décrypte](3024035.md),  [fCrypte](3036013.md), [fDécrypte](3036018.md), [Encode](1000022258.md), [Décode](1000022259.md) |
| **encodeBASE64SansRC** | Format BASE 64 (respecte la norme RFC 4648) sans les RC (Retour Chariot). Le texte encodé comporte uniquement des caractères imprimables. | [Encode](1000022258.md), [Décode](1000022259.md) |
| **encodeBASE64URL** | Format de la chaîne ou du fichier crypté : BASE 64 URL. Le texte encodé comporte uniquement des caractères imprimables. | [Encode](1000022258.md), [Décode](1000022259.md) |
| **encodeBASE85** | Format de la chaîne ou du fichier crypté : BASE 85. Le texte encodé comporte uniquement des caractères imprimables. | [Encode](1000022258.md), [Décode](1000022259.md) |
| **encodePCS** | Format de la chaîne ou du fichier crypté : ASCII. Le texte encodé comporte uniquement des caractères imprimables. | [Crypte](3024014.md), [Décrypte](3024035.md),  [fCrypte](3036013.md), [fDécrypte](3036018.md), [Encode](1000022258.md), [Décode](1000022259.md) |
| **encodeURLDepuisAnsi** | Format de la chaîne ou du fichier crypté : URL. Le texte encodé comporte uniquement des caractères autorisés dans une URL. Le texte à encoder est une chaîne ANSI. | [Encode](1000022258.md) [URLEncode](3024040.md) |
| **encodeURLDepuisUnicode** | Format de la chaîne ou du fichier crypté : URL. Le texte encodé comporte uniquement des caractères autorisés dans une URL. Le texte à encoder est une chaîne Unicode. | [Encode](1000022258.md) [URLEncode](3024040.md) |
| **encodeURLDepuisUTF8** | Format de la chaîne ou du fichier crypté : URL. Le texte encodé comporte uniquement des caractères autorisés dans une URL. Le texte à encoder est une chaîne UTF-8. | [Encode](1000022258.md) [URLEncode](3024040.md) |
| **encodeURLParamètre** | Format de la chaîne ou du fichier crypté : URL. Les caractères réservés d'une URL sont encodés pour pouvoir passer une URL en paramètre d'une autre URL. Attention : Il faut auparavant avoir encodé l'URL passée en paramètre avec une des constantes *encodeURLDepuisAnsi*, *encodeURLDepuisUnicode* ou *encodeURLDepuisUTF8*. | [Encode](1000022258.md) [URLEncode](3024040.md) |

| **encodeURLVersUTF8** | Format de la chaîne ou du fichier crypté : URL. Le texte encodé comporte uniquement des caractères autorisés dans une URL. Le texte décodé est une chaîne UTF-8. | [Décode](1000022259.md) [URLDécode](3024041.md) |
| **encodeUUEncode** | Format de la chaîne ou du fichier crypté : UUEncode. Le texte encodé comporte uniquement des caractères imprimables. | [Crypte](3024014.md), [Décrypte](3024035.md),  [fCrypte](3036013.md), [fDécrypte](3036018.md), [Encode](1000022258.md), [Décode](1000022259.md) |
