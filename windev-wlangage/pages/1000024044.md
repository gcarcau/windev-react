# <Saisie>.InsèreJeton (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Insère un jeton dans un champ de saisie de type "Jetons de texte".

## Exemple

```wlangage
// Clic sur [Insérer le robot de test]
SAI_Destinataire.InsèreJeton(1, "ROBOT", "robotmail@adresse.test.fr")
```

```wlangage
// Syntaxe utilisant le type Jeton
MonJeton est un Jeton
MonJeton.ValeurAffichée = "ROBOT"
MonJeton.ValeurMémorisée = "robotmail@adresse.test.fr"
SAI_Destinataire.InsèreJeton(1, MonJeton)
```

## Syntaxe

#### Insérer un jeton directement

```wlangage
<Résultat> = <Champ de saisie>.InsèreJeton(<Position> , <Valeur> [, <Libellé>])
```

`<Résultat>` *Entier*
> - Indice effectif du jeton inséré,
> - 0 en cas d'erreur :
>   - Si le champ de saisie n'est pas un champ de type "Jetons de texte" (propriété [JetonActif](1000023782.md) vaut Faux).
>   - Si un doublon a été détecté et si la propriété [JetonAutoriseDoublon](1000023784.md) vaut Faux.
`<Champ de saisie>` *Nom de champ*
> Nom du champ de saisie de type "Jetons de texte".
`<Position>` *Entier*
> Indice d'insertion du jeton.
>
> - Si <Position> est supérieur au nombre de jetons dans le champ, le jeton est ajouté à la fin des jetons existants (équivalent à la fonction [<Saisie>.AjouteJeton](1000024043.md)).
> - Si <Position> vaut 0, le jeton est inséré en première position.
> - Si <Position> vaut -1, <Résultat> vaut 0.
`<Valeur>` *Chaîne de caractères*
> Valeur du jeton.
`<Libellé>` *Chaîne de caractères optionnelle*
> Libellé du jeton. Si cette valeur n'est pas précisée, elle correspondra à la valeur du jeton.

#### Insérer un jeton via le type Jeton

```wlangage
<Résultat> = <Champ de saisie>.InsèreJeton(<Position> , <Jeton>)
```

`<Résultat>` *Entier*
> - Indice effectif du jeton inséré,
> - 0 en cas d'erreur :
>   - Si le champ de saisie n'est pas un champ de type "Jetons de texte" (propriété [JetonActif](1000023782.md) vaut Faux).
>   - Si un doublon a été détecté et si la propriété [JetonAutoriseDoublon](1000023784.md) vaut Faux.
`<Champ de saisie>` *Nom de champ*
> Nom du champ de saisie de type "Jetons de texte".
`<Position>` *Entier*
> Indice d'insertion du jeton.
>
> - Si <Position> est supérieur au nombre de jetons dans le champ, le jeton est ajouté à la fin des jetons existants (équivalent à la fonction [<Saisie>.AjouteJeton](1000024043.md)).
> - Si <Position> vaut 0, le jeton est inséré en première position.
> - Si <Position> vaut -1, <Résultat> vaut 0.
`<Jeton>` *Variable de type Jeton*
> Nom de la variable de type [Jeton](1000023942.md) décrivant le jeton à ajouter.

## Remarques

- Pour ajouter un jeton à la position du curseur de saisie, utilisez la fonction [<Saisie>.AjouteJeton](1000024043.md).
- La propriété [ValeurMémorisée](2510127.md) du champ de saisie renvoie les valeurs mémorisées des jetons du champ séparées par le caractère <RC> (Retour Chariot).
