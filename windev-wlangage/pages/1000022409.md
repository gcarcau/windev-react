# mongoConnexion (Type de variable)

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows, Linux)

Le type **mongoConnexion** permet de définir toutes les caractéristiques avancées d'une connexion à un serveur MongoDB. Les caractéristiques de cette connexion peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
cnxMDB est un mongoConnexion
cnxMDB = MongoCrée("mongodb://db1.exemple.net")
POUR TOUT MaBase DE cnxMDB.BaseDeDonnées
	Trace(MaBase.Nom)
FIN
```

```wlangage
cnxMDB est un mongoConnexion("mongodb://db1.exemple.net")
POUR TOUT MaBase DE cnxMDB.BaseDeDonnées
	Trace(MaBase.Nom)
FIN
```

## Déclaration

```wlangage
MaVariable est un mongoConnexion(<Chaîne de connexion>)
```

`<Chaîne de connexion>` *Chaîne de caractères*
> Chaîne de connexion au serveur ou du cluster hébergeant la base MongoDB. Pour plus de détails, consultez la documentation de MongoDB.

## Propriétés

### Propriétés spécifiques à la description des variables de type mongoConnexion
Les propriétés suivantes peuvent être utilisées pour manipuler une connexion MongoDB:

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| BaseDeDonnées | Tableau de [mongoBase](1000022410.md) | Tableau associatif contenant les bases créées sur le serveur MongoDB. |
