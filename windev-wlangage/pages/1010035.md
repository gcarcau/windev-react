# Propriétés associées aux cases des barres de message

> **Disponible :** **WINDEV** (Windows)

Les propriétés associées aux cases des barres de message sont les suivantes :

| [CadrageHorizontal](2510023.md) | La propriété **CadrageHorizontal** permet de connaître et de modifier le cadrage horizontal d'un champ. |
| --- | --- |
| [Couleur](2510071.md) | La propriété **Couleur** permet de connaître ou modifier la couleur de la police de :  - une variable de type Police. - un texte d'un champ Libellé ou calculé d'un état. - un texte d'un champ d'une fenêtre. - un texte d'un champ d'une page. |
| [CouleurFond](2510022.md) | La propriété **CouleurFond** permet de gérer la couleur de fond d'un champ, d'une fenêtre, d'une page ou d'un bloc d'un état. |
| [FenEditionAutorisée](1000021850.md) | La propriété **FenEditionAutorisée** permet de connaître et de modifier les manipulations autorisées sur un champ lorsque la fenêtre passe en mode "Modification de l'UI par l'utilisateur final". |
| [Image](2510034.md) | La propriété **Image** permet de connaître et de modifier l'image de fond d'un champ ou d'un bloc. |
| [Largeur](2510059.md) | La propriété **Largeur** permet de connaître et modifier la largeur :  - d'un champ ou d'un bloc dans un état. - d'un champ (présent dans une fenêtre), d'une fenêtre, d'une colonne de table ou d'une colonne de liste (y compris liste image). - d'un champ (présent dans une page), d'une colonne de table ou d'une liste. Le champ peut être superposable ou non. |
| [LargeurInitiale](2510067.md) | La propriété **LargeurInitiale** permet de :  - Connaître la largeur de création d'un champ ou d'une fenêtre. - Modifier la largeur de base utilisée pour l'ancrage des champs "en largeur". - Connaître la largeur de création d'un champ d'un état. |
| [Libellé](2510053.md) | **Dans une base de données**, la propriété **Libellé** permet de :  - Connaître le libellé associé à une rubrique d'un fichier de données. - Connaître le libellé associé à un fichier de données. - Connaître et modifier le libellé d'une connexion.   **Dans un état**, la propriété **Libellé** permet de :   - Connaître le texte d'un champ Libellé ou Lien. - Modifier le texte d'un champ Libellé ou Lien.   **Dans une fenêtre ou une page**, la propriété **Libellé** permet également de :   - Connaître et modifier le libellé d'un champ présent dans une fenêtre ou une page. - Connaître et modifier le libellé d'une option de menu. - Connaître et modifier le titre d'une fenêtre ou d'une page. - Connaître le contenu d'un champ chemin de navigation. |
| [Nom](2510082.md) | La propriété **Nom** permet de connaître :  - le nom de la police associée à une variable de type Police. - le nom d'un champ, d'un état ou d'un bloc d'un état. - le nom d'un champ, d'un groupe de champs ou d'une fenêtre. - le nom d'un champ, d'un groupe de champs ou d'une page. |
| [NomComplet](2514005.md) | La propriété **NomComplet** permet de connaître le nom complet :  - d'un champ. - d'une fenêtre. - d'une option de menu. - d'une colonne de table. |
| [NuméroAide](2510141.md) | La propriété **NuméroAide** permet de connaître et de modifier le numéro d'aide associé au champ. |
| [Police](2510095.md) | La propriété **Police** permet de :  - Connaître l'identifiant de la police utilisée dans un champ d'un état, d'une page ou d'une fenêtre. - Modifier la police utilisée dans un champ d'un état, d'une page ou d'une fenêtre. |
| [PoliceAlphabet](2510089.md) | La propriété **PoliceAlphabet** permet de :  - Connaître l'alphabet actuellement utilisé par les polices écran d'un champ. - Modifier l'alphabet utilisé par les polices écran d'un champ. |
| [PoliceBarrée](2510091.md) | La propriété **PoliceBarrée** permet de :  - Savoir si le texte affiché est barré ou non. - Barrer ou non le texte affiché dans un champ. |
| [PoliceCondensée](2510096.md) | La propriété **PoliceCondensée** permet de :  - Savoir si les caractères du texte affiché sont condensés ou non. - Condenser ou non les caractères du texte affiché. |
| [PoliceEtendue](2510104.md) | La propriété **PoliceEtendue** permet de :  - Savoir si les caractères du texte affiché sont étendus ou non. - Étendre ou non les caractères du texte affiché. |
| [PoliceGras](2510103.md) | La propriété **PoliceGras** permet de :  - Savoir si le texte affiché est en gras ou non. - Modifier la graisse du texte. |
| [PoliceItalique](2510102.md) | La propriété **PoliceItalique** permet de :  - Savoir si le texte affiché est en italique ou non. - Modifier la mise en forme italique du texte. |
| [PoliceLarge](2510101.md) | La propriété **PoliceLarge** permet de :  - Savoir si les caractères du texte affiché sont élargis ou non. - Élargir ou non les caractères du texte affiché. |
| [PoliceNom](2510100.md) | La propriété **PoliceNom** permet de :  - Connaître la police utilisée dans un champ. - Modifier la police utilisée dans un champ. |
| [PoliceSoulignée](2510099.md) | La propriété **PoliceSoulignée** permet de :  - Savoir si le texte affiché est souligné ou non. - Souligner ou non le texte. |
| [PoliceTaille](2510072.md) | La propriété **PoliceTaille** permet de :  - Connaître la taille de la police utilisée dans un champ. - Modifier la taille de la police utilisée dans un champ. |
| [TauxAncrageLargeur](2510120.md) | La propriété **TauxAncrageLargeur** permet de :  - Connaître le taux d'ancrage en agrandissement d'un champ (ou d'une colonne de table) sur l'axe horizontal. - Modifier le taux d'ancrage en agrandissement d'un champ (ou d'une colonne de table) sur l'axe horizontal. |
| [Type](2510131.md) | La propriété **Type** permet de connaître :  - le type d'un élément décrit par programmation (description de rubrique ou de fichier) ou non (fichier ou rubrique défini sous l'éditeur d'analyses, vue ou requête). - le type d'un objet. - le type de la valeur stockée dans un variant. |
| [Valeur](2510130.md) | La propriété **Valeur** permet de :  - Connaître et modifier la valeur d'un champ d'un état. - Connaître et modifier la valeur d'un champ ou le titre d'une fenêtre. - Connaître l'identifiant d'un flux. - Connaître et modifier la valeur d'un champ ou le titre d'une page. |
| [ValeurInitiale](2510128.md) | La propriété **ValeurInitiale** permet de connaître la valeur initiale d'un champ d'une fenêtre ou d'une page. |
| [Visible](2510138.md) | La propriété **Visible** permet de :  - Savoir si un élément est visible. - Rendre un élément visible ou invisible. |
| [VisibleInitial](2510070.md) | La propriété **VisibleInitial** permet de savoir si :  - un champ était visible lors du premier affichage de la fenêtre ou la page associée. - une fenêtre était visible lors de son premier affichage. |

**Rappel** : La propriété [Message](2510078.md) permet de connaître et de modifier le message d'aide associé à un champ d'une fenêtre.

**Remarques** :

- La propriété [BarreDeMessage](2510007.md) permet de :
  - savoir si la barre de message de la fenêtre en cours est activée.
  - activer la barre de message de la fenêtre en cours.
- Le nom d'une case créée avec la fonction [MessageAjouteCase](3021001.md) doit être entouré d'opérateurs d'indirection pour être manipulé avec les propriétés WLangage.
