# Logiciel Etats et requêtes : Spécificités

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes)

## Présentation

Cette page d'aide présente les différentes spécificités du logiciel "Etats & Requêtes" (c'est-à-dire l'éditeur d'états Utilisateur) :

- Source de données de l'état.
- Fonctions de modification des enregistrements.
- Volets verticaux.
- Gabarit personnalisé d'états.
- Modification d'états présents dans un composant.

**Remarque** : L'icône suivante  (présent dans l'aide en ligne) permet d'indiquer les différences entre l'éditeur d'états Utilisateur et l'éditeur d'états intégré.

## Spécificités

### Source de données de l'état
Sous l'éditeur d'états Utilisateur, il n'est pas possible de créer :

- ***des états sur un vue HFSQL***. Cependant, il est possible de personnaliser des états sur une vue HFSQL créés sous l'éditeur d'états intégré (couleur, polices, taille, etc.).
- ***des états sur un champ Table***. Cependant, il est possible de personnaliser des états sur un champ Table créés sous l'éditeur d'états intégré (couleur, polices, taille, colonne reliée, etc.).
- ***des états sur un champ Agenda ou Planning***. Cependant, il est possible de personnaliser des états sur un champ Agenda ou Planning créés sous l'éditeur d'états intégré (couleur, polices, taille, colonne reliée, etc.).
- ***des états sur une source de données programmée***.

**Remarque** : Les fichiers de données et les rubriques pouvant être utilisés dans un état sur un fichier de données sont définis sous l'éditeur d'analyses de WINDEV. Pour plus de détails sur la préparation nécessaire à l'utilisation d'une application WINDEV avec l'éditeur d'états Utilisateur, consultez [Diffuser le logiciel Etats & Requêtes](3088002.md).

Pour plus de détails sur les différentes sources de données d'un état, consultez [Sources de données d'un état](1011055.md).

### Fonctions de modification des enregistrements
Sous l'éditeur d'états Utilisateur, l'utilisation des fonctions de modification des enregistrements ([HAjoute](3044147.md), [HModifie](3044042.md), [HSupprime](3044018.md), etc.) est interdite.

### Volets ancrables
Sous l'éditeur d'états Utilisateur, les volets ancrables permettent d'accéder uniquement :

- aux principales fonctionnalités de l'éditeur d'états Utilisateur.
- aux éléments accessibles (états, requêtes, etc.) de votre projet.

Pour plus de détails sur les volets ancrables, consultez [Volets ancrables](2027001.md).

### Gabarit personnalisé d'états
Sous l'éditeur d'états Utilisateur, il n'est pas possible de créer vos propres gabarits d'états.
Pour plus de détails sur les gabarits d'états, consultez [Création d'un gabarit d'état](2016005.md).

### Modification d'états présents dans un composant externe
Il n'est pas possible à l'utilisateur final de modifier un état présent dans un composant externe avec le logiciel "Etats & Requêtes".
Pour plus de détails sur les composants externes, consultez [Composant externe](2014011.md).

### Modification d'états présents dans une bibliothèque externe
Il n'est pas possible à l'utilisateur final de modifier un état présent dans une bibliothèque externe avec le logiciel "Etats & Requêtes".
Pour plus de détails sur les composants, consultez [Bibliothèque](2030022.md).
