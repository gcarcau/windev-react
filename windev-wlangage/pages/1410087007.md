# Manipuler un champ Barre de navigation par programmation

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

## Présentation

Le champ Barre de navigation peut être manipulé directement par programmation. Il suffit d'utiliser directement la variable du champ Barre de navigation dans le code. La variable du champ Barre de navigation correspond au nom du champ Barre de navigation. Le type de la variable est une chaîne de caractères.
Remarque : Les différentes zones du champ Barre de navigation ne peuvent pas être manipulées par programmation indépendamment.

## Manipuler le champ Barre de navigation par programmation

### Dérouler la zone enroulée
La propriété [Enroulé](2513014.md) utilisée en code navigateur sur le champ Barre de navigation permet d'enrouler ou de dérouler la zone centrale de la barre de navigation.
Il est par exemple possible d'utiliser la propriété [Enroulé](2513014.md) dans le code de survol d'un champ.
La propriété [Enroulé](2513014.md) a un effet uniquement si le champ Barre de navigation est en mode compact.

Exemple :

```wlangage
// -- Code de chargement de la page (navigateur) // Variable utile pour masquer le menu déroulé en cas de clic en dehorsgbClicSurBurger est un booléen = Faux // -- Clic sur la page (code navigateur)SI PAS gbClicSurBurger ALORS // On masque le menu NAV_Bandeau.Enroulé = VraiFINgbClicSurBurger = Faux
```
