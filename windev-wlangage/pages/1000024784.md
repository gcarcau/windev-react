# Procédure WLangage appelée par la fonction BTLECaractéristiqueChangementValeur

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Procédure (également appelée "Callback") appelée par la fonction [BTLECaractéristiqueChangementValeur](1000022071.md) lorsqu'une caractéristique change sur l'appareil. Cette procédure peut être une procédure locale, globale ou interne.

## Exemple

```wlangage
caractéristique est un btleCaractéristique
BTLECaractéristiqueChangementValeur(caractéristique, CB_ChangementValeur)
// ===========================
PROCÉDURE CB_ChangementValeur(caractéristique est un btleCaractéristique <utile>, bufValeur est un Buffer)
// Récupération de la valeur et affichage dans un champ Libellé
sBuf est une chaîne ANSI = bufValeur
LIB_ValeurAbonnement = sBuf
```

## Syntaxe

```wlangage
BTLECaractéristiqueChangementValeur_Callback(<Caractéristique> , <Valeur>)
```

`<Caractéristique>` *Variable de type btleCaractéristique*
> Variable de type [btleCaractéristique](1000022060.md) correspondant à la caractéristique du périphérique Bluetooth dont la valeur a changé.
`<Valeur>` *Buffer*
> Nouvelle valeur de la caractéristique.
