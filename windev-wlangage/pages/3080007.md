# xlsNbColonnes (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

|  | **But** Obtenir le nombre de colonnes du fichier XLS.  **Syntaxe (utilisant le type xlsDocument)**  <Résultat = xlsNbColonnes(<Document XLS>)   - <Résultat est un entier, correspondant au nombre de colonnes. - <Document XLS est le nom de la variable de type [xlsDocument](1000017464.md) correspondant au fichier XLS à manipuler.   **Syntaxe (compatibilité version 12)**  <Résultat = xlsNbColonnes(<NumFichier>)   - <Résultat est un entier, correspondant au nombre de colonnes. - <NumFichier est un entier contenant l'identifiant du fichier fourni par xlsOuvre   **Détail**  xlsNbColonnes retourne le nombre de colonnes du fichier XLS. Les colonnes vides ne sont pas prises en compte. Par exemple, dans le cas suivant, la fonction xlsNbColonnes retourne 4 :   \| Nom \| Prénom \| \| Age \| Profession \| \| --- \| --- \| --- \| --- \| --- \| \| Durand \| Paul \| \| 18 \| Etudiant \| \| Dupond \| Jacques \| \| 19 \| Etudiant \| \| Martin \| Jean \| \| 20 \| Etudiant \|  **Notes** Cette fonction suppose que le fichier XLS possède une structure de type base de données, c'est-à-dire qu'à chaque ligne correspond un nombre de colonnes fixe. |  |  |  |
| --- | --- | --- | --- | --- |
|  |  |  |  |  |
| Nom | Prénom |  | Age | Profession |
| Durand | Paul |  | 18 | Etudiant |
| Dupond | Jacques |  | 19 | Etudiant |
| Martin | Jean |  | 20 | Etudiant |
