# Constantes de gestion des ports

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android)

| Constante | Description | Utilisée par la fonction |
| --- | --- | --- |
| **sEveBreak** | Réception d'un événement sur le port : Réception d'un événement "Break line". | [sEvénement](3062014.md), [sFinEvénement](3062008.md) |
| **sEveCaractèreReçu** | Réception d'un événement sur le port : Réception d'un caractère. | [sEvénement](3062014.md), [sFinEvénement](3062008.md) |
| **sEveCTS** | Réception d'un événement sur le port : Changement d'état CTS. | [sEvénement](3062014.md), [sFinEvénement](3062008.md) |
| **sEveDSR** | Réception d'un événement sur le port : Changement d'état DSR. | [sEvénement](3062014.md), [sFinEvénement](3062008.md) |
| **sEveEnvoiTerminé** | Réception d'un événement sur le port : Le buffer de sortie est vide. | [sEvénement](3062014.md), [sFinEvénement](3062008.md) |
| **sEveErreur** | Réception d'un événement sur le port : Détection d'une erreur sur la ligne. _(Java)_ Cette constante n'est pas disponible. | [sEvénement](3062014.md), [sFinEvénement](3062008.md) |
| **sEveErreurImprimante** | Réception d'un événement sur le port : Erreur d'imprimante détectée. _(Java)_ Cette constante n'est pas disponible. | [sEvénement](3062014.md), [sFinEvénement](3062008.md) |
| **sEveFileEntrée80** | Réception d'un événement sur le port : Le buffer d'entrée est plein à 80%. _(Java)_ Cette constante n'est pas disponible. | [sEvénement](3062014.md), [sFinEvénement](3062008.md) |
| **sEveRing** | Réception d'un événement sur le port : Détection du signal "Ring" (sonnerie). | [sEvénement](3062014.md), [sFinEvénement](3062008.md) |
| **sEveRLSD** | Réception d'un événement sur le port : Changement d'état RLSD. _(Java)_ Cette constante n'est pas disponible. | [sEvénement](3062014.md), [sFinEvénement](3062008.md) |
| **sTimeoutDéfaut** | Durée d'attente définie par défaut. _(Java)_ Cette constante n'est pas disponible. | [sOuvre](3062013.md) |
