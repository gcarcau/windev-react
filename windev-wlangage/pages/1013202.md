# Filtres dans les champs Table lié à un fichir de données

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Pour filtrer les enregistrements affichés dans un champ de type Table fichier, WINDEV, WEBDEV et WINDEV Mobile mettent plusieurs moyens à votre disposition :

- Filtre sur la clé de parcours, défini dans la fenêtre de description du champ Table.
- Propriété [Filtre](2510042.md).
- Fonction [HFiltre](3044100.md).
- Evénement optionnel de filtrage des enregistrements d'un champ Table. Pour plus de détails, consultez [Evénements associés aux champs Table](1013189.md).

## Description du champ Table

L'option "Afficher les enregistrements dont la rubrique de parcours commence par" permet de décrire un filtre sur un champ de type Table fichier.
Le filtre a les caractéristiques suivantes :

- Filtre de type "Commence par". La condition est saisie directement sous l'éditeur.
- Filtre uniquement pour l'affichage des champs de type Table fichier.
- Filtre n'influant pas sur le parcours du fichier de données (fonctions [HLitPremier](3044051.md), ...).

## Propriété Filtre

La propriété [Filtre](2510042.md) permet de paramétrer dynamiquement les caractéristiques du filtre appliqué au champ Table.

> _(WINDEV, WINDEV Mobile)_ Le filtre appliqué prend en compte l'option "Utiliser la fonction HFiltre pour parcourir le fichier" définie sous l'éditeur.

## Fonction HFiltre

La fonction [HFiltre](3044100.md) permet de filtrer le fichier de base du champ Table. La fonction [HFiltre](3044100.md) permet d'utiliser tout type de filtre (y compris les filtres de type "Commence par").
Si la fonction [HFiltre](3044100.md) n'est pas utilisée dans le code d'initialisation du champ Table, il est nécessaire de ré-afficher le contenu du champ Table avec la fonction [TableAffiche](3074003.md).

**Remarque** : Lorsqu'un champ de type Table fichier est rempli automatiquement (par WINDEV, WEBDEV ou WINDEV Mobile), lors de l'exécution du code d'initialisation, le champ Table n'est pas encore rempli. Il est possible de filtrer les enregistrements avec la fonction [HFiltre](3044100.md).
