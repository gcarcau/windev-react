# SonJoue (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Joue le son demandé. L'interpréteur de son doit être initialisé avec [SonInit](75130305.md).

## Exemple

```wlangage
// En CAPPELWD("SonJoue,DING.WAV");
```

```wlangage
// En PascalAPPELWD('SonJoue,DING.WAV');
```

```wlangage
// En VBcall APPELWD("SonJoue,DING.WAV")
```

## Syntaxe

```wlangage
SonJoue(<Nom du son>)
```

`<Nom du son>` *Chaîne de caractères*
> Nom du fichier son à jouer. Ce fichier est de type ".WAV" ou ".VOC".
