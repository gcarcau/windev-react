# <Fenêtre>.Maximise (Fonction)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU))

Affiche une fenêtre WINDEV dans sa taille maximale.
**Remarque** : La fonction **<Fenêtre>.Maximise** réalise la même action que le bouton d'agrandissement présent dans le coin haut droit des fenêtres.

## Exemple

```wlangage
// Affichage de la fenêtre "FEN_SaisieClient" dans sa taille maximale
FEN_SaisieClient.Maximise()
```

## Syntaxe

```wlangage
<Fenêtre>.Maximise()
```

`<Fenêtre>` *Nom de fenêtre*
> Nom de la fenêtre à afficher dans sa taille maximale.

**Composante : wd300obj.dll**
