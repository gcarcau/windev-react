# PleinEcranDésactive (Fonction)

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur)

Désactive le mode "Plein écran" du navigateur.
Remarque : Pour activer le mode "Plein écran", utilisez la fonction [PleinEcranActive](1000021012.md).

## Exemple

```wlangage
PleinEcranDésactive()
```

## Syntaxe

```wlangage
PleinEcranDésactive()
```

**Composante : WDJS.DLL**
