# IgnoreErreur (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **IgnoreErreur** permet de spécifier les erreurs ignorées. Cette propriété est utilisable sur :

- une variable de type [httpRequête](1000021158.md).
- une variable de type [restRequête](1000021481.md).
- une variable de type [mqttSession](1000023023.md).
- Nouveauté 2025
   une variable de type [ftpConnexion](1410090869.md).
