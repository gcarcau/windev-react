# TâcheLit (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **Autres** (Procédures stockées)

Lit une tâche dans la liste des tâches d'une messagerie Lotus Notes ou Outlook. Pour être lue, cette tâche doit avoir été précédemment lue (fonction [TâcheDernier](1000012002.md), [TâchePrécédent](1000012004.md), [TâchePremier](1000012005.md) ou [TâcheSuivant](1000012007.md)), ajoutée (fonction [TâcheAjoute](1000012001.md)) ou modifiée (fonction [TâcheModifie](1000012003.md)).
**Attention** : Cette fonction **ne permet pas** de lire une tâche dans la liste des tâches d'une messagerie Outlook Express.

## Exemple

```wlangage
// Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", "mail\julie.nsf", ...
					"C:\Users\Julie\AppData\Local\Lotus\Notes\Data\user.id")

// Lecture de la première tâche
TâchePremier(IDSession)
...
// Re-lecture de cette même tâche
TâcheLit(IDSession, mTâche.ID)
```

## Syntaxe

```wlangage
<Résultat> = TâcheLit(<Identifiant de la session> , <Identifiant de la tâche>)
```

`<Résultat>` *Booléen*
> - Vrai si la tâche a été lue,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Identifiant de la session>` *Entier*
> Identifiant de la session à utiliser. Cet identifiant est renvoyé par une des fonctions suivantes : [EmailOuvreSessionNotes](3032121.md), [EmailOuvreSessionOutlook](3032128.md), [NotesOuvreBase](1000005101.md) ou [OutlookOuvreSession](3032123.md).
`<Identifiant de la tâche>` *Chaîne de caractères*
> Identifiant de la tâche à lire. Cet identifiant est contenu dans la variable mTâche.ID.

## Remarques

### Tâche en cours
La variable mTâche.EnDehors permet de savoir s'il y a une tâche courante.
