# Constantes SaaS

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

| Constante | Description | Utilisée par |
| --- | --- | --- |
| **saasAdministrateur** | Niveau requis pour se connecter : Administrateur | [SaaSAdminConnecte](1000019098.md), [SaaSAdminEstConnecté](1000019101.md) |
| **saasAvecCache** | La valeur est lue depuis le cache. Si cette valeur n'existe pas dans le cache, elle est lue sur le serveur SaaS et le cache est automatiquement mis à jour. | [SaaSLitParamètreSite](1000019037.md) |
| **saasBaseAucune** | Le site SaaS n'utilise pas de base de données. | [SaaSAdminModifieConnexionSite](1000019142.md) |
| **saasBaseClient** | Chaque client du site SaaS exploite sa propre base de données. | [SaaSAdminModifieConnexionSite](1000019142.md) |
| **saasBaseCommune** | La base de données du site SaaS est partagée entre tous les clients. | [SaaSAdminModifieConnexionSite](1000019142.md) |
| **saasDuréeIllimitée** | Indique un abonnement SaaS sans date de fin. | [saasAbonnement](1000019088.md) |
| **saasFacturationForfaitaire** | Indique une facturation au forfait (sans comptage de licences). | [saasTarification](1000019091.md) |
| **saasFacturationParUtilisateur** | Indique une facturation par utilisateur (avec comptage de licences). | [saasTarification](1000019091.md) |
| **saasGestionnaireDeCompte** | Niveau requis pour se connecter : Gestionnaire de compte. | [SaaSAdminConnecte](1000019098.md), [SaaSAdminEstConnecté](1000019101.md) |
| **saasLicencesIllimitées** | Indique un abonnement SaaS facturé au forfait. | [saasAbonnement](1000019088.md) |
| **saasPériodicitéIllimitée** | Indique une tarification comptabilisé de façon unique. | [saasTarification](1000019091.md) |
| **saasSansCache** | Force la lecture de la valeur sur le serveur SAAS. La valeur présente dans le cache n'est ni lue ni mise à jour. | [SaaSLitParamètreSite](1000019037.md) |
| **saasRéInitCache** | Réinitialise le cache en entier, puis la valeur est lue sur le serveur SaaS et le cache est automatiquement mis à jour. | [SaaSLitParamètreSite](1000019037.md) |
