# CarteSupprimeMarqueur (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Supprime un marqueur d'une carte affichée par un champ Carte.
> _(Android)_ Remarque : Cette fonction est disponible dans l'émulateur Android et dans le simulateur Android.

## Exemple

```wlangage
// Suppression d'un marqueur
MonMarqueur est un Marqueur
MonMarqueur.Nom = "Destination"
MonMarqueur.Position.Latitude = 43.613708
MonMarqueur.Position.Longitude = 3.876972

SI INT_AfficheMaDestination = Vrai ALORS
	CarteAjouteMarqueur(CARTE_Position, MonMarqueur)
SINON
	CarteSupprimeMarqueur(CARTE_Position, MonMarqueur)
FIN
```

## Syntaxe

```wlangage
<Résultat> = CarteSupprimeMarqueur([<Champ Carte> [, <Marqueur>]])
```

`<Résultat>` *Booléen*
> - Vrai si le marqueur a pu être supprimé,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Carte>` *Nom de champ optionnel*
> Nom du champ Carte à manipuler. Si ce paramètre correspond à une chaîne vide ("") ou n'est pas spécifié, le champ Carte auquel appartient l'événement en cours sera utilisé.
`<Marqueur>` *Variable de type Marqueur ou chaîne de caractères optionnelle*
> Marqueur à supprimer. Ce paramètre peut correspondre :
>
> - à une variable de type [Marqueur](1000019940.md) correspondant au marqueur à supprimer.
> - à une chaîne de caractères correspondant au nom du marqueur à supprimer. Ce nom correspond à la propriété **Nom** de la variable de type [Marqueur](1000019940.md).
>
>
> Si ce paramètre n'est pas spécifié, tous les marqueurs de la carte seront supprimés (équivalent à la fonction [CarteSupprimeTout](1000019952.md)).

## Remarques

- Seul un marqueur précédemment ajouté au champ Carte peut être supprimé.
- Pour ajouter un nouveau marqueur dans un champ Carte, utilisez la fonction [CarteAjouteMarqueur](1000019794.md).
- Pour modifier un marqueur affiché dans un champ Carte, utilisez la fonction [CarteModifieMarqueur](1000019796.md).
