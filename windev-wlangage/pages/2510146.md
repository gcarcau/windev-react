# MAJAutomatique (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

La propriété **MAJAutomatique** permet de :

- Savoir si les données de la séries sont automatiquement recalculées à chaque appel de la fonction [grDessine](3042026.md).
- Modifier le mode de recalcule des données de la série.

Remarque : Cette propriété est équivalente à la fonction [grMAJAutomatiqueSérie](3042066.md).

## Exemple

```wlangage
// Recalcul automatique du graphe pour la série 2
GRF_MonGraphe[2].MAJAutomatique = Vrai
```

## Syntaxe

#### Connaître le mode de calcul d'une série

```wlangage
<Résultat> = <Série manipulée>.MAJAutomatique
```

`<Résultat>` *Booléen*
> - Vrai si les données de la série sont automatiquement recalculées lors de l'appel de la fonction [grDessine](3042026.md),
> - Faux dans le cas contraire.
`<Série manipulée>` *Chaîne de caractères*
> Série à manipuler. Utilisez la notation : *<Nom du graphe>[<Numéro de la série>]*.

#### Modifier le mode de calcul d'une série

```wlangage
<Série manipulée>.MAJAutomatique = <Nouveau mode>
```

`<Série manipulée>` *Chaîne de caractères*
> Série à manipuler. Utilisez la notation : *<Nom du graphe>[<Numéro de la série>]*.
`<Nouveau mode>` *Booléen*
> - Vrai pour que la série soit automatiquement recalculée à chaque appel de la fonction [grDessine](3042026.md),
> - Faux dans le cas contraire.
