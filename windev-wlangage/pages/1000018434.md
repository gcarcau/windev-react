# NomComplet (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

La propriété **NomComplet** permet de connaître le nom complet d'un élément. Cette propriété est utilisable sur :

- un champ, une fenêtre ou une option de menu. Pour plus de détails, consultez [NomComplet](2514005.md).
- une variable de type [sfInfoUtilisateur](1000018423.md).
