# AnimationChangeType (Fonction)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Change le type d'animation :

- d'une image dans un champ Image.
- d'un texte dans un champ Libellé.

Les paramètres spécifiques au nouveau type peuvent être modifiés avec la fonction [AnimationChangeParamètre](3017002.md).

> _(Android, iPhone/iPad, Java)_ Dans cette version, il est possible uniquement de changer le type d'animation d'un texte dans un champ Libellé.

Nouveauté 2025

> _(Android)_ Cette fonction est désormais disponible pour les applications Android.

> _(iPhone/iPad)_ Cette fonction est désormais disponible pour les applications iPhone/iPad.

## Exemple

```wlangage
// Change l'animation du champ IMG_Image1
IMG_Image1.Animation = Vrai
AnimationChangeType(IMG_Image1, actDéfilement)
```

```wlangage
// Changement des paramètres d'animation d'un champ Libellé
LIB_MonLibellé.Animation = Vrai
AnimationChangeType(LIB_MonLibellé, actClignotement)
AnimationChangeParamètre(LIB_MonLibellé, acpDurée, 100)
AnimationChangeParamètre(LIB_MonLibellé, acpCouleur, BleuFoncé)
```

## Syntaxe

```wlangage
AnimationChangeType(<Champ manipulé> , <Type d'animation>)
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ Image ou Libellé à manipuler.
`<Type d'animation>` *Constante ou chaîne de caractères*
> Animation à réaliser.
>
>
> | *actAnimationWinDev* (ou "Image à animer") | L'image est découpée en plusieurs dessins. Chaque dessin est affiché successivement, donnant une impression de vidéo.  Cette constante est utilisable uniquement avec les champs Image. _(Android, iPhone/iPad, Java)_ Cette constante n'est pas disponible. |
> | --- | --- |
> | *actClignotement* (ou "Clignotement") | Le libellé s'affiche alternativement dans sa couleur par défaut et dans sa couleur de clignotement. |
> | *actDéfilement* (ou "Défilement") | L'image (ou le libellé) apparaît progressivement, affichée à partir de la droite, de la gauche, etc. _(Android, iPhone/iPad, Java)_ Cette constante est utilisable uniquement avec les champs Libellé. |

## Remarques

### Changer le type de l'animation
Si le nouveau type correspond au type utilisé actuellement, les paramètres spécifiques à ce type sont ré-initialisés avec les paramètres par défaut.

### Arrêt ou reprise d'une animation
L'animation peut être activée ou désactivée grâce à la propriété [Animation](2510006.md).

> _(Etats et Requêtes, Windows, Code Utilisateur (MCU))_ Images utilisant un format animéLa fonction AnimationChangeType n'a aucun effet sur les images utilisant un format animé. Ainsi, pour une image au format GIF animé, les paramètres sont lus dans le fichier et ne peuvent être modifiés.
