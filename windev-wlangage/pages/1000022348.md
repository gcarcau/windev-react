# ServeurAppliModifieTâchePlanifiée (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux)

Modifie la description d'une tâche planifiée existante.

## Exemple

```wlangage
// Change la programmation de la tâche pour l'exécuter toutes les heuresMaTâchePlanifiée.Mois = "*"MaTâchePlanifiée.JourDuMois = "*"MaTâchePlanifiée.JourDeLaSemaine = "*"MaTâchePlanifiée.Heure = "*"MaTâchePlanifiée.Minute = "0" SI PAS ServeurAppliModifieTâchePlanifiée(MaTâchePlanifiée) ALORS // Cas d'erreur (par exemple si la tâche n'existe plus)FIN
```

## Syntaxe

```wlangage
<Résultat> = ServeurAppliModifieTâchePlanifiée(<Tâche planifiée>)
```

`<Résultat>` *Booléen*
> - Vrai si la tâche planifiée a été modifiée.
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Tâche planifiée>` *Variable de type serveurAppliTâchePlanifiée*
> Nom de la variable de type [serveurAppliTâchePlanifiée](1000022367.md) correspondant à la description de la tâche planifiée à modifier.
> Remarque : La tâche planifiée est recherchée par son nom. Si la tâche planifiée n'est pas trouvée, la fonction retourne une erreur.

**Composante : wd300page.dll**
