# iCalendarVersAgenda (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Mac Catalyst)

Importe des données au format iCalendar dans un champ Agenda.

## Exemple

```wlangage
siCal est une chaîne ANSI
siCal = fChargeBuffer("calendar.ics")

iCalendarVersAgenda(AGD_MonAgenda, siCal)
```

## Syntaxe

```wlangage
iCalendarVersAgenda(<Champ Agenda> , <Données iCalendar>)
```

`<Champ Agenda>` *Nom de champ*
> Nom du champ Agenda à manipuler. Ce champ peut correspondre :
>
> - au champ Agenda d'une fenêtre.
> - au champ Agenda d'un état.
> - au champ Agenda d'une page.
`<Données iCalendar>` *Chaîne de caractères ANSI au format UTF-8*
> Données au format iCalendar.

## Remarques

- Pour exporter les données d'un champ Agenda au format iCalendar, utilisez la fonction [AgendaVersiCalendar](1000021919.md).
- Cette fonction est disponible uniquement dans les sites WEBDEV pour Linux. Cette fonction n'est pas disponible dans les applications WINDEV pour Linux.

**Classification Métier / UI : Code UI**

**Composante : wd300mdl.dll**
