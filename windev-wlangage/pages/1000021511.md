# <Variable xlsDocument>.Sauve (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Sauve un document Excel. Le document sauvegardé reste ouvert. Pour le fermer, il est nécessaire d'utiliser la fonction [<Variable xlsDocument>.Ferme](1000021510.md).
Les formats supportés sont :

- XLSX (classeur Excel),
- XLSM (classeur Excel prenant en charge les macros),
- XLTX (modèle Excel),
- XLTM (modèle Excel prenant en charge les macros),
- Nouveauté 2025
  CSV (fichier csv).

Nouveauté 2025

> _(Android)_ Cette fonction est désormais disponible pour les applications Android.

> _(Widget Android)_ Cette fonction est désormais disponible en mode Widget Android.

> _(iPhone/iPad)_ Cette fonction est désormais disponible pour les applications iPhone/iPad.

## Exemple

```wlangage
MaFeuille est un xlsDocument
NomFichier est une chaîne
NomFichier = fSélecteur(fRepExe(), "", "Sélectionnez un fichier...", ...
	"Tous fichiers (*.*)" + TAB + "*.*", "*", fselOuvre + fselExiste)
SI NomFichier = "" ALORS RETOUR
MaFeuille = xlsOuvre(NomFichier, xlsEcriture)

// On va mettre OK dans la case A 25
MaFeuille[25,"A"] = "OK"
// Sauvegarde
MaFeuille.Sauve()
```

## Syntaxe

```wlangage
<Résultat> = <Document XLS>.Sauve([<Chemin du fichier> [, <Mot de passe>]])
```

`<Résultat>` *Booléen*
> - Vrai si la sauvegarde a été effectuée,
> - Faux dans le cas contraire.
`<Document XLS>` *Variable de type xlsDocument*
> Nom de la variable de type [xlsDocument](1000017464.md) à utiliser.
`<Chemin du fichier>` *Chaîne de caractères optionnelle*
> Chemin complet et nom du fichier XLS.
>
> **Si ce paramètre est précisé,** le fichier est sauvegardé à l'emplacement indiqué (le fichier existant est écrasé si nécessaire).
>
> - Si la sauvegarde est réussie, la propriété **Fichier** de la variable de type [xlsDocument](1000017464.md) manipulée contient <Chemin du fichier>. Le fichier XLS reste ouvert.
> - Si le document XLS est enregistré avec un chemin différent de celui d'origine (correspond à un "Enregistrer sous"), le fichier d'origine est fermé, le document est enregistré dans le nouveau fichier et le nouveau fichier XLS reste ouvert.
>
> **Si ce paramètre n'est pas précisé**, le chemin pris en compte est le chemin spécifié dans la propriété **Fichier** de la variable de type [xlsDocument](1000017464.md) manipulée.
`<Mot de passe>` *Chaîne de caractères optionnelle ou Chaîne secrète*
> Mot de passe à utiliser pour protéger le fichier XLS en ouverture. Ce mot de passe devra être indiqué pour ouvrir le fichier XLS.
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).

## Remarques

### Formats supportés
Les formats supportés sont :

- XLSX (classeur Excel),
- XLSM (classeur Excel prenant en charge les macros),
- XLTX (modèle Excel),
- XLTM (modèle Excel prenant en charge les macros),
- Nouveauté 2025
  CSV (fichier csv).

Pour réaliser une conversion (par exemple convertir un fichier XLS en XLSX et inversement), il suffit de modifier l'extension dans le paramètre <Chemin du fichier>.
Attention : La conversion perd la fusion des cellules, les graphes, les dessins, etc.

Fichiers CSV :

- Seule la feuille en cours est sauvée.
- Seule la valeur des cellules est sauvée (les formules par exemple ne sont pas sauvées, seul le résultat affiché de la formule est sauvé).
