# grOptionMenu (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Modifie le texte d'une option du menu contextuel d'un graphe.
**Remarque** :

- Par défaut, le menu contextuel est actif. Pour modifier l'état du menu contextuel, utilisez la fonction [grMenu](3042035.md).
- Cette fonction est utilisable uniquement si les menus des graphes sont en mode compatible (mode activé via la constante *grMenuPourCompatibilité* de la fonction [grMenu](3042035.md)).

## Exemple

```wlangage
// Modification de la ligne 50 du menu contextuel du graphe "MonGraphe"
grOptionMenu("MonGraphe", 50, "Imprimer le graphe")
```

```wlangage
// Modification de la ligne 50 du menu contextuel du graphe GRF_MonGraphe
grOptionMenu(GRF_MonGraphe, 50, "Imprimer le graphe")
```

## Syntaxe

```wlangage
grOptionMenu(<Nom du graphe> , <Identifiant de l'option> , <Texte>)
```

`<Nom du graphe>` *Nom de champ ou chaîne de caractères*
> Nom du graphe défini avec la fonction [grCrée](3042005.md) ou nom du champ Graphe présent dans l'éditeur de fenêtres.
`<Identifiant de l'option>` *Entier*
> Identifiant de l'option du menu contextuel.
`<Texte>` *Chaîne de caractères*
> Nouveau texte de l'option de menu spécifiée. Si ce paramètre correspond à une chaîne vide (""), la ligne de menu spécifiée est désactivée : cette ligne ne sera plus affichée dans le menu.

### Ligne active/désactive

- Pour désactiver une option de menu, utilisez la fonction **grOptionMenu** en spécifiant une chaîne vide ("") dans le paramètre <Texte>.
- Pour réactiver une option de menu désactivée par la fonction **grOptionMenu**, il suffit de rappeler cette fonction avec le même identifiant de menu mais avec un libellé non vide.
- Les données définies avec la fonction **grOptionMenu** seront prises en compte lors du prochain appel à la fonction [grDessine](3042026.md).

### Langues

- Le menu contextuel est prédéfini dans deux langues (Français et Anglais). Il n'est pas possible de rajouter une langue.
- Le texte est modifié dans la langue en cours. Pour gérer des langues étrangères, modifiez les textes prédéfinis.
