# Procédure WLangage appelée par la fonction CaméraVidéoDémarre

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

Procédure WLangage (également nommée "callback") appelée lorsque l'enregistrement de la vidéo est terminé. L'enregistrement de la vidéo a été démarré via la fonction [CaméraVidéoDémarre](1410087227.md). La fonction [CaméraVidéoArrête](1410087229.md) doit avoir été appelée pour arrêter l'enregistrement de la vidéo.

## Exemple

```wlangage
// Code de clic sur le champ BTN_Démarre_video
ChronoDébut()
TimerSys(TimerSys_Callback, 1 s)
PROCÉDURE INTERNE TimerSys_Callback()
	dDurée est une Durée = ChronoValeur()
	LIB_CPT_VIDEO = DuréeVersChaîne(dDurée, "HH:MM:SS")
FIN
CaméraVidéoDémarre(CAM_Caméra, CaméraVidéoDémarre_Callback)

PROCÉDURE INTERNE CaméraVidéoDémarre_Callback(bRéussite est un booléen, CheminVidéo est une chaîne)
	ChronoFin()
	FinTimerSys()
	LIB_CPT_VIDEO = "00:00:00"
	SI bRéussite ALORS
		LIB_CHEMIN_VIDEO = CheminVidéo
		MaFenêtre.Plan = 4
	SINON
		ToastAffiche("Erreur lors de l'enregistrement de la vidéo." + RC + ErreurInfo())
	FIN
FIN
```

```wlangage
// Arrêt de la vidéo
CaméraVidéoArrête(CAM_Caméra)
```

## Syntaxe

```wlangage
CaméraVidéoDémarre_Callback(<Réussite> , <Chemin de la vidéo>)
```

`<Réussite>` *Booléen*
> - Vrai si la vidéo a été enregistrée,
> - Faux dans le cas contraire. Dans ce cas, la fonction [ErreurInfo](3013008.md) permet d'obtenir le détail de l'erreur.
`<Chemin de la vidéo>` *Chaîne de caractères*
> Chemin de la vidéo qui vient d'être enregistrée.
