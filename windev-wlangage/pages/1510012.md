# Instruction SORTIR / Etiquette "SORTIR :"

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

Le mot-clé **SORTIR** peut correspondre :

- à l'instruction **SORTIR** :
  L'instruction **SORTIR** permet de sortir d'un bloc d'instructions et d'exécuter la suite du traitement en cours.
  L'instruction **SORTIR** peut être utilisée dans les boucles de type :
  - [POUR](1510001.md)
  - [POUR TOUT](1510013.md)
  - [BOUCLE](1510004.md)
  - [TANTQUE](1510010.md)
   Remarque : L'instruction **SORTIR** ne peut pas être utilisée pour sortir d'une procédure. Utilisez les mots-clés RETOUR ou RENVOYER.
- **à l'étiquette SORTIR:** :
  L'étiquette "SORTIR:" permet de déclarer un code dans une boucle.
  - Ce code sera exécuté uniquement lors de la sortie de la boucle par l'instruction "SORTIR".
  - Ce code ne sera jamais exécuté à chaque itération de la boucle.

## Syntaxe

#### Instruction SORTIR utilisée dans une instruction POUR

```wlangage
POUR <Variable de contrôle> = <Valeur initiale> A <Valeur finale> [PAS <x>] ... SI <Condition> ALORS SORTIR ...FIN<Suite du traitement>
```

#### Instruction SORTIR utilisée dans une instruction POUR TOUT

```wlangage
POUR TOUT <Fichier> SUR <Rubrique clé> ... SI <Condition> ALORS SORTIR ...FIN<Suite du traitement>
```

#### Instruction SORTIR utilisée dans une instruction BOUCLE

```wlangage
BOUCLE ... SI <Condition> ALORS SORTIR ...FIN<Suite du traitement>
```

#### Instruction SORTIR utilisée dans une instruction TANTQUE

```wlangage
TANTQUE <Condition> ... SI <Condition> ALORS SORTIR ...FIN<Suite du traitement>
```

```wlangage
Dans tous les cas, si la <Condition> est vérifiée, les opérations effectuées sont les suivantes :- Sortie du bloc d'instructions.- Exécution de la suite du traitement en cours.
```

## Remarques

### Autres instructions permettant de sortir d'une boucle
Plusieurs instructions sont possibles :

- [RETOUR](1510009.md) : Sortie de la boucle et sortie du traitement (ou de la procédure) en cours.
- [RENVOYER](1510007.md) : Renvoi d'un compte-rendu au traitement appelant. Sortie de la boucle et sortie du traitement (ou de la procédure) en cours.

La fonction [Ferme](3038018.md) permet de sortir de la boucle et de fermer la fenêtre en cours.

Attention : Il n'est pas possible d'utiliser les instructions [RETOUR](1510009.md) et [RENVOYER](1510007.md) dans un même traitement.

### Exemple d'utilisation de l'étiquette "SORTIR:"
Dans cet exemple, le total représentant la somme des 10 dernières factures est affiché.

```wlangage
NbFactures est un entierTotFact est un monétaire NbFactures = 0// Parcours des factures depuis la dernière factureHLitDernier(COMMANDE, NumCommande)TANTQUE PAS HEnDehors()   SI NbFactures >= 10  ALORS SORTIR // Saute directement au label SORTIR: // Cumule les factures TotFact += COMMANDE.TotalTTC NbFactures ++  HLitPrécédent(COMMANDE, NumCommande)  SORTIR: // Sort de la boucle au bout de 10 itérations Info("Le total des 10 dernières factures est : ", TotFact)FIN
```

### Instruction "SORTIR:" : Cas des boucles imbriquées
Il est parfois nécessaire lors de plusieurs boucles imbriquées de sortir d'une imbrication pour remonter au niveau précédent ou même à un niveau encore plus haut.
Pour cela, l'instruction **SORTIR** accepte un paramètre indiquant le nombre de niveau à remonter pour la sortie. La syntaxe est la suivante :

```wlangage
SORTIR(<Nombre de niveau>)
```

où <Nombre de niveau> est un entier entre 1 et N, N représentant le nombre de niveau d'imbrications de boucles.

Par exemple :

```wlangage
x, y, z sont des entiers POUR x = 1 À 15 // Boucle 1  POUR y = 1 À 25 // Boucle 2   POUR z = 1 À 50 // Boucle 3    SI <Ma condition est vérifiée> ALORS     SORTIR(2)  // Sort de la boucle 3 et de la boucle 2     // et passe à l'itération suivante de la boucle 1    FIN   FIN  FINFIN
```
