# <Carte>.AffichePopup (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Ouvre la popup d'un marqueur affiché dans un champ Carte.

## Exemple

```wlangage
// Affiche un marqueur
MaPosition est une géoPosition
MaPosition.Latitude = 43.613708
MaPosition.Longitude = 3.876972
MonMarqueur est un Marqueur
MonMarqueur.Position = MaPosition
MonMarqueur.AvecPopup = Vrai
MonMarqueur.Nom = "Position"
MonMarqueur.Description = "Position du lieu"
CARTE_MaCarte.AjouteMarqueur(MonMarqueur)

// Affiche la popup du marqueur
CARTE_MaCarte.AffichePopup(MonMarqueur)
```

## Syntaxe

```wlangage
<Résultat> = <Champ Carte>.AffichePopup(<Marqueur>)
```

`<Résultat>` *Booléen*
> - Vrai si la popup du marqueur a pu être affichée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler.
`<Marqueur>` *Variable de type Marqueur*
> Nom de la variable de type [Marqueur](1000019940.md) décrivant la popup du marqueur à afficher. Ce marqueur doit avoir été ajouté sur la Carte.

## Remarques

- Pour masquer la popup d'un marqueur déjà affichée, utilisez la fonction [<Carte>.FermePopup](1000025803.md).
- Pour savoir si la popup d'un marqueur est affichée, utilisez la fonction [<Carte>.PopupAffichée](1000025819.md).
