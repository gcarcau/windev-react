# BandeauLanceDéfilement (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

Active le défilement automatique sur un champ Bandeau défilant.

## Exemple

```wlangage

// Démarre le défilement
BandeauLanceDéfilement(BAN_Bannière)
```

## Syntaxe

```wlangage
BandeauLanceDéfilement(<Champ Bandeau défilant>)
```

`<Champ Bandeau défilant>` *Nom de champ*
> Nom du champ Bandeau défilant à manipuler.

**Classification Métier / UI : Code UI**

**Composante : wd300page.dll**
