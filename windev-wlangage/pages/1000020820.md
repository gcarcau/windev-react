# NationDroiteAGauche (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Permet de savoir si la langue courante s'écrit de droite à gauche. Cette information est renseignée dans les informations de langue du projet (onglet "Langues" de la fenêtre de description du projet, sous-onglet "Divers") :

## Exemple

```wlangage
SI NationDroiteAGauche() ALORS
	// Code spécifique aux langues qui s'écrivent de droite à gauche
FIN
```

## Syntaxe

```wlangage
<Résultat> = NationDroiteAGauche()
```

`<Résultat>` *Booléen*
> - Vrai si la langue courante s'écrit de droite à gauche,
> - Faux dans le cas contraire.

**Composante : wd300vm.dll**
