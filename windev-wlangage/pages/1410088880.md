# <Variable Diagramme>.VersSVG (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Exporte un diagramme vers une image vectorielle au format SVG.

## Exemple

```wlangage
MonDiagramme est un Diagramme <- EDIAG_MonDiagramme
soit bufSVG = MonDiagramme.VersSVG()
SI ErreurDétectée ALORS
	Erreur()
	RETOUR
FIN
fSauveBuffer("exportDuDiagramme.svg", bufSVG)
```

## Syntaxe

```wlangage
<Résultat> = <Diagramme>.VersSVG()
```

`<Résultat>` *Buffer*
> Image vectorielle au format SVG (chaîne encodée en UTF-8).
`<Diagramme>` *Variable de type Diagramme*
> Variable de type [Diagramme](1410088055.md) à manipuler

## Remarques

La variable de type Buffer renvoyée peur être sauvegardée dans un fichier (fonction [fSauveBuffer](1000019412.md)) ou directement affichée dans un autre champ,

**Composante : wd300mdl.dll**
