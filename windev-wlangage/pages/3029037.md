# gFond (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Construit une séquence de caractères permettant de définir la couleur d'affichage (couleur de fond d'un texte, d'un cercle, d'un rectangle, ...).
> _(WINDEV, Android, iPhone/iPad, Widget IOS, Mac Catalyst, WINDEV)_ Dans une fenêtre, cette séquence de caractères permet de définir la couleur de fond d'une texte ou d'une figure (rectangle ou cercle) : dans un élément d'un champ Liste ou Combo. dans la barre de titre et/ou de message d'une fenêtre. dans un champ Libellé.

**Remarque** : Pour utiliser une couleur dégradée, utilisez la fonction [gFondDégradé](1000017060.md).

## Exemple

> _(WINDEV)_ // Ajout du mot "Jaune" sur fond jaune dans la liste "LISTE_ListeCouleur"
ListeAjoute(LISTE_ListeCouleur, gFond(JauneClair) + "Jaune")

## Syntaxe

```wlangage
<Résultat> = gFond(<Couleur>)
```

`<Résultat>` *Chaîne de caractères*
> Séquence de caractères définissant la couleur de fond du texte, du cercle, du rectangle, ...
> > _(WINDEV, Android, iPhone/iPad, Widget IOS, Mac Catalyst, WINDEV)_ Cette séquence de caractères peut être : utilisée dans les fonctions ListeAjoute, ListeInsère ou ListeModifie.affectée à un champ Libellé. utilisée dans la barre de titre ou de message d'une fenêtre.
>
> > _(WEBDEV - Code Serveur)_ Cette séquence de caractères n'est pas interprétée par les champs en WEBDEV. Cette fonction peut être utilisée pour formater la chaîne renvoyée par un Webservice WEBDEV consommé par une application WINDEV ou WINDEV Mobile.
`<Couleur>` *Entier ou constante*
> Couleur d'affichage du fond du texte ou de la partie intérieure d'une figure (rectangle ou cercle). Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md).
> - la constante *Transparent* (permet par exemple de superposer du texte et un graphique).
