# dbgFinEnregistrement (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Arrête l'enregistrement du scénario en cours. L'enregistrement a été commencé grâce à la fonction [dbgDébutEnregistrement](1000017160.md).
**Remarque** : Cette fonction est à utiliser dans le cadre de la [création d'un test automatique par l'utilisateur final](2019031.md).

## Exemple

```wlangage
dbgFinEnregistrement()
```

## Syntaxe

```wlangage
dbgFinEnregistrement()
```

## Remarques

La fonction **dbgFinEnregistrement** est sans effet si aucun enregistrement de scénario n'est en cours.
**Note** : L'enregistrement du scénario peut être également démarré grâce au fichier ".wx" placé à côté de l'exécutable. Pour plus de détails, consultez [Scénario créé par l'utilisateur](2019031.md).

**Composante : wd300vm.dll**
