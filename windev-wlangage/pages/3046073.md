# iSautePage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Génère un saut de page : le code correspondant est envoyé dans la file d'impression de l'imprimante. Le curseur d'impression est positionné aux coordonnées (0,0) de la page suivante.
L'impression n'est pas lancée (seule la fonction [iFinImprime](3046053.md) permet de lancer l'impression).

**Remarque** : Il est fortement déconseillé d'utiliser cette fonction dans les états créés avec l'éditeur d'états. Utilisez à la place la fonction [iTerminePage](3046038.md).

## Exemple

```wlangage
// Impression d'un texte
iImprime("Bonjour")
// Saut de page
iSautePage()
// Impression d'un texte
iImprime("Nous sommes le" + DateSys())
// Lancement de l'impression
iFinImprime()
```

## Syntaxe

```wlangage
iSautePage()
```
