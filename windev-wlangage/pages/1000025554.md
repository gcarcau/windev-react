# CarteFermePopup (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Ferme la popup d'un marqueur affichée dans le champ Carte.

## Exemple

```wlangage
CarteFermePopup(CARTE_MaCarte, MonMarqueur)
```

## Syntaxe

```wlangage
<Résultat> = CarteFermePopup(<Champ Carte> , <Marqueur>)
```

`<Résultat>` *Booléen*
> - Vrai si la popup a pu être fermée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler. Si ce paramètre correspond à une chaîne vide (""), le champ Carte auquel appartient l'événement en cours sera utilisé.
`<Marqueur>` *Variable de type Marqueur*
> Nom de la variable de type [Marqueur](1000019940.md) pour laquelle la popup associée doit être fermée. Ce marqueur doit exister sur le champ Carte.

## Remarques

- Pour afficher la popup, utilisez la fonction [CarteAffichePopup](1000025553.md).
- Pour savoir si la popup d'un marqueur est affichée, utilisez la fonction [CartePopupAffichée](1000025555.md).

**Classification Métier / UI : Code UI**
