# Constantes de gestion des champs Planning et TimeLine

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Afficher uniquement les constantes utilisées par les syntaxes préfixées
Afficher uniquement les constantes utilisées par les syntaxes non préfixées
Les constantes de gestion des champs Planning et TimeLine sont les suivantes :

| Constante | Description | Utilisée par les fonctions ou les types de variables |
| --- | --- | --- |
| **plnDateDébut** | Type de date recherchée : Première date affichée dans le champ Planning.  - Date de début de la plage horaire sélectionnée. | - [PlanningPosition](1000019372.md) - [PlanningPlageSélectionnée](1000022550.md) |
| **plnDateFin** | - Type de date recherchée : Dernière date affichée dans le champ Planning. - La répétition du rendez-vous a une date de fin. - Date de fin de la plage horaire sélectionnée. | - [PlanningPosition](1000019372.md), - Type [Répétition](1000019262.md) - [PlanningPlageSélectionnée](1000022550.md) |
| **plnDateHeure** | Type d'information demandée : Date et heure de du rendez-vous correspondant aux coordonnées fournies. | [PlanningInfoXY](1000019553.md) |
| **plnModeJournée** | Mode d'affichage : Affichage sur une journée. | [PlanningChangeMode](1000019440.md),  [TimelineChangeMode](1000020397.md) |
| **plnModeMicroseconde** | Mode d'affichage : Affichage à la microseconde. | [TimelineChangeMode](1000020397.md) |
| **plnModeMilliseconde** | Mode d'affichage : Affichage à la milliseconde. | [TimelineChangeMode](1000020397.md) |
| **plnModeMois** | Mode d'affichage : Affichage sur un mois. | [PlanningChangeMode](1000019440.md), [TimelineChangeMode](1000020397.md) |
| **plnModeNbJourPersonnalisé** | Mode d'affichage : Affichage sur un nombre de jours spécifique. | [PlanningChangeMode](1000019440.md), [TimelineChangeMode](1000020397.md) |
| **plnModeSeconde** | Mode d'affichage : Affichage à la seconde. | [TimelineChangeMode](1000020397.md) |
| **plnModeSelonRdv** | Mode d'affichage du planning : Affiche le planning en utilisant un nombre de jours permettant de voir tous les rendez-vous disponibles. | [PlanningChangeMode](1000019440.md) |
| **plnModeSemaine** | Mode d'affichage : Affichage sur une semaine de 5 ou 7 jours. | [PlanningChangeMode](1000019440.md), [TimelineChangeMode](1000020397.md) |
| **plnMoisEnCours** | Type de date recherchée : Premier jour du mois affiché dans le champ Planning. | [PlanningPosition](1000019372.md) |
| **plnOccurrenceMax** | Caractéristique de la répétition : La répétition du rendez-vous a un nombre maximum défini d'occurrences. | Variable de type [Répétition](1000019262.md) |
| **plnOrigineEcran** | Utiliser des coordonnées relatives à l'écran. | [PlanningInfoXY](1000019553.md) |
| **plnPasDeFin** | Caractéristique de la répétition : Le rendez-vous sera répété à l'infini. | Variable de type [Répétition](1000019262.md) |
| **plnRdvSélectionné** | Type de rendez-vous recherché : Rendez-vous actuellement sélectionné dans le champ Planning. | [PlannnigListeRendezVous](1000019276.md) |
| **plnRdvSurvolé** | Type de rendez-vous recherché : Rendez-vous survolé par la souris dans le champ Planning. | [PlanningListeRendezVous](1000019276.md) |
| **plnRendezVous** | Type d'information demandée : Indice du rendez-vous correspondant aux coordonnées fournies. | [PlanningInfoXY](1000019553.md) |
| **plnRessource** | Type d'information demandée : Nom de la ressource correspondant aux coordonnées fournies. | [PlanningInfoXY](1000019553.md) |
| **plnSansExécuteRequête** | Affichage du planning sans ré-exécution de la requête de base du champ. | [PlanningAffiche](1000019426.md), [TimelineAffiche](1000020683.md) |
| **plnTousLesAns** | Type de répétition du rendez-vous : le rendez-vous sera répété tous les ans, le même jour à la même heure. | Variable de type [Répétition](1000019262.md) |
| **plnTousLesJours** | Type de répétition du rendez-vous : le rendez-vous sera répété tous les jours à la même heure. | Variable de type [Répétition](1000019262.md) |
| **plnTousLesMois** | Type de répétition du rendez-vous : le rendez-vous sera répété tous les mois, le même jour à la même heure. | Variable de type [Répétition](1000019262.md) |
| **plnToutesLesSemaines** | Type de répétition du rendez-vous : le rendez-vous sera répété toutes les semaines, le même jour à la même heure. | Variable de type [Répétition](1000019262.md) |
| **tlEveSélectionné** | Type d'événement recherché : Evénement actuellement sélectionné dans le champ TimeLine. | [TimelineListeEvénement](1000020401.md) |
| **tlEveSurvolé** | Type d'événement recherché : Evénement survolé par la souris dans le champ TimeLine. | [TimelineListeEvénement](1000020401.md) |
