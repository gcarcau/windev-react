# TableColonnesTriées (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

Renvoie la liste des colonnes triées d'un champ Table.
Ces colonnes ont été triées :

- directement par l'utilisateur.
- par la fonction [TableTrie](3074035.md).

## Exemple

```wlangage
ListeColonnes est une chaîne
ListeColonnes = TableColonnesTriées(TABLE_Table1)
```

## Syntaxe

```wlangage
<Résultat> = TableColonnesTriées(<Champ Table>)
```

`<Résultat>` *Chaîne de caractères*
> Liste des différentes colonnes triées avec leur sens de tri. Cette liste est de la forme :
>
>
> ```wlangage
> <Sens><Colonne1> + TAB + <Sens><Colonne2> + TAB + ...
> ```
>
>
>
>
> - <Sens> est le sens du tri. Lorsque le tri est décroissant, ce paramètre correspond à "-".
> - <Colonne> est le nom de la colonne.
`<Champ Table>` *Nom de champ*
> Nom du champ Table à manipuler.

**Composante : wd300obj.dll**
