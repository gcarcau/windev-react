# <Variable Drive>.SupprimeRépertoire (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Supprime un répertoire (et les fichiers qu'il contient) sur un drive (disque distant).

## Exemple

```wlangage

oOAuth2Param est un OAuth2Paramètres
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.URLRedirection = "http://localhost:9000/"

oDrive est un Drive
oDrive = oDriveConnecte(oOAuth2Param)

SI oDrive.SupprimeRépertoire("/MesRépertoires/MonSousRepertoire/") = Faux ALORS
 Erreur("Impossible de supprimer le répertoire demandé", ErreurInfo())
 RETOUR
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Drive>.SupprimeRépertoire(<Répertoire à supprimer>)
```

`<Résultat>` *Booléen*
> - Vrai si le répertoire a été supprimé,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Drive>` *Variable de type Drive ou gglDrive*
> Nom de la variable de type [Drive](1410089369.md) ou [gglDrive](1410089374.md) correspondant au drive à manipuler. La connexion au drive voulu doit avoir été effectuée. Dans le cas contraire, la copie n'est pas réalisée.
`<Répertoire à supprimer>` *Chaîne de caractères*
> Chemin absolu du répertoire à supprimer. Si ce paramètre ne correspond pas à un chemin de répertoire valide, le répertoire ne sera pas supprimé.

## Remarques

### Spécificités

- Si le répertoire spécifié contient des sous-répertoires, ces sous-répertoires et les fichiers qu'ils contiennent seront également supprimés.
- Un répertoire supprimé via la fonction **<Variable Drive>.SupprimeRépertoire** ne peut pas être recrée directement. L'utilisateur doit se connecter à nouveau au drive pour que la recréation du répertoire soit possible.

### Paramètre <Répertoire à supprimer>
Exemples de chemins valides :

```wlangage
"/mon répertoire de vacances/2021/""\photos"
```

Exemples de chemins invalides :

```wlangage
"répertoireA/RépertoireB""Ce/Chemin/Est/invalide""c:\Users\"
```
