# TraceFin (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Ferme la fenêtre de trace si cette fenêtre a été ouverte ou arrête l'enregistrement des informations de trace dans un fichier texte.
**Remarque** : A la fermeture du projet, la fenêtre de trace est automatiquement fermée et l'enregistrement dans le fichier texte est automatiquement arrêté.

## Exemple

```wlangage
// Fermeture de la fenêtre de trace
TraceFin()
```

## Syntaxe

```wlangage
TraceFin()
```

## Remarques

> _(iPhone/iPad, Apple Watch, PHP, PHP, iPhone/iPad, Apple Watch)_ Cas particuliers Arrête l'affichage des informations en début de la page HTML. Arrête l'affichage des informations dans la fenêtre de sortie standard de Xcode.

**Composante : wd300vm.dll**
