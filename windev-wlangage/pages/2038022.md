# Administrateur du GDS : Gestion des branches

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

L'administrateur de GDS (Gestionnaire de sources) permet de gérer directement les branches des différents projets présents dans le GDS.
Une branche est une copie séparée du projet réalisée à un instant donné. Par exemple, une branche peut être créée pour permettre la stabilisation d'une version envoyée en clientèle. Les développeurs peuvent ainsi travailler à la fois sur la branche et à la fois sur les éléments prévus pour une prochaine version. Pour plus de détails sur les branches, consultez [Gestion des branches](2038016.md).

**Remarque** : L'administrateur du GDS permet également de réaliser des opérations de maintenance sur la base de sources, etc. Pour plus de détails, consultez [Présentation de l'administrateur du GDS](2038008.md).

## Gestion des branches

### Créer une branche
Pour créer une branche :

1. Sélectionnez le répertoire contenant le projet voulu sous l'administrateur du GDS.
2. Sous le volet "Répertoires et projets", dans le groupe "Branches", cliquez sur "Créer une Branche".

L'assistant de création d'une branche se lance. Pour plus de détails, consultez [Création d'une branche](2038016.md).
**Branche sur un répertoire** : L'administrateur du GDS permet également de créer une branche sur un répertoire spécifique (même s'il ne contient pas de projet). Il est ainsi possible par exemple de créer une branche sur un répertoire contenant des ressources : images, gabarits, etc.

### Récupérer les modifications effectuées dans une branche
Pour récupérer les modifications effectuées dans une branche :

1. Sélectionnez le projet voulu sous l'administrateur du GDS.
2. Sous le volet "Répertoires et projets", dans le groupe "Branches", cliquez sur "Récupérer des modifications".

L'assistant de récupération des modifications d'une branche se lance. Pour plus de détails, consultez [Récupération des modifications d'une branche](2038016.md).
**Branche sur un répertoire** : L'administrateur du GDS permet également de récupérer les modifications effectuées sur une branche sur un répertoire spécifique.

### Supprimer une branche
Pour supprimer une branche :

1. Sélectionnez la branche voulue sous l'administrateur du GDS.
2. Dans le menu contextuel de la branche, sélectionnez l'option "Supprimer".

ATTENTION : La suppression d'une branche du GDS n'est pas conseillée. Cette opération n'est pas annulable.
