# EnModeServeurWebSocketServiceGlobal (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Permet de savoir si l'exécution en cours est effectuée dans le service global du serveur de WebSockets.

## Exemple

```wlangage

SI EnModeServeurWebSocketServiceGlobal() ALORS
 // Code spécifique au service global du serveur de WebSockets
SINON
 // Code à exécuter dans les autres cas
FIN
```

## Syntaxe

```wlangage
<Résultat> = EnModeServeurWebSocketServiceGlobal()
```

`<Résultat>` *Booléen*
> - Vrai si le code est exécuté dans le service global du serveur de WebSockets,
> - Faux dans tous les autres cas.

## Remarques

### Disponibilité de la fonction
La fonction **EnModeServeurWebSocketServiceGlobal** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **EnModeServeurWebSocketServiceGlobal** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.

**Composante : wd300vm.dll**
