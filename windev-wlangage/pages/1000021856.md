# NavigateurMobile (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

Permet de savoir si le navigateur utilisé par l'internaute est lancé sur un mobile.

## Exemple

```wlangage
// Redirige vers la page mobileSI NavigateurMobile() = Vrai ALORS PageAffiche(PAGE_Home_Mobile)FIN
```

## Syntaxe

```wlangage
<Résultat> = NavigateurMobile()
```

`<Résultat>` *Booléen*
> - Vrai si le navigateur est lancé sur un mobile.
> - Faux dans le cas contraire.

## Remarques

Les tablettes ne sont pas considérées comme des mobiles.

**Composante : wd300page.dll**
