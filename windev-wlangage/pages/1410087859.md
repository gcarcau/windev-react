# Signet (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Signet** permet de gérer les signet d'un document. Cette propriété est utilisable sur :

- une variable de type [Document](1000022461.md).
- une variable de type [pdfParamètre](1410087857.md).
- une variable de type [pdfDocument](1000024909.md).
