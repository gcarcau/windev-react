# grNuageAjouteDonnéeXY (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Ajoute une donnée dans un graphe de type "Nuage de points".
**Rappel** : Par défaut, un graphe n'a aucune donnée.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

Nouveauté Abonnement

> _(Android)_ Cette fonction est désormais disponible pour les applications Android.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
// Ajoute une donnée dans le graphe "MonGraphe" de type "Nuage de points".
// Cette valeur (10, 20) est ajoutée à la fin de la première série.
grNuageAjouteDonnéeXY("MonGraphe", 1, 10, 20)
```

```wlangage
// Ajoute une donnée dans le champ GRF_MonGraphe de type "Nuage de points".
// Cette valeur (20, 10) est ajoutée à la fin de la première série.
grNuageAjouteDonnéeXY(GRF_MonGraphe, 1, 20, 10)
```

## Syntaxe

```wlangage
grNuageAjouteDonnéeXY(<Nom du graphe> , <Numéro de la série> [, <Indice>] , <Valeur X> , <Valeur Y>)
```

`<Nom du graphe>` *Nom de champ ou chaîne de caractères*
> Nom du graphe à manipuler. Ce nom correspond :
>
> - soit au nom du graphe défini par programmation avec la fonction [grCrée](3042005.md).
> - soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.
>
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Numéro de la série>` *Entier*
> Numéro de la série dans laquelle un point doit être initialisé. Si la série spécifiée n'existe pas, le grapheur crée autant de séries que nécessaire pour obtenir une matrice de données cohérente. Les séries ainsi créées sont toutes initialisées à 0.
`<Indice>` *Entier optionnel*
> Indice de la donnée à initialiser dans la série. Si ce paramètre n'est pas spécifié, la valeur est ajoutée à la fin de la série.
`<Valeur X>` *Réel*
> Coordonnée horizontale (abscisse) du point à ajouter.
`<Valeur Y>` *Réel*
> Coordonnée verticale (ordonnée) du point à ajouter.

## Remarques

### Ajout de données dans un graphe de type Nuage de points
Les données définies avec la fonction **grNuageAjouteDonnéeXY** seront prises en compte lors du prochain appel à la fonction [grDessine](3042026.md).

### Ajout de données dans un graphe
La fonction [grAjouteDonnée](3042023.md) permet d'ajouter des données dans un graphe (secteur, histogramme, ...)
Selon le type de graphe, des fonctions spécifiques permettent également d'ajouter des données :

- Pour les graphes boursiers, il est conseillé d'utiliser la fonction [grBourseAjouteDonnée](3042009.md).
- Pour les graphes Heatmap, il est conseillé d'utiliser la fonction [grHMAjouteDonnée](1000021628.md).
- Pour les graphes Secteur Multiniveau, il est conseillé d'utiliser la fonction [grSMNAjouteDonnée](1000021285.md).
- Pour les graphes de type Surface, il est conseillé d'utiliser la fonction [grSurfaceAjouteDonnée](1000020425.md).

Rappel : Pour ajouter une valeur à une donnée d'un graphe, utilisez la fonction [grIncrémenteDonnée](3042030.md).

### Équivalence
Il est préférable d'utiliser la fonction **grNuageAjouteDonnéeXY** pour ajouter des données dans des graphes de type "Nuage de points". Cependant, il est également possible d'utiliser la fonction [grAjouteDonnée](3042023.md).
La syntaxe suivante :

```wlangage
grNuageAjouteDonnéeXY(GRF_MonGraphe, i, 1, 10, 20)
```

est équivalente à la syntaxe :

```wlangage
grAjouteDonnée(GRF_MonGraphe, i*2-1, 1, 10)
grAjouteDonnée(GRF_MonGraphe, i*2, 1, 20)
```
