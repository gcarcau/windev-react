# CmdLitSortieStandard (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU))

Lit les données disponibles sur la sortie standard pour la commande lancée en mode console.

## Exemple

```wlangage
// Exécution de la commande 'C:\Chemin\MonProgramme.exe -opt1=val1'

// Définition de la commande
MaCommandeAExécuter est une Commande
// Exécutable à lancer
MaCommandeAExécuter = "C:\Chemin\MonProgramme.exe"
// Arguments à passer à l'exécutable
MaCommandeAExécuter.Arguments = "Argument1"
// Activation des flux
MaCommandeAExécuter.Flux = cmdEntréeStandard + cmdSortieStandard
// Ajout d'un argument à la ligne de commande
CmdAjouteArgument(MaCommandeAExécuter, "Argument2")
// Ajout d'une option à la ligne de commande
CmdAjouteOption(MaCommandeAExécuter, "opt1", "val1")

// Exécution de la commande
CmdExécute(MaCommandeAExécuter, Faux)

// Lecture dans la sortie standard (possible car le flux est actif)
stdout est une chaîne = CmdLitSortieStandard(MaCommandeAExécuter)
```

## Syntaxe

```wlangage
<Résultat> = CmdLitSortieStandard(<Commande à manipuler> [, <Bloquant>])
```

`<Résultat>` *Chaîne de caractères*
> Données présentes dans la sortie standard.
> **Attention** : Le flux de sortie standard de commande doit être activé dans la variable de type [Commande](1410090491.md) (propriété **Flux**).
`<Commande à manipuler>` *Variable de type Commande*
> Nom de la variable de type [Commande](1410090491.md) correspondant à la commande exécutée en mode console.
`<Bloquant>` *Booléen optionnel*
> - Vrai (valeur par défaut) pour un fonctionnement bloquant : les données sont lues uniquement lorsque la commande a fini de s'exécuter.
> - Faux pour un fonctionnement non bloquant (asynchrone) : les données sont lues même si la commande n'a pas fini son exécution.
