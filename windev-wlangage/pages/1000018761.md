# Port (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **Port** permet de connaître et de modifier le port de connexion à un serveur. Cette propriété est utilisable sur :

- une variable de type [emailSessionIMAP](1000018957.md).
- une variable de type [emailSessionPOP3](1000018759.md).
- une variable de type [emailSessionSMTP](1000018765.md).
- une variable de type [rssFlux](1000017795.md).
- une variable de type [rssCloud](1000017785.md).
- une variable de type [sshSession](1000021157.md).
- une variable de type [mqttSession](1000023023.md).
- une variable de type [memcachedConnexion](1000023339.md).
- une variable de type [URI](1000024027.md).
- une variable de type [adminWBAuth](1410089328.md).
- une variable générée automatiquement pour représenter [un Webservice REST importé](1410087809.md).
