# HInfoTâche (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie les caractéristiques d'une tâche planifiée dans une variable de type [hTâchePlanifiée](1000017448.md). Il est par exemple possible de lire certaines caractéristiques de la tâche planifiée pour les modifier par la suite avec la fonction [HModifieTâche](1000017374.md).

## Exemple

```wlangage
MaTâche est une hTâchePlanifiée
// Récupération des caractéristiques de la tâche planifiée
MaTâche = HInfoTâche(MaConnexion, IDTâche)
// Modification de la tâche planifiée
MaTâche.Heure = SAI_Heure.Heure + 1
HModifieTâche(MaConnexion, IDTâche, MaTâche)
```

## Syntaxe

```wlangage
<Résultat> = HInfoTâche(<Connexion> , <Tâche planifiée>)
```

`<Résultat>` *Variable de type hTâchePlanifiée*
> Variable de type [hTâchePlanifiée](1000017448.md) contenant les caractéristiques de la tâche planifiée spécifiée.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion pour laquelle une tâche doit être manipulée. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Tâche planifiée>` *Entier*
> Identifiant de la tâche planifiée renvoyé par les fonctions [HAjouteTâche](1000017091.md) et [HListeTâche](1000017092.md).

## Remarques

- Pour vérifier l'existence d'une tâche, utilisez la fonction [HListeTâche](1000017092.md) : il suffit de vérifier si l'identifiant de la tâche est présent parmi les tâches renvoyées par la fonction [HListeTâche](1000017092.md).
- Pour récupérer les caractéristiques d'une tâche planifiée, il est nécessaire de posséder le droit de connexion (constante *hDroitConnexion* ou *hDroitConnexionCryptée*) sur la base de données contenant la procédure stockée.
