# Grisé (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **Grisé** permet de :

- Savoir si un champ, un groupe de champs ou une fenêtre est grisé ou non.
- Griser ou dégriser un champ, un groupe de champs ou une fenêtre.

## Exemple

```wlangage
// Grise le groupe de champs GR_FraisDeLivraison en fonction de la valeur du champ SAI_Prix
SI SAI_Prix > 100 ALORS
	GR_FraisDeLivraison.Grisé = Vrai
FIN
```

## Syntaxe

#### Savoir si un élément est grisé

```wlangage
<Résultat> = <Elément manipulé>.Grisé
```

`<Résultat>` *Booléen*
> - Vrai si l'élément est grisé,
> - Faux dans le cas contraire.
`<Elément manipulé>` *Nom de champ ou nom de fenêtre*
> Nom de l'élément à manipuler :
>
> - Nom du champ,
> - Nom du groupe de champs,
> - Nom de la fenêtre.

#### Modifier l'état grisé pour un élément

```wlangage
<Elément manipulé>.Grisé = <Nouvelle valeur>
```

`<Elément manipulé>` *Nom de champ ou nom de fenêtre*
> Nom de l'élément à manipuler :
>
> - Nom du champ,
> - Nom du groupe de champs,
> - Nom de la fenêtre.
`<Nouvelle valeur>` *Booléen*
> - Vrai si l'élément doit être grisé,
> - Faux dans le cas contraire.

## Remarques

### Equivalence
La propriété **Grisé** à Vrai est équivalente à la propriété [Etat](2510039.md) égale à la constante *Grisé* sauf pour les champs en lecture seule qui conservent l'état "en lecture seule".

### Limites

> _(WINDEV, WINDEV Mobile)_ La propriété Grisé s'applique à tous les types de champs (sauf pour les cases des barres de message).

> _(iPhone/iPad, Widget IOS)_ La propriété Grisé utilisée sur une option de menu contextuel permet de rendre cette option invisible.

> _(WEBDEV - Code Serveur)_ La propriété Grisé ne s'applique pas aux champs suivants : Champ Menu, Champ Web Caméra, Champ Réglette, Champ iFrame, Champ Tiroir, Cellule, Champ Silverlight, Champ Flex, Champ Flash, Champ Captcha, Champ Jauge, Champ Lien Social, ...Consultez la liste des propriétés disponibles pour le champ voulu.

> _(WEBDEV - Code Navigateur)_ La propriété Grisé ne s'applique pas aux champs suivants : Champ Menu, Champ Web Caméra, Champ Réglette, Champ iFrame, Champ Tiroir, Champ Table,Champ Vignette,Champ Zone répétée,Champ Zone répétée linéaire,Cellule, Colonne de table,Champ Silverlight, Champ Flex, Champ Flash, Champ Captcha, Champ Jauge, Champ Lien Social, ...Consultez la liste des propriétés disponibles pour le champ voulu.
