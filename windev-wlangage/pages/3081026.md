# XMLNomElément (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie le nom de l'élément en cours (balise ou attribut). Pour sélectionner un élément, utilisez les fonctions de recherche et de parcours XML ([XMLPremier](3081024.md), [XMLDernier](3081013.md), [XMLFils](3081012.md), ...).

## Exemple

```wlangage
NomBalise est une chaîne
// Récupère le nom de l'élément en cours
NomBalise = XMLNomElément("DocXML")

// Positionné sur un élément ?
SI NomBalise = "" ALORS
	Erreur("Aucune balise en cours")
SINON
	Info("Le nom de l'élément courant est : " + NomBalise)
FIN

// Autre possibilité :

// Positionné sur un élément ?
SI ErreurDétectée = Vrai ALORS
	Erreur("Aucune balise en cours")
SINON
	Info("Le nom de l'élément courant est : " + NomBalise)
FIN
```

## Syntaxe

```wlangage
<Résultat> = XMLNomElément(<Document XML>)
```

`<Résultat>` *Chaîne de caractères*
> - Nom de l'élément en cours.
> - Chaîne vide ("") si aucun élément n'est en cours. Dans ce cas, la variable [ErreurDétectée](3087001.md) est à Vrai. Pour obtenir plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Document XML>` *Chaîne de caractères*
> Nom du document XML manipulé. Ce document contient le code XML à analyser et a été créé avec la fonction [XMLDocument](3081008.md).

## Remarques

### Connaître l'élément courant

- Le type de l'élément en cours peut être connu avec la fonction [XMLTypeElément](3081031.md).
- La valeur de l'élément en cours peut être connue avec la fonction [XMLDonnée](3081004.md).

### Fonctions XML et threads
Si votre application utilise des threads, le document XML est partagé entre tous ces threads. Pour plus de détails sur la gestion des threads, consultez [Gestion des threads](3077026.md).
