# Le champ Graphe

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation du champ Graphe

Le champ Graphe permet de visualiser un graphe dans vos fenêtres, vos pages et vos états.
Les types de graphes disponibles sont les suivants :

- [Graphe de type Secteur (ou Camembert), Beignet ou Hémicycle](3042007.md).
- [Graphe de type Histogramme](3042011.md).
- [Graphe de type Courbe](3042002.md).
- [Graphe de type Nuage de points](3042008.md).
  Nouveauté Abonnement
   Ce type de graphe est désormais disponible pour les applications Android.
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
- [Graphe de type Boursier](3042004.md).

## Création d'un champ Graphe

**Pour créer un champ de type Graphe** :

- dans une fenêtre ou une page :
  1. Sous le volet "Création", dans le groupe "Champs graphiques", cliquez sur "Graphe".
  2. Cliquez dans la fenêtre ou la page à la position où le champ doit être créé. L'assistant de création d'un champ Graphe se lance automatiquement.
    **Astuce** : Il est également possible de créer directement un champ Graphe en choisissant son type : il suffit de dérouler l'option "Graphe" sous le volet "Création". La liste des différents types de graphes disponibles apparaît. Il suffit de cliquer sur le type de graphe voulu pour le créer dans l'éditeur.
- dans un état :
  1. Sous le volet "Création", dans le groupe "Données", cliquez sur "Graphe".
  2. Cliquez dans l'état à la position où le champ doit être créé. L'assistant de création d'un champ Graphe se lance automatiquement.

Remarque : Les dimensions du champ créé sont optimisées pour occuper l'espace disponible à la position indiquée. Si la taille du champ ne vous convient pas, utilisez la combinaison de touches Ctrl + Z : le champ retrouvera sa taille par défaut.
Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ. Pour plus de détails, consultez [Champ Graphe : Caractéristiques sous l'éditeur](3042076.md).

### Echantillonnage automatique
Dès qu'un graphe contient un nombre important de données et que celles-ci deviennent illisibles, un échantillonnage (également appelé downsampling) est automatiquement réalisé.
[image: En haut : un graphe sans échantillonnage. En bas : le même graphe avec échantillonnage]En haut : un graphe sans échantillonnage. En bas : le même graphe avec échantillonnage
Remarque : l'échantillonnage est réalisé automatiquement. Il est possible de le désactiver avec la fonction [grParamètre](1000018337.md).
