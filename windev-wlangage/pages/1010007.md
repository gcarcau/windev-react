# Manipuler les options de menu par programmation

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Les options de menu peuvent être manipulées :

- depuis l'éditeur de fenêtres. Pour plus de détails, consultez [Manipuler les options de menu sous l'éditeur](1010008.md).
- par programmation.

## Principe

La manipulation d'une option de menu est identique que le menu soit un menu contextuel ou un menu principal.
Pour manipuler par programmation une option de menu, utilisez la notation :

- **"<Nom de l'option>"** si l'option de menu est manipulée depuis la fenêtre.
- **"<Nom de la fenêtre>.<Nom du menu>.<Nom de l'option>"** si l'option est manipulée depuis une autre fenêtre.

**Remarque** : il est également possible de manipuler les menus contextuels par programmation (et non uniquement ses options). Pour plus de détails, consultez [Menu contextuel personnalisé](1010017.md).

### Fonctions du WLangage
WINDEV et WINDEV Mobile proposent plusieurs fonctions du WLangage spécifiques aux options de menu :

| [EnumèreMenu](3038039.md) | Renvoie :  - le nom de la nième option ou sous-option du menu principal de la fenêtre. - le nom de la nième option ou sous-option d'un menu contextuel personnalisé (créé avec WINDEV ou WINDEV Mobile). |
| --- | --- |
| [MenuAjoute](3038048.md) | Ajoute un menu contextuel existant dans le menu principal de la fenêtre en cours. |
| [MenuAjouteMenu](1000017266.md) | Ajoute un nouveau menu dans un menu existant (déroulant ou contextuel) d'une fenêtre ou d'une page. |
| [MenuAjouteOption](1000017262.md) | Ajoute une nouvelle option de menu à la suite de la dernière option d'un menu (déroulant ou contextuel). |
| [MenuAjouteSéparateur](1000017270.md) | Ajoute un nouveau séparateur dans un menu (menu déroulant ou contextuel). |
| [MenuClone](1000017257.md) | Clone un menu ou une option de menu ainsi que le code associé. |
| [MenuDémarque](3038002.md) | Enlève la marque placée devant l'option de menu (menu contextuel ou déroulant). |
| [MenuEtat](3038003.md) | Identifie l'état d'une option de menu (menu contextuel ou déroulant) : active, inactive ou invisible. |
| [MenuExiste](1000019365.md) | Indique si une option de menu existe dans un menu. |
| [MenuInsèreMenu](1000017267.md) | Insère un menu avant un autre menu dans une fenêtre. |
| [MenuInsèreOption](1000017265.md) | Insère une nouvelle option à une position spécifique. |
| [MenuInsèreSéparateur](1000017271.md) | Insère un séparateur dans un menu. |
| [MenuInvisible](3038022.md) | Rend une option de menu invisible (menu contextuel ou déroulant). |
| [MenuLibellé](3038009.md) | Identifie ou modifie le libellé d'une option de menu (menu contextuel ou déroulant). |
| [MenuMarquage](3038008.md) | Permet de savoir si la marque est présente devant l'option de menu (menu contextuel ou déroulant). |
| [MenuMarque](3038007.md) | Positionne la marque devant l'option de menu (menu contextuel ou déroulant). |
| [MenuSelectMoins](3038010.md) | Désactive (grise) une option de menu (menu contextuel ou déroulant). |
| [MenuSelectPlus](3038005.md) | Active une option de menu (menu contextuel ou déroulant). |
| [MenuSupprime](3038058.md) | Supprime un menu ou une option de menu. |
