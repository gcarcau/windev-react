# SaaSAdminModifieSite (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Modifie un site SaaS.
**Remarques** :

- L'utilisation de cette fonction nécessite d'avoir ouvert une session d'administration SaaS au préalable en utilisant la fonction [SaaSAdminConnecte](1000019098.md).
- L'utilisation de cette fonction est réservée à l'Administrateur SaaS. Un gestionnaire de compte client ne peut pas utiliser cette fonction.

## Exemple

```wlangage
S est un saasSite
S = SaaSAdminChercheSite("Forum")
S.Nom = "Ancien Forum"

SI SaaSAdminModifieSite(S) = Vrai ALORS
	Info("Site modifié")
FIN
```

## Syntaxe

#### Modifier un site SaaS (utilisation d'une variable de type saasSite)

```wlangage
<Résultat> = SaaSAdminModifieSite(<Site SaaS>)
```

`<Résultat>` *Booléen*
> - Vrai si la modification a été effectuée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Site SaaS>` *Variable de type saasSite*
> Nom de la variable de type [saasSite](1000019068.md) correspondant au site SaaS à modifier.

#### Modifier un site SaaS identifié par son nom

```wlangage
<Résultat> = SaaSAdminModifieSite(<Ancien nom> , <Nouveau nom>)
```

`<Résultat>` *Booléen*
> - Vrai si la modification a été effectuée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Ancien nom>` *Chaîne de caractères*
> Nom du site à modifier dans la base SaaS.
`<Nouveau nom>` *Chaîne de caractères*
> Nouveau nom du site SaaS.
