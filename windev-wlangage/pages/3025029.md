# OuvreMenuContextuel (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Ouvre automatiquement un menu contextuel pour le champ, la fenêtre ou la page en cours.

## Exemple

```wlangage
// -- Code de clic du bouton BTN_Action
OuvreMenuContextuel(MenuChoixDate)
```

## Syntaxe

```wlangage
OuvreMenuContextuel([<Nom du menu contextuel> [, <X> , <Y >]])
```

`<Nom du menu contextuel>` *Chaîne de caractères optionnelle*
> Nom du menu contextuel à ouvrir pour le champ en cours.
> Si ce paramètre n'est pas spécifié, le menu contextuel par défaut associé au champ est ouvert.
>
> > _(Android)_ Ce paramètre n'est pas disponible. Seul le menu contextuel du champ en cours peut être ouvert.
`<X>` *Entier (optionnel)*
> Abscisse de la position d'ouverture du menu contextuel. Cette abscisse est indiquée en pixels, par rapport au coin haut gauche de la fenêtre. Si les paramètres <X> et <Y> ne sont pas spécifiés, le menu contextuel est ouvert à la position de la souris.
>
> > _(Android, iPhone/iPad)_ Ce paramètre n'est pas disponible : Sous iPhone, le menu contextuel s'ouvre selon la norme iPhone : le menu contextuel provient du bas de l'écran. Sous iPad, le menu contextuel s'ouvre selon la norme iPad : le menu contextuel s'affiche à côté du champ qui a déclenché l'ouverture du menu.Sous Android, le menu contextuel s'ouvre au milieu de l'écran.
`<Y >` *Entier (optionnel)*
> Ordonnée de la position d'ouverture du menu contextuel. Cette ordonnée est indiquée en pixels, par rapport au coin haut gauche de la fenêtre. Si les paramètres <X> et <Y> ne sont pas spécifiés, le menu contextuel est ouvert à la position de la souris.
>
> > _(Android, iPhone/iPad)_ Ce paramètre n'est pas disponible : Sous iPhone, le menu contextuel s'ouvre selon la norme iPhone : le menu contextuel provient du bas de l'écran. Sous iPad, le menu contextuel s'ouvre selon la norme iPad : le menu contextuel s'affiche à côté du champ qui a déclenché l'ouverture du menu.Sous Android, le menu contextuel s'ouvre au milieu de l'écran.

## Remarques

- Cette fonction doit être exécutée dans un code associé à un champ, une fenêtre ou une page.
  Il n'est pas conseillé d'utiliser cette fonction dans le code de redimensionnement d'une fenêtre.
- Cette fonction est bloquante jusqu'à ce que le menu contextuel soit fermé.
   Cette fonction n'est pas bloquante en iOS.  Cette fonction n'est pas bloquante.
- Dans le cas d'une fenêtre fille MDI, il peut être intéressant d'ouvrir un menu contextuel défini dans la fenêtre mère MDI. Dans ce cas, le paramètre <Nom du menu contextuel> doit être de la forme :
  ```wlangage
  NomDeLaFenêtre.NomDuMenuContextuel
  ```
- Cette fonction doit être utilisée dans un des traitements du champ pour lequel le menu contextuel doit être affiché.
