# Fonctions de gestion de la corbeille

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Les fonctions de gestion de la corbeille sont les suivantes :

| [CorbeilleListeFichier](1000017162.md) | Liste les fichiers contenus dans la corbeille du système. |
| --- | --- |
| [CorbeilleRestaure](1000017159.md) | Restaure un fichier placé dans la corbeille système. |
| [CorbeilleSupprime](1000017158.md) | Affiche un message de confirmation pour la suppression d'un fichier dans la corbeille. |
| [CorbeilleVide](1000017157.md) | Vide la corbeille du système. |
