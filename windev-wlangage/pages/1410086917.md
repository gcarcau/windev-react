# 3. Données manipulées par une application WINDEV Mobile

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

| [Page précédente](1410086916.md) | [Sommaire](1410086964.md) | [Page suivante](1410086918.md) |
| --- | --- | --- |

Les données manipulées dans une application WINDEV Mobile peuvent provenir :

- d'une base de données HFSQL Classic ou HFSQL Client/Serveur (fichiers ".Fic").
- de fichiers ".INI".
- de fichiers texte (au format ANSI ou Unicode).
