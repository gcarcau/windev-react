# GglCompteDissocie (Fonction)

> **Disponible :** **WINDEV Mobile** (Android)

Supprime de l'appareil l'association entre l'application et le compte Google de l'utilisateur. Cette association a été effectuée précédemment avec la fonction [GglCompteAssocie](1410089808.md).
Rappel : Cette association permet d'effectuer une authentification en un clic dans l'application avec un compte Google enregistré sur l'appareil sans avoir besoin de saisir un login et un mot de passe.

## Exemple

```wlangage
GglCompteDissocie()
```

## Syntaxe

```wlangage
GglCompteDissocie()
```

**Classification Métier / UI : Code neutre**
