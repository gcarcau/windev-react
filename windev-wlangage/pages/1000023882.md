# Fonctions de gestion des images (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

Différentes fonctions de gestion des images sont disponibles :

- Les fonctions spécifiques au Web permettant de manipuler les images (notamment les fonctions de gestion de défilement d'images).
- Les fonctions de gestion des images dans les champs Image.

| [<Image>.ArrêteDéfilement](1000023746.md) | Arrête le défilement automatique des images. |
| --- | --- |
| [<Image>.CalqueVisible](1000023747.md) | Permet de rendre visible ou invisible un calque d'une image de type WDPIC. |
| [<Image>.Dernier](1000023748.md) | Affiche la dernière image du défilement. |
| [<Image>.LanceDéfilement](1000023749.md) | Lance le défilement automatique des images. |
| [<Image>.Occurrence](1000023750.md) | Renvoie le nombre total d'images prises en compte par le défilement. |
| [<Image>.PositionDéfilement](1000023751.md) | Retourne l'image affichée. |
| [ImagePosX](3045003.md) | Renvoie la position horizontale (X) du curseur de souris par rapport au champ Image considéré. |
| [ImagePosY](3045001.md) | Renvoie la position verticale (Y) du curseur de souris par rapport au champ Image cliquable considéré. |
| [<Image>.Précédent](1000023752.md) | Affiche l'image précédente du défilement. |
| [<Image>.Premier](1000023753.md) | Affiche la première image du défilement. |
| [<Image>.Suivant](1000023754.md) | Affiche l'image suivante du défilement. |
| [ImageZone](3045002.md) | Renvoie le numéro de la zone de l'image cliquée par l'internaute. |
