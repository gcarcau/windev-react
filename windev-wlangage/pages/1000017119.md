# HTTPCréeFormulaire (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Crée un formulaire HTTP. Ce formulaire pourra être envoyé avec la fonction [HTTPEnvoieFormulaire](1000017190.md) et manipulé avec les fonctions de gestion de formulaires HTTP.

## Exemple

```wlangage
HTTPCréeFormulaire("FORM")
...
HTTPEnvoieFormulaire("FORM", "www.monsite.fr")
```

## Syntaxe

```wlangage
HTTPCréeFormulaire(<Nom du formulaire>)
```

`<Nom du formulaire>` *Chaîne de caractères*
> Nom du formulaire HTTP. Ce nom permet de manipuler le formulaire HTTP par programmation (par exemple avec la fonction [HTTPAjouteParamètre](1000017189.md)). Si le formulaire existe déjà, il est vidé.

## Remarques

### Libération des ressources
La déclaration du formulaire peut être annulée par la fonction [HTTPAnnuleFormulaire](1000017123.md). Cette fonction permet de libérer les ressources allouées. Les ressources allouées seront automatiquement libérées :

- à la fin du thread en cours (ou de l'application s'il s'agit du thread principal).
- lors de l'appel à la fonction [HTTPEnvoieFormulaire](1000017190.md).

**Composante : wd300com.dll**
