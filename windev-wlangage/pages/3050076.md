# MatExiste (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Teste l'existence d'une matrice en mémoire.

## Exemple

```wlangage
// Teste l'existence de la matrice
ResExiste = MatExiste("MaMatrice")
```

## Syntaxe

```wlangage
<Résultat> = MatExiste(<Matrice>)
```

`<Résultat>` *Booléen*
> - Vrai si la matrice existe en mémoire,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Matrice>` *Chaîne de caractères*
> Nom de la matrice à tester, défini avec la fonction [MatCrée](3050058.md).

## Remarques

### Existence d'une matrice en mémoire
Une matrice peut être créée de plusieurs façons :

- par la fonction [MatCrée](3050058.md),
- en copiant une matrice (fonction [MatCopie](3050048.md)),
- en additionnant deux matrices (fonction [MatAdditionne](3050049.md)),
- en multipliant deux matrices (fonction [MatMultiplie](3050072.md)),
- en créant la matrice transposée (fonction [MatTranspose](3050001.md)),
- en créant la matrice inverse (fonction [MatInverse](3050075.md)).

Une matrice peut être supprimée :

- par la fonction [MatSupprime](3050031.md),
- à la fermeture de l'application.

**Classification Métier / UI : Code neutre**

**Composante : wd300mat.dll**
