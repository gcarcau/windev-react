# Gestion du Markdown

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Markdown est un langage de balisage "léger" qui permet de formater des textes. Markdown est assez simple mais très pratique et facile à prendre en main, à retenir et à relire.
Markdown est supporté dans tous les champs WINDEV et WINDEV Mobile. Il suffit d'activer l'option et de saisir un libellé au format Markdown.

> _(WEBDEV - Code Serveur)_ En WEBDEV, seules les fonctions du type MarkdownVersxxx sont supportées.

## Comment le faire ?

> _(WINDEV, WINDEV Mobile)_ Activation du rendu Markdown dans un champ Pour activer le rendu Markdown dans un champ d'une fenêtre, il suffit de : Afficher la fenêtre de description du champ. Dans l'onglet "UI", cocher l'option "Support du Markdown".Cette option permet d'activer la gestion du Markdown sur les éléments suivants :le libellé,la bulle d'aide du champ,les jetons associés à un champ de saisie.Remarque : Cette propriété ne s'applique pas au contenu du champ de saisie.La propriété Markdown permet d'activer ou non le rendu Markdown dans un champ d'une fenêtre par programmation. Remarque : Dans l'éditeur d'états, il est également possible de gérer le Markdown dans les champs Libellé. Par programmation, il suffit d'utiliser la propriété Markdown.

> _(WINDEV, WINDEV Mobile)_ Champ de saisie MarkdownLa gestion du Markdown dans un champ de saisie est un cas particulier. En effet, pour afficher un contenu Markdown dans le champ de saisie, il suffit que le champ de saisie soit de type "Visualisation Markdown". Le contenu affecté au champ sera affiché (dans l'éditeur et en exécution) avec le rendu Markdown.Cette fonctionnalité offre plusieurs avantages (par rapport à l'affichage d'un contenu dans un champ Libellé) :si le contenu formaté est trop grand pour être affiché, un ascenseur sera automatiquement affiché pour scroller dans le contenu.il est possible de sélectionner une portion du texte affiché (pour le copier par exemple).Par programmation, il est possible d'utiliser la propriété VisualisationMarkdown.

### Conversions Markdown
Le WLangage propose en standard plusieurs fonctions pour convertir un contenu Markdown en d'autres formats :

| [MarkdownVersDOCX](1410089153.md) | Convertit une chaîne de caractères au format Markdown en un document au format DOCX. |
| --- | --- |
| [MarkdownVersHTML](1410088874.md) | Convertit une chaîne de caractères au format Markdown en un buffer au format HTML (encodé en UTF8). |
| [MarkdownVersPDF](1410089119.md) | Convertit une chaîne (ou un buffer) au format Markdown en un buffer contenant un document PDF. |
| [MarkdownVersTexte](1410089001.md) | Convertit une chaîne de caractères au format Markdown en une chaîne de caractères au format texte (sans balises). |

Lors de l'édition de documents au format Markdown (des comptes-rendus de réunion, des rapports d'interventions, etc.), ces fonctions permettent de :

- afficher le contenu dans un site Web (HTML),
- transmettre le document par email (PDF),
- etc.

## Les balises et syntaxes Markdown

Les balises Markdown et leur syntaxe sont les suivantes :

| **Titres** |  |
| --- | --- |
| # Titre 1 ## Titre 2 ### Titre 3 #### Titre 4  ##### Titre 5  ###### Titre 6 | ### Titre 1  ### Titre 2  ### Titre 3  ### Titre 4  ### Titre 5  ### Titre 6 |
| **Gras/Italique** |  |
| texte *Italique*  texte **Gras**  texte ***Gras et italique*** | texte *Italique*    texte **Gras**    texte ***Gras et italique*** |
| **Barré** |  |
| texte ~~barre~~ | texte ~~barré~~ |
| **Saut de ligne** |  |
| **Texte gras** RC RC *Texte italique*  RC correspond à un retour chariot | **Texte gras**   *Texte italique* |
| **Texte gras** ESP ESP RC *Texte italique*  ESP correspond au caractère espace RC correspond à un retour chariot | **Texte gras**  *Texte italique* |
| **Changement de paragraphe** |  |
| **Texte gras** Ligne vide *Texte italique* | **Texte gras**  *Texte italique* |
| **Citation** |  |
| Citation Citation  2eme ligne de la citation Citation niveau 1   Citation niveau 2     Citation niveau 3 | Citation Citation 2eme ligne de la citation Citation niveau 1  Citation niveau 2   Citation niveau 3 |
| **Listes** |  |
| * Liste 1 * Liste 2  * Liste 3   * Sous liste 1  * Sous liste 2  1. Liste 1 2. Liste 2  3. Liste 3   1. Sous liste 1  2. Sous liste 2 | - Liste 1 - Liste 2 - Liste 3   - Sous liste 1  - Sous liste 2    1. Liste 1 2. Liste 2 3. Liste 3   1. Sous liste 1  2. Sous liste 2 |
| **Code** |  |
| ``` // Calcul n = Factorielle(6) ``` | ``` // Calcul n = Factorielle(6) ``` |
| **Séparateur** |  |
| a * * * b *** c - - - d --- e | a b c d e |
| **Liens** |  |
| [WINDEV](https://pcsoft.fr/windev/)  [WEBDEV](https://pcsoft.fr/webdev "WEBDEV !")  [lien]: https://pcsoft.fr/windevmobile [WINDEV Mobile][lien] | [WINDEV](https://pcsoft.fr/windev) [WEBDEV !](https://pcsoft.fr/webdev)  [WINDEV Mobile](https://pcsoft.fr/windevmobile) |
| **Images**  NB : URLs gérées en synchrone |  |

| \\ \# \_ \- \` \! \( \) \{ \} \[ \] | \ # _ - ' ! ( ) { } [ ] |
