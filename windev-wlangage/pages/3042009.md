# grBourseAjouteDonnée (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Ajoute une donnée dans un graphe boursier (chandelier, barcharts ou minmax).
**Attention** : Selon le type de graphe à manipuler, il existe une fonction WLangage spécifique pour ajouter les données (voir paragraphe "Remarques").

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
// Graphe créé par programmation
grCrée("MonGraphe", grChandelier)
...
// Ajout de données dans le graphe "MonGraphe"
grBourseAjouteDonnée("MonGraphe", 1, 5.4, 6.8, 6.1, 6.3)
```

```wlangage
// Champ Graphe
// Ajout de données dans le graphe "GRF_MonGraphe"
grBourseAjouteDonnée(GRF_MonGraphe, 1, 5.4, 6.8, 6.1, 6.3)
```

## Syntaxe

```wlangage
grBourseAjouteDonnée(<Nom du graphe> , <Numéro de la série> [, <Indice>] , <Valeur minimale> , <Valeur maximale> , <Première valeur> , <Dernière valeur>)
```

`<Nom du graphe>` *Nom de champ ou chaîne de caractères*
> Nom du graphe à manipuler. Ce nom correspond :
>
> - soit au nom du graphe défini par programmation avec la fonction [grCrée](3042005.md).
> - soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.
>
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Numéro de la série>` *Entier*
> Numéro de la série dans laquelle une valeur doit être ajoutée. Si la série spécifiée n'existe pas, le grapheur crée autant de séries que nécessaire pour obtenir une matrice de données cohérente. Les séries ainsi créées sont toutes initialisées à 0.
> **Attention : Seule la première série sera dessinée**.
`<Indice>` *Entier optionnel*
> Indice de la donnée dans la série où les valeurs doivent être ajoutées. Si ce paramètre :
>
> - n'est pas spécifié : les valeurs sont ajoutées à la fin de la série.
> - est spécifié : l'ancienne valeur est remplacée.
`<Valeur minimale>` *Entier ou réel*
> Valeur minimale de la journée.
`<Valeur maximale>` *Entier ou réel*
> Valeur maximale de la journée.
`<Première valeur>` *Entier ou réel*
> Première valeur de la journée.
`<Dernière valeur>` *Entier ou réel*
> Dernière valeur de la journée.

## Remarques

### Cohérence des valeurs
Si les valeurs ne sont pas cohérentes, les données ne seront pas affichées dans le graphe :

- <Première valeur>, <Dernière valeur> et <Valeur minimale> doivent être strictement inférieures à <Valeur maximale>.
- <Première valeur>, <Dernière valeur> et <Valeur maximale> doivent être strictement supérieures à <Valeur minimale>.

### Ajout de données

- Les données ajoutées avec la fonction **grBourseAjouteDonnée** seront prises en compte lors du prochain appel à la fonction [grDessine](3042026.md).
- Seule la première série sera dessinée.

- Par défaut, un graphe boursier créé avec la fonction [grCrée](3042005.md) ne contient aucune donnée.

### Ajout de données dans les différents types de graphes

- Pour ajouter des données dans les graphes standard (courbe, secteur, ...), utilisez la fonction [grAjouteDonnée](3042023.md).
- Pour les graphes de type Nuage de points, il est conseillé d'utiliser la fonction [grNuageAjouteDonnéeXY](3042032.md).
- Pour les graphes Heatmap, il est conseillé d'utiliser la fonction [grHMAjouteDonnée](1000021628.md).
- Pour les graphes Secteur Multiniveau, il est conseillé d'utiliser la fonction [grSMNAjouteDonnée](1000021285.md).
- Pour les graphes de type Surface, il est conseillé d'utiliser la fonction [grSurfaceAjouteDonnée](1000020425.md).
- Pour ajouter une valeur à une donnée d'un graphe, utilisez la fonction [grIncrémenteDonnée](3042030.md).
