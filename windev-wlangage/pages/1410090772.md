# BitcoinCoreConnexionOccurrence (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Renvoie le nombre de pairs connectés.
Nouveauté 2025
**Attention** : Cette fonction est disponible uniquement à partir de la version 2025 Update 2.

## Exemple

```wlangage
// Récupération du nombre de pairs connectés
nbPairs est un entier
nbPairs = BitcoinCoreConnexionOccurrence()
SI ErreurDétectée ALORS
	Erreur()
	RETOUR
FIN
Trace("Nombre de pairs connectés :" + nbPairs)
```

## Syntaxe

```wlangage
<Résultat> = BitcoinCoreConnexionOccurrence()
```

`<Résultat>` *Entier*
> Nombre de pairs connectés.

## Remarques

Pour utiliser les fonctions [BitcoinCoreXXXX](1410090347.md), il est nécessaire de configurer un serveur Bitcoin Core. Pour plus de détails, consultez [Installation et utilisation d'un serveur Bitcoin Core](1410090348.md).
