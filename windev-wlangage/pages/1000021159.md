# Fonctions SSH

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions SSH (syntaxe préfixée)](1000021168.md)).
Les fonctions permettant de se connecter et de dialoguer avec un serveur SSH sont les suivantes :

| [SSHCommande](1000021143.md) | Envoie une commande à un serveur SSH. La session est ouverte et refermée automatiquement après l'envoi de la commande. |
| --- | --- |
| Nouveauté Abonnement [SSHConnecteCommande](1410091112.md) | Permet de conserver la session SSH active entre plusieurs envois de commandes (via la fonction [SSHCommande](1000021143.md)) à un serveur SSH. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [SSHConnecteShell](1000021147.md) | Ouvre une nouvelle session SSH de type "Shell". |
| Nouveauté Abonnement [SSHDéconnecteCommande](1410091113.md) | Permet d'arrêter la session SSH qui était active pour permettre l'envoi groupé de plusieurs commandes. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [SSHDéconnecteShell](1000021148.md) | Ferme une session SSH précédemment ouverte grâce à la fonction [SSHConnecteShell](1000021147.md). |
| [SSHEcrit](1000021150.md) | Ecrit des données dans la session SSH spécifiée. |
| [SSHLit](1000021149.md) | Lit les données présentes sur le buffer de sortie de la session SSH. |

Remarque : Le protocole géré est SSH-2.
