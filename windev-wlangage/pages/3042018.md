# grDestinationBMP (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Définit un fichier BitMap comme destination d'un graphe (BMP signifie BitMap). Ce fichier sera créé lors du prochain dessin du graphe (fonction [grDessine](3042026.md)).
**Remarques** :

- Cette fonction ne peut pas être utilisée avec les champs Graphe.
- Cette fonction ne peut pas être utilisée sous l'éditeur d'états.
- Cette fonction ne permet pas d'obtenir l'image d'un graphe cylindrique en 3D.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
// Définition du fichier "C:\Graphes\Graphe.BMP"
// comme destination du graphe "MonGraphe"
grDestinationBMP("MonGraphe", "C:\Graphes\Graphe.BMP")
```

## Syntaxe

```wlangage
grDestinationBMP(<Nom du graphe> , <Nom du fichier BMP>)
```

`<Nom du graphe>` *Chaîne de caractères*
> Nom du graphe à manipuler, défini avec la fonction [grCrée](3042005.md).
`<Nom du fichier BMP>` *Chaîne de caractères*
> Nom du fichier BMP dans lequel le graphe doit être enregistré. Ce fichier est créé lors de l'appel à la fonction [grDessine](3042026.md).

## Remarques

### Fichier BMP comme destination

- Lors du prochain appel à la fonction [grDessine](3042026.md), le graphe sera dessiné dans le fichier <Nom du fichier BMP>.
- Ce fichier pourra être lu grâce à un outil reconnaissant le format BMP.
- Il est possible de définir la taille de ce fichier grâce à la fonction [grFenTaille](3042016.md).
- Il est conseillé de visualiser le graphe à l'écran avant de l'enregistrer dans un fichier.

### Créer et dessiner un graphe par programmation
Pour dessiner un graphe :

- créez le graphe (fonction [grCrée](3042005.md)),
- ajoutez les données (fonctions [grAjouteDonnée](3042023.md), [grBourseAjouteDonnée](3042009.md) et [grNuageAjouteDonnéeXY](3042032.md)),
- définissez la destination du graphe à l'aide des fonctions suivantes :
  - **grDestinationBMP**,
  - [grDestinationChamp](3042020.md),
  - [grDestinationEMF](3042017.md),
  - [grDestinationFen](3042031.md),
  - [grDestinationImage](1000020952.md),
  - [grDestinationWMF](3042019.md).
- dessinez le graphe (fonction [grDessine](3042026.md)).

### Différences entre les fonctions grDestinationBMP et grSauveBMP

- La fonction **grDestinationBMP** permet de définir la destination du prochain dessin du graphe. Lors de l'utilisation de la fonction [grDessine](3042026.md), le graphe sera dessiné dans le fichier spécifié et toutes les modifications effectuées depuis le dernier dessin du graphe seront prises en compte.
- La fonction [grSauveBMP](3042050.md) permet de sauvegarder le graphe directement dans un fichier au format BMP. L'image enregistrée correspond au graphe lors du dernier appel de la fonction [grDessine](3042026.md). Si des modifications ont été effectuées sur le graphe depuis l'appel de la fonction [grDessine](3042026.md), ces modifications ne seront pas prises en compte.
