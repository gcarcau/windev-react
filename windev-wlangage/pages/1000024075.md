# Constantes de gestion des bases Big Data Redis

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Afficher uniquement les constantes utilisées par les syntaxes préfixées
Afficher uniquement les constantes utilisées par les syntaxes non préfixées
Les constantes utilisées par la syntaxe classique des fonctions Redisxxx sont les suivantes :

| Constante | Détail | Fonction |
| --- | --- | --- |
| **redisAbonnement** | L'application vient de s'abonner au canal spécifié. | [RedisAbonne](1000023552.md) |
| **redisDéconnexion** | La connexion au serveur Redis a été perdue. | [RedisAbonne](1000023552.md) |
| **redisDésabonnement** | L'application vient de se désabonner du canal spécifié. | [RedisAbonne](1000023552.md) |
| **redisMessage** | L'application vient de recevoir un message. | [RedisAbonne](1000023552.md) |
| **redisTypeBuffer** | Type du résultat : Le résultat correspond à un buffer. | Type [redisRéponse](1000023534.md) |
| **redisTypeEntier** | Type du résultat : Le résultat correspond à un entier. | Type [redisRéponse](1000023534.md) |
| **redisTypeErreur** | Type du résultat : Le résultat correspond à une erreur. | Type [redisRéponse](1000023534.md) |
| **redisTypeNil** | Type du résultat : Le résultat n'a pas de valeur. | Type [redisRéponse](1000023534.md) |
| **redisTypeStatus** | Type du résultat : Le résultat correspond à un état. | Type [redisRéponse](1000023534.md) |
| **redisTypeTableau** | Type du résultat : Le résultat correspond à un tableau. | Type [redisRéponse](1000023534.md) |
