# <Variable Polyligne2D>.AjoutePoint (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Ajoute un nouveau point dans une polyligne en 2 dimensions (polyligne géométrique).
**Rappel** : Un polygone en 2 dimensions est un ensemble de polylignes géométriques.

## Exemple

```wlangage
MaLigne est une Polyligne2D
// Ajout de points dans la polyligne
MaLigne.AjoutePoint(32, 22)
MaLigne.AjoutePoint(134, 12)
```

## Syntaxe

```wlangage
<Polyligne>.AjoutePoint(<X> , <Y>)
```

`<Polyligne>` *Variable de type Polyligne2D*
> Nom de la variable de type [Polyligne2D](1410090109.md) dans laquelle des points doivent être ajoutés.
`<X>` *Réel*
> Coordonnée X du point en 2 dimensions.
`<Y>` *Réel*
> Coordonnée Y du point en 2 dimensions.
