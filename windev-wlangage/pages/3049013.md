# ListeSupprimeTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Vide de tous ses éléments un champ Liste par programmation (y compris Liste image) ou un champ Combo par programmation.
**Remarque** : La fonction **ListeSupprimeTout** peut être utilisée indifféremment sur les champs Liste monosélection et multisélection.

> _(WEBDEV - Code Navigateur)_ Attention : Le champ Liste (ou Combo) sera vidé uniquement sur la page affichée dans le navigateur. Pour plus de détails, voir les Remarques.

## Exemple

```wlangage
// Suppression de tous les éléments présents dans le champ "LISTE_ListeClient"
ListeSupprimeTout(LISTE_ListeClient)
```

## Syntaxe

```wlangage
ListeSupprimeTout(<Champ Liste>)
```

`<Champ Liste>` *Nom de champ*
> Nom du champ Liste (ou Combo) à manipuler. Si ce paramètre correspond à une chaîne vide (""), tous les éléments du champ Liste (ou Combo) auquel appartient l'événement en cours sont effacés.
> > _(WEBDEV - Code Navigateur)_ Le nom du champ Liste (ou Combo) à manipuler doit obligatoirement être spécifié.

## Remarques

> _(WEBDEV - Code Navigateur)_ Suppression sur le navigateurLors de la suppression des éléments d'un champ Liste (ou Combo) en code navigateur, ces éléments sont supprimés uniquement sur la page affichée dans le navigateur. Pour que ces éléments soient également supprimés sur le serveur, il est nécessaire d'exécuter la fonction ListeSupprimeTout sur le serveur.L'utilisation de la fonction ListeSupprimeTout en code navigateur est intéressante lors de l'utilisation de la technologie AJAX, en mode "AJAX Programmé" (utilisation de la fonction AJAXExécute ou AJAXExécuteAsynchrone).Rappel : En mode "AJAX automatique et immédiat", il suffit de passer le traitement serveur contenant la fonction ListeSupprimeTout en mode AJAX automatique. Rien de plus ! Aucune programmation supplémentaire n'est nécessaire. Pour plus de détails, consultez AJAX.

### Divers

- Pour supprimer l'ensemble des lignes d'un champ Table, utilisez la fonction [TableSupprimeTout](3074034.md).
- La fonction **ListeSupprimeTout** peut être utilisée sur une colonne d'un champ Table de type "Combo".
- Dans le cas des champs Combo avec saisie, la zone de saisie est vidée.
