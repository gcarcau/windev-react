# Fonctions de gestion des champs Onglet (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU))

Les fonctions permettant de manipuler les champs Onglet (via la syntaxe préfixée) sont les suivantes :

| [<Onglet>.ChargeConfiguration](1000021699.md) | Restaure la configuration des volets dynamiques d'un champ Onglet. |
| --- | --- |
| [OngletDuChamp](3025028.md) | Renvoie le nom du champ Onglet qui contient le champ spécifié. |
| [<Onglet>.Etat](1000021700.md) | Renvoie l'état d'un volet d'onglet dynamique (identifié par son alias). |
| [<Onglet>.Ferme](1000021702.md) | Ferme un volet dynamique dans un champ Onglet. |
| [<Onglet>.FermeTout](1000021703.md) | Ferme tous les volets dynamiques d'un champ Onglet. |
| [<Onglet>.Ouvre](1000021704.md) | Ouvre un nouveau volet dans un champ Onglet dynamique. |
| [<Onglet>.SauveConfiguration](1000021708.md) | Sauvegarde la configuration des volets dynamiques d'un champ Onglet sous forme d'une chaîne de caractères. |
| [VoletDuChamp](1000021625.md) | Renvoie le nom du volet (statique ou dynamique) d'un champ Onglet associé à un champ. |
