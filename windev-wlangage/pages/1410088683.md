# PicCaptureLasso (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Effectue une capture d'écran via le lasso et récupère cette capture dans une variable de type [Image](1000019650.md).

## Exemple

```wlangage
MaCapture est une Image
MaCapture = PicCaptureLasso(Vrai)
```

## Syntaxe

```wlangage
<Résultat> = PicCaptureLasso([<Iconise>])
```

`<Résultat>` *Variable de type Image*
> Variable de type [Image](1000019650.md) contenant le résultat de la capture effectuée.
`<Iconise>` *Booléen optionnel*
> - Vrai pour iconiser l'application lors de la capture,
> - Faux dans le cas contraire.

**Composante : wd300pic.dll**
