# <Planning>.ChangeMode (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

Modifie la période (c'est-à-dire le nombre de jours) affichée par un champ Planning.

## Exemple

```wlangage
// Clic sur BTN_Jour
PLN_Planning.ChangeMode(plnModeJournée)

// Clic sur BTN_Semaine
PLN_Planning.ChangeMode(plnModeSemaine)

// Clic sur BTN_Mois
PLN_Planning.ChangeMode(plnModeMois)
```

## Syntaxe

```wlangage
<Champ Planning>.ChangeMode(<Mode d'affichage> [, <Nombre de jours>])
```

`<Champ Planning>` *Nom de champ*
> Nom du champ Planning manipulé. Ce champ peut correspondre :
>
> - au champ Planning d'une fenêtre,
> - au champ Planning d'une page,
> - au champ Planning d'un état.
`<Mode d'affichage>` *Constante de type Entier*
> Plage de temps à afficher dans le champ Planning :
>
> | *plnModeJournée* | Affiche le champ Planning sur une journée. |
> | --- | --- |
> | *plnModeMois* | Affiche le champ Planning sur un mois. |
> | *plnModeNbJourPersonnalisé* | Affiche le champ Planning sur le nombre de jours indiqué dans le paramètre <Nombre de jours>. |
> | *plnModeSelonRdv* | Affiche le champ Planning en utilisant un nombre de jours permettant de voir tous les rendez-vous disponibles. _(Android, iPhone/iPad)_ Cette constante n'est pas disponible. |
> | *plnModeSemaine* | Affiche le champ Planning sur une semaine de 5 jours ou sur une semaine de 7 jours. Le nombre de jours est indiqué dans le paramètre <Nombre de jours>. Le premier jour affiché est le premier jour de la semaine défini dans la fenêtre de description du champ Planning. |
`<Nombre de jours>` *Entier optionnel*
> Nombre de jours affichés. Ce paramètre est pris en compte uniquement si le paramètre <Mode d'affichage> correspond à la constante *plnModeNbJourPersonnalisé* ou à la constante *plnModeSemaine*. Dans le cas contraire, une erreur WLangage est affichée.
