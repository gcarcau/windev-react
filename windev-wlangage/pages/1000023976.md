# Jeton (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

La propriété **Jeton** permet de manipuler les différents jetons associés à un champ de saisie de type "Texte avec jetons".
> _(WEBDEV - Code Navigateur)_ Cette propriété permet uniquement de connaître la valeur d'un jeton.

## Exemple

```wlangage
J est un Jeton
J.Valeur = "Mon jeton"
SaisieAjouteJeton(SAI_Email, J)
// équivalences :
// SAI_Email.AjouteJeton(J)
// Ajoute(SAI_Email.Jeton[J])
Info(SAI_Email.Jeton[1].Valeur)
```

## Syntaxe

#### Connaître la valeur d'un jeton

```wlangage
<Résultat> = <Champ de saisie>.Jeton[<Indice du jeton>]
```

`<Résultat>` *Chaîne de caractères*
> Valeur du jeton.
`<Champ de saisie>` *Nom de champ*
> Nom du champ de saisie de type "Texte avec jetons".
`<Indice du jeton>` *Entier*
> Indice du jeton à manipuler. Les indices correspondent à l'ordre d'affichage actuel des jetons (et non l'indice initial d'ajout ou d'insertion du jeton).

> Non disponible en code navigateur

Modifier la valeur d'un jeton Masquer les détails
<Champ de saisie>.Jeton[<Indice du jeton>] = <Nouvelle valeur>

 <Champ de saisie> : Nom de champNom du champ de saisie de type "Texte avec jetons". <Indice du jeton> : EntierIndice du jeton à manipuler. Les indices correspondent à l'ordre d'affichage actuel des jetons (et non l'indice initial d'ajout ou d'insertion du jeton). <Nouvelle valeur> : Chaîne de caractèresNouvelle valeur du jeton.
