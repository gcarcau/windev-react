# Propriétés associées aux colonnes des champs Table

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Une colonne d'un champ Table peut être manipulée en WLangage aussi bien dans une fenêtre que dans une page à l'aide des propriétés suivantes.

- Propriétés disponibles sur une colonne d'un champ Table.
- Propriétés disponibles sur une colonne d'un champ Table hiérarchique.
