# NomUtilisateur (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

La propriété **NomUtilisateur** permet de connaître et de modifier le nom de l'utilisateur. Cette propriété est utilisable :

- une variable de type [OpenIDParamètres](1000023561.md).
- une variable de type [OAuth2Paramètres](1000022212.md).
