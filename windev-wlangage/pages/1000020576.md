# fSurveilleStopTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Arrête toutes les surveillances en cours sur les fichiers et les répertoires. Ces surveillances ont pu être lancées par la fonction [fSurveilleFichier](1000020522.md) ou par la fonction [fSurveilleRépertoire](1000020523.md).

## Exemple

```wlangage
// Arrêt de toutes les surveillances en cours
SI PAS fSurveilleStopTout() ALORS
	Erreur("Aucune surveillance n'a été lancée.")
SINON
	Info("La suppression des surveillances a réussi.")
FIN
```

## Syntaxe

```wlangage
<Résultat> = fSurveilleStopTout()
```

`<Résultat>` *Booléen*
> - Vrai si toutes les surveillances précédemment activées ont été arrêtées,
> - Faux dans le cas contraire (surveillance inexistante).

**Composante : wd300std.dll**
