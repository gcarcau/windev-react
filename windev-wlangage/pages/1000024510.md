# <Variable Document>.FinModification (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Signale la fin du regroupement d'un ensemble d'opérations sur une variable de type [Document](1000022461.md) en un seul événement (gestion du "undo/redo").

## Exemple

```wlangage
MonDocument est un Document

MonDocument.DébutModification()
MonDocument.Remplace("%NomClient%", Client.Nom)
MonDocument.Remplace("%PrénomClient%", Client.Prénom)
MonDocument.FinModification()
```

## Syntaxe

```wlangage
<Document>.FinModification()
```

`<Document>` *Variable de type Document*
> Nom de la variable de type [Document](1000022461.md) à manipuler.

## Remarques

Les modifications effectuées sur le document sont regroupées à partir de l'appel de la fonction [<Variable Document>.DébutModification](1000024507.md). Si plusieurs modifications annulables sont effectuées, il suffit d'un seul "Ctrl + Z" pour annuler toutes les opérations effectuées.

**Composante : wd300obj.dll**
