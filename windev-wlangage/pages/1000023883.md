# Fonctions Tableur (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Les fonctions (syntaxe préfixée) permettant de manipuler le champ Tableur sont les suivantes :

| [<Tableur>.AjouteDonnée](1000023711.md) | Ajoute une donnée dans un champ Tableur présent dans une fenêtre. |
| --- | --- |
| [<Tableur>.AjouteFeuille](1000023712.md) | Ajoute une feuille de calcul dans un champ Tableur présent dans une fenêtre. |
| [<Tableur>.AjouteFormule](1000023713.md) | Ajoute une formule de calcul dans un champ Tableur présent dans une fenêtre. |
| [<Tableur>.AjouteImage](1000023714.md) | Ajoute une image dans la feuille en cours d'un champ Tableur. |
| [<Tableur>.AjouteLien](1410090430.md) | Crée un lien dans une cellule d'un champ Tableur. Le texte de la cellule devient le texte du lien. |
| [<Tableur>.AjouteNom](1000023715.md) | Spécifie un nom pour identifier une cellule d'un champ Tableur. |
| [<Tableur>.AutoriseProcédure](1000023716.md) | Autorise l'utilisation d'une fonction/procédure WLangage dans une formule d'un champ Tableur. |
| [<Tableur>.CadreSélection](1000023717.md) | Modifie le cadre des cellules sélectionnées dans un champ Tableur présent dans une fenêtre. |
| [<Tableur>.ChampFormule](1000023718.md) | Permet d'utiliser un champ pour réaliser une barre de formule personnalisée pour le champ Tableur. |
| [<Tableur>.Charge](1000023719.md) | Charge un fichier au format XLSX dans un champ Tableur présent dans une fenêtre. |
| [<Tableur>.Cherche](1000023720.md) | Recherche une valeur dans les cellules d'un champ Tableur présent dans une fenêtre. |
| [<Tableur>.DébutModification](1000023721.md) | Signale le début du regroupement d'un ensemble d'opérations sur un champ Tableur en un seul événement (gestion du "undo/redo"). |
| [<Tableur>.DéfusionneCellule](1410089570.md) | Supprime la fusion de cellule pour la cellule spécifiée ou pour la cellule sélectionnée dans un champ Tableur. |
| [<Tableur>.DéplaceFeuille](1410087262.md) | Déplace une feuille de calcul dans un champ Tableur présent dans une fenêtre. |
| [<Tableur>.Ferme](1000023722.md) | Ferme le document XLSX ouvert précédemment par la fonction [<Tableur>.Charge](1000023719.md). |
| [<Tableur>.Fige](1000023723.md) | Permet de figer l'affichage d'une ligne ou d'une colonne dans un champ Tableur. |
| [<Tableur>.FinModification](1000023724.md) | Signale la fin du regroupement d'un ensemble d'opérations sur un champ Tableur en un seul événement (gestion du "undo/redo"). |
| [<Tableur>.FusionneCellule](1000026322.md) | Fusionne les cellules spécifiées ou les cellules sélectionnées dans un champ Tableur. |
| [<Tableur>.InsèreColonne](1000023725.md) | Insère une colonne vide dans un champ Tableur présent dans une fenêtre. |
| [<Tableur>.InsèreFeuille](1000023726.md) | Insère une feuille de calcul dans un champ Tableur présent dans une fenêtre. |
| [<Tableur>.InsèreLigne](1000023727.md) | Insère une ligne vide dans un champ Tableur présent dans une fenêtre. |
| [<Tableur>.ListeCommentaire](1410090614.md) | Liste tous les commentaires de la feuille courante d'un champ Tableur. |
| [<Tableur>.Position](1000023728.md) | Affiche la cellule spécifiée dans un champ Tableur présent dans une fenêtre:   - soit la zone visible du champ Tableur est déplacée pour afficher la cellule. - soit la cellule est affichée en haut à gauche de la zone visible du champ Tableur. |
| [<Tableur>.RecalculeTout](1000023729.md) | Recalcule toutes les formules d'un champ Tableur présent dans une fenêtre (y compris les formules utilisant des fonctions/procédures WLangage). |
| [<Tableur>.RécupèreFormule](1000023730.md) | Récupère la formule de calcul d'une cellule présente dans un champ Tableur d'une fenêtre. |
| [<Tableur>.RécupèreFusion](1000023731.md) | Permet de savoir si une cellule est fusionnée avec d'autres cellules et d'obtenir le nom des cellules fusionnées. |
| [<Tableur>.RécupèreSélection](1000023732.md) | Récupère la liste des cellules sélectionnées dans un champ Tableur présent dans une fenêtre. |
| [<Tableur>.Remplace](1000023898.md) | Recherche et remplace une valeur dans un champ Tableur. |
| [<Tableur>.RestaurePositionEtSélection](1000023733.md) | Restaure :   - la position de l'ascenseur d'un champ Tableur, - la feuille en cours, - le ou les éléments sélectionnés dans la feuille en cours du champ Tableur.  Ces éléments ont été précédemment sauvegardés par la fonction [<Tableur>.SauvePositionEtSélection](1000023735.md). |
| [<Tableur>.Sauve](1000023734.md) | Sauve le contenu d'un champ Tableur dans un fichier au format XLSX. |
| [<Tableur>.SauvePositionEtSélection](1000023735.md) | Sauve :   - la position de l'ascenseur d'un champ Tableur pour la feuille en cours, - la feuille en cours dans le champ Tableur, - le ou les éléments sélectionnés dans le champ Tableur pour la feuille en cours. |
| [<Tableur>.SelectCommentaire](1410090615.md) | Permet de :   - savoir si un commentaire est sélectionné dans un champ Tableur, - sélectionner ou désélectionner un commentaire dans un champ Tableur. |
| [<Tableur>.SelectFeuille](1000023736.md) | Sélectionne une feuille de calcul (identifiée par son nom) dans un champ Tableur. |
| [<Tableur>.SelectMoins](1000023737.md) | Désélectionne une ou plusieurs cellules dans un champ Tableur présent dans une fenêtre. |
| [<Tableur>.SelectPlus](1000023738.md) | Sélectionne une ou plusieurs cellules dans un champ Tableur présent dans une fenêtre. |
| [<Tableur>.StyleSélection](1000023739.md) | Renvoie ou modifie le style des cellules sélectionnées dans un champ Tableur présent dans une fenêtre. |
| [<Tableur>.SupprimeColonne](1000023740.md) | Supprime une colonne dans un champ Tableur. |
| [<Tableur>.SupprimeFeuille](1000023741.md) | Supprime une feuille de calcul dans un champ Tableur présent dans une fenêtre. |
| [<Tableur>.SupprimeLigne](1000023742.md) | Supprime une ligne dans un champ Tableur. |
| [<Tableur>.SupprimeTout](1000023743.md) | Supprime toutes les données d'un champ Tableur présent dans une fenêtre (cellules, formules, taille et mises en forme d'entêtes). |
| [<Tableur>.TrieSélection](1000023744.md) | Trie les valeurs sélectionnées dans un champ Tableur. |
| [<Tableur>.TypeEtMasqueSélection](1000023745.md) | Renvoie ou modifie le type et le masque des cellules sélectionnées dans un champ Tableur. |
