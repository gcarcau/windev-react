# Coché (Propriété)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android)

La propriété **Coché** permet de savoir si un élément est coché ou non.
Cette propriété est utilisable :

- sur les options de menu et les lignes d'un champ Arbre. Pour plus de détails, consultez [la propriété Cochée sur les champs](2510019.md).
- sur une variable de type [docElémentInterrupteur](1410089762.md).
