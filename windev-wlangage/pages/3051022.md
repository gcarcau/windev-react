# MCIRécupère (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Renvoie le dernier résultat de la commande MCI exécutée avec la fonction [MCIExécute](3051005.md).

## Exemple

```wlangage
// Dernier résultat de la fonction MCIExécute
ResRécupère = MCIRécupère()
```

## Syntaxe

```wlangage
<Résultat> = MCIRécupère()
```

`<Résultat>` *Chaîne de caractères*
> - Résultat retourné par la fonction [MCIExécute](3051005.md),
> - Chaîne vide ("") si la fonction [MCIExécute](3051005.md) n'a retourné aucun résultat.

**Composante : wd300std.dll**
