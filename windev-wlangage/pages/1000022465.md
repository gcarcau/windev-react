# <Carte>.SupprimeItinéraire (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Supprime un itinéraire d'un champ Carte.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, WEBDEV - Code Navigateur, Android)_ // Affiche un itinéraire automobile entre les deux adresses spécifiées
sID est une chaîne
sID = CARTE_ChampCarte.AjouteItinéraire(["Place de la comédie, Montpellier", ...
 "Avenue des Champs Elysées, Paris"], itinéraireAutomobile)
// Suppression de l'itinéraire
CARTE_ChampCarte.SupprimeItinéraire(sID)

```wlangage
// Affiche un itinéraire correspondant à la liste de positions géographiques spécifiées
posDépart est une géoPosition
posDépart.Latitude = XXX
posDépart.Longitude = XXX
posArrivée est une géoPosition
posArrivée.Latitude = XXX
posArrivée.Longitude = XXX
sID est une chaîne
sID = CARTE_ChampCarte.AjouteItinéraire([posDépart, posArrivée])
// Suppression de l'itinéraire
CARTE_ChampCarte.SupprimeItinéraire(sID)
```

## Syntaxe

```wlangage
<Résultat> = <Champ Carte>.SupprimeItinéraire(<Identifiant>)
```

`<Résultat>` *Booléen*
> - Vrai si l'itinéraire a été supprimé,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler.
`<Identifiant>` *Chaîne de caractères*
> Identifiant de l'itinéraire à supprimer. Cet identifiant correspond à la valeur retournée par la fonction [<Carte>.AjouteItinéraire](1000022420.md).

## Remarques

Pour supprimer tous les itinéraires ajoutés sur un champ Carte, utilisez la fonction [<Carte>.SupprimeTout](1000022472.md).
