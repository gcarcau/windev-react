# SablierRéseau (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

Affiche ou masque une jauge sans fin :

- dans la barre de statut d'une application iOS.
- dans la barre de titre des fenêtres d'une application Android.

## Exemple

```wlangage
// Affichage de la jauge
SablierRéseau(Vrai)
// Traitement
...
Multitâche(-1)
...
// Masquage de la jauge
SablierRéseau(Faux)
```

## Syntaxe

```wlangage
SablierRéseau(<Activation>)
```

`<Activation>` *Booléen*
> - Vrai pour activer la jauge sans fin,
> - Faux pour masquer la jauge sans fin.

## Remarques

### Fonctionnement sous Android
Si la fonction **SablierRéseau** est appelée avec le paramètre d'activation à Vrai, la jauge sans fin sera affichée dans la barre de titre (ou l'ActionBar) de toutes les fenêtres ouvertes de l'application ainsi que toutes les prochaines fenêtres ouvertes jusqu'au prochain appel de la fonction **SablierRéseau** avec le paramètre d'activation à Faux.
Remarques :

- Lors de l'exécution de traitements longs, il est conseillé d'ajouter des appels à la fonction [Multitâche](3015004.md) dans le code afin de laisser le temps à la jauge de rafraîchir son affichage.
- Il est également possible d'utiliser la fonction [Sablier](3071011.md). Dans ce cas, la jauge sans fin s'affiche dans une fenêtre spécifique.
- L'affichage de la jauge dans les ActionBar utilisant le thème Material Design n'est pas supporté par le système. La fonction **SablierRéseau** sera sans effet si la fenêtre contient un champ ActionBar et si l'option "Appliquer le thème Material design aux champs natifs et aux fenêtres Info/Erreur/Dialogue" a été cochée dans les options de la configuration Android.
