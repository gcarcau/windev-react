# Genérateur de gabarits WINDEV Mobile : Personnaliser les éléments

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Le générateur de gabarits WINDEV Mobile permet de générer les fichiers nécessaires à la création d'un gabarit personnalisé WINDEV Mobile.
Il est possible de personnaliser les différents éléments générés :

- Images : ces images seront utilisées dans le style des champs.
- Modèles de fenêtres.
- Modèles d'états.

Cette page d'aide présente les principales images utilisées ainsi que les modifications pouvant être effectuées.

## Images du gabarit

### Conseils

- L'extension des fichiers image peut être modifiée. Il est possible d'utiliser les formats suivants : JPG, PNG et GIF.
- Si vous souhaitez qu'une image ne soit pas utilisée dans un champ, il vous suffit de la rendre transparente et de dimension 1x1 pixel. Dans ce cas, l'image doit être au format PNG. Ainsi, lors de la génération du gabarit, l'image ne sera pas générée.
- Pour être certain d'un bon affichage des images dans vos gabarits, ne pas modifier les dimensions des fichiers.

## Modèles de fenêtres

Les modèles de fenêtres sont placés dans le répertoire "Modele" du projet source du gabarit.
Le modèle de fenêtres disponible est Modele.wdt, modèle général de vos fenêtres. Ce modèle permet de définir le fond de vos fenêtres (couleur de fond, image de fond, ...).

Pour personnaliser les modèles de fenêtres, il suffit de les ouvrir directement sous WINDEV Mobile. Il est conseillé d'ouvrir ces éléments dans WINDEV Mobile **hors projet** (par exemple, réalisez un Drag and Drop de l'élément vers WINDEV Mobile).

## Modèles d'états

Les modèles d'états sont placés dans le répertoire "Modele" du projet source du gabarit. Les différents modèles d'états disponibles sont :

- Modele_Etats.wte : Modèle général des états.
- Modele_Etiquette.wte : Modèle utilisé pour les états de type Etiquette.
- Modele_Mailing.wte : Modèle utilisé pour les états de type Mailing.

Pour personnaliser les modèles d'états, il suffit de les ouvrir directement sous WINDEV Mobile. Il est conseillé d'ouvrir ces éléments dans WINDEV Mobile **hors projet** (par exemple, réalisez un Drag and Drop de l'élément vers WINDEV Mobile).
