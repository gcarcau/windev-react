# Le champ Lien

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

## Champ Lien

Le champ Lien permet de :

- créer un lien dans une page HTML .
- créer un lien dans un état imprimé au format HTML.

## Champ Lien dans une page

> _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur)_ Le champ Lien permet une connexion entre un texte et un élément de la page, une page, une ancre, une adresse email, ...Le lien est mis en relief grâce à sa couleur et à son soulignement. L'internaute active le lien en cliquant dessus.

### Créer un champ Lien
Pour créer un champ de type Lien :

1. Sous le volet "Création", dans le groupe "Champs usuels", cliquez sur "Lien".
2. Cliquez dans la page à la position où le champ doit être créé. Le champ apparaît en création.

Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ.

## Champ Lien dans un état

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes)_ PrésentationLe champ "Lien URL" permet d'insérer des liens dans un état. Il est ainsi possible d'insérer par exemple :un lien vers une adresse email,un lien vers une adresse de site Internet,...Le champ "Lien URL" est actif uniquement si l'état est imprimé dans un fichier HTML. Dans les autres cas, le champ "Lien URL" est visible mais inactif.

### Créer un champ Lien URL
Pour créer un champ de type Lien URL :

1. Sous le volet "Création", dans le groupe "Interactions", cliquez sur "Lien".
2. Cliquez dans l'état à la position où le champ doit être créé. Le champ apparaît en création.

Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes)_ Action associée au champ Lien présent dans l'étatL'action associée au champ "Lien" est défini dans la fenêtre de description du champ. Cette action peut provenir :soit d'une rubrique.soit d'une adresse URL. Dans ce cas, le bouton "..." situé à droite du champ "URL (fixe)" permet de définir une action spécifique.Il est ainsi possible de :afficher une page d'un site,se connecter à un serveur FTP,télécharger un fichier,d'envoyer un mail, ...Remarques : Toutes ces opérations sont également réalisables par programmation.La copie d'un champ Lien présent dans l'éditeur d'états colle la balise ainsi que le texte et le champ dans le presse-papiers. Cela permet par exemple de copier directement le lien dans une page HTML.
