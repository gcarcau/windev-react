# telNumérote (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Permet de simuler l'utilisation des touches du clavier téléphonique.

## Exemple

```wlangage
telNumérote("123456789ABCD*#", LISTE_ListeAppel[LISTE_ListeAppel])
```

## Syntaxe

```wlangage
<Résultat> = telNumérote(<Suite de touches> [, <Identifiant de l'appel>])
```

`<Résultat>` *Booléen*
> - Vrai si le la numérotation a été effectuée,
> - Faux dans le cas contraire.
`<Suite de touches>` *Chaîne de caractères*
> Suite de touches à simuler.
`<Identifiant de l'appel>` *Entier optionnel*
> Identifiant de l'appel à manipuler. Cet identifiant est connu dans la procédure WLangage appelée par la fonction [telDémarreDétectionAppel](3076029.md). Si ce paramètre n'est pas spécifié, l'appel en cours est manipulé.

## Remarques

### Limitation
Il n'est pas possible d'appeler la fonction **telNumérote** dans la procédure de détection d'appels (définie grâce à la fonction [telDémarreDétectionAppel](3076029.md)).

> _(WINDEV, Code Utilisateur (MCU))_ Configuration nécessaireLes fonctions de téléphonie utilisent la technologie TAPI 2.0 et/ou la technologie TAPI 3.1. Ces technologies sont utilisables sur tous les systèmes.

**Composante : wd300com.dll**
