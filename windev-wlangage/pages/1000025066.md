# <Source>.StatHeure (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Renvoie l'heure de la dernière mise à jour des statistiques d'index. Ces statistiques ont été réalisées grâce aux fonctions [<Source>.StatCalcule](1000025064.md) ou [<Source>.Réindexe](1000025060.md).

## Exemple

```wlangage
// Réalisation de statistiques sur la clé NomCli du fichier de données Client
Client.StatCalcule(NomCli)

// Connaître l'heure de réalisation de ces statistiques
ResHeure = Client.StatHeure()
Info("Les statistiques effectuées sur la rubrique NomCli ont été réalisées à : " + HeureVersChaîne(ResHeure))
```

## Syntaxe

```wlangage
<Résultat> = <Source>.StatHeure([<Rubrique clé>])
```

`<Résultat>` *Chaîne de caractères*
> Heure au format HHMMSS (HH correspond aux heures, MM aux minutes et SS aux secondes). L'heure renvoyée est au format UTC (Universal Time Coordinated).
`<Source>` *Type correspondant à la source spécifiée*
> Nom du fichier de données manipulé.
`<Rubrique clé>` *Chaîne de caractères optionnelle*
> Nom de la rubrique clé sur laquelle les statistiques ont été effectuées. Si ce nom n'est pas spécifié, la fonction **<Source>.StatHeure** manipule la dernière rubrique clé utilisée par la dernière fonction de gestion HFSQL (fonction commençant par la lettre H).

## Remarques

- Dans les fichiers de données HFSQL, seules les rubriques clés peuvent faire l'objet d'un calcul de statistiques.

**Composante : wd300hf.dll**
