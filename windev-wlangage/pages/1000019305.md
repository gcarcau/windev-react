# HClusterParamètre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Lit et modifie les paramètres d'un cluster HFSQL.

## Exemple

```wlangage
// Lecture du nom DNS du cluster
sDNS est une chaîne
sDNS = HClusterParamètre("clustermanager.mondomaine.com", "secret", hCPDNS)
InfoConstruit("Utilisez <%1> comme adresse de serveur dans vos applications" + ...
    " clientes pour vous connecter au cluster.", sDNS)
```

## Syntaxe

#### Connaître la valeur d'un paramètre du cluster

```wlangage
<Résultat> = HClusterParamètre(<Coordinateur> , <Mot de passe> , <Paramètre>)
```

`<Résultat>` *Chaîne de caractères*
> Valeur du paramètre.
`<Coordinateur>` *Chaîne de caractères*
> Nom DNS de la machine où se trouve le coordinateur du cluster.
`<Mot de passe>` *Chaîne de caractères ou Chaîne secrète*
> Mot de passe permettant de se connecter au coordinateur. Ce mot de passe a été fourni lors de l'[installation du cluster](1000019031.md).
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).
`<Paramètre>` *Constante de type Entier*
> Paramètre à lire. Les valeurs possibles sont :
>
>
> | *hCPDNS* | Nom DNS du cluster. Ce paramètre est purement informatif. **Remarque** : Il est important de ne pas confondre :   - le nom désignant le cluster (correspondant à la valeur associé à ce paramètre) : nom à utiliser pour accéder aux bases de données du cluster. - le nom désignant le coordinateur (utilisé dans le paramètre <Coordinateur>) : nom (DNS) de la machine sur laquelle a été installé le coordinateur du cluster. - le nom désignant le noeud (non utilisé par cette fonction) : nom (DNS) de la machine sur laquelle a été installé le nouveau serveur HFSQL. |
> | --- | --- |
> | *hCPPortClient* | Port d'écoute des connexions clientes. **Remarque** : La modification de ce paramètre sera prise en compte au prochain redémarrage du cluster. |
> | Nouveauté 2025 *hCPTélémétrieActive* | Paramètre <Active de la section TELEMETRY du fichier clustermanager.conf Configuration de la transmission des données en vue de l'amélioration du cluster HFSQL. Valeur :  - 1, si lors de l'installation du cluster HFSQL, la transmission des données (télémétrie) a été activée, - 0, si lors de l'installation du cluster HFSQL, la transmission des données (télémétrie) a été refusée, - une autre valeur signifie qu'aucun choix n'a été fait lors de l'installation concernant l'usage de la télémétrie. La question sera reposée lors de la prochaine installation du cluster HFSQL.  **Remarque** : Si la section "TELEMETRY" n'existe pas dans le fichier clustermanager.conf, la transmission des données relatives à l'utilisation du produit n'est pas activée pour le cluster HFSQL. |

#### Modifier la valeur d'un paramètre du cluster

```wlangage
<Résultat> = HClusterParamètre(<Coordinateur> , <Mot de passe> , <Paramètre> [, <Nouvelle valeur>])
```

> Ancienne valeur du paramètre.
`<Coordinateur>` *Chaîne de caractères*

> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).
`<Paramètre>` *Constante de type Entier*
> Paramètre à modifier. Les valeurs possibles sont :
>
>
> | *hCPDNS* | Nom DNS du cluster. Ce paramètre est purement informatif. **Remarque** : Il est important de ne pas confondre :   - le nom désignant le cluster (correspondant à la valeur associé à ce paramètre) : nom à utiliser pour accéder aux bases de données du cluster. - le nom désignant le coordinateur (utilisé dans le paramètre <Coordinateur>) : nom (DNS) de la machine sur laquelle a été installé le coordinateur du cluster. - le nom désignant le noeud (non utilisé par cette fonction) : nom (DNS) de la machine sur laquelle a été installé le nouveau serveur HFSQL. |
