# Minor (Propriété)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **Minor** permet de connaître et de modifier le numéro Minor d'une balise Beacon. Cette propriété est utilisable sur :

- une variable de type [beaconInfoDétection](1000023109.md).
- une variable de type [beaconGroupe](1000023105.md).
