# HTransactionListe (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Liste les transactions en cours ou interrompues sur le serveur de la connexion spécifiée.
> _(Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)_ La gestion des transactions est disponible uniquement pour les bases de données HFSQL Client/Serveur.

## Exemple

```wlangage
MaConnexion est une Connexion

// Récupérer la liste des transactions
sListeTrs est une chaîne = HTransactionListe(MaConnexion)
```

## Syntaxe

```wlangage
<Résultat> = HTransactionListe(<Connexion>)
```

`<Résultat>` *Chaîne de caractères*
> Liste des transactions en cours ou interrompues sur le serveur associé à la connexion. Cette liste est de la forme :
>
>
> ```wlangage
> <Identifiant de la transaction> + TAB + <Nom de l'application> + TAB + <Poste Client> + TAB + <Valeur du HPoste> + TAB + <Etat de la transaction> + RC + ...
> ```
>
>
> Le paramètre <Etat de la transaction> correspond à 0 pour une transaction en cours, et 1 pour une transaction interrompue.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion pour laquelle les transactions doivent être listées. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).

**Composante : wd300hf.dll**
