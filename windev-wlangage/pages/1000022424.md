# DocUndo (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Annule la dernière modification effectuée sur un document de type Traitement de texte.

## Exemple

```wlangage
// Annule la dernière action effectuée sur le document
DocUndo(TT_MonDocument)
```

## Syntaxe

```wlangage
<Résultat> = DocUndo(<Document>)
```

`<Résultat>` *Booléen*
> - Vrai si la dernière modification a été annulée,
> - Faux dans le cas contraire.
`<Document>` *Nom de champ ou variable de type Document*
> Document à manipuler. Ce document peut correspondre à :
>
> - une variable de type [Document](1000022461.md).
> - un champ Traitement de texte.

**Composante : wd300mdl.dll**
