# TitreEnCours (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Modifie le titre de la fenêtre en cours (connu par la fonction [FenEnCours](3038033.md)).
**Rappel** : Par défaut, le titre de la fenêtre est celui défini sous l'éditeur.

## Exemple

```wlangage
// Remplacer le titre de la fenêtre en cours
TitreEnCours(gFond(RougeClair) + gStylo(Noir) + "Modification d'une fiche client")
```

```wlangage
// Modifier le titre de la fenêtre en cours
// Ajoute "en cours"
TitreEnCours(EOT + gFond(RougeClair) + gStylo(Noir) + " en cours")
```

## Syntaxe

```wlangage
TitreEnCours(<Nouveau titre de la fenêtre>)
```

`<Nouveau titre de la fenêtre>` *Chaîne de caractères*
> Nouveau titre de la fenêtre en cours.
>
> - Si la constante EOT est précisée, le nouveau titre sera ajouté au titre existant.
> - Il est possible d'utiliser dans cette chaîne la fonction [gFond](3029037.md) pour modifier la couleur de fond, la fonction [gStylo](3029039.md) pour modifier la couleur du texte, etc. Pour plus de détails, consultez les remarques.

## Remarques

### Titre des boîtes de dialogues
Les fenêtres ouvertes par les fonctions [Avertissement](3021009.md), [Confirmer](3021007.md), [Dialogue](3021015.md), [Erreur](3021013.md), [ErreurInfo](3013008.md), [Info](3021011.md), [OKAnnuler](3021004.md) ou [OuiNon](3021005.md) ont le même titre que la fenêtre précédente.
Pour modifier le titre de la prochaine fenêtre à ouvrir, utilisez la fonction [TitreSuivant](3038043.md).

> _(WINDEV)_ Titre des fenêtres détouréesSur les fenêtres détourées, la fonction TitreEnCours permet également de modifier le titre de la fenêtre. Cependant, ce titre n'est pas affiché dans la fenêtre.Si vous avez utilisé un gabarit détouré, le titre de la fenêtre est affiché dans un champ de type libellé. Le contenu de ce champ n'est pas pris en compte par la fonction TitreEnCours. Il est nécessaire de le modifier spécifiquement.

> _(WINDEV, Etats et Requêtes, Code Utilisateur (MCU))_ Présentation du titreLes fonctions de manipulation des chaînes graphiques (fonctions commençant par "g") permettent de :ajouter des dessins au titre,modifier la mise en forme d'un titre (couleur de fond, couleur de texte, etc.) avec les fonctions gFond et gStylo.Par exemple : pour modifier la couleur de texte et la couleur de fond d'un titre :

TitreEnCours(EOT + gFond(RVB(0, 255, 255)) + gStylo(RVB(255, 0, 0)) + "Test de couleur")

Cas particulier sous Windows Vista et 7 : Les fenêtres utilisant le look "Aero system" ne peuvent pas avoir de titre graphique : la partie graphique est ignorée. Si "Aero" n'est pas actif, le titre graphique sera affiché normalement.

### Équivalence
Le code suivant :

```wlangage
TitreEnCours(<Nouveau titre de la fenêtre>)
```

est équivalent à la propriété [Titre](2510090.md) :

```wlangage
MaFenêtre.Titre = <Nouveau titre de la fenêtre>
```

> _(WINDEV, Etats et Requêtes, Java, Code Utilisateur (MCU))_ Fenêtre iconiséeQuand une fenêtre est iconisée, le titre de cette fenêtre apparaît à côté de l'icône dans la barre de tâches.
