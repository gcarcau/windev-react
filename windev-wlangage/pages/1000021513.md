# Fonctions de gestion des fichiers XLS (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Nouveauté 2025

> _(Android)_ La plupart de ces fonctions sont désormais disponibles pour les applications Android.

> _(Widget Android)_ La plupart de ces fonctions sont désormais disponibles en mode Widget Android.

> _(iPhone/iPad)_ La plupart de ces fonctions sont désormais disponibles pour les applications iPhone/iPad.

Les différentes fonctions de gestion des fichiers XLS (syntaxe préfixée) sont les suivantes :

| [<Variable xlsDocument>.AjouteFeuille](1000021509.md) | Ajoute ou insère une nouvelle feuille dans un document Excel. |
| --- | --- |
| [<Variable xlsDocument>.DéfusionneCellule](1410089571.md) | Supprime la fusion de la cellule spécifiée. |
| [<Variable xlsDocument>.Ferme](1000021510.md) | Ferme un fichier XLS. |
| [<Variable xlsDocument>.FusionneCellule](1410089568.md) | Fusionne les cellules spécifiées dans un document Excel. |
| [<Variable xlsDocument>.RecalculeTout](1410089739.md) | Recalcule toutes les formules d'un document Excel au format XLSX. |
| [<Variable xlsDocument>.RécupèreFusion](1410089569.md) | Permet de savoir si une cellule est fusionnée avec d'autres cellules et d'obtenir la plage des cellules fusionnées correspondante. |
| [<Variable xlsDocument>.Sauve](1000021511.md) | Sauve un document XLS. |
| [<Variable xlsDocument>.SupprimeFeuille](1000021512.md) | Supprime une feuille du document Excel. |
