# ImageFenêtre (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Crée l'image de la fenêtre spécifiée dans un fichier BMP.
**Attention** : L'image de la fenêtre correspond à la fenêtre telle qu'elle apparaît sous l'éditeur de fenêtres. Pour réaliser une image de la fenêtre en exécution, utilisez la fonction [dCopieImageFenêtre](1000019912.md) et le type [Image](1000019650.md).

## Exemple

```wlangage
// Création des images de la fenêtre "FEN_SaisieClient"
// dans le fichier "C:\Images\SaisieClient"
Res = ImageFenêtre(FEN_SaisieClient, "C:\Images\SaisieClient")
```

## Syntaxe

```wlangage
<Résultat> = ImageFenêtre(<Fenêtre> , <Fichier image>)
```

`<Résultat>` *Entier*
> Nombre d'images créées. Pour la fenêtre spécifiée, la fonction **ImageFenêtre** crée autant d'images (fichiers BMP) que la fenêtre possède de plans. Si la fenêtre possède des onglets, une seule image est créée.
`<Fenêtre>` *Nom de fenêtre*
> Fenêtre à manipuler :
>
> - Nom de la fenêtre,
> - Chaîne de caractères contenant le nom et chemin complet de la fenêtre à manipuler.
>
> Cette fenêtre peut être fermée.
`<Fichier image>` *Chaîne de caractères*
> Nom et chemin complet (ou relatif) du fichier résultat (sans préciser l'extension). Un chemin de type UNC peut être utilisé.
> Si un seul fichier image est créé, son extension sera ".BMP".
>
> Si plusieurs fichiers images sont créés, ils auront pour extension ".B01", ".B02", ...

## Remarques

L'image est créée avec les informations système en cours : couleurs, polices, ...

**Composante : wd300obj.dll**
