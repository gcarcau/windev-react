# Fonctions de débogage

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

Les différentes fonctions de débogage sont les suivantes :

| [dbgActiveAssertion](3014021.md) | Active ou désactive la programmation défensive. |
| --- | --- |
| [dbgActiveAudit](1000018835.md) | Active l'audit dynamique par programmation. |
| [dbgActiveLog](1000017137.md) | Active par programmation le log d'exécution. |
| [dbgAssertion](3014022.md) | Permet de trouver et de signaler les erreurs potentielles grâce à un mode de programmation défensif. |
| [dbgConnecte](1000024735.md) | Permet de connecter un débogueur à distance sur une application, un service, un Webservice, ... |
| [dbgDébutDiffMémoire](1000018840.md) | Débute une opération de différence de la mémoire utilisée par l'application. |
| [dbgDébutEnregistrement](1000017160.md) | Démarre l'enregistrement d'un scénario de test (également appelé scénario de reproduction). |
| [dbgEcritCommentaireAudit](1000018839.md) | Ecrit un commentaire dans l'audit dynamique en cours. |
| [dbgEcritWarningAudit](1000018838.md) | Ecrit un warning d'exécution personnalisé dans l'audit dynamique. |
| [dbgErreur](1000020526.md) | Provoque :   - une assertion lors du test de l'élément ou du projet (mode Go). - une erreur en mode test automatique. |
| [dbgEtatAudit](1000018836.md) | Récupère et modifie l'état de l'audit dynamique. |
| [dbgEtatLog](1000017138.md) | Renvoie et modifie l'état du log d'exécution. |
| [dbgFinDiffMémoire](1000018841.md) | Sauve un dump mémoire contenant uniquement les ressources mémoire qui ont été allouées et qui n'ont pas encore été libérées depuis l'appel précédent de la fonction [dbgDébutDiffMémoire](1000018840.md). |
| [dbgFinEnregistrement](1000017161.md) | Arrête l'enregistrement du scénario en cours. |
| [dbgInfo](3014024.md) | Récupère une information de débogage. |
| [dbgOptionAudit](1000018837.md) | Récupère ou modifie les options de l'audit dynamique. |
| [dbgOptionLog](1000017136.md) | Récupère ou modifie les options du log d'exécution. |
| [dbgSauveDumpDébogage](1000018834.md) | Sauve un dump de débogage de l'application. |
| [dbgSauveDumpMémoire](1000018852.md) | Sauve un dump de la mémoire utilisée par l'application. |
| [dbgSortieStandard](3014020.md) | Écrit une information dans le flux de sortie standard "stdout" (également appelé "console"). |
| [dbgSurErreur](1000020722.md) | Définit la procédure WLangage qui sera appelée en cas d'erreur détectée par une fonction de la famille dbgVérifieXXXX. |
| [dbgVérifieDifférence](1000019777.md) | Vérifie si les expressions spécifiées sont différentes en programmation défensive et en mode test automatique. |
| [dbgVérifieEgalité](1000019776.md) | Vérifie si les expressions sont égales en programmation défensive et en mode test automatique. |
| [dbgVérifieFaux](1000019781.md) | Vérifie si une expression est fausse en programmation défensive et en mode test automatique. |
| [dbgVérifieNonNull](1000019779.md) | Vérifie si l'expression n'est pas Null en programmation défensive et en mode test automatique. |
| [dbgVérifieNull](1000019778.md) | Vérifie si l'expression est Null en programmation défensive et en mode test automatique. |
| [dbgVérifieVrai](1000019780.md) | Vérifie si une expression vaut Vrai en programmation défensive et en mode test automatique. |
