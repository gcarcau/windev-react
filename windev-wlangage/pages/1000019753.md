# DroiteAGauche (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **DroiteAGauche** permet de connaître et de modifier le sens d'écriture d'un élément. Cette propriété est utilisable sur :

- un champ, une fenêtre ou un état. Pour plus de détails, consultez l'aide de la propriété [DroiteAGauche](1000017228.md).
- une variable de type [xlsDocument](1000017464.md).
- une variable de type [docParagraphe](1000022483.md).
