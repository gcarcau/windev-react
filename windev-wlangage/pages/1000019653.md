# Fonctions de gestion des Webservices

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

Les fonctions de gestion des Webservices sont les suivantes :

| [AnnuleContexteWebservice](1000019591.md) | Supprime du contexte du webservice une variable ajoutée par la fonction [DéclareContexteWebservice](1000019460.md). |
| --- | --- |
| [DéclareContexteWebservice](1000019460.md) | Permet de déclarer une liste de variables dont la valeur sera persistante entre les appels successifs à un Webservice. |
| [WebserviceAdresseIPClient](1000019641.md) | Renvoie l'adresse IP du poste utilisant et appelant le Webservice. |
| [WebserviceEcritCodeHTTP](1000022785.md) | Renseigne le code HTTP qui sera retourné à la fin de l'exécution de la fonction du Webservice REST. |
| [WebserviceEcritCodeHTTPPersonnalisé](1410087803.md) | Renseigne le code HTTP personnalisé qui sera retourné à la fin de l'exécution de la fonction du Webservice REST. |
| [WebserviceEcritEntêteHTTP](1000022788.md) | Ajoute un entête HTTP supplémentaire à une requête à un Webservice (REST ou SOAP). |
| [WebserviceEcritTypeMIME](1000022681.md) | Indique le type MIME de la réponse renvoyée par le Webservice (cas d'un appel à un Webservice REST). |
| Nouveauté Abonnement [WebserviceEnvoieMorceau](1410091271.md) | Permet dans un Webservice REST de renvoyer immédiatement au client un morceau de la réponse (avant la fin de l'exécution du point d'entrée). **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.** |
| [WebserviceLitEntêteHTTP](1000022787.md) | Lit l'entête HTTP reçu lors d'un appel à un webservice (SOAP ou REST). |
| Nouveauté 2025 [WebserviceLitTokenUtilisateur](1410090917.md) | Récupère le token d'autorisation ("access token") reçu par le webservice qui est en cours d'exécution. |
| [WebserviceParamètre](1000022786.md) | Permet de récupérer la valeur d'un paramètre lors de l'appel d'une requête d'un Webservice (SOAP ou REST). |
