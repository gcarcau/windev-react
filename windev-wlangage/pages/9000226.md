# Défilement automatique des libellés trop longs

> **Disponible :** **WINDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Un texte présent dans un champ Libellé ou dans un champ Bouton peut être plus large que la taille du champ : contenu dynamique provenant d'une base de données ou construit par programmation, message d'avertissement, validation d'action, libellé traduit dynamiquement.
Pour permettre à l'utilisateur de lire la totalité du texte, il suffit de prévoir un défilement automatique : ainsi, plus de texte tronqué !

[image: La ligne du bas est plus large que le champ, et défile pour que son contenu puisse être lu]La ligne du bas est plus large que le champ, et défile pour que son contenu puisse être lu

**Attention** : Cette fonctionnalité est disponible uniquement à partir de la version 2025 Update 1.

## Comment le faire ?

Pour permettre le défilement automatique d'un libellé trop long dans un champ Libellé ou un champ Bouton :

1. Affichez la fenêtre de description du champ.
2. Dans l'onglet "Détail", dans la zone "Libellé trop long", cochez l'option "Faire défiler le libellé".
  | Valeur | Description |
  | --- | --- |
3. L'animation correspondra automatiquement à un défilement du libellé. Si nécessaire, validez le message d'information.
4. Dans la fenêtre qui s'ouvre spécifiez les paramètres d'animation :
  - La cadence de rafraîchissement entre chaque déplacement du libellé.
  - Le nombre de pixels correspondant à un déplacement du libellé.
  - Le sens de défilement. Le libellé peut défiler :
    - de gauche à droite,
    - de droite à gauche,
    - de bas en haut,
    - de haut en bas.
  - L'animation en boucle : Si l'animation est effectuée en boucle (pour être sûr que le texte soit lu), il est possible de définir le nombre de boucles à effectuer (pour ne pas créer de point de fixation visuelle).
5. Validez la fenêtre de définition de l'animation.
6. Validez la fenêtre de description du champ.

**Remarques** :

- L'animation du libellé du champ est obligatoirement un défilement.
- Champ Libellé : Un champ Libellé peut également être animé à la création.
- Si une ellipse a été définie, elle est supprimée pendant l'animation.
- L'animation est effectuée même si le champ est grisé ou inactif.
