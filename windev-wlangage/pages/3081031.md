# XMLTypeElement (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie le type de l'élément en cours (balise ou attribut). Pour sélectionner un élément, utilisez les fonctions de recherche et de parcours XML ([XMLPremier](3081024.md), [XMLDernier](3081013.md), [XMLFils](3081012.md), ...).

## Exemple

```wlangage
XMLPremier("DocXML")
SELON XMLTypeElement("DocXML")
	CAS XMLBalise : Info(XMLNomElément("DocXML") + " est de type XMLBalise")
	CAS XMLAttribut : Info(XMLNomElément("DocXML") + " est de type XMLAttribut")
FIN
```

## Syntaxe

```wlangage
<Résultat> = XMLTypeElement(<Document XML>)
```

`<Résultat>` *Constante de type Entier*
> Type de l'élément en cours.
>
> | *XMLAttribut* | L'élément en cours est un attribut. |
> | --- | --- |
> | *XMLBalise* | L'élément en cours est une balise. |
> | *XMLErreur* | Aucun élément n'est en cours de lecture. La variable [ErreurDétectée](3087001.md) est à Vrai. |
`<Document XML>` *Chaîne de caractères*
> Nom du document XML manipulé. Ce document contient le code XML à analyser et a été créé avec la fonction [XMLDocument](3081008.md).

## Remarques

### Caractéristiques de l'élément en cours

- La valeur de l'élément en cours peut être connue avec la fonction [XMLDonnée](3081004.md).
- Le nom de l'élément en cours peut être connu avec la fonction [XMLNomElément](3081026.md).

### Fonctions XML et threads
Si votre application utilise des threads, le document XML est partagé entre tous ces threads. Pour plus de détails sur la gestion des threads, consultez [Gestion des threads](3077026.md).
