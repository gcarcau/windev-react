# Erreur

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows)

Le mot-clé **Erreur** permet de gérer les erreurs. Ce mot-clé peut correspondre :

- au mot-clé "CAS ERREUR" utilisé pour la [gestion automatique des erreurs](3034010.md).
- à la fonction **[Erreur](3021013.md)**.
- à la propriété **Erreur** utilisée sur une variable de type [sfRésultatConvertitPiste](1000018739.md).
- à la propriété **Erreur** utilisée sur une variable de type [sfRésultatDéconnecte](1000018560.md).
- à la propriété **Erreur** utilisée sur une variable de type [sfRésultatFusionne](1000018499.md).
- à la propriété **Erreur** utilisée sur une variable de type [sfRésultatRestaure](1000018526.md).
- à la propriété **Erreur** utilisée sur une variable de type [sfRésultatSauvegarde](1000018460.md).
- à la propriété **Erreur** utilisée sur une variable de type [sfRésultatSupprime](1000018546.md).
- à la propriété **Erreur** utilisée sur une variable de type [sfRésultatVideCorbeille](1000018467.md).
- Nouveauté 2025
  à la propriété **Erreur** utilisée sur une variable de type [hHistoriquePlanification](1410090764.md).
- Nouveauté SaaS
  à la propriété **Erreur** utilisée sur une variable de type [hHistoriqueRéindexation](1410091059.md).
