# EstPair (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Identifie un nombre pair.

## Exemple

```wlangage
// Nombre pair ?
ResPair = EstPair(66)     // Renvoie Vrai
ResPair = EstPair(6 + 13) // Renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = EstPair(<Nombre>)
```

`<Résultat>` *Booléen*
> - Vrai si le nombre spécifié est pair,
> - Faux dans le cas contraire.
`<Nombre>` *Expression numérique entière ou entier*
> Expression numérique entière ou entier à identifier.

## Remarques

Le chiffre zéro est considéré comme étant un chiffre pair.

**Classification Métier / UI : Code neutre**

**Composante : wd300std.dll**
