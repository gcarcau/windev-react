# Allemagne.VérifieUStIdNr (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un numéro UStIdNr (numéro d'identification d'entreprise en Allemagne).

## Exemple

```wlangage
// Test d'une variableMonNuméroUStIdNr est une chaîne = "DE262843185"Allemagne.VérifieUStIdNr(MonNuméroUStIdNr) // renvoie Vrai // Test d'un champSAI_NuméroUStIdNr = "ABC"Allemagne.VérifieUStIdNr(SAI_NuméroUStIdNr) // renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = Allemagne.VérifieUStIdNr(<Numéro à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un numéro UStIdNr valide.
> - Faux dans le cas contraire.
`<Numéro à vérifier>` *Nom de champ ou variable de type chaîne*
> Numéro UStIdNr à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.

**Composante : wd300std.dll**
