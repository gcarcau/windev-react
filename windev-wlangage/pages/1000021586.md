# Description de TâcheParallèle (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

Le type **Description de TâcheParallèle** permet de définir toutes les caractéristiques d'une tâche parallèle. Les caractéristiques de cette tâche peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
d est une Description de TâcheParallèled.Procédure = ProcédureAExécuterd.Option = tpoCopieLégèreContexteHFSQLTâcheParallèleExécute(d)
```

## Remarques

### Propriétés spécifiques à la description des variables de type Description de TâcheParallèle
Les propriétés suivantes peuvent être utilisées pour manipuler une Description de TâcheParallèle :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Option | Constante de type Entier | Options de la tâche :   - *tpoCopieLégèreContexteHFSQL* : Effectue une copie légère du contexte HFSQL courant au moment de la demande d'exécution de la tâche.   Seuls les répertoires où se trouvent les fichiers de données en HFSQL Classic et/ou les connexions en HFSQL Client/Serveur sont mémorisés. - *tpoCopieComplèteContexteHFSQL* : Effectue une copie complète du contexte HFSQL courant au moment de la demande d'exécution de la tâche.   Conseillé par exemple si la tâche doit tenir compte des positions en cours dans les fichiers et requêtes du contexte de l'appelant. - *tpoCopieDifféréeContexteHFSQL* (Valeur par défaut) : Effectue une copie légère du contexte HFSQL **lors du premier accès aux données HFSQL**. - *tpoThreadPrincipal* : Exécute la tâche dans le thread principal. |
| Paramètre | Tableau de variants | Tableau contenant les paramètres de la tâche. |
| Procédure | Procédure ou chaîne de caractères | Procédure à exécuter lors de l'exécution de la tâche parallèle. Cette propriété peut correspondre :   - à une chaîne de caractères correspondant au nom d'une procédure WLangage. - à une variable de type [Procédure](1000018907.md). |
