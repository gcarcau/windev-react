# Personnaliser les raccourcis clavier

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Les différents éditeurs de WINDEV, WEBDEV et WINDEV Mobile proposent de nombreuses options directement manipulables grâce aux raccourcis clavier.
Le plus souvent, les raccourcis clavier correspondent à des raccourcis standard, disponibles dans de nombreux logiciels, par exemple :

- Ctrl + S pour enregistrer un document,
- Ctrl + A pour sélectionner le contenu d'un document,
- Ctrl + F pour faire une recherche, etc.

WINDEV, WEBDEV et WINDEV Mobile proposent également de nombreux raccourcis correspondant à des actions spécifiques à l'éditeur manipulé.
Pour simplifier la manipulation des éditeurs et améliorer la productivité, il est possible de redéfinir la grande majorité des raccourcis par défaut en modifiant la combinaison de touches associée à une action dans l'éditeur. Il est également possible d'associer une combinaison de touches à une action n'en n'ayant pas.

Nouveauté 2025
Il est également possible de remplacer des raccourcis "historiques" par des raccourcis plus modernes, disponibles dans de nombreux logiciels.

## Afficher la fenêtre de gestion des raccourcis clavier

Pour afficher la fenêtre de gestion des raccourcis clavier :

1. Sous le volet "Accueil", dans le groupe "Environnement", déroulez "Options" et sélectionnez "Personnaliser les raccourcis clavier".
2. La fenêtre de gestion des raccourcis clavier s'affiche. Cette fenêtre affiche :
  - dans l'onglet "Commandes", les différentes options du produit, regroupées par thème. Cet onglet vous permet de personnaliser les raccourcis clavier proposés par les différents éditeurs de WINDEV, WEBDEV et WINDEV Mobile. Pour plus de détails, consultez Redéfinir les raccourcis clavier par défaut.
  - Nouveauté 2025
    dans l'onglet "Autres raccourcis", les différents raccourcis historiques pouvant être modifiés. Pour plus de détails, consultez Redéfinir les raccourcis historiques.

## Redéfinir les raccourcis clavier par défaut

L'onglet "Commandes" de la fenêtre de gestion des raccourcis clavier liste tous les raccourcis clavier modifiables :

[image: Gestion des raccourcis clavier]

Remarques :

- Il est possible de rechercher une commande ou un raccourci dans cette fenêtre.
- Si un raccourci clavier est associé à la commande, il est affiché.

### Associer une combinaison de touches à une commande
Dans la fenêtre de gestion des raccourcis clavier :

1. Cliquez sur l'icône "+".
2. Une fenêtre popup apparaît : [image: Association d'une commande à une combinaison de touches]
3. Vous pouvez :
  - soit presser une combinaison de touches : cette combinaison de touches sera détectée et associée à la commande en cours.
  - soit annuler la détection.
4. La combinaison de touches est automatiquement associée à la commande.

Remarques :

- Si une combinaison de touches existe déjà pour la commande, la nouvelle combinaison de touches est également associée à la commande.
- Si la combinaison de touches choisie existe déjà pour une autre commande, un message et affiché et un picto spécifique apparaît à coté de chaque raccourci identique. [image: Combinaison de touches existante]Ce raccourci n'est pas mémorisé. Pour forcer l'affectation du raccourci à la commande, il est nécessaire de supprimer l'association existante.

### Modifier ou supprimer la combinaison de touches associée à une commande
Dans la fenêtre de gestion des raccourcis clavier :

1. Cliquez sur le raccourci associé à une commande.
2. Une fenêtre popup apparaît : [image: Gestion des raccourcis]
3. Vous pouvez :
  - détecter la prochaine touche : la prochaine combinaison de touches sera détectée et associée à la commande en cours.
  - utiliser la combinaison par défaut (si par défaut la commande est associée à une combinaison).
  - supprimer le raccourci existant.
  - annuler l'opération.

### Autres actions possibles
Le menu contextuel des raccourcis (affichable par l'icône  ou par un clic droit sur une commande) permet de : [image: Menu contextuel]

- choisir le mode d'affichage des raccourcis clavier. Il est possible d'afficher tout, uniquement les commandes avec raccourci, uniquement les raccourcis personnalisé.
- importer / exporter le fichier de configuration des raccourcis clavier (sous forme de fichier ".ini").
- réinitialiser la liste des raccourcis, afin de revenir à la liste originale des raccourcis clavier.
Nouveauté 2025

## Redéfinir les raccourcis historiques de l'éditeur

L'onglet "Autres raccourcis" de la fenêtre de gestion des raccourcis clavier propose de redéfinir les raccourcis "historiques".
[image: Gestion des raccourcis historiques]

Ces raccourcis concernent principalement

- La duplication de la sélection par Drag and Drop.
  Pour effectuer cette manipulation, il suffit de sélectionner le champ voulu, de commencer le Drag and Drop puis d'appuyer sur la touche (Alt ou Ctrl).
- Le déplacement orthonormé de la sélection.
  Pour effectuer cette manipulation, il suffit de déplacer le champ par Drag and Drop puis d'appuyer sur la touche (Alt ou Ctrl) : le déplacement du champ sera effectué uniquement selon un repère orthonormé.

Il suffit de cliquer sur l'interrupteur "Usuel" pour activer les nouveaux raccourcis.
