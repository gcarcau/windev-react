# NouvelEnregistrement (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **NouvelEnregistrement** permet de savoir si l'enregistrement est un nouvel enregistrement ou provient du fichier de données.

## Exemple

```wlangage
// Savoir si l'enregistrement vient d'être saisi
SI Client.NouvelEnregistrement = Vrai ALORS
	Info("Cet enregistrement vient d'être saisi")
FIN
```

## Syntaxe

#### Savoir si l'enregistrement est nouveau

```wlangage
<Résultat> = <Fichier de données>.NouvelEnregistrement
```

`<Résultat>` *Booléen*
> - Vrai si l'enregistrement est nouveau (la fonction [HRAZ](3044118.md) a été utilisée),
> - Faux dans le cas contraire.
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données manipulé.

## Remarques

Par défaut, la propriété **NouvelEnregistrement** est à Vrai. Cette propriété est également à Vrai si la fonction [HRAZ](3044118.md) a été utilisée.
Elle est remise à Faux lors de l'appel de l'une des fonctions suivantes :

- [HAjoute](3044147.md).
- [HEcrit](3044092.md).
- [HLit](3044047.md).
- [HLitDernier](3044140.md).
- [HLitPrécédent](3044048.md).
- [HLitPremier](3044051.md).
- [HLitRecherche](3044050.md).
- [HLitRecherchePremier](3044036.md).
- [HLitSuivant](3044037.md).
- [HModifie](3044042.md).
- [HRaye](3044121.md).
- [HRetourPosition](3044137.md).
- [HSupprime](3044018.md).
- [POUR TOUT Fichier](1510013.md).

Remarque : L'affectation d'une variable de type [Enregistrement](1000020962.md) à un fichier modifie également la valeur de la propriété **NouvelEnregistrement**.
