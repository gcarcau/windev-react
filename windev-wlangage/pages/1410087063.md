# 1. RAD (Rapid Application Development)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU))

| [Page précédente](1410087062.md) | [Sommaire](1410087098.md) | [Page suivante](1410087064.md) |
| --- | --- | --- |

Le RAD (Rapid Application Development) permet de créer des fenêtres à partir :

- de l'analyse liée au projet,
- des patterns RAD standard ou personnalisés,
- des gabarits.

En génération RAD, les fenêtres générées contiennent tout le code nécessaire à leur fonctionnement. Ces fenêtres peuvent être testées immédiatement, avec les données présentes sur le poste de développement.
