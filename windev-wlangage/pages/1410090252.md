# EditeurCodeDupliqueLigne (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur)

Duplique la ligne courante dans le champ Editeur de code.
Il est également possible de dupliquer la ligne courante dans le champ Editeur de code via le raccourci Ctrl + D.

Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.

## Exemple

```wlangage
// Duplique la ligne en cours dans le champ Éditeur de code
EditeurCodeDupliqueLigne(EDCODE_Exemple)
```

## Syntaxe

```wlangage
EditeurCodeDupliqueLigne(<Champ Editeur de code>)
```

`<Champ Editeur de code>` *Nom de champ*
> Nom du champ Editeur de code à manipuler.
