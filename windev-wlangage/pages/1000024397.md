# <Traitement de texte>.Undo (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

Annule la dernière modification effectuée sur un champ Traitement de texte.

## Exemple

```wlangage
// Annule la dernière action effectuée sur le champ
TT_MonDocument.Undo()
```

## Syntaxe

```wlangage
<Résultat> = <Champ Traitement de texte>.Undo()
```

`<Résultat>` *Booléen*
> - Vrai si la dernière modification a été annulée,
> - Faux dans le cas contraire.
`<Champ Traitement de texte>` *Nom de champ*
> Nom du champ Traitement de texte à manipuler.

**Composante : wd300mdl.dll**
