# Environnement de l'éditeur de fenêtres

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Les éléments importants de l'éditeur de fenêtres sont les suivants :

|  | **Ruban** Permet un accès rapide aux principales fonctionnalités de l'éditeur de fenêtres. |
| --- | --- |
|  | [**Règles d'alignement**](2022001.md) Permettent d'aligner les champs dans la fenêtre. Pour afficher les règles, utilisez le raccourci Ctrl + R. |
|  | [Barre des documents ouverts](2029012.md) Chaque document ouvert correspond à un "bouton". Un clic sur le "bouton" permet d'afficher l'élément sous l'éditeur correspondant. |
|  | **Champ sélectionné** Champ en cours de modification. Des poignées noires permettent d'identifier immédiatement le champ sélectionné. Pour plus de détails, consultez [Sélectionnez un ou plusieurs champs](2026007.md). |
|  | [**Ancrage**](2026002.md) Les flèches rouges indiquent l'ancrage du champ. Rappel : L'ancrage permet de gérer la position du champ lors du redimensionnement de la fenêtre. |
|  | **[Volets ancrables](2027001.md)** Affiche :  - les raccourcis vers les principales fonctionnalités disponibles sous l'éditeur en cours ([volet "Commandes"](2027010.md)). - les fonctionnalités les plus utilisées ([volet "Commandes"](2027010.md)). - les éléments (fenêtres, états, champs, ...) disponibles dans le projet en cours ([volet "Explorateur de Projet"](2027029.md)). - ... |
|  | **Fenêtre de description** Permet de visualiser et/ou de modifier les caractéristiques :  - du ou des champs sélectionnés. - de la fenêtre sélectionnée.  Les informations affichées sont identiques à celles affichées dans le modifieur ([volet "Modifieur"](2027006.md), affiché parmi les volets ancrables). |
|  | **[Volets ancrables](2027001.md)** Volets permettant de :  - afficher les différents éléments du code (liste des classes, des procédures locales ou globales, [volet "Code"](2027009.md)), - afficher les erreurs de compilation (erreurs présentes dans le code WLangage, [volet "Erreurs de compilation"](2027031.md)), - effectuer des recherches ([volet "Rechercher - Remplacer"](2027013.md)), - afficher le débogueur lors du test d'un élément ([volet "Débogueur"](2027009.md)), - ... |
