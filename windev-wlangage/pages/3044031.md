# HStatNbDoublon (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Renvoie le nombre de doublons pour une rubrique clé donnée. Ce nombre de doublons a été calculé lors du dernier calcul de statistiques.

## Exemple

```wlangage
// Réalisation de statistiques de doublons sur la clé NomCli du fichier de données Client
ResultatStat = HStatNbDoublon(Client, NomCli)
```

## Syntaxe

```wlangage
<Résultat> = HStatNbDoublon([<Fichier de données> [, <Rubrique clé>]])
```

`<Résultat>` *Entier*
> Nombre de doublons trouvés. Correspond à la constante *hNumEnrInvalide* si :
>
> - les statistiques n'ont jamais été calculées pour la rubrique spécifiée.
> - les statistiques ne sont pas supportées pour le type de la rubrique spécifiée. HFSQL permet de calculer des statistiques uniquement sur des clés.
`<Fichier de données>` *Chaîne de caractères optionnelle*
> Nom du fichier de données manipulé. Si ce nom n'est pas spécifié, la fonction **HStatNbDoublon** va manipuler le dernier fichier de données utilisé par la dernière fonction de gestion HFSQL (fonction commençant par la lettre H).
`<Rubrique clé>` *Chaîne de caractères optionnelle*
> Nom de la rubrique clé permettant de réaliser les statistiques. Si ce nom n'est pas spécifié, la fonction **HStatNbDoublon** va manipuler la dernière rubrique utilisée par la dernière fonction de gestion HFSQL (fonction commençant par la lettre H).

## Remarques

- La mise à jour des statistiques peut également être réalisée par la fonction [HRéindexe](3044133.md). Les fonctions [HRéindexe](3044133.md) et [HStatCalcule](3044134.md) sont les deux seules fonctions à mettre à jour les statistiques du fichier de données.
- Dans les fichiers de données HFSQL Classic, seules les rubriques clés peuvent faire l'objet d'un calcul de statistiques.
- Le nombre de doublons correspond au nombre total d'entrées moins le nombre de valeurs distinctes. Par exemple, si les entrées sont les nombres : 1, 3, 3, 5, 5, 5, 6, 7, 7, 7, 8, 9, alors le nombre de doublons est 12-7 = 5.
