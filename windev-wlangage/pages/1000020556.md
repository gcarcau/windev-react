# HRSDéclenche (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Exécute immédiatement une réplication périodique entre serveurs HFSQL : la réplication se déclenche avant la planification prévue.

## Exemple

```wlangage
Cnx est une Connexion
ConfigRéplication1 est un hRSConfig
...
HRSDéclenche(Cnx, ConfigRéplication1.Identifiant)
```

## Syntaxe

```wlangage
<Résultat> = HRSDéclenche(<Connexion> , <Réplication à déclencher>)
```

`<Résultat>` *Booléen*
> - Vrai si la réplication a été déclenchée,
> - Faux dans le cas contraire. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion vers le serveur HFSQL maître de la réplication. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Réplication à déclencher>` *Entier*
> Identifiant la réplication à déclencher. Cet identifiant correspond à la propriété **Identifiant** de la variable de type [hRSConfig](1000020484.md) décrivant la réplication.

**Composante : wd300hf.dll**
