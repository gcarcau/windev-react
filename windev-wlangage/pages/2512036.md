# FichierTransaction (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

La propriété **FichierTransaction** permet de savoir si un fichier de données est un fichier de transaction ou non.
**Rappel** : Un fichier de transaction permet de stocker les différentes opérations effectuées lors d'une transaction. Ces opérations sont ensuite soit validées, soit annulées. Le fichier de transaction est créé lors au début de la transaction par la fonction [HTransactionDébut](3044002.md).

## Exemple

```wlangage
EXTERNE GESCOM_TRS
HDéclareExterne("C:\WinDev\Exemples\GestCom\GESCOM_TRS.fic", "GESCOM_TRS")
SI GESCOM_TRS.FichierTransaction = Vrai ALORS
	Info("Vous manipulez un fichier de transaction.")
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Fichier de données>.FichierTransaction
```

`<Résultat>` *Booléen*
> - Vrai si le fichier de données est un fichier de transaction,
> - Faux dans le cas contraire.
>   Remarque : Les fichiers de données décrits dans l'analyse ne sont pas des fichiers de transaction.
`<Fichier de données>` *Chaîne de caractères*
> Nom logique du fichier de données manipulé. Peut correspondre à un nom d'alias d'un fichier de données déclaré par la fonction [HDéclareExterne](3044204.md).
