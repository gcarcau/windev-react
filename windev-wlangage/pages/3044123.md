# HFinInterditModif (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **Autres** (Procédures stockées)

Débloque un fichier de données qui a été bloqué par le même programme avec la fonction [HInterditModif](3044053.md).
**Attention** : Ne débloque pas les blocages effectués par d'autres programmes.

## Exemple

```wlangage
HInterditModif(Facture)
// Traitement
HFinInterditModif(Facture)
```

## Syntaxe

```wlangage
<Résultat> = HFinInterditModif(<Fichier de données>)
```

`<Résultat>` *Booléen*
> - Vrai si aucun problème n'a été rencontré,
> - Faux dans le cas contraire. La fonction [HErreur](3044088.md) permet d'obtenir plus d'informations sur le problème rencontré.
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données manipulé.

**Composante : wd300hf.dll**
