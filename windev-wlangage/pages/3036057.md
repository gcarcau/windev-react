# fStopCompacte (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Arrête l'opération de compression ou de décompression d'un fichier. Le fichier compacté ou décompacté n'est pas créé.

## Exemple

```wlangage
// Arrêt de la compression d'un fichier
fStopCompacte()
```

## Syntaxe

```wlangage
fStopCompacte()
```

## Remarques

> _(WINDEV, Etats et Requêtes, Code Utilisateur (MCU))_ JaugeSous Windows, pour visualiser la progression de la compression ou de la décompression du fichier, branchez un événement sur le message JaugeCompactage (1174). A la réception de ce message, la variable _EVE.wParam contient le pourcentage de compression ou de décompression du fichier.

**Composante : wd300std.dll**
