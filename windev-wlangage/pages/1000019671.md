# dHalo (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Ajoute un effet de halo sur une image présente dans une variable de type [Image](1000019650.md).
> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Dessiner en WINDEV, WEBDEV et WINDEV Mobile.

## Exemple

```wlangage
MonImage est une Image
MonImage = "Image.png"

// Ajoute un halo jaune de 5 pixels de large
dHalo(MonImage, JauneClair, 5)
```

## Syntaxe

```wlangage
dHalo(<Image> , <Couleur du halo> [, <Epaisseur> [, <Détourer>]])
```

`<Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) correspondant à l'image à manipuler.
`<Couleur du halo>` *Entier*
> Couleur du halo à ajouter à l'image. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md).
`<Epaisseur>` *Entier optionnel*
> Epaisseur du halo en pixels (2 pixels par défaut).
`<Détourer>` *Booléen optionnel*
> - Vrai si le halo doit être détouré,
> - Faux (valeur par défaut) dans le cas contraire.

**Composante : wd300pnt.dll**
