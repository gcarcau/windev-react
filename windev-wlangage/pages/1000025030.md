# <Source>.SurveilleStop (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Arrête la surveillance d'un fichier de données sur un serveur HFSQL. Cette surveillance a été précédemment démarrée via la fonction [<Source>.Surveille](1000025029.md).

## Exemple

```wlangage
// Lance la surveillance du fichier de données Commande
// La procédure TraiteCommande est appelée pour tout ajout d'enregistrement dans le fichier de données
Commande.Surveille(TraiteCommande, hNumEnrTous, hsAjout)
...
// Arrête la surveillance du fichier de données Commande
Commande.SurveilleStop(TraiteCommande, hNumEnrTous)
```

## Syntaxe

```wlangage
<Résultat> = <Source>.SurveilleStop(<Procédure WLangage> [, <Numéro d'enregistrement>])
```

`<Résultat>` *Booléen*
> - Vrai si la surveillance a été arrêtée,
> - Faux dans le cas contraire (par exemple, surveillance inexistante). Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Source>` *Type correspondant à la source spécifiée*
> Nom du fichier de données HFSQL à manipuler.
`<Procédure WLangage>` *Nom de procédure*
> Nom d'une procédure WLangage à ne plus appeler pour la surveillance du fichier de données.
`<Numéro d'enregistrement>` *Entier optionnel*
> Numéro de l'enregistrement à ne plus surveiller.
> Si ce paramètre n'est pas précisé ou correspond à la constante *hNumEnrTous*, la fonction **<Source>.SurveilleStop** va arrêter de surveiller tous les enregistrements du fichier de données (c'est-à-dire tout le fichier de données).

## Remarques

Les fonctions [<Source>.Surveille](1000025029.md) et **<Source>.SurveilleStop** peuvent être utilisées dans un service Windows.

**Composante : wd300hf.dll**
