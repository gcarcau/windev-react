# Fonctions DLNA / UPnP (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows) · **WINDEV Mobile** (iPhone/iPad)

Les fonctions WLangage (syntaxe préfixée) permettant de manipuler des périphériques UPnP sont les suivantes :
| [<Variable upnpPériphérique>.MédiaArrêt](1000020979.md) | Arrête la lecture du média en cours sur le périphérique UPnP. |
| --- | --- |
| [<Variable upnpPériphérique>.MédiaJoue](1000020985.md) | Lance la lecture du média en cours sur le périphérique UPnP. |
| [<Variable upnpPériphérique>.MédiaOuvre](1000020986.md) | Ouvre un média sur le périphérique UPnP. |
| [<Variable upnpPériphérique>.MédiaPause](1000020987.md) | Met en pause la lecture du média en cours sur le périphérique UPnP. |
| [<Variable upnpPériphérique>.ModifieContraste](1000020989.md) | Modifie le contraste d'un périphérique UPnP. |
| [<Variable upnpPériphérique>.ModifieLuminosité](1000020990.md) | Modifie la luminosité d'un périphérique UPnP. |
| [<Variable upnpPériphérique>.ModifieMuet](1000020991.md) | Modifier l'état 'Muet' d'un périphérique UPnP. |
| [<Variable upnpPériphérique>.ModifieNetteté](1000020992.md) | Modifie la netteté d'un périphérique UPnP. |
| [<Variable upnpPériphérique>.ModifieVolume](1000020993.md) | Modifie le volume d'un périphérique UPnP. |
| [<Variable upnpPériphérique>.RécupèreContraste](1000020994.md) | Récupère le contraste d'un périphérique UPnP. |
| [<Variable upnpPériphérique>.RécupèreLuminosité](1000020995.md) | Récupère la luminosité d'un périphérique UPnP. |
| [<Variable upnpPériphérique>.RécupèreMuet](1000020996.md) | Récupère l'état 'Muet' d'un périphérique UPnP. |
| [<Variable upnpPériphérique>.RécupèreNetteté](1000020997.md) | Récupère la netteté d'un périphérique UPnP. |
| [<Variable upnpPériphérique>.RécupèreVolume](1000020999.md) | Récupère le volume d'un périphérique UPnP. |
| [<Variable upnpService>.ExécuteAction](1000020973.md) | Exécute une action sur le service UPnP. |
