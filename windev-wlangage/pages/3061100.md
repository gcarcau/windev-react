# Fonctions Verrou

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

Les fonctions de verrouillage d'une application sont les suivantes :

| [ValideMotDePasse](1000017009.md) | Indique si le mot de passe spécifié est valide pour l'utilisateur en cours. |
| --- | --- |
| [VerrouAppliBloque](1000017011.md) | Verrouille une application WINDEV. |
| [VerrouAppliDébloque](1000017012.md) | Déverrouille une application bloquée par le verrouillage automatique ou la fonction [VerrouAppliBloque](1000017011.md). |
| [VerrouAppliDélai](1000017006.md) | Renvoie ou modifie le délai d'inactivité avant qu'une application WINDEV passe en mode verrouillé. |
| [VerrouAppliMotDePasse](1000017010.md) | Spécifie un mot de passe spécifique utilisable pour déverrouiller l'application en cours (application verrouillée automatiquement ou par la fonction [VerrouAppliBloque](1000017011.md)). |
