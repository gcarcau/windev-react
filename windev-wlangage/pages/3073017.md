# SysIconisé (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Permet de savoir si une fenêtre est iconisée. Cette fenêtre n'a pas été créée par WINDEV.
**Remarque** : Pour savoir si une fenêtre WINDEV est iconisée, utilisez la fonction [FenTaille](3038020.md).

## Exemple

```wlangage
// Savoir si la fenêtre "Microsoft Word - Ventes.DOC" est iconisée
ResHandle = SysFenHandle("Microsoft Word - Ventes.DOC")
ResIconiseFen = SysIconisé(ResHandle)
```

## Syntaxe

```wlangage
<Résultat> = SysIconisé(<Handle de la fenêtre>)
```

`<Résultat>` *Booléen*
> - Vrai si la fenêtre spécifiée est iconisée,
> - Faux dans le cas contraire.
`<Handle de la fenêtre>` *Entier*
> Handle de la fenêtre à tester. Ce handle peut être obtenu avec la fonction [SysFenHandle](3073007.md).

**Composante : wd300std.dll**
