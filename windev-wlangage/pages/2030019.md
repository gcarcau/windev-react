# Exportation d'éléments vers un répertoire

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Tous les éléments manipulés par un projet (fenêtre, état, classes, collection de procédures, requêtes, etc.) peuvent être transférés d'un projet à un autre. L'exportation permet de copier les éléments du projet en cours vers un autre répertoire (et donc un autre projet).

## Comment le faire ?

### Exporter des éléments du projet en cours
Pour exporter des éléments du projet en cours :

1. Sous le volet "Accueil", dans le groupe "Général", déroulez "Enregistrer" et sélectionnez "Exporter .. Vers un répertoire".
2. Sélectionnez le répertoire dans lequel doivent être exportés les fichiers. Une coche apparaît devant les fichiers sélectionnés.
3. Dans la liste des éléments WINDEV affichée, sélectionnez les éléments à exporter.
  Remarque : Cette liste est composée du nom du fichier, de la description du fichier (si elle existe), de l'emplacement actuel du fichier.
4. Validez.
  Les fichiers sélectionnés sont automatiquement exportés dans le répertoire du projet spécifié.

**Remarque** : Pour intégrer les éléments exportés aux composants d'un projet, utilisez la [liste des composants du projet](2030033.md).

## Notes

### Dépendance des fichiers
Les éléments sont exportés avec leurs dépendances : tous les fichiers liés à l'élément exporté sont également exportés. Par exemple, la fenêtre et son image de fond sont automatiquement exportés.

### Estimation de la taille des fichiers exportés
Il est possible d'estimer la taille des fichiers exportés avec le bouton "Calculer". Cette taille prend en compte la taille de l'élément à exporter et la taille des fichiers dépendant de cet élément.
