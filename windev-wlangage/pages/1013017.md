# Modifier les caractéristiques des champs d'un état

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

## Présentation

Les différentes caractéristiques d'un ou de plusieurs champs peuvent être visualisées et/ou modifiées dans :

- la fenêtre de description de ce champ.
- le volet "Modifieur".

L'éditeur d'états permet également directement de :

- modifier le libellé d'un champ.
- modifier le nom d'un champ.

## Fenêtre de description des champs d'un état

Pour afficher la fenêtre de description d'un champ, utilisez une des méthodes suivantes :

- double-cliquez sur le champ (conseillé).
- sélectionnez l'option "Description" du menu contextuel du champ (clic droit de la souris).
- sélectionnez le champ et sous le volet "Modification", cliquez sur l'icône de regroupement [image: Icône regroupement] du groupe "Edition rapide" (combinaison de touches Alt + Entrée).
- sous le volet "Affichage", cliquez sur l'icône de regroupement [image: Icône regroupement] du groupe "Options" (touche F12). Sélectionnez ensuite le champ et cliquez sur le bouton "Description".

**Remarque** : Il est possible d'afficher la fenêtre de description pour une sélection de champs. Seules les caractéristiques communes aux différents champs sélectionnés seront affichées.

### Caractéristiques par onglet
La fenêtre de description regroupe les différentes caractéristiques du ou des champs sélectionnés par onglet :

| Onglet | Caractéristiques |
| --- | --- |
| **Général** | Permet de spécifier le nom du champ et toutes les caractéristiques d'affichage du champ. Par exemple :  - le libellé du champ (ce libellé peut être multilingue). - le type d'information affiché dans le champ (texte, numérique, etc.). - le masque d'affichage utilisé pour le champ (ce masque peut être multilingue). Pour plus de détails, consultez les [Différents masques d'affichage](1014003.md). - l'image affichée dans un champ Image, le type de code-barres utilisé dans un champ Code-barres, le type de graphe utilisé dans un champ Graphe, etc. Pour plus de détails sur les caractéristiques d'un champ, consultez directement l'aide sur le type de ce champ. |
| **UI** | Permet de définir :  - les différents paramètres d'impression du champ (visible, sécable, ...). Pour plus de détails, consultez le paragraphe Paramètres d'impression des champs d'un état. - la taille du champ. - la position du champ dans l'état et dans le bloc auquel le champ appartient. - l'ancrage du champ. - le groupe de champs associé. - le plan associé. |
| **Liaison** | Permet de définir la rubrique ou la variable présente dans la source de données à laquelle le champ est lié. La valeur de cette rubrique ou de cette variable sera affichée dans le champ. Pour lier le champ avec une rubrique ou une variable appartenant à la source de données de l'état, sélectionnez directement cette rubrique dans la liste "Rubrique ou variable reliée".  Pour lier le champ avec une rubrique n'appartenant pas à la source de données de l'état, sélectionnez l'option "Multi-fichier de données" puis sélectionnez la rubrique liée au champ en cours. |
| **Note** | Permet de décrire le fonctionnement détaillé du champ. Ces informations seront imprimées dans la documentation technique (icône [image: Icône impression] sous le volet "Accueil", dans le groupe "Général"). Ces informations peuvent être remplies et connues par programmation grâce aux propriétés [Note](2510085.md) et [TitreNote](2510121.md). |
| **Style** | Permet de définir :  - l'aspect du champ (couleur de fond, cadre, etc.). - la police utilisée dans le champ.  **Remarque** : La police utilisée dans le champ peut également être définie grâce aux icônes du groupe "Edition rapide" dans le volet "Modification". |

Remarque : Toutes les options de la fenêtre de description de l'éditeur d'états proposent des bulles d'aide complètes, affichant par exemple, en plus de l'aide sur l'option, la propriété WLangage correspondante, la disponibilité par plateforme, les valeurs multilingues, ...

## Principaux paramètres d'impression des champs d'un état

Les paramètres d'impression d'un champ sont les suivants (définis dans l'onglet "UI" de la fenêtre de description) :

| Paramètre | Description | Disponible pour les champs suivants |
| --- | --- | --- |
| ***Visible*** | Le champ peut être affiché ou non. Cette caractéristique peut être modifiée en programmation grâce à la propriété [Visible](2510138.md). | [Libellé](1013179.md), [Rubrique](1013059.md), [Champ calculé](1013212.md), [Image](1013218.md), [Code-Barres](1013010.md), [Champ RTF](1013056.md), [Champ prédéfini](1013058.md), [Graphe](1013006.md), [Forme](1013102.md), [Champ Etat Interne](1013044.md) |
| ***Auto-Extensible*** | La taille du champ définie sous l'éditeur d'états peut augmenter en fonction du contenu du champ. Les champs placés après le champ "auto-extensible" sont automatiquement déplacés.  **Remarques** :  - Si un champ n'est pas auto-extensible, son contenu peut être tronqué si la taille du champ est trop petite.  Pour connaître par programmation la hauteur d'un champ auto-extensible lorsque ce champ sera agrandi, utilisez la propriété [HauteurFuture](2511061.md). - Si un champ d'un bloc est auto-extensible, le bloc associé sera automatiquement auto-extensible. Un bloc contenant des champs auto-extensible est auto-extensible. Un bloc contenant aucun champ auto-extensible n'est pas auto-extensible. - Les champs présents dans un bas de page ne peuvent pas être auto-extensibles.  **Limite** : Dans un état en mode Etiquette, les champs ne peuvent pas être auto-extensibles. | [Libellé](1013179.md), [Rubrique](1013059.md), [Champ calculé](1013212.md), [Forme](1013102.md), [Code-Barres](1013010.md), [Champ Etat Interne](1013044.md) |
| ***Multi-ligne*** | Le contenu du champ peut être affiché sur plusieurs lignes. Cette caractéristique peut être modifiée en programmation grâce à la propriété [Multiligne](2510105.md). **Remarques** :  - La hauteur du champ doit être suffisante pour visualiser plusieurs lignes. - Pour modifier par programmation la hauteur d'un champ, utilisez la propriété [Hauteur](2510050.md). - Si un angle d'orientation est appliqué à un champ multiligne, les retours chariot automatiques ne sont pas pris en compte. Seuls les retours à la ligne manuels sont pris en compte. | [Libellé](1013179.md), [Rubrique](1013059.md), [Champ calculé](1013212.md), [Champ prédéfini](1013058.md) |
| ***Sécable*** | Le contenu d'un champ sécable peut être imprimé sur plusieurs pages lorsque l'espace restant pour imprimer la totalité du champ sur une page est insuffisant. **Remarques** :  - Pour qu'un champ soit sécable, le bloc contenant le champ doit également être sécable. - S'il n'y a pas assez de place sur la page en cours pour imprimer complètement un champ non-sécable, tout le champ sera totalement imprimé sur la page suivante. | [Libellé](1013179.md), [Rubrique](1013059.md), [Champ calculé](1013212.md), [Image](1013218.md), [Code-Barres](1013010.md), [Champ RTF](1013056.md), [Champ prédéfini](1013058.md), [Graphe](1013006.md), [Forme](1013102.md) |
| ***Mise à blanc si zéro*** | La valeur du champ est affichée uniquement si la valeur du champ est différente de 0. Si la valeur du champ est égale à 0, le champ affiche une chaîne vide (""). | [Libellé](1013179.md), [Rubrique](1013059.md) |
| ***Ellipse (tronquer les libellés trop longs par '...')*** | L'ellipse consiste à indiquer qu'un libellé est trop long pour être affiché en entier. Les caractères suivants sont alors ajoutés au libellé : "...". Ces caractères peuvent être ajoutés en fin du libellé ou au milieu du texte (conseillé pour l'affichage de chemins de fichiers). | [Rubrique](1013059.md), [Champ calculé](1013212.md) |
| ***Affiché lorsque la valeur change*** | La valeur du champ est affichée uniquement si la valeur de la rubrique liée change lors du passage à l'enregistrement suivant dans la source de données de l'état. | [Rubrique](1013059.md), [Champ calculé](1013212.md) |
| ***Remis à 0 après impression*** | La valeur du champ est automatiquement remise à 0 après son impression. Ce paramètre est souvent utilisé pour les calculs sur rupture. | [Champ calculé](1013212.md) |
| ***Format RTF*** | La valeur du champ pourra être au format RTF. **Rappel** : Le format RTF permet de prendre en compte les attributs des caractères (gras, italique, souligné, ...) d'un texte. | [Libellé](1013179.md), [Rubrique](1013059.md), [Champ RTF](1013056.md) |
| ***Utiliser les Infos Partagées en exécution*** | Le champ affichera les "infos partagées" de la rubrique liée au champ (et non les indices correspondant à ces "infos partagées"). Par exemple, les "Infos RAD" de la rubrique "Civilité" correspondent à la combo suivante : [image: Infos RAD]Dans la base de données, seuls les indices des "Infos partagées" sont conservés. | [Rubrique](1013059.md) |
| ***Quadrillage horizontal / vertical*** | Le quadrillage horizontal et/ou vertical d'un graphe peut être affiché ou non. | [Graphe](1013006.md) |

## Utilisation du volet "Modifieur"

### Présentation
Le volet "Modifieur" permet de visualiser et/ou de modifier directement depuis l'éditeur d'états les principales caractéristiques :

- du ou des champs sélectionnés.
- de l'état ou du bloc sélectionné.

Pour plus de détails, consultez le [volet "Modifieur"](2027006.md).

### Visualiser et/ou modifier les caractéristiques d'un ou de plusieurs champs grâce au modifieur
Pour visualiser et/ou modifier les caractéristiques d'un ou de plusieurs champs grâce au modifieur :

1. Sélectionnez le ou les champs à modifier :
  - soit directement dans la fenêtre, la page ou l'état (voir [Sélectionner un ou plusieurs champs](2026007.md)).
  - soit grâce à la liste déroulante du modifieur. Les poignées du/des champ(s) sélectionné(s) s'affichent automatiquement.
   Si plusieurs champs sont sélectionnés, seules les informations communes aux champs sélectionnés sont affichées dans le modifieur.
2. Effectuez les modifications nécessaires. Ces modifications sont réalisées sur tous les champs sélectionnés.

**Remarque** : Pour que les caractéristiques affichées dans le modifieur correspondent à l'élément sélectionné dans la liste déroulante du modifieur (et non à l'élément actuellement sélectionné dans WINDEV, WEBDEV ou WINDEV Mobile) :

1. Sous le volet "Affichage", dans le groupe "Options", cliquez sur l'icône de regroupement ().
2. Dans la fenêtre qui s'affiche, affichez l'onglet "Options".
3. Décochez l'option "Afficher les propriétés dans le modifieur" et validez.

Dans ce cas, le modifieur ne sera pas mis à jour avec les caractéristiques de l'élément sélectionné dans WINDEV, WEBDEV ou WINDEV Mobile.

## Modifier le libellé d'un champ

Pour modifier le libellé d'un champ directement dans l'état en création :

1. Sélectionnez le champ à modifier.
2. Cliquez une nouvelle fois sur le champ ou appuyez sur le touche Entrée. Le curseur de la souris se transforme en curseur de saisie. [image: Modifier le libellé ]
3. Saisissez le nouveau libellé du champ.
4. Validez la saisie du libellé en appuyant sur la touche Entrée.

## Modifier le nom d'un champ

Il est possible de modifier le nom d'un champ directement depuis la barre de messages de l'éditeur d'états.
Pour modifier le nom d'un champ :

1. Sélectionnez le champ à modifier.
2. Saisissez directement dans la barre de messages le nouveau nom du champ. [image: Modifier le nom du champ ]
