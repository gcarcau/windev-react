# BoutonCalendrier (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

La propriété **BoutonCalendrier** permet de savoir et d'indiquer si un champ de saisie de type Date propose un bouton pour afficher un calendrier en popup.

## Exemple

```wlangage
// Affiche un bouton Calendrier si nécessaire
SI SAI_Date.BoutonCalendrier = Faux ALORS
	SAI_Date.BoutonCalendrier = Vrai
FIN
```

## Syntaxe

#### Savoir si un bouton Calendrier est affiché

```wlangage
<Résultat> = <Champ de saisie>.BoutonCalendrier
```

`<Résultat>` *Booléen*
> - Vrai si un bouton Calendrier est affiché,
> - Faux dans le cas contraire.
`<Champ de saisie>` *Nom de champ*
> Nom du champ de saisie de type Date à manipuler.

#### Afficher ou non un bouton Calendrier

```wlangage
<Champ de saisie>.BoutonCalendrier = <Afficher>
```

`<Champ de saisie>` *Nom de champ*
> Nom du champ de saisie de type Date à manipuler.
`<Afficher>` *Booléen*
> - Vrai si un bouton Calendrier doit être affiché,
> - Faux dans le cas contraire.

## Remarques

> _(WINDEV, Etats et Requêtes, Code Utilisateur (MCU))_ Fonctionnement du champ CalendrierPar défaut, en exécution, les champs de saisie de type Date proposent l'option "Calendrier". Cette option permet d'afficher un calendrier pour sélectionner une date.Si la propriété BoutonCalendrier est utilisée pour afficher un bouton Calendrier dans le champ de saisie de type Date, l'option "Calendrier" n'est alors plus disponible dans le menu contextuel du champ Date.Remarque : Il est possible de désactiver pour un projet ou un champ l'affichage du calendrier (via le bouton ou le menu contextuel) grâce à la fonction FAADésactive.
