# zipFichierArchivé (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le type **zipFichierArchivé** permet de manipuler :

- un fichier contenu dans une archive correspondant à l'un des formats suivants : ZIP, CAB, RAR, WDZ, 7z, TAR, gzip ou TGZ (TAR.GZ).
- un fichier à ajouter dans une archive.

Les caractéristiques de ce fichier peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.

Ce type de variable est utilisé :

- par les variables de type [zipArchive](1000018679.md).
- par la fonction [zipAjouteFichier](3082008.md).

> _(Android, Widget Android)_ Le format CAB n'est pas disponible.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

Nouveauté 2025

> _(WINDEV, WEBDEV - Code Serveur, Windows, Linux, iPhone/iPad)_ Le format gzip (extension .gz) est désormais géré.

## Exemple

```wlangage
// Ouverture d'un fichier d'archive
MonArchive est une zipArchive
zipOuvre(MonArchive, "c:\Sauvegardes\archive.zip")

// Affichage dans la trace de la liste des fichiers contenus dans l'archive
POUR TOUT FichierArc DE MonArchive.Fichier
	Trace(FichierArc.Nom)
FIN

// Ajout d'un nouveau fichier dans l'archive
NouveauFichier est un zipFichierArchivé
NouveauFichier.Nom = "FichierArchivé.txt"
NouveauFichier.Contenu = "Ce fichier a été archivé"
zipAjouteFichier(MonArchive, NouveauFichier)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type zipFichierArchivé
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **zipFichierArchivé** :

| **Nom** | **Type manipulé** | **Effet** |
| --- | --- | --- |
| AttributFichier | Chaîne de caractères | Une ou plusieurs lettres correspondant aux attributs du fichier ("AH" par exemple) mémorisés lors de son ajout dans l'archive. Les lettres utilisées sont :  - R : Fichier en lecture seule. Le fichier est uniquement accessible en lecture. - H : Fichier caché. Le nom du fichier est généralement grisé ou invisible dans l'explorateur. - S : Fichier système. Le fichier est un fichier système Windows. - A : Fichier "archive". Cet attribut indique que le fichier peut être archivé. Certains programmes se servent de cet attribut pour savoir quels fichiers ont été sauvegardés.  Cette information est restaurée lors de l'extraction du fichier. _(Linux)_ Cette propriété n'est pas disponible. |
| Contenu | Buffer | Contenu du fichier. Cette propriété est disponible en lecture seulement si le fichier a déjà été ajouté dans une archive. |
| DateCréation | Chaîne de caractères ou variable de type DateHeure | Date de création du fichier. Cette date a été mémorisée lors de l'ajout du fichier dans l'archive. Cette information est restaurée lors de l'extraction du fichier. Cette information est conservée uniquement pour le format d'archive WDZ. |
| DateDernierAccès | Chaîne de caractères ou variable de type DateHeure | Date de dernier accès au fichier. Cette date a été mémorisée lors de l'ajout du fichier dans l'archive. Cette information est restaurée lors de l'extraction du fichier. Cette information est conservée uniquement pour le format d'archive WDZ. |
| DateModification | Chaîne de caractères ou variable de type DateHeure | Date de modification du fichier. Cette date a été mémorisée lors de l'ajout du fichier dans l'archive. Cette information est restaurée lors de l'extraction du fichier. |
| ModeCryptage | Chaîne de caractères | Caractère indiquant si le fichier archivé est protégé par cryptage. Les valeurs possibles sont :  - N : Fichier normal. - + : Fichier crypté (il sera nécessaire de fournir un mot de passe pour l'extraire de l'archive).  Cette propriété est disponible en lecture seulement si le fichier a déjà été ajouté dans une archive. |
| Nom | Chaîne de caractères | Chemin du fichier mémorisé lors de l'ajout du fichier dans l'archive. |
| Taille | Entier sur 8 octets | Taille originale du fichier mémorisée lors de l'ajout du fichier dans l'archive. **Cette propriété est disponible en lecture seulement**. |
| TailleCompressée | Entier sur 8 octets | Taille occupée par le fichier compressé dans l'archive. **Cette propriété est disponible en lecture seulement**. |
