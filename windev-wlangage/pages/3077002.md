# Constantes de gestion des threads

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |
| **DestructionSansModification** | Par défaut un signal est automatiquement modifié lors de sa destruction. Si le signal est créé avec cette constante, il ne sera pas modifié au moment de l'appel de la fonction SignalDétruit ou de la destruction automatique du signal à la fermeture de l'application. | [SignalCrée](3077009.md) |
| **Infini** | Attente infinie | [ThreadAttend](3077020.md), [ThreadArrête](3077019.md),  [ThreadAttendSignal](3077022.md), [SémaphoreDébut](3077008.md) [MutexDébut](1000019023.md) |
| **partageAucun** | Le signal, le sémaphore ou le mutex est propre à l'application. Si les fonctions [SignalDétruit](3077025.md), [SémaphoreDétruit](3077011.md) ou [MutexDétruit](1000019025.md) ne sont pas appelées, le signal, le sémaphore ou le mutex est détruit à la fin de l'application. | [SémaphoreCrée](3077012.md), [SignalCrée](3077009.md),  [MutexCrée](1000019022.md) |
| **partageGlobal** | Le signal, le sémaphore ou le mutex est partagé avec toutes les applications de la machine. | [SémaphoreCrée](3077012.md), [SignalCrée](3077009.md),  [MutexCrée](1000019022.md) |
| **partageUtilisateur** | Le signal, le sémaphore ou le mutex est partagé avec toutes les applications de la session de l'utilisateur qui exécute l'application. | [SémaphoreCrée](3077012.md), [SignalCrée](3077009.md),  [MutexCrée](1000019022.md) |
| **PrioritéBasse** | Thread de priorité basse. | [ThreadPriorité](3077027.md) |
| **PrioritéElevée** | Thread de priorité élevée. | [ThreadPriorité](3077027.md) |
| **PrioritéNormale** | Thread de priorité normale. | [ThreadPriorité](3077027.md) |
| **signalAutomatique** | Après son ouverture, le signal est automatiquement refermé lorsque tous les threads sont débloqués. | [SignalCrée](3077009.md) |
| **signalFermé** | Le signal est fermé. | [SignalCrée](3077009.md), [SignalModifie](3077017.md) |
| **signalOuvert** | Le signal est ouvert. | [SignalCrée](3077009.md), [SignalModifie](3077017.md) |
| **signalOuvertEtFermé** | Ouvre le signal, débloque tous les threads en attente et referme le signal. | [SignalModifie](3077017.md) |
| **signalManuel** | Le signal est modifié uniquement par la fonction [SignalModifie](3077017.md). | [SignalCrée](3077009.md) |
| Nouveauté 2025 **thpAppareilConnecté** | Cas d'usage : Interaction avec des appareils connectés. | [ThreadPersistant](1000020584.md) |
| Nouveauté 2025 **thpCaméra** | Cas d'usage : Accès à la caméra en arrière-plan. | [ThreadPersistant](1000020584.md) |
| Nouveauté 2025 **thpLocalisation** | Cas d'usage : Opérations nécessitant un accès à la localisation, telles que la navigation et le partage de localisation. | [ThreadPersistant](1000020584.md) |
| Nouveauté 2025 **thpMédia** | Cas d'usage : Lecture continue de musique ou de vidéo en arrière-plan. | [ThreadPersistant](1000020584.md) |
| Nouveauté 2025 **thpMicro** | Cas d'usage : Enregistrement audio en arrière-plan. | [ThreadPersistant](1000020584.md) |
| Nouveauté 2025 **thpSanté** | Cas d'usage : Suivi d'activité physique. | [ThreadPersistant](1000020584.md) |
| Nouveauté 2025 **thpServiceCourt** | Cas d'usage : Opération critique qui doit se terminer impérativement sans être interrompue. | [ThreadPersistant](1000020584.md) |
| Nouveauté 2025 **thpSynchroDonnees** | Cas d'usage : Synchronisation de données. | [ThreadPersistant](1000020584.md) |
| Nouveauté 2025 **thpUsageSpécial** | Cas d'usage : Opération dont le cas d'usage ne correspond à aucun des cas prédéfinis. | [ThreadPersistant](1000020584.md) |
| **threadArrêtDemandé** | Etat du thread : L'arrêt a été demandé pour ce thread. | [ThreadEtat](3077016.md),  Type [Thread](1000024879.md) |
| **threadAttendDémarrage** | Mode de lancement du thread : Attend le démarrage effectif du thread avant de continuer l'exécution. | [ThreadExécute](3077024.md),  Type [Thread](1000024879.md) |
| **threadAuto** | Gestion automatique des threads. | [ThreadMode](3077028.md) |
| **threadContexteGlobal** | Mode de lancement du thread : Force l'utilisation du contexte global du projet si le thread est exécuté depuis une fenêtre.  Par défaut, le contexte de la fenêtre est utilisé. | [ThreadExécute](3077024.md),  Type [Thread](1000024879.md) |
| **threadEnCours** | Le thread est en cours d'exécution. | [ThreadEtat](3077016.md),  Type [Thread](1000024879.md) |
| **threadInexistant** | Le thread n'a pas été créé ou a été détruit. | [ThreadEtat](3077016.md) |
| **threadMonoProcesseur** | Force l'application à s'exécuter sur un seul processeur sur les machines multiprocesseur, hyperthread ou dual core. | [ThreadMode](3077028.md) |
| **threadMultiProcesseur** | Retour à l'utilisation normale des processeurs sur les machines multiprocesseur, hyperthread ou dual core. | [ThreadMode](3077028.md) |
| **threadNonExécuté** | Lancement du thread en mode normal. | Type [Thread](1000024879.md) |
| **threadNormal** | Lancement du thread en mode normal. | [ThreadExécute](3077024.md) |
| **threadPrincipal** | Manipule le thread principal. | [ThreadArrête](3077019.md),  [ThreadEnvoieSignal](3077021.md),  Type [Thread](1000024879.md) |
| **threadSectionCritique** | Gestion manuelle des sections critiques. | [ThreadMode](3077028.md) |
| **threadSécurisé** | Lance un thread secondaire en mode sécurisé. | [ThreadExécute](3077024.md),  Type [Thread](1000024879.md) |
| **threadSuspendu** | Le thread est suspendu. | [ThreadEtat](3077016.md) Type [Thread](1000024879.md) |
| **threadTerminé** | Le thread est terminé. | Type [Thread](1000024879.md) |
| **threadUtiliseHyperFile** **threadUtiliseHFSQL** **threadCopieComplèteContexteHFSQL** | Provoque la copie immédiate du contexte HFSQL.  Conseillé par exemple si le thread doit tenir compte des positions en cours dans les fichiers et requêtes du contexte de l'appelant. | [ThreadExécute](3077024.md),  Type [Thread](1000024879.md) |
| **threadCopieLégèreContexteHFSQL** | Provoque la copie immédiate d'une partie du contexte HFSQL. Seuls les répertoires où se trouvent les fichiers de données en HFSQL Classic et/ou les connexions en HFSQL Client/Serveur sont mémorisés. | [ThreadExécute](3077024.md),  Type [Thread](1000024879.md) |
