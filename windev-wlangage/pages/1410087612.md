# HTMLEncadreTousLesFils (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Mac Catalyst)

Encadre tous les fils du noeud donné dans un nouveau noeud dans un document HTML.

## Exemple

```wlangage
hDoc est un htmlDocument = "
<html>
	<head/>
	<body>
		<h1></h1><div id="div">
			<p>Texte1</p>
			<p>Texte2</p>
		</div><h3></h3>
	</body>
</html>
"
hNoeud est un htmlNoeud <- HTMLChercheElémentParID(hDoc, "div")
hNoeudInsertion est un htmlNoeud

hNoeudInsertion..NomBalise = "h2"
HTMLEncadre(hNoeud, hNoeudInsertion)
// body : <h1/><h2><div id="div"><p>Texte1</p><p>Texte2</p></div></h2><h3/>
Trace(hDoc)
hNoeudInsertion..NomBalise = "span"
HTMLEncadreTousLesFils(hNoeud, hNoeudInsertion)
// body : <h1/><h2><div id="div"><span><p>Texte1</p><p>Texte2</p></span></div></h2><h3/>
Trace(hDoc)
HTMLDésencadreTousLesFils(hNoeud)
// body : <h1/><h2><span><p>Texte1</p><p>Texte2</p></span></h2><h3/>
Trace(hDoc)
```

## Syntaxe

```wlangage
HTMLEncadreTousLesFils(<Noeud source> , <Encadrant>)
```

`<Noeud source>` *Variable de type htmlNoeud*
> Nom de la variable de type [htmlNoeud](1000026081.md) correspondant au noeud de référence.
`<Encadrant>` *Variable de type htmlNoeud*
> Nom de la variable de type [htmlNoeud](1000026081.md) correspondant au noeud encadrant les fils du <Noeud source>.
