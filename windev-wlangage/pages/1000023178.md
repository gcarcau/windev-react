# ModeAjustement (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

La propriété **ModeAjustement** permet de connaître et de modifier le mode d'ajustement d'un champ Tableur pour l'impression. Cette propriété est utilisable sur :

- un champ Tableur dans un état. Pour plus de détails, consultez [ModeAjustement](1000021790.md).
- une variable de type [xlsMiseEnPage](1000023139.md).
