# Trait (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

La propriété **Trait** permet de définir le style de trait utilisé. Cette propriété est utilisable sur :

- une variable de type [Cadre](15140100.md).
- une variable de type [docElémentZoneDeTexte](1000023420.md).
- une variable de type [CarteCercle](1000025504.md).
- une variable de type [CarteImage](1000025523.md).
- une variable de type [CartePolygone](1000025476.md).
- une variable de type [CartePolyligne](1000025489.md).
