# AgendaZoom (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP)

**Avertissement**

 A partir de la version **17**, cette fonction est conservée par compatibilité. Cette fonction est remplacée par la fonction [AgendaMode](1000019545.md).

Renvoie la plage temporelle affichée par un champ Agenda : jour, semaine, mois, ...
**Remarque** : La fonction [AgendaChangeZoom](1000018883.md) permet de modifier la plage temporelle affichée par le champ Agenda.

## Exemple

```wlangage
// Alterne entre l'affichage par jour et par moisSI AgendaZoom(AGD_MonAgenda) = agzJour ALORS AgendaChangeZoom(AGD_MonAgenda, agzMois)SINON AgendaChangeZoom(AGD_MonAgenda, agzJour)FIN
```

## Syntaxe

```wlangage
<Résultat> = AgendaZoom(<Champ Agenda>)
```

`<Résultat>` *Constante de type Entier*
> Plage de temps affichée par le champ Agenda :
>
> | *agzJour* | L'agenda affiche une journée. |
> | --- | --- |
> | *agzMois* | L'agenda affiche un mois complet. |
> | *agzSemaine* | L'agenda affiche une semaine complète (ou partielle si un nombre de jours a été précisé grâce à la fonction [AgendaChangeZoom](1000018883.md)). |
> | *agzSemaineSur5* | L'agenda affiche une semaine sur 5 jours (sans le week-end). |
`<Champ Agenda>` *Nom de champ*
> Nom du champ Agenda à manipuler. Ce champ peut correspondre :
>
> - au champ Agenda d'une fenêtre ou d'une page,
> - au champ Agenda d'un état.

## Remarques

Les lignes de code suivantes sont équivalentes :
```wlangage
AgendaZoom(AGD_Agenda, agzSemaine, 5)
```

et

```wlangage
AgendaZoom(AGD_Agenda, agzSemaineSur5)
```

Dans les 2 cas, la fonction **AgendaZoom** renvoie la constante *agzSemaineSur5*.
