# Remplissage automatique des champs de saisie

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Dans les applications mobiles, il est possible d'utiliser un service de remplissage automatique des champs. Ces services peuvent mémoriser avec votre accord des informations telles que vos noms d'utilisateur, vos mots de passe, votre adresse, et les indiquer automatiquement lorsque les applications le demandent.
WINDEV Mobile propose désormais de paramétrer les champs de saisie de vos applications pour que ces services puissent proposer à vos utilisateurs un remplissage automatique.

Remarques :

- Plusieurs services de remplissage automatique existent, aussi bien sur des appareils Android que iOS (Dashlane, LastPass, etc.). Le choix du service de remplissage peut être effectué dans les paramètres du périphérique.
- Selon le service utilisé, plus ou moins d'éléments sont gérés. Certains services proposent uniquement la gestion des associations "login/mot de passe". D'autres services proposent une gestion plus complète des informations.

## Comment le faire ?

### Paramétrage sous l'éditeur de fenêtres
Le paramétrage du remplissage automatique d'un champ de saisie est réalisé dans l'onglet "Général" de la fenêtre de description du champ de saisie, grâce à l'option "Remplissage auto.".
Par défaut, lors de la création d'un champ de saisie dans une fenêtre mobile, le champ de saisie utilise le mode de remplissage "automatique". Il est possible de :

- utiliser le mode automatique.
- ne pas utiliser le remplissage automatique.
- utiliser une information spécifique pour le remplissage. Si le service utilisé gère ce type information, une suggestion sera automatiquement proposée à l'utilisateur.

### Paramétrage par programmation
La propriété [RemplissageAuto](1410090515.md) permet de connaître et de configurer le mode de remplissage automatique pour le champ de saisie manipulé.

### Caractéristiques du mode de remplissage "Automatique"
Le mode de remplissage "Automatique" permet de remplir automatiquement :

- les champs correspondant à un mot de passe (si le champ de saisie est de type "Mot de passe").
- les champs correspondant à un numéro de téléphone (si le champ de saisie possède un masque de saisie de type "Numéro de téléphone").
- les champs correspondant à une adresse email (si le champ de saisie possède un masque de saisie de type "Email").
- les champs correspondant à un code postal (si le champ de saisie possède un masque de saisie de type "Code postal").
- les champs correspondant à un numéro de carte de crédit (si le champ de saisie possède un masque de saisie de type "Carte bancaire" (Amex ou Visa)).

Pour tous les autres cas, si l'utilisateur final utilise le service Google, ce service applique une heuristique pour déterminer le type de remplissage à utiliser (basé sur le libellé du champ, son type, etc.).

### Cas particulier : Lecture de SMS
De nombreuses applications utilisent un code SMS pour valider l'identité d'un utilisateur. Le code SMS est reçu sur le téléphone et l'application lancée peut lire directement le SMS.
La mise en place de ce type de fonctionnalité est différente en Android et en iOS. Pour plus de détails, consultez [Génération et réception d'un code SMS à usage unique](1410090676.md).

### Limites

- Le remplissage automatique est disponible uniquement à partir de Android 8. Les options de remplissage sont ignorées dans les versions précédentes.
- Un même type de remplissage ne peut pas être utilisé dans deux champs de la même fenêtre.
