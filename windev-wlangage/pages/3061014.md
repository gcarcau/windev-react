# GraveurEjecte (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Ouvre ou ferme le tiroir du graveur en cours. Ce graveur peut être sélectionné grâce à la fonction [GraveurSélectionne](3061012.md).
**Remarque** : Pour connaître l'ensemble des graveurs disponibles à partir du poste en cours, utilisez la fonction [GraveurListe](3061009.md).

## Exemple

```wlangage
// Ouvre le tiroir du graveur
ResOuverture est un booléen
ResOuverture = GraveurEjecte()
// Erreur rencontrée ?
SI ResOuverture = Faux ALORS
	// Affichage de l'erreur
	Erreur(ErreurInfo(errMessage))
SINON
	Info("Veuillez insérer le CD ou le DVD dans le graveur")
FIN
```

## Syntaxe

```wlangage
<Résultat> = GraveurEjecte([<Ouverture>])
```

`<Résultat>` *Booléen*
> - Vrai si l'opération demandée a été effectuée,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Ouverture>` *Booléen optionnel*
> - Vrai (par défaut) si le tiroir du graveur doit s'ouvrir,
> - Faux si le tiroir du graveur doit se fermer.

## Remarques

### Ouverture et fermeture du tiroir du graveur
Si le tiroir du graveur est déjà ouvert, la ligne de code suivante sera sans effet :

```wlangage
GraveurEjecte(Vrai)
```

Inversement, si le tiroir du graveur est fermé, la ligne de code suivante sera également sans effet :

```wlangage
GraveurEjecte(Faux)
```

Certains graveurs ignorent la demande de fermeture du tiroir. Dans ce cas, la fonction **GraveurEjecte** renvoie Vrai bien que le tiroir du graveur reste ouvert.

### Configuration nécessaire

> _(WINDEV)_ La gravure de CD est disponible uniquement sous Windows XP et supérieur. La gravure de DVD est disponible sous Windows Vista, et sous Windows XP en utilisant la mise à jour KB932716 pour Windows XP (cette mise à jour doit être téléchargée depuis le site de Microsoft et installée car elle n'est pas prise en compte par le mécanisme de Live Update).

> _(WEBDEV - Code Serveur)_ La gravure de CD et DVD sera réalisée sur le serveur Web. Pour graver des CD ou des DVD, le serveur doit être sous Windows XP ou supérieur. Pour graver des CD sous Windows 2003 Serveur, il est nécessaire d'activer le service de gravure IMAPI (nommée "Service COM de gravage de CD IMAPI"). Pour graver des DVD sous Windows 2003 Serveur, il est nécessaire d'installer en plus la mise à jour KB932716.
