# Fonctions Vidéo

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions Caméra/Vidéo (syntaxe préfixée)](1000022386.md)).
Les fonctions permettant de gérer les vidéos sont les suivantes :

| [VidéoAffiche](3079004.md) | Affiche dans un champ Caméra la séquence vidéo actuellement retransmise par une "web caméra" ou par la caméra de l'appareil mobile. _(Android, iPhone/iPad)_ Fonction conservée pour les champs Caméra "Compatibles 26". |
| --- | --- |
| [VidéoArrête](3079001.md) | Arrête l'affichage ou l'enregistrement d'une séquence vidéo affichée dans un champ Caméra. _(Android, iPhone/iPad)_ Fonction conservée pour les champs Caméra "Compatibles 26". |
| [VidéoArrêteDécodage](1000022164.md) | Arrête le décodage d'un code-barres dans un champ Caméra. |
| [VidéoCapture](3079007.md) | Capture la séquence vidéo actuellement retransmise par une "caméra" :  - sous forme d'une image : prend une photo. - sous forme de vidéo : enregistre une vidéo. _(Android, iPhone/iPad)_ Fonction conservée pour les champs Caméra "Compatibles 26". |
| [VidéoChangeDriver](3079010.md) | Connecte le champ "Caméra" à un driver de capture vidéo spécifique. |
| [VidéoConfigure](3079009.md) | Permet de configurer le driver de capture vidéo. |
| [VidéoDemandePermission](1000022355.md) | Demande la permission d'utiliser la caméra de l'appareil. |
| [VidéoDémarreDécodage](1000022163.md) | Démarre le décodage des codes-barres dans un champ Caméra. |
| [VidéoEtat](3079006.md) | Renvoie l'état d'un champ Caméra. _(Android, iPhone/iPad)_ Fonction conservée pour les champs Caméra "Compatibles 26". |
| [VidéoGénèreMiniature](1000020268.md) | Génère une miniature de la photo ou de la vidéo spécifiée. |
| [VidéoLanceAppli](1000019368.md) | Lance l'application caméra native de l'appareil afin d'enregistrer une vidéo ou de prendre une photo. |
| [VidéoListeDriver](3079008.md) | Liste les drivers de capture vidéo installés sur le poste en cours. |
| [VidéoListeParamètre](1000019695.md) | Liste les valeurs supportées par la caméra de l'appareil pour un paramètre donné. _(Android, iPhone/iPad)_ Fonction conservée pour les champs Caméra "Compatibles 26". |
| [VidéoParamètre](1000019694.md) | Renvoie ou modifie la valeur d'un paramètre de la caméra de l'appareil. _(Android, iPhone/iPad)_ Fonction conservée pour les champs Caméra "Compatibles 26". |

### Remarques :

- Les fonctions Vidéoxxx et les fonctions Caméraxxx sont identiques.
- La fonction [dSauveImageJpeg](3029038.md) permet de sauver l'image contenue dans un champ Caméra :
  - soit dans un fichier au format JPEG.
  - soit en mémoire.
- La fonction [dSauveImageBmp](3029026.md) permet de sauver l'image contenue dans un champ Caméra :
  - soit dans un fichier au format BMP.
  - soit en mémoire.
