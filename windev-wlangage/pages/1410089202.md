# LecteurPDFAfficheSignet (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Positionne le document PDF affiché dans le champ Lecteur PDF sur le signet demandé.

## Exemple

```wlangage
MonPDF est un pdfDocument = "test.pdf"
PDF_MonLecteur = MonPDF

// Positionnement sur le premier signet
SI PAS MonPDF.Signet.Vide ALORS
	Signet est un pdfSignet = MonPDF.Signet[1]
	LecteurPDFAfficheSignet(PDF_MonLecteur, Signet)
FIN
```

## Syntaxe

```wlangage
LecteurPDFAfficheSignet(<Champ Lecteur PDF> , <Signet>)
```

`<Champ Lecteur PDF>` *Nom de champ*
> Nom du champ Lecteur PDF à manipuler.
`<Signet>` *Variable de type pdfSignet*
> Nom de la variable de type [pdfSignet](1410089195.md) correspondant au signet à afficher dans le champ Lecteur PDF.

**Composante : wd300obj.dll**
