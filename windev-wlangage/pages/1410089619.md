# UTF8Valide (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'une chaîne de caractères ou d'un buffer au format UTF8.

## Exemple

```wlangage
// Test : Chaîne UTF8 valide ?
SI UTF8Valide(sUTF8) ALORS
	// Oui => conversion en UNICODE
	sUNICODE est une chaîne Unicode = UTF8VersChaîne(sUTF8)
	...
FIN
```

## Syntaxe

```wlangage
<Résultat> = UTF8Valide(<Chaîne à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si la chaîne correspond à un format UTF8 valide,
> - Faux dans le cas contraire.
`<Chaîne à vérifier>` *Chaîne de caractères ou Buffer*
> Chaîne de caractères ANSI ou buffer contenant les données au format UTF8.

**Composante : wd300vm.dll**
