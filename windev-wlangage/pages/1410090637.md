# VoletVisibleParDéfaut (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

La propriété **VoletVisibleParDéfaut** permet de savoir et d'indiquer si le volet de l'éditeur d'images est visible par défaut.

## Exemple

```wlangage
// Ne pas afficher le volet dans l'éditeur d'images à son ouverture
EI_Editeur.VoletVisibleParDéfaut = Faux
```

## Syntaxe

#### Savoir si le volet du champ Editeur d'images est visible par défaut

```wlangage
<Résultat> = <Champ Editeur d'images>.VoletVisibleParDéfaut
```

`<Résultat>` *Booléen*
> - Vrai si le volet du champ est visible par défaut,
> - Faux dans le cas contraire.
`<Champ Editeur d'images>` *Nom de champ*
> Nom du champ Editeur d'images à manipuler.

#### Rendre le volet du champ Editeur d'images visible ou invisible par défaut

```wlangage
<Champ Editeur d'images>.VoletVisibleParDéfaut = <Visibilité>
```

`<Champ Editeur d'images>` *Nom de champ*
> Nom du champ Editeur d'images à manipuler.
`<Visibilité>` *Booléen*
> - Vrai si le volet du champ doit être visible par défaut,
> - Faux si le volet du champ doit être invisible par défaut.
