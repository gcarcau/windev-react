# DateFin (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Mac Catalyst)

La propriété **DateFin** permet de connaître et de modifier la date de fin d'une période. Cette propriété est utilisable sur :

- les champs Calendrier, Agenda et Planning. Pour plus de détails, consultez [Propriété DateFin](1000017427.md).
- une variable de type [saasAbonnement](1000019088.md).
- une variable de type [gglEvénement](1000017440.md).
- une variable de type [RendezVous](1000019244.md).
- une variable de type [Répétition](1000019262.md).
- une variable de type [TâcheGantt](1000020881.md).
- Nouveauté 2025
  une variable de type [hHistoriquePlanification](1410090764.md).
- Nouveauté SaaS
  une variable de type [hHistoriqueRéindexation](1410091059.md).
