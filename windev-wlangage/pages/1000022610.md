# TypeInterligne (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **TypeInterligne** permet de connaître et de modifier le type d'interligne utilisé. Cette propriété est utilisable sur :

- les variables de type [docParagraphe](1000022483.md).
- les variables de type [docNiveauNumérotation](1000022799.md).
