# <Graphe>.SMNRécupèreDonnée (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP)

Récupère une valeur numérique dans un graphe de type Secteur multiniveau.

## Exemple

```wlangage
MaVal est réel = GRF_Graphe1.SMNRécupèreDonnée("Europe" + TAB + "France" + TAB + "Montpellier")
```

## Syntaxe

```wlangage
<Résultat> = <Champ Graphe>.SMNRécupèreDonnée(<Chemin de la portion>)
```

`<Résultat>` *Réel*
> - Valeur à récupérer.
> - 0 si le chemin est invalide ou si la portion ne contient pas de donnée.
`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres, de pages ou d'états).
>
> > _(WEBDEV - Code Serveur, PHP)_ Dans les pages, seuls les champs "Graphe interactif" sont disponibles pour les graphes de type Secteur multiniveau.
`<Chemin de la portion>` *Chaîne de caractères*
> Chemin complet de la portion dont la valeur doit être récupérée. Ce paramètre est de la forme :
>
>
> ```wlangage
> "<Nom du niveau de base>" + TAB + ["<Nom du 1er niveau>" + TAB + ...["<Nom du dernier niveau>" + TAB + [...]]]"<Nom de la portion>"
> ```

## Remarques

- Pour récupérer une donnée dans un graphe Boursier, il est conseillé d'utiliser la fonction [<Graphe>.BourseRécupèreDonnée](1000023566.md).
- Pour récupérer une donnée dans un graphe Surface, il est conseillé d'utiliser la fonction [grSurfaceRécupèreDonnée](1000001036.md).
- Pour récupérer une donnée dans un autre type de graphe (Secteur, Histogramme, Courbe, etc.), utilisez [<Graphe>.RécupèreDonnée](1000024122.md).
- Pour récupérer une donnée dans un graphe de type Heatmap, il est conseillé d'utiliser la fonction [<Graphe>.HMRécupèreDonnée](1000024083.md).
