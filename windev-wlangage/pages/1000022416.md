# mongoGridFS (Type de variable)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Le type **mongoGridFS** permet de définir toutes les caractéristiques avancées d'un système de fichiers d'une base MongoDB. Les caractéristiques de ce système de fichiers peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
cnxMDB est un mongoConnexion("mongodb://db1.exemple.net")
fs est un mongoGridFS
fs.BaseDeDonnées = cnxMDB.BaseDeDonnées["CRM"]
fs.Préfixe = "myfs"
Trace(MongoGridFSListeFichier(fs))
```

## Déclaration

```wlangage
MaVariable est un mongoGridFS(<Base de données>, <Préfixe>)
```

`<Base de données>` *Chaîne de caractères*
> Base de données MongoDB contenant le système de fichiers.
`<Préfixe>` *Chaîne de caractères*
> Préfixe de la collection.
> Les fichiers seront stockés dans les collections sous la forme **<prefixe>.files** et **<prefixe>.chunck**.

## Propriétés

### Propriétés spécifiques à la description des variables de type mongoGridFS
Les propriétés suivantes peuvent être utilisées pour manipuler un système de fichiers MongoDB :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| BaseDeDonnées | Variable de type [mongoBase](1000022410.md) | Base de données contenant le système de fichiers. |
| Préfixe | Chaîne de caractères | Préfixe de la collection.  Les fichiers seront stockés dans les collections sous la forme **<prefixe>.files** et **<prefixe>.chunck**. |

## Remarques

### Fonctions manipulant le type mongoGridFS
Les fonctions manipulant le type mongoGridFS sont les suivantes :

| [MongoGridFSEnvoieFichier](1000022436.md) | Copie un fichier du poste local vers un système de fichiers MongoDB (GridFS). |
| --- | --- |
| [MongoGridFSListeFichier](1000022438.md) | Récupère la liste des fichiers MongoDB présents dans le système de fichiers MongoDB (gridFS). |
| [MongoGridFSRécupèreFichier](1000022439.md) | Récupère sur le poste local un fichier identifié par son nom et présent dans un système de fichiers MongoDB. |
| [MongoGridFSRécupèreFichierParID](1000022595.md) | Récupère sur le poste local un fichier (identifié par son identifiant) présent dans un système de fichiers MongoDB. |
| [MongoGridFSRécupèreInfoFichier](1000023495.md) | Permet de récupérer les informations concernant un fichier MongoDB (gridFS). |
| [MongoGridFSSupprimeFichier](1000022440.md) | Supprime un fichier identifié par son nom dans un système de fichiers MongoDB. |
| [MongoGridFSSupprimeFichierParID](1000022596.md) | Supprime un fichier identifié par son identifiant dans un système de fichiers MongoDB. |

**Remarque** : Ces fonctions peuvent également manipuler une base MongoDB. Dans ce cas, le préfixe correspond à la valeur pas défaut "fs".
