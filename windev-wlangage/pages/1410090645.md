# Paramètres de la procédure utilisée par la fonction PartageProximitéEnvoie

> **Disponible :** **WINDEV Mobile** (Android)

Procédure WLangage (également nommée "callback") appelée par la fonction [PartageProximitéEnvoie](1410090653.md) pour notifier le succès ou l'échec de l'envoi.

## Exemple

```wlangage
PartageProximitéEnvoie(gTabAppareilsSélectionnés, SAI_Message, CallbackEnvoi)
```

```wlangage
PROCÉDURE CallbackEnvoi(bResultat est un booléen, nIdTransfert est un entier)
SI bResultat ALORS
	ToastAffiche("Message envoyé")
SINON
	ToastAffiche(ErreurInfo())
FIN
```

## Syntaxe

```wlangage
PartageProximitéEnvoie_Callback(<Résultat> , <Identifiant>)
```

`<Résultat>` *Booléen*
> - Vrai si les données ont été envoyées,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet de connaître le détail de l'erreur.
`<Identifiant>` *Entier*
> Identifiant du transfert.
