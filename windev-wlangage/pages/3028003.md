# DDEDéconnecte (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Supprime une connexion entre le programme en cours et un destinataire.

## Exemple

```wlangage
MaConnexion = DDEConnecte("Excel", Sujet)		// Connexion
Compteur = 3			// Répète 3 fois si nécessaire
BOUCLE				// Envoie les données
	SI DDEEnvoie(MaConnexion, Item, Data, 10) ALORS SORTIR
	Compteur --
	SI Compteur = 0 ALORS
		Erreur("L'information n'a pas pu être envoyée à Excel")
		SORTIR
	FIN
FIN
DDEDéconnecte(MaConnexion)		// Déconnexion
```

## Syntaxe

```wlangage
<Résultat> = DDEDéconnecte([<Identifiant connexion>])
```

`<Résultat>` *Booléen*
> - Vrai si la déconnexion a été effectuée,
> - Faux en cas d'erreur (la fonction [DDEErreur](3028006.md) permet d'obtenir le compte-rendu de l'erreur).
`<Identifiant connexion>` *Entier optionnel*
> Identifiant de la connexion renvoyé par la fonction [DDEConnecte](3028015.md). Si ce paramètre n'est pas précisé, la dernière connexion manipulée est déconnectée.

**Composante : wd300std.dll**
