# Propriétés associées à un champ Libellé

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

## Propriétés associées à un champ Libellé

Un champ Libellé peut être manipulé en WLangage aussi bien dans une fenêtre ou une page que dans un état avec les propriétés suivantes :

- Propriétés associées à un champ Libellé dans une fenêtre.
- Propriétés associées à un champ Libellé dans une page (code serveur, code navigateur et PHP).
- Propriétés associées à un champ Libellé dans un état.
