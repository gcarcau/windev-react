# LangueVersAlphabet (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Renvoie l'alphabet correspondant à une langue.

## Exemple

```wlangage
// Connaître l'alphabet correspondant
// à la langue arménienne
ResAlphabet est un entier
ResAlphabet = LangueVersAlphabet(langueArménien)
SELON ResAlphabet
	CAS alphabetArabe :
	 ...
	CAS alphabetChinois :
	 ...
	CAS alphabetEuropeEst :
	 ...
FIN
```

```wlangage
// Connaître l'alphabet correspondant
// à la langue chinoise à Taiwan
ResAlphabet est un entier
ResAlphabet = LangueVersAlphabet(langueChinois, 1)
SELON ResAlphabet
	CAS alphabetChinois :
	 ...
	CAS alphabetChinoisTraditionnel :
	 ...
FIN
```

## Syntaxe

```wlangage
<Résultat> = LangueVersAlphabet(<Langue> [, <Sous-langue>])
```

`<Résultat>` *Constante de type Entier*
> Constante identifiant l'alphabet de la langue spécifiée. Pour plus de détails sur ces constantes, consultez [Correspondance entre les langues, les sous-langues, les alphabets et les nations](3054022.md).
`<Langue>` *Constante de type Entier*
> Langue dont on veut connaître l'alphabet. Pour plus de détails sur ces constantes, consultez [Correspondance entre les langues, les sous-langues, les alphabets et les nations](3054022.md).
`<Sous-langue>` *Entier optionnel*
> Numéro de la sous-langue dont on veut connaître l'alphabet. Pour plus de détails sur ces sous-langues, consultez [Correspondance entre les langues, les sous-langues, les alphabets et les nations](3054022.md).
> Si ce paramètre n'est pas spécifié, l'alphabet standard de la <Langue> spécifiée est donné.
