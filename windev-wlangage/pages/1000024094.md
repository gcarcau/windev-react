# <Graphe>.Menu (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Permet de choisir le type du menu contextuel affiché par un graphe.

## Exemple

```wlangage
// Active le menu contextuel sous forme de fenêtre pour le champ GRF_MonGraphe
GRF_MonGraphe.Menu(grMenuFenêtre)
```

## Syntaxe

```wlangage
<Champ Graphe>.Menu(<Type de menu>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres).
`<Type de menu>` *Constante de type Entier*
> Type de menu à afficher :
>
> | *grMenuAucun* | Aucun menu contextuel n'est affiché.  Remarque : Cette constante correspond à la valeur Faux utilisée dans les versions précédentes. |
> | --- | --- |
> | *grMenuFenêtre* | Un menu contextuel sous forme de fenêtre est affiché. |
> | *grMenuPourCompatibilité* | Un menu contextuel déroulant est affiché. Cette option permet d'afficher le menu des graphes présent dans les versions antérieures à la version 23.  Remarque : Cette constante correspond à la valeur Vrai utilisée dans les versions précédentes. |

## Remarques

- Pour modifier le texte des options du menu contextuel conservé par compatibilité, utilisez la fonction [<Graphe>.OptionMenu](1000024112.md).
- Les données définies avec la fonction **<Graphe>.Menu** seront prises en compte lors du prochain appel à la fonction [<Graphe>.Dessine](1000024062.md).
