# <redisConnexion>.PipelineRécupère (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Récupère le résultat de l'exécution d'une commande Redis ayant été ajouté par [<redisConnexion>.PipelineAjoute](1410088283.md).
Nouveauté 2025
Cette fonction peut également être utilisée pour manipuler des données sur un serveur Valkey.

## Exemple

```wlangage
gRedis.PipelineAjoute("set p1 pv1")
gRedis.PipelineAjoute("set p2 pv2")
gRedis.PipelineAjoute("get p2")
gRedis.PipelineAjoute("get p1")

r1 est un redisRéponse = gRedis.PipelineRécupère()
r2 est un redisRéponse = gRedis.PipelineRécupère()
r3 est un redisRéponse = gRedis.PipelineRécupère()
r4 est un redisRéponse = gRedis.PipelineRécupère()
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.PipelineRécupère()
```

`<Résultat>` *Variable de type redisRéponse*
> Variable de type [redisRéponse](1000023534.md) contenant le résultat de la commande Redis.
`<Connexion>` *Variable de type redisConnexion*
> Nom de la variable de type [redisConnexion](1000023527.md) correspondant à la connexion au serveur Redis.

## Remarques

### Fonctionnement du pipeline
Lorsque l'ensemble des commandes souhaitées auront été ajoutées dans le pipeline, les résultats pourront être récupérés avec la fonction [<redisConnexion>.PipelineRécupère](1410088285.md).
Pour ne pas récupérer les résultats, il est possible d'utiliser la fonction [<redisConnexion>.PipelineRAZ](1410088284.md).

En l'absence de l'appel à la fonction [<redisConnexion>.PipelineRAZ](1410088284.md), il doit y avoir autant d'appels à la fonction **<redisConnexion>.PipelineRécupère** que d'appels à la fonction [<redisConnexion>.PipelineAjoute](1410088283.md).
