# <Variable Connexion>.DéconnecteClient (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Affiche un message sur le(s) poste(s) Client et déconnecte l'application. Les postes Client concernés sont les postes renseignés dans la structure [HClient](3044340.md).

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion

// Déconnexion de tous les utilisateurs de la base de données "BAL"
HClient.Base = "BAL"
MaConnexion.DéconnecteClient("Attention : Déconnexion imminente", 300)
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.DéconnecteClient(<Message de déconnexion> , <Durée d'affichage>)
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème.
>
> La fonction **<Variable Connexion>.DéconnecteClient** est bloquante : la suite du programme ne s'exécutera que lorsque les différents clients seront déconnectés.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion à manipuler.
`<Message de déconnexion>` *Chaîne de caractères*
> Message à afficher sur le poste Client avant la déconnexion.
`<Durée d'affichage>` *Entier ou Durée*
> Durée d'affichage du message exprimée en secondes. Ce paramètre peut correspondre à :
>
> - un entier correspondant au nombre de secondes,
> - une variable de type Durée,
> - l'indication directe de la durée (par exemple 1 s).
>
>
> > _(Android, Widget Android)_ La fermeture automatique après ce délai n'est pas disponible. La fenêtre reste affichée. Pour effectuer la déconnexion sans afficher la fenêtre, le paramètre <Durée d'affichage> doit être égal à 0.

## Remarques

### Fonctionnement
Le poste Client spécifié dans la structure [HClient](3044340.md) affiche le message pendant le durée indiquée et exécute la fonction [FinProgramme](3013033.md) à la fermeture de la boîte de message.

### Personnalisation de l'affichage des messages
La fonction [HSurAppelServeur](3044343.md) permet de personnaliser la gestion de l'affichage d'un message sur le poste client.
