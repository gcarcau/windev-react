# ServeurAppliListeTâchePlanifiée (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux)

Renvoie la liste des tâches planifiées de l'application (site ou Webservice).

## Exemple

```wlangage
POUR TOUT UneTâchePlanifiée DE ServeurAppliListeTâchePlanifiée() Trace(UneTâchePlanifiée.Nom)FIN
```

## Syntaxe

```wlangage
<Résultat> = ServeurAppliListeTâchePlanifiée()
```

`<Résultat>` *Tableau de variables de type serveurAppliTâchePlanifiée*
> Tableau de variables de type [serveurAppliTâchePlanifiée](1000022367.md) correspondant aux tâches planifiées de l'application (site ou Webservice).

## Remarques

Si l'application (site ou Webservice) n'a pas de tâches planifiées, la fonction retourne un tableau vide.

**Composante : wd300page.dll**
