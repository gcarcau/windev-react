# CorbeilleListeFichier (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **Autres** (Procédures stockées)

Liste les fichiers contenus dans la corbeille du système.

## Exemple

```wlangage
// -- Bouton de remplissage d'un champ Liste
// Affiche les éléments de la corbeille dans un champ Liste
sMaListeCorbeille est une chaîne
ListeSupprimeTout(LISTE_Corbeille)
sMaListeCorbeille = CorbeilleListeFichier()
ListeAjoute(LISTE_Corbeille, sMaListeCorbeille)
```

## Syntaxe

```wlangage
<Résultat> = CorbeilleListeFichier()
```

`<Résultat>` *Chaîne de caractères*
> Liste des fichiers contenus dans la corbeille. Cette liste est de la forme :
>
>
> ```wlangage
> <Nom et chemin complet d'origine 1> + TAB + <Heure d'effacement 1> + RC + ... + <Nom et chemin complet d'origine N> + TAB + <Heure d'effacement N>
> ```

**Composante : wd300std.dll**
