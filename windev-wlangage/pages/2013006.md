# Recycler les fenêtres de code

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Par défaut, une seule fenêtre de code est ouverte par élément ouvert sous l'éditeur.
Par exemple, une fenêtre de code affiche le code d'un bouton d'une fenêtre. Si une nouvelle fenêtre de code est ouverte pour afficher le code d'un champ de cette fenêtre, la fenêtre affichant le code du bouton est utilisée.

C'est le recyclage des fenêtres de code (mode par défaut).

Pour utiliser plusieurs fenêtres de code pour afficher le code de plusieurs objets d'un même élément, il suffit d'annuler le recyclage des fenêtres de code.

## Comment le faire ?

### Mettre en place le recyclage des fenêtres de code
Pour recycler les fenêtres de code d'un fichier WINDEV ou WEBDEV (fenêtre, état, etc.) :

1. Affichez un des codes de l'élément voulu.
2. Sous le volet "Affichage", dans le groupe "Aide à l'édition", cochez l'option "Réutiliser la même fenêtre de code".

### Utiliser plusieurs fenêtres de code pour un même élément
Par défaut, le recyclage des fenêtres de code est utilisé : une seule fenêtre de code est affichée pour chaque élément (fenêtre, page, etc.).
Pour afficher plusieurs fenêtres de code pour un élément WINDEV, WINDEV Mobile ou WEBDEV (fenêtre, état, etc.) :

1. Affichez un des codes de l'élément voulu.
2. Sous le volet "Affichage", dans le groupe "Aide à l'édition", décochez l'option "Réutiliser la même fenêtre de code".

Lorsque plusieurs fenêtres de code sont ouvertes pour le même élément (par exemple, une fenêtre de code ouverte pour chaque bouton de la fenêtre) :

## Notes

### Cas des procédures globales, classes, etc.
Lors de la sélection d'une procédure ou d'une méthode dans le volet "Explorateur de projet", l'option "Editer le code dans une nouvelle fenêtre" du menu contextuel permet d'ouvrir une nouvelle fenêtre de code pour l'affichage des procédures globales (que l'option "Réutiliser la même fenêtre de code" soit cochée ou non). Il est ensuite possible de changer la vue de code affichée et/ou de la détacher grâce au clic sur l'icône .

### Utiliser plusieurs fenêtres de code pour un même élément WINDEV/WINDEV Mobile/WEBDEV (fenêtre, état, etc.)
Si le code d'un même élément (code d'un bouton, code d'un champ, etc.) est demandé plusieurs fois, la fenêtre de code correspondante est ré-activée.
