# <Variable PolygoneGéo>.Intersecte (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Vérifie si une géométrie de type polygone géographique et une géométrie quelconque ont une intersection non vide.
**Remarques** :

- Pour connaître la géométrie correspondant à l'intersection, utilisez la fonction [<Variable PolygoneGéo>.Intersection](1410090578.md).
- La fonction **<Variable PolygoneGéo>.Intersecte** ne renvoyant pas la géométrie résultat, elle est beaucoup plus rapide que la fonction [<Variable PolygoneGéo>.Intersection](1410090578.md).

## Syntaxe

```wlangage
<Résultat> = <Géométrie A>.Intersecte(<Géométrie B>)
```

`<Résultat>` *Booléen*
> - Vrai si les deux géométries ont une intersection non vide,
> - Faux dans le cas contraire.
>
> En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Géométrie A>` *Variable de type PolygoneGéo*
> Nom de la variable de type [PolygoneGéo](1410090127.md) à manipuler.
`<Géométrie B>` *Variable correspondant à des données spatiales*
> Seconde géométrie à prendre en compte pour l'intersection. Cette géométrie peut correspondre à un des types de variables suivants :
>
> - [PointGéo](1410090102.md).
> - [Point2D](1410090100.md).
> - [PolyligneGéo](1410090128.md).
> - [Polyligne2D](1410090109.md).
> - [PolygoneGéo](1410090127.md).
> - [Polygone2D](1410090122.md).
> - [MultiPointGéo](1410090130.md).
> - [MultiPoint2D](1410090129.md).
> - [MultiPolyligneGéo](1410090133.md).
> - [MultiPolyligne2D](1410090131.md).
> - [MultiPolygoneGéo](1410090136.md).
> - [MultiPolygone2D](1410090135.md).

## Remarques

### Parcours des données spatiales : utilisation des index spatiaux
Il est possible d'effectuer un parcours sur un fichier de données avec un filtre concernant des données spatiales. Par exemple, le filtre utilisé peut être basé sur le résultat de la fonction **<Variable PolygoneGéo>.Intersecte**.
Pour optimiser ce filtre sur des données spatiales, il est recommandé d'utiliser les index spatiaux via la syntaxe suivante :

```wlangage
POUR TOUT Fichier AVEC Fonction_WLangage(Fichier.Rubrique_spatiale, Variable_spatiale)
```

où :

- Fonction_WLangage correspond à la fonction **<Variable PolygoneGéo>.Intersecte**.
- Rubrique_spatiale correspond à une rubrique spatiale du fichier de données. Cette rubrique doit :
  - être de type "Données géographiques" ou de type "Données géométriques".
  - être définie comme une "Clé spatiale".
- Variable_spatiale correspond à une variable spatiale donnée, utilisée pour la comparaison avec la rubrique spatiale. Cette variable est par exemple, une variable de type PolygoneGéo, Polygone2D, etc.

Remarque : Bien que disponible, la syntaxe "POUR TOUT Fichier" n'est pas recommandée car cette syntaxe n'utilisant pas les index spatiaux, ses performances ne sont pas optimisées. En effet, dans ce cas, tout le fichier de données est parcouru : les index spatiaux ne sont pas utilisés.

```wlangage
POUR TOUT Fichier  SI Fonction_WLangage(Fichier.Rubrique_spatiale, Variable_spatiale) = Vrai ALORS    ...    FINFIN
```
