# CalculEnCours (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

La propriété **CalculEnCours** permet de savoir si le calcul d'un champ Tableau croisé dynamique est en cours (calcul synchrone ou asynchrone).
Ce calcul peut avoir été lancé par les fonctions [TCDCalculeTout](1000020539.md), [TCDCalculeToutAsynchrone](1410090244.md), [TCDCalculeMiseAJour](1000020534.md) ou [TCDCalculeMiseAJourAsynchrone](1410089990.md).

## Exemple

```wlangage
// Code du bouton de recalcul
TCDCalculeToutAsynchrone(TCD_Statistiques, Calcul_terminé)
	PROCÉDURE INTERNE Calcul_terminé(bOK est booléen)
		SI PAS bOK ALORS
			Erreur(ErreurInfo())
			RETOUR
		FIN
	FIN
```

```wlangage
// Code de clic du bouton "Détail facture"
SI TCD_Statistiques.CalculEnCours ALORS
	ToastAffiche("Calcul du Tableau croisé dynamique en cours")
	RETOUR
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Champ Tableau croisé dynamique>.CalculEnCours
```

`<Résultat>` *Booléen*
> - Vrai si le calcul du champ Tableau croisé dynamique est en cours,
> - Faux dans le cas contraire.
`<Champ Tableau croisé dynamique>` *Nom de champ*
> Nom du champ Tableau croisé dynamique manipulé.
