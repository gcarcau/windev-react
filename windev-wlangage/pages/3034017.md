# Fonctions de gestion des erreurs en exécution

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Les fonctions permettant de gérer les erreurs et les exceptions sont les suivantes :

| [ErreurChangeParamètre](3034009.md) | Paramètre le comportement automatique à adopter en cas d'erreur dans le traitement en cours. |
| --- | --- |
| [ErreurDéclenche](3034011.md) | Déclenche une erreur non fatale. |
| [ErreurInfo](3013008.md) | Récupère des informations sur la dernière erreur d'une fonction d'une composante de WINDEV, WINDEV Mobile ou de WEBDEV. |
| [ErreurPropage](3034015.md) | Propage une erreur non fatale qui pourra être traitée par le code appelant, si ce code a activé une gestion des erreurs non fatales (sous l'éditeur de code, ou par la fonction [ErreurChangeParamètre](3034009.md)). |
| [ErreurRAZ](1000025702.md) | Réinitialise la détection des erreurs non fatales :   - Le résultat de la fonction [ErreurInfo](3013008.md) est réinitialisé. - La variable [ErreurDétectée](3087001.md) revient à Faux. |
| [ErreurRestaureParamètre](3034012.md) | Rétablit le traitement d'erreur d'un traitement. |
| [ExceptionActive](3034002.md) | Ré-active le traitement d'exception en cours si l'exception a pu être corrigée. |
| [ExceptionAffiche](1000019408.md) | Affiche la fenêtre standard des exceptions avec le contenu de l'exception courante. |
| [ExceptionChangeParamètre](3034007.md) | Paramètre le comportement automatique à adopter en cas d'exception dans le traitement en cours. |
| [ExceptionDéclenche](3034005.md) | Déclenche artificiellement le mécanisme de sécurité de WLangage en provoquant une exception. |
| [ExceptionInfo](3034006.md) | Récupère des informations sur l'exception en cours. |
| [ExceptionPropage](3034014.md) | Propage une exception. |
| [ExceptionRestaureParamètre](3034008.md) | Rétablit le traitement d'exception d'un traitement. |
