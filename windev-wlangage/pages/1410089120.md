# Composant (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

Le type **Composant** permet de manipuler facilement un composant externe. Il permet de récupérer une [interface](6010017.md) globale sur le composant.

## Exemple

```wlangage
// Charment d'un composant
compo est un Composant
SI ComposantCharge(compo, fRepExe() + fSep() + "CompoExemple.wdk") ALORS
	Trace("OK")
	// Exécution des procédures du composant
	Trace(ComposantExécute("ProcéduresGlobales.Test"))
	Trace(ComposantExécute("ProcéduresGlobales.TestAvecParam", (1)))
FIN
```

## Syntaxe

```wlangage
MaVariable est un Composant
```

## Remarques

- Pour initialiser une variable de type Composant, utilisez la fonction [ComposantCharge](3014023.md).
- Une variable de type **Composant** peut être manipulée grâce aux fonctions :
  | [ComposantCharge](3014023.md) | Charge un composant externe. Ce composant peut être :  - un composant externe présent dans le projet en cours. - un composant externe indépendant du projet en cours. |
  | --- | --- |
  | [ComposantExécute](1410089107.md) | Exécute une procédure globale présente dans un composant externe. Ce composant externe a été précédemment chargé par la fonction [ComposantCharge](3014023.md). |
