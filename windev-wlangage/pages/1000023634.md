# <Fenêtre>.Repeint (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android)

Redessine immédiatement les champs de la fenêtre nécessitant une mise à jour graphique.
**Remarque** : Cette fonction est identique à la fonction [MultitâcheRepeint](3038004.md).

> _(WEBDEV - Code Serveur)_ Cette fonction n'a aucun effet sur les pages. Cette fonction est disponible uniquement pour simplifier la wébisation des fenêtres WINDEV ou WINDEV Mobile.

## Exemple

```wlangage
i est un entier
POUR i = 1 À 1000
	TraitementLong()
	FEN_Client.Repeint()
FIN
```

## Syntaxe

```wlangage
<Fenêtre>.Repeint()
```

`<Fenêtre>` *Nom de fenêtre*
> Nom de la fenêtre à redessiner.

## Remarques

### Comparaison avec la fonction Multitâche
Contrairement à la fonction [Multitâche](3015004.md), l'appel de la fonction **<Fenêtre>.Repeint** n'interrompt pas le code en cours (les fonctions Timer ne sont pas appelées par exemple).

**Composante : wd300obj.dll**
