# 1. Installation d'une application Android, iOS, etc.

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

| [Page précédente](1410087597.md) | [Sommaire](1410086964.md) | [Page suivante](1410086936.md) |
| --- | --- | --- |

Plusieurs méthodes sont proposées pour installer une application WINDEV Mobile :

|  | - **Installation au format APK**. Ce programme d'installation est exécuté sur le périphérique Android. - **Installation par Google Play**. - **Installation via le Store Privé**. |
| --- | --- |
|  | - **Compilation sous Xcode sur Mac**. La compilation sous Xcode permet de créer l'application exécutable sur iPhone ou iPad. - **Installation** :   - **par App Store**,  - **via un réseau In-House**,  - **via un réseau Ad-Hoc**,  - **via le Store Privé**. |
