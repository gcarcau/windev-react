# RubriqueFiltrée (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **RubriqueFiltrée** permet de connaître la rubrique sur laquelle un filtre a été mis en place par la fonction [HFiltre](3044100.md). Cette propriété est utilisable sur un fichier de données, une vue HFSQL ou une requête.

## Exemple

```wlangage
// Active le filtre
HFiltre(Client, NomClient, "D" + hValMin, "F" + hValMax, "Ville='Paris'")
Trace(Client.RubriqueFiltrée)  // Indique "NomClient"

// Désactive le filtre
HDésactiveFiltre(Client)
```

## Syntaxe

```wlangage
<Rubrique> = <Elément manipulé>.RubriqueFiltrée
```

`<Rubrique>` *Chaîne de caractères*
> - Rubrique sur laquelle s'applique le filtre défini avec la fonction [HFiltre](3044100.md),
> - Chaîne vide ("") si aucun filtre n'est actif.
`<Elément manipulé>` *Chaîne de caractères*
> Nom du fichier de données, de la requête ou de la vue HFSQL sur laquelle le filtre a été défini.
