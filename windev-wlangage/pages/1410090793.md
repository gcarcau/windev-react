# FichierVisualise (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux)

Lance la visualisation d'un fichier dans le navigateur. Le fichier est téléchargé dans un répertoire temporaire du navigateur, puis affiché dans le visualisateur dédié au type du fichier.
Si la visualisation ne peut pas être lancée (type de fichier non géré), le fichier est directement téléchargé dans le répertoire de téléchargement par défaut du navigateur.

## Exemple

```wlangage
soit sFichier = fFichierTemp()
// Remplissage du fichier
// ...
// Changement du nom du fichier temporaire pour la sauvegarde
FichierVisualise(sFichier, "Rapport" + DateSys() + ".pdf", typeMimePDF)
// Supprime le fichier temporaire à la fin du téléchargement
fSupprime(sFichier)
```

## Syntaxe

```wlangage
FichierVisualise(<Fichier à télécharger> [, <Nouveau nom du fichier> [, <Type MIME>]])
```

`<Fichier à télécharger>` *Chaîne de caractères*
> Nom du fichier (présent sur le serveur) à envoyer et afficher sur le poste au client.
`<Nouveau nom du fichier>` *Chaîne de caractères optionnelle*
> Nom sous lequel le fichier sera proposé à l'enregistrement sur le poste client. Si ce paramètre est absent ou correspond à chaîne vide (""), le nom du fichier sur le serveur sera utilisé.
> Ce nom sera également proposé par défaut à l'utilisateur si ce dernier enregistre le fichier sur son poste.
`<Type MIME>` *Chaîne de caractères optionnelle*
> Type MIME du fichier. Cette valeur sera utilisé par le poste client pour déterminer comment afficher le fichier. Si cette valeur est absente, la valeur renvoyée par la fonction [fTypeMIME](1410089105.md) (avec le nom de fichier) sera utilisée.
> Les valeurs possibles sont :
>
> - Nom du type MIME à utiliser. Le type MIME permet de préciser au navigateur le type du fichier qu'il doit manipuler. Des centaines de types sont définis dans la norme de communication MIME (disponible sur Internet). Les valeurs les plus courantes et reconnues par la plupart des navigateurs sont :
>   - "text/html" : page HTML (*.htm, *.html)
>   - "text/plain" : fichier texte (*.txt)
>   - "application/pdf" : document au format PDF (*.pdf)
>   - "image/gif" : image au format GIF (*.gif)
>   - "image/jpeg" : image au format JPEG (*.jpg, *.jpeg)
>   - "video/mpeg" : vidéo au format MPEG (*.mpg, *.mpeg)
>   - "application/msword" : permet d'afficher un fichier Word.
>   - "application/vnd.ms-excel" : permet d'afficher un fichier Excel.
> - Type MIME correspondant à une des constantes suivantes :
>   | *typeMimeApplicationXML* | Contenu de type XML. |
>   | --- | --- |
>   | *typeMimeBinaire* | Contenu de type binaire (flux d'octets). |
>   | *typeMimeDOC* | Contenu de type fichier Word (*.doc) |
>   | *typeMimeDOCX* | Contenu de type fichier Word (*.docx) |
>   | *typeMimeGIF* | Contenu de type image au format GIF (*.gif) |
>   | *typeMimeHTML* | Contenu de type page HTML (*.htm, *.html) |
>   | *typeMimeJPEG* | Contenu de type image au format JPEG (*.jpg, *.jpeg) |
>   | *typeMimeJSON* | Contenu de type JSON. |
>   | *typeMimePDF* | Contenu de type document PDF (*.pdf) |
>   | *typeMimePNG* | Contenu de type image au format PNG (*.png) |
>   | *typeMimeSOAP* | Contenu SOAP au format XML. |
>   | *typeMimeTexte* | Contenu au format texte (*.txt) |
>   | *typeMimeTexteXML* | Contenu texte au format XML |
>   | *typeMimeXLS* | Contenu au format Excel (*.xls) |
>   | *typeMimeXLSX* | Contenu au format Excel (*.xlsx) |
>   | *typeMimeZIP* | Contenu au format ZIP (*.zip) |
