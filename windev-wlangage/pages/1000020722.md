# dbgSurErreur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Provoque :

- une assertion lors du test de l'élément ou du projet (mode Go).
- une erreur en mode test automatique.

## Syntaxe

```wlangage
dbgSurErreur(<Commentaire 1> [, <Commentaire 2> [... [, <Commentaire N>]]])
```

`<Commentaire 1>` *Chaîne de caractères*
> Texte à afficher dans la fenêtre d'assertion ou dans le compte-rendu du test unitaire.
`<Commentaire 2>` *Chaîne de caractères optionnelle*
> Texte à afficher dans la fenêtre d'assertion ou dans le compte-rendu du test unitaire.
`<Commentaire N>` *Chaîne de caractères optionnelle*
> Texte à afficher dans la fenêtre d'assertion ou dans le compte-rendu du test unitaire.

## Remarques

Lorsque la fonction **dbgSurErreur** est appelée :

- en mode test automatique, une erreur est ajoutée dans le compte-rendu du test (équivalent de la fonction [TestEcritRésultat](1000013001.md)).
- en mode test manuel, une assertion est affichée (équivalent de la fonction [dbgAssertion](3014022.md)).
- en mode exécution, une assertion est affichée si les assertions ont été activées (équivalent de la fonction [dbgAssertion](3014022.md)).

**Composante : wd300vm.dll**
