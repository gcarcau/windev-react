# Connecteur Natif SAP ASE (Sybase) pour WINDEV et WEBDEV

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows)

## Présentation

En option, WINDEV et WEBDEV proposent un Connecteur Natif SAP ASE (également appelé Accès Natif à Sybase). Ce Connecteur Natif permet d'accéder à une base Sybase sans driver externe depuis un programme en WLangage.
Cette version permet également :

- D'exécuter plusieurs fois une même requête.
- De récupérer la valeur de sortie d'une procédure stockée exécutée sur le serveur

Ces fonctionnalités sont disponibles à partir de la version 12.5 de Sybase Adaptive Server Enterprise (ASE).

**Attention** : Cette version du Connecteur Natif SAP ASE (Sybase) ne fonctionne qu'avec WINDEV et/ou WEBDEV 2025.

## Configuration nécessaire

### Conditions nécessaires à l'utilisation du Connecteur Natif SAP ASE (Sybase)

- Sybase Adaptive Server Enterprise (ASE) version 10 ou supérieure (version 12.5 pour récupérer le résultat d'une procédure stockée).
- Couche client Sybase installée.
- La DLL ***LIBSYBDB.DLL*** doit être accessible :
  - à partir du poste de développement.
  - à partir du poste de déploiement.

### Les fichiers nécessaires
Les fichiers nécessaires à l'utilisation du Connecteur Natif SAP ASE (Sybase) sont :

- la DLL ***LIBSYBDB.DLL***. Cette DLL est installée par la couche client de Sybase. Pour les conditions de diffusion de cette DLL, reportez-vous à la licence de Sybase.
- ***wd300syb.dll*** : Nécessaire au Connecteur Natif à une base Sybase. Ce fichier est livré avec le Connecteur Natif WINDEV/WEBDEV pour Sybase.

## Utilisation

### Utiliser le Connecteur Natif SAP ASE (Sybase) dans vos applications WINDEV et vos sites WEBDEV
Pour utiliser Sybase en natif, il suffit de programmer :

- soit avec les fonctions "SQL" du WLangage (voir [Programmation à l'aide des fonctions SQL](5516001.md)).
- soit avec les fonctions "HFSQL" du WLangage (voir [Programmation à l'aide des fonctions HFSQL](5516006.md)).

**Remarques** :

- N'oubliez pas de consulter les [limitations concernant l'utilisation du Connecteur Natif SAP ASE (Sybase)](5516004.md).
- L'option "Créer les fichiers de données automatiquement au moment de leur ouverture" (disponible dans l'onglet "Fichiers de données" de la description du projet) est prise en compte par le Connecteur Natif SAP ASE (Sybase).
