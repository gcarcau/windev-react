# Fonctions de gestion de la reconnaissance vocale

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Les fonctions permettant de gérer la reconnaissance vocale sont les suivantes :

| [ReconnaissanceVocaleAjouteCommande](1000020014.md) | Ajoute une commande vocale dans la fenêtre en cours. |
| --- | --- |
| [ReconnaissanceVocaleDéclenche](1000020013.md) | Déclenche le service de reconnaissance vocale de l'appareil. |
| [ReconnaissanceVocaleSupprimeCommande](1000020017.md) | Supprime une commande vocale précédemment ajoutée par la fonction [ReconnaissanceVocaleAjouteCommande](1000020014.md). |

> _(iPhone/iPad)_ Ces fonctions sont utilisables uniquement à partir de iOS 10.

> _(WINDEV, Windows)_ Remarque : Par compatibilité avec les versions précédentes, les fonctions suivantes sont également disponibles :
AjouteCommandeVocaleAjoute une commande vocale dans la fenêtre en cours. A partir de la version 17, cette fonction est remplacée par la fonction ReconnaissanceVocaleAjouteCommande.SupprimeCommandeVocaleSupprime une commande vocale précédemment ajoutée par la fonction AjouteCommandeVocale. A partir de la version 17, cette fonction est remplacée par la fonction ReconnaissanceVocaleSupprimeCommande.
