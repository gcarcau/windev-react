# Fonctions de pilotage du Serveur d'application WEBDEV (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Les fonctions de gestion des utilisateurs et des connexions sur un Serveur d'application WEBDEV via une syntaxe préfixée sont les suivantes :
| [<Variable adminWBAuth>.CréeCompte](1410089712.md) | Crée un compte WEBDEV sur un Serveur d'application WEBDEV. |
| --- | --- |
| [<Variable adminWBAuth>.Déconnecte](1410089713.md) | Supprime une connexion sur un Serveur d'application WEBDEV. |
| [<Variable adminWBAuth>.ListeApplication](1410090464.md) | Renvoie la liste des applications WEBDEV d'un serveur d'application, pour un compte donnée, et pour un type donné. |
| [<Variable adminWBAuth>.ListeCompte](1410089714.md) | Renvoie la liste des comptes WEBDEV sur un Serveur d'application WEBDEV. |
| [<Variable adminWBAuth>.ListeConnexion](1410089715.md) | Renvoie la liste des connexions en cours sur un Serveur d'application WEBDEV. |
| [<Variable adminWBAuth>.ModifieCompte](1410089716.md) | Modifie les paramètres d'un compte WEBDEV sur un Serveur d'application WEBDEV. |
| [<Variable adminWBAuth>.SupprimeApplication](1410090465.md) | Supprime une application du serveur d'application WEBDEV. |
| [<Variable adminWBAuth>.SupprimeCompte](1410089717.md) | Supprime un compte WEBDEV sur un Serveur d'application WEBDEV. |
