# Opérateur d'échange (<=>)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

L'opérateur **<=>** permet d'échanger les contenus de deux éléments. Si nécessaire, les conversions de type sont effectuées. Retourne l'adresse d'une variable sous la forme d'un entier.

## Exemple

```wlangage
I est un entier = 5
J est un entier = 6
I <=> J
```

## Syntaxe

```wlangage
<Élément 1> <=> <Élément 2>
```

`<Élément 1>` *Type simple*
> Nom de la variable, du champ, de la rubrique HFSQL dont le contenu doit être échangé avec le contenu de <Élément 2>.
`<Élément 2>` *Type simple*
> Nom de la variable, du champ, de la rubrique HFSQL dont le contenu doit être échangé avec le contenu de <Élément 1>.

## Remarques

L'opérateur d'échange ne fonctionne qu'avec des types simples.
