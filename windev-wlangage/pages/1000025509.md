# CarteAjouteForme (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Ajoute une nouvelle forme (polygone, ligne, cercle) sur la carte affichée dans un champ Carte.

## Exemple

```wlangage
// Ajoute un polygone dans le champ Carte
Polygone est un CartePolygone
POUR TOUTE PositionPoint DE tabPositions
	Ajoute(Polygone.Point, PositionPoint)
FIN
Polygone.CouleurTrait = RougeClair
Polygone.ActionClic = ProcClic
CarteAjouteForme(CARTE_MaCarte, Polygone)
```

## Syntaxe

```wlangage
<Résultat> = CarteAjouteForme(<Champ Carte> , <Forme>)
```

`<Résultat>` *Booléen*
> - Vrai si la forme a pu être ajoutée dans le champ Carte,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler. Si ce paramètre correspond à une chaîne vide (""), le champ Carte auquel appartient le traitement en cours sera utilisé.
`<Forme>` *Variable de type CarteCercle, CartePolygone ou CartePolyligne*
> Forme à dessiner sur la carte affichée dans le champ Carte. Cette forme est décrite à l'aide d'un des types de variables suivants :
>
> - une variable de type [CartePolygone](1000025476.md),
> - une variable de type [CartePolyligne](1000025489.md),
> - une variable de type [CarteCercle](1000025504.md).

## Remarques

- Lorsque la forme a été ajoutée, il sera possible de la manipuler par son nom (propriété **Nom** de la variable associée).
- Si la forme a été déjà été ajoutée dans le champ Carte ou si la forme est invalide (exemple : polygone avec un nombre insuffisant de points), une erreur fatale sera affichée.
- Pour supprimer une forme dessinée dans un champ Carte, utilisez la fonction [CarteSupprimeForme](1000025510.md).
- Pour modifier une forme dessinée dans un champ Carte, utilisez la fonction [CarteModifieForme](1000025511.md).
