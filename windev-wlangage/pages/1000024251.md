# <Table>.EnumèreRupture (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Enumère les ruptures d'un champ Table.

## Exemple

```wlangage
// Liste les ruptures de TABLE_MaTable
sNomRupture est chaîne
bPosition est un booléen
nNumCol est un entier

soit i = 1
sDesc est une chaîne = TABLE_MaTable.EnumèreRupture(i)
TANTQUE sDesc <> ""
	sNomRupture = ExtraitChaîne(sDesc, 1, TAB)
	bPosition = ExtraitChaîne(sDesc, 2, TAB)
	nNumCol = ExtraitChaîne(sDesc, 3, TAB)
   	SI {sNomRupture, indChamp}..Visible ALORS
		Trace(sNomRupture, bPosition, nNumCol)
	FIN
	// Rupture suivante
	i++
	sDesc = TABLE_MaTable.EnumèreRupture(i)

FIN
```

## Syntaxe

```wlangage
<Résultat> = <Champ Table>.EnumèreRupture(<Indice de la rupture>)
```

`<Résultat>` *Chaîne de caractères*
> - Description de la rupture pour l'indice spécifié. Cette description est de la forme :
>   ```wlangage
>   <Rupture> + TAB + <Position de la rupture> + TAB + <Numéro de la colonne>
>   ```
>   où :
>   - <Rupture> : Nom de la rupture.
>   - <Position de la rupture> : 1 pour un haut de rupture et 0 pour un bas de rupture.
>   - <Numéro de la colonne> : Numéro de la colonne qui provoque la rupture.
> - Chaîne vide ("") si le champ Table ne contient pas de rupture ou si le paramètre <Indice de la rupture> est égal au nombre de ruptures du champ Table + 1.
`<Champ Table>` *Nom de champ*
> Nom du champ Table à manipuler.
`<Indice de la rupture>` *Entier*
> Indice de la rupture recherchée, compris entre 1 et le nombre de ruptures du champ Table + 1.
> Si ce paramètre est supérieur au nombre de ruptures du champ Table, la fonction renvoie une chaîne vide ("").

## Remarques

### Conditions d'utilisation
La fonction **<Table>.EnumèreRupture** peut être utilisée indifféremment sur un champ Table fichier ou sur un champ Table par programmation.

**Composante : wd300obj.dll**
