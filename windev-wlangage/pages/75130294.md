# Message (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Affiche un message dans la barre des messages.

## Exemple

```wlangage
// En CAPPELWD("Message,Saisir les informations demandées");
```

```wlangage
// En PascalAPPELWD('Message,Saisir les informations demandées');
```

```wlangage
// En VBcall APPELWD("Message,Saisir les informations demandées")
```

## Syntaxe

```wlangage
Message(<Contenu du message>)
```

`<Contenu du message>` *Chaîne de caractères*
> Message à afficher.

## Remarques

Le message reste affiché jusqu'au prochain message affiché dans la barre.
