# <Popup>.Ferme (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur)

Masque un champ Popup affiché dans la page via la fonction [<Popup>.Affiche](1000021654.md).

## Exemple

```wlangage
POPUP_Question.Ferme()
```

## Syntaxe

```wlangage
<Popup>.Ferme()
```

`<Popup>` *Nom de champ*
> Nom du champ Popup qui sera masqué.

## Remarques

Les navigateurs ne rafraîchissent pas l'affichage au milieu d'un code Javascript : les fonctions [<Popup>.Affiche](1000021654.md) et **<Popup>.Ferme** doivent être utilisées dans des traitements/événements différents. Si ces fonctions sont utilisées dans le même traitement/événement, le champ Popup n'est pas affiché.

**Composante : wd300page.dll**
