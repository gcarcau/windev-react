# iImpressionAbandonnée (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android)

Permet de savoir si l'utilisateur a demandé l'abandon de l'impression du document en cours.
**Remarque** : Si l'utilisateur abandonne une impression en cours, les fonctions d'impression n'ont aucun effet jusqu'au prochain appel à la fonction [iFinImprime](3046053.md). Le code WLangage continue cependant de s'exécuter.

## Exemple

```wlangage
SI iImpressionAbandonnée() = Vrai ALORS
	Info("Vous avez annulé l'impression en cours")
FIN
```

## Syntaxe

```wlangage
<Résultat> = iImpressionAbandonnée()
```

`<Résultat>` *Booléen*
> Vrai si l'utilisateur :
>
> - a fermé le visualisateur de rapports avant la fin des impressions,
> - a cliqué sur le bouton ***Annuler*** de la fenêtre d'impression en cours.

**Composante : wd300prn.dll**
