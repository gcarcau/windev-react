# Source de données d'un état

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

## Les différentes sources de données

WINDEV, WEBDEV et WINDEV Mobile permettent de créer des états grâce à l'éditeur d'états. Les états peuvent être créés à partir de données issues :

- [d'un fichier de données](1011052.md).
- [du résultat d'une requête](1011013.md).
- [d'un champ Table présent dans une fenêtre ou une page](1011012.md).
- [d'un champ Zone répétée présent dans une fenêtre ou une page](1011093.md).
- [d'une variable](1011058.md).
- Nouveauté Abonnement
  [d'une classe en paramètre (architecture MVP)](1011097.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
- [d'un champ Table hiérarchique présent dans une fenêtre ou une page](1011082.md).
- [d'un champ Agenda présent dans une fenêtre ou une page](1011081.md).
- [d'un champ Planning présent dans une fenêtre ou une page](1011080.md).
- [d'une vue sur un fichier de données HFSQL](1011064.md).
- [d'une zone mémoire](1011061.md).
- [d'un fichier de type texte](1011011.md).
- [d'une source de données programmée](1011034.md).

L'éditeur d'états permet également de créer des états associés à aucune source de données.
Sous [le logiciel Etats & Requêtes](3088004.md), il n'est pas possible de créer :

- des états sur une vue HFSQL.
- des états sur une zone mémoire.
- des états sur un champ Table.
- des états sur un champ Zone répétée.
- des états sur un champ Table hiérarchique.
- des états sur un champ Agenda.
- des états sur un champ Planning.
- des états sur une source de données programmée.

Pour plus de détails, consultez [Limitations du logiciel Etats & Requêtes](3088005.md).

> _(Android)_ Seuls les états basés sur les fichiers de données, les requêtes ou les sources de données programmées sont disponibles.

## Notes

Si vous sélectionnez une des sources de données ci-dessus, l'éditeur d'états se charge entièrement de la programmation du parcours des enregistrements à afficher dans l'état.
Pour programmer et sélectionner vous-même les enregistrements à afficher dans l'état, choisissez un [état sur une source programmée](1011034.md).
