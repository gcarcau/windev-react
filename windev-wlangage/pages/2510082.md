# Nom (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

La propriété **Nom** permet de connaître :

- le nom de la police associée à une variable de type [Police](1514045.md).
  **Remarque** : Le nom d'une police doit correspondre à une des polices installées sur le poste en cours.
- le nom d'un champ, d'un état ou d'un bloc d'un état.
- le nom d'un champ, d'un groupe de champs ou d'une fenêtre.
- le nom d'un champ, d'un groupe de champs ou d'une page.
   La propriété **Nom** permet de connaître le nom réel d'un champ généré dans la page, c'est-à-dire **l'alias du champ**. Cette propriété est utilisable uniquement sur les champs de type champ de saisie, liste, combo, interrupteur, sélecteur et bouton.

La propriété **Nom** permet de modifier le nom de la police associée à une variable de type Police.

La propriété **Nom** permet également de gérer le nom des différents objets HFSQL. Il est ainsi possible de :

- Connaître le nom d'une connexion.
- Connaître le nom d'un objet manipulé par indirection :
  - fichier de données défini sous l'éditeur d'analyses ou défini par programmation,
  - vue,
  - requête préalablement exécutée avec la fonction [HExécuteRequête](3044080.md),
  - rubrique définie sous l'éditeur d'analyses ou définie par programmation,
  - liaison définie sous l'éditeur d'analyses ou définie par programmation.
- Définir le nom de l'élément décrit :
  - lors de la description d'un fichier par programmation,
  - lors de la description d'une rubrique par programmation,
  - lors de la description d'une liaison par programmation,
  - lors de la description d'un index full-text par programmation.

> _(Android, iPhone/iPad, Widget IOS, Mac Catalyst)_ Utilisée sur le mot-clé MaFenêtreFille, la propriété Nom permet de récupérer le nom de la dernière fenêtre fille fermée dans une application mobile.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS, Mac Catalyst, Code Utilisateur (MCU), Ajax)_ // Définir les caractéristiques d'une variable de type Police
Police1 est une Police
Police1.Nom = "Arial"
Police1.Couleur = JauneClair
Police1.Taille = 14
Police1.UnitéTaille = unitéPoint
Police1.Angle = 45
// Appliquer la police au champ "MonChamp"
MonChamp.Police = Police1

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS, Mac Catalyst, Code Utilisateur (MCU), Ajax, HFSQL Classic, HFSQL Client/Serveur, Hyper File 5.5)_ UneRub1 est une Description de Rubrique
...
// Déclaration de la rubrique 1
UneRub1.Nom = "RUB1"
UneRub1.Type = hRubTexte
UneRub1.Taille = 20
HDécritRubrique(UnFichier, UneRub1)
...
HDécritFichier(UnFichier)
HCréation(Fic_temp)

```wlangage
// Procédure à laquelle le nom d'un champ est passé en paramètre
PROCÉDURE RendreVisible(Champ)
// Nom du champ en cours
SI {Champ}..Nom = "NomClient" ALORS
	{Champ}..Visible = Vrai
FIN
```

## Syntaxe

#### Connaître le nom de l'élément spécifié

```wlangage
<Résultat> = <Elément manipulé>.Nom
```

`<Résultat>` *Chaîne de caractères*
> Nom de l'élément spécifié.
`<Elément manipulé>` *Chaîne de caractères*
> Nom de l'élément à manipuler.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst, Code Utilisateur (MCU), Ajax, HFSQL Classic, HFSQL Client/Serveur)_ Modifier le nom de l'élément spécifié Masquer les détails
<Elément manipulé>.Nom = <Nouveau nom>

 <Elément manipulé> : Chaîne de caractèresNom de l'objet dynamique manipulé :fichier défini par programmation grâce au type Description de Fichier,rubrique définie par programmation grâce au type Description de Rubrique,liaison définie par programmation grâce au type Description de Liaison.index full-text défini par programmation grâce au type Description d'IndexFullText.ouNom de la variable de type Police à manipuler. <Nouveau nom> : Chaîne de caractèresNouveau nom de l'élément spécifié

## Remarques

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst, Code Utilisateur (MCU), Ajax, Android, Widget Android, Android, Widget Android, Android, Widget Android)_ Une police peut être créée à partir d'une variable de type Police.Pour définir les caractéristiques de la police, utilisez :soit la fonction PoliceCrée. Cette fonction n'est pas disponible. soit les propriétés Alphabet, Angle, Barré, Couleur, Gras, Italique, Interlettre, Interligne, Nom, Souligné, Taille et UnitéTaille. Les propriétés Alphabet, Angle ne sont pas disponibles pour les variables de type Police. Cette police pourra être utilisée :Pour écrire du texte dans des dessins (fonction dPolice).Pour écrire dans les graphes (fonctions grPoliceEtiquette, grPoliceLégende, grPoliceTitre et grPoliceTitreAxe).Pour imprimer (fonction iPolice).Dans les champs d'une fenêtre (propriété Police des champs d'une fenêtre).Dans les champs d'un état (propriété Police des champs d'un état). Cette police pourra être utilisée uniquement dans les champs d'une fenêtre (propriété Police des champs d'une fenêtre).

> _(WINDEV, Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst, Code Utilisateur (MCU))_ Alias d'une fenêtreUne même fenêtre (fille ou soeur) peut être ouverte plusieurs fois en parallèle. Pour différencier et identifier les fenêtres ouvertes, un alias est attribué à chaque fenêtre.Pour définir un alias, utilisez les fonctions OuvreSoeur ou OuvreFille. Cet alias est utilisé pour identifier les fenêtres avec les fonctions acceptant un nom de fenêtre en paramètre (TitreEnCours, TitreSuivant, DonneFocusEtRetourUtilisateur, etc.) ou pour manipuler un champ d'une fenêtre donnée.Pour connaître l'alias d'une fenêtre, utilisez les fonctions FenEnCours, FenPrécédente ou la propriété Alias.Si aucun alias n'est précisé lors de l'ouverture d'une fenêtre, WINDEV attribue automatiquement un alias à cette fenêtre.

> _(WINDEV, Java, Code Utilisateur (MCU))_ Nom d'un volet d'ongletLa propriété Nom renvoie le nom du volet d'onglet. Par exemple : Onglet[2] pour le second volet d'onglet.

> _(WINDEV, WEBDEV - Code Serveur, Android, iPhone/iPad, Widget IOS, Mac Catalyst, Java, Code Utilisateur (MCU), PHP, Ajax)_ Type d'objetLa propriété Nom renvoie une chaîne vide ("") pour : les lignes des champs Table, Liste, Liste image ou Combo, les cellules des champs Table.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS, Mac Catalyst, Code Utilisateur (MCU), Ajax, HFSQL Client/Serveur, OLE DB, Connecteurs Natifs (Accès Natifs))_ Nom d'une connexionUne connexion peut être créée grâce à une variable de type Connexion. Le nom de la connexion correspond alors au nom de la variable. Si une connexion de même nom existe déjà (dans l'analyse ou décrite précédemment), le nom de la connexion est défini par le moteur HFSQL qui suffixe le nom de la variable par un numéro.Dans ce cas, la propriété Nom permet de connaître le nom de la connexion définit par le moteur HFSQL.

> _(Android, iPhone/iPad, Widget IOS, Mac Catalyst)_ Connaître le nom de la dernière fenêtre fille ferméeDans les applications mobiles, l'ouverture des fenêtres est effectuée par la fonction OuvreFenêtreMobile (ou la fonction OuvreFille) et non la fonction Ouvre. Il est possible de connaître le nom de la dernière fenêtre fille fermée dans l'événement "Fermeture d'une fenêtre fille" de la fenêtre ouvrant la fenêtre fille (celle qui a utilisé la fonction OuvreFenêtreMobile ou la fonction OuvreFille).Il suffit d'utiliser la propriété Nom sur le mot-clé MafenêtreFille :

// Fermeture d'une fenêtre fille
NomFenêtreFille = MaFenêtreFille.Nom

Remarque : La propriété ValeurRenvoyée permet de connaître la valeur renvoyée par la fenêtre fille lors de sa fermeture.

### Limites

> _(WINDEV, WEBDEV - Code Serveur)_ La propriété Nom ne peut pas être utilisée sur :une option d'un champ Sélecteur ou Interrupteur,un élément d'un champ Arbre.

> _(WEBDEV - Code Navigateur)_ La propriété Nom s'applique uniquement sur les champs suivants :Champ de saisie,Champ Liste,Champ Combo,Champ Interrupteur,Champ Sélecteur,Champ Bouton, Groupe de champs.

> _(Java)_ La propriété Nom s'applique uniquement aux éléments suivants :Champ Bouton.Champ Libellé.Champ de saisie.Champ Image.Champ Interrupteur.Champ Sélecteur.Champ Liste.Champ Combo.Champ Arbre.Champ Onglet.Fenêtre.Champ Table.Colonne de table.Superchamp.

> _(Widget Android)_ La propriété Nom s'applique uniquement aux éléments suivants :Champ Bouton.Champ Libellé.Champ Image.Fenêtre.
