# BitcoinCoreDateHeureDernierBloc (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Renvoie la date et l'heure de création du dernier bloc.
**Remarque** : En moyenne, un nouveau bloc est produit par le réseau toutes les 10 minutes. La fonction **BitcoinCoreDateHeureDernierBloc** permet par exemple :

- de savoir si le noeud Bitcoin a perdu sa connexion/synchonisation avec le réseau.
- d'avoir une preuve forte qu'une date/heure est passée sans devoir se fier à la date/heure de l'ordinateur.

## Exemple

```wlangage
// Récupération de la date et heure du dernier bloc de la chaîne valide
d est une DateHeure
d = BitcoinCoreDateHeureDernierBloc()
SI ErreurDétectée ALORS
	Erreur()
	RETOUR
FIN
Trace("Date du dernier bloc :" + DateVersChaîne(d))
```

## Syntaxe

```wlangage
<Résultat> = BitcoinCoreDateHeureDernierBloc()
```

`<Résultat>` *DateHeure*
> Date et heure de création du dernier bloc.
