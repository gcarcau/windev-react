# Préfixe (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **Préfixe** permet de définir des préfixes. Cette propriété est utilisable sur :

- une variable de type [mongoGridFS](1000022416.md).
- une variable de type [FormatNumérique](1410089836.md).
