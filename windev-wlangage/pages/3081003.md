# Constantes de gestion des documents XML

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |
| **depuisChaîne** | Charge un document XML depuis une chaîne ou un buffer. | [XMLOuvre](1000018792.md) |
| **depuisFichier** | Charge un document XML depuis un fichier. | [XMLOuvre](1000018792.md) |
| **depuisURL** | Charge un document XML depuis une URL. | [XMLOuvre](1000018792.md) |
| **xdHTML** | Document de type HTML. Cette constante permet d'optimiser le fonctionnement de la fonction [XMLConstruitChaîne](3081016.md). | [XMLDocument](3081008.md) |
| **xHTML** | Précise que le document XML contient du HTML. **Attention** : Cette constante n'est plus disponible. | [XMLDocument](3081008.md) |
| **XMLAttribut** | Précise que l'élément est un attribut. | [XMLFilsExiste](3081038.md),  [XMLTypeElement](3081031.md),  [XMLRecherche](3081025.md) |
| **XMLAvecNamespace** | Recherche sur les éléments contenant un namespace. | [XMLRecherche](3081025.md) |
| **XMLBalise** | Précise que l'élément est une balise. | [XMLTypeElement](3081031.md),  [XMLRecherche](3081025.md),  variables de type [xmlNoeud](1000018786.md) |
| **XMLCDATA** | Précise qu'un noeud contient des données brutes. | Variables de type [xmlNoeud](1000018786.md) |
| **XMLCommencePar** | La recherche permettra de sélectionner tous les éléments commençant par une suite de caractères définie. | [XMLDonnée](3081004.md),  [XMLRecherche](3081025.md) |
| **XMLConserveNoeudTexteVide** | Permet de conserver les noeuds texte contenant uniquement des caractères blancs (espace, tabulation, RC). Cette constante est notamment nécessaire si la fonction [XMLVérifieSignature](1410090391.md) doit être utilisée. | [XMLOuvre](1000018792.md) |
| **XMLContient** | La recherche permettra de sélectionner tous les éléments contenant une suite de caractères définie. | [XMLDonnée](3081004.md),  [XMLRecherche](3081025.md) |
| **XMLContinue** | La recherche sera "montante" et "descendante" dans l'arborescence. | [XMLRecherche](3081025.md) |
| **XMLDocumentDéfaut** | Construit un document XML avec un entête par défaut. | [XMLConstruitChaîne](3081016.md), [XMLSauve](1000019026.md) |
| **XMLElément** | Précise que l'élément peut être un attribut ou une balise. | [XMLRecherche](3081025.md) |
| **XMLElémentPrécédent** | L'insertion s'effectue juste avant la balise en cours, dans la même branche. | [XMLInsèreDocument](3081014.md),  [XMLInsèreElément](3081007.md) |
| **XMLElémentSuivant** | L'insertion s'effectue juste après la balise en cours, dans la même branche. | [XMLInsèreDocument](3081014.md),  [XMLInsèreElément](3081007.md) |
| **XMLEncodageAucun** | Aucun encodage. | [rssAffiche](1000017397.md),  [rssConstruitChaîne](1000017395.md),  [rssSauve](1000017396.md),  [XMLConstruitChaîne](3081016.md) |
| **XMLEncodageIso8859_1** | Encodage selon l'alphabet latin. | [rssAffiche](1000017397.md),  [rssConstruitChaîne](1000017395.md),  [rssSauve](1000017396.md),  [XMLConstruitChaîne](3081016.md) |
| **XMLEncodageIso8859_2** | Encodage selon Iso8859_2. | [rssAffiche](1000017397.md),  [rssConstruitChaîne](1000017395.md),  [rssSauve](1000017396.md),  [XMLConstruitChaîne](3081016.md) |
| **XMLEncodageIso8859_3** | Encodage selon Iso8859_3. | [rssAffiche](1000017397.md),  [rssConstruitChaîne](1000017395.md),  [rssSauve](1000017396.md),  [XMLConstruitChaîne](3081016.md) |
| **XMLEncodageIso8859_4** | Encodage selon Iso8859_4. | [rssAffiche](1000017397.md),  [rssConstruitChaîne](1000017395.md),  [rssSauve](1000017396.md),  [XMLConstruitChaîne](3081016.md) |
| **XMLEncodageIso8859_5** | Encodage selon Iso8859_5. | [rssAffiche](1000017397.md),  [rssConstruitChaîne](1000017395.md),  [rssSauve](1000017396.md),  [XMLConstruitChaîne](3081016.md) |
| **XMLEncodageIso8859_6** | Encodage selon Iso8859_6. | [rssAffiche](1000017397.md),  [rssConstruitChaîne](1000017395.md),  [rssSauve](1000017396.md),  [XMLConstruitChaîne](3081016.md) |
| **XMLEncodageIso8859_7** | Encodage selon Iso8859_7. | [rssAffiche](1000017397.md),  [rssConstruitChaîne](1000017395.md),  [rssSauve](1000017396.md),  [XMLConstruitChaîne](3081016.md) |
| **XMLEncodageIso8859_8** | Encodage selon Iso8859_8. | [rssAffiche](1000017397.md),  [rssConstruitChaîne](1000017395.md),  [rssSauve](1000017396.md),  [XMLConstruitChaîne](3081016.md) |
| **XMLEncodageIso8859_9** | Encodage selon Iso8859_9. | [rssAffiche](1000017397.md),  [rssConstruitChaîne](1000017395.md),  [rssSauve](1000017396.md),  [XMLConstruitChaîne](3081016.md) |
| **XMLEncodageIso8859_15** | Encodage selon l'alphabet latin-9. | [rssAffiche](1000017397.md),  [rssConstruitChaîne](1000017395.md),  [rssSauve](1000017396.md),  [XMLConstruitChaîne](3081016.md) |
| **XMLEncodageUTF8** | Encodage Unicode 8. | [rssAffiche](1000017397.md),  [rssConstruitChaîne](1000017395.md),  [rssSauve](1000017396.md),  [XMLConstruitChaîne](3081016.md) |
| **XMLEncodageUTF16** | Encodage Unicode. | [rssAffiche](1000017397.md),  [rssConstruitChaîne](1000017395.md),  [rssSauve](1000017396.md),  [XMLConstruitChaîne](3081016.md) |
| **XMLEncodeEtCommercial** | Si le caractère "&" ("et" commercial) est présent dans la valeur de la balise ajoutée, il sera encodé sous la forme "&". Si cette valeur d'option n'est pas spécifiée, le caractère "&" sera conservé sans modification. | [XMLAjouteFils](3081002.md) |
| **XMLErreur** | Le type de l'élément n'a pas été reconnu. | [XMLTypeElement](3081031.md) |
| **XMLExact** | Effectue une recherche à l'identique avec prise en compte de la casse. | [XMLExtraitChaîne](3081017.md), [XMLRecherche](3081025.md) |
| **XMLIgnoreLaCasse** | Effectue une recherche à l'identique en ignorant la casse. | [XMLExtraitChaîne](3081017.md), [XMLRecherche](3081025.md) |
| **XMLLecteurAucun** | Type du noeud : Ne correspond pas à un noeud. | Type [xmlLecteur](1000023392.md) |
| **XMLLecteurBaliseDébut** | Type du noeud : Début de balise. | Type [xmlLecteur](1000023392.md) |
| **XMLLecteurBaliseFin** | Type du noeud : Fin de balise. | Type [xmlLecteur](1000023392.md) |
| **XMLLecteurBaliseVide** | Type du noeud : Balise vide. | Type [xmlLecteur](1000023392.md) |
| **XMLLecteurCDATA** | Type du noeud : Section CDATA. | Type [xmlLecteur](1000023392.md) |
| **XMLLecteurCommentaire** | Type du noeud : Commentaires. | Type [xmlLecteur](1000023392.md) |
| **XMLLecteurEntité** | Type du noeud : Déclaration d'une entité. | Type [xmlLecteur](1000023392.md) |
| **XMLLecteurInconnu** | Type du noeud : Type inconnu. | Type [xmlLecteur](1000023392.md) |
| **XMLLecteurProcessingInstruction** | Type du noeud : Processing instruction. | Type [xmlLecteur](1000023392.md) |
| **XMLLecteurRéférenceEntité** | Type du noeud : Référence à une entité. | Type [xmlLecteur](1000023392.md) |
| **XMLLecteurTexte** | Type du noeud : Texte. | Type [xmlLecteur](1000023392.md) |
| **XMLLecteurTypeDocument** | Type du noeud : Déclaration DOCTYPE. | Type [xmlLecteur](1000023392.md) |
| **XMLMiseEnForme** | Sauvegarde le document XML avec une mise en forme (indentation et retours chariot). | [XMLConstruitChaîne](3081016.md), [XMLSauve](1000019026.md) |
| **XMLNiveauCourant** | La recherche s'effectuera uniquement sur le niveau courant de l'arborescence. | [XMLRecherche](3081025.md) |
| **XMLPositionCourante** | Génère le code XML à partir de la position courante dans le document XML (au lieu de la racine). | [XMLConstruitChaîne](3081016.md) |
| **XMLRPConserve** | La position n'est pas libérée (d'autres XMLRetourPosition pourront être réalisés sur cette position). | [XMLRetourPosition](3081032.md) |
| **XMLRPDéfaut** | La position est libérée. La position sauvegardée est restaurée. | [XMLRetourPosition](3081032.md) |
| **XMLRPFiltre** | Restaure le filtre posé au moment du XMLSauvePosition. | [XMLRetourPosition](3081032.md) |
| **XMLSansEntête** | Construit un document XML sans ajouter d'entête. | [XMLConstruitChaîne](3081016.md), [XMLSauve](1000019026.md) |
| **XMLSousElément** | La recherche s'effectuera sur le niveau courant et dans les branches descendantes du niveau courant de l'arborescence | [XMLRecherche](3081025.md) |
| **XMLTexte** | Précise qu'un noeud contient du texte. | Variables de type [xmlNoeud](1000018786.md) |
| **XMLValeur** | Précise que l'élément recherché est une valeur (de balise ou d'attribut). | [XMLRecherche](3081025.md) |
| **xvSansValidation** | Sauvegarde le document XML sans prendre en compte le modèle XSD précisé lors de la description du document XML. | [XMLSauve](1000019026.md) |
