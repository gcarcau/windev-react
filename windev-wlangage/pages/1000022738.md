# RuptureSupprime (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Supprime une rupture dans un champ Table ou dans un champ Zone répétée. Cette rupture a été précédemment ajoutée via la fonction [RuptureAjoute](1000022737.md).

## Exemple

```wlangage
// Ajout d'une rupture sur la date
xRupture est un Champ
xRupture <- RuptureAjoute(TABLE_Commande.COL_Date, "RuptDate", ruptHaut, 50)

//...

// Supprime la rupture "xRupture"
RuptureSupprime(xRupture)
```

## Syntaxe

```wlangage
RuptureSupprime(<Rupture>)
```

`<Rupture>` *Variable de type Champ*
> Nom de la variable de type [Champ](1000020967.md) correspondant à la rupture à supprimer.

## Remarques

- La fonction **RuptureSupprime** supprime en même temps le haut et le bas de rupture s'ils existent.
- Pour rendre invisible une rupture définie sous l'éditeur, utilisez la propriété [Visible](2510138.md).
