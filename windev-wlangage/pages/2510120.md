# TauxAncrageLargeur (Propriété)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **TauxAncrageLargeur** permet de :

- Connaître le taux d'ancrage en agrandissement d'un champ (ou d'une colonne de table) sur l'axe horizontal.
- Modifier le taux d'ancrage en agrandissement d'un champ (ou d'une colonne de table) sur l'axe horizontal.

Le taux d'ancrage permet de définir la manière dont le champ se déplace ou change de taille en fonction de l'évolution de la taille de la fenêtre (ou de l'état) à laquelle il est ancré. Le taux d'ancrage correspond au pourcentage de déplacement du champ par rapport à la fenêtre (ou à l'état). Ainsi, si le taux d'ancrage est de 0, le champ ne sera pas déplacé, si le taux d'ancrage est de 1000, l'ancrage du champ sera normal.

Le taux d'ancrage en largeur (propriété **TauxAncrageLargeur**) est appliqué si le champ est ancré en largeur (constante *ancreLargeur* utilisée pour la propriété [Ancrage](2510001.md)).

> _(WEBDEV - Code Serveur)_ Cette propriété permet uniquement de connaître le taux d'ancrage des blocs ou des champs d'un état.

## Exemple

```wlangage
// Le champ Liste s'élargit de 50% de l'agrandissement de la fenêtre (500 pour 1000).
LISTE_ListePersonne.TauxAncrageLargeur = 500
```

## Syntaxe

#### Connaître le taux d'ancrage en agrandissement d'un champ ancré en largeur

```wlangage
<Résultat> = <Champ manipulé>.TauxAncrageLargeur
```

`<Résultat>` *Entier*
> Taux d'ancrage en agrandissement compris entre 0 (champ non étiré) et 1000 (ancrage normal)
`<Champ manipulé>` *Nom du champ*
> Nom du champ (ou de la colonne) à manipuler. Ce champ peut être un champ :
>
> - d'une fenêtre.
> - d'un état.

> _(WINDEV, iPhone/iPad, Widget IOS, Java)_ Modifier le taux d'ancrage en agrandissement d'un champ ancré en largeur Masquer les détails
<Champ manipulé>.TauxAncrageLargeur = <Taux d'ancrage>

 <Champ manipulé> : Nom du champNom du champ (ou de la colonne) à manipuler. <Taux d'ancrage> : EntierNouveau taux d'ancrage en agrandissement compris entre 0 (champ non étiré) et 1000 (ancrage normal)

## Remarques

### Ancrage d'un champ

- Dans une fenêtre, la propriété [Ancrage](2510001.md) permet de définir le comportement du champ (dimensions et déplacement) lors du changement de taille de la fenêtre. Si le champ est associé à un champ Onglet, l'ancrage est défini par rapport à l'onglet.
  Pour plus de détails, consultez [Ancrage des champs dans une fenêtre](2026002.md).
- Dans le cas d'une colonne d'un champ Table ou Table hiérarchique, la propriété [Ancrage](2510001.md) n'est pas disponible. L'ancrage d'une colonne se spécifie directement avec la propriété **TauxAncrageLargeur**.
- Dans un état, la propriété [Ancrage](2510001.md) permet de connaître le comportement du champ (dimensions et déplacement) lors du changement de taille de l'état. Ce comportement a été défini sous l'éditeur d'états.
  Pour plus de détails, consultez [Ancrage des champs dans un état](1013298.md).

### Limites

> _(WINDEV, Android, iPhone/iPad, Widget IOS, Java)_ La propriété TauxAncrageLargeur s'applique à tous les champs d'une fenêtre.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS)_ La propriété TauxAncrageLargeur s'applique à tous les champs d'un état. Dans ce cas, il est uniquement possible de connaître le taux d'ancrage utilisé.

> _(Java)_ La propriété TauxAncrageLargeur s'applique uniquement aux éléments suivants :Bouton.Libellé.Champ de saisie.Image.Interrupteur.Sélecteur.Liste.Combo.Arbre.Onglet.Table.Superchamp.Regroupement de ruban.
