# FaxSuspend (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Met en pause un fax dans la file d'attente. Si le fax est actif, il sera mis en pause lorsqu'il retournera dans la file d'attente.
**Remarque** : Cette fonction ne peut être utilisée que sous Windows 2000, XP ou version supérieure. Sous Windows Vista (et supérieur), la gestion des fax est disponible uniquement avec Windows Professionnel et Windows Edition Intégrale.

## Syntaxe

```wlangage
<Résultat> = FaxSuspend(<Identifiant connexion> , <Nom du fax ou Identifiant du fax>)
```

`<Résultat>` *Booléen*
> - Vrai si le fax est mis en pause,
> - Faux en cas d'erreur (par exemple si le nom du fax n'existe pas).
`<Identifiant connexion>` *Entier*
> Identifiant de la connexion obtenu avec la fonction [FaxConnecte](3037005.md).
`<Nom du fax ou Identifiant du fax>` *Chaîne de caractères*
> Correspond :
>
> - soit au nom permettant d'identifier le fax envoyé. Ce nom a été donné avec la fonction [FaxEnvoie](3037006.md).
> - soit à l'identifiant du fax (obtenu par les fonctions [FaxBoîteEnvoi](3037008.md) ou [FaxBoîteRéception](3037009.md))

**Composante : wd300com.dll**
