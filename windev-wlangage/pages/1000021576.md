# AvancementEnvoi (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **AvancementEnvoi** permet d'obtenir la notification de l'état d'avancement de l'envoi des données POST. Cette propriété est utilisable sur :

- une variable de type [httpRequête](1000021158.md).
- une variable de type [restRequête](1000021481.md).
