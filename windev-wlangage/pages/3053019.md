# MemSupprimeTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Vide et supprime une zone mémoire.

## Exemple

```wlangage
// Suppression de la zone mémoire "MaZoneMémoire"
MemSupprimeTout("MaZoneMémoire")
```

## Syntaxe

```wlangage
MemSupprimeTout(<Zone mémoire>)
```

`<Zone mémoire>` *Chaîne de caractères*
> - Nom de la zone mémoire à supprimer, défini par la fonction [MemCrée](3053005.md).
> - "*" pour supprimer toutes les zones mémoire précédemment créées.

## Remarques

### Existence de la zone mémoire
L'existence de la zone mémoire n'est pas vérifiée.
Si la zone mémoire spécifiée n'existe pas, une erreur du WLangage est générée lors de l'exécution de la fonction **MemSupprimeTout**.

Pour vérifier l'existence d'une zone mémoire, utilisez la fonction [MemExiste](3053006.md).

**Classification Métier / UI : Code neutre**

**Composante : wd300std.dll**
