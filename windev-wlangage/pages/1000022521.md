# HDéclencheMiseAJourServeur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Permet de déclencher immédiatement la mise à jour automatique du serveur. Les utilisateurs seront déconnectés lors du lancement de cette opération.

## Exemple

```wlangage
// Déclenche la mise à jour du serveurHDéclencheMiseAJourServeur(MaConnexion)
```

## Syntaxe

```wlangage
<Résultat> = HDéclencheMiseAJourServeur(<Connexion> [, <Version>])
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème.
>
> La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion à une base de données. Cette connexion correspond :
>
> - soit au nom de la connexion définie dans l'éditeur d'analyses.
> - soit au nom de la connexion définie par la fonction [HDécritConnexion](3044205.md). La description de la connexion doit être connue au moment de l'exécution de la fonction.
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Version>` *Chaîne de caractères optionnelle*
> Version pour laquelle la mise à jour doit être effectuée (par exemple : "240036"). Par défaut, si ce paramètre n'est pas spécifié, la dernière mise à jour disponible est utilisée.

## Remarques

Le serveur de mise à jour (contenant le pack de mise à jour du serveur HFSQL) peut être défini par la fonction [HGèreMiseAJourServeur](1000022635.md).
