# HSauveParamètre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Sauve une valeur persistante. Cette valeur pourra être lue grâce à la fonction [HChargeParamètre](1000017314.md).
Remarque : Les paramètres sont sauvegardés par base de données dans le fichier "user_param.fic".

## Exemple

```wlangage
// Sauvegarde d'une valeur à partir d'une procédure stockée
// (Code serveur)
HSauveParamètre("MonParamètre", 5)
```

## Syntaxe

#### Sauvegarde d'un paramètre sur le serveur (dans le code de la procédure stockée)

```wlangage
<Résultat> = HSauveParamètre(<Paramètre> , <Valeur du paramètre>)
```

`<Résultat>` *Booléen*
> - Vrai si la sauvegarde a été réalisée,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Paramètre>` *Chaîne de caractères*
> Nom du paramètre à sauvegarder. Ce paramètre ne doit pas correspondre à une chaîne vide et ne doit pas contenir le caractère "RC" (Retour Chariot).
`<Valeur du paramètre>` *Type correspondant à la valeur à sauver*
> Valeur à sauver.

#### Sauvegarde d'un paramètre sur le serveur (depuis le poste Client)

```wlangage
<Résultat> = HSauveParamètre(<Connexion> , <Paramètre> , <Valeur du paramètre>)
```

`<Résultat>` *Booléen*
> - Vrai si la sauvegarde a été réalisée,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion à utiliser. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Paramètre>` *Chaîne de caractères*
> Nom du paramètre à sauvegarder. Ce paramètre ne doit pas correspondre à une chaîne vide et ne doit pas contenir le caractère "RC" (Retour Chariot).
`<Valeur du paramètre>` *Type correspondant à la valeur à sauver*
> Valeur à sauver.

## Remarques

### Type de variables sauvegardées
La fonction **HSauveParamètre** permet de sauvegarder des variables de type simple (chaîne, entier, ...).
Pour sauvegarder des variables complexes (objets, structures, ...), il est nécessaire de sérialiser ces variables sous forme de chaîne grâce à la fonction [Sérialise](3013065.md).
