# <Variable Image>.DessinePolyligne (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Dessine une ligne composée de plusieurs segments dans une variable de type [Image](1000019650.md).
La première coordonnée désigne le point de départ du premier segment, ensuite chaque coordonnée désigne la fin du segment précédent et le début du segment suivant.

## Exemple

```wlangage
MonImage est une Image = "Test.bmp"

MonImage.Stylo(BleuClair, 2, 4)
tabCoordonnéesXY2 est un tableau de 0 entier = [2, 2, 140, 2, 150, 70, 0, 100, 200, 100]
MonImage.DessinePolyligne(tabCoordonnéesXY2)

IMG_MonDessin = MonImage
```

## Syntaxe

#### Construction d'une ligne point par point

```wlangage
<Variable Image>.DessinePolyligne(<NbPoint> , <X1> , <Y1> , <X2> , <Y2> [, <Xn> [, <Yn> [, <Couleur du trait>]]])
```

`<Variable Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) à manipuler.
`<NbPoint>` *Entier*
> Nombre de segments de la ligne. Ce paramètre détermine le nombre de couples <X>, <Y> à spécifier dans la fonction.
`<X1>` *Entier*
> Abscisse du premier segment de la ligne. Ces coordonnées sont exprimées en pixels.
`<Y1>` *Entier*
> Ordonnée du premier segment de la ligne. Ces coordonnées sont exprimées en pixels.
`<X2>` *Entier*
> Abscisse du second segment de la ligne. Ces coordonnées sont exprimées en pixels.
`<Y2>` *Entier*
> Ordonnée du second segment de la ligne. Ces coordonnées sont exprimées en pixels.
`<Xn>` *Entier optionnel*
> Abscisse du Nième segment de la ligne. Ces coordonnées sont exprimées en pixels.
`<Yn>` *Entier optionnel*
> Ordonnée du Nième segment de la ligne. Ces coordonnées sont exprimées en pixels.
`<Couleur du trait>` *Entier ou constante (optionnel)*
> Couleur de la ligne. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md).
>
> Si ce paramètre n'est pas précisé, la couleur du trait :
>
> - est *Transparent* si la fonction [<Variable Image>.Stylo](1000024240.md) n'a pas été utilisée auparavant.
>   Dans le cas d'une variable de type [Image](1000019650.md), la ligne aura la couleur noire.
> - correspond à la couleur précisée dans le dernier appel à la fonction [<Variable Image>.Stylo](1000024240.md).

#### Construction d'une ligne par tableau de coordonnées X et Y

```wlangage
<Variable Image>.DessinePolyligne(<Tableau de coordonnées> [, <Couleur du trait>])
```

`<Variable Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) à manipuler.
`<Tableau de coordonnées>` *Tableau d'entiers ou de points*
> Tableau WLangage d'entiers contenant les coordonnées des segments composant la ligne. Les indices pairs représentent les abscisses (X) et les indices impairs représentent les ordonnées (Y) des points. Ces coordonnées sont exprimées en pixels.
`<Couleur du trait>` *Entier ou constante (optionnel)*
> Couleur de la ligne. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md),
> - une variable de type [Couleur](1000019661.md).
>
> Si ce paramètre n'est pas précisé, la couleur du trait :
>
> - est *Transparent* si la fonction [<Variable Image>.Stylo](1000024240.md) n'a pas été utilisée auparavant.
>   Dans le cas d'une variable de type [Image](1000019650.md), la ligne aura la couleur noire.
> - correspond à la couleur précisée dans le dernier appel à la fonction [<Variable Image>.Stylo](1000024240.md).

> _(Etats et Requêtes, Windows, Linux, Android, iPhone/iPad, Code Utilisateur (MCU))_ Construction d'une ligne via une variable de type Polygone Masquer les détails
<Variable Image>.DessinePolyligne(<Polygone> [, <Couleur du trait>])

 <Variable Image> : Variable de type ImageNom de la variable de type Image à manipuler. <Polygone> : Variable de type PolygoneNom de la variable de type Polygone décrivant les différents points du polygone. <Couleur du trait> : Entier ou constante (optionnel)Couleur de la ligne. Cette couleur peut correspondre à :une couleur RVB (obtenue avec la fonction RVB),une couleur TSL (obtenue avec la fonction TSL),une couleur prédéfinie du WLangage,une variable de type Couleur. Si ce paramètre n'est pas précisé, la couleur du trait :est Transparent si la fonction <Variable Image>.Stylo n'a pas été utilisée auparavant. Dans le cas d'une variable de type Image, la ligne aura la couleur noire. correspond à la couleur précisée dans le dernier appel à la fonction <Variable Image>.Stylo.

## Remarques

### Coordonnées
Les coordonnées sont indiquées par rapport au coin haut gauche de l'image (coordonnées (0,0)).
