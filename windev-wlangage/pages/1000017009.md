# ValideMotDePasse (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Indique si le mot de passe spécifié est valide pour l'utilisateur en cours. Le mot de passe peut être :

- le mot de passe d'authentification Windows
- le mot de passe du groupware utilisateur WINDEV/WEBDEV.
- le mot de passe spécifié pour le blocage des applications (mot de passe spécifié avec la fonction [VerrouAppliMotDePasse](1000017010.md)).

> _(WEBDEV - Code Serveur, Windows, Linux)_ Cette fonction est disponible uniquement pour vérifier si le mot de passe est valide pour le groupware utilisateur.

## Exemple

```wlangage
SI ValideMotDePasse("MonMotDePasse") = Vrai ALORS
	Info("Utilisateur reconnu")
SINON
	Info("Mauvais mot de passe")
FIN
```

## Syntaxe

```wlangage
<Résultat> = ValideMotDePasse(<Mot de passe> [, <Authentification>])
```

`<Résultat>` *Booléen*
> - Vrai si le mot de passe est correct,
> - Faux dans le cas contraire.
`<Mot de passe>` *Chaîne de caractères ou Chaîne secrète*
> Mot de passe à valider pour l'utilisateur en cours.
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).
`<Authentification>` *Constante de type Entier optionnelle*
> Méthode d'authentification du mot de passe :
>
>
> | *mdpGpw* | Authentification réalisée par le groupware utilisateur de WINDEV/WEBDEV. |
> | --- | --- |
> | *mdpPersonnalisé* | Authentification réalisée par rapport au mot de passe spécifié avec la fonction [VerrouAppliMotDePasse](1000017010.md). _(WEBDEV - Code Serveur)_ Cette constante n'est pas disponible. |
> | *mdpWindows* | Authentification réalisée par rapport au mot de passe Windows. _(WEBDEV - Code Serveur)_ Cette constante n'est pas disponible. |
>
>
> Si <Authentification> n'est pas précisé :
>
> - Si la fonction [VerrouAppliMotDePasse](1000017010.md) a été utilisée, ce mot de passe est vérifié.
> - Si le groupware utilisateur est actif, le mot de passe est vérifié par rapport au groupware utilisateur.
> - Sinon, le mot de passe est vérifié par rapport au compte Windows.
