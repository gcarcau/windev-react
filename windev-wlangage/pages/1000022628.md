# <Bandeau défilant>.ArrêteDéfilement (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

Arrête le défilement automatique sur un champ Bandeau défilant.

## Exemple

```wlangage
// Stoppe le défilement (laisse le bandeau courant)BAN_Bannière.ArrêteDéfilement()
```

## Syntaxe

```wlangage
<Champ Bandeau défilant>.ArrêteDéfilement()
```

`<Champ Bandeau défilant>` *Nom de champ*
> Nom du champ Bandeau défilant à manipuler.
