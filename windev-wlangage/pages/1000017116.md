# SaisieManuscrite (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

La propriété **SaisieManuscrite** permet de gérer la saisie à l'aide du stylet (Windows XP Tablet PC) ou de la souris (Windows Vista). Il est possible de :

- Savoir si un champ de saisie de type RTF autorise la saisie manuscrite.
- Autoriser la saisie manuscrite dans un champ de saisie RTF.

Cette propriété est équivalente à l'option "Saisie manuscrite (Tablet PC)" disponible dans l'onglet "Général" de la fenêtre de description des champs de saisie.

## Exemple

```wlangage
// Autoriser la saisie manuscrite
SAI_SaisieRTF.SaisieManuscrite = Vrai
```

## Syntaxe

#### Savoir si le champ autorise la saisie manuscrite

```wlangage
<Saisie manuscrite> = <Champ de saisie>.SaisieManuscrite
```

`<Saisie manuscrite>` *Booléen*
> - Vrai si le champ de saisie autorise la saisie manuscrite,
> - Faux dans le cas contraire.
`<Champ de saisie>` *Nom de champ*
> Nom du champ de saisie manipulé. Ce champ doit être un champ de saisie de type RTF.

#### Autoriser ou non la saisie manuscrite

```wlangage
<Champ de saisie>.SaisieManuscrite = <Saisie manuscrite>
```

`<Champ de saisie>` *Nom de champ*
> Nom du champ de saisie manipulé. Ce champ doit être un champ de saisie de type RTF.
`<Saisie manuscrite>` *Booléen*
> - Vrai si le champ de saisie doit autoriser la saisie manuscrite,
> - Faux dans le cas contraire.
