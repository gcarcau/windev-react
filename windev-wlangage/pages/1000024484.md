# Indice (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Indice** permet de connaître l'indice d'un élément. Cette propriété est utilisable sur :

- une rubrique d'un enregistrement. Pour plus de détails, consultez l'aide de la propriété [Indice](2512040.md).
- une variable de type [htmlNoeud](1000026081.md).
- une variable de type [kbCarte](1410089167.md).
- une variable de type [VisiteGuidéeEtape](1410090178.md).
