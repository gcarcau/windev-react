# Le champ Graphe : Caractéristiques sous l'éditeur

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Quel que soit le type de graphe affiché par le champ Graphe, toutes ces caractéristiques peuvent être configurées grâce à sa fenêtre de description.
Cette fenêtre est disponible aussi bien dans l'éditeur de fenêtres, l'éditeur de pages ou l'éditeur d'états. Cette page présente :

- Caractéristiques du champ Graphe dans une fenêtre.
- Caractéristiques du champ Graphe dans une page.
- Caractéristiques du champ Graphe dans un état.
