# telAppelFin (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Renvoie la date et l'heure de la fin de l'appel.

## Exemple

```wlangage
DateHeureFinAppel est une DateHeure
DateHeureFinAppel = telAppelFin()
```

## Syntaxe

```wlangage
<Résultat> = telAppelFin([<Identifiant de l'appel>])
```

`<Résultat>` *DateHeure*
> Date et heure de la fin de l'appel.
`<Identifiant de l'appel>` *Entier optionnel*
> Identifiant de l'appel à manipuler. Cet identifiant est connu dans la procédure WLangage appelée par la fonction [telDémarreDétectionAppel](3076029.md). Si ce paramètre n'est pas spécifié, l'appel en cours est manipulé.

## Remarques

### Disponibilité de l'information
L'information est disponible :

- à n'importe quel moment pour le dernier appel sortant
- jusqu'à la fin de l'appel pour les appels entrants. Si cette information doit être stockée, il est nécessaire de la mémoriser avant la fin de l'appel. L'information sera disponible jusqu'à ce que la procédure WLangage ait pour statut la constante *telLigneRaccrochée*.

### Configuration nécessaire
Les fonctions de téléphonie utilisent la technologie TAPI 2.0 et/ou la technologie TAPI 3.1. Ces technologies sont utilisables sur tous les systèmes.

**Composante : wd300com.dll**
