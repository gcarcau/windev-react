# <Table>.DésactiveFiltre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Annule un filtre utilisateur sur une colonne ou toutes les colonnes d'un champ Table ou Table hiérarchique. Ce filtre a été activé par l'utilisateur ou grâce à la fonction [TableActiveFiltre](1000017149.md).

## Exemple

```wlangage
// Annule le filtre sur toutes les colonnes du champ Table
TABLE_Client.DésactiveFiltre()
```

## Syntaxe

```wlangage
<Champ Table ou Colonne>.DésactiveFiltre()
```

`<Champ Table ou Colonne>` *Nom de champ*
> Correspond :
>
> - soit au nom du champ Table ou Table hiérarchique.
>   Dans ce cas, tous les filtres utilisateur spécifiés sur le champ sont annulés.
> - soit au nom d'une colonne d'un champ Table ou Table hiérarchique. Ce nom est de la forme :
>   ```wlangage
>   <Nom champ Table>.<Nom colonne>
>   ```
>   Par exemple : TABLE_TableClient.COL_NomSociété.
>   Dans ce cas, seul le filtre activé sur cette colonne est annulé.

## Remarques

### Avantage des filtres utilisateur
Les filtres utilisateur sont modifiables par l'utilisateur final (à la différence d'un filtre mis en place par la fonction [<Source>.Filtre](1000024960.md) ou par la propriété [Filtre](2510042.md)).

### Conditions d'utilisation
Cette fonction est disponible sur :

- un champ Table ou Table hiérarchique fichier.
- un champ Table ou Table hiérarchique par programmation.
- un champ Table en mode "Serveur + AJAX", un champ Table en mode "Serveur" et un champ Table hiérarchique.
- un champ Table en mode "Navigateur".
   Le champ Table hiérarchique n'est pas disponible.
