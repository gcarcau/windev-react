# Fonctions de gestion des Combinaisons et des Enumérations

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad) · **Autres** (Procédures stockées)

Les fonctions de gestion des Combinaisons et des Enumérations sont les suivantes :

| [CombinaisonDepuisNom](1000020771.md) | Renvoie une combinaison d'une ou de plusieurs options connues par leurs noms. |
| --- | --- |
| [CombinaisonDepuisValeur](1000020770.md) | Renvoie une combinaison d'une ou plusieurs options connues par leurs valeurs associées. |
| [CombinaisonVérifieNom](1000020772.md) | Vérifie si une combinaison d'une ou plusieurs options connues par leurs noms est valide. |
| [EnumérationDepuisNom](1000020769.md) | Renvoie une valeur d'énumération connue par son nom. |
| [EnumérationDepuisValeur](1000020768.md) | Renvoie une valeur d'énumération connue par sa valeur associée. |
| [EnumérationVérifieNom](1000020767.md) | Vérifie si une valeur d'énumération connue par son nom est valide. |
| [EnumérationVérifieValeur](1000020866.md) | Vérifie si une valeur d'énumération connue par sa valeur associée est valide. |
