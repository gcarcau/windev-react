# <Variable xmlNoeud>.ChercheNamespaceParNom (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Recherche un namespace (espace de nommage) XML à partir de son nom dans un noeud XML et dans les parents de ce noeud.

## Exemple

```wlangage
gcDocumentXML est un xmlDocument
gcDocumentXML = XMLOuvre("c:\temp\fichier.xml", depuisFichier)

cNoeud est un xmlNoeud = gcDocumentXML..NoeudRacine[1]
cNamespace est un xmlNamespace = cNoeud.ChercheNamespaceParNom("monnamepace")

SI ErreurDétectée = Vrai ALORS
	Info("Le namespace n'a pas été trouvé.")
SINON
	Info("Namespace trouvé : ", cNamespace.URI)
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Noeud XML>.ChercheNamespaceParNom(<Nom du namespace>)
```

`<Résultat>` *Variable de type xmlNamespace*
> Namespace correspondant au nom recherché.
`<Noeud XML>` *Variable de type xmlNoeud*
> Nom de la variable de type [xmlNoeud](1000018786.md) correspondant au noeud du document XML à partir duquel la recherche est effectuée.
`<Nom du namespace>` *Chaîne de caractères Unicode*
> Nom du namespace à rechercher.

**Composante : wd300xml.dll**
