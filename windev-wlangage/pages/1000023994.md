# PanneauSauveConfiguration (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Sauve la configuration courante des champs Panneau dockable d'une fenêtre.

## Exemple

```wlangage
// Sauve la configuration courante
sConf est une chaîne = PanneauSauveConfiguration()

// Restaure la configuration sauvée dans sConf
PanneauChargeConfiguration(sConf)
SI ErreurDétectée ALORS ToastAffiche(ErreurInfo())
```

## Syntaxe

```wlangage
<Résultat> = PanneauSauveConfiguration()
```

`<Résultat>` *Chaîne de caractères*
> Configuration de tous les champs Panneau dockable de la fenêtre en cours.
> Cette configuration peut être sauvée avec les fonctions [fSauveTexte](3036046.md) ou [SauveParamètre](3025046.md).
>
> Cette configuration pourra être restaurée grâce à la fonction [PanneauChargeConfiguration](1000023995.md).

## Remarques

Les informations suivantes sont sauvées pour chaque champ Panneau dockable de la fenêtre :

- Taille,
- Position,
- Attaché / détaché,
- Visible / invisible
- Replié / déplié.

Pour sauver/restaurer la position d'un champ Panneau dockable de la fenêtre, utilisez les fonctions [PanneauPosition](1000023992.md) et [PanneauAttache](1000023990.md).

**Composante : wd300obj.dll**
