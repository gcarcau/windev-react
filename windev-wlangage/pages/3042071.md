# grMAJAutomatiqueEtiquetteCatégorie (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Identifie ou définit si les étiquettes de catégorie sont mises à jour à chaque dessin du graphe. Dans ce cas, à chaque appel de la fonction [grDessine](3042026.md), le contenu de la série est automatiquement recalculé pour refléter les derniers changements de la source de données. Les étiquettes de catégories sont alors mises à jour si nécessaire.
**Exemple d'utilisation** : une série dans un graphe sert de série de référence : cette série n'est pas mise à jour automatiquement.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
// Graphe créé par programmation
SI grMAJAutomatiqueEtiquetteCatégorie("MonGraphe") = Vrai ALORS
	grDessine("MonGraphe")
FIN
```

```wlangage
// Champ Graphe
SI grMAJAutomatiqueEtiquetteCatégorie(GRF_MonGraphe) = Vrai ALORS
	grDessine(GRF_MonGraphe)
FIN
```

## Syntaxe

#### Identifier le mode de mise à jour des étiquettes de catégorie

```wlangage
<Résultat> = grMAJAutomatiqueEtiquetteCatégorie(<Nom du graphe>)
```

`<Résultat>` *Booléen*
> Mode de mise à jour actuel des étiquettes de catégories :
>
> - Vrai si les étiquettes sont mises à jour automatiquement,
> - Faux dans le cas contraire.
`<Nom du graphe>` *Nom de champ ou chaîne de caractères*
> Nom du graphe à manipuler. Ce nom correspond :
>
> - soit au nom du graphe défini par programmation avec la fonction [grCrée](3042005.md).
> - soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.
>
>
> > _(Android)_ Seuls les champs Graphe sont disponibles.
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.

#### Définir le mode de mise à jour des étiquettes de catégorie

```wlangage
grMAJAutomatiqueEtiquetteCatégorie(<Nom du graphe> , <Mise à jour automatique>)
```

`<Nom du graphe>` *Nom de champ ou chaîne de caractères*
> Nom du graphe à manipuler. Ce nom correspond :
>
> - soit au nom du graphe défini par programmation avec la fonction [grCrée](3042005.md).
> - soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.
>
>
> > _(Android)_ Seuls les champs Graphe sont disponibles.
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Mise à jour automatique>` *Booléen*
> - Vrai pour une mise à jour automatique,
> - Faux dans le cas contraire.

## Remarques

- Si les étiquettes de catégories sont en mode automatique, les étiquettes de catégories sont automatiquement recalculées lors du prochain appel à la fonction [grDessine](3042026.md).
- Si les étiquettes de catégories ne sont pas en mode automatique, les étiquettes de catégories seront recalculées uniquement lors du prochain appel de la fonction [grSourceEtiquetteCatégorie](3042072.md).
