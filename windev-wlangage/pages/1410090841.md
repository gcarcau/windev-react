# AuthIntrospecteToken (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Introspecte un token OAuth. L'introspection permet à toute application cliente de vérifier l'état actuel d'un jeton d'accès (access token). Il est possible de vérifier la validité du token et de connaître les informations correspondant aux scopes demandés.
Remarque : Cette fonction est notamment utile dans les Webservices pour connaître la validité du jeton d'accès (access token).

## Exemple

```wlangage
g_openid_param est un OpenIDParamètres
g_openid_param.URLConfiguration = "http://webapp/.well-known/openid-configuration"
g_openid_param.ClientID = "e2776f74-7a74-4ecf-9f0b-09aa9ebc8ab4"
g_openid_param.ClientSecret = "11492281-3238-4503-9312-6c9c03c7051b"
g_openid_param.Scope = "email profile"
g_openid_param.TypeAutorisation = taCodeAutorisation

g_token est un AuthToken = AuthIdentifie(g_openid_param)
SI PAS g_token.Valide ALORS
	SI ErreurDétectée ALORS
		Info(ErreurInfo(errComplet))
	SINON
		Info("Token invalide")
	FIN
	RETOUR
FIN

identité est une OpenIDIdentité = OpenIDLitIdentité(g_token)
SI PAS identité.Valide ALORS
	SI ErreurDétectée ALORS
		Info(ErreurInfo(errComplet))
	SINON
		Info("Identité invalide")
	FIN
	RETOUR
FIN
Trace("Email = " + identité.Email)

token est un JSON = g_token.RéponseServeur
access_token est un JSON = token.access_token
res est un JSON = AuthIntrospecteToken(access_token, oauth2AccessToken, "http://webapp/oauth2/v1/introspect")
Trace(res)
```

## Syntaxe

```wlangage
<Résultat> = AuthIntrospecteToken(<Token> , <Type du token> , <URL d'introspection>)
```

`<Résultat>` *Chaîne de caractères JSON ou Variable JSON*
> Chaîne de caractères au format JSON contenant les informations d'introspection.
`<Token>` *Chaîne de caractères ou variable de type AuthToken*
> Token à analyser. Ce token peut être :
>
> - une chaîne de caractères,
> - une variable de type [AuthToken](1000022220.md).
`<Type du token>` *Constante de type Entier*
> Type du token à analyser :
>
> | *oauth2AccessToken* | Token d'accès. |
> | --- | --- |
> | *oauth2IdToken* | Token d'identification. |
`<URL d'introspection>` *Chaîne de caractères*
> URL permettant de lancer l'introspection du token.
