# <Variable gglConnexion>.Ecrit (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Crée et/ou met à jour des données sur le serveur Google (ajout ou modification de données). Les données créées ou mises à jour sont contenues dans une variable correspondant au service manipulé :

- Variable de type [gglAgenda](1000017418.md) pour créer/mettre à jour l'agenda.
- Variable de type [gglGroupeContact](1000017576.md) pour créer/mettre à jour les groupes de contacts.
- Variable de type [gglContact](1000017434.md) pour créer/mettre à jour les contacts.

**Remarques** :

- En cas d'ajouts multiples, la fonction [VariableRAZ](3013069.md) permet de réinitialiser ces variables entre les appels à la fonction **<Variable gglConnexion>.Ecrit**.
- En cas de modification, il est nécessaire de récupérer les données avant de les modifier.

**Avertissement**

 A partir du 15 juin 2021, l'API Contacts de Google utilisée par cette fonctionnalité pour gérer les contacts et les groupes de contacts n'est plus disponible ([https://developers.google.com/contacts/v3/announcement](https://developers.google.com/contacts/v3/announcement)).
Pour utiliser les contacts de Google, consultez l'API People proposée en remplacement par Google : [https://developers.google.com/people](https://developers.google.com/people).
La fonction [<Variable restRequête>.Envoie](1410089811.md) simplifie l'intégration d'une API REST dans vos développements.

## Exemple

```wlangage
// Connexion
Cnx est une gglConnexion
...

// Récupération de l'agenda nommé "Travail"
Agenda est un gglAgenda = Cnx.RécupèreAgenda("Travail")
// Modification du premier événement de l'agenda
Agenda[1].Titre = "Rdv patron"
Agenda[1].DateFin = "200810131530"
// Suppression du deuxième événement de l'agenda
Supprime(Agenda.Evénement, 2)
// Mise à jour effective des changements sur le serveur
Cnx.Ecrit(Agenda)
```

## Syntaxe

#### Créer et/ou mettre à jour un élément Google

```wlangage
<Résultat> = <Connexion Google>.Ecrit(<Elément Google>)
```

`<Résultat>` *Booléen*
> - Vrai si la mise à jour a été réalisée,
> - Faux en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Connexion Google>` *Variable de type gglConnexion*
> Nom de la variable de type [gglConnexion](1000018009.md) à utiliser. Cette connexion a été validée avec la fonction [<Variable gglConnexion>.Connecte](1000021455.md).
`<Elément Google>` *Variable correspondant au type à mettre à jour*
> Elément à mettre à jour. Ce paramètre peut correspondre à :
>
> - Nom de la variable de type [gglAgenda](1000017418.md) correspondant à l'agenda à créer/modifier.
> - Nom de la variable de type [gglContact](1000017434.md) correspondant au contact à créer/modifier.
> - Nom de la variable de type [gglGroupeContact](1000017576.md) correspondant au groupe de contacts à créer/modifier.
