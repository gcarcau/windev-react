# Référence (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **Référence** permet :

- de connaître et de modifier l'identifiant unique d'un ou de plusieurs emails de référence liés à la conversation en cours.
- de connaître et de modifier l'élément à signer.

Cette propriété est utilisable sur :

- la structure [Email](3032029.md).
- une variable de type [Email](1000018713.md).
- une variable de type [xmlSignature](1000020736.md).
- Nouveauté Abonnement
  une variable de type [xmlSignatureXAdES](1410091158.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
