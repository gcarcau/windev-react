# LDAPRAZ (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **Autres** (Procédures stockées)

Ré-initialise la [structure LDAPSession](3032101.md) avec les valeurs par défaut. Cette structure est utilisée par la fonction [LDAPConnecte](3032100.md).

## Exemple

```wlangage
LDAPRAZ()
```

## Syntaxe

```wlangage
LDAPRAZ()
```

**Composante : wd300com.dll**
