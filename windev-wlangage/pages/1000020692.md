# RendezVousAffiche (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Affiche un rendez-vous dans l'application native de gestion des rendez-vous de l'appareil mobile (Android ou iOS).

## Exemple

```wlangage
SI PAS RendezVousAffiche(rdv) ALORS
	Erreur("Impossible d'afficher le rendez-vous.", ErreurInfo())
FIN
```

## Syntaxe

```wlangage
<Résultat> = RendezVousAffiche(<Rendez-vous>)
```

`<Résultat>` *Booléen*
> - Vrai si la description du rendez-vous a pu être affichée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Rendez-vous>` *Variable de type RendezVous*
> Nom de la variable de type [RendezVous](1000019244.md) correspondant au rendez-vous dont la description doit être affichée. Ce rendez-vous doit exister et appartenir à un calendrier de l'appareil (obtenu par la fonction [RendezVousListe](1000020690.md)).

## Remarques

### Cas particuliers

- La fonction **RendezVousAffiche** rend la main à l'application immédiatement après l'affichage de la description du rendez-vous dans l'application native.
- La fonction **RendezVousAffiche** peut être utilisée dans l'émulateur mais pas dans le simulateur.

> _(Android, Widget Android)_ Application en arrière-plan : Spécificité à partir de Android 10A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. La fonction RendezVousAffiche peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. Conseils : Il est possible de savoir si l'application est en arrière-plan grâce à la fonction EnModeArrièrePlan. Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type Notification). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété ActiveApplication est à Vrai. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété ActionClic.Pour plus de détails, consultez Android 10 : Comportement des applications en arrière-plan.
