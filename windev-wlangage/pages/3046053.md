# iFinImprime (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Signale la fin du document à imprimer et lance l'impression effective des données actuellement stockées dans la file d'attente de l'imprimante par les fonctions [iImprime](3046031.md), [iImprimeImage](3046017.md), [iLigne](3046035.md), ... L'ensemble de ces données constitue le document à imprimer.
**Remarque** : Si la fonction **iFinImprime** n'est pas exécutée, l'ensemble de l'édition sera perdue. Cette fonction ne doit être utilisée qu'avec les états créés par programmation. Cette fonction ne doit pas être appelée dans les traitements d'un état créé avec l'éditeur d'états de WINDEV.

## Exemple

```wlangage
iImprime("Liste des clients")
iSauteLigne()
// Traitement
iFinImprime()
```

## Syntaxe

```wlangage
iFinImprime()
```

## Remarques

### Action de iFinImprime
La fonction **iFinImprime** annule :

- le paramétrage de [iMarge](3046011.md),
- les polices créées précédemment.
- le mode d'impression "aperçu" en cours.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Windows, Linux, Android, Widget Android, Java, Code Utilisateur (MCU), WINDEV, WEBDEV - Code Serveur, WINDEV, WINDEV Mobile)_ Traitements à interrompre pendant une impressionPendant une impression, il faut interrompre les traitements suivants :timer (avec la fonction FinTimer), gestion des liens DDE (avec la fonction DDEFinLien), événement (avec la fonction FinEvénement).

**Composante : wd300prn.dll**
