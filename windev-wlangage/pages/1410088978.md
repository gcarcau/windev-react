# ValeurMémorisée (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Mac Catalyst)

La propriété **ValeurMémorisée** permet de connaître et de modifier la valeur mémorisée d'un élément. Cette propriété est utilisable sur :

- les lignes des champs Liste et des champs Table, ainsi que les champs de saisie avec jetons. Pour plus de détails, consultez [ValeurMémorisée](2510127.md).
- une variable de type [Jeton](1000023942.md).
- une variable de type [SaisieAssistée](1410088983.md).
