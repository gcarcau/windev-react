# TâcheParallèleDemandeAnnulation (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Demande l'annulation d'une tâche parallèle.

## Exemple

```wlangage
// Déclenche l'exécution d'une tâche
t est une TâcheParallèle = TâcheParallèleExécute(Proc)
...
// Annule l'exécution de la tâche
TâcheParallèleDemandeAnnulation(t)
```

## Syntaxe

#### Demander l'annulation d'une tâche parallèle

```wlangage
TâcheParallèleDemandeAnnulation(<Tâche>)
```

`<Tâche>` *Variable de type TâcheParallèle*
> Nom de la variable de type [TâcheParallèle](1000021220.md) à manipuler.

#### Demander l'annulation des tâches parallèles présentes dans un tableau

```wlangage
TâcheParallèleDemandeAnnulation(<Tableau de tâches>)
```

`<Tableau de tâches>` *Tableau de variables de type TâcheParallèle*
> Nom du tableau de variables de type [TâcheParallèle](1000021220.md) à manipuler.

## Remarques

- Une demande d'annulation est transmise à la tâche. Le code de la tâche doit gérer la demande d'annulation grâce à la syntaxe suivante :
  ```wlangage
  MaTâcheParallèle.Annulée
  ```
- L'appel de la fonction **TâcheParallèleDemandeAnnulation** est non bloquant. La tâche est considérée comme annulée dès l'appel à la fonction.
- L'état de la tâche passe à *tpeAnnulationDemandée*. Tout appel à la propriété [ValeurRenvoyée](2510134.md) provoquera une erreur fatale.

**Classification Métier / UI : Code neutre**
