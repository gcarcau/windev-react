# HModifiePropriétéServeur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Modifie les propriétés d'un serveur HFSQL.
**Remarque** : Il est possible de connaître les propriétés d'un serveur HFSQL grâce à la fonction [HInfoPropriétéServeur](3044325.md).

## Exemple

```wlangage
ResModif est un booléen
ResModif = HModifiePropriétéServeur("MaConnexion", hNotes, "Serveur HFSQL Client/Serveur")
SI ResModif = Vrai ALORS
	Info("Modification effectuée")
FIN
```

## Syntaxe

```wlangage
<Résultat> = HModifiePropriétéServeur(<Connexion> , <Propriété à modifier> , <Nouvelle valeur>)
```

`<Résultat>` *Booléen*
> - Vrai si les propriétés ont été modifiées,
> - Faux dans le cas contraire. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion pour laquelle la valeur d'une propriété doit être modifiée. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Propriété à modifier>` *Constante de type Entier*
> Propriété du serveur à modifier :
>
> | *hNotes* | Description du serveur ou toute autre information associée au serveur.  Si cette constante est utilisée, <Nouvelle valeur est une chaîne de caractères contenant le texte de la note. |
> | --- | --- |
`<Nouvelle valeur>` *Chaîne de caractères*
> Nouvelle valeur de la propriété.
