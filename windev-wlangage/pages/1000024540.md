# <Variable Document>.UndoRedoSupprimeTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Supprime tout l'historique du mécanisme d'Undo/Redo d'une variable de type [Document](1000022461.md).

## Exemple

```wlangage
MonDocument est un Document

// Supprime l'historique des actions effectuées sur le document
MonDocument.UndoRedoSupprimeTout()
```

## Syntaxe

```wlangage
<Résultat> = <Document>.UndoRedoSupprimeTout()
```

`<Résultat>` *Booléen*
> - Vrai si la suppression a bien été effectuée,
> - Faux dans le cas contraire
`<Document>` *Variable de type Document*
> Nom de la variable de type [Document](1000022461.md) à manipuler.

**Composante : wd300mdl.dll**
