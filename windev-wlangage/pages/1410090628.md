# <Fenêtre>.ExtPosX (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Renvoie la position horizontale du coin haut gauche d'une fenêtre par rapport au coin haut gauche de l'écran.
> _(WINDEV, Java)_ Fenêtres sous Windows : Remarque : La fonction <Fenêtre>.ExtPosX est équivalente à la propriété X.

> _(Android, iPhone/iPad)_ Fenêtres mobile : deux cas sont à prendre en compte : Cas des fenêtres mobiles maximisées : Cette position correspond toujours à 0. Cas des fenêtres mobiles non maximisées et des fenêtres popup : Cette position correspond à la propriété X.

Nouveauté 2025

> _(Android)_ Cette fonction est désormais disponible pour les applications Android.

> _(iPhone/iPad)_ Cette fonction est désormais disponible pour les applications iPhone/iPad.

## Exemple

```wlangage
// Position horizontale de la fenêtre "FEN_SaisieClient" par rapport à l'écran
ResPosH = FEN_SaisieClient.ExtPosX()
```

## Syntaxe

```wlangage
<Résultat> = <Fenêtre>.ExtPosX()
```

`<Résultat>` *Entier*
> Position horizontale ou abscisse (en pixels) du coin haut gauche de la fenêtre par rapport au coin haut gauche de l'écran.
> > _(Android, iPhone/iPad)_ Si la fenêtre manipulée correspond à une fenêtre mobile maximisée, cette position vaut 0.
`<Fenêtre>` *Nom de fenêtre*
> Nom ou alias de la fenêtre à manipuler. Si ce paramètre n'est pas précisé ou correspond à une chaîne vide (""), la position horizontale de la fenêtre en cours est retournée.

**Composante : wd300obj.dll**
