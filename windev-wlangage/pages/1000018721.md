# MessageID (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **MessageID** permet de connaître et de modifier l'identifiant d'un email.
Cette propriété est utilisable sur :

- la structure [Email](3032029.md).
- une variable de type [Email](1000018713.md).
