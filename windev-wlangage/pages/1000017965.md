# Identifiant (Propriété)

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Identifiant** permet de connaître et de modifier l'identifiant d'un élément. Cette propriété est utilisable sur :

- les flux. Pour plus de détails, consultez [Propriété Identifiant sur les flux](2510036.md).
- une variable de type [gglAgenda](1000017418.md).
- une variable de type [gglContact](1000017434.md).
- une variable de type [gglDocument](1000018001.md).
- une variable de type [gglEvénement](1000017440.md).
