# <Variable upnpPériphérique>.ModifieNetteté (Fonction)

> **Disponible :** **WINDEV** (Windows) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Modifie la netteté d'un périphérique UPnP.
**Attention** : Pour utiliser cette fonction, le périphérique doit posséder un service "RenderingControl".

## Exemple

```wlangage
tabPériphérique est un tableau de upnpPériphérique
tabPériphérique = UPNPListePériphérique(...
		"urn:schemas-upnp-org:device:MediaRenderer:1", 5)
POUR TOUT Périphérique DE tabPériphérique
	Périphérique.ModifieNetteté(50)
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Périphérique UPnP>.ModifieNetteté(<Nouvelle valeur>)
```

`<Résultat>` *Booléen*
> - Vrai si la netteté a été modifiée,
> - Faux dans le cas contraire.
`<Périphérique UPnP>` *Variable de type upnpPériphérique*
> Nom de la variable [upnpPériphérique](1000020903.md) correspondant au périphérique UPnP à manipuler.
`<Nouvelle valeur>` *Entier*
> Nouvelle netteté à appliquer. Ce paramètre doit être compris entre 0 et 100.

**Composante : wd300device.dll**
