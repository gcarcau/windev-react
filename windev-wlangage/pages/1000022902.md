# <Planning>.AffichePériodeSuivante (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

Déplace la zone temporelle affichée sur la zone suivante (par exemple, semaines suivantes) dans un champ Planning. Le champ Planning s'affiche alors à partir du jour correspondant à la zone temporelle suivante.
**Remarque** : Les fonctions [<Planning>.AffichePériodePrécédente](1000022901.md) et **<Planning>.AffichePériodeSuivante** permettent de mettre en place simplement des champs Bouton "Suivant / Précédent". Ces champs permettent de faire défiler les zones temporelles affichées par le champ Planning.


## Exemple

```wlangage
// Clic sur le champ Bouton BTN_SUIVANT
PLN_PlanningSalles.AffichePériodeSuivante()
```

## Syntaxe

```wlangage
<Champ Planning>.AffichePériodeSuivante()
```

`<Champ Planning>` *Nom de champ*
> Nom du champ Planning à manipuler.

**Composante : wd300obj.dll**
