# Fonctions de gestion des flux (vidéo et son)

> **Disponible :** **WINDEV** (Windows)

Les fonctions de gestion des flux sont les suivantes :

| [FluxAccepte](3039003.md) | Associe une demande de connexion de flux à un champ Conférence. |
| --- | --- |
| [FluxChangeDriver](1000021613.md) | Indique la caméra à utiliser comme source pour un flux et/ou un champ Conférence. |
| [FluxConfigure](1000021645.md) | Spécifie les paramètres réseau permettant d'utiliser des champs Conférence sur Internet. |
| [FluxConnecte](3039008.md) | Connecte un flux (et le champ associé) à une adresse spécifique. |
| [FluxDéconnecte](3039007.md) | Arrête la réception ou l'émission d'un flux. |
| [FluxInfo](3039009.md) | Renvoie le nom et / ou le numéro de l'émetteur du flux. |
| [FluxJoue](3039010.md) | Reprend la réception ou l'émission d'un type de données dans un flux. |
| [FluxRefuse](3039006.md) | Refuse une demande de connexion d'un flux. |
| [FluxStop](3039002.md) | Arrête la réception ou l'émission d'un type de données dans un flux. |
