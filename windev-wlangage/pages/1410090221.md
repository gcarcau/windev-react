# Canada.VérifieNuméroFiscal (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un numéro fiscal du Canada.
Remarque : Le numéro fiscal correspond au NAS pour les particuliers et au NE9 pour les entreprises.

Nouveauté 2025

> _(Android)_ Cette fonction est désormais disponible pour les applications Android.

> _(Widget Android)_ Cette fonction est désormais disponible en mode Widget Android.

## Exemple

```wlangage
// Test d'une variable
MonNuméroFiscal est une chaîne = "046454286"
Canada.VérifieNuméroFiscal(MonNuméroFiscal) // renvoie Vrai

// Test d'un champ
SAI_NuméroFiscal = "ABC"
Canada.VérifieNuméroFiscal(SAI_NuméroFiscal) // renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = Canada.VérifieNuméroFiscal(<Numéro à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un numéro fiscal valide.
> - Faux dans le cas contraire.
`<Numéro à vérifier>` *Nom de champ ou variable de type chaîne*
> Numéro fiscal à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.

**Composante : wd300std.dll**
