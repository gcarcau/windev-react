# Accéder à des fichiers de données HFSQL via SAMBA sur Linux

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

## Présentation

Pour accéder à des fichiers de données HFSQL via Samba sur Linux, un paramétrage spécifique est nécessaire.

## Paramétrage nécessaire

Dans le fichier **smb.conf** qui se trouve communément sous /etc/samba, il faut rajouter ou modifier les paramètres suivants dans la section [global] du fichier.
```wlangage
[global]locking = yesstrict locking = yesshare modes = yesoplocks = nokernel oplocks = noblocking locks = nofake oplocks = nolevel2 oplocks = no
```

Ensuite, il est nécessaire de redémarrer le service Samba pour prendre en compte le nouveau paramétrage.
