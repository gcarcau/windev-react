# Agrandir une fenêtre ou une page

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Une tendance actuelle est l'agrandissement des fenêtres, des pages et de la taille des polices dans les champs.
Il est possible d'agrandir automatiquement la taille des polices de l'ensemble des champs d'une sélection, d'une fenêtre, d'une page ou d'un projet sans avoir à changer de gabarit ou d'ambiance et sans avoir à redimensionner les champs un à un.

L'augmentation de la taille des polices agrandit et décale automatiquement tous les champs afin de conserver la mise en page. La taille de la fenêtre ou de la page est également agrandie si nécessaire.

Nouveauté 2025

> _(WEBDEV - Code Serveur, PHP)_ Cette fonctionnalité est désormais disponible pour les sites WEBDEV.

## Comment le faire ?

Pour agrandir une fenêtre ou une page :

1. Ouvrez la fenêtre ou la page à agrandir sous l'éditeur.
2. Sous le volet "Alignement", dans le groupe "Autres alignements", déroulez "Agrandir
  Aérer" et sélectionnez "Agrandir".
3. Dans la fenêtre qui s'affiche, indiquez les paramètres permettant de réaliser l'agrandissement :
  | Valeur | Description |
  | --- | --- |
  | Agrandissement d'une fenêtre | Agrandissement d'une page |
4. Il est possible de :
  - indiquer le facteur d'agrandissement.
  - spécifier si la police et les styles doivent être agrandis.
     Dans ce cas, il est possible de :
    - Créer des surcharges de style : le style de base sera surchargé pour prendre en compte les modifications.
    - Créer / utiliser un gabarit agrandi : dans ce cas, un nouveau gabarit basé sur le gabarit en cours est généré. Par exemple, si la fenêtre utilise le gabarit "Phoenix", avec un agrandissement de 25%, un gabarit "Phoenix (x1.25)" sera créé.
      Seuls les éléments provenant des modèles et surchargés seront agrandis.
   L'icône  permet d'obtenir un aperçu de la modification en temps réel dans votre fenêtre.
5. Validez. Les paramètres indiqués sont appliqués.

Remarques :

- L'agrandissement peut être effectué sur la sélection en cours, la fenêtre, la page ou le projet.
- Si la création d'un gabarit "agrandi" est demandée, ce gabarit pourra ensuite être appliqué aux autres éléments du projet.
- Si le gabarit de base est mis à jour, le gabarit "agrandi" sera également mis à jour automatiquement.
- Si la fenêtre contient un modèle de fenêtres, il est nécessaire d'agrandir également le modèle de fenêtres. Il est également possible d'agrandir le projet (le modèle sera automatiquement agrandi avec les autres éléments du projet).
- Les modèles de champs ne sont pas agrandis.
