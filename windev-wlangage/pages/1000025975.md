# DoubleAuthGénèreLien (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Génère un lien pour enregistrer un compte dans une application d'authentification. Affecté à un champ Code-barres, ce lien permet d'afficher un QRCode pouvant être scanné dans l'application d'authentification choisie sur le téléphone.

## Exemple

```wlangage
soit sURL = DoubleAuthGénèreLien(sCléTOTP, sEmail, sNomAppli)
CBA_MonQRCode = sURL
```

## Syntaxe

```wlangage
<Résultat> = DoubleAuthGénèreLien(<Clé TOTP> , <Compte> , <Application>)
```

`<Résultat>` *Chaîne de caractères*
> URL permettant de créer un compte dans une application d'authentification.
`<Clé TOTP>` *Chaîne de caractères, Buffer ou chaîne secrète*
> Clé TOTP de l'utilisateur à authentifier. Cette clé TOTP a été générée avec la fonction [DoubleAuthGénèreClé](1000025974.md).
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre peut être "Buffer ASCII" ou "Buffer UTF 8".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md). Nouveauté 2025
>
> > _(Android, Widget Android)_ Les chaînes secrètes ne sont pas disponibles pour ce paramètre en Android/Android Widget.
`<Compte>` *Chaîne de caractères*
> Nom du compte à enregistrer (généralement c'est l'adresse email qui est utilisée).
`<Application>` *Chaîne de caractères*
> Nom de l'application à enregistrer sur l'application d'authentification.
