# PartieEntière (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **PartieEntière** permet de paramétrer les rubriques de type Numérique. Il est possible de :

- Connaître le nombre de chiffres de la partie entière d'une rubrique de type Numérique.
- Définir le nombre de chiffres de la partie entière d'une rubrique de type Numérique.

**Remarque** : La propriété [PartieDécimale](2512119.md) permet de définir et de connaître le nombre de chiffres de la partie décimale d'une rubrique de type Numérique.

## Exemple

```wlangage
// Description du fichier de données UnFichier
...

// Description de la rubrique "Montant"
UneRubrique.Nom = "MONTANT"
UneRubrique.Type = hRubNumérique
UneRubrique.PartieEntière = 15
UneRubrique.PartieDécimale = 7

// Validation de la description de la rubrique "Montant"
HDécritRubrique(UnFichier, UneRubrique)

// Validation de la description du fichier de données UnFichier
...
```

## Syntaxe

#### Connaître le nombre de chiffres de la partie entière d'une rubrique de type Numérique

```wlangage
<Résultat> = <Fichier de données>.<Rubrique>.PartieEntière
```

`<Résultat>` *Entier*
> Nombre de chiffres pris en compte par la partie entière de la rubrique.
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données manipulé. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Fichier](1514065.md).
`<Rubrique>` *Chaîne de caractères*
> Nom de la rubrique manipulée. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Rubrique](1514071.md).

#### Définir le nombre de chiffres de la partie entière d'une rubrique de type Numérique

```wlangage
<Rubrique>.PartieEntière = <Nombre de chiffres>
```

`<Rubrique>` *Chaîne de caractères*
> Nom de la rubrique manipulée. Ce nom vient d'être défini grâce au type [Description de Rubrique](1514071.md).
`<Nombre de chiffres>` *Entier*
> Nombre de chiffres à prendre en compte pour la partie entière de la rubrique de type Numérique.
