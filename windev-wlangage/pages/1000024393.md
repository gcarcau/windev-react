# <Traitement de texte>.Sauve (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

Sauve un document au format "docx". Le document sauvegardé reste ouvert. Pour le fermer, il est nécessaire d'utiliser la fonction [<Traitement de texte>.Ferme](1000024264.md).

## Exemple

```wlangage
// On choisit le répertoire et le nom de sauvegarde
sNomFichier est une chaîne = fSélecteur(ComplèteRep(fRepExe()), "présentation.docx", ...
	"Sélection de fichiers DocX","Fichier Docx (*.docx)" + TAB + "*.docx" , "*.docx", fselCrée)

// On sauvegarde le fichier
TT_SansNom1.Sauve(sNomFichier)

SI ErreurDétectée ALORS
	Erreur(ChaîneConstruit("Le fichier %1 n'a pas pu être enregistré.", sNomFichier), ErreurInfo())
	RETOUR
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Champ Traitement de texte>.Sauve([<Chemin du fichier>])
```

`<Résultat>` *Booléen*
> - Vrai si la sauvegarde a été effectuée,
> - Faux dans le cas contraire.
`<Champ Traitement de texte>` *Nom de champ*
> Nom du champ Traitement de texte à manipuler.
`<Chemin du fichier>` *Chaîne de caractères optionnelle*
> Chemin complet et nom du fichier "docx".
>
> **Si ce paramètre est précisé,** le fichier est sauvegardé à l'emplacement indiqué (le fichier existant est écrasé si nécessaire).
> Remarque : Si le document "docx" est enregistré avec un chemin différent de celui d'origine (correspond à un "Enregistrer sous"), le fichier d'origine est fermé, le document est enregistré dans le nouveau fichier et le nouveau fichier "docx" reste ouvert.
> **Si ce paramètre n'est pas précisé**, le chemin pris en compte est le chemin spécifié dans la propriété **Valeur** du champ Traitement de texte manipulé. Si cette propriété est vide, la fonction renvoie Faux.

**Classification Métier / UI : Code UI**
