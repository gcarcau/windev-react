# HSupprimeVue (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Supprime une vue matérialisée sur le serveur HFSQL.

## Exemple

```wlangage
// Création d'une vue matérialisée sur un serveur
SI PAS HMiseAJourVue(MaConnexion1, MaVueMatérialisée) ALORS
	Trace(HErreurInfo())
FIN

// Rafraichissement de la vue matérialisée sur le serveur
SI PAS HRafraîchitVue(MaConnexion1, MaVueMatérialisée) ALORS
	Trace(HErreurInfo())
FIN

// Suppression de la vue matérialisée sur le serveur
SI PAS HSupprimeVue(MaConnexion1, MaVueMatérialisée) ALORS
	Trace(HErreurInfo())
FIN
```

## Syntaxe

```wlangage
<Résultat> = HSupprimeVue(<Connexion> , <Vue> [, <Suppression en cascade>])
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion vers le serveur HFSQL qui contient la vue matérialisée. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Vue>` *Chaîne de caractères*
> Nom de la vue matérialisée à manipuler, présente sur le serveur.
`<Suppression en cascade>` *Booléen optionnel*
> - Vrai pour gérer la suppression en cascade,
> - Faux (valeur par défaut) dans le cas contraire.

## Remarques

Si la vue matérialisée n'existe pas, la fonction retourne une erreur non fatale.

**Classification Métier / UI : Code métier**
