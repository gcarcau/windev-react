# ScrollAuDoigt (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

La propriété **ScrollAuDoigt** permet de :

- Savoir si le contenu d'un champ peut être déplacé avec le doigt ("scroll au doigt").
- Autoriser ou non un champ à être manipulé directement avec le doigt.

> _(WINDEV)_ Cette propriété correspond à l'option "Déplacement au doigt" disponible dans l'onglet "Détail" des champs Liste, Table et Zone répétée.

> _(Android, iPhone/iPad, Widget IOS)_ Cette propriété permet notamment d'interrompre temporairement le scroll au doigt pour pouvoir dessiner dans un champ Image. De la même façon, il est possible d'interrompre le zoom au doigt avec la propriété ZoomAuDoigt. L'appel aux fonctions dDébutDessin et dFinDessin désactive/réactive automatiquement les fonctionnalités de zoom et scroll au doigt.

## Exemple

```wlangage
SI INT_InterfaceTactile = Vrai ALORS
	TABLE_TableClient.ScrollAuDoigt = Vrai
SINON
	TABLE_TableClient.ScrollAuDoigt = Faux
FIN
```

> _(Android, iPhone/iPad, Widget IOS)_ SI INT_ModeDessin = Faux ALORS
 IMG_Photo.ScrollAuDoigt = Vrai
SINON
 IMG_Photo.ScrollAuDoigt = Faux
FIN

## Syntaxe

#### Savoir si un champ permet le déplacement avec le doigt

```wlangage
<Résultat> = <Champ manipulé>.ScrollAuDoigt
```

`<Résultat>` *Booléen*
> - Vrai si le champ permet le déplacement avec le doigt,
> - Faux dans le cas contraire.
`<Champ manipulé>` *Nom de champ*
> Nom du champ manipulé. Ce champ peut être :
>
> - un champ Liste.
> - un champ Table.
> - un champ Zone répétée.
> - un champ Image.

#### Permettre le déplacement avec le doigt ou non

```wlangage
<Champ manipulé>.ScrollAuDoigt = <Défilement au doigt>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ manipulé. Ce champ peut être :
>
> - un champ Liste.
> - un champ Table.
> - un champ Zone répétée.
> - un champ Image.
`<Défilement au doigt>` *Booléen*
> - Vrai si champ autorise le défilement au doigt,
> - Faux dans le cas contraire.

## Remarques

### Limites

> _(WINDEV)_ La propriété ScrollAuDoigt peut uniquement être utilisée sur les champs Liste, Table et Zone répétée.

> _(Android, iPhone/iPad, Widget IOS)_ La propriété ScrollAuDoigt peut uniquement être utilisée sur les champs Image.

> _(iPhone/iPad, Widget IOS)_ Attention : La fonctionnalité de Scroll et zoom doit avoir été activée dans la fenêtre de description du champ Image (option "Scroll et zoom automatiques" dans l'onglet "Détail" de la fenêtre de description du champ).

> _(WINDEV)_ Cas particuliersSur certains systèmes, un défilement au doigt automatique (fourni par le système) peut être actif même si le défilement au doigt du champ est désactivé.
