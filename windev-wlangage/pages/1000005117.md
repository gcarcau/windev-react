# Fonctions de gestion des documents Notes

| [NotesActiveVue](1000005118.md) | Indique la vue à manipuler dans Lotus Notes. |

| [NotesDimensionChamp](1000005103.md) | Renvoie la dimension d'un champ du document en cours dans Lotus Notes. |
| [NotesDocumentCherche](1000005104.md) | Recherche un document dans Lotus Notes. |
| [NotesDocumentDernier](1000005105.md) | Positionne sur le dernier document présent dans Lotus Notes. |
| [NotesDocumentIdentifiant](1000017084.md) | Renvoie l'identifiant du document en cours dans la base Lotus Notes parcourue. |
| [NotesDocumentPrécédent](1000005106.md) | Positionne sur le document précédent le document en cours dans Lotus Notes. |
| [NotesDocumentPremier](1000005107.md) | Positionne sur le premier document présent dans Lotus Notes. |
| [NotesDocumentSuivant](1000005108.md) | Positionne sur le document suivant le document en cours dans Lotus Notes. |
