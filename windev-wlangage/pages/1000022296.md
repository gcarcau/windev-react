# <Variable emailSessionOutlook>.NbMessage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **Autres** (Procédures stockées)

Renvoie le nombre de messages reçus actuellement présents dans le logiciel de messagerie Outlook. Ce nombre de messages évolue en fonction des emails reçus ou supprimés avec la fonction [EmailSupprimeMessage](3032027.md).

## Exemple

```wlangage
MaSessionOutlook est une emailSessionOutlook

nbMSG est un entier = MaSessionOutlook.NbMessage()
POUR I = 1 À nbMSG
	EmailLitMessage(MaSessionOutlook,I)
	SI Email.EnDehors <> Vrai ALORS
		CL.NOM = Email.Expéditeur
		CL.MESSAGE_TXT = Email.Message
		...
	SINON
		Info("Ce message a été supprimé")
	FIN
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Session Outlook>.NbMessage()
```

`<Résultat>` *Entier*
> - Nombre de messages reçus présents dans le logiciel de messagerie Outlook au moment de l'appel de la fonction **<Variable emailSessionOutlook>.NbMessage**,
> - -1 en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Session Outlook>` *Variable de type emailSessionOutlook*
> Nom de la variable de type [emailSessionOutlook](1000018767.md) correspondant à la session d'email à manipuler.

## Remarques

### Messages supprimés (messagerie Outlook)
Si, dans la même session d'emails, un message a été supprimé par la fonction [EmailSupprimeMessage](3032027.md), la fonction **<Variable emailSessionOutlook>.NbMessage** renvoie le nombre correct de messages présents dans le dossier des emails reçus.

**Composante : wd300com.dll**
