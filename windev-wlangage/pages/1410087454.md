# 15. Centre de Gestion de Projets

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

| [Page précédente](1410087453.md) | [Sommaire](1410087102.md) | [Page suivante](1410087455.md) |
| --- | --- | --- |

Pour gérer le cycle de vie de vos projets de développement, WEBDEV vous propose d'utiliser le Centre de Gestion de Projets. Le Centre de Gestion de Projets permet de :

- Gérer les exigences d'un projet,
- Gérer le suivi d'un projet (planning des tâches à réaliser),
- Gérer les bugs et les évolutions signalés par vos utilisateurs sur un projet.

Le Centre de Gestion de Projets utilise une base de données (HFSQL Classic ou Client/Serveur) : la base de données des Centres de Contrôle. Cette base de données est partagée par de nombreux outils disponibles dans WEBDEV :

Remarque : Lors de l'installation de WEBDEV, le programme d'installation propose de choisir une des options suivantes :

- créer la base des Centres de Contrôle. Cette base sera automatiquement créée au format HFSQL Classic dans le répertoire spécifié.
- partager une base de données des Centres de Contrôle existante.
