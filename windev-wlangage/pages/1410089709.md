# Fonctions de pilotage du Serveur d'application WEBDEV

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de pilotage du Serveur d'application WEBDEV (syntaxe préfixée)](1410089903.md)).
Les fonctions de gestion des utilisateurs et des connexions sur un Serveur d'application WEBDEV sont les suivantes :

| [AdminWBCréeCompte](1410089450.md) | Crée un compte WEBDEV sur un Serveur d'application WEBDEV. |
| --- | --- |
| [AdminWBDéconnecte](1410089343.md) | Supprime une connexion sur un Serveur d'application WEBDEV. |
| [AdminWBListeApplication](1410089996.md) | Renvoie la liste des applications WEBDEV d'un serveur d'application, pour un compte donnée, et pour un type donné. |
| [AdminWBListeCompte](1410089449.md) | Renvoie la liste des comptes WEBDEV sur un Serveur d'application WEBDEV. |
| [AdminWBListeConnexion](1410089342.md) | Renvoie la liste des connexions en cours sur un Serveur d'application WEBDEV. |
| [AdminWBModifieCompte](1410089471.md) | Modifie les caractéristiques d'un compte WEBDEV sur un Serveur d'application WEBDEV. |
| [AdminWBSupprimeApplication](1410089999.md) | Supprime une application du serveur d'application WEBDEV. |
| [AdminWBSupprimeCompte](1410089472.md) | Supprime un compte WEBDEV sur un Serveur d'application WEBDEV. |
