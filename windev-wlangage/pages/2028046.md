# Déploiement d'un site WEBDEV : Profil de déploiement

> **Disponible :** **WEBDEV** (Windows)

## Présentation

L'assistant de création du programme d'installation permet de sélectionner le profil de déploiement à utiliser. Ce profil contient les paramètres du serveur d'application ainsi que les paramètres de déploiement du site.
Il est possible :

- soit de choisir un profil précédemment créé (cas de la mise à jour d'un site par exemple). Dans ce cas, les informations concernant le profil sont automatiquement prises en compte. Il suffit de les valider.
- soit de créer un nouveau profil (cas d'une première installation par exemple).
- soit de ne pas choisir de profil pour l'instant. Dans ce cas, les paramètres du profil de déploiement seront indiqués lors de l'installation du site (cas d'une installation par package ou par média physique).

Dans le cas d'une mise à jour, il est possible de créer de nouveaux profils (en général, un profil par serveur) et de les sélectionner pour la mise à jour. Le site sera déployé sur tous les serveurs sélectionnés :

- Si le site est déjà installé sur le serveur, l'assistant effectuera une mise à jour.
- Si le site n'est pas installé sur le serveur, l'assistant fera une nouvelle installation.

**Remarque** : Si l'installation échoue sur l'un des serveurs, l'installation se poursuit normalement sur les autres serveurs.

## Etape 'Paramètres du serveur d'application'

### Saisie des informations sur le serveur d'application
Les informations à saisir sont les suivantes :

- Adresse : Adresse du serveur, correspondant au nom de machine accessible par le réseau, une adresse IP ou une adresse Internet.
  Dans le cas d'une installation sur un Cluster WEBDEV, il est nécessaire d'indiquer l'adresse du proxy associé au Cluster WEBDEV.
- Compte et mot de passes : Caractéristiques du compte de déploiement. Le compte et le mot de passe ont été définis dans le Centre de Contrôle Hébergement, par l'hébergeur).

Remarque : Attention : le nom de compte peut être précédé du nom du domaine pour éviter des confusions. Par exemple : "monposte\test" ou "mondomaine\test".
Plusieurs boutons sont également disponibles :

- Le bouton "Tester les paramètres" permet d'établir une connexion avec le serveur Web et permet de vérifier que toutes les informations saisies sont correctes.
- Le bouton "Paramètres avancés" permet de :
  - Définir les paramètres du serveur.
  - Définir les paramètres du site.
  - Indiquer le mode de transfert des fichiers d'installation (FTP ou HTTP)
    Remarque : HTTP est le mode par défaut à partir de la version 25).
  - Indiquer les commandes d'installation.
   Pour plus de détails, consultez le paragraphe Paramètres avancés.
- Le bouton "Exporter les paramètres du serveur" permet de créer un fichier XML contenant les paramètres du serveur. Par défaut, ce fichier est créé dans le sous-répertoire "\Personal\Serveurs WEBDEV" du répertoire d'installation de WEBDEV. Il est ainsi possible de transmettre les informations concernant un serveur d'un projet à un autre. Les paramètres pourront être importés grâce au bouton "Importer les paramètres d'un serveur".

## Etape "Paramètres de déploiement du site"

L'assistant permet ensuite d'indiquer les paramètres de déploiement du site.

Les informations à saisir sont les suivantes :

- **Nom de ce profil de déploiement**.
  Ce nom sera donné au profil de déploiement pour le retrouver facilement (lors de la mise à jour du site par exemple).
- **Nom public du site sur le serveur d'application**.
  Par défaut, ce nom correspond au nom du projet. Il est possible d'utiliser un nom différent. Il est ainsi possible de déployer plusieurs instances du même projet sur le même serveur en leur donnant des noms de sites différents. Par exemple, le projet "REWALI" peut être déployé sur un serveur Web :
  - sous le nom REWALI : ce site est destiné à l'agence de voyage X1.
  - sous le nom RESA : ce site est destiné à l'agence de voyage X2.
   Il est possible d'indiquer si le site doit être définit comme site par défaut sur le serveur. Dans ce cas, le site sera définit comme application par défaut pour le serveur virtuel et sera accessible directement depuis l'adresse du serveur.
  Remarque : Il ne peut y avoir qu'une seule application par défaut.
- **Domaine associé**.
  Ce paramètre doit être renseigné dans le cas où le nom du serveur utilisé pour le déploiement est différent du nom de domaine permettant d'y accéder. Le nom du domaine indiqué sera utilisé dans la construction du fichier SiteMap ainsi que dans les URL de connexion. Le fichier SiteMap est un fichier utilisé par Google pour le référencement.
- **Emplacement des fichiers de données**.
  Permet d'indiquer le sous-répertoire contenant les fichiers de données au format HFSQL Classic. Le nom de ce sous-répertoire est lié au nom du site. Il correspond au nom du répertoire où les fichiers de données du site sont installés. Ce répertoire est un sous-répertoire du répertoire de données attribué par l'hébergeur. Ce nom de répertoire doit être modifié uniquement si plusieurs sites partagent les mêmes fichiers de données.

**Remarque** : Si vous avez renseigné ces informations dans les paramètres avancés, ces informations sont automatiquement récupérées.

## Validation

Si vous avez choisi de déployer le site WEBDEV sur un Serveur d'application WEBDEV distant, lors de la validation des paramètres de déploiement du site, WEBDEV tente de se connecter au serveur Web indiqué (et au serveur FTP indiqué si le déploiement est effectué par FTP).
En cas de problème, un message d'erreur est indiqué. Pour plus de détails sur les différentes erreurs, et leur mode de résolution, consultez : [Erreur en cas d'installation par FTP](2028057.md).

## Paramètres avancés

Les paramètres avancés permettent de spécifier les caractéristiques du profil de déploiement utilisé :

- **Nom du profil de déploiement**. Ce nom sera donné au profil de déploiement pour le retrouver facilement (lors de la mise à jour du site par exemple).
- **Paramètres du serveur d'application** (onglet "Général") :
  Adresse du serveur d'application, Compte de déploiement et mot de passe associé. Ces paramètres sont ceux renseignés dans l'étape "Paramètres du serveur d'application".
- **Paramètres du site** (onglet "Général") :
  - **Nom public du site sur le serveur d'application**.
    Par défaut, ce nom correspond au nom du projet. Il est possible d'utiliser un nom différent. Il est ainsi possible de déployer plusieurs instances du même projet sur le même serveur en leur donnant des noms de sites différents. Par exemple, le projet "REWALI" peut être déployé sur un serveur Web :
    - sous le nom REWALI : ce site est destiné à l'agence de voyage X1.
    - sous le nom RESA : ce site est destiné à l'agence de voyage X2.
     Il est possible d'indiquer si le site doit être définit comme site par défaut sur le serveur. Dans ce cas, le site sera définit comme application par défaut pour le serveur virtuel et sera accessible directement depuis l'adresse du serveur.
    Remarque : Il ne peut y avoir qu'une seule application par défaut.
  - **Domaine**.
    Ce paramètre doit être renseigné dans le cas où le nom du serveur utilisé pour le déploiement est différent du nom de domaine permettant d'y accéder. Le nom du domaine indiqué sera utilisé dans la construction du fichier SiteMap ainsi que dans les URL de connexion. Le fichier SiteMap est un fichier utilisé par Google pour le référencement.
  - **Répertoire contenant les fichiers de données HFSQL Classic**.
    Le nom de ce sous-répertoire est lié au nom du site. Il correspond au nom du répertoire où les fichiers de données du site sont installés. Ce répertoire est un sous-répertoire du répertoire de données attribué par l'hébergeur. Ce nom de répertoire doit être modifié uniquement si plusieurs sites partagent les mêmes fichiers de données.
  - **Gestion des langues** : Il est possible d'indiquer si le site doit être déployé dans toutes les langues ou uniquement pour certaines langues (à sélectionner).
- **Transfert des fichiers d'installation** (onglet "Avancé") :
  - Sélection du mode de transfert : HTTP ou FTP.
     Lors d'un transfert par FTP, il est possible d'indiquer :
    - L'adresse du serveur FTP,
    - Le mode FTP : FTP actif ou passif
  - Commandes d'installation (onglet "Avancé") :
    - **Utiliser le protocole HTTPS (un certificat SSL doit être installé sur le serveur web)**
      Si cette option est cochée, il est nécessaire qu'un certificat SSL soit installé sur le serveur web. Si ce certificat n'est pas signé par une autorité de confiance, un message d'avertissement sera affiché lors du déploiement. Pour ne plus avoir ce message, cochez la case "Ignorer les avertissements de sécurité des certificats HTTPS".
    - **Utiliser un serveur proxy pour les connexions HTTP et HTTPS**. Si cette option est cochée, il est possible d'indiquer les caractéristiques du serveur proxy à utiliser : adresse, nom d'utilisateur et mot de passe et port du proxy.
