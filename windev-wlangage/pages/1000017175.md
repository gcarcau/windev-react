# Fonctions OBEX

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Les fonctions OBEX sont les suivantes :

| [OBEXConnecte](1000017153.md) | Permet de se connecter à un périphérique supportant le protocole OBEX.  Rappel : Le protocole OBEX est un protocole de transfert de données utilisable par les faisceaux infrarouges et par Bluetooth. |
| --- | --- |
| [OBEXDéconnecte](1000017154.md) | Permet de se déconnecter d'un périphérique supportant le protocole OBEX. |
| [OBEXEnvoieFichier](1000017151.md) | Envoie un fichier sur un périphérique gérant le protocole OBEX. |
| [OBEXEnvoieVCard](1000017155.md) | Envoie un fichier VCard (carte de visite virtuelle) à un périphérique gérant le protocole OBEX. |
| [OBEXListeFichier](1000017148.md) | Liste les fichiers partagés par un périphérique utilisant le protocole OBEX. |
| [OBEXRécupèreFichier](1000017152.md) | Récupère un fichier sur un périphérique gérant le protocole OBEX. |
| [OBEXRécupèreVCard](1000017156.md) | Récupère une VCard sur un périphérique gérant le protocole OBEX. |
