# MiseEnForme (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **MiseEnforme** permet de décrire la mise en forme d'un élément. Cette propriété est utilisable :

- sur une variable de type [docElémentFormule](1000022937.md).
- sur une variable de type [docElémentTexte](1000022493.md).
- sur une variable de type [docFragment](1000022482.md).
- sur une variable de type [docNiveauNumérotation](1000022799.md).
