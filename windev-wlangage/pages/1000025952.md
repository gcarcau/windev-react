# websocketClient (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

Le type **websocketClient** permet de connaître et définir toutes les caractéristiques avancées d'un client connecté à un serveur de WebSocket. Les caractéristiques de ce client peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Récupère la liste des clients
tabClients est un tableau de websocketClient = WebSocketListeClientConnecté()
// Pour envoyer un message à chacun
POUR TOUT oClient DE tabClients
	WebSocketEnvoie(oClient, bufMessage)
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type websocketClient
Les propriétés suivantes peuvent être utilisées pour manipuler un client connecté à un serveur de WebSocket :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Connecté | Booléen | - Vrai si le client est encore connecté, - Faux dans le cas contraire.   **Cette propriété est disponible en lecture seulement**. |
| IP | Chaîne de caractères | Adresse IP du client. **Cette propriété est disponible en lecture seulement**. |
| Note | Tous types | Données métier quelconques associées à ce client. Ces données sont écrites par programmation, pour être réutilisés plus tard. La valeur par défaut est une chaîne vide (""). Grâce à cette propriété, le contexte global ou un autre client peut obtenir des informations sur ce client. |
