# <Graphe>.NuageCouleurSérie (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Initialise la couleur d'une série pour un graphe de type "Nuage de points".
**Rappel** : Par défaut, les couleurs des séries (ou des parts de secteur) sont sélectionnées selon un ordre prédéfini parmi un éventail de 13 couleurs.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

Nouveauté Abonnement

> _(Android)_ Cette fonction est désormais disponible pour les applications Android.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
// Ajoute une donnée dans le champ GRF_MonGraphe de type "Nuage de points".
// Cette valeur (20, 20) est ajoutée à la fin de la première série.
GRF_MonGraphe.NuageAjouteDonnéeXY(1, 20, 20)
// La série 1 du graphe GRF_MonGraphe est de couleur verte
GRF_MonGraphe.NuageCouleurSérie(1, VertClair)
```

## Syntaxe

```wlangage
<Champ Graphe>.NuageCouleurSérie(<Numéro de la série> , <Couleur>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres, de pages ou d'états).
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Numéro de la série>` *Entier*
> Numéro de la série à manipuler.
`<Couleur>` *Entier ou constante*
> Couleur de la série spécifiée. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md).

## Remarques

- Les données définies avec la fonction **<Graphe>.NuageCouleurSérie** seront prises en compte lors du prochain appel à la fonction [<Graphe>.Dessine](1000024062.md).
- Pour obtenir des couleurs dégradées, utilisez la fonction [<Graphe>.Dégradé](1000024061.md).
- La fonction **<Graphe>.NuageCouleurSérie** est équivalente à la fonction [<Graphe>.CouleurSérie](1000023599.md).
  La syntaxe de la fonction [<Graphe>.CouleurSérie](1000023599.md) utilisée avec les graphes de type "Nuage de points" est la suivante :
  ```wlangage
  <Champ Graphe>.CouleurSérie(2*<Indice>-1, <Couleur>)
  ```
