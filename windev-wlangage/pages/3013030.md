# InitHasard (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Initialise le générateur de nombres aléatoires.
> _(WEBDEV - Code Navigateur)_ Cette fonction n'a aucun effet en code navigateur.

## Exemple

```wlangage
// Initialisation du générateur de nombres aléatoires
InitHasard()
```

## Syntaxe

```wlangage
<Résultat> = InitHasard(<n>)
```

`<Résultat>` *Entier*
> Nouveauté 2025
> Valeur de la graine aléatoire choisie par le système pour initialiser le générateur de nombres aléatoires.
> Si le paramètre <n> est précisé, la graine correspond à cette valeur.
>
> > _(WEBDEV - Code Navigateur, Android, Widget Android, Java, PHP)_ Cette valeur n'est pas disponible.
`<n>` *Entier*
> Nombre de base du générateur de nombres aléatoires.
> Si ce paramètre n'est pas spécifié, le générateur de nombres aléatoires se base sur l'heure système (centièmes de seconde).

## Remarques

- Si la fonction **InitHasard** n'est pas appelée, les valeurs aléatoires générées par la fonction [Hasard](3013037.md) seront les mêmes à chaque exécution du programme.
- Des appels à la fonction **InitHasard** très rapprochés dans le temps donneront des séquences identiques car la fonction **InitHasard** utilise l'heure système pour générer des suites de nombres aléatoires.
- L'utilisation du paramètre <n> ne garantit pas d'obtenir des séquences différentes.
