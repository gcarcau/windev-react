# Fonctions de gestion des tableaux (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

| [<Tableau>.Agrège](1000024951.md) | Exécute une opération d'agrégation sur chaque élément d'un tableau. |
| --- | --- |
| [<Tableau>.Ajoute](1000024299.md) | Ajoute un élément en dernière position :  - d'un tableau WLangage à une dimension. - d'une propriété tableau d'un type avancé (tableau des événements de gglAgenda, ...). - d'une liste WLangage. |
| [<Tableau>.AjouteLigne](1000024300.md) | Ajoute une ligne à la fin :   - d'un tableau WLangage à une ou deux dimensions. - d'une propriété tableau d'un type avancé à deux dimensions (xlsDocument, ...). |
| [<Tableau>.AjouteRéférence](1000025416.md) | Ajoute la référence d'un objet en dernière position dans un tableau à une dimension. |
| [<Tableau>.AjouteTrié](1000024301.md) | Ajoute un élément dans un tableau WLangage à une dimension en prenant en compte :   - le critère de tri défini par la fonction [<Tableau>.Trie](1000024318.md) - l'opérateur de comparaison décrit dans la classe si les éléments du tableau sont des instances de classe. |
| [<Tableau>.Applique](1000024969.md) | Exécute une procédure pour chaque élément d'un tableau WLangage. |
| [<Tableau>.Cherche](1000024302.md) | Cherche l'indice d'un élément dans un tableau WLangage. |
| [<Tableau>.ChercheParProcédure](1000024303.md) | Recherche un élément dans un tableau WLangage à une dimension en utilisant une procédure de comparaison. |
| [<Tableau>.Copie](1000024304.md) | Copie le contenu d'un tableau dans un autre. |
| [<Tableau>.Déplace](1000024305.md) | Permet :  - de déplacer un élément dans un tableau WLangage à une dimension ou dans une propriété tableau d'un type avancé (tableau des événements de gglAgenda, ...). Les autres éléments du tableau sont décalés. - d'échanger deux éléments dans un tableau WLangage à une dimension ou dans une propriété tableau d'un type avancé (tableau des événements de gglAgenda, ...). |
| [<Tableau>.DéplaceLigne](1000024306.md) | Permet :  - soit de déplacer une ligne dans un tableau à deux dimensions ou dans une propriété tableau d'un type avancé. Les autres lignes du tableau sont décalées. - soit d'échanger deux lignes dans un tableau à deux dimensions ou dans une propriété tableau d'un type avancé. |
| [<Tableau>.Distinct](1000025406.md) | Renvoie un tableau sans doublons. _(WEBDEV - Code Navigateur)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2. |
| [<Tableau>.EchangeLigne](1000024307.md) | Permet d'échanger deux lignes dans un tableau à deux dimensions ou dans une propriété tableau d'un type avancé. |
| [<Tableau>.Filtre](1000024968.md) | Renvoie un tableau contenant les éléments d'un tableau source pour lesquels une procédure renvoie Vrai. |
| [<Tableau>.Info](1000024308.md) | Renvoie les caractéristiques d'un tableau : type des éléments, nombre de dimensions, dimensions, ... |
| [<Tableau>.Insère](1000024309.md) | Insère un élément à une position donnée :  - dans un tableau à une dimension. - dans un tableau associatif. - dans une propriété tableau d'un type avancé (tableau des événements de gglAgenda, ...). - dans une liste WLangage. |
| [<Tableau>.InsèreLigne](1000024310.md) | Insère une ligne à une position donnée :   - dans un tableau WLangage à deux dimensions. - dans une propriété tableau d'un type avancé à deux dimensions (xlsDocument, ...). |
| [<Tableau>.InsèreRéférence](1000025414.md) | Ajoute la référence d'un objet à la position donnée dans un tableau à une dimension. |
| [<Tableau>.Intersection](1000025407.md) | Renvoie un tableau correspondant à l'intersection de deux tableaux. _(WEBDEV - Code Navigateur)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2. |
| [<Tableau>.Inverse](1000024311.md) | Inverse le contenu d'un tableau à une dimension. |
| [<Tableau>.Max](1000025411.md) | Renvoie la plus grande des valeurs présentes dans le tableau. |
| [<Tableau>.Mélange](1000024312.md) | Mélange les éléments d'un tableau WLangage. |
| [<Tableau>.Min](1000025412.md) | Renvoie la plus petite des valeurs présentes dans le tableau. |
| [<Tableau>.Moyenne](1000025417.md) | Calcule la moyenne des éléments d'un tableau. |
| [<Tableau>.Occurrence](1000024313.md) | Renvoie :  - soit le nombre d'éléments présents dans un tableau à une dimension. - soit le nombre de lignes présentes dans un tableau à deux dimensions. - soit le nombre d'éléments présents dans la première dimension d'un tableau à trois dimensions ou plus. |
| [<Tableau>.Somme](1000025415.md) | Calcule la somme des éléments d'un tableau. |
| [<Tableau>.Supprime](1000024314.md) | Supprime un élément à une position donnée :  - dans un tableau WLangage à une dimension. - dans une propriété tableau d'un type avancé (tableau des événements de gglAgenda, ...). - dans un tableau associatif. - dans une liste WLangage. |
| [<Tableau>.SupprimeDoublon](1000024315.md) | Supprime les doublons dans un tableau. |
| [<Tableau>.SupprimeLigne](1000024316.md) | Supprime une ligne à une position donnée :   - dans un tableau à deux dimensions. - dans la propriété tableau d'un type avancé (tableau des événements de gglAgenda, ...)  La taille du tableau est automatiquement réduite. |
| [<Tableau>.SupprimeTout](1000024317.md) | Supprime tous les éléments :  - d'un tableau WLangage à une dimension ou deux dimensions. - d'un tableau associatif. - de la propriété tableau d'un type avancé (tableau des événements de gglAgenda, ...). - d'une file WLangage. - d'une pile WLangage. - d'une liste WLangage. |
| [<Tableau>.TousFaux](1000024935.md) | Renvoie Vrai si tous les éléments d'un tableau sont Faux. |
| [<Tableau>.TousVrai](1000024936.md) | Renvoie Vrai si tous les éléments d'un tableau sont Vrai. |
| [<Tableau>.Transforme](1000025418.md) | Renvoie un tableau WLangage contenant les résultats d'une procédure exécutée pour chaque élément d'un tableau source. |
| [<Tableau>.Trie](1000024318.md) | Trie un tableau WLangage. |
| [<Tableau>.UnFaux](1000024937.md) | Renvoie Vrai si au moins un élément d'un tableau est Faux. |
| [<Tableau>.Union](1000025408.md) | Renvoie un tableau correspondant à l'union de deux tableaux. _(WEBDEV - Code Navigateur)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2. |
| [<Tableau>.UnionTout](1000025410.md) | Renvoie un tableau correspondant à l'union de deux tableaux (sans suppression des doublons). _(WEBDEV - Code Navigateur)_ Attention : Cette fonctionnalité est disponible uniquement à partir de WINDEV Suite SaaS 2025 Update 2. Pour plus de détails, consultez Utiliser les nouveautés de WINDEV Suite SaaS 2025. |
| [<Tableau>.UnVrai](1000024938.md) | Renvoie Vrai si au moins un élément d'un tableau est Vrai. |
| [<Type Tableau>.Contient](1410091180.md) | Cherche un élément dans un tableau WLangage. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
