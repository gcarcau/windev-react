# gglSociété (Type de variable)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Le type **gglSociété** permet de décrire les sociétés et organisations auxquelles appartiennent un contact.
Ce type de variable est utilisé par le type [gglContact](1000017434.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Connexion à Google
Cnx est une gglConnexion
Cnx.Email = "balthazar@gmail.com"
Cnx.MotDePasse = "azerty"
Cnx.NomApplication = "MonAppli-01"
SI GglConnecte(Cnx) = Faux ALORS
	Erreur(ErreurInfo())
FIN
...
// Récupération du tableau des contacts
tabContacts est un tableau de gglContact
tabContacts = GglListeContact(Cnx)
// Affichage des sociétés du premier contact
MonContact est un gglContact = tabContacts[1]
Org est une gglSociété dynamique
POUR TOUT Org DE MonContact.Société
	Trace(Org.Nom + " : " + Org.Libellé)
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type gglSociété
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **gglSociété** :

| Nom | Type manipulé | Effet |
| --- | --- | --- |
| Libellé | Chaîne de caractères | Description de la société. |
| Nom | Chaîne de caractères | Nom de la société. |
| Principal | Booléen | - Vrai si la société correspond à la société principale du contact, - Faux dans le cas contraire. |
| Titre | Chaîne de caractères | Titre du contact dans la société. |
| Type | Constante de type entier | Type de la société correspondant à une des variables suivantes :  - *gglAutre* : Société à laquelle le contact est lié d'une manière non professionnelle. - *gglBureau* : Société à laquelle le contact est lié d'une manière professionnelle. |
