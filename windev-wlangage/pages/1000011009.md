# Fonctions de gestion des rendez-vous (Outlook, Lotus Notes, appareil mobile)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions de gestion des rendez-vous permettent :

- de gérer les contacts présents dans l'agenda d'une messagerie Lotus Notes ou Outlook.
- de gérer les rendez-vous présents sur un mobile (Android/iOS).

| [iCalendarVersRendezVous](1000021827.md) | Liste les rendez-vous décrits dans une chaîne de caractères au format iCalendar. |
| --- | --- |
| [RendezVousAffiche](1000020692.md) | Affiche un rendez-vous dans l'application native de gestion des rendez-vous de l'appareil mobile (Android ou iOS). |
| [RendezVousAjoute](1000011001.md) | Ajoute un rendez-vous :   - dans l'agenda d'une messagerie Lotus Notes ou Outlook. - dans un calendrier (ou agenda) d'un appareil mobile (Android ou iOS). |
| [RendezVousCrée](1000020691.md) | Permet de créer un rendez-vous via la fenêtre de création de rendez-vous de l'application native de gestion des rendez-vous de l'appareil Android ou iOS. |
| [RendezVousDernier](1000011002.md) | Lit le dernier rendez-vous présent dans l'agenda d'une messagerie Lotus Notes ou Outlook. |
| [RendezVousListe](1000020690.md) | Liste les rendez-vous présents sur le mobile (Android/iOS) et correspondant aux critères spécifiés. |
| [RendezVousListeCalendrier](1000020661.md) | Liste les calendriers disponibles sur l'appareil mobile (Android/iOS). |
| [RendezVousLit](1000011011.md) | Lit un rendez-vous présent dans l'agenda d'une messagerie Lotus Notes ou Outlook. |
| [RendezVousModifie](1000011003.md) | Modifie le rendez-vous en cours :   - dans l'agenda d'une messagerie Lotus Notes ou Outlook. - dans un calendrier (ou agenda) d'un appareil mobile (Android/iOS). |
| [RendezVousPrécédent](1000011004.md) | Lit le rendez-vous précédent le rendez-vous en cours, dans l'agenda d'une messagerie Lotus Notes ou Outlook. |
| [RendezVousPremier](1000011005.md) | Lit le premier rendez-vous présent dans l'agenda d'une messagerie Lotus Notes ou Outlook. |
| [RendezVousRAZ](1000011006.md) | Réinitialise :   - la structure [RendezVous](1000011010.md). - la variable de type [RendezVous](1000019244.md). |
| [RendezVousSuivant](1000011007.md) | Lit le rendez-vous suivant le rendez-vous en cours, dans l'agenda d'une messagerie Lotus Notes ou Outlook. |
| [RendezVousSupprime](1000011008.md) | Supprime :   - le rendez-vous en cours de l'agenda d'une messagerie Lotus Notes ou Outlook. - un rendez-vous dans un calendrier (ou agenda) d'un appareil mobile (Android/iOS). |
| [RendezVousVersiCalendar](1000021828.md) | Exporte un rendez-vous ou une liste de rendez-vous au format iCalendar. |
