# <Variable Connexion>.RSAttendTraitementDonnées (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Permet d'attendre que :

- les données à répliquer sur le serveur maître soient envoyées sur le serveur abonné.
- les données à répliquer reçues sur le serveur abonné soient entièrement appliquées.

## Exemple

```wlangage
MaConnexion est une Connexion

MaConnexion.RSAttendTraitementDonnées(idRpl, 10000)
```

## Syntaxe

#### Attendre que les données à répliquer sur le serveur maître soient envoyées sur le serveur abonné

```wlangage
<Résultat> = <Connexion>.RSAttendTraitementDonnées(<Réplication> , <Timeout>)
```

`<Résultat>` *Booléen*
> - Vrai si les données sont envoyées,
> - Faux en cas d'erreur ou si le délai d'attente est écoulé.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion vers le serveur maître HFSQL.
`<Réplication>` *Entier*
> Identifiant de la réplication. Cet identifiant correspond à la propriété **Identifiant** de la variable de type [hRSConfig](1000020484.md) décrivant la réplication.
`<Timeout>` *Entier*
> Temps maximal en millisecondes d'attente. Ce paramètre peut correspondre à :
>
> - un entier correspondant au nombre de millisecondes,
> - une variable de type Durée,
> - l'indication directe de la durée (par exemple '10 ms').

#### Attendre que les données à répliquer reçues sur le serveur abonné soient entièrement appliquées

```wlangage
<Résultat> = <Connexion>.RSAttendTraitementDonnées(<Serveur Maître> , <Réplication> , <Timeout>)
```

`<Résultat>` *Booléen*
> - Vrai si les données sont appliquées,
> - Faux en cas d'erreur ou si le délai d'attente est écoulé.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion vers le serveur abonné HFSQL.
`<Serveur Maître>` *Entier*
> Identifiant du serveur maître.
`<Réplication>` *Entier*
> Identifiant de la réplication. Cet identifiant correspond à la propriété **Identifiant** de la variable de type [hRSConfig](1000020484.md) décrivant la réplication.
`<Timeout>` *Entier*
> Temps maximal en millisecondes d'attente. Ce paramètre peut correspondre à :
>
> - un entier correspondant au nombre de millisecondes,
> - une variable de type Durée,
> - l'indication directe de la durée (par exemple '10 ms').
