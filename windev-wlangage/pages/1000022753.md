# <Variable Connexion>.SauveParamètre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Sauve une valeur persistante. Cette valeur pourra être lue grâce à la fonction [<Variable Connexion>.ChargeParamètre](1000022649.md).
Remarque : Les paramètres sont sauvegardés par base de données dans le fichier "user_param.fic".

## Exemple

```wlangage
// Sauvegarde d'une valeur
MaConnexion est une Connexion
MaConnexion.SauveParamètre("MonParamètre", 5)
```

#### Sauvegarde d'un paramètre sur le serveur (depuis le poste Client)

```wlangage
<Résultat> = <Connexion>.SauveParamètre(<Paramètre> , <Valeur du paramètre>)
```

`<Résultat>` *Booléen*
> - Vrai si la sauvegarde a été réalisée,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion à utiliser.
`<Paramètre>` *Chaîne de caractères*
> Nom du paramètre à sauvegarder. Ce paramètre ne doit pas correspondre à une chaîne vide et ne doit pas contenir le caractère "RC" (Retour Chariot).
`<Valeur du paramètre>` *Type correspondant à la valeur à sauver*
> Valeur à sauver.

## Remarques

### Type de variables sauvegardées
La fonction **<Variable Connexion>.SauveParamètre** permet de sauvegarder des variables de type simple (chaîne, entier, ...).
Pour sauvegarder des variables complexes (objets, structures, ...), il est nécessaire de sérialiser ces variables sous forme de chaîne grâce à la fonction [Sérialise](3013065.md).
