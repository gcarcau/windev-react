# CertificatExtraitValeurExtension (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Renvoie la valeur d'une extension du certificat.

## Exemple

```wlangage
// Extraction de la valeur de l'extension "1.3.6.1.4.1.311.10.3.4" du certificat
cert est un Certificat = CertificatSélecteur()

bufValeur est un Buffer = CertificatExtraitValeurExtension(cert, "1.3.6.1.4.1.311.10.3.4")
```

## Syntaxe

```wlangage
<Résultat> = CertificatExtraitValeurExtension(<Certificat> , <OID>)
```

`<Résultat>` *Buffer*
> Valeur de l'extension. Si l'extension n'existe pas, le buffer renvoyé est vide.
`<Certificat>` *Variable de type Certificat*
> Nom de la variable de type [Certificat](1000019287.md) correspondant au certificat dans lequel l'extension doit être cherchée.
`<OID>` *Chaîne de caractères*
> OID de l'extension.

**Composante : wd300std.dll**
