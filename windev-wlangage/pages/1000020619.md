# SysIdentifiant (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Renvoie l'identifiant unique de l'appareil mobile en cours.
> _(Android)_ L'identifiant de l'appareil est généré aléatoirement lors du tout premier démarrage de l'appareil et reste inchangé durant toute la vie de l'appareil. Seule exception : cet identifiant peut être réinitialisé en cas de restauration des paramètres d'usine. Attention : A partir d'Android 8.0, l'identifiant retourné est unique pour chaque combinaison signature, utilisateur et appareil. Par conséquent, les applications avec des signatures différentes exécutées sur le même appareil n'obtiendront pas le même identifiant (même pour le même utilisateur).

> _(iPhone/iPad)_ Cet identifiant est un identifiant unique identifiant le mobile pour un fournisseur. Cet identifiant est généré à partir de l'identifiant du Bundle.

## Exemple

```wlangage
sIdentifiant est une chaîne
sIdentifiant = SysIdentifiant()
```

## Syntaxe

```wlangage
<Résultat> = SysIdentifiant()
```

`<Résultat>` *Chaîne de caractères*
> Identifiant unique de l'appareil.
