# DDEDestinataire (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Identifie le destinataire d'une connexion DDE.

## Exemple

```wlangage
// Ouverture d'une connexion DDE
NumConnexion = DDEConnecte(NomServeur, "MonSujet")
...

// Destinataire de la connexion en cours
ResDestinataire = DDEDestinataire(NumConnexion)
```

## Syntaxe

```wlangage
<Résultat> = DDEDestinataire([<Identifiant connexion>])
```

`<Résultat>` *Chaîne de caractères*
> Destinataire de la connexion DDE.
`<Identifiant connexion>` *Entier optionnel*
> Identifiant de la connexion renvoyé par la fonction [DDEConnecte](3028015.md). Si ce paramètre n'est pas précisé, **DDEDestinataire** utilise la dernière connexion manipulée.

**Composante : wd300std.dll**
