# Requête

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

Le mot-clé "Requête" permet de désigner :

- les requêtes SQL disponibles en WLangage. Pour plus de détails, consultez [Requêtes SQL en WLangage](1514082.md).
- les requêtes utilisées par les variables de type [URI](1000024027.md).
