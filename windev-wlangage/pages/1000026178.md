# <Variable Email>.ExporteHTML (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Récupère le code HTML d'un email pour l'afficher dans un champ HTML (champ HTML, champ d'affichage HTML, ...). Les images sont extraites sur le disque.

## Exemple

```wlangage
oMailReçu est un Email//...// Lecture de la boîte mail pour renseigner oMailReçu//...EDHTML_Mail.RépertoireDeTravail = "C:\Temp\mail"EDHTML_Mail = oMailReçu.ExporteHTML(EDHTML_Mail.RépertoireDeTravail)
```

## Syntaxe

```wlangage
<Résultat> = <Email>.ExporteHTML(<Répertoire>)
```

`<Résultat>` *Chaîne de caractères*
> Code HTML pouvant être affecté à un champ HTML (champ HTML, champ d'affichage HTML, ...).
`<Email>` *Variable de type Email*
> Nom de la variable de type [Email](1000018713.md) correspondant à l'email dont le code HTML doit être récupéré.
`<Répertoire>` *Chaîne de caractères*
> Chemin du répertoire dans lequel les images seront enregistrées.
> Remarque : Si au moment de la récupération, l'image existe déjà, un suffixe est ajouté au nom de l'image enregistrée sur le disque (_1, _2, ..., _n).

## Remarques

- Les images extraites sont référencées dans le code HTML résultat par une balise de type "./monimage.png".
- Les références aux images de type <img src="cid:dddd"> sont remplacées par des références de type <img src="./monimage.png">.
