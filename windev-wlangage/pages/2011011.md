# Analyse d'un projet : le Modèle Logique des Données (MLD)

> **Disponible :** **WINDEV** (Windows, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Une Modèle Logique des Données (MLD) permet de décrire les structures de données (fichiers de données, rubriques, etc.) utilisées dans une application WINDEV, WEBDEV ou WINDEV Mobile. Ce Modèle Logique des Données est appelé "Analyse" sous WINDEV, WEBDEV ou WINDEV Mobile et peut être créé et édité via l'éditeur d'analyses.
**Remarques** :

- Les termes "MLD" et "Analyse" sont utilisés indifféremment pour définir la structure de la base de données associée à un projet.
- Pour plus de détails sur les manipulations d'une analyse (MLD), consultez [Manipulations d'une analyse (MLD)](2011006.md).

## Création d'une analyse (MLD)

Pour créer une analyse (MLD) :

1. Cliquez sur  parmi les boutons d'accès rapide.
  - La fenêtre de création d'un nouvel élément s'affiche : cliquez sur "Données" puis sur "Analyse".
  - L'assistant de création d'une analyse se lance.
2. Spécifiez dans la première étape de l'assistant :
  - le ***nom et le répertoire de l'analyse***. L'analyse correspond à un fichier ".WDA". Par défaut, ce fichier sera créé dans le répertoire de l'analyse du projet (répertoire <Nom du projet>.ANA). Ce répertoire doit être accessible en lecture et en écriture.
  - si l'analyse doit être associée au projet en cours à la place de l'analyse actuelle (cas de la création d'une analyse dans un projet déjà associé à une analyse).
  - la ***description de l'analyse*** décrivant succinctement le sujet de l'analyse.
3. L'étape suivante de l'assistant permet de spécifier le type de la base de données manipulée par le projet :
  - HFSQLDrive (solution payante). Pour plus de détails sur HFSQLDrive, consultez [HFSQLDrive, votre base de données dans le Cloud en 3 clics](https://pcscloud-drive.net/FR/HFSQLDrive/index.awp).
  - PCSCloud (solution payante). Pour plus de détails sur PCSCloud, consultez [Cloud pour base de données HFSQL](https://pcscloud.net/FR/cloud_applications.awp).
  - HFSQL Client/Serveur,
  - HFSQL Classic,
  - Bases de données externes : SQL Server, Oracle, MySQL, etc.
    Remarque : Si l'analyse doit manipuler une base de données externe, le connecteur natif correspondant doit être installé sur le poste.
4. Si la base de données est différente de HFSQL Classic, l'assistant permet de définir la connexion à la base de données (nom, libellé) et de saisir les paramètres avancés (serveur, utilisateur et mot de passe). Ces informations peuvent être également modifiées par la suite, dans l'éditeur d'analyses.
5. Validez. L'analyse créée devient l'analyse en cours.
6. Créez l'ensemble des éléments (fichiers de données, rubriques et liaisons) de votre analyse.
  **Remarque** : Pour plus de détails, consultez [Fichiers de données de l'analyse](2011010.md), [Rubriques d'un fichier de données](2011009.md) et [Liaisons de l'analyse](2011008.md).
7. Pour utiliser l'analyse dans votre projet, générez l'analyse : sous le volet "Analyse", dans le groupe "Analyse", déroulez "Génération" et sélectionnez "Génération". Pour plus de détails, consultez [Génération d'une analyse](2011012.md).
