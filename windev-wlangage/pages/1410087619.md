# HTMLSupprimeAttribut (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Mac Catalyst)

Supprime un attribut donné

## Exemple

```wlangage
hDoc est un htmlDocument = "
<html>
	<head/>
	<body>
		<h2><span>
			<p>Texte</p>
			</span></h2><h3><div></div><span></span></h3>
	</body>
</html>
"

hNoeud est un htmlNoeud

hNoeudRecherche est un tableau de htmlNoeud <- HTMLChercheElémentParBalise(hDoc, "h3")
hNoeud <- hNoeudRecherche[1]
HTMLModifieAttribut(hNoeud, "id")
// body : <h2><span><p>Texte</p></span></h2><h3 id><div></div><span></span></h3>
HTMLModifieAttribut(hNoeud, "id", "h3")
// body : <h2><span><p>Texte</p></span></h2><h3 id="h3"><div></div><span></span></h3>
HTMLSupprimeAttribut(hNoeud, "id")
// body : <h2><span><p>Texte</p></span></h2><h3><div></div><span></span></h3>
```

## Syntaxe

```wlangage
HTMLSupprimeAttribut(<Noeud source> , <Attribut>)
```

`<Noeud source>` *Variable de type htmlNoeud*
> Nom de la variable de type [htmlNoeud](1000026081.md) correspondant au noeud de référence pour la suppression de l'attribut.
`<Attribut>` *Variable de type htmlAttribut ou chaîne de caractères*
> Attribut à supprimer. Cet attribut peut correspondre :
>
> - à une variable de type [htmlAttribut](1000025912.md).
> - à une chaîne de caractères correspondant à l'attribut à supprimer.
