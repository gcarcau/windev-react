# gpwRecupInfoUtilisateur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Récupère des informations sur l'utilisateur en cours (application utilisant le groupware utilisateur).

## Exemple

```wlangage
// Récupération du prénom de l'utilisateur
Prénom est une chaîne
Prénom = gpwRecupInfoUtilisateur(gpwInfoPrénom)

// Récupération de la liste des groupes de l'utilisateur
sListeGroupe est une chaîne = gpwRecupInfoUtilisateur(gpwInfoGroupe)

POUR TOUTE CHAÎNE sGroupe DE sListeGroupe SÉPARÉE PAR TAB
        Trace(sGroupe)
FIN
```

## Syntaxe

```wlangage
<Résultat> = gpwRecupInfoUtilisateur(<Information>)
```

`<Résultat>` *Chaîne de caractères, Booléen ou variable de type gpwUtilisateur*
> - Information demandée.
> - Variable de type [gpwUtilisateur](1000021088.md), si la constante *gpwComplet* a été utilisée.
`<Information>` *Constante*
> Type d'information recherchée :
>
> | *gpwComplet* | Permet de récupérer une variable de type [gpwUtilisateur](1000021088.md) contenant toutes les informations sur l'utilisateur courant. Remarque : la propriété **MotDePasse** de la variable n'est pas renseignée. |
> | --- | --- |
> | *gpwInfoDoubleAuthentification* | Permet de savoir si la double authentification est activée (<Résultat sera à Vrai) ou non (<Résultat sera à Faux) pour l'utilisateur connecté (cette information est donnée par application). |
> | *gpwInfoGroupe* | Nom du groupe de l'utilisateur, ou liste des groupes séparés par une tabulation. |
> | *gpwInfoLogin* | Login de l'utilisateur ou constante correspondant au type de l'utilisateur :   - *gpwSuperviseur* : Superviseur de l'application. - *gpwVisiteur* : Visiteur. |
> | *gpwInfoNom* | Nom de l'utilisateur |
> | *gpwInfoPrénom* | Prénom de l'utilisateur. |
> | *gpwInfoSuperviseur* | Permet de savoir si l'utilisateur connecté est un administrateur (<Résultat sera à Vrai) ou non (<Résultat sera à Faux). |

**Classification Métier / UI : Code neutre**

**Composante : wd300gpu.dll**
