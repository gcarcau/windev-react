# Propriétés associées au champ Bouton

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

## Présentation

Les champs Bouton peuvent être manipulés avec les propriétés WLangage aussi bien dans une fenêtre que dans une page.
