# MemCrée (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Crée une zone mémoire. Cette zone mémoire peut contenir des informations de type texte ou numérique.

## Exemple

```wlangage
// Création d'une zone mémoire
MemCrée("MaZoneMémoire")

// Lors de la saisie des fonctions MemXXX suivantes,
// "MaZoneMémoire" sera automatiquement proposée dans la complétion
```

```wlangage
sChaîne est une chaîne = "A"
sChaîne = Complète(sChaîne, 10000, "B")
Trace(Taille(sChaîne))

MemCrée("ZM")
MemAjoute("ZM", "1", sChaîne)
sChaîne = MemPremier("ZM")
Trace(Taille(sChaîne))
```

## Syntaxe

```wlangage
MemCrée(<Zone mémoire>)
```

`<Zone mémoire>` *Chaîne de caractères*
> Nom de la zone mémoire à créer (20 caractères maximum). Ce nom sera utilisé par toutes les fonctions de gestion des zones mémoire.

## Remarques

### Existence de la zone mémoire
L'existence de la zone mémoire n'est pas vérifiée. Si la zone mémoire existait auparavant, cette zone mémoire est écrasée. Pour vérifier l'existence d'une zone mémoire, utilisez la fonction [MemExiste](3053006.md).

### Complétion automatique sur le nom de la zone mémoire
Sous l'éditeur de code, dès qu'une zone mémoire a été manipulée avec une fonction Memxxx (par exemple la fonction **MemCrée**), ce nom sera automatiquement proposé lors de la saisie de fonctions WLangage acceptant le nom de la zone mémoire en paramètre.

### Taille des informations
Si la taille des informations à stocker dans la zone mémoire est plus importante que la place mémoire disponible, un "swap disque" est utilisé : un ou plusieurs fichiers temporaires sont créés afin de stocker le surplus d'informations. Ces fichiers temporaires seront créés sur le disque local, dans le répertoire indiqué par la variable d'environnement "TEMP".
