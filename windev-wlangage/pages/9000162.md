# Personnalisation du visualisateur de rapports : Fenêtres disponibles

> **Disponible :** **WINDEV** (Windows)

## Fenêtres utilisées par le visualisateur de rapports

Par défaut, ces fenêtres sont les suivantes :

| [image: Fenêtre ]Fenêtre "Aperçu"Cette fenêtre correspond à l'aperçu avant impression. |  |
| --- | --- |
| [image: Fenêtre ]Fenêtre "WD_Filigrane"Cette fenêtre permet de gérer les filigranes. |  |
| [image: Fenêtre ]Fenêtre "WD_Imprimer_Etat"Cette fenêtre est utilisée lors de l'impression d'un état WINDEV depuis la fenêtre d'aperçu avant impression. Cette fenêtre permet de paramétrer :  - les pages à imprimer. - le nombre de copies à réaliser. - la destination de l'impression (imprimante). - les paramètres de l'imprimante, notamment l'orientation du papier.   Cette fenêtre permet également de connaître l'état de l'imprimante et son type. | [image: Fenêtre ]Fenêtre "WD_Imprimer"Cette fenêtre est utilisée lors d'une impression réalisée en WLangage (fonction [iFinImprime](3046053.md) utilisée après la fonction [iAperçu](3046069.md)).  Cette fenêtre permet de paramétrer :  - les pages à imprimer. - le nombre de copies à réaliser.  Cette fenêtre permet également de connaître :  - le nom de l'imprimante utilisée, - l'état de l'imprimante utilisée - le type de l'imprimante utilisée. |
| [image: Fenêtre ]Fenêtre "WD_Patience" |  |
| [image: Fenêtre ]Fenêtre "WD_Installe_EtatsEtRequêtes"Cette fenêtre est affichée par exemple lorsque l'utilisateur tente de modifier un état sans avoir installé le logiciel "Etats et requêtes". |  |
| [image: Fenêtre ]Fenêtre "WD_PopupSelCouleur"Cette fenêtre permet de sélectionner les couleurs utilisées pour les annotations. | [image: Fenêtre ]Fenêtre "WD_PopupSelEpaisseur"Cette fenêtre permet de sélectionner l'épaisseur du trait utilisé pour les annotations. |
| [image: Fenêtre ]Fenêtre "WD_PopupGroupeEtat"Cette fenêtre permet de sélectionner le type d'état à imprimer (cas d'un groupe d'états ou d'états avec ancrage). | [image: Fenêtre ]Fenêtre "WD_PopupImprimante"Cette fenêtre permet de sélectionner l'imprimante à utiliser. |
| [image: Fenêtre ]Fenêtre "WD_PopupOptionMire"Cette fenêtre permet de définir les options de la mire de l'aperçu. |  |
| [image: Fenêtre ]Fenêtre "WD_SelImprimante"Cette fenêtre permet d'afficher le message provenant de l'imprimante. |  |
