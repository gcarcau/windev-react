# grWaterfallCouleur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (iPhone/iPad)

Indique la couleur d'un type de catégorie pour un graphe de type Waterfall.
**Remarque** : Si cette fonction n'est pas utilisée, le graphe est affiché avec des couleurs sélectionnées par défaut.

## Exemple

```wlangage
grWaterfallCouleur(GRF_Waterfall, grTotal, RVB(83,129,179))
grWaterfallCouleur(GRF_Waterfall, grSousTotal, RVB(103,89,159))
grWaterfallCouleur(GRF_Waterfall, grPositif, RVB(115,179,83))
grWaterfallCouleur(GRF_Waterfall, grNégatif, RVB(179,84,92))
```

## Syntaxe

```wlangage
grWaterfallCouleur(<Nom du graphe> , <Type de la catégorie> , <Couleur>)
```

`<Nom du graphe>` *Nom de champ ou chaîne de caractères*
> Nom du graphe à manipuler. Ce nom peut correspondre :
>
> - au nom du graphe défini par programmation avec la fonction [grCrée](3042005.md).
> - au nom du champ Graphe présent dans l'éditeur de fenêtres, d'états ou de pages.
>
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Type de la catégorie>` *Constante de type Entier*
> Type de la catégorie pour laquelle la couleur doit être définie :
>
>
> | *grNégatif* | Valeurs négatives du graphe. |
> | --- | --- |
> | *grPositif* | Valeurs positives du graphe. |
> | *grSousTotal* | Valeurs de type sous-total du graphe. |
> | *grTotal* | Valeurs de type total du graphe. |
`<Couleur>` *Entier ou constante de type Entier*
> Couleur du type de catégorie spécifié. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - une couleur prédéfinie (voir [les couleurs prédéfinies du WLangage](3010002.md)).
> - la constante *CouleurDéfaut* :
>   - Si la constante *CouleurDéfaut* est utilisée pour les types de catégorie *grPositif* et *grNégatif*, les couleurs par défaut des séries sont utilisées.
>   - Si la constante *CouleurDéfaut* est utilisée pour le type de catégorie *grSousTotal* et si des couleurs spécifiques sont utilisées pour les types de catégorie *grPositif* et *grNégatif*, ces couleurs spécifiques sont utilisées pour le sous-total.

## Remarques

- Les couleurs définies pour les catégories avec la fonction [grCouleurCatégorie](1000020928.md) sont prioritaires sur les couleurs définies avec la fonction **grWaterfallCouleur**.
- Cette fonction s'applique uniquement aux graphes de type Waterfall.
