# <Variable Email>.ConstruitSource (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Génère le code source de l'email à envoyer à partir d'une variable de type [Email](1000018713.md).
Le code source est généré dans la propriété **Source** de la variable [Email](1000018713.md). Ce code source peut ensuite être sauvé dans un fichier .eml par exemple.

**Remarque** : Cette fonction peut être utile pour modifier un élément dans un email à envoyer. Le mail pourra être envoyé par la fonction [EmailEnvoie](3032003.md). Pour plus de détails, consultez [Ecrire un email personnalisé](3032002.md).

## Exemple

```wlangage
// Initialisation de la variable
MonMessage est un Email

Ajoute(MonMessage.Destinataire, "support_test@pcsoft_test.fr")
MonMessage.Expediteur = "client@societe.fr"
MonMessage.Message = "Test Auto eMail"

// Création du fichier .eml
SI MonMessage.ConstruitSource() = Vrai ALORS
	fSauveTexte("c:\MesEmails\Test.eml", MonMessage.Source)
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Email>.ConstruitSource([<Options avancées>])
```

`<Résultat>` *Booléen*
> - Vrai si le code source a été généré,
> - Faux dans le cas contraire. En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai.
>   Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*. Le code généré peut être lu dans la variable Email.Source du thread en cours.
`<Email>` *Variable de type Email*
> Nom de la variable de type [Email](1000018713.md) à manipuler.
`<Options avancées>` *Constante optionnelle de type Entier*
> Combinaison des constantes suivantes :
>
> | *emailOptionEncodeEntête* | Encode les entêtes du message en Quoted-Printable si nécessaire.  Par défaut, l'entête du message n'est pas encodé. Cette constante évite les messages avec des accents mal encodés. |
> | --- | --- |
> | *emailOptionEntêteCCi* | Permet d'ajouter les destinataires non officiels dans le code source de l'entête de l'email. |

## Remarques

Pour remplir une variable de type [Email](1000018713.md) à partir du contenu de sa propriété **Source**, utilisez la fonction [<Variable Email>.ImporteSource](1000022288.md).

**Composante : wd300com.dll**
