# Constantes de gestion du son

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

| Constante | Détail |
| --- | --- |
| **sonBloque** | Le code continue de s'exécuter lorsque le son a été joué |
| **sonBoucle** | Son joué en boucle |
| **sonDéfaut** | Le code continue de s'exécuter dès que le son est lancé |
| **sonSystèmeArrêtCritique** | Son système correspondant à l'arrêt critique du poste. |
| **sonSystèmeAstérisque** | Son système astérisque. |
| **sonSystèmeDéfaut** | Son par défaut du système (bip en général). |
| **sonSystèmeExclamation** | Son système exclamation. |
| **sonSystèmeFermeture** | Son système de fermeture de Windows. |
| **sonSystèmeQuestion** | Son système question. |
