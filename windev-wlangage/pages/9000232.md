# Choisir son vocabulaire

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

WINDEV dispose de son propre vocabulaire, vous le savez.
En version 2025, il devient possible de sélectionner le vocabulaire que vous désirez utiliser.
L'exemple le plus représentatif est celui de "fichier" ou "fichier de données", que l'on souhaite souvent remplacer par "table".
Certains termes historiques peuvent maintenant être remplacés par d'autres termes.
Voici quelques exemples :

| **Vocabulaire historique** | **Vocabulaire générique** |
| --- | --- |
| Fichier de données | Table |
| Analyse | Schéma des données |
| Gabarit | Thème |

En fonction du vocabulaire choisi, l'environnement s'adapte :

- l'assistance à la saisie,
- les "7 onglets",
- aide, etc.

Le WLangage permet de coder avec le vocabulaire de son choix. En effet, certaines fonctions WLangage ou propriétés ont été renommées pour utiliser les termes du vocabulaire choisi. Quelques exemples :

| [EcranVersFichier](3044146.md) | FenêtreVersTable |
| --- | --- |
| [FichierVersEcran](3044210.md) | TableVersFenêtre |
| [ConstruitTableFichier](3074002.md) | TableConstruitDataBinding |
| [HOuvreAnalyse](3044106.md) | HOuvreSchémaDesDonnées |
| [HListeFichier](3044045.md) | HListeTable |
| [ChangeGabarit](3013026.md) | ChangeThème |

## Mise en place : sélectionner le vocabulaire à utiliser

### Choix du vocabulaire
Le choix du vocabulaire est effectué dans les options de WINDEV, WEBDEV, WINDEV Mobile :

1. Dans le ruban, sous le volet "Accueil", dans le groupe "Environnement", déroulez "Options générales de xxx".
2. Dans l'onglet "Général", sélectionnez le vocabulaire voulu :
3. Validez

Au prochain lancement, le vocabulaire choisi sera automatiquement utilisé pour l'interface du produit.

### Norme de programmation
Il est possible de mettre en place une norme de programmation concernant l'utilisation du vocabulaire. Dans ce cas, toutes les lignes de code ne correspondant pas au vocabulaire en cours sous l'éditeur seront signalées.
En effet, certaines fonctions WLangage n'ont pas le même nom selon le vocabulaire utilisé.

Pour activer les erreurs de norme de programmation depuis la description du projet :

1. Affichez la fenêtre de description du projet (sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description").
2. Dans l'onglet "Compilation", dans la section "Norme de programmation", cochez l'option "Signaler les mélanges de vocabulaire".
3. Validez. Le projet est recompilé.
4. Si nécessaire, les erreurs de norme de programmation "Mélange de vocabulaire" sont affichées dans le volet des erreurs de compilation. Un double-clic sur l'erreur permet d'afficher la ligne de code posant problème.

### Conversion du code
Pour utiliser le code WLangage correspondant à la norme choisie, il est possible de convertir automatiquement le code.
Pour changer le vocabulaire utilisé dans le code :

1. Affichez sous l'éditeur de code le code voulu.
2. Sous le volet "Code", dans le groupe "Langues", sélectionnez la langue à utiliser :
  - Si le vocabulaire en cours est "historique", la conversion en Français ou Anglais convertira en utilisant le vocabulaire historique.
  - Si le vocabulaire en cours est "générique", la conversion en Français ou Anglais convertira en utilisant le vocabulaire générique.
  - L'option "Convertir tout le projet en xxx" permet de convertir automatiquement tout le code WLangage du projet et de ses éléments dans une version de vocabulaire.
