# MultitâcheRepeint (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Re-dessine immédiatement les champs de la fenêtre nécessitant une mise à jour graphique.
**Remarque** : Cette fonction est identique à la fonction [FenRepeint](3038006.md).

> _(WEBDEV - Code Serveur, Windows, Linux)_ Cette fonction est disponible uniquement pour simplifier la Webisation de projets WINDEV/WINDEV Mobile. Dans un site WEBDEV, cette fonction n'a aucun effet.

## Exemple

```wlangage
i est un entier
POUR i = 1 À 1000
	TraitementLong()
	MultitâcheRepeint()
FIN
```

## Syntaxe

```wlangage
MultitâcheRepeint([<Fenêtre ou page>])
```

`<Fenêtre ou page>` *Nom de fenêtre ou nom de page*
> Nom de la fenêtre à re-dessiner. Si ce paramètre n'est pas précisé, la fenêtre en cours est re-dessinée.
> > _(WEBDEV - Code Serveur)_ Ce paramètre correspond à un nom de page. Cette fonction n'a aucun effet.

## Remarques

Contrairement à la fonction [Multitâche](3015004.md), l'appel de la fonction **MultitâcheRepeint** n'interrompt pas le code en cours (les fonctions [Timer](3015008.md) ne sont pas appelées par exemple).

**Composante : wd300obj.dll**
