# WDSQL : Structure d'une base de données

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows)

## Présentation

WDSQL permet de connaître la structure complète de la base de données accédée.
Pour afficher la structure de la base de données, cliquez sur l'icône [image: Icône Analyse].

Cette fonctionnalité est disponible :

- sur les bases de données Oracle ou SQL Server,
- sur les autres types de bases de données.

## Structure d'une base de données Oracle ou SQL Server

Si la base de données en cours est une base de données Oracle ou SQL Server, lors d'un clic sur l'icône [image: Icône Analyse], la fenêtre suivante s'affiche :
Les informations affichées sont réparties dans différents onglets.
**Remarque** : Les informations affichées concernent tous les utilisateurs de la base de données (et non uniquement l'utilisateur connecté).

| Onglet | Contenu |
| --- | --- |
| Tables | Liste des tables de la base de données créées par l'utilisateur sélectionné (dans la combo "Utilisateur"). Pour chaque table, les informations suivantes sont affichées :  - Le nom des colonnes. - Le type HFSQL des colonnes. Ce type correspond au type utilisé sous WINDEV. - Le type Oracle des colonnes. Ce type correspond au type des colonnes sous Oracle. - La taille des colonnes. |
| Vues | Liste des vues de la base de données créées par l'utilisateur sélectionné (dans la combo "Utilisateur"). Pour chaque vue, les informations suivantes sont affichées :  - Le nom des colonnes. - Le type HFSQL des colonnes. Ce type correspond au type utilisé sous WINDEV. - Le type Oracle des colonnes. Ce type correspond au type des colonnes sous Oracle. - La taille des colonnes. |
| Synonymes | Liste des synonymes de la base de données visibles par l'utilisateur sélectionné (dans la combo "Utilisateur"). Pour chaque synonyme, les informations suivantes sont affichées :  - La visibilité du synonyme. - Le nom du propriétaire du synonyme. - Le nom du synonyme. - Le nom d'origine de l'objet. - La base de données distante à laquelle l'objet appartient (si nécessaire). |
| Index | Liste des index de la base de données créés par l'utilisateur sélectionné (dans la combo "Utilisateur"). Lors de la sélection d'un index, le nom de la (ou des) colonne(s) associée(s) à cet index s'affiche. |
| Procédures | Liste des procédures stockées, des fonctions et des packages de la base de données créés par l'utilisateur sélectionné (dans la combo "Utilisateur"). L'icône précédant le nom d'une procédure indique que la procédure contient au moins une erreur de compilation. Il est possible de créer, de modifier ou de supprimer une procédure stockée, une fonction ou un package. Pour créer une procédure stockée (une fonction ou un package), il suffit de préciser :  - Le nom de la procédure stockée (de la fonction ou du package). - Le code de la procédure stockée (de la fonction ou du package).  La procédure stockée (la fonction ou le package) est automatiquement créée dans la base de données et compilée. La liste des erreurs détectées à la compilation est affichée si nécessaire. Exemple d'utilisation d'une procédure : la syntaxe suivante permet d'afficher le résultat d'une fonction :   ```wlangage SELECT <NomFonction>(<Paramètres>) from dual ``` |
| Liens (uniquement pour les bases de données Oracle) | Liste des différentes bases de données distantes accessibles depuis la base de données. Pour chaque base de données, les informations suivantes sont affichées :  - Le nom du propriétaire de la base de données distante. - Le nom du lien à utiliser pour accéder à la base de données distante. - La chaîne de connexion utilisé par Oracle pour accéder à la base de données distante. - La visibilité de la base de données distante.  Exemple : la syntaxe suivante permet de sélectionner les données présentes dans une table d'une base de données distante :   ```wlangage SELECT * from <NomTable>@<NomDuLlien ``` |
| Utilisateurs | Liste des utilisateurs définis sur la base de données. Pour chaque utilisateur, la date et l'heure de création de cet utilisateur sont affichées. |

## Structure d'une base de données différentes de Oracle et SQL Server

Si la base de données en cours n'est pas une base de données Oracle ou SQL Server, lors d'un clic sur l'icône [image: Icône Analyse], la fenêtre suivante s'affiche :

Les informations affichées sont réparties dans différents onglets.

| Onglet | Contenu |
| --- | --- |
| Tables | Liste des tables de la base de données. Pour chaque table, les informations suivantes sont affichées :  - le nom des colonnes, - le type des colonnes, - la taille des colonnes. |
| Vues | Liste des vues de la base de données. Pour chaque vue, les informations suivantes sont affichées :  - le nom des colonnes, - le type des colonnes, - la taille des colonnes. |
