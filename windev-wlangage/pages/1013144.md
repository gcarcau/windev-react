# Manipuler un champ de saisie par programmation

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Il est possible de manipuler un champ de saisie directement par programmation. Il suffit d'utiliser directement la variable du champ de saisie dans le code.
La variable du champ de saisie correspond au nom du champ de saisie. Le type de la variable dépend du type du champ de saisie (numérique, texte, monétaire, etc.).

> _(WINDEV)_ Cas particulier : Manipuler un champ de saisie de type RTF par programmation

## Afficher une information dans un champ de saisie

Pour afficher une information dans un champ de saisie, une simple affectation suffit.
Quelques exemples :

- affectation directe :
  ```wlangage
  SAI_NomClient = "Dupont"
  ```
- affectation par variable :
  ```wlangage
  SAI_NOM = Nom_Client
  ```
- affectation par calcul :
  ```wlangage
  SAI_NOM = SansEspace(CLIENT.NOM) + TAB + SansEspace(CLIENT.PRENOM)
  ```

**Remarque** : Si le champ est associé à une rubrique d'un fichier de données, l'affectation est automatiquement réalisée en utilisant :

- la fonction [FichierVersEcran](3044210.md).
- la fonction [FichierVersPage](3044148.md).

Il est aussi possible d'utiliser la notation NomClient = CLIENT.NOM. Pour plus de détails, consultez [Lier un champ de saisie à une rubrique](1013159.md).

## Récupérer la valeur saisie dans un champ de saisie

Pour récupérer le contenu d'un champ de saisie :

- réalisez une simple affectation.
  Par exemple :
  ```wlangage
  ContenuActuelSaisie = SAI_SAISIE1
  ```
- récupérez une partie de l'information.
  Par exemple :
  ```wlangage
  Initiale = Gauche(SAI_Nom, 1)
  Initiale = SAI_Nom[[1]]
  ```
- utilisez la propriété [Valeur](2510130.md)

**Remarque** : Si le champ est associé à une rubrique d'un fichier de données, la récupération de la valeur saisie est automatiquement réalisée en utilisant :

- la fonction [EcranVersFichier](3044146.md).
- la fonction [PageVersFichier](3044022.md).

Il est aussi possible d'utiliser la notation CLIENT.NOM = Saisie1. Pour plus de détails, consultez [Lier un champ de saisie à une rubrique](1013159.md).
