# DnDImpose (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

|  | But Indiquer l'action exécutée par la source (glisser/déplacer). Syntaxe DnDImpose (<Action>) <Action est un entier qui peut prendre pour valeur :   - *dndCopier* (les données seront copiées). - *dndDéplacer* (les données seront déplacées). - *dndDéfaut* (les données seront déplacées ou copiées selon les manipulations).   Détail **DnDImpose** indique si le champ source permet :  - aucune action - de déplacer les données (les données sont coupées de la source) - de copier les données (les données sont copiées, elles restent dans la source)   Notes **DnDImpose** permet de forcer la copie ou le déplacer des données du champ source.  **DnDAccepte** indique l'action acceptée dans la cible.  Les variables suivantes peuvent être utilisées :  - **_DND.Action** pour connaître l'action du glisser/déplacer - **_DND.ChampCible** pour connaître le nom du champ cible - **_DND.ChampSource** pour connaître le nom du champ source dans la fenêtre - **_DND.CtrlEnfoncé** pour connaître l'état de la touche contrôle Ctrl - **_DND.FenSource** pour connaître le nom de la fenêtre source - **_DND.SourisPosX** pour connaître l'abscisse de la souris lors de l'événement - **_DND.SourisPosY** pour connaître l'ordonnée de la souris lors de l'événement |
