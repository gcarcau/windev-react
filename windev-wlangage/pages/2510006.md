# Animation (Propriété)

> **Disponible :** **WINDEV** (Windows, Java) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Animation** permet de gérer l'animation d'une image ou d'un texte (présent dans un champ Libellé).
Il est possible de :

- Connaître l'état actuel de l'image animée ou du texte animé.
- Lancer ou arrêter l'animation d'une image ou d'un texte (par exemple, l'animation d'une image de type GIF animée).

Cette propriété s'applique aux champs suivants :

- Champs Image,
- Champs Bouton,
- Champs Libellé,
- Champs Carrousel,
- Champs Jauge.

> _(WINDEV)_ La propriété Animation permet également l'animation d'un texte dans un champ Libellé.

Nouveauté 2025

> _(Android, iPhone/iPad, Mac Catalyst)_ Il est désormais possible de gérer l'animation d'un texte présent dans un champ Libellé.

## Exemple

> _(Windows, Android, iPhone/iPad, Widget IOS)_ // Initialisation du champ Image avec Flèche.GIF (GIF animé)
IMG_Image1 = "C:\Temp\Flèche.gif"
// Lancement de l'animation
IMG_Image1.Animation = Vrai

> _(Windows, Android, iPhone/iPad, Java)_ // Initialisation du champ Libellé avec le texte "WINDEV est formidable"
LIB_Libellé1 = "WINDEV est formidable"
// Lancement de l'animation
LIB_Libellé1.Animation = Vrai

## Syntaxe

#### Connaître l'état actuel de l'image animée ou du texte animé

```wlangage
<Etat> = <Champ manipulé>.Animation
```

`<Etat>` *Booléen*
> - Vrai si l'image ou le texte actuellement présent dans le champ est animé,
> - Faux dans le cas contraire.
`<Champ manipulé>` *Nom de champ*
> Nom du champ manipulé :
>
> - Champ Image,
> - Champ Libellé.

#### Lancer ou arrêter l'animation

```wlangage
<Champ manipulé>.Animation = <Mode d'animation>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ manipulé :
>
> - Champ Image,
> - Champ Libellé.
`<Mode d'animation>` *Booléen*
> - Vrai pour lancer l'animation,
> - Faux pour arrêter l'animation.

## Remarques

> _(Windows)_ Animation d'une imagePour animer l'image affichée dans le champ Image, cette image peut être :soit une image de type animé (par exemple, Gif animé).soit une image animée par WINDEV. Dans ce cas, le type de l'animation peut être choisi soit dans la fenêtre de description de l'image (onglet "Détail"), soit par programmation avec la fonction AnimationChangeType.Dans un champ Bouton, seule une image de type animée peut être associée au champ (par exemple Gif Animé).

> _(Windows, Android, iPhone/iPad, Java)_ Animation d'un textePour animer un texte dans un champ Libellé, il est nécessaire de choisir l'animation effectuée :soit dans la fenêtre de description du champ Libellé (onglet "Détail"),soit par programmation avec la fonction AnimationChangeType.

> _(Windows)_ Animation d'une jaugeDans une jauge, l'animation se fait lors d'une variation importante de la valeur de la jauge : au lieu de se positionner immédiatement sur la nouvelle valeur, la jauge est incrémentée (ou décrémentée) progressivement pour obtenir un effet d'animation.Remarque : cet effet est particulièrement adapté pour les jauges circulaires.

### Divers
Par défaut, l'animation est à Vrai.
