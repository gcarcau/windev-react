# Langue (Propriété)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **Langue** permet de connaître et de modifier la langue utilisée. Cette propriété est utilisable sur :

- les rubriques des fichiers de données pour gérer la langue utilisée pour les comparaisons et le tri. Pour plus de détails, consultez [Propriété Langue sur les rubriques](1000017053.md).
- une variable de type [gglParamètreCarte](1000017505.md).
- une variable de type [nfcDonnée](1000020406.md).
- une variable de type [rssCanal](1000017769.md).
- une variable de type [sfInfoUtilisateur](1000018423.md).
- une variable de type [VoixDeSynthèse](1000025986.md).
- une variable de type [CodeWLangageMiseEnForme](1410090146.md).
