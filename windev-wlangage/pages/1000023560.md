# Chrono (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Le type **Chrono** permet de définir toutes les caractéristiques avancées d'un chronomètre. Les caractéristiques de ce chronomètre peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Ce type de variable est désormais disponible en code navigateur.

## Exemple

```wlangage
c est un Chrono
ChronoDébut(c)
...
// Code à chronométrer
...
ChronoFin(c)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type Chrono
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **Chrono** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Démarré | Booléen | - Vrai si le chronomètre est démarré, - Faux dans le cas contraire.   **Cette propriété est disponible en lecture seulement**. |
| Valeur | Durée | Durée chronométrée.  Remarque : Cette propriété correspond au résultat de la fonction [ChronoValeur](3027033.md).   **Cette propriété est disponible en lecture seulement**. |

## Remarques

### Fonctions WLangage manipulant le type Chrono

- Les fonctions manipulant le type **Chrono** sont les suivantes :
  | [ChronoDébut](3027031.md) | Démarre un chronomètre afin de mesurer la durée d'un traitement (en millisecondes) et permet de remettre à zéro un chronomètre existant. |
  | --- | --- |
  | [ChronoFin](3027032.md) | Arrête un chronomètre et renvoie le temps écoulé (en millisecondes) depuis le début du chronométrage (appel de la fonction [ChronoDébut](3027031.md)). |
  | [ChronoPause](1000018829.md) | Interrompt un chronomètre afin de mesurer la durée d'un traitement. |
  | [ChronoRAZ](1000020474.md) | Arrête et remet un chronomètre existant à zéro. |
  | [ChronoReprend](1000018830.md) | Redémarre un chronomètre précédemment arrêté par les fonctions [ChronoFin](3027032.md) ou [ChronoPause](1000018829.md). |
  | [ChronoValeur](3027033.md) | Indique le temps écoulé (en millisecondes) depuis l'appel à la fonction [ChronoDébut](3027031.md). |
- Les fonctions (syntaxe préfixée) manipulant le type **Chrono** sont les suivantes :
  | [<Chrono>.Début](1000023788.md) | Démarre un chronomètre afin de mesurer la durée d'un traitement (en millisecondes) et permet de remettre à zéro un chronomètre existant. |
  | --- | --- |
  | [<Chrono>.Fin](1000023789.md) | Arrête un chronomètre et renvoie le temps écoulé (en millisecondes) depuis le début du chronométrage (appel de la fonction [<Chrono>.Début](1000023788.md)). |
  | [<Chrono>.Pause](1000023790.md) | Interrompt un chronomètre afin de mesurer la durée d'un traitement. |
  | [<Chrono>.RAZ](1000023791.md) | Arrête et remet un chronomètre existant à zéro. |
  | [<Chrono>.Reprend](1000023792.md) | Redémarre un chronomètre précédemment arrêté par les fonctions [<Chrono>.Fin](1000023789.md) ou [<Chrono>.Pause](1000023790.md). |
