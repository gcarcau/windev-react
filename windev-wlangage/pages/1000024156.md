# <Graphe>.TypeSérie (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

Fixe le type d'une série utilisée dans un graphe composite (graphe composé de plusieurs graphes de types différents).

## Exemple

```wlangage
GRF_MonGraphe.TypeSérie(1, grCourbe)
GRF_MonGraphe.TypeSérie(2, grNuage)
GRF_MonGraphe.TypeSérie(3, grHisto)
```

## Syntaxe

```wlangage
<Champ Graphe>.TypeSérie(<Numéro de la série> , <Type> [, <Paramètre>])
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres ou d'états).
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Numéro de la série>` *Entier*
> Numéro de la série pour laquelle le type de graphe doit être modifié.
`<Type>` *Constante de type Entier*
> Type de graphe à utiliser pour représenter les données de la série :
>
>
> | *grAire* | Graphe de type Aire. |
> | --- | --- |
> | *grAirePolaire* | Graphe de type Aire Polaire. |
> | *grBarCharts* | Graphe de type Boursier. |
> | *grChandelier* | Graphe boursier de type Chandelier Japonais. |
> | *grCourbe* | Graphe de type Courbe. |
> | *grCourbeRégressionQuadratique* | Graphe de type Courbe de la forme "ax2 + bx + c". La courbure est déterminée en réalisant une régression quadratique sur la série spécifiée dans <Paramètre>. |
> | *grDroiteConstante* | Affiche une droite horizontale à la position indiquée dans <Paramètre>. |
> | *grDroiteMoyenne* | Affiche une droite horizontale à la moyenne de la série indiquée dans <Paramètre>. |
> | *grDroiteRégressionLinéaire* | Affiche une droite dont la pente est calculée en faisant une régression linéaire sur la série spécifiée dans <Paramètre>. |
> | *grGrapheBulle* | Graphe de type Graphe à bulle. |
> | *grHisto* | Graphe de type Histogramme. |
> | *grHistoEmpilé* | Graphe de type Histogramme empilé. |
> | *grMinMax* | Graphe boursier affichant la différence entre la valeur minimale et la valeur maximale du cours. |
> | *grNuage* | Graphe de type Nuage de points.  Nouveauté Abonnement _(Android)_ Cette constante est désormais disponible pour les applications Android. **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md). |
> | *grWaffle* | Graphe de type Waffle. |
> | *grWaterfall* | Graphe de type Waterfall. |
> | *grZoneIntervalle* | Graphe de type Zone d'intervalle. |
`<Paramètre>` *Constante de type Entier*
> Paramètre nécessaire pour certains types de graphe. Si <Type> correspond à :
>
> - *grCourbeRégressionQuadratique* : <Paramètre> correspond au numéro de la série utilisée pour faire la régression quadratique.
> - *grDroiteConstante* : <Paramètre> correspond à la position d'affichage de la droite horizontale.
> - *grDroiteMoyenne* : <Paramètre> correspond au numéro de la série utilisée pour calculer la moyenne.
> - *grDroiteRégréssionLinéaire* : <Paramètre> correspond au numéro de la série utilisée pour faire la régression linéaire.
>   Attention : La régression linéaire fonctionne uniquement avec une seule série.

## Remarques

La fonction [<Graphe>.Type](1000024168.md) annule tous les types de série spécifiques fixés par la fonction **<Graphe>.TypeSérie** : toutes les séries auront le même type.
