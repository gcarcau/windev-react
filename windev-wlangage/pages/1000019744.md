# Propriétés associées au champ Notation

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Le champ Notation peut être utilisé aussi bien dans une fenêtre que dans une page. Cette page d'aide présente les différentes propriétés disponibles sur ce type de champ.
