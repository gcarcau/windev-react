# <Variable Diagramme>.Sauve (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Sauve un diagramme dans un fichier "diag".

## Exemple

```wlangage
MonDiagramme est un Diagramme
MonDiagramme.Sauve("diagramme1.wddiag")
SI ErreurDétectée ALORS
	Erreur("Fichier non sauvegardé : " + ErreurInfo())
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Diagramme>.Sauve(<Fichier>)
```

`<Résultat>` *Booléen*
> - Vrai si la sauvegarde a été effectuée,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de détails sur l'erreur.
`<Diagramme>` *Variable de type Diagramme*
> Nom de la variable de type [Diagramme](1410088055.md) à manipuler.
`<Fichier>` *Chaîne de caractères*
> Chemin complet du fichier "diag".

**Classification Métier / UI : Code neutre**

**Composante : wd300mdl.dll**
