# Fonctions FTP Standard (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Les fonctions permettant la gestion du FTP (syntaxe préfixée) sont les suivantes :

| [<Variable ftpConnexion>.Attribut](1410091117.md) | Identifie les attributs d'un fichier présent sur un serveur FTP (File Transfer Protocol). **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 1.** |
| --- | --- |
| [<Variable ftpConnexion>.Commande](1410091118.md) | Envoie une commande FTP spécifique à un serveur. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [<Variable ftpConnexion>.Connecte](1410091119.md) | Connecte le poste en cours à un serveur FTP (File Transfer Protocol). **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [<Variable ftpConnexion>.Date](1410091120.md) | Renvoie les différentes dates (date de création, de modification ou d'accès) d'un fichier présent sur un serveur FTP (File Transfer Protocol). **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [<Variable ftpConnexion>.DateHeure](1410091121.md) | Renvoie les différentes dates et heures (de création, de modification ou d'accès) d'un fichier présent sur un serveur FTP (File Transfer Protocol). **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [<Variable ftpConnexion>.Déconnecte](1410091122.md) | Ferme la connexion entre le poste en cours et le serveur FTP (File Transfer Protocol). **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [<Variable ftpConnexion>.Envoie](1410091123.md) | Transfère un fichier ou un répertoire sur un serveur FTP (File Transfer Protocol). **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [<Variable ftpConnexion>.FichierExiste](1410091124.md) | Teste l'existence d'un fichier sur un serveur FTP. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [<Variable ftpConnexion>.Heure](1410091125.md) | Renvoie les différentes heures (heure de création, de modification ou d'accès) d'un fichier présent sur un serveur FTP (File Transfer Protocol). **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [<Variable ftpConnexion>.ListeFichier](1410091126.md) | Liste les fichiers d'un répertoire (et/ou les répertoires) d'un serveur FTP et retourne le nombre de fichiers (et/ou de répertoires) listés. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [<Variable ftpConnexion>.Nom](1410091137.md) | Renvoie le nom du dernier fichier accédé par une fonction FTP (File Transfer Protocol). **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [<Variable ftpConnexion>.Récupère](1410091127.md) | Transfère un fichier ou un répertoire d'un serveur FTP (File Transfer Protocol) sur le poste en cours. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [<Variable ftpConnexion>.RécupèreFichier](1410091128.md) | Transfère un fichier d'un serveur FTP (File Transfer Protocol) sur le poste en cours. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [<Variable ftpConnexion>.RenommeFichier](1410091129.md) | Renomme ou déplace un fichier présent sur un serveur FTP (File Transfer Protocol). **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [<Variable ftpConnexion>.RepCrée](1410091130.md) | Crée un répertoire sur un serveur FTP (File Transfer Protocol). **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [<Variable ftpConnexion>.RepEnCours](1410091131.md) | Identifie ou modifie le répertoire en cours sur un serveur FTP (File Transfer Protocol). **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [<Variable ftpConnexion>.RepExiste](1410091282.md) | Permet de savoir si un répertoire existe sur un serveur FTP (File Transfer Protocol). **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.** |
| [<Variable ftpConnexion>.RepSupprime](1410091132.md) | Supprime un répertoire et son contenu (fichiers et sous-répertoires) d'un serveur FTP (File Transfer Protocol). **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [<Variable ftpConnexion>.SupprimeFichier](1410091133.md) | Supprime un fichier d'un serveur FTP (File Transfer Protocol). **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [<Variable ftpConnexion>.Taille](1410091134.md) | Renvoie la taille (en octets) d'un fichier présent sur un serveur FTP (File Transfer Protocol). **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
