# <Variable Connexion>.FichierExiste (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Permet de savoir si un fichier de données existe, c'est-à-dire s'il a été créé physiquement (fonctions [<Source>.Création](1000024207.md) ou [<Source>.CréationSiInexistant](1000024208.md)).
Remarque : Les substitutions en cours sur le fichier de données (effectuées avec les fonctions [HSubstRep](3044028.md), [<Source>.ChangeRep](1000024202.md) et [<Source>.ChangeNom](1000024201.md)) sont prises en compte.

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion

// Test de l'existence d'un fichier de données Client/Serveur
SI MaConnexion.FichierExiste("MonFichier.FIC") = Vrai ALORS
	// Traitements
	...
FIN
```

#### Tester l'existence d'un fichier de données en HFSQL Client/Serveur

```wlangage
<Résultat> = <Connexion>.FichierExiste(<Fichier physique>)
```

`<Résultat>` *Booléen*
> - Vrai si le fichier de données physique existe sur le serveur,
> - Faux dans le cas contraire.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion associée au fichier de données.
`<Fichier physique>` *Chaîne de caractères*
> Nom physique du fichier de données recherché. L'extension du fichier doit être précisée (par exemple "Client.fic").

## Remarques

- La fonction **<Variable Connexion>.FichierExiste** est utilisable que le fichier de données soit ouvert ou non.
- La fonction **<Variable Connexion>.FichierExiste** n'ouvre pas le fichier de données si celui-ci est fermé.

**Composante : wd300hf.dll**
