# Téléphone (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android)

La propriété **Téléphone** permet de connaître et de modifier le numéro de téléphone. Cette propriété est utilisable sur :

- une variable de type [gglContact](1000017434.md).
- une variable de type [Contact](1000020254.md).
- une variable de type [gpwUtilisateur](1000021088.md).
- une variable de type [adminWBCompte](1410089382.md).
