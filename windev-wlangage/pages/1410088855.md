# ActionAutorisée (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **ActionAutorisée** permet de définir les actions autorisées ou non sur un élément. Cette propriété est utilisable sur :

- une variable de type [diagForme](1410088082.md).
- une variable de type [diagChemin](1410088384.md),
- une variable de type [diagGroupe](1410088127.md),
- une variable de type [diagImage](1410088414.md),
- une variable de type [diagLien](1410088454.md),
- une variable de type [diagOvale](1410088135.md),
- une variable de type [diagPolygone](1410088137.md),
- une variable de type [diagRectangle](1410088083.md),
- une variable de type [kbCarte](1410089167.md).
- une variable de type [VisiteGuidée](1410090170.md).
- une variable de type [VisiteGuidéeEtape](1410090178.md).
