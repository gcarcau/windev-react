# ThreadArrêtDemandé (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Vérifie si une demande d'arrêt a été envoyée au thread en cours d'exécution.

## Exemple

```wlangage
// Si une demande d'arrêt a été envoyée au thread
SI ThreadArrêtDemandé() ALORS
	// Libérer les ressources du thread
	...
	// Terminer le thread
	ThreadFin()
FIN
```

## Syntaxe

```wlangage
<Résultat> = ThreadArrêtDemandé()
```

`<Résultat>` *Booléen*
> - Vrai si une demande d'arrêt a été envoyée au thread en cours d'exécution,
> - Faux dans le cas contraire.

## Remarques

- L'arrêt d'un thread est demandé par un autre thread grâce à la fonction [ThreadDemandeArrêt](1000021218.md).
- Le code du thread courant doit vérifier régulièrement (boucles, ... ) si un arrêt a été demandé et il doit se terminer proprement le cas échéant.
- Lorsque le code d'un thread est sur une fonction d'attente (par exemple les fonctions [ThreadPause](3077029.md), [ThreadAttendSignal](3077022.md) ou [SignalAttend](3077007.md)), l'attente est automatiquement terminée lorsqu'une demande d'arrêt du thread est effectuée par un autre thread.

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
