# PoliceTaille (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **PoliceTaille** permet de :

- Connaître la taille de la police utilisée dans un champ.
- Modifier la taille de la police utilisée dans un champ.

## Exemple

```wlangage
// Modifier la taille de la police utilisée dans le champ "SAI_NomClient"
SAI_NomClient.PoliceTaille = 16
```

## Syntaxe

#### Connaître la taille de la police utilisée dans un champ

```wlangage
<Résultat> = <Champ manipulé>.PoliceTaille
```

`<Résultat>` *Entier*
> Taille de la police utilisée dans l'objet spécifié.
>
> > _(WEBDEV - Code Navigateur)_ Ce paramètre correspond à une chaîne de caractères.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.

#### Modifier la taille de la police utilisée dans un champ

```wlangage
<Champ manipulé>.PoliceTaille = <Taille de la police>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.
`<Taille de la police>` *Entier*
> Nouvelle taille de la police utilisée dans le champ spécifié.
>
> > _(WEBDEV - Code Navigateur)_ Ce paramètre correspond à une chaîne de caractères.

## Remarques

### Limites

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad)_ Dans un état, la propriété PoliceTaille peut être utilisée uniquement sur :un champ Libellé.un champ Calculé.un champ Prédéfini.un champ Lien.

> _(WINDEV, iPhone/iPad, Java)_ Dans une fenêtre, la propriété PoliceTaille ne peut pas être utilisée sur :un champ Spin,un champ Web Camera,un champ Conférence.Remarque : Cette propriété s'applique sur les champs "Liste image" en mode d'affichage "Liste classique" uniquement.
 La propriété PoliceTaille ne peut pas être utilisée sur les colonnes de table. La propriété PoliceTaille s'applique uniquement aux éléments suivants :Bouton,Libellé,Combo,Arbre,Colonne de table.

> _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur, PHP)_ Dans une page, la propriété PoliceTaille s'applique uniquement aux éléments suivants :Champ de saisie,Libellé,Bouton,Interrupteur/sélecteur,Liste, combo,Table,Champ d'affichage formaté,Champ HTML,Lien,Libellé HTML,Colonne de table (non disponible en code navigateur),Cellule de table (disponible en lecture seulement et non disponible en code navigateur),Réglette (non disponible en code navigateur),Chemin de navigation (non disponible en code navigateur et en PHP),Groupe de champs (non disponible en code navigateur).
