# HeureSélecteur (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android)

Affiche le sélecteur d'heure du système.
[image: Sélecteur Heure]

**Remarque** : Pour sélectionner une heure à l'aide du rouleau, il est conseillé d'utiliser directement le **masque de saisie de type "Rouleau Heure"**pour le champ de saisie de type "Heure". Ce masque de saisie est également disponible pour les applications iPhone/iPad.

## Exemple

```wlangage
h est une Heure = HeureSélecteur()
```

```wlangage
HeureDébut est une Heure = "0730"
HeureSélectionnée est une Heure = HeureSélecteur(HeureDébut, Vrai, "Saisissez l'heure d'arrivée")
```

## Syntaxe

```wlangage
<Résultat> = HeureSélecteur([<Heure initiale> [, <Mode 24 heures> [, <Titre>]]])
```

`<Résultat>` *Heure ou chaîne de caractères*
> - Heure sélectionnée dans le sélecteur,
> - Chaîne vide ("") si la sélection a été annulée par l'utilisateur.
`<Heure initiale>` *Heure ou chaîne de caractères optionnelle*
> Heure affichée à l'ouverture du sélecteur. Si cette heure n'est pas spécifiée, le sélecteur affichera l'heure courante.
`<Mode 24 heures>` *Booléen optionnel*
> - Vrai (valeur par défaut) pour afficher l'heure au format 24 heures.
> - Faux pour afficher l'heure au format AM/PM.
`<Titre>` *Chaîne de caractères optionnelle*
> Titre à afficher dans le sélecteur. Si ce paramètre n'est pas spécifié, le titre affiché sera une représentation textuelle de l'heure affichée par le sélecteur.

## Remarques

> _(Android, Widget Android)_ Application en arrière-plan : Spécificité à partir de Android 10A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. La fonction HeureSélecteur peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. Conseils : Il est possible de savoir si l'application est en arrière-plan grâce à la fonction EnModeArrièrePlan. Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type Notification). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété ActiveApplication est à Vrai. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété ActionClic.Pour plus de détails, consultez Android 10 : Comportement des applications en arrière-plan.
