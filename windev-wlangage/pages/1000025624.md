# Polygone (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Le type **Polygone** permet de définir les différents points d'un polygone. Ces points sont ordonnés et reliés selon l'ordre défini.
Les caractéristiques de ce polygone peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
polTriangle est un Polygone
oPoint est Point
oPoint.X = 460
oPoint.Y = 10
Ajoute(polTriangle.Point, oPoint)
oPoint.X = 500
oPoint.Y = 80
Ajoute(polTriangle.Point, oPoint)
oPoint.X = 420
oPoint.Y = 80
Ajoute(polTriangle.Point, [oPoint.X, oPoint.Y])
dPolygone(polTriangle, BleuPastel, VertClair)

polRectangle est un Polygone
polRectangle.Point = [[420,90], [500,90], [500,150], [420,150]]
dPolygone(polRectangle, MarronFoncé)
```

## Remarques

### Propriétés spécifiques à la description des variables de type Polygone
Les propriétés suivantes peuvent être utilisées pour manipuler un polygone :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Point | Tableau de variables de type [Point](1000018908.md) | Points du polygone. |

### Fonctions WLangage manipulant le type Polygone

| [dPolygone](3029006.md) | Dessine un polygone :   - dans un champ Image, - dans une variable de type [Image](1000019650.md), - dans une variable de type [WDPic](1000023503.md) (sur le calque d'arrière-plan), - dans une variable de type [picCalque](1000024604.md). |
| --- | --- |
| [dPolyligne](1000023919.md) | Dessine une ligne composée de plusieurs segments. |
