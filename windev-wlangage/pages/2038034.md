# Administrateur du GDS : Options réservées aux administrateurs

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

L'administrateur du GDS (Gestionnaire de sources) propose certains outils spécifiques pour l'administration de la base de sources.
Les outils d'administration sont disponibles uniquement lors de la connexion à la base de sources du GDS en tant que Administrateur.

Pour se connecter à la base de sources du GDS en tant qu'administrateur :

1. Sous le volet "Accueil", dans le groupe "Base de sources", cliquez sur "Connexion ".
2. Dans la fenêtre qui s'ouvre :
  - Indiquez les caractéristiques de la base de sources utilisée.
  - Spécifiez le nom et le mot de passe de l'administrateur de la base de sources :
    - Si vous utilisez une base de sources GDS au format HFSQL Classic, par défaut l'administrateur est "Admin" (sans mot de passe).
    - Si vous utilisez une base de sources GDS au format HFSQL Client/Serveur, par défaut l'administrateur correspond à l'utilisateur de type "Administrateur".

**Remarque** : La connexion à la base de sources du GDS en tant qu'administrateur n'est pas la même chose que "Devenir maître sur le projet". Pour réaliser des manipulations d'administration, il est nécessaire de se connecter en tant qu'administrateur.

## Les options d'administration

### Paramétrage de l'authentification
Le paramétrage de l'authentification permet d'utiliser la base de données des Centres de Contrôle pour authentifier les utilisateurs du GDS. Le login et le mot de passe seront ceux spécifiés dans le Centre de Gestion de Projets.
Cette option est disponible uniquement si vous travaillez avec une base de sources du GDS au format HFSQL Classic.

Pour activer l'authentification :

1. Sous le volet "Administration", dans le groupe "Sécurité", cliquez sur "Paramétrer l'authentification".
2. Cochez l'option "Activer l'authentification".
3. Indiquez la base de données des Centres de Contrôle utilisée (au format HFSQL Classic).
4. Validez.

### Annuler les extractions
L'administrateur a la possibilité d'annuler toutes les extractions en cours sur le projet sélectionné : sous le volet "Administration", dans le groupe "Extractions", cliquez sur "Annuler des extractions".
Une fenêtre s'affiche listant tous les éléments extraits. Il est possible également de lister les éléments extraits pour tests ou les éléments extraits dans un répertoire distant différent.

Il suffit de sélectionner les éléments voulus et de cliquer sur le bouton "Annuler l'extraction". L'extraction est annulée. L'élément est présent dans la base de sources dans son état avec l'extraction.

Il est possible de prévenir les utilisateurs (option "Envoyer un message à ceux dont l'extraction a été annulée").

### Sauvegarde de la base de sources
L'administrateur a la possibilité de réaliser une sauvegarde de la base de sources du GDS : sous le volet "Administration", dans le groupe "Sauvegardes", cliquez sur "Sauvegarde complète". Cette sauvegarde est effectuée dans un fichier au format .ZIP. **Remarques** :

- Pendant la sauvegarde, la base de sources du GDS est accessible uniquement en lecture seule.
- Nouveauté Abonnement
  Un seul fichier zip est créé pour la sauvegarde.
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

La sauvegarde de la base de sources peut également être réalisée en ligne de commande grâce à la notation suivante :

```wlangage
WDGDSAdmin.exe /SAVE   /BASE=<Adresse de la base de sources>   /LOGIN=<Login>   /PASS=<Mot de passe>   /ZIP=<Nom complet du fichier zip>
```

Dans ce code, le paramètre <Adresse de la base de sources> est de la forme :

- Cas HFSQL Client/Serveur : "CS:\\<Adresse IP du serveur>:<Port serveur>\<Nom base de sources GDS>"
- Cas HFSQL Classic : le chemin local de la base doit être indiqué. Par exemple : "D:\PC SOFT\Base de sources GDS locale\"

Exemple :

```wlangage
LanceAppli("""C:\WinDev\Programs\WDGDSAdmin.exe"" /SAVE /BASE=CS:\\DOC2:4900\GDS" + ...
		" /LOGIN=admin /PASS=admin /ZIP=C:\Temp\test.zip")
```

### Sauvegarde et purge de l'historique
L'administrateur a la possibilité de supprimer une partie de l'historique de la base de sources du GDS : sous le volet "Administration", dans le groupe "Sauvegardes", cliquez sur "Purge de l'historique avec sauvegarde". La partie supprimée est automatiquement sauvegardée dans un fichier au format ZIP. Cette sauvegarde pourra être ensuite restaurée.
Pour effectuer la sauvegarde et la purge de l'historique, il suffit d'indiquer la date à partir de laquelle l'historique doit être conservé.

Nouveauté Abonnement
Remarque : Un seul fichier zip est créé pour la sauvegarde.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

### Restauration d'une sauvegarde complète
Pour restaurer une sauvegarde complète de la base de sources précédemment réalisée, sous le volet "Administration", dans le groupe "Sauvegardes", cliquez sur "Restauration complète".

### Restauration d'une sauvegarde d'historique
Pour restaurer une sauvegarde d'historique de la base de sources précédemment réalisée, sous le volet "Administration", dans le groupe "Sauvegardes", cliquez sur "Restauration d'historique".
