# EntêteBrut (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **EntêteBrut** permet de connaître l'entête qui a été retourné avec la réponse. Cette propriété est utilisable sur :

- une variable de type [httpRéponse](1000021165.md).
- une variable de type [restRéponse](1000021477.md).
