# Mode (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Mode** permet de gérer :

- le nombre de noeuds minimum devant avoir acquitté le traitement pour considérer l'écriture effectuée (variable de type [mongoOptionEcriture](1000022597.md)).
- le mode de gestion des sections multicolonnes (variable de type [docFormatMulticolonne](1000023580.md)).
- le mode d'affichage de la bulle d'une étape de la visite guidée. Dans ce cas, cette propriété est utilisable sur :
  - une variable de type [VisiteGuidée](1410090170.md).
  - une variable de type [VisiteGuidéeEtape](1410090178.md).
