# sfRésultatConvertitPiste (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Le type **sfRésultatConvertitPiste** permet de connaître le résultat de la fonction [SFConvertitPiste](1000018498.md). Les caractéristiques de ce résultat peuvent être connues à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Propriétés

### Propriétés spécifiques à la description des variables de type sfRésultatConvertitPiste
Les propriétés suivantes peuvent être utilisées pour manipuler le résultat de la fonction [SFConvertitPiste](1000018498.md) :

| Nom | Type manipulé | Effet |
| --- | --- | --- |
| Erreur | Tableau de [sfErreur](1000018455.md) | Compte-rendu d'erreurs. |
| IDCompte | Chaîne de caractères | Identifiant du compte créé ou modifié lors de la conversion. **Cette propriété est disponible en lecture seulement**. |
| IDContact | Chaîne de caractères | Identifiant du contact créé ou modifié lors de la conversion. **Cette propriété est disponible en lecture seulement**. |
| IDOpportunité | Chaîne de caractères | Identifiant de l'opportunité éventuellement créée lors de la conversion. **Cette propriété est disponible en lecture seulement**. |
| IDPiste | Chaîne de caractères | Identifiant de la piste convertie.  **Cette propriété est disponible en lecture seulement**. |
| Succès | Booléen | - Vrai si la conversion s'est correctement déroulée, - Faux en cas d'erreur.  **Cette propriété est disponible en lecture seulement**. |

## Remarques

### Fonctions manipulant le type sfRésultatConvertitPiste

| [SFConvertitPiste](1000018498.md) | Convertit des pistes, également appelées LEAD. |
