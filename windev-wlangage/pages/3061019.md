# GraveurNomVolume (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Permet de connaître ou de modifier le nom du CD ou DVD à graver.
**Remarque** : Il est nécessaire d'appeler cette fonction avant d'ajouter des fichiers dans la compilation (fonctions [GraveurAjouteFichier](3061001.md) ou [GraveurAjouteRépertoire](3061002.md)). Dans le cas contraire, le nom du CD ne sera pas pris en compte.

## Exemple

```wlangage
// Nom du CD
ResNom est un entier = GraveurNomVolume("Mon CD")
// Erreur rencontrée ?
SI ResNom = Faux ALORS
	// Affichage de l'erreur
	Erreur(ErreurInfo(errMessage))
SINON
	// Ajout de fichiers
	GraveurAjouteRépertoire("C:\MesMusiques\*.WAV")
	...
FIN
```

## Syntaxe

#### Connaître le nom du CD ou DVD à graver

```wlangage
<Résultat> = GraveurNomVolume()
```

`<Résultat>` *Chaîne de caractères*
> Nom du CD ou DVD à graver.

#### Modifier le nom du CD ou DVD à graver

```wlangage
<Résultat> = GraveurNomVolume(<Nom du CD ou DVD>)
```

`<Résultat>` *Entier*
> - Vrai si le nom du CD ou DVD a été pris en compte,
> - Faux dans le cas contraire.
`<Nom du CD ou DVD>` *Chaîne de caractères*
> Nom à donner au CD ou DVD à graver. C'est ce nom qui apparaît sous l'explorateur de fichiers pour identifier le CD ou le DVD.

## Remarques

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU))_ Présence d'un CD/DVD dans le graveurPour connaître le nom du volume dans le graveur, il est bien entendu nécessaire qu'un CD ou DVD soit présent dans le graveur. Pour modifier le nom du volume, il est nécessaire que le CD/DVD présent dans le graveur contienne assez de place pour graver une nouvelle session.

### Configuration nécessaire

> _(WINDEV, WEBDEV - Code Serveur)_ La gravure de CD est disponible uniquement sous Windows XP et supérieur. La gravure de DVD est disponible sous Windows Vista, et sous Windows XP en utilisant la mise à jour KB932716 pour Windows XP (cette mise à jour doit être téléchargée depuis le site de Microsoft et installée car elle n'est pas prise en compte par le mécanisme de Live Update). La gravure de CD et DVD sera réalisée sur le serveur Web. Pour graver des CD ou des DVD, le serveur doit être sous Windows XP ou supérieur. Pour graver des CD sous Windows 2003 Serveur, il est nécessaire d'activer le service de gravure IMAPI (nommée "Service COM de gravage de CD IMAPI"). Pour graver des DVD sous Windows 2003 Serveur, il est nécessaire d'installer en plus la mise à jour KB932716.

**Composante : wd300grv.dll**
