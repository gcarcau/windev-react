# Taille (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le mot-clé **Taille** peut correspondre à :

- La fonction [Taille](3024031.md) permet de connaître la taille d'une chaîne de caractères ou d'un buffer.
- La propriété **Taille** permet de connaître et de modifier la taille d'un élément. Cette propriété est utilisable sur :
  - les champs d'une fenêtre ou d'un état. Pour plus de détails, consultez l'aide de la propriété [Taille](2510125.md).
  - les rubriques de type Texte et Heure d'un fichier de données. Pour plus de détails, consultez l'aide de la propriété [Taille](3024031.md).
  - une variable de type [Police](1514045.md). Pour plus de détails, consultez l'aide de la propriété [Taille](2510125.md).
  - une variable de type [gglMarqueur](1000017442.md).
  - une variable de type [rssDocumentJoint](1000017789.md).
  - une variable de type [sfRésultatExécuteRequête](1000018558.md).
  - une variable de type [InfoVersion](1000018905.md).
  - une variable de type [zipArchive](1000018679.md).
  - une variable de type [zipFichierArchivé](1000019044.md).
  - une variable de type [Filigrane](1000019922.md).
  - une variable de type [hdfsInformation](1000021973.md).
  - une variable de type [mongoGridFSInfofichier](1000022417.md).
  - une variable de type [MarqueurImage](1000025796.md).
  - une variable de type [MotDePasseSécurisé](1000021064.md).
  - Nouveauté 2025
    une variable de type [FichierGgl](1410089586.md).
