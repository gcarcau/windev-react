# <Graphe>.SMNCouleurPortion (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP)

Change la couleur d'une portion d'un graphe de type Secteur multiniveau.

## Exemple

```wlangage
// Ajoute les données
GRF_Graphe.SMNAjouteDonnée("Europe" + TAB + "France" + TAB + "Montpellier", 320000)
GRF_Graphe.SMNAjouteDonnée("Europe" + TAB + "France" + TAB + "Paris", 789000)
GRF_Graphe.SMNAjouteDonnée("Europe" + TAB + "France", 1109000)
GRF_Graphe.SMNAjouteDonnée("Europe" + TAB + "Belgique", 900000)
GRF_Graphe.SMNAjouteDonnée("Asie", 250000)

// Personnalise les couleurs du graphe
GRF_Graphe.SMNCouleurPortion("Europe", RVB(106, 188, 227))
GRF_Graphe.SMNCouleurPortion("Asie", RVB(182, 115, 251))

GRF_Graphe.Dessine()
```

## Syntaxe

```wlangage
<Champ Graphe>.SMNCouleurPortion(<Chemin de la portion> , <Couleur>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres ou d'états).
>
> > _(WEBDEV - Code Serveur, PHP)_ Dans les pages, seuls les champs "Graphe interactif" sont disponibles pour les graphes de type Secteur multiniveau.
`<Chemin de la portion>` *Chaîne de caractères*
> Chemin complet de la portion à colorer dans le graphe. Ce paramètre est de la forme :
>
>
> ```wlangage
> "<Nom du niveau de base>" + TAB + ["<Nom du 1er niveau>" + TAB + ...["<Nom du dernier niveau>" + TAB + [...]]]"<Nom de la portion>"
> ```
`<Couleur>` *Entier ou constante de type Entier*
> Couleur de la portion spécifiée. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - une couleur prédéfinie (voir [les couleurs prédéfinies du WLangage](3010002.md)).

## Remarques

- Si une portion n'a pas une couleur spécifiée, une couleur lui est automatiquement attribuée. Il est ainsi possible d'obtenir un dégradé avec les portions de niveau supérieur si elles existent.
- La couleur peut être modifiée à tout moment avant le dessin du graphe.
