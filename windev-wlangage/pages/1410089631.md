# <Kanban>.SupprimeToutCarte (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Supprime toutes les cartes d'un champ Kanban ou d'un champ Liste de Kanban.

## Exemple

```wlangage
// Supprime toutes les cartes du champ Kanban
KANBAN_MonKanban.SupprimeToutCarte()
```

## Syntaxe

```wlangage
KanbanSupprimeToutCarte(<Champ manipulé>)
```

`<Champ manipulé>` *Nom de champ*
> Nom d'un champ Kanban.

**Classification Métier / UI : Code UI**

**Composante : wd300obj.dll**
