# Propriétés associées au champ Cellule

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Les champs Cellule peuvent être manipulés avec les propriétés WLangage :

- dans une fenêtre.
- dans une page en code Serveur, Navigateur ou PHP.
