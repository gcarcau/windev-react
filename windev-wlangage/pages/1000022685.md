# docSection (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Le type **docSection** permet de définir toutes les caractéristiques avancées d'une section d'un document ou d'un paragraphe.
Au niveau du document :

- le type **docSection** permet de connaître les informations générale du document.
- le type **docSection** permet de modifier toutes les informations de toutes les sections du document.

Au niveau du paragraphe :

- le type **docSection** permet de connaître les informations sur le ou les paragraphes appartenant à la même section.
- le type **docSection** permet de modifier les informations sur le ou les paragraphes de la même section.

Les caractéristiques de cette section peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Récupération du champ Traitement de texte
MonDoc est un Document <- TT_MonDoc
// Récupération du l'orientation du document
Info(MonDoc.Section.Orientation)
// Passage de l'orientation du document en paysage
MonDoc.Section.Orientation = docPaysage
```

## Propriétés

### Propriétés spécifiques à la description des variables de type docSection
Les propriétés suivantes peuvent être utilisées pour manipuler une section :

| **Nom de la propriété** | Type manipulé | Effet |  |
| --- | --- | --- | --- |
| Entête |  |  | Caractéristiques de l'entête de page |
|  | Entête.PremièrePageHéritée | Booléen | - Vrai si l'entête de première page de la section est identique à celle de la section précédente. - Faux dans le cas contraire. |
|  | Entête.PremièrePage | Variable de type [docEntêtePiedDePage](1000022996.md) | Caractéristiques de l'entête pour la première page de la section. |
|  | Entête.PagePaireHéritée | Booléen | - Vrai si l'entête des pages paires de la section est identique à celle de la section précédente. - Faux dans le cas contraire. |
|  | Entête.PagePaire | Variable de type [docEntêtePiedDePage](1000022996.md) | Caractéristiques de l'entête pour les pages paires de la section. |
|  | Entête.PageImpaireHéritée | Booléen | - Vrai si l'entête des pages impaires de la section est identique à celle de la section précédente. - Faux dans le cas contraire. |
|  | Entête.PageImpaire | Variable de type [docEntêtePiedDePage](1000022996.md) | Caractéristiques de l'entête pour les pages impaires de la section. |
| HauteurPage | Réel | Hauteur de page pour les pages de la section (exprimée en millimètres). |  |
| LargeurPage | Réel | Largeur de page pour les pages de la section (exprimée en millimètres). |  |
| MargeBasse | Réel | Marge basse pour les pages de la section (exprimée en millimètres). |  |
| MargeDroite | Réel | Marge droite pour les pages de la section (exprimée en millimètres). |  |
| MargeEntête | Réel | Marge pour les entêtes de page de la section (exprimée en millimètres). |  |
| MargeGauche | Réel | Marge gauche pour les pages de la section (exprimée en millimètres). |  |
| MargeHaute | Réel | Marge haute pour les pages de la section (exprimée en millimètres). |  |
| MargePiedDePage | Réel | Marge pour les pieds de page de la section (exprimée en millimètres). |  |
| Multicolonne | Variable de type [docFormatMulticolonne](1000023580.md) | Options de gestion du multicolonne de la section. |  |
| Numéro | Entier | Numéro de la section.  Cette propriété est disponible en lecture seulement. |  |
| Orientation | Constante de type Entier | Orientation de la section :   - *docPaysage* : toutes les pages de la section sont en mode Paysage. - *docPortrait* : toutes les pages de la section sont en mode Portrait. |  |
| PiedDePage |  |  | Caractéristiques du pied de page. |
|  | PiedDePage.PremièrePageHéritée | Booléen | - Vrai si le pied de page de la première page de la section est identique à celui de la section précédente. - Faux dans le cas contraire. |
|  | PiedDePage.PremièrePage | Variable de type [docEntêtePiedDePage](1000022996.md) | Caractéristiques du pied de page pour la première page de la section. |
|  | PiedDePage.PagePaireHéritée | Booléen | - Vrai si le pied de page des pages paires est identique à celui de la section précédente. - Faux dans le cas contraire. |
|  | PiedDePage.PagePaire | Variable de type [docEntêtePiedDePage](1000022996.md) | Caractéristiques du pied de page pour les pages paires de la section. |
|  | PiedDePage.PageImpaireHéritée | Booléen | - Vrai si le pied de page des pages impaires est identique à celui de la section précédente. - Faux dans le cas contraire. |
|  | PiedDePage.PageImpaire | Variable de type [docEntêtePiedDePage](1000022996.md) | Caractéristiques du pied de page pour les pages impaires de la section. |
| PremièrePageDifférente | Booléen | - Vrai si, pour cette section, les entêtes et les pieds de page de la première page de la section sont différents de ceux de la section précédente, - Faux dans le cas contraire. |  |
| Type | Constante de type Entier | Type de saut de section à appliquer sur tous les paragraphes de la section :   - *ssSautDeSection* : Saut de section vers la page suivante. - *ssSautDeSectionContinu* : Saut de section sur la même page. Ce type de saut de section permet par exemple de séparer une section à 2 colonnes d'une section à une colonne sur une même page. Ce type de section n'est pas compatible avec des modifications de taille, d'orientation ou de marge du document. - *ssSautDeSectionPageImpaire* : Saut de section vers la page impaire suivante. - *ssSautDeSectionPagePaire* : Saut de section vers la page paire suivante. |  |
