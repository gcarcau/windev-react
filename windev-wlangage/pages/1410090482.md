# ValeurAffichéeCombo (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

La propriété **ValeurAffichéeCombo** permet de connaître et de modifier la valeur affichée d'une ligne d'un champ Combo, c'est-à-dire la valeur affichée dans le champ de la combo lorsque cette ligne est sélectionnée. Il est ainsi possible d'afficher une valeur différente dans la combo ouverte et dans le champ lorsque la combo est fermée.

## Exemple

```wlangage
ListeAjoute(COMBO_Classe, "1ère classe (plus de confort)")
COMBO_Classe[1].ValeurAffichéeCombo = "1ère classe"
ListeAjoute(COMBO_Classe, "2ème classe (le moins cher)")
COMBO_Classe[2].ValeurAffichéeCombo = "2ème classe"
```

## Syntaxe

#### Connaître la valeur affichée associée à une ligne d'un champ Combo

```wlangage
<Résultat> = <Champ manipulé>.ValeurAffichéeCombo
```

`<Résultat>` *Type de la valeur*
> Valeur affichée dans le champ de la combo si la ligne est sélectionnée.
`<Champ manipulé>` *Nom de champ*
> Ligne du champ Combo à manipuler. La notation suivante doit être utilisée :
>
>
> ```wlangage
> <Nom du champ Combo>[Indice de l'élément]
> ```

#### Modifier la valeur affichée associée à une ligne d'un champ Combo

```wlangage
<Champ manipulé>.ValeurAffichéeCombo = <Nouvelle valeur>
```

`<Champ manipulé>` *Nom de champ*
> Ligne du champ Combo à manipuler. La notation suivante doit être utilisée :
>
>
> ```wlangage
> <Nom du champ Combo>[Indice de l'élément]
> ```
`<Nouvelle valeur>` *Type de la valeur*
> Valeur à afficher dans le champ de la combo si la ligne est sélectionnée.

## Remarques

- Cette propriété est disponible uniquement pour les champs Combo par programmation.
- Lorsque la ligne est sélectionnée (par l'utilisateur ou par programmation), la valeur affichée dans le champ Combo correspond à la valeur spécifiée par la propriété **ValeurAffichéeCombo**.
- La valeur affichée dans le champ Combo peut être relue par la propriété [ValeurAffichée](2510129.md).
- Pour les champs Combo en saisie, la propriété **ValeurAffichéeCombo** correspond à la valeur qui sera affichée dans le champ de saisie.
