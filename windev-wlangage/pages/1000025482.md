# CouleurTrait (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Mac Catalyst)

La propriété **CouleurTrait** permet de définir la couleur de trait d'une forme. Cette propriété est utilisable sur :

- une variable de type [CarteCercle](1000025504.md).
- une variable de type [CartePolygone](1000025476.md).
- une variable de type [CartePolyligne](1000025489.md).
