# GraveurMédiaPrésent (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Permet de savoir si le graveur est plein ou vide.

## Exemple

```wlangage
MédiaPrésent est un booléen
MédiaPrésent = GraveurMédiaPrésent()
```

## Syntaxe

```wlangage
<Résultat> = GraveurMédiaPrésent()
```

`<Résultat>` *Booléen*
> - Vrai si un média est présent dans le graveur.
> - Faux dans le cas contraire.

**Composante : wd300grv.dll**
