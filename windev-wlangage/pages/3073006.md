# SysYRes (Fonction)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Renvoie la résolution verticale de l'écran.
> _(WEBDEV - Code Navigateur)_ Renvoie la résolution verticale de l'écran de l'internaute.

## Exemple

```wlangage
// Résolution verticale de l'écran
ResResVert = SysYRes()
```

## Syntaxe

```wlangage
<Résultat> = SysYRes()
```

`<Résultat>` *Entier*
> Résolution verticale de l'écran.

## Remarques

> _(WINDEV)_ Résolution des configurations multi écransDans les configurations multi écrans, il est nécessaire d'employer les fonctions SysListeCarteGraphique, SysListeEcran et SysRésolutionEcran pour obtenir la résolution maximale dans une dimension donnée.

**Composante : wd300std.dll**
