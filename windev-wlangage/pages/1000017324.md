# Arrondi (mot-clé)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le mot-clé **Arrondi** peut correspondre :

- à la fonction WLangage [Arrondi](3050063.md).
- à la propriété **Arrondi** utilisable sur:
  - une variable de type [Cadre](15140100.md).
  - une variable de type [diagSélection](1410088172.md).
  - une variable de type [diagRectangle](1410088083.md).
  - une variable de type [VisiteGuidée](1410090170.md).
  - une variable de type [VisiteGuidéeEtape](1410090178.md).
  - Nouveauté Abonnement
     une variable de type [Toast](1000024638.md).
    **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
    Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
