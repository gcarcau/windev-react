# Description (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Description** permet de connaître et de modifier la description d'un élément. Cette propriété est utilisable sur :

- une page WEBDEV. Pour plus de détails, consultez l'aide de la propriété [Description](1000017164.md) sur une page.
- une variable de type [gglAgenda](1000017418.md).
- une variable de type [hDescriptionSauvegarde](1000017455.md).
- une variable de type [hOptimisationPlanifiée](1000018854.md).
- une variable de type [hTâchePlanifiée](1000017448.md).
- une variable de type [Marqueur](1000019940.md).
- une variable de type [rssCanal](1000017769.md).
- une variable de type [rssFlux](1000017795.md).
- une variable de type [rssImage](1000017799.md).
- une variable de type [rssEntrée](1000017792.md).
- une variable de type [rssSaisieTexte](1000017802.md)
- une variable de type [hRSConfig](1000020484.md).
- une variable de type [inAppProduit](1000020868.md).
- une variable de type [hPlanificationVueMatérialisée](1000021444.md).
- une variable de type [beaconGroupe](1000023105.md).
- une variable de type [notificationCatégorie](1000023981.md).
- une variable de type [CarteCercle](1000025504.md).
- une variable de type [CarteImage](1000025523.md).
- une variable de type [CartePolygone](1000025476.md).
- une variable de type [CartePolyligne](1000025489.md).
- une variable de type [Permission](1410087419.md).
- une variable de type [TéléchargementInfo](1410087306.md).
