# RendezVousVersiCalendar (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Exporte un rendez-vous ou une liste de rendez-vous au format iCalendar.

## Exemple

```wlangage
// Crée un fichier au format iCalendar // contenant la liste des rendez-vous affichés dans un champ PlanningtabRDV est un tableau de RendezVoustabRDV = PlanningListeRendezVous(MonPlanning)sChaîne est une chaîne = RendezVousVersiCalendar(tabRDV)SI PAS ErreurDétectée ALORS fSauveTexte("agenda.ics", sChaîne)FIN
```

## Syntaxe

#### Exporter une liste de rendez-vous au format iCalendar

```wlangage
<Résultat> = RendezVousVersiCalendar(<Tableau de rendez-vous>)
```

`<Résultat>` *Chaîne de caractères ANSI au format UTF-8*
> - Liste des rendez-vous au format iCalendar,
> - Chaîne vide ("") en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Tableau de rendez-vous>` *Tableau de variables de type RendezVous*
> Nom de la variable de type Tableau contenant les variables de type [RendezVous](1000019244.md) à exporter au format iCalendar.

#### Exporter un rendez-vous au format iCalendar

```wlangage
<Résultat> = RendezVousVersiCalendar(<Rendez-vous>)
```

`<Résultat>` *Chaîne de caractères ANSI au format UTF-8*
> - Rendez-vous au format iCalendar,
> - Chaîne vide ("") en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Rendez-vous>` *Variable de type RendezVous*
> Nom de la variable de type [RendezVous](1000019244.md) à exporter au format iCalendar.

## Remarques

Pour récupérer une liste de rendez-vous à partir d'une chaîne au format iCalendar, utilisez la fonction [iCalendarVersRendezVous](1000021827.md).
