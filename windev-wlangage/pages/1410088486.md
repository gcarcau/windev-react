# mdpsAge (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **mdpsAge** permet de connaître la durée écoulée depuis la dernière modification du mot de passe.

## Exemple

```wlangage
// Vérification du dernier changement du mot de passe dans le fichier Identification
AgeMdp est une Durée
AgeMdp = Identification.RubMotPasse.mdpsAge
```

## Syntaxe

```wlangage
<Durée écoulée> = <Fichier de données>.<Rubrique>.mdpsAge
```

`<Durée écoulée>` *Durée*
> Durée écoulée depuis le dernier changement du mot de passe.
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données manipulé. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Fichier](1514065.md).
`<Rubrique>` *Chaîne de caractères*
> Nom de la rubrique de type "Mot de passe" manipulée. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Rubrique](1514071.md).
