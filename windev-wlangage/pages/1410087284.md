# Propriétés associées au champ Flexbox

> **Disponible :** **WINDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Les propriétés WLangage permettent de manipuler :

- Un champ Flexbox présent dans une fenêtre.
- Les champs présents dans un champ Flexbox. Ces propriétés spécifiques permettent de gérer leur comportement lors de l'exécution d'un champ Flexbox.
