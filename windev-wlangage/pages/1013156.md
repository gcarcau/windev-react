# Le champ Jauge

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

## Présentation du Champ Jauge

### Champ d'une fenêtre ou d'une page dynamique

Les différents types de jauges proposés sont :

- Les jauges linéaires simples (horizontales ou verticales).
   Seules les jauges linéaires simples horizontales sont disponibles en WEBDEV.
- Les jauges linéaires symétriques (horizontales ou verticales) : la jauge est séparée en deux parties (négative et positive) permettant d'afficher la progression.[image: Exemples de jauges linéaires] Ce type de jauge n'est pas disponible.
- Les jauges circulaires à aiguilles : une aiguille se déplace pour indiquer la valeur de la jauge.
- Les jauges circulaires "LCD" : une "barre LCD" se remplit pour indiquer la valeur de la jauge.[image: Quelques jauges circulaires]

## Créer un champ Jauge

> _(WINDEV, Android, iPhone/iPad, Widget IOS, Mac Catalyst, Java, WINDEV, Android, iPhone/iPad, Widget IOS, Mac Catalyst, Java)_ Créer un champ de type Jauge dans une fenêtrePour créer un champ de type Jauge : Sous le volet "Création", dans le groupe "Champs graphiques", déroulez l'option "Jauge" et sélectionnez une jauge linéaire ou circulaire. Remarque : l'option "Jauge infinie" permet de créer un champ de type Jauge infinie. Cliquez dans la fenêtre à la position où le champ doit être créé. Le champ apparaît en création.Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ.Remarques : Un grand choix de jauges circulaires prédéfinies est livré en standard. Ces jauges sont directement accessibles dans le volet "Champs prédéfinis" de l'éditeur. Seules les jauges linéaires simples sont disponibles.

> _(WEBDEV - Code Serveur, PHP)_ Créer un champ de type Jauge dans une pagePour créer un champ de type Jauge : Sous le volet "Création", dans le groupe "Champs graphiques", déroulez l'option "Jauge".Cliquez dans la page à la position où le champ doit être créé. Le champ apparaît en création.Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ.Remarques : Seules les jauges linéaires simples horizontales sont disponibles en WEBDEV. Le champ Jauge ne peut être inclus dans un champ Zone répétée ou dans une colonne conteneur de table

### Créer un champ de type Jauge dans un état
Pour créer un champ de type Jauge :

1. Sous le volet "Création", dans le groupe "Visuel", déroulez l'option "Jauge".
2. Cliquez sur le type de jauge voulu puis cliquez dans l'état à la position où le champ doit être créé.
3. Le champ apparaît en création.

Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ.

## Caractéristiques des champs Jauge

> _(WINDEV, Android, iPhone/iPad, Widget IOS, Mac Catalyst, Java, Android, Java, Android, Java)_ Caractéristiques des jauges dans une fenêtre : fenêtre à 7 ongletsL'onglet "Général" permet de configurer :Le type de jauge : linéaire (horizontale ou verticale) ou circulaire (à aiguille ou LCD).Les différentes valeurs de la jauge. Ces valeurs peuvent également être spécifiées par programmation. Pour plus de détails, consultez Manipuler une jauge par programmation. L'onglet "Détail" permet de configurer :Les différentes images affichées dans la jauge (pour les jauges linéaires)Il est possible d'utiliser le mode 9 images sur les images affichées dans les jauges.Si la jauge est symétrique. Cette option n'est pas disponible. Si la jauge utilise une image fixe.Si le pourcentage de progression doit être affiché dans le champ Jauge. Il est possible d'indiquer si ce pourcentage doit être mis à blanc si la valeur affichée est zéro. Il est également possible de définir la position du pourcentage affiché. Cette position peut être modifiée par programmation grâce à la propriété CadrageHorizontal. La mise en forme de ce pourcentage peut être effectuée par programmation grâce à la propriété MasqueSaisie. Cette option n'est pas disponible. L'onglet "Style" permet de configurer tous les paramètres de présentation de la jauge (y compris les images et leur position pour les jauges circulaires).Remarque : Ces informations sont également disponibles pour les jauges affichées dans les champs Table.

> _(WEBDEV - Code Serveur, PHP)_ Caractéristiques des jauges dans une page : fenêtre à 7 ongletsL'onglet "Général" permet de configurer les différentes valeurs de la jauge. Ces valeurs peuvent également être spécifiées par programmation. Pour plus de détails, consultez Manipuler une jauge par programmation. L'onglet "Détail" permet de configurer si le pourcentage de progression doit être affiché dans le champ Jauge (option "Afficher le pourcentage de progression"). Il est possible d'indiquer si ce pourcentage doit être mis à blanc si la valeur affichée est zéro (option "Ne pas afficher le pourcentage s'il vaut 0%"). La position du pourcentage affiché peut être modifiée par programmation grâce à la propriété CadrageHorizontal. La mise en forme de ce pourcentage peut être effectuée par programmation grâce à la propriété MasqueSaisie.L'onglet "Style" permet de configurer tous les paramètres de présentation de la jauge. Il est possible par exemple de configurer le style CSS de la barre de progression pour afficher une image de progression.
