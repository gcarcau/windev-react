# fRepRessource (Fonction)

> **Disponible :** **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie le chemin des ressources en lecture seule de l'application.

## Exemple

```wlangage
// La fonction renvoie le contenu du fichier
fChargeBuffer(fRepRessource() + ["\"] + "data.bin")
```

## Syntaxe

```wlangage
<Résultat> = fRepRessource()
```

`<Résultat>` *Chaîne de caractères*
> Chemin complet des ressources en lecture seule de l'application. Correspond au répertoire ".app" de l'application. Il n'est pas possible d'écrire dans ce répertoire.

## Remarques

> _(iPhone/iPad, Widget IOS, Mac Catalyst)_ Intégration de ressources lors de la génération de l'application iPhone/iPadL'assistant de génération de l'application pour iOS permet d'inclure des fichiers dans l'exécutable. Il est possible d'intégrer :des ressources spécifiques.des images spécifiques.des fichiers de données. Si les fichiers ont l'option "Ecriture" cochée, ces fichiers seront extraits automatiquement (fichiers à modifier par l'application par exemple). Dans ce cas, spécifiez dans quel répertoire de l'application ce fichier doit être extrait (répertoire "Documents" ou répertoire "Library"). Si les fichiers ont l'option "Ecriture" décochée, ces fichiers pourront ensuite :soit être utilisés directement (fichiers à lire par exemple : fichiers son, image, ...). Ces fichiers sont intégrés à l'application et ne seront pas extraits. La fonction fRepRessource permet d'accéder en lecture à ces fichiers. soit être extraits par programmation avec la fonction fExtraitRessource. Attention : Le système iOS est sensible à la casse.

> _(iPhone/iPad, Widget IOS, Mac Catalyst)_ Manipulation des fichiers en lecture seule présents dans le répertoire des ressourcesL'arborescence du répertoire des ressources est identique à l'arborescence du répertoire du projet sur le poste de développement : sur le poste de développement, la ressource intégrée au projet Xcode peut être présente dans un répertoire de la forme : <Nom_Projet>\EXE\<Nom de la configuration>\<Répertoire personnalisé>. sur l'iPhone ou l'iPad, le ressource sera présente dans un répertoire de la forme : fRepRessource() + \EXE\<Nom de la configuration>\<Répertoire personnalisé>. Exemple : Le code suivant permet de vérifier l'existence du fichier "stop.png" dans le répertoire des ressources. Sur le poste de développement, ce fichier était présent dans le répertoire "C:\Mes Projets\MonAppli\Exe\Application iOS\stop.png". Sur l'iPhone ou l'iPad, ce chemin correspond à : "<Répertoire de l'application>/MonAppli.app/Exe/Application iOS/stop.png".
