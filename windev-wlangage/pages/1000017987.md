# DateMiseAJour (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

La propriété **DateMiseAJour** permet de connaître la date de mise à jour d'un élément. Cette propriété est utilisable sur :

- une variable de type [gglGroupeContact](1000017576.md).
- une variable de type [gglDocument](1000018001.md).
- une variable de type [gglEvénement](1000017440.md).
- une variable de type [rssCanal](1000017769.md).
- une variable de type [rssFlux](1000017795.md).
