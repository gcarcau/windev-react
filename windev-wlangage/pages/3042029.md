# grDégradé (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Active ou désactive l'affichage des dégradés de couleurs dans un graphe.
**Rappel** : Par défaut, les couleurs d'un graphe sont dégradées.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
// Graphe créé par programmation
grCrée("MonGraphe", grChandelier)
...
// Désactive les dégradés de couleurs
grDégradé("MonGraphe", Faux)
```

```wlangage
// Champ Graphe
// Désactive les dégradés de couleurs
grDégradé(GRF_MonGraphe, Faux)
```

## Syntaxe

```wlangage
grDégradé(<Nom du graphe> , <Dégradé>)
```

`<Nom du graphe>` *Nom de champ ou chaîne de caractères*
> Nom du graphe à manipuler. Ce nom correspond :
>
> - soit au nom du graphe défini par programmation avec la fonction [grCrée](3042005.md).
> - soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.
>
>
> > _(Android)_ Seuls les champs Graphe sont disponibles.
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Dégradé>` *Booléen*
> - Vrai pour afficher le graphe en utilisant les dégradés de couleurs,
> - Faux dans le cas contraire.

## Remarques

- Par défaut, les graphes utilisent les dégradés de couleurs. Tous les types de graphes peuvent afficher des couleurs dégradées.
- Le paramétrage réalisé avec la fonction **grDégradé** sera pris en compte lors du prochain appel à la fonction [grDessine](3042026.md).
- Lors de l'impression, le mode dégradé ne sera pas pris en compte pour les graphes de type Secteur.

**Composante : wd300grf.dll**
