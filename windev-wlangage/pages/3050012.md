# Fonctions de gestion des valeurs binaires

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android)

Les fonctions de gestion des valeurs binaires sont les suivantes :

| [ETBinaire](3050010.md) | Renvoie le résultat du ET logique (bit à bit) entre deux valeurs. |
| --- | --- |
| [NONBinaire](3050011.md) | Renvoie le résultat du NON logique (bit à bit) d'une valeur. |
| [OUBinaire](3050038.md) | Renvoie le résultat du OU logique (bit à bit) entre deux valeurs. |
| [OUExclusifBinaire](3050023.md) | Renvoie le résultat du OU Exclusif logique (bit à bit) entre deux valeurs. |
