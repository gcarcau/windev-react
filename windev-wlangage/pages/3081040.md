# XMLNamespaceURI (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie l'URI de définition de l'espace de nommage de la balise courante dans un document XML.

## Exemple

```wlangage
MonDoc est une chaîne
MonDoc = fChargeTexte("Exemple.xml")
XMLDocument("exemple", MonDoc)
SI ErreurDétectée = Vrai ALORS
	Erreur("Le fichier n'est pas au format XML")
	RETOUR
FIN
// On se positionne sur la première balise du fichier
SI XMLPremier() = Vrai ALORS
	SI XMLNamespace() <> "" ALORS
		Info("Le préfixe utilisé pour l'espace de nommage est : " + XMLNamespace(), ...
			"L'URI correspondante est : " + XMLNamespaceURI())
	SINON
		SI ErreurDétectée = Vrai ALORS
			Info("L'élément lu n'est pas une balise")
	  	SINON
			Info("La balise ne contient pas d'espace de nommage")
	  	FIN
   	FIN
FIN

XMLTermine()
```

## Syntaxe

```wlangage
<Résultat> = XMLNamespaceURI([<Document XML>])
```

`<Résultat>` *: Chaîne de caractères*
> - URI de définition de l'espace de nommage associé à la balise en cours,
> - Chaîne vide ("") :
>   - si la balise ne contient pas de préfixe de nommage.
>   - si le document XML n'est pas positionné sur une balise. La variable [ErreurDétectée](3087001.md) est à Vrai.
`<Document XML>` *: Chaîne de caractères optionnelle*
> Nom du document XML à manipuler. Ce document contient le code XML et a été créé avec la fonction [XMLDocument](3081008.md). Si ce paramètre n'est pas précisé, la fonction **XMLNamespaceURI**s'applique au dernier document XML manipulé dans le thread en cours.

## Remarques

### Manipulation d'une balise associée à un espace de nommage

- Une balise associée à un espace de nommage peut être manipulée grâce aux fonctions [XMLDonnée](3081004.md), [XMLExtraitChaîne](3081017.md), ...
- Le préfixe de l'espace de nommage associé à une balise peut être connu par la fonction [XMLNamespace](3081039.md).

### Fonctions XML et threads
Si votre application utilise des threads, le document XML est partagé entre tous ces threads. Pour plus de détails sur la gestion des threads, consultez [Gestion des threads](3077026.md).
