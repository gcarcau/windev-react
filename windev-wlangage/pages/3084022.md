# Compilation du projet : Warning, Erreur, Informations, Norme de programmation, ...

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Compilation du projet

Lors du développement d'un projet, le projet est régulièrement compilé. Cette compilation permet de vérifier le code saisi dans l'éditeur de code. En cas d'erreurs, les problèmes potentiels et leurs solutions sont affichés dans le volet "Erreurs de compilation".
Plusieurs types d'information peuvent être donnés :

- Erreurs de code ().
- Warnings ().
- Informations ().
- Erreurs d'UI ().
- Erreurs de norme de programmation ().

**Remarque** : Sur une machine disposant de plusieurs processeurs ou de plusieurs "core" (dual core, ...), la compilation de projets s'effectue en parallèle et utilise toute la puissance disponible. La phase de compilation est ainsi accélérée d'environ 30%.

## Les différents types d'erreurs possibles

### Erreurs
Les erreurs () signalent un problème grave (erreur de programmation, ...). Le test ou l'exécution du projet ne pourra pas fonctionner.
Les erreurs sont toujours visibles sous l'éditeur de code et doivent être corrigées pour que le code fonctionne.

### Warnings
Les warnings () signalent des cas de programmation pouvant entraîner des comportements inattendus.
Les warnings sont affichés par défaut sous l'éditeur de code et n'empêchent pas l'exécution du programme.

Les warnings surviennent dans des cas de programmation qui peuvent réellement poser un problème

### Informations
Les informations () expliquent les choix du compilateur ou présentent d'éventuels conseils pour améliorer le code.
Les informations peuvent être affichées uniquement pour comprendre par exemple pourquoi un code ne fournit pas le résultat attendu.

### Erreurs d'UI
Les erreurs de compilation d'UI () vous informent des problèmes potentiels détectés sur vos interfaces : images inexistantes, libellés tronqués, ...

### Erreurs de norme de programmation
Les erreurs de norme de programmation () vous informent des problèmes détectés par rapport à la norme de programmation mise en place. Pour plus de détails, consultez [Erreurs de norme de programmation](9000187.md).
