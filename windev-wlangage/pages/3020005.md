# Constantes de gestion des champs Barre d'outils

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Afficher uniquement les constantes utilisées par les syntaxes préfixées
Afficher uniquement les constantes utilisées par les syntaxes non préfixées

Les constantes de gestion des champs Barres d'outils sont les suivantes :

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |
| **barBas** | La barre d'outils est ancrée en bas de la fenêtre principale. | [BarreAttache](3020003.md) [BarrePosition](3020004.md) |
| **barDroite** | La barre d'outils est ancrée à droite de la fenêtre principale. | [BarreAttache](3020003.md) [BarrePosition](3020004.md) |
| **barGauche** | La barre d'outils est ancrée à gauche de la fenêtre principale. | [BarreAttache](3020003.md) [BarrePosition](3020004.md) |
| **barHaut** | La barre d'outils est ancrée en haut de la fenêtre principale. | [BarreAttache](3020003.md) [BarrePosition](3020004.md) |
| **barLibre** | Barre d'outils "flottante". | [BarreAttache](3020003.md) [BarrePosition](3020004.md) |
