# Canada.VérifieNE15 (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un numéro NE15 (numéro d'entreprise sur 15 caractères identifiant un établissement d'une entreprise au Canada).

## Exemple

```wlangage
// Test d'une variableMonNuméroNE15 est une chaîne = "887471886RT0001"Canada.VérifieNE15(MonNuméroNE15)  // renvoie Vrai // Test d'un champSAI_NuméroNE15 = "ABC"Canada.VérifieNE15(SAI_NuméroNE15) // renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = Canada.VérifieNE15(<Numéro à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un numéro NE15 valide.
> - Faux dans le cas contraire.
`<Numéro à vérifier>` *Nom de champ ou variable de type chaîne*
> Numéro NE15 à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.

**Composante : wd300std.dll**
