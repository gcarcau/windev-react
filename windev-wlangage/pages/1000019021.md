# Fonctions de gestion des champs Agenda

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Remarque : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des champs Agenda (syntaxe préfixée)](1000022884.md)).
Les fonctions de gestion des champs Agenda sont les suivantes :

| [AgendaAffiche](1000019425.md) | Réinitialise le contenu d'un champ Agenda à partir de sa source de données (fichier de données HFSQL par exemple). |
| --- | --- |
| [AgendaAffichePériodePrécédente](1000018886.md) | Déplace la zone temporelle affichée sur la zone précédente (par exemple, semaines précédentes) dans un champ Agenda. |
| [AgendaAffichePériodeSuivante](1000018885.md) | Déplace la zone temporelle affichée sur la zone suivante (par exemple, semaines suivantes) dans un champ Agenda. |
| [AgendaAjouteRendezVous](1000018877.md) | Ajoute un nouveau rendez-vous dans un champ Agenda. |
| [AgendaChangeMode](1000019497.md) | Modifie la plage temporelle affichée par un champ Agenda (Jour/Semaine/Mois). |
| [AgendaChangeZoom](1000018883.md) | Modifie la plage temporelle affichée par un champ Agenda (Jour/Semaine/Mois). Cette fonction est conservée par compatibilité. |
| [AgendaCouleurFond](1000020004.md) | Fixe une couleur de fond sur une plage horaire d'un champ Agenda. |
| [AgendaDateVisible](1000022875.md) | Rend visible ou invisible un jour dans un champ Agenda. |
| [AgendaHeureAffichée](1000018888.md) | Définit la plage horaire affichée par le champ Agenda en mode Jour ou Semaine. |
| [AgendaHeureOuvrable](1000022530.md) | Permet d'indiquer les heures ouvrables spécifiques par jour dans un champ Agenda. |
| [AgendaInfoXY](1000018887.md) | Renvoie pour une position donnée dans le champ Agenda (coordonnées d'un point de l'agenda) :   - soit l'indice du rendez vous pour la position indiquée. - soit la date correspondant à la position indiquée. |
| [AgendaListeRendezVous](1000018880.md) | Renvoie :   - la liste des rendez-vous compris entre deux dates données dans un champ Agenda, - tous les rendez-vous d'un champ Agenda, - un rendez-vous particulier (sélectionné ou survolé). |
| [AgendaMode](1000019545.md) | Renvoie le mode d'affichage par un champ Agenda : jour, semaine, mois, ... |
| [AgendaPlageSélectionnée](1000022399.md) | Renvoie la date et l'heure de début ou de fin de la plage horaire sélectionnée dans un champ Agenda. |
| [AgendaPosition](1000018889.md) | Affiche un champ Agenda à partir d'une date spécifiée ou renvoie la date du premier jour (ou dernier jour) affiché dans un champ Agenda. |
| [AgendaSelectMoins](1000019147.md) | Désélectionne un rendez-vous dans un champ Agenda. |
| [AgendaSelectPlus](1000019003.md) | Sélectionne un rendez-vous dans un champ Agenda. |
| [AgendaSupprimeRendezVous](1000018881.md) | Supprime un rendez-vous dans un champ Agenda. |
| [AgendaSupprimeTout](1000018882.md) | Supprime tous les rendez-vous d'un champ Agenda. |
| [AgendaVersiCalendar](1000021919.md) | Exporte les rendez-vous d'un champ Agenda au format iCalendar. |
| [AgendaZoom](1000018884.md) | Renvoie la plage temporelle affichée par un champ Agenda. |
| [iCalendarVersAgenda](1000021918.md) | Importe des données au format iCalendar dans un champ Agenda. |

**Remarque** : Il est également possible de gérer les agendas Lotus Notes et les agendas Outlook. Pour plus de détails, consultez :
