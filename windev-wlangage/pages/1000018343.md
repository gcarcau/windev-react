# Timestamp (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

La propriété **Timestamp** permet de gérer l'horodatage des valeurs. Cette propriété est disponible sur :

- une variable de type [hbRésultatScan](1000021724.md).
- une variable de type [hbCellule](1000021707.md).
