# PositionDébut (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **PositionDébut** permet de connaître la position de début d'un élément dans un document Traitement de texte. Cette propriété est utilisable sur :

- les variables de type [docElément](1000022484.md).
- les variables de type [docFragment](1000022482.md)
- les variables de type [docParagraphe](1000022483.md).
