# EspaceV (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

La propriété **EspaceV** permet de connaître et de modifier l'espacement vertical entre les étiquettes d'un état. Cet espace a été défini lors de la création de l'état au format étiquette.

## Exemple

```wlangage
// Modification de l'espace vertical entre les étiquettes
ETAT_EtatEtiquette.EspaceV += 10   // Ajoute 10 mm
```

## Syntaxe

#### Connaître l'espace vertical entre les étiquettes

```wlangage
<Espace actuel> = <Etat Etiquette>.EspaceV
```

`<Espace actuel>` *Réel*
> Espace vertical actuel entre les étiquettes. Cet espace est exprimé en millimètres.
`<Etat Etiquette>` *Nom d'état*
> Nom de l'état de type Étiquette.

#### Modifier l'espace vertical entre les étiquettes

```wlangage
<Etat Etiquette>.EspaceV = <Nouvel espace>
```

`<Etat Etiquette>` *Nom d'état*
> Nom de l'état de type Étiquette.
`<Nouvel espace>` *Réel*
> Espace vertical à définir entre les étiquettes. Cet espace est exprimé en millimètres.

## Remarques

### Hauteur et largeur des étiquettes
Les propriétés [LargeurEtiquette](2511055.md) et [HauteurEtiquette](2511069.md) permettent de définir la taille des étiquettes par programmation.
La propriété [EspaceH](2511065.md) permet de définir l'espace horizontal entre les étiquettes d'un état.

### Divers
Cette propriété peut être utilisée dans n'importe quel événement de l'état.
