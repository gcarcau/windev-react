# HSupprimeRequête (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Supprime une requête (utilisée par des procédures stockées) d'un serveur HFSQL.

## Exemple

```wlangage
// Supprimer la requête "GestionMail" du serveur
HSupprimeRequête("MaConnexion", GestionMail)
```

## Syntaxe

```wlangage
<Résultat> = HSupprimeRequête(<Connexion> , <Requête à supprimer>)
```

`<Résultat>` *Booléen*
> - Vrai si la requête a été supprimée,
> - Faux dans le cas contraire. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion vers le serveur HFSQL contenant la requête à supprimer. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Requête à supprimer>` *Chaîne de caractères*
> Nom de la requête à supprimer du serveur.

**Composante : wd300hf.dll**
