# ConstruitEntier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad) · **Autres** (Procédures stockées)

Construit un entier de 4 octets à partir de deux entiers de 2 octets.

## Exemple

```wlangage
Valeur est un entier = 5000
Faible est un entier sur 2 octets = PoidsFaible(Valeur)
Fort est un entier sur 2 octets = PoidsFort(Valeur)
// Reconstruit la valeur d'après ces octets de poids fort et de poids faible
ValeurConstruite est un entier = ConstruitEntier(Fort, Faible)
// ValeurConstruite est égal à Valeur
```

## Syntaxe

```wlangage
<Résultat> = ConstruitEntier(<Poids Fort> , <Poids Faible>)
```

`<Résultat>` *Entier*
> Valeur entière (sur 4 octets) construite par concaténation de <Poids Fort> et de <Poids Faible>.
`<Poids Fort>` *Entier sur 2 octets*
> Valeur qui déterminera les 2 octets de poids fort de l'entier <Résultat>.
`<Poids Faible>` *Entier sur 2 octets*
> Valeur qui déterminera les 2 octets de poids faible de l'entier <Résultat>.

**Classification Métier / UI : Code neutre**

**Composante : wd300mat.dll**
