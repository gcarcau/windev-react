# Fonctions de gestion de l'exécution des commandes en mode console (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU))

| Nouveauté 2025 [<Variable Commande>.AjouteArgument](1410090748.md) | Ajoute un argument à une commande à exécuter en mode console. |
| --- | --- |
| Nouveauté 2025 [<Variable Commande>.AjouteOption](1410090749.md) | Ajoute une option à la commande à exécuter en mode console. |
| Nouveauté 2025 [<Variable Commande>.EcritEntréeStandard](1410090750.md) | Ecrit les données sur l'entrée standard de la commande exécutée en mode console. |
| Nouveauté 2025 [<Variable Commande>.Exécute](1410090751.md) | Exécute une commande en mode console. |
| Nouveauté 2025 [<Variable Commande>.ExécutionEstEnCours](1410091033.md) | Indique si l'exécutable lié à une commande exécutée en mode console est actuellement en cours d'exécution.  **Attention** : Cette fonction est disponible uniquement à partir de la version 2025 Update 1. |
| Nouveauté 2025 [<Variable Commande>.LitSortieErreur](1410090752.md) | Lit les données disponibles sur la sortie d'erreur pour la commande lancée en mode console. |
| Nouveauté 2025 [<Variable Commande>.LitSortieStandard](1410090753.md) | Lit les données disponibles sur la sortie standard pour la commande lancée en mode console. |
| Nouveauté 2025 [<Variable Commande>.RécupèreCodeRetour](1410090754.md) | Récupère le code de retour de la commande lancée en mode console, c'est-à-dire la valeur renvoyée à la terminaison de la commande. |
| Nouveauté 2025 [<Variable Commande>.Termine](1410091034.md) | Force la terminaison de l'exécutable associé à une commande en mode console en cours d'exécution. **Attention** : Cette fonction est disponible uniquement à partir de la version 2025 Update 1. |
