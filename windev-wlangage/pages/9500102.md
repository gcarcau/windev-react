# Menu automatique des tables (FAA)

> **Disponible :** **WINDEV** (Windows)

## Présentation

Chaque champ Table présent dans une fenêtre propose par défaut un menu à l'utilisateur.
Ce menu, disponible sans programmation, permet des actions utiles :

- Export vers Word ou vers OpenOffice Writer (selon le logiciel installé sur le poste de l'utilisateur).
- Export vers Excel ou vers OpenOffice Calc (selon le logiciel installé sur le poste de l'utilisateur).
- Export vers XML.
- Copie de la ligne ou de la table.
- Création d'un graphique de représentation des données.
  Exemple de graphique généré automatiquement par le menu contextuel d'un champ Table :
- Impression de la table (voir [FAA d'impression d'une table](9500132.md)).
- Sélection de plusieurs colonnes de table :
  Pour simplifier le menu, seules les 32 premières colonnes sont visibles dans le menu. De plus, seules les colonnes ayant un titre sont proposées.


Grâce à ce menu, l'utilisateur gagne en autonomie et peut réaliser des traitements qui n'étaient pas forcément prévus dans l'application :

- Exportation dans un fichier externe Excel, Word ou XML.
- Possibilités d'afficher ou masquer les colonnes (pour éviter d'avoir un menu trop important, seules les 32 première colonnes de la table sont affichées).
- Génération d'un graphique automatique à partir des données de la table.
  Remarque : il n'est pas possible de sélectionner les colonnes à intégrer dans le graphe. Pour choisir uniquement certaines colonnes de la table, il est conseillé de créer un nouveau graphe à partir du champ Table s'affichant dans une fenêtre.

Remarques :

- Il est possible d'ajouter des choix à ce menu par programmation. Il suffit d'utiliser la propriété [MenuContextuel](2510077.md).
- Lors de l'export d'une table par le menu contextuel, la fusion des colonnes est ignorée.
- Table horizontale : Le menu des FAA ne contient pas les options permettant de réaliser un export dans un fichier externe Excel, Word ou XML.

## Paramétrage

### Paramétrage du menu automatique dans un champ Table
Le menu contextuel d'un champ Table peut bien évidemment être désactivé. Pour paramétrer l'affichage du menu contextuel du champ Table, vous devez :

1. Ouvrir la fenêtre de description du champ Table.
2. Sélectionner l'onglet "UI".
3. Choisir le menu désiré dans la combo "Menu contextuel". Il est possible de :
  - "Afficher le menu des FAA (Système)" : Dans ce cas, le menu contextuel affiché sera le menu automatique du champ Table (Menu des FAA). Pour plus de détails sur la configuration de ce menu, consultez [Configurer le menu des FAA](2010040.md).
  - "Ajouter un menu contextuel" : Si cette option est cochée, vous pouvez sélectionner le menu contextuel personnalisé à afficher.

Remarques :

- Si les deux options sont cochées, le menu contextuel personnalisé peut être ajouté avant ou après le menu des FAA.
- Si aucune option n'est sélectionnée, aucun menu contextuel ne sera sélectionné. L'option <Désactivé> sera affichée dans la fenêtre de description.
- La propriété [MenuContextuel](2510077.md) permet également de supprimer le menu contextuel spécifique aux FAA et de retrouver le menu Windows classique pour un champ spécifique.

> _(WINDEV, Windows)_ Paramétrage de l'option de menu "Sélectionner les colonnes..."Dans certains cas il peut être gênant de donner la possibilité à l'utilisateur de masquer des colonnes. Vous pouvez pour cela activer ou désactiver l'option de menu "Sélectionner les colonnes..." :Ouvrez la fenêtre de description du champ Table.Sélectionnez l'onglet "Détail".Cochez ou décochez l'option "Menu 'Sélectionner les colonnes...'".

> _(WINDEV, Windows)_ Paramétrage du fonctionnement par défaut de l'option "Export vers Excel"Il est possible de paramétrer le fonctionnement par défaut de l'export vers Excel grâce à la fonction FAAParamètre.
