# Contenu (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Contenu** permet de connaître et de modifier le contenu d'un élément. Cette propriété est utilisable sur :

- les champs de type liste ou combo. Pour plus de détails, consultez [Propriété Contenu sur les champs](1000017242.md).
- une variable de type [gglEvénement](1000017440.md).
- une variable de type [emailAttache](1000018752.md).
- une variable de type [EvénementTimeline](1000020612.md).
- une variable de type [nfcDonnée](1000020406.md).
- une variable de type [zipFichierArchivé](1000019044.md).
- une variable de type [RendezVous](1000019244.md).
- une variable de type [CodeBarres](1000019451.md).
- une variable de type [OrgaElément](1000019713.md).
- une variable de type [Notification](1000019441.md).
- une variable de type [Enregistrement](1000020962.md).
- une variable de type [httpRequête](1000021158.md).
- une variable de type [httpRéponse](1000021165.md).
- une variable de type [restRequête](1000021481.md).
- une variable de type [restRéponse](1000021477.md).
- une variable de type [notificationFormat](1000021301.md).
- une variable de type [docCellule](1000022927.md).
- une variable de type [docElémentLien](1000022970.md).
- une variable de type [docElémentZoneDeTexte](1000023420.md).
- une variable de type [pdfPièceJointe](1000024899.md).
- une variable de type [MotDePasseSécurisé](1000021064.md).
