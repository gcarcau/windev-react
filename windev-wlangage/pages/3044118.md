# HRAZ (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Initialise :

- une ou toutes les variables des rubriques d'un fichier de données avec leurs valeurs par défaut.
- une ou toutes les rubriques d'une variable de type [Enregistrement](1000020962.md) avec leurs valeurs par défaut.

Les valeurs par défaut sont définies lors de la description du fichier de données sous l'éditeur d'analyses.
**Remarques** :

- La fonction **HRAZ** ne modifie pas l'enregistrement dans le fichier de données mais uniquement les données en mémoire.
- La fonction **HRAZ** modifie la propriété [NouvelEnregistrement](1000017090.md) du fichier de données concerné : cette propriété passe à Vrai.

## Exemple

```wlangage
// Affecte les rubriques avec leur valeur par défaut
HRAZ(Client)
// Affichage
FichierVersPage()
```

## Syntaxe

#### Initialiser les rubriques d'un fichier de données avec leurs valeurs par défaut

```wlangage
<Résultat> = HRAZ([<Fichier de données> [, <Rubrique>]])
```

`<Résultat>` *Booléen*
> - Vrai si l'initialisation a été effectuée,
> - Faux en cas de problème. La fonction [HErreurInfo](3044071.md) permet d'obtenir plus de détails.
`<Fichier de données>` *Chaîne de caractères optionnelle*
> Nom du fichier de données manipulé. Si ce nom n'est pas spécifié, la fonction **HRAZ** va manipuler le dernier fichier de données utilisé par la dernière fonction de gestion HFSQL (fonction commençant par la lettre H).
`<Rubrique>` *Chaîne de caractères optionnelle*
> Nom de la rubrique à initialiser. Si ce paramètre n'est pas spécifié ou est égal à "*", l'initialisation sera effectuée pour toutes les rubriques du fichier de données.
>
> > _(Hyper File 5.5)_ Ce paramètre n'est pas pris en compte. Toutes les rubriques sont automatiquement ré-initialisées.

> _(WINDEV, WEBDEV - Code Serveur, Android, Widget Android, Java, Hyper File 5.5)_ Initialiser les rubriques d'un enregistrement avec leurs valeurs par défaut (variable de type Enregistrement) Masquer les détails
<Résultat> = HRAZ(<Enregistrement> [, <Rubrique>])

 <Résultat> : BooléenVrai si l'initialisation a été effectuée, Faux en cas de problème. La fonction HErreurInfo permet d'obtenir plus de détails. <Enregistrement> : Variable de type EnregistrementNom de la variable de type Enregistrement manipulée. <Rubrique> : Chaîne de caractères optionnelleNom de la rubrique à initialiser. Si ce paramètre n'est pas spécifié ou est égal à "*", l'initialisation sera effectuée pour toutes les rubriques de l'enregistrement. Ce paramètre n'est pas pris en compte. Toutes les rubriques sont automatiquement ré-initialisées.

## Remarques

### Ouverture de fichiers de données
La fonction **HRAZ** effectue une ouverture du fichier de données manipulé. Le fichier de données doit donc avoir été créé.

> _(WINDEV, WEBDEV - Code Serveur)_ Lors d'une gestion personnalisée des erreurs, il est nécessaire de tester la fonction HErreurBlocage après l'utilisation de la fonction HRAZ.

> _(WINDEV, WEBDEV - Code Serveur, Android, Widget Android, Java)_ Variable de type EnregistrementPour réinitialiser une variable de type Enregistrement, il est également possible d'utiliser la fonction VariableRAZ.
