# PaletteCharge (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Charge une palette à partir d'un fichier de type ".wdpalette".

## Exemple

```wlangage
// Charger les couleurs de la fenêtre FEN_Info
MaPaletteSombre est une Palette
PaletteCharge(MaPaletteSombre, "defaut_csombre.wdpalette")
PaletteChange(FEN_Info, MaPaletteSombre)
```

## Syntaxe

#### Charger un fichier "wdpalette" dans une palette existante

```wlangage
PaletteCharge(<Palette> , <Fichier Palette>)
```

`<Palette>` *Variable de type Palette*
> Nom de la variable de type [Palette](1000021347.md) dans laquelle le fichier doit être chargé.
`<Fichier Palette>` *Chaîne de caractères*
> Chemin et nom du fichier contenant la description de la palette de couleurs. Ce fichier est de type ".wdpalette".

#### Créer une nouvelle palette à partir d'un fichier "wdpalette"

```wlangage
<Résultat> = PaletteCharge(<Fichier Palette>)
```

`<Résultat>` *Variable de type Palette*
> Variable de type [Palette](1000021347.md) correspondant au fichier chargé.
`<Fichier Palette>` *Chaîne de caractères*
> Chemin et nom du fichier contenant la description de la palette de couleurs. Ce fichier est de type ".wdpalette".
