# DéchargeWDL (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Décharge la bibliothèque précédemment chargée en mémoire avec la fonction [ChargeWDL](3013020.md). La mémoire est libérée.

## Exemple

```wlangage
// Code de fermeture de la première fenêtre du projet
DéchargeWDL(hWnd) // Fermeture de la bibliothèque
```

## Syntaxe

```wlangage
DéchargeWDL(<Identifiant de la bibliothèque>)
```

`<Identifiant de la bibliothèque>` *Entier*
> Identifiant de la bibliothèque à décharger, renvoyée par la fonction [ChargeWDL](3013020.md).

## Remarques

- La bibliothèque principale du projet est toujours chargée et ne peut pas être déchargée.
- Lorsqu'une bibliothèque est fermée grâce à la fonction **DéchargeWDL**, les fichiers de données HFSQL ouverts dans la bibliothèque ne sont pas automatiquement fermés. Dans ce cas, tout accès à ces fichiers de données HFSQL provoquera l'erreur "La WDL xxx a été déchargée".
  Il est conseillé d'utiliser la fonction [HFerme](3044073.md) sur les fichiers ouverts d'une bibliothèque qui va être déchargée.
