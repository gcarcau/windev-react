# Fonctions de gestion des documents Google (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows)

Les fonctions suivantes permettent de gérer des documents sur un serveur Google :

| [<Variable gglConnexion>.EnvoieDocument](1000020424.md) | Envoie un document sur le serveur Google. |
| --- | --- |
| [GglImprimeDocument](1000020420.md) | Lance l'impression d'un document (fichier texte, pdf, images, document Word, Excel, ...) en utilisant le service Cloud Print de Google. |
| [<Variable gglConnexion>.ListeDocument](1000020436.md) | Récupère la liste des documents disponibles sur le serveur Google pour l'utilisateur en cours. |
| [<Variable gglConnexion>.RécupèreDocument](1000020437.md) | Télécharge un document depuis le service Google Docs. |

Il est également possible d'utiliser les fonctions suivantes :

| [<Variable gglConnexion>.Requête](1000021462.md) | Effectue une requête de communication (requête HTTP) à un service Google. |
| --- | --- |
| [<Variable gglConnexion>.Supprime](1000021461.md) | Supprime un document Google du serveur. |

**Avertissement** : Avant d'utiliser une fonctionnalité reliée à des services Google, nous vous conseillons vivement de vous reporter à la licence d'utilisation de ce service. Certaines restrictions peuvent s'appliquer. Le contenu des licences peut varier avec le temps.
PC SOFT dégage toute responsabilité de l'usage qui peut être fait des fonctions d'accès natif. Il vous appartient de vérifier que l'usage que vous faites respecte la licence du fournisseur du service.

**Attention** : Si vous utilisez un proxy pour accéder à Internet, il est nécessaire de configurer le proxy (fonction [Proxy](3043002.md)) pour utiliser les fonctions Google.
