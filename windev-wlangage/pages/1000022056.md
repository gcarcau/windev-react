# Service (Propriété)

> **Disponible :** **WINDEV** (Windows) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Service** permet de connaître et de modifier les permissions. Cette propriété est utilisable sur :

- une variable de type [btleService](1000022057.md).
- une variable de type [upnpService](1000020908.md).
