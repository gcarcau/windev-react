# SQLReqExiste (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Teste l'existence d'une requête.
> _(WEBDEV - Code Navigateur)_ Les fonctions SQL permettent de manipuler des bases de données locales (de type Web SQL database). Pour plus de détails, consultez Accès en mode local à une base de données (SQLite).

## Exemple

```wlangage
// Teste l'existence d'une requête
SI SQLReqExiste("REQ1") = 1 ALORS
	Info("La requête existe")
FIN
```

## Syntaxe

```wlangage
<Résultat> = SQLReqExiste(<Nom de la requête>)
```

`<Résultat>` *Booléen*
> - Vrai si la requête existe,
> - Faux dans le cas contraire.
`<Nom de la requête>` *Chaîne de caractères*
> Nom de la requête créée et exécutée avec la fonction [SQLExec](3072007.md), ou exécutée avec la fonction [SQLExecWDR](3072010.md).
> > _(Java)_ Les requêtes créées avec l'éditeur de requêtes doivent être spécifiées sous forme d'une chaîne de caractères avec guillemets.
>
> > _(WEBDEV - Code Navigateur)_ Seules les requêtes créées et exécutées avec la fonction SQLExec sont disponibles.

**Composante : wd300hf.dll**
