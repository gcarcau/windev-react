## Création du projet Pattern RAD

La création d'un pattern RAD est réalisée à partir d'un projet spécifique, de type "Pattern RAD".

Pour créer un projet "Pattern RAD" :

1. Cliquez sur  parmi les boutons d'accès rapide. La fenêtre de création d'un nouvel élément s'affiche : cliquez sur "Projet".
2. Dans l'assistant de création d'un projet, sélectionnez l'option "Pattern RAD".
3. Indiquez le nom du projet et son emplacement. Ces options ne seront pas modifiables. Le projet correspond à un fichier ".WDP" pour WINDEV. Ce fichier pourra être ouvert avec les produits WEBDEV et WINDEV Mobile. Pour plus de détails, consultez [Projet Commun](2030049.md).
  Tous les objets associés au projet seront créés dans le répertoire spécifié.
4. Terminez l'assistant. Le projet est automatiquement créé et associé à une analyse. Cette analyse contient les fichiers nécessaires à la création d'un RAD adaptable à toutes les configurations de fichiers.

Remarque : WEBDEV intégré dans WINDEV : Une configuration de type "Pattern RAD" n'admet que des fenêtres, il n'est pas possible de générer un pattern pour WEBDEV.

## L'analyse du projet de type Pattern RAD

### Analyse
Les projets de type "Pattern RAD" sont tous associés à une analyse identique. Cette analyse contient tous les types de liaisons et de groupes de fichiers.
Cette analyse comporte :

- un fichier seul (par exemple RADFichierC).
- deux fichiers reliés par une liaison simple (par exemple RADFichierB lié à RADFichierC ou RADFichierA lié à RADFichierB).
- deux fichiers (et un fichier de relation) liés par une liaison complexe (RADFichierB lié à RADFichierC par le fichier de relation RADFichierD).

Toute analyse peut être décomposée en plusieurs ensembles de ces trois groupes de fichiers.
