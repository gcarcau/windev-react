# Message

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, iPhone/iPad)

Le mot-clé **Message** peut correspondre :

- à la fonction **[Message](3021006.md)** qui permet d'afficher un message dans la barre de message.
- à la propriété **[Message](2510078.md)** qui permet de connaître et modifier le message d'aide associé à un champ ou une option de menu d'une fenêtre.
- à la propriété **Message** disponible sur :
  - une variable de type [SFErreur](1000018455.md).
  - la structure [Email](3032029.md)
  - une variable de type [Email](1000018713.md).
  - une variable de type [Notification](1000019441.md).
