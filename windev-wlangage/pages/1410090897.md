# PaletteChange (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Modifie la palette utilisée par le projet ou par une fenêtre.
**Remarque** : A partir de la version 2025 Update 2, il est possible de charger une palette en indiquant simplement le nom du fichier correspondant.

## Exemple

```wlangage
PaletteClient est une Palette = PaletteGénère(CouleurClient)
PaletteChange(FEN_Client, PaletteClient)
```

```wlangage
// Syntaxe disponible à partir de la version 2025 Update 2
PaletteChange("Themes\WD\300 Eleven_Palette\Eleven_Palette.wdpalette")
```

## Syntaxe

#### Changer la palette utilisée par le projet ou une fenêtre (variable de type palette)

```wlangage
PaletteChange([<Fenêtre>, ] <Nouvelle palette>)
```

`<Fenêtre>` *Nom de fenêtre*
> Nom de la fenêtre à manipuler. La palette utilisée par cette fenêtre sera remplacée par la palette spécifiée.
> Si ce paramètre n'est pas spécifié, la palette du projet est modifiée. Dans ce cas, toutes les fenêtres du projet sont modifiées.
`<Nouvelle palette>` *Variable de type Palette*
> Nom de la variable de type [Palette](1000021347.md) correspondant à la nouvelle palette qui sera utilisée pour la fenêtre spécifiée ou pour le projet.

#### Changer la palette du projet (fichier de type "wdpalette")

```wlangage
PaletteChange(<Nouvelle palette>)
```

`<Nouvelle palette>` *Chaîne de caractères*
> Chemin complet du fichier ".wdpalette" à utiliser.

**Classification Métier / UI : Code UI**

**Composante : wd300pnt.dll**
