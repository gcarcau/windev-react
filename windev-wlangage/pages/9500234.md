# Description du projet : Onglet Style

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

La fenêtre de description du projet permet de configurer de nombreux éléments de votre projet. Cette fenêtre est constituée des onglets suivants :

- L'onglet ["Projet"](2030046.md) qui permet de saisir les informations générales du projet.
- L'onglet "Analyse" qui permet d'associer une ou plusieurs analyses au projet et / ou un modèle UML.
- L'onglet ["Fichiers de données"](2030052.md) qui permet de saisir différentes informations sur les fichiers de données gérés par l'application (uniquement disponible si le projet est lié au moins à une analyse).
- L'onglet "Live data" qui permet de configurer l'affichage des données (provenant des fichiers de données) sous les différents éditeurs.
- L'onglet ["Langues"](9500219.md) qui permet de paramétrer les différentes langues manipulées par le projet ainsi que les options linguistiques à utiliser pour chaque langue.
- L'onglet **"Style"** qui permet de choisir le gabarit, les palettes, la feuille de styles personnalisée et de personnaliser le visualisateur de rapports. Il est également possible de paramétrer la taille des écrans.
- L'onglet ["Ambiance"](1410087360.md) qui permet de choisir l'ambiance du projet, la palette associée, la feuille de styles et les ressources externes.
- L'onglet ["GDS"](9500239.md) qui permet de gérer le travail en groupe (GDS ou GIT).
- L'onglet ["Options"](9500227.md) qui permet de configurer les options de création, de mise à jour, et de sauvegarde des éléments. Cet onglet permet également de gérer la synchronisation des modèles, d'activer le mode strict et de définir la charte de programmation.
- L'onglet ["Avancé"](9500236.md) qui permet de gérer l'utilisation de "Etats & Requêtes", les FAA et le verrouillage de l'application.
- L'onglet ["Compilation"](9500218.md) qui permet de configurer les options de compilation.
- L'onglet ["Télémétrie"](9500223.md) qui permet de configurer les options de télémétrie pour le projet.
   Cette option n'est pas disponible.

## Onglet Style

### Gabarit du projet
L'onglet "Style" de la fenêtre de description du projet permet de connaître et de définir le gabarit utilisé par le projet.

- **Nom du gabarit utilisé** : Le nom du gabarit utilisé est affiché. Il est possible de modifier le gabarit du projet en déroulant la combo. Une vignette permet de visualiser le look correspondant.
  **Remarque** : Si le gabarit est modifié via la fenêtre de description du projet, cette modification est prise en compte uniquement pour les nouvelles fenêtres créées. Pour appliquer un gabarit sur les fenêtres existantes, sous le volet "Projet", dans le groupe "Autres actions", cliquez sur "Appliquer un gabarit au projet".
- **Appliquer le gabarit aux fenêtres systèmes** :
  - L'option "Fenêtres système Info, OuiNon, Confirmer, Dialogue (pour les configurations WINDEV)" permet de personnaliser les fenêtres d'information système, en utilisant les FAA ou en intégrant directement les fenêtres correspondantes dans le projet. Pour plus de détails, consultez [Personnaliser les fenêtres d'information système (ou boîtes de dialogue)](3021003.md).
  - L'option "Personnaliser les fenêtres système Info, OuiNon, Confirmer, Dialogue (pour les configurations iOS et Android)" permet de personnaliser les fenêtres d'information système. Pour plus de détails, consultez [Personnaliser les fenêtres d'information système (ou boîtes de dialogue)](3021003.md).
  - L'option "Appliquer le thème de gabarit sur les composants intégrés dans le projet et sur les fenêtres des FAA" permet d'utiliser le thème du gabarit du projet sur tous les éléments intégrés dans le projet : composants, fenêtres spécifiques des FAA, etc.
  - L'option "Autoriser le passage en thème sombre (automatique ou manuellement via la fonction ChangeThème)" permet de gérer le thème sombre automatiquement dans vos applications mobile. Pour plus de détails, consultez [Gestion du thème sombre mobile](1000025338.md).
- **Gestion du look de la bulle d'aide**: L'option "Bulle d'aide" permet de définir le mode d'affichage des bulles d'aide de votre application. Par défaut, le mode d'affichage est "Standard". Il est possible de personnaliser les bulles d'aide de l'application. Pour plus de détails, consultez [Bulles d'aide personnalisées](9500233.md).

Nouveauté 2025

> _(WINDEV, WINDEV Mobile)_ PalettesLors de l'utilisation d'un gabarit avec palette, la palette est automatiquement associée au projet. Il est possible d'associer plusieurs palettes à un même projet. Le bouton permet d'ouvrir la fenêtre de sélection de palettes :

 Il suffit de sélectionner la palette à ajouter dans le projet. Le bouton permet de définir la palette par défaut. La palette par défaut correspond à la première palette de la liste des palettes. Pour plus de détails sur les palettes de couleurs, consultez Palettes de couleurs.

> _(WINDEV)_ Visualisateur de rapportsLe visualisateur de rapports permet à l'utilisateur final d'une application WINDEV de visualiser les états avant de les imprimer. Ce visualisateur de rapports peut être personnalisé pour suivre le look de votre application. Pour plus de détails, consultez Personnalisation du visualisateur de rapports (aperçu).

### Feuilles de styles
Cette option permet de sélectionner la ou les feuilles de styles associées au projet.

> _(WINDEV)_ Taille de fenêtres à leur créationCette option permet de sélectionner la taille qui sera proposée par défaut lors de la création des fenêtres sous l'éditeur de fenêtres.
