# Emission (Propriété)

> **Disponible :** **WINDEV** (Windows)

La propriété **Emission** permet de connaître et modifier le type des données sortantes transférées par le flux.
Par défaut, les données sortante transférées par un flux sont de type son et vidéo.

**Attention** : La transmission en cours n'est pas modifiée. Les changements effectués par cette propriété seront pris en compte uniquement lors de la prochaine connexion.

## Exemple

```wlangage
// Gère uniquement le son
MonFlux.Emission = FluxSon
MonFlux.Adresse = "123.123.123"
```

## Syntaxe

#### Connaître le type de données sortantes transférées par le flux

```wlangage
<Résultat> = <Nom du flux>.Emission
```

`<Résultat>` *Constante ou combinaison de constantes de type entier*
> Type de données sortantes transférées actuellement par le flux :
>
>
> | *FluxSon* | Les données sortantes de type Son sont transférées. |
> | --- | --- |
> | *FluxVidéo* | Les données sortantes de type Vidéo sont transférées. |
`<Nom du flux>` *Chaîne de caractères*
> Nom du Flux ou nom du champ Conférence associé au flux.

#### Modifier le type de données sortantes transférées par le flux

```wlangage
<Nom du flux>.Emission = <Nouveau type de données>
```

`<Nom du flux>` *Chaîne de caractères*
> Nom du Flux ou nom du champ Conférence associé au flux.
`<Nouveau type de données>` *Constante ou combinaison de constantes de type Entier*
> Nouveau type de données sortantes à transférer par le flux. Cette modification sera prise en compte uniquement lors de la prochaine connexion.
>
>
> | *FluxSon* | Les données sortantes de type Son sont transférées. |
> | --- | --- |
> | *FluxVidéo* | Les données sortantes de type Vidéo sont transférées. |
