# AffichageLED (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android)

La propriété **AffichageLED** permet de gérer l'affichage de la LED lors de l'affichage des notifications. Cette propriété est utilisable sur :

- une variable de type [Notification](1000019441.md).
- une variable de type [notificationCatégorie](1000023981.md).
