# Programmation des attributs des zones répétées (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Il est possible de manipuler tous les attributs des champs Zone répétée par programmation.
> _(WEBDEV - Code Navigateur)_ En code navigateur, seuls les types d'attributs suivants sont manipulables : Attribut sur un interrupteurIl est uniquement possible de manipuler un attribut sur la valeur de l'interrupteur (lecture et modification).Attribut sur un libelléAucune manipulation possible par programmation.Attribut sur un lienAucune manipulation possible par programmation.Attribut sur un sélecteurIl est uniquement possible de manipuler un attribut sur la valeur du sélecteur (lecture et modification).Attribut sur une image ou une image cliquableIl est uniquement possible de manipuler un attribut sur la valeur de l'image associée au champ (lecture et modification).
