# <Chrono>.RAZ (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Arrête et remet un chronomètre existant à zéro. La valeur de la durée écoulée est perdue.
Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Les variables de type Chrono sont désormais disponibles en code navigateur. La syntaxe manipulant les variables de type Chrono devient également disponible.

## Exemple

```wlangage
MonChrono est un Chrono
...
// -- Code de clic du bouton BTN_Reinit
...
// Réinitialise le chronomètre MonChrono
MonChrono.RAZ()
```

## Syntaxe

```wlangage
<Chronomètre>.RAZ()
```

`<Chronomètre>` *Variable de type Chrono*
> Nom de la variable de type [Chrono](1000023560.md) correspondant au chronomètre à utiliser.

## Remarques

### Erreur
Si la fonction [<Chrono>.Début](1000023788.md) n'a pas été appelée avant la fonction **<Chrono>.RAZ**, une erreur WLangage est affichée (erreur de type "le chronomètre n'est pas démarré").

**Composante : wd300vm.dll**
