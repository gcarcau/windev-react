# <Type DateHeure>.VersRéel (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Convertit une date et une heure en un réel sur 8 octets. Ce réel correspond :

- soit au numéro du jour depuis le 1er janvier 1900 (compatible Excel, commence à 1).
- soit au numéro du jour depuis le 1er janvier 1904 (compatible Excel avec l'option "Utiliser le calendrier depuis 1904", commence à 0).

Remarque : L'option "Utiliser le calendrier depuis 1904" est configurable dans les options avancées de MS Excel. Sous Open Office, cette option est disponible dans les options de Open Office Calc (rubrique "Calculer", option "Date").

## Exemple

```wlangage
MonJour est une DateHeure
MonJour = "190001030600"
// Affiche "3.25"
Info(MonJour.VersRéel())
```

## Syntaxe

```wlangage
<Résultat> = <DateHeure à convertir>.VersRéel([<Depuis 1904>])
```

`<Résultat>` *Réel*
> - Numéro du jour correspondant à la variable de type DateHeure passée en paramètre.
> - -1 en cas d'erreur (date et heure invalides).
`<DateHeure à convertir>` *Variable de type DateHeure*
> Valeur de la date et de l'heure à convertir. Ce paramètre peut correspondre à :
>
> - une variable de type DateHeure.
> - une chaîne de caractères au format :
>   - AAAAMMJJHHmmSSCCC
>   - AAAAMMJJHHmmSSCC
>   - AAAAMMJJHHmmSS
>   - AAAAMMJJHHmm
>   - AAAAMMJJHH
>   - AAAAMMJJ
`<Depuis 1904>` *Booléen optionnel*
> Mode de calcul :
>
> - Vrai si la date est calculée à partir de 1904.
> - Faux (valeur par défaut) si la date est calculée à partir de 1900.

## Remarques

### Mode de calcul
La partie entière du résultat donne le numéro du jour de la partie date du paramètre :

- la numérotation commence à 1 pour le 01/01/1900.
- la numérotation commence à 0 pour le 01/01/1904 si le paramètre <Depuis 1904> vaut Vrai.

La partie décimale donne la fraction de jour de la partie heure du paramètre (par exemple 06h00 donne une partie décimale de 0.25).
Toute conversion de type peut engendrer une perte de précision.

### Dates/heures valides
Le paramètre <DateHeure à convertir> est considéré invalide :

- si la date est invalide ou antérieure à la date de début de numérotation. La date doit être comprise entre le 01/01/1900 ou 01/01/1904 et le 31/12/999. La validité de la date peut être vérifiée avec la fonction [DateValide](3027003.md).
- si l'heure est invalide. La validité de l'heure peut être vérifiée avec la fonction [HeureValide](3027021.md).
