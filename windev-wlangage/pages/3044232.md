# HListeProvider (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Renvoie la liste des providers OLE DB et/ou des Connecteurs Natifs installés sur le poste en cours.

## Exemple

```wlangage
// Récupérer la liste des Connecteurs Natifs
sListeCN est une chaîne
sCNExtrait est une chaîne
sDescription est une chaîne
nIndice est un entier = 1
sListeCN = HListeProvider()
BOUCLE
	// Extraire chaque Connecteur Natif
	sCNExtrait = ExtraitChaîne(sListeCN, nIndice, RC)
	sDescription = ExtraitChaîne(sCNExtrait, 1, TAB)
	sCNExtrait = ExtraitChaîne(sCNExtrait, 2, TAB)
	SI sCNExtrait = EOT ALORS SORTIR
	// Ajouter le Connecteur Natif dans le champ Combo
	ListeAjoute(COMBO_ChFournisseur, sDescription + gValeurMémorisée(sCNExtrait))
	nIndice++
FIN
```

## Syntaxe

```wlangage
<Résultat> = HListeProvider()
```

`<Résultat>` *Chaîne de caractères*
> Liste des providers et/ou des Connecteurs Natifs (également appelées Accès Natifs) trouvés sous la forme:
>
>
> ```wlangage
> <Description du provider 1> + TAB + <Nom du provider 1> + <RC> +...<Description du provider n> + TAB + <Nom du provider n> + <RC>
> ```
>
>
> où
>
> - <Description du provider> correspond :
>   - soit au nom générique du provider (Excel 2000 par exemple).
>   - soit au nom du Connecteur Natif.
>   - soit à une description extraite de la base de registre.
> - <Nom du provider> correspond à la constante identifiant le provider OLE DB ou Connecteur Natif. Cet identifiant peut être utilisé dans les fonctions HFSQL ([HOuvreConnexion](3044107.md), [HDécritConnexion](3044205.md), ...).

## Remarques

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Windows, Linux, Code Utilisateur (MCU), Ajax, Connecteurs Natifs (Accès Natifs))_ Connecteur natif SQL ServerLa fonction HListeProvider prend en compte la valeur de la variable H.ModeSQLServer. En mode par défaut, si un des deux Connecteurs Natifs SQL Server est installé sur le poste, le Connecteur Natif SQL Server sera listé.Si l'ancien Connecteur Natif est forcé (H.ModeSQLServer=2) et n'est pas présent sur le poste, le Connecteur Natif SQL Server ne sera pas listé.Si le nouveau Connecteur Natif est forcé (H.ModeSQLServer=0) et n'est pas présent sur le poste, le Connecteur Natif SQL Server ne sera pas listé.
