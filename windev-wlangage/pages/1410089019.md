# IBANValide (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un IBAN (International Bank Acount Number).
Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.

## Exemple

```wlangage
// Test d'une variable
MonCompteIBAN est une chaîne = "FR7630006000011234567890189"
IBANValide(MonCompteIBAN) // Renvoie Vrai

// Test d'un champ
SAI_CompteIBAN = "ABC"
IBANValide(SAI_CompteIBAN) // Renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = IBANValide(<IBAN à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un IBAN valide.
> - Faux dans le cas contraire.
`<IBAN à vérifier>` *Nom de champ ou variable de type chaîne*
> IBAN à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.

**Composante : wd300std.dll**
