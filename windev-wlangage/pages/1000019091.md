# saasTarification (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

Le type **saasTarification** permet de définir toutes les caractéristiques avancées d'une tarification SaaS.
Les caractéristiques de cette tarification peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
MonSite est un saasSite dynamique
MonSite = SaaSAdminChercheSite("Gestion de voitures")

T est une saasTarification
T.Nom = "Offre Premium"
T.Prix = 150
SaaSAdminAjouteTarification(T, MonSite)

S est un saasService
S.Nom = "Accès Complet"

// Ajoute le service dans le site
SaaSAdminAjouteService(T, MonSite)

// La tarification proposera ce service
SaaSAdminActiveService(T, S)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type saasTarification
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **saasTarification** :

| **Nom** | **Type** | **Effet** |
| --- | --- | --- |
| Facturation | Constante de type Entier | Indique si la tarification est par utilisateur ou au forfait. Les constantes suivantes sont disponibles :   - *saasFacturationForfaitaire* : La tarification est facturée au forfait - *saasFacturationParUtilisateur* : La tarification est facturée par utilisateur |
| Nom | Chaîne de caractères | Nom de la tarification. Ce nom doit être unique pour chaque Site. |
| Périodicité | Entier ou Constante de type Entier | Durée d'une période de facturation. Cette durée est exprimée en nombre de jours. La constante *saasPériodicitéIllimitée* permet d'indiquer une tarification sur une période illimitée. |
| Prix | Monétaire | Coût de la tarification. Si la tarification est facturée par période ce prix concerne une période. |
| Site | Variable de type [saasSite](1000019068.md) | Référence vers le site qui offre cette tarification. Cette propriété est accessible en lecture seulement. |
