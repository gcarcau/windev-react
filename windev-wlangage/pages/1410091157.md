# PDFChampInfoXY (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android)

Renvoie les caractéristiques du champ formulaire actuellement survolé dans un champ Lecteur PDF.
Nouveauté Abonnement
Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
// Récupération de la page et de la position de la souris en mm dans le document pdf
num_page est un entier = LecteurPDFInfoXY(MoiMême, pdfNuméroPage, SourisPosX(), SourisPosY())
X est un réel = LecteurPDFInfoXY(MoiMême, pdfCoordonnéeX, SourisPosX(), SourisPosY())
Y est un réel = LecteurPDFInfoXY(MoiMême, pdfCoordonnéeY, SourisPosX(), SourisPosY())
// Gestion du cas ou la souris est en dehors du document
SI num_page = -1 ALORS
	Info("Aucune page à cette position")
	RETOUR
FIN
// Récupération du champ formulaire à la position trouvée
doc_pdf est un pdfDocument = MoiMême
champ_formulaire est un pdfChamp = PDFChampInfoXY(doc_pdf.Page[num_page], X, Y)
SI champ_formulaire.Nom = "" ALORS
	Info("Il n'y a aucun champ du formulaire à cette position")
SINON
	Info(champ_formulaire.Nom + " = " + champ_formulaire.Valeur)
FIN
```

## Syntaxe

```wlangage
<Résultat> = PDFChampInfoXY(<Page> , <X> , <Y>)
```

`<Résultat>` *Variable de type pdfChamp*
> Variable de type [pdfChamp](1410090536.md) contenant les caractéristiques du champ survolé : nom, coordonnées, largeur et hauteur, valeur, etc.
`<Page>` *Variable de type pdfPage*
> Nom de la variable de type[pdfPage](1000024904.md)correspondant à la page contenant le champ.
`<X>` *Réel*
> Coordonnée X (en millimètres) à analyser. Cette coordonnée est exprimée par rapport au champ.
`<Y>` *Réel*
> Coordonnée Y (en millimètres) à analyser. Cette coordonnée est exprimée par rapport au champ.

**Composante : wd300pdf.dll**
