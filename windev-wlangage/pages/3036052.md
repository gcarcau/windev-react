# fRepWeb (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux, PHP)

Renvoie le nom physique complet du répertoire contenant les images, les fichiers Javascript et Java du site WEBDEV. Ce répertoire correspond au répertoire <Nom du projet>_WEB. Ce répertoire est présent sur le poste de développement et sur le poste de déploiement.
Il est ainsi possible de lire, d'écrire ou de modifier les fichiers présents dans ce répertoire.

**Avertissement**

 Les écritures et les modifications peuvent être effectuées sur le poste de développement.
**Sur le serveur de déploiement**, les écritures et modifications seront possibles uniquement si l'hébergeur accepte de donner les droits d'écriture (problèmes de sécurité).

> _(PHP)_ Renvoie le nom physique complet du répertoire contenant la page PHP en cours d'exécution, les images, les fichiers Javascript et Java du site WEBDEV. Ce répertoire correspond au sous-répertoire de la langue du répertoire <Nom du projet>_WEB. Ce répertoire est présent sur le poste de développement et sur le poste de déploiement.

Remarque : Pour atteindre le répertoire "<Nom projet>_WEB", il est possible d'utiliser :

- la fonction [RépertoireWeb](3012015.md) : cette fonction renvoie un chemin relatif destiné à être interprété par le navigateur.
- la fonction **fRepWeb** : cette fonction renvoie un chemin absolu à utiliser depuis le serveur avec les [fonctions de gestion des fichiers externes (fxxx)](3036034.md).

## Exemple

```wlangage
// Répertoire de lancement
Info("Fichiers images présents dans le répertoire : " + fRepWeb())
```

## Syntaxe

```wlangage
<Résultat> = fRepWeb()
```

`<Résultat>` *Chaîne de caractères*
> Nom physique complet du répertoire contenant les images, les fichiers Javascript et Java du site WEBDEV. Ce résultat est de la forme "C:\Mes Projets\Planning\Planning_WEB". Il n'y a pas de caractère "\" à la fin de ce résultat.
> > _(PHP)_ Nom physique complet du répertoire contenant la page PHP, les images, les fichiers Javascript et Java du site WEBDEV. Ce résultat est de la forme "C:\Mes Projets\Planning\Planning_WEB\FR". Il n'y a pas de caractère "\" à la fin de ce résultat.

**Composante : wd300page.dll**
