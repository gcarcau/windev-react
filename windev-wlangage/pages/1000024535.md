# <Variable Document>.RedoOccurrence (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Renvoie le nombre d'actions annulées qui peuvent être refaites sur une variable de type [Document](1000022461.md).

## Exemple

```wlangage
MonDocument est un Document

// Affiche le nombre d'actions annulées et qui peuvent être refaites
Info(MonDocument.RedoOccurrence())
```

## Syntaxe

```wlangage
<Résultat> = <Document>.RedoOccurrence()
```

`<Résultat>` *Entier*
> Nombre d'actions annulées qui peuvent être refaites.
`<Document>` *Variable de type Document*
> Nom de la variable de type [Document](1000022461.md) à manipuler.

**Classification Métier / UI : Code UI**

**Composante : wd300mdl.dll**
