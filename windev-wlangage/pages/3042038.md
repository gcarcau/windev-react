# grNuageEtiquetteSérie (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Initialise l'étiquette d'une série de données dans un graphe de type "Nuage de points".
Exemple d'étiquette de série : [image: Etiquette de série]

**Rappel** : Par défaut, un graphe n'a aucune étiquette.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

Nouveauté Abonnement

> _(Android)_ Cette fonction est désormais disponible pour les applications Android.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
// Initialise l'étiquette "Vente" de la série de données 2 dans le graphe "MonGraphe"
grNuageEtiquetteSérie("MonGraphe", 2, "Vente")
```

```wlangage
// Initialise l'étiquette "Achat" de la série de données 3 dans le champ GRF_MonGraphe
grNuageEtiquetteSérie(GRF_MonGraphe, 3, "Achat")
```

## Syntaxe

```wlangage
grNuageEtiquetteSérie(<Nom du graphe> , <Numéro de la série> , <Étiquette>)
```

`<Nom du graphe>` *Nom de champ ou chaîne de caractères*
> Nom du graphe à manipuler. Ce nom correspond :
>
> - soit au nom du graphe défini par programmation avec la fonction [grCrée](3042005.md).
> - soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.
>
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Numéro de la série>` *Entier*
> Numéro de la série pour laquelle une étiquette doit être initialisée.
`<Étiquette>` *Chaîne de caractères*
> Libellé de l'étiquette à initialiser.

## Remarques

- Il est possible de modifier la police de l'étiquette grâce à la fonction [grPoliceEtiquette](3042012.md).
- Les données définies avec la fonction **grNuageEtiquetteSérie** seront prises en compte lors du prochain appel à la fonction [grDessine](3042026.md).
- La fonction **grNuageEtiquetteSérie** est équivalente à la fonction [grEtiquetteSérie](3042024.md).
  La syntaxe de [grEtiquetteSérie](3042024.md) utilisée avec des graphes de type "Nuage de points" est la suivante :
  ```wlangage
  grEtiquetteSérie(<Nom graphe>, 2*<Indice>-1, <Étiquette>)
  ```
  **Rappel** : Un graphe de type "Nuage de points" utilise les données par groupe de deux séries (pour plus de détails, consultez la fonction [grNuageAjouteDonnéeXY](3042032.md)).

**Composante : wd300grf.dll**
