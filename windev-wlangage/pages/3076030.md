# telRaccroche (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Raccroche une ligne téléphonique ouverte avec la fonction [telCompose](3076013.md) ou par la fonction [telRépondAppel](3076026.md).

## Exemple

```wlangage
SI telCompose(SAI_NuméroTéléphone, "EtatLigne") = Vrai ALORS
	Info("Cliquez sur OK pour raccrocher")
	telRaccroche()
FIN
```

## Syntaxe

#### Raccrocher une ligne ouverte par la fonction telCompose

```wlangage
telRaccroche()
```

#### Raccrocher une ligne ouverte par la fonction telRépondAppel

```wlangage
telRaccroche(<Identifiant de l'appel>)
```

`<Identifiant de l'appel>` *Entier*
> Identifiant de l'appel à terminer. Cet identifiant est connu dans la procédure WLangage appelée par la fonction [telRépondAppel](3076026.md).

## Remarques

### Limitation
Il n'est pas possible d'appeler la fonction **telRaccroche** dans la procédure de détection d'appels (définie grâce à la fonction [telDémarreDétectionAppel](3076029.md)).

### Configuration nécessaire
Les fonctions de téléphonie utilisent la technologie TAPI 2.0 et/ou la technologie TAPI 3.1. Ces technologies sont utilisables sur tous les systèmes.

**Composante : wd300com.dll**
