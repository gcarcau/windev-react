# Ecran,Premier (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Indique le nom du premier champ en saisie ou le nom du champ suivant devant être en saisie.

## Exemple

```wlangage
// En C// Le prochain champ sera NOMCLIAPPELWD("Ecran,Premier,NOMCLI");
```

```wlangage
// En Pascal(* Le prochain champ sera NOMCLI *APPELWD('Ecran,Premier,NOMCLI');
```

```wlangage
// En VB' Le prochain champ sera NOMCLIcall APPELWD("Ecran,Premier,NOMCLI")
```

## Syntaxe

```wlangage
Ecran,Premier(<Nom du champ> [, <Indice>])
```

`<Nom du champ>` *Chaîne de caractères*
> Nom du champ dans lequel le texte doit être affiché.
`<Indice>` *Chaîne de caractères (optionnelle)*
> Indice du champ.

## Remarques

Dans le cas d'une table, la ligne de la table à saisir doit être sélectionnée au préalable.

Exemple :
```wlangage
Table,Select,+,<Nom de la table>,<Indice de la ligne>Ecran,Premier,<Nom de la colonne>
```
