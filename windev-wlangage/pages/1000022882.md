# <Agenda>.SelectMoins (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Mac Catalyst)

Désélectionne un rendez-vous dans un champ Agenda.

## Exemple

```wlangage
// Ajout d'un rendez-vous dans un champ Agenda
nRangRendezVous est un entier
nRangRendezVous = AGD_MonAgenda.AjouteRendezVous(...
				"Réunion équipe commerciale", ...
				DateSys() + "1400", DateSys() + "1600")
// Sélection du rendez-vous ajouté
AGD_MonAgenda.SelectPlus(nRangRendezVous)
...
// Clic sur le champ Bouton "Désélectionner"
AGD_MonAgenda.SelectMoins()
```

## Syntaxe

#### Désélectionner un rendez-vous identifié par son indice

```wlangage
<Champ Agenda>.SelectMoins([<Indice du rendez-vous>])
```

`<Champ Agenda>` *Nom de champ*
> Nom du champ Agenda à manipuler. Ce champ peut correspondre :
>
> - au champ Agenda d'une fenêtre.
> - au champ Agenda d'une page.
`<Indice du rendez-vous>` *Entier optionnel*
> Indice du rendez-vous à désélectionner. Les indices des rendez-vous commencent à 1.
> Si ce paramètre n'est pas précisé, le rendez-vous actuellement sélectionné est désélectionné.
> Si ce paramètre est précisé et ne correspond pas à l'indice du rendez-vous actuellement sélectionné dans le champ Agenda, la fonction est sans effet.

> _(WINDEV, iPhone/iPad)_ Désélectionner un rendez-vous identifié par une variable de type RendezVous Masquer les détails
<Champ Agenda>.SelectMoins([<Rendez-vous à désélectionner>])

 <Champ Agenda> : Nom de champNom du champ Agenda à manipuler (champ d'une fenêtre). <Rendez-vous à désélectionner> : Variable de type RendezVous optionnelleNom de la variable de type RendezVous correspondant au rendez-vous à désélectionner. Si ce paramètre n'est pas précisé, le rendez-vous actuellement sélectionné est désélectionné.Si ce paramètre est précisé et ne correspond pas au rendez-vous actuellement sélectionné dans le champ Agenda, la fonction est sans effet.
