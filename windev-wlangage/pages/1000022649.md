# <Variable Connexion>.ChargeParamètre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Lit un paramètre précédemment sauvegardé à partir d'une procédure stockée grâce à la fonction [<Variable Connexion>.SauveParamètre](1000022753.md).

## Exemple

```wlangage
// Description de la connexion
MonParamètre est une Connexion

MonParamètre.ChargeParamètre()
```

#### Chargement d'un paramètre sur le serveur (depuis le poste Client)

```wlangage
<Résultat> = <Connexion>.ChargeParamètre(<Paramètre> , <Valeur par défaut>)
```

`<Résultat>` *Variant*
> Valeur du paramètre si celui-ci existe, <Valeur par défaut> si le paramètre n'existe pas.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion à manipuler.
`<Paramètre>` *Chaîne de caractères*
> Nom du paramètre à restaurer. Ce paramètre ne doit pas correspondre à une chaîne vide et ne doit pas contenir le caractère "RC" (Retour Chariot).
`<Valeur par défaut>` *Variant*
> Valeur par défaut renvoyée si le paramètre n'est pas trouvée. Si ce paramètre n'est pas précisé, la valeur par défaut correspond à une chaîne vide ("").
