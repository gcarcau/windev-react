# EnModeAWP (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Permet de savoir si la page en cours d'exécution est une page AWP.

Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.

## Exemple

```wlangage
// Code exécuté depuis une page AWP ?
SI EnModeAWP() = Vrai ALORS
	// Mode AWP
	// Traitements à effectuer
	...
SINON
	// Mode non AWP
	// Traitements à effectuer
	...
FIN
```

## Syntaxe

```wlangage
<Résultat> = EnModeAWP()
```

`<Résultat>` *Booléen*
> - Vrai si la page exécutée est une page AWP WEBDEV,
> - Faux dans tous les autres cas.

## Remarques

### Disponibilité de la fonction
La fonction **EnModeAWP** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **EnModeAWP** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
