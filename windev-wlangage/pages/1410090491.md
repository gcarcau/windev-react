# Commande (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU))

Le type **Commande** permet de définir toutes les caractéristiques avancées d'une commande pour un exécutable en mode "console". Les caractéristiques de cette commande à exécuter peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Exécution de la commande 'C:\Chemin\MonProgramme.exe -opt1=val1'

// Définition de la commande
MaCommandeAExécuter est une Commande
// Exécutable à lancer
MaCommandeAExécuter = "C:\Chemin\MonProgramme.exe"
// Arguments à passer à l'exécutable
MaCommandeAExécuter.Arguments = "Argument1"
// Activation des flux
MaCommandeAExécuter.Flux = cmdEntréeStandard + cmdSortieStandard
// Ajout d'un argument à la ligne de commande
CmdAjouteArgument(MaCommandeAExécuter, "Argument2")
// Ajout d'une option à la ligne de commande
CmdAjouteOption(MaCommandeAExécuter, "opt1", "val1")

// Exécution de la commande
CmdExécute(MaCommandeAExécuter, Faux)
// Écriture dans l'entrée standard (possible car le flux est actif)
CmdEcritEntréeStandard(MaCommandeAExécuter, "Test Ecriture" + RC)
// Récupération du code de retour de la commande
code est un entier = CmdRécupèreCodeRetour(MaCommandeAExécuter, Vrai)
// Lecture dans la sortie standard (possible car le flux est actif)
stdout est une chaîne = CmdLitSortieStandard(MaCommandeAExécuter)
// Lecture dans la sortie d'erreur (impossible car le flux n'est pas activé)
// Message d'erreur : Le flux 'STDERR' n'est pas activé.
stderr est une chaîne = CmdLitSortieErreur(MaCommandeAExécuter)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type Commande
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **Commande** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Arguments | Chaîne de caractères | Arguments à passer à la commande.  Le contenu de cette propriété remplace tous les arguments et options précédemment définis. |
| DestructionAutomatique | Booléen | - Vrai (valeur par défaut) : l'exécutable associé à la commande s'arrête si la variable est détruite ou remise à zéro. - Faux : l'exécutable associé à la commande continue de s'exécuter même si la variable est détruite ou remise à zéro.   Remarque : Il est possible de forcer l'arrêt de l'exécutable associé à une commande via la fonction [CmdTermine](1410091013.md).   **Attention** : Cette propriété est disponible uniquement à partir de la version 2025 Update 1. |
| Exécutable | Chaîne de caractères | Chemin vers l'exécutable associé à la commande. |
| Flux | Constante de type Entier | Flux à activer :   - *cmdEntréeStandard* : Flux d'entrée standard (StdIn). - *cmdSortieErreur* : Flux d'erreur standard (StdErr). - *cmdSortieStandard* : Flux de sortie standard (StdOut).  Par défaut, tous les flux sont activés. |
| ID | Entier | Identifiant du processus lancé (Handle ou pid). **Cette propriété est disponible uniquement en lecture.** |
| RedirigeStdErrDansStdOut | Booléen | - Vrai pour rediriger le flux STDERR dans STDOUT.   Attention : les flux STDOUT et STDERR doivent être actifs. - Faux dans le cas contraire. |

## Remarques

### Fonctions manipulant des variables de type Commande

| Nouveauté 2025 [CmdAjouteArgument](1410090501.md) | Ajoute un argument à une commande à exécuter en mode console. |
| --- | --- |
| Nouveauté 2025 [CmdAjouteOption](1410090502.md) | Ajoute une option à la commande à exécuter en mode console. |
| Nouveauté 2025 [CmdEcritEntréeStandard](1410090503.md) | Ecrit les données sur l'entrée standard de la commande exécutée en mode console. |
| Nouveauté 2025 [CmdExécute](1410090500.md) | Exécute une commande en mode console. |
| Nouveauté 2025 [CmdExécutionEstEnCours](1410091011.md) | Indique si l'exécutable lié à une commande exécutée en mode console est actuellement en cours d'exécution.  **Attention** : Cette fonction est disponible uniquement à partir de la version 2025 Update 1. |
| Nouveauté 2025 [CmdLitSortieErreur](1410090505.md) | Lit les données disponibles sur la sortie d'erreur pour la commande lancée en mode console. |
| Nouveauté 2025 [CmdLitSortieStandard](1410090504.md) | Lit les données disponibles sur la sortie standard pour la commande lancée en mode console. |
| Nouveauté 2025 [CmdRécupèreCodeRetour](1410090506.md) | Récupère le code de retour de la commande lancée en mode console, c'est-à-dire la valeur renvoyée à la terminaison de la commande. |
| Nouveauté 2025 [CmdTermine](1410091013.md) | Force la terminaison de l'exécutable associé à une commande en mode console en cours d'exécution. **Attention** : Cette fonction est disponible uniquement à partir de la version 2025 Update 1. |
