# UUEncode (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Encode une chaîne de caractères selon l'algorithme UUEncode. Cette chaîne encodée pourra ensuite être décodée avec la fonction [UUDécode](1000018864.md).

## Exemple

```wlangage
// Encodage d'une chaîne
Res = UUEncode("Le numéro de mon compte est 0123456789")
```

## Syntaxe

```wlangage
<Résultat> = UUEncode(<Chaîne à encoder>)
```

`<Résultat>` *Chaîne de caractères*
> Chaîne encodée selon l'algorithme UUEncode.
`<Chaîne à encoder>` *Chaîne de caractères*
> Texte à encoder.

**Composante : wd300std.dll**
