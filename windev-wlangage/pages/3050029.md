# Exp (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Calcule l'exponentielle (inverse du logarithme népérien) d'une valeur numérique.

## Exemple

```wlangage
// Calcul de l'exponentielle de 5
ResExponentielle = Exp(5)
// Renvoie 148.413159103
```

## Syntaxe

```wlangage
<Résultat> = Exp(<Valeur numérique>)
```

`<Résultat>` *Réel*
> Exponentielle recherchée.
`<Valeur numérique>` *Entier ou réel*
> Valeur numérique à manipuler.

**Composante : wd300mat.dll**
