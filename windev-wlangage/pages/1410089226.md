# EtatsUnis.VérifieEIN (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un numéro EIN (numéro d'identification d'entreprise aux Etats-Unis).

## Exemple

```wlangage
// Test d'une variableMonNuméroEIN est une chaîne = "322124444"EtatsUnis.VérifieEIN(MonNuméroEIN) // renvoie Vrai // Test d'un champSAI_NuméroEIN = "ABC"EtatsUnis.VérifieEIN(SAI_NuméroEIN) // renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = EtatsUnis.VérifieEIN(<Numéro à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un numéro EIN valide.
> - Faux dans le cas contraire.
`<Numéro à vérifier>` *Nom de champ ou variable de type chaîne*
> Numéro EIN à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.

**Composante : wd300std.dll**
