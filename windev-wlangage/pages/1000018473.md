# DernièreDateCouverte (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

La propriété **DernièreDateCouverte** permet de connaître la date du dernier enregistrement sélectionné. Cette propriété est utilisable sur :

- une variable de type [sfRésultatRechercheModifié](1000018561.md).
- une variable de type [sfRésultatRechercheSupprimé](1000018562.md).
