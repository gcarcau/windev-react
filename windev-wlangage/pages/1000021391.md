# Fonctions de gestion des champs Onglet

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU))

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des champs Onglet (syntaxe préfixée)](1000021709.md)).
Les fonctions permettant de manipuler les champs Onglet sont les suivantes :

| [OngletChargeConfiguration](1000021370.md) | Restaure la configuration des volets dynamiques d'un champ Onglet. |
| --- | --- |
| [OngletDuChamp](3025028.md) | Renvoie le nom du champ Onglet qui contient le champ spécifié. |
| [OngletEtat](1000021637.md) | Renvoie l'état d'un volet d'onglet dynamique (identifié par son alias). |
| [OngletFerme](1000021362.md) | Ferme un volet dynamique dans un champ Onglet. |
| [OngletFermeTout](1000021372.md) | Ferme tous les volets dynamiques d'un champ Onglet. |
| [OngletOuvre](1000021369.md) | Ouvre un nouveau volet dans un champ Onglet dynamique. |
| [OngletSauveConfiguration](1000021371.md) | Sauvegarde la configuration des volets dynamiques d'un champ Onglet sous forme d'une chaîne de caractères. |
| [VoletDuChamp](1000021625.md) | Renvoie le nom du volet (statique ou dynamique) d'un champ Onglet associé à un champ. |
