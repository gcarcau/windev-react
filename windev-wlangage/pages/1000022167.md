# Existe (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Apple Watch)

La propriété **Existe** permet de savoir si un élément d'un tableau associatif existe ou non.

## Exemple

```wlangage
// Tableau associatif d'entiers // indexé sur des chaînes et avec doublonstaIDParClient est un tableau associatif d'entiers// Ajout de l'identifiant du client "A"taIDParClient["A"] = 55// Ajout de l'identifiant du client "B" taIDParClient["B"] = 321 SI taIDParClient["A"]..Existe = Vrai ALORS  Info("Il existe au moins un élément A")FIN
```

## Syntaxe

```wlangage
<Résultat> = <Elément manipulé>.Existe
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié existe (n'est pas vide),
> - Faux dans le cas contraire.
`<Elément manipulé>` *Elément d'un tableau associatif*
> Nom de l'élément à manipuler (élément d'un tableau associatif).

## Remarques

La propriété **Existe** permet de savoir si un élément d'un tableau associatif existe ou non.

- Dans le cas d'un tableau associatif sans doublons, la propriété **Existe** est à Vrai si l'élément existe.
- Dans le cas d'un tableau associatif avec doublons, la propriété **Existe** est à Vrai si au moins un élément existe.
