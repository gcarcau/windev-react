# HFermeConnexion (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Ferme une connexion à une base de données. Tous les fichiers de données utilisant cette connexion sont fermés.

## Exemple

```wlangage
// Décrire et ouvrir la nouvelle connexion
HDécritConnexion("MaConnexion", "", "", "Serveur_SQLServer", ...
	"dbo", hODBC, hOLectureEcriture, "")
HOuvreConnexion("MaConnexion")

// Indiquer que "Salaires" utilise la nouvelle connexion
HChangeConnexion("Salaires", "MaConnexion")

// Commencer le parcours de la table "Salaires" sur SQLServer
HLitPremier("Salaires")
...

// Fermer la connexion
HFermeConnexion("MaConnexion")
```

## Syntaxe

```wlangage
<Résultat> = HFermeConnexion(<Connexion>)
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion à une base de données. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
>
>
> > _(PHP)_ Ce paramètre doit correspondre au nom de la connexion entre guillemets. Il n'est pas possible d'utiliser une variable de type Connexion.

## Remarques

La description de la connexion doit être connue au moment de l'exécution de la fonction **HFermeConnexion**.

**Composante : wd300hf.dll**
