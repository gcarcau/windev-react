# Résultat d'une requête en mode test

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Après son exécution en mode test (voir [Test d'une requête](2019011.md)), le résultat de la requête peut ensuite au choix être :

- exporté vers un fichier texte (Word ou Open Office).
- exporté vers un fichier XML.
- exporté vers un fichier tableur (Excel ou Open Office).
- exporté vers un fichier de données HFSQL.
- imprimé.

Il est également possible de copier un enregistrement du résultat de la requête dans le presse-papiers.

## Exporter le résultat vers un fichier texte

Pour l'opération suivante, nous considérons que le résultat de la requête est affiché.
Pour exporter le résultat de la requête vers un fichier texte :

1. Affichez le menu contextuel (clic droit) du résultat de la requête.
2. Sélectionnez l'option "Autres fonctionnalités automatiques (FAA) .. Exporter la table vers Word" (ou l'option "Exporter la table vers OpenOffice.org Writer"). La fenêtre de sélection du fichier "RTF" s'affiche.
3. Spécifiez le nom et l'emplacement du fichier "RTF".
4. Validez. Les enregistrements du résultat de la requête sont automatiquement exportés dans le fichier "RTF".

## Exporter le résultat vers un fichier XML

Pour l'opération suivante, nous considérons que le résultat de la requête est affiché.
Pour exporter le résultat de la requête vers un fichier XML :

1. Affichez le menu contextuel (clic droit) du résultat de la requête.
2. Sélectionnez l'option "Autres fonctionnalités automatiques (FAA) .. Exporter la table vers XML". La fenêtre de sélection du fichier XML s'affiche.
3. Spécifiez le nom et l'emplacement du fichier XML.
4. Validez. Les enregistrements du résultat de la requête sont automatiquement exportés dans le fichier XML.

## Exporter le résultat vers un fichier de type tableur

Pour l'opération suivante, nous considérons que le résultat de la requête est affiché.
Pour exporter le résultat de la requête vers un fichier Excel :

1. Affichez le menu contextuel (clic droit) du résultat de la requête.
2. Sélectionnez l'option "Autres fonctionnalités automatiques (FAA) .. Exporter la table vers Excel" (ou l'option "Exporter la table vers OpenOffice.org Calc"). La fenêtre de sélection du fichier "XLS" s'affiche.
3. Spécifiez le nom et l'emplacement du fichier "XLS".
4. Validez. Les enregistrements du résultat de la requête sont automatiquement exportés dans le fichier "XLS".

## Exporter le résultat vers un fichier de données HFSQL

Pour l'opération suivante, nous considérons que le résultat de la requête est affiché.
Pour exporter le résultat de la requête vers un fichier de données HFSQL :

1. Cliquez sur le bouton "Exporter vers un fichier de données HFSQL" ou sélectionnez l'option "Exporter vers un fichier HFSQL" dans le menu contextuel (clic droit) du résultat de la requête. La fenêtre de sélection du fichier de données HFSQL s'affiche.
2. Spécifiez le nom et l'emplacement du fichier de données HFSQL.
3. Validez. Les enregistrements du résultat de la requête sont automatiquement exportés dans le fichier de données HFSQL. Le résultat peut être visualisé par exemple avec WDMap.

## Imprimer le résultat

Pour l'opération suivante, nous considérons que le résultat de la requête est affiché.
Pour imprimer le résultat de la requête :

1. Sélectionnez l'option "Imprimer" dans le menu contextuel (clic droit) du résultat de la requête ou cliquez sur le bouton . La fenêtre de sélection des rubriques à imprimer s'ouvre.
2. Indiquez les rubriques à imprimer et validez.
3. Un aperçu avant impression s'affiche avec le résultat de la requête.
