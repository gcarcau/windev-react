# Réception (Propriété)

> **Disponible :** **WINDEV** (Windows)

La propriété **Réception** permet de connaître et modifier le type des données entrantes transférées par le flux.
Par défaut, les données entrantes transférées par un flux sont de type son et vidéo.

**Attention** : La transmission en cours n'est pas modifiée. Les changements effectués par cette propriété seront pris en compte uniquement lors de la prochaine connexion.

## Exemple

```wlangage
// Modifie le type de données entrantes transférées par le flux
MonFlux.Réception = FluxSon
```

## Syntaxe

#### Connaître le type de données entrantes transférées par le flux

```wlangage
<Résultat> = <Nom du flux>.Réception
```

`<Résultat>` *Constante ou combinaison de constantes de type entier*
> Type de données entrantes transférées actuellement par le flux :
>
>
> | *FluxSon* | Les données entrantes de type Son sont transférées. |
> | --- | --- |
> | *FluxVidéo* | Les données entrantes de type Vidéo sont transférées. |
`<Nom du flux>` *Chaîne de caractères*
> Nom du Flux ou nom du champ Conférence associé au flux.

#### Modifier le type de données entrantes transférées par le flux

```wlangage
<Nom du flux>.Réception = <Nouveau type de données>
```

`<Nom du flux>` *Chaîne de caractères*
> Nom du Flux ou nom du champ Conférence associé au flux.
`<Nouveau type de données>` *Constante ou combinaison de constantes de type Entier*
> Nouveau type de données entrantes à transférer par le flux :
>
>
> | *FluxSon* | Les données entrantes de type Son sont transférées. |
> | --- | --- |
> | *FluxVidéo* | Les données entrantes de type Vidéo sont transférées. |
