# grZoom (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Règle le zoom d'un graphe.
**Remarque** : Cette fonction est similaire à la fonction [grOrigine](3042039.md). Cependant, la fonction **grZoom** permet à l'utilisateur de revenir au zoom initial du graphe en utilisant une des méthodes suivantes :

- grâce au menu contextuel du graphe (option "Zoom initial").
- grâce à la combinaison de touches Ctrl + 0.
- grâce à un double tap sur le graphe.

## Exemple

```wlangage
grZoom(GRF_MonGraphe, 5, 12, grAbscisse)
grDessine(GRF_MonGraphe)
```

## Syntaxe

```wlangage
grZoom(<Nom du graphe> , <Graduation minimale> [, <Graduation maximale> [, <Axe>]])
```

`<Nom du graphe>` *Nom de champ ou chaîne de caractères*
> Nom du graphe à manipuler. Ce nom correspond :
>
> - soit au nom du graphe défini par programmation avec la fonction [grCrée](3042005.md).
> - soit au nom du champ Graphe présent dans l'éditeur de fenêtres.
>
>
> > _(Android)_ Seuls les champs Graphe sont disponibles.
`<Graduation minimale>` *Réel*
> Graduation de départ sur l'axe spécifié.
> Ce paramètre peut également correspondre à une durée, une date, une heure ou une date-heure.
`<Graduation maximale>` *Réel optionnel*
> Graduation de fin sur l'axe spécifié.
> Si ce paramètre n'est pas spécifié, <Graduation maximale> correspond à la valeur maximale des données du graphe.
> Ce paramètre peut également correspondre à une durée, une date, une heure ou une date-heure.
`<Axe>` *Constante optionnelle de type Entier*
> Axe pour lequel les graduations doivent être modifiées :
>
>
> | *grAbscisse* (valeur par défaut) | Axe des abscisses (axe horizontal). |
> | --- | --- |
> | *grOrdonnée* | Axe des ordonnées (axe vertical). |
> | *grOrdonnéeSecondaire* | Axe secondaire des ordonnées (axe vertical). |

## Remarques

### Graduations des axes

- Axe des abscisses (axe horizontal) : les paramètres <Graduation minimale> et <Graduation maximale> correspondent à l'indice minimal et maximal des données dans les séries affichées.
- Axe des ordonnées (axe vertical) : les paramètres <Graduation minimale> et <Graduation maximale> correspondent à la valeur minimale et maximale des données.
- Limites : 100 graduations au-dessus et 100 graduations en dessous de l'axe des abscisses.
- Pour modifier la fréquence des graduations sur l'axe vertical ou horizontal d'un graphe, utilisez la fonction [grGraduation](3042027.md).
- Les données définies avec la fonction **grZoom** seront prises en compte lors du prochain appel à la fonction [grDessine](3042026.md).

### Types de graphes
La graduation des axes est sans effet sur les graphes de type Secteur.

### Restauration des valeurs par défaut
Pour restaurer l'affichage du graphe avant le zoom, il est nécessaire d'utiliser les valeurs minimales et maximales des axes. Ces valeurs peuvent être connues grâce aux propriétés suivantes :

| [AxeXMax](1000018169.md) | La propriété **AxeXMax** permet de connaître la borne maximale des abscisses (axe X) d'un champ de type Graphe. Cette propriété peut être utilisée par exemple dans l'événement "Zoom" d'un champ Graphe pour identifier la partie affichée. |
| --- | --- |
| [AxeXMin](1000018168.md) | La propriété **AxeXMin** permet de connaître la borne minimale des abscisses (axe X) d'un champ Graphe. Cette propriété peut être utilisée par exemple dans l'événement "Zoom" d'un champ Graphe pour identifier la partie affichée. |
| [AxeYMax](1000018171.md) | La propriété **AxeYMax** permet de connaître la borne maximale des ordonnées (axe Y) d'un champ Graphe. Cette propriété peut être utilisée par exemple dans l'événement "Zoom" d'un champ Graphe pour identifier la partie affichée. |
| [AxeYMin](1000018170.md) | La propriété **AxeYMin** permet de connaître la borne minimale des ordonnées (axe Y) d'un champ Graphe. |
| [AxeZMax](1000020626.md) | La propriété **AxeZMax** permet de connaître la borne maximale des altitudes (axe Z) d'un champ Graphe (graphe Surface). |
| [AxeZMin](1000020662.md) | La propriété **AxeZMin** permet de connaître la borne minimale des altitudes (axe Z) d'un champ Graphe (graphe Surface). |

Par exemple :

```wlangage
// Code permettant de zoomer
grZoom(GRF_MonGraphe, 5, 12, grAbscisse)
grDessine(GRF_MonGraphe)
```

```wlangage
// Code permettant de dé-zoomer
grZoom(GRF_MonGraphe, GRF_MonGraphe.AxeXMin, GRF_MonGraphe.AxeXMax, grAbscisse)
grDessine(GRF_MonGraphe)
```

### Gestion du zoom
La fonction [grParamètre](1000018337.md) permet de configurer plusieurs options de gestion du zoom dans les champs Graphe :

- Gestion des ascenseurs.
- Gestion du zoom arrière.
