# ListeInfo (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch)

Récupère les caractéristiques d'une liste WLangage : types des éléments et nombre d'éléments.
Nouveauté Abonnement

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
// Liste dont les éléments sont des instances de MaClasse
MaListe est une Liste de MaClasse
// Récupère la définition du type des éléments
MaDéfinition est un Définition
MaDéfinition = ListeInfo(MaListe, tiDéfinitionElément)
```

## Syntaxe

```wlangage
<Résultat> = ListeInfo(<Liste WLangage> , <Information>)
```

`<Résultat>` *Variant*
> Information demandée.
`<Liste WLangage>` *Liste*
> Nom de la variable de type [Liste](1514023.md) à manipuler.
`<Information>` *Constante de type Entier*
> Information à récupérer :
>
> | *tiDéfinitionElément* | <Résultat est une variable de type [Définition](1000019540.md) et contient la définition du type des éléments. _(WEBDEV - Code Navigateur, Android, Widget Android, Java)_ Cette constante n'est pas disponible. |
> | --- | --- |
> | *tiNombreTotal* | <Résultat est une variable de type Entier et contient le nombre total d'éléments dans la liste. |
> | *tiTypeElément* | <Résultat est une variable de type Entier et contient le type des éléments de la liste. Ce résultat est compatible avec la fonction [TypeVar](3013056.md). _(WEBDEV - Code Navigateur)_ Cette constante n'est pas disponible. |

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
