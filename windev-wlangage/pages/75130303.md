# Recupere (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Récupère la valeur d'un champ.

## Exemple

```wlangage
// En CAPPELWD("Recupere,Nom");
```

```wlangage
// En PascalAPPELWD('Recupere,Nom');
```

```wlangage
// En VBcall APPELWD("Recupere,Nom")
```

## Syntaxe

```wlangage
Recupere(<Nom du champ> [, <Indice>])
```

`<Nom du champ>` *Chaîne de caractères*
> Nom du champ à récupérer.
`<Indice>` *Chaîne de caractères (optionnelle)*
> Indice dans le cas d'un champ indicé.

## Remarques

Recupere est équivalent à [Ecran,Recupere](75130264.md).
