# TCDSelect (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur)

Permet de connaître la position de la cellule sélectionnée et de sélectionner une cellule dans un champ Tableau croisé dynamique.
Nouveauté Abonnement

> _(WEBDEV - Code Serveur, Linux)_ Cette fonction est désormais disponible pour les sites WEBDEV sous Windows et sous Linux.

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
// Récupérer la position courante
tcdPos est une tcdPosition
tcdPos = TCDSelect(TCD_Stats)
SI PAS tcdPos.EnDehors ALORS
	Trace(tcdPos.Pays + " " + tcdPos.Ville)
FIN
```

```wlangage
// Parcours des cellules sélectionnées
tcdPos est une tcdPosition de TCD_MonTCD

nbSel est un entier = TCDSelectOccurrence(TCD_MonTCD)
POUR i = 1 À nbSel
	tcdPos = TCDSelect(TCD_MonTCD, i)
	Trace(tcdPos.COL_Date_Jour + ":" + tcdPos.COL_Produit))
FIN
```

```wlangage
tcdPos est une tcdPosition
// Sélectionner "France / 2014"
tcdPos.Pays = "FRANCE"
tcdPos.Annee = "2014"
TCDSelect(TCD_Stats, tcdPos)
```

## Syntaxe

#### Récupérer la position de la cellule sélectionnée dans un champ Tableau croisé dynamique

```wlangage
<Résultat> = TCDSelect(<Champ Tableau croisé dynamique> [, <Rang>])
```

`<Résultat>` *Variable de type tcdPosition*
> Variable de type [tcdPosition](1000020726.md) contenant la position de la cellule sélectionnée dans le champ. Si aucun élément n'est sélectionné, la propriété **EnDehors** de la variable de type [tcdPosition](1000020726.md) renvoyée vaut Vrai.
`<Champ Tableau croisé dynamique>` *Nom de champ*
> Nom du champ Tableau croisé dynamique à manipuler.
`<Rang>` *Entier optionnel*
> Rang de la sélection dans le cas d'un champ multisélection. Si ce paramètre n'est pas spécifié, la position de la première cellule sélectionnée est renvoyé.

#### Sélectionner une position dans un champ Tableau croisé dynamique

```wlangage
TCDSelect(<Champ Tableau croisé dynamique> , <Position> [, <Valeur>])
```

`<Champ Tableau croisé dynamique>` *Nom de champ*
> Nom du champ Tableau croisé dynamique à manipuler.
`<Position>` *Variable de type tcdPosition*
> Nom de la variable de type [tcdPosition](1000020726.md) correspondant à la position à sélectionner. Si la position ne correspond pas à une cellule visible, une erreur WLangage est affichée.
`<Valeur>` *Chaîne de caractères*
> Nom de la valeur à sélectionner. Si ce paramètre n'est pas spécifié et si plusieurs valeurs sont présentes dans la même cellule, la première valeur est sélectionnée.

**Classification Métier / UI : Code UI**

**Composante : wd300obj.dll**
