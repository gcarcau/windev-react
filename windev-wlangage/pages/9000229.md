# Installation MSIX

> **Disponible :** **WINDEV** (Windows)

## Présentation

Une installation MSIX est un format d'installation sécurisé pour les applications Windows.
Le principe est simple : tous les fichiers installés sont regroupés sous forme de "paquet". Les fichiers nécessaires à l'installation ne sont ainsi pas éparpillés dans les répertoires de Windows. La désinstallation de l'application est ainsi simplifiée. L'utilisateur ne peut donc pas choisir le répertoire d'installation de l'application : tous les fichiers de l'application sont installés dans un sous répertoire de "Program files\WindowsApps".
Les différents fichiers nécessaires à l'application et livrés avec l'application (DLL ou autres) sont virtualisés.
Ces installations doivent être signées.

Ces packages d'installation ont une taille réduite et permettent l'utilisation de l'installateur dans le cadre de stratégie de groupe.

WINDEV permet de réaliser des packages d'installation au format MSIX. Il est possible de personnaliser cette installation en personnalisant le manifest lié à l'installation.

**Attention** : Le programme d'installation à la norme MSIX ne peut être utilisé que dans le cadre d'une installation autonome. En effet, actuellement, les installations avec "Live update" ou la modification automatique des fichiers de données ne sont pas gérées.

## Comment le faire ?

### Création d'une installation MSIX via l'assistant
Pour créer une installation à la norme MSIX :

1. Créez l'exécutable de l'application : sous le volet "Projet", dans le groupe "Génération", cliquez sur "Générer".
2. Lancez la création de la procédure d'installation : sous le volet "Projet", dans le groupe "Génération", cliquez sur "Procédure d'installation".
3. Dans l'assistant d'installation, sur la partie gauche de l'assistant, cliquez sur "2 - Installation". Dans la boîte de dialogue qui s'affiche, sélectionnez "Accéder aux options d'installation".
4. Choisissez une "Installation individuelle", puis dans l'étape suivante, choisissez l'option "Installation par un package MSIX".
5. Dans la suite de l'assistant :
  - Sélectionnez les fichiers à installer.
  - Aucun module complémentaire ne peut être spécifié.
  - Spécifiez les options de description du package :
    - Nom de l'application, titre du package, version : Par défaut, les informations spécifiées dans l'exécutable sont reprises.
    - Editeur : Par défaut, cette information est spécifiée dans le Certificat.
    - Description (obligatoire) : Description de l'application.
    - Image de l'application (obligatoire) : Cette image doit être carrée, au format JPEG ou PNG. Cette image est utilisée dans l'assistant d'installation (en haut à droite), dans la barre des tâches et dans le menu "Démarrer" de Windows.
    - Identifiant : L'identifiant permet d'identifier le package de l'application. Le bouton "Générer" permet d'obtenir un nouvel identifiant.
      En modifiant cet identifiant, il est possible de permettre l'installation de plusieurs versions différentes par un même utilisateur.
    - Fichier manifeste MSIX : Fichier manifeste généré automatiquement grâce aux informations spécifiées. Il est possible de fournir un fichier manifeste personnalisé :
      - Ce ficher manifeste a pour nom AppxManifest.xml.
      - Si ce fichier est fourni, toutes les informations saisies dans cette étape sont ignorées.
      - Si les informations présentes dans le manifeste ne sont pas conformes à l'API MSIX, la génération du package échouera. Pour plus de détails sur les informations présentes dans le fichier manifeste et son format, consultez [https://learn.microsoft.com/fr-fr/windows/msix/desktop/desktop-to-uwp-manual-conversion#create-a-package-manifest](https://learn.microsoft.com/fr-fr/windows/msix/desktop/desktop-to-uwp-manual-conversion#create-a-package-manifest)
      - De même, pour la signature, le certificat utilisé pour la signature doit être celui indiqué dans le fichier AppxManifest.xml
  - Spécifiez les options de génération du package :
    - Fichier à générer (d'extension msix).
    - Certificat à utiliser pour la signature.
6. Terminez l'assistant. L'installation au format MSIX est automatiquement créée.

L'installation au format MSIX peut être exécutée.
