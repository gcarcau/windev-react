# <Variable Connexion>.AjouteOptimisationPlanifiée (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Ajoute une tâche d'optimisation des fichiers de données HFSQL Client/Serveur.

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion
...
// Recalculer les statistiques des fichiers de la base "MaBase",
// tous les samedis à 23H00
Optim est une hOptimisationPlanifiée
Optim.Description = "Recalcul des statistiques des fichiers de la base de données MaBase"
Optim.Planification.Mois = "*"
Optim.Planification.JourDeLaSemaine = "samedi"
Optim.Planification.Heure = "23"
Optim.Planification.Minute = "0"
Optim.Fichier[1].Nom = "MaBase"
Optim.Fichier[1].Option = hOptStat
MaConnexion.AjouteOptimisationPlanifiée(Optim)
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.AjouteOptimisationPlanifiée(<Tâche d'optimisation planifiée>)
```

`<Résultat>` *Booléen*
> - Vrai si la tâche d'optimisation planifiée a été ajoutée
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle une tâche d'optimisation planifiée doit être ajoutée.
`<Tâche d'optimisation planifiée>` *Variable de type hOptimisationPlanifiée*
> Nom de la variable de type [hOptimisationPlanifiée](1000018854.md) manipulée.

## Remarques

### Droits nécessaires
Pour ajouter une tâche d'optimisation planifiée, il est nécessaire de posséder :

- le droit correspondant (constante *hDroitGèreTâche*) sur le serveur,
- pour chaque base concernée, le droit de connexion (constante *hDroitConnexion* ou *hDroitConnexionCryptée*),
- le droit d'exécuter la commande liée à la tâche d'optimisation planifiée.

La tâche sera exécutée avec le compte de l'utilisateur qui a créé la tâche.
Pour une optimisation du serveur complet, l'utilisateur doit être super-utilisateur.

**Remarque** : Si le serveur est éteint, la tâche d'optimisation planifiée ne sera pas réalisée. La tâche d'optimisation planifiée sera réalisée à la prochaine date disponible lorsque le serveur sera allumé.

Pour savoir si un utilisateur ou un groupe possède ces droits, utilisez la fonction [<Variable Connexion>.InfoDroitServeur](1000022668.md) ou [HInfoDroitDaseDeDonnées](1000022666.md).

Pour modifier les droits d'un utilisateur ou d'un groupe d'utilisateurs, utilisez la fonction [<Variable Connexion>.ModifieDroitServeur](1000022710.md) ou [<Variable Connexion>.ModifieDroitBaseDeDonnées](1000022707.md).
