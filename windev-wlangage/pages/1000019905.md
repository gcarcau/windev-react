# CouleurPalette (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

Renvoie une couleur de la palette courante.

## Exemple

```wlangage
Trace(CouleurPalette(couleurFondGénéral))
```

## Syntaxe

```wlangage
<Couleur> = CouleurPalette(<Famille> [, <Variation>])
```

## Remarques

### Fonctionnement
La fonction **CouleurPalette** choisit la palette selon le contexte :

- Dans le code d'un champ ou d'une page, la fonction retourne les couleurs de la palette de la page.
- Dans le code du projet, la fonction retourne les couleurs de la palette du projet.

Si la palette recherchée n'existe pas, la fonction **CouleurPalette** utilise une palette d'un élément plus général :

- Dans une page (sans palette ou qui utilise la palette du projet) : la fonction **CouleurPalette** recherche la palette du composant parent (si la page est dans un composant) ou du projet (si la page est directement dans l'application).
- Dans un composant (sans palette ou qui utilise la palette par défaut), la fonction **CouleurPalette** recherche la palette du composant parent (si le composant est dans un autre composant) ou du projet (si le composant est directement dans l'application).
- Dans le projet (sans palette ou qui utilise la palette par défaut), la fonction **CouleurPalette** retourne une erreur car la palette par défaut n'est pas disponible par programmation.
