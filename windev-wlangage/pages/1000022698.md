# <Variable Connexion>.ListePlanification (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Liste les éléments planifiés définis sur un serveur HFSQL : tâches planifiées (procédure stockée), sauvegarde, optimisation, rafraîchissement d'une vue matérialisée.

## Exemple

```wlangage
// Description de la connexion
MaConnexionBase est une Connexion

// Modification de toutes les sauvegardes planifiées
tabDescSvg est un tableau dynamique de hDescriptionSauvegarde
tabDescSvg = MaConnexionBase.ListePlanification(hlpSauvegarde)
hDescSvg est une hDescriptionSauvegarde
POUR TOUT hDescSvg DE tabDescSvg
	SI hDescSvg.LimiteNombreSauvegarde = 3 ALORS
		hDescSvg.LimiteNombreSauvegarde = 5
		MaConnexionBase.ModifiePlanification(hDescSvg)
	FIN
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.ListePlanification(<Type de planification>)
```

`<Résultat>` *Tableau*
> Tableau contenant les descriptions listées. Le type des éléments du tableau dépend du paramètre <Type de planification>.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion à manipuler.
`<Type de planification>` *Constante de type Entier*
> Type de planification à lister :
>
> | *hlpOptimisation* | Tâches d'optimisation des fichiers de données (réindexation, calcul des statistiques). |
> | --- | --- |
> | *hlpSauvegarde* | Planifications des sauvegardes. |
> | *hlpTâche* | Tâches planifiées exécutant une procédure stockée. |
> | *hlpVueMatérialisée* | Tâches de rafraîchissement des vues matérialisées. |

## Remarques

### Droits nécessaires
Pour lister les tâches de rafraîchissement des vues matérialisées ou les tâches planifiées, il est nécessaire de posséder le droit de connexion (constante *hDroitConnexion* ou *hDroitConnexionCryptée*) pour chaque base de données concernée, c'est-à-dire pour chaque base de données qui contient une vue à traiter ou une procédure stockée à exécuter.
Pour savoir si un utilisateur ou un groupe possède ces droits, utilisez la fonction [<Variable Connexion>.InfoDroitServeur](1000022668.md) ou la fonction [HInfoDroitDaseDeDonnées](1000022666.md).

Pour modifier les droits d'un utilisateur ou d'un groupe d'utilisateurs, utilisez la fonction [<Variable Connexion>.ModifieDroitServeur](1000022710.md) ou la fonction [<Variable Connexion>.ModifieDroitBaseDeDonnées](1000022707.md).
