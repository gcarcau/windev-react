# ChronoRAZ (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Arrête et remet un chronomètre existant à zéro. La valeur de la durée écoulée est perdue.
Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Les variables de type Chrono sont désormais disponibles en code navigateur. La syntaxe manipulant les variables de type Chrono devient également disponible.

## Exemple

```wlangage
// -- Code de clic du bouton BTN_Reinit
// Réinitialise le chronomètre en cours
ChronoRAZ()
```

## Syntaxe

#### Interrompre et réinitialiser le chronométrage réalisé avec un numéro de chronomètre

```wlangage
ChronoRAZ([<Numéro du chronomètre>])
```

`<Numéro du chronomètre>` *Entier optionnel*
> Identifiant du chronomètre à réinitialiser. Si ce paramètre n'est pas précisé, sa valeur par défaut est 1.

> Syntaxe non disponible en PHP

Interrompre et réinitialiser le chronométrage réalisé avec une variable de type Chrono Masquer les détails
ChronoRAZ(<Chronomètre>)

 <Chronomètre> : Variable de type ChronoNom de la variable de type Chrono correspondant au chronomètre à utiliser.

## Remarques

### Erreur
Si la fonction [ChronoDébut](3027031.md) n'a pas été appelée avant la fonction **ChronoRAZ**, une erreur WLangage est affichée (erreur de type "le chronomètre n'est pas démarré").

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
