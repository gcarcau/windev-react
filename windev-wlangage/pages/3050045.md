# MatDéterminant (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Calcule le déterminant d'une matrice carrée (nombre de lignes égal au nombre de colonnes).

## Exemple

```wlangage
// Calcul du déterminant d'une matrice
ResDéterminant = MatDéterminant("MaMatrice")
```

## Syntaxe

```wlangage
<Résultat> = MatDéterminant(<Matrice>)
```

`<Résultat>` *Réel*
> Déterminant de la matrice. Si cette valeur est égale à 0, le déterminant de la matrice est nul.
`<Matrice>` *Chaîne de caractères*
> Nom de la matrice à manipuler, défini avec la fonction [MatCrée](3050058.md).

## Remarques

### Existence de la matrice
L'existence de la matrice n'est pas vérifiée. Pour vérifier l'existence d'une matrice, utilisez la fonction [MatExiste](3050076.md).

### Gestion des erreurs
**Attention** : La fonction **MatDéterminant** ne retourne pas de code d'erreur. Pour savoir si des erreurs ont été générées par le calcul du déterminant, utilisez la fonction [MatErreur](3050044.md). Le libellé de l'erreur peut être connu grâce à la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
