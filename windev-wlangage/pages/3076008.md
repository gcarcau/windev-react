# telAppelPasDeRéponse (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Permet de savoir si une réponse a été donnée à l'appel.

## Exemple

```wlangage
PROCÉDURE ComposerNumTel(sNuméroTel)
// On compose le numéro
SI telCompose(sNuméroTel, "EtatAppel", 4) = Vrai ALORS
	// Communication établie
	Message("La communication est établie")
	Info("La communication est établie, vous pouvez décrocher")
	RETOUR
SINON
	SI PAS ErreurInfo() ~= "" ALORS
		Erreur(ErreurInfo())
	FIN
	// On teste si la ligne est occupée
	SI telAppelEstOccupé() = Vrai ALORS
		Info("La ligne est occupée")
		RETOUR
	FIN
	// On teste si le correspondant a répondu
	SI telAppelPasDeRéponse() = Vrai ALORS
		Info("Le correspondant n'a pas répondu")
		RETOUR
	FIN
FIN
```

## Syntaxe

```wlangage
<Résultat> = telAppelPasDeRéponse([<Identifiant de l'appel>])
```

`<Résultat>` *Booléen*
> - Vrai si le numéro appelé n'a pas eu de réponse,
> - Faux dans le cas contraire.
`<Identifiant de l'appel>` *Entier optionnel*
> Identifiant de l'appel à manipuler. Cet identifiant est connu dans la procédure WLangage appelée par la fonction [telDémarreDétectionAppel](3076029.md). Si ce paramètre n'est pas spécifié, l'appel en cours est manipulé.

## Remarques

### Configuration nécessaire
Les fonctions de téléphonie utilisent la technologie TAPI 2.0 et/ou la technologie TAPI 3.1. Ces technologies sont utilisables sur tous les systèmes.

**Composante : wd300com.dll**
