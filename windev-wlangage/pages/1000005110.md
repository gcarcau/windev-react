# NotesEnregistre (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Enregistre le document en cours dans Lotus Notes. Ce document vient d'être modifié à l'aide des fonctions [NotesModifieChamp](1000005113.md), [NotesSupprimeChamp](1000005116.md) ou [NotesAjouteFichierAttaché](1000005119.md).

## Exemple

```wlangage
// Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", ...
			"ServeurMars", "mail\julie.nsf", ...
			"C:\Users\Julie\AppData\Local\Lotus\Notes\Data\user.id")
...
// Lecture du premier document
NotesDocumentPremier(IDSession)
// Modification du sujet du document
NotesModifieChamp(IDSession, "Subject", "Mon nouveau sujet")
// Enregistrement des modifications
NotesEnregistre(IDSession)
```

## Syntaxe

```wlangage
<Résultat> = NotesEnregistre(<Identifiant de la session>)
```

`<Résultat>` *Booléen*
> - Vrai si le document a bien été enregistré,
> - Faux dans le cas contraire.
>
> En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Identifiant de la session>` *Entier*
> Identifiant de la session à utiliser. Cet identifiant est renvoyé par la fonction [EmailOuvreSessionNotes](3032121.md) ou la fonction [NotesOuvreBase](1000005101.md).
