# HModifieSauvegardePlanifiée (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Modifie une planification de sauvegarde. Cette planification a été décrite grâce à une variable de type [hDescriptionSauvegarde](1000017455.md).

## Exemple

```wlangage
// Description de la connexion
MaConnexionBase est une Connexion

tabSvg est un tableau dynamique de hDescriptionSauvegarde
tabSvg = HListeSauvegardePlanifiée(MaConnexionBase)
hSvg est une hDescriptionSauvegarde

POUR TOUT hSvg DE tabSvg
	SI hSvg.LimiteNombreSauvegarde = 3 ALORS
		hSvg.LimiteNombreSauvegarde = 5
		HModifieSauvegardePlanifiée(MaConnexionBase, hSvg)
	FIN
FIN
```

## Syntaxe

```wlangage
<Résultat> = HModifieSauvegardePlanifiée(<Connexion> , <Sauvegarde planifiée>)
```

`<Résultat>` *Booléen*
> - Vrai si la sauvegarde planifiée a été modifiée,
> - Faux en cas d'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion pour laquelle une sauvegarde planifiée doit être modifiée. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Sauvegarde planifiée>` *Variable de type hDescriptionSauvegarde*
> Nom de la variable de type [hDescriptionSauvegarde](1000017455.md) à modifier.

## Remarques

### Droits nécessaires
Pour avoir le droit de modifier une sauvegarde planifiée, il est nécessaire :

- soit d'être le propriétaire de la sauvegarde planifiée.
- soit d'être super-utilisateur.

**Composante : wd300hf.dll**
