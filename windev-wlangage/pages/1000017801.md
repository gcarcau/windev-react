# Hauteur (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Hauteur** permet de connaître et de modifier la hauteur d'un élément. Cette propriété est utilisable sur :

- un élément d'une fenêtre, d'une page ou d'un état. Pour plus de détails, consultez [Hauteur](2510050.md).
- une variable de type [rssFlux](1000017795.md).
- une variable de type [rssImage](1000017799.md).
- une variable de type [xlsDocument](1000017464.md).
- une variable de type [xlsLigne](1000017325.md).
- une variable de type [Image](1000019650.md).
- une variable de type [upnpImage](1000020905.md).
- une variable de type [Cadre](15140100.md).
- une variable de type [Rectangle](1514079.md).
- une variable de type [pdfSignature](1000022255.md).
- une variable de type [docElémentImage](1000022696.md).
- une variable de type [docLigne](1000022925.md).
- une variable de type [docElémentZoneDeTexte](1000023420.md).
- une variable de type [WDPic](1000023503.md).
- une variable de type [picCalque](1000024604.md).
- une variable de type [pdfPage](1000024904.md).
- une variable de type [pdfElémentTexte](1000024556.md).
- une variable de type [CarteImage](1000025523.md).
- une variable de type [diagSélection](1410088172.md).
- une variable de type [Scanneur](1410087808.md).
- la propriété [BoutonGauche](1410090001.md) d'un champ de saisie.
- la propriété [BoutonDroit](1410090002.md) d'un champ de saisie.
- Nouveauté Abonnement
   une variable de type [pdfChamp](1410090536.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
- Nouveauté Abonnement
  une variable de type [OptionsOuvertureFenêtre](1410091298.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
