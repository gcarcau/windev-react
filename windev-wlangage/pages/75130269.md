# Erreur (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Affiche une boîte de dialogue contenant un sigle d'erreur et le message passé en paramètre.

## Exemple

```wlangage
// En CAPPELWD("Erreur,Erreur de lecture du fichier %s",NomFic);
```

```wlangage
// En PascalAPPELWD('Erreur,Erreur de lecture du fichier '+NomFic);
```

```wlangage
// En VBcall APPELWD("Erreur,Erreur de lecture du fichier "+NomFic)
```

## Syntaxe

```wlangage
Erreur(<Message>)
```

`<Message>` *Chaîne de caractères*
> Message à afficher (200 caractères maximum).

## Remarques

- La fenêtre sera fermée lorsque l'utilisateur valide le bouton "OK".
- Par défaut, la fenêtre a le même titre que la fenêtre en cours. Pour modifier le titre, il faut utiliser la fonction [Windows,TSuivant](75130326.md).
- Pour afficher le message sur plusieurs lignes, il faut utiliser la syntaxe suivante :
  - Exemple en C :
    ```wlangage
    APPELWD("Erreur,  \n ");
    ```
  - Exemple en Pascal :
    ```wlangage
    APPELWD('Erreur, '+Chr(10)+ ' ');
    ```
  - Exemple en VB :
    ```wlangage
    call APPELWD("Erreur, "+CHR(10)+"")
    ```
