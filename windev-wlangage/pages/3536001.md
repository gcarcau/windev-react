# WDStatistics : Utiliser WDStatistics

> **Disponible :** **WEBDEV** (Windows)

## Présentation

Après avoir importé les fichiers journal, l'utilisation de WDStatistics peut commencer.
La fenêtre principale de WDStatistics est la suivante :

|  | Paramètres des données à afficher. Sélectionnez les différents paramètres concernant les statistiques à afficher : Nom du serveur, nom du site, période, etc. |
| --- | --- |
|  | Types de statistiques à afficher Cliquez sur le type de statistiques à afficher. |
|  | Statistiques demandées.  Ces différentes statistiques sont présentées sous forme de :  - **tableaux récapitulatifs**.   Ces tableaux peuvent être enregistrés au format Word, Excel ou XML (clic droit sur le tableau). - **graphiques**. Ces graphiques peuvent être personnalisés (clic droit sur le graphique). Il est ainsi possible de changer le type de graphe, d'ajouter des légendes, de modifier la police utilisée, etc. |

## Les statistiques disponibles

Les statistiques proposées par WDStatistics sont les suivantes :

| - ***Tableau de bord*** : | Tableau de bord récapitulant :  - le nombre de visiteurs. - le nombre de pages vues. - le nombre de pages moyen par visiteur. - le nombre moyen de visiteurs par jour. - le nombre moyen de pages vues par jour. - le nombre maximum de connexions. - le nombre minimum de connexions. - la date de dernière importation des fichiers journal. - le fuseau horaire du site. - le type de site (Classique ou AWP). |
| --- | --- |
| - ***Moteurs de recherche*** : | Liste des mot-clés utilisés sur les moteurs de recherche permettant d'arriver sur le site. |
| - ***Répartition*** : | Liste des systèmes d'exploitation des internautes et des navigateurs. |
| - ***Fréquentation*** : | Graphe récapitulant le nombre de visites selon différentes répartitions temporelles. |
| - ***Vue Géographique*** : | Répartition de chaque visiteur selon le pays. |
| - ***Parcours des visiteurs*** : | Parcours effectués pour chaque visiteur sur le site (temps de parcours et durée passée sur chaque page). |
