# UnitéTaille (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **UnitéTaille** permet de connaître et de modifier l'unité utilisée pour manipuler la taille d'une police définie avec une variable de type [Police](1514045.md).

## Exemple

```wlangage
p est une Police
p.Nom = "arial"
p.UnitéTaille = unitéPoint
p.Taille = 12
```

## Syntaxe

#### Connaître l'unité utilisée pour définir la taille d'une police

```wlangage
<Résultat> = <Police>.UnitéTaille
```

`<Résultat>` *Constante de type Entier*
> Unité utilisée :
>
>
> | *unitéPixel* | L'unité utilisée est le pixel CSS. |
> | --- | --- |
> | *unitéPoint* | L'unité utilisée est le point. |
> | *unitéPointW* | L'unité utilisée est le point WINDEV (unité permettant de retrouver la taille utilisée dans les versions précédentes). |
`<Police>` *Variable de type Police*
> Nom de la variable de type [Police](1514045.md) à manipuler.

#### Modifier l'unité utilisée pour définir la taille d'une police

```wlangage
<Police>.UnitéTaille = <Nouvelle unité>
```

`<Police>` *Variable de type Police*
> Nom de la variable de type [Police](1514045.md) à manipuler.
`<Nouvelle unité>` *Constante de type Entier*
> Unité à utiliser :
>
>
> | *unitéPixel* | L'unité utilisée est le pixel CSS. |
> | --- | --- |
> | *unitéPoint* | L'unité utilisée est le point. |
> | *unitéPointW* | L'unité utilisée est le point WINDEV (unité permettant de retrouver la taille utilisée dans les versions précédentes). |

## Remarques

### Style d'un champ : Sélection de l'unité de la police sous l'éditeur
Le style d'un champ permet de définir la police utilisée pour les différents éléments du champ (Onglet "Style" de la fenêtre de description du champ). Lors de la saisie des informations de taille de la police sous l'éditeur, il est possible de choisir l'unité à utiliser.

### Variable de type Police
Une police peut être créée à partir d'une variable de type [Police](1514045.md).
Pour définir les caractéristiques de la police, utilisez :

- soit la fonction [PoliceCrée](3060002.md).
   Cette fonction n'est pas disponible.
- soit les propriétés [Alphabet](2512008.md), [Angle](1410086632.md), [Barré](2513005.md), [Couleur](2510071.md), [Gras](2513001.md), [Italique](2513007.md), [Interlettre](1410088367.md), [Interligne](1410088366.md), [Nom](2510082.md), [Souligné](2513013.md), [Taille](2510125.md) et [UnitéTaille](1410088365.md).
   Les propriétés [Alphabet](2512008.md), [Angle](1410086632.md) ne sont pas disponibles pour les variables de type [Police](1514045.md).

Cette police pourra être utilisée :

- Pour écrire du texte dans des dessins (fonction [dPolice](3029020.md)).
- Pour écrire dans les graphes (fonctions [grPoliceEtiquette](3042012.md), [grPoliceLégende](3042037.md), [grPoliceTitre](3042048.md) et [grPoliceTitreAxe](3042059.md)).
- Pour imprimer (fonction [iPolice](3046014.md)).
- Dans les champs d'une fenêtre (propriété [Police](1514045.md) des champs d'une fenêtre).
- Dans les champs d'un état (propriété [Police](1514045.md) des champs d'un état).

> _(Android, Widget Android)_ Cette police pourra être utilisée uniquement dans les champs d'une fenêtre (propriété Police des champs d'une fenêtre).
