# <Variable Connexion>.SupprimeUtilisateur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Supprime un utilisateur associé à une connexion sur le serveur HFSQL.

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion

// Ouverture de la connexion
MaConnexion.OuvreConnexion()
// Association du fichier de données à la connexion
Client.ChangeConnexion(MaConnexion)
...
SI MaConnexion.SupprimeUtilisateur("Flo") = Vrai ALORS
	Info("Utilisateur Flo supprimé")
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.SupprimeUtilisateur(<Utilisateur à supprimer>)
```

`<Résultat>` *Booléen*
> - Vrai si l'utilisateur a été supprimé,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
>
>
> **Remarque** : Une erreur "Utilisateur inconnu" sera renvoyée par la fonction [HErreurInfo](3044071.md) si l'utilisateur en cours n'a pas le droit de visualisation des utilisateurs (constante *hDroitVisualisationUtilisateur*).
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle un utilisateur doit être supprimé.
`<Utilisateur à supprimer>` *Chaîne de caractères*
> Nom de l'utilisateur à supprimer. Ce nom doit correspondre à la variable **HUtilisateur.Login** de l'un des utilisateurs de la connexion spécifiée.
