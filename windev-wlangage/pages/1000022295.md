# <Variable emailSessionNotes>.NbMessage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **Autres** (Procédures stockées)

Renvoie le nombre de messages reçus actuellement présents dans le logiciel de messagerie Notes. Ce nombre de messages évolue en fonction des emails reçus ou supprimés avec la fonction [EmailSupprimeMessage](3032027.md).

## Exemple

```wlangage
MaSession est un emailSessionNotes // Boucle de lecture de tous les messages reçus présents// dans la messagerie NotesI est un entiernbMSG est un entier = MaSession.NbMessage()POUR I = 1 À nbMSG EmailLitMessage(NomUser, I)  SI Email.EnDehors <> Vrai ALORS  CL.NOM = Email.Expéditeur  CL.MESSAGE_TXT = Email.Message   ...  SINON  Info("Ce message a été supprimé")  FINFIN
```

## Syntaxe

```wlangage
<Résultat> = <Session>.NbMessage()
```

`<Résultat>` *Entier*
> - Nombre de messages reçus présents dans le logiciel de messagerie Notes au moment de l'appel de la fonction **<Variable emailSessionNotes>.NbMessage**,
> - -1 en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Session>` *Variable de type emailSessionNotes*
> Nom de la variable de type [emailSessionNotes](1000018768.md) correspondant à la session d'email à manipuler.
