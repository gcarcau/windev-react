# Fonctions de gestion des scanneurs

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU))

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des scanneurs (syntaxe préfixée)](1410087867.md)).
Les fonctions de gestion des scanneurs sont les suivantes :

| [ScanAvecInterfaceUtilisateur](1410087840.md) | Enregistre un document provenant d'un scanneur dans un ou plusieurs fichiers, en utilisant l'interface utilisateur du scanneur. |
| --- | --- |
| [ScanCapacité](1410088661.md) | Permet de savoir si un scanneur possède une capacité donnée. |
| [ScanListe](1410087807.md) | Liste les scanneurs connectés au poste en cours. |
| [ScanPropriété](1410087853.md) | Permet de connaître ou de modifier les propriétés d'un scanneur. |
| [ScanRécupère](1410087836.md) | Récupère les caractéristiques d'un scanneur dans une variable de type [Scanneur](1410087808.md). |
| [ScanSélecteur](1410087835.md) | Affiche une boîte de dialogue standard listant les scanneurs disponibles. |
| [ScanVersImage](1410087838.md) | Récupère un document provenant d'un scanneur dans une variable de type [Image](1000019650.md). |
| [ScanVersPDF](1410087839.md) | Enregistre un document provenant d'un scanneur dans un fichier PDF. |
