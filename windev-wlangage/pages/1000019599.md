# Connecteur Natif SQLite

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android)

## Présentation

WINDEV et WEBDEV 2025 proposent un Connecteur Natif (également appelé module d'Accès Natif) à SQLite. Ce Connecteur Natif permet d'accéder à une base SQLite sans drivers externes depuis un programme en WLangage.
SQLite est un système de gestion de fichiers indexés.

Le Connecteur Natif à SQLite est disponible :

- sous Windows 32 et 64 bits.
- sous Linux 64 bits.

> _(Android)_ Remarque : WINDEV Mobile propose également un Connecteur Natif à SQLite pour les applications Android. Pour plus de détails, consultez Particularités des applications Android.

## Configuration nécessaire

### Conditions nécessaires à l'utilisation du Connecteur Natif SQLite

- SQLite version 3

### Fichiers nécessaires
L'utilisation du Connecteur Natif SQLite nécessite le fichier wd300sqlite.dll. Ce fichier est nécessaire pour une connexion native à une base SQLite.

## Utilisation

### Utiliser le Connecteur Natif SQLite dans vos applications WINDEV ou vos sites WEBDEV
Pour utiliser SQLite en natif, il suffit de programmer :

- soit avec les fonctions "SQL" du WLangage (voir [Programmation à l'aide des fonctions SQL](1000019634.md)).
- soit avec les fonctions "HFSQL" du WLangage (voir [Programmation à l'aide des fonctions HFSQL](1000019624.md)).

**Remarques** :

- N'oubliez pas de consulter les [limitations concernant l'utilisation du Connecteur Natif SQLite](1000019635.md).
- Pour déployer des sites utilisant le Connecteur Natif SQLite, il est nécessaire d'installer le Connecteur Natif SQLite sur le poste Serveur (Serveur d'Application WEBDEV).
