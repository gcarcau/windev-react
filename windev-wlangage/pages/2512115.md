# Vignette (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

La propriété **Vignette** permet de :

- connaître la valeur d'une vignette d'une rubrique. Cette rubrique a été définie sous l'éditeur d'analyses ou définie par programmation. Pour plus de détails, consultez [Vignettes HFSQL](3044348.md).
- connaître et modifier l'image associée à un champ Vignette.

## Exemple

```wlangage
// Valeur de la première vignette de la rubrique Client.Photo
ValeurVignette est une chaîne
ValeurVignette = Client.Photo.Vignette[1]
// équivalent à ValeurVignette = Client.Photo.Vignette

// Valeur nulle ?
SI ValeurVignette <> "" ALORS
	Info("La valeur de cette vignette est : " + ValeurVignette)
SINON
	ChaîneErreur = Client.Photo.InfoGénérationVignette[1]
	Erreur("Erreur de génération", ChaîneErreur)
FIN
```

> _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur, PHP)_ Trace(VIG_MaVignette.Vignette)

## Syntaxe

#### Connaître la valeur de la vignette d'une rubrique

```wlangage
<Valeur> = <Fichier de données>.<Rubrique>.Vignette
```

`<Valeur>` *Chaîne de caractères*
> Image de la vignette spécifiée sous forme de mémo binaire.
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données manipulé. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Fichier](1514065.md).
`<Rubrique>` *Chaîne de caractères*
> Nom de la rubrique de type mémo binaire manipulée. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Rubrique](1514071.md).

> _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur, PHP)_ Connaître le chemin de l'image associée à un champ Vignette Masquer les détails
<Résultat> = <Champ Vignette>.Vignette

 <Résultat> : Chaîne de caractèresChemin de l'image utilisée pour la vignette. Ce chemin est relatif au répertoire "_WEB" du projet. <Champ Vignette> : Nom de champNom du champ Vignette à manipuler.

> _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur, PHP)_ Modifier le chemin de l'image associée à un champ Vignette Masquer les détails
<Champ Vignette>.Miniature = <Nouvelle image>

 <Champ Vignette> : Nom de champNom du champ Vignette à manipuler. <Nouvelle image> : Chaîne de caractèresNouveau chemin de l'image utilisée pour la vignette. Ce chemin est relatif au répertoire "_WEB" du projet.

## Remarques

### Vignette d'un rubrique
La propriété **Vignette** est disponible :

- en HFSQL Classic et en HFSQL Mobile : sur les rubriques d'un fichier de données, d'une vue ou d'une requête.
- en HFSQL Client/Serveur : sur les rubriques d'un fichier de données uniquement.

> _(Linux)_ La propriété Vignette est disponible uniquement en HFSQL Client/Serveur sur les rubriques d'un fichier de données.
