# Développer des applications multilingues

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

## Présentation

Une application multilingue est une application qui pourra être diffusée dans plusieurs langues. WINDEV, WEBDEV et WINDEV Mobile prennent en compte les différentes langues de l'application à toutes les étapes du développement d'une application.

## Principe de développement d'une application multilingue

Pour développer une application multilingue, les étapes sont les suivantes :

1. [Choix des langues gérées par le projet et l'analyse.](3054010.md)
2. [Traduction des différents éléments du projet (fenêtre, messages du code, ...) dans les différentes langues du projet.](3054009.md)
3. [Détermination de la langue du projet par programmation](3054012.md).
4. [Gestion des alphabets spécifiques dans les fichiers de données](3054017.md).
5. [Création de l'exécutable et du programme d'installation](3054006.md).
