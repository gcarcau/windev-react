# IA dans l'éditeur de code

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Plusieurs fonctionnalités de WINDEV, WEBDEV et WINDEV Mobile utilisent l'IA (Intelligence Artificielle) :

- l'explication de code,
- la génération de commentaires de code,
- la génération des commentaires de réintégration dans le GDS.

Attention : Pour utiliser ces fonctionnalités, il est nécessaire de posséder un compte OpenAI et une clé OpenAI. Pour plus de détails, consultez [OpenAI : Comment trouver la clé OpenAI](2036005.md).

## Génération automatique de l'explication d'un code WLangage

Reprendre le code d'un autre développeur peut arriver. Si les commentaires n'ont pas été saisis, il devient difficile de comprendre ce que fait le code.
Pour vous aider, l'éditeur de code et l'IA vous proposent de générer automatiquement l'explication du code concerné :

1. Sélectionnez le code concerné.
2. Dans le menu contextuel de la sélection, sélectionnez "Que fait ce code ?".
3. Dans la fenêtre qui s'affiche, l'explication du code est affichée. Il est possible de :
  - demander une explication détaillée.
  - demander à générer à nouveau l'explication.

Remarques :

- L'IA ne générera jamais 2 fois exactement la même explication.
- La facturation par OpenAI est réalisée pour chaque requête qui aboutit.
- Pour utiliser les fonctionnalités OpenAI dans WINDEV, WEBDEV et WINDEV Mobile, il est nécessaire de posséder un compte utilisant un moyen de paiement. Si l'offre n'est pas suffisante, le message "quota dépassé" sera affiché. Pour plus de détails sur les pré-requis OpenAI, consultez [OpenAI : Comment trouver la clé OpenAI](2036005.md).
- Cette fonctionnalité utilise une adresse internet spécifique. Dans le cas d'une connexion Internet sécurisée, il peut être nécessaire d'autoriser expressément certains domaines dans une "liste blanche". Pour connaître la liste des domaines concernés, consultez la FAQ **22325** : [Quels domaines autoriser afin d'utiliser toutes les fonctionnalités de WINDEV, WEBDEV et WINDEV Mobile depuis une connexion Internet sécurisée ?](https://faq.pcsoft.fr/faqread.awp?idfaq=22325).

## Génération automatique de la documentation d'une procédure

Par défaut, lors de la création d'une procédure, il est possible de demander la génération d'une documentation automatique dans l'entête de la procédure. Dans ce cas, l'éditeur de code propose un squelette d'informations que le développeur doit renseigner. Les informations saisies dans la documentation automatique sont réutilisées notamment la description des paramètres.
Pour vous aider, l'éditeur de code propose d'utiliser l'IA pour générer le contenu de cette documentation automatique :

1. Affichez sous l'éditeur de code la procédure voulue.
2. Cliquez sur l'icône  du bandeau de la procédure.
3. La documentation est automatiquement générée dans l'en-tête de la procédure. Cette documentation peut être modifiée.

Remarques :

- L'IA ne générera jamais 2 fois exactement la même documentation automatique. Si la documentation générée ne convient pas, il est possible de faire un Ctrl Z (ou de la supprimer) puis de la re-générer.
- La documentation automatique est générée au format spécifié dans les options du projet : historique ou Doxygen.
- Les options de génération automatique de la documentation sont prises en compte. Pour plus de détails, consultez [Documentation automatique des procédures et méthodes](1513006.md).
- La facturation par OpenAI est réalisée pour chaque requête qui aboutit.
- Pour utiliser les fonctionnalités OpenAI dans WINDEV, WEBDEV et WINDEV Mobile, il est nécessaire de posséder un compte utilisant un moyen de paiement. Si l'offre n'est pas suffisante, le message "quota dépassé" sera affiché. Pour plus de détails sur les pré-requis OpenAI, consultez [OpenAI : Comment trouver la clé OpenAI](2036005.md).
- L'explication est générée dans la langue de l'éditeur : français, anglais ou espagnol.

## Génération automatique du commentaire de réintégration

Lors de la réintégration d'un élément dans le GDS, il est possible de saisir un commentaire résumant les modifications effectuées.
Le bouton "IA - Générer le commentaire" permet de simplifier l'écriture de ce commentaire. Le principe est le suivant :

- les codes modifiés, supprimés et ajoutés sont détectés.
- tous les commentaires ajoutés, supprimés ou modifiés sont extraits et envoyés à l'IA.
- l'IA fait une synthèse en quelques mots (une centaine de mots environ).
- cette synthèse est affichée dans la zone de commentaires.

Remarques :

- L'IA ne générera jamais 2 fois exactement la même documentation automatique. Si le commentaire généré ne convient pas, il est possible de recommencer l'opération.
- La facturation par OpenAI est réalisée pour chaque requête qui aboutit.
- Pour utiliser les fonctionnalités OpenAI dans WINDEV, WEBDEV et WINDEV Mobile, il est nécessaire de posséder un compte utilisant un moyen de paiement. Si l'offre n'est pas suffisante, le message "quota dépassé" sera affiché. Pour plus de détails sur les pré-requis OpenAI, consultez [OpenAI : Comment trouver la clé OpenAI](2036005.md).
- L'explication est générée dans la langue de l'éditeur : français, anglais ou espagnol.
