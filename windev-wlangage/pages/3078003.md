# TwainHauteurSource (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Renvoie la hauteur (en millimètres) du document récupéré par un périphérique Twain.

## Exemple

```wlangage
// Affiche dans le champ HauteurScan la
// hauteur du document qui va être scanné
HauteurScan = TwainHauteurSource()
```

## Syntaxe

```wlangage
<Résultat> = TwainHauteurSource()
```

`<Résultat>` *Réel*
> Hauteur (en millimètres) du document récupéré par un périphérique Twain. Si ce paramètre correspond à "0", le périphérique Twain utilisé ne gère pas cette fonctionnalité.

## Remarques

### Fonctionnement dans des applications 64 bits
Dans une application 64 bits, cette fonction utilisera automatiquement le driver Twain 64 bits. Si ce driver n'est pas installé, le périphérique TWAIN ne pourra pas être manipulé.

**Composante : wd300std.dll**
