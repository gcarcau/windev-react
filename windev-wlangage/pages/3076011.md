# telTransfertDirect (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Effectue un transfert d'appel "en aveugle". Aucune reprise de ligne n'est possible.

## Syntaxe

```wlangage
<Résultat> = telTransfertDirect(<Identifiant de l'appel> , <Numéro de transfert>)
```

`<Résultat>` *Booléen*
> - Vrai si le transfert d'appel est effectué,
> - Faux dans le cas contraire.
`<Identifiant de l'appel>` *Entier*
> Identifiant de l'appel à transférer. Cet identifiant est connu dans la procédure WLangage appelée par la fonction [telDémarreDétectionAppel](3076029.md).
`<Numéro de transfert>` *Chaîne de caractères*
> Numéro de téléphone à composer.

## Remarques

### Limitation
Il n'est pas possible d'appeler la fonction **telTransfertDirect** dans la procédure de détection d'appels (définie grâce à la fonction [telDémarreDétectionAppel](3076029.md)).

> _(WINDEV, Etats et Requêtes, Code Utilisateur (MCU))_ Transfert d'appel avec possibilité de reprise de la communicationPour effectuer un transfert d'appel avec possibilité de reprise du numéro initial (par exemple si le numéro de transfert refuse de prendre la communication), utilisez la fonction telExécuteTransfert.

> _(WINDEV, Etats et Requêtes, Code Utilisateur (MCU))_ Les fonctions de téléphonie utilisent la technologie TAPI 2.0 et/ou la technologie TAPI 3.1. Ces technologies sont utilisables sur tous les systèmes.Attention : le transfert d'appel n'est pas disponible pour tous les matériels. Le transfert d'appel est pris en compte uniquement dans le cas d'un PABX.
