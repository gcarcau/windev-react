# NoteChargeTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Importe et affiche les notes repositionnables de la fenêtre en cours précédemment sauvées par la fonction [NoteSauveTout](1000022396.md).

## Exemple

```wlangage
// Clic sur [Exporter mes notes]
NoteSauveTout()
SI ErreurDétectée = Vrai ALORS
	Erreur(ErreurInfo())
FIN

// Clic sur [Importer mes notes]
NoteChargeTout()
```

## Syntaxe

```wlangage
NoteChargeTout([<Fichier>])
```

`<Fichier>` *Chaîne de caractères optionnelle*
> Nom du fichier contenant les notes repositionnables à charger.
> Si ce paramètre n'est pas précisé, les notes chargées sont celles correspondant au fichier : <Nom fenêtre>.wdnote présent dans le répertoire des données. Le fichier recherché correspond à :
>
> ```wlangage
> fRepDonnées()\<MaFenetre..Nom>.wdnote
> ```

## Remarques

- Cette fonction est équivalente à la FAA (Fonctionnalités Automatiques de vos Applications) d'importation des notes sans l'affichage du sélecteur de fichiers. Pour plus de détails, consultez [Note repositionnable (FAA)](1000021820.md).
- Les éléments restaurés sont : la position de la note, son contenu, sa couleur de fond et les caractéristiques de la police utilisée.
