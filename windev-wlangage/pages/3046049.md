# Etape 3 : Impression de caractères, d'images, ...

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

## Présentation

Cette étape consiste à "envoyer à l'impression" les différents éléments à imprimer :

- texte,
- images,
- dessins, ...

L'impression sur le support voulu (configuré avec la fonction [iAperçu](3046069.md) ou [iDestination](3046074.md)) ne sera effective qu'à la fin de l'impression (fonction [iFinImprime](3046053.md)).

## Impression de texte

Voici les principales fonctions du WLangage permettant d'imprimer des textes.
**Remarques** :

- Les textes peuvent être dans des polices différentes : la police est sélectionnée par la fonction [iPolice](3046014.md).
- Les textes peuvent être écrits à des positions spécifiques : fonctions [iPosX](3046015.md) et [iPosY](3046075.md).

| [iHauteurTexte](3046070.md) | Calcule la hauteur de la police du texte à imprimer (en millimètres). |
| --- | --- |
| [iHauteurZone](3046062.md) | Calcule la hauteur nécessaire d'une zone de largeur fixe pour que l'ensemble d'un texte utilisant la police en cours puisse être imprimé dans cette zone. |
| [iImprime](3046031.md) | Envoie au buffer d'impression la chaîne de caractères passée en paramètre. |
| [iImprimeMot](3046034.md) | Envoie au "buffer" d'impression la chaîne de caractères passée en paramètre. |
| [iImprimeZone](3046027.md) | Imprime un texte dans une zone rectangulaire. |
| [iLargeurTexte](3046033.md) | Calcule la largeur (en millimètres) du texte à imprimer en fonction de la police spécifiée. |
| [iPolice](3046014.md) | Sélectionne la police par défaut. |
| [iPoliceDidot](3046016.md) | Sélectionne l'unité à utiliser pour la hauteur des polices (créées avec la fonction [iCréePolice](3046045.md)) : point DIDOT ou point PICA. |
| [iPosX](3046015.md) | Permet de gérer la position horizontale (abscisse ou colonne) du curseur d'impression dans la page. |
| [iPosY](3046075.md) | Permet de gérer la position verticale (ordonnée ou ligne) du curseur d'impression dans la page. |

## Impression d'images

Plusieurs fonctions du WLangage permettent d'imprimer des images, en tenant compte de la taille de l'image.

| [iHauteurImage](3046057.md) | Calcule la hauteur de l'image à imprimer (en millimètres). |
| --- | --- |
| [iImprimeCodeBarre](3046020.md) | Imprime un code-barres (à l'intérieur d'un rectangle). |
| [iImprimeImage](3046017.md) | Envoie au buffer d'impression le fichier image à imprimer. |
| [iLargeurImage](3046061.md) | Calcule la largeur de l'image à imprimer (en millimètres). |
| [iMagentaTransparent](3046003.md) | Modifie la gestion de la couleur Magenta afin que cette couleur soit considérée comme transparente ou non dans toutes les prochaines impressions. |

> _(Linux)_ En Linux, seules les images au format JPEG peuvent être imprimées.

## Impression de dessin

Le WLangage permet d'imprimer simplement différentes formes, grâce aux fonctions suivantes :

| [iCadre](3046044.md) | Imprime un cadre aux coordonnées spécifiées. |
| --- | --- |
| [iCadreArrondi](3046024.md) | Imprime un cadre avec des bords arrondis aux coordonnées spécifiées. |
| [iEllipse](3046009.md) | Imprime une ellipse (à l'intérieur d'un rectangle). |
| [iImprimeCodeBarre](3046020.md) | Imprime un code-barres (à l'intérieur d'un rectangle). |
| [iLigne](3046035.md) | Imprime une ligne (au standard Windows, avec le bout arrondi) aux coordonnées spécifiées. |
| [iMagentaTransparent](3046003.md) | Modifie la gestion de la couleur Magenta afin que cette couleur soit considérée comme transparente ou non dans toutes les prochaines impressions. |
| [iPosX](3046015.md) | Permet de gérer la position horizontale (abscisse ou colonne) du curseur d'impression dans la page. |
| [iPosY](3046075.md) | Permet de gérer la position verticale (ordonnée ou ligne) du curseur d'impression dans la page. |
| [iTrait](3046050.md) | Imprime un trait aux coordonnées spécifiées. |
| [iTraitH](3046051.md) | Imprime un trait horizontal aux coordonnées spécifiées. |
| [iTraitV](3046066.md) | Imprime un trait vertical aux coordonnées spécifiées. |

## Autres fonctions

Le WLangage propose diverses fonctions permettant d'optimiser les impressions réalisées en WLangage. Il est ainsi possible de gérer par exemple :

- le saut de page
- la taille de la page, ...

| [iFinImprime](3046053.md) | Signale la fin du document à imprimer et lance l'impression effective des données actuellement stockées dans la file d'attente de l'imprimante par les fonctions [iImprime](3046031.md), [iImprimeImage](3046017.md), [iLigne](3046035.md), etc. |
| --- | --- |
| [iHauteurPage](3046052.md) | Calcule la hauteur de la page imprimable (en millimètres) en tenant compte des marges (hautes ou bases) définies. |
| [iHauteurRestantePage](3046060.md) | Calcule la hauteur disponible (en millimètres) restant sur la page en cours en tenant compte des marges (hautes ou basses) définies. |
| [iLargeurPage](3046036.md) | Calcule la largeur de la page imprimable (en millimètres) en tenant compte des marges (gauches ou droites) définies. |
| [iNumColonne](1000018825.md) | Renvoie le numéro de la colonne en cours dans un état multi-colonnes. |
| [iNumPage](3046013.md) | Renvoie ou initialise le numéro de la page en cours d'impression. |
| [iRAZ](3046067.md) | Ré-initialise les paramètres d'impression (marges, police, format du papier, orientation, ...) mémorisés dans la librairie d'impression. |
| [iSauteLigne](3046071.md) | Force un ou plusieurs sauts de ligne. |
| [iSautePage](3046073.md) | Génère un saut de page : le code correspondant est envoyé dans la file d'impression de l'imprimante. |
| [iStatusImpressionEtat](3046043.md) | Renvoie l'état de l'impression en cours. |
