# JourDuMoisOuDeLaSemaine (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **JourDuMoisOuDeLaSemaine** permet de gérer l'exécution d'une tâche planifiée en précisant le numéro de jour de la semaine ou le numéro de jour du mois. Exemple : exécution tous les lundis 1er jour du mois.
Cette propriété est utilisable sur :

- une variable de type [hTâchePlanifiée](1000017448.md).
- une variable de type [hPlanification](1000018853.md).
- une variable de type [Répétition](1000019262.md).
- une variable de type [serveurAppliTâchePlanifiée](1000022367.md).
