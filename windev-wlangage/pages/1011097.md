# Etat sur une classe (MVP)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WINDEV Mobile** (iPhone/iPad, Mac Catalyst)

## Présentation

L'état sur une classe permet d'imprimer directement les informations présentes dans un membre de type Tableau d'une classe.
Ce type d'état est notamment utile pour réaliser les états des applications MVP.

Remarque : l'instance de la classe parente doit être passée en paramètre à l'état lors de l'impression.
[**Le logiciel Etats & Requêtes**](3088004.md) ne permet pas de créer ou de modifier des états sur classe.

## Créer un état sur une classe (MVP)

Pour créer un état sur variable :

1. Cliquez sur  parmi les boutons d'accès rapide.
  - La fenêtre de création d'un nouvel élément s'affiche : cliquez sur "Etat" puis sur "Etat".
  - L'assistant de création d'un état se lance.
2. Dans l'assistant, choisissez la présentation de votre état (tableau, fiche, étiquette, etc.). Pour plus de détails, consultez [Les différents types d'états](1011054.md).
3. Sélectionnez si nécessaire le modèle d'états à utiliser. Un modèle d'états permet de respecter une mise en page spécifique. Pour plus de détails sur les modèles d'états, consultez [Les modèles d'états](9000105.md).
4. Sélectionnez la source de données de l'état (option "Une classe en paramètre (architecture MVP)").
5. Sélectionnez le membre de type tableau sur lequel est basé l'état. Seules les classes présentes dans le projet en cours et les membres associés sont proposées.
6. Pour grouper les enregistrements, il est possible de créer des ruptures sur les éléments du tableau. Pour créer des ruptures, répondez "Oui" à la question "Voulez-vous des ruptures dans l'état ?".
  L'étape suivante de l'assistant permet alors de sélectionner les variables correspondant aux ruptures.
  **Attention** : Avant d'imprimer l'état, il sera nécessaire de trier le tableau par programmation selon la variable de rupture. Ce tri sera par exemple réalisé avec la fonction [Trie](1000017364.md).
  Pour plus de détails sur les ruptures, consultez les [Ruptures dans un état](1011028.md).
7. Sélectionnez les membres à afficher dans l'état. Modifiez si nécessaire l'ordre d'affichage des différents champs dans l'état à l'aide des boutons fléchés à droite de la liste.
8. Sélectionnez le bloc dans lequel chaque variable sera affiché. Il est également possible de renommer le libellé du champ.
  Remarque : Par défaut, les champs associés aux variables sont affichées dans le bloc Corps. Le libellé du champ correspond par défaut au nom de la variable. Ce libellé pourra être modifié également directement sous l'éditeur d'états.
9. Si la variable associée à l'état contient au moins une rubrique de type numérique, il est possible de réaliser des calculs sur ces rubriques. Spécifiez le calcul réalisé pour chaque rubrique (somme, moyenne, etc.). Deux types de calcul sont possibles :
  - calcul général : un champ Calculé sera créé dans le bloc *Fin de document*.
  - calcul sur rupture : un champ Calculé sera créé dans le bloc *Bas de rupture*. Dans les calculs sur rupture, le résultat du calcul est réinitialisé à chaque rupture. Pour réaliser un calcul sur rupture, une rupture doit être présente dans l'état en cours de création.
10. Selon le type d'état en cours de création, indiquez les options spécifiques correspondantes.
  | Type d'état | Options spécifiques |
  | --- | --- |
  | État sur formulaire | Image du formulaire, impression de l'image du formulaire, etc. Options détaillées dans la page [Etat sur formulaire](1011067.md) |
  | État Étiquette | Format des étiquettes, nombre d'exemplaires identiques, etc. Options détaillées dans la page [Etat Étiquette](1011050.md) |
11. Spécifiez le format de la feuille sur laquelle l'état va être imprimé. Par défaut, l'état est imprimé sur une feuille au format A4.
  Remarque : Par défaut, les champs de l'état sont disposés sur une seule colonne. Pour réaliser un état multicolonne, il suffit de spécifier le nombre de colonnes voulues dans l'onglet "Format" de la fenêtre de description de l'état.
12. Sélectionnez le gabarit de l'état si nécessaire.
13. Saisissez le nom et le titre de l'état (nom du fichier ".WDE" correspondant à l'état). Ce nom permettra d'identifier l'état dans vos programmes.
14. Validez la création de l'état.
15. L'éditeur d'états propose automatiquement de changer le format de l'état utilisé si les conditions suivantes sont réunies :
  - l'état en cours de création comporte un tableau.
  - le format de l'état ne permet pas d'afficher l'ensemble des colonnes du tableau.
16. Si nécessaire, indiquez le mode de réduction de l'état :
  - Imprimer l'état sur plusieurs pages. Dans ce cas, l'utilisateur final devra assembler les pages. Pour plus de détails, consultez [Impression multipage](1011065.md).
  - Utiliser le mode paysage.
  - Réduire l'état par rapport à l'original. Attention : selon le pourcentage de réduction choisi, l'état imprimé pourra devenir illisible.
17. L'état en cours de création s'affiche sous l'éditeur d'états.

## Imprimer un état sur une classe (MVP)

### Imprimer un état sur une classe
Pour imprimer un état sur une classe, il suffit de :

1. Initialiser la classe, l'objet associée et le membre utilisé.
2. Si nécessaire, trier le membre de type tableau (par exemple avec la fonction [TableauTrie](3075007.md)).
3. Paramétrer la destination de l'impression de l'état :
  - En WINDEV, grâce à la fonction [iDestination](3046074.md) (visualisateur de rapports, impression dans un fichier HTML, etc.).
  - En WEBDEV, grâce à la fonction [iDestination](3046074.md) (impression dans un fichier HTML, etc.).
   Pour plus de détails, consultez [Modes d'impression d'un état](1011031.md).
4. Préciser le nom de l'état à imprimer et l'instance de la classe parente lors de l'appel à la fonction [iImprimeEtat](3046032.md).

Si nécessaire, il est possible de spécifier des paramètres supplémentaires lors de l'impression d'un état paramétré basé sur une classe. Par exemple, il est possible de passer en paramètre le nom de la variable tableau à utiliser. Dans ce cas, l'état est un état paramétré sur une variable tableau (voir paragraphe suivant). Sous [le logiciel Etats & Requêtes](3088004.md), il est possible d'imprimer un état :

- soit en lançant une impression (icône ).
- soit en testant l'état (icône ).

Il n'est donc pas nécessaire de programmer l'impression de l'état.

### Remarques

- La propriété [NomSource](2511035.md) utilisée dans le code de l'état permet de connaître et de changer le nom de la variable associée à l'état.
- La propriété [RubriqueAffichee](2510123.md) utilisée dans le code de l'état permet de connaître et de changer le nom de la variable associée à la rubrique.
- Nouveauté SaaS
  Le mot-clé **MaValeurMémorisée** permet de connaître l'objet en cours du tableau de classes pendant l'impression d'un état basé sur une classe.

### Imprimer un état paramétré basé sur une classe
Pour imprimer un état paramétré basé sur une classe, il suffit de :

1. Initialiser la classe, l'objet associée et le membre utilisé.
2. Si nécessaire, trier le membre de type tableau (par exemple avec la fonction [TableauTrie](3075007.md)).
3. Paramétrer la destination de l'impression de l'état :
  - En WINDEV, grâce à la fonction [iDestination](3046074.md) (visualisateur de rapports, impression dans un fichier HTML, etc.).
  - En WEBDEV, grâce à la fonction [iDestination](3046074.md) (impression dans un fichier HTML, etc.).
   Pour plus de détails, consultez [Modes d'impression d'un état](1011031.md).
4. Préciser les paramètres suivants grâce à la fonction [iImprimeEtat](3046032.md) :
  - le nom de l'état à imprimer.
  - l'instance de la classe parente.
  - les différents paramètres attendus par l'état (dans l'ordre spécifié dans l'état).

Remarque : Pour plus de détails sur le passage de paramètres à un état, consultez [Etats paramétrés](1011008.md).
