# StatErreur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Calcule le numéro de la dernière erreur due à une fonction Statxx ([fonctions statistiques](3050027.md)).

## Exemple

```wlangage
// Identification du type d'erreur
ResErreur = StatErreur()
```

## Syntaxe

```wlangage
<Résultat> = StatErreur()
```

`<Résultat>` *Entier*
> Numéro de la dernière erreur due à une fonction statistique :
>
> | 0 | Pas d'erreur | Toutes les fonctions |
> | --- | --- | --- |
> | 1 | Matrice vide | Toutes les fonctions |
> | 2 | Deux valeurs minimum sont nécessaires dans la ligne ou la colonne de la matrice | [StatVariance](3050033.md), [StatEcartMoyen](3050024.md) |
> | 3 | Moyenne géométrique négative | [StatMoyenne](3050036.md), [StatEcartType](3050025.md) |
> | 4 | Division par zéro | [StatMoyenne](3050036.md), [StatCorrélation](3050022.md) |
> | 5 | La matrice n'existe pas ou les valeurs limites sont dépassées | Toutes les fonctions |

## Remarques

Le libellé de l'erreur peut être connu grâce à la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.

**Classification Métier / UI : Code neutre**

**Composante : wd300mat.dll**
