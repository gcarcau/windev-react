# Fonctions de gestion des champs Liste, Liste image et Combo

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des champs Liste, Liste image et Combo (syntaxe préfixée)](1000017419.md)).
Les fonctions permettant de gérer les champs Liste, Liste image et Combo sont les suivantes :

| [FichierVersListeMémoire](3049007.md) | Remplit un champ Liste par programmation (ou Combo) avec tous les enregistrements d'un fichier de données ou d'une requête. |
| --- | --- |
| [ListeAffiche](3049005.md) | Rafraîchit l'affichage d'un champ Liste, Liste image ou Combo fichier |
| [ListeAjoute](3049004.md) | Ajoute un élément dans un champ Liste par programmation (y compris Liste image) ou un champ Combo par programmation. |
| [ListeCherche](3049003.md) | Recherche un élément dans un champ Liste (liste classique ou liste image) ou un champ Combo (y compris les valeurs décrites par la fonction [gValeurMémorisée](1410088363.md)). |
| [ListeDéplaceLigne](1000017279.md) | Déplace une ligne ou échange deux lignes d'un champ Liste ou Combo. |
| [ListeInfoXY](3049006.md) | Renvoie, pour une position dans un champ Liste (liste classique ou liste image), l'indice de la ligne (ou de l'image) correspondant à cette position. |
| [ListeInsère](3049002.md) | Insère un élément dans un champ Liste par programmation (y compris Liste image) ou dans un champ Combo par programmation. |
| [ListeModifie](3049009.md) | Modifie un élément dans un champ Liste par programmation (liste classique ou liste image) ou dans un champ Combo par programmation. |
| [ListeOccurrence](3049014.md) | Renvoie le nombre d'éléments présents dans un champ Liste, Liste image ou Combo. |
| [ListePosition](3049015.md) | Affiche un champ Liste (y compris Liste image) à partir d'un élément spécifié ou renvoie l'indice du premier élément affiché dans un champ Liste (lorsque l'ascenseur du champ a été utilisé). |
| Nouveauté 2025 [ListeProcédureChargeImage](1410090789.md) | Permet d'indiquer la procédure appelée lors de l'affichage d'une ligne d'un champ Liste image. Il est ainsi possible d'afficher une image calculée plutôt qu'une image stockée sur le disque. |
| [ListeSelect](3049011.md) | Renvoie l'indice de l'élément sélectionné dans un champ Liste, Liste image ou Combo. |
| [ListeSelectMoins](3049008.md) | Désélectionne un élément dans un champ Liste, Liste image ou Combo. |
| [ListeSelectOccurrence](3049010.md) | Renvoie le nombre d'éléments sélectionnés dans un champ Liste, Liste image ou Combo. |
| [ListeSelectPlus](3049012.md) | Sélectionne un ou plusieurs éléments dans un champ Liste, Liste image ou Combo. |
| [ListeSupprime](3049016.md) | Supprime un élément d'un champ Liste par programmation (y compris Liste image) ou d'un champ Combo par programmation. |
| [ListeSupprimeTout](3049013.md) | Vide de tous ses éléments un champ Liste par programmation (y compris Liste image) ou un champ Combo par programmation. |
| [ListeTrie](1000017022.md) | Trie les éléments d'un champ Liste, Liste image ou Combo rempli par programmation. |

## Liste des exemples associés :

| [image: Le champ Liste Image] | Exemples unitaires (WINDEV) : Le champ Liste Image     [ + ] Utilisation du champ Liste Image de WINDEV. Le champ Liste Image permet d'afficher le contenu d'une liste sous forme de vignettes. Tout comme les champs Liste ou Table, le champ Liste Image peut être "mémoire" (rempli par programmation) ou "fichier" (lié à une base de données). |
