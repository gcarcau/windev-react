# fSurveilleStop (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Arrête toutes les surveillances en cours sur un fichier ou un répertoire. Ces surveillances ont pu être lancées par la fonction [fSurveilleFichier](1000020522.md) ou par la fonction [fSurveilleRépertoire](1000020523.md).

## Exemple

```wlangage
// Arrêt de toutes les surveillances en cours sur le répertoire "C:\Test\Dossiers importants"
SI PAS fSurveilleStop("C:\Test\Dossiers importants") ALORS
	Erreur("Aucune surveillance n'était active")
SINON
	Info("Surveillance arrêtée")
FIN
```

## Syntaxe

```wlangage
<Résultat> = fSurveilleStop(<Nom de l'élément>)
```

`<Résultat>` *Booléen*
> - Vrai si la surveillance précédemment activée a été arrêtée,
> - Faux dans le cas contraire (surveillance inexistante).
`<Nom de l'élément>` *Chaîne de caractères*
> Nom complet du fichier ou du répertoire à manipuler.

**Composante : wd300std.dll**
