# Calendrier (Type de variable)

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le type **Calendrier** permet de manipuler un calendrier (ou agenda) associé à un compte utilisateur ou bien se trouvant sur l'appareil. Il est possible de lister les rendez-vous du calendrier grâce à la fonction [RendezVousListeCalendrier](1000020661.md).
Les caractéristiques de ce calendrier peuvent être lues à l'aide de différentes propriétés WLangage.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Remplit une liste avec les calendriers disponibles sur l'appareil
tabCalendrier est un tableau de Calendrier = RendezVousListeCalendrier()
POUR TOUT Calendrier DE tabCalendrier
	ListeAjoute(LISTE_Liste1, Calendrier.Nom)
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type Calendrier
Les propriétés suivantes peuvent être utilisées pour manipuler un Calendrier :

| **Nom de la propriété** | **Type manipulé** | **Effet** |
| --- | --- | --- |
| Couleur | Entier | Couleur associé au calendrier. Cette couleur est le résultat de la formule suivante : Couleur = 65536 * Composante Bleu + 256 * Composante Verte + Composante Rouge. |
| ID | Entier sur 8 | Identifiant associé au calendrier. Cette propriété sera renseignée automatiquement lors de lecture du calendrier. Il est déconseillé de mémoriser cet identifiant au-delà de la durée de vie de l'application car cet identifiant peut être modifié lors de la synchronisation du calendrier. |
| Nom | Chaîne de caractères | Nom du calendrier. |
| NomCompte | Chaîne de caractères | Nom du compte utilisateur auquel est associé le calendrier. _(Android)_ Cette propriété peut par exemple correspondre à une adresse email dans le cas d'un compte Google (exemple "nom.prenom@gmail.com"). _(iPhone/iPad)_ Cette propriété peut par exemple correspondre à "Gmail" dans le cas d'un compte Google.  Si cette propriété correspond à une chaîne vide (""), le calendrier n'est associé à aucun compte : il se trouve uniquement stocké localement sur l'appareil. |
| TypeCompte | Chaîne de caractères | Type de compte. _(Android)_ Cette propriété peut par exemple correspondre à "com.google" pour un compte Google. _(iPhone/iPad)_ Cette propriété peut par exemple correspondre à "CalDAV", nom du protocole permettant d'accéder aux calendriers en ligne (Calendaring Extensions to WebDAV).  Si cette propriété correspond à une chaîne vide (""), le calendrier n'est associé à aucun compte et se trouve uniquement stocké localement sur l'appareil. |

Attention : Les propriétés du type **Calendrier** sont toutes en lecture seule et renseignées automatiquement lors de la lecture des calendriers avec la fonction [RendezVousListeCalendrier](1000020661.md).

## Remarques

### Fonctions utilisant des variables de type Calendrier

| [RendezVousAjoute](1000011001.md) | Ajoute un rendez-vous :   - dans l'agenda d'une messagerie Lotus Notes ou Outlook. - dans un calendrier (ou agenda) d'un appareil mobile (Android ou iOS). |
| --- | --- |
| [RendezVousListe](1000020690.md) | Liste les rendez-vous présents sur le mobile (Android/iOS) et correspondant aux critères spécifiés. |
| [RendezVousListeCalendrier](1000020661.md) | Liste les calendriers disponibles sur l'appareil mobile (Android/iOS). |
