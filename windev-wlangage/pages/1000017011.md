# VerrouAppliBloque (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

Verrouille une application WINDEV. Un mot de passe sera demandé à l'utilisateur pour déverrouiller cette application.

## Exemple

```wlangage
VerrouAppliBloque()
```

## Syntaxe

```wlangage
VerrouAppliBloque()
```

## Remarques

### Application verrouillée
Lorsque l'application est verrouillée, toutes les fenêtres de l'application sont iconisées. Lorsque l'utilisateur tente de restaurer l'application, la fenêtre suivante apparaît :
L'utilisateur doit saisir un mot de passe. Ce mot de passe peut correspondre :

- par défaut, au mot de passe Windows du poste en cours,
- au mot de passe de l'utilisateur défini dans le groupware utilisateur (si l'application utilise le groupware utilisateur),
- à un mot de passe spécifique, défini avec la fonction [VerrouAppliMotDePasse](1000017010.md).
