# telDialerCompose (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch)

Ouvre l'application de téléphonie (dialer) par défaut du téléphone et compose le numéro spécifié.

## Exemple

```wlangage
telDialerCompose("0612345678")
```

## Syntaxe

```wlangage
<Résultat> = telDialerCompose(<Numéro de téléphone>)
```

`<Résultat>` *Booléen*
> - Vrai si l'application de téléphonie a été correctement lancée,
> - Faux dans le cas contraire. En cas d'erreur, il est possible d'obtenir le détail de l'erreur grâce à la fonction [ErreurInfo](3013008.md).
`<Numéro de téléphone>` *Chaîne de caractères*
> Numéro de téléphone à composer.
> Si ce paramètre correspond à une chaîne vide (""), la fonction retournera Faux.
> Attention : le numéro ne doit pas contenir d'espaces.

## Remarques

### Cas particuliers

- Pour afficher l'écran de numérotation sans composer de numéro, utilisez la fonction [telDialerAffiche](1000019236.md).
- Il n'est pas possible de déclencher automatiquement l'appel des numéros d'urgence.
- Il n'est pas possible de composer des codes USSD.

> _(Android, Widget Android)_ Application en arrière-plan : Spécificité à partir de Android 10A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. La fonction telDialerCompose peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. Conseils : Il est possible de savoir si l'application est en arrière-plan grâce à la fonction EnModeArrièrePlan. Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type Notification). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété ActiveApplication est à Vrai. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété ActionClic.Pour plus de détails, consultez Android 10 : Comportement des applications en arrière-plan.

> _(Android, Widget Android)_ Permissions requisesL'utilisation de cette fonction entraîne la modification des permissions requises par l'application.Permission requise : CALL_PHONE.
