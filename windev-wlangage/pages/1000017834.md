# Région (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android)

La propriété **Région** permet de connaître et de modifier une région utilisée par le service publicitaire Google AdWords. Cette propriété est utilisable sur :

- une variable de type [sfInfoUtilisateur](1000018423.md).
- une variable de type [Adresse](1000019944.md).
