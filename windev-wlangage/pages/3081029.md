# XMLVersTexte (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Convertit une chaîne de caractères au format XML en une chaîne de caractères standard.

## Exemple

```wlangage
// Convertir une chaîne de caractères au format XML
// en une chaîne de caractères au format ANSI
sChaîneAnsi est une chaîne
sChaîneAnsi = XMLVersTexte("X est &gt; que Y")
// sChaîneAnsi contient "X est > que Y"
```

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Java, Code Utilisateur (MCU), PHP)_ MonDoc est une chaîne
MonDoc = fChargeTexte("exemple.xml")
MonRésultat est une chaîne
i est un entier = 1
MonRésultat = XMLExtraitChaîne(MonDoc, "NOM", i)
TANTQUE MonRésultat <> ""
 Trace(MonRésultat)
 i = i + 1
 MonRésultat = XMLVersTexte(XMLExtraitChaîne(MonDoc, "NOM", i))
FIN
// Dans la trace, on doit voir apparaître :
// navets
// échalote

## Syntaxe

```wlangage
<Résultat> = XMLVersTexte(<Chaîne à convertir>)
```

`<Résultat>` *Chaîne de caractères*
> Chaîne de caractères. Les caractères réservés suivants sont automatiquement remplacés :
>
> - &amp; devient &
> - &apos; devient '
> - &gt; devient >
> - &lt; devient <
> - &quot; devient "
`<Chaîne à convertir>` *Chaîne de caractères*
> Chaîne de caractères au format XML à convertir.

## Remarques

Pour extraire une partie d'un code XML contenu dans une balise XML, utilisez la fonction [XMLExtraitChaîne](3081017.md).
