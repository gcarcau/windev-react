# UUID

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Le mot-clé **UUID** peut correspondre :

- à une variable de type [UUID](1514083.md).
- à la propriété **UUID**. La propriété **UUID** permet de connaître l'identifiant de l'élément. Cette propriété est utilisable sur :
  - une variable de type [btleCaractéristique](1000022060.md).
  - une variable de type [btleDescripteur](1000022064.md).
  - une variable de type [btleService](1000022057.md).
  - une variable de type [beaconGroupe](1000023105.md).
  - une variable de type [beaconInfoDétection](1000023109.md).
