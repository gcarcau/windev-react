# MatInverse (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Inverse une matrice carrée.
**Remarque** : La matrice inverse ne peut être calculée que :

- à partir d'une matrice carrée (nombre de lignes égal au nombre de colonnes)
- si le déterminant (renvoyé par la fonction [MatDéterminant](3050045.md)) n'est pas nul.

## Exemple

```wlangage
// Inversion d'une matrice carrée
ResInversion = MatInverse("MaMatrice", "MaMatriceInversée")
```

## Syntaxe

```wlangage
<Résultat> = MatInverse(<Matrice à inverser> , <Matrice inversée>)
```

`<Résultat>` *Booléen*
> - Vrai si l'inversion a été effectuée,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Matrice à inverser>` *Chaîne de caractères*
> Nom de la matrice à inverser, défini avec la fonction [MatCrée](3050058.md).
`<Matrice inversée>` *Chaîne de caractères*
> Nom de la matrice inversée, automatiquement créée lors de l'inversion.

## Remarques

### Existence de la matrice inversée
L'existence de la matrice n'est pas vérifiée. Si la matrice existait auparavant, cette matrice est écrasée. Pour vérifier l'existence d'une matrice, utilisez la fonction [MatExiste](3050076.md).

### Matrices identiques
Une erreur du WLangage est générée si le paramètre <Matrice à inverser> et le paramètre <Matrice inversée> sont identiques.
