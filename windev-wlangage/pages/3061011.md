# GraveurPropriété (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Permet de connaître ou de modifier les propriétés du graveur en cours. Ce graveur peut être sélectionné grâce à la fonction [GraveurSélectionne](3061012.md).
**Remarque** : Pour connaître l'ensemble des graveurs disponibles à partir du poste en cours, utilisez la fonction [GraveurListe](3061009.md).

## Exemple

```wlangage
// Vitesse du graveur
ResVitesse est un entier
ResVitesse = GraveurPropriété(graveurVitesse)

Info("La vitesse de gravure est : " + ResVitesse + "x")
```

```wlangage
// Gestion du "SmartBurn"
GraveurPropriété(graveurSmartBurn, 1)
```

## Syntaxe

#### Connaître les propriétés du graveur

```wlangage
<Résultat> = GraveurPropriété(<Propriété du graveur>)
```

`<Résultat>` *Entier*
> Valeur de la propriété demandée.
`<Propriété du graveur>` *Constante de type Entier*
> Propriété à demander :
>
> | *graveurSecondesEntrePistes* | Nombre de secondes insérées entre chaque piste. |
> | --- | --- |
> | *graveurSmartBurn* | Gestion du SmartBurn :  - 0 : le SmartBurn n'est pas géré. - 1 : le SmartBurn est géré. |
> | *graveurVitesse* | Vitesse actuelle de gravure |
> | *graveurVitesseMax* | Vitesse maximale de gravure |

#### Modifier les propriétés du graveur

```wlangage
<Résultat> = GraveurPropriété(<Propriété du graveur> , <Nouvelle valeur>)
```

`<Résultat>` *Booléen*
> - Vrai si la propriété a été modifiée,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Propriété du graveur>` *Constante de type Entier*
> Propriété à modifier :
>
> | *graveurSecondesEntrePistes* | Nombre de secondes insérées entre chaque piste. |
> | --- | --- |
> | *graveurSmartBurn* | Gestion du SmartBurn :  - 0 : le SmartBurn n'est pas géré. - 1 : le SmartBurn est géré. |
> | *graveurVitesse* | Vitesse de gravure. |
`<Nouvelle valeur>` *Entier*
> Nouvelle valeur de la propriété demandée.

## Remarques

### SmartBurn
La technologie Smart Burn (Smart Monitoring And Adapting Recording Technology for Burning) optimise la vitesse de gravure en fonction de la qualité du CD utilisé et permet d'éviter les erreurs du type "buffer underruns".
Cette technologie est disponible uniquement sur certains types de graveur.

### Configuration nécessaire

> _(WINDEV)_ La gravure de CD est disponible uniquement sous Windows XP et supérieur. La gravure de DVD est disponible sous Windows Vista, et sous Windows XP en utilisant la mise à jour KB932716 pour Windows XP (cette mise à jour doit être téléchargée depuis le site de Microsoft et installée car elle n'est pas prise en compte par le mécanisme de Live Update).

> _(WEBDEV - Code Serveur)_ La gravure de CD et DVD sera réalisée sur le serveur Web. Pour graver des CD ou des DVD, le serveur doit être sous Windows XP ou supérieur. Pour graver des CD sous Windows 2003 Serveur, il est nécessaire d'activer le service de gravure IMAPI (nommée "Service COM de gravage de CD IMAPI"). Pour graver des DVD sous Windows 2003 Serveur, il est nécessaire d'installer en plus la mise à jour KB932716.

**Composante : wd300grv.dll**
