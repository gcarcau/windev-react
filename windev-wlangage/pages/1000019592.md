# Administrateur de la fabrique logicielle

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

L'administrateur de la fabrique logicielle permet de :

- gérer les plans d'actions : exécution, paramétrage, etc.
- gérer les planifications des plans d'action.
- gérer les automates.
- gérer les plans d'action dans l'entrepôt.
- [définir les options de l'administrateur](1000019583.md).

Les différents options sont regroupées dans les différents onglets de l'administrateur de la fabrique logicielle. Pour lancer l'administrateur de la Fabrique Logicielle :

1. Sous le volet "Outils", dans le groupe "Utilitaires", cliquez sur "WDFAdmin".
2. Dans la fenêtre qui s'affiche, indiquez le nom du coordinateur auquel l'administrateur doit se connecter.
3. L'administrateur de la Fabrique Logicielle se lance.

## Gestion des plans d'action

L'onglet "Plans d'action" permet de visualiser des différents utilisateurs, leur propriétaire et la date de dernière exécution.
Il est possible de :

- Exécuter le ou les plans d'action sélectionnés,
- Actualiser l'affichage.
- Utiliser un plan d'action : Permet d'ajouter un plan d'action à la liste des plans d'action de l'utilisateur en cours. Lors de l'ajout d'un plan d'action, il faut :
  - Sélectionner le plan d'action à ajouter dans la liste des plans d'action de l'entrepôt.
  - Paramétrer le plan d'action. Ce paramétrage permet de créer une instance de plan (appelé également un "plan d'action paramétré"). Lors de ce paramétrage, il est possible de définir : la description, les paramètres du plan d'action, les notifications et les étiquettes associées.
- Supprimer le paramétrage. Dans ce cas, le paramétrage spécifique du plan d'action sera supprimé.
- Modifier le paramétrage : Permet de modifier les options du plan d'action. Il est notamment possible de définir les options de planification et d'exécution.
- Dupliquer le paramétrage : Permet de dupliquer le paramétrage du plan d'action en cours. Cette option permet simplement de créer un nouveau paramétrage en reprenant la majorité des options du paramétrage en cours.
- Planifier le plan d'action : Permet de planifier l'exécution du plan d'action à l'aide d'un assistant.

## Gestion des planifications

L'onglet "Planifications" permet de visualiser les planifications définies pour les plans d'actions paramétrés de l'utilisateur en cours. Il est possible d'ajouter, modifier ou supprimer une planification.
L'option "Afficher les planifications de tous les plans d'action paramétrés de l'entrepôt" permet de lister l'ensemble des plans d'action de l'entrepôt qui possèdent une planification.

## Gestion des automates

L'onglet "Automates" permet de visualiser les différents automates gérés par le coordinateur et de connaître les différents plans d'action en cours d'exécution.
Il est possible d'agir sur les automates :

- Ajouter ou supprimer un automate.
- Editer un automate. Cette option permet notamment d'associer une étiquette à un automate.
  Les étiquettes peuvent être associées à un plan d'action paramétré et à un automate. Un plan d'action avec une ou plusieurs étiquettes s'exécutera sur l'automate ayant la même étiquette.

Il est également possible d'agir sur le spool d'exécution des plans d'action. Il est possible de :

- Supprimer un plan d'action,
- Définir l'ordre d'exécution des plans d'action.

## Gestion des plans d'action dans l'entrepôt

L'onglet "Entrepôt" liste toutes les bibliothèques et les plans d'action qui ont été déployés sur le coordinateur.
Ces plans d'action sont disponibles pour être utilisés. Lorsqu'un plan d'action est utilisé, un plan d'action paramétré est automatiquement créé à partir de ce plan d'action. Pour utiliser un plan d'action, il suffit de :

- Sélectionner le plan d'action,
- Cliquer sur le bouton "Paramétrer le plan d'action".

Le plan d'action paramétré apparaîtra ensuite dans l'onglet "Plans d'action".
Cet onglet permet de :

- Ajouter une bibliothèque : Cette option permet d'ajouter une bibliothèque de plans d'action générée mais non déployée. Pour plus de détails, consultez [Déployer un plan d'action](1000019571.md).
- Manipuler les bibliothèques de plans d'action : Mettre à jour, supprimer, éditer.
- Manipuler les plans d'action : Paramétrer ou éditer le plan d'action.
  - "Paramétrer un plan d'action" permet de créer un plan d'action paramétré qui sera affiché dans l'onglet "Plans d'action".
  - "Editer le plan d'action" permet d'afficher les caractéristiques du plan d'action et de voir tous les plans paramétrés créés à partir de ce plan d'action.
