# DateCréation (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **DateCréation** permet de connaître la date de création d'un élément. Cette propriété est utilisable sur :

- une variable de type [zipFichierArchivé](1000019044.md).
- une variable de type [docPropriété](1000022945.md).
- une variable de type [pdfDocument](1000024909.md).
- une variable de type [pdfPièceJointe](1000024899.md).
- une variable de type [FichierDisque](1410088883.md).
