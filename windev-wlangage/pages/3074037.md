# TableVersXML (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP)

Crée un fichier XML avec les données d'un champ Table ou Table hiérarchique.
**Remarques** :

- Par défaut, une feuille de styles (fichier ".XSL") est automatiquement générée lors de la création du fichier XML.
- L'entité document du fichier XML généré se nomme WINDEV_TABLE.

## Exemple

> _(WINDEV, Etats et Requêtes, Code Utilisateur (MCU))_ sFic est une chaîne
// Nom du fichier
sFic = fSélecteur("", "", "Choisissez le fichier d'exportation", ...
 "Fichiers XML (*.XML) *.xml", "xml", fselCrée + fselExiste)
// Si le nom n'a pas été fourni, on abandonne l'export
// Sinon, on exporte le contenu du champ Table TABLE_TABLE1
SI sFic <> "" ALORS TableVersXML(TABLE_TABLE1, sFic, taSansTitre)

> _(WEBDEV - Code Serveur, Ajax)_ sFic est une chaîne
// Nom du fichier
sFic = ComplèteRep(fRepExe()) + "MonXML" + ConnexionOccurrence() + ".xml"
// Si le nom n'a pas été fourni, on abandonne l'export
// Sinon, on exporte le contenu du champ Table TABLE_TABLE1
SI sFic <> "" ALORS TableVersXML(TABLE_TABLE1, sFic, taSansTitre)

## Syntaxe

```wlangage
<Résultat> = TableVersXML(<Champ Table> , <Nom du fichier XML> [, <Options> [, <Ligne début> [, <Ligne fin>]]])
```

`<Résultat>` *Booléen*
> - Vrai si le fichier a été créé,
> - Faux dans le cas contraire.
`<Champ Table>` *Nom de champ*
> Nom du champ à manipuler. Ce champ peut correspondre :
>
> - à un champ Table.
> - à un champ Table hiérarchique.
`<Nom du fichier XML>` *Chaînes de caractères*
> Nom et chemin complet du fichier XML à créer. Si le fichier existe déjà, il est remplacé par le nouveau fichier.
`<Options>` *Constante optionnelle de type Entier*
> Paramètre le fichier XML à créer.
>
> | *taAvecColonnesInvisibles* | Exporte aussi les colonnes invisibles du champ. _(WINDEV)_ Les colonnes définies comme non imprimables et non exportables sont exportées. Ces colonnes sont définies : soit par programmation : propriété VisibleEnExportEtImpression à Faux. soit dans l'onglet "Général" de la fenêtre de description des colonnes : option "Export et impression" à "Jamais". |
> | --- | --- |
> | *taColonneOrdreAffiché* | Exporte les colonnes selon l'ordre des colonnes actuellement affiché dans le champ (et non selon l'ordre des colonnes défini sous l'éditeur). _(WEBDEV - Code Serveur)_ Cette constante n'est pas disponible. |
> | *taLigneSélectionnées* | Exporte uniquement les lignes sélectionnées (par défaut, toutes les lignes sont exportées). |
> | *taSansTitre* | Seules les données sont copiées dans le fichier. |
> | *taSansTotaux* | N'exporte pas :   - les lignes de totaux, moyenne et comptage automatique (par défaut, ces lignes sont exportées). - les lignes de calculs personnalisés (par défaut, ces lignes sont exportées). _(WEBDEV - Code Serveur)_ Cette constante n'est pas disponible. |
> | *taSansXSL* | La feuille de style (fichier ".XSL") n'est pas créée. |
> | *taTitreColonnes* (valeur par défaut) | Le titre des colonnes est inséré dans le fichier. |
`<Ligne début>` *Entier optionnel*
> Numéro de la ligne de début de l'exportation.
> Si ce paramètre n'est pas précisé, la ligne de début est la première ligne du champ.
`<Ligne fin>` *Entier optionnel*
> Numéro de la ligne de fin de l'exportation.
> Si ce paramètre n'est pas précisé, la ligne de fin est la dernière ligne du champ.

## Remarques

### Conditions d'utilisation
La fonction **TableVersXML** peut être utilisée indifféremment sur :

- un champ Table ou Table hiérarchique fichier.
- un champ Table ou Table hiérarchique par programmation.
- un champ monosélection ou multisélection.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ Colonne de type mémo binaire (image)Pour les colonnes de type mémo binaire, le fichier XML contient une chaîne vide.

### Limite
Les colonnes fusionnées sont ignorées.
