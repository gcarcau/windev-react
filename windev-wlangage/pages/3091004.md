# Fonctions Exif

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Les fonctions permettant de manipuler les marqueurs Exif sont les suivantes :

| [ImageInfoFerme](3091001.md) | Ferme le fichier image (au format JPEG ou TIFF) utilisé par la fonction [ImageInfoValeur](3091003.md) et/ou la fonction [ImageInfoListe](3091002.md) et libère l'image de la mémoire. |
| --- | --- |
| [ImageInfoListe](3091002.md) | Renvoie la liste des marqueurs Exif disponibles pour l'image manipulée. |
| [ImageInfoModifie](3091005.md) | Modifie la valeur d'un marqueur Exif pour l'image manipulée. |
| [ImageInfoSauve](3091006.md) | Enregistre les modifications effectuées sur les marqueurs Exif d'une image à l'aide de la fonction [ImageInfoModifie](3091005.md). |
| [ImageInfoValeur](3091003.md) | Renvoie la valeur d'un marqueur Exif pour l'image manipulée. |

## Liste des exemples associés :

| [image: Les fonctions EXIF] | Exemples unitaires (WINDEV) : Les fonctions EXIF     [ + ] Utilisation des fonctions ImageXXX. Ces fonctions permettent d'accéder aux informations EXIF d'une image. Les informations EXIF sont contenues dans les images de type JPEG ou TIFF. Il y a par exemple, la date de prise de vue de la photo, l'orientation de l'appareil quand la photo a été prise, la marque et le modèle de l'appareil photo, une miniature de l'image... |
