# Commentaire (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

La propriété **Commentaire** permet de gérer les commentaires. Cette propriété est utilisable sur :

- un champ de type Tableur. Pour plus de détails, consultez [Commentaire](1410090471.md).
- une variable de type [sfRequêteTraitementSoumission](1000018516.md).
- une variable de type [sfRequêteTraitementTâche](1000018520.md).
- une variable de type [Cookie](1000019222.md).
- une variable de type [InfoVersion](1000018905.md).
- une variable de type [docPropriété](1000022945.md).
- une variable de type [diagForme](1410088082.md).
- une variable de type [diagSélection](1410088172.md).
- une variable de type [mongoLotOpérationsOption](1410089271.md).
- une variable de type [xlsDocument](1000017464.md).
- Nouveauté Abonnement
   une variable de type [pdfProtection](1410091145.md).
  Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
