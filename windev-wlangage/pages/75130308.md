# Table,Affiche (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Rafraîchit l'affichage du champ Table. Les champs calculés sont recalculés. Le champ Table est repositionné par rapport au fichier de données.

## Exemple

```wlangage
// En CAPPELWD("Table,Affiche,TabProduit,10");
```

```wlangage
// En PascalAPPELWD('Table,Affiche,TabProduit,10');
```

```wlangage
// En VBcall APPELWD("Table,Affiche,TabProduit,10")
```

## Syntaxe

```wlangage
Table,Affiche(<Champ Table> , <Indice>)
```

`<Champ Table>` *Nom de champ*
> Nom du champ Table à manipuler.
`<Indice>` *Chaîne de caractères*
> Indice de l'élément à réafficher ou caractère indiquant l'action à réaliser.

## Remarques

### Affichage d'un champ Table par programmation

- Si <Indice> est précisé, **Table,Affiche** réaffiche la ligne dont l'indice est spécifié.
- Si <Indice>=P ou si <Indice>=T ou si <Indice>=*, **Table,Affiche** réaffiche les éléments actuellement visualisés.
- **Table,Affiche** est utilisée pour recalculer les champs calculés.

### Affichage dans un champ Table fichier

- Si <Indice> est précisé, **Table,Affiche** réaffiche la ligne dont l'indice est spécifié.
- Si <Indice>=P, **Table,Affiche** réaffiche les éléments actuellement visualisés dans le champ Table. Cela permet de réactualiser l'affichage (après l'écriture dans le fichier par Table,Enregistre par exemple)
- Si <Indice>=T, **Table,Affiche** réaffiche le champ Table à partir de l'élément en cours dans le fichier. Il est ainsi possible d'afficher le champ Table à partir d'une position donnée.

Par exemple pour afficher les enregistrements correspondant à une recherche.

1. La recherche est effectuée (HLitRecherche).
2. Le résultat est affiché avec Table,Affiche.
