# NomDécrit (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **NomDécrit** permet de gérer le nom logique des fichiers de données HFSQL (sans tenir compte des éventuelles modifications effectuées par la fonction [HAlias](3044176.md)). Il est ainsi possible de :

- Connaître le nom logique d'un élément :
  - fichier de données défini sous l'éditeur d'analyses ou défini par programmation,
  - vue,
  - requête
- Définir le nom logique d'un fichier de données (lors de la description du fichier par programmation uniquement).

## Exemple

```wlangage
// Connaître le nom logique du fichier de données Client
ResNom = Client.NomDécrit
```

## Syntaxe

#### Connaître le nom logique d'un élément

```wlangage
<Nom logique> = <Elément>.NomDécrit
```

`<Nom logique>` *Chaîne de caractères*
> Nom logique de l'élément :
>
> - fichier de données défini sous l'éditeur d'analyses ou défini par programmation,
> - vue,
> - requête.
`<Elément>` *Chaîne de caractères*
> Elément manipulé (par indirection par exemple).

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS, Code Utilisateur (MCU), Ajax)_ Définir le nom logique d'un fichier de données créé par programmation Masquer les détails
<Fichier de données>.NomDécrit = <Nouveau nom>

 <Fichier de données> : Chaîne de caractèresNom logique du fichier de données manipulé. Ce nom vient d'être défini grâce au type Description de Fichier. <Nouveau nom> : Chaîne de caractèresNom logique de l'élément.
