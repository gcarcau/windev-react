# Associer un identifiant à un élément d'un champ Arbre

> **Disponible :** **WINDEV** (Windows, Java) · **WEBDEV** (Windows, Linux)

## Identifiant d'un élément

WINDEV, WINDEV Mobile et WEBDEV donnent la possibilité d'associer un identifiant à chaque élément d'un champ Arbre. Cet identifiant peut être une chaîne de caractères ou un entier.
Cet identifiant peut être utilisé pour mémoriser une information spécifique (numéro de l'enregistrement correspondant à l'élément sélectionné dans le champ Arbre par exemple).

**Remarque** : Il est également possible d'associer une image à un élément. Pour plus de détails, consultez [Associer une image aux éléments](1013034.md).

## Associer un identifiant à un élément

Pour associer un identifiant à un élément d'un champ Arbre, il suffit de préciser cet identifiant dans les fonctions de programmation suivantes :

| [ArbreAjoute](3018012.md) | Ajoute un élément "feuille" (et tous les noeuds nécessaires) dans un champ Arbre. |
| --- | --- |
| [ArbreInsère](3018023.md) | Insère une feuille à une position spécifique dans un champ Arbre. |
| [ArbreModifie](3018013.md) | Modifie un élément (noeud ou feuille) dans un champ Arbre. |

Ces fonctions sont également disponibles en syntaxe préfixée :

| [<Arbre>.Ajoute](1000023422.md) | Ajoute un élément "feuille" (et tous les noeuds nécessaires) dans un champ Arbre. |
| --- | --- |
| [<Arbre>.Insère](1000023761.md) | Insère une feuille à une position spécifique dans un champ Arbre. |
| [<Arbre>.Modifie](1000023763.md) | Modifie un élément (noeud ou feuille) dans un champ Arbre. |

## Lire l'identifiant d'un élément

Pour connaître l'identifiant d'un élément, il suffit d'utiliser la fonction suivante :

| [ArbreRécupèreIdentifiant](3018004.md) | Renvoie l'identifiant associé à un élément (noeud ou feuille) dans un champ Arbre. |
| --- | --- |

Cette fonction est également disponible en syntaxe préfixée :

| [<Arbre>.RécupèreIdentifiant](1000023766.md) | Renvoie l'identifiant associé à un élément (noeud ou feuille) dans un champ Arbre. |
| --- | --- |
