# <Bouton segmenté>.Supprime (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Supprime une option dans un champ Bouton segmenté.

## Exemple

```wlangage
POUR i = 4 À 1 PAS -1
	SI BS_Niveau[i].Libellé = "Avancé" ALORS
		BS_Niveau.Supprime(i)
	FIN
FIN
```

## Syntaxe

```wlangage
<Champ Bouton segmenté>.Supprime(<Indice de l'option>)
```

`<Champ Bouton segmenté>` *Nom de champ*
> Nom du champ Bouton segmenté manipulé.
`<Indice de l'option>` *Entier*
> Indice de l'option à supprimer. Cet indice doit être compris entre 1 et le nombre d'options contenues dans le champ Bouton Segmenté. La propriété [Occurrence](2510097.md) permet de connaître le nombre d'options d'un champ Bouton segmenté.

## Remarques

- Lors de la suppression d'options dans un champ Bouton segmenté, la taille du champ n'est pas modifiée. Il est possible de modifier la taille du champ avec les propriétés [Largeur](2510059.md) et [Hauteur](2510050.md).
- Lors de la suppression d'une option, les indices des options suivant l'option supprimée sont automatiquement renumérotés.
