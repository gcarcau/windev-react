# Fonctions de gestion des fichiers PDF

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des fichiers PDF (syntaxe préfixée)](1410089902.md)).
Pour manipuler les fichiers PDF, le WLangage dispose de différents types de variables :

| Nouveauté 2025 [pdfChamp](1410090536.md) | Le type **pdfChamp** permet de connaître toutes les caractéristiques et les valeurs d'un champ présent dans un formulaire au format PDF. |
| --- | --- |
| [pdfDocument](1000024909.md) | Le type **pdfDocument** permet de connaître toutes les caractéristiques d'un fichier PDF : auteur, date de création, contenu des pages, ... |
| [pdfElémentTexte](1000024556.md) | Le type **pdfElémentTexte** permet de connaître toutes les caractéristiques d'un élément textuel dans une page PDF. |
| Nouveauté 2025 [pdfOptionChamp](1410090533.md) | Le type **pdfOptionChamp** permet de connaître et de modifier les caractéristiques suivantes d'une option d'un champ présent dans un formulaire PDF :   - libellé de l'option. - sélection ou non de l'option. |
| [pdfPage](1000024904.md) | Le type **pdfPage** permet de définir toutes les caractéristiques avancées d'une page d'un document PDF chargé en mémoire. |
| [pdfParamètre](1410087857.md) | Le type **pdfParamètre** permet de définir toutes les caractéristiques d'un fichier PDF à générer. |
| [pdfPièceJointe](1000024899.md) | Le type **pdfPièceJointe** permet de définir toutes les caractéristiques avancées d'une pièce jointe dans un document PDF. |
| Nouveauté Abonnement [pdfProtection](1410091145.md) | Le type **pdfProtection** permet de connaître les différentes protections appliquées à un document PDF présent dans une variable de type [pdfDocument](1000024909.md). **Ce type de variable est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.** |
| [pdfSignature](1000022255.md) | Le type **pdfSignature** permet de définir toutes les caractéristiques avancées d'une signature à appliquer à un fichier PDF lors de la signature d'un PDF existant (via la fonction [PDFSigne](1000022241.md)). |
| [pdfSignet](1410089195.md) | Le type **pdfSignet** permet de définir toutes les caractéristiques avancées d'un signet dans un document PDF. |

Les fonctions permettant de manipuler des fichiers PDF via ces variables sont les suivantes :

| [PDFAjouteFiligrane](1410087843.md) | Ajoute un filigrane sur toutes les pages ou sur certaines pages d'un fichier PDF existant. |
| --- | --- |
| [PDFAjouteImage](1410087847.md) | Ajoute une image dans une page d'un fichier PDF existant. |
| [PDFExtraitPage](1000021279.md) | Extrait une page d'un fichier PDF dans une variable de type [Image](1000019650.md). |
| [PDFFerme](1000025127.md) | Ferme le fichier PDF chargé en mémoire dans une variable de type [pdfDocument](1000024909.md). |
| [PDFNbSignature](1410088119.md) | Récupère le nombre de signatures dans un document PDF. |
| [PDFOuvre](1000025032.md) | Ouvre un document PDF et charge ce document dans une variable de type [pdfDocument](1000024909.md). |
| [PDFRécupèreDateSignature](1410088121.md) | Récupère la date de l'une des signatures d'un document PDF. |
| [PDFRécupèreSignature](1410088120.md) | Récupère la signature d'un document PDF sous forme d'un buffer. |
| [PDFSauve](1000024864.md) | Sauve le contenu d'une variable de type [pdfDocument](1000024909.md) dans un fichier ".PDF". |
| [PDFSigne](1000022241.md) | Applique une signature d'approbation sur un PDF existant. |
| Nouveauté 2025 [PDFVérifieSignatures](1410090988.md) | Vérifie la validité des signatures contenues dans un PDF. **Attention** : Cette fonction est disponible uniquement à partir de la version 2025 Update 1. |
| [PDFVersTexte](1000017479.md) | Extrait le texte contenu dans un document PDF. |

Remarque : Les fonctions suivantes permettent de manipuler directement les fichiers PDF :

| [PDFEstProtégé](1000017491.md) | Vérifie si le fichier PDF nécessite un mot de passe pour être lu. |
| --- | --- |
| [PDFExtraitPage](1000021279.md) | Extrait une page d'un fichier PDF dans une variable de type [Image](1000019650.md). |
| [PDFFusionne](1000019712.md) | Fusionne plusieurs fichiers PDF existant en un seul fichier PDF. Les fichiers sont fusionnés les uns après les autres. Les chemins des fichiers PDF peuvent être présents dans un tableau. |
| [PDFFusionneAvecMotDePasse](1000020126.md) | Fusionne plusieurs fichiers PDF existants et protégés par un mot de passe d'ouverture en un seul fichier PDF. |
| [PDFMotDePasse](1000024229.md) | Protège un document PDF par un mot de passe. |
| [PDFNombreDePages](1000017480.md) | Renvoie le nombre total de pages d'un fichier PDF. |
| [PDFSigne](1000022241.md) | Applique une signature d'approbation sur un PDF existant. |
| Nouveauté 2025 [PDFVérifieSignatures](1410090988.md) | Vérifie la validité des signatures contenues dans un PDF. **Attention** : Cette fonction est disponible uniquement à partir de la version 2025 Update 1. |
| [PDFVersTexte](1000017479.md) | Extrait le texte contenu dans un document PDF. |
