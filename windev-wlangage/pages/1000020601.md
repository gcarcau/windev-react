# DateModification (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

La propriété **DateModification** permet de connaître la date de modification d'un élément. Cette propriété est utilisable sur :

- une variable de type [gglContact](1000017434.md).
- une variable de type [zipFichierArchivé](1000019044.md).
- une variable de type [hdfsInformation](1000021973.md).
- une variable de type [pdfDocument](1000024909.md).
- une variable de type [pdfPièceJointe](1000024899.md).
- une variable de type [FichierDisque](1410088883.md).
