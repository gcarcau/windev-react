# Défaut (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

La propriété **Défaut** permet de gérer les valeurs par défaut. Cette propriété est utilisable sur :

- une procédure. Pour plus de détails, consultez [Défaut](1000017046.md).
- une variable de type [gglNotification](1000026200.md).
