# Option,Test (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Affiche dans une fenêtre d'information chaque appel de fonction et chaque compte-rendu retourné par la fonction.

## Exemple

```wlangage
// En CAPPELWD("Option,Test,Oui");
```

```wlangage
// En PascalAPPELWD('Option,Test,Oui');
```

```wlangage
// En VBcall APPELWD("Option,Test,Oui")
```

## Syntaxe

```wlangage
Option,Test(<Indicateur>)
```

`<Indicateur>` *Chaîne de caractères*
> Prend pour valeur :
>
> - "oui" pour passer en mode test
> - "non" pour inhiber le mode test.

## Remarques

- Pour exécuter la fonction suivante de l'application, il faut appuyer sur une touche.
- Pour abandonner le mode test, il suffit d'appuyer sur la touche Echap (équivalent à **Option,Test,Non**).
