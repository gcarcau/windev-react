# <Editeur de code>.Commente (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur)

Commente la sélection en cours dans le champ Editeur de code. Les caractères "//" sont ajoutés devant la ligne en cours.
Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.

## Exemple

```wlangage
// Permet de commenter le code sélectionné dans le champ Éditeur de code
EDCODE_Exemple.Commente()
```

## Syntaxe

```wlangage
<Champ Editeur de code>.Commente()
```

`<Champ Editeur de code>` *Nom de champ*
> Nom du champ Editeur de code à manipuler.

**Classification Métier / UI : Code UI**

**Composante : wd300obj.dll**
