# PoliceSoulignée (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **PoliceSoulignée** permet de gérer le soulignement d'un texte. Cette propriété est utilisable sur :

- les champs. Pour plus de détails, consultez [PoliceSoulignée](2510099.md).
- une variable de type [docMiseEnForme](1000022817.md).
