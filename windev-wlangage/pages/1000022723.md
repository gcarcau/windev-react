# <Variable Connexion>.ModifieUtilisateur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Modifie les informations d'un utilisateur en fonction des éléments présents dans les [variables de gestion des utilisateurs](3044315.md) correspondantes.

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion

// Ouverture de la connexion
MaConnexion.OuvreConnexion()
// Association du fichier de données à la connexion
Client.ChangeConnexion(MaConnexion)
SI MaConnexion.InfoUtilisateur("Florence") = Vrai ALORS
	// Modification des caractéristiques
	HUtilisateur.Groupes = "ADMIN" + RC + "TEST" + RC + "DOC"
	SI MaConnexion.ModifieUtilisateur("Florence") = Vrai ALORS
		Info("Utilisateur modifié")
	FIN
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.ModifieUtilisateur(<Utilisateur>)
```

`<Résultat>` *Booléen*
> - Vrai si l'utilisateur a été modifié,
> - Faux en cas d'erreur. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle un utilisateur doit être modifié.
`<Utilisateur>` *Chaîne de caractères*
> Nom de l'utilisateur dont on veut modifier les caractéristiques. Ce nom doit correspondre à la variable **HUtilisateur.Login** de l'un des utilisateurs de la connexion spécifiée.

## Remarques

### Droits nécessaires pour modifier un utilisateur
Pour modifier un utilisateur (différent de l'utilisateur en cours), il est nécessaire de posséder le droit de visualisation des utilisateurs (constante *hDroitVisualisationUtilisateur*). Dans le cas contraire, la fonction **<Variable Connexion>.ModifieUtilisateur** renverra Faux et le message d'erreur sera "Utilisateur inconnu".
Pour modifier le nom d'un utilisateur, il est nécessaire de posséder le droit de visualisation des utilisateurs (constante *hDroitVisualisationUtilisateur*) et le droit de gestion des utilisateurs (constante *hDroitGestionUtilisateur*).

Remarque : Ces constantes sont utilisées dans les fonctions [<Variable Connexion>.InfoDroitServeur](1000022668.md) et [<Variable Connexion>.ModifieDroitServeur](1000022710.md).
