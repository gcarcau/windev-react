# SysEspace (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android) · **Autres** (Procédures stockées)

Renvoie l'espace mémoire physique du poste en cours.
> _(WEBDEV - Code Serveur)_ Renvoie l'espace mémoire physique du poste serveur.

> _(Android, Widget Android)_ Cette fonction permet de connaître uniquement l'espace libre ou total sur la carte de stockage (zone de stockage externe primaire).

## Exemple

```wlangage
// Connaître l'espace mémoire physique
ResEspMémoire = SysEspace()
```

## Syntaxe

```wlangage
<Résultat> = SysEspace([<Type de mémoire>])
```

`<Résultat>` *Entier*
> Espace demandé (en octets) du poste en cours (ou du poste serveur).
> > _(Android, Widget Android)_ Si la carte de stockage n'est pas disponible ou absente, la fonction SysEspace renvoie 0.
>
> **Remarque** : La fonction **SysEspace** retourne un entier sur 8 octets si la taille demandée est supérieure à 2 Go.
`<Type de mémoire>` *Constante optionnelle de type entier*
> Type de mémoire à renvoyer :
>
> | *sysEspaceProgramme* (Valeur par défaut) | Espace mémoire physique. _(Android, Widget Android)_ Cette constante n'est pas disponible. |
> | --- | --- |
> | *sysEspaceProgrammeLibre* | Espace mémoire physique inutilisé. _(Android, Widget Android)_ Cette constante n'est pas disponible. |
> | *sysEspaceStockage* | Espace utilisé pour le stockage _(WINDEV, WEBDEV - Code Serveur)_ Cette constante n'est pas disponible. |
> | *sysEspaceStockageLibre* | Espace libre pour le stockage _(WINDEV, WEBDEV - Code Serveur)_ Cette constante n'est pas disponible. |

**Composante : wd300std.dll**
