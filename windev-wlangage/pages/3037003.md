# Fonctions Fax

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Les fonctions permettant d'envoyer des fax sont les suivantes :

| [FaxBoîteEnvoi](3037008.md) | Énumère les fax en attente ou en cours d'envoi. |
| --- | --- |
| [FaxBoîteRéception](3037009.md) | Énumère les fax en attente ou en cours de réception. |
| [FaxConnecte](3037005.md) | Ouvre une connexion à un serveur de fax. |
| [FaxDéconnecte](3037007.md) | Ferme une connexion à un serveur de fax (précédemment ouverte avec la fonction [FaxConnecte](3037005.md)). |
| [FaxEnvoie](3037006.md) | Envoie un fax selon la connexion ouverte précédemment (fonction [FaxConnecte](3037005.md)). |
| [FaxEtat](3037001.md) | Renvoie l'état d'un fax précédemment envoyé avec la fonction [FaxEnvoie](3037006.md). |
| [FaxRéinitialise](3037012.md) | Redémarre un fax dans la file d'attente. |
| [FaxReprend](3037013.md) | Ré-active un fax mis en pause dans la file d'attente (fax mis en attente de transmission). |
| [FaxSupprime](3037014.md) | Supprime un fax de la file d'attente et annule son envoi. |
| [FaxSuspend](3037015.md) | Met en pause un fax dans la file d'attente. |
