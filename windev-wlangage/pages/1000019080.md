# <Variable zipArchive>.EstMulti (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie le type de l'archive : archive mono-partie ou archive multi-parties.

## Exemple

```wlangage
MonArchive est une zipArchive
// Ouverture de l'archive "MonArchive"
ResOuvreArchive = MonArchive.Ouvre("D:\Sauvegardes\Sauvegarde.zip")
SI ResOuvreArchive = 0 ALORS
	...
FIN
// Archive mono-partie ou multi-parties ?
ResEstMulti = MonArchive.EstMulti()
// Affichage du résultat
SI ResEstMulti = Vrai ALORS
	Info("L'archive est multi-parties")
SINON
	Info("L'archive est mono-partie")
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Archive>.EstMulti()
```

`<Résultat>` *Booléen*
> - Vrai si l'archive est multi-parties,
> - Faux si l'archive est mono-partie.
`<Archive>` *Variable de type zipArchive*
> Nom d'une variable de type [zipArchive](1000018679.md) correspondant à l'archive à manipuler.

## Remarques

### Conditions d'utilisation

- La recherche du type d'archive peut être réalisée uniquement si l'archive existe (la création d'une archive s'effectue avec la fonction [<Variable zipArchive>.Crée](1000019160.md)).
- Cette fonction est disponible pour les archives au format WDZ, ZIP et 7z.

> _(Linux, iPhone/iPad, Widget IOS, Mac Catalyst)_ Rappel : Seules les archives au format ZIP, TAR, gzip et TGZ (TAR.GZ) sont disponibles.

### Actions réalisables sur une archive multi-parties
Certaines fonctions d'archivage sont utilisables uniquement sur des archives mono-partie (ajout et suppression de fichiers, création d'un exécutable auto-extractible, etc.). Pour effectuer ces opérations, il suffit de regrouper les sous-archives ([<Variable zipArchive>.Regroupe](1000019151.md)) pour obtenir une archive mono-partie.
A partir d'une archive multi-parties, il est uniquement possible de :

- Regrouper les différentes parties (fonction [<Variable zipArchive>.Regroupe](1000019151.md)).
- Obtenir diverses informations sur l'archive et sur les fichiers de l'archive (fonctions [<Variable zipArchive>.ExtraitChemin](1000019081.md), [<Variable zipArchive>.InfoFichier](1000019092.md), [<Variable zipArchive>.ListeFichier](1000019093.md), etc.).
- Extraire les fichiers (fonctions [<Variable zipArchive>.ExtraitFichier](1000019082.md), [<Variable zipArchive>.ExtraitTout](1000019085.md)).

### Actions réalisables sur une archive mono-partie
Toutes les fonctions d'archivage sont utilisables sur des archives mono-partie, exceptée la fonction [<Variable zipArchive>.Regroupe](1000019151.md) (permettant de regrouper les différentes parties d'une archive entre elles).
