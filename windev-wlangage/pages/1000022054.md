# btlePériphérique (Type de variable)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le type **btlePériphérique** permet de manipuler un périphérique utilisant la technologie Bluetooth Low Energy.
Les caractéristiques de ce périphérique peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
monPériph est un btlePériphérique
BTLEConnecte(monPériph)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type btlePériphérique
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **btlePériphérique** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Identifiant | Chaîne de caractères | Identifiant du périphérique. _(iPhone/iPad)_ Cet identifiant est identifiant unique, géré par le système. Attention : cet identifiant peut changer à chaque nouvelle connexion du même périphérique.  Cette propriété est disponible en lecture seulement. |
| Nom | Chaîne de caractères | Nom du périphérique. Ce nom peut correspondre à une chaîne vide ("").  Cette propriété est disponible en lecture seulement. |
| Service | Tableau de [btleService](1000022057.md) | Liste des services Bluetooth LE supportés par le périphérique. Il est nécessaire d'être connecté au périphérique (avec la fonction [BTLEConnecte](1000021884.md)) pour accéder à cette propriété. Une erreur fatale sera déclenchée dans le cas contraire. |
