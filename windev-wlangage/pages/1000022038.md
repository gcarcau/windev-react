# Fond (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le type **Fond** permet de définir toutes les caractéristiques avancées du fond d'un élément. Les caractéristiques de ce fond peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Dessine un rectangle avec bords bleus, fond vert et coins arrondis
// dans un champ Image

// Initialise le dessin dans le champ Image
dDébutDessin(IMG_Dessin)

Rect est un Rectangle
Rect.X = 10
Rect.Y = 15
Rect.Largeur = 100
Rect.Hauteur = 150
StyleCadre est un Cadre
StyleCadre.Couleur  = BleuClair
StyleCadre.Arrondi = 30
StyleCadre.Epaisseur = 1
StyleFond est un Fond
StyleFond.Couleur = VertClair
dCadre(Rect, StyleCadre, StyleFond)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type Fond
Les propriétés suivantes peuvent être utilisées pour manipuler le fond d'un élément :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Couleur | Variable de type [Couleur](1000019661.md) | Couleur de fond. |
| Dégradé |  | Dégradé de la couleur de fond :   - Propriété **CouleurDébut** (type [Couleur](1000019661.md)) : Couleur de début du dégradé. - Propriété **CouleurFin** (type [Couleur](1000019661.md)) : Couleur de fin du dégradé. - Propriété **Angle** (entier) : Angle à utiliser pour la sélection des couleurs dans le dégradé. La valeur de l'angle est comprise entre 0 (angle horizontal, valeur par défaut) et 360°. - Propriété **Couleur3** (type [Couleur](1000019661.md)) : Couleur à utiliser dans le dégradé. - Propriété **DistanceCouleur3** (entier) : Pourcentage séparant la couleur de début et la couleur 3. - Propriété **Couleur4** (type [Couleur](1000019661.md)) : Couleur à utiliser dans le dégradé. - Propriété **DistanceCouleur4** (entier) : Pourcentage séparant la couleur de début et la couleur 4.   Les paramètres de couleur sont utilisés de la façon suivante :  L'angle permet de définir l'orientation du dégradé.  Les dégradés réalisés avec 3 ou 4 couleurs sont disponibles uniquement pour un angle de 0 ou de 90 degrés.  **Remarques** :    - Sur certains systèmes (TSE 256 couleurs par exemple), les dégradés ne sont pas disponibles. Dans ce cas, la couleur définie via la propriété **CouleurDébut** est affichée. - Sur les documents docx, les fonds dégradés ne sont pas gérés. |
| Hachure | Constante de type Entier | Type de hachures utilisées :   - *HachureAucune* : Pas de hachures. - *HachureCroisé* : Hachures croisées. - *HachureCroiséDiagonale* : Hachures diagonales croisées. - *HachureDiagonale* : Hachures diagonales à 60%. - *HachureDiagonaleBas* : Hachures diagonales à 120%. - *HachureHorizontale* : Hachures horizontales. - *HachureVerticale* : Hachures verticales. |
| Type | Constante de type Entier | Type de fond :   - *FondPlein* : Fond plein. - *FondTransparent* : Fond transparent (la propriété **Couleur** est alors ignorée). - *FondHachuré* : Fond avec hachures (la propriété **Hachure** est prise en compte). - *FondDégradé* : Fond avec un dégradé de couleurs (la propriété **Dégradé** est prise en compte). |

## Remarques

### Fonctions utilisant les variables de type Fond

| [dCadre](1000021894.md) | Dessine un cadre. |
| --- | --- |
| [dRectangle](3029023.md) | Dessine un rectangle :   - dans un champ Image, - dans une variable de type [Image](1000019650.md), - dans une variable de type [WDPic](1000023503.md) (sur le calque d'arrière-plan), - dans une variable de type [picCalque](1000024604.md). |
| [dRectangleArrondi](1000021773.md) | Dessine un rectangle arrondi :  - dans un champ Image, - dans une variable de type [Image](1000019650.md), - dans une variable de type [WDPic](1000023503.md) (sur le calque d'arrière-plan), - dans une variable de type [picCalque](1000024604.md). |
| [dRectangleDégradé](1000017059.md) | Dessine un rectangle :   - dans un champ Image, - dans une variable de type [Image](1000019650.md), - dans une variable de type [WDPic](1000023503.md) (sur le calque d'arrière-plan), - dans une variable de type [picCalque](1000024604.md). |

> _(Android)_ Les syntaxes des fonctions dRectangle, dRectangleArrondi et dRectangleDégradé utilisant des variables de type Cadre ou Fond ne sont pas disponibles sous Android. Il faut utiliser la fonction dCadre.
