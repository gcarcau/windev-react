# Fonctions MongoDB

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions MongoDB (syntaxe préfixée)](1000023897.md)).
Les fonctions de gestion des bases MongoDB et les GridFS sont les suivantes :

| [MongoAjoute](1000022432.md) | Ajoute un ou plusieurs documents dans une collection d'une base MongoDB. |
| --- | --- |
| [MongoCherche](1000022433.md) | Cherche des documents dans une collection MongoDB. |
| [MongoCrée](1000022408.md) | Crée une connexion à un serveur ou à un cluster MongoDB. |
| [MongoCréeCollection](1000022434.md) | Crée une collection dans une base MongoDB en précisant des options de cette collection. |
| [MongoExécuteCommande](1000022435.md) | Exécute une commande générique sur une base MongoDB ou sur une collection MongoDB. |
| [MongoExécuteLotOpérations](1410089189.md) | Effectue un ensemble d'opérations d'écriture MongoDB en lot. Il est ainsi possible d'éviter des latences réseau qui pourraient subvenir en effectuant les opérations séquentiellement. |
| [MongoGridFSEnvoieFichier](1000022436.md) | Copie un fichier du poste local vers un système de fichiers MongoDB (GridFS). |
| [MongoGridFSListeFichier](1000022438.md) | Récupère la liste des fichiers MongoDB présents dans le système de fichiers MongoDB (gridFS). |
| [MongoGridFSRécupèreFichier](1000022439.md) | Récupère sur le poste local un fichier identifié par son nom et présent dans un système de fichiers MongoDB. |
| [MongoGridFSRécupèreFichierParID](1000022595.md) | Récupère sur le poste local un fichier (identifié par son identifiant) présent dans un système de fichiers MongoDB. |
| [MongoGridFSRécupèreInfoFichier](1000023495.md) | Permet de récupérer les informations concernant un fichier MongoDB (gridFS). |
| [MongoGridFSSupprimeFichier](1000022440.md) | Supprime un fichier identifié par son nom dans un système de fichiers MongoDB. |
| [MongoGridFSSupprimeFichierParID](1000022596.md) | Supprime un fichier identifié par son identifiant dans un système de fichiers MongoDB. |
| [MongoInfo](1000022441.md) | Renvoie des informations sur une base MongoDB. |
| [MongoModifieTout](1000022603.md) | Modifie des documents dans une collection d'une base MongoDB. |
| [MongoModifieUn](1000022443.md) | Modifie un document dans une collection d'une base MongoDB. |
| [MongoPipelineAgrégation](1000025267.md) | Permet de récupérer des documents issus de la transformation et de l'agrégation en plusieurs étapes. |
| [MongoSupprimeBase](1000022444.md) | Supprime une base MongoDB et toutes ses collections. |
| [MongoSupprimeCollection](1000022558.md) | Supprime une collection d'une base MongoDB. |
| [MongoSupprimeTout](1000022445.md) | Supprime tous les documents (correspondant au filtre spécifié) d'une collection d'une base MongoDB. |
| [MongoSupprimeUn](1000022446.md) | Supprime un document dans une collection d'une base MongoDB. |

Les types de variables permettant de manipuler les bases MongoDB et les GridFS sont les suivantes :

| [mongoBase](1000022410.md) | Le type **mongoBase** permet de définir toutes les caractéristiques d'une base de données d'un serveur MongoDB. |
| --- | --- |
| [mongoBaseInfo](1000022412.md) | Le type **mongoBaseInfo** permet de définir toutes les caractéristiques avancées des informations d'une base MongoDB. |
| [mongoChercheOption](1000022414.md) | Le type **mongoChercheOption** permet de définir toutes les caractéristiques avancées d'une recherche dans une base MongoDB. |
| [mongoCollection](1000022411.md) | Le type **mongoCollection** permet de définir toutes les caractéristiques avancées d'une collection dans une base d'un serveur MongoDB. |
| [mongoCollectionOption](1000022413.md) | Le type **mongoCollectionOption** permet de définir toutes les caractéristiques avancées des options d'une collection d'une base MongoDB. |
| [mongoConnexion](1000022409.md) | Le type **mongoConnexion** permet de définir toutes les caractéristiques avancées d'une connexion à un serveur MongoDB. |
| [mongoGridFS](1000022416.md) | Le type **mongoGridFS** permet de définir toutes les caractéristiques avancées d'un système de fichiers d'une base MongoDB. |
| [mongoGridFSInfoFichier](1000022417.md) | Le type **mongoGridFSInfoFichier** permet de définir toutes les caractéristiques avancées d'un fichier contenu dans une base MongoDB. |
| [mongoOpération](1410089157.md) | Le type **mongoOpération** permet de définir les différentes opérations à effectuer par lot. Ces opérations sont enregistrées dans un tableau de variables de type **mongoOpération**. |
| [mongoOpérationAjout](1410089163.md) | Le type **mongoOpérationAjout** permet de définir toutes les caractéristiques avancées d'une opération d'ajout d'un document par lot. |
| [mongoOpérationModificationTout](1410089165.md) | Le type **mongoOpérationModificationTout** permet de définir toutes les caractéristiques avancées d'une opération de modification de documents, qui sera ensuite intégrée dans un lot d'opérations. Tous les documents correspondant au filtre de sélection seront modifiés. |
| [mongoOpérationModificationUn](1410089164.md) | Le type **mongoOpérationModificationUn** permet de définir toutes les caractéristiques avancées d'une opération de modification d'un document, qui sera ensuite intégrée dans un lot d'opérations. Le document modifié sera le premier correspondant au filtre de sélection. |
| [mongoOpérationRemplacementUn](1410089166.md) | Le type **mongoOpérationRemplacementUn** permet de définir toutes les caractéristiques avancées d'une opération de remplacement d'un élément, qui sera ensuite intégrée dans un lot d'opérations. Le document remplacé sera le premier correspondant au filtre spécifié. |
| [mongoOpérationSuppressionTout](1410089162.md) | Le type **mongoOpérationSuppressionTout** permet de définir toutes les caractéristiques avancées d'une opération de suppression de documents qui sera ensuite intégrée dans un lot d'opérations. Tous les documents correspondant au filtre de sélection seront supprimés. |
| [mongoOpérationSuppressionUn](1410089161.md) | Le type **mongoOpérationSuppressionUn** permet de définir toutes les caractéristiques avancées d'une opération de suppression d'un document, qui sera ensuite intégrée dans un lot d'opérations. Le document supprimé sera le premier correspondant au filtre spécifié. |
| [mongoOptionEcriture](1000022597.md) | Le type **mongoOptionEcriture** permet de définir le niveau d'accusé de réception demandé pour les opérations d'écriture dans un mongod autonome, dans un ensemble de réplicas ou dans des clusters fragmentés. |
| [mongoRésultat](1000022415.md) | Le type **mongoRésultat** permet de connaître le résultat lors d'une recherche dans une base de type MongoDB. |
