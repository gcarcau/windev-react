# PièceJointe (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

La propriété **PièceJointe** permet de gérer les pièces jointes. Cette propriété est utilisable sur :

- une variable de type [pdfDocument](1000024909.md).
- une variable de type [gglEvénement](1000017440.md).
