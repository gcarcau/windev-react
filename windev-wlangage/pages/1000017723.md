# TypeRemplissage (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

La propriété **TypeRemplissage** permet de connaître le type de source utilisé pour remplir les champs de type Table, Liste, Liste image, Combo et Zone répétée. Cette propriété est utilisable en lecture uniquement.

## Exemple

```wlangage
// Type de remplissage d'un champ Table
ResRemplissage = TABLE_Commande.TypeRemplissage
```

## Syntaxe

```wlangage
<Type de remplissage> = <Champ manipulé>.TypeRemplissage
```

`<Type de remplissage>` *Constante de type Entier*
> Type de remplissage du champ :
>
> | *treFichierAccèsDirect* | Champ fichier en mode accès direct. |
> | --- | --- |
> | *treFichierChargéEnMémoire* | Champ fichier en mode chargé en mémoire. |
> | *treMémoire* | Champ par programmation (fonctions [TableAjoute](3074017.md) ou [TableAjouteLigne](3074006.md) pour un champ Table). |
> | *treVariable* | Champ sur variable lié à une variable WLangage. |
`<Champ manipulé>` *Nom de champ*
> Nom du champ manipulé : champ Table, Liste, Liste image, Combo ou Zone répétée.

## Remarques

### Champs Liste, Liste image, Combo et Table fichier
Les propriétés suivantes définissent les enregistrements qui sont affichés.

- [FichierParcouru](2510040.md) : Nom du fichier de base.
- [RubriqueParcourue](2510111.md) : Nom de la rubrique utilisée pour le parcours (le tri est effectué sur cette rubrique).
- [Filtre](2510042.md) : Si ce filtre n'est pas vide, seuls les enregistrements correspondant au filtre sont affichés.
- [ParcoursAuto](2510093.md) : Indique si l'on utilise les traitements de parcours associés à l'objet.

### Equivalence
Cette propriété remplace la propriété [Mémoire](2510076.md) et permet d'obtenir des renseignements plus détaillés.
