# AvecSaisie (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

La propriété **AvecSaisie** permet de savoir si un champ Combo est avec ou sans saisie et permet de modifier cet état.

## Exemple

```wlangage
SI bModeExpert = Vrai ALORS
	COMBO_AdresseInternet.AvecSaisie = Vrai
FIN

SI COMBO_AdresseInternet.AvecSaisie = Vrai ALORS
	sAdresseNet = COMBO_AdresseInternet
SINON
	sAdresseNet = COMBO_AdresseInternet[COMBO_AdresseInternet]
FIN
```

## Syntaxe

#### Savoir si un champ Combo est avec saisie ou non

```wlangage
<Résultat> = <Champ Combo>.AvecSaisie
```

`<Résultat>` *Booléen*
> - Vrai si le champ Combo est un champ Combo avec saisie,
> - Faux dans le cas contraire.
`<Champ Combo>` *Nom de champ*
> Nom du champ Combo à manipuler.

#### Permettre ou non de saisir dans un champ Combo

```wlangage
<Champ Combo>.AvecSaisie = <Type de saisie>
```

`<Champ Combo>` *Nom de champ*
> Nom du champ Combo à manipuler.
`<Type de saisie>` *Booléen*
> - Vrai si le champ Combo doit être avec saisie,
> - Faux dans le cas contraire.

## Remarques

- La valeur renvoyée par le champ Combo est différente si le champ est en saisie (propriété **AvecSaisie** égale à Vrai) ou sans saisie (propriété **AvecSaisie** égale à Faux).
- Dans un champ Combo en saisie (propriété **AvecSaisie** égale à Vrai), l'utilisateur peut saisir une valeur dans le champ au clavier. Dans le cas contraire, l'utilisateur peut uniquement choisir une valeur dans la liste/table/popup déroulée par la combo.
