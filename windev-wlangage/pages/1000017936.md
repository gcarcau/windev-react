# Format (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **Format** permet de connaître et de modifier le format d'un élément. Cette propriété est utilisable sur :

- les fichiers de données. Pour plus de détails, consultez [Propriété Format sur les fichiers de données](2512045.md).
- une variable de type [gglParamètreCarte](1000017505.md).
- une variable de type [Icône](1000020811.md).
- une variable de type [Notification](1000019441.md).
- une variable de type [docNiveauNumérotation](1000022799.md).
- une variable de type [CodeWLangageMiseEnForme](1410090146.md).
