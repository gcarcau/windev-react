# ContinentListe (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Renvoie la liste des continents.

## Exemple

```wlangage
// Initialisation de la liste des continentstabListeContinent est un tableau de Continents = ContinentListe()POUR TOUT oContinent DE tabListeContinent ListeAjoute(LISTE_ListeContinent, oContinent.Nom)FIN
```

## Syntaxe

```wlangage
<Résultat> = ContinentListe()
```

`<Résultat>` *Tableau de Continents*
> Tableau de variables de type [Continent](1000024919.md) contenant la liste des continents.
