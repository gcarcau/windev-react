# <Variable adminWBAuth>.ListeConnexion (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Renvoie la liste des connexions en cours sur un Serveur d'application WEBDEV.

## Exemple

```wlangage
wbAuthLogin est un adminWBAuth
wbAuthLogin.AdresseServeur = "https://mon-serveur.interne/"
wbAuthLogin.Utilisateur = "WWW\DATA"
wbAuthLogin.MotDePasse = "www"

ConnexionsWB est un tableau de adminWBConnexion = wbAuthLogin.ListeConnexion()

SI ErreurDétectée = Vrai ALORS
	Info(ErreurInfo)
	RETOUR
FIN

POUR i = 1 _À_ ConnexionsWB.Occurrence
	Trace(ConnexionsWB[i].Site)
	Trace(ConnexionsWB[i].DateHeureDébutConnexion.VersChaîne())
	Trace(ConnexionsWB[i].TempsInactivité.VersChaîne(duréeCentième))
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Serveur d'application WEBDEV>.ListeConnexion()
```

`<Résultat>` *Tableau*
> Tableau de variables de type [adminWBConnexion](1410089344.md) correspondant à chaque connexion en cours sur le serveur.
> En cas d'erreur, la variable [ErreurDétectée](3087001.md) vaut Vrai.
`<Serveur d'application WEBDEV>` *Variable de type adminWBAuth*
> Nom de la variable de type [adminWBAuth](1410089328.md) décrivant le serveur et le compte administrateur utilisé pour interroger le Serveur d'application WEBDEV.

## Remarques

### Gestion de la double authentification
Il est possible d'activer la double authentification sur un compte via l'administrateur distant WEBDEV. La vérification en 2 étapes nécessite d'obtenir un code unique pour vérifier l'identité de l'utilisateur. Ce code peut être reçu par email ou via une application "Authenticator".
Lors de l'utilisation d'une fonction de pilotage du serveur d'application WEBDEV, si le compte utilise la double authentification, une erreur d'authentification peut survenir. Deux cas doivent être pris en compte :

- si la fonction renvoie un booléen, <Résultat> est à Faux. Pour vérifier si l'erreur concerne l'authentification, il est nécessaire de vérifier la valeur de la variable [ErreurDétectée](3087001.md) et la valeur renvoyée par la fonction [ErreurInfo](3013008.md).
- si la fonction ne renvoie pas de booléen. Pour vérifier si l'erreur concerne l'authentification, les conditions suivantes doivent être réunies :
  - la variable [ErreurDétectée](3087001.md) est à Vrai,
  - la fonction [ErreurInfo](3013008.md) utilisée avec la constante *errCode* renvoie 2.

La procédure à suivre pour gérer cette erreur est la suivante :

- Faire une fenêtre / page permettant à l'utilisateur de saisir son code de vérification.
- En cas d'erreur due à la double authentification :
  - Afficher la fenêtre de saisie du code de vérification.
  - L'utilisateur reçoit automatiquement le code d'authentification selon la méthode choisie dans l'administrateur distant WEBDEV. Il peut alors saisir le code dans la fenêtre / page.
  - Affecter le code à la propriété **CodeVérification** de la variable [adminWBAuth](1410089328.md).
  - Ré-exécuter la fonction de pilotage.
