# CoordonnéeEcranVersEditeur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Convertit une taille ou une position donnée dans le dpi natif de l'écran de l'appareil sur lequel s'exécute l'application vers le dpi de référence sous l'éditeur (160 dpi).
Cette fonction permet notamment d'effectuer un positionnement au pixel.

> _(WEBDEV - Code Serveur, Windows)_ Cette fonction est disponible uniquement pour simplifier la Webisation de projets WINDEV.

## Exemple

```wlangage
// Récupère la taille et la position d'un champ telles qu'elles ont été définies sous l'éditeur
nX est un entier = CoordonnéeEcranVersEditeur(MonChampSaisie.X)
nY est un entier = CoordonnéeEcranVersEditeur(MonChampSaisie.Y)
nLargeur est un entier = CoordonnéeEcranVersEditeur(MonChampSaisie.Largeur)
nHauteur est un entier = CoordonnéeEcranVersEditeur(MonChampSaisie.Hauteur)
```

## Syntaxe

```wlangage
<Résultat> = CoordonnéeEcranVersEditeur(<Valeur>)
```

`<Résultat>` *Entier*
> Résultat de la conversion : taille ou position convertie dans le dpi de référence sous l'éditeur (160 dpi).
>
> > _(WEBDEV - Code Serveur)_ Ce paramètre correspond toujours au paramètre <Valeur>.
`<Valeur>` *Entier*
> Valeur à convertir : taille ou position donnée dans le dpi natif de l'écran de l'appareil.

## Remarques

- Sous l'éditeur, les tailles et les positions des champs des fenêtres Android ou iPhone correspondent toujours à un écran en 160 dpi (dot per inch).
- Lors de l'exécution de l'application, ces tailles et ces positions sont automatiquement converties en fonction du dpi natif de l'écran de l'appareil hôte. Ainsi, il est possible d'obtenir un rendu WYSIWYG quel que soit le dpi de l'appareil. Par exemple, si un champ a une taille de 100x100 sous l'éditeur, il aura une taille en exécution de 150x150 sur un appareil en 240 dpi, 200x200 sur un appareil en 320 dpi, etc.
- La fonction [CoordonnéeEditeurVersEcran](1000021277.md) permet d'effectuer la conversion inverse, c'est-à-dire du dpi de référence sous l'éditeur (160 dpi) vers le dpi natif de l'écran de l'appareil sur lequel s'exécute l'application.
