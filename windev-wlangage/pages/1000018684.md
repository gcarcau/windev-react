# TailleCompressée (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **TailleCompressée** permet de connaître la taille compressée d'un élément. Cette propriété est utilisable sur :

- une variable de type [zipArchive](1000018679.md).
- une variable de type [zipFichierArchivé](1000019044.md).
