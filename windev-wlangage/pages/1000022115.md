# BTLERécupèreToutesCaractéristiques (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Récupère toutes les caractéristiques (ayant le même identifiant) associées à un service Bluetooth Low Energy.

## Exemple

```wlangage
MonPériph est un btlePériphérique
...
tabService est un tableau de btleCaractéristique
tabService = BTLERécupèreToutesCaractéristiques(MonPériph.Service[1], "ACC54-DAD4D5-DADD")
...
```

## Syntaxe

```wlangage
<Résultat> = BTLERécupèreToutesCaractéristiques(<Service> , <Identifiant>)
```

`<Résultat>` *Tableau de variables btleCaractéristique*
> Tableau de variables de type [btleCaractéristique](1000022060.md) correspondant aux caractéristiques trouvées pour le service spécifié. Si aucune caractéristique ne correspond à l'identifiant spécifié, le tableau est vide.
`<Service>` *Variable de type btleService*
> Nom de la variable de type [btleService](1000022057.md) correspondant au service manipulé.
`<Identifiant>` *Chaîne de caractères*
> Identifiant (UUID) des caractéristiques à récupérer pour le service spécifié. Toutes les caractéristiques ayant cet identifiant seront récupérées.

## Remarques

Plusieurs caractéristiques d'un même service peuvent correspondre au même identifiant (UUID). Pour récupérer uniquement la première caractéristique correspondant à un identifiant, utilisez la fonction [BTLERécupèreUneCaractéristique](1000022113.md).
