# Fonctions Euro

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

Les fonctions permettant de gérer l'Euro sont les suivantes :

| [eChangeDevise](3033012.md) | Convertit une devise en une autre devise. |
| --- | --- |
| [eDeviseAffParDéfaut](3033009.md) | Identifie ou modifie la devise d'affichage utilisée par défaut. |
| [eDeviseMemParDéfaut](3033016.md) | Identifie ou modifie la devise de mémorisation utilisée par défaut. |
| [eDifférenceArrondi](3033015.md) | Renvoie la différence d'arrondi entre :  - la valeur affichée d'un champ de type "Monétaire + Euro", - le champ associé permettant un double affichage. |
| [eInitDevise](3033003.md) | Ajoute ou modifie les caractéristiques d'une devise dans la table des changes des devises. |
| [eNomDevise](3033006.md) | Renvoie le libellé d'une devise. |
| [eTauxDeChange](3033004.md) | Renvoie la valeur du taux de change d'une devise. |
| [eVersDevise](3033001.md) | Convertit une valeur exprimée en Euro en une autre devise. |
| [eVersEuro](3033005.md) | Convertit en Euros une valeur exprimée dans une devise spécifique. |
