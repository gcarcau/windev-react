# Liste,Select,- (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Désélectionner un élément dans une liste déroulante ou dans une liste déroulée. Cette fonction est notamment utilisée pour manipuler les listes multisélections.

## Exemple

```wlangage
// En CAPPELWD("Liste,Select,-,ListeProd,10");
```

```wlangage
// En PascalAPPELWD('Liste,Select,-,ListeProd,10');
```

```wlangage
// En VBcall APPELWD("Liste,Select,-,ListeProd,10")
```

## Syntaxe

```wlangage
Liste,Select,-(<Nom de la liste> , <Indice>)
```

`<Nom de la liste>` *Chaîne de caractères*
> Nom de la liste à manipuler.
`<Indice>` *Chaîne de caractères*
> Indice de l'élément à désélectionner. Si <Indice>=*, tous les éléments de la liste sont désélectionnés.
> **Remarque** : Si <Indice> est supérieur au nombre d'éléments de la liste, **Liste,Select,-** n'a aucun effet.
