# TauxAncrageHauteur (Propriété)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **TauxAncrageHauteur** permet de :

- Connaître le taux d'ancrage en hauteur d'un champ
- Modifier le taux d'ancrage en hauteur d'un champ.

Le taux d'ancrage permet de définir la manière dont le champ se déplace ou change de taille en fonction de l'évolution de la taille de la fenêtre (ou de l'état) à laquelle il est ancré. Le taux d'ancrage correspond au pourcentage de déplacement du champ par rapport à la fenêtre (ou à l'état). Ainsi, si le taux d'ancrage est de 0, le champ ne sera pas déplacé, si le taux d'ancrage est de 1000, l'ancrage du champ sera normal.

Le taux d'ancrage en hauteur (propriété **TauxAncrageHauteur**) est appliqué si le champ est ancré vers le haut (constante *ancreHauteur* utilisée pour la propriété [Ancrage](2510001.md)).

> _(WEBDEV - Code Serveur)_ Cette propriété permet uniquement de connaître le taux d'ancrage des champs d'un état.

## Exemple

```wlangage
// Le champ Liste se déplacera de 50% de l'agrandissement de la fenêtre.
LISTE_ListePersonne.TauxAncrageHauteur = 500
```

## Syntaxe

#### Connaître le taux d'ancrage d'un champ ancré en hauteur

```wlangage
<Résultat> = <Champ manipulé>.TauxAncrageHauteur
```

`<Résultat>` *Entier*
> Taux d'ancrage compris entre 0 (champ non étiré) et 1000 (ancrage normal)
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler. Ce champ peut être un champ :
>
> - d'une fenêtre.
> - d'un état.

> _(WINDEV, iPhone/iPad, Widget IOS, Java)_ Modifier le taux d'ancrage d'un champ ancré en hauteur Masquer les détails
<Champ manipulé>.TauxAncrageHauteur = <Taux d'ancrage>

 <Champ manipulé> : Nom de champNom du champ à manipuler. <Taux d'ancrage> : EntierNouveau taux d'ancrage compris entre 0 (champ non étiré) et 1000 (ancrage normal)

## Remarques

### Ancrage d'un champ

- Dans une fenêtre, la propriété [Ancrage](2510001.md) permet de définir le comportement du champ (dimensions et déplacement) lors du changement de taille de la fenêtre. Si le champ est associé à un champ Onglet, l'ancrage est défini par rapport à l'onglet.
  Pour plus de détails, consultez [Ancrage des champs dans une fenêtre](2026002.md).
- Dans un état, la propriété [Ancrage](2510001.md) permet de connaître le comportement du champ (dimensions et déplacement) lors du changement de taille de l'état. Ce comportement a été défini sous l'éditeur d'états.
  Pour plus de détails, consultez [Ancrage des champs dans un état](1013298.md).

### Limites

> _(WINDEV, Android, iPhone/iPad, Widget IOS, Java)_ La propriété TauxAncrageHauteur s'applique à tous les champs d'une fenêtre.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS)_ La propriété TauxAncrageHauteur s'applique à tous les champs d'un état. Dans ce cas, il est uniquement possible de connaître le taux d'ancrage utilisé.

> _(Java)_ La propriété TauxAncrageHauteur s'applique uniquement aux éléments suivants :Bouton.Libellé.Champ de saisie.Image.Interrupteur.Sélecteur.Liste.Combo.Arbre.Onglet.Table.Superchamp.
