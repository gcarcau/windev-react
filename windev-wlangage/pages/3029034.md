# gCoord (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **Autres** (Procédures stockées)

Construit une séquence de caractères permettant de définir la position du curseur d'écriture d'un texte.
> _(WINDEV)_ Dans une fenêtre, cette séquence de caractères permet de définir la position du curseur d'écriture d'un texte : dans un élément d'un champ Liste ou Combo.dans la barre de titre et/ou de message d'une fenêtre.dans un champ Libellé.

## Exemple

> _(WINDEV)_ // Ajout en relief du mot "Relief" dans le champ "LISTE_TypeEcriture"
ListeAjoute(LISTE_TypeEcriture, gCoord(2,2) + "Relief" + 18 + gCoord(1,1) + "Relief")

## Syntaxe

```wlangage
<Résultat> = gCoord(<X> , <Y>)
```

`<Résultat>` *Chaîne de caractères*
> Séquence de caractères définissant la position d'écriture.
>
> > _(WINDEV)_ Cette séquence de caractères peut être : utilisée dans les fonctions ListeAjoute, ListeInsère ou ListeModifie.affectée à un champ Libellé. utilisée dans la barre de titre ou de message d'une fenêtre.
>
> > _(WEBDEV - Code Serveur)_ Cette séquence de caractères n'est pas interprétée par les champs en WEBDEV. Cette fonction peut être utilisée pour formater la chaîne renvoyée par un Webservice WEBDEV consommé par une application WINDEV ou WINDEV Mobile.
`<X>` *Réel*
> Abscisse (en pixels) de la nouvelle position du curseur pour le prochain texte à écrire. Si ce paramètre correspond à une chaîne vide (""), l'abscisse correspondant à la position du curseur ne sera pas modifiée.
`<Y>` *Réel*
> Ordonnée (en pixels) de la nouvelle position du curseur pour le prochain texte à écrire. Si ce paramètre correspond à une chaîne vide (""), l'ordonnée correspondant à la position du curseur ne sera pas modifiée.

## Remarques

Toutes les coordonnées sont exprimées en pixels par rapport au coin haut gauche de l'élément manipulé (par exemple le coint haut gauche de la ligne du champ Liste ou Combo).
