# CarteSupprimeImage (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Supprime une image dessinée sur la carte affichée dans un champ Carte.

## Exemple

```wlangage
// Suppression d'une image présente dans le champ Carte
CarteSupprimeImage(CARTE_MaCarte, Image)
```

## Syntaxe

#### Supprimer une image identifiée par la variable associée

```wlangage
<Résultat> = CarteSupprimeImage(<Champ Carte> [, <Image>])
```

`<Résultat>` *Booléen*
> - Vrai si l'image a pu être supprimée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler. Si ce paramètre correspond à une chaîne vide (""), le champ Carte auquel appartient l'événement en cours sera utilisé.
`<Image>` *Variable de type CarteImage optionnel*
> Nom de la variable de type [CarteImage](1000025523.md) correspondant à l'image à supprimer. Si ce paramètre n'est pas spécifié, toutes les images de la carte seront supprimées.

#### Supprimer une image identifiée par son nom

```wlangage
<Résultat> = CarteSupprimeImage(<Champ Carte> , <Nom de l'image>)
```

`<Résultat>` *Booléen*
> - Vrai si l'image a pu être supprimée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler. Si ce paramètre correspond à une chaîne vide (""), le champ Carte auquel appartient l'événement en cours sera utilisé.
`<Nom de l'image>` *Chaîne de caractères*
> Nom de l'image à supprimer. Ce nom correspond à la propriété **Nom** de la variable de type [CarteImage](1000025523.md) à supprimer. Si ce paramètre n'est pas spécifié, toutes les images de la carte seront supprimées.

## Remarques

- Pour ajouter une nouvelle image à dessiner sur une carte, utilisez la fonction [CarteAjouteImage](1000025532.md).
- Pour modifier une image dessinée dans un champ Carte, utilisez la fonction [CarteModifieImage](1000025533.md).
