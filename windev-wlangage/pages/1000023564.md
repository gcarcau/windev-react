# <Graphe>.AxeVisible (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Paramètre l'affichage des axes dans un graphe de type Courbe ou Histogramme. L'axe peut :

- être visible,
- être invisible,
- afficher uniquement le libellé.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
GRF_Graphe1.AxeVisible(grAbscisse, grInvisible)
// ou par compatibilité
// GRF_Graphe1.AxeVisible(grAbscisse, Faux)
```

## Syntaxe

```wlangage
<Champ Graphe>.AxeVisible(<Type de l'axe> , <Visible>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres, de pages ou d'états).
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Type de l'axe>` *Constante de type Entier*
> Axe à manipuler :
>
> | *grAbscisse* | Axe des abscisses. |
> | --- | --- |
> | *grOrdonnée* | Axe des ordonnées. |
`<Visible>` *Booléen*
> Mode d'affichage de l'axe :
>
> | *grInvisible* | L'axe devient invisible. Par compatibilité, il est également possible d'utiliser <Visible = Faux. |
> | --- | --- |
> | *grLibelléUniquement* | Seuls les libellés de l'axe sont visibles. _(PHP)_ Non disponible. |
> | *grVisible* | L'axe devient visible.  Par compatibilité, il est également possible d'utiliser <Visible = Vrai. |

## Remarques

- Si l'axe des ordonnées est invisible, l'axe des ordonnées secondaires est également invisible.
- Les paramètres définis avec la fonction **<Graphe>.AxeVisible** seront pris en compte lors du prochain appel à la fonction [<Graphe>.Dessine](1000024062.md).
