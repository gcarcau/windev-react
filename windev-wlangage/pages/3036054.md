# fTailleDécompacté (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **Autres** (Procédures stockées)

Renvoie la taille d'un fichier avant compression.
Lors de la décompression d'un fichier avec [fDécompacte](3036021.md), il est conseillé de comparer la taille non-compressée du fichier et l'espace disque disponible.

## Exemple

```wlangage
// Taille avant compression d'un fichier
ResTailleDécompacté = fTailleDécompacté("C:\MesRépertoires\Fichier.doc")
```

## Syntaxe

```wlangage
<Résultat> = fTailleDécompacté(<Chemin du fichier>)
```

`<Résultat>` *Entier*
> - Taille du fichier avant compression (en octets),
> - -1 en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
> - -2 si le fichier n'a pas été compressé avec [fCompacte](3036016.md) ou si le fichier a été compressé avec WINDEV version 4 (4.0 ou 4.1).
`<Chemin du fichier>` *Chaîne de caractères*
> Nom et chemin complet (ou relatif) du fichier compressé (260 caractères maximum). Un chemin de type UNC peut être utilisé. Ce fichier doit avoir été compressé avec [fCompacte](3036016.md). Les caractères jokers (*, ?) sont interdits.
>
> > _(WINDEV, Windows)_ Ce paramètre peut être au format Ansi ou Unicode.

## Remarques

### Gestion des erreurs
La fonction **fTailleDécompacté** génère une erreur dans les cas suivants :

- le fichier spécifié n'existe pas,
- le nom du fichier spécifié est invalide,
- le fichier est bloqué par une autre application.

**Composante : wd300std.dll**
