# PileInfo (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch)

Récupère les caractéristiques d'une pile : types des éléments et nombre d'éléments.
Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.

## Exemple

```wlangage
// Pile dont les éléments sont des instances de MaClasse
MaPile est une Pile de MaClasse
// Récupère la définition du type des éléments
MaDéfinition est un Définition
MaDéfinition = PileInfo(MaPile, tiDéfinitionElément)
```

## Syntaxe

```wlangage
<Résultat> = PileInfo(<Pile WLangage> , <Information>)
```

`<Résultat>` *Variant*
> Information demandée.
`<Pile WLangage>` *Pile*
> Nom de la variable de type [Pile](1514022.md) à manipuler.
`<Information>` *Constante de type Entier*
> Information à récupérer :
>
> | *tiDéfinitionElément* | <Résultat est une variable de type [Définition](1000019540.md) et contient la définition du type des éléments. _(WEBDEV - Code Navigateur, Android, Widget Android, Java)_ Cette constante n'est pas disponible. |
> | --- | --- |
> | *tiNombreTotal* | <Résultat est une variable de type Entier et contient le nombre total d'éléments dans la pile. |
> | *tiTypeElément* | <Résultat est une variable de type Entier et contient le type des éléments de la pile. Ce résultat est compatible avec la fonction [TypeVar](3013056.md). _(WEBDEV - Code Navigateur)_ Cette constante n'est pas disponible. |

**Composante : wd300vm.dll**
