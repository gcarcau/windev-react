# InsèreRéférence (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Ajoute la référence d'un objet à la position donnée dans un tableau à une dimension.

## Exemple

```wlangage
UnTableau est un tableau de UneClasseUnObjet est un UneClasseInsèreRéférence(UnTableau, IndiceInsertion, UnObjet)
```

## Syntaxe

```wlangage
InsèreRéférence(<Tableau WLangage> , <Indice> , <Objet>)
```

`<Tableau WLangage>` *Tableau*
> Nom de la variable de type Tableau à manipuler. Ce tableau doit être un tableau à une dimension.
`<Indice>` *Entier*
> Indice du tableau où l'élément doit être inséré.
`<Objet>` *Objet*
> Nom de l'objet pour lequel une référence est ajoutée dans le tableau.

**Composante : wd300vm.dll**
