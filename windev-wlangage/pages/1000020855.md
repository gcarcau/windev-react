# HeureUTC (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **HeureUTC** permet de savoir ou de définir si une heure est une heure UTC (temps universel) ou non.
Cette propriété est utilisable sur :

- une variable de type [hTâchePlanifiée](1000017448.md).
- une variable de type [hPlanification](1000018853.md).
- une variable de type [serveurAppliTâchePlanifiée](1000022367.md).
