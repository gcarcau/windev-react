# Types avancés

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Le WLangage propose des variables de type avancé, permettant de définir et de manipuler des éléments spécifiques (voir liste ci-dessous).

### Syntaxe
Pour déclarer une variable de type avancé, il suffit d'utiliser la syntaxe suivante :

```wlangage
<Nom variable> est un <Type variable>
```

Par exemple :

```wlangage
MonDocument est un pdfDocument
```

Les caractéristiques de la variable peuvent ensuite être précisées à l'aide des propriétés associées.

### Types de base et héritage
Certains types avancés héritent d'un type de base. C'est le cas par exemple des variables de type [diagOvale](1410088135.md), [diagRectangle](1410088083.md) (etc.) qui héritent des variables de type [diagForme](1410088082.md).
Une instance d'un type avancé qui hérite d'un type de base peut être manipulée grâce à une variable du type de base.

Pour manipuler l'instance par son type réel à partir d'une variable du type de base, il est possible d'utiliser une variable du type réel et l'affecter grâce à l'opérateur <-.

Nouveauté 2025
L'opérateur de conversion explicite permet de manipuler l'instance par son type réel sans variable intermédiaire.
Pour plus de détails, consultez [Opérateur de conversion explicite sur les types avancés](1515005.md).
