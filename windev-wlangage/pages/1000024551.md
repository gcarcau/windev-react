# ParamètresSupplémentaires (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **ParamètresSupplémentaires** permet de spécifier des paramètres supplémentaires dans la chaîne d'authentification. Cette propriété est utilisable sur :

- une variable de type [OAuth2Paramètres](1000022212.md),
- une variable de type [JWTParamètres](1410089572.md).
