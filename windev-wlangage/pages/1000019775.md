# HListePersoDossier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Renvoie la liste des perso-dossiers (également appelés groupes) définis :

- dans l'analyse en cours,
- dans les analyses en cours (cas des projets multi-analyses).
- dans l'analyse spécifiée.

## Exemple

```wlangage
Trace(HListePersoDossier())
```

## Syntaxe

```wlangage
<Résultat> = HListePersoDossier([<Chemin du WDD> [, <Mot de passe du WDD>]])
```

`<Résultat>` *Chaîne de caractères*
> Liste des perso-dossiers définis :
>
> - dans l'analyse en cours,
> - dans les analyses en cours (cas des projets multi-analyses).
> - dans l'analyse spécifiée.
>
>
> Les différents noms des perso-dossiers sont séparés par RC (Retour Chariot). Le résultat est de la forme :
>
>
> ```wlangage
> <Perso-dossier 1> + RC + <Perso-dossier 2> + ... + <Perso-dossier N>
> ```
`<Chemin du WDD>` *Chaîne de caractères optionnelle*
> Chemin complet de l'analyse (c'est-à-dire du ficher .WDD) à manipuler.
> Si ce paramètre n'est pas précisé ou est égal à une chaîne vide (""), les perso-dossiers sont recherchés :
>
> - dans l'analyse en cours.
> - dans l'ensemble des analyses en cours (cas des projets multi-analyses).
`<Mot de passe du WDD>` *Chaîne de caractères optionnelle ou Chaîne secrète*
> Mot de passe défini pour l'analyse. Si aucun mot de passe n'est défini, ce paramètre doit être égal à une chaîne vide ("").
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).
