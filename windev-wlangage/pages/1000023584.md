# Colonnes (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **Colonnes** permet d'accéder :

- à la configuration d'une colonne d'un tableau dans un document au format Traitement de texte (variable [docTableau](1000022924.md)).
- à la configuration d'une colonne de texte dans un document multicolonne (variable [docFormatMulticolonne](1000023580.md)).
