# MotDePasseUtilisateur (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **MotDePasseUtilisateur** permet de gérer le mot de passe de l'utilisateur utilisé dans le cadre d'une authentification par mot de passe. Cette propriété est utilisée :

- par les variables de type [sshSession](1000021157.md).
- par les variables de type [mqttSession](1000023023.md).
- par les variables de type [URI](1000024027.md).
