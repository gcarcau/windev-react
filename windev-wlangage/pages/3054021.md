# NationVersLangue (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Renvoie la langue correspondant à une nation.

## Exemple

```wlangage
// Connaître la langue correspondant à la nation italienne
ResLangue est un entier
ResLangue = NationVersLangue(nationItalien)
SELON ResLangue
	CAS langueAllemand :
	 ...
	CAS langueItalien :
	 ...
FIN
```

## Syntaxe

```wlangage
<Résultat> = NationVersLangue(<Nation>)
```
