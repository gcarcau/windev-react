# <Onglet>.ChargeConfiguration (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Restaure la configuration des volets dynamiques d'un champ Onglet. Cette configuration a été précédemment sauvée sous forme d'une chaîne de caractères avec la fonction [<Onglet>.SauveConfiguration](1000021708.md).

## Exemple

```wlangage
// Demande à l'utilisateur la configuration qu'il souhaite charger
sFichier est une chaîne

// Ouvre le sélecteur de fichiers
sFichier = fSélecteur("", "", "Sélectionnez un fichier de configuration...", ...
	"Configuration de tableau de bord" + TAB + "*.conf", "*.conf")
// Si un fichier est sélectionné
SI sFichier <> "" ALORS
	// Récupère la configuration contenue dans le fichier
	sConfiguration est chaîne = fChargeTexte(sFichier)
	// Charge la configuration
	SI ONG_OngletDyn.ChargeConfiguration(sConfiguration) ALORS
		ToastAffiche("La configuration a été chargée", toastCourt, cvMilieu, chCentre)
	SINON
		Erreur("Erreur en chargement de configuration", ErreurInfo())
	FIN
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Champ Onglet>.ChargeConfiguration(<Configuration>)
```

`<Résultat>` *Booléen*
> - Vrai si la configuration a été chargée,
> - Faux en cas d'erreur. En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Champ Onglet>` *Nom de champ*
> Nom du champ Onglet à manipuler.
`<Configuration>` *Chaîne de caractères*
> Configuration des volets dynamiques sauvegardée avec la fonction [<Onglet>.SauveConfiguration](1000021708.md).
