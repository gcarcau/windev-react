# PartieDécimale (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Renvoie la partie décimale d'un nombre.

## Exemple

```wlangage
// Partie décimale de 16.487
ResPartieDécimal = PartieDécimale(16.487)
// Renvoie 0.487
```

## Syntaxe

```wlangage
<Résultat> = PartieDécimale(<Nombre>)
```

`<Résultat>` *Réel*
> Partie décimale recherchée.
`<Nombre>` *Réel*
> Nombre à manipuler.

**Composante : wd300mat.dll**
