# Propriétés associées au champ Jauge

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Les propriétés WLangage permettent de manipuler un champ Jauge aussi bien dans une fenêtre, une page ou un état.
