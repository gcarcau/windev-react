# CDListe (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Liste les lecteurs de CD/DVD installés sur le poste en cours.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Windows, Code Utilisateur (MCU))_ // Affiche la liste des lecteurs de CD/DVD
// du poste en cours dans le champ LISTE_ListeLecteurs
ListeAjoute(LISTE_ListeLecteurs, CDListe())

## Syntaxe

```wlangage
<Résultat> = CDListe()
```

`<Résultat>` *Chaîne de caractères*
> Liste des lecteurs installés sur le poste en cours, sous la forme :
>
>
> ```wlangage
> <Identifiant du lecteur 1> + RC + ... + <Identifiant du lecteur N>
> ```
>
>
>
> > _(WEBDEV - Code Serveur)_ Le poste en cours correspond au serveur Web.

## Remarques

> _(WINDEV, WEBDEV - Code Serveur)_ Les fonctions CD sont disponibles uniquement sous Windows XP et supérieur.
 Le lecteur manipulé correspond au lecteur présent sur le serveur Web. Ce serveur doit être sous Windows XP ou supérieur.

**Composante : wd300grv.dll**
