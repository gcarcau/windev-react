# <Tableau>.Distinct (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Renvoie un tableau sans doublons.
Les tableaux suivants peuvent être manipulés :

- Tableau d'éléments simples (entier, réel, chaîne de caractères) à une dimension.
- Tableau de structures à une dimension. La suppression des doublons est réalisée en fonction de la valeur d'un ou de plusieurs membres.

Nouveauté Abonnement

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
// Premier tableau d'entiers
tabMonTableau1 est un tableau d'entiers
tabMonTableau1.Ajoute(1)
tabMonTableau1.Ajoute(2)
tabMonTableau1.Ajoute(1)
tabMonTableau1.Ajoute(3)

// Tableau "distinct"
tabMonDistinct est un tableau d'entiers
tabMonDistinct = tabMonTableau1.Distinct()
// le résultat est 1; 2; 3
```

## Syntaxe

```wlangage
<Résultat> = <Tableau WLangage>.Distinct()
```

`<Résultat>` *Tableau*
> Variable de type Tableau contenant le tableau sans doublons.
`<Tableau WLangage>` *Tableau*
> Nom de la variable de type Tableau à manipuler. Ce tableau doit être un tableau à une dimension.

## Remarques

**Divers**
Il est également possible de supprimer les doublons dans un tableau grâce à la fonction [<Tableau>.SupprimeDoublon](1000024315.md).

- La fonction [<Tableau>.SupprimeDoublon](1000024315.md) manipule directement le tableau passé en paramètre.
- La fonction **<Tableau>.Distinct** ne modifie pas le tableau passé en paramètre et renvoie un nouveau tableau sans les doublons.
  **Enchaînement de fonctions**
  Il est possible d'enchaîner les différentes fonctions de manipulation d'un tableau.
  Les fonctions suivantes peuvent être utilisées dans un enchaînement :
  - [<Tableau>.Filtre](1000024968.md)
  - [<Tableau>.Transforme](1000025418.md)
  - [<Tableau>.Union](1000025408.md)
  - [<Tableau>.Intersection](1000025407.md)
  - [<Tableau>.Distinct](1000025406.md).
  Cet enchaînement pourra être utilisé comme source d'une instruction POUR TOUT ou se terminer par une des fonctions suivantes :
  - [<Tableau>.Applique](1000024969.md)
  - [<Tableau>.Agrège](1000024951.md)
  - [<Tableau>.Min](1000025412.md)
  - [<Tableau>.Max](1000025411.md)
  - [<Tableau>.Somme](1000025415.md)
  - [<Tableau>.Moyenne](1000025417.md)
  - [<Tableau>.TousFaux](1000024935.md), [<Tableau>.TousVrai](1000024936.md), [<Tableau>.UnFaux](1000024937.md), [<Tableau>.UnVrai](1000024938.md).
  Exemple :
  ```wlangage
  gnMoyenne = gtabUser.Filtre(cbFiltre).Transforme(cbTransforme).Moyenne()
  ```
