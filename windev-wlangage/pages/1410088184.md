# Bordure (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

La propriété **Bordure** permet de définir les caractéristiques de la bordure d'un document. Cette propriété est utilisable sur :

- une variable de type [diagForme](1410088082.md).
- une variable de type [diagSélection](1410088172.md).
