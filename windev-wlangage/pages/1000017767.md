# HPurgeRepTravail (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **Autres** (Procédures stockées)

Purge et détruit le répertoire temporaire précédemment créé lors de l'exécution de la fonction [HRepTravailServeur](1000017768.md). Ce répertoire est automatiquement vidé et détruit lors de la déconnexion du client.
**Remarque** : Cette fonction peut être exécutée uniquement à partir d'une procédure stockée.

## Exemple

```wlangage
// Code d'une procédure stockée
fSauveTexte(ComplèteRep(HRepTravailServeur()) + "MonFichier.txt", MaChaîneTexte)
...
HPurgeRepTravail()
```

## Syntaxe

```wlangage
<Résultat> = HPurgeRepTravail()
```

`<Résultat>` *Booléen*
> - Vrai si le répertoire a été détruit,
> - Faux dans le cas contraire. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.

**Composante : wd300hf.dll**
