# Suisse.VérifieNAVS (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un numéro NAVS (numéro d'assurance vieillesse survivants de Suisse).

## Exemple

```wlangage
// Test d'une variableMonNuméroNAVS est une chaîne = "7566523572040"Suisse.VérifieNAVS(MonNuméroNAVS)  // renvoie Vrai // Test d'un champSAI_NuméroNAVS = "ABC"Suisse.VérifieNAVS(SAI_NuméroNAVS) // renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = Suisse.VérifieNAVS(<Numéro à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un numéro NAVS valide.
> - Faux dans le cas contraire.
`<Numéro à vérifier>` *Nom de champ ou variable de type chaîne*
> Numéro NAVS à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.

**Composante : wd300std.dll**
