# Angle (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Angle** permet de connaître et de modifier l'angle d'un élément. Cette propriété est utilisable sur :

- une variable de type [Police](1514045.md). Pour plus de détails, consultez l'aide de la propriété [Angle](1410086632.md).
- une variable de type [Filigrane](1000019922.md).
- une variable de type [Fond](1000022038.md).
- une variable de type [CarteImage](1000025523.md).
- une variable de type [diagForme](1410088082.md).
- une variable de type [diagSélection](1410088172.md).
