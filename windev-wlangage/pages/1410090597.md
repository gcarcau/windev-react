# Fonctions de gestion du téléphone (syntaxe préfixée)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Les fonctions permettant de gérer le téléphone via une syntaxe préfixée sont les suivantes :

| [<Variable Notification>.Ajoute](1410090431.md) | Ajoute une notification dans la barre système de l'appareil (Android) ou dans le centre de notification (iOS). |
| --- | --- |
| [<Variable Notification>.EnvoiePush](1410090433.md) | Envoie une notification push (distante) à un appareil mobile (iOS ou Android). |
| [<Variable Notification>.EnvoiePushAbonné](1410090479.md) | Envoie une notification push distante aux appareils Android abonnés d'un sujet. |
| [<Variable Notification>.Modifie](1410090432.md) | Modifie une notification actuellement affichée dans la barre système de l'appareil. |
| [<Variable Notification>.Supprime](1410090434.md) | Supprime une notification affichée dans la barre système de l'appareil. |
