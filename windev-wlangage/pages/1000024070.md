# Fonctions de gestion des Exécutables en mode Console

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU))

Les fonctions permettant de manipuler les différents flux des exécutables en mode "console" sont les suivantes :

| [ConsoleEcrit](1000024022.md) | Ecrit une chaîne de caractères dans le flux de sortie standard "stdout" (également appelé "console"). |
| --- | --- |
| [ConsoleErreur](1000024023.md) | Ecrit une chaîne de caractères dans le flux de sortie d'erreurs "stderr". |
| [ConsoleLit](1000024024.md) | Lit une chaîne sur le flux d'entrée standard "stdin". |
