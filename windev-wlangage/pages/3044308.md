# HModifieGroupe (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Modifie les informations du groupe en fonction des éléments présents dans [les variables de gestion de groupe](3044315.md) correspondantes.

## Exemple

```wlangage
// Description de la connexion
HDécritConnexion("MaConnexion", "Julie", "MotDePasse", "MonServeurHF", "MaBaseDeDonnées", ...
	hAccèsHFClientServeur, hOLecture)
// Ouverture de la connexion
HOuvreConnexion("MaConnexion")
...
// Modification des membres du groupe
HGroupe.Utilisateurs = "Flo" + RC + "Julie" + RC + "Luc"
// Modification du groupe
SI HModifieGroupe("MaConnexion", "TESTEURS") = Vrai ALORS
	Info("Groupe modifié")
FIN
```

## Syntaxe

```wlangage
<Résultat> = HModifieGroupe(<Connexion> , <Groupe>)
```

`<Résultat>` *Booléen*
> - Vrai si le groupe a été modifié,
> - Faux en cas d'erreur. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion pour laquelle un groupe doit être modifié. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Groupe>` *Chaîne de caractères*
> Nom du groupe dont on veut modifier les caractéristiques.

## Remarques

### Droits nécessaires pour modifier un groupe
Pour modifier un groupe (différent de celui de l'utilisateur en cours) , il est nécessaire de posséder le droit de visualisation des utilisateurs (constante *hDroitVisualisationUtilisateur*). Dans le cas contraire, la fonction **HModifieGroupe** renverra Faux et le message d'erreur sera "Groupe inconnu".
Pour modifier le nom d'un groupe, il est nécessaire de posséder le droit de visualisation des utilisateurs (constante *hDroitVisualisationUtilisateur*) et le droit de gestion des utilisateurs (constante *hDroitGestionUtilisateur*).

Remarque : Ces constantes sont utilisées dans les fonctions [HInfoDroitServeur](3044322.md) et [HModifieDroitServeur](3044328.md).

### Gestion des droits
Il est possible de donner des droits à un groupe grâce aux fonctions :

- [HModifieDroitBaseDeDonnées](3044326.md) : permet de donner des droits sur une base de données.
- [HModifieDroitFichier](3044327.md) : permet de donner des droits sur un fichier de données.
- [HModifieDroitServeur](3044328.md) : permet de donner des droits sur un serveur.

Pour plus de détails sur la gestion des droits, consultez [Gestion des droits en HFSQL Client/Serveur](3044333.md).
