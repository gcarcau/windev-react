# TâcheParallèleExécuteAprèsUne (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Indique une tâche parallèle de continuation qui sera exécutée après la première tâche terminée d'un tableau de tâches parallèles.

## Exemple

```wlangage
// Lance deux tâches
t1 est une TâcheParallèle = TâcheParallèleExécute(Proc1)
t2 est une TâcheParallèle = TâcheParallèleExécute(Proc2)
// Lorsqu'une des deux tâches sera terminée, la procédure ProcContinuation sera exécutée
TâcheParallèleExécuteAprèsUne([t1,t2], ProcContinuation)
```

## Syntaxe

#### Indiquer une procédure à exécuter après la première tâche précédente

```wlangage
<Résultat> = TâcheParallèleExécuteAprèsUne(<Tâches précédentes> , <Procédure de continuation> [, <Paramètres> [, <Options>]])
```

`<Résultat>` *Variable de type TâcheParallèle*
> Variable de type [TâcheParallèle](1000021220.md) correspondant à la tâche de continuation créée.
`<Tâches précédentes>` *Tableau de TâchesParallèles*
> Nom du tableau de variables de type [TâcheParallèle](1000021220.md) correspondant aux tâches précédentes.
`<Procédure de continuation>` *Chaîne de caractères ou variable de type Procédure*
> Procédure de continuation à exécuter. Ce paramètre peut correspondre :
>
> - au nom de la procédure de continuation à exécuter.
> - au nom de la variable [Procédure](1000018907.md) correspondant à la procédure de continuation à exécuter.
`<Paramètres>` *Liste de valeurs entre parenthèses et séparées par des virgules*
> Paramètres de la procédure à exécuter. Cette liste de paramètres est de la forme :
>
>
> ```wlangage
> (<Paramètre 1>, ..., <Paramètre N>)
> ```
>
>
> où :
>
> - <Paramètre 1> : Premier paramètre de la procédure.
> - ...
> - <Paramètre N> : Nième paramètre de la procédure.
>
> Le mot-clé ***ValeurRenvoyéeTâchePrécédente*** permet de passer la ou les valeurs de retour de la première tâche précédente terminée en paramètre de la procédure de continuation.
`<Options>` *Constante ou combinaison de constantes optionnelle de type Entier*
> Options de la tâche à exécuter :
>
> | *tpoCopieComplèteContexteHFSQL* | Provoque la copie immédiate du contexte HFSQL courant. Conseillé par exemple si la tâche parallèle doit tenir compte des positions en cours dans les fichiers et requêtes du contexte de l'appelant. |
> | --- | --- |
> | *tpoCopieDifféréeContexteHFSQL* (Valeur par défaut) | Provoque une copie légère du contexte HFSQL **lors du premier accès aux données HFSQL**. |
> | *tpoCopieLégèreContexteHFSQL* | Provoque la copie immédiate d'une partie du contexte HFSQL courant.  Seuls les répertoires où se trouvent les fichiers de données en HFSQL Classic et/ou les connexions en HFSQL Client/Serveur sont mémorisés. |
> | *tpoThreadPrincipal* | Exécute la tâche dans le thread principal.  Cette constante peut être combinée avec une des autres constantes. |

#### Indiquer une tâche à exécuter après la première tâche précédente

```wlangage
<Résultat> = TâcheParallèleExécuteAprèsUne(<Tâches précédentes> , <Tâche de continuation>)
```

`<Résultat>` *Variable de type TâcheParallèle*
> Variable de type [TâcheParallèle](1000021220.md) correspondant à la tâche de continuation.
`<Tâches précédentes>` *Tableau de TâchesParallèles*
> Nom du tableau de variables de type [TâcheParallèle](1000021220.md) correspondant aux tâches précédentes.
`<Tâche de continuation>` *Variable de type TâcheParallèle*
> Nom de la variable de type [TâcheParallèle](1000021220.md) correspondant à la tâche de continuation.

#### Décrire une tâche à exécuter après la première tâche précédente

```wlangage
<Résultat> = TâcheParallèleExécuteAprèsUne(<Tâches précédentes> , <Description tâche de continuation>)
```

`<Résultat>` *Variable de type TâcheParallèle*
> Variable de type [TâcheParallèle](1000021220.md) correspondant à la tâche de continuation.
`<Tâches précédentes>` *Tableau de TâchesParallèles*
> Nom du tableau de variables de type [TâcheParallèle](1000021220.md) correspondant aux tâches exécutées.
`<Description tâche de continuation>` *Variable de type Description de TâcheParallèle*
> Nom de la variable de type [Description de TâcheParallèle](1000021586.md) décrivant la tâche de continuation.

## Remarques

- La fonction **TâcheParallèleExécuteAprèsUne** est non bloquante.
- Si la fonction est appelée alors qu'une des tâches est déjà terminée, la continuation sera exécutée dès que possible.
- Si la fonction est appelée alors que toutes les tâches ont été annulées, la continuation ne sera pas exécutée.
- Si toutes les tâches précédentes sont annulées alors qu'une continuation a été créée, la continuation ne sera pas exécutée.
- Dans le code de la tâche de continuation, le mot-clé **MaTâcheParallèlePrécédente** permet de manipuler la première tâche précédente terminée.
