# LDAPListeFils (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **Autres** (Procédures stockées)

Liste les fils d'un objet d'un serveur LDAP.

## Exemple

```wlangage
// On recherche les fils
sListeFils est une chaîne
sListeFils = LDAPListeFils("MaSession", "DC=pcs,DC=local")
```

## Syntaxe

```wlangage
<Résultat> = LDAPListeFils(<Session LDAP> , <DN de l'objet de base>)
```

`<Résultat>` *Chaîne de caractères*
> - Liste des noms absolus (DN) des objets trouvés,
> - chaîne vide ("") si aucun fils n'est associé à l'objet.
>
> Les différents éléments sont séparés par le caractère "Retour chariot" (RC).
> En cas d'erreur, <Résultat> vaut chaîne vide ("") et la variable [ErreurDétectée](3087001.md) est à Vrai. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de détails sur l'erreur.
>
> Attention :
>
>
> - Si la taille de <Résultat> dépasse 2 Go, <Résultat> sera tronqué à 2 Go.
> - En fonction des stratégies LDAP définies dans Active Directory, l'importation peut être limitée à 1 000 utilisateurs. Dans ce cas, pour supprimer cette limitation, il faut intervenir sur le paramètre LDAP MaxPageSize. Pour plus de détails, consultez [https://support.microsoft.com/kb/315071](https://support.microsoft.com/kb/315071).
`<Session LDAP>` *Chaîne de caractères*
> Nom de la session LDAP manipulée.
`<DN de l'objet de base>` *Chaîne de caractères*
> Nom absolu de l'objet (Distinguished Name) dont les fils sont recherchés.

**Composante : wd300com.dll**
