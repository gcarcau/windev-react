# RedisDéconnecte (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Force la fermeture de la connexion vers un serveur Redis (ou un cluster Redis).
Nouveauté 2025
Cette fonction peut également être utilisée pour manipuler des données sur un serveur Valkey.

## Exemple

```wlangage
gRedis est un redisConnexion
gRedis.Serveur = "MonServeurRedis:7001"
SI RedisConnecte(gRedis) ALORS
    RedisDéconnecte(gRedis)
FIN
```

## Syntaxe

```wlangage
RedisDéconnecte(<Connexion>)
```

`<Connexion>` *Variable de type redisConnexion*
> Nom de la variable de type [redisConnexion](1000023527.md) correspondant à la connexion au serveur Redis.

**Composante : wd300big.dll**
