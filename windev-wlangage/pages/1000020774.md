# emailEntête (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Le type **emailEntête** permet de récupérer ou de fixer les entêtes supplémentaires de l'email. Les caractéristiques d'un entête peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
Ce type de variable est utilisé par les variables de type [Email](1000018713.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
cMonEmail est un Email
cUneEntête est un emailEntête
cUneEntête.Nom = "List-Unsubscribe"
cUneEntête.Valeur = "<mailto:unsubscribe@domain.com>"
Ajoute(cMonEmail.Entête, cUneEntête)
EmailEnvoieMessage(MaSession, cMonEmail, emailOptionEncodeEntête)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type emailEntête
Les propriétés suivantes peuvent être utilisées pour manipuler un entête d'email :

| **Nom de la propriété** | **Type manipulé** | **Effet** |
| --- | --- | --- |
| Nom | Chaîne de caractères | Nom de l'entête. |
| Valeur | Chaîne de caractères | Valeur de l'entête.  **Remarque** : Si la fonction [EmailEnvoieMessage](3032005.md) utilise la constante *emailOptionEncodeEntête*, la valeur de l'entête sera encodée en base 64. |
