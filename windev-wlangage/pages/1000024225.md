# Constantes utilisées par les fonctions de gestion des champs Panneau dockable

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU))

Les constantes de gestion des champs Panneau dockable sont les suivantes :

| Constante | Détail | Fonction |
| --- | --- | --- |
| **padoBas** | Attache le champ Panneau dockable en bas. | [PanneauAttache](1000023990.md),  [PanneauCrée](1000023989.md) |
| **padoDroite** | Attache le champ Panneau dockable à droite. | [PanneauAttache](1000023990.md),  [PanneauCrée](1000023989.md) |
| **padoFlottant** | Le champ Panneau dockable est flottant. | [PanneauAttache](1000023990.md),  [PanneauCrée](1000023989.md) |
| **padoGauche** | Attache le champ Panneau dockable à gauche. | [PanneauAttache](1000023990.md),  [PanneauCrée](1000023989.md) |
| **padoHaut** | Attache le champ Panneau dockable en haut. | [PanneauAttache](1000023990.md),  [PanneauCrée](1000023989.md) |
