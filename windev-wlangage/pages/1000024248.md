# <Table>.EchangeLigne (Fonction)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Echange :

- deux lignes dans un champ Table par programmation.
- deux branches dans un champ Table hiérarchique par programmation.

**Remarques** :

- Dans un champ Table, la fonction **<Table>.EchangeLigne** permet d'échanger deux lignes identifiées par leur numéro. Pour réaliser des échanges spécifiques (prendre en compte la ligne en cours, ...), utilisez la fonction [<Table>.DéplaceLigne](1000024245.md).
- Dans un champ Table hiérarchique, la fonction **<Table>.EchangeLigne** permet d'échanger deux branches identifiées par leur numéro. Pour échanger des lignes identifiées par leur chemin, utilisez la fonction [<Table hiérarchique>.EchangeBranche](1000021930.md).

## Exemple

```wlangage
// On échange les lignes 5 et 20 dans un champ Table
TABLE_Menu.EchangeLigne(5, 20)
```

## Syntaxe

```wlangage
<Champ Table>.EchangeLigne(<Indice de la ligne à déplacer> , <Indice de la ligne destination>)
```

`<Champ Table>` *Nom de champ*
> Nom du champ Table ou Table hiérarchique à manipuler.
`<Indice de la ligne à déplacer>` *Entier*
> Position de la ligne à déplacer. Cette position doit être comprise entre 1 et le nombre de lignes total du champ (connu par exemple par la fonction [<Table>.Occurrence](1000024277.md) ou la propriété [Occurrence](2510097.md)).
`<Indice de la ligne destination>` *Entier*
> Nouvelle position de la ligne. Cette position doit être comprise entre 1 et le nombre de lignes total du champ (connu par exemple par la fonction [<Table>.Occurrence](1000024277.md) ou la propriété [Occurrence](2510097.md)). Si ce paramètre n'est pas valide, une erreur fatale est générée.

## Remarques

### Conditions d'utilisation
La fonction **<Table>.EchangeLigne** peut être utilisée sur :

- un champ Table ou Table hiérarchique par programmation.
- un champ Table en mode "Serveur + AJAX", un champ Table en mode "Serveur" et un champ Table hiérarchique.
- un champ Table en mode "Navigateur".

**Composante : wd300obj.dll**
