# <Panneau>.Détache (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Détache un champ Panneau dockable pour le transformer en une fenêtre flottante.

## Exemple

```wlangage
// Détacher le champ Panneau dockable et le met en haut à gauche de l'écran
PADO_Test.Détache()
PADO_Test.X = 0
PADO_Test.Y = 0
```

## Syntaxe

```wlangage
<Champ Panneau dockable>.Détache()
```

`<Champ Panneau dockable>` *Nom de champ*
> Nom du champ Panneau dockable à manipuler.

## Remarques

- Si le champ Panneau dockable est déjà flottant, la fonction **<Panneau>.Détache** n'a aucun effet.
- Le champ Panneau dockable peut être réattaché à sa fenêtre avec la fonction [<Panneau dockable>.Attache](1000024404.md).

**Composante : wd300obj.dll**
