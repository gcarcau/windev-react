# Utiliser des données d'une base de données tierce

## Utiliser des données d'une base de données tierce

**Ce que vous allez apprendre** :

- Création d'un projet pour manipuler une base tierce.
- Création d'une analyse manipulant des fichiers d'une base tierce.

[image: Durée de la leçon] 40 mn

## Présentation

Cette leçon va vous permettre de découvrir comment manipuler des bases de données SQL avec WINDEV.Cette leçon est destinée aux personnes maîtrisant les bases de données SQL. Toutes les manipulations à faire sur la base de données SQL ne seront pas détaillées.
Pour créer une application utilisant une base de données SQL, il faut :

- Créer le projet lié à l'application. Ce projet regroupera tous les éléments de l'application (fenêtres, codes, requêtes, états, etc.).
- Importer la description des fichiers de données SQL.

**Pour réaliser cette leçon** :

1. Vous devez récupérer les éléments nécessaires sur votre poste.
  - Depuis la page d'accueil, cliquez sur "Tutoriel".
  - Dans la zone "Tuto - Utiliser les données d'une base de données tierce", cliquez sur le lien "Récupérer les éléments pour l'exercice".
2. Vous devez vous connecter à votre serveur SQL.
3. Vous devez importer sur le serveur SQL les fichiers de script SQL et le répertoire des images (précédemment récupérés et présents dans le répertoire "Exercises\BaseSQL\" du répertoire contenant les exemples de ce tutoriel) avec les outils d'importation fournis (MySQL, Oracle, SQL Server, etc.). Le répertoire des images permet d'obtenir les images du fichier de données Produit.
4. Pour terminer, vous devez exécuter les fichiers de script SQL sur le serveur SQL.
  Remarque : Les scripts SQL fournis sont des scripts fonctionnant sur Oracle uniquement.

Votre base de données SQL de travail pour cette leçon est prête.

## Création du projet

Pour créer le projet :

1. Lancez WINDEV et affichez la page d'accueil de WINDEV si nécessaire (Ctrl + <).
2. Dans la page d'accueil, cliquez sur "Créer un projet", puis sur l'option "Application Windows ou Linux". L'assistant de création d'un projet se lance. Les différentes étapes de l'assistant vont vous aider à créer votre projet.
  Tous les renseignements indiqués dans cet assistant pourront être modifiés par la suite.
3. L'assistant propose de définir la charte graphique. Sélectionnez "Eleven".
4. L'assistant propose de saisir le nom du projet, son emplacement et sa description. Dans notre cas, ce projet va simplement s'appeler "basesql".
5. Terminez l'assistant (bouton "Terminer").
6. Dans la fenêtre de création d'un élément qui s'affiche, cliquez sur "Données" puis sur "Analyse".
7. L'assistant de création d'une analyse se lance.

## Création de l'analyse

Les étapes de l'assistant de création d'analyse sont les suivantes :

1. Indiquez le nom et le répertoire de l'analyse. Par défaut, le nom de l'analyse correspond au nom du projet et le répertoire de l'analyse est un répertoire ".ana" dans le répertoire du projet. Nous allons conserver ces paramètres par défaut.
  [image: Assistant de création d'analyse]
  Passez à l'étape suivante de l'assistant.
2. Vous pouvez ensuite choisir le ou les types de bases de données manipulées par le projet. Sélectionnez OLE DB (ou la base de données SQL utilisée si vous possédez le Connecteur Natif correspondant).
  Remarque : Les Connecteurs Natifs sont listés en premier.
  [image: Sélection du type de la base de données]
  Passez à l'étape suivante de l'assistant.
3. Sélectionnez la source OLE DB correspondant au type de votre base de données.
  Passez à l'étape suivante de l'assistant.
4. Indiquez dans les étapes suivantes les paramètres de votre connexion OLE DB (si vous avez choisi un Connecteur Natif, les étapes sont identiques) :
  - le nom du serveur de la base de données.
  - le nom de l'utilisateur et son mot de passe.
  - le nom de la base de données si nécessaire.
  - le nom de la connexion (le libellé associé à la connexion est optionnel).
   Passez à l'étape suivante.
5. Terminez l'assistant. L'analyse associée au projet est créée. L'assistant de création d'un fichier de données s'affiche.

Dans l'assistant de création de fichiers de données :

1. Sélectionnez l'option "Utiliser les fichiers de données d'une base existante". Passez à l'étape suivante de l'assistant.
2. Sélectionnez le type de données à importer, OLE DB (ou la base de données SQL utilisée si vous possédez le Connecteur Natif correspondant). Passez à l'étape suivante de l'assistant.
3. Sélectionnez la source OLE DB correspondant au type de votre base de données.
  Passez à l'étape suivante de l'assistant.
4. Sélectionnez la connexion utilisée lors de la création de l'analyse.
  Passez à l'étape suivante de l'assistant.
5. Indiquez le mode d'accès aux données.
  [image: Mode d'accès aux données]
  Il est possible de :
  - accéder directement aux données dans leur format actuel. Seule la description des tables est importée dans l'analyse. Aucune conversion n'est nécessaire.
  - convertir les données dans le format HFSQL Classic.
6. Dans notre cas, choisissez "Accéder directement aux données dans leur format actuel". Passez à l'étape suivante.
7. Sélectionnez le (ou les) fichier(s) de données à importer.
  [image: Sélection des fichiers de données à importer]
8. Validez et terminez l'assistant. Les tables sont importées et visualisées sous l'éditeur d'analyses.

## Génération de l'analyse

La génération de l'analyse consiste à valider les modifications de l'analyse (création de fichiers de données, ajout ou suppression de rubriques, etc.) et à les propager dans tout le projet (pages, champs reliés, états, etc.).
La génération est automatiquement proposée lorsque vous fermez l'éditeur d'analyses et que des modifications ont été effectuées.

Il est également possible de générer l'analyse manuellement. C'est ce que nous allons faire.

Pour générer l'analyse :

1. Sous l'éditeur d'analyses, sous le volet "Analyse" du ruban, dans le groupe "Analyse", cliquez sur "Génération".
2. La génération de l'analyse est automatiquement lancée.

## Conclusion

Ce tuto vous a permis de suivre la création d'un projet et d'une analyse permettant de manipuler une base de données tierce.
Lorsque votre analyse est générée, la manipulation des données se fait de la même manière que les données HFSQL. Il n'y a aucune différence. Il est possible de :

- Créer une application complète grâce au RAD (Rapid Application Development).
- Créer une application complète entièrement personnalisée.
