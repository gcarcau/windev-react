# LecteurPDFFerme (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Ferme et libère le fichier PDF affiché dans un champ Lecteur PDF.

## Exemple

```wlangage
LecteurPDFFerme(PDF_MonLecteurPDF)
```

## Syntaxe

```wlangage
LecteurPDFFerme(<Champ Lecteur PDF>)
```

`<Champ Lecteur PDF>` *Nom de champ*
> Nom du champ Lecteur PDF contenant le fichier PDF à fermer.

## Remarques

> _(Android)_ A partir de la version 28, cette fonction n'est pas supportée par les processeurs ARM 32 bits. En effet, les nouveautés en matière de gestion des PDF imposent une exécution en 64 bits. Si une application doit être exécutée sur une flotte existante d'appareils ARM 32 bits, la génération de cette application doit être effectuée avec la version 27 de WINDEV Mobile.

**Classification Métier / UI : Code UI**

**Composante : wd300obj.dll**
