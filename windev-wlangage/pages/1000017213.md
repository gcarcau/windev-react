# MultimédiaLargeur (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android)

Renvoie la largeur en pixels de l'image source du fichier multimédia joué dans le champ Multimédia. Cette fonction est utilisable par exemple pour les fichiers vidéo.
> _(WEBDEV - Code Navigateur)_ Remarque : Selon le type de vidéo et la configuration du navigateur, cette fonction peut ne pas être supportée. Dans ce cas son utilisation sera sans effet mais ne provoquera pas d'erreur.

## Syntaxe

```wlangage
<Résultat> = MultimédiaLargeur(<Champ Multimédia>)
```

`<Résultat>` *Entier*
> - Largeur en pixels de l'image du fichier multimédia,
> - 0 en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
>
>
> > _(WEBDEV - Code Navigateur)_ Remarque : La fonction ErreurInfo n'est pas disponible.
`<Champ Multimédia>` *Nom de champ*
> Nom du champ Multimédia à manipuler.

## Remarques

- La fonction [MultimédiaHauteur](1000017212.md) permet de connaître la hauteur d'un fichier multimédia.
- La fonction **MultimédiaLargeur** permet de connaître la largeur d'un fichier multimédia.

**Composante : wd300obj.dll**
