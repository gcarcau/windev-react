# RépertoireDonnées (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux)

|  | **But** Connaître le répertoire des données HFSQL.  **Syntaxe**  <Résultat = RépertoireDonnées()  <Resultat est une chaîne de caractères, correspondant au chemin absolu permettant d'accéder aux données.  **Détail**  La fonction **RépertoireDonnées** renvoie le chemin des fichiers de données HFSQL.  Dans le cas d'une installation par média physique, ce répertoire est donné lors de l'installation.  Dans le cas d'une installation par accès distant (FTP), l'hébergeur fournit le répertoire de base des fichiers de données, et l'utilisateur fournit le sous-répertoire dans lequel les fichiers de données sont installés.  En mode test, cette fonction retourne une chaîne vide.  Le répertoire des données est le répertoire où se trouvent les fichiers de données HFSQL par défaut, c'est-à-dire :   - si la fonction [HSubstRep](3044028.md) n'est pas utilisée. - si les fichiers sont décrits dans l'analyse avec un répertoire spécifique (vivement déconseillé)   **Notes**  La chaîne renvoyée ne se termine pas par un '\' (anti slash)  Le chemin renvoyé est :   - soit un chemin complet. Exemple : "D:\DATA\Rewali. - soit un nom UNC. Exemple : \\SERVEURA\DATA\Rewali |
