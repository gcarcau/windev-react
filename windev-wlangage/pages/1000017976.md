# Texte (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **Texte** permet de connaître et de modifier un texte. Cette propriété est utilisable sur :

- les rubriques d'un fichier de données : elle permet de savoir si une rubrique est une rubrique de type texte. Pour plus de détails, consultez [Propriété Texte](2512089.md).
- une variable de type [xmlNoeud](1000018786.md).
- une variable de type [Filigrane](1000019922.md).
- une variable de type [docElément](1000022484.md).
- une variable de type [docFragment](1000022482.md).
- une variable de type [docNiveauNumérotation](1000022799.md).
- une variable de type [Toast](1000024638.md).
- une variable de type [pdfElémentTexte](1000024556.md).
- une variable de type [picCalque](1000024604.md).
- une variable de type [picTexte](1000025178.md).
- une variable de type [ocrBlocTexte](1000025639.md).
- une variable de type [diagForme](1410088082.md).
- une variable de type [diagSélection](1410088172.md).
- une variable de type [kbCarte](1410089167.md).
- une variable de type [xlsCommentaire](1000024870.md).
