# PoliceCharge (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Charge une police personnelle depuis un fichier ou un buffer. Après le chargement, les polices et variantes déclarées par le fichier (ou le buffer) seront disponibles dans toute l'application.
Nouveauté Abonnement
Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 1.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
PoliceCharge("Roboto-Regular.ttf")
```

## Syntaxe

```wlangage
<Résultat> = PoliceCharge(<Police>)
```

`<Résultat>` *Booléen*
> - Vrai si la police a été chargée,
> - Faux dans le cas contraire.
`<Police>` *Chaîne de caractères ou Buffer*
> - Nom et chemin du fichier correspondant à la police à charger.
> - Buffer contenant la police à charger.

## Remarques

- Pour décharger une police, utilisez la fonction [PoliceDécharge](1410090995.md).
- Les formats gérés dépendent des plateformes : .ttf, .otf et .woff.
- Si une même police est chargée plusieurs fois, il faut effectuer autant d'appels à la fonction [PoliceDécharge](1410090995.md) que d'appels de **PoliceCharge**.
- Si un police de même nom est chargée depuis plusieurs fichiers/buffers, seul le premier chargement sera pris en compte.
- Les polices chargées par la fonction **PoliceCharge** ne sont pas listées par la fonction [PoliceListe](3060003.md).
