# Créer un pattern RAD

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows)

## Présentation

Le RAD est basé sur un projet de type Pattern RAD, ce qui simplifie sa création, sa modification et la génération d'une version directement utilisable.

## Etapes de création du pattern RAD

Les différentes étapes permettant de créer un Pattern RAD sont les suivantes :

1. [Création du projet de type "Pattern RAD"](2031021.md).
2. [Création des différentes fenêtres et pages du pattern](2031022.md).
3. [Génération du Pattern RAD](2031023.md).
4. [Utilisation du Pattern RAD](2031024.md).
