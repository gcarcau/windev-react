# MemExiste (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Teste l'existence d'une zone de mémoire.

## Exemple

```wlangage
// Teste l'existence de la zone mémoire "MaZoneMémoire"
ResExiste = MemExiste("MaZoneMémoire")
```

## Syntaxe

```wlangage
<Résultat> = MemExiste(<Zone mémoire>)
```

`<Résultat>` *Booléen*
> - Vrai si la zone mémoire existe,
> - Faux dans le cas contraire.
`<Zone mémoire>` *Chaîne de caractères*
> Nom de la zone mémoire, défini par la fonction [MemCrée](3053005.md).

## Remarques

Pour exister, une zone mémoire doit avoir été créée avec la fonction [MemCrée](3053005.md). Une zone mémoire peut être détruite avec la fonction [MemSupprimeTout](3053019.md).

**Classification Métier / UI : Code neutre**

**Composante : wd300std.dll**
