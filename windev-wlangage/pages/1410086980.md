# 1. Les éditeurs de WINDEV

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU))

| [Page précédente](1410086979.md) | [Sommaire](1410087098.md) | [Page suivante](1410086981.md) |
| --- | --- | --- |

Pour manipuler un projet, WINDEV propose de nombreux éditeurs intégrés :

| - éditeur de projet. | - éditeur d'analyses. |
| --- | --- |
| - éditeur de requêtes. | - éditeur de fenêtres. |
| - éditeur d'états. | - éditeur de modèles UML. |

- etc.

Ces éditeurs permettent de manipuler facilement les différents éléments du projet.
