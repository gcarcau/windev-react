# ErreurRAZ (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Réinitialise la détection des erreurs non fatales :

- Le résultat de la fonction [ErreurInfo](3013008.md) est réinitialisé.
- La variable [ErreurDétectée](3087001.md) revient à Faux.

## Exemple

```wlangage
// dans une bouclePOUR TOUT ... // Réinitialise la détection des erreurs non fatales ErreurRAZ() // Exécute l'opération bExécutionOK = UneOpération() // Traite les erreurs   SI bExécutionOK = Faux ALORS  // Ecriture de l'erreur dans un log  LogErreur(ErreurInfo())  FINFIN
```

## Syntaxe

```wlangage
ErreurRAZ()
```

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
