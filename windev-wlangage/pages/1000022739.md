# RuptureSupprimeTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Supprime toutes les ruptures présentes dans un champ Table ou un champ Zone répétée. Ces ruptures ont été précédemment ajoutées via la fonction [RuptureAjoute](1000022737.md).

## Exemple

```wlangage
// Regroupe les clients par Code postal (CP)
// 1. Suppression des anciennes ruptures
RuptureSupprimeTout(TABLE_Client)
// 2. Création de la nouvelle rupture
RuptureAjoute(TABLE_Client.CP, "Rup_CP")
TableTrie(TABLE_Client, "CP")
```

## Syntaxe

```wlangage
RuptureSupprimeTout(<Champ à manipuler>)
```

`<Champ à manipuler>` *Nom de champ*
> Nom du champ à manipuler :
>
> - champ Table.
> - champ Zone répétée.

## Remarques

- La fonction **RuptureSupprimeTout** supprime toutes les ruptures créées avec la fonction [RuptureAjoute](1000022737.md). Si aucune rupture n'a été créée, la fonction n'a aucun effet.
- Pour supprimer une seule rupture, utilisez la fonction [RuptureSupprime](1000022738.md).
