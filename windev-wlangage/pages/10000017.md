# Erreur 17 : AUTRES CAS doit être en dernier dans le SELON

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Cause

Vous utilisez une instruction conditionnelle de type SELON ... CAS. L'instruction "AUTRES CAS" doit être le dernier CAS utilisé.

## Correction

Déplacez le bloc d'instructions commençant par "AUTRES CAS" à la fin de l'instruction conditionnelle SELON.

## Exemple

### L'instruction AUTRES CAS n'est pas la dernière instruction
**Code provoquant l'erreur**
```wlangage
SELON TypeProduit  CAS "1"      Message("Produit alimentaire")  AUTRES CAS      Message("Promotion exceptionnelle")  CAS "2"      Message("Produit de nettoyage")FIN
```

**Correction proposée**
Déplacez le bloc d'instructions commençant par "AUTRES CAS" à la fin de l'instruction conditionnelle SELON.

```wlangage
SELON TypeProduit  CAS "1"      Message("Produit alimentaire")  CAS "2"      Message("Produit de nettoyage")  AUTRES CAS      Message("Promotion exceptionnelle")FIN
```
