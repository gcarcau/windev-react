# <Variable sshSession>.ConnecteCommande (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Permet de conserver la session SSH active entre plusieurs envois de commandes (via la fonction [<Variable sshSession>.Commande](1410091176.md)) à un serveur SSH.
Rappel : Par défaut, lors de l'envoi d'une commande à un serveur SSH, la session est ouverte et refermée automatiquement après l'envoi de la commande.

Nouveauté Abonnement
Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
Session est une sshSession
// Propriétés de la session
// ...
// Initialise la session SSH à conserver
Session.ConnecteCommande()
Session.Commande("echo 'Hello world !'")
Session.Commande("echo 'Hello world !'")
Session.Commande("echo 'Hello world !'")
Session.Commande("echo 'Hello world !'")
// Ferme la session SSH pour retrouver un fonctionnement normal
Session.DéconnecteCommande()
```

## Syntaxe

```wlangage
<Résultat> = <Session SSH>.ConnecteCommande()
```

`<Résultat>` *Booléen*
> - Vrai si la session a été ouverte correctement,
> - Faux dans le cas contraire.
`<Session SSH>` *Variable de type sshSession*
> Nom d'une variable [sshSession](1000021157.md) contenant les paramètres de connexion de la session SSH à ne pas déconnecter.
