# Constantes utilisées par les fonctions de gestion des champs Onglet

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU))

Afficher uniquement les constantes utilisées par les syntaxes préfixées
Afficher uniquement les constantes utilisées par les syntaxes non préfixées

Les constantes de gestion des champs Onglet sont les suivantes :

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |
| **voletActif** | Le volet existe et il est attaché à son onglet. | [OngletEtat](1000021637.md) |
| **voletFlottant** | Le volet existe et il est détaché. | [OngletEtat](1000021637.md) |
| **voletInexistant** | Le volet n'existe pas ou il a été fermé. | [OngletEtat](1000021637.md) |

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |

| **voletFlottant** | Le volet existe et il est détaché. | [<Onglet>.Etat](1000021700.md) |
| **voletInexistant** | Le volet n'existe pas ou il a été fermé. | [<Onglet>.Etat](1000021700.md) |
