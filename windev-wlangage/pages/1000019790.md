# CarteRécupèrePosition (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Renvoie la position géographique du point situé au centre de la carte actuellement affichée dans un champ Carte.
> _(Android)_ Remarque : Cette fonction est disponible dans l'émulateur Android et dans le simulateur Android.

## Exemple

> _(Windows, Android, iPhone/iPad)_ // Retourne le point de la carte correspondant à la position courante de l'utilisateur
MaPosition est une géoPosition
MaPosition = CarteRécupèrePosition(CARTE_Position)
SI ErreurDétectée = Faux ALORS
 RENVOYER CarteInfoPosition(CARTE_Position, MaPosition)
FIN

## Syntaxe

```wlangage
<Résultat> = CarteRécupèrePosition([<Champ Carte>])
```

`<Résultat>` *Variable de type géoPosition*
> Variable de type [géoPosition](1000019191.md) correspondant à la position géographique du point actuellement affiché au centre du champ Carte.
> > _(Windows, Android, iPhone/iPad)_ En cas d'erreur, la variable ErreurDétectée est à Vrai et le détail de l'erreur peut être obtenu avec la fonction ErreurInfo.
`<Champ Carte>` *Nom de champ optionnel*
> Nom du champ Carte à manipuler. Si ce paramètre correspond à une chaîne vide ("") ou n'est pas spécifié, le champ Carte auquel appartient l'événement en cours sera utilisé.
