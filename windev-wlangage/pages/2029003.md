# Environnement de l'éditeur de requêtes

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Pour afficher l'éditeur de requêtes, il suffit de :

- créer une nouvelle requête :
  - cliquez sur  présent dans les boutons d'accès rapide.
  - la fenêtre de création d'un nouvel élément s'affiche : cliquez sur "Requêtes".
- ouvrir une requête existante (via le volet "Explorateur de projet" par exemple).

Les éléments importants de l'éditeur de requêtes sont les suivants :

|  | **Ruban** Permet un accès rapide aux principales fonctionnalités de l'éditeur de requêtes. |
| --- | --- |
|  | **Code SQL de la requête en cours** |
|  | **Représentation graphique de la requête en cours** Des ascenseurs permettent de faire défiler la représentation de la requête si la taille de cette représentation est importante. Il est également possible de réaliser un zoom (par exemple à l'aide de la souris : Ctrl + Roulette de la souris). |
|  | **[Volets ancrables](2027001.md)** Affiche :  - les raccourcis vers les principales fonctionnalités disponibles sous l'éditeur en cours ([volet "Commandes"](2027010.md)), - les fonctionnalités les plus utilisées ([volet "Commandes"](2027010.md)), - les éléments (fichiers, rubriques, états, champs, ...) disponibles dans le projet en cours ([volet "Explorateur de projet"](2027029.md)).  **Sous le logiciel Etats & Requêtes**, seuls les éléments accessibles sont listés dans le [volet "Explorateur de projet"](2027029.md). |
|  | **Liste des rubriques et des paramètres de la requête sélectionnée** Si la requête est exécutée par programmation (fonction [HExécuteRequête](3044080.md)), l'ordre de passage des paramètres (cas d'une [requête paramétrée](3044080.md)) correspond à l'ordre indiqué dans cette liste. **Sous le logiciel Etats & Requêtes**, la liste des rubriques et des paramètres de la requête sélectionnée n'est pas disponible. |
|  | **Fenêtre de description de la requête en cours**. Permet de connaître et de modifier l'ensemble des caractéristiques de la requête. |
|  | **Navigateur** Lorsqu'une requête ne peut pas être affichée entièrement dans l'espace de travail, le navigateur permet de se déplacer aisément dans cette requête. |
|  | **[Documents ouverts](2029012.md)** Affiche un bouton pour chaque document ouvert (états, requêtes, ...) sous l'éditeur. Pour afficher l'élément voulu au premier plan, il suffit de cliquer sur le "bouton" correspondant. |
