# <Variable docFragment>.EffaceMiseEnForme (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Remplace la mise en forme actuelle d'un fragment par la mise en forme par défaut.

## Exemple

```wlangage
MonDoc est un Document = DocOuvre(fRepExe() + fSep() + "MonDoc.docx")
FragmentTexte est un docFragment(MonDoc, 1, Taille(DocVersTexte(MonDoc)))
FragmentTexte.EffaceMiseEnForme()
```

## Syntaxe

```wlangage
<Elément manipulé>.EffaceMiseEnForme()
```

`<Elément manipulé>` *Variable de type docFragment*
> Nom d'une variable de type [docFragment](1000022482.md).

**Classification Métier / UI : Code neutre**

**Composante : wd300mdl.dll**
