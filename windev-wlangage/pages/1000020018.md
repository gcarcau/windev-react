# DateSélecteur (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android)

Affiche le sélecteur de date du système.
**Remarque** : Pour sélectionner une date à l'aide du sélecteur de date, il est conseillé d'utiliser directement le masque de saisie de type "Rouleau Date" pour le champ de saisie de type "Date". Ce masque de saisie est également disponible pour les applications iPhone/iPad.

[image: Sélecteur de date système Android]

## Exemple

```wlangage
d est une Date = DateSélecteur()
```

```wlangage
DateInitiale est une Date = "20170101"
MaDate est une Date
MaDate = DateSélecteur(DateInitiale, "Date de départ")
```

## Syntaxe

```wlangage
<Résultat> = DateSélecteur([<Date initiale> [, <Titre>]])
```

`<Résultat>` *Date ou Chaîne de caractères*
> - Date sélectionnée dans la sélecteur,
> - Chaîne vide ("") si la sélection a été annulée par l'utilisateur.
`<Date initiale>` *Date ou Chaîne de caractères optionnelle*
> Date affichée à l'ouverture du sélecteur. Si cette date n'est pas spécifiée, le sélecteur affichera la date du jour.
`<Titre>` *Chaîne de caractères optionnelle*
> Titre à afficher dans le sélecteur. Si ce paramètre n'est pas spécifié, le titre affiché sera une représentation textuelle de la date affichée par le sélecteur.

## Remarques

> _(Android, Widget Android)_ Application en arrière-plan : Spécificité à partir de Android 10A partir de Android 10, il n'est plus possible d'ouvrir une fenêtre lorsque l'application est en arrière-plan. La fonction DateSélecteur peut provoquer l'ouverture d'une fenêtre. Si cette fonction est utilisée alors que l'application est en arrière-plan, une erreur fatale sera générée. Conseils : Il est possible de savoir si l'application est en arrière-plan grâce à la fonction EnModeArrièrePlan. Si une application a besoin d'interagir avec l'utilisateur alors qu'elle se trouve en arrière-plan, la solution consiste à afficher une notification (via le type Notification). Lors du clic sur la notification, l'application sera remise au premier plan si la propriété ActiveApplication est à Vrai. Il est également possible d'ouvrir une fenêtre depuis la procédure passée à la propriété ActionClic.Pour plus de détails, consultez Android 10 : Comportement des applications en arrière-plan.
