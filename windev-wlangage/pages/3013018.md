# DéchargeProcédure (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

|  | But Décharger les procédures internes d'une fenêtre qui ont été rendues globales par [ChargeProcédure](3013019.md). Syntaxe <Résultat = DéchargeProcédure(<NomFenetre [, <Message>])  - <Résultat est un booléen permettant de savoir si les procédures ont été déchargées - <NomFenetre est une chaîne de caractères contenant le nom ou l'alias de la fenêtre dans laquelle les procédures ont été décrites. - <Message est un booléen permettant d'afficher un message d'erreur si les procédures de la fenêtre ne sont pas trouvées.   Détail <Résultat renvoie Vrai si le déchargement a été correctement effectué, Faux sinon. Si <Message = Vrai (valeur par défaut), un message d'erreur signale si <Nom Fenêtre n'est pas trouvée à l'exécution.  Si <Message = Faux, aucun message d'erreur signale l'absence de <NomFenêtre>. Il est nécessaire de tester la valeur de <Résultat par programmation.  Notes   - **DéchargeProcédure** doit être utilisée pour charger les procédures internes d'autres fenêtres avec [ChargeProcédure](3013019.md). - Les procédures internes de 16 fenêtres (au maximum) peuvent être chargées par [ChargeProcédure](3013019.md). - Lors de l'exécution d'une procédure, celle-ci est recherchée :  - en premier dans les procédures internes de la fenêtre,  - ensuite dans les différents "modules" chargés,  - enfin dans les procédures globales. - Les procédures chargées par [ChargeProcédure](3013019.md) sont automatiquement déchargées lors de la fermeture du projet. |
