# <Liste>.Supprime (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Supprime un élément d'un champ Liste par programmation (y compris Liste image) ou d'un champ Combo par programmation.
**Remarque** : La fonction **<Liste>.Supprime** peut être utilisée indifféremment sur les champs Liste monosélection et multisélection.

> _(WEBDEV - Code Navigateur)_ Attention : L'élément sera supprimé uniquement sur la page affichée dans le navigateur. Pour plus de détails, voir les Remarques.

## Exemple

```wlangage
// Suppression de l'élément sélectionné dans le champ "LISTE_ListeClient"
LISTE_ListeClient.Supprime()
```

## Syntaxe

```wlangage
<Champ Liste>.Supprime([<Indice de l'élément>])
```

`<Champ Liste>` *Nom de champ*
> Nom du champ Liste (ou Combo) à manipuler.
`<Indice de l'élément>` *Entier optionnel*
> Indice de l'élément à supprimer du champ Liste (ou Combo). Si ce paramètre n'est pas précisé :
>
> - dans un champ Liste monosélection, l'élément en cours est supprimé.
> - dans un champ Liste multisélection, les éléments sélectionnés dans le champ Liste sont supprimés.
> - dans un champ Combo, l'élément en cours est supprimé. Si ce champ est un champ Combo est en saisie, le champ de saisie est mis à vide.
>
>
> > _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur)_ Les champs Combo en saisie ne sont pas disponibles.

## Remarques

### Suppression en chaîne
Dans le cas de la suppression en chaîne d'éléments, les éléments situés après chaque élément supprimé sont déplacés. Il est conseillé d'effectuer les suppressions en chaîne en partant du dernier élément.
Par exemple :

```wlangage
Indice est un entier
POUR Indice = LISTE_ListeClient.Occurrence() À 1 PAS -1
	LISTE_ListeClient.Supprime(Indice)
FIN
```

> _(WEBDEV - Code Navigateur)_ Suppression d'un élément sur le navigateurLors de la suppression d'un élément en code navigateur, cet élément est supprimé uniquement sur la page affichée dans le navigateur. Pour que cet élément soit également supprimé sur le serveur, il est nécessaire d'exécuter la fonction <Liste>.Supprime sur le serveur.L'utilisation de la fonction <Liste>.Supprime en code navigateur est intéressante lors de l'utilisation de la technologie AJAX, en mode "AJAX Programmé" (utilisation de la fonction AJAXExécute ou AJAXExécuteAsynchrone).Rappel : En mode "AJAX automatique et immédiat", il suffit de passer le traitement serveur contenant la fonction <Liste>.Supprime en mode AJAX automatique. Rien de plus ! Aucune programmation supplémentaire n'est nécessaire. Pour plus de détails, consultez AJAX.

### Divers

- Pour supprimer un élément dans un champ Table, utilisez la fonction [<Table>.Supprime](1000024289.md).
- La fonction **<Liste>.Supprime** peut être utilisée sur une colonne d'un champ Table de type "Combo".
