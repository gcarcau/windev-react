# Fonctions de gestion du téléphone

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Les fonctions de gestion du téléphone sont les suivantes :

| [AfficheLicence](1410090236.md) | Affiche la licence du framework WINDEV Mobile ou des librairies du framework dans une nouvelle fenêtre. |
| --- | --- |
| [AndroidActivityResultProcédure](1410088881.md) | Permet de spécifier la procédure à appeler pour récupérer le résultat renvoyé par une Activity tierce. |
| [AppleIdentifiantPublicitaire](1410087936.md) | Renvoie l'identifiant publicitaire de l'appareil (iOS uniquement). |
| [AppleSignIn](1000025404.md) | Permet d'effectuer une authentification par "Connexion avec Apple" sur le matériel iOS 13 et plus. |
| [AppleTrackingDemandeAutorisationAsynchrone](1410087935.md) | Affiche la demande de permission concernant le suivi de l'activité de l'utilisateur. |
| [AppleTrackingEtatAutorisation](1410087934.md) | Permet de savoir si l'application est autorisée à réaliser un suivi d'activité sur les données de l'utilisateur (iOS uniquement). |
| [ChangeThème](1000025266.md) | Permet de modifier par programmation le thème (sombre ou clair) utilisé par l'application mobile. |
| [ClavierVisible](3071013.md) | Permet de rendre le clavier visible. |
| [DeepLinkProcédure](1410089051.md) | Définit la procédure WLangage exécutée lors du clic sur un "deep link". |
| [EtatAlimentation](3067007.md) | Permet de connaître diverses informations sur la batterie (principale ou de secours) de l'appareil sur lequel l'application est exécutée. |
| [GglCompteAssocie](1410089808.md) | Permet d'effectuer une authentification en un clic dans l'application avec un compte Google enregistré sur l'appareil sans avoir besoin de saisir un login et un mot de passe. |
| [GglCompteDissocie](1410089813.md) | Supprime de l'appareil l'association entre l'application et le compte Google de l'utilisateur. Cette association a été effectuée précédemment avec la fonction [GglCompteAssocie](1410089808.md). |
| [iOSApplicationOpenURLProcédure](1410089346.md) | Permet de spécifier la procédure à appeler lorsque l'application doit ouvrir une ressource désignée par une URL. |
| [iOSExclutFichieriCloud](1000021779.md) | Exclut un fichier des sauvegardes réalisées par le cloud Apple. |
| [iOSRépertoireAppGroup](1410088694.md) | Renvoie le chemin du répertoire du conteneur permettant de partager des fichiers entre plusieurs applications appartenant à un même App Group iOS. |
| [LEDAllume](1000019446.md) | Allume la LED (Light-Emitting Diode) de l'appareil. |
| [LEDEteint](1000019447.md) | Éteint la LED (Light-Emitting Diode) de l'appareil. |
| [LuminositéAuto](1000020182.md) | Retourne ou modifie l'état d'activation de l'ajustement automatique de la luminosité sur l'appareil. |
| [LuminositéModifie](1000020170.md) | Modifie le réglage de la luminosité de l'écran de l'appareil. |
| [LuminositéRécupère](1000019810.md) | Renvoie le réglage actuel de la luminosité de l'écran de l'appareil. |
| [MagnetoAction](1000014001.md) | Exécute une action sur le magnétophone / dictaphone de l'appareil en cours. |
| [NotifAjoute](1000019442.md) | Ajoute une notification dans la barre système de l'appareil (Android) ou dans le centre de notification (iOS). |
| [NotifListeCatégorie](1000023979.md) | Liste les catégories de notification de l'application. |
| [NotifModifie](1000019443.md) | Modifie une notification actuellement affichée dans la barre système de l'appareil. |
| [NotifPushAbonne](1410089870.md) | Abonne l'application Android en cours aux notifications push relatives à un sujet. |
| [NotifPushActive](1000020816.md) | Active la gestion des notifications push dans une application WINDEV Mobile (Android ou iOS). |
| [NotifPushDésabonne](1410089871.md) | Désabonne l'application des notifications push envoyées pour le sujet spécifié. |
| [NotifPushDésactive](1000020817.md) | Désactive la gestion des notifications push pour une application WINDEV Mobile (Android ou IOS). |
| [NotifPushEnvoie](1000020819.md) | Envoie une notification push (distante) à un appareil mobile (iOS ou Android). |
| [NotifPushEnvoieAbonné](1410089872.md) | Envoie une notification push distante aux appareils Android abonnés d'un sujet. |
| [NotifPushListeIdentifiantsInvalides](1000020854.md) | Renvoie la liste des identifiants invalides sur le service APN d'Apple. |
| [NotifPushProcédure](1000020818.md) | Spécifie la procédure WLangage appelée lorsqu'une notification push est reçue par une application WINDEV Mobile (Android ou iOS). |
| [NotifSupprime](1000019444.md) | Supprime une notification affichée dans la barre système de l'appareil. |
| [NotifSupprimeCatégorie](1000023980.md) | Supprime une catégorie de notification de l'application. |
| [RécupèreThème](1000025320.md) | Permet de connaître le thème actuel d'une application mobile. |
| [RéseauMobileEtat](1000020175.md) | Retourne l'état actuel de connexion aux données sur le réseau mobile ou demande à être notifié des changements d'état de la connexion aux données. |
| [RéseauMobileInfoConnexion](1000020176.md) | Renvoie les informations demandées concernant la connexion actuelle aux données sur le réseau mobile. |
| Nouveauté 2025 [ScanDepuisCaméraVersImage](1410090763.md) | Ouvre une fenêtre spécifique permettant de numériser sous forme d'image un ou plusieurs documents à l'aide de la caméra du téléphone ou de la tablette. |
| Nouveauté 2025 [ScanDepuisCaméraVersPDF](1410090790.md) | Ouvre une fenêtre spécifique permettant de numériser sous forme d'un fichier PDF un ou plusieurs documents à l'aide de la caméra du téléphone (ou de la tablette). |
| Nouveauté 2025 [ScanDocumentDepuisCaméra](1410090545.md) | Ouvre une fenêtre spécifique permettant de numériser sous forme d'image un ou plusieurs documents à l'aide de la caméra du téléphone ou de la tablette. Cette fonction est identique à la fonction [ScanDepuisCaméraVersImage](1410090763.md). |
| [TailleEcran](1000022211.md) | Renvoie la taille en pouces de la diagonale de l'écran de l'appareil sur lequel s'exécute l'application. |
| [telDialerAffiche](1000019236.md) | Ouvre l'application de téléphonie (dialer) par défaut et affiche le numéro spécifié. Aucun appel n'est déclenché. |
| [telDialerCompose](1000019235.md) | Ouvre l'application de téléphonie (dialer) par défaut du téléphone et compose le numéro spécifié. |
| Nouveauté 2025 [telRécupèreNuméro](1410090442.md) | Affiche la fenêtre d'autorisation et de sélection du ou des numéros de téléphone de l'utilisateur enregistrés sur l'appareil. |
| [TypeEcran](1000022210.md) | Renvoie le type d'écran sur lequel s'exécute l'application : téléphone, tablette, ordinateur ou montre. |
| [VérifieIdentitéUtilisateur](1000021348.md) | Permet de vérifier l'identité réelle de l'utilisateur en cours par vérification biométrique. |
| [VibrationArrête](1000019449.md) | Arrête les vibrations de l'appareil (même si elles ont été déclenchées par une autre application). |
| [VibrationDéclenche](1000019448.md) | Déclenche les vibrations de l'appareil. |
| [VolumeBoutonPhysique](1000020168.md) | Identifie ou modifie la source sonore associée aux boutons physiques de réglage du volume de l'appareil. |
| [VolumeModifie](1000020169.md) | Modifie le réglage du volume d'une source sonore. |
| [VolumeRécupère](1000019807.md) | Récupère le réglage actuel du volume d'une source sonore. |

> _(WEBDEV - Code Serveur)_ Remarque : Pour afficher une notification sur un navigateur depuis un site WEBDEV, utilisez la fonction NotificationAffiche.
