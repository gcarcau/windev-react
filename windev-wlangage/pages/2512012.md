# CxMotDePasseDécrit (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

La propriété **CxMotDePasseDécrit** permet de définir le mot de passe utilisé pour ouvrir le fichier de données lors d'une connexion OLE DB (fichier défini par programmation uniquement).

**Rappel** : La fonction [HConnecte](3044263.md) permet de redéfinir un ou plusieurs paramètres de la connexion OLE DB sur une table. Par défaut, les caractéristiques de la connexion OLE DB sont définies :

- soit sous l'éditeur d'analyses lors de la description du fichier de données,
- soit lors de la description par programmation du fichier de données.

## Exemple

```wlangage
// Définir le mot de passe utilisé pour ouvrir le fichier de données Client
Client.CxMotDePasseDécrit = "MotDePasse"
```

## Syntaxe

```wlangage
<Fichier de données>.CxMotDePasseDécrit = <Mot de passe>
```

`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données manipulé. Ce nom a été défini grâce au type [Description de Fichier](1514065.md).
`<Mot de passe>` *Chaîne de caractères ou Chaîne secrète*
> Mot de passe du fichier à ouvrir par une connexion OLE DB.
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).

## Remarques

La propriété [MotDePasse](2510086.md) permet de définir le mot de passe associé à un utilisateur et une connexion.
