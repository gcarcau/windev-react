# Bibli,Erreur (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Charge le fichier qui contient les messages d'erreur gérés par WD???EXE.DLL dans la langue souhaitée. Par défaut, si aucune fonction **Bibli,Erreur** n'est appelée, les messages d'erreur sont en français.

## Exemple

```wlangage
// En CAPPELWD("BIBLI,ERREUR,ALLEMAND.WDM");if WdEntier>0 { APPELWD("ERREUR, Fichier des messages non trouvé");}
```

```wlangage
// En PascalAPPELWD('BIBLI, ERREUR, ALLEMAND.WDM');if WdEntier>0 then APPELWD('ERREUR,Fichier des messages non trouvé');
```

```wlangage
// En VBcall APPELWD("BIBLI, ERREUR, ALLEMAND.WDM")if WdEntier>0 then call APPELWD("ERREUR,Fichier des messages non trouvé")end if
```

## Syntaxe

```wlangage
Bibli,Erreur(<Nom du fichier>)
```

`<Nom du fichier>` *Chaîne de caractères*
> Nom et chemin du fichier à charger. Ce fichier fourni avec WINDEV ou créé avec WDINT. Il a pour extension .WDM. WdEntier est supérieur à 0 lorsque <Nom du fichier> n'a pas été trouvé.

## Remarques

**Bibli,Erreur** ne peut pas être utilisée pour charger un fichier qui n'a pas été créé avec WDINT.
