# Fonctions Modbus

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions Modbus (syntaxe préfixée)](1000026091.md)).
La liste des fonctions Modbus est la suivante :

| [ModbusConnecteRTU](1000025929.md) | Connecte un poste client à un esclave Modbus via le port série. |
| --- | --- |
| [ModbusConnecteTCP](1000025930.md) | Connecte un poste client à un serveur Modbus via le protocole TCP. |
| [ModbusDéconnecte](1000025931.md) | Ferme la session Modbus. |
| [ModbusEcritBit](1000025932.md) | Écrit un ou plusieurs bits à une adresse précise dans un esclave Modbus. |
| [ModbusEcritFlottant](1000025933.md) | Ecrit une ou plusieurs flottants simple précision à partir d'une adresse précise dans un esclave Modbus. |
| [ModbusEcritRegistre](1000025934.md) | Ecrit un ou plusieurs registres (valeur 16 bits) à partir d'une adresse précise dans un esclave Modbus. |
| [ModbusEnvoieTrameBrute](1410089145.md) | Envoie une trame brute à un esclave Modbus. Il est ainsi possible de communiquer avec des automates qui disposent de fonctionnalités non-standards. |
| [ModbusLitBit](1000025935.md) | Lit un ou plusieurs bits à partir d'une adresse précise sur un esclave Modbus. |
| [ModbusLitFlottant](1000025936.md) | Lit un ou plusieurs flottants "simple précision" à partir d'une adresse précise dans un esclave Modbus. |
| [ModbusLitRegistre](1000025937.md) | Lit un ou plusieurs registres à partir d'une adresse précise dans un esclave Modbus. |
