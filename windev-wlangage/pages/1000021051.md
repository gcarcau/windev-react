# VariantVersJSON (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Convertit le contenu d'une variable de type Variant au format JSON.

## Exemple

```wlangage
Personne est un Variant
Personne.Nom = "DUPONT"
Personne.Prenom = "Michel"
Trace(VariantVersJSON(Personne))
// Affiche : { "Nom":"DUPONT", "Prenom":"Michel" }
```

## Syntaxe

```wlangage
<Résultat> = VariantVersJSON(<Variant> [, <Options>])
```

`<Résultat>` *Chaîne de caractères*
> Résultat de la conversion au format JSON.
`<Variant>` *Variable de type Variant*
> Nom de la variable de type Variant à convertir au format JSON.
`<Options>` *Constante de type Entier*
> Option de mise en forme du JSON :
>
> | *psdMinifié* | Génère un JSON en supprimant les espaces inutiles (retours à la ligne, caractères d'espacement, ...). |
> | --- | --- |
> | *psdMiseEnForme* | Génère un JSON avec des retours à la ligne et une indentation. |
>
>
>
> > _(WEBDEV - Code Navigateur, Android, Widget Android)_ Ce paramètre n'est pas disponible.

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
