# Importance (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Importance** permet connaître et de modifier le niveau d'importance d'un rendez-vous. Cette propriété est utilisable sur :

- une variable de type [EvénementTimeline](1000020612.md).
- une variable de type [RendezVous](1000019244.md).
