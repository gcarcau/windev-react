# UPNPExécuteAction (Fonction)

> **Disponible :** **WINDEV** (Windows) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Exécute une action sur le service UPnP.

## Exemple

```wlangage
MonService est un upnpService
...

SELON TableOccurrence(TABLE_ParamIN)
	CAS 0
		tabRésultat = UPNPExécuteAction(MonService, SAI_Action)
		SI ErreurDétectée ALORS
			Info(ErreurInfo(errComplet))
			RETOUR
		FIN
	CAS 1
		tabRésultat = UPNPExécuteAction(MonService, SAI_Action, ...
				TABLE_ParamIN[1].COL_Param)
		SI ErreurDétectée ALORS
			Info(ErreurInfo(errComplet))
			RETOUR
		FIN
	CAS 2
		tabRésultat = UPNPExécuteAction(MonService, SAI_Action, ...
				TABLE_ParamIN[1].COL_Param, ...
				TABLE_ParamIN[2].COL_Param)
		SI ErreurDétectée ALORS
			Info(ErreurInfo(errComplet))
			RETOUR
		FIN
	AUTRE CAS
		Info("Non géré")
		RETOUR
FIN
```

## Syntaxe

```wlangage
<Résultat> = UPNPExécuteAction(<Service> , <Action> [, <Paramètre 1> [... [, <Paramètre N>]]])
```

`<Résultat>` *Tableau de chaîne de caractères*
> Variable de type Tableau de chaînes contenant le résultat de l'action UPnP exécutée.
`<Service>` *Variable de type upnpService*
> Nom de la variable de type [upnpService](1000020908.md) correspondant au service sur lequel l'action doit être effectuée.
`<Action>` *Chaîne de caractères*
> Action à appeler sur le service.
`<Paramètre 1>` *Type de la valeur attendu (optionnel)*
> Premier paramètre à passer au service UPnP.
`<Paramètre N>` *Type de la valeur attendu (optionnel)*
> Nième paramètre à passer au service UPnP.

## Remarques

Si l'action n'est pas exécutée, la variable [ErreurDétecté](3087001.md) est à Vrai et la fonction [ErreurInfo](3013008.md) permet de connaître le détail de l'erreur.

**Composante : wd300device.dll**
