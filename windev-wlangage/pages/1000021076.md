# LienGantt (Type de variable)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU))

Le type **LienGantt** permet de définir toutes les caractéristiques avancées d'une liaison entre deux tâches d'un diagramme de Gantt. Les caractéristiques de cette liaison peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Récupération de tous les liens qui pointent sur "ID1"
tabLien est un tableau de LienGantt
tabLien = GanttListeLien(COL_Gantt, "ID1")
Lien est un LienGantt
POUR TOUT Lien DE tabLien
	Trace("Lié à " + Lien.IDSource)
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type LienGantt
Les propriétés suivantes peuvent être utilisées pour manipuler un lien entre deux tâches Gantt :

| **Nom de la propriété** | **Type manipulé** | **Effet** |
| --- | --- | --- |
| IDDestination | Chaîne de caractères | Identifiant de la tâche destination. Cet identifiant correspond à la propriété **ID** définie dans la variable de type [TâcheGantt](1000020881.md). |
| IDSource | Chaîne de caractères | Identifiant de la tâche source. Cet identifiant correspond à la propriété **ID** définie dans la variable de type [TâcheGantt](1000020881.md). |
| Type | Constante de type Entier | Type du lien. Les types de lien disponibles sont les suivants :   - *tlgDébutADébut* : Lien de type "Début à Début" : La tâche destination ne peut pas commencer avant que la tâche source ne soit commencée. - *tlgDébutAFin* : Lien de type "Début à Fin" : La tâche destination ne peut pas se terminer avant que la tâche source ne soit commencée (cas rare). - *tlgFinADébut* (valeur par défaut) : Lien de type "Fin à Début" : La tâche destination ne peut pas commencer avant que la tâche source ne soit terminée. - *tlgFinAFin* : Lien de type "Fin à Fin" : La tâche destination ne peut pas se terminer avant que la tâche source ne soit terminée. |

## Remarques

### Notes

- Un lien entre 2 tâches est représenté par une flèche.
- Ce type de variable :
  - sert à ajouter un lien via la fonction [GanttAjouteLien](1000021075.md),
  - peut être renvoyé par la fonction [GanttListeLien](1000021079.md).
- Un lien de type "Fin à Début" est créé par défaut entre les deux tâches : la tâche correspondant à la propriété **IDSource** doit être finie pour que la tâche **IDDestination** puisse commencer.
- Selon leurs types, les liens sont dessinés sur les bords de début ou de fin des tâches.

### Utilisation des variables de type LienGantt
Les variables de type **LienGantt** sont utilisées par les fonctions suivantes :

| [GanttAjouteLien](1000021075.md) | Crée un lien de type "Fin à Début" entre deux tâches affichées dans une colonne d'un champ Table (ou Table hiérarchique) de type Diagramme de Gantt. |
| --- | --- |
| [GanttListeLien](1000021079.md) | Liste les liens présents dans une colonne d'un champ Table (ou Table hiérarchique) de type Diagramme de Gantt. |
| [GanttSupprimeLien](1000021080.md) | Supprime des liens dans une colonne d'un champ Table (ou Table hiérarchique) de type Diagramme de Gantt. |
