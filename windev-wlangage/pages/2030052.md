# Description du projet : Onglet Fichiers de données

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

La fenêtre de description du projet permet de configurer de nombreux éléments de votre projet. Cette fenêtre est constituée des onglets suivants :

- L'onglet ["Projet"](2030046.md) qui permet de saisir les informations générales du projet.
- L'onglet "Analyse" qui permet d'associer une ou plusieurs analyses au projet et / ou un modèle UML.
- L'onglet **"Fichiers de données"** qui permet de saisir différentes informations sur les fichiers de données gérés par l'application (uniquement disponible si le projet est lié à une analyse).
- L'onglet "Live data" qui permet de configurer l'affichage des données (provenant des fichiers de données) sous les différents éditeurs.
- L'onglet ["Langues"](9500219.md) qui permet de paramétrer les différentes langues manipulées par le projet ainsi que les options linguistiques à utiliser pour chaque langue.
- L'onglet ["Style"](9500234.md) qui permet de choisir le thème de gabarit, la feuille de styles personnalisée et de personnaliser l'aperçu avant impression. Il est également possible de paramétrer la taille des écrans.
- L'onglet ["Ambiance"](1410087360.md) qui permet de choisir l'ambiance du projet, la palette associée, la feuille de styles et les ressources externes.
- L'onglet ["GDS"](9500239.md) qui permet de gérer le travail en groupe (GDS ou GIT).
- L'onglet ["Options"](9500227.md) qui permet de configurer les options de création, de mise à jour, et de sauvegarde des éléments. Cet onglet permet également de gérer la synchronisation des modèles, d'activer le mode strict et de définir la charte de programmation.
- L'onglet ["Avancé"](9500236.md) qui permet de gérer l'utilisation de "Etats & Requêtes", les FAA et le verrouillage de l'application.
- L'onglet ["Compilation"](9500218.md) qui permet de configurer les options de compilation.
- L'onglet ["Télémétrie"](9500223.md) qui permet de configurer les options de télémétrie pour le projet.
   Cette option n'est pas disponible.

## Onglet Fichiers de données

### Répertoire des fichiers de données à utiliser en mode test
Cette option permet de définir le répertoire des fichiers de données à utiliser en mode test : débogage, Go de fenêtre, de page ou de projet.
Par défaut, le répertoire utilisé est le répertoire de la configuration courante (sous-répertoire du répertoire EXE du projet).

Il est possible de spécifier un répertoire spécifique.

Cette option est intéressante si WINDEV est utilisé avec l'UAC active : il est possible d'utiliser en mode test le répertoire des données de l'application.

### Automatismes
Les options suivantes sont disponibles sur tous les types de données :

- **Activer l'assistance automatique HFSQL**
  Cette option permet d'activer la gestion automatique des erreurs par le moteur HFSQL. Pour plus de détails, consultez [Gestion assistée des erreurs](3044188.md).
- **Créer les fichiers de données automatiquement au moment de leur ouverture** :
  Cette option permet de créer automatiquement les fichiers de données décrits dans l'analyse si ces fichiers de données n'existent pas lors de l'utilisation de fonctions nécessitant leur ouverture. Dans ce cas, la fonction [HCréationSiInexistant](3044254.md) est automatiquement exécutée.
   Cette option est prise en compte par les connecteurs natifs à SQL Server, Informix, Sybase, MySQL, MariaDB et PostgreSQL.

### Ré-indexation automatique (Uniquement pour HFSQL)
La ré-indexation d'un fichier de données peut être rendue nécessaire par la perte ou l'altération du fichier d'index. Une ré-indexation automatique des fichiers de données peut être mise en place.
L'option "Activer la réindexation automatique" permet d'activer la réindexation automatique des fichiers de données en spécifiant plusieurs paramètres :

- le nombre d'enregistrements maximum : Si le fichier de données contient moins de XXX enregistrements, la réindexation est automatique en cas d'erreur d'index. Par défaut, cette valeur vaut 100000. Si cette variable vaut 0, la ré-indexation automatique est désactivée.
- l'affichage de la fenêtre de jauge permettant de suivre la ré-indexation en cours.

Remarque : la ré-indexation automatique est disponible uniquement sur les fichiers de données HFSQL Classic et HFSQL Client/Serveur.

### Mode de gestion des fichiers de données (Uniquement pour HFSQL)
Cette option permet de définir le mode de gestion des fichiers de données de l'application. Par défaut, les applications créées avec WINDEV et WEBDEV sont des applications multi-utilisateurs : les blocages sont gérés de manière automatique.
Il est possible de demander une gestion "Mono-utilisateur" : dans ce cas, les fichiers de données sont totalement bloqués en lecture et en écriture dès leur ouverture.

### Options pour les Connecteurs Natifs
Si l'option "Copier les connexions pendant la copie de contexte" est cochée, en utilisant un connecteur natif, lors de la copie de contexte, chaque contexte bénéficie en option de sa propre connexion au serveur de la base de données tierce. Cette option est nécessaire notamment dans le cas des transactions.
 Cette nouveauté est disponible pour les bases : MS SQLServer, Oracle, MySQL, Sybase, Progress, Informix, DB2, SQLite, MariaDB.
