# Fonctions de manipulation de chaînes graphiques

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions de gestion des chaînes graphiques permettent notamment d'afficher des chaînes graphiques dans :

- les lignes des champs Liste ou Combo,
- les champs Libellé.
- la barre de titre ou de message d'une fenêtre.

Les différentes fonctions permettant de créer et manipuler des chaînes graphiques sont les suivantes :

| [ChargeImage](3029022.md) | Charge une image en mémoire pour une utilisation ultérieure par la fonction [gImage](3029042.md). |
| --- | --- |
| [ChargePlancheImage](1000018826.md) | Charge une planche d'images en mémoire pour une utilisation ultérieure par la fonction [gImage](3029042.md). |
| [gARécupérer](3029025.md) | Décrit la valeur texte à afficher et à retourner lors de la récupération de la valeur d'un élément d'un champ Liste ou d'un champ Combo. |
| [gCadrage](3029046.md) | Construit une séquence de caractères contenant un texte cadré ou une image cadrée. |
| [gCercle](3029041.md) | Construit une séquence de caractères contenant un cercle ou une ellipse. |
| [gCoord](3029034.md) | Construit une séquence de caractères permettant de définir la position du curseur d'écriture d'un texte. |
| [gFond](3029037.md) | Construit une séquence de caractères permettant de définir la couleur d'affichage (couleur de fond d'un texte, d'un cercle, d'un rectangle, ...). |
| [gFondDégradé](1000017060.md) | Décrit une couleur d'affichage en mode dégradé. |
| [gImage](3029042.md) | Construit une séquence de caractères contenant une image. |
| [gImageExiste](1000021860.md) | Vérifie si une image a bien été chargée en mémoire. |
| [gLien](3029043.md) | Ajoute une valeur "invisible" dans un élément d'un champ Liste ou Combo. Fonction est conservée par compatibilité. Il est conseillé d'utiliser la fonction [gValeurMémorisée](1410088363.md). |
| [gLienActive](3029036.md) | Autorise ou non la récupération de la valeur définie par la fonction [gLien](3029043.md) dans un champ Liste ou dans un champ Combo. Fonction est conservée par compatibilité. Il est conseillé d'utiliser la fonction [gValeurMémoriséeActive](1410088364.md). |
| [gLienCliquable](1000021774.md) | Ajoute un lien cliquable dans une chaîne graphique. |
| [gLigne](3029044.md) | Construit une séquence de caractères contenant une ligne. |
| [gPolice](3029047.md) | Construit une séquence de caractères décrivant la police d'affichage à utiliser pour le texte. |
| [gPoliceBarrée](1000023596.md) | Construit une séquence de caractères permettant d'indiquer si le texte suivant l'appel de cette fonction est barré ou non. |
| [gPoliceGras](3029061.md) | Construit une séquence de caractères permettant d'indiquer si le texte suivant l'appel de cette fonction est en gras ou non. |
| [gPoliceItalique](3029062.md) | Construit une séquence de caractères permettant d'indiquer si le texte suivant l'appel de cette fonction est en italique ou non. |
| [gPoliceSoulignée](3029063.md) | Construit une séquence de caractères permettant d'indiquer si le texte suivant l'appel de cette fonction est souligné ou non. |
| [gPoliceTaille](3029064.md) | Construit une séquence de caractères permettant d'indiquer la taille de la police d'affichage du texte d'une chaîne graphique. |
| [gRectangle](3029045.md) | Construit une séquence de caractères permettant de dessiner un rectangle. |
| [gStylo](3029039.md) | Construit une séquence de caractères permettant de décrire la couleur d'affichage du texte et/ou du contour d'une figure (rectangle ou cercle). |
| [gValeurMémorisée](1410088363.md) | Ajoute une valeur "invisible" dans un élément d'un champ Liste, Combo ou Planning. |
| [gValeurMémoriséeActive](1410088364.md) | Autorise ou non la récupération de la valeur définie par la fonction [gValeurMémorisée](1410088363.md) dans un champ Liste ou dans un champ Combo. |
| [gVersTexte](1000020524.md) | Supprime les éléments graphiques d'une chaîne de caractères utilisant les fonctions [gValeurMémorisée](1410088363.md), [gImage](3029042.md), ... |
