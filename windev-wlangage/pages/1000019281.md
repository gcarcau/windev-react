# XMLDocument

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le mot-clé **xmlDocument** peut correspondre :

- à la fonction **XMLDocument** qui permet de créer un nouveau document XML. Pour plus de détails, consultez [XMLDocument](3081008.md).
- à une variable de type **xmlDocument**. Pour plus de détails, consultez [xmlDocument](1000018782.md).
