# ChampSupprime (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Supprime définitivement un champ d'une fenêtre, d'une page ou d'un état.
> _(WINDEV, iPhone/iPad)_ Dans une fenêtre ou un état, ce champ peut avoir été créé sous l'éditeur ou par la fonction ChampClone.

> _(WEBDEV - Code Serveur)_ Dans une page, la fonction ChampSupprime permet uniquement de supprimer les champs créés avec la fonction ChampClone.

> _(Android, Widget Android, Java)_ La fonction ChampSupprime permet uniquement de supprimer les champs créés avec la fonction ChampClone.

## Exemple

```wlangage
// Suppression d'un ensemble de champs
POUR I = 1 À 10
	s est une chaîne = "SAI_" + I
	SI ChampExiste(s) = Vrai ALORS
		ChampSupprime(s)
	FIN
FIN
```

## Syntaxe

```wlangage
ChampSupprime(<Champ manipulé>)
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ ou de la colonne (d'un champ Table) à supprimer. Si ce champ n'existe pas, une erreur WLangage est générée.

## Remarques

### Suppression d'une colonne d'un champ Table
Lors de la suppression d'une colonne d'un champ Table, le contenu du champ Table (fichier ou par programmation) associé à cette colonne est supprimé.

### Limites
Un champ supprimé ne peut pas être ré-utilisé par la suite comme source d'un clonage de champ (avec la fonction [ChampClone](3025017.md)).
