# Restaurer une sauvegarde d'un projet

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

WINDEV, WEBDEV et WINDEV Mobile permettent de sauvegarder régulièrement les différents éléments d'un projet sous forme d'archive (fichier d'extension ZIP). Ce fichier contient tous les éléments du projet sauvegardés. Pour plus de détails, consultez [Sauvegarder un projet](2030014.md).
A tout moment, il est possible de restaurer le projet archivé. La restauration d'un projet est effectuée depuis WINDEV, WEBDEV ou WINDEV Mobile.

## Comment le faire ?

### Pour restaurer une archive d'un projet :

1. Sous le volet "Projet", dans le groupe "Autres actions", déroulez "Plus d'actions" et sélectionnez "Restaurer un projet". L'assistant de restauration s'affiche.
2. Spécifiez le fichier archive contenant le projet à restaurer.
3. Sélectionnez le répertoire de la restauration.
4. Validez. La restauration est effectuée dans le répertoire spécifié.
