# FonctionsInterdites (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

La propriété **FonctionsInterdites** permet de connaître et de définir la liste des fonctions interdites dans un champ Editeur de code ou via les fonctions [Compile](3013015.md), [ExécuteCode](1000019783.md), [EvalueExpression](1000019782.md).
Cette propriété est disponible sur :

- la propriété [Compilateur](1410090383.md) du champ Editeur de code.
- une variable de type [CodeWLangageCompilation](1410090373.md).
