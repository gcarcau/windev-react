# Début (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Début** permet de connaître le début d'un élément ou événement. Cette propriété est utilisable sur :

- une variable de type [EvénementTimeline](1000020612.md).
- une variable de type [edtHTMLSélection](1000026093.md).
