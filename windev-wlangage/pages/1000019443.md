# NotifModifie (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android)

Modifie une notification actuellement affichée dans la barre système de l'appareil.

## Exemple

```wlangage
notif est une Notification
notif.Titre = "Nouveau message reçu"
notif.Message = "Cliquez pour afficher le message"
NotifAjoute(notif)
...
notif.Titre = "2 messages reçus"
notif.Message = "Cliquez pour afficher les messages"
NotifModifie(notif)
```

## Syntaxe

```wlangage
<Résultat> = NotifModifie(<Notification>)
```

`<Résultat>` *Booléen*
> - Vrai si la notification a été modifiée,
> - Faux dans le cas contraire.
>
>
> **Remarque** : Dans le simulateur, cette fonction est sans effet et renvoie toujours Faux.
`<Notification>` *Variable de type Notification*
> Nom de la variable de type [Notification](1000019441.md) contenant la description de la notification à mettre à jour.

**Composante : wd300android.jar**
