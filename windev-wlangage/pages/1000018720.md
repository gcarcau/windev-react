# Priorité (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

La propriété **Priorité** permet de connaître et de modifier le niveau de priorité d'un élément.
Cette propriété est utilisable sur :

- la structure [Email](3032029.md).
- une variable de type [Email](1000018713.md).
- une variable de type [Notification](1000019441.md).
- une variable de type [notificationCatégorie](1000023981.md).
- une variable de type [Document](1000022461.md).
- une variable de type [Thread](1000024879.md).
