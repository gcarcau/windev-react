# xlsFerme (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Ferme un fichier XLS.
Nouveauté 2025

> _(Android)_ Cette fonction est désormais disponible pour les applications Android.

> _(Widget Android)_ Cette fonction est désormais disponible en mode Widget Android.

> _(iPhone/iPad)_ Cette fonction est désormais disponible pour les applications iPhone/iPad.

## Exemple

```wlangage
MonFichierXLS est un xlsDocument

// Ouverture d'un fichier XLS
MonFichierXLS = xlsOuvre("C:\MesRépertoires\Fichier.XLS")
...
// Fermeture du fichier XLS
xlsFerme(MonFichierXLS)
```

## Syntaxe

#### Syntaxe utilisant le type xlsDocument

```wlangage
xlsFerme(<Document XLS>)
```

`<Document XLS>` *Variable de type xlsDocument*
> Nom de la variable de type [xlsDocument](1000017464.md) correspondant au fichier XLS à fermer. Le fichier physique associé à cette variable (s'il existe) est fermé. Les modifications réalisées dans le fichier ne sont pas sauvées avant sa fermeture (utilisez la fonction [xlsSauve](1000018057.md) si nécessaire).

#### Syntaxe conservée par compatibilité avec la version 12

```wlangage
xlsFerme(<Identifiant du fichier XLS>)
```

`<Identifiant du fichier XLS>` *Entier*
> Identifiant du fichier XLS à fermer, renvoyé par la fonction [xlsOuvre](3080017.md).
