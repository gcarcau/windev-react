# Manipuler un champ Popup par programmation

> **Disponible :** **WEBDEV** (Windows, PHP, WEBDEV - Code Navigateur)

## Présentation

La popup étant un champ de la page, il est possible d'accéder :

- depuis la popup aux champs de la page.
- depuis la page aux champs de la popup. Par exemple :
  ```wlangage
  SAI_NomSaisie = POPUP_MaPopup.SAI_Info_a_saisir
  ```

Les variables de la page sont accessibles dans les événements associés au champ Popup. Par exemple, le code suivant permet d'afficher une popup Fiche sur l'élément sélectionné dans un champ Zone répétée :

```wlangage
// Code de clic navigateur sur le champ Zone répétée ZR_ProduitsPOPUP_FICHE.IMG_PRODUIT = RépertoireWeb + "ui/vide.gif"PopupAnime(POPUP_FICHE, CELL_PAGE, animDéfilementGauche, 25)IDPRODUIT = ATT_IDPRODUITExécuteTraitement(POPUP_FICHE.ZONE_ENTETE_POPUP.BTN_Charger, trtClic)
```

## Manipuler le champ Popup par programmation

### Fonctions disponibles
Plusieurs fonctions sont spécifiques à la gestion des champs Popup :

| [PopupAffiche](1000019788.md) | Affiche une popup dans la page avec un effet de GFI (Grisage des Fenêtres Inaccessibles). |
| --- | --- |
| [PopupAnime](1000020313.md) | Affiche une popup dans une cellule de la page. |
| [PopupFerme](1000019789.md) | Masque une popup affichée dans la page via la fonction [PopupAffiche](1000019788.md). |

Remarques :

- Les fonctions [CelluleAfficheDialogue](1000017139.md) et [CelluleFermeDialogue](1000017140.md) sont compatibles avec les champs Popup. En cas de permutation des champs Cellules en champs Popup, le code existant reste compatible et fonctionnel.
- La fonction [MenuAjoutePopup](1000020583.md) permet de transformer une option de menu d'une page pour que cette option ouvre un champ Popup.
- Il est possible d'épingler un champ Popup grâce à la fonction [PopupAffiche](1000019788.md).

### Propriétés disponibles
Pour connaître la liste complète des propriétés du WLangage pouvant être utilisées avec un champ de type Popup, consultez [Propriétés associées au champ Popup](1000022003.md).
