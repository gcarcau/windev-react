# Constantes Hasp

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |
| **haspFichierLicence** | Fichier "zone de licence" de la clé. | [HaspHLEcrit](1000018897.md), [HaspHLInfo](1000018895.md), [HaspHLLit](1000018896.md) |
| **haspFichierPrincipal** | Fichier "zone de mémoire principale" de la clé. | [HaspHLEcrit](1000018897.md), [HaspHLInfo](1000018895.md), [HaspHLLit](1000018896.md) |
| **haspIgnoreTSE** | Désactive la vérification de l'environnement "Terminal Server". | [HaspHLConnecte](1000018891.md) |
| **haspInfoClé** | Informations sur la clé électronique. | [HaspHLInfo](1000018895.md) |
| **haspInfoSession** | Informations sur la session Hasp en cours. | [HaspHLInfo](1000018895.md) |
| **haspInfoTailleFichier** | Taille en octets d'un fichier de la clé Hasp. | [HaspHLConnecte](1000018891.md) |
| **haspLicenceLocale** | Utilise uniquement les clés Hasp locales. | [HaspHLConnecte](1000018891.md) |
| **haspLicenceParProcessus** | Les licences seront décomptées pour chaque processus lancé. | [HaspHLConnecte](1000018891.md) |
| **haspLicenceRéseau** | Utilise uniquement les clés Hasp réseau. | [HaspHLConnecte](1000018891.md) |
| **haspModeCompatible** | Connexion aux clés HASP de type HASP3 et HASP4. | [HaspHLConnecte](1000018891.md) |
