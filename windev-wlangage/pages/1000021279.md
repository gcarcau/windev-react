# PDFExtraitPage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Extrait une page d'un fichier PDF dans une variable de type [Image](1000019650.md).
Nouveauté 2025

> _(Widget IOS)_ Cette fonction est désormais disponible en mode Widget iOS.

> _(iPhone/iPad)_ Cette fonction est désormais disponible pour les applications iPhone/iPad.

> _(Android, Widget Android)_ La syntaxe permettant de manipuler une variable de type pdfDocument est désormais disponible.

## Exemple

```wlangage
// Extrait la page 3 du fichier texte.pdf
MonImage est une Image = PDFExtraitPage("texte.pdf", 3)
```

```wlangage
// Extrait la page 3 du fichier texte.pdf
MonPDF est un pdfDocument = PDFOuvre("test.pdf")
MonImage est une Image = PDFExtraitPage(MonPDF, 3)
```

## Syntaxe

#### Extraire une page d'un fichier PDF identifié par un chemin

```wlangage
<Résultat> = PDFExtraitPage(<Chemin du fichier> , <Numéro de la page> [, <Largeur> [, <Hauteur> [, <Mot de passe>]]])
```

`<Résultat>` *Image (variable de type image)*
> Variable de type [Image](1000019650.md) contenant l'image de la page extraite. L'image renvoyée est une image raster (non vectorielle).
> Remarque : Si le fichier PDF n'existe pas ou si la page n'existe pas, la variable [Image](1000019650.md) renvoyée sera invalide. La variable [ErreurDétectée](3087001.md) correspondra à Vrai.
`<Chemin du fichier>` *Chaîne de caractères*
> Chemin du fichier PDF à partir duquel la page doit être extraite.
`<Numéro de la page>` *Entier*
> Numéro de la page à extraire.
`<Largeur>` *Entier optionnel*
> Largeur à laquelle la page doit être rastérisée.
> Si ce paramètre n'est pas spécifié (ou si ce paramètre vaut 0), la hauteur et la largeur seront calculées à partir de la taille en millimètres de la page, en considérant un DPI de 300.
`<Hauteur>` *Entier optionnel*
> Hauteur à laquelle la page doit être rastérisée.
> Si ce paramètre n'est pas spécifié (ou si ce paramètre vaut 0), la hauteur et la largeur seront calculées à partir de la taille en millimètres de la page, en considérant un DPI de 300.
`<Mot de passe>` *Chaîne de caractères optionnelle ou Chaîne secrète*
> Mot de passe du document PDF.
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md). Nouveauté 2025
>
> > _(Android, Widget Android)_ Les chaînes secrètes ne sont pas disponibles pour ce paramètre en Android/Android Widget.

#### Extraire une page d'un fichier PDF identifié par une variable de type pdfDocument

```wlangage
<Résultat> = PDFExtraitPage(<Document PDF> , <Numéro de la page> [, <Largeur> [, <Hauteur> [, <Mot de passe>]]])
```

`<Résultat>` *Image (variable de type image)*
> Variable de type [Image](1000019650.md) contenant l'image de la page extraite. L'image renvoyée est une image raster (non vectorielle).
> Remarque : Si le fichier PDF n'existe pas ou si la page n'existe pas, la variable [Image](1000019650.md) renvoyée sera invalide. La variable [ErreurDétectée](3087001.md) correspondra à Vrai.
`<Document PDF>` *Variable de type pdfDocument*
> Nom de la variable de type [pdfDocument](1000024909.md) correspondant au document PDF à manipuler.
`<Numéro de la page>` *Entier*
> Numéro de la page à extraire.
`<Largeur>` *Entier optionnel*
> Largeur à laquelle la page doit être rastérisée.
> Si ce paramètre n'est pas spécifié (ou si ce paramètre vaut 0), la hauteur et la largeur seront calculées à partir de la taille en millimètres de la page, en considérant un DPI de 300.
`<Hauteur>` *Entier optionnel*
> Hauteur à laquelle la page doit être rastérisée.
> Si ce paramètre n'est pas spécifié (ou si ce paramètre vaut 0), la hauteur et la largeur seront calculées à partir de la taille en millimètres de la page, en considérant un DPI de 300.
`<Mot de passe>` *Chaîne de caractères optionnelle ou Chaîne secrète*
> Mot de passe du document PDF.
> Nouveauté 2025

> > _(Android, Widget Android)_ Les chaînes secrètes ne sont pas disponibles pour ce paramètre en Android/Android Widget.
