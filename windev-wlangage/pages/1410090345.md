# Manipuler des fichiers sur Dropbox, Google Drive et OneDrive

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

De nombreux drives permettent de stocker des fichiers. WINDEV, WEBDEV et WINDEV Mobile permettent de manipuler simplement les fichiers présents sur les drives Dropbox, Google Drive et OneDrive. Le code est identique quelque soit le drive manipulé.
Dans Google Drive, il est également possible de manipuler les fichiers de la suite Google.

Nouveauté 2025

> _(Android, iPhone/iPad)_ La manipulation des fichiers Dropbox est désormais disponible.

## Pré-requis

Pour manipuler les fichiers présents sur les différents drives, il est nécessaire de configurer les drives utilisés. Pour plus de détails, consultez [Pré-requis à l'utilisation des drives Google Drive, OneDrive et Dropbox](1410090346.md).

## Comment le faire ?

### Connexion
Avant d'utiliser les drives, il est nécessaire de s'y connecter.
Il est possible de se connecter aux différents drives en utilisant le protocole OAuth 2.0.

Pour cela :

1. Créez une nouvelle variable de type [OAuth2Paramètres](1000022212.md).
2. Définissez les différentes propriétés de cette variable, notamment :
  - ClientID : Identifiant client obtenu lors de la configuration du drive.
  - ClientSecret : Identifiant secret obtenu lors de la configuration du drive.
     Pour iOS, l'identifiant secret n'existe pas.
  - URLRedirection : Indiquez l'URL voulue, par exemple "http://localhost:9000".
     Pour iOS, l'URL de redirection correspond au "Schéma d'URL iOS" fourni par Google lors de la configuration. L'URL de redirection doit ressembler à l'URL suivante : "com.googleusercontent.apps.123-abc:/oauth".
3. Créez une variable de type [Drive](1410089369.md), et utilisez la fonction de connexion correspondant au drive voulu :
  | [dpDriveConnecte](1410089379.md) | Crée une connexion à un drive Dropbox. |
  | --- | --- |
  | [GglDriveConnecte](1410089373.md) | Crée une connexion à un drive Google Drive. |
  | [oDriveConnecte](1410089376.md) | Crée une connexion à un drive OneDrive. |

Remarque : Il est également possible de passer un token avec "refresh token". Cette solution permet d'éviter de redemander les informations de connexion à l'utilisateur. Le détail des informations à utiliser est donné dans la documentation de chaque fonction de connexion.

Exemples :

- Connexion à un drive Google via le protocole OAuth 2.0 :
  ```wlangage
  // Connexion au drive Google Drive via le protocole OAuth 2.0
  oOAuth2Param est un OAuth2Paramètres
  oOAuth2Param.ClientID = "client_id"
  oOAuth2Param.ClientSecret = "client_secret"
  oOAuth2Param.URLRedirection = "http://localhost:9000/"
  MonDrive est un gglDrive
  MonDrive = GglDriveConnecte(oOAuth2Param)
  ```
- Connexion à un drive Google via un token :
  ```wlangage
  // Connexion au drive Google Drive via un token (refresh token)
  oOAuth2Param est un OAuth2Paramètres
  oOAuth2Param est un OAuth2Paramètres
  oOAuth2Param.ClientID = "client_id"
  oOAuth2Param.ClientSecret = "client_secret"
  oOAuth2Param.URLRedirection = "http://localhost:9000/"
  oOAuth2Token est un AuthToken
  oOAuth2Token = AuthIdentifie(oOAuth2Param)
  MonDrive est un gglDrive
  MonDrive = GglDriveConnecte(oOAuth2Token)
  ```

### Manipulation des fichiers et des répertoires du drive
La manipulation des fichiers et des répertoires du drive est réalisée grâce aux fonctions suivantes. Ces fonctions manipulent toutes la variable de type Drive, renseignée lors de la connexion au drive.

- Fonctions de manipulation des fichiers :
  | [DriveCopieFichier](1410089524.md) | Copie un fichier unique du disque distant vers un autre répertoire du disque distant. |
  | --- | --- |
  | [DriveCréeFichier](1410089477.md) | Crée un fichier sur le disque distant. |
  | [DriveDéplaceFichier](1410089555.md) | Déplace un fichier présent dans un répertoire d'un drive vers un autre répertoire de ce drive (disque distant). |
  | [DriveEnvoieFichier](1410089563.md) | Envoie un fichier (présent sur la machine de l'utilisateur) vers un drive (disque distant). |
  | [DriveListeFichier](1410089380.md) | Liste les fichiers d'un répertoire d'un drive. |
  | [DriveRécupèreFichier](1410089558.md) | Récupère un fichier présent sur un drive (disque distant) et enregistre ce fichier sur le poste de l'utilisateur. |
  | [DriveRenomme](1410089566.md) | Renomme un fichier ou un répertoire présent sur un drive. |
  | [DriveSupprimeFichier](1410089480.md) | Supprime un fichier dans un drive (disque distant). |

- Fonctions de manipulation des répertoires :
  | [DriveCopieRépertoire](1410089554.md) | Copie un répertoire du drive vers un autre répertoire de ce drive (disque distant). |
  | --- | --- |
  | [DriveCréeRépertoire](1410089479.md) | Crée un répertoire sur le disque distant. |
  | [DriveDéplaceRépertoire](1410089556.md) | Déplace un répertoire et son contenu vers un autre répertoire du même drive (disque distant). |
  | [DriveEnvoieRépertoire](1410089564.md) | Envoie un répertoire et ses fichiers (présents sur la machine de l'utilisateur) vers un drive (disque distant). |
  | [DriveListeRépertoire](1410089448.md) | Liste les répertoires d'un drive. |
  | [DriveRécupèreRépertoire](1410089559.md) | Récupère un répertoire (et ses fichiers) présent sur un drive (disque distant) pour l'enregistrer sur le poste de l'utilisateur. |
  | [DriveRenomme](1410089566.md) | Renomme un fichier ou un répertoire présent sur un drive. |
  | [DriveSupprimeRépertoire](1410089481.md) | Supprime un répertoire (et les fichiers qu'il contient) sur un drive (disque distant). |

### Cas particulier : manipulation des fichiers de la suite Google Drive
Le drive Google Drive permet de manipuler les fichiers de la suite Google : Docs, Sheets, Slides, etc.
La manipulation de ces fichiers doit se faire via :

- une variable de type [gglDrive](1410089374.md), résultat de la fonction [GglDriveConnecte](1410089373.md).
- une variable de type [FichierGgl](1410089586.md), permettant de manipuler les fichiers de la suite Google.

Deux fonctions spécifiques à la manipulation de ces fichiers sont disponibles :

| [DriveListeFichierGgl](1410089601.md) | Liste les fichiers de la suite Google (Google Docs, Google Sheets, etc.) présents dans un drive Google. |
| --- | --- |
| [DriveRécupèreFichierGgl](1410089618.md) | Récupère un document de la suite Google présent sur un Google Drive dans le format compatible souhaité. |

La fonction [DriveListeFichierGgl](1410089601.md) permet d'obtenir la liste des fichiers de la suite Google présents sur le Drive. Cette fonction permet d'initialiser le type [FichierGgl](1410089586.md). Ce type de variable pourra ensuite être utilisé par les différentes fonctions de gestion des drives.

Exemple :

```wlangage
oOAuth2Param est un OAuth2Paramètres
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.URLRedirection = "http://localhost:9000/"

gglMonDrive est un gglDrive
gglMonDrive = GglDriveConnecte(oOAuth2Param)

tabFicGgl est un tableau de FichierGgl
tabFicGgl = DriveListeFichierGgl(gglMonDrive, "/", frRécursif)

POUR TOUT Fichier DE tabFicGgl
	SELON Fichier.TypeMime
		CAS typeMimeGglDocs : Fichier.TypeMimeExport = typeMimeDOCX
		CAS typeMimeGglSheets : Fichier.TypeMimeExport = typeMimeXLSX
		AUTRE CAS : Fichier.TypeMimeExport = typeMimePDF
	FIN
	soit ResRécupère = DriveRécupèreFichierGgl(gglMonDrive, tabFicGgl[1], "c:\MesDocuments")
	SI ErreurDétectée ALORS
		// Gestion de l'erreur
		Trace ("Une erreur s'est produite")
		RETOUR
	FIN
FIN
```
