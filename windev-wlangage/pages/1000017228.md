# DroiteAGauche (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **DroiteAGauche** permet de connaître le sens d'écriture réel, effectif sur un champ, une colonne, une fenêtre ou un état.
Le sens d'écriture peut être modifié avec la propriété [SensEcriture](2513020.md). Si le sens d'écriture utilisé dans le champ est le sens d'écriture défini dans les options du projet, la propriété [SensEcriture](2513020.md) renvoie la constante *seDéfaut*. Dans ce cas, la propriété **DroiteAGauche** permet de connaître le sens d'écriture réellement utilisé.

Cette propriété s'applique à :

- Une fenêtre ou les champs d'une fenêtre (sauf : Champ indicé, Champ Web caméra, Splitter, Calendrier et Agenda).
- Un état ou les champs suivants d'un état :
  - Champ Libellé,
  - Champ Calculé,
  - Champ texte RTF,
  - Champ Prédéfini,
  - Lien et Champ de saisie,
  - Champ Graphe.

> _(WEBDEV - Code Serveur, iPhone/iPad, Widget IOS, Mac Catalyst)_ Attention : Cette propriété est disponible uniquement dans les états.

## Exemple

> _(WINDEV)_ // Le sens d'écriture de la colonne est le sens par défaut
TABLE_Table1.COL_Colonne2.SensEcriture = seDéfaut
// Recherche du sens d'écriture par défaut
SI TABLE_Table1.COL_Colonne2.DroiteAGauche = Vrai ALORS
 SAI_Saisie1.SensEcriture = seDroiteAGauche
FIN

## Syntaxe

#### Connaître le sens d'écriture effectif utilisé

```wlangage
<Résultat> = <Nom de l'élément>.DroiteAGauche
```

`<Résultat>` *Booléen*
> - Vrai si le sens d'écriture utilisé est de droite à gauche,
> - Faux si le sens d'écriture utilisé est de gauche à droite.
`<Nom de l'élément>` *Nom de fenêtre, nom d'état ou nom de champ*
> Nom de l'élément pour lequel le sens d'écriture effectif est recherché :
>
> - Nom de la fenêtre,
> - Nom des champs de la fenêtre,
> - Nom de l'état,
> - Nom des champs de l'état.
>
>
> > _(WEBDEV - Code Serveur, iPhone/iPad, Widget IOS, Mac Catalyst)_ Ce paramètre correspond uniquement au nom de l'état ou au nom d'un champ de l'état.
