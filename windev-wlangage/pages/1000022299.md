# <Variable emailSessionIMAP>.SupprimeDossier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Supprime un dossier sur un serveur IMAP.

## Exemple

```wlangage
// Protocole IMAPMaSession est un emailSessionIMAP...// Suppression d'un dossier dans le dossier en cours MaSession.SupprimeDossier(MaSession.DossierCourant() + "\Travail") // Suppression d'un dossier dans le dossier personnelMaSession.SupprimeDossier("Dossiers personnels\Boîte de réception\TravailPerso")
```

## Syntaxe

```wlangage
<Résultat> = <Session>.SupprimeDossier(<Chemin du dossier>)
```

`<Résultat>` *Booléen*
> - Vrai si la suppression a été effectuée,
> - Faux dans le cas contraire. En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Session>` *Variable de type emailSessionIMAP*
> Nom de la variable de type [emailSessionIMAP](1000018957.md) correspondant à la session d'email à manipuler.
`<Chemin du dossier>` *Chaîne de caractères Unicode*
> Chemin du dossier à supprimer.

**Composante : wd300com.dll**
