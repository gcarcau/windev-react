# RendezVousAjoute (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Ajoute un rendez-vous :

- dans l'agenda d'une messagerie Lotus Notes ou Outlook. La structure [RendezVous](1000011010.md) permet de définir les informations concernant ce rendez-vous.
- dans un calendrier (ou agenda) d'un appareil Android.
- dans un calendrier (ou agenda) d'un appareil iOS.
- Nouveauté 2025
   dans l'agenda par défaut du périphérique.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur)_ // Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", "mail/julie.nsf", "C:\Lotus Notes\julie.id")
// Initialisation des variables de la structure RendezVous
RendezVousRAZ()
// Renseignements des variables pour le nouveau rendez-vous
mRendezVous.Objet = "Réunion commerciaux"
mRendezVous.DateDébut = "20070125100000"
mRendezVous.Lieu = "Salle 3B"
mRendezVous.NbParticipant = 3
mRendezVous.Participant[1] = "Romain"
mRendezVous.Participant[2] = "Lucas"
mRendezVous.Participant[3] = "Stéphane"
// Ajout du rendez-vous
SI RendezVousAjoute(IDSession) = Vrai ALORS
 Info("Rendez-vous ajouté")
SINON
 Erreur("Erreur lors de l'ajout", ErreurInfo())
FIN

> _(Android, Widget Android, iPhone/iPad, Widget IOS)_ gRDV est un RendezVous
gCal est un Calendrier
tabCalendrier est un tableau de Calendrier
// Récupère la liste des calendriers
tabCalendrier = RendezVousListeCalendrier()
gCal = tabCalendrier[1]

// Ajout d'un nouveau rendez-vous dans le premier calendrier
gRDV.Titre = SAI_Titre
gRDV.DateDébut = SAI_DateDeb + SAI_HeureDeb
gRDV.DateFin = SAI_DateFin + SAI_HeureFin
gRDV.Lieu = SAI_Lieu
gRDV.Contenu = SAI_Desc
SI SAI_Fuseau <> "" ALORS
 gRDV.FuseauHoraire = SAI_Fuseau
FIN
gRDV.Auteur = SAI_Auteur
gRDV.Invité = SAI_Invités
gRDV.JournéeEntière = INT_Jentière[1]

SI RendezVousAjoute(gCal, gRDV) ALORS
 ToastAffiche("RDV ajouté")
SINON
 Erreur(ErreurInfo())
FIN

> _(Android, Widget Android, iPhone/iPad, Widget IOS, Android, Widget Android)_ Ajouter un rendez-vous dans un calendrier (ou agenda) d'un appareil Android/iOS Masquer les détails
<Résultat> = RendezVousAjoute([<Calendrier>, ] <Rendez-vous>)

 <Résultat> : BooléenVrai si le rendez-vous a été ajouté, Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction ErreurInfo. <Calendrier> : Variable de type Calendrier optionnelleNom de la variable de type Calendrier correspondant au calendrier Android/iOS dans lequel le rendez-vous doit être ajouté. Nouveauté 2025Si ce paramètre n'est pas précisé, le rendez-vous sera ajouté dans l'agenda par défaut du téléphone.
 Si plusieurs comptes sont présents sur le téléphone et si un calendrier par défaut est associé à ces différents comptes, une fenêtre de sélection de compte sera affichée pour que l'utilisateur puisse sélectionner le compte à utiliser. <Rendez-vous> : Variable de type RendezVousNom de la variable de type RendezVous correspondant au rendez-vous à ajouter dans le calendrier spécifié de l'appareil Android/iOS.

## Syntaxe

#### Ajouter un rendez-vous dans l'agenda d'une messagerie Lotus Notes ou Outlook

```wlangage
<Résultat> = RendezVousAjoute(<Identifiant de la session>)
```

`<Résultat>` *Booléen*
> - Vrai si le rendez-vous a été ajouté,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Identifiant de la session>` *Entier*
> Identifiant de la session à utiliser. Cet identifiant est renvoyé par une des fonctions suivantes : [EmailOuvreSessionNotes](3032121.md), [EmailOuvreSessionOutlook](3032128.md), [NotesOuvreBase](1000005101.md) ou [OutlookOuvreSession](3032123.md).

## Remarques

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU))_ Agenda d'une messagerie Lotus Notes ou OutlookLors de la création d'un rendez-vous avec rappel dans Outlook, le rappel s'affiche immédiatement quelle que soit la date du rendez-vous.Les rendez-vous ajoutés sont des rendez-vous de type "meeting" (et non pas des rendez-vous de type "appointment"). Il est possible de modifier le type du rendez-vous en modifiant le champ "AppointmentType" du rendez-vous créé (par exemple avec la fonction NotesModifieChamp).Les différentes valeurs possibles pour les types sont :"0" : appointment"1" : anniversary"2" : event"3" : meeting"4" : reminder Exemple :

NotesModifieChamp(ID, "AppointmentType", "0")

Sous Outlook, il est possible de spécifier le mode de gestion des contacts/participants lors de l'ouverture de la session (fonction EmailOuvreSessionOutlook ou fonction OutlookOuvreSession). Rappel : Cette fonction ne permet pas d'ajouter un rendez-vous dans l'agenda d'une messagerie Outlook Express.

> _(Android, Widget Android)_ Agenda AndroidLa fonction RendezVousAjoute peut être utilisée dans l'émulateur mais pas dans le simulateur.
