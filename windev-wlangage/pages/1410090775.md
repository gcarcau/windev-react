# ExécuteProcédureRéactive (Fonction)

> **Disponible :** **WINDEV** (Windows)

Force l'exécution immédiate d'une procédure réactive.

## Exemple

```wlangage
ExécuteProcédureRéactive(CalculTTC)
```

```wlangage
PROCÉDURE RÉACTIVE CalculeTTC()
SAI_TTC = SAI_HT + SAI_HT * (SAI_TVA + 1) / 100
```

## Syntaxe

```wlangage
ExécuteProcédureRéactive(<Procédure WLangage> [, <Paramètre 1> [... [, <Paramètre N>]]])
```

`<Procédure WLangage>` *Nom de procédure*
> Nom de la procédure réactive WLangage à lancer. Cette procédure doit avoir été définie comme procédure réactive sous l'éditeur de code. Pour plus de détails, consultez [Procédures réactives](1514090.md).
`<Paramètre 1>` *Type du paramètre*
> Premier paramètre associé à la procédure.
`<Paramètre N>` *Type du paramètre*
> Nième paramètre associé à la procédure.

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
