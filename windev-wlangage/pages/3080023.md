# xlsNbFeuille (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Renvoie le nombre de feuilles d'un fichier XLS.
**Remarque** : En mode compatible, le nombre de feuilles est toujours égal à 1.

Nouveauté 2025

> _(Android)_ Cette fonction est désormais disponible pour les applications Android.

> _(Widget Android)_ Cette fonction est désormais disponible en mode Widget Android.

> _(iPhone/iPad)_ Cette fonction est désormais disponible pour les applications iPhone/iPad.

## Exemple

```wlangage
IdentifiantFichier est un entier

// Ouverture d'un fichier XLS
IdentifiantFichier = xlsOuvre("C:\Mes documents\MonFichier.XLS")
SI IdentifiantFichier <> -1 ALORS
	// Récupération du nombre de feuilles du fichier
	Info("Le fichier contient " + xlsNbFeuille(IdentifiantFichier) + " feuille(s).")
FIN
```

## Syntaxe

#### Syntaxe utilisant le type xlsDocument

```wlangage
<Résultat> = xlsNbFeuille(<Document XLS>)
```

`<Résultat>` *Entier*
> - Nombre de feuilles du fichier XLS spécifié,
> - -1 en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [xlsMsgErreur](3080016.md) ou la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Document XLS>` *Variable de type xlsDocument*
> Nom de la variable de type [xlsDocument](1000017464.md) correspondant au fichier XLS à fermer. Le fichier physique associé à cette variable (s'il existe) est fermé. Les modifications réalisées dans le fichier ne sont pas sauvées avant fermeture (utilisez la fonction [xlsSauve](1000018057.md) si nécessaire).

#### Syntaxe conservée par compatibilité avec la version 12

```wlangage
<Résultat> = xlsNbFeuille(<Identifiant du fichier XLS>)
```

`<Résultat>` *Entier*
> - Nombre de feuilles du fichier XLS spécifié,
> - -1 en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [xlsMsgErreur](3080016.md) ou la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Identifiant du fichier XLS>` *Entier*
> Identifiant du fichier XLS à manipuler, renvoyé par la fonction [xlsOuvre](3080017.md).

## Remarques

### Gestion des feuilles de type Graphique
Les feuilles Excel de type "Graphiques" sont ignorées. En effet, ces feuilles ne contiennent pas de cellules et ne sont donc pas accessibles.

**Composante : wd300xls.dll**
