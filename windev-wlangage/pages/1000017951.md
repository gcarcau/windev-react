# Latitude (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **Latitude** permet de connaître et de modifier la latitude d'un élément. Cette propriété est utilisable sur :

- une variable de type [gglCoordonnée](1000017489.md).
- une variable de type [gglMarqueur](1000017442.md).
- une variable de type [géoPosition](1000019191.md).
- une variable de type [PointGéo](1410090102.md).
