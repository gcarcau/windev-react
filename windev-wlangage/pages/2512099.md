# GUIDFichier (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

La propriété **GUIDFichier** renvoie le GUID du fichier de données défini dans l'analyse qui a permis de créer le fichier de données. Cet identifiant est utilisé dans le fichier .REP (pour plus de détails, consultez [Gestion du fichier .REP](3044186.md)).
**Remarque** : Le GUID du fichier de données peut également être connu dans l'éditeur d'analyses (onglet "Général" de la description du fichier de données).

## Exemple

```wlangage
// GUID du fichier de données "Client"
Trace(Client.GUIDFichier)
```

## Syntaxe

```wlangage
<GUID Fichier> = <Fichier de données>.GUIDFichier
```

`<GUID Fichier>` *Chaîne de caractères*
> - GUID du fichier de données défini dans l'analyse. Cette analyse a permis de créer le fichier de données.
> - Chaîne vide ("") si le fichier de données a été créé par programmation ou si le fichier de données utilisé n'est pas au format HFSQL Classic ou Client/Serveur.
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données pour lequel le GUID est recherché.

## Remarques

La propriété [GUIDAnalyse](2512098.md) permet de connaître le GUID de l'analyse qui a permis de créer le fichier de données.
