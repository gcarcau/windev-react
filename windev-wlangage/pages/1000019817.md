# Fonctions de gestion des champs Organigramme

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des champs Organigramme (syntaxe préfixée)](1000019986.md)).
Les fonctions de gestion des champs Organigramme sont les suivantes :

| [OrgaAffiche](1000019764.md) | Réinitialise le contenu d'un champ Organigramme à partir de sa source de données (fichier de données HFSQL par exemple). |
| --- | --- |
| [OrgaAjoute](1000019729.md) | Ajoute un nouvel élément "racine" dans un champ Organigramme. |
| [OrgaAjouteFils](1000019763.md) | Ajoute un élément fils dans un champ Organigramme. |
| [OrgaInfoXY](1000019759.md) | Renvoie l'indice de l'élément se trouvant à une position donnée dans le champ Organigramme. |
| [OrgaModifie](1000019921.md) | Modifie un élément dans un champ Organigramme. |
| [OrgaOccurrence](1000019971.md) | Renvoie le nombre d'éléments présents dans un champ Organigramme. |
| [OrgaSauveImage](1000019972.md) | Crée une image représentant la totalité d'un champ Organigramme. |
| [OrgaSelect](1000019762.md) | Renvoie l'indice de l'élément sélectionné dans un champ Organigramme. |
| [OrgaSelectMoins](1000019761.md) | Dé-sélectionne un élément dans un champ Organigramme. |
| [OrgaSelectPlus](1000019760.md) | Sélectionne un élément dans un champ Organigramme. |
| [OrgaSupprime](1000019758.md) | Supprime un élément et l'ensemble de ses "fils" d'un champ Organigramme. |
| [OrgaSupprimeTout](1000019749.md) | Supprime tous les éléments d'un champ Organigramme. |
