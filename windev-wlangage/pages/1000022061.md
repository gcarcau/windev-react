# Propriété (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Apple Watch)

La propriété **Propriété** permet de connaître et de modifier les propriétés d'un élément. Cette propriété est utilisable sur :

- une variable de type [Définition](1000019540.md).
- une variable de type [btleCaractéristique](1000022060.md).
