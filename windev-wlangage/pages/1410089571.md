# <Variable xlsDocument>.DéfusionneCellule (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Supprime la fusion d'une plage de cellules. La plage de cellules est identifiée par une cellule lui appartenant.
Nouveauté 2025

> _(Android)_ Cette fonction est désormais disponible pour les applications Android.

> _(Widget Android)_ Cette fonction est désormais disponible en mode Widget Android.

> _(iPhone/iPad)_ Cette fonction est désormais disponible pour les applications iPhone/iPad.

## Exemple

```wlangage
MonDocumentXLS est un xlsDocument
// Défusionne la plage de cellules identifiée par la cellule B2
MonDocumentXLS.DéfusionneCellule("B2")
```

## Syntaxe

#### Défusionner une plage de cellules identifiée par sa ligne et colonne

```wlangage
<Résultat> = <Document Excel>.DéfusionneCellule(<Ligne cellule> , <Colonne cellule>)
```

`<Résultat>` *Booléen*
> - Vrai si la plage de cellules a été défusionnée.
> - Faux dans le cas contraire.
`<Document Excel>` *Variable de type xlsDocument*
> Nom de la variable de type [xlsDocument](1000017464.md) à utiliser.
`<Ligne cellule>` *Entier*
> Numéro de ligne d'une des cellules de la plage de cellules à défusionner.
`<Colonne cellule>` *Entier*
> Numéro de colonne d'une des cellules de la plage de cellules à défusionner.

#### Défusionner une plage de cellules identifiée par son nom

```wlangage
<Résultat> = <Document Excel>.DéfusionneCellule(<Cellule>)
```

`<Résultat>` *Booléen*
> - Vrai si la plage de cellules a été défusionnée.
> - Faux dans le cas contraire.
`<Document Excel>` *Variable de type xlsDocument*
> Nom de la variable de type [xlsDocument](1000017464.md) à utiliser.
`<Cellule>` *Chaîne de caractères*
> Cellule présente dans la plage de cellules à défusionner. Ce paramètre est au format <Lettre de la colonne><Numéro de la ligne>. Par exemple : "A32".
