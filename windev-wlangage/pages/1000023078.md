# Fonctions MQTT

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions MQTT (syntaxe préfixée)](1000023098.md)).
Les fonctions permettant de gérer les clients MQTT sont les suivantes :

| [MQTTAbonne](1000023073.md) | Permet de s'abonner à une notification MQTT. |
| --- | --- |
| [MQTTConnecte](1000023021.md) | Permet de se connecter à un serveur MQTT (également appelé "Broker"). |
| [MQTTDéconnecte](1000023022.md) | Permet de se déconnecter d'un serveur MQTT (également appelé "Broker"). |
| [MQTTDésabonne](1000023074.md) | Permet de se désabonner d'une notification MQTT. |
| [MQTTDésabonneTout](1000023080.md) | Permet de se désabonner de tous les abonnements préalablement souscrits. |
| [MQTTPublie](1000023060.md) | Publie un message sur le broker MQTT. |
