# DriveCréeFichier (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Crée un fichier sur un drive (disque distant).

## Exemple

```wlangage
oOAuth2Param est un OAuth2Paramètres
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.URLRedirection = "http://localhost:9000/"
oDrive est un Drive
oDrive = oDriveConnecte(oOAuth2Param)

SI DriveCréeFichier(oDrive, "/MesRépertoires/Fichier.txt") = Faux ALORS
	Erreur("Impossible de créer le fichier demandé", ErreurInfo())
	RETOUR
FIN
```

## Syntaxe

```wlangage
<Résultat> = DriveCréeFichier(<Drive> , <Fichier à créer>)
```

`<Résultat>` *Booléen*
> - Vrai si le fichier a été créé,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Drive>` *Variable de type Drive ou gglDrive*
> Nom de la variable de type [Drive](1410089369.md) ou [gglDrive](1410089374.md) correspondant au drive à manipuler. La connexion au drive voulu doit avoir été effectuée. Dans le cas contraire, la création n'est pas réalisée.
`<Fichier à créer>` *Chaîne de caractères*
> Chemin absolu du fichier à créer. Si ce paramètre ne correspond pas à un chemin valide, l'élément ne sera pas créé. Les répertoires manquants dans le chemin ne sont pas créés.

## Remarques

### Paramètre <Fichier à créer>
Exemples de chemins valides :

```wlangage
"/mon répertoire de vacances/2021/""\photos"
```

Exemples de chemins invalides :

```wlangage
"répertoireA/RépertoireB""Ce/Chemin/Est/invalide""c:\Users\"
```
