# Gestion des menus principaux des fenêtres

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Un menu principal est obligatoirement associé à une fenêtre. Ce menu est affiché sous la barre de titre de la fenêtre. En règle générale, les applications contiennent une fenêtre menu. Cette fenêtre contient uniquement un menu principal et permet d'accéder aux autres fenêtres de l'application.

## Comment créer, éditer et supprimer un menu principal ?

### Créer un menu principal
Pour créer un menu principal :

1. Sous l'éditeur de fenêtres, ouvrez la fenêtre dans laquelle un menu principal doit être ajouté.
2. Sous le volet "Fenêtre", dans le groupe "Barres et menus", déroulez "Menu principal" et sélectionnez "Ajouter le menu principal". La première option de menu apparaît dans la barre de menu. Par défaut, le nom du menu principal créé est "_Menu" et le libellé de cette première option est "Menu".
   Le menu est automatiquement créé dans le champ Action Bar.
3. Pour modifier le nom du menu principal :
  - affichez l'onglet "Général" de la description de la fenêtre (option "Description" du menu contextuel de la fenêtre) et saisissez le nouveau nom du menu principal dans l'option "Nom du menu principal".
  - affichez l'onglet "Style" de la description de la fenêtre (option "Description" du menu contextuel de la fenêtre) et saisissez le nouveau nom du menu principal dans l'option "Nom du menu principal".
4. Ajoutez des options de menu directement dans la fenêtre en édition. Pour plus de détails, consultez [Manipuler les options de menu](1010008.md).

**Astuce** : Pour ajouter des images dans les options du menu, utilisez le catalogue d'images (option "Catalogue" du bouton [image: Bouton déroulant]). Les images sélectionnées seront automatiquement adaptées à la taille et au format d'image attendu par la plateforme d'exécution utilisée.

> _(WINDEV, Windows)_ Remarque : Menu dans les fenêtres détourées : Il est possible de spécifier la position du menu principal pour l'adapter au mieux à la fenêtre. Pour positionner le menu :Affichez la description de la fenêtre (option "Description" du menu contextuel de la fenêtre).Dans l'onglet "Général", saisissez les coordonnées X et Y du menu.

### Editer un menu principal
Pour éditer un menu principal :

1. Ouvrez une fenêtre avec un menu principal sous l'éditeur de fenêtres.
2. Sélectionnez une des options de menu. Les options et les sous-options s'affichent automatiquement.

### Supprimer un menu principal
Pour supprimer un menu principal :

1. Sous l'éditeur de fenêtres, ouvrez la fenêtre dans laquelle le menu principal doit être supprimé.
2. Sous le volet "Fenêtre", dans le groupe "Barres et menus", déroulez "Menu principal" et sélectionnez "Supprimer le menu principal". Toutes les options de menu et le code associé à ce menu principal sont supprimés.

> _(WINDEV, Windows)_ Menu ?WINDEV permet d'insérer automatiquement un menu utilitaire (menu "?") à la fin du menu principal.Pour plus de détails, consultez Menu ?.

## Manipuler un menu principal par programmation

Il n'est pas possible de manipuler directement un menu principal par programmation. Cependant, il est possible de manipuler par programmation les options d'un menu principal. Pour plus de détails, consultez [Manipuler les options de menu par programmation](1010007.md).
