# grTempsRéelIntervalle (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Fixe l'intervalle de temps visible dans un graphe temporel avec affichage en temps réel.
Exemple : Dans cet exemple, l'intervalle de temps est de 10 secondes.
Remarque : Cette fonction s'applique uniquement aux graphes ayant une échelle temporelle, pour lesquelles les données sont ajoutées avec la fonction [grAjouteDonnéeTemporelle](1000023532.md).

## Exemple

```wlangage
POUR i = 1 À 10
	d est une Durée
	d.Minute = i
	grAjouteDonnéeTemporelle(GRF_MonGraphe, 1, d, 2 + Sinus(i*36))
FIN

d est une Durée = 2 min
grTempsRéelIntervalle(GRF_MonGraphe, d)
grDessine(GRF_SansNom1)
```

## Syntaxe

```wlangage
grTempsRéelIntervalle(<Champ Graphe> , <Intervalle>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler.
`<Intervalle>` *Durée*
> Intervalle de temps visible dans le graphe (exprimé en millisecondes). Par défaut, cette valeur est de 60 secondes. Si ce paramètre correspond à 0, la valeur par défaut est utilisée.

**Classification Métier / UI : Code neutre**

**Composante : wd300grf.dll**
