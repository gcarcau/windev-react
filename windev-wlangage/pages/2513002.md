# Etendu (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

La propriété **Etendu** permet de :

- Savoir si une variable de type Police est étendue.
- Étendre ou non une variable de type Police.

**Remarque** : L'étirement des caractères d'une police peut être :

- Normal : la largeur des caractères est normale.
- Condensé : la largeur des caractères est diminuée (propriété [Condensé](2513006.md)).
- Étendu : la largeur des caractères est augmentée.
- Large : la largeur des caractères est augmentée au maximum (propriété [Large](2513012.md)).

## Exemple

```wlangage
// Définir les caractéristiques d'une variable de type police
Police1 est une Police
Police1.Nom = "Arial"
Police1.Taille = 14
Police1.Etendu = Vrai
// Appliquer la police au champ "MonChamp"
MonChamp.Police = Police1
```

## Syntaxe

#### Savoir si une variable de type Police est étendue

```wlangage
<Résultat> = <Police manipulée>.Etendu
```

`<Résultat>` *Booléen*
> - Vrai si la police spécifiée est étendue,
> - Faux dans le cas contraire.
`<Police manipulée>` *Variable de type Police*
> Nom de la variable de type [Police](1514045.md) à manipuler.

#### Étendre ou non une variable de type Police

```wlangage
<Police manipulée>.Etendu = <Étendu/Non étendu>
```

`<Police manipulée>` *Variable de type Police*
> Nom de la variable de type [Police](1514045.md) à manipuler.
`<Étendu/Non étendu>` *Booléen*
> - Vrai si la police spécifiée doit être étendue,
> - Faux dans le cas contraire.

## Remarques

### Variable de type Police
Il est possible de créer une police à partir d'une variable de type [Police](1514045.md).
Pour définir les caractéristiques de la police, utilisez :

- soit la fonction [PoliceCrée](3060002.md),
- soit les propriétés [Alphabet](2512008.md), [Angle](1410086632.md), [Barré](2513005.md), [Condensé](2513006.md), [Couleur](2510071.md), [Gras](2513001.md), [Italique](2513007.md), [Large](2513012.md), [Nom](2510082.md), [Souligné](2513013.md) et [Taille](2510125.md).

Cette police pourra être utilisée :

- Pour écrire du texte dans des dessins (fonction [dPolice](3029020.md)).
- Pour écrire dans les graphes (fonctions [grPoliceEtiquette](3042012.md), [grPoliceLégende](3042037.md), [grPoliceTitre](3042048.md) et [grPoliceTitreAxe](3042059.md)).
- Pour imprimer (fonction [iPolice](3046014.md)).
- Dans les champs d'une fenêtre (propriété [Police](1514045.md) des champs d'une fenêtre).
- Dans les champs d'un état (propriété [Police](1514045.md) des champs d'un état).

### Limites
Les propriétés permettant de définir l'étirement des caractères (propriétés [Condensé](2513006.md), **Etendu** et [Large](2513012.md)) sont gérées uniquement si la variable de type [Police](1514045.md) spécifiée est utilisée pour l'impression (police d'impression ou police des champs d'un état).
Dans les autres cas (police utilisée pour les dessins, les graphes ou les champs d'une fenêtre), ces caractéristiques ne sont pas prises en compte.
