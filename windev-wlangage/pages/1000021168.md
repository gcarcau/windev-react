# Fonctions SSH (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Les fonctions (syntaxe préfixée) permettant de se connecter et de dialoguer avec un serveur SSH sont les suivantes :

| [<Variable sshSession>.Commande](1410091176.md) | Envoie une commande à un serveur SSH. La session est ouverte et refermée automatiquement après l'envoi de la commande. |
| --- | --- |
| [<Variable sshSession>.ConnecteCommande](1410091177.md) | Permet de conserver la session SSH active entre plusieurs envois de commandes (via la fonction [<Variable sshSession>.Commande](1410091176.md)) à un serveur SSH. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [<Variable sshSession>.ConnecteShell](1000021163.md) | Ouvre une nouvelle session SSH de type "Shell". |
| [<Variable sshSession>.DéconnecteCommande](1410091178.md) | Permet d'arrêter la session SSH qui était active pour permettre l'envoi groupé de plusieurs commandes. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [<Variable sshSession>.DéconnecteShell](1000021164.md) | Ferme une session SSH précédemment ouverte grâce à la fonction [<Variable sshSession>.ConnecteShell](1000021163.md). |
| [<Variable sshSession>.Ecrit](1000021166.md) | Ecrit des données dans la session SSH spécifiée. |
| [<Variable sshSession>.Lit](1000021167.md) | Lit les données présentes sur le buffer de sortie de la session SSH. |

Remarque : Le protocole géré est SSH-2.
