# <Variable WDPic>.PixelOpacité (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Identifie l'opacité d'un pixel d'une image (calque d'arrière-plan d'une variable de type [WDPic](1000023503.md)) gérant la couche Alpha.

## Exemple

```wlangage
MonImageWDPic est un WDPic = "Test.bmp"
// Identification de l'opacité du pixel (15, 25)
// sur la variable MonImageWDPic
ResOpacité = MonImageWDPic.PixelOpacité(15, 25)
IMG_MonDessin = MonImageWDPic
```

## Syntaxe

```wlangage
<Résultat> = <Image WDPic>.PixelOpacité(<Abscisse> , <Ordonnée>)
```

`<Résultat>` *Entier*
> Opacité du pixel spécifié (comprise entre 0 pour transparent, et 255 pour une opacité complète).
`<Image WDPic>` *Variable de type WDPic*
> Nom de la variable de type [WDPic](1000023503.md) à manipuler. Seul le calque d'arrière-plan sera manipulé.
`<Abscisse>` *Entier*
> Position horizontale du pixel à manipuler.
`<Ordonnée>` *Entier*
> Position verticale du pixel à manipuler.

## Remarques

### Coordonnées
Les coordonnées sont indiquées en pixels par rapport au coin haut gauche de l'image (coordonnées (0,0)).

### Dessin dans une image avec opacité
Pour spécifier que le dessin dans l'image gère l'opacité (couche Alpha), utilisez la fonction [<Variable WDPic>.DébutDessin](1000024471.md) en spécifiant la constante ***dAvecOpacité***.
