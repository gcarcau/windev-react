# PoidsFaible (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Renvoie les deux octets de poids faible d'un entier.

## Exemple

```wlangage
Res est un entier
Res = 0x000A001F
Trace(PoidsFort(Res))	// Affiche 10 (correspond à 0x000A)
Trace(PoidsFaible(Res))	// Affiche 31 (correspond à 0x001F)
```

> _(WINDEV, Etats et Requêtes, Code Utilisateur (MCU))_ Res est un entier = CurseurPos(cpClient)
SI Res <> -1 ALORS
 Message("Position X = " + PoidsFaible(Res) + "Position Y = " + PoidsFort(Res))
FIN

## Syntaxe

```wlangage
<Résultat> = PoidsFaible(<Valeur> [, <Taille>])
```

`<Résultat>` *Entier sans signe sur 2 octets*
> Les deux octets de poids faible.
`<Valeur>` *Entier*
> Valeur dont le poids faible est recherché.
> Si cette valeur est d'un type numérique différent de entier, cette valeur sera automatiquement convertie en entier.
> Si cette valeur est une chaîne de caractères, une erreur sera affichée.
`<Taille>` *Entier optionnel*
> Taille de l'entier retourné :
>
> - 1 pour un entier sur 1 octet,
> - 2 pour un entier sur 2 octets,
> - 4 pour un entier sur 4 octets.
>
>
> > _(WEBDEV - Code Navigateur, Android, Widget Android)_ Ce paramètre n'est pas disponible.

## Remarques

- L'opérateur [&](1512002.md) permet de connaître l'adresse d'une variable.
- La fonction **PoidsFaible** peut être utilisée pour récupérer le poids faible d'un entier retourné par la fonction [API](3014005.md) ou [AppelDLL32](3014003.md).
- La fonction [PoidsFort](3014017.md) permet de récupérer le poids fort d'un entier.
- Pour construire un entier de 4 octets à partir de deux entiers de 2 octets, utilisez la fonction [ConstruitEntier](3062016.md).
