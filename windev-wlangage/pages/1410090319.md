# BitcoinCoreNombreHashParSeconde (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Renvoie le nombre de fois où la fonction sha256 a du être calculée par secondes pour calculer le dernier bloc. Ce nombre correspond à une preuve de travail.
Il est ainsi possible de connaître le niveau de sécurité des informations renvoyées par les fonctions [BitcoinCoreXXXX](1410090347.md).

## Exemple

```wlangage
// Récupération de la preuve de travail du dernier bloc
hashParSeconde est un réel
hashParSeconde = BitcoinCoreNombreHashParSeconde()
SI ErreurDétectée ALORS
	Erreur()
	RETOUR
FIN
Trace("Preuve de travail : " + hashParSeconde/1E18, "EH/s" + " (" + hashParSeconde + ")")
```

## Syntaxe

```wlangage
<Résultat> = BitcoinCoreNombreHashParSeconde()
```

`<Résultat>` *Réel*
> Nombre de fois où la fonction sha256 a du être calculée par secondes pour calculer le dernier bloc.

## Remarques

Pour utiliser les fonctions [BitcoinCoreXXXX](1410090347.md), il est nécessaire de configurer un serveur Bitcoin Core. Pour plus de détails, consultez [Installation et utilisation d'un serveur Bitcoin Core](1410090348.md).
