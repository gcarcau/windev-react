# UUDécode (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Décode une chaîne de caractères au format UUEncode.
**Remarque** : Cette chaîne a été encodée auparavant avec la fonction [UUEncode](1000018862.md).

## Exemple

```wlangage
// Encodage d'une chaîne
Res = UUEncode("Le numéro de mon compte est 0123456789")

// ...

// Décodage de la chaîne
ChaîneDécodée est une chaîne
ChaîneDécodée = UUDécode(Res)
```

## Syntaxe

```wlangage
<Résultat> = UUDécode(<Chaîne à décoder>)
```

`<Résultat>` *Chaîne de caractères*
> Chaîne décodée selon l'algorithme UUEncode.
`<Chaîne à décoder>` *Chaîne de caractères*
> Texte à décoder. Ce texte a été encodé avec la fonction [UUEncode](1000018862.md).

**Composante : wd300std.dll**
