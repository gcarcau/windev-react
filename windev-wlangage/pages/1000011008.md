# RendezVousSupprime (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Supprime :

- le rendez-vous en cours de l'agenda d'une messagerie Lotus Notes ou Outlook.
  **Rappel** : Cette fonction ne permet pas de supprimer le rendez-vous en cours de l'agenda d'une messagerie Outlook Express.
- un rendez-vous dans un calendrier (ou agenda) d'un appareil Android.
- un rendez-vous dans un calendrier (ou agenda) d'un appareil iOS.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur)_ // Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", ...
 "mail/julie.nsf", "C:\Lotus Notes\julie.id")
// Lecture du dernier rendez-vous
RendezVousDernier(IDSession)
// Suppression du rendez-vous
RendezVousSupprime(IDSession)

> _(Android, Widget Android, iPhone/iPad)_ // Supprime le rendez-vous correspondant à l'identifiant <25>
tabRDV est un tableau de RendezVous
tabRDV = RendezVousListe(MonCalendrier, rdvIdentifiant, 25)
SI tabRDV.Occurrence > 0 ALORS
 RendezVousSupprime(tabRDV[1])
FIN

## Syntaxe

#### Supprimer le rendez-vous en cours de l'agenda d'une messagerie Lotus Notes ou Outlook

```wlangage
<Résultat> = RendezVousSupprime(<Identifiant de la session> [, <Identifiant du rendez-vous>])
```

`<Résultat>` *Booléen*
> - Vrai si la suppression a été effectuée,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Identifiant de la session>` *Entier*
> Identifiant de la session à utiliser. Cet identifiant est renvoyé par une des fonctions suivantes : [EmailOuvreSessionNotes](3032121.md), [EmailOuvreSessionOutlook](3032128.md), [NotesOuvreBase](1000005101.md) ou [OutlookOuvreSession](3032123.md).
`<Identifiant du rendez-vous>` *Chaîne de caractères optionnelle*
> Identifiant du rendez-vous à supprimer. Cet identifiant est contenu dans la variable mRendezVous.ID.

> _(Android, Widget Android, iPhone/iPad)_ Supprimer un rendez-vous dans un calendrier (ou agenda) d'un appareil mobile (Android/iOS) Masquer les détails
<Résultat> = RendezVousSupprime(<Rendez-vous>)

 <Résultat> : BooléenVrai si la suppression a été effectuée, Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction ErreurInfo. <Rendez-vous> : Variable de type RendezVousNom de la variable de type RendezVous correspondant au rendez-vous à supprimer dans le calendrier de l'appareil mobile (Android/iOS).

## Remarques

> _(Android, Widget Android)_ Agenda AndroidLa fonction RendezVousSupprime peut être utilisée dans l'émulateur mais pas dans le simulateur.

> _(Android, Widget Android)_ Permissions requisesL'utilisation de cette fonction entraîne la modification des permissions requises par l'application.Permissions requises : READ_CALENDAR : Cette permission autorise l'application à lire les données calendrier de l'utilisateur.WRITE_CALENDAR : Cette permission autorise l'application à écrire les données calendrier de l'utilisateur.
