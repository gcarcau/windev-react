# RVB (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Décrit une couleur à partir de ses composantes Rouge, Vert et Bleu.

## Exemple

```wlangage
// Coloriage d'une zone en bleu clair
dRemplissage(10, 50, RVB(0, 255, 255))
```

## Syntaxe

```wlangage
<Résultat> = RVB(<Composante rouge> , <Composante verte> , <Composante bleue>)
```

`<Résultat>` *Entier*
> Couleur (24 bits) relative aux composantes fournies. Cette couleur est le résultat de la formule suivante :
> Couleur = 65536 * Composante Bleu + 256 * Composante Verte + Composante Rouge.
>
> > _(WEBDEV - Code Navigateur)_ La couleur est renvoyée sous forme de chaîne de caractères par le navigateur.
`<Composante rouge>` *Entier (de 0 à 255)*
> Portion de rouge dans la couleur.
`<Composante verte>` *Entier (de 0 à 255)*
> Portion de vert dans la couleur.
`<Composante bleue>` *Entier (de 0 à 255)*
> Portion de bleu dans la couleur.

## Remarques

> _(WEBDEV - Code Serveur, Ajax)_ Couleurs HTMLDans une page HTML, les couleurs sont représentées par une chaîne de caractères du type "#RRVVBB". RR, VV et BB représentent la valeur des composantes rouge, vert, bleu en hexadécimal.Pour convertir une couleur HTML en couleur RVB, utilisez le code suivant :

nRVB est un entier
CouleurHTML est une chaîne
// Si Couleur HTML n'a pas le #
nRVB = RVB(Val(Gauche(CouleurHTML, 2), "x"), ...
 Val(Milieu(CouleurHTML, 3, 2), "x"), ...
 Val(Droite(CouleurHTML, 2), "x"))
// Si Couleur HTML contient le #
nRVB = RVB(Val(Milieu(CouleurHTML, 2, 2), "x"), ...
 Val(Milieu(CouleurHTML, 4, 2), "x"), ...
 Val(Droite(CouleurHTML, 2), "x"))

Il est également possible d'utiliser la fonction RVBVersHTML.

### Fonction **RVB** et éditeur de code
Sous l'éditeur de code, la saisie de la fonction **RVB** avec ses paramètres affiche directement un carré avec la couleur correspondante :
Un clic dans le carré coloré permet d'ouvrir le sélecteur de couleur. [image: Sélecteur de couleur]

Si la couleur est modifiée, la modification est prise en compte à la validation du sélecteur de couleur.

### Divers

- Les couleurs demandées avec la fonction **RVB** peuvent être modifiées selon les capacités du mode écran en cours (VGA, 32 couleurs, etc.).
- **Important** : Il est conseillé, pour indiquer les couleurs, d'utiliser les constantes de couleurs définies dans le WLangage (voir [les couleurs prédéfinies du WLangage](3010002.md)).
