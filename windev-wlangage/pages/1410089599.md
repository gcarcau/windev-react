# GraduationY (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (iPhone/iPad)

La propriété **GraduationY** permet de connaître le pas de graduation sur l'axe des Y.

## Exemple

```wlangage
// Affiche le pas de graduation sur l'axe des Y
Info(GRF_MonGraphe.GraduationY)
```

## Syntaxe

```wlangage
<Résultat> = <Champ Graphe>.GraduationY
```

`<Résultat>` *Réel*
> Pas de graduation sur l'axe des Y.
`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler.
