# Evénement optionnel "Appui long"

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

L'événement optionnel "Appui long / Affichage menu contextuel" est exécuté lors de l'appui long sur les champs d'une fenêtre. Cet événement peut être utilisé :

- pour réaliser un traitement spécifique avant l'affichage du menu contextuel.
  Rappel : le menu contextuel associé au champ peut être défini dans l'onglet "UI" de la fenêtre de description du champ.
- pour afficher un menu contextuel par programmation via la fonction [OuvreMenuContextuel](3025029.md).

> _(Android)_ Cet événement est disponible sur tous les champs.

> _(iPhone/iPad)_ Cet événement est disponible sur les champs suivants : Champ Bouton, Champ Zone répétée,Champ Table, Champ Image.
Remarque : Pour les champs Table et Zone répétée, l'événement "Sélection de ligne" est exécuté AVANT l'événement "Appui long / Affichage menu contextuel".

## Mise en place

Pour utiliser l'événement optionnel "Appui long / Affichage menu contextuel" :

1. Affichez le code du champ (utilisez par exemple la touche F2 sur le champ).
2. Cliquez sur le lien "Ajouter d'autres événements à xxx" situé à la fin de la fenêtre de code, après le dernier événement.Dans la liste des événements optionnels, sélectionnez l'événement "Appui long / Affichage menu contextuel".
3. Validez. L'événement apparaît sous l'éditeur de code.
