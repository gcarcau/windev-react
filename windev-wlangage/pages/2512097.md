# FiltreAvecBornes (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **FiltreAvecBornes** permet de savoir si des bornes ont été précisées sur le filtre mis en place par la fonction [HFiltre](3044100.md) sur un fichier de données, une vue HFSQL ou une requête.

## Exemple

```wlangage
// Active le filtre
HFiltre(Client, NomClient, "D" + hValMin, "F" + hValMax, "Ville='Paris'")
SI Client.FiltreAvecBornes = Vrai ALORS Trace("Des bornes ont été précisées pour le filtre")
// Désactive le filtre
HDésactiveFiltre(Client)
```

## Syntaxe

```wlangage
<Résultat> = <Elément manipulé>.FiltreAvecBornes
```

`<Résultat>` *Booléen*
> - Vrai si des bornes ont été spécifiées pour le filtre avec la fonction [HFiltre](3044100.md),
> - Faux dans le cas contraire.
`<Elément manipulé>` *Chaîne de caractères*
> Nom du fichier de données, de la requête ou de la vue HFSQL sur laquelle le filtre a été défini.

## Remarques

### Valeur des bornes
Si des bornes ont été précisées, leurs valeurs peuvent être connues grâce aux propriétés [BorneMin](2510008.md) et [BorneMax](2510009.md).

### Rappel : hValMin et hValMax utilisées dans un filtre
Pour réaliser **un filtre générique sur une valeur**, il suffit de :

- compléter la borne minimale avec la constante ***hValMin*** pour lui donner la valeur minimale.
- compléter la borne maximale avec la constante ***hValMax*** pour lui donner la valeur maximale.

Par exemple, pour sélectionner les clients dont le nom commence par "Dupon" :

```wlangage
HFiltre(Client, Nom, "Dupon" + hValMin, "Dupon" + hValMax)
```

Les clients "Dupon" et "Dupontel" seront sélectionnés.

Pour plus de détails, consultez l'aide de la fonction [HFiltre](3044100.md).
