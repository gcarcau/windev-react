# Propriétés de gestion des polices

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Ces propriétés peuvent être utilisées sur une variable de type [Police](1514045.md).

| [Alphabet](2512008.md) | La propriété **Alphabet** permet de :   - Connaître l'alphabet actuellement utilisé par une variable de type Police. - Modifier l'alphabet utilisé par une variable de type Police. - Connaître l'alphabet utilisé par un fichier de données HFSQL. |
| --- | --- |
| [Angle](1410086632.md) | La propriété **Angle** permet de :  - Connaître l'angle (en degrés) d'une variable de type Police. - Modifier l'angle (en degrés) d'une variable de type Police. |
| [Barré](2513005.md) | La propriété **Barré** permet de :  - Savoir si une variable de type Police est barrée. - Barrer (ou non) une variable de type Police. |
| [Condensé](2513006.md) | La propriété **Condensé** permet de :  - Savoir si une variable de type Police est condensée. - Condenser (ou non) une variable de type Police.  **Cette propriété est conservée par compatibilité.** |
| [Couleur](2510071.md) | La propriété **Couleur** permet de connaître ou modifier la couleur de la police de :  - une variable de type Police. - un texte d'un champ Libellé ou calculé d'un état. - un texte d'un champ d'une fenêtre. - un texte d'un champ d'une page. |
| [Etendu](2513002.md) | La propriété **Etendu** permet de :  - Savoir si une variable de type Police est étendue. - Étendre ou non une variable de type Police.  **Cette propriété est conservée par compatibilité.** |
| [Gras](2513001.md) | La propriété **Gras** permet de :  - Savoir si une variable de type Police est en gras. - Modifier l'attribut gras d'une variable de type Police. |
| [Interlettre](1410088367.md) | La propriété **Interlettre** permet de connaître et de modifier l'espacement ajouté entre les caractères. |
| [Interligne](1410088366.md) | La propriété **Interligne** permet de connaître et de modifier l'interligne défini pour une variable de type [Police](1514045.md). |
| [Italique](2513007.md) | La propriété **Italique** permet de :  - Savoir si une variable de type Police est en italique. - Modifier l'attribut italique d'une variable de type Police. |
| [Large](2513012.md) | La propriété **Large** permet de :  - Savoir si une variable de type Police est élargie. - Élargir ou non une variable de type Police.  **Cette propriété est conservée par compatibilité.** |
| [Nom](2510082.md) | La propriété **Nom** permet de connaître :  - le nom de la police associée à une variable de type Police. - le nom d'un champ, d'un état ou d'un bloc d'un état. - le nom d'un champ, d'un groupe de champs ou d'une fenêtre. - le nom d'un champ, d'un groupe de champs ou d'une page. |
| [Souligné](2513013.md) | La propriété **Souligné** permet de :  - Savoir si une variable de type Police est soulignée. - Souligner (ou non) une variable de type Police. |
| [Taille](2510125.md) | La propriété **Taille** permet de connaître et modifier la taille d'un élément. |
| [UnitéTaille](1410088365.md) | La propriété **UnitéTaille** permet de connaître et de modifier l'unité utilisée pour manipuler la taille d'une police. |
