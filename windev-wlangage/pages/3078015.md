# TwainSourceEnCours (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Permet de connaître et de changer le périphérique Twain utilisé par défaut. Ce périphérique sera utilisé par défaut pour toutes les fonctions Twain suivantes.
**Remarque** : Pour connaître l'ensemble des périphériques Twain installés sur le poste en cours, utilisez la fonction [TwainListeSource](3078005.md).

## Exemple

```wlangage
// Périphérique Twain utilisé par défaut ?
Trace("Le périphérique utilisé par défaut est : " + TwainSourceEnCours())
```

```wlangage
// Changer le périphérique Twain utilisé par défaut
TwainSourceEnCours("Logitech Camera")
```

## Syntaxe

#### Changer le périphérique Twain utilisé par défaut

```wlangage
<Résultat> = TwainSourceEnCours(<Nom du driver>)
```

`<Résultat>` *Booléen*
> - Vrai si le périphérique spécifié a été pris en compte,
> - Faux dans le cas contraire. Le message d'erreur correspondant peut être connu avec la fonction [ErreurInfo](3013008.md).
`<Nom du driver>` *Chaîne de caractères*
> Nom du driver du périphérique Twain à utiliser par défaut. Ce nom doit correspondre à un des noms renvoyé par la fonction [TwainListeSource](3078005.md).

#### Connaître le périphérique Twain utilisé par défaut

```wlangage
<Résultat> = TwainSourceEnCours()
```

`<Résultat>` *Chaîne de caractères*
> Nom du driver du périphérique Twain utilisé par défaut.

## Remarques

### Changer le périphérique Twain par défaut
Pour changer le périphérique Twain utilisé par défaut, il est possible :

- soit d'utiliser la fonction **TwainSourceEnCours**.
- soit d'afficher la liste des périphériques Twain installés grâce à la fonction [TwainSelectSource](3078013.md). L'utilisateur pourra alors choisir le périphérique Twain à utiliser par défaut.

### Fonctionnement dans des applications 64 bits
Dans une application 64 bits, cette fonction utilisera automatiquement le driver Twain 64 bits. Si ce driver n'est pas installé, le périphérique TWAIN ne pourra pas être manipulé.

**Composante : wd300std.dll**
