# NullIndexé (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **NullIndexé** permet de paramétrer le mode de gestion de la valeur "Null" pour une rubrique clé. Il est ainsi possible de :

- Savoir si l'index peut supporter la valeur "Null" pour une rubrique clé.
- Définir le mode de gestion de la valeur "Null" pour une rubrique clé (lors de la description du fichier de données par programmation uniquement).

Remarque : Cette propriété est équivalente à l'option **"NULL indexé (le fichier de données sera incompatible avec les applications en version inférieure à 28)"** présente dans l'onglet "Détail" de la fenêtre de description du fichier de données, dans l'éditeur d'analyses.

**Attention : Les fichiers de données possédant l'option "Null indexé" activée, sont incompatibles avec les applications en version inférieure à la version 28.**

## Exemple

```wlangage
UnFichier est une Description de Fichier
UneRubrique est une Description de Rubrique
// Description du fichier de données "CLIENT"
UnFichier.Nom = "CLIENT"
UnFichier.Type = hFichierNormal
UnFichier.NullIndexé = Vrai
// Description de la rubrique
UneRubrique.Nom = "Message"
UneRubrique.Type = hRubTexte
UneRubrique.Taille = 40
HDécritRubrique(UnFichier, UneRubrique)
// Valide la description du fichier de données
HDécritFichier(UnFichier)
```

## Syntaxe

#### Savoir si l'index peut supporter la valeur "Null" pour une rubrique clé

```wlangage
<Résultat> = <Fichier de données>.NullIndexé
```

`<Résultat>` *Booléen*
> - Vrai si le fichier de données est configuré pour gérer la valeur "Null" pour une rubrique clé,
> - Faux dans le cas contraire.
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données manipulé. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Fichier](1514065.md).

#### Définir le mode de gestion de la valeur "Null" pour une rubrique clé (fichier de données défini par programmation)

```wlangage
<Fichier de données>.NullIndexé = <Gestion de la valeur Null>
```

`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données manipulé. Ce nom vient d'être défini grâce au type [Description de Fichier](1514065.md).
`<Gestion de la valeur Null>` *Booléen*
> - Vrai si le fichier de données doit être configuré pour autoriser la valeur "Null" pour une rubrique clé,
> - Faux dans le cas contraire.

## Remarques

### Gestion de la valeur "Null" pour les rubriques clé
Si le fichier de données supporte la valeur "Null" pour les clés :

- Il est possible d'utiliser les fonctions de recherche avec la valeur "Null".
- Plusieurs clés du fichier de données peuvent avoir la valeur "Null".
