# Invité (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Invité** permet de connaître et de modifier une liste d'invités. Cette propriété est utilisable sur :

- une variable de type [gglEvénement](1000017440.md)
- une variable de type [RendezVous](1000019244.md).
