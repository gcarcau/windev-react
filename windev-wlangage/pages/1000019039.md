# SaaSEcritParamètreSite (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Enregistre une information spécifique pour un site SaaS dans la configuration d'un compte client.

## Exemple

```wlangage
// Personnalisation du logo
SaaSEcritParamètreSite("logo", "./logo_PCSOFT.png")
```

## Syntaxe

```wlangage
<Résultat> = SaaSEcritParamètreSite(<Nom du paramètre> , <Valeur>)
```

`<Résultat>` *Booléen*
> - Vrai si le paramètre a pu être modifié,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
>
> Remarque : L'utilisateur connecté doit posséder les droits pour écrire cette information (droits d'administration).
`<Nom du paramètre>` *Chaîne de caractères*
> Nom du paramètre à modifier dans le site en cours.
> Les paramètres d'un site doivent avoir été définis dans l'[Administrateur SaaS](1600000.md) lors de la configuration du site.
`<Valeur>` *Chaîne de caractères*
> Nouvelle valeur du paramètre.

## Remarques

Les paramètres d'un site sont définis par l'administrateur du système SaaS lors de la configuration du site dans l'[Administrateur SaaS](1600000.md). Ils peuvent avoir des valeurs par défaut.
Les paramètres des sites sont destinés à permettre la personnalisation de l'IHM ou du comportement des sites SaaS. Pour plus de détails sur leur utilisation, consultez "[Développement d'un site SaaS](9500214.md)".
