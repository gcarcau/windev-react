# PlanificateurModifieTâche (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Modifie les paramètres d'une tâche planifiée. Ces paramètres sont ceux saisis dans la structure [TâchePlanifiée](3089004.md).
**Remarque** : Pour remplir la structure TâchePlanifiée avec les paramètres d'une tâche, utilisez la fonction [PlanificateurPropriétésTâche](3089011.md).

## Exemple

```wlangage
// Initialisation des valeurs par défaut
PlanificateurRAZ()
// Description de la tâche à ajouter
TâchePlanifiée.Application = "Calc.exe"  // Chemin du programme
TâchePlanifiée.Utilisateur = "Janis"     // Utilisateur de la session
TâchePlanifiée.MotDePasse = SAI_MDP          // Mot de passe de la session
TâchePlanifiée.Commentaire = "Programme de calcul"      // Commentaire de la tâche
TâchePlanifiée.SuppressionAutomatique = Faux      // Booléen à vrai si la tâche doit être supprimée
// Ajout de la tâche préalablement décrite
PlanificateurAjouteTâche("Calculatrice")

...

// Modification du commentaire
TâchePlanifiée.Commentaire = "Calculette"
PlanificateurModifieTâche("Calculatrice")
```

## Syntaxe

```wlangage
<Résultat> = PlanificateurModifieTâche(<Nom de la tâche>)
```

`<Résultat>` *Booléen*
> - Vrai en cas de succès,
> - Faux en cas d'erreur.
`<Nom de la tâche>` *Chaîne de caractères*
> Nom de la tâche à manipuler. Ce nom a été défini lors de la création de la tâche avec la fonction [PlanificateurAjouteTâche](3089003.md).

## Remarques

### Paramètres concernant l'utilisateur
Si la variable **TâchePlanifiée.Application** est modifiée, il est nécessaire de renseigner à nouveau le mot de passe de l'utilisateur (variable TâchePlanifiée.MotDePasse).
