# SaaSAdminModifieUtilisateur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Modifie un utilisateur SaaS.
**Remarques** :

- L'utilisation de cette fonction nécessite d'avoir ouvert une session d'administration SaaS au préalable en utilisant la fonction [SaaSAdminConnecte](1000019098.md).
- L'Administrateur SaaS gère tous les utilisateurs de tous les clients. Un gestionnaire de compte client ne peut modifier des utilisateurs que dans son propre compte client.

## Exemple

```wlangage
MonUtilisateur est un saasUtilisateur
...
MonUtilisateur = SaaSAdminChercheUtilisateur("marc@hybrid.com")
MonUtilisateur.Nom = "marc.durand@hybrid.com"

SaaSAdminModifieUtilisateur(MonUtilisateur)
```

## Syntaxe

```wlangage
<Résultat> = SaaSAdminModifieUtilisateur(<Utilisateur>)
```

`<Résultat>` *Booléen*
> - Vrai si la modification a été effectuée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Utilisateur>` *Variable de type saasUtilisateur*
> Nom de la variable de type [saasUtilisateur](1000019083.md) correspondant à l'utilisateur à modifier dans la base SaaS.

**Composante : wd300com.dll**
