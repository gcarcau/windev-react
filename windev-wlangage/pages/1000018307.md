# Fonctions de gestion des files, des piles et des listes

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Les fonctions suivantes permettent de gérer les types File, Pile et Liste :

| [Défile](1000018322.md) | Défile un élément d'une file. |
| --- | --- |
| [Dépile](1000017372.md) | Dépile un élément d'une pile. |
| [Empile](1000017366.md) | Empile un élément dans une pile. |
| [Enfile](1000018323.md) | Enfile un élément dans une file. |
| [FileInfo](1000019547.md) | Récupère les caractéristiques d'une file : types des éléments et nombre d'éléments. |
| [ListeInfo](1000019548.md) | Récupère les caractéristiques d'une liste WLangage : types des éléments et nombre d'éléments. _(WEBDEV - Code Navigateur)_ Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. |
| [PileInfo](1000019546.md) | Récupère les caractéristiques d'une pile : types des éléments et nombre d'éléments. |
