# <redisConnexion>.PipelineRAZ (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Ignore les résultats de l'exécution d'une commande Redis ayant été ajoutée par la fonction [<redisConnexion>.PipelineAjoute](1410088283.md).
Nouveauté 2025
Cette fonction peut également être utilisée pour manipuler des données sur un serveur Valkey.

## Exemple

```wlangage
gRedis.PipelineAjoute("get p2")
gRedis.PipelineAjoute("get p1")
gRedis.PipelineAjoute("set p3 v3")
gRedis.PipelineAjoute("set p4 v4")

// Récupération des 2 premiers résultats
r1 est un redisRéponse = gRedis.PipelineRécupère()
r2 est un redisRéponse = gRedis.PipelineRécupère()
// Ignore les résultats suivants
gRedis.PipelineRAZ()
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.PipelineRAZ()
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été effectuée,
> - Faux dans le cas contraire.
`<Connexion>` *Variable de type redisConnexion*
> Nom de la variable de type [redisConnexion](1000023527.md) correspondant à la connexion au serveur Redis.

## Remarques

### Fonctionnement du pipeline
Lorsque l'ensemble des commandes souhaitées auront été ajoutées dans le pipeline, les résultats pourront être récupérés avec la fonction [<redisConnexion>.PipelineRécupère](1410088285.md).
Pour ne pas récupérer les résultats, il est possible d'utiliser la fonction **<redisConnexion>.PipelineRAZ**.

Si la fonction **<redisConnexion>.PipelineRAZ** n'a pas été utilisée, il doit y avoir autant d'appels à la fonction [<redisConnexion>.PipelineRécupère](1410088285.md) que d'appels à la fonction [<redisConnexion>.PipelineAjoute](1410088283.md).
