# gpwAjouteUtilisateurDansGroupe (Fonction)

> **Disponible :** **WINDEV** (Windows) · **WINDEV Mobile** (Android, iPhone/iPad)

Ajoute un utilisateur dans un groupe de la base de données du groupware utilisateur.

## Exemple

```wlangage
gpwAjouteUtilisateurDansGroupe("Premium")
SI ErreurDétectée = Vrai ALORS
       // Message complet de l'erreur principale
        Trace(ErreurInfo())
FIN
```

## Syntaxe

```wlangage
<Résultat> = gpwAjouteUtilisateurDansGroupe(<Groupe> [, <Déplacement>])
```

`<Résultat>` *Booléen*
> - Vrai si l'utilisateur a été ajouté au groupe,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet d'identifier l'erreur.
`<Groupe>` *Chaîne de caractères*
> Nom du groupe auquel l'utilisateur en cours doit être associé.
`<Déplacement>` *Booléen optionnel*
> - Vrai si l'utilisateur doit être déplacé dans le groupe spécifié. Dans ce cas, l'utilisateur sera associé uniquement à ce groupe. Il sera supprimé de tous les autres groupes.
> - Faux (valeur par défaut) si l'utilisateur doit être associé au groupe spécifié tout en restant associé aux autres groupes.

**Composante : wd300gpu.dll**
