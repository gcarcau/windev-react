# ContactDernier (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **Autres** (Procédures stockées)

Lit le dernier contact présent dans le carnet d'adresses d'une messagerie Lotus Notes ou Outlook.
**Attention** : Cette fonction **ne permet pas** de lire le dernier contact présent dans le carnet d'adresses d'une messagerie Outlook Express.
Lors de la lecture d'un contact, les données de ce contact sont mis à jour dans la [structure Contact](1000006111.md). Pour récupérer les données du contact en cours, il suffit de récupérer les valeurs de la [structure Contact](1000006111.md).

## Exemple

```wlangage
// Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", ...
		"mail/julie.nsf", "C:\Lotus Notes\julie.id")
// Lecture du dernier contact
ContactDernier(IDSession)
// Ajout des contacts trouvés dans un champ Liste
TANTQUE mContact.EnDehors = Faux
	ListeAjoute(LISTE_ListeContact, mContact.Nom + TAB + mContact.Prénom)
	ContactPrécédent(IDSession)
FIN
```

## Syntaxe

#### Lire le dernier contact dans la messagerie Lotus Notes ou Outlook

```wlangage
<Résultat> = ContactDernier(<Identifiant de la session>)
```

`<Résultat>` *Booléen*
> - Vrai si le dernier contact a été lu,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Identifiant de la session>` *Entier*
> Identifiant de la session à utiliser. Cet identifiant est renvoyé par la fonction [EmailOuvreSessionNotes](3032121.md), [EmailOuvreSessionOutlook](3032128.md), [NotesOuvreBase](1000005101.md) ou [OutlookOuvreSession](3032123.md).
