# HTMLExécuteProcédureNavigateur (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Exécute une procédure WLangage navigateur WEBDEV dans un champ d'affichage HTML avec une page créée par WEBDEV.

## Exemple

```wlangage
// Exécuter la procédure navigateur VérifieSaisie()
HTMLExécuteProcédureNavigateur(HTM_AffichageHTML, "VérifieSaisie")
```

## Syntaxe

```wlangage
HTMLExécuteProcédureNavigateur(<Champ d'affichage HTML> , <Procédure navigateur> [, <Paramètre 1> [, <Paramètre N>]])
```

`<Champ d'affichage HTML>` *Nom de champ*
> Nom du champ d'affichage HTML manipulé.
`<Procédure navigateur>` *Chaîne de caractères*
> Nom de la procédure WLangage navigateur WEBDEV à exécuter. Cette procédure doit être une procédure locale de la page WEBDEV affichée dans le champ.
`<Paramètre 1>` *Type quelconque optionnel*
> Premier paramètre optionnel à passer à la procédure.
> $~ ... |
`<Paramètre N>` *Type quelconque optionnel*
> Nème paramètre optionnel à passer à la procédure.

## Remarques

Le nom réel de la procédure utilisé par WEBDEV pour les procédures Javascript ne correspond pas au nom de la procédure navigateur saisi sous l'éditeur. La fonction **HTMLExécuteProcédureNavigateur** effectue automatiquement la liaison entre les différents noms. Cette fonction doit donc être préférée à la fonction [ExécuteJS](1000023014.md).
