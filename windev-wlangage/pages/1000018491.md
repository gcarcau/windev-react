# IDUtilisateur (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **IDUtilisateur** permet de connaître l'identifiant de l'utilisateur. Cette propriété est utilisable sur :

- une variable de type [sfInfoSession](1000018416.md).
- une variable de type [sfInfoUtilisateur](1000018423.md).
