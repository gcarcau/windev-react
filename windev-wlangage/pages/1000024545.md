# NavigateurImprime (Fonction)

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur)

Imprime la page courante actuellement affichée dans le navigateur.

## Exemple

```wlangage
NavigateurImprime()
```

## Syntaxe

```wlangage
NavigateurImprime()
```

**Composante : WDJS.DLL**
