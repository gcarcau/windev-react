# PointDAttache (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **PointDAttache** permet de gérer les points d'attache d'une forme présente dans un diagramme affiché dans un champ Editeur de diagrammes. Cette propriété est utilisable sur :

- une variable de type [diagForme](1410088082.md).
- une variable de type [diagChemin](1410088384.md),
- une variable de type [diagGroupe](1410088127.md),
- une variable de type [diagImage](1410088414.md),
- une variable de type [diagLien](1410088454.md),
- une variable de type [diagOvale](1410088135.md),
- une variable de type [diagPolygone](1410088137.md),
- une variable de type [diagRectangle](1410088083.md),
- une variable de type [diagExtrémité](1410088470.md),
- une variable de type [diagActionAutorisée](1410088840.md).

**Composante : wd300.dll**
