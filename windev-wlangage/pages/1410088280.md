# <redisConnexion>.Connecte (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Ouvre une connexion vers un serveur Redis (ou un cluster Redis).
Nouveauté 2025
Cette fonction peut également être utilisée pour manipuler des données sur un serveur Valkey.

## Exemple

```wlangage
gRedis est un redisConnexion
gRedis.Serveur = "MonServeurRedis:7001"
SI gRedis.Connecte() = Faux ALORS
	ErreurInfo()
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.Connecte()
```

`<Résultat>` *Booléen*
> - Vrai si la connexion a réussi,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet d'identifier l'erreur. Pour plus de détails, consultez la documentation de Redis.
`<Connexion>` *Variable de type redisConnexion*
> Nom de la variable de type [redisConnexion](1000023527.md) correspondant à la connexion à un serveur Redis (ou à un cluster Redis).
