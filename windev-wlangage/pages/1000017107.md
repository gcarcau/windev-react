# ServiceActualise (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Demande à un service de relire ses informations de configuration. Ce service peut être un service présent sur le poste local ou sur un poste distant.

## Exemple

```wlangage
// Actualise le service présent dans la table TABLE_Service
SI ServiceActualise(COL_Nom[TABLE_Service]) = Faux ALORS
	Erreur(ErreurInfo(errMessage))
FIN
```

## Syntaxe

```wlangage
<Résultat> = ServiceActualise(<Nom du service> [, <Poste distant>])
```

`<Résultat>` *Booléen*
> - Vrai si la demande d'actualisation a été transmise au gestionnaire de services,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Nom du service>` *Chaîne de caractères*
> Nom du service à actualiser.
`<Poste distant>` *Chaîne de caractères optionnelle*
> Adresse IP du poste distant au format xxx.xxx.xxx.xxx (obtenu par la fonction [NetAdresseIP](3056023.md)) ou nom du poste distant (obtenu par la fonction [NetNomMachine](3056014.md)). Ce paramètre permet d'actualiser un service sur un autre poste. Pour utiliser cette option, l'utilisateur doit être administrateur de la machine distante.
> Si ce paramètre n'est pas précisé ou correspond à une chaîne vide, le service est manipulé en local.

## Remarques

### Mode de fonctionnement
La fonction **ServiceActualise** demande au gestionnaire de services d'actualiser le service. Cette opération peut ne pas être effectuée immédiatement. Pour connaître l'état du service, utilisez la fonction [ServiceAttendEtat](1000017101.md).

**Composante : wd300std.dll**
