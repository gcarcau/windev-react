# PoliceBarrée (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

La propriété **PoliceBarrée** permet de gérer si un texte est barré ou non. Cette propriété est utilisable sur :

- les champs. Pour plus de détails, consultez [PoliceBarrée](2510091.md).
- une variable de type [docMiseEnForme](1000022817.md).
