# Constantes de gestion des images dans des sites Web

> **Disponible :** **WEBDEV** (Windows, Linux, PHP)

Afficher uniquement les constantes utilisées par les syntaxes préfixées
Afficher uniquement les constantes utilisées par les syntaxes non préfixées
Les constantes de gestion des champs Image sont les suivantes :

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |
| **défilementCourant** | Remplit la liste des images et lance le défilement depuis la position courante si possible. | [ImageLanceDéfilement](1000019427.md) |
| **défilementInitialise** | Remplit la liste des images et lance le défilement depuis le début. | [ImageLanceDéfilement](1000019427.md) |
| **défilementLance** | Lance (ou relance) le défilement depuis la position courante. | [ImageLanceDéfilement](1000019427.md) |

Les constantes de gestion des champs Image (via les syntaxes préfixées) sont les suivantes :

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |
| **défilementCourant** | Remplit la liste des images et lance le défilement depuis la position courante si possible. | [<Image>.LanceDéfilement](1000023749.md) |
| **défilementInitialise** | Remplit la liste des images et lance le défilement depuis le début. | [<Image>.LanceDéfilement](1000023749.md) |
| **défilementLance** | Lance (ou relance) le défilement depuis la position courante. | [<Image>.LanceDéfilement](1000023749.md) |
