# NbVignette (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **NbVignette** permet de connaître le nombre de vignettes générées d'une rubrique. Cette rubrique a été définie sous l'éditeur d'analyses ou définie par programmation.
**Remarque** : Les vignettes HFSQL d'une rubrique sont générées automatiquement lors :

- de l'écriture de l'enregistrement correspondant (fonctions [HAjoute](3044147.md) ou [HEcrit](3044092.md)),
- de la modification de la valeur de la rubrique (fonction [HModifie](3044042.md)),
- de la [modification automatique des fichiers de données](3044195.md).

## Exemple

```wlangage
// Connaître le nombre de vignettes générées
// et le nombre de vignettes attendues
// pour la rubrique Client.Photo
NombreVignette est un entier
NombreVignetteAttendu est un entier
NombreVignette = Client.Photo.NbVignette
NombreVignetteAttendu = Client.Photo.NbVignetteDécrit
// Nombre égal ?
SI NombreVignette = NombreVignetteAttendu ALORS
	Info("Toutes les vignettes ont été générées")
SINON
	POUR Nombre = 1 À NombreVignetteAttendu
		ChaîneErreur += "Vignette " + Nombre + Client.Photo.InfoGénérationVignette[n] + RC
	FIN
	Erreur("Erreur de génération", ChaîneErreur)
FIN
```

## Syntaxe

```wlangage
<Nombre de vignettes générées> = <Fichier de données>.<Rubrique>.NbVignette
```

`<Nombre de vignettes générées>` *Entier*
> Nombre de vignettes générées pour la rubrique spécifiée.
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données manipulé. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Fichier](1514065.md).
`<Rubrique>` *Chaîne de caractères*
> Nom de la rubrique de type mémo binaire manipulée. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Rubrique](1514071.md).

## Remarques

La propriété **NbVignette** est disponible :

- en HFSQL Classic et en HFSQL Mobile : sur les rubriques d'un fichier de données, d'une vue ou d'une requête.
- en HFSQL Client/Serveur : sur les rubriques d'un fichier de données uniquement.

> _(Linux)_ La propriété NbVignette est disponible uniquement en HFSQL Client/Serveur sur les rubriques d'un fichier de données.
