# PoliceListe (Fonction)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Renvoie la liste des polices valides installées sur le poste en cours (TrueType, Postscript, ...).
> _(Java)_ Seules les polices supportées en Java sont listées.

## Exemple

```wlangage
// Liste des polices dans une fenêtre d'information
Info(PoliceListe())
// Liste des polices dans un champ Liste
ListeAjoute(LISTE_ListePolice, PoliceListe())
```

## Syntaxe

```wlangage
<Résultat> = PoliceListe([<Type de police>])
```

`<Résultat>` *Chaîne de caractères*
> Liste des polices sous la forme :
>
>
> ```wlangage
> <Police 1> + RC + ... + <Police N>
> ```
>
>
> Où <Police 1> .. <Police N> correspond au nom de la police.
`<Type de police>` *Constante optionnelle de type Entier*
> Type de police à lister :
>
>
> | *policeDéfaut* (Valeur par défaut) | Liste les polices du driver d'affichage. |
> | --- | --- |
> | *policeImprimante* | Liste les polices du driver d'impression. |
> | *policeParFamille* | Liste les familles de polices disponibles. Les familles de polices sont listées par ordre alphabétique. Les variantes de langues ne sont pas listées.  Remarque : Cette constante peut être combinée avec les constantes *policeDéfaut* et *policeImprimante*. |
>
>
>
> > _(Java)_ Ce paramètre n'est pas disponible. Seules les polices supportées en Java sont listées.

**Composante : wd300std.dll**
