# fFichierExiste (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Teste l'existence d'un fichier externe.
**Remarque** : Sous Windows 64 bits, l'accès à un répertoire système à partir d'un exécutable 32 bits peut être effectué dans un répertoire différent de celui attendu. Pour plus de détails, consultez la page d'aide [64 bits natif et 32 bits natif](2030048.md).

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Java, Code Utilisateur (MCU), PHP, Ajax)_ UnFichier est une chaîne
UnFichier = "C:\Temp\Exemple.txt"
SI fFichierExiste(UnFichier) = Vrai ALORS
 Info("Le fichier " + UnFichier + " existe bien sur le disque")
FIN

## Syntaxe

```wlangage
<Résultat> = fFichierExiste(<Nom du fichier>)
```

`<Résultat>` *Booléen*
> - Vrai si le fichier existe,
> - Faux sinon (par exemple si le nom du fichier correspond à un nom de répertoire).
`<Nom du fichier>` *Chaîne de caractères*
> Nom et chemin complet du fichier. Les caractères jokers (*, ?) ne sont pas utilisables. Pour utiliser les caractères jokers, la fonction [fRep](3036056.md) peut être utilisée. Si seul le nom du fichier est précisé (sans le chemin), le fichier est recherché dans le répertoire en cours (par exemple : fFichierExiste("Test.jpg"))
>
> > _(Windows, Linux)_ Ce paramètre peut être au format Ansi ou Unicode.
>
> > _(Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)_ Ce paramètre peut correspondre à un chemin complet ou relatif par rapport au répertoire en cours (connu avec la fonction fRepEnCours). Ce paramètre est sensible à la casse.

## Remarques

### Tester l'existence d'un répertoire
Pour tester l'existence d'un répertoire, utilisez la fonction [fRépertoireExiste](3036059.md).
