# ProcédureTrace (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **ProcédureTrace** permet de spécifier le nom de la procédure WLangage utilisée pour connaître les entêtes et les données envoyées. Cette propriété est utilisable sur :

- une variable de type [httpRequête](1000021158.md).
- une variable de type [restRequête](1000021481.md).
- Nouveauté 2025
   une variable de type [ftpConnexion](1410090869.md).
