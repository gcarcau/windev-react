# Constantes de gestion des données spatiales

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Les constantes de gestion des données spatiales sont les suivantes :

| Constante | Détail | Type de variable |
| --- | --- | --- |
| **tgInvalide** | Type de la géométrie en cours : Type invalide. Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfInvalide*. | Variable de type [Géométrie](1410090098.md) |
| **tgMultiGéométrie** | Type de la géométrie en cours : Ensemble de géométries. Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfMultiForme*. | Variable de type [Géométrie](1410090098.md), Variable de type [MultiGéométrie](1410090298.md) |
| **tgMultiPoint2D** | Type de la géométrie en cours : Type MultiPoint2D. Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfMultiPoint2D*. | Variable de type [Géométrie](1410090098.md), Variable de type [MultiPoint2D](1410090129.md) |
| **tgMultiPointGéo** | Type de la géométrie en cours : Type MultiPointGéo. Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfMultiPointGéo*. | Variable de type [Géométrie](1410090098.md), Variable de type [MultiPointGéo](1410090130.md) |

| **tgMultiPolyligne2D** | Type de la géométrie en cours : Type MultiPolyligne2D. Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfMultiPolyligne2D*. | Variable de type [Géométrie](1410090098.md), Variable de type [MultiPolyligne2D](1410090131.md) |
