# Fonctions de gestion des raccourcis d'application (app shortcuts)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Les fonctions permettant la gestion des raccourcis d'application (également appelés "apps shortcuts" ou "Action rapide") sont les suivantes :

| [ActionRapideAjoute](1410090053.md) | Ajoute une nouvelle action rapide à l'application. |
| --- | --- |
| [ActionRapideEpingle](1410090069.md) | Demande à épingler une action rapide. |
| [ActionRapideListe](1410090067.md) | Liste les actions rapides de l'application. |
| [ActionRapideSupprime](1410090064.md) | Supprime une action rapide de l'application. |
| [ActionRapideSupprimeTout](1410090068.md) | Supprime toutes les actions rapides de l'application. Les actions rapides épinglées sur l'écran d'accueil seront désactivées (mais pas supprimées). |
