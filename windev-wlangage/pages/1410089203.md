# TableurDéfusionneCellule (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

Supprime la fusion de cellule pour la cellule spécifiée ou pour la cellule sélectionnée dans un champ Tableur.

## Exemple

```wlangage
// Dé-fusionne la cellule B2
TableurDéfusionneCellule(TBLR_MonTableur, "B2")
```

## Syntaxe

```wlangage
TableurDéfusionneCellule(<Champ Tableur> [, <Cellule>])
```

`<Champ Tableur>` *Nom de champ*
> Nom du champ Tableur à manipuler.
`<Cellule>` *Chaîne de caractères optionnelle*
> Nom d'une des cellules de la plage de cellules à dé-fusionner. Ce paramètre est au format <Lettre de la colonne><Numéro de la ligne>. Par exemple : "A32".
> Si ce paramètre n'est pas précisé, la cellule sélectionnée dans le champ Tableur sera dé-fusionnée.
