# Fonctions diverses Windows

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions diverses Windows sont les suivantes :

| [API](3014005.md) | Exécute une fonction présente dans une DLL externe. |
| --- | --- |
| [APIParamètre](3014026.md) | Modifie les options d'appel de la fonction [API](3014005.md) et de la fonction [AppelDLL32](3014003.md). |
| [AppelDLL32](3014003.md) | Exécute une fonction présente dans une DLL externe. |
| [AppelInterface](1000017088.md) | Exécute une méthode d'une interface d'un objet implémenté dans une DLL externe au framework WINDEV. |
| [ChargeDLL](3014006.md) | Charge en mémoire la librairie (DLL) spécifiée. |
| [COMAppelleMéthode](1000018832.md) | Exécute une méthode d'une interface d'un objet COM instancié grâce à la fonction [COMCréeInstance](1000018831.md). |
| [COMCréeInstance](1000018831.md) | Instancie un objet COM (Component Object Model). |
| [COMRécupèreInterface](1000019784.md) | Appelle la méthode QueryInterface de l'objet COM spécifié pour obtenir une interface spécifique de cet objet afin de l'utiliser avec la fonction [COMAppelleMéthode](1000018832.md). |
| [ConstruitEntier](3062016.md) | Construit un entier de 4 octets à partir de deux entiers de 2 octets. |
| [CréeRaccourci](3014008.md) | Crée un raccourci sur le bureau de Windows, dans le menu "Démarrer" de Windows ou dans un répertoire spécifique. |
| [DéchargeDLL](3014009.md) | Décharge la librairie 32 bits (DLL) qui a été précédemment chargée en mémoire avec la fonction [ChargeDLL](3014006.md). |
| [EnvoieTouche](3014014.md) | Simule des manipulations de touches au clavier et à la souris. |
| [IBANValide](1410089019.md) | Teste la validité d'un IBAN (International Bank Acount Number). |
| [InstalleIcone](3014016.md) | Crée une icône (associée à un programme) dans un groupe de programme de Windows, avec la ligne de commande associée. |
| [Instance](3014019.md) | Renvoie le "Handle système" (HINSTANCE) du programme en cours. |
| [OpenSSLVérifie](1000020432.md) | Vérifie grâce à une clé publique que la signature de données réalisée avec la bibliothèque OpenSSL est correcte. |
| [Ping](3014013.md) | Teste si une adresse réseau est joignable en utilisant le protocole ICMP (équivalent de l'utilitaire réseau PING). |
| [PoidsFaible](3014018.md) | Renvoie les deux octets de poids faible d'un entier. |
| [PoidsFort](3014017.md) | Renvoie les deux octets de poids fort d'un entier. |
| [sCalculeCrc16](3062007.md) | Contrôle une chaîne de caractères avant et après transmission entre applications WINDEV / entre sites WEBDEV. |
| [sCalculeCrc32](3062015.md) | Calcule le code de redondance cyclique (CRC) d'un tampon. |
| [SupprimeRaccourci](3014012.md) | Supprime un raccourci précédemment créé avec la fonction [CréeRaccourci](3014008.md) sur le bureau de Windows, dans le menu "Démarrer" de Windows ou dans un répertoire spécifique. |
| [ToucheEnfoncée](3014007.md) | Vérifie quelle est la touche enfoncée. |
| [Transfert](3014015.md) | Copie un bloc d'octets ou une chaîne de taille fixe d'une adresse mémoire dans une autre. |
| [VersionWindows](3014002.md) | Renvoie le mode d'exécution de Windows. |

Il est également possible d'utiliser les types de variables suivants :

| [Description d'API](1000019149.md) | Une variable de type **Description d'API** permet de décrire par programmation une API, ses paramètres, sa valeur de retour et ses options d'appel. |
