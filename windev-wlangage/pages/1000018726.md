# Sujet (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **Sujet** permet de connaître et de modifier le sujet d'un élément.
Cette propriété est utilisable sur :

- la structure [Email](3032029.md).
- une variable de type [Email](1000018713.md).
- une variable de type [docPropriété](1000022945.md).
- une variable de type [JWTParamètres](1410089572.md).
