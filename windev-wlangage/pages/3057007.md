# Fonctions OLE

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

| [ObjetActif](3057006.md) | Permet d'utiliser un objet Automation déjà lancé sur le poste en cours. |
| --- | --- |
| [OLECharge](3057002.md) | Initialise un champ OLE avec un objet OLE. |
| [OLEColle](3057003.md) | Colle le contenu du presse-papiers de Windows dans un champ OLE. |
| [OLECopie](3057004.md) | Copie l'objet présent dans un champ OLE vers le presse-papiers de Windows. |
| [OLECréeCopie](3057005.md) | Associe un champ OLE à un objet OLE en précisant un fichier de base. |
| [OLECréeVide](3057001.md) | Associe un champ OLE à un objet OLE en invoquant un serveur OLE spécifique. |
| [OLEEdite](3057008.md) | Édite un objet OLE contenu dans un champ OLE. |
| [OLEJoue](3057009.md) | Permet :  - soit de récupérer la liste des opérations possibles (autres que l'édition) depuis un serveur, - soit d'effectuer une opération. |
| [OLESauve](3057011.md) | Sauve l'objet contenu dans un champ OLE sous forme binaire. |
| [OLEServeur](3057010.md) | Liste les serveurs OLE enregistrés auprès du système en cours. |

**Remarque** : Les fonctions OLE fonctionnent avec Office 2007.
