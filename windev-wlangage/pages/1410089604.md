# gpwListeUtilisateur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Récupère la liste des utilisateurs du groupware utilisateur.

## Exemple

```wlangage
TabUtilisateur est un tableau de gpwUtilisateur
UnUtilisateur est un gpwUtilisateur
TabUtilisateur = gpwListeUtilisateur()
SI ErreurDétectée ALORS
	ErreurInfo(errMessage)
SINON
	POUR TOUT UnUtilisateur DE TabUtilisateur
		Trace(UnUtilisateur.Login + "//" + UnUtilisateur.Nom + "//" + UnUtilisateur.Prénom)
	FIN
FIN
```

## Syntaxe

```wlangage
<Utilisateurs> = gpwListeUtilisateur()
```

`<Utilisateurs>` *Tableau WLangage*
> Tableau de variables de type [gpwUtilisateur](1000021088.md) correspondant aux utilisateurs du groupware utilisateur.
> En cas d'erreur (aucune connexion par exemple), la variable [ErreurDétectée](3087001.md) est à Vrai et la fonction [ErreurInfo](3013008.md) permet de connaître le détail de l'erreur.
> **Remarque** : Les informations récupérées sont différentes si l'utilisateur actuellement connecté est superviseur ou simple utilisateur. Si l'utilisateur n'est pas un superviseur, seules les propriétés **Login** et **Activé** de la variable [gpwUtilisateur](1000021088.md) sont disponibles.

**Composante : wd300gpu.dll**
