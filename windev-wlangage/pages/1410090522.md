# <Variable Polygone2D>.Contient (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Permet de savoir si une géométrie A de type polygone en 2 dimensions contient une géométrie B.
**Remarques** :

- Si la géométrie A contient la géométrie B, cela signifie que la géométrie B est complètement dans la géométrie A. Dans ce cas :
  - Il n'existe pas de point de la géométrie B dans l'extérieur de la géométrie A : tout point de la géométrie B est soit dans l'intérieur de la géométrie A, soit dans son contour.
  - Il existe au moins un point de l'intérieur de la géométrie B dans l'intérieur de la géométrie A.
- Différence par rapport à la fonction [<Variable Polygone2D>.Couvre](1410090526.md) : Avec la fonction [<Variable Polygone2D>.Couvre](1410090526.md), il n'est pas nécessaire d'avoir un point de l'intérieur de géométrie B à l'intérieur de géométrie A. Un polygone couvre son contour, mais il ne le contient pas.

## Exemple

```wlangage
oPolygone2D_1 est un Polygone2D
oPolygone2D_1.Contour.AjoutePoint(-4.00, -4.00)
oPolygone2D_1.Contour.AjoutePoint(-4.00, 2.00)
oPolygone2D_1.Contour.AjoutePoint(5.00, 2.00)
oPolygone2D_1.Contour.AjoutePoint(5.00, -4.00)
// Ajout du dernier point (identique au premier)
oPolygone2D_1.Contour.AjoutePoint(-4.00, -4.00)

oPolygone2D_2 est un Polygone2D
oPolygone2D_2.Contour.AjoutePoint(-1.00, -2.00)
oPolygone2D_2.Contour.AjoutePoint(2.00, 0.00)
oPolygone2D_2.Contour.AjoutePoint(2.00, -2.00)
// Ajout du dernier point (identique au premier)
oPolygone2D_2.Contour.AjoutePoint(-1.00, -2.00)

soit p2_dans_p1 = oPolygone2D_1.Contient(oPolygone2D_2) // Renvoie "vrai"
oPolygone2D_2.EstContenu(oPolygone2D_1) // Renvoie "vrai"
```

## Syntaxe

```wlangage
<Résultat> = <Géométrie A>.Contient(<Géométrie B>)
```

`<Résultat>` *Booléen*
> - Vrai si la géométrie A contient la géométrie B,
> - Faux dans le cas contraire.
>
> En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Géométrie A>` *Variable de type Polygone2D*
> Nom de la variable de type [Polygone2D](1410090122.md) à manipuler.
`<Géométrie B>` *Variable correspondant à des données spatiales*
> Nom de la variable correspondant à la seconde géométrie manipulée. Cette géométrie peut correspondre à un des types de variables suivants :
>
> - [PointGéo](1410090102.md).
> - [Point2D](1410090100.md).
> - [PolyligneGéo](1410090128.md).
> - [Polyligne2D](1410090109.md).
> - [PolygoneGéo](1410090127.md).
> - [Polygone2D](1410090122.md).
> - [MultiPointGéo](1410090130.md).
> - [MultiPoint2D](1410090129.md).
> - [MultiPolyligneGéo](1410090133.md).
> - [MultiPolyligne2D](1410090131.md).
> - [MultiPolygoneGéo](1410090136.md).
> - [MultiPolygone2D](1410090135.md).

## Remarques

### Parcours des données spatiales : utilisation des index spatiaux
Il est possible d'effectuer un parcours sur un fichier de données avec un filtre concernant des données spatiales. Par exemple, le filtre utilisé peut être basé sur le résultat de la fonction **<Variable Polygone2D>.Contient**.
Pour optimiser ce filtre sur des données spatiales, il est recommandé d'utiliser les index spatiaux via la syntaxe suivante :

```wlangage
POUR TOUT Fichier AVEC Fonction_WLangage(Fichier.Rubrique_spatiale, Variable_spatiale)
```

où :

- Fonction_WLangage correspond à la fonction **<Variable Polygone2D>.Contient**.
- Rubrique_spatiale correspond à une rubrique spatiale du fichier de données. Cette rubrique doit :
  - être de type "Données géographiques" ou de type "Données géométriques".
  - être définie comme une "Clé spatiale".
- Variable_spatiale correspond à une variable spatiale donnée, utilisée pour la comparaison avec la rubrique spatiale. Cette variable est par exemple, une variable de type PolygoneGéo, Polygone2D, etc.

Remarque : Bien que disponible, la syntaxe "POUR TOUT Fichier" n'est pas recommandée car cette syntaxe n'utilisant pas les index spatiaux, ses performances ne sont pas optimisées. En effet, dans ce cas, tout le fichier de données est parcouru : les index spatiaux ne sont pas utilisés.

```wlangage
POUR TOUT Fichier  SI Fonction_WLangage(Fichier.Rubrique_spatiale, Variable_spatiale) = Vrai ALORS    ...    FINFIN
```
