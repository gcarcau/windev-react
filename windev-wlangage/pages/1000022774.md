# <Variable Connexion>.InfoBlocage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Renvoie des informations sur le blocage d'un fichier de données, d'un enregistrement ou de tous les enregistrements d'un fichier de données.

## Exemple

```wlangage
ConnexionCS est une Connexion
ListeLock est une chaîne
...
// Liste tous les blocages des fichiers de données de la connexion ConnexionCS
ListeLock = ConnexionCS.InfoBlocage()
// Liste tous les blocages du fichier de données Client.fic de la connexion ConnexionCS
ListeLock = ConnexionCS.InfoBlocage(".\client.fic")
```

#### Informations de blocage sur un fichier de données identifié par sa connexion

```wlangage
<Résultat> = <Connexion>.InfoBlocage([<Chemin du fichier de données>] [, <Numéro d'enregistrement>])
```

`<Résultat>` *Chaîne de caractères*
> Nom du fichier de données utilisé.
`<Connexion>` *Nom de champ*
> Numéro de l'enregistrement pour lequel des informations de blocage sont demandées.
> Si ce paramètre n'est pas spécifié, la fonction **<Variable Connexion>.InfoBlocage** liste tous les blocages du fichier de données.
`<Chemin du fichier de données>` *Chaîne de caractères optionnelle*
> Chemin complet du fichier de données, relatif à la base de données définie par le paramètre <Connexion>.
> Si le paramètre <Connexion> correspond au nom logique d'un fichier de données, ce paramètre est ignoré.
> Si ce paramètre n'est pas précisé, tous les blocages de tous les fichiers de données de la base de données sont renvoyés.
`<Numéro d'enregistrement>` *Entier optionnel*
> Numéro de l'enregistrement pour lequel des informations de blocage sont demandées.
> Si ce paramètre n'est pas spécifié, la fonction **<Variable Connexion>.InfoBlocage** liste tous les blocages du fichier de données.
