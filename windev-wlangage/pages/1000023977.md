# Jeton

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Le mot-clé **Jeton** peut correspondre :

- à la propriété [Jeton](1000023976.md) qui permet de manipuler les différents jetons associés à un champ de saisie de type "Texte avec jetons".
- à une variable de type [Jeton](1000023942.md) qui permet de manipuler un jeton associé à un champ de saisie de type "Texte avec jetons".
