# <Variable Diagramme>.FinModification (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Signale la fin du regroupement d'un ensemble d'opérations sur une variable de type [Diagramme](1410088055.md) en un seul événement (gestion du "undo/redo").

## Exemple

```wlangage
MonDiagramme est un Diagramme <- EDIAG_MonDiagramme
MaSélection est un diagSélection <- EDIAG_MonDiagramme.Sélection
MonDiagramme.DébutModification()
MaSélection.Fond.Couleur = Blanc
MaSélection.Bordure.Couleur = Noir
MonDiagramme.FinModification()
```

## Syntaxe

```wlangage
<Diagramme>.FinModification()
```

`<Diagramme>` *Variable de type Diagramme*
> Nom de la variable de type [Diagramme](1410088055.md) à manipuler.

## Remarques

Toutes les modifications effectuées entre la fonction [<Variable Diagramme>.DébutModification](1410088877.md) et la fonction **<Variable Diagramme>.FinModification** sont regroupées en une seule opération annulable par un "undo/redo").
