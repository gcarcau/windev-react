# LDAPRenommeAttribut (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **Autres** (Procédures stockées)

Renomme un attribut. Lors de ce renommage, la valeur des attributs est conservée.

## Exemple

```wlangage
// Renomme l'attribut "NomAttribut" en "Nom2"
LDAPDébutModification("NomSession")
LDAPRenommeAttribut("NomSession", "NomAttribut", "Nom2")
LDAPValideModification("NomSession", "DN")
```

## Syntaxe

```wlangage
<Résultat> = LDAPRenommeAttribut(<Session LDAP> , <Ancien nom de l'attribut> , <Nouveau nom de l'attribut>)
```

`<Résultat>` *Booléen*
> - Vrai si la modification a été effectuée,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de détails sur l'erreur.
>
> La modification effective ne sera réalisée que lors de l'appel de la fonction [LDAPValideModification](3032117.md).
`<Session LDAP>` *Chaîne de caractères*
> Nom de la session LDAP manipulée.
`<Ancien nom de l'attribut>` *Chaîne de caractères*
> Nom actuel de l'attribut à manipuler.
`<Nouveau nom de l'attribut>` *Chaîne de caractères*
> Nouveau nom de l'attribut à utiliser.

## Remarques

### Renommage
Le nouveau nom de l'attribut doit être un attribut valide pour l'objet modifié.
Si le renommage concerne un attribut multi-valué, le nouveau nom doit correspondre à un attribut valide et multi-valué. Dans le cas contraire, une erreur sera rencontrée avec la fonction [LDAPValideModification](3032117.md).

### Modifier un objet existant sur un serveur LDAP
Pour modifier un objet existant dans un serveur LDAP, il est nécessaire de définir les différentes modifications à effectuer.
Pour optimiser la vitesse de modification des objets, les modifications effectuées sont définies localement : une seule communication avec le serveur est établie lors de la validation de la modification. Les étapes sont les suivantes :

1. Initialisation de la modification (fonction [LDAPDébutModification](3032112.md)).
2. Opérations de modification :
  - Ajout des attributs et de leurs valeurs (fonction [LDAPAjouteAttribut](3032110.md)).
  - Suppression des attributs (fonction [LDAPSupprimeAttribut](3032115.md)) ou de leurs valeurs (fonction [LDAPSupprimeValeurAttribut](3032116.md)).
  - Remplacement des valeurs d'un attribut (fonction [LDAPRemplaceAttribut](3032113.md) ou [LDAPRemplaceValeurAttribut](3032119.md)).
  - Renommage de l'attribut (fonction **LDAPRenommeAttribut**)
3. Validation des modifications sur le serveur (fonction [LDAPValideModification](3032117.md)). Les modifications sont effectuées sur le serveur en suivant l'ordre utilisé dans le code WLangage.
