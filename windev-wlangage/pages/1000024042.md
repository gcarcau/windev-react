# Fonctions de gestion des jetons

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des jetons (syntaxe préfixée)](1000024048.md)).
Les fonctions de gestion des jetons dans les champs de saisie sont les suivantes :

| [SaisieAjouteJeton](1000023953.md) | Ajoute un jeton dans un champ de saisie de type "Jetons de texte". |
| --- | --- |
| [SaisieInsèreJeton](1000023954.md) | Insère un jeton dans un champ de saisie de type "Jetons de texte". |
| [SaisieOccurrenceJeton](1000023955.md) | Renvoie le nombre de jetons présents dans un champ de saisie de type "Jetons de texte". |
| [SaisieSupprimeJeton](1000023956.md) | Supprime un jeton dans un champ de saisie de type "Jetons de texte". |
| [SaisieSupprimeToutJeton](1000023957.md) | Supprime tous les jetons d'un champ de saisie de type "Jetons de texte". |
