# FichierOrigine (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **FichierOrigine** permet de connaître le nom original du fichier de données associé à une rubrique présente dans une requête. Ce nom est connu à partir de l'alias de cette rubrique.
**Remarque** : La propriété [RubriqueOrigine](2512079.md) permet de connaître le nom original d'une rubrique présente dans une requête. Ce nom est connu à partir de l'alias de cette rubrique.

## Exemple

```wlangage
RequêteExemple est une Source de Données
HExécuteRequêteSQL("RequêteExemple", "SELECT Client.NomCli AS MonSuperClient FROM Client")
Trace(RequêteExemple.MonSuperClient.FichierOrigine) // Client
Trace(RequêteExemple.MonSuperClient.RubriqueOrigine) // NomCli
```

## Syntaxe

```wlangage
<Résultat> = <Requête>.<Alias de la rubrique>.FichierOrigine
```

`<Résultat>` *Chaîne de caractères*
> - Nom du fichier de données associé à la rubrique,
> - Chaîne vide ("") si la rubrique est un agrégat ou correspond à un compteur.
`<Requête>` *Chaîne de caractères*
> Nom de la requête contenant la rubrique. Ce paramètre peut également correspondre à un nom de fichier de données HFSQL, un nom de vue HFSQL, ...
`<Alias de la rubrique>` *Chaîne de caractères*
> Nom de la rubrique dans le résultat de la requête (ou dans le fichier de données, la vue, ...).
