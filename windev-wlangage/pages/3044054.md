# HFermeAnalyse (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Ferme l'analyse en cours (ou toutes les analyses en cours dans le cas d'un projet multi-analyse).
Tous les fichiers de données, vues HFSQL et requêtes actuellement ouverts sont fermés et libérés. Après l'exécution de la fonction **HFermeAnalyse**, aucune analyse n'est en cours.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax, HFSQL Classic)_ // Ouvre une analyse
HOuvreAnalyse("C:\Gestcom\Gestcom.WDD")
// Traitements
...
// Ferme l'analyse actuellement utilisée par l'application
HFermeAnalyse()

## Syntaxe

```wlangage
<Résultat> = HFermeAnalyse()
```

`<Résultat>` *Booléen*
> - Vrai si l'analyse a été fermée,
> - Faux en cas de problème : l'analyse n'est pas fermée. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.

## Remarques

- Un projet peut être associé à une ou plusieurs analyses (projets multi-analyses).
- La fonctions **HFermeAnalyse** permet de fermer :
  - les analyses ouvertes avec la fonction [HOuvreAnalyse](3044106.md).
  - les analyses ouvertes avec la fonction [HOuvreAnalyseComplémentaire](1410090082.md).
- Si aucune analyse n'est en cours, la fonction **HFermeAnalyse** n'a aucun effet.
