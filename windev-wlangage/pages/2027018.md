# Le volet "Centre de Contrôle Qualité"

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Le volet "Centre de Contrôle Qualité" affiche les différents incidents associés au projet sélectionné.
Le menu contextuel (clic droit) du volet "Centre de Contrôle Qualité" permet de :

- Ajouter un incident.
- Modifier un incident.
- Corriger un incident.
- Réattribuer un incident.
- Lier une tâche à l'incident.

Pour plus de détails, consultez [Centre de Gestion de Projets : Gestion des incidents](3540723.md).

## Afficher le volet "Centre de Contrôle Qualité"

**Pour afficher le volet "Centre de Contrôle Qualité"**, sous le volet "Accueil", dans le groupe "Environnement", déroulez "Volets" et sélectionnez "Volets" puis "Centre de Contrôle Qualité".
Pour plus de détails sur les manipulations des volets, consultez [Manipuler les volets ancrables](2027001.md).
