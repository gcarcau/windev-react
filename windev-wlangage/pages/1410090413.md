# <Editeur de code>.Compile (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Compile le code WLangage affiché dans le champ Editeur de code et affiche les potentielles erreurs.

## Exemple

```wlangage
// Compile le code présent dans le champ Editeur de code
// et affiche les erreurs potentielles directement dans le champ
bResult est un booléen = EDCODE_Exemple.Compile()
SI bResult = Vrai ALORS
	ToastAffiche("Bravo ! Votre code compile parfaitement !")
SINON
	ToastAffiche("Encore quelques petites erreurs à corriger. Vous y êtes presque !")
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Champ Editeur de code>.Compile()
```

`<Résultat>` *Booléen*
> - Vrai si le code WLangage affiché dans l'éditeur de code compile correctement,
> - Faux dans le cas contraire.
`<Champ Editeur de code>` *Nom de champ*
> Nom du champ Editeur de code à manipuler.

**Classification Métier / UI : Code UI**

**Composante : wd300obj.dll**
