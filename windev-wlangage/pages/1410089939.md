# LongueurMinimale (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **LongueurMinimale** permet de connaître et de modifier la longueur minimale d'un élément. Cette propriété est utilisable sur :

- une description d'un index full-text. Pour plus de détails, consultez [LongueurMinimale](1000017716.md).
- une variable de type [FormatNumérique](1410089836.md).
