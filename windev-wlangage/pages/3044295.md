# HSupprimeGroupe (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Supprime un groupe d'utilisateurs associé à une connexion, sur le serveur.

## Exemple

```wlangage
// Description de la connexion
HDécritConnexion("MaConnexion", "Julie", "MotDePasse", "MonServeurHF", ...
		"MaBaseDeDonnées", hAccèsHFClientServeur, hOLecture)
// Ouverture de la connexion
HOuvreConnexion("MaConnexion")
// Association du fichier de données à la connexion
HChangeConnexion(Client, "MaConnexion")
...
SI HSupprimeGroupe("MaConnexion", "Util1") = Vrai ALORS
	Info("Groupe Util1 supprimé")
FIN
```

## Syntaxe

```wlangage
<Résultat> = HSupprimeGroupe(<Connexion> , <Groupe>)
```

`<Résultat>` *Booléen*
> - Vrai si le groupe a été supprimé,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
>
>
> Remarque : Une erreur "Groupe inconnu" sera renvoyée par la fonction [HErreurInfo](3044071.md) si l'utilisateur en cours n'a pas le droit de visualisation des utilisateurs (constante *hDroitVisualisationUtilisateur*) et s'il demande la suppression d'un autre groupe.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion pour laquelle un groupe doit être supprimé. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Groupe>` *Chaîne de caractères*
> Nom du groupe à supprimer.
