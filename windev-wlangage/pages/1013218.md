# Le champ Image

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

## Présentation du champ Image

### Champ d'une fenêtre, d'une page, d'un état
Le champ Image permet de :

- Afficher des images statiques ou animées dans vos applications.
- Dessiner.
- Afficher des graphes réalisés avec le grapheur. Cependant, il est conseillé d'utiliser un [champ Graphe](1013006.md).
- Exécuter des traitements spécifiques lors d'un clic de l'utilisateur sur l'image (équivalent aux zones de cliquages de WINDEV 5.5).
- Afficher des vidéos grâce [aux fonctions MCI](3051010.md).
- [Afficher des fichiers PDF](9500147.md).
   Cette fonctionnalité nécessite le [framework GDI+](2020007.md).
- [Faire défiler les images](9500118.md).
- [Gérer le multi-touch](9500131.md).
- [Zoomer automatiquement les images](9500127.md).

## Créer un champ Image

### Dans une fenêtre ou une page
Pour créer un champ de type Image dans une fenêtre ou dans une page :

1. Sous le volet "Création", dans le groupe "Champs usuels", cliquez sur "Image".
2. Cliquez dans la fenêtre ou la page à la position où le champ doit être créé. Le champ apparaît en création.

**Pour afficher les caractéristiques du champ**, sélectionnez l'option "Description" dans le menu contextuel du champ. Les principales options disponibles sont présentées :

- dans la page [Champ Image dans une fenêtre](9500147.md).
- dans la page [Champ Image dans une page](9500148.md).

**Pour éditer l'image présente dans un champ Image**, utilisez l'option "Editer l'image" du menu contextuel. L'éditeur d'images se lance automatiquement. Pour plus de détails, consultez [Editeur d'images](1410086603.md).

## Images multilingues

Si votre application est multilingue, il est possible de sélectionner une image différente pour chaque langue. Cette option est intéressante par exemple lorsque les images contiennent du texte.
Pour gérer des images multilingues :

1. Affichez la description du champ Image, onglet "Général".
2. Cliquez sur le bouton , option "Multilingue". La fenêtre de gestion des images multilingues apparaît. Par défaut, le même fichier est associé à toutes les langues gérées par la fenêtre, la page ou l'état.
3. Pour chaque langue, cliquez sur le bouton , option "Parcourir" et sélectionnez l'image correspondant à la langue. En exécution, en fonction de la langue choisie par la fonction [Nation](3054014.md), l'image correspondante sera affichée.

**Attention** : Seuls les fichiers image sont gérés par le multilingue et non les caractéristiques d'affichage de l'image.

**Remarque** : Si une image multilingue a été définie, le message "<Valeur Multilingue>" apparaît dans la zone correspondant au nom du fichier image dans la fenêtre de description du champ Image.
