# rssCatégorie (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

Le type **rssCatégorie** permet de manipuler la catégorie d'un flux RSS ou d'une entrée de flux. Les caractéristiques de ce type de variable peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
Ce type de variable est utilisé par :

- [le type rssFlux](1000017795.md).
- [le type rssEntrée](1000017792.md).

**Notes** :

- Le plus souvent, la déclaration d'une variable de type **rssCatégorie** n'est pas nécessaire. En effet, les propriétés du [type rssFlux](1000017795.md) ou du [type rssEntrée](1000017792.md) permettent de manipuler directement les propriétés du type **rssCatégorie** (notamment la propriété **Catégorie**).
- Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Remarques

### Propriétés spécifiques à la description des variables de type rssCatégorie
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **rssCatégorie** :

| Nom | Type manipulé | Effet |
| --- | --- | --- |
| Domaine | Chaîne de caractères | URL qui décrit le domaine sur lequel s'applique la catégorie. |
| Valeur | Chaîne de caractères | Valeur arbitraire décrivant la catégorie de l'entrée. Cette valeur est utilisée par les programmes qui agrègent des flux XML. |
