# TâchePrécédent (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **Autres** (Procédures stockées)

Lit la tâche précédente de la tâche en cours dans la liste des tâches d'une messagerie Lotus Notes ou Outlook. Cette tâche devient la tâche en cours.
Lors de la lecture d'une tâche, les données de cette tâche sont mises à jour dans la [structure Tâche](1000012010.md). Pour récupérer les données de la tâche en cours, il suffit de récupérer les valeurs de la [structure Tâche](1000012010.md).

**Attention** : Cette fonction **ne permet pas** de lire la tâche précédente de la tâche en cours dans la liste des tâches d'une messagerie Outlook Express.

## Exemple

```wlangage
// Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", "mail\julie.nsf",...
					"C:\Users\Julie\AppData\Local\Lotus\Notes\Data\user.id")

// Lecture de la dernière tâche
TâcheDernier(IDSession)
// Ajout des tâches trouvées dans une liste
TANTQUE mTâche.EnDehors = Faux
	ListeAjoute(LISTE_ListeTâche, mTâche.Objet + TAB + mTâche.Catégorie)
	TâchePrécédent(IDSession)
FIN
```

## Syntaxe

```wlangage
<Résultat> = TâchePrécédent(<Identifiant de la session>)
```

`<Résultat>` *Booléen*
> - Vrai si la tâche précédente a été lue,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Identifiant de la session>` *Entier*
> Identifiant de la session à utiliser. Cet identifiant est renvoyé par une des fonctions suivantes : [EmailOuvreSessionNotes](3032121.md), [EmailOuvreSessionOutlook](3032128.md), [NotesOuvreBase](1000005101.md) ou [OutlookOuvreSession](3032123.md).

## Remarques

### Tâche en cours
La variable mTâche.EnDehors permet de savoir s'il y a une tâche courante.

**Composante : wd300com.dll**
