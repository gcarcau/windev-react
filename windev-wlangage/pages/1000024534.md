# <Variable Document>.Redo (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Rétablit la dernière action annulée sur un document de type [Document](1000022461.md).

## Exemple

```wlangage
MonDocument est un Document

// Refait la dernière action annulée sur le document
MonDocument.Redo()
```

## Syntaxe

```wlangage
<Résultat> = <Document>.Redo()
```

`<Résultat>` *Booléen*
> - Vrai si la dernière action annulée a été rétablie,
> - Faux dans le cas contraire.
`<Document>` *Variable de type Document*
> Nom de la variable de type [Document](1000022461.md) à manipuler.

**Composante : wd300mdl.dll**
