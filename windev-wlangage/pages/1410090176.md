# VisiteGuidéeDémarre (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Démarre une visite guidée et affiche la première étape.

## Exemple

```wlangage
MaVisiteDécouverte est un VisiteGuidée
// ...
// Démarrage de la visite guidée
VisiteGuidéeDémarre(MaVisiteDécouverte)
```

## Syntaxe

```wlangage
VisiteGuidéeDémarre(<Visite guidée> [, <Etape à afficher>])
```

`<Visite guidée>` *Variable de type VisiteGuidée*
> Nom de la variable de type [VisiteGuidée](1410090170.md) correspondant à la visite guidée qui doit être démarrée.
`<Etape à afficher>` *Entier optionnel*
> Numéro de l'étape de la visite guidée à afficher. Par défaut, l'étape 1 est affichée.

**Classification Métier / UI : Code UI**

**Composante : wd300mdl.dll**
