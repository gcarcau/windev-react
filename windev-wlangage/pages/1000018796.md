# UploadTailleEnvoyéeFichierEnCours (Fonction)

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur)

Renvoie la taille (en octets) déjà envoyée du fichier en cours d'upload via un champ Upload.

## Exemple

```wlangage
// -- Evénement "Progression du transfert"
// Affiche la taille totale du fichier en Ko
LIB_TailleEnvoyéeFichier = Arrondi(UploadTailleFichierEnCours(MoiMême) / 1024, 0) + "Ko"
```

## Syntaxe

```wlangage
<Résultat> = UploadTailleEnvoyéeFichierEnCours(<Champ Upload>)
```

`<Résultat>` *Entier*
> Taille déjà envoyée du fichier en cours d'upload.
`<Champ Upload>` *Nom de champ*
> Nom du champ Upload à manipuler.

## Remarques

### Dans quel événement utiliser cette fonction ?
La fonction **UploadTailleEnvoyéeFichierEnCours** peut être utilisée uniquement dans l'événement navigateur "Progression du transfert". Cet événement est associé :

- soit au bouton "Envoyer" pour un champ Upload monofichier.
- soit au bouton "Ajouter" pour un champ Upload multifichier.

Utilisée dans un autre événement, la fonction **UploadTailleEnvoyéeFichierEnCours** renverra 0.

### Taille maximale des fichiers à uploader
**Par défaut,** la taille des fichiers à uploader est illimitée dans le moteur WEBDEV. Cette taille peut être limitée par le serveur d'application WEBDEV.
Si le fichier à uploader dépasse la taille limite, le fichier n'est pas uploadé.
Pour modifier la taille maximale des fichiers à uploader dans le serveur d'application WEBDEV, il est nécessaire de modifier la base de registre sur le serveur :

1. Pour modifier la taille des fichiers uploadés pour toutes les applications WEBDEV 2025, sélectionnez la clé suivante :
  - sur une machine 32 bits : HKEY_LOCAL_MACHINE\SOFTWARE\PC SOFT\WEBDEV\30.0
  - sur une machine 64 bits : HKEY_LOCAL_MACHINE\SOFTWARE\WOW6432Node\PC SOFT\WEBDEV\30.0
2. Ajoutez la chaîne MAX_UPLOAD. Cette chaîne aura pour valeur la taille maximale des fichiers à uploader (en Ko).
