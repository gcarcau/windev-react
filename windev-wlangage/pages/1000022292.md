# <Fenêtre>.EdCharge (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Charge :

- les modifications faites par l'utilisateur final dans une fenêtre. Ces modifications ont été préalablement sauvegardées en mémoire ou dans un fichier.
- les notes créées par l'utilisateur finale dans une fenêtre.

Remarque : Cette fonction peut être utilisée lorsque le mode "Modification de l'UI par l'utilisateur final" est autorisé pour les fenêtres de l'application.

## Exemple

```wlangage
// Clic sur [Sauver]
FEN_Présentation.EdSauve("Mes modifications.wdmodif")

// Clic sur [Charger]
FEN_Présentation.EdCharge("Mes modifications.wdmodif")
SI ErreurDétectée = Vrai ALORS
	Info("Chargement impossible" + RC + ErreurInfo())
FIN
```

## Syntaxe

#### Charger les modifications enregistrées dans un buffer

```wlangage
<Résultat> = <Fenêtre>.EdCharge(<Buffer>)
```

`<Résultat>` *Booléen*
> - Vrai si les modifications ont été chargées,
> - Faux en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Fenêtre>` *Nom de fenêtre*
> Nom de la fenêtre ou de la fenêtre interne à manipuler.
`<Buffer>` *Variable de type Buffer*
> Buffer contenant les modifications (les modifications ont été précédemment enregistrées avec la fonction [<Fenêtre>.EdSauve](1000022330.md)).

#### Charger les modifications enregistrées dans un fichier

```wlangage
<Résultat> = <Fenêtre>.EdCharge(<Fichier>)
```

`<Résultat>` *Booléen*
> - Vrai si les modifications ont été chargées,
> - Faux en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Fenêtre>` *Nom de fenêtre*
> Nom de la fenêtre ou de la fenêtre interne à manipuler.
`<Fichier>` *Chaîne de caractères*
> - Nom et chemin complet ou relatif du fichier ".wdmodif" contenant les modifications effectuées (les modifications ont été précédemment enregistrées avec la fonction [<Fenêtre>.EdSauve](1000022330.md)).
> - Nom et chemin complet ou relatif du fichier ".wdnote" contenant les notes créées par l'utilisateur (les notes ont été précédemment enregistrées avec la fonction [FenEdSauveNote](1000022120.md)).
