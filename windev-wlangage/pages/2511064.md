# HauteurPixel (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **HauteurPixel** permet de connaître la hauteur d'un champ d'un état en pixels.
**Remarque** : Le cadre du champ est compris dans sa hauteur. La propriété [Hauteur](2510050.md) permet de connaître et de modifier la hauteur d'un champ en millimètres.

## Exemple

```wlangage
// Connaître la hauteur du champ "RUB_NomClient"
ResHauteur = RUB_NomClient.HauteurPixel
```

## Syntaxe

```wlangage
<Résultat> = <Champ manipulé>.HauteurPixel
```

`<Résultat>` *Réel*
> Hauteur (en pixels) du champ spécifié.
`<Champ manipulé>` *Nom de champ*
> Nom du champ de l'état à manipuler.

## Remarques

### Hauteur
Un champ doit être entièrement contenu dans le bloc auquel il appartient.

### Limites
La propriété **HauteurPixel** ne peut pas être utilisée sur :

- un état dans son ensemble,
- un bloc de l'état,
- un groupe de champs,
- un champ Interrupteur,
- un champ de saisie,
- un champ Agenda,
- un champ Planning,
- un champ Diagramme de Gantt,
- un champ Signature.
