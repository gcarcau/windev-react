# TableSaisieEnCours (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Indique si un champ Table ou Table hiérarchique est en cours de saisie.
**Remarque** : Si l'utilisateur utilise le mode Recherche dans l'entête de colonne (loupe), le champ Table ou Table hiérarchique est considéré en cours de saisie.

## Exemple

```wlangage
// Si l'utilisateur n'est pas en train de saisir dans le champ
SI TableSaisieEnCours(TABLE_TABLE1) = Faux ALORS
	// Met à jour le champ Table
	TableAffiche(TABLE_TABLE1)
FIN
```

## Syntaxe

```wlangage
<Résultat> = TableSaisieEnCours(<Champ Table>)
```

`<Résultat>` *Booléen*
> - Vrai si le champ est en cours de saisie (c'est-à-dire si l'utilisateur est en train de saisir des informations dans le champ),
> - Faux dans le cas contraire.
`<Champ Table>` *Nom de champ*
> Nom du champ à manipuler. Ce champ peut correspondre à :
>
> - un champ Table.
> - un champ Table hiérarchique.
>    Les champs Table hiérarchique ne sont pas disponibles.

## Remarques

### Conditions d'utilisation
Cette fonction est disponible sur :

- un champ Table ou Table hiérarchique fichier.
- un champ Table ou Table hiérarchique par programmation.

> _(WEBDEV - Code Serveur)_ Cette fonction est disponible pour les champs Table en mode "Serveur + AJAX" et les champs Table hiérarchique.

> _(WEBDEV - Code Navigateur)_ Cette fonction est disponible uniquement pour les champs Table en mode "Navigateur".

> _(WEBDEV - Code Navigateur)_ Le champ Table hiérarchique n'est pas disponible.
