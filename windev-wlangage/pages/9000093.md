# Programmation par action prédéfinie

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

La programmation par action prédéfinie permet de décrire le code correspondant à un événement d'un seul clic, sans avoir à saisir des lignes de code, simplement en sélectionnant l'action à exécuter dans une liste.
Par exemple, sous WINDEV :

Les actions prédéfinies sont proposées :

- sur les champs Bouton (dans l'événement "Clic").
- sur les options de menu.
- sur les champs Lien (dans l'événement "Clic (serveur)").

## Comment le faire ?

### Définir une action prédéfinie
Pour définir une action prédéfinie :

1. Affichez la fenêtre de description du champ (option "Description" du menu contextuel).
2. Dans l'onglet "Général", définissez l'action à effectuer :
  1. Sélectionnez l'action à exécuter dans la combo "Action".
    Toutes les actions les plus courantes sont proposées dans cette liste. Pour sélectionner une action plus spécifique, cliquez sur le bouton "Toutes les actions" ou "Autres actions".
  2. Sélectionnez l'action à exécuter dans la combo "Type" (zone "Action du bouton").
    Toutes les actions les plus courantes sont proposées dans cette liste. Pour sélectionner une action plus spécifique, cliquez sur le lien "Plus de choix".

Les différentes actions proposées dépendent des éléments présents dans le projet en cours (fenêtres, pages, composant, procédure, ...).
> _(WINDEV, WINDEV Mobile)_ Remarque : Pour choisir l'action prédéfinie, il est également possible de sélectionner l'option "Action prédéfinie..." du menu contextuel du champ.

## Note

### Information affichée sous l'éditeur de code
Lorsqu'une action prédéfinie est utilisée, une information indiquant cette action prédéfinie est spécifiée sous l'éditeur de code.
Par exemple :

[image: Action prédéfinie dans le code]

Le clic sur l'action prédéfinie affichée dans l'éditeur de code affiche :

- la fenêtre de sélection des actions prédéfinies.
- la fenêtre de description du champ.

Il est ainsi possible de modifier l'action prédéfinie directement depuis l'éditeur de code.
**Attention** : Tout code WLangage saisi sous l'éditeur de code en dessous de l'appel à l'action prédéfinie ne sera pas exécuté.

> _(WINDEV, Android, Java)_ Pour inclure une action prédéfinie dans du code WLangage, utilisez la fonction ExécuteActionPrédéfinie.

> _(WINDEV, Android, Java)_ Exécuter une action prédéfinie par programmationWINDEV propose également d'exécuter une action prédéfinie en utilisant la fonction ExécuteActionPrédéfinie.
