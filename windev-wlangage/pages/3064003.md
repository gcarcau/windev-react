# Fonctions de gestion des projets

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

Ces fonctions permettent de manipuler facilement des éléments d'un projet WINDEV :
| [ComposantCharge](3014023.md) | Charge un composant externe. Ce composant peut être :  - un composant externe présent dans le projet en cours. - un composant externe indépendant du projet en cours. |
| --- | --- |
| [ComposantChargeTout](1000018926.md) | Charge en mémoire de manière récursive tous les composants externes utilisés dans le projet. |
| [ComposantExécute](1410089107.md) | Exécute une procédure globale présente dans un composant externe. Ce composant externe a été précédemment chargé par la fonction [ComposantCharge](3014023.md). |
| [ComposantListe](3064007.md) | Retourne la liste des composants externes (fichiers ".WDK") utilisés par l'application WINDEV, WINDEV Mobile ou par le site WEBDEV en cours. |
| [ComposantLocalise](3064009.md) | Spécifie le chemin d'accès à un composant externe du projet. |
| [EnumèreElément](3064001.md) | Permet d'énumérer les éléments du projet : fenêtres, pages, états, requêtes, ... |
| [EnumèreSousElément](3064002.md) | Permet d'énumérer les sous-éléments d'un élément du projet. |
| [ListeDLL](3064006.md) | Retourne :  - **en exécution**: la liste des librairies (fichiers ".DLL") utilisées par l'application WINDEV, WINDEV Mobile ou par le site WEBDEV en cours. Seules les librairies en mémoire sont listées. - **en mode test** : toutes les librairies installées sur le poste en cours. |
| [NombreFenêtre](3064005.md) | Calcule le nombre de fenêtres de l'application en cours actuellement ouvertes. |
| [ProjetInfo](3064004.md) | Renvoie une information spécifique sur le projet en cours d'exécution. |
