# VidéoListeDriver (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Liste les drivers de capture vidéo installés sur le poste en cours.

## Exemple

```wlangage
// Connaître les drivers Vidéo installés
// Affichage dans le champ LISTE_ListeDriver
ListeAjoute(LISTE_ListeDriver, VidéoListeDriver(viDirectShow))
```

## Syntaxe

```wlangage
<Résultat> = VidéoListeDriver([<Technologie utilisée>])
```

`<Résultat>` *Chaîne de caractères*
> Liste des drivers vidéo installés sur le poste, sous la forme :
>
>
> ```wlangage
> <Nom du driver 1> + TAB + <Version du driver 1> + RC + ... <Nom du driver N> + TAB + <Version du driver N>
> ```
>
>
>
> Où :
>
>
> - <Nom du driver 1> ... <Nom du driver N> correspondent au nom des drivers vidéos,
> - <Version du driver 1> ... <Version du driver N> correspondent à la version du driver.
`<Technologie utilisée>` *Constante de type Entier*
> Type de technologie utilisée pour lister les drivers :
>
> | *viDirectShow* | Technologie utilisée : Direct Show.  Cette constante doit être utilisée :    - pour lister des drivers correspondant aux différentes caméras installées (par exemple sur une tablette). - pour sélectionner un driver utilisé dans un champ Conférence (fonction [FluxChangeDriver](1000021613.md)). |
> | --- | --- |
> | *viVideoForWindows* (Valeur par défaut) | Technologie utilisée : Video for Windows |

## Remarques

- Pour afficher la liste des drivers vidéo dans un champ Liste ou un champ Combo, utilisez la syntaxe :
  ```wlangage
  ListeAjoute(<Nom du champ Liste>, <Résultat>)
  ```
  ou
  ```wlangage
  ListeAjoute(<Nom du champ Liste>, VidéoListeDriver())
  ```
- Cette fonction est équivalente à la fonction [CaméraListeDriver](1000022457.md).

**Composante : wd300obj.dll**
