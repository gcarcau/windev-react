# Fonctions de gestion des fichiers Hyper File conservées pour compatibilité uniquement

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Voici la liste des fonctions de gestion des fichiers Hyper File (utilisées en version 5.5) conservées par compatibilité uniquement avec leur équivalence en version 2025.

| BinaireCharge | Charge un fichier binaire dans une rubrique de type mémo binaire 4.1 (initialise un mémo binaire avec le contenu d'un fichier).  Fonction équivalente : [HAttacheMémo](3044173.md). |
| --- | --- |
| BinaireInfo | Permet de connaître les informations d'un mémo binaire 4.1 (type, nom, date, heure et taille du fichier d'origine).  Fonction équivalente : [HInfoMémo](3044008.md) |
| BinaireSauve | Sauve le contenu d'une rubrique mémo binaire 4.1 dans un fichier.  Fonction équivalente : [HExtraitMémo](3044072.md) |
| HAlias_55 | Crée un alias d'un fichier logique ou annuler tous les alias d'un fichier logique.  Fonction équivalente : [HAlias](3044176.md). |
| HAliasExterne | Charge la description de fichiers Hyper File contenue dans une analyse externe à l'application sans fermer l'analyse en cours.  Fonctions équivalentes :   - [HDéclare](3044203.md) : Importe une description de fichier à partir d'une analyse autre que l'analyse en cours. - [HDéclareExterne](3044204.md) : Importe une description de fichier à partir d'un fichier existant. |
| HAssigne | Modifie le chemin d'accès d'un fichier.  Fonction équivalente : [HChangeRep](3044168.md). |
| HCopieEnreg_55 | Copie l'enregistrement en cours d'un fichier dans l'enregistrement en cours d'un autre fichier ayant la même structure.  Fonction équivalente : [HCopieEnreg](3044261.md) |
| HCréeVue_55 | Crée une vue sur un fichier Hyper File.  Fonction équivalente : [HCréeVue](3044159.md). |
| HDébutVerrou | Marque le début du verrouillage de lecture des fichiers. Toutes les fonctions de lecture 'simple' bloquent automatiquement les enregistrements lus.   Fonctions équivalentes :   - Utiliser les fonctions de lecture avec les constantes de blocage appropriées : [HLit](3044047.md), [HLitPremier](3044051.md), [HLitSuivant](3044037.md), .... - Ouvrir le fichier de données en lecture avec la fonction [HOuvre](3044120.md). - Fonction [HBloqueFichier](3044153.md) |
| HDécritClé | Décrit une clé simple ou composée dans un fichier temporaire au format Hyper File.   Fonctionnement équivalent :   1. Déclarer une variable de type [Description de Rubrique](1514071.md). 2. Définir toutes les propriétés de la rubrique grâce aux propriétés HFSQL. 3. Utiliser la fonction [HDécritRubrique](3044233.md) pour valider la création de la rubrique. |
| HDécritTrigger_55 | Ajoute ou modifie un trigger sur Hyper File.   Fonction équivalente : [HDécritTrigger](3044074.md) |
| HDéjàBloque | Teste si la dernière opération WINDEV a pu être exécutée ou non.   Fonctionnement équivalent : cette fonction a été remplacée par :  - une gestion automatique des blocages (désactivable si nécessaire), - la fonction [HErreurBlocage](3044099.md). |
| HDoublon | Teste l'unicité d'une clé.  Fonctionnement équivalent : cette fonction a été remplacée par :  - une gestion automatique des doublons, permettant à l'utilisateur de saisir une valeur différente pour la rubrique générant une erreur de doublon. - la fonction [HErreurDoublon](3044077.md). |
| HFinVerrou | Marque la fin du verrouillage des fichiers : tous les enregistrements bloqués sont débloqués.   Fonctions équivalentes :   - Utiliser les fonctions de lecture avec les constantes appropriées : [HLit](3044047.md), [HLitPremier](3044051.md), [HLitSuivant](3044037.md), .... - Ouvrir le fichier de données en lecture/écriture avec la fonction [HOuvre](3044120.md). - Fonction [HDébloqueFichier](3044160.md). |
| HImporteTexte_55 | Importe un fichier texte dans un fichier Hyper File.   Fonction équivalente : [HImporteTexte](3044011.md). |
| HInfoGéné | Retourne les informations générales sur un fichier Hyper File.  Fonctionnement équivalent : cette fonction a été remplacée par :  - des fonctions (par exemple, [HNbEnr](3044006.md) remplace la variable H.NbEnr). - des [propriétés HFSQL](2512070.md) (par exemple, la propriété **Répertoire** remplace la variable H.Rep). |
| HInfoRubrique | Permet d'obtenir des informations sur une rubrique de l'analyse.   Fonctionnement équivalent : cette fonction a été remplacée par différentes [propriétés HFSQL](2512070.md). |
| HLitBloque | Lit et bloque un enregistrement en fonction du numéro d'enregistrement spécifié.   Fonction équivalente : [HLit](3044047.md) avec les constantes permettant la gestion des blocages. |
| HLitDernierBloque | Lit et bloque le dernier enregistrement du fichier selon la clé passée en paramètre.  Fonction équivalente : [HLitDernier](3044140.md) avec les constantes permettant la gestion des blocages. |
| HLitDernierSansBloquer | Lit le dernier enregistrement du fichier selon la clé passée en paramètre. Si le fichier est verrouillé, l'enregistrement lu n'est pas bloqué.  Fonction équivalente : [HLitDernier](3044140.md) avec les constantes permettant la gestion des blocages. |
| HLitPrécédentBloque | Lit et bloque l'enregistrement précédent selon la clé spécifiée.  Fonction équivalente : [HLitPrécédent](3044048.md) avec les constantes permettant la gestion des blocages. |
| HLitPrécédentSansBloquer | Lit l'enregistrement précédent selon la clé spécifiée. Si le fichier est verrouillé, l'enregistrement lu n'est pas bloqué.   Fonction équivalente : [HLitPrécédent](3044048.md) avec les constantes permettant la gestion des blocages. |
| HLitPremierBloque | Lit et bloque le premier enregistrement du fichier relativement à la clé spécifiée.  Fonction équivalente : [HLitPremier](3044051.md) avec les constantes permettant la gestion des blocages. |
| HLitPremierSansBloquer | Lit le premier enregistrement selon la clé spécifiée. Si le fichier est verrouillé, l'enregistrement lu n'est pas bloqué.  Fonction équivalente : [HLitPremier](3044051.md) avec les constantes permettant la gestion des blocages. |
| HLitRechercheBloque | Lit et bloque le premier enregistrement dont la valeur de la clé donnée est égale ou supérieure à la valeur de l'argument de recherche.  Fonction équivalente : [HLitRecherche](3044050.md) avec les constantes permettant la gestion des blocages.  Fonction équivalente : [HLitRecherche](3044050.md) avec les constantes permettant la gestion des blocages. |
| HLitRechercheSansBloquer | Lit le premier enregistrement dont la valeur de la clé donnée est égale ou supérieure à la valeur de l'argument de recherche. Si le fichier est verrouillé, l'enregistrement lu n'est pas bloqué.  Fonction équivalente : [HLitRecherche](3044050.md) avec les constantes permettant la gestion des blocages. |
| HLitSansBloquer | Lit l'enregistrement en fonction du numéro d'enregistrement spécifié. Si le fichier est verrouillé, l'enregistrement lu n'est pas bloqué.  Fonction équivalente : [HLit](3044047.md) avec les constantes permettant la gestion des blocages. |
| HLitSuivantBloque | Lit et bloque l'enregistrement suivant selon la clé spécifiée.  Fonction équivalente : [HLitSuivant](3044037.md) avec les constantes permettant la gestion des blocages. |
| HLitSuivantSansBloquer | Lit l'enregistrement suivant selon la clé spécifiée. Si le fichier est verrouillé, l'enregistrement lu n'est pas bloqué.  Fonction équivalente : [HLitSuivant](3044037.md) avec les constantes permettant la gestion des blocages. |
| HRéindexe_55 | Réindexe d'un fichier Hyper File de l'analyse en cours.  Fonction équivalente : [HRéindexe](3044133.md). |
| HSubstNom | Modifie le nom (physique) d'un fichier de données.  Fonction équivalente : [HChangeNom](3044141.md). |
| HVueVersTable | Remplit un champ Table par programmation avec une vue.  Fonction équivalente : [FichierVersTableMémoire](3074005.md). |
