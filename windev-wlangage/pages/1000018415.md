# Login (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **Login** permet de connaître et de modifier le login. Cette propriété est utilisable sur :

- une variable de type [sfConnexion](1000017579.md).
- une variable de type [sfInfoUtilisateur](1000018423.md).
- une variable de type [saasUtilisateur](1000019083.md).
- une variable de type [gpwUtilisateur](1000021088.md).
