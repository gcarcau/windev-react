# Le volet "Briques de code"

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Le volet "Briques de code" liste les briques de code actuellement disponibles.
[image: Volet 'Brique de code']Il permet de :

- Ajouter une brique de code,
- Modifier une brique de code,
- Utiliser une brique de code,
- Supprimer une brique de code.

Pour plus de détails, consultez [Gestion des briques de code](9000066.md).

## Afficher le volet "Briques de code"

**Pour afficher le volet "Briques de code"**, sous le volet "Accueil", dans le groupe "Environnement", déroulez "Volets" et sélectionnez "Volets" puis "Briques de code".
Pour plus de détails sur les manipulations des volets, consultez [Manipuler les volets ancrables](2027001.md).
