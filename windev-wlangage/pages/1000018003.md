# Epaisseur (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Epaisseur** permet de connaître et de modifier l'épaisseur d'un élément. Cette propriété est utilisable sur :

- les champs d'une fenêtre :
  - les graphes de type courbe.
  - les champs Fil.
   Pour plus de détails, consultez [Epaisseur](2510144.md).
- une variable de type [gglParamètreCarte](1000017505.md).
- une variable de type [gglChemin](1000017433.md).
- une variable de type [Cadre](15140100.md).
- une variable de type [CarteCercle](1000025504.md).
- une variable de type [CartePolygone](1000025476.md).
- une variable de type [CartePolyligne](1000025489.md).
