# NamespaceDéclaré (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **NamespaceDéclaré** permet de gérer les espaces de nommage définis. Cette propriété est utilisable sur :

- une variable de type [xmlNoeud](1000018786.md).
- une variable de type [xmlLecteur](1000023392.md).
