# SysNombreEcran (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Renvoie le nombre d'écrans actuellement connectés au poste en cours.

## Exemple

```wlangage
// Renvoyer le nombre d'écrans connectés
Info(SysNombreEcran())
```

## Syntaxe

```wlangage
<Résultat> = SysNombreEcran()
```

`<Résultat>` *Entier*
> Nombre d'écrans actuellement connectés.

## Remarques

> _(WINDEV, Etats et Requêtes, Windows, Code Utilisateur (MCU))_ Nom des écransLa liste des noms des écrans peut être connue grâce à la fonction SysListeEcran.
