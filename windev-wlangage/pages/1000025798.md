# <Carte>.RécupèreStyle (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android)

Renvoie le style utilisé par la carte affichée dans le champ Carte.
Nouveauté Abonnement

> _(Android)_ Cette fonction est disponible uniquement si le style de la carte n'a pas été personnalisé. Dans le cas contraire, cette fonction est sans effet. Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3. Pour plus de détails, consultez Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement.

## Exemple

```wlangage
// Applique une style "rétro" à la carte
CARTE_MaCarte.ChangeStyle(ccsRétro)
...
soit StyleUtilisé = CARTE_MaCarte.RécupèreStyle()
SI StyleUtilisé = ccsRétro ALORS Trace("Style rétro")
```

## Syntaxe

```wlangage
<Résultat> = <Champ Carte>.RécupèreStyle()
```

`<Résultat>` *Constante de type Entier*
> Style utilisé par la carte affichée dans le champ Carte :
>
> | *ccsArgenté* | Style "Argenté". |
> | --- | --- |
> | *ccsAubergine* | Style "Aubergine". |
> | *ccsNuit* | Style "Nuit". |
> | *ccsPersonnalisé* | Style "Personnalisé". |
> | *ccsRétro* | Style "Retro". |
> | *ccsSombre* | Style "Sombre". |
> | *ccsStandard* | Style "Standard". |
`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler.

## Remarques

Pour modifier le style de la carte affichée par le champ Carte, utilisez la fonction [<Carte>.ChangeStyle](1000025797.md).
