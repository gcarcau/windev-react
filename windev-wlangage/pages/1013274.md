# Modes d'affichage d'un champ Onglet

> **Disponible :** **WINDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Pour optimiser le look de vos onglets, vous pouvez utiliser des images et des couleurs. Pour plus de détails, consultez [Images et onglets](1013195.md).
Mais vous pouvez également utiliser :

- la position des onglets : en bas, en haut, à gauche ou à droite. Cette position peut être combinée avec l'orientation du libellé de l'onglet.
- le mode d'affichage des onglets.
- le décalage des volets sous l'éditeur.

## Position des onglets

Par défaut, lors de la création d'un champ Onglet, les volets d'onglets sont positionnés en haut du champ.
Pour modifier cette position :

1. Affichez la fenêtre de description du champ Onglet.
2. Dans l'onglet "Détail", sélectionnez la position voulue :
  - en haut,
  - en bas,
  - à gauche,
  - à droite.
   Seules les positions en haut et en bas sont disponibles.
3. Validez la fenêtre de description du champ.

**Remarque** : Si vous sélectionnez une position à gauche ou à droite, par défaut le libellé du volet reste horizontal. Pour afficher ce libellé verticalement, pensez à modifier l'orientation du libellé dans l'onglet "Style" de la description du champ :

1. Affichez la fenêtre de description du champ Onglet.
2. Dans l'onglet "Style, sélectionnez l'élément "Libellé du volet actif".
3. Modifiez l'orientation de le police (0° par défaut).
4. Répétez l'opération 3 pour l'élément "Libellé du volet inactif".

## Mode d'affichage des onglets

> _(WINDEV, Android, Android, WINDEV)_ Les différents modesLe champ Onglet propose différents modes d'affichage des onglets : le mode standard (par défaut) : les volets d'onglets sont affichés sur une ligne et s'il n'y a plus de place, les onglets sont affichés sur une ligne supplémentaire : S'il n'y a plus de place, il suffit de faire scroller les onglets avec le doigt pour afficher les volets masqués. le mode 3 volets avec glissement : seuls 3 volets sont affichés, et lors du clic sur le dernier ou le premier volet, celui-ci passe au milieu : le mode volets invisibles : tous les volets sont invisibles. le mode standard avec boutons + / - : les volets d'onglets sont affichés sur une ligne et s'il n'y a plus de place, des boutons apparaissent permettant à l'utilisateur de faire défiler les volets. Le look de ces boutons peut être modifié dans l'onglet "Style" de la description du champ (élément "Boutons suivant/précédent"). Pour définir le mode d'affichage des onglets : Affichez la fenêtre de description du champ Onglet. Dans l'onglet "Détail", sélectionnez le mode d'affichage voulu. Validez la fenêtre de description du champ.

> _(Android)_ Changer de volet par balayageQuel que soit le mode d'affichage des onglets, il est possible de changer de volet par balayage. Cette option permet d'afficher le contenu de l'onglet précédent ou suivant par un simple mouvement de balayage sur l'écran. Remarque : Cette option est notamment utilisée pour changer le contenu du volet d'onglet lorsque les onglets sont invisibles.

## Décalage des volets d'onglet

> _(WINDEV)_ Quelque soit la position des volets d'onglets, il est possible de les décaler sous l'éditeur grâce à une poignée spécifique. Ainsi, si les volets d'onglet sont positionnés : En haut ou en bas, il est possible de les décaler vers la droite. A gauche ou à droite, il est possible de les décaler vers le bas. L'espace ainsi libéré peut être par exemple utilisé pour afficher un logo ou un bouton déroulant des options. Pour décaler la position des volets d'onglet : Sélectionnez le champ Onglet. Une poignée spécifique apparaît au milieu du bord du premier onglet. Sélectionnez cette poignée et déplacez-la. La zone située à côté du premier onglet s'agrandit et les différents onglets sont décalés (vers la droite ou vers le bas selon l'orientation des volets). Les volets d'onglet ont été décalés.
