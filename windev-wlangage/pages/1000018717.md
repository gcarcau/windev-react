# ConfirmationLecture (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **ConfirmationLecture** permet de connaître et de modifier la demande de confirmation de lecture d'un email.
Cette propriété est utilisable sur :

- la structure [Email](3032029.md).
- une variable de type [Email](1000018713.md).
