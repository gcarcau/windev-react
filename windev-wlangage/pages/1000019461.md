# SaaSUtilisateurConnecté (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Renvoie l'utilisateur actuellement connecté via la fonction [SaaSConnecte](1000018959.md). Cette fonction permet par exemple de connaître l'utilisateur connecté dans un site SaaS via une page de connexion automatique.

## Exemple

```wlangage
U est un saasUtilisateur
U = SaaSUtilisateurConnecté()
Info("Bonjour" + U.Prénom)
```

## Syntaxe

```wlangage
<Résultat> = SaaSUtilisateurConnecté()
```

`<Résultat>` *Variable de type saasUtilisateur*
> Variable de type [saasUtilisateur](1000019083.md) contenant les caractéristiques de l'utilisateur connecté.

**Composante : wd300com.dll**
