# <Variable mongoGridFS>.SupprimeFichier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Supprime un fichier identifié par son nom dans un système de fichiers MongoDB.
**Remarque** : Pour supprimer un fichier identifié à partir de son identifiant, utilisez la fonction [<Variable mongoGridFS>.SupprimeFichierParID](1000025395.md).

## Exemple

```wlangage
gclGridFS est un mongoGridFS
// Supprime le fichier présent dans la colonne de la table
gclGridFS.SupprimeFichier(TABLE_GridFS.COL_Nom)
ToastAffiche("Suppression terminée avec succès.")
```

## Syntaxe

```wlangage
<Résultat> = <Système de fichiers>.SupprimeFichier(<Nom du fichier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème. La fonction [ErreurInfo](3013008.md) permet d'identifier l'erreur.
`<Système de fichiers>` *Variable de type mongoGridFS*
> Nom de la variable de type [mongoGridFS](1000022416.md) correspondant au système de fichiers Mongo à manipuler.
`<Nom du fichier>` *Chaîne de caractères*
> Nom du fichier à supprimer.

**Composante : wd300big.dll**
