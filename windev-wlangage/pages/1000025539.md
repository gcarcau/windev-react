# Déplaçable (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Déplaçable** permet de gérer la possibilité de déplacer un élément. Cette propriété est utilisable sur :

- une colonne d'un champ Table. Pour plus de détails, consultez l'aide de la propriété [Déplaçable](2510032.md).
- une variable de type [Marqueur](1000019940.md).
