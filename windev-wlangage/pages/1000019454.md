# Obtention d'un certificat TSL (SSL) pour IIS

> **Disponible :** **WEBDEV** (Windows)

## Les différentes étapes

Pour obtenir un certificat TSL (SSL) pour IIS, les différentes étapes sont les suivantes :

1. Création de la demande de certification.
2. Envoi de la demande de certification à un organisme.
3. Mise en place du certificat.

IIS 7 permet également de créer un certificat auto-signé.

## Etape n°1 : Création d'une requête de signature de certificat

Pour créer une demande de certification :

1. Ouvrez le Gestionnaire des services Internet (option "Démarrer .. Exécuter": Inetmgr.exe).
2. Sélectionnez l'ordinateur en cours (la racine des connexions).
3. Double-cliquez sur l'option "Certificats de serveur".
4. Dans l'écran qui s'affiche, cliquez sur le lien "Créer une demande de certificat". Un assistant se lance.
5. Renseignez les différentes informations demandées et indiquez le nom du fichier à générer.

## Etape n°2 : Envoi de la demande de certification à un fournisseur de certificat

La demande de certification se fait à un organisme de certification de clé. Les étapes sont presque les mêmes pour chaque organisme.
Il suffit de se connecter au site Web de l'organisme de certification, de s'identifier, et de fournir le fichier précédemment généré pour obtenir un certificat (payant ou en version d'évaluation selon les organismes). .

## Certificat auto-signé

IIS permet de créer un certificat auto-signé. Cette option permet de créer un certificat local pour tester le TSL/SSL.
Pour créer un certificat auto-signé :

1. Ouvrez le Gestionnaire des services Internet (option "Démarrer .. Exécuter": Inetmgr.exe).
2. Sélectionnez l'ordinateur en cours (la racine des connexions).
3. Double-cliquez sur l'option "Certificats de serveur".
4. Dans l'écran qui s'affiche, cliquez sur le lien "Créer un certificat auto-signé". Un assistant se lance.
