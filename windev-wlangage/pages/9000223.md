# HFSQL Client/Serveur : Optimisation planifiée

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

## Présentation

### Définition
Une optimisation planifiée est un mécanisme d'optimisation automatique de votre base de données. Une tâche d'optimisation planifiée permet d'effectuer de façon périodique un calcul des statistiques ou une réindexation des fichiers de données du serveur HFSQL.
Les tâches planifiées peuvent être gérées :

- soit dans le Centre de Contrôle HFSQL.
- soit par programmation.

## Tâches d'optimisation planifiée dans le Centre de Contrôle HFSQL

### Créer une optimisation planifiée
Dans le Centre de Contrôle HFSQL, les tâches d'optimisation peuvent être définies au niveau du serveur ou de la base de données.
Pour créer une tâche d'optimisation :

1. Connectez-vous si nécessaire à un serveur HFSQL et affichez la description du serveur ou d'une de ses bases (double-clic sur le nom du serveur ou de la base dans l'arborescence).
2. Cliquez sur l'onglet "Eléments planifiés".
3. Dans le ruban, dans le groupe "Eléments planifiés", déroulez "Nouvelle planification" et sélectionnez "Planifier une optimisation". L'assistant de création d'une optimisation planifiée se lance.
4. Sélectionnez les fichiers à optimiser :
  - Une base de données,
  - Une sélection de fichiers d'une base de données.
5. Définissez la fréquence de la tâche : mois, jour, heure.
6. Indiquez l'action réalisée :
  - **Réindexer les fichiers** :
    Cette action permet un accès aux index optimal. La réindexation effectue automatiquement le recalcul des statistiques sur les clés.
  - **Recalculer les statistiques sur les clés des fichiers** :
    Cet action permet d'optimiser les parcours des fichiers de données.
7. Indiquez si nécessaire les mots de passe des fichiers de données.
  Attention : Si des mots de passe différents sont utilisés sur les fichiers de données, il est nécessaire de créer une tâche d'optimisation différente pour chaque fichier de données associé à un mot de passe différent.
8. Donnez une description à votre tâche planifiée et validez l'assistant.
9. L'optimisation planifiée apparaît dans l'onglet "Eléments planifiés" du Centre de Contrôle HFSQL.

### Supprimer une optimisation planifiée
Pour supprimer une optimisation planifiée :

1. Connectez-vous si nécessaire à un serveur HFSQL et affichez l'onglet du serveur ou de la base de données voulu.
2. Cliquez sur l'onglet "Eléments planifiés".
3. Sélectionnez l'optimisation planifiée à supprimer.
4. Dans le ruban, dans le groupe "Eléments planifiés", cliquez sur "Supprimer".
  Vous pouvez également utiliser le menu contextuel de l'élément planifié (option "Supprimer").

### Modifier une optimisation planifiée
Pour modifier une optimisation planifiée :

1. Connectez-vous si nécessaire à un serveur HFSQL et affichez l'onglet du serveur ou de la base de données voulu.
2. Cliquez sur l'onglet "Eléments planifiés".
3. Sélectionnez l'optimisation planifiée à modifier.
4. Dans le ruban, dans le groupe "Eléments planifiés", cliquez sur "Editer".
  Vous pouvez également utiliser le menu contextuel de l'élément planifié (option "Editer").
5. Une fenêtre de description de l'élément planifié apparaît. Toutes les caractéristiques saisies dans l'assistant sont regroupées sur plusieurs onglets :
  - Onglet "Général" : Définit si l'optimisation est active.
  - Onglet "Planification" : Définit les options d'exécution de l'optimisation planifiée (mois, jour, heure).
  - Onglet "Contenu" : Définit les éléments inclus dans l'optimisation planifiée (serveur, base de données, fichiers, etc.) ainsi que l'action réalisée.
  - Nouveauté 2025
    Onglet "Historique des exécutions" : Cet onglet apparaît lorsque l'optimisation planifiée a été exécutée automatiquement. Cet onglet liste les différentes exécutions automatiques de la tâche planifiée, en indiquant :
    - la date de début de l'optimisation,
    - l'état de l'optimisation : terminée, en cours, en erreur,
    - la durée d'exécution,
    - l'utilisateur qui a lancé l'optimisation,
    - si le lancement a été fait manuellement (lancement via la fonction [HExécutePlanification](1000021453.md)).
6. Validez.

## Optimisations planifiées par programmation

### Création d'une optimisation planifiée
La gestion des optimisation planifiées par programmation est réalisée grâce à une variable de type [hOptimisationPlanifiée](1000018854.md) et à plusieurs fonctions WLangage.
Pour créer une optimisation planifiée par programmation :

1. Créez une variable de type [hOptimisationPlanifiée](1000018854.md) et décrivez les différentes caractéristiques de l'optimisation planifiée.
2. Ajoutez l'optimisation planifiée grâce à la fonction [HAjoutePlanification](1000021447.md) (ou la fonction [HAjouteOptimisationPlanifiée](1000018860.md)).

Remarques :

- Pour ajouter une tâche planifiée, il est nécessaire de posséder :
  - le droit de gérer les tâches (constante ***hDroitGèreTâche***).
  - le droit d'exécuter la commande liée à l'optimisation planifiée.
- L'optimisation planifiée sera exécutée avec l'identité de l'utilisateur défini par la connexion.

Nouveauté 2025

### Historique d'exécution des optimisations planifiées
Un historique des exécutions est automatiquement enregistré lors de l'exécution automatique de l'optimisation planifiée (ou lors de son exécution via la fonction [HExécutePlanification](1000021453.md)). Il est possible de manipuler cet historique par programmation, via une variable de type [hHistoriquePlanification](1410090764.md) et les fonctions suivantes :

| Nouveauté 2025 [HListeHistoriquePlanification](1410090762.md) | Liste l'historique d'exécution d'une opération planifiée sur un serveur HFSQL : tâche planifiée (procédure stockée), sauvegarde, optimisation, rafraîchissement d'une vue matérialisée. |
| --- | --- |
| Nouveauté 2025 [HSupprimeHistoriquePlanification](1410090760.md) | Supprime l'historique d'exécution d'un élément planifié sur un serveur HFSQL : tâche planifiée (procédure stockée), sauvegarde, optimisation, rafraîchissement d'une vue matérialisée. |
| Nouveauté 2025 [HSupprimeToutHistoriquePlanification](1410090761.md) | Purge la totalité de l'historique d'exécution des éléments planifiés sur un serveur HFSQL. |

### Manipulation des optimisations planifiées en WLangage
Les optimisations planifiées peuvent être manipulées via :

- les fonctions de gestion des optimisations planifiées :
  | [HAjouteOptimisationPlanifiée](1000018860.md) | Ajoute une tâche d'optimisation des fichiers de données HFSQL Client/Serveur. |
  | --- | --- |
  | [HListeOptimisationPlanifiée](1000018863.md) | Liste les tâches d'optimisation planifiées des fichiers de données HFSQL Client/Serveur pour une connexion. |
  | [HModifieOptimisationPlanifiée](1000018931.md) | Modifie une tâche d'optimisation planifiée sur le serveur HFSQL défini par la connexion. |
  | [HSupprimeOptimisationPlanifiée](1000018865.md) | Supprime une tâche d'optimisation planifiée de fichiers de données HFSQL Client/Serveur. |
- les fonctions de gestion des éléments planifiés (conseillées) :
  | [HAjoutePlanification](1000021447.md) | Ajoute un nouvel élément planifié sur un serveur HFSQL : tâche planifiée (procédure stockée), sauvegarde, optimisation ou rafraîchissement d'une vue matérialisée. |
  | --- | --- |
  | [HExécutePlanification](1000021453.md) | Exécute immédiatement un élément planifié sans tenir compte de sa planification : tâche planifiée (procédure stockée), sauvegarde, optimisation, rafraîchissement d'une vue matérialisée. |
  | [HListePlanification](1000021452.md) | Liste les éléments planifiés définis sur un serveur HFSQL : tâches planifiées (procédure stockée), sauvegarde, optimisation, rafraîchissement d'une vue matérialisée. |
  | [HModifiePlanification](1000021450.md) | Modifie un élément planifié sur un serveur HFSQL : tâche planifiée (procédure stockée), sauvegarde, optimisation, rafraîchissement d'une vue matérialisée. |
  | [HSupprimePlanification](1000021448.md) | Supprime un élément planifié sur un serveur HFSQL : tâche planifiée (procédure stockée), sauvegarde, optimisation, rafraîchissement d'une vue matérialisée. |
