# CaractèreRemplissage

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **CaractèreRemplissage** permet de connaître et de modifier le caractère utilisé pour le remplissage d'un élément. Cette propriété est utilisable sur :

- une variable de type [docTabulation](1000022573.md).
- une variable de type [FormatNumérique](1410089836.md).
