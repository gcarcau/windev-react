# HLibère (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Transforme les enregistrements rayés (fonction [HRaye](3044121.md)) d'un fichier de données en enregistrements supprimés. La place occupée par les enregistrements rayés est ainsi libérée et pourra être réutilisée lors des prochains ajouts (fonction [HAjoute](3044147.md)).
**Rappel** : Un enregistrement rayé est inactif et disparaît de l'index. Les données de cet enregistrement rayé ne sont pas supprimées (contrairement à la fonction [HSupprime](3044018.md)).

## Exemple

```wlangage
// Supprime tous les enregistrements rayés du fichier de données "Client"
HLibère(Client)
```

## Syntaxe

```wlangage
<Résultat> = HLibère([<Fichier de données>])
```

`<Résultat>` *Booléen*
> - Vrai si l'enregistrement a été supprimé,
> - Faux en cas de problème : l'enregistrement n'est pas supprimé. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Fichier de données>` *Chaîne de caractères optionnelle*
> Nom du fichier de données manipulé. Si ce nom n'est pas spécifié, la fonction **HLibère** va manipuler le dernier fichier de données utilisé par la dernière fonction de gestion HFSQL (fonction commençant par la lettre H).

## Remarques

Cette fonction n'est pas adaptée à des fichiers xBase.
