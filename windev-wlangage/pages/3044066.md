# HGèreTransaction (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Active ou désactive la gestion des transactions sur un ou plusieurs fichiers de données.
Lorsque la gestion des transaction est désactivée, toutes les fonctions relatives aux transactions sont inhibées ([HTransactionDébut](3044002.md), [HTransactionFin](3044032.md), [HTransactionAnnule](3044001.md)).

**Remarque** : Par défaut, la gestion des transactions est active.

> _(Android, Widget Android)_ Cette fonction peut être utilisée uniquement avec des fichiers de données HFSQL Client/Serveur.

## Exemple

```wlangage
// Désactive la gestion des transactions sur le fichier de données Client
HGèreTransaction(Client, Faux)
```

## Syntaxe

```wlangage
<Résultat> = HGèreTransaction([<Fichier de données>, ] <Options>)
```

`<Résultat>` *Booléen*
> Correspond à l'ancienne gestion des transactions (avant utilisation de la fonction **HGèreTransaction**) :
>
> - Vrai si la gestion des transactions était active,
> - Faux si la gestion des transactions n'était pas active.
>
> Si <Fichier de données>= "*", <Résultat> est à Vrai si dans l'ancien mode de gestion des transactions, la gestion des transactions était active au moins sur un des fichiers de données.
`<Fichier de données>` *Chaîne de caractères optionnelle*
> Nom du fichier de données manipulé. Si ce nom n'est pas spécifié ou correspond à "*", la gestion des transactions est prise en compte pour tous les fichiers de données de l'analyse.
`<Options>` *Booléen*
> - Vrai si la gestion des transactions sur le fichier de données doit être activée,
> - Faux si cette gestion doit être désactivée.

## Remarques

### Gestion des transactions activée
Si la gestion des transactions est activée pour un seul fichier de données, seules les manipulations réalisées sur ce fichier de données seront prises en compte dans la gestion des transactions (quels que soit les fichiers de données indiqués dans la fonction [HTransactionDébut](3044002.md)).

> _(WINDEV, WEBDEV - Code Serveur, Code Utilisateur (MCU), Ajax)_ Limite La gestion des transactions ne s'applique pas aux fichiers xBase.
