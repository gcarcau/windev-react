# Groupe (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

La propriété **Groupe** permet de connaître et de modifier les groupes d'éléments. Cette propriété est utilisable sur :

- les groupes de champs. Pour plus de détails, consultez [Groupe sur les groupes de champs](2510049.md).
- une variable de type [gglContact](1000017434.md).
- une variable de type [Notification](1000019441.md).
- une variable de type [hdfsInformation](1000021973.md).
