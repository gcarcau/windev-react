# Fonctions de gestion de l'OCR (Optical Character Recognition) intégré

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Les fonctions de gestion de l'OCR intégré à WINDEV, WEBDEV et WINDEV Mobile sont les suivantes :

| [OCRAjouteLangue](1000025728.md) | Ajoute une langue de détection à l'OCR natif. |
| --- | --- |
| [OCRChargeLangue](1000025790.md) | Ajoute une langue à l'OCR natif. |
| [OCRDétecteZoneTexte](1000025704.md) | Renvoie toutes les zones de texte d'une image sans lire le texte. |
| [OCRExtraitBlocTexte](1000025703.md) | Renvoie tous les blocs texte d'une image. |
| [OCRExtraitTexte](1000025699.md) | Lit le texte contenu dans une image. |
| [OCRParamètre](1000025701.md) | Initialise les options générales de l'OCR (Optical Character Recognition) natif. |
| [OCRRépertoireModèle](1000025700.md) | Permet de définir le répertoire contenant les modèles de langue pour l'OCR natif. |
| [OCRSupprimeToutesLangues](1000025729.md) | Supprime toutes les langues de l'OCR natif. |

## Liste des exemples associés :

| [image: Les fonctions OCR] | Exemples unitaires (WINDEV) : Les fonctions OCR     [ + ] Cet exemple montre l'utilisation des fonctions OCR de WINDEV. Ces fonctions permettent d'analyser une image afin d'en extraire le texte. Il est possible de spécifier la langue du document analysé afin de détecter plus finement. Il est également possible de récupérer les positions des blocs de texte trouvés. |
