# <Variable Connexion>.AjouteUtilisateur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Ajoute un utilisateur à une base de données. Toutes les caractéristiques de l'utilisateur doivent être saisies dans les [différentes variables de gestion des utilisateurs](3044315.md).

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion

// Ouverture de la connexion
MaConnexion.OuvreConnexion()
// Association du fichier de données à la connexion
Client.ChangeConnexion(MaConnexion)
// Caractéristiques du nouvel utilisateur
HUtilisateur.Login = "FLO"
HUtilisateur.MotDePasse = "FLOP"
HUtilisateur.NomComplet = "Florence"
HUtilisateur.Email = "Flo@monadresse.fr"
HUtilisateur.Téléphone = "01.67.40.47.58"
HUtilisateur.Groupes = "ADMIN" + RC + "TEST"
// Ajout de l'utilisateur
SI MaConnexion.AjouteUtilisateur() = Vrai ALORS
	Info("Utilisateur ajouté")
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.AjouteUtilisateur()
```

`<Résultat>` *Booléen*
> - Vrai si l'utilisateur a été ajouté,
> - Faux en cas d'erreur. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle un utilisateur doit être ajouté.

## Remarques

### Droits nécessaires pour ajouter un utilisateur
Pour ajouter un utilisateur, il est nécessaire de posséder les droits suivants :

- Droit de gestion des utilisateurs (constante *hDroitGestionUtilisateur*).
- Droit de visualisation des utilisateurs (constante *hDroitVisualisationUtilisateur*).

Ces constantes sont utilisées dans les fonctions [<Variable Connexion>.InfoDroitServeur](1000022668.md) et [<Variable Connexion>.ModifieDroitServeur](1000022710.md).

### Gestion des droits
Par défaut, lors de la création d'un utilisateur (si cet utilisateur n'est associé à aucun groupe), cet utilisateur n'a aucun droit.
Si cet utilisateur est associé à un ou plusieurs groupes, cet utilisateur a alors les droits associés à ce groupe (l'utilisateur "hérite" des droits associés au groupe).

Il est possible de donner des droits à un utilisateur grâce aux fonctions :

- [<Variable Connexion>.ModifieDroitBaseDeDonnées](1000022707.md) : permet de donner des droits sur une base de données.
- [<Variable Connexion>.ModifieDroitFichier](1000022709.md) : permet de donner des droits sur un fichier de données.
- [<Variable Connexion>.ModifieDroitServeur](1000022710.md) : permet de donner des droits sur un serveur.

Pour plus de détails sur la gestion des droits, consultez [Gestion des droits en HFSQL Client/Serveur](3044333.md).

### Utilisateur "SuperUtilisateur"
Si la variable HUtilisateur.SuperUtilisateur = Vrai, les droits de l'utilisateur ne sont pas vérifiés lors d'une action. Cet utilisateur peut donc faire toutes les actions.
