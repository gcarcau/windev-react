# Constantes Pilote

> **Disponible :** **WINDEV** (Windows) · **WINDEV Mobile** (Android, iPhone/iPad)

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |
| **pabBoutonGauche** | Simule un appui sur le bouton gauche de l'Action Bar. | [PiloteActionBar](1000021199.md) |
| **pabOption** | Simule un appui sur une des options de l'Action Bar. | [PiloteActionBar](1000021199.md) |
| **pabVue** | Simule un appui sur une des vues de l'Action Bar. | [PiloteActionBar](1000021199.md) |
| **psAlt** | Maintient la touche Alt. | [PiloteSouris](1000009011.md), [PiloteSaisie](1000009012.md) |
| **psClicDroit** | Effectue un clic droit. | [PiloteSouris](1000009011.md) |
| **psClicGauche** | Effectue un clic gauche. | [PiloteSouris](1000009011.md) |
| **psControl** | Maintient la touche Ctrl. | [PiloteSouris](1000009011.md), [PiloteSaisie](1000009012.md) |
| **psDoubleClicDroit** | Effectue un double-clic droit. | [PiloteSouris](1000009011.md) |
| **psDoubleClicGauche** | Effectue un double-clic gauche. | [PiloteSouris](1000009011.md) |
| **psEnfonceBoutonDroit** | Enfonce le bouton droit. | [PiloteSouris](1000009011.md) |
| **psEnfonceBoutonGauche** | Enfonce le bouton gauche. | [PiloteSouris](1000009011.md) |
| **psFerme** | Ferme le simulateur. | [PiloteSimulateur](1000021151.md) |
| **psMenu** | Simule un appui sur le bouton Menu du simulateur. | [PiloteSimulateur](1000021151.md) |
| **psRelacheBoutonDroit** | Relâche le bouton droit. | [PiloteSouris](1000009011.md) |
| **psRelacheBoutonGauche** | Relâche le bouton gauche. | [PiloteSouris](1000009011.md) |
| **psRetour** | Simule un appui sur le bouton Retour du simulateur. | [PiloteSimulateur](1000021151.md) |
| **psShift** | Maintient la touche Maj. | [PiloteSouris](1000009011.md), [PiloteSaisie](1000009012.md) |
| **psTourneEcran** | Tourne l'écran du simulateur : passe du mode paysage au mode portrait ou inversement. | [PiloteSimulateur](1000021151.md) |
| **pvDéfaut** | Vitesse d'exécution des fonctions de pilotage : vitesse normale. | [PiloteVitesse](1000022075.md) |
| **pvRalenti** | Vitesse d'exécution des fonctions de pilotage : vitesse ralentie pour visualiser les actions effectuées. | [PiloteVitesse](1000022075.md) |
