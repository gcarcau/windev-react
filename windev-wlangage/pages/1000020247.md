# MessagerieInstantanée (Type de variable)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le type **MessagerieInstantanée** permet de définir toutes les caractéristiques avancées de la messagerie instantanée d'un contact (Google Talk, Skype, MSN, etc.).
Les caractéristiques de cette messagerie peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.

Ce type de variable est utilisé par les variables de type [Contact](1000020254.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Propriétés

### Propriétés spécifiques à la description des variables de type MessagerieInstantanée
Les propriétés suivantes peuvent être utilisées :

| **Nom de la propriété** | **Type manipulé** | **Effet** |
| --- | --- | --- |
| Adresse | Chaîne de caractères | Adresse du contact sur la messagerie instantanée considérée. |
| Etiquette | Chaîne de caractères | Etiquette pour les messageries personnalisées (optionnel).  Si la propriété **Type** ne correspond pas à la constante *miPersonnalisé*, la valeur de cette propriété sera ignorée. |
| Protocole | Constante de type Entier | _(Android)_ Nom du protocole de la messagerie instantanée considérée : miAIM : AOL Instant MessengermiAutre : autres types de messageriemiGoogleTalk : Google TalkmiICQ : ICQmiMSN : Windows Live MessengermiNetMeeting : NetMeetingmiSkype : SkypemiYahoo : Yahoo _(iPhone/iPad, Widget IOS, Mac Catalyst)_ Nom du protocole de la messagerie instantanée considérée : miAIM : AOL Instant MessengermiICQ : ICQmiMSN : Windows Live MessengermiYahoo : Yahoo |
| Type | Constante de type Entier | Type d'adresse :   - *miAutre* : autres types - *miBureau* : adresse de messagerie instantanée du bureau - *miDomicile* : adresse de messagerie instantanée du domicile - *miPersonnalisé* : type personnalisé correspondant à la valeur de la propriété **Etiquette**. _(iPhone/iPad, Widget IOS, Mac Catalyst)_ Cette propriété n'est pas disponible. |

## Remarques

### Réinitialisation
Pour réinitialiser le contenu d'une variable de type **MessagerieInstantanée**, il est possible d'utiliser la fonction [VariableRAZ](3013069.md).
