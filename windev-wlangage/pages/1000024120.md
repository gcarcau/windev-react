# <Graphe>.PoliceTitreAxe (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Modifie la police utilisée pour les titres des axes d'un graphe.
Exemple de titres des axes : [image: Titre des axes]

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
// Modification de la police utilisée pour
// les titre des axes du graphe "GRF_MonGraphe".
MaPolice est une Police
MaPolice.Nom = "Arial"
MaPolice.Taille = 12
MaPolice.Gras = Vrai
GRF_MonGraphe.PoliceTitreAxe(MaPolice)
```

## Syntaxe

#### Définition de la police utilisée pour le titre des axes d'un graphe

```wlangage
<Champ Graphe>.PoliceTitreAxe(<Police utilisée>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe manipulé présent dans l'éditeur de fenêtres, de pages ou d'états.
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Police utilisée>` *Police*
> Police à utiliser. Ce paramètre correspond à une variable de type [Police](1514045.md). Les caractéristiques de la police ont été définies grâce à la fonction [PoliceCrée](3060002.md) ou grâce aux [propriétés de gestion des polices](2515045.md).

#### Définition de la police utilisée pour le titre des axes d'un graphe (syntaxe pour compatibilité)

```wlangage
<Champ Graphe>.PoliceTitreAxe(<Identifiant de la police>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe manipulé présent dans l'éditeur de fenêtres, de pages ou d'états.
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Identifiant de la police>` *Entier*
> Identifiant de la police, défini avec la fonction [grCréePolice](3042001.md). Si cette police n'existe pas, une erreur du WLangage est générée.

## Remarques

### Titre d'un graphe
Le titre des axes du graphe peut être affiché le long des différents axes.
[image: Titre des axes]Le contenu du titre des axes du graphe est défini par la fonction [<Graphe>.TitreAxe](1000024153.md). Cette fonction permet également de positionner ce titre.
La police utilisée pour le titre du graphe peut être modifiée grâce à la fonction **<Graphe>.PoliceTitreAxe**.

### Initialisation des polices
La police utilisée par défaut pour le titre des axes a les caractéristiques suivantes :

- Nom de la police : Arial,
- Taille : 14,
- Style : Normal,
- Couleur : Noir.
