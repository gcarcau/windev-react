# <Image>.AnimationChangeType (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Mac Catalyst)

Change le type d'animation d'une image dans un champ Image.
Les paramètres spécifiques au nouveau type peuvent être modifiés avec la fonction [<Image>.AnimationChangeParamètre](3017006.md).
Nouveauté 2025

> _(Android)_ Cette fonction est désormais disponible pour les applications Android.

> _(iPhone/iPad)_ Cette fonction est désormais disponible pour les applications iPhone/iPad.

## Exemple

```wlangage
// Change l'animation du champ IMG_Image1
IMG_Image1.Animation = Vrai
IMG_Image1.AnimationChangeType(actDéfilement)
```

## Syntaxe

```wlangage
<Champ manipulé>.AnimationChangeType(<Type d'animation>)
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ Image à manipuler.
`<Type d'animation>` *Constante ou chaîne de caractères*
> Animation à réaliser.
>
>
> | *actAnimationWinDev* (ou "Image à animer") | L'image est découpée en plusieurs dessins. Chaque dessin est affiché successivement, donnant une impression de vidéo.  Cette constante est utilisable uniquement avec les champs Image. _(Android, iPhone/iPad)_ Cette constante n'est pas disponible. |
> | --- | --- |
> | *actClignotement* (ou "Clignotement") | Le libellé s'affiche alternativement dans sa couleur par défaut et dans sa couleur de clignotement. |
> | *actDéfilement* (ou "Défilement") | L'image (ou le libellé) apparaît progressivement, affichée à partir de la droite, de la gauche, etc. _(Android, iPhone/iPad)_ Cette constante est utilisable uniquement avec les champs Libellé. |

## Remarques

### Changer le type de l'animation
Si le nouveau type correspond au type utilisé actuellement, les paramètres spécifiques à ce type sont ré-initialisés avec les paramètres par défaut.

### Arrêt ou reprise d'une animation
L'animation peut être activée ou désactivée grâce à la propriété [Animation](2510006.md).

> _(Etats et Requêtes, Windows, Code Utilisateur (MCU))_ Images utilisant un format animéLa fonction <Image>.AnimationChangeType n'a aucun effet sur les images utilisant un format animé. Ainsi, pour une image au format GIF animé, les paramètres sont lus dans le fichier et ne peuvent être modifiés.
