# Types associés au Traitement de texte

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

## Présentation

WINDEv et WEBDEV mettent à votre disposition différents types de variables pour manipuler les documents de type Traitement de texte.
Ces types sont les suivants :

| [docCellule](1000022927.md) | Le type **docCellule** permet de définir toutes les caractéristiques avancées d'une cellule d'un tableau présent dans un document de type Traitement de texte. |
| --- | --- |
| [docElément](1000022484.md) | Le type **docElément** permet de manipuler chaque élément composant une variable de type [docParagraphe](1000022483.md). |
| [docElémentFormule](1000022937.md) | Le type **docElémentFormule** permet de définir toutes les caractéristiques d'un élément de type Formule présent dans une variable de type [docElément](1000022484.md). |
| [docElémentImage](1000022696.md) | Le type **docElémentImage** permet de manipuler les caractéristiques avancées d'un élément de type Image présent dans une variable de type [docElément](1000022484.md). |
| [docElémentLien](1000022970.md) | Le type **docElémentLien** permet de connaître toutes les caractéristiques avancées d'un élément de type Lien présent dans une variable de type [docElément](1000022484.md). |
| [docElémentTexte](1000022493.md) | Le type **DocElémentTexte** permet de manipuler les caractéristiques d'un élément de type Texte présent dans une variable de type [DocElément](1000022484.md). |
| [docElémentZoneDeTexte](1000023420.md) | Le type **docElémentZoneDeTexte** permet de définir toutes les caractéristiques avancées d'une zone de texte présente dans une variable de type [docElément](1000022484.md). |
| [docFormatMulticolonne](1000023580.md) | Le type **docFormatMulticolonne** permet de définir toutes les caractéristiques avancées d'une section multicolonne définie dans une variable de type [docSection](1000022685.md). |
| [docFragment](1000022482.md) | Le type **docFragment** permet de définir toutes les caractéristiques d'un fragment d'un document "docx". |
| [docLigne](1000022925.md) | Le type **docLigne** permet de définir toutes les caractéristiques avancées d'une ligne d'un tableau présent dans un document de type Traitement de texte. |
| [docNiveauNumérotation](1000022799.md) | Le type **docNiveauNumérotation** permet de définir toutes les caractéristiques avancées d'un niveau de numérotation utilisable dans un document de type traitement de texte. |
| [docNumérotation](1000022794.md) | Le type **docNumérotation** permet de définir toutes les caractéristiques avancées d'une numérotation utilisable dans un document de type Traitement de texte. |
| [docParagraphe](1000022483.md) | Le type **docParagraphe** permet de manipuler toutes les caractéristiques d'un paragraphe d'un document DOCX. |
| [docSection](1000022685.md) | Le type **docSection** permet de définir toutes les caractéristiques avancées d'une section d'un document ou d'un paragraphe. |
| [docStyle](1000022486.md) | Le type **docStyle** permet de connaître toutes les caractéristiques d'un style faisant partie d'un document, d'un paragraphe ou d'un fragment de document. |
| [docTableau](1000022924.md) | Le type **docTableau** permet de définir toutes les caractéristiques avancées d'un paragraphe de type Tableau présent dans un document de type Traitement de texte. |
| [docTabulation](1000022573.md) | Le type **docTabulation** permet de définir les caractéristiques d'une tabulation personnalisée. |
| [Document](1000022461.md) | Le type **Document** permet de manipuler un document de type "docx". |
Cette page d'aide présente l'imbrication de ces différents types de variables. Un document de type Traitement de texte peut être manipulé de deux façons :

- directement via une variable de type [Document](1000022461.md).
- après une recherche ou une sélection, via une variable de type [docFragment](1000022482.md).
