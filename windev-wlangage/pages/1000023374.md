# Poids (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **Poids** permet de connaître et de modifier le poids d'un élément. Cette propriété est utilisable sur :

- un champ TreeMap. Pour plus de détails, consultez [Poids](1000018904.md).
- une variable de type [memcachedConnexion](1000023339.md).
