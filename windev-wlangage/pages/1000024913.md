# Générateur (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **Générateur** permet de connaître le logiciel générateur d'un élément. Cette propriété est utilisable sur :

- une variable de type [rssCanal](1000017769.md).
- une variable de type [pdfDocument](1000024909.md).
