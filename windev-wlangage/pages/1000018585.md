# IDApprobateurSuivant (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

La propriété **IDApprobateurSuivant** permet de gérer les utilisateurs réalisant la prochaine action. Cette propriété est utilisable sur :

- une variable de type [sfRequêteTraitementSoumission](1000018516.md).
- une variable de type [sfRequêteTraitementTâche](1000018520.md).
