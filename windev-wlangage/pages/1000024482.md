# <Variable WDPic>.Fusionne (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Fusionne une image dans une autre image. Il est ainsi possible de créer des effets de fondu entre 2 images.

## Exemple

```wlangage
MonImageWDPic est un WDPic = "Test.bmp"// Déclaration de l'image de promoMonImagePromo est une Image = "ImagePromo.png"// Fusion de l'image de promo dans l'image du produit avec une opacité à 80 %MonImageWDPic.Fusionne(MonImagePromo, 80)IMG_MonDessin = MonImageWDPic
```

## Syntaxe

```wlangage
<Image Destination>.Fusionne(<Image Source> [, <Opacité>])
```

`<Image Destination>` *Variable de type WDPic*
> Nom de la variable de type [WDPic](1000023503.md) dans laquelle la fusion doit être effectuée. Seul le calque d'arrière-plan sera manipulé. Lors de la fusion, cette image sera considérée comme l'image d'arrière-plan.
`<Image Source>` *Champ Image ou variable de type Image, WDPic ou picCalque*
> Image à fusionner. Cette image peut correspondre :
>
> - au nom d'un champ Image.
> - au nom d'une variable de type [Image](1000019650.md).
> - au nom d'une variable de type [WDPic](1000023503.md). Seul le calque d'arrière-plan sera manipulé.
> - au nom d'une variable de type [picCalque](1000024604.md).
`<Opacité>` *Réel optionnel*
> Pourcentage d'opacité à appliquer sur <Image Source> avant d'effectuer la fusion (100% par défaut, aucune opacité n'est appliquée).

## Remarques

- La taille de l'image destination correspond à la taille de référence.
- La fonction **<Variable WDPic>.Fusionne** effectue la fusion en conservant la couche alpha de l'image destination. La couche alpha de l'image source n'est donc pas utilisée.
