# Propriétés associées au champ Potentiomètre (dans une page)

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

## Présentation

Un champ Potentiomètre linéaire et un champ Potentiomètre d'intervalle peuvent être manipulés en WLangage dans une page avec les propriétés suivantes.

## Propriétés disponibles dans une page pour un champ Potentiomètre linéaire

### Propriétés disponibles dans une page
Les différentes propriétés associées aux champs Potentiomètre Linéaire sont les suivantes :

BulleLa propriété Bulle permet de connaître et de modifier le texte affiché dans une bulle d'aide. Cette bulle d'aide peut être associée : à un champ d'une fenêtre ou d'une page,Nouveauté Abonnementà un champ d'un état.
