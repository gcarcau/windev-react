# HTTPCookieRécupère (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Récupère les cookies lus :

- par un appel à la fonction [HTTPRequête](3043007.md) pour un domaine HTTP.
- par un appel à la fonction [HTTPEnvoie](1000021183.md) pour un domaine HTTP.
- dans la variable [httpRéponse](1000021165.md) (contenant le résultat de la fonction [HTTPEnvoie](1000021183.md)).

**Remarque** : Les cookies lus et envoyés par la fonction [HTTPRequête](3043007.md) sont uniquement conservés en mémoire dans l'application. Ils n'ont pas de rapport avec les cookies des navigateurs Web installés sur le poste.

## Exemple

```wlangage
// Requête vers le site google.fr
HTTPRequête("www.google.fr")

// Lecture du tableau de cookies renvoyé par le site
tabCookie est un tableau de Cookie
tabCookie = HTTPCookieRécupère(".www.google.fr")
Info("Le site www.google.fr stocke actuellement " + tabCookie.Occurrence + " cookies localement.")
```

## Syntaxe

#### Récupérer les cookies lus par un appel à la fonction HTTPRequête

```wlangage
<Résultat> = HTTPCookieRécupère(<Domaine>)
```

`<Résultat>` *Tableau de variables de type Cookie*
> Liste des cookies stockés en mémoire pour le domaine spécifié.
`<Domaine>` *Chaîne de caractères*
> Domaine pour lequel la liste des cookies actuellement en mémoire doit être récupérée.

> _(WINDEV, WEBDEV - Code Serveur, Android, Widget Android, iPhone/iPad, Ajax)_ Récupérer les cookies lus par un appel à la fonction HTTPEnvoie Masquer les détails
<Résultat> = HTTPCookieRécupère(<Requête HTTP> , <Domaine>)

 <Résultat> : Tableau de variables de type CookieListe des cookies stockés en mémoire pour le domaine spécifié. <Requête HTTP> : Variable de type httpRequêteNom de la variable httpRequête pour laquelle les cookies doivent être listés. <Domaine> : Chaîne de caractèresDomaine pour lequel la liste des cookies actuellement en mémoire doit être récupérée.

> _(WINDEV, WEBDEV - Code Serveur, Android, Widget Android, iPhone/iPad, Ajax)_ Récupérer les cookies lus via une variable de type httpRéponse Masquer les détails
<Résultat> = HTTPCookieRécupère(<Réponse HTTP>)

 <Résultat> : Tableau de variables de type CookieListe des cookies stockés en mémoire pour le domaine spécifié. <Réponse HTTP> : Variable de type httpRéponseNom de la variable httpRéponse pour laquelle les cookies doivent être listés.
