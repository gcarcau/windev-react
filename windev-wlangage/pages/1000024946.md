# Constantes utilisées par les fonctions de gestion des pays et continents

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

Les constantes de gestion des pays et des continents sont les suivantes :

| Constante | Détail | Fonction |
| --- | --- | --- |
| **continentAfrique** | Afrique (la constante vaut "AF"). | [ContinentRécupère](1000024933.md),  [PaysListe](1000024930.md),  Type [Continent](1000024919.md) |
| **continentAmériqueNord** | Amérique du Nord (la constante vaut "NA"). | [ContinentRécupère](1000024933.md),  [PaysListe](1000024930.md),  Type [Continent](1000024919.md) |
| **continentAmériqueSud** | Amérique du Sud (la constante vaut "SA"). | [ContinentRécupère](1000024933.md),  [PaysListe](1000024930.md),  Type [Continent](1000024919.md) |
| **continentAntarctique** | Antarctique (la constante vaut "AN"). | [ContinentRécupère](1000024933.md),  [PaysListe](1000024930.md),  Type [Continent](1000024919.md) |
| **continentAsie** | Asie (la constante vaut "AS"). | [ContinentRécupère](1000024933.md),  [PaysListe](1000024930.md),  Type [Continent](1000024919.md) |
| **continentEurope** | Europe (la constante vaut "EU"). | [ContinentRécupère](1000024933.md),  [PaysListe](1000024930.md),  Type [Continent](1000024919.md) |
| **continentIndéfini** | Le continent n'a pas pu être identifié. | Type [Continent](1000024919.md) |
| **continentOcéanie** | Océanie (la constante vaut "OC") | [ContinentRécupère](1000024933.md),  [PaysListe](1000024930.md),  Type [Continent](1000024919.md) |
