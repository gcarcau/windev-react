# FuseauHoraire (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **FuseauHoraire** permet de paramétrer le fuseau horaire utilisé. Cette propriété est utilisable sur :

- une variable de type [gglAgenda](1000017418.md).
- une variable de type [sfInfoUtilisateur](1000018423.md).
- une variable de type [RendezVous](1000019244.md).
