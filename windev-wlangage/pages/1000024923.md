# <Variable WDPic>.Sauve (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Sauve l'image présente dans une variable de type [WDPic](1000023503.md).

## Exemple

```wlangage
MonImageWDPic est un WDPic
...
// Demande de sauvegarde de l'image
SI MonImageWDPic.Sauve("C:\temp\test.png") = Faux ALORS
	Erreur(ErreurInfo())
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Image WDPic>.Sauve(<Fichier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'image a été créée,
> - Faux dans le cas contraire (erreur, annulation du sélecteur de fichier, ...). En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai et la fonction [ErreurInfo](3013008.md) permet de connaître le détail de l'erreur.
`<Image WDPic>` *Variable de type WDPic*
> Nom de la variable de type [WDPic](1000023503.md) contenant l'image à manipuler.
`<Fichier>` *Chaîne de caractères*
> Nom et chemin du fichier image à sauver. L'extension du fichier détermine le type de l'image à sauver.
