# Fonctions de gestion des menus (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Les fonctions de gestion des menus (syntaxe préfixée) sont les suivantes :
| [<Menu>.Ajoute](1000020591.md) | Ajoute un menu contextuel existant dans le menu principal de la fenêtre en cours. |
| --- | --- |
| [<Menu>.AjouteMenu](1000020592.md) | Ajoute un nouveau menu dans un menu existant (déroulant ou contextuel) d'une fenêtre ou d'une page. |
| Nouveauté 2025 [<Menu>.AjouteMenuNavigateur](1410091027.md) | Ajoute un nouveau menu dans un menu existant. Ce nouveau menu peut exécuter une procédure navigateur passée en paramètre. |
| [<Menu>.AjouteOption](1000020593.md) | Ajoute une nouvelle option de menu à la suite de la dernière option d'un menu (déroulant ou contextuel). |
| Nouveauté 2025 [<Menu>.AjouteOptionNavigateur](1410091028.md) | Ajoute une nouvelle option de menu à la suite de la dernière option d'un menu (déroulant ou contextuel). Cette option de menu exécute une procédure navigateur WLangage. |
| [<Menu>.AjouteOptionURL](1000020594.md) | Ajoute une nouvelle option de menu à la suite de la dernière option d'un menu (déroulant ou contextuel). Cette option de menu permet d'afficher la page correspondant à l'URL indiquée. |
| [<Menu>.AjoutePopup](1000020602.md) | Transforme une option de menu d'une page pour que cette option ouvre une popup. |
| [<Menu>.AjouteSéparateur](1000020603.md) | Ajoute un nouveau séparateur dans un menu (menu déroulant ou contextuel). |
| [<Menu>.Clone](1000020604.md) | Clone un menu ou une option de menu ainsi que le code associé. |
| [<Menu>.Existe](1000020605.md) | Indique si une option de menu existe dans un menu. |
| [<Menu>.InsèreMenu](1000020606.md) | Insère un menu avant un autre menu dans une fenêtre. |
| [<Menu>.InsèreOption](1000020609.md) | Insère une nouvelle option à une position spécifique. |
| [<Menu>.InsèreSéparateur](1000020610.md) | Insère un séparateur dans un menu. |
| [<Menu>.Supprime](1000020614.md) | Supprime un menu ou une option de menu. |

Les fonctions suivantes permettent également de gérer les menus :

| [<Graphe>.Menu](1000024094.md) | Active ou désactive le menu contextuel d'un graphe. |
| --- | --- |
| [ChampContextuel](3025012.md) | Identifie le champ sur lequel le menu contextuel a été ouvert. |
| [EnumèreMenu](3038039.md) | Utilisée dans une boucle, cette fonction permet d'énumérer les options de menu d'une fenêtre, comme les sous options d'une option de menu. |
| [EnumèreSousElément](3064002.md) | Utilisée dans une boucle, cette fonction permet d'énumérer les menus déroulants ou les menus contextuels d'une fenêtre ou d'un champ. |
| [OuvreMenuContextuel](3025029.md) | Ouvre automatiquement un menu contextuel pour le champ ou la fenêtre en cours. |
| [PiloteMenu](1000009010.md) | Pilote le prochain menu qui sera ouvert, puis exécute automatiquement une option de ce menu indiquée en paramètre. |
