# <Variable Connexion>.ExécuteSauvegardePlanifiée (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Force le déclenchement d'une sauvegarde planifiée. La sauvegarde planifiée est exécutée lors de l'appel de la fonction au lieu d'être déclenchée selon sa planification.

## Exemple

```wlangage
// Description de la connexionConnexionBase est une Connexion hSvg est une hDescriptionSauvegardehSvg.AvecIndex = Faux // Sauvegarde sans indexhSvg.Source = ConnexionBase.BaseDeDonnéeshSvg.Description = ConnexionBase.BaseDeDonnéeshSvg.PlanificationComplète.Mois = "12"hSvg.PlanificationComplète.Heure = "22"hSvg.PlanificationDifférentielle.Mois = "12"hSvg.PlanificationDifférentielle.Heure = "23"// Création de la sauvegarde planifiéeConnexionBase.AjouteSauvegardePlanifiée(hSvg)// Exécution immédiateSI ConnexionBase.ExécuteSauvegardePlanifiée(hSvg.Identifiant, Faux) = Faux ALORS Erreur("Echec de <connexion>.SauvegardePlanifiée (sauvegarde complète) : " + ...   HErreurInfo(hErrComplet))FIN
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.ExécuteSauvegardePlanifiée(<Identifiant de la sauvegarde> [, <Type de sauvegarde>])
```

`<Résultat>` *Booléen*
> - Vrai si la sauvegarde planifiée a été déclenchée immédiatement,
> - Faux en cas d'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle la sauvegarde planifiée doit être effectuée.
`<Identifiant de la sauvegarde>` *Entier*
> Identifiant de la sauvegarde planifiée à exécuter.
`<Type de sauvegarde>` *Booléen optionnel*
> Type de sauvegarde à effectuer :
>
> - Vrai (valeur par défaut) : Sauvegarde différentielle.
> - Faux : Sauvegarde complète.
>
>
> **Remarque** : Une sauvegarde différentielle peut être effectuée uniquement si la tâche de sauvegarde comporte une planification différentielle.
