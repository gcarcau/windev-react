# HOpérationEncours (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Renvoie la liste des opérations automatiques en cours sur un serveur HFSQL.

## Exemple

```wlangage
// Liste de toutes les opérations en courstabOp est un tableau dynamique de hOpérationServeur tabOp = HOpérationEncours(cnx)
```

## Syntaxe

```wlangage
<Résultat> = HOpérationEncours(<Connexion>)
```

`<Résultat>` *Tableau de hOpérationServeur*
> Tableau de variables de type [hOpérationServeur](1000022471.md) contenant la description de toutes les opérations en cours sur le serveur HFSQL.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion à une base de données. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).

**Composante : wd300hf.dll**
