# Procédure WLangage appelée par la fonction URISélecteur

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Procédure WLangage (également nommée "callback") appelée par la fonction [URISélecteur](1000024026.md) pour le fichier sélectionné. Cette procédure est appelée lorsque l'utilisateur ferme la fenêtre de sélection d'URI.

## Exemple

```wlangage
// Ouvre la fenêtre système pour la sélection d'une image ou d'un pdf
URISélecteur(MaProcURISélecteur, uriImage + TAB + "application/pdf")

PROCÉDURE INTERNE MaProcURISélecteur(Succès est un booléen, Résultat1 est une URI)
	SI Succès = Vrai ALORS
		// Affiche le nom de la ressource sélectionnée
		ToastAffiche(URIRécupèreInfo(Résultat1, uriInfoNom))
	FIN
FIN
```

## Syntaxe

```wlangage
URISélecteur_Callback(<Succès> , <Résultat>)
```

`<Succès>` *Booléen*
> - Vrai si la ressource a été sélectionnée.
>   Dans ce cas, <Résultat> est une variable de type [URI](1000024027.md) correspondant à la ressource sélectionnée.
> - Faux en cas d'erreur.
`<Résultat>` *Variable de type URI*
> Variable de type [URI](1000024027.md) correspondant à la ressource sélectionnée.

**Composante : wd300std.dll**
