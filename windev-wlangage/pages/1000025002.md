# Evénements associés à un champ Action Bar

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

## Evénements gérés par défaut

**Pour le champ Action Bar**, WINDEV Mobile gère par défaut les événements suivants (ordre d'apparition sous l'éditeur de code) :

| **Evénement** | **Condition d'exécution** |
| --- | --- |
| Clic sur le bouton de gauche | Exécuté lorsque l'utilisateur clique sur le bouton gauche affiché dans l'Action Bar de la fenêtre. Après cet événement, une action prédéfinie peut être exécutée. Cette action est définie dans l'onglet "Général" (option "1", bouton à gauche). _(Android)_ Pour ne pas exécuter l'action prédéfinie, cet événement doit renvoyer la valeur Faux.  Pour plus de détails, consultez le paragraphe "Bouton gauche" de la page [Description du champ Action Bar](1000025005.md).  Remarque : Cet événement remplace l'événement "Clic sur l'icône" disponible en version 18. |
| _(Android, iPhone/iPad)_ Modification de la recherche | Exécuté lorsque l'utilisateur modifie le champ de recherche de l'Action Bar.  Cet événement est disponible uniquement si la recherche dans l'Action Bar a été activée (option "Autoriser la recherche dans l'Action Bar" dans l'onglet "Détail" de la fenêtre de description du champ Action Bar).   Remarques :    - Le champ de recherche de l'Action Bar peut être rendu visible grâce à la fonction [ActionBarRechercheVisible](1000021599.md). - La valeur saisie dans le champ de recherche peut être connue ou modifiée grâce à la propriété [ValeurRecherche](1000021602.md). |
| _(Android, iPhone/iPad)_ Validation de la recherche | Exécuté lorsque l'utilisateur valide la saisie dans le champ de recherche de l'Action Bar.  Cet événement est disponible uniquement si la recherche dans l'Action Bar a été activée (option "Autoriser la recherche dans l'Action Bar" dans l'onglet "Détail" de la fenêtre de description du champ Action Bar).   Remarques :    - Le champ de recherche de l'Action Bar peut être rendu visible grâce à la fonction [ActionBarRechercheVisible](1000021599.md). - La valeur saisie dans le champ de recherche peut être connue grâce à la propriété [ValeurRecherche](1000021602.md). |
| Modification de la vue affichée | Exécuté lors du changement de la vue affichée. Cet événement permet par exemple de modifier la fenêtre interne affichée par le champ Zone d'Action Bar. |

**Pour la zone d'Action Bar**, WINDEV Mobile gère par défaut les événements suivants (ordre d'apparition sous l'éditeur de code) :

| Evénement | Condition d'exécution |
| --- | --- |
| Après chargement de la fenêtre interne | Exécuté lors du changement de la fenêtre interne avec la fonction [ChangeFenêtreSource](3038053.md). Cet événement est exécuté après l'événement "Déclarations globales" et l'événement "Initialisation" de la nouvelle fenêtre interne. Cet événement permet par exemple d'initialiser des champs, de restaurer des valeurs dans la fenêtre interne.  La fonction [ChangeFenêtreSource](3038053.md) ne doit pas être utilisée dans cet événement. |
| Avant déchargement de la fenêtre interne | Exécuté lors du changement de la fenêtre interne avec la fonction [ChangeFenêtreSource](3038053.md). Cet événement est exécuté avant l'événement de fermeture de la fenêtre interne initiale. Cet événement permet par exemple de sauvegarder les valeurs présentes dans la fenêtre interne.  La fonction [ChangeFenêtreSource](3038053.md) ne doit pas être utilisée dans cet événement. |

## Evénements optionnels

> _(iPhone/iPad)_ Un événement optionnel est proposé pour le champ Action Bar : "Touché / Bouton gauche enfoncé".Pour gérer cet événement optionnel, il suffit de le sélectionner dans la barre d'icônes de la fenêtre de code.
Pour plus de détails, consultez les Evénements optionnels.
