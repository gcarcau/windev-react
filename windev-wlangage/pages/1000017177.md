# Constantes SNMP

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

| Constante | Description | Utilisée par la fonction |
| --- | --- | --- |
| **snmpAccèsAucun** | L'OID n'est pas accessible. | [SNMPOIDAccès](1000017077.md) |
| **snmpAccèsEcritureSeule** | L'OID est accessible en écriture seulement. | [SNMPOIDAccès](1000017077.md) |
| **snmpAccèsInconnu** | Erreur : la fonction [ErreurInfo](3013008.md) permet d'obtenir plus de renseignements sur le problème rencontré. | [SNMPOIDAccès](1000017077.md) |
| **snmpAccèsLectureEcriture** | L'OID est accessible en lecture et en écriture. | [SNMPOIDAccès](1000017077.md) |
| **snmpAccèsLectureSeule** | L'OID est accessible en lecture seulement. | [SNMPOIDAccès](1000017077.md) |
| **snmpEtatAncien** | L'OID est ancien : il a été remplacé par un ou plusieurs autres OID mais sa valeur est toujours renseignée. | [SNMPOIDEtat](1000017078.md) |
| **snmpEtatInconnu** | Erreur : la fonction [ErreurInfo](3013008.md) permet d'obtenir plus de renseignements sur le problème rencontré. | [SNMPOIDEtat](1000017078.md) |
| **snmpEtatObligatoire** | L'OID est obligatoire. | [SNMPOIDEtat](1000017078.md) |
| **snmpEtatObsolète** | L'OID est obsolète et ne doit plus être renseigné. | [SNMPOIDEtat](1000017078.md) |
| **snmpEtatOptionnel** | L'OID est optionnel. | [SNMPOIDEtat](1000017078.md) |
| **snmpTypeAdresseIP** | L'OID contient une adresse IP. | [SNMPEcrit](1000017071.md), [SNMPLit](1000017069.md), [SNMPLitSuivant](1000017070.md), [SNMPOIDType](1000017080.md) |
| **snmpTypeBits** | L'OID contient des bits. | [SNMPEcrit](1000017071.md), [SNMPLit](1000017069.md), [SNMPLitSuivant](1000017070.md), [SNMPOIDType](1000017080.md) |
| **snmpTypeChaîne** | L'OID contient une chaîne. | [SNMPEcrit](1000017071.md), [SNMPLit](1000017069.md), [SNMPLitSuivant](1000017070.md), [SNMPOIDType](1000017080.md) |
| **snmpTypeCompteur32** | L'OID est un compteur (entier signé sur 32 bits). | [SNMPEcrit](1000017071.md), [SNMPLit](1000017069.md), [SNMPLitSuivant](1000017070.md), [SNMPOIDType](1000017080.md) |
| **snmpTypeCompteur64** | L'OID est un compteur (entier signé sur 64 bits). | [SNMPEcrit](1000017071.md), [SNMPLit](1000017069.md), [SNMPLitSuivant](1000017070.md), [SNMPOIDType](1000017080.md) |
| **snmpTypeEntierSansSigne** | L'OID contient un entier sans signe. | [SNMPEcrit](1000017071.md), [SNMPLit](1000017069.md), [SNMPLitSuivant](1000017070.md), [SNMPOIDType](1000017080.md) |
| **snmpTypeEntier** | L'OID contient un entier. | [SNMPEcrit](1000017071.md), [SNMPLit](1000017069.md), [SNMPLitSuivant](1000017070.md), [SNMPOIDType](1000017080.md) |
| **snmpTypeInconnu** | Erreur : la fonction [ErreurInfo](3013008.md) permet d'obtenir plus de renseignements sur le problème rencontré. | [SNMPOIDType](1000017080.md) |
| **snmpTypeJauge** | L'OID contient une jauge. | [SNMPEcrit](1000017071.md), [SNMPLit](1000017069.md), [SNMPLitSuivant](1000017070.md), [SNMPOIDType](1000017080.md) |
| **snmpTypeNull** | L'OID n'est pas associé à une valeur (par exemple une branche qui a des enfants mais qui n'a pas de valeur par elle-même). | [SNMPEcrit](1000017071.md), [SNMPLit](1000017069.md), [SNMPLitSuivant](1000017070.md), [SNMPOIDType](1000017080.md) |
| **snmpTypeOID** | L'OID contient une OID. | [SNMPEcrit](1000017071.md), [SNMPLit](1000017069.md), [SNMPLitSuivant](1000017070.md), [SNMPOIDType](1000017080.md) |
| **snmpTypeOpaque** | L'OID contient une valeur qui n'est pas directement interprétable. | [SNMPEcrit](1000017071.md), [SNMPLit](1000017069.md), [SNMPLitSuivant](1000017070.md), [SNMPOIDType](1000017080.md) |
| **snmpTypeTicks** | L'OID contient un nombre de ticks d'horloge. | [SNMPEcrit](1000017071.md), [SNMPLit](1000017069.md), [SNMPLitSuivant](1000017070.md), [SNMPOIDType](1000017080.md) |
