# Erreur 105 : Redéfinition de la variable locale

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Cause

Vous tentez de déclarer une variable locale qui a déjà été déclarée dans le traitement en cours.

## Correction

Renommez une des variables ou supprimez la déclaration inutile.

## Exemples

### Deux variables locales de même nom mais de type différent sont utilisées

**Code provoquant l'erreur**

```wlangage
b est un entier b est une chaîne
```

**Correction proposée**

Renommez la seconde variable.

```wlangage
b est un entier c est une chaîne
```

### Deux variables locales ont le même nom et le même type

**Code provoquant l'erreur**

```wlangage
I est un entierPOUR I = 1 À 10...FIN... I est un entierPOUR I = 1 À 10...FIN
```

**Correction proposée**

Supprimez la seconde déclaration (déclaration inutile).

```wlangage
I est un entierPOUR I = 1 À 10...FIN... POUR I = 1 À 10...FIN
```
