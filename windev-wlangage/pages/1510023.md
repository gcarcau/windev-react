# Instruction POUR TOUT / POUR TOUS (parcours d'énumérations)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (iPhone/iPad, Apple Watch)

L'instruction **POUR TOUT** permet de parcourir les valeurs disponibles dans les énumérations.
**Remarque** : Les instructions **POUR TOUT, POUR TOUS, POUR CHAQUE** sont acceptées. Dans cette documentation, seule l'instruction **POUR TOUT** est utilisée et peut être remplacée par **POUR TOUS** ou **POUR CHAQUE**.

## Exemple

```wlangage
// Parcours des options d'une énumération
// ---------------------------------------
// Code de déclaration
// Déclarer une énumération
TypeAutomate est une Enumération
	Marche
	Arrêté
	EnMaintenance
	EnPanne
FIN
```

```wlangage
// Parcours des valeurs
POUR TOUT Option DE TypeAutomate
	Trace(Option..Nom)
FIN
```

## Syntaxe

```wlangage
POUR TOUT <MaValeur> DE <Enumération> ...FIN
```

`<POUR TOUT>` **
> Signale le début du bloc d'instructions.
`<MaValeur>` **
> Variable de type [Description de Valeur](1000023061.md) correspondant à la valeur de l'énumération. Il n'est pas nécessaire de déclarer cette variable.
`<Enumération>` **
> [Enumération](1514067.md) contenant les valeurs à parcourir.
