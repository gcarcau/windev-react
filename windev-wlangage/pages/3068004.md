# Fonctions SMS

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Ces fonctions permettent d'envoyer et de lire facilement des SMS :

| Nouveauté 2025 [SMSDétecteCodeUsageUnique](1410090437.md) | Remplit automatiquement un champ de saisie avec un code à usage unique reçu par SMS. |
| --- | --- |
| [SMSEnvoie](3068002.md) | Envoie un SMS. |
| [SMSLanceAppli](1000020864.md) | Lance l'application native d'envoi de SMS de l'appareil (Android ou iPhone/iPad). |
| [SMSNbMessage](3068009.md) | Renvoie le nombre de SMS stockés dans la mémoire du téléphone Android. |
| [SMSPremier](3068006.md) | Lit le premier SMS stocké dans la mémoire du téléphone Android. |
| [SMSRAZ](3068001.md) | Ré-initialise toutes les variables de la [structure SMS](3068003.md). |
| [SMSSuivant](3068007.md) | Lit le SMS suivant stocké dans la mémoire du téléphone Android. |
| [SMSSupprime](3068008.md) | Supprime un SMS stocké dans la mémoire du téléphone Android. Cette fonction ne doit plus être utilisée. |
