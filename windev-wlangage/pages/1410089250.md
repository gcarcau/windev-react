# EtatsUnis.VérifieFEI (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un numéro FEI (numéro d'identification d'établissement d'entreprise aux Etats-Unis).

## Exemple

```wlangage
// Test d'une variableMonNuméroFEI est une chaîne = "3003591836"EtatsUnis.VérifieFEI(MonNuméroFEI) // renvoie Vrai // Test d'un champSAI_NuméroFEI = "ABC"EtatsUnis.VérifieFEI(SAI_NuméroFEI) // renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = EtatsUnis.VérifieFEI(<Numéro à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un numéro FEI valide.
> - Faux dans le cas contraire.
`<Numéro à vérifier>` *Nom de champ ou variable de type chaîne*
> Numéro FEI à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.

**Composante : wd300std.dll**
