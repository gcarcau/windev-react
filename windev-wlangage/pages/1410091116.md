# Paramètres de la procédure utilisée par la fonction HStatCalculeAsynchrone

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Procédure WLangage (également nommée "callback") appelée par la fonction [HStatCalculAsynchrone](1410091108.md) pour chaque fichier de données HFSQL Client/Serveur vérifié.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
CnxBaseDeDonnées est une Connexion
TableauFichier est un tableau de hParamètreFichier

MonFichierParam est un hParamètreFichier
MonFichierParam.Nom = "ActionPossible"
// MonFichierParam.MotDePasse = ""
// La propriété Option n'est pas prise en compte
TableauAjoute(TableauFichier, MonFichierParam)

SI bTâcheDeFond ALORS
	HStatCalculeAsynchrone(CnxBaseDeDonnées, TableauFichier, hTâcheDeFond, Callback_HStatCalculeAsynchrone)
SINON
	HStatCalculeAsynchrone(CnxBaseDeDonnées, TableauFichier, Callback_HStatCalculeAsynchrone)
FIN
	PROCÉDURE INTERNE Callback_HStatCalculeAsynchrone(MonFichier est une chaîne, MonRésultat est un booléen)
		SI MonRésultat ALORS
			Trace("Statistiques calculées pour le fichier de données " + MonFichier)
		SINON
			Trace("Problème dans le calcul des statistiques du fichier de données " + MonFichier + ErreurInfo())
		FIN
	FIN
```

## Syntaxe

```wlangage
HStatCalculeAsynchrone_Callback(<Fichier de données> , <Résultat du calcul>)
```

`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données HFSQL Client/Serveur manipulé.
`<Résultat du calcul>` *Booléen*
> - Vrai si le calcul a été effectué,
> - Faux en cas de problème (fichier de données bloqué par une application par exemple). La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
