# ContexteExiste (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux)

Permet de savoir si un contexte de page existe sur le serveur (c'est-à-dire si la page a été ouverte).

## Exemple

```wlangage
// Actualise la page si le contexte existe sinon ouvre la pageSI ContexteExiste(PAGE_Page3) = Vrai ALORS PageActualise(PAGE_Page3)SINON PageAffiche(PAGE_Page3)FIN
```

## Syntaxe

```wlangage
<Résultat> = ContexteExiste(<Page>)
```

`<Résultat>` *Booléen*
> - Vrai si le contexte de la page spécifiée existe (c'est-à-dire si la page spécifiée est ouverte),
> - Faux dans le cas contraire.
`<Page>` *Nom de page*
> - Nom de la page dont l'existence du contexte doit être vérifiée.
> - Chaîne vide ("") pour désigner la page à laquelle appartient le traitement en cours.

**Composante : wd300page.dll**
