# Editeur de code : Options d'affichage

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

L'éditeur de code propose différentes options d'affichage :

- [Réutilisation d'une fenêtre de code](2013006.md).
- Affichage des traitements des modèles surchargés.
- Affichage des procédures et méthodes d'un élément.
- Affichage des numéros de ligne.
- Affichage de la date et de l'auteur.
- Affichage des traitements vides.
- Nouveauté 2025
  Affichage du code des sous-éléments.
- Nouveauté 2025
  [Entête épinglé](9000224.md).
- Nouveauté Abonnement
  Tri par ordre alphabétique.
  **Attention** : Cette fonctionnalité est disponible dans la version Abonnement, uniquement à partir de WINDEV Suite 2025 Update 1.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Afficher/Masquer les événements WLangage vides

### Présentation
L'éditeur de code permet d'afficher le code d'une multisélection (plusieurs champs, plusieurs procédures globales, plusieurs méthodes de classes, etc.). Chaque élément propose un certain nombre d'événements WLangage.
L'affichage de ces événements peut rapidement devenir illisible en raison de leur nombre, alors que la plupart de ces événements sont vides.

Par défaut, les événements vides ne sont pas affichés.

### Afficher les événements WLangage vides
Pour afficher les événements WLangage vides :

1. Placez-vous sous l'éditeur de code.
2. Sous le volet "Affichage", dans le groupe "Aide à l'édition", cochez ou décochez "Afficher les traitements vides". Si les événements WLangage vides sont déjà affichés, ils sont automatiquement masqués et inversement.

Il est également possible d'utiliser la combinaison de touches Ctrl + F6.

Pour plus de détails, consultez [Afficher ou non les événements ou traitements vides d'un élément](9000190.md).

## Afficher/Masquer les événements WLangage des modèles surchargés

### Présentation
Si l'élément affiché dans l'éditeur de code est associé à un modèle, il est possible d'afficher les événements WLangage des modèles surchargés.

### Afficher les événements WLangage des modèles surchargés
Pour afficher les événements WLangage des modèles surchargés :

1. Placez-vous sous l'éditeur de code.
2. Sous le volet "Affichage", dans le groupe "Aide à l'édition", cochez ou décochez "Afficher les traitements des modèles". Si ces événements sont déjà affichés, ils sont automatiquement masqués et inversement.

## Afficher/Masquer les numéros de ligne

### Présentation
L'éditeur de code permet d'afficher un numéro de ligne devant chaque ligne de code.
Par défaut, les numéros de ligne ne sont pas affichés.

### Afficher les numéros de ligne
Pour afficher les numéros de ligne :

1. Placez-vous sous l'éditeur de code.
2. Sous le volet "Affichage", dans le groupe "Aide à l'édition", cliquez sur "Afficher les numéros de ligne". Si les numéros de ligne sont déjà affichés, ils sont automatiquement masqués et inversement.

Il est également possible d'utiliser la combinaison de touches Ctrl + Maj + G.

Nouveauté Abonnement
Remarque : Le numéro de la ligne en cours est mis en valeur.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Afficher/Masquer les procédures et méthodes de l'élément

### Présentation
L'éditeur de code permet d'afficher les procédures et méthodes de l'élément en cours dans la même fenêtre de code.
Par défaut, les procédures et méthodes de l'élément en cours sont affichées.

### Afficher les procédures et méthodes de l'élément en cours
Pour afficher les procédures et méthodes de l'élément en cours :

1. Placez-vous sous l'éditeur de code.
2. Sous le volet "Affichage", dans le groupe "Aide à l'édition", cliquez sur "Afficher les procédures/méthodes de l'élément". Si les procédures et méthodes de l'élément sont déjà affichées, ils sont automatiquement masqués et inversement.

## Afficher/Masquer la date et l'auteur

### Présentation
L'éditeur de code permet d'afficher la date et l'auteur de chaque ligne de code.
Par défaut, ces informations ne sont pas affichées.

### Afficher la date et l'auteur
Pour afficher la date et l'auteur d'une ligne de code :

1. Placez-vous sous l'éditeur de code.
2. Sous le volet "Affichage", dans le groupe "Aide à l'édition", cliquez sur "Afficher la date et l'auteur". Si la date et l'auteur sont déjà affichés, ils sont automatiquement masqués et inversement.

Il est également possible d'utiliser la touche F6.
Nouveauté 2025

## Afficher/Masquer le code des sous-éléments

### Présentation
L'éditeur de code permet d'afficher les codes de tous les sous éléments de l'élément en cours. Par exemple, pour une fenêtre, il est possible d'afficher dans la fenêtre de code, le code de tous les champs présents dans cette fenêtre
Par défaut, ces informations ne sont pas affichées.

### Afficher le code des sous-éléments
Pour afficher le code des sous-éléments de l'élément en cours :

1. Placez-vous sous l'éditeur de code pour afficher le code de l'élément en cours.
2. Sous le volet "Affichage", dans le groupe "Aide à l'édition", cliquez sur "Afficher le code des sous-éléments". Si le code des sous-éléments est déjà affiché, il sera masqué et inversement.

Il est également possible d'utiliser l'option "Tous les codes" du menu contextuel de l'élément présent dans le volet "Explorateur de projet".

L'option "Afficher les traitements vides" est prise en compte lors de l'affichage de tous les codes.

**Remarque** : Cette option remplace l'option "Tous les codes" présente dans l'onglet "Code" du ruban disponible dans les versions 2024 et précédentes.

Nouveauté Abonnement

## Tri par ordre alphabétique

### Présentation
Par défaut, les différentes procédures d'une collection de procédures ou les méthodes d'une classes, sont classées suivant leur ordre de création dans l'éditeur de code. Pour une meilleure lecture du code, il est possible d'afficher ces procédures et méthodes par ordre alphabétique dans l'éditeur de code.
Plus besoin de faire défiler le code ou de faire une recherche pour trouver une procédure !

### Trier alphabétiquement les méthodes et les procédures
Pour trier alphabétiquement les procédures et méthodes affichée dans la vue de code en cours :

1. Placez-vous sous l'éditeur de code et affichez les codes de la collection de procédures ou de la classe.
2. Sous le volet "Affichage", dans le groupe "Aide à l'édition", cliquez sur "Ordre alphabétique".
3. Les différentes méthodes et procédures affichées dans l'éditeur de code seront triées alphabétiquement.

Remarques :

- Si des événements WLangage sont également affichés dans l'éditeur de code, ces événements gardent leur mode de tri.
- Cette fonctionnalité permet de changer le mode d'affichage de toutes les procédures ou méthodes. Il est également possible de déplacer une seule procédure ou méthode. Pour plus de détails, consultez [Déplacement de procédures et de méthodes](2010031.md).

**Attention** : Cette fonctionnalité est disponible dans la version Abonnement, uniquement à partir de WINDEV Suite 2025 Update 1.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
