# EmailChangeEtat (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Change l'état d'un email sur un serveur de messagerie.

## Exemple

```wlangage
// Passer tous les emails d'une session IMAP en lus
MaSession est une emailSessionIMAP
...
POUR TOUT MessageEmail NON LU DE MaSession
	EmailChangeEtat(MaSession, MessageEmail, emailEtatLu)
FIN
```

## Syntaxe

```wlangage
<Résultat> = EmailChangeEtat(<Session> , <Email> , <Nouvel état>)
```

`<Résultat>` *Booléen*
> - Vrai si l'état a été modifié sur le serveur,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Session>` *Variable de type emailSessionOutlook ou emailSessionIMAP*
> Identifie la session d'un utilisateur. Correspond :
>
> - à une variable de type [emailSessionOutlook](1000018767.md).
> - à une variable de type [emailSessionIMAP](1000018957.md).
`<Email>` *Variable de type Email*
> Nom de la variable de type [Email](1000018713.md) correspondant à l'email à manipuler.
`<Nouvel état>` *Constante de type Entier*
> Etat à affecter à l'email, les valeurs possibles sont :
>
> | *emailEtatLu* | Indique que le message a été lu. |
> | --- | --- |
> | *emailEtatNonLu* | Indique que le message n'a pas encore été lu. |

## Remarques

Cette fonction n'est pas disponible :

- sur les sessions Notes (variable de type [emailSessionNotes](1000018768.md)),
- sur les sessions POP3 (variable de type [emailSessionPOP3](1000018759.md)),
- sur les sessions SMTP (variable de type [emailSessionSMTP](1000018765.md)).
