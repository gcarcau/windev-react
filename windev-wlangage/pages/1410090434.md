# <Variable Notification>.Supprime (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Supprime une notification affichée dans la barre système de l'appareil.

## Exemple

```wlangage
notif est une Notification
notif.Titre = "Nouveau message reçu"
notif.Message = "Cliquez pour afficher le message"
notif.Ajoute()
...
notif.Supprime()
```

## Syntaxe

```wlangage
<Résultat> = <Notification>.Supprime()
```

`<Résultat>` *Booléen*
> - Vrai si la notification a été supprimée,
> - Faux dans le cas contraire.
>
>
> **Remarque** : Dans le simulateur, cette fonction est sans effet et renvoie toujours Faux.
`<Notification>` *Variable de type Notification*
> Nom de la variable de type [Notification](1000019441.md) correspondant à la notification à supprimer.
