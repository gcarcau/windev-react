# Fonctions XML

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

## Principe de manipulation d'un document XML

Deux méthodes peuvent être utilisées pour manipuler un document XML :

1. [Utilisation d'une variable de type xmlDocument](3081018.md) (**Méthode conseillée**). Cette méthode permet d'utiliser un fichier de type XSD.
   Plusieurs types de variables spécifiques sont disponibles :
  | [xmlAttribut](1000018799.md) | Le type **xmlAttribut** permet de manipuler les attributs d'un noeud dans un document XML. |
  | --- | --- |
  | [xmlDocument](1000018782.md) | Le type **xmlDocument** permet de manipuler simplement un fichier XML. |
  | [xmlNamespace](1000018803.md) | Le type **xmlNamespace** permet de manipuler l'espace de nommage XML d'un attribut de noeud dans un document XML. |
  | [xmlNoeud](1000018786.md) | Le type **xmlNoeud** permet de manipuler un noeud d'un document XML. |
  Plusieurs fonctions spécifiques permettent de manipuler les variables de type xmlDocument
  | [XMLConstruitChaîne](3081016.md) | Récupère et met en forme le contenu d'un document XML (créé avec la fonction [XMLDocument](3081008.md) et modifié grâce aux fonctions XML). |
  | --- | --- |
  | [XMLDocumentValide](1000019272.md) | Valide un document XML à partir d'un schéma XSD. |
  | [XMLOuvre](1000018792.md) | Charge un document XML à partir d'un fichier, d'une URL ou d'une chaîne dans une variable de type [xmlDocument](1000018782.md). |
  | [XMLSauve](1000019026.md) | Sauvegarde un document XML dans un fichier. |
2. [Utilisation d'une variable de type chaîne pour stocker le document XML](3081018.md). Le document XML peut être ensuite manipulé grâce aux différentes fonctions XML.
  Les différentes fonctions de gestion des documents XML sont les suivantes :
  | [TexteVersXML](3081006.md) | Convertit une chaîne de caractères au format ANSI en une chaîne de caractères au format XML. |
  | --- | --- |
  | [XMLAjouteAttribut](3081011.md) | Ajoute un attribut dans un document XML. |
  | [XMLAjouteFils](3081002.md) | Ajoute une balise fille dans un document XML. |
  | [XMLAnnuleRecherche](3081001.md) | Annule la recherche effectuée par la fonction [XMLRecherche](3081025.md). |
  | [XMLChercheNamespaceParNom](1000019167.md) | Recherche un namespace (espace de nommage) XML à partir de son nom dans un noeud XML et dans les parents de ce noeud. |
  | [XMLChercheNamespaceParURI](1000019168.md) | Recherche un namespace (espace de nommage) XML à partir de son URI (Universal Resource Identifier) dans un noeud et dans les parents de ce noeud. |
  | [XMLConstruitChaîne](3081016.md) | Récupère et met en forme le contenu d'un document XML (créé avec la fonction [XMLDocument](3081008.md) et modifié grâce aux fonctions XML). |
  | [XMLDernier](3081013.md) | Positionne sur le dernier élément (balise ou attribut) du niveau en cours de l'arborescence. |
  | [XMLDocument](3081008.md) | Crée un nouveau document XML. |
  | [XMLDocumentValide](1000019272.md) | Valide un document XML à partir d'un schéma XSD. |
  | [XMLDonnée](3081004.md) | Renvoie la valeur de l'élément en cours (balise ou attribut XML) ou d'un de ses attributs. |
  | [XMLEcrit](1000017031.md) | Crée ou modifie la valeur d'un élément XML, ou la valeur de l'attribut d'un élément XML. |
  | [XMLEnDehors](3081009.md) | Permet de savoir si l'élément (balise ou attribut) sur lequel on veut se positionner est en dehors du document XML. |
  | [XMLExécuteXPath](3081015.md) | Exécute une requête XPATH :   - dans un document XML. - dans une variable de type xmlDocument. |
  | [XMLExtraitChaîne](3081017.md) | Extrait le contenu d'une balise dans un document XML. |
  | [XMLExtraitDocument](3081010.md) | Crée un nouveau document XML à partir d'une partie d'un document XML existant. |
  | [XMLFils](3081012.md) | Positionne sur le premier élément fils de l'élément en cours. |
  | [XMLFilsExiste](3081038.md) | Indique si la balise courante a des fils correspondant au type recherché (balise, attribut, ...). |
  | [XMLInsèreDocument](3081014.md) | Insère la balise XML en cours présente dans un document XML dans un autre document XML. |
  | [XMLInsèreElément](3081007.md) | Insère un élément (balise ou attribut) XML dans un document XML. |
  | [XMLLit](1000017030.md) | Renvoie la valeur d'un élément XML ou la valeur de l'attribut d'un élément XML. |
  | [XMLModifie](3081037.md) | Modifie le contenu de l'élément courant dans un document XML. |
  | [XMLNamespace](3081039.md) | Renvoie le préfixe de l'espace de nommage de la balise courante dans un document XML. |
  | [XMLNamespaceURI](3081040.md) | Renvoie l'URI de définition de l'espace de nommage de la balise courante dans un document XML. |
  | [XMLNoeudValide](1000019280.md) | Valide un noeud XML, ses fils et ses attributs à partir de sa description dans le schéma XSD lié au document XML. |
  | [XMLNomElément](3081026.md) | Renvoie le nom de l'élément en cours (balise ou attribut). |
  | [XMLNomParent](3081035.md) | Renvoie le nom de la balise parente de l'élément (balise ou attribut) en cours. |
  | [XMLOuvre](1000018792.md) | Charge un document XML à partir d'un fichier, d'une URL ou d'une chaîne dans une variable de type [xmlDocument](1000018782.md). |
  | [XMLOuvreLecteur](1000023396.md) | Crée un lecteur permettant de lire un document XML sans le charger en mémoire. |
  | [XMLParent](3081022.md) | Positionne sur l'élément parent de l'élément en cours (balise ou attribut). |
  | [XMLPosition](3081028.md) | Renvoie la position en cours dans le document sous la forme XPATH. |
  | [XMLPrécédent](3081023.md) | Positionne sur l'élément (balise ou attribut) précédent. |
  | [XMLPremier](3081024.md) | Positionne sur le premier élément (balise ou attribut) du niveau en cours de l'arborescence. |
  | [XMLRacine](3081019.md) | Positionne sur la balise racine d'un document XML. |
  | [XMLRecherche](3081025.md) | Lance une recherche dans un document XML. |
  | [XMLRenomme](3081021.md) | Modifie le nom de l'élément courant (balise ou attribut) dans un document XML. |
  | [XMLRésultat](3081027.md) | Donne le résultat d'une requête XPath de calcul. |
  | [XMLRetourPosition](3081032.md) | Restaure le contexte précédemment sauvegardé d'un document XML. |
  | [XMLSauve](1000019026.md) | Sauvegarde un document XML dans un fichier. |
  | [XMLSauvePosition](3081033.md) | Mémorise la position en cours dans le document XML. |
  | [XMLSigne](1000020753.md) | Signe un document XML. |
  | [XMLSuivant](3081030.md) | Positionne sur l'élément suivant (balise ou attribut). |

  | [XMLTermine](3081034.md) | Ferme un document XML créé avec [XMLDocument](3081008.md). |
  | [XMLTrouve](3081020.md) | Vérifie si l'élément en cours correspond au parcours ou à la recherche en cours. |
  | [XMLTypeElement](3081031.md) | Renvoie le type de l'élément en cours (balise ou attribut). |
  | [XMLVérifieSignature](1410090391.md) | Vérifie la signature d'un noeud XML. |

  | [XMLVersTexte](3081029.md) | Convertit une chaîne de caractères au format XML en une chaîne de caractères standard. |

| [J2EEExécuteXML](3047008.md) | Exécute une procédure sur un serveur de services Web XML J2EE. |

| [TableVersXML](3074037.md) | Crée un fichier XML avec les données d'un champ Table ou Table hiérarchique. |
| [ZoneRépétéeVersXML](3083032.md) | Crée un fichier XML avec les données d'un champ Zone répétée (champ Zone répétée fichier ou champ Zone répétée par programmation). |
