# IndiceEnCours (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Renvoie selon le champ spécifié :

- le numéro de la ligne en cours affichée dans le champ Table en cours,
- le numéro de l'option d'un champ Interrupteur ayant le focus,
- le numéro de la répétition en cours dans le champ Zone répétée en cours,
- l'indice du champ indicé en cours.

## Exemple

```wlangage
NumLigne est un entier = IndiceEnCours()
Trace("Numéro de la ligne en cours: " + NumLigne)
```

## Syntaxe

```wlangage
<Résultat> = IndiceEnCours()
```

`<Résultat>` *Entier*
> - Numéro de la ligne en cours affichée dans le champ Table en cours.
> - Numéro de l'option du champ Interrupteur en cours.
> - Indice du champ indicé en cours.
> - Numéro de la répétition en cours affichée dans le champ Zone répétée en cours.

## Remarques

### Utilisation dans les événements d'un champ Table
Lors de l'initialisation d'un champ Table, l'événement "Affichage d'une ligne" est exécuté pour chaque ligne affichée dans le champ Table.
Lors de l'initialisation d'un champ Table, si la fonction IndiceEnCours est utilisée dans l'événement "Affichage d'une ligne", la fonction **IndiceEnCours** renvoie 0.

### Limites
La fonction **IndiceEnCours** peut être utilisée avec :

- les champs Table, les champs Interrupteur et les champs Indicés.
- les champs Table et les champs Zone répétée.
