# Fonctions de gestion du champ Editeur d'images et des variables WDPic

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU))

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion du champ Editeur d'images et des variables WDPic (syntaxe préfixée)](1000023434.md)).
Les fonctions de gestion du champ Editeur d'images sont :

| [PicCaptureLasso](1410088683.md) | Effectue une capture d'écran via le lasso et récupère cette capture dans une variable de type [Image](1000019650.md). |
| --- | --- |
| [PicCaptureLassoOCR](1410088839.md) | Lance une capture d'écran par le lasso pour en extraire le texte via une analyse avec le système OCR intégré. |
| [PicCrée](1000023380.md) | Crée une image dans le champ Editeur d'images. |
| [PicFerme](1000023382.md) | Ferme l'image se trouvant dans un champ Editeur d'images. |
| [PicFusionneCalque](1000024865.md) | Fusionne les calques d'une image au format WDPic. |
| [PicOuvre](1000023379.md) | Ouvre une image dans un champ Editeur d'images. |
| [PicRedimensionne](1000024635.md) | Redimensionne une image au format WDPic. |
| [PicRotation](1000024633.md) | Effectue une rotation d'une image au format WDPic. |
| [PicSauve](1000023381.md) | Sauve l'image présente :   - dans un champ Editeur d'images. - dans une variable de type WDPic. |
