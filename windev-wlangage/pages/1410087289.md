# Fonctions de gestion des certificats (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Les fonctions suivantes permettent de manipuler des certificats Windows (via une syntaxe préfixée) :

| [<Variable Certificat>.ExtraitValeurExtension](1410087241.md) | Renvoie la valeur d'une extension du certificat. |
| --- | --- |
| [<Variable Certificat>.OuvrePropriétés](1000024378.md) | Ouvre la fenêtre Windows permettant de connaître les propriétés d'un certificat. |
