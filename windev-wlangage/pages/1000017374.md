# HModifieTâche (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Modifie une tâche planifiée sur le serveur HFSQL défini par la connexion. Cette tâche est présente dans une variable de type [hTâchePlanifiée](1000017448.md).
**Remarque** : La fonction [HInfoTâche](1000017409.md) permet de récupérer les caractéristiques d'une tâche planifiée dans une variable de type [hTâchePlanifiée](1000017448.md).

## Exemple

```wlangage
MaConnexion est une Connexion
MaTâche est une hTâchePlanifiée

// Récupération des caractéristiques de la tâche
MaTâche = HInfoTâche(MaConnexion, IDTâche)
// Modification de la tâche
MaTâche.Heure = SAI_Heure.Heure+1
HModifieTâche(MaConnexion, IDTâche, MaTâche)
```

## Syntaxe

```wlangage
<Résultat> = HModifieTâche(<Connexion> , <Identifiant de la tâche> , <Tâche planifiée>)
```

`<Résultat>` *Booléen*
> - Vrai si la tâche planifiée a été modifiée,
> - Faux en cas d'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion pour laquelle une tâche doit être ajoutée. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Identifiant de la tâche>` *Entier*
> Identifiant de la tâche à modifier. Cet identifiant est renvoyé par la fonction [HAjouteTâche](1000017091.md).
`<Tâche planifiée>` *Variable de type hTâchePlanifiée*
> Nom de la variable de type [hTâchePlanifiée](1000017448.md) contenant les modifications.

## Remarques

### Droits nécessaires
Pour modifier une tâche, il est nécessaire de posséder :

- le droit correspondant (constante *hDroitGèreTâche*) sur le serveur,
- le droit d'exécuter la commande liée à la tâche planifiée.

La tâche sera exécutée avec le compte de l'utilisateur qui a créé la tâche.

**Remarque** : Si le serveur est éteint, la tâche planifiée ne sera pas réalisée. La tâche planifiée sera réalisée à la prochaine date disponible lorsque le serveur sera allumé.
