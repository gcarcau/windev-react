# Erreur 1032 : L'héritage est interdit dans une structure

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

## Cause

Vous tentez de définir un héritage dans la définition d'une structure. L'héritage est interdit dans une structure.

## Correction

Supprimez la syntaxe d'héritage.

## Exemple

### Tentative d'héritage dans une structure

**Code provoquant l'erreur**

```wlangage
Coord est une Structure  PosX est un entier PosY est un entierFIN TailleObjet est une Structure   un objet coord Hauteur est un entier Largeur est un entierFIN
```

**Correction proposée**

Supprimer la syntaxe d'héritage.

```wlangage
Coord est une Structure  PosX est un entier PosY est un entierFIN TailleObjet est une Structure Hauteur est un entier Largeur est un entierFIN
```
