# RedisRécupère (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Récupère la valeur d'une clé sur un serveur Redis sous forme de chaîne.
Remarque : Pour récupérer la valeur d'une clé sous forme de chaîne binaire, utilisez la fonction [RedisExécuteCommande](1000023541.md).

Nouveauté 2025
Cette fonction peut également être utilisée pour manipuler des données sur un serveur Valkey.

## Exemple

```wlangage
gRedis est un redisConnexion
gRedis.Serveur = "MonServeurRedis:7001"

RedisAffecte(gRedis, "MaClé", "MaValeur", 0 s)
Trace(RedisRécupère(gRedis, "MaClé"))
```

## Syntaxe

```wlangage
<Résultat> = RedisRécupère(<Connexion> , <Clé>)
```

`<Résultat>` *Chaîne de caractères*
> - Valeur de la clé.
> - Null, si la clé n'a pas de valeur.
`<Connexion>` *Variable de type redisConnexion*
> Nom de la variable de type [redisConnexion](1000023527.md) correspondant à la connexion au serveur Redis.
`<Clé>` *Chaîne de caractères ou Chaîne secrète*
> Nom de la clé à récupérer.
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).
