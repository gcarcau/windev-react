# Evénements associés à un champ Editeur de diagrammes

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur)

## Evénements gérés par défaut

> _(WINDEV)_ WINDEV gère par défaut les événements suivants (ordre d'apparition sous l'éditeur de code) :EvénementCondition d'exécutionInitialisationExécuté à l'ouverture de la fenêtre. *Modification de l'étendue (zoom)Exécuté après le changement du zoom dans le champ Editeur de diagrammes (bouton de zoom, Ctrl + roulette, etc.).Avant fermeture du documentExécuté avant la fermeture du diagramme dans le champ Editeur de diagrammes. Ajout d'une formeExécuté lors de l'ajout d'une forme dans le champ Editeur de diagrammes. Sélection d'une formeExécuté lors de la sélection d'une forme dans le champ Editeur de diagrammes. Il est possible de connaître les caractéristiques de la forme sélectionnée grâce à la propriété Sélection, qui permet d'obtenir une variable de type diagSélection. Remarque : lors de la création d'une forme depuis une bibliothèque, la forme est sélectionnée. Déplacement d'une formeExécuté lors du déplacement d'une forme dans le champ Editeur de diagrammes. Redimensionnement d'une formeExécuté lors du redimensionnement d'une forme dans le champ Editeur de diagrammes. Modification d'une formeExécuté à chaque modification d'une forme dans le champ Editeur de diagrammes (par exemple lors de la validation du texte associé à la forme). Double-clic sur une formeExécuté lors d'un double-clic sur une forme dans le champ Editeur de diagrammes. A chaque modificationExécuté à chaque modification du champ Editeur de diagrammes : déplacement de forme, ajout de forme, suppression de forme, etc. (*) Par défaut, l'événement "Initialisation" de chaque champ est exécuté selon l'ordre de création des différents champs dans la fenêtre. Pour modifier cet ordre d'exécution : Sous le volet "Fenêtre", dans le groupe "Ordre", cliquez sur "Initialisation".Dans la fenêtre qui s'affiche, utilisez les flèches situées sur la droite pour modifier l'ordre d'initialisation des champs.

> _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur)_ WEBDEV gère par défaut les événements suivants (ordre d'apparition sous l'éditeur de code) :EvénementCondition d'exécutionInitialisation (Code serveur)Exécuté à l'ouverture de la page.A chaque modification (Code navigateur)Exécuté à chaque modification du champ Editeur de diagrammes : déplacement de forme, ajout de forme, suppression de forme, etc. Changement de zoom (Code navigateur)Exécuté après le changement du zoom dans l'éditeur de diagrammes (bouton de zoom, Ctrl + roulette, etc.).Remarque : L'instruction "RENVOYER Vrai/Faux" permet d'exécuter ou non l'événement. Ajout d'une forme (Code navigateur)Exécuté lors de l'ajout d'une forme dans le champ Editeur de diagrammes. Remarque : L'instruction "RENVOYER Vrai/Faux" permet d'exécuter ou non l'événement. Sélection d'une forme (Code navigateur)Exécuté lors de la sélection d'une forme dans le champ Editeur de diagrammes. Déplacement d'une forme (Code navigateur)Exécuté lors du déplacement d'une forme dans le champ Editeur de diagrammes. Remarque : L'instruction "RENVOYER Vrai/Faux" permet d'exécuter ou non l'événement. Redimensionnement d'une forme (Code navigateur)Exécuté lors du redimensionnement d'une forme dans le champ Editeur de diagrammes. Remarque : L'instruction "RENVOYER Vrai/Faux" permet d'exécuter ou non l'événement. Modification d'une forme (Code navigateur)Exécuté à chaque modification d'une forme dans le champ Editeur de diagrammes (par exemple lors de la validation du texte associé à la forme). Remarque : L'instruction "RENVOYER Vrai/Faux" permet d'exécuter ou non l'événement. Suppression d'une forme (Code navigateur)Exécuté lors de la suppression d'une forme dans le champ Editeur de diagrammes. Remarque : L'instruction "RENVOYER Vrai/Faux" permet d'exécuter ou non l'événement. Double-clic sur une forme (Code navigateur)Exécuté lors d'un double-clic sur une forme dans le champ Editeur de diagrammes. En code navigateur, les fonctions et variables WLangage spécifiques au champ Editeur de diagrammes ne sont pas disponibles. L'astuce consiste à utiliser un champ Bouton invisible contenant le code serveur à exécuter. Le code de clic de ce champ Bouton pourra être exécuté depuis le code navigateur grâce à la fonction ExécuteTraitement utilisée avec la constante trtClic. Remarques : Il est conseillé d'utiliser un code de clic serveur de type "AJAX".Il n'est pas possible d'utiliser la fonction AJAXExécute dans les événements navigateur.

## Evénements optionnels

Plusieurs événements optionnels peuvent être gérés.
Pour ajouter un événement optionnel :

1. Sélectionnez le champ voulu.
2. Affichez la fenêtre de code de ce champ (touche F2).
3. Cliquez sur le lien "Ajouter d'autres événements à xxx" situé à la fin de la fenêtre de code, après le dernier événement.
4. La totalité des événements optionnels disponibles pour le champ est affichée.
5. Cochez l'événement optionnel à ajouter et validez.
  Remarque : Il est possible de sélectionner plusieurs événements optionnels.
6. L'événement optionnel sélectionné est automatiquement ajouté dans les événements gérés par le champ.

Pour désactiver un événement optionnel, il suffit d'effectuer les mêmes manipulations pour afficher la liste des événements optionnels. Il suffit ensuite de décocher les événements optionnels à supprimer.
Remarque : Si le code désactivé contient du code WLangage, ce code est automatiquement supprimé.
Il est ainsi possible de gérer par exemple :

- le survol du champ par la souris,
- le bouton gauche enfoncé, relâché, avec un double-clic,
- le bouton droit enfoncé, relâché, avec double-clic,
- la roulette de la souris, ...

Pour plus de détails, consultez les [Evénements optionnels](1014004.md).
