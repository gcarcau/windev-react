# MongoGridFSSupprimeFichierParID (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Supprime un fichier identifié par son identifiant dans un système de fichiers MongoDB.
**Remarque** : Pour supprimer un fichier identifié à partir de son nom, utilisez la fonction [MongoGridFSSupprimeFichier](1000022440.md).

## Exemple

```wlangage
gCnxMONGO est un mongoConnexion

fsVV est un mongoGridFS
fsVV.Préfixe = "fs"
fsVV.BaseDeDonnées = gCnxMONGO.BaseDeDonnées[SAI_BASE]

tabFichier = MongoGridFSListeFichier(fsVV)
fic est un mongoGridFSInfoFichier
i est entier
POUR TOUT fic DE tabFichier
	i++
	Trace("-------------------------------------------------------------")
	Trace("n°: " + i)
	Trace("ID : " + VariantVersJSON(fic.ID))
	Trace("Nom : " + fic.Nom)
	MongoGridFSSupprimeFichierParID(fsVV, fic.ID)
	SI ErreurDétectée ALORS
		Info("Pb dans MongoGridFSSupprimeFichierParID : ", ErreurInfo(errComplet))
	FIN
FIN
```

## Syntaxe

```wlangage
<Résultat> = MongoGridFSSupprimeFichierParID(<Système de fichiers> , <Identifiant du fichier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème. La fonction [ErreurInfo](3013008.md) permet d'identifier l'erreur.
`<Système de fichiers>` *Variable de type mongoGridFS ou de type mongoBase*
> Système de fichiers de la base MongoDB à manipuler. Correspond :
>
> - au nom de la variable de type [mongoGridFS](1000022416.md) correspondant au système de fichiers Mongo.
> - au nom de la variable de type [mongoBase](1000022410.md) correspondant à la base MongoDB. Dans ce cas, le système de fichiers utilise le préfixe "fs".
`<Identifiant du fichier>` *Variant*
> Identifiant du fichier à supprimer.

**Composante : wd300big.dll**
