# <Fenêtre>.PaletteRécupère (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Récupère la palette de la fenêtre.

## Exemple

```wlangage
MaPalette est une Palette = FEN_Menu.PaletteRécupère()
LIB_Problème.CouleurFond = MaPalette["attention"]
```

## Syntaxe

```wlangage
<Résultat> = <Fenêtre>.PaletteRécupère()
```

`<Résultat>` *Variable de type Palette*
> Variable de type [Palette](1000021347.md) contenant la palette de la fenêtre spécifiée.
`<Fenêtre>` *Nom de la fenêtre*
> Nom de la fenêtre pour laquelle la palette doit être récupérée.

**Classification Métier / UI : Code UI**

**Composante : wd300obj.dll**
