# Procédure WLangage appelée par la fonction TCDCalculeMiseAJourAsynchrone

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Procédure WLangage (également nommée "callback") appelée par la fonction [TCDCalculeMiseAJourAsynchrone](1410090401.md) à la fin du calcul complet du champ Tableau croisé dynamique.

## Exemple

```wlangage
TCDCalculeMiseAJourAsynchrone(TCD_Statistiques, Calcul_terminé)
PROCÉDURE INTERNE Calcul_terminé(bOK est booléen)
	SI PAS bOK ALORS
		Erreur(ErreurInfo())
		RETOUR
	FIN
FIN
```

## Syntaxe

```wlangage
TCDCalculeMiseAJourAsynchrone_Callback(<Etat>)
```

`<Etat>` *Booléen*
> - Vrai si le calcul du champ Tableau croisé dynamique a été effectué avec succès,
> - Faux dans le cas contraire. Dans ce cas, la fonction [ErreurInfo](3013008.md) permet de connaître la cause de l'échec du calcul.

**Composante : wd300.dll**
