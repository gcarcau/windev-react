# EmailCopie (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Copie un email présent dans un répertoire vers un autre répertoire d'un serveur IMAP.
**Remarque** : Cette fonction n'est pas disponible pour les sessions POP3, Outlook et Notes.

## Exemple

```wlangage
MonEmail est un Email
MaSession est une emailSessionIMAP
...
// Ouverture de la session
SI EmailOuvreSession(MaSession) = Vrai ALORS
	// Lecture du premier email
	SI EmailLitPremier(MaSession, MonEmail) = Vrai ALORS
		// Copie l'email dans un autre dossier
		EmailCopie(MaSession, MonEmail, "Inbox/Lu")
	FIN
	EmailFermeSession(MaSession)
FIN
```

## Syntaxe

#### Copier un email contenu dans une variable de type Email

```wlangage
<Résultat> = EmailCopie(<Email> , <Dossier>)
```

`<Résultat>` *Booléen*
> - Vrai si la copie a été effectuée,
> - Faux dans le cas contraire.
`<Email>` *Variable de type Email*
> Nom de la variable de type [Email](1000018713.md) correspondant à l'email à copier. Cet email est associé à une session IMAP.
`<Dossier>` *Chaîne de caractères*
> Dossier destination de l'email. Ce dossier doit exister. La liste des dossiers peut être connue par la fonction [EmailListeDossier](3032133.md).

#### Copier un email contenu dans une variable de type Email en précisant la session IMAP

```wlangage
<Résultat> = EmailCopie(<Session> , <Email> , <Dossier>)
```

`<Résultat>` *Booléen*
> - Vrai si la copie a été effectuée,
> - Faux dans le cas contraire.
`<Session>` *Variable de type emailSessionIMAP*
> Nom de la session de type [emailSessionIMAP](1000018957.md) correspondant à la session à laquelle appartient l'email.
`<Email>` *Variable de type Email*
> Nom de la variable de type [Email](1000018713.md) correspondant à l'email à copier.
`<Dossier>` *Chaîne de caractères*
> Dossier destination de l'email. Ce dossier doit exister. La liste des dossiers peut être connue par la fonction [EmailListeDossier](3032133.md).

**Composante : wd300com.dll**
