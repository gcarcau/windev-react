# Police (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Une variable de type **Police** permet de créer une police par programmation. Les caractéristiques de cette police peuvent être modifiées à l'aide de différentes propriétés WLangage.
Une variable de type **Police** peut être utilisée :

- dans les dessins,
- dans les graphes,
- pour les impressions,
- dans les champs d'une fenêtre (propriété [Police](1514045.md) des champs d'une fenêtre),
- dans les champs d'une page (propriété [Police](1514045.md) des champs d'une page),
- dans les champs d'un état (propriété [Police](1514045.md) des champs d'un état).

**Remarques** :

- Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).
- Pour modifier les caractéristiques d'une cellule d'un champ Tableur, utilisez la fonction [TableurStyleSélection](1000021338.md).

## Exemple

```wlangage
// Déclaration de variables de type Police
MaPolice est une Police
MaPolice1, MaPolice2 sont des Polices
```

```wlangage
// Variable initialisée avec la police créée avec la fonction PoliceCrée
MaPolice = PoliceCrée("Arial", 12, iGras)
```

```wlangage
// Modification des caractéristiques de la police
MaPolice.Nom = "Arial"
MaPolice.Taille = 12
MaPolice.Gras = Vrai
```

```wlangage
// Utilisation d'une police sur un champ d'une fenêtre
SAI_Nom.Police = MaPolice

// Récupération de la police d'un champ
MaPolice1 = SAI_Prénom.Police
```

## Remarques

### Caractéristiques d'une police
Par défaut, une variable Police a les caractéristiques suivantes :

- "Arial",
- taille 12,
- couleur noir,
- sans attribut.

Pour définir les caractéristiques d'une police par programmation, utilisez :

- Soit la fonction [PoliceCrée](3060002.md).
- Soit les propriétés de gestion des polices (voir ci-dessous)
- Soit la fonction [PoliceSelect](3060004.md) qui ouvre la fenêtre standard Windows de sélection des polices.

### Propriétés de gestion des polices
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **Police** :

| Nom de la propriété | Effet |
| --- | --- |
| [Alphabet](2512008.md) | Renvoie et modifie l'alphabet utilisé par une variable de type Police. _(Android, Widget Android)_ Non disponible. |
| [Angle](1410086632.md) | Renvoie et modifie l'angle (en degrés) d'une variable de type Police. _(Android, Widget Android)_ Non disponible. |
| [Barré](2513005.md) | Vérifie si une variable de type Police est barrée et barre (ou non) une variable de type Police. |
| [Couleur](2510071.md) | Vérifie et modifie la couleur d'une variable de type Police. |
| [Gras](2513001.md) | Teste si une variable de type Police est en gras et modifie l'attribut gras d'une variable de type Police. |
| [Interlettre](1410088367.md) | Renvoie et modifie l'espacement ajouté entre les caractères d'une variable de type Police. |
| [Interligne](1410088366.md) | Renvoie et modifie le coefficient d'espacement entre les lignes pour une variable de type Police. |
| [Italique](2513007.md) | Vérifie si une variable de type Police est en italique et modifie l'attribut italique d'une variable de type Police. |
| [Nom](2510082.md) | Renvoie et modifie le nom d'une variable de type Police. |
| [Souligné](2513013.md) | Vérifie si une variable de type Police est soulignée et souligne (ou non) une variable de type Police. |
| [Taille](2510125.md) | Renvoie et modifie la taille (en points pica) d'une variable de type Police. |
| [UnitéTaille](1410088365.md) | Renvoie et modifie l'unité utilisée pour manipuler la taille d'une variable de type Police. |

Ces propriétés peuvent être utilisées directement sur la variable de type **Police**. Exemple :

```wlangage
MaPolice est une Police
MaPolice.Gras = Vrai
MaPolice.Couleur = RougeClair
```

### Fonctions utilisant des variables de type Police
Les fonctions suivantes peuvent manipuler une variable de type **Police** :

| [dPolice](3029020.md) | Déclare la police de caractères qui sera utilisée par la fonction [dTexte](3029032.md) :   - dans un champ Image, - dans une variable de type [Image](1000019650.md), - dans une variable de type [WDPic](1000023503.md) (sur le calque d'arrière-plan), - dans une variable de type [picCalque](1000024604.md). |
| --- | --- |
| [grPoliceEtiquette](3042012.md) | Modifie la police utilisée pour les étiquettes de catégorie d'un graphe. |
| [grPoliceLégende](3042037.md) | Modifie la police utilisée pour la légende d'un graphe. |
| [grPoliceTitre](3042048.md) | Modifie la police utilisée pour le titre d'un graphe. |
| [iPolice](3046014.md) | Sélectionne la police par défaut. |
| [PoliceCrée](3060002.md) | Crée une définition de police. |
| [PoliceSelect](3060004.md) | Ouvre la fenêtre standard de sélection de polices de Windows en sélectionnant la police spécifiée. |
