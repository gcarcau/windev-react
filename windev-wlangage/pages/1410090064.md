# ActionRapideSupprime (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

Supprime une action rapide de l'application.

## Exemple

```wlangage
ActionRapideSupprime("ID_ACTION_ENVOI_MESSAGE")
```

## Syntaxe

#### Supprimer une action rapide identifiée par une variable de type ActionRapide

```wlangage
<Résultat> = ActionRapideSupprime(<Action>)
```

`<Résultat>` *Booléen*
> - Vrai si l'action rapide a été supprimée,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet de connaître le détail de l'erreur.
`<Action>` *Variable de type ActionRapide*
> Variable de type [ActionRapide](1410090054.md) décrivant l'action à supprimer

#### Supprimer une action rapide identifiée par son identifiant

```wlangage
<Résultat> = ActionRapideSupprime(<Identifiant>)
```

`<Résultat>` *Booléen*
> - Vrai si l'action rapide a été supprimée,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet de connaître le détail de l'erreur.
`<Identifiant>` *Chaîne de caractères*
> Identifiant de l'action rapide à supprimer.
