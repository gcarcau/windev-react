# <Source>.DébloqueFichier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Débloque les enregistrements d'un fichier de données :

- précédemment bloqués avec la fonction [<Source>.BloqueFichier](1000024196.md).
- bloqués individuellement avec une fonction de lecture bloquante.

Le déblocage du fichier de données peut aussi être obtenu en fermant le fichier de données (fonction [<Source>.Ferme](1000024958.md)).

Remarque : La fonction **<Source>.DébloqueFichier** ne permet pas de débloquer un fichier de données bloqué par une autre session ou un autre programme. Il est conseillé de débloquer un fichier de données le plus rapidement possible, afin que les autres sessions puissent accéder à ce fichier de données.

> _(Android, Widget Android, Java)_ Cette fonction peut être utilisée avec des fichiers de données HFSQL Client/Serveur.

## Exemple

```wlangage
// Blocage
Client.BloqueFichier(hBlocageLectureEcriture)
// Modification du fichier
...
// Déblocage
Client.DébloqueFichier()
```

## Syntaxe

```wlangage
<Résultat> = <Source>.DébloqueFichier()
```

`<Résultat>` *Booléen*
> - Vrai si le fichier de données a été débloqué,
> - Faux en cas de problème (par exemple le fichier de données n'est pas bloqué, ...). La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Source>` *Type correspondant à la source spécifiée*
> Nom du fichier de données manipulé.

## Remarques

La fonction **<Source>.DébloqueFichier** est sans effet si :

- le fichier de données est en mode Mono (voir la fonction [<Source>.Mode](1000025037.md)).
- le fichier de données n'est pas bloqué.
- le fichier de données a été bloqué par un autre programme.
