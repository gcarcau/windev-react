# <Variable zipArchive>.FichierEnCours (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie le nom du fichier archivé en cours de manipulation par les fonctions d'ajout et d'extraction de fichiers. Cette fonction est utilisable sur les archives au format CAB, RAR, WDZ, ZIP, gzip, TAR et TGZ (TAR.GZ).
Nouveauté 2025

> _(WINDEV, WEBDEV - Code Serveur, Windows, Linux, iPhone/iPad)_ Le format gzip (extension .gz) est désormais géré.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Ajax)_ Archive est une zipArchive

POUR Indice = 1 À 5
 // Extraction des 5 premiers fichiers de l'archive
 ResExtraitFichier = Archive.ExtraitFichier(Indice)
 ...
 // Recherche du nom du fichier en cours d'extraction
 ResFichierEnCours = Archive.FichierEnCours()
 // Affichage du nom du fichier dans la barre de message
 Message(ResFichierEnCours)
 ...
FIN

## Syntaxe

```wlangage
<Résultat> = <Archive>.FichierEnCours()
```

`<Résultat>` *Chaîne de caractères*
> Fichier en cours de manipulation par les fonctions [<Variable zipArchive>.AjouteFichier](1000019050.md), [<Variable zipArchive>.AjouteRépertoire](1000019078.md), [<Variable zipArchive>.ExtraitFichier](1000019082.md) ou [<Variable zipArchive>.ExtraitTout](1000019085.md).
`<Archive>` *Variable de type zipArchive*
> Nom d'une variable de type [zipArchive](1000018679.md) correspondant à l'archive à manipuler.

## Remarques

### Rappel

- Seules les archives au format ZIP, gzip, TAR et TGZ (TAR.GZ) sont disponibles.
- Seules les archives au format ZIP sont disponibles.

### Erreur pendant les traitements d'ajout et d'extraction de fichiers
En cas d'erreur pendant les traitements d'ajout ou d'extraction, la fonction **<Variable zipArchive>.FichierEnCours** contient le nom du fichier qui n'a pas pu être lu ou écrit dans l'archive.

**Composante : wd300zip.dll**
