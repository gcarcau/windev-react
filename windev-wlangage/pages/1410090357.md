# <Variable Drive>.EnvoieFichier (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Envoie un fichier (présent sur la machine de l'utilisateur) vers un drive (disque distant).

## Exemple

```wlangage
oOAuth2Param est un OAuth2Paramètres
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.URLRedirection = "http://localhost:9000/"

oDrive est un Drive
oDrive = oDriveConnecte(oOAuth2Param)

// Choix du fichier local
sFichier est une chaîne
sFichier = fSélecteur("", "", "Fichier local à envoyer", "Tous les fichiers (*.*)" + TAB + "*.*", "*.*")

// Récupère le contenu du répertoire
SI oDrive.EnvoieFichier(sFichier, "/A_Verifier") = Faux ALORS
	Erreur("Impossible d'envoyer le fichier demandé", ErreurInfo())
	RETOUR
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Drive>.EnvoieFichier(<Fichier à envoyer> , <Répertoire destination>)
```

`<Résultat>` *Booléen*
> - Vrai si le fichier a été envoyé,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Drive>` *Variable de type Drive ou gglDrive*
> Nom de la variable de type [Drive](1410089369.md) ou [gglDrive](1410089374.md) correspondant au drive à manipuler. La connexion au drive voulu doit avoir été effectuée. Dans le cas contraire, le fichier n'est pas envoyé.
`<Fichier à envoyer>` *Chaîne de caractères*
> Chemin absolu du fichier présent sur le poste local et devant être envoyé. Si ce paramètre ne correspond pas à un chemin de fichier valide, le fichier ne sera pas envoyé.
`<Répertoire destination>` *Chaîne de caractères*
> Chemin absolu du répertoire destination.
>
> - Si ce paramètre ne correspond pas à un chemin valide, l'élément ne sera pas envoyé.
> - Les répertoires manquants dans le chemin ne sont pas créés.
> - Si le fichier existe déjà à l'emplacement indiqué dans le drive, il sera écrasé.

## Remarques

### Dropbox
Selon le type de compte Dropbox utilisé, les appels à cette fonction peuvent être considérés comme des transferts de données. Certains types de compte ont une limite pour les données transférées par mois. Pour plus de détails, consultez [https://www.dropbox.com/developers/reference/data-transport-limit](https://www.dropbox.com/developers/reference/data-transport-limit).

### Paramètre <Répertoire destination>
Exemples de chemins valides :

```wlangage
"/mon répertoire de vacances/2021/""\photos"
```

Exemples de chemins invalides :

```wlangage
"répertoireA/RépertoireB""Ce/Chemin/Est/invalide""c:\Users\"
```
