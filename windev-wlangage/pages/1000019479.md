# Icone

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Le mot-clé **Icône** peut correspondre :

- à la propriété **Icone**. Cette propriété permet de connaître et de modifier l'icône d'un élément. Cette propriété est utilisable sur :
  - une fenêtre. Pour plus de détails, consultez [Propriété Icone](1000019344.md).
  - une variable de type [Notification](1000019441.md).
  - une variable de type [upnpPériphérique](1000020903.md).
  - une variable de type [notificationAction](1000021304.md).
  - une variable de type [ActionRapide](1410090054.md).
  - Nouveauté Abonnement
     une variable de type [zipParamètreCréationExe](1410091226.md).
    **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
    Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
- à une variable de type [Icône](1000020811.md).
