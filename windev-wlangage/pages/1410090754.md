# <Variable Commande>.RécupèreCodeRetour (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU))

Récupère le code de retour de la commande lancée en mode console, c'est-à-dire la valeur renvoyée à la terminaison de la commande.

## Exemple

```wlangage
// Exécution de la commande 'C:\Chemin\MonProgramme.exe -opt1=val1'

// Définition de la commande
MaCommandeAExécuter est une Commande
// Exécutable à lancer
MaCommandeAExécuter = "C:\Chemin\MonProgramme.exe"
// Arguments à passer à l'exécutable
MaCommandeAExécuter.Arguments = "Argument1"
// Activation des flux
MaCommandeAExécuter.Flux = cmdEntréeStandard + cmdSortieStandard
// Ajout d'un argument à la ligne de commande
MaCommandeAExécuter.AjouteArgument("Argument2")
// Ajout d'une option à la ligne de commande
MaCommandeAExécuter.AjouteOption("opt1", "val1")

// Exécution de la commande
MaCommandeAExécuter.Exécute(Faux)
// Écriture dans l'entrée standard (possible car le flux est actif)
MaCommandeAExécuter.EcritEntréeStandard("Test Ecriture" + RC)
// Récupération du code de retour de la commande
code est un entier = MaCommandeAExécuter.RécupèreCodeRetour(Vrai)
// Lecture dans la sortie standard (possible car le flux est actif)
stdout est une chaîne = MaCommandeAExécuter.LitSortieStandard()
// Lecture dans la sortie d'erreur (impossible car le flux n'est pas activé)
// Message d'erreur : Le flux 'STDERR' n'est pas activé.
stderr est une chaîne = MaCommandeAExécuter.LitSortieErreur()
```

## Syntaxe

```wlangage
<Code Retour> = <Commande>.RécupèreCodeRetour([<Bloquant>])
```

`<Code Retour>` *Entier*
> Code de retour de l'exécution de la commande en mode console. Ce code de retour correspond à la valeur renvoyée par le programme.
> Remarque : Par convention, un programme qui se termine avec succès renvoie 0, et renvoie une autre valeur en cas d'erreur. Ce n'est en rien une règle.
`<Commande>` *Variable de type Commande*
> Nom de la variable de type [Commande](1410090491.md) correspondant à la commande exécutée en mode console.
`<Bloquant>` *Booléen optionnel*
> - Vrai (valeur par défaut) pour un fonctionnement bloquant : les données sont lues uniquement lorsque la commande a fini de s'exécuter.
> - Faux pour un fonctionnement non bloquant (asynchrone) : les données sont lues même si la commande n'a pas fini son exécution. Si la commande n'a pas fini son exécution, une erreur sera affichée.
