# Bulle (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Bulle** permet de connaître et de modifier le texte d'une bulle d'aide. Cette propriété est utilisable sur :

- les champs d'une fenêtre, d'une page ou d'un état. Pour plus de détails, consultez [Bulle](2510005.md).
- une variable de type [EvénementTimeline](1000020612.md).
- une variable de type [RendezVous](1000019244.md).
- une variable de type [OrgaElément](1000019713.md).
- une variable de type [TâcheGantt](1000020881.md).
- une variable de type [docElémentLien](1000022970.md).
- une variable de type [Jeton](1000023942.md).
- une variable de type [VisiteGuidée](1410090170.md).
- une variable de type [VisiteGuidéeEtape](1410090178.md).
