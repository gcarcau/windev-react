# Erreur 112 : Un tableau ne peut avoir que X dimensions au maximum

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Cause

Vous avez défini un tableau (dynamique ou non) de plus de 10 dimensions.

## Correction

Diminuez le nombre de dimensions du tableau.

## Exemples

### Tableau déclaré avec 13 dimensions.

**Code provoquant l'erreur**

```wlangage
Tableau13 est un tableau de 3 par 3 par 3 par 3 par 3 par 3 par 3 par 3 par 3    par 3 par 3 par 3 par 3 entiers
```

**Correction proposée**

Diminuez la taille, pour respecter la valeur maximale autorisée.

```wlangage
Tableau13 est un tableau de 3 par 3 par 3 par 3 par 3 par 3 par 3 par 3 par 3 entiers
```
