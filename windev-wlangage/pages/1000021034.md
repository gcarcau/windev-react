# Fonctions In-App

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions WLangage permettant de gérer les achats in-App sont les suivantes :
| [inAppAchèteProduit](1000020873.md) | Envoie une demande d'achat d'un produit "In-App" associé à l'application. |
| --- | --- |
| [inAppConsommeProduit](1000020880.md) | Permet de consommer dans une application un produit précédemment acheté par l'utilisateur. |
| [inAppListeAchat](1000020888.md) | Renvoie la liste des produits de l'application achetés par l'utilisateur et non consommés. |
| [inAppListeInfoProduit](1000020872.md) | Récupère à partir du store les informations sur les produits "In-App" associés à l'application. |
| [inAppRestaureAchats](1000020879.md) | Restaure les achats de produits non consommables précédemment effectués par l'utilisateur dans une application iOS. |
| [inAppVérifieAbonnement](1000022719.md) | Vérifie au démarrage de l'application iOS si les abonnements In-App ont été renouvelés. |
