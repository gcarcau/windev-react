# TraceDébut (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch) · **Autres** (Procédures stockées)

Ouvre la fenêtre de trace ou enregistre les différentes informations de trace dans un fichier texte.
**Remarques** :

- Si la fenêtre de trace est déjà ouverte, la fonction **TraceDébut** n'a aucune action.
- La fonction **TraceDébut** est optionnelle. Le premier appel à la fonction [Trace](3013050.md) ou à la fonction [TraceConstruit](1000021683.md) ouvre automatiquement la fenêtre de trace.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, WEBDEV - Code Navigateur, Etats et Requêtes, iPhone/iPad, Apple Watch, Java, Code Utilisateur (MCU), Ajax)_ // Ouvre la fenêtre de trace
TraceDébut()
...
// Ecrit dans la fenêtre de trace
Trace("Résultat du calcul : " + ResCalcul)

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Apple Watch, Java, Code Utilisateur (MCU), Ajax)_ // Désactiver les appels à la fonction Trace
TraceDébut(trDésactive)
...
Trace("Résultat du calcul : " + ResCalcul) // Fonction Trace sans effet

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ // Enregistre les informations contenues dans
// la fenêtre de trace dans le fichier "C:\Trace\MonFichier.txt"
TraceDébut(trFichier, "C:\Trace\MonFichier.txt")
...
Trace("Résultat du calcul : " + ResCalcul)
// Aucune fenêtre de trace n'est affichée
// Cette information sera enregistrée dans le fichier "C:\Trace\MonFichier.txt"

## Remarques

### Conditions d'utilisation selon les plateformes

> _(Linux)_ La fonction TraceDébut permet d'enregistrer les informations demandées uniquement dans un fichier. Par défaut, ce fichier est créé dans le répertoire temporaire d'UNIX, sous le nom "Trace_<Projet>.txt".

> _(PHP)_ La fonction TraceDébut permet d'afficher les informations demandées dans la page en cours ou de les enregistrer dans un fichier.

> _(WEBDEV - Code Serveur)_ En mode AWP, la fonction TraceDébut permet d'enregistrer les informations demandées uniquement dans un fichier.

> _(Android, Widget Android)_ La fonction TraceDébut permet d'enregistrer les informations demandées : soit dans le log de l'application (en exécution ou en mode émulateur). Ce log est consultable lorsque l'appareil est connecté en USB ou en cas d'utilisation de l'émulateur depuis l'application DDMS fournie avec le SDK Android.soit dans un fichier texte spécifique.

> _(iPhone/iPad, Apple Watch)_ La fonction TraceDébut permet : soit d'afficher les informations demandées dans la fenêtre de sortie standard (output) de Xcode. soit d'enregistrer les informations demandées dans un fichier texte spécifique.

### Fermeture de la fenêtre de trace
La fonction [TraceFin](3013044.md) permet de fermer la fenêtre de trace.
Si la constante *trFichier* est spécifiée, la fonction [TraceFin](3013044.md) arrête l'enregistrement dans le fichier de trace.

> _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur, Ajax)_ Fenêtre de traceLa fenêtre de trace affichée depuis un code navigateur est différente de celle affichée depuis un code serveur. Deux fenêtres de trace différentes peuvent donc être ouvertes en même temps.
