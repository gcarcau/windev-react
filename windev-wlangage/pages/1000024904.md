# pdfPage (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Le type **pdfPage** permet de définir toutes les caractéristiques avancées d'une page d'un document PDF chargé en mémoire. Les caractéristiques de cette page peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
MonPDF est un pdfDocument = "test.pdf"
POUR TOUTE PageDocument DE MonPDF.Page
	Trace(PageDocument.Hauteur)
FIN
PDFSauve(MonPDF, "testmdp.pdf")
// Il est également possible d'utiliser la syntaxe préfixée
// MonPDF.Sauve("testmdp.pdf")
```

```wlangage
FichierPDF est un pdfDocument = PDFOuvre(fRepDonnées + fSep +"MONPDF.pdf")
UnePage est un pdfPage
// Ajoute une image dans une page
UnePage = FichierPDF.Page[1]
UnePage.AjouteImage(fRepDonnées + fSep + "MONIMAGE.jpg", 0, 0, UnePage.Largeur, UnePage.Hauteur)
// Affiche le document PDF dans un champ Lecteur PDF
PDF_NoName1 = FichierPDF
```

```wlangage
MonDocPDF est un pdfDocument = PDFOuvre("C:\temp\Monguide.pdf")
Trace(MonDocPDF.VersionPDF)
Trace(MonDocPDF.Auteur)
Trace(MonDocPDF.Page.Occurrence)
Trace(MonDocPDF.Page[1].Largeur)
Trace(MonDocPDF.Page[36].Hauteur)
POUR TOUT UnElémentTexte DE MonDocPDF.Page[2].ElémentTexte
	Trace(UnElémentTexte.Texte + " X = " +
	UnElémentTexte.X + " Y = " + UnElémentTexte.Y + " L = " +
	UnElémentTexte.Largeur + " H = " + UnElémentTexte.Hauteur)
FIN
MonDocPDF2 est un pdfDocument = "C:\temp\plan.pdf"
// Ajout de pages
Ajoute(MonDocPDF2.Page, MonDocPDF.Page[5])
// Insertion de pages
Insère(MonDocPDF2.Page, 1, MonDocPDF.Page[32])
// Enregistrement du PDF modifié
PDFSauve(MonDocPDF2, "MonDocPDF2.pdf")
LanceAppliAssociée("MonDocPDF2.pdf")
```

## Propriétés

### Propriétés spécifiques à la description des variables de type pdfPage
Les propriétés suivantes peuvent être utilisées pour manipuler une page d'un document PDF :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Nouveauté 2025 Champ | Tableau de [pdfChamp](1410090536.md) | Caractéristiques des champs d'un formulaire PDF. _(iPhone/iPad)_ Cette propriété n'est pas disponible. |
| ElémentTexte | Tableau de [pdfElémentTexte](1000024556.md) | Informations de texte contenu dans la page. |
| Hauteur | Réel | Hauteur de la page en millimètres.  Si cette hauteur est modifiée, la page est automatiquement redimensionnée et les éléments contenus sont recadrés. _(iPhone/iPad)_ Cette propriété est disponible en lecture seulement. |
| Largeur | Réel | Largeur de la page en millimètres.  Si cette largeur est modifiée, la page est automatiquement redimensionnée et les éléments contenus sont recadrés. _(iPhone/iPad)_ Cette propriété est disponible en lecture seulement. |
| Orientation | Constante de type Chaîne | Permet de connaître et de modifier l'orientation de la page :   - *Orient0* : Orientation par défaut. - *Orient90* : Orientation de la page à 90°. - *Orient180* : Orientation de la page à 180°. - *Orient270* : Orientation de la page à 270°. |
