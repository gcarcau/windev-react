# Booléen (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Le type **Booléen** est conseillé pour toutes les opérations logiques où seules deux alternatives sont possibles :

- Vrai (valeur différente de 0).
- Faux (valeur égale à 0).

Le type Booléen est un type nullable. Pour plus de détails, consultez [Activation des types nullables](1511031.md).

## Exemple

```wlangage
b est un booléen
```

## Syntaxe

```wlangage
<Nom de la variable> est un booléen<Nom de la variable 1>, <Nom de la variable 2> sont des booléens
```

`<Nom de la variable>` **
> Nom de la variable à déclarer.
