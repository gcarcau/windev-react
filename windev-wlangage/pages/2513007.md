# Italique (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **Italique** permet de :

- Savoir si une variable de type Police est en italique.
- Modifier l'attribut italique d'une variable de type Police.

## Exemple

```wlangage
// Définir les caractéristiques d'une variable de type PolicePolice1 est une PolicePolice1.Nom = "Arial"Police1.Taille = 14Police1.UnitéTaille = unitéPointPolice1.Italique = Vrai// Appliquer la police au champ "MonChamp"MonChamp.Police = Police1
```

## Syntaxe

#### Savoir si une variable de type Police est en italique

```wlangage
<Résultat> = <Police>.Italique
```

`<Résultat>` *Booléen*
> - Vrai si la variable de type [Police](1514045.md) spécifiée est en italique,
> - Faux dans le cas contraire.
`<Police>` *variable de type Police*
> Nom de la variable de type [Police](1514045.md) à manipuler.

#### Modifier l'attribut italique d'une variable de type Police

```wlangage
<Police>.Italique = <Italique/Non italique>
```

`<Police>` *variable de type Police*
> Nom de la variable de type [Police](1514045.md) à manipuler.
`<Italique/Non italique>` *Booléen*
> - Vrai si la variable de type [Police](1514045.md) doit être en italique,
> - Faux dans le cas contraire.

## Remarques

Une police peut être créée à partir d'une variable de type [Police](1514045.md).
Pour définir les caractéristiques de la police, utilisez :

- soit la fonction [PoliceCrée](3060002.md).
   Cette fonction n'est pas disponible.
- soit les propriétés [Alphabet](2512008.md), [Angle](1410086632.md), [Barré](2513005.md), [Couleur](2510071.md), [Gras](2513001.md), [Italique](2513007.md), [Interlettre](1410088367.md), [Interligne](1410088366.md), [Nom](2510082.md), [Souligné](2513013.md), [Taille](2510125.md) et [UnitéTaille](1410088365.md).
   Les propriétés [Alphabet](2512008.md), [Angle](1410086632.md) ne sont pas disponibles pour les variables de type [Police](1514045.md).

Cette police pourra être utilisée :

- Pour écrire du texte dans des dessins (fonction [dPolice](3029020.md)).
- Pour écrire dans les graphes (fonctions [grPoliceEtiquette](3042012.md), [grPoliceLégende](3042037.md), [grPoliceTitre](3042048.md) et [grPoliceTitreAxe](3042059.md)).
- Pour imprimer (fonction [iPolice](3046014.md)).
- Dans les champs d'une fenêtre (propriété [Police](1514045.md) des champs d'une fenêtre).
- Dans les champs d'un état (propriété [Police](1514045.md) des champs d'un état).

> _(Android, Widget Android)_ Cette police pourra être utilisée uniquement dans les champs d'une fenêtre (propriété Police des champs d'une fenêtre).
