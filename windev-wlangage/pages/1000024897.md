# DocMiseAJourFormule (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Met à jour les formules d'un document. Cette formule peut être contenue dans :

- une variable de type Document,
- un champ Traitement de texte,
- une variable de type docFragment.

## Exemple

```wlangage
MonDocument est un Document
...

DocMiseAJourFormule(MonDocument)
```

## Syntaxe

#### Mettre à jour les formules d'une variable Document

```wlangage
DocMiseAJourFormule(<Document>)
```

`<Document>` *Variable de type Document*
> Nom de la variable de type [Document](1000022461.md) à manipuler.

> _(WINDEV)_ Mettre à jour les formules d'un champ Traitement de texte Masquer les détails
DocMiseAJourFormule(<Champ Traitement de texte>)

 <Champ Traitement de texte> : Nom de champNom du champ Traitement de texte à manipuler.

#### Mettre à jour les formules d'une variable docFragment

```wlangage
DocMiseAJourFormule(<Fragment>)
```

`<Fragment>` *Variable de type docFragment*
> Nom de la variable de type [docFragment](1000022482.md) contenant les formules.

**Composante : wd300mdl.dll**
