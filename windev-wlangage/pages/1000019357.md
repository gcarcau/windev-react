# WiFiSupprimeRéseau (Fonction)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android)

Supprime un réseau de la liste des réseaux Wi-Fi configurés de l'appareil.
> _(Android, Widget Android)_ Attention : Cette fonctionnalité est disponible jusqu'à Android 9. A partir d'Android 10, cette information n'est plus accessible : cette fonction provoque une erreur fatale. Il est conseillé de tester la version d'Android utilisée via la fonction SysVersionAndroid.

## Exemple

```wlangage
WiFiSupprimeRéseau("1478")
```

## Syntaxe

```wlangage
<Résultat> = WiFiSupprimeRéseau(<Identifiant>)
```

`<Résultat>` *Booléen*
> - Vrai si la suppression a été effectuée,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de renseignements sur le problème rencontré.
`<Identifiant>` *Chaîne de caractères*
> Identifiant du réseau à supprimer.

## Remarques

> _(Android, Widget Android)_ Permissions requisesL'utilisation de cette fonction entraîne la modification des permissions requises par l'application.Permissions requises : ACCESS_WIFI_STATE : cette permission permet aux applications d'accéder à des informations concernant les réseaux Wi-Fi. CHANGE_WIFI_STATE : cette permission permet aux applications de modifier l'état de connectivité Wi-Fi.
