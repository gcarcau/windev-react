# <Sélecteur>.Supprime (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Supprime une option d'un champ Sélecteur.

## Exemple

```wlangage
// Supprime l'option numéro 3 d'un champ Sélecteur
SEL_Options.Supprime(3)
```

## Syntaxe

#### Suppression d'une option identifiée par son indice

```wlangage
<Champ Sélecteur>.Supprime(<Indice>)
```

`<Champ Sélecteur>` *Nom de champ*
> Nom du champ Sélecteur à manipuler.
`<Indice>` *Entier*
> Indice de l'option à supprimer. Cet indice doit être compris entre 1 et le nombre d'options contenues dans le champ Sélecteur. La propriété [Occurrence](2510097.md) permet de connaître le nombre d'options d'un champ Sélecteur.

> Cette syntaxe n'est pas disponible pour les applications Android

Suppression d'une option identifiée par son nom Masquer les détails
Supprime(<Champ Sélecteur> , <Nom de l'option>)

 <Champ Sélecteur> : Nom de champNom du champ Sélecteur à manipuler. <Nom de l'option> : Chaîne de caractèresNom de l‘option à supprimer. Le nom de l'option a été défini dans la fenêtre de description du champ Sélecteur (onglet "Contenu).

## Remarques

- Lors de la suppression d'options dans un champ Sélecteur, la taille du champ n'est pas modifiée. Il est possible de modifier la taille du champ avec les propriétés [Largeur](2510059.md) et [Hauteur](2510050.md).
- Il est possible de compacter les options pour optimiser l'aspect du champ après suppression des options.
  En mode compacté, les options d'un champ Sélecteur se resserrent :
  - lorsqu'une option est rendue invisible.
  - lorsqu'une option est supprimée.
- Pour utiliser le mode compacté :
  - cochez l'option "Compacter les options invisibles" dans l'onglet "Détail" de la description du champ.
  - utilisez la propriété [CompacteOption](1000020608.md).
- Lors de la suppression d'une option, si le sélecteur utilise la numérotation des options, les indices des options suivant l'option supprimée sont automatiquement renumérotées.
- Seul l'indice de l'option à supprimer peut être indiqué. Si le sélecteur utilise les valeurs renvoyées, il n'est pas possible de spécifier le nom de l'option à supprimer. Il est cependant possible d'indiquer l'indice correspondant à l'option.
