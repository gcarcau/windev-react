# fRepTemp (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Renvoie le nom du répertoire utilisé pour stocker les fichiers temporaires.

## Exemple

```wlangage
// Récupération du nom du répertoire temporaireResRepTemp = fRepTemp()
```

## Syntaxe

```wlangage
<Résultat> = fRepTemp()
```

`<Résultat>` *Chaîne de caractères*
> - Chemin du répertoire utilisé pour stocker les fichiers temporaires (260 caractères maximum). Ce chemin se termine par le caractère "\".
>    Ce chemin correspond au répertoire "tmp" de l'application.
> - Chaîne vide ("") en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
>
> **Remarque** : Le résultat de la fonction **fRepTemp** est toujours une chaîne de caractères au format Ansi. Il est cependant possible de stocker le résultat dans une chaîne de caractères Unicode.

## Remarques

### Répertoire temporaire
Si le répertoire temporaire géré par le système n'existe pas sur le poste en cours, la fonction **fRepTemp** renvoie :

- avec Windows 98 ou Me : le répertoire en cours sur le poste.
- avec Windows 2000, NT ou CE : le nom du répertoire temporaire géré par défaut par le système. Aucun test n'est réalisé sur l'existence du répertoire temporaire.

**Attention** : Sous Windows Vista (ou supérieur) avec le [système de l'UAC](2025014.md) activé, le répertoire temporaire utilisé est différent si l'utilisateur à les privilèges administrateur ou non.

### Equivalence
La fonction **fRepTemp** est équivalente à la fonction [fRépertoireTemp](3036044.md).
