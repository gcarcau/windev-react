# <Variable xmlDocument>.ExécuteXPath (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

## Exemple

```wlangage
clDoc est un xmlDocument = XMLOuvre(n, depuisChaîne)
c est un xpathRésultat = clDoc.ExécuteXPath("/root/text()")
SI c..EstValeur ALORS
	Trace(c..Valeur)
SINON
	POUR TOUT noeud DE c..Noeud
		Trace("Noeud : " + noeud..Texte)
	FIN
	POUR TOUT attrib DE c..Attribut
		Trace("Noeud : " + attrib..Nom)
	FIN
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Document XML>.XMLExécuteXPath(<Texte de la requête XPath>)
```

`<Résultat>` *Variable de type xpathRésultat*
> Variable de type [xpathRésultat](1000021967.md) contenant le résultat de la requête XPATH.
> Lecture du résultat :
>
>
> - La propriété **EstValeur** permet de savoir si le résultat est une valeur.
> - Pour une requête de sélection (le résultat n'est pas une valeur), il est nécessaire de parcourir la variable [xpathRésultat](1000021967.md).
> - Pour une requête de calcul (le résultat est une valeur), la propriété **Valeur** permet de lire le résultat.
`<Document XML>` *Variable de type xmlDocument*
> Nom de la variable de type [xmlDocument](1000018782.md) contenant le code XML à analyser.
`<Texte de la requête XPath>` *Chaîne de caractères*
> Texte de la requête XPath à exécuter.

## Remarques

### Limitations

- Il n'est pas possible d'imbriquer plusieurs requêtes XPath de parcours.
- Exécuter une requête XPATH sur un document XML :
  Les fonctions [XMLSauvePosition](3081033.md) et [XMLRetourPosition](3081032.md) ne permettent pas de sauver / restaurer une position lors du parcours du résultat d'une requête XPath de sélection.

### Fonctions XML et threads
Si votre application utilise des threads, le document XML est partagé entre tous ces threads. Pour plus de détails sur la gestion des threads, consultez [Gestion des threads](3077026.md).
Si la position courante dans un document XML est modifiée dans un thread, la position courante dans ce document XML est modifiée pour tous les threads.
