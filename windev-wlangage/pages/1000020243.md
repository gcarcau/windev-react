# Etiquette (Propriété)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

La propriété **Etiquette** permet de connaître et de définir l'étiquette d'un élément. Cette propriété est utilisable sur :

- une variable de type [AdresseEmail](1000020244.md).
- une variable de type [AdresseSIP](1000020245.md).
- une variable de type [AdresseWeb](1000020246.md).
- une variable de type [Evénement](1000020248.md).
- une variable de type [MessagerieInstantanée](1000020247.md).
- une variable de type [Téléphone](1000020241.md).
- une variable de type [Adresse](1000019944.md).
