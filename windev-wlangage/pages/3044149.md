# HAnnuleAlias (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Annule un alias précédemment déclaré avec la fonction [HAlias](3044176.md). Après cette opération, le fichier de données associé à l'alias n'est plus connu par le moteur HFSQL.
**Remarque** : Si le fichier alias est ouvert, il est automatiquement fermé lors de l'annulation.

## Exemple

```wlangage
// Crée 2 alias sur le fichier de données CLIENT
HAlias(CLIENT, CLIENT1)
HAlias(CLIENT, CLIENT2)
// Annule le premier alias
HAnnuleAlias(CLIENT1)
```

## Syntaxe

```wlangage
<Résultat> = HAnnuleAlias(<Fichier alias>)
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Fichier alias>` *Chaîne de caractères*
> Nom du fichier alias à annuler. Si le fichier alias n'existe pas, une erreur WLangage non fatale apparaît.

## Remarques

Lors de l'annulation d'un alias (fonction **HAnnuleAlias**) :

- les modifications réalisées avec les fonctions [HChangeNom](3044141.md) et [HChangeRep](3044168.md) ne sont pas annulées. Si l'alias est à nouveau décrit, ces paramètres sont conservés et ré-appliqués.
- si un fichier de données a été créé avec un nom donné par la fonction [HChangeNom](3044141.md) et un emplacement donné par la fonction [HChangeRep](3044168.md), le fichier de données n'est pas supprimé physiquement.
  - Pour supprimer un fichier de données créé à partir d'un alias, il faut utiliser la fonction [HSupprimeFichier](3044294.md).
  - Pour supprimer un dossier créé à partir d'un alias, il faut utiliser la fonction [HSupprimeRépertoire](1000019001.md).
