# <Variable EmailSessionOutlook>.OuvreSession (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **Autres** (Procédures stockées)

Ouvre une session d'emails via la messagerie Outlook.
**Remarque** : Pour ouvrir une session avec le logiciel de messagerie Outlook, utilisez la fonction [EmailOuvreSessionOutlook](3032128.md).

## Exemple

```wlangage
// Ouverture de la session d'emails
MaSessionOutlook est une emailSessionOutlook

SI MaSessionOutlook.OuvreSession() = Vrai ALORS
	// Connexion réalisée
SINON
	Erreur("Impossible d'établir la connexion")
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Session Outlook>.OuvreSession()
```

`<Résultat>` *Booléen*
> - Vrai si la session a été ouverte,
> - Faux dans le cas contraire. En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai.
>   Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Session Outlook>` *Variable de type emailSessionOutlook*
> > _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ Nom de la variable de type emailSessionOutlook correspondant à la session d'emails à manipuler.
