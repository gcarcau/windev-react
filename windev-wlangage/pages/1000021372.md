# OngletFermeTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Ferme tous les volets dynamiques d'un champ Onglet.

## Exemple

```wlangage
OngletFermeTout(ONG_OngletDyn)
```

## Syntaxe

```wlangage
OngletFermeTout(<Champ Onglet>)
```

`<Champ Onglet>` *Nom de champ*
> Nom du champ Onglet à manipuler.

## Remarques

Toutes les fenêtres internes associées aux volets dynamiques sont déchargées et les volets dynamiques sont supprimés du champ Onglet spécifié.
