# <Variable Image>.SauveBMP (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Sauve une image contenue dans une variable de type [Image](1000019650.md) :

- soit dans un fichier au format BMP.
- soit en mémoire.

**Remarque** : Cette fonction permet uniquement de sauvegarder des images pour des résolutions d'écran allant jusqu'à 32 bits.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les dessins.

## Exemple

```wlangage
MonImage est une Image = "Test.bmp"
// Sauve en mémoire l'image présente dans MonImage
ResSauvegarde = MonImage.SauveBMP(enMémoire)
```

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Windows, Code Utilisateur (MCU), Ajax)_ MonImage est une Image = "Test.bmp"
// Sauve l'image présente dans MonImage sur "C:\Documents\Image.BMP"
ResSauvegarde = MonImage.SauveBMP("C:\Documents\Image.BMP")

## Syntaxe

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS, Mac Catalyst, Code Utilisateur (MCU), Ajax)_ Sauvegarder une image dans un fichier au format BMP Masquer les détails
<Résultat> = <Variable Image>.SauveBMP(<Nom du fichier> [, <Nombre de couleurs>])

 <Résultat> : BooléenVrai si l'image a été sauvegardée, Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction ErreurInfo avec la constante errMessage. <Variable Image> : Variable de type ImageNom de la variable de type Image à manipuler. <Nom du fichier> : Chaîne de caractèresNom et chemin complet (ou relatif) du fichier BMP à créer. Un chemin de type UNC peut être utilisé. L'extension du fichier n'est pas obligatoire.Attention : Pour que l'image soit sauvée, le répertoire de destination doit exister.L'existence du fichier BMP n'est pas vérifiée. Si ce fichier existe, il est automatiquement écrasé. <Nombre de couleurs> : Entier optionnelNombre de couleurs de l'image sauvegardée :0 (par défaut) : nombre de couleurs défini dans la résolution d'écran16 : 16 couleursCe paramètre correspond au nombre de couleurs proposées dans la palette de couleurs lors de l'utilisation du fichier BMP.

#### Sauvegarder une image en mémoire

```wlangage
<Résultat> = <Variable Image>.SauveBMP([<Nombre de couleurs>])
```

`<Résultat>` *Buffer*
> Chaîne d'octets contenant l'image au format BMP. Cette chaîne d'octets peut être par la suite affectée à un champ Image, enregistrée dans un fichier (fonction [fSauveTexte](3036046.md)), envoyée à travers un réseau (grâce aux [fonctions Socket](3070007.md)), ...
`<Variable Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) à manipuler.
`<Nombre de couleurs>` *Entier optionnel*
> Nombre de couleurs de l'image sauvegardée :
>
> - 0 (par défaut) : nombre de couleurs défini dans la résolution d'écran.
> - 16 : 16 couleurs.
>
>
> Ce paramètre correspond au nombre de couleurs proposées dans la palette de couleurs lors de l'utilisation du fichier BMP.

**Composante : wd300pnt.dll**
