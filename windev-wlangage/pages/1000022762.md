# <Variable Connexion>.SupprimePlanification (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Supprime un élément planifié sur un serveur HFSQL : tâche planifiée (procédure stockée), sauvegarde, optimisation, rafraîchissement d'une vue matérialisée.

## Exemple

```wlangage
cnxMaBase est une Connexion

// Suppression de toutes les sauvegardes planifiées
tabDescSvg est un tableau dynamique de hDescriptionSauvegarde
tabDescSvg = cnxMaBase.ListePlanification(hlpSauvegarde)
hDescSvg est une hDescriptionSauvegarde
POUR TOUT hDescSvg DE tabDescSvg
	SI Position(hDescSvg.Source, cnxMaBase.BaseDeDonnées, 0, SansCasse) > 0 ALORS
		cnxMaBase.SupprimePlanification(hDescSvg)
	FIN
FIN
```

## Syntaxe

#### Supprimer une tâche planifiée

```wlangage
<Résultat> = <Connexion>.SupprimePlanification(<Tâche planifiée>)
```

`<Résultat>` *Booléen*
> - Vrai si la tâche planifiée a été supprimée,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle une tâche planifiée doit être supprimée.
`<Tâche planifiée>` *Variable de type hTâchePlanifiée*
> Nom de la variable de type [hTâchePlanifiée](1000017448.md), décrivant la tâche déclenchant une procédure stockée.

#### Supprimer une tâche d'optimisation planifiée

```wlangage
<Résultat> = <Connexion>.SupprimePlanification(<Tâche d'optimisation planifiée>)
```

`<Résultat>` *Booléen*
> - Vrai si la tâche d'optimisation planifiée a été supprimée,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle une tâche d'optimisation planifiée doit être supprimée.
`<Tâche d'optimisation planifiée>` *Variable de type hOptimisationPlanifiée*
> Nom de la variable de type [hOptimisationPlanifiée](1000018854.md) manipulée.

#### Supprimer une planification de sauvegarde

```wlangage
<Résultat> = <Connexion>.SupprimePlanification(<Sauvegarde planifiée>)
```

`<Résultat>` *Booléen*
> - Vrai si la sauvegarde planifiée a été supprimée,
> - Faux dans le cas contraire.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle une sauvegarde planifiée doit être supprimée.
`<Sauvegarde planifiée>` *Variable de type hDescriptionSauvegarde*
> Nom de la variable de type [hDescriptionSauvegarde](1000017455.md) manipulée.

#### Supprimer une planification de rafraîchissement de vue matérialisée

```wlangage
<Résultat> = <Connexion>.SupprimePlanification(<Vue matérialisée>)
```

`<Résultat>` *Booléen*
> - Vrai si la planification a été supprimée,
> - Faux dans le cas contraire.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle une planification de rafraîchissement de vue matérialisée doit être supprimée.
`<Vue matérialisée>` *Variable de type hPlanificationVueMatérialisée*
> Nom de la variable de type [hPlanificationVueMatérialisée](1000021444.md) contenant la description des vues matérialisées à rafraîchir.
