# Couleur (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Couleur** permet de connaître et de modifier la couleur d'un élément. Cette propriété est utilisable sur :

- les champs d'une fenêtre ou d'une page. Pour plus de détails, consultez [Couleur sur les champs d'une fenêtre ou d'une page](2510071.md).
- une variable de type [gglChemin](1000017433.md).
- une variable de type [gglMarqueur](1000017442.md).
- une variable de type [gglParamètreCarte](1000017505.md).
- une variable de type [Cadre](15140100.md).
- une variable de type [Couleur](1000019661.md).
- une variable de type [Calendrier](1000020663.md).
- une variable de type [Fond](1000022038.md).
- une variable de type [Jeton](1000023942.md).
- une variable de type [MarqueurImage](1000025796.md).
- une variable de type [gglEvénement](1000017440.md).
- une variable de type [diagTexte](1410088393.md).
- une variable de type [VisiteGuidée](1410090170.md).
- une variable de type [VisiteGuidéeEtape](1410090178.md).
