# <Traitement de texte>.Ferme (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

Ferme le fichier docx associé au champ Traitement de texte et libère le document.

## Exemple

```wlangage
TT_MonDocument.Ferme()
```

## Syntaxe

```wlangage
<Champ Traitement de texte>.Ferme()
```

`<Champ Traitement de texte>` *Nom de champ*
> Nom du champ Traitement de texte à manipuler.
> Le fichier physique associé au champ (s'il existe) est fermé. Les modifications réalisées dans le fichier ne sont pas sauvées avant sa fermeture (utilisez la fonction [<Traitement de texte>.Sauve](1000024393.md) si nécessaire).

**Composante : wd300mdl.dll**
