# iCloudCléValeurSurveille (Fonction)

> **Disponible :** **WINDEV Mobile** (iPhone/iPad)

Définit la procédure appelée lors du changement de la valeur d'une clé dans un conteneur de paires clé-valeur basé sur Apple iCloud.

## Exemple

```wlangage
SI iCloudCléValeurSurveille(Callback_Surveillance) = Vrai ALORS
	Trace("Lancement de la surveillance")
FIN

PROCÉDURE INTERNE Callback_Surveillance(nEvénement, tabClés)
	sLibelléEvénement, sListeClé est une chaîne

	SELON nEvénement
		CAS iccvModificationServeur : sLibelléEvénement = "Modification serveur"
		CAS iccvModificationSynchronisationInitiale : sLibelléEvénement = "Synchronisation initiale"
		CAS iccvViolationQuota : sLibelléEvénement = "Dépassement de quota"
		CAS iccvChangementCompte : sLibelléEvénement = "Changement de compte"
		CAS iccvEchecSynchronisation : sLibelléEvénement = "Échec de synchronisation"
		AUTRE CAS
				sLibelléEvénement = "Non géré"
	FIN

	Trace("------------------>>> " + sLibelléEvénement)

	POUR TOUT sClé DE tabClés
		Trace(sClé)
		sListeClé += [" / "] + sClé
	FIN
	gsCompteRenduSurveillance += [RC] + sLibelléEvénement + TAB + sListeClé
FIN
```

## Syntaxe

```wlangage
<Résultat> = iCloudCléValeurSurveille(<Procédure WLangage>)
```

`<Résultat>` *Booléen*
> - Vrai si la procédure de surveillance est activée,
> - Faux dans le cas contraire.
`<Procédure WLangage>` *Nom de procédure*
> Nom de la procédure WLangage (également nommée "callback") appelée lors d'un changement sur le serveur Apple iCloud. Cette procédure permet de connaître la cause de la modification.
> Pour plus de détails sur cette procédure, consultez [Paramètres de la procédure utilisée par la fonction iCloudCléValeurSurveille](1410088759.md).

**Classification Métier / UI : Code neutre**
