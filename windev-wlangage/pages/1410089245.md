# Brésil.VérifieCPF (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un numéro CPF (numéro d'identification personnel au Brésil).

## Exemple

```wlangage
// Test d'une variableMonNuméroCPF est une chaîne = "16650440396"Brésil.VérifieCPF(MonNuméroCPF) // renvoie Vrai // Test d'un champSAI_NuméroCPF = "ABC"Brésil.VérifieCPF(SAI_NuméroCPF) // renvoie Faux
```

```wlangage
// Test d'une variableMonNuméroCPF est une chaîneMonRésultat est un booléenSaisie("Entrez le numéro CPF : ", MonNuméroCPF)SI MonRésultat = Faux ALORS Info("Numéro CPF invalide")FIN
```

## Syntaxe

```wlangage
<Résultat> = Brésil.VérifieCPF(<Numéro à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un numéro CPF valide,
> - Faux dans le cas contraire.
`<Numéro à vérifier>` *Nom de champ ou variable de type chaîne*
> Numéro CPF à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.

**Composante : wd300std.dll**
