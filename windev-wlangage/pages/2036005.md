# OpenAI : Où trouver la clé OpenAI

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Plusieurs fonctionnalités de WINDEV, WEBDEV et WINDEV Mobile utilisent un compte OpenAI :

- [l'explication de code](9000219.md),
- [la génération de commentaires de code](9000219.md),
- [la génération des commentaires de réintégration dans le GDS](9000219.md).

Pour utiliser ces fonctionnalités, il est nécessaire de posséder un compte OpenAI et une clé OpenAI.

**Remarques** :

- Votre compte doit être associé à un moyen de paiement.
- Les fonctionnalités WINDEV, WEBDEV et WINDEV Mobile nécessitant un compte OpenAI utilisent le modèle **gpt-3.5**.
- Selon l'abonnement souscrit, le message "quota dépassé" peut être affiché.
- N'hésitez pas à consulter le site de openAI pour plus obtenir plus de détails concernant :
  - les différentes limites : nombre de mots par minutes, par jour, etc.
  - le tarif appliqué (ce tarif est disponible sur la page suivante à la date d'écriture de cette page : [https://platform.openai.com/docs/pricing#other-models](https://platform.openai.com/docs/pricing#other-models)).

## Comment générer et utiliser une clé OpenAI ?

Pour générer une clé OpenAI :

1. Lancez le site "[https://openai.com](https://openai.com)".
2. Dans le menu "Products", cliquez sur "API login".
3. Connectez-vous à votre compte ou créez un nouveau compte.
4. Cliquez sur le menu "Dashboard" en haut de la page.
5. Dans le menu à gauche, sélectionnez "API keys".
6. Cliquez sur "Create new secret key".
7. Indiquez le nom de votre clé puis cliquez sur "Create new secret key".
8. La clé est générée. Cette clé doit être immédiatement copiée car elle ne sera plus accessible. Si vous perdez cette clé, il sera nécessaire d'en générer une nouvelle.

**Attention** : Pour utiliser les fonctionnalités OpenAI dans WINDEV, WEBDEV et WINDEV Mobile, il est nécessaire de posséder un compte utilisant un moyen de paiement. Ce moyen de paiement peut être défini via l'option "Settings .. Billing .. Payment methods" (la roue crantée en haut de la page permet d'accéder au menu "Settings"). En effet, ce service peut entraîner une facturation. Consultez le détail de la facturation sur le site "[https://openai.com](https://openai.com)". Si le compte ne dispose pas des options d'abonnement nécessaires, le message **"quota dépassé"** peut être affiché.

### Saisir la clé dans WINDEV, WEBDEV ou WINDEV Mobile
Dans WINDEV, WEBDEV ou WINDEV Mobile, renseignez la clé OpenAI dans les options générales du produit :

1. Sous le volet "Accueil", dans le groupe "Environnement", déroulez "Options" et sélectionnez "Options générales de xxx".
2. Affichez l'onglet "API tierces".
3. Dans l'option "Clé OpenAI", indiquez la clé OpenAI générée précédemment.
4. Validez.
