# <btlePéripherique>.Initialise (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Initialise un périphérique Bluetooth Low Energy sous Windows.
Remarque : Sous Windows, cette fonction remplace la fonction [<Variable btlePériphérique>.Connecte](1000022195.md).

## Exemple

```wlangage
monPeriph est un btlePériphérique
SI monPeriph.Initialise() = Vrai ALORS
	Info("Périphérique initialisé")
SINON
	ErreurInfo()
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Périphérique>.Initialise()
```

`<Résultat>` *Booléen*
> - Vrai si l'initialisation a réussi,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de renseignements sur le problème rencontré.
`<Périphérique>` *Variable de type btlePériphérique*
> Nom de la variable de type [btlePériphérique](1000022054.md) correspondant au périphérique à manipuler.

## Remarques

Les fonctions WLangage Bluetooth Low Energy sont disponibles uniquement sur :

- les PC gérant le Bluetooth Low Energy version 5 minimum.
- les PC utilisant une clé Bluetooth gérant le Bluetooth Low Energy version 5 minimum.
