# EnModeKiosque (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Indique si l'application Android est en mode kiosque.
Dans ce mode, les actions de l'utilisateur sont limitées :

- l'utilisateur ne peut pas quitter l'application par lui-même,
- l'utilisateur ne peut pas lancer d'autres applications,
- l'utilisateur n'a pas accès aux paramètres de l'appareil,
- l'utilisateur ne voit et ne reçoit ni les notifications ni les appels.

Pour plus de détails, consultez [Application en mode kiosque](1000024431.md).

## Exemple

```wlangage
// Si l'application est en mode kiosque
SI EnModeKiosque() ALORS
	...
FIN
```

## Syntaxe

```wlangage
<Résultat> = EnModeKiosque()
```

`<Résultat>` *Booléen*
> - Vrai si l'application est actuellement en mode kiosque,
> - Faux dans le cas contraire.

## Remarques

### Mode kiosque simple ou complet
Deux modes kiosque sont disponibles :

- Mode kiosque simple : lors du passage en mode kiosque (fonction [KiosqueActive](1000024425.md)), un message demande à l'utilisateur de confirmer le passage de l'application en mode kiosque.
- Mode kiosque complet : l'application est également en mode "Device Owner" aucun message n'est affiché à l'utilisateur. Pour savoir si l'application utilise ce mode, utilisez la fonction [EnModeDeviceOwner](1000024428.md).

Si l'application est en mode kiosque simple, la fonction **EnModeKiosque** renverra Vrai uniquement lorsque l'utilisateur aura validé le message de confirmation du passage en mode kiosque.

### Disponibilité de la fonction
La fonction **EnModeKiosque** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **EnModeKiosque** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.

### Exécution des traitements contenant des erreurs de compilation
Par défaut, le mécanisme de sécurité du WLangage se déclenche uniquement si la ligne contenant l'erreur de compilation est exécutée.
Par exemple, si une fonction interdite dans le produit en cours est présente dans une boucle SI, le mécanisme de sécurité du WLangage se déclenchera uniquement si la ligne contenant cette fonction s'exécute.
