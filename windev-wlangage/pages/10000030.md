# Erreur 30 : Il est interdit de déclarer un traitement d'exception à l'intérieur d'un traitement ...

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

## Cause

Le traitement en cours utilise un traitement d'exception. Dans ce traitement d'exception, une nouvelle gestion des exception est mise en place. Il est impossible de gérer les exceptions dans un traitement d'exception.

## Conseil

Le code de traitement d'une exception doit être vérifié avec soin. En effet, si ce code contient une erreur, cette erreur ne pourra pas être interceptée par un traitement d'exception.

## Exemples

### Un traitement d'exception permet de gérer une erreur intervenue dans le premier traitement d'exception

**Code provoquant l'erreur**

```wlangage
SI EnModeTest() = Faux ALORS  QUAND EXCEPTION Erreur("Erreur:" + ExceptionInfo(errMessage) + " Code " + ExceptionInfo(errCode) + ...     " à la ligne " + ExceptionInfo(errLigne) + " de "  + ...      ExceptionInfo(errTraitement) , "EXC")   QUAND EXCEPTION   // Si on arrive pas a écrire dans le .ini, on quitte le programme   FinProgramme()    FIN  // Procédure d'écriture dans un fichier INI  bEcritDansIni("")  FINFIN
```

**Correction proposée**

Supprimez le traitement d'exception inutile et vérifiez le traitement d'exception.

```wlangage
SI EnModeTest() = Faux ALORS  QUAND EXCEPTION Erreur("Erreur:" + ExceptionInfo(errMessage) + " Code " + ExceptionInfo(errCode) + ...     " à la ligne " + ExceptionInfo(errLigne) + " de "  + ...      ExceptionInfo(errTraitement) , "EXC")  // Procédure d'écriture dans un fichier INI  bEcritDansIni("")  FINFIN
```
