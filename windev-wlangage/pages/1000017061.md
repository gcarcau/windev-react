# TableVersTexte (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP)

Crée une chaîne de caractères avec les données d'un champ Table ou Table hiérarchique. Cette chaîne pourra ensuite par exemple être sauvegardée dans un format spécifique.

## Exemple

```wlangage
sText est une chaîne
sText = TableVersTexte(TABLE_TABLE1, taSansTitre, ";")
fSauveTexte("Export.csv", sText)
```

## Syntaxe

```wlangage
<Résultat> = TableVersTexte(<Champ Table> [, <Options> [, <Séparateur de colonnes> [, <Séparateur de lignes> [, <Ligne début> [, <Ligne fin>]]]]])
```

`<Résultat>` *Chaîne de caractères*
> - Chaîne de caractères contenant les données du champ Table. Dans cette chaîne, les colonnes sont séparées par <Séparateur> et les lignes sont séparées par des Retours Chariot (RC).
> - Chaîne vide ("") en cas d'erreur ou si le champ Table est vide.
`<Champ Table>` *Nom de champ*
> Nom du champ à manipuler. Ce champ peut correspondre :
>
> - à un champ Table.
> - à un champ Table hiérarchique.
`<Options>` *Constante optionnelle*
> Paramètre les informations à prendre en compte dans la chaîne.
>
> | *taAvecColonnesInvisibles* | Exporte aussi les colonnes invisibles du champ. _(WINDEV)_ Les colonnes définies comme non imprimables et non exportables sont exportées. Ces colonnes sont définies : soit par programmation : propriété VisibleEnExportEtImpression à Faux. soit dans l'onglet "Général" de la fenêtre de description des colonnes : option "Export et impression" à "Jamais". |
> | --- | --- |
> | *taColonneOrdreAffiché* | Exporte les colonnes selon l'ordre des colonnes actuellement affiché dans le champ (et non selon l'ordre des colonnes défini sous l'éditeur). _(WEBDEV - Code Serveur)_ Cette constante n'est pas disponible. |
> | *taLigneSélectionnées* | Exporte uniquement les lignes sélectionnées (par défaut, toutes les lignes sont exportées). |
> | *taSansTitre* | Seules les données sont copiées. |
> | *taSansTotaux* | N'exporte pas :   - les lignes de totaux, moyenne et comptage automatique (par défaut, ces lignes sont exportées). - les lignes de calculs personnalisés (par défaut, ces lignes sont exportées). _(WEBDEV - Code Serveur)_ Cette constante n'est pas disponible. |
> | *taTitreColonnes* (Valeur par défaut) | Le titre des colonnes est inséré. |
`<Séparateur de colonnes>` *Chaîne de caractères optionnelle*
> Séparateur utilisé entre les colonnes. Par défaut, le séparateur utilisé est la tabulation (TAB).
`<Séparateur de lignes>` *Chaîne de caractères optionnelle*
> Séparateur utilisé entre les lignes. Par défaut, le séparateur utilisé est le Retour-Chariot (RC).
`<Ligne début>` *Entier optionnel*
> Numéro de la ligne de début de l'exportation.
> Si ce paramètre n'est pas précisé, la ligne de début est la première ligne du champ.
`<Ligne fin>` *Entier optionnel*
> Numéro de la ligne de fin de l'exportation.
> Si ce paramètre n'est pas précisé, la ligne de fin est la dernière ligne du champ.

## Remarques

### Conditions d'utilisation
La fonction **TableVersTexte** peut être utilisée indifféremment sur :

- un champ Table ou Table hiérarchique fichier.
- un champ Table ou Table hiérarchique par programmation.
- un champ monosélection ou multisélection.

### Limite
Les colonnes fusionnées sont ignorées.
