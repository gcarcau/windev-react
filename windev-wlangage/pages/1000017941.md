# Version (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

La propriété **Version** permet de connaître et de modifier la version d'un élément. Cette propriété est utilisable sur :

- une variable de type [rssFlux](1000017795.md).
- une variable de type [xlsDocument](1000017464.md).
- une variable de type [xmlDocument](1000018782.md).
- une variable de type [hbLecture](1000021701.md).
- une variable de type [pdfParamètre](1410087857.md).
- une variable de type [VisiteGuidée](1410090170.md).
- Nouveauté Abonnement
   une variable de type [zipParamètreCréationExe](1410091226.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
