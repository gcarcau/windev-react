# RendezVousPrécédent (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **Autres** (Procédures stockées)

Lit le rendez-vous précédent le rendez-vous en cours dans l'agenda d'une messagerie Lotus Notes ou Outlook.
Lors de la lecture d'un rendez-vous, les données de ce rendez-vous sont mis à jour dans la [structure RendezVous](1000011010.md). Pour récupérer les données du rendez-vous en cours, il suffit de récupérer les valeurs de la [structure RendezVous](1000011010.md).

**Rappel** : Cette fonction ne permet pas de lire le rendez-vous précédent le rendez-vous en cours dans l'agenda d'une messagerie Outlook Express.

## Exemple

```wlangage
// Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", ...
	"mail/julie.nsf", "C:\Lotus Notes\julie.id")
// Lecture du dernier rendez-vous
RendezVousDernier(IDSession)
// Ajout des rendez-vous trouvés dans un champ Liste
TANTQUE mRendezVous.EnDehors = Faux
	ListeAjoute(LISTE_ListeRDV, mRendezVous.Objet + TAB + mRendezVous.Lieu)
	RendezVousPrécédent(IDSession)
FIN
```

## Syntaxe

```wlangage
<Résultat> = RendezVousPrécédent(<Identifiant de la session>)
```

`<Résultat>` *Booléen*
> - Vrai si le rendez-vous précédent a été lu,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Identifiant de la session>` *Entier*
> Identifiant de la session à utiliser. Cet identifiant est renvoyé par une des fonctions suivantes : [EmailOuvreSessionNotes](3032121.md), [EmailOuvreSessionOutlook](3032128.md), [NotesOuvreBase](1000005101.md) ou [OutlookOuvreSession](3032123.md).

## Remarques

- La variable mRendezVous.EnDehors permet de savoir s'il y a un rendez-vous courant.
- Sous Outlook, il est possible de spécifier le mode de gestion des contacts/participants lors de l'ouverture de la session (fonction [EmailOuvreSessionOutlook](3032128.md) ou fonction [OutlookOuvreSession](3032123.md)).
