# ocrOption (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Le type **ocrOption** permet de définir toutes les options générales de l'OCR (Optical Character Recognition) natif. Les caractéristiques de ces options peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Création des options
MesOCROptions est un ocrOption

// Ne souhaite que les nombres lors de la lecture d'une image
MesOCROptions.NombreUniquement = Vrai

OCRParamètre(MesOCROptions)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type ocrOption
Les propriétés suivantes peuvent être utilisées pour manipuler les options avancées de l'OCR natif :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| AvecCorrecteurLinguistique | Booléen | - Vrai (valeur par défaut) pour activer le correcteur linguistique, - Faux pour le désactiver. |
| ListeMot | Tableau de chaînes | _(iPhone/iPad)_ Liste de mots à ajouter au modèle. |
| NombreUniquement | Booléen | - Vrai si l'OCR doit renvoyer uniquement les chiffres arabes, - Faux dans le cas contraire. _(iPhone/iPad)_ Cette propriété n'est pas disponible. |
| Précision | Constante de type Entier | _(iPhone/iPad)_ Mode de précision à utiliser : ocrPrécis : La précision de la lecture est privilégiée. ocrRapide : La rapidité de la lecture est privilégiée. |
