# Compression (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Compression** permet de connaître et de modifier le mode de compression des données.
Cette propriété est utilisable sur :

- une connexion (HFSQL Client/Serveur, ...). Pour plus de détails, consultez [Compression](1000017276.md).
- une variable de type [hDescriptionSauvegarde](1000017455.md).
