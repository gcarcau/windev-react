# PointGéo (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Le type **PointGéo** permet de définir toutes les caractéristiques avancées d'une position sur la sphère terrestre (point géographique).
Cette position est basée sur une approximation de la sphère terrestre, en coordonnées géographiques (latitude et longitude).
Les calculs effectués avec les coordonnées géographiques utilisent le **système WGS84**, système de référence notamment utilisé par le GPS : les points géographiques correspondent donc à des "points GPS".

Les caractéristiques de cette position géographique peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Déclaration d'un point géographique
p est un PointGéo
p.Latitude = 26.152
p.Longitude = 63.2101221

// Affichage du point sous forme d'une chaîne de caractères
Trace(GéométrieSérialiseWKT(p))

// Résultat : "POINT(63.2101221 26.152)"
// Attention : au format WKT, la longitude est précisée avant la latitude
```

## Propriétés

### Propriétés spécifiques à la description des variables de type PointGéo
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **PointGéo** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Latitude | Réel | Latitude du point. Correspond à l'angle que le point fait avec l'équateur. |
| Longitude | Réel | Latitude du point. Correspond à l'angle que le point fait avec le méridien de Greenwich.  La latitude est une valeur comprise entre -180 (exclue) et +180 (incluse) degrés. |
| Type | Constante de type Entier | Type de la géométrie en cours. Dans le cas d'un point géographique, correspond à la constante *tgPointGéo*. Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfPointGéo*. **Cette propriété est disponible en lecture uniquement.** |
