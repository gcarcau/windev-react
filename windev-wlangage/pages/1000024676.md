# <Variable WDPic>.DessineTexte (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Dessine un texte dans une variable de type [WDPic](1000023503.md) (sur le calque d'arrière-plan).

## Exemple

```wlangage
MonImageWDPic est un WDPic = "Test.bmp"
// Dessin d'un texte en jaune clair
MonImageWDPic.DessineTexte(10, 20, "Le développement facile", JauneClair)
IMG_MonDessin = MonImageWDPic
```

## Syntaxe

```wlangage
<Image WDPic>.DessineTexte(<Abscisse> , <Ordonnée> , <Texte> [, <Couleur du texte> [, <Gestion du &>]])
```

`<Image WDPic>` *Variable de type WDPic*
> Nom de la variable de type [WDPic](1000023503.md) à manipuler. Seul le calque d'arrière-plan sera manipulé.
`<Abscisse>` *Entier*
> Coordonnées (abscisse) du texte à dessiner (en pixels).
`<Ordonnée>` *Entier*
> Coordonnées (ordonnée) du texte à dessiner (en pixels).
`<Texte>` *Type correspondant au texte à dessiner*
> Texte à dessiner. Ce texte peut être :
>
> - une chaîne de caractères (sans caractères de contrôle tels que TAB, RC, etc.),
> - un numérique.
`<Couleur du texte>` *Entier ou constante (optionnel)*
> Couleur du texte à utiliser. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md).
>
>
> Si ce paramètre n'est pas précisé, la couleur du texte :
>
>
> - est Noire si la fonction [<Variable WDPic>.Stylo](1000024636.md) n'a pas été utilisée auparavant,
> - correspond à la couleur précisée dans le dernier appel à la fonction [<Variable WDPic>.Stylo](1000024636.md).
`<Gestion du &>` *Booléen optionnel*
> - Vrai (valeur par défaut) si le "&" ne doit pas être interprété comme opérateur de soulignement.
> - Faux si le "&" doit être interprété comme opérateur de soulignement : le caractère qui suit le caractère "&" sera souligné.

## Remarques

### Police
Par défaut :

- La police utilisée est la police "MS Sans Serif" (taille 13).
- Le sens d'écriture est horizontal (de gauche à droite).
- L'angle haut gauche de l'image a les coordonnées (0,0).
- Le caractère "&" n'est pas interprété.

Pour modifier ces paramètres, utilisez la fonction [<Variable WDPic>.Police](1000024502.md).

### Coordonnées
Les coordonnées sont indiquées par rapport au coin haut gauche de l'image (coordonnées (0,0)).
Les coordonnées correspondent au point haut gauche du rectangle dans lequel le texte sera dessiné. L'emplacement précis du texte dans ce rectangle dépend de la taille, de la forme et des attributs de la police.

### Gestion du '&'
Le paramètre <Gestion du & > permet de gérer la présence du caractère '&'.
Exemple :

- le "&" ne doit pas être interprété comme opérateur de soulignement. Par exemple :
  ```wlangage
  MonImageWDPic.DessineTexte(10, 10, "Lui&Moi", RougeClair, Vrai)
  ```
  affichera "Lui&Moi".
- le "&" doit être interprété comme opérateur de soulignement : le caractère qui suit le caractère "&" sera souligné. Par exemple :
  ```wlangage
  MonImageWDPic.DessineTexte(10, 10, "&Saisie", RougeClair, Faux)
  ```
  affichera "Saisie".

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU))_ LimitationsEn mode anti-aliasing (fonction <Variable WDPic>.ChangeMode) ou en mode opacité (fonction <Variable WDPic>.DébutDessin), la fonction <Variable WDPic>.DessineTexte est disponible uniquement pour les polices TrueType.
