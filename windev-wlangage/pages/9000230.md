# Edition de texte (Editeur de code)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Lors du développement d'une fonctionnalité, il peut être utile de conserver le même environnement pour ouvrir des fichiers texte.
L'éditeur de code permet d'ouvrir vos fichiers texte, en proposant également une coloration syntaxique (si le langage édité est connu).

Nouveauté Abonnement
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Ouvrir un fichier texte

Pour ouvrir un fichier texte sous l'éditeur de code :

- Réalisez un "Drag and Drop" du fichier vers l'éditeur de projets.
- Utilisez l'option "Ouvrir" : sous le volet "Accueil", dans le groupe "Général", déroulez "Ouvrir" et sélectionnez "Ouvrir". Sélectionnez ensuite le fichier texte à ouvrir.
- Si le fichier est présent dans le volet "Explorateur de projet", double-cliquez sur son nom.

### Informations affichées sous l'éditeur
Lorsque le fichier est ouvert sous l'éditeur de code, un bandeau spécifique permet d'obtenir des informations sur le fichier ouvert et si nécessaire de les modifier.
Les informations affichées sont les suivantes :

- langage du fichier texte,
- encodage,
- type de fin de ligne.

## Détail des informations affichées

### Langage et coloration syntaxique
Le premier indicateur correspond au langage du fichier affiché. La détection du langage est basée sur l'extension du fichier lors de son ouverture.
Pour changer le langage correspondant au fichier affiché :

1. Cliquez sur le nom du langage actuel. Un menu alphabétique s'affiche.
2. Sélectionnez l'initiale puis le nom du langage.

Le fichier affiché est automatiquement coloré selon les caractéristiques du langage choisi.
Remarques :

- Les fichiers "Texte" (extension txt) ne sont pas colorés.
- De nombreux langages sont pris en compte. Quelques exemples :
  | - HTML - XML - CSS - SQL - C# - JAVA - Objective-C - Javascript - Typescript - PHP - Swift - Kotlin - bat | - C - C++ - Fortran - go - ini - json - markdown - powershell - python - rust - shell - visual basic - yaml - zig |
  | --- | --- |

### Encodage du fichier sur disque
Lors de l'ouverture du fichier texte, l'encodage est automatiquement détecté. En création d'un fichier texte, l'encodage est automatiquement réalisé en UTF-8.
Pour changer l'encodage correspondant au fichier affiché :

1. Cliquez sur l'encodage actuel. La liste des encodages disponibles s'affiche.
2. Sélectionnez l'encodage voulu.
3. Enregistrez le fichier.

### Type de fin de ligne
Il est possible de sélectionner et de connaître le type de délimiteur de fin de ligne utilisé par le fichier. La détection est automatiquement réalisée en ouverture du fichier.
Pour changer le type de délimiteur de fin de ligne au fichier affiché :

1. Cliquez sur le délimiteur actuel.
2. Sélectionnez le délimiteur voulu.
3. Enregistrez le fichier.
