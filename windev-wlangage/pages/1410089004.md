# <Variable Image>.ModifieContraste (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Modifie le contraste d'une image contenue dans une variable de type [Image](1000019650.md).

## Exemple

```wlangage
MonImage est une Image// Modification du contrasteMonImage.ModifieContraste(50)
```

## Syntaxe

```wlangage
<Résultat> = <Variable Image>.ModifieContraste(<Variation du contraste> [, <Image destination>])
```

`<Résultat>` *Booléen*
> - Vrai si le contraste a été modifié,
> - Faux dans le cas contraire.
`<Variable Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) à manipuler.
`<Variation du contraste>` *Réel*
> Valeur comprise entre -100 et +100. Les valeurs négatives diminuent le contraste, les valeurs positives l'augmentent. Cette valeur sera ajoutée au contraste actuel pour obtenir un nouveau contraste.
`<Image destination>` *Nom de champ optionnel ou variable de type Image optionnelle*
> Image dans laquelle l'image transformée sera dessinée. Cette image peut correspondre :
>
> - au nom d'un champ Image.
> - au nom d'une variable de type [Image](1000019650.md).
>
> Si ce paramètre n'est pas spécifié, la transformation s'effectuera sur <Variable Image>.

**Classification Métier / UI : Code neutre**

**Composante : wd300pnt.dll**
