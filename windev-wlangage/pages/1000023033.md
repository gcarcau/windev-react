# Sélection (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **Sélection** permet d'obtenir les caractéristiques de la sélection (ou du curseur) :

- dans un champ Traitement de texte.
  Remarque : Cette sélection est située dans la partie en cours d'édition dans le champ (corps, entête ou pied de page).
- dans un champ Tableur.
- dans un champ Editeur HTML.
- dans un champ Editeur de diagrammes.

## Exemple

> _(WINDEV)_ // Récupération du fragment sélectionné par l'utilisateur
MaSélection est un docFragment = TT_Doc.Sélection.Fragment
// Mise en gras de la sélection de l'utilisateur
MaSélection.MiseEnForme.PoliceGras = Vrai

// Récupération de la première section du texte sélectionné par l'utilisateur
MaSection1 est une docSection = TT_Doc.Sélection.Section[1]

```wlangage
// Obtenir la sélection dans un champ Editeur de diagrammes
MaSélection est un diagSélection <- EDIAG_MonDiagramme.Sélection
SI MaSélection.Forme.Occurrence > 0 ALORS
	// Obtenir les formes
	POUR TOUT stForme DE MaSélection.Forme
		LIB_INFO_SELECTION = "Sélection de " + stForme.Nom +
		" [ " + stForme.X + ", " + stForme.Y + " - " + stForme.Largeur +
		"x" + stForme.Hauteur + " ]"
	FIN
SINON
	LIB_INFO_SELECTION = "Cliquez sur une forme dans le diagramme pour connaître la sélection"
FIN
```

## Syntaxe

> _(WINDEV)_ Récupérer les propriétés de la sélection dans un champ Traitement de texte Masquer les détails
<Résultat> = <Champ Traitement de texte>.Sélection.<Propriété>

 <Résultat> : Type correspondant à la propriété utiliséeRésultat attendu (voir "Remarques"). <Champ Traitement de texte> : Nom de champNom du champ Traitement de texte. <Propriété> : Propriété à utiliser sur la sélection (voir Remarques).

> _(WINDEV)_ Récupérer les propriétés de la sélection dans un champ Tableur Masquer les détails
<Résultat> = <Champ Tableur>.Sélection

 <Résultat> : Variable de type tblrSélectionVariable de type tblrSélection décrivant la sélection. <Champ Tableur> : Nom de champNom du champ Tableur.

> _(WINDEV)_ Récupérer les propriétés de la sélection dans un champ Editeur HTML Masquer les détails
<Résultat> = <Champ Editeur HTML>.Sélection

 <Résultat> : Variable de type edtHTMLSélectionVariable de type edtHTMLSélection décrivant la sélection. <Champ Editeur HTML> : Nom de champNom du champ Editeur HTML.

#### Récupérer les propriétés de la sélection dans un champ Editeur de diagrammes

```wlangage
<Résultat> = <Champ Editeur de diagrammes>.Sélection
```

`<Résultat>` *Variable de type diagSélection*
> Variable de type [diagSélection](1410088172.md) décrivant la sélection.
`<Champ Editeur de diagrammes>` *Nom de champ*
> Nom du champ Editeur de diagrammes.

## Remarques

> _(WINDEV)_ Sélection dans un champ Traitement de textePropriétéExplicationsFragment<Résultat> correspond à une variable de type docFragment contenant les caractéristiques du fragment sélectionné. Exemple : <Résultat> = <Champ Traitement de texte>.Sélection.FragmentSection[X]Permet de récupérer la section associée à la sélection. X correspond au numéro de la section à récupérer.<Résultat> correspond à une variable de type docSection contenant les caractéristiques de la section associée à la sélection. Exemple : <Résultat> = <Champ Traitement de texte>.Sélection.Section[1]
