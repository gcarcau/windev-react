# Manipuler un champ Ascenseur par programmation

> **Disponible :** **WINDEV** (Windows, Linux)

## Présentation

WINDEV permet de manipuler un champ Ascenseur directement par programmation. Il suffit d'utiliser directement la variable du champ ascenseur dans le code.
La variable du champ Ascenseur :

- correspond au nom de l'ascenseur.
- est initialisée avec la position de la cage de l'ascenseur.

## Récupérer la position du curseur

Pour récupérer la position du curseur dans un champ Ascenseur, utilisez la syntaxe suivante :
```wlangage
<Position> = <Nom Ascenseur>
```

<Position> est une variable de type entier

**Remarque** : Il est également possible d'utiliser la propriété [Valeur](2510130.md).

## Modifier la position du curseur

Pour modifier la position du curseur dans un champ Ascenseur, utilisez la syntaxe suivante :
```wlangage
<Nom Ascenseur> = <valeur>
```

<Valeur> est une valeur comprise entre la valeur minimale et la valeur maximale de l'ascenseur. Ces valeurs ont été décrites dans la fenêtre de description du champ, ou par programmation, grâce aux propriétés [BorneMin](2510008.md) et [BorneMax](2510009.md).

**Remarque** : Il est également possible d'utiliser la propriété [Valeur](2510130.md).

## Propriétés spécifiques à la gestion d'un champ Ascenseur

Les propriétés suivantes sont spécifiques à la gestion des caractéristiques d'un champ Ascenseur par programmation.

| [Avance](1000021574.md) | Permet de connaître et de modifier le pas d'avancement d'un champ Ascenseur. |
| --- | --- |
| [AvanceRapide](2510011.md) | Permet de connaître et de modifier la valeur de l'avance rapide d'un champ Ascenseur. |
| [BorneMax](2510009.md) | Permet de connaître et de modifier la borne maximale d'un champ Ascenseur. |
| [BorneMin](2510008.md) | Permet de connaître et de modifier la borne minimale d'un champ Ascenseur. |

Pour connaître la liste complète des propriétés du WLangage pouvant être utilisées avec un champ de type Ascenseur, consultez [Propriétés associées au champ Ascenseur](1013112.md).
