# FIListePrécédent (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Affiche la fenêtre interne précédente de la liste des fenêtres internes parcourue par un champ Fenêtre Interne.

## Exemple

```wlangage
FIListePrécédent(FI_ChampFenêtreInterne)
```

## Syntaxe

```wlangage
<Résultat> = FIListePrécédent(<Champ Fenêtre Interne>)
```

`<Résultat>` *Booléen*
> - Vrai si la fenêtre interne précédente a été affichée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Fenêtre Interne>` *Nom de champ*
> Nom du champ Fenêtre Interne à manipuler.

## Remarques

Le changement de fenêtre interne avec les fonctions [FIListeSuivant](1000020564.md) et **FIListePrécédent** utilise une animation. Pour effectuer un changement sans animation, utilisez la fonction [FIListePosition](1000020562.md).

**Composante : wd300obj.dll**
