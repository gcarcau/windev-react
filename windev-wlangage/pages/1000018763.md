# Option (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Option** permet de connaître et de modifier certaines options. Cette propriété est utilisable sur :

- un champ Code-barres. Pour plus de détails, consultez [Option](2510154.md).
- une variable de type [emailSessionIMAP](1000018957.md).
- une variable de type [emailSessionPOP3](1000018759.md).
- une variable de type [emailSessionSMTP](1000018765.md).
- une variable de type [hParamètreFichier](1000018900.md).
- une variable de type [Description d'API](1000019149.md).
- une variable de type [Description de TâcheParallèle](1000021586.md).
- une variable de type [Description d'IndexFullText](1000017461.md).
- une variable de type [mqttSession](1000023023.md).
- une variable de type [mongoOpérationAjout](1410089163.md).
- une variable de type [mongoOpérationModificationUn](1410089164.md).
- une variable de type [mongoOpérationModificationTout](1410089165.md).
- une variable de type [mongoOpérationRemplacementUn](1410089166.md).
- une variable de type [mongoOpérationSuppressionTout](1410089162.md).
- une variable de type [mongoOpérationSuppressionUn](1410089161.md).
- une variable de type [OAuth2Paramètres](1000022212.md).
- Nouveauté 2025
   une variable de type [pdfChamp](1410090536.md).
- Nouveauté 2025
