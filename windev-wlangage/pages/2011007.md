# Editeur d'analyses : Manipulation d'un fichier de données

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Les principales manipulations possibles sur un fichier de données depuis l'éditeur d'analyses sont les suivantes :

- Dupliquer/Copier un fichier de données.
- Supprimer un fichier de données.
- Renommer un fichier de données.
- Utiliser un dictionnaire.
- Créer à vide le fichier de données physique correspondant (fichier ".FIC").

## Manipulation d'un fichier de données

### Dupliquer/Copier un fichier de données
La duplication d'un fichier de données permet de disposer de deux fichiers de données identiques de noms différents.
Pour dupliquer/copier un fichier de données :

1. Sélectionnez le fichier de données à dupliquer dans l'éditeur d'analyses.
2. Sous le volet "Accueil", dans le groupe "Edition", cliquez sur "Dupliquer".
  Remarque : Il est également possible de sélectionner l'option "Dupliquer" dans le menu contextuel du fichier de données.
3. Spécifiez les informations demandées et validez. Le fichier de données dupliqué est automatiquement créé dans l'analyse (MLD) en cours.

### Supprimer un fichier de données
Pour supprimer un fichier de données :

1. Sélectionnez le fichier de données à supprimer dans l'éditeur d'analyses.
2. Affichez le menu contextuel du fichier de données sélectionné (clic droit).
3. Sélectionnez l'option "Supprimer". Le fichier de données est automatiquement supprimé de l'analyse (MLD). Si des liaisons pointaient sur ce fichier de données, ces liaisons sont également supprimées.

**Remarque** : Lors de la création d'un fichier de données dont le nom est identique à celui d'un fichier de données précédemment supprimé, WINDEV, WEBDEV et WINDEV Mobile proposent de restaurer la description du fichier de données supprimé.

### Renommer un fichier de données
Pour renommer un fichier de données :

1. Sélectionnez le fichier de données à renommer dans l'éditeur d'analyses.
2. Affichez la description du fichier de données :
  - Sous le volet "Analyse", dans le groupe "Élément courant", cliquez sur "Description".
  - Affichez le menu contextuel du fichier de données (clic droit) et sélectionnez l'option "Description du fichier de données".
3. Dans la fenêtre de description, modifiez le nom du fichier de données (et si nécessaire son nom sur disque).
4. Validez. Le fichier de données est automatiquement renommé.

### Utiliser un dictionnaire
Un fichier de données peut simplement être intégré dans un dictionnaire pour être ré-utilisé par exemple dans une nouvelle application. L'intégration du fichier de données dans un dictionnaire se fait par simple "Drag and Drop" du fichier de données depuis l'éditeur d'analyses, vers le dictionnaire (affiché dans le [volet "Dictionnaire"](2027014.md)).
Lors de son intégration dans le dictionnaire, la description du fichier de données peut être abonnée aux modifications. Toute modification réalisée dans la description du fichier de données pourra être reportée sur l'objet du dictionnaire et sur toutes les utilisations de cet objet.

Pour plus de détails, consultez le [dictionnaire](2023002.md).

### Créer à vide le fichier de données physique correspondant à la description
Pour créer à vide le fichier de données physique correspondant :

1. Dans l'éditeur d'analyses, sélectionnez le fichier de données pour lequel un fichier physique doit être créé.
2. Affichez le menu contextuel du fichier de données (clic droit) et sélectionnez l'option "Créer le fichier de données".
3. Sélectionnez le répertoire dans lequel le fichier de données doit être créé et validez.

Les fichiers suivants sont automatiquement créés dans le répertoire donné :

- "<Nom du fichier de données>.FIC" (fichier de données).
- "<Nom du fichier de données>.MMO" (fichier mémo).
- "<Nom du fichier de données>.NDX" (fichier d'index).

Si le fichier de données est journalé, un sous-répertoire "JNL" sera automatiquement créé et contiendra les différents fichiers du journal.

Si le fichier de données contient un index full-text, un fichier "<Nom du fichier de données>.FTX" sera créé.

**Remarques** :

- Cette option est identique à l'utilisation de la fonction [HCréationSiInexistant](3044254.md).
- Si le fichier de données existe déjà dans le répertoire spécifié, cette option n'est pas prise en compte.
