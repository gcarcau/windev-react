# Source (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **Source** permet de connaître et de modifier la source d'un élément. Cette propriété est utilisable sur :

- un champ Graphe ou une connexion. Pour plus de détails, consultez [Propriété Source sur un graphe ou une connexion](2510147.md).
- une variable de type [hDescriptionSauvegarde](1000017455.md).
- une variable de type [rssEntrée](1000017792.md).
- la structure [Email](3032029.md)
- une variable de type [Email](1000018713.md).
- une variable de type [Contact](1000020254.md).
- une variable de type [OpenIDIdentité](1000023567.md).
- une variable de type [AppleID](1000025405.md).
- une variable de type [TéléchargementInfo](1410087306.md).
- une variable de type [TéléchargementParamètre](1410087293.md).
