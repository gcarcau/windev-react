# Paramètres de la procédure utilisée par la fonction HVérifieMémoAsynchrone

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Procédure WLangage (également nommée "callback") appelée par la fonction [HVérifieMémoAsynchrone](1410091107.md) pour chaque fichier de données HFSQL Client/Serveur vérifié.
Nouveauté Abonnement
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
CnxBaseDeDonnées est une Connexion
TableauFichier est un tableau de hParamètreFichier

MonFichierParam est un hParamètreFichier
MonFichierParam.Nom = "ActionPossible"
// MonFichierParam.MotDePasse = ""
// La propriété Option n'est pas prise en compte
TableauAjoute(TableauFichier, MonFichierParam)

HVérifieMémoAsynchrone(CnxBaseDeDonnées, TableauFichier, CB_HVérifieMémoAsynchrone)
	PROCÉDURE INTERNE CB_HVérifieMémoAsynchrone(MonFichier est une chaîne, MonRésultat est une chaîne)
		SI MonRésultat = "" ALORS
			Trace("Fichier traité et vérifié " + MonFichier)
		SINON
			Trace("Fichier traité avec problème " + MonFichier)
		FIN
	FIN
```

## Syntaxe

```wlangage
HVérifieMémoAsynchrone_Callback(<Fichier de données> , <Résultat>)
```

`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données HFSQL Client/Serveur manipulé.
`<Résultat>` *Chaîne de caractères*
> - Chaîne vide ("") si aucun problème n'a été trouvé.
> - En cas de corruption de la liste des blocs libres, <Résultat> contient :
>   ```wlangage
>   <TAB> + "-1"+ RC + <Rubrique 1> + TAB + <Numéro d'enregistrement 1> + RC + ...<Rubrique N> + TAB + <Numéro d'enregistrement N>
>   ```
>    où :
>   - <Rubrique X> est la rubrique mémo,
>   - <Numéro d'enregistrement> est le numéro de l'enregistrement contenant la rubrique Mémo.
