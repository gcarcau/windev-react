# Erreur 123 : La constante existe déjà

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Cause

Vous tentez de déclarer une constante qui a déjà été déclarée dans le projet ou la fenêtre en cours.

## Correction

Renommez une des constantes ou supprimez la déclaration inutile.

## Exemples

### Deux constantes sont utilisées dans le même traitement avec la même valeur

**Code provoquant l'erreur**

```wlangage
// -- Code d'initialisation du projetCONSTANTE B=5 CONSTANTE B = 5FIN
```

**Correction proposée**

Une des déclarations est inutile. Supprimez la constante en trop.

```wlangage
// -- Code d'initialisation du projetCONSTANTE B=5
```

### Une constante est définie dans le code du projet puis dans le code d'initialisation d'une fenêtre

**Code provoquant l'erreur**

```wlangage
// -- Code d'initialisation du projetCONSTANTE B = 5 // -- Déclarations globales de la fenêtreCONSTANTE B = 7FIN
```

**Correction proposée**

Renommez la seconde déclaration.

```wlangage
// -- Code d'initialisation du projetCONSTANTE B = 5 // -- Déclarations globales de la fenêtreCONSTANTE D = 7FIN
```
