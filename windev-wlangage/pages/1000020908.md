# upnpService (Type de variable)

> **Disponible :** **WINDEV** (Windows) · **WINDEV Mobile** (iPhone/iPad)

Le type **upnpService** permet de définir toutes les caractéristiques avancées d'un service fourni par le périphérique UPnP. Les caractéristiques de ce type de variable peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
Ce type de variable est utilisé par les variables de type [upnpPériphérique](1000020903.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Propriétés

### Propriétés spécifiques à la description des variables de type upnpService
Les propriétés suivantes peuvent être utilisées pour manipuler un service fourni par un périphérique UPnP :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Identifiant | Chaîne de caractères | Identifiant du service. |
| Type | Chaîne de caractères | Type du service. |
| URL | Chaîne de caractères | URL contenant la description du service. |
| URLControle | Chaîne de caractères | URL pour envoyer les commandes au service. |
