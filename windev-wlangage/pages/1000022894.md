# <Agenda>.AjouteRendezVous (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Mac Catalyst)

Ajoute un nouveau rendez-vous dans un champ Agenda.
> _(WINDEV, WEBDEV - Code Serveur, PHP)_ Si le champ Agenda est lié à une source de données, le rendez-vous est également ajouté dans la source de données.

## Exemple

```wlangage
// Ajoute un rendez-vous en précisant ses caractéristiques
AGD_Agenda.AjouteRendezVous("Rendez-vous chez le dentiste", "202310291800", "202310291900")
```

```wlangage
// Ajoute un rendez-vous en utilisant le type RendezVous
gMonRendezVous est un RendezVous
gMonRendezVous.Titre = "Rendez-vous avec l'expert comptable"
gMonRendezVous.Lieu = "12 rue des fleurs, Montpellier"
gMonRendezVous.Contenu = "Ne pas oublier les dossiers en cours"
gMonRendezVous.DateDébut = "202310291800"
gMonRendezVous.DateFin = "202310291900"
AGD_Agenda.AjouteRendezVous(gMonRendezVous)
```

```wlangage
// Ajoute un rendez-vous en utilisant le type RendezVous et avec répétition
// Tous les premier lundi du mois
// un Lundi dans les jours de 1 à 7 du mois = le 1er du mois.
x est un RendezVous
x.DateDébut = DateDuJour() + "1200"
x.DateFin = DateDuJour() + "1400"
x.AvecRépétition =Vrai
y est une Répétition
y.Type = plnTousLesJours
y.JourDeLaSemaine = 1
y.JourDuMois = "1-7"
y.JourDuMoisOuDeLaSemaine = Faux
x.Répétition = y
AGD_Agenda.AjouteRendezVous(x)
```

## Syntaxe

#### Ajouter un rendez-vous en précisant ses caractéristiques

```wlangage
<Résultat> = <Champ Agenda>.AjouteRendezVous(<Titre> , <Date de début> [, <Date de fin> [, <Catégorie>]])
```

`<Résultat>` *Entier*
> - Indice du rendez-vous ajouté,
> - -1 en cas d'erreur. La fonction [ErreurInfo](3013008.md) permet d'identifier l'erreur.
`<Champ Agenda>` *Nom de champ*
> Nom du champ Agenda à manipuler. Ce champ peut correspondre :
>
> - au champ Agenda d'une fenêtre.
> - au champ Agenda d'un état.
> - au champ Agenda d'une page.
`<Titre>` *Chaîne de caractères*
> Titre du rendez-vous.
`<Date de début>` *Chaîne de caractères ou variable de type DateHeure*
> Date et heure de début du rendez-vous.
`<Date de fin>` *Chaîne de caractères optionnelle ou variable optionnelle de type DateHeure*
> Date et heure de fin du rendez-vous. Si ce paramètre n'est pas spécifié, la durée par défaut du rendez-vous sera de 1 heure.
`<Catégorie>` *Chaîne de caractères optionnelle*
> Nom de la catégorie associée au rendez-vous. Si ce paramètre n'est pas spécifié, le rendez-vous n'est associé à aucune catégorie. Si la catégorie n'existe pas, elle est automatiquement créée.

#### Ajouter un rendez-vous dans un champ Agenda en utilisant le type RendezVous

```wlangage
<Résultat> = <Champ Agenda>.AjouteRendezVous(<Rendez-Vous>)
```

`<Résultat>` *Entier*
> - Indice du rendez-vous ajouté,
> - -1 en cas d'erreur. La fonction [ErreurInfo](3013008.md) permet d'identifier l'erreur.
`<Champ Agenda>` *Nom de champ*
> Nom du champ Agenda à manipuler. Ce champ peut correspondre :
>
> - au champ Agenda d'une fenêtre.
> - au champ Agenda d'un état.
> - au champ Agenda d'une page.
`<Rendez-Vous>` *Variable de type RendezVous*
> Nom de la variable de type [RendezVous](1000019244.md) décrivant les caractéristiques du rendez-vous à ajouter.
