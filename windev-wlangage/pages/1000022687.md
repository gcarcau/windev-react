# <Variable Connexion>.InfoUtilisateur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Met à jour [les variables de gestion des utilisateurs](3044315.md) avec les informations concernant l'utilisateur spécifié. Pour des raisons de sécurité, le mot de passe de l'utilisateur n'est pas récupéré.

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion

// Ouverture de la connexion
MaConnexion.OuvreConnexion()
// Association du fichier de données à la connexion
Client.ChangeConnexion(MaConnexion)
SI MaConnexion.InfoUtilisateur("Florence") = Vrai ALORS
	Info("Voici les caractéristiques de l'utilisateur" + RC + ...
		"Login : " + HUtilisateur.Login + ...
		"Nom Complet : " + HUtilisateur.NomComplet + ...
		"Email : " + HUtilisateur.Email)
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.InfoUtilisateur(<Utilisateur>)
```

`<Résultat>` *Booléen*
> - Vrai si la structure de gestion des utilisateurs a été mise à jour,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
>
>
> Remarque : Une erreur "Utilisateur inconnu" sera renvoyée par la fonction [HErreurInfo](3044071.md) si l'utilisateur en cours n'a pas le droit de visualisation des utilisateurs (constante *hDroitVisualisationUtilisateur*). Ce droit peut être défini par la fonction [<Variable Connexion>.ModifieDroitServeur](1000022710.md).
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle les renseignements concernant l'utilisateur doivent être récupérés.
`<Utilisateur>` *Chaîne de caractères*
> Nom de l'utilisateur pour lequel les informations doivent être récupérées. Ce nom doit correspondre à la variable **HUtilisateur.Login** de l'un des utilisateurs de la connexion spécifiée.
