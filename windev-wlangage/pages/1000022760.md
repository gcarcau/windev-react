# <Variable Connexion>.SupprimeOptimisationPlanifiée (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Supprime une tâche d'optimisation planifiée de fichiers de données HFSQL Client/Serveur.

## Syntaxe

```wlangage
<Résultat> = <Connexion>.SupprimeOptimisationPlanifiée(<Tâche à supprimer>)
```

`<Résultat>` *Booléen*
> - Vrai si la tâche a été supprimée,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle la tâche doit être supprimée.
`<Tâche à supprimer>` *Entier*
> Identifiant de la tâche à supprimer. Cet identifiant est fourni par les fonctions [<Variable Connexion>.AjouteOptimisationPlanifiée](1000022641.md) et [<Variable Connexion>.ListeOptimisationPlanifiée](1000022695.md).

## Remarques

### Droits nécessaires
Pour avoir le droit de supprimer une tâche d'optimisation planifiée, il est nécessaire :

- soit d'être le propriétaire de la tâche.
- soit d'être super-utilisateur.

**Composante : wd300hf.dll**
