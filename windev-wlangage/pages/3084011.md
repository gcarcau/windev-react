# Outils WINDEV, WEBDEV et WINDEV Mobile

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

## Lancer un outil redistribuable en ligne de commande

Pour lancer un outil redistribuable en ligne de commande, il suffit d'exécuter le code suivant :
```wlangage
sChemin est une chaîne
sChemin = """" + ComplèteRep(SysRep(srProgramFilesCommun)) + ...
	"PC SOFT\<Version de l'outil>\<Nom de l'outil>\<Nom de l'outil>.exe"""
LanceAppli(sChemin)
```

Où :

- <Version de l'outil> : numéro de version de l'outil utilisé (par exemple, "30.0" pour un outil livré avec WINDEV 2025).
- <Nom de l'outil> : nom de l'outil à lancer (par exemple, "WDLog").
