# Fonctions Bandeau défilant

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions Bandeau défilant (syntaxe préfixée)](1000022632.md)).
Les fonctions de gestion des champs Bandeau défilant sont les suivantes :

| [BandeauArrêteDéfilement](1000022512.md) | Arrête le défilement automatique sur un champ Bandeau défilant. |
| --- | --- |
| [BandeauDernier](1000022516.md) | Affiche le dernier plan d'un champ Bandeau défilant. |
| [BandeauLanceDéfilement](1000022511.md) | Active le défilement automatique sur un champ Bandeau défilant. |
| [BandeauPrécédent](1000022515.md) | Affiche le plan précédent d'un champ Bandeau défilant. |
| [BandeauPremier](1000022513.md) | Affiche le premier plan d'un champ Bandeau défilant. |
| [BandeauSuivant](1000022514.md) | Affiche le plan suivant d'un champ Bandeau défilant. |
