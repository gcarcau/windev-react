# Type (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Le mot-clé type peut correspondre :

- au mot-clé utilisé pour définir un alias de type. Pour plus de détails, consultez [Alias de type](1514089.md).
- à la propriété **Type** du WLangage.

La propriété **Type** permet de connaître et de modifier le type d'un élément. Cette propriété est utilisable sur :
