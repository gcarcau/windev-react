# CaméraEtat (Fonction)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Renvoie l'état d'un champ Caméra.
> _(Android, iPhone/iPad)_ Avertissement
A partir de la version 27, cette fonction est obsolète pour les applications Android et iOS. Cette fonction est conservée uniquement pour les champs Caméra créés dans les versions précédentes et ayant l'option "Mode compatible 26" cochée (onglet "Général" de la fenêtre de description du champ).

## Exemple

```wlangage
// Connaître l'état du champ Caméra "CAM_Cuisine"
// L'explication est affichée dans la barre de message.
ResEtat = CaméraEtat(CAM_Cuisine)
SELON ResEtat
	CAS viEtatAffichageCapture :
		Message("Affichage de la vidéo dans le champ Caméra. " + ...
			"Enregistrement en cours de cette vidéo")
	CAS viEtatAffichageSansCapture :
		Message("Affichage de la vidéo dans le champ Caméra. " + ...
			"Aucune enregistrement n'est actuellement réalisé")
	CAS viEtatCaptureSansAffichage :
		Message("Enregistrement en cours d'une vidéo. "+ ...
			"Cette vidéo n'est pas affichée dans le champ Caméra")
	CAS viEtatSansCaptureSansAffichage :
		Message("Aucune vidéo n'est affichée et/ou en cours " + ...
			"d'enregistrement dans le champ Caméra")
FIN
```

## Syntaxe

```wlangage
<Résultat> = CaméraEtat(<Champ Caméra>)
```

`<Résultat>` *Constante de type entier*
> Etat du champ Caméra spécifié :
>
> | *viEtatAffichageCapture* | Affichage de la vidéo dans le champ Caméra spécifié. Capture en cours de cette vidéo. |
> | --- | --- |
> | *viEtatAffichageSansCapture* | Affichage de la vidéo dans le champ Caméra spécifié. Aucun enregistrement de la vidéo n'est actuellement réalisé. |
> | *viEtatCaptureSansAffichage* | Capture en cours d'une vidéo. Cette vidéo n'est pas affichée dans le champ Caméra spécifié. |
> | *viEtatSansCaptureSansAffichage* | Aucune vidéo n'est affichée et/ou en cours d'enregistrement dans le champ Caméra spécifié. |
`<Champ Caméra>` *Nom de champ*
> Nom du champ Caméra à manipuler.

## Remarques

### Conditions d'utilisation :

- Pour utiliser cette fonction, une "web caméra" doit être connectée au poste en cours.
- Cette fonction nécessite un matériel équipé d'une caméra. Elle peut également être utilisée lors d'une exécution dans l'émulateur Android.
- Cette fonction nécessite un matériel équipé d'une caméra.
- Cette fonction est équivalente à la fonction [VidéoEtat](3079006.md).

### Cas particuliers

- Pour capturer la vidéo actuellement retransmise par une "web caméra", utilisez la fonction [CaméraCapture](1000022450.md).
- Pour afficher dans un champ Caméra la séquence vidéo actuellement retransmise par une "web caméra", utilisez la fonction [CaméraAffiche](1410086595.md).

> _(Android)_ Permissions requisesL'utilisation de cette fonction entraîne la modification des permissions requises par l'application.Permission requise : CAMERA.Cette permission permet aux applications d'accéder à la caméra.
