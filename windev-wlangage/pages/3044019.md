# HJournalRedémarre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Redémarre la journalisation du fichier de données. Cette journalisation a été arrêtée grâce à la fonction [HJournalStop](3044035.md).

## Exemple

```wlangage
HJournalInfo("Client", "début impression de " + Critère)
HJournalStop("Client") // Stopper le journal
HLitPremier("Client", Critère)
TANTQUE HTrouve()
	// Traitement
	HLitSuivant("Client")
FIN
HJournalRedémarre("Client") // Redémarrer le journal
HJournalInfo("Client", "fin impression de" + Critère) // Ecrire
```

## Syntaxe

```wlangage
<Résultat> = HJournalRedémarre(<Fichier de données>)
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données journalé dont la journalisation doit redémarrer.

## Remarques

- Lors du redémarrage du journal, le fichier de données doit être dans son état initial, c'est-à-dire l'état dans lequel il était avant l'utilisation de la fonction [HJournalStop](3044035.md).
- Entre les fonctions [HJournalStop](3044035.md) et **HJournalRedémarre**, les informations ne seront pas sauvegardées dans le journal.
- La fonction **HJournalRedémarre** est équivalente à l'utilisation de la fonction [HGèreJournal](3044052.md) avec le paramètre Vrai.
