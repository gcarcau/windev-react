# Ecran,Suivant (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Retourne le nom du prochain champ à saisir.

## Exemple

```wlangage
// En CAPPELWD("Ecran,suivant");strcpy(NomChamp,WdNom);Indice=WDIndice;
```

```wlangage
// En PascalAPPELWD('Ecran,Suivant');NomChamp:=WdNom;Indice:=WdIndice;
```

```wlangage
// En VBcall APPELWD("Ecran,Suivant")NomChamp=WdNomIndice=WdIndice
```

## Syntaxe

```wlangage
Ecran,Suivant()
```

## Remarques

- Le nom du champ est retourné dans WdNom.
- WdIndice contient l'indice du champ dans le cas d'un champ indicé.
