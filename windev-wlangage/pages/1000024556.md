# pdfElémentTexte (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Le type **pdfElémentTexte** permet de connaître toutes les caractéristiques d'un élément textuel dans une page PDF. Les caractéristiques de cet élément peuvent être connues à l'aide de différentes propriétés WLangage. Il est par exemple possible de connaître la position du texte et son contenu, pour faire des recherches.
Attention : Toutes les propriétés de la variable **pdfElémentTexte** sont en lecture seulement car le texte d'un fichier PDF n'est pas modifiable.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
MonPDF est un pdfDocument = "test.pdf"

POUR TOUTE PageDocument DE MonPDF.Page
	POUR TOUT ElémentPage DE PageDocument.ElémentTexte
		Trace(ElémentPage.Texte)
	FIN
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type pdfElémentTexte
Les propriétés suivantes peuvent être utilisées pour manipuler un élément texte du fichier PDF :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Hauteur | Réel | Hauteur du rectangle indiquant la position et la taille de l'élément dans la page (en millimètres).  **Cette propriété est disponible en lecture seulement**. |
| Largeur | Réel | Largeur du rectangle indiquant la position et la taille de l'élément dans la page (en millimètres).  **Cette propriété est disponible en lecture seulement**. |
| PoliceNom | Chaîne de caractères | Nom de la police utilisée pour dessiner l'élément textuel.  **Cette propriété est disponible en lecture seulement**. _(iPhone/iPad)_ Les informations sur la police ne sont pas disponibles. |
| PoliceTaille | Réel | Taille de la police utilisée pour dessiner l'élément textuel (en point typographique, 72PPP).  **Cette propriété est disponible en lecture seulement**. _(iPhone/iPad)_ Les informations sur la police ne sont pas disponibles. |
| Texte | Chaîne de caractères | Texte de l'élément. **Cette propriété est disponible en lecture seulement**. |
| X | Réel | Position X du rectangle indiquant la position et la taille de l'élément dans la page (en millimètres).  **Cette propriété est disponible en lecture seulement**. |
| Y | Réel | Position Y du rectangle indiquant la position et la taille de l'élément dans la page (en millimètres).  **Cette propriété est disponible en lecture seulement**. |
