# <Variable Document>.Ferme (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Ferme le fichier docx associé à la variable [Document](1000022461.md) et libère le document.

## Exemple

```wlangage
MonDocument est un Document

MonDocument.Ferme()
```

## Syntaxe

```wlangage
<Document>.Ferme()
```

`<Document>` *Variable de type Document*
> Nom de la variable de type [Document](1000022461.md) à manipuler.
> Le fichier physique associé à la variable (s'il existe) est fermé. Les modifications réalisées dans le fichier ne sont pas sauvées avant sa fermeture (utilisez la fonction [<Variable Document>.Sauve](1000024537.md) si nécessaire).

**Composante : wd300mdl.dll**
