# Belgique.VérifieNISS (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un numéro NISS (numéro d'identification de la sécurité sociale de Belgique).

## Exemple

```wlangage
// Test d'une variableMonNuméroNISS est une chaîne = "85073003328"Belgique.VérifieNISS(MonNuméroNISS) // renvoie Vrai // Test d'un champSAI_NuméroNISS = "ABC"Belgique.VérifieNISS(SAI_NuméroNISS) // renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = Belgique.VérifieNISS(<Numéro à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un numéro NISS valide,
> - Faux dans le cas contraire.
`<Numéro à vérifier>` *Nom de champ ou variable de type chaîne*
> Numéro NISS à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.

**Composante : wd300std.dll**
