# Fonctions de gestion des certificats

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des certificats (syntaxe préfixée)](1410087289.md)).
Les fonctions suivantes permettent de manipuler des certificats Windows :

| [CertificatCharge](1000020851.md) | Charge un certificat à partir d'un fichier ou d'un buffer. |
| --- | --- |
| [CertificatDeConfianceAjoute](1000024320.md) | Ajoute un certificat dans la liste des autorités racine de confiance utilisées pour valider les chaînes de certification. |
| [CertificatDeConfianceRAZ](1000024321.md) | Retire tous les certificats ajoutés par la fonction [CertificatDeConfianceAjoute](1000024320.md). |
| Nouveauté 2025 [CertificatExporte](1410090436.md) | Exporte un certificat du magasin de certificats Windows vers un fichier au format "pfx"ou "cert". |
| [CertificatExtrait](1000019300.md) | Extrait un certificat d'un buffer de signature ou d'un duplicata d'impression. |
| Nouveauté Abonnement [CertificatExtraitMessageEnveloppé](1410091163.md) | Vérifie la validité d'une signature au format PKCS7 enveloppée et extrait le message enveloppé. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.** |
| [CertificatExtraitValeurExtension](1410087221.md) | Renvoie la valeur d'une extension du certificat. |
| [CertificatListe](1000019293.md) | Renvoie la liste des certificats disponibles sur le poste. |
| [CertificatOuvrePropriétés](1000019301.md) | Ouvre la fenêtre Windows permettant de connaître les propriétés d'un certificat. |
| Nouveauté 2025 [CertificatPEMVersPFX](1410090438.md) | Convertit un fichier de certificat au format "pem" en un ficher de certificat au format "PFX" incluant la clé privée. |
| [CertificatSélecteur](1000019295.md) | Ouvre une fenêtre de sélection de certificats. Les certificats listés sont les certificats installés dans le magasin personnel. |
| [CertificatSigneChaîne](1000019296.md) | Crée la signature d'une chaîne de caractères. |
| [CertificatSigneExécutable](1000020560.md) | Signe un fichier exécutable avec un certificat. |
| [CertificatSigneFichier](1000019297.md) | Crée la signature d'un fichier. Cette signature peut être mémorisée dans une variable de type Buffer ou bien dans un fichier texte. |
| Nouveauté Abonnement [CertificatSignePackageMSIX](1410091135.md) | Signe un package MSIX avec un certificat. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.** |
| [CertificatVérifieChaîne](1000019298.md) | Vérifie la correspondance entre une signature et une chaîne. |
| [CertificatVérifieDuplicata](1000019306.md) | Vérifie la signature d'un duplicata. |
| [CertificatVérifieFichierSignatureBuffer](1000019500.md) | Vérifie la correspondance entre une signature et un fichier. La signature a été conservée sous forme de variable de type Buffer. |
| [CertificatVérifieFichierSignatureFichier](1000019499.md) | Vérifie la correspondance entre une signature et un fichier. La signature a été conservée sous forme d'un fichier externe. |
