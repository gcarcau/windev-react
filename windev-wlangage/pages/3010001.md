# Constantes diverses

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Les constantes suivantes peuvent être utilisées dans les traitements sans être déclarées. Elles ont une valeur prédéfinie.

| Constante | Utilisation | Valeur |
| --- | --- | --- |
| **CRLF** | Passage à la ligne suivante _(WEBDEV - Code Navigateur)_ Cette constante n'est pas disponible. Utilisez plutôt RC. | Caract(13) + Caract(10) |
| **EOT** | Caractère présent à la fin des fichiers externes | Caract(4) |
| **ESC** | Caractère correspondant à la touche "Echap". _(WEBDEV - Code Navigateur)_ Cette constante n'est pas disponible. | Caract(27) |
| **ESP** | Espace insécable. _(WEBDEV - Code Navigateur)_ Cette constante n'est pas disponible. | Caract(160) |
| **Faux** | Booléen | 0 |
| **NULL** | Entier initialisé à 0. Par exemple, il est possible d'utiliser un paramètre "null" dans une fonction API (fonction [API](3014005.md) ou [AppelDLL32](3014003.md)) | 0 |
| **RC** | Caractère "Retour Chariot" : passage à la ligne suivante (utilisé dans les chaînes de caractères) | Caract(13) + Caract(10) |
| **TAB** | Caractère "Tabulation" (utilisé dans les chaînes de caractères) | Caract(9) |
| **ValPI** | Valeur approximative de Pi. _(WEBDEV - Code Navigateur)_ Cette constante n'est pas disponible. | 3,14159265358979323 |
| **Vrai** | Booléen | 1 |
