# Fonctions de gestion des tâches parallèles (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Les fonctions de gestion des tâches parallèles sont les suivantes :

| [<Description de TâcheParallèle>.Exécute](1000021669.md) | Déclenche l'exécution d'une tâche parallèle. |
| --- | --- |
| [<Variable TâcheParallèle>.Attend](1000021604.md) | Attend la fin de l'exécution d'une tâche parallèle. |
| [<Variable TâcheParallèle>.DemandeAnnulation](1000021605.md) | Demande l'annulation d'une tâche parallèle. |
| [<Variable TâcheParallèle>.Exécute](1000021667.md) | Déclenche l'exécution d'une tâche parallèle. |
| [<Variable TâcheParallèle>.ExécuteAprès](1000021668.md) | Indique une tâche parallèle de continuation qui sera exécutée lorsque la tâche parallèle spécifiée sera terminée. |
