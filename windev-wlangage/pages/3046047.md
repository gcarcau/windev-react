# iHautBasPageImbriqué (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Imprime ou non les hauts et bas de page de l'état imbriqué.
Cette fonction peut être utilisée :

- soit dans le code d'ouverture de l'état principal : elle sera prise en compte pour tous les états imbriqués qui seront imprimés depuis l'état principal.
- soit directement avant l'impression de l'état imbriqué : elle sera prise en compte uniquement pour l'état imbriqué suivant.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Imprimer sous Linux.

## Exemple

```wlangage
// Impression de l'état "ETAT_Imb2" en conservant son haut et bas de page
iHautBasPageImbriqué(Vrai)
iImprimeEtat(ETAT_Imb2)
```

## Syntaxe

```wlangage
iHautBasPageImbriqué(<Haut et bas de page Etat imbriqué>)
```

`<Haut et bas de page Etat imbriqué>` *Booléen*
> - Faux (valeur par défaut) si l'état principal doit être imprimé en partageant son haut et bas de page avec l'état imbriqué. Le haut et bas de page de l'état imbriqué ne seront pas imprimés.
> - Vrai si le haut de page et le bas de page de l'état imbriqué doivent être imprimés.

## Remarques

### Impression du haut et du bas de page de l'état imbriqué :

| Cas n°1 : l'état imbriqué s'imprime sur une seul page : | Cas n°2 : L'état imbriqué s'imprime sur plusieurs pages |
| --- | --- |

### Astuce
Lors de l'utilisation de la fonction **iHautBasPageImbriqué** avec le paramètre Vrai, il est conseillé d'utiliser la fonction [iTerminePage](3046038.md) avant la fonction [iImprimeEtat](3046032.md). Il sera ainsi possible par exemple d'imprimer successivement deux états dans la même fenêtre d'aperçu avant impression.

### Changement d'orientation
Si un état imbriqué n'a pas la même orientation que l'état principal, cette fonction est sans effet : les blocs de haut et bas de page ne seront **pas** partagés.
