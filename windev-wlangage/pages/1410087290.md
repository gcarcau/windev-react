# Fonctions de cryptage / compression (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

Les fonctions permettant de gérer le cryptage et la compression via une syntaxe préfixée sont les suivantes :

| [<Type Buffer>.CrypteAsymétrique](1410087279.md) | Crypte un buffer en utilisant un algorithme de chiffrement asymétrique (RSA) nécessitant une clé publique et une clé privée. |
| --- | --- |
| [<Type Buffer>.CrypteAsymétriqueEnveloppé](1410087280.md) | Réalise un cryptage asymétrique d'une enveloppe. |
| [<Type Buffer>.CrypteStandard](1410087281.md) | Crypte une chaîne de caractères ou un buffer binaire en utilisant un algorithme de chiffrement symétrique (AES, DES, etc.). |
| Nouveauté 2025 [<Type Buffer>.Décode](1410087344.md) | Décode une chaîne de caractères précédemment encodée avec la fonction [<Type Buffer>.Encode](1410087345.md). |
| [<Type Buffer>.DécrypteAsymétrique](1410087282.md) | Décrypte un buffer avec un algorithme clé privée/publique selon le cryptage RSA. |
| [<Type Buffer>.DécrypteAsymétriqueEnveloppé](1410087283.md) | Réalise le décryptage asymétrique d'une enveloppe encryptée avec la fonction [<Type Buffer>.CrypteAsymétriqueEnveloppé](1410087280.md). |
| Nouveauté 2025 [<Type Buffer>.Encode](1410087345.md) | Encode une chaîne de caractères ou un buffer. Pour décoder le résultat, il suffit d'utiliser la fonction [<Type Buffer>.Décode](1410087344.md). |
