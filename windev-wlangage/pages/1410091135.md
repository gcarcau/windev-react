# CertificatSignePackageMSIX (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

Signe un package MSIX avec un certificat.
Remarque : Cette fonction est d'un usage avancé. La signature du package MSIX est automatiquement réalisée lors de la création d'une installation MSIX. Pour plus de détails, consultez [Installation MSIX](9000229.md).

Nouveauté Abonnement
Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
// Charge un certificat
certificat_signature est un Certificat
tabCertificat est un tableau de Certificat
tabCertificat = CertificatCharge(nom_fichier_signature, "")
certificat_signature = tabCertificat[1]
// Signe le package
SI certificat_signature.ValidePourSignature ALORS
	CertificatSignePackageMSIX(nom_fichier_package_msix, certificat_signature)
FIN
```

## Syntaxe

```wlangage
<Résultat> = CertificatSignePackageMSIX(<Package MSIX> , <Certificat>)
```

`<Résultat>` *Booléen*
> - Vrai si le package a été signé,
> - Faux dans le cas contraire.
`<Package MSIX>` *Chaîne de caractères*
> Nom du fichier correspondant au package MSIX à signer.
`<Certificat>` *Variable de type Certificat*
> Nom de la variable de type [Certificat](1000021684.md) correspondant au certificat à utiliser pour signer le package MSIX.

**Composante : wd300std.dll**
