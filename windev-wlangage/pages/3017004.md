# Fonctions de gestion des animations

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Plusieurs fonctions WLangage permettent de gérer des animations. Il est possible de :

- gérer l'animation des champs Image et des champs Libellé.
- animer la modification de champs.
- animer le passage d'une fenêtre à une autre.

## Animation des champs Image et Libellé

Ces fonctions permettent de gérer l'animation d'une image dans un champ Image ou d'un texte dans un champ Libellé.

| [AnimationChangeParamètre](3017002.md) | Change un paramètre d'animation d'une image affichée dans un champ Image ou d'un texte affiché dans un champ Libellé |
| --- | --- |
| [AnimationChangeType](3017001.md) | Change le type d'animation d'une image dans un champ Image ou d'un texte dans un champ Libellé (les paramètres spécifiques au nouveau type peuvent être modifiés avec la fonction [AnimationChangeParamètre](3017002.md)) |
| [AnimationLitParamètre](3017003.md) | Lit la valeur d'un des paramètres d'animation défini pour un champ Image ou pour un champ Libellé |
| [FenDésactiveEffet](1000017172.md) | Désactive des effets visuels du moteur graphique de WINDEV (pour une utilisation sous TSE par exemple). Cette fonction est utile pour permettre à une application de fonctionner sur un poste ayant des capacités graphiques limitées ou pour le mode TSE si la bande passante est limitée. |

Pour plus de détails, consultez [Animer un champ Libellé](1013160.md) et [Animer une image](1013244.md).

## Animation des champs

Ces fonctions permettent d'animer la modification d'un ou de plusieurs champs réalisée par programmation.

| [AnimationActive](1000017399.md) | Active ou désactive les animations dans les champs (animations définies dans le projet ou par programmation). |
| --- | --- |
| [AnimationJoue](1000017387.md) | Joue une animation sur une modification d'un champ, d'un groupe de champs ou d'une fenêtre. |
| [AnimationJoueSurPropriétéChamp](1000017398.md) | Anime la modification d'une propriété entière entre 2 valeurs. |
| [AnimationMinFPS](1000017400.md) | Paramètre le nombre minimal d'images par seconde pour que les animations dans les champs (effets de transitions) soient activées. |
| [AnimationPrépare](1000017386.md) | Prépare l'animation sur un champ, un groupe de champs ou une fenêtre. L'animation sera ensuite jouée avec la fonction [AnimationJoue](1000017387.md). |

Il existe également des fonctions permettant de jouer une animation lors du changement d'état d'un champ ou d'un groupe de champs :

| [ChampActif](1000017377.md) | Dégrise un champ ou un groupe de champs d'une fenêtre. Pendant cette opération, une animation sur les champs peut être effectuée. |
| --- | --- |
| [ChampGrisé](1000017375.md) | Grise un champ ou un groupe de champs. Pendant cette opération, une animation sur les champs peut être effectuée. |
| [ChampInvisible](1000017369.md) | Rend invisible un champ ou un groupe de champs dans une fenêtre. Pendant cette opération, une animation sur les champs peut être effectuée. |
| [ChampVisible](1000017338.md) | Rend visible un champ ou un groupe de champs dans une fenêtre. Pendant cette opération, une animation sur les champs peut être effectuée. |

## Animation des fenêtres

Ces fonctions permettent d'animer le passage d'une fenêtre à une autre. Pour plus de détails, consultez [Animation de fenêtres](3038054.md).

| [FenAnimationFermeture](3038050.md) | Modifie le type et la durée des animations utilisées lors de la fermeture des fenêtres de l'application. |
| --- | --- |
| [FenAnimationOuverture](3038051.md) | Modifie le type et la durée des animations utilisées lors de l'ouverture des fenêtres de l'application. |
| [FenAnimationSuivante](3038052.md) | Modifie le type et la durée des animations utilisées lors de l'ouverture et de la fermeture de la prochaine fenêtre. |
