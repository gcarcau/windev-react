# Afficher une page dans un site WEBDEV

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

## Présentation

L'affichage d'une nouvelle page dans un site WEBDEV peut être réalisé selon plusieurs méthodes :

- directement depuis la description du champ qui doit ouvrir la page (bouton, lien, menu, image cliquable, etc.).
- par programmation en WLangage.

## Affichage d'une page depuis la description d'un champ

Lors de la description d'un champ Bouton, Lien, ou Image, il est possible de définir directement l'action effectuée, et la destination de cette action.
Pour afficher directement une page "xxx" à partir d'un champ Bouton, Lien, Image, etc. :

1. Affichez la description de l'élément (option "Description" du menu contextuel de l'élément).
2. Sélectionnez l'action à effectuer : "Afficher la page xxx".
3. Sélectionnez la destination de l'action : page en cours, navigateur en cours, etc.
  Dans le cas d'un frameset, il est possible de choisir une frame spécifique. L'action précédemment sélectionnée sera effectuée dans cette frame.
4. Validez.

## Affichage d'une page par programmation (en WLangage)

Le WLangage propose plusieurs fonctions permettant d'ouvrir une page.

| [PageActualise](3058011.md) | Actualise la page affichée par rapport à son contexte. |
| --- | --- |
| [PageAffiche](3058008.md) | Ouvre et affiche une nouvelle page dans le navigateur de l'internaute. |
| [PageUtilise](3058016.md) | Ferme toutes les pages en cours et leurs contexte, et ouvre une nouvelle page. |

Lors de l'ouverture de la page, il est possible de passer des paramètres à la page. Pour plus de détails, consultez [Page paramétrée](1012020.md).
Remarque : Par défaut, lors de l'ouverture d'une page en programmation, la destination choisie est :

- soit la destination définie dans la description de l'objet lançant l'ouverture de la page (bouton, lien, etc.).
- soit la destination définie pour la page en cours.

## Cas des pages dynamiques

Lors de l'affichage d'une page dynamique, les actions effectuées sont les suivantes :

1. Vérification de l'existence du contexte de la page sur le serveur.
2. Si le contexte existe, fermeture du contexte.
3. Ouverture du contexte de la page. Toutes les variables, champs (ou autres) liés à la page sont ré-initialisés.
4. Affichage de la page demandée sous le navigateur.
