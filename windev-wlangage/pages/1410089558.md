# DriveRécupèreFichier (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Récupère un fichier présent sur un drive (disque distant) et enregistre ce fichier sur le poste de l'utilisateur.

## Exemple

```wlangage
oOAuth2Param est un OAuth2Paramètres
oOAuth2Param.ClientID = "client_id"
oOAuth2Param.ClientSecret = "client_secret"
oOAuth2Param.URLRedirection = "http://localhost:9000/"

oDrive est un Drive
oDrive = oDriveConnecte(oOAuth2Param)

// Choix du répertoire local
sRépertoire est une chaîne
sRépertoire = fRepSélecteur(fRepExe(), "Répertoire local où récupérer le fichier")

// Récupère le fichier
SI DriveRécupèreFichier(oDrive, "/MesPhotos/2000/0001.jpg", sRépertoire) = Faux ALORS
	Erreur("Impossible de récupérer le fichier demandé", ErreurInfo())
	RETOUR
FIN
```

## Syntaxe

```wlangage
<Résultat> = DriveRécupèreFichier(<Drive> , <Fichier à récupérer> , <Emplacement local>)
```

`<Résultat>` *Booléen*
> - Vrai si le fichier a été récupéré,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Drive>` *Variable de type Drive ou gglDrive*
> Nom de la variable de type [Drive](1410089369.md) ou [gglDrive](1410089374.md) correspondant au drive à manipuler. La connexion au drive voulu doit avoir été effectuée. Dans le cas contraire, le fichier n'est pas récupéré.
`<Fichier à récupérer>` *Chaîne de caractères*
> Chemin absolu du fichier présent sur le drive (poste distant) et devant être récupéré. Si ce paramètre ne correspond pas à un chemin de fichier valide, le fichier ne sera pas récupéré.
`<Emplacement local>` *Chaîne de caractères*
> Chemin absolu du fichier à enregistrer sur le poste local. Si ce paramètre ne correspond pas à un chemin de fichier valide ou si un fichier de même nom existe déjà, le fichier ne sera pas récupéré.

## Remarques

### Fichier récupéré
Le fichier récupéré n'a plus de lien avec le disque distant. Le fichier récupéré sur le poste de l'utilisateur ne sera pas modifié si le fichier présent sur le disque distant est modifié (et inversement).
