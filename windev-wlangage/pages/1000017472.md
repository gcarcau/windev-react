# xlsCellule (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Une variable de type **xlsCellule** permet de décrire et de modifier une cellule d'un document Excel.
Ce type de variable est utilisé :

- par les variables de type [xlsDocument](1000017464.md).
- par les variables de type [xlsColonne](1000017471.md).
- par les variables de type [xlsLigne](1000017325.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

Nouveauté 2025

> _(Android)_ Ce type de variable est désormais disponible pour les applications Android.

> _(Widget Android)_ Ce type de variable est désormais disponible en mode Widget Android.

> _(iPhone/iPad)_ Ce type de variable est désormais disponible pour les applications iPhone/iPad.

## Exemple

```wlangage
// Ouverture d'un fichier Excel
sFichierExcel est une chaîne
sFichierExcel = fSélecteur("", "", "Sélectionnez un fichier Excel...", "Excel" + ...
	TAB + "*.xlsx" + RC + "Tous les fichiers (*.*)" + TAB + "*.*", "*.xlsx")
SI sFichierExcel = "" ALORS RETOUR

// Ouverture du document Excel
MonDocument est un xlsDocument
MonDocument = xlsOuvre(sFichierExcel)

// Création d'une variable xlsCellule avec fond rouge.
Cellule est une xlsCellule
Cellule = "WINDEV est formidable !"
Cellule.CouleurFond = RougeClair

// Renseigne la cellule A6
MonDocument..Cellule[6,"A"] = Cellule

// Sauvegarde les modifications
xlsSauve(MonDocument)
xlsFerme(MonDocument)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type xlsCellule
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **xlsCellule** :

| Nom | Type manipulé | Effet |
| --- | --- | --- |
| AlignementH | Constante de type Entier | Alignement horizontal de la cellule. Les valeurs possibles sont les suivantes :  - *chCentre* : centré. - *chDroite* : alignement à droite. - *chGauche* : alignement à gauche. |
| AlignementV | Constante de type Entier | Alignement vertical de la cellule. Les valeurs possibles sont les suivantes :  - *cvHaut* : alignement en haut. - *cvMilieu* : alignement au milieu. - *cvBas* : alignement en bas. |
| Cadre | [Variable de type Cadre](15140100.md) | Caractéristiques du cadre de la cellule. _(Android, Widget Android)_ Cette propriété n'est pas disponible. |
| CouleurFond | Entier ou constante de type Entier | Couleur de fond de la cellule. Cette couleur peut correspondre à :  - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)), - [une couleur prédéfinie](3010002.md). |
| Formule | Chaîne de caractères | Formule d'une cellule.  Attention : La modification de la formule d'une cellule ne déclenche pas automatiquement le calcul des formules du classeur.  Il faut appeler la fonction [xlsRecalculeTout](1410089617.md) après avoir modifié la formule d'une ou plusieurs cellules pour mettre à jour les valeurs des cellules du classeur ayant une formule.  Cette propriété fonctionne uniquement sur un document XLSX (elle ne fonctionne pas sur un document XLS). |
| Masque | Chaîne de caractères | Masque d'affichage dans Excel. Ce masque doit correspondre au masque reconnu par Excel. Pour plus de détails sur les masques disponibles, consultez la documentation de Excel. |
| MasqueWD | Chaîne de caractères | Masque d'affichage au format WINDEV ou WEBDEV à utiliser dans la cellule Excel (par exemple "JJ/MM/AAAA"). Le masque spécifié est automatiquement converti au format Excel. Les centièmes de seconde présents dans les masques ne sont pas gérés. Pour plus de détails, consultez [Masques gérés](1000017473.md). Cette propriété est disponible en écriture uniquement. |
| Multiligne | Booléen | - Vrai si la cellule est multiligne, - Faux dans le cas contraire. |
| Police | [Variable de type Police](1514045.md) | Police de la cellule. _(Android, Widget Android)_ Cette propriété n'est pas disponible. |
| Type | Constante de type Entier | Type Excel de la cellule. Les valeurs possibles sont les suivantes :  - *xlsTypeChaîne* : Colonne "chaîne de caractères" ou colonne contenant des données de différents types. - *xlsTypeDate* : Colonne "Date". - *xlsTypeDateHeure* : Colonne "DateHeure". - *xlsTypeDouble* : Colonne "Numérique". - *xlsTypeDurée* : Colonne "Durée". - *xlsTypeErreur* : En cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [xlsMsgErreur](3080016.md) ou la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*. - *xlsTypeHeure* : Colonne "Heure". - *xlsTypeMonétaire* : Colonne "Monétaire".  **Cette propriété est disponible en lecture seulement**. |
| Valeur | Type de la valeur de la cellule | Valeur de la cellule. Dans le cas de la définition du style d'une colonne (xlsColonne.CelluleDéfaut), cette propriété est ignorée en écriture et initialisée à vide en lecture). |
