# BTSélecteurPériphérique (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Ouvre une fenêtre système pour sélectionner un périphérique Bluetooth.

## Exemple

```wlangage
MesPériphériques est une chaîne
MesPériphériques = BTSélecteurPériphérique(btEtatTous, "Sélectionnez le périphérique à connecter")
```

## Syntaxe

```wlangage
<Résultat> = BTSélecteurPériphérique([<Condition de filtre> [, <Texte du sélecteur>]])
```

`<Résultat>` *Chaîne de caractères*
> - Identifiant du ou des périphériques Bluetooth sélectionnés. Si plusieurs périphériques sont sélectionnés, les identifiants sont séparés par une tabulation (TAB).
> - Chaîne vide ("") dans les cas suivants :
>   - le sélecteur a été annulé.
>   - aucun périphérique n'a été sélectionné.
>   - une erreur est intervenue. Dans ce cas, la variable [ErreurDétecté](3087001.md) est à Vrai, et la fonction [ErreurInfo](3013008.md) permet d'obtenir plus de renseignements sur l'erreur.
`<Condition de filtre>` *Constante ou combinaison de constantes de type entier optionnelle*
> État des périphériques à sélectionner :
>
>
> | *btEtatAuthentifié* | Propose les périphériques authentifiés. |
> | --- | --- |
> | *btEtatInconnu* | Propose les périphériques inconnus. |
> | *btEtatMémorisé* | Propose les périphériques mémorisés. |
> | *btEtatTous* (Valeur par défaut) | Propose tous les périphériques. |
`<Texte du sélecteur>` *Chaîne de caractères optionnelle*
> Texte à afficher dans la fenêtre du sélecteur.

## Remarques

Seule la pile bluetooth Microsoft est supportée par cette fonction. Pour connaître la pile utilisée, utilisez la fonction [BTPile](1000017229.md).
Pour plus de détails sur les clés supportées, consultez [Quelles piles utiliser ?](1000017231.md)
