# Interface de l'éditeur d'installation WDInst

> **Disponible :** **WINDEV** (Windows)

|  | **Barres d'outils et menu déroulant** Permet un accès rapide aux principales fonctionnalités de WDInst. |
| --- | --- |
|  | **Liste des fichiers à installer** Permet de visualiser rapidement l'ensemble des fichiers à installer. Pour plus de détails, consultez [Manipulation des fichiers à installer](2028021.md). |
|  | **Description du fichier** Permet de connaître et de modifier l'ensemble des caractéristiques du ou des fichiers sélectionnés dans la liste des fichiers. Pour plus de détails, consultez [Manipulation des fichiers à installer](2028021.md). |
|  | **Composants** Permet de visualiser rapidement l'ensemble des composants du programme d'installation et d'associer le ou les fichiers sélectionnés dans la liste des fichiers à un composant. Pour plus de détails, consultez les [Composants](2028032.md). |
|  | **Options de l'installation** Permet de connaître et de modifier l'ensemble des caractéristiques de l'installation (décor, diapositives, type d'installation, ...). Pour afficher cette fenêtre, sélectionnez l'option "Paramètres de l'installation ...". |
