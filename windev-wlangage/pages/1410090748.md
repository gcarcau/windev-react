# <Variable Commande>.AjouteArgument (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU))

Ajoute un argument à une commande à exécuter en mode console.

## Exemple

```wlangage
// Définition de la commande
MaCommandeAExécuter est une Commande
// Exécutable à lancer
MaCommandeAExécuter = "C:\Chemin\MonProgramme.exe"
// Arguments à passer à l'exécutable
MaCommandeAExécuter.Arguments = "Argument1"
// Activation des flux
MaCommandeAExécuter.Flux = cmdEntréeStandard + cmdSortieStandard
// Ajout d'un argument à la ligne de commande
MaCommandeAExécuter.AjouteArgument("C:\chemin\fichier.log")
```

## Syntaxe

```wlangage
<Commande>.AjouteArgument(<Argument>)
```

`<Commande>` *Variable de type Commande*
> Nom de la variable de type [Commande](1410090491.md) correspondant à la commande à manipuler.
`<Argument>` *Chaîne de caractères*
> Argument à ajouter.
