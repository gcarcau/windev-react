# Constantes de gestion des notifications interactives

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Les constantes de gestion des notifications interactives sont les suivantes :

| Constante | Détail | Type de variable |
| --- | --- | --- |
| **sysNotifAlarme** | Comportement spécifique de la notification : La notification reste à l'écran jusqu'à intervention de l'utilisateur. Un son système de "rappel" est joué en boucle. | [sysNotification](1410087893.md) |
| **sysNotifAppel** | Comportement spécifique de la notification : La notification reste à l'écran jusqu'à intervention de l'utilisateur. Un son système d'appel entrant est joué en boucle et un style différent est utilisé pour les boutons. | [sysNotification](1410087893.md) |
| **sysNotifAucunContour** | Contour à appliquer sur le logo : Aucun contour, image carrée. | [sysNotification](1410087893.md) |
| **sysNotifBoutonContextuel** | Comportement ou positionnement spécifique du bouton : Bouton à ajouter au menu contextuel de la notification. | [sysNotificationBouton](1410087947.md) |
| **sysNotifBoutonFerme** | Comportement ou positionnement spécifique du bouton : Bouton système qui ferme automatiquement la notification. | [sysNotificationBouton](1410087947.md) |
| **sysNotifBoutonNormal** | Comportement ou positionnement spécifique du bouton : Bouton simple. | [sysNotificationBouton](1410087947.md) |
| **sysNotifBoutonRappel** | Comportement ou positionnement spécifique du bouton : Bouton système de type "Rappeler plus tard" | [sysNotificationBouton](1410087947.md) |
| Nouveauté 2025 **sysNotifBoutonStyleDéfaut** | Style du bouton : Style par défaut.  **Attention** : Cette constante est disponible uniquement à partir de la version 2025 Update 1. | [sysNotificationBouton](1410087947.md) |
| Nouveauté 2025 **sysNotifBoutonStyleÉchec** | Style du bouton : Bouton rouge (style de l'échec sous Windows). **Attention** : Cette constante est disponible uniquement à partir de la version 2025 Update 1. | [sysNotificationBouton](1410087947.md) |
| Nouveauté 2025 **sysNotifBoutonStyleSuccès** | Style du bouton : Bouton vert (style du succès sous Windows).  **Attention** : Cette constante est disponible uniquement à partir de la version 2025 Update 1. | [sysNotificationBouton](1410087947.md) |
| **sysNotifContourCercle** | Contour à appliquer sur le logo : Image avec un contour circulaire. | [sysNotification](1410087893.md) |
| **sysNotifEntréeCombo** | Type du champ permettant une interaction avec l'utilisateur : champ Combo. | [sysNotificationEntrée](1410088024.md) |
| **sysNotifEntréeTexte** | Type du champ permettant une interaction avec l'utilisateur : champ de saisie texte. | [sysNotificationEntrée](1410088024.md) |
| **sysNotifNormal** | Comportement spécifique de la notification : La notification est affichée quelques secondes à l'écran avant de se mettre dans le centre d'actions de Windows. | [sysNotification](1410087893.md) |
| **sysNotifRappel** | Comportement spécifique de la notification : La notification reste à l'écran jusqu'à intervention de l'utilisateur. Un son système de "rappel" est joué à l'apparition de la notification. | [sysNotification](1410087893.md) |
