# rssIdentifiant (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

Le type **rssIdentifiant** permet de décrire l'identifiant unique d'une entrée de flux RSS. Les caractéristiques de ce type de variable peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
Ce type de variable est utilisé par le [type rssEntrée](1000017792.md).

**Notes** :

- Le plus souvent, la déclaration d'une variable de type **rssIdentifiant** n'est pas nécessaire. En effet, les propriétés du [type rssEntrée](1000017792.md) permettent de manipuler directement les propriétés du type rssIdentifiant (notamment la propriété .Identifiant).
- Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Remarques

### Propriétés spécifiques à la description des variables de type rssIdentifiant
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **rssIdentifiant** :

| Propriété | Type manipulé | Effet |
| --- | --- | --- |
| LienPermanent | Booléen | - Vrai si l'identifiant est permanent, - Faux dans le cas contraire. |
| Valeur | Chaîne de caractères | Identifiant de l'entrée. Si le lien est permanent, l'identifiant est une URL. |
