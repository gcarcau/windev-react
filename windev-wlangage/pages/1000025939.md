# EnModeServeurWebSocket (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Permet de savoir si l'exécution en cours est effectuée dans le serveur de WebSocket.

## Exemple

```wlangage
SI EnModeServeurWebSocket() ALORS // Code spécifique au serveur de WebSocketSINON // Code à exécuter dans les autres casFIN
```

## Syntaxe

```wlangage
<Résultat> = EnModeServeurWebSocket()
```

`<Résultat>` *Booléen*
> - Vrai si le code est exécuté dans le serveur de WebSocket,
> - Faux dans tous les autres cas.

## Remarques

### Disponibilité de la fonction
La fonction **EnModeServeurWebSocket** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **EnModeServeurWebSocket** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.

**Classification Métier / UI : Code neutre**

**Composante : wd300page.dll**
