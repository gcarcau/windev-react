# Animation (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Animation** permet de gérer l'animation d'un élément. Cette propriété permet de :

- lancer ou arrêter l'animation d'une image ou d'un texte (présent dans un champ Libellé). Pour plus de détails, consultez l'aide de la propriété [Animation](2510006.md).
- Nouveauté Abonnement
  définir l'animation d'une fenêtre à son ouverture. Pour plus de détails, consultez [OptionsOuvertureFenêtre](1410091298.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
