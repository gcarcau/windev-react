# <Variable FichierDisque>.Ferme (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Ferme un fichier externe.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Java, Code Utilisateur (MCU), Ajax)_ ResFerme est un entier
// Ouverture d'un fichier externe
MonFichierTxt est un FichierDisque
SI MonFichierTxt.Ouvre("C:\MesRépertoires\Fichier.txt", foLectureEcriture) = Vrai ALORS
 ...
 // Fermeture du fichier externe
 ResFerme = MonFichierTxt.Ferme()
FIN

## Syntaxe

```wlangage
<Résultat> = <Fichier manipulé>.Ferme()
```

`<Résultat>` *Entier*
> - 0 si le fichier externe est fermé,
> - -1 en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*. La fonction **<Variable FichierDisque>.Ferme** génère une erreur si le fichier n'est pas ouvert.
`<Fichier manipulé>` *Variable de type FichierDisque*
> Nom de la variable de type [FichierDisque](1410088883.md) initialisée avec la fonction [<Variable FichierDisque>.Ouvre](1410090197.md) ou [<Variable FichierDisque>.Crée](1410090211.md).

## Remarques

### Fermeture d'un fichier ouvert plusieurs fois
Il est possible d'ouvrir un même fichier plusieurs fois en même temps. Chaque version du fichier doit être fermée individuellement par son propre identifiant.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ Fermeture d'un fichier bloquéUn fichier bloqué sera automatiquement débloqué lors de sa fermeture.Rappel : La fonction <Variable FichierDisque>.Bloque permet de bloquer un fichier externe. La fonction <Variable FichierDisque>.Débloque permet de débloquer un fichier externe.
