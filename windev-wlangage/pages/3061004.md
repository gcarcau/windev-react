# GraveurChemin (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Renvoie le chemin du graveur en cours. Ce graveur peut être sélectionné grâce à la fonction [GraveurSélectionne](3061012.md).
**Remarque** : Pour connaître l'ensemble des graveurs disponibles à partir du poste en cours, utilisez la fonction [GraveurListe](3061009.md).

## Exemple

```wlangage
// Connaître les graveurs installés
ListeGraveur est une chaîne
ListeGraveur = GraveurListe()
SI ListeGraveur ~= "" ALORS
	Erreur("Aucun graveur n'a été détecté sur ce poste")
	RETOUR
FIN
// Remplissage de la table TABLE_TableGraveur avec la liste des graveurs
UnGraveur est une chaîne
CheminGraveur est une chaîne

POUR CHAQUE CHAÎNE UnGraveur DE ListeGraveur SÉPARÉE PAR RC
	// Sélection du graveur
	SI GraveurSélectionne(ExtraitChaîne(UnGraveur, 1)) = Faux ALORS
		Erreur("Echec de la sélection de graveur", ErreurInfo())
		RETOUR
	FIN
	// Chemin du graveur en cours
	CheminGraveur = GraveurChemin()
	// Ajout dans la table
	TableAjouteLigne(TABLE_TableGraveur, CheminGraveur, UnGraveur)
FIN
```

## Syntaxe

```wlangage
<Résultat> = GraveurChemin()
```

`<Résultat>` *Chaîne de caractères*
> - Chemin du graveur en cours.
>   Ce chemin se termine toujours par un "antislash" ("\").
> - Chaîne vide ("") en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
>
>
> > _(WEBDEV - Code Serveur)_ Ce graveur est présent sur le serveur Web.

## Remarques

### Configuration nécessaire

> _(WINDEV)_ La gravure de CD est disponible uniquement sous Windows XP et supérieur. La gravure de DVD est disponible sous Windows Vista, et sous Windows XP en utilisant la mise à jour KB932716 pour Windows XP (cette mise à jour doit être téléchargée depuis le site de Microsoft et installée car elle n'est pas prise en compte par le mécanisme de Live Update).

> _(WEBDEV - Code Serveur)_ La gravure de CD et DVD sera réalisée sur le serveur Web. Pour graver des CD ou des DVD, le serveur doit être sous Windows XP ou supérieur. Pour graver des CD sous Windows 2003 Serveur, il est nécessaire d'activer le service de gravure IMAPI (nommée "Service COM de gravage de CD IMAPI"). Pour graver des DVD sous Windows 2003 Serveur, il est nécessaire d'installer en plus la mise à jour KB932716.

**Composante : wd300grv.dll**
