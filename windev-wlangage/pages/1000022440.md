# MongoGridFSSupprimeFichier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Supprime un fichier identifié par son nom dans un système de fichiers MongoDB.
**Remarque** : Pour supprimer un fichier identifié à partir de son identifiant, utilisez la fonction [MongoGridFSSupprimeFichierParID](1000022596.md).

## Exemple

```wlangage
// Supprime un fichier image
MongoGridFSSupprimeFichier(cnx.BaseDeDonnées, "produit.png")
```

```wlangage
// Supprime le fichier présent dans la colonne de la table
MongoGridFSSupprimeFichier(gclGridFS, TABLE_GridFS.COL_Nom)
ToastAffiche("Suppression terminée avec succès.")
```

## Syntaxe

```wlangage
<Résultat> = MongoGridFSSupprimeFichier(<Système de fichiers> , <Nom du fichier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème. La fonction [ErreurInfo](3013008.md) permet d'identifier l'erreur.
`<Système de fichiers>` *Variable de type mongoGridFS ou de type mongoBase*
> Système de fichiers de la base MongoDB à manipuler. Correspond :
>
> - au nom de la variable de type [mongoGridFS](1000022416.md) correspondant au système de fichiers Mongo.
> - au nom de la variable de type [mongoBase](1000022410.md) correspondant à la base MongoDB. Dans ce cas, le système de fichiers utilise le préfixe "fs".
`<Nom du fichier>` *Chaîne de caractères*
> Nom du fichier à supprimer.
