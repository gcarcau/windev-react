# Constantes de gestion des cadres

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android)

Les constantes suivantes sont utilisées par les variables de type Cadre pour gérer les caractéristiques des cadres.

| Constante | Utilisation | Fonction |
| --- | --- | --- |
| **ArrondiIndéfini** | Tous les coins n'ont pas la même hauteur et la même largeur. | Propriété Arrondi de la variable de type [Cadre](15140100.md). |
| **BordAucun** | Le cadre n'a aucun bord. | Propriété Bords de la variable de type [Cadre](15140100.md). |
| **BordBas** | Le cadre a un bord bas. | Propriété Bords de la variable de type [Cadre](15140100.md). |
| **BordDroite** | Le cadre a un bord droit. | Propriété Bords de la variable de type [Cadre](15140100.md). |
| **BordGauche** | Le cadre a un bord gauche. | Propriété Bords de la variable de type [Cadre](15140100.md). |
| **BordHaut** | Le cadre a un bord haut. | Propriété Bords de la variable de type [Cadre](15140100.md). |
| **BordTous** | Tous les bords du cadre sont affichés. | Propriété Bords de la variable de type [Cadre](15140100.md). |
| **CouleurIndéfinie** | Tous les bords n'ont pas la même couleur. | Propriété Couleur de la variable de type [Cadre](15140100.md). |
| **EpaisseurIndéfinie** | Tous les bords n'ont pas la même épaisseur. | Propriété Epaisseur de la variable de type [Cadre](15140100.md). |
