# HeureDifférence (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Calcule la différence en centièmes de seconde entre deux heures.

## Exemple

```wlangage
// Affiche le temps écoulé depuis 12h15
Diff est un entier
Signe_temps est une chaîne
MonRésultat est une chaîne

Diff = HeureDifférence("1215", HeureSys())
MonRésultat = EntierVersHeure(Abs(Diff))
SI Diff < 0 ALORS Signe_temps = "-"
Info("Temps écoulé : " + Signe_temps + Gauche(MonRésultat, 2) + " heures " + ...
	Milieu(MonRésultat, 3, 2) + " minutes " + ...
	Milieu(MonRésultat, 5, 2) + " secondes " + ...
	Milieu(MonRésultat, 7, 2) + " centièmes de seconde")
```

## Syntaxe

```wlangage
<Résultat> = HeureDifférence(<Heure de début> , <Heure de fin>)
```

`<Résultat>` *Entier*
> Nombre de centièmes de seconde écoulés entre les deux heures. Ce nombre est issu de l'opération :
> <Heure de fin> - <Heure de début>.
> Ce résultat sera négatif si l'<Heure de début> est postérieure à l'<Heure de fin>.
`<Heure de début>` *Chaîne de caractères ou variable de type Heure*
> Heure de début du calcul au format :
>
> - HHMMSSCC
> - HHMMSS
> - HHMM
> - HH
`<Heure de fin>` *Chaîne de caractères ou variable de type Heure*
> Heure de fin du calcul au format :
>
> - HHMMSSCC
> - HHMMSS
> - HHMM
> - HH

## Remarques

### Format du résultat
Pour obtenir la durée dans un format (par exemple HHMMSSCC), utilisez la fonction [EntierVersHeure](3027006.md).

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst, Java, Code Utilisateur (MCU), PHP, Ajax)_ Validité des heuresLa validité des heures passées en paramètre est vérifiée. Un message est affiché en cas d'heure invalide. Il est possible de tester la validité d'une heure avec la fonction HeureValide.

**Classification Métier / UI : Code neutre**
