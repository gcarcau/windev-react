# JSONValide (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Teste la validité d'une chaîne au format JSON.
Nouveauté Abonnement

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 1. Pour plus de détails, consultez Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement.

## Exemple

```wlangage
// Chaîne JSON valide ?
SI JSONValide(sJSON) ALORS
	// Oui => initialisation variable de type JSON
	oJSON est un JSON = ChaîneVersJSON(sJSON)
	...
FIN
```

## Syntaxe

```wlangage
<Résultat> = JSONValide(<Chaîne JSON>)
```

`<Résultat>` *Booléen*
> - Vrai si la chaîne correspond à un format JSON valide,
> - Faux dans le cas contraire. En cas d'erreur, il est possible de connaître le libellé de l'erreur avec la fonction [ErreurInfo](3013008.md).
`<Chaîne JSON>` *Chaîne de caractères*
> Chaîne de caractères (ANSI encodé en ASCII 7 bits + encodage JSON ou UTF-8) contenant les données au format JSON.

## Remarques

### Encodage
L'encodage utilisé correspond au standard JSON :

- utilisation d'un encodage en ASCII 7 bits pour les 128 premiers caractères, les caractères non accentués,
- utilisation d'un encodage JSON des autres caractères : "\u" suivi du code du caractère en hexadécimal sur 4. Exemple : pour "é" (code ASCII 233, code hexadécimal E9), l'encodage correspond à "\u00E9".

Nouveauté Abonnement

> _(WEBDEV - Code Navigateur)_ RemarqueLes commentaires ne sont pas acceptés lors de la vérification du JSON effectuée en code navigateur.
