# VisibleUtilisateurFinal (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **VisibleUtilisateurFinal** permet de :

- Savoir si une rubrique est visible ou non par les utilisateurs finaux. Cette rubrique a été définie sous l'éditeur d'analyses ou définie par programmation.
- Définir si une rubrique doit être visible ou non par les utilisateurs finaux (lors de la description de la rubrique par programmation uniquement).

Lorsqu'une rubrique est visible par les utilisateurs finaux :

- cette rubrique est manipulable sous le [logiciel Etats & Requêtes](3088003.md). Les utilisateurs finaux pourront utiliser cette rubrique dans leurs états et leurs requêtes personnalisés.
- les valeurs de cette rubrique seront modifiables dans les différentes [fenêtres d'assistance automatique HFSQL](3044188.md) (en cas d'erreur de doublons par exemple).

**Remarque** : La visibilité d'une rubrique est définie sous l'éditeur lors de la description des rubriques d'un fichier (option "Visible par l'utilisateur final dans le logiciel "États et Requêtes"" dans l'onglet "Etats et Requêtes" de la fenêtre de description des rubriques).

## Exemple

```wlangage
// Définir la visibilité de la rubrique Commande.DateCde
DateCde.VisibleUtilisateurFinal = Vrai
...
// Valide la description du fichier de données
HDécritFichier(Commande)
```

## Syntaxe

#### Savoir si la rubrique est visible par l'utilisateur final

```wlangage
<Résultat> = <Fichier de données>.<Rubrique>.VisibleUtilisateurFinal
```

`<Résultat>` *Booléen*
> - Vrai si la rubrique est visible par les utilisateurs finaux,
> - Faux dans le cas contraire.
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données manipulé.
`<Rubrique>` *Chaîne de caractères*
> Nom de la rubrique manipulée.

#### Définir la visibilité par l'utilisateur final d'une rubrique décrite par programmation

```wlangage
<Rubrique>.VisibleUtilisateurFinal = <Visibilité>
```

`<Rubrique>` *Chaîne de caractères*
> Nom de la rubrique manipulée. Ce nom vient d'être défini grâce au type [Description de Rubrique](1514071.md).
`<Visibilité>` *Booléen*
> - Vrai si la rubrique doit être visible par les utilisateurs finaux,
> - Faux dans le cas contraire.
