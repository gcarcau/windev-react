# ImageInfoFerme (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Ferme le fichier image (au format JPEG ou TIFF) utilisé par la fonction [ImageInfoValeur](3091003.md) et/ou la fonction [ImageInfoListe](3091002.md) et libère l'image de la mémoire.
**Remarques** :

- Cette fonction n'a aucun effet si l'image utilisée par la fonction [ImageInfoValeur](3091003.md) et/ou la fonction [ImageInfoListe](3091002.md) provient d'un champ Image, d'un mémo image ou d'une chaîne binaire.
- Pour manipuler les marqueurs Exif d'une image, il est également possible d'utiliser la propriété **Exif** des variables de type [Image](1000019650.md). Cette propriété peut être utilisée pour les applications Android.

## Exemple

```wlangage
CheminImg est une chaîne = "C:\Mes Images\MonImage.JPG"
// Connaître la date de réalisation de cette image
Info("Date de réalisation : " + ImageInfoValeur(CheminImg, imgDate))
// Fermeture du fichier image
ImageInfoFerme(CheminImg)
```

## Syntaxe

```wlangage
ImageInfoFerme(<Fichier image>)
```

`<Fichier image>` *Chaîne de caractères*
> Nom et chemin complet (ou relatif) du fichier image à fermer (260 caractères maximum). Un chemin de type UNC peut être utilisé.

## Remarques

La fonction **ImageInfoFerme** ne retourne pas de code d'erreur. Pour savoir si cette fonction a généré une erreur, utilisez la variable [ErreurDétectée](3087001.md). En cas d'erreur, il est possible de connaître le détail de l'erreur grâce à la fonction [ErreurInfo](3013008.md).

**Composante : wd300img.dll**
