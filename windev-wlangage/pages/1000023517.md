# iImprimeXLS (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Imprime la feuille courante d'un document au format "xlsx" ou "xls".

## Exemple

```wlangage
MonXLSX est une chaîne = "c:\temp\Comptes.xlsx"
iDestination(iVisualisateur)
iImprimeXLS(MonXLSX)
```

## Syntaxe

#### Imprimer le contenu d'un champ Tableur ou d'une variable xlsDocument

```wlangage
<Résultat> = iImprimeXLS(<Document>)
```

`<Résultat>` *Booléen*
> - Vrai si le document a été envoyé au spooler d'impression,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Document>` *Type correspondant*
> Document XLS ou XLSX à imprimer. Ce document correspond :
>
> - à une variable de type [xlsDocument](1000017464.md).
> - au chemin d'un fichier de type Tableur (fichier XLS ou XLSX).
> - à un mémo HFSQL correspondant à un document de type XLS ou XLSX.

#### Imprimer le contenu d'un fichier "xlsx" ou "xls"

```wlangage
<Résultat> = iImprimeXLS(<Chemin> [, <Mot de passe>])
```

`<Résultat>` *Booléen*
> - Vrai si le document a été envoyé au spooler d'impression,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Chemin>` *Chaîne de caractères*
> Chemin d'un fichier de type Tableur (fichier XLS ou XLSX).
`<Mot de passe>` *Chaîne de caractères optionnelle ou Chaîne secrète*
> Mot de passe d'ouverture du fichier XLS ou XLSX à imprimer.
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).

## Remarques

Seule la feuille courante du document XLS ou XLSX est imprimée. Pour imprimer d'autres feuilles, il est nécessaire d'utiliser une variable de type [xlsDocument](1000017464.md) et de changer le numéro de la feuille courante via la propriété **Feuille**.

**Classification Métier / UI : Code neutre**
