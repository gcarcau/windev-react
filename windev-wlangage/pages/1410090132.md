# Polyligne (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **Polyligne** permet de définir les différentes polylignes d'un multipolyligne. Cette propriété est disponible sur :

- une variable de type [MultiPolyligneGéo](1410090133.md).
- une variable de type [MultiPolyligne2D](1410090131.md).
