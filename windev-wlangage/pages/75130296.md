# Nation (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Définit la langue d'affichage des titres, libellés, messages... des fenêtres et des champs.

## Exemple

```wlangage
// En CFrancais=5Espagnol=7;//LANGUE est un sélecteurAPPELWD("ECRAN,RECUPERE, LANGUE");If WdEntier==1 APPELWD("NATION,%d",Français);If WdEntier==2 { //espagnol APPELWD("NATION,%d",Espagnol); APPELWD("BIBLI,ERREUR,ESPAGNOL.WDM");If WdEntier>0 APPELWD("ERREUR,Fichier WDM non trouvé")
```

```wlangage
// En PascalFrançais:=5; Espagnol:=7;{LANGUE est un sélecteur}APPELWD('ECRAN,RECUPERE, LANGUE');If WdEntier=1 THEN  {Français} APPELWD('NATION,'+ConvertChaine(Français));End;If WdEntier=2 THEN  {Espagnol}Begin APPELWD('NATION,'+ ConvertChaine(Espagnol)); APPELWD('BIBLI,ERREUR,ESPAGNOL.WDM'); If WdEntier>0 THEN APPELWD('ERREUR,Fichier WDM non trouvé');End;
```

```wlangage
// En VBFrançais=5Espagnol=7'LANGUE est un sélecteurCALL APPELWD("ECRAN,RECUPERE, LANGUE")If WdEntier=1 THEN  CALL APPELWD("NATION,"+STR$(Français))End IfIf WdEntier=2 THEN CALL APPELWD("NATION,"+ STR$(Espagnol)) CALL APPELWD("BIBLI,ERREUR,ESPAGNOL.WDM") If WdEntier>0 THEN  CALL APPELWD("ERREUR,Fichier WDM non trouvé") End ifEnd if
```

## Syntaxe

```wlangage
Nation(<Numéro de la langue>)
```

`<Numéro de la langue>` *Entier*
> Numéro de la langue dans laquelle s'exécutera le projet. Cette valeur est définie sous l'éditeur lors du choix des langues.

## Remarques

- Après l'appel de **Nation**, les chargements des fenêtres affichent les titres, libellés, messages... dans la langue demandée.
- **Nation** peut être utilisée pour développer des applications internationales pouvant être diffusées dans plusieurs langues
