# telNuméroAppelant (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Permet de connaître le numéro de téléphone appelant (qui appelle).

## Exemple

```wlangage
// Procédure permettant de rechercher le numéro de téléphone
// dans la base de donnée des contacts
PROCÉDURE RechercheIdentite(sNumTel)
// On met en forme le numéro de téléphone
sNumTel = Droite(SansEspace(sNumTel), 9)
// On recherche dans le carnet d'adresse
HLitRecherchePremier(CONTACT, TélSurNeuf, sNumTel)
SI HTrouve(CONTACT) = Vrai ALORS
	LIB_NOM = CONTACT.Nom
	LIB_PRENOM = CONTACT.Prénom
	LIB_SOCIETE = CONTACT.Société
	LIB_TEL = CONTACT.Téléphone
SINON
	LIB_NOM = "CONTACT INCONNU"
	LIB_PRENOM = "CONTACT INCONNU"
	LIB_SOCIETE = "CONTACT INCONNU"
	LIB_TEL = telNuméroAppelant(nIDAppel)
FIN
```

## Syntaxe

```wlangage
<Résultat> = telNuméroAppelant([<Identifiant de l'appel>])
```

`<Résultat>` *Chaîne de caractères*
> Numéro de téléphone appelant.
`<Identifiant de l'appel>` *Entier optionnel*
> Identifiant de l'appel à manipuler. Cet identifiant est connu dans la procédure WLangage appelée par la fonction [telDémarreDétectionAppel](3076029.md). Si ce paramètre n'est pas spécifié, l'appel en cours est manipulé.

## Remarques

### Configuration nécessaire
Les fonctions de téléphonie utilisent la technologie TAPI 2.0 et/ou la technologie TAPI 3.1. Ces technologies sont utilisables sur tous les systèmes.

**Composante : wd300com.dll**
