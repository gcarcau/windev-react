# <Graphe>.PIValeurMaximale (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Permet de spécifier la valeur maximale du graphe permettant de calculer automatiquement les pourcentages d'un graphe de type "Pourcentage imagé".

## Exemple

```wlangage
ImageGraphe est une Image = "rocket.png"
GRF_Pourcentage.SupprimeSérie(1)
nSomme est un entier
POUR TOUTE LIGNE DE TABLE_Série
	nValeur est un entier = COL_Données
	nSomme += nValeur
	GRF_Pourcentage.AjouteDonnée(1, nValeur)
FIN
GRF_Pourcentage.PIValeurMaximale(nSomme)
GRF_Pourcentage.PIImage(ImageGraphe)
GRF_Pourcentage.Dessine()
```

## Syntaxe

```wlangage
<Champ Graphe>.PIValeurMaximale(<Valeur maximale>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe présent dans l'éditeur de fenêtres ou de pages.
>
> > _(Android)_ Seuls les champs Graphe sont disponibles.
`<Valeur maximale>` *Réel*
> Nouvelle valeur maximale à prendre en compte. Cette valeur est strictement positive.
> Par défaut, cette valeur vaut 100, ainsi les données sont exprimées en pourcentage. Lors du changement de cette valeur, les données du graphe sont recalculées automatiquement.
