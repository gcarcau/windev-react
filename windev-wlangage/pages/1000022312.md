# <Variable emailSessionOutlook>.ChangeEtat (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Change l'état d'un email sur un serveur de messagerie.

## Exemple

```wlangage
// Passer tous les emails d'une session Outlook en lus
MaSession est une emailSessionOutlook
...
POUR TOUT MessageEmail NON LU DE MaSession
	MaSession.ChangeEtat(MessageEmail, emailEtatLu)
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Session>.ChangeEtat(<Email> , <Nouvel état>)
```

`<Résultat>` *Booléen*
> - Vrai si l'état a été modifié sur le serveur,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Session>` *Variable de type emailSessionOutlook*
> Nom de la variable de type [emailSessionOutlook](1000018767.md) à utiliser.
`<Email>` *Variable de type Email*
> Nom de la variable de type [Email](1000018713.md) correspondant à l'email à manipuler.
`<Nouvel état>` *Constante de type Entier*
> Etat à affecter à l'email, les valeurs possibles sont :
>
> | *emailEtatLu* | Indique que le message a été lu. |
> | --- | --- |
> | *emailEtatNonLu* | Indique que le message n'a pas encore été lu. |
