# Séparateur (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux)

La propriété **Séparateur** permet de gérer les séparateurs. Cette propriété est utilisable sur :

- les variables de type [docNiveauNumérotation](1000022799.md).
- les variables de type [docFormatMulticolonne](1000023580.md).
