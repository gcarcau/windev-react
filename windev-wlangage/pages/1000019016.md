# SaaSConnexionClient (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Renvoie les caractéristiques de la connexion à la base de données du client. Cette fonction permet à un utilisateur connecté grâce à la fonction [SaaSConnecte](1000018959.md) d'accéder à la base de données cliente lui appartenant.

## Exemple

```wlangage
MaConnexion est une Connexion

SI SaaSEstConnecté() = Vrai ALORS
	MaConnexion = SaaSConnexionClient()
	HChangeConnexion("*", MaConnexion)
FIN
```

## Syntaxe

```wlangage
<Résultat> = SaaSConnexionClient()
```

`<Résultat>` *Variable de type Connexion*
> Variable de type [Connexion](1514073.md) contenant les caractéristiques de connexion à la base de données du client.

**Composante : wd300com.dll**
