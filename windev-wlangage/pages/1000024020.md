# CertificatClient (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **CertificatClient** permet de gérer les certificats client. Cette propriété est utilisable sur :

- une variable de type [httpRequête](1000021158.md).
- une variable de type [restRequête](1000021481.md).
- une variable de type [wsRequête](1000020577.md).
- une variable de type [apiRequête](1410088935.md).
- Nouveauté SaaS
  une variable de type [OAuth2Paramètres](1000022212.md).
- Nouveauté SaaS
  une variable de type [OpenIDParamètres](1000023561.md).
