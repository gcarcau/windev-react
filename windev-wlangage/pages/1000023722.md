# <Tableur>.Ferme (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Ferme le document XLSX ouvert précédemment par la fonction [<Tableur>.Charge](1000023719.md).

## Exemple

```wlangage
TBLR_Tableur.Charge("doc1.xlsx")
TBLR_Tableur.Ferme()
LanceAppliAssociée("doc1.xlsx")
```

## Syntaxe

```wlangage
<Champ Tableur>.Ferme()
```

`<Champ Tableur>` *Nom de champ*
> Nom du champ Tableur à manipuler.

## Remarques

- Par défaut, la fonction [<Tableur>.Charge](1000023719.md) laisse le fichier XLSX ouvert en écriture. Lors de l'enregistrement, seules les cellules modifiées dans le champ Tableur sont écrasées.
- Pour ouvrir le fichier ".xlxs" avec une autre application, il est nécessaire de le fermer avec la fonction **<Tableur>.Ferme**.
- Si aucun fichier ".xlsx" n'a été ouvert, la fonction **<Tableur>.Ferme** ne fait rien.
- Cette fonction est utilisable uniquement sur un champ Tableur présent dans une fenêtre.
