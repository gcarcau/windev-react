# fDisquePrêt (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Permet de savoir :

- si le lecteur de carte, CD ou DVD est disponible,
- si le disque existe.

## Exemple

```wlangage
// Lecteur disponible ?
ResDisponible = fDisquePrêt("E")
```

## Syntaxe

```wlangage
<Résultat> = fDisquePrêt(<Chemin du disque>)
```

`<Résultat>` *Booléen*
> - Vrai si le lecteur est prêt, accessible et disponible,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Chemin du disque>` *Chaîne de caractères*
> Chemin du disque à manipuler de la forme :
>
> - <lettre du lecteur>. Par exemple : "a", "a:" ou "a:\".
> - chemin UNC. Par exemple : "\\<NomServeur>\<NomPartage>".
>
>
> Si le lecteur est un lecteur de disquette, de carte, de CD ou de DVD, le lecteur est prêt uniquement s'il contient une disquette, une carte, un CD ou un DVD.
