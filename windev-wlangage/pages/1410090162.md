# Effet (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Effet** permet de connaître et définir l'effet appliqué sur les champs.
Cette propriété est disponible :

- pour définir l'effet d'affichage à utiliser pour mettre en évidence le ou les champ(s) cible(s) pour l'étape de la visite guidée. Cette propriété est utilisable sur :
  - une variable de type [VisiteGuidée](1410090170.md).
  - une variable de type [VisiteGuidéeEtape](1410090178.md).
- Nouveauté 2025
   pour définir et connaître les caractéristiques du floutage effectué sur un champ. Pour plus de détails, consultez l'aide sur la propriété [Effet](1410090859.md).
