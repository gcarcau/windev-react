# LEDEteint (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android)

Éteint la LED (Light-Emitting Diode) de l'appareil. Cette LED doit avoir été allumée par la fonction [LEDAllume](1000019446.md).
Attention :

- L'appareil doit disposer d'une LED.
- Cette fonction est sans effet dans le simulateur ou l'émulateur.

## Exemple

```wlangage
// Allumage de la diode en rouge pendant 10 secondes
LEDAllume(RougeClair, 1000)

// Extinction de la LED
LEDEteint()
```

## Syntaxe

```wlangage
LEDEteint()
```

**Composante : wd300android.jar**
