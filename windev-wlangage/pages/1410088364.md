# gValeurMémoriséeActive (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Mac Catalyst)

Autorise ou non la récupération de la valeur définie par la fonction [gValeurMémorisée](1410088363.md) dans un champ Liste ou dans un champ Combo.
Remarque : Cette fonction est identique à la fonction [gLienActive](3029036.md).

## Exemple

```wlangage
// Le champ Combo "COMBO_Civilité" affiche les titres de civilité :
// "Monsieur", "Madame" et "Mademoiselle".
// Un entier représentant une civilité sera retourné au langage.
ListeAjoute(COMBO_Civilité, "Monsieur" + gValeurMémorisée("1"))
// Seule la chaîne de caractères "1" est retournée au langage.
// Cette chaîne de caractères retournée n'est pas affichée dans le champ Combo.
// Autoriser la récupération de la valeur définie par la fonction gValeurMémorisée.
gValeurMémoriséeActive(COMBO_Civilité, Vrai)
```

## Syntaxe

```wlangage
<Résultat> = gValeurMémoriséeActive(<Champ Liste ou Combo> [, <Active>])
```

`<Résultat>` *Booléen*
> Correspond à l'ancien mode de gestion :
>
> - Vrai si la valeur définie par la fonction [gValeurMémorisée](1410088363.md) a été récupérée (valeur par défaut),
> - Faux dans le cas contraire.
`<Champ Liste ou Combo>` *Nom de champ*
> Nom du champ Liste ou Combo à manipuler.
`<Active>` *Booléen optionnel*
> - Vrai si la valeur définie par la fonction [gValeurMémorisée](1410088363.md) doit être récupérée (valeur par défaut),
> - Faux dans le cas contraire.

## Remarques

### Activation/Désactivation

- Si la récupération des valeurs définies avec la fonction [gValeurMémorisée](1410088363.md) est activée sur le champ COMBO_COMBO1 (<Active> = Vrai) :
  COMBO_COMBO1.Valeur renvoie le numéro d'ordre dans le champ COMBO_COMBO1.
  COMBO_COMBO1[COMBO_COMBO1] renvoie la valeur de la fonction [gValeurMémorisée](1410088363.md).
  - Si le champ COMBO_COMBO1 est liée à une rubrique :
    - La fonction [FichierVersEcran](3044210.md) sélectionne la ligne dont la valeur de la fonction [gValeurMémorisée](1410088363.md) est celle de la rubrique liée.
    - La fonction [EcranVersFichier](3044146.md) affecte la rubrique HFSQL liée avec la valeur de la fonction [gValeurMémorisée](1410088363.md).
- Si la récupération des valeurs définies avec la fonction [gValeurMémorisée](1410088363.md) est désactivée sur le champ COMBO_COMBO1 (<Active> = Faux) :
  COMBO_COMBO1.Valeur renvoie le numéro d'ordre dans le champ COMBO_COMBO1.
  COMBO_COMBO1[COMBO_COMBO1] renvoie la valeur affichée en cours.
  - Si le champ COMBO_COMBO1 est lié à une rubrique :
    - La fonction [FichierVersEcran](3044210.md) sélectionne la ligne dont le rang est égal à la rubrique liée.
    - La fonction [EcranVersFichier](3044146.md) affecte la rubrique HFSQL liée avec le numéro de l'élément sélectionné, c'est-à-dire ListeSelect(COMBO_COMBO1).

### Fonction ListeCherche

- Si **gValeurMémoriséeActive**()=Vrai, la fonction [ListeCherche](3049003.md) tient compte des valeurs ajoutées par la fonction [gValeurMémorisée](1410088363.md). La recherche est effectuée sur la valeur mémorisée.
- Si **gValeurMémoriséeActive**()=Faux, la fonction [ListeCherche](3049003.md) ne tient pas compte des valeurs ajoutées par la fonction [gValeurMémorisée](1410088363.md). La recherche est effectuée sur la valeur affichée.

### Combos auto-alimentées
La fonction **gValeurMémoriséeActive** est utilisée pour gérer les champs de type "Combo auto-alimentée".
