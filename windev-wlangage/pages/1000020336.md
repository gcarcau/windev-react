# ToastSupprimeTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur)

Supprime tous les toasts affichés par la fonction [ToastAffiche](1000019358.md). Si aucun toast n'est affiché, la fonction est sans effet.

## Exemple

```wlangage
// Fermeture de la fenêtre : tous les toasts sont effacés
ToastSupprimeTout()
```

## Syntaxe

```wlangage
ToastSupprimeTout()
```

**Composante : wd300obj.dll**
