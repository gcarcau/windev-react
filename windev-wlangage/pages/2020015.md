# Installation de WINDEV/WEBDEV/WINDEV Mobile : Respect des normes de répertoires

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Les différentes versions de Windows proposent des normes concernant l'emplacement de certains fichiers et l'usage des répertoires.
Depuis la version 14, l'installation de WINDEV, WEBDEV et WINDEV Mobile respecte ces normes. Lors de l'installation, vous pouvez :

- Installer le produit sélectionné dans un répertoire unique. Ce mode d'installation correspond à l'installation "Classique".
- Installer le produit en respectant la norme Windows.

## Répertoire d'installation

Les répertoires d'installation en fonction du mode d'installation sélectionné sont les suivants :

|  | Répertoire unique | Norme Windows (pour WINDEV par exemple) |
| --- | --- | --- |
| Programmes | <Rep Inst>\Programmes | C:\Program Files\PC SOFT\WINDEV 2025\Programmes |
| Données | <Rep Inst>\Programmes\Donnees | C:\Program Files\PC SOFT\WINDEV 2025\Programmes\Donnees |
| Aide | <Rep Inst>\Aide | C:\Program Files\PC SOFT\WINDEV 2025\Aide |
| Framework | <Rep Inst>\Programmes\Framework | C:\Program Files\PC SOFT\WINDEV 2025\Programmes\Framework |
| Langages externes | <Rep Inst>\Langages externes | C:\Program Files\PC SOFT\WINDEV 2025\Langages externes |
| ODBC | <Rep Inst>\ODBC | C:\Program Files\Common Files\PC SOFT\WINDEV 2025\ODBC |
| Gabarits | <Rep Inst>\Personal\Gabarits | <User>\AppData\Roaming\PC SOFT\30.0\Gabarits\WD |
| Exemples | <Rep Inst>\Exemples | C:\Program Data\PC SOFT\30.0\Exemples\WD |
| Composants | <Rep Inst>\Composants | C:\Program Data\PC SOFT\30.0\Exemples\WD\Composants |
| Composants utilitaires | <Rep Inst>\Composants\Composants utilitaires | C:\Program Data\PC SOFT\30.0\Exemples\WD\Composants utilitaires |
| Tutoriel | <Rep Inst>\Tutoriel | C:\Program Data\PC SOFT\30.0\Exemples\WD\Tutoriel |
| Packs annexes | <Rep Inst>\Install | C:\Program Files\Common Files\PC SOFT\30.0\Install |
| Eléments personnels | <Rep Inst>\Personnel | <User>\AppData\Roaming\PC SOFT\30.0 |
