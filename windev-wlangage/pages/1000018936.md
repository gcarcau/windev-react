# ServiceExiste (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Teste si un service est installé. L'existence du service peut être testée sur le poste local ou sur un poste distant.

## Exemple

```wlangage
// Test de l'existence du collecteur du SILO
SI ServiceExiste("WDCollecteur") = Vrai ALORS
	Info("Le service de collecte du SILO est installé sur ce poste.")
FIN
```

## Syntaxe

```wlangage
<Résultat> = ServiceExiste(<Nom du service> [, <Poste distant>])
```

`<Résultat>` *Booléen*
> - Vrai si le service existe,
> - Faux dans le cas contraire.
`<Nom du service>` *Chaîne de caractères*
> Nom du service à contrôler
`<Poste distant>` *Chaîne de caractères optionnelle*
> Adresse IP du poste distant au format xxx.xxx.xxx.xxx (obtenu par la fonction [NetAdresseIP](3056023.md)) ou nom du poste distant (obtenu par la fonction [NetNomMachine](3056014.md)). Ce paramètre permet de contrôler un service sur un autre poste. Pour utiliser cette option, l'utilisateur doit être administrateur de la machine distante.
> Si ce paramètre n'est pas précisé ou correspond à une chaîne vide (""), le service est manipulé en local.

**Composante : wd300std.dll**
