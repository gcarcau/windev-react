# dbgActiveAssertion (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Active ou désactive la programmation défensive. La programmation défensive a été mise en place grâce à la fonction [dbgAssertion](3014022.md).

## Exemple

```wlangage
dbgActiveAssertion(Vrai)
```

## Syntaxe

```wlangage
<Résultat> = dbgActiveAssertion([<Activation>])
```

`<Résultat>` *Booléen*
> Si le paramètre <Activation> n'est pas précisé, <Résultat> correspond au fonctionnement actuel :
>
> - <Résultat> = Vrai si la programmation défensive est activée,
> - <Résultat> = Faux si la programmation défensive est désactivée.
>
>
> Si le paramètre <Activation> est précisé, <Résultat> correspond à l'ancien mode de fonctionnement :
>
>
> - <Résultat> = Vrai si la programmation défensive est activée,
> - <Résultat> = Faux si la programmation défensive est désactivée.
`<Activation>` *Booléen optionnel*
> - Vrai pour activer la programmation défensive,
> - Faux pour la désactiver (valeur par défaut).

## Remarques

- Par défaut, en mode test, la programmation défensive est activée.
- Par défaut, en exécution, la programmation défensive est désactivée.
- Si le mode JITc est activé (mode par défaut), cette fonction doit être appelée dans le code d'initialisation du projet. Pour plus de détails, consultez [Technologie JITc](2020009.md).
