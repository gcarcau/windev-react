# WebSocketListeClientConnecté (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Liste les clients connectés au serveur de WebSocket.

## Exemple

```wlangage
// Récupère la liste des clients
tabClients est un tableau de websocketClient = WebSocketListeClientConnecté()
// Pour envoyer un message à chacun
POUR TOUT Client DE tabClients
	WebSocketEnvoie(Client, bufMessage)
FIN
```

## Syntaxe

```wlangage
<Résultat> = WebSocketListeClient()
```

`<Résultat>` *Tableau*
> Tableau de variables de type [websocketClient](1000025952.md) correspondant aux clients connectés au moment de l'appel à la fonction. Si un nouveau client se connecte, il n'est pas ajouté dans le tableau. Si un client se déconnecte, il n'est pas supprimé.

**Composante : wd300awws.dll**
