# iFermeEtat (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Arrête immédiatement l'impression de l'état en cours. Le code WLangage situé après l'appel à la fonction est exécuté. Cette fonction doit être utilisée dans un des traitements de l'état.
> _(WINDEV)_ Si l'état est imprimé dans le visualisateur de rapports, la fenêtre d'aperçu est automatiquement fermée.

**Remarque** : Cette fonction peut uniquement être utilisée dans les traitements des états créés avec l'éditeur d'états.

## Exemple

```wlangage
// Fin de l'impression
SI MoiMême..Source.NomClient = "MOULIN" ALORS
	iFermeEtat()
FIN
```

## Syntaxe

```wlangage
iFermeEtat()
```

## Remarques

Pour ne pas exécuter le code WLangage présent après la fonction **iFermeEtat**, utilisez par exemple le mot-clé [RETOUR](1510009.md).
Exemple :

```wlangage
SI TraitementFini() = Vrai ALORS
	iFermeEtat()
	RETOUR
FIN
Info("Coucou")
```

**Classification Métier / UI : Code neutre**

**Composante : wd300etat.dll**
