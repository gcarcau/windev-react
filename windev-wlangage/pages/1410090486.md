# <Variable PolyligneGéo>.AjoutePoint (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Ajoute un nouveau point dans une polyligne géographique.
Rappel : Un polygone géographique est un ensemble de polylignes géographiques.

## Exemple

```wlangage
// Déclaration d'une polyligne
maPolyligneGéo est une PolyligneGéo
// Construction de la polyligne : 4 points
maPolyligneGéo.AjoutePoint(2.681548, 43.802043)
maPolyligneGéo.AjoutePoint(2.816297, 43.725179)
maPolyligneGéo.AjoutePoint(2.842733, 43.817899)
maPolyligneGéo.AjoutePoint(2.644979, 43.837466)
// Sérialisation au format WKT
Trace("maPolyligneGéo : " + maPolyligneGéo.SérialiseWKT())
```

## Syntaxe

```wlangage
<Polyligne géographique>.AjoutePoint(<Latitude> , <Longitude>)
```

`<Polyligne géographique>` *Variable de type PolyligneGéo*
> Nom de la variable de type [PolyligneGéo](1410090128.md) à laquelle un nouveau point doit être ajouté.
`<Latitude>` *Réel*
> Latitude du point.
`<Longitude>` *Réel*
> Longitude du point.
