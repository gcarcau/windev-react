# <Variable Image>.DessinePoint (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Dessine un point dans une variable de type [Image](1000019650.md).
> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Dessiner en WINDEV, WEBDEV et WINDEV Mobile.

## Exemple

```wlangage
MonImage est une Image = "Test.bmp"
// Dessin d'un point jaune clair dans une variable Image
MonImage.DessinePoint(10, 50, JauneClair)
IMG_MonDessin = MonImage
```

## Syntaxe

#### Dessiner un point en donnant ses coordonnées

```wlangage
<Variable Image>.DessinePoint(<Abscisse> , <Ordonnée> [, <Couleur du point> [, <Opacité>]])
```

`<Variable Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) à manipuler.
`<Abscisse>` *Entier*
> Position horizontale (en pixels) du point à dessiner.
`<Ordonnée>` *Entier*
> Position verticale (en pixels) du point à dessiner.
`<Couleur du point>` *Entier ou constante (optionnel)*
> Couleur à affecter au point. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md).
>
>
> Si ce paramètre n'est pas précisé, la couleur du point :
>
>
> - est *Transparent* si la fonction [<Variable Image>.Stylo](1000024240.md) n'a pas été utilisée auparavant,
> - correspond à la couleur précisée dans le dernier appel à la fonction [<Variable Image>.Stylo](1000024240.md).
`<Opacité>` *Entier optionnel*
> Opacité de la couleur, comprise entre 0 (transparent) et 255 (opacité complète). Une opacité de 128 indique que le pixel concerné aura une transparence de 50% lorsqu'il sera dessiné à l'écran ou sauvé dans une image au format PNG.
> **Remarque** : Cette opacité sera prise en compte si le dessin dans l'image a été initialisé avec la constante *dAvecOpacité* (fonction [<Variable Image>.DébutDessin](1000024349.md)).

## Remarques

### Coordonnées
Les coordonnées sont indiquées par rapport au coin haut gauche de l'image (coordonnées (0,0)).
