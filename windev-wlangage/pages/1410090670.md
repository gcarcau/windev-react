# Paramètres de la procédure utilisée par la fonction PartageProximitéEnvoieFichier

> **Disponible :** **WINDEV Mobile** (Android)

Procédure WLangage (également nommée "callback") appelée par la fonction [PartageProximitéEnvoieFichier](1410090654.md) pour notifier le succès ou l'échec de l'envoi.

## Exemple

```wlangage
PartageProximitéEnvoieFichier(gTabAppareilsSélectionnés, sCheminRessource, CallbackEnvoi)
```

```wlangage
PROCÉDURE CallbackEnvoi(bResultat est un booléen, nIdTransfert est un entier)
SI bResultat ALORS
	ToastAffiche("Fichier envoyé")
SINON
	ToastAffiche(ErreurInfo())
FIN
```

## Syntaxe

```wlangage
PartageProximitéEnvoieFichier_Callback(<Résultat> , <Identifiant>)
```

`<Résultat>` *Booléen*
> - Vrai si les données ont été envoyées,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet de connaître le détail de l'erreur.
`<Identifiant>` *Entier*
> Identifiant du transfert.
