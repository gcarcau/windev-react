# <Table>.DébutRemplissage (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Indique le début du remplissage d'un champ Table (ou Table hiérarchique) par programmation. L'avancement du remplissage est représenté :

- soit par une jauge infinie affichée au bas du champ.
- soit par une fenêtre interne.

**Attention** : Avant d'utiliser cette fonction, vous devez activer le mécanisme de gestion du remplissage dans la fenêtre de description du champ. Pour plus de détails, consultez [Caractéristiques des champs Table dans une fenêtre](1013200.md).

## Exemple

```wlangage
TABLE_Mem.DébutRemplissage()

POUR i = 1 À 10000
	TABLE_Mem.AjouteLigne()
FIN

TABLE_Mem.FinRemplissage() // Remplissage terminé
```

## Syntaxe

```wlangage
<Champ Table>.DébutRemplissage()
```

`<Champ Table>` *Nom de champ*
> Nom du champ à manipuler. Ce champ peut correspondre à :
>
> - un champ Table.
> - un champ Table hiérarchique.
> - un champ Combo avec table.

## Remarques

- A la fin de votre traitement de chargement du champ Table, il est nécessaire d'appeler la fonction [<Table>.FinRemplissage](1000024252.md) afin d'indiquer que le remplissage est terminé.
- Cette fonction est sans effet sur les champs Table reliés à une source de données de type fichier ou requête.

**Composante : wd300obj.dll**
