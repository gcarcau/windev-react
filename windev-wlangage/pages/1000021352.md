# mlTermine (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Termine une session MATLAB. Cette session a été initialisée avec la fonction [mlInitialise](1000021351.md).

## Exemple

```wlangage
nIdSession est un entier = mlInitialise()
SI ErreurDétectée() ALORS
	ErreurInfo(errComplet)
	RETOUR
FIN
mlExécute(nIdSession, "A = cosd(180)")
...
mlTermine(nIdSession)
```

## Syntaxe

```wlangage
mlTermine(<Identifiant de la session>)
```

`<Identifiant de la session>` *Entier*
> Identifiant de la session MATLAB à manipuler. Cet identifiant est renvoyé par la fonction [mlInitialise](1000021351.md).

**Composante : wd300com.dll**
