# kbActionAutorisée (Type de variable)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Le type **kbActionAutorisée** permet de définir toutes autorisations données à l'utilisateur final pour manipuler une carte d'un champ Kanban. Ces autorisations peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
Attention : Ce type de variable peut être utilisé uniquement sur les variables de type [kbCarte](1410089167.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Interdire de supprimer une tâche
laTache est un kbCarte
laTache.Titre = "IMPORTANT"
laTache.ActionAutorisée.Supprimer = Faux
KanbanAjouteCarte(LISTE_TODO, laTache)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type kbActionAutorisée :
Les propriétés suivantes peuvent être utilisées pour manipuler les actions autorisées sur une carte d'un champ Kanban :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| AfficherDétail | Booléen | - Vrai pour autoriser l'exécution de l'événement "Affichage du détail de la carte" lors d'un clic ou double-clic sur mobile, - Faux pour l'interdire. |
| ChangerListe | Booléen | - Vrai pour autoriser l'utilisateur final à déplacer la carte d'une liste à l'autre, - Faux pour l'interdire. |
| Déplacer | Booléen | - Vrai pour autoriser l'utilisateur final à déplacer la carte dans la liste, - Faux pour l'interdire. |
| Supprimer | Booléen | - Vrai pour autoriser l'utilisateur final à supprimer la carte par un Drag and Drop vers le pied de la liste, - Faux pour l'interdire. |
