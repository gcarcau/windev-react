# <Variable Connexion>.ActiveTriggerServeur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Ré-active un trigger serveur précédemment désactivé par la fonction [<Variable Connexion>.DésactiveTriggerServeur](1000022654.md).
**Remarque** : Les fonctions de manipulation des triggers serveur sont des fonctions avancées. Les triggers serveur peuvent être créés directement dans l'éditeur d'analyses. Pour plus de détails, consultez [Triggers serveur](3044369.md).

## Syntaxe

#### Activer un trigger serveur sur des fichiers physiques associés à une connexion

```wlangage
<Résultat> = <Connexion>.ActiveTriggerServeur(<Trigger> [, <Fichiers physiques HFSQL Client/Serveur>])
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom d'une variable de type [Connexion](1514073.md) correspondant à la connexion à manipuler.
`<Trigger>` *Chaîne de caractères*
> Nom du trigger à activer. Ce nom a été donné grâce à la fonction [<Variable Connexion>.DécritTriggerServeur](1000022653.md).
`<Fichiers physiques HFSQL Client/Serveur>` *Chaîne de caractères optionnelle*
> Nom physique de un ou plusieurs fichiers de données HFSQL Client/Serveur associés à la connexion (par exemple "CLIENT.FIC").
> Pour indiquer plusieurs noms, séparez les noms des fichiers de données par une virgule (",").
> Si ce paramètre n'est pas précisé ou est égal à une chaîne vide (""), le trigger sera activé sur tous les fichiers de données de la base de données associée à la connexion.
