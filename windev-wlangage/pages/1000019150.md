# <Variable zipArchive>.OuvreRAR (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Ouvre une archive existante au format RAR.
Remarque : les archives RAR sont gérées jusqu'à la version 5 incluse.

Nouveauté 2025

> _(iPhone/iPad)_ Cette fonction est désormais disponible pour les applications iPhone/iPad.

> _(Widget IOS)_ Cette fonction est désormais disponible en mode Widget iOS.

## Exemple

```wlangage
MonArchive est une zipArchive
// Ouverture d'une archive
ResOuvreArchive = MonArchive.OuvreRAR("C:\MesArchives\Archive.rar")
// Affichage du message d'erreur si l'archive n'a pas été ouverte
SI ResOuvreArchive <> 0 ALORS
	Erreur(zipMsgErreur(ResOuvreArchive))
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Archive>.OuvreRAR(<Chemin de l'archive> [, <Mode d'ouverture de l'archive>])
```

`<Résultat>` *Entier*
> - 0 si l'archive a été ouverte,
> - Un code d'erreur (valeur supérieure à 0) dans le cas contraire. Pour plus de détails sur ces codes d'erreur, consultez les Remarques.
`<Archive>` *Variable de type zipArchive*
> Nom d'une variable de type [zipArchive](1000018679.md) correspondant à l'archive à manipuler.
`<Chemin de l'archive>` *Chaîne de caractères*
> Chemin et nom de l'archive (260 caractères maximum). L'extension de l'archive peut être précisée.
`<Mode d'ouverture de l'archive>` *Constante optionnelle ou combinaison de constantes*
> Options d'ouverture de l'archive :
>
> | *zipEntête64* | Permet de créer une archive de plus de 4 gigas sur laquelle la fonction [<Variable zipArchive>.ChangeChemin](1000026329.md) pourra être utilisée. |
> | --- | --- |
> | *zipLecture* | Ouverture en lecture seule. |

## Remarques

### Codes d'erreur
Les codes d'erreur retournés sont les suivants :

- 1 : Le chemin passé en paramètre n'existe pas.
- 2 : Accès interdit : l'utilisateur n'a pas les droits nécessaires.
- 3 : L'archive est corrompue.
- 6 : Les fichiers des sous-archives ne sont pas dans l'ordre (cas de l'ouverture d'une archive multi-parties).

Le message correspondant au code d'erreur peut être connu grâce à la fonction [zipMsgErreur](3082034.md).
