# grHistoTypeBarre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Définit le type de barre à utiliser dans un graphe de type histogramme.

## Exemple

```wlangage
// Les barres de l'histogramme ont des coins arrondis
grHistoTypeBarre(GRF_MonGraphe, grHistoCoinsArrondis)
```

## Syntaxe

```wlangage
grHistoTypeBarre(<Nom du graphe> , <Forme des barres>)
```

`<Nom du graphe>` *Nom de champ ou chaîne de caractères*
> Nom du graphe à manipuler. Ce nom correspond :
>
> - soit au nom du graphe défini par programmation avec la fonction [grCrée](3042005.md).
> - soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.
>
>
> > _(Android)_ Seuls les champs Graphe sont disponibles.
`<Forme des barres>` *Constante de type Entier*
> Constante permettant de spécifier la forme des barres :
>
> | *grHistoCoinsArrondis* | Les barres de l'histogramme ont des coins arrondis. |
> | --- | --- |
> | *grHistoCoinsRectangulaires* | Les barres de l'histogramme ont des coins rectangulaires. |

**Classification Métier / UI : Code métier**

**Composante : wd300grf.dll**
