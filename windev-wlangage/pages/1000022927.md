# docCellule (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Le type **docCellule** permet de définir toutes les caractéristiques avancées d'une cellule d'un tableau présent dans un document de type Traitement de texte. Les caractéristiques de cette cellule peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**ATTENTION : Ce type ne doit pas être utilisé directement.** Il doit être utilisé uniquement :

- via le type [docElément](1000022484.md) (dans le cas d'un élément de type Cellule).
- via le type [docParagraphe](1000022483.md) (dans le cas d'un paragraphe de type Tableau).

Pour plus de détails sur les différents types liés aux documents de type Traitement de texte, consultez [Types associés au Traitement de texte](1000022736.md).

## Exemple

```wlangage
// Récupération du document
MonDocument est un Document <- TT_Tableau
// Récupération du tableau, ici le paragraphe 1
pTableau est un docParagraphe <- MonDocument.Paragraphe[1]

// Parcours les lignes
POUR i = 1 _À_ pTableau.Tableau.Lignes.Occurrence
	// Parcours les colonnes
	POUR j = 1 _À_ pTableau.Tableau.Colonnes.Occurrence
		Trace("Valeur de la cellule [[%i%]][[%j%]] = " +
		pTableau.Tableau.Cellules[i,j].Contenu.Texte)
	FIN
FIN
```

## Remarques

### Propriétés spécifiques à la description des variables de type docCellule
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **docCellule** :

| **Nom de la propriété** | Type manipulé | Effet |  |
| --- | --- | --- | --- |
|  | MiseEnPage.Cadre | Variable de type [Cadre](15140100.md) | Caractéristiques du cadre utilisé pour le paragraphe.  Remarque : les coins arrondis ne sont pas gérés. |
|  | MiseEnPage.TrameFond | Variable de type [Fond](1000022038.md) | Caractéristiques de fond de la cellule. |
|  | MiseEnPage.CouleurFond | Entier | Couleur de fond de la cellule. Cette couleur peut correspondre à :  - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)), - [une couleur prédéfinie](3010002.md). |
| Contenu | Variable de type [docFragment](1000022482.md) | Contenu d'une cellule du tableau. |  |
| EtendueHorizontale | Entier | Indice de la colonne en cours. |  |
| EtendueVerticale | Entier | Indice de la ligne en cours. |  |
| IndiceColonne | Entier | Indice de la colonne en cours. |  |
| IndiceLigne | Entier | Indice de la ligne en cours. |  |
| MiseEnPage |  | Mise en page de la cellule en cours. |  |
