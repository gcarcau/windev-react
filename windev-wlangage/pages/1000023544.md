# LecteurPDFSurligne (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Cherche un texte dans le document affiché par un champ Lecteur PDF et surligne les occurrences de ce texte dans le champ.

## Exemple

```wlangage
// Surligne toutes les occurrences de "WINDEV" dans un champ lecteur PDF en jaune
LecteurPDFSurligne(PDF_LECTEUR_PDF, "WINDEV", JauneClair, MotComplet)
// Surligne toutes les occurrences de "WEBDEV" en bleu
LecteurPDFSurligne(PDF_LECTEUR_PDF, "WEBDEV", BleuClair, MotComplet)
// Surligne toutes les occurrences de "WINDEV Mobile" en orange
LecteurPDFSurligne(PDF_LECTEUR_PDF, "WINDEV Mobile", OrangeClair, MotComplet)
// Supprime tous les surlignages
LecteurPDFSurligne(PDF_LECTEUR_PDF, "")
```

## Syntaxe

```wlangage
<Résultat> = LecteurPDFSurligne(<Champ Lecteur PDF> , <Texte recherché> [, <Couleur> [, <Options de recherche>]])
```

`<Résultat>` *Entier*
> - Nombre d'occurrences trouvées du texte dans le champ.
> - 0 si aucun élément ne contient le texte recherché.
`<Champ Lecteur PDF>` *Nom de champ*
> Nom du champ Lecteur PDF à manipuler.
`<Texte recherché>` *Chaîne de caractères*
> - Texte à rechercher dans l'élément spécifié.
> - "" (chaîne vide) pour annuler la recherche.
`<Couleur>` *Entier, constante ou variable de type Couleur optionnel*
> Couleur utilisée pour surligner les occurrences trouvées. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md).
> - une variable de type [Couleur](1000019661.md).
>
>
> **Remarque** : La couleur utilisée par défaut est le jaune clair.
`<Options de recherche>` *Constante optionnelle de type Entier*
> Indique les options de la recherche :
>
> | *MotComplet* | Recherche un mot complet (entouré par des caractères de ponctuation ou des espaces). |
> | --- | --- |
> | *SansCasse* | Recherche sans tenir compte de la casse (différences majuscules / minuscules) ou des accents. |
>
>
> Par défaut, aucune option n'est sélectionnée : la recherche est sensible à la casse et est effectuée sur les mots incomplets.

## Remarques

- Tant que la fonction n'est pas rappelée avec une chaîne vide ("") pour arrêter le surlignage, tous les nouveaux appels ajouteront un surlignage en plus.
- A partir de la version 28, cette fonction n'est pas supportée par les processeurs ARM 32 bits. En effet, les nouveautés en matière de gestion des PDF imposent une exécution en 64 bits.
  Si une application doit être exécutée sur une flotte existante d'appareils ARM 32 bits, la génération de cette application doit être effectuée avec la version 27 de WINDEV Mobile.
