# Fonctions de gestion des jetons (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions de gestion des jetons dans les champs de saisie via une syntaxe préfixée sont les suivantes :

| [<Saisie>.AjouteJeton](1000024043.md) | Ajoute un jeton dans un champ de saisie de type "Jetons de texte". |
| --- | --- |
| [<Saisie>.InsèreJeton](1000024044.md) | Insère un jeton dans un champ de saisie de type "Jetons de texte". |
| [<Saisie>.OccurrenceJeton](1000024045.md) | Renvoie le nombre de jetons présents dans un champ de saisie de type "Jetons de texte". |
| [<Saisie>.SupprimeJeton](1000024046.md) | Supprime un jeton dans un champ de saisie de type "Jetons de texte". |
| [<Saisie>.SupprimeToutJeton](1000024047.md) | Supprime tous les jetons d'un champ de saisie de type "Jetons de texte". |
