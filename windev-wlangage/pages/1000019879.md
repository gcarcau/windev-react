# ArcTang2 (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Renvoie l'arc tangente 2 des valeurs passées en paramètre.

## Exemple

```wlangage
ArcTang2(1, 1) 	// Renvoie 45
ArcTang2(1, -1) 	// Renvoie 135
ArcTang2(-1, 1) 	// Renvoie -45
ArcTang2(-1, -1) 	// Renvoie -135
```

## Syntaxe

```wlangage
<Résultat> = ArcTang2(<Y> , <X>)
```

`<Résultat>` *Réel*
> - Angle (en degrés) entre :
>   - la partie positive de l'axe des X d'un plan,
>   - et le point de ce plan aux coordonnées (X,Y).
>     Cet angle est positif pour les angles dans le sens anti-horaire dit sens trigonométrique (moitié haute du plan, Y > 0) et négatif dans l'autre (moitié basse du plan, Y < 0).
>     Cet angle est compris dans l'intervalle [-180,180].
> - 0 si les paramètres <X> et <Y> sont égaux à 0.
`<Y>` *Réel*
> Valeur Y.
`<X>` *Réel*
> Valeur X.

**Classification Métier / UI : Code neutre**
