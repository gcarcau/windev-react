# zipFichierEnCours (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie le nom du fichier archivé en cours de manipulation par les fonctions d'ajout et d'extraction de fichiers. Cette fonction est utilisable sur les archives au format CAB, RAR, WDZ, ZIP, gzip, TAR et TGZ (TAR.GZ).
Nouveauté 2025

> _(WINDEV, WEBDEV - Code Serveur, Windows, Linux, iPhone/iPad)_ Le format gzip (extension .gz) est désormais géré.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Ajax)_ Archive est une zipArchive

POUR Indice = 1 À 5
 // Extraction des 5 premiers fichiers de l'archive
 ResExtraitFichier = zipExtraitFichier(Archive, Indice)
 ...
 // Recherche du nom du fichier en cours d'extraction
 ResFichierEnCours = zipFichierEnCours(Archive)
 // Affichage du nom du fichier dans la barre de message
 Message(ResFichierEnCours)
 ...
FIN

## Syntaxe

```wlangage
<Résultat> = zipFichierEnCours(<Archive>)
```

`<Résultat>` *Chaîne de caractères*
> Fichier en cours de manipulation par les fonctions [zipAjouteFichier](3082008.md), [zipAjouteRépertoire](3082014.md), [zipExtraitFichier](3082019.md) ou [zipExtraitTout](3082011.md).
`<Archive>` *Chaîne de caractères ou variable de type zipArchive*
> Nom de l'archive à manipuler.
> Ce nom peut correspondre :
>
> - soit au nom d'une archive défini avec la fonction [zipOuvre](3082044.md) ou [zipCrée](3082003.md).
> - soit au nom d'une variable de type [zipArchive](1000018679.md).
>    Les variables de type [zipArchive](1000018679.md) ne sont pas disponibles en JAVA.

## Remarques

### Rappel

- Seules les archives au format ZIP, gzip, TAR et TGZ (TAR.GZ) sont disponibles.
- Seules les archives au format ZIP sont disponibles.

### Erreur pendant les traitements d'ajout et d'extraction de fichiers
En cas d'erreur pendant les traitements d'ajout ou d'extraction, la fonction **zipFichierEnCours** contient le nom du fichier qui n'a pas pu être lu ou écrit dans l'archive.
