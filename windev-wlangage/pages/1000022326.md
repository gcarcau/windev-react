# Constantes de sérialisation

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Les constantes de sérialisation sont les suivantes :

| Constante | Description | Fonction |
| --- | --- | --- |
| **psdBinaire** | Sérialisation binaire. | [Désérialise](3013066.md) [Sérialise](3013065.md) |
| **psdBinaireFormat16** | Sérialisation binaire au format compatible 16. | [Désérialise](3013066.md) [Sérialise](3013065.md) |
| **psdJSON** | Sérialisation au format JSON. | [Désérialise](3013066.md) [Sérialise](3013065.md) |
| **psdMiseEnForme** | Sérialisation au format JSON avec retours à la ligne et indentation. | [Sérialise](3013065.md) [VariantVersJSON](1000021051.md) |
| **psdXML** | Sérialisation XML avec référence aux sous-objets. Ce type de sérialisation permet d'utiliser le format XML comme moyen de stockage et d'échange entre des applications écrites en WLangage. | [Désérialise](3013066.md) [Sérialise](3013065.md) |
| **psdXML_AncienFormat** | Jusqu'à la version 100050, l'utilisation de la constante psdXML ne générait pas un fichier XML correct. Le format généré posait un problème essentiellement sur les postes Mobiles. Ce problème a été corrigé. Un fichier XML créé avec une version supérieure à la version 100050 n'est pas lisible par un programme compilé avec une version antérieure. Pour conserver le fonctionnement de la version 100050, il suffit d'utiliser la constante psdXML_AncienFormat. | [Désérialise](3013066.md) [Sérialise](3013065.md) |
| **psdXMLAgrégé** | Sérialisation XML avec agrégation directe des sous-objets. Ce type de sérialisation permet de générer rapidement un fichier XML dans un format classique, utilisé pour des échanges avec d'autres systèmes. | [Désérialise](3013066.md) [Sérialise](3013065.md) |
| Nouveauté 2025 **psdXMLTableauÉlémentsRépétés** | Sérialisation XML permettant de gérer les tableaux sous forme répétée.  **Attention** : Cette constante est disponible uniquement à partir de la version 2025 Update 1. | [Désérialise](3013066.md) [Sérialise](3013065.md) |
