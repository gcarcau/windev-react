# Evénements associés aux champs Graphe

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

## Evénements gérés par défaut

> _(WINDEV, Android, iPhone/iPad, iPhone/iPad)_ Evénements gérés par WINDEV et WINDEV MobileDans une fenêtre, WINDEV et WINDEV Mobile gèrent par défaut les événements suivants (ordre d'apparition sous l'éditeur de code) :EvénementCondition d'exécutionInitialisationExécuté à l'ouverture de la fenêtre. (*)ClicExécuté lors d'un clic de souris sur le champ Graphe. Avant affichage de la bulleExécuté dans une application iPhone/iPad avant l'affichage de la bulle d'aide lors d'un appui sur une valeur du graphe avec un doigt.Cet événement permet par exemple de lancer une procédure spécifique.(*) Par défaut, l'événement "Initialisation" de chaque champ est exécuté selon l'ordre de création des différents champs dans la fenêtre. Pour modifier cet ordre d'exécution : Sous le volet "Fenêtre", dans le groupe "Ordre", cliquez sur "Initialisation". Dans la fenêtre qui s'affiche, utilisez les flèches situées sur la droite pour modifier l'ordre d'initialisation des champs.

> _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur, PHP)_ Evénements gérés par WEBDEVDans une page, WEBDEV gère par défaut les événements suivants (ordre d'apparition sous l'éditeur de code) :EvénementCondition d'exécutionInitialisation (Code serveur)Exécuté à l'ouverture de la page.Chargement (Code navigateur)Exécuté à chaque chargement et affichage de l'image du graphe par le navigateur.Clic sur l'image (Code navigateur)Exécuté lorsque l'internaute clique sur le champ Graphe.

### Evénement disponibles sous l'éditeur d'états
L'éditeur d'états gère par défaut les événements suivants (ordre d'apparition sous l'éditeur de code) :

| Evénement | Condition d'exécution |
| --- | --- |
| Initialisation | Exécuté lors de l'initialisation de l'état. L'ordre d'exécution des événements au lancement d'un état (y compris lors d'un test) est le suivant :  - événement "Ouverture" de l'état. - événement "Initialisation" des blocs de l'état. - événement "Initialisation" des champs. |
| Avant impression | Exécuté avant l'impression du champ. |
| Clic | Exécuté lors du clic sur le champ. Le clic sur le champ est disponible uniquement dans le visualisateur de rapports. Une étoile permet à l'utilisateur d'identifier simplement les champs cliquables. |

## Evénements optionnels

Plusieurs événements optionnels peuvent être gérés.
Pour ajouter un événement optionnel :

1. Sélectionnez le champ voulu.
2. Affichez la fenêtre de code de ce champ (touche F2).
3. Cliquez sur le lien "Ajouter d'autres événements à xxx" situé à la fin de la fenêtre de code, après le dernier événement.
4. La totalité des événements optionnels disponibles pour le champ est affichée.
5. Cochez l'événement optionnel à ajouter et validez.
  Remarque : Il est possible de sélectionner plusieurs événements optionnels.
6. L'événement optionnel sélectionné est automatiquement ajouté dans les événements gérés par le champ.

Pour désactiver un événement optionnel, il suffit d'effectuer les mêmes manipulations pour afficher la liste des événements optionnels. Il suffit ensuite de décocher les événements optionnels à supprimer.
Remarque : Si le code désactivé contient du code WLangage, ce code est automatiquement supprimé.
Il est ainsi possible de gérer par exemple :

- le survol du champ par la souris,
- le bouton gauche enfoncé, relâché, avec un double-clic,
- le bouton droit enfoncé, relâché, avec double-clic,
- la roulette de la souris, ...

Pour plus de détails, consultez les [Evénements optionnels](1014004.md).

> _(WINDEV)_ Evénements optionnels spécifiques aux champs GrapheWINDEV propose deux événements optionnels spécifiques aux champs Graphe : EvénementCondition d'exécutionZoom horizontalExécuté lors d'un zoom dans un champ Graphe. Cet événement est exécuté :si seul le zoom horizontal est activé.si le zoom horizontal et le zoom vertical sont activés.Zoom verticalExécuté lors d'un zoom dans un champ Graphe. Cet événement est exécuté :si seul le zoom vertical est activé.si le zoom horizontal et le zoom vertical sont activés.Ces événements de zoom peuvent permettre par exemple de gérer le zoom dans l'image superposée au graphe.
