# RendezVousRAZ (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android) · **Autres** (Procédures stockées)

Réinitialise :

- la structure [RendezVous](1000011010.md).
  **Rappel** : Cette fonction ne permet pas de réinitialiser la structure RendezVous d'une messagerie Outlook Express.
- la variable de type [RendezVous](1000019244.md) utilisée par un calendrier (ou agenda) d'un appareil Android.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur)_ // Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", "mail/julie.nsf", "C:\Lotus Notes\julie.id")
// Initialisation des variables de la structure RendezVous
RendezVousRAZ()
// Renseignements des variables pour le nouveau rendez-vous
mRendezVous.Objet = "Réunion commerciaux"
mRendezVous.DateDébut = "20070125100000"
mRendezVous.Lieu = "Salle 3B"
mRendezVous.NbParticipant = 3
mRendezVous.Participant[1] = "Romain"
mRendezVous.Participant[2] = "Lucas"
mRendezVous.Participant[3] = "Stéphane"
// Ajout du rendez-vous
SI RendezVousAjoute(IDSession) = Vrai ALORS
 Info("Rendez-vous ajouté")
SINON
 Erreur("Erreur lors de l'ajout", ErreurInfo())
FIN

> _(Android, Widget Android)_ // Ajout d'un nouveau rendez-vous
RendezVousRAZ(gRDV)
gRDV.Titre = SAI_Titre
gRDV.DateDébut = SAI_DateDeb + SAI_HeureDeb
gRDV.DateFin = SAI_DateFin + SAI_HeureFin
gRDV.Lieu = SAI_Lieu
gRDV.Contenu = SAI_Desc
SI SAI_Fuseau <> "" ALORS
 gRDV.FuseauHoraire = SAI_Fuseau
FIN
gRDV.Auteur = SAI_Auteur
gRDV.Invité = SAI_Invités
gRDV.JournéeEntière = INT_Jentière[1]

SI RendezVousAjoute(gCal, gRDV) ALORS
 ToastAffiche("RDV ajouté")
SINON
 Erreur(ErreurInfo())
FIN

## Syntaxe

> _(WINDEV, WEBDEV - Code Serveur)_ Réinitialiser la structure RendezVous
RendezVousRAZ()

> _(Android, Widget Android)_ Réinitialiser une variable de type RendezVous Masquer les détails
RendezVousRAZ(<Rendez-vous>)

 <Rendez-vous> : Variable de type RendezVousNom de la variable de type RendezVous à réinitialiser.

## Remarques

> _(Android, Widget Android)_ Cas particuliersLa fonction RendezVousRAZ peut être utilisée dans l'émulateur mais pas dans le simulateur.

**Composante : wd300com.dll**
