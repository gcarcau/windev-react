# <Variable Image>.SymétrieVerticale (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Retourne l'image contenue dans une variable de type [Image](1000019650.md) par rapport à un axe vertical (symétrie par rapport à un axe vertical).
> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Dessiner en WINDEV, WEBDEV et WINDEV Mobile.

## Exemple

```wlangage
MonImage est une Image = "Test.bmp"
// Symétrie verticale de l'image contenue dans la variable Image
MonRésultat est un booléen
MonRésultat = MonImage.SymétrieVerticale()
SI MonRésultat = Faux ALORS Erreur("L'opération a échoué")
IMG_MonDessin = MonImage
```

## Syntaxe

```wlangage
<Résultat> = <Variable Image>.SymétrieVerticale()
```

`<Résultat>` *Booléen*
> - Vrai si la symétrie a été effectuée,
> - Faux dans le cas contraire.
`<Variable Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) à manipuler.
> La symétrie est réalisée par rapport à l'axe vertical médian de l'image. L'image est directement modifiée.

## Remarques

### Fin du dessin
Si la fonction [<Variable WDPic>.FinDessin](1000024472.md) est appelée dans le même traitement que la fonction **<Variable Image>.SymétrieVerticale**, la transformation de l'image ne sera pas affichée.

**Composante : wd300pnt.dll**
