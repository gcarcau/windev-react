# ZoneRépétéeEnrouleTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Enroule toutes les ruptures déroulées d'un champ Zone répétée.

## Exemple

```wlangage
// Clic sur le champ Bouton [4 étoiles uniquement]
ZoneRépétéeEnrouleTout(ZR_HOTEL)
nLigne4Etoile est un entier
nLigne4Etoile = ZoneRépétéeCherche(ZR_HOTEL, ATT_NBETOILE, 4)
ZoneRépétéeDéroule(ZR_HOTEL, nLigne4Etoile)
```

## Syntaxe

```wlangage
ZoneRépétéeEnrouleTout(<Champ Zone répétée>)
```

`<Champ Zone répétée>` *Nom de champ*
> Nom du champ Zone répétée à manipuler.
> Si ce paramètre est égal à chaîne vide (""), le champ Zone répétée en cours est manipulé.

## Remarques

### Conditions d'utilisation
La fonction **ZoneRépétéeEnrouleTout** peut être utilisée indifféremment sur :

- un champ Zone répétée fichier,
- un champ Zone répétée par programmation.

> _(WEBDEV - Code Navigateur)_ Cette fonction n'est pas disponible sur les champs Zone répétée linéaire. Cette fonction est disponible uniquement sur les champs Zone répétée en mode navigateur.

> _(WEBDEV - Code Serveur, PHP)_ Cette fonction est disponible pour les champs Zone répétée en mode Ajax, les champs Zone répétée en mode classique et les champs Zone répétée linéaire.
