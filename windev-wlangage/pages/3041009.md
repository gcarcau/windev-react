# gpwOuvreConfiguration (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

Ouvre la fenêtre ou la page de configuration du groupware utilisateur.
Cette fonction est prise en compte uniquement si l'utilisateur en cours est un **superviseur** et s'il est connecté au groupware utilisateur (grâce à la fonction [gpwLogin](3041001.md) ou depuis la page ouverte par la fonction [gpwOuvre](3041002.md)).

**Remarque** : Cette fonction est disponible uniquement en mode "Groupware utilisateur classique".

## Exemple

```wlangage
// Ouverture de la page de configuration du groupware utilisateur
gpwOuvreConfiguration()
```

## Syntaxe

```wlangage
<Résultat> = gpwOuvreConfiguration()
```

`<Résultat>` *Booléen*
> - Vrai si la page de configuration s'est ouverte,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.

**Composante : wd300gpu.dll**
