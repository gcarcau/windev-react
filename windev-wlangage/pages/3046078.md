# iRepImageHTML (Fonction)

> **Disponible :** **WEBDEV** (Windows)

Permet de sélectionner le répertoire dans lequel les images doivent être générées lors d'une impression au format HTML.

## Exemple

```wlangage
// Génération des images dans le sous-répertoire "Temp" du répertoire "_WEB"
iRepImageHTML(iRépertoireWeb, "Temp")

// Impression au format HTML
iDestination(iHTML)

// Impression de l'état
iImprimeEtat(ETAT_MonEtat)

// Ouverture du fichier HTML généré dans le navigateur
FichierAffiche(iDernierFichier())
```

## Syntaxe

```wlangage
iRepImageHTML(<Répertoire> [, <Sous-Répertoire>])
```

`<Répertoire>` *Constante de type Entier*
> Répertoire dans lequel les images d'une impression au format HTML doivent être générées :
>
> | *iRépertoireHTML* | Répertoire dans lequel le fichier HTML est généré. Ce répertoire est sélectionné grâce à la fonction [iDestination](3046074.md). Les images générées dans ce répertoire **ne** pourront **pas** être affichées grâce à la fonction [FichierAffiche](3012005.md). |
> | --- | --- |
> | *iRépertoireWeb* | Répertoire "<MonProjet>_WEB" du site. Ce répertoire doit être accessible en lecture et en écriture. Les images générées dans ce répertoire pourront être affichées grâce à la fonction [FichierAffiche](3012005.md). |
`<Sous-Répertoire>` *Chaîne de caractères optionnelle*
> Sous-répertoire relatif au répertoire spécifié dans <Répertoire>. Si aucun sous-répertoire n'est spécifié, les images seront générées directement dans le répertoire spécifié dans <Répertoire>.

## Remarques

Pour plus de détails sur l'affichage d'un état au format HTML, consultez [Afficher un état au format HTML dans le navigateur de l'internaute](1011051.md).
