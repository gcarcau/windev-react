# sfEnregistrementSupprimé (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Le type **sfEnregistrementSupprimé** permet de connaître les caractéristiques d'un enregistrement supprimé puis récupéré avec la fonction [SFRechercheSupprimé](1000018475.md).
Ce type de variable est utilisé par le type [sfRésultatRechercheSupprimé](1000018562.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Connexion à Salesforce
Cnx est une sfConnexion
Cnx.Login = "balthazar@gmail.com"
Cnx.MotDePasse = "azerty" + "XXB12VCZ54"
SI SFConnecte(Cnx) = Faux ALORS
	Erreur("La connexion a échoué")
	RETOUR
FIN

ResRecupSuppr est un sfRésultatRechercheSupprimé
ResRecupSuppr = SFRechercheSupprimé(Cnx, "Mileage__c", "20090101", "20090131")

MonEnregistrement est un sfEnregistrementSupprimé
POUR TOUT MonEnregistrement DE ResRecupSuppr.EnregistrementSupprimé
	Trace("--- ID : " + MonEnregistrement.ID)
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type sfEnregistrementSupprimé
Les propriétés suivantes peuvent être utilisées pour manipuler un enregistrement supprimé puis récupéré avec la fonction [SFRechercheSupprimé](1000018475.md) :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| DateSuppression | DateHeure | Date et heure de la suppression de l'enregistrement (au format UTC). **Cette propriété est disponible en lecture seulement**. |
| ID | Chaîne de caractères | Identifiant de l'enregistrement supprimé. **Cette propriété est disponible en lecture seulement**. |
