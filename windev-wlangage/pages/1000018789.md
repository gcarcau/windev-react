# SourceXML (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **SourceXML** permet de connaître le code source XML. Cette propriété est utilisable avec :

- une variable de type [wsRéponse](1000020568.md).
- une variable de type [xmlNoeud](1000018786.md).
