# <Variable picCalque>.FinDessin (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Libère les ressources associées à la variable de type [picCalque](1000024604.md).
**Remarque** : L'appel de la fonction **<Variable picCalque>.FinDessin** est optionnel. Les ressources sont automatiquement libérées au moment de la fermeture de la fenêtre ou de la page.

## Exemple

```wlangage
MonWDPic est un WDPic = "Test.bmp"
MonCalque est un picCalque
...
// Destruction de l'image présente dans le calque
MonCalque.FinDessin()
```

## Syntaxe

```wlangage
<Image picCalque>.FinDessin()
```

`<Image picCalque>` *Variable de type picCalque*
> Nom de la variable de type [picCalque](1000024604.md) à manipuler.

## Remarques

### Utilisation dans le cadre de la syntaxe préfixée
La fonction [<Variable picCalque>.DébutDessin](1000024470.md) doit être appelée avant l'utilisation des fonctions de dessin. La fonction [<Variable picCalque>.DébutDessin](1000024470.md) permet de définir les options de dessin utilisées sur le type [picCalque](1000024604.md).
La fonction **<Variable picCalque>.FinDessin** ne doit pas être appelée dans le même traitement que la fonction [<Variable picCalque>.DébutDessin](1000024470.md).
Si la fonction **<Variable picCalque>.FinDessin** est appelée dans le même traitement que la fonction [<Variable picCalque>.DébutDessin](1000024470.md), le dessin n'apparaîtra pas : il sera automatiquement effacé.
