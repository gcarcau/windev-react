# Section (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **Section** permet de gérer les sections dans les documents de type Traitement de texte. Cette propriété est disponible :

- sur les variables de type [docParagraphe](1000022483.md).
- sur les variables de type [Document](1000022461.md).
- avec la propriété [Sélection](1000023033.md).
