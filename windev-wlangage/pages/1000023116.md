# BeaconArrêteDétectionPrécise (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Arrête la détection de balises Beacon lancée avec la fonction [BeaconDétectePrécis](1000023115.md).

## Exemple

```wlangage
// Lance une détection d'un groupe de balises Beacon en arrière-plan
BeaconDétecteEnArrièrePlan(tabGroupeBalises, ProcDétection)

	PROCÉDURE INTERNE ProcDétection(groupe est un beaconGroupe, nType est un entier)
	// Entrée dans la zone d'émission des balises de groupes
		SI nType = bdapEntrée
			// On recherche les balises à proximité
			BeaconDétectePrécis(groupe, procDétectionPrécise)
			// Sortie de la zone d'émission des balises de groupes
		SINON
			// On stoppe la détection précise
			BeaconArrêteDétectionPrécise()
		FIN
	FIN
```

## Syntaxe

```wlangage
<Résultat> = BeaconArrêteDétectionPrécise()
```

`<Résultat>` *Booléen*
> - Vrai si la détection a bien été arrêtée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).

## Remarques

### Version nécessaire

> _(Android, Widget Android)_ Les fonctions de gestion des balises Beacon sont disponibles uniquement sur les appareils disposant d'une version d'Android supérieure ou égale à la version 4.3 (api level 18).
Si la fonction est utilisée avec une version antérieure du système, une erreur fatale sera déclenchée. Pour connaître la version du système Android sur laquelle s'exécute l'application, utilisez la fonction SysVersionAndroid.

> _(iPhone/iPad, Widget IOS)_ Les fonctions de gestion des balises Beacon sont disponibles uniquement sur les appareils disposant d'une version d'iOS supérieure ou égale à iOS 11.
