# Constantes de gestion des tableaux

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Les différentes constantes de gestion des tableaux sont les suivantes :

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |
| **AprèsElémentCourant** | Permet d'insérer un élément après l'élément courant de la liste. | [Insère](1000017351.md), [TableauInsère](3075009.md) |
| **AvantElémentCourant** | Permet d'insérer un élément avant l'élément courant de la liste. | [Insère](1000017351.md), [TableauInsère](3075009.md) |
| **DernierElément** | Permet de manipuler le dernier élément de la liste. | [Insère](1000017351.md), [Supprime](1000017354.md), [TableauInsère](3075009.md), [TableauSupprime](3075008.md) |
| **ElémentCourant** | Permet de manipuler l'élément courant de la liste ou du tableau associatif. | [Supprime](1000017354.md), [TableauSupprime](3075008.md) |
| **PremierElément** | Permet de manipuler le premier élément de la liste. | [Insère](1000017351.md), [Supprime](1000017354.md), [TableauInsère](3075009.md), [TableauSupprime](3075008.md) |
| **tccOrdreLexicographique** | Option de recherche : Tri selon l'ordre linguistique. | [Cherche](1000017365.md), [TableauCherche](3075002.md), [TableauSupprimeDoublon](1000019422.md), [TableauTrie](3075007.md), [Trie](1000017364.md) |
| **tccRespecteNumérique** | Option de recherche : Trie en respectant l'ordre des valeurs numériques. | [Cherche](1000017365.md), [TableauCherche](3075002.md), [TableauSupprimeDoublon](1000019422.md), [TableauTrie](3075007.md), [Trie](1000017364.md) |
| **tccSansAccent** | Option de recherche : Recherche sans tenir compte des accents. | [Cherche](1000017365.md), [TableauCherche](3075002.md), [TableauSupprimeDoublon](1000019422.md), [TableauTrie](3075007.md), [Trie](1000017364.md) |
| **tccSansCasse** | Option de recherche : Recherche sans tenir compte de la casse. | [Cherche](1000017365.md), [TableauCherche](3075002.md), [TableauSupprimeDoublon](1000019422.md), [TableauTrie](3075007.md), [Trie](1000017364.md) |
| **tccSansEspace** | Option de recherche : Recherche sans tenir compte des espaces au début et à la fin des chaînes. | [Cherche](1000017365.md), [TableauCherche](3075002.md), [TableauSupprimeDoublon](1000019422.md), [TableauTrie](3075007.md), [Trie](1000017364.md) |
| **tccSansEspaceIntérieur** | Option de recherche : Recherche sans tenir compte des espaces à l'intérieur des chaînes. | [Cherche](1000017365.md), [TableauCherche](3075002.md), [TableauSupprimeDoublon](1000019422.md), [TableauTrie](3075007.md), [Trie](1000017364.md) |
| **tccSansPonctuationNiEspace** | Option de recherche : Recherche sans tenir compte des espaces et des ponctuations. | [Cherche](1000017365.md), [TableauCherche](3075002.md), [TableauSupprimeDoublon](1000019422.md), [TableauTrie](3075007.md), [Trie](1000017364.md) |
| **tcDichotomique** | Type de recherche à effectuer : Recherche dichotomique décroissante | [Cherche](1000017365.md), [ChercheParProcédure](1000020102.md) , [TableauCherche](3075002.md), [TableauChercheParProcédure](1000020101.md), |
| **tcDichotomiqueConforme** | Type de recherche à effectuer : Recherche dichotomique croissante | [Cherche](1000017365.md), [TableauCherche](3075002.md) |
| **tcLinéaire** | Type de recherche à effectuer : Recherche linéaire | [Cherche](1000017365.md), [TableauCherche](3075002.md) |
| **tcLinéaireDernier** | Type de recherche à effectuer : Recherche linéaire à partir du dernier élément | [Cherche](1000017365.md), [TableauCherche](3075002.md) |
| **tcLinéairePrécédent** | Type de recherche à effectuer : Recherche linéaire de l'élément précédent | [Cherche](1000017365.md), [TableauCherche](3075002.md) |
| **tcLinéairePremier** | Type de recherche à effectuer : Recherche linéaire à partir du premier élément | [Cherche](1000017365.md), [TableauCherche](3075002.md) |
| **tcLinéaireSuivant** | Type de recherche à effectuer : Recherche linéaire de l'élément suivant | [Cherche](1000017365.md), [TableauCherche](3075002.md) |
| **tdDéplace** | Permet d'échanger ou de déplacer deux éléments ou deux lignes dans un tableau | [Déplace](1000017358.md), [DéplaceColonne](1000017360.md), [DéplaceLigne](1000017359.md), [TableauDéplace](3075011.md), [TableauDéplaceLigne](3075016.md) |
| **tdEchange** | Permet d'échanger ou de déplacer deux éléments ou deux lignes dans un tableau | [Déplace](1000017358.md), [DéplaceColonne](1000017360.md), [DéplaceLigne](1000017359.md), [TableauDéplace](3075011.md), [TableauDéplaceLigne](3075016.md) |
| **tiAssociatifAvecDoublon** | Type d'information à récupérer : Tableau associatif avec doublons | [TableauInfo](3075005.md) |
| **tiDéfinitionElément** | Type d'information à récupérer : Définition du type des éléments. | [FileInfo](1000019547.md) [ListeInfo](1000019548.md) [PileInfo](1000019546.md) [TableauInfo](3075005.md) |
| **tiDimension** | Type d'information à récupérer : Nombre d'éléments dans une dimension du tableau. | [TableauInfo](3075005.md) |
| **tiDynamique** | Type d'information à récupérer : Vrai si le tableau est un tableau dynamique | [TableauInfo](3075005.md) |
| **tiNombreColonnes** | Type d'information à récupérer : Nombre de colonnes d'un tableau à 2 dimensions | [TableauInfo](3075005.md) |
| **tiNombreDimensions** | Type d'information à récupérer : Nombre de dimensions du tableau (entre 1 et 10) | [TableauInfo](3075005.md) |
| **tiNombreLignes** | Type d'information à récupérer : Nombre de lignes d'un tableau à 2 dimensions | [TableauInfo](3075005.md) |
| **tiNombreTotal** | Type d'information à récupérer : Nombre total d'éléments dans le tableau | [FileInfo](1000019547.md) [ListeInfo](1000019548.md) [PileInfo](1000019546.md)[TableauInfo](3075005.md) |
| **tiTailleElément** | Type d'information à récupérer : Taille (en octets) d'un élément du tableau | [TableauInfo](3075005.md) |
| **tiTailleTotale** | Type d'information à récupérer : Taille totale (en octets) du tableau | [TableauInfo](3075005.md) |
| **tiTypeClé** | Type d'information à récupérer : Type des clés du tableau associatif | [TableauInfo](3075005.md) |
| **tiTypeElément** | Type d'information à récupérer : Type des éléments du tableau | [FileInfo](1000019547.md) [ListeInfo](1000019548.md) [PileInfo](1000019546.md) [TableauInfo](3075005.md) |
| **ttClé** | Tri d'un tableau associatif : Tableau associatif trié selon l'ordre des clés. Si cette constante n'est pas spécifié, le tableau associatif est trié selon l'ordre des valeurs. | [TableauTrie](3075007.md), [Trie](1000017364.md) |
| **ttColonne** | Manipule un tableau d'éléments simples à deux dimensions selon plusieurs colonnes | [TableauTrie](3075007.md), [Trie](1000017364.md) [TableauSupprimeDoublon](1000019422.md) |
| **ttCroissant** | Type de tri à effectuer : Tri croissant | [TableauTrie](3075007.md), [Trie](1000017364.md) |
| **ttDécroissant** | Type de tri à effectuer : Tri décroissant | [TableauTrie](3075007.md), [Trie](1000017364.md) |
| **ttFonction** | Manipule d'un tableau à une dimension en utilisant une procédure de tri | [TableauTrie](3075007.md), [Trie](1000017364.md) [TableauSupprimeDoublon](1000019422.md) |
| **ttMembre** | Manipule un tableau de classes ou de structures à une dimension | [TableauTrie](3075007.md), [Trie](1000017364.md) [TableauSupprimeDoublon](1000019422.md) |
