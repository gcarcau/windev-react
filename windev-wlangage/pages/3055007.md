# NavigateurFerme (Fonction)

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur)

Ferme la fenêtre en cours du navigateur et stoppe l'exécution du code en cours. Il est également possible de fermer un navigateur spécifique.
Cas particuliers :

- **Internet Explorer** : Pour des raisons de sécurité Internet, le navigateur demande une autorisation avant de se fermer. Si l'utilisateur répond "Non" à l'autorisation de fermeture demandée par le navigateur, le navigateur n'est pas fermé, mais le code en cours d'exécution est tout de même interrompu.
- **FireFox** : Pour des raisons de sécurité Internet, FireFox refuse la fermeture du navigateur lorsque celui-ci n'a pas été ouvert par la fonction [NavigateurOuvre](3055006.md).

## Exemple

```wlangage
NavigateurFerme()
```

## Syntaxe

#### Fermer le navigateur en cours

```wlangage
NavigateurFerme()
```

#### Fermer le navigateur désigné par un identifiant

```wlangage
NavigateurFerme(<Identifiant>)
```

`<Identifiant>` *Entier*
> Identifiant de la fenêtre du navigateur à fermer. Cet identifiant est renvoyé par la fonction [NavigateurOuvre](3055006.md).

## Remarques

### Arrêter le site WEBDEV
La fonction **NavigateurFerme** permet uniquement de fermer la fenêtre en cours du navigateur : cette fonction ne permet pas d'arrêter un site WEBDEV. Pour arrêter un site WEBDEV, utilisez la fonction [FinProgramme](3013033.md).

**Composante : WDJS.DLL**
