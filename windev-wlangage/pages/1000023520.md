# <Zone répétée>.ModifieLigne (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Modifie les valeurs des attributs dans une répétition d'un champ Zone répétée.
> _(WINDEV, WINDEV Mobile)_ Pour les champs Zone répétée sans attributs, il est conseillé de modifier directement la valeur des champs concernés. Pour plus de détails, consultez le paragraphe Modifier un champ Zone répétée sans attributs.

## Exemple

```wlangage
// Modification d'une ligne dans un champ Zone répétée
ZR_Zone1.ModifieLigne(Indice, NomProduit, CodeProduit)
```

```wlangage
// Modifie une valeur dans un champ Zone répétée en 12ème position
ZR_Zone1.ModifieLigne(12, Nom, Prénom, NumTel, NumFax)
```

## Syntaxe

```wlangage
<Champ Zone répétée>.ModifieLigne([<Indice> [, <Valeur 1> [, <Valeur N>]]])
```

`<Champ Zone répétée>` *Nom de champ*
> Nom du champ Zone répétée à manipuler.
`<Indice>` *Entier optionnel*
> Indice de la répétition à modifier.
>
> - Si ce paramètre n'est pas précisé, la modification sera effectuée sur l'élément en cours.
> - Si <Indice> est supérieur au nombre de répétitions, une erreur WLangage est affichée.
`<Valeur 1>` *Type de l'attribut associé (optionnel)*
> Valeur du 1er attribut de la ligne à modifier dans le champ Zone répétée spécifié.
> Les différentes valeurs doivent être indiquées dans l'ordre des attributs (fenêtre de description du champ Zone répétée).
> Si aucun de ces paramètres n'est spécifié, la fonction **<Zone répétée>.ModifieLigne** affecte chaîne vide ("") ou 0.
`<Valeur N>` *Type de l'attribut associé (optionnel)*
> Valeur du Nème attribut de la ligne à modifier dans le champ Zone répétée spécifié.
> Les différentes valeurs doivent être indiquées dans l'ordre des attributs (fenêtre de description du champ Zone répétée).
> Si aucun des ces paramètres n'est spécifié, la fonction **<Zone répétée>.ModifieLigne** affecte chaîne vide ("") ou 0.

## Remarques

### Conditions d'utilisation
La fonction **<Zone répétée>.ModifieLigne** peut être utilisée indifféremment sur :

- un champ Zone répétée fichier,
- un champ Zone répétée par programmation.

> _(WEBDEV - Code Navigateur)_ Cette fonction n'est pas disponible sur les champs Zone répétée linéaire. Cette fonction est disponible uniquement sur les champs Zone répétée en mode navigateur.

> _(WEBDEV - Code Serveur, PHP)_ Cette fonction est disponible pour les champs Zone répétée en mode Ajax, les champs Zone répétée en mode classique et les champs Zone répétée linéaire.

> _(PHP)_ La fonction <Zone répétée>.ModifieLigne peut être utilisée uniquement sur un champ Zone répétée mémoire.

### Caractéristiques de la répétition
Si une valeur correspond au résultat d'un calcul, mettez l'expression numérique entre parenthèses. Par exemple :

```wlangage
ZR_ZoneCalcul.ModifieLigne(5, (53+29), (83-21))
```

### Tri
Si la fonction **<Zone répétée>.ModifieLigne** modifie un attribut de tri du champ Zone répétée en cours, le tri sur cet attribut sera annulé.

### Modifier un champ Zone répétée sans attributs
Pour modifier un champ Zone répétée sans attributs, il est conseillé de modifier directement la valeur des champs concernés.
Par exemple :

```wlangage
// Modification de la valeur des champs
// du champ Zone répétée "ZR_Zone1" pour la répétition 23
ZR_Zone1[23].ChampNom = "Hobbes"
ZR_Zone1[23].ChampPrénom = "Samantha"
```
