# fTaille (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Renvoie la taille d'un fichier en octets.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Java, Code Utilisateur (MCU), PHP, Ajax)_ // Taille d'un fichier
ResTaille est un entier
ResTaille = fTaille("C:\MesRépertoires\Fichier.doc")

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Java, Code Utilisateur (MCU), PHP, Ajax)_ // Ouverture d'un fichier externe
MonFichierTxt est un FichierDisque
ResTaille est un entier
MonFichierTxt = fOuvre("C:\MesRépertoires\Fichier.txt", foLectureEcriture)

// Taille d'un fichier
ResTaille = fTaille(MonFichierTxt)

## Remarques

### Gestion des erreurs
La fonction **fTaille** génère une erreur dans les cas suivants :

- le fichier spécifié n'existe pas,
- le nom du fichier spécifié est invalide.

**Remarque** : la fonction **fTaille** ne fonctionne pas sur les fichiers cachés.
