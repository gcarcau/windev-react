# grDestinationWMF (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

**Avertissement**

 A partir de la version **14**, cette fonction est conservée par compatibilité. Il est conseillé d'utiliser la fonction [grDestinationEMF](3042017.md).

Définit un méta fichier comme destination d'un graphe. Ce méta fichier est créé lors de l'appel à la fonction [grDessine](3042026.md).
**Remarques** :

- Il est conseillé d'utiliser la fonction [grDestinationEMF](3042017.md).
- Cette fonction ne peut pas être utilisée avec les champs Graphe.
- Cette fonction ne peut pas être utilisée sous l'éditeur d'états.

## Exemple

```wlangage
// Définition du fichier "C:\Graphes\Graphe.WMF" comme destination du graphe "MonGraphe"
grDestinationWMF("MonGraphe", "C:\Graphes\Graphe.WMF")
```

## Syntaxe

```wlangage
grDestinationWMF(<Nom du graphe> , <Nom du méta fichier>)
```

`<Nom du graphe>` *Chaîne de caractères*
> Nom du graphe à manipuler, défini avec la fonction [grCrée](3042005.md).
`<Nom du méta fichier>` *Chaîne de caractères*
> Nom du méta fichier dans lequel le graphe doit être enregistré. Ce méta fichier est créé lors de l'appel à la fonction [grDessine](3042026.md).

## Remarques

### Créer et dessiner un graphe par programmation
Pour dessiner un graphe :

- créez le graphe (fonction [grCrée](3042005.md)),
- ajoutez les données (fonctions [grAjouteDonnée](3042023.md), [grBourseAjouteDonnée](3042009.md) et [grNuageAjouteDonnéeXY](3042032.md)),
- définissez la destination du graphe (fonctions [grDestinationBMP](3042018.md), [grDestinationChamp](3042020.md), [grDestinationEMF](3042017.md), [grDestinationFen](3042031.md) et **grDestinationWMF**),
- dessinez le graphe (fonction [grDessine](3042026.md)).

### Fichier WMF pour destination

- Lors du prochain appel à la fonction [grDessine](3042026.md), le graphe sera dessiné dans le méta fichier <Nom du méta fichier>.
- Ce fichier pourra être lu grâce à un outil reconnaissant le format WMF.
- Il est possible de définir la taille de ce méta fichier grâce à la fonction [grFenTaille](3042016.md).
- Il est conseillé de visualiser le graphe à l'écran avant de l'enregistrer dans un fichier.

### Différences entre les fonctions grDestinationWMF et grSauveWMF

- La fonction **grDestinationWMF** permet de définir la destination du prochain dessin du graphe. Lors de l'utilisation de la fonction [grDessine](3042026.md), le graphe sera dessiné dans le fichier spécifié et toutes les modifications effectuées depuis le dernier dessin du graphe seront prises en compte.
- La fonction [grSauveWMF](3042044.md) permet de sauvegarder le graphe directement dans un fichier au format WMF. L'image enregistrée correspond au graphe lors du dernier appel de la fonction [grDessine](3042026.md). Si des modifications ont été effectuées sur le graphe depuis l'appel de la fonction [grDessine](3042026.md), ces modifications ne seront pas prises en compte.
