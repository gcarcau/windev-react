# BTLERécupèreUnDescripteur (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Récupère le descripteur d'une caractéristique Bluetooth Low Energy correspondant à l'identifiant (UUID) spécifié.

## Exemple

```wlangage
MonPériph est un btlePériphérique
...
MonDesc est un btleDescripteur
MonDesc = BTLERécupèreUnDescripteur(MonPériph.Service[1].Caractéristique[1], "AD09")
SI ErreurDétectée ALORS
	Erreur("Le descripteur n'existe pas.")
	RETOUR
FIN
...
```

## Syntaxe

```wlangage
<Résultat> = BTLERécupèreUnDescripteur(<Caractéristique> , <Identifiant>)
```

`<Résultat>` *Variable de type btleDescripteur*
> Variable de type [btleDescripteur](1000022064.md) correspondant aux informations du descripteur demandé. Si aucun descripteur ne correspond à l'identifiant spécifié, la variable [ErreurDétectée](3087001.md) vaut Vrai.
`<Caractéristique>` *Variable de type btleCaractéristique*
> Nom de la variable de type [btleCaractéristique](1000022060.md) correspondant à la caractéristique manipulée.
`<Identifiant>` *Chaîne de caractères*
> Identifiant (UUID) du descripteur à récupérer.
