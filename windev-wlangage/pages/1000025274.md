# HTransactionEnCours (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Permet de savoir si une transaction est en cours.
> _(iPhone/iPad, Widget IOS, Mac Catalyst)_ La gestion des transactions est disponible uniquement pour les bases de données HFSQL Client/Serveur.

## Exemple

```wlangage
// Recherche si une transaction est en cours
// Base de données ISAM (HFSQL Classic)
bConnexionEnCours est un booléen = HTransactionEnCours()
```

```wlangage
// Recherche si une transaction avec MaConnexion est en cours
// Base de données Client/Serveur (HFSQL Client/Serveur)
MaConnexion est une Connexion
bConnexionEnCours est un booléen = HTransactionEnCours(MaConnexion)
```

## Syntaxe

```wlangage
<Résultat> = HTransactionEnCours([<Connexion>])
```

`<Résultat>` *Booléen*
> **Si une connexion est spécifiée** :
>
> - Vrai s'il existe une transaction sur la connexion spécifiée ou s'il existe une transaction globale (pour HFSQL Classic (ISAM) et toutes les connexions HFSQL Client/Serveur).
> - Faux s'il n'existe pas de transaction en cours sur la connexion spécifiée.
>
> **Si aucune connexion n'est spécifiée** :
>
> - Vrai s'il existe une transaction globale (pour HFSQL Classic (ISAM) et toutes les connexions HFSQL Client/Serveur).
> - Faux dans le cas contraire. Attention : il peut cependant exister des transactions en cours sur des connexions spécifiques.
`<Connexion>` *Chaîne de caractères optionnelle ou variable optionnelle de type Connexion*
> Connexion à utiliser. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
