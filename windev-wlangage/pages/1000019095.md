# Site (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

La propriété **Site** permet de connaître le site SaaS associé à :

- une variable de type [saasService](1000019096.md),
- une variable de type [saasTarification](1000019091.md).
- une variable de type [saasVisite](1000024560.md).
- une variable de type [adminWBConnexion](1410089344.md).
