# MiseEnPage (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **MiseEnPage** permet de définir les caractéristiques de mise en page d'un document. Cette propriété est utilisable sur :

- le champ Editeur de diagrammes. Pour plus de détails, consultez [MiseEnPage](1000023138.md).
- une variable de type [docFragment](1000022482.md).
- une variable de type [docParagraphe](1000022483.md).
- une variable de type [docNiveauNumérotation](1000022799.md).
- une variable de type [diagMiseEnPage](1410088610.md).
