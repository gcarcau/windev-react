# Fonctions de géolocalisation/ GPS

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Les fonctions suivantes permettent de manipuler des informations de géolocalisation et de contrôler un appareil GPS :

| [géoAzimut](1000019212.md) | Retourne la direction représentée par une position par rapport à une autre. |
| --- | --- |
| [géoDistance](1000019211.md) | Retourne la distance séparant deux positions. Cette distance est exprimée par défaut en mètres. |
| [géoLanceAppli](1000019954.md) | Lance l'application de cartographie native de l'appareil pour afficher :   - une position géographique donnée, - un itinéraire entre deux positions. |
| [géoRécupèreAdresse](1000019797.md) | Récupère une adresse ou une liste d'adresses correspondant à la description d'un lieu géographique. |
| [géoRécupèreZone](1000025776.md) | Récupère les coordonnées de la zone géographique correspondant à la description. |
| [géoSuiviActive](1000021583.md) | Active la gestion du suivi de position dans une application WINDEV Mobile. |
| [géoSuiviDésactive](1000021584.md) | Désactive le suivi des positions utilisateur pour une application WINDEV Mobile. |
| [géoSuiviEtat](1000021592.md) | Récupère l'état du système de suivi de position. |
| [géoSuiviProcédure](1000021585.md) | Définit la procédure WLangage appelée lorsque la position de l'utilisateur a changé. |
| [GPSArrêteDétection](1000019240.md) | Arrête la détection de position déclenchée par la fonction [GPSDétectePosition](1000019209.md). |
| [GPSDernièrePosition](1000019239.md) | Récupère les informations sur la dernière position connue de l'appareil. |
| [GPSDétectePosition](1000019209.md) | Demande à être notifié lorsque le périphérique arrive à proximité d'une position donnée. |
| [GPSEtat](1000019207.md) | Récupère l'état d'activation du fournisseur de géolocalisation ou demande à être notifié lors du changement d'état. |
| [GPSInfo](1000019208.md) | Renvoie les informations sur le fournisseur de localisation utilisé par l'application pour les fonctions de géolocalisation. |
| [GPSInitParamètre](1000019204.md) | Initialise les paramètres des fonctions WLangage de géolocalisation et recherche un fournisseur de localisation. |
| [GPSRécupèrePosition](1000019205.md) | Récupère les informations sur la position actuelle du périphérique. |
| [GPSSuitDéplacement](1000019206.md) | Demande à être notifié périodiquement de la position courante du périphérique. |
| [GPSTermine](1000019210.md) | Indique la fin de l'utilisation des fonctions de géolocalisation. |

Les types avancés suivants permettent de manipuler des informations de géolocalisation :

| [Adresse](1000019944.md) | Le type **Adresse** permet de manipuler l'adresse d'un lieu ou d'une personne. |
| --- | --- |
| [géoPosition](1000019191.md) | Le type **géoPosition** permet de manipuler des positions géographiques à l'aide des fonctions WLangage de géolocalisation. |

> _(iPhone/iPad, Widget IOS, Mac Catalyst)_ Fonctionnement sous iPhone/iPadAu premier lancement d'une fonction GPS, le système demande à l'utilisateur l'autorisation d'effectuer une géolocalisation. En cas de refus de l'utilisateur, toutes les fonctions GPS utilisées dans la suite de l'application échoueront (erreur fatale). Pour ré-autoriser l'utilisation du GPS pour cette application, il est nécessaire de modifier la configuration système de l'application.
