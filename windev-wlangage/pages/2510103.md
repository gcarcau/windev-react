# PoliceGras (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

La propriété **PoliceGras** permet de :

- Savoir si le texte affiché est en gras ou non.
- Modifier la graisse du texte.

## Exemple

```wlangage
// Mettre le texte affiché dans le champ "LIB_ChampLibellé" en gras
LIB_ChampLibellé.PoliceGras = Vrai
```

## Syntaxe

#### Savoir si le texte affiché dans un champ est en gras

```wlangage
<Résultat> = <Champ manipulé>.PoliceGras
```

`<Résultat>` *Booléen*
> - Vrai si le texte affiché est en gras,
> - Faux dans le cas contraire.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.

#### Modifier la mise en forme gras du texte affiché dans un champ

```wlangage
<Champ manipulé>.PoliceGras = <Gras/Non gras>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.
`<Gras/Non gras>` *Booléen*
> - Vrai si le texte affiché doit être en gras,
> - Faux dans le cas contraire.

## Remarques

### Limites
Dans un état, la propriété **PoliceGras** peut être utilisée uniquement sur :

- un champ Libellé.
- un champ Lien URL.
- un champ Calculé.
- un champ Prédéfini.

> _(WINDEV)_ Dans une fenêtre, la propriété PoliceGras ne peut pas être utilisée sur :un champ Spin,un champ Web Camera,un champ Conférence.Remarque : Cette propriété s'applique sur les champs "Liste image" en mode d'affichage "Liste classique" uniquement.

> _(WEBDEV - Code Serveur)_ Dans une page, la propriété PoliceGras peut être utilisée sur :un champ Libellé,un champ de saisie,un champ Bouton,un champ Interrupteur,un champ Sélecteur,un champ Liste,une colonne de table,une cellule de table (en lecture uniquement),un champ d'affichage formaté,un champ HTML,un champ Combo,un champ Lien,un champ Libellé HTML,un champ Réglette,un champ Chemin de navigation,un champ Arbre,un menu.

> _(PHP)_ Dans une page PHP, la propriété PoliceGras peut être utilisée sur :un champ Libellé,un champ de saisie,un champ Bouton,un champ Interrupteur,un champ Sélecteur,un champ Liste,une colonne de table,un champ d'affichage formaté,un champ HTML,un champ Combo,un champ Lien,un champ Libellé HTML,un champ Réglette,un champ Arbre,un menu.

> _(Java)_ En Java, la propriété PoliceGras s'applique uniquement aux éléments suivants :Champ Bouton.Champ Libellé.Champ Combo.Champ Arbre.Colonne de table.
