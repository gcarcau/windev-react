# Fonctions de gestion des graphes

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des graphes (syntaxe préfixée)](1000024173.md)).
> _(WEBDEV - Code Serveur, Linux)_ Utilisation des graphes en WEBDEV LinuxPour utiliser les graphes en WEBDEV Linux, il est nécessaire d'installer la librairie QT (Core et GUI), version 5 minimale. Sous Ubuntu, cette librairie peut être installée avec les commandes suivantes :

sudo apt-get install libqtcore5sudo apt-get install libqtgui5
