# Fonctions MongoDB (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

Les fonctions de gestion des bases MongoDB (syntaxe préfixée) sont les suivantes :

| [<Variable mongoBase>.CréeCollection](1000023612.md) | Crée une collection dans une base MongoDB en précisant des options de cette collection. |
| --- | --- |
| [<Variable mongoBase>.ExécuteCommande](1000023636.md) | Exécute une commande générique sur une base MongoDB. |
| [<Variable mongoBase>.Info](1000025396.md) | Renvoie des informations sur une base MongoDB. |
| [<Variable mongoBase>.SupprimeBase](1000025399.md) | Supprime une base MongoDB et toutes ses collections. |
| [<Variable mongoCollection>.Ajoute](1000025345.md) | Ajoute un ou plusieurs documents dans une collection d'une base MongoDB. |
| [<Variable mongoCollection>.Cherche](1000025356.md) | Cherche des documents dans une collection MongoDB. |
| [<Variable mongoCollection>.ExécuteCommande](1000023819.md) | Exécute une commande générique sur une collection MongoDB. |
| [<Variable mongoCollection>.ExécuteLotOpérations](1410089633.md) | Effectue un ensemble d'opérations d'écriture MongoDB en lot. Il est ainsi possible d'éviter des latences réseau qui pourraient subvenir en effectuant les opérations séquentiellement. |
| [<Variable mongoCollection>.ModifieTout](1000025397.md) | Modifie des documents dans une collection d'une base MongoDB. |
| [<Variable mongoCollection>.ModifieUn](1000025398.md) | Modifie un document dans une collection d'une base MongoDB. |
| [<Variable mongoCollection>.SupprimeCollection](1000025400.md) | Supprime une collection d'une base MongoDB. |
| [<Variable mongoCollection>.SupprimeTout](1000025401.md) | Supprime tous les documents (correspondant au filtre spécifié) d'une collection d'une base MongoDB. |
| [<Variable mongoCollection>.SupprimeUn](1000025402.md) | Supprime un document dans une collection d'une base MongoDB. |
| [<Variable mongoGridFS>.EnvoieFichier](1000025357.md) | Copie un fichier du poste local vers un système de fichiers MongoDB (GridFS). |
| [<Variable mongoGridFS>.ListeFichier](1000025358.md) | Récupère la liste des fichiers MongoDB présents dans le système de fichiers MongoDB (gridFS). |
| [<Variable mongoGridFS>.RécupèreFichier](1000025391.md) | Récupère sur le poste local un fichier identifié par son nom et présent dans un système de fichiers MongoDB. |
| [<Variable mongoGridFS>.RécupèreFichierParID](1000025392.md) | Récupère sur le poste local un fichier (identifié par son identifiant) présent dans un système de fichiers MongoDB. |
| [<Variable mongoGridFS>.RécupèreInfoFichier](1000025393.md) | Permet de récupérer les informations concernant un fichier MongoDB (gridFS). |
| [<Variable mongoGridFS>.SupprimeFichier](1000025394.md) | Supprime un fichier identifié par son nom dans un système de fichiers MongoDB. |
| [<Variable mongoGridFS>.SupprimeFichierParID](1000025395.md) | Supprime un fichier identifié par son identifiant dans un système de fichiers MongoDB. |
