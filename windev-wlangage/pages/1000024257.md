# <Table>.IndiceColonne (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Renvoie l'indice d'une colonne dans un champ Table ou Table hiérarchique.

## Exemple

> _(WINDEV, Etats et Requêtes, Java, Code Utilisateur (MCU))_ // Indice de la colonne "Réf" du champ Table "TABLE_Produit"
// L'ordre d'affichage est pris en compte
ResIndiceColonne = TABLE_Produit.IndiceColonne("Réf", ticAffichage)

> _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur, Ajax)_ // Indice de la colonne "Réf" du champ Table "TABLE_Produit"
// L'ordre d'affichage est pris en compte
ResIndiceColonne = TABLE_Produit.IndiceColonne("Réf")

## Syntaxe

```wlangage
<Résultat> = <Champ Table>.IndiceColonne(<Colonne> , <Ordre>)
```

`<Résultat>` *Entier*
> Indice de la colonne :
>
> - La première colonne possède l'indice 1.
> - Les colonnes invisibles sont également listées.
`<Champ Table>` *Nom de champ*
> Nom du champ Table ou Table hiérarchique à manipuler.
`<Colonne>` *Chaîne de caractères*
> Nom de la colonne à manipuler.
`<Ordre>` *Constante de type Entier*
> Indique l'ordre des colonnes considérées :
>
> | *ticAffichage* | Ordre d'affichage des colonnes en exécution. |
> | --- | --- |
> | *ticCréation* | Ordre de création des colonnes lors de la description du champ Table. |
>
>
>
> > _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur, PHP)_ Ce paramètre est optionnel. Par défaut, la constante utilisée par défaut est ticCréation : l'ordre de création des colonnes est pris en compte.

## Remarques

### Conditions d'utilisation
La fonction **<Table>.IndiceColonne** peut être utilisée indifféremment sur :

- un champ Table ou Table hiérarchique fichier.
- un champ Table ou Table hiérarchique par programmation.
- un champ monosélection ou multisélection.
   **Rappel** : La multisélection n'est pas disponible sur les champs Table en mode "Serveur".
- un champ Table en mode "Serveur + AJAX", un champ Table en mode "Serveur" et un champ Table hiérarchique.
- un champ Table en mode "Navigateur".
   Le champ Table hiérarchique n'est pas disponible.
