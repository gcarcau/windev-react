# MarqueurImage (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le type **MarqueurImage** permet personnaliser l'image associée à un marqueur ou à un cluster de marqueurs affiché dans le champ Carte. Les caractéristiques de cette image peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
MonImg est une MarqueurImage
MonImg.Taille = 60
MonImg.CouleurFond = VertClair
MonImg.Texte = 100

MonMarqueur est un Marqueur
MonMarqueur.Position = MaPosition
MonMarqueur.Image = MonImg

CarteAjouteMarqueur(CARTE_Carte1, MonMarqueur)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type MarqueurImage
Les propriétés suivantes peuvent être utilisées pour manipuler l'image d'un marqueur :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Couleur | [Couleur](1000019661.md), entier, constante | Couleur du contour de la forme et du libellé du marqueur. Cette couleur peut correspondre à :  - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)), - [une couleur prédéfinie du WLangage](3010002.md), - une variable [Couleur](1000019661.md).  Couleur par défaut : noir. |
| CouleurFond | [Couleur](1000019661.md), entier, constante | Contours du cercle. Cette couleur peut correspondre à :  - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)), - [une couleur prédéfinie du WLangage](3010002.md), - une variable [Couleur](1000019661.md).  Remarque : Pour modifier l'opacité du remplissage, il est possible d'écrire :   ```wlangage MonMarqueurImage.CouleurFond.Opacité = 50 ```   Couleur par défaut : noir. |
| Forme | Constante de type Entier | Forme à représenter parmi les constantes suivantes :   - *formeCarré* : Forme carrée. - *formeCarréArrondi* : Forme carrée à coin arrondi. - *formeRond* (valeur par défaut) : Forme ronde. |
| Taille | Entier | Taille de la forme (rayon pour un cercle, côté pour un carré) exprimée en pixels. |
| Texte | Chaîne de caractères | Libellé à afficher dans la forme. |
