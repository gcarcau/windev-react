# Dessinez des graphes dans un champ Image

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

## Présentation

WINDEV, WINDEV Mobile et WEBDEV mettent à votre disposition des fonctions qui permettent de créer et de manipuler des graphes.
Il est possible de réaliser plusieurs types de graphes : Secteurs, Histogramme, Courbe, Nuage de points, ... Pour chacun des types de graphes, des options d'affichage permettent d'avoir des rendus différents.

Ces graphes peuvent être dessinés :

- dans un fichier image,
- dans un champ Image.
- dans une fenêtre,
- dans un champ Image ou Image cliquable (de type image générée).
- dans une variable de type [Image](1000019650.md).

## Comment dessiner ?

Pour dessiner un graphe dans un champ Image, quelques règles doivent être suivies :

1. Créez le graphe avec la fonction [grCrée](3042005.md).
2. Initialisez les données du graphe, avec les fonctions [grAjouteDonnée](3042023.md) et [grNuageAjouteDonnéeXY](3042032.md).
3. Choisissez un champ Image comme destination du graphe (fonction [grDestinationChamp](3042020.md))
4. Dessinez le graphe avec la fonction [grDessine](3042026.md).

Exemple :

```wlangage
grCrée("Graphe1",grSecteur)grAjouteDonnée("Graphe1",1,50)grAjouteDonnée("Graphe1",1,90)grAjouteDonnée("Graphe1",1,500)grDestinationChamp("Graphe1", IMG_Image1)grDessine("Graphe1")
```
