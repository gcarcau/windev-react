# PanneauChargeConfiguration (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Restaure la configuration des champs Panneau dockable d'une fenêtre.

## Exemple

```wlangage
// Sauve la configuration courante
sConf est une chaîne = PanneauSauveConfiguration()

// Restaure la configuration sauvée dans sConf
PanneauChargeConfiguration(sConf)
SI ErreurDétectée ALORS ToastAffiche(ErreurInfo())
```

## Syntaxe

```wlangage
<Résultat> = PanneauChargeConfiguration(<Configuration>)
```

`<Résultat>` *Booléen*
> - Vrai si la configuration a été chargée.
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Configuration>` *Chaîne de caractères*
> Configuration à restaurer. Cette configuration est le résultat de la fonction [PanneauSauveConfiguration](1000023994.md).
> Attention : Si le format de ce paramètre est invalide ou ne peut pas être appliqué au champ Panneau dockable, <Résultat> vaut Faux.

**Classification Métier / UI : Code UI**

**Composante : wd300obj.dll**
