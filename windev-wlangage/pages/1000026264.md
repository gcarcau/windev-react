# Fonctions de gestion des champs d'affichage HTML

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Les fonctions suivantes permettent de gérer le champ d'affichage HTML :

| [HTMLActiveDébogueur](1410087849.md) | Active le débogueur HTML/Javascript sur les champs HTML basé sur CEF (Chromium) : Champ d'affichage HTML ou champ Editeur HTML. |
| --- | --- |
| [HTMLDepuisEmail](1410087263.md) | Importe le contenu HTML d'un email et ses images dans un champ d'affichage HTML. Les images contenues dans l'email sont également affichées dans le champ. |
| [HTMLExécuteProcédureNavigateur](1000025920.md) | Exécute une procédure WLangage navigateur WEBDEV dans un champ d'affichage HTML avec une page créée par WEBDEV. |
| [HTMLExécuteTraitementChamp](1000025969.md) | Lance l'exécution d'un événement WLangage associé à un champ présent dans une page HTML affichée par une champ d'affichage HTML. |
| [HTMLNavigue](3025042.md) | Lance une opération de navigation dans un champ d'affichage HTML. |
| [HTMLSurErreurJS](1000026259.md) | Indique la procédure à appeler en cas d'erreur dans l'exécution du Javascript dans un champ d'affichage HTML. |
| [HTMLValeurChamp](1000025968.md) | Permet de connaître ou modifier un champ d'un formulaire HTML présent dans un champ d'affichage HTML. |
| [HTMLValideFormulaire](1000025970.md) | Valide le formulaire d'une page HTML affichée dans un champ d'affichage HTML. |
