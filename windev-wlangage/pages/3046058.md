# Etape 4 : Lancement de l'impression

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

## Présentation

Pour lancer l'impression effective, il suffit d'utiliser la fonction [iFinImprime](3046053.md).

## Impression par infrarouge

> _(WINDEV, WEBDEV - Code Serveur, Windows)_ Si l'ordinateur et l'imprimante associée sont équipés d'un port Infrarouge, l'impression est réalisée lors de l'appel de la fonction iFinImprime.Rappel : L'imprimante utilisée a été préalablement sélectionnée grâce à la fonction iDestination, iParamètre ou iConfigure.

## Impression grâce à un fichier PCL

> _(WINDEV, WEBDEV - Code Serveur, Windows)_ WINDEV et WEBDEV permettent aussi d'imprimer par l'intermédiaire d'un fichier PCL (Printer Control Language).Pour réaliser ce type d'impression :Spécifiez le fichier PCL à créer (fonction iDestination).Par exemple :

iDestination(iPCL, "C:\MesDocuments\MonFichier.PCL")

Copiez le fichier PCL du poste PC vers l'imprimante à utiliser. Par exemple :à l'aide de la fonction fCopieFichier.en saisissant une ligne de commande (dans la boîte de dialogue "Démarrer .. Exécuter" de Windows).

Copy "<FichierPCL>" "<ImprimanteUtilisée>"

Remarque : A partir de la fenêtre de configuration d'une imprimante (fonction iConfigure ou iParamètre), l'utilisateur peut également créer un fichier PCL.
