# Protection (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Protection** permet de connaître et de modifier les caractéristiques de protection d'un document PDF.
Cette propriété est utilisable avec :

- une variable de type [pdfParamètre](1410087857.md).
- une variable de type [pdfDocument](1000024909.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
