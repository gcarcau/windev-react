# DocVersImage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Exporte une page d'un document de type Traitement de texte sous forme d'une image.

## Exemple

```wlangage
MonDoc est un Document <- TT_MonDocument
d est une Image = DocVersImage(MonDoc, 1)
dSauveImageJPEG(d, "test")
LanceAppliAssociée("test.jpg")
```

## Syntaxe

```wlangage
<Résultat> = DocVersImage(<Document> , <Page>)
```

`<Résultat>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) correspondant à la page du document Traitement de texte.
`<Document>` *Variable de type Document ou nom de champ*
> Document à manipuler. Ce document peut correspondre à :
>
> - une variable de type [Document](1000022461.md).
> - un champ Traitement de texte.
`<Page>` *Entier*
> Numéro de la page à exporter sous forme d'une image.

**Composante : wd300mdl.dll**
