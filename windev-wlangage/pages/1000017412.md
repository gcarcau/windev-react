# TableSauvePositionEtSélection (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Sauve :

- la position de l'ascenseur d'un champ Table ou d'un champ Table hiérarchique,
- le ou les éléments sélectionnés dans le champ.

Ces éléments peuvent être restaurés par la fonction [TableRestaurePositionEtSélection](1000017413.md).

## Exemple

```wlangage
SauveTable est une chaîne
SauveTable = TableSauvePositionEtSélection(TABLE_Table1)
TableAffiche(TABLE_Table1, taInit)
TableRestaurePositionEtSélection(TABLE_Table1, SauveTable)
```

## Syntaxe

```wlangage
<Résultat> = TableSauvePositionEtSélection(<Champ Table>)
```

`<Résultat>` *Chaîne de caractères*
> - Informations qui seront transmises à la fonction [TableRestaurePositionEtSélection](1000017413.md).
> - Chaîne vide ("") si le champ Table est vide.
`<Champ Table>` *Nom de champ*
> Nom du champ Table ou Table hiérarchique à manipuler.

## Remarques

### Conditions d'utilisation
La fonction **TableSauvePositionEtSélection** peut être utilisée indifféremment sur :

- un champ Table ou Table hiérarchique fichier.
- un champ Table ou Table hiérarchique par programmation.
- un champ monosélection ou multisélection.

### Equivalence
Les fonctions **TableSauvePositionEtSélection** et [TableRestaurePositionEtSélection](1000017413.md) sont équivalentes à l'option "Mémoriser la position et la sélection" disponible dans l'onglet "Détail" de la description du champ Table.

### Limitation
La fonction **TableSauvePositionEtSélection** ne fonctionne pas sur les champs Table fichier à rebond (c'est-à-dire sans ascenseur proportionnel).
