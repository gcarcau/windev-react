# <Variable File>.Info (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

Récupère les caractéristiques d'une file : types des éléments et nombre d'éléments.
Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.

## Exemple

```wlangage
// File dont les éléments sont des chaînes
MaFile est une File de chaînes
// Récupère la définition du type des éléments
MaDéfinition est un Définition
MaDéfinition = MaFile.Info(tiDéfinitionElément)
```

## Syntaxe

```wlangage
<Résultat> = <File>.Info(<Information>)
```

`<Résultat>` *Variant*
> Information demandée.
`<File>` *Variable de type File*
> Nom de la variable de type [File](1514021.md) à manipuler.
`<Information>` *Constante de type Entier*
> Information à récupérer :
>
> | *tiDéfinitionElément* | <Résultat est une variable de type [Définition](1000019540.md) et contient la définition du type des éléments. _(WEBDEV - Code Navigateur, Android, Widget Android, Java)_ Cette constante n'est pas disponible. |
> | --- | --- |
> | *tiNombreTotal* | <Résultat est une variable de type Entier et contient le nombre total d'éléments dans la file. |
> | *tiTypeElément* | <Résultat est une variable de type Entier et contient le type des éléments de la file. Ce résultat est compatible avec la fonction [TypeVar](3013056.md). _(WEBDEV - Code Navigateur)_ Cette constante n'est pas disponible. |

**Composante : wd300vm.dll**
