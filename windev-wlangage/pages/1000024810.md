# Procédure WLangage appelée par la fonction inAppVérifieAbonnement

> **Disponible :** **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Procédure (également appelée "Callback") appelée par la fonction [inAppVerifieAbonnement](1000022719.md) si un des abonnements a été renouvelé. Cette procédure peut être une procédure locale, globale ou interne.

## Exemple

```wlangage
// Code d'initialisation du projet
inAppVérifieAbonnement(VérifAbonnement)
```

```wlangage
PROCÉDURE VérifAbonnement(bSuccès est un booléen, Produit est un inAppProduit)
SI PAS bSuccès ALORS
	ToastAffiche(ErreurInfo())
	RETOUR
SINON
	// Appel de la fonction inAppListeAchat
	// pour vérifier la date de début et fin de l'abonnement
FIN
```

## Syntaxe

```wlangage
inAppVérifieAbonnement_Callback(<Succès> , <Produit>)
```

`<Succès>` *Booléen*
> - Vrai si l'abonnement a été renouvelé,
> - Faux dans le cas contraire.
`<Produit>` *Variable de type inAppProduit*
> Variable de type [inAppProduit](1000020868.md) correspondant au produit pour lequel le renouvellement de l'abonnement est vérifié.
