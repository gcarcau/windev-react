# NbEtiquette (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

La propriété **NbEtiquette** permet de :

- Connaître le nombre d'étiquettes imprimées sur la largeur d'une page.
- Modifier le nombre d'étiquettes imprimées sur la largeur d'une page.

**Remarque** : Le nombre d'étiquettes imprimées sur la largeur d'une page peut être connu et/ou modifié sous l'éditeur d'états : sous le volet "Modification", dans le groupe "Etat", sélectionnez "Format et étiquettes".
[image: Format des étiquettes]

## Exemple

```wlangage
// Augmente le nombre d'étiquettes à imprimer dans la largeur de la page
ETAT_EtiqClient.NbEtiquette = ETAT_EtiqClient.NbEtiquette + 2
// Est équivalent à : ETAT_EtiqClient.NbEtiquette += 2
```

## Syntaxe

#### Connaître le nombre d'étiquettes imprimées sur la largeur d'une page

```wlangage
<Résultat> = <Etat manipulé>.NbEtiquette
```

`<Résultat>` *Entier*
> Nombre d'étiquettes à imprimer sur la largeur de la page.
`<Etat manipulé>` *Nom d'état*
> Nom de l'état de type "Étiquette" à manipuler.

#### Modifier le nombre d'étiquettes imprimées sur la largeur d'une page

```wlangage
<Etat manipulé>.NbEtiquette = <Nouveau nombre>
```

`<Etat manipulé>` *Nom d'état*
> Nom de l'état de type "Étiquette" à manipuler.
`<Nouveau nombre>` *Entier*
> Nouveau nombre d'étiquettes à imprimer sur la largeur de la page.

## Remarques

### Modification du nombre d'étiquettes
Lors de la modification du nombre d'étiquettes par programmation, les étiquettes ne sont pas automatiquement re-dimensionnées. Il est donc conseillé de vérifier la taille des étiquettes.

### Modification des dimensions des étiquettes

- Pour connaître ou modifier la hauteur des étiquettes d'un état de type "Étiquette", utilisez la propriété [HauteurEtiquette](2511069.md).
- Pour connaître ou modifier la largeur des étiquettes d'un état de type "Étiquette", utilisez la propriété [LargeurEtiquette](2511055.md).
- Pour connaître ou modifier l'espacement horizontal entre les étiquettes d'un état de type "Étiquette", utilisez la propriété [EspaceH](2511067.md).
- Pour connaître ou modifier l'espacement vertical entre les étiquettes d'un état de type "Étiquette", utilisez la propriété [EspaceV](2511065.md).

### Limite
La propriété **NbEtiquette** s'applique uniquement aux états de type "Étiquette".
