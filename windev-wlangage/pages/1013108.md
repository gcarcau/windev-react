# Propriétés associées au champ HTML

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes) · **WEBDEV** (Windows, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Dans une page ou un état, le champ HTML peut être manipulé par les propriétés du WLangage.
