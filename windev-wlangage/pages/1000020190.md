# Fonctions de gestion de la synthèse vocale

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Les fonctions de gestion de la synthèse vocale sont les suivantes :

| [SynthèseVocaleArrête](1000020174.md) | Stoppe toutes les lectures en cours du moteur de synthèse vocale. |
| --- | --- |
| [SynthèseVocaleEnCours](1000020173.md) | Permet de savoir si une lecture est en cours par le moteur de synthèse vocale. |
| [SynthèseVocaleInitialise](1000020171.md) | Initialise les paramètres de la synthèse vocale pour l'application en cours. |
| [SynthèseVocaleListeVoix](1000025921.md) | Renvoie la liste des voix disponibles sur l'appareil pour le moteur de synthèse vocale. |
| [SynthèseVocaleLitFichier](1000020172.md) | Lit le contenu du fichier spécifié en utilisant le moteur de synthèse vocale de l'appareil. |
| [SynthèseVocaleLitTexte](1000019805.md) | Lit le texte spécifié en utilisant le moteur de synthèse vocale de l'appareil. |
