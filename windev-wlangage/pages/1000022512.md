# BandeauArrêteDéfilement (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

Arrête le défilement automatique sur un champ Bandeau défilant.

## Exemple

```wlangage
// Stoppe le défilement (laisse le bandeau courant)BandeauArrêteDéfilement(BAN_Bannière)
```

## Syntaxe

```wlangage
BandeauArrêteDéfilement(<Champ Bandeau défilant>)
```

`<Champ Bandeau défilant>` *Nom de champ*
> Nom du champ Bandeau défilant à manipuler.

**Classification Métier / UI : Code UI**

**Composante : wd300page.dll**
