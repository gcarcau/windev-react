# fFerme (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Ferme un fichier externe.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Java, Code Utilisateur (MCU), PHP, Ajax)_ // Ouverture d'un fichier externe
IDFichier est un entier
ResFerme est un entier
IDFichier = fOuvre("C:\MesRépertoires\Fichier.txt", foLectureEcriture)
SI IDFichier <> -1 ALORS
 ...
 // Fermeture du fichier externe
 ResFerme = fFerme(IDFichier)
FIN

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Java, Code Utilisateur (MCU), Ajax)_ ResFerme est un entier
// Ouverture d'un fichier externe
MonFichierTxt est un FichierDisque
fOuvre(MonFichierTxt, "C:\MesRépertoires\Fichier.txt", foLectureEcriture)
SI PAS ErreurDétectée ALORS
 ...
 // Fermeture du fichier externe
 ResFerme = fFerme(MonFichierTxt)
FIN

## Syntaxe

```wlangage
<Résultat> = fFerme(<Fichier manipulé>)
```

`<Résultat>` *Entier*
> - 0 si le fichier externe est fermé,
> - -1 en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*. La fonction **fFerme** génère une erreur si le fichier n'est pas ouvert.
`<Fichier manipulé>` *Entier ou variable de type FichierDisque*
> - Identifiant du fichier à manipuler, défini avec la fonction [fOuvre](3036036.md) ou [fCrée](3036017.md).
> - Nom de la variable de type [FichierDisque](1410088883.md) initialisée avec la fonction [fOuvre](3036036.md) ou [fCrée](3036017.md).
>    Non disponible.
>
>
> > _(PHP)_ Ce paramètre doit être de type variant.

## Remarques

### Fermeture d'un fichier ouvert plusieurs fois
Il est possible d'ouvrir un même fichier plusieurs fois en même temps. Chaque version du fichier doit être fermée individuellement par son propre identifiant.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ Fermeture d'un fichier bloquéUn fichier bloqué sera automatiquement débloqué lors de sa fermeture.Rappel : La fonction fBloque permet de bloquer un fichier externe. La fonction fDébloque permet de débloquer un fichier externe.
