# Table,Select,+ (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Sélectionne un élément dans un champ Table.

## Exemple

```wlangage
// En CAPPELWD("Table,Select,+,TableProd,10");
```

```wlangage
// En PascalAPPELWD('Table,Select,+,TableProd,10');
```

```wlangage
// En VBcall APPELWD("Table,Select,+,TableProd,10")
```

## Syntaxe

```wlangage
Table,Select,+(<Champ Table> , <Indice>)
```

`<Champ Table>` *Nom de champ*
> Nom du champ Table à manipuler.
`<Indice>` *Chaîne de caractères*
> Numéro de la ligne à sélectionner. Si ce paramètre est inférieur à 0, le champ Table fichier "remonte" pour visualiser l'enregistrement demandé. Si l'indice est supérieur au nombre de lignes affichées, le champ Table "descend" pour visualiser l'enregistrement demandé. Il est cependant conseillé d'utiliser [Table,Affiche](75130308.md) précédé du positionnement dans le fichier.

## Remarques

- Dans le cas d'un champ Table par programmation, l'indice est relatif à la totalité du champ Table.
- Dans le cas d'un champ Table fichier, l'indice est relatif aux seuls éléments visualisés.
