# EtatsUnis.VérifieSSN (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un numéro SSN (numéro d'identification personnel aux Etats-Unis).

## Exemple

```wlangage
// Test d'une variableMonNuméroSSN est une chaîne = "721074426"EtatsUnis.VérifieSSN(MonNuméroSSN)  // renvoie Vrai // Test d'un champSAI_NuméroSSN = "ABC"EtatsUnis.VérifieSSN(SAI_NuméroSSN) // renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = EtatsUnis.VérifieSSN(<Numéro à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un numéro SSN valide.
> - Faux dans le cas contraire.
`<Numéro à vérifier>` *Nom de champ ou variable de type chaîne*
> Numéro SSN à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.

**Composante : wd300std.dll**
