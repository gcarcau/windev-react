# PDFRécupèreSignature (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android)

Récupère la signature d'un document PDF sous forme d'un buffer. Le certificat correspondant pourra être extrait via la fonction [CertificatExtrait](1000019300.md).
Nouveauté 2025

> _(Android)_ Cette fonction est désormais disponible pour les applications Android.

> _(Widget Android)_ Cette fonction est désormais disponible en mode Widget Android.

## Exemple

```wlangage
MonPDF est un pdfDocument = PDFOuvre("test.pdf")

// Nombre de signatures dans le fichier PDF
nNbSignature est un entier = PDFNbSignature(MonPDF)

// Récupération des informations sur les signatures
POUR i = 1 _À_ nNbSignature
	// Récupération de la signature
	bufSignature est un Buffer = PDFRécupèreSignature(MonPDF, i)

	// Récupération de la date de la signature
	dhDateSignature est une DateHeure = PDFRécupèreDateSignature(MonPDF, i)

	// Récupération du certificat
	Certif est un Certificat = CertificatExtrait(bufSignature)
FIN
```

## Syntaxe

```wlangage
<Résultat> = PDFRécupèreSignature(<Document PDF> , <Indice>)
```

`<Résultat>` *Buffer*
> Signature du document.
`<Document PDF>` *Nom de champ ou variable de type pdfDocument*
> Document PDF à analyser. Ce document peut correspondre :
>
> - à une variable de type [pdfDocument](1000024909.md).
> - à un champ Lecteur PDF.
`<Indice>` *Entier*
> Indice de la signature dans le document (le nombre de signatures est connu par la fonction [PDFNbSignature](1410088119.md)).

**Composante : wd300wdpdf.dll**
