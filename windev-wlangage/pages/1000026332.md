# <Variable zipArchive>.Existe (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Permet de savoir si une archive existe. Une archive existe si elle a été ouverte par la fonction [<Variable zipArchive>.Ouvre](1000019097.md) ou créée par la fonction [<Variable zipArchive>.Crée](1000019160.md).
Nouveauté 2025

> _(WINDEV, WEBDEV - Code Serveur, Windows, Linux, iPhone/iPad)_ Le format gzip (extension .gz) est désormais géré.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ MonArchive est une zipArchive
// Création de l'archive
ResCréation = MonArchive.Crée("C:\Temp\Archive.zip")
...
// Test de l'existence de l'archive
SI MonArchive.Existe() = Vrai ALORS
 // Ajout d'un fichier dans une archive
 ResAjoutFichier = MonArchive.AjouteFichier(...
 "C:\MonRépertoire\MesFichiers\Fichier.pdf", zipDisque)
 // Affichage du message d'erreur si le fichier n'a pas été ajouté
 SI ResAjoutFichier <> 0 ALORS
 Erreur(zipMsgErreur(ResAjoutFichier))
 FIN
FIN

## Syntaxe

```wlangage
<Résultat> = <Archive>.Existe()
```

`<Résultat>` *Booléen*
> - Vrai si l'archive existe,
> - Faux dans le cas contraire.
`<Archive>` *Variable de type zipArchive*
> Nom d'une variable de type [zipArchive](1000018679.md) correspondant à l'archive à manipuler.

**Classification Métier / UI : Code métier**

**Composante : wd300zip.dll**
