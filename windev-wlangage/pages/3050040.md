# MatRéelMultiplie (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Multiplie chaque élément d'une matrice par une valeur. Cette multiplication est réalisée directement dans la matrice spécifiée.

## Exemple

```wlangage
// Multiplication des éléments de la matrice par la valeur 3
MatRéelMultiplie("MaMatrice", 3)
```

## Syntaxe

```wlangage
MatRéelMultiplie(<Matrice> , <Valeur>)
```

`<Matrice>` *Chaîne de caractères*
> Nom de la matrice à manipuler, défini avec la fonction [MatCrée](3050058.md).
`<Valeur>` *Réel*
> Valeur utilisée pour la multiplication.

## Remarques

### Diviser tous les éléments d'une matrice
Pour diviser tous les éléments d'une matrice par une valeur donnée, multipliez la matrice par : 1/<Valeur>.

### Existence de la matrice
L'existence de la matrice n'est pas vérifiée. Pour vérifier l'existence d'une matrice, utilisez la fonction [MatExiste](3050076.md).

### Gestion des erreurs
**Attention** : La fonction **MatRéelMultiplie** ne retourne pas de code d'erreur. Pour savoir si des erreurs ont été générées par la multiplication, utilisez la fonction [MatErreur](3050044.md). Le libellé de l'erreur peut être connu grâce à la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
