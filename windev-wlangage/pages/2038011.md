# GDS : Options du ruban

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Menu GDS

Les opérations sur le GDS peuvent être effectuées directement depuis le volet GDS de WINDEV, WEBDEV ou WINDEV Mobile.

Ce volet propose différentes zones :

- "Ajouter le projet".
- "Base GDS".
- "Tous les éléments".
- "Elément en cours".
- "Projet".
- "Autres actions".

Voyons en détail les options de ces différentes zones.

### Zone "Ajouter le projet"
Cette zone est présente uniquement si le projet en cours n'a pas été intégré dans le GDS ou dans Git.
Cette zone permet d'ajouter le projet en cours :

- Dans le GDS. Pour plus de détails, consultez [Ajouter un projet dans la base de sources](2038002.md).
- Dans Git. Pour plus de détails, consultez [Partagez vos projets via Git](9500230.md).

### Zone "Base GDS"
L'option "Gérer" permet de :

- Lancer l'administrateur du Gestionnaire de Sources. Pour plus de détails, consultez [Administrateur du GDS](2038008.md).
- Créer une base de sources. Pour plus de détails, consultez [Créer une base de sources](2038005.md).
- Définir une politique de réintégration. Pour plus de détails, consultez [GDS : Politique de réintégration](2038024.md).

### Zone "Tous les éléments"
Cette zone permet de gérer tous les éléments du projet.
Les options disponibles sont les suivantes :

- **Tout récupérer** : Permet de récupérer toutes les nouvelles versions des éléments du projet qui sont présents dans la base de sources. Les éléments qui sont actuellement extraits par l'utilisateur ne sont pas proposés. Pour plus de détails, consultez [GDS : Récupérer tout](2038033.md).
- **Tout réintégrer** : Permet de réintégrer dans la base de sources du GDS tous les éléments du projet en cours qui ont été extraits. Il est possible de garder extraits certains éléments. Pour plus de détails, consultez [GDS : Réintégrer tout](2038033.md).
- **Etat des éléments** : Permet de connaître et de rechercher l'état des éléments du projet :
  - Connaître l'état des éléments : Affiche la liste des éléments du projet, avec pour chaque élément la date de la dernière extraction et son auteur.
  - Rafraîchir l'état des éléments : Permet de mettre à jour la liste des éléments du projet et l'état de chaque élément.
  - Nouveauté 2025
    Rechercher des extractions : Affiche la fenêtre de recherche des éléments extraits. Cette fenêtre permet de rechercher les éléments extraits selon plusieurs filtres. Il est possible si nécessaire de réintégrer directement un élément depuis cette fenêtre.

### Zone "Elément en cours"
Cette zone permet de gérer l'élément en cours sous l'éditeur.
Les options disponibles sont les suivantes :

- **Extraire** : Permet d'extraire de la base de sources le fichier correspondant à l'élément en cours. La dernière version de l'élément est recopié sur le poste local. Plusieurs modes d'extraction sont disponibles. Pour plus de détails, consultez [Extraction d'un élément](2038006.md).
- **Réintégrer** : Permet de réintégrer dans la base de sources le fichier correspondant à l'élément en cours. L'élément est recopié dans la base de sources du GDS. Il est mis à la disposition des autres utilisateurs du GDS. Pour plus de détails, consultez [Réintégration d'un élément](2038007.md).
- **Annuler l'extraction** : Permet d'annuler la dernière extraction. Les modifications faites sont annulées, et le fichier repasse en mode "Lecture seule".
- **Récupérer la dernière version** : Permet d'obtenir la dernière version de l'élément en cours sous l'éditeur. Cette dernière version est celle présente dans la base de source du GDS.
- **Comparer** :
  - **Voir mes modifications depuis l'extraction** : Permet de voir les modifications réalisées sur l'élément en cours depuis son extraction.
  - **Comparer avec la version de la base** : Compare l'élément en cours (disponible en local) avec la version présente dans la base de sources du GDS. Cette comparaison peut être faite même si l'élément n'a pas été extrait. Permet par exemple de vérifier les modifications effectuées avant de récupérer l'élément.
- **Ajouter** : Permet d'ajouter l'élément actuellement présent dans l'éditeur dans la base de sources du GDS. Si cette option est utilisée depuis l'éditeur d'analyses, c'est l'analyse qui est ajoutée dans la base de sources. Pour plus de détails, consultez [Ajout d'un élément dans la base de sources](2038009.md).
- **Propriétés** : Permet d'afficher les propriétés de l'élément en cours (les différentes extractions, les partages, etc.).
- **Historique** : Permet d'obtenir la liste des modifications réalisées sur l'élément et par qui. Il est possible d'obtenir une ancienne version, de l'enregistrer, de comparer les différences (entre 2 versions par exemple), ou de fusionner la version du GDS avec votre version.

### Zone "Projet"
Cette zone permet de gérer le projet en cours sous l'éditeur.
Les options disponibles sont les suivantes :

- **Historique du projet** : Permet d'obtenir la liste des modifications réalisées sur le projet dans son ensemble et sur le fichier du projet (fichier WDP, WWP ou WPP). Il est possible d'obtenir une ancienne version, de l'enregistrer, de comparer les différences (entre 2 versions par exemple), d'étiqueter la version du projet, etc.
- **Branches** : Permet de :
  - Créer une branche.
  - Récupérer les modifications depuis une branche.
   Pour plus de détails, consultez [GDS : Gestion des branches](2038016.md).
- **Importer depuis le GDS** : Permet d'importer dans le projet en cours un élément présent dans le GDS (par exemple un composant, une fenêtre présente dans un autre projet). Il est possible de partager l'élément ou d'importer une copie.
- **Maître / Invité** : Permet de gérer les options de manipulation des projets maître et invités. Pour plus de détails, consultez [Travailler avec le Gestionnaire de sources](2038004.md).
- Nouveauté 2025
  **Lister les partages** : Affiche une fenêtre listant les répertoires possédant des partages avec le répertoire courant. Ces partages peuvent concerner des fichiers ou des répertoires. Pour chaque répertoire, il est possible d'obtenir la liste détaillée des fichiers et des répertoires partagés. Il est ainsi possible de voir rapidement les projets qui seront impactés par une modification de ces éléments.

### Zone "Autres actions"
Cette zone permet de gérer la feuille de style du projet et le travail à distance.
Il est possible de :

- Extraire ou réintégrer la feuille de styles du projet.
- Se déconnecter pour une utilisation nomade puis se reconnecter et se synchroniser.
