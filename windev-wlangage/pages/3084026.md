# Partager des éléments avec une application WINDEV

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

## Partage d'éléments entre WEBDEV, WEBDEV et WINDEV Mobile

Un site WEBDEV peut partager de nombreux éléments avec une application WINDEV ou WINDEV Mobile.
Les éléments partageables sont les suivants :

| Analyse | L'analyse d'un projet WINDEV ou WINDEV Mobile peut être partagé avec un projet WEBDEV. |
| --- | --- |
| Classes | Les classes d'un projet WINDEV ou WINDEV Mobile peuvent être partagées avec un projet WEBDEV.  Attention : seul le code compatible avec WEBDEV doit être utilisé dans la classe partagée. |
| Collections de procédures | Les collections de procédures d'un projet WINDEV ou WINDEV Mobile peuvent être partagées avec un projet WEBDEV.  Attention : seul le code compatible avec WEBDEV doit être utilisé dans la collection de procédures partagée. |
| Etats | - Les états d'un projet WINDEV peuvent être partagés avec un projet WEBDEV. - Les états d'un projet WINDEV ne peuvent pas être partagés avec un projet WINDEV. |
| Requêtes | - Les requêtes d'un projet WINDEV ou WINDEV Mobile peuvent être partagées avec un projet WEBDEV. - Les requêtes d'un projet WINDEV ou WINDEV Mobile peuvent être chargées dans un projet WEBDEV.   Ces requêtes sont en lecture seule. Il est possible de les exécuter, et le code SQL associé est visualisable. Il n'est pas possible de visualiser le graphe de la requête. |

**Remarque** : Les fenêtres d'une application WINDEV peuvent être directement importées dans un projet WEBDEV. Pour plus de détails, consultez [Importer une fenêtre WINDEV](2030034.md).
