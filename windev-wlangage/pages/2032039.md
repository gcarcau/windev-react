# Fenêtre de description d'une requête de sélection : Actions appliquées

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Actions appliquées sur les rubriques de la requête

Cette partie de la fenêtre de description d'une requête permet de définir les différentes actions à appliquer sur les rubriques de la requête.
[image: Actions disponibles]

| [image: Numéro 1] | Rubrique sur laquelle les actions seront appliquées. |
| --- | --- |
| [image: Numéro 2] | Permet :  - soit d'afficher ou non les valeurs de la rubrique sélectionnée dans le résultat de la requête. - soit de renommer la rubrique sélectionnée dans le résultat de la requête (création d'un alias). |
| [image: Numéro 3] | Trie les valeurs de la rubrique sélectionnée dans le résultat de la requête. |
| [image: Numéro 4] | Ajoute une nouvelle rubrique au résultat de la requête. Cette rubrique correspond :  - soit au nombre d'enregistrements présents dans un groupement d'enregistrements. - soit au nombre d'enregistrements présents dans un fichier de données. |
| [image: Numéro 5] | Ajoute une nouvelle rubrique au résultat de la requête. Cette rubrique correspond à la somme d'un ensemble d'enregistrements. |
| [image: Numéro 6] | Ajoute une nouvelle rubrique au résultat de la requête. Cette rubrique correspond :  - soit à la moyenne d'un ensemble d'enregistrements. - soit à la valeur minimale d'un ensemble d'enregistrements. - soit à la valeur maximale d'un ensemble d'enregistrements. |
| [image: Numéro 7] | Modifie les valeurs affichées dans le résultat de la requête. Il est possible d'afficher uniquement :  - l'année à partir d'une rubrique de type date. - le mois à partir d'une rubrique de type date.    - le département à partir d'une rubrique contenant un code postal. |
| [image: Numéro 8] | Définit les conditions de sélection. Il est possible de :  - appliquer une condition de sélection sur la rubrique sélectionnée. - modifier et/ou supprimer une condition existante. - modifier l'enchaînement des conditions existantes. |
| [image: Numéro 9] | Sélectionne les enregistrements correspondant à une période donnée. |
| [image: Numéro 10] | Sélectionne les n premiers ou les n derniers enregistrements affichés dans le résultat de la requête. |
| [image: Numéro 11] | Supprime ou non les enregistrements "doublons" du résultat de la requête. |
| [image: Numéro 12] | Permet de :  - indiquer le type de la base de données utilisée (HFSQL, Oracle ou autre). - gérer les jointures (ajouter, modifier, supprimer, ré-initialiser). - vérifier ou non la syntaxe SQL utilisée (en mode test uniquement). - préciser les options d'exécution (optimisation de l'espace mémoire, vérification du format des fichiers, ...). - indiquer si la requête est visible sous le logiciel "Etats & Requêtes". |
