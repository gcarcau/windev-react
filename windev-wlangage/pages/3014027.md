# EnModeTestAutomatique (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Permet de savoir si un test automatique est en cours ou non.
**Remarque** : Les tests automatiques peuvent être lancés uniquement sur des fenêtres, des classes ou des procédures.

## Exemple

```wlangage
SI EnModeTestAutomatique() = Vrai ALORS
	Trace("Variable NumClient : " + NumClient)
FIN
```

## Syntaxe

```wlangage
<Résultat> = EnModeTestAutomatique()
```

`<Résultat>` *Booléen*
> - Vrai si un test automatique est en cours,
> - Faux dans le cas contraire.

## Remarques

### Disponibilité de la fonction
La fonction **EnModeTestAutomatique** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **EnModeTestAutomatique** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
