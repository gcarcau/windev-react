# <Éditeur de diagrammes>.DébutModification (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Signale le début du regroupement d'un ensemble d'opérations sur champ Editeur de diagrammes en un seul événement (gestion du "undo/redo").

## Exemple

```wlangage
MaSélection est un diagSélection <- EDIAG_MonDiagramme.Sélection
EDIAG_MonDiagramme.DébutModification()
MaSélection.Fond.Couleur = Blanc
MaSélection.Bordure.Couleur = Noir
EDIAG_MonDiagramme.FinModification()
```

## Syntaxe

```wlangage
<Editeur de diagrammes>.DébutModification()
```

`<Editeur de diagrammes>` *Nom de champ*
> Nom du champ Editeur de diagrammes à manipuler.

## Remarques

Toutes les modifications effectuées entre la fonction **<Éditeur de diagrammes>.DébutModification** et la fonction [<Éditeur de diagrammes>.FinModification](1410088876.md) sont regroupées en une seule opération annulable par un "undo/redo".

**Classification Métier / UI : Code UI**

**Composante : wd300mdl.dll**
