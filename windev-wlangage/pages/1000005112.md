# NotesListeChamp (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Renvoie la liste des champs du document Notes en cours dans Lotus Notes.

## Exemple

```wlangage
// Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", ...
		"mail\julie.nsf", "C:\Users\Julie\AppData\Local\Lotus\Notes\Data\user.id")
...
// Lecture du premier document
NotesDocumentPremier(IDSession)
// Récupération des champs Lotus Notes de ce document
ListeChampLotusNotes est une chaîne
UnChampLotusNotes est une chaîne
ListeChampLotusNotes = NotesListeChamp(IDSession)
// Pour chaque champ Lotus Notes
POUR TOUTE CHAÎNE UnChampLotusNotes DE ListeChampLotusNotes SÉPARÉE PAR RC
	// Ajoute le nom du champ Lotus Notes et sa valeur dans un champ Liste
	ListeAjoute(LISTE_ChampLotusNotes, UnChampLotusNotes + RC + ...
		NotesChamp(IDSession, UnChampLotusNotes))
FIN
```

## Syntaxe

#### Renvoyer uniquement le nom des champs du document Notes en cours

```wlangage
<Résultat> = NotesListeChamp(<Identifiant de la session>)
```

`<Résultat>` *Chaîne de caractères*
> Nom des champs du document Notes en cours, séparé par des RC (Retour Chariot). En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Identifiant de la session>` *Entier*
> Identifiant de la session à utiliser. Cet identifiant est renvoyé par la fonction [EmailOuvreSessionNotes](3032121.md) ou [NotesOuvreBase](1000005101.md).

#### Renvoyer le nom et le type des champs du document Notes en cours

```wlangage
<Résultat> = NotesListeChamp(<Identifiant de la session> , <notesLstType>)
```

`<Résultat>` *Chaîne de caractères*
> Nom et type des champs du document Notes en cours, au format suivant :
>
>
> ```wlangage
> <Nom du champ Lotus Notes 1> + TAB + <Type du champ Lotus Notes 1> + RC + <Nom du champ Lotus Notes 2> + TAB + <Type du champ Lotus Notes 2> + RC + ...
> ```
>
>
>
> Où :
>
> - <Nom du champ Lotus Notes X> correspond au nom du champ Lotus Notes.
> - <Type du champ Lotus Notes X> correspond au type du champ Lotus Notes. Ce paramètre peut correspondre à :
>   - *notesTypeDateHeure* : Champ Lotus Notes de type DateHeure
>   - *notesTypeInconnu* : Type de champ Lotus Notes non supporté
>   - *notesTypeNombre* : Champ Lotus Notes de type Nombre
>   - *notesTypeTexte* : Champ Lotus Notes de type Texte
>   - *notesTypeTexteRiche* : Champ Lotus Notes de type Texte Riche (contenant un formatage et éventuellement des pièces attachées)
>
>
> En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Identifiant de la session>` *Entier*
> Identifiant de la session à utiliser. Cet identifiant est renvoyé par la fonction [EmailOuvreSessionNotes](3032121.md) ou [NotesOuvreBase](1000005101.md).
`<notesLstType>` *Constante*
> *notesLstType* : Constante permettant de renvoyer le type des champs du document Notes en cours.
