# <Variable Connexion>.AnnuleSauvegarde (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Annule une sauvegarde en cours.

## Syntaxe

```wlangage
<Résultat> = <Connexion>.AnnuleSauvegarde(<Sauvegarde à annuler>)
```

`<Résultat>` *Booléen*
> - Vrai si la sauvegarde a été annulée,
> - Faux dans le cas contraire. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion vers le serveur qui réalise la sauvegarde.
`<Sauvegarde à annuler>` *Entier*
> Identifiant de la sauvegarde à annuler. Cet identifiant est fourni par la fonction [<Variable Connexion>.Sauvegarde](1000022752.md).

**Composante : wd300hf.dll**
