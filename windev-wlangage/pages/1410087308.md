# Gestionnaire des chaînes du projet

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

L'ensemble des chaînes manipulées par le projet (ou par un élément du projet) peuvent être visualisées et manipulées via le Gestionnaire des chaînes du projet, proposé avec WINDEV, WEBDEV et WINDEV Mobile.
Ce gestionnaire de chaînes permet notamment de :

- Lister les chaînes simples, multilingues ou les constantes présentes dans un projet ou un élément d'un projet.
- Filtrer les chaînes affichées dans le gestionnaire (filtre sur le contenu et/ou sur la taille).
- Réaliser certaines actions : convertir en chaîne multilingue, convertir en constante, etc.

Le gestionnaire de chaînes peut être lancé depuis l'éditeur de code via une des options suivantes :

- sous le volet "Refactoring", dans le groupe "Chaînes", déroulez l'option "Chaînes de l'élément" et choisissez d'afficher les chaînes de l'élément en cours ou du projet.
- sous le volet "Code", dans le groupe "Langues", déroulez "Traduire les chaînes" et sélectionnez "Gestionnaire des chaînes du projet".

## Fonctionnalités du gestionnaire des chaînes du projet

### Lister les chaînes
Le gestionnaire de chaînes permet de lister les différents types de chaînes manipulées par le projet ou par un élément du projet. Les chaînes multilingues sont rapidement identifiées grâce à un drapeau.
Grâce aux différentes options, il est possible de sélectionner :

- les chaînes de tout le projet ou d'un élément.
- les chaînes simples, les chaînes multilingues ou les constantes (contenant des chaînes).
- les chaînes contenant un texte spécifique et/ou correspondant à une taille. Il est possible de poser une condition sur la taille des chaînes.

### Faire des actions sur les chaînes
Plusieurs actions sont disponibles dans le gestionnaires de chaînes :

- Voir le code contenant la chaîne sélectionnée. L'éditeur de code est alors affiché sur la ligne de code correspondant à la chaîne de caractères en cours.
- Editer la chaîne.
- Convertir en chaîne multilingue : Permet de convertir une chaîne simple en chaîne multilingue. Cette manipulation est nécessaire lors de la mise en place de la gestion des langues dans une application, afin de paramétrer l'extraction des chaînes à traduire. Cette action peut être réalisée sur une multisélection de chaînes.
- Convertir en chaîne simple : Permet de convertir une chaîne multilingue en chaîne simple. Cette manipulation est nécessaire notamment pour certaines chaînes restant les mêmes quelque soit la langue de l'application (paramètre d'une ligne de commande par exemple). Cette action peut être réalisée sur une multisélection de chaînes.
- Fusionner plusieurs chaînes en une constante : Il est nécessaire de sélectionner les différentes chaînes à fusionner. Ces chaînes doivent correspondre au même contenu. Il suffit ensuite d'indiquer le nom de la constante à utiliser. Le remplacement est automatiquement réalisée dans l'éditeur.
- Ne plus afficher dans le gestionnaire de chaînes. Il sera possible de réafficher cette chaîne en cochant l'option "Afficher les chaînes masquées".
