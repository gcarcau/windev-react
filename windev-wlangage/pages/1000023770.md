# <Arbre>.SelectPlus (Fonction)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Sélectionne un élément dans un champ Arbre.
Exemple de champ Arbre :
[image: Vocabulaire lié à un champ Arbre]

## Exemple

```wlangage
// Sélection du noeud "Desserts" dans le champ Arbre "ARBRE_RecetteTV"
Res = ARBRE_RecetteTV.SelectPlus("Recettes" + TAB + "Desserts")
```

```wlangage
// Initialisation de l'arbre
ARBRE_Arbre1.Ajoute("Racine", aDéfaut, aDéfaut, "")
ARBRE_Arbre1.Ajoute("Racine" + TAB + "Feuille 1", aDéfaut, aDéfaut, "1")
ARBRE_Arbre1.Ajoute("Racine" + TAB + "Feuille 2", aDéfaut, aDéfaut, "2")
ARBRE_Arbre1.Ajoute("Racine" + TAB + "Feuille 3", aDéfaut, aDéfaut, "3")
ARBRE_Arbre1.Ajoute("Racine" + TAB + "Feuille 4", aDéfaut, aDéfaut, "4")
ARBRE_Arbre1.Ajoute("Racine" + TAB + "Feuille 2" + TAB + "Sous Feuille 2-1", ...
		aDéfaut, aDéfaut, "5")
ARBRE_Arbre1.Ajoute("Racine" + TAB + "Feuille 2" + TAB + "Sous Feuille 2-2", ...
		aDéfaut, aDéfaut, "6")
ARBRE_Arbre1.Ajoute("Racine" + TAB + "Feuille 2" + TAB + "Sous Feuille 2-3", ...
		aDéfaut, aDéfaut, "7")
ARBRE_Arbre1.Ajoute("Racine" + TAB + "Feuille 2" + TAB + "Sous Feuille 2-4", ...
	aDéfaut, aDéfaut, "8")
ARBRE_Arbre1.Ajoute("Racine" + TAB + "Feuille 2" + TAB + "Sous Feuille 2-5", ...
		aDéfaut, aDéfaut, "9")

// Initialisation du champ Arbre
ARBRE_Arbre1.SelectPlus("Racine" + TAB + "Feuille 2" + TAB + "Sous Feuille 2-5")
```

## Syntaxe

```wlangage
<Résultat> = <Champ Arbre>.SelectPlus(<Chemin de l'élément>)
```

`<Résultat>` *Booléen*
> - Vrai si la sélection a été effectuée,
> - Faux si l'élément spécifié n'existe pas.
`<Champ Arbre>` *Nom de champ*
> Nom du champ Arbre à manipuler.
`<Chemin de l'élément>` *Chaîne de caractères*
> Chemin complet de l'élément à manipuler. Ce paramètre est de la forme :
>
>
> ```wlangage
> "<Nom de la racine>" + TAB + ["<Nom du 1er noeud>" + TAB + ...["<Nom du 2ème noeud>" + TAB + [...]]]"<Nom de la feuille>"
> ```
>
>
> En cas de doublons sur un élément du chemin, ce chemin peut contenir l'identifiant de l'élément (indiqué à la suite du nom grâce à la fonction [ArbreID](3018027.md)).

## Remarques

### Bandeau de sélection
Si l'élément à sélectionner n'est pas visible, le champ Arbre est déroulé jusqu'à rendre cet élément visible, puis l'élément est sélectionné.

### Evénements exécutés
Lors de l'appel de la fonction **<Arbre>.SelectPlus**, les événements "Affichage d'une ligne" et "Sélection d'une ligne" ne sont pas exécutés.
