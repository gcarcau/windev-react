# Administrateur de la fabrique logicielle : Options

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows)

## Présentation

Plusieurs options sont paramétrables dans l'administrateur de la Fabrique Logicielle :

- Authentification.
- Coordinateur.
- Automates.
- Autres options :
  - Variables d'environnement.
  - Nouveauté Abonnement
    Droits sur la fabrique logicielle.
    **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
    Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
  - Boites de dialogues.

Pour paramétrer ces options :

1. Lancez l'administrateur de la Fabrique Logicielle : sous le volet "Outils", dans le groupe "Utilitaires", cliquez sur "WDFAdmin".
2. Dans la fenêtre qui s'affiche, indiquez le nom du coordinateur auquel l'administrateur doit se connecter.
3. L'administrateur de la Fabrique Logicielle se lance.
4. Cliquez sur l'onglet "Options" pour réaliser le paramétrage de l'administrateur de la Fabrique Logicielle.

## Authentification - Paramètres des Centres de Contrôle

Les paramètres d'authentification permettent de définir la base de données des comptes utilisée par la Fabrique Logicielle. La Fabrique Logicielle utilise les comptes des Centres de Contrôle. Il est nécessaire d'indiquer les options de connexion à cette base de données. Cette base de données peut être :

- une base de données locale en mode partagé. Il suffit d'indiquer le répertoire de partage contenant les fichiers de données de la base de données des Centres de Contrôle.
- une base de données HFSQL Client/Serveur. Il suffit d'indiquer le serveur et son port ainsi que la base utilisée.
  Remarque : le bouton "Tester" permet de vérifier les paramètres saisis.
- une plateforme Cloud. Il suffit d'indiquer le nom de la plateforme utilisée.
  Remarque : Il est possible de créer directement une plateforme Cloud si nécessaire.
  **PCSCLOUD** est une solution payante, clé en main. Pour plus de détails, consultez [PCSCloud](https://pcscloud.net/FR/cloud_developpement.awp).
- une plateforme GDS Drive. Il suffit d'indiquer le nom du compte utilisé.
  Remarque : Il est possible de créer directement un compte PCSCloud si nécessaire.
   **GDSDrive** est une solution payante, clé en main. Pour plus de détails, consultez [GDSDrive](https://pcscloud-drive.net/FR/GDSDrive/index.awp).

L'option "Demander le mot de passe au démarrage" permet de forcer l'identification de l'utilisateur au démarrage de l'administrateur de la Fabrique Logicielle.

## Coordinateur

Le paramétrage du coordinateur permet de :

- Choisir le coordinateur.
- Définir les options du coordinateur (lien "Options du coordinateur").

Les options du coordinateur concernent :

- La base des Centres de Contrôle utilisée pour stocker les plans d'actions et mémoriser leurs comptes-rendus.
- Le paramétrage de l'historique des résultats. Il est possible de fixer le nombre de résultats conservés pour chaque plan d'action.
- Le paramétrage de la méthode d'envoi des comptes-rendus des plans d'action (messagerie interne des Centres de Contrôle, email, etc.).
- Le paramétrage des destinataires en cas de défaillance d'un automate.

## Automates

Le lien **Modifier l'ordre de priorité des automates** permet de définir un ordre d'utilisation des automates.
Lorsque plusieurs machines sont disponibles, il est possible de sélectionner une machine spécifique pour exécuter les plans d'action (par exemple la machine la plus rapide).
Rappel : Il est possible d'ajouter des automates dans l'onglet "Automates" de l'administrateur de la Fabrique Logicielle.

## Autres options

Les options diverses sont les suivantes :

- **Editer la liste des variables d'environnement** : Cette option permet de lister les variables d'environnement utilisables dans les plans d'action paramétrés. Ces variables peuvent par exemple correspondre à un numéro de version interne, une version de diffusion, ... La mise à jour de ces variables impactera tous les plans d'action paramétré les utilisant. La modification sera prise en compte à la prochaine exécution du plan d'action.
- Nouveauté Abonnement
  Droits de la Fabrique Logicielle : Cette option permet à un administrateur (défini dans la base des Centres de Contrôle) de définir des droits selon les utilisateurs sur la fabrique logicielle. Pour plus de détails, consultez [Gestion des droits](1000019594.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
- **Boîtes de dialogue "Ne plus afficher"** : Cette option permet de réactiver si nécessaire les boîtes de dialogues précédemment désactivées (en cochant l'option "Ne plus demander" par exemple).
