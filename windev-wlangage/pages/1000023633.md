# <Html>.Navigue (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Mac Catalyst)

Lance une opération de navigation dans un champ d'affichage HTML.

## Exemple

```wlangage
// Code du bouton Suivant
HTM_ChampHTML1.Navigue(htmlSuivant)
```

```wlangage
// Code du bouton Précédent
HTM_ChampHTML1.Navigue(htmlPrécédent)
```

## Syntaxe

```wlangage
<Champ HTML>.Navigue(<Option de navigation>)
```

`<Champ HTML>` *Nom de champ*
> Nom du champ d'affichage HTML à manipuler.
`<Option de navigation>` *Constante*
> Sens de la navigation :
>
> | *htmlActualise* | Actualise la page en cours (équivalent au bouton "Actualiser" du navigateur). |
> | --- | --- |
> | *htmlDémarrage* | Affiche la page de démarrage (équivalent au bouton "Home" du navigateur). Pour obtenir la valeur initiale du champ d'affichage HTML, utilisez la propriété [ValeurInitiale](2510128.md). _(Android, iPhone/iPad)_ Cette constante n'est pas disponible. |
> | *htmlPrécédent* | Affiche la page précédente (équivalent au bouton "BACK/Précédent" du navigateur). |
> | *htmlStop* | Arrête le chargement des ressources utilisées par la page. L'événement "Chargement de ressources" du champ n'est pas exécuté. |
> | *htmlSuivant* | Affiche la page suivante (équivalent au bouton "SUIVANT" du navigateur). |
Nouveauté Abonnement

```wlangage
<Champ HTML>.Navigue(<URL à afficher>)
```

`<Champ HTML>` *Nom de champ*
> Nom du champ d'affichage HTML à manipuler.
`<URL à afficher>` *Chaîne de caractères*
> URL à afficher dans le champ d'affichage formaté.**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
> Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
