# MQTTDésabonne (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Permet de se désabonner d'une notification MQTT.

## Exemple

```wlangage
MQTTDésabonne(gMqttSession, "sensors/sensor1/temperature1")
```

## Syntaxe

```wlangage
<Résultat> = MQTTDésabonne(<Session MQTT> , <Sujet>)
```

`<Résultat>` *Booléen*
> - Vrai si le désabonnement est mis en place,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de détails.
`<Session MQTT>` *Variable de type mqttSession*
> Nom de la variable [mqttSession](1000023023.md) correspondant à la session MQTT à manipuler.
`<Sujet>` *Chaîne de caractères*
> Sujet pour lequel le désabonnement est demandé.

**Classification Métier / UI : Code métier**

**Composante : wd300com.dll**
