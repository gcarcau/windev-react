# TableurSupprimeNom (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Supprime un des noms permettant d'identifier une cellule d'un champ Tableur.

## Exemple

```wlangage
// Remplacer un nom
TableurSupprimeNom(TBLR_MonTableur, "PrixHT")
TableurAjouteNom(TBLR_MonTableur, "PrixHT", "$A$1")
```

## Syntaxe

```wlangage
TableurSupprimeNom(<Champ Tableur> , <Nom de cellule>)
```

`<Champ Tableur>` *Nom de champ*
> Nom du champ Tableur à manipuler.
`<Nom de cellule>` *Chaîne de caractères*
> Nom de la cellule à supprimer. Si ce nom n'existe pas, une erreur non fatale est renvoyée.
