# DuréeNonRéponse (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **DuréeNonRéponse** permet de connaître et de modifier le délai d'attente maximum. Cette propriété est utilisable sur :

- le flux lors de l'utilisation d'un champ VisioConférence. Pour plus de détails, consultez [DuréeNonRéponse](2510052.md).
- une variable de type [httpRequête](1000021158.md).
- une variable de type [restRequête](1000021481.md).
- une variable de type [wsRequête](1000020577.md).
- Nouveauté 2025
   une variable de type [ftpConnexion](1410090869.md).
