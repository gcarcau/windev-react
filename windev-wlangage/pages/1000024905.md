# <Chaîne ANSI>.Incrémente (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Incrémente un nombre situé en fin ou début d'une chaîne de caractères.

## Exemple

```wlangage
Chaîne1 est une chaîne = "Chaîne1"
// Affiche "Chaîne2"
Info(Chaîne1.Incrémente())
```

## Syntaxe

```wlangage
<Résultat> = <Chaîne initiale>.Incrémente([<Position>])
```

`<Résultat>` *Chaîne de caractères*
> Chaîne initiale avec le nombre (ou le chiffre) incrémenté.
`<Chaîne initiale>` *Chaîne de caractères*
> Chaîne à incrémenter.
`<Position>` *Entier optionnel*
> Position où se situe le nombre (ou le chiffre) à incrémenter :
>
> | *DepuisDébut* | Le nombre en début de chaîne est incrémenté. Si la chaîne ne commence pas par un nombre, le chiffre 1 sera ajouté en début de chaîne. |
> | --- | --- |
> | *DepuisFin* | Le nombre en fin de chaîne est incrémenté. Si la chaîne ne se termine pas par un nombre, le chiffre 1 sera ajouté en fin de chaîne. |
>
>
> Si ce paramètre n'est pas spécifié, trois cas peuvent se présenter :
>
> - la chaîne se termine par un nombre : dans ce cas, c'est le nombre à la fin qui sera incrémenté,
> - la chaîne commence par un nombre : dans ce cas, c'est le nombre au début qui sera incrémenté,
> - la chaîne ne commence ou ne se termine pas par un nombre : dans ce cas, le chiffre 1 sera ajouté en fin de chaîne.

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
