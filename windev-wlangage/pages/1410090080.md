# SousLibellé (Propriété)

> **Disponible :** **WINDEV** (Windows) · **WINDEV Mobile** (iPhone/iPad)

La propriété **SousLibellé** permet de connaître et de modifier le libellé secondaire défini pour :

- une option d'un champ Sélecteur ou Interrupteur. Pour plus de détails, consultez [SousLibellé](1000017232.md).
- un élément d'un champ TreeMap. Pour plus de détails, consultez [SousLibellé](1000017232.md).
- une variable de type [ActionRapide](1410090054.md).
