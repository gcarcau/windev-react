# Entête

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **Entête** permet de connaître et de modifier un entête. Cette propriété est utilisable sur :

- une variable de type [Email](1000018713.md).
- une variable de type [httpRequête](1000021158.md).
- une variable de type [httpRéponse](1000021165.md).
- une variable de type [restRequête](1000021481.md).
- une variable de type [restRéponse](1000021477.md).
- une variable de type [apiRequête](1410088935.md).
- une variable de type [tblrSélection](1000023498.md).
- une variable de type [TéléchargementParamètre](1410087293.md).
