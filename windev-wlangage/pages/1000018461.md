# Succès (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

La propriété **Succès** permet de savoir si l'opération a été effectuée avec succès. Cette propriété est utilisable sur :

- une variable de type [sfRésultatConvertitPiste](1000018739.md)
- une variable de type [sfRésultatDéconnecte](1000018560.md).
- une variable de type [sfRésultatExécuteTraitement](1000018559.md).
- une variable de type [sfRésultatFusionne](1000018499.md).
- une variable de type [sfRésultatRestaure](1000018526.md).
- une variable de type [sfRésultatSauvegarde](1000018460.md).
- une variable de type [sfRésultatSupprime](1000018546.md).
- une variable de type [sfRésultatVideCorbeille](1000018467.md).
