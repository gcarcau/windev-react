# <Variable Image>.Découpe (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie la partie découpée d'une image. Cette image est présente dans une variable de type [Image](1000019650.md).

## Exemple

```wlangage
MonImageDécoupée est une Image
MonImage est une Image
MonImage = "Image.png"

MonImageDécoupée = MonImage.Découpe(10, 10, 100, 100)
```

## Syntaxe

#### Découper une image selon des coordonnées

```wlangage
<Résultat> = <Variable Image>.Découpe(<X> , <Y> , <Largeur> , <Hauteur>)
```

`<Résultat>` *Variable de type Image*
> Variable de type [Image](1000019650.md) contenant l'image découpée.
`<Variable Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) correspondant à l'image à découper.
`<X>` *Entier*
> Abscisse (en pixels) du coin haut gauche de la zone à découper.
`<Y>` *Entier*
> Ordonnée (en pixels) du coin haut gauche de la zone à découper.
`<Largeur>` *Entier*
> Largeur de la zone à découper.
`<Hauteur>` *Entier*
> Hauteur de la zone à découper.

> _(WINDEV, WEBDEV - Code Serveur, Linux, iPhone/iPad, Widget IOS, Mac Catalyst)_ Découper une image selon un rectangle Masquer les détails
<Résultat> = dDécoupe(<Image> , <Rectangle>)

 <Résultat> : Variable de type ImageVariable de type Image contenant l'image découpée. <Image> : Variable de type ImageNom de la variable de type Image correspondant à l'image à découper. <Rectangle> : Variable de type RectangleNom de la variable de type Rectangle correspondant à la zone à découper dans l'image.

## Remarques

Si la zone à découper est invalide (zone plus grande que l'image source ou zone vide), cette fonction provoque une erreur non fatale.

**Composante : wd300pnt.dll**
