# DocSortEdition (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Sort de l'édition en cours. L'entrée en édition a été effectuée avec la fonction [DocEntreEdition](1000023077.md).

## Exemple

```wlangage
DocSortEdition(TT_ChampMonDoc)
```

## Syntaxe

```wlangage
DocSortEdition(<Champ Traitement de texte>)
```

`<Champ Traitement de texte>` *Nom de champ*
> Nom du champ Traitement de texte à manipuler.

**Composante : wd300mdl.dll**
