# <Image>.Efface (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Efface le contenu d'un champ Image avec la couleur spécifiée.

## Exemple

```wlangage
IMG_Dessin.DébutDessin()
// Dessin d'un rectangle dont le fond est jaune clair et le bord bleu clair
IMG_Dessin.DessineRectangle(10, 10, 50, 50, JauneClair, BleuClair)
// Efface le dessin avec la couleur bleue
IMG_Dessin.Efface(BleuClair)
```

## Syntaxe

```wlangage
<Image>.Efface([<Couleur>])
```

`<Image>` *Nom de champ*
> Nom du champ Image à manipuler.
`<Couleur>` *Constante ou Variable de type Couleur optionnelle*
> Couleur utilisée pour effacer. Cette couleur peut correspondre à :
>
> - une des constantes WLangage de couleur,
> - une variable de type [Couleur](1000019661.md).
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - une couleur prédéfinie (voir [les couleurs prédéfinies du WLangage](3010002.md)).
>
> Si ce paramètre n'est pas précisé, l'état initial de l'image sera appliqué :
>
> - transparent pour une variable de type [Image](1000019650.md),
> - couleur du fond de la fenêtre pour un champ Image.

## Remarques

### Gestion de l'opacité

- Si le dessin a été activé dans le champ sans l'option d'opacité (fonction [<Image>.DébutDessin](1000024326.md) sans la constante *dAvecOpacité*) :
  - Sous Windows, la fonction **<Image>.Efface** utilisée avec une couleur ne prendra pas en compte l'opacité.
  - Sous Linux, seules les couleurs dont l'opacité est maximum seront utilisables.
- Si le dessin a été activé dans le champ avec l'option d'opacité (fonction [<Image>.DébutDessin](1000024326.md) avec la constante *dAvecOpacité*), la fonction **<Image>.Efface** utilisée avec une couleur prendra en compte l'opacité.
