# WINDEV Mobile : Présentation

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Environnement de développement Mobile

WINDEV Mobile est un environnement de développement sous poste PC qui permet de développer :

- des applications pour Android.
- des applications pour iPhone/iPad.

**Remarques** :

- Les applications générées fonctionnent uniquement sous des terminaux mobiles (équipés de processeur ARM, XScale, Samsung et compatible ARM). Ces applications ne fonctionnent pas sous des postes PC.
- Le développement d'applications Windows Mobile n'est plus disponible à partir de la version 27. Windows Mobile, Windows CE et Windows Embedded ne sont plus supportés par Microsoft, mais sont encore utilisés dans le domaine industriel.
  Pour continuer à développer pour Windows Mobile, vous devez utiliser une version 26. Votre version 2025 donne accès à la version 26 qui peut être téléchargée en version Abonnement [ici](https://download.windev.com/FR/saas.awp) ou en version avec clé [ici](https://download.windev.com/FR/).
- Le développement d'applications en mode Universal Windows 10 App n'est plus disponible à partir de la version 2025. La plateforme "Universal Windows 10 App" n'est plus supportée par WINDEV, WEBDEV et WINDEV Mobile.
  Pour continuer à développer une application en mode Universal Windows 10 App, vous devez utiliser une version 2024. Votre version 2025 donne accès à la version 2024 qui peut être téléchargée en version Abonnement [ici](https://download.windev.com/FR/) ou en version avec clé [ici](https://download.windev.com/FR/dongle.awp).

## Fonctions WLangage

La plupart des fonctions WLangage présentes dans WINDEV standard sont également disponibles dans WINDEV Mobile. Il s'agit des fonctions communes aux deux produits.
Seules les fonctions spécifiques à Windows ne sont pas disponibles sous WINDEV Mobile.

## Base de données

Les données manipulées dans une application WINDEV Mobile peuvent provenir :

- d'une base de données HFSQL Classic ou HFSQL Client/Serveur.
- d'une base de données SQLite.
- de fichiers ".INI".
- de fichiers texte (au format ANSI ou Unicode).
