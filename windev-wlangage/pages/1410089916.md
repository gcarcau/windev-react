# Fonctions de gestion des chaînes de caractères (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Les fonctions permettant de manipuler des chaînes de caractères via une syntaxe préfixée sont les suivantes :
| [<Buffer>.AnsiVersUnicode](1000026033.md) | Convertit un buffer contenant une chaîne de caractères au format ANSI (Windows) en un buffer contenant une chaîne de caractères au format UNICODE. |
| --- | --- |
| [<Buffer>.UTF8Valide](1410090487.md) | Teste la validité d'un buffer au format UTF8. |
| [<Chaîne ANSI>.AnsiVersOem](1000024891.md) | Convertit une chaîne de caractères au format ANSI (Windows) en une chaîne de caractères au format OEM (DOS). |
| [<Chaîne ANSI>.AnsiVersUnicode](1000024892.md) | Convertit une chaîne de caractères au format ANSI (Windows) en une chaîne de caractères au format Unicode. |
| [<Chaîne ANSI>.BufferVersHexa](1000024894.md) | Convertit une chaîne Ansi ou Unicode en une chaîne hexadécimale affichable (par exemple : "4A 5B 00"). |
| [<Chaîne ANSI>.CaractOccurrenceType](1000024895.md) | Renvoie le nombre de caractères vérifiant les informations de type données. |
| [<Chaîne ANSI>.CommencePar](1000024901.md) | Vérifie si une chaîne de caractères commence :   - soit par une chaîne de caractères spécifique. - soit par une des chaînes de caractères présentes dans un tableau. |
| [<Chaîne ANSI>.Complète](1410089823.md) | Renvoie une chaîne de caractères spécifique de taille déterminée. |
| [<Chaîne ANSI>.Contient](1410089824.md) | Permet de savoir si une sous-chaîne est contenue dans une chaîne. |
| [<Chaîne ANSI>.Découpe](1000024902.md) | Extrait toutes les sous-chaînes d'une chaîne de caractères en fonction d'un ou plusieurs séparateurs de chaînes. |
| [<Chaîne ANSI>.Droite](1410089825.md) | Extrait la partie droite (c'est-à-dire les derniers caractères) d'une chaîne de caractères ou d'un buffer. |
| [<Chaîne ANSI>.ExtraitChaîne](1000024876.md) | Permet de :  - extraire une sous-chaîne d'une chaîne de caractères en fonction d'un séparateur de chaîne donné. - effectuer un parcours de sous-chaînes dans une chaîne de caractères en fonction d'un séparateur de chaîne donné. |
| [<Chaîne ANSI>.FinitPar](1000024903.md) | Vérifie si une chaîne de caractères se termine :   - soit par une chaîne de caractères spécifique. - soit par une des chaînes de caractères présentes dans un tableau. |
| [<Chaîne ANSI>.Formate](1000024877.md) | Formate une chaîne de caractères selon les options choisies. |
| [<Chaîne ANSI>.Incrémente](1000024905.md) | Incrémente un nombre situé en fin ou début d'une chaîne de caractères. |
| [<Chaîne ANSI>.Insère](1000024906.md) | Insère une chaîne dans une autre chaîne de caractères à une position donnée. |
| [<Chaîne ANSI>.Inverse](1000024908.md) | Inverse les caractères d'une chaîne. |
| [<Chaîne ANSI>.RegexCherche](1410090616.md) | Cherche toutes les parties d'une chaîne de caractères qui respectent un format donné. |
| [<Chaîne ANSI>.RegexRemplace](1410090617.md) | Remplace toutes les parties d'une chaîne qui respectent un format donné. |
| [<Chaîne ANSI>.RegexVérifie](1410090618.md) | Vérifie si une chaîne respecte un format défini par une expression régulière. |
| [<Chaîne ANSI>.Remplace](1000024890.md) | Remplace toutes les occurrences d'un mot présent dans une chaîne par un autre mot. |
| [<Chaîne ANSI>.SupprimeDoublon](1410087983.md) | Supprime les doublons parmi les sous-chaînes d'une chaîne de caractères en fonction d'un ou plusieurs séparateurs. |
| [<Chaîne ANSI>.VersNumérique](1410087984.md) | Renvoie la valeur numérique d'une chaîne de caractères. Il est ainsi possible d'effectuer des calculs numériques sur des chaînes de caractères. |
| [<Chaîne OEM>.OemVersAnsi](1410090334.md) | Convertit une chaîne de caractères au format OEM (DOS) en une chaîne de caractères au format ANSI (Windows). |
| [<Chaîne Unicode>.RegexCherche](1410090619.md) | Cherche toutes les parties d'une chaîne de caractères qui respectent un format donné. |
| [<Chaîne Unicode>.RegexRemplace](1410090620.md) | Remplace toutes les parties d'une chaîne qui respectent un format donné. |
| [<Chaîne Unicode>.RegexVérifie](1410090621.md) | Vérifie si une chaîne respecte un format défini par une expression régulière. |
