# Propriétés HFSQL des requêtes et des vues

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows)

Ces propriétés peuvent être utilisées sur des requêtes ou des vues HFSQL.
| [BorneMax](2510009.md) | La propriété **BorneMax** permet de :  - connaître et de modifier la borne maximale d'un état basé sur un fichier de données. - connaître la borne maximale du filtre en cours. - connaître la valeur maximale d'une série d'un graphe. - connaître et modifier la valeur maximale de certains types de champs. |
| --- | --- |
| [BorneMin](2510008.md) | La propriété **BorneMin** permet de :  - connaître et de modifier la borne minimale d'un état basé sur un fichier de données. - connaître la borne minimale du filtre en cours. - connaître la valeur minimale d'une série d'un graphe. - connaître et modifier la valeur minimale de certains types de champs. |
| [CodeSQL](1000017045.md) | La propriété **CodeSQL** permet de connaître le code SQL d'une requête créée avec l'éditeur de requêtes (fichier d'extension ".WDR"). |
| [ConditionFiltre](2512096.md) | La propriété **ConditionFiltre** permet de connaître la condition de sélection mise en place par la fonction [HFiltre](3044100.md) sur un fichier de données, une vue HFSQL ou une requête. |
| [ExécutionTerminée](2512117.md) | La propriété **ExécutionTerminée** permet de savoir si une requête ou une vue HFSQL Classic ou Client/Serveur a fini de s'exécuter. |
| [FiltreAvecBornes](2512097.md) | La propriété **FiltreAvecBornes** permet de savoir si des bornes ont été précisées sur le filtre mis en place par la fonction [HFiltre](3044100.md) sur un fichier de données, une vue HFSQL ou une requête. |
| [IDAutoMax](2512023.md) | La propriété **IDAutoMax** permet de connaître l'identifiant automatique maximum sur un fichier de données répliqué. |
| [IDAutoMin](2512039.md) | La propriété **IDAutoMin** permet de connaître l'identifiant automatique minimum sur un fichier de données répliqué. |
| [NbRubrique](2512055.md) | La propriété **NbRubrique** permet d'obtenir le nombre total de rubriques (y compris les clés composées) présentes dans un enregistrement de :  - un fichier décrit sous l'éditeur d'analyses, - un fichier décrit par programmation, - une vue HFSQL, - une requête. |
| [NbRubriqueClé](2512056.md) | La propriété **NbRubriqueClé** permet d'obtenir le nombre total de rubriques clé (y compris les clés composées) présentes dans un enregistrement de :  - un fichier décrit sous l'éditeur d'analyses, - un fichier décrit par programmation, - une vue HFSQL, - une requête. |
| [NbRubriqueMémo](2512057.md) | La propriété **NbRubriqueMémo** permet d'obtenir le nombre total de rubriques mémo présentes dans un enregistrement de :  - un fichier décrit sous l'éditeur d'analyses, - un fichier décrit par programmation, - une vue HFSQL, - une requête. |
| [Nom](2510082.md) | La propriété **Nom** permet de connaître :  - le nom de la police associée à une variable de type Police. - le nom d'un champ, d'un état ou d'un bloc d'un état. - le nom d'un champ, d'un groupe de champs ou d'une fenêtre. - le nom d'un champ, d'un groupe de champs ou d'une page. |
| [NomDécrit](2512066.md) | La propriété **NomDécrit** permet de gérer le nom logique des fichiers de données HFSQL (sans tenir compte des éventuelles modifications effectuées par la fonction [HAlias](3044176.md)). |
| [RubriqueFiltrée](2512086.md) | La propriété **RubriqueFiltrée** permet de connaître la rubrique sur laquelle un filtre a été mis en place par la fonction [HFiltre](3044100.md). |
| [TailleEnregistrement](2512090.md) | La propriété **TailleEnregistrement** permet d'obtenir la taille (en octets) d'un enregistrement de :  - un fichier décrit sous l'éditeur d'analyses, - un fichier décrit par programmation, - une vue HFSQL, - une requête. |
| [Type](2510131.md) | La propriété **Type** permet de connaître :  - le type d'un élément décrit par programmation (description de rubrique ou de fichier) ou non (fichier ou rubrique défini sous l'éditeur d'analyses, vue ou requête). - le type d'un objet. - le type de la valeur stockée dans un variant. |
