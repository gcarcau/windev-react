# SysArrête (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Arrête le système ou ferme la session Windows en cours.

## Exemple

```wlangage
// Arrête le système et coupe l'alimentation
SysArrête(sysEteint)
```

## Syntaxe

```wlangage
<Résultat> = SysArrête(<Mode d'arrêt>)
```

`<Résultat>` *Booléen*
> - Vrai si aucun problème n'a été rencontré,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de détails.
>
>
> Le résultat est immédiatement renvoyé. Le processus d'arrêt est ensuite effectué en tâche de fond.
`<Mode d'arrêt>` *Constante*
> Indique le mode de fermeture souhaité :
>
> | *sysEteint* | Arrête le système et coupe l'alimentation. |
> | --- | --- |
> | *sysFermeSession* | Termine la session en cours |
> | *sysRedémarre* | Arrête et redémarre le système. |
> | *sysVerrouilleSession* | Verrouille la session en cours. |

## Remarques

### Arrêt par logiciel impossible
Si le système ne supporte pas l'extinction par logiciel, la fonction **SysArrête** se contente d'arrêter Windows et de placer la machine dans l'état affichant le message : "Vous pouvez éteindre votre ordinateur en toute sécurité".
