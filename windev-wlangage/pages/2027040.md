# Volet "Analyseur Temps Réel"

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Le volet "Analyseur Temps Réel" permet de visualiser pendant le test d'un élément l'activité de votre application ou de votre site.
[image: Volet Analyseur Temps Réel]

Le volet "Analyseur temps réel" permet de :

- suivre les différents threads de l'application.
- connaître à tout moment le code exécuté.
- accéder au code exécuté, ...

Pour plus de détails, consultez [Analyseur Temps réel](9500237.md).

## Afficher le volet "Analyseur Temps Réel"

**Pour afficher le volet "Analyseur Temps Réel"**, sous le volet "Accueil", dans le groupe "Environnement", déroulez "Volets" et sélectionnez "Volets" puis "Analyseur Temps Réel".
Ce volet peut également être affiché directement via le bouton  du volet "Débogueur", lors du débogage d'une application ou d'un site.

Pour plus de détails sur les manipulations des volets, consultez [Manipuler les volets ancrables](2027001.md).
