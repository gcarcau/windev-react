# DocVersHTML (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Convertit un document de type Traitement de texte en un fichier HTML.
Nouveauté 2025

> _(WINDEV, Linux)_ Cette fonction est désormais disponible pour les applications WINDEV sous Linux.

> _(WEBDEV - Code Serveur, Linux)_ Cette fonction est désormais disponible pour les sites WEBDEV sous Linux.

## Exemple

```wlangage
d est un Document = "texte.docx"
SI DocVersHTML(d, "texte.htm") ALORS
	Info("Document converti au format HTML")
FIN
```

```wlangage
// Export en HTML du contenu d'un champ Traitement de texte
// Code de clic du bouton "Export HTML"
DocVersHTML(TT_MonDoc, fRepExe() + [fSep] + "tt.htm")
```

## Syntaxe

```wlangage
<Résultat> = DocVersHTML(<Document à convertir> [, <Chemin>] [, <Gestion des styles CSS>])
```

`<Résultat>` *Booléen ou Buffer*
> - Si <Chemin> est précisé :
>   - Vrai si le fichier a été généré,
>   - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
> - Si <Chemin> n'est pas précisé, <Résultat> correspond à un buffer contenant le code HTML.
`<Document à convertir>` *Variable de type Document ou nom de champ*
> Document à manipuler. Ce document peut correspondre à :
>
> - une variable de type [Document](1000022461.md).
> - un champ Traitement de texte.
`<Chemin>` *Chaîne de caractères optionnelle*
> Chemin du fichier HTML à générer. Si ce chemin n'est pas précisé, le code HTML est renvoyé sous forme de buffer.
`<Gestion des styles CSS>` *Constante optionnelle*
> Attributs de style à utiliser :
>
>
> | *dvhAvecCSS* (Valeur par défaut) | Applique les styles CSS **externes** Le code CSS est généré dans un fichier ".CSS" externe à la page HTML. Ce fichier est créé dans le même répertoire que la page HTML générée. Ce fichier porte le même nom que la page HTML avec l'extension ".CSS". Un lien vers ce fichier est ajouté dans le code HTML de la page. Si le document contient des images, celles-ci sont sauvegardées dans un sous-répertoire portant le même nom que le fichier HTML généré. |
> | --- | --- |
> | *dvhSansCSS* | Applique les styles CSS **inline** : le code CSS est généré et intégré dans le code HTML de la page générée. Chaque balise contient les styles CSS qui lui sont appliqués.  Si le document contient des images, celles-ci sont intégrées et sont encodées en base 64.   Cette constante permet par exemple de réaliser une génération HTML adaptée aux nouvelles messageries emails.   Remarque : si une image contenue dans un email fait plus de 100 Ko, elle sera généralement affichée comme une pièce jointe de l'email, même si elle est encodée en base 64 dans l'email. |
