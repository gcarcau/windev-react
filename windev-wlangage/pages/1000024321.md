# CertificatDeConfianceRAZ (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Retire tous les certificats ajoutés par la fonction [CertificatDeConfianceAjoute](1000024320.md).

## Exemple

```wlangage
CertificatDeConfianceAjoute("MonCA.pem")
// code
CertificatDeConfianceRAZ()
```

## Syntaxe

```wlangage
<Résultat> = CertificatDeConfianceRAZ()
```

`<Résultat>` *Booléen*
> - Vrai si les certificats de confiance (ajoutés par la fonction [CertificatDeConfianceAjoute](1000024320.md)) ont été retirés,
> - Faux en cas d'erreur.

**Composante : wd300com.dll**
