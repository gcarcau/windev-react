# URL (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **URL** permet de connaître et de modifier une URL. Cette propriété est utilisable sur :

- un lien, un bouton, une image cliquable ou un champ iFrame. Pour plus de détails, consultez [URL](2510132.md).
- une variable de type [rssDocumentJoint](1000017789.md).
- une variable de type [rssImage](1000017799.md).
- une variable de type [rssSource](1000017803.md).
- une variable de type [upnpPériphérique](1000020903.md).
- une variable de type [upnpImage](1000020905.md).
- une variable de type [upnpService](1000020908.md).
- une variable de type [httpRequête](1000021158.md).
- une variable de type [restRequête](1000021481.md).
