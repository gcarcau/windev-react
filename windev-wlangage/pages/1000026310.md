# Fonctions de gestion du champ Editeur HTML (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Les fonctions WLangage permettant de gérer les champs Editeur HTML (syntaxe préfixée) sont les suivantes :

| [<Editeur HTML>.DepuisEmail](1000026296.md) | Importe le contenu HTML d'un email et ses images dans un champ Editeur HTML. Les images contenues dans l'email sont également affichées dans le champ. |
| --- | --- |
| [<Editeur HTML>.ExécuteJS](1000026297.md) | Exécute du code Javascript dans un champ Editeur HTML. |
| [<Editeur HTML>.FormateSelection](1000026298.md) | Modifie le style de la sélection dans un champ Editeur HTML. |
| [<Editeur HTML>.Insère](1000026299.md) | Insère du texte ou du code HTML à la position du curseur dans un champ Editeur HTML. |
| [<Editeur HTML>.InsèreTableau](1000026300.md) | Insère un tableau à la position du curseur dans un champ Editeur HTML. |
| [<Editeur HTML>.Recherche](1000026301.md) | Recherche une chaîne de caractères dans un champ Editeur HTML. |
| [<Editeur HTML>.Récupère](1000026302.md) | Récupère en mode asynchrone la valeur d'une des propriétés d'un champ Editeur HTML. |
| [<Editeur HTML>.RécupèreDocument](1000026304.md) | Récupère en mode asynchrone le document HTML en cours dans un champ Editeur HTML. |
| [<Editeur HTML>.RécupèreSélection](1000026305.md) | Récupère en mode asynchrone la sélection effectuée dans un champ Editeur HTML. |
| [<Editeur HTML>.Remplace](1000026306.md) | Remplace une chaîne de caractères par une autre dans un champ Editeur HTML. |
| [<Editeur HTML>.Sélectionne](1000026307.md) | Sélectionne une portion de texte dans un champ Editeur HTML. |
| [<Editeur HTML>.VersEmail](1000026308.md) | Exporte le contenu d'un champ Editeur HTML vers une variable de type Email (pour envoyer l'email). |
| [<Editeur HTML>.VersPDF](1000026309.md) | Exporte le contenu d'un champ Editeur HTML vers un fichier PDF. |
