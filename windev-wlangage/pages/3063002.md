# PressePapierFormat (Fonction)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android)

Identifie le format des informations contenues dans le presse-papiers.

## Exemple

```wlangage
SI PressePapierFormat(ppfTexte) = Vrai ALORS
	BTN_Coller.Etat = Actif
SINON
	BTN_Coller.Etat = Grisé
FIN
```

## Syntaxe

```wlangage
<Résultat> = PressePapierFormat(<Format recherché>)
```

`<Résultat>` *Booléen*
> - Vrai si le format demandé est disponible,
> - Faux dans le cas contraire.
`<Format recherché>` *Constante de type entier*
> Format contenu dans le presse-papiers :
>
> | *ppfBitmap* | Format image |
> | --- | --- |
> | *ppfRtf* | Format RTF |
> | *ppfTexte* | Format texte |
> | *ppfTexteUnicode* | Format texte Unicode. |

## Remarques

- Lecture du presse-papiers :
  - La fonction [PressePapier](3063004.md) lit l'information de type texte ou image contenue dans le presse-papiers de Windows.
  - La fonction [PressePapierRTF](1000017200.md) lit l'information de type texte RTF dans le presse-papiers de Windows (le contenu du presse-papiers est au format RTF).
  - La fonction [PressePapierUnicode](1000018858.md) lit l'information de type texte Unicode dans le presse-papiers.
- La fonction [VersPressePapier](3063005.md) permet d'écrire dans le presse-papiers. La fonction [VersPressePapierRTF](1000017199.md) permet d'écrire un texte au format RTF dans le presse-papiers.

**Composante : wd300std.dll**
