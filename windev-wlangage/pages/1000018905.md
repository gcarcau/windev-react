# InfoVersion (Type de variable)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Le type **InfoVersion** permet de connaître les caractéristiques d'une version spécifique d'une application. Les caractéristiques de cette version peuvent être connues à l'aide de différentes propriétés WLangage.

## Exemple

```wlangage
sRes est une chaîne = AppliListeVersion()
IV est un InfoVersion

sAffiche est une chaîne = [
Numéro = %1
Date = %2
Taille = %3 octets
Commentaire = %4
Actif = %5
Forcé = %6
Interdite = %7
]

POUR TOUTE CHAÎNE MaChaîne DE sRes SÉPARÉE PAR RC
	IV = AppliInfoVersion(MaChaîne)
	Trace(ChaîneConstruit(sAffiche, ...
		IV.NuméroVersion, IV.Date, ...
		IV.Taille, IV.Commentaire, ...
		IV.Activé, IV.Forcé, IV.Interdit))
	Trace("===============================================")
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type InfoVersion
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **InfoVersion** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Activé | Booléen | - Vrai si la version est activée (c'est-à-dire visible par les postes client), - Faux dans le cas contraire.  **Cette propriété est disponible en lecture seulement**. _(Android, iPhone/iPad, Widget IOS, Mac Catalyst)_ Cette propriété n'est pas disponible. |
| Commentaire | Chaîne de caractères | Informations concernant les nouveautés de la version. Ces informations ont été renseignées par le développeur. Le contenu de cette propriété peut être :   - un texte, - un fichier texte, RTF ou CHM, - un "lien" vers un page d'aide (aide des nouveautés générée à la création de l'exécutable).  **Cette propriété est disponible en lecture seulement**. |
| Date | DateHeure | Date de mise en ligne de la version.  **Cette propriété est disponible en lecture seulement**. |
| Forcé | Booléen | - Vrai si la version est forcée, - Faux dans le cas contraire.  **Cette propriété est disponible en lecture seulement**. _(Android, iPhone/iPad, Widget IOS, Mac Catalyst)_ Cette propriété n'est pas disponible. |
| Interdit | Booléen | - Vrai si cette version est interdite, - Faux si la version est autorisée.  **Cette propriété est disponible en lecture seulement**. _(Android, iPhone/iPad, Widget IOS, Mac Catalyst)_ Cette propriété n'est pas disponible. |
| NuméroVersion | Chaîne de caractères | Numéro de la version.  **Cette propriété est disponible en lecture seulement**. |
| Taille | Entier | Taille de la version sur le disque (exprimée en octets).  **Cette propriété est disponible en lecture seulement**. |
