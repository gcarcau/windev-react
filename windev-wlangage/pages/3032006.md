# EmailFermeSession (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Ferme une session de gestion des emails selon le mode choisi :

- emails gérés par le protocole SMTP/POP3/IMAP : la fonction **EmailFermeSession** permet de fermer la session SMTP/POP3/IMAP. Si une session POP3, une session SMTP et une session IMAP ont été ouvertes, toutes les sessions sont fermées.
- emails gérés par l'intermédiaire du client MS Exchange (Outlook) : la fonction **EmailFermeSession** permet de fermer la session MS Exchange.
- emails gérés avec Lotus Notes : la fonction **EmailFermeSession** permet de fermer une session avec le logiciel de messagerie Lotus Notes.

Une session d'emails non terminée sera automatiquement fermée à la fin du programme WINDEV ou WINDEV Mobile ou à la fin de la session WEBDEV.

> _(Linux, Java)_ Seules les sessions POP3/SMTP sont gérées.

## Exemple

```wlangage
// Ouverture d'une session d'emails par le protocole SMTP/POP3
SI EmailOuvreSession(USER, PASSWORD, "pop3.nomfournisseur.com", ...
		"smtp.nomfournisseur.com") = Vrai ALORS
	NomUser = USER
SINON
	NomUser = ""
	Erreur("Impossible d'établir la connexion")
FIN
// Si une session est ouverte, fermeture de cette session
SI NomUser <> "" ALORS
	EmailFermeSession(NomUser)
	NomUser = ""
FIN
```

## Syntaxe

#### Fermer une session d'emails utilisant le protocole POP3, SMTP ou IMAP

```wlangage
EmailFermeSession(<Session>)
```

`<Session>` *Chaîne de caractères ou variable de type emailSessionPOP3, emailSessionSMTP ou emailSessionIMAP*
> Identifie la session d'un utilisateur. Correspond à :
>
> - le nom d'utilisateur utilisé pour ouvrir la session email (fonction [EmailOuvreSession](3032028.md), [EmailOuvreSessionSMTP](3032025.md) ou [EmailOuvreSessionPOP3](3032022.md)).
> - une variable de type [emailSessionPOP3](1000018759.md).
> - une variable de type [emailSessionSMTP](1000018765.md).
> - une variable de type [emailSessionIMAP](1000018957.md).

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ Fermer une session d'emails utilisant MS Exchange (Outlook) ou Lotus Notes Masquer les détails
EmailFermeSession(<Session>)

 <Session> : Entier ou variable de type emailSessionOutlook ou emailSessionNotesIdentifiant de la session email en cours. Cette valeur peut être :un entier renvoyée par la fonction EmailOuvreSession ou EmailOuvreSessionNotes.une variable de type emailSessionOutlook.une variable de type emailSessionNotes.
