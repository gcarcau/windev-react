# MatNbColonne (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie le nombre de colonnes d'une matrice. Le nombre de colonnes d'une matrice varie dynamiquement. Il correspond au nombre de colonnes initialisées. Le nombre de colonnes peut varier après l'utilisation des fonctions :

- [MatEcrit](3050077.md),
- [MatRemplit](3050057.md).

## Exemple

```wlangage
// Nombre de colonnes ?
ResNbColonne = MatNbColonne("MaMatrice")
```

## Syntaxe

```wlangage
<Résultat> = MatNbColonne(<Matrice>)
```

`<Résultat>` *Entier*
> Nombre de colonnes dans la matrice spécifiée.
`<Matrice>` *Chaîne de caractères*
> Nom de la matrice à manipuler, défini avec la fonction [MatCrée](3050058.md).

## Remarques

### Existence de la matrice
L'existence de la matrice n'est pas vérifiée. Pour vérifier l'existence d'une matrice, utilisez la fonction [MatExiste](3050076.md).

### Gestion des erreurs
**Attention** : La fonction **MatNbColonne** ne retourne pas de code d'erreur. Pour savoir si des erreurs ont été générées par le renvoi du nombre de colonnes, utilisez la fonction [MatErreur](3050044.md). Le libellé de l'erreur peut être connu grâce à la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
