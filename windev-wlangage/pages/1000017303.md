# JourFérié (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Indique si un jour est férié ou non. Les dates correspondant à des jours fériés sont précisées avec la fonction [JourFériéAjoute](1000017304.md).

## Exemple

```wlangage
// Définition des jours fériés
JourFériéAjoute("0714")
// Vérification d'un jour férié
SI JourFérié("19700714") = Vrai ALORS
	Info(DateVersChaîne("19700714", maskDateSystème) + " est un jour férié")
FIN
// Vérification d'une date présente dans un champ de saisie
SI JourFérié(SAI_Date) = Vrai ALORS
	Info(DateVersChaîne(SAI_Date, maskDateSystème) + " est un jour férié")
FIN
```

## Syntaxe

```wlangage
<Résultat> = JourFérié(<Date à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si la date indiquée correspond à un jour férié défini avec la fonction [JourFériéAjoute](1000017304.md),
> - Faux dans le cas contraire.
`<Date à vérifier>` *Chaîne de caractères ou variable de type Date*
> Date à vérifier. Si cette date correspond à une chaîne, elle doit être au format AAAAMMJJ (AAAA correspond à l'année, MM au mois et JJ au jour).

**Classification Métier / UI : Code neutre**

**Composante : wd300obj.dll**
