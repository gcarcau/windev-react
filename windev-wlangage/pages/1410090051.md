# Procédure WLangage appelée par la fonction TCDCalculeToutAsynchrone

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Procédure WLangage (également nommée "callback") appelée par la fonction [TCDCalculeToutAsynchrone](1410090244.md) à la fin du calcul complet du champ Tableau croisé dynamique.

## Exemple

```wlangage
TCDCalculeToutAsynchrone(TCD_Statistiques, Calcul_terminé)
	PROCÉDURE INTERNE Calcul_terminé(bOK est booléen)
		SI PAS bOK ALORS
			Erreur(ErreurInfo())
			RETOUR
		FIN
	FIN
```

## Syntaxe

```wlangage
TCDCalculeToutAsynchrone_Callback(<Etat>)
```

`<Etat>` *Booléen*
> - Vrai si le calcul du champ Tableau croisé dynamique a été effectué avec succès,
> - Faux dans le cas contraire. Dans ce cas, la fonction [ErreurInfo](3013008.md) permet de connaître la cause de l'échec du calcul.

**Composante : wd300obj.dll**
