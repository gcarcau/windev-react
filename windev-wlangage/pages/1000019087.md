# Client (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

La propriété **Client** permet de connaître le compte client SaaS associé à :

- une variable de type [saasAbonnement](1000019088.md),
- une variable de type [saasUtilisateur](1000019083.md).
