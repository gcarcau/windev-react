# Afficher le code d'un élément

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

WINDEV, WEBDEV et WINDEV Mobile permettent d'utiliser une programmation événementielle et une programmation orientée objet.
La programmation événementielle proposée associe un ou plusieurs événements WLangage à chaque élément utilisé. Ces événements sont affichés dans l'éditeur de code.

Pour de nombreux éléments :

- Certains événements WLangage sont proposés par défaut : ce sont les événements les plus courants et les plus utilisés.
- Certains événements WLangage peuvent être ajoutés. Ces événements permettent de gérer des cas spécifiques (par exemple, la gestion du Drag and Drop dans certains cas particuliers). Pour plus de détails, consultez [Evénements optionnels](1014004.md).

## Comment le faire ?

### Comment afficher les événements WLangage associés à un élément ?
Pour afficher les événements associés à un élément (champ, fenêtre, page, etc.), plusieurs méthodes sont disponibles :

- **Utiliser la touche F2**. Il suffit pour cela de :
  - Sélectionner l'élément voulu.
  - Utiliser la touche F2 : l'éditeur de code est automatiquement affiché avec la liste des événements associés par défaut.
- **Utiliser l'option "Code" du menu contextuel**. Il suffit pour cela de :
  - Sélectionner l'élément voulu.
  - Afficher le menu contextuel (clic droit) et de sélectionner l'option "Code". L'éditeur de code est automatiquement affiché avec la liste des événements associés par défaut.

**Remarques** :

- Il est également possible d'afficher les événements associés à un élément depuis la fenêtre de description de l'élément : il suffit de cliquer sur le bouton  placé en bas de la fenêtre de description.
- Pour afficher les événements associés au projet, à une fenêtre, à une page ou un état, il est également possible d'utiliser la barre des éléments ouverts. Il suffit de :
  - Afficher le menu contextuel du bouton correspondant à l'élément voulu.
  - Sélectionner l'option "Code de l'élément" dans le menu qui s'affiche. L'éditeur de code est automatiquement affiché avec la liste des événements associés par défaut.
- Les événements "Serveur" et "Navigateur" liés à l'élément sélectionné sont affichés sous l'éditeur de code. Pour plus de détails, consultez [Code serveur / Code navigateur](2013002.md).

### Cas particulier : afficher les événements WLangage associés à un élément présent dans l'éditeur de code
Le code WLangage placé dans les différents traitements ou événements peut manipuler des éléments spécifiques (champs, fenêtres, pages, etc.).
Il est possible d'afficher directement les événements d'un élément manipulé dans une ligne de code WLangage en cliquant sur le nom de l'élément et en utilisant la touche F2.

Par exemple : Considérons le code suivant :

```wlangage
Ouvre(FEN_Menu)
```

Si la touche F2 est utilisée sur le mot "FEN_Menu", l'éditeur de code affichera les événements associés à l'élément "FEN_Menu".

### Cas particulier : F2 sur le nom d'un plan
Si le code WLangage manipule un plan nommé, l'utilisation de la touche F2 sur le nom du plan dans l'éditeur de code permet d'ouvrir la fenêtre si nécessaire dans l'éditeur de fenêtre et de se positionner sur le plan spécifié.

### Astuce : Revenir à la dernière modification de code
Il arrive souvent qu'après avoir tapé un code, on navigue dans le code pour vérifier certains éléments. Et ensuite, il faut revenir au code initial pour continuer ses tâches.
Pour revenir au code initial, utilisez la combinaison de touches Ctrl + Alt + Flèche gauche.
