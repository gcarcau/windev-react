# Document (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Le mot-clé **Document** peut correspondre :

- à la variable de type [Document](1000022461.md), utilisée pour manipuler des documents de type Traitement de texte.
- à la propriété **Document**. Cette propriété est utilisable sur :
  - une variable de type [mongoOpérationAjout](1410089163.md).
  - une variable de type [mongoOpérationRemplacementUn](1410089166.md).
