# <Graphe>.Relief (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

Permet d'afficher un graphe en relief. Il suffit de spécifier la profondeur du relief voulu. Tous les types de graphes peuvent être affichés avec un relief.
Exemple de graphe en relief :

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
// Augmentation de la profondeur du relief du graphe GRF_MonGraphe
GRF_MonGraphe.Relief(7)
```

## Syntaxe

```wlangage
<Champ Graphe>.Relief(<Relief>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe manipulé présent dans l'éditeur de fenêtres, de pages ou d'états.
`<Relief>` *Entier*
> Profondeur du relief du graphe (en pixels). Pour que le graphe reste lisible, il est déconseillé de spécifier un relief trop important.
> Si ce paramètre est égal à 0, le graphe est affiché en deux dimensions (sans relief).

## Remarques

- Tous les types de graphes peuvent être affichés en relief.
- Les données définies avec la fonction **<Graphe>.Relief** seront prises en compte lors du prochain appel à la fonction [<Graphe>.Dessine](1000024062.md).
