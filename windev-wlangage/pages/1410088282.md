# <redisConnexion>.ExécuteCommande (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Exécute une commande sur un serveur Redis et récupère le résultat.
Nouveauté 2025
Cette fonction peut également être utilisée pour manipuler des données sur un serveur Valkey.

## Exemple

```wlangage
gRedis est un redisConnexion
gRedis.Serveur = "MonServeurRedis:7001"

// Exécution d'une commande utilisant des paramètres simples
r1 est un redisRéponse = gRedis.ExécuteCommande("SET MaClé MaValeur")

// Exécution d'une commande utilisant un paramètre avec espace
// et un paramètre de type buffer
r2 est un redisRéponse = gRedis.ExécuteCommande("SET", "Clé avec espace", bufImage)
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.ExecuteCommande(<Commande> [, <Paramètre 1> [... [, <Paramètre N>]]])
```

`<Résultat>` *Variable de type redisRéponse*
> Variable de type [redisRéponse](1000023534.md) contenant le résultat de l'exécution de la commande.
`<Connexion>` *Variable de type redisConnexion*
> Nom de la variable de type [redisConnexion](1000023527.md) correspondant à la connexion au serveur Redis.
`<Commande>` *Chaîne de caractères*
> Texte de la commande Redis à exécuter.
> Cette commande peut contenir des paramètres séparés par des espaces.
`<Paramètre 1>` *Type du paramètre optionnel*
> Premier paramètre optionnel de la commande. Ce paramètre permet de passer des chaînes contenant des espaces ou des valeurs binaires à la commande exécutée.
> Remarque : Les chaînes sont converties en UTF8 lors de l'envoi de la commande vers le serveur Redis.
`<Paramètre N>` *Type du paramètre optionnel*
> Nième paramètre de la commande. Ce paramètre permet de passer des chaînes contenant des espaces ou des valeurs binaires à la commande exécutée.
> Remarque : Les chaînes sont converties en UTF8 lors de l'envoi de la commande vers le serveur Redis.
