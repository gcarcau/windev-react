# <Variable Connexion>.SupprimeCollection (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Supprime une collection de procédures stockées d'un serveur HFSQL.

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion

// Supprimer la collection de procédures "GestionMail" du serveur
MaConnexion.SupprimeCollection(GestionMail)
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.SupprimeCollection(<Collection de procédures>)
```

`<Résultat>` *Booléen*
> - Vrai si la collection de procédures a été supprimée,
> - Faux dans le cas contraire. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion vers le serveur HFSQL contenant la collection de procédures à supprimer.
`<Collection de procédures>` *Chaîne de caractères*
> Nom de la collection de procédures à supprimer du serveur.

**Composante : wd300hf.dll**
