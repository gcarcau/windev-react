# JourDeLaSemaine (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **JourDeLaSemaine** permet de connaître et de modifier le jour de la semaine concerné par une planification. Cette propriété est utilisable sur :

- une variable de type [hTâchePlanifiée](1000017448.md).
- une variable de type [hPlanification](1000018853.md).
- une variable de type [Répétition](1000019262.md).
- une variable de type [serveurAppliTâchePlanifiée](1000022367.md).
