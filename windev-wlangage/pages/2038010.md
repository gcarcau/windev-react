# GDS : Enlever un projet

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Comment le faire ?

### Enlever un projet du gestionnaire de sources
Pour enlever un projet du gestionnaire de sources :

1. Ouvrez le projet.
2. Affichez la description du projet : sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description".
3. Dans l'onglet "GDS", sélectionnez l'option "Aucun GDS ou gestionnaire externe (GIT)".
4. Validez.

**Remarque** : Si vous cochez à nouveau l'option "Utiliser le GDS (seul ou à plusieurs)", le bouton "Paramètres" propose différentes options :

- Ajouter le projet dans une base de sources : Ouvre l'assistant d'import d'un projet dans une base de sources.
- Reconnecter le projet à sa base de sources : Reconnecte le projet à la base de sources lui correspondant.
