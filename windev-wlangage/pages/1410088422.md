# DiagrammeDégroupe (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Dissocie les différentes formes d'un groupe dans un champ Editeur de diagrammes.

## Exemple

```wlangage
// Si la sélection correspond à un groupe, dégroupe les formes de ce groupe
SI DiagrammeDégroupe(EDIAG_MonDiagramme) ALORS
	ToastAffiche("Groupement dissocié - CTRL+Z pour annuler")
FIN
```

## Syntaxe

```wlangage
<Résultat> = DiagrammeDégroupe(<Diagramme> [, <Groupe>])
```

`<Résultat>` *Booléen*
> - Vrai si les éléments du groupe ont été dissociés,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de détails sur l'erreur.
`<Diagramme>` *Nom de champ*
> Nom du champ Editeur de diagrammes à manipuler.
`<Groupe>` *Variable de type diagGroupe optionnelle*
> Nom de la variable de type [diagGroupe](1410088127.md) à manipuler. Si ce paramètre n'est pas précisée, le groupe sélectionné dans le champ Editeur de diagrammes est manipulé.

## Remarques

- Si le paramètre <Groupe> n'est pas une variable de type [diagGroupe](1410088127.md) ou si la sélection ne correspond pas à un groupe, la fonction **DiagrammeDégroupe** n'a aucun effet et renvoie Faux.
- La dissociation d'un groupe est annulable par l’utilisateur final (via le "undo") si le diagramme est en cours d’édition.

**Composante : wd300mdl.dll**
