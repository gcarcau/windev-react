# HDBCréation (Fonction)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Termine la description de la structure du fichier de données xBase par programmation. Le fichier de données qui vient d'être décrit est créé sur le disque dans le chemin indiqué dans la fonction [HDBDécritFichier](3044172.md). Les fichiers de données, mémos et d'index sont créés sur le disque.

## Exemple

```wlangage
HDBDécritFichier("CLIENTDB", "CD", "C:\FIC\CLIENT.DBF")
HDBDécritRubrique("NOM,C,20")
HDBDécritRubrique("PRENOM,C,20")
HDBDécritRubrique("AGE,N,3,0")
HDBDécritRubrique("SOLDE,N,10,2")
HDBDécritRubrique("MARIE,L")
HDBDécritRubrique("DATNAISS,D")
HDBDécritRubrique("INFOS,M")
HDBCréation()
```

## Syntaxe

```wlangage
<Résultat> = HDBCréation()
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.

## Remarques

### Création d'un fichier xBase via le Connecteur Natif xBase

- Les fichiers de données et d'index sont créés au format dBase 3 (fichier NDX).
- Après la fonction **HDBCréation**, le fichier peut être utilisé sans appeler les fonctions [HDBOuvre](3044163.md) et [HDBIndex](3044165.md).

### Création d'un fichier xBase

- Si le fichier existe déjà, il est écrasé par le nouveau fichier créé.
- Si le fichier est ouvert lors de l'appel de **HDBCréation**, une erreur 1009 sera générée.

### Création d'un fichier xBase sous l'éditeur d'analyses
Un fichier xBase peut également être décrit et créé depuis l'éditeur. Il est également possible d'importer sous l'éditeur d'analyses, un fichier xBase existant.

### Limitations
Cette fonction n'est pas disponible lors de l'utilisation d'un exécutable autonome.
