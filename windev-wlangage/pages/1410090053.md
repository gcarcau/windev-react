# ActionRapideAjoute (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

Ajoute une nouvelle action rapide à l'application. Cette action rapide apparaîtra dans le menu contextuel de l'icône de raccourci de l'application.

## Exemple

```wlangage
action est une ActionRapide
action.Identifiant = "ID_ACTION_ENVOI_MESSAGE"
action.Libellé = "Envoyer un message"
action.Procédure = ProcEnvoiMessage // ProcEnvoiMessage est une procédure globale
SI ActionRapideAjoute(action) ALORS
	ToastAffiche("Action ajoutée.")
FIN
```

## Syntaxe

```wlangage
<Résultat> = ActionRapideAjoute(<Action>)
```

`<Résultat>` *Booléen*
> - Vrai si l'action rapide a été ajoutée,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet de connaître le détail de l'erreur.
`<Action>` *Variable de type ActionRapide*
> Variable de type [ActionRapide](1410090054.md) décrivant l'action à ajouter.

## Remarques

- Si une action rapide avec le même identifiant a déjà été ajoutée pour l'application, elle sera mise à jour avec les informations contenues dans la variable [ActionRapide](1410090054.md) passée en paramètre.
- Pour lister les actions rapides déjà ajoutées pour l'application, utilisez la fonction [ActionRapideListe](1410090067.md).
- Pour supprimer une action rapide définie pour l'application, utilisez la fonction [ActionRapideSupprime](1410090064.md).
