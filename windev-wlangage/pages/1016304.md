# Manipuler un jour d'un champ Calendrier par programmation

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

WINDEV, WEBDEV et WINDEV Mobile permettent de manipuler par programmation :

- Un champ Calendrier. Pour plus de détails, consultez [Manipuler un champ Calendrier par programmation](1016301.md).
- Un jour d'un champ Calendrier.

## Comment le faire ?

### Programmation
Pour manipuler un jour d'un champ calendrier, il suffit d'utiliser la notation suivante :
```wlangage
<Champ Calendrier>[<Date à manipuler>]
```

Par exemple :

```wlangage
// Affiche la date sur fond rouge
CAL_Calendrier1["20120701"].CouleurFond = RougeClair
```

Plusieurs propriétés permettent de manipuler un jour d'un champ calendrier.
