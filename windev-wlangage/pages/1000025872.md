# Procédure WLangage appelée par la fonction SelectCouleur

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur)

Procédure WLangage Navigateur (également nommée "callback") exécutée par la fonction [SelectCouleur](3013045.md) lors de la fermeture de la popup de sélection de couleur.

## Exemple

```wlangage
// == Code de clic d'un bouton navigateur
// Sélection de la couleur en code Navigateur
SelectCouleur(RVB(42,56,99), SelectCouleur_Callback)
PROCÉDURE INTERNE SelectCouleur_Callback(coCouleur est une Couleur)
	CELL_SansNom1.CouleurFond = coCouleur
FIN
```

## Syntaxe

```wlangage
SelectCouleur_Callback(<Couleur>)
```

`<Couleur>` *Variable de type Couleur*
> Variable de type [Couleur](1000019661.md) correspondant à la couleur sélectionnée dans la popup de sélection de couleur.

**Composante : WDJS.DLL**
