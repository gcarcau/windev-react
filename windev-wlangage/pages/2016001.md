# Edition des styles d'élément WEBDEV du projet

> **Disponible :** **WEBDEV** (Windows, Linux, PHP)

## Présentation

WEBDEV offre la possibilité de gérer l'ensemble des styles d'élément WEBDEV utilisés dans un projet.
Il est possible de :

- éditer les styles d'élément WEBDEV d'un projet.
- définir les styles d'élément WEBDEV par défaut.

Nouveauté 2025
A partir de la version 2025 Update 1, le terme "Style d'élément WEBDEV" remplace le terme "Style CSS". Cette page prend en compte le nouveau vocabulaire.

## Editer les styles d'élément d'un projet

Pour éditer les styles d'élément WEBDEV d'un projet :

1. Sous le volet "Page", dans le groupe "Ambiance et styles", déroulez "Styles" et sélectionnez "Editer les styles d'élément WEBDEV et CSS externes".
2. La liste des styles d'élément présents dans le projet s'affiche. [image: Liste des styles d'élément WEBDEV]

Cette fenêtre présente :

- la liste des styles d'élément WEBDEV présents dans la feuille de style du projet. Ce sont par exemple les styles d'élément créés à partir du projet en cours.
- la liste des styles d'élément WEBDEV présents dans l'ambiance associée au projet.
  Rappel : ces styles d'élément ne sont pas modifiables.

Cette fenêtre permet de :

- Modifier le style d'élément sélectionné. Cette modification sera reportée sur tous les champs utilisant ce style d'élément.
- Créer un nouveau style d'élément vierge.
- Dupliquer le style d'élément sélectionné.
- Supprimer le style d'élément sélectionné. Dans ce cas, le style d'élément associé au champ sera le même mais sera dissocié : il sera local au champ.
- Voir les utilisations du style d'élément.

Remarque : Les styles d'élément WEBDEV présents dans l'ambiance du projet sont en lecture uniquement : ils ne peuvent pas être modifiés. Par contre, ils peuvent être dupliqués et le style dupliqué peut être modifié.

## Définir les styles d'élément par défaut

Les styles d'élément WEBDEV par défaut correspondent aux styles d'élément WEBDEV qui seront utilisés par défaut lors de la création d'un nouveau champ.
Pour un type de champ donné, s'il n'existe pas de style WEBDEV dans le projet, il est possible de définir un ou plusieurs styles d'élément par défaut (cela dépend du type de champ).

**Pour définir les styles d'élément par défaut d'un projet** :

1. Sous le volet "Page", dans le groupe "Ambiance et styles", déroulez "Styles" et sélectionnez "Définir les styles d'élément WEBDEV par défaut". La liste des champs et les styles disponibles s'affichent.[image: Liste des styles d'élément WEBDEV du projet]
2. Sélectionnez un type de champ. Selon le type de champ sélectionné, il est possible de voir la liste des styles proposés pour le champ ou non. Les styles peuvent être déplacés d'une liste à l'autre.
3. Dans la liste des styles proposés par défaut, sélectionnez le style à utiliser par défaut, et cochez la case "Style proposé par défaut".
4. Validez (bouton "OK").
