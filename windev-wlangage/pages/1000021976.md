# Constantes HDFS

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Afficher uniquement les constantes utilisées par les syntaxes préfixées
Afficher uniquement les constantes utilisées par les syntaxes non préfixées

Les constantes utilisées par les fonctions HDFS sont les suivantes :

| Constante | Description | Utilisée par les fonctions ou types de variables |
| --- | --- | --- |
| **hdfsDéfaut** | Options de copie ou de renommage : si le fichier destination existe déjà sur le serveur, il n'est pas écrasé. | [hdfsCopieVers](1000021679.md),  [hdfsRenomme](1000021676.md),  [hdfsSupprime](1000021674.md) |
| **hdfsEcraser** | - Options de copie : si le fichier destination existe déjà sur le serveur, il est remplacé par le fichier copié depuis la machine locale. - Options de renommage : si le fichier destination existe déjà, il est remplacé par le fichier renommé. | - [hdfsCopieVers](1000021679.md) - [hdfsRenomme](1000021676.md) |
| **hdfsFichier** | L'élément est un fichier. | Type [hdfsInformation](1000021973.md) |
| **hdfsLien** | L'élément est un lien vers un autre fichier. | Type [hdfsInformation](1000021973.md) |
| **hdfsRécursif** | L'élément est un lien vers un répertoire. | Type [hdfsInformation](1000021973.md) |
| **hdfsRépertoire** | Suppression : Les contenus du répertoire et des sous-répertoires sont également supprimés. | [hdfsSupprime](1000021674.md) |
