# RichEdit (Propriété)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **RichEdit** permet de gérer le type RTF (Rich Text Format) :

- d'un champ d'une fenêtre.
  **Rappel** : Le type RTF est une option des champs de saisie et des champs Libellé. Cette option est située dans l'onglet "Détail" de la description du champ.
- d'un champ Libellé d'un état.
  **Rappel** : Le type RTF est une option des champs Libellé. Cette option est située dans l'onglet "Général" de la description du champ.

Il est possible de :

- savoir si le champ est de type RTF.
- modifier le type RTF d'un champ.

## Exemple

```wlangage
// Si le champ Libellé "LIB_Nom" est de type RTF, il devient visible
SI LIB_Nom.RichEdit = Vrai ALORS
	LIB_Nom.Visible = Vrai
FIN
```

## Syntaxe

#### Savoir si le champ est de type RTF

```wlangage
<Résultat> = <Champ manipulé>.RichEdit
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié est de type RTF,
> - Faux dans le cas contraire.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler :
>
> - Champ de saisie ou champ Libellé dans une fenêtre.
> - Champ Libellé dans un état.

#### Modifier le type RTF d'un champ

```wlangage
<Champ manipulé>.RichEdit = <Type>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler :
>
> - Champ de saisie ou champ Libellé dans une fenêtre.
> - Champ Libellé dans un état.
`<Type>` *Booléen*
> - Vrai si l'élément spécifié doit être de type RTF,
> - Faux dans le cas contraire.

## Remarques

> _(WINDEV, Windows)_ Manipuler la valeur d'un champ RTFSi l'affectation (ou la lecture) est directe ou réalisée avec la propriété Valeur : la valeur du champ de type RTF est au format RTF (cette valeur contient des balises RTF).Si l'affectation (ou la lecture) est réalisée avec la fonction RTFVersTexte : la valeur du champ de type RTF n'est pas au format RTF (cette valeur ne contient pas de balises RTF).

### Limites
Dans une fenêtre, la propriété **RichEdit** s'applique uniquement aux champs suivants :

- champs de saisie,
- champs Libellé.
- colonne de table de type texte.

Dans un état, la propriété **RichEdit** s'applique uniquement aux champs Libellé.
