# Fonctions de gestion des champs Organigramme (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Les fonctions de gestion des champs Organigramme (via la syntaxe préfixée) sont les suivantes :

| [<Organigramme>.Affiche](1000019974.md) | Réinitialise le contenu d'un champ Organigramme à partir de sa source de données (fichier de données HFSQL par exemple). |
| --- | --- |
| [<Organigramme>.Ajoute](1000019975.md) | Ajoute un nouvel élément "racine" dans un champ Organigramme. |
| [<Organigramme>.AjouteFils](1000019976.md) | Ajoute un élément fils dans un champ Organigramme. |
| [<Organigramme>.InfoXY](1000019977.md) | Renvoie l'indice de l'élément se trouvant à une position donnée dans le champ Organigramme. |
| [<Organigramme>.Modifie](1000019978.md) | Modifie un élément dans un champ Organigramme. |
| [<Organigramme>.Occurrence](1000019979.md) | Renvoie le nombre d'éléments présents dans un champ Organigramme. |
| [<Organigramme>.SauveImage](1000019980.md) | Crée une image représentant la totalité d'un champ Organigramme. |
| [<Organigramme>.Select](1000019981.md) | Renvoie l'indice de l'élément sélectionné dans un champ Organigramme. |
| [<Organigramme>.SelectMoins](1000019982.md) | Dé-sélectionne un élément dans un champ Organigramme. |
| [<Organigramme>.SelectPlus](1000019983.md) | Sélectionne un élément dans un champ Organigramme. |
| [<Organigramme>.Supprime](1000019984.md) | Supprime un élément et l'ensemble de ses "fils" d'un champ Organigramme. |
| [<Organigramme>.SupprimeTout](1000019985.md) | Supprime tous les éléments d'un champ Organigramme. |
