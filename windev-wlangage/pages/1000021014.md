# PageVisible (Fonction)

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur)

Indique si la page est visible pour l'utilisateur.

## Exemple

```wlangage
// Page visible ? Oui => on l'initialise
SI PageVisible() ALORS Initialise()
```

## Syntaxe

```wlangage
<Résultat> = PageVisible()
```

`<Résultat>` *Booléen*
> - Vrai si la page est visible pour l'utilisateur,
> - Faux dans le cas contraire.

**Composante : WDJS.DLL**
