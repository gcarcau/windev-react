# CarteConfigureAPIGgl (Fonction)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP)

Déclare des paramètres supplémentaires pour le champ Carte qui seront transmis à l'API Google.
Cette fonction permet notamment de manipuler des librairies supplémentaires de fonctions, non disponibles dans le champ Carte par défaut. Ces fonctions seront disponibles en code navigateur dans l'objet natif JavaScript retourné par la fonction [CarteRécupèreObjetJS](1000021474.md).

> _(WINDEV)_ Attention : Cette fonction doit être utilisée dans le code d'initialisation du projet. Si cette fonction est utilisée dans un traitement différent, elle n'aura aucun effet.

## Exemple

```wlangage
// Code fonctionnant jusqu'à la version 2025 Update 1
// CarteConfigureAPIGgl("libraries=geometry,places","language=fr")
// Code fonctionnant à partir de la version 2025 Update 2
CarteConfigureAPIGgl("libraries=geometry,marker,places","language=fr")
```

## Syntaxe

```wlangage
CarteConfigureAPIGgl(<Paramètre 1> [, <Paramètre 2> [... [, <Paramètre N>]]])
```

`<Paramètre 1>` *Chaîne de caractères*
> Premier paramètre transmis à l'API. Le paramètre est de la forme Nom=Valeur.
`<Paramètre 2>` *Chaîne de caractères optionnelle*
> Second paramètre optionnel transmis à l'API. Le paramètre est de la forme Nom=Valeur.
`<Paramètre N>` *Chaîne de caractères optionnelle*
> Dernier paramètre optionnel transmis à l'API. Le paramètre est de la forme Nom=Valeur.

## Remarques

- La configuration est globale au projet. Chaque appel de la fonction remplace les paramètres précédemment définis.
- Si la fonction est appelée sans paramètres, les paramètres précédemment définis sont effacés et aucun paramètre n'est transmis à l'API.
- Si la valeur transmise est invalide, le champ Carte peut ne pas fonctionner.
- Nouveauté 2025
  Attention : Certaines API Google ont été dépréciées. Les fonctions de gestion des champs Carte ont été mises à jour. Si vous utilisez la fonction **CarteConfigureAPIGgl**, pensez à vérifier son fonctionnement et à faire des adaptations si nécessaires.
