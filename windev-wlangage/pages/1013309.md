# Manipuler une barre d'outils par programmation (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows)

## Présentation

WINDEV permet de manipuler un champ Barre d'outils directement par programmation. Il suffit d'utiliser directement la variable du champ "Barre d'outils" dans le code.
La variable du champ Barre d'outils correspond au nom de la barre d'outils. Cette variable n'a aucune valeur.

## Manipuler les champs présents dans un champ Barre d'outils

Les champs présents dans la barre d'outils sont accessibles :

- soit comme tous les champs, en utilisant directement leur nom.
- soit en précisant le nom du champ Barre d'outils puis le nom du champ. Par exemple :
  ```wlangage
  Barre1.Bouton1
  ```

**Remarque** : les propriétés de taille et de position des champs présents dans la barre d'outils ne sont accessibles qu'en lecture.

## Comment fermer un champ Barre d'outils flottant ?

Pour fermer un champ Barre d'outils flottant en utilisant la croix, il faut utiliser la ligne de code suivante dans l'événement "Fermeture" du champ Barre d'outils :

```wlangage
MoiMême..Visible = Faux
```

**Attention** : Il est déconseillé d'utiliser la fonction [Ferme](3038018.md). En effet, cette fonction ferme la fenêtre et non le champ Barre d'outils.

## Fonctions spécifiques à la manipulation de champs Barre d'outils

Les fonctions suivantes sont spécifiques à la manipulation du champ Barre d'outils par programmation :

| [<Barre d'outils>.Attache](3020006.md) | Ancre un champ Barre d'outils à la fenêtre ou change la position d'ancrage d'un champ Barre d'outils ancré. |
| --- | --- |
| [<Barre d'outils>.Détache](3020008.md) | Transforme un champ Barre d'outils ancré en champ Barre d'outils flottant. |
| [<Barre d'outils>.Position](3020007.md) | Indique le mode d'affichage d'un champ Barre d'outils. |

## Propriétés spécifiques à la gestion d'un champ Barre d'outils

Les propriétés suivantes sont spécifiques à la gestion des caractéristiques d'un champ Barre d'outils par programmation :

| [Hauteur](2510050.md) | Permet de connaître la hauteur d'un champ Barre d'outils. |
| --- | --- |
| [HauteurInitiale](2510043.md) | Permet de connaître la hauteur de création d'un champ Barre d'outils. |
| [Largeur](2510059.md) | Permet de connaître et de modifier la largeur d'un champ Barre d'outils. |
| [LargeurInitiale](2510067.md) | Permet de connaître la largeur de création d'un champ Barre d'outils. |

Pour connaître la liste complète des propriétés du WLangage pouvant être utilisées avec un champ de type Barre d'outils, consultez [Propriétés associées au champ Barre d'outils](1013124.md).
