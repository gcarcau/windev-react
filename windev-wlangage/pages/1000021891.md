# <Table hiérarchique>.AjouteFils (Fonction)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

Ajoute une ligne dans un champ Table hiérarchique, à la fin d'un niveau de hiérarchie donné.

## Exemple

```wlangage
// Ajoute une racine "Desserts" au champ Table hiérarchique TABLEH_Recette
TABLEH_Recette.AjouteFils(Null, "Desserts")

// Ajoute une feuille "Glaces" sous le noeud "Desserts"
TABLEH_Recette.AjouteFils("Desserts", "Glaces")
```

## Syntaxe

#### Ajouter une ligne en spécifiant l'indice de l'élément parent

```wlangage
<Résultat> = <Champ Table hiérarchique>.AjouteFils(<Indice de l'élément parent> [, <Élément colonne 1> [... [, <Élément colonne N>]]])
```

`<Résultat>` *Entier*
> - Indice de la ligne ajoutée,
> - -1 en cas d'erreur.
`<Champ Table hiérarchique>` *Nom de champ*
> Nom du champ Table hiérarchique à manipuler.
`<Indice de l'élément parent>` *Entier*
> Indice de la ligne parente dans la hiérarchie ou constante *NULL* pour ajouter la ligne à la racine du champ Table hiérarchique (dans ce cas, le fonctionnement est le même que celui de la fonction [<Table>.AjouteLigne](1000023404.md)).
`<Élément colonne 1>` *Type de la colonne associée (optionnel)*
> Éléments de la ligne à ajouter dans le champ Table hiérarchique spécifié. Chaque élément correspond à une colonne du champ. Le type de l'élément ajouté doit être compatible avec le type de la colonne concernée.
>
> Si aucun paramètre n'est spécifié, une ligne vide est ajoutée dans le champ Table hiérarchique.
`<Élément colonne N>` *Type de la colonne associée (optionnel)*
> Éléments de la ligne à ajouter dans le champ Table hiérarchique spécifié. Chaque élément correspond à une colonne du champ. Le type de l'élément ajouté doit être compatible avec le type de la colonne concernée.
>
> Si aucun paramètre n'est spécifié, une ligne vide est ajoutée dans le champ Table hiérarchique.

#### Ajouter une ligne en spécifiant l'élément parent

```wlangage
<Résultat> = <Champ Table hiérarchique>.AjouteFils(<Élément parent> [, <Élément colonne 1> [... [, <Élément colonne N>]]])
```

`<Résultat>` *Entier*
> - Indice de la ligne ajoutée,
> - -1 en cas d'erreur.
`<Champ Table hiérarchique>` *Nom de champ*
> Nom du champ Table hiérarchique à manipuler.
`<Élément parent>` *Chaîne de caractères*
> Contenu de la première colonne de l'élément parent dans le champ Table hiérarchique. Ce paramètre est de la forme :
>
>
> ```wlangage
> "<Nom de la racine>" + TAB + ["<Nom du 1er noeud>" + TAB + ...["<Nom du 2ème noeud>" + TAB + [...]]]"<Nom de la feuille>"
> ```
`<Élément colonne 1>` *Type de la colonne associée (optionnel)*
> Éléments de la ligne à ajouter dans le champ Table hiérarchique spécifié. Chaque élément correspond à une colonne. Le type de l'élément ajouté doit être compatible avec le type de la colonne concernée.
> Si aucun paramètre n'est spécifié, une ligne vide est ajoutée dans le champ Table hiérarchique.
`<Élément colonne N>` *Type de la colonne associée (optionnel)*
> Éléments de la ligne à ajouter dans le champ Table hiérarchique spécifié. Chaque élément correspond à une colonne. Le type de l'élément ajouté doit être compatible avec le type de la colonne concernée.
> Si aucun paramètre n'est spécifié, une ligne vide est ajoutée dans le champ Table hiérarchique.
