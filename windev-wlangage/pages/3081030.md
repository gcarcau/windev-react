# XMLSuivant (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Positionne sur l'élément suivant (balise ou attribut).
**Si aucune recherche est en cours** : positionne sur l'élément suivant l'élément en cours dans l'arborescence.

**Si une recherche est en cours :** positionne sur l'élément suivant recherché.

> _(PHP)_ Les commentaires XML (entourés des balises "<!-" et "-->") ne sont pas pris en compte.

> _(Android, Widget Android, Java)_ Les parcours sont effectués dans l'ordre alphabétique des attributs.

## Exemple

```wlangage
// Cas 1 : sans recherche
XMLPremier("DocXML")
TANTQUE XMLEnDehors("DocXML") = Faux
	// Traitements des données
	XMLSuivant("DocXML")
FIN
```

```wlangage
// Cas 2 : avec recherche
XMLRecherche("DocXML", "balise")
TANTQUE XMLTrouve("DocXML") = Vrai
	// Traitements des données
	XMLSuivant("DocXML")
FIN
```

## Syntaxe

```wlangage
<Résultat> = XMLSuivant(<Document XML>)
```

`<Résultat>` *Booléen*
> - Vrai si un élément a été trouvé,
> - Faux dans le cas contraire. En cas d'erreur :
>   - la position courante reste inchangée.
>   - la variable [ErreurDétectée](3087001.md) est à Vrai. Pour obtenir plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Document XML>` *Chaîne de caractères*
> Nom du document XML manipulé. Ce document contient le code XML à analyser et a été créé avec la fonction [XMLDocument](3081008.md).

## Remarques

### Manipulation des éléments dans le code XML
Après la fonction **XMLSuivant**, l'élément en cours peut être manipulé avec les fonctions [XMLNomElément](3081026.md), [XMLNomParent](3081035.md), [XMLTypeElément](3081031.md) et [XMLDonnée](3081004.md).

### Fonctions XML et threads
Si votre application utilise des threads, le document XML est partagé entre tous ces threads. Pour plus de détails sur la gestion des threads, consultez [Gestion des threads](3077026.md).
Si la position courante dans un document XML est modifiée dans un thread, la position courante dans ce document XML est modifiée pour tous les threads.

**Composante : wd300xml.dll**
