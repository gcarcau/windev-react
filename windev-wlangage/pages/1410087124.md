# 13. Les différents types de champs standard

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

| [Page précédente](1410087123.md) | [Sommaire](1410087102.md) | [Page suivante](1410087125.md) |
| --- | --- | --- |

| Vous voulez... | Utilisez... |
| --- | --- |
| Afficher du texte, un titre, etc. | Champ Libellé |
| Proposer un libellé avec une mise en page spécifique (images, liens, etc.). | Champ Zone de texte riche |
| Définir une zone de couleur. | Champ Cellule, Tableau HTML |
| Afficher un prix, une quantité, une adresse, une date, une heure, etc. | Champ d'affichage formaté |
| Sélectionner une valeur parmi une liste (pays, ville, couleur, etc.). | Champ Sélecteur, Champ Combo,  Champ Liste |
| Sélectionner plusieurs valeurs parmi une liste (les destinataires d'un message, des fichiers à télécharger, etc.). | Champ Interrupteur, Champ Liste |
| Afficher une animation (Gif animé). | Champ Image |
| Afficher une page selon la zone cliquée sur une image. | Champ Image (avec zones de clic) |
| Utiliser un code HTML existant. | Champ HTML |
| Afficher une image graphique (photo, etc.). | Champ Image |
| Retoucher ou modifier les images ou les photos affichées dans un site. | Champ Editeur d'images |
| Utiliser une applet Java (horloge, etc.). | Champ Java |
| Afficher le contenu d'un fichier de données en table (liste des clients, détail d'une commande, etc.). | Champ Table fichier ou Champ Table par programmation, Champ Zone répétée fichier ou champ Zone répétée par programmation |
| Afficher une image rafraîchie régulièrement. | Champ Web Caméra |
| Répéter des champs dans une page (catalogue Produits avec la photo, etc.). | Champ Zone répétée |
| Saisir des informations. | Champ de saisie |
| Afficher des informations hiérarchisées (contenu d'un répertoire, etc.). | Champ Arbre |
| Aligner des champs (tableau HTML). | Champ Cellule, Tableau HTML |
| Programmer une action dans une page (afficher une page, valider une saisie, etc.). | Champ Bouton, Champ Lien |
| Afficher une vidéo. | Champ Vidéo |
| Afficher une page d'un autre site dans une de vos pages. | Champ IFrame |
| Sélectionner et afficher une date sur un calendrier. | Champ Calendrier |
| Afficher les rendez-vous sous forme de planning ou d'agenda. | Champ Planning, Champ Agenda |
| Classer visuellement les tâches. | Champ Kanban |
| Afficher un histogramme, une courbe, un graphe de type Camembert. | Champ Graphe |
| Afficher une page de votre site à l'intérieur d'une de vos pages. | Page Interne |
| Afficher un menu automatique (qui se construit au fur et à mesure du parcours du site). | Champ Chemin de navigation |
| Permettre à l'internaute de donner ou de visualiser une note. | Champ Notation |
| Afficher des vignettes d'images. | Champ Vignette |
| Afficher un ensemble d'images sous forme de galerie. | Champ Zone répétée de type galerie |
| Enrouler / Dérouler une zone d'affichage | Champ Tiroir |
| Uploader un ou plusieurs fichiers. | Champ Upload |
| Afficher successivement plusieurs contenus. | Champ Bandeau défilant |
| Afficher le plan d'une salle (de concert, de restaurant, ...) pour permettre une réservation interactive. | Champ Editeur de diagrammes |
| Afficher un tableau de bord affichant des informations différentes sous forme de vignettes. | Champ Tableau de bord |
| Afficher une liste d'objets sous forme de liste horizontale défilante. | Champ Zone répétée linéaire |
| Utiliser des ressources externes disponibles sur Internet (composants Angular JS, snippets Bootstrap, etc.). | Champ Composant Web |
| Créer un effet visuel dans une page en présentant une image partiellement recouverte par une autre. | Champ Page cornée |
