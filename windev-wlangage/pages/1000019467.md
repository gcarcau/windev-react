# Fonctions Captcha

> **Disponible :** **WEBDEV** (Windows, Linux, PHP)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions Captcha (syntaxe préfixée)](1000019584.md)).
Les fonctions permettant de manipuler les champs Captcha sont les suivantes :

| [CaptchaAffiche](1000019389.md) | Affiche un nouveau Captcha dans un champ Captcha. |
| --- | --- |
| [CaptchaVérifie](1000019390.md) | Vérifie si la valeur saisie par l'utilisateur correspond à la chaîne affichée dans un champ Captcha. |

Il est consultable par tous, et chacun peut y apporter des commentaires. L'auteur du blog écrit ses messages lorsqu'il le souhaite. Il est possible de mettre en forme le texte, d'inclure des images, des citations, etc... Cet exemple est basé sur une génération AWP, ce qui permet entre autres de pouvoir référencer le site dans tous les moteurs de recherche. De plus, le blog peut être exporté en RSS.
