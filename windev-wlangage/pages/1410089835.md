# JourEnCours (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Renvoie le numéro du jour en cours dans le mois courant.
Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.

## Exemple

```wlangage
nJour est un entier

// Si la date courante est : "03/04/2023"
nJour = JourEnCours() // nJour vaut 3

// Si la date courante est : "27/07/2048"
nJour = JourEnCours() // nJour vaut 27
```

## Syntaxe

```wlangage
<Résultat> = JourEnCours()
```

`<Résultat>` *Entier*
> Jour en cours dans le mois courant.

## Remarques

Les codes suivants sont équivalents :

```wlangage
dDate est une Date = DateDuJour()
```

et

```wlangage
nJour est un entier
nJour = dDate.Jour
```

**Classification Métier / UI : Code neutre**

**Composante : wd300std.dll**
