# EmailDossierCourant (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie le nom du dossier en cours dans le logiciel de messagerie (Outlook, logiciel de messagerie utilisant le protocole IMAP (Internet Message Access Protocol), ...). Ce dossier est présent dans la branche "Dossiers personnels".

## Exemple

```wlangage
// Protocole IMAP
MaSession est une emailSessionIMAP
...
// Création d'un dossier dans le dossier en cours
EmailAjouteDossier(MaSession, EmailDossierCourant(MaSession) + "\Travail")

// Création d'un dossier dans le dossier personnel
EmailAjouteDossier(MaSession, "Dossiers personnels\Boîte de réception\TravailPerso")
```

> _(WINDEV, WEBDEV - Code Serveur)_ // Ouverture de la session Outlook
IDSession = EmailOuvreSessionOutlook("MonProfil")
...
// Création d'un dossier dans le dossier en cours
EmailAjouteDossier(IDSession, EmailDossierCourant(IDSession) + "\Travail")

// Création d'un dossier dans le dossier personnel
EmailAjouteDossier(IDSession, "Dossiers personnels\Boîte de réception\TravailPerso")

## Syntaxe

```wlangage
<Résultat> = EmailDossierCourant(<Session>)
```

`<Résultat>` *Chaîne de caractères*
> - Nom du dossier en cours,
> - Chaîne vide ("") en cas d'erreur. En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Session>` *Chaîne de caractères, Entier ou variable de type emailSessionOutlook ou emailSessionIMAP*
> Identifiant de la session email en cours. Cet identifiant peut être :
>
> - un entier renvoyé par la fonction [EmailOuvreSessionOutlook](3032128.md) ou [OutlookOuvreSession](3032123.md).
> - une variable de type [emailSessionOutlook](1000018767.md).
> - une variable de type [emailSessionIMAP](1000018957.md).
> - le nom d'utilisateur passé à la fonction [EmailOuvreSessionIMAP](1000019189.md).
