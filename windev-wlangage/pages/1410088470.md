# diagExtrémité (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Le type **diagExtrémité** permet de définir toutes les caractéristiques avancées d'une extrémité d'un lien entre 2 formes d'un diagramme. Les caractéristiques de cette extrémité peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Crée une liaison entre rect1 et rect2
rect1 est un diagRectangle
rect2 est un diagRectangle
Lien est un diagLien

Lien.Départ.PointDAttache = rect1.PointDAttache(100, 50)
Lien.Départ.Dessin = formeAucune
Lien.Arrivée.PointDAttache = rect2.PointDAttache(0, 50)
Lien.Départ.Dessin = formeTriangle
```

## Propriétés

### Propriétés spécifiques à la description des variables de type diagExtrémité
Les propriétés suivantes peuvent être utilisées pour manipuler l'extrémité d'un lien :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Dessin | Constante de type Entier | Dessin de la flèche :   - *formeAucune* : L'extrémité n'a pas de forme particulière. - *formeCarré* : L'extrémité est un carré. - *formeCarréArrondi* : L'extrémité est un carré arrondi. - *formeFlèche* : L'extrémité est une flèche. - *formeLosange* : L'extrémité est un losange. - *formeRond* : L'extrémité est un rond. - *formeTriangle* : L'extrémité est un triangle. |
| Destination | Constante de type Entier | Position de l'extrémité du lien sur la forme destination :   - *lienDestinationAuto* : La position de l'extrémité du lien est déterminée automatiquement selon la position du lien et de la forme. - *lienDestinationForme* : La position de l'extrémité du lien est situé au milieu de la forme. - *lienDestinationPointDAttache* : La position de l'extrémité du lien correspond à un point d'attache. - *lienDestinationRectangleEnglobant* : La position de l'extrémité du lien correspond à un point du rectangle englobant la forme. |
| PointDAttache | [diagPointDAttache](1410088457.md) | Point d'attache du lien. |
| X | Réel | Position de l'extrémité (X) dans le diagramme. |
| Y | Réel | Position de l'extrémité (Y) dans le diagramme. |
