# iLien (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Ajoute un lien sur une adresse URL dans la page HTML en cours d'impression.
**Remarque** : La fonction **iLien** n'a aucun effet si l'impression n'est pas réalisée dans un fichier HTML.

## Exemple

```wlangage
iDestination(iHTMLCSS, "MaPage")
iImprime("Sur la ligne suivante, un lien vers une page")
iLien("Tout savoir sur WINDEV", "http://www.pcsoft.fr")
iFinImprime()
```

## Syntaxe

```wlangage
<Résultat> = iLien(<Libellé du lien> , <Adresse URL> [, <Navigateur en cours>])
```

`<Résultat>` *Booléen*
> - Vrai si le lien a été imprimé,
> - Faux dans le cas contraire.
`<Libellé du lien>` *Chaîne de caractères*
> Texte du lien. Ce texte sera affiché dans la page HTML sous forme de lien.
`<Adresse URL>` *Chaîne de caractères*
> Adresse de la page à lancer. Cette page sera automatiquement ouverte lorsque l'utilisateur cliquera sur le <Libellé du lien>.
`<Navigateur en cours>` *Booléen optionnel*
> - Vrai (valeur par défaut) : la page est ouverte dans le navigateur en cours.
> - Faux : la page est ouverte dans un nouveau navigateur.

## Remarques

### Impression d'une URL
Un saut de ligne est automatiquement généré après le libellé du lien. Le curseur est positionné sur la ligne suivante. Le passage à la ligne suivante tient compte de la hauteur de la ligne courante. Cette hauteur dépend de la hauteur de la police utilisée.
