# Polyligne2D (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Le type **Polyligne2D** permet de définir toutes les caractéristiques avancées d'une polyligne en 2 dimensions. Les caractéristiques de cette polyligne en deux dimensions peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Caractéristiques d'une polyligne en 2 dimensions** :

Une polyligne en 2 dimensions est un ensemble de segments du plan en deux dimensions qui se suivent. Elle est définie par une suite de points. En mathématiques, le terme utilisé est "ligne polygonale".

Si le dernier point d'une polyligne est identique au premier point, la polyligne est dite "fermée".
Si les différents segments de la polyligne ne se coupent pas les uns les autres, la polyligne est dite "simple".
Une polyligne simple **et** fermée s'appelle un "anneau" (ou "LinearRing" en anglais).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
MaLigne est une Polyligne2D

// Ajout de points dans la polyligne
// 1. Syntaxe classique
Polyligne2DAjoutePoint(MaLigne, 31, 21)
// 2. Syntaxe préfixée
MonPoint est un Point2D
MonPoint.X = 31
MonPoint.Y = 21
MaLigne.Point.Ajoute(MonPoint)
```

```wlangage
MaLigne est une Polyligne2D

// Ajout de points dans la polyligne
// 1. Syntaxe classique
Polyligne2DAjoutePoint(MaLigne, 32, 22)
Polyligne2DAjoutePoint(MaLigne, 134, 12)

// 2. Syntaxe préfixée
MaLigne.AjoutePoint(32, 22)
MaLigne.AjoutePoint(134, 12)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type Polyligne2D
Les propriétés suivantes peuvent être utilisées pour manipuler une polyligne en 2 dimensions :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Point | Tableau de [Point2D](1410090100.md) | Points de la polyligne. |
| Type | Constante de type Entier | Type de la géométrie en cours. Dans le cas d'une polyligne en 2 dimensions, correspond à la constante *tgPolyligne2D*. Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfPolyligne2D*. **Cette propriété est disponible en lecture uniquement.** |
