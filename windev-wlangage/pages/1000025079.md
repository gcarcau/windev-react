# <Source>.VérifieMémo (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Vérifie l'intégrité structurelle des mémos d'un fichier de données HFSQL.
Nouveauté Abonnement

> _(HFSQL Client/Serveur)_ L'intégrité structurelle des mémos d'un fichier de données HFSQL Client/Serveur peut être vérifiée de manière asynchrone grâce à la fonction <Connexion HFSQL>.VérifieMémoAsynchrone. Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2. Pour plus de détails, consultez Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement.

## Exemple

```wlangage
SI Client.VérifieMémo(JAUGE_Jauge1) <> "" ALORS
	Info("Mémo corrompu")
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Source>.VérifieMémo([<Jauge>])
```

`<Résultat>` *Chaîne de caractères*
> - Chaîne vide ("") s'il n'y a aucun problème.
> - En cas de problème, chaîne de la forme :
>   ```wlangage
>   <Rubrique 1> + TAB + <Numéro d'enregistrement 1> + RC + ...<Rubrique N> + TAB + <Numéro d'enregistrement N>
>   ```
>    où :
>   - <Rubrique X> est la rubrique mémo,
>   - <Numéro d'enregistrement> est le numéro de l'enregistrement contenant la rubrique Mémo.
> - En cas de corruption de la liste des blocs libres, <Résultat> sera de la forme :
>   ```wlangage
>   <TAB> + "-1"+ RC + <Rubrique 1> + TAB + <Numéro d'enregistrement 1> + RC + ...<Rubrique N> + TAB + <Numéro d'enregistrement N>
>   ```
`<Source>` *Type correspondant à la source spécifiée*
> Nom du fichier de données HFSQL à vérifier.
`<Jauge>` *Nom de fenêtre ou nom de champ optionnel*
> - Nom de la fenêtre dans laquelle la jauge doit être affichée.
> - Nom du champ de type Jauge affichant la progression.
>
>
> > _(WEBDEV - Code Serveur)_ Ce paramètre n'est pas pris en compte.

## Remarques

- La vérification de la liste des blocs libres est effectuée uniquement en HFSQL Client/Serveur.
- La fonction **<Source>.VérifieMémo** est plus rapide que la fonction [<Source>.Réindexe](1000025060.md) utilisée avec la constante *hVérifieMémo*.
- Si un problème est détecté, il est possible d'utiliser la fonction [<Source>.Réindexe](1000025060.md) avec la constante *hVérifieMémo*.
- A partir de la version 27, la vérification du mémo est améliorée et approfondie, ce qui peut entraîner un allongement des durées de traitement.
