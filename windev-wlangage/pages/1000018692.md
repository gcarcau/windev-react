# Fichier (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **Fichier** permet de gérer les fichiers pris en compte par une fonctionnalité. Cette propriété est utilisable sur :

- une variable de type [xlsDocument](1000017464.md).
- une variable de type [hOptimisationPlanifiée](1000018854.md).
- une variable de type [zipArchive](1000018679.md).
- une variable de type [hRSConfig](1000020484.md).
- Nouveauté SaaS
  une variable de type [hHistoriqueRéindexation](1410091059.md).

Remarque : Le mot-clé **Fichier** peut aussi correspondre à une [Description de Fichier](1514065.md).
