# Store Privé : Une méthode pour changer de serveur

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Le Store Privé regroupe les installations des applications et des sites au sein de l'entreprise.
En cas de changement du serveur (machine) qui héberge le Store Privé, comment conserver la configuration de ce Store Privé ?
La procédure à suivre en 6 points.

## Procédure à suivre

### 1. Le serveur HFSQL du Store Privé
Le Store Privé a besoin de 2 éléments pour fonctionner :

- un serveur HFSQL,
- un serveur d'application proposant les services BaaS.

Lorsque le serveur HFSQL utilisé par le Store Privé est hébergé sur la même machine serveur que le serveur d'application proposant les services BaaS, il est nécessaire de sauvegarder ce serveur HFSQL. Il pourra ainsi être restauré à l'identique sur la nouvelle machine serveur.

Si le serveur HFSQL utilisé par le Store Privé est hébergé sur une autre machine, consultez directement **l'étape 4**.

### 2. Sauvegarde du serveur HFSQL
Pour sauvegarder le serveur HFSQL Client/Serveur utilisé par le Store Privé, utilisez le Centre de Contrôle HFSQL :

1. Lancez le Centre de Contrôle HFSQL.
2. Sélectionnez le serveur HFSQL dans l'arborescence à gauche.
3. Dans l'onglet "Sauvegardes" du ruban, cliquez sur "Nouvelle sauvegarde".
4. Indiquez le contenu de la sauvegarde, option "Tout le contenu du serveur (toutes les bases de données, ainsi que la base système)".

### 3. Restauration de la sauvegarde HFSQL
Sur la nouvelle machine serveur :

1. Installez tout d'abord un serveur HFSQL.
  L'installation du serveur HFSQL est disponible dans le sous-dossier "Install\HFSQL Server" de WINDEV.
2. Lancez le Centre de Contrôle HFSQL.
3. Restaurez ensuite la sauvegarde réalisée : depuis l'onglet "Sauvegardes", cliquez sur "Restaurer".

### 4. Installation du Serveur d'application avec les services BaaS
Sur la nouvelle machine serveur :

1. Installez un serveur d'application avec les services BaaS. Pour plus de détails, consultez [Installation des services BaaS](1000021311.md).
2. À l'étape "WDBaaS : serveur HFSQL", dans la majorité des cas, les paramètres de connexion HFSQL Client/Serveur restent inchangés et correspondent à ceux utilisés auparavant. En effet, soit le serveur HFSQL était hébergé sur l'ancienne machine serveur et a donc été sauvegardé puis restauré (étapes 2 et 3), soit le serveur HFSQL est hébergé sur une machine tierce (donc pas de changement).

### 5. Token de connexion
Le déploiement des applications WINDEV Mobile dans le Store Privé nécessite un token de connexion.
Ce token est indiqué à la fin de l'installation du serveur d'application avec les services BaaS. Le fait d'installer un nouveau serveur BaaS modifie donc ce token de connexion.

Pour conserver l'ancien token :

1. Sur l'ancienne machine serveur, accédez au fichier de configuration du serveur BaaS : "GPUConnexion.default.xml".
2. Copiez le contenu de la balise <token>.
3. Sur la nouvelle machine, accédez au fichier de configuration du serveur BaaS et recopiez ces caractères.

**Note** : Selon la version du Serveur BaaS, le fichier "GPUConnexion.default.xml" peut se trouver dans :

- le répertoire "C:\ProgramData\WDBaaS",
- le répertoire racine des comptes, par défaut : "c:\sites\Data_WDBaaS\". Ce répertoire racine est renseigné dans le Centre de Contrôle d'Hébergement WEBDEV.

### 6. Dernière étape : Un peu de résau ...

- **S'il s'agissait d'un serveur utilisé en interne dans un intranet via son nom de machine ou adresse IP**, stoppez l'ancien serveur puis reconfigurez le nouveau pour qu'il porte le même nom et / ou adresse.
- **S'il s'agissait d'un serveur utilisé par Internet**, au choix en fonction des besoins, stoppez l'ancien serveur puis reconfigurez le nouveau pour qu'il réponde à la même adresse que le précédent ou modifiez la configuration du domaine qui permet d'accéder au serveur, afin d'aller vers l'adresse du nouveau serveur.
