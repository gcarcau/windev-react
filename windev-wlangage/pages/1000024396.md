# PanneauActive (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Rend un panneau actif lorsque plusieurs panneaux sont dockés entre eux.

## Exemple

```wlangage
// Tableau permettant de connaître le nombre d'erreurs
tabErreurs est un tableau d'entier
...
// Force l'affichage du panneau des erreurs si au moins 1 erreur
SI tabErreurs.Occurrence > 0 ALORS
	PanneauActive(PADO_Erreurs)
FIN
```

## Syntaxe

```wlangage
<Résultat> = PanneauActive(<Champ Panneau dockable>)
```

`<Résultat>` *Booléen*
> - Vrai si le panneau a été affiché,
> - Faux dans le cas contraire (le panneau est déjà actif ou le panneau n'est pas docké avec d'autres panneaux).
`<Champ Panneau dockable>` *Nom de champ*
> Champ Panneau dockable à manipuler.

**Composante : wd300obj.dll**
