# <Liste>.Affiche (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

Rafraîchit l'affichage d'un champ Liste, Liste image ou Combo fichier. Pour un champ Liste, Liste image ou Combo par programmation, le rafraîchissement est automatique.
> _(WINDEV, WINDEV Mobile)_ Ce rafraîchissement peut être réalisé à partir d'un position donnée.
**Remarque** : La fonction **<Liste>.Affiche** peut être utilisée indifféremment sur les listes monosélection et multisélections.

## Exemple

```wlangage
// Rafraîchissement du champ "LISTE_ListeClient"
LISTE_ListeClient.Affiche()
```

> _(WINDEV, Etats et Requêtes, Android, Java, Code Utilisateur (MCU))_ // Rafraîchissement du champ "LISTE_ListeClient" à partir du début du champ Liste
LISTE_ListeClient.Affiche(taDébut)

## Syntaxe

```wlangage
<Champ Liste>.Affiche([<Position>])
```

`<Champ Liste>` *Nom de champ*
> Nom du champ Liste (Liste image ou Combo) fichier à rafraîchir.
`<Position>` *Entier ou constante (optionnel)*
> Indique la position de départ du rafraîchissement. Ce paramètre peut correspondre à :
>
> - un entier. Le rafraîchissement est effectué à partir de cette position. L'élément sélectionné n'est pas modifié. Si ce paramètre est invalide, la fonction **<Liste>.Affiche** est sans effet.
> - une constante :
>   | *taCourantBandeau* | - Rafraîchit le champ Liste à partir de la position du bandeau de sélection. - La position du bandeau de sélection n'est pas modifiée.   Cette constante n'est pas disponible. |
>   | --- | --- |
>   | *taCourantPremier* | - Rafraîchit le champ Liste à partir de l'enregistrement courant dans le fichier de données. - La première ligne du champ Liste est sélectionnée. Cette ligne correspond à l'enregistrement courant du champ. |
>   | *taDébut* | - Rafraîchit le champ Liste en se positionnant sur la première ligne du champ Liste. - La première ligne du champ Liste est sélectionnée. Cette ligne correspond au premier enregistrement affiché dans le champ. |
>   | *taInit* | - Exécute les événements d'initialisation du champ Liste (événements "Initialisation" et "Fin d'initialisation"). - Remplit le champ Liste. - La première ligne du champ Liste est sélectionnée. Cette ligne correspond au premier enregistrement affiché dans le champ. |
>   | *taRéExécuteRequête* | - Ré-exécute la requête (cas des champs Liste sur requête intégrée uniquement). - Rafraîchit le champ Liste en se positionnant sur la première ligne du champ Liste. - La première ligne du champ Liste est sélectionnée. Cette ligne correspond au premier enregistrement affiché dans le champ. |
>   | *taSansMajSaisieCb* | Si le champ est un champ Combo avec saisie, le champ de saisie associé au champ Combo n'est pas modifié en fonction du nouveau contenu de la liste. Si cette constante n'est pas utilisée, par défaut, le champ de saisie associé au champ Combo est modifié.  Cette constante peut être combinée avec les autres constantes.  Cette constante n'est pas disponible. |
>
>
> > _(WEBDEV - Code Serveur)_ Ce paramètre n'est pas disponible.

## Remarques

### Divers

- Pour réactualiser les champs Table, utilisez la fonction [<Table>.Affiche](1000023505.md).
- La fonction **<Liste>.Affiche** peut être utilisée sur une colonne d'un champ Table de type "Combo".

> _(WINDEV, Connecteurs Natifs (Accès Natifs))_ Connecteur Natif SQLServerSi la fonction <Liste>.Affiche manipule un champ Liste lié à un fichier de données accédé par le Connecteur Natif SQLServer, il est conseillé d'utiliser les constantes taCourantPremier et taDébut.
