# SensiblePonctuation (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

La propriété **SensiblePonctuation** permet de paramétrer la prise en compte de la ponctuation (virgule, point, etc.) dans les différentes recherches effectuées sur la rubrique (avec les fonctions [HLitRecherche](3044050.md), [HLitRecherchePremier](3044036.md) et [HLitRechercheDernier](3044034.md) par exemple). Il est ainsi possible de :

- Savoir si la ponctuation est prise en compte ou non dans les recherches sur cette rubrique (définie sous l'éditeur d'analyses ou définie par programmation).
- Définir la gestion de la ponctuation pour une rubrique (lors de la description de la rubrique par programmation uniquement).

## Exemple

```wlangage
// Définir la gestion de la ponctuation de la rubrique Commande.Nom
Nom.SensiblePonctuation = Vrai
...
// Valide la description du fichier de données
HDécritFichier(Commande)
```

## Syntaxe

#### Savoir si la ponctuation est prise en compte

```wlangage
<Résultat> = <Fichier de données>.<Rubrique>.SensiblePonctuation
```

`<Résultat>` *Booléen*
> - Vrai si la ponctuation est prise en compte pour les recherches effectuées sur cette rubrique,
> - Faux dans le cas contraire.
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données manipulé. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Fichier](1514065.md).
`<Rubrique>` *Chaîne de caractères*
> Nom de la rubrique manipulée. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Rubrique](1514071.md).

#### Définir la gestion de la ponctuation (rubrique décrite par programmation)

```wlangage
<Rubrique>.SensiblePonctuation = <Nouvelle gestion>
```

`<Rubrique>` *Chaîne de caractères*
> Nom de la rubrique manipulée. Ce nom vient d'être défini grâce au type [Description de Rubrique](1514071.md).
`<Nouvelle gestion>` *Booléen*
> - Vrai si la ponctuation doit être prise en compte pour les recherches effectuées sur cette rubrique,
> - Faux dans le cas contraire.

## Remarques

### Recherche réalisée sur une rubrique "sensible à la ponctuation"
Si une recherche est réalisée sur une rubrique "sensible à la ponctuation", seuls les mots identiques du point de vue de la ponctuation seront trouvés. Ainsi, si le nom de client enregistré est "M.Jérémy", la recherche effectuée sur :

- le nom de client "M.Jérémy" trouvera l'enregistrement,
- le nom de client "M Jérémy" ne trouvera pas l'enregistrement.

### Paramétrer les différentes options de recherche pour une rubrique

- Pour gérer l'accentuation lors des recherches, utilisez la propriété [SensibleAccentuation](2512077.md).
- Pour gérer la casse lors des recherches, utilisez la propriété [SensibleCasse](2512085.md).
- Pour gérer la ponctuation lors des recherches, utilisez la propriété **SensiblePonctuation**.
