# Gérer les utilisateurs d'une application installée en réseau

> **Disponible :** **WINDEV** (Windows)

## Présentation

La gestion des utilisateurs permet de connaître à partir du poste serveur :

- les utilisateurs connectés actuellement à l'application,
- pour chaque utilisateur connecté :
  - le poste de lancement de l'application,
  - la version de l'application utilisée.

## Caractéristiques des utilisateurs

Pour visualiser les caractéristiques des utilisateurs d'une application sur le poste serveur :

1. Lancez l'application WDADMINEXE présent dans le sous-répertoire INSTALL du répertoire d'installation sur le poste serveur.
2. Affichez l'onglet "Utilisateurs".

[image: WDADMINEXE - Onglet Utilisateurs]

|  | Nom de l'exécutable de l'application dont les informations sont affichées. Une même application peut être associée à plusieurs exécutables. |
| --- | --- |
|  | Cadence de rafraîchissement d'affichage des caractéristiques des utilisateurs. |
|  | Nom du poste à partir duquel l'application a été lancée. Ce nom a été défini dans les propriétés réseau du poste. |
|  | Adresse IP du poste à partir duquel l'application a été lancée. |
|  | Nom de l'utilisateur du poste à partir duquel l'application a été lancée. Ce nom a été spécifié lors du lancement du poste. |
|  | Date de début de la connexion de l'utilisateur à l'application. |
|  | Heure de début de la connexion de l'utilisateur à l'application. |
|  | Version de l'application utilisée. |

**Remarque** : Les données affichées dans cet onglet sont contenues dans les fichiers LOKxxx.tmp. Ces fichiers sont présents dans le sous-répertoire LOCK du répertoire INSTALL sur le poste serveur. Chaque fichier correspond à un utilisateur connecté à l'application. Ces fichiers sont supprimés dès que la connexion est terminée.

Pour plus de détails sur l'application WDADMINEXE, consultez le [Contrôle à distance des exécutables WINDEV](2028052.md).

## Notes

### Si vous choisissez de ne pas intégrer la gestion des utilisateurs
Si la gestion des utilisateurs n'est pas intégrée dans le programme d'installation, l'application WDADMINEXE sera tout de même installée sur le serveur. Cependant :

- les fichiers LOKxxx.tmp ne seront pas créés,
- l'onglet "Utilisateurs" sera grisé,
- le contrôle à distance de l'application sera disponible. Le contrôle à distance permet à tout moment de déconnecter les utilisateurs. Pour plus de détails sur le contrôle à distance de l'application, consultez le [Contrôle à distance des exécutables WINDEV](2028052.md).
