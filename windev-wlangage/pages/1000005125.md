# NotesNbFichierAttaché (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Renvoie le nombre de fichiers attachés à un champ du document en cours dans Lotus Notes.

## Exemple

```wlangage
// Ouverture de la connexion
IDConnexion est un entier
IDConnexion = NotesOuvreConnexion("MotDePasse", "ServeurMars", ...
		"C:\Users\Julie\AppData\Local\Lotus\Notes\Data\user.id")
// Spécification de la base Lotus Notes à utiliser
IDBase est un entier
IDBase = NotesOuvreBase(IDConnexion, "julie.nsf")
...
// Lecture du premier document
NotesDocumentPremier(IDBase)
...
// Nombre de fichiers attachés au champ "MonChampLotusNotes" du document Notes en cours ?
NbFichier est un entier
NbFichier = NotesNbFichierAttaché(IDBase, "MonChampLotusNotes")
```

## Syntaxe

```wlangage
<Résultat> = NotesNbFichierAttaché(<Identifiant de la session> , <Champ Lotus Notes>)
```

`<Résultat>` *Entier*
> Nombre de fichiers attachés au champ spécifié dans le document Notes en cours. En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Identifiant de la session>` *Entier*
> Identifiant de la session à utiliser. Cet identifiant est renvoyé par la fonction [EmailOuvreSessionNotes](3032121.md) ou [NotesOuvreBase](1000005101.md).
`<Champ Lotus Notes>` *Chaîne de caractères*
> Nom du champ Lotus Notes de type Texte Riche à utiliser.
> Pour connaître le nom et le type des champs du document Notes en cours, utilisez la fonction [NotesListeChamp](1000005112.md).

## Remarques

### Champ d'un document Notes
Chaque champ d'un document Notes peut avoir jusqu'à 256 fichiers attachés.

**Composante : wd300mess.dll**
