# Volet "Trace du débogueur"

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Le volet "Trace du débogueur" permet de visualiser les messages affichés dans la trace lors du dernier test de l'application.
Ces messages peuvent correspondre :

- aux appels de la fonction [Trace](3013050.md).
- aux erreurs rencontrées lors du test. Le texte complet de l'erreur est affiché dans la fenêtre de trace.
- aux messages associés aux points d'arrêt. Pour plus de détails, consultez [Gestion des points d'arrêt](2019005.md).

Le menu contextuel (clic droit) de ce volet permet de :

- Vider la trace.
- Voir le code associé à la ligne en cours (il est également possible de double-cliquer sur la ligne dans la trace pour voir le code associé).
- Paramétrer les informations listées dans la trace du débogueur :
  - affichage des appels à la fonction Trace,
  - affichage des exceptions,
  - affichage des erreurs non fatales,
  - affichage des assertions,
  - affichage des caractères de contrôle sous forme de caractères (<\r><\n>) ou les convertir dans leur valeur.
- Récupérer le contenu d'une ligne, exporter le contenu de la trace.

**Remarques** :

- Le volet "Trace du débogueur" affiche uniquement les 1000 derniers affichages (1 affichage correspond à un appel de la fonction [Trace](3013050.md) ou à une erreur).
- Seules les informations affichées dans la fenêtre de trace serveur sont reprises dans le volet "Trace du débogueur". Les informations affichées dans la fenêtre de trace navigateur ne sont pas affichées.

## Afficher le volet "Trace du débogueur"

**Pour afficher le volet "Trace du débogueur"**, sous le volet "Accueil", dans le groupe "Environnement", déroulez "Volets" et sélectionnez "Volets" puis "Trace du débogueur".
Pour plus de détails sur les manipulations des volets, consultez [Manipuler les volets ancrables](2027001.md).
