# MQTTDésabonneTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Permet de se désabonner de tous les abonnements préalablement souscrits.

## Exemple

```wlangage
MQTTDésabonneTout(gMqttSession)
```

## Syntaxe

```wlangage
<Résultat> = MQTTDésabonneTout(<Session MQTT>)
```

`<Résultat>` *Booléen*
> - Vrai si tous les désabonnements ont été effectués,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de détails.
`<Session MQTT>` *Variable de type mqttSession*
> Nom de la variable [mqttSession](1000023023.md) correspondant à la session MQTT à manipuler.

**Composante : wd300com.dll**
