# <Variable Image>.PixelOpacité (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Identifie l'opacité d'un pixel d'une image (présente dans une variable de type [Image](1000019650.md)) gérant la couche Alpha.
> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Dessiner en WINDEV, WEBDEV et WINDEV Mobile.

## Exemple

```wlangage
MonImage est une Image = "Test.bmp"
// Identification de l'opacité du pixel (15, 25)
// sur la variable Image
ResOpacité = MonImage.PixelOpacité(15, 25)
IMG_MonDessin = MonImage
```

## Syntaxe

```wlangage
<Résultat> = <Variable Image>.PixelOpacité(<Abscisse> , <Ordonnée>)
```

`<Résultat>` *Entier*
> Opacité du pixel spécifié (comprise entre 0 pour transparent, et 255 pour une opacité complète).
`<Variable Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) à manipuler.
`<Abscisse>` *Entier*
> Position horizontale du pixel à manipuler.
`<Ordonnée>` *Entier*
> Position verticale du pixel à manipuler.

## Remarques

### Coordonnées
Les coordonnées sont indiquées en pixels par rapport au coin haut gauche de l'image (coordonnées (0,0)).

### Dessin dans une image avec opacité
Pour spécifier que le dessin dans l'image gère l'opacité (couche Alpha), utilisez la fonction [<Variable Image>.DébutDessin](1000024349.md) en spécifiant la constante ***dAvecOpacité***.

**Composante : wd300obj.dll**
