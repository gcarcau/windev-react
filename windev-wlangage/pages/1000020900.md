# NuméroSérie (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (iPhone/iPad)

La propriété **NuméroSérie** permet de gérer les numéros de série. Cette propriété est utilisable sur :

- une variable de type [Certificat](1000019287.md).
- une variable de type [upnpPériphérique](1000020903.md).
