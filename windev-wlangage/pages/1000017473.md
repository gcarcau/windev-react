# Type XLSCellule : Propriété MasqueWD

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows)

## Présentation

La propriété MasqueWD du type xlsDocument permet de définir le masque d'affichage au format WINDEV ou WEBDEV à utiliser dans la cellule Excel (par exemple "JJ/MM/AAAA").
Le masque spécifié est automatiquement converti au format Excel. Les centièmes de seconde présents dans les masques ne sont pas gérés.

Cette page d'aide présente les différents masques pouvant être utilisés.

## Masques pouvant être utilisés dans la propriété MasqueWD

### Masques de type entier
Quelques exemples de masques gérés pour les cellules affichant des entiers :

- "9"
- "999"
- "999999"
- "999 999"
- "999 999 999"

### Masques de type réel
Quelques exemples de masques gérés pour les cellules affichant des réels :

- "999 999, 999 999"
- "999 999, 999999"
- "999, 999"
- "999999,9"

### Masques de type date
Quelques exemples de masques gérés pour les cellules affichant des dates :

- "JJ/MM/AAAA"
- "MM/JJ/AAA"
- "JJ/MM/AA"
- "JJ-MM-AAAA"
- "JJ-MM-AA"
- "JJ MM AAAA"
- "JJ MM AA"
- "Jour:JJ Mois:MM Année:AAAA"

### Masques de type heure
Quelques exemples de masques gérés pour les cellules affichant des heures :

- "HH:MM:SS"
- "HH:MM"
- "HH"
- "HH h MM"
- "HH hr MM min"
- "HH Heures MM Minutes SS Secondes"

### Masques de type Date-Heure
Quelques exemples de masques gérés pour les cellules affichant des dates et des heures :

- "JJ/MM/AAAA HH:MM:SS"
- "JJ/MM/AA HH:MM"
- "MM/JJ/AA HH:MM:SS"

### Masques de type Durée
Quelques exemples de masques gérés pour les cellules affichant des durées :

- "HH:MM:SS"
- "J HH:MM:SS"
- "J Jours HH Heures MM Minutes"

### Masques de type Monétaire
Quelques exemples de masques gérés pour les cellules affichant des monétaires :

- "+999 999,99 $"
- "999999,99$"
- "+999 999,999999 $"
- "999999,999 999$"
