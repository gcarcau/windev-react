# GglSupprime (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Supprime des données sur le serveur Google. Les données créées ou mises à jour sont contenues dans une variable correspondant au service manipulé :

- Variable de type [gglAgenda](1000017418.md) pour supprimer un agenda.
- Variable de type [gglContact](1000017434.md) pour supprimer un contact.
- Variable de type [gglGroupeContact](1000017576.md) pour supprimer un groupe de contacts.

**Avertissement**

 A partir du 15 juin 2021, l'API Contacts de Google utilisée par cette fonctionnalité pour gérer les contacts et les groupes de contacts n'est plus disponible ([https://developers.google.com/contacts/v3/announcement](https://developers.google.com/contacts/v3/announcement)).
Pour utiliser les contacts de Google, consultez l'API People proposée en remplacement par Google : [https://developers.google.com/people](https://developers.google.com/people).
La fonction [RESTEnvoie](1000021476.md) simplifie l'intégration d'une API REST dans vos développements.

## Exemple

```wlangage
// Connexion
Cnx est une gglConnexion
...
SI GglConnecte(Cnx) = Faux ALORS
	Erreur(ErreurInfo())
FIN

// Récupération de l'agenda "Travail"
tabAgenda est un tableau de 0 gglAgenda
tabAgenda = GglListeAgenda(Cnx, gglUtilisateur)
// Affichage du titre de chaque agenda
Agenda est un gglAgenda
POUR TOUT Agenda DE tabAgenda
	SI Agenda.Titre = "TRAVAIL" ALORS
	 	// Suppression de l'agenda
	 	GglSupprime(Cnx, Agenda)
	FIN
FIN
```

## Syntaxe

```wlangage
<Résultat> = GglSupprime(<Connexion Google> , <Elément Google>)
```

`<Résultat>` *Booléen*
> - Vrai si la suppression a été réalisée,
> - Faux en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Connexion Google>` *Variable de type gglConnexion*
> Nom de la variable de type [gglConnexion](1000018009.md) à utiliser. Cette connexion a été validée avec la fonction [GglConnecte](1000017332.md).
`<Elément Google>` *Variable correspondant au type à supprimer*
> Elément à supprimer. Ce paramètre peut correspondre à :
>
> - Nom de la variable de type [gglAgenda](1000017418.md) correspondant à l'agenda à supprimer.
> - Nom de la variable [gglContact](1000017434.md) correspondant au contact à supprimer.
> - Nom de la variable de type [gglGroupeContact](1000017576.md) correspondant au groupe de contacts à supprimer.

## Remarques

### Suppression d'agenda
Pour supprimer un agenda, cet agenda doit avoir été récupéré auparavant avec la fonction [GglListeAgenda](1000017330.md) avec la constante *gglUtilisateur*. Dans le cas contraire, le serveur renvoie une erreur "InternalServerError".

**Composante : wd300ggl.dll**
