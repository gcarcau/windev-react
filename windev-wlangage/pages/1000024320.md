# CertificatDeConfianceAjoute (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Ajoute un certificat dans la liste des autorités racine de confiance utilisées pour valider les chaînes de certification.
Attention : Cet ajout est réalisé pour l'application en cours. Aucun ajout n'est réalisé dans les magasins de certificats de Windows.

Remarque : Cette fonction impacte :

- Les requêtes HTTPS utilisant des variables de type [httpRequête](1000021158.md),
- La gestion des fichiers par FTPS,
- Les sockets SSL,
- MQTT via SSL,
- la vérification des signatures (2ème syntaxe de la fonction [CertificatVérifieChaîne](1000019298.md)).

## Exemple

```wlangage
CertificatDeConfianceAjoute("MonCA.pem")
```

## Syntaxe

```wlangage
<Résultat> = CertificatDeConfianceAjoute(<Certificat>)
```

`<Résultat>` *Booléen*
> - Vrai si l'ajout a été effectué,
> - Faux en cas d'erreur.
`<Certificat>` *Chaîne de caractères*
> Chemin du fichier de certificat à ajouter dans la liste des autorités racine de confiance.
> Remarque : Ce fichier peut être intégré dans la librairie de l'application (fichier WDL).

## Remarques

- Les certificats au format cer, pem, der et p12 sont supportés.
- La fonction **CertificatDeConfianceAjoute** est prise en compte par la fonction [SocketConnecteSSL](1000017042.md) uniquement si le mode de gestion des fonctions Socket permet de passer en OpenSSL (fonction [SocketParamètre](1410088949.md)) :
  ```wlangage
  SocketParamètre(socketParamètreMode, 1)
  ```
