# sfRésultatFusionne (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Le type **sfRésultatFusionne** permet de connaître le résultat de la fonction [SFFusionne](1000018509.md). Les caractéristiques de ce résultat peuvent être connues à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Propriétés

### Propriétés spécifiques à la description des variables de type sfRésultatFusionne
Les propriétés suivantes peuvent être utilisées pour manipuler le résultat de la fonction [SFFusionne](1000018509.md) :

| Nom | Type manipulé | Effet |
| --- | --- | --- |
| Erreur | Tableau de [sfErreur](1000018455.md) | Compte-rendu d'erreurs. |
| ID | Chaîne de caractères | Identifiant de l'objet fusionné. **Cette propriété est disponible en lecture seulement**. |
| IDEnregistrementApparentéMisAJour | Chaîne de caractères | Liste des identifiants Salesforce des enregistrements qui ont été modifiés suite à la fusion (enregistrements liés aux enregistrements fusionnés). Les différents identifiants sont séparés par des RC (Retour-chariot).  **Cette propriété est disponible en lecture seulement**. |
| IDEnregistrementFusionné | Chaîne de caractères | Liste des identifiants Salesforce des enregistrements fusionnés. Les différents identifiants sont séparés par des RC (Retour-chariot).  **Cette propriété est disponible en lecture seulement**. |
| Succès | Booléen | - Vrai si la fusion s'est correctement déroulée, - Faux en cas d'erreur.  **Cette propriété est disponible en lecture seulement**. |

## Remarques

### Fonctions manipulant le type sfRésultatFusionne

| [SFFusionne](1000018509.md) | Fusionne des enregistrements Salesforce (appelés également objets Salesforce). |
