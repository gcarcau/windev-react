# telFinDétectionAppel (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Termine la détection d'appel spécifié lancée par la fonction [telDémarreDétectionAppel](3076029.md).

## Exemple

```wlangage
// -- Fermeture de la fenêtre de gestion des appels
// Arrêt du service de détection des appels
telFinDétectionAppel("AppelEntrant")
```

## Syntaxe

```wlangage
telFinDétectionAppel(<Identifiant de la détection d'appel>)
```

`<Identifiant de la détection d'appel>` *Chaîne de caractères*
> Identifiant du service de détection d'appel en cours. Cet identifiant a été donné lors du démarrage de la détection d'appels par la fonction [telDémarreDétectionAppel](3076029.md).

## Remarques

Il n'est pas possible d'appeler la fonction **telFinDétectionAppel** dans la procédure de détection d'appel (définie grâce à la fonction [telDémarreDétectionAppel](3076029.md)).

> _(WINDEV, Etats et Requêtes, Code Utilisateur (MCU))_ Configuration nécessaireLes fonctions de téléphonie utilisent la technologie TAPI 2.0 et/ou la technologie TAPI 3.1. Ces technologies sont utilisables sur tous les systèmes.

**Composante : wd300com.dll**
