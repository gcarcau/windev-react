# AscenseurEstVisible (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Permet de savoir si un ascenseur d'un champ dans une application WINDEV est visible.

## Exemple

```wlangage
SI AscenseurEstVisible(LISTE_MaListe, ascHorz) ALORS
	Info("La liste n'est pas assez large.")
FIN
```

## Syntaxe

```wlangage
<Résultat> = AscenseurEstVisible(<Champ manipulé> [, <Orientation>])
```

`<Résultat>` *Booléen*
> - Vrai si l'ascenseur est visible,
> - Faux dans le cas contraire.
`<Champ manipulé>` *Nom de champ*
> Nom du champ manipulé.
`<Orientation>` *Constante optionnelle de type Entier*
> Orientation de l'ascenseur à manipuler :
>
> | *ascHorz* | Recherche si l'ascenseur horizontal du champ est visible. |
> | --- | --- |
> | *ascVert* (Valeur par défaut) | Recherche si l'ascenseur vertical du champ est visible. |

**Composante : wd300obj.dll**
