# <Variable picCalque>.InverseCouleur (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Inverse les couleurs dans une variable de type [picCalque](1000024604.md).

## Exemple

```wlangage
MonImageWDPic est un WDPic = "Test.bmp"
MonCalque est un picCalque
// Inverse les couleurs de la variable picCalque
Résultat1 est un booléen
Résultat1 = MonCalque.InverseCouleur()
SI Résultat1 = Faux ALORS Erreur("L'opération a échoué")
IMG_MonDessin = MonImageWDPic
```

## Syntaxe

```wlangage
<Résultat> = <Image picCalque>.InverseCouleur()
```

`<Résultat>` *Booléen*
> - Vrai si l'inversion des couleurs a été effectuée,
> - Faux dans le cas contraire.
`<Image picCalque>` *Variable de type picCalque*
> Nom de la variable de type [picCalque](1000024604.md) à manipuler.
> Chaque pixel de l'image prend la couleur opposée (négation bit à bit) de la couleur d'origine. L'image manipulée est directement modifiée.

## Remarques

### Fin du dessin
Si la fonction [<Variable picCalque>.FinDessin](1000024473.md) est appelée dans le même traitement que la fonction **<Variable picCalque>.InverseCouleur**, la transformation de l'image ne sera pas affichée.

**Composante : wd300pnt.dll**
