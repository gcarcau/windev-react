# <Graphe>.BourseRécupèreDonnée (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Récupère une donnée dans un graphe boursier (chandelier, barcharts ou minmax).

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
// Affichage d'une donnée dans le champ "GRF_MonGraphe".
// Cette donnée est la première valeur minimale de la première série.
Info(GRF_MonGraphe.BourseRécupèreDonnée(1, 1, grValeurMin))
```

## Syntaxe

```wlangage
<Résultat> = <Champ Graphe>.BourseRécupèreDonnée(<Numéro de la série> , <Indice> , <Valeur à récupérer>)
```

`<Résultat>` *Réel*
> Valeur récupérée.
`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres, de pages ou d'états).
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Numéro de la série>` *Entier*
> Numéro de la série pour laquelle une valeur doit être récupérée.
> Si la série spécifiée n'existe pas, la valeur récupérée est 0.
`<Indice>` *Entier*
> Indice de la donnée dans la série pour laquelle la valeur doit être récupérée.
> Si la donnée correspondant à l'indice spécifié n'existe pas dans la série, la valeur récupérée est 0.
`<Valeur à récupérer>` *Constante de type Entier*
> Indique la valeur à récupérer :
>
>
> | *grValeurDébut* | Valeur de début. |
> | --- | --- |
> | *grValeurFin* | Valeur de fin. |
> | *grValeurMax* | Valeur maximale. |
> | *grValeurMin* | Valeur minimale. |

## Remarques

- Pour récupérer une donnée dans un graphe de type Nuage de points, il est conseillé d'utiliser la fonction [<Graphe>.NuageRécupèreDonnéeXY](1000024108.md).
- Pour récupérer une donnée dans un graphe de type Secteur multiniveau, il est conseillé d'utiliser la fonction [<Graphe>.SMNRécupèreDonnée](1000024137.md).
- Pour récupérer une donnée dans un graphe Surface, il est conseillé d'utiliser la fonction [<Graphe>.SurfaceRécupèreDonnée](1000024148.md).
- Pour récupérer une donnée dans un graphe de type Heatmap, il est conseillé d'utiliser la fonction [<Graphe>.HMRécupèreDonnée](1000024083.md).
- Pour récupérer une donnée dans un autre type de graphe (Secteur, Histogramme, Courbe, etc.), utilisez la fonction [<Graphe>.RécupèreDonnée](1000024122.md).
