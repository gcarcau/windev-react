# Domaine

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

La propriété **Domaine** permet de connaître et de modifier les domaines gérés.
Cette propriété est utilisable sur :

- une variable de type [Cookie](1000019222.md).
- une variable de type [rssCatégorie](1000017782.md).
- une variable de type [rssCloud](1000017785.md).
