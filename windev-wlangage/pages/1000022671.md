# LectureSeule (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android)

La propriété **LectureSeule** permet de savoir si un élément est en lecture seulement. Cette propriété est utilisable sur :

- une variable de type [NFCTag](1000020411.md).
- une variable de type [Document](1000022461.md).
