# TélémétrieEstActive (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Permet de savoir si la télémétrie est activée.

## Exemple

```wlangage
SI TélémétrieEstActive() = Faux ALORS TélémétrieActive()
```

## Syntaxe

```wlangage
<Résultat> = TélémétrieEstActive()
```

`<Résultat>` *Booléen*
> - Vrai si la télémétrie est activée,
> - Faux dans le cas contraire.

## Remarques

Attention : La télémétrie n'est jamais activée en mode test afin d'éviter de remplir la base de données avec des données partielles. La télémétrie est activée et activable uniquement dans l'application générée.

**Composante : wd300vm.dll**
