# Ressource

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Ressource** permet de manipuler la ressource associée à un rendez-vous.
Cette propriété est utilisable sur :

- un champ Planning. Pour plus de détails, consultez [Ressource](1000019308.md).
- une variable de type [RendezVous](1000019244.md).
