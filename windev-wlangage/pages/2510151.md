# InterprèteEtCommercial (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

La propriété **InterprèteEtCommercial** permet de connaître et de modifier le mode d'interprétation du caractère '&' dans :

- le libellé d'un champ Libellé d'une fenêtre.
- les éléments d'un champ Liste.
- les éléments d'un champ Combo.
- les valeurs d'une colonne d'un champ Table.

**Remarque** : Par défaut, si une chaîne de caractères contient le caractère '&', la lettre qui suit le caractère '&' est interprétée comme lettre d'appel. Pour plus de détails, consultez [Raccourci clavier et lettre d'appel](1014018.md).

## Exemple

```wlangage
// Ne pas interpréter le caractère '&' comme une lettre d'appel
LISTE_ListeLivre.InterprèteEtCommercial = Faux
// Ajout d'un titre de livre
ListeAjoute(LISTE_ListeLivre, "Guerre&Paix")
```

## Syntaxe

#### Connaître le mode d'interprétation du caractère '&'

```wlangage
<Résultat> = <Champ manipulé>.InterprèteEtCommercial
```

`<Résultat>` *Booléen*
> - Vrai si la lettre suivant le caractère '&' est interprétée comme lettre d'appel,
> - Faux si le caractère '&' n'est pas interprété.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.

#### Modifier le mode d'interprétation du caractère '&'

```wlangage
<Champ manipulé>.InterprèteEtCommercial = <Nouveau mode d'interprétation>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.
`<Nouveau mode d'interprétation>` *Booléen*
> - Vrai si la lettre suivant le caractère '&' doit être interprétée comme lettre d'appel,
> - Faux si le caractère '&' ne doit pas être interprété.

## Remarques

### Caractère '&' interprété comme lettre d'appel
Si la lettre suivant le caractère '&' est interprétée comme lettre d'appel, pour utiliser le caractère '&' dans un libellé, il est nécessaire de le doubler. Par exemple :

- le libellé "Guerre&Paix" sera "GuerrePaix" (avec Alt + P comme lettre d'appel).
- le libellé "Guerre&&Paix" sera "Guerre&Paix".

### Limitations
La propriété **InterprèteEtCommercial** peut uniquement être utilisée sur les champs suivants dans une fenêtre :

- un champ Libellé.
- un champ Liste.
- un champ Combo.
- une colonne d'un champ Table.
