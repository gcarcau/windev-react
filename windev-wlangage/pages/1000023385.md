# CheminFichier (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **CheminFichier** permet de connaître le chemin du fichier associé à un champ. Cette propriété est utilisable sur :

- un champ bureautique présent dans une fenêtre (champ Tableur, champ Traitement de texte, champ Editeur d'images, champ Lecteur PDF). Pour plus de détails, consultez [CheminFichier](1000023104.md).
- une variable de type [Document](1000022461.md).
