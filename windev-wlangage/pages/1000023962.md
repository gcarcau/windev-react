# <Variable Connexion>.OuvreConnexion (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Ouvre une connexion à une base de données spécifique. La connexion reste ouverte jusqu'à l'appel de la fonction [<Variable Connexion>.FermeConnexion](1000023941.md). La fonction **<Variable Connexion>.OuvreConnexion** permet d'ouvrir une connexion définie avec une variable de type [Connexion](1514073.md).
**Attention** : L'ordre d'utilisation des fonctions permettant de se connecter à une base de données HFSQL Client/Serveur est important. Consultez [Optimiser les temps de connexion aux bases HFSQL Client/Serveur](9000176.md) pour plus de détails.

## Exemple

> _(Etats et Requêtes, Windows, Linux, Java, Code Utilisateur (MCU), Ajax, HFSQL Classic, HFSQL Client/Serveur, OLE DB, Connecteurs Natifs (Accès Natifs))_ MaConnexion est une Connexion
// Description de la connexion
MaConnexion.Utilisateur = "USER"
MaConnexion.MotDePasse = "PASSWORD"
MaConnexion.Serveur = "MONSERVEUR"
MaConnexion.BaseDeDonnées = "Base de données"
MaConnexion.Provider = hAccèsHFClientServeur
MaConnexion.Accès = hOLectureEcriture
MaConnexion.InfosEtendues = "Infos étendues"
MaConnexion.OptionsCurseur = hCurseurClient

MaConnexion.OuvreConnexion()

## Syntaxe

```wlangage
<Résultat> = <Connexion>.OuvreConnexion()
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème (par exemple, lors d'une connexion décrite par programmation, certains paramètres utilisés dans la fonction [HDécritConnexion](3044205.md) peuvent être inexacts).
>
>
> La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion à une base de données.

## Remarques

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Code Utilisateur (MCU), PHP, Ajax, HFSQL Classic, HFSQL Client/Serveur, OLE DB, Connecteurs Natifs (Accès Natifs))_ Syntaxe 1 : Ouvrir une connexion prédéfinie : gestion automatique des connexionsLa connexion associée à un fichier de données est automatiquement ouverte lors de l'ouverture du fichier de données. La connexion est fermée lorsque le dernier fichier de données utilisant cette connexion est fermé.Si une connexion est ouverte avec la fonction <Variable Connexion>.OuvreConnexion, cette connexion reste ouverte même si aucun fichier de données ne l'utilise.Si l'application effectue de nombreuses ouvertures et fermetures de fichiers de données successives, la gestion automatique des connexions va provoquer de nombreuses ouvertures/fermetures des connexions, entraînant d'importants ralentissements. Il est dans ce cas conseillé d'utiliser la fonction <Variable Connexion>.OuvreConnexion pour forcer la conservation de la connexion ouverte.
