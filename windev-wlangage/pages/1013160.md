# Animer un champ Libellé

> **Disponible :** **WINDEV** (Windows, Java) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

## Principe

WINDEV et WINDEV Mobile permettent d'animer un champ Libellé de deux façons différentes :

- libellé défilant : le libellé défile d'un côté à l'autre du champ.
- libellé clignotant : le libellé s'affiche alternativement de deux couleurs différentes.

Nouveauté 2025

> _(Android)_ Cette fonctionnalité est désormais disponible pour les applications Android.

> _(iPhone/iPad)_ Cette fonctionnalité est désormais disponible pour les applications iPhone/iPad.

## Animer un champ Libellé

### Comment le faire ?
Pour animer un champ Libellé :

1. Affichez la fenêtre de description du libellé (option "Description" du menu contextuel du libellé).
2. Dans l'onglet "Détail", paramétrez les options d'animation (zone "Animation"). Choisissez le type d'animation et configurez les options associées. Les options varient selon le mode d'animation choisi.

Pour une animation de type **défilement** il est possible d'indiquer :

- La cadence de rafraîchissement entre chaque déplacement du libellé.
- Le nombre de pixels correspondant à un déplacement du libellé.
- Le sens de défilement. Le libellé peut défiler :
  - de gauche à droite,
  - de droite à gauche,
  - de bas en haut,
  - de haut en bas.
- Nouveauté 2025
  Si l'animation doit boucler et le nombre de répétitions à effectuer.
  **Attention** : Cette fonctionnalité est disponible uniquement à partir de la version 2025 Update 1.

Pour une animation de type **clignotement**, il est possible d'indiquer :

- La cadence de rafraîchissement entre chaque clignotement.
- La couleur de clignotement du libellé. Pour faire clignoter un libellé, deux couleurs sont nécessaires :
  - la couleur normale du libellé.
  - la couleur de clignotement du libellé. Si cette couleur est transparente, le libellé apparaîtra une fois sur deux.

### Remarques

- Il n'est possible d'animer un libellé au format RTF ou un libellé avec une "Ombre floue".
- L'animation d'un libellé est visible uniquement en exécution.
- Un libellé animé est limité à 1024 octets.
- Si les fonctions de mise en forme du texte sont utilisées ([gPoliceGras](3029061.md), [gPoliceTaille](3029064.md), [gPoliceItalique](3029062.md), [gPoliceSoulignée](3029063.md)), l'animation ne fonctionne plus.
- Nouveauté 2025
  Il est également possible de faire défiler un texte trop long dans un champ Libellé. Cette option est notamment utile pour les champs Libellé affichant des informations construites dynamiquement. Pour plus de détails, consultez [Défilement automatique des libellés trop longs](9000226.md).
  **Attention** : Cette fonctionnalité est disponible uniquement à partir de la version 2025 Update 1.

## Programmation

Différentes fonctions du WLangage permettent de gérer les libellés animés. Ces fonctions sont les suivantes :

| [AnimationChangeParamètre](3017002.md) | Change un des paramètres d'animation d'un texte dans un champ Libellé. |
| --- | --- |
| [AnimationChangeType](3017001.md) | Change le type d'animation utilisé dans un champ Libellé. |
| [AnimationLitParamètre](3017003.md) | Lit la valeur d'un paramètre d'animation d'une image dans un champ Libellé. |

Différentes propriétés WLangage permettent de gérer les libellés animés. Ces propriétés sont les suivantes :

| [Animation](2510006.md) | Permet de connaître l'état actuel de l'animation dans un champ Libellé et de lancer ou d'arrêter l'animation d'un champ Libellé animé. |
| --- | --- |
| [AnimationInitiale](2510012.md) | Permet de connaître l'état initial de l'animation dans un champ Libellé. |
