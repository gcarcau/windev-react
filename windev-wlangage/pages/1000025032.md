# PDFOuvre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Ouvre un document PDF et charge ce document dans une variable de type [pdfDocument](1000024909.md).

## Exemple

```wlangage
MonPDF est un pdfDocument = PDFOuvre("test.pdf")

SI ErreurDétectée() ALORS
   Erreur(ErreurInfo())
   RETOUR
FIN
```

## Syntaxe

```wlangage
<Résultat> = PDFOuvre(<Source du document> [, <Mot de passe>])
```

`<Résultat>` *Variable de type pdfDocument*
> Variable de type [pdfDocument](1000024909.md) correspondant au document PDF spécifié.
> En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai et la fonction [ErreurInfo](3013008.md) permet de connaître la cause de l'erreur.
`<Source du document>` *Type correspondant à la source*
> Correspond à un des éléments suivants :
>
> - Chemin complet ou relatif du fichier PDF à ouvrir (260 caractères maximum).
> - Nom de la variable de type Buffer contenant le document PDF.
> - Nom de la rubrique mémo contenant le document PDF. Ce paramètre est de la forme : <Fichier de données>.<Rubrique>.
`<Mot de passe>` *Chaîne de caractères optionnelle ou Chaîne secrète*
> Mot de passe d'ouverture du fichier PDF à manipuler (si le fichier est protégé par un mot de passe d'ouverture).
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).

## Remarques

> _(Android, Widget Android)_ A partir de la version 28, cette fonction n'est pas supportée par les processeurs ARM 32 bits. En effet, les nouveautés en matière de gestion des PDF imposent une exécution en 64 bits. Si une application doit être exécutée sur une flotte existante d'appareils ARM 32 bits, la génération de cette application doit être effectuée avec la version 27 de WINDEV Mobile.
