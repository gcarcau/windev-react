# <VisiteGuidée>.Arrête (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Arrête la visite guidée spécifiée.

## Exemple

```wlangage
MaVisiteDécouverte est un VisiteGuidée
// ...
// Démarrage de la visite guidée
MaVisiteDécouverte.Démarre()
// ...
// Arrête la visite guidée MaVisiteDécouverte
MaVisiteDécouverte.Arrête()
```

## Syntaxe

```wlangage
<Visite guidée>.Arrête()
```

`<Visite guidée>` *Variable de type VisiteGuidée*
> Nom de la variable de type [VisiteGuidée](1410090170.md) correspondant à la visite guidée à arrêter.

**Composante : wd300mdl.dll**
