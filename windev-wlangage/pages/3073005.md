# SysFenActive (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Renvoie le handle de la fenêtre active ou active une fenêtre. Cette fenêtre n'a pas été créée par WINDEV.
**Remarques** :

- Pour connaître le handle d'une fenêtre WINDEV, utilisez la fonction [Handle](3015005.md).
- Pour activer une fenêtre WINDEV, utilisez la fonction [DonneFocusEtRetourUtilisateur](1410088107.md).

## Exemple

```wlangage
// Identifier la fenêtre active
ResActive = SysFenActive()
```

## Syntaxe

#### Identifier la fenêtre active

```wlangage
<Résultat> = SysFenActive()
```

`<Résultat>` *Entier*
> - Handle de la fenêtre active.
> - Constante *NULL* en cas d'erreur.

#### Activer une fenêtre

```wlangage
<Résultat> = SysFenActive(<Handle de la fenêtre>)
```

`<Résultat>` *Entier*
> - Handle de la fenêtre active précédente.
> - Constante *NULL* en cas d'erreur.
`<Handle de la fenêtre>` *Entier*
> Handle de la fenêtre à activer. Ce handle peut être obtenu avec la fonction [SysFenHandle](3073007.md).
