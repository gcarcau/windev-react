# gpwEnModeLDAP (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Permet de savoir si l'identification des utilisateurs dans le groupware utilisateur sera réalisée via un annuaire LDAP.

## Syntaxe

```wlangage
<Résultat> = gpwEnModeLDAP()
```

`<Résultat>` *Booléen*
> - Vrai si le groupware utilisateur utilise un annuaire LDAP pour l'authentification des utilisateurs,
> - Faux dans le cas contraire.
>
>
> > _(Linux)_ <Résultat> est toujours à Faux.

**Composante : wd300gpu.dll**
