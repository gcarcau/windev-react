# <Variable Scanneur>.VersImage (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Récupère un document provenant d'un scanneur dans une variable de type [Image](1000019650.md).

## Exemple

```wlangage
MonScanneur est un Scanneur
MonScanneur = ScanSélecteur()

// Affiche le document présent dans le scanneur dans un champ Image
IMG_MonImage = MonScanneur.VersImage()
SI ErreurDétectée ALORS
	Erreur("Le document n'a pas été scanné", ErreurInfo())
FIN

// Scan de toutes les pages du chargeur
MonScanneur.VersImage(TraitePageScan)
// Traitement d'une page scannée
PROCÉDURE INTERNE TraitePageScan(nNumPage est un entier, ImageScan est une Image)
	ImageScan.SauveJPEG("page" + nNumPage + ".jpg")
FIN
```

## Syntaxe

#### Scanner une seule page

```wlangage
<Résultat> = <Scanneur>.VersImage()
```

`<Résultat>` *Variable de type Image*
> Variable de type [Image](1000019650.md) récupérée du scanneur. En cas d'erreur, la variable [ErreurDétectée](3087001.md) vaut Vrai et le message d'erreur correspondant peut être connu avec la fonction [ErreurInfo](3013008.md).
`<Scanneur>` *Variable de type Scanneur*
> Nom de la variable de type [Scanneur](1410087808.md) initialisée avec les informations du scanneur à utiliser.

#### Scanner plusieurs pages (avec chargeur)

```wlangage
<Résultat> = <Scanneur>.VersImage([<Nombre pages>, ] <Fin de scan d'une page>)
```

`<Résultat>` *Booléen*
> - Vrai si le scan a été effectué sans erreur,
> - Faux en cas d'erreur durant le scan. Le message d'erreur correspondant peut être connu avec la fonction [ErreurInfo](3013008.md).
`<Scanneur>` *Variable de type Scanneur*
> Nom de la variable de type [scanneur](1410087808.md) initialisée avec les informations du scanneur à utiliser.
`<Nombre pages>` *Entier optionnel*
> - Nombre de pages à scanner,
> - Constante *scanNombrePageToutes* pour scanner toutes les pages du chargeur (valeur par défaut).
`<Fin de scan d'une page>` *Nom de procédure*
> Nom de la procédure WLangage (également nommée "callback") appelée lors de la fin du scan d'une page. Cette procédure est de la forme :
>
>
> ```wlangage
> <Nom de la procédure>(<Numéro de page>, <Image>)
> ```
>
>
> où :
>
> - <Numéro de page> : Numéro de la page scannée.
> - <Image> : Variable de type [Image](1000019650.md) contenant la page scannée. Cette variable est valable uniquement lors de l'appel à la procédure : elle doit donc être copiée ou sauvée dans un fichier (il ne faut pas prendre de référence sur cette variable).
>
> Si la procédure renvoie Faux, le scan est interrompu.
