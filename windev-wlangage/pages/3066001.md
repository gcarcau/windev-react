# Fonctions de gestion des réseaux

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Les fonctions de gestion des réseaux sont les suivantes :

| [RéseauConnecte](3066002.md) | Associe un lecteur à un répertoire réseau partagé. |
| --- | --- |
| [RéseauDéconnecte](3066003.md) | Déconnecte un lecteur réseau. |
| [RéseauNomDomaine](1000018859.md) | Renvoie le nom du domaine auquel est associée la machine. |
| [RéseauNomRep](3066005.md) | Identifie le répertoire partagé associé à un lecteur réseau. |
| [RéseauUtilisateur](3066004.md) | Identifie le nom de l'utilisateur connecté. |
