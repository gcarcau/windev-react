# Procédure WLangage appelée par la fonction DeepLinkProcédure

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

Procédure WLangage (également nommée "callback") appelée par la fonction [DeepLinkProcédure](1410089051.md) en cas de clic sur un "deep link" dont l'URL cible a été associée à l'application. Cette procédure doit être une procédure globale.

## Exemple

```wlangage
DeepLinkProcédure(ProcDeepLink)
```

```wlangage
// ---------------------------------
// Procédure globale
// ---------------------------------
PROCÉDURE ProcDeepLink(url est une URI)
// Extrait l'identifiant du produit contenu dans l'url
sId est une chaîne = ExtraitChaîne(url.Requête, 2, " = ")
SI sId <> EOT ALORS
	SI FenEtat(FEN_FicheProduit) <> Inexistant ALORS
		Ferme(FEN_FicheProduit)
	FIN
	OuvreFenêtreMobile(FEN_FicheProduit, sId)
FIN
```

## Syntaxe

```wlangage
DeepLinkProcédure_Callback(<URL>)
```

`<URL>` *Variable de type URI*
> Variable de type [URI](1000024027.md) correspondant à la cible du lien "deep link" cliqué.
