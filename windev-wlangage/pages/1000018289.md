# Jauge / Fonction Jauge (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

Le WLangage propose :

- La fonction [Jauge](3021008.md) qui permet d'afficher une jauge de progression.
- La propriété **Jauge**, utilisable sur :
  - une variable de type [hDescriptionSauvegarde](1000017455.md).
  - une variable de type [httpAvancement](1000021222.md).
  - un champ Tableau croisé dynamique. Pour plus de détails, consultez [Jauge](1000020706.md).
