# SurInvisibilité (Propriété)

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **SurInvisibilité** permet de définir une procédure qui sera appelée lorsque la fenêtre coulissante basse associée à la fenêtre en cours deviendra invisible.
Nouveauté Abonnement
**Attention** : Cette propriété est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2. Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
MaFenêtreCoulissanteBasse.SurInvisibilité = () => { Trace("La fenêtre coulissante basse a disparue") }
MaFenêtreCoulissanteBasse.ParamètresOuverture = (42, "Adams")
MaFenêtreCoulissanteBasse.FenêtreInterne = "FI_Menu_Coulissant"
MaFenêtreCoulissanteBasse.HauteurRéduite = 58 // Valeur en pixels
MaFenêtreCoulissanteBasse.HauteurIntermédiaire = fcAdaptée
MaFenêtreCoulissanteBasse.HauteurÉtendue = 0.9 // 90%
MaFenêtreCoulissanteBasse.Modale = Vrai
MaFenêtreCoulissanteBasse.Masquable = Vrai
MaFenêtreCoulissanteBasse.CoinArrondi = Faux

// Affiche la fenêtre coulissante basse
FenCoulissanteVisible(fcBasse, fcIntermédiaire)
```

## Syntaxe

#### Connaître la procédure appelée lorsque la fenêtre coulissante basse devient invisible

```wlangage
<Résultat> = <Fenêtre coulissante>.SurInvisibilité
```

`<Résultat>` *Procédure*
> Procédure appelée lorsque la fenêtre coulissante basse associée à la fenêtre en cours devient invisible.
`<Fenêtre coulissante>` *MaFenêtreCoulissanteBasse*
> Mot-clé [MaFenêtreCoulissanteBasse](1511030.md) correspondant à la fenêtre coulissante basse définie pour la fenêtre en cours.

#### Modifier la procédure appelée lorsque la fenêtre coulissante basse devient invisible

```wlangage
<Fenêtre coulissante>.SurInvisibilité = <Procédure WLangage>
```

`<Fenêtre coulissante>` *MaFenêtreCoulissanteBasse*
> Mot-clé [MaFenêtreCoulissanteBasse](1511030.md) correspondant à la fenêtre coulissante basse définie pour la fenêtre en cours.
`<Procédure WLangage>` *Nom de procédure*
> Nom de la procédure WLangage à appeler lorsque la fenêtre coulissante basse devient invisible.
