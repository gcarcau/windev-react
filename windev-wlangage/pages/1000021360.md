# mlRAZEspaceDeTravail (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Supprime l'ensemble des variables de la session MATLAB.

## Exemple

```wlangage
tRésultat est un tableau  de 1 par 1 réel = [[123]]

mlRAZEspaceDeTravail(gnIdSession)
tRésultat = mlRécupèreVariable(gnIdSession, "maRac")
SI ErreurDétectée ALORS
	Trace("Erreur : " + ErreurInfo())
FIN

Trace("Racine = " + tRésultat[1,1])
```

## Syntaxe

```wlangage
<Résultat> = mlRAZEspaceDeTravail(<Identifiant de la session>)
```

`<Résultat>` *Booléen*
> - Vrai si l'espace de travail est réinitialisé,
> - Faux dans le cas contraire. En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Identifiant de la session>` *Entier*
> Identifiant de la session MATLAB. Cet identifiant est renvoyé par la fonction [mlInitialise](1000021351.md).

**Composante : wd300com.dll**
