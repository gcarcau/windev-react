# ErreurDétectée (Variable)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

**ErreurDétectée** est une variable prédéfinie du WLangage indiquant le résultat de la dernière fonction WLangage utilisée.
**ErreurDétectée** correspond à :

- Faux si la dernière fonction WLangage utilisée a réussi.
- Vrai si la dernière fonction WLangage utilisée a provoqué une erreur non fatale.

Remarque : Des informations concernant l'erreur rencontrée peuvent être récupérées grâce aux fonctions [ErreurInfo](3013008.md) ou [HErreurInfo](3044071.md).

## Exemple

```wlangage
nFichier est un entiernFichier = fOuvre("C:\MesRépertoires\Fichier.txt", foLectureEcriture)SI nFichier <> -1 ET ErreurDétectée = Faux ALORS  ...SINON Erreur(ErreurInfo())FIN
```

## Remarques

- Pour gérer les erreurs fatales, utilisez [QUAND EXCEPTION](3034001.md).
- Les erreurs fatales non gérées provoquent l'arrêt immédiat de l'application. Un message d'erreur est automatiquement affiché.
  - Ce message peut être paramétré lors de la création de l'exécutable.
  - Les messages d'erreur peuvent être personnalisés lors du déploiement du site sur le serveur Web. Pour plus de détails, consultez [Personnalisation des erreurs](3539001.md).
