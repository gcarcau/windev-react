# Fonctions de gestion du champ Lecteur PDF

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion du champ Lecteur PDF (syntaxe préfixée)](1000023877.md)).
Les fonctions de gestion des champs Lecteur PDF sont les suivantes :

| [LecteurPDFAfficheSignet](1410089202.md) | Positionne le document PDF affiché dans le champ Lecteur PDF sur le signet demandé. |
| --- | --- |
| [LecteurPDFFerme](1000023453.md) | Ferme et libère le fichier PDF affiché dans un champ Lecteur PDF. |
| [LecteurPDFInfoXY](1000025332.md) | Renvoie pour une position donnée dans un champ Lecteur PDF (coordonnées d'un point du champ) :   - soit le numéro de la page pour la position indiquée, - soit la position X (en mm) pour la position indiquée, - soit la position Y (en mm) pour la position indiquée. |
| [LecteurPDFOuvre](1000023452.md) | Ouvre un fichier PDF dans un champ Lecteur PDF. |
| [LecteurPDFRecherchePrécédent](1000023411.md) | Positionne sur le résultat précédent d'une recherche initiée par la fonction [LecteurPDFRecherchePremier](1000023409.md) dans le contenu d'un champ Lecteur PDF. |
| [LecteurPDFRecherchePremier](1000023409.md) | Initialise la recherche d'un texte dans le fichier PDF affiché par le champ Lecteur PDF et positionne sur la première occurrence trouvée (à partir de la page en cours). |
| [LecteurPDFRechercheSuivant](1000023410.md) | Positionne sur le résultat suivant d'une recherche dans le contenu d'un champ Lecteur PDF. |
| [LecteurPDFSauve](1000024898.md) | Sauve le contenu d'un champ Lecteur PDF dans un fichier. |
| [LecteurPDFSurligne](1000023544.md) | Cherche un texte dans le document affiché par un champ Lecteur PDF et surligne les occurrences de ce texte dans le champ. |
| [LecteurPDFTournePage](1000023940.md) | Effectue une rotation d'une page affichée dans le champ Lecteur PDF. |

Remarque : La fonction [iImprimePDF](1000020519.md) peut être utilisée pour imprimer le contenu d'un champ Lecteur PDF.
> _(Android, Widget Android)_ A partir de la version 28, le type pdfDocument et les fonctions de gestion du champ Lecteur PDF ne sont plus supportés par les processeurs ARM 32 bits. En effet, les nouveautés apportées par la version 28 en matière de gestion des PDF imposent une exécution en 64 bits. Si une application doit être exécutée sur une flotte existante d'appareils 32 bits, la génération doit être faite avec la version 27 de WINDEV Mobile.
