# Police

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Le mot-clé **Police** peut correspondre :

- à la variable de type [Police](1514045.md) qui permet de définir les caractéristiques d'une police.
- à la propriété **Police** qui permet de connaître et de modifier la police utilisée dans les champs d'une page, d'une fenêtre ou d'un état. Pour plus de détails, consultez [Police sur les champs](2510095.md).
- à la propriété **Police** disponible sur :
  - une variable de type [xlsCellule](1000017472.md).
  - une variable de type [Filigrane](1000019922.md).
  - une variable de type [picTexte](1000025178.md).
  - une variable de type [diagTexte](1410088393.md).
