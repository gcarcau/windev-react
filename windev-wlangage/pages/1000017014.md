# SysListeEcran (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Renvoie la liste des écrans connectés sur une ou plusieurs cartes graphiques.

## Exemple

```wlangage
// Récupération des différents écrans du PC en cours
ListeAjoute(LISTE_ListeEcran, SysListeEcran())
```

## Syntaxe

```wlangage
<Résultat> = SysListeEcran([<Nom de la carte graphique>])
```

`<Résultat>` *Chaîne de caractères*
> - Liste des noms des écrans séparés par RC. Cette liste est du type :
>   ```wlangage
>   <Nom Ecran 1> + RC + <Nom Ecran 2> + RC + ... + RC + <Nom Ecran N>
>   ```
>   Si la fonction système n'a pas pu être manipulée, <Résultat> correspond à une chaîne vide ("").
> - Chaîne vide ("") en cas d'erreur. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de renseignements sur le problème rencontré.
`<Nom de la carte graphique>` *Chaîne de caractères optionnelle*
> Nom de la carte graphique pour laquelle les écrans doivent être listés. Le nom des cartes graphiques peut être connu grâce à la fonction [SysListeCarteGraphique](1000017016.md). Si ce paramètre n'est pas spécifié, les écrans de l'ensemble des cartes graphiques sont listés.
> Si le nom spécifié n'existe pas, <Résultat> correspond à chaîne vide ("").
