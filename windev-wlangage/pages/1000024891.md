# <Chaîne ANSI>.AnsiVersOem (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android) · **Autres** (Procédures stockées)

Convertit une chaîne de caractères au format ANSI (Windows) en une chaîne de caractères au format OEM (DOS). Les caractères accentués sont différents dans les deux normes. La conversion consiste à modifier les caractères accentués.
**Rappel** :

- ANSI est la norme des caractères au standard Windows.
- OEM est la norme des caractères au standard DOS (ou des fenêtres "console" de Windows).

Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.

## Exemple

```wlangage
Res est une chaîne
ChaîneAConvertir est une chaîne ANSI = "Crème brûlée"
Res = ChaîneAConvertir.AnsiVersOem()
```

## Syntaxe

```wlangage
<Résultat> = <Chaîne à convertir>.AnsiVersOem()
```

`<Résultat>` *Chaîne de caractères OEM*
> Chaîne de caractères au format OEM.
`<Chaîne à convertir>` *Chaîne de caractères ANSI*
> Chaîne de caractères au format ANSI à convertir.

## Remarques

- La fonction **<Chaîne ANSI>.AnsiVersOem** ne convertit pas les caractères ayant un code ASCII compris entre 0 et 31 (caractères de contrôle).
- **Attention** : Ne pas utiliser la fonction **<Chaîne ANSI>.AnsiVersOem** avec une chaîne de caractères contenant des caractères spécifiques OEM (caractères accentués) : ces caractères seront transformés et le résultat sera incorrect.

**Composante : wd300vm.dll**
