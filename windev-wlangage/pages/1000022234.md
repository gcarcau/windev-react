# CadrageHorizontal (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

La propriété **CadrageHorizontal** permet de connaître et de modifier le cadrage horizontal d'un champ ou d'un texte. Cette propriété est utilisable sur :

- les champs d'une fenêtre ou d'une page. Pour plus de détails, consultez [CadrageHorizontal](2510023.md).
- une variable de type [pdfSignature](1000022255.md).
- une variable de type [Toast](1000024638.md).
- une variable de type [picTexte](1000025178.md).
- une variable de type [diagTexte](1410088393.md).
