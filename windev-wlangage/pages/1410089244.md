# Allemagne.VérifieIdNr (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un numéro IdNr (numéro d'identification personnel en Allemagne).

## Exemple

```wlangage
// Test d'une variableMonNuméroIdNr est une chaîne = "36574261809"Allemagne.VérifieIdNr(MonNuméroIdNr) // renvoie Vrai // Test d'un champSAI_NuméroIdNr = "ABC"Allemagne.VérifieIdNr(SAI_NuméroIdNr) // renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = Allemagne.VérifieIdNr(<Numéro à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un numéro IdNr valide.
> - Faux dans le cas contraire.
`<Numéro à vérifier>` *Nom de champ ou variable de type chaîne*
> Numéro IdNr à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.

**Composante : wd300std.dll**
