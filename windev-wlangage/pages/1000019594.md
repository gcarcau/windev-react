# Fabrique logicielle : Gestion des droits

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Pour sécuriser l'exécution des plans d'action, il est possible de mettre en place un gestion des droits. Cette gestion des droits est mise en place par les utilisateurs définis comme "Administrateur" dans la base de données des Centres de Contrôle.
Il sera par exemple possible de donner moins de droits à un stagiaire qu'à un développeur confirmé.

**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Gestion des droits

Il est possible de définir des droits sur :

- une Fabrique Logicielle,
- une bibliothèque de plans d'action,
- un plan d'action,
- un plan d'action paramétré.

Pour chaque élément, il est possible de donner un ou plusieurs droits. Pour chaque droit, il est possible de donner une des valeurs suivantes :

| Autorisé | L'utilisateur est autorisé à utiliser la fonctionnalité. |
| --- | --- |
| Hérité | Le droit est indéfini à ce niveau. Le droit défini au niveau supérieur est utilisé :  - droit défini au niveau du plan d'action pour un plan d'action paramétré. - droit défini au niveau de la bibliothèque pour un plan d'action. - droit défini au niveau de la fabrique logicielle pour une bibliothèque. |
| Interdit | L'utilisateur n'est pas autorisé à utiliser la fonctionnalité. S'il tente d'utiliser cette fonctionnalité, un message indique que l'utilisateur ne possède pas les droits nécessaires pour utiliser cette fonctionnalité. |

## Droits disponibles et mise en place

### Droits sur la fabrique logicielle
Les différents droits disponibles **sur la fabrique logicielle** sont les suivants :

- Ajouter ou supprimer le paramétrage d'un plan d'action.
- Modifier le paramétrage d'un plan d'action.
- Exécuter un plan d'action.
- Ajouter, modifier ou supprimer une bibliothèque de plans d'action.
- Modifier la configuration de la fabrique logicielle. Ce droit concerne :
  - l'ajout, la pause ou la suppression d'un automate.
  - la modification de l'ordre de priorité des automates.
  - l'ajout ou la suppression d'étiquettes.
  - la modification des étiquettes liées aux automates.
  - la modification de la valeur des variables d'environnement.

Pour définir ces droits :

1. Lancez l'administrateur de la Fabrique Logicielle : sous le volet "Outils", dans le groupe "Utilitaires", cliquez sur "WDFAdmin".
2. Dans la fenêtre qui s'affiche, indiquez le nom du coordinateur auquel l'administrateur doit se connecter.
3. L'administrateur de la Fabrique Logicielle se lance.
4. Dans l'onglet "Options", cliquez sur "Droits de la Fabrique Logicielle".
5. Pour chaque utilisateur, indiquez les droits nécessaires puis appliquez les modifications.

### Droits sur une bibliothèque
Les différents droits disponibles **sur une bibliothèque** sont les suivants :

- Ajouter ou supprimer le paramétrage d'un plan d'action
- Modifier le paramétrage d'un plan d'action
- Exécuter un plan d'action
- Ajouter, modifier ou supprimer une bibliothèque de plans d'action

Pour définir ces droits :

1. Lancez l'administrateur de la Fabrique Logicielle : sous le volet "Outils", dans le groupe "Utilitaires", cliquez sur "WDFAdmin".
2. Dans la fenêtre qui s'affiche, indiquez le nom du coordinateur auquel l'administrateur doit se connecter.
3. L'administrateur de la Fabrique Logicielle se lance.
4. Dans l'onglet "Entrepôt", sélectionnez une bibliothèque puis cliquez sur "Editer la bibliothèque".
5. Dans la description de la bibliothèque, cliquez sur "Droits de la bibliothèque".
6. Pour chaque utilisateur, indiquez les droits nécessaires puis appliquez les modifications.

### Droits sur un plan d'action
Les différents droits disponibles **sur un plan d'action** sont les suivants :

- Ajouter ou supprimer le paramétrage d'un plan d'action.
- Modifier le paramétrage d'un plan d'action.
- Exécuter un plan d'action.

Pour définir ces droits :

1. Lancez l'administrateur de la Fabrique Logicielle : sous le volet "Outils", dans le groupe "Utilitaires", cliquez sur "WDFAdmin".
2. Dans la fenêtre qui s'affiche, indiquez le nom du coordinateur auquel l'administrateur doit se connecter.
3. L'administrateur de la Fabrique Logicielle se lance.
4. Dans l'onglet "Entrepôt", sélectionnez un plan d'action présent dans une bibliothèque puis cliquez sur "Editer le plan d'action".
5. Dans la description du plan d'action, cliquez sur "Droits du plan d'action".
6. Pour chaque utilisateur, indiquez les droits nécessaires puis appliquez les modifications.

### Droits sur un plan d'action paramétré
Les différents droits disponibles **sur un plan d'action paramétré** sont les suivants :

- Ajouter ou supprimer le paramétrage d'un plan d'action.
- Modifier le paramétrage d'un plan d'action.
- Exécuter un plan d'action.

Pour définir ces droits :

1. Lancez l'administrateur de la Fabrique Logicielle : sous le volet "Outils", dans le groupe "Utilitaires", cliquez sur "WDFAdmin".
2. Dans la fenêtre qui s'affiche, indiquez le nom du coordinateur auquel l'administrateur doit se connecter.
3. L'administrateur de la Fabrique Logicielle se lance.
4. Dans l'onglet "Plans d'action", sélectionnez un plan d'action paramétré puis cliquez sur "Modifier le paramétrage".
5. Dans la description du plan d'action paramétré, cliquez sur "Droits".
6. Pour chaque utilisateur, indiquez les droits nécessaires puis appliquez les modifications.
