# Champ Editeur d'images WEBDEV : Fonctionnalités

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

## Présentation

Le champ Editeur d'images WEBDEV propose de nombreuses fonctionnalités accessibles via plusieurs rubans, en haut et en bas du champ.[image: Editeur d'images WEBDEV]

## Détail des fonctionnalités

### Ouvrir une image sous l'éditeur
Pour ouvrir une image dans le champ Editeur d'images, il est possible :

- soit de dropper directement un fichier image dans le champ,
- soit de dropper un image contenue dans la page.
- soit de cliquer sur le bouton "+" dans le ruban du bas de l'éditeur. [image: Ajout d'une image]Le menu permet alors :
  - d'ouvrir une image depuis le disque : il suffit de préciser dans la fenêtre qui s'affiche le chemin du fichier (ou de dropper le fichier voulu). [image: Ajout d'un fichier]
  - d'ouvrir une image depuis une URL : il suffit de préciser dans la fenêtre qui s'affiche l'URL correspondante. [image: Ajour d'une URL]

### Dessiner sur l'image
Le champ Editeur d'images permet de dessiner librement sur l'image affichée, via le crayon, le feutre ou le surligneur. [image: Ajout d'un dessin]Lorsqu'une de ces options est sélectionnée, une nouvelle barre d'outils apparaît en bas du champ permettant de configurer la couleur et l'épaisseur du trait. [image: Configuration]Il est également possible de supprimer le trait en cours.

### Ajouter une forme sur l'image
Le champ Editeur d'images permet d'ajouter :

- une ligne ou une flèche sur l'image affichée. [image: Ajout d'une ligne]
- une forme (triangle, rectangle ou cercle). [image: Ajout d'une forme]

Lorsqu'une de ces options est sélectionnée, une nouvelle barre d'outils apparaît en bas du champ permettant de configurer la couleur et l'épaisseur du trait. Il est également possible de supprimer la forme en cours.

### Ajouter un texte sur l'image
Le champ Editeur d'images permet d'ajouter un texte sur l'image. [image: Ajout d'un texte]Lorsqu'une de ces options est sélectionnée, le texte modifiable apparait dans l'image dans une zone de texte, et une nouvelle barre d'outils apparaît en bas du champ permettant de configurer la police, la couleur, .... [image: Configuration du texte]Il est également possible de supprimer le texte en cours.

### Manipuler l'image
Le champ Editeur d'images permet de manipuler l'image. [image: Manipulations de l'image]Il est possible de recadrer, agrandir et faire pivoter l'image. La barre d'outils en bas du champ s'adapte pour proposer les différentes options : [image: Manipulations de l'image]
Pour zoomer l'image, il est possible d'utiliser :

- soit la roulette de la souris,
- soit les boutons + et - situés dans la barre du haut de l'éditeur.

A tout moment, il est possible de sauver l'image en la téléchargeant via le bouton fléché ([image: Télécharger]) présent dans la barre du haut de l'éditeur.
