# Suisse.VérifieIDE (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un numéro IDE (numéro d'identification des entreprises en Suisse).

## Exemple

```wlangage
// Test d'une variableMonNuméroIDE est une chaîne = "CHE320488267"Suisse.VérifieIDE(MonNuméroIDE)  // renvoie Vrai // Test d'un champSAI_NuméroIDE = "ABC"Suisse.VérifieIDE(SAI_NuméroIDE) // renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = Suisse.VérifieIDE(<Numéro à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un numéro IDE valide.
> - Faux dans le cas contraire.
`<Numéro à vérifier>` *Nom de champ ou variable de type chaîne*
> Numéro IDE à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.

**Composante : wd300std.dll**
