# Profondeur (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Apple Watch)

La propriété **Profondeur** permet de connaître la profondeur d'un élément. Cette propriété est utilisable sur :

- une variable de type [xmlLecteur](1000023392.md).
- Nouveauté 2025
  une variable de type [jsonLecteur](1410090783.md).
  **Attention** : Cette fonctionnalité est disponible uniquement à partir de la version 2025 Update 3.
