# <Source>.SupprimeToutRayé (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Transforme les enregistrements rayés (fonction [<Source>.Raye](1000025051.md)) d'un fichier de données en enregistrements supprimés. La place occupée par les enregistrements rayés est ainsi libérée et pourra être réutilisée lors des prochains ajouts (fonction [<Source>.Ajoute](1000024187.md)).
**Rappel** : Un enregistrement rayé est inactif et disparaît de l'index. Les données de cet enregistrement rayé ne sont pas supprimées (contrairement à la fonction [<Source>.Supprime](1000025071.md)).

## Exemple

```wlangage
// Supprime tous les enregistrements rayés du fichier de données "Client"
Client.SupprimeToutRayé()
```

## Syntaxe

```wlangage
<Résultat> = <Source>.SupprimeToutRayé()
```

`<Résultat>` *Booléen*
> - Vrai si l'enregistrement a été supprimé,
> - Faux en cas de problème : l'enregistrement n'est pas supprimé. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Source>` *Type correspondant à la source spécifiée*
> Nom du fichier de données manipulé.

## Remarques

Cette fonction n'est pas adaptée à des fichiers xBase.

**Classification Métier / UI : Code métier**

**Composante : wd300hf.dll**
