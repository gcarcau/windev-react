# HVérifieMiseAJourServeur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Vérifie s'il existe une version plus récente du serveur HFSQL pouvant être mise à jour automatiquement.

## Exemple

```wlangage
MaConnexion est une Connexion soit sNouvelleVersion = HVérifieMiseAJourServeur(MaConnexion)SI sNouvelleVersion<>"" ALORS Info(sNouvelleVersion)
```

## Syntaxe

```wlangage
<Résultat> = HVérifieMiseAJourServeur(<Connexion>)
```

`<Résultat>` *Chaîne de caractères*
> Version de la mise à jour disponible sur le serveur HFSQL.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion au serveur HFSQL. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).

## Remarques

Le serveur de mise à jour (contenant le pack de mise à jour du serveur HFSQL) peut être défini par la fonction [HGèreMiseAJourServeur](1000022635.md).

**Composante : wd300hf.dll**
