# Ordre (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Ordre** permet de connaître et de définir l'ordre utilisé pour une liste d'éléments. Cette propriété est utilisable :

- sur une variable de type [RendezVous](1000019244.md).
- sur une variable de type [ActionRapide](1410090054.md).
