# sfRésultatExécuteTraitement (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Le type **sfRésultatExécuteTraitement** permet de connaître le résultat de la fonction [SFExécuteTraitement](1000018523.md). Les caractéristiques de ce résultat peuvent être connues à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Propriétés

### Propriétés spécifiques à la description des variables de type sfRésultatExécuteTraitement
Les propriétés suivantes peuvent être utilisées pour manipuler le résultat de la fonction [SFExécuteTraitement](1000018523.md) :

| Nom | Type manipulé | Effet |
| --- | --- | --- |
| Erreur | Tableau de [sfErreur](1000018455.md) | Compte-rendu d'erreurs. |
| IDActeur | Chaîne de caractères | Identifiants des acteurs actuellement assignés à l'étape de validation. **Cette propriété est disponible en lecture seulement**. |
| IDEntité | Chaîne de caractères | Identifiant de l'objet Salesforce en cours de traitement. **Cette propriété est disponible en lecture seulement**. |
| IDInstance | Chaîne de caractères | Identifiant de l'instance de traitement associé à l'objet Salesforce. **Cette propriété est disponible en lecture seulement**. |
| IDNouvelleTâche | Chaîne de caractères | Identifiants des nouvelles tâches liées au traitement. Ces identifiants sont séparés par des RC (Retour-chariot). **Cette propriété est disponible en lecture seulement**. |
| StatutInstance | Chaîne de caractères | Statut de l'instance du traitement. Cette propriété peut par exemple correspondre à "Approved", "Rejected", "Remove", ou "Pending". **Cette propriété est disponible en lecture seulement**. |
| Succès | Booléen | - Vrai si le traitement s'est correctement déroulé, - Faux en cas d'erreur.  **Cette propriété est disponible en lecture seulement**. |
