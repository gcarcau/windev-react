# <Variable docFragment>.Insère (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Remplace le contenu du fragment en cours. Les objets manipulables sont :

- un élément,
- un document,
- un paragraphe,
- un texte,
- une image,
- un fragment,
- une table des matières.

## Syntaxe

```wlangage
<Résultat> = <Fragment>.Insère(<Objet à insérer>)
```

`<Résultat>` *Variable de type docFragment*
> Variable de type [docFragment](1000022482.md) contenant le fragment inséré.
`<Fragment>` *Variable de type docFragment*
> Nom de la variable de type [docFragment](1000022482.md) à manipuler. Le contenu de ce fragment sera remplacé par l'objet spécifié.
`<Objet à insérer>` *Type correspondant à l'élément à insérer*
> Objet remplaçant le contenu du fragment. Cet objet peut correspondre :
>
> - à une chaîne de caractères.
>   Il est possible d'utiliser les constantes suivantes dans le texte pour gérer les différents sauts possibles :
>   | *docSautDeColonne* | Ajoute un saut de colonne dans une section multicolonne. Si la section n'est pas multicolonne, un saut de page est ajouté. |
>   | --- | --- |
>   | *docSautDeLigne* | Ajoute un saut de ligne. |
>   | *docSautDePage* | Ajoute un saut de page. |
>   | *docSautDeParagraphe* | Ajoute un saut de paragraphe. |
>
>
>
> - au nom d'une variable de type [docElément](1000022484.md).
> - au nom d'une variable de type [Document](1000022461.md).
> - au nom d'une variable de type [docParagraphe](1000022483.md).
> - au nom d'une variable de type [Image](1000019650.md).
> - au nom d'une variable de type [docFragment](1000022482.md).
> - au nom d'une variable de type [docTableDesMatières](1000024893.md).
