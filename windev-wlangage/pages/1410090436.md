# CertificatExporte (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Exporte un certificat du magasin de certificats Windows vers un fichier au format "pfx"ou "cert".

## Exemple

```wlangage
tabCertificats est un tableau de Certificat = CertificatListe()

POUR TOUT UnCertificat DE tabCertificats
	SELON UnCertificat.DateValiditéFin
		CAS <= Maintenant() :
			Erreur("Le certificat [%UnCertificat.Nom%] (N° de série [%UnCertificat..NuméroSérie%]) est expiré !")
			SORTIR SELON
		CAS <= (Maintenant() - 7 j) :
			Erreur("Le certificat [%UnCertificat.Nom%] (N° de série [%UnCertificat..NuméroSérie%]) expire dans moins de 7 jours !")
			SORTIR SELON
		AUTRES CAS
			CONTINUER
	FIN
	// On exporte les certificats expirés
	// et on les envoie par mail à l'administrateur réseau
	// pour qu'il puisse déterminer plus facilement le certificat à renouveler
	sCheminCerficatExporté est une chaîne
	sCheminCerficatExporté = CertificatExporte(UnCertificat, UnCertificat.MotDePasse, fRepExe() / "Certificat")
	// Envoi du certificat à l'administrateur réseau
	// ...
	fSupprime(sCheminCerficatExporté)
FIN
```

## Syntaxe

```wlangage
<Résultat> = CertificatExporte(<Certificat> , <Mot de passe> , <Fichier de sauvegarde>)
```

`<Résultat>` *Chaîne de caractères*
> Nom complet du fichier exporté, avec l'extension générée.
`<Certificat>` *Variable de type Certificat*
> Nom de la variable [Certificat](1000019287.md) contenant la description du certificat à exporter.
`<Mot de passe>` *Chaîne de caractères ou Chaîne secrète*
> Mot de passe de la clé privée nécessaire à l'export du certificat.
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).
`<Fichier de sauvegarde>` *Chaîne de caractères*
> Nom complet du fichier d'export du certificat. L'extension du fichier ne doit pas être indiquée. En effet, cette extension sera ajoutée lors de l'export du certificat. Si le certificat possède une clé privée, le fichier sera exporté au format "pfx" sinon il sera exporté au format "cert".
