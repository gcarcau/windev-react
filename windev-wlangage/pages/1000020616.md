# Fonctions de gestion des champs Sélecteur

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions de gestion des champs Sélecteur (syntaxe préfixée)](1000021190.md)).
Les fonctions permettant de gérer les champs Sélecteur sont les suivantes :

| [SélecteurAjoute](1000020598.md) | Ajoute une nouvelle option dans un champ Sélecteur. |
| --- | --- |
| [SélecteurInsère](1000020599.md) | Insère une nouvelle option dans un champ Sélecteur. |
| [SélecteurOccurrence](1000021184.md) | Renvoie le nombre d'options présentes dans un champ Sélecteur. |
| [SélecteurSupprime](1000020600.md) | Supprime une option d'un champ Sélecteur. |
