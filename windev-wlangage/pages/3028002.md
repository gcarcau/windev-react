# DDEChaîne (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Retourne les informations récupérées par la fonction [DDERécupère](3028017.md).
**Rappel** : La fonction [DDERécupère](3028017.md) permet de récupérer une donnée. Cette donnée est stockée dans **DDEChaîne**.

## Exemple

```wlangage
// Exécute une action par le serveur
DDEExécute(NumConnexion, "EXE1")
SI DDERécupère(NumConnexion, "Item1") ALORS
	Info("La donnée récupérée est" + DDEChaîne())
FIN
```

## Syntaxe

```wlangage
<Résultat> = DDEChaîne([<Identifiant connexion>])
```

`<Résultat>` *Chaîne de caractères*
> Informations récupérées.
`<Identifiant connexion>` *Entier optionnel*
> Identifiant de la connexion renvoyé par la fonction [DDEConnecte](3028015.md). Si ce paramètre n'est pas précisé, **DDEChaîne** utilise la dernière connexion manipulée.

**Composante : wd300std.dll**
