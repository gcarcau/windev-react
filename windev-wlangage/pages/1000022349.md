# ServeurAppliSupprimeTâchePlanifiée (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux)

Supprime une tâche planifiée associée à l'application (site ou Webservice).

## Exemple

```wlangage
uneTâchePlanifiée est un serveurAppliTâchePlanifiéeuneTâchePlanifiée.Nom = "MaTâche" // Tente de supprimer la Tâche planifiée dont le nom est "MaTâche"ServeurAppliSupprimeTâchePlanifiée(uneTâchePlanifiée)
```

## Syntaxe

```wlangage
<Résultat> = ServeurAppliSupprimeTâchePlanifiée(<Tâche planifiée>)
```

`<Résultat>` *Booléen*
> - Vrai si la tâche planifiée a été supprimée,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Tâche planifiée>` *Type associé*
> Tâche planifiée à supprimer. Ce paramètre peut correspondre :
>
> - à une variable de type [serveurAppliTâchePlanifiée](1000022367.md).
> - au nom d'une procédure. La tâche planifiée associée au nom de cette procédure sera supprimée.
> - au nom d'une tâche planifiée. La tâche planifiée correspondante sera supprimée.

**Composante : wd300page.dll**
