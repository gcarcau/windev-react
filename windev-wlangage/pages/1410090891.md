# <Variable Connexion>.SupprimeHistoriquePlanification (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Supprime l'historique d'exécution d'un élément planifié sur un serveur HFSQL : tâche planifiée (procédure stockée), sauvegarde, optimisation, rafraîchissement d'une vue matérialisée.

## Exemple

```wlangage
MaConnexionBase est une Connexion
MaSauvegarde est une hDescriptionSauvegarde

SI PAS MaConnexionBase.SupprimeHistoriquePlanification(MaSauvegarde) ALORS
	Trace(HErreurInfo())
FIN
```

## Syntaxe

#### Supprimer l'historique d'une planification de sauvegarde

```wlangage
<Résultat> = <Connexion>.SupprimeHistoriquePlanification(<Sauvegarde planifiée>)
```

`<Résultat>` *Booléen*
> - Vrai si l'historique a été supprimé,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion à manipuler.
`<Sauvegarde planifiée>` *Variable de type hDescriptionSauvegarde*
> Nom de la variable de type [hDescriptionSauvegarde](1000017455.md) manipulée.

#### Supprimer l'historique d'une tâche d'optimisation planifiée

```wlangage
<Résultat> = <Connexion>.SupprimeHistoriquePlanification(<Tâche d'optimisation planifiée>)
```

`<Résultat>` *Booléen*
> - Vrai si l'historique a été supprimé,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion à manipuler.
`<Tâche d'optimisation planifiée>` *Variable de type hOptimisationPlanifiée*
> Nom de la variable de type [hOptimisationPlanifiée](1000018854.md) manipulée.

#### Supprimer l'historique d'une tâche planifiée

```wlangage
<Résultat> = <Connexion>.SupprimeHistoriquePlanification(<Tâche planifiée>)
```

`<Résultat>` *Booléen*
> - Vrai si l'historique a été supprimé,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion à manipuler.
`<Tâche planifiée>` *Variable de type hTâchePlanifiée*
> Nom de la variable de type [hTâchePlanifiée](1000017448.md) à manipuler.

`<Vue matérialisée>` *Variable de type hPlanificationVueMatérialisée*
> Nom de la variable de type [hPlanificationVueMatérialisée](1000021444.md) à manipuler.
