# Ecran,Xvar (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Détermine si un champ fait partie ou non de la fenêtre en cours.

## Exemple

```wlangage
// En C// Vérifie si le champ NOMCLI est présent dans la fenêtreAPPELWD("Ecran,XVar,%s",NomChamp);if WDEntier==1 APPELWD("ECRAN,PREMIER,%s",NomChamp);
```

```wlangage
// En Pascal(* Vérifie si le champ NOMCLI est présent dans la fenêtre *)APPELWD('Ecran,XVar,NOMCLI');if WdEntier=1 then APPELWD('ECRAN,PREMIER,'+NomChamp);
```

```wlangage
// En VB' Vérifie si le champ NOMCLI est présent dans la fenêtrecall APPELWD("Ecran,XVar,NOMCLI")if WdEntier=1 then  APPELWD("ECRAN,PREMIER,"+NomChamp)end if
```

## Syntaxe

```wlangage
Ecran,Xvar(<Nom du champ> [, <Indice>])
```

`<Nom du champ>` *Chaîne de caractères*
> Nom du champ dans lequel le texte doit être affiché.
`<Indice>` *Chaîne de caractères (optionnelle)*
> Indice du champ.

## Remarques

La variable WdEntier vaut :

- 0 si le champ n'est pas présent dans la fenêtre
- 1 si le champ est présent dans la fenêtre.
