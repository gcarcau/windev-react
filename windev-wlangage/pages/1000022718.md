# <Variable Connexion>.ModifiePropriétéFichier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Modifie les propriétés d'un fichier de données HFSQL situé sur un serveur.
**Remarque** : Il est possible de connaître les propriétés d'un fichier de données HFSQL grâce à la fonction [<Variable Connexion>.InfoPropriétéFichier](1000022674.md).

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion

ResModif est un booléen
ResModif = MaConnexion.ModifiePropriétéFichier(hPropriétaire, "Florence", "MaBase", "Client.fic")
SI ResModif = Vrai ALORS
	Info("Modification effectuée")
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.ModifiePropriétéFichier(<Propriété à modifier> , <Nouvelle valeur> , <Base de données> , <Fichier de données>)
```

`<Résultat>` *Booléen*
> - Vrai si les propriétés ont été modifiées,
> - Faux dans le cas contraire. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle la valeur d'une propriété doit être modifiée.
`<Propriété à modifier>` *Constante de type Entier*
> Propriété du fichier de données à modifier :
>
> | *hNotes* | Description du fichier de données ou toute autre information associée au fichier de données.  Si cette constante est utilisée, <Nouvelle valeur est une chaîne de caractères contenant le texte de la note. |
> | --- | --- |
> | *hPropriétaire* | Propriétaire du fichier de données.  Si cette constante est utilisée, <Nouvelle valeur est une chaîne de caractères contenant le nom du propriétaire. |
`<Nouvelle valeur>` *Chaîne de caractères*
> Nouvelle valeur de la propriété.
`<Base de données>` *Chaîne de caractères*
> Nom de la base de données contenant le fichier de données pour lequel les propriétés doivent être modifiées.
> Si ce paramètre correspond à une chaîne vide (""), la base de données utilisée sera celle définie dans la connexion.
> Si aucune base de données n'est définie dans la connexion, une erreur WLangage sera générée.
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données pour lequel les propriétés doivent être modifiées. L'extension du fichier doit être précisée.

## Remarques

### Changer le propriétaire d'un fichier de données

- L'utilisateur spécifié comme nouveau propriétaire doit être un utilisateur existant sur le serveur. Si l'utilisateur n'existe pas, une erreur WLangage est générée.
- Pour modifier le propriétaire, l'utilisateur faisant la modification doit :
  - soit être un "Super utilisateur".
  - soit avoir le droit de changer le propriétaire du fichier de données (droit correspondant à la constante *hChangeDroitPropriétaire*). Pour savoir si l'utilisateur a le droit approprié, utilisez la fonction [<Variable Connexion>.InfoPropriétéFichier](1000022674.md).
