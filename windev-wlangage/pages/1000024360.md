# <Variable Image>.IncrusteCouleur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Incruste une couleur dans une image contenue dans une variable de type [Image](1000019650.md). La couleur est appliquée au contenu de l'image. L'utilisation de l'opacité permet d'obtenir des effets spécifiques.
> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Dessiner en WINDEV, WEBDEV et WINDEV Mobile.

## Exemple

```wlangage
// Utilisation d'une variable de type Image
MonImage est une Image
MonImage = "Image.png"
// Incruste la couleur Jaune bulle avec 5% d'opacité
MonImage.IncrusteCouleur(JauneBulle, 5)
// Affiche l'image dans un champ Image
IMG_ImagePaysage = MonImage
```

## Syntaxe

```wlangage
<Variable Image>.IncrusteCouleur(<Couleur à incruster> [, <Opacité>])
```

`<Variable Image>` *Variable de type Image*
> Variable de type [Image](1000019650.md) correspondant à l'image à manipuler.
`<Couleur à incruster>` *Entier*
> Couleur à incruster dans l'image. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md).
`<Opacité>` *Réel optionnel*
> Pourcentage d'opacité utilisée pour la couleur incrustée (100% par défaut, aucune opacité n'est appliquée).

**Composante : wd300pnt.dll**
