# docElémentTexte (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Le type **docElémentTexte** permet de manipuler les caractéristiques d'un élément de type Texte présent dans une variable de type [docElément](1000022484.md).
Les caractéristiques de ce type de variable peuvent être manipulées à l'aide de différentes propriétés WLangage.

**ATTENTION : Ce type ne doit pas être utilisé directement. Il doit être utilisé uniquement via le type [docElément](1000022484.md)**.

## Propriétés

### Propriétés spécifiques à la description des variables de type docElémentTexte
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **docElémentTexte** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| MiseEnForme | Variable de type [docMiseEnForme](1000022817.md) | Informations de mise en forme de cet élément. |
| Valeur | Chaîne de caractères | Texte de l'élément. |
