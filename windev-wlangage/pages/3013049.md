# Constantes utilisées par la fonction TraceDébut

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

La fonction [TraceDébut](3013052.md) utilise les constantes suivantes :

| Constante | Détail |
| --- | --- |
| **trConsole** | La trace est redirigée vers la console. |
| **trCréation** | Vide la fenêtre de trace |
| **trDessusTout** | Fenêtre de trace affichée au dessus de toutes les fenêtres système |
| **trDésactive** | Tous les appels à la fonction [Trace](3013050.md) seront ignorés. |
| **trFenêtre** | La fenêtre de Trace s'affiche en haut à gauche de l'écran. _(WEBDEV - Code Serveur)_ En déploiement d'un site, la fenêtre de trace ne s'affichera pas. |
| **trFichier** | La fenêtre de Trace ne s'affichera plus et les informations contenues dans la fenêtre de Trace seront enregistrées dans le fichier <Fichier de trace>. _(Linux)_ Seule cette constante est disponible. Par défaut, ce fichier est créé dans le répertoire temporaire d'UNIX, sous le nom "Trace_<Projet>.txt". |
| **trFenêtre** + **trFichier** | La fenêtre de trace s'affichera et le contenu de la fenêtre de trace sera également enregistré dans le fichier <Fichier de Trace> |
