# <Variable Polygone2D>.EnveloppeConvexe (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Calcule l'enveloppe convexe du polygone en 2 dimensions spécifié. L'enveloppe convexe correspond à la plus petite géométrie convexe qui englobe toute la géométrie spécifiée.
L'enveloppe convexe d'un objet ou d'un regroupement d'objets géométriques est l'ensemble convexe le plus petit parmi les ensembles qui contiennent l'objet.
Dans un plan, l'enveloppe convexe peut être comparée à la région limitée par un élastique qui englobe tous les points qu'on relâche jusqu'à ce qu'il se contracte au maximum.
L'enveloppe convexe correspond en général à un polygone.

## Exemple

```wlangage
// Création d'un polygone non convexe (voir image)
oPolygone2D_1 est un Polygone2D
oPolygone2D_1.Contour.AjoutePoint(-1.00, 3.00)
oPolygone2D_1.Contour.AjoutePoint(0.00, 4.00)
oPolygone2D_1.Contour.AjoutePoint(2.00, 3.00)
oPolygone2D_1.Contour.AjoutePoint(2.00, 2.00)
oPolygone2D_1.Contour.AjoutePoint(3.00, 3.00)
oPolygone2D_1.Contour.AjoutePoint(4.00, 2.00)
oPolygone2D_1.Contour.AjoutePoint(2.00, 1.00)
oPolygone2D_1.Contour.AjoutePoint(0.00, 1.00)
oPolygone2D_1.Contour.AjoutePoint(1.00, 0.00)
oPolygone2D_1.Contour.AjoutePoint(2.00, 0.00)
oPolygone2D_1.Contour.AjoutePoint(2.00, -3.00)
oPolygone2D_1.Contour.AjoutePoint(-2.00, -3.00)
oPolygone2D_1.Contour.AjoutePoint(-2.00, -2.00)
oPolygone2D_1.Contour.AjoutePoint(-1.00, -2.00)
oPolygone2D_1.Contour.AjoutePoint(0.00, -1.00)
oPolygone2D_1.Contour.AjoutePoint(0.00, 0.00)
oPolygone2D_1.Contour.AjoutePoint(-1.00, 0.00)
oPolygone2D_1.Contour.AjoutePoint(-2.00, -1.00)
oPolygone2D_1.Contour.AjoutePoint(-3.00, 0.00)
// Ajout du dernier point (identique au premier)
oPolygone2D_1.Contour.AjoutePoint(-1.00, 3.00)
// Corrige la géométrie créée
oPolygone2D_1 = oPolygone2D_1.Corrige()

// Polygone convexe englobant le polygone d'entrée. En pointillés dans l'image
enveloppeConvexe est un Polygone2D = oPolygone2D_1.EnveloppeConvexe()
```
