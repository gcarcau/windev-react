# Fonctions de gestion des champs Interrupteur

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions permettant de gérer les champs Interrupteur sont les suivantes :

| [InterrupteurAjoute](1000020595.md) | Ajoute une nouvelle option dans un champ Interrupteur. |
| --- | --- |
| [InterrupteurInsère](1000020597.md) | Insère une nouvelle option dans un champ Interrupteur. |
| [InterrupteurOccurrence](1000021274.md) | Renvoie le nombre d'options présentes dans un champ Interrupteur. |
| [InterrupteurSupprime](1000020596.md) | Supprime une option d'un champ Interrupteur. |
