# HNotifSupprimeDestinataireEmail (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Supprime les destinataires d'une notification par email. Cette notification est envoyée par le serveur HFSQL lorsqu'il rencontre un problème.

## Exemple

```wlangage
cnxConnexionCS est une Connexion
cnxConnexionCS.Provider = hAccèsHFClientServeur
cnxConnexionCS.Utilisateur = "admin"
cnxConnexionCS.MotDePasse = ""
cnxConnexionCS.Serveur = "test:4900"
HOuvreConnexion(cnxConnexionCS)
...
HNotifConfigure(cnxConnexionCS, hNotifEmail, "FLEUR:25", "test.doc", "doc", "doc@pcsoft.com", Faux)
HNotifAjouteDestinataireEmail(cnxConnexionCS, "test.appli@gmail.com", hNotifAvertissement)
...
HNotifSupprimeDestinataireEmail(cnxConnexionCS, "doc@pcsoft.com")
```

## Syntaxe

```wlangage
<Résultat> = HNotifSupprimeDestinataireEmail(<Connexion> , <Destinataire>)
```

`<Résultat>` *Booléen*
> - Vrai si la suppression a été effectuée.
> - Faux dans le cas contraire. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion à manipuler. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Destinataire>` *Chaîne de caractères*
> Adresse email du destinataire à supprimer.

**Composante : wd300hf.dll**
