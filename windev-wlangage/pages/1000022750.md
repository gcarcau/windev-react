# <Variable Connexion>.RécupèreSauvegarde (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Récupère en local le contenu d'une sauvegarde compressée (au format ZIP) réalisée sur un serveur HFSQL.

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion
...
MaConnexion.RécupèreSauvegarde(idSauvegarde, "C:\temp\MonFichier.zip", JAUGE_Progress)
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.RécupèreSauvegarde(<Sauvegarde> , <Fichier destination> [, <Jauge>])
```

`<Résultat>` *Booléen*
> - Vrai si la sauvegarde a été récupérée,
> - Faux en cas de problème. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion vers le serveur contenant la sauvegarde à récupérer.
`<Sauvegarde>` *Entier ou chaîne de caractères*
> Sauvegarde à récupérer. Peut correspondre à :
>
> - **Identifiant de la sauvegarde**. Cet identifiant peut correspondre à l'identifiant d'une sauvegarde complète ou d'une sauvegarde différentielle.
>   Lors d'une sauvegarde immédiate, cet identifiant est renvoyé par la fonction [<Variable Connexion>.Sauvegarde](1000022752.md). Cet identifiant peut également être obtenu grâce à la fonction [<Variable Connexion>.InfoSauvegarde](1000022679.md).
>   Lors d'une sauvegarde planifiée, cet identifiant correspond à la propriété **Identifiant** de la variable [hDescriptionSauvegarde](1000017455.md).
> - **Chemin et nom de la sauvegarde**. Ce nom a été spécifié lors de la sauvegarde. Ce nom peut également être obtenu grâce à la fonction [<Variable Connexion>.InfoSauvegarde](1000022679.md). Si ce nom correspond à un chemin relatif, la sauvegarde sera recherchée dans le sous-répertoire "Backup" du serveur HFSQL. Pour spécifier le répertoire du service Manta, il suffit d'utiliser la chaîne de caractères "%%EXE%%".
`<Fichier destination>` *Chaîne de caractères*
> Chemin et nom du fichier local dans lequel la sauvegarde va être récupérée.
> Dans le cas d'une sauvegarde complète, le fichier destination est un fichier au format zip (l'extension ".zip" doit être précisée dans le nom du fichier).
`<Jauge>` *Nom de champ optionnel, nom de fenêtre optionnel ou entier optionnel*
> - Nom de la fenêtre dans laquelle la jauge doit être affichée ou nom du champ de type Jauge.
> - Identifiant (Handle) de la fenêtre qui affiche la jauge.
>
>
> > _(WEBDEV - Code Serveur)_ Ce paramètre est ignoré.

## Remarques

### Droits nécessaires pour récupérer une sauvegarde
Pour récupérer une sauvegarde, l'utilisateur ou le groupe doit posséder le droit de faire des sauvegardes (constante *hDroitSauvegarde*). Ce droit s'applique aux serveurs et aux bases de données. Par exemple, pour faire une sauvegarde du serveur complet, il faut posséder le droit de faire des sauvegardes au niveau du serveur.
Pour savoir si un utilisateur ou un groupe possède ces droits, utilisez la fonction [<Variable Connexion>.InfoDroitServeur](1000022668.md) ou [HInfoDroitDaseDeDonnées](1000022666.md).

Pour modifier les droits d'un utilisateur ou d'un groupe d'utilisateurs, utilisez la fonction [<Variable Connexion>.ModifieDroitServeur](1000022710.md) ou [<Variable Connexion>.ModifieDroitBaseDeDonnées](1000022707.md).
