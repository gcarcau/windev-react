# <Variable Image>.DessineRectangleArrondi (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Dessine un rectangle arrondi dans une variable de type [Image](1000019650.md).
> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Dessiner en WINDEV, WEBDEV et WINDEV Mobile.

## Exemple

```wlangage
MonImage est une Image = "Test.bmp"
// Dessin d'un rectangle arrondi dont le fond est jaune clair
// et le bord bleu clair
MonImage.DessineRectangleArrondi(10, 10, 50, 50, 3, JauneClair, BleuClair)
IMG_MonDessin = MonImage
```

## Syntaxe

#### Dessiner un rectangle arrondi en spécifiant les coordonnées du rectangle et le diamètre des coins

```wlangage
<Variable Image>.DessineRectangleArrondi(<X1> , <Y1> , <X2> , <Y2> , <Diamètre du coin> [, <Fond> [, <Trait>]])
```

`<Variable Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) à manipuler.
`<X1>` *Entier*
> Abscisse en pixels du coin haut gauche du rectangle.
`<Y1>` *Entier*
> Ordonnée en pixels du coin haut gauche du rectangle.
`<X2>` *Entier*
> Abscisse en pixels du coin bas droit du rectangle.
`<Y2>` *Entier*
> Ordonnée en pixels du coin bas droit du rectangle.
`<Diamètre du coin>` *Entier*
> Diamètre des coins du rectangle.
`<Fond>` *Entier ou constante de type Entier (optionnel)*
> - Couleur du fond du rectangle. Cette couleur peut être :
>   - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
>   - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
>   - [une couleur prédéfinie du WLangage](3010002.md),
>   - une variable de type [Couleur](1000019661.md),
>   - transparente si ce paramètre n'est pas précisé et si la fonction [<Variable Image>.Fond](1000024056.md) n'a pas été utilisée auparavant.
> - Caractéristiques du fond :
>   - variable de type [Fond](1000022038.md). Dans ce cas, le dégradé défini dans la variable n'est pas pris en compte.
>   - caractéristiques spécifiées dans le dernier appel à la fonction [<Variable Image>.Fond](1000024056.md) si ce paramètre n'est pas précisé.
>
>
> Pour utiliser une couleur de fond dégradée, utilisez la fonction [<Variable Image>.DessineRectangleDégradé](1000024238.md).
`<Trait>` *Entier, constante ou variable de type Cadre (optionnel)*
> Couleur du trait du rectangle. Cette couleur peut être :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md),
> - une variable de type [Couleur](1000019661.md).
>
> Si ce paramètre n'est pas spécifié :
>
> - couleur précisée dans le dernier appel à la fonction [<Variable Image>.Stylo](1000024240.md).
> - couleur identique à la couleur utilisée pour le fond si la fonction [<Variable Image>.Stylo](1000024240.md) n'a pas été utilisée.

#### Dessiner un rectangle arrondi en spécifiant les coordonnées du rectangle et le type de cadre

```wlangage
<Variable Image>.DessineRectangleArrondi(<X1> , <Y1> , <X2> , <Y2> , <Cadre> [, <Fond>])
```

`<Variable Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) à manipuler.
`<X1>` *Entier*
> Abscisse en pixels du coin haut gauche du rectangle.
`<Y1>` *Entier*
> Ordonnée en pixels du coin haut gauche du rectangle.
`<X2>` *Entier*
> Abscisse en pixels du coin bas droit du rectangle.
`<Y2>` *Entier*
> Ordonnée en pixels du coin bas droit du rectangle.
`<Cadre>` *Variable de type Cadre*
> Nom de la variable de type [Cadre](15140100.md) définissant les caractéristiques du rectangle. Seules les propriétés suivantes sont prises en compte :
>
> - Arrondi : si la propriété correspond à la constante *ArrondiIndéfini*, aucun arrondi n'est réalisé.
> - Couleur : si la propriété correspond à la constante *CouleurIndéfinie*, la couleur définie lors dernier appel à la fonction [<Variable Image>.Stylo](1000024240.md) est utilisée. Si cette fonction n'a pas été utilisée, la couleur de fond du rectangle est utilisée.
> - Epaisseur : si la propriété correspond à la constante *EpaisseurIndéfinie*, l'épaisseur définie lors du dernier appel à la fonction [<Variable Image>.Stylo](1000024240.md) est utilisée. Si cette fonction n'a pas été utilisée, l'épaisseur vaut 1.
> - Trait : si la propriété correspond à *TraitIndéfini*, le type de trait défini lors du dernier appel à la fonction [<Variable Image>.Stylo](1000024240.md) est utilisé. Si cette fonction n'a pas été utilisée, le trait est un trait continu.
`<Fond>` *Entier, constante ou variable de type Fond (optionnel)*
> - Couleur du fond du rectangle. Cette couleur peut être :
>   - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
>   - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
>   - [une couleur prédéfinie du WLangage](3010002.md),
>   - une variable de type [Couleur](1000019661.md),
>   - transparente si ce paramètre n'est pas précisé et si la fonction [<Variable Image>.Fond](1000024056.md) n'a pas été utilisée auparavant.
> - Caractéristiques du fond :
>   - variable de type [Fond](1000022038.md). Dans ce cas, le dégradé défini dans la variable n'est pas pris en compte.
>   - caractéristiques spécifiées dans le dernier appel à la fonction [<Variable Image>.Fond](1000024056.md) si ce paramètre n'est pas précisé.
>
>
> Pour utiliser une couleur de fond dégradée, utilisez la fonction [<Variable Image>.DessineRectangleDégradé](1000024238.md).
