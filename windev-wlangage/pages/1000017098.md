# ServiceDésinstalle (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Désinstalle un service. Ce service peut être un service présent sur le poste local ou sur un poste distant.
> _(Linux)_ Désactive tous les "runlevels" du service mais n'efface aucun fichier (y compris les scripts de démarrage).

## Exemple

```wlangage
// Désinstalle le service présent dans la table TABLE_Service
SI ServiceDésinstalle(COL_Nom[TABLE_Service]) = Faux ALORS
	Erreur(ErreurInfo(errMessage))
FIN
```

## Syntaxe

```wlangage
<Résultat> = ServiceDésinstalle(<Nom du service> [, <Poste distant>])
```

`<Résultat>` *Booléen*
> - Vrai si le service s'est désinstallé,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Nom du service>` *Chaîne de caractères*
> Nom du service à désinstaller.
`<Poste distant>` *Chaîne de caractères optionnelle*
> Adresse IP du poste distant au format xxx.xxx.xxx.xxx (obtenu par la fonction [NetAdresseIP](3056023.md)) ou nom du poste distant (obtenu par la fonction [NetNomMachine](3056014.md)). Ce paramètre permet de désinstaller un service sur un autre poste. Pour utiliser cette option, l'utilisateur doit être administrateur de la machine distante.
> Si ce paramètre n'est pas précisé ou correspond à une chaîne vide, le service est manipulé en local.

## Remarques

### Cas particulier
La désinstallation d'un service n'est pas immédiate. Une demande est envoyée au système. Cette demande sera réalisée lorsque le service se terminera. Le service pourra être terminé lorsque aucune instance du service ne sera utilisée.
Si le service est en cours d'exécution, il sera automatiquement arrêté avant d'être désinstallé.

**Composante : wd300std.dll**
