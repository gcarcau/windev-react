# Fonctions de gestion des applications avec "live update"

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Les fonctions de gestion des applications avec "live update" sont les suivantes :

| [AppliActiveVersion](1000018846.md) | Active une des versions de l'application disponible dans l'historique des versions sur le serveur d'installation de référence. |
| --- | --- |
| [AppliChangeParamètre](1000017260.md) | Change une information du mécanisme de mise à jour automatique de l'application spécifiée. |
| [AppliContrôle](3013003.md) | Active (ou désactive) le contrôle à distance de l'application WINDEV multi-utilisateurs en cours. Cette fonction est d'un usage avancé. |
| [AppliDéclencheMAJ](1000017261.md) | Déclenche la mise à jour automatique de l'application en cours. |
| [AppliDétecteMAJDisponible](1410087705.md) | Désactive ou personnalise la détection des mises à jour disponibles. |
| [AppliInfoVersion](1000018844.md) | Renvoie des informations sur une version disponible sur le serveur d'installation. |
| [AppliInstalleVersion](1000018918.md) | Installe une version spécifique de l'application. |
| [AppliListeVersion](1000018843.md) | Liste les versions disponibles sur le serveur d'installation de référence. |
| [AppliMAJDisponible](1000017293.md) | Permet de savoir si une mise à jour est disponible pour l'application spécifiée. |
| [AppliParamètre](1000017268.md) | Renvoie des informations sur le mécanisme de mise à jour automatique de l'application spécifiée. |
| [AppliSupprimeVersion](1000018847.md) | Supprime une version de l'historique des versions présent sur le serveur d'installation de référence. |

## Liste des exemples associés :

| [image: WD ContrôleADistance] | Exemples didactiques (WINDEV) : WD ContrôleADistance     [ + ] Cet exemple met en application le contrôle à distance d’une application WINDEV.  Ce contrôle permet de prévenir les utilisateurs de la fermeture prochaine de l’application, d’empêcher de nouveaux utilisateurs de s'y connecter et enfin de fermer l’application. Ce mode doit être généralement réservé à l’administrateur de l’application. Important : pour tester cet exemple, il est nécessaire de le déployer en tant que "Installation avec mise à jour réseau". |
| --- | --- |
