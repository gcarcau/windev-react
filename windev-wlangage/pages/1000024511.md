# <Variable Document>.Imprime (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Imprime le contenu d'une variable de type [Document](1000022461.md) au format "docx".
Remarque : Cette fonction est équivalente à la fonction [iImprimeDoc](1000022390.md).

## Exemple

```wlangage
MonDocument est un Document = "c:\temp\propale.docx"
iDestination(iVisualisateur)
MonDocument.Imprime()
```

## Syntaxe

```wlangage
<Document>.DocImprime()
```

`<Document>` *Variable de type Document ou Chaîne de caractères*
> Nom de la variable de type [Document](1000022461.md) dont le contenu doit être imprimé.
