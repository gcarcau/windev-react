# Cloner un gabarit ou une ambiance

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Gabarits et Ambiances permettent de choisir et d'appliquer un modèle d'UI à un projet. Les Gabarits s'appliquent aux applications, les Ambiances s'appliquent aux sites.
Pour changer l'apparence d'un champ qui utilise un gabarit ou une ambiance, il suffit ensuite de surcharger le style du champ, ou de dissocier le champ du gabarit ou de l'ambiance.

En version 2024, il n'est plus nécessaire de surcharger les styles. Une nouvelle méthode consiste à cloner (ou dupliquer) un Gabarit ou une Ambiance existants, à le renommer, et ensuite à modifier directement les styles, nativement, sans avoir à les surcharger. La description des styles est ainsi plus simple. Notez qu'une fois dupliqué, le Gabarit ou l'Ambiance ne bénéficie plus des éventuelles mises à jour fournies par PC SOFT.

**Le principe est simple** :

1. Vous clonez le gabarit ou l'ambiance.
2. Vous modifiez les styles du gabarit ou de l'ambiance cloné.

## Cloner un gabarit

### Comment le faire ?
Pour cloner un gabarit :

1. Ouvrir le projet WINDEV ou WINDEV Mobile voulu.
2. Sous le menu "Projet", dans le groupe "Autres actions", déroulez "Gabarits du projet" et sélectionnez "Cloner le gabarit du projet".
3. Dans la fenêtre qui s'affiche, indiquez :
  - Le gabarit à cloner. Ce gabarit peut être différent du gabarit en cours dans le projet.
  - Le nom du nouveau gabarit. Ce nom permettra d'identifier le gabarit utilisé.
  - Les différentes options :
    - **Appliquer ce gabarit cloné à toutes les fenêtres qui utilisent le gabarit original** : Cette option permet d'associer automatiquement le gabarit cloné aux fenêtres du projet utilisant le gabarit à cloner. Bien entendu, il est également possible d'appliquer le gabarit cloné ultérieurement (pour plus de détails, consultez [Appliquer un gabarit](2016011.md)).
    - **Renommer les images** : Cette option permet de renommer toutes les images du gabarit cloné avec le nouveau nom du gabarit. Cela permet de modifier facilement les images utilisées par le nouveau gabarit sans risquer de modifier les images utilisées par le gabarit original (par exemple si les deux gabarits restent associés au projet).
    - **Faire de ce gabarit le gabarit par défaut du projet** : Cette option permet de modifier le gabarit associé au projet (dans la fenêtre de description du projet). Dans ce cas, toute nouvelle fenêtre utilisera le gabarit cloné.
4. Validez.

Le gabarit sélectionné est cloné dans le projet en cours. Selon les options choisies, le gabarit cloné est appliqué aux fenêtres utilisant le gabarit original et/ou il devient le gabarit par défaut du projet.

Le gabarit cloné est copié dans le répertoire du projet (sous-répertoire "Gabarits").

### Remarques

- Si le projet contient plusieurs configurations (par exemple WINDEV et WINDEV Mobile), le clonage des gabarits WINDEV s'appliquera aux configurations WINDEV et le clonage des gabarit WINDEV Mobile s'appliquera aux configurations WINDEV Mobile.
- Si un même gabarit est cloné avec le même nom dans deux projets différents, les modifications effectuées dans le gabarit cloné du premier projet ne sont pas reportées dans le second projet.
- Si le répertoire du gabarit cloné est copié dans le répertoire des gabarits de WINDEV ou de WINDEV Mobile, il sera proposé dans les gabarits applicables.
- Si le projet utilise exclusivement les styles du gabarit cloné, le répertoire du gabarit original sera automatiquement supprimé lors de la réactualisation des styles.
- Projet dans le GDS :
  - Lors de la création d'un gabarit cloné, toutes les fenêtres sont extraites pour leur appliquer le gabarit cloné.
  - Pour partager un gabarit cloné entre plusieurs projets, il suffit de partager le répertoire du gabarit via le GDS.

## Cloner une ambiance

### Comment le faire ?
Pour cloner une ambiance :

1. Ouvrir le projet WEBDEV voulu.
2. Sous le menu "Projet", dans le groupe "Autres actions", déroulez "Plus d'actions" et sélectionnez "Cloner l'Ambiance du projet".
3. Dans la fenêtre qui s'affiche, indiquez :
  - L'ambiance à cloner. Cette ambiance peut être différente de l'ambiance en cours dans le projet.
  - Le nom de la nouvelle ambiance. Ce nom permettra d'identifier l'ambiance utilisée.
  - Si l'ambiance doit devenir l'ambiance par défaut du projet. Si cette option est sélectionnée, l'ambiance associée au projet sera modifiée (dans la fenêtre de description du projet). Dans ce cas, toute nouvelle page utilisera l'ambiance clonée.
4. Validez.

L'ambiance sélectionnée est clonée dans le projet en cours. Selon les options choisies, l'ambiance clonée devient l'ambiance par défaut du projet.

L'ambiance clonée est copiée dans le répertoire du projet (sous-répertoire au nom de la nouvelle ambiance).

### Remarques

- Si le projet contient plusieurs configurations (par exemple WINDEV et WEBDEV), le clonage des ambiances WEBDEV s'appliquera uniquement aux configurations WEBDEV.
- Si une même ambiance est clonée avec le même nom dans deux projets différents, les modifications effectuées dans l'ambiance clonée du premier projet ne sont pas reportées dans le second projet.
- Si le répertoire de l'ambiance clonée est copié dans le répertoire des gabarits de WEBDEV, elle sera proposée dans les ambiances applicables.
- Projet dans le GDS :
  - Lors de la création d'une ambiance clonée, toutes les pages sont extraites pour leur appliquer l'ambiance clonée.
  - Pour partager une ambiance clonée entre plusieurs projets, il suffit de partager le répertoire de l'ambiance via le GDS.

## Modifier les styles

### Comment le faire ?
Lorsque votre projet utilise un gabarit (ou une ambiance) cloné, il est possible de modifier les styles du gabarit (ou de l'ambiance) cloné pour les adapter à vos besoins. Plusieurs méthodes sont disponibles.
**Méthode 1 : Modification du style via le report de surcharges** (onglet "Style" d'un champ) :

1. Modifiez le style du champ :
  - Sélectionnez le champ pour lequel vous souhaitez modifier le style par défaut.
  - Affichez l'onglet "Style" de la fenêtre de description du champ. Le style affiché correspond au style du gabarit (ou de l'ambiance) cloné, avec ou non des surcharges.
  - Réalisez les modifications voulues (et si nécessaire appliquez-les pour voir le résultat).
2. Modifiez le style du gabarit (ou de l'ambiance) cloné :
  Pour reporter les différentes modifications (surcharges) dans le style du gabarit ou de l'ambiance cloné, vous pouvez :
  - Cliquer dans l'entête de la fenêtre de description sur le lien "Reporter".
  - Dérouler le menu présent dans l'entête du lien et sélectionnez l'option "Reporter les surcharges".

Dans ce cas :

- Tous les champs du projet utilisant le style du gabarit (ou de l'ambiance) cloné sont modifiés.
- Les surcharges du champ sont annulées. Le champ utilise donc le style "sans surcharge".
- Les autres champs utilisant le style modifié gardent leurs propres surcharges si elles existent.

**Méthode 2 : Modification d'un style via l'option "Choisir un style"**:

1. Sélectionnez le champ pour lequel vous souhaitez modifier le style par défaut.
2. Affichez le menu contextuel et sélectionnez :
  - l'option "Choisir un style".
  - l'option "Choisir un style WEBDEV".
   La fenêtre qui s'affiche présente tous les styles présents dans les différents gabarits (ou ambiances) gérés par le projet.
3. Sélectionnez le style voulu pour le champ dans le gabarit (ou l'ambiance) modifié.
4. Dans le menu contextuel du style, sélectionnez l'option "Modifier".
5. Dans la fenêtre qui s'affiche, modifiez le style selon vos besoins.
6. Validez les modifications.

Le style du gabarit cloné (ou de l'ambiance clonée) est modifié. Cette modification est automatiquement reportée à tous les champs utilisant ce style du gabarit cloné (ou de l'ambiance clonée) dans le projet. Tous les champs gardent leurs surcharges (même le champ à partir duquel la modification a été réalisée).

Nouveauté 2025
**Méthode 3 : Modification du style du gabarit** ("Style" d'un champ) :

1. Modifiez le style du champ :
  - Sélectionnez le champ pour lequel vous souhaitez modifier le style par défaut.
  - Affichez l'onglet "Style" de la fenêtre de description du champ. Le style affiché correspond au style du gabarit cloné.
  - Réalisez les modifications voulues (et si nécessaire appliquez-les pour voir le résultat).
2. Modifiez le style du gabarit cloné :
  Pour modifier le style du gabarit avec les modifications effectuées dans le champ, vous pouvez :
  - Cliquer dans l'entête de la fenêtre de description sur le lien "Modifier le style".
  - Déroulez le menu présent dans l'enête du lien et sélectionnez l'option "Modifier le style".

Dans ce cas :

- Tous les champs du projet utilisant le style du gabarit cloné sont modifiés.
- Les surcharges du champ sont conservées.
- Les autres champs utilisant le style modifié gardent leurs propres surcharges si elles existent.
