# Paramètres de la procédure utilisée par la fonction HRéindexeAsynchrone

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Procédure WLangage (également nommée "callback") appelée par la fonction [HRéindexeAsynchrone](1410091053.md) pour chaque fichier de données HFSQL Client/Serveur réindexé.
Nouveauté Abonnement
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
CnxBaseDeDonnées est une Connexion
TableauFichier est un tableau de hParamètreFichier
MonFichierParam est un hParamètreFichier
MonFichierParam.Nom = "ActionPossible"
MonFichierParam.MotDePasse = "MotDePasse"
// Propriété Option de la variable hParamètreFichier non prise en compte
TableauAjoute(TableauFichier, MonFichierParam)
// Lance la réindexation
SI bTâcheDeFond ALORS
	HRéindexeAsynchrone(CnxBaseDeDonnées, TableauFichier, hTâcheDeFond, 60, CB_HRéindexeAsynchrone)
SINON
	HRéindexeAsynchrone(CnxBaseDeDonnées, TableauFichier, CB_HRéindexeAsynchrone)
FIN

	PROCÉDURE INTERNE CB_HRéindexeAsynchrone(MonFichier est une chaîne, Res est un booléen)
		SI Res ALORS
			Trace("Fichier traité : " + MonFichier)
		SINON
			Trace("Erreur Fichier " + MonFichier + ErreurInfo())
		FIN
	FIN
```

## Syntaxe

```wlangage
HRéindexeAsynchrone_Callback(<Fichier de données> , <Résultat réindexation>)
```

`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données HFSQL Client/Serveur manipulé.
`<Résultat réindexation>` *Booléen*
> - Vrai si la ré-indexation a été effectuée sans problème,
> - Faux dans le cas contraire. La fonction [HErreurInfo](3044071.md) permet d'obtenir plus d'informations sur le problème rencontré.
