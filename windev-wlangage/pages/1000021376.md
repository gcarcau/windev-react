# HRafraîchitVue (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Demande le recalcul du contenu d'une vue matérialisée.
**Remarque** : Il est également possible de mettre à jour la vue matérialisée grâce à l'instruction SQL ["REFRESH MATERIALIZED VIEW"](2034001.md).

## Exemple

```wlangage
HRafraîchitVue(MaConnexion, MaVue)
```

## Syntaxe

```wlangage
<Résultat> = HRafraîchitVue(<Connexion> , <Vue> [, <Option>])
```

`<Résultat>` *Booléen*
> - Vrai si la vue matérialisée a été rafraîchie,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion à manipuler. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Vue>` *Chaîne de caractères*
> Nom de la vue matérialisée dont les données doivent être recalculées. Cette vue a été créée :
>
> - via l'éditeur d'analyses.
> - grâce à l'instruction SQL ["CREATE MATERIALIZED VIEW"](2034001.md).
`<Option>` *Constante optionnelle de type Entier*
> Mode de rafraîchissement de la vue matérialisée.
>
> | *hSansAttente* | Le rafraîchissement de la vue matérialisée n'est pas bloquant : il est effectué en tâche de fond. La fonction [HInfoVue](1000021619.md) permet de connaître le résultat du rafraîchissement de la vue matérialisée. |
> | --- | --- |
> | Paramètre non spécifié (par défaut) | Le rafraîchissement de la vue matérialisée est bloquant pour celui qui l'a demandé. <Résultat permet de connaître le compte-rendu du rafraîchissement. |

## Remarques

### Droits nécessaires
Pour recalculer du contenu d'une vue matérialisée, il est nécessaire de posséder :

- le droit correspondant (constante *hDroitGèreTâche*) sur le serveur,
- pour chaque base concernée (c'est-à-dire qui contient une vue à traiter), le droit de connexion (constante *hDroitConnexion* ou *hDroitConnexionCryptée*).

Pour savoir si un utilisateur ou un groupe possède ces droits, utilisez la fonction [HInfoDroitServeur](3044322.md) ou [HInfoDroitDaseDeDonnées](3044320.md).

Pour modifier les droits d'un utilisateur ou d'un groupe d'utilisateurs, utilisez la fonction [HModifieDroitServeur](3044328.md) ou [HModifieDroitBaseDeDonnées](3044326.md).
