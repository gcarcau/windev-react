# Ancrage (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Ancrage** permet de gérer l'ancrage d'un champ. Il est possible de :

- Connaître l'ancrage actuel d'un champ dans une fenêtre ou un état.
- Modifier les caractéristiques d'ancrage d'un champ dans une fenêtre.

**Rappel** : L'ancrage d'un champ permet de définir le comportement du champ (dimensions et déplacement) lors du changement de taille de la fenêtre (ou de l'état).

Plusieurs propriétés permettent de définir ou de connaître le taux d'ancrage d'un champ. Ces propriétés sont les suivantes :

- [TauxAncrageBas](2510113.md).
- [TauxAncrageDroite](2510114.md).
- [TauxAncrageHauteur](2510119.md).
- [TauxAncrageLargeur](2510120.md).

> _(WEBDEV - Code Serveur)_ Cette propriété est disponible uniquement pour les champs d'un état.

## Exemple

```wlangage
// Définition des caractéristiques d'ancrage
// Le champ sera agrandi en hauteur et largeur
LISTE_Liste1.Ancrage = ancreLargeur + ancreHauteur
```

## Syntaxe

#### Connaître l'ancrage d'un champ

```wlangage
<Ancrage actuel> = <Champ manipulé>.Ancrage
```

`<Ancrage actuel>` *Constante de type entier*
> Caractéristique d'ancrage actuellement définie pour le champ :
>
>
> | *ancreBas* | Le champ se déplace vers le bas. |
> | --- | --- |
> | *ancreDroite* | Le champ se déplace vers la droite. |
> | *ancreHauteur* | Le champ s'étire vers le bas. |
> | *ancreHautGauche* | Aucune action. |
> | *ancreLargeur* | Le champ s'étire vers la droite. |
>
> Les constantes *ancreDroite* et *ancreLargeur* peuvent être combinées avec les constantes *ancreBas* et *ancreHauteur*.
`<Champ manipulé>` *Nom de champ*
> Nom du champ manipulé (champ d'une fenêtre ou d'un état).

> _(WINDEV, Android, iPhone/iPad, Widget IOS, Mac Catalyst, Java)_ Modifier l'ancrage d'un champ Masquer les détails
<Champ manipulé>.Ancrage = <Nouvel ancrage>

 <Champ manipulé> : Nom de champNom du champ manipulé (champ d'une fenêtre ou d'un état). <Nouvel ancrage> : Constante de type entierNouvelle caractéristique d'ancrage définie pour le champ :
ancreBasLe champ se déplace vers le bas.ancreDroiteLe champ se déplace vers la droite.ancreHauteurLe champ s'étire vers le bas.ancreHautGaucheAucune action.ancreLargeurLe champ s'étire vers la droite.Les constantes ancreDroite et ancreLargeur peuvent être combinées avec les constantes ancreBas et ancreHauteur.

## Remarques

### Ancrage
Rappel : l'ancrage d'un champ permet de définir le comportement du champ (dimensions et déplacement) lors du changement de taille de la fenêtre ou de l'état.
Les positions et largeurs utilisées pour calculer les nouvelles tailles et positions sont celles définies sous l'éditeur. Elles peuvent être connues grâce aux propriétés [XInitial](2510140.md), [YInitial](2510087.md), [LargeurInitiale](2510067.md) et [HauteurInitiale](2510043.md).

> _(WINDEV, Android, iPhone/iPad, Widget IOS, Mac Catalyst, Java)_ Remarques : Dans le cas d'une colonne d'un champ Table ou Table hiérarchique, la propriété Ancrage n'est pas disponible. L'ancrage d'une colonne se spécifie directement avec la propriété TauxAncrageLargeur.Si le champ est associé à un volet d'onglet, l'ancrage est défini par rapport au champ Onglet.

### Limites

> _(WINDEV, Android, iPhone/iPad, Widget IOS, Mac Catalyst, Java)_ La propriété Ancrage s'applique à tous les champs d'une fenêtre.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS)_ La propriété Ancrage s'applique à tous les champs d'un état. Dans ce cas, il est uniquement possible de connaître le type d'ancrage utilisé.

> _(Java)_ La propriété Ancrage s'applique uniquement aux champs suivants :Champ Bouton.Champ Libellé.Champ de saisie.Champ Image.Champ Interrupteur.Champ Sélecteur.Champ Liste.Champ Combo.Champ Arbre.Champ Onglet.Champ Table.Superchamp.
