# EnModeWeb (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Identifie le mode de lancement du traitement en cours :

- depuis un exécutable WINDEV.
- depuis le moteur d'exécution de WEBDEV (AWP).

**Remarque** : Pour les codes partagés entre une application WINDEV et un site WEBDEV (code de classe, composant, ...), cette fonction permet de connaître le mode d'exécution, et de lancer le traitement approprié.

> _(Android, Widget Android, Java, PHP)_ Dans cette version, cette fonction n'a aucun effet.

> _(PHP)_ La fonction EnModeWeb renvoie toujours Vrai en mode simulation.

## Exemple

```wlangage
// Mode de lancement ?
SI EnModeWeb() = Vrai ALORS
	// Traitement lancé depuis le moteur d'exécution de WEBDEV :
	// Appel de la procédure "WebEnvoiePage"
	WebEnvoiePage("Info.htm")
SINON
	// Traitement lancé depuis un exécutable WINDEV
	// Affichage d'une boîte de dialogue
	Info("Action réalisée")
FIN
```

## Syntaxe

```wlangage
<Résultat> = EnModeWeb()
```

`<Résultat>` *Booléen*
> - Vrai si le code est exécuté avec le moteur d'exécution de WEBDEV,
> - Faux dans le cas contraire.
>
>
> > _(Android, Widget Android, Java, PHP)_ Ce paramètre correspond toujours à Faux.

## Remarques

### Partages de composants et de classes entre WINDEV et WEBDEV
La fonction **EnModeWeb** permet de partager simplement des classes ou des composants réalisés en WLangage entre un site WEBDEV et une application WINDEV. Selon si l'exécution est réalisée en mode Web ou non, il est possible d'utiliser des fonctions différentes, spécifiques à l'application en cours.

### Exécution des traitements contenant des erreurs de compilation
Par défaut, le mécanisme de sécurité du WLangage se déclenche uniquement si la ligne contenant l'erreur de compilation est exécutée.
Par exemple, si une fonction interdite dans le produit en cours est présente dans une boucle SI, le mécanisme de sécurité du WLangage se déclenchera uniquement si la ligne contenant cette fonction s'exécute.

### Disponibilité de la fonction
La fonction **EnModeWeb** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **EnModeWeb** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.
