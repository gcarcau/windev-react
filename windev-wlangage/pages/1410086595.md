# CaméraAffiche (Fonction)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Affiche dans un champ "Caméra" la séquence vidéo actuellement retransmise par une "web caméra" ou par la caméra de l'appareil mobile.
> _(Android, iPhone/iPad)_ Avertissement
A partir de la version 27, cette fonction est obsolète pour les applications Android et iOS. Cette fonction est conservée uniquement pour les champs Caméra créés dans les versions précédentes et ayant l'option "Mode compatible 26" cochée (onglet "Général" de la fenêtre de description du champ).

## Exemple

```wlangage
// Affiche la séquence vidéo actuellement retransmise dans le champ "CAM_Caméra"
ResFilm = CaméraAffiche(CAM_Caméra)
SI ResFilm = Vrai ALORS
	// Affiche un libellé
	CAM_Caméra.Libellé = "En ce moment dans la cuisine"
SINON
	Erreur(ErreurInfo())
FIN
```

## Syntaxe

```wlangage
<Résultat> = CaméraAffiche(<Champ Caméra>)
```

`<Résultat>` *Booléen*
> - Vrai si la séquence vidéo actuellement retransmise est correctement affichée dans le champ Caméra,
> - Faux en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Caméra>` *Nom de champ*
> Nom du champ Caméra à manipuler.

## Remarques

### Conditions d'utilisation

- Pour utiliser cette fonction, une "caméra" doit être connectée au poste en cours.
- Cette fonction nécessite un matériel équipé d'une caméra. Elle peut également être utilisée lors d'une exécution dans l'émulateur Android.
- Cette fonction nécessite un matériel équipé d'une caméra.

**Remarque** : Cette fonction est équivalente à la fonction [VidéoAffiche](3079004.md).

### Cas particuliers

- En exécution, dès l'ouverture de la fenêtre contenant le champ Caméra, la séquence vidéo retransmise par la Caméra associée s'affiche automatiquement. Dans ce cas, l'utilisation de la fonction **CaméraAffiche** n'est pas nécessaire.
- Pour arrêter l'affichage d'une séquence vidéo, utilisez la fonction [CaméraArrête](1410086596.md).

> _(Android)_ Permissions requisesL'utilisation de cette fonction entraîne la modification des permissions requises par l'application.Permission requise : CAMERA.Cette permission permet aux applications d'accéder à la caméra.
