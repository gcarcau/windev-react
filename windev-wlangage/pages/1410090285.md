# Agrandissement (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Agrandissement** permet de définir le pourcentage d’agrandissement du halo utilisé pour mettre en valeur un élément dans une étape d'une visite guidée. Cette propriété est utilisable sur :

- une variable de type [VisiteGuidée](1410090170.md).
- une variable de type [VisiteGuidéeEtape](1410090178.md).
