# <Source>.FichierExiste (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Permet de savoir si un fichier de données existe, c'est-à-dire s'il a été créé physiquement (fonctions [<Source>.Création](1000024207.md) ou [<Source>.CréationSiInexistant](1000024208.md)).
Remarque : Les substitutions en cours sur le fichier de données (effectuées avec les fonctions [HSubstRep](3044028.md), [<Source>.ChangeRep](1000024202.md) et [<Source>.ChangeNom](1000024201.md)) sont prises en compte.

## Exemple

```wlangage
// Test de l'existence du fichier de données "Client"
SI Client.FichierExiste() = Vrai ALORS
	// Traitements
	...
FIN
```

## Syntaxe

#### Tester l'existence d'un fichier de données, d'une requête ou d'une vue

```wlangage
<Résultat> = <Source>.FichierExiste()
```

`<Résultat>` *Booléen*
> - Vrai si le fichier physique existe,
> - Faux dans le cas contraire.
`<Source>` *Type correspondant à la source spécifiée*
> Nom de l'élément à manipuler :
>
> - Nom du fichier de données.
> - Nom de la vue ou de la requête.

## Remarques

- La fonction **<Source>.FichierExiste** est utilisable que le fichier de données soit ouvert ou non.
- La fonction **<Source>.FichierExiste** n'ouvre pas le fichier de données si celui-ci est fermé.

**Composante : wd300hf.dll**
