# CurseurLigne (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur)

La propriété **CurseurLigne** permet de connaître et modifier le numéro de ligne où se trouve le curseur dans un champ Editeur de code.
Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Cette propriété est désormais disponible en code navigateur.

## Exemple

```wlangage
EDCODE_MonEditeur.CurseurLigne = 5
```

## Syntaxe

#### Connaître le numéro de la ligne en cours

```wlangage
<Résultat> = <Champ Editeur de code>.CurseurLigne
```

`<Résultat>` *Entier*
> Numéro de la ligne en cours.
`<Champ Editeur de code>` *Nom de champ*
> Nom du champ Editeur de code manipulé.

#### Modifier le numéro de la ligne en cours

```wlangage
<Champ Editeur de code>.CurseurLigne = <Nouveau numéro>
```

`<Champ Editeur de code>` *Nom de champ*
> Nom du champ Editeur de code manipulé.
`<Nouveau numéro>` *Entier*
> Numéro de la ligne sur laquelle le curseur doit être positionné.
