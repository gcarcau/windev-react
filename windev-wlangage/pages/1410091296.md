# Fonctions de manipulation des variables JSON

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Les fonctions suivantes permettent de manipuler le format JSON.

| Nouveauté 2025 [JSONOuvreLecteur](1410090784.md) | Crée un lecteur permettant de lire un document JSON sans le charger en mémoire. **Attention** : Cette fonction est disponible uniquement à partir de la version 2025 Update 3. |
| --- | --- |
| [JSONValide](1410089147.md) | Teste la validité d'une chaîne au format JSON. |
| [JSONVersChaîne](1000024530.md) | Convertit le contenu d'une variable de type JSON en une chaîne au format JSON. |
| [JSONVersTable](1410090328.md) | Initialise le contenu d'un champ Table ou Table hiérarchique à partir d'une chaîne JSON ou d'une variable JSON. |
| [JSONVersVariant](1000021052.md) | Convertit une chaîne au format JSON en une variable de type Variant. |
| [JSONVersXML](1410087330.md) | Convertit une chaîne de caractères au format JSON en une chaîne de caractères au format XML. |

Remarque : Il existe également des fonctions permettant de convertir des types de variable en variable au format JSON.
