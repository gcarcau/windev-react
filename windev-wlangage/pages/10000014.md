# Erreur 14 : Instruction SINON sans SI

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Cause

Vous avez utilisé le mot-clé SINON sans utiliser l'instruction conditionnelle SI correspondante.

## Correction

Vérifiez le code de votre instruction conditionnelle.

## Exemple

### Le début de l'instruction conditionnelle n'a pas été saisie

**Code provoquant l'erreur**

```wlangage
SAI_Cours = "Français"SINON SAI_Cours = "Anglais"FIN
```

**Corrections proposées**
Complétez l'instruction conditionnelle.

```wlangage
SI TableSelect(TABLE_Cours) = 1 ALORS SAI_Cours = "Français"SINON SAI_Cours = "Anglais"FIN
```
