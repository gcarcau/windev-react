# FinVisite (Propriété)

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **FinVisite** permet d'autoriser ou non à terminer la visite guidée depuis la bulle de l'étape. Cette propriété est utilisable sur :

- une variable de type [VisiteGuidée](1410090170.md).
- une variable de type [VisiteGuidéeEtape](1410090178.md).
