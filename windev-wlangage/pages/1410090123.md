# Contour (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **Contour** permet de définir le contour d'un polygone. Ce contour correspond à une polyligne simple et fermée. Cette propriété est disponible sur :

- une variable de type [Polygone2D](1410090122.md).
- une variable de type [PolygoneGéo](1410090127.md).
