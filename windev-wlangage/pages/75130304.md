# Sablier (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Affiche un pointeur de souris en forme de sablier.

## Exemple

```wlangage
// En CAPPELWD("Sablier,Oui");
```

```wlangage
// En PascalAPPELWD('Sablier,Oui');
```

```wlangage
// En VBcall APPELWD("Sablier,Oui")
```

## Syntaxe

```wlangage
Sablier(<Indicateur>)
```

`<Indicateur>` *Chaîne de caractères*
> Prend pour valeur :
>
> - "Oui" pour afficher le pointeur en sablier
> - "Non" pour réafficher le pointeur de souris initial.

## Remarques

- Par défaut la fonction Sablier,Non est appelée.
- Le sablier reprend automatiquement sa forme initiale lors de l'appel de la fonction [Ecran,Saisie](75130265.md).
