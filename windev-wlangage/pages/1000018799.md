# xmlAttribut (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Le type **xmlAttribut** permet de manipuler les attributs d'un noeud dans un document XML.
Ce type de variable est utilisé par :

- le type [xmlNoeud](1000018786.md).
- le type [xpathRésultat](1000021967.md).
- le type [xmlLecteur](1000023392.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Propriétés

### Propriétés spécifiques à la description des variables de type xmlAttribut
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **xmlAttribut** :

| Nom | Type manipulé | Effet |
| --- | --- | --- |
| Namespace | Variable de type [xmlNamespace](1000018803.md) | Espace de nommage dans lequel se trouve l'attribut. Deux attributs de même nom peuvent être définis sur un noeud de document XML s'ils proviennent d'espaces de nommage différents. |
| Nom | Chaîne de caractères Unicode | Nom de l'attribut. _(Android)_ Attention : Le nom de l'attribut ne doit pas contenir des caractères accentués. |
| Valeur | Chaîne de caractères Unicode | Valeur de l'attribut. |
| Vide | Booléen | - Vrai si l'attribut est défini dans un noeud donné, - Faux dans le cas contraire.  Cette propriété est accessible en lecture seulement. |

> _(Android, Java)_ Attention : L'ordre d'itération n'est pas nécessairement l'ordre de déclaration des attributs dans le document (généralement les attributs sont listés dans l'ordre alphabétique).
