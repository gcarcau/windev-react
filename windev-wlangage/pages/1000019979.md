# <Organigramme>.Occurrence (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Renvoie le nombre d'éléments présents dans un champ Organigramme.

## Exemple

```wlangage
// Recherche de l'élément selon son nom
NbElement est un entier = ORGA_Direction.Occurrence()
POUR i = 1 À NbElement
	SI ORGA_Direction[i].Titre = "Boris" ALORS
		ORGA_Direction[i].SousTitre = "Employé du mois"
	FIN
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Champ Organigramme>.Occurrence()
```

`<Résultat>` *Entier*
> Nombre d'éléments présents dans le champ Organigramme. Ce nombre correspond :
>
> - au nombre d'éléments ajoutés par les fonctions [<Organigramme>.Ajoute](1000019975.md) et [<Organigramme>.AjouteFils](1000019976.md).
> - au nombre d'éléments ajoutés grâce à la liaison fichier si le champ est lié à une source de données. Dans ce cas, ces éléments ont été affichés grâce à la fonction [<Organigramme>.Affiche](1000019974.md).
`<Champ Organigramme>` *Nom de champ*
> Nom du champ Organigramme à manipuler.
