# iHauteurPage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Calcule la hauteur de la page imprimable (en millimètres) en tenant compte des marges (hautes ou bases) définies.

## Exemple

```wlangage
// Imprime les dimensions de la feuille (en mm)
iImprime("Largeur de la page : " + iLargeurPage() + "mm")
iImprime("Hauteur de la page : " + iHauteurPage() + "mm")
iFinImprime()
```

## Syntaxe

```wlangage
<Résultat> = iHauteurPage(<Identifiant de la police>)
```

`<Résultat>` *Réel*
> Hauteur de la page :
>
> - en millimètres si le paramètre <Identifiant de la police> n'est pas précisé,
> - en nombre de lignes imprimables avec la police <Identifiant de la police>.
`<Identifiant de la police>` *Chaîne de caractères*
> Identifiant de la police utilisée, renvoyé par la fonction [iPolice](3046014.md) ou précisé lors de la création de la police avec la fonction [iCréePolice](3046045.md). Si ce paramètre n'est pas spécifié, la dernière police utilisée sera sélectionnée.

## Remarques

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Code Utilisateur (MCU), Ajax)_ Utilisation dans le code d'un étatSi la fonction iHauteurPage est utilisée :après le code d'ouverture de l'état, le résultat correspond à la hauteur imprimable dans l'état (hauteur de la page - les marges de haut et bas).dans le code d'ouverture de l'état, le résultat correspond à la hauteur imprimable physiquement (hauteur de la page - les marges physiques de haut et bas définies pour l'imprimante).

### Divers
La fonction [iLargeurPage](3046036.md) permet de connaître la largeur imprimable d'une page.
