# Eléments d'ambiance

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

## Présentation

Les éléments d'ambiance permettent de changer très rapidement l'aspect visuel d'un projet sans avoir besoin de retoucher chaque page et chaque modèle de pages.
Les éléments d'ambiances sont composées de trois éléments :

- **[les modèles de pages prédéfinis](2016019.md)** : ils sont constitués de champs (essentiellement des [cellules](1013096.md)) et définissent une mise en page par défaut pour les pages du projet.
- **[l'ambiance](2016020.md)** : elle est constituée d'une feuille de style normalisée pouvant être échangée avec celle de n'importe quelle autre ambiance. Une ambiance s'applique sur une page, un modèle de page ou sur l'ensemble d'un projet.
- **[la palette de couleurs](2016021.md)** : elle est constitué d'une série de couleurs harmonieuses entre elles et dont les noms sont normalisés pour pouvoir être interchangés. Elle s'applique sur les styles de l'ambiance pour en redéfinir les tons.

## Utilisation des éléments d'ambiance

### Utilisation dans un nouveau projet
Lors de la création d'un nouveau projet, l'assistant permet de choisir une ambiance et une palette de couleurs. Celles-ci seront associées au projet et utilisées par défaut dans toutes les pages.
L'ambiance d'un projet peut être changée à tout moment dans l'éditeur. Pour cela :

1. Affichez la description du projet : sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description".
2. Sélectionnez l'onglet "Ambiance".
3. Choisissez la nouvelle ambiance et sa palette de couleurs.
4. Validez la fenêtre de description du projet.

Lors de la création des pages, vous pourrez choisir le ou les modèles de pages prédéfinis à utiliser.
