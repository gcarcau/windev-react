# Image (Mot-clé)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

Le mot-clé**Image** peut correspondre :

- à une variable de type [Image](1000019650.md).
- à la propriété **Image** qui permet de connaître et de modifier l'image associée à un élément. Cette propriété est utilisable sur :
  - un champ. Pour plus de détails, consultez [Propriété Image sur un champ](2510034.md).
  - une variable de type [EvénementTimeline](1000020612.md).
  - une variable de type [Marqueur](1000019940.md).
  - une variable de type [RendezVous](1000019244.md).
  - une variable de type [rssCanal](1000017769.md).
  - une variable de type [rssFlux](1000017795.md).
  - une variable de type [OrgaElément](1000019713.md).
  - une variable de type [Icône](1000020811.md).
  - une variable de type [Tiff](1000021025.md).
  - une variable de type [TâcheGantt](1000020881.md).
  - une variable de type [upnpImage](1000020905.md).
  - une variable de type [pdfSignature](1000022255.md).
  - une variable de type [docElément](1000022484.md).
  - une variable de type [WDPic](1000023503.md).
  - une variable de type [CodeBarres](1000019451.md).
  - une variable de type [picCalque](1000024604.md).
  - une variable de type [CarteImage](1000025523.md).
  - la propriété [BoutonGauche](1410090001.md) d'un champ de saisie.
  - la propriété [BoutonDroit](1410090002.md) d'un champ de saisie.
  - Nouveauté Abonnement
     une variable de type [Toast](1000024638.md).
    **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
    Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
