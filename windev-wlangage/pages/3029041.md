# gCercle (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Construit une séquence de caractères contenant un cercle ou une ellipse.
> _(WINDEV, iPhone/iPad, Widget IOS, Mac Catalyst)_ Dans une fenêtre, cette séquence de caractères permet de dessiner un cercle ou une ellipse : dans un élément d'un champ Liste ou d'un champ Combo.dans la barre de titre et/ou de message d'une fenêtre. dans un champ Libellé.

## Exemple

> _(WINDEV)_ // Dessin d'un cercle dans un élément du champ "LISTE_ListeFigure"
// Le fond du cercle est vert clair et les bordures sont jaune clair
ListeAjoute(LISTE_ListeFigure, gCercle(0, 0, 25, 18, VertClair, JauneClair))

## Syntaxe

```wlangage
<Résultat> = gCercle(<X1> , <Y1> , <X2> , <Y2> [, <Couleur du fond> [, <Couleur du trait>]])
```

`<Résultat>` *Chaîne de caractères*
> Séquence de caractères définissant un cercle ou une ellipse.
> > _(WINDEV, iPhone/iPad, Widget IOS, Mac Catalyst)_ Cette séquence de caractères peut être : utilisée dans les fonctions ListeAjoute, ListeInsère ou ListeModifie.affectée à un champ Libellé. utilisée dans la barre de titre ou de message d'une fenêtre.
>
> > _(WEBDEV - Code Serveur)_ Cette séquence de caractères n'est pas interprétée par les champs en WEBDEV. Cette fonction peut être utilisée pour formater la chaîne renvoyée par un Webservice WEBDEV consommé par une application WINDEV ou WINDEV Mobile.
`<X1>` *Réel*
> Abscisse (en pixels) du coin haut gauche du rectangle dans lequel le cercle est inscrit.
`<Y1>` *Réel*
> Ordonnée (en pixels) du coin haut gauche du rectangle dans lequel le cercle est inscrit.
`<X2>` *Réel*
> Abscisse (en pixels) du coin bas droit du rectangle dans lequel le cercle est inscrit.
`<Y2>` *Réel*
> Ordonnée (en pixels) du coin bas droit du rectangle dans lequel le cercle est inscrit.
`<Couleur du fond>` *Entier ou constante (optionnel)*
> Couleur du fond du cercle. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md).
>
>
> Si ce paramètre n'est pas précisé, la couleur du fond correspond à la couleur du fond du texte en cours (définie par la fonction [gFond](3029037.md)).
`<Couleur du trait>` *Entier ou constante (optionnel)*
> Couleur du trait du cercle. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md).
>
>
> Si ce paramètre n'est pas précisé, la couleur du trait correspond à la couleur du texte en cours (définie par la fonction [gStylo](3029039.md)).

## Remarques

### Coordonnées
Toutes les coordonnées sont exprimées en pixels par rapport au coin haut gauche de l'élément manipulé (ligne du champ Liste ou du champ Combo, barre de titre de la fenêtre, barre de message de la fenêtre ou champ Libellé).

### Largeur/Hauteur du rectangle
La largeur du rectangle de référence vaut <X2> - <X1>.
La hauteur du rectangle de référence vaut <Y2> - <Y1>.
