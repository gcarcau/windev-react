# <Variable Connexion>.ListeGroupe (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Renvoie la liste des groupes d'utilisateurs définis pour une connexion.

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion

// Ouverture de la connexion
MaConnexion.OuvreConnexion()
Res est une chaîne
Res = MaConnexion.ListeGroupe()
// Ajout des groupes dans un champ Liste
ListeAjoute(LISTE_Maliste, Res)
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.ListeGroupe()
```

`<Résultat>` *Chaîne de caractères*
> Nom des différents groupes existants pour la connexion spécifiée. Les noms des différents groupes sont séparés par RC (Retour-Chariot).
> **Remarque** : Si l'utilisateur en cours ne possède pas le droit de visualisation des utilisateurs (constante *hDroitVisualisationUtilisateur*) sur le serveur (fonction [<Variable Connexion>.ModifieDroitServeur](1000022710.md) ou [<Variable Connexion>.InfoDroitServeur](1000022668.md)), la fonction **<Variable Connexion>.ListeGroupe** renvoie uniquement le groupe en cours.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion manipulée.

**Composante : wd300hf.dll**
