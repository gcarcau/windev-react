# AttributNote (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

La propriété **AttributNote** permet de connaître la valeur de l'attribut d'extension <Note>. Cette propriété est disponible sur :

- les variables de type [Définition](1000019540.md).
- les variables de type [Description de variable](1000019560.md).
