# PressePapier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Récupère le texte ou l'image contenu dans le presse-papiers du système.
Remarques :

- Pour identifier le contenu du presse-papiers, utilisez la fonction [PressePapierFormat](3063002.md).
- Pour récupérer du texte au format RTF, utilisez la fonction [PressePapierRTF](1000017200.md).
- Pour récupérer un texte au format Unicode, utilisez la fonction [PressePapierUnicode](1000018858.md).

> _(Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)_ Il est possible uniquement de récupérer le texte contenu dans le presse-papiers.

## Exemple

```wlangage
Texte est une chaîne
SI PressePapierFormat(ppfTexte) = Vrai ALORS
	Texte = PressePapier()  // Contenu du presse-papiers dans Texte
FIN
```

> _(WINDEV, Etats et Requêtes, Java, Code Utilisateur (MCU))_ SI PressePapierFormat(ppfBitmap) = Vrai ALORS
 PressePapier(IMG_Image1) // Contenu du presse-papiers dans le champ IMG_Image1
FIN

> _(WINDEV)_ MonImage est une Image
SI PressePapierFormat(ppfBitmap) = Vrai ALORS
 PressePapier(MonImage) // Contenu du presse-papiers dans la variable de type Image
FIN

## Syntaxe

#### Récupérer du texte

```wlangage
<Résultat> = PressePapier()
```

`<Résultat>` *Chaîne de caractères*
> Texte contenu dans le presse-papiers.

> _(WINDEV, Etats et Requêtes, Java, Code Utilisateur (MCU))_ Récupérer une image dans un champ Image Masquer les détails
<Résultat> = PressePapier(<Champ Image>)

 <Résultat> : BooléenVrai si l'image contenue dans le presse-papiers a été récupérée, Faux dans le cas contraire. <Champ Image> : Nom de champNom du champ Image (présent dans la fenêtre en cours) dans lequel l'image présente dans le presse-papiers doit être copiée.

> _(WINDEV, Etats et Requêtes, Code Utilisateur (MCU))_ Récupérer une image dans une variable de type Image Masquer les détails
<Résultat> = PressePapier(<Image>)

 <Résultat> : BooléenVrai si l'image contenue dans le presse-papiers a été récupérée, Faux dans le cas contraire. <Image> : Variable type ImageNom de la variable de type Image dans laquelle l'image présente dans le presse-papiers doit être copiée.

## Remarques

- La fonction **PressePapier** lit l'information de type texte ou image contenue dans le presse-papiers du système en cours. Les informations autres que celles de type texte ou image (binaire, etc.) contenues dans le presse-papiers ne peuvent pas être lues par la fonction **PressePapier**. Pour lire du texte au format RTF, utilisez la fonction [PressePapierRTF](1000017200.md).
- La fonction **PressePapier** peut être utilisée pour gérer le couper/copier/coller d'informations de type texte ou image.
- Si un champ Image doit être affecté plusieurs fois avec le contenu du presse-papiers, il faut utiliser la fonction [dFinDessin](3029019.md) entre les différentes affectations.
- La fonction [VersPressePapier](3063005.md) permet d'écrire dans le presse-papiers.
- Si les informations de transparence de l'image ont été conservées lors de la copie de l'image dans le presse-papiers (fonction [VersPressePapier](3063005.md)), ces informations sont également conservées lors de la copie vers le champ Image et/ou vers la variable de type [Image](1000019650.md).
- Seules les informations de type Texte peuvent être récupérées (Syntaxe 1).
- A partir de Android 10, si l'application est en arrière-plan, il n'est pas possible de récupérer le contenu du presse-papiers. La fonction **PressePapier** renverra chaîne vide ("") dans ce cas.
