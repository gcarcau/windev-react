# FinEvénement (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Annule l'interception d'un événement Windows sur un champ ou une fenêtre WINDEV (mis en place grâce à la fonction [Evénement](3015011.md)). La procédure associée à un événement Windows ne sera plus appelée.
**Remarque** : L'interception des événements est automatiquement arrêtée lorsque la fenêtre associée est fermée.

## Exemple

```wlangage
// Capture du clic souris sur un champ de saisie
WM_LBUTTONDOWN est un entier = 513
IDEve est entier
IDEve = Evénement("ClicSouris", "SAI_SAISIE1", WM_LBUTTONDOWN)
...
// Arrêt de l'interception de WM_LBUTTONDOWN sur le champ "SAI_SAISIE1"
FinEvénement(IDEve)
```

## Syntaxe

```wlangage
<Résultat> = FinEvénement(<Numéro de l'événement>)
```

`<Résultat>` *Booléen*
> - Vrai si l'interception de l'événement a été annulée,
> - Faux en cas de problème (numéro d'événement incorrect par exemple).
`<Numéro de l'événement>` *Entier*
> Numéro de l'événement à annuler (renvoyé par la fonction [Evénement](3015011.md)).

**Composante : wd300obj.dll**
