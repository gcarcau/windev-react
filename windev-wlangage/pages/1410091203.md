# CoffreFortContenusSecrets (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch)

Permet de savoir si les contenus secrets des coffres-forts sont présents, c'est-à-dire si l'exécution est réalisée avec les contenus secrets.
Remarque : Si les contenus secrets sont présents, les contenus pour test sont également présents dans les coffres-forts.

Nouveauté Abonnement
Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
SI CoffreFortContenusSecrets = Vrai ALORS
	// Mode test avec contenus secrets
	SI OuiNon("Passer en mode test ?") = Oui ALORS
		// mode test choisi par l'utilisateur
		// on demande l'utilisation des contenus pour test
		CoffreFortUtiliseContenusPourTest()
	SINON
		// mode production
		// on ne change rien, on utilise les contenus secrets
	FIN
SINON
	// Mode test forcé (le développeur n'avait pas les droits)
	// On utilise les contenus pour test qui sont les seuls disponibles
FIN
```

## Syntaxe

```wlangage
<Résultat> = CoffreFortContenusSecrets()
```

`<Résultat>` *Booléen*
> - Vrai si les contenus secrets sont présents,
> - Faux dans le cas contraire.

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
