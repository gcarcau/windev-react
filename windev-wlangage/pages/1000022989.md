# CléPrivée (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **CléPrivée** permet de gérer les connexions par clés privées (connexion SSH ou MQTT). Cette propriété est utilisable sur :

- une variable de type [sshSession](1000021157.md).
- une variable de type [mqttSession](1000023023.md).
- une variable de type [JWTParamètres](1410089572.md).
- Nouveauté 2025
   une variable de type [ftpConnexion](1410090869.md).
