# Markdown (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Markdown** permet de gérer le format Markdown :

- dans un champ d'une fenêtre. Pour plus de détails, consultez l'aide de la propriété [Markdown](1410089000.md).
- dans un champ Libellé d'un état. Pour plus de détails, consultez l'aide de la propriété [Markdown](1410089000.md).
- dans les champs de la fenêtre interne (titre et description) correspondant à l'étape de la visite guidée. Cette propriété est utilisable sur :
  - une variable de type [VisiteGuidée](1410090170.md).
  - une variable de type [VisiteGuidéeEtape](1410090178.md).
