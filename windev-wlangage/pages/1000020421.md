# Fonctions NFC

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions de gestion des NFC sont les suivantes :

| [NFCEcritTag](1000020417.md) | Déclenche l'écriture de données sur un tag (ou puce) NFC. |
| --- | --- |
| [NFCEnvoieTag](1000020418.md) | Envoie un tag NFC à un autre appareil. |
| [NFCEtat](1000020415.md) | Retourne l'état d'activation du capteur NFC de l'appareil. |
| [NFCLitTag](1000020416.md) | Déclenche la lecture d'un tag (ou puce) NFC ou active la détection de tags NFC pour la fenêtre en cours. |

Remarques :

- Les fonctions NFC supportent normalement les tags correspondant aux types standardisés 1 à 4 définis par le NFC Forum ([https://nfc-forum.org/build/specifications#tag-type-technical-specifications](https://nfc-forum.org/build/specifications#tag-type-technical-specifications)) et ne savent lire et écrire que des données encodées au format NDEF (NFC Data Exchange Service).
- Les fonctions NFC ne peuvent pas être utilisées dans le simulateur ou dans l'émulateur.
