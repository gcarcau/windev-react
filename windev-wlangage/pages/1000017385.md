# <Calendrier>.Select (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Mac Catalyst)

Renvoie la date sélectionnée dans un champ Calendrier.

## Exemple

```wlangage
// Affiche la date sélectionnée dans une fenêtre de trace
Trace(CAL_Calendrier1.Select())
```

```wlangage
// Récupère la date dans un champ de saisie
SAI_Date = CAL_Calendrier1.Select()
```

## Syntaxe

```wlangage
<Résultat> = <Champ Calendrier>.Select([<Indice de l'élément sélectionné>])
```

`<Résultat>` *Chaîne de caractères ou variable de type date*
> Jour sélectionné dans le champ Calendrier. Ce paramètre est de la forme "AAAAMMJJ". Par exemple, si le jour sélectionné est le 12 novembre 2008, <Résultat> vaut "20081112".
`<Champ Calendrier>` *Nom de champ*
> Nom du champ Calendrier manipulé.
`<Indice de l'élément sélectionné>` *Entier optionnel*
> Rang de la sélection dans le cas d'un calendrier multisélection.
> Si ce paramètre n'est pas spécifié, la date correspondant au premier élément sélectionné sera renvoyée.
> > _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur)_ Le champ Calendrier n'est pas multisélection. Si ce paramètre est précisé, seul l'indice 1 est valide, et le résultat correspondra alors à celui de la propriété Valeur.
