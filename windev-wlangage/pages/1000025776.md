# géoRécupèreZone (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Récupère les coordonnées de la zone géographique correspondant à la description.

## Exemple

```wlangage
// Affiche la France dans un champ Carte
soit (p1,p2) = géoRécupèreZone("France")
SI PAS ErreurDétectée() ALORS
	CarteAfficheZone(CARTE_Carte1, p1, p2)
FIN
```

## Syntaxe

```wlangage
(<Position NO>, <Position SE>) = géoRécupèreZone(<Description>)
```

`<Position NO>` *Variable de type géoPosition*
> Variable de type [géoPosition](1000019191.md) correspondant à la zone géographique Nord Ouest.
`<Position SE>` *Variable de type géoPosition*
> Variable de type [géoPosition](1000019191.md) correspondant à la zone géographique Sud Est.
`<Description>` *Chaîne de caractères*
> Zone géographique dont les coordonnées doivent être récupérées. Par exemple : "Paris, France".

## Remarques

### Licence Google
Pour pouvoir utiliser les services de géocodage de Google, il est nécessaire que l'application fournisse une clé de licence Google valide. Il est possible de fournir cette clé en utilisant la fonction [CarteLicenceGgl](1000021299.md). Elle doit avoir été appelée avant l'exécution de la fonction **géoRécupèreZone**.
> _(Android)_ Sous Android, si l'application possède un champ Carte et que la clé de licence a été fournie dans l'assistant de génération, il n'est pas nécessaire d'appeler la fonction CarteLicenceGgl.

Pour plus d'informations sur la clé de licence, consultez [https://developers.google.com/maps/gmp-get-started](https://developers.google.com/maps/gmp-get-started).
