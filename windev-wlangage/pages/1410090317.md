# Fonctions de gestion des visites guidées

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions permettant de manipuler les visites guidées sont les suivantes :

| [VisiteGuidéeArrête](1410090225.md) | Arrête la visite guidée spécifiée ou la visite guidée en cours. |
| --- | --- |
| [VisiteGuidéeChangeEtape](1410090229.md) | Modifie l'étape en cours de la visite guidée. |
| [VisiteGuidéeDémarre](1410090176.md) | Démarre la visite guidée et affiche la première étape. |
| [VisiteGuidéeInfo](1410090219.md) | Renvoie des informations sur une visite guidée. |
