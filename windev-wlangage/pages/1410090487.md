# <Buffer>.UTF8Valide (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un buffer au format UTF8.

## Exemple

```wlangage
bufUTF8 est un Buffer
// Test : Buffer UTF8 valide ?
SI bufUTF8.UTF8Valide() ALORS
	// Oui => conversion en UNICODE
	sUNICODE est une chaîne Unicode = bufUTF8.UTF8VersChaîne()
	...
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Buffer à vérifier>.UTF8Valide()
```

`<Résultat>` *Booléen*
> - Vrai si la chaîne correspond à un format UTF8 valide,
> - Faux dans le cas contraire.
`<Buffer à vérifier>` *Buffer*
> Buffer contenant les données au format UTF8.

**Composante : wd300vm.dll**
