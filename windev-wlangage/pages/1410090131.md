# MultiPolyligne2D (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Le type **MultiPolyligne2D** permet de stocker un ensemble de polylignes en 2 dimensions non connectées entre elles.
Une variable de type **MultiPolyligne2D** peut servir à stocker un ensemble de polylignes en 2 dimensions dans un seul et même enregistrement HFSQL, sans avoir à utiliser un enregistrement par polyligne. Ce type de variable est nécessaire par exemple si l'ensemble de polylignes correspond à l'entité manipulée par un programme (dans ce cas, chaque polyligne n'est pas manipulée indépendamment).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
maPolyligne2D est une Polyligne2D
multipolyligne est un MultiPolyligne2D
multipolyligne.Polyligne.Ajoute(maPolyligne2D)
multipolyligne.Polyligne.Ajoute(maPolyligne2D)
multipolyligne.Polyligne.Ajoute(maPolyligne2D)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type MultiPolyligne2D
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **MultiPolyligne2D** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Polyligne | Tableau de [Polyligne2D](1410090109.md) | Polylignes en 2 dimensions. |
| Type | Constante de type Entier | Type de la géométrie en cours. Dans le cas d'un ensemble de polylignes en 2 dimensions, correspond à la constante *tgMultiPolyligne2D*. Remarque : Jusqu'à la version 2024 Update 2, cette constante se nommait *tfMultiPolyligne2D*. **Cette propriété est disponible en lecture uniquement.** |
