# Constantes iCloud

> **Disponible :** **WINDEV Mobile** (iPhone/iPad)

Les constantes iCloud sont les suivantes :

| Constante | Détail | Fonction |
| --- | --- | --- |
| **iccvChangementCompte** | Cause de l'événement : L'utilisateur a changé de compte. | [iCloudCléValeurSurveille](1410088760.md) |
| **iccvEchecSynchronisation** | Cause de l'événement : Erreur lors de la tentative de synchronisation entre le périphérique et le serveur Apple iCloud. | [iCloudCléValeurSurveille](1410088760.md) |
| **iccvModificationServeur** | Cause de l'événement : Les clés ont été modifiées depuis le serveur Apple iCloud. | [iCloudCléValeurSurveille](1410088760.md) |
| **iccvModificationSynchronisationInitiale** | Cause de l'événement : Synchronisation initiale avec le serveur Apple iCloud. | [iCloudCléValeurSurveille](1410088760.md) |
| **iccvViolationQuota** | Cause de l'événement : Le quota concernant les clés a été dépassé (Nombre de clés, espace de stockage, etc.). | [iCloudCléValeurSurveille](1410088760.md) |
