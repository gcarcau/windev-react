# <Tableur>.RestaurePositionEtSélection (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Restaure :

- la position de l'ascenseur d'un champ Tableur,
- la feuille en cours,
- le ou les éléments sélectionnés dans la feuille en cours du champ Tableur.

Ces éléments ont été précédemment sauvegardés par la fonction [<Tableur>.SauvePositionEtSélection](1000023735.md).

## Exemple

```wlangage
soit MaSauvegarde = TBLR_Tableur1.SauvePositionEtSélection()

// Met en gras la cellule B1
TBLR_Tableur.SelectPlus("B1")
TBLR_Tableur.StyleSélection(tblrGras, Vrai)

// Restaure la position/sélection
TBLR_Tableur1.RestaurePositionEtSélection(MaSauvegarde)
```

## Syntaxe

```wlangage
<Champ Tableur>.RestaurePositionEtSélection([<Sauvegarde>])
```

`<Champ Tableur>` *Nom de champ*
> Nom du champ Tableur à manipuler.
`<Sauvegarde>` *Chaîne de caractères optionnelle*
> Caractéristiques de la sauvegarde renvoyées par la fonction [<Tableur>.SauvePositionEtSélection](1000023735.md).
>
> - Si ce paramètre n'est pas précisé, la dernière sauvegarde réalisée par [<Tableur>.SauvePositionEtSélection](1000023735.md) sur le champ est utilisée (si elle existe).
> - Si aucune sauvegarde n'a été réalisée précédemment ou si la chaîne spécifiée est invalide, une erreur est affichée.

## Remarques

### Cas particuliers

- Le nom du champ utilisé pour la sauvegarde (fonction [<Tableur>.SauvePositionEtSélection](1000023735.md)) peut être différent de celui utilisé pour la restauration. Cette fonctionnalité peut être utile pour dupliquer la position et la sélection sur deux champs Tableur affichés alternativement par exemple.
- Si le champ est vide, la fonction **<Tableur>.RestaurePositionEtSélection** n'a aucun effet.
