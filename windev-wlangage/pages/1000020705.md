# Constantes de gestion des champs Tableau croisé dynamique

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Nouveauté Abonnement

> _(WEBDEV - Code Serveur, Windows, Linux)_ La plupart de ces constantes sont désormais disponibles pour les sites WEBDEV pour Windows et Linux.Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4. Pour plus de détails, consultez Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement.

Afficher uniquement les constantes utilisées par les syntaxes préfixées

Afficher uniquement les constantes utilisées par les syntaxes non préfixées
Les différentes constantes de gestion des champs Tableau croisé dynamique sont les suivantes :

| Constante | Détail | Fonction |
| --- | --- | --- |
| **tcdAvecUI** | Sauvegarde la configuration du champ Tableau croisé dynamique :  - taille des colonnes, - taille des lignes, - entête de colonnes et de lignes enroulées ou déroulées. | [TCDSauve](1000020471.md) |
| **tcdEntêteColonne** | Manipule les entêtes de colonnes. | [TCDDérouleTout](1000020623.md), [TCDEnrouleTout](1000020622.md) |
| **tcdEntêteLigne** | Manipule les entêtes de lignes. | [TCDDérouleTout](1000020623.md), [TCDEnrouleTout](1000020622.md) |
| **tcdEvolutionAbsolue** | Affiche l'évolution entre les périodes en valeur absolue. | [TCDComparePériode](1000024869.md) |
| **tcdEvolutionPourcentage** | Affiche l'évolution entre les périodes en pourcentage. | [TCDComparePériode](1000024869.md) |
| **tcdSansEvolution** | N'affiche pas l'évolution entre les périodes. | [TCDComparePériode](1000024869.md) |

Les différentes constantes de gestion des champs Tableau croisé dynamique (syntaxe préfixée) sont les suivantes :

| Constante | Détail | Fonction |
| --- | --- | --- |
| **tcdAvecUI** | Sauvegarde la configuration du champ Tableau croisé dynamique :  - taille des colonnes, - taille des lignes, - entête de colonnes et de lignes enroulées ou déroulées. | [<Tableau croisé dynamique>.Sauve](1000022189.md) |
| **tcdEntêteColonne** | Manipule les entêtes de colonnes. | [<Tableau croisé dynamique>.DérouleTout](1000022183.md), [<Tableau croisé dynamique>.EnrouleTout](1000022185.md) |
| **tcdEntêteLigne** | Manipule les entêtes de lignes. | [<Tableau croisé dynamique>.DérouleTout](1000022183.md), [<Tableau croisé dynamique>.EnrouleTout](1000022185.md) |
