# Longitude (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **Longitude** permet de connaître et de modifier la longitude d'un élément. Cette propriété est utilisable sur :

- une variable de type [gglCoordonnée](1000017489.md).
- une variable de type [gglMarqueur](1000017442.md).
- une variable de type [géoPosition](1000019191.md).
- une variable de type [PointGéo](1410090102.md).
