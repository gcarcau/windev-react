# HCréeTriggerServeur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Ajoute ou modifie un trigger serveur sur le serveur HFSQL. Pour effectuer ces opérations :

- Le trigger doit avoir été préalablement décrit dans l'analyse.
- La procédure stockée déclenchée par le trigger doit exister sur le serveur. Cette procédure peut être mise à jour grâce à la fonction [HMiseAJourCollection](3044354.md).

**Cette fonction permet de mettre à jour le serveur HFSQL sans faire de mise à jour automatique des données.**

**Rappel** : Les triggers serveur sont des procédures stockées exécutées par le serveur avant ou après une action d'écriture effectuée sur un fichier de la base de données. Pour plus de détails, consultez [Triggers serveur](3044369.md).

## Exemple

```wlangage
HCréeTriggerServeur(TriggerClient)
```

## Syntaxe

```wlangage
<Résultat> = HCréeTriggerServeur(<Trigger>)
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Trigger>` *Chaîne de caractères*
> Nom du trigger serveur à créer. Ce trigger a été décrit dans l'analyse.
> Si ce paramètre correspond à "*", tous les triggers décrits dans l'analyse seront créés.

## Remarques

Les triggers serveur décrits dans l'analyse peuvent être mis à jour via la modification automatique des données.
