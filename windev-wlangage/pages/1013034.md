# Associer une image aux éléments d'un champ Arbre

> **Disponible :** **WINDEV** (Windows, Java) · **WEBDEV** (Windows, Linux)

## Image associée à un élément

Tout élément d'un champ Arbre est précédé d'une image. Cette image peut être différente en fonction de l'état de l'élément (ou du niveau) en cours. Il est ainsi possible d'afficher une image :

- soit lorsque le niveau est déroulé,
- soit lorsque le niveau est enroulé (ou lorsque le niveau correspond à une feuille).

Exemple d'image associée au niveau enroulé : [image: Image niveau enroulé]

**Remarque** : Il est également possible d'associer un identifiant à un élément. Pour plus de détails, consultez [Associer un identifiant à un élément](1013033.md).

## Associer une ou plusieurs images à un élément

Pour associer une ou plusieurs images à un élément d'un champ Arbre, il suffit de préciser le nom (et si nécessaire le chemin) de l'image dans les fonctions de programmation suivantes :

| [ArbreAjoute](3018012.md) | Ajoute un élément "feuille" (et tous les noeuds nécessaires) dans un champ Arbre. |
| --- | --- |
| [ArbreInsère](3018023.md) | Insère une feuille à une position spécifique dans un champ Arbre. |
| [ArbreModifie](3018013.md) | Modifie un élément (noeud ou feuille) dans un champ Arbre. |

Ces fonctions sont également disponibles en syntaxe préfixée :

| [<Arbre>.Ajoute](1000023422.md) | Ajoute un élément "feuille" (et tous les noeuds nécessaires) dans un champ Arbre. |
| --- | --- |
| [<Arbre>.Insère](1000023761.md) | Insère une feuille à une position spécifique dans un champ Arbre. |
| [<Arbre>.Modifie](1000023763.md) | Modifie un élément (noeud ou feuille) dans un champ Arbre. |

Remarque : Si aucune image spécifique n'est associée aux éléments d'un champ Arbre, les icônes "dossier fermé" ([image: Dossier fermé]) et "dossier ouvert" ([image: Dossier ouvert]) sont utilisées.

## Format des images

Les formats d'images supportés sous Windows sont :

- Bitmap (*.BMP)
- Graphics Interchange Format (*.gif)
- Joint Picture Experts Group (*.jpg ; *.jpeg)
- Kodak Photo CD (*.pcd)
- PaintBrush (*.pcx)
- Adobe Photoshop Format (*.psd)
- TrueVision TARGA (*.tga)
- Tagged Image File Format (*.tif ; *.tiff)
  Remarque : l'option "tiff mosaïque" de la norme tiff 6.0 n'est pas supportée. Dans ce cas, il est conseillé d'enregistrer l'image à la norme tiff 5.0.
- Portable Network Graphics (*.png)
- Windows MetaFiles (*.emf ; *.wmf)
- Icônes (*.ico ; *.icw)
  Remarques :
  - Affichage HQ (Haute Qualité) disponible.
  - Gestion des planches au format BMP transparent (32 bits).
- Curseurs (*.cur)
- Portable Document Format (*.pdf)
- Scalable Vector Graphics (*.svg)
- Images WINDEV (générées par l'éditeur d'images, *.WDPIC).
- Nouveauté 2025
  Images au format WebP (*.webp).

> _(WEBDEV - Code Serveur)_ Les formats d'images reconnus sont les suivants : GIF, JPEG, PNG ou SVG (selon le support des navigateurs).

Les images employées peuvent être :

- des fichiers image.
- des rubriques d'un fichier de données HFSQL de type "Memo Binaire" contenant une image.
- des dessins réalisés à l'aide des [fonctions de dessin dans les listes et dans les combos](3029028.md).

> _(WEBDEV - Code Serveur)_ Les images utilisées peuvent uniquement être des fichiers image. Ces fichiers doivent être présents dans le répertoire "<NomProjet>_WEB". Ces images ne sont pas transformées lors de l'enregistrement de la page. Il n'est pas nécessaire d'utiliser la fonction fRepWeb pour indiquer le chemin de l'image. Ce chemin est relatif au répertoire "<NomProjet>_WEB".

Remarques :

- L'image spécifiée est réduite proportionnellement : la hauteur de l'image correspond à la hauteur de la ligne du champ Arbre. Il est conseillé d'utiliser des images 16 x 16 pixels (taille des petites icônes de WINDEV).
- La couleur Magenta présente dans les images est considérée comme transparente en exécution.
