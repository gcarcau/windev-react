# Styles WEBDEV

> **Disponible :** **WEBDEV** (Windows)

## Présentation

Les styles WEBDEV sont des styles avancés. Chaque champ possède un style WEBDEV, regroupant un ensemble de styles d'élément pour chaque élément du champ.
Par exemple, pour un champ de saisie, le style WEBDEV regroupe :

- un style d'élément pour le libellé du champ,
- un style d'élément pour la zone de saisie,
- un style d'élément pour les jetons,
- des éléments spécifiques (image du bouton calendrier et du bouton mot de passe),
- des effets prédéfinis.

Un champ peut être associé à un **style WEBDEV**. Le style WEBDEV utilisé est sélectionné dans l'onglet "Style" de la fenêtre de description du champ.
Le style sélectionné s'applique au champ en cours uniquement.

Chaque élément d'un champ peut être associé à un ou plusieurs **styles d'élément**. Ces styles sont indiqués pour chaque élément du champ dans l'onglet "Style" de la fenêtre de description du champ. Remarque : Il est recommandé de ne pas utiliser pour un même élément des styles redéfinissant les mêmes propriétés.

Il est possible de modifier un style WEBDEV depuis la fenêtre de description du champ. Cette modification surcharge le style WEBDEV du champ en cours. Il est ensuite possible de créer à partir de ces modifications un nouveau style WEBDEV qui pourra être appliqué aux champs voulus.
Remarque : Pour modifier un style WEBDEV (et ainsi modifier le style de tous les champs utilisant ce style WEBDEV), il est nécessaire d'utiliser la fenêtre de gestion des styles WEBDEV.

Nouveauté 2025
A partir de la version 2025 Update 1, le terme "Style d'élément WEBDEV" remplace le terme "Style CSS". Cette page prend en compte le nouveau vocabulaire.

## Gestion des styles WEBDEV

### Création et modification d'un style WEBDEV
La création et la modification d'un style WEBDEV peut être effectuée :

- depuis la fenêtre de description des styles d'un champ.
- depuis la fenêtre de gestion des styles WEBDEV. Pour plus de détails, consultez [Edition des feuilles de styles WEBDEV](2016014.md).

### Création et modification d'un style WEBDEV depuis la fenêtre de description d'un champ
La fenêtre de description des champs permet de gérer le style de ce champ (onglet "Style"). Différents éléments sont gérés par l'onglet "Style".
Lors de l'affichage de l'onglet "Style", il est possible de :

- Connaître le nom du style WEBDEV utilisé.
- Savoir si des surcharges ont été effectuées sur le style WEBDEV du champ. Dans ce cas, le style WEBDEV initial a été modifié pour certaines caractéristiques. Un clic sur le lien affichant le nombre de surcharges permet de lister les surcharges et de les supprimer si nécessaire.

Les différents liens et le menu déroulant permettent de :

- **Choisir un autre style**. Cette option permet de sélectionner un style WEBDEV et de l'associer au champ en cours. Dans ce cas, le champ sera automatiquement mis à jour lorsque le style associé sera mis à jour.
- **Transformer en nouveau style**. Cette option permet de créer un nouveau style WEBDEV dans le projet à partir de toutes les caractéristiques actuellement définies pour le champ en cours. Le champ sera automatiquement associé à ce nouveau style WEBDEV. Il suffit alors d'indiquer le nom du nouveau style.
- **Dissocier**. Cette option permet de supprimer la liaison entre le style WEBDEV et le style du champ. Si le style WEBDEV évolue, le champ ne prendra pas en compte ces évolutions.
- **Voir les utilisations du style**, c'est-à-dire voir la liste des champs du projet qui utilisent ce style.
- Nouveauté 2025
  **Accéder à la description du style**. Cette option permet de modifier le style.
  Attention : Si le style WEBDEV provient de l'ambiance, ce style ne peut pas être modifié.

### Edition des styles WEBDEV
WEBDEV offre la possibilité d'éditer les styles WEBDEV présents dans la feuille de styles associée au projet.
Pour plus de détails, consultez [Edition des styles WEBDEV](2016014.md).
