# ContactLit (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **Autres** (Procédures stockées)

Lit un contact présent dans le carnet d'adresses d'une messagerie Lotus Notes ou Outlook.
**Attention** : Cette fonction **ne permet pas** de lire un contact présent dans le carnet d'adresses d'une messagerie Outlook Express.
Pour être lu, ce contact doit avoir été précédemment :

- lu (fonction [ContactDernier](1000006103.md), [ContactPrécédent](1000006105.md), [ContactPremier](1000006106.md) ou [ContactSuivant](1000006108.md)),
- ajouté (fonction [ContactAjoute](1000006101.md)),
- modifié (fonction [ContactModifie](1000006104.md)),
- recherché (fonction [ContactCherche](1000006102.md)).

La fonction **ContactLit** ne positionne pas sur le contact lu.

Lors de la lecture d'un contact, les données de ce contact sont mises à jour dans la [structure Contact](1000006111.md).

## Exemple

```wlangage
// Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", "mail/julie.nsf", ...
		"C:\Lotus Notes\julie.id")
// Lecture du premier contact
ContactPremier(IDSession)
...
// Re-lecture de ce même contact
ContactLit(IDSession, mContact.ID)
```

## Syntaxe

```wlangage
<Résultat> = ContactLit(<Identifiant de la session> , <Identifiant du contact>)
```

`<Résultat>` *Booléen*
> - Vrai si le contact a été lu,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Identifiant de la session>` *Entier*
> Identifiant de la session à utiliser. Cet identifiant est renvoyé par une des fonctions suivantes : [EmailOuvreSessionNotes](3032121.md), [EmailOuvreSessionOutlook](3032128.md), [NotesOuvreBase](1000005101.md) ou [OutlookOuvreSession](3032123.md).
`<Identifiant du contact>` *Chaîne de caractères*
> Identifiant du contact à lire. Cet identifiant est contenu dans la variable mContact.ID.

## Remarques

### Contact en cours
La variable mContact.EnDehors permet de savoir s'il y a un contact courant.

**Composante : wd300com.dll**
