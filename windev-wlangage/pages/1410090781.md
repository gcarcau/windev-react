# JourDansLAnnéeVersDate (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Renvoie la date (au format "AAAAMMJJ") correspondant à un numéro de jour dans l'année.
> _(Android, Widget Android, Java)_ Attention : Cette fonction est disponible pour les applications Android, Widget Android et Java uniquement à partir de la version 2025 Update 1.

## Exemple

```wlangage
dDate est une Date
nJour est un entier = 50
dDate = JourDansLAnnéeVersDate(nJour)
```

## Syntaxe

```wlangage
<Résultat> = JourDansLAnnéeVersDate(<Jour> [, <Année>])
```

`<Résultat>` *Chaîne de caractères*
> Date au format "AAAAMMJJ".
`<Jour>` *Entier*
> Numéro de jour dans l'année (compris entre 1 et 366).
`<Année>` *Entier optionnel*
> Année à utiliser pour le calcul.
> Si ce paramètre n'est pas spécifié, l'année en cours est utilisée.

**Composante : wd300std.dll**
