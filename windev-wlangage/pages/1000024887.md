# Fonctions de gestion des masques

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU))

Les fonctions de gestion des masques de saisie sont les suivantes :

| [MasqueCodePostal](1000024742.md) | Récupère le masque de saisie du code postal adapté à un pays donné. |
| --- | --- |
| [MasqueFormate](1000024738.md) | Formate une chaîne de caractères à l'aide d'une variable de type [MasqueDeSaisie](1000024886.md). |
| [MasqueNuméroDeTéléphone](1000024741.md) | Récupère le masque de saisie du numéro de téléphone adapté à un pays donné. |
