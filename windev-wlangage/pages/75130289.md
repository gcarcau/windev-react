# Liste,Recupere (Langage externe)

> **Disponible :** **WINDEV** (Windows)

Récupère la valeur d'un élément donné ou de l'élément choisi en cours dans une liste déroulante ou dans une liste déroulée.

## Exemple

```wlangage
// En CAPPELWD("Liste,Recupere,ListeProd,3");strcpy(Valeur,WDChaine);
```

```wlangage
// En PascalAPPELWD('Liste,Recupere,ListeProd,3');Valeur:=WdChaine;
```

```wlangage
// En VBcall APPELWD("Liste,Recupere,ListeProd,3")Valeur=WdChaine
```

## Syntaxe

```wlangage
Liste,Recupere(<Nom de la liste> [, <Indice>])
```

`<Nom de la liste>` *Chaîne de caractères*
> Nom de la liste à manipuler.
`<Indice>` *Chaîne de caractères (optionnelle)*
> Indice de l'élément qui doit être récupéré.

## Remarques

- Si <Indice> n'est pas précisé, la valeur de l'élément sélectionné est contenue dans WdChaine. L'indice de l'élément, s'il existe, est contenu dans WdEntier.
  Il est conseillé d'utiliser [Liste,Select,?](75130290.md) pour récupérer l'indice de l'élément sélectionné.
- Si aucun élément n'est sélectionné dans la liste ou si la liste est vide, **Liste,Recupere** retourne -1 dans WdEntier.
- Si <Indice> est précisé, **Liste,Recupere** retourne dans WdChaine la valeur de l'élément dont l'indice est spécifié et dans WdEntier la taille de l'élément.
- Pour les combos avec saisie, **Liste,Recupere** renvoie toujours WdChaine qui contient la valeur du champ de saisie de la combo.
- WdEntier n'a pas de signification.
