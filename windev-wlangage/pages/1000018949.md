# Occurrence (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

Le mot-clé **Occurrence** peut correspondre à :

- la fonction **[Occurrence](3025009.md)**. Cette fonction renvoie le nombre d'occurrences d'un champ dans une fenêtre, une page ou un groupe de champs.
- la propriété **Occurrence** qui permet de connaître un nombre d'éléments. Cette propriété est utilisable sur :
  - les champs d'une fenêtre ou d'une page. Pour plus de détails, consultez [Occurrence](2510097.md).
  - une variable de type [xmlNoeud](1000018786.md).
  - une variable de type [JSON](1000023611.md).
  - une variable de type [YAML](1000024438.md).
