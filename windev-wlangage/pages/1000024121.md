# <Graphe>.Quadrillage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Affiche ou rend invisible le quadrillage d'un graphe.
Exemple de quadrillage : [image: Quadrillage d'un graphe]

**Rappel** : Par défaut, le quadrillage d'un graphe est invisible.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
// Affichage du quadrillage horizontal du graphe GRF_MonGraphe
GRF_MonGraphe.Quadrillage(Vrai, grAbscisse)
```

## Syntaxe

```wlangage
<Champ Graphe>.Quadrillage(<Affiche> , <Sens de l'axe>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler présent dans l'éditeur de fenêtres, de pages ou d'états.
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Affiche>` *Booléen*
> - Vrai si le quadrillage doit être affiché,
> - Faux dans le cas contraire.
`<Sens de l'axe>` *Constante ou combinaison de constantes de type Entier*
> Axe utilisé pour le quadrillage :
>
>
> | *grAbscisse* (valeur par défaut) | Graduations sur l'axe des abscisses (axe horizontal). |
> | --- | --- |
> | *grOrdonnée* | Graduations sur l'axe des ordonnées (axe vertical). |
>
>
> La combinaison de ces deux constantes permet d'obtenir un quadrillage complet (vertical et horizontal).

## Remarques

- Le quadrillage est pris en compte :
  - dans les graphes de type histogramme (constantes *grHisto* et *grHistoEmpilé*), nuage de points (constante *grNuage*), courbe (constante *grCourbe*) et boursier (constantes *grChandelier*, *grBarCharts* et *grMinMax*) lorsque le paramètre <Sens de l'axe> correspond à la constante *grAbscisse*.
  - dans les graphes de type nuage de points (constante *grNuage*), courbe (constante *grCourbe*) et boursier (constantes *grChandelier* et *grBarCharts*) lorsque le paramètre <Sens de l'axe> correspond à la constante *grOrdonnée*.
- Le quadrillage est sans effet sur les graphes de type secteur (constante *grSecteur*) ou entonnoir (constante *grEntonnoir*).
- Les données définies avec la fonction **<Graphe>.Quadrillage** seront prises en compte lors du prochain appel à la fonction [<Graphe>.Dessine](1000024062.md).
