# ArcTang (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Renvoie l'arc tangente d'une valeur numérique (entière ou réelle).

## Exemple

```wlangage
// Récupération de l'arc tangente de 12
ResTang = ArcTang(12)
// Renvoie 85,2363583093
```

## Syntaxe

```wlangage
<Résultat> = ArcTang(<Valeur numérique>)
```

`<Résultat>` *Réel*
> Arc tangente (angle en degré de la tangente) de la valeur numérique spécifiée, compris dans l'intervalle [-90, 90] bornes exclues.
`<Valeur numérique>` *Entier ou réel*
> Valeur numérique (tangente) à manipuler.

## Remarques

### Comment retrouver un angle à partir de sa tangente ?
Dans un triangle rectangle, la tangente d'un angle est égale au rapport du coté opposé sur le coté adjacent. Comment obtenir l'angle ? Il suffit d'utiliser la fonction **ArcTang**.
Exemple : Le code suivant :

```wlangage
Trace("ArcTang(1) = " + ArcTang(1))
Trace("ArcTang(3/4) = " + ArcTang(3/4))
```

affiche dans la fenêtre de trace :

```wlangage
ArcTang(1) = 45ArcTang(3/4) = 36.86989764584
```
