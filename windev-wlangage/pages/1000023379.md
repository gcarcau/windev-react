# PicOuvre (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Ouvre une image dans un champ Editeur d'images.

## Exemple

```wlangage
sFichier est une chaîne

// Ouvre le sélecteur d'images
sFichier = fSélecteurImage("", "", "Sélectionnez une image...")
SI sFichier = "" ALORS
	RETOUR
FIN

// Ouverture de l'image dans le champ Editeur d'images
SI PicOuvre(EI_MonEditeur, sFichier) = Faux ALORS
	Erreur(ErreurInfo())
FIN
```

## Syntaxe

```wlangage
<Résultat> = PicOuvre(<Champ Editeur d'images> , <Image> [, <Mode d'ouverture>])
```

`<Résultat>` *Booléen*
> - Vrai si l'image a été ouverte,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Champ Editeur d'images>` *Nom de champ*
> Nom du champ Editeur d'images utilisé pour afficher l'image.
`<Image>` *Chaîne de caractères ou variable de type Image*
> Image à afficher dans le champ Editeur d'images. Ce paramètre peut correspondre à :
>
> - une variable de type [Image](1000019650.md).
> - le chemin d'un fichier image.
`<Mode d'ouverture>` *Constante optionnelle de type Entier*
> Mode d'ouverture de l'image :
>
>
> | *odOptionAucune* (valeur par défaut) | L'image est affichée dans le champ Editeur d'images en mode lecture/écriture. |
> | --- | --- |
> | *odOptionLectureSeule* | L'image est affichée dans l'éditeur d'images en mode lecture seule.  Dans ce mode, seules les options d'affichage et l'OCR seront accessibles. L'utilisateur pourra également imprimer et faire un "Enregistrer sous". |
> | *odOptionVoletInvisible* | L'image est affichée dans l'éditeur d'images en mode lecture/écriture et le volet de droite (permettant par exemple d'afficher les caractéristiques de couleur) n'est pas affiché par défaut. |

## Remarques

Cette fonction est équivalente aux syntaxes suivantes :

```wlangage
<Champ Editeur d'images> = <Chemin de l'image><Champ Editeur d'images> = <Variable de type Image>
```
