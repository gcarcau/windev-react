# InterrupteurSupprime (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Supprime une option d'un champ Interrupteur.

## Exemple

```wlangage
// Supprime l'option numéro 3 d'un champ Interrupteur
InterrupteurSupprime(INT_Options, 3)
```

## Syntaxe

#### Suppression d'une option identifiée par son indice

```wlangage
InterrupteurSupprime(<Champ Interrupteur> , <Indice>)
```

`<Champ Interrupteur>` *Nom de champ*
> Nom du champ Interrupteur à manipuler.
`<Indice>` *Entier*
> Indice de l‘option à supprimer. Cet indice doit être compris entre 1 et le nombre d'options contenues dans le champ Interrupteur. La propriété [Occurrence](2510097.md) permet de connaître le nombre d'options d'un champ Interrupteur.

> Cette syntaxe n'est pas disponible pour les applications Android

Suppression d'une option identifiée par son nom Masquer les détails
Supprime(<Champ Interrupteur> , <Nom de l'option>)

 <Champ Interrupteur> : Nom de champNom du champ Interrupteur à manipuler. <Nom de l'option> : Chaîne de caractèresNom de l‘option à supprimer. Le nom de l'option a été défini dans la fenêtre de description du champ Interrupteur (onglet "Contenu).

## Remarques

- Lors de la suppression d'options dans un champ Interrupteur, la taille du champ n'est pas modifiée. Il est possible de modifier la taille du champ avec les propriétés [Largeur](2510059.md) et [Hauteur](2510050.md).
- Il est possible de compacter les options pour optimiser l'aspect du champ après suppression des options.
  En mode compacté, les options d'un champ Interrupteur se resserrent :
  - lorsqu'une option est rendue invisible.
  - lorsqu'une option est supprimée.
- Pour utiliser le mode compacté :
  - cochez l'option "Compacter les options invisibles" dans l'onglet "Détail" de la description du champ.
  - utilisez la propriété [CompacteOption](1000020608.md).
- Lors de la suppression d'une option, les indices des options suivant l'option supprimée sont automatiquement renumérotés.
