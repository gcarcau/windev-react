# Propriétés associées au champ Kanban

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Dans une fenêtre ou une page, il est possible de manipuler avec les propriétés WLangage :

- un champ Kanban,
- un champ Liste de Kanban.
