# Image (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Image** permet de connaître et de modifier l'image de fond associée à un élément.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS)_ Dans un état, la propriété Image permet de connaître et de modifier l'image de fond d'un champ ou d'un bloc.

> _(WINDEV, WINDEV Mobile, WINDEV, WINDEV, WINDEV, WINDEV, Android, iPhone/iPad, Widget IOS, Android, WINDEV, WINDEV, Android, iPhone/iPad, Widget IOS)_ Dans une fenêtre, la propriété Image permet de connaître et de modifier l'image : affichée dans la barre d'icônes d'une fenêtre de type mère MDI (uniquement en WINDEV), associée au libellé d'un bouton,associée à un volet d'onglet ou à un onglet,associée aux volets d'une boîte à outils ou à un bouton d'un volet de la boîte à outils,associée au libellé d'une option de menu,utilisée comme curseur dans une jauge ou dans un potentiomètre non rotatif, utilisée pour la coche des interrupteurs ou des sélecteurs (uniquement en WINDEV), utilisée dans les options des interrupteurs et sélecteurs au look Vista,utilisée en image de fond d'un champ Calendrier. utilisée dans un champ Notation. utilisée pour les marqueurs d'un champ Carte. utilisée en icône dans une Action Bar (propriété disponible à partir de la version 4.0 d'Android (Ice cream sandwich, api level 14)). utilisée pour un regroupement lorsque le regroupement d'un ruban est fermé. utilisée pour représenter une jauge infinie.

> _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur, PHP)_ Dans une page, la propriété Image permet de connaître et de modifier l'image associée :à un champ Image,à un champ Web Caméra (code serveur uniquement),à un bouton à image fixe (code navigateur uniquement),à un champ Vignette,à un champ Calendrier (image de fond).à un champ Réseau social (dont l'image est personnalisée).aux marqueurs d'un champ Carte.
**Remarque** : Ces images sont définies sous l'éditeur dans la description du champ, de la fenêtre ou de la page (onglet "Général" ou "Détail").

## Exemple

> _(WINDEV, Etats et Requêtes, Java, Code Utilisateur (MCU))_ // Modification de l'image associée au libellé du bouton "Aide"
BTN_Aide.Image = "C:\MesImages\Aide.ICO"

> _(WINDEV, Etats et Requêtes, Java, Code Utilisateur (MCU))_ // Modification de l'image associée à la case à cocher d'un interrupteur
INT_Inter.Image = "C:\MesImages\Interrupteur_anim.gif"

> _(WINDEV, WEBDEV - Code Serveur, WEBDEV - Code Navigateur, Etats et Requêtes, Java, Code Utilisateur (MCU), Ajax)_ // Modifier l'image de fond du champ "NomClient"
NomClient.Image ="C:\MesImages\Image.BMP"

## Remarques

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS)_ Image associée à un champ ou à un bloc d'un étatL'image d'un champ Image peut être connue et/ou modifiée sous l'éditeur d'états dans l'onglet "Général" de la description du champ.L'image de fond d'un champ ou d'un bloc peut être connue et/ou modifiée sous l'éditeur d'états, dans l'onglet "Style" de la description du champ ou du bloc. Il suffit de sélectionner l'élément "Image de fond".

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS)_ Image scannée dans un étatLa propriété Image ne permet pas de modifier l'image scannée d'un état. En effet, l'image scannée d'un état permet de :faciliter le positionnement des différents champs dans l'état,visualiser le résultat lors de l'aperçu avant impression.

> _(WINDEV, Code Utilisateur (MCU))_ Image dans une option de menuSi une image est associée à une option de menu marquée, l'image remplace la marque.

> _(WINDEV, Android, Code Utilisateur (MCU))_ Image d'un onglet ou d'un volet d'ongletPour modifier l'image d'un onglet (c'est-à-dire l'image des boutons de l'onglet), il suffit d'utiliser le code suivant :

ONG_Onglet.Image = "Exemple.jpg"

Pour modifier l'image affichée dans le bouton de l'onglet (à côté du libellé), il suffit de préciser l'indice de l'onglet à modifier :

ONG_Onglet[1].Image = "Exemple.jpg"

> _(WINDEV, Code Utilisateur (MCU))_ Image des coches d'interrupteur et de sélecteurLa propriété Image permet de changer la coche des interrupteurs et des sélecteurs. Cette propriété correspond à l'option "Image des coches" dans l'onglet "Détail" de la description du champ.Si l'image de la coche ne doit pas être animée : l'image utilisée doit être constituée des deux ou trois états de la coche : Coché, Décoché et Indéfini si nécessaire.Si l'image de la coche est animée, l'image utilisée doit être une image GIF, contenant pour chaque état principal (Coché, Décoché et Indéfini), les images suivantes :Coche active (pas d'animation)Coche enfoncée (animation)Coche grisée (pas d'animation)Coche survolée (animation)Exemple d'image utilisée pour une coche animée :
1. Images pour l'état coché.2. Images pour l'état décoché.3. Images pour l'état indéfini.

> _(Android, iPhone/iPad)_ Action BarLa propriété Image permet de changer l'icône affichée dans l'Action Bar de la fenêtre. Si la propriété Image correspond à une chaîne vide (""), l'icône de l'application sera utilisée (cas par défaut). Nouveauté AbonnementLa propriété Image permet de changer également de modifier l'icône affichée dans un des volets de l'Action Bar (dans la barre de navigation). Dans ce cas, la syntaxe à utiliser est la suivante :

<Nom Action Bar>[<Indice>].Image

où Indice correspond à l'indice de la vue dans le champ Action Bar. Par exemple, pour afficher l'image "produit.jpg" dans le second volet, le code WLangage est le suivant :

ACTB_ActionBar[2].Image = "produit.jpg"

Attention : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3. Pour plus de détails, consultez Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement.Remarque : Pour plus de détails sur les volets / vues d'une action bar, consultez Description du champ Action Bar.

### Limites

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS)_ Dans un état, la propriété Image ne peut pas être utilisée sur :un état.un code-barres.un champ Interrupteur.
Formats d'images autorisés :

- Les formats d'images pouvant être affichés sont les suivants : tous les formats décrits dans la fonction [fFiltreImage](3036009.md).
- Les formats d'images pouvant être affichés sont les suivants : BMP, ICO, JPEG, et GIF.

> _(WINDEV)_ La propriété Image peut être utilisée uniquement sur :une fenêtre de type MDI,un bouton,un volet d'onglet ou un onglet,un volet d'une barre d'outils ou un bouton d'un volet,une option de menu,une jauge,un potentiomètre non rotatif,un interrupteur,un sélecteur,un champ Calendrier,un champ Notation.un marqueur d'un champ Carte.un champ Jauge infinie personnalisé.

> _(WEBDEV - Code Serveur)_ La propriété Image peut être utilisée uniquement sur :un champ Image.un champ Web Camera.un champ Calendrier.un champ Réseau social (dont l'image est personnalisée).un marqueur d'un champ Carte.

> _(WEBDEV - Code Navigateur)_ La propriété Image peut être utilisée uniquement sur :un bouton à image fixe.un champ Image. un marqueur d'un champ Carte.

> _(Java)_ La propriété Image s'applique uniquement aux éléments suivants :Bouton.Fenêtre.
