# GroupePremier (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **Autres** (Procédures stockées)

Lit le premier groupe de contacts présent dans le carnet d'adresses d'une messagerie Lotus Notes ou Outlook.
Lors de la lecture d'un groupe de contacts, les données de ce groupe sont mises à jour dans la [structure Groupe](1000008120.md). Pour récupérer les données du groupe de contacts en cours, il suffit de récupérer les valeurs de la [structure Groupe](1000008120.md).

**Attention** : Cette fonction **ne permet pas** de lire le premier groupe de contacts présent dans le carnet d'adresses d'une messagerie Outlook Express.

## Exemple

```wlangage
// Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", ...
	"mail\julie.nsf", "C:\Users\Julie\AppData\Local\Lotus\Notes\Data\user.id")

// Lecture du premier groupe de contacts
GroupePremier(IDSession)
// Ajout des groupes de contacts trouvés dans un champ Liste
TANTQUE mGroupe.EnDehors = Faux
	ListeAjoute(LISTE_GroupeContact, mGroupe.Nom + TAB + mGroupe.Description)
	GroupeSuivant(IDSession)
FIN
```

## Syntaxe

```wlangage
<Résultat> = GroupePremier(<Identifiant de la session>)
```

`<Résultat>` *Booléen*
> - Vrai si le premier groupe de contacts a été lu,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Identifiant de la session>` *Entier*
> Identifiant de la session à utiliser. Cet identifiant est renvoyé par une des fonctions suivantes : [EmailOuvreSessionNotes](3032121.md), [EmailOuvreSessionOutlook](3032128.md), [NotesOuvreBase](1000005101.md) ou [OutlookOuvreSession](3032123.md).

## Remarques

### Groupe de contact en cours
La variable mGroupe.EnDehors permet de savoir s'il y a un groupe de contacts courant.

### Version de Outlook utilisée
Les groupes de contacts ne sont pas gérés par Outlook version 97. Il n'est donc pas possible de rechercher un groupe de contacts dans cette version de Outlook.

**Composante : wd300com.dll**
