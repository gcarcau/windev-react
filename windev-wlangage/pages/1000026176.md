# TexteSaisieObligatoire (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (iPhone/iPad)

La propriété **TexteSaisieObligatoire** permet de connaître et de définir le texte qui sera affiché si le champ est vide (avec la propriété [SaisieObligatoire](1000026174.md) activée).

## Exemple

```wlangage
SAI_DateNaissance.TexteSaisieObligatoire = ...
	"Donner votre date de naissance, on vous souhaitera votre anniversaire"
```

## Syntaxe

#### Connaître le texte affiché en cas de saisie obligatoire

```wlangage
<Résultat> = <Champ manipulé>.TexteSaisieObligatoire
```

`<Résultat>` *Chaîne de caractères*
> - Message d'erreur utilisé en cas de saisie obligatoire (propriété [SaisieObligatoire](1000026174.md) à Vrai),
> - Chaîne vide si le message d'erreur par défaut est utilisé ("Saisie obligatoire").
`<Champ manipulé>` *Nom de champ*
> Nom du champ manipulé. Ce champ peut être :
>
> - un champ de saisie,
> - un champ Interrupteur,
> - un champ Sélecteur,
> - un champ Combo,
> - un champ Notation.

#### Modifier le texte affiché en cas de saisie obligatoire

```wlangage
<Champ manipulé>.TexteSaisieObligatoire = <Message>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ manipulé. Ce champ peut être :
>
> - un champ de saisie,
> - un champ Interrupteur,
> - un champ Sélecteur,
> - un champ Combo,
> - un champ Notation.
`<Message>` *Chaîne de caractères*
> - Message d'erreur utilisé en cas de saisie obligatoire (propriété [SaisieObligatoire](1000026174.md) à Vrai),
> - Chaîne vide si le message d'erreur par défaut est utilisé ("Saisie obligatoire").
