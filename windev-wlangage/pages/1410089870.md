# NotifPushAbonne (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android)

Abonne l'application Android en cours aux notifications push relatives à un sujet. L'application recevra automatiquement les notifications push envoyées avec la fonction [NotifPushEnvoieAbonné](1410089872.md) pour le sujet spécifié.

## Exemple

```wlangage
// Demande à recevoir les notifications push du sujet "score"
NotifPushAbonne("score")
```

## Syntaxe

```wlangage
<Résultat> = NotifPushAbonne(<Sujet>)
```

`<Résultat>` *Booléen*
> - Vrai si l'abonnement a été effectué,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet de connaître l'erreur renvoyée par le service de notification.
`<Sujet>` *Chaîne de caractères*
> Sujet (ou topic) associé aux notifications push auxquelles l'application veut s'abonner.

**Composante : wd300android.jar**
