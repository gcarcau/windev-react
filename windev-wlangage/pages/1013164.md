# Evénements associés aux champs Libellé

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

## Evénements gérés par défaut

> _(WINDEV, Android, Widget Android, iPhone/iPad, Java, Code Utilisateur (MCU))_ Evénements gérés par WINDEV et WINDEV MobileWINDEV et WINDEV Mobile gèrent par défaut les événements suivants (ordre d'apparition sous l'éditeur de code) :EvénementCondition d'exécutionInitialisationExécuté à l'ouverture de la fenêtre.*(*) Par défaut, l'événement "Initialisation" de chaque champ est exécuté selon l'ordre de création des différents champs dans la fenêtre. Pour modifier cet ordre d'exécution : Sous le volet "Fenêtre", dans le groupe "Ordre", cliquez sur "Initialisation".Dans la fenêtre qui s'affiche, utilisez les flèches situées sur la droite pour modifier l'ordre d'initialisation des champs.

> _(WEBDEV - Code Serveur, PHP)_ Evénements gérés par WEBDEVWEBDEV gère par défaut l'événement suivant :EvénementCondition d'exécutionInitialisation (Code serveur)Exécuté à l'ouverture de la page.Dans une page statique, le champ Libellé ou Libellé HTML n'est associé à aucun code.
