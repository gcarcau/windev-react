# Namespace (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Namespace** permet de gérer les espaces de nommage. Cette propriété est utilisable sur :

- une variable de type [xmlAttribut](1000018799.md).
- une variable de type [xmlNoeud](1000018786.md).
- une variable de type [xmlLecteur](1000023392.md).
- une variable de type [memcachedConnexion](1000023339.md).
