# ArrondiAuMultiple (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Renvoie une valeur numérique arrondie au multiple le plus proche d'une autre valeur numérique.
Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.

## Exemple

```wlangage
ArrondiAuMultiple(10, 9)
// Renvoie 9

ArrondiAuMultiple(-10, -3)
// Renvoie -9

ArrondiAuMultiple(1.3, 0.2)
// Renvoie 1.4

ArrondiAuMultiple(2.64, 0.25)
// Renvoie 2.75
```

## Syntaxe

```wlangage
<Résultat> = ArrondiAuMultiple(<Valeur numérique> , <Valeur multiple>)
```

`<Résultat>` *Variant*
> Valeur de <Valeur numérique> arrondie au multiple le plus proche de <Valeur multiple>.
`<Valeur numérique>` *Numérique*
> Valeur numérique à arrondir.
`<Valeur multiple>` *Numérique*
> Valeur dont le multiple le plus proche doit être calculé.

## Remarques

Les arrondis avec le type "Réel" ne sont pas précis. En effet, les opérations avec le type "réel" ne sont pas précises du fait de la représentation informatique des réels. Pour obtenir un arrondi exact, il est conseillé d'utiliser le type Monétaire (ou Numérique) qui utilise une représentation mémoire exacte. Pour plus de détails, consultez [le type Réel](1514048.md).
