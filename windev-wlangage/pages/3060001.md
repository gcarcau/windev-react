# Fonctions de gestion des polices

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Les fonctions permettant de manipuler les polices (police des dessins, polices d'impression, ...) sont les suivantes :

| [dPolice](3029020.md) | Déclare la police de caractères qui sera utilisée par la fonction [dTexte](3029032.md) :   - dans un champ Image, - dans une variable de type [Image](1000019650.md), - dans une variable de type [WDPic](1000023503.md) (sur le calque d'arrière-plan), - dans une variable de type [picCalque](1000024604.md). |
| --- | --- |
| [gPolice](3029047.md) | Construit une séquence de caractères décrivant la police d'affichage à utiliser pour le texte. |
| [gPoliceGras](3029061.md) | Construit une séquence de caractères permettant d'indiquer si le texte suivant l'appel de cette fonction est en gras ou non. |
| [gPoliceItalique](3029062.md) | Construit une séquence de caractères permettant d'indiquer si le texte suivant l'appel de cette fonction est en italique ou non. |
| [gPoliceSoulignée](3029063.md) | Construit une séquence de caractères permettant d'indiquer si le texte suivant l'appel de cette fonction est souligné ou non. |
| [gPoliceTaille](3029064.md) | Construit une séquence de caractères permettant d'indiquer la taille de la police d'affichage du texte d'une chaîne graphique. |
| [grPoliceEtiquette](3042012.md) | Modifie la police utilisée pour les étiquettes de catégorie d'un graphe. |
| [grPoliceLégende](3042037.md) | Modifie la police utilisée pour la légende d'un graphe. |
| [grPoliceTitre](3042048.md) | Modifie la police utilisée pour le titre d'un graphe. |
| [grPoliceTitreAxe](3042059.md) | Modifie la police utilisée pour les titres des axes d'un graphe. |
| [iCréePolice](3046045.md) | Crée une nouvelle police d'impression. |
| [iPolice](3046014.md) | Sélectionne la police par défaut. |
| [iPoliceDidot](3046016.md) | Sélectionne l'unité à utiliser pour la hauteur des polices (créées avec la fonction [iCréePolice](3046045.md)) : point DIDOT ou point PICA. |
| [iSelectPolice](3046055.md) | Crée une nouvelle police d'impression depuis la fenêtre standard de sélection des polices de Windows... |
| Nouveauté Abonnement [PoliceCharge](1410090994.md) | Charge une police personnelle depuis un fichier (ou un buffer). Après le chargement, les polices et variantes déclarées par le fichier seront disponibles dans toute l'application.  **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 1.** |
| [PoliceCrée](3060002.md) | Crée une définition de police. |
| Nouveauté Abonnement [PoliceDécharge](1410090995.md) | Décharge une police précédemment chargée avec la fonction [PoliceCharge](1410090994.md). **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 1.** |
| [PoliceListe](3060003.md) | Renvoie la liste des polices valides installées sur le poste en cours (TrueType, Postscript, ...). |
| [PoliceSelect](3060004.md) | Ouvre la fenêtre standard de sélection de polices de Windows en sélectionnant la police spécifiée. |
