# sfRésultatDéconnecte (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Le type **sfRésultatDéconnecte** permet de connaître le compte-rendu de la fonction [SFDéconnecte](1000017585.md) lors d'une déconnexion de session. Les caractéristiques de ce type de variable peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Connexion à Salesforce
Cnx est une sfConnexion
Cnx.Login = "balthazar@gmail.com"
Cnx.MotDePasse = "azerty" + "XXB12VCZ54"
SI SFConnecte(Cnx) = Faux ALORS
	Erreur("La connexion a échoué")
	RETOUR
FIN
...
// Déconnexion (deuxième syntaxe)
MesSessions est un tableau de chaînes
Ajoute(MesSessions, Cnx.InfoSession.IDSession)
MonRésultat est un tableau de sfRésultatDéconnecte
SI SFDéconnecte(Cnx, MesSessions, MonRésultat) = Faux ALORS
	 Erreur("Une déconnexion a échoué")
	 Trace(MonRésultat[1].Succès) // Affiche 0
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type sfRésultatDéconnecte
Les propriétés suivantes peuvent être utilisées pour manipuler le compte-rendu de la fonction [SFDéconnecte](1000017585.md) :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Erreur | Tableau de [sfErreur](1000018455.md) | Compte-rendu d'erreurs. |
| Succès | Booléen | - Vrai si la déconnexion a été effectuée, - Faux dans le cas contraire.  **Cette propriété est disponible en lecture seulement**. |

## Remarques

### Fonctions manipulant le type sfRésultatDéconnecte

| [SFDéconnecte](1000017585.md) | Déconnecte :   - la plateforme Salesforce. - la session Salesforce en cours. |
| --- | --- |
