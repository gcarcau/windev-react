# Fonctions MDI

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

**Remarque** : Ces fonctions sont également disponibles en syntaxe préfixée ([Fonctions MDI (syntaxe préfixée)](3052008.md)).
Les fonctions MDI sont les suivantes :

| [MDIActive](3052002.md) | Identifie ou place une fenêtre fille MDI en avant-plan. |
| --- | --- |
| [MDIEnumèreFille](3052001.md) | Renvoie l'alias de la fenêtre fille MDI spécifiée. |
| [MDIMenuFenêtre](3052004.md) | Modifie l'agencement des fenêtres filles MDI. |
| [MDIMère](3052006.md) | Identifie le nom de la fenêtre mère MDI. |
| [MDIOuvre](3052005.md) | Ouvre et active une fenêtre fille MDI. |
