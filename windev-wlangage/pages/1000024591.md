# <Source>.ChangeMotDePasse (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Change le mot de passe d'un fichier de données HFSQL Classic ou HFSQL Client/Serveur. Les applications utilisant l'ancien mot de passe ne pourront plus accéder à ce fichier de données : une erreur de mot de passe sera affichée.
**Attention** : Cette fonction est une fonction avancée. Il est nécessaire de l'utiliser avec prudence car elle peut entraîner des erreurs des applications clientes.

## Exemple

```wlangage
// Ancien mot de passe
HPasse("*", "MotDePasse")
// Modification du mot de passe
Client.ChangeMotDePasse("NouveauMotDePasse")
```

```wlangage
// Création d'un fichier de données avec un mot de passe
FichierA.MotDePasse("TEST")
FichierA.Création()

// Ajout de données
FichierA.RubriqueA = "Test 1"
FichierA.Ajoute()

// Lecture des données
FichierA.LitPremier()
Info(FichierA.RubriqueA)

// Changement du mot de passe
Info("Maintenant, changement de mot de passe ...")
FichierA.ChangeMotDePasse("NV_Test")
Info("Mot de passe changé, relecture du premier enregistrement")

// Relecture des données
FichierA.LitPremier()
Info(FichierA.RubriqueA)

// Gestion des erreurs
CAS ERREUR:
	Erreur(HErreurInfo())
	RETOUR
```

## Syntaxe

```wlangage
<Résultat> = <Source>.ChangeMotDePasse(<Nouveau mot de passe>)
```

`<Résultat>` *Booléen*
> - Vrai si le mot de passe a été modifié,
> - Faux dans le cas contraire. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Source>` *Type correspondant à la source spécifiée*
> Nom du fichier de données HFSQL (défini dans l'analyse) à manipuler.
`<Nouveau mot de passe>` *Chaîne de caractères ou Chaîne secrète*
> Nouveau mot de passe à utiliser pour le fichier de données.
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).

## Remarques

- Si le fichier de données est déjà protégé par un mot de passe, il est nécessaire d'indiquer ce mot de passe avec la fonction [<Source>.MotDePasse](1000025044.md) avant d'utiliser la fonction **<Source>.ChangeMotDePasse**.
- Pour pouvoir modifier le mot de passe d'un fichier de données, il est nécessaire de posséder les droits de modification automatique (constante *hDroitModifAuto*). Ce droit peut être défini grâce à la fonction [<Variable Connexion>.ModifieDroitFichier](1000022709.md).
- Cette fonction lance une modification automatique du fichier de données. Si le fichier de données était crypté avec un mot de passe différent, il sera entièrement re-crypté avec le nouveau mot de passe. Cette opération peut être relativement longue.
