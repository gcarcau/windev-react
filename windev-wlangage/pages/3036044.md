# fRépertoireTemp (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Renvoie le nom du répertoire utilisé pour stocker les fichiers temporaires.

## Exemple

```wlangage
// Récupération du nom du répertoire temporaire
ResRepTemp = fRépertoireTemp()
```

## Syntaxe

```wlangage
<Résultat> = fRépertoireTemp()
```

`<Résultat>` *Chaîne de caractères*
> - Chemin du répertoire utilisé pour stocker les fichiers temporaires (260 caractères maximum). Ce chemin se termine par le caractère "\".
>    Ce chemin correspond au répertoire "tmp" de l'application.
> - Chaîne vide ("") en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
>
> **Remarque** : Le résultat de la fonction **fRépertoireTemp** est toujours une chaîne de caractères au format Ansi. Il est cependant possible de stocker le résultat dans une chaîne de caractères Unicode.

## Remarques

### Répertoire temporaire
Sous Windows Vista (ou supérieur) avec le [système de l'UAC](2025014.md) activé, le répertoire temporaire utilisé est différent si l'utilisateur a les privilèges administrateur ou non.

### Equivalence
La fonction **fRépertoireTemp** est équivalente à la fonction [fRepTemp](1000021768.md).
