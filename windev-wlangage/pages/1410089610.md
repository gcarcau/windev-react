# Formule (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **Formule** permet de décrire une formule dans un document ou une feuille de données. Cette propriété est utilisable sur :

- une variable de type [xlsCellule](1000017472.md).
- une variable de type [docElément](1000022484.md).
