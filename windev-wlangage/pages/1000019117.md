# SaaSAdminSupprimeClient (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Supprime un compte client SaaS.
**Remarques** :

- L'utilisation de cette fonction nécessite d'avoir ouvert une session d'administration SaaS au préalable en utilisant la fonction [SaaSAdminConnecte](1000019098.md).
- L'utilisation de cette fonction est réservée à l'Administrateur SaaS. Un gestionnaire de compte client ne peut pas utiliser cette fonction.

## Exemple

```wlangage
S est un saasClient
S = SaaSAdminChercheClient("Hybrid")

SI SaaSAdminSupprimeClient(S) = Vrai ALORS
	Info("Client supprimé.")
FIN
```

## Syntaxe

```wlangage
<Résultat> = SaaSAdminSupprimeClient(<Compte client>)
```

`<Résultat>` *Booléen*
> - Vrai si la suppression a été effectuée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Compte client>` *Variable de type saasClient ou chaîne de caractères*
> Nom de la variable de type [saasClient](1000019072.md) ou chaîne de caractères correspondant au compte client à supprimer le la base SaaS.
> Si ce paramètre est une chaîne de caractères, celle-ci représente le nom du compte client ou sa propriété [RéférenceExterne](1000019072.md).
