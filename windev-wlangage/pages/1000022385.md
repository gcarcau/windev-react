# <Carte>.RécupèreObjetJS (Fonction)

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur)

Retourne l'instance de l'API d'un champ Carte. Il est ainsi possible de manipuler le champ Carte directement dans du code Javascript.
Combinée à la fonction [CarteConfigureAPIGgl](1000021611.md), cette fonction permet de gérer des paramètres supplémentaires, non proposés par défaut par le champ Carte.

**Remarque** : En WINDEV, cette fonction peut être utilisée dans le code Javascript exécuté par la fonction [<Carte>.ExécuteJS](1000022384.md) pour manipuler le champ Carte de l'application WINDEV.

## Exemple

```wlangage
// Code serveur
CarteConfigureAPIGgl("libraries=geometry,places","language=fr")
```

```wlangage
// Code navigateur
MaCarte est un objet dynamique
MaCarte = CARTE_Navigateur.RécupèreObjetJS()
RechercheAdresse(MaCarte)
```

```wlangage
// Fonction Javascript utilisant l'objet dynamiquefunction RechercheAdresse(MaCarte){ var infowindow; // Rome : 41.873144, 12.480391 var pyrmont = new google.maps.LatLng(41.873144, 12.480391); var request = {  location: pyrmont,  radius: 500,  types: ['store']  }; infowindow = new google.maps.InfoWindow(); var service = new google.maps.places.PlacesService(MaCarte); service.nearbySearch(request, RetourAdresse_WB); }
```

## Syntaxe

```wlangage
<Champ Carte>.RécupèreObjetJS()
```

`<Champ Carte>` *Nom de champ*
> Nom du champ Carte à manipuler.

**Composante : WDJS.DLL**
