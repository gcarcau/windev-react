# OUExclusifBinaire (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Renvoie le résultat du OU Exclusif logique (bit à bit) entre deux valeurs.

## Exemple

```wlangage
// Récupération du OU Exclusif logique
ResOUEXBinaire = OUExclusifBinaire(6, 6)  // Renvoie 0
ResOUEXBinaire = OUExclusifBinaire(6, 2)  // Renvoie 4
```

## Syntaxe

```wlangage
<Résultat> = OUExclusifBinaire(<Valeur 1> , <Valeur 2>)
```

`<Résultat>` *Entier*
> Résultat du OU Exclusif logique.
`<Valeur 1>` *Entier*
> Première valeur à tester.
`<Valeur 2>` *Entier*
> Seconde valeur à tester.

## Remarques

### Calcul bit à bit
La fonction **OUExclusifBinaire** effectue le calcul bit à bit entre <Valeur 1> et <Valeur 2> selon la table suivante :

|  | **0** | **1** |
| --- | --- | --- |
| **0** | 0 | 1 |
| **1** | 1 | 0 |

### Opérateur binaire

- La fonction **OUExclusifBinaire** est équivalente à l'opérateur binaire **||** pour les entiers sur 4 octets. Pour plus de détails, consultez [Opérateurs binaires](1512009.md).
- Le résultat de la fonction **OUExclusifBinaire** est exact sur des entiers sur 4 octets. Son utilisation avec des entiers sur 8 octets provoque un débordement de capacité.
- L'opérateur binaire **||** permet de faire des opérations sur des entiers sur 8 octets.
