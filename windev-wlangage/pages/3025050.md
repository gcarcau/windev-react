# TexteVersHTML (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Convertit une chaîne texte en chaîne HTML (les retours chariots sont remplacés par des <BR>, les accents sont remplacés par leur équivalent en HTML, ...).

## Exemple

```wlangage
// SAI_HTML est un champ de saisie
SAI_HTML = TexteVersHTML("WINDEV est un outil formidable" + RC + ...
	"Le développement devient un jeu d'enfant")
```

## Syntaxe

```wlangage
<Résultat> = TexteVersHTML(<Texte> [, <Alphabet utilisé>])
```

`<Résultat>` *Chaîne de caractères*
> Texte au format HTML. Attention : les balises <html> et </html> ne sont pas intégrées dans le résultat. Si le résultat doit être affiché dans un champ HTML, il est nécessaire de les ajouter.
`<Texte>` *Chaîne de caractères*
> Nom du champ de type texte ou bien chaîne de caractères au format texte.
`<Alphabet utilisé>` *Constante optionnelle de type Entier*
> Constante identifiant l'alphabet utilisé pour l'écriture du <Texte>. Par défaut, l'alphabet en cours de WINDEV/WEBDEV est utilisé (constante *alphabetCourant*).
> Pour plus de détails sur ces constantes, consultez [Correspondance entre les langues, les sous-langues, les alphabets et les nations](3054022.md).
> > _(WEBDEV - Code Navigateur, PHP)_ Ce paramètre n'est pas disponible

## Remarques

- Pour convertir une chaîne RTF au format HTML, utilisez la fonction [RTFVersHTML](3025049.md).
- Pour convertir une chaîne RTF au format Texte, utilisez la fonction [RTFVersTexte](3025032.md).
