# IndiceConfiance (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **IndiceConfiance** permet de connaître l'indice de confiance d'une analyse de données. Cette propriété est utilisable sur :

- une variable de type [ocrBlocTexte](1000025639.md).
- une variable de type [iaRésultatImage](1410087965.md).
