# Erreur 1037 : Ce membre existe déjà dans la structure

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

## Cause

Vous déclarez une structure utilisant deux membres de même nom. Cette erreur peut apparaître suite à une faute de frappe par exemple dans le nom d'un des membres de la structure.

## Correction

Renommez ou supprimez le membre en trop.

## Exemple

### Déclaration d'une structure avec deux membres de même nom

**Code provoquant l'erreur**

```wlangage
Coord est une Structure  PosX est un entier PosX est un entierFIN
```

**Correction proposée**
Renommer un des membres.

```wlangage
Coord est une Structure  PosX est un entier PosY est un entierFIN
```
