# ThreadReprend (Fonction)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Relance l'exécution d'un thread précédemment suspendu par la fonction [ThreadSuspend](3077014.md).
**Rappel** : Un thread est un processus lancé en parallèle de l'application en cours ("thread" principal). Il est par exemple possible de lancer l'exécution d'une tâche en traitement de fond (sauvegarde, ...).

## Exemple

```wlangage
// -- Clic sur le champ Bouton BTN_Enregistre
// Suspend l'impression en tâche de fond
ThreadSuspend("Impression_fond")
// Enregistrement
...
// Reprend l'impression
ThreadReprend("Impression_fond")
```

## Syntaxe

```wlangage
ThreadReprend(<Thread>)
```

`<Thread>` *Chaîne de caractères*
> Nom du thread à relancer. Ce nom est donné lors de l'exécution du thread (fonction [ThreadExécute](3077024.md)).
> Si le thread n'existe pas (thread déjà arrêté par exemple), aucune erreur n'est affichée.

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
