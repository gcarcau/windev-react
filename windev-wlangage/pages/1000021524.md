# CodeEtat

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **CodeEtat** permet de connaître l'état de la réponse à la requête. Cette propriété est utilisable sur :

- une variable de type [httpRéponse](1000021165.md).
- une variable de type [restRéponse](1000021477.md).
