# SocketRefuse (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Exécutée sur le poste serveur, cette fonction refuse une demande de connexion sur un socket existant sur le poste serveur.
**Remarque** :

- Si le poste client utilise une application WINDEV pour se connecter à ce socket, cette application devra utiliser la fonction [SocketConnecte](3070016.md).
- La fonction **SocketRefuse** ne peut pas être utilisée avec un socket de type UDP.
- La fonction **SocketRefuse** peut être utilisée avec un socket SSL.

**Rappel** : Un socket est une ressource de communication utilisée par les applications pour communiquer d'une machine à une autre sans se soucier du type de réseau.

## Syntaxe

```wlangage
<Résultat> = SocketRefuse(<Nom du socket>)
```

`<Résultat>` *Booléen*
> - Vrai si la connexion a été refusée,
> - Faux en cas d'erreur. Pour obtenir plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Nom du socket>` *Chaîne de caractères*
> Nom du socket serveur qui refuse la connexion. Ce nom a été défini :
>
> - soit par la fonction [SocketCrée](3070011.md), [SocketCréeSSL](1000017041.md), [SocketCréeInfraRouge](3070012.md) (cas d'un serveur simplifié).
> - soit la fonction [SocketAccepte](3070004.md) (cas d'un serveur standard).
>
>
> > _(WINDEV)_ Attention : Le nom du socket est "case-sensitive".

## Remarques

> _(Android, Widget Android)_ Permissions requisesL'utilisation de cette fonction entraîne la modification des permissions requises par l'application. Permission requise : INTERNET Cette permission autorise l'application à ouvrir des sockets réseau.
