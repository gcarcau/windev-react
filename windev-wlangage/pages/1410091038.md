# EmailExécuteCommande (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Envoie une commande IMAP au serveur de mails.
Nouveauté Abonnement
Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
session est une emailSessionIMAP
session.AdresseServeur = "imap.gmail.com"
session.Port = 993
session.Option = optionTLS
session.Nom = "XXXXXXXX"
session.MotDePasse = "XXXXXXXXXX"

// Ouverture d'une session
EmailOuvreSession(session)

// Exécution d'une commande
res = EmailExécuteCommande(session, "NOOP")
Trace("Commande : " + res)
```

## Syntaxe

```wlangage
<Résultat> = EmailExécuteCommande(<Session IMAP> , <Commande>)
```

`<Résultat>` *Chaîne de caractères*
> Résultat de la commande.
> En cas d'erreur (si le serveur a retourné un message d'erreur NO ou BAD), la variable [ErreurDétectée](3087001.md) est à Vrai. Le compte-rendu détaillé de l'erreur est connu grâce à la fonction [ErreurInfo](3013008.md).
`<Session IMAP>` *Variable de type emailSessionIMAP*
> Nom de la variable de type [emailSessionIMAP](1000018957.md) correspondant à la session IMAP connectée au serveur de mails.
`<Commande>` *Chaîne de caractères*
> Commande à envoyer au serveur de mails.
> Attention : Le serveur de mails doit supporter la commande envoyée.
