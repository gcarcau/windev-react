# Fonctions de gestion d'une base Big Data Redis (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Les fonctions de gestion d'une base de données Redis via une syntaxe préfixée sont les suivantes :

| [<redisConnexion>.Abonne](1410088279.md) | Souscrit un abonnement à un canal de diffusion Redis. |
| --- | --- |
| [<redisConnexion>.Affecte](1410088245.md) | Modifie la valeur d'une clé sur un serveur Redis. |
| [<redisConnexion>.Connecte](1410088280.md) | Ouvre une connexion vers un serveur Redis (ou un cluster Redis). |
| [<redisConnexion>.Désabonne](1410088281.md) | Supprime un abonnement à un canal de diffusion Redis. |
| [<redisConnexion>.ExécuteCommande](1410088282.md) | Exécute une commande sur un serveur Redis et récupère le résultat. |
| [<redisConnexion>.PipelineAjoute](1410088283.md) | Ajoute une commande Redis dans un pipeline. |
| [<redisConnexion>.PipelineRAZ](1410088284.md) | Ignore les résultats de l'exécution d'une commande Redis ayant été ajoutée par la fonction [<redisConnexion>.PipelineAjoute](1410088283.md). |
| [<redisConnexion>.PipelineRécupère](1410088285.md) | Récupère le résultat de l'exécution d'une commande Redis ayant été ajouté par [<redisConnexion>.PipelineAjoute](1410088283.md). |
| [<redisConnexion>.Publie](1410088286.md) | Publie un message sur un canal de diffusion Redis. |
| [<redisConnexion>.Récupère](1410088278.md) | Récupère la valeur d'une clé sur un serveur Redis sous forme de chaîne. |
| [<Variable redisConnexion>.Déconnecte](1410090488.md) | Force la fermeture de la connexion vers un serveur Redis (ou un cluster Redis). |
