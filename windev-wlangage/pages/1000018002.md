# Opacité (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **Opacité** permet de connaître et de modifier l'opacité d'un élément. Cette propriété est utilisable sur :

- les champs d'une fenêtre ou d'une page. Pour plus de détails, consultez [Propriété Opacité sur les champs](2514006.md).
- une variable de type [gglChemin](1000017433.md).
- une variable de type [Couleur](1000019661.md).
- une variable de type [Filigrane](1000019922.md).
- une variable de type [pdfSignature](1000022255.md).
- une variable de type [Toast](1000024638.md).
- une variable de type [picTexte](1000025178.md).
- une variable de type [CarteImage](1000025523.md).
- une variable de type [Marqueur](1000019940.md).
- une variable de type [VisiteGuidée](1410090170.md).
- une variable de type [VisiteGuidéeEtape](1410090178.md).
- Nouveauté Abonnement
  une variable de type [OptionsOuvertureFenêtre](1410091298.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
