# hdfsOuvreConnexion (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Ouvre une connexion vers un serveur Hadoop.

## Exemple

```wlangage
// Connexion
MaConnexion est une hdfsConnexion
MaConnexion.namenode = "MonServeur"
MaConnexion.Utilisateur = "Admin"
SI hdfsOuvreConnexion(MaConnexion) = Faux ALORS
	Erreur(ErreurInfo())
FIN
```

## Syntaxe

```wlangage
<Résultat> = hdfsOuvreConnexion(<Connexion>)
```

`<Résultat>` *Booléen*
> - Vrai si la connexion a été réalisée,
> - Faux en cas de problème. La fonction [ErreurInfo](3013008.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type hdfsConnexion*
> Nom de la variable de type [hdfsConnexion](1000021650.md) correspondant à la connexion au serveur Hadoop à ouvrir.

**Composante : wd300big.dll**
