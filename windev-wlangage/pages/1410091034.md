# <Variable Commande>.Termine (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

Force la terminaison de l'exécutable associé à une commande en mode console en cours d'exécution.
Nouveauté 2025
**Attention** : Cette fonction est disponible uniquement à partir de la version 2025 Update 1.

## Exemple

```wlangage
// Exécution de la commande 'C:\Chemin\MonProgramme.exe -opt1=val1'
// Définition de la commande
MaCommandeAExécuter est une Commande
// Exécutable à lancer
MaCommandeAExécuter.Exécutable = "C:\Chemin\MonProgramme.exe"
// Arguments à passer à l'exécutable
MaCommandeAExécuter.Arguments = "Argument1"
// Activation des flux
MaCommandeAExécuter.Flux = cmdEntréeStandard + cmdSortieStandard
// Ajout d'un argument à la ligne de commande
MaCommandeAExécuter.AjouteArgument("Argument2")
// Ajout d'une option à la ligne de commande
MaCommandeAExécuter.AjouteOption("opt1", "val1")

// Exécution de la commande
MaCommandeAExécuter.Exécute(Faux)
...
SI MaCommandeAExécuter.ExécutionEstEnCours() = Vrai ALORS
	MaCommandeAExécuter.Termine()
FIN
```

## Syntaxe

```wlangage
<Commande manipulée>.Termine()
```

`<Commande manipulée>` *Variable de type Commande*
> Nom de la variable de type [Commande](1410090491.md) correspondant à la commande en mode console à manipuler.

## Remarques

Il est possible de forcer l'arrêt de l'exécutable associé à une commande via la propriété **DestructionAutomatique** d'une variable de type [Commande](1410090491.md).
Si la propriété **DestructionAutomatique** est à Faux, il est possible de :

- savoir si l'exécutable est en cours d'exécution via la fonction [<Variable Commande>.ExécutionEstEnCours](1410091033.md).
- forcer l'arrêt de l'exécutable via la fonction **<Variable Commande>.Termine**.

**Classification Métier / UI : Code métier**

**Composante : wd300std.dll**
