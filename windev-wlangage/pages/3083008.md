# ZoneRépétéeSupprime (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Supprime une répétition dans un champ Zone répétée. Le champ Zone répété est automatiquement rafraîchi.

## Exemple

```wlangage
// Suppression de la répétition 1
ZoneRépétéeSupprime(ZR_ZoneProd, 1)
```

```wlangage
// Suppression de la répétition en cours
ZoneRépétéeSupprime(ZR_ZoneProd)
```

## Syntaxe

```wlangage
ZoneRépétéeSupprime(<Champ Zone répétée> [, <Indice> [, <Animation>]])
```

`<Champ Zone répétée>` *Nom de champ*
> Nom du champ Zone répétée à manipuler.
> Si ce paramètre est égal à chaîne vide (""), la suppression sera effectuée sur le champ Zone répétée en cours.
`<Indice>` *Entier optionnel*
> Indice de la répétition à supprimer.
>
> - Si ce paramètre n'est pas précisé, la suppression sera effectuée sur la répétition en cours.
> - Si <Indice> est supérieur au nombre de répétitions, la fonction **ZoneRépétéeSupprime** est sans effet.
`<Animation>` *Constante optionnelle de type Entier*
> > _(WINDEV, Android, iPhone/iPad)_ Gestion de l'animation lors de la suppression : zrAnimationAucune(Valeur par défaut)Aucune animation n'est jouée lors de la suppression. zrAnimationSuppressionJoue une animation lors de la suppression. Cette animation correspond à un effet de disparition par diminution de la hauteur de la répétition.

## Remarques

### Conditions d'utilisation
La fonction **ZoneRépétéeSupprime** peut être utilisée indifféremment sur :

- un champ Zone répétée fichier,
- un champ Zone répétée par programmation.

> _(WEBDEV - Code Navigateur)_ Cette fonction n'est pas disponible sur les champs Zone répétée linéaire. Cette fonction est disponible uniquement sur les champs Zone répétée en mode navigateur.

> _(WEBDEV - Code Serveur, PHP)_ Cette fonction est disponible pour les champs Zone répétée en mode Ajax, les champs Zone répétée en mode classique et les champs Zone répétée linéaire.

> _(PHP)_ La fonction ZoneRépétéeSupprime peut être utilisée uniquement sur un champ Zone répétée par programmation.

### Utilisation avec un champ Zone répétée fichier
Si le champ Zone répétée est basé sur un fichier de données :

- l'enregistrement est supprimé dans le fichier de données.
- la répétition suivante est sélectionnée (si la dernière répétition est supprimée, la répétition précédente sera sélectionnée). L'enregistrement sélectionné dans le fichier de données lié correspond à la répétition sélectionnée.
