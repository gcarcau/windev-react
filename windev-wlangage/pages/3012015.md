# RépertoireWeb (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

Renvoie le chemin relatif du répertoire contenant :

- les images,
- les fichiers Javascript,
- les fichiers applet Java,
- les autres fichiers accessibles depuis le navigateur.

Ce répertoire correspond au répertoire <Nom du projet>_WEB. Ce répertoire est présent sur le poste de développement et sur le poste de déploiement.
Remarque : Pour atteindre le répertoire "<Nom projet>_WEB", il est possible d'utiliser :

- la fonction **RépertoireWeb** : cette fonction renvoie un chemin relatif destiné à être interprété par le navigateur.
- la fonction [fRepWeb](3036052.md) : cette fonction renvoie un chemin absolu à utiliser depuis le serveur avec les [fonctions de gestion des fichiers externes (fxxx)](3036034.md).

## Exemple

> _(WEBDEV - Code Serveur, Windows, Linux, PHP, Ajax)_ // Champ HTML généré par programmation
NomImage est une chaîne = "Hello.gif"
HTM_ChampHTML = "<IMG SRC=""/" + RépertoireWeb() + "/" + NomImage + """>"

> _(WEBDEV - Code Navigateur, Windows, Linux, PHP)_ // IMG_IMAGE1 est un champ Image
// Option cochée :
// "Localiser l'image dans le répertoire _WEB en code navigateur"
// Modification de l'image affichée dans le champ IMG_IMAGE1
IMG_IMAGE1 = "/Image_Plan.gif"

> _(WEBDEV - Code Navigateur, Windows, Linux, PHP)_ // IMG_IMAGE1 est un champ Image
// Option décochée :
// "Localiser l'image dans le répertoire _WEB en code navigateur"
// Modification de l'image affichée dans le champ IMG_IMAGE1
IMG_IMAGE1 = RépertoireWeb() + "Image_Plan.gif"

## Syntaxe

```wlangage
<Résultat> = RépertoireWeb()
```

`<Résultat>` *Chaîne de caractères*
> Chemin relatif du répertoire contenant les images, les fichiers Javascript, ...
>
> > _(WEBDEV - Code Serveur)_ Le chemin n'est pas complété par le caractère / à la fin.
>
>
> > _(WEBDEV - Code Navigateur)_ Le chemin est complété par le caractère / au début et à la fin.

## Remarques

> _(WEBDEV - Code Navigateur, Windows, Linux, PHP)_ Répertoire des images (en code navigateur)Par défaut, l'option "Localiser l'image dans le répertoire _WEB en code navigateur" est cochée lors de la description d'une image. Dans ce cas, en code navigateur, l'image est automatiquement recherchée dans le répertoire _WEB du site. Aucun code spécifique n'est nécessaire.Si l'option "Localiser l'image dans le répertoire _WEB en code navigateur" est décochée, le chemin complet de l'image doit être indiqué pour retrouver l'image. Il faut pour cela, utiliser la fonction RépertoireWeb.

### Spécifier le répertoire des images en WLangage pour la génération du code HTML
La fonction **RépertoireWeb** peut être utilisée pour spécifier le répertoire des images lors de la génération de code HTML en WLangage.
Si le code HTML doit contenir des références à des images ou tout autre objet statique (fichier Java ou Javascript), il est nécessaire d'utiliser la fonction **RépertoireWeb** pour localiser ces fichiers.

### Installation
Dans le cas d'une installation par média physique, le répertoire des fichiers de données est spécifié lors de l'installation.
Dans le cas d'une installation par accès distant (FTP), l'hébergeur fournit le répertoire de base des fichiers de données et l'utilisateur fournit le nom du sous-répertoire dans lequel les fichiers de données sont installés.
