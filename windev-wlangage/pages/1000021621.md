# <Variable httpRequête>.LitCookie (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Retourne la valeur d'un cookie reçu suite à une requête HTTP.

#### Syntaxe utilisable avec la fonction HTTPEnvoie

```wlangage
<Résultat> = <Requête HTTP>.LitCookie(<Domaine> , <Nom>)
```

`<Résultat>` *Chaîne de caractères*
> - Valeur du cookie.
> - Chaîne vide ("") si le cookie n'existe pas. La variable [ErreurDétectée](3087001.md) est alors à Vrai.
`<Requête HTTP>` *Variable de type httpRequête*
> Nom de la variable [httpRequête](1000021158.md) pour laquelle le cookie doit être lu.
`<Domaine>` *Chaîne de caractères*
> Nom du domaine pour lequel le cookie a été reçu.
`<Nom>` *Chaîne de caractères*
> Nom du cookie.

## Remarques

Pour utiliser la fonction **<Variable httpRequête>.LitCookie**, la gestion des cookies doit avoir été activée par la fonction [<Variable httpRequête>.GèreCookie](1000021608.md).

**Composante : wd300com.dll**
