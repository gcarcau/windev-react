# HDétruitTriggerServeur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Détruit un trigger serveur. Ce trigger serveur ne sera plus utilisable.
**Remarque** : Les fonctions de manipulation des triggers serveur sont des fonctions avancées. Les triggers serveur peuvent être créés directement dans l'éditeur d'analyses. Pour plus de détails, consultez [Triggers serveur](3044369.md).

## Syntaxe

#### Détruire un trigger serveur (fichiers de données HFSQL logiques)

```wlangage
HDétruitTriggerServeur(<Trigger> , <Fichiers logiques HFSQL Client/Serveur>)
```

`<Trigger>` *Chaîne de caractères*
> Nom du trigger à détruire. Ce nom a été donné grâce à la fonction [HDécritTriggerServeur](1000017033.md).
`<Fichiers logiques HFSQL Client/Serveur>` *Chaîne de caractères*
> Nom logique de un ou plusieurs fichiers de données HFSQL Client/Serveur.
> Pour indiquer plusieurs noms, séparez les noms de fichiers de données par une virgule (",").

#### Détruire un trigger serveur sur des fichiers de données HFSQL physiques associés à une connexion

```wlangage
<Résultat> = HDétruitTriggerServeur(<Connexion> , <Trigger> [, <Fichiers physiques HFSQL Client/Serveur>])
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème. La fonction [HErreur](3044088.md) permet d'identifier l'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion à manipuler. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Trigger>` *Chaîne de caractères*
> Nom du trigger à détruire. Ce nom a été donné grâce à la fonction [HDécritTriggerServeur](1000017033.md).
`<Fichiers physiques HFSQL Client/Serveur>` *Chaîne de caractères optionnelle*
> Nom physique de un ou plusieurs fichiers de données HFSQL Client/Serveur associés à la connexion (par exemple "CLIENT.FIC").
> Pour indiquer plusieurs noms, séparez les noms de fichiers de données par une virgule (",").
> Si ce paramètre n'est pas précisé ou est égal à une chaîne vide (""), le trigger sera activé sur tous les fichiers de données de la base de données.
