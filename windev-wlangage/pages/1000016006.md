# NetAdresseMAC (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android) · **Autres** (Procédures stockées)

Renvoie l'adresse MAC (adresse physique) de l'une des cartes réseau de la machine.
> _(Android, Widget Android)_ Attention : Cette information est disponible jusqu'à Android 10. A partir d'Android 11, cette information n'est plus accessible : Cette fonction renvoie une chaîne vide. Une solution couramment utilisée pour identifier un appareil, est de créer un fichier contenant un GUID qui sera mémorisé par exemple dans un fichier de votre base de données.

## Exemple

```wlangage
// Renvoie l'adresse MAC du poste
Info(NetAdresseMAC())
```

## Syntaxe

```wlangage
<Résultat> = NetAdresseMAC([<Rang carte réseau>])
```

`<Résultat>` *Chaîne de caractères*
> - Adresse MAC obtenue (au format "aa:bb:cc:dd:ee:ff"),
> - Chaîne vide ("") en cas de problème.
`<Rang carte réseau>` *Entier optionnel*
> Permet de préciser le numéro de la carte réseau pour laquelle l'adresse MAC doit être récupérée (pour les machines disposant de plusieurs cartes réseau). La première carte est au rang 0.
> Si ce paramètre est négatif, l'adresse obtenue sera celle de la première carte réseau.

**Composante : wd300com.dll**
