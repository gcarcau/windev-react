# <Tableur>.TypeEtMasqueSélection (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Renvoie ou modifie le type et le masque des cellules sélectionnées dans un champ Tableur présent dans une fenêtre.
**Remarque** : Cette fonction permet par exemple de réaliser une barre de mise en forme pour un champ Tableur.

## Exemple

```wlangage
// CLIC sur [NOMBRE] - Changement du masque
TBLR_Tableur.TypeEtMasqueSélection(typSaisieNum, "999 999 999,99")

// CLIC sur [DATE Longue].
// Changement du masque : par exemple 19 -> "Dimanche 19 Janvier 1900"
TBLR_Tableur.TypeEtMasqueSélection(typSaisieDate, "JJJ J MMMM AAAA")
```

```wlangage
// Renvoie le masque de la sélection
sRes est une chaîne
nType est un entier
sMasque est une chaîne
sRes = TBLR_Tableur.TypeEtMasqueSélection()
nType = Val(ExtraitChaîne(sRes, 1, TAB))
sMasque = Val(ExtraitChaîne(sRes, 2, TAB))
```

## Syntaxe

#### Connaître le type et le masque des cellules sélectionnées

```wlangage
<Résultat> = <Champ Tableur>.TypeEtMasqueSélection()
```

`<Résultat>` *Chaîne de caractères*
> Masque des cellules sélectionnées. Ce masque est de la forme :
>
>
> ```wlangage
> <Type> + TAB + <Masque>
> ```
>
>
> où :
>
> - &ltType> correspond à une des constantes suivantes :
>   | *typSaisieDate* | Type date |
>   | --- | --- |
>   | *typSaisieDurée* | Type durée |
>   | *typSaisieHeure* | Type heure |
>   | *typSaisieMonétaire* | Type monétaire |
>   | *typSaisieNum* | Type numérique (entier, réel, ...) |
>   | *typSaisieTexte* | Type texte |
> - <Masque> correspond au masque utilisé.
`<Champ Tableur>` *Nom de champ*
> Nom du champ Tableur à manipuler.

#### Modifier le type et le masque des cellules sélectionnées

```wlangage
<Champ Tableur>.TypeEtMasqueSélection(<Type> , <Masque>)
```

`<Champ Tableur>` *Nom de champ*
> Nom du champ Tableur à manipuler.
`<Type>` *Constante de type Entier*
> Nouveau type de la cellule sélectionnée :
>
> | *typSaisieDate* | Type date |
> | --- | --- |
> | *typSaisieDurée* | Type durée |
> | *typSaisieHeure* | Type heure |
> | *typSaisieMonétaire* | Type monétaire |
> | *typSaisieNum* | Type numérique (entier, réel, ...) |
> | *typSaisieTexte* | Type texte |
`<Masque>` *Chaîne de caractères*
> Nouveau masque à utiliser (le masque dépend du type choisi).

## Remarques

### Masques disponibles
Les masques disponibles dépendent du type de masque. Tous les masques utilisables avec la propriété [MasqueSaisie](2510033.md) sont disponibles. Pour plus de détails, consultez l'aide de la propriété [MasqueSaisie](2510033.md).
Quelques exemples :

- sur une date : il est possible d'utiliser le masque "JJ/MM/AAAA".
- sur un numérique : il est possible d'utiliser le masque "999 999".

Remarques :

- Le couple (typSaisieTexte, "") signifie "aucun masque".
- Le masque défini par la fonction **<Tableur>.TypeEtMasqueSélection** peut être modifié par la propriété [MasqueSaisie](2510033.md).
  Attention : seul le masque peut être modifié, le type de la cellule n'est pas modifié.

### Définir un masque sur une colonne
Pour définir un masque sur une colonne, il suffit de sélectionner la colonne et d'appliquer le masque voulu. Exemple :

```wlangage
TBLR_SansNom1.SelectPlus("A")
TBLR_SansNom1.TypeEtMasqueSélection(typSaisieDate, "JJ-MM-AA")
```

### Divers

- L'opération de modification est ajoutée dans la liste des opérations à annuler : l'utilisateur peut annuler cette opération via le menu contextuel ou via la combinaison de touches Ctrl + Z.
- Cette fonction est utilisable uniquement sur un champ Tableur présent dans une fenêtre.
