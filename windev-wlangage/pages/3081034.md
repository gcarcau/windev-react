# XMLTermine (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Ferme un document XML créé avec la fonction [XMLDocument](3081008.md). Toutes les ressources allouées lors de la création et de la manipulation du document XML sont libérées.

## Exemple

```wlangage
XMLDocument("DocXML", CodeXML)
// Traitement et analyse du document XML
// ...

XMLTermine("DocXML")
```

## Syntaxe

```wlangage
<Résultat> = XMLTermine(<Document XML>)
```

`<Résultat>` *Booléen*
> - Vrai si le document existe et est fermé,
> - Faux dans le cas contraire.
`<Document XML>` *Chaîne de caractères*
> Nom du document XML manipulé. Ce document contient le code XML et a été créé avec la fonction [XMLDocument](3081008.md).

**Composante : wd300xml.dll**
