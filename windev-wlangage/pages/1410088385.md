# mdpsCorrespondÀLaDescription (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **mdpsCorrespondÀLaDescription** permet de savoir si les paramètres de la rubrique de type "Mot de passe" présents dans le fichier de données (algorithme de dérivation de clé, algorithme de hash, nombre d'itérations et taille du résultat) sont identiques à ceux décrits (dans l'analyse ou par programmation).
Il est possible que ces paramètres soient différents s'ils ont été changés dans la description du fichier de données. La modification automatique des données ne recalcule pas les mots de passe (ce recalcul nécessitant le mot de passe de l'utilisateur). Il peut ainsi avoir un décalage entre les paramètres réels du mot de passe et les paramètres souhaités dans la description du fichier de données.

## Exemple

```wlangage
// Vérification des paramètres de la rubrique RubMotPasse dans le fichier de données Identification
SI Identification.RubMotPasse.mdpsCorrespondÀLaDescription = Faux ALORS
	Info("Votre mot de passe doit être modifié.")
FIN
```

## Syntaxe

```wlangage
<Paramètres identiques> = <Fichier de données>.<Rubrique>.mdpsCorrespondÀLaDescription
```

`<Paramètres identiques>` *Booléen*
> - Vrai si les paramètres du mot de passe sécurisé décrits sont identiques à ceux présent dans le fichier de données,
> - Faux dans le cas contraire.
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données manipulé. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Fichier](1514065.md).
`<Rubrique>` *Chaîne de caractères*
> Nom de la rubrique manipulée. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Rubrique](1514071.md).
