# DonneIdentifiant (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Calcule un identifiant unique de type entier pour un exécutable ou une session donné. Ces données ne sont pas mémorisées : elles sont perdues dès la fin de l'exécution de l'application ou de la session.

## Exemple

> _(WINDEV, Etats et Requêtes, Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst, Java, Code Utilisateur (MCU))_ // Ouvrir une fenêtre avec alias
OuvreFille("Alias" + DonneIdentifiant() + " = Fiche")

> _(WEBDEV - Code Serveur, PHP, Ajax)_ // Ouvrir une page avec alias
GUID est une entier = ConnexionOccurrence() + ...
 DonneIdentifiant() + Maintenant()

## Syntaxe

```wlangage
<Résultat> = DonneIdentifiant()
```

`<Résultat>` *Entier*
> Identifiant généré. Le premier appel à la fonction **DonneIdentifiant** renvoie 1, le second 2, ...

## Remarques

### Limites

- L'identifiant généré est un entier, il est donc limité à 231. En cas de dépassement, l'identifiant devient négatif.
- La fonction **DonneIdentifiant** peut être utilisée dans une tâche parallèle.

### Calcul d'un identifiant
Il est également possible d'obtenir un identifiant global (GUID) grâce à la fonction [DonneGUID](1000018857.md).

**Classification Métier / UI : Code neutre**

**Composante : wd300obj.dll**
