# gglAdressePostale (Type de variable)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Le type **gglAdressePostale** permet de décrire et de modifier une adresse postale d'un contact.
Ce type de variable est utilisé par le type [gglContact](1000017434.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Connexion
Cnx est une gglConnexion
Cnx.Email = "balthazar@gmail.com"
Cnx.MotDePasse = "azerty"
Cnx.NomApplication = "MonAppli-01"
SI GglConnecte(Cnx) = Faux ALORS
	Erreur(ErreurInfo())
FIN
...
// Récupération du tableau des contacts
tabContacts est un tableau de gglContact
tabContacts = GglListeContact(Cnx)
// Affichage des adresses du premier contact
UnContact est un gglContact = tabContacts[1]
UneAdresse est une gglAdressePostale dynamique
POUR TOUT UneAdresse DE UnContact.Adresse
	Trace(UneAdresse.Libellé + " : " + UneAdresse.Valeur)
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type gglAdressePostale
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **gglAdressePostale** :

| Nom | Type manipulé | Effet |
| --- | --- | --- |
| Adresse | Chaîne de caractères | Adresse postale du contact. |
| Libellé | Chaîne de caractères | Libellé de description de l'adresse. |
| Principal | Booléen | - Vrai si l'adresse correspond à l'adresse principale du contact, - Faux dans le cas contraire. |
| Type | Constante de type entier | Type de l'adresse correspondant à une des variables suivantes :  - *gglAutre* : Autre type d'adresse. - *gglBureau* : Adresse professionnelle. - *gglDomicile* : Adresse du domicile. |
