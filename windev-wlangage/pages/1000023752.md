# <Image>.Précédent (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

Affiche l'image précédente du défilement.

## Exemple

```wlangage
// Retourne à la bannière précédente
IMG_Bannière.Précédent()
```

## Syntaxe

```wlangage
<Champ Image>.Précédent()
```

`<Champ Image>` *Nom de champ*
> Nom du champ à manipuler :
>
> - Champ Image.
> - Champ Image cliquable.
> - Champ Vignette.

## Remarques

### Gestion des effets de transition
Si des effets de transition ont été spécifiés lors de la description du champ :

- Ces effets de transition sont pris en compte lors de l'utilisation de la fonction **<Image>.Précédent**.
- Ces effets de transition ne sont pas pris en compte lors de l'utilisation de la fonction **<Image>.Précédent**. En effet, la page est totalement rafraîchie. Pour prendre en compte ces effets, il suffit d'utiliser un code en mode Ajax.

**Composante : wd300page.dll**
