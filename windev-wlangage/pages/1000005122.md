# NotesListeFichierAttaché (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Renvoie la liste des fichiers attachés à un champ du document en cours dans Lotus Notes.

## Exemple

```wlangage
// Ouverture de la connexion
IDConnexion est un entier
IDConnexion = NotesOuvreConnexion("MotDePasse", "ServeurMars", ...
		"C:\Users\Julie\AppData\Local\Lotus\Notes\Data\user.id")
// Spécification de la base Lotus Notes à utiliser
IDBase est un entier
IDBase = NotesOuvreBase(IDConnexion, "julie.nsf")
...
// Lecture du premier document
NotesDocumentPremier(IDBase)
...
// Liste des fichiers attachés au champ Lotus Notes "MonChampLotusNotes"
ListeFic est une chaîne
ListeFic = NotesListeFichierAttaché(IDConnexion, "MonChampLotusNotes")
...
// Pour chaque fichier attaché
UnFic est une chaîne
i est un entier = 1
POUR TOUTE CHAÎNE UnFic DE ListeFic SÉPARÉE PAR RC
	// Copie le fichier attaché dans le répertoire du projet
	NotesExtraitFichierAttaché(IDBase, "MonChampLotusNotes", i, fRepExe() + ["\"] + UnFic)
	i++
FIN
```

## Syntaxe

```wlangage
<Résultat> = NotesListeFichierAttaché(<Identifiant de la session> , <Champ Lotus Notes>)
```

`<Résultat>` *Chaîne de caractères*
> - Nom des fichiers attachés au champ spécifié dans le document Notes en cours, séparé par des RC (Retour Chariot).
> - Chaîne vide ("") si aucun fichier n'est attaché au champ Lotus Notes spécifié ou en cas d'erreur.
>
>
> En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Identifiant de la session>` *Entier*
> Identifiant de la session à utiliser. Cet identifiant est renvoyé par la fonction [EmailOuvreSessionNotes](3032121.md) ou [NotesOuvreBase](1000005101.md).
`<Champ Lotus Notes>` *Chaîne de caractères*
> Nom du champ Lotus Notes de type "Texte Riche" à utiliser. Le plus souvent ce champ correspond au champ "BODY".
> Pour connaître le nom et le type des champs du document Notes en cours, utilisez la fonction [NotesListeChamp](1000005112.md).

## Remarques

### Champ d'un document Notes
Chaque champ d'un document Notes peut avoir jusqu'à 256 fichiers attachés.

**Composante : wd300mess.dll**
