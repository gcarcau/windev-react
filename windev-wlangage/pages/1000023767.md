# <Arbre>.Select (Fonction)

> **Disponible :** **WINDEV** (Windows, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur)

Renvoie le chemin complet de l'élément sélectionné dans un champ Arbre.
Exemple de champ Arbre :
[image: Vocabulaire lié à un champ Arbre]
> _(WINDEV)_ Remarque : La fonction <Arbre>.Select peut être utilisée indifféremment sur :un champ Arbre fichier, Arbre par programmation ou Arbre sur variable. un champ Arbre monosélection ou multisélection. Dans le cas des champs Arbre multisélection, il est nécessaire d'utiliser la fonction <Arbre>.Select dans une boucle pour connaître toutes les lignes sélectionnées.

## Exemple

```wlangage
// Chemin complet de l'élément sélectionné dans le champ Arbre "ARBRE_RecetteTV"
ResChemin = ARBRE_RecetteTV.Select()
```

> _(WINDEV)_ // Lignes sélectionnées dans un champ Arbre par programmation multisélection
POUR i = 1 _À_ ARBRE_ARBRE1.SelectOccurrence()
 Trace("Elément sélectionné : " + ARBRE_ARBRE1.Select(Faux, i))
FIN
// Équivalent à :
// i est un entier
// POUR TOUTE LIGNE SELECTIONNEE i DE ARBRE_ARBRE1
// Trace("Elément sélectionné : " + ARBRE_ARBRE1.Select(Faux, i-1))
// FIN

## Syntaxe

```wlangage
<Résultat> = <Champ Arbre>.Select([<Gestion des doublons> [, <Rang>]])
```

`<Résultat>` *Chaîne de caractères*
> Chemin complet de l'élément sélectionné, de la forme :
>
>
> ```wlangage
> "<Nom de la racine>" + TAB + ["<Nom du 1er noeud>" + TAB + ...["<Nom du 2ème noeud>" + TAB + [...]]]"<Nom de la feuille>"
> ```
`<Champ Arbre>` *Nom de champ*
> Nom du champ Arbre à manipuler.
`<Gestion des doublons>` *Booléen optionnel*
> Mode de gestion des doublons dans les éléments :
>
> - Faux (par défaut) : aucune gestion n'est effectuée.
> - Vrai : les noms des éléments du chemin sont construits de manière à contenir leur identifiant. Pour plus de détails, consultez [Gestion des doublons dans les champs Arbre](1013325.md).
>
>
> > _(WEBDEV - Code Navigateur)_ Ce paramètre n'est pas supporté.
>
> > _(Java)_ Ce paramètre est ignoré.
`<Rang>` *Entier optionnel*
> Rang de la sélection dans le cas d'un champ Arbre multisélection. Si ce paramètre n'est pas spécifié, l'indice de la première ligne sélectionnée est renvoyé.
> Par exemple, pour récupérer le premier élément sélectionné, <Rang> = 1.
> Pour récupérer le deuxième élément sélectionné, <Rang> = 2, etc.
>
> > _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur, Ajax)_ Ce paramètre n'est pas supporté.
>
>
> > _(Java)_ Ce paramètre n'est pas supporté.
