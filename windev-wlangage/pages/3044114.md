# HTrieVue (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Trie une vue HFSQL en créant un index sur une rubrique de la vue.

## Exemple

```wlangage
HTrieVue(VueClient84, "Ville,Nom")
```

## Syntaxe

```wlangage
<Résultat> = HTrieVue([<Vue> [, <Rubrique de tri>]])
```

`<Résultat>` *Booléen*
> - Vrai si la vue a été triée,
> - Faux dans le cas contraire. La fonction [HErreur](3044088.md) permet d'obtenir plus d'informations sur le problème rencontré.
`<Vue>` *Chaîne de caractères optionnelle*
> Nom de la vue manipulée. Si ce nom n'est pas spécifié, la fonction **HTrieVue** va manipuler la dernière vue utilisée par la dernière fonction de gestion HFSQL (fonction commençant par la lettre H).
`<Rubrique de tri>` *Chaîne de caractères optionnelle*
> Liste des rubriques de tri de la vue. Les rubriques sont séparées par une virgule ou *RC*. Le sens du tri peut être précisé pour chaque rubrique en la préfixant par "+" (croissant) ou "-" (décroissant). Par défaut, le tri est croissant ("+"). Si ce paramètre n'est pas spécifié, **HTrieVue** se réfère à la dernière rubrique de la vue utilisée.
> Les formats possibles de cette liste sont :
>
> - "[+/-]<1ère rubrique> [, [+/-]<2ème rubrique> ]"
> - "[+/-]<1ère rubrique> [*RC* [+/-]<2ème rubrique> ]"
>
>
> Le tri est appliqué d'abord selon la première rubrique de tri, puis selon la seconde, ... L'ordre de tri appliqué est le suivant : dans un tri croissant, "a" < "u" < "é".
>
> > _(Hyper File 5.5)_ Une seule rubrique de tri doit être spécifiée dans ce paramètre.

## Remarques

### Rubrique de tri
Un index peut être créé sur n'importe quelle rubrique de la vue. Si la rubrique était clé dans le fichier de données, la relation d'ordre qui lui a été donnée sous l'analyse est utilisée (sensibilité à la casse, à la ponctuation, etc.).

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax, HFSQL Classic, HFSQL Client/Serveur)_ Trier une vue sur plusieurs rubriquesPour trier une vue sur plusieurs rubriques, il est possible d'afficher les enregistrements de la vue dans un champ Table mémoire et d'utiliser la fonction TableTrie.Attention : Cette solution est utilisable uniquement pour les fichiers de données au format HFSQL Classic ou Client/Serveur.
