# <Variable Document>.Undo (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Annule la dernière modification effectuée sur une variable de type [Document](1000022461.md).

## Exemple

```wlangage
MonDocument est un Document

// Annule la dernière action effectuée sur le document
MonDocument.Undo()
```

## Syntaxe

```wlangage
<Résultat> = <Document>.Undo()
```

`<Résultat>` *Booléen*
> - Vrai si la dernière modification a été annulée,
> - Faux dans le cas contraire.
`<Document>` *Variable de type Document*
> Nom de la variable de type [Document](1000022461.md) à manipuler.

**Composante : wd300mdl.dll**
