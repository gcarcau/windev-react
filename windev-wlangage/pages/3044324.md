# HInfoPropriétéFichier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Permet de connaître les propriétés d'un fichier de données situé sur un serveur HFSQL.

## Exemple

```wlangage
// Description de la connexion
HDécritConnexion("MaConnexion", "Julie", "MotDePasse", "MonServeurHF", "MaBaseDeDonnées", ...
	hAccèsHFClientServeur, hOLecture)
// Ouverture de la connexion
HOuvreConnexion("MaConnexion")
...
NomPropriétaire est une chaîne
NomPropriétaire = HInfoPropriétéFichier("MaConnexion", hPropriétaire, "MaBaseDeDonnées", "Client.fic")
SI NomPropriétaire <> "" ALORS
	Trace("Propriétaire de la base de donnée : " + NomPropriétaire)
FIN
```

## Syntaxe

```wlangage
<Résultat> = HInfoPropriétéFichier(<Connexion> , <Propriété> , <Base de données> , <Fichier de données>)
```

`<Résultat>` *Chaîne de caractères*
> - Valeur de la propriété demandée,
> - Chaîne vide ("") en cas d'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion pour laquelle la valeur d'une propriété est recherchée. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Propriété>` *Constante de type Entier*
> Propriété du fichier recherchée :
>
> | *hApplication* | Nom de l'application à partir de laquelle le fichier de données a été créé.  Si cette constante est utilisée, <Résultat est une chaîne de caractères de la forme :  <Nom de l'exécutable>(<Nom du projet>). |
> | --- | --- |
> | *hCréateur* | Nom du propriétaire du fichier de données. Si cette constant est utilisée, <Résultat est une chaîne de caractères. |
> | *hDate* | Date de la création du fichier de données.  Si cette constante est utilisée, <Résultat est une chaîne de caractères de la forme AAAAMMJJHHmmSSCCC. |
> | *hMachine* | Nom du poste à partir duquel a été créé le fichier de données.  Si cette constante est utilisée, <Résultat est de la forme :  <Nom du poste client + TAB + <Adresse IP du poste Client>. |
> | *hNotes* | Description du fichier de données ou toute autre information associée au fichier de données grâce à la fonction [HModifiePropriétéFichier](3044330.md).  Si cette constante est utilisée, <Résultat est une chaîne de caractères. |
> | *hPropriétaire* | Propriétaire du fichier de données.  Si cette constante est utilisée, <Résultat est une chaîne de caractères. |
`<Base de données>` *Chaîne de caractères*
> Nom de la base de données contenant le fichier pour lequel les propriétés sont recherchées.
> Si ce paramètre correspond à une chaîne vide (""), la base de données utilisée sera celle définie dans la connexion.
> Si aucune base de données n'est définie dans la connexion, une erreur WLangage sera générée.
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données HFSQL pour lequel les propriétés sont recherchées. L'extension du fichier doit être précisée.

## Remarques

- Pour modifier les propriétés d'un fichier de données, utilisez la fonction [HModifiePropriétéFichier](3044330.md).
- Attention : le fichier de données manipulé doit avoir été créé sur le serveur (fonctions [HCréation](3044255.md) ou [HCréationSiInexistant](3044254.md)).
