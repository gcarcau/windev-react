# EtatAlimentation (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Permet de connaître diverses informations sur la batterie (principale ou de secours) de l'appareil sur lequel l'application est exécutée.

## Exemple

```wlangage
// Etat de la batterie principale ?
Info("La batterie est chargée à : " + EtatAlimentation(PourcentageCharge) + " %")
```

## Syntaxe

```wlangage
<Résultat> = EtatAlimentation(<Type d'information> [, <Batterie>])
```

`<Résultat>` *Entier ou booléen selon le type d'information demandé*
> - Information demandée,
> - Chaîne vide ("") si l'information demandée n'est pas disponible.
`<Type d'information>` *Constante de type entier*
> Indique le type d'information à rechercher :
>
>
> | *EnRecharge* | - Vrai si la batterie est en charge, - Faux dans le cas contraire. |
> | --- | --- |
> | *NiveauCharge* | Niveau de charge de la batterie :  - 0 : batterie inexistante. - 1 : niveau haut. - 2 : niveau bas. - 3 : niveau critique. |
> | *PourcentageCharge* | Pourcentage de charge de la batterie. |
> | *SurSecteur* | - Vrai si l'appareil est branché sur le secteur, - Faux dans le cas contraire. |
> | *VieRestante* | Durée de vie restante (en secondes) de la batterie. _(Android, Widget Android, iPhone/iPad)_ Cette constante n'est pas disponible. |
> | *VieTotale* | Durée de vie totale (en secondes) de la batterie. _(Android, Widget Android, iPhone/iPad)_ Cette constante n'est pas disponible. |
`<Batterie>` *Booléen optionnel*
> - Vrai (par défaut) pour obtenir des informations sur la batterie principale de l'appareil,
> - Faux pour obtenir des informations sur la batterie de secours de l'appareil.
>
>
> > _(Android, Widget Android)_ Il n'est pas possible de récupérer des informations sur la batterie de secours. Si le paramètre <Batterie> est à Faux, <Résultat> correspondra à une chaîne vide ("").

## Remarques

### Batterie

- Il n'est pas possible de récupérer des informations sur la batterie de secours.
- En mode émulateur, les informations retournées ne sont pas valides.

### Gestion des erreurs
**Attention** : La fonction **EtatAlimentation** ne retourne pas de code d'erreur. Pour savoir si cette fonction a généré une erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
