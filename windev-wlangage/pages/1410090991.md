# Fonctions Palette

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions de gestion de palettes de couleurs sont les suivantes :

| Nouveauté 2025 [PaletteChange](1410090897.md) | Modifie la palette utilisée par le projet ou par une fenêtre. |
| --- | --- |
| Nouveauté 2025 [PaletteCharge](1410090780.md) | Charge une palette à partir d'un fichier de type ".wdpalette". |
| Nouveauté 2025 [PaletteGénère](1410090825.md) | Génère une palette à partir d'une couleur de base. |
| Nouveauté 2025 [PaletteRécupère](1410090898.md) | Récupère la palette courante du projet ou la palette de la fenêtre. |
| Nouveauté 2025 [PaletteSauve](1410090779.md) | Sauve une palette dans un fichier. |
