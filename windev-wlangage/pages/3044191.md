# HDécritLiaison (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Décrit par programmation une liaison entre deux fichiers de données.
Après l'appel à la fonction **HDécritLiaison** :

- La description de la liaison est validée.
- La description de la liaison ne peut plus être modifiée.
- La variable de description de la liaison est réinitialisée. Une nouvelle description de liaison peut être effectuée.

**Remarque** : Pour ajouter une liaison dans une base de données HFSQL Client/Serveur, utilisez la fonction [HAjouteLiaison](3044312.md).

## Exemple

```wlangage
HDécritLiaison(LiaisonClientProduit)
```

## Syntaxe

```wlangage
<Résultat> = HDécritLiaison(<Liaison>)
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été réalisée,
> - Faux en cas de problème. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Liaison>` *Variable de type Description de Liaison*
> Nom de la variable de type [Description de Liaison](1514039.md) correspondant à la liaison à créer.

## Remarques

### Comment décrire une liaison par programmation ?
Pour décrire une liaison par programmation, il faut :

1. Utiliser des variables de type [Description de Liaison](1514039.md).
2. Décrire les caractéristiques de la liaison grâce aux propriétés HFSQL.
3. Utiliser la fonction **HDécritLiaison** pour enregistrer la description de la liaison.

**Remarque** : Pour décrire un fichier de données par programmation, utilisez la fonction [HDécritFichier](3044206.md). Pour décrire des rubriques par programmation, utilisez la fonction [HDécritRubrique](3044233.md).

| --- | --- |

| [CardinalitéSourceMax](2512005.md) | La propriété **CardinalitéSourceMax** permet de connaître et modifier la cardinalité maximale de la rubrique source dans la liaison. |
| [CardinalitéSourceMin](2512006.md) | La propriété **CardinalitéSourceMin** permet de connaître et modifier la cardinalité minimale de la rubrique source dans la liaison. |
| [CléReliée](2512007.md) | La propriété **CléReliée** permet de paramétrer les caractéristiques d'une liaison. |
| [CléSource](2512003.md) | La propriété **CléSource** permet de paramétrer les caractéristiques d'une liaison. |
| [FichierRelié](2512031.md) | La propriété **FichierRelié** permet de paramétrer les caractéristiques d'une liaison. |
| [FichierSource](2512034.md) | La propriété **FichierSource** permet de paramétrer les caractéristiques d'une liaison. |
| [Nom](2510082.md) | La propriété **Nom** permet de connaître :  - le nom de la police associée à une variable de type Police. - le nom d'un champ, d'un état ou d'un bloc d'un état. - le nom d'un champ, d'un groupe de champs ou d'une fenêtre. - le nom d'un champ, d'un groupe de champs ou d'une page. |
| [RègleModification](2512051.md) | La propriété **RègleModification** permet de paramétrer la règle de modification (gestion de l'intégrité) des enregistrements à appliquer au fichier de données décrit par programmation. |
| [RègleSuppression](2512083.md) | La propriété **RègleSuppression** permet de paramétrer la règle de suppression (gestion de l'intégrité) des enregistrements à appliquer au fichier de données décrit par programmation. |
