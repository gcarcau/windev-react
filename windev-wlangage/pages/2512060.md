# TypeClé (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **TypeClé** permet de paramétrer les caractéristiques d'une rubrique clé. Il est ainsi possible de :

- Savoir si une rubrique est clé pour une rubrique définie sous l'éditeur d'analyses ou définie par programmation.
- Définir une rubrique clé (lors de la description de la rubrique par programmation uniquement).

## Exemple

```wlangage
// Définir les caractéristiques la rubrique clé Commande.IdCde
Commande.IDCde.TypeClé = hCléUnique
...
// Valide la description du fichier de données
HDécritFichier(Commande)
```

## Syntaxe

#### Savoir si une rubrique est clé

```wlangage
<Caractéristique> = <Fichier de données>.<Rubrique>.TypeClé
```

`<Caractéristique>` *Constante de type entier*
> Les caractéristiques d'une rubrique sont :
>
>
> | *hCléDoublon* | Clé avec doublon. Cette rubrique pourra avoir la même valeur pour plusieurs enregistrements du fichier de données. |
> | --- | --- |
> | *hCléPrimaire* | Clé primaire. La valeur affectée à cette rubrique sera unique dans le fichier de données et non nulle. |
> | *hCléSpatiale* | Clé spatiale. Cette rubrique clé contient des données spatiales (données géographiques et / ou géométriques). |
> | *hCléUnique* | Clé unique. La valeur affectée pour cette rubrique sera unique dans le fichier de données. Aucun enregistrement du fichier n'aura la même valeur pour cette rubrique. Remarque : une clé unique peut autoriser une valeur nulle. |
> | *hNonClé* | La rubrique n'est pas une clé. |
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données manipulé. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Fichier](1514065.md).
`<Rubrique>` *Chaîne de caractères*
> Nom de la rubrique manipulée. Ce nom a été défini sous l'éditeur d'analyses ou grâce au type [Description de Rubrique](1514071.md).

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS, Code Utilisateur (MCU), Ajax)_ Définir une clé par programmation Masquer les détails
<Rubrique>.TypeClé = <Type de la clé>
