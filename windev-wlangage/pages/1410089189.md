# MongoExécuteLotOpérations (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

Effectue un ensemble d'opérations d'écriture MongoDB en lot. Il est ainsi possible d'éviter des latences réseau qui pourraient subvenir en effectuant les opérations séquentiellement.

## Exemple

```wlangage
gclCollection est un mongoCollection
tabOp est un tableau de mongoOpération
opAjout1 est une mongoOpérationAjout
opAjout1.Document = doc1
tabOp.Ajoute(opAjout1)
opAjout2 est une mongoOpérationAjout
opAjout2.Document = doc2
tabOp.Ajoute(opAjout2)
opModifie est une mongoOpérationModificationTout
opModifie.Filtre = "{ ""Nom"": ""SMITH"" }"
opModifie.Modification = "{ ""$set"": { ""Nom"": ""PAULSON"" } }"
tabOp.Ajoute(opModifie)
opSupprime est une mongoOpérationSuppressionTout
opSupprime.Filtre = "{ ""Prenom"": ""Robert"" }"
MongoExécuteLotOpérations(gclCollection, tabOp)
```

## Syntaxe

```wlangage
<Résultat> = MongoExécuteLotOpérations(<Collection> , <Opérations> [, <Option d'exécution> [, <Niveau d'accusé de réception>]])
```

`<Résultat>` *Variant ou JSON*
> Informations sur les opérations réalisées.
`<Collection>` *Variable de type mongoCollection*
> Nom de la variable de type [mongoCollection](1000022411.md) représentant la collection dans laquelle les opérations doivent être effectuées.
`<Opérations>` *Tableau de variables de type mongoOpération*
> Tableau de variables de type [mongoOpération](1410089157.md). Ce tableau contient les variables correspondant aux opérations à effectuer par lot :
>
> - [mongoOpérationAjout](1410089163.md),
> - [mongoOpérationSuppressionUn](1410089161.md),
> - [mongoOpérationSuppressionTout](1410089162.md),
> - [mongoOpérationModificationUn](1410089164.md),
> - [mongoOpérationModificationTout](1410089165.md),
> - [mongoOpérationRemplacementUn](1410089166.md).
>
> Ces opérations d'écriture seront appliquées en lot (bulk write).
`<Option d'exécution>` *Variable optionnelle de type mongoLotOperationsOption*
> Nom de la variable de type [mongoLotOperationsOption](1410089271.md) correspondant aux options à utiliser pour l'exécution des opérations par lot.
`<Niveau d'accusé de réception>` *Variable optionnelle de type mongoOptionEcriture*
> Nom de la variable de type [mongoOptionEcriture](1000022597.md) permettant de spécifier le niveau d'accusé de réception demandé pour l'exécution des opérations par lot.
