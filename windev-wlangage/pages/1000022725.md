# <Variable Connexion>.NotifAjouteDestinataireEmail (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Ajoute des destinataires pour les notifications envoyées par email. Ces notifications sont envoyées lorsque le serveur HFSQL rencontre un problème.
**Remarque** : L'envoi par email utilise les paramètres spécifiés avec la fonction [<Variable Connexion>.NotifConfigure](1000022726.md) (serveur d'emails, ...).

## Exemple

```wlangage
// Description de la connexion
cnxConnexionCS est une Connexion

cnxConnexionCS est une Connexion
cnxConnexionCS.Provider = hAccèsHFClientServeur
cnxConnexionCS.Utilisateur = "admin"
cnxConnexionCS.MotDePasse = ""
cnxConnexionCS.Serveur = "test:4900"
cnxConnexionCS.OuvreConnexion()

cnxConnexionCS.NotifConfigure(hNotifEmail, "FLEUR:25", "test.doc", "doc", "doc@pcsoft.com", Faux)
cnxConnexionCS.NotifAjouteDestinataireEmail("test.appli@gmail.com", hNotifAvertissement)
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.NotifAjouteDestinataireEmail(<Destinataire> , <Niveau minimum>)
```

`<Résultat>` *Booléen*
> - Vrai si l'ajout du destinataire a été effectué.
> - Faux dans le cas contraire. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion à manipuler.
`<Destinataire>` *Chaîne de caractères*
> Adresse email du destinataire.
`<Niveau minimum>` *Constante de type Entier*
> Niveau minimum de gravité du problème à partir duquel une notification est envoyée :
>
> | *hNotifAvertissement* | Les notifications seront envoyées dès le niveau avertissement (pour les problèmes de type avertissement, critique et erreur). Exemple d'avertissement : "Le serveur XX et le serveur YY n'ont pas la même heure. La résolution des conflits lors de la réplication peut être faussée." |
> | --- | --- |
> | *hNotifCritique* | Les notifications seront envoyées dès le niveau critique (pour les problèmes de type critique et erreur). Exemple d'erreur critique : "Erreur pendant la préparation du réplica sur le maître." |
> | *hNotifErreur* | Les notifications seront envoyées seulement pour les problèmes de type erreur. Exemple d'erreur : "Le fichier des statistiques d'activité du serveur est endommagé. Il va être réinitialisé." |
> | *hNotifInformation* | Les notifications seront envoyées dès le niveau information (pour les problèmes de type information, avertissement, critique et erreur). Exemples d'information :    - Lors de la mise à jour automatique du serveur :   - "Le serveur va être arrêté pour mise à jour. Une autre notification sera ajoutée après la mise à jour."  - "Le serveur a été mis a jour en version XXX." - Lors de la recherche de clés nécessaires sur une base en exploitation. |
>
>
> L'ordre de gravité des problèmes est :
>
> - Information.
> - Avertissement.
> - Erreur.
> - Critique.
