# <Graphe>.MAJAutomatiqueEtiquetteCatégorie (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Identifie ou définit si les étiquettes de catégorie sont mises à jour à chaque dessin du graphe. Dans ce cas, à chaque appel de la fonction [<Graphe>.Dessine](1000024062.md), le contenu de la série est automatiquement recalculé pour refléter les derniers changements de la source de données. Les étiquettes de catégories sont alors mises à jour si nécessaire.
**Exemple d'utilisation** : une série dans un graphe sert de série de référence : cette série n'est pas mise à jour automatiquement.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
// Champ Graphe
SI GRF_MonGraphe.MAJAutomatiqueEtiquetteCatégorie() = Vrai ALORS
	GRF_MonGraphe.Dessine()
FIN
```

## Syntaxe

#### Identifier le mode de mise à jour des étiquettes de catégorie

```wlangage
<Résultat> = <Champ Graphe>.MAJAutomatiqueEtiquetteCatégorie()
```

`<Résultat>` *Booléen*
> Mode de mise à jour actuel des étiquettes de catégories :
>
> - Vrai si les étiquettes sont mises à jour automatiquement,
> - Faux dans le cas contraire.
`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres, de pages ou d'états).
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.

#### Définir le mode de mise à jour des étiquettes de catégorie

```wlangage
<Champ Graphe>.MAJAutomatiqueEtiquetteCatégorie(<Mise à jour automatique>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres, de pages ou d'états).
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Mise à jour automatique>` *Booléen*
> - Vrai pour une mise à jour automatique,
> - Faux dans le cas contraire.

## Remarques

- Si les étiquettes de catégories sont en mode automatique, les étiquettes de catégories sont automatiquement recalculées lors du prochain appel à la fonction [<Graphe>.Dessine](1000024062.md).
- Si les étiquettes de catégories ne sont pas en mode automatique, les étiquettes de catégories seront recalculées uniquement lors du prochain appel de la fonction [<Graphe>.SourceEtiquetteCatégorie](1000024138.md).
