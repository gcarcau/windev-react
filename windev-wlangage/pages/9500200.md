# Le champ Multimédia

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

## Présentation

### Champ d'une fenêtre WINDEV et WINDEV Mobile
Le champ Multimédia permet de jouer des fichiers multimédia.
> _(WINDEV)_ Sur un PC, il est nécessaire d'avoir les éléments suivants installés : Windows Media Player, une version récente de DirectX ainsi que les codecs nécessaires à la lecture des fichiers vidéo. Si les codecs nécessaires ne sont pas installés, la lecture des vidéos ne pourra pas être effectuée.

> _(Android)_ Sous Android, le champ Multimédia doit être utilisé pour jouer des fichiers Vidéo. Pour jouer des fichiers audio, utilisez la fonction Son.

> _(WEBDEV - Code Serveur, WEBDEV - Code Navigateur)_ Dans un site, il est conseillé d'utiliser le format MP4 (supporté par tous les navigateurs à la norme HTML5). Les anciens formats demandent l'installation de plugins de moins en moins supportés par tous les navigateurs pour des raisons de sécurité. Pour plus de détails sur le champ Multimédia dans un site WEBDEV, consultez Le champ Multimédia (WEBDEV).

## Créer un champ Multimédia

> _(WINDEV, WINDEV Mobile, WINDEV, WINDEV Mobile)_ Pour créer un champ Multimédia dans une fenêtre : Sous le volet "Création", dans le groupe "Champs graphiques" : déroulez "Vidéo et capture" et sélectionnez "Multimédia". cliquez sur "Multimédia". Cliquez dans la fenêtre à la position où le champ doit être créé. Le champ apparaît en création.Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ.

> _(WEBDEV - Code Serveur)_ Pour créer un champ Multimédia dans une page: Sous le volet "Création", dans le groupe "Champs usuels", déroulez "Image" et sélectionnez "Champ multimédia".Cliquez dans la page à la position où le champ doit être créé. Le champ apparaît en création.Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ.Pour plus de détails sur le champ Multimédia dans un site WEBDEV, consultez Le champ Multimédia (WEBDEV).

## Manipuler un champ Multimédia

Un champ Multimédia peut être manipulé par programmation grâce :

- aux [fonctions Multimédia du WLangage](1000015005.md). Ces fonctions permettent par exemple d'associer un ficher multimédia au champ et de le jouer.
- aux [propriétés du WLangage](9500201.md). La propriété [Valeur](2510130.md) permet notamment d'associer un fichier multimédia au champ et de le jouer.

### Remarques

- Il n'est pas possible d'utiliser le champ Multimédia dans un champ Zone répétée.
- Il n'est pas possible de capturer l'image d'une vidéo jouée dans un champ Multimédia.
- Les propriétés [ScreenCastAutorisé](1000021992.md) et [ScreenCastEnCours](1000021993.md) permettent de gérer la possibilité d'afficher la vidéo sur un périphérique externe (compatible Air Play).
- Si le format de la vidéo n'est pas supporté par iOS, la vidéo n'est pas jouée (par exemple, vidéo au format AVI).
- La lecture automatique est disponible uniquement avec une vidéo sans piste son.
