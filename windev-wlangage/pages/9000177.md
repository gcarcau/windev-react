# Première fenêtre du projet

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

La première fenêtre du projet correspond à la première fenêtre ouverte lors du lancement de l'application WINDEV ou WINDEV Mobile.
Cette fenêtre est également ouverte en premier lors du test du projet sur le poste de développement.

## Comment définir la première fenêtre du projet ?

WINDEV propose plusieurs méthodes pour définir et choisir la première fenêtre d'un projet :

- Par le volet "Explorateur de projet".
- Dans la description de la configuration.
- Lors du premier test du projet.

**Remarque** : La première fenêtre du projet est également demandée lors du test du projet, si aucune fenêtre n'a été définie. Pour plus de détails, consultez [Tester un projet](2019003.md).

### Définir la première fenêtre du projet dans le volet "Explorateur de projet"
Pour définir la première fenêtre du projet :

1. Sélectionnez la fenêtre qui va être la première fenêtre dans le volet "Explorateur de projet".
2. Affichez le menu contextuel de la fenêtre (clic droit) et sélectionnez l'option "Première fenêtre du projet". [image: Option de menu ]
  L'icône [image: Icône première fenêtre] permet d'identifier la première fenêtre du projet dans le volet "Explorateur de projet".

> _(Android, iPhone/iPad)_ Si l'application est destinée à être utilisée sur téléphones et tablettes, il est possible de définir une première fenêtre pour chacune des utilisations : Sélectionnez la fenêtre qui va être la première fenêtre dans le volet "Explorateur de projet". Affichez le menu contextuel de la fenêtre (clic droit). Sélectionnez l'option : "Première fenêtre pour téléphones" pour définir la première fenêtre affichée lorsque l'application est exécutée sur un téléphone."Première fenêtre pour tablettes" pour définir la première fenêtre affichée lorsque l'application est exécutée sur une tablette.

**Remarque** : Si le projet comporte plusieurs configurations, il est possible de définir une première fenêtre par configuration. Il suffit de :

1. Sélectionner la configuration de projet voulue dans le volet "Explorateur de projet".
2. Définir la première fenêtre du projet via le menu contextuel du volet "Explorateur de projet".

### Définir la première fenêtre dans la description de la configuration
Pour définir la première fenêtre dans la description du projet :

1. Affichez la description du projet : sous le volet "Projet", dans le groupe "Projet", cliquez sur "Description".
2. Dans l'onglet "Général", cliquez sur "Description de la configuration courante".
3. La fenêtre de description de la configuration courante s'affiche.
4. Dans l'onglet "Général", la liste "Première fenêtre du projet" permet de sélectionner la première fenêtre du projet.

> _(Android, iPhone/iPad)_ Si l'application est destinée à être utilisée sur téléphones et tablettes, la première fenêtre du projet définie dans la description de la configuration sera utilisée comme première fenêtre sur téléphones et sur tablettes.

### Définir la première fenêtre lors du test du projet
Pour tester un projet depuis l'éditeur :

1. Sous le volet "Projet", dans le groupe "Mode test", déroulez "Mode test" et sélectionnez "Déboguer le projet" (Ctrl + F9). Il est également possible de cliquer sur  parmi les boutons d'accès rapide.
2. Si la première fenêtre du projet n'a pas été définie, une fenêtre s'affiche permettant de sélectionner la première fenêtre du projet.
   Si l'application est destinée à être utilisée sur téléphones et tablettes, deux fenêtres s'affichent :
  - une fenêtre permettant de définir la première fenêtre du projet sur les téléphones.
  - une fenêtre permettant de définir la première fenêtre du projet sur les tablettes.
3. L'éditeur est automatiquement réduit en icône et le projet s'exécute.
