# Description de Propriété (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Le type **Description de Propriété** permet d'obtenir des informations sur une propriété d'une classe.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Récupère la description de la classe type de la variable x
MaDescription est un Définition
MaDescription = RécupèreDéfinition(x)
// Récupère la description de la propriété Prop de la classe
p est une Description de Propriété
p = MaDescription.Propriété["Prop"]
```

## Propriétés

### Propriétés spécifiques à la description des variables de type Description de Propriété
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type Description de Propriété :

| **Nom de la propriété** | **Type manipulé** | **Effet** |
| --- | --- | --- |
| Associé | Booléen | - Vrai si la propriété provient d'une classe associée, - Faux si la propriété provient d'une classe de base.  **Cette propriété est disponible en lecture seulement**. |
| Déclaration | [Définition](1000019540.md) | Définition du type qui déclare la propriété.  **Cette propriété est disponible en lecture seulement**. |
| Définition | [Définition](1000019540.md) | Définition du type de la propriété.  **Cette propriété est disponible en lecture seulement**. |
| Ecriture | Booléen | - Vrai si la propriété est accessible en écriture, - Faux dans le cas contraire.   **Cette propriété est disponible en lecture seulement**. |
| Global | Booléen | - Vrai si la propriété est globale, - Faux dans le cas contraire.  **Cette propriété est disponible en lecture seulement**. |
| Hérité | Booléen | - Vrai si la propriété est héritée d'une classe de base, - Faux dans le cas contraire.  **Cette propriété est disponible en lecture seulement**. |
| Lecture | Booléen | - Vrai si la propriété est accessible en lecture, - Faux dans le cas contraire.  **Cette propriété est disponible en lecture seulement**. |
| Nom | Chaîne de caractères | Nom de la propriété.  Pour les types natifs du WLangage, le nom est renvoyé dans la langue du framework utilisé (français ou anglais).  **Cette propriété est disponible en lecture seulement**. |
| Virtuel | Booléen | - Vrai si la propriété est virtuelle, - Faux dans le cas contraire.  **Cette propriété est disponible en lecture seulement**. |

## Remarques

### Manipulation
La propriété décrite peut être manipulée grâce à l'indirection :

- {<objet>, <Description de Propriété>}
- {<objet>, <Description de Propriété>} = ...
