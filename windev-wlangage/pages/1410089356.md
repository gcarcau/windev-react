# Suisse.VérifieREE (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Teste la validité d'un numéro REE (numéro dans le registre des entreprises et des établissements identifiant un établissement d'une entreprise en Suisse).

## Exemple

```wlangage
// Test d'une variableMonNuméroREE est une chaîne = "73462600"Suisse.VérifieREE(MonNuméroREE)  // renvoie Vrai // Test d'un champSAI_NuméroREE = "ABC"Suisse.VérifieREE(SAI_NuméroREE) // renvoie Faux
```

## Syntaxe

```wlangage
<Résultat> = Suisse.VérifieREE(<Numéro à vérifier>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément spécifié contient un numéro REE valide.
> - Faux dans le cas contraire.
`<Numéro à vérifier>` *Nom de champ ou variable de type chaîne*
> Numéro REE à vérifier. Ce paramètre peut correspondre :
>
> - au nom d'une variable de type chaîne.
> - au nom d'un champ.

**Composante : wd300std.dll**
