# Planification (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

La propriété **Planification** permet de connaître et de modifier les options de planification. Cette propriété est utilisable sur :

- une variable de type [hOptimisationPlanifiée](1000018854.md).
- une variable de type [hRSConfig](1000020484.md).
- une variable de type [hPlanificationVueMatérialisée](1000021444.md).
