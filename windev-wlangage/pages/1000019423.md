# ThreadCourant (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Renvoie le nom du thread en cours d'exécution.

## Syntaxe

```wlangage
<Résultat> = ThreadCourant()
```

`<Résultat>` *Chaîne de caractères*
> - Nom du thread en cours d'exécution,
> - "" (chaîne vide) si le thread courant est le thread principal.

**Composante : wd300vm.dll**
