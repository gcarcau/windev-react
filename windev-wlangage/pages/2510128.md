# ValeurInitiale (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

La propriété **ValeurInitiale** permet de connaître la valeur initiale d'un champ d'une fenêtre ou d'une page. La valeur initiale correspond à la valeur initiale définie sous l'éditeur (onglet "Contenu" de la fenêtre de description du champ).

## Exemple

```wlangage
// Initialiser la valeur du champ "SAI_Client" avec sa valeur d'origine
SAI_Client = SAI_Client.ValeurInitiale
```

## Syntaxe

```wlangage
<Valeur initiale> = <Champ manipulé>.ValeurInitiale
```

`<Valeur initiale>` *Tout type*
> Valeur initiale du champ spécifié.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.

## Remarques

> _(WINDEV)_ Champ ActiveXPour un champ ActiveX, la valeur initiale correspond à l'identifiant COM (ProgId) de l'ActiveX sélectionné lors de la création de la fenêtre.

> _(WEBDEV - Code Serveur, Ajax)_ Champ iFramePour un champ iFrame, la propriété ValeurInitiale correspond :soit au nom de page affichée (nom sélectionné dans la fenêtre de description du champ iFrame). Par exemple : "MaPage1".soit à une URL complète si la page affichée correspond à une page d'un autre site Internet.

> _(WINDEV, WEBDEV - Code Serveur, iPhone/iPad, Widget IOS, Ajax)_ Champ GraphePour un champ Graphe, la valeur initiale correspond à l'image affichée dans le fond du champ, sélectionnée lors de la création de la fenêtre / page.

> _(WINDEV)_ Champ TiroirPour un champ Tiroir, la propriété ValeurInitiale correspond à l'état du champ (déroulé (1) ou enroulé (0)) sélectionné lors de la création du champ.

> _(WINDEV)_ Champ ComboPour un champ Combo, la propriété ValeurInitiale permet de relire la chaîne initiale affecté à l'élément.Par exemple, si le code suivant est utilisé pour ajouter un élément :

ListeAjoute(COMBO_Combo1, gImage(nNumImage,i) + "Client.NomClient" + i + ...
 gValeurMémorisée("Client.NomClient" + i))

le code suivant permet de relire la chaîne d'origine :

COMBO_Combo1[1].ValeurInitiale

Remarque : Le résultat de la propriété ValeurAffichée ne permet pas de récupérer les informations sur le contenu ajouté avec la fonction gValeurMémorisée.

### Limites

> _(WINDEV)_ Dans une fenêtre, la propriété ValeurInitiale ne peut pas être utilisée sur :une fenêtre,un champ Libellé,un champ Bouton,un champ Forme,une option de sélecteur ou d'interrupteur,une ligne de liste (y compris Liste image) ou de table,une cellule ou une colonne de table,un menu,un volet d'onglet,un groupe de champs,un élément d'un champ Arbre.

> _(WEBDEV - Code Serveur)_ Dans une page, la propriété ValeurInitiale peut être utilisée uniquement sur :un champ de saisie,un champ d'affichage formaté,un champ Combo,un champ Liste,un champ Libellé,un champ Table, un champ Zone de texte riche,une cellule de mise en page (si la cellule est en mode flux).

> _(Java)_ La propriété ValeurInitiale s'applique uniquement aux éléments suivants :Champ de saisie.Champ Image.Champ Interrupteur.Champ Sélecteur.Champ Liste.Champ Combo.Champ Table.Superchamp.

> _(Widget Android)_ La propriété ValeurInitiale s'applique uniquement aux champs Image.
