# CDEjecte (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Ouvre ou ferme le tiroir du lecteur de CD/DVD sélectionné sur le poste en cours.
**Remarque** : Pour connaître l'ensemble des lecteurs CD/DVD disponibles à partir du poste en cours, utilisez la fonction [CDListe](1000004102.md).

## Exemple

```wlangage
// Ouvre le tiroir du lecteur E:
ResOuverture est un booléen
ResOuverture = CDEjecte("E:")
// Erreur rencontrée ?
SI ResOuverture = Faux ALORS
	// Affichage de l'erreur
	Erreur(ErreurInfo(errMessage))
SINON
	Info("Veuillez insérer le CD dans le lecteur")
FIN
```

## Syntaxe

```wlangage
<Résultat> = CDEjecte(<Lecteur> [, <Ouverture>])
```

`<Résultat>` *Booléen*
> - Vrai si l'opération demandée a été effectuée,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Lecteur>` *Chaîne de caractères*
> Lecteur pour lequel le tiroir doit s'ouvrir ou se fermer.
`<Ouverture>` *Booléen optionnel*
> - Vrai (par défaut) si le tiroir du lecteur doit s'ouvrir,
> - Faux si le tiroir du lecteur doit se fermer.

## Remarques

### Ouverture et fermeture du tiroir du lecteur

- Si le tiroir du lecteur est déjà ouvert, **CDEjecte**(<Lecteur>,Vrai) sera sans effet. Inversement, si le tiroir du lecteur est fermé, **CDEjecte**(<Lecteur>, Faux) sera également sans effet.
- Certains lecteurs ignorent la demande de fermeture du tiroir. Dans ce cas, la fonction **CDEjecte** renvoie Vrai bien que le tiroir du lecteur reste ouvert.

### Utilisation des fonctions de gestion des lecteurs CD/DVD

> _(WINDEV, WEBDEV - Code Serveur)_ Les fonctions CD sont disponibles uniquement sous Windows XP et supérieur. Le lecteur manipulé correspond au lecteur présent sur le serveur Web. Ce serveur doit être sous Windows XP ou supérieur.

**Composante : wd300grv.dll**
