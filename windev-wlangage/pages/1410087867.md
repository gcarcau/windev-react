# Fonctions de gestion des scanneurs (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU))

Les fonctions de gestion des scanneurs (syntaxe préfixée) sont les suivantes :

| [<Variable Scanneur>.AvecInterfaceUtilisateur](1410087860.md) | Enregistre un document provenant d'un scanneur dans un ou plusieurs fichiers, en utilisant l'interface utilisateur du scanneur. |
| --- | --- |
| [<Variable Scanneur>.Capacité](1410088721.md) | Permet de savoir si un scanneur possède une capacité donnée. |
| [<Variable Scanneur>.Propriété](1410087863.md) | Permet de connaître ou de modifier les caractéristiques d'un scanneur. |
| [<Variable Scanneur>.VersImage](1410087864.md) | Récupère un document provenant d'un scanneur dans une variable de type [Image](1000019650.md). |
| [<Variable Scanneur>.VersPDF](1410087866.md) | Enregistre un document provenant d'un scanneur dans un fichier PDF. |
