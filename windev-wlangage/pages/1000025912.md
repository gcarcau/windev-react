# htmlAttribut (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Le type **htmlAttribut** permet de définir toutes les caractéristiques avancées d'un attribut d'un élément d'un document HTML. Les caractéristiques de cet attribut peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Ce code permet de manipuler un champ de saisie destiné à la saisie d'un code à usage unique
noeud_html est un htmlNoeud
noeud_html..NomBalise = "input"
attribut_html est un htmlAttribut
attribut_html.Nom = "autocomplete"
attribut_html.Valeur = "one-time-code"
TableauAjoute(noeud_html..Attribut, attribut_html)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type htmlAttribut
Les propriétés suivantes peuvent être utilisées pour manipuler un attribut d'un document HTML :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Existe | Booléen | - Vrai si l'élément existe dans le document, - Faux dans le cas contraire.  **Cette propriété est disponible en lecture seulement**. |
| Nom | Chaîne de caractères | Nom de l'attribut. |
| Valeur | Tous types | Valeur de l'attribut. |
