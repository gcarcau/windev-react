# CouleurSouligné (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **CouleurSouligné** permet de définir la couleur utilisée pour souligner un élément. Cette propriété est utilisable sur :

- une variable de type [docMiseEnForme](1000022817.md).
- une variable de type [docElémentTexte](1000022493.md) (caractéristiques de mise en forme).
- une variable de type [docFragment](1000022482.md) (caractéristiques de mise en forme).
