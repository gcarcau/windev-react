# HErreurIntégrité (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Permet de vérifier si une erreur d'intégrité est survenue.
> _(WINDEV)_ Par défaut, WINDEV propose une gestion automatique des erreurs d'intégrité. Cette gestion automatique n'est pas disponible dans le code des procédures stockées.

> _(Java)_ Seules les erreurs d'intégrité survenues sur des fichiers de données HFSQL sont signalées.

## Exemple

```wlangage
// Gestion d'une erreur d'intégrité
SI HModifie(Client) = Faux ALORS
	SI HErreurIntégrité() = Vrai ALORS
		Erreur("Erreur d'intégrité : cet enregistrement ne peut être modifié")
	FIN
FIN
```

## Syntaxe

```wlangage
<Résultat> = HErreurIntégrité()
```

`<Résultat>` *Booléen*
> - Vrai si une erreur d'intégrité est survenue,
> - Faux sinon (pas d'erreur).

## Remarques

Par défaut, toutes les règles d'intégrité définies dans la description de l'analyse sont actives. Pour activer ou désactiver la gestion d'une contrainte d'intégrité, utilisez la fonction [HGèreIntégrité](3044058.md).
