# Structure FaxEtatComplet

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

## Présentation

La structure FaxEtatComplet est automatiquement remplie lors de l'appel à la fonction [FaxEtat](3037001.md).

## Détail de la structure FaxEtatComplet

| **FaxEtatComplet.DateHeureExpédition** | DateHeure Date et heure à laquelle le fax sera envoyé. |
| --- | --- |
| **FaxEtatComplet.DépartementExpéditeur** | Chaîne de caractères Département de l'expéditeur. |
| **FaxEtatComplet.EnErreur** | Booléen Vrai : Indique si le fax a été abandonné pour quelque raison que ce soit (même par l'utilisateur) |
| **FaxEtatComplet.EnvoyéParConnexionEnCours** | Booléen Vrai : Indique si un fax est envoyé via la connexion précisée dans la fonction [FaxEtat](3037001.md) par le paramètre <Identifiant Connexion>. |
