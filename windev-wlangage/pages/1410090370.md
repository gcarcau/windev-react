# TypeEstNullable (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Permet de savoir si un élément est nullable.

## Exemple

```wlangage
PROCÉDURE UneProcédure(UnParamètre)
SI TypeEstNullable(UnParamètre) ALORS
	// ...
FIN
```

## Syntaxe

```wlangage
<Résultat> = TypeEstNullable(<Expression>)
```

`<Résultat>` *Booléen*
> - Vrai si l'élément passé en paramètre est nullable,
> - Faux dans le cas contraire.
`<Expression>` *Type correspondant*
> Expression à manipuler.
