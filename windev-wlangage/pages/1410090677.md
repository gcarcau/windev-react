# grVignetteCatégorie (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Initialise une image de catégorie dans les graphes de type Secteur, Beignet ou Hémicycle.
> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
grSupprimeTout(GRF_Consommation)
grAjouteDonnée(GRF_Consommation, 1, 1, 35)
grEtiquetteCatégorie(GRF_Consommation, 1, "Chauffage")
grVignetteCatégorie(GRF_Consommation, 1, IMG_Chauffage)
grCouleurCatégorie(GRF_Consommation, 1, HTMLVersRVB("#FF5722"))

grAjouteDonnée(GRF_Consommation, 1, 2, 20)
grEtiquetteCatégorie(GRF_Consommation, 2, "Eau")
grVignetteCatégorie(GRF_Consommation, 2, IMG_Eau)
grCouleurCatégorie(GRF_Consommation, 2, HTMLVersRVB("#2196F3"))

grAjouteDonnée(GRF_Consommation, 1, 3, 12)
grEtiquetteCatégorie(GRF_Consommation, 3, "Recharge voiture")
grVignetteCatégorie(GRF_Consommation, 3, IMG_Voiture)
grCouleurCatégorie(GRF_Consommation, 3, HTMLVersRVB("#8BC34A"))

grAjouteDonnée(GRF_Consommation, 1, 4, 18)
grEtiquetteCatégorie(GRF_Consommation, 4, "Électroménager")
grVignetteCatégorie(GRF_Consommation, 4, IMG_Electromenager)
grCouleurCatégorie(GRF_Consommation, 4, HTMLVersRVB("#9C27B0"))

grDessine(GRF_Consommation)
```

## Syntaxe

```wlangage
grVignetteCatégorie(<Nom du graphe> , <Indice> , <Image>)
```

`<Nom du graphe>` *Nom de champ ou chaîne de caractères*
> Nom du graphe à manipuler. Ce nom correspond :
>
> - soit au nom du graphe défini par programmation avec la fonction [grCrée](3042005.md).
> - soit au nom du champ Graphe présent dans l'éditeur de fenêtres, de pages ou d'états.
>
>
> > _(Android)_ Seuls les champs Graphe sont disponibles.
`<Indice>` *Entier*
> Indice de la donnée dans la série.
`<Image>` *Chaîne de caractères ou variable de type Image*
> Image de la catégorie. Cette image peut correspondre à :
>
> - une rubrique mémo,
> - le chemin d'un fichier image (ou juste son nom si l'image est présente dans le répertoire de l'exécutable),
> - un nom du champ Image contenant une image.
> - une variable de type [Image](1000019650.md).

## Remarques

- L'image est réduite pour être affichée dans la portion. Si la taille de l'image est trop petite ou si la portion dans laquelle l'image doit être affichée est trop petite, l'image n'est pas affichée.
- Par défaut, si le graphe est redimensionné, la vignette n'est pas redimensionnée. Pour gérer l'agrandissement de la vignette, il est nécessaire d'utiliser la fonction [grParamètre](1000018337.md) avec la constante *grVignetteAvecAgrandissement*.
- Il est possible d'afficher à la fois l'image et le libellé de la catégorie.
- La fonction [grMAJAutomatiqueEtiquetteCatégorie](3042071.md) n'a pas d'impact sur l'affichage des vignettes de catégories.
