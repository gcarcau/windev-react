# hOpérationServeur (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Le type **hOpérationServeur** permet de connaître toutes les caractéristiques d'une opération qui se déroule sur un serveur HFSQL. Les caractéristiques de cette opération peuvent être connues à l'aide de différentes propriétés WLangage.
Ce type de variable est utilisé par la fonction [HOpérationEnCours](1000022480.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
TabOp est un tableau de hOpérationServeur = HOpérationEncours(cnx)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type hOpérationServeur
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **hOpérationServeur** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| DateDébut | DateHeure | Date et Heure de début de l'opération. **Cette propriété est disponible en lecture seulement**. |
| OptimisationPlanifiée | Variable de type [hOptimisationPlanifiée](1000018854.md) | Cette propriété est renseignée uniquement si l'opération est de type "Optimisation de fichiers" (propriété **Type** vaut *hlpOptimisation*). **Cette propriété est disponible en lecture seulement**. |
| Réplication | Variable de type [hRSConfig](1000020484.md) | Cette propriété est renseignée uniquement si l'opération est de type "Réplication" (propriété **Type** vaut *hlpRéplication*).  **Cette propriété est disponible en lecture seulement**. |
| SauvegardePlanifiée | Variable de type [hDescriptionSauvegarde](1000017455.md) | Cette propriété est renseignée uniquement si l'opération est de type "Sauvegarde" (propriété **Type** vaut *hlpSauvegarde*).  **Cette propriété est disponible en lecture seulement**. |
| TâchePlanifiée | Variable de type [hTâchePlanifiée](1000017448.md) | Cette propriété est renseignée uniquement si l'opération est de type "Tâche" (propriété **Type** vaut *hlpTâche*).  **Cette propriété est disponible en lecture seulement**. |
| Type | Constante de type Entier | Type de l'opération :   - *hlpCalculStat* : Calcul de statistiques. - *hlpDétectionClé* : Détection de clés. - *hlpOptimisation* : Optimisation des fichiers de données. - *hlpRéplication* : Réplication entre serveurs. - *hlpSauvegarde* : Sauvegarde. - *hlpTâche* : Tâche planifiée. - *hlpVueMatérialisée* : Rafraîchissement d'une vue matérialisée.   **Cette propriété est disponible en lecture seulement**. |
| VueMatérialiséePlanifiée | Variable de type [hPlanificationVueMatérialisée](1000021444.md) | Cette propriété est renseignée uniquement si l'opération est de type "Rafraîchissement de vue" (propriété **Type** vaut *hlpVueMatérialisée*). **Cette propriété est disponible en lecture seulement**. |
