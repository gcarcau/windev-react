# <Graphe>.Lissage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Lisse un graphe de type Courbe ou Nuage de points par la méthode des "splines cubiques".
**Rappel** : Par défaut, un graphe est non lissé.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
// Lisse le graphe affiché dans le champ GRF_MonGraphe
GRF_MonGraphe.Lissage(Vrai)
```

## Syntaxe

#### Lisser un graphe

```wlangage
<Champ Graphe>.Lissage(<Lissage>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres, de pages ou d'états).
>
> > _(PHP)_ Seuls les champs Graphe interactif sont disponibles.
`<Lissage>` *Booléen*
> - Vrai si le lissage doit être activé,
> - Faux dans le cas contraire.

## Remarques

Le lissage est pris en compte :

- dans les graphes de type courbe (constante *grCourbe*),
- dans les graphes de type nuage de points (constante *grNuage*) dont les points sont reliés (fonction [<Graphe>.NuageReliePoint](1000024109.md)).

**Attention** : Cette fonction n'a aucun effet sur un graphe 3D.

Les paramètres définis avec la fonction **<Graphe>.Lissage** seront pris en compte lors du prochain appel à la fonction [<Graphe>.Dessine](1000024062.md).
