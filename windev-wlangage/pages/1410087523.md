# Constantes Permission

> **Disponible :** **WINDEV Mobile** (Android, Widget Android)

Les constantes de gestion des permissions sont les suivantes :

| Constante | Détail | Fonction |
| --- | --- | --- |
| **permCaméra** | Permission d'accéder aux caméras de l'appareil. | [PermissionDemande](1410087423.md),  [PermissionListe](1410087429.md) |
| **permEcritureContact** | Permission de modification des contacts. | [PermissionDemande](1410087423.md),  [PermissionListe](1410087429.md) |
| **permEcritureStockageExterne** | Permission d'écriture sur le stockage externe. | [PermissionDemande](1410087423.md),  [PermissionListe](1410087429.md) |
| **permEnregistrementAudio** | Permission d'enregistrement du flux audio. | [PermissionDemande](1410087423.md),  [PermissionListe](1410087429.md) |
| **permEnvoiSMS** | Permission d'envoi de SMS. | [PermissionDemande](1410087423.md),  [PermissionListe](1410087429.md) |
| **permGestionStockageExterne** | Permission de gestion du stockage externe. | [PermissionDemande](1410087423.md),  [PermissionListe](1410087429.md) |
| **permLectureContact** | Permission d'accès en lecture aux contacts. | [PermissionDemande](1410087423.md),  [PermissionListe](1410087429.md) |
| **permLectureEtatTéléphone** | Permission d'accès aux informations du téléphone. | [PermissionDemande](1410087423.md),  [PermissionListe](1410087429.md) |
| **permLocalisation** | Permission d'accès à la position de l'appareil. | [PermissionDemande](1410087423.md),  [PermissionListe](1410087429.md) |
| **permLocalisationEnArrièrePlan** | Permission d'accès à la position de l'appareil lorsque l'application est en arrière-plan. | [PermissionDemande](1410087423.md),  [PermissionListe](1410087429.md) |
| **permLocalisationPrécise** | Permission d'accès à la position de l'appareil avec une précision élevée. | [PermissionDemande](1410087423.md),  [PermissionListe](1410087429.md) |
