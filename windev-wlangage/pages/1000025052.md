# <Source>.RAZ (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Initialise une ou toutes les variables des rubriques d'un fichier de données avec leurs valeurs par défaut. Les valeurs par défaut sont définies lors de la description du fichier de données sous l'éditeur d'analyses.
**Remarques** :

- La fonction **<Source>.RAZ** ne modifie pas l'enregistrement dans le fichier de données mais uniquement les données en mémoire.
- La fonction **<Source>.RAZ** modifie la propriété [NouvelEnregistrement](1000017090.md) du fichier de données concerné : cette propriété passe à Vrai.

## Exemple

```wlangage
// Affecte les rubriques avec leur valeur par défaut
Client.RAZ()
// Affichage
PAGE_Client.DepuisFichier(Client)
```

## Syntaxe

#### Initialiser les rubriques d'un fichier de données avec leurs valeurs par défaut

```wlangage
<Résultat> = <Source>.RAZ([<Rubrique>])
```

`<Résultat>` *Booléen*
> - Vrai si l'initialisation a été effectuée,
> - Faux en cas de problème. La fonction [HErreurInfo](3044071.md) permet d'obtenir plus de détails.
`<Source>` *Type correspondant à la source spécifiée*
> Nom du fichier de données manipulé.
`<Rubrique>` *Chaîne de caractères optionnelle*
> Nom de la rubrique à initialiser. Si ce paramètre n'est pas spécifié ou est égal à "*", l'initialisation sera effectuée pour toutes les rubriques du fichier de données.
>
> > _(Hyper File 5.5)_ Ce paramètre n'est pas pris en compte. Toutes les rubriques sont automatiquement ré-initialisées.

## Remarques

### Ouverture de fichiers de données
La fonction **<Source>.RAZ** effectue une ouverture du fichier de données manipulé. Le fichier de données doit donc avoir été créé.

> _(WINDEV, WEBDEV - Code Serveur)_ Lors d'une gestion personnalisée des erreurs, il est nécessaire de tester la fonction HErreurBlocage après l'utilisation de la fonction <Source>.RAZ.
