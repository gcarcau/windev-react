# Le volet "Navigateur"

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Lorsqu'un élément WINDEV, WEBDEV ou WINDEV Mobile (analyse, requête, etc.) ne peut pas être affiché entièrement dans l'espace de travail, le volet "Navigateur" permet de se déplacer aisément dans cet élément.

Le menu contextuel (clic droit) du volet "Navigateur" permet de :

- Synchroniser l'élément affiché dans le volet "Navigateur" avec l'élément en cours sous l'éditeur.
- Copier l'image affichée dans le volet "Navigateur".
- Enregistrer l'image affichée dans le volet "Navigateur" au format EMF ("Windows Enhanced Meta File"). Cette image au format vectoriel peut ensuite être utilisée dans une présentation (document Word, PowerPoint, etc.).
- Visualiser le graphe de l'analyse, la modélisation souple, le graphe UML ou le graphe des requêtes.

## Afficher le volet "Navigateur"

**Pour afficher le volet "Navigateur"**, sous le volet "Accueil", dans le groupe "Environnement", déroulez "Volets" et sélectionnez "Volets" puis "Navigateur".
Pour plus de détails sur les manipulations des volets, consultez [Manipuler les volets ancrables](2027001.md).
