# dOmbre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Ajoute un effet d'ombre sur une image contenue dans une variable de type [Image](1000019650.md).

## Exemple

```wlangage
MonImage est une Image
MonImage = "Image.png"
// Ajoute une ombre
dOmbre(MonImage)

// Ajoute une ombre jaune
dOmbre(MonImage, JauneBulle)
```

## Syntaxe

```wlangage
dOmbre(<Image> [, <Couleur de l'ombre> [, <Opacité de l'ombre> [, <Détourer>]]])
```

`<Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) correspondant à l'image à manipuler.
`<Couleur de l'ombre>` *Entier optionnel*
> Couleur de l'ombre à ajouter à l'image. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md).
>
>
> Par défaut, l'ombre est noire.
`<Opacité de l'ombre>` *Entier optionnel*
> Pourcentage d'opacité de l'ombre à ajouter (pour le mixage avec les pixels existants). Par défaut, cette valeur est de 100 : aucune opacité n'est appliquée.
`<Détourer>` *Booléen optionnel*
> - Vrai si l'ombre doit être détourée,
> - Faux (valeur par défaut) dans le cas contraire.

**Composante : wd300pnt.dll**
