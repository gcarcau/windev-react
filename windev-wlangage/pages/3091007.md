# Constantes des fonctions Exif

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Nouveauté Abonnement

> _(iPhone/iPad)_ La plupart de ces constantes sont désormais disponibles pour les applications iPhone/iPad.

> _(Widget IOS)_ La plupart de ces constantes sont désormais disponibles en mode Widget iOS.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
Les constantes Exif sont les suivantes :
