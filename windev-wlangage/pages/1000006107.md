# ContactRAZ (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Réinitialise :

- la structure [Contact](1000006111.md). Cette structure permet de manipuler le carnet d'adresses d'une messagerie Lotus Notes ou Outlook.
- une variable de type [Contact](1000020254.md).

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ // Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", ...
 "mail/julie.nsf", "C:\Lotus Notes\julie.id")
// Initialisation des variables de la structure Contact
ContactRAZ()
// Renseignements des variables pour le nouveau contact
mContact.Nom = "Dupont"
mContact.Prénom = "Axelle"
mContact.Email = "axelle.dupont@mesmails.com"
// Ajout du contact
SI ContactAjoute(IDSession) = Vrai ALORS
 Info("Contact ajouté")
SINON
 Erreur("Erreur lors de l'ajout", ErreurInfo())
FIN

## Syntaxe

#### Réinitialiser la structure Contact

```wlangage
ContactRAZ()
```

> _(Android, Widget Android, iPhone/iPad)_ Réinitialiser les variables de type Contact Masquer les détails
ContactRAZ([<Contact>])

 <Contact> : Variable de type ContactNom de la variable de type Contact à réinitialiser.

**Composante : wd300com.dll**
