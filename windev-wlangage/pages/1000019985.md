# <Organigramme>.SupprimeTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Supprime tous les éléments d'un champ Organigramme. Le champ Organigramme est entièrement vidé.
**Remarque** : Si le champ Organigramme est relié à une source fichier, la fonction **<Organigramme>.SupprimeTout** n'a aucun effet sur la source : aucun enregistrement n'est supprimé si la source n'est pas préalablement vidée.

## Exemple

```wlangage
// Suppression de tous les éléments du champ Organigramme
ORGA_DIRECTION.SupprimeTout()
```

## Syntaxe

```wlangage
<Champ Organigramme>.SupprimeTout()
```

`<Champ Organigramme>` *Nom de champ*
> Nom du champ Organigramme dont tous les éléments doivent être supprimés.

**Composante : wd300obj.dll**
