# NetNomMachine (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Renvoie le nom de la machine locale ou le nom d'un poste dont on connaît l'adresse IP (résolution DNS inverse).
> _(WEBDEV - Code Serveur)_ Renvoie le nom du poste serveur.

## Exemple

```wlangage
// Affiche le nom de la machine locale
Info(NetNomMachine())
```

## Syntaxe

```wlangage
<Résultat> = NetNomMachine([<Adresse IP>])
```

`<Résultat>` *Chaîne de caractères*
> Nom du poste en cours.
>
> > _(WEBDEV - Code Serveur)_ Nom du poste serveur.
> En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai et la fonction [ErreurInfo](3013008.md) permet d'identifier l'erreur.
`<Adresse IP>` *Chaîne de caractères optionnelle*
> Adresse IP (au format XXX.XXX.XXX.XXX) du poste dont on veut connaître le nom. Si ce paramètre n'est pas spécifié, le nom du poste en cours sera retourné. Cette adresse doit être une adresse valide.

## Remarques

### Adresse IP valide
Pour vérifier qu'une adresse IP est valide, utilisez la fonction [Ping](3014013.md).

**Classification Métier / UI : Code métier**

**Composante : wd300com.dll**
