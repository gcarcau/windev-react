# sfConnexion (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Le type **sfConnexion** permet de décrire une connexion à la plateforme Salesforce et de gérer l'authentification de l'utilisateur. Les caractéristiques de ce type de variable peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
La fonction [SFConnecte](1000017583.md) permet de vérifier la validité des informations de connexion.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Connexion à Salesforce
Cnx est une sfConnexion

Cnx.Login = "balthazar@gmail.com"
Cnx.MotDePasse = "azerty" + "XXB12VCZ54"
Cnx.URLServeurLogin = "https://login.salesforce.com/services/Soap/u/42.0"

SI SFConnecte(Cnx) = Faux ALORS
	Erreur("La connexion a échoué")
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type sfConnexion
Les propriétés suivantes peuvent être utilisées pour manipuler une connexion Salesforce :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| InfoSession | [sfInfoSession](1000018416.md) | Données sur la session en cours. Cette propriété est renseignée après authentification. **Cette propriété est disponible en lecture seulement**. |
| Login | Chaîne de caractères | Login de l'utilisateur. |
| ModeBacASable | Booléen | - Vrai si le mode "Bac à sable" est activé (connexion au serveur de tests) - Faux dans le cas contraire. |
| MotDePasse | Chaîne de caractères ou Chaîne secrète | Mot de passe de connexion. Il est nécessaire d'ajouter à ce mot de passe un jeton de sécurité fourni par Salesforce. Nouveauté 2025 **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode". Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md). |
| URLServeurLogin | Chaîne de caractères | URL du serveur à utiliser. Cette propriété est optionnelle. Si cette propriété est renseignée, elle est utilisée pour l'authentification. |
