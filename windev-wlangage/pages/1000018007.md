# MotDePasse (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **MotDePasse** permet de connaître et de modifier le mot de passe. Cette propriété est utilisable :

- pour savoir si un champ de saisie est de type "Mot de passe". Pour plus de détails, consultez [MotDePasse](2510086.md).
- pour définir le mot de passe d'une connexion. Pour plus de détails, consultez [MotDePasse](2510086.md).
