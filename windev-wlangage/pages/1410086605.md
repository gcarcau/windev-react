# Niveau

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **Niveau** permet de connaître et de modifier le niveau d'une numérotation. Cette propriété est utilisable sur :

- une variable de type [docParagraphe](1000022483.md),
- une variable de type [docNumérotation](1000022794.md).
