# gglPersonne (Type de variable)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Le type **gglPersonne** permet de décrire et de modifier les personnes participant à un événement d'un agenda Google.
Ce type de variable est utilisé par les variables de type [gglEvénement](1000017440.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Connexion à Google
Cnx est une gglConnexion
Cnx.Email = "balthazar@gmail.com"
Cnx.MotDePasse = "azerty"
Cnx.NomApplication = "MonAppli-01"
SI GglConnecte(Cnx) = Faux ALORS
	Erreur(ErreurInfo())
FIN
...
// Récupération du tableau des agendas disponibles
tabAgendas est un tableau de gglAgenda
tabAgendas = GglListeAgenda(Cnx)
// Récupération des événements du premier agenda
GglRemplitAgenda(Cnx, tabAgendas[1])
// Affichage des participants au premier événement
MonAgenda est un gglAgenda = tabAgendas[1]
Participant est une gglPersonne
Evt est un gglEvénement

POUR TOUT Evt DE MonAgenda.Evénement
	Trace(Evt.Titre)
	POUR TOUT Participant DE Evt.Invité
		Trace(Participant.Libellé + " (" + Participant.Email + ")")
	FIN
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type gglPersonne
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **gglPersonne** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Email | Chaîne de caractères | Email de la personne. |
| Libellé | Chaîne de caractères | Chaîne représentant la personne (Nom-Prénom par exemple). |
