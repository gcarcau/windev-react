# Le champ Editeur d'images

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows, Linux)

## Présentation du champ Editeur d'images

Le champ "Editeur d'images" est un champ évolué permettant à l'éditeur final de créer et d'éditer des images directement dans son application WINDEV ou dans un site WEBDEV. Les avantages sont immédiats : gain de temps, interface homogène, aucun autre logiciel à installer/piloter/gérer. Ce champ est basé sur Chromium CEF.
**Cette page d'aide présente le champ Editeur d'images dans une application WINDEV. Pour plus de détails, sur l'utilisation dans un site WEBDEV, consultez [Le champ Editeur d'images (WEBDEV)](1410087158.md).**

Grâce à ce champ, il est possible de :

- Ouvrir, créer, modifier, enregistrer des fichiers image,
- Annoter des images,
- Fusionner des images,
- Réaliser des rotations, des symétries,
- Saisir du texte sur une image,
- Imprimer l'image, etc.

Le ruban associé à ce champ permet de réaliser les manipulations les plus courantes. Pour plus de détails, consultez [Champ Editeur d'images : Options du ruban et des volets](1410087035.md).

De nombreux raccourcis clavier sont également disponibles :

| Raccourci | Effet | Raccourci | Effet |
| --- | --- | --- | --- |
| Ctrl + A | Sélectionne le calque en cours. | Ctrl + C | Copie la sélection dans le presse-papiers. |
| Ctrl + N | Crée une nouvelle image. | Ctrl + 0 | Ouvre une image existante. |
| Ctrl + P | Imprime l'image en cours. | Ctrl + S | Sauvegarde l'image. |
| Ctrl + T | Sélectionne le calque en cours. | Ctrl + V | Colle le contenu du presse-papiers. |
| Ctrl + X | Coupe la sélection et la place dans le presse-papiers. | Ctrl + Y | Refait la dernière action. |
| Ctrl + Z | Annule la dernière action. | Ctrl + molette de la souris | Change le zoom. |

Remarques :

- Les images au format "Gif animé" sont gérées par l'éditeur d'images.
- L'éditeur d'images propose automatiquement la reconnaissance des dessins effectués à main levée. Ainsi, un trait, un cercle ou un rectangle dessiné à main levée sera automatiquement reconnu et redessiné.

## Créer un champ Editeur d'images

**Pour créer un champ de type Editeur d'images** :

1. Sous le volet "Création", dans le groupe "Champs graphiques", déroulez "Bureautique" puis cliquez sur "Editeur d'images".
2. Cliquez dans la fenêtre à la position où le champ doit être créé.

Remarque : Les dimensions du champ créé sont optimisées pour occuper l'espace disponible à la position indiquée. Si la taille du champ ne vous convient pas, utilisez la combinaison de touches Ctrl + Z : le champ retrouvera sa taille par défaut.

Pour afficher les caractéristiques du champ, sélectionnez l'option "Description" dans le menu contextuel du champ.

## Caractéristiques du champ Editeur d'images

### Fenêtre de description
L'onglet "Général" de la fenêtre de description du champ Editeur d'images propose les options suivantes :

- **Avec ruban** : Permet d'afficher un ruban en haut du champ. Ce ruban propose les options permettant de manipuler l'image affichée dans le champ. Il est possible :
  - d'utiliser le ruban proposé par défaut. Dans ce cas, la zone "FI source du ruban" correspond à "Aucune".
  - de personnaliser le ruban proposé par défaut.
    Il suffit de sélectionner la fenêtre prédéfinie par défaut dans la zone "FI source du ruban". Dans ce cas, la fenêtre "FI_WinDevFAA_RubanPIC" est automatiquement intégrée dans votre projet, dans le composant interne WDFAA. Cette fenêtre interne (disponible en français et anglais) peut être modifiée selon vos besoins. Cette fenêtre interne contient les différents appels aux fonctionnalités du champ. Vous pouvez ajouter des nouveaux champs dans cette fenêtre interne, rendre invisibles ou supprimer les champs existants. Le code des différentes options ne peut pas être modifié. Nous vous conseillons de vérifier les erreurs d'UI ainsi que le bon fonctionnement de la fenêtre après toute modification.
  - d'utiliser une fenêtre interne pour proposer un ruban spécifique.
    Vous pouvez utiliser n'importe quelle fenêtre interne de votre projet pour réaliser ce ruban.
- Lors de l'utilisation d'un ruban, l'option "Appliquer le gabarit du projet sur le ruban" permet d'utiliser automatiquement le gabarit du projet sur le ruban sélectionné.
- **Autoriser le changement de document (Ouvrir, Nouveau, ... )** : Si cette option est cochée, l'utilisateur aura la possibilité de charger n'importe quel document dans le champ Editeur d'images. Dans le cas contraire, les options "Ouvrir" et "Nouveau" ne seront pas disponibles. Il sera uniquement possible d'éditer l'image présente dans le champ.

### Formats gérés par le champ Editeur d'images
Le champ Editeur d'images gère les formats suivants (en lecture et écriture) :

- JPG, JPEG, JPE
- BMP
- GIF
- GIF animés
- PNG
- ICO
- TIF
- WDPIC

Nouveauté 2025
Remarque : Les caractéristiques EXIF de positionnement de l'image sont automatiquement prises en compte.
**Attention** : Cette fonctionnalité est disponible uniquement à partir de la version 2025 Update 1.
