# AfficheLicence (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

Affiche la licence du framework WINDEV Mobile ou des librairies du framework dans une nouvelle fenêtre.

## Exemple

```wlangage
AfficheLicence(alFramework)
```

## Syntaxe

```wlangage
AfficheLicence([<Type de la licence>])
```

`<Type de la licence>` *Constante optionnelle de type Entier*
> Licence à afficher :
>
>
> | *alFramework* | Permet d'afficher la licence du framework WINDEV Mobile. |
> | --- | --- |
> | *alLibrairie* | Permet d'afficher la licence des différentes librairies Android ou iOS utilisées par l'application (selon la plateforme utilisée). |

**Classification Métier / UI : Code UI**
