# Constantes de gestion de la correction orthographique

> **Disponible :** **WINDEV** (Windows)

| Constante | Description | Utilisée par les fonctions |
| --- | --- | --- |
| **orthPortéePersistant** | Le mot est ajouté dans le dictionnaire de OpenOffice. Cette constante a le même effet que l'option "Ajouter au dictionnaire" du menu contextuel des FAA avec correction orthographique. | [OrthoAjouteDictionnaire](1000018921.md) |
| **orthPortéeProcessus** | Le mot n'est pas ajouté dans le dictionnaire de OpenOffice. Il continuera donc à être affiché comme "faux" si l'application est relancée. | [OrthoAjouteDictionnaire](1000018921.md) |
