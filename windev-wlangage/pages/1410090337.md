# Gérer l'accessibilité en Mobile

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Sur les smartphones et les tablettes, il existe un mode d'utilisation destiné aux personnes malvoyantes et non voyantes.
Ce mode se nomme TalkBack sur Android et VoiceOver sur iOS.
En version 2024, WINDEV Mobile permet de bénéficier de ces modes.

Chaque champ contient une description générique (par défaut) et peut contenir une description personnalisée.
La description générique correspond par défaut au libellé ou au texte d'indication du champ.
Une description personnalisée peut être définie :

- soit via la fenêtre de description du champ.
- soit par programmation, via diverses propriétés WLangage.

## Définition et personnalisation de l'accessibilité via la fenêtre de description des champs

Par défaut, tous les champs d'une interface utilisée sous Android ou iOS utilisent l'option d'accessibilité.
Pour qu'un champ soit pris en compte par les fonctionnalités d'accessibilité du mobile utilisé :

1. Affichez la fenêtre de description du champ.
2. Dans l'onglet "Aide", cochez si nécessaire l'option "Inclure ce champ dans l'accessibilité". Par défaut, une description automatique et une action automatique sont définies pour le champ.

Pour personnaliser les caractéristiques de l'accessibilité :

1. Affichez la fenêtre de description du champ.
2. Dans l'onglet "Aide", cochez si nécessaire l'option "Inclure ce champ dans l'accessibilité".
3. Cliquez sur le bouton "Personnaliser".
4. Dans la fenêtre qui s'affiche, spécifiez les éléments à personnaliser.
  - Description du champ et du contenu attendu.
  - Description de l'action accomplie lors de l'utilisation du champ.
5. Validez.

Remarque : Si votre interface utilise des champs de type "décor", servant uniquement à améliorer la lisibilité de l'interface, il est possible dans ce cas de ne pas les inclure dans les propriétés d'accessibilité. Il suffit pour cela de décocher l'option "Inclure ce champ dans l'accessibilité".

## Personnalisation de l'accessibilité par programmation

Plusieurs propriétés et fonctions permettent de gérer l'accessibilité sur les champs d'une fenêtre :

- Propriétés :
  | [Accessibilité.Décor](1410090235.md) | Permet d'indiquer si le champ est un champ de décor, c'est-à-dire s'il doit être ignoré par le système de lecture. |
  | --- | --- |
  | [Accessibilité.Description](1410090235.md) | Décrit le contenu du champ. |
  | [Accessibilité.DescriptionAction](1410090235.md) | Permet de décrire l'action du champ. |
  | [Accessibilité.OrdreLecture](1410090235.md) | Permet d'indiquer l'ordre de lecture utilisé par le système de lecture. Il suffit d'indiquer le numéro d'ordre. La lecture sera effectuée dans l'ordre croissant. |
- Fonction :
  | [AccessibilitéLecteurEcranActif](1410090330.md) | Permet de savoir si le lecteur d'écran est actif. |
  | --- | --- |
