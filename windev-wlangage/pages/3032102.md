# LDAPDéconnecte (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **Autres** (Procédures stockées)

Permet de se déconnecter d'un serveur LDAP spécifique.

## Exemple

```wlangage
LDAPDéconnecte("MaSessionLDAP")
```

## Syntaxe

```wlangage
<Résultat> = LDAPDéconnecte(<Session LDAP>)
```

`<Résultat>` *Booléen*
> - Vrai si la connexion est fermée,
> - Faux dans le cas contraire. La fonction [ErreurInfo](3013008.md) permet d'obtenir plus de détails sur l'erreur.
`<Session LDAP>` *Chaîne de caractères*
> Nom de la session LDAP à fermer.
