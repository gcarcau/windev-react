# LecteurPDFRecherchePremier (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Initialise la recherche d'un texte dans le fichier PDF affiché par le champ Lecteur PDF et positionne sur la première occurrence trouvée (à partir de la page en cours). Le texte trouvé est sélectionné.

## Exemple

```wlangage
// Recherche un texte dans un champ Lecteur PDF et affiche le texte
LecteurPDFRecherchePremier(PDF_MonLecteurPDF, "société")
// Recherche l'élément suivant
SI LecteurPDFRechercheSuivant(PDF_MonLecteurPDF) = Faux ALORS
	Info("Recherche terminée")
FIN

// Recherche l'élément précédent
LecteurPDFRecherchePrécédent(PDF_MonLecteurPDF)
```

## Syntaxe

```wlangage
<Résultat> = LecteurPDFRecherchePremier(<Champ Lecteur PDF> , <Texte à rechercher> [, <Options>])
```

`<Résultat>` *Booléen*
> - Vrai si le texte a été trouvé dans le document,
> - Faux si le texte n'a pas été trouvé.
`<Champ Lecteur PDF>` *Nom de champ*
> Nom du champ Lecteur PDF à manipuler.
`<Texte à rechercher>` *Chaîne de caractères*
> Texte à rechercher dans le contenu du champ Lecteur PDF.
`<Options>` *Constante (ou combinaison de constantes) optionnelle*
> Options de recherche :
>
> | *MotComplet* | Recherche le mot complet (entouré par des caractères de ponctuation ou des espaces). |
> | --- | --- |
> | *SansCasse* | Recherche sans tenir compte de la casse (majuscules/minuscules) et des accents. |
>
>
> Par défaut, la recherche est sensible à la casse : le texte recherché doit avoir la même casse que le texte à trouver. Pour effectuer une recherche ne tenant pas compte de la casse, utilisez la constante *SansCasse*.

## Remarques

- Le texte et les options de recherche spécifiées sont automatiquement pris en compte par les fonctions [LecteurPDFRechercheSuivant](1000023410.md) et [LecteurPDFRecherchePrécédent](1000023411.md) exécutées après la fonction **LecteurPDFRecherchePremier**.
- A partir de la version 28, cette fonction n'est pas supportée par les processeurs ARM 32 bits. En effet, les nouveautés en matière de gestion des PDF imposent une exécution en 64 bits.
  Si une application doit être exécutée sur une flotte existante d'appareils ARM 32 bits, la génération de cette application doit être effectuée avec la version 27 de WINDEV Mobile.
