# dCopieImageChamp (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Copie l'image d'un champ d'une fenêtre WINDEV dans une variable de type [Image](1000019650.md).

## Exemple

```wlangage
// Image du champ de saisie du nom
MonImage est une Image = dCopieImageChamp(SAI_Nom)
```

## Syntaxe

```wlangage
<Résultat> = dCopieImageChamp(<Champ à copier>)
```

`<Résultat>` *Variable de type Image*
> Variable de type [Image](1000019650.md) contenant l'image du champ.
> En cas d'erreur, la variable [ErreurDétectée](3087001.md) vaut Vrai et le message d'erreur correspondant peut être connu avec la fonction [ErreurInfo](3013008.md).
`<Champ à copier>` *Nom de champ*
> Nom du champ dont l'image doit être copiée.

## Remarques

- L'image du champ prend en compte l'état du champ (actif, grisé, ...) au moment de l'appel de la fonction.
- L'image du champ sera récupérée même si le champ est invisible, hors fenêtre, ou s'il n'est pas dans le plan de la fenêtre affiché.

**Composante : wd300pnt.dll**
