# Fonctions de gestion des champs Tableau de bord (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Les fonctions de gestion des champs Tableau de bord (syntaxe préfixée) sont les suivantes :

| [<Tableau de bord>.Affiche](1000022500.md) | Rafraîchit l'affichage des éléments d'un champ Tableau de bord. |
| --- | --- |
| [<Tableau de bord>.AjouteWidget](1000022502.md) | Ajoute et affiche un Widget (fenêtre interne) dans un champ Tableau de bord. |
| [<Tableau de bord>.ChangeTailleWidget](1000022504.md) | Change les dimensions d'un Widget présent dans un champ Tableau de bord. |
| [<Tableau de bord>.ChargeConfiguration](1000022506.md) | Restaure la configuration d'un champ Tableau de bord. |
| [<Tableau de bord>.ConfigurationInitiale](1000022525.md) | Modifie la configuration d'un champ Tableau de bord (définie sous l'éditeur) avant son premier affichage. |
| [<Tableau de bord>.DéplaceWidget](1000022527.md) | Change la position d'un widget présent dans un champ Tableau de bord. |
| [<Tableau de bord>.InfoXY](1000022529.md) | Permet de savoir :  - si un Widget est présent dans un champ Tableau de bord à une position donnée. - quel est le Widget présent dans un champ Tableau de bord à une position donnée. |
| [<Tableau de bord>.Mode](1000022532.md) | Ouvre ou ferme le mode "Edition" d'un champ Tableau de bord. |
| [<Tableau de bord>.Occurrence](1000022538.md) | Renvoie le nombre de Widgets présents dans un champ Tableau de bord. |
| [<Tableau de bord>.RécupèreWidgetPosition](1000022533.md) | Renvoie la position d'un Widget présent dans un champ Tableau de bord. |
| [<Tableau de bord>.SauveConfiguration](1000022534.md) | Sauvegarde la configuration d'un champ Tableau de bord sous forme d'une chaîne. |
| [<Tableau de bord>.Supprime](1000022535.md) | Supprime un Widget affiché dans un champ Tableau de bord. Le champ Tableau de bord est mis à jour et un emplacement vide remplace le Widget supprimé. |
| [<Tableau de bord>.SupprimeTout](1000022536.md) | Supprime tous les Widgets affichés dans un champ Tableau de bord. |
