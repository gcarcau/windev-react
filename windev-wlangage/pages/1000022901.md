# <Planning>.AffichePériodePrécédente (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, iPhone/iPad)

Déplace la zone temporelle affichée sur la zone précédente (par exemple, semaines précédentes) dans un champ Planning. Le champ Planning s'affiche alors à partir du jour correspondant à la zone temporelle précédente.
**Remarque** : Les fonctions **<Planning>.AffichePériodePrécédente** et [<Planning>.AffichePériodeSuivante](1000022902.md) permettent de mettre en place simplement des champs Bouton "Suivant / Précédent". Ces champs permettent de faire défiler les zones temporelles affichées par le champ Planning.

## Exemple

```wlangage
// Clic sur le champ Bouton [PRECEDENT]
PLN_PlanningSalles.AffichePériodePrécédente()
```

## Syntaxe

```wlangage
<Champ Planning>.AffichePériodePrécédente()
```

`<Champ Planning>` *Nom de champ*
> Nom du champ Planning à manipuler.

**Composante : wd300obj.dll**
