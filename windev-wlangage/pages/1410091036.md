# <Variable Connexion>.RSTransformeSpareEnServeur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Transforme un serveur Spare en un serveur HFSQL. Il est ainsi possible de supprimer les réplications d'un serveur spare pour pouvoir l'utiliser à nouveau (cas par exemple d'un serveur maître inaccessible).
**Cette fonction doit être utilisée uniquement en cas d'urgence.**

**Attention** : Cette fonction est disponible uniquement à partir de la version 2025 Update 1.

## Exemple

```wlangage
// Suppression d'une réplication spare identifiée par l'identifiant de réplication
tabRS_SpareComplet est un tableau de hRSConfig = gcnxSpareComplet_bdd1.RSListeConfig(hrsAbonné)
gcnxSpareComplet_bdd1.RSTransformeSpareEnServeur(tabRS_SpareComplet[1].IdentifiantOpposé)

// Suppression des réplications spare d'un serveur maître
tabRS_SpareComplet est un tableau de hRSConfig = gcnxSpareComplet_bdd1.RSListeConfig(hrsAbonné)
gcnxSpareComplet_bdd1.RSTransformeSpareEnServeur(tabRS_SpareComplet[1].Serveur)

// Suppression de toutes les réplications d'un serveur spare
gcnxSpareComplet_bdd1.RSTransformeSpareEnServeur()
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.RSTransformeSpareEnServeur([<Réplication à supprimer>])
```

`<Résultat>` *Booléen*
> - Vrai si la suppression a été effectuée,
> - Faux dans le cas contraire. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom d'une variable de type [Connexion](1514073.md) décrivant la connexion vers le serveur HFSQL spare.
`<Réplication à supprimer>` *Entier optionnel ou chaîne de caractères optionnelle*
> - Identifiant de la réplication à supprimer. Cet identifiant correspond à la propriété **IdentifiantOpposé** de la variable de type [hRSConfig](1000020484.md) décrivant la réplication.
> - Nom du serveur maître pour lequel les réplications spare associées doivent être supprimées.
>
>
> Si ce paramètre n'est pas spécifié, toutes les réplications spare sont supprimées.
