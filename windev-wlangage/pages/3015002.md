# Fonctions de gestion des événements Windows

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur)

Les fonctions de gestion des événements sont les suivantes :

| [Evénement](3015011.md) | Intercepte un événement Windows sur un champ, un groupe de champs ou une fenêtre WINDEV. |
| --- | --- |
| [EvénementExiste](1000024424.md) | Indique si une procédure spécifique est exécutée lorsqu'un événement Windows est envoyé à un champ ou une fenêtre. |
| [FinEvénement](3015010.md) | Annule l'interception d'un événement Windows sur un champ ou une fenêtre WINDEV (mis en place grâce à la fonction [Evénement](3015011.md)). |
| [FinTimer](3015007.md) | Termine l'exécution d'un timer déclenché par la fonction [Timer](3015008.md). |
| [FinTimerSys](3015009.md) | Termine l'exécution d'un timer déclenché par la fonction [TimerSys](3015006.md). |
| [Handle](3015005.md) | Renvoie le "Handle" système (HWND) d'un champ ou d'une fenêtre WINDEV. |
| [HandleParentSuivant](1000017312.md) | Force le parent de la prochaine fenêtre à ouvrir. |
| [Multitâche](3015004.md) | La fonction Multitâche permet de :   - effectuer une temporisation, - rendre la main à Windows, - rendre la main à Windows et au WLangage. |
| [PostMessage](3015001.md) | Envoie un message Windows à un champ ou à une fenêtre. |
| [SendMessage](3015003.md) | Envoie un message Windows à un champ ou à une fenêtre. |
| [Temporisation](3015012.md) | Stoppe temporairement l'exécution du programme. |
| [Timer](3015008.md) | Appelle périodiquement et automatiquement une procédure du WLangage. |
| [TimerSys](3015006.md) | Appelle périodiquement et automatiquement une procédure du WLangage. |
