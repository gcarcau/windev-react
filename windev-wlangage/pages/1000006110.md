# Fonctions de gestion des contacts (Lotus Notes, Outlook et appareil mobile)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Les fonctions de gestion des contacts permettent :

- de gérer les contacts présents dans le carnet d'adresses d'une messagerie Lotus Notes ou Outlook.
- de gérer les contacts présents sur un téléphone Android.

| [ContactAffiche](1000019506.md) | Ouvre la fiche d'un contact dans l'application native de gestion des contacts de l'appareil (Android, iPhone ou iPad). |
| --- | --- |
| [ContactAjoute](1000006101.md) | Ajoute un contact :   - dans le carnet d'adresses d'une messagerie Lotus Notes ou Outlook. - dans la liste des contacts de l'appareil (Android, iPhone ou iPad). |
| [ContactCherche](1000006102.md) | Recherche un contact dans le carnet d'adresses d'une messagerie Lotus Notes ou Outlook. |
| [ContactCrée](1000019556.md) | Affiche la fenêtre de création de contact de l'application native de gestion des contacts de l'appareil (Android, iPhone ou iPad). |
| [ContactDernier](1000006103.md) | Lit le dernier contact présent dans le carnet d'adresses d'une messagerie Lotus Notes ou Outlook. |
| [ContactEdite](1000019507.md) | Ouvre en édition la fiche d'un contact en cours dans l'application native de gestion des contacts de l'appareil (Android, iPhone ou iPad). |
| [ContactListe](1000020266.md) | Liste les contacts de l'appareil correspondant aux critères spécifiés. |
| [ContactListeSource](1000020214.md) | Liste les sources (ou comptes) de contacts enregistrés sur l'appareil. |
| [ContactLit](1000006112.md) | Lit un contact présent dans le carnet d'adresses d'une messagerie Lotus Notes ou Outlook. |
| [ContactModifie](1000006104.md) | Modifie le contact en cours dans le carnet d'adresses d'une messagerie Lotus Notes ou Outlook. |
| [ContactPrécédent](1000006105.md) | Lit le contact précédent du contact en cours dans le carnet d'adresses d'une messagerie Lotus Notes ou Outlook. |
| [ContactPremier](1000006106.md) | Lit le premier contact présent dans le carnet d'adresses d'une messagerie Lotus Notes ou Outlook. |
| [ContactRAZ](1000006107.md) | Réinitialise :   - la structure [Contact](1000006111.md). - une variable de type [Contact](1000020254.md). |
| [ContactSélectionne](1000019508.md) | Affiche la liste des contacts de l'appareil (Android, iPhone ou iPad). |
| [ContactSuivant](1000006108.md) | Lit le contact suivant du contact en cours dans le carnet d'adresses d'une messagerie Lotus Notes ou Outlook. |
| [ContactSupprime](1000006109.md) | Supprime le contact en cours :   - du carnet d'adresses d'une messagerie Lotus Notes ou Outlook. - dans la liste des contacts du téléphone (Android, iPhone ou iPad). |
