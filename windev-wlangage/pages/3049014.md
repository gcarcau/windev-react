# ListeOccurrence (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Renvoie le nombre d'éléments présents dans un champ Liste, Liste image ou Combo.
**Remarque** : La fonction **ListeOccurrence** peut être utilisée indifféremment sur :

- les champs Liste fichier ou Liste par programmation,
- les champs Liste monosélection ou multisélections.

## Exemple

```wlangage
// Nombre d'éléments présents dans le champ "LISTE_ListeClient"
ResNombreElément = ListeOccurrence(LISTE_ListeClient)
```

## Syntaxe

```wlangage
<Résultat> = ListeOccurrence(<Champ Liste>)
```

`<Résultat>` *Entier*
> Nombre d'éléments (lignes) présents dans le champ spécifié.
`<Champ Liste>` *Nom de champ*
> Nom du champ Liste ou Combo à manipuler. Si ce paramètre correspond à une chaîne vide (""), le champ manipulé correspond au champ auquel le traitement en cours appartient.
>
> > _(WEBDEV - Code Navigateur)_ Le nom du champ Liste (ou Combo) à manipuler doit obligatoirement être précisé.

## Remarques

### Limitations
Si le champ Liste (ou Combo) spécifié est relié à un fichier de données qui contient plus de 2 147 483 647 enregistrements, la valeur renvoyée est tronquée à cette valeur.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Android, iPhone/iPad, Java, Code Utilisateur (MCU), Ajax)_ Champ Liste fichierPour un champ Liste fichier, la fonction ListeOccurrence renvoie :soit le nombre total d'enregistrements du fichier relié si aucun filtre n'a été défini.soit le nombre d'enregistrements qui correspondent au filtre si un filtre a été défini.soit le nombre d'enregistrements présents dans la requête liée au champ.Le code de fin d'initialisation du champ est exécuté uniquement lorsque le total est calculé.Attention : Le temps de calcul du nombre d'enregistrements peut être long.

### Dernier élément
Pour se positionner sur le dernier élément d'un champ Liste, la syntaxe est :

```wlangage
ListeSelectPlus(<Champ Liste>, <Champ Liste>.Occurrence)
```

ou

```wlangage
<Champ Liste> = <Champ Liste>.Occurrence
```

ou

```wlangage
<Champ Liste> = ListeOccurrence(<Champ Liste>)
```

### Divers

- Pour connaître le nombre de lignes d'un champ Table, utilisez la fonction [TableOccurrence](3074021.md).
- La fonction **ListeOccurrence** peut être utilisée sur une colonne d'un champ Table de type "Combo".
