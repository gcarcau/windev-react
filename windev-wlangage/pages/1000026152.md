# zipSélectionFichier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Définit une sélection des fichiers contenus dans l'archive. Cette sélection de fichiers sera traitéé par les fonctions WLangage de gestion des archives.
Il est ainsi possible par exemple de sélectionner uniquement les fichiers ".doc" d'une archive. Dans ce cas, toutes les fonctions WLangage permettant de manipuler la totalité de l'archive (fonction [zipExtraitTout](3082011.md) par exemple) n'agiront que sur les fichiers sélectionnés (fichiers ".doc" dans notre exemple).

Nouveauté 2025

> _(WINDEV, WEBDEV - Code Serveur, Windows, Linux, iPhone/iPad)_ Le format gzip (extension .gz) est désormais géré.

## Exemple

```wlangage
Archive est une zipArchive
// Ouverture d'une archive
SI zipOuvre(Archive, "C:\Archives\Archive.zip") = 0 ALORS
	// On veut extraire uniquement les documents
	sAncienneSélection est une chaîne = zipSélectionFichier(Archive, "*.doc")
	// Extraction de tous les documents de l'archive
	zipExtraitTout(Archive, zipDisque)
	// Restitution de la sélection précédente
	zipSélectionFichier(Archive, sAncienneSélection)
FIN
```

## Syntaxe

```wlangage
<Résultat> = zipSélectionFichier(<Archive> [, <Sélection>])
```

`<Résultat>` *Chaîne de caractères*
> Ancienne sélection appliquée sur l'archive.
`<Archive>` *Chaîne de caractères ou variable de type zipArchive*
> Nom de l'archive à manipuler.
> Ce nom peut correspondre :
>
> - soit au nom d'une archive défini avec la fonction [zipOuvre](3082044.md) ou [zipCrée](3082003.md).
> - soit au nom d'une variable de type [zipArchive](1000018679.md).
`<Sélection>` *Chaîne de caractères optionnelle*
> Nom générique des fichiers à sélectionner.
> Les caractères génériques (* et ?) sont autorisés.
> Si ce paramètre n'est pas précisé ou vaut chaîne vide (""), la sélection est supprimée et tous les fichiers seront traités.

## Remarques

### Principe
Après l'appel de la fonction **zipSélectionFichier**, les prochaines fonctions de gestion des archives manipulant l'ensemble des fichiers de l'archive respecteront la sélection : ces fonctions manipuleront uniquement la sélection de fichiers spécifiée.
Pour manipuler à nouveau l'ensemble des fichiers de l'archive, il suffit d'appeler la fonction **zipSélectionFichier** sans spécifier le paramètre <Sélection>.

### Rappel

- Seules les archives au format ZIP, gzip, TAR et TGZ (TAR.GZ) sont disponibles.
- Les archives au format CAB ne sont pas disponibles.

**Composante : wd300zip.dll**
