# Utilisateur (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **Utilisateur** permet de connaître et de modifier l'utilisateur d'une fonctionnalité. Cette propriété est utilisable sur :

- une variable de type [Connexion](1514073.md). Pour plus de détails, consultez [Utilisateur](2512107.md).
- une variable de type [hDescriptionSauvegarde](1000017455.md).
- une variable de type [hOptimisationPlanifiée](1000018854.md).
- une variable générée automatiquement pour représenter [un Webservice importé](3086001.md).
- une variable générée automatiquement pour représenter [un Webservice REST importé](1410087809.md).
- une variable de type [httpRequête](1000021158.md).
- une variable de type [restRequête](1000021481.md).
- une variable de type [sshSession](1000021157.md).
- une variable de type [hTâchePlanifiée](1000017448.md).
- une variable de type [hPlanificationVueMatérialisée](1000021444.md).
- une variable de type [hdfsConnexion](1000021650.md).
- une variable de type [serveurAppliTâchePlanifiée](1000022367.md).
- une variable de type [mqttSession](1000023023.md).
- une variable de type [memcachedConnexion](1000023339.md).
- une variable de type [URI](1000024027.md).
- une variable de type [saasVisite](1000024560.md).
- une variable de type [AppleID](1000025405.md).
- une variable de type [adminWBAuth](1410089328.md).
- une variable de type [adminWBCompte](1410089382.md).
- Nouveauté 2025
  une variable de type [hHistoriquePlanification](1410090764.md).
- Nouveauté 2025
  une variable de type [ftpConnexion](1410090869.md).
