# <Page>.Adresse (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux, PHP)

Permet d'obtenir l'adresse Internet d'une page.

## Exemple

> _(WEBDEV - Code Serveur, Ajax)_ Trace(PAGE_COORDONNEE.Adresse())
// Affiche par exemple :
// /WD300AWP/WD300AWP.EXE/CTX_2420-0-FCFOVjoyom/COORDONNEES/SYNC_12564

> _(WEBDEV - Code Serveur, Ajax)_ Trace(PAGE_COORDONNEE.Adresse(paComplète))
// Affiche par exemple :
// http://www.pcsoft.fr/WD300AWP/WD300AWP.EXE/CTX_2420-0-FCFOVjoyom/COORDONNEES/SYNC_12564

> _(WEBDEV - Code Serveur, Ajax)_ // Code d'initialisation d'un lien permettant
// d'ouvrir une page en liaison sécurisée
ContexteOuvre(PAGE_PageSecu)
MoiMême.Valeur = PAGE_PageSecu.Adresse(paSécurisée) + "?WD_ACTION_=REFRESH")

## Syntaxe

> _(WEBDEV - Code Serveur, PHP, Ajax)_ Récupérer l'adresse d'une page Masquer les détails
<Résultat> = <Page>.Adresse([<Option>])

 <Résultat> : Chaîne de caractères AnsiAdresse de la page spécifiée ou chaîne vide ("") si :la page n'existe pas dans le projetle contexte de la page n'est pas ouvert (fonction ContexteOuvre). <Page> : Nom de pageNom de la page dont l'adresse doit être renvoyée. <Option> : Constante optionnelleType d'adresse à renvoyer :paComplèteAdresse complète de la page (adresse en HTTP). paComplèteAutoAdresse complète de la page avec le protocole utilisé pour son affichage (HTTP ou HTTPS). paRelative(Valeur par défaut)Adresse relative au domaine en cours.paSécuriséeAdresse complète de la page, sécurisée par SSL (adresse en HTTPS).
