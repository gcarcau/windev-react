# Le volet "Centre de Gestion de Projets"

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Le volet "Centre de Gestion de Projets" affiche les tâches du développeur en cours. Ces tâches correspondent au projet sélectionné ou à tous les projets.
Le menu contextuel (clic droit) du volet "Centre de Gestion de Projets" permet de :

- Ajouter une tâche.
- Modifier une tâche.
- Annuler une tâche.
- Réaliser une tâche.
- Actualiser la liste des tâches.
- Ouvrir l'élément relié à une tâche.
- Démarrer une tâche.

## Afficher le volet "Centre de Gestion de Projets"

**Pour afficher le volet "Centre de Gestion de Projets"**, sous le volet "Accueil", dans le groupe "Environnement", déroulez "Volets" et sélectionnez "Volets" puis "Centre de Gestion de Projets".
Pour plus de détails sur les manipulations des volets, consultez [Manipuler les volets ancrables](2027001.md).
