# <Variable Connexion>.InfoPropriétéServeur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Permet de connaître les propriétés d'un serveur HFSQL.

## Exemple

```wlangage
// Description de la connexion
MaConnexion est une Connexion

// Ouverture de la connexion
MaConnexion.OuvreConnexion()
...
NotesServeur est une chaîne
NotesServeur = MaConnexion.InfoPropriétéServeur(hNotes)
SI NotesServeur <> "" ALORS
	Trace("Description du serveur : " + NotesServeur)
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Connexion>.InfoPropriétéServeur(<Propriété>)
```

`<Résultat>` *Chaîne de caractères*
> - Valeur de la propriété demandée,
> - Chaîne vide ("") en cas d'erreur.
`<Connexion>` *Variable de type Connexion*
> Nom de la variable de type [Connexion](1514073.md) décrivant la connexion pour laquelle la valeur d'une propriété est recherchée.
`<Propriété>` *Constante de type Entier*
> Propriété du serveur recherchée :
>
> | *hNotes* | Description du serveur ou toute autre information associée au serveur grâce à la fonction [<Variable Connexion>.ModifiePropriétéServeur](1000022720.md).  Si cette constante est utilisée, <Résultat est une chaîne de caractères. |
> | --- | --- |

## Remarques

Pour modifier les propriétés d'un serveur, utilisez la fonction [<Variable Connexion>.ModifiePropriétéServeur](1000022720.md).

**Composante : wd300hf.dll**
