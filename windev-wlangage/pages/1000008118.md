# GroupeSupprime (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **Autres** (Procédures stockées)

Supprime le groupe de contacts en cours du carnet d'adresses d'une messagerie Lotus Notes ou Outlook.
**Attention** : Cette fonction **ne permet pas** de supprimer le groupe de contacts en cours du carnet d'adresses d'une messagerie Outlook Express.

## Exemple

```wlangage
// Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", ...
	"mail\julie.nsf", "C:\Users\Julie\AppData\Local\Lotus\Notes\Data\user.id")
// Lecture du premier groupe de contacts
GroupePremier(IDSession)
// Suppression de ce groupe
GroupeSupprime(IDSession)
```

## Syntaxe

```wlangage
<Résultat> = GroupeSupprime(<Identifiant de la session>)
```

`<Résultat>` *Booléen*
> - Vrai si la suppression a été effectuée,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Identifiant de la session>` *Entier*
> Identifiant de la session à utiliser. Cet identifiant est renvoyé par la fonction [EmailOuvreSessionNotes](3032121.md), [EmailOuvreSessionOutlook](3032128.md), [NotesOuvreBase](1000005101.md) ou [OutlookOuvreSession](3032123.md).

## Remarques

### Version de Outlook utilisée
Les groupes de contacts ne sont pas gérés par Outlook version 97. Il n'est donc pas possible de supprimer un groupe de contacts dans cette version de Outlook.

**Composante : wd300com.dll**
