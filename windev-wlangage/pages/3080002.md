# Constantes de gestion des fichiers XLS

> **Disponible :** **WINDEV** (Windows) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Nouveauté 2025

> _(Android)_ La plupart de ces constantes sont désormais disponibles pour les applications Android.

> _(Widget Android)_ La plupart de ces constantes sont désormais disponibles en mode Widget Android.

> _(iPhone/iPad)_ La plupart de ces constantes sont désormais disponibles pour les applications iPhone/iPad.

| Constante | Description | Détail | Utilisée par les fonctions |
| --- | --- | --- | --- |
| **xlsCompatible** | Mode d'ouverture d'un fichier XLS | Ouverture en mode compatible avec les versions précédentes de WINDEV et WEBDEV (gestion uniquement de la première feuille du classeur) | [xlsOuvre](3080017.md) |
| **xlsDonnéeErreur** | Erreur (constante conservée par compatibilité) | Constante retournée en cas d'erreur | [xlsDonnée](3080021.md) |
| **xlsEcriture** | Mode d'ouverture d'un fichier XLS | Ouvre le fichier Excel en mode "Lecture / Ecriture" : le fichier XLS est ouvert et bloqué jusqu'à sa fermeture. | [xlsOuvre](3080017.md) |
| **xlsFusionCelluleCentrée** | Mode de fusion des cellules | Fusionne les cellules en centrant le contenu. | [xlsFusionneCellule](1410089537.md) |
| **xlsFusionCelluleSimple** | Mode d'ouverture d'un fichier XLS | Fusionne les cellules sans centrer le contenu. | [xlsFusionneCellule](1410089537.md) |
| **xlsNumColonne** | Type de coordonnée à renvoyer | Numéro de colonne. | [xlsNomVersCoordonnées](1000021501.md) |
| **xlsNumLigne** | Type de coordonnée à renvoyer | Numéro de ligne. | [xlsNomVersCoordonnées](1000021501.md) |
| **xlsTitreErreur** | Erreur | Constante retournée en cas d'erreur | [xlsTitreColonne](3080012.md) |
| **xlsTypeChaîne** | Type des données saisies | Colonne "chaîne de caractères" ou colonne contenant des données de différents types | [xlsTypeColonne](3080019.md), variable de type [xlsCellule](1000017472.md). |
| **xlsTypeDate** | Type des données saisies | Colonne "date" | [xlsTypeColonne](3080019.md), variable de type [xlsCellule](1000017472.md). |
| **xlsTypeDateHeure** | Type des données saisies | Colonne "dateheure" | [xlsTypeColonne](3080019.md), variable de type [xlsCellule](1000017472.md). |
| **xlsTypeDouble** | Type des données saisies | Colonne "numérique" | [xlsTypeColonne](3080019.md), variable de type [xlsCellule](1000017472.md). |
| **xlsTypeDurée** | Type des données saisies | Colonne "durée" | [xlsTypeColonne](3080019.md), variable de type [xlsCellule](1000017472.md). |
| **xlsTypeErreur** | Erreur | Constante retournée en cas d'erreur | [xlsTypeColonne](3080019.md), variable de type [xlsCellule](1000017472.md). |
| **xlsTypeHeure** | Type des données saisies | Colonne "heure" | [xlsTypeColonne](3080019.md), variable de type [xlsCellule](1000017472.md). |
| **xlsTypeMonétaire** | Type des données saisies | Colonne "monétaire" | [xlsTypeColonne](3080019.md), variable de type [xlsCellule](1000017472.md). |
| **xlsTypeVide** | Type des données saisies | Colonne entièrement vide | [xlsTypeColonne](3080019.md) |
| **xlsVersionIndéfinie** | Format du fichier | Le format sera définit lors de l'enregistrement du fichier. | Variable de type [xlsDocument](1000017464.md) |
| **xlsVersionXls** | Format du fichier | Document de type XLS. | Variable de type [xlsDocument](1000017464.md) |
| **xlsVersionXlsx** | Format du fichier | Document de type XLSX. | Variable de type [xlsDocument](1000017464.md) |
