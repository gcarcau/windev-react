# Fonctions Gantt (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU))

Les fonctions permettant de manipuler une colonne d'un champ Table (ou Table hiérarchique) de type Diagramme de Gantt via une syntaxe préfixée sont les suivantes :
| [<Diagramme de Gantt>.AjouteCongé](1000021118.md) | Déclare une nouvelle période de congés pour une ligne dans une colonne d'un champ Table (ou Table hiérarchique) de type Diagramme de Gantt. |
| --- | --- |
| [<Diagramme de Gantt>.AjouteLien](1000021120.md) | Crée un lien de type "Fin à Début" entre deux tâches affichées dans une colonne d'un champ Table (ou Table hiérarchique) de type Diagramme de Gantt. |
| [<Diagramme de Gantt>.AjouteTâche](1000021121.md) | Ajoute une tâche dans une colonne d'un champ Table (ou Table hiérarchique) de type Diagramme de Gantt. |
| [<Diagramme de Gantt>.ChangeMode](1000021122.md) | Modifie la période (c'est-à-dire le nombre de jours) affichée dans une colonne d'un champ Table (ou Table hiérarchique) de type Diagramme de Gantt. |
| [<Diagramme de Gantt>.HeureAffichée](1000021123.md) | Définit la plage horaire affichée dans une colonne d'un champ Table (ou Table hiérarchique) de type Diagramme de Gantt. |
| [<Diagramme de Gantt>.HeureOuvrable](1000021124.md) | Surcharge les heures ouvrables d'une ligne dans une colonne d'un champ Table (ou Table hiérarchique) de type Diagramme de Gantt. |
| [<Diagramme de Gantt>.JourSemaineOuvré](1000021125.md) | Indique si un jour de la semaine est ouvré dans une colonne d'un champ Table (ou Table hiérarchique) de type Diagramme de Gantt. |
| [<Diagramme de Gantt>.ListeLien](1000021128.md) | Liste les liens présents dans une colonne d'un champ Table (ou Table hiérarchique) de type Diagramme de Gantt. |
| [<Diagramme de Gantt>.ListeTâche](1000021129.md) | Renvoie :   - la liste des tâches comprises entre deux dates données dans une colonne de type Diagramme de Gantt, - toutes les tâches d'une colonne de type Diagramme de Gantt, - une tâche spécifique (sélectionnée ou survolée). |
| [<Diagramme de Gantt>.OrganiseTâche](1000021130.md) | Réorganise les tâches d'un diagramme de Gantt selon les contraintes (dépendances et ressources). |
| [<Diagramme de Gantt>.PositionDateHeure](1000021131.md) | Paramètre le premier jour et la première heure affichés dans une colonne (d'un champ Table ou Table hiérarchique) de type Diagramme de Gantt. |
| [<Diagramme de Gantt>.RécupèreTâche](1000021137.md) | Récupère une tâche à partir de son identifiant dans une colonne (d'un champ Table ou Table hiérarchique) de type Diagramme de Gantt. |
| [<Diagramme de Gantt>.SupprimeLien](1000021138.md) | Supprime des liens dans une colonne d'un champ Table (ou Table hiérarchique) de type Diagramme de Gantt. |
| [<Diagramme de Gantt>.SupprimeTâche](1000021139.md) | Supprime une tâche dans une colonne d'un champ Table (ou Table hiérarchique) de type Diagramme de Gantt. |
| [<Diagramme de Gantt>.SupprimeTout](1000021140.md) | Supprime toutes les tâches dans une colonne d'un champ Table (ou Table hiérarchique) de type Diagramme de Gantt. |
