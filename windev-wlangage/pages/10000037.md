# Information 37 : Optimisez votre boucle POUR

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch)

## Cause

Le code de votre boucle POUR utilise un compteur de type :

- Entier sur 2 octets
- Réel sur 4 octets

## Correction

Utilisez un compteur de type Entier ou Réel.

## Exemple

### Utilisation d'un compteur de type Entier sur 2 octets

**Code provoquant le message d'information**

```wlangage
I est un entier sur 2 octetsPOUR I = 1 À 5 ListeAjoute(LISTE_Liste1,"Elément "+I)FIN
```

**Correction proposée**

Utiliser un compteur de type Entier.

```wlangage
I est un entierPOUR I = 1 À 5 ListeAjoute(LISTE_Liste1,"Elément "+I)FIN
```
