# CaméraDemandePermission (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, iPhone/iPad)

Demande la permission d'utiliser la caméra de l'appareil.

## Exemple

```wlangage
SI CaméraDemandePermission() = Vrai ALORS
	OuvreFenêtreMobile(FEN_Caméra)
FIN
```

## Syntaxe

```wlangage
<Résultat> = CaméraDemandePermission()
```

`<Résultat>` *Booléen*
> - Vrai si la permission d'utiliser la caméra a été accordée,
> - Faux dans le cas contraire.

## Remarques

> _(Android)_ Fonctionnement sous AndroidSi la permission "CAMERA" n'a pas été ajoutée à la liste des permissions de l'application dans l'assistant de génération, la fonction CaméraDemandePermission retournera Faux.A partir de Android 6.0 ou supérieure, l'appel de cette fonction peut provoquer l'affichage d'une boîte de dialogue pour demander à l'utilisateur d'autoriser l'application à utiliser la caméra de l'appareil. Si l'utilisateur ne donne pas son autorisation, cette boîte de dialogue sera affichée à chaque appel de cette fonction.

### Equivalence
Cette fonction est équivalente à la fonction [VidéoDemandePermission](1000022355.md).
