# TexteVersRTF (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Convertit une chaîne texte en chaîne au format RTF.

## Exemple

```wlangage
sTexteEnRTF est une chaîne
sTexteEnRTF = TexteVersRTF("WINDEV est un outil formidable" + RC + ...
		"Le développement devient un jeu d'enfant")

// sTexteEnRTF contient la chaîne avec les balises RTF :
// {\rtf1\ansi\ansicpg1252\deff0{\fonttbl
// {\f0\froman\fcharset0 Times New Roman;} }
// {\*\generator WinDev 19.0.20.0;}
// {WINDEV est un outil formidable\line
// Le développement devient un jeu d'enfant} }
```

## Syntaxe

```wlangage
<Résultat> = TexteVersRTF(<Texte>)
```

`<Résultat>` *Chaîne de caractères*
> Texte au format RTF.
`<Texte>` *Chaîne de caractères*
> Chaîne de caractères au format texte à convertir en RTF.

## Remarques

### Cas particulier
Dans un projet Unicode, une chaîne Unicode contenant des caractères utilisant plusieurs alphabets ne sera pas correctement transformée en RTF. Seuls les caractères de l'alphabet courant seront transformés en RTF. Les autres apparaîtront avec des '?'.

**Composante : wd300rtf.dll**
