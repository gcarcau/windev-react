# ChaîneVersJSON (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Convertit une chaîne au format JSON en une variable de type JSON.

## Exemple

```wlangage
sJZon est une chaîne ANSI = [
{
"glossary": {
"title": "example glossary",
"GlossDiv": {
"title": "S",
"GlossList": {
"GlossEntry": {
"ID": "SGML",
"SortAs": "SGML",
"GlossTerm": "Standard Generalized Markup Language",
"Acronym": "SGML",
"Abbrev": "ISO 8879:1986",
"GlossDef": {
"para": "A meta-markup language, used to create markup languages such as DocBook.",
"GlossSeeAlso": ["GML", "XML"]
},
"GlossSee": "markup"
}
}
}
}
}
]

jz est un JSON = ChaîneVersJSON(sJZon)
```

## Syntaxe

```wlangage
<Résultat> = ChaîneVersJSON(<Chaîne au format JSON>)
```

`<Résultat>` *Variable de type JSON*
> Variable de type [JSON](1000023611.md) contenant le résultat de la conversion.
> En cas d'échec, la variable [ErreurDétectée](3087001.md) vaut Vrai et la fonction [ErreurInfo](3013008.md) permet de connaître le détail de l'erreur.
`<Chaîne au format JSON>` *Chaîne de caractères*
> Chaîne de caractères contenant les données au format JSON.

**Composante : wd300vm.dll**
