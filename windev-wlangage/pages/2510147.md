# Source (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Widget IOS)

La propriété **Source** peut être utilisée sur :

- **un champ Graphe** : dans ce cas, la propriété **Source** permet de connaître la source de la série : Colonne de table, liste de valeurs, ...
  Remarques :
  - La fonction [grSourceSérie](3042067.md) permet de définir la source de données d'une série.
  - La propriété [SourceDescription](2510148.md) permet de connaître le nom et/ou le contenu de la source de données.
- **une connexion** : dans ce cas, la propriété **Source** permet de :
  - Connaître la source d'une connexion (HFSQL Client/Serveur, OLE DB, ...).
  - Définir la source d'une connexion (HFSQL Client/Serveur, OLE DB, ...). Dans ce cas, si la connexion est actuellement ouverte, elle sera fermée, puis ré-ouverte avec les nouveaux paramètres lors d'un premier accès à un fichier utilisant cette connexion.

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ SI GRF_MonGraphe[3].Source = grColonneTable ALORS
 // Change la source de données
 grSourceSérie(GRF_MonGraphe, 3, grListe, "MaListe")
FIN

## Syntaxe

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Widget IOS, Code Utilisateur (MCU), Ajax)_ Connaître la source de données d'une série Masquer les détails
<Résultat> = <Série>.Source

 <Résultat> : Constante de type entierType de source de données de la série : grColonneTableLa source de données est une colonne de table.grFonctionLa source de données est une fonction WLangage.grListeLa source de données est un champ Liste.grProgrammationLa source de données est une liste de valeurs.grRubriqueLa source de données est une rubrique d'un fichier.grTableauLa source de données est un tableau. <Série> : Chaîne de caractèresSérie à manipuler. Utilisez la notation : <Nom du graphe>[<Numéro de la série>].

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), PHP, Ajax, HFSQL Client/Serveur, OLE DB, Connecteurs Natifs (Accès Natifs))_ Connaître la source d'une connexion Masquer les détails
<Source de données> = <Connexion manipulée>.Source

 <Source de données> : Chaîne de caractèresNom du serveur (dans le cas d'une connexion HFSQL Client/Serveur, SQL Server, Oracle, MySQL, ...)Nom du fichier source de données (dans la cas d'une connexion Access, XML, xBase, ...) <Connexion manipulée> : Chaîne de caractères ou variable de type ConnexionNom de la connexion manipulée. Ce nom a été défini :soit sous l'éditeur d'analyses,soit avec les fonctions HDécritConnexion ou HOuvreConnexion,soit avec le type Connexion.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax, HFSQL Client/Serveur, OLE DB, Connecteurs Natifs (Accès Natifs))_ Définir la source de données de la connexion Masquer les détails
<Connexion manipulée>.Source = <Source de données>

 <Connexion manipulée> : Chaîne de caractères ou variable de type ConnexionNom de la connexion manipulée. Ce nom a été défini :soit sous l'éditeur d'analyses,soit avec les fonctions HDécritConnexion ou HOuvreConnexion,soit avec le type Connexion. <Source de données> : Chaîne de caractèresNom du serveur ou adresse IP du serveur (dans le cas d'une connexion HFSQL Client/Serveur, SQL Server, Oracle, MySQL, ...).Nom du fichier source de données (dans la cas d'une connexion Access, XML, xBase, ...).

## Remarques

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax, HFSQL Client/Serveur, OLE DB, Connecteurs Natifs (Accès Natifs))_ EquivalenceLa propriété Serveur est équivalente à la propriété Source.Ces deux propriétés sont conservées pour améliorer la lisibilité du code. En effet, lors de la connexion (HFSQL Client/Serveur, SQL Server, Oracle, MySQL, ...), la propriété Serveur a plus de sens car il est nécessaire d'indiquer un nom de serveur.Par contre, lors de la connexion Access, XML, xBase, la propriété Source a plus de sens car il est nécessaire d'indiquer un fichier.
