# grCrée (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Mac Catalyst)

Crée un graphe d'un type spécifié.
**Remarques** :

- Il est conseillé de créer directement un champ Graphe plutôt que d'utiliser la fonction **grCrée**. En effet, le champ Graphe offre beaucoup plus de possibilités.
- Cette fonction permet uniquement de créer un graphe par programmation. Cette fonction ne peut pas être utilisée dans l'éditeur de fenêtres, de pages ou d'états.

> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Les graphes.

## Exemple

```wlangage
// Création d'un histogramme
// (avec sauvegarde des paramètres modifiés par l'utilisateur)
grCrée("MonGraphe", grHisto)
```

## Syntaxe

```wlangage
grCrée(<Nom du graphe> , <Type de graphe> [, <Persistance>])
```

> Nom du graphe à créer. Ce nom sera utilisé dans toutes les fonctions de gestion des graphes.

## Remarques

### Créer et dessiner un graphe par programmation
Pour créer et dessiner un graphe :

- créez le graphe (fonction **grCrée**),
- ajoutez les données (fonctions [grAjouteDonnée](3042023.md), [grBourseAjouteDonnée](3042009.md) et [grNuageAjouteDonnéeXY](3042032.md)),
- définissez la destination du graphe à l'aide des fonctions suivantes :
  - [grDestinationBMP](3042018.md),
  - [grDestinationChamp](3042020.md),
  - [grDestinationEMF](3042017.md),
  - [grDestinationFen](3042031.md),
  - [grDestinationImage](1000020952.md),
  - [grDestinationWMF](3042019.md).
- dessinez le graphe (fonction [grDessine](3042026.md)).

### Tracer plusieurs graphes simultanément
A un instant donné, il ne peut pas exister plusieurs graphes avec le même nom.
Pour tracer plusieurs graphes en même temps (dans une ou plusieurs fenêtres par exemple), il est nécessaire d'utiliser des noms de graphes différents.

### Graphes et threads
Un seul graphe peut être manipulé dans un thread.
Conséquences :

- Deux threads ne peuvent pas manipuler le même graphe.
- Un graphe créé dans un thread est automatiquement détruit à la fin de ce thread. Le graphe existe dans le thread qui contient l'appel à la fonction **grCrée**.

### Valeurs par défaut d'un graphe créé par programmation
Les valeurs par défaut d'un graphe sont les suivantes :

- Menu contextuel activé (paramétrable avec les fonctions [grMenu](3042035.md) et [grOptionMenu](3042042.md)).
   Les menus contextuel ne sont pas disponibles.
- Graduation automatique des axes (paramétrable avec la fonction [grGraduation](3042027.md)).
- Les couleurs sont sélectionnées selon un ordre prédéfini parmi un éventail de 13 couleurs (paramétrable avec la fonction [grCouleurSerie](3042013.md)).
- Les couleurs sont dégradées (paramétrable avec la fonction [grDégradé](3042029.md)).
- Taille fichier (paramétrable avec la fonction [grFenTaille](3042016.md)).
- Taille fenêtre (paramétrable avec la fonction [grFenTaille](3042016.md)).
   L'affichage dans une fenêtre n'est pas disponible.
- Pas d'étiquette pour les séries (paramétrable avec la fonction [grEtiquetteSérie](3042024.md)).
- Pas de libellé pour les éléments (paramétrable avec les fonctions [grEtiquetteCatégorie](3042015.md) et [grLibellé](3042046.md)).
- Pas de légende (paramétrable avec la fonction [grLégende](3042047.md)).
- Pas de titre pour le graphe (paramétrable avec la fonction [grTitre](3042056.md)).
- Pas de titre pour les axes (paramétrable avec la fonction [grTitreAxe](3042057.md)).
- Pas de quadrillage de fond (paramétrable avec la fonction [grQuadrillage](3042052.md)).
- Pas de données (ajout d'éléments avec la fonction [grAjouteDonnée](3042023.md)).
- Pas de destination (paramétrable avec les fonctions [grDestinationBMP](3042018.md), [grDestinationChamp](3042020.md), [grDestinationEMF](3042017.md), [grDestinationFen](3042031.md) et [grDestinationWMF](3042019.md)).
- Pas d'affichage du graphe (pour dessiner le graphe, utilisez la fonction [grDessine](3042026.md)).
- Pas de relief (paramétrable avec la fonction [grRelief](3042051.md)).
- Pour les graphes en secteurs, l'angle de départ est égal à 0 (paramétrable avec la fonction [grSecteurAngleDépart](3042022.md)).
- Pour les histogrammes et les graphes boursiers de type Minimum/Maximum, l'espace entre deux catégories est égal à 10 pixels (paramétrable avec la fonction [grHistoEspacement](3042014.md)).
- Pour les nuages de points, les points sont reliés et de taille égale à 1 (paramétrable avec les fonctions [grNuageReliePoint](3042040.md) et [grNuageTaillePoint](3042041.md)).
