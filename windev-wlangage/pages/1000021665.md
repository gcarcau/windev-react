# Fonctions HTTP (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Les fonctions suivantes (syntaxe préfixée) permettent de manipuler des pages Internet, d'envoyer des formulaires HTTP, ... :

| [<Variable httpRéponse>.RécupèreCookie](1000021633.md) | Récupère les cookies lus dans la variable [httpRéponse](1000021165.md) (contenant le résultat de la fonction [<Variable httpRequête>.Envoie](1000021624.md)). |
| --- | --- |
| [<Variable httpRequête>.EcritCookie](1000021607.md) | Ajoute ou modifie un cookie dans une requête HTTP. |
| [<Variable httpRequête>.Envoie](1000021624.md) | Envoie une requête HTTP et attend la réponse du serveur HTTP. |
| [<Variable httpRequête>.EnvoieAsynchrone](1410091297.md) | Envoie une requête HTTP en mode asynchrone : le programme continue de s'exécuter et la réponse est traitée par une procédure spécifique. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.** |
| [<Variable httpRequête>.GèreCookie](1000021608.md) | Active ou désactive la gestion des cookies dans une requête [HTTPRequête](3043007.md). |
| [<Variable httpRequête>.LitCookie](1000021621.md) | Retourne la valeur d'un cookie reçu suite à une requête HTTP. |
| [<Variable httpRequête>.RAZCookie](1000021622.md) | Supprime l'ensemble des cookies (globalement ou pour un domaine) stockés par les appels à la fonction [HTTPRequête](3043007.md). |
| [<Variable httpRequête>.RécupèreCookie](1000021627.md) | Récupère les cookies lus par un appel à la fonction [<Variable httpRequête>.Envoie](1000021624.md) pour un domaine HTTP. |
| [<Variable httpRequête>.RemplaceCookie](1000021623.md) | Remplace l'ensemble des cookies stockés pour un domaine par la fonction [<Variable httpRequête>.Envoie](1000021624.md). |
| [<Variable restRequête>.Envoie](1410089811.md) | Envoie une requête REST et attend la réponse du serveur. |
