# CombinaisonVérifieNom (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Apple Watch) · **Autres** (Procédures stockées)

Vérifie si une combinaison d'une ou plusieurs options connues par leurs noms est valide.

## Exemple

```wlangage
// Description de la combinaison
UneCombinaison est une Combinaison
	Option1
	Option2
FIN

// Renvoie Vrai
CombinaisonVérifieNom(UneCombinaison, "Option1")

// Renvoie Vrai
CombinaisonVérifieNom(UneCombinaison, "Option1+Option2")

// Renvoie Faux
CombinaisonVérifieNom(UneCombinaison, "Option3")
```

## Syntaxe

```wlangage
<Résultat> = CombinaisonVérifieNom(<Combinaison> , <Options>)
```

`<Résultat>` *Booléen*
> - Vrai si une combinaison d'une ou plusieurs options connues par leurs noms est valide,
> - Faux dans le cas contraire.
`<Combinaison>` *Variable de type Combinaison*
> Nom de la variable de type [Combinaison](1514074.md) à manipuler.
`<Options>` *Chaîne de caractères*
> Options du type [Combinaison](1514074.md) à vérifier. Si plusieurs options sont manipulées, elles doivent être séparées par l'opérateur '+'. Exemple : "Option1 + Option2".
