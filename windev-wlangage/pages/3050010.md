# ETBinaire (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Renvoie le résultat du ET logique (bit à bit) entre deux valeurs.

## Exemple

```wlangage
// Récupération du ET logique
ResETBinaire = ETBinaire(6, 6)  // Renvoie 6
ResETBinaire = ETBinaire(6, 2)  // Renvoie 2
```

## Syntaxe

```wlangage
<Résultat> = ETBinaire(<Valeur 1> , <Valeur 2>)
```

`<Résultat>` *Entier*
> Résultat du ET logique.
`<Valeur 1>` *Entier*
> Première valeur à tester.
`<Valeur 2>` *Entier*
> Seconde valeur à tester.

## Remarques

### Calcul bit à bit
**ETBinaire** effectue le calcul bit à bit entre <Valeur1> et <Valeur2> selon la table suivante :

|  | 0 | 1 |
| --- | --- | --- |
| 0 | 0 | 0 |
| 1 | 0 | 1 |

### Opérateur binaire

- La fonction **ETBinaire** est équivalente à l'opérateur binaire **&**. Pour plus de détails, consultez [Opérateurs binaires](1512009.md).
- Le résultat de la fonction **ETBinaire** est exact sur des entiers sur 4 octets. Son utilisation avec des entiers sur 8 octets provoque un débordement de capacité.
- L'opérateur binaire **&** permet de faire des opérations sur des entiers sur 8 octets.
