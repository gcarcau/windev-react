# Procédure WLangage appelée par la fonction AppliContrôle

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Procédure (également appelée "Callback") appelée par la fonction [AppliContrôle](3013003.md) pour traiter les messages du contrôle à distance. Cette procédure doit être une procédure globale.

## Exemple

```wlangage
// Code d'initialisation du projet
// Personnalisation avec procédure
AppliContrôle("C:\MonAppli\FicStop.Txt", AppliControle_Callback)
// ----------------------------------
// -- Procédure globale AppliControle_Callback
PROCÉDURE AppliControle_Callback(ModeAccès, MessageAAfficher, TempsAff)
SELON ModeAccès
	CAS acInterdit
		SI NomUser <> "ADMIN" ALORS Ouvre(FEN_ConnexionImpossible)
	CAS acAvertissement
		SI NomUser <> "ADMIN" ALORS Info(MessageAAfficher)
	CAS acArrêt
		SI NomUser <> "ADMIN" ALORS FinProgramme()
FIN
```

## Syntaxe

```wlangage
AppliContrôle_Callback(<Mode> , <Message> , <Temps d'affichage>)
```

`<Mode>` *Constante de type Entier*
> Mode de contrôle à distance en cours :
>
> | *acArrêt* | Arrêt de l'application. |
> | --- | --- |
> | *acAvertissement* | Avertissement d'un arrêt imminent. |
> | *acInterdit* | Accès interdit à l'application. Attention : Lors d'un arrêt de l'application, l'arrêt du programme n'est pas fait automatiquement : votre code doit comporter l'instruction [FinProgramme](3013033.md) pour terminer l'application. |
`<Message>` *Chaîne de caractères*
> Message correspondant au mode en cours.
`<Temps d'affichage>` *Entier*
> Temps d'affichage maximal d'une éventuelle fenêtre (en secondes).
