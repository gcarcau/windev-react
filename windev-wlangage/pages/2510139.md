# XImage (Propriété)

> **Disponible :** **WINDEV** (Windows, Java) · **WINDEV Mobile** (Android)

La propriété **XImage** permet de connaître et de modifier l'origine (abscisse) de la portion de l'image qui sera affichée dans un champ Image ou dans le fond d'un champ Graphe.
**Rappel** : L'origine de l'image correspond au point de l'image qui va être affiché dans le coin haut gauche du champ. Par défaut, **XImage** = 0.

## Exemple

```wlangage
// Connaître l'origine de l'image affichée dans le champ "IMG_Car"
AbscisseSource = IMG_Car.XImage
```

## Syntaxe

#### Connaître l'abscisse de la portion d'image affichée

```wlangage
<Résultat> = <Champ manipulé>.XImage
```

`<Résultat>` *Entier*
> Abscisse de la portion d'image qui sera affichée dans le champ (en pixels).
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.

#### Modifier l'abscisse de la portion d'image affichée

```wlangage
<Champ manipulé>.XImage = <Nouvelle abscisse>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.
`<Nouvelle abscisse>` *Entier*
> Nouvelle abscisse de la portion d'image qui sera affichée dans le champ (en pixels). Cette valeur doit être positive.

## Remarques

### Définition de la portion d'image
Un champ Image permet d'afficher une portion de l'image contenue dans le fichier image associé. Pour définir la portion d'image affichée dans le champ Image, utilisez les propriétés suivantes :

- **XImage** : permet de définir l'origine X de la portion d'image.
- [YImage](2510046.md) : permet de définir l'origine Y de la portion d'image.
- [HauteurImage](2510044.md) : permet de définir la hauteur de la portion d'image.
- [LargeurImage](2510066.md) : permet de définir la largeur de la portion d'image.

|  | Dans cet exemple, seule la portion d'image affichée dans le cadre rouge sera affichée dans le champ Image. Le mode d'affichage de cette portion d'image sera celui défini pour le champ Image. |
| --- | --- |

### Limites
La propriété **XImage** s'applique uniquement aux champs Image et aux champs Graphe d'une fenêtre. Cette propriété ne s'applique pas aux champs Image associés à une image animée.
> _(Android, Java)_ La propriété XImage s'applique uniquement aux champs Image.
