# GraveurEtat (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Renvoie l'état actuel du graveur en cours. Ce graveur peut être sélectionné grâce à la fonction [GraveurSélectionne](3061012.md).
**Remarque** : Pour connaître l'ensemble des graveurs disponibles à partir du poste en cours, utilisez la fonction [GraveurListe](3061009.md).

## Exemple

```wlangage
// Connaître l'état du graveur
ResEtat est un entier
ResEtat = GraveurEtat()
// État du graveur
SELON ResEtat
	// Gravure en cours
	CAS graveurGrave
		Info("Le graveur est en cours de gravure")
	// Graveur inactif
	CAS graveurInactif
		Info("Le graveur est inactif")
	// Graveur en cours d'utilisation
	CAS graveurUtiliséExclusivement
		Info("Le graveur est en cours d'utilisation")
	CAS graveurPrépareEffacement
		Info("Effacement en préparation")
	CAS graveurPrépareGravure
		Info("Gravure en préparation")
FIN
```

## Syntaxe

```wlangage
<Résultat> = GraveurEtat()
```

`<Résultat>` *Constante de type Entier*
> - État actuel du graveur :
>   Le graveur peut être dans un des états suivants :
>   | *graveurGrave* | Graveur en cours de gravure |
>   | --- | --- |
>   | *graveurInactif* | Graveur inactif |
>   | *graveurPrépareEffacement* | Graveur en cours de préparation pour effacer des fichiers |
>   | *graveurPrépareGravure* | Graveur en cours de préparation pour graver des fichiers |
>   | *graveurUtiliséExclusivement* | Graveur en cours d'utilisation par l'application en cours (effacement de données par exemple) ou par une autre application |
> - -1 en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.

## Remarques

### Configuration nécessaire

> _(WINDEV)_ La gravure de CD est disponible uniquement sous Windows XP et supérieur. La gravure de DVD est disponible sous Windows Vista, et sous Windows XP en utilisant la mise à jour KB932716 pour Windows XP (cette mise à jour doit être téléchargée depuis le site de Microsoft et installée car elle n'est pas prise en compte par le mécanisme de Live Update).

> _(WEBDEV - Code Serveur)_ La gravure de CD et DVD sera réalisée sur le serveur Web. Pour graver des CD ou des DVD, le serveur doit être sous Windows XP ou supérieur. Pour graver des CD sous Windows 2003 Serveur, il est nécessaire d'activer le service de gravure IMAPI (nommée "Service COM de gravage de CD IMAPI"). Pour graver des DVD sous Windows 2003 Serveur, il est nécessaire d'installer en plus la mise à jour KB932716.

**Composante : wd300grv.dll**
