# MasqueFormate (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Formate une chaîne de caractères à l'aide d'une variable de type [MasqueDeSaisie](1000024886.md). La chaîne de caractères est formatée comme pour l'affichage dans un champ de saisie utilisant ce masque.

## Exemple

```wlangage
MonMasque est un MasqueDeSaisie = MasqueNuméroDeTéléphone("FR")
Trace(MasqueFormate(MonMasque, "+33467032032"))
```

## Syntaxe

```wlangage
<Résultat> = MasqueFormate(<Masque à appliquer> , <Chaîne>)
```

`<Résultat>` *Chaîne de caractères*
> - Chaîne formatée en fonction du masque spécifié.
> - Chaîne vide ("") en cas d'erreur.
`<Masque à appliquer>` *Variable de type MasqueDeSaisie*
> Nom de la variable de type [MasqueDeSaisie](1000024886.md) à utiliser pour formater la chaîne de caractères.
`<Chaîne>` *Chaîne de caractères*
> Chaîne de caractères à formater. si ce paramètre est invalide, <Résultat> correspond à chaîne vide ("").

**Classification Métier / UI : Code neutre**

**Composante : wd300obj.dll**
