# docTabulation (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Le type **docTabulation** permet de définir les caractéristiques d'une tabulation personnalisée. Cette tabulation personnalisée est associée à un paragraphe faisant partie d'un document de type Traitement de texte. Les caractéristiques de cette tabulation peuvent être définies et modifiées à l'aide de différentes propriétés du WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
MonDoc est un Document = MonChampDoc
// Récupération du premier paragraphe
Parag est un docParagraphe = MonDoc.Paragraphe[1]
// Tabulation à 3 cm
Tabul est une docTabulation
Tabul.Position = 30
// Ajout de la tabulation aux tabulations personnalisées du paragraphe
Ajoute(Parag.MiseEnPage.TabulationPerso, Tabul)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type docTabulation
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **docTabulation** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| CaractèreRemplissage | Chaîne de caractères ou constante | Caractère de remplissage de l'espace avant la tabulation.  Cette propriété peut correspondre à une des constantes suivantes :   - *docTabulationCaractèreAucun* : Caractère vide (pas de caractère de remplissage). - *docTabulationCaractèrePoint* : Point. - *docTabulationCaractèrePointCentré* : Point centré. - *docTabulationCaractèreSouligné* : Souligné. - *docTabulationCaractèreTraitUnion* : Trait d'union.  Par défaut, cette propriété correspond à un caractère vide. |
| Position | Réel | Position de la tabulation en millimètres depuis le bord gauche du paragraphe (0 par défaut). |
| Type | Constante optionnelle de type Entier | Type de la tabulation à ajouter :  - *tabTypeBarre* : Une barre verticale sera affichée au niveau de la tabulation. - *tabTypeCentre* : Le centre du texte sera aligné sur la tabulation. - *tabTypeDécimale* : Le séparateur décimal sera aligné sur la tabulation. - *tabTypeDroite* : Le bord droit du texte sera aligné sur la tabulation. - *tabTypeGauche* (Valeur par défaut) : Le bord gauche du texte sera aligné sur la tabulation. |
