# HTMLSauve (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Sauve le contenu d'une variable de type [htmlDocument](1000025910.md) dans un fichier HTML.

## Exemple

```wlangage
// Chargement du document
d est un htmlDocument = HTMLOuvre("..\Modèles\Modèle1.html", depuisFichier)

// Modifications du document
// ...

// Sauvegarde du document modifié
HTMLSauve(d, "..\Génération\" + NomDocument)
```

## Syntaxe

```wlangage
HTMLSauve(<Document> [, <Nom du fichier>])
```

`<Document>` *Variable de type htmlDocument*
> Nom de la variable de type [htmlDocument](1000025910.md) correspondant au document à manipuler.
`<Nom du fichier>` *Chaîne de caractères optionnelle*
> Nom du fichier à enregistrer. Si le nom du fichier n'est pas précisé et que le document avait été ouvert à partir d'un fichier, le fichier d'origine est écrasé.

**Classification Métier / UI : Code métier**

**Composante : wd300html.dll**
