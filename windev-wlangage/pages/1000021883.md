# BTLEDéconnecte (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Permet de se déconnecter d'un périphérique Bluetooth Low Energy.

## Exemple

```wlangage
monPeriph est un btlePériphérique
BTLEConnecte(monPeriph)
...
BTLEDéconnecte(monPeriph)
```

## Syntaxe

```wlangage
BTLEDéconnecte(<Périphérique>)
```

`<Périphérique>` *Variable de type btlePériphérique*
> Nom de la variable de type [btlePériphérique](1000022054.md) représentant le périphérique Bluetooth à manipuler.

## Remarques

### Divers
La fonction [BTLEListePériphérique](1000021882.md) permet de lister les périphériques Bluetooth LE accessibles depuis l'appareil.

> _(Android)_ Permissions requisesL'utilisation de cette fonction entraîne la modification des permissions requises par l'application.Permission requise : BLUETOOTH.Cette permission permet aux applications de se connecter à des services Bluetooth.

**Versions nécessaires**

- **Applications ANDROID** :
  - Les fonctions WLangage Bluetooth Low Energy sont disponibles uniquement sur les appareils disposant d'une version d'Android supérieure ou égale à la version 4.3 (api level 18).
  - Si la fonction est utilisée avec une version antérieure du système, une erreur fatale sera déclenchée.
  - Pour connaître la version du système Android sur laquelle s'exécute l'application, utilisez la fonction [SysVersionAndroid](1000019785.md).
- **Applications iOS** :
  Les fonctions WLangage Bluetooth Low Energy sont disponibles uniquement sur les appareils disposant d'iOS 9.
- **Applications WINDEV** :
  - Les fonctions WLangage Bluetooth Low Energy sont disponibles uniquement sur :
    - les PC gérant le Bluetooth Low Energy version 5 minimum.
    - les PC utilisant une clé Bluetooth gérant le Bluetooth Low Energy version 5 minimum.
  - Le gestionnaire de périphériques de Windows permet en cas de doute de contrôler la version du Bluetooth d'un poste de travail : [https://support.microsoft.com/en-us/windows/what-bluetooth-version-is-on-my-pc-f5d4cff7-c00d-337b-a642-d2d23b082793](https://support.microsoft.com/en-us/windows/what-bluetooth-version-is-on-my-pc-f5d4cff7-c00d-337b-a642-d2d23b082793)
  - L'appairage doit être fait au niveau de Windows. Ainsi, la fonction [BTLEListePériphérique](1000021882.md) ne permettra d'énumérer que les périphériques qui sont visibles et associés dans les réglages Bluetooth de Windows.
