# Proprietés associées à un champ Agenda

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

## Présentation

Il est possible d'utiliser des propriétés WLangage sur un champ Agenda :

- dans une fenêtre.
- dans une page.
- dans un état.
