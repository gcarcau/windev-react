# Comment donner le focus à un champ d'une fenêtre ?

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android)

## Principe

Pour se positionner en saisie (ou donner le focus) à un champ, vous disposez de 2 méthodes :

- Utilisation de la fonction [DonneFocusEtRetourUtilisateur](1410088107.md) ou [DonneFocus](3025001.md).
- Utilisation de la fonction [EcranPremier](3025039.md).

## Première méthode : fonction DonneFocusEtRetourUtilisateur ou DonneFocus

La fonction [DonneFocusEtRetourUtilisateur](1410088107.md) (ou la fonction [DonneFocus](3025001.md)) donne le focus au champ indiqué et permet de revenir directement en saisie sur la fenêtre **sans exécuter le code WLangage placé après l'appel de la fonction**.
Exemple de code :

```wlangage
SI SAI_CODE = "" ALORS
	DonneFocusEtRetourUtilisateur(SAI_CODE)
	// Code non exécuté
SINON
	DonneFocusEtRetourUtilisateur(SAI_INTITULE)
	// Code non exécuté
FIN
// Code non exécuté
```

## Seconde méthode : fonction EcranPremier

La fonction [EcranPremier](3025039.md) permet de mémoriser le champ qui doit prendre le focus. Le code WLangage suivant l'appel de la fonction continue de s'exécuter. Il est ainsi possible de changer le champ sur lequel se positionner avant de retourner dans la saisie sur la fenêtre.
Exemple de code :

```wlangage
// En fonction des retours des traitements 1 et 2
// on se positionne à la fin du traitement sur le champ SAI_QTE ou SAI_CODEREMISE

// Exécution traitement partie 1
...
SI nResPartie1 = 0 ALORS EcranPremier(SAI_QTE)
...
// Exécution traitement partie 2
...
SI bResPartie2 = Faux ALORS EcranPremier(SAI_CODEREMISE)
...
```
