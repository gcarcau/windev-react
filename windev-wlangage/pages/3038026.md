# FenExtPosY (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Renvoie la position verticale du coin haut gauche d'une fenêtre par rapport au coin haut gauche de l'écran.
> _(WINDEV, Java)_ Fenêtres sous Windows : Remarque : La fonction FenExtPosY est équivalente à la propriété Y (<Fenêtre>.Y).

> _(Android, iPhone/iPad)_ Fenêtres mobile : deux cas sont à prendre en compte : Cas des fenêtres mobiles maximisées : Cette position correspond toujours à 0.Cas des fenêtres mobiles non maximisées et des fenêtres popup : Cette position correspond à la propriété Y.

Nouveauté 2025

> _(Android)_ Cette fonction est désormais disponible pour les applications Android.

> _(iPhone/iPad)_ Cette fonction est désormais disponible pour les applications iPhone/iPad.

## Exemple

```wlangage
// Position verticale de la fenêtre "FEN_SaisieClient" par rapport à l'écran
ResPosV = FenExtPosY(FEN_SaisieClient)
```

## Syntaxe

```wlangage
<Résultat> = FenExtPosY([<Fenêtre>])
```

`<Résultat>` *Entier*
> Position verticale ou ordonnée (en pixels) du coin haut gauche de la fenêtre par rapport au coin haut gauche de l'écran.
>
> > _(Android, iPhone/iPad)_ Si la fenêtre manipulée correspond à une fenêtre mobile maximisée, cette position vaut 0.
`<Fenêtre>` *Nom de fenêtre optionnel*
> Nom ou alias de la fenêtre à manipuler. Si ce paramètre n'est pas précisé ou correspond à une chaîne vide (""), la position verticale de la fenêtre en cours est retournée.

**Composante : wd300obj.dll**
