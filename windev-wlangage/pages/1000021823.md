# FormuleRubriqueCalculée (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **FormuleRubriqueCalculée** permet de :

- Connaître la formule SQL définissant la valeur d'une rubrique de type formule (ou rubrique calculée). Cette rubrique a été définie sous l'éditeur d'analyses ou définie par programmation.
- Définir la formule SQL donnant la valeur d'une rubrique de type formule (lors de la description de la rubrique par programmation uniquement).

> _(Connecteurs Natifs (Accès Natifs))_ Cette propriété est disponible pour le Connecteur Natif MySQL.

## Exemple

```wlangage
UnFichier est une Description de Fichier
UneRubrique est une Description de Rubrique
UneRubrique.Nom = "DateCmd"
UneRubrique.FormuleRubriqueCalculée = "'Ecrit par ' + CURRENT_USER + ' le ' + SYSDATE"
UneRubrique.PersistanceRubriqueCalculée = Vrai
HDécritRubrique(UnFichier, UneRubrique)
```

## Syntaxe

#### Connaître la formule SQL définissant la valeur d'une rubrique calculée

```wlangage
<Résultat> = <Fichier de données>.<Rubrique>.FormuleRubriqueCalculée
```

`<Résultat>` *Chaîne de caractères*
> Formule SQL définissant la valeur de la rubrique.
`<Fichier de données manipulé>` *Nom de fichier de données*
> Nom du fichier de données manipulé.
`<Rubrique manipulée>` *Nom de rubrique*
> Nom de la rubrique manipulée.

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, iPhone/iPad, Widget IOS, Mac Catalyst, Code Utilisateur (MCU), Ajax)_ Définir la formule SQL donnant la valeur d'une rubrique calculée Masquer les détails
<Rubrique manipulé>.FormuleRubriqueCalculée = <Formule SQL>

 <Rubrique manipulé> : Nom de rubriqueNom de la rubrique manipulée. Ce nom vient d'être défini grâce au type Description de Rubrique. <Formule SQL> : Chaîne de caractèresFormule SQL définissant la valeur de la rubrique.

## Remarques

Une rubrique de type formule (ou rubrique calculée) est une rubrique dont le contenu est calculé en fonction de la formule SQL associée et des valeurs de rubriques dans l'enregistrement courant. Pour plus de détails, consultez [Editeur d'analyses : les différents types de rubriques](2011026.md).
