# PopupFermePage (Fonction)

> **Disponible :** **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur)

Masque une page affichée en popup via la fonction [PopupAffichePage](1410087258.md).

## Exemple

```wlangage
// Ferme la page affichée en popup
PopupFermePage(PAGE_DétailsProduit)
```

## Syntaxe

```wlangage
PopupFermePage([<Page> [, <Valeur renvoyée>]])
```

`<Page>` *Nom de page optionnel*
> Nom de la page affichée en popup qui sera masquée. Cette page doit avoir été affichée par la fonction [PopupAffichePage](1410087258.md). Si ce n'est pas le cas, la fonction **PopupFermePage** n'a aucune action.
>
> Si la fonction **PopupFermePage** est utilisée dans le code de la page principale, ce paramètre est obligatoire : le nom de la page popup à fermer doit être précisée.
> Si la fonction **PopupFermePage** est utilisée dans le code de la page courante (affichée comme popup), ce paramètre n'est pas obligatoire : la page courante est fermée.
`<Valeur renvoyée>` *Type correspondant à la valeur renvoyée (optionnel)*
> > _(WEBDEV - Code Navigateur)_ Valeur renvoyée par la page lors de sa fermeture. Cette valeur est récupérée uniquement si la page a été ouverte avec la fonction PopupAffichePage.Il est possible de renvoyer :des types simples : chaîne de caractères, etc.des types avancés : structure, etc.

## Remarques

Les navigateurs ne rafraîchissent pas l'affichage au milieu d'un code Javascript : les fonctions [PopupAffichePage](1410087258.md) et **PopupFermePage** doivent être utilisées dans des traitements/événements différents. Si ces fonctions sont utilisées dans le même traitement/événement, la page Popup n'est pas affichée.
