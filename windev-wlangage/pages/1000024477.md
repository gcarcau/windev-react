# URLAuth (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

La propriété **URLAuth** permet de connaître et de définir l'URL d'autorisation à utiliser (première URL du standard OAuth 2.0). Cette propriété est utilisable sur :

- une variable de type [OAuth2Paramètres](1000022212.md).
- une variable de type [gpwOAuthParamètres](1000024751.md).
