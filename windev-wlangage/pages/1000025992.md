# EditeurHTMLRécupèreSélection (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Récupère en mode asynchrone la sélection effectuée dans un champ Editeur HTML.
**Remarque** : Cette fonction est notamment utile pour les applications Android et iOS pour lesquelles la propriété WLangage [Sélection](1000023033.md) n'est pas disponible en lecture.

## Exemple

```wlangage
// Grise ou non le bouton Ouvrir selon la sélection
EditeurHTMLRécupèreSélection(EDHTML_MonEditeurHTML, EditeurHTMLRécupèreSélection_Callback)
PROCÉDURE INTERNE EditeurHTMLRécupèreSélection_Callback(Sélection est un edtHTMLSélection)
   	BTN_Ouvrir.Grisé = PAS Gauche(Sélection.Texte, "https:\\" )
FIN
```

## Syntaxe

```wlangage
EditeurHTMLRécupèreSélection(<Champ Editeur HTML> , <Procédure WLangage>)
```

`<Champ Editeur HTML>` *Nom de champ*
> Nom du champ Editeur HTML manipulé.
`<Procédure WLangage>` *Nom de procédure*
> Procédure WLangage (également nommée "callback") exécutée lorsque la sélection a été récupérée. Cette procédure est de la forme :
>
>
> ```wlangage
> PROCEDURE <Nom de la procédure>(MaSélection est un edtHTMLSélection)
> ```
>
>
> où <MaSélection> est une variable de type [edtHTMLSélection](1000026093.md) correspondant à la sélection en cours dans le champ Editeur HTML.
