# Constantes de pilotage du serveur d'application WEBDEV

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Les constantes utilisées pour le pilotage du serveur d'application WEBDEV sont les suivantes :

| Constante | Détail | Fonction |
| --- | --- | --- |
| **adminWBEcraseSiExistant** | Permet la recréation d'un compte existant. | [AdminWBCréeCompte](1410089450.md) |
| **adminWBTypeSite** | Type d'application : Site. | [AdminWBListeApplication](1410089996.md) [AdminWBSupprimeApplication](1410089999.md) |
| **adminWBTypeWebserviceREST** | Type d'application : Webservice REST. | [AdminWBListeApplication](1410089996.md) [AdminWBSupprimeApplication](1410089999.md) |
| **adminWBTypeWebserviceSOAP** | Type d'application : Webservice SOAP. | [AdminWBListeApplication](1410089996.md) [AdminWBSupprimeApplication](1410089999.md) |
| **adminWBTypeWebSocket** | Type d'application : WebSocket. | [AdminWBListeApplication](1410089996.md) [AdminWBSupprimeApplication](1410089999.md) |
