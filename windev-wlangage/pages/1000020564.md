# FIListeSuivant (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Affiche la fenêtre interne suivante dans la liste des fenêtres internes parcourue par un champ Fenêtre Interne.

## Exemple

```wlangage
FIListeSuivant(FI_ChampFenêtreInterne)
```

## Syntaxe

```wlangage
<Résultat> = FIListeSuivant(<Champ Fenêtre Interne>)
```

`<Résultat>` *Booléen*
> - Vrai si la fenêtre interne suivante a été affichée,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Champ Fenêtre Interne>` *Nom de champ*
> Nom du champ Fenêtre Interne à manipuler.

## Remarques

Le changement de fenêtre interne avec les fonctions **FIListeSuivant** et [FIListePrécédent](1000020565.md) utilise une animation. Pour effectuer un changement sans animation, utilisez la fonction [FIListePosition](1000020562.md).
