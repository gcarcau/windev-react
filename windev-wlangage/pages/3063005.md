# VersPressePapier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Écrit des informations de type texte ou image dans le presse-papiers du système.
Pour écrire des informations de type Texte RTF, utilisez la fonction [VersPressePapierRTF](1000017199.md).

> _(Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)_ Il est possible uniquement d'écrire des informations de type texte dans le presse-papiers de Windows.

## Exemple

```wlangage
Texte est une chaîne
Res est un entier
// Le contenu du champ est copié dans le presse-papiers
Texte = SAI_SAISIE1
Res = VersPressePapier(Texte)
SI Res = Faux ALORS
	Erreur("Erreur lors de l'écriture dans le presse-papiers")
FIN
```

## Syntaxe

#### Écrire du texte dans le presse-papiers

```wlangage
<Résultat> = VersPressePapier(<Texte>)
```

`<Résultat>` *Booléen*
> - Vrai si le texte a été copié dans le presse-papiers,
> - Faux dans le cas contraire.
`<Texte>` *Chaîne de caractères*
> Texte à écrire dans le presse-papiers.

> _(WINDEV, Etats et Requêtes, Java, Code Utilisateur (MCU), WINDEV, WINDEV)_ Copier une image dans le presse-papiers Masquer les détails
<Résultat> = VersPressePapier(<Image> , <Transparence>)

 <Résultat> : BooléenVrai si l'image a été copiée dans le presse-papiers, Faux dans le cas contraire. <Image> : Chaîne de caractères ou variable de type ImageNom du champ Image à copier dans le presse-papiers. Si le champ Image n'appartient pas à la fenêtre en cours, il est possible d'utiliser la notation <Nom Fenêtre>.<Nom champ Image>. Nom de la variable de type Image à copier dans le presse-papiers. <Transparence> : Booléen Vrai (valeur par défaut) pour conserver la transparence de l'image (si possible) lors de la copie vers le presse-papiers, Faux dans le cas contraire.

## Remarques

- La fonction **VersPressePapier** peut être utilisée pour gérer le couper/copier/coller d'informations de type texte ou de type image (BMP).
- La fonction [PressePapier](3063004.md) permet de lire le contenu du presse-papiers. Les informations autres que celles de type texte ou image (binaire, etc.) contenues dans le presse-papiers ne peuvent pas être lues par la fonction [PressePapier](3063004.md).
- La gestion d'informations de type texte au format RTF est réalisée avec les fonctions [VersPressePapierRTF](1000017199.md) et [PressePapierRTF](1000017200.md).
