# Numéro (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android)

La propriété **Numéro** permet de connaître le numéro d'un élément. Cette propriété est utilisable sur :

- une variable de type [Description d'API](1000019149.md).
- une variable de type [gglTéléphone](1000017573.md).
- une variable de type [Téléphone](1000020241.md).
- une variable de type [docSection](1000022685.md).
