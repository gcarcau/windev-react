# Propriétés de gestion des dates et des heures

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Les différentes propriétés de gestion des dates et des heures sont les suivantes :

| [Année](2512095.md) | La propriété **Année** permet de :  - Récupérer l'année d'une variable ou d'une rubrique de type [Date](1514066.md) ou [DateHeure](1514070.md). - Modifier l'année d'une variable ou d'une rubrique de type [Date](1514066.md) ou [DateHeure](1514070.md). |
| --- | --- |
| [EnHeures](1000017296.md) | La propriété **EnHeures** permet de convertir une variable de type Durée en heures. |
| [EnJours](1000017295.md) | La propriété **EnJours** permet de convertir une variable de type Durée en jours. |
| [EnMillisecondes](1000017299.md) | La propriété **EnMillisecondes** permet de convertir une variable de type Durée en millisecondes. |
| [EnMinutes](1000017297.md) | La propriété **EnMinutes** permet de convertir une variable de type Durée en minutes. |
| [EnSecondes](1000017298.md) | La propriété **EnSecondes** permet de convertir une variable de type Durée en secondes. |
| [Heure](2512038.md) | La propriété **Heure** permet de :  - Récupérer l'heure d'une variable de type [Heure](1514068.md), [DateHeure](1514070.md) ou récupérer le nombre d'heures d'une variable de type [Durée](1514069.md). - Modifier l'heure d'une variable de type [Heure](1514068.md), [DateHeure](1514070.md) ou modifier le nombre d'heures d'une variable de type [Durée](1514069.md). - Récupérer l'heure ou le nombre d'heures d'une rubrique de type [Date](1514066.md) (au format "Date et heure" ou "Durée") ou d'une rubrique de type [Heure](1514068.md). - Modifier l'heure ou le nombre d'heures d'une rubrique de type [Date](1514066.md) (au format "Date et heure" ou "Durée") ou d'une rubrique de type [Heure](1514068.md). |
| [Jour](2512043.md) | La propriété **Jour** permet de :  - Récupérer le jour d'une variable de type [Date](1514066.md), [DateHeure](1514070.md) ou récupérer le nombre de jours d'une variable de type [Durée](1514069.md). - Modifier le jour d'une variable de type [Date](1514066.md), [DateHeure](1514070.md) ou modifier le nombre de jours d'une variable de type [Durée](1514069.md). - Récupérer le jour ou le nombre de jours d'une rubrique de type Date (au format "Date", "Date et heure" ou "durée") - Modifier le jour ou le nombre de jours d'une rubrique de type Date (au format "Date", "Date et heure" ou "durée") |
| [Milliseconde](2512062.md) | La propriété **Milliseconde** permet de :  - Récupérer le nombre de millisecondes d'une variable de type [Heure](1514068.md), [DateHeure](1514070.md) ou [Durée](1514069.md). - Modifier le nombre de millisecondes d'une variable de type [Heure](1514068.md), [DateHeure](1514070.md) ou [Durée](1514069.md). - Récupérer les millisecondes ou le nombre de millisecondes d'une rubrique de type Date (au format "Date et heure" ou "durée") - Modifier les millisecondes ou le nombre de millisecondes d'une rubrique de type Date (au format "Date et heure" ou "durée") |
| [Minute](2512050.md) | La propriété **Minute** permet de :  - Récupérer les minutes d'une variable de type [Heure](1514068.md), [DateHeure](1514070.md) ou le nombre de minutes d'une [Durée](1514069.md). - Modifier les minutes d'une variable de type [Heure](1514068.md), [DateHeure](1514070.md) ou le nombre de minutes d'une [Durée](1514069.md). - Récupérer les minutes ou le nombre de minutes d'une rubrique de type Date (au format "Date et heure" ou "durée") ou d'une rubrique de type Heure. - Modifier les minutes ou le nombre de minutes d'une rubrique de type Date (au format "Date et heure" ou "durée") ou d'une rubrique de type Heure. |
| [Mois](2512052.md) | La propriété **Mois** permet de :  - Récupérer le mois d'une variable de type [Date](1514066.md) ou [DateHeure](1514070.md). - Modifier le mois d'une variable de type [Date](1514066.md) ou [DateHeure](1514070.md). - Récupérer le mois d'une rubrique de type Date (au format "Date simple" ou "Date et Heure") - Modifier le mois d'une rubrique de type Date (au format "Date simple" ou "Date et Heure") |
| [PartieDate](2512065.md) | La propriété **PartieDate** permet de :  - Récupérer uniquement la date d'une variable de type [DateHeure](1514070.md). - Modifier uniquement la date d'une variable de type [DateHeure](1514070.md). - Récupérer la date d'une rubrique de type Date (au format "Date et Heure") . - Modifier la date d'une rubrique de type Date (au format "Date et Heure") |
| [PartieHeure](2512069.md) | La propriété **PartieHeure** permet de :  - Récupérer uniquement l'heure d'une variable de type [DateHeure](1514070.md). - Modifier uniquement l'heure d'une variable de type [DateHeure](1514070.md). - Récupérer l'heure d'une rubrique de type Date (au format "Date et Heure") - Modifier l'heure d'une rubrique de type Date (au format "Date et Heure"). |
| [Seconde](2512081.md) | La propriété **Seconde** permet de :  - Récupérer le nombre de secondes d'une variable de type [Heure](1514068.md), [DateHeure](1514070.md) ou [Durée](1514069.md). - Modifier le nombre de secondes d'une variable de type [Heure](1514068.md), [DateHeure](1514070.md) ou [Durée](1514069.md). - Récupérer les secondes ou le nombre de secondes d'une rubrique de type Date (au format "Date et heure" ou "Durée") - Modifier les secondes ou le nombre de secondes d'une rubrique de type Date (au format "Date et heure" ou "Durée") |
