# ImageFond (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

La propriété **ImageFond** permet de connaître et de modifier l'image de fond d'un élément. Cette propriété est utilisable sur :

- une fenêtre ou un champ (bouton, jauge, potentiomètre, champ de saisie HTML). Pour plus de détails, consultez [ImageFond](2510056.md).
- une variable de type [OrgaElement](1000019713.md).
