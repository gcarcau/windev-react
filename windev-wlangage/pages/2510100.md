# PoliceNom (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **PoliceNom** permet de :

- Connaître la police utilisée dans un champ.
- Modifier la police utilisée dans un champ.

## Exemple

```wlangage
// Modifier la police utilisée dans le champ "SAI_NomClient"
SAI_NomClient.PoliceNom = "Arial"
```

## Syntaxe

#### Connaître la police utilisée dans un champ

```wlangage
<Résultat> = <Champ manipulé>.PoliceNom
```

`<Résultat>` *Chaîne de caractères*
> Nom de la police utilisée dans le champ spécifié.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.

#### Modifier la police utilisée dans un champ

```wlangage
<Champ manipulé>.PoliceNom = <Nouvelle police>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.
`<Nouvelle police>` *Chaîne de caractères*
> Nouvelle police utilisée dans le champ spécifié.

## Remarques

### Limites

> _(WINDEV, WEBDEV - Code Serveur, WINDEV Mobile, Etats et Requêtes, iPhone/iPad)_ Dans un état, la propriété PoliceNom peut être utilisée uniquement sur :un champ Lien URL.un champ Libellé.un champ Calculé.un champ Prédéfini.

> _(WINDEV, WINDEV Mobile, WINDEV, WINDEV)_ Dans une fenêtre, la propriété PoliceNom ne peut pas être utilisée sur :un champ Spin, un champ Web Camera, un champ Conférence. Remarque : Cette propriété s'applique sur les champs "Liste image" en mode d'affichage "Liste classique" uniquement.

> _(WEBDEV - Code Serveur)_ Dans une page, la propriété PoliceNom peut être utilisée sur :un champ Libellé,un champ de saisie,un champ Bouton,un champ Interrupteur,un champ Sélecteur,un champ Liste,une colonne d'un champ Table,une cellule d'un champ Table (en lecture uniquement),un champ d'affichage formaté,un champ HTML,un champ Combo,un champ Lien,un champ Libellé HTML,un champ Réglette,un champ Chemin de navigation (sauf en PHP),un champ Arbre,un menu.

> _(Java)_ La propriété PoliceNom s'applique uniquement aux éléments suivants :Champ Bouton.Champ Libellé.Champ Combo.Champ Arbre.Colonne d'un champ Table.

> _(PHP)_ PHP : Fichiers des policesEn PHP, il est nécessaire que les fichiers des polices correspondantes soient accessibles (fichiers ttf). Ces fichiers doivent être présents dans le répertoire du site (répertoire _WEB connu avec la fonction fRepWeb) et nommés de la façon suivante : <Nom de la police normale><Nom de la police normale>_Bold<Nom de la police normale>_Italic<Nom de la police normale>_Italic_Bold
