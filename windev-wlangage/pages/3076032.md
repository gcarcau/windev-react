# telPériphérique (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Sélectionne le périphérique TAPI qui sera utilisé lors des opérations de téléphonie suivantes :

- [telCompose](3076013.md),
- [telDémarreDétectionAppel](3076029.md),

## Exemple

```wlangage
// Récupère la liste des périphériques TAPI
sListeTAPI est une chaîne = telListePériphérique()

// Affiche la liste dans un champ Combo
ListeAjoute(COMBO_TAPI, sListeTAPI)
...
// Sélectionne le périphérique TAPI choisi dans le champ Combo
telPériphérique(COMBO_TAPI[COMBO_TAPI])
```

## Syntaxe

```wlangage
<Résultat> = telPériphérique(<Nom du périphérique>)
```

`<Résultat>` *Booléen*
> - Vrai si le périphérique a été sélectionné. Le périphérique sélectionné sera utilisé pour toutes les prochaines opérations de téléphonie.
> - Faux en cas d'erreur.
`<Nom du périphérique>` *Chaîne de caractères*
> Nom du périphérique à utiliser. La liste des périphériques de téléphonie est connue avec la fonction [telListePériphérique](3076024.md).

## Remarques

### Limitation
Il n'est pas possible d'appeler la fonction **telPériphérique** dans la procédure de détection d'appels (définie grâce à la fonction [telDémarreDétectionAppel](3076029.md)).

### Configuration nécessaire
Les fonctions de téléphonie utilisent la technologie TAPI 2.0 et/ou la technologie TAPI 3.1. Ces technologies sont utilisables sur tous les systèmes.

**Composante : wd300com.dll**
