# <Variable Palette>.Génère (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Génère une palette à partir d'une couleur de base.

## Exemple

```wlangage
MaPalettePerso est une Palette
// Génération de la palette à partir d'une couleur
MaPalettePerso.Génère(0x7F67BE)
// Affectation d'une couleur de la palette à un champ
LIB_Promo.CouleurFond = MaPalettePerso[FondSelection]
```

## Syntaxe

```wlangage
<Palette>.Génère(<Couleur de base> [, <Couleur secondaire>])
```

`<Palette>` *Variable de type Palette*
> Nom de la variable de type [Palette](1000021347.md) correspondant à la palette qui doit être remplacée.
`<Couleur de base>` *Entier*
> Couleur de base de la palette, utilisée pour générer toutes les couleurs de la palette. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md),
> - une variable de type [Couleur](1000019661.md).
`<Couleur secondaire>` *Entier optionnel*
> Couleur secondaire de la palette.
>
> - Si ce paramètre n'est pas spécifié, la couleur secondaire sera automatiquement calculée.
> - Si ce paramètre est spécifiée, la couleur secondaire sera forcée avec la valeur indiquée.
>
> Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md),
> - une variable de type [Couleur](1000019661.md).
>
>
> **Attention** : Ce paramètre est disponible uniquement à partir de la version 2025 Update 2.
