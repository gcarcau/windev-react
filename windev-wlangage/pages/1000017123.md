# HTTPAnnuleFormulaire (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Annule une déclaration de formulaire HTTP et libère toutes ses ressources. Ce formulaire a été créé grâce à la fonction [HTTPCréeFormulaire](1000017119.md).

## Exemple

```wlangage
HTTPCréeFormulaire("FORM")
...
HTTPEnvoieFormulaire("FORM", "www.monsite.fr")

CAS ERREUR:
HTTPAnnuleFormulaire("FORM")
```

## Syntaxe

```wlangage
HTTPAnnuleFormulaire(<Nom du formulaire>)
```

`<Nom du formulaire>` *Chaîne de caractères*
> Nom du formulaire HTTP. Ce nom a été donné lors de la création du formulaire HTTP (fonction [HTTPCréeFormulaire](1000017119.md)).

**Composante : wd300com.dll**
