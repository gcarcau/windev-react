# EnModeService (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Identifie si le code est exécuté dans un service.

## Exemple

```wlangage
// Code exécuté dans un service ?
SI EnModeService() = Vrai ALORS
	// Traitement à effectuer dans le service
	...
SINON
	// Traitement à effectuer dans une application normale
	...
FIN
```

```wlangage
// Tentative d'exécuter l'exécutable d'un service
SI EnModeService() = Faux ALORS Erreur("Ce programme est un service," + ...
		" merci de l'installer par la procédure adéquate")
```

## Syntaxe

```wlangage
<Résultat> = EnModeService()
```

`<Résultat>` *Booléen*
> - Vrai si le code est exécuté dans un service,
> - Faux dans le cas contraire.
>
>
> > _(WEBDEV - Code Navigateur)_ Ce paramètre correspond toujours à Faux.

## Remarques

### Disponibilité de la fonction
La fonction **EnModeService** est disponible dans tous les produits pour permettre l'écriture d'un code multi-produits. Des fonctions ou procédures utilisant la fonction **EnModeService** peuvent être partagées entre plusieurs produits, sans que des erreurs de compilation soient générées.

### Exécution des traitements contenant des erreurs de compilation
Par défaut, le mécanisme de sécurité du WLangage se déclenche uniquement si la ligne contenant l'erreur de compilation est exécutée.
Par exemple, si une fonction interdite dans le produit en cours est présente dans une boucle SI, le mécanisme de sécurité du WLangage se déclenchera uniquement si la ligne contenant cette fonction s'exécute.
