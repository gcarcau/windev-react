# Log (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst) · **Autres** (Procédures stockées)

Calcule le logarithme décimal d'une valeur numérique.

## Exemple

```wlangage
// Calcul du logarithme de 10
ResLogarithme = Log(10)
// Renvoie 1
```

## Syntaxe

```wlangage
<Résultat> = Log(<Valeur numérique>)
```

`<Résultat>` *Réel*
> Logarithme décimale recherché.
`<Valeur numérique>` *Entier ou réel*
> Valeur numérique à manipuler. Si ce paramètre est un nombre négatif ou nul, une erreur du WLangage est générée.

**Composante : wd300mat.dll**
