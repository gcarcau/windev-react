# <Variable picCalque>.SymétrieHorizontale (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Retourne l'image contenue dans une variable de type [picCalque](1000024604.md) par rapport à un axe horizontal (symétrie par rapport à un axe horizontal).

## Exemple

```wlangage
MonImageWDPic est un WDPic = "Test.bmp"
MonCalque est un picCalque

// Symétrie du calque par rapport à un axe horizontal
MonRésultat est un booléen
MonRésultat = MonCalque.SymétrieHorizontale()
SI MonRésultat = Faux ALORS Erreur("L'opération a échoué")
IMG_MonDessin = MonImageWDPic
```

## Syntaxe

```wlangage
<Résultat> = dSymétrieHorizontale(<Image>)
```

`<Résultat>` *Booléen*
> - Vrai si la symétrie a été effectuée,
> - Faux dans le cas contraire.
`<Image>` *Variable de type picCalque*
> Nom de la variable de type [picCalque](1000024604.md) à manipuler.
> La symétrie est réalisée par rapport à l'axe horizontal médian de l'image. L'image est directement modifiée.

## Remarques

### Fin du dessin
Si la fonction [<Variable picCalque>.FinDessin](1000024473.md) est appelée dans le même traitement que la fonction **<Variable picCalque>.SymétrieHorizontale**, la transformation de l'image ne sera pas affichée.

**Composante : wd300pnt.dll**
