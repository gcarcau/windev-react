# Fonctions de gestion des champs TreeMap (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Les fonctions permettant de gérer les champs TreeMap (via une syntaxe préfixée) sont les suivantes :

| [<TreeMap>.Ajoute](1000019740.md) | Ajoute un élément dans un champ TreeMap. |
| --- | --- |
| [<TreeMap>.Cherche](1000019742.md) | Recherche l'indice d'un élément dans un champ TreeMap à partir du chemin de l'élément. |
| [<TreeMap>.InfoXY](1000019743.md) | Renvoie l'indice de l'élément affiché à une position donnée dans un champ TreeMap. |
| [<TreeMap>.Occurrence](1000019752.md) | Renvoie le nombre d'éléments présents dans un champ TreeMap. |
| [<TreeMap>.SelectGroupe](1000019793.md) | Sélectionne visuellement un groupe d'éléments dans un champ TreeMap. |
| [<TreeMap>.Supprime](1000019799.md) | Supprime un élément dans un champ TreeMap. |
| [<TreeMap>.SupprimeTout](1000019800.md) | Supprime tous les éléments d'un champ TreeMap. |

## Liste des exemples associés :

| [image: Le champ Treemap] | Exemples unitaires (WINDEV) : Le champ Treemap     [ + ] Utilisation du champ Treemap. Le champ TreeMap permet de représenter dynamiquement des données, éventuellement arborescentes, de manière pondérée. Ce type de champ est très utile notamment pour permettre une visualisation intuitive de volumes de données.   Par exemple, dans l'exemple, il permet de visualiser le contenu d'un répertoire et d'analyser la taille des fichiers et sous-répertoires qu'il contient. |
