# SocketConnecteInfraRouge (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Connecte un poste client à un socket donné via le port infrarouge.
**Rappel** : Un socket est une ressource de communication utilisée par les applications pour communiquer d'une machine à une autre sans se soucier du type de réseau.

## Exemple

```wlangage
SI SocketConnecteInfraRouge("client", "service") = Faux ALORS
	Erreur("Erreur de connexion " + ErreurInfo(errMessage))
FIN
```

## Syntaxe

```wlangage
<Résultat> = SocketConnecteInfraRouge(<Nom du socket> , <Nom du service>)
```

`<Résultat>` *Booléen*
> - Vrai si la fonction a réussi,
> - Faux dans le cas contraire. En cas d'erreur, il est possible de connaître le détail de l'erreur grâce à la fonction [ErreurInfo](3013008.md).
`<Nom du socket>` *Chaîne de caractères*
> Nom à donner à la connexion ouverte sur le socket du serveur. Ce nom sera utilisé dans toutes les fonctions socket.
`<Nom du service>` *Chaîne de caractères*
> Nom du service spécifié dans la fonction [SocketCréeInfraRouge](3070012.md).

## Remarques

### Protocole IRDA
La fonction **SocketConnecteInfraRouge** utilise le protocole IRDA (Infrared Data Association). Il est ainsi possible de connecter une application WINDEV avec n'importe quel appareil utilisant ce protocole (à condition de connaître le nom du service utilisé).

### Limite Windows
Le nombre maximum de sockets infrarouge utilisés simultanément est 80.

### Connexion à un socket donné
Pour connecter un poste client à un socket donné, utilisez la fonction [SocketConnecte](3070016.md).
