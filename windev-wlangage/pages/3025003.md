# CouleurSélection (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU))

Change les caractéristiques du bandeau de sélection dans un champ Table, un champ Combo ou un champ Liste. Les nouvelles caractéristiques sont immédiatement prises en compte.

## Exemple

```wlangage
// Change la couleur du bandeau de sélection du champ Table "TABLE_Commande"
CouleurSélection(TABLE_Commande, RVB(255,200,200), VertClair)
```

## Syntaxe

```wlangage
CouleurSélection(<Champ manipulé> , <Couleur du texte> , <Couleur de fond>)
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler : champ Table, Liste ou Combo. La couleur du bandeau de sélection sera modifiée pour ce champ.
`<Couleur du texte>` *Entier*
> Nouvelle couleur du texte des éléments sélectionnés dans le champ. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md).
`<Couleur de fond>` *Entier*
> Nouvelle couleur de fond du bandeau de sélection du champ. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - [une couleur prédéfinie du WLangage](3010002.md).

## Remarques

### Erreur
Une erreur WLangage apparaît à l'exécution si le nom du champ ne correspond ni à un champ Table, ni à un champ Liste, ni à un champ Combo.

### Divers

- La fonction **CouleurSélection** peut être utilisée pour définir les caractéristiques du bandeau de sélection d'un champ Combo présent dans un champ Table.
- Pour changer l'image utilisée par le bandeau de sélection, il est nécessaire redéfinir les styles et d'utiliser la fonction [ChangeStyle](1000017171.md).
