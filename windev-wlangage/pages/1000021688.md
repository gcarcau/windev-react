# hbDescriptionTable (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

Le type **hbDescriptionTable** permet de définir et de connaître toutes les caractéristiques d'une table HBase. Les caractéristiques de cette table HBase peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Connexion
Connexion est un hbConnexion
Connexion.Serveur = "MonServeur"
// Récupération de la description de la table
DescTable est un hbDescriptionTable = hbRécupèreDescriptionTable(Connexion, "blog")
// Affichage du nom de la table
Trace("table : " + DescTable.Nom)
// Affichage de la description des colonnes
POUR TOUT DescCol DE DescTable.Colonne
	Trace(TAB + "colonne : " + DescCol.Nom)
	Trace(TAB + TAB + "attribut : ")
	POUR TOUT ValAttribut, NomAttribut de DescCol.Attribut
		Trace(TAB + TAB + NomAttribut + " = " + ValAttribut)
	FIN
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type hbDescriptionTable
Les propriétés suivantes peuvent être utilisées pour manipuler une table HBase :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Attribut | Tableau de Chaîne de caractères | Tableau associatif contenant les noms des attributs et les valeurs de chaque attribut. Ces noms et valeurs sont spécifiques à HBase et réservés à une utilisation avancée. Pour plus de détails sur les attributs de table, consultez la documentation HBase. |
| Colonne | Tableau de [hbDescriptionColonne](1000021694.md) | Description des colonnes. |
| Nom | Chaîne de caractères | Nom de la table HBase. |
