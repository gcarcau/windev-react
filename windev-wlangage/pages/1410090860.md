# Constantes de gestion du partage de proximité

> **Disponible :** **WINDEV Mobile** (Android)

Les constantes de gestion du partage de proximité sont les suivantes :

| Constante | Détail | Fonction |
| --- | --- | --- |
| **ppAnnulé** | Transfert de données annulé. | [PartageProximitéAccepteConnexion (procédure)](1410090657.md) |
| **ppBuffer** | Les données reçues correspondent à un buffer binaire. | [PartageProximitéAccepteConnexion (procédure)](1410090644.md) |
| **ppCluster** | Topologie de cluster entre les appareils à proximité. Dans cette topologie, chaque appareil peut se connecter à plusieurs appareils et/ou accepter les connexions de plusieurs appareils. Chaque appareil peut être à la fois "annonceur" (qui peut accepter des connexions entrantes de N autres appareils) ou "découvreur" (qui peut établir une connexion sortante à un seul appareil). | [PartageProximitéAttendConnexion](1410090655.md) [PartageProximitéRechercheAppareil](1410090648.md) |
| **ppConnexion** | Etat de la connexion avec l'appareil distant : Connexion établie. | [PartageProximitéAttendConnexion (procédure)](1410090665.md) [PartageProximitéDemandeConnexion (procédure)](1410090667.md) |
| **ppDéconnexion** | Etat de la connexion avec l'appareil distant : Déconnexion | [PartageProximitéAttendConnexion (procédure)](1410090665.md) [PartageProximitéDemandeConnexion (procédure)](1410090667.md) |
| **ppDemandeConfirmation** | Affiche une boîte de dialogue pour afficher le jeton d'authentification à l'utilisateur et lui demander confirmation.  **Attention** : Cette constante est disponible uniquement à partir de la version 2025 Update 1. | [PartageProximitéAccepteConnexion](1410090646.md) |
| **ppEchecConnexion** | Etat de la connexion avec l'appareil distant : Echec de la connexion | [PartageProximitéAttendConnexion (procédure)](1410090665.md) [PartageProximitéDemandeConnexion (procédure)](1410090667.md) |
| **ppEnCours** | Transfert de données en cours. | [PartageProximitéAccepteConnexion (procédure)](1410090657.md) |
| **ppErreur** | Transfert de données en erreur. | [PartageProximitéAccepteConnexion (procédure)](1410090657.md) |
| **ppEtoile** | Topologie pour les applications qui distribuent des informations à partir d'un point centralisé. Chaque appareil peut, à tout moment, jouer le rôle d'un "annonceur" (qui peut accepter des connexions entrantes de N autres appareils) ou d'un "découvreur" (qui peut établir une connexion sortante à un seul appareil), mais pas les deux en même temps. Une fois le lien établi, les appareils conservent leur rôle jusqu'à la fin de la connexion. | [PartageProximitéAttendConnexion](1410090655.md) [PartageProximitéRechercheAppareil](1410090648.md) |
| **ppFichier** | Les données reçues correspondent à un fichier. | [PartageProximitéAccepteConnexion (procédure)](1410090644.md) |
| **ppPointAPoint** | Topologie pour les connexions de type "un à un" où chaque appareil peut se connecter uniquement à un seul autre appareil à la fois. Il est ainsi possible de maximiser la bande passante du lien. | [PartageProximitéAttendConnexion](1410090655.md) [PartageProximitéRechercheAppareil](1410090648.md) |
| **ppRefusConnexion** | Etat de la connexion avec l'appareil distant : Connexion refusée par l'appareil distant. | [PartageProximitéAttendConnexion (procédure)](1410090665.md) [PartageProximitéDemandeConnexion (procédure)](1410090667.md) |
| **ppTerminé** | Transfert de données terminé. | [PartageProximitéAccepteConnexion (procédure)](1410090657.md) |
