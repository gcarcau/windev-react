# WiFiEtat (Fonction)

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Renvoie l'état actuel d'activation du Wi-Fi sur l'appareil ou demande à être notifié des changements d'état d'activation du Wi-Fi.
**Remarques** :

- Pour activer ou désactiver le Wi-Fi sur l'appareil, utilisez la fonction [WiFiActive](1000019350.md).
- L'accès Wi-Fi n'est pas disponible dans l'émulateur Android.
- Attention : Cette fonctionnalité est disponible jusqu'à Android 9. A partir d'Android 10, cette information n'est plus accessible : cette fonction provoque une erreur fatale. Il est conseillé de tester la version d'Android utilisée via la fonction [SysVersionAndroid](1000019785.md).

## Exemple

```wlangage
SI WiFiEtat() = wifiDésactivé ALORS
	WiFiActive(Vrai)
FIN
```

## Syntaxe

#### Connaître l'état actuel d'activation du Wi-Fi sur le poste en cours

```wlangage
<Résultat> = WiFiEtat()
```

`<Résultat>` *Entier*
> Etat actuel d'activation du Wi-Fi :
>
> | *wifiActif* | Le Wi-Fi est activé sur l'appareil. |
> | --- | --- |
> | *wifiActivationEnCours* | Le Wi-Fi est en cours d'activation sur l'appareil. _(WEBDEV - Code Navigateur)_ Cette constante n'est pas disponible. |
> | *wifiDésactivationEnCours* | Le Wi-Fi est en cours de désactivation sur l'appareil. _(WEBDEV - Code Navigateur)_ Cette constante n'est pas disponible. |
> | *wifiDésactivé* | Le Wi-Fi est désactivé sur l'appareil. |
> | *wifiErreur* | L'état d'activation du Wi-Fi n'a pas pu être récupéré. _(iPhone/iPad)_ Cette constante ne correspond pas à une option possible. |

> _(Android, Widget Android)_ Activer la notification des changements d'activation du Wi-Fi Masquer les détails
WiFiEtat(<Procédure WLangage>)

 <Procédure WLangage> : Nom de procédureProcédure WLangage (également nommée "callback") appelée lorsque l'état d'activation du Wi-Fi sur l'appareil change. Cette procédure est de la forme :

PROCEDURE <Nom de la procédure> (<Nouvel état>, <Ancien état>)

où : <Nouvel état> est un entier correspondant au nouvel état d'activation du Wi-Fi sur l'appareil <Ancien état> est un entier correspondant à l'état d'activation du Wi-Fi sur l'appareil avant le changement d'état.Les paramètres de cette procédure sont optionnels. Il n'est pas nécessaire de passer de paramètres à cette procédure. En effet, ces paramètres sont renseignés automatiquement à chaque appel.Si ce paramètre vaut chaîne vide (""), les notifications de changement d'état ne seront plus envoyées. Si aucune demande de notification n'a été effectuée, la fonction est sans effet.

## Remarques

> _(Android)_ Permissions requisesL'utilisation de cette fonction entraîne la modification des permissions requises par l'application.Permission requise : ACCESS_WIFI_STATECette permission permet aux applications d'accéder à des informations concernant les réseaux Wi-Fi.
