# TCDSelectOccurrence (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur)

Renvoie le nombre de cellules sélectionnées dans un champ Tableau croisé dynamique.
Nouveauté Abonnement

> _(WEBDEV - Code Serveur, Linux)_ Cette fonction est désormais disponible pour les sites WEBDEV sous Windows et sous Linux.

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.
**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Exemple

```wlangage
// Parcours des cellules sélectionnées
tcdPos est une tcdPosition de TCD_MonTCD

nbSel est un entier = TCDSelectOccurrence(TCD_MonTCD)
POUR i = 1 À nbSel
	tcdPos = TCDSelect(TCD_MonTCD, i)
	Trace(tcdPos.COL_Date_Jour + ":" + tcdPos.COL_Produit))
FIN
```

## Syntaxe

```wlangage
<Résultat> = TCDSelectOccurrence(<Champ Tableau croisé dynamique>)
```

`<Résultat>` *Entier*
> Nombre de cellules sélectionnées dans le champ Tableau croisé dynamique.
`<Champ Tableau croisé dynamique>` *Nom de champ*
> Nom du champ Tableau croisé dynamique à manipuler.

**Classification Métier / UI : Code UI**

**Composante : wd300obj.dll**
