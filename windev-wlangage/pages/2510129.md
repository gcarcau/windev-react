# ValeurAffichée (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

La propriété **ValeurAffichée** permet de connaître la valeur actuellement affichée à l'écran dans un champ d'une fenêtre ou d'une page.

## Exemple

```wlangage
// Connaître la valeur affichée à l'écran dans le champ "Date"
SAI_Date = 18031972
Trace(SAI_Date.ValeurAffichée) // Affiche "18/03/1972"
```

## Syntaxe

```wlangage
<Valeur affichée> = <Champ manipulé>.ValeurAffichée
```

`<Valeur affichée>` *Chaîne de caractères*
> Valeur actuellement affichée à l'écran dans le champ spécifié.
`<Champ manipulé>` *Nom de champ*
> Nom du champ à manipuler.

## Remarques

### Valeur affichée dans un champ de saisie
La propriété **ValeurAffichée** retourne la chaîne formatée avec son masque de saisie.

> _(WINDEV, WEBDEV - Code Serveur, Android, iPhone/iPad, Ajax, Android, iPhone/iPad)_ Valeur affichée dans un champ d'affichage HTMLLa propriété ValeurAffichée retourne le code HTML contenu entre les balises <BODY> et </BODY>. Remarque : Cette propriété n'est pas disponible sur les champs d'affichage HTML. Le résultat correspond à une chaîne vide.

### Valeur affichée dans un champ Combo
La propriété **ValeurAffichée** retourne la chaîne formatée affichée :

- dans le champ de saisie si le champ Combo est en saisie,
- dans la ligne en cours si le champ Combo n'est pas en saisie.

**Remarque : utilisation des fonctions gImage et gValeurMémorisée**
Pour récupérer le contenu ajouté avec les fonctions [gImage](3029042.md) et [gValeurMémorisée](1410088363.md), utilisez la propriété [ValeurInitiale](2510128.md).
Par exemple, si le code suivant est utilisé pour ajouter un élément :

```wlangage
ListeAjoute(COMBO_Combo1, gImage(nNumImage,i) + "Client.NomClient" + i + ...
	 ValeurMémorisée("Client.NomClient" + i))
```

le code suivant permet de relire la chaîne d'origine :

```wlangage
COMBO_Combo1[1].ValeurInitiale
```

### Valeur affichée dans un champ Liste
La propriété **ValeurAffichée** retourne :

- la chaîne formatée affichée dans la ligne spécifiée si un numéro de ligne est indiqué,
- la chaîne formatée affichée dans la ligne en cours si aucun numéro de ligne n'est spécifié.

### Valeur affichée dans une colonne d'un champ Table
La propriété **ValeurAffichée** retourne la chaîne formatée affichée dans la cellule correspondant à la colonne spécifiée et à la ligne en cours.

### Valeur affichée dans une cellule d'un champ Table
La propriété **ValeurAffichée** retourne la chaîne formatée affichée dans la cellule correspondant à la colonne spécifiée et à la ligne spécifiée.

### Valeur affichée dans une ligne d'un champ Table
La propriété **ValeurAffichée** retourne les valeurs de chaque colonne de la ligne spécifiée séparées par des *TAB*.
Remarque : La propriété **ValeurAffichée** ne retourne pas la valeur des colonnes invisibles.

> _(WINDEV)_ Valeur affichée dans un champ Liste imageLa propriété ValeurAffichée retourne :le libellé de l'élément affiché dans la ligne spécifiée si un numéro de ligne est indiqué,le libellé de l'élément affiché dans la ligne en cours si aucun numéro de ligne n'est spécifié.

### Limite
La propriété **ValeurAffichée** s'applique uniquement aux :

- Champs de saisie,
- Champs Combo,
- Champs Liste et lignes de champ Liste,
- Colonnes et lignes de champ Table,
- Cellules de champ Table,
- Champs Libellés,
- Champs HTML.
- Champs Image.
- Champs Image cliquable.
- Champs Vignette.

> _(Java)_ En Java, la propriété ValeurAffichée s'applique uniquement aux éléments suivants :Champ de saisie.Champ Liste.Champ Combo.Colonne de champ Table.

> _(WEBDEV - Code Navigateur)_ En code navigateur, la propriété ValeurAffichée s'applique uniquement aux éléments suivants :Champ de saisie.Champ d'affichage formaté.
