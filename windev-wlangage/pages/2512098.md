# GUIDAnalyse (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

La propriété **GUIDAnalyse** renvoie le GUID de l'analyse qui a permis de créer le fichier de données. Cet identifiant est utilisé dans le fichier .REP (pour plus de détails, consultez [Gestion du fichier .REP](3044186.md)).
**Remarque** : Le GUID de l'analyse peut également être connu dans l'éditeur d'analyses, dans l'onglet "Général" de la fenêtre de description de l'analyse.

## Exemple

```wlangage
Trace(Client.GUIDAnalyse)
```

## Syntaxe

```wlangage
<GUID Analyse> = <Fichier de données>.GUIDAnalyse
```

`<GUID Analyse>` *Chaîne de caractères*
> - GUID de l'analyse qui a permis de créer le fichier de données.
> - Chaîne vide ("") si le fichier de données a été créé par programmation ou si le fichier utilisé n'est pas un fichier de données au format HFSQL Classic ou Client/Serveur.
`<Fichier de données>` *Chaîne de caractères*
> Nom du fichier de données pour lequel le GUID de l'analyse est recherché.

## Remarques

La propriété [GUIDFichier](2512099.md) permet de connaître le GUID du fichier. Ce GUID a été défini dans l'analyse qui a permis de créer le fichier de données.
