# Dessus (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

Le mot-clé **Dessus** permet d'indiquer que la fenêtre est au premier plan par rapport aux autres fenêtres de l'application. Ce mot-clé peut correspondre :

- à la constante *Dessus* utilisée par les fonctions [FenEtat](3038030.md), [OuvreFille](3038021.md) et [OuvreSoeur](3038045.md).
- Nouveauté Abonnement
  à la propriété **Dessus** des variables de type [OptionsOuvertureFenêtre](1410091298.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
