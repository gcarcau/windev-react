# <Variable Diagramme>.DébutModification (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Signale le début du regroupement d'un ensemble d'opérations sur une variable de type Diagramme en un seul événement (gestion du "undo/redo").

## Exemple

```wlangage
MonDiagramme est un Diagramme <- EDIAG_MonDiagramme
MaSélection est un diagSélection <- EDIAG_MonDiagramme.Sélection
MonDiagramme.DébutModification()
MaSélection.Fond.Couleur = Blanc
MaSélection.Bordure.Couleur = Noir
MonDiagramme.FinModification()
```

## Syntaxe

```wlangage
<Diagramme>.DébutModification()
```

`<Diagramme>` *Variable de type Diagramme*
> Nom de la variable de type [Diagramme](1410088055.md) à manipuler.

## Remarques

Toutes les modifications effectuées entre la fonction **<Variable Diagramme>.DébutModification** et la fonction [<Variable Diagramme>.FinModification](1410088878.md) sont regroupées en une seule opération annulable par un "undo/redo".

**Classification Métier / UI : Code UI**

**Composante : wd300mdl.dll**
