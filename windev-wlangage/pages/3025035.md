# ChampExiste (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Teste l'existence d'un champ (ou d'un groupe de champs) dans une fenêtre, dans une page ou dans un état.

## Exemple

```wlangage
// Test de l'existence du champ "SaisieNom"
ResExiste = ChampExiste("SaisieNom")
```

## Syntaxe

```wlangage
<Résultat> = ChampExiste(<Champ manipulé>)
```

`<Résultat>` *Booléen*
> - Vrai si le champ (ou le groupe de champs) existe,
> - Faux dans le cas contraire.
`<Champ manipulé>` *Chaîne de caractères ou variable de type Champ*
> Champ pour lequel l'existence doit être testée. Ce paramètre peut correspondre :
>
> - au nom du champ à tester **entre guillemets**. Ce paramètre peut aussi correspondre au nom d'un groupe de champs.
>   Pour tester l'existence des champs des autres fenêtres, pages ou états, <Champ manipulé> est de la forme :
>   "<Nom de la fenêtre, de la page ou de l'état>.<Nom du champ de la fenêtre, de la page ou de l'état>".
> - Nouveauté Abonnement
>   au nom d'une variable de type [Champ](1000020967.md).
>    Non disponible.
>   **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
>   Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

## Remarques

### Champs pris en compte

- Les cases des barres de message et les entrées de menus ne sont pas considérées comme des champs.
- Les entrées de menus ne sont pas considérées comme des champs.
- Les colonnes des champs Table ne sont pas considérées comme des champs.

**Classification Métier / UI : Code UI**
