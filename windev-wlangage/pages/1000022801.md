# ValeurInitiale (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

La propriété **ValeurInitiale** permet de connaître et/ou de modifier une valeur initiale. Cette propriété est utilisable sur :

- les champs d'une fenêtre ou d'une page. Pour plus de détails, consultez [ValeurInitiale](2510128.md).
- une variable de type [docNiveauNumérotation](1000022799.md).
