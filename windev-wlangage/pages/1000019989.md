# <Multimédia>.Durée (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, iPhone/iPad)

Renvoie la taille du fichier multimédia en cours de lecture (en millisecondes) dans le champ Multimédia.
> _(WEBDEV - Code Navigateur)_ Remarque : Selon le type de vidéo et la configuration du navigateur, cette fonction peut ne pas être supportée. Dans ce cas, son utilisation sera sans effet mais ne provoquera pas d'erreur.

## Exemple

> _(WINDEV, Etats et Requêtes, Code Utilisateur (MCU))_ MonFichier est une chaîne = "C:\Ma musique\mysong.mp3"
MM_Multimédia1.Ouvre(MonFichier)
Info("La durée de ce fichier est " + MM_Multimédia1.Durée() + " millisecondes")

## Syntaxe

```wlangage
<Résultat> = <Champ Multimédia>.Durée()
```

`<Résultat>` *Entier*
> - Durée (en millisecondes) du fichier multimédia,
> - 0 en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
>
>
> > _(WEBDEV - Code Navigateur)_ Remarque : La fonction ErreurInfo n'est pas disponible.
`<Champ Multimédia>` *Nom de champ*
> Nom du champ Multimédia à manipuler.

**Composante : wd300obj.dll**
