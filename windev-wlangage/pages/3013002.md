# AnalyseurFin (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Arrête la "collecte d'informations" pour l'[analyseur de performances](2030035.md).
Le fichier WPF contenant l'analyse de tous les traitements effectués est enregistré. Ce fichier pourra être ouvert avec l'[analyseur de performances](2030035.md) ou directement sous l'éditeur, via [image: Icône ] parmi les boutons d'accès rapide.

## Exemple

```wlangage
AnalyseurDébut("Test_ProcédureLancement.wpf")
ProcédureLancement()
AnalyseurFin()
```

## Syntaxe

```wlangage
AnalyseurFin()
```

## Remarques

Si la fonction [AnalyseurDébut](3013012.md) n'a pas été appelée avant la fonction **AnalyseurFin**, l'appel de la fonction **AnalyseurFin** est sans effet.

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
