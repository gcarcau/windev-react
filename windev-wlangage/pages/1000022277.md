# <Variable Email>.ChargeFichierAttaché (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Ajoute un fichier en attachement d'un email.

## Exemple

```wlangage
// Ajout d'un fichier dans les pièces jointes d'un email
MonMessage est un Email
MonMessage.ChargeFichierAttaché(...
	SysRep(srMesDocuments) + ["\"] + "Rapport Annuel.pdf")
```

## Syntaxe

```wlangage
<Résultat> = <Email>.ChargeFichierAttaché(<Nom et chemin d'un fichier>)
```

`<Résultat>` *Entier*
> - Rang du fichier dans le tableau des fichiers attachés (variable [Email.Attache](1000018713.md)),
> - -1 en cas d'erreur. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Email>` *Variable de type Email*
> Nom de la variable de type [Email](1000018713.md) auquel le fichier doit être attaché.
`<Nom et chemin d'un fichier>` *Chaîne de caractères*
> Nom et chemin complet (ou relatif) du fichier à attacher. Un chemin de type UNC peut être utilisé. Il n'est pas possible d'utiliser des caractères joker ("*" ou "?").

**Composante : wd300com.dll**
