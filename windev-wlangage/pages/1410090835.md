# BoutonSegmentéInsère (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Insère une nouvelle option dans un champ Bouton segmenté.

## Exemple

```wlangage
BoutonSegmentéInsère(BS_Mode, 2, "Mode Avancé")
```

## Syntaxe

```wlangage
<Résultat> = BoutonSegmentéInsère(<Champ Bouton segmenté> , <Indice de l'option> , <Libellé de l'option>)
```

`<Résultat>` *Entier*
> - Indice de l‘option insérée.
> - -1 en cas d'erreur. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
>
> **Attention** : Ce paramètre est disponible uniquement à partir de la version 2025 Update 1.
`<Champ Bouton segmenté>` *Nom de champ*
> Nom du champ Bouton segmenté dans lequel l'option doit être ajoutée. L'option est ajoutée à la suite des options existantes.
`<Indice de l'option>` *Entier*
> Indice de l'option à insérer.
> Si ce paramètre :
>
> - est supérieur au nombre d'options présentes dans le champ, l'option est ajoutée après la dernière option du champ.
> - est égal à 1 ou 0, l'élément est ajouté avant la première option du champ.
`<Libellé de l'option>` *Chaîne de caractères*
> Libellé de l'option à insérer.

**Classification Métier / UI : Code UI**

**Composante : wd300obj.dll**
