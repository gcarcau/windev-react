# <Variable Image>.InverseCouleur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Inverse les couleurs dans une variable de type [Image](1000019650.md).
> _(Linux)_ Attention : L'utilisation de cette fonction sous Linux nécessite une configuration spécifique. Pour plus de détails, consultez Dessiner en WINDEV, WEBDEV et WINDEV Mobile.

## Exemple

```wlangage
MonImage est une Image = "Test.bmp"
// Inverse les couleurs de la variable MonImage
Résultat1 est un booléen
Résultat1 = MonImage.InverseCouleur()
SI Résultat1 = Faux ALORS Erreur("L'opération a échoué")
IMG_MonDessin = MonImage
```

## Syntaxe

```wlangage
<Résultat> = <Variable Image>.InverseCouleur()
```

`<Résultat>` *Booléen*
> - Vrai si l'inversion des couleurs a été effectuée,
> - Faux dans le cas contraire.
`<Variable Image>` *Variable de type Image*
> Nom de la variable de type [Image](1000019650.md) à manipuler.
> Chaque pixel de l'image prend la couleur opposée (négation bit à bit) de la couleur d'origine. L'image manipulée est directement modifiée.

## Remarques

### Fin du dessin
Si la fonction [<Variable WDPic>.FinDessin](1000024472.md) est appelée dans le même traitement que la fonction **<Variable Image>.InverseCouleur**, la transformation de l'image ne sera pas affichée.

**Composante : wd300pnt.dll**
