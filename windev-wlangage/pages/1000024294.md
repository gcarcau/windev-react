# <Table>.Fin (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Arrête le parcours manuel du fichier de données lié à un champ Table fichier. Après l'exécution de la fonction **<Table>.Fin**, les enregistrements situés après l'enregistrement en cours dans le champ Table ne seront pas lus.

## Exemple

```wlangage
// Arrêt du parcours du fichier lié au champ Table "TABLE_TableProduit"
TABLE_TableProduit.Fin()
```

## Syntaxe

```wlangage
<Champ Table>.Fin()
```

`<Champ Table>` *Nom de champ*
> Nom du champ Table à manipuler.

## Remarques

### Conditions d'utilisation

- La fonction **<Table>.Fin** peut être utilisée indifféremment sur un champ Table monosélection ou multisélection.
- La fonction **<Table>.Fin** ne doit pas être utilisée sur les champs Table fichier utilisant un parcours automatique.

> _(WEBDEV - Code Serveur)_ Rappel : La multisélection n'est pas disponible sur les champs Table "classiques".

### Evénements du champ Table
La fonction **<Table>.Fin** peut être utilisée uniquement dans les événements du champ Table suivants :

- Initialisation.
- Lecture de l'enregistrement précédent.
- Lecture de l'enregistrement suivant.

> _(WEBDEV - Code Serveur)_ La fonction <Table>.Fin peut être utilisée uniquement dans l'événement "Initialisation" du champ Table.

### Réinitialisation du champ Table
Après l'appel de la fonction **<Table>.Fin** dans un événement d'un champ Table, ré-initialisez l'affichage des données du champ Table. Par exemple :

```wlangage
TABLE_TABLE1.Affiche(taInit)
```

### Visualisation des enregistrements entre deux valeurs
Pour visualiser dans un champ Table les enregistrements correspondant à un intervalle de valeurs, il est conseillé d'utiliser la fonction [<Source>.Filtre](1000024960.md) (et non la fonction **<Table>.Fin**).
