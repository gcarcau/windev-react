# EmailListeDossier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie la liste des dossiers :

- d'une session IMAP.
- présents dans le logiciel de messagerie Outlook.
  **Rappel** : Cette fonction ne permet pas de lister les dossiers présents dans le logiciel de messagerie Outlook Express.

## Exemple

```wlangage
MaSession est une emailSessionIMAP
...
// Liste des dossiers
ListeDossier = EmailListeDossier(MaSession, LstDossierTous + LstDossierType)
// ListeDossier contient par exemple :
// "Dossiers personnels" + TAB + dossierPersonnel + RC + ...
// "Dossiers personnels\Boîte de réception" + ...
// TAB + dossierRéception + RC + ...
// "Dossiers personnels\Boîte de réception\Travail" + ...
// TAB + dossierGénérique + RC + ...
// "Dossiers personnels\Boîte de réception\Personnel" + ...
// TAB + dossierGénérique + RC + ...
```

> _(WINDEV, WEBDEV - Code Serveur)_ // Ouverture de la session
IDSession = EmailOuvreSessionOutlook("MonProfil")
...
// Liste des dossiers
ListeDossier = EmailListeDossier(IDSession)
// ListeDossier contient par exemple :
// "Dossiers personnels" + RC + ...
// "Dossiers personnels\Boîte de réception" + RC + ...
// "Dossiers personnels\Boîte de réception\Travail" + RC + ...
// "Dossiers personnels\Boîte de réception\Personnel" + RC + ...

## Syntaxe

```wlangage
<Résultat> = EmailListeDossier(<Session> [, <Option>])
```

`<Résultat>` *Chaîne de caractères*
> Liste des dossiers. Les différents dossiers sont séparés par des RC (Retour Chariot). En fonction de la constante utilisée, le format du résultat diffère :
>
> | *LstDossierNormal* (Valeur par défaut) | <Nom Dossier1 + RC + <Nom Dossier2 + RC + ... |
> | --- | --- |
> | *LstDossierTous* | <Nom Dossier1 + RC + <Nom Dossier2 + RC + ... |
> | *LstDossierTrié* | <Nom Dossier1 + RC + <Nom Dossier2 + RC + ... |
> | *LstDossierType* | <Nom Dossier1 + TAB + <Type Dossier1 + RC + <Nom Dossier2 + TAB + <Type Dossier2 + RC + ... |
>
> Où :
> <Nom DossierX> : Nom complet du dossier. Par exemple : "Dossiers personnels\Boîte de réception\Travail".
>
> <Type DossierX> : Type du dossier listé. Ce paramètre peut correspondre à :
>
>
> - *dossierBrouillon* : Dossier des brouillons
> - *dossierContact* : Dossier des contacts et des groupes de contacts
> - *dossierCorbeille* : Dossier des éléments supprimés
> - *dossierEnvoie* : Dossier des emails en attente d'envoi
> - *dossierEnvoyé* : Dossier des emails envoyés
> - *dossierGénérique* : Dossier générique (dossier créé par les utilisateurs)
> - *dossierJournal* : Dossier des journaux
> - *dossierNote* : Dossier des notes
> - *dossierPersonnel* : Racine du dossier "Dossiers personnels"
> - *dossierRéception* : Dossier des emails reçus
> - *dossierRendezVous* : Dossier des rendez-vous
> - *dossierTâche* : Dossier des tâches
>
>
> En cas d'erreur, la variable [ErreurDétectée](3087001.md) est à Vrai. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Session>` *Chaîne de caractères, Entier ou variable de type emailSessionOutlook ou emailSessionIMAP*
> Identifiant de la session email en cours. Cet identifiant peut être :
>
> - un entier renvoyé par la fonction [EmailOuvreSessionOutlook](3032128.md) ou [OutlookOuvreSession](3032123.md).
> - une variable de type [emailSessionOutlook](1000018767.md).
> - une variable de type [emailSessionIMAP](1000018957.md).
> - le nom d'utilisateur passé à la fonction [EmailOuvreSessionIMAP](1000019189.md).
`<Option>` *Constante ou combinaison de constantes optionnelle de type entier*
> Indique :
>
> - le type de liste à effectuer :
>   | *LstDossierNormal* | Liste des dossiers contenant uniquement des emails ("Boîte de réception", "Eléments envoyés", ...). |
>   | --- | --- |
>   | *LstDossierTous* | Liste de tous les dossiers. |
> - le mode de tri de la liste :
>   | *LstDossierTrié* | Liste triée dans l'ordre alphabétique. |
>   | --- | --- |
> - l'affichage du type du dossier :
>   | *LstDossierType* | Renvoie le type des dossiers en plus de leur nom (option non supportée avec le protocole IMAP) |
>   | --- | --- |
>
> Par défaut, tous les dossiers contenant des emails sont listés. Cette liste n'est pas triée par ordre alphabétique et contient uniquement le nom de chaque dossier.

## Remarques

Pour manipuler :

- le contenu du dossier "Contacts", utilisez les [fonctions Contact](1000006110.md) et les [fonctions Groupe](1000008119.md).
- le contenu du dossier "RendezVous", utilisez les [fonctions RendezVous](1000011009.md).
- le contenu du dossier "Tâches", utilisez les [fonctions Tâche](1000012009.md).
