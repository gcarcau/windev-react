# Réplication (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **Réplication** permet de connaître et de modifier le mode de réplication. Cette propriété est utilisable sur :

- un fichier de données. Pour plus de détails, consultez [Réplication](2512073.md).
- une variable de type [hOpérationServeur](1000022471.md).
