# Choisir l'action associée au lien

> **Disponible :** **WEBDEV** (Windows, Linux, PHP)

## Présentation

Quel que soit le type du lien, il est possible d'associer une action à ce lien. WEBDEV propose les actions les plus courantes directement dans l'onglet général de la fenêtre de description du champ.
[image: Action associée au champ Lien]

Pour les actions plus spécifiques, il suffit de cliquer sur le lien "Plus de choix".

Dans tous les cas, il est nécessaire de définir la destination de cette action.

## Les actions disponibles

### Actions prédéfinies
Différentes actions prédéfinies sont proposées par défaut dans une liste déroulante. Ces actions prédéfinies dépendent des éléments présents dans la page et présents dans le projet.
Il est ainsi possible par exemple de choisir de :

- Détecter automatiquement les codes serveur et navigateur à exécuter :
  - Si l'événement "Clic (Serveur)" contient du code WLangage, ce code sera automatiquement exécuté sur le serveur. En effet, le navigateur appellera automatiquement le serveur pour exécuter ce code serveur.
  - Si aucun code n'est présent dans l'événement "Clic (Serveur)", le serveur ne sera pas appelé.
- Toujours exécuter les codes serveur et navigateur,
- Exécuter le code de clic navigateur uniquement,
- Afficher une page du site,
- Afficher une page d'un autre site,
- Réaliser une action personnalisée (envoyer un email, appeler un numéro de téléphone, se connecter à un serveur FTP, télécharger un fichier, ...). Dans ce cas, des paramètres peuvent être spécifiés.

**Attention** : les actions sont effectuées après le code de clic du bouton (code navigateur et code serveur).

### Actions spécifiques
Le lien "Plus de choix" permet de proposer plus d'options. Il est ainsi possible par exemple de :

- faire une action sur un autre champ,
- se positionner sur une ancre de la page,
- partager sur un réseau social,
- changer la langue courante,
- envoyer la valeur des champs de la page vers ... une page ou un script. Cette option permet par exemple de traiter le contenu d'un formulaire présent dans un site statique.

**Remarque** : Toutes ces opérations sont également réalisables par programmation.

### Cas particulier : partager sur un réseau social
L'action "Partager sur un réseau social" permet de créer un lien permettant de partager la page en cours, le domaine en cours ou une URL spécifique sur un réseau social. Cette action peut également être effectuée grâce au champ [Réseau social](1000028001.md).
Remarque : L'utilisation d'un bouton, d'un lien ou d'une image cliquable permet de paramétrer entièrement le look utilisé (il est cependant conseillé de suivre les licences d'utilisation des différents réseaux sociaux). Le champ [Réseau social](1000028001.md) offre un paramétrage avancé (affichage du nombre de partages, etc.).

Le tableau suivant présente pour chaque réseau social proposé, les informations utilisées :

| Réseau social | Elément partagé | Effet |
| --- | --- | --- |
| **Facebook** | Le domaine | Crée sur le fil Facebook de l'internaute connecté un lien vers le domaine du site en cours. Attention : Une page d'index par défaut doit exister sur le serveur d'hébergement. |
|  | La page | Crée sur le fil Facebook de l'internaute connecté un lien vers la page du site en cours. |
|  | Cible personnalisée | L'URL doit être saisie dans le champ "URL cible". **Cas 1 : URL d'une page Facebook** :  Incrémente le compteur de la page Facebook aimée. **Cas 2 : URL d'une page ou d'un site quelconque** :  Crée sur le fil Facebook de l'internaute connecté un lien vers la page ou le site spécifié. |
| **Twitter** | Le domaine | Crée sur le fil Twitter de l'internaute connecté un message contenant un lien vers le domaine du site en cours. |
|  | La page | Crée sur le fil Twitter de l'internaute connecté un message contenant un lien vers la page du site en cours. |
|  | Cible personnalisée | L'URL doit être saisie dans le champ "URL cible". Crée sur le fil Twitter de l'internaute connecté un message contenant un lien vers l'URL indiquée. |
| **LinkedIn** | Le domaine | Crée un post sur les nouvelles du profil LinkedIn connecté avec un lien sur le domaine. Attention : Une page d'index par défaut doit exister sur le serveur d'hébergement. |
|  | La page | Crée un post sur les nouvelles du profil LinkedIn connecté avec un lien sur la page. |
|  | Cible personnalisée | Crée un post sur les nouvelles du profil LinkedIn connecté avec un lien personnalisé. L'URL du lien à envoyer doit être saisie dans le champ "URL cible". |
| **Tumblr** | Le domaine | Crée sur le fil Tumblr de l'internaute connecté un message contenant un lien vers le domaine du site en cours. |
|  | La page | Crée sur le fil Tumblr de l'internaute connecté un message contenant un lien vers la page du site en cours. |
|  | Cible personnalisée | L'URL doit être saisie dans le champ "URL cible". Crée sur le fil Tumblr de l'internaute connecté un message contenant un lien vers l'URL indiquée. |
| **WhatsApp** | La page | Crée un message WhatsApp contenant un lien vers la page du site en cours. |
|  | Cible personnalisée | L'URL doit être saisie dans le champ "URL cible". Crée un message WhatsApp contenant un lien vers l'URL indiquée. |

Le champ "Destination" permet de sélectionner le mode d'affichage de la fenêtre de connexion et de saisie du message sur le réseau social paramétré.

## La destination de l'action

Si aucune destination n'est choisie pour l'action, l'action est réalisée dans la destination par défaut définie pour la page en cours.
Les destinations possibles d'une action effectuée par un champ Lien sont :

| **A la même place (_self)** : Affiche le résultat dans le même navigateur. | [image: Frame en cours] |
| --- | --- |
| **Nouvel onglet du navigateur (_blank)** : Affiche le résultat dans une nouvelle fenêtre du navigateur. | [image: Nouveau navigateur] |
| **Onglet nommé du navigateur** : Affiche le résultat dans une fenêtre existante du navigateur. | [image: Nouveau navigateur] |
| **Frame parent (_parent)** : Affiche le résultat dans la frame d'origine (cas de framesets imbriqués). | [image: Frame parent] |
| **Navigateur en cours (_top)** : Affiche le résultat dans la page en cours du navigateur (sans frames). | [image: Navigateur en cours] |
| **Autres frames du frameset** (si la page fait partie d'un frameset) : Affiche le résultat dans une frame spécifique. |  |
| **Champ iFrame de la page** (si la page contient au moins un champ iFrame) : Affiche le résultat dans un [champ iFrame](1013270.md). |  |
