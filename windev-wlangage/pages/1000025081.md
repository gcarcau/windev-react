# <Source>.VersFichier (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS)

Copie une source de données (fichier de données, requête, vue, ...) vers un fichier de données physique HFSQL de même description. Ce fichier de données n'est ni crypté, ni protégé par mot de passe.
Cette fonction permet par exemple de sauvegarder un historique : une requête sélectionne tous les enregistrements de l'année 2019, le résultat est transféré dans un fichier de données, et une nouvelle requête supprime tous les enregistrements de l'année 2019.

## Exemple

```wlangage
SI MaVue.VersFichier("C:\temp\Test.fic") = Vrai ALORS
	Info("Données transférées dans un fichier de données")
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Source>.VersFichier(<Fichier destination>)
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été effectuée,
> - Faux dans le cas contraire (par exemple le fichier destination existe déjà).
`<Source>` *Type correspondant à la source spécifiée*
> Nom logique de la source de données à copier (fichier de données, vue, requête, ...).
`<Fichier destination>` *Chaîne de caractères*
> Nom complet du fichier de données physique dans lequel les enregistrements de la source doivent être copiés. Ce fichier de données aura la même description que la source de données. Pour accéder à ce fichier de données, utilisez par exemple la fonction [<Source>.DéclareExterne](1000024214.md).

## Remarques

### Source filtrée
Si un filtre est défini et actif sur la source de données, seuls les enregistrements correspondant au filtre seront copiés.

### Source de données : Vue ou requête
Si la source de données est une vue ou une requête, toutes les rubriques seront des clés du fichier de données créé à l'exception :

- des rubriques de type Mémo.
- des rubriques dont la taille est supérieure à 260 caractères et non clé dans le fichier source de la vue ou de la requête.
