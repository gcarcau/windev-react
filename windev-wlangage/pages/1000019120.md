# SaaSAdminAjouteUtilisateur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Ajoute un utilisateur SaaS.
**Remarques** :

- L'utilisation de cette fonction nécessite d'avoir ouvert une session d'administration SaaS au préalable en utilisant la fonction [SaaSAdminConnecte](1000019098.md).
- L'Administrateur SaaS gère tous les utilisateurs de tous les clients. Un gestionnaire de compte client ne peut ajouter des utilisateurs que dans son propre compte client.

## Exemple

```wlangage
// Recherche du compte client
C est un saasClient dynamique
C = SaaSAdminChercheClient("Hybrid")

// Ajout d'un nouvel utilisateur
SAM est un saasUtilisateur
SAM.Login = "sam@hybrid.com"
SAM.MotDePasse = "secret"
SaaSAdminAjouteUtilisateur(SAM, C)
```

## Syntaxe

#### Ajouter un utilisateur (utilisation des variables de type saasxxx)

```wlangage
<Résultat> = SaaSAdminAjouteUtilisateur(<Utilisateur> , <Compte client>)
```

`<Résultat>` *Booléen*
> - Vrai si l'ajout a été effectué,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Utilisateur>` *Variable de type saasUtilisateur*
> Nom de la variable de type [saasUtilisateur](1000019083.md) correspondant à la description du nouvel utilisateur.
`<Compte client>` *Variable de type saasClient ou chaîne de caractères*
> Compte client auquel l'utilisateur doit être rattaché.
> Si ce paramètre est une chaîne de caractères, celle-ci peut représenter le nom ou la propriété [RéférenceExterne](1000019072.md) du compte client.

#### Ajouter un utilisateur identifié par son nom

```wlangage
<Résultat> = SaaSAdminAjouteUtilisateur(<Login> , <Mot de passe> , <Compte client>)
```

`<Résultat>` *Booléen*
> - Vrai si l'ajout a été effectué,
> - Faux dans le cas contraire. Pour plus de détails sur l'erreur, utilisez la fonction [ErreurInfo](3013008.md).
`<Login>` *Chaîne de caractères*
> Login du nouvel utilisateur.
`<Mot de passe>` *Chaîne de caractères ou Chaîne secrète*
> Mot de passe du nouvel utilisateur.
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).
`<Compte client>` *Chaîne de caractères*
> Nom ou référence externe du compte client auquel l'utilisateur doit être rattaché.
