# Fonctions de gestion des services

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

Les fonctions de gestion des services sont les suivantes :

| [FinService](1000018711.md) | Termine l'exécution du service en cours. |
| --- | --- |
| [ServiceActualise](1000017107.md) | Demande à un service de relire ses informations de configuration. |
| [ServiceArrête](1000017111.md) | Arrête un service. |
| [ServiceAttendEtat](1000017101.md) | Attend qu'un service soit dans un état spécifique. |
| [ServiceContrôle](1000017108.md) | Envoie un message de contrôle à un service. |
| [ServiceDémarre](1000017110.md) | Démarre un service. |
| [ServiceDésinstalle](1000017098.md) | Désinstalle un service. |
| [ServiceEcritEvénementJournal](1000018807.md) | Ecrit un événement dans le journal des événements Windows. |
| [ServiceEtat](1000017102.md) | Renvoie l'état actuel d'un service. |
| [ServiceExiste](1000018936.md) | Teste si un service est installé. |
| [ServiceInfo](1000017103.md) | Renvoie des informations concernant la configuration d'un service. |
| [ServiceInstalle](1000017099.md) | Installe un service Windows ou un daemon Linux grâce aux informations données dans les membres de la [variable Service](1000017118.md). |
| [ServiceListe](1000017104.md) | Liste les services présents sur le poste en cours ou sur le poste distant indiqué. |
| [ServiceModifie](1000017100.md) | Modifie la configuration d'un service grâce aux informations données dans les membres de la [variable Service](1000017118.md). |
| [ServicePause](1000017109.md) | Met un service en pause. |
| [ServiceRedémarre](1000017112.md) | Redémarre un service (déjà démarré). |
| [ServiceRelance](1000017105.md) | Relance un service en pause. |
| [ServiceTemporise](1000018712.md) | Temporise le service en cours pour la durée indiquée. |

Résumé de l'exemple livré avec WINDEV :  Un service est un programme résident qui peut fonctionner hors session Windows (démarrage de l'application avant le "Login" Windows). Ce type d'application n'a généralement pas d'interface (pas de fenêtres) Par exemple, un service peut être un automate de traitements (automatisation d'un traitement batch). Cet exemple montre comment créer un programme de type 'Service' avec WINDEV. |
