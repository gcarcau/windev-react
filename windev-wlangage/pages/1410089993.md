# adminWBApplication (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Le type **adminWBApplication** permet de définir toutes les caractéristiques avancées d'une application WEBDEV déployée sur un serveur WEBDEV. Les caractéristiques de cette application peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
login est un adminWBAuth
login.AdresseServeur = "http://xxxx"
login.Utilisateur = "monuser"
login.MotDePasse = "monmotdepasse"

Applications est un tableau de adminWBApplication
Applications = AdminWBListeApplication(login)
POUR i = 1 _À_ Applications.Occurrence
     Trace(Applications[i].Nom)
     Trace(Applications[i].ComptePropriétaire)
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type adminWBApplication
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **adminWBApplication** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| ComptePropriétaire | Chaîne de caractères | Compte propriétaire de l'application. |
| Nom | Chaîne de caractères | Nom de l'application. |
| Type | Constante de type Entier | Type de l'application :  - *adminWBTypeSite* : Site. - *adminWBTypeWebserviceSOAP* : Webservice SOAP. - *adminWBTypeWebserviceREST* : Webservice REST. - *adminWBTypeWebSocket* : WebSocket. |

## Remarques

### Fonctions manipulant le type adminWBApplication
Les fonctions manipulant des variables de type **adminWBApplication** sont les suivantes :

| [AdminWBListeApplication](1410089996.md) | Renvoie la liste des applications WEBDEV d'un serveur d'application, pour un compte donnée, et pour un type donné. |
| --- | --- |
| [AdminWBSupprimeApplication](1410089999.md) | Supprime une application du serveur d'application WEBDEV. |
