# KanbanSupprimeCarte (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad)

Supprime une carte d'un champ Kanban ou d'un champ Liste de Kanban.

## Exemple

```wlangage
PROCÉDURE SupprimeCarteAvecToast(Carte est un kbCarte)
KanbanSupprimeCarte(LISTE_A_Faire, Carte.Priorité)
ToastAffiche("Tâche supprimée de la liste A")
```

## Syntaxe

#### Supprimer une carte identifiée par son indice

```wlangage
KanbanSupprimeCarte(<Champ Liste de Kanban> , <Indice>)
```

`<Champ Liste de Kanban>` *Nom de champ*
> Nom du champ Liste de Kanban à manipuler.
`<Indice>` *Entier*
> Indice de la carte à supprimer.

#### Supprimer une carte identifié par une variable kbCarte

```wlangage
KanbanSupprimeCarte(<Champ manipulé> , <Carte>)
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ manipulé :
>
> - Nom d'un champ Kanban.
> - Nom d'un champ Liste de Kanban.
`<Carte>` *Variable de type kbCarte*
> Nom de la variable de type [kbCarte](1410089167.md) correspondant à la carte à supprimer.

**Classification Métier / UI : Code UI**
