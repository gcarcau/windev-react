# SynthèseVocaleEnCours (Fonction)

> **Disponible :** **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Permet de savoir si une lecture est en cours par le moteur de synthèse vocale.

## Exemple

```wlangage
SI SynthèseVocaleEnCours() = Vrai ALORS
	SynthèseVocaleArrête()
FIN
```

## Syntaxe

```wlangage
<Résultat> = SynthèseVocaleEnCours()
```

`<Résultat>` *Booléen*
> - Vrai si une lecture est en cours,
> - Faux dans le cas contraire.

## Remarques

- Seules les lectures lancées par l'application sont prises en compte.
- Pour stopper toutes les lectures en cours, utilisez la fonction [SynthèseVocaleArrête](1000020174.md).
- Les fonctions de synthèse vocale sont disponibles uniquement sur les appareils disposant d'une version d'Android supérieure ou égale à la version 1.6 (api level 4).
  Si la fonction est utilisée avec une version antérieure du système, une erreur fatale sera déclenchée.
  Pour connaître la version du système Android sur laquelle s'exécute l'application, utilisez la fonction [SysVersionAndroid](1000019785.md).
- Les fonctions de synthèse vocale sont disponibles uniquement sur les appareils disposant d'une version d'iOS supérieure à la version 6. La synthèse vocale ne fonctionne pas sur les émulateurs iOS 8.
