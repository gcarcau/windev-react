# DocRedo (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Rétablit la dernière action annulée sur un document de type Traitement de texte.

## Exemple

```wlangage
// Refait la dernière action annulée sur le document
DocRedo(TT_MonDocument)
```

## Syntaxe

```wlangage
<Résultat> = DocRedo(<Document>)
```

`<Résultat>` *Booléen*
> - Vrai si la dernière action annulée a été rétablie,
> - Faux dans le cas contraire.
`<Document>` *Nom de champ ou variable de type Document*
> Document à manipuler. Ce document peut correspondre à :
>
> - une variable de type [Document](1000022461.md).
> - un champ Traitement de texte.

**Composante : wd300mdl.dll**
