# TexteHauteur (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS)

Calcule la hauteur (en pixels) d'un texte affiché dans un champ de saisie, un champ Libellé ou un champ Combo. Il est ainsi possible de prévoir la hauteur occupée par le texte afin d'agrandir le champ si nécessaire.

## Exemple

```wlangage
Res est un réel = TexteHauteur(SAI_Saisie1, "Bonjour")
```

## Syntaxe

```wlangage
<Résultat> = TexteHauteur(<Nom du champ> , <Texte> [, <Option>])
```

`<Résultat>` *Réel*
> Hauteur du texte (en pixels) dans le champ spécifié (en fonction du style du champ).
>
> > _(Android)_ Remarque : La hauteur sera nulle pour les champs non gérés. Seuls les champs de saisie et les champs Libellé sont gérés.
`<Nom du champ>` *Chaîne de caractères*
> Nom du champ de saisie, du champ Libellé ou du champ Combo.
>
> > _(Android)_ Nom du champ de saisie ou du champ Libellé.
`<Texte>` *Chaîne de caractères*
> Texte dont la hauteur doit être calculée.
`<Option>` *Constante optionnelle de type entier*
> Configure le mode de calcul de la hauteur :
>
> | *tAvecMarge* | Permet de prendre en compte les marges définies pour le champ (retrait gauche, retrait droit, ...).  Cette constante peut être combinée avec la constante *tMultiligne*. _(Android, Java)_ Cette constante n'est pas disponible. |  |
> | --- | --- | --- |
> | *tDéfaut* (valeur par défaut) | Hauteur du texte dans le champ. |  |
> | *tMultiligne* | Hauteur du texte en tenant compte des retours à la ligne (automatiques ou forcés par un "Retour Chariot"). |  |
> | *tMonoligne* | Hauteur d'une ligne en tenant compte uniquement des "Retour chariot". |  |
