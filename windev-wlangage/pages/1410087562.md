# Découvrez WINDEV Mobile

## WINDEV Mobile et son environnement

**Ce que vous allez apprendre** :

- Lancement de WINDEV Mobile.

[image: Durée de la leçon] 10 mn

## Présentation

WINDEV Mobile est un Atelier de Génie Logiciel DevOps complet permettant de développer des applications mobile (Android, iOS, Universal Windows, etc.) dans de nombreux domaines : gestion, industrie, médical, restauration, etc.
Les applications développées peuvent inclure l'accès à des informations stockées dans des bases de données.

Les différents tutoriels de WINDEV Mobile vont vous permettre d'apprendre à créer vos applications (avec ou sans base de données), et à les enrichir en utilisant les nombreuses fonctionnalités proposées par WINDEV Mobile.

## Premier lancement de WINDEV Mobile : la page d'accueil

Pour découvrir WINDEV Mobile, nous allons tout simplement lancer WINDEV Mobile 2025.
Identifiez-vous si nécessaire.

L'environnement de développement se lance. La page d'accueil de WINDEV Mobile apparaît.

[image: Page d'accueil]

Cette page d'accueil permet de :

- afficher les actualités des produits PC SOFT,
- créer un projet,
- ouvrir un projet existant,
- ouvrir un exemple,
- accéder aux différents tutoriels existants sur WINDEV Mobile.

**Si vous n'avez jamais lancé WINDEV Mobile 2025**, un assistant de bienvenue se lance :

- Si vous possédiez une ancienne version de WINDEV Mobile, cet assistant permet de récupérer les configurations existantes.
- Si vous êtes nouvel utilisateur, cet assistant permet de paramétrer votre environnement. Vous pouvez ainsi choisir la configuration écran utilisée et paramétrer les Centres de Contrôle.

## Environnement de développement

Pour découvrir les points importants de l'environnement de WINDEV Mobile, ouvrons un premier projet :

1. Depuis la page d'accueil, cliquez sur "Tutoriel".
2. Dans la zone "Tuto - A la découverte de WINDEV Mobile", cliquez sur le lien "Ouvrir le projet exercice".
  [image: Exemple du tutoriel]
3. Le projet correspondant s'ouvre sous l'éditeur. Le tableau de bord du projet est affiché. Le tableau de bord permet d'avoir une vision globale et synthétique de l'état d'avancement d'un projet, via de nombreux éléments (appelés Widgets).
  [image: Tableau de bord du projet]

### L'éditeur
L'environnement de développement de WINDEV Mobile est constitué d'une interface spécifique et de plusieurs éditeurs permettant de créer les différents éléments de vos applications : l'éditeur de fenêtres permet de créer des fenêtres, l'éditeur d'états permet de créer des états, etc.
Affichons une fenêtre dans l'éditeur de fenêtres :

1. Utilisez le raccourci Ctrl + E.
2. Dans la fenêtre qui s'affiche, saisissez le nom de la fenêtre à ouvrir : FEN_Fiche_du_produit.
3. Validez. La fenêtre apparaît sous l'éditeur.

Tous les éditeurs utilisent le même environnement :

[image: Editeur WINDEV Mobile]

- **Menu des éditeurs** (1), affiché sous forme de ruban (nous allons voir sa manipulation dans le paragraphe suivant).
- **Editeur en cours** (2) (ici, éditeur de fenêtres). Cet espace permet de visualiser de manière WYSIWYG (What You See Is What You Get) l'élément en cours de création ou de modification.
- **Volets** (3). L'UI de WINDEV Mobile dispose de plusieurs volets permettant d'accéder rapidement à différents types d'informations.
  Quelques exemples :
  - le volet "Explorateur de projet" (ici, affiché à gauche) permet de lister tous les éléments du projet par catégorie.
  - le volet de recherche (ici, affiché en bas) permet de réaliser des recherches dans tout le projet et ses éléments.
   Si nécessaire, ces volets peuvent être cachés rapidement en utilisant la combinaison de touches Ctrl + W.
- **Barre des documents ouverts** (4). Cette barre permet de visualiser rapidement tous les éléments ouverts. Un simple clic sur le bouton correspondant à l'élément l'affiche dans son propre éditeur.

### Le ruban en détail
Le ruban est un des éléments clé de l'interface des éditeurs. En effet, toutes les options de WINDEV Mobile sont accessibles via ce ruban.
Le ruban est constitué de 3 zones :

[image: Ruban de WINDEV Mobile]

- la zone des boutons, à gauche (1).
- la zone des volets en haut (2).
- la zone des options (3).

Voyons ces différentes zones en détail.
**La zone des boutons (1)**

| [image: Zone de boutons] | La zone des boutons regroupe principalement les **boutons d'accès rapide**. Ces boutons permettent d'effectuer les opérations les plus courantes, bien souvent communes à tous les éditeurs : enregistrer, ouvrir, créer, etc. Le logo du produit permet d'afficher notamment la fenêtre "A propos". |
| --- | --- |

**La zone des volets (2)**
[image: Zone des volets]Les différents volets du ruban permettent d'accéder aux options des différents éditeurs pour le projet en cours. Plusieurs types de volets sont disponibles :

- le volet en cours : Le nom du volet apparaît en gras et un trait orange est affiché sous le nom du volet.
- les volets contextuels, spécifiques à l'élément en cours : Le nom du volet est affiché en orange (ou en bleu en utilisant le thème clair).
- les volets disponibles : Le nom du volet apparaît en blanc (ou en noir en utilisant le thème clair).

**La zone des options (3)**

[image: Zone des options]

En fonction du volet sélectionné, les options affichées dans le ruban diffèrent. Plusieurs types d'options sont disponibles :

- Options à cocher,
- Boutons à cliquer,
- Boutons à flèche permettant de dérouler des options. Deux types de boutons à flèche sont disponibles :
  - les boutons à flèche permettant uniquement de dérouler un menu
  - les boutons à flèche permettant soit de dérouler un menu (clic sur la flèche), soit d'effectuer une action par défaut (clic sur l'icône du bouton).

Les options sont regroupées par groupe. Chaque groupe d'options a un nom et peut avoir un bouton de regroupement [image: Bouton de regroupement]. Ce bouton permet d'effectuer une action spécifique selon le groupe en cours : affichage de la description de l'élément en cours, affichage de l'aide, etc. Dans les différents tutoriels WINDEV Mobile, pour désigner une option de menu, nous parlerons donc de volets et de groupes. Par exemple : Pour afficher l'aide, sous le volet "Accueil", dans le groupe "Aide en ligne", cliquez sur "Aide".

## Le WLangage

Le WLangage est le langage de programmation commun de WINDEV, WEBDEV et WINDEV Mobile.
Si vous ne connaissez pas ce langage, nous vous conseillons de suivre les différentes leçons du tutoriel présentant [les bases de la programmation](1410087570.md). Ces leçons présentent rapidement les différents types de variables, les instructions de base du WLangage, les procédures, etc.

## Conclusion

Nous venons de découvrir l'environnement de WINDEV Mobile. Le tuto [Ma première application iOS/Android](1410087563.md) vous permettra de créer une fenêtre simple, utilisable aussi bien sur Android que sur iOS.

Nous avons terminé cette leçon, pensez à fermer le projet en cours :

1. Sous le volet "Accueil", dans le groupe "Général", déroulez "Fermer" et sélectionnez "Fermer le projet".
2. Validez la sauvegarde des éléments modifiés si nécessaire.
3. La page d'accueil de WINDEV Mobile apparaît.
