# JaugeDésactive (Fonction)

> **Disponible :** **WEBDEV** (WEBDEV - Code Navigateur)

Stoppe le rafraîchissement périodique d'une jauge via Ajax.
**Attention** : Cette fonction ne peut pas être utilisée dans un site PHP ou AWP.

## Exemple

```wlangage
// Stoppe le rafraîchissement de la jauge
JaugeDésactive(JAUGE_Copie)
// Et masque la jauge affichée dans une cellule
CelluleFermeDialogue(CELL_Jauge)
```

## Syntaxe

```wlangage
JaugeDésactive(<Champ Jauge>)
```

`<Champ Jauge>` *Nom de champ*
> Nom du champ Jauge à manipuler.

## Remarques

- Si aucun rafraîchissement n'est actif, la fonction ne fait rien.
- Si le rafraîchissement a été lancé par la fonction [JaugeActive](1000019477.md), la fonction **JaugeDésactive** stoppe les appels périodiques au serveur. Si un traitement serveur est actif, son exécution continue.
- Si le rafraîchissement a été lancé par la fonction [JaugeExécute](1000019481.md), la fonction **JaugeDésactive** stoppe les appels périodiques à la fonction navigateur. Les derniers appels à la fonction ne sont donc pas exécutés.

**Composante : WDJS.DLL**
