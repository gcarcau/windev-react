# Impression d'un état en WINDEV

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes)

## Présentation

Lors de la création d'un état, il est possible de tester directement cet état depuis l'éditeur d'états.
Il est également possible d'intégrer cet état à vos applications. L'utilisateur pourra ainsi lancer l'impression de l'état directement depuis un bouton, une option de menu par exemple.
**Si vous utilisez le logiciel Etats & Requêtes**, il est possible d'imprimer un état :

- soit en lançant une impression (icône ).
- soit en testant l'état (icône ).

Il n'est donc pas nécessaire de programmer l'impression de l'état.
Pour que l'impression d'états réalisés avec le logiciel Etats & Requêtes soit possible directement à partir d'une application WINDEV, le fournisseur de l'application WINDEV doit prévoir cette fonctionnalité dans son application.

Le fournisseur peut par exemple intégrer une fenêtre permettant à l'utilisateur final :

- de sélectionner un état réalisé avec le logiciel Etats & Requêtes.
- puis de lancer l'exécution de cet état.

## Principe d'impression en WINDEV

Quel que soit le type d'état à imprimer, le principe de lancement d'un état est le suivant :

1. Spécifier le mode d'impression de l'état (aperçu, impression directe, génération d'une page HTML, etc.) avec la fonction [iAperçu](3046069.md) ou la fonction [iDestination](3046074.md)
2. Lancer l'impression avec la fonction [iImprimeEtat](3046032.md).

Ce principe doit être adapté et complété selon la source de données utilisée dans chaque état.
