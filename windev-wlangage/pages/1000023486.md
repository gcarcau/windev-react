# Parent (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

La propriété **Parent** permet de connaître l'élément parent d'un élément. Cette propriété est utilisable sur :

- une variable de type [docElément](1000022484.md).
- une variable de type [docParagraphe](1000022483.md).
- Nouveauté 2025
  une variable de type [jsonLecteur](1410090783.md).
  **Attention** : Cette fonctionnalité est disponible uniquement à partir de la version 2025 Update 3.
- Nouveauté Abonnement
  une variable de type [OptionsOuvertureFenêtre](1410091298.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
