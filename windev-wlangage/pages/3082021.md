# zipEstMulti (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Renvoie le type de l'archive : archive mono-partie ou archive multi-parties.

## Exemple

```wlangage
MonArchive est une zipArchive
// Ouverture de l'archive "MonArchive"
ResOuvreArchive = zipOuvre(MonArchive, "D:\Sauvegardes\Sauvegarde.zip")
SI ResOuvreArchive = 0 ALORS
	...
FIN
// Archive mono-partie ou multi-parties ?
ResEstMulti = zipEstMulti(MonArchive)
// Affichage du résultat
SI ResEstMulti = Vrai ALORS
	Info("L'archive est multi-parties")
SINON
	Info("L'archive est mono-partie")
FIN
```

## Syntaxe

```wlangage
<Résultat> = zipEstMulti(<Archive>)
```

`<Résultat>` *Booléen*
> - Vrai si l'archive est multi-parties,
> - Faux si l'archive est mono-partie.
`<Archive>` *Chaîne de caractères ou variable de type zipArchive*
> Nom de l'archive à manipuler.
> Ce nom peut correspondre :
>
> - soit au nom d'une archive défini avec la fonction [zipOuvre](3082044.md) ou la fonction [zipCrée](3082003.md).
> - soit au nom d'une variable de type [zipArchive](1000018679.md).

## Remarques

### Conditions d'utilisation

- La recherche du type d'archive peut être réalisée uniquement si l'archive existe (la création d'une archive s'effectue avec la fonction [zipCrée](3082003.md)).
- Cette fonction est disponible pour les archives au format WDZ, ZIP et 7z.

> _(Linux, iPhone/iPad, Widget IOS, Mac Catalyst)_ Rappel : Seules les archives au format ZIP, TAR, gzip et TGZ (TAR.GZ) sont disponibles.

### Actions réalisables sur une archive multi-parties
Certaines fonctions d'archivage sont utilisables uniquement sur des archives mono-partie (ajout et suppression de fichiers, création d'un exécutable auto-extractible, etc.). Pour effectuer ces opérations, il suffit de regrouper les sous-archives ([zipRegroupe](3082046.md)) pour obtenir une archive mono-partie.
A partir d'une archive multi-parties, il est uniquement possible de :

- Regrouper les différentes parties (fonction [zipRegroupe](3082046.md)).
- Obtenir diverses informations sur l'archive et sur les fichiers de l'archive (fonctions [zipExtraitChemin](3082023.md), [zipInfoFichier](3082040.md), [zipListeFichier](3082031.md), etc.).
- Extraire les fichiers (fonctions [zipExtraitFichier](3082019.md), [zipExtraitTout](3082011.md)).

### Actions réalisables sur une archive mono-partie
Toutes les fonctions d'archivage sont utilisables sur des archives mono-partie, exceptée la fonction [zipRegroupe](3082046.md) (permettant de regrouper les différentes parties d'une archive entre elles).
