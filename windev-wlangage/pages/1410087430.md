# 7. HFSQL : les fichiers créés physiquement

> **Disponible :** **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur)

| [Page précédente](1410087428.md) | [Sommaire](1410087102.md) | [Page suivante](1410087431.md) |
| --- | --- | --- |

L'éditeur d'analyses permet de décrire la structure des fichiers de données.
Selon les informations saisies sous l'éditeur d'analyses, différents fichiers sont créés physiquement.**Remarque** : Ce schéma présente uniquement les principaux fichiers créés. D'autres fichiers spécifiques peuvent être créés si le fichier de données utilise la journalisation, les transactions ou encore la réplication.
