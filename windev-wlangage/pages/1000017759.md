# <Variable gglConnexion>.ListeGroupeContact (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Récupère la liste des groupes de contacts associés au compte Google spécifié.

## Exemple

```wlangage
// Connexion
Cnx est une gglConnexion
...
// Récupère les groupes de contacts
tabGroupes est un tableau de gglGroupeContact
tabGroupes = Cnx.ListeGroupeContact()
// Parcours des groupes
Grp est un gglGroupeContact dynamique
POUR TOUT Grp DE tabGroupes
	Trace(Grp.Nom)
FIN
```

## Syntaxe

#### Récupérer les groupes d'un contact

```wlangage
<Résultat> = <Connexion Google>.ListeGroupeContact(<Contact>)
```

`<Résultat>` *Tableau de variables gglGroupeContact*
> Tableau de variables de type [gglGroupeContact](1000017576.md).
`<Connexion Google>` *Variable de type gglConnexion*
> Nom de la variable de type [gglConnexion](1000018009.md) à utiliser. Cette connexion a été validée avec la fonction [<Variable gglConnexion>.Connecte](1000021455.md).
`<Contact>` *Variable de type gglContact*
> Nom de la variable de type [gglContact](1000017434.md) dont on veut connaître les groupes associés.

#### Récupérer les groupes de la connexion

```wlangage
<Résultat> = <Connexion Google>.ListeGroupeContact()
```

`<Résultat>` *Tableau de variables gglGroupeContact*
> Tableau de variables de type [gglGroupeContact](1000017576.md).
`<Connexion Google>` *Nom de champ*
> Nom de la variable de type [gglConnexion](1000018009.md) à utiliser. Cette connexion a été validée avec la fonction [<Variable gglConnexion>.Connecte](1000021455.md).

## Remarques

### Cas d'erreurs possibles :

- La connexion Internet n'est pas valide.
- L'authentification n'a pas pu être réalisée correctement.
- La réponse XML du serveur n'est pas lisible.

Pour savoir si une erreur est survenue, utilisez la variable [ErreurDétectée](3087001.md).
