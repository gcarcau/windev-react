# NationVersNom (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch) · **Autres** (Procédures stockées)

Renvoie le nom de la langue correspondant à une nation.

## Exemple

```wlangage
// Connaître le nom de la langue correspondant à la nation italienneResNom est une chaîne de caractèresResNom = NationVersNom(nationItalien)
```

## Syntaxe

```wlangage
<Résultat> = NationVersNom(<Nation>)
```
