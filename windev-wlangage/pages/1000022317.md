# <Fenêtre>.EdDésélectionneTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Désélectionne tous les champs lors de la modification de l'interface par l'utilisateur final (mode "Modification de l'UI par l'utilisateur final" activé).

## Exemple

```wlangage
// Active l'édition sur la fenêtre
FEN_Formulaire.EdActive(Vrai)
FEN_Formulaire.EdDésélectionneTout()
```

## Syntaxe

```wlangage
<Fenêtre>.EdDésélectionneTout()
```

`<Fenêtre>` *Nom de fenêtre*
> Nom de la fenêtre ou de la fenêtre interne à manipuler. Cette fenêtre doit être en mode modification (fonction [<Fenêtre>.EdActive](1000022294.md)).

**Composante : wd300obj.dll**
