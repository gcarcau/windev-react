# <Tableur>.SupprimeTout (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Supprime toutes les données d'un champ Tableur présent dans une fenêtre (cellules, formules, taille et mises en forme d'entêtes). La liste des opérations stockées dans les "undo/redo" est également vidée : la suppression n'est donc pas annulable.

## Exemple

```wlangage
TBLR_Tableur.SupprimeTout()
TBLR_Tableur.AjouteDonnée("A2", 2)
```

## Syntaxe

```wlangage
<Champ Tableur>.SupprimeTout()
```

`<Champ Tableur>` *Nom de champ*
> Nom du champ Tableur à manipuler.
