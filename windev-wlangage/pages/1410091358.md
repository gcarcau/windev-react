# Fonctions de gestion des utilisateurs sur le serveur d'authentification OAuth WEBDEV

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Les fonctions de gestion des utilisateurs sur le serveur d'authentification OAuth WEBDEV sont les suivantes :
| Nouveauté Abonnement [wdbaasCréeUtilisateur](1410091289.md) | Crée un nouvel utilisateur dans le serveur d'authentification OAuth. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.** |
| --- | --- |
| Nouveauté Abonnement [wdbaasInfoUtilisateur](1410091290.md) | Récupère les informations concernant un utilisateur sur le serveur OAuth WEBDEV. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.** |
| Nouveauté Abonnement [wdbaasListeUtilisateur](1410091288.md) | Renvoie la liste des utilisateurs du serveur d'authentification OAuth WEBDEV. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.** |
| Nouveauté Abonnement [wdbaasModifieUtilisateur](1410091291.md) | Modifie un utilisateur existant dans le serveur d'authentification OAuth WEBDEV. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.** |
| Nouveauté Abonnement [wdbaasSupprimeUtilisateur](1410091292.md) | Supprime un utilisateur existant du serveur d'authentification OAuth WEBDEV. **Cette fonction est une nouveauté disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 4.** |

## Remarques

### Conditions d'utilisation
L'utilisation des fonctions de gestion d'un utilisateur sur un serveur OAuth WEBDEV nécessite la mise en place de droits au niveau de l'identifiant OAuth utilisé. Ces droits sont mis en place dans le site d'administration des services BaaS de WEBDEV.
Il est possible par exemple de donner les droits suivants :

- Autoriser la création d'utilisateurs uniquement.
- Autoriser la lecture des informations des utilisateurs.
- Tout autoriser (lecture, création, modification, suppression).
- etc.

Pour plus de détails, consultez [Site d'administration des services BaaS](1410086668.md).
