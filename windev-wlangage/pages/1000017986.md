# DatePublication (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

La propriété **DatePublication** permet de connaître la date du dernier accès à un élément. Cette propriété est utilisable sur :

- une variable de type [gglAgenda](1000017418.md).
- une variable de type [rssCanal](1000017769.md).
- une variable de type [rssFlux](1000017795.md).
- une variable de type [rssEntrée](1000017792.md).
