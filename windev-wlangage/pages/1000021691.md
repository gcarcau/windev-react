# Attribut (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **Attribut** permet de gérer des attributs. Cette propriété est disponible sur :

- une variable de type [xmlNoeud](1000018786.md).
- une variable de type [xmlLecteur](1000023392.md).
- une variable de type [hbDescriptionTable](1000021688.md).
- une variable de type [hbDescriptionColonne](1000021694.md).
- une variable de type [xpathRésultat](1000021967.md).
