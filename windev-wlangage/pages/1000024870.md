# xlsCommentaire (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Le type **xlsCommentaire** permet de définir toutes les caractéristiques avancées d'un commentaire dans une cellule d'une feuille XLS ou dans une cellule d'un champ Tableur. Les caractéristiques de ce commentaire peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.
**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

Nouveauté 2025

> _(Android)_ Ce type de variable est désormais disponible pour les applications Android.

> _(Widget Android)_ Ce type de variable est désormais disponible en mode Widget Android.

> _(iPhone/iPad)_ Ce type de variable est désormais disponible pour les applications iPhone/iPad.

## Exemple

```wlangage
// Ajoute un commentaire pour la cellule A1 et le rend visible
TBLR_Tableur["A1"].Commentaire.Texte = "Titre" + RC + "ma note"
TBLR_Tableur["A1"].Commentaire.Visible = Vrai
```

```wlangage
sFic est une chaîne	= "fichier.xlsx"
xlsDoc est un xlsDocument
xlsDoc.AjouteFeuille("F1")
xlsDoc..Cellule[2, 5] = xlsCoordonnéesVersNom(2, 2)
xlsDoc..Commentaire[2, 5].Texte = "Commentaire"
xlsDoc..Commentaire[2, 5].Rectangle.X = 10
xlsDoc..Commentaire[2, 5].Rectangle.Y = 10
xlsDoc..Commentaire[2, 5].Rectangle.Largeur = 40
xlsDoc..Commentaire[2, 5].Rectangle.Hauteur = 20
xlsDoc..Commentaire[2, 5].Visible = Vrai
xlsDoc.Sauve(sFic)
xlsDoc.Ferme()
```

## Propriétés

### Propriétés spécifiques à la description des variables de type xlsCommentaire
Les propriétés suivantes peuvent être utilisées pour manipuler un commentaire d'une cellule :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Position | Chaîne de caractères | Cellule pour laquelle le commentaire est affiché (par exemple, "A3").  **Cette propriété est disponible en lecture seulement.** |
| Rectangle | Variable de type [Rectangle](1514079.md) | Taille et position en pixels du rectangle contenant le commentaire.  Remarque : L'origine du rectangle 0,0 est donnée par rapport au point haut droit de la cellule. _(Android, Widget Android)_ Cette propriété n'est pas disponible. |
| Texte | Chaîne de caractères | Texte du commentaire. |
| Visible | Booléen | - Vrai pour afficher le commentaire, - Faux pour rendre le commentaire invisible. Dans ce cas, seul un triangle rouge dans le coin haut droit de la cellule permettra à l'utilisateur de savoir que la cellule est associée à un commentaire. |
