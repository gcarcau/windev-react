# Fonctions de gestion des documents HTML (syntaxe préfixée)

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Les fonctions suivantes (syntaxe préfixée) permettent de manipuler des documents HTML :

| [<Variable htmlDocument>.ChercheElémentParBalise](1000026312.md) | Cherche les éléments d'un document HTML correspondant à une balise. |
| --- | --- |
| [<Variable htmlDocument>.ChercheElémentParClasse](1000026314.md) | Cherche les éléments d'un document HTML pour lesquels l'attribut "class" correspond à une valeur spécifique. |
| [<Variable htmlDocument>.ChercheElémentParID](1000026316.md) | Cherche l'élément d'un document HTML dont l'attribut "ID" correspond à une valeur spécifique. |
| [<Variable htmlDocument>.ChercheElémentParNom](1000026318.md) | Cherche les éléments d'un document HTML dont l'attribut "name" correspond à une valeur spécifique. |
| [<Variable htmlDocument>.ConstruitChaîne](1000026320.md) | Génère une chaîne de caractères au format UTF8 contenant un document HTML. |
| [<Variable htmlDocument>.Sauve](1000026321.md) | Sauve le contenu d'une variable de type [htmlDocument](1000025910.md) dans un fichier HTML. |
| [<Variable htmlNoeud>.ChercheElémentParBalise](1000026313.md) | Cherche les éléments d'un noeud HTML correspondant à une balise. |
| [<Variable htmlNoeud>.ChercheElémentParClasse](1000026315.md) | Cherche les éléments d'un noeud HTML pour lesquels l'attribut "class" correspond à une valeur spécifique. |
| [<Variable htmlNoeud>.ChercheElémentParID](1000026317.md) | Cherche l'élément d'un noeud HTML dont l'attribut "ID" correspond à une valeur spécifique. |
| [<Variable htmlNoeud>.ChercheElémentParNom](1000026319.md) | Cherche les éléments d'un noeud HTML dont l'attribut "name" correspond à une valeur spécifique. |
| [<Variable htmlNoeud>.DésencadreTousLesFils](1410088108.md) | Supprime le noeud spécifié dans un document HTML sans supprimer ses fils, qui prennent sa place. |
| [<Variable htmlNoeud>.Encadre](1410088117.md) | Encadre le noeud spécifié dans un noeud donné d'un document HTML. |
| [<Variable htmlNoeud>.EncadreTousLesFils](1410088109.md) | Encadre tous les fils du noeud donné dans un nouveau noeud dans un document HTML. |
| [<Variable htmlNoeud>.InsèreAprès](1410088110.md) | Ajoute un noeud après le noeud spécifié dans un document HTML. |
| [<Variable htmlNoeud>.InsèreAvant](1410088111.md) | Ajoute un noeud avant le noeud spécifié dans un document HTML. |
| [<Variable htmlNoeud>.InsèreDernierFils](1410088112.md) | Ajoute un fils après les fils du noeud courant dans un document HTML. |
| [<Variable htmlNoeud>.InsèrePremierFils](1410088113.md) | Ajoute un fils au début des fils du noeud courant dans un document HTML. |
| [<Variable htmlNoeud>.ModifieAttribut](1410088114.md) | Ajoute ou modifie un attribut du noeud courant du document HTML. |
| [<Variable htmlNoeud>.Supprime](1410088115.md) | Supprime le noeud spécifié et son arborescence dans un document HTML. |
| [<Variable htmlNoeud>.SupprimeAttribut](1410088118.md) | Supprime un attribut donné |
| [<Variable htmlNoeud>.SupprimeFils](1410088116.md) | Supprime un noeud donné dans le noeud courant d'un document HTML. |
