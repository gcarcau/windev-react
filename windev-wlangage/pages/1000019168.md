# XMLChercheNamespaceParURI (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Recherche un namespace (espace de nommage) XML à partir de son URI (Universal Resource Identifier) dans un noeud et dans les parents de ce noeud.

## Exemple

```wlangage
gcDocumentXML est un xmlDocument
gcDocumentXML = XMLOuvre("c:\temp\fichier.xml", depuisFichier)

cNoeud est un xmlNoeud = gcDocumentXML..NoeudRacine[1]
cNamespace est un xmlNamespace = XMLChercheNamespaceParURI(cNoeud, "http://schemas.xmlsoap.org/wsdl/")

SI ErreurDétectée = Vrai ALORS
	Info("Le namespace n'a pas été trouvé")
SINON
	Info("Namespace trouvé : ", cNamespace.Nom)
FIN
```

## Syntaxe

```wlangage
<Résultat> = XMLChercheNamespaceParURI(<Noeud de départ> , <URI>)
```

`<Résultat>` *Variable de type xmlNamespace*
> Variable de type [xmlNamespace](1000018803.md) correspondant au namespace de l'URI recherché.
`<Noeud de départ>` *Variable de type xmlNoeud*
> Nom de la variable de type [xmlNoeud](1000018786.md) correspondant au noeud du document XML à partir duquel le namespace doit être recherché.
`<URI>` *Chaîne de caractères Unicode*
> URI du namespace à rechercher.
