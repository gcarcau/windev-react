# MatCopie (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Crée la copie d'une matrice. La nouvelle matrice a les mêmes dimensions que la matrice de base. Tous les éléments de la matrice d'origine sont copiés dans la nouvelle matrice.

## Exemple

```wlangage
// Copie d'une matrice
ResCopie = MatCopie("MaMatrice", "MaMatriceCopie")
```

## Syntaxe

```wlangage
<Résultat> = MatCopie(<Matrice à copier> , <Matrice copiée>)
```

`<Résultat>` *Booléen*
> - Vrai si la matrice a été copiée,
> - Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Matrice à copier>` *Chaîne de caractères*
> Nom de la matrice à copier, défini avec la fonction [MatCrée](3050058.md).
`<Matrice copiée>` *Chaîne de caractères*
> Nom de la matrice copiée, automatiquement créée lors de la copie.

## Remarques

### Existence de la matrice copiée
L'existence de la matrice n'est pas vérifiée. Si la matrice existait auparavant, cette matrice est écrasée. Pour vérifier l'existence d'une matrice, utilisez la fonction [MatExiste](3050076.md).
