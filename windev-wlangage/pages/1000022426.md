# DocUndoOccurrence (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Renvoie le nombre d'actions annulables sur un document de type Traitement de texte.

## Exemple

```wlangage
// Affiche le nombre d'actions annulables sur le document
Info(DocUndoOccurrence(TT_MonDocument))
```

## Syntaxe

```wlangage
<Résultat> = DocUndoOccurrence(<Document>)
```

`<Résultat>` *Entier*
> Nombre d'actions annulables.
`<Document>` *Nom de champ ou variable de type Document*
> Document à manipuler. Ce document peut correspondre à :
>
> - une variable de type [Document](1000022461.md).
> - un champ Traitement de texte.
