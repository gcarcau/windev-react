# MembreVariant (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Apple Watch)

Le type **MembreVariant** est un type avancé, correspondant à un tableau de membres, chaque membre étant une variable de type [variant](1514019.md).
Ce type de variable ne doit être utilisé que dans des cas très spécifiques, par exemple lors du traitement du résultat de la fonction [JSONVersVariant](1000021052.md).

## Propriétés

### Propriétés spécifiques à la description des variables de type MembreVariant
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **MembreVariant** :

| Nom de la propriété | Type manipulé | Effet |
| --- | --- | --- |
| Existe | Booléen | - Vrai si l'élément existe, - Faux dans le cas contraire.   **Cette propriété est disponible en lecture seulement**. |
| Nom | Chaîne de caractères | Nom de l'élément.  **Cette propriété est disponible en lecture seulement**. |
| Occurrence | Entier | Nombre d'éléments.  **Cette propriété est disponible en lecture seulement**. |
| Type | Constante de type Entier | Type de l'élément (mêmes valeurs que celles de la fonction [TypeVar](3013056.md)). **Cette propriété est disponible en lecture seulement**. |
| Valeur |  | Valeur de l'élément. |
