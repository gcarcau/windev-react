# <Variable Pile>.Empile (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Empile un élément dans une pile. L'élément est ajouté au sommet de la pile.
Nouveauté 2025

> _(WEBDEV - Code Navigateur)_ Cette fonction est désormais disponible en code navigateur.

## Exemple

```wlangage
MaPile est une Pile d'entiers

// On empile les valeurs 1, 2 et 3
MaPile.Empile(1)
MaPile.Empile(2)
MaPile.Empile(3)

// Affichage de la trace : 3, 2, 1
x est un entier
TANTQUE MaPile.Dépile(x)
	Trace(x)
FIN
```

## Syntaxe

```wlangage
<Pile>.Empile(<Valeur>)
```

`<Pile>` *Variable de type Pile*
> Nom de la variable de type [Pile](1514022.md) à manipuler.
`<Valeur>` *Type d'éléments manipulés par la pile*
> Valeur à ajouter au sommet de la pile.

## Remarques

### Gestion du multithread
Si la propriété [AjoutTerminé](1000018388.md) vaut Vrai, la fonction **<Variable Pile>.Empile** échoue et provoque une erreur WLangage.
> _(WEBDEV - Code Navigateur)_ La gestion du multithread n'est pas disponible.

**Composante : wd300vm.dll**
