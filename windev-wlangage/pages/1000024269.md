# <Traitement de texte>.Ouvre (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

Ouvre un fichier Traitement de texte (format docx) en mode Lecture/Ecriture. Le fichier docx est ouvert et bloqué jusqu'à sa fermeture.
**Remarque** : Pour créer un fichier docx sans utiliser un fichier initial, il suffit de créer une variable de type [Document](1000022461.md) (la fonction **<Traitement de texte>.Ouvre** est alors inutile).

## Exemple

```wlangage
TT_MonTT.Ouvre("C:\Users\test\Documents\fichier.docx")

SI ErreurDétectée() ALORS
	Erreur(ErreurInfo())
	RETOUR
FIN
```

## Syntaxe

```wlangage
<Résultat> = <Champ Traitement de texte>.Ouvre(<Chemin> [, <Mot de passe>])
```

`<Résultat>` *Booléen*
> - Vrai si le fichier docx a été ouvert dans le champ Traitement de texte,
> - Faux dans le cas contraire.
`<Champ Traitement de texte>` *Nom de champ*
> Nom du champ Traitement de texte dans lequel le fichier docx doit être ouvert.
`<Chemin>` *Chaîne de caractères*
> Correspond à un des éléments suivants :
>
> - Chemin complet ou relatif du fichier docx à ouvrir (260 caractères maximum).
> - Nom de la variable de type Buffer contenant le document docx à afficher dans le champ Traitement de texte.
> - Nom de la rubrique mémo contenant le document docx à afficher dans le champ Traitement de texte. Ce paramètre est de la forme : <Fichier de données>.<Rubrique>.
`<Mot de passe>` *Chaîne de caractères optionnelle ou Chaîne secrète*
> Mot de passe d'ouverture du fichier docx à manipuler (si le fichier est protégé par un mot de passe d'ouverture).
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).
