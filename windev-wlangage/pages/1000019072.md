# saasClient (Type de variable)

> **Disponible :** **WINDEV** (Windows, Linux) · **WEBDEV** (Windows, Linux)

Le type **saasClient** permet de définir toutes les caractéristiques avancées d'un Compte Client SaaS.
Les caractéristiques de ce compte client peuvent être définies et modifiées à l'aide de différentes propriétés WLangage.

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
C est un saasClient
C.Nom = "Hybrid"

SaaSAdminAjouteClient(C)
```

## Propriétés

### Propriétés spécifiques à la description des variables de type saasClient
Les propriétés suivantes peuvent être utilisées pour manipuler un compte client SaaS :

| **Propriété** | **Type manipulé** | **Effet** |
| --- | --- | --- |
| Informations | Chaîne de caractères | Informations diverses. Cette propriété n'est accessible que par l'administrateur du Webservice SaaS (le compte "admin"). |
| Nom | Chaîne de caractères | Nom du compte client. Généralement, le nom de la société cliente, sa raison sociale, ou les nom et prénom de la personne physique. Cette propriété ne peut pas être vide et doit être unique pour chaque Webservice SaaS. |
| RéférenceExterne | Chaîne de caractères | La référence externe permet de stocker un lien vers un Système d'Information externe au Serveur d'Application WEBDEV. Le contenu de cette propriété est libre et son emploi n'est pas obligatoire. |
