# EntierVersHeure (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst) · **Autres** (Procédures stockées)

Transforme un entier en une heure au format HHMMSSCC.

## Exemple

```wlangage
EntierVersHeure(0)	 // Retourne "00000000"

// Attente de 4 secondes
Départ, t sont des entiers
Départ = HeureVersEntier(HeureSys())
BOUCLE
	t = HeureVersEntier(HeureSys()) - Départ
	// Affiche le temps écoulé entre 0 et 4s
	Trace(EntierVersHeure(t))
	// Sort si les 4 secondes sont écoulées
	SI t > 400 ALORS SORTIR
FIN
```

## Syntaxe

```wlangage
<Résultat> = EntierVersHeure(<Valeur>)
```

`<Résultat>` *Chaîne de caractères ou variable de type Heure*
> Chaîne de caractères au format HHMMSSCC où HH représente les heures, MM les minutes, SS les secondes et CC les centièmes de seconde.
`<Valeur>` *Entier*
> Nombre de centièmes de seconde écoulés depuis minuit (00:00:00:00). L'entier 0 correspond à minuit. <Valeur> ne peut pas dépasser 8.639.999 (24 heures - 1 centième de seconde).

## Remarques

### Format HHMMSSCC
Pour obtenir l'heure sous un format différent de HHMMSSCC, il faut formater la chaîne avec les fonctions [HeureVersChaîne](3027023.md), [Droite](3024016.md), [Gauche](3024001.md), etc.
Le format HHMMSSCC a été choisi car il permet de comparer deux heures au centième de seconde près.

### Validité de l'heure
La validité de l'heure passée en paramètre est vérifiée. Un message est affiché en cas d'heure invalide. La validité de l'heure peut être vérifiée avec la fonction [HeureValide](3027021.md).
