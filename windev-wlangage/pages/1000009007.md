# PiloteOKAnnuler (Fonction)

> **Disponible :** **WINDEV** (Windows, Code Utilisateur (MCU))

Pilote le prochain appel de la fonction [OKAnnuler](3021004.md), puis clique automatiquement sur le bouton passé en paramètre.

## Exemple

```wlangage
// Fermeture automatique de la prochaine boîte de dialogue OKAnnuler
// La réponse sur lequel le clic aura lieu est Ok
PiloteOKAnnuler(Vrai)

// Traitement
// ...

SELON OKAnnuler("Souhaitez-vous enregistrer les modifications ?")
	CAS Vrai
	// Enregistrement des modifications
	CAS Faux
	// Annulation des modifications
FIN // Le message est fermé automatiquement, par un clic sur Ok
```

## Syntaxe

```wlangage
PiloteOKAnnuler(<Bouton>)
```

`<Bouton>` *Constante de type entier*
> Indique le bouton de la fenêtre OkAnnuler sur lequel le clic doit avoir lieu :
>
> | *Faux* | Clic sur le bouton [ANNULER] |
> | --- | --- |
> | *Vrai* | Clic sur le bouton [OK] |

## Remarques

### Vérification de la fonction
L'existence d'une fonction de pilotage ([PiloteAvertissement](1000009001.md), [PiloteErreur](1000009005.md), [PiloteInfo](1000009006.md), ...) est vérifiée lors de l'appel de la fonction de dialogue associée ([Avertissement](3021009.md), [Erreur](3021013.md), [Info](3021011.md), ...).

### Différence de type de message
L'ordre des fonctions [PiloteXXX](1000009002.md) doit respecter l'ordre d'affichage des fonctions [Erreur](3021013.md), [Info](3021011.md), ... Dans le cas contraire, une erreur fatale sera déclenchée.
