# MarkdownLien (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad)

Ajoute un lien cliquable dans une chaîne Markdown. Il est ainsi possible d'ajouter un lien dans le libellé d'un champ au format Markdown.

## Exemple

```wlangage
sLien est chaîne = MarkdownLien("Détail", ProcAfficheDevis,"25471")
LIB_MD = "Cliquez sur " + sLien + " pour afficher le devis numéro **25471**"
```

```wlangage
sLien est chaîne = MarkdownLien("Site PCSoft", "http://www.pcsoft.fr")
LIB_MD = "Consultez " + sLien + " pour plus de détails"
```

## Syntaxe

#### Générer un lien cliquable pour exécuter une procédure WLangage

```wlangage
<Résultat> = MarkdownLien(<Texte> , <Procédure WLangage> [, <Paramètre de la procédure>])
```

`<Résultat>` *Chaîne de caractères*
> Valeur du lien. Cette valeur peut être concaténée à une autre chaîne. Cette chaîne est valide uniquement dans la fenêtre en cours.
`<Texte>` *Chaîne de caractères*
> Texte à afficher dans le lien.
`<Procédure WLangage>` *Nom de procédure*
> Nom de la procédure WLangage (également nommée "callback") qui sera appelée lors du clic sur le lien.
`<Paramètre de la procédure>` *Type attendu (optionnel)*
> Valeur du paramètre à passer à la procédure.

#### Générer un lien cliquable pour afficher une URL externe

```wlangage
<Résultat> = MarkdownLien(<Texte> , <URL à afficher>)
```

`<Résultat>` *Chaîne de caractères*
> Valeur du lien. Cette valeur peut être concaténée à une autre chaîne. Cette chaîne est valide uniquement dans la fenêtre en cours.
`<Texte>` *Chaîne de caractères*
> Texte à afficher dans le lien.
`<URL à afficher>` *Chaîne de caractères*
> URL externe à afficher lors du clic sur le lien.
