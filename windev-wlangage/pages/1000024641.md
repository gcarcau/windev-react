# <Variable WDPic>.SymétrieVerticale (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Retourne l'image contenue dans une variable de type [WDPic](1000023503.md) (sur le calque d'arrière-plan) par rapport à un axe vertical (symétrie par rapport à un axe vertical).

## Exemple

```wlangage
MonImageWDPic est un WDPic = "Test.bmp"
// Symétrie verticale de l'image contenue dans la variable WDPic
MonRésultat est un booléen
MonRésultat = MonImage.SymétrieVerticale()
SI MonRésultat = Faux ALORS Erreur("L'opération a échoué")
IMG_MonDessin = MonImage
```

## Syntaxe

```wlangage
<Résultat> = <Image WDPic>.SymétrieVerticale()
```

`<Résultat>` *Booléen*
> - Vrai si la symétrie a été effectuée,
> - Faux dans le cas contraire.
`<Image WDPic>` *Variable de type WDPic*
> Nom de la variable de type [WDPic](1000023503.md) à manipuler. Seul le calque d'arrière-plan sera manipulé.
> La symétrie est réalisée par rapport à l'axe vertical médian de l'image. L'image est directement modifiée.

## Remarques

### Fin du dessin
Si la fonction [<Variable WDPic>.FinDessin](1000024472.md) est appelée dans le même traitement que la fonction **<Variable WDPic>.SymétrieVerticale**, la transformation de l'image ne sera pas affichée.

**Composante : wd300pnt.dll**
