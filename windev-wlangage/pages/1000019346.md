# OutlookListeProfil (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Liste les profils Outlook disponibles.

## Exemple

```wlangage
ListeProfil est une chaîne
ListeProfil = OutlookListeProfil()
POUR TOUTE CHAÎNE sUnProfil DE ListeProfil SÉPARÉE PAR RC
	Trace(sUnProfil)
FIN
```

## Syntaxe

```wlangage
<Résultat> = OutlookListeProfil()
```

`<Résultat>` *Chaîne de caractères*
> Liste des profils Outlook disponibles séparés par RC (Retour Chariot).

**Composante : wd300com.dll**
