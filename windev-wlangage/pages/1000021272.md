# SignalFerme (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS, Apple Watch)

Ferme un signal de synchronisation entre plusieurs threads.

## Syntaxe

```wlangage
SignalFerme(<Signal>)
```

`<Signal>` *Chaîne de caractères ou variable de type SignalAutomatique ou SignalManuel*
> Nom du signal à fermer. Ce nom peut correspondre :
>
> - à une chaîne de caractères,
> - au nom d'une variable de type [SignalManuel](1000021275.md),
> - au nom d'une variable de type [SignalAutomatique](1000021270.md).

## Remarques

- Cette fonction est équivalente à la syntaxe suivante de la fonction [SignalModifie](3077017.md) :
  ```wlangage
  SignalModifie(<Signal>, signalFermé)
  ```
- **Cas d'un signal automatique** : Le signal reste fermé.
  **Nouveaux threads** : Si d'autres threads arrivent, ils sont mis en attente.
- **Cas d'un signal manuel** : Le signal se ferme.
  **Nouveaux threads** : Si d'autres threads arrivent, ils sont mis en attente.

**Classification Métier / UI : Code neutre**

**Composante : wd300vm.dll**
