# SysLibèreDC (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU))

Libère le DC (Device Context) en cours récupéré par la fonction [SysRécupèreDC](3073023.md).
**Remarque** : Si un DC (Device Context) a été récupéré pendant le déroulement d'une application et qu'aucune libération n'a été faite, le DC (Device Context) en cours est automatiquement libéré à la fin de l'application.

## Exemple

```wlangage
// Libération du DC
SysLibèreDC()
```

## Syntaxe

```wlangage
SysLibèreDC()
```

**Composante : wd300std.dll**
