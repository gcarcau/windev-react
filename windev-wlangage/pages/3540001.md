# Centre de Contrôle HFSQL : Présentation

> **Disponible :** **WINDEV** (Windows, Linux, Java) · **WEBDEV** (Windows, Linux, PHP) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Apple Watch, Mac Catalyst)

## Présentation

Le Centre de Contrôle HFSQL permet de gérer les différentes bases de données HFSQL (Réseau, Mobile, Client/Serveur) ainsi que les bases tierces.

## Lancement du Centre de Contrôle HFSQL

### Lancement du Centre de Contrôle HFSQL
Le Centre de Contrôle HFSQL peut être lancé :

- depuis WINDEV, WEBDEV ou WINDEV Mobile : sous le volet "Outils", dans le groupe "Base de données", cliquez sur "HFSQL".
- en lançant directement le programme "CCxx0HF.EXE".
- directement à partir d'un fichier de données (double-clic sur un fichier ".FIC"),

### Conditions d'utilisation
Le Centre de Contrôle HFSQL est un outil redistribuable.

## Fonctionnalités du Centre de Contrôle HFSQL

Le Centre de Contrôle HFSQL permet de gérer : [image: Options du CCHF]

- Les bases de données HFSQL Client/Serveur. Il est possible d'obtenir des informations et de manipuler :
  - [le serveur](35400014.md) : Arrêt, redémarrage, configuration du serveur, définition des utilisateurs, tâches planifiées, sauvegardes.
  - [la base de données](35400015.md) : Description, recherche, sauvegarde, maintenance des fichiers de données, transactions, etc.
  - [chaque fichier de données de la base](35400016.md) : Description, contenu, recherche, journal, transactions, etc.
- Les [fichiers de données HFSQL Classic](35400010.md). Il est possible d'obtenir des informations et de manipuler chaque fichier de données de la base de données : description, contenu, recherche, journal, transactions, etc.
- [Une analyse](3540003.md). Il est possible d'obtenir des informations et de manipuler l'ensemble des fichiers de données de l'analyse. Ces fichiers de données peuvent être :
  - HFSQL Client/Serveur,
  - HFSQL Classic,
  - Bases tierces
- Les bases tierces. Il est possible d'obtenir des informations et de manipuler des fichiers de données non HFSQL :
  - Oracle,
  - SQL Server
  - MySQL
  - etc.
- [Un cluster HFSQL](3540005.md). Il est possible d'obtenir des informations et de manipuler des fichiers de données HFSQL Cluster.

## Options du Centre de Contrôle HFSQL

Le Centre de Contrôle HFSQL propose plusieurs options générales concernant l'ensemble des fonctionnalités disponibles. Pour afficher ces options :

1. Déroulez le menu du Centre de Contrôle HFSQL ().
2. Sélectionnez "Options".

La fenêtre de configuration des options apparaît. Cette fenêtre regroupe les options selon plusieurs thèmes :

- Options générales.
- Visualisation des données.
- Requêtes SQL.
- Nouveauté Abonnement
  Optimisations et réparations.
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
- Nouveauté Abonnement
  Trousseau de mots de passe.
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).

Attention : A partir de la version 2024, le format de sauvegardes des données du CCHFSQL (paramétrage, liste des connexions, historique des requêtes, etc.) n'est pas compatible avec les précédentes versions du Centre de Contrôle HFSQL. Les paramètres des anciennes versions sont récupérés à la première ouverture du Centre de Contrôle HFSQL. Les anciennes versions du Centre de Contrôle HFSQL continuent à lire et à sauver les données dans l'ancien format.

### Options "Général"
Les options disponibles sont les suivantes :

- **Afficher l'icône "x" permettant de visualiser les mots de passe saisis** : Permet d'afficher un oeil à côté des champs de type "Mot de passe". Il sera ainsi possible de connaître le mot de passe en cliquant sur cette icône.
- **Afficher la base système des serveurs HFSQL (nécessite le droit de connexion à la base)** : Permet d'afficher la base système des serveurs HFSQL.
- **Mémoriser les volets affichés (connexions HFSQL Client/Serveur uniquement)** : Permet de mémoriser les vues ouvertes (volets affichant les informations sur le serveur, la base de données, le fichier de données, la requête, etc.) lorsque le Centre de Contrôle est fermé ou lors d'une déconnexion. Les volets sont automatiquement réouverts à la prochaine connexion. Cette option est sélectionnée par défaut.
  L'option "réinitialiser" permet de réinitialiser les vues mémorisées.
- **Ordre d'affichage des rubriques** : Permet de spécifier l'ordre d'affichage des rubriques utilisé lors de l'affichage de la description des fichiers de données (onglet "Description" du fichier de données). Il est possible de choisir l'ordre logique (par défaut) ou l'ordre alphabétique.
- **Nombre max. de volets ouverts simultanément** : Permet de limiter le nombre maximum de volets ouverts simultanément. Il est ainsi possible d'économiser des ressources mémoire.
- **"Boîtes de dialogue "Ne plus afficher""** : Permet de lister les questions et les réponses mémorisées des boîtes de dialogue "Ne plus afficher", affichées par le Centre de Contrôle HFSQL. Il est ainsi possible de désactiver ou réactiver l'affichage de ces boîtes de dialogue.

### Options "Visualisation des données"
La visualisation des données d'un fichier de données est effectuée dans une table d'affichage. Le Centre de Contrôle HFSQL donne la possibilité de paramétrer de nombreuses options d'affichage. Les options disponibles sont les suivantes :

- **Afficher les rubriques de type mémo texte** : Permet d'afficher dans le contenu du fichier de données les rubriques de type mémo texte.
- Rubriques de type mémo binaire :
  - **Afficher le contenu** : Permet d'afficher directement le contenu du mémo binaire. Attention, cette option peut ralentir l'affichage du contenu du fichier de données.
  - **Afficher le contenu uniquement si la qualité de la connexion est suffisante, sinon afficher la taille** : Les mémos images seront affichés uniquement si la qualité de la connexion est suffisante. Dans le cas contraire, seule la taille du mémo sera affichée. Cette option permet d'optimiser les accès et l'affichage des données. Attention, cette option peut ralentir l'affichage du contenu du fichier de données.
  - **Afficher uniquement la taille** (option par défaut) : Permet d'afficher la rubrique de type mémo binaire en spécifiant uniquement la taille du mémo.
  - **Ne pas afficher** : Les rubriques de type mémo binaire ne seront pas affichées dans le contenu du fichier de données.
- **Afficher les clés composées** : Permet d'afficher les clés composées et leur contenu.
- **Afficher le texte en multi-lignes** : Cette option permet d'afficher toutes les rubriques de type Texte sur plusieurs lignes si nécessaire. Dans ce cas, il est possible de définir :
  - si uniquement les mémos texte sont concernés.
  - le nombre maximum de lignes.
- **Afficher les numéros d'enregistrement** : Permet d'afficher le numéro d'enregistrement en première colonne de la table listant les enregistrements du fichier de données.
- **Afficher la date de dernière écriture des enregistrements (bulle en survol et fiche)** : Permet d'afficher la date de modification de l'enregistrement dans une bulle d'aide.

Il est également possible de spécifier si la modification des enregistrements peut être effectuée directement depuis le Centre de Contrôle HFSQL via l'option "Autoriser la modification des enregistrements dans la table". Il suffit ensuite de préciser le mode d'ouverture des fiches des enregistrements sur le double-clic (mode visualisation ou édition).

### Options "Requêtes SQL"
Les options disponibles sont les suivantes :

- **Activer la gestion de l'intégrité lors de l'exécution des requêtes SQL** : Permet de prendre en compte la gestion de l'intégrité lors de l'exécution des requêtes SQL depuis le Centre de Contrôle HFSQL.
- **Activer la gestion des doublons lors de l'exécution des requêtes SQL** : Permet de prendre en compte la gestion des doublons lors de l'exécution des requêtes SQL depuis le Centre de Contrôle HFSQL.

### Options "Optimisations et réparations"
Ces options permettent de gérer le fonctionnement des optimisations des fichiers de données.
L'optimisation des fichiers de donnes peut être réalisée :

- en mode synchrone : La réindexation effectuée via le Centre de Contrôle HFSQL est bloquante.
- en mode asynchrone : La réindexation est effectuée en mode asynchrone. Les résultats sont affiché dans l'onglet "Optimisation" et sont conservés sur le serveur pendant 48 heures.

Si l'option "Lancer les optimisations et réparations des fichiers de données en mode asynchrone* (si le serveur le supporte)" est cochée, le mode asynchrone est activé. Pour plus de détails, consultez [Centre de Contrôle HFSQL : Optimiser et réparer les fichiers de données](3540007.md).

**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.

### Options "Trousseau de mots de passe"
Le volet "Trousseau de mots de passe" permet de visualiser et de supprimer les différents mots de passe mémorisé par le Centre de Contrôle HFSQL.
Les mots de passe mémorisés dans le Centre de Contrôle HFSQL sont désormais sauvés dans un trousseau de mots de passe.

Ce trousseau correspond à un fichier stocké dans le répertoire des données du Centre de Contrôle HFSQL. Il est chiffré en utilisant les informations d'authentification de l'utilisateur Windows. Il n'est donc utilisable que pour cet utilisateur et sur cette machine.

Remarque : Seuls les nouveaux mots de passe mémorisés sont ajoutés au trousseau, les anciens mots de passe restent par compatibilité présents dans la sauvegarde du Centre de Contrôle HFSQL tant qu'aucune modification n'est effectuée.

Si le Centre de Contrôle HFSQL est lancé à partir d'une version qui ne gère pas le trousseau de mots de passe, les mots de passe mémorisés ne seront pas disponibles.

Les mots de passe mémorisés sont les suivants :

- Mots de passe des fichiers de données HFSQL classic.
- Mots de passe des fichiers de données HFSQL Client/Serveur.
- Mots de passe des analyses.
- Login et mot de passe des connexions HFSQL Client/Serveur.
- Login et mot de passe des connexions à des bases de données tierces.
- Login et mot de passe des connexions au Cluster HFSQL.
- Mot de passe des clusters.

**Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 2.
Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
