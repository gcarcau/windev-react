# Fonctions Python

> **Disponible :** **WINDEV** (Windows, Linux, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Les fonctions Python sont les suivantes :

| [PythonAjouteChemin](1410088169.md) | Permet d'ajouter le chemin d'un répertoire ou le chemin de l'environnement virtuel pour la recherche des modules Python. |
| --- | --- |
| [PythonExécute](1410088102.md) | Exécute une fonction présente dans un module Python. |
| [PythonInitialise](1410088100.md) | Indique l'emplacement de la DLL Python à charger. |
| [PythonTermine](1410088101.md) | Décharge la DLL Python et libère la mémoire. |
