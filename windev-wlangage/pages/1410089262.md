# Modification (Propriété)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad)

La propriété **Modification** permet de spécifier les modifications à effectuer. Cette propriété est disponible sur :

- une variable de type [mongoOpérationModificationUn](1410089164.md).
- une variable de type [mongoOpérationModificationTout](1410089165.md).
- Nouveauté Abonnement
  une variable de type [pdfProtection](1410091145.md).
  **Attention** : Cette fonctionnalité est disponible uniquement dans la version Abonnement à partir de WINDEV Suite 2025 Update 3.
  Pour plus de détails, consultez [Utiliser les nouveautés de WINDEV Suite 2025 spécifiques à l'abonnement](1410087359.md).
