# <Graphe>.SurfaceMaillage (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU))

Active ou désactive le maillage sur un graphe de type Surface.
**Remarque** : Le maillage d'un graphe de type Surface peut également être activé/désactivé dans la fenêtre de description du champ Graphe (option "Afficher un maillage sur la surface" dans l'onglet "Général" de la description du champ).

## Exemple

```wlangage
GRF_Graphe1.SurfaceMaillage(Vrai, BleuFoncé)
```

## Syntaxe

```wlangage
<Champ Graphe>.SurfaceMaillage(<Maillage> , <Couleur>)
```

`<Champ Graphe>` *Nom de champ*
> Nom du champ Graphe à manipuler (présent dans l'éditeur de fenêtres ou d'états).
`<Maillage>` *Booléen*
> - Vrai pour activer le maillage.
> - Faux pour désactiver le maillage.
`<Couleur>` *Entier ou constante de type Entier*
> Couleur du maillage. Cette couleur peut correspondre à :
>
> - une couleur RVB (obtenue avec la fonction [RVB](3029012.md)),
> - une couleur TSL (obtenue avec la fonction [TSL](3029057.md)),
> - une couleur prédéfinie (voir [les couleurs prédéfinies du WLangage](3010002.md)).
