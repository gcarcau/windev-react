# MatLit (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Java, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux, PHP, WEBDEV - Code Navigateur) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS, Mac Catalyst)

Lit la valeur d'un élément d'une matrice.
**Rappel** : Un élément d'une matrice est identifié par sa ligne et sa colonne.

## Exemple

```wlangage
// Lecture de l'élément (ligne 3, colonne 5)
ResLecture = MatLit("MaMatrice", 3, 5)
```

## Syntaxe

```wlangage
<Résultat> = MatLit(<Matrice> , <Ligne de l'élément> , <Colonne de l'élément>)
```

`<Résultat>` *Réel*
> Valeur de l'élément lu.
`<Matrice>` *Chaîne de caractères*
> Nom de la matrice à lire, défini avec la fonction [MatCrée](3050058.md).
`<Ligne de l'élément>` *Entier*
> Numéro de la ligne de l'élément à lire.
`<Colonne de l'élément>` *Entier*
> Numéro de la colonne de l'élément à lire.

## Remarques

### Existence de la matrice
L'existence de la matrice n'est pas vérifiée. Pour vérifier l'existence d'une matrice, utilisez la fonction [MatExiste](3050076.md).

### Gestion des erreurs
**Attention** : La fonction **MatLit** ne retourne pas de code d'erreur.
Pour savoir si des erreurs ont été générées par la lecture d'un élément, utilisez la fonction [MatErreur](3050044.md). Le libellé de l'erreur peut être connu grâce à la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.

**Classification Métier / UI : Code neutre**
