# RedisPipelineRAZ (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux)

Ignore les résultats de l'exécution d'une commande Redis ayant été ajoutée par la fonction [RedisPipelineAjoute](1000023542.md).
Nouveauté 2025
Cette fonction peut également être utilisée pour manipuler des données sur un serveur Valkey.

## Exemple

```wlangage
RedisPipelineAjoute(gRedis, "get p2")
RedisPipelineAjoute(gRedis, "get p1")
RedisPipelineAjoute(gRedis, "set p3 v3")
RedisPipelineAjoute(gRedis, "set p4 v4")

// Récupération des 2 premiers résultats
r1 est un redisRéponse = RedisPipelineRécupère(gRedis)
r2 est un redisRéponse = RedisPipelineRécupère(gRedis)
// Ignore les résultats suivants
RedisPipelineRAZ(gRedis)
```

## Syntaxe

```wlangage
<Résultat> = RedisPipelineRAZ(<Connexion>)
```

`<Résultat>` *Booléen*
> - Vrai si l'opération a été effectuée,
> - Faux dans le cas contraire.
`<Connexion>` *Variable de type redisConnexion*
> Nom de la variable de type [redisConnexion](1000023527.md) correspondant à la connexion au serveur Redis.

## Remarques

### Fonctionnement du pipeline
Lorsque l'ensemble des commandes souhaitées auront été ajoutées dans le pipeline, les résultats pourront être récupérés avec la fonction [RedisPipelineRécupère](1000023543.md).
Pour ne pas récupérer les résultats, il est possible d'utiliser la fonction **RedisPipelineRAZ**.

Si la fonction **RedisPipelineRAZ** n'a pas été utilisée, il doit y avoir autant d'appels à la fonction [RedisPipelineRécupère](1000023543.md) que d'appels à la fonction [RedisPipelineAjoute](1000023542.md).
