# BTInfoRadio (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Renvoie des informations spécifiques sur une radio Bluetooth connectée à la machine.

## Exemple

```wlangage
sListeRadios est une chaîne
sUneRadio est une chaîne
sId est une chaîne
sNom est une chaîne
sAdresseMAC est une chaîne
// Vide la liste
TableSupprimeTout(TABLE_Radios)
// Liste les radios
sListeRadios = BTListeRadio(btListeSimple)
// Parcours des radios
POUR TOUTE CHAÎNE sUneRadio DE sListeRadios SÉPARÉE PAR RC
	// Mémorise les informations du périphérique
	sId = ExtraitChaîne(sUneRadio, 1)
	sNom = ExtraitChaîne(sUneRadio, 3)
	sAdresseMAC = ExtraitChaîne(sUneRadio, 2)
	// Si le nom n'est pas renseigné, demande le nom explicitement
	SI sNom ~= "" ALORS sNom = BTInfoRadio(sId, btNom)
	// Remplit le champ Table avec les radios
	TableAjouteLigne(TABLE_Radios, Faux, sId, sNom, sAdresseMAC)
FIN
```

## Syntaxe

```wlangage
<Résultat> = BTInfoRadio(<Identifiant de la radio> , <Information demandée>)
```

`<Résultat>` *Chaîne de caractères*
> Information demandée sur la radio spécifiée.
`<Identifiant de la radio>` *Entier*
> Identifiant de la radio Bluetooth à manipuler. Cet identifiant est retourné par la fonction [BTListeRadio](1000017125.md).
`<Information demandée>` *Constante de type Entier*
> Information sur la radio. Le tableau suivant liste les informations disponibles et les valeurs pouvant être renvoyées :
>
> | *btAdresseMAC* | Adresse MAC du périphérique |
> | --- | --- |
> | *btClasseDePériphérique* | Classe du périphérique, pouvant correspondre à une des constantes suivantes :  - btCoD_AccèsRéseau - btCoD_AudioVidéo - btCoD_Divers - btCoD_Image - btCoD_Inconnu - btCoD_Jouet - btCoD_Ordinateur - btCoD_Périphérique - btCoD_Téléphone - btCoD_Vêtement |
> | *btClasseDeService* | Classe de service, pouvant correspondre à une ou à une combinaison des constantes suivantes :  - btCoS_Acquisition : Périphérique d'acquisition de données (scanner, micro, ...). - btCoS_Audio : Périphérique audio (micro, haut-parleur, ...). - btCoS_Information : Service d'information (Serveur Web ou WAP, ...). - btCoS_Positionnement : Périphérique de positionnement (GPS, ...). - btCoS_Réseau : Périphérique réseau (point d'accès, ...). - btCoS_Restitution : Imprimante, haut-parleur. - btCoS_Téléphonie : Appareil de téléphonie (téléphone, modem, ...). - btCoS_Transfert : Support de transfert (carte mémoire, ...). |
> | *btFabricant* | Nom du fabricant. |
> | *btIDClasseDeService* | Valeur numérique (entier sur 11 bits) correspondant à la classe de service. |
> | *btIDFabricant* | Identifiant du fabricant. |
> | *btIDMajeurClasseDePériphérique* | Valeur numérique (entier sur 5 bits) correspondant au numéro majeur de la classe de périphérique. |
> | *btIDMineurClasseDePériphérique* | Valeur numérique (entier sur 6 bits) correspondant au numéro mineur de la classe de périphérique. |
> | *btIDVersion* | Numéro de version fixé par le fabricant. |
> | *btNom* | Nom de la radio. |

## Remarques

Seules les piles bluetooth Microsoft, Bluesoleil et Broadcom (Widcomm) sont supportées par cette fonction. Pour connaître la pile utilisée, utilisez la fonction [BTPile](1000017229.md).
Les piles Broadcom (Widcomm) ne sont pas disponibles en 64 bits.

Pour plus de détails sur les clés supportées, consultez [Quelles piles utiliser ?](1000017231.md)
