# NbJourAffiché (Propriété)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad, Widget IOS, Mac Catalyst)

La propriété **NbJourAffiché** permet de :

- connaître et de modifier le nombre de jours affichés dans un champ Agenda ou dans un champ Planning.
- connaître le nombre de jours affichés dans un champ Diagramme de Gantt présent dans un état.

**Remarque** : Ce nombre de jours est utilisé uniquement pour l'affichage en mode "semaine".

## Exemple

```wlangage
// Affiche 2 jours dans le champ Planning
PLN_Planning1.NbJourAffiché = 2
```

## Syntaxe

#### Connaître le nombre de jours affichés

```wlangage
<Résultat> = <Champ manipulé>.NbJourAffiché
```

`<Résultat>` *Entier*
> Nombre de jours affichés dans le champ.
`<Champ manipulé>` *Nom de champ*
> Nom du champ manipulé :
>
> - Champ Agenda.
> - Champ Planning.
> - Champ Diagramme de Gantt d'un état.

#### Modifier le nombre de jours affichés

```wlangage
<Champ manipulé>.NbJourAffiché = <Nouveau nombre de jours>
```

`<Champ manipulé>` *Nom de champ*
> Nom du champ manipulé :
>
> - Champ Agenda.
> - Champ Planning.
`<Nouveau nombre de jours>` *Entier*
> Nombre de jours à afficher dans le champ.

## Remarques

- **Utilisation de la fonction AgendaChangeMode** :
  La fonction [AgendaChangeMode](1000019497.md) permet de modifier la plage temporelle affichée par un champ Agenda (Jour/Semaine/Mois). Si le nombre de jours affichés a été paramétré avec la propriété **NbJourAffiché**, la fonction [AgendaChangeMode](1000019497.md) écrase cette valeur avec la valeur spécifiée lors de l'appel à la fonction.
- **Utilisation de la fonction PlanningChangeMode** :
  La fonction [PlanningChangeMode](1000019440.md) permet de modifier la plage temporelle affichée par un champ Planning (Jour/Semaine/Mois). Si le nombre de jours affichés a été paramétré avec la propriété **NbJourAffiché**, la fonction [PlanningChangeMode](1000019440.md) écrase cette valeur avec la valeur spécifiée lors de l'appel à la fonction.
