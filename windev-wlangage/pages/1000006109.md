# ContactSupprime (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows) · **WINDEV Mobile** (Android, Widget Android, iPhone/iPad, Widget IOS) · **Autres** (Procédures stockées)

Supprime le contact en cours :

- du carnet d'adresses d'une messagerie Lotus Notes ou Outlook.
  **Attention** : Cette fonction **ne permet pas** de supprimer un contact dans le carnet d'adresses d'une messagerie Outlook Express.
- dans la liste des contacts de l'appareil (Android, iPhone ou iPad).

## Exemple

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ // Ouverture d'une session Lotus Notes
IDSession est un entier
IDSession = EmailOuvreSessionNotes("MotDePasse", "ServeurMars", "mail/julie.nsf", ...
 "C:\Lotus Notes\julie.id")
// Recherche du contact à supprimer
SI ContactCherche(IDSession, "Dupont", mContactNom, "Axelle", mContactPrénom) = Vrai ALORS
 // Suppression du contact
 ContactSupprime(IDSession)
 Info("Ce contact a été supprimé")
SINON
 Info("Aucun contact n'a été trouvé")
FIN

> _(Android, Widget Android, iPhone/iPad)_ gContactEnCours est un Contact
gtabContacts est un tableau de Contact
gtabContacts = ContactListe(Null)

// Supprime le contact sélectionné
gContactEnCours = gtabContacts[ZR_CONTACTS]

SI OuiNon(Oui, "Voulez-vous vraiment supprimer ce contact ?") = Oui ALORS
 // Suppression du contact
 ContactSupprime(gContactEnCours)
 // Rafraîchit les contacts
 RafraîchitContacts()
FIN

## Syntaxe

> _(WINDEV, WEBDEV - Code Serveur, Etats et Requêtes, Code Utilisateur (MCU), Ajax)_ Supprimer un contact dans la messagerie Lotus Notes ou Outlook Masquer les détails
<Résultat> = ContactSupprime(<Identifiant de la session>)

 <Résultat> : BooléenVrai si la suppression a été effectuée, Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction ErreurInfo avec la constante errMessage. <Identifiant de la session> : EntierIdentifiant de la session à utiliser. Cet identifiant est renvoyé par la fonction EmailOuvreSessionNotes, EmailOuvreSessionOutlook, NotesOuvreBase ou OutlookOuvreSession.

> _(Android, Widget Android, iPhone/iPad)_ Supprimer un contact dans la liste des contacts de l'appareil (Android, iPhone, iPad) Masquer les détails
<Résultat> = ContactSupprime(<Contact>)

 <Résultat> : BooléenVrai si la suppression a été effectuée, Faux dans le cas contraire. Pour connaître le libellé de l'erreur, utilisez la fonction ErreurInfo avec la constante errMessage. <Contact> : Variable de type ContactNom de la variable de type Contact correspondant au contact à supprimer.
