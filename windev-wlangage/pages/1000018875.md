# SysIconeSupprimeImage (Fonction)

> **Disponible :** **WINDEV** (Etats et Requêtes, Code Utilisateur (MCU))

Supprime l'icône en surimpression de l'icône de l'application dans la barre des tâches. Cette icône a pu être affichée grâce à la fonction [SysIconeAjouteImage](1000018874.md).
**Important** : La barre des tâches doit être configurée pour afficher le mode "Grandes icônes".

## Exemple

```wlangage
// Pendant le traitement, ajoute une icône de sablier sur l'icône de l'application
SysIconeAjouteImage("sablier.ico")
Sablier()
Traitement_Long()
Sablier(Faux)
// Supprime l'icône à la fin du traitement
SysIconeSupprimeImage()
```

## Syntaxe

```wlangage
<Résultat> = SysIconeSupprimeImage()
```

`<Résultat>` *Booléen*
> - Vrai si l'icône en surimpression a été supprimée,
> - Faux dans le cas contraire.

**Composante : wd300std.dll**
