# <Lecteur PDF>.Ouvre (Fonction)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WINDEV Mobile** (Android, iPhone/iPad)

Ouvre un fichier PDF dans un champ Lecteur PDF.

## Exemple

```wlangage
PDF_MonLecteurPDF.Ouvre("C:\MonDocument.pdf")
```

## Syntaxe

```wlangage
<Résultat> = <Champ Lecteur PDF>.Ouvre(<Chemin> [, <Mot de passe>])
```

`<Résultat>` *Booléen*
> - Vrai si l'ouverture du fichier PDF a été effectuée,
> - Faux dans le cas contraire. Le document actuellement affiché dans le champ n'est pas modifié. Pour connaître le libellé de l'erreur, utilisez la fonction [ErreurInfo](3013008.md) avec la constante *errMessage*.
`<Champ Lecteur PDF>` *Nom de champ*
> Nom du champ Lecteur PDF à manipuler.
`<Chemin>` *Chaîne de caractères*
> Chemin absolu ou relatif du fichier PDF à ouvrir.
`<Mot de passe>` *Chaîne de caractères optionnelle ou Chaîne secrète*
> Mot de passe nécessaire pour ouvrir le fichier (fichier PDF protégé en ouverture).
>
> - Si ce paramètre n'est pas spécifié et si le fichier PDF est protégé par mot de passe en ouverture, une fenêtre sera affichée pour permettre à l'utilisateur de saisir le mot de passe.
>    Si ce paramètre n'est pas spécifié et si le fichier PDF est protégé par mot de passe en ouverture, la fonction renverra une erreur.
> - Si le mot de passe spécifié n'est pas valide pour le document, la fonction renverra une erreur.
>
> Nouveauté 2025
> **Utilisation de chaînes secrètes** : Si vous utilisez le coffre-fort de chaînes secrètes, le type de la chaîne secrète utilisable pour ce paramètre doit être "Chaîne Ansi ou Unicode".
> Pour plus de détails sur les chaînes secrètes et l'utilisation du coffre-fort, consultez [Coffre-fort de chaînes secrètes](1410087353.md).

## Remarques

- Pour fermer le document PDF affiché dans le champ Lecteur PDF, utilisez la fonction [<Lecteur PDF>.Ferme](1000023695.md).
- A partir de la version 28, cette fonction n'est pas supportée par les processeurs ARM 32 bits. En effet, les nouveautés en matière de gestion des PDF imposent une exécution en 64 bits.
  Si une application doit être exécutée sur une flotte existante d'appareils ARM 32 bits, la génération de cette application doit être effectuée avec la version 27 de WINDEV Mobile.
