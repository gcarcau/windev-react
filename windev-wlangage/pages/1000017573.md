# gglTéléphone (Type de variable)

> **Disponible :** **WINDEV** (Windows, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows)

Le type **gglTéléphone** permet de décrire et de modifier le numéro de téléphone d'un contact.
Ce type de variable est utilisé par le type [gglContact](1000017434.md).

**Remarque** : Pour plus de détails sur la déclaration de ce type de variable et l'utilisation des propriétés WLangage, consultez [Déclaration d'une variable](1514032.md).

## Exemple

```wlangage
// Connexion à Google
Cnx est une gglConnexion
Cnx.Email = "balthazar@gmail.com"
Cnx.MotDePasse = "azerty"
Cnx.NomApplication = "MonAppli-01"
SI GglConnecte(Cnx) = Faux ALORS
	Erreur(ErreurInfo())
FIN

...

// Récupération du tableau des contacts
tabContacts est un tableau de gglContact
tabContacts = GglListeContact(Cnx)

// Affichage des téléphones du premier contact
MonContact est un gglContact = tabContacts[1]
MonTéléphoneContact est un gglTéléphone dynamique
POUR TOUT MonTéléphoneContact DE MonContact.Téléphone
	Trace(MonTéléphoneContact.Libellé + " : " + MonTéléphoneContact.Numéro)
FIN
```

## Propriétés

### Propriétés spécifiques à la description des variables de type gglTéléphone
Les propriétés suivantes peuvent être utilisées pour manipuler une variable de type **gglTéléphone** :

| Nom | Type manipulé | Effet |
| --- | --- | --- |
| Libellé | Chaîne de caractères | Description du numéro de téléphone. |
| Numéro | Chaîne de caractères | Numéro de téléphone. |
| Principal | Chaîne de caractères | - Vrai si le numéro correspond au numéro de téléphone principal du contact, - Faux dans le cas contraire. |
| Type | Constante de type entier | Type du numéro de téléphone correspondant à une des variables suivantes :  - *gglAutre* : Autre numéro. - *gglBureau* : Numéro professionnel. - *gglDomicile* : Numéro du domicile. - *gglFax* : Numéro de fax. - *gglFaxDomicile* : Numéro de fax du domicile. - *gglFaxTravail* : Numéro de fax professionnel. - *gglPager* : Numéro de pager / bippeur. - *gglPériphériqueMobile* : Numéro du téléphone portable. |
