# HExécutePlanification (Fonction)

> **Disponible :** **WINDEV** (Windows, Linux, Etats et Requêtes, Code Utilisateur (MCU)) · **WEBDEV** (Windows, Linux) · **WINDEV Mobile** (iPhone/iPad, Widget IOS)

Exécute immédiatement un élément planifié sans tenir compte de sa planification : tâche planifiée (procédure stockée), sauvegarde, optimisation, rafraîchissement d'une vue matérialisée.

## Exemple

```wlangage
tabDescSvg est un tableau dynamique de hDescriptionSauvegarde
tabDescSvg = HListePlanification(MaConnexionBase, hlpSauvegarde)
hDescSvg est une hDescriptionSauvegarde
POUR TOUT hDescSvg DE tabDescSvg
	HExécutePlanification(MaConnexionBase, hDescSvg)
FIN
```

## Syntaxe

#### Exécuter immédiatement une tâche planifiée

```wlangage
<Résultat> = HExécutePlanification(<Connexion> , <Tâche planifiée>)
```

`<Résultat>` *Booléen*
> - Vrai si la tâche planifiée a été exécutée,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion à manipuler. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Tâche planifiée>` *Variable de type hTâchePlanifiée*
> Nom de la variable de type [hTâchePlanifiée](1000017448.md) décrivant la tâche déclenchant une procédure stockée.

#### Exécuter une tâche d'optimisation planifiée

```wlangage
<Résultat> = HExécutePlanification(<Connexion> , <Tâche d'optimisation planifiée>)
```

`<Résultat>` *Booléen*
> - Vrai si la tâche d'optimisation planifiée a été exécutée,
> - Faux en cas d'erreur. La fonction [HErreurInfo](3044071.md) permet d'identifier l'erreur.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion à manipuler. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Tâche d'optimisation planifiée>` *Variable de type hOptimisationPlanifiée*
> Nom de la variable de type [hOptimisationPlanifiée](1000018854.md) manipulée.

#### Exécuter une planification de sauvegarde

```wlangage
<Résultat> = HExécutePlanification(<Connexion> , <Sauvegarde planifiée> [, <Type de sauvegarde>])
```

`<Résultat>` *Booléen*
> - Vrai si la sauvegarde planifiée a été exécutée,
> - Faux dans le cas contraire.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion à manipuler. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Sauvegarde planifiée>` *Variable de type hDescriptionSauvegarde*
> Nom de la variable de type [hDescriptionSauvegarde](1000017455.md) manipulée.
`<Type de sauvegarde>` *Booléen optionnel*
> Type de sauvegarde à effectuer :
>
> - Vrai (valeur par défaut) : Sauvegarde différentielle.
> - Faux : Sauvegarde complète.
>
>
> **Remarque** : Une sauvegarde différentielle peut être effectuée uniquement si la tâche de sauvegarde comporte une planification différentielle.

#### Exécuter une planification de rafraîchissement d'une vue matérialisée

```wlangage
<Résultat> = HExécutePlanification(<Connexion> , <Vue matérialisée>)
```

`<Résultat>` *Booléen*
> - Vrai si la planification a été exécutée,
> - Faux dans le cas contraire.
`<Connexion>` *Chaîne de caractères ou variable de type Connexion*
> Connexion à manipuler. Cette connexion correspond :
>
> - soit au nom de la connexion définie sous l'éditeur d'analyses ou grâce aux fonctions [HDécritConnexion](3044205.md) ou [HOuvreConnexion](3044107.md).
> - soit au nom d'une variable de type [Connexion](1514073.md).
`<Vue matérialisée>` *Variable de type hPlanificationVueMatérialisée*
> Nom de la variable de type [hPlanificationVueMatérialisée](1000021444.md) contenant la description des vues matérialisées à rafraîchir.
